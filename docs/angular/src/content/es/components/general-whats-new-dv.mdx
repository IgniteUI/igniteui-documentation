# Novedades de Ignite UI for Angular

Este tema ofrece información sobre los cambios importantes en Ignite UI for Angular, así como sobre cómo actualizar el código antiguo a la API más reciente.

## Funciones de gráficos

Esta versión introduce varias opciones nuevas y mejoradas de diseño visual y de configuración para todos los componentes de gráficos. p. ej. Data Chart, Category Chart y Financial Chart.

### Valores predeterminados de gráficos rediseñados

- Nueva paleta de colores para series y marcadores en todos los gráficos

- Se cambió la serie Bar/Column/Waterfall para que tenga esquinas cuadradas en lugar de redondeadas
- Se cambiaron los colores de la serie Scatter High Density para las propiedades de calor mín./máx.
- Se cambiaron los colores de las series Financial/Waterfall para el relleno negativo de sus elementos visuales
- Se cambió el grosor del marcador de 1px a 2px
- Se cambió el relleno del marcador para que coincida con el contorno del marcador en PointSeries, BubbleSeries, ScatterSeries y PolarScatterSeries
  - Tenga en cuenta que puede establecer la propiedad `MarkerFillMode` en Normal para deshacer este cambio
- Etiquetado comprimido para TimeXAxis y OrdinalTimeXAxis
- Nuevas propiedades de marcador:
  - `MarkerFillMode`: puede establecerse en 'MatchMarkerOutline' para que el marcador dependa del contorno
  - `MarkerFillOpacity`: puede establecerse en un valor de 0 a 1
  - `MarkerOutlineMode`: puede establecerse en 'MatchMarkerBrush' para que el contorno del marcador dependa del color del pincel de relleno
- Nueva propiedad de serie `OutlineMode`:
  - Puede establecerse para alternar la visibilidad del contorno de la serie. Tenga en cuenta que, en Data Chart, la propiedad está en la serie
- Nuevas propiedades de margen del área de trazado:
  - `PlotAreaMarginLeft`
  - `PlotAreaMarginTop`
  - `PlotAreaMarginRight`
  - `PlotAreaMarginBottom`
  - `ComputedPlotAreaMarginMode`
  - Las propiedades de margen del área de trazado definen la zona de desbordamiento que se introduce en el viewport cuando el gráfico está en el nivel de zoom predeterminado. Un caso de uso habitual es dejar espacio entre los ejes y los primeros y últimos puntos de datos. Tenga en cuenta que `ComputedPlotAreaMarginMode`, indicada más abajo, establecerá automáticamente el margen cuando los marcadores estén habilitados. Las demás están diseñadas para especificar un `Double` que represente el grosor, donde PlotAreaMarginLeft, etc., ajusta el espacio en los cuatro lados del gráfico.
- Nuevas propiedades de resaltado
  - `HighlightingMode`: establece si las series sobre las que se pasa el cursor, o las que no, se desvanecen o se aclaran
  - `HighlightingBehavior`: establece si la serie se resalta según la posición del ratón, p. ej. directamente sobre el elemento o el más cercano
  - Tenga en cuenta que, en versiones anteriores, el resaltado se limitaba a desvanecerse al pasar el cursor.
- Se añadió resaltado para las siguientes series:
  - Apilado
  - Dispersión
  - Polar
  - Radial
  - Forma
- Se añadieron capas de anotación a las siguientes series:
  - Apilado
  - Dispersión
  - Polar
  - Radial
  - Forma
- Se añadió compatibilidad para sobrescribir el origen de datos de fragmentos de pila individuales dentro de una serie apilada
- Se añadieron eventos de estilo personalizado a las series Stacked, Scatter, Range, Polar, Radial y Shape
- Se añadió compatibilidad para sincronizar automáticamente el zoom vertical con el contenido de la serie
- Se añadió compatibilidad para ampliar automáticamente los márgenes horizontales del gráfico según las etiquetas iniciales mostradas

### Funciones de la leyenda del gráfico

- Se añadió orientación horizontal para ItemLegend
  - Los siguientes tipos de gráfico pueden usar ItemLegend en orientación horizontal:
    - Burbuja
    - Anillo
    - Circular
- `LegendHighlightingMode`: habilita el resaltado de series al pasar el cursor sobre los elementos de la leyenda

### Funciones del mapa geográfico (CTP)

- Se añadió compatibilidad para mostrar el mapa en modo envolvente (desplazamiento horizontal infinito)  
- Se añadió compatibilidad para desplazar la visualización de algunas series del mapa al envolver alrededor del origen de coordenadas  
- Se añadió compatibilidad para resaltar la serie de formas
- Se añadió compatibilidad para algunas capas de anotación en la serie de formas
