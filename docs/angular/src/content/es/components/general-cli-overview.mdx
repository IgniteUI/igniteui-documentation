# Ignite UI CLI para Angular

Nuestras herramientas de CLI proporcionan plantillas de proyecto preconfiguradas para el conjunto de herramientas de Ignite UI for Angular, que le ayudan a poner en marcha su próxima aplicación en muy poco tiempo. Ignite UI CLI es una herramienta de línea de comandos independiente para crear y generar la estructura de sus aplicaciones para distintos frameworks, y proporciona un aumento sustancial de la productividad para los desarrolladores.

## Primeros pasos

Para empezar, instale la CLI:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
npm install -g igniteui-cli
</pre>

El comando de instalación anterior pondrá Ignite UI CLI a disposición para crear, generar la estructura y ejecutar su aplicación de Ignite UI for Angular.

## Añadir componentes

Una vez creado un proyecto, puede añadir más plantillas de componentes en cualquier momento usando **ig add**. Si ejecuta este comando sin parámetros, le guiará por las plantillas disponibles mediante una navegación por teclado en la CLI para añadir el control que elija.

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig add
</pre>

También puede ejecutar el comando **ig list** para obtener una lista completa de las plantillas compatibles en el proyecto actual que ha creado.

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig list
</pre>

Después de ejecutar **ig list** y encontrar la plantilla de componente que quiere añadir, puede hacerlo rápidamente siguiendo esta plantilla en la línea de comandos:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig add [component_template] [component_name]
</pre>

El "component\_template" anterior coincidirá, por lo general, con un componente de Ignite UI for Angular ("grid", "category-chart", "linear-gauge", etc.).

Por ejemplo, si quisiera añadir a su aplicación un componente de plantilla de cuadrícula de datos llamado "MyGridComponent", podría ejecutar lo siguiente:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig add grid MyGridComponent
</pre>

## Compilar y ejecutar la aplicación

Para compilar y ejecutar la aplicación de Ignite UI for Angular, puede llamar a los comandos **ig build** e **ig run**:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig build
ig run
</pre>
