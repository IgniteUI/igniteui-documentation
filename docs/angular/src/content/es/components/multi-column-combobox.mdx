# Descripción general del cuadro combinado de varias columnas de Angular

El cuadro combinado de varias columnas genera automáticamente columnas para las propiedades del objeto de datos. Este componente es único porque es un cuadro combinado que visualiza grandes cantidades de datos de forma similar a una cuadrícula de datos incrustada en la lista desplegable.

### Configurar el modo de ordenación

El usuario puede ordenar las columnas que se muestran en el cuadro combinado de varias columnas haciendo clic en el encabezado de la columna en la lista desplegable. También puede modificarse la forma en que se configura la ordenación, ya que las columnas pueden ordenarse por una sola columna o por varias, y pueden limitarse a ascendente y descendente, o bien ser de tres estados. Esto se hace estableciendo la propiedad `SortMode` del componente.

Tenga en cuenta que las opciones de ordenación de tres estados permiten que las columnas ordenadas vuelvan a quedar sin ordenar.
