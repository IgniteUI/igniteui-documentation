# Descripción general de Angular Sparkline

El componente sparkline de Ignite UI for Angular es un control de gráficos ligero. Está pensado para renderizarse a pequeña escala, como en una celda de cuadrícula, pero también puede renderizarse de forma independiente.

El control sparkline tiene varios elementos visuales y funciones correspondientes que pueden configurarse y personalizarse, como el tipo de gráfico, los marcadores, los rangos, las líneas de tendencia, la representación de valores desconocidos y las información emergentes (tooltips).

## Tipos de sparkline

El componente sparkline de Ignite UI for Angular admite los siguientes tipos de sparkline:

- [`Area`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#area)
- [`Column`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#column)
- [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line)
- [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss)

El tipo se define estableciendo la propiedad [`displayType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#displaytype). Si no se especifica la propiedad [`displayType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#displaytype), de forma predeterminada se muestra el tipo [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line).

El tipo de sparkline [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) es un gráfico de columnas, en el que el valor de cada columna es igual al máximo positivo (para valores positivos) o al mínimo negativo (para valores negativos) del conjunto de datos enlazado; a menudo denota una victoria o una derrota, o conceptos opuestos similares. Para que el sparkline [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) se muestre correctamente, el conjunto de datos debe tener valores positivos y negativos.

Si el sparkline [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) está enlazado a los mismos datos que los demás tipos, como el tipo [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line), que puede enlazarse a una colección de valores numéricos, el componente sparkline seleccionará dos valores de la colección (el más alto y el más bajo) y renderizará el sparkline a partir de esos valores.

```html
<igx-sparkline height="200px" width="400px"
    [dataSource]="data"
    valueMemberPath="Value"
    displayType="Area" />
```

## Marcadores

El componente sparkline de Ignite UI for Angular le permite mostrar marcadores como iconos circulares de colores en sus series, para indicar los puntos de datos individuales en función de las coordenadas X/Y. Los marcadores pueden establecerse en sparklines de los tipos de visualización [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line), [`Area`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#area) y [`Column`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#column). El tipo [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) de sparkline no admite actualmente marcadores. De forma predeterminada, los marcadores no se muestran.

Los marcadores del sparkline pueden colocarse en cualquier combinación de las siguientes ubicaciones:

- `All`: muestra marcadores en todos los puntos de datos del sparkline.
- `Low`: muestra marcadores en el punto de datos del valor más bajo. Si hay varios puntos con el valor más bajo, se mostrará en cada uno de ellos.
- `High`: muestra marcadores en el punto de datos del valor más alto. Si hay varios puntos con el valor más alto, se mostrará en cada uno de ellos.
- `First`: muestra un marcador en el primer punto de datos del sparkline.
- `Last`: muestra un marcador en el último punto de datos del sparkline.
- `Negative`: muestra marcadores en los puntos de datos negativos representados en el sparkline.

Todos los marcadores mencionados anteriormente pueden personalizarse mediante la propiedad de los tipos de marcador correspondientes en cuanto a color, visibilidad y tamaño. Por ejemplo, los marcadores `Low` anteriores tendrán las propiedades [`lowMarkerBrush`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#lowmarkerbrush), [`lowMarkerVisibility`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#lowmarkervisibility) y [`lowMarkerSize`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#lowmarkersize).

```html
<igx-sparkline
    highMarkerVisibility="Visible"
    lowMarkerVisibility="Visible"
    firstMarkerVisibility="Visible"
    lastMarkerVisibility="Visible"
    negativeMarkerVisibility="Visible"
    markerVisibility="Collapsed"
    markerSize="10"
    firstMarkerSize="10"
    lastMarkerSize="10"
    lowMarkerSize="10"
    highMarkerSize="10"
    negativeMarkerSize="10"/>
```

## Rango normal

La función de rango normal del componente sparkline de Ignite UI for Angular es una franja horizontal que representa un rango predefinido y significativo cuando se visualizan los datos. El rango normal puede establecerse como un área sombreada delineada con el color deseado.

El rango normal puede ser más ancho que el punto de datos máximo o incluso mayor, y también puede ser tan fino como el tipo de visualización [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line) del sparkline, por ejemplo, para servir como indicador de umbral. El ancho del rango normal se determina mediante las tres propiedades siguientes, que son los ajustes mínimos necesarios para mostrar el rango normal:

- [`normalRangeVisibility`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangevisibility): indica si el rango normal es visible o no.
- [`normalRangeMaximum`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangemaximum): el borde inferior del rango.
- [`normalRangeMinimum`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangeminimum): el borde superior del rango.

De forma predeterminada, el rango normal no se muestra. Cuando está habilitado, el rango normal aparece con un aspecto en gris claro, que también puede configurarse mediante la propiedad [`normalRangeFill`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangefill).

También puede configurar si el rango normal se muestra delante o detrás de las series representadas en el componente sparkline estableciendo la propiedad [`displayNormalRangeInFront`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#displaynormalrangeinfront).

```html
<igx-sparkline
    normalRangeVisibility="Visible"
    normalRangeMinimum="1"
    normalRangeMaximum="4"
    normalRangeFill="rgba(88, 88, 88, 0.4)"
    displayNormalRangeInFront="true" />
```

## Líneas de tendencia

El componente sparkline de Ignite UI for Angular admite una serie de líneas de tendencia que se muestran como otra capa sobre la capa del sparkline. Para mostrar un sparkline, puede usar la propiedad [`trendLineType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#trendlinetype).

Las líneas de tendencia se calculan según el algoritmo especificado por la propiedad [`trendLineType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#trendlinetype), usando los valores de los datos a los que está enlazado el gráfico.

Las líneas de tendencia solo pueden mostrarse una a la vez y, de forma predeterminada, la línea de tendencia no se muestra.

A continuación puede ver la lista de líneas de tendencia admitidas:

- [`None`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#none)
- [`CubicFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#cubicfit)
- [`CumulativeAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#cumulativeaverage)
- [`ExponentialAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#exponentialaverage)
- [`ExponentialFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#exponentialfit)
- [`LinearFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#linearfit)
- [`LogarithmicFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#logarithmicfit)
- [`ModifiedAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#modifiedaverage)
- [`PowerLawFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#powerlawfit)
- [`QuadraticFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#quadraticfit)
- [`QuarticFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#quarticfit)
- [`QuinticFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#quinticfit)
- [`SimpleAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#simpleaverage)
- [`WeightedAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#weightedaverage)

El siguiente ejemplo de código muestra cómo habilitar una línea de tendencia en el componente sparkline de Ignite UI for Angular:

```html
<igx-sparkline
    trendLineThickness="3"
    trendLinePeriod="5"
    trendLineType="ExponentialFit"
    trendLineBrush="gray" />
```

## Interpolación de valores desconocidos

El componente sparkline de Ignite UI for Angular puede detectar valores desconocidos y renderizar el espacio correspondiente a ellos mediante un algoritmo de interpolación específico. Si sus datos contienen valores nulos y no usa esta función, es decir, no se especifica ninguna interpolación, el valor desconocido no se representará.

Para representar los valores desconocidos, puede establecer la propiedad [`unknownValuePlotting`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#unknownvalueplotting) del componente sparkline.

```html
<igx-sparkline
    unknownValuePlotting="LinearInterpolate" />
```

## Sparkline en la cuadrícula de datos

Puede incrustar el componente sparkline de Ignite UI for Angular en una columna de plantilla de la cuadrícula de datos u otros componentes que admitan plantillas. El siguiente ejemplo de código muestra cómo hacerlo:

```html
<igx-grid #grid1 [data]="data | async"
[height]="'500px'" width="100%" [autoGenerate]='false' >
    {/* ... */}
    <igx-column [field]="'OrderHistory'" [width]="'160px'" header="Order History" >
        <ng-template igxCell let-val>
            <igx-sparkline height="50px" width="150px"
            [dataSource]="val"
            valueMemberPath="Sold"
            displayType="Line"
            lineThickness="2"
            brush="rgb(21, 190, 6)"  >
            </igx-sparkline>
        </ng-template>
    </igx-column>
    {/* ... */}
</igx-grid>
```
