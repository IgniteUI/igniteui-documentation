# Descripción general del componente Angular Divider

<div class="highlight">
El componente divider permite a los usuarios separar el contenido tanto en horizontal como en vertical.
</div>

## Ejemplo de Angular Divider

De forma predeterminada, el divider es una línea horizontal continua.

## Primeros pasos con Ignite UI for Angular Divider

Para empezar con el componente Ignite UI for Angular Divider, primero debe instalar Ignite UI for Angular. En una aplicación Angular existente, escriba el siguiente comando:

```cmd
ng add igniteui-angular
```

Para una introducción completa a Ignite UI for Angular, lea el tema [_primeros pasos_](/general/getting-started).

El siguiente paso es importar `IgxDividerModule` en el archivo **app.module.ts**.

```typescript
// app.module.ts

...
import { IgxDividerModule } from 'igniteui-angular/directives';
// import { IgxDividerModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxDividerModule],
    ...
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` puede importar `IgxDividerComponent` como dependencia independiente.

```typescript
// home.component.ts

import { IgxDividerComponent } from 'igniteui-angular/directives';
// import { IgxDividerComponent } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: '<igx-divider></igx-divider>',
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxDividerComponent]
})
export class HomeComponent {}
```

Ahora que ha importado el módulo o el componente de Ignite UI for Angular Divider, puede empezar a usar el componente `igx-divider`.

## Uso de Angular Divider

### Divider vertical

Añadiendo el atributo <ApiLink type="Divider" member="vertical" label="vertical" /> y estableciendo su valor en `true`, puede cambiar la dirección del divider de horizontal a vertical.

```html
<igx-divider [vertical]="true"></igx-divider>
```

<Sample src="/layouts/divider-sample-2" height={238} alt="" />

### Divider discontinuo

El estilo predeterminado del divider es una línea `solid`, pero también puede ser `dashed`.
Para cambiar el aspecto predeterminado, basta con usar el atributo <ApiLink type="Divider" member="type" label="type" /> del divider y establecer su valor en `dashed`.

```html
<igx-divider type="dashed"></igx-divider>
```

<Sample src="/layouts/divider-sample-3" height={187} alt="" />

### Divider con sangría

El divider se puede establecer en ambos lados.
Para aplicar sangría al divider, establezca el atributo <ApiLink type="Divider" member="middle" label="middle" /> del divider en `true` e indique el valor <ApiLink type="Divider" member="inset" label="inset" /> deseado; el divider empezará a acortarse desde ambos extremos.

**Tenga en cuenta que debe añadir la unidad (px, rem, %...) al final del valor; de lo contrario, no funcionará.**

```html
// Both side
<igx-divider [middle]="true" inset="80px"></igx-divider>

// Left side only 
<igx-divider inset="40px"></igx-divider>

```

<Sample src="/layouts/divider-sample-4" height={311} alt="" />

Si el valor del atributo <ApiLink type="Divider" member="middle" label="middle" /> se establece en un valor falso, o si el atributo se omite por completo, el divider solo tendrá sangría a la izquierda.
