# Lista desplegable jerárquica de selección múltiple

Los siguientes ejemplos muestran cómo crear una lista desplegable jerárquica de selección múltiple que permite al usuario elegir una o varias opciones de una lista desplegable jerárquica con estilo de árbol.

## Descripción general del tema

Para la lista desplegable usaremos <ApiLink type="DropDown" />, así como <ApiLink type="ToggleActionDirective" /> para abrir y cerrar la lista.

Para visualizar los datos jerárquicos en la lista desplegable, puede usar <ApiLink type="Tree" /> o <ApiLink type="TreeGrid" />.

<ApiLink type="Chip" /> se usa para mostrar los elementos seleccionados.

## Selección

Para mostrar los nodos o las filas seleccionados de la lista, use <ApiLink type="Chip" /> gestionando los eventos que notifican los cambios de selección y rellenando el array `selectedNodes` / `selectedRows`. Esto se puede hacer suscribiéndose al evento <ApiLink type="Tree" member="nodeSelection" label="nodeSelection" /> de IgxTreeComponent y al evento <ApiLink type="TreeGrid" member="rowSelectionChanging" label="rowSelectionChanging" /> de IgxTreeGridComponent.

Para quitar el chip del DOM y deseleccionar el elemento del árbol o de la cuadrícula, tiene que gestionar el evento <ApiLink type="Chip" member="remove" label="remove" /> de IgxChipComponent.

Además, una forma de evitar que la lista desplegable se cierre al eliminar un chip consiste en comprobar la ruta compuesta del evento para ver si contiene un nodo `igx-chip` y, después, cancelar el evento en el controlador del evento <ApiLink type="DropDown" member="closing" label="closing" /> de `IgxDropDownComponent`.
