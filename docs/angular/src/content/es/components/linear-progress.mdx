# Descripción general del componente Angular Linear Progress

<div class="highlight">
El componente Linear Progress Bar Indicator de Ignite UI for Angular proporciona un indicador visual del proceso de una aplicación a medida que cambia. El indicador actualiza su aspecto según cambia su estado. El indicador puede darse estilo con una selección de colores en rayas o en sólido.
</div>

## Primeros pasos con Ignite UI for Angular Linear Progress

Para empezar con el componente Ignite UI for Angular Linear Progress, primero debe instalar Ignite UI for Angular. En una aplicación Angular existente, escriba el siguiente comando:

```cmd
ng add igniteui-angular
```

Para una introducción completa a Ignite UI for Angular, lea el tema [_primeros pasos_](/general/getting-started).

El siguiente paso es importar `IgxProgressBarModule` en el archivo **app.module.ts**:

```typescript
// app.module.ts

...
import { IgxProgressBarModule } from 'igniteui-angular/progressbar';
// import { IgxProgressBarModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxProgressBarModule],
    ...
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` puede importar `IgxLinearProgressBarComponent` como dependencia independiente, o usar el token [`IGX_LINEAR_PROGRESS_BAR_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/progressbar/src/progressbar/public_api.ts) para importar el componente y todos sus componentes y directivas de apoyo.

```typescript
// home.component.ts

import { IGX_LINEAR_PROGRESS_BAR_DIRECTIVES } from 'igniteui-angular/progressbar';
// import { IGX_LINEAR_PROGRESS_BAR_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: '<igx-linear-bar [value]="progress"></igx-linear-bar>',
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IGX_LINEAR_PROGRESS_BAR_DIRECTIVES],
  /* or imports: [IgxLinearProgressBarComponent] */
})
export class HomeComponent {
  public progress = 50;
}
```

Ahora que ha importado el módulo o las directivas de Ignite UI for Angular Progress Bar, puede empezar a usar el componente `igx-linear-bar`.

## Uso de Angular Linear Progress

Para entender mejor cómo funciona todo, vamos a crear un ejemplo sencillo, como el de la demostración:

```html
<igx-linear-bar [value]="100"></igx-linear-bar>
```

Después, debería ver el ejemplo de la demostración en su navegador.

### Tipos de progreso

Puede establecer el tipo de su barra usando el atributo <ApiLink type="LinearProgressBar" member="type" label="type" />. Hay cinco tipos de barras de progreso lineales: `default`, `error`, `success`, `info` y `warning`.

### Progreso con rayas

Puede hacer que la barra tenga rayas usando la propiedad <ApiLink type="LinearProgressBar" member="striped" label="striped" /> y estableciéndola en `true`.

Veamos cómo podemos crear distintos tipos de barras de progreso, con rayas o sin ellas.

```html
<div class="linear-container">

  <igx-linear-bar [value]="100" type="default"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="success" [striped]="true"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="error"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="info" [striped]="true"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="warning"></igx-linear-bar>
</div>
```


Así que, si lo hemos configurado todo correctamente, debería ver lo siguiente en su navegador:

### Progreso indeterminado

Si quiere hacer el seguimiento de un proceso que no se puede determinar con precisión, puede establecer la propiedad de entrada <ApiLink type="LinearProgressBar" member="indeterminate" label="indeterminate" /> en `true`.

### Duración de la animación

La propiedad de entrada <ApiLink type="LinearProgressBar" member="animationDuration" label="animationDuration" /> sirve para especificar cuánto debe durar el ciclo de animación.

El siguiente ejemplo establece la duración de la animación en 5 segundos.

```html
<igx-linear-bar [striped]="false" [value]="100" [animationDuration]="5000"></igx-linear-bar>
```

### Propiedades del texto

Puede alinear el texto usando la propiedad <ApiLink type="LinearProgressBar" member="textAlign" label="textAlign" />. Los valores permitidos son `left`, `center` y `right`.

Para ocultar el texto, use la propiedad <ApiLink type="LinearProgressBar" member="textVisibility" label="textVisibility" /> y establezca su valor en `false`.

Establezca la propiedad <ApiLink type="LinearProgressBar" member="textTop" label="textTop" /> en `true` para mover el texto encima de la barra.

La propiedad <ApiLink type="LinearProgressBar" member="text" label="text" /> puede usarse para personalizar el valor del propio texto.

Actualicemos nuestro ejemplo anterior usando las propiedades de texto mencionadas. También incluiremos una barra de progreso indeterminada.

```html
<div class="linear-container">

  <igx-linear-bar type="default" [value]="100"></igx-linear-bar>
  <igx-linear-bar
    type="success"
    [value]="100"
    class="indeterminate"
    [indeterminate]="true"
    [striped]="true"
  ></igx-linear-bar>
  <igx-linear-bar
    type="error"
    [value]="100"
    [textAlign]="positionEnd"
    [text]="'Custom text'"
  ></igx-linear-bar>
  <igx-linear-bar
    type="info"
    [value]="100"
    [textVisibility]="false"
    [striped]="true"
  ></igx-linear-bar>
  <igx-linear-bar
    type="warning"
    [value]="100"
    [textTop]="true"
  ></igx-linear-bar>
</div>
```

Y no olvide importar el enumerador <ApiLink type="IgxTextAlign" kind="variable" /> en su componente si usa la propiedad `textAlign`.

```typescript
import { ..., IgxTextAlign } from 'igniteui-angular/progressbar';
// import { ..., IgxTextAlign } from '@infragistics/igniteui-angular'; for licensed package
...

public positionCenter: IgxTextAlign = IgxTextAlign.CENTER;
public positionEnd: IgxTextAlign = IgxTextAlign.END;
```

<DocsAside type="info">
Si no se define el valor de la entrada <ApiLink type="LinearProgressBar" member="step" label="step" />, la actualización del progreso es **del 1 % del valor de <ApiLink type="LinearProgressBar" member="max" label="max" />**. Si quiere que el progreso avance más rápido, el valor de <ApiLink type="LinearProgressBar" member="step" label="step" /> debe ser mayor que (**<ApiLink type="LinearProgressBar" member="max" label="max" /> * 1 %**); del mismo modo, para un progreso más lento, <ApiLink type="LinearProgressBar" member="step" label="step" /> debe ser menor que la actualización de progreso predeterminada.
</DocsAside>

<DocsAside type="info">
Si el valor de <ApiLink type="LinearProgressBar" member="step" label="step" /> se define mayor que la entrada <ApiLink type="LinearProgressBar" member="value" label="value" />, solo hay una actualización, que recibe **el valor que se pasa para la actualización del progreso**.
</DocsAside>

### Progreso dinámico

Puede cambiar dinámicamente el valor de la barra de progreso usando controles externos, como botones. Para lograrlo, podemos enlazar el valor a una propiedad de la clase:

```html
<div class="linear-container">

  <igx-linear-bar [value]="currentValue" [max]="100"></igx-linear-bar>

  <div class="button-container">

    <button igxIconButton="flat" (click)="decrementProgress()">
      <igx-icon fontSet="material">remove</igx-icon>
    </button>
    <button igxIconButton="flat" (click)="incrementProgress()">
      <igx-icon fontSet="material">add</igx-icon>
    </button>
  
</div>
</div>
```

<DocsAside type="info">
Este componente usa Material Icons. Añada el siguiente enlace a su `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

Cree los métodos que incrementan y decrementan el valor:

```typescript
public currentValue: number;

public ngOnInit() {
    this.currentValue = 0;
}

public incrementProgress() {
    this.currentValue += 10;
    if (this.currentValue > 100) {
        this.currentValue = 100;
    }
}

public decrementProgress() {
    this.currentValue -= 10;
    if (this.currentValue < 0) {
        this.currentValue = 0;
    }
}
```

## Estilos

Para empezar a dar estilo a la barra de progreso lineal, tenemos que importar el archivo `index`, donde se exportan todas las funciones de tema y el mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Siguiendo el enfoque más sencillo, creamos un tema nuevo que extiende <ApiLink kind="sass" module="themes" type="function-progress-linear-theme" label="progress-linear-theme" code={true} /> y sobrescribe los parámetros `$fill-color-default` y `$text-color`.

```scss
$custom-theme: progress-linear-theme(
  $fill-color-default: #ecaa53,
  $text-color: #ecaa53,
);
```

### Inclusión de temas

El último paso es **incluir** el tema del componente en nuestra aplicación.

```scss
:host {
  @include tokens($custom-theme);
}
```
