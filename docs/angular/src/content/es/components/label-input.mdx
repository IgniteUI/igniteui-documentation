# Descripción general de las directivas Angular Label e Input

Las directivas Input y Label de Ignite UI for Angular se usan para decorar y dar estilo a elementos de entrada de una o varias líneas dentro de un componente `igx-input-group`.

## Primeros pasos con Ignite UI for Angular Label e Input

Para empezar con las directivas Label e Input de Ignite UI for Angular, primero debe instalar Ignite UI for Angular. En una aplicación Angular existente, escriba el siguiente comando:

```cmd
ng add igniteui-angular
```

Para una introducción completa a Ignite UI for Angular, lea el tema [_primeros pasos_](/general/getting-started).

El siguiente paso es importar `IgxInputGroupModule` en el archivo **app.module.ts**.

```typescript
// app.module.ts

import { FormsModule } from '@angular/forms';
import { IgxInputGroupModule } from 'igniteui-angular/input-group';
// import { IgxInputGroupModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxInputGroupModule, FormsModule],
    ...
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` puede importar `IgxLabelDirective`, `IgxInputDirective` y `IgxInputGroupComponent` como dependencias independientes, o usar el token [`IGX_INPUT_GROUP_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/input-group/src/input-group/public_api.ts) para importar el componente y todos sus componentes y directivas de apoyo.

```typescript
// home.component.ts

import { FormsModule } from '@angular/forms';
import { IGX_INPUT_GROUP_DIRECTIVES } from 'igniteui-angular/input-group';
// import { IGX_INPUT_GROUP_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: `
    <igx-input-group>
      <input igxInput name="fullName" type="text" [(ngModel)]="fullName" />
      <label igxLabel for="fullName">Full Name</label>
    </igx-input-group>
  `,
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IGX_INPUT_GROUP_DIRECTIVES, FormsModule],
  /* or imports: [IgxInputGroupComponent, IgxLabelDirective, IgxInputDirective, FormsModule] */
})
export class HomeComponent {
  public fullName = 'John Doe';
}
```

Ahora que ha importado el módulo o las directivas de Ignite UI for Angular Input Group, puede empezar a usar las directivas `igxLabel` y `igxInput` y el componente `igx-input-group`.

## Uso de Angular Label e Input

El estilo predeterminado de las directivas Label e Input sigue la especificación de campos de texto de Material Design
[**pautas**](https://material.io/guidelines/components/text-fields.html).

Para usar <ApiLink type="InputDirective" label="igxInput" /> y <ApiLink type="LabelDirective" label="igxLabel" />, tiene que envolverlos en un contenedor `<igx-input-group>`:

```html
<igx-input-group>
  <input igxInput name="fullName" type="text" />
  <label igxLabel for="fullName">Full Name</label>
</igx-input-group>
```

La directiva `igxInput` puede aplicarse a elementos HTML `<input>` y `<textarea>`, tanto en campos de texto de una línea como de varias líneas.

### Validación

Podemos validar un `input` usando el atributo <ApiLink type="InputDirective" member="required" label="required" />. Esto añadirá un asterisco junto a la etiqueta, para indicar que este campo debe completarse. La entrada se mostrará en verde o en rojo según la validación sea correcta o incorrecta.

```html
<igx-input-group>
  <input igxInput name="fullName" type="text" required="required" />
  <label igxLabel for="fullName">Full Name</label>
</igx-input-group>
```

### Enlace de datos

La directiva Input de Ignite UI for Angular admite tanto el enlace de datos unidireccional como el bidireccional. El siguiente código muestra cómo añadir un enlace de datos bidireccional usando `NgModel`:

```typescript
public user = {
    fullName: ""
};

```

en nuestro marcado:

```html
<igx-input-group>
  <input igxInput name="fullName" type="text" [(ngModel)]="user.fullName" required="required"/>
  <label igxLabel for="fullName">Full Name</label>
</igx-input-group>
```

### Foco y selección de texto

Puede añadir lógica para forzar `focus` en los elementos de entrada usando la directiva <ApiLink type="FocusDirective" />.

```html
<igx-input-group>
  <input igxInput [igxFocus]="isFocused" name="fullName" type="text" />
  <label igxLabel for="fullName">Full Name</label>
</igx-input-group>
```

<DocsAside type="info">
Para usar la directiva <ApiLink type="FocusDirective" />, tiene que importar <ApiLink type="FocusDirective" />.
</DocsAside>

Si quiere que el texto de un elemento de entrada, marcado con `igxInput`, se seleccione al recibir el foco, tiene que habilitar la directiva <ApiLink type="TextSelectionDirective" />.

```html
<igx-input-group>
  <input igxInput [igxTextSelection]="true" [igxFocus]="isFocused" name="fullName" type="text"/>
  <label igxLabel for="fullName">Full Name</label>
</igx-input-group>

<igx-input-group>
  <input igxInput [igxTextSelection]="true" name="email" type="text" />
  <label igxLabel for="email">Email</label>
</igx-input-group>
```

<DocsAside type="info">
Para usar la directiva <ApiLink type="TextSelectionDirective" />, tiene que importar <ApiLink type="TextSelectionDirective" />.
</DocsAside>
