# Agent Skills de Ignite UI for Angular

Ignite UI for Angular incluye **[Agent Skills](https://agentskills.io/)**: archivos de conocimiento estructurado que enseñan a los asistentes de programación con IA (GitHub Copilot, Cursor, Windsurf, Claude, Gemini CLI, JetBrains Junie, etc.) a trabajar con Ignite UI for Angular. Estos archivos de skills ofrecen orientación contextual sobre componentes, cuadrículas, operaciones de datos y temas, lo que permite a su asistente de IA generar código preciso e idiomático que sigue las buenas prácticas.

<DocsAside type="info">
El panorama de las herramientas de IA evoluciona rápidamente. Las ubicaciones de detección de skills y las opciones de distribución pueden cambiar a medida que se actualizan las herramientas y los IDE. Consulte siempre la documentación oficial de su herramienta o agente específico para obtener la información más reciente.
</DocsAside>

## Skills disponibles

Los archivos de skills se encuentran en el directorio [`skills/`](https://github.com/IgniteUI/igniteui-angular/tree/master/skills) del repositorio de Ignite UI for Angular:

| Skill | Ruta | Descripción |
|:------|:-----|:------------|
| Componentes y diseño | [`skills/igniteui-angular-components/SKILL.md`](https://github.com/IgniteUI/igniteui-angular/blob/master/skills/igniteui-angular-components/SKILL.md) | Componentes independientes, controles de formulario, superposiciones, diseño |
| Cuadrículas de datos | [`skills/igniteui-angular-grids/SKILL.md`](https://github.com/IgniteUI/igniteui-angular/blob/master/skills/igniteui-angular-grids/SKILL.md) | Cuadrícula, cuadrícula de árbol, cuadrícula jerárquica, cuadrícula dinámica, ordenación, filtrado, agrupación, paginación, datos remotos |
| Temas y estilos | [`skills/igniteui-angular-theming/SKILL.md`](https://github.com/IgniteUI/igniteui-angular/blob/master/skills/igniteui-angular-theming/SKILL.md) | Paletas, tipografía, elevaciones, temas de componentes, servidor MCP |
| Generar a partir de un diseño de imagen | [`skills/igniteui-angular-generate-from-image-design/SKILL.md`](https://github.com/IgniteUI/igniteui-angular/blob/master/skills/igniteui-angular-generate-from-image-design/SKILL.md) | Cree aplicaciones de Angular a partir de capturas de pantalla, maquetas y wireframes usando componentes de Ignite UI |

<DocsAside type="info">
A partir de Ignite UI for Angular **21.1.0**, estos skills se detectan automáticamente cuando se colocan en la ruta de skills de su agente (por ejemplo, `.claude/skills`, `.agents/skills`, `.cursor/rules/`). Esta versión incluye una migración opcional para añadir estos skills a su proyecto automáticamente.
</DocsAside>

## Ubicaciones de los skills

Cada herramienta de programación con IA detecta los skills en directorios concretos. Coloque sus archivos de skills en la ubicación adecuada para que su asistente de IA los encuentre y los use automáticamente. La convención general `.agents/skills/` es compatible con varias herramientas, mientras que cada herramienta también tiene sus propios directorios específicos.

### General (`.agents/skills/`)

El directorio `.agents/skills/` es una convención entre agentes compatible con varias herramientas, entre ellas [VS Code con Copilot](https://code.visualstudio.com/docs/copilot/customization/agent-skills), [OpenAI Codex](https://developers.openai.com/codex/skills), [Cursor](https://cursor.com/docs/skills), [Gemini CLI](https://geminicli.com/docs/cli/skills/#skill-discovery-tiers), [Antigravity](https://antigravity.google/docs/skills) y [Windsurf](https://docs.windsurf.com/windsurf/cascade/skills#skill-scopes). Copie los directorios de skills en `.agents/skills/` en la raíz de su proyecto:

```
.agents/
  skills/
    igniteui-angular-components/
      SKILL.md
    igniteui-angular-grids/
      SKILL.md
    igniteui-angular-theming/
      SKILL.md
    igniteui-angular-generate-from-image-design/
      SKILL.md
```

Para skills a nivel de usuario (globales), disponibles en todos los proyectos, use `~/.agents/skills/` en su lugar.

### GitHub Copilot

[GitHub Copilot](https://docs.github.com/en/copilot/concepts/agents/about-agent-skills) detecta los skills en:

| Ámbito | Ubicación |
|:------|:---------|
| Proyecto | `.github/skills/`, `.claude/skills/` |
| Personal | `~/.copilot/skills/`, `~/.claude/skills/` (solo el agente de programación de Copilot y la CLI de GitHub Copilot) |

> **Consejo:** En [VS Code](https://code.visualstudio.com/docs/copilot/customization/agent-skills), estas ubicaciones incluyen también las rutas generales `.agents/skills/` y `~/.agents/skills/`, y puede configurar ubicaciones de skills adicionales con el ajuste `chat.agentSkillsLocations`.

### Claude

[Claude](https://code.claude.com/docs/en/skills#where-skills-live) detecta los skills en:

| Ámbito | Ubicación |
|:------|:---------|
| Proyecto | `.claude/skills/` |
| Personal | `~/.claude/skills/` |

### Cursor

[Cursor](https://cursor.com/docs/skills#skill-directories) detecta los skills en:

| Ámbito | Ubicación |
|:------|:---------|
| Proyecto | `.agents/skills/`, `.cursor/skills/` |
| Usuario (global) | `~/.cursor/skills/` |

### Gemini CLI y Antigravity

[Gemini CLI](https://geminicli.com/docs/cli/skills/#skill-discovery-tiers) y [Antigravity](https://antigravity.google/docs/skills) detectan los skills en:

| Ámbito | Ubicación |
|:------|:---------|
| Espacio de trabajo | `.gemini/skills/`, `.agents/skills/` |
| Usuario | `~/.gemini/skills/`, `~/.agents/skills/` |

> **Consejo:** Use el comando `/skills` en Gemini CLI para ver y gestionar los skills instalados.

### Junie (IDE de JetBrains)

[Junie](https://junie.jetbrains.com/docs/agent-skills.html) detecta los skills en:

| Ámbito | Ubicación |
|:------|:---------|
| Proyecto | `.junie/skills/` |
| Usuario | `~/.junie/skills/` |

### Windsurf

[Windsurf](https://docs.windsurf.com/windsurf/cascade/skills#skill-scopes) detecta los skills en:

| Ámbito | Ubicación |
|:------|:---------|
| Espacio de trabajo | `.windsurf/skills/`, `.agents/skills/` |
| Global | `~/.codeium/windsurf/skills/`, `~/.agents/skills/` |

## Instalar los skills

Utilice una de las opciones siguientes para descargar los archivos de skills y colocarlos en la [ubicación de skills](#ubicaciones-de-los-skills) adecuada para su asistente de IA.

### **Opción A: use Ignite UI CLI**

El comando `ai-config` configura los servidores MCP, copia los archivos de skills específicos de cada framework en el directorio de skills de cada agente y configura los archivos de instrucciones, todo en un solo paso. Utilice `--assistants` para elegir qué asistentes de programación reciben la configuración de MCP y `--agents` para elegir qué agentes reciben los archivos de skills. Los archivos existentes solo se actualizan si su contenido ha cambiado. Si no se proporciona ningún parámetro, el comando entra en modo interactivo y le pide que seleccione asistentes y agentes. Para ver las opciones disponibles, consulte la tabla siguiente.

```bash
ig ai-config --assistants generic --agents claude
```

Utilice `--agents` con varios valores para dirigirse a varios agentes a la vez:

```bash
ig ai-config --assistants generic vscode --agents claude copilot cursor
```

| Indicador | Valores | Valor predeterminado |
|------|--------|---------|
| `--assistants` | `generic`, `vscode`, `cursor`, `gemini`, `junie`, `none` | Solicitado de forma interactiva |
| `--agents` | `generic`, `claude`, `copilot`, `cursor`, `codex`, `windsurf`, `gemini`, `junie`, `none` | Solicitado de forma interactiva |

**Usar Angular Schematics:**

```bash
ng generate @igniteui/angular-schematics:ai-config --assistants cursor --agents claude copilot
```

Esto también registra el servidor MCP `@angular/cli` junto con los servidores de Ignite UI.

<DocsAside type="info">
Si instaló Ignite UI for Angular manualmente y quiere copiar los skills sin ejecutar `ai-config`, los archivos de skills también están disponibles en `node_modules`. Para copiarlos en su proyecto (por ejemplo, en `.agents/skills/`), ejecute:
</DocsAside>

**macOS / Linux / Windows (PowerShell)**

```bash
cp -r node_modules/igniteui-angular/skills/. .agents/skills/
```

**Windows (símbolo del sistema)**

```cmd
robocopy node_modules\igniteui-angular\skills .agents\skills /E
```

O copie directorios de skills individuales según sea necesario:

**macOS / Linux / Windows (PowerShell)**

```bash
cp -r node_modules/igniteui-angular/skills/igniteui-angular-components .agents/skills/
cp -r node_modules/igniteui-angular/skills/igniteui-angular-grids .agents/skills/
cp -r node_modules/igniteui-angular/skills/igniteui-angular-theming .agents/skills/
cp -r node_modules/igniteui-angular/skills/igniteui-angular-generate-from-image-design .agents/skills/
```

**Windows (símbolo del sistema)**

```cmd
robocopy node_modules\igniteui-angular\skills\igniteui-angular-components .agents\skills\igniteui-angular-components /E
robocopy node_modules\igniteui-angular\skills\igniteui-angular-grids .agents\skills\igniteui-angular-grids /E
robocopy node_modules\igniteui-angular\skills\igniteui-angular-theming .agents\skills\igniteui-angular-theming /E
robocopy node_modules\igniteui-angular\skills\igniteui-angular-generate-from-image-design .agents\skills\igniteui-angular-generate-from-image-design /E
```

### **Opción B: use `GitHub CLI`**

La CLI de GitHub puede usarse para descargar los archivos de skills directamente del repositorio de Ignite UI for Angular. Ejecute los siguientes comandos en la raíz de su proyecto para iniciar la instalación:

```bash
gh skill install IgniteUI/igniteui-angular
```

Se le pedirá que seleccione qué skills instalar y los agentes de destino para los archivos de skills de su proyecto. A continuación, la CLI descargará y colocará los skills seleccionados según los agentes elegidos.

Para actualizar los skills más adelante, ejecute el siguiente comando:

```bash
gh skill update IgniteUI/igniteui-angular
```

### **Opción C: use la CLI de `gemini skills`**

El comando `gemini skills install` instala skills directamente desde un repositorio Git. Admite dos ámbitos:

- **Ámbito de usuario** (predeterminado): instala los skills globalmente para su cuenta de usuario, de modo que estén disponibles en todos los proyectos. Los skills se colocan en `~/.gemini/skills/` o en `~/.agents/skills/`.
- **Ámbito de espacio de trabajo**: instala los skills localmente en el directorio del proyecto actual, en `.agents/skills/`, limitándolos solo a ese proyecto.

**Instalar en el ámbito de usuario (predeterminado):**

```bash
gemini skills install https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-components
gemini skills install https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-grids
gemini skills install https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-theming
gemini skills install https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-generate-from-image-design
```

**Instalar en el ámbito de espacio de trabajo:**

```bash
gemini skills install --scope workspace https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-components
gemini skills install --scope workspace https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-grids
gemini skills install --scope workspace https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-theming
gemini skills install --scope workspace https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-generate-from-image-design
```

Una vez instalados, los archivos de skills están disponibles en la ubicación correspondiente y los detectan automáticamente los asistentes de IA compatibles.

### **Opción D: use la CLI de `npx skills`**

La CLI de `skills` es una herramienta interactiva que descarga e instala los skills directamente en su proyecto. Ejecute el siguiente comando en la raíz de su proyecto:

```bash
npx skills add IgniteUI/igniteui-angular
```

La CLI le guiará mediante una serie de preguntas para:

1. Seleccionar qué skills instalar (componentes, temas, etc.).
2. Elegir la ubicación de destino de los archivos de skills en su proyecto (por ejemplo, `.agents/skills/`, `.github/skills/`).
3. Descargar y escribir automáticamente los archivos de skills seleccionados.

Una vez finalizado, los skills están listos para usarse, sin necesidad de copiar archivos manualmente.

> **Nota:** Requiere Node.js y conexión a Internet. El comando descarga los archivos de skills más recientes del repositorio [IgniteUI/igniteui-angular](https://github.com/IgniteUI/igniteui-angular).

## Servidor MCP de Theming

El **skill de Theming** incluye instrucciones de configuración del servidor MCP `igniteui-theming`, que da a los asistentes de IA acceso a herramientas de temas en tiempo real, como la generación de paletas y la creación de la estructura de temas de componentes. Consulte el [archivo del skill de Theming](https://github.com/IgniteUI/igniteui-angular/blob/master/skills/igniteui-angular-theming/SKILL.md) para ver los pasos de configuración de VS Code, Cursor, Claude Desktop y los IDE de JetBrains.

Para más información sobre Theming MCP, consulte la documentación de [Ignite UI Theming MCP](/ai/theming-mcp).
