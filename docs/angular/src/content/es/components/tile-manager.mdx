# Descripción general de Angular Tile Manager

El componente Tile Manager permite mostrar contenido en mosaicos individuales. Permite a los usuarios interactuar con estos mosaicos reorganizándolos y cambiando su tamaño, lo que les da libertad para personalizar la disposición y el aspecto del contenido según sus preferencias. Esta flexibilidad mejora la experiencia de usuario al permitir una forma más personalizada y eficiente de ver y gestionar el contenido.

## Primeros pasos con Ignite UI for Angular Tile Manager

Ignite UI Tile Manager es un [componente web](https://developer.mozilla.org/en-US/docs/Web/Web_Components) estándar y, como tal, puede usarse en una aplicación Angular.

Para empezar a usarlo, primero debe instalar el paquete Ignite UI for Web Components ejecutando el siguiente comando:

```cmd
npm install igniteui-webcomponents --save
```

A continuación, debe llamar a la función `defineCustomElements()` con el argumento `IgcTileManagerComponent`, ya sea en su archivo `main.ts` o en el archivo `.ts` del componente que usa `IgcTileManager`.

```ts
import { defineComponents, IgcTileManagerComponent } from 'igniteui-webcomponents';

defineComponents(IgcTileManagerComponent);
```

También debe incluir el esquema `CUSTOM_ELEMENTS_SCHEMA` en la configuración de su componente

```typescript
import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';

@Component({
    schemas: [CUSTOM_ELEMENTS_SCHEMA]
})
export class AppComponent {
```

Ahora puede empezar con una configuración básica de Angular Tile Manager.

## Uso

El Tile Manager proporciona un comportamiento básico de disposición de mosaicos, gestionando la colocación de los mosaicos en estado maximizado o normal. Los mosaicos pueden dimensionarse de forma independiente y usarse para formar disposiciones complejas. Los usuarios finales pueden reordenar los mosaicos arrastrándolos y soltándolos, lo que ofrece una experiencia flexible e intuitiva.

El Tile Manager ofrece dos componentes que podemos usar:

- `IgcTileComponent`: representa un mosaico individual mostrado dentro del Tile Manager.
- `IgcTileManagerComponent`: es el componente principal que contiene todos los componentes de mosaico, y actúa como contenedor de toda la disposición de mosaicos.

```html
<igc-tile-manager>
  <igc-tile>
    <p>Tile 1</p>
  </igc-tile>
  <igc-tile>
    <p>Tile 2</p>
  </igc-tile>
  <igc-tile>
    <p>Tile 3</p>
  </igc-tile>
</igc-tile-manager>
```
