# Descripción general del componente Angular Select

Angular Select es un componente de formulario que sirve para seleccionar un único valor de una lista de valores predefinidos. El componente Angular Select ofrece una funcionalidad idéntica al elemento select nativo de HTML, pero con muchas más opciones de personalización. Se basa en <ApiLink type="DropDown" /> y admite todas sus funciones, incluidas la creación de plantillas, la virtualización y la personalización de los elementos de la lista desplegable.

## Primeros pasos con Ignite UI for Angular Select

Para empezar con el componente Ignite UI for Angular Select, primero debe instalar Ignite UI for Angular. En una aplicación Angular existente, escriba el siguiente comando:

```cmd
ng add igniteui-angular
```

Para una introducción completa a Ignite UI for Angular, lea el tema [_primeros pasos_](/general/getting-started).

El siguiente paso es importar `IgxSelectModule` en el archivo **app.module.ts**.

```typescript
// app.module.ts
...
import { IgxSelectModule } from 'igniteui-angular/select';
// import { IgxSelectModule } from '@infragistics/igniteui-angular'; for licensed package
@NgModule({
    ...
    imports: [..., IgxSelectModule],
    ...
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` puede importar `IgxSelectComponent` como dependencia independiente, o usar el token [`IGX_SELECT_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/select/src/select/public_api.ts) para importar el componente y todos sus componentes y directivas de apoyo.

```typescript
// home.component.ts

import { FormsModule } from '@angular/forms';
import { IGX_SELECT_DIRECTIVES } from 'igniteui-angular/select';
// import { IGX_SELECT_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-select [(ngModel)]="selected">
        <label igxLabel>Simple Select</label>
        <igx-select-item value="Orange">Orange</igx-select-item>
        <igx-select-item value="Apple">Apple</igx-select-item>
        <igx-select-item value="Banana">Banana</igx-select-item>
        <igx-select-item value="Mango">Mango</igx-select-item>
    </igx-select>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_SELECT_DIRECTIVES, FormsModule]
    /* or imports: [IgxSelectComponent, IgxSelectItemComponent, IgxLabelDirective, FormsModule] */
})
export class HomeComponent {
    public selected: string;
}
```

Ahora que ha importado el módulo o las directivas de Ignite UI for Angular Select, puede empezar a usar el componente `igx-select`.

## Uso de Angular Select

Añada `igx-select` junto con una lista de elementos entre los que elegir. Usamos <ApiLink type="SelectItem" label="igx-select-item" /> para mostrar los elementos que contiene `igx-select`.

```html
<igx-select>
    <label igxLabel>Simple Select</label>
    <igx-select-item value="Orange">Orange</igx-select-item>
    <igx-select-item value="Apple">Apple</igx-select-item>
    <igx-select-item value="Banana">Banana</igx-select-item>
    <igx-select-item value="Mango">Mango</igx-select-item>
</igx-select>
```

<DocsAside type="info">
Este componente usa Material Icons. Añada el siguiente enlace a su `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

Otra forma de hacerlo sería usar una colección de elementos que queremos mostrar mediante la directiva estructural [*ngFor](https://angular.io/api/common/NgForOf):

```typescript
public items: string[] = ['Orange', 'Apple', 'Banana', 'Mango'];
```

```html
<igx-select [(ngModel)]="selected">
    <label igxLabel>Simple Select</label>
    <igx-select-item *ngFor="let item of items" [value]="item">
        {{item}}
    </igx-select-item>
</igx-select>
```

De forma predeterminada, el componente Select usará el `innerText` del elemento de la opción en el campo de entrada. En casos con plantillas de elemento más complejas, puede establecer explícitamente la propiedad `text` para especificar qué mostrar en el campo de entrada cuando se selecciona este elemento. Por ejemplo:

```html
<igx-select>
    <igx-select-item *ngFor="let item of items" [value]="item.value" [text]="item.text">
        {{item.text}} ( {{item.count}} )
    </igx-select-item>
</igx-select>
```

Para ver la propiedad `text` en acción con plantillas de elemento algo más sofisticadas, consulte el ejemplo de agrupación en la sección **Select con grupos**.

### Propiedades de entrada

El componente Select admite las siguientes directivas aplicables a [Input Group](/input-group):

- `igxLabel`: no es necesario establecer la propiedad `for`, ya que la vinculación con la entrada de Angular Select se gestiona automáticamente mediante `aria-labelledby`.
- `igx-prefix`/`igxPrefix`
- `igx-suffix`/`igxSuffix`: tenga en cuenta que el sufijo integrado del botón de alternancia se mostrará siempre al final.
- `igx-hint`/`igxHint`

```html
<igx-select [(ngModel)]="selected">
    <label igxLabel>Pick a fruit</label>
    <igx-prefix>
        <span class="bio-prefix">BIO</span>
    </igx-prefix>
    @if (selected) {
        <igx-suffix>
            <igx-icon (click)="clearSelection($event)">clear</igx-icon>
        </igx-suffix>
    }
    <igx-hint>Choose a banana</igx-hint>
    <igx-select-item *ngFor="let item of items" [value]="item">
        {{item}}
    </igx-select-item>
</igx-select>
```

### Agrupar elementos de selección

Para separar visualmente los grupos de elementos, el componente select admite la agrupación de elementos envolviéndolos en un `<igx-select-item-group>`.
Esto funciona mejor con datos jerárquicos que puedan recorrerse para declarar los componentes. En el siguiente ejemplo, cada grupo tiene un `label` y una colección de `items`:

```typescript
public greengrocery: Array<{ label: string, items: Array<{ type: string, origin: string }> }> = [
    { label: 'Fruits', items: [
            { type: 'Apple', origin: 'local' },
            { type: 'Orange', origin: 'import' },
            { type: 'Banana', origin: 'import'}
        ]
    },
    { label: 'Vegetables', items: [
            { type: 'Cucumber', origin: 'local' },
            { type: 'Potato', origin: 'import' },
            { type: 'Pepper', origin: 'local' }
        ]
    }
];
```

Después, en el archivo de plantilla puede recorrer los objetos y acceder a sus elementos en consecuencia:

```html
<igx-select #select>
    <label igxLabel>Select With Groups</label>
    <igx-select-item-group *ngFor="let group of greengrocery" [label]="group.label">
        <igx-select-item *ngFor="let item of group.items" [value]="item.type" [text]="item.type">
            {{item.type}}
            @if (item.origin === 'local') {
                <igx-icon title="Local product">local_shipping</igx-icon>
            } @else {
                <igx-icon title="Import product">flight</igx-icon>
            }
        </igx-select-item>
    </igx-select-item-group>
</igx-select>
```

### Encabezado y pie

Actualmente, el componente Select no tiene plantillas predeterminadas de encabezado ni de pie. Sin embargo, puede añadir una plantilla de encabezado o de pie marcándolas respectivamente con `igxSelectHeader` o `igxSelectFooter`. Como son plantillas personalizadas, también debe definir su estilo.
En este ejemplo se definen plantillas ng-template de encabezado y de pie. En el encabezado hay un filtrado básico, implementado mediante <ApiLink type="ButtonGroup" label="igx-buttongroup" />. El pie incluye un resumen estático de todos los elementos, en función del método de entrega.

```html
<igx-select>
    <label igxLabel>Pick your fruit</label>
    <igx-select-item *ngFor="let fruit of fruits" [value]="fruit.type" [text]="fruit.type" [ngSwitch]="fruit.delivery">
        {{fruit.type}}
        <igx-icon *ngSwitchCase="'flight'">flight</igx-icon>
        <igx-icon *ngSwitchCase="'train'">train</igx-icon>
        <igx-icon *ngSwitchCase="'boat'">directions_boat</igx-icon>
    </igx-select-item>
    <ng-template igxSelectHeader>
        <div class="custom-select-header">

            <span class="sample-template-heading">DELIVERY METHOD</span>
            <igx-buttongroup (click)="filter($event.target.title)">
                    <button igxButton title="flight"><igx-icon title="flight">flight</igx-icon></button>
                    <button igxButton title="train"><igx-icon title="train">train</igx-icon></button>
                    <button igxButton title="boat"><igx-icon title="boat">directions_boat</igx-icon></button>
            </igx-buttongroup>
        
</div>
    </ng-template>
    <ng-template igxSelectFooter>
        <div class="custom-select-footer">

            <span class="sample-template-heading">TOTAL</span>
            <div class="sample-template-icons">

                <span class="sample-template-icons__item">
                    <igx-icon
                        title="flight"
                        [class.important-icon]="selected === 'flight'"
                    >flight</igx-icon>
                    {{flightCount}}
                </span>
                <span class="sample-template-icons__item">
                    <igx-icon
                        title="train"
                        [class.important-icon]="selected === 'train'"
                    >train</igx-icon>
                    {{trainCount}}
                </span>
                <span class="sample-template-icons__item">
                    <igx-icon
                        title="boat"
                        [class.important-icon]="selected === 'boat'"
                    >directions_boat
                    </igx-icon>
                    {{boatCount}}
                </span>
            
</div>
        
</div>
    </ng-template>
</igx-select>
```

### Botón de alternancia personalizado en Angular Select

Puede personalizar el botón de alternancia predeterminado usando la directiva `igxSelectToggleIcon` o estableciendo una `TemplateRef` en la propiedad <ApiLink type="Select" member="toggleIconTemplate" label="toggleIconTemplate" />.

```html
<igx-select #select>
    ...
    <ng-template igxSelectToggleIcon let-collapsed>
        <igx-icon>{{ collapsed ? 'add_circle' : 'add_circle_outline'}}</igx-icon>
    </ng-template>
    ...
</igx-select>
```

## Navegación por teclado

- Abra la `igx-select` haciendo clic en las teclas `Space`, `Enter` o `ALT + Up/Down Arrow`, mientras el select tiene el foco.
- Cierre la `igx-select` usando la combinación `ALT + Up/Down Arrow` o cualquiera de las teclas `Enter`, `Space`, `Esc` o `Tab`.
- Las teclas `Up/Down Arrow` permiten desplazarse por los elementos.
- Las teclas `Home` o `End` le llevan al primer y al último elemento de la lista.
- Puede desplazarse por los elementos de la lista, empezando por un carácter determinado, pulsando la tecla correspondiente.
- Puede ir a un elemento concreto escribiendo rápidamente los primeros caracteres del elemento al que quiere ir.
- Seleccione un elemento usando las teclas `Enter` o `Space`

<DocsAside type="info">
`igx-select` admite solo la selección _única_ de elementos.
</DocsAside>

## Ajustes personalizados de superposición

Puede crear <ApiLink type="OverlaySettings" kind="interface" /> personalizados. Para ello, primero defina su plantilla así:

```html
<igx-select [overlaySettings]="customOverlaySettings">
    <igx-select-item *ngFor="let item of items">
        {{item}}
    </igx-select-item>
</igx-select>
```

- Donde la propiedad `overlaySettings` se enlaza a sus ajustes personalizados.

Dentro de su clase tendría algo parecido a:

```typescript
export class MyClass implements OnInit {
    @ViewChild(IgxSelectComponent)
    public select: IgxSelectComponent;
    public items: string[] = ['Orange', 'Apple', 'Banana', 'Mango', 'Tomato'];
    public customOverlaySettings: OverlaySettings;

    public ngOnInit(): void {
        const positionSettings: PositionSettings = {
            closeAnimation: scaleOutBottom,
            horizontalDirection: HorizontalAlignment.Right,
            horizontalStartPoint: HorizontalAlignment.Left,
            openAnimation: scaleInTop,
            verticalDirection: VerticalAlignment.Bottom,
            verticalStartPoint: VerticalAlignment.Bottom
        };
        this.customOverlaySettings = {
            target: this.select.inputGroup.element.nativeElement,
            positionStrategy: new ConnectedPositioningStrategy(
                positionSettings
            ),
            scrollStrategy: new AbsoluteScrollStrategy()
        };
    }
}
```

Como puede ver, creamos un objeto <ApiLink kind="interface" type="PositionSettings" /> que se pasa directamente a nuestro <ApiLink type="ConnectedPositioningStrategy" />. No es obligatorio hacerlo, pero como queremos definir un posicionamiento personalizado, los usamos para sobrescribir los ajustes predeterminados de la estrategia.

- Puede establecer todos los ajustes dentro del hook [_ngOnInit_](https://angular.io/api/core/OnInit) y esto afectará automáticamente a su plantilla al generarse el componente.

<Sample src="/data-entries/select-sample-4" height={260} alt="" />

También puede pasar un objeto <ApiLink type="OverlaySettings" kind="interface" /> personalizado a la función open de <ApiLink type="Select" member="open" label="IgxSelectComponent" />; en ese caso, su plantilla debería tener este aspecto:

```html
<igx-select>
    <igx-select-item *ngFor="let item of items">
        {{item}}
    </igx-select-item>
</igx-select>

<button (click)="onClick($event)"></button>
```

Y su clase tiene lo siguiente:

```typescript
export class MyClass implements OnInit {
    /* -- */
    private otherCustomOverlaySettings: OverlaySettings = {
        positionStrategy: new GlobalPositionStrategy(),
        scrollStrategy: new AbsoluteScrollStrategy()
    }
    onClick(event: MouseEvent): void {
        this.select.open(this.otherCustomOverlaySettings)
    }
    /* -- */
}
```

<DocsAside type="info">
Si pasa sus ajustes personalizados tanto como argumento de la función `open` como en la plantilla, `igx-select` usará el que se proporciona en la función `open`. Sin embargo, si enlaza los ajustes a un evento interno, como `opening` o `opened`, entonces `igx-select` usará los ajustes que se proporcionan en la plantilla.
</DocsAside>

## Estilos

### Mapa de propiedades del tema de Select

Al modificar una propiedad principal, todas las propiedades dependientes relacionadas se actualizan automáticamente para reflejar el cambio:

| Propiedad principal | Propiedad dependiente | Descripción |
| --- | --- | --- |
| **$toggle-button-background** | $toggle-button-foreground | Color del primer plano del botón de alternancia |
|  | $toggle-button-foreground-filled | Color del primer plano cuando el botón de alternancia está rellenado |
|  | $toggle-button-background-focus | Color de fondo cuando tiene el foco |
|  | $toggle-button-background-focus--border (bootstrap/indigo) | Fondo cuando tiene el foco en la variante con borde (Bootstrap/Indigo) |
|  | $toggle-button-foreground-focus | Color del primer plano cuando el botón de alternancia tiene el foco |

Cada componente tiene su propia función de tema.

Para dar estilo al componente Select, hay que dar estilo a los componentes que lo contienen. En nuestro caso, son <ApiLink kind="sass" module="themes" type="function-input-group-theme" label="input-group-theme" /> y <ApiLink kind="sass" module="themes" type="function-drop-down-theme" label="drop-down-theme" />.
Consulte las secciones de estilos [`Input Group`](/input-group#estilos) y [`Drop Down`](/drop-down#estilos) para entender mejor cómo dar estilo a esos dos componentes.

También tenemos una función <ApiLink kind="sass" module="themes" type="function-select-theme" label="select-theme" code={true} /> que solo se usa para dar estilo al botón de nuestro componente Select. <br/>
Para empezar a dar estilo al botón del componente Select, tenemos que importar el archivo `index`, donde se exportan todas las funciones de tema y el mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Siguiendo el enfoque más sencillo, creamos un tema nuevo que extiende <ApiLink kind="sass" module="themes" type="function-select-theme" label="select-theme" code={true} /> y solo proporciona el parámetro `$toggle-button-background`. La función de tema calculará automáticamente todos los colores de fondo y de primer plano correspondientes para los distintos estados a partir de este único valor.

```scss
$custom-select-theme: select-theme(
  $toggle-button-background: #57a5cd,
);
```

El último paso es pasar el tema personalizado de radio en nuestra aplicación:

```scss
:host {
    @include tokens($custom-select-theme);
}
```

### Dar estilo con Tailwind

Puede dar estilo al select usando nuestras clases de utilidad personalizadas de Tailwind. Asegúrese de [configurar Tailwind](/themes/tailwind) primero.

Junto con la importación de tailwind en su hoja de estilos global, puede aplicar las utilidades de tema deseadas de la siguiente manera:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

El archivo de utilidades incluye las variantes de tema `light` y `dark`.

- Use las clases `light-*` para el tema claro.
- Use las clases `dark-*` para el tema oscuro.
- Añada el nombre del componente después del prefijo, por ejemplo, `light-select`, `dark-select`.

Una vez aplicadas, estas clases habilitan los cálculos dinámicos del tema. A partir de ahí, puede sobrescribir las variables CSS generadas usando `arbitrary properties`. Después de los dos puntos, indique cualquier formato de color CSS válido (HEX, variable CSS, RGB, etc.).

Puede encontrar la lista completa de propiedades en <ApiLink kind="sass" module="themes" type="function-select-theme" label="select-theme" />. La sintaxis es la siguiente:

```html
<igx-select
  class="!light-select ![--toggle-button-background:#99BAA6]">
  ...
</igx-select>
```

<DocsAside type="info">
El signo de exclamación (`!`) es obligatorio para asegurar que la clase de utilidad tenga prioridad. Tailwind aplica los estilos por capas y, si no se marcan estos estilos como importantes, los sobrescribirá el tema predeterminado del componente.
</DocsAside>
