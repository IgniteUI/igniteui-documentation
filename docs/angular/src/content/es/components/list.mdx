# Descripción general del componente Angular List View

El componente List de Ignite UI for Angular muestra filas de elementos y admite uno o varios elementos de encabezado, así como la búsqueda y el filtrado de los elementos de la lista. Cada elemento de la lista es totalmente personalizable con plantillas y admite cualquier HTML válido o [componente de Angular](https://www.infragistics.com/products/ignite-ui-angular). El componente de lista también incluye funcionalidad de desplazamiento integrada, plantillas para los estados vacío y de carga, y admite la virtualización de listas grandes mediante la directiva [`IgxForOf`](/for-of).

## Ejemplo de lista de Angular

El siguiente ejemplo muestra una lista rellenada con contactos que tienen las propiedades _nombre_ y _número de teléfono_. El componente <ApiLink type="List" /> usa [`igx-avatar`](layouts/avatar.mdx) y [`igx-icon`](/layouts/icon) para enriquecer la experiencia del usuario y mostrar las funciones de establecer una imagen de avatar y un icono distinto para _marcar un contacto como favorito_. Además, la vista de lista expone capacidades de ordenación mediante nuestro pipe de filtrado.

## Primeros pasos con Ignite UI for Angular List

Para empezar con el componente Ignite UI for Angular List View, primero debe instalar Ignite UI for Angular. En una aplicación Angular existente, escriba el siguiente comando:

```cmd
ng add igniteui-angular
```

Para una introducción completa a Ignite UI for Angular, lea el tema [_primeros pasos_](/general/getting-started).

El siguiente paso es importar `IgxListModule` en el archivo **app.module.ts**.

```typescript
// app.module.ts

import { IgxListModule } from 'igniteui-angular/list';
// import { IgxListModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxListModule],
    ...
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` puede importar `IgxListComponent` como dependencia independiente, o usar el token [`IGX_LIST_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/list/src/list/public_api.ts) para importar el componente y todos sus componentes y directivas de apoyo.

```typescript
// home.component.ts

import { IGX_LIST_DIRECTIVES } from 'igniteui-angular/list';
// import { IGX_LIST_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-list>
        <igx-list-item isHeader="true">Header</igx-list-item>
        <igx-list-item>Item 1</igx-list-item>
        <igx-list-item>Item 2</igx-list-item>
        <igx-list-item>Item 3</igx-list-item>
    </igx-list>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_LIST_DIRECTIVES]
    /* or imports: [IgxListComponent, IgxListItemComponent] */
})
export class HomeComponent {}
```


Ahora que ha importado el módulo o las directivas de Ignite UI for Angular List, puede empezar a usar el componente `igx-list`.

## Uso de Angular List

Después, en la plantilla de nuestro componente de contactos, podemos crear la lista, pero ¿qué pasa si ahora (o en algún momento futuro) no tenemos elementos en ella?
En ese caso, la lista de Angular nos proporciona una plantilla predeterminada que se usa cuando la lista está vacía.
Siempre podemos proporcionar nuestra propia plantilla para el aspecto de la lista vacía usando simplemente la directiva <ApiLink type="EmptyListTemplateDirective" />. En este caso, no se usará la plantilla predeterminada:

```html
{/*contacts.component.html*/}

<igx-list>
    <ng-template igxEmptyList>
        <div class="empty">
No contacts! :(
</div>
    </ng-template>
</igx-list>
```

Y nuestro estilo para la plantilla vacía:

```css
/* contacts.component.css */

.empty {
    color: rgba(0, 153, 255, 1);
    font-size: 25px;
    font-weight: 600;
    text-shadow: 2px 1px 2px rgba(150, 150, 150, 1);
}
```

Si todo ha ido bien, así debería verse nuestra lista vacía:

<DocsAside type="info">
Este componente usa Material Icons. Añada el siguiente enlace a su `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

- `igxListThumbnail` se usa si necesitamos añadir algún tipo de contenido multimedia al principio de nuestros elementos de la lista. La directiva envolverá el elemento de destino, en nuestro caso igx-avatar, en un contenedor que proporcionará una posición y un espaciado predeterminados.
- `igxListAction` se usa en los elementos de la lista que tienen algún tipo de acción o metadatos, por ejemplo, un switch, un botón de radio, una casilla, etc. En nuestro caso, la acción estará representada por un `igx-icon`. De nuevo, la directiva envolverá el elemento de destino en un contenedor que tendrá la posición y el espaciado correctos.
- `igxListLine` se usa si necesitamos algo de texto entre `igxListThumbnail` y `igxListAction`; la directiva se asegurará de que la posición, el espaciado y la alineación del texto queden bien junto con las otras dos directivas que lo rodean.

A continuación, escuchamos un evento de clic en el componente [**IgxIcon**](/layouts/icon) para alternar la propiedad _isFavorite_ de nuestro objeto de contacto.

```typescript
toggleFavorite(item: IgxListItem) {
    const contact = this.contacts[item.index - 1];
    contact.isFavorite = !contact.isFavorite;
}
```

### Desplazamiento de los elementos de la lista

Ahora que tenemos una lista de Angular tan atractiva con contactos y sus números de teléfono, ¿por qué no implementar la posibilidad de llamar a un contacto?
<ApiLink type="List" /> tiene la solución perfecta para esto: el desplazamiento de elementos de la lista.
Para hacerlo, tiene que seguir estos pasos:

- Habilite el desplazamiento usando las propiedades <ApiLink type="List" member="allowLeftPanning" label="allowLeftPanning" /> y/o <ApiLink type="List" member="allowRightPanning" label="allowRightPanning" />
- Defina las plantillas para el desplazamiento hacia la izquierda y/o hacia la derecha
- Gestione los eventos de desplazamiento del elemento de la lista y realice la acción deseada

El siguiente ejemplo muestra cómo gestionar el desplazamiento hacia la izquierda y hacia la derecha. El controlador del evento para el desplazamiento hacia la derecha muestra un mensaje emergente. El controlador del evento para el desplazamiento hacia la izquierda elimina un elemento de la <ApiLink type="List" />.

<DocsAside type="info">
Tenga en cuenta que eliminar un elemento de la lista es una tarea de la aplicación. El propio <ApiLink type="List" /> no puede eliminar elementos del origen de datos, porque <ApiLink type="List" /> no tiene referencia al origen de datos.
</DocsAside>

Este es el código HTML del ejemplo:

```html
{/* contacts.component.html */}

<igx-list [allowLeftPanning]="true" [allowRightPanning]="true"
  (leftPan)="leftPanPerformed($event)" (rightPan)="rightPanPerformed($event)">
  <ng-template igxListItemLeftPanning>
    <div class="listItemLeftPanningStyle">

      <igx-icon [color]="white" style="margin-left:10px">delete</igx-icon>Delete
    
</div>
  </ng-template>
  <ng-template igxListItemRightPanning>
    <div class="listItemRightPanningStyle">

      <igx-icon [color]="white" style="margin-right:10px">call</igx-icon>Dial
    
</div>
  </ng-template>
  <igx-list-item isHeader="true">Contacts</igx-list-item>
  <igx-list-item #item *ngFor="let contact of contacts">
    <igx-avatar igxListThumbnail [src]="contact.photo" shape="circle"></igx-avatar>
    <h4 igxListLineTitle>{{ contact.name }}</h4>
    <p igxListLineSubTitle class="phone">{{ contact.phone }}</p>
    <igx-icon igxListAction [color]="contact.isFavorite ? 'orange' : 'lightgray'" (click)="toggleFavorite(item)">star</igx-icon>
  </igx-list-item>
</igx-list>

<igx-toast #toast></igx-toast>
```

Y, por último, este es el código TypeScript que gestiona los eventos de desplazamiento:

```typescript
// contacts.component.ts

...
@ViewChild('toast')
public toast: IgxToastComponent;

public rightPanPerformed(args) {
  args.keepItem = true;
  this.toast.message = 'Dialing ' + this.contacts[args.item.index - 1].name;
  this.toast.open();
}

public leftPanPerformed(args) {
  args.keepItem = false;
  setTimeout((idx = args.item.index - 1) => {
    this.toast.message = 'Contact ' + this.contacts[idx].name + ' removed.';
    this.toast.open();
    this.contacts.splice(idx, 1);
  }, 500);
}

...
```

<DocsAside type="info">
Al desplazar los elementos de la lista hay un umbral que debe alcanzarse para que se emitan los eventos de desplazamiento. Puede cambiar el umbral usando la propiedad <ApiLink type="List" member="panEndTriggeringThreshold" label="panEndTriggeringThreshold" /> de <ApiLink type="List" />. De forma predeterminada, esta propiedad tiene un valor de 0,5, lo que significa el 50 % del ancho del elemento de la lista.
</DocsAside>

## Lista filtrable de Angular

Nuestra lista tiene buen aspecto, pero ¿no sería aún mejor poder buscar contactos por nombre? Podemos conseguirlo fácilmente usando nuestro pipe de filtrado.
Hagámoslo.

Primero vamos a añadir un campo de entrada en la parte superior de la plantilla de nuestro componente de Angular y a enlazarlo a una propiedad de nuestro componente llamada _searchContact_:

```html
{/*contacts.component.html*/}

<igx-input-group type="search" class="search">
    <igx-prefix>
        <igx-icon>search</igx-icon>
    </igx-prefix>
    <input #search igxInput placeholder="Search Contacts" [(ngModel)]="searchContact"/>
    @if (search.value.length > 0) {
        <igx-suffix (click)="searchContact = null">
            <igx-icon>clear</igx-icon>
        </igx-suffix>
    }
</igx-input-group>
```

Es momento de importar `IgxFilterModule` y `IgxInputGroupModule` en nuestro archivo app.module.ts y <ApiLink type="FilterOptions" /> en nuestro componente de contactos:

```typescript
// app.module.ts
...
import { IgxFilterModule } from 'igniteui-angular/directives';
import { IgxInputGroupModule } from 'igniteui-angular/input-group';
// import { IgxFilterModule, IgxInputGroupModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    imports: [..., IgxFilterModule, IgxInputGroupModule]
})

// contacts.component.ts
...
import { IgxFilterOptions } from 'igniteui-angular/directives';
// import { IgxFilterOptions } from '@infragistics/igniteui-angular'; for licensed package

@Component({...})
export class ContactListComponent {
    public searchContact: string;
    ...
    get filterContacts(): IgxFilterOptions {
        const fo = new IgxFilterOptions();
        fo.key = 'name';
        fo.inputValue = this.searchContact;
        return fo;
    }
}
```

Después de importar <ApiLink type="FilterOptions" />, tenemos que registrar un nuevo getter que devuelva las opciones de filtrado que usará el pipe cada vez que se actualice la propiedad `searchContact`. Para que el filtro funcione, tenemos que registrar un `key` por el que filtrar el objeto de contacto. En nuestro caso, sería el `name` de cada contacto. La segunda propiedad que hay que registrar en el objeto <ApiLink type="FilterOptions" /> es el valor con el que debemos comparar el nombre del contacto. Este es la propiedad `searchContact` que enlazamos al campo de entrada situado encima de nuestra lista de contactos.

Por último, tenemos que aplicar el pipe de filtrado a nuestros datos de contactos antes de usarlos. Así que, en nuestra plantilla, simplemente añadimos:

```html
{/*contacts.component.html*/}

<igx-list-item *ngFor="let contact of contacts | igxFilter: filterContacts; let i = index">
    ...
</igx-list-item>
```

## Selección de elementos de la lista

Los elementos de la lista tienen una propiedad `selected` que nos ayuda a hacer el seguimiento de los elementos "seleccionados". Esta propiedad permite identificar y gestionar el estado de selección de cada elemento.

Este es un ejemplo que ilustra cómo cambia el estilo visual de los elementos al usar la propiedad `selected`:

<Sample src="/lists/list-item-selection" height={420} alt="" />

De forma predeterminada, la propiedad `selected` está establecida en `false`. Podemos alternar su valor usando una expresión en línea enlazada al evento `(click)` de cada elemento de la lista, cambiando efectivamente el estado visual del elemento cada vez que se hace clic en él.

```html
<igx-list>
    <igx-list-item [isHeader]="true">Contacts</igx-list-item>
    @for (contact of contacts | igxFilter: filterContacts; track contact) {
      <igx-list-item [selected]="contact.selected" (click)="contact.selected = !contact.selected">
        <igx-avatar igxListThumbnail [src]="contact.photo" shape="circle"></igx-avatar>
        <span igxListLineTitle>{{ contact.name }}</span>
        <span igxListLineSubTitle>{{ contact.phone }}</span>
        <igx-icon igxListAction [style.color]="contact.isFavorite ? 'orange' : 'lightgray'" igxRipple="pink"
          [igxRippleCentered]="true" (click)="toggleFavorite(contact, $event)"
        (mousedown)="mousedown($event)">star</igx-icon>
      </igx-list-item>
    }
  </igx-list>
```

El elemento de la lista también expone algunas variables CSS que puede usar para dar estilo a distintas partes de los elementos seleccionados:

- `--item-background-selected`
- `--item-text-color-selected`
- `--item-title-color-selected`
- `--item-action-color-selected`
- `--item-subtitle-color-selected`
- `--item-thumbnail-color-selected`

```scss
igx-list-item {
  --item-background-selected: var(--ig-secondary-500);
  --item-title-color-selected: var(--ig-secondary-500-contrast);
  --item-subtitle-color-selected: var(--ig-info-100);
}
```

Si prefiere usar la función de temas de la lista, hay parámetros disponibles que le permiten dar estilo al estado seleccionado de los elementos de la lista. Puede encontrar más información sobre estos parámetros aquí: <ApiLink kind="sass" module="themes" type="function-list-theme" label="list-theme" code={true} />

### Mapa de propiedades del tema de List

Al modificar una propiedad principal, todas las propiedades dependientes relacionadas se actualizan automáticamente para reflejar el cambio:

| Propiedad principal | Propiedad dependiente | Descripción |

```scss
@use "igniteui-angular/theming" as *;

// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Siguiendo el enfoque más sencillo, creamos un tema nuevo que extiende <ApiLink kind="sass" module="themes" type="function-list-theme" label="list-theme" code={true} /> y, al pasar solo el parámetro `$background`, el tema calculará automáticamente los colores de estado y los primeros planos con contraste adecuado. $my-list-theme: list-theme(

### Dar estilo con Tailwind

Puede dar estilo a la lista usando nuestras clases de utilidad personalizadas de Tailwind. Asegúrese de [configurar Tailwind](/themes/tailwind) primero.

Junto con la importación de tailwind en su hoja de estilos global, puede aplicar las utilidades de tema deseadas de la siguiente manera:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

El archivo de utilidades incluye las variantes de tema `light` y `dark`.

- Use las clases `light-*` para el tema claro.
- Use las clases `dark-*` para el tema oscuro.
- Añada el nombre del componente después del prefijo, por ejemplo, `light-list`, `dark-list`.

Una vez aplicadas, estas clases habilitan los cálculos dinámicos del tema. A partir de ahí, puede sobrescribir las variables CSS generadas usando `arbitrary properties`. Después de los dos puntos, indique cualquier formato de color CSS válido (HEX, variable CSS, RGB, etc.).

Puede encontrar la lista completa de propiedades en <ApiLink kind="sass" module="themes" type="function-list-theme" label="list-theme" />. La sintaxis es la siguiente:

```html
<igx-list class="!light-list ![--background:#81B698] ![--item-background:#A3C7B2]">
    ...
</igx-list>
```

<DocsAside type="info">
El signo de exclamación (`!`) es obligatorio para asegurar que la clase de utilidad tenga prioridad. Tailwind aplica los estilos por capas y, si no se marcan estos estilos como importantes, los sobrescribirá el tema predeterminado del componente.
</DocsAside>
