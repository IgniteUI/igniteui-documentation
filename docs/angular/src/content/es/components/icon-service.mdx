# Descripción general del servicio de iconos de Angular

<div class="highlight">
El servicio de iconos de Ignite UI for Angular permite a los desarrolladores añadir iconos nuevos de distintas fuentes a sus interfaces.
</div>

## Introducción

El servicio de iconos de Ignite UI for Angular proporciona varios métodos que permiten crear y gestionar familias de iconos.

El servicio de iconos puede importarse directamente desde el paquete de Ignite UI for Angular.

```ts
import { IgxIconComponent } from 'igniteui-angular/icon';
import { IgxIconService } from 'igniteui-angular/core';

@Component({
    selector: 'app-root',
    standalone: true,
    imports: [ IgxIconComponent ]
})
export class AppComponent implements OnInit {
    constructor(public iconService: IgxIconService) {}
}
```

### Añadir familias de iconos

De forma predeterminada, el servicio de iconos establece su familia predeterminada en `material`.

Añadir nuevas familias de iconos se hace con el método `setFamily` del servicio de iconos. Crea una entrada de familia con algunos metadatos que indican al componente `igx-icon` qué icono o iconos debe renderizar.

Veamos un ejemplo práctico para explicar cómo funciona el método `setFamily`:

```ts
/** 
* The icon service associates a given family name (provided by the user) 
* with a specific CSS class (as documented in the providing icon font) 
* and corresponding icon name (documented in the icon font).
* NOTE: Material is already the default family.
*/ 
iconService.setFamily('material', { className: 'material-icons', type: 'liga' });
iconService.setFamily('fa-solid', { className: 'fas', type: 'font', prefix: 'fa' });
```

El ejemplo anterior crea dos familias de iconos: 'material' y 'fa-solid'. Sus tipos son distintos: la familia `material` se registra como `liga`, mientras que la familia `fa-solid` se registra como `font`. La diferencia entre ambas está en cómo el componente `igx-icon` las renderiza. Normalmente, [Font Awesome](https://fontawesome.com/) usa nombres de clase para indicar puntos de código a una familia de **fuentes**, y por eso establecemos su tipo en `font`. Siempre que tengamos que depender de puntos de código para renderizar iconos, debemos establecer el tipo en `font`. La familia [Material Icons](https://material.io/icons) también es una familia de fuentes, pero la forma estándar de mostrar un icono es indicar un nombre de `ligature`, en lugar de un nombre de clase que apunte a un punto de código concreto. Por eso, tenemos que establecer el tipo en `liga`. Existe un tercer tipo de familia, `svg`, reservado para las familias de iconos formadas por SVG que se registran mediante el servicio de iconos.

Una vez registradas las dos familias de fuentes anteriores, ya podemos usar sus iconos de forma estandarizada mediante el componente `igx-icon`:

```html
<igx-icon family="material" name="home"></igx-icon>
<igx-icon family="fa-solid" name="car"></igx-icon>
```


<DocsAside type="info">
Para renderizar iconos de la familia `material` predeterminada con `igx-icon`, añada el siguiente enlace a su `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

Quizá haya notado que, para la familia `material`, usamos la ligadura `name` como nombre, mientras que para la familia `fa-solid` especificamos el `className` como nombre, que es `fa-car`, pero sin el prefijo `fa-`, ya que se especificó al registrar la familia de iconos en el paso anterior.

### Añadir iconos SVG

El servicio de iconos de Ignite UI for Angular nos permite asociar imágenes SVG a familias y asignarles nombres para que puedan incluirse mediante el componente `igx-icon` de la misma forma que los iconos basados en fuentes. Los SVG deben resolverse mediante cadenas o mediante un URI absoluto al recurso SVG.

```ts
// Add a new 'material' icon called 'my-icon' from an SVG file
iconService.addSvgIcon('my-icon', 'my-icon.svg', 'material');

// Add a new 'fa-solid' icon called 'my-icon' from string 
iconService.addSvgIconFromText('my-icon', '<svg>...</svg>', 'fa-solid');
```

Más adelante, en el marcado:

```html
<igx-icon family="material" name="my-icon"></igx-icon>
<igx-icon family="fa-solid" name="my-icon"></igx-icon>
```

Tenga en cuenta que estamos añadiendo iconos SVG personalizados a familias de tipo `liga` y `font`. Esto es posible porque los métodos `addSvgIcon` y `addSvgIconFromText` registran los iconos implícitamente como tipo `svg`, lo que permite que el componente `igx-icon` renderice correctamente el SVG.

## Metafamilias

El servicio de iconos de Ignite UI for Angular nos permite crear mapas de familias pseudo que combinan iconos añadidos mediante la definición de una familia de iconos de fuente o mediante la adición de SVG bajo un nombre común, para que sea más fácil referenciarlos.

```ts
// The `setIconRef` sets an icon reference in the icon map,
// assuming material and fa-solid have been added as families,
iconService.setIconRef('home', 'my-family', { family: 'material', name: 'home' });
iconService.setIconRef('home-alt', 'my-family', { family: 'fa-solid', name: 'home' });
iconService.setIconRef('car', 'my-family', { family: 'fa-solid', name: 'car' });
```

Más adelante, en el marcado:

```html
<igx-icon family="my-family" name="home"></igx-icon>
<igx-icon family="my-family" name="home-alt"></igx-icon>
<igx-icon family="my-family" name="car"></igx-icon>
```

## Recuperación de iconos

Es posible obtener un icono para una `family` y un icono `name` concretos, para leer el `type`, `name`, `family` y `className` originales del icono.

```ts
const { family, className, name, type } = iconService.getIcon('my-family', 'car');

console.log(family); // -> 'fa-solid'
console.log(className); // -> 'fas'
console.log(name); // -> 'fa-car'
console.log(type); // -> 'font'
```

Para aprovechar el cambio de los iconos internos por referencia, en lugar de crear plantillas personalizadas, puede hacer lo siguiente para sustituir los iconos de expandir/contraer en los componentes combo y select:

```ts
iconService.setIconRef('input_expand', 'default', {
    name: 'arrow_downward',
    family: 'material',
});

iconService.setIconRef('input_collapse', 'default', {
    name: 'arrow_upward',
    family: 'material',
});
```

Esto establecerá los iconos de expandir y contraer en las ligaduras `arrow_downward` y `arrow_upward`, respectivamente, de la familia de fuentes `material` para todos los componentes combo y select.

## API

Este es un breve resumen de todos los métodos disponibles mediante el servicio de iconos de Ignite UI for Angular.

### Añadir familia

```ts
setFamily(name: string, meta: IconFamilyMeta): IgxIconService;
```

### Referencias de iconos

Establecer SOLO si aún no está presente en el mapa de iconos:

```ts
addIconRef(name: string, family: string, icon: IconMeta): void;
```

Establecer una referencia de icono en el mapa de iconos (se sobrescribe si ya existe):

```ts
setIconRef(name: string, family: string, icon: IconMeta): void;
```

Obtener una referencia de icono

```ts
getIconRef(family: string, name: string): IconReference;
```

### Iconos SVG

Desde URI:

```ts
addSvgIcon(name: string, url: string, family: string, stripMeta = false): void;
```

Desde cadena:

```ts
addSvgIconFromText(name: string, iconText: string, family: string, stripMeta = false): void;
```
