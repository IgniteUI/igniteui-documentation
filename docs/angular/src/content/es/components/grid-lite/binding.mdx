# Enlace de datos de Angular Grid Lite

Grid Lite acepta como origen de datos un array de objetos simples. Cada fila de la cuadrícula es la representación renderizada de un registro de datos del array, y las celdas de la fila se controlan mediante la configuración de columnas.

Al aplicar transformaciones de datos, como la ordenación y el filtrado, la cuadrícula no modifica la referencia de los datos originales. Es decir, las transformaciones de datos no se reflejarán en el origen original. La cuadrícula no hace un seguimiento de los cambios en los objetos del array de datos, por lo que la modificación directa de los objetos de datos no se reflejará.

## Cambiar el origen de datos en tiempo de ejecución

El componente admite cambiar su origen de datos en tiempo de ejecución. Si el nuevo origen tiene una "forma" distinta a la del anterior, asegúrese de actualizar también la configuración de columnas.

```typescript
grid.data = [...{
  /** records follow */
}];
```

```html
<igx-grid-lite>
    {/* Update column configuration, add or remove columns as needed to represent the new data. */}
    <igx-grid-lite-column field="id"></igx-grid-lite-column>
</igx-grid-lite>
```

Si la cuadrícula tiene habilitado `autoGenerate`, "_inferirá_" automáticamente la nueva configuración de columnas cuando cambien los datos.

```typescript
grid.autoGenerate = true;

/** After the new binding the grid will infer the column collection from the bound data. */
grid.data = [];
```

O bien, establezca las propiedades correspondientes en el HTML en lugar de usar un `@ViewChild` para la cuadrícula.

```html
  <igx-grid-lite
    [autoGenerate]="true"
    [data]="data">
  </igx-grid-lite>
```


<DocsAside type="info">
Los estados de ordenación y filtrado del componente Grid Lite se conservan al cambiar el origen de datos de esta manera.
</DocsAside>
Normalmente querrá restablecerlos llamando a <ApiLink type="GridLite" member="clearSort" label="clearSort()" /> y/o a <ApiLink type="GridLite" member="clearFilter" label="clearFilter()" />.

En el ejemplo siguiente, la cuadrícula tiene habilitada la generación automática de columnas. Al hacer clic en el botón de cambiar datos,
la colección de columnas se restablece y se enlaza un nuevo origen de datos a la cuadrícula.
