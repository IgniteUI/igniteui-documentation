# Cuadrícula de datos de Angular gratuita y de código abierto (Grid Lite)

Ignite UI for Angular Grid Lite es una cuadrícula de datos de Angular ligera y de alto rendimiento, gratuita, de código abierto y creada para las aplicaciones modernas de Angular.

Esta cuadrícula de datos de Angular gratuita es una cuadrícula de datos JavaScript de código abierto creada como Web Component, lo que significa que puede usarla sin dependencias, con o sin un framework web. Ofrece las funciones esenciales de visualización de datos con una sobrecarga mínima y el rendimiento que esperan los usuarios. Angular Grid Lite está diseñado para desarrolladores que necesitan una presentación de datos rápida y ligera.

## Lo que obtiene con nuestra cuadrícula de datos de Angular gratuita

Nuestro Angular Grid Lite gratuito y de código abierto incluye las siguientes funciones por columna: ordenación, filtrado, ocultación, redimensionado y una variedad de tipos de datos predefinidos. El rendimiento es muy alto gracias a la virtualización de filas. Además, el componente admite la navegación por teclado y los temas mediante el [Ignite UI Theming Framework](/themes).

Angular <a href="https://custom-elements-everywhere.com/#angular" target="_blank">admite</a> elementos personalizados, por lo que puede usar Grid Lite con facilidad.

## Instalación y configuración
Para usar Grid Lite en su aplicación puede importarlo directamente desde `igniteui-angular` a través de este punto de entrada `igniteui-angular/grids/lite`. Pero también necesita instalar el paquete `igniteui-grid-lite` que impulsa la interfaz. <ApiLink type="GridLite" /> proporciona los enlaces de Angular (eventos, plantillas, DI, detección de cambios, pipes), mientras que la interfaz visual de Grid Lite la renderiza `igniteui-grid-lite`. Instalar ambos garantiza que Grid Lite se comporte de forma nativa en Angular y aprovecha toda la interfaz de `igniteui-grid-lite`.

```shell
npm install igniteui-grid-lite
```

Antes de iniciar la aplicación, asegúrese de importar y pasar el esquema de elementos personalizados tal como se muestra a continuación.

```typescript
// app.component.ts

import { Component } from '@angular/core';
import { IgxGridLiteComponent, IgxGridLiteColumnComponent } from 'igniteui-angular/grids/lite';

@Component({
  ...
  imports: [IgxGridLiteComponent, IgxGridLiteColumnComponent],
  template: `
    <div>
      <igx-grid-lite [data]="products">
        <igx-grid-lite-column field="id" header="ID" dataType="number"></igx-grid-lite-column>
        <igx-grid-lite-column field="name" header="Name"></igx-grid-lite-column>
        {/* Additional columns */}
      </igx-grid-lite>
    
</div>
  `
})
export class AppComponent {
  products: Products[] = [...];
}
```

## Funciones

### Rendimiento integrado

Cuando usa nuestra cuadrícula de datos de Angular gratuita, puede implementar la virtualización a nivel de fila. Esto le permite renderizar cantidades ilimitadas de datos con un desplazamiento fluido.

### Tipos de columna automáticos

Los tipos de columna se generan automáticamente a partir de su origen de datos, con filtrado integrado según el tipo de columna.

### Plantillas de columna personalizadas

Con nuestro control de cuadrícula de datos de Angular de código abierto también puede ofrecer cualquier tipo de experiencia de usuario mediante plantillas de columna. ¡Cualquier cosa que imagine puede renderizarse en una columna de la cuadrícula!

### Funciones interactivas

Todas las funciones interactivas básicas que esperan sus usuarios, como el filtrado, la ocultación, el redimensionado y la ordenación de columnas, y más.

### Diseño atractivo y marca

Esta cuadrícula de datos de Angular gratuita (Grid Lite) incluye compatibilidad integrada con los temas Bootstrap, Material y Fluent, además de infinitas opciones de marca con paletas de colores, fuentes, elevación, densidad de visualización y más.

### Navegación por teclado completa

La navegación por teclado completa al estilo de Excel ofrece al usuario la experiencia que espera, con una navegación por teclado de alto rendimiento.
