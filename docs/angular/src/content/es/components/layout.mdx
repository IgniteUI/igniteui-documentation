# Descripción general de las directivas Angular Layout Manager

<div class="highlight">
Las directivas de disposición de Ignite UI for Angular permiten a los desarrolladores especificar una dirección de disposición para los elementos hijos del contenedor al que se aplican. La disposición puede fluir en vertical o en horizontal, con controles para el ajuste de línea, la justificación y la alineación.
</div>

## Uso

Use la directiva <ApiLink type="LayoutDirective" label="**igxLayout**" /> en un elemento contenedor para especificar la dirección de disposición de sus hijos:

<hr/>

### En horizontal con dirección Row

Use <ApiLink type="LayoutDirective" member="dir" label="igxLayoutDir" />`="row"`.

<Sample src="/layouts/layout-direction-row" height={180} alt="" />

<hr/>

### En vertical con dirección Column

Use <ApiLink type="LayoutDirective" member="dir" label="igxLayoutDir" />`="column"`.

<Sample src="/layouts/layout-direction-column" height={300} alt="" />

<hr/>

<DocsAside type="info">
Invierta el orden usando <ApiLink type="LayoutDirective" member="reverse" label="igxLayoutReverse" />`="true"`.
</DocsAside>

<hr/>

### Personalizar el orden de los elementos

Personalice el orden del elemento usando `igxFlexOrder`.

<Sample src="/layouts/layout-custom-order" height={110} alt="" />

<hr/>

### Cambiar el espaciado entre elementos

Use <ApiLink type="LayoutDirective" member="justify" label="igxLayoutJustify" />`="space-between | space-around"`.

<Sample src="/layouts/layout-content-space" height={180} alt="" />

<hr/>

### Colocar los elementos a lo largo del eje principal

Use <ApiLink type="LayoutDirective" member="justify" label="igxLayoutJustify" />`="flex-start | center | flex-end"` para especificar la posición de los elementos a lo largo del eje principal según sus preferencias.

<Sample src="/layouts/layout-justify-content" height={180} alt="" />

<hr/>

### Colocar los elementos a lo largo del eje transversal

Use <ApiLink type="LayoutDirective" member="itemalign" label="itemAlign" />`="flex-start | center | flex-end"` para especificar la posición de los elementos a lo largo del eje transversal según sus preferencias.

<Sample src="/layouts/layout-align-items" height={400} alt="" />

<hr/>

### También puede envolver los elementos

Use <ApiLink type="LayoutDirective" member="wrap" label="igxLayoutWrap" />`="wrap"`.

<Sample src="/layouts/layout-wrap" height={180} alt="" />

<DocsAside type="info">
La directiva <ApiLink type="LayoutDirective" label="igxLayout" /> afecta a las direcciones de flujo de
</DocsAside>
los hijos **directos** del contenedor.
<hr/>

## Anidamiento

Use la directiva <ApiLink type="FlexDirective" label="igxFlex" /> para los elementos dentro de un padre <ApiLink type="LayoutDirective" label="igxLayout" /> con el fin de controlar propiedades específicas de flexbox.
