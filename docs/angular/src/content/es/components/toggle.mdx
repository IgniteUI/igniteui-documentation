# Descripción general de la directiva Angular Toggle

<div class="highlight">
La directiva Toggle de Ignite UI for Angular permite convertir en desplegable un contenedor del DOM mediante la interacción del usuario.
</div>

## Primeros pasos con Ignite UI for Angular Toggle

Para empezar a usar la directiva Ignite UI for Angular Toggle, primero debe instalar Ignite UI for Angular. En una aplicación Angular existente, escriba el siguiente comando:

```cmd
ng add igniteui-angular
```

Para una introducción completa a Ignite UI for Angular, lea el tema [_primeros pasos_](/general/getting-started).

El siguiente paso es importar `IgxToggleModule` en el archivo **app.module.ts**.

```typescript
// app.module.ts

...
import { IgxToggleModule } from 'igniteui-angular/directives';
// import { IgxToggleModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxToggleModule]
    ...
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` puede importar `IgxToggleDirective` como dependencia independiente.

```typescript
// home.component.ts

import { IgxToggleDirective, IgxButtonDirective } from 'igniteui-angular/directives';

// import { IgxToggleDirective, IgxButtonDirective } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <button class="toggle-button" igxButton="contained" (click)="toggleContent()">Toggle</button>
    <div class="toggle-content" igxToggle>
        <section class="toggle-section">
            <img src="assets/images/toggle/nature.jpg" alt="Nature" />
        </section>
    
</div>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxToggleDirective, IgxButtonDirective]
})
export class HomeComponent {}
```

Ahora que ha importado el módulo o la directiva de Ignite UI for Angular Toggle, puede empezar a usar la directiva `igxToggle`.

## Uso de la directiva Angular Toggle

### Mostrar el toggle

Para mostrar y ocultar el contenido del toggle, use sus métodos <ApiLink type="ToggleDirective" member="open" label="open" /> y <ApiLink type="ToggleDirective" member="close" label="close" />:

```typescript
import { IgxToggleDirective } from 'igniteui-angular/directives'
// import { IgxToggleDirective } from '@infragistics/igniteui-angular'; for licensed package
...

export class Class {
    @ViewChild(IgxToggleDirective) toggle: IgxToggleDirective;

    toggleContent() {
        if (this.toggle.collapsed) {
            this.toggle.open();
        } else {
            this.toggle.close();
        }
    }
}
```

Después, en la plantilla de nuestro componente, podemos aplicar la directiva al elemento que queremos que sea desplegable:

```html
{/*template.component.html*/}
<button class="toggle-button" igxButton="contained" (click)="toggleContent()">Toggle</button>
<div class="toggle-content" igxToggle>
    <section class="toggle-section">
        <img src="assets/images/toggle/nature.jpg"/>
    </section>
</div>
```

## Ejemplos

### Cambiar la posición

En el siguiente ejemplo usaremos una estrategia de posicionamiento distinta, de modo que el contenido se muestre debajo del botón.

La directiva `igxToggle` usa el proveedor <ApiLink type="OverlayService" />. Los métodos `open`, `close` y `toggle` aceptan opciones de superposición opcionales que controlan cómo se muestra el contenido. Si se omiten, se usan las opciones de superposición predeterminadas, como en el ejemplo anterior.

<DocsAside type="info">
De forma predeterminada, la propiedad <ApiLink kind="interface" type="OverlaySettings" member="closeOnOutsideClick" /> está establecida en `true`. Para desactivar esta función, la propiedad debe establecerse en `false`. Además, la propiedad <ApiLink kind="interface" type="OverlaySettings" member="closeOnEscape" /> toma por defecto `false`, así que para usarla tenemos que establecerla en `true`.
</DocsAside>

```typescript
// template.component.ts

...
    @ViewChild(IgxToggleDirective) public igxToggle: IgxToggleDirective;
    @ViewChild('button') public igxButton: ElementRef;

    public _positionSettings = {
        horizontalStartPoint: HorizontalAlignment.Left,
        verticalStartPoint: VerticalAlignment.Bottom
    };

    public _overlaySettings = {
        target: this.igxButton.nativeElement,
        closeOnOutsideClick: false,
        closeOnEscape: true,
        positionStrategy: new ConnectedPositioningStrategy(this._positionSettings)
    };

    public toggle() {
        this.igxToggle.toggle(this._overlaySettings);
    }
```

### Acciones automáticas del toggle

Para evitar usar los métodos `open` y `close`, podemos usar una directiva que tiene un controlador `onClick` y que cambia automáticamente el estado del toggle al que se refiere.

Si queremos aprovechar esta funcionalidad, tendremos que usar la `IgxToggleActionDirective` de `IgxToggleModule` y asignarle `IgxToggleDirective`.

<DocsAside type="info">
La <ApiLink type="ToggleActionDirective" /> debe declararse en el elemento que vamos a usar como disparador (toggle).
</DocsAside>

```html
{/*template.component.html*/}
<button class="toggle-button"  igxButton="contained" [igxToggleAction]="toggleRef">Toggle</button>
<div class="toggle-content" igxToggle #toggleRef="toggle">
    <section class="toggle-section">
        <h6>Automatic toggle actions</h6>
    </section>
</div>
```

Después de estos cambios, el toggle debería funcionar exactamente igual.

<Sample src="/interactions/toggle-sample-2" height={370} alt="" />

<DocsAside type="info">
De forma predeterminada, `IgxToggleActionDirective` excluye su elemento host de la propiedad <ApiLink kind="interface" type="OverlaySettings" member="closeOnOutsideClick" />. Por tanto, al hacer clic en el elemento host no se dispara ningún evento. Además, esta directiva establece su elemento host como las opciones de superposición <ApiLink kind="interface" type="OverlaySettings" member="target" />.
</DocsAside>

### Proveedor de servicio de toggle automático

Hay una forma cómoda de mantener el estado de la directiva `igxToggle` y controlarla a través del proveedor <ApiLink type="NavigationService" />. Solo tenemos que establecer un identificador para nuestro elemento `igxToggle`, que se usará para registrar el toggle en el servicio. Si queremos controlar su estado automáticamente, tenemos que pasar este identificador a `igxToggleActionDirective`.

```html
{/*template.component.html*/}
<button igxToggleAction="toggleId" class="toggle-button" igxButton="contained">Toggle</button>
<div igxToggle id="toggleId" class="toggle-content">
    <section class="toggle-section">
        <h6>Toggled by the service provider</h6>
    </section>
</div>
```

### Desplazar el contenedor del toggle

Podemos desplazar la posición del contenedor del toggle a lo largo del eje correspondiente en una cantidad determinada. El método `setOffset` también admite un parámetro opcional `offsetMode` que determina si se suman los valores de desplazamiento actuales o si se establecen en un valor específico.

```typescript
// deltaX and deltaY determine by how much the container will be offset compared to its' previous position
// Using OffsetMode.Add to add the values (default behavior)
public offsetToggleAdd() {
    const deltaX = 30;
    const deltaY = 30;
    this.toggle.setOffset(deltaX, deltaY, OffsetMode.Add);
}
```

```typescript
// deltaX and deltaY determine the exact position to set the container to, relative to its target element.
// Using OffsetMode.Set to set the offset to specific values
public offsetToggleSet() {
    const deltaX = 30;
    const deltaY = 30;
    this.toggle.setOffset(deltaX, deltaY, OffsetMode.Set);
}
```
