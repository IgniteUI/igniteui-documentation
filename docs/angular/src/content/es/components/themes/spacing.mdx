# Espaciado

La configuración del espaciado puede mejorar notablemente la representación visual de grandes cantidades de datos. En Ignite UI for Angular ofrecemos un conjunto predefinido de opciones para ajustar los rellenos y los márgenes.

En lugar de usar valores fijos, usamos propiedades personalizadas CSS para ajustar el espaciado a nivel de aplicación o de componente.

## Cómo funciona el espaciado

Ignite UI for Angular ofrece un sofisticado sistema de espaciado que se escala dinámicamente según el tamaño de los componentes (pequeño, mediano, grande). El sistema de espaciado se basa en propiedades personalizadas CSS que le permiten controlar el espaciado a nivel global o de componente sin escribir CSS personalizado.

## La relación entre tamaño y espaciado

El sistema de espaciado de Ignite UI está estrechamente ligado al tamaño de los componentes. Los componentes pueden tener tres tamaños distintos:

- **Pequeño**: espaciado compacto para diseños densos
- **Mediano**: espaciado equilibrado predeterminado.  
- **Grande**: espaciado cómodo para interfaces táctiles

El espaciado se adapta automáticamente según el tamaño que esté activo, lo que garantiza una jerarquía visual coherente en toda la aplicación.

## Propiedades personalizadas CSS básicas

El sistema de espaciado gira en torno a varias propiedades personalizadas CSS clave:

### Propiedades de espaciado globales

- `--ig-spacing`: el multiplicador base de espaciado (predeterminado: 1)
- `--ig-spacing-small`: espaciado para componentes de tamaño pequeño
- `--ig-spacing-medium`: espaciado para componentes de tamaño mediano.  
- `--ig-spacing-large`: espaciado para componentes de tamaño grande

### Propiedades de espaciado direccional

- `--ig-spacing-inline`: controla el espaciado horizontal
- `--ig-spacing-block`: controla el espaciado vertical
- `--ig-spacing-inline-small`: espaciado horizontal para componentes pequeños
- `--ig-spacing-inline-medium`: espaciado horizontal para componentes medianos
- `--ig-spacing-inline-large`: espaciado horizontal para componentes grandes
- `--ig-spacing-block-small`: espaciado vertical para componentes pequeños
- `--ig-spacing-block-medium`: espaciado vertical para componentes medianos
- `--ig-spacing-block-large`: espaciado vertical para componentes grandes

## Variables de detección de tamaño

Los componentes usan propiedades personalizadas CSS para detectar automáticamente su tamaño actual:

- `--is-small`: vale 1 cuando el componente es de tamaño pequeño, y 0 en caso contrario.
- `--is-medium`: vale 1 cuando el componente es de tamaño mediano, y 0 en caso contrario  
- `--is-large`: vale 1 cuando el componente tiene tamaño large; 0 en caso contrario.
- `--component-size`: valor numérico que indica el tamaño actual (1=pequeño, 2=mediano, 3=grande).

El sistema de temas gestiona estas variables automáticamente, y cambian según la configuración de tamaño del componente, que se controla con `--ig-size`.

## Ejemplos prácticos de uso

### Control del espaciado global

Para que todos los componentes sean más compactos en toda su aplicación:

```css
:root {
  --ig-spacing: 0.8; /* 20% less spacing */
}
```

Para aumentar el espaciado y mejorar la accesibilidad táctil:

```css
:root {
  --ig-spacing: 1.2; /* 20% more spacing */
}
```

### Espaciado específico de componente

Para ajustar el espaciado de un tipo de componente concreto:

```css
.my-grid {
  --ig-spacing: 0.5; /* More compact grid, 50% of the original spacing in all sizes */
}
```

### Control del espaciado direccional

Para reducir solo el espaciado horizontal y mantener el vertical normal:

```css
:root {
  --ig-spacing-inline: 0.7;
  --ig-spacing-block: 1.0;
}
```

### Espaciado específico por tamaño

Para personalizar el espaciado de tamaños de componente concretos:

```css
:root {
  --ig-spacing-small: 0.5;   /* Very tight for small components */
  --ig-spacing-medium: 1.0;  /* Normal for medium components */
  --ig-spacing-large: 1.5;   /* Extra spacious for large components */
}
```

## Cómo funcionan los multiplicadores de espaciado

El sistema de espaciado usa multiplicadores para escalar los valores base:

- Los valores de espaciado de los componentes se multiplican por las variables de espaciado activas
- Por ejemplo, si un componente tiene un relleno base de `8px` y establece `--ig-spacing: 1.5`, el relleno real pasa a ser `12px`
- Los multiplicadores específicos por tamaño, como `--ig-spacing-large`, sustituyen a `--ig-spacing` global para los componentes de tamaño grande
- Los multiplicadores direccionales, como `--ig-spacing-inline`, le permiten escalar el espaciado horizontal y vertical de forma independiente

Este enfoque en cascada mantiene relaciones de espaciado coherentes y le ofrece un control detallado solo con propiedades personalizadas CSS.
