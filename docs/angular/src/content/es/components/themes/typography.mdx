# Tipografía

<div class="highlight">

La tipografía de Ignite UI for Angular está basada en el [sistema de tipos de Material](https://material.io/design/typography/the-type-system.html#). No es intrusiva y es opcional, lo que le permite modificar los estilos de texto usando solo CSS.
</div>

## Descripción general

El sistema de tipos es una **_escala tipográfica_** compuesta por **_13 estilos tipográficos de categoría diferentes_** que se usan en la mayoría de los componentes. Todas las categorías de la escala son totalmente reutilizables y ajustables por el usuario final.

Esta es una lista de las 13 categorías de estilo definidas para el tema Material de Ignite UI for Angular:

Cada tema define su propia escala tipográfica. Esto significa que cada uno de los temas que incluimos (Material, Fluent, Bootstrap e Indigo) tendrá su propia escala tipográfica. Todos comparten las mismas _categorías de escala_, pero pueden tener distinta familia tipográfica, grosor, tamaño, transformación del texto, espaciado entre letras y altura de línea.

## Uso
>
<DocsAside type="info">
De forma predeterminada no aplicamos ningún estilo tipográfico. Para usar nuestra tipografía en su aplicación, debe aplicar la clase CSS `ig-typography` a un elemento de nivel superior. Todos sus descendientes usarán entonces nuestros estilos tipográficos.
</DocsAside>

Hemos elegido [Titillium Web](https://fonts.google.com/selection?selection.family=Titillium+Web:300,400,600,700) como fuente predeterminada del tema Material de Ignite UI for Angular. Para usarla, debe alojarla usted mismo o incluirla desde Google Fonts:

```html
<link
  href="https://fonts.googleapis.com/css?family=Titillium+Web:300,400,600,700"
  rel="stylesheet"
/>
```

Active los estilos tipográficos asignando la clase `ig-typography` al elemento body.

```html
{/* index.html */}
<body class="ig-typography">
  <app-root></app-root>
</body>
```

### Cambiar la familia tipográfica

Para cambiar la familia tipográfica en todos los componentes, solo tiene que sobrescribir la variable CSS `--ig-typography` con otro valor de font-family;

```css
/* styles.css */
:root {
    --ig-font-family: "Open Sans", sans-serif;
}
```

## Estilos de texto

La mayoría de los componentes de Ignite UI for Angular usan internamente los estilos de texto. Por ejemplo, la documentación indica que el componente de botón usa el estilo de texto de botón. Esto significa que podemos modificar la tipografía del componente de botón sobrescribiendo las variables CSS `--ig-button-*` incluidas.

Supongamos que queremos que el texto del botón del tema Material aparezca siempre en minúsculas.

```css
:root {
    --ig-button-text-transform: lowercase;
}
```
