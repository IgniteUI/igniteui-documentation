# Configuración

<div class="highlight">
La biblioteca de temas de Ignite UI for Angular expone varias variables de argumentos de entrada que le permiten configurar el funcionamiento del motor de temas.
</div>
<igc-divider></igc-divider>

## Variables globales

Esta es una lista de las variables globales de Sass reenviadas en el módulo principal de temas:

|    Nombre de la variable  |                                                      Descripción        |
| :---------------: | :---------------------------------------------------------------------: |
|    `$components`  |       Almacena un registro de todos los temas de componente. Se usa para tree-shaking. |
| `$dropped-themes` |            Almacena un registro de los temas descartados. Se usa para tree-shaking.  |

## Estilo de la barra de desplazamiento

Los temas de Ignite UI for Angular incluyen estilos personalizados de barra de desplazamiento que le permiten cambiar el ancho o los colores de todas las barras de desplazamiento de su aplicación. Para aplicar los estilos incluidos, asegúrese de asignar la clase `ig-scrollbar` a un elemento que contenga su componente raíz de la aplicación.

Para personalizar la barra de desplazamiento con más detalle, puede crear un nuevo estilo de barra de desplazamiento con la función <ApiLink kind="sass" module="themes" type="function-scrollbar-theme" label="scrollbar-theme" code={true} />. La función acepta argumentos para cambiar el estilo de la barra de desplazamiento. Podemos personalizar el tamaño, el color, el borde, la altura mínima de la barra... y muchas cosas más.

```scss
// app.component.scss
// Here we set the scrollbar to have size of 16px, scrollbar thumb to be in color pink, and scrolblar track to be in color green
$my-scrollbar-theme: scrollbar-theme($sb-size: 16px, $sb-thumb-bg-color: pink, $sb-track-bg-color: green);

// We use 'tokens' mixin for generating the css variables with the new scrollbar values.

:host {
  @include tokens($my-scrollbar-theme);
}
```
