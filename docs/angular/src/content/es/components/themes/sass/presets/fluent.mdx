# Cambiar del tema Material al tema Fluent

Desde la versión `8.2`, nuestros componentes incluyen un nuevo tema inspirado en [`Microsoft Fluent Design System`](https://www.microsoft.com/design/fluent/)

Para cambiar de `Material` a `Fluent`, puede usar el mixin integrado <ApiLink kind="sass" module="themes" type="mixin-theme" label="theme" />.

También admitimos paletas de Word y Excel. Para usarlas, basta con pasar uno de los dos mapas _**claros**_ `$light-fluent-excel-palette`, `$light-fluent-word-palette`, o uno de los dos mapas _**oscuros**_ `dark-fluent-excel-palette`, `$light-fluent-word-palette` al mixin `theme`:

## Tema Fluent claro

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
@include core();
@include theme(
  $palette: $light-fluent-palette, 
  $schema: $light-fluent-schema
);

// We can also include the Indigo font and font scaling
@include typography(
  $font-family: $fluent-typeface,
  $type-scale: $fluent-type-scale
);
```

## Tema Fluent oscuro

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
@include core();
@include theme(
  $palette: $dark-fluent-palette, 
  $schema: $dark-fluent-schema
);

@include typography(
  $font-family: $fluent-typeface,
  $type-scale: $fluent-type-scale
);
```
