# Elevaciones

<div class="highlight">


Las elevaciones se usan para establecer y mantener límites funcionales entre los árboles del Document Object Model, con el fin de lograr un mejor encapsulado funcional. La implementación de las elevaciones en Ignite UI for Angular se ha modelado según las [elevaciones de Material Design](https://material.io/design/environment/elevation.html#elevation-in-material-design).

</div>
<igc-divider></igc-divider>

## Descripción general

Las sombras en Ignite UI for Angular siguen de cerca las pautas de Material Design para establecer una jerarquía de profundidad basada en 25 niveles de elevación. El tamaño de la sombra proyectada está relacionado con el número de nivel de elevación: cuanto mayor sea el número, mayor será la sombra. Las elevaciones en Ignite UI for Angular se exponen como variables CSS. Cada variable almacena un conjunto de 3 `box-shadows`. Estas `box-shadows` representan los elementos umbra, penumbra y antumbra, que son las propiedades de las sombras tal como se observan en el mundo real.

Esta es una lista de las elevaciones en reposo que usan distintos componentes de Ignite UI for Angular en el tema Material, junto con los nombres de las variables CSS correspondientes:

| Componente                                          | Nivel de elevación predeterminado | Variable CSS      |
| :------------------------------------------------- | :---------------------- | :---------------- |
| banner, button, toast                              | 0                       | --ig-elevation-0  |
| badge, carousel buttons, search input              | 1                       | --ig-elevation-1  |
| button group, contained button, card, grid, switch | 2                       | --ig-elevation-2  |
| navbar, snackbar                                   | 4                       | --ig-elevation-4  |
| floating action button,                            | 6                       | --ig-elevation-6  |
| bottom navigation, ghost chip, dropdown            | 8                       | --ig-elevation-8  |
| navdrawer                                          | 16                      | --ig-elevation-16 |
| dialog                                             | 24                      | --ig-elevation-24 |

Como puede ver en la columna `CSS Variable`, todas las elevaciones se definen con el siguiente formato `--ig-elevation-[level]`. Como se ha mencionado, el número de nivel de elevación va de 0 a 24 (inclusive).

## Uso

Para empezar a usar elevaciones en sus propios componentes, basta con referenciar el nombre de la variable del nivel deseado.

```css
.floaty-element {
  box-shadow: var(--ig-elevation-6);
}
```

Cambiar la elevación en el tema de un componente existente funciona de forma similar.

```css
[igxButton="contained"] {
  --resting-shadow: var(--ig-elevation-4);
  --hover-shadow: var(--ig-elevation-12);
  --focus-shadow: var(--ig-elevation-12);
}
```

La documentación de cada tema de componente indica la elevación predeterminada usada en cada uno de sus estados. Si no se indica ninguna elevación, el componente no usa ninguno de los niveles de elevación predefinidos.

## Definir elevaciones

Actualizar las elevaciones predeterminadas funciona de forma similar a cómo se actualizan los colores de las paletas. Basta con reasignar la variable a otro valor. En el caso de las elevaciones, asegúrese de que el valor sea un `box-shadow`.

Ejemplo:

```css
/* styles.css */
:root {
    --ig-elevation-1: 0 2px 6px 0 rgba(0, 0, 0, .18);
    --ig-elevation-2: 0 3px 9px 0 rgba(0, 0, 0, .24);
}
```

Ahora, todos los componentes que usan los niveles de elevación 1 y 2 tendrán sus sombras actualizadas.

### Sombreado

Puede sobrescribir las elevaciones establecidas globalmente solo para un ámbito concreto. Ya hemos visto que el componente botón usa el nivel de elevación 2 en su estado de reposo. El nivel 2 también lo usan los componentes card y grid. Así que, para cambiar las sombras de los tres, solo tiene que hacer lo siguiente:

```css
[igxButton="contained"],
igx-grid,
igx-card {
    --ig-elevation-2: 0 3px 9px 0 rgba(0, 0, 0, .24);
}
```

Esto establecerá la `--resting-shadow` del botón contenido y de la tarjeta, y la `--grid-shadow` de la cuadrícula, con el valor asignado a `--ig-elevation-2`;

Las elevaciones también pueden crearse y usarse de una forma más potente con Sass. Consulte los temas relacionados a continuación para obtener más información.
