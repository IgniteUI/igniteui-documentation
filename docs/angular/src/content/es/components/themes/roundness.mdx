# Redondeo

Ignite UI for Angular le permite personalizar la forma de los componentes ajustando su redondeo con un valor entre 0 y 1.

## Descripción general

Muchos componentes de Ignite UI tienen valores predefinidos mínimos y máximos de border-radius, que pueden ajustarse usando la variable CSS `--ig-radius-factor`.

Cuando establece `--ig-radius-factor` en 0, el componente usa su border-radius mínimo y tendrá un aspecto más de bloque, con esquinas vivas. Cuando se establece en 1, el componente usa su border-radius máximo predefinido y aparece redondeado.

Esta es una lista de los componentes que tienen valores predefinidos mínimos y máximos de border-radius y que pueden modificarse con la variable `--ig-radius-factor`: <br/>
• [Action Strip](/action-strip) • [Button](inputs/button) • [Button Group](/inputs/button-group) • [Calendar](/calendar) • [Card](/layouts/card) • [Carousel](/layouts/carousel) • [Checkbox](/inputs/checkbox) • [Chip](/inputs/chip) • [Combo](/inputs/combo/overview) • [Date Picker](/date-picker) • [Date Range Picker](/date-range-picker) • [Grid](/grid/grid) • [Input Group](/input-group) • [Linear Progress](/linear-progress) • [List](/list) • [Month Picker](/month-picker) • [Navigation Drawer](/navdrawer) • [Radio](/inputs/radio) • [Ripple](/ripple) • [Snackbar](/snackbar) • [Switch](inputs/switch) • [Toast](/toast)

## Uso

Para alternar entre los dos valores de border-radius de un componente, apunte al selector del elemento y establezca la variable `--ig-radius-factor` en 0 o en 1:

```css
igx-chip {
   --ig-radius-factor: 0;
}
```

Esto aplicará el border-radius mínimo predefinido, de modo que el componente [Chip](/inputs/chip) tendrá esquinas rectas.

```css
igx-chip {
    --ig-radius-factor: 1;
}
```

Y al establecer el valor en 1 se aplica el border-radius máximo predefinido, de modo que el componente [Chip](/inputs/chip) tendrá esquinas redondeadas.

Si quiere que el border-radius esté entre los valores mínimo y máximo definidos, puede establecer la variable `--ig-radius-factor` en un valor decimal entre 0 y 1.
Por ejemplo, si lo establece en `0.5`, se aplicará un border-radius que equivale al 50 % del valor máximo permitido del componente.

```css
igx-chip {
    --ig-radius-factor: 0.5;
}
```
