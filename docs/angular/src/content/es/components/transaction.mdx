# Servicio Transaction

<ApiLink kind="interface" type="TransactionService" label="Servicio Transaction" /> es un middleware inyectable (mediante [la DI de Angular](https://angular.io/guide/dependency-injection)) que un componente puede usar para acumular cambios sin afectar de inmediato a los datos subyacentes.

        alt="Arquitectura del servicio Transaction"

<DocsAside type="info">
La transformación de datos del esquema anterior no es obligatoria. No necesita usar un pipe para usar <ApiLink kind="interface" type="TransactionService" label="Servicio Transaction" />.
</DocsAside>

<ApiLink kind="interface" type="TransactionService" label="Servicio Transaction" /> permite añadir transacciones. Después de añadir al menos una transacción, puede confirmar o borrar todos los cambios, o los cambios de un único registro. Como mantiene un registro detallado, también puede ejecutar operaciones de deshacer y rehacer.

Cada vez que ejecuta una operación (<ApiLink kind="interface" type="Transaction" />), se añade al registro de transacciones y a la pila de deshacer. Todos los cambios del registro de transacciones se acumulan después por registro. A partir de ese momento, el servicio mantiene un **estado** agregado que consiste solo en operaciones de añadir, actualizar o eliminar para registros únicos. Esto se basa en una interfaz <ApiLink type="State" kind="interface" /> que tiene tres propiedades: `recordRef`, `type` y `value`.

Hemos creado tres clases sobre <ApiLink kind="interface" type="TransactionService" label="Servicio Transaction" /> que permiten confirmar de una vez todos los cambios realizados, o solo los cambios realizados en un registro concreto. Esas clases son <ApiLink type="BaseTransactionService" label="igxBaseTransactionService" />, <ApiLink type="TransactionService" /> y `IgxHierarchicalTransactionService`.

<ApiLink type="TransactionService" /> y `IgxHierarchicalTransactionService` están totalmente integrados con nuestros componentes <ApiLink type="Grid" label="igxGrid" />, <ApiLink type="HierarchicalGrid" label="igxHierarchicalGrid" /> y <ApiLink type="TreeGrid" label="igxTreeGrid" />. Puede encontrar ejemplos detallados del uso de esos componentes con transacciones habilitadas en los temas siguientes:

- [Edición por lotes y transacciones en igxHierarchicalGrid](/hierarchicalgrid/batch-editing)
- [Edición por lotes y transacciones en igxTreeGrid](/treegrid/batch-editing)
