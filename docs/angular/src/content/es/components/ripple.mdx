## Primeros pasos con la directiva Ignite UI for Angular Ripple

Para empezar con la directiva Ripple de Ignite UI for Angular, primero debe instalar Ignite UI for Angular. En una aplicación Angular existente, escriba el siguiente comando:

```cmd
ng add igniteui-angular
```

Para una introducción completa a Ignite UI for Angular, lea el tema [_primeros pasos_](/general/getting-started).

El siguiente paso es importar `IgxRippleModule` en el archivo **app.module.ts**.

```typescript
// app.module.ts

import { IgxRippleModule } from 'igniteui-angular/directives';
// import { IgxRippleModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    imports: [
        ...
        IgxRippleModule,
        ...
    ]
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` puede importar `IgxRippleDirective` como dependencias independientes.

```typescript
// home.component.ts

import { IgxRippleDirective, IgxButtonDirective } from 'igniteui-angular/directives';
// import { IgxRippleDirective, IgxButtonDirective } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: '<button igxButton="contained" igxRipple>Click Me</button>',
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IgxRippleDirective, IgxButtonDirective],
})
export class HomeComponent {}
```

Ahora que ha importado el módulo o la directiva de Ignite UI for Angular Ripple, puede empezar a usar la directiva `igxRipple`.

<DocsAside type="warning">
<ApiLink type="RippleDirective" label="igxRipple" /> usa la API Web Animation y se ejecuta de forma nativa en [los navegadores que la admiten.](http://caniuse.com/#feat=web-animation)
El polyfill `web-animations.min.js` está [disponible](https://github.com/web-animations/web-animations-js)
para otros navegadores.
</DocsAside>

## Uso de la directiva Angular Ripple

### Añadir el efecto de onda

Use la directiva `igxRipple` para añadir un efecto de onda al elemento especificado:

```html
<button igxButton="contained" igxRipple>Click Me</button>
```

## Ejemplos

### Color personalizado

Puede cambiar fácilmente el color predeterminado de la onda usando `igxRipple`:

```html
<button igxButton="contained" igxRipple="white">White</button>
```

<Sample src="/interactions/ripple-sample-6" height={100} alt="Ejemplo de Angular Ripple" />

### Efecto de onda centrado

De forma predeterminada, el efecto de onda empieza en la posición del evento de clic. Puede cambiar este comportamiento usando la propiedad <ApiLink type="RippleDirective" member="centered" label="igxRippleCentered" /> y estableciendo el centro del elemento como origen.

```html
<button igxButton="contained" igxRipple="white" [igxRippleCentered]="true">
  Centered
</button>
```

<Sample src="/interactions/ripple-sample-3" height={100} alt="Ejemplo de Angular Ripple" />

### Duración de la onda

Podemos usar la propiedad <ApiLink type="RippleDirective" member="rippleDuration" label="igxRippleDuration" /> para cambiar la duración de la animación de la onda, que por defecto es de 600 milisegundos.

```html
<button igxButton="contained" igxRipple [igxRippleDuration]="2000">
  Click Me
</button>
```

<Sample src="/interactions/ripple-sample-4" height={100} alt="Ejemplo de Angular Ripple" />

### Destino de la onda

Use la propiedad <ApiLink type="RippleDirective" member="rippleTarget" label="igxRippleTarget" /> para asociar un efecto de onda a un elemento concreto dentro de un elemento padre.

```html
<div class="parent" igxRipple="white" igxRippleTarget=".child" [igxRippleCentered]="true">
  ...
  <button class="sample-button child" igxButton="contained">Read More</button>
</div>
```

Tenga en cuenta que, tanto si hace clic en el elemento padre como en el hijo, el efecto de onda solo aparecerá en el botón.

<Sample src="/interactions/ripple-sample-2" height={350} alt="Ejemplo de Angular Ripple" />

<DocsAside type="info">
El elemento hijo que quiere seleccionar con la propiedad `igxRippleTarget` debe tener posición relativa.
</DocsAside>

## Estilos

En primer lugar, para usar las funciones que expone el motor de temas, tenemos que importar en nuestro archivo de estilos el archivo `index`, donde se encuentran todas las funciones de estilo y los mixins:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Puede crear fácilmente un tema nuevo que extienda <ApiLink kind="sass" module="themes" type="function-ripple-theme" label="ripple-theme" code={true} /> y acepte los parámetros necesarios para personalizar la onda como desee.

```scss
$custom-ripple-theme: ripple-theme(
  $color: #383779,
);
```

El siguiente paso es pasar el tema personalizado de la onda:

```scss
:host {
  @include tokens($custom-ripple-theme);
}
```

<DocsAside type="info">
Un color establecido con la directiva `igxRiple` tendría prioridad sobre el establecido por un tema personalizado.
</DocsAside>
