# Guía paso a paso con Ignite UI CLI

El modo paso a paso de Ignite UI CLI es un asistente interactivo que le guía por la creación del proyecto, la selección de la plantilla, el tema y la adición de vistas de componentes para proyectos Angular basados en [Ignite UI CLI](./getting-started-with-cli.mdx). Cubre las mismas operaciones que los comandos no interactivos `ig new` y `ig add`, pero le pregunta en cada paso en lugar de exigir todos los argumentos de antemano.

El modo paso a paso no admite el uso mediante scripts ni sin interacción; para eso, use los comandos directos `ig new` y `ig add` con argumentos explícitos. El asistente depende de `Inquirer.js`; consulte [los terminales compatibles](https://github.com/SBoudrias/Inquirer.js#support-os-terminals) para ver la compatibilidad.

Para activar el asistente, ejecute:

```bash
ig
```

o:

```bash
ig new
```

## Crear un proyecto nuevo

Primero se le pedirá que escriba un nombre para su aplicación:

<Image src={igStepByStepNewProjectName} alt="Pregunta paso a paso del nombre del nuevo proyecto" class="responsive-img" />

Después de seleccionar `Angular` como framework, se le pedirá que elija el tipo de proyecto que se va a generar:

<Image src={igStepByStepProjectTypeCli} alt="Pregunta paso a paso: selección del tipo de proyecto" class="responsive-img" />

A continuación, se le guiará para elegir una de las plantillas de proyecto disponibles. Hay tres plantillas base: **Empty Project**, **Side Navigation** y **Side Navigation Mini**. Desplácese por las opciones disponibles con las teclas de flecha y pulse ENTER para confirmar la selección:

<Image src={igStepByStepNewProjectTemplate} alt="Pregunta paso a paso: selección de la plantilla del nuevo proyecto" class="responsive-img" />

Si selecciona **Side Navigation** o **Side Navigation Mini**, el asistente mostrará un paso adicional que pregunta si quiere añadir un [módulo de autenticación](./auth-template.mdx) al proyecto. Si responde que sí, se genera la variante de autenticación correspondiente (`side-nav-auth` o `side-nav-mini-auth`). Si selecciona **Empty Project**, se omite la pregunta de autenticación.

<Image src={igStepByStepNewProjectQuestion} alt="Pregunta paso a paso sobre la autenticación" class="responsive-img" />

El siguiente paso es elegir un tema para su aplicación. Si selecciona la opción predeterminada, se incluye un archivo CSS precompilado (`igniteui-angular.css`) con el tema predeterminado de Ignite UI for Angular en la carpeta `angular.json` de su proyecto. La opción personalizada genera una paleta de colores y una configuración de tema con la [API de temas](../../themes/sass/index.mdx) en `app/styles.scss`.

<Image src={igStepByStepNewProjectTheme} alt="Pregunta paso a paso: selección del tema del nuevo proyecto" class="responsive-img" />

Tras completar los pasos anteriores, se genera la estructura de la aplicación. Después, el asistente le pide que [configure los asistentes de programación con IA](#configurar-asistentes-de-ia). Cuando termina la configuración de IA, se inicializa un repositorio Git, se confirma el proyecto y se le pregunta si quiere terminar el proceso o añadir una nueva vista a su aplicación:

<Image src={igStepByStepNewProjectAction} alt="Pregunta paso a paso: acción del nuevo proyecto" class="responsive-img" />

## Añadir vista

Ignite UI CLI admite varias plantillas de componentes y plantillas de escenarios que pueden añadirse a un proyecto. Este modo puede activarse como continuación de la creación del proyecto o dentro de un proyecto existente con el comando siguiente.

```bash
ig add
```

Se le mostrará una [lista de las plantillas disponibles](./component-templates.mdx#plantillas-de-componentes), agrupadas por categoría.

<Image src={igStepByStepTemplateGroup} alt="Pregunta paso a paso: selección del grupo de plantillas" class="responsive-img" />

Use las teclas de flecha para desplazarse por las opciones y ENTER para seleccionar. Para algunas plantillas, como `Custom Grid`, se le mostrará una lista de funciones opcionales que puede activar o desactivar con la tecla SPACE:

<Image src={igStepByStepComponentFeatures} alt="Pregunta paso a paso: alternancia de funciones del componente" class="responsive-img" />

Si decide añadir un escenario a su aplicación, también verá una lista de las [plantillas de escenario](./component-templates.mdx#plantillas-de-escenarios) disponibles:

<Image src={igStepByStepScenarioTemplates} alt="Pregunta paso a paso: selección de plantilla de escenario" class="responsive-img" />

Después de añadir una plantilla, se le preguntará si quiere añadir más vistas o terminar el proceso. Al terminar, se instalan las dependencias de paquetes pendientes y la aplicación se sirve y se abre en su navegador predeterminado.

Para añadir más vistas de Ignite UI for Angular a un proyecto más adelante sin el asistente, use el comando directo `add`:

```bash
ig add [template] [name]
```

## Configurar asistentes de IA

Tras elegir el framework, el tipo de proyecto, la plantilla y el tema, el asistente le pide que configure la integración con los asistentes de programación con IA. Este paso ejecuta la misma lógica que `ig ai-config`, pero está integrado en el flujo de creación del proyecto.

### Elegir asistentes de programación

Se le pedirá que seleccione para qué asistentes de programación quiere configurar los servidores MCP. Use la tecla SPACE para alternar las selecciones y ENTER para confirmar:

<Image src={igStepByStepAiConfigAssistants} alt="Pregunta paso a paso de configuración de IA: asistentes de programación" class="responsive-img" />

- **Generic** (Claude Code, VS Code y otros): escribe `.mcp.json`
- **VS Code** (GitHub Copilot): escribe `.vscode/mcp.json`
- **Cursor**: escribe `.cursor/mcp.json`
- **Gemini**: escribe `.gemini/settings.json`
- **JetBrains Junie**: escribe `.junie/mcp/mcp.json`
- **None**: omite la configuración de MCP

La selección predeterminada es **Generic**. Seleccionar **None** omite por completo la configuración del servidor MCP.

### Elegir agentes de IA

A continuación, se le pedirá que seleccione para qué agentes de IA quiere configurar los archivos de skills y las instrucciones:

<Image src={igStepByStepAiConfigAgents} alt="Pregunta paso a paso de configuración de IA: agentes" class="responsive-img" />

- **Generic**: `.agents/skills/` y `AGENTS.md`
- **Claude**: `.claude/skills/` y `.claude/CLAUDE.md`
- **Copilot**: `.github/skills/` y `.github/copilot-instructions.md`
- **Cursor**: `.cursor/skills/` y `.cursor/rules/cursor.mdc`
- **Codex**: `.codex/skills/` y `.codex/instructions.md`
- **Windsurf**: `.windsurf/skills/` y `.windsurf/rules/guidelines.md`
- **Gemini**: `.gemini/skills/` y `.gemini/GEMINI.md`
- **Junie**: `.junie/skills/` y `.junie/guidelines.md`
- **None**: omite los archivos de skills y las instrucciones

Las selecciones predeterminadas son **Generic** y **Claude**. Seleccionar **None** omite por completo la configuración de los agentes.

<DocsAside type="info">
Para omitir por completo las preguntas de configuración de IA durante la creación del proyecto sin interacción, pase `--assistants none --agents none` a `ig new`. Para repetir la configuración de IA más adelante, use `ig ai-config` desde la raíz del proyecto.
</DocsAside>
