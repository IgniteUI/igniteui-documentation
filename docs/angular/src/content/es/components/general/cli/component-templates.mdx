# Plantillas de componentes

Las plantillas de componentes son estructuras de componentes de Angular preconfiguradas que Ignite UI CLI (`ig add`) e Ignite UI Angular Schematics (`ng g @igniteui/angular-schematics:c`) generan en un proyecto de Angular existente. Cada plantilla produce un componente de Angular funcional con las importaciones y declaraciones de módulo correctas, y un conjunto de datos de ejemplo, listo para ejecutarse sin configuración adicional. Hay plantillas disponibles para cuadrículas, gráficos, medidores, mapas, componentes de disposición, menús, notificaciones, controles de entrada de datos, interacciones, controles de programación y escenarios de aplicación completos.

Estas plantillas solo generan componentes dentro de un espacio de trabajo de Angular existente. No crean un proyecto de Angular nuevo: para eso use `ig new` o `ng new`. Las plantillas son específicas de Ignite UI for Angular; los patrones equivalentes para React, Web Components y Blazor se tratan en la documentación de cada framework. El código generado sirve como punto de partida funcional y puede diferir de las demostraciones en vivo enlazadas en esta página, que reflejan los ejemplos completos de la documentación.
