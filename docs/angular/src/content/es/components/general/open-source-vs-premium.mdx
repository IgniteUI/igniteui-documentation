# Código abierto frente a Premium en Ignite UI for Angular

Ignite UI for Angular ofrece dos caminos distintos para crear aplicaciones modernas basadas en datos: componentes de código abierto y componentes Premium. Este enfoque dual garantiza flexibilidad para los desarrolladores en cada etapa de su proyecto.

## Componentes de código abierto

Hay más de 50 componentes de interfaz disponibles bajo la licencia MIT, entre ellos [Grid Lite](/grid-lite/overview), Accordion, Avatar, Badge, Banner, Button, Calendar, Carousel, Checkbox, Chip, Combo, Date Picker, Drop Down, Input, List, Snackbar y muchos más. Puede encontrar la lista completa en la [tabla comparativa de todos los componentes](#tabla-comparativa-de-todos-los-componentes).

Todos los componentes de código abierto están marcados en el encabezado de sus temas con: <Badge variant="opensource" />

Son ideales para aplicaciones ligeras que necesitan funciones esenciales sin la carga de las funciones empresariales. Puede usarlos libremente en producción, personalizarlos, hacer forks y contribuir a través de GitHub. No se necesita ninguna licencia.

## Componentes Premium

Nuestros componentes Ignite UI Premium incluyen funciones empresariales avanzadas y se usan en aplicaciones complejas que requieren alto rendimiento y más funcionalidad. Los componentes Premium incluyen:

### Cuadrículas y componentes avanzados

- [Data Grid](/grid/grid), [Hierarchical Grid](/hierarchicalgrid/hierarchical-grid), [Tree Grid](/treegrid/tree-grid), [Pivot Grid](/pivotgrid/pivot-grid)
- [Dock Manager](/dock-manager)
- [Query Builder](/query-builder)
- [Biblioteca de gráficos](/charts/chart-overview)
- [Biblioteca de mapas](/geo-map)
- [Excel Library](/excel-library)
- [Spreadsheet](/spreadsheet-overview)
- Medidores: [Bullet Graph](/bullet-graph), [Linear Gauge](/linear-gauge) y [Radial Gauge](/radial-gauge)

Todos los componentes Premium están marcados en el encabezado de sus temas con: <Badge variant="premium" />

Todos los componentes Premium se pueden evaluar localmente e incluso probar en producción con marca de agua. Sin embargo, se requiere una licencia comercial para las implantaciones orientadas al cliente y para aprovechar al máximo las cuadrículas, los gráficos y otros controles Premium avanzados.

## Ruta de actualización

Empiece con Grid Lite para las necesidades básicas y actualice sin problemas a Data Grid, con todas las funciones, a medida que crezca la complejidad de su aplicación. Así se garantiza una refactorización mínima y una transición sin fricciones a las capacidades de nivel empresarial.
