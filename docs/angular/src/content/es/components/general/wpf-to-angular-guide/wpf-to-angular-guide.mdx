# Migrar de escritorio a web: un tutorial de WPF a Angular

El tutorial de WPF a Angular es el primer paso que debe dar para hacer una transición fluida de un framework de `desktop` a uno de `web`. El tutorial está dirigido a desarrolladores de WPF que dan sus primeros pasos en el desarrollo web, y examina algunas diferencias y similitudes de ambos frameworks: estructura de las aplicaciones, enlace de datos, eventos, componentes, etc.

</p>

La guía se divide en los siguientes temas e incluye tutoriales en vídeo:

## [Cree su primera aplicación Angular](/general/wpf-to-angular-guide/create-first-angular-app)

Antes de comenzar a aprender Angular, necesitará instalar los requisitos previos para el desarrollo de aplicaciones web modernas con Angular. Esta sección trata el uso del gestor de paquetes de Node.js, la instalación del IDE Visual Studio Code y algunos conceptos básicos necesarios para el desarrollo web moderno. Consulte el [tutorial en vídeo](https://youtu.be/dhjrAPPad54) de este tema.

## [Cree su interfaz con componentes de Angular](/general/wpf-to-angular-guide/create-ui-with-components)

Crear una interfaz en Angular es muy parecido a crearla en WPF. Normalmente usamos controles de usuario, representados por la clase UserControl. Un UserControl agrupa el marcado y el código en un contenedor reutilizable, lo que permite usar la misma interfaz y funcionalidad en varios lugares distintos. Entender los componentes de Angular es clave para el resto de esta serie, así que empecemos por entender cómo se traducen los componentes de WPF a componentes de Angular. Consulte el [tutorial en vídeo](https://youtu.be/z1SZUezpRXY) de este tema.

## [Enlace de datos unidireccional en Angular](/general/wpf-to-angular-guide/one-way-binding)

Una de las funciones más potentes y más usadas de WPF es el enlace de datos. Facilita mucho la vida de los desarrolladores, al sincronizar la lógica de negocio con la vista y viceversa, sin escribir una sola línea de código adicional. Sin esta potencia, WPF sería simplemente un Windows Forms con mejor aspecto. ¡Por suerte, Angular admite el enlace de datos! Hay dos tipos: el enlace unidireccional y el enlace bidireccional. Esta sección le muestra cómo realizar el enlace de datos unidireccional y cómo se compara con WPF. Consulte el [tutorial en vídeo](https://youtu.be/fP7iVhFNTOk) de este tema.

## [Eventos de Angular](/general/wpf-to-angular-guide/angular-events)

Enlazar los eventos de entrada del usuario es fundamental en cualquier aplicación. Es difícil imaginar una aplicación nueva que no responda de alguna forma a la interacción del usuario. La forma más habitual de hacerlo es con algún tipo de sistema de eventos. WPF ofrece eventos enrutados, eventos CLR y comandos. En Angular existen los eventos del DOM. En esta sección aprenderá sobre los eventos del DOM y cómo gestionar la entrada del usuario. Consulte el [tutorial en vídeo](https://youtu.be/V1Futz4W400) de este tema.

## [Enlace de datos bidireccional en Angular](/general/wpf-to-angular-guide/two-way-binding)

En Angular, el enlace unidireccional actualiza la vista con los datos procedentes de la clase del componente. Como en WPF, también podemos hacer lo contrario: actualizar la clase del componente desde la vista. En ese caso necesitamos usar un enlace bidireccional. Esta sección compara el enlace bidireccional en WPF y muestra lo fácil que es empezar. Consulte el [tutorial en vídeo](https://youtu.be/MrjTTDEj7cA) de este tema.

## [Transformar datos con pipes de Angular](/general/wpf-to-angular-guide/angular-pipes)

En WPF usamos un IValueConverter para transformar datos; en una aplicación Angular usamos pipes de Angular. El pipe es muy parecido al convertidor de WPF. Recibe datos como entrada y los transforma en la salida deseada para mostrarlos. Esta sección muestra algunos de los pipes predefinidos de Angular y cómo usarlos en una aplicación. Consulte el [tutorial en vídeo](https://youtu.be/Gmz5kio50FE) de este tema.

## [Directivas estructurales en Angular](/general/wpf-to-angular-guide/structural-directives)

Como desarrolladores de WPF, cada vez que queremos añadir o quitar un elemento del árbol visual tenemos que recurrir al code-behind y escribir código C#, o podemos combinar el enlace de datos con un convertidor de visibilidad, lo que de nuevo requiere lógica personalizada y recursos estáticos. Así lo hemos hecho siempre en WPF, pero Angular lo hace mucho más fácil. Esta sección muestra cómo las directivas estructurales permiten manipular los elementos de una aplicación Angular. Consulte el [tutorial en vídeo](https://youtu.be/vQe7R78Od8k) de este tema.

## [Elementos de disposición](/general/wpf-to-angular-guide/layout)

En WPF, para disponer los elementos de la aplicación, hay que colocarlos dentro de un Panel. En Angular usamos CSS. Este tema trata la disposición y cómo usar funciones de CSS como Flexbox y CSS Grid.
