# Angular Schematics e Ignite UI CLI

Ignite UI CLI y la colección de Ignite UI for Angular Schematics son dos herramientas de andamiaje complementarias para generar proyectos de Angular y vistas de componentes preconfigurados para Ignite UI for Angular. Ambas ofrecen un asistente guiado paso a paso y modos de comando no interactivos. Las dos producen el mismo resultado de proyecto; solo se diferencian en cómo se integran en su flujo de trabajo.

Ignite UI CLI no gestiona proyectos de Blazor ni de Web Components a través de esta cadena de herramientas de Angular. Para el flujo de trabajo solo de Schematics de Angular, sin una herramienta global aparte, use `@igniteui/angular-schematics` directamente con Angular CLI. No es necesaria ninguna de las dos herramientas para usar Ignite UI for Angular: la biblioteca puede instalarse y configurarse manualmente, como se describe en la [guía de primeros pasos](./getting-started.mdx).

## Ignite UI CLI

[Ignite UI CLI](https://github.com/IgniteUI/igniteui-cli) es una herramienta de línea de comandos global e independiente para crear y generar la estructura de aplicaciones de Angular, React y jQuery. Instálela con `npm install -g igniteui-cli` y ejecútela con el comando `ig`.

La CLI proporciona un asistente guiado (`ig` o `ig new`) y la creación de proyectos no interactiva (`ig new <name> --framework=angular --type=igx-ts`), la generación de estructura de componentes (`ig add`), un servidor de desarrollo (`ig start`) y un servidor MCP integrado para la integración con asistentes de IA (`ig mcp`).

Para las instrucciones de configuración y todos los comandos disponibles, consulte [Primeros pasos con Ignite UI CLI](./cli/getting-started-with-cli.mdx).

## Ignite UI for Angular Schematics

[Ignite UI for Angular Schematics](https://github.com/IgniteUI/igniteui-cli/tree/master/packages/ng-schematics) es una colección de schematics que se integra en Angular CLI. La colección se añade a su proyecto automáticamente cuando ejecuta `ng add igniteui-angular`. Invóquela con `ng new --collection="@igniteui/angular-schematics"` para crear el proyecto y con `ng g @igniteui/angular-schematics:component` para generar la estructura de componentes.

La colección de Schematics proporciona las mismas plantillas de proyecto básicas y vistas de componentes que la CLI, dentro del flujo de trabajo nativo de Angular CLI. No incluye el servidor MCP: para la integración con asistentes de IA, use Ignite UI CLI junto con su proyecto de Angular CLI.

Para las instrucciones de configuración, consulte [Primeros pasos con Ignite UI for Angular Schematics](./cli/getting-started-with-angular-schematics.mdx).

## Integración con asistentes de IA (MCP)

Ignite UI CLI incluye un servidor MCP (Model Context Protocol) integrado que conecta los asistentes de programación con IA (GitHub Copilot, Claude, Cursor y otros) con la documentación de componentes de Ignite UI en tiempo real y las referencias de API. Una vez configurado, su asistente de IA puede consultar las API de los componentes, obtener guías de configuración y generar código preciso de Ignite UI for Angular sin salir de su editor.

Inicie el servidor MCP con:

```cmd
ig mcp
```

Para la configuración de clientes (VS Code, Claude Desktop, Cursor) y la descripción de las herramientas disponibles, consulte [Ignite UI CLI MCP](../ai/cli-mcp.mdx).
