# Primeros pasos con Ignite UI for Angular

[`Ignite UI for Angular`](https://github.com/IgniteUI/igniteui-angular) es una biblioteca de más de 100 componentes de interfaz empresariales, como grids de datos, gráficos, editores, controles de navegación y contenedores de disposición, distribuida por Infragistics como el paquete npm `igniteui-angular`. Esta guía recorre tres vías de instalación (Ignite UI CLI, Angular Schematics y Angular CLI con `ng add`) y termina con un `IgxGridComponent` funcional renderizado a partir de datos locales.

Ignite UI for Angular está pensado para Angular 17 y versiones posteriores, con los componentes standalone como modelo de arranque predeterminado. No admite de forma nativa Vue, React ni Web Components; para esos frameworks consulte [Ignite UI for React](https://www.infragistics.com/products/ignite-ui-react), [Ignite UI for Web Components](https://www.infragistics.com/products/ignite-ui-web-components) e [Ignite UI for Blazor](https://www.infragistics.com/products/ignite-ui-blazor).

Ignite UI for Angular se ofrece con un modelo de doble licencia: algunos componentes son de código abierto con licencia MIT y otros requieren una licencia comercial. Para más detalles consulte [Licencias de Ignite UI](./ignite-ui-licensing.mdx) y [Código abierto frente a Premium](./open-source-vs-premium.mdx).

## Requisitos previos

- Node.js 20 LTS o posterior (se recomienda Node.js 22 LTS)
- npm 10 o posterior (incluido con Node.js 20), yarn o pnpm
- Angular CLI 17 o posterior para la vía de instalación `ng add`
- Visual Studio Code o cualquier editor con soporte para TypeScript

## Instalar Ignite UI for Angular

Ignite UI for Angular admite tres vías de instalación. Use Ignite UI CLI o Angular Schematics al empezar un proyecto nuevo desde cero. Use `ng add` cuando añada Ignite UI for Angular a un espacio de trabajo Angular existente.

### Instalar con Ignite UI CLI

Ignite UI CLI es una herramienta de línea de comandos independiente que genera un proyecto Angular totalmente configurado con Ignite UI for Angular en un único comando. Instálela de forma global:

```cmd
npm install -g igniteui-cli
```

Active el asistente guiado de proyecto:

```cmd
ig
```

O cree un proyecto sin interacción:

```cmd
ig new <project-name> --framework=angular --type=igx-ts --template=side-nav
```

<DocsAside type="info">
Desde Ignite UI CLI v13.1.0, el tipo de proyecto `igx-ts` genera un proyecto que usa componentes standalone de forma predeterminada. Para usar en su lugar el arranque basado en NgModule, establezca `--type=igx-ts-legacy`.
</DocsAside>

<DocsAside type="info">
En algún momento del proceso es posible que se le pida que [inicie sesión en el registro npm de Infragistics](./ignite-ui-licensing.mdx#cómo-configurar-su-entorno-para-usar-el-feed-npm-privado-guía-paso-a-paso) si aún no está configurado. Esto se aplica cuando se usan componentes con una [licencia comercial](./open-source-vs-premium.mdx#tabla-comparativa-de-todos-los-componentes).
</DocsAside>

Para un recorrido completo por todas las opciones de la CLI y las plantillas de proyecto, consulte [Primeros pasos con Ignite UI CLI](./cli/getting-started-with-cli.mdx) y [Angular Schematics e Ignite UI CLI](./cli-overview.mdx).

### Instalar con Angular Schematics

La colección Ignite UI for Angular Schematics se integra en el flujo de trabajo de Angular CLI y ofrece la misma experiencia guiada que la CLI independiente, sin necesidad de una herramienta global aparte:

```cmd
npm i -g @igniteui/angular-schematics
```

Active el asistente guiado:

```cmd
ng new --collection="@igniteui/angular-schematics"
```

Para un recorrido paso a paso, consulte [Guía paso a paso para usar Ignite UI for Angular Schematics](./cli/step-by-step-guide-using-angular-schematics.mdx).

### Instalar con Angular CLI (`ng add`)

Si ya tiene un proyecto Angular o prefiere trabajar íntegramente con Angular CLI, use `ng add` para instalar y configurar Ignite UI for Angular. Si hace falta, cree antes una aplicación Angular nueva:

```cmd
ng new <project-name> --style=scss
```

Se recomienda SCSS porque la [biblioteca de temas de Ignite UI for Angular](../themes/sass/index.mdx) se basa en él y `ng add` configura el tema predeterminado automáticamente. Después, añada Ignite UI for Angular:

```cmd
ng add igniteui-angular
```

<DocsAside type="info">
`ng add` instala la versión de prueba de `igniteui-angular`. Si su proyecto se generó con Ignite UI CLI, omita este paso, ya que la CLI ya se encarga de la configuración de los paquetes. Para cambiar más adelante al paquete con licencia, consulte [Actualizar de prueba a licenciado](#actualizar-de-prueba-a-licenciado) más abajo.
</DocsAside>

#### Paquetes adicionales

Algunos componentes de Ignite UI for Angular se distribuyen como paquetes npm independientes y se añaden por separado:

**[Grid Lite](../grid-lite/overview.mdx): código abierto (MIT)**

Un grid ligero para proyectos que necesitan mostrar datos básicos sin el conjunto completo de funciones comerciales. Su API es compatible con `IgxGrid`, por lo que actualizar más adelante requiere cambios mínimos.

```cmd
ng add igniteui-grid-lite
```

**[Dock Manager](../dock-manager.mdx): premium**

Un componente de disposición basado en paneles, en el que los usuarios finales pueden anclar, redimensionar, mover y ocultar paneles en tiempo de ejecución.

```cmd
ng add igniteui-dockmanager
```

## Añadir componentes con CLI o Schematics

Después de la configuración inicial del proyecto, añada vistas de componentes de Ignite UI for Angular con el schematic `component` o con el comando `add`:

```cmd
ng g @igniteui/angular-schematics:component
```

```cmd
ig add
```

<DocsAside type="info">
El comando `ig add` está disponible en los proyectos creados con Ignite UI CLI o en los proyectos de Angular CLI en los que Ignite UI for Angular se añadió con `ng add igniteui-angular`.
</DocsAside>

## Añadir componentes manualmente (standalone)

Desde Angular 19, los componentes standalone son el modelo de arranque predeterminado. El ejemplo siguiente añade un `IgxGridComponent` a una aplicación Angular standalone sin usar Schematics ni la CLI.

Algunos componentes usan animaciones, que requieren un proveedor en la llamada a `bootstrapApplication`. Configúrelo en `app.config.ts`:

```typescript
// app/app.config.ts
import { ApplicationConfig, importProvidersFrom } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { provideAnimations } from '@angular/platform-browser/animations';
import { Provider } from '@angular/core';

const providers: Provider[] = [
  importProvidersFrom(BrowserModule),
  provideAnimations()
];

export const appConfig: ApplicationConfig = { providers };
```

### Importar y usar el Grid

Importe `IgxGridComponent` y `IgxColumnComponent` directamente en su componente standalone. Como se trata de un componente standalone, añada ambos al array `imports` en lugar de a un `NgModule`:

```typescript
// app.component.ts
import { Component } from '@angular/core';
import { IgxGridComponent, IgxColumnComponent } from 'igniteui-angular';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styleUrls: ['./app.component.css'],
  imports: [IgxGridComponent, IgxColumnComponent]
})
export class AppComponent {
  localData = [
    { Name: 'John', Age: 29 },
    { Name: 'Alice', Age: 27 },
    { Name: 'Jessica', Age: 31 },
  ];
}
```

Añada el grid a la plantilla del componente, enlazando `[data]` al array local y definiendo las columnas explícitamente:

```html
<!-- app.component.html -->
<igx-grid [data]="localData" width="600px" height="400px" [allowFiltering]="true">
  <igx-column field="Name" dataType="string"></igx-column>
  <igx-column field="Age" dataType="number"></igx-column>
</igx-grid>
```

Esto renderiza un Grid de Ignite UI for Angular con el filtrado de columnas habilitado, que muestra tres filas de datos locales.

### Ejecutar la aplicación

Ejecute la aplicación con el comando correspondiente a su configuración:

```cmd
ig start
```

O, en proyectos creados con Angular CLI:

```cmd
ng serve
```

## Actualizar de prueba a licenciado

Para cambiar del paquete de prueba `igniteui-angular` a la versión con licencia, ejecute el schematic de actualización en la raíz del proyecto:

```bash
ng g @igniteui/angular-schematics:upgrade-packages
```

O, con Ignite UI CLI:

```bash
ig upgrade-packages
```

El schematic actualiza las dependencias de los paquetes y sustituye las referencias en el código fuente. Se le pedirá que [inicie sesión en el registro npm privado de Infragistics](./ignite-ui-licensing.mdx#cómo-configurar-su-entorno-para-usar-el-feed-npm-privado-guía-paso-a-paso) si aún no está configurado.

## Desarrollo asistido por IA

Ignite UI for Angular incluye dos herramientas para el desarrollo asistido por IA.

**Agent Skills** son archivos de conocimiento estructurado que enseñan a los asistentes de programación con IA (GitHub Copilot, Cursor, Windsurf, Claude, JetBrains AI) a trabajar correctamente con los componentes, las API y los patrones de temas de Ignite UI. Las skills cubren grids de datos, operaciones de grid, gráficos y temas. Consulte [Skills de Ignite UI for Angular](../ai/skills.mdx).

**El servidor MCP de Ignite UI** es un servidor integrado en Ignite UI CLI que conecta los asistentes de IA con la documentación actualizada de los componentes de Ignite UI y con las referencias de la API directamente dentro de su editor. A diferencia de las skills estáticas, el servidor MCP responde consultas sobre las API actuales, recupera guías de configuración bajo demanda y permite generar código preciso para los componentes de Ignite UI. Inícielo con `ig mcp` después de instalar la CLI. Para la configuración del cliente y las herramientas disponibles, consulte [Información general de Ignite UI CLI MCP](../ai/cli-mcp.mdx).
