# Dock Manager

El componente Dock Manager de Ignite UI ofrece los medios para gestionar la disposición de su aplicación mediante paneles, lo que permite a sus usuarios finales personalizarla aún más fijando, redimensionando, moviendo y ocultando paneles.

## Uso

Dock Manager es un [web component](https://developer.mozilla.org/en-US/docs/Web/Web_Components) estándar y, como tal, se puede usar en una aplicación Angular.

Siga los pasos siguientes para añadir el paquete de Dock Manager a su proyecto de Angular y configurarlo para usar el componente.

En primer lugar, instale el paquete `igniteui-dockmanager`

```cmd
npm install igniteui-dockmanager
```

A continuación, incluya el esquema `CUSTOM_ELEMENTS_SCHEMA` en `AppModule`:

```typescript
import { CUSTOM_ELEMENTS_SCHEMA, NgModule } from '@angular/core';

@NgModule({
    ...
    schemas: [CUSTOM_ELEMENTS_SCHEMA]
})
export class AppModule {}
```

Después, hay que llamar a la función `defineComponents()` en el archivo `main.ts`:

```typescript
import { AppModule } from './app/app.module';
import { defineComponents } from 'igniteui-dockmanager';
import { enableProdMode } from '@angular/core';
import { environment } from '.environments/environment';
import { platformBrowserDynamic } from '@angular/platform-browser-dynamic';

if (environment.production) {
    enableProdMode();
}

platformBrowserDynamic().bootstrapModule(AppModule)
    .catch(err => console.log(err));

defineComponents(IgcDockManagerComponent);
```

Y listo: ya puede usar el componente Dock Manager en una plantilla de componente de Angular. Para ello, basta con usar su nombre de etiqueta:

```html
<igc-dockmanager>
</igc-dockmanager>
```

Para más información sobre el uso del componente Dock Manager, puede consultar [este tema]({environment:infragisticsBaseUrl}/products/ignite-ui-web-components/web-components/components/dock-manager.html).
