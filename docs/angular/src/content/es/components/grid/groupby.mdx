# Agrupación de Angular Grid

El comportamiento de agrupación en una tabla o cuadrícula de interfaz de Ignite UI for Angular crea filas de datos agrupadas a partir de los valores de las columnas. La agrupación en <ApiLink type="Grid" /> permite visualizar los grupos en una estructura jerárquica. Las filas de datos agrupadas pueden expandirse o contraerse, y el orden de agrupación puede cambiarse mediante la interfaz o la API. Cuando la selección de filas está habilitada, se muestra un selector de fila de agrupación en el área más a la izquierda de la fila del grupo. Si la propiedad <ApiLink type="Grid" member="rowSelection" /> está establecida en single, las casillas se desactivan y solo sirven como indicación del grupo donde se coloca la selección. Si la propiedad <ApiLink type="Grid" member="rowSelection" /> está establecida en multiple, al hacer clic en el selector de fila de agrupación se seleccionan todos los registros que pertenecen a ese grupo.

## Ejemplo de agrupación de Angular Grid

Este ejemplo presenta las capacidades de agrupación de una gran cantidad de datos. Al arrastrar los encabezados de columna hasta la parte superior (área de agrupación), los usuarios pueden ver los datos de la columna seleccionada en una estructura jerárquica. Pueden agrupar por varios campos arrastrando más encabezados de columna a la parte superior. Estas opciones de agrupación resultan útiles cuando tiene tablas con muchas filas y columnas y los usuarios quieren presentar los datos de una forma mucho más rápida y visualmente aceptable.

## Estado de agrupación inicial

Es posible definir la agrupación inicial de la cuadrícula asignando un array de expresiones a la propiedad <ApiLink type="Grid" member="groupingExpressions" /> de la cuadrícula.

```typescript
public ngOnInit() {
    grid.groupingExpressions = [
        { fieldName: 'ProductName', dir: SortingDirection.Desc },
        { fieldName: 'Released', dir: SortingDirection.Desc }
    ];
}
```

Las expresiones de agrupación implementan la interfaz <ApiLink kind="interface" type="ISortingExpression" />.

## API de agrupación

### API de agrupación

La agrupación está disponible a través de la interfaz y de una API completa que expone el componente de cuadrícula. Los desarrolladores pueden permitir que los usuarios finales agrupen los datos de la cuadrícula por determinadas columnas, estableciendo la propiedad <ApiLink type="Column" member="groupable" /> de cada columna en `true`.

```html
<igx-grid [data]="data">
    <igx-column *ngFor="let c of columns" [field]="c.field" [groupable]="true">
    </igx-column>
</igx-grid>
```

```typescript
public ngOnInit() {
    grid.columns.forEach((column) => {
        column.groupable = true;
    });
}
```

Durante la ejecución, las expresiones pueden leerse y establecerse desde la propiedad <ApiLink type="Grid" member="groupingExpressions" />. Si necesita añadir o cambiar una expresión existente, también puede usar el método <ApiLink type="Grid" member="groupby" /> con una sola <ApiLink kind="interface" type="ISortingExpression" /> o con un array de ellas.

```typescript
grid.groupBy({ fieldName: 'ProductName', dir: SortingDirection.Desc, ignoreCase: true });
```

<DocsAside type="info">
Hasta ahora, la agrupación y la ordenación funcionaban conjuntamente. En la versión 13.2 se introduce un nuevo comportamiento que desacopla la agrupación de la ordenación. Por ejemplo, borrar la agrupación no borrará las expresiones de ordenación de la cuadrícula, o viceversa. Aun así, si una columna está ordenada y agrupada a la vez, las expresiones de agrupación tienen prioridad.
</DocsAside>

### API de expandir/contraer

Además de las expresiones de agrupación, también puede controlar los estados de expansión de las filas de grupo. Se almacenan en una propiedad independiente del componente <ApiLink type="Grid" />, <ApiLink type="Grid" member="groupingExpansionState" />. Una fila de grupo se identifica de forma única por el nombre del campo para el que se creó y por el valor que representa en cada nivel de agrupación. Esto significa que la firma de la interfaz de estado de expansión es la siguiente:

```typescript
export interface IGroupByKey {
    fieldName: string;
    value: any;
}

export interface IGroupByExpandState {
    hierarchy: Array<IGroupByKey>;
    expanded: boolean;
}
```

Al igual que con <ApiLink type="Grid" member="groupingExpressions" />, establecer una lista de <ApiLink kind="interface" type="IGroupByExpandState" /> directamente en <ApiLink type="Grid" member="groupingExpansionState" /> cambiará la expansión en consecuencia. Además, <ApiLink type="Grid" /> expone un método que alterna un grupo a partir de la instancia del registro de grupo.

```typescript
    const groupRow = this.grid.groupsRecords.find(r => r.value === "France");
    const groupRow = this.grid.getRowByIndex(0).groupRow;
    grid.toggleGroup(groupRow);
    groupRow.expanded = false;
```

Los grupos pueden crearse expandidos (_**predeterminado**_) o contraídos, y los estados de expansión normalmente solo contendrán el estado contrario al comportamiento predeterminado. Puede controlar si los grupos deben crearse expandidos o no mediante la propiedad <ApiLink type="Grid" member="groupsExpanded" />.

### API para seleccionar/deseleccionar todas las filas de un grupo

La selección o deselección de todas las filas de un grupo está disponible mediante los métodos de la API <ApiLink type="Grid" member="selectRowsInGroup" /> y <ApiLink type="Grid" member="deselectRowsInGroup" />.

El fragmento de código siguiente puede usarse para seleccionar todas las filas de un grupo mediante el método <ApiLink type="Grid" member="selectRowsInGroup" /> de la instancia del registro de grupo. Además, el segundo parámetro de este método es una propiedad booleana con la que puede elegir si la selección de filas anterior se borra o no. Por defecto, la selección anterior se conserva.

```typescript
    const groupRow = this.grid.groupsRecords.find(r => r.value === "France");
    const groupRow = this.grid.getRowByIndex(0).groupRow;
    grid.selectRowsInGroup(groupRow);
```

Si necesita deseleccionar mediante programación todas las filas de un grupo, puede usar el método <ApiLink type="Grid" member="deselectRowsInGroup" />.

```typescript
    const groupRow = this.grid.groupsRecords.find(r => r.value === "France");
    const groupRow = this.grid.getRowByIndex(0).groupRow;
    grid.deselectRowsInGroup(groupRow);
```

## Plantillas

### Plantillas de filas de grupo

La fila de grupo, salvo la interfaz de expandir/contraer, es totalmente personalizable con plantillas. De forma predeterminada, muestra un icono de agrupación y el nombre del campo y el valor que representa. El registro de agrupación con el que se renderiza la plantilla tiene la siguiente firma:

```typescript
export interface IGroupByRecord {
    expression: ISortingExpression;
    level: number;
    records: GroupedRecords;
    value: any;
    groupParent: IGroupByRecord;
    groups?: IGroupByRecord[];
}
```

Como ejemplo, la siguiente plantilla haría más detallado el resumen de las filas de grupo:

```html
<ng-template igxGroupByRow let-groupRow>
    <span>Total items with value: {{ groupRow.value }} are {{ groupRow.records.length }}</span>
</ng-template>
```

### Plantillas del selector de filas de grupo

Como se ha mencionado, la fila de grupo, salvo la interfaz de expandir/contraer, es totalmente personalizable con plantillas. Para crear una plantilla personalizada del selector de fila de agrupación dentro de la cuadrícula, declare un `<ng-template>` con la directiva `igxGroupByRowSelector`. Desde la plantilla puede acceder a la variable de contexto proporcionada implícitamente, con propiedades que le dan información sobre el estado de la fila de agrupación.

La propiedad `selectedCount` indica cuántos de los registros del grupo están seleccionados actualmente, mientras que `totalCount` indica cuántos registros pertenecen al grupo.

```html
<ng-template igxGroupByRowSelector let-groupByRowContext>
    {{ groupByRowContext.selectedCount }} / {{ groupByRowContext.totalCount  }}
</ng-template>
```

La propiedad `groupRow` devuelve una referencia a la fila de grupo.

```html
<ng-template igxGroupByRowSelector let-groupByRowContext>
    <div (click)="handleGroupByRowSelectorClick($event, groupByRowContext.groupRow)">Handle groupRow</div>
</ng-template>
```

Las propiedades `selectedCount` y `totalCount` pueden usarse para determinar si el selector de fila de agrupación debe aparecer marcado o indeterminado (parcialmente seleccionado).

```html
<igx-grid #grid [data]="gridData" primaryKey="ProductID" rowSelection="multiple">
    <!-- ... -->
    <ng-template igxGroupByRowSelector let-context>
        <igx-checkbox
            [checked]=" context.selectedCount > 0 && context.selectedCount === context.totalCount"
            [indeterminate]="context.selectedCount > 0 && context.selectedCount !== context.totalCount">
        </igx-checkbox>
    </ng-template>
</igx-grid>
```

## Agrupación de Angular Grid con paginación

Las filas de grupo participan en el proceso de paginación junto con las filas de datos. Cuentan para el tamaño de página de cada página. Las filas contraídas no se incluyen en el proceso de paginación. Cualquier operación de expandir o contraer obliga a la paginación a recalcular el número de páginas y, si es necesario, ajustar el índice de página.
Los grupos que abarcan varias páginas se dividen entre ellas. La fila de grupo solo es visible en la página en la que empieza y no se repite en las páginas siguientes. La información de resumen de las filas de grupo se calcula sobre todo el grupo y no se ve afectada por la paginación.

## Navegación por teclado

La interfaz de agrupación admite las siguientes interacciones con el teclado:

- Para las filas de grupo (el foco debe estar en la fila o en la celda de expandir/contraer)
  - <kbd>ALT</kbd> + <kbd>RIGHT</kbd>: expande el grupo
  - <kbd>ALT</kbd> + <kbd>LEFT</kbd>: contrae el grupo
  - <kbd>SPACE</kbd>: selecciona todas las filas del grupo, si la propiedad <kbd>rowSelection</kbd> está establecida en multiple

- Para los componentes de grupo <ApiLink type="Chip" /> en el área de agrupación (el foco debe estar en el chip)
  - <kbd>SHIFT</kbd> + <kbd>LEFT</kbd>: mueve el chip enfocado a la izquierda, cambiando el orden de agrupación, si es posible
  - <kbd>SHIFT</kbd> + <kbd>RIGHT</kbd>: mueve el chip enfocado a la derecha, cambiando el orden de agrupación, si es posible
  - <kbd>SPACE</kbd>: cambia la dirección de la ordenación
  - <kbd>DELETE</kbd>: desagrupa el campo
  - Los elementos independientes del chip también pueden recibir el foco y se puede interactuar con ellos usando la tecla <kbd>ENTER</kbd>.

## Agrupación personalizada de Angular Grid

igxGrid permite definir una agrupación personalizada por columna o por expresión de agrupación, lo que proporciona agrupación basada en una condición personalizada. Es útil cuando necesita agrupar por objetos complejos u otros escenarios específicos de la aplicación.

<DocsAside type="info">
Para implementar la agrupación personalizada, primero hay que ordenar los datos de forma adecuada. Por ello, puede que también necesite aplicar una estrategia de ordenación personalizada que extienda la clase base <ApiLink type="DefaultSortingStrategy" />. Una vez ordenados los datos, los grupos personalizados pueden determinarse especificando un <ApiLink kind="interface" type="IGroupingExpression" member="groupingComparer" /> para la columna o para la expresión de agrupación concreta.
</DocsAside>

El siguiente ejemplo muestra la agrupación personalizada por `Date`, donde los valores de fecha se ordenan y agrupan por día, semana, mes o año según el modo de agrupación que seleccione el usuario.

### Ejemplo de agrupación personalizada de Angular


<Sample src="/grid/grid-groupby-custom" height={605} alt="Ejemplo de agrupación personalizada de Angular" />


El ejemplo define estrategias de ordenación personalizadas para las distintas condiciones de fecha.
Cada estrategia personalizada extiende la clase base <ApiLink type="DefaultSortingStrategy" /> y define el método <ApiLink type="DefaultSortingStrategy" member="compareValues" />, que es la función de comparación personalizada que se usa al ordenar los valores. Además, extrae de la fecha los valores necesarios para la comparación.

```typescript
class BaseSortingStrategy extends DefaultSortingStrategy {

    public getParsedDate(date: any) {
        return {
            day: date.getDay(),
            month: date.getMonth() + 1,
            year: date.getFullYear()
        };
    }

    compareValues(a: any, b: any) {
        const dateA = this.getParsedDate(a);
        const dateB = this.getParsedDate(b);
        return dateA.year < dateB.year ?
            -1 : dateA.year > dateB.year ?
            1 : dateA.month  < dateB.month ?
            -1 : dateA.month > dateB.month ?
            1 : 0;
    }
}

class DaySortingStrategy extends BaseSortingStrategy {
    compareValues(a: any, b: any) {
        const dateA = this.getParsedDate(a);
        const dateB = this.getParsedDate(b);
        return dateA.year < dateB.year ?
            -1 : dateA.year > dateB.year ?
            1 : dateA.month  < dateB.month ?
            -1 : dateA.month > dateB.month ?
            1 : dateA.day < dateB.day ?
            -1 : dateA.day > dateB.day ?
            1 : 0;
    }
}

class WeekSortingStrategy extends BaseSortingStrategy {

    public getWeekOfDate(a: any) {
       return parseInt(new DatePipe("en-US").transform(a, 'w'), 10);
    }

    compareValues(a: any, b: any) {
        const dateA = this.getParsedDate(a);
        const dateB = this.getParsedDate(b);
        const weekA = this.getWeekOfDate(a);
        const weekB = this.getWeekOfDate(b);
        return dateA.year < dateB.year ?
            -1 : dateA.year > dateB.year ?
            1 : weekA < weekB ?
            -1 : weekA > weekB ?
            1 : 0;
    }
}
```

Para las expresiones de agrupación se define una función <ApiLink kind="interface" type="IGroupingExpression" member="groupingComparer" />, que determina los elementos que pertenecen al mismo grupo según el modo de agrupación seleccionado. Los valores de los datos ordenados para los que esta función devuelve 0 se marcan como parte del mismo grupo.

```typescript
 groupingComparer: (a, b) => {
    const dateA = this.sortingStrategy.getParsedDate(a);
    const dateB = this.sortingStrategy.getParsedDate(b);
    if (this.groupByMode === 'Month') {
        return dateA.month === dateB.month ? 0 : -1;
    } else if (this.groupByMode === "Year") {
        return dateA.year === dateB.year ? 0 : -1;
    } else if (this.groupByMode === "Week") {
        return this.sortingStrategy.getWeekOfDate(a) === this.sortingStrategy.getWeekOfDate(b) ? 0 : -1;
    }
    return dateA.day === dateB.day && dateA.month === dateB.month ? 0 : -1;
}
```

A partir de la versión 15.1.0, también puede usar la estrategia de ordenación integrada `GroupMemberCountSortingStrategy` para ordenar los elementos según el número de miembros.

```typescript
public sortByGroup() {
        const expressions = this.grid1.groupingExpressions;
        if (expressions.length) {
            const fieldName = expressions[0].fieldName;
            const dir = expressions[0].dir === SortingDirection.Asc ? SortingDirection.Desc : SortingDirection.Asc;
            this.grid1.groupBy({ fieldName, dir, ignoreCase: false, strategy: GroupMemberCountSortingStrategy.instance() });
        }
    }
```

## Estilos

igxGrid permite dar estilo mediante [`Ignite UI for Angular Theme Library`](/themes/sass/component-themes). La <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> de la cuadrícula expone una gran variedad de propiedades que permiten personalizar todas las funciones de la cuadrícula.

En los pasos siguientes vamos a personalizar el estilo de la agrupación de la cuadrícula.

### Importar el tema global

Para empezar a personalizar la función de agrupación, debe importar el archivo `index`, donde se encuentran todas las funciones de estilo y los mixins.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### Definir un tema personalizado

A continuación, cree un tema nuevo que extienda <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> y acepte los parámetros necesarios para personalizar la agrupación como desee. También tiene que extender <ApiLink kind="sass" module="themes" type="function-chip-theme" label="chip-theme" code={true} />, porque se usa en la función de agrupación.

```scss

$custom-theme: grid-theme(
  $group-row-background: #494949,
  $group-row-selected-background: #383838,
  $group-label-column-name-text: #f8f8f8,
  $group-label-icon: #ffcd0f,
  $group-label-text: #f8f8f8,
  $group-count-background: #ffcd0f,
  $group-count-text-color: #000,
  $expand-icon-color: #ffcd0f,
  $expand-icon-hover-color: rgb(223, 181, 13),
  $cell-active-border-color: #ffcd0f,
  $row-selected-background: #fff6d3,
  $row-selected-text-color: #000,
  $drop-indicator-color: #ffcd0f
);

/* Chip theme will style the chips in the Group By area */
$custom-chips-theme: chip-theme(
  $background: #494949,
  $text-color: #f8f8f8,
  $hover-text-color: #e7e7e7
);
```

### Definir una paleta de colores personalizada

En el enfoque que describimos antes, los valores de color estaban codificados. Como alternativa, puede lograr mayor flexibilidad usando las funciones <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> y <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />.
`palette` genera una paleta de colores a partir de los colores primario, secundario y de superficie proporcionados.  

```scss
$black-color: #292826;
$yellow-color: #ffcd0f;
$grey-color: #efefef;

$custom-palette: palette(
  $primary: $black-color, 
  $secondary: $yellow-color, 
  $surface: $grey-color
);
```

Después de generar una paleta personalizada, la función `color` puede usarse para obtener distintas variantes de los colores primario y secundario.
  
```scss
$custom-theme: grid-theme(
  $group-row-background: color($custom-palette, "primary", 300),
  $group-row-selected-background: color($custom-palette, "primary", 400),
  $group-label-column-name-text:contrast-color($custom-palette, "primary", 500),
  $group-label-icon: color($custom-palette, "secondary", 600),
  $group-label-text:contrast-color($custom-palette, "primary", 500),
  $group-count-background: color($custom-palette, "secondary", 600),
  $group-count-text-color: color($custom-palette, "primary", 400),
  $expand-icon-color: color($custom-palette, "secondary", 600),
  $expand-icon-hover-color: color($custom-palette, "secondary", 300),
  $cell-active-border-color: color($custom-palette, "secondary", 600)
);

$custom-chips-theme: chip-theme(
  $background: color($custom-palette, "primary", 300),
  $text-color:contrast-color($custom-palette, "primary", 500),
  $hover-text-color:contrast-color($custom-palette, "primary", 600)
);
```

### Definir esquemas personalizados

Puede ir aún más allá y construir una estructura flexible que tenga todas las ventajas de un [**esquema**](/themes/sass/schemas). El **esquema** es la receta de un tema.
Extienda uno de los dos esquemas predefinidos que se proporcionan para cada componente. En nuestro caso, usaríamos <ApiLink kind="sass" module="schemas" type="variable-light-material-schema" label="light-grid" code={true} />.

```scss
$custom-grid-schema: extend(
  map.get('grid', $light-material-schema),
  (
    group-row-background: (color:('secondary', 100)),
    group-row-selected-background: (color:('primary', 400)),
    group-label-column-name-text: (color:('primary', 600)),
    group-label-icon: (color:('primary', 600)),
    group-label-text: (color:('secondary', 700)),
    group-count-background: (color:('primary', 600)),
    group-count-text-color: (color:('secondary', 400)),
    expand-icon-color: (color:('primary', 600)),
    expand-icon-hover-color: (color:('primary', 400))
  )
);
```

Para que se aplique el esquema personalizado, hay que extender los globales (<ApiLink kind="sass" module="schemas" type="variable-light-material-schema" label="light" code={true} /> o <ApiLink kind="sass" module="schemas" type="variable-dark-material-schema" label="dark" code={true} />). Todo el proceso consiste en proporcionar a un componente un esquema personalizado y añadirlo después al tema de componente correspondiente.

```scss
$my-custom-schema: extend(
  $light-material-schema, 
  ( 
    grid: $custom-grid-schema
  )
);

$custom-theme: grid-theme(
  $palette: $custom-palette,
  $schema: $my-custom-schema
);
```

### Aplicar el tema personalizado

La forma más sencilla de aplicar su tema es con una sentencia `sass` `@include` en el archivo de estilos global:

```scss
:host {
  @include tokens($custom-theme);
  @include tokens($custom-chips-theme);
}
```

### Tema de componente con ámbito

Para que el tema personalizado afecte solo a un componente concreto, puede mover todos los estilos que acaba de definir del archivo de estilos global al archivo de estilos del componente personalizado (incluida la importación del archivo `index`).

De este modo, gracias al [ViewEncapsulation](https://angular.io/api/core/Component#encapsulation) de Angular, sus estilos se aplicarán solo a su componente personalizado.

Según dónde se rendericen los chips agrupados, el encapsulado de vista emulado puede impedir que coincidan sus declaraciones de tokens. Si el tema del chip no surte efecto, use `::ng-deep` para ese tema anidado o trasládelo a una hoja de estilos global:

```scss
:host {
  @include tokens($custom-theme);

  ::ng-deep {
    @include tokens($custom-chips-theme);
  }
}
```
