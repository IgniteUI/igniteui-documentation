# Descripción general del componente Angular Bottom Navigation

<div class="highlight">
El componente Bottom Navigation de Ignite UI for Angular permite al usuario desplazarse entre varios paneles de contenido mostrados en una única vista. La navegación entre paneles se realiza con los botones de pestaña situados en la parte inferior de su aplicación.
</div>

<DocsAside type="info">
El selector `igx-tab-bar` está obsoleto. Puede usar <ApiLink type="BottomNav" label="igx-bottom-nav" /> en su lugar. La clase `IgxTabBarComponent` se ha renombrado a <ApiLink type="BottomNav" />. `IgxTabBarModule` se ha renombrado a `IgxBottomNavModule`.
</DocsAside>

## Primeros pasos con Ignite UI for Angular Bottom Navigation

Para empezar con el componente Ignite UI for Angular Bottom Navigation, primero debe instalar Ignite UI for Angular. En una aplicación Angular existente, escriba el siguiente comando:

```cmd
ng add igniteui-angular
```

Para una introducción completa a Ignite UI for Angular, lea el tema [_primeros pasos_](./general/getting-started.mdx).

El siguiente paso es importar `IgxBottomNavModule` en el archivo **app.module.ts**.

```typescript
// app.module.ts

...
import { IgxBottomNavModule } from 'igniteui-angular/bottom-nav';
// import { IgxBottomNavModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxBottomNavModule],
    ...
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` puede importar `IgxBottomNavComponent` como dependencia independiente, o usar el token [`IGX_BOTTOM_NAV_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/bottom-nav/src/bottom-nav/public_api.ts) para importar el componente y todos sus componentes y directivas de apoyo.

```typescript
// home.component.ts

import { IGX_BOTTOM_NAV_DIRECTIVES } from 'igniteui-angular/bottom-nav';
import { IgxIconComponent } from 'igniteui-angular/icon';
// import { IGX_BOTTOM_NAV_DIRECTIVES, IgxIconComponent } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-bottom-nav>
        <igx-bottom-nav-item>
            <igx-bottom-nav-header>
                <igx-icon>library_music</igx-icon>
            </igx-bottom-nav-header>
            <igx-bottom-nav-content>This is Item 1 content.</igx-bottom-nav-content>
        </igx-bottom-nav-item>
        <igx-bottom-nav-item>
            <igx-bottom-nav-header>
                <igx-icon>video_library</igx-icon>
            </igx-bottom-nav-header>
            <igx-bottom-nav-content>This is Item 2 content.</igx-bottom-nav-content>
        </igx-bottom-nav-item>
        <igx-bottom-nav-item>
            <igx-bottom-nav-header>
                <igx-icon>library_books</igx-icon>
            </igx-bottom-nav-header>
            <igx-bottom-nav-content>This is Item 3 content.</igx-bottom-nav-content>
        </igx-bottom-nav-item>
    </igx-bottom-nav>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_BOTTOM_NAV_DIRECTIVES, IgxIconComponent]
    /* or imports: [IgxBottomNavComponent, IgxBottomNavItemComponent, IgxBottomNavHeaderComponent, IgxBottomNavContentComponent, IgxIconComponent] */
})
export class HomeComponent {}
```

Ahora que ha importado el módulo o las directivas de Ignite UI for Angular Bottom Navigation, puede empezar a usar el componente `igx-bottom-nav`.

## Uso de Angular Bottom Navigation

La plantilla de nuestro componente incluye la navegación inferior y tres elementos. Cada elemento envuelve un componente `igx-bottom-nav-header` y un componente `igx-bottom-nav-content`, que representan respectivamente el encabezado y el contenedor de los datos. Los encabezados suelen constar de un icono y una etiqueta de texto opcional. El control Bottom Navigation es compatible con los [**iconos**](https://material.io/icons/) de Material Design, así que, para adoptarlos en su aplicación, basta con añadir la importación de Material+Icons en el archivo 'styles.css' de la carpeta principal de la aplicación.

<DocsAside type="info">
Si hasta ahora no ha usado `igx-icon` en su aplicación, asegúrese de importar `IgxIconModule` en **app.module.ts** antes de continuar.
</DocsAside>

```css
// styles.css

...
@import url('https://fonts.googleapis.com/icon?family=Material+Icons');
...
```

```html
<igx-bottom-nav>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon>library_music</igx-icon>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>This is Item 1 content.</igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon>video_library</igx-icon>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>This is Item 2 content.</igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon>library_books</igx-icon>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>This is Item 3 content.</igx-bottom-nav-content>
    </igx-bottom-nav-item>
</igx-bottom-nav>
```

Si todo ha ido bien, debería ver la demostración en su navegador.

## Personalizar Bottom Navigation

Vamos a modificar las pestañas añadiendo etiquetas junto a los iconos y asegurándonos de que los encabezados tengan el estilo adecuado.

En primer lugar, defina algunos arrays de objetos para el origen de datos en el archivo TypeScript del componente:

```typescript
public songsList: object[] = [
    { title: 'Havana', artist: 'Camila Cabello' },
    { title: 'Meant To Be', artist: 'Bebe Rexha & Florida Georgia Line' },
    { title: 'New Rules', artist: 'Dua Lipa' },
    { title: 'Wolves', artist: 'Selena Gomez & Marshmello' }
];

public moviesList: object[] = [
    { title: 'Logan', genre: 'Action, Drama, Sci-Fi' },
    { title: 'Wonder Woman', genre: 'Action, Adventure, Fantasy' },
    { title: 'Guardians of the Galaxy Vol. 2', genre: 'Action, Adventure, Sci-Fi' },
    { title: 'Star Wars: The Last Jedi', genre: 'Action, Adventure, Fantasy' }
];

public booksList: object[] = [
    { title: 'Wonder', author: 'R. J. Palacio' },
    { title: 'Milk and Honey', author: 'Rupi Kaur' },
    { title: 'Giraffes Can\'t Dance', author: 'Jeff Kinne' },
    { title: 'The Getaway', author: 'Selena Gomez & Marshmello' }
];
```

A continuación, actualice el marcado de la plantilla del componente de la siguiente manera:

```html
<igx-bottom-nav>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon igxBottomNavHeaderIcon>library_music</igx-icon>
            <span igxBottomNavHeaderLabel>Songs</span>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>
            <div class="item" *ngFor="let song of songsList">
                <span class="item-line1">{{song.title}}</span><br/>
                <span class="item-line2">{{song.artist}}</span>
            
</div>
        </igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon igxBottomNavHeaderIcon>video_library</igx-icon>
            <span igxBottomNavHeaderLabel>Movies</span>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>
            <div class="item" *ngFor="let movie of moviesList">
                <span class="item-line1">{{movie.title}}</span><br/>
                <span class="item-line2">{{movie.genre}}</span>
            
</div>
        </igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon igxBottomNavHeaderIcon>library_books</igx-icon>
            <span igxBottomNavHeaderLabel>Books</span>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>
            <div class="item" *ngFor="let book of booksList">
                <span class="item-line1">{{book.title}}</span><br/>
                <span class="item-line2">{{book.author}}</span>
            
</div>
        </igx-bottom-nav-content>
    </igx-bottom-nav-item>
</igx-bottom-nav>
```

Probablemente haya notado que, además de colocar el icono y el span con la etiqueta entre las etiquetas del encabezado del elemento, también aplicamos a ellos las directivas `igxBottomNavHeaderIcon` y `igxBottomNavHeaderLabel`. Estas directivas denotan los elementos respectivos y les aplican los estilos adecuados.

Por último, añada al archivo CSS del componente las clases CSS usadas por los elementos DIV y SPAN de la plantilla del contenido:

```css
.item {
    margin-bottom: 5px;
}

.item-line1 {
    font-size: 14px;
    color: gray;
}

.item-line2 {
    font-size: 12px;
    color: darkgray;
}

igx-bottom-nav-content {
    padding: 10px;
}
```

## Integración con el contenedor router-outlet

Aunque el uso principal del componente Bottom Navigation es definir elementos de pestaña con contenido, puede haber casos en los que necesite definir elementos de pestaña solo con encabezados. Probablemente, el escenario principal de este uso es la navegación entre vistas mediante Angular Router. El siguiente ejemplo muestra cómo configurar el componente Bottom Navigation para cambiar entre tres componentes en un único router-outlet.

Para empezar necesitamos un componente principal que aloje el componente Bottom Navigation y tres componentes de vista con algo de contenido de demostración. Para simplificar los fragmentos de código, los componentes de vista tendrán una plantilla muy breve, pero puede hacerlos más distinguibles si lo necesita. Además, importe estos componentes de vista en su archivo `app.module.ts`.

```typescript
// bottomnav-routing.component.ts
import { Component } from '@angular/core';

@Component({
    selector: 'app-bottomnav-routing',
    styleUrls: ['bottomnav-routing.component.scss'],
    templateUrl: 'bottomnav-routing.component.html'
})
export class BottomNavRoutingComponent { }

@Component({
    template: '<p>Item 1 Content</p>'
})
export class BottomNavRoutingView1Component { }

@Component({
    template: '<p>Item 2 Content</p>'
})
export class BottomNavRoutingView2Component { }

@Component({
    template: '<p>Item 3 Content</p>'
})
export class BottomNavRoutingView3Component { }
```

El siguiente paso es crear las asignaciones de navegación adecuadas en el archivo `app-routing.module.ts`:

```typescript
import { RouterModule, Routes } from '@angular/router';

import {
    TabbarRoutingComponent,
    TabbarRoutingView1Component,
    TabbarRoutingView2Component,
    TabbarRoutingView3Component,
} from './tabbar-routing.component';

const routes: Routes = [
    {
        path: '',
        pathMatch: 'full',
        redirectTo: '/tabbar-routing'
    },
    {
        path: 'tabbar-routing',
        component: TabbarRoutingComponent,
        children: [
            { path: 'tabbar-view1', component: TabbarView1Component },
            { path: 'tabbar-view2', component: TabbarView2Component },
            { path: 'tabbar-view3', component: TabbarView3Component }
        ]
    }
];

@NgModule({
    exports: [ RouterModule ],
    imports: [ RouterModule.forChild(routes) ]
})
export class TabbarRoutingModule { }
```

Ahora que tenemos configuradas todas las rutas de navegación, tenemos que declarar el componente BottomNavigation y configurarlo para el enrutamiento.
Además, asegúrese de añadir un router-outlet para renderizar la salida de los componentes de vista.

```html
{/* bottomnav-routing.component.html */}
<router-outlet></router-outlet>

<igx-bottom-nav #tabs1>
    <igx-bottom-nav-item
        routerLinkActive
        #rla1="routerLinkActive"
        [selected]="rla1.isActive"
        >
        <igx-bottom-nav-header routerLink="tabbar-view1">
            <igx-icon igxBottomNavHeaderIcon>phone</igx-icon>
        </igx-bottom-nav-header>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item
        routerLinkActive
        #rla2="routerLinkActive"
        [selected]="rla2.isActive"
    >
        <igx-bottom-nav-header routerLink="tabbar-view2">
            <igx-icon igxBottomNavHeaderIcon>supervisor_account</igx-icon>
        </igx-bottom-nav-header>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item
        routerLinkActive
        #rla3="routerLinkActive"
        [selected]="rla3.isActive"
    >
        <igx-bottom-nav-header routerLink="tabbar-view3">
            <igx-icon igxBottomNavHeaderIcon>format_list_bulleted</igx-icon>
        </igx-bottom-nav-header>
    </igx-bottom-nav-item>
</igx-bottom-nav>
```

El código anterior crea un componente BottomNavigation con tres elementos de pestaña. A todos los elementos de pestaña se les aplica la directiva `RouterLinkActive`, que hace un seguimiento de si la ruta vinculada está activa actualmente. Tenga en cuenta que la directiva `RouterLink` se aplica al propio elemento de encabezado, no al elemento de pestaña. Si alguno de estos enlaces se activa, el elemento de pestaña correspondiente tendrá establecida su propiedad `selected`, gracias al enlace a la propiedad `isActive` de la directiva `RouterLinkActive`. De este modo, la pestaña seleccionada siempre permanecerá sincronizada con la dirección actual del navegador.

Para empezar a dar estilo a las pestañas, tenemos que importar el archivo `index`, donde se exportan todas las funciones de tema y el mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Siguiendo el enfoque más sencillo, creamos un tema nuevo que extiende <ApiLink kind="sass" module="themes" type="function-bottom-nav-theme" label="bottom-nav-theme" code={true} /> y acepta varios parámetros que nos permiten dar estilo a los grupos de pestañas.

```scss
$dark-bottom-nav: bottom-nav-theme(
  $background: #292826,
  $icon-selected-color: #f4d45c
);
```

<DocsAside type="info">
En lugar de codificar los valores de color como acabamos de hacer, podemos lograr más flexibilidad con los colores usando las funciones <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> y <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Consulte el tema [`Palettes`](./themes/sass/palettes.mdx) para obtener orientación detallada sobre cómo usarlas.
</DocsAside>

Si echamos un vistazo a <ApiLink kind="sass" module="themes" type="function-bottom-nav-theme" label="bottom-nav-theme" code={true} />, veremos que hay aún más parámetros disponibles para dar estilo a nuestro componente de navegación inferior.

<DocsAside type="info">
Para dar estilo a cualquier componente adicional que se use como parte del contenido de un elemento, debe crearse un tema adicional específico de ese componente.
</DocsAside>

El último paso es **incluir** el tema del componente en nuestra aplicación.

```scss
:host {
    @include tokens($dark-bottom-nav);
}
```

### Dar estilo con Tailwind

Puede dar estilo a la navegación inferior usando nuestras clases de utilidad personalizadas de Tailwind. Asegúrese de [configurar Tailwind](./themes/tailwind.mdx) primero.

Junto con la importación de Tailwind en su hoja de estilos global, puede aplicar las utilidades de tema deseadas de la siguiente manera:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

El archivo de utilidades incluye las variantes de tema `light` y `dark`.

- Use las clases `light-*` para el tema claro.
- Use las clases `dark-*` para el tema oscuro.
- Añada el nombre del componente después del prefijo, por ejemplo, `light-bottom-nav`, `dark-bottom-nav`.

Una vez aplicadas, estas clases habilitan los cálculos dinámicos del tema. A partir de ahí, puede sobrescribir las variables CSS generadas usando `arbitrary properties`. Después de los dos puntos, indique cualquier formato de color CSS válido (HEX, variable CSS, RGB, etc.).

Puede encontrar la lista completa de propiedades en <ApiLink kind="sass" module="themes" type="function-bottom-nav-theme" label="Tema de IgxBottomNav" />. La sintaxis es la siguiente:

```html
<igx-bottom-nav
    class="!light-bottom-nav
    ![--background:#011627]
    ![--icon-selected-color:#FF8040] 
    ![--label-selected-color:#FF8040]">
    ...
</igx-bottom-nav>
```

<DocsAside type="info">
El signo de exclamación (`!`) es obligatorio para asegurar que la clase de utilidad tenga prioridad. Tailwind aplica los estilos por capas y, si no se marcan estos estilos como importantes, los sobrescribirá el tema predeterminado del componente.
</DocsAside>
