# Descripción general de Angular Icon Button

La directiva Icon Button de Ignite UI for Angular sirve para convertir cualquier icono en un botón totalmente funcional. El `igxIconButton` tiene tres tipos: flat, outlined y contained, que es el predeterminado.

## Primeros pasos con Ignite UI for Angular Icon Button

Para empezar con la directiva Icon Button de Ignite UI for Angular, primero debe instalar Ignite UI for Angular. En una aplicación Angular existente, escriba el siguiente comando:

```cmd
ng add igniteui-angular
```

Para una introducción completa a Ignite UI for Angular, lea el tema [_primeros pasos_](/general/getting-started).

El siguiente paso es importar `IgxIconButtonDirective` como dependencia independiente:

```typescript
// home.component.ts

...
import { IgxIconButtonDirective } from 'igniteui-angular/directives';
// import { IgxIconButtonDirective } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
        <button igxIconButton="outlined">
            <igx-icon>home</igx-icon>
        </button>`,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxIconButtonDirective]
})
export class HomeComponent {}
```


<DocsAside type="info">
Este componente usa Material Icons. Añada el siguiente enlace a su `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

Ahora que ha importado la directiva Icon Button de Ignite UI for Angular, puede empezar a usar la directiva `igxIconButton` en los elementos.

## Tipos de Angular Icon Button

### Flat Icon Button

Use la directiva <ApiLink type="IconButtonDirective" label="igxIconButton" /> para añadir un botón de icono plano sencillo en la plantilla de su componente:

```html
<button igxIconButton="flat">
    <igx-icon>edit</igx-icon>
</button>
```

<Sample src="/data-entries/flat-icon-button" height={70} iframeOnly />

### Contained Icon Button

Lo único que tiene que hacer para crear un botón de icono contenido es cambiar el valor de la propiedad `igxIconButton`. Tenga en cuenta que, si no elige un tipo, por defecto también se establecerá en `contained`.

```html
<button igxIconButton>
    <igx-icon>favorite</igx-icon>
</button>
```

<Sample src="/data-entries/contained-icon-button" height={70} iframeOnly />

### Outlined Icon Button

De forma análoga, podemos cambiar al tipo outlined:

```html
<button igxIconButton="outlined">
    <igx-icon>more_vert</igx-icon>
</button>
```

<Sample src="/data-entries/outlined-icon-button" height={70} iframeOnly />

## Ejemplos

### Disabled Icon Button

Si quiere desactivar un botón de icono, puede usar la propiedad <ApiLink type="IconButtonDirective" member="disabled" label="disabled" />. En este ejemplo también mostramos cómo usar iconos de distintas familias con la directiva `igxIconButton`:

```html
<button igxIconButton="flat" disabled>
    <igx-icon family="fa" name="fa-home"></igx-icon>
</button>
```

<Sample src="/data-entries/disabled-icon-button" height={70} iframeOnly />

### Iconos SVG

Además de los iconos de Material, la directiva `igxIconButton` también admite el uso de imágenes SVG como iconos. Para ello, primero debemos inyectar la dependencia <ApiLink type="IconService" /> y después usar el método <ApiLink type="IconService" member="addSvgIcon" label="addSvgIcon" /> para importar el archivo SVG en la caché. Para más información, puede leer la [sección SVG](/layouts/icon#svg-icons) del tema de iconos.

```typescript
constructor(private _iconService: IgxIconService) { }

public ngOnInit() {
    // register custom SVG icon
    this._iconService.addSvgIcon('rain', 'assets/images/card/icons/rain.svg', 'weather-icons');
}
```

```html
<button igxIconButton>
    <igx-icon family="weather-icons" name="rain"></igx-icon>
</button>
```

<Sample src="/data-entries/svg-icon-button" height={70} iframeOnly />

### Tamaño

Los usuarios pueden elegir uno de los tres tamaños `igxIconButton` predefinidos usando la propiedad personalizada de CSS `--ig-size`. De forma predeterminada, el tamaño del componente es medium.

<Sample src="/data-entries/icon-button-size" height={70} alt="Ejemplo de tamaño de Angular Icon Button" />

Como puede ver en el ejemplo anterior, también podemos usar la directiva `igxIconButton` para convertir elementos como `span` y `div` en botones de icono con el estilo de Ignite UI for Angular.

Siguiendo el enfoque más sencillo, usamos variables CSS para personalizar el aspecto del botón de icono:

```scss
[igxIconButton="contained"] {
  --background: #011627;
  --foreground: #fefefe;
  --hover-foreground: #011627dc;
  --hover-background: #ecaa53;
  --focus-foreground: #011627dc;
  --focus-background: #ecaa53;
  --focus-border-color: #0116276c;
  --active-foreground: #011627dc;
  --active-background: #ecaa53;
}
```

Consulte la sección <ApiLink kind="sass" module="themes" type="function-icon-button-theme" label="icon-button-theme" code={true} /> para ver una lista completa de los parámetros disponibles para dar estilo a cualquier tipo de botón de icono.

También puede optar por dar estilo solo a los botones de un tipo concreto: `flat`, `outlined` o `contained`.
Para ello, puede usar las nuevas funciones de tema específicas de cada tipo: <ApiLink kind="sass" module="themes" type="function-flat-icon-button-theme" label="flat-icon-button-theme" code={true} />, <ApiLink kind="sass" module="themes" type="function-outlined-icon-button-theme" label="outlined-icon-button-theme" code={true} /> y <ApiLink kind="sass" module="themes" type="function-contained-icon-button-theme" label="contained-icon-button-theme" code={true} />

Este es un ejemplo de uso de la función `contained-icon-button-theme` para definir un tema personalizado en SCSS:

```scss
@use "igniteui-angular/theming" as *;

$custom-contained: contained-icon-button-theme(
    $background: #ECAA53,
);
```

Esto generará un `contained icon button` completamente tematizado, con colores de primer plano y de fondo adecuados para sus distintos estados, como el de pasar el puntero, el foco y el activo.

### Dar estilo con Tailwind

Puede dar estilo al botón de icono usando nuestras clases de utilidad personalizadas de Tailwind. Asegúrese de [configurar Tailwind](/themes/tailwind) primero.

Junto con la importación de tailwind en su hoja de estilos global, puede aplicar las utilidades de tema deseadas de la siguiente manera:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

El archivo de utilidades incluye las variantes de tema `light` y `dark`.

- Use las clases `light-*` para el tema claro.
- Use las clases `dark-*` para el tema oscuro.
- Añada el nombre del componente después del prefijo, por ejemplo, `light-icon-button`, `dark-icon-button`.

Una vez aplicadas, estas clases habilitan los cálculos dinámicos del tema. A partir de ahí, puede sobrescribir las variables CSS generadas usando `arbitrary properties`. Después de los dos puntos, indique cualquier formato de color CSS válido (HEX, variable CSS, RGB, etc.).

Puede encontrar la lista completa de propiedades en <ApiLink kind="sass" module="themes" type="function-icon-button-theme" label="icon-button-theme" />. La sintaxis es la siguiente:

```html
<button igxIconButton class="!light-icon-button ![--icon-color:#FF4E00]">
  <igx-icon>edit</igx-icon>
</button>
```

<DocsAside type="info">
El signo de exclamación (`!`) es obligatorio para asegurar que la clase de utilidad tenga prioridad. Tailwind aplica los estilos por capas y, si no se marcan estos estilos como importantes, los sobrescribirá el tema predeterminado del componente.
</DocsAside>
