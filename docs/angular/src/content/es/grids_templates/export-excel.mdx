## Exportar los datos de {ComponentTitle}

Incorporar los exportadores a su proyecto solo requiere unas pocas líneas de código. Siga estos pasos y tendrá servicios reutilizables que pueden crear archivos Excel o PDF bajo demanda:

1. Importe <ApiLink type="ExcelExporterService" /> y/o <ApiLink type="PdfExporterService" /> en su módulo raíz.
2. Inyecte el exportador que necesite y llame a su método `export` cuando el usuario solicite un archivo.

```typescript
// component.ts
import { IgxExcelExporterService, IgxPdfExporterService } from 'igniteui-angular/grids/core';
// import { IgxExcelExporterService, IgxPdfExporterService } from '@infragistics/igniteui-angular/grids/core'; for licensed package

...

private excelExportService = inject(IgxExcelExporterService);
private pdfExportService = inject(IgxPdfExporterService);

```

<DocsAside type="info">
En la versión 12.2.1 y posteriores, `IgxExcelExporterService` se proporciona en root y no necesita registrarse en el array `providers`. El exportador de PDF se introdujo en versiones posteriores y está disponible como servicio inyectable sin configuración adicional.
</DocsAside>

Para iniciar un proceso de exportación puede usar el manejador de un botón en la plantilla de su componente.

```html
<{ComponentSelector} #{ComponentObjectRef} [data]="localData" [autoGenerate]="true"></{ComponentSelector}>
<button (click)="exportButtonHandler()">Export {ComponentName} to Excel</button>
<button (click)="exportPdfButtonHandler()">Export {ComponentName} to PDF</button>
```

</ComponentBlock>

</ComponentBlock>

Puede acceder a cualquiera de los dos servicios exportadores definiéndolo como dependencia del constructor y dejando que Angular proporcione una instancia. Llamar al método compartido <ApiLink type="ExcelExporterService" member="export" label="export" /> inicia la descarga y respeta automáticamente el estado del componente, las filas seleccionadas y las reglas de formato.

Este es el código que ejecutará ambos procesos de exportación en el archivo typescript del componente:

```typescript
// component.ts
import { IgxExcelExporterService, IgxExcelExporterOptions, IgxPdfExporterService, IgxPdfExporterOptions } from 'igniteui-angular/grids/core';
import { {ComponentName}Component } from 'igniteui-angular/grids/{ComponentMainTopic}';

@ViewChild('{ComponentObjectRef}') public {ComponentObjectRef}: {ComponentName}Component;

private excelExportService = inject(IgxExcelExporterService);
private pdfExportService = inject(IgxPdfExporterService);

public exportButtonHandler() {
  this.excelExportService.export(this.{ComponentObjectRef}, new IgxExcelExporterOptions('ExportedDataFile'));
}

public exportPdfButtonHandler() {
  this.pdfExportService.export(this.{ComponentObjectRef}, new IgxPdfExporterOptions('ExportedDataFile'));
}
```

Una vez conectado, al pulsar los botones respectivos se descargarán archivos con el nombre `ExportedDataFile.xlsx` o `ExportedDataFile.pdf`, con la vista {ComponentTitle} actual. Puede cambiar los nombres de archivo por otros más fáciles para el cliente, añadir marcas de tiempo o mostrar un toast de éxito para que los usuarios sepan que la exportación se ha completado.

## Exportar todos los datos

Los conjuntos de datos remotos y grandes suelen cargarse página a página o a demanda, lo que significa que {ComponentTitle} podría no tener todos los registros disponibles cuando el usuario hace clic en **Exportar**. Para garantizar un libro completo, rellene el exportador con la colección de datos completa antes de iniciar el proceso. El ayudante `exportData` omite el componente y trabaja directamente con objetos simples, por lo que puede reutilizar la misma rutina para exportaciones programadas o descargas solo para administradores.

```ts
public exportButtonHandler() {
  this.excelExportService.exportData(this.localData, new IgxExcelExporterOptions('ExportedDataFile'));
}
```

<DocsAside type="tip">
Al ofrecer descargas en PDF para datos remotos, considere obtener primero el conjunto de datos completo y después llamar a `export`, para que el documento refleje lo que espera el usuario.
</DocsAside>

## Exportar datos agrupados

La agrupación es una forma habitual de resumir segmentos de clientes, categorías de productos o periodos financieros antes de compartir los resultados. El exportador conserva la jerarquía de agrupación exacta que está aplicada actualmente en {ComponentTitle}, de modo que sus destinatarios ven el mismo desglose que usted en el navegador. Basta con agrupar por una o más columnas y lanzar la exportación; no se necesita configuración adicional.

Si necesita datos planos en el archivo exportado, elimine la agrupación antes de llamar a `export` o gestione el evento `rowExporting` para reestructurar la salida.

## Exportar un grid con encabezados de varias columnas

Los paneles suelen apoyarse en [encabezados de varias columnas](/{igPath}/multi-column-headers) para añadir contexto; piense en una banda "Q1/Q2/Q3" sobre las columnas de meses individuales. El exportador refleja esta estructura para que los usuarios de hojas de cálculo entiendan de inmediato la lógica de agrupación. Si su flujo de trabajo posterior prefiere nombres de columna sencillos, cambie el indicador <ApiLink kind="interface" type="IGridToolbarExportEventArgs" label="opción del exportador" /> <ApiLink type="ExcelExporterOptions" member="ignoremulticolumnheaders" label="ignoreMultiColumnHeaders" /> a `true` y la salida solo incluirá los encabezados hoja.

El {ComponentTitle} exportado no tendrá formato de tabla, ya que las tablas de Excel no admiten varios encabezados de fila.
</DocsAside>

## Exportar un grid con encabezados de columna fijos

Las hojas largas pueden ser difíciles de leer cuando la fila de encabezados sale de la vista. Si habilita los encabezados fijos, el contexto clave, como "Customer" o "Invoice Total", permanece visible en la parte superior de la hoja de cálculo mientras los usuarios exploran los datos más abajo. Cambie el indicador <ApiLink kind="interface" type="IGridToolbarExportEventArgs" label="opción del exportador" /> <ApiLink type="ExcelExporterOptions" member="freezeHeaders" label="freezeHeaders" /> a `true` antes de llamar a `export` y el servicio se encargará del resto.

```typescript
public exportButtonHandler() {
    const exporterOptions = new IgxExcelExporterOptions('ExportedDataFile');
    exporterOptions.freezeHeaders = true;
    this.excelExportService.export(this.grid, exporterOptions);
}
```

</ComponentBlock>

Las exportaciones a PDF incluyen automáticamente la fila de encabezados de columna en la parte superior del documento, de modo que los lectores mantienen el mismo contexto al abrir o imprimir el archivo.

## Personalizar el contenido exportado

La mayoría de los equipos adaptan las exportaciones antes de compartirlas: ocultan columnas de uso interno, renombran encabezados u omiten filas que solo se aplican a los administradores. Ambos servicios exportadores exponen eventos que le permiten interceptar cada fila o columna y decidir cómo debe aparecer en el archivo. Suscríbase a <ApiLink type="ExcelExporterService" member="columnexporting" label="columnExporting" /> y <ApiLink type="ExcelExporterService" member="rowexporting" label="rowExporting" /> para hacer ajustes de última hora: establezca `cancel = true` para omitir un elemento, o modifique los argumentos del evento para actualizar valores sobre la marcha.

<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">

El siguiente ejemplo excluye de la exportación una columna si su encabezado es "Age" y su índice es 1:

```typescript
// component.ts

this.excelExportService.columnExporting.subscribe((args: IColumnExportingEventArgs) => {
  if (args.header == 'Age' && args.columnIndex == 1) {
      args.cancel = true;
  }
});
this.excelExportService.export(this.{ComponentObjectRef}, new IgxExcelExporterOptions('ExportedDataFile'));
```

</ComponentBlock>

<ComponentBlock for="PivotGrid">

El ejemplo siguiente excluirá de la exportación todas las columnas cuyo encabezado sea "Amount of Sale":

```typescript
// component.ts

this.excelExportService.columnExporting.subscribe((args: IColumnExportingEventArgs) => {
    if (args.header == 'Amount of Sale') {
        args.cancel = true;
    }
});
this.excelExportService.export(this.{ComponentObjectRef}, new IgxExcelExporterOptions('ExportedDataFile'));
```

</ComponentBlock>

Cuando exporta datos desde el componente {ComponentTitle}, los servicios respetan automáticamente la ordenación, el filtrado, los resúmenes y las columnas ocultas, de modo que el archivo refleja lo que el usuario ve en ese momento. ¿Necesita el conjunto de datos completo? Active los indicadores correspondientes en <ApiLink type="ExcelExporterOptions" /> o <ApiLink type="PdfExporterOptions" /> para incluir las filas filtradas, las columnas ocultas o metadatos personalizados.

## Limitaciones conocidas

Antes de publicar las exportaciones para los usuarios de producción, revise las siguientes restricciones de la plataforma para establecer expectativas y ofrecer orientación útil dentro de su aplicación.

<ComponentBlock for="Grid">

|Limitación|Descripción|
|--- |--- |
|Tamaño máximo de hoja de cálculo|El tamaño máximo de hoja de cálculo admitido por Excel es de 1.048.576 filas por 16.384 columnas. Considere dividir las exportaciones muy grandes por intervalo de fechas o por segmento para mantenerse dentro de estos límites.|
|Estilo de celdas|El servicio exportador de Excel no admite exportar un estilo personalizado aplicado directamente a un componente de celda. En estos casos recomendamos usar la biblioteca [Excel Library](/excel-library), más completa, para un formato detallado.|
|Diseños PDF anchos|Los grids muy anchos pueden hacer que las columnas del PDF se reduzcan para ajustarse a la página. Aplique anchos de columna u oculte los campos de menor prioridad antes de exportar para que el documento siga siendo legible.|
