# Dimensionamiento de Angular Grid

Hay muchas formas diferentes de dimensionar <ApiLink type="{ComponentApiType}" /> para adaptarse a numerosos escenarios que pueden tener los usuarios. Aunque algunas son sencillas, otras pueden ser más complejas, por lo que veremos cada una con más detalle. Revisaremos por separado el establecimiento de `width` y `height`, ya que existen algunas diferencias, por ejemplo, al usar porcentajes en cada caso.

En cuanto al borde y el relleno de <ApiLink type="{ComponentApiType}" />, se tienen en cuenta en los cálculos de su ancho y alto, lo que también se conoce como dimensionamiento de [cuadro de borde (Border box)](https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing). Se aplica en todos los escenarios.

<DocsAside type="info">
Si el usuario sustituye el dimensionamiento Border box, no podemos garantizar que <ApiLink type="{ComponentApiType}" /> se dimensione correctamente.
</DocsAside>

## Ancho

Si la entrada `width` no tiene ningún valor asignado, su valor predeterminado es `100%` y <ApiLink type="{ComponentApiType}" /> intenta ocupar el espacio disponible. Puede comprobar cómo reacciona la cuadrícula en la sección `Percentages`.

<DocsAside type="info">
Establecer manualmente el estilo `width` de <ApiLink type="{ComponentApiType}" /> provocará un comportamiento inesperado.
</DocsAside>

### Null

La propiedad `width` de la cuadrícula puede aceptar el valor `null`, que, al establecerse, muestra todas las columnas en el DOM. La cuadrícula se dimensiona en consecuencia, de modo que no hay barra de desplazamiento horizontal, ya que no se aplica virtualización de columnas.

- Si hay 6 columnas y ninguna tiene un ancho definido, la cuadrícula tendrá `width` de `816px`, porque en este escenario cada columna tiene asignado por defecto un `width` de `136px`. Lo mismo ocurrirá si las columnas tienen `width` en porcentajes. Si se muestra una barra de desplazamiento vertical o si hay funciones que muestran columnas adicionales, su ancho también se sumará.

    <Image src={columnsDefaultGridwidthNullV2} alt="Columnas, ancho predeterminado del Grid nulo" style="width: 80%" />

- Si hay 6 columnas con el ancho de columna establecido en `200px`, cabrán en nuestra ventana y todas serán visibles:

    <Image src={widthNullNoScrollV2} alt="Ancho nulo sin desplazamiento" style="width: 80%" />

- Si hay más columnas o columnas con un ancho mayor que quedan fuera de la vista del navegador, se renderizarán todas igualmente. Tengamos la misma cantidad de columnas, pero cada una con un ancho de columna de `300px`. Como no caben todas en el área visible del navegador, se creará una barra de desplazamiento de forma nativa. El siguiente ejemplo muestra exactamente este escenario:

    <Image src={widthNullScrollV2} alt="Ancho nulo con desplazamiento" style="width: 80%" />

- Si la cuadrícula tiene un elemento padre de cualquier tipo y no tiene ningún overflow definido, seguirá mostrando todas las columnas visibles. En caso contrario, si el elemento padre tiene overflow `auto` o `scroll`, se renderizará de forma nativa una barra de desplazamiento para ese elemento padre. El padre tiene mayor altura para facilitar la visualización en el siguiente ejemplo.

    <Image src={widthNullParentScrollV2} alt="Ancho nulo con desplazamiento del elemento principal" style="width: 80%" />

<DocsAside type="info">
Debido a este comportamiento, si los datos de la cuadrícula contienen demasiadas columnas, puede tener un impacto considerable en el rendimiento del navegador, ya que todas las columnas se renderizarían sin virtualización.
</DocsAside>

### Píxeles

Cuando la entrada <ApiLink type="{ComponentApiType}" /> `width` se establece en píxeles, se fijará el tamaño de toda la cuadrícula en ese valor y será estático. No reaccionará a cambios de tamaño del navegador ni a cambios en el DOM, aunque este no es el caso del contenido de la cuadrícula:

- Cuando el ancho se establece en píxeles para que la cuadrícula muestre una barra de desplazamiento horizontal, el ancho de su contenido debe superar el `width` de cuadrícula especificado. Por ejemplo, hagamos que el ancho combinado de las columnas supere `1200px`. En este caso se mostrará una barra de desplazamiento horizontal.

    <Image src={widthColsScrollbarV2} alt="Ancho de columnas con barra de desplazamiento" style="width: 80%" />

- En los escenarios en los que la cuadrícula tiene un elemento padre, depende del estilo del padre que se muestre o no una barra de desplazamiento. Todo lo demás relacionado con la propia cuadrícula se conserva. Si el ancho del elemento padre es menor que el de la cuadrícula y tiene el estilo de overflow establecido en `auto` o `scroll`, se mostrará una barra de desplazamiento de forma nativa. Por ejemplo, si el padre tiene `width` establecido en `1000px` y el <ApiLink type="{ComponentApiType}" /> `width` sigue siendo `1200px`, tendrá un aspecto similar a las ilustraciones siguientes:

    <Image src={widthColsScrollParentNoscrollV2} alt="Ancho de columnas con desplazamiento, elemento principal sin desplazamiento" style="width: 80%" />
    <Image src={widthColsScrollParentScrollV2} alt="Ancho de columnas con desplazamiento, elemento principal con desplazamiento" style="width: 80%" />

### Porcentajes

Cuando el `width` de <ApiLink type="{ComponentApiType}" /> se establece en porcentajes, la cuadrícula se dimensiona según el ancho del elemento padre. Si el elemento padre no tiene un ancho especificado, <ApiLink type="{ComponentApiType}" /> se dimensionará en relación con la ventana del navegador.

- Por ejemplo, si establecemos la entrada `width` de la cuadrícula en `100%` y no hay elemento padre, ocupará el 100 % del ancho disponible de la ventana del navegador. Si se redimensiona, la cuadrícula también se redimensionará en consecuencia.

    <Image src={widthPercent100PV2} alt="Ancho en porcentaje 100 %" style="width: 80%" />

- Si establecemos el ancho de la cuadrícula en `100%` y hay un elemento padre con un ancho específico de `1200px`, esto significa que la cuadrícula se dimensionará en relación con ese elemento y su ancho final será `1200px`.

    <Image src={widthPercentParent100PV2} alt="Ancho en porcentaje, elemento principal 100 %" style="width: 80%" />

- Si tenemos un elemento padre con `width` de `1000px` y establecemos el `width` de la cuadrícula en `150%`, el ancho calculado de la cuadrícula será `1500px`. En este caso, la cuadrícula seguirá mostrándose completamente visible, pero si establecemos `overflow: auto` del padre, ese padre mostrará su propia barra de desplazamiento.

    <Image src={widthPercent150PParentNoscrollV2} alt="Ancho en porcentaje 150 %, elemento principal sin desplazamiento" style="width: 80%" />
    <Image src={widthPercent150PParentScrollV2} alt="Ancho en porcentaje 150 %, elemento principal con desplazamiento" style="width: 80%" />

## Alto

De forma predeterminada, si no se define ningún alto para <ApiLink type="{ComponentApiType}" />, se establecerá en `100%`. Puede comprobar cómo reacciona la cuadrícula según la estructura del DOM en la sección `Percentages`.

<DocsAside type="info">
Establecer manualmente el estilo `height` de <ApiLink type="{ComponentApiType}" /> provocará un comportamiento inesperado.
</DocsAside>

### Null

La entrada <ApiLink type="{ComponentApiType}" /> `height` puede aceptar el valor `null`, que, al establecerse, muestra todas las filas sin barra de desplazamiento, sin importar cuántas sean. En este caso no hay virtualización vertical, ya que la cuadrícula renderiza todas las filas de todos modos.

- Si tenemos datos con 14 filas, en este caso la cuadrícula renderizará las 14 y se dimensionará para que todas sean visibles, sin espacio vacío dentro de la cuadrícula.

    <Image src={heightNull14RowsV2} alt="Alto nulo, 14 filas" style="width: 80%" />

- Si en lugar de eso tenemos 24 filas, la cuadrícula seguirá renderizando todas las filas, pero como son demasiadas, superan los límites del navegador. Por eso el propio navegador mostrará de forma predeterminada una barra de desplazamiento vertical para que el usuario pueda desplazarse hacia abajo y ver el resto de filas.

    <Image src={heightNull24RowsV2} alt="Alto nulo, 24 filas" style="width: 80%" />

- Si hay un elemento principal con `height` definido, la cuadrícula seguirá representando todas las filas y no se verá afectada. Supongamos que el elemento principal tiene `height` de `650px`. Si tiene `overflow` establecido en `auto` o `scroll`, mostrará una barra de desplazamiento vertical, pero la cuadrícula seguirá sin verse afectada:

    <Image src={heightNull24RowsParentNoscrollV2} alt="Alto nulo, 24 filas, elemento principal sin desplazamiento" style="width: 80%" />
    <Image src={heightNull24RowsParentScrollV2} alt="Alto nulo, 24 filas, elemento principal con desplazamiento" style="width: 80%" />

<DocsAside type="info">
Debido a este comportamiento, si los datos de la cuadrícula contienen demasiadas filas, puede tener un impacto considerable en el rendimiento del navegador, ya que todas las filas se renderizarían sin virtualización.
</DocsAside>

### Píxeles

Establecer el <ApiLink type="{ComponentApiType}" /> `height` en píxeles es más sencillo, ya que la cuadrícula siempre se dimensionará a ese tamaño concreto, de forma similar a como se establece `width` en píxeles.

- Si establecemos, por ejemplo, el alto `500px` con 4 filas para nuestros datos, la cuadrícula ocupará ese tamaño y, como 4 filas no bastan para llenar el área visible, es normal que haya algo de espacio vacío.

    <Image src={height500Px4RowsV2} alt="Alto 500 px, 4 filas" style="width: 80%" />

- Si el número de filas supera el área visible de la cuadrícula cuando `height` se establece en píxeles, se mostrará una barra de desplazamiento vertical. Por ejemplo, una cuadrícula con un alto de `500px` y 14 filas se renderizará de la siguiente manera:

    <Image src={height500Px14RowsV2} alt="Alto 500 px, 14 filas" style="width: 80%" />

- Si hay un elemento padre con `height` definido, a menos que tenga `overflow` establecido en `auto` o `scroll`, la cuadrícula seguirá siendo completamente visible. En caso contrario, se mostrará una barra de desplazamiento.

    <Image src={height700Px14RowsParentNoscrollV2} alt="Alto 700 px, 14 filas, elemento principal sin desplazamiento" style="width: 80%" />
    <Image src={height700Px14RowsParentScrollV2} alt="Alto 700 px, 14 filas, elemento principal con desplazamiento" style="width: 80%" />

### Porcentajes

Cuando la entrada `height` se establece en porcentajes, <ApiLink type="{ComponentApiType}" /> se dimensionará según el alto del elemento principal. Si el elemento principal tiene su `height` establecido en píxeles o porcentajes, la cuadrícula se dimensionará en relación con el tamaño del elemento principal.

Cuando el elemento padre no tiene un alto definido, el navegador no le asigna inicialmente ninguna altura y lo dimensiona según sus hijos y su tamaño. Por eso la cuadrícula no tiene forma de saber qué altura base usar para aplicar un dimensionamiento porcentual. Por este motivo, renderizará un máximo de 10 filas y, si hay más, se mostrará una barra de desplazamiento vertical. En caso contrario, la cuadrícula se ajustará al número de filas renderizadas. Veremos este escenario con más detalle en los siguientes ejemplos.

Tengamos `width` establecido en `1200px` y el elemento padre sin ningún tamaño aplicado:

- Si hay menos de 10 filas, la cuadrícula intentará ajustar todas las filas en el área visible sin dejar un espacio vacío entre la última fila y la parte inferior del área visible. Por ejemplo, supongamos que los datos de la cuadrícula constan de 7 filas. La cuadrícula representará las 7 filas sin barra de desplazamiento vertical y sin espacio vacío dentro de la cuadrícula.

    <Image src={heightUndefined7RowsV2} alt="Alto indefinido, 7 filas" style="width: 80%" />

- Si hay más de 10 filas, se mostrará una barra de desplazamiento vertical para el resto de las filas, y solo podrán verse 10 filas en cada momento. En el siguiente ejemplo, solo se aumenta el número de filas a 14.

    <Image src={heightUndefined14RowsV2} alt="Alto indefinido, 14 filas" style="width: 80%" />

- Si establecemos el alto del elemento padre en `800px` y el <ApiLink type="{ComponentApiType}" /> en `100%` de alto, esto significa que la cuadrícula se dimensionará al 100 por ciento de `800px`.

    <Image src={heightPercent100Parent800PxV2} alt="Alto en porcentaje 100 %, elemento principal de 800 px" style="width: 80%" />

- Si el <ApiLink type="{ComponentApiType}" /> `height` se establece en un número mayor que `100%` y el elemento padre tiene altura, para que el padre muestre una barra de desplazamiento es necesario que tenga `overflow` establecido en `auto` o `scroll`. De lo contrario, la cuadrícula será completamente visible y se dimensionará en relación con el tamaño del padre.

    <Image src={heightPercent130PParentNoscrollV2} alt="Alto en porcentaje 130 %, elemento principal sin desplazamiento" style="width: 80%" />
    <Image src={heightPercent130PParentScrollV2} alt="Alto en porcentaje 130 %, elemento principal con desplazamiento" style="width: 80%" />

- Si queremos que la cuadrícula ocupe `100%` de la ventana del navegador, tendríamos que establecer la altura tanto de `body` como del elemento padre de la cuadrícula en `100%`. En este caso, el elemento padre puede dimensionarse y la cuadrícula se dimensionará en consecuencia si se redimensiona el navegador.

    <Image src={heightPercent100Parent100V2} alt="Alto en porcentaje 100 %, elemento principal 100 %" style="width: 80%" />

## Dimensionamiento de columnas

Según el tamaño de la propia cuadrícula, las columnas que contiene también pueden dimensionarse de forma distinta, lo que puede dar lugar a escenarios en los que la cuadrícula muestre una barra de desplazamiento horizontal o no. Las columnas pueden tener el ancho establecido en píxeles, en porcentajes, o dimensionarse automáticamente cuando no se establece nada. Veremos estos escenarios con más detalle en esta sección.

### Valor predeterminado

De forma predeterminada, cuando una columna no tiene un ancho especificado, intentará dimensionarse automáticamente para ocupar el espacio vacío disponible en el área de la cuadrícula. Las columnas con dimensionamiento automático tienen un ancho mínimo de `136px`, así que, si el área disponible es menor que `136px` para esa columna, se usará ese tamaño por defecto.

Cuando la cuadrícula se redimensiona en estos escenarios, el ancho de la columna también se actualiza para reflejar los cambios, de modo que ocupa cualquier nuevo espacio vacío disponible.

- Si una columna no tiene `width` especificado y <ApiLink type="{ComponentApiType}" /> tiene `width` establecido en `null`, se dimensionará al mínimo de `136px`. Esto significa que, en una cuadrícula con `width` `null` y 6 columnas sin ancho, cada columna se dimensionará a `136px`.

    <Image src={columnsDefaultGridwidthNullV2} alt="Columnas, Grid predeterminado con ancho nulo" style="width: 80%" />

- Cuando hay varias columnas con dimensionamiento automático, dividirán el espacio disponible entre ellas por igual. Esto significa que, si tenemos 6 columnas y hay un área vacía de `1200px`, cada una se dimensionará a `200px`.

    <Image src={columnsDefaultAllRowSelectorsV2} alt="Columnas, todos los selectores de fila predeterminados" style="width: 80%" />

- Si hay espacio vacío disponible, de modo que cada columna con dimensionamiento automático sea menor que `136px`, todas las columnas con dimensionamiento automático se establecerán por defecto en `136px` y la cuadrícula mostrará una barra de desplazamiento horizontal. En el siguiente ejemplo tendremos 12 columnas con dimensionamiento automático y la cuadrícula `width` establecida en `1000px`.

    <Image src={columnsDefaultAllMin136PxV2} alt="Columnas, todas con mínimo predeterminado de 136 px" style="width: 80%" />

- Si una columna no tiene `width` especificado, pero todas las demás columnas tienen `width` en píxeles o porcentajes, esa columna también intentará ocupar el espacio disponible. Por ejemplo, si no establecemos el ancho de la primera columna y las otras 5 tienen un `width` de `100px`, la primera ocupará el resto.

    <Image src={columnsDefaultFirstRest100PxV2} alt="Columnas, primera predeterminada y resto de 100 px" style="width: 80%" />

- Lo mismo se aplica si varias columnas no tienen `width` especificado: todas dividirán el espacio disponible entre ellas por igual. En la siguiente ilustración, la primera columna tiene `width` establecido en `100px`.

    <Image src={columnsDefaultAllFirst100PxV2} alt="Columnas, todas predeterminadas excepto la primera de 100 px" style="width: 80%" />

<DocsAside type="info">
Las columnas de funciones, como la columna de casillas del selector de filas, etc., ocupan espacio adicional que se tiene en cuenta al dimensionar automáticamente las columnas.
</DocsAside>

### Píxeles

Cuando las columnas tienen establecido un `width` específico en píxeles, se mantienen en ese tamaño, a menos que se redimensionen manualmente. Como el `width` combinado de las columnas es estático, puede ser menor que el <ApiLink type="{ComponentApiType}" /> `width` o superarlo.

- Si el `width` combinado de todas las columnas es menor que el <ApiLink type="{ComponentApiType}" /> `width`, quedará un área vacía dentro de la cuadrícula que las columnas no podrán ocupar. Este es el comportamiento esperado de <ApiLink type="{ComponentApiType}" />. En el siguiente ejemplo, las columnas tienen un ancho de `150px`.

    <Image src={columns150PxEmptyAreaV2} alt="Columnas de 150 px con área vacía como resultado" style="width: 80%" />

- Si el `width` combinado de todas las columnas es mayor que el <ApiLink type="{ComponentApiType}" /> `width` real, se mostrará una barra de desplazamiento horizontal. En el siguiente ejemplo, cada una de las 6 columnas tiene un ancho de `300px` y la cuadrícula tiene un ancho de `1200px`, lo que significa que el exceso combinado de las columnas de `600px` queda fuera de los límites.

    <Image src={columns150PxExtraAreaV2} alt="Columnas de 150 px con área adicional como resultado" style="width: 80%" />

### Auto

Cuando las columnas se establecen en `auto`, su tamaño se ajusta a la palabra más larga de la columna. Pueden aparecer áreas vacías si hay celdas con valores muy cortos mientras otras tienen valores muy largos. En este escenario, todas las celdas de la columna se ajustarían para adoptar el ancho de la celda con el valor más largo.

<Image src={columns150PxEmptyAreaV2} alt="Columnas con ancho automático" style="width: 80%" />

### Porcentajes

Cuando las columnas tienen establecido un `width` en porcentajes, su tamaño se calcula en relación con el tamaño de la cuadrícula. Es similar a cómo funciona el ancho en píxeles, pero además proporciona adaptabilidad a las columnas, lo que significa que, al redimensionarse la cuadrícula, las columnas también se redimensionan en consecuencia.

- Si el ancho combinado de todas las columnas es menor que `100%`, al igual que ocurre con los píxeles, puede quedar un área vacía de la cuadrícula que las columnas no cubren.

    <Image src={columnsPercentLess100PV2} alt="Columnas en porcentaje, menos del 100 %" style="width: 80%" />

- Si el ancho combinado es exactamente `100%`, las columnas ocuparán todo el espacio disponible de la cuadrícula.

    <Image src={columnsPercent100PV2} alt="Columnas en porcentaje, 100 %" style="width: 80%" />

- Si el ancho combinado supera `100%`, para que el usuario pueda ver las columnas que quedan fuera de la vista, se mostrará una barra de desplazamiento horizontal.

## Dimensionamiento del Grid secundario

Como <ApiLink type="{ComponentApiType}" /> suele contener hijos, estos también pueden tener especificados su `width` y su `height`, para adaptarse a distintos escenarios. Como los hijos se definen mediante la plantilla `row island`, esto significa que todos los hijos del mismo nivel y de la misma isla tendrán aplicadas las mismas propiedades `width` y `height`.

### Ancho

El `width` de los hijos no se comporta de forma muy distinta al de <ApiLink type="{ComponentApiType}" /> en sí, ya que cada cuadrícula hija también es una instancia de <ApiLink type="{ComponentApiType}" />.

La única diferencia es que el usuario no puede cambiar el elemento padre de la cuadrícula hija. Por eso, cuando el `width` se establece en porcentajes, el `100%` asignado a la hija es menor que el de la cuadrícula padre `width`. Así es más fácil distinguirla cuando está expandida. La siguiente imagen muestra los tamaños predeterminados de la cuadrícula hija, ya que por defecto usa un ancho `100%`.

<Image src={hgridWidthPercentagesV2} alt="Ancho del Grid secundario en porcentajes" style="width: 80%" />

### Alto

El `height` de cada hijo en <ApiLink type="{ComponentApiType}" /> también se comporta de forma similar al `height` de la cuadrícula de nivel raíz.

La diferencia es que, en el caso de la cuadrícula hija, cuando `height` se establece en porcentajes, se comporta como si el elemento padre no tuviera altura definida. Esto significa que, en este escenario, la cuadrícula renderizará como máximo 10 filas. Cuando el número de filas de los datos es menor que 10, la cuadrícula ajustará el área de visualización para que quepan todas las filas. Si los datos tienen más filas, se mostrará una barra de desplazamiento vertical y el área de visualización se dimensionará a una altura de 10 filas.

## Control del espaciado de celdas del Grid

<ApiLink type="{ComponentApiType}" /> adapta automáticamente su espaciado interno según el valor de [tamaño](/{igPath}/display-density). Puede personalizar aún más el relleno y los márgenes de las celdas de encabezado y cuerpo del Grid mediante propiedades personalizadas de CSS para controlar el espaciado.

### Espaciado global del Grid

Para reducir o aumentar el espaciado en todas las celdas de la cuadrícula de su aplicación:

```css
/* Reduce all grid spacing by 20% */
igx-grid {
    --ig-spacing: 0.8;
}

/* Increase spacing for better touch accessibility */
igx-grid {
    --ig-spacing: 1.2;
}
```

### Espaciado específico del Grid

Para ajustar el espaciado de una instancia concreta de la cuadrícula:

```css
/* Make a particular grid more compact */
.my-compact-grid {
    --ig-spacing: 0.6;
}

/* Give a specific grid more breathing room */
.my-spacious-grid {
    --ig-spacing: 1.4;
}
```

### Control del espaciado direccional

Puede controlar el espaciado horizontal y vertical de forma independiente:

```css
/* Reduce only horizontal spacing (left/right padding) */
.my-grid {
    --ig-spacing-inline: 0.5;
    --ig-spacing-block: 1.0; /* Keep vertical spacing normal */
}

/* Adjust vertical spacing for tighter row spacing */
.my-grid {
    --ig-spacing-inline: 1.0; /* Keep horizontal spacing normal */
    --ig-spacing-block: 0.7; /* Reduce vertical spacing (if applicable) */
}
```

### Espaciado específico por tamaño

Se pueden aplicar distintos multiplicadores de espaciado según la densidad de visualización de la cuadrícula:

```css
.my-grid {
    /* Compact density gets very tight spacing */
    --ig-spacing-small: 0.5;

    /* Medium density uses normal spacing */
    --ig-spacing-medium: 1.0;

    /* Comfortable density gets extra spacing */
    --ig-spacing-large: 1.3;
}
```

### Espaciado de celdas de encabezado frente a celdas de cuerpo

Aunque las propiedades de espaciado afectan tanto a las celdas de encabezado como a las del cuerpo, puede dirigirse a ellas de forma específica si lo necesita:

```css
/* Reduce padding in header cells specifically */
.my-grid igx-grid-header {
    --ig-spacing: 0.7;
}

/* Adjust spacing in data cells */
.my-grid igx-grid-cell {
    --ig-spacing: 0.9;
}
```

<DocsAside type="info">
Estos ajustes de espaciado funcionan junto con la densidad de visualización de la cuadrícula. Los multiplicadores de espaciado se aplican a los valores de espaciado base que ya están determinados por el modo de densidad de la cuadrícula: compacta, normal o cómoda.
</DocsAside>
