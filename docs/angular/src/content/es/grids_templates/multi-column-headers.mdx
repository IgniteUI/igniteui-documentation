# Descripción general de los encabezados de varias columnas de {ComponentTitle} en Angular

<ApiLink type="{ComponentApiType}" /> admite `multi-column headers`, que le permiten agrupar columnas colocándolas bajo un encabezado múltiple común. Cada grupo de encabezados de varias columnas puede representar combinaciones de otros grupos o columnas dentro de la cuadrícula de Material UI.

La declaración de `Multi-column header` puede lograrse envolviendo un conjunto de columnas en el componente <ApiLink type="ColumnGroup" label="igx-column-group" /> con el título <ApiLink type="ColumnGroup" member="header" label="header" /> proporcionado.

<ComponentBlock for="Grid">

```html
<igx-grid [data]="data" [allowFiltering]="true">
    <igx-column-group header="Contact Information">
        <igx-column sortable="true" resizable="true" field="Phone"></igx-column>
        <igx-column sortable="true" resizable="true" field="Fax"></igx-column>
        <igx-column sortable="true" resizable="true" field="PostalCode"></igx-column>
    </igx-column-group>
</igx-grid>
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```html

        <igx-column field="Fax" dataType="string" [sortable]="true" [resizable]="true"></igx-column>
```

Para lograr `n-th` niveles de encabezados anidados, debe seguir la declaración anterior. Así, anidando <ApiLink type="ColumnGroup" label="igx-column-group" /> se obtiene el resultado deseado.

Cada <ApiLink type="ColumnGroup" label="igx-column-group" /> admite [`moving`](/{igPath}/column-moving), [`pinning`](/{igPath}/column-pinning) y [`hiding`](/{igPath}/column-hiding).
<DocsAside type="info">
Cuando hay un conjunto de columnas y grupos de columnas, el anclaje solo funciona para los padres de columnas de nivel superior. Más concretamente, no se permite anclar un `column groups` o un `columns` anidado. <br />
Tenga en cuenta que, al usar el anclaje con encabezados de varias columnas, todo el grupo queda anclado. <br />
El movimiento entre `columns` y `column groups` solo se permite cuando están en el mismo nivel de la jerarquía y ambos pertenecen al mismo `group`. <br />
Cuando `columns/column-groups` no están envueltas por el `group` actual, lo que significa que son **de nivel superior** `columns`, el movimiento se permite entre todas las columnas visibles.
</DocsAside>

## Plantilla de encabezado de varias columnas

Cada uno de los grupos de columnas del grid puede tener una plantilla por separado. El grupo de columnas espera una etiqueta `ng-template` decorada con la directiva `igxHeader`.
A la `ng-template` se le proporciona el objeto del grupo de columnas como contexto.

```html
...
<igx-column-group header="General Information">
    <ng-template igxHeader let-columnGroup>
        {{ columnGroup.header | uppercase }}
    </ng-template>
    ...
</igx-column-group>
...
```

Si quiere reutilizar una única plantilla para varios grupos de columnas, puede establecer la propiedad <ApiLink type="ColumnGroup" member="headertemplate" label="headerTemplate" /> del grupo de columnas así:

```html
<ng-template #columnGroupHeaderTemplate let-columnGroup>
    {{ columnGroup.header | uppercase }}
</ng-template>

...
<igx-column-group header="General Information" [headerTemplate]="columnGroupHeaderTemplate">
    ...
</igx-column-group>
<igx-column-group header="Address Information" [headerTemplate]="columnGroupHeaderTemplate">
    ...
</igx-column-group>
...
```

<DocsAside type="info">
Si se vuelve a crear la plantilla de un encabezado de columna y el movimiento de la cuadrícula está habilitado, debe establecer el atributo **draggable** de la columna correspondiente en **false** en los elementos con plantilla, ¡para poder gestionar cualquiera de los eventos que se apliquen!
</DocsAside>

```html
<ng-template igxHeader>
    <igx-icon [attr.draggable]="false" (click)="onClick()"></igx-icon>
</ng-template>
```

## Estilos

Para empezar a dar estilo al comportamiento de ordenación, debemos importar el archivo `index`, donde se exportan todas las funciones de tema y el mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Siguiendo el enfoque más sencillo, creamos un tema nuevo que extiende <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> y acepta los parámetros `$header-background`, `$header-text-color`, `$header-border-width`, `$header-border-style` y `$header-border-color`.

<ComponentBlock for="Grid">

```scss
$custom-theme: grid-theme(
  $header-background: #e0f3ff,
  $header-text-color: #e41c77,
  $header-border-width: 1px,
  $header-border-style: solid,
  $header-border-color: rgba(0, 0, 0, 0.08)
);
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```scss
$custom-theme: grid-theme(
  $header-background: #f1eaf6,
  $header-text-color: #8c1bdd,
  $header-border-width: 1px,
  $header-border-style: solid,
  $header-border-color: #d3b9e6,
  $cell-active-border-color: #7409c1
);
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```scss
$custom-theme: grid-theme(
  $header-background: #f8f8ed,
  $header-text-color: #7a6551,
  $header-border-style: dashed,
  $header-border-color: rgba(0, 0, 0, 0.08)
);
```

</ComponentBlock>

<DocsAside type="info">
En lugar de codificar los valores de color como acabamos de hacer, podemos lograr más flexibilidad con los colores usando las funciones <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> y <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Consulte el tema [`Palettes`](/themes/sass/palettes) para obtener orientación detallada sobre cómo usarlas.
</DocsAside>

El último paso es aplicar el tema del componente con `tokens()`:

```scss
:host {
  @include tokens($custom-theme);
}
```
