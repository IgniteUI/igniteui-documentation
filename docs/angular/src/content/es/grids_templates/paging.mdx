# Paginación de {ComponentTitle} en Angular

La paginación se usa para dividir un gran conjunto de datos en una secuencia de páginas con contenido similar. La paginación de la tabla de Angular mejora la experiencia del usuario y la interacción con los datos. La paginación de {ComponentTitle} se configura mediante un componente independiente proyectado en el árbol de la cuadrícula, definiendo una etiqueta `igx-paginator`, de forma similar a como se añade una columna. Como en cualquier tabla de Angular, la paginación de {ComponentTitle} admite plantillas para páginas personalizadas.

Añadir un componente [`igx-paginator`](/paginator) controlará si la función está presente; puede habilitarla o deshabilitarla usando un bloque `@if` sencillo con una propiedad de alternancia. La entrada <ApiLink type="Paginator" member="perPage" label="perPage" /> controla los registros visibles por página. Actualicemos nuestro {ComponentTitle} para habilitar la paginación:

```html
<{ComponentSelector} #{ComponentObjectRef} [data]="data" [height]="'500px'" [width]="'100%'">
    <igx-paginator [perPage]="10">
    </igx-paginator>
</{ComponentSelector}>
```

Ejemplo:

```html
<igx-paginator #paginator [totalRecords]="20">
    <igx-paginator-content>
        <div id="numberPager" style="justify-content: center;">
            <button [disabled]="paginator.isFirstPage" (click)="paginator.previousPage()" igxButton="flat">
                PREV
            </button>
            <span>
               Page {{paginator.page}} of {{paginator.totalPages}}
            </span>
            <button [disabled]="paginator.isLastPage" (click)="paginator.nextPage()" igxButton="flat">
                NEXT
            </button>
        </div>
    </igx-paginator-content>
</igx-paginator>
```

## Paginación con Agrupar por

Las filas de grupo participan en el proceso de paginación junto con las filas de datos. Cuentan para el tamaño de página de cada página. Las filas contraídas no se incluyen en el proceso de paginación.
La integración entre la paginación y Agrupar por se describe en el tema [Agrupar por](/{igPath}/groupby#agrupación-de-angular-grid-con-paginación).
</ComponentBlock>

## Uso

<ComponentBlock for="Grid">

El componente `igx-paginator` se usa junto con el componente `igx-grid` en el ejemplo siguiente, pero puede usarse con cualquier otro componente si necesita la funcionalidad de paginación.

```html
<igx-grid #grid [data]="data">
    <igx-paginator #paginator [(page)]="grid.page" [totalRecords]="grid.totalRecords" [(perPage)]="10"
            [selectOptions]="selectOptions">
    </igx-paginator>
</igx-grid>
```

</ComponentBlock>

<ComponentBlock for="TreeGrid">

El componente `igx-paginator` se usa junto con el componente `igx-tree-grid` en el ejemplo siguiente, pero puede usarse con cualquier otro componente si necesita la funcionalidad de paginación.

```html
<igx-tree-grid #treeGrid [data]="data">
    <igx-paginator #paginator [(page)]="treeGrid.page" [totalRecords]="treeGrid.length" [(perPage)]="10"
            [selectOptions]="selectOptions">
    </igx-paginator>
</igx-tree-grid>
```

</ComponentBlock>

<ComponentBlock for="HierarchicalGrid">

El componente `igx-paginator` se usa junto con el componente `igx-hierarchical-grid` en el ejemplo siguiente, pero puede usarse con cualquier otro componente si necesita la funcionalidad de paginación.

```html
<igx-hierarchical-grid>
    <igx-column *ngFor="let c of hColumns" [field]="c.field">
    </igx-column>
    <igx-row-island [key]="'childData'" [autoGenerate]="true">
        <igx-row-island [key]="'childData'" [autoGenerate]="true">
            <igx-paginator *igxPaginator></igx-paginator>
        </igx-row-island>
        <igx-paginator *igxPaginator></igx-paginator>
    </igx-row-island>
    <igx-row-island [key]="'childData2'" [autoGenerate]="true">
        <igx-paginator *igxPaginator></igx-paginator>
    </igx-row-island>

    <igx-paginator></igx-paginator>
</igx-hierarchical-grid>
```

</ComponentBlock>

### Configuración del paginador dentro de los grids hijos

Debido a ciertas limitaciones en la forma en que se implementan los grids hijos de un IgxHierarchicalGrid y en cómo funciona el ámbito de DI, al definir un componente paginador dentro de las etiquetas igx-row-island, asegúrese siempre de usar la directiva IgxPaginator en el propio paginador. Así se garantiza que el grid hijo tenga la instancia de paginador correcta como referencia:

```html
<igx-hierarchical-grid>
    ...
    <igx-row-island>
        ...
        <igx-grid-toolbar *igxPaginator>
           ...
        </igx-grid-toolbar>
    </igx-row-island>
    ...
</igx-hierarchical-grid>
```

</ComponentBlock>

## Estilos

Para empezar a dar estilo al paginador, debemos importar el archivo `index`, donde se exportan todas las funciones de tema y el mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Siguiendo el enfoque más sencillo, creamos un tema nuevo que extiende <ApiLink kind="sass" module="themes" type="function-paginator-theme" label="paginator-theme" code={true} /> y acepta los parámetros `$foreground`, `$background`, `$border-color` y `$accent-color`.

```scss
$paginator-theme: paginator-theme(
  $foreground: #ff570f,
  $background: #130425FF,
  $border-color: #ff570f,
  $accent-color: #ff570f,
);
```

Después podemos **incluir** el tema recién creado.

```scss
igx-paginator {
  @include tokens($paginator-theme);
}
```
