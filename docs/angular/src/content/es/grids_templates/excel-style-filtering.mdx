## Uso

Para activar el filtrado de Excel de la cuadrícula, hay que establecer dos entradas. <ApiLink type="{ComponentApiType}" member="allowFiltering" label="allowFiltering" /> debe establecerse en `true` y <ApiLink type="{ComponentApiType}" member="filterMode" label="filterMode" /> debe establecerse en `excelStyleFilter`.

<ComponentBlock for="Grid">

```html
<igx-grid [data]="data" [autoGenerate]="true" [allowFiltering]="true" [filterMode]="'excelStyleFilter'">
</igx-grid>
```

</ComponentBlock>

## Interacciones

Para abrir el menú de filtro de una columna concreta, hay que hacer clic en el icono de filtro de Angular del encabezado. Además, puede usar la combinación `Ctrl + Shift + L` sobre un encabezado seleccionado. Si la columna puede ordenarse, anclarse, moverse, seleccionarse u ocultarse junto con la función de filtrado, aparecerán botones para las funciones que estén habilitadas.

Si no se aplica ningún filtro, se seleccionan todos los elementos de la lista. Pueden filtrarse desde el campo de entrada situado encima de la lista. Para filtrar los datos, puede seleccionar o deseleccionar los elementos de la lista y después hacer clic en el botón Aplicar, o pulsar `Enter`. El filtrado aplicado mediante los elementos de la lista crea expresiones de filtro con el operador `equals`, y el operador lógico entre las expresiones es <ApiLink kind="enum" type="FilteringLogic" member="Or" />.

Si escribe algo en el cuadro de búsqueda y aplica el filtro, solo se seleccionarán los elementos que coincidan con el criterio de búsqueda. Sin embargo, si quiere añadir elementos a los que ya están filtrados, debe seleccionar la opción `Add current selection to filter`.

Si quiere borrar el filtro, puede marcar la opción `Select All` y después hacer clic en el botón Aplicar.

Para aplicar un filtro con distintas expresiones, puede hacer clic en **Filtro de texto**, que abrirá un submenú con todos los operadores de filtro disponibles para la columna concreta. Al seleccionar uno de ellos se abrirá el cuadro de diálogo de filtro personalizado, donde puede añadir todas las expresiones que quiera con distintos operadores de filtro y lógicos. También hay un botón de borrar, que puede eliminar el filtro.

## Plantillas

Si quiere personalizar aún más el menú de filtro al estilo de Excel sin deshabilitar las funciones de las columnas, puede usar plantillas personalizadas. El menú de filtro al estilo de Excel proporciona dos directivas para crear plantillas:

- `IgxExcelStyleColumnOperationsTemplateDirective`: vuelve a crear la plantilla del área con todas las operaciones de columna, como ordenar, anclar, etc.
- `IgxExcelStyleFilterOperationsTemplateDirective`: vuelve a crear la plantilla del área con todas las operaciones específicas del filtro.

Puede volver a crear la plantilla de solo una de esas áreas o de ambas. Puede poner cualquier contenido personalizado dentro de esas directivas, o usar cualquiera de nuestros componentes integrados de filtrado al estilo de Excel.

El código siguiente muestra cómo definir un menú de filtro personalizado al estilo de Excel usando los componentes <ApiLink type="ExcelStyleHeader" />, <ApiLink type="ExcelStyleSorting" /> y <ApiLink type="ExcelStyleSearch" />.

## Salida externa

El {ComponentTitle} de [`z-index`](https://developer.mozilla.org/en-US/docs/Web/CSS/z-index) crea un contexto de apilamiento independiente para cada grid del DOM. Esto garantiza que todos los elementos descendientes del grid se rendericen como se pretende, sin solaparse entre sí.
Sin embargo, los elementos que salen fuera del grid (por ejemplo, el filtro al estilo de Excel) entrarán en conflicto con elementos externos que tengan el mismo `z-index` (por ejemplo, si hay dos grids uno debajo de otro), lo que provoca un renderizado incorrecto. La solución a este problema es establecer la propiedad <ApiLink type="{ComponentApiType}" member="outlet" label="outlet" /> en una directiva de salida externa, que permite que los elementos de superposición aparezcan siempre encima.

## Estilos

Para empezar a dar estilo al cuadro de diálogo de filtrado al estilo de Excel, debemos importar el archivo `index`, donde se exportan todas las funciones de tema y el mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Hay un par de formas de dar estilo al cuadro de diálogo de filtrado al estilo de Excel. Puede darle estilo usando <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />. El cuadro de diálogo de filtrado al estilo de Excel hereda los valores `$background`, `$foreground` y `$accent-color` definidos en <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />. También proporciona parámetros específicos para personalizar los colores del texto del cuadro de diálogo.

Como alternativa, puede usar <ApiLink kind="sass" module="themes" type="function-excel-filtering-theme" label="excel-filtering-theme" code={true} /> específico, que le permite dar estilo completo solo al cuadro de diálogo de filtrado al estilo de Excel.

El enfoque más sencillo es usar <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />:

```scss
$background: #292826;
$foreground: #eeece1;
$accent: #ffcd0f;

$custom-grid: grid-theme(
  $background: $background,
  $foreground: $foreground,
  $accent-color: $accent,
);
```

Los colores de fondo y de primer plano del cuadro de diálogo de filtrado al estilo de Excel se heredan del tema de la cuadrícula. Además, todos los componentes anidados, como botones y casillas, heredan el color de acento del tema de la cuadrícula.

Después, ya estamos listos para incluir el tema de la cuadrícula que acabamos de crear. Si queremos hacer cambios de estilo adicionales específicos del cuadro de diálogo de filtrado al estilo de Excel, podemos dirigirnos a él directamente:

```scss
:host {
    @include tokens($custom-grid);

    igx-grid-excel-style-filtering {
        --ig-excel-filtering-background: #444;
    }
}
```

<DocsAside type="info">
Este ejemplo usa `::ng-deep` porque tanto los selectores de tema generados como el selector directo del filtrado de Excel deben llegar a los elementos dentro de la vista de la cuadrícula. Mover las sobrescrituras a una hoja de estilos global es una alternativa.
</DocsAside>

```scss
:host ::ng-deep {
    @include tokens($custom-grid);

    igx-grid-excel-style-filtering {
        --ig-excel-filtering-background: #444;
    }
}
```
