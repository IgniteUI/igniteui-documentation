# Edición de {ComponentTitle} en Angular

El componente {ComponentTitle} de Ignite UI for Angular ofrece una forma sencilla de realizar operaciones de manipulación de datos, como crear, actualizar y eliminar registros. Las fases de manipulación de datos son: [Edición de celdas](/{igPath}/cell-editing), [Edición de filas](/{igPath}/row-editing) y [Edición por lotes](/{igPath}/batch-editing). El {ComponentTitle} ofrece una API pública potente que le permite personalizar la forma en que se realizan estas operaciones. Además, la **edición de celdas** expone varios editores predeterminados según el tipo de datos de la columna, que pueden personalizarse fácilmente mediante la directiva [igxCellEditor](/{igPath}/cell-editing#plantillas-de-edición-de-celdas) o las directivas [igxRow](/{igPath}/row-editing#personalizar-la-superposición-de-edición-de-filas).

## Configuración

Para especificar qué modo de edición debe habilitarse, el {ComponentTitle} expone las siguientes propiedades booleanas: <ApiLink type="Column" member="editable" label="editable" /> y <ApiLink type="Grid" member="rowEditable" label="rowEditable" />.

La propiedad **editable** le permite especificar las siguientes opciones:

- **false**: la edición de la columna correspondiente quedará deshabilitada; /valor predeterminado/
- **true**: la edición de la columna correspondiente quedará habilitada;

>Tenga en cuenta que, si la columna no es editable, aún puede modificar su valor mediante la API pública que expone {ComponentTitle}.

La propiedad **rowEditable** le permite especificar las siguientes opciones:

- **false**: la edición de filas en el grid correspondiente quedará deshabilitada; /valor predeterminado/
- **true**: la edición de filas en el grid correspondiente quedará habilitada;

En {ComponentTitle}, si establece la propiedad rowEditable en true y la propiedad editable no está definida explícitamente en ninguna columna, la edición quedará habilitada para todas las columnas excepto la _clave primaria_.

La **edición por lotes** de la cuadrícula puede habilitarse tanto para el modo de **edición de celdas** como para el de **edición de filas**. Para configurar la edición por lotes es necesario proporcionar a la cuadrícula un _TransactionService_.

- _Edición de celdas y por lotes_: en este escenario, cada modificación individual de cada celda se conserva por separado, y las operaciones de deshacer y rehacer están disponibles a nivel de celda;
- _Edición de filas y por lotes_: en este escenario, las modificaciones se conservan a nivel de fila, de modo que las operaciones de deshacer y rehacer no funcionarán para cada celda modificada, sino para el conjunto de celdas de cada fila.

### Plantillas de edición

 Si quiere usar _plantillas de edición_ específicas de un tipo de datos, debe especificar la propiedad <ApiLink type="Column" member="dataType" label="dataType" /> de la columna. Veamos ahora cuáles son las plantillas predeterminadas de cada tipo:

- Para el tipo de datos `string`, la plantilla predeterminada usa <ApiLink type="InputDirective" label="igxInput" />
- Para el tipo de datos `number`, la plantilla predeterminada usa <ApiLink type="InputDirective" label="igxInput" /> type="number", así que si intenta actualizar una celda con un valor que no puede interpretarse como número, su cambio se descartará y el valor de la celda se establecerá en 0.
- Para el tipo de datos `date`, la plantilla predeterminada usa <ApiLink type="DatePicker" label="igxDatePicker" />
- Para el tipo de datos `dateTime`, la plantilla predeterminada usa <ApiLink type="DateTimeEditorDirective" />. Este editor le ofrecerá indicaciones de máscara para los elementos de entrada que forman parte del objeto DateTime.
- Para el tipo de datos `date`, la plantilla predeterminada usa <ApiLink type="DatePicker" />.
- Para el tipo de datos `time`, la plantilla predeterminada usa <ApiLink type="TimePicker" />.
- Para el tipo de datos `boolean`, la plantilla predeterminada usa <ApiLink type="Checkbox" label="igxCheckbox" />
- Para el tipo de datos `currency`, la plantilla predeterminada usa <ApiLink type="InputGroup" /> con una configuración de prefijo/sufijo según la configuración regional de la aplicación o de la cuadrícula.
- Para el tipo de datos `percent`, la plantilla predeterminada usa <ApiLink type="InputGroup" /> con un elemento sufijo que muestra una vista previa del valor editado en porcentaje.
- Para plantillas personalizadas, puede consultar el tema [Edición de celdas](/{igPath}/cell-editing#plantillas-de-edición-de-celdas)

Todos los tipos de datos de columna disponibles se pueden consultar en el tema oficial [Tipos de columna](/{igPath}/column-types#plantilla-predeterminada).

#### Editores de plantilla predeterminada de las columnas de fecha y hora

Los editores de plantilla de los tipos de datos de columna `date`, `dateTime` y `time` usan un formato de entrada predeterminado según la `IgxGrid` <ApiLink type="Grid" member="locale" label="locale" />.

Si en la columna se establece la propiedad `format` del objeto <ApiLink kind="interface" type="ColumnType" member="pipeArgs" />, el formato de entrada de los editores se deducirá de ella. La condición es que pueda interpretarse como una cadena que contenga solo partes numéricas de fecha y hora.

Si el formato de entrada de los editores debe establecerse explícitamente, puede usarse el objeto <ApiLink kind="interface" type="ColumnType" member="editorOptions" /> de tipo <ApiLink type="IColumnEditorOptions" kind="interface" />. Acepta una propiedad `dateTimeFormat` que se usa como formato de entrada para los editores de los tipos de datos de columna `date`, `dateTime` y `time`.

```typescript
const editorOptions: IColumnEditorOptions = {
    dateTimeFormat: 'MM/dd/YYYY',
}
```

```html
<igx-column field="sampleDate" dataType="date" [editorOptions]="editorOptions"></igx-column>
```

### Argumentos del evento y secuencia

La cuadrícula expone una amplia variedad de eventos que ofrecen un mayor control sobre la experiencia de edición. Estos eventos se disparan durante el ciclo de vida de [**edición de filas**](/{igPath}/row-editing) y [**edición de celdas**](/{igPath}/cell-editing): al iniciar, confirmar o cancelar la acción de edición.

 | Evento | Descripción | Argumentos | Cancelable |
|-------|-------------|-----------|-------------|
| <ApiLink type="{ComponentApiType}" member="rowEditEnter" label="rowEditEnter" /> | Si `rowEditing` está habilitado, se dispara cuando una fila entra en modo de edición | <ApiLink type="IGridEditEventArgs" kind="interface" /> | `true` |
| <ApiLink type="{ComponentApiType}" member="cellEditEnter" label="cellEditEnter" /> | Se dispara cuando una celda **entra en modo de edición** (después de `rowEditEnter`) | <ApiLink type="IGridEditEventArgs" kind="interface" /> | `true` |
| <ApiLink type="{ComponentApiType}" member="cellEdit" label="cellEdit" /> | Si el valor cambia, se dispara justo **antes** de que el valor de una celda se **confirme** (por ejemplo, al pulsar `Enter`) | <ApiLink type="IGridEditEventArgs" kind="interface" /> | `true` |
| <ApiLink type="{ComponentApiType}" member="celleditdone" label="cellEditDone" /> | Si el valor cambia, se dispara **después** de que una celda se haya editado y el valor de la celda se haya **confirmado** | <ApiLink type="IGridEditDoneEventArgs" kind="interface" /> | `false` |
| <ApiLink type="{ComponentApiType}" member="cellEditExit" label="cellEditExit" /> | Se dispara cuando una celda **sale del modo de edición** | <ApiLink kind="interface" type="IGridEditEventArgs" /> | `false` |
| <ApiLink type="{ComponentApiType}" member="rowEdit" label="rowEdit" /> | Si `rowEditing` está habilitado, se dispara justo antes de que se **confirme** el valor de una fila en modo de edición (por ejemplo, al hacer clic en el botón `Done` de la superposición de edición de filas) | <ApiLink type="IGridEditEventArgs" kind="interface" /> | `true` |
| <ApiLink type="{ComponentApiType}" member="rowEditDone" label="rowEditDone" /> | Si `rowEditing` está habilitado, se dispara **después** de que una fila se haya editado y el nuevo valor de la fila se haya **confirmado**. | <ApiLink kind="interface" type="IGridEditEventArgs" /> | `false` |
| <ApiLink type="{ComponentApiType}" member="rowEditExit" label="rowEditExit" /> | Si `rowEditing` está habilitado, se dispara cuando una fila **sale del modo de edición** | <ApiLink kind="interface" type="IGridEditEventArgs" /> | `false` |

### Cancelación del evento

- `RowEditEnter`: ni la fila ni la celda entrarán en modo de edición.
- `CellEditEnter`: impide entrar en la edición de celdas. Si <ApiLink type="Grid" member="rowEditable" label="rowEditable" /> está habilitado, se activará la edición de filas, aunque la edición de celdas seguirá prohibida.
- `CellEdit`: se permite la edición de celdas o filas; al pulsar el botón **Hecho** o **Enter** no se confirma el valor ni la transacción de la fila. La edición de celdas y de filas no se cerrará hasta que se haga clic en el botón **Cancelar**.
- `RowEdit`: es posible confirmar la celda, pero no la fila completa. La fila permanecerá en modo de edición y la transacción de la fila se considerará abierta. Al pulsar **Hecho** no se confirma ni se cierra la fila. El botón **Cancelar** cierra el proceso de edición y la transacción sin confirmar los cambios.

### Integración de funciones

Mientras una celda o fila está en modo de edición, el usuario puede interactuar con la cuadrícula de muchas formas. La tabla siguiente indica cómo afecta una determinada interacción a la edición actual:

| {ComponentTitle}     | Filtrado  | Ordenación | Paginación | Movimiento | Anclaje | Ocultación | GroupBy | Redimensionamiento | Escape | Enter | F2 | Tabulador | Clic en celda | Añadir fila/Eliminar/Editar |
| ----------------- |:---------:|:-------:|:------:|:------:|:-------:|:------:|:-------:|:--------:|:------:|:-----:|:--:|:---:|:----------:|:-----------------------:|
| Mantener el modo de edición    |           |      |   |   |   |   |   | ✔ |   |   |   |   |   |   |
| Salir del modo de edición    |✔         | ✔ | ✔ | ✔ | ✔ | ✔ | ✔ |   | ✔ | ✔ | ✔ | ✔ | ✔ | ✔ |
| Confirmar            |   |   |  |  |  |   |   |   |  | ✔ | ✔ | ✔ | ✔ | ✔ |
| Descartar           | ✔ | ✔ | ✔ | ✔ | ✔ | ✔ |✔ |   | ✔  |  |   |   |   |  |

Como se ve en la tabla, todas las interacciones, excepto redimensionar una columna, terminarán la edición y descartarán los nuevos valores. Si quiere confirmar el nuevo valor, el desarrollador puede hacerlo en el evento "-ing" correspondiente de la función.

Ejemplo de cómo confirmar los nuevos valores si el usuario intenta ordenar la columna mientras una celda o fila está en modo de edición:

```html
<igx-grid #grid [data]="localData" [primaryKey]="'ProductID'" (sorting)="onSorting($event)">
...
</igx-grid>
```

```typescript
public onSorting(event: ISortingEventArgs) {
    this.grid.endEdit(true);
    // (event.owner as IgxGridComponent).endEdit(true);
}
```
