# Combinación de celdas en Angular

El {ComponentTitle} de Ignite UI for Angular ofrece una función de combinación de celdas que une dos o más celdas adyacentes con el mismo valor en una única celda más grande. La combinación se aplica verticalmente dentro de una columna y ayuda a mejorar la legibilidad al reducir los valores duplicados. La función puede configurarse para combinar celdas según los valores de datos coincidentes predeterminados o aplicando una condición personalizada.

## Habilitar y usar la combinación de celdas

La combinación de celdas en la cuadrícula se controla en dos niveles:

- Modo de combinación a nivel de grid: determina cuándo se aplica la combinación.
- Interruptor de combinación a nivel de columna: determina qué columnas pueden combinar celdas.

### Modo de combinación del grid

El grid expone una propiedad `cellMergeMode` que acepta valores de la enumeración `GridCellMergeMode`:

- `always`: combina cualquier celda adyacente que cumpla la condición de combinación, independientemente del estado de ordenación.
- `onSort`: combina celdas adyacentes solo cuando la columna está ordenada **(valor predeterminado)**.

```html
<{ComponentSelector} [data]="data" [cellMergeMode]="cellMergeMode">
    ...
</{ComponentSelector}>
```

```ts
protected cellMergeMode: GridCellMergeMode = 'always';
```

### Interruptor de combinación de columna

A nivel de columna, la combinación puede habilitarse o deshabilitarse con la propiedad `merge`.

```html
<igx-column field="OrderID" [merge]="true"></igx-column>
<igx-column field="ShipperName" [merge]="false"></igx-column>
```

En el ejemplo anterior:

- La columna **OrderID** combinará los valores duplicados adyacentes.
- La columna **ShipperName** se mostrará normalmente, sin combinar.

### Ejemplo combinado

```html
<{ComponentSelector} [data]="data" [cellMergeMode]="cellMergeMode" [autoGenerate]="false">
    <igx-column field="OrderID" header="Order ID" [merge]="true"></igx-column>
    <igx-column field="ShipperName" header="Shipper Name" [merge]="true"></igx-column>
    <igx-column field="Salesperson" header="Salesperson"></igx-column>
</{ComponentSelector}>
```

```ts
protected cellMergeMode: GridCellMergeMode = 'onSort';
```

Aquí, el grid está configurado para combinar solo cuando las columnas están ordenadas, y tanto la columna Category como la columna Product están configuradas para combinarse.

## Condiciones de combinación personalizadas

Además de los modos integrados `always` y `onSort`, el grid le permite definir una condición personalizada para combinar celdas mediante la propiedad `mergeStrategy`. Esta estrategia controla tanto cómo se comparan las celdas como cómo se calculan los rangos combinados.

### Interfaz de estrategia de combinación

Una estrategia de combinación personalizada debe implementar la interfaz `IGridMergeStrategy`:

```ts
export interface IGridMergeStrategy {
    merge: (
        data: any[],
        field: string,
        comparer: (prevRecord: any, currentRecord: any, field: string) => boolean,
        result: any[],
        activeRowIndex?: number,
        grid?: GridType
    ) => any[];

    comparer: (prevRecord: any, record: any, field: string) => boolean;    
}
```

- `merge`: define cómo se producen las celdas combinadas.
- `comparer`: define la condición para decidir si dos registros adyacentes deben combinarse.

### Extender la estrategia predeterminada

Si solo quiere personalizar una parte del comportamiento (por ejemplo, la lógica del comparador), puede extender `DefaultMergeStrategy` integrada y sobrescribir los métodos correspondientes.

```ts
export class MyCustomStrategy extends DefaultMergeStrategy {
    /* Merge only cells within their respective projects */
    public override comparer(prevRecord: any, record: any, field: string): boolean {
        const a = prevRecord[field];
        const b = record[field];
        const projA = prevRecord['ProjectName'];
        const projB = record['ProjectName'];
        return a === b && projA === projB;
    }
}
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">


`IgxTreeGrid` proporciona dos estrategias integradas que implementan la interfaz `IGridMergeStrategy`: `DefaultTreeGridMergeStrategy` y `ByLevelTreeGridMergeStrategy`. `DefaultTreeGridMergeStrategy` combina todas las celdas con el mismo valor, independientemente de su nivel jerárquico. En cambio, `ByLevelTreeGridMergeStrategy` solo combina celdas si tienen el mismo valor y están en el mismo nivel, por lo que el nivel es una condición obligatoria para combinar.

### Extender la estrategia predeterminada

Si solo quiere personalizar una parte del comportamiento (por ejemplo, la lógica del comparador), puede extender una de las estrategias integradas, `DefaultTreeGridMergeStrategy` o `ByLevelTreeGridMergeStrategy`, y sobrescribir los métodos correspondientes.

```ts
export class MyCustomStrategy extends DefaultTreeGridMergeStrategy {
    /* Merge only cells within their respective projects */
    public override comparer(prevRecord: any, record: any, field: string): boolean {
        const a = prevRecord[field];
        const b = record[field];
        const projA = prevRecord['ProjectName'];
        const projB = record['ProjectName'];
        return a === b && projA === projB;
    }
}
```

</ComponentBlock>

### Aplicar una estrategia personalizada

Una vez definida, asigne la estrategia a la cuadrícula mediante la propiedad `mergeStrategy`:

```html
<{ComponentSelector} [data]="data" [mergeStrategy]="customStrategy">
  <igx-column field="ActionID" [merge]="true"></igx-column>
  <igx-column field="ProjectName" [merge]="true"></igx-column>
</{ComponentSelector}>
```

```ts
protected customStrategy = new MyCustomStrategy();
```

## Integración de funciones

Debido al comportamiento específico de las celdas combinadas, conviene tener en cuenta cómo se relaciona exactamente con algunas de las demás funciones de la cuadrícula:
<ComponentBlock for="Grid">


- **Expandir/contraer**: si una función (como detalle maestro, agrupación, etc.) genera una fila que no es de datos, la combinación de celdas se interrumpe y el grupo se divide.
</ComponentBlock>
- **Exportación a Excel**: las celdas combinadas siguen combinadas al exportarse a Excel.
- **Anclaje de columnas**: las celdas siguen combinadas cuando una columna está anclada y se muestran en el área anclada.
- **Anclaje de filas**: las celdas solo se combinan dentro de su área contenedora; es decir, las celdas de las filas ancladas solo se combinan con las celdas de otras filas ancladas, mientras que las celdas de las filas no ancladas solo se combinan con las celdas de filas no ancladas.
- **Navegación/activación**: cuando una celda está activa, todas las celdas combinadas de la misma fila se convierten en celdas individuales, es decir, se rompe su secuencia de combinación. Esto incluye también la activación mediante la navegación por teclado.

<DocsAside type="info">
Si se hace clic en una celda combinada, la celda más cercana de la secuencia de combinación pasa a estar activa.
</DocsAside>

- **Actualización/edición**: como la activación rompe la secuencia de combinación, solo una celda estará en modo de edición.
- **Selección de filas**: si las filas seleccionadas intersecan celdas combinadas, todas las celdas combinadas relacionadas deben marcarse como parte de la selección.
