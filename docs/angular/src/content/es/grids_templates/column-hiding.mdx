# Ocultar columnas de {ComponentTitle} en Angular

El {ComponentTitle} de Ignite UI for Angular incluye un <ApiLink type="ColumnActions" /> con un <ApiLink type="ColumnHidingDirective" /> que permite a los usuarios ocultar columnas directamente desde la interfaz de usuario o mediante el componente de Angular. El Material UI Grid tiene una interfaz integrada para ocultar columnas, que puede usarse desde la barra de herramientas de {ComponentTitle} para cambiar el estado de visibilidad de las columnas. Además, los desarrolladores siempre pueden definir la interfaz de ocultación de columnas como un componente independiente y colocarlo donde quieran en la página.

## Interfaz de ocultar columnas de la barra de herramientas

La interfaz integrada para ocultar columnas se coloca dentro de un <ApiLink type="DropDown" /> en la barra de herramientas de {ComponentTitle}. Podemos mostrar u ocultar la interfaz de ocultar columnas usando precisamente este desplegable.
Para ello, solo tenemos que establecer <ApiLink type="GridToolbarActions" /> y <ApiLink type="GridToolbarHiding" /> dentro de {ComponentTitle}. También añadiremos un título a nuestra barra de herramientas con <ApiLink type="GridToolbarTitle" /> y un estilo personalizado para el contenedor de {ComponentTitle}.

## Interfaz personalizada de ocultar columnas

Supongamos que queremos definir manualmente nuestro <ApiLink type="ColumnActions" />, añadir <ApiLink type="ColumnHidingDirective" /> para que sepa cuál es su finalidad y colocarlo en cualquier parte de la página. Primero, sin embargo, debemos importar `IgxColumnActionsModule`.

```typescript
// app.module.ts

...

    ...
    IgxColumnActionsModule 
} from 'igniteui-angular/grids/core';
// import { ..., IgxColumnActionsModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxColumnActionsModule],
})
export class AppModule {}
```

Ahora creemos nuestro <ApiLink type="ColumnActions" />. En nuestra aplicación lo colocaremos junto a la cuadrícula (algo que no ocurre con la interfaz de ocultar columnas de la barra de herramientas, donde el componente está dentro de un desplegable por diseño). También estableceremos la propiedad <ApiLink type="ColumnActions" member="columns" label="columns" /> del componente con las columnas de nuestro {ComponentTitle} e incluiremos algunos estilos personalizados para que nuestra aplicación se vea aún mejor.

### Añadir título y texto de ayuda del filtro

Hay un par de cosas más que podemos hacer para enriquecer la experiencia de usuario de nuestro componente de ocultar columnas: establecer las propiedades <ApiLink type="ColumnActions" member="title" label="title" /> y <ApiLink type="ColumnActions" member="filtercolumnsprompt" label="filterColumnsPrompt" />. <ApiLink type="ColumnActions" member="title" label="title" /> se muestra en la parte superior, y <ApiLink type="ColumnActions" member="filterColumnsPrompt" label="filterColumnsPrompt" /> es el texto de ayuda que aparece en el campo de filtro de nuestra interfaz de ocultar columnas.

```html
<!--columnHiding.component.html-->

<div class="columnHidingContainer">
    <igx-column-actions igxColumnHiding #columnHidingUI [columns]="{ComponentObjectRef}.columns"
                       title="Column Hiding" filterColumnsPrompt="Type here to search">
    </igx-column-actions>
</div>
```

### Añadir opciones de orden de visualización de columnas

También podemos permitir que el usuario elija el orden de visualización de las columnas en la interfaz de ocultar columnas. Para ello usaremos la propiedad <ApiLink type="ColumnActions" member="columnDisplayOrder" label="columnDisplayOrder" />, que es de tipo enumeración y tiene las siguientes opciones:

- **Alphabetical** (ordena las columnas alfabéticamente)
- **DisplayOrder** (ordena las columnas según la forma en que se muestran en {ComponentTitle})

¡Creemos un par de botones de opción bien diseñados para nuestras opciones! Solo tenemos que importar el módulo [**IgxRadio**](/inputs/radio).

```typescript
// app.module.ts

...

    ...
    IgxRadioModule    
} from 'igniteui-angular/radio';
// import { ..., IgxRadioModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxRadioModule],    
})
export class AppModule {}
```

Ahora solo tenemos que enlazar la propiedad <ApiLink type="Radio" member="checked" label="checked" /> de ambos botones de opción con condiciones distintas y gestionar sus eventos de clic.

```html
<!--columnHiding.component.html-->

<div class="columnHidingContainer">
    ...
    <div class="columnsOrderOptionsContainer">
        <igx-radio [checked]="columnHidingUI.columnDisplayOrder === 'Alphabetical'"
                   (click)="columnHidingUI.columnDisplayOrder = 'Alphabetical'">
            Alphabetical order
        </igx-radio>
        <igx-radio [checked]="columnHidingUI.columnDisplayOrder === 'DisplayOrder'"
                   (click)="columnHidingUI.columnDisplayOrder = 'DisplayOrder'">
            Display order
        </igx-radio>
    </div>
</div>
```

## Estilos

Para empezar a dar estilo al componente de acciones de columna, debemos importar el archivo index, donde se exportan todas las funciones de tema y el mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Usando el enfoque más sencillo, creamos un tema nuevo que extiende <ApiLink kind="sass" module="themes" type="function-column-actions-theme" label="column-actions-theme" code={true} /> y acepta los parámetros `$title-color` y `$background-color`.

```scss
$custom-column-actions-theme: column-actions-theme(
  $background-color: #292826,
  $title-color: #ffcd0f
);
```

Como se ve, `column-actions-theme` solo controla los colores del contenedor de acciones de columna, pero no afecta a los botones, las casillas ni el grupo de entrada que contiene. Supongamos que queremos dar estilo también a los botones, así que crearemos un nuevo tema de botón:

```scss
$custom-button: flat-button-theme(
  $foreground: #292826, 
  $disabled-foreground: rgba(255, 255, 255, .54)
);
```

<DocsAside type="info">
En lugar de codificar los valores de color como acabamos de hacer, podemos lograr más flexibilidad con los colores usando las funciones <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> y <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Consulte el tema [`Palettes`](/themes/sass/palettes) para obtener orientación detallada sobre cómo usarlas.
</DocsAside>

En este ejemplo solo hemos cambiado el color de texto de los botones planos y el color de los botones deshabilitados, pero <ApiLink kind="sass" module="themes" type="function-flat-button-theme" label="flat-button-theme" code={true} /> ofrece muchos más parámetros para controlar el estilo de los botones.

El último paso es aplicar el tema de cada componente con `tokens()`:

```scss
:host {
  @include tokens($custom-column-actions-theme);
  
  .igx-column-actions {
    @include tokens($custom-button);
  }
}
```

<DocsAside type="info">
Incluimos el **flat-button-theme** creado dentro de `.igx-column-actions`, de modo que solo se den estilo los botones de ocultar columnas. De lo contrario, otros botones del grid también se verían afectados.
</DocsAside>

<DocsAside type="info">
En algunas plantillas de componentes, el encapsulado de vista emulado puede impedir que las declaraciones de tokens generadas lleguen a los elementos anidados de Ignite UI. Si el tema no surte efecto, use `::ng-deep` como se muestra a continuación o traslade el tema a una hoja de estilos global.
</DocsAside>

```scss
:host {
  @include tokens($custom-column-actions-theme);

  ::ng-deep {
    .igx-column-actions {
      @include tokens($custom-button);
    }
  }
}
```
