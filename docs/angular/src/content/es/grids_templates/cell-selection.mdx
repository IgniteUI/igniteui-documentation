# Selección de celdas en Angular

La función de selección permite funciones avanzadas de selección de datos en el {ComponentTitle} basado en Material UI. Hay disponibles diversas acciones de eventos y de selección única gracias a una API potente y a métodos fáciles de usar. El {ComponentTitle} admite ahora tres modos de selección de celdas, y puede cambiar fácilmente entre ellos modificando la propiedad <ApiLink type="Grid" member="cellSelection" label="cellSelection" />. Puede desactivar la selección de celdas, puede _seleccionar solo una celda dentro del grid_ o _seleccionar varias celdas del grid_, que es la opción predeterminada.
<ComponentBlock for="HierarchicalGrid">
 En Hierarchical Grid puede especificar el modo de selección de celdas a nivel de grid. Por ejemplo, en el grid padre puede habilitarse la selección de varias celdas, mientras que en los grids hijos el modo de selección de celdas puede ser único o estar deshabilitado. </ComponentBlock>Pero profundicemos en cada una de estas opciones.

## Tipos de selección

### {ComponentTitle} Selección de varias celdas

<ComponentBlock for="HierarchicalGrid">

Este es el modo predeterminado de selección de celdas tanto en el grid padre como en los hijos. Tenga en cuenta que solo puede hacer la selección de celdas en un grid cada vez; no puede hacer selecciones de rango entre grids ni tener celdas seleccionadas en varios grids. Cada combinación de teclas relacionada con la selección por rango y la funcionalidad de arrastre con el ratón solo puede usarse dentro del mismo grid.
</ComponentBlock>
Cómo seleccionar celdas:

- Con `Mouse drag`: se realizará una selección rectangular de datos de celdas.
- Con `Ctrl key` pulsado + `Mouse drag`: se realizarán varias selecciones de rango. Cualquier otra selección de celdas existente se conservará.
- Selección instantánea de varias celdas usando la tecla Shift. Seleccione una celda y luego otra celda manteniendo pulsada la tecla Shift. Se seleccionará el rango de celdas entre las dos. Tenga en cuenta que si se selecciona una segunda celda mientras se mantiene pulsado `Shift key`, el rango de selección de celdas se actualizará según la posición de la primera celda seleccionada (punto de inicio).
- Selección de varias celdas con el teclado usando `Arrow keys` mientras se mantiene pulsado `Shift key`. El rango de selección de varias celdas se creará a partir de la celda enfocada.
- Selección de varias celdas con el teclado usando `Ctrl + Arrow keys` y `Ctrl + Home/End` mientras se mantiene pulsado `Shift key`. El rango de selección de varias celdas se creará a partir de la celda enfocada.
- Hacer clic con `Left Mouse key` mientras se mantiene pulsado `Ctrl key` añadirá rangos de una sola celda a la colección de celdas seleccionadas.
- También está disponible la selección continua de varias celdas, haciendo clic con el ratón y arrastrando.

### {ComponentTitle} Selección única

Al establecer `[cellSelection]="'single'"`, solo puede haber una celda seleccionada en la cuadrícula a la vez. Además, el modo `mouse drag` no funcionará y, en lugar de seleccionar una celda, se hará la selección de texto predeterminada.

<DocsAside type="info">
Cuando se selecciona una sola celda, se emite el evento <ApiLink type="Grid" member="selected" label="selected" />, independientemente de si `selection mode` es `single` o `multiple`. En el modo de selección de varias celdas, cuando selecciona un rango de celdas se emite el evento <ApiLink type="Grid" member="rangeSelected" label="rangeSelected" />.
</DocsAside>

### {ComponentTitle} Sin selección

Si quiere desactivar la selección de celdas, basta con establecer la propiedad `[cellSelection]="'none'"`. En este modo, cuando hace clic en la celda o intenta navegar con el teclado, la celda **no se selecciona**; solo se aplica el `activation style`, que se perderá al desplazarse o al hacer clic en otro elemento de la página. La única forma de definir la selección es usando los métodos de la API que se describen a continuación.

## Interacciones de navegación por teclado

### Mientras se pulsa la tecla Shift

- <kbd>Shift</kbd> + <kbd>Arrow Up</kbd> para añadir la celda de arriba a la selección actual.
- <kbd>Shift</kbd> + <kbd>Arrow Down</kbd> para añadir la celda de abajo a la selección actual.
- <kbd>Shift</kbd> + <kbd>Arrow Left</kbd> para añadir la celda de la izquierda a la selección actual.
- <kbd>Shift</kbd> + <kbd>Arrow Right</kbd> para añadir la celda de la derecha a la selección actual.

### Mientras se pulsan las teclas Ctrl + Shift

- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Arrow Up</kbd> para seleccionar todas las celdas situadas encima de la celda enfocada en la columna.
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Arrow Down</kbd> para seleccionar todas las celdas situadas debajo de la celda enfocada en la columna.
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Arrow Left</kbd> para seleccionar todas las celdas hasta el inicio de la fila.
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Arrow Right</kbd> para seleccionar todas las celdas hasta el final de la fila.
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Home</kbd> para seleccionar todas las celdas desde la celda enfocada hasta la primera celda de la cuadrícula
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>End</kbd> para seleccionar todas las celdas desde la celda enfocada hasta la última celda de la cuadrícula

<DocsAside type="info">
El desplazamiento continuo solo es posible dentro del cuerpo del Grid.
</DocsAside>

<ComponentBlock for="HierarchicalGrid">

<ApiLink type="HierarchicalGrid" member="selectRange" label="selectRange(range)" />: selecciona un rango de celdas con la API. `rowStart` y `rowEnd` deben usar índices de fila, y `columnStart` y `columnEnd` pueden usar el índice de columna o el valor del campo de datos de la columna.

```typescript

this.grid1.selectRange(range);

```

<DocsAside type="info">
Seleccionar un rango es una operación aditiva. No borra la selección anterior.
</DocsAside>

## Integración de funciones

La selección de varias celdas se basa en índices (selección de elementos del DOM).

- `Sorting`: al ordenar, la selección no se borra. Las celdas seleccionadas se mantienen al ordenar de forma ascendente o descendente.
- `Paging`: al paginar, las celdas seleccionadas se borran. La selección no se conserva entre páginas.
- `Filtering`: al filtrar, la selección no se borra. Si se borra el filtro, vuelven a aparecer las celdas seleccionadas inicialmente.
- `Resizing`: al redimensionar columnas, las celdas seleccionadas no se borran.
- `Hiding`: no borra las celdas seleccionadas. Si la columna se oculta, se seleccionarán las celdas de la siguiente columna visible.
- `Pinning`: la celda seleccionada no se borra. Igual que al ocultar.
- `Group by`: al agrupar columnas, las celdas seleccionadas no se borran.

</ComponentBlock>

## Estilos

El motor de temas expone propiedades que nos permiten dar estilo al **rango de celdas seleccionadas**.

### Importar el tema

Para empezar a dar estilo a la selección, debemos importar el archivo `index`, donde se exportan todas las funciones de tema y el mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### Definir los colores

Una vez hecho esto, podemos usar las funciones <ApiLink kind="sass" module="palettes" type="function-contrast-color" label="contrast-color" code={true} /> y <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Con ellas definimos los colores que queremos usar para el rango de selección:

```scss
$text-color: contrast-color($color: 'primary', $variant: 900);
$background-color: color($color: "primary", $variant: 900);
$border-yellow: #f2c43c;
```

<DocsAside type="info">
Si no queremos usar las funciones `contrast-color` y `color`, siempre podemos fijar los valores de color directamente.
</DocsAside>

### Crear un tema personalizado

A continuación creamos un tema nuevo que extiende <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />, pasando nuestras variables `text-color`, `background-color` y `border-yellow` como `$cell-selected-text-color`, `$cell-selected-background` y `$cell-active-border-color`, respectivamente:

```scss
$custom-grid-theme: grid-theme(
  $cell-selected-text-color: $text-color,
  $cell-active-border-color: $border-yellow,
  $cell-selected-background: $background-color
);
```

### Aplicar el tema

Después, solo tenemos que incluir el mixin en el estilo de nuestro componente (también puede estar en los estilos de la aplicación), para que nuestro {ComponentSelector} use el tema recién creado en lugar del predeterminado:

```scss
:host {
  @include tokens($custom-grid-theme);
}
```

Con el tema personalizado aplicado, las celdas seleccionadas de la cuadrícula se resaltan con nuestros colores de selección:
