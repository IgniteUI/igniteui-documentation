# Tamaño de {ComponentTitle} en Angular

El diseño de **{ComponentName}** se basa en las [guías de Material Design](https://material.io/design). Actualmente ofrecemos la opción de elegir entre un conjunto predefinido de tamaños que dan lugar a una vista pequeña, mediana o grande, respectivamente. Al elegir el tamaño adecuado para su tabla o grid de Material UI puede mejorar notablemente la experiencia del usuario al interactuar con grandes cantidades de contenido.

## Uso

Como puede ver en la demostración anterior, <ApiLink type="{ComponentApiType}" /> ofrece tres opciones de tamaño: **small**, **medium** y **large**. El fragmento de código siguiente muestra cómo establecer el tamaño:

```html
<{ComponentSelector} #{ComponentObjectRef} [data]="data" style="--ig-size: var(--ig-size-small)">
</{ComponentSelector}>
```

Y ahora veamos en detalle cómo se refleja cada opción en el componente {ComponentTitle}. Al cambiar entre distintos tamaños, cambian la altura de cada elemento {ComponentTitle} y los rellenos correspondientes. Además, si quiere aplicar un <ApiLink type="Column" member="width" label="**width**" /> de columna personalizado, tenga en cuenta que debe ser mayor que la suma de los rellenos izquierdo y derecho.

- **--ig-size-large**: es el tamaño {ComponentTitle} predeterminado, con la menor intensidad y una altura de fila igual a `50px`. Los rellenos izquierdo y derecho son `24px`; el <ApiLink type="Column" member="width" label="width" /> mínimo de columna es `80px`;
- **--ig-size-medium**: es el tamaño intermedio, con una altura de fila de `40px`. Los rellenos izquierdo y derecho son `16px`; el <ApiLink type="Column" member="width" label="width" /> mínimo de columna es `64px`;
- **--ig-size-small**: es el tamaño más pequeño, con una altura de fila de `32px`. Los rellenos izquierdo y derecho son `12px`; el <ApiLink type="Column" member="width" label="width" /> mínimo de columna es `56px`;

<DocsAside type="info">
Tenga en cuenta que actualmente **no puede** sobrescribir ninguno de los tamaños.
</DocsAside>

Continuemos con nuestro ejemplo y veamos en acción cómo se aplica cada tamaño. Primero, añadamos un botón que nos ayude a cambiar entre cada tamaño:

```html
<div class="density-chooser">
    <igx-buttongroup [values]="sizes"></igx-buttongroup>
</div>
```

```typescript
@ViewChild(IgxButtonGroupComponent) public buttonGroup: IgxButtonGroupComponent;
public size = 'small';
public sizes;

public ngOnInit() {
    this.sizes = [
        {
            label: 'small',
            selected: this.size === 'small',
            togglable: true
        },
        {
            label: 'medium',
            selected: this.size === 'medium',
            togglable: true
        },
        {
            label: 'large',
            selected: this.size === 'large',
            togglable: true
        }
    ];
}
```

Por último, proporcionemos la lógica necesaria para aplicar realmente el tamaño:

```typescript
@ViewChild('{ComponentObjectRef}', { read: {ComponentName}Component })
public {ComponentObjectRef}: {ComponentName}Component;

public selectSize(event: any) {
    this.size = this.sizes[event.index].label;
}

@HostBinding('style.--ig-size')
protected get sizeStyle() {
    return `var(--ig-size-${this.size})`;
}
```

Otra opción que <ApiLink type="{ComponentApiType}" /> le ofrece para poder cambiar la altura de las filas de {ComponentTitle} es la propiedad <ApiLink type="{ComponentApiType}" member="rowheight" label="rowHeight" />. Veamos en acción cómo afecta esta propiedad a la disposición de {ComponentTitle} junto con la variable CSS `--ig-size`.

Tenga en cuenta lo siguiente:

- La variable CSS `--ig-size` **NO** tendrá ningún efecto en la altura de la fila **si se especifica <ApiLink type="{ComponentApiType}" member="rowheight" label="rowHeight" />**;
- `--ig-size` **afectará a todos los demás elementos de {ComponentTitle}**, como se ha descrito antes;

Y ahora podemos ampliar nuestro ejemplo y añadir la propiedad <ApiLink type="{ComponentApiType}" member="rowHeight" label="rowHeight" /> a {ComponentTitle}:

 ```html
 <{ComponentSelector} #{ComponentObjectRef} [data]="data" [rowHeight]="'80px'" width="100%" 
 height="550px" [allowFiltering]="true">
 ..............
 </{ComponentSelector}>
 ```
