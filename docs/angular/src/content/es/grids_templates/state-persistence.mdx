# Persistencia del estado de {ComponentTitle} en Angular

La directiva igxGridState permite a los desarrolladores guardar y restaurar fácilmente el estado de la cuadrícula. Cuando la directiva <ApiLink type="GridStateDirective" /> se aplica a la cuadrícula, expone los métodos <ApiLink type="GridStateDirective" member="getState" label="getState" /> y <ApiLink type="GridStateDirective" member="setState" label="setState" />, que los desarrolladores pueden usar para lograr la persistencia del estado en cualquier escenario.

## Uso

<ApiLink type="GridStateDirective" member="getState" label="getState" />: este método devuelve el estado de la cuadrícula en una cadena JSON serializada, para que los desarrolladores puedan guardarla en cualquier almacenamiento de datos (base de datos, nube, localStorage del navegador, etc.). El método acepta como primer parámetro opcional `serialize`, que determina si <ApiLink type="GridStateDirective" member="getState" label="getState" /> devolverá un objeto <ApiLink type="IGridState" kind="interface" /> o una cadena JSON serializada.
El desarrollador puede optar por obtener solo el estado de una o varias funciones, pasando el nombre de la función, o un array con los nombres de las funciones como segundo argumento.

```typescript
// get all features` state in a serialized JSON string
const gridState = state.getState();

// get an `IGridState` object, containing all features original state objects, as returned by the grid public API
const gridState: IGridState = state.getState(false);

// get the sorting and filtering expressions
const sortingFilteringStates: IGridState = state.getState(false, ['sorting', 'filtering']);
```

<ApiLink type="GridStateDirective" member="setState" label="setState" />: el método <ApiLink type="GridStateDirective" member="setState" label="setState" /> acepta como argumento la cadena JSON serializada o el objeto <ApiLink type="IGridState" kind="interface" /> y restaurará el estado de cada función encontrada en el objeto o en la cadena JSON.

```typescript
state.setState(gridState);
state.setState(sortingFilteringStates)
```

`options`: el objeto <ApiLink type="GridStateDirective" member="options" label="options" /> implementa la interfaz <ApiLink type="IGridStateOptions" kind="interface" />, es decir, para cada clave, que es el nombre de una función, hay un valor booleano que indica si el estado de esa función se rastreará. El método <ApiLink type="GridStateDirective" member="getState" label="getState" /> no incluirá el estado de estas funciones en el valor devuelto, y el método <ApiLink type="GridStateDirective" member="setState" label="setState" /> no restaurará su estado.

```typescript
public options =  { cellSelection: false; sorting: false; }
```

La API de un único punto, sencilla de usar, permite lograr una persistencia completa del estado con unas pocas líneas de código. **Copie y pegue el código de abajo**: guardará el estado del grid en el objeto `sessionStorage` del navegador cada vez que el usuario abandone la página actual. Cada vez que el usuario vuelva a la página principal, el estado del grid se restaurará. Ya no es necesario configurar cada vez las expresiones complejas de filtrado y ordenación avanzadas para obtener los datos que desea; hágalo una vez y deje que el código de abajo haga el resto para sus usuarios:

```typescript
// app.component.ts
@ViewChild(IgxGridStateDirective, { static: true })
public state!: IgxGridStateDirective;

public ngOnInit() {
    this.router.events.pipe(take(1)).subscribe((event: NavigationStart) => {
        this.saveGridState();
    });
}

public ngAfterViewInit() {
    this.restoreGridState();
}

public saveGridState() {
    const state = this.state.getState() as string;
    window.sessionStorage.setItem('grid1-state', state);
}

public restoreGridState() {
    const state = window.sessionStorage.getItem('grid1-state');
    this.state.setState(state);
}
```

## Restaurar columnas

Cuando es posible, la directiva de estado reutiliza las columnas que ya existen en la cuadrícula al restaurar el estado, en lugar de crear nuevas instancias de columna. El único escenario en el que se creará una nueva instancia es cuando la columna (o sus hijos, en el caso de grupos de columnas) no tiene la propiedad `field`, por lo que no hay forma de identificar de manera única la columna correspondiente y reutilizarla.

Para esos escenarios se aplican las siguientes [`limitations`](/{igPath}/state-persistence#limitaciones). En ese caso, la restauración de objetos complejos puede lograrse con código a nivel de aplicación. Veamos cómo hacerlo para las columnas con plantilla:

1. Defina una variable de referencia de plantilla (en el ejemplo siguiente es `#activeTemplate`) y asigne un controlador de evento para el evento <ApiLink type="Grid" member="columnInit" label="columnInit" />:
<ComponentBlock for="Grid">

```html
<igx-grid id="grid" #grid igxGridState (columnInit)="onColumnInit($event)">
    <igx-column [field]="'IsActive'" header="IsActive">
        <ng-template igxCell #activeTemplate let-column let-val="val">
            <igx-checkbox [checked]="val"></igx-checkbox>
        </ng-template>
    </igx-column>
    ...
</igx-grid>
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```html
<igx-hierarchical-grid id="grid" #grid igxGridState (columnInit)="onColumnInit($event)">
    <igx-column [field]="'IsActive'" header="IsActive">
        <ng-template igxCell #activeTemplate let-column let-val="val">
            <igx-checkbox [checked]="val"></igx-checkbox>
        </ng-template>
    </igx-column>
    ...
</igx-hierarchical-grid>
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```html
<igx-tree-grid id="grid" #grid igxGridState (columnInit)="onColumnInit($event)">
    <igx-column [field]="'IsActive'" header="IsActive">
        <ng-template igxCell #activeTemplate let-column let-val="val">
            <igx-checkbox [checked]="val"></igx-checkbox>
        </ng-template>
    </igx-column>
    ...
</igx-tree-grid>
```

</ComponentBlock>
2. Consulte la vista de plantilla en el componente usando el decorador @ViewChild o @ViewChildren. En el controlador del evento <ApiLink type="Grid" member="columnInit" label="columnInit" />, asigne la plantilla a la propiedad `bodyTemplate` de la columna:

```typescript
@ViewChild('activeTemplate', { static: true }) public activeTemplate: TemplateRef<any>;
public onColumnInit(column: IgxColumnComponent) {
    if (column.field === 'IsActive') {
        column.bodyTemplate = this.activeTemplate;
        column.summaries = MySummary;
        column.filters = IgxNumberFilteringOperand.instance();
    }
}
```

## Restaurar la configuración de pivot

<ApiLink type="GridStateDirective" /> no conserva de forma predeterminada las funciones de dimensión de pivot, los formateadores de valores, etc. (véase [`limitations`](/{igPath}/state-persistence#limitaciones)). Restaurar cualquiera de ellos puede lograrse con código a nivel de aplicación. El `IgxPivotGrid` expone dos eventos que pueden usarse para volver a establecer cualquier función personalizada que tenga en la configuración: <ApiLink type="{ComponentApiType}" member="dimensionInit" label="dimensionInit" /> y <ApiLink type="{ComponentApiType}" member="valueInit" label="valueInit" />. Veamos cómo hacerlo:

- Asigne controladores de evento para los eventos `dimensionInit` y `valueInit`:

```html
<igx-pivot-grid #grid1 [data]="data" [pivotConfiguration]="pivotConfig" [igxGridState]="options"
    (valueInit)='onValueInit($event)' (dimensionInit)='onDimensionInit($event)'>
</igx-pivot-grid>
```

> Los eventos <ApiLink type="{ComponentApiType}" member="dimensionInit" label="dimensionInit" /> y <ApiLink type="{ComponentApiType}" member="valueInit" label="valueInit" /> se emiten para cada valor y dimensión definidos en la propiedad <ApiLink type="PivotGrid" member="pivotConfiguration" label="pivotConfiguration" />.

- En el controlador del evento `valueInit`, establezca todos los agregadores, formateadores y estilos personalizados:

```typescript
public onValueInit(value: IPivotValue) {
    // Needed only for custom aggregators, formatter or styles.
    if (value.member === 'AmountofSale') {
        value.aggregate.aggregator = IgxTotalSaleAggregate.totalSale;
        value.aggregateList?.forEach((aggr: IPivotAggregator) => {
            switch (aggr.key) {
                case 'SUM':
                    aggr.aggregator = IgxTotalSaleAggregate.totalSale;
                    break;
                case 'MIN':
                    aggr.aggregator = IgxTotalSaleAggregate.totalMin;
                    break;
                case 'MAX':
                    aggr.aggregator = IgxTotalSaleAggregate.totalMax;
                    break;
            }
        });
    } else if (value.member === 'Value') {
        value.formatter = (value) => value ? '$' + parseFloat(value).toFixed(3) : undefined;
        value.styles.upFontValue = (rowData: any, columnKey: any): boolean => parseFloat(rowData.aggregationValues.get(columnKey.field)) > 150
        value.styles.downFontValue = (rowData: any, columnKey: any): boolean => parseFloat(rowData.aggregationValues.get(columnKey.field)) <= 150;
    }
}
```

- En el controlador del evento `dimensionInit`, establezca todas las implementaciones personalizadas de `memberFunction`:

```typescript
public onDimensionInit(dim: IPivotDimension) {
    switch (dim.memberName) {
        case 'AllProducts':
            dim.memberFunction = () => 'All Products';
            break;
        case 'ProductCategory':
            dim.memberFunction = (data) => data.Product.Name;
            break;
        case 'City':
            dim.memberFunction = (data) => data.Seller.City;
            break;
        case 'SellerName':
            dim.memberFunction = (data) => data.Seller.Name;
            break;
    }
}
```

## Restaurar grids hijos

Guardar y restaurar el estado de los grids hijos se controla mediante la propiedad <ApiLink kind="interface" type="IGridStateOptions" member="rowIslands" /> y está habilitado de forma predeterminada. <ApiLink type="GridStateDirective" /> usará las mismas opciones para guardar y restaurar las funciones tanto del grid raíz como de todos los grids hijos de la jerarquía. Por ejemplo, si pasamos las siguientes opciones:

``` html
<!-- public options = {selection: false, sorting: false, rowIslands: true} -->
<igx-grid [igxGridState]="options"></igx-grid>
```

Entonces la API `getState` devolverá el estado de las funciones de todos los grids (grid raíz y grids hijos), excepto `selection` y `sorting`. Si más adelante el desarrollador quiere restaurar solo el estado de `filtering` para todos los grids, use:

```typescript
this.state.setState(state, ['filtering', 'rowIslands']);
```

</ComponentBlock>

## Restaurar las estrategias de pivot

<ApiLink type="GridStateDirective" /> no conserva de forma predeterminada ni las operaciones de pivot remotas ni las estrategias de dimensión personalizadas (para más información, consulte el ejemplo [Operaciones remotas de Pivot Grid](/{igPath}/pivot-grid-custom)) (véase [`limitations`](/{igPath}/state-persistence#limitaciones)). Restaurar cualquiera de ellas puede lograrse con código a nivel de aplicación. El `IgxGridState` expone un evento llamado <ApiLink type="GridStateDirective" member="stateParsed" label="stateParsed" /> que puede usarse para modificar adicionalmente el estado de la cuadrícula antes de aplicarlo. Veamos cómo hacerlo:

> <ApiLink type="GridStateDirective" /> solo se emite cuando usamos <ApiLink type="GridStateDirective" member="setState" label="setState" /> con un argumento de cadena.

- Establezca la estrategia de ordenación personalizada y las estrategias personalizadas de dimensión de columna y de fila de pivot:

```html
<igx-pivot-grid #grid [data]="data" [pivotConfiguration]="pivotConfigHierarchy" [defaultExpandState]='true'
    [igxGridState]="options" [sortStrategy]="customStrategy" [pivotUI]='{ showConfiguration: false }' [superCompactMode]="true" [height]="'500px'">
</igx-pivot-grid>
```

```typescript
@ViewChild(IgxGridStateDirective, { static: true })
public state!: IgxGridStateDirective;

public customStrategy = NoopSortingStrategy.instance();
public options: IGridStateOptions = {...};
public pivotConfigHierarchy: IPivotConfiguration = {
    columnStrategy: NoopPivotDimensionsStrategy.instance(),
    rowStrategy: NoopPivotDimensionsStrategy.instance(),
    columns: [...],
    rows: [...],
    values: [...],
    filters: [...]
};
```

- Restaurar el estado desde `sessionStorage` y aplicar las estrategias personalizadas tiene este aspecto:

```typescript
public restoreState() {
    const state = window.sessionStorage.getItem('grid-state');
    this.state.stateParsed.pipe(take(1)).subscribe(parsedState => {
        parsedState.sorting.forEach(x => x.strategy = NoopSortingStrategy.instance());
        parsedState.pivotConfiguration.rowStrategy = NoopPivotDimensionsStrategy.instance();
        parsedState.pivotConfiguration.columnStrategy = NoopPivotDimensionsStrategy.instance();
    });
    this.state.setState(state as string);
}
```

<ApiLink type="GridStateDirective" /> no conserva de forma predeterminada ni las operaciones remotas ni las estrategias de dimensión personalizadas (para más información, consulte el ejemplo [Operaciones remotas de Grid](/{igPath}/remote-data-operations)) (véase [`limitations`](/{igPath}/state-persistence#limitaciones)). El `IgxGridState` expone un evento llamado <ApiLink type="GridStateDirective" member="stateParsed" label="stateParsed" /> que puede usarse para modificar adicionalmente el estado de la cuadrícula antes de aplicarlo. Veamos cómo hacerlo:

<DocsAside type="info">
<ApiLink type="GridStateDirective" /> solo se emite cuando usamos <ApiLink type="GridStateDirective" member="setState" label="setState" /> con un argumento de cadena.
</DocsAside>

- Establezca la estrategia de ordenación personalizada y las estrategias personalizadas de dimensión de columna y de fila:

```typescript
@ViewChild(IgxGridStateDirective, { static: true })

public customStrategy = NoopSortingStrategy.instance();
public options: IGridStateOptions = {...};
```

- Restaurar el estado desde `sessionStorage` y aplicar las estrategias personalizadas tiene este aspecto:

```typescript
public restoreState() {
    const state = window.sessionStorage.getItem('grid-state');
```

## Limitaciones

<ComponentBlock for="HierarchicalGrid">

- Al restaurar todas las funciones de la cuadrícula a la vez (usando la API `setState` sin parámetros), las propiedades de columna de la cuadrícula raíz podrían restablecerse a sus valores predeterminados. Si esto ocurre, restaure después las columnas o la función de selección de columnas por separado:

```typescript
state.setState(gridState);
state.setState(gridState.columns);
state.setState(gridState.columnSelection);
```

</ComponentBlock>
<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">

- El método <ApiLink type="GridStateDirective" member="getstate" label="getState" /> usa el método JSON.stringify() para convertir los objetos originales en una cadena JSON. JSON.stringify() no admite funciones, por eso la directiva [`IgxGridState`] ignorará las propiedades de columna <ApiLink type="Column" member="formatter" label="formatter" />, <ApiLink type="Column" member="filters" label="filters" />, <ApiLink type="Column" member="summaries" label="summaries" />, <ApiLink type="Column" member="sortstrategy" label="sortStrategy" />, <ApiLink type="Column" member="cellClasses" label="cellClasses" />, <ApiLink type="Column" member="cellstyles" label="cellStyles" />, <ApiLink type="Column" member="headerTemplate" label="headerTemplate" /> y <ApiLink type="Column" member="bodyTemplate" label="bodyTemplate" />.
</ComponentBlock>
<ComponentBlock for="PivotGrid">

- El método <ApiLink type="GridStateDirective" member="getState" label="getState" /> usa el método JSON.stringify() para convertir los objetos originales en una cadena JSON. JSON.stringify() no admite funciones, por eso la directiva <ApiLink type="GridStateDirective" /> ignorará la dimensión de pivot <ApiLink kind="interface" type="IPivotDimension" member="memberFunction" />, los valores de pivot <ApiLink kind="interface" type="IPivotValue" member="member" />, <ApiLink kind="interface" type="IPivotValue" member="formatter" />, las funciones personalizadas <ApiLink kind="interface" type="IPivotValue" member="aggregate" />,
<ApiLink kind="interface" type="IPivotValue" member="styles" /> y las estrategias de configuración de pivot: <ApiLink kind="interface" type="IPivotConfiguration" member="columnStrategy" /> y <ApiLink kind="interface" type="IPivotConfiguration" member="rowStrategy" />.
</ComponentBlock>
