# Barra de herramientas de {ComponentTitle} en Angular

El {ComponentTitle} de Ignite UI for Angular proporciona un <ApiLink type="GridToolbar" />, que es básicamente un contenedor para las operaciones de **interfaz**. La barra de herramientas de Angular se encuentra en la parte superior del componente de Angular, es decir, en {ComponentTitle}, y coincide con su tamaño horizontal. El contenedor de la barra de herramientas puede alojar controles de interfaz predefinidos para las siguientes funciones de {ComponentTitle}:

- Ocultación de columnas
- Anclaje de columnas
- Exportar a Excel, CSV y PDF
- Filtrado avanzado

o simplemente cualquier otro contenido personalizado. La barra de herramientas y los componentes de interfaz predefinidos admiten eventos de Angular y exponen una API para los desarrolladores.

## Barra de herramientas con grids hijos

Debido a ciertas limitaciones en la forma en que se implementan los grids hijos de un IgxHierarchicalGrid y en cómo funciona el ámbito de DI, al definir un componente de barra de herramientas dentro de las etiquetas `igx-row-island` use la directiva `igxGridToolbar` con la forma abreviada de plantilla. Así, los grids hijos pueden crear sus propias instancias independientes de barra de herramientas:

```html
<igx-hierarchical-grid>
    ...
    <igx-row-island>
        <igx-grid-toolbar *igxGridToolbar>
            <igx-grid-toolbar-title>Child toolbar</igx-grid-toolbar-title>
        </igx-grid-toolbar>
    </igx-row-island>
    ...
</igx-hierarchical-grid>
```

El contexto de plantilla de la barra de herramientas expone implícitamente una referencia a la instancia de la cuadrícula correspondiente, que puede usar para cualquier otra necesidad de enlace o lógica. Vea un ejemplo más abajo.

### Con versiones anteriores a 17.1.0

Las versiones anteriores a 17.1.0 también requerían pasar la instancia del grid proporcionada como propiedad de entrada a la propia barra de herramientas. Así se garantiza que siempre tenga la instancia correcta del grid en el ámbito de su plantilla:

```html
<igx-hierarchical-grid>
    ...
    <igx-row-island>
        <!--
            You can name the binding from igxGridToolbar however you want. Just make sure to use
            it inside the template if you need to access the grid instance.
        -->
        <igx-grid-toolbar [grid]="gridRef" *igxGridToolbar="let gridRef">
            <igx-grid-toolbar-title>Child toolbar {{ gridRef.parentIsland.level }}</igx-grid-toolbar-title>
        </igx-grid-toolbar>
    </igx-row-island>
    ...
</igx-hierarchical-grid>
```

</ComponentBlock>

el filtrado avanzado y la exportación de datos de la cuadrícula.
Estas funciones pueden habilitarse de forma independiente siguiendo un patrón similar al del componente card del
conjunto Ignite UI for Angular.

### Título

Para establecer un título en la barra de herramientas de su cuadrícula se usa <ApiLink type="GridToolbarTitle" />.
Los usuarios pueden proporcionar desde un texto sencillo hasta plantillas más elaboradas.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-title>Grid toolbar title</igx-grid-toolbar-title>
</igx-grid-toolbar>
```

### Acciones

La barra de herramientas expone un <ApiLink type="GridToolbarActions" label="contenedor específico" /> donde los usuarios pueden colocar acciones e interacciones en relación con la cuadrícula padre.
Al igual que con la parte del título de la barra de herramientas, los usuarios pueden proporcionar cualquier contenido dentro de esa parte de la plantilla, incluidos los componentes de interacción predeterminados de la barra de herramientas.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <button igxButton>Action</button>
        <igx-select></igx-select>
        ...
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

Cada acción ofrece ahora una forma de cambiar la configuración de la superposición del cuadro de diálogo de acciones mediante la entrada <ApiLink type="GridToolbarHiding" member="overlaySettings" label="overlaySettings" />, por ejemplo:

```html
<igx-grid-toolbar-actions>
    <igx-grid-toolbar-pinning [overlaySettings]="overlaySettingsScaleCenter"></igx-grid-toolbar-pinning>
    <igx-grid-toolbar-hiding [overlaySettings]="overlaySettingsAuto"></igx-grid-toolbar-hiding>
</igx-grid-toolbar-actions>
```

```ts
public data: any[];
public positionStrategyScaleCenter = new GlobalPositionStrategy({
    openAnimation: scaleInCenter,
    closeAnimation: scaleOutCenter
});
public overlaySettingsScaleCenter = {
    positionStrategy: this.positionStrategyScaleCenter,
    scrollStrategy: new AbsoluteScrollStrategy(),
    modal: true,
    closeOnEscape: true
};

public positionStrategyAuto = new AutoPositionStrategy();
public overlaySettingsAuto = {
    positionStrategy: this.positionStrategyAuto,
    scrollStrategy: new AbsoluteScrollStrategy(),
    modal: false,
    closeOnEscape: false
};
constructor() {
    this.data = athletesData;
}
```

Las overlaySettings predeterminadas usan _ConnectedPositionStrategy_ con la estrategia de desplazamiento _Absolute_, _modal_ establecido en false, con las interacciones _cerrar con Escape_ y _cerrar al hacer clic fuera_ habilitadas.

### Anclaje de columnas

<ApiLink type="GridToolbarPinning" label="Componente de anclaje de la barra de herramientas" /> proporciona la interfaz predeterminada para interactuar con el anclaje de columnas en la cuadrícula.
El componente está configurado para funcionar desde el primer momento con la cuadrícula padre que contiene la barra de herramientas, así como con varias propiedades de entrada para personalizar la interfaz, como el título del componente, el texto de ayuda de la entrada del componente y la altura del propio desplegable.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-pinning
            title="Grid pinned columns"
            prompt="Filter column collection"
            columnListHeight="400px"
        >
        </igx-grid-toolbar-pinning>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

### Ocultar columnas

<ApiLink type="GridToolbarHiding" label="Componente de ocultación de la barra de herramientas" /> proporciona la interfaz predeterminada
para interactuar con la ocultación de columnas. Expone las mismas propiedades de entrada para personalizar la interfaz, como el título del componente,
el texto de ayuda de la entrada del componente y la altura del propio desplegable.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-hiding
            title="Grid column hiding"
            prompt="Filter column collection"
            columnListHeight="400px"
        >
        </igx-grid-toolbar-hiding>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

### Filtrado avanzado

<ApiLink type="GridToolbarAdvancedFiltering" label="Componente de filtrado avanzado de la barra de herramientas" /> proporciona la interfaz predeterminada para la función de filtrado avanzado. El componente expone una forma de cambiar el texto predeterminado del botón.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-advanced-filtering>Custom text for the toggle button</igx-grid-toolbar-advanced-filtering>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

### Exportación de datos

<ComponentBlock for="HierarchicalGrid">

<DocsAside type="info">
Al exportar el Hierarchical Grid, o cualquiera de sus grids hijos en la jerarquía, los datos exportados serán una colección plana de filas que pertenecen a su grid respectivo (los grids hijos no se incluirán en los datos exportados).
</DocsAside>
</ComponentBlock>

Al igual que el resto de acciones de la barra de herramientas, la exportación se proporciona mediante un <ApiLink type="GridToolbarExporter" label="Componente de exportación de la barra de herramientas" /> desde el primer momento.
El componente de exportación usa el servicio correspondiente al formato de datos de destino (<ApiLink type="ExcelExporterService" label="Excel" />, <ApiLink type="CsvExporterService" label="CSV" />, <ApiLink type="PdfExporterService" label="PDF" />). Eso significa que, si el servicio correspondiente no se proporciona en la cadena de inyección de dependencias, el componente
no podrá exportar nada.
Si necesita repasar la DI de Angular, consulte la [guía oficial](https://angular.io/guide/dependency-injection). Este es un fragmento de ejemplo que muestra cómo habilitar
todos los servicios de exportación en su aplicación.

```typescript
// app.module.ts
import { IgxExcelExporterService, IgxCsvExporterService, IgxPdfExporterService } from 'igniteui-angular/grids/core';
// import { IgxExcelExporterService, IgxCsvExporterService, IgxPdfExporterService } from '@infragistics/igniteui-angular/grids/core'; for licensed package

@NgModule({
    ...
    providers: [IgxExcelExporterService, IgxCsvExporterService, IgxPdfExporterService ]
})
export class AppModule { ... }
```

<DocsAside type="info">
En la versión 12.2.1 y posteriores, los servicios de exportación se proporcionan en root, lo que significa que ya no es necesario declararlos en los providers de AppModule.
</DocsAside>

El componente exportador de la barra de herramientas expone varias propiedades de entrada para personalizar tanto la interfaz como la experiencia de exportación.
Van desde cambiar el texto mostrado hasta habilitar o deshabilitar opciones del desplegable o personalizar el nombre del
archivo generado. Para la referencia completa, consulte la <ApiLink type="GridToolbarExporter" label="Documentación de la API" /> del componente exportador de la barra de herramientas.

Este es un fragmento que muestra algunas de las opciones que pueden personalizarse desde la plantilla de Angular:

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-exporter
            <!-- If active, enables the CSV export entry in the dropdown UI -->
            [exportCSV]="csvExportEnabled"
            <!-- If active, enables the excel export entry in the dropdown UI -->
            [exportExcel]="excelExportEnabled"
            <!-- If active, enables the PDF export entry in the dropdown UI -->
            [exportPDF]="pdfExportEnabled"
            <!-- The name of the generated export file without the file extension -->
            filename="exported_data"
        >
            Custom text for the exporter button
            <span excelText>Custom text for the excel export entry</span>
            <span csvText>Custom text for the CSV export entry</span>
            <span pdfText>Custom text for the PDF export entry</span>
        </igx-grid-toolbar-exporter>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

<ComponentBlock for="Grid, TreeGrid, PivotGrid">

Además de cambiar el nombre del archivo exportado, el usuario puede configurar más opciones del exportador esperando al evento <ApiLink type="{ComponentApiType}" member="toolbarExporting" label="toolbarExporting" /> y personalizando la entrada de opciones en las propiedades del evento.

<DocsAside type="info">
De forma predeterminada, al exportar a CSV, el exportador usa un separador de coma y una extensión '.csv' para el archivo de salida.
Puede personalizar estos parámetros de exportación suscribiéndose a los eventos del exportador o cambiando los valores de los campos de opciones del exportador.
También puede cancelar el proceso de exportación estableciendo el campo cancel de los argumentos del evento en true.
</DocsAside>

El fragmento de código siguiente muestra cómo suscribirse al evento de exportación de la barra de herramientas y configurar las opciones del exportador:

```html
<{ComponentSelector} (toolbarExporting)="configureExport($event)" ></{ComponentSelector}>
```

```typescript
configureExport(args: IGridToolbarExportEventArgs) {
    const options: IgxExporterOptionsBase = args.options;
    
    options.fileName = `Report_${new Date().toDateString()}`;

    if (options instanceof IgxExcelExporterOptions) {
        options.columnWidth = 10;
    } else {
        options.fileType = CsvFileTypes.TSV;
        options.valueDelimiter = '\t';
    }

    args.exporter.columnExporting.subscribe((columnArgs: IColumnExportingEventArgs) => {
        <ComponentBlock for="Grid">

        // Don't export image fields
        columnArgs.cancel = columnArgs.header === 'Athlete' ||
                            columnArgs.header === 'Country';
        </ComponentBlock>
        <ComponentBlock for="TreeGrid">

        // Don't export image field
        columnArgs.cancel = columnArgs.header === 'Name';
        </ComponentBlock>
    });
}
```

</ComponentBlock>

        <igx-grid-toolbar-actions>
            ...

## Estilos

Para empezar a dar estilo a la barra de herramientas, debemos importar el archivo index, donde se exportan todas las funciones de tema y el mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

A continuación, cree un tema nuevo que extienda <ApiLink kind="sass" module="themes" type="function-grid-toolbar-theme" label="grid-toolbar-theme" code={true} />.

```scss
$accent: #ffcd0f;

$grid-toolbar-theme: grid-toolbar-theme(
  $background: #170237,
  $border-color: $accent,
  $title-text-color: #f6d8d8,
  $item-hover-background: rgb(246 216 216 / 0.3),
);
```

El último paso es **incluir** los temas recién creados.

```scss
:host {
  igx-grid-toolbar {
    @include tokens($grid-toolbar-theme);
  }
}
```

<DocsAside type="info">
En algunas plantillas de componentes, el encapsulado de vista emulado puede impedir que las declaraciones de tokens generadas lleguen a los elementos anidados de Ignite UI. Si el tema no surte efecto, use `::ng-deep` como se muestra a continuación o traslade el tema a una hoja de estilos global.
</DocsAside>

```scss
:host ::ng-deep {
  igx-grid-toolbar {
    @include tokens($grid-toolbar-theme);
  }
}
```
