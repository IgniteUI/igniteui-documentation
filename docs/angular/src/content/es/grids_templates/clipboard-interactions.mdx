# Interacciones del portapapeles de {ComponentTitle} en Angular

Las operaciones de copiar al portapapeles ya están disponibles en {ComponentTitle}. Esta función ofrece una forma rápida, sencilla y personalizable de copiar datos del Angular Data Grid a través de la selección actual de datos de varias celdas. El comportamiento del portapapeles del sistema permite al usuario copiar datos de {ComponentTitle} en Excel u otros programas externos.

## Funcionalidad

El comportamiento de copiar funciona con la interacción predeterminada definida por el navegador y el sistema operativo. Por tanto, para copiar y pegar, estas son las opciones:

- Basado en Windows/Unix
  - <kbd>Ctrl</kbd> + <kbd>C</kbd> / <kbd>Ctrl</kbd> + <kbd>Ins</kbd> como atajo de teclado
  - <kbd>Ctrl</kbd> + <kbd>V</kbd> / <kbd>Shift</kbd> + <kbd>Ins</kbd> como atajo de teclado
  - Acción de copiar mediante el menú del navegador
- macOS
  - <kbd>⌘ Cmd</kbd> + <kbd>C</kbd> como atajo de teclado
  - <kbd>⌘ Cmd</kbd> + <kbd>V</kbd> como atajo de teclado
  - Acción de copiar mediante el menú del navegador

## Limitaciones

- Los eventos **cut** y **copy** no se admiten de forma nativa en Internet Explorer. La excepción es el evento
**paste** (IE 11), que se emite pero no expone la propiedad `clipboardData` en el evento.

<DocsAside type="info">
Para `copy` celdas en IE 11, puede usar la selección con el teclado. Mantenga pulsada la tecla `shift key` para hacer una selección de varias celdas y pulse `Ctrl + C` para copiar.
</DocsAside>

- El comportamiento de copiar está deshabilitado mientras el grid está en modo de edición.
- La versión actual de esta función cubre solo el comportamiento de `copy` de la cuadrícula. Más adelante planeamos exponer `paste` dentro del comportamiento de la cuadrícula.
<ComponentBlock for="Grid">
 Puede usar un controlador de pegado personalizado para configurar el comportamiento de `paste`; consulte nuestro tema [Pegar desde Excel](/{igPath}/paste-excel).
 </ComponentBlock>


## Uso de la API

Exponemos la propiedad de entrada <ApiLink type="Grid" member="clipboardOptions" label="clipboardOptions" />, que gestiona las siguientes opciones:

- <ApiLink type="Grid" member="clipboardoptions.enabled" label="enabled" /> Activa o desactiva la copia de las celdas seleccionadas.
- <ApiLink type="Grid" member="clipboardoptions.copyHeaders" label="copyHeaders" /> Incluye los encabezados asociados al copiar.
- <ApiLink type="Grid" member="clipboardoptions.copyFormatters" label="copyFormatters" /> Aplica los formateadores de columna existentes a los datos copiados.
- <ApiLink type="Grid" member="clipboardoptions.separator" label="separator" /> El separador de cadena que se usa para dar formato a los datos en el portapapeles. El valor predeterminado es `/t`

<DocsAside type="info">
Excel puede detectar automáticamente el texto separado por tabulaciones (`/t` delimitado por tabuladores) y pegar los datos correctamente en columnas separadas. Cuando el formato de pegado no funciona y todo lo que pega aparece en una única columna, es porque el delimitador de Excel está configurado con otro carácter, o porque su texto usa espacios en lugar de tabulaciones.
</DocsAside>

- <ApiLink type="Grid" member="gridCopy" label="gridCopy" /> Se emite cuando se ejecuta una operación de copia. Solo se dispara si el comportamiento de copia está habilitado mediante <ApiLink type="Grid" member="clipboardOptions" label="clipboardOptions" />
