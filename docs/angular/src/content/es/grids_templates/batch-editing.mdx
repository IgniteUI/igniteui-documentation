## Uso

Para empezar, importe `{ComponentName}Module` en el archivo **app.module.ts**:

```typescript
// app.module.ts

...
import { {ComponentName}Module } from 'igniteui-angular';

@NgModule({
    ...
    imports: [..., {ComponentName}Module],
    ...
})
export class AppModule {}
```

Después, solo tiene que habilitar `batchEditing` desde su {ComponentTitle}:

```html
<{ComponentSelector} [data]="data" [batchEditing]="true">
  ...
</{ComponentSelector}>
```

Así se garantiza que se proporcione una instancia adecuada del servicio `Transaction` para {ComponentSelector}. El `TransactionService` adecuado se proporciona mediante una `TransactionFactory`. Puede obtener más información sobre esta implementación interna en el tema [Transacciones](/transaction-classes#factoría-de-transacciones).

Una vez habilitada la edición por lotes, defina un `{ComponentName}` con el origen de datos enlazado, establezca <ApiLink type="{ComponentApiType}" member="rowEditable" label="rowEditable" /> en true y enlácelo:

El código siguiente muestra el uso de la API de <ApiLink type="GridComponent" member="transactions" />: deshacer, rehacer y confirmar.

```typescript
export class GridBatchEditingSampleComponent {
    @ViewChild('grid', { read: IgxGridComponent }) public gridRowEditTransaction: IgxGridComponent;

    public undo() {
        /* exit edit mode and commit changes */
        this.grid.endEdit(true);
        this.grid.transactions.undo();
    }

    public redo() {
        /* exit edit mode and commit changes */
        this.grid.endEdit(true);
        this.grid.transactions.redo()
    }

    public commit() {
        this.grid.transactions.commit(this.data);
        this.toggle.close();
    }
}
```

</ComponentBlock>

El código siguiente muestra el uso de la API de <ApiLink type="GridComponent" member="transactions" />: deshacer, rehacer y confirmar.

```typescript
...
export class HierarchicalGridBatchEditingSampleComponent {
    public undo(grid: any) {
        /* exit edit mode and commit changes */
        grid.endEdit(true);
        grid.transactions.undo();
    }

    public redo(grid: any) {
        /* exit edit mode and commit changes */
        grid.endEdit(true);
        grid.transactions.redo();
    }

    public commit() {
        this.hierarchicalGrid.transactions.commit(this.data);
        this.childGrid.hgridAPI.getChildGrids().forEach((grid) => {
            grid.transactions.commit(grid.data);
        });
        this.dialogChanges.close();
    }
}
```

<DocsAside type="info">
La API de transacciones no gestiona el fin de la edición, así que tendrá que hacerlo usted mismo. De lo contrario, `{ComponentTitle}` permanecería en modo de edición. Una forma de hacerlo es llamar a <ApiLink type="Grid" member="endEdit" label="endEdit" /> en el método correspondiente.
</DocsAside>

<ComponentBlock for="TreeGrid">

Eliminar un nodo padre en `{ComponentTitle}` tiene algunas particularidades. Si usa datos jerárquicos, los hijos se eliminarán al eliminar su padre. Si usa datos planos, puede establecer el comportamiento deseado mediante la propiedad <ApiLink type="{ComponentApiType}" member="cascadeOnDelete" label="cascadeOnDelete" /> de `{ComponentTitle}`. Esta propiedad indica si los registros hijos deben eliminarse cuando se elimina su padre (de forma predeterminada, está establecida en `true`).
</ComponentBlock>

<DocsAside type="info">
Desactivar la propiedad <ApiLink type="{ComponentApiType}" member="rowEditable" label="rowEditable" /> hará que `{ComponentTitle}` cree transacciones al cambiar una celda y no mostrará la superposición de edición de filas en la interfaz.
</DocsAside>
