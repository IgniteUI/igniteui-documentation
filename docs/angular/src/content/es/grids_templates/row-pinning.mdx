# Anclaje de filas de {ComponentTitle} en Angular

Una o varias filas pueden anclarse a la parte superior o inferior del grid de interfaz de Angular. El **anclaje de filas** en Ignite UI for Angular permite a los usuarios finales anclar filas en un orden determinado, duplicándolas en un área especial que siempre está visible aunque se desplacen verticalmente por {ComponentTitle}. El Material UI Grid tiene una interfaz integrada de anclaje de filas, que se habilita inicializando un componente `igxActionStrip` en el contexto de {ComponentTitle}. Además, puede definir una interfaz personalizada y cambiar el estado de anclaje de las filas mediante la API de anclaje de filas.

## Interfaz de anclaje de filas

La interfaz integrada de anclaje de filas se habilita añadiendo un componente `igxActionStrip` con el componente `GridPinningActions`. El action strip se muestra automáticamente al pasar el cursor sobre una fila y mostrará un icono de botón de anclar o desanclar según el estado de la fila para la que se muestra. Para cada fila anclada también se muestra una acción adicional que permite desplazar la copia de la fila anclada hasta la vista.

<ComponentBlock for="Grid">

```html
<igx-grid [data]="data" [autoGenerate]="false">
    <igx-column *ngFor="let c of columns" [field]="c.field" [header]="c.field">
    </igx-column>

    <igx-action-strip #actionStrip>
        <igx-grid-pinning-actions></igx-grid-pinning-actions>
        <igx-grid-editing-actions></igx-grid-editing-actions>
    </igx-action-strip>
</igx-grid>
```

## API de anclaje de filas

El anclaje de filas se controla mediante la entrada `pinned` de <ApiLink kind="interface" type="RowType"/>. Las filas ancladas se muestran de forma predeterminada en la parte superior de {ComponentTitle} y permanecen fijas mientras se desplazan verticalmente las filas no ancladas en el cuerpo de {ComponentTitle}.

<ComponentBlock for="Grid">

```typescript
this.grid.getRowByIndex(0).pinned = true;
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```typescript
this.treeGrid.getRowByIndex(0).pinned = true;
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```typescript
this.hierarchicalGrid.getRowByIndex(0).pinned = true;
```

</ComponentBlock>

También puede usar los métodos <ApiLink type="{ComponentApiType}" member="pinRow" label="pinRow" /> o <ApiLink type="{ComponentApiType}" member="unpinRow" label="unpinRow" /> de {ComponentTitle} de <ApiLink type="{ComponentApiType}" /> para anclar o desanclar registros por su ID:

<ComponentBlock for="Grid">

```typescript
this.grid.pinRow('ALFKI');
this.grid.unpinRow('ALFKI');
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```typescript

this.treeGrid.unpinRow('ALFKI');
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```typescript

this.hierarchicalGrid.unpinRow('ALFKI');
```

</ComponentBlock>

Tenga en cuenta que el ID de la fila es el valor de la clave primaria, definido por <ApiLink type="{ComponentApiType}" member="primaryKey" label="primaryKey" /> de la cuadrícula, o la propia instancia del registro. Ambos métodos devuelven un valor booleano que indica si su operación respectiva se ha realizado correctamente. Normalmente fallan porque la fila ya está en el estado deseado.

Una fila se ancla debajo de la última fila anclada. Para cambiar el orden de las filas ancladas, puede suscribirse al evento <ApiLink type="{ComponentApiType}" member="rowPinning" label="rowPinning" /> y cambiar la propiedad <ApiLink kind="interface" type="IPinRowEventArgs" member="insertAtIndex" /> de los argumentos del evento a la posición de índice deseada.

<ComponentBlock for="Grid">

```html
<igx-grid #grid1 [data]="data" [autoGenerate]="true" (rowPinning)="rowPinning($event)">
</igx-grid>
```

```typescript
public rowPinning(event) {
    event.insertAtIndex = 0;
}
```

</ComponentBlock>

## Posición del anclaje

Puede cambiar la posición del anclaje de filas mediante la opción de configuración <ApiLink type="{ComponentApiType}" member="pinning" label="pinning" />. Permite establecer la posición del área de anclaje en Top o Bottom.
Cuando se establece en Bottom, las filas ancladas se renderizan al final de la cuadrícula, después de las filas no ancladas. Las filas no ancladas pueden desplazarse verticalmente, mientras que las filas ancladas permanecen fijas en la parte inferior.

## Interfaz personalizada de anclaje de filas

Puede definir su propia interfaz y cambiar el estado de anclaje de las filas mediante la API relacionada.

### Mediante una columna extra con icono

Supongamos que, en lugar de un action strip, quiere mostrar un icono de anclaje en cada fila para que el usuario final pueda hacer clic y cambiar el estado de anclaje de una fila concreta.

Al hacer clic en el icono personalizado, puede cambiarse el estado de anclaje de la fila correspondiente usando los métodos de la API de la fila.

```typescript
public togglePinning(row: IgxGridRow, event) {
    event.preventDefault();
    if (row.pinned) {
        row.unpin();
    } else {
        row.pin();
    }
}
```

### Mediante arrastre de filas

Supongamos que quiere poder arrastrar y soltar directamente una fila entre las filas ancladas y las no ancladas para cambiar su estado de anclaje.
Esto puede lograrse habilitando la función de arrastre de filas y anclando o desanclando las filas mediante la API al soltarlas.

En primer lugar, el grid debe marcarse como área de colocación usando la directiva `igxDrop`, y la función de arrastre de filas debe habilitarse mediante la opción `rowDraggable`.

```html
<igx-grid [data]="data" [autoGenerate]="true" [rowDraggable]="true"
    [primaryKey]="'ID'" igxDrop (dropped)="onDropAllowed($event)">
</igx-grid>
```

Después, el evento `dropped` puede usarse para gestionar la lógica de reordenación y de anclar/desanclar.

```typescript
public onDropAllowed(args) {
    const event = args.originalEvent;
    let currRowPinnedIndex;
    const currRowIndex = this.getCurrentRowIndex(this.grid.rowList.toArray(),
        { x: event.clientX, y: event.clientY });
    if (currRowIndex === -1) { return; }

    const currRowID = this.getCurrentRowID(this.grid.rowList.toArray(),
        { x: event.clientX, y: event.clientY });

    const currentRow = this.grid.rowList.toArray().find((r) => r.rowID === currRowID);
    if (currentRow.pinned) {
        currRowPinnedIndex = this.grid.pinnedRows.indexOf(this.grid.pinnedRows.find((r) => r.rowID === currRowID));
    }
    // remove the row that was dragged and place it onto its new location
    this.grid.deleteRow(args.dragData.key);
    this.data.splice(currRowIndex, 0, args.dragData.data);
    if (currentRow.pinned && !args.dragData.pinned) {
        this.grid.pinRow(args.dragData.key, currRowPinnedIndex);
    } else if (!currentRow.pinned && args.dragData.pinned) {
        this.grid.unpinRow(args.dragData.key);
    } else if (currentRow.pinned && args.dragData.pinned) {
        this.grid.unpinRow(args.dragData.key);
        this.grid.pinRow(args.dragData.key, currRowPinnedIndex);
    }
}
```

Esto permitiría reordenar las filas y moverlas entre las colecciones de filas ancladas y no ancladas.

## Limitaciones del anclaje de filas

- Solo pueden anclarse los registros que existen en el origen de datos.
- El estado de anclaje de filas no se exporta a Excel. El grid se exporta como si no se aplicara ningún anclaje de filas.
- Debido a la forma en que se almacenan internamente las filas ancladas para que puedan aparecer tanto en el área anclada como en la no anclada de la cuadrícula, el anclaje de filas no se admite cuando los registros de la cuadrícula se obtienen bajo demanda desde un punto final remoto (virtualización remota).
- Las copias de las filas ancladas en el área desplazable de la cuadrícula forman parte integral de cómo otras funciones de la cuadrícula logran su funcionalidad en presencia de filas ancladas; por tanto, no puede deshabilitarse su creación ni eliminarse.
- Como la selección de filas funciona completamente con los IDs de fila, al seleccionar filas ancladas también se seleccionan sus copias (y viceversa). Además, la selección por rango (por ejemplo, usando Shift + clic) dentro del área anclada funciona igual que la selección de un rango de filas dentro del área desplazable. La selección resultante incluye todas las filas intermedias, aunque no estén ancladas actualmente. Obtener las filas seleccionadas a través de la API solo devuelve una instancia de cada registro seleccionado.
- Cuando el grid no tiene `primaryKey` establecido y los escenarios de datos remotos están habilitados (cuando la paginación, la ordenación, el filtrado o el desplazamiento provocan solicitudes a un servidor remoto para obtener los datos que se mostrarán en el grid), una fila perderá el siguiente estado tras completarse una solicitud de datos:
  - Selección de filas
  - Expandir/contraer filas
  - Edición de filas
  - Anclaje de filas


## Estilos

El {ComponentName} permite dar estilo mediante [`Ignite UI for Angular Theme Library`](/themes/sass/component-themes). La {ComponentTitle} del <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> expone una gran variedad de propiedades que permiten personalizar todas las funciones del {ComponentTitle}.

A continuación repasamos los pasos para personalizar el estilo del anclaje de filas de {ComponentTitle}.

### Importar la biblioteca de estilos

Para empezar a personalizar la función de anclaje de filas, debe importar el archivo `index`, donde se encuentran todas las funciones de estilo y los mixins.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### Definir un tema

A continuación, cree un tema nuevo que extienda <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> y acepte los parámetros necesarios para personalizar la función de anclaje de filas como desee.

<ComponentBlock for="Grid">

```scss
$custom-theme: grid-theme(
  $pinned-border-width: 5px,
  $pinned-border-style: double,
  $pinned-border-color: #ffcd0f,
  $cell-active-border-color: #ffcd0f
);
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```scss
$custom-theme: grid-theme(
  $pinned-border-width: 1px,
  $pinned-border-style: dashed,
  $pinned-border-color: #f325e9,
);
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```scss
$background: #292826;
$foreground: #eeece1;
$accent: #ffcd0f;

$custom-grid: grid-theme(
  $background: $background,
  $foreground: $foreground,
  $accent-color: $accent,
  $pinned-border-color: $accent,
);
```

</ComponentBlock>

### Usar variables CSS

El último paso es pasar el tema personalizado de la cuadrícula:

<ComponentBlock for="Grid, TreeGrid">

```scss

  @include tokens($custom-theme);
}
```

</ComponentBlock>

<ComponentBlock for="HierarchicalGrid">

```scss

}
```

</ComponentBlock>
