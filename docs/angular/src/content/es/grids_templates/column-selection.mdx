# Selección de columnas de {ComponentTitle} en Angular

La función de selección de columnas ofrece una forma sencilla de seleccionar una columna completa con un solo clic. Destaca la importancia de una columna concreta al enfocar la celda o las celdas del encabezado y todo lo que hay debajo. La función incluye una `API` completa que permite manipular el estado de selección, extraer datos de las fracciones seleccionadas y realizar operaciones y visualizaciones de análisis de datos.

## Uso básico

La función de selección de columnas puede habilitarse mediante la entrada <ApiLink type="{ComponentApiType}" member="columnSelection" label="columnSelection" />, que acepta valores <ApiLink kind="variable" type="GridSelectionMode" />.

## Interacciones

El modo de selección predeterminado es `none`. Si se establece en `single` o `multiple`, todas las columnas presentadas estarán <ApiLink type="Column" member="selectable" label="selectable" />. Dicho esto, para seleccionar una columna basta con hacer clic en una, lo que la marcará como <ApiLink type="Column" member="selected" label="selected" />. Si la columna no es seleccionable, no se aplica ningún estilo de selección al encabezado al pasar el ratón por encima.

<DocsAside type="info">
[`Multi-column Headers`](/{igPath}/multi-column-headers) no se reflejan en la entrada <ApiLink type="Column" member="selectable" label="selectable" />. El <ApiLink type="ColumnGroup" /> está <ApiLink type="Column" member="selectable" label="selectable" /> si al menos uno de sus hijos tiene habilitado el comportamiento de selección. Además, el componente se marca como <ApiLink type="ColumnGroup" member="selected" label="selected" /> si todos sus descendientes `selectable` están <ApiLink type="Column" member="selected" label="selected" />.
</DocsAside>

## Combinaciones de teclas

<DocsAside type="info">
Las combinaciones de teclas solo están disponibles cuando la entrada <ApiLink type="{ComponentApiType}" member="columnselection" label="columnSelection" /> del grid está establecida en `multiple`.
</DocsAside>

Hay dos escenarios para la navegación por teclado de la función **Selección de columnas**:

- Selección de varias columnas: mantener pulsado <kbd>Ctrl</kbd> + <kbd>clic</kbd> en cada celda de encabezado **seleccionable**.
- Selección de un rango de columnas: mantener pulsado <kbd>Shift</kbd> + <kbd>clic</kbd> selecciona todas las columnas **seleccionables** que hay entre ellas.

## Manipulaciones con la API

La **API** ofrece algunas capacidades adicionales para las columnas **no visibles**, de modo que cada columna **oculta** puede marcarse como <ApiLink type="Column" member="selected" label="selected" /> mediante el **setter** correspondiente.

<DocsAside type="info">
Lo anterior también se aplica a <ApiLink type="ColumnGroup" />, salvo que, al cambiar la propiedad <ApiLink type="ColumnGroup" member="selected" label="selected" />, cambia el estado de sus descendientes.
</DocsAside>

Puede encontrar más información sobre las manipulaciones con la API en la sección [`API References`](#api-references).

## Estilos

Antes de profundizar en las opciones de estilo, es necesario importar el módulo de temas.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

<DocsAside type="info">
Tenga en cuenta que [`row selection`](/{igPath}/row-selection) y [`column selection`](/{igPath}/column-selection) no pueden manipularse de forma independiente. Dependen del mismo `variables`.
</DocsAside>

Dicho esto, pasemos a cambiar los estilos de **selección** y de **paso del ratón**.<br/>
Siguiendo el enfoque más sencillo, definamos nuestro **tema** personalizado.

<ComponentBlock for="TreeGrid">

```scss
$background: #0b0119;
$foreground: #eeece1;
$accent: #f6b560;

$grid-theme: grid-theme(
  $background: $background,
  $foreground: $foreground,
  $accent-color: $accent,
  
  $row-selected-background: #012724,
  $row-selected-text-color: $accent,
  $header-selected-text-color: $accent,
  $header-selected-background: #012427,
  
  $row-selected-hover-background: hsl(from #012427 h s 10%),
  $row-selected-hover-text-color: $accent,
);
```

</ComponentBlock>
<ComponentBlock for="Grid, HierarchicalGrid, PivotGrid">

```scss
$background: #011627;
$accent: #ecaa53;

$custom-grid-theme: grid-theme(
  $row-selected-background: $background,
  $row-selected-text-color: $accent,
  $row-selected-hover-background: hsl(from $background h s 10%),
  $row-selected-hover-text-color: $accent,
  $header-selected-text-color: $accent,
  $header-selected-background: $background,
);
```

</ComponentBlock>

<ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> acepta varios parámetros, pero estos son los cinco responsables de cambiar la apariencia de todas las columnas seleccionadas:

- **$row-selected-background**: establece el fondo de la fracción seleccionada.
- **$row-selected-text-color**: establece el color del texto de la fracción seleccionada
- **$row-selected-hover-background**: establece el color de la celda o del grupo de celdas sobre el que se pasa el ratón.
- **$row-selected-hover-text-color**: establece el color del texto de la celda o del grupo de celdas sobre el que se pasa el ratón.
- **$header-selected-text-color**: establece el color del texto del encabezado de la columna seleccionada
- **$header-selected-background**: establece el color de fondo del encabezado de la columna seleccionada.

### Uso de variables CSS

El último paso es **incluir** el tema personalizado de la cuadrícula.

```scss
:host {
  @include tokens($custom-grid-theme)
}
```
