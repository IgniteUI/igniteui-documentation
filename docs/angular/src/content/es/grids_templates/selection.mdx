## Opciones de selección en Angular Grid

El componente {ComponentTitle} de IgniteUI for Angular ofrece tres modos de selección: [selección de filas](/{igPath}/row-selection), [selección de celdas](/{igPath}/cell-selection) y [selección de columnas](/{igPath}/column-selection). De forma predeterminada, solo está habilitado el modo **selección de varias celdas** en {ComponentTitle}. Para cambiar o habilitar el modo de selección puede usar las propiedades <ApiLink type="Grid" member="rowSelection" label="rowSelection" />, <ApiLink type="Grid" member="cellSelection" label="cellSelection" /> o <ApiLink type="Column" member="selectable" label="selectable" />.

### Selección de filas en Angular

La propiedad <ApiLink type="Grid" member="rowSelection" label="rowSelection" /> le permite especificar las siguientes opciones:

- none: la selección de filas quedará deshabilitada para {ComponentTitle}
- single: estará disponible la selección de una única fila dentro de {ComponentTitle}
- multiple: la selección de varias filas estará disponible usando `Row selectors`, con una combinación de teclas como <kbd>ctrl</kbd> + <kbd>clic</kbd>, o pulsando la <kbd>tecla space</kbd> una vez que una celda tiene el foco
<ComponentBlock for="TreeGrid">
- multipleCascade: es un modo de selección en cascada, que da lugar a la selección de todos los hijos del árbol que hay debajo del registro que el usuario selecciona. En este modo, el estado de selección de un padre depende por completo del estado de selección de sus hijos.
</ComponentBlock>

> Consulte el tema [Selección de filas](/{igPath}/row-selection) para más información.

### Selección de celdas en Angular

La propiedad <ApiLink type="Grid" member="cellSelection" label="cellSelection" /> le permite especificar las siguientes opciones:

- none: la selección de celdas quedará deshabilitada para {ComponentTitle}
- single: estará disponible la selección de una única celda dentro de {ComponentTitle}.
- multiple: actualmente, este es el estado predeterminado de la selección en {ComponentTitle}. La selección de varias celdas está disponible arrastrando el ratón sobre las celdas, después de mantener pulsado continuamente el botón izquierdo del ratón.

> Consulte el tema [Selección de celdas](/{igPath}/cell-selection) para más información.

### Selección de columnas en Angular

La <ApiLink type="Column" member="selectable" label="propiedad selectable`" /> le permite especificar las siguientes opciones para cada **columna**:

- false: la selección de la columna correspondiente quedará deshabilitada para {ComponentTitle}
- true: la selección de la columna correspondiente quedará habilitada para {ComponentTitle}
- Esto da lugar a las tres variantes siguientes:
- Selección única: <kbd>clic con el ratón</kbd> sobre la celda de la columna.
- Selección de varias columnas: mantener pulsado <kbd>ctrl</kbd> + <kbd>clic con el ratón</kbd> sobre las celdas de la columna.
- Selección de un rango de columnas: mantener pulsado <kbd>shift</kbd> + <kbd>clic con el ratón</kbd> selecciona todo lo que hay entre ellas.

> Consulte el tema [Selección de columnas](/{igPath}/column-selection) para más información.

## Menú contextual del grid

Usando el evento <ApiLink type="Grid" member="contextMenu" label="contextMenu" /> puede añadir un menú contextual personalizado para facilitar su trabajo con **IgxGrid**. Con un **clic derecho** en el cuerpo de la cuadrícula, el evento emite la celda sobre la que se ha disparado. El **menú contextual** actuará sobre la celda emitida.

Si hay una **selección de varias celdas**, añadiremos lógica que comprobará si la celda seleccionada está dentro del área de la selección de varias celdas. Si es así, también emitiremos los valores de las celdas seleccionadas.

En esencia, la función principal tendrá este aspecto:

```typescript
public rightClick(eventArgs: any) {
     // Prevent the default behavior of the right click
    eventArgs.event.preventDefault();
    this.multiCellArgs = {};
    // If we have multi-cell selection, check if selected cell is within the ranges
    if (this.multiCellSelection) {
        const node = eventArgs.cell.selectionNode;
        const isCellWithinRange = this.grid1.getSelectedRanges().some(range => {
            if (node.column >= range.columnStart &&
                node.column <= range.columnEnd &&
                node.row >= range.rowStart &&
                node.row <= range.rowEnd) {
                return true;
            }
            return false;
        })
        // If the cell is within a multi-cell selection range, bind all the selected cells data
        if (isCellWithinRange) {
            this.multiCellArgs = { data: this.multiCellSelection.data };
        }
    }
    // Set the position of the context menu
    this.contextmenuX = eventArgs.event.clientX;
    this.contextmenuY = eventArgs.event.clientY;
    this.clickedCell = eventArgs.cell;
    // Enable the context menu
    this.contextmenu = true;
}
```

El menú contextual tendrá las siguientes funciones:

- Copiar el _valor_ de la celda seleccionada
- Copiar el _dataRow_ de la celda seleccionada
- Si la celda seleccionada está dentro de un **rango de selección de varias celdas**, copiar todos los _datos seleccionados_

```typescript
//contextmenu.component.ts

public copySelectedCellData(event) {
    const selectedData = { [this.cell.column.field]: this.cell.value };
    this.copyData(JSON.stringify({ [this.cell.column.field]: this.cell.value }));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copyRowData(event) {
    const selectedData = this.cell.row.data ;
    this.copyData(JSON.stringify(this.cell.row.data));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copySelectedCells(event) {
    const selectedData = this.selectedCells.data;
    this.copyData(JSON.stringify(selectedData));
    this.onCellValueCopy.emit({ data: selectedData });
}
```

El IgxGrid obtendrá los datos copiados y los pegará en un elemento contenedor.

La plantilla que vamos a usar para combinar el grid con el menú contextual:

```html
<div class="wrapper">
    <div class="grid__wrapper" (window:click)="disableContextMenu()">
        <igx-grid #grid1 [data]="data" [autoGenerate]="false" height="500px" width="100%"
            (contextMenu)="rightClick($event)" (rangeSelected)="getCells($event)"
            (selected)="cellSelection($event)">
        <!-- Columns area -->
        </igx-grid>
        @if (contextmenu==true) {
            <div>
                <contextmenu [x]="contextmenuX" [y]="contextmenuY" [cell]="clickedCell" [selectedCells]="multiCellArgs" (onCellValueCopy)="copy($event)">
                </contextmenu>
            </div>
        }
    </div>
    <div class="selected-data-area">
        <div>
           <pre>{{copiedData}}</pre>
        </div>
    </div>
</div>
```

 Seleccione varias celdas y pulse el botón `right mouse`. Aparecerá el menú contextual y, al seleccionar `Copy cells data`, los datos seleccionados aparecerán en el cuadro vacío de la derecha.

## Problemas conocidos y limitaciones

- Usar {ComponentTitle} con la selección habilitada en IE11 requiere importar explícitamente el polyfill de array en polyfill.ts de la aplicación Angular. IE11 ya no se admite desde la versión 13.0.0.

    ```typescript
    import 'core-js/es7/array';
    ```

- Cuando el grid no tiene `primaryKey` establecido y los escenarios de datos remotos están habilitados (cuando la paginación, la ordenación, el filtrado o el desplazamiento provocan solicitudes a un servidor remoto para obtener los datos que se mostrarán en el grid), una fila perderá el siguiente estado tras completarse una solicitud de datos:
  - Selección de filas
  - Expandir/contraer filas
  - Edición de filas
  - Anclaje de filas
