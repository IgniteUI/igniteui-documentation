# Tipos de columna de {ComponentTitle} en Angular

{ComponentTitle} de Ignite UI for Angular ofrece un tratamiento predeterminado de los tipos de datos de columna _number_, _string_, _date_, _boolean_, _currency_ y _percent_, a partir de los cuales se determina el aspecto de las plantillas predeterminada y de edición.

## Plantilla predeterminada

Si quiere habilitar una plantilla específica del tipo de datos, debe establecer la entrada <ApiLink type="Column" member="dataType" label="dataType" /> de la columna; de lo contrario, la columna se tratará como una columna de cadena, ya que ese es el valor predeterminado de dataType. Veamos cuáles son las plantillas predeterminadas de cada tipo.

### String

Esta columna <ApiLink type="Column" member="dataType" label="dataType" /> no cambia el aspecto ni el formato del valor de la celda.

### Número

Si <ApiLink type="Column" member="dataType" label="dataType" /> se establece en _number_, el valor de la celda se dará formato según la configuración de la aplicación o del <ApiLink type="Grid" member="locale" label="locale" /> de la cuadrícula, así como cuando se especifica la propiedad <ApiLink type="Column" member="pipeArgs" label="pipeArgs" />. Entonces el formato numérico cambiará según ellos; por ejemplo, podría cambiar:

- El número de dígitos después del punto decimal
- El separador decimal con `,` o `.`

```ts
public options = {
  digitsInfo: '1.4-4',
};
public formatOptions = this.options;
```

```html
<igx-column [pipeArgs]="formatOptions" [dataType]="'number'">
</igx-column>
```

### DateTime, Date y Time

El aspecto de las partes de la fecha (por ejemplo, día, mes, año) se establecerá según el formato de <ApiLink type="Grid" member="locale" label="locale" /> o la entrada <ApiLink type="Column" member="pipeArgs" label="pipeArgs" />. Los argumentos del pipe pueden usarse para especificar un [formato de fecha](https://angular.io/api/common/DatePipe#pre-defined-format-options) o una [zona horaria](https://angular.io/api/common/DatePipe#parameters) personalizados:

- **format**: el valor predeterminado para dar formato a la fecha es 'mediumDate'. Otras opciones disponibles son 'short', 'long', 'shortDate', 'fullDate', 'longTime', 'fullTime', etc. Esta es la lista completa de todas las [opciones de formato predefinidas de Angular](https://angular.io/api/common/DatePipe#pre-defined-format-options) (heredadas).
- **timezone**: el valor predeterminado es la zona horaria local del sistema del usuario. También puede pasarse el desfase horario, o la abreviatura estándar GMT/UTC o de la zona horaria continental de EE. UU. Estos son distintos ejemplos de zonas horarias que mostrarán la hora correspondiente de cualquier lugar del mundo:

<DocsAside type="info">
Desde la versión 20.2.x, si tiene desactivada la localización de Angular, la lista de opciones de formato disponibles puede consultarse en nuestro nuevo tema de [localización](../general/localization.mdx#formatting).
</DocsAside>

```ts
public formatDateOptions = {
    /** The date/time components that a date column will display, using predefined options or a custom format string. */
    /** e.g 'dd/mm/yyyy' or 'shortDate' **/
    format: 'longDate',
    /** A timezone offset (such as '+0430'), or a standard UTC/GMT or continental US timezone abbreviation. */
    timezone: 'GMT'
};
public formatOptions = this.options;
```

```html
<igx-column [pipeArgs]="formatDateOptions" [dataType]="'date'">
</igx-column>
```

Como puede ver en el ejemplo, especificamos distintas opciones de formato para mostrar los formatos disponibles para el tipo de columna concreto. Por ejemplo, a continuación encontrará las opciones de formato de la parte de _hora_ del objeto Date:

```ts
// Time format with equivalent example
public timeFormats = [
    { format: 'shortTime', eq: 'h:mm a' },
    { format: 'mediumTime', eq: 'h:mm:ss a' },
    { format: 'longTime', eq: 'h:mm:ss a z' },
    { format: 'fullTime', eq: 'h:mm:ss a zzzz' },
];
```

#### Edición de celdas

En la edición de celdas, según el tipo de columna, aparecerá un editor distinto:

- dateTime: se usará <ApiLink type="DateTimeEditorDirective" />. Este editor le ofrece indicaciones de máscara para los elementos de entrada que forman parte del objeto DateTime.
- date: se usará <ApiLink type="DatePicker" />.
- time: se usará <ApiLink type="TimePicker" />.

#### Filtrado

Se usarán los mismos editores indicados antes para el filtrado rápido o el filtrado al estilo de Excel. Estos son los operandos de filtrado que expone cada tipo:

- dateTime y date: Equals, Does Not Equal, Before, After, Today, Yesterday, This Month, Last Month, Next Month, This Year, Last Year, Next Year, Empty, Not Empty, Null, Not Null;
- time: At, Not At, Before, After, At or Before, At or After, Empty, Not Empty, Null, Not Null;

#### Resúmenes

Los operandos de resumen disponibles serán **Count**, **Earliest** (fecha/hora) y **Latest** (fecha/hora).

#### Ordenación

Una columna de tipo time se ordena según la parte de hora del objeto; los milisegundos se ignoran.
Una columna de tipo date se ordena según la parte de fecha; se ignora la parte de hora.
Una columna DateTime se ordena según la fecha completa

### Booleano

La plantilla predeterminada usa iconos de Material para mostrar los valores booleanos: el icono 'clear' para los valores _false_ y el icono 'check' para los valores _true_. En cuanto a la plantilla de edición, usa el componente <ApiLink type="Checkbox" label="igx-checkbox" />.

```html
<igx-column [dataType]="'boolean'">
</igx-column>
```

### Moneda

#### Plantilla predeterminada

La plantilla predeterminada mostrará un valor numérico con el símbolo de moneda, antepuesto o pospuesto. Tanto la ubicación del símbolo de moneda como el formato del valor numérico se basan en la [`LOCALE_ID`](https://angular.io/api/core/LOCALE_ID) de la aplicación proporcionada o en {ComponentTitle} <ApiLink type="Grid" member="locale" label="locale" />.

_Usando LOCALE_ID_

```ts

...

 @Component({
    selector: 'app-component.sample',
    templateUrl: 'grid-component.sample.html',
    providers: [{provide: LOCALE_ID, useValue: 'fr-FR' }]
})
```

_Usando la configuración regional del grid_

```html
<igx-grid [locale]="'fr-FR'" [data]="data">
</igx-grid>
```

Usando la entrada <ApiLink type="Column" member="pipeArgs" label="pipeArgs" />, el usuario final puede personalizar el formato numérico mediante el _punto decimal_, el _currencyCode_ y el _display_.

```ts
public options = {
  digitsInfo: '3.4-4',
  currencyCode: 'USD',
  display: 'symbol-narrow'
};
public formatOptions = this.options;
```

```html
<igx-column field="UnitsInStock"
    [pipeArgs]="formatOptions"
    [dataType]="'currency'">
</igx-column>
```

| Parámetro                 | Descripción                                                |
|---------------------------| -------------------------                                  |
| digitsInfo                | Representa la forma decimal del valor monetario        |
| currencyCode              | Código de moneda ISO 4217                                     |
| display*                  | Muestra el valor con el símbolo estrecho o amplio                |

*display: para la configuración regional predeterminada en-US, el código USD puede representarse con el símbolo estrecho $ o con el símbolo amplio US$.

Al editar el valor de una celda, el _símbolo de moneda_ será visible como sufijo o prefijo. Puede encontrar más información en el tema oficial [Edición de celdas](/{igPath}/cell-editing#plantillas-de-edición-de-celdas).

### Porcentaje

La plantilla predeterminada muestra el equivalente en porcentaje del valor numérico subyacente. El valor de celda mostrado es el resultado de multiplicar por el factor de visualización '100'; por ejemplo, como el factor predeterminado es 100 y el "valor" pasado a la celda es 0.123, el valor de celda mostrado será "12.3%".

En cuanto a la edición de celdas, el valor será el mismo que el del origen de datos: el factor de visualización es '1'. Al editar la celda, se mostrará una vista previa del valor en porcentaje como elemento sufijo. Por ejemplo, al editar '0.0547', el elemento de vista previa mostrará '5.47%'.

```ts
public options = {
    /**
    * Decimal representation options, specified by a string in the following format:
    * `{minIntegerDigits}`.`{minFractionDigits}`-`{maxFractionDigits}`.
    * `minIntegerDigits`: The minimum number of integer digits before the decimal point. Default is 1.
    * `minFractionDigits`: The minimum number of digits after the decimal point. Default is 0.
    * `maxFractionDigits`: The maximum number of digits after the decimal point. Default is 3.
    */
    digitsInfo: '2.2-3'
};
public formatPercentOptions = this.options;
```

```html
<igx-column field="UnitsInStock"
    [pipeArgs]="formatPercentOptions"
    [dataType]="'percent'">
</igx-column>
```

<DocsAside type="info">
Al usar las teclas de flecha arriba/abajo, el valor se incrementará o disminuirá con un paso basado en digitsInfo: minFractionDigits (el número mínimo de dígitos después del punto decimal. El valor predeterminado es 0)
</DocsAside>

### Imagen

La plantilla predeterminada usa el valor procedente de los datos como origen de una imagen en una plantilla de imagen predeterminada. La plantilla de imagen predeterminada extraerá el nombre del archivo de imagen y lo establecerá como atributo `alt` de la imagen para cumplir el requisito de accesibilidad. El tamaño de celda mostrado se ajusta al tamaño de las imágenes renderizadas, así que tenga en cuenta que las imágenes grandes se seguirán renderizando y las filas de la cuadrícula serán tan grandes como las imágenes de la columna de imagen. El filtrado, la ordenación y la agrupación están desactivados de forma predeterminada en las columnas de tipo imagen. Si quiere habilitarlos, debe proporcionar estrategias personalizadas que realicen las operaciones sobre los datos.

```html
<igx-column [dataType]="'image'">
</igx-column>
```

Cuando las columnas <ApiLink type="Grid" member="autoGenerate" label="auto-generating" />, el grid analiza los valores del primer registro de datos. Si un valor es de tipo string y coincide con el patrón de una URL que termina en una extensión de imagen (gif, jpg, jpeg, tiff, png, webp, bmp), la columna se marcará automáticamente como `dataType === GridColumnDataType.Image` y se renderizará una plantilla de imagen predeterminada.

## Plantilla de edición y formateador personalizados

La definición de una plantilla personalizada y de un formateador de columna siempre tiene prioridad sobre el tipo de datos de columna establecido:

### Plantilla personalizada

```html
<igx-grid #grid1 [data]="data | async" [autoGenerate]="false">
    <igx-column [field]="'UnitsInStock'" [dataType]="'currency'" [pipeArgs]="formatOptions" [editable]="true">
        <ng-template igxCellEditor let-value>
            {{ value | currency:'USD':'symbol':'1.0-0'}}
        </ng-template>
    </igx-column>
</igx-grid>
```

### Formateador de columna

```ts
 // Through column formatter property
public formatCurrency(value: number) {
    return `Dollar sign ${value.toFixed(0)}`;
}

public init(column: IgxColumnComponent) {
    switch (column.field) {
        case 'UnitsInStock':
            column.formatter = this.formatCurrency;
            break;
        default:
            return;
}
```
