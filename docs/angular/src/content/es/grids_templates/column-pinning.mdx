# Anclaje de columnas de {ComponentTitle} en Angular

Una columna o varias columnas pueden anclarse al lado izquierdo o derecho del grid de interfaz de Angular. El **anclaje de columnas** en Ignite UI for Angular permite a los usuarios finales bloquear columnas en un orden determinado, de modo que puedan verlas mientras se desplazan horizontalmente por {ComponentTitle}. El Material UI Grid tiene una interfaz integrada de anclaje de columnas, que puede usarse desde la barra de herramientas de {ComponentTitle} para cambiar el estado de anclaje de las columnas. Además, puede definir una interfaz personalizada y cambiar el estado de anclaje de las columnas mediante la API de anclaje de columnas.

## API de anclaje de columnas

El anclaje de columnas se controla mediante la entrada `pinned` de <ApiLink type="Column" label="igx-column" />. Las columnas ancladas se muestran de forma predeterminada en el lado izquierdo de {ComponentTitle} y permanecen fijas mientras se desplazan horizontalmente las columnas no ancladas en el cuerpo de {ComponentTitle}.

<ComponentBlock for="Grid">

```html
<igx-grid #grid1 [data]="data | async" [width]="700px" [autoGenerate]="false" (columnInit)="initColumns($event)"
    (selected)="selectCell($event)">
    <igx-column [field]="Name" [pinned]="true"></igx-column>
    <igx-column [field]="AthleteNumber"></igx-column>
    <igx-column [field]="TrackProgress"></igx-column>
    <igx-paginator [perPage]="10">
    </igx-paginator>
</igx-grid>
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```html
<igx-tree-grid #treeGrid [data]="data" primaryKey="ID" foreignKey="ParentID" [autoGenerate]="false">
    <igx-column [field]="Name" [pinned]="true"></igx-column>
    <igx-column [field]="Title"></igx-column>
    <igx-column [field]="ID"></igx-column>
</igx-tree-grid>
```

</ComponentBlock>

<ComponentBlock for="HierarchicalGrid">

```html
<igx-hierarchical-grid class="hgrid" [data]="localdata" [autoGenerate]="false"
        [height]="'600px'" [width]="'800px'" #hierarchicalGrid>
    <igx-column [field]="Artist" [width]="200px" [pinned]="true"></igx-column>
    <igx-column [field]="Debut" [width]="200px"></igx-column>
</igx-hierarchical-grid>
```

</ComponentBlock>

También puede usar los métodos <ApiLink type="{ComponentApiType}" member="pinColumn" label="pinColumn" /> o <ApiLink type="{ComponentApiType}" member="unpinColumn" label="unpinColumn" /> de {ComponentTitle} de <ApiLink type="{ComponentApiType}" /> para anclar o desanclar columnas por su nombre de campo:

<ComponentBlock for="Grid">

```typescript
this.grid.pinColumn('AthleteNumber');
this.grid.unpinColumn('Name');
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```typescript
this.treeGrid.pinColumn('Title');
this.treeGrid.unpinColumn('Name');
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```typescript
this.hierarchicalGrid.pinColumn('Artist');
this.hierarchicalGrid.unpinColumn('Debut');
```

</ComponentBlock>

Ambos métodos devuelven un valor booleano que indica si su operación respectiva se ha realizado correctamente. Normalmente fallan porque la columna ya está en el estado deseado.

Una columna se ancla a la derecha de la columna anclada más a la derecha. Para cambiar el orden de las columnas ancladas, puede suscribirse al evento <ApiLink type="{ComponentApiType}" member="columnPin" label="columnPin" /> y cambiar la propiedad <ApiLink kind="interface" type="IPinColumnEventArgs" member="insertAtIndex" /> de los argumentos del evento a la posición de índice deseada.

<ComponentBlock for="Grid">

```html
<igx-grid #grid1 [data]="data | async" [autoGenerate]="true" (columnPin)="columnPinning($event)"></igx-grid>
```

```typescript
public columnPinning(event) {
    if (event.column.field === 'Name') {
        event.insertAtIndex = 0;
    }
}
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```html
<igx-tree-grid #treeGrid [data]="data" primaryKey="ID" foreignKey="ParentID" [autoGenerate]="true" (columnPin)="columnPinning($event)"></igx-tree-grid>
```

```typescript
public columnPinning(event) {
    if (event.column.field === 'Name') {
        event.insertAtIndex = 0;
    }
}
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```html
<igx-hierarchical-grid class="hgrid" [data]="localdata" [autoGenerate]="false"
        [height]="'600px'" [width]="'800px'" 
        (columnPin)="columnPinning($event)" #hierarchicalGrid>
</igx-hierarchical-grid> 
```

```typescript

```

## Posición del anclaje

Puede cambiar la posición del anclaje de columnas mediante la opción de configuración <ApiLink type="{ComponentApiType}" member="pinning" label="pinning" />. Permite establecer la posición de las columnas en Start o End.
Cuando se establece en End, las columnas se renderizan al final de la cuadrícula, después de las columnas no ancladas. Las columnas no ancladas pueden desplazarse horizontalmente, mientras que las columnas ancladas permanecen fijas a la derecha.

<ComponentBlock for="Grid">

```html
<igx-grid [data]="data" [autoGenerate]="true" [pinning]="pinningConfig"></igx-grid>
```

</ComponentBlock>

<ComponentBlock for="TreeGrid">

```html
<igx-tree-grid #grid1 [data]="data" [autoGenerate]="true" [pinning]="pinningConfig"></igx-tree-grid>
```

</ComponentBlock>

<ComponentBlock for="HierarchicalGrid">

```html
<igx-hierarchical-grid #grid1 [data]="data" [autoGenerate]="true" [pinning]="pinningConfig"></igx-hierarchical-grid>
```

</ComponentBlock>

```typescript
public pinningConfig: IPinningConfig = { columns: ColumnPinningPosition.End };
```

## Interfaz personalizada de anclaje de columnas

Puede definir su propia interfaz y cambiar el estado de anclaje de las columnas mediante la API relacionada.

Supongamos que, en lugar de una barra de herramientas, quiere definir iconos de anclaje en los encabezados de las columnas que el usuario final pueda pulsar para cambiar el estado de anclaje de una columna concreta.
Para ello, puede crear una plantilla de encabezado para la columna con un icono personalizado.

<ComponentBlock for="Grid">

```html
<igx-grid #grid1 [data]="data" [width]="'100%'" [height]="'500px'">
    <igx-column #col *ngFor="let c of columns" [field]="c.field" [header]="c.header" [width]="c.width" [pinned]='c.pinned'
        [hidden]='c.hidden' [headerClasses]="'customHeaderSyle'">
        <ng-template igxHeader>
            <div class="title-inner">
                <span style="float:left">{{col.header}}</span>
                <igx-icon class="pin-icon" fontSet="fas" name="fa-thumbtack" (click)="toggleColumn(col)"></igx-icon>
            </div>
        </ng-template>
    </igx-column>
</igx-grid>
```

</ComponentBlock>

Al hacer clic en el icono personalizado, puede cambiarse el estado de anclaje de la columna correspondiente usando los métodos de la API de la columna.

```typescript
public toggleColumn(col: ColumnType) {
    col.pinned ? col.unpin() : col.pin();
}
```

## Limitaciones del anclaje

- Establecer explícitamente los anchos de columna en porcentaje (%) hace que el cuerpo y el contenido del encabezado de {ComponentTitle} se desalineen cuando hay columnas ancladas. Para que el anclaje de columnas funcione correctamente, los anchos de columna deben estar en píxeles (px) o asignarse automáticamente mediante {ComponentTitle}.

## Estilos

El igxGrid permite dar estilo mediante la [Biblioteca de temas de Ignite UI for Angular](/themes/sass/component-themes). La <ApiLink kind="sass" module="themes" type="function-grid-theme" label="theme" /> de la cuadrícula expone una gran variedad de propiedades que permiten personalizar todas las funciones de la cuadrícula.

En los pasos siguientes veremos cómo personalizar el estilo del anclaje de la cuadrícula.

### Importar el tema global

Para empezar a personalizar la función de anclaje, debe importar el archivo `index`, donde se encuentran todas las funciones de estilo y los mixins.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### Definir un tema personalizado

A continuación, cree un tema nuevo que extienda <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> y acepte los parámetros necesarios para personalizar la función de anclaje como desee.

```scss
$custom-theme: grid-theme(
  $pinned-border-width: 5px,
  $pinned-border-style: double,
  $pinned-border-color: #ffcd0f,
  $cell-active-border-color: #ffcd0f
);
```

<DocsAside type="info">
En lugar de codificar los valores de color como acabamos de hacer, podemos lograr más flexibilidad con los colores usando las funciones <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> y <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Consulte el tema [`Palettes`](/themes/sass/palettes) para obtener orientación detallada sobre cómo usarlas.
</DocsAside>

### Aplicar el tema personalizado

La forma más sencilla de aplicar su tema es con una sentencia `sass` `@include` en el archivo de estilos global:

```scss
:host {
  @include tokens($custom-theme);
}
```
