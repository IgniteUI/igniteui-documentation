# Resúmenes de {ComponentTitle} en Angular

El grid de interfaz de Angular de Ignite UI for Angular tiene una función de **resúmenes** que funciona por columna, como pie de grupo. Los resúmenes del grid de Angular son una función potente que permite al usuario ver la información de la columna en un contenedor aparte, con un conjunto predefinido de elementos de resumen predeterminados según el tipo de datos de la columna, o implementando una plantilla de Angular personalizada en {ComponentTitle}.

<DocsAside type="info">
El resumen de la columna es una **función de todos los valores de la columna**, salvo que se aplique un filtro; entonces el resumen de la columna será una **función de los valores del resultado filtrado**
</DocsAside>

Los **{ComponentTitle} resúmenes** también pueden habilitarse por columna en Ignite UI for Angular, lo que significa que puede activarlos solo para las columnas que necesite. Los resúmenes {ComponentTitle} le ofrecen un conjunto predefinido de resúmenes predeterminados, según el tipo de datos de la columna, para que ahorre tiempo:

Para `string` y `boolean` <ApiLink type="Column" member="dataType" label="tipos de datos" />, está disponible la siguiente función:

- count

Para los tipos de datos `number`, `currency` y `percent`, están disponibles las siguientes funciones:

- count
- min
- max
- average
- sum

Para el tipo de datos `date`, están disponibles las siguientes funciones:

- count
- earliest
- latest

Todos los tipos de datos de columna disponibles se pueden consultar en el tema oficial [Tipos de columna](/{igPath}/column-types#plantilla-predeterminada).

Los **{ComponentTitle} resúmenes** se habilitan por columna estableciendo la propiedad <ApiLink type="Column" member="hasSummary" label="hasSummary" /> en `true`. También es importante tener en cuenta que los resúmenes de cada columna se resuelven según el tipo de datos de la columna. En `{ComponentSelector}`, el tipo de datos predeterminado de la columna es `string`, así que si quiere resúmenes específicos de `number` o de `date`, debe especificar la propiedad <ApiLink type="Column" member="datatype" label="dataType" /> como `number` o `date`. Tenga en cuenta que los valores de resumen se mostrarán localizados, según la <ApiLink type="Grid" member="locale" label="locale" /> de la cuadrícula y la <ApiLink type="Column" member="pipeArgs" label="pipeArgs" /> de la columna.

## Resúmenes {ComponentTitle} personalizados

Si estas funciones no cumplen sus requisitos, puede proporcionar un resumen personalizado para columnas específicas. Para lograrlo, debe sobrescribir una de las clases base <ApiLink type="SummaryOperand" />, <ApiLink type="NumberSummaryOperand" /> o <ApiLink type="DateSummaryOperand" /> según el tipo de datos de la columna y sus necesidades. Así puede redefinir la función existente o añadir funciones nuevas. La clase <ApiLink type="SummaryOperand" /> proporciona la implementación predeterminada solo para el método <ApiLink type="SummaryOperand" member="count" label="count" />. <ApiLink type="NumberSummaryOperand" /> extiende <ApiLink type="SummaryOperand" /> y proporciona la implementación de <ApiLink type="NumberSummaryOperand" member="min" label="min" />, <ApiLink type="NumberSummaryOperand" member="max" label="max" />, <ApiLink type="NumberSummaryOperand" member="sum" label="sum" /> y <ApiLink type="NumberSummaryOperand" member="average" label="average" />. <ApiLink type="DateSummaryOperand" /> extiende <ApiLink type="SummaryOperand" /> y además le proporciona <ApiLink type="DateSummaryOperand" member="earliest" label="earliest" /> y <ApiLink type="DateSummaryOperand" member="latest" label="latest" />.

<ComponentBlock for="Grid, TreeGrid, PivotGrid">

```typescript
import { IgxSummaryResult, IgxSummaryOperand, IgxNumberSummaryOperand, IgxDateSummaryOperand } from 'igniteui-angular/core';
// import { IgxSummaryResult, IgxSummaryOperand, IgxNumberSummaryOperand, IgxDateSummaryOperand } from '@infragistics/igniteui-angular'; for licensed package

class MySummary extends IgxNumberSummaryOperand {
    constructor() {
        super();
    }

    operate(data?: any[]): IgxSummaryResult[] {
        const result = super.operate(data);
        result.push({
            key: 'test',
            label: 'Test',
            summaryResult: data.filter(rec => rec > 10 && rec < 30).length
        });
        return result;
    }
}
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```typescript
import { IgxRowIslandComponent, IgxHierarchicalGridComponent } from 'igniteui-angular/grids/hierarchical-grid';
import { IgxNumberSummaryOperand, IgxSummaryResult } from 'igniteui-angular/core';
// import { IgxRowIslandComponent, IgxHierarchicalGridComponent, IgxNumberSummaryOperand, IgxSummaryResult } from '@infragistics/igniteui-angular'; for licensed package

class MySummary extends IgxNumberSummaryOperand {
    constructor() {
        super();
    }

    public operate(data?: any[]): IgxSummaryResult[] {
        const result = super.operate(data);
        result.push({
            key: 'test',
            label: 'More than 5',
            summaryResult: data.filter((rec) => rec > 5).length
        });

        return result;
    }
}
```

</ComponentBlock>

Como se ve en los ejemplos, las clases base exponen el método <ApiLink type="SummaryOperand" member="operate" label="operate" />; así puede optar por obtener todos los resúmenes predeterminados y modificar el resultado, o calcular resultados de resumen completamente nuevos.
El método devuelve una lista de <ApiLink type="IgxSummaryResult" kind="interface" />.

```typescript
interface IgxSummaryResult {
    key: string;
    label: string;
    summaryResult: any;
}
```

y aceptan parámetros opcionales para calcular los resúmenes.
Consulte la sección [Resúmenes personalizados que acceden a todos los datos](#resúmenes-personalizados-que-acceden-a-todos-los-datos) más abajo.

<DocsAside type="info">
Para calcular correctamente la altura de la fila de resumen, {ComponentTitle} necesita que el método <ApiLink type="SummaryOperand" member="operate" label="operate" /> devuelva siempre un array de <ApiLink type="IgxSummaryResult" kind="interface" /> con la longitud adecuada, incluso cuando los datos están vacíos.
</DocsAside>

### Resúmenes personalizados que acceden a todos los datos

 Ahora puede acceder a todos los datos de {ComponentTitle} dentro del resumen personalizado de la columna. En el método `operate` de IgxSummaryOperand se introducen dos parámetros opcionales adicionales.
Como puede ver en el fragmento de código siguiente, el método operate tiene tres parámetros:

- columnData: le proporciona un array que contiene solo los valores de la columna actual
- allGridData: le proporciona el origen de datos completo de la cuadrícula
- fieldName: el campo de la columna actual

<ComponentBlock for="TreeGrid">

```typescript
class MySummary extends IgxNumberSummaryOperand {
    constructor() {
        super();
    }
    operate(columnData: any[], allGridData = [], fieldName?): IgxSummaryResult[] {
        const result = super.operate(allData.map(r => r[fieldName]));
        result.push({ key: 'test', label: 'Total Undelivered', summaryResult: allData.filter((rec) => rec.Discontinued).length });
        return result;
    }
}
```

</ComponentBlock>

### Plantilla de resumen

`igxSummary` se dirige al resumen de la columna y proporciona como contexto los resultados del resumen de la columna.

```html
<igx-column ... [hasSummary]="true">
    <ng-template igxSummary let-summaryResults>
        <span> My custom summary template</span>
        <span>{{ summaryResults[0].label }} - {{ summaryResults[0].summaryResult }}</span>
    </ng-template>
</igx-column>
```

Cuando se define un resumen predeterminado, la altura del área de resumen se calcula por diseño en función de la columna con mayor número de resúmenes y del tamaño de la cuadrícula. Use la propiedad de entrada <ApiLink type="Grid" member="summaryRowHeight" label="summaryRowHeight" /> para sustituir el valor predeterminado. Como argumento espera un valor numérico; si se establece un valor falso, se activará el comportamiento predeterminado de dimensionamiento del pie de la cuadrícula.

<DocsAside type="info">
La plantilla de resumen de la columna puede definirse mediante la API estableciendo la propiedad <ApiLink type="Column" member="summaryTemplate" label="summaryTemplate" /> de la columna en el TemplateRef requerido.
</DocsAside>

## Deshabilitar resúmenes

La propiedad <ApiLink type="{ComponentApiType}" member="disabledSummaries" label="disabledSummaries" /> ofrece un control preciso por columna sobre la función de resúmenes de la cuadrícula de Ignite UI for Angular. Esta propiedad permite personalizar los resúmenes que se muestran para cada columna de la cuadrícula, garantizando que solo se muestren los datos más relevantes y significativos. Por ejemplo, puede excluir tipos de resumen concretos, como `['count', 'min', 'max']`, indicando sus claves de resumen en un array.

Esta propiedad también puede modificarse **dinámicamente en tiempo de ejecución** mediante código, lo que permite adaptar los resúmenes de la cuadrícula a los cambios de estado de la aplicación o a las acciones del usuario.

Los ejemplos siguientes muestran cómo usar la propiedad `disabledSummaries` para gestionar los resúmenes de distintas columnas y excluir tipos concretos de resúmenes predeterminados y personalizados en la cuadrícula de Ignite UI for Angular:

<ComponentBlock for="Grid">

```html
<!-- default summaries -->
<igx-column
    field="UnitPrice"
    header="Unit Price"
    dataType="number"
    [hasSummary]="true"
    [disabledSummaries]="['count', 'sum', 'average']"
>
</igx-column>
<!-- custom summaries -->
<igx-column
    field="UnitsInStock"
    header="Units In Stock"
    dataType="number"
    [hasSummary]="true"
    [summaries]="discontinuedSummary"
    [disabledSummaries]="['discontinued', 'totalDiscontinued']"
>
</igx-column>
```

Para `UnitPrice`, los resúmenes predeterminados como `count`, `sum` y `average` están deshabilitados, y los demás, como `min` y `max`, permanecen activos.

Para `UnitsInStock`, los resúmenes personalizados como `total` y `totalDiscontinued` se excluyen usando la propiedad `disabledSummaries`.
</ComponentBlock>
<ComponentBlock for="TreeGrid">

```html
<!-- custom summaries -->
<igx-column
    field="Units"
    header="Units"
    dataType="number"
    [hasSummary]="true"
    [summaries]="unitsSummary"
    [disabledSummaries]="['uniqueCount', 'maxDifference']"
>
</igx-column>
<!-- default summaries -->
<igx-column
    field="UnitPrice"
    header="Unit Price"
    dataType="number"
    [hasSummary]="true"
    [disabledSummaries]="['count', 'sum', 'average']"
>
</igx-column>
```

Para `Units`, los resúmenes personalizados como `totalDelivered` y `totalNotDelivered` se excluyen usando la propiedad `disabledSummaries`.

Para `UnitPrice`, los resúmenes predeterminados como `count`, `sum` y `average` están deshabilitados, y los demás, como `min` y `max`, permanecen activos.
</ComponentBlock>

## Dar formato a los resúmenes

De forma predeterminada, los resultados de resumen producidos por los operandos de resumen integrados se localizan y se formatean según la <ApiLink type="Grid" member="locale" label="locale" /> de la cuadrícula y la <ApiLink type="Column" member="pipeArgs" label="pipeArgs" /> de la columna. Al usar operandos personalizados, no se aplican `locale` ni `pipeArgs`. Si quiere cambiar el aspecto predeterminado de los resultados de resumen, puede darles formato usando la propiedad <ApiLink type="Column" member="summaryFormatter" label="summaryFormatter" />.

```typescript
public dateSummaryFormat(summary: IgxSummaryResult, summaryOperand: IgxSummaryOperand): string {
    const result = summary.summaryResult;
    if(summaryOperand instanceof IgxDateSummaryOperand && summary.key !== 'count'
        && result !== null && result !== undefined) {
        const pipe = new DatePipe('en-US');
        return pipe.transform(result,'MMM YYYY');
    }
    return result;
}
```

```html
<igx-column ... [summaryFormatter]="dateSummaryFormat"></igx-column>
```

## Resúmenes con Agrupar por

Cuando ha agrupado por columnas, {ComponentTitle} le permite cambiar la posición del resumen y el modo de cálculo usando las propiedades <ApiLink type="{ComponentApiType}" member="summaryCalculationMode" label="summaryCalculationMode" /> y <ApiLink type="{ComponentApiType}" member="summaryPosition" label="summaryPosition" />. Junto con estas dos propiedades, {ComponentName} expone además la propiedad <ApiLink type="{ComponentApiType}" member="showSummaryOnCollapse" label="showSummaryOnCollapse" />, que le permite determinar si la fila de resumen permanece visible cuando la fila de grupo a la que hace referencia está contraída.

Los valores disponibles de la propiedad <ApiLink type="{ComponentApiType}" member="summaryCalculationMode" label="summaryCalculationMode" /> son:

- rootLevelOnly: los resúmenes se calculan solo para el nivel raíz.
- childLevelsOnly: los resúmenes se calculan solo para los niveles hijos.
- rootAndChildLevels: los resúmenes se calculan tanto para el nivel raíz como para los niveles hijos. Este es el valor predeterminado.

Los valores disponibles de la propiedad <ApiLink type="{ComponentApiType}" member="summaryPosition" label="summaryPosition" /> son:

- top: la fila de resumen aparece antes de los hijos de la fila de agrupación.
- bottom: la fila de resumen aparece después de los hijos de la fila de agrupación. Este es el valor predeterminado.

La propiedad <ApiLink type="{ComponentApiType}" member="showSummaryOnCollapse" label="showSummaryOnCollapse" /> es booleana. Su valor predeterminado es **false**, lo que significa que la fila de resumen se oculta cuando la fila de grupo se contrae. Si la propiedad se establece en **true**, la fila de resumen permanece visible cuando la fila de grupo se contrae.

<DocsAside type="info">
La propiedad <ApiLink type="{ComponentApiType}" member="summaryPosition" label="summaryPosition" /> solo se aplica a los resúmenes de los niveles hijos. Los resúmenes del nivel raíz aparecen siempre fijos en la parte inferior de {ComponentTitle}.
</DocsAside>

## Resúmenes de hijos

### Limitaciones conocidas

|Limitación|Descripción|
|--- |--- |
| Exportar resúmenes personalizados | Los resúmenes personalizados se exportarán como cadenas en lugar de como funciones de Excel. |

## Navegación por teclado

Las filas de resumen pueden recorrerse con las siguientes interacciones de teclado:

- <kbd>UP</kbd>: se desplaza una celda hacia arriba
- <kbd>DOWN</kbd>: se desplaza una celda hacia abajo
- <kbd>LEFT</kbd>: se desplaza una celda a la izquierda
- <kbd>RIGHT</kbd>: se desplaza una celda a la derecha
- <kbd>CTRL</kbd> + <kbd>LEFT</kbd> o <kbd>HOME</kbd>: se desplaza a la celda más a la izquierda
- <kbd>CTRL</kbd> + <kbd>RIGHT</kbd> o <kbd>END</kbd>: se desplaza a la celda más a la derecha

Para empezar a dar estilo al comportamiento de ordenación, debemos importar el archivo `index`, donde se exportan todas las funciones de tema y el mixin `tokens()`:

:host {

</DocsAside>

```scss
:host {
  ::ng-deep {
    @include tokens($custom-theme);
  }
}
```
