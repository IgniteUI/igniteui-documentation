# Actualizaciones de datos en tiempo real de {ComponentTitle} en Angular

El componente {ComponentTitle} es capaz de gestionar miles de actualizaciones por segundo, manteniendo la capacidad de respuesta ante las interacciones del usuario.

El ejemplo siguiente muestra el rendimiento de {ComponentTitle} cuando todos los registros se actualizan varias veces por segundo. Use los controles de la interfaz para elegir el número de registros cargados y la frecuencia de las actualizaciones.

## Enlace de datos y actualizaciones

Un servicio proporciona los datos al componente cuando se carga la página, y cuando se usa el control deslizante para obtener un número determinado de registros. Mientras que en un escenario real los datos actualizados se consumirían desde el servicio, aquí los datos se actualizan en el código. Esto se hace para mantener la demostración sencilla y centrarse en su objetivo principal: mostrar el rendimiento de la cuadrícula.

```html
<igx-grid #grid [data]="data"></igx-grid>
```

```typescript
public ngOnInit() {
    this.localService.getData(this.volume);
    this.volumeSlider.onValueChange.subscribe(x => this.localService.getData(this.volume);
    this.localService.records.subscribe(x => { this.data = x; });
}
```

Los pipes de Angular se usan internamente para actualizar la vista de la cuadrícula. Un cambio en el valor de un campo de datos o un cambio en la referencia del objeto de datos o de la colección de datos activará los pipes correspondientes. Sin embargo, esto no ocurre con las columnas enlazadas a [`complex data objects`](/{igPath}/grid#enlace-de-datos-complejos), porque el pipe puro de Angular no detecta un cambio en una propiedad anidada. Para resolver la situación, proporcione una nueva referencia de objeto para el objeto de datos que contiene la propiedad. Ejemplo:

```html
<igx-grid #grid [data]="data">
    <igx-column field="price.usd"></igx-column>
</igx-grid>
```

```typescript
private updateData(data: IRecord[]) {
    const newData = []
    for (const rowData of data) {
        rowData.price = { usd: getUSD(), eur: getEUR() };
        newData.push({...rowData});
    }
    this.grid.data = newData;
}
```

## Plantillas

Actualizar la vista funciona igual para las columnas con plantilla predeterminada que para las columnas con plantilla personalizada. Sin embargo, se recomienda mantener las plantillas personalizadas relativamente sencillas. A medida que aumenta el número de elementos de la plantilla, también aumenta el impacto negativo en el rendimiento.

## Alimentación de datos en vivo con Dock Manager y componentes igxGrid

El objetivo de esta demostración es mostrar un panel financiero con un flujo de datos en tiempo real que usa un back-end de concentrador [SignalR](https://dotnet.microsoft.com/apps/aspnet/signalr).
Como puede ver, el componente igxGrid gestiona con facilidad las actualizaciones de alta frecuencia procedentes del servidor. El código de la aplicación ASP.NET Core con SignalR puede encontrarse en este [repositorio público de GitHub](https://github.com/IgniteUI/finjs-web-api).

### Iniciar la conexión del concentrador

El servicio signal-r gestiona la conectividad y las actualizaciones de los parámetros gestionables expuestos: _frecuencia_, _volumen_ y _alternancia del estado de actualización en vivo_ (Iniciar/Detener).

```ts
this.hubConnection = new signalR.HubConnectionBuilder()
        .configureLogging(signalR.LogLevel.Trace)
        .withUrl('https://www.infragistics.com/angular-apis/webapi/streamHub')
        .build();
    this.hubConnection
        .start()
        .then(() => {
            this.hasRemoteConnection = true;
            this.registerSignalEvents();
            this.broadcastParams(interval, volume, live, updateAll);
        })
        .catch(() => {});
```

Según la frecuencia especificada, los grids recibirán del servidor un total de 30 actualizaciones nuevas. Se aplican clases cellStyle específicas a las tres columnas que gestionan los cambios (Price, Change y Change in percent).

### Frecuencia de actualización y volumen de datos

Usando el panel de acciones de la izquierda, puede gestionar la frecuencia del flujo de datos y el volumen de datos solicitados. Todos los grids usan el mismo origen de datos. Siéntase libre de usar los demás elementos de acción para _detener el flujo de datos_, cambiar el _tema de la aplicación_ o añadir _dinámicamente un contenedor DockSlot_ con un igxGrid.

Usamos el método 'updateparameters' para solicitar un nuevo conjunto de datos con una frecuencia determinada. Este método forma parte de la [implementación del concentrador de streaming](https://github.com/IgniteUI/finjs-web-api/blob/master/WebAPI/Models/StreamHub.cs#L18) de SignalR.

```ts
this.hubConnection.invoke('updateparameters', frequency, volume, live, updateAll)
    .then(() => console.log('requestLiveData', volume))
    .catch(err => {
        console.error(err);
    });
```

### Crear dinámicamente los componentes DockSlot y Grid

Usando [ComponentFactoryResolver](https://angular.io/api/core/ComponentFactoryResolver) podemos crear los componentes DockSlot y Grid sobre la marcha.

### Componente DockManager

Aproveche el WebComponent [Dock Manager](/dock-manager) y cree su propia vista web usando paneles acoplados o flotantes. Para añadir un nuevo panel flotante, abra el panel de acciones de la derecha y haga clic en el botón 'Add floating pane'. Arrastre y suelte el nuevo panel en la ubicación deseada.
