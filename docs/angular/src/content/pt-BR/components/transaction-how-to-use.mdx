# Como usar o Transaction service

Você pode aproveitar o <ApiLink kind="interface" type="TransactionService" label="Transaction Service" /> ao usar qualquer componente que precise preservar o estado da sua fonte de dados e confirmar muitas transações de uma só vez.

Ao trabalhar com os componentes de grid do Ignite UI for Angular, você pode usar o <ApiLink type="TransactionService" /> e o <ApiLink type="HierarchicalTransactionService" />, que são integrados aos grids e oferecem edição em lote pronta para uso. No entanto, se precisar usar transações com qualquer outro componente do Ignite UI for Angular ou personalizado, você pode novamente usar o <ApiLink type="TransactionService" /> e implementar um comportamento semelhante.

## Exemplo de como usar o Transaction service no Angular

Neste tópico, usaremos o componente <ApiLink type="List" label="igxList" /> para demonstrar como habilitar transações. Vamos demonstrar como adicionar transações, como transformar os dados por meio de um [pipe](https://angular.io/guide/pipes) e como atualizar visualmente a visualização, para que o usuário veja as alterações que estão prestes a ser confirmadas.

## Incluindo o Transaction Service

### Incluindo o Transaction Service no projeto

Temos duas opções para incluir o `IgxTransactionService` na nossa aplicação. A primeira é adicioná-lo ao `AppModule` ou a outro módulo pai da aplicação, como foi feito na demonstração acima:

```typescript
@NgModule({
    ...
    providers: [
        IgxTransactionService
    ]
})
export class AppModule { }
```

A outra opção é fornecê-lo no componente em que o serviço de transações é usado:

```typescript
@Component({
    selector: 'transaction-base',
    styleUrls: ['./transaction-base.component.scss'],
    templateUrl: 'transaction-base.component.html',
    providers: [IgxTransactionService]
})
export class TransactionBaseComponent { }
```

### Injetando o Transaction Service no componente

No nosso arquivo `ts`, devemos importar o <ApiLink type="TransactionService" /> da biblioteca `igniteui-angular`, bem como as interfaces <ApiLink type="State" kind="interface" /> e <ApiLink type="Transaction" kind="interface" /> e a enumeração <ApiLink pkg="core" type="TransactionType" kind="enum" />, que serão necessárias na nossa aplicação:

```typescript
import { IgxTransactionService, State, Transaction, TransactionType } from 'igniteui-angular/core';
// import { IgxTransactionService, State, Transaction, TransactionType } from '@infragistics/igniteui-angular'; for licensed package
```

Em seguida, o Transaction Service deve ser importado no construtor:

```typescript
constructor(private _transactions: IgxTransactionService<Transaction, State>) { ... }
```

## Definindo o igxList

No nosso template HTML, definimos um componente <ApiLink type="List" label="igxList" /> com ações de **editar**, **excluir** e **adicionar**, que modificam a lista e os seus itens:

```html
<igx-list>
    <igx-list-item [isHeader]="true">Wishlist</igx-list-item>
    <igx-list-item *ngFor="let item of this.wishlist | transactionBasePipe"
        [ngClass]="{ deleted: isDeleted(item.id), edited: isEdited(item.id) }">
        <p igxListLineTitle>{{item.name}}</p>
        <p igxListLineSubTitle>Costs: {{item.price}}</p>
        @if (item.id === 1 && item.price !== '$999') {
            <igx-icon igxListAction (click)="onEdit()">edit</igx-icon>
        }
        @if (item.id === 2 && !isDeleted(item.id)) {
            <igx-icon igxListAction (click)="onDelete()">delete</igx-icon>
        }
    </igx-list-item>
    <button igxButton (click)="onAdd()" [disabled]="itemAdded(4)">Add New</button>
</igx-list>
```


<DocsAside type="info">
Este exemplo usa `igx-icon` com a família padrão Material Icons. Adicione o seguinte link ao seu `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

## Pipe para alterações pendentes

O componente de lista acima usa o `transactionBasePipe` para exibir as alterações nos itens da lista de desejos sem afetar os dados originais. Veja como o pipe é:

```typescript
@Pipe({
    name: 'transactionBasePipe',
    pure: false
})
export class TransactionBasePipe implements PipeTransform {
    /**
     * @param transactions Injected Transaction Service.
     */
    constructor(public transactions: IgxTransactionService<Transaction, State>) { }

    public transform(data: WishlistItem[]) {
        // the pipe should NOT operate on the original dataset
        // we create a copy of the original data and then use it for visualization only
        const _data = [...data];
        const pendingStates = this.transactions.getAggregatedChanges(false);

        for (const state of pendingStates) {
            switch (state.type) {
                case TransactionType.ADD:
                    // push the newValue property of the current `ADD` state
                    _data.push(state.newValue);
                    break;
                case TransactionType.DELETE:
                    // pipe doesn't delete items because the demo displays them with a different style
                    // the record will be deleted once the state is committed
                    break;
                case TransactionType.UPDATE:
                    const index = _data.findIndex(x => x.id === state.id);
                    // merge changes with the item into a new object
                    // to avoid modifying the original data item
                    _data[index] = Object.assign({}, _data[index], state.newValue);
                    break;
                default:
                    return _data;
            }
        }

        return _data;
    }
}
```

## Funcionalidade de editar, excluir e adicionar

### Definindo a funcionalidade de edição

O segundo item da lista contém um botão de editar, que atualiza os dados do item.

```html
@if (item.id === 1 && item.price !== '$999') {
    <igx-icon igxListAction (click)="onEdit()">edit</igx-icon>
}
```

Quando o botão é pressionado, dentro do manipulador de evento `onEdit`, é criada uma transação 'UPDATE':

```typescript
public onEdit(): void {
    const newPrice = "$999";
    // there can be multiple `UPDATE` transactions for the same item `id`
    // the `newValue` property should hold only the changed properties
    const editTransaction: Transaction = {
        id: this.wishlist[0].id,
        type: TransactionType.UPDATE,
        newValue: { price: newPrice }
    };
    // provide the first wishlist item as a `recordRef` argument
    this.transactions.add(editTransaction, this.wishlist[0]);
}
```

Além disso, há uma função que verifica se os itens têm edições não salvas:

```typescript
public isEdited(id): boolean {
    const state = this.transactions.getState(id);
    return state && state.type === TransactionType.UPDATE;
}
```

### Definindo a funcionalidade de exclusão

O terceiro item da lista contém um botão de excluir, que apaga os dados do item.

```html
@if (item.id === 2 && !isDeleted(item.id)) {
    <igx-icon igxListAction (click)="onDelete()">delete</igx-icon>
}
```

Quando o botão é pressionado, dentro do manipulador de evento `onDelete`, é criada uma transação 'DELETE':

```typescript
public onDelete(): void {
    // after a `DELETE` transaction, no further changes should be made for the same `id`
    // the `newValue` property should be set to `null` since we do not change any values,
    const deleteTransaction: Transaction = {
        id: this.wishlist[1].id,
        type: TransactionType.DELETE,
        newValue: null
    };
    // provide the second wishlist item as a `recordRef` argument
    this.transactions.add(deleteTransaction, this.wishlist[1]);
}
```

Além disso, há uma função que verifica se os itens têm exclusões não salvas:

```typescript
public isDeleted(id): boolean {
    const state = this.transactions.getState(id);
    return state && state.type === TransactionType.DELETE;
}
```

### Definindo a funcionalidade de adição

No fim da lista, é adicionado um botão ADD, que inclui um novo item na lista.

```html
<button igxButton (click)="onAdd()" [disabled]="itemAdded(4)">Add New</button>```
```

Quando o botão é pressionado, dentro do manipulador de evento `onAdd`, é criada uma transação 'ADD':

```typescript
public onAdd(): void {
    // it must have a unique 'id' property
    const item: WishlistItem = { id: 4, name: 'Yacht', price: 'A lot!' };

    // in an `ADD` transaction you do not need to provide a `recordRef` argument,
    // since there is nothing to refer to yet
    this.transactions.add({ id: 4, type: TransactionType.ADD, newValue: item });
}
```

Além disso, há uma função que verifica se os itens têm adições não salvas:

```typescript
public itemAdded(id: number): boolean {
    const found = this.transactions.getState(id) || this.wishlist.find(x => x.id === 4);
    return !!found;
}
```

## Log de transações

A demonstração mostra as transações pendentes dentro de um log:

```html
<div>
    <h5>Transaction Log</h5>
    <div *ngFor="let transaction of this.getTransactionLog()">
        {{transaction.type.toUpperCase()}} -> {{transaction.name}} Costs: {{transaction.price}}
    
</div>
</div>
```

```typescript
public getTransactionLog(): any[] {
    return this.transactions.getTransactionLog().map(transaction => {
        const item = this.wishlist.find(x => x.id === transaction.id);
        return Object.assign({ type: transaction.type }, item, transaction.newValue);
    });
}
```

Também vamos adicionar uma representação do estado atual da nossa lista. Ela mostrará como os dados ficam antes de as transações pendentes serem confirmadas:

```html
<div>
    <h5>Data Items</h5>
    <div *ngFor="let item of this.wishlist">
        <div>{{item.name}} - {{item.price}}
</div>
    
</div>
</div>
```

## Confirmando as transações pendentes

Quando terminarmos todas as alterações, podemos confirmá-las de uma só vez usando o método <ApiLink type="TransactionService" member="commit" label="commit" /> do <ApiLink type="TransactionService" />. Ele aplica todas as transações sobre os dados fornecidos:

```html
<button igxButton="contained" (click)="onCommit()" [disabled]="this.getTransactionLog().length === 0">Commit Transactions</button>
```

```typescript
public onCommit(): void {
    // the `commit` function expects the original data array as its parameter
    this.transactions.commit(this.wishlist);
}

```

Se estivermos usando o <ApiLink type="HierarchicalTransactionService" kind="interface" />, também podemos usar uma sobrecarga do método <ApiLink type="TransactionService" member="commit" label="commit" /> que espera primaryKey e childDataKey como argumentos.

```typescript
public onCommit(): void {
    this.transactions.commit(this.wishlist, primaryKey, childDataKey);
}
```

## Limpando as transações pendentes

Em qualquer momento da nossa interação com a lista, podemos limpar o log de transações usando o método <ApiLink type="TransactionService" member="clear" label="clear" />.

```html
<button igxButton="contained" (click)="onClear()" [disabled]="this.getTransactionLog().length === 0">Clear Transactions</button>
```

```typescript
public onClear(): void {
    this.transactions.clear();
}

```
