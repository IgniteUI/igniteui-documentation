# Visão geral do Angular Icon Button

A diretiva Icon Button do Ignite UI for Angular foi projetada para transformar qualquer ícone em um botão totalmente funcional. O `igxIconButton` vem em três tipos - flat, outlined e contained, sendo este último o padrão.

## Primeiros passos com o Icon Button do Ignite UI for Angular

Para começar com a diretiva Icon Button do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](/general/getting-started).

O próximo passo é importar o `IgxIconButtonDirective` como dependência standalone:

```typescript
// home.component.ts

...
import { IgxIconButtonDirective } from 'igniteui-angular/directives';
// import { IgxIconButtonDirective } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
        <button igxIconButton="outlined">
            <igx-icon>home</igx-icon>
        </button>`,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxIconButtonDirective]
})
export class HomeComponent {}
```


<DocsAside type="info">
Este componente usa Material Icons. Adicione o seguinte link ao seu `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

Agora que você importou a diretiva Icon Button do Ignite UI for Angular, pode começar a usar a diretiva `igxIconButton` nos elementos.

## Tipos de Angular Icon Button

### Botão de ícone flat

Use a diretiva <ApiLink type="IconButtonDirective" label="igxIconButton" /> para adicionar um botão de ícone flat simples no template do seu componente:

```html
<button igxIconButton="flat">
    <igx-icon>edit</igx-icon>
</button>
```

<Sample src="/data-entries/flat-icon-button" height={70} iframeOnly />

### Botão de ícone contained

Tudo o que você precisa fazer para criar um botão de ícone contained é alterar o valor da propriedade `igxIconButton`. Observe que, se você não escolher um tipo, ele também será definido como `contained` por padrão.

```html
<button igxIconButton>
    <igx-icon>favorite</igx-icon>
</button>
```

<Sample src="/data-entries/contained-icon-button" height={70} iframeOnly />

### Botão de ícone outlined

De forma análoga, podemos mudar para o tipo outlined:

```html
<button igxIconButton="outlined">
    <igx-icon>more_vert</igx-icon>
</button>
```

<Sample src="/data-entries/outlined-icon-button" height={70} iframeOnly />

## Exemplos

### Botão de ícone desabilitado

Se quiser desabilitar um botão de ícone, você pode usar a propriedade <ApiLink type="IconButtonDirective" member="disabled" label="disabled" />. Neste exemplo, também demonstramos como usar ícones de diferentes famílias com a diretiva `igxIconButton`:

```html
<button igxIconButton="flat" disabled>
    <igx-icon family="fa" name="fa-home"></igx-icon>
</button>
```

<Sample src="/data-entries/disabled-icon-button" height={70} iframeOnly />

### Ícones SVG

Além dos material icons, a diretiva `igxIconButton` também oferece suporte ao uso de imagens SVG como ícones. Para isso, primeiro devemos injetar a dependência <ApiLink type="IconService" /> e depois usar o método <ApiLink type="IconService" member="addSvgIcon" label="addSvgIcon" /> para importar o arquivo SVG para o cache. Para mais informações, você pode ler a [seção SVG](/layouts/icon#svg-icons) no tópico de ícones.

```typescript
constructor(private _iconService: IgxIconService) { }

public ngOnInit() {
    // register custom SVG icon
    this._iconService.addSvgIcon('rain', 'assets/images/card/icons/rain.svg', 'weather-icons');
}
```

```html
<button igxIconButton>
    <igx-icon family="weather-icons" name="rain"></igx-icon>
</button>
```

<Sample src="/data-entries/svg-icon-button" height={70} iframeOnly />

### Tamanho

Os usuários podem escolher um dos três tamanhos predefinidos de `igxIconButton` usando a propriedade CSS personalizada `--ig-size`. Por padrão, o tamanho do componente é definido como medium.

Seguindo a abordagem mais simples, usamos variáveis CSS para personalizar a aparência do botão de ícone:

```scss
[igxIconButton="contained"] {
  --background: #011627;
  --foreground: #fefefe;
  --hover-foreground: #011627dc;
  --hover-background: #ecaa53;
  --focus-foreground: #011627dc;
  --focus-background: #ecaa53;
  --focus-border-color: #0116276c;
  --active-foreground: #011627dc;
  --active-background: #ecaa53;
}
```

Veja a seção <ApiLink kind="sass" module="themes" type="function-icon-button-theme" label="icon-button-theme" code={true} /> para uma lista completa dos parâmetros disponíveis para estilizar qualquer tipo de botão de ícone.

Você também pode optar por estilizar apenas os botões de um tipo específico - `flat`, `outlined` ou `contained`.
Para isso, você pode usar as novas funções de tema específicas por tipo: <ApiLink kind="sass" module="themes" type="function-flat-icon-button-theme" label="flat-icon-button-theme" code={true} />, <ApiLink kind="sass" module="themes" type="function-outlined-icon-button-theme" label="outlined-icon-button-theme" code={true} /> e <ApiLink kind="sass" module="themes" type="function-contained-icon-button-theme" label="contained-icon-button-theme" code={true} />

Aqui está um exemplo de uso da função `contained-icon-button-theme` para definir um tema personalizado em SCSS:

```scss
@use "igniteui-angular/theming" as *;

$custom-contained: contained-icon-button-theme(
    $background: #ECAA53,
);
```

Isso vai gerar um `contained icon button` totalmente temado, incluindo as cores de primeiro plano e de fundo adequadas para os seus diversos estados, como mouse sobre, foco e ativo.

### Estilizando com Tailwind

Você pode estilizar o botão de ícone usando as nossas classes utilitárias personalizadas do Tailwind. Certifique-se de [configurar o Tailwind](/themes/tailwind) primeiro.

Junto com a importação do tailwind na sua folha de estilos global, você pode aplicar os utilitários de tema desejados da seguinte forma:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

O arquivo de utilitários inclui as variantes de tema `light` e `dark`.

- Use as classes `light-*` para o tema claro.
- Use as classes `dark-*` para o tema escuro.
- Acrescente o nome do componente depois do prefixo, por exemplo, `light-icon-button`, `dark-icon-button`.

Depois de aplicadas, essas classes habilitam cálculos dinâmicos de tema. A partir daí, você pode substituir as variáveis CSS geradas usando `arbitrary properties`. Depois dos dois-pontos, informe qualquer formato de cor CSS válido (HEX, variável CSS, RGB etc.).

Você pode encontrar a lista completa de propriedades em <ApiLink kind="sass" module="themes" type="function-icon-button-theme" label="icon-button-theme" />. A sintaxe é a seguinte:

```html
<button igxIconButton class="!light-icon-button ![--icon-color:#FF4E00]">
  <igx-icon>edit</igx-icon>
</button>
```

<DocsAside type="info">
O ponto de exclamação (`!`) é obrigatório para garantir que a classe utilitária tenha precedência. O Tailwind aplica estilos em camadas e, sem marcar esses estilos como importantes, eles serão sobrescritos pelo tema padrão do componente.
</DocsAside>
