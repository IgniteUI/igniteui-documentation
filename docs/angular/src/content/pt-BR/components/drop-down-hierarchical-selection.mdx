# Drop Down hierárquico de seleção múltipla

Os exemplos a seguir mostram como criar um drop-down hierárquico de seleção múltipla, que permite ao usuário selecionar uma ou várias opções de uma lista suspensa hierárquica, em estilo de árvore.

## Visão geral do tópico

Para a lista suspensa, usaremos o <ApiLink type="DropDown" />, bem como o <ApiLink type="ToggleActionDirective" /> para abrir e fechar a lista suspensa.

Para visualizar os dados hierárquicos na lista suspensa, você pode usar o <ApiLink type="Tree" /> ou o <ApiLink type="TreeGrid" />.

O <ApiLink type="Chip" /> é usado para exibir os itens selecionados.

## Seleção

Para exibir os nós/linhas selecionados da lista, use o <ApiLink type="Chip" /> tratando os eventos que notificam mudanças de seleção e preenchendo o array `selectedNodes` / `selectedRows`. Isso pode ser feito assinando o evento <ApiLink type="Tree" member="nodeSelection" label="nodeSelection" /> do IgxTreeComponent e o evento <ApiLink type="TreeGrid" member="rowSelectionChanging" label="rowSelectionChanging" /> do IgxTreeGridComponent.

Para remover o chip do DOM e desmarcar o item da árvore/grade, você precisa tratar o evento <ApiLink type="Chip" member="remove" label="remove" /> do IgxChipComponent.

Além disso, uma forma de impedir que a lista suspensa seja fechada ao excluir um chip é verificar o caminho composto do evento em busca de um nó `igx-chip` e, em seguida, cancelar o evento no manipulador do evento <ApiLink type="DropDown" member="closing" label="closing" /> de `IgxDropDownComponent`.
