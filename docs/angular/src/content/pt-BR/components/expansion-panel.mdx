# Visão geral do componente Angular Expansion Panel

O Ignite UI for Angular oferece aos desenvolvedores um dos componentes de layout mais úteis e fáceis de usar: o Expansion Panel. Este componente rico em recursos é usado para criar uma visualização de resumo detalhado expansível/recolhível. O conteúdo pode incluir animação do Angular Expansion Panel, texto, ícones, cabeçalho, barra de ações e outros elementos.
<div class="highlight">

O Ignite UI Expansion Panel <ApiLink type="ExpansionPanel" label="igx-expansion-panel" /> é um componente de acordeão leve para Angular, que pode ser renderizado em dois estados - recolhido ou expandido. O Expansion Panel no Angular pode ser alternado por clique do mouse ou por interações com o teclado. Você também pode combinar vários Angular Expansion Panels em um acordeão Angular.
</div>

## Primeiros passos com o Expansion Panel do Ignite UI for Angular

Para começar com o componente Drop Down do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](/general/getting-started).

O próximo passo é importar o `IgxExpansionPanelModule` no arquivo **app.module.ts**.

```typescript
// app.module.ts
...
import { IgxExpansionPanelModule } from 'igniteui-angular/expansion-panel';
// import { IgxExpansionPanelModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxExpansionPanelModule],
    ...
})
export class AppModule {}
```

Alternativamente, a partir de `16.0.0` você pode importar o `IgxExpansionPanelComponent` como uma dependência independente, ou usar o token [`IGX_EXPANSION_PANEL_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/expansion-panel/src/expansion-panel/public_api.ts) para importar o componente e todos os seus componentes e diretivas de apoio.

```typescript
// home.component.ts

import { IGX_EXPANSION_PANEL_DIRECTIVES } from 'igniteui-angular/expansion-panel';
// import { IGX_EXPANSION_PANEL_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-expansion-panel>
        <igx-expansion-panel-header>
            <igx-expansion-panel-title>
            Golden Retriever
            </igx-expansion-panel-title>
            <igx-expansion-panel-description>
            Medium-large gun dog
            </igx-expansion-panel-description>
        </igx-expansion-panel-header>
        <igx-expansion-panel-body>
            The Golden Retriever is a medium-large gun dog that retrieves shot waterfowl, 
            such as ducks and upland game birds, during hunting and shooting parties. 
            The name "retriever" refers to the breed's ability to retrieve shot game undamaged due to their soft mouth. 
            Golden retrievers have an instinctive love of water, and are easy to train to basic or advanced obedience standards.
        </igx-expansion-panel-body>
    </igx-expansion-panel>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_EXPANSION_PANEL_DIRECTIVES]
    /* or imports: [IgxExpansionPanelComponent, IgxExpansionPanelHeaderComponent, IgxExpansionPanelTitleDirective, IgxExpansionPanelDescriptionDirective, IgxExpansionPanelBodyComponent] */
})
export class HomeComponent {}
```

Agora que você importou o módulo ou as diretivas do Expansion Panel do Ignite UI for Angular, pode começar a usar o componente `igx-expansion-panel`.

## Usando o Angular Expansion Panel

A tabela abaixo mostra todas as partes de marcação disponíveis para o Angular Expansion Panel.

|                      Nome da tag     |                                                                                             Descrição               |
| :-------------------------------: | :-------------------------------------------------------------------------------------------------------------------: |
|           `igx-expansion-panel`   |                                                                 O host do componente - armazena o cabeçalho e o corpo.          |
|     `igx-expansion-panel-header`  |  Armazena o cabeçalho do componente. Ele fica sempre visível. Armazena o título e a descrição, bem como qualquer conteúdo adicional  |
|      `igx-expansion-panel-title`  |                                                                        Use-o para definir o título do expansion panel.           |
| `igx-expansion-panel-description` |  Pode ser usado para fornecer um resumo curto. A descrição sempre aparece depois do título (se o título estiver definido). |
|       `igx-expansion-panel-icon`  |                                                           Use-o para alterar o ícone padrão de expandir/recolher.          |
|       `igx-expansion-panel-body`  |                               Este é o contêiner expansível, visível apenas quando o painel está expandido.      |

## Vinculação de propriedades e eventos

Podemos adicionar alguma lógica ao componente para exibir/ocultar a `igx-expansion-panel-description` de acordo com o estado atual do painel.  
Podemos fazer isso vinculando a descrição à propriedade <ApiLink type="ExpansionPanel" member="collapsed" label="collapsed" /> do controle:

```typescript
// in expansion-panel.component.ts
import { IgxExpansionPanelComponent } from 'igniteui-angular/expansion-panel';
// import { IgxExpansionPanelComponent } from '@infragistics/igniteui-angular'; for licensed package

@Component({...})
export class ExpansionPanelComponent {
    @ViewChild(IgxExpansionPanelComponent, {read: IgxExpansionPanelComponent})
    public panel: IgxExpansionPanelComponent;
}
```

```html
{/* in expansion-component.component.html */}
<igx-expansion-panel>
    <igx-expansion-panel-header>
        Golden Retriever
        @if (panel.collapsed) {
            <igx-expansion-panel-description>
                Medium-large gun dog
            </igx-expansion-panel-description>
        }
    </igx-expansion-panel-header>
    ...
</igx-expansion-panel>
```

O exemplo de código a seguir mostrará a descrição curta somente quando o componente estiver em seu estado recolhido.
Se quisermos adicionar funcionalidades mais complexas dependendo do estado do componente, também podemos vincular a um emissor de eventos.

```typescript
// in expansion-panel.component.ts

@Component({...})
export class ExpansionPanelComponent {
    ...
    public handleExpansion(args: {event: Event}): void {
        ... // Some functionality
    }
}
```

```html
{/* in expansion-component.component.html */}
<igx-expansion-panel (onExpanded)="handleExpansion($event)" (contentCollapsed)="handleCollapse($event)"></igx-expansion-panel>
```

## Personalização do componente

A <ApiLink type="ExpansionPanel" /> permite personalizar facilmente <ApiLink type="ExpansionPanelHeader" label="o cabeçalho" />.
A posição do ícone do cabeçalho pode ser configurada pela entrada <ApiLink type="ExpansionPanelHeader" member="iconPosition" label="iconPosition" /> do `igx-expansion-panel-header`. As opções possíveis para a posição do ícone são **left**, **right** e **none**. O próximo exemplo de código demonstra como configurar o botão do componente para ficar do lado _direito_.

```html
{/* in expansion-component.component.html */}
<igx-expansion-panel>
    <igx-expansion-panel-header [iconPosition]="'right'"></igx-expansion-panel-header>
    ...
</igx-expansion-panel>
```

<DocsAside type="info">
A propriedade <ApiLink type="ExpansionPanelHeader" member="iconPosition" label="iconPosition" /> funciona com `RTL` - por exemplo, um ícone definido para aparecer em **right** será exibido na parte mais à esquerda do cabeçalho quando o RTL estiver ativado.
</DocsAside>

O ícone padrão do estado de alternância do controle pode ser transformado em template.
Podemos fazer isso passando conteúdo em uma tag `igx-expansion-panel-icon`:

```html
{/* in expansion-component.component.html */}
<igx-expansion-panel>
    <igx-expansion-panel-header [iconPosition]="'right'">
        ...
        <igx-expansion-panel-icon>
            @if (panel.collapsed) {
                <span class="example-icon">Show More</span>
            } @else {
                <span class="example-icon">Show Less</span>
            }
        </igx-expansion-panel-icon>
    </igx-expansion-panel-header>   
    ...
</igx-expansion-panel>
```

Nosso Angular Expansion Panel agora vai renderizar "Mostrar mais" quando o painel estiver recolhido e "Mostrar menos" quando estiver totalmente expandido.

O controle `IgxExpansionPanel` permite adicionar todo tipo de conteúdo dentro do `igx-expansion-panel-body`. Ele pode renderizar [`IgxGrid`](/grid/grid)s, [`IgxCombo`](/inputs/combo/overview), gráficos e até outros expansion panels!

Para simplificar, vamos adicionar uma marcação básica ao corpo do nosso expansion panel.

```html
{/* in expansion-panel.component.html */}
...
<igx-expansion-panel-body>
    <div class="example-content">

        <img [src]="imgSource" alt="dog-image">
        The Golden Retriever is a medium-large gun dog that retrieves shot waterfowl, such as ducks and upland game birds, during hunting and shooting parties. The name "retriever" refers to the breed's ability to retrieve shot game undamaged due to their soft mouth. Golden retrievers have an instinctive love of water, and are easy to train to basic or advanced obedience standards.
        <a igxButton="outlined" target="_blank" [href]="readMore">Read more</a>
    
</div>
</igx-expansion-panel-body>
...
```

## Estilização

### Mapa de propriedades de tema do Expansion Panel

Alterar as propriedades `$header-background` e `$body-background` atualiza automaticamente as seguintes propriedades dependentes:

| Propriedade primária | Propriedade dependente | Descrição |
| --- | --- | --- |
| **$header-background** | $header-title-color | A cor do texto do título do cabeçalho do painel. |
|  | $header-icon-color | A cor do ícone do cabeçalho do painel. |
|  | $header-description-color | A cor do texto da descrição do cabeçalho do painel. |
|  | $header-focus-background | A cor de fundo com foco do cabeçalho do painel. |
|  | $disabled-text-color | A cor do texto desabilitado do painel. |
|  | $disabled-description-color | A cor do texto da descrição do cabeçalho desabilitado do painel. |
| **$body-background** | $body-color | A cor do texto do corpo do painel. |

### Paletas e cores

Primeiro, criamos uma paleta personalizada que poderá ser passada para o nosso componente depois:

```scss
// In real life, this should be in our main sass file so we can share the palette between all components. 
// In our case, it's in the component SCSS file "expansion-styling.component.scss".

@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';

// Add your brand colors.
$my-primary-color:#353a4b;
$my-secondary-color: #ffd351;
$my-surface-color: #efefef;

// Create custom palette.
$my-color-palette: palette(
  $primary: $my-primary-color,
  $secondary: $my-secondary-color,
  $surface: $my-surface-color
);
```

### Criando o tema do componente

Agora vamos criar o tema do nosso componente e passar a paleta `$my-color-palette` do trecho acima.

```scss
// In expansion-styling.component.scss
// Create expansion panel theme.
$custom-panel-theme: expansion-panel-theme(
  // Styling parameters.
  $header-background: color($my-color-palette, "primary", 700),
  $header-focus-background: color($my-color-palette, "primary", 700),
  $header-title-color: color($my-color-palette, "secondary"),
  $header-icon-color: color($my-color-palette, "secondary"),
  $body-background: color($my-color-palette, "primary", 700),
  $body-color: color($my-color-palette, "secondary", 100),
  $border-radius: .5
);
```

Se preferirmos, em vez de criar uma paleta, podemos atribuir as cores diretamente à função expansion-panel-theme como argumentos. Se `title-color`, `icon-color` ou outras propriedades de primeiro plano não forem informadas explicitamente, elas serão atribuídas automaticamente a preto ou branco, o que oferecer o melhor contraste com o fundo.

```scss
$custom-panel-theme: expansion-panel-theme(
  $header-background: #353a4b,
  $header-focus-background: #353a4b,
  $header-title-color: #ffd351,
  $header-icon-color: #ffd351,
  ...
);
```

<DocsAside type="info">
Para ver todos os parâmetros disponíveis para estilização por meio do mecanismo [`theming`](/themes/sass/component-themes), consulte <ApiLink kind="sass" module="themes" type="function-expansion-panel-theme" label="Documentação da API" code={true} />
</DocsAside>

### Aplicando o tema do componente

Agora, para aplicar o tema do componente, falta apenas incluir o mixin `tokens` e passar o mapa `$custom-panel-theme`.

```scss
// In expansion-styling.component.scss
:host {
  @include tokens($custom-panel-theme);
}
```

Para saber mais sobre como você pode usar o mecanismo de temas do Ignite UI [`click here`](/themes/sass/component-themes)

### Estilizando com Tailwind

Você pode estilizar o expansion panel usando nossas classes utilitárias personalizadas do Tailwind. Certifique-se de [configurar o Tailwind](/themes/tailwind) primeiro.

Junto com a importação do tailwind na sua folha de estilos global, você pode aplicar os utilitários de tema desejados da seguinte forma:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

O arquivo de utilitários inclui as variantes de tema `light` e `dark`.

- Use as classes `light-*` para o tema claro.
- Use as classes `dark-*` para o tema escuro.
- Acrescente o nome do componente depois do prefixo, por exemplo, `light-expansion-panel`, `dark-expansion-panel`.

Depois de aplicadas, essas classes habilitam cálculos dinâmicos de tema. A partir daí, você pode substituir as variáveis CSS geradas usando `arbitrary properties`. Depois dos dois-pontos, informe qualquer formato de cor CSS válido (HEX, variável CSS, RGB etc.).

Você pode encontrar a lista completa de propriedades em <ApiLink kind="sass" module="themes" type="function-expansion-panel-theme" label="expansion-panel-theme" />. A sintaxe é a seguinte:

```html
<igx-expansion-panel
  class="!light-expansion-panel
  ![--header-background:#4F6A5A]
  ![--body-background:#A3C7B2]"
>
  ...
</igx-expansion-panel>
```

<DocsAside type="info">
O ponto de exclamação (`!`) é obrigatório para garantir que a classe utilitária tenha precedência. O Tailwind aplica estilos em camadas e, sem marcar esses estilos como importantes, eles serão sobrescritos pelo tema padrão do componente.
</DocsAside>

## Animações do Angular Expansion Panel

### Usando uma animação específica

É possível usar outra animação além da padrão ao expandir e recolher o componente.
Considerando que o igxExpansionPanel já esteja importado em `app.module.ts`, como descrito anteriormente, você pode criar um objeto de configuração de animação personalizado e defini-lo para uso no Expansion Panel do Ignite UI for Angular. A abordagem exige o método [`useAnimation`](https://angular.io/api/animations/useAnimation) e as animações específicas que serão usadas; então, começamos importando-os e definindo as configurações de animação assim:

```typescript
// in expansion-panel.component.ts
import { useAnimation } from '@angular/animations';
import { IgxExpansionPanelComponent } from 'igniteui-angular/expansion-panel';
import { slideInLeft, slideOutRight } from 'igniteui-angular/animations';
// import { IgxExpansionPanelComponent, slideInLeft, slideOutRight } from '@infragistics/igniteui-angular'; for licensed package

@Component({...})
export class ExpansionPanelComponent {
    @ViewChild(IgxExpansionPanelComponent, {read: IgxExpansionPanelComponent})
    public panel: IgxExpansionPanelComponent;

    public animationSettingsCustom = {
        closeAnimation: useAnimation(slideOutRight, {
            params: {
                duration: '100ms',
                toPosition: 'translateX(25px)'
            }
        }),
        openAnimation: useAnimation(slideInLeft, {
            params: {
                duration: '500ms',
                fromPosition: 'translateX(-15px)',
                startOpacity: 0.1
            }
        })
    };

    public collapsed() {
        return this.panel && this.panel.collapsed;
    }
}
```

Como você pode ver, vamos usar as animações <ApiLink kind="sass" module="animations" type="mixin-slide-in-left" label="slideInLeft" code={true} /> e <ApiLink kind="sass" module="animations" type="mixin-slide-out-right" label="slideOutRight" code={true} /> do nosso <ApiLink kind="sass" module="animations" label="**conjunto integrado de animações**" /> para que o conteúdo do componente apareça de forma mais dramática pela esquerda e desapareça pela direita ao recolher o conteúdo. No processo, substituímos alguns dos parâmetros existentes pelos que queremos usar.

O exemplo mostra algumas informações do usuário, e o ponto principal aqui é passar as configurações de animação para o componente assim:
`[animationSettings] = "animationSettingsCustom"`

```html
{/* in expansion-panel.component.html */}
...
<igx-expansion-panel [animationSettings] = "animationSettingsCustom" class="my-expansion-panel">
    <igx-expansion-panel-header>
        <igx-expansion-panel-title class="sample-title">Angular</igx-expansion-panel-title>
    </igx-expansion-panel-header>
    <igx-expansion-panel-body>
        Angular (commonly referred to as "Angular 2+" or "Angular v2 and above") is a TypeScript-based open-source web application framework led by the Angular Team at Google and by a community of individuals and corporations.
    </igx-expansion-panel-body>
</igx-expansion-panel>
...
```
