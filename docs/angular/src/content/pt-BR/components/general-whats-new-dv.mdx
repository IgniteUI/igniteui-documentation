# Novidades no Ignite UI for Angular

Este tópico traz informações sobre as mudanças que quebram compatibilidade no Ignite UI for Angular, bem como sobre como atualizar código antigo para a API mais recente.

## Recursos de gráfico

Esta versão traz várias opções novas e aprimoradas de design visual e de configuração para todos os componentes de gráfico. por exemplo, Data Chart, Category Chart e Financial Chart.

### Padrões de gráfico redesenhados

- Nova paleta de cores para séries/marcadores em todos os gráficos

- As séries Bar/Column/Waterfall passaram a ter cantos quadrados, em vez de cantos arredondados
- As cores da série Scatter High Density para as propriedades de calor mínimo/máximo foram alteradas
- As cores das séries Financial/Waterfall para o preenchimento negativo de seus elementos visuais foram alteradas
- A espessura do marcador passou de 1px para 2px
- O preenchimento do marcador passou a corresponder ao contorno do marcador nas séries PointSeries, BubbleSeries, ScatterSeries e PolarScatterSeries
  - Observação: você pode definir a propriedade `MarkerFillMode` como Normal para desfazer esta mudança
- Rotulagem compactada para o TimeXAxis e o OrdinalTimeXAxis
- Novas propriedades de marcador:
  - `MarkerFillMode` - pode ser definida como 'MatchMarkerOutline', para que o marcador dependa do contorno
  - `MarkerFillOpacity` - pode ser definida com um valor de 0 a 1
  - `MarkerOutlineMode` - pode ser definida como 'MatchMarkerBrush', para que o contorno do marcador dependa da cor do pincel de preenchimento
- Nova propriedade de série `OutlineMode`:
  - Pode ser definida para alternar a visibilidade do contorno da série. Observação: para o Data Chart, a propriedade fica na série
- Novas propriedades de margem da área de plotagem:
  - `PlotAreaMarginLeft`
  - `PlotAreaMarginTop`
  - `PlotAreaMarginRight`
  - `PlotAreaMarginBottom`
  - `ComputedPlotAreaMarginMode`
  - As propriedades de margem da área de plotagem definem a área de extravasamento introduzida na janela de visualização quando o gráfico está no nível de zoom padrão. Um uso comum é criar espaço entre os eixos e o primeiro/último ponto de dados. Observação: a `ComputedPlotAreaMarginMode`, listada abaixo, define automaticamente a margem quando os marcadores estão habilitados. As outras foram projetadas para especificar um `Double` que representa a espessura, onde PlotAreaMarginLeft etc. ajusta o espaço para os quatro lados do gráfico.
- Novas propriedades de destaque
  - `HighlightingMode` - define se as séries com e sem foco do mouse devem ser esmaecidas ou clareadas
  - `HighlightingBehavior` - define se a série é destacada de acordo com a posição do mouse, por exemplo, diretamente sobre ou no item mais próximo
  - Observação: nas versões anteriores, o destaque se limitava ao esmaecimento ao passar o mouse.
- Destaque adicionado para as seguintes séries:
  - Stacked
  - Scatter
  - Polar
  - Radial
  - Shape
- Camadas de anotação adicionadas às seguintes séries:
  - Stacked
  - Scatter
  - Polar
  - Radial
  - Shape
- Adicionado suporte para substituir a fonte de dados de fragmentos de pilha individuais dentro de uma série empilhada
- Adicionados eventos de estilo personalizado às séries Stacked, Scatter, Range, Polar, Radial e Shape
- Adicionado suporte para sincronizar automaticamente o zoom vertical com o conteúdo da série
- Adicionado suporte para expandir automaticamente as margens horizontais do gráfico com base nos rótulos iniciais exibidos

### Recursos da legenda do gráfico

- Adicionada orientação horizontal para o ItemLegend
  - Os seguintes tipos de gráfico podem usar o ItemLegend na orientação horizontal:
    - Bubble
    - Donut
    - Pie
- `LegendHighlightingMode` - habilita o destaque da série ao passar o mouse sobre os itens da legenda

### Recursos do Geographic Map (CTP)

- Adicionado suporte para exibição em loop do mapa (rolagem horizontal infinita)  
- Adicionado suporte para deslocar a exibição de algumas séries de mapa ao dar a volta na origem das coordenadas  
- Adicionado suporte para destacar a série shape
- Adicionado suporte para algumas camadas de anotação na série shape
