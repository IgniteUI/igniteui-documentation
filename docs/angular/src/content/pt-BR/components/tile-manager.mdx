# Visão geral do Angular Tile Manager

O componente Tile Manager permite exibir conteúdo em blocos individuais. Ele permite que os usuários interajam com esses blocos, reorganizando-os e redimensionando-os, dando-lhes liberdade para personalizar o layout e a aparência do conteúdo de acordo com as suas preferências. Essa flexibilidade melhora a experiência do usuário, ao permitir uma forma mais personalizada e eficiente de visualizar e gerenciar o conteúdo.

## Primeiros passos com o Ignite UI for Angular Tile Manager

O Ignite UI Tile Manager é um [web component](https://developer.mozilla.org/en-US/docs/Web/Web_Components) padrão e, como tal, pode ser usado em uma aplicação Angular.

Para começar a usá-lo, primeiro você precisa instalar o pacote Ignite UI for Web Components, executando o seguinte comando:

```cmd
npm install igniteui-webcomponents --save
```

Em seguida, você deve chamar a função `defineCustomElements()` com o argumento `IgcTileManagerComponent` no seu arquivo `main.ts` ou no arquivo `.ts` do componente que usa `IgcTileManager`.

```ts
import { defineComponents, IgcTileManagerComponent } from 'igniteui-webcomponents';

defineComponents(IgcTileManagerComponent);
```

Você também precisa incluir o esquema `CUSTOM_ELEMENTS_SCHEMA` na configuração do seu componente

```typescript
import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';

@Component({
    schemas: [CUSTOM_ELEMENTS_SCHEMA]
})
export class AppComponent {
```

Agora você pode começar com uma configuração básica do Angular Tile Manager.

## Uso

O Tile Manager oferece um comportamento base de layout de blocos, gerenciando a posição dos blocos nos estados maximizado ou normal. Os blocos podem ser dimensionados independentemente uns dos outros e usados para formar layouts complexos. Os usuários finais podem reordenar os blocos arrastando e soltando-os, o que proporciona uma experiência flexível e intuitiva.

O Tile Manager oferece dois componentes que podemos usar:

- `IgcTileComponent` - Este componente representa um bloco individual exibido dentro do Tile Manager.
- `IgcTileManagerComponent` - Este é o componente principal, que contém todos os componentes de bloco e serve como contêiner de todo o layout de blocos.

```html
<igc-tile-manager>
  <igc-tile>
    <p>Tile 1</p>
  </igc-tile>
  <igc-tile>
    <p>Tile 2</p>
  </igc-tile>
  <igc-tile>
    <p>Tile 3</p>
  </igc-tile>
</igc-tile-manager>
```
