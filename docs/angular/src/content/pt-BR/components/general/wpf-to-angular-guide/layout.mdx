# Layout de página

No WPF, para organizar os elementos da aplicação, você precisa colocá-los dentro de um [`Panel`](https://docs.microsoft.com/en-us/dotnet/api/system.windows.controls.panel?view=netframework-4.8). O painel é um elemento contêiner que controla a disposição dos seus elementos filhos. No Angular, para personalizar o layout da página e os seus elementos filhos, você usa CSS. Vamos ver alguns dos painéis mais populares do WPF e como podemos obter um layout semelhante com CSS.

## StackPanel

O [`StackPanel`](https://docs.microsoft.com/en-us/dotnet/api/system.windows.controls.stackpanel?view=netframework-4.8) organiza os seus elementos filhos em uma única linha, que pode ser orientada na horizontal ou na vertical. Vamos adicionar vários botões em um StackPanel e ver como eles ficam no WPF:

```xml
<StackPanel>
    <Button>1</Button>
    <Button>2</Button>
    <Button>3</Button>
    <Button>4</Button>
    <Button>5</Button>
</StackPanel>
```

<Image src={wpfStackpanel} alt="StackPanel do WPF" class="responsive-img" />

Se quisermos obter um layout semelhante no Angular, podemos usar o layout CSS Flexbox. O Flexible Box Layout Module é um mecanismo poderoso que permite projetar uma estrutura de layout flexível e responsiva. Para usar o layout Flexbox, precisamos definir um contêiner que tenha a propriedade [`display`](https://www.w3schools.com/cssref/pr_class_display.asp) definida como `flex`. Além disso, para empilhar os itens na vertical, precisamos definir a propriedade [`flex-direction`](https://www.w3schools.com/cssref/css3_pr_flex-direction.asp) como `column`.

```html
<div class="flex-container">

    <button>1</button>
    <button>2</button>
    <button>3</button>
    <button>4</button>
    <button>5</button>
</div>
```

```css
.flex-container {
    display: flex;
    flex-flow: column;
}
```

Aqui está o resultado final no navegador:

<Image src={angularStackpanel} alt="StackPanel do Angular" class="responsive-img" />

O valor padrão da propriedade [`flex-direction`](https://www.w3schools.com/cssref/css3_pr_flex-direction.asp) é `row`, que equivale a um StackPanel com orientação Horizontal no WPF. O flexbox também oferece suporte às direções `row-reverse` e `column-reverse`, que empilham os itens da direita para a esquerda e de baixo para cima, respectivamente.

## WrapPanel

O [`WrapPanel`](https://docs.microsoft.com/en-us/dotnet/api/system.windows.controls.wrappanel?view=netframework-4.8) posiciona os elementos filhos em sequência da esquerda para a direita, quebrando o conteúdo para a próxima linha na borda da caixa que o contém. A ordenação seguinte acontece sequencialmente de cima para baixo ou da direita para a esquerda, dependendo do valor da propriedade Orientation. Vamos adicionar vários botões em um WrapPanel e ver como eles ficam no WPF:

```xml
<WrapPanel>
    <WrapPanel.Resources>
        <Style TargetType="Button">
            <Setter Property="Width" Value="150"></Setter>
        </Style>
    </WrapPanel.Resources>
    <Button>1</Button>
    <Button>2</Button>
    <Button>3</Button>
    <Button>4</Button>
    <Button>5</Button>
</WrapPanel>
```

<Image src={wpfWrappanel} alt="WrapPanel do WPF" class="responsive-img" />

Para obter um resultado semelhante no Angular, vamos usar o layout Flexbox novamente. Assim como no caso do StackPanel, precisamos definir a propriedade [`display`](https://www.w3schools.com/cssref/pr_class_display.asp) como `flex`, mas também precisamos definir a propriedade [`flex-wrap`](https://www.w3schools.com/cssref/css3_pr_flex-wrap.asp) como `wrap`.

```html
<div class="flex-container">

    <button>1</button>
    <button>2</button>
    <button>3</button>
    <button>4</button>
    <button>5</button>
</div>
```

```css
.flex-container {
    display: flex;
    flex-wrap: wrap;
}

button {
    width: 150px;
}
```

Aqui está o resultado final no navegador:

<Image src={angularWrappanel} alt="WrapPanel do Angular" class="responsive-img" />

Se você quiser obter um resultado semelhante a um WrapPanel com Orientation="Vertical", precisa definir a propriedade [`flex-direction`](https://www.w3schools.com/cssref/css3_pr_flex-direction.asp) como `column`. A propriedade [`flex-flow`](https://www.w3schools.com/cssref/css3_pr_flex-flow.asp) é uma propriedade abreviada para definir as propriedades `flex-direction` e `flex-wrap` ao mesmo tempo.

```css
.flex-container {
    display: flex;
    flex-flow: row wrap;
}
```

O flexbox oferece mais algumas propriedades de CSS para alinhar os itens. Você pode saber mais sobre elas neste [tutorial](https://www.w3schools.com/css/css3_flexbox.asp).

## Grid

O [`Grid`](https://docs.microsoft.com/en-us/dotnet/api/system.windows.controls.grid?view=netframework-4.8) define uma área de grade flexível composta por colunas e linhas. Vamos adicionar vários botões em um Grid e ver como eles ficam no WPF:

```xml
<Grid>
    <Grid.ColumnDefinitions>
        <ColumnDefinition />
        <ColumnDefinition />
        <ColumnDefinition />
    </Grid.ColumnDefinitions>
    <Grid.RowDefinitions>
        <RowDefinition Height="50" />
        <RowDefinition Height="50" />
        <RowDefinition Height="50" />
        <RowDefinition Height="50" />
    </Grid.RowDefinitions>
    <Button Grid.RowSpan="2" Grid.ColumnSpan="2">1</Button>
    <Button Grid.Column="2">2</Button>
    <Button Grid.Row="1" Grid.Column="2">3</Button>
    <Button Grid.Row="2">4</Button>
    <Button Grid.Row="2" Grid.Column="1">5</Button>
    <Button Grid.Row="2" Grid.Column="2">6</Button>
    <Button Grid.Row="3" Grid.ColumnSpan="3">7</Button>
</Grid>
```

<Image src={wpfGrid} alt="Grid do WPF" class="responsive-img" />

No Angular, podemos usar o módulo CSS Grid Layout, que oferece um sistema de layout baseado em grade, com linhas e colunas. Para usar o layout Grid, precisamos definir um contêiner que tenha a propriedade [`display`](https://www.w3schools.com/cssref/pr_class_display.asp) definida como `grid` ou `inline-grid`.

```html
<div class="grid-container">

    <button class="button1">1</button>
    <button>2</button>
    <button>3</button>
    <button>4</button>
    <button>5</button>
    <button>6</button>
    <button class="button7">7</button>
</div>
```

```css
.grid-container {
    display: grid;
}
```

<DocsAside type="info">
O CSS Grid Layout [não é compatível](https://caniuse.com/#feat=css-grid) com navegadores mais antigos, como o Internet Explorer 11.
</DocsAside>

Agora vamos definir as colunas da grade usando a propriedade [`grid-template-columns`](https://www.w3schools.com/cssref/pr_grid-template-columns.asp).

```css
.grid-container {
    display: grid;
    grid-template-columns: auto auto auto;
}
```

Definimos três colunas com largura `auto`, o que significa que elas terão a mesma largura. Se você quiser distribuir o espaço disponível de forma proporcional, semelhante ao dimensionamento por estrela do WPF, pode usar a unidade de dimensionamento flexível `fr` do CSS. O trecho de código a seguir define duas colunas: a primeira recebe uma vez o espaço disponível, enquanto a segunda recebe duas vezes o espaço disponível:

```css
.grid-container {
    display: grid;
    grid-template-columns: 1fr 2fr;
}
```

Agora vamos adicionar as linhas com altura de 50px cada, usando a propriedade [`grid-template-rows`](https://www.w3schools.com/cssref/pr_grid-template-columns.asp).

```css
.grid-container {
    display: grid;
    grid-template-columns: auto auto auto;
    grid-template-rows: 50px 50px 50px 50px;
}
```

Se abrirmos a aplicação agora, ela fica assim:

<Image src={angularGrid} alt="Grid do Angular" class="responsive-img" />

Você pode ver uma diferença importante entre as grades do WPF e do CSS. No WPF, o valor padrão de Grid.Row e Grid.Column é 0, enquanto o layout de grade do CSS atribui automaticamente a próxima linha e coluna disponíveis aos seus filhos.

Agora vamos aplicar os spans de coluna e de linha ao primeiro e ao sétimo botões. Para isso, usaremos as propriedades [`grid-row`](https://www.w3schools.com/cssref/pr_grid-row.asp) e [`grid-column`](https://www.w3schools.com/cssref/pr_grid-column.asp).

```css
.button1 {
    grid-column: 1 / 3;
    grid-row: 1 / 3;
}

.button7 {
    grid-column: 1 / span 3;
}
```

Primeiro especificamos a linha/coluna inicial; depois do símbolo `/`, podemos especificar a linha/coluna final ou quantas linhas/colunas o item deve ocupar. Diferentemente do WPF, a numeração de colunas da grade do CSS não é baseada em zero, e a primeira linha/coluna é 1.

Aqui estão o CSS completo e o resultado final no navegador:

```css
.grid-container {
    display: grid;
    grid-template-columns: auto auto auto;
    grid-template-rows: 50px 50px 50px 50px;
}

.button1 {
    grid-column: 1 / 3;
    grid-row: 1 / 3;
}

.button7 {
    grid-column: 1 / span 3;
}
```

<Image src={angularGridSpan} alt="Grid com span do Angular" class="responsive-img" />

As propriedades `grid-row` e `grid-column` são propriedades abreviadas para as propriedades [`grid-row-start`](https://www.w3schools.com/cssref/pr_grid-row-start.asp), [`grid-row-end`](https://www.w3schools.com/cssref/pr_grid-row-end.asp), [`grid-column-start`](https://www.w3schools.com/cssref/pr_grid-column-start.asp) e [`grid-column-end`](https://www.w3schools.com/cssref/pr_grid-column-end.asp). Você pode saber mais sobre as propriedades do contêiner e dos itens do CSS Grid nos tutoriais da seção **Recursos adicionais**.
