# Migrando do desktop para a web: um tutorial de WPF para Angular

O tutorial de WPF para Angular é o primeiro passo que você deve dar para fazer uma transição tranquila de um framework `desktop` para um framework `web`. O tutorial é voltado a desenvolvedores de WPF que dão os primeiros passos no desenvolvimento web e examina algumas diferenças e semelhanças entre os dois frameworks - estrutura de aplicações, vinculação de dados, eventos, componentes etc.

    <Image src={wpfToAngularGuide} alt="Guia de WPF para Angular" class="responsive-img" style="vertical-align: middle;" />
</p>

O guia está dividido nos tópicos a seguir e inclui tutoriais em vídeo:

## [Crie a sua primeira aplicação Angular](/general/wpf-to-angular-guide/create-first-angular-app)

Antes de começar o seu caminho de aprendizado do Angular, você precisará instalar os pré-requisitos para o desenvolvimento moderno de aplicações web com Angular. Esta seção aborda o uso do gerenciador de pacotes do Node.js, a instalação da IDE Visual Studio Code e alguns conceitos básicos necessários para o desenvolvimento web moderno. Confira o [tutorial em vídeo](https://youtu.be/dhjrAPPad54) deste tópico.

## [Crie a sua UI com componentes Angular](/general/wpf-to-angular-guide/create-ui-with-components)

Criar uma UI no Angular é muito semelhante a como a criaríamos no WPF. Normalmente usamos controles de usuário, representados pela classe UserControl. Um UserControl agrupa marcação e código em um contêiner reutilizável, permitindo que a mesma interface e funcionalidade sejam usadas em vários lugares diferentes. Entender os componentes do Angular é fundamental para o restante desta série - então vamos começar entendendo como os componentes do WPF se traduzem para componentes do Angular. Confira o [tutorial em vídeo](https://youtu.be/z1SZUezpRXY) deste tópico.

## [Vinculação de dados unidirecional no Angular](/general/wpf-to-angular-guide/one-way-binding)

Um dos recursos mais poderosos e amplamente usados no WPF é a vinculação de dados. Ela facilita muito a vida dos desenvolvedores, sincronizando a lógica de negócio com a visualização e vice-versa, sem precisar escrever uma única linha de código extra. Sem esse poder, o WPF seria apenas um Windows Forms com aparência melhor. Felizmente, o Angular oferece suporte à vinculação de dados! Existem dois tipos de vinculação de dados: unidirecional e bidirecional. Esta seção mostra como realizar a vinculação de dados unidirecional e como ela se compara ao WPF. Confira o [tutorial em vídeo](https://youtu.be/fP7iVhFNTOk) deste tópico.

## [Eventos do Angular](/general/wpf-to-angular-guide/angular-events)

Vincular eventos de entrada do usuário é fundamental em toda aplicação. É difícil imaginar uma nova aplicação que não responda de alguma forma às interações do usuário. A forma mais comum de fazer isso é com algum tipo de sistema de eventos. O WPF oferece eventos roteados, eventos CLR e comandos. Já no Angular, existem os eventos do DOM. Esta seção mostra como funcionam os eventos do DOM e como tratar as entradas do usuário. Confira o [tutorial em vídeo](https://youtu.be/V1Futz4W400) deste tópico.

## [Vinculação bidirecional de dados no Angular](/general/wpf-to-angular-guide/two-way-binding)

No Angular, a vinculação unidirecional atualiza a visualização com os dados vindos da classe do componente. Assim como no WPF, podemos fazer a operação inversa - atualizar a classe do componente a partir da visualização. Nesse caso, precisamos usar uma vinculação bidirecional. Esta seção compara a vinculação bidirecional no WPF e mostra como é fácil começar. Confira o [tutorial em vídeo](https://youtu.be/MrjTTDEj7cA) deste tópico.

## [Transformando dados com pipes do Angular](/general/wpf-to-angular-guide/angular-pipes)

No WPF, usamos um IValueConverter para transformar dados; em uma aplicação Angular, usamos Pipes do Angular. O pipe é muito semelhante ao converter do WPF. Ele recebe dados como entrada e depois os transforma em uma saída desejada para exibição. Esta seção mostra alguns dos Pipes do Angular predefinidos e como usá-los em uma aplicação. Confira o [tutorial em vídeo](https://youtu.be/Gmz5kio50FE) deste tópico.

## [Diretivas estruturais no Angular](/general/wpf-to-angular-guide/structural-directives)

Como desenvolvedores de WPF, sempre que queremos adicionar ou remover um elemento da árvore visual, precisamos entrar no code-behind e escrever C#, ou podemos usar uma combinação de vinculação e um converter de visibilidade, que, novamente, exige lógica personalizada e recursos estáticos. É assim que sempre fizemos no WPF, mas o Angular torna tudo muito mais fácil. Esta seção demonstra como as diretivas estruturais permitem manipular elementos em uma aplicação Angular. Confira o [tutorial em vídeo](https://youtu.be/vQe7R78Od8k) deste tópico.

## [Elementos de layout](/general/wpf-to-angular-guide/layout)

No WPF, para organizar os elementos da aplicação, você precisa colocá-los dentro de um Panel. No Angular, usamos CSS. Este tópico trata do layout e de como usar recursos de CSS como Flexbox e CSS Grid.
