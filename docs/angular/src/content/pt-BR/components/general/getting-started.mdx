# Comece a usar o Ignite UI for Angular

[`Ignite UI for Angular`](https://github.com/IgniteUI/igniteui-angular) é uma biblioteca com mais de 100 componentes de UI corporativos - incluindo data grids, gráficos, editores, controles de navegação e contêineres de layout - distribuída como o pacote npm `igniteui-angular` pela Infragistics. Este guia percorre três caminhos de instalação (Ignite UI CLI, Angular Schematics e Angular CLI com `ng add`) e termina com um `IgxGridComponent` funcional renderizado a partir de dados locais.

O Ignite UI for Angular é voltado ao Angular 17 e versões posteriores, com componentes standalone como modelo padrão de bootstrap. Ele não oferece suporte nativo a Vue, React ou Web Components - para esses frameworks, veja [Ignite UI for React](https://www.infragistics.com/products/ignite-ui-react), [Ignite UI for Web Components](https://www.infragistics.com/products/ignite-ui-web-components) e [Ignite UI for Blazor](https://www.infragistics.com/products/ignite-ui-blazor).

O Ignite UI for Angular é oferecido em um modelo de licença dupla: alguns componentes são de código aberto sob a licença MIT, e outros exigem uma licença comercial. Para detalhes, veja [Licenciamento do Ignite UI](./ignite-ui-licensing.mdx) e [Código aberto vs Premium](./open-source-vs-premium.mdx).

## Pré-requisitos

- Node.js 20 LTS ou posterior (Node.js 22 LTS recomendado)
- npm 10+ (incluído com o Node.js 20), yarn ou pnpm
- Angular CLI 17+ para o caminho de instalação `ng add`
- Visual Studio Code ou qualquer editor com suporte à linguagem TypeScript

## Instalar o Ignite UI for Angular

O Ignite UI for Angular oferece três caminhos de instalação. Use o Ignite UI CLI ou o Angular Schematics ao começar um novo projeto do zero. Use `ng add` ao adicionar o Ignite UI for Angular a um workspace Angular existente.

### Instalar com o Ignite UI CLI

O Ignite UI CLI é uma ferramenta de linha de comando independente que faz o scaffolding de um projeto Angular totalmente configurado com o Ignite UI for Angular, em um único comando. Instale-a globalmente:

```cmd
npm install -g igniteui-cli
```

Ative o assistente guiado de projeto:

```cmd
ig
```

Ou crie um projeto de forma não interativa:

```cmd
ig new <project-name> --framework=angular --type=igx-ts --template=side-nav
```

<DocsAside type="info">
A partir do Ignite UI CLI v13.1.0, o tipo de projeto `igx-ts` gera um projeto que usa componentes standalone por padrão. Para usar a inicialização baseada em NgModule, defina `--type=igx-ts-legacy`.
</DocsAside>

<DocsAside type="info">
Em algum momento do processo, você pode ser solicitado a [fazer login no registro npm da Infragistics](./ignite-ui-licensing.mdx#como-configurar-o-seu-ambiente-para-usar-o-feed-npm-privado-guia-passo-a-passo), se ainda não estiver configurado. Isso se aplica ao usar componentes sob uma [licença comercial](./open-source-vs-premium.mdx#tabela-de-comparação-de-todos-os-componentes).
</DocsAside>

Para um passo a passo completo de todas as opções do CLI e dos templates de projeto, consulte [Primeiros passos com o Ignite UI CLI](./cli/getting-started-with-cli.mdx) e [Angular Schematics e Ignite UI CLI](./cli-overview.mdx).

### Instalar com Angular Schematics

A coleção Ignite UI for Angular Schematics se integra ao fluxo de trabalho do Angular CLI e oferece a mesma experiência guiada do CLI independente, sem exigir uma ferramenta global separada:

```cmd
npm i -g @igniteui/angular-schematics
```

Ative o assistente guiado:

```cmd
ng new --collection="@igniteui/angular-schematics"
```

Para um passo a passo, veja [Guia passo a passo usando o Ignite UI for Angular Schematics](./cli/step-by-step-guide-using-angular-schematics.mdx).

### Instalar com o Angular CLI (`ng add`)

Se você já tem um projeto Angular ou prefere trabalhar inteiramente no Angular CLI, use `ng add` para instalar e configurar o Ignite UI for Angular. Crie primeiro um novo aplicativo Angular, se necessário:

```cmd
ng new <project-name> --style=scss
```

Recomenda-se SCSS, porque a [Ignite UI for Angular Theming Library](../themes/sass/index.mdx) é construída sobre ele e o `ng add` configura o tema padrão automaticamente. Em seguida, adicione o Ignite UI for Angular:

```cmd
ng add igniteui-angular
```

<DocsAside type="info">
`ng add` instala a versão de avaliação de `igniteui-angular`. Se o seu projeto foi criado com o Ignite UI CLI, pule esta etapa - o CLI já cuida da configuração dos pacotes. Para migrar depois para o pacote licenciado, veja [Atualizar de avaliação para licenciado](#atualizar-de-avaliação-para-licenciado) abaixo.
</DocsAside>

#### Pacotes adicionais

Alguns componentes do Ignite UI for Angular são distribuídos como pacotes npm separados e são adicionados de forma independente:

**[Grid Lite](../grid-lite/overview.mdx) - código aberto (MIT)**

Uma grade leve para projetos que precisam de exibição básica de dados, sem o conjunto completo de recursos comerciais. Sua API é compatível com `IgxGrid`, então a atualização posterior exige alterações mínimas.

```cmd
ng add igniteui-grid-lite
```

**[Dock Manager](../dock-manager.mdx) - premium**

Um componente de layout baseado em painéis, em que os usuários finais podem fixar, redimensionar, mover e ocultar painéis em tempo de execução.

```cmd
ng add igniteui-dockmanager
```

## Adicionar componentes com o CLI ou o Schematics

Depois da configuração inicial do projeto, adicione visualizações de componentes do Ignite UI for Angular usando o schematic `component` ou o comando `add`:

```cmd
ng g @igniteui/angular-schematics:component
```

```cmd
ig add
```

<DocsAside type="info">
O comando `ig add` está disponível em projetos criados com o Ignite UI CLI ou em projetos Angular CLI em que o Ignite UI for Angular foi adicionado com `ng add igniteui-angular`.
</DocsAside>

## Adicionar componentes manualmente (standalone)

A partir do Angular 19, os componentes standalone são o modelo de bootstrap padrão. O exemplo a seguir adiciona um `IgxGridComponent` a uma aplicação Angular standalone, sem usar Schematics ou o CLI.

Alguns componentes usam animações, que exigem um provider na chamada `bootstrapApplication`. Configure isso em `app.config.ts`:

```typescript
// app/app.config.ts
import { ApplicationConfig, importProvidersFrom } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { provideAnimations } from '@angular/platform-browser/animations';
import { Provider } from '@angular/core';

const providers: Provider[] = [
  importProvidersFrom(BrowserModule),
  provideAnimations()
];

export const appConfig: ApplicationConfig = { providers };
```

### Importe e use a Grid

Importe `IgxGridComponent` e `IgxColumnComponent` diretamente no seu componente standalone. Como este é um componente standalone, adicione ambos ao array `imports`, e não a um `NgModule`:

```typescript
// app.component.ts
import { Component } from '@angular/core';
import { IgxGridComponent, IgxColumnComponent } from 'igniteui-angular';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styleUrls: ['./app.component.css'],
  imports: [IgxGridComponent, IgxColumnComponent]
})
export class AppComponent {
  localData = [
    { Name: 'John', Age: 29 },
    { Name: 'Alice', Age: 27 },
    { Name: 'Jessica', Age: 31 },
  ];
}
```

Adicione a grade ao template do componente, vinculando `[data]` ao array local e definindo as colunas explicitamente:

```html
<!-- app.component.html -->
<igx-grid [data]="localData" width="600px" height="400px" [allowFiltering]="true">
  <igx-column field="Name" dataType="string"></igx-column>
  <igx-column field="Age" dataType="number"></igx-column>
</igx-grid>
```

Isso renderiza uma Grid do Ignite UI for Angular com a filtragem por coluna habilitada, exibindo três linhas de dados locais.

### Execute a aplicação

Execute a aplicação usando o comando da sua configuração:

```cmd
ig start
```

Ou, para projetos criados com o Angular CLI:

```cmd
ng serve
```

## Atualizar de avaliação para licenciado

Para trocar o pacote de avaliação `igniteui-angular` pela versão licenciada, execute o schematic de atualização na raiz do projeto:

```bash
ng g @igniteui/angular-schematics:upgrade-packages
```

Ou, usando o Ignite UI CLI:

```bash
ig upgrade-packages
```

O schematic atualiza as dependências de pacotes e substitui as referências no código-fonte. Você será solicitado a [fazer login no registro npm privado da Infragistics](./ignite-ui-licensing.mdx#como-configurar-o-seu-ambiente-para-usar-o-feed-npm-privado-guia-passo-a-passo), se ainda não estiver configurado.

## Desenvolvimento assistido por IA

O Ignite UI for Angular inclui duas ferramentas para o desenvolvimento assistido por IA.

**Agent Skills** são arquivos de conhecimento estruturados que ensinam assistentes de programação com IA - GitHub Copilot, Cursor, Windsurf, Claude, JetBrains AI - a trabalhar corretamente com os componentes, as APIs e os padrões de tema do Ignite UI. Os skills abrangem grades de dados, operações de grade, gráficos e tema. Veja [Skills do Ignite UI for Angular](../ai/skills.mdx).

**O servidor Ignite UI MCP** é um servidor integrado ao Ignite UI CLI, que conecta assistentes de IA à documentação ao vivo dos componentes do Ignite UI e às referências de API, diretamente no seu editor. Diferentemente dos skills estáticos, o servidor MCP responde a consultas sobre as APIs atuais, busca guias de configuração sob demanda e oferece suporte à geração precisa de código para os componentes do Ignite UI. Inicie-o com `ig mcp` depois de instalar o CLI. Para a configuração do cliente e as ferramentas disponíveis, veja [Visão geral do Ignite UI CLI MCP](../ai/cli-mcp.mdx).
