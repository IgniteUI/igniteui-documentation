# Templates de componentes

Os templates de componentes são estruturas de componentes Angular pré-configuradas, que o Ignite UI CLI (`ig add`) e o Ignite UI Angular Schematics (`ng g @igniteui/angular-schematics:c`) geram em um projeto Angular existente. Cada template produz um componente Angular funcional, com as importações corretas, as declarações de módulo e um conjunto de dados de exemplo - pronto para executar sem configuração adicional. Há templates disponíveis para grades, gráficos, medidores, mapas, componentes de layout, menus, notificações, controles de entrada de dados, interações, controles de agendamento e cenários de aplicação completos.

Esses templates geram componentes apenas em um workspace Angular existente. Eles não criam um novo projeto Angular - para isso, use `ig new` ou `ng new`. Os templates são específicos do Ignite UI for Angular; padrões equivalentes para React, Web Components e Blazor são abordados na documentação de cada framework. O código gerado serve como ponto de partida funcional e pode diferir das demonstrações ao vivo vinculadas nesta página, que refletem as amostras completas da documentação.
