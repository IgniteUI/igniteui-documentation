# Guia passo a passo usando o Ignite UI CLI

O modo passo a passo do Ignite UI CLI é um assistente interativo que guia você pela criação do projeto, pela seleção do template, pelo tema e pela adição de visualizações de componentes para projetos Angular baseados no [Ignite UI CLI](./getting-started-with-cli.mdx). Ele cobre as mesmas operações dos comandos não interativos `ig new` e `ig add`, mas faz perguntas em cada etapa, em vez de exigir todos os argumentos de antemão.

O modo passo a passo não oferece suporte a uso em scripts ou não interativo - para isso, use os comandos diretos `ig new` e `ig add` com argumentos explícitos. O assistente depende de `Inquirer.js`; veja [terminais compatíveis](https://github.com/SBoudrias/Inquirer.js#support-os-terminals) para a compatibilidade.

Para ativar o assistente, execute:

```bash
ig
```

ou:

```bash
ig new
```

## Criar novo projeto

Primeiro, você será solicitado a informar um nome para a sua aplicação:

<Image src={igStepByStepNewProjectName} alt="Prompt do passo a passo: nome do novo projeto" class="responsive-img" />

Depois de selecionar `Angular` como framework, você será solicitado a escolher o tipo do projeto a ser gerado:

<Image src={igStepByStepProjectTypeCli} alt="Passo a passo: seleção do tipo de projeto" class="responsive-img" />

Em seguida, você será guiado a escolher um dos templates de projeto disponíveis. Três templates base estão disponíveis: **Empty Project**, **Side Navigation** e **Side Navigation Mini**. Navegue pelas opções disponíveis usando as teclas de seta e pressione ENTER para confirmar a seleção:

<Image src={igStepByStepNewProjectTemplate} alt="Passo a passo: seleção do template de novo projeto" class="responsive-img" />

Se você selecionar **Side Navigation** ou **Side Navigation Mini**, o assistente apresentará uma etapa adicional perguntando se deve adicionar um [módulo de autenticação](./auth-template.mdx) ao projeto. Responder sim gera a variante de autenticação correspondente (`side-nav-auth` ou `side-nav-mini-auth`). Se você selecionar **Empty Project**, o prompt de autenticação é ignorado.

<Image src={igStepByStepNewProjectQuestion} alt="Passo a passo: prompt de pergunta sobre autenticação" class="responsive-img" />

A próxima etapa é escolher um tema para a sua aplicação. Ao selecionar a opção padrão, é incluído um arquivo CSS pré-compilado (`igniteui-angular.css`) com o tema padrão do Ignite UI for Angular no `angular.json` do seu projeto. A opção personalizada gera uma paleta de cores e uma configuração de tema usando a [API de temas](../../themes/sass/index.mdx) em `app/styles.scss`.

<Image src={igStepByStepNewProjectTheme} alt="Passo a passo: seleção do tema do novo projeto" class="responsive-img" />

Depois de concluir as etapas acima, a estrutura da aplicação é gerada. Em seguida, o assistente pede para você [configurar os assistentes de programação com IA](#configure-os-assistentes-de-ia). Quando a configuração de IA estiver concluída, um repositório Git é inicializado, o projeto é registrado e você é perguntado se deseja concluir o processo ou adicionar uma nova visualização à sua aplicação:

<Image src={igStepByStepNewProjectAction} alt="Passo a passo: prompt de ação do novo projeto" class="responsive-img" />

## Adicionar visualização

O Ignite UI CLI oferece suporte a vários templates de componentes e templates de cenário que podem ser adicionados a um projeto. Este modo pode ser ativado tanto como continuação da criação do projeto quanto dentro de um projeto existente, usando o comando abaixo.

```bash
ig add
```

Você verá uma [lista dos templates disponíveis](./component-templates.mdx#templates-de-componentes), agrupados por categoria.

<Image src={igStepByStepTemplateGroup} alt="Passo a passo: seleção do grupo de templates" class="responsive-img" />

Use as teclas de seta para navegar pelas opções e ENTER para selecionar. Para alguns templates, como `Custom Grid`, você verá uma lista de recursos opcionais que podem ser alternados com a tecla SPACE:

<Image src={igStepByStepComponentFeatures} alt="Passo a passo: alternância de recursos opcionais do componente" class="responsive-img" />

Se você optar por adicionar um cenário à sua aplicação, também receberá uma lista dos [templates de cenário](./component-templates.mdx#templates-de-cenário) disponíveis:

<Image src={igStepByStepScenarioTemplates} alt="Passo a passo: seleção de template de cenário" class="responsive-img" />

Depois de adicionar um template, você será perguntado se deseja adicionar mais visualizações ou concluir o processo. Ao concluir, as dependências de pacotes restantes são instaladas e a aplicação é servida e aberta no seu navegador padrão.

Para adicionar mais visualizações do Ignite UI for Angular a um projeto depois, sem o assistente, use o comando direto `add`:

```bash
ig add [template] [name]
```

## Configure os assistentes de IA

Depois de escolher o framework, o tipo de projeto, o template e o tema, o assistente pede para você configurar a integração com assistentes de programação com IA. Esta etapa executa a mesma lógica de `ig ai-config`, mas está incorporada ao fluxo de criação do projeto.

### Escolha os assistentes de programação

Você será solicitado a selecionar para quais assistentes de programação configurar os servidores MCP. Use a tecla SPACE para alternar as seleções e ENTER para confirmar:

<Image src={igStepByStepAiConfigAssistants} alt="Passo a passo: prompt de assistentes de programação para a configuração de IA" class="responsive-img" />

- **Genérico** (Claude Code, VS Code e outros) - grava `.mcp.json`
- **VS Code** (GitHub Copilot) - grava `.vscode/mcp.json`
- **Cursor** - grava `.cursor/mcp.json`
- **Gemini** - grava `.gemini/settings.json`
- **JetBrains Junie** - grava `.junie/mcp/mcp.json`
- **None** - pula a configuração MCP

A seleção padrão é **Genérico**. Selecionar **None** pula totalmente a configuração dos servidores MCP.

### Escolha os agentes de IA

Em seguida, você será solicitado a selecionar para quais agentes de IA configurar os arquivos de skill e as instruções:

<Image src={igStepByStepAiConfigAgents} alt="Passo a passo: prompt de agentes para a configuração de IA" class="responsive-img" />

- **Genérico** - `.agents/skills/` e `AGENTS.md`
- **Claude** - `.claude/skills/` e `.claude/CLAUDE.md`
- **Copilot** - `.github/skills/` e `.github/copilot-instructions.md`
- **Cursor** - `.cursor/skills/` e `.cursor/rules/cursor.mdc`
- **Codex** - `.codex/skills/` e `.codex/instructions.md`
- **Windsurf** - `.windsurf/skills/` e `.windsurf/rules/guidelines.md`
- **Gemini** - `.gemini/skills/` e `.gemini/GEMINI.md`
- **Junie** - `.junie/skills/` e `.junie/guidelines.md`
- **None** - pula os arquivos de skill e as instruções

As seleções padrão são **Genérico** e **Claude**. Selecionar **None** pula totalmente a configuração dos agentes.

<DocsAside type="info">
Para pular totalmente os prompts de configuração de IA durante a criação de projetos não interativa, informe `--assistants none --agents none` para `ig new`. Para executar a configuração de IA novamente mais tarde, use `ig ai-config` na raiz do projeto.
</DocsAside>
