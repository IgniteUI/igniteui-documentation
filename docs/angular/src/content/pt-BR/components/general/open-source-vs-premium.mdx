# Código aberto vs Premium no Ignite UI for Angular

O Ignite UI for Angular oferece dois caminhos distintos para criar aplicações modernas orientadas a dados: componentes de código aberto e componentes Premium. Essa abordagem dupla garante flexibilidade para os desenvolvedores em todas as etapas do projeto.

## Componentes de código aberto

Há mais de 50 componentes de UI disponíveis sob a licença MIT, incluindo [Grid Lite](/grid-lite/overview), Accordion, Avatar, Badge, Banner, Button, Calendar, Carousel, Checkbox, Chip, Combo, Date Picker, Drop Down, Input, List, Snackbar e outros. Você pode encontrar a lista completa na [Tabela de comparação de todos os componentes](#tabela-de-comparação-de-todos-os-componentes).

Todos os componentes de código aberto são marcados no cabeçalho dos seus tópicos com: <Badge variant="opensource" />

Eles são ideais para aplicações leves que precisam de funcionalidades essenciais sem a sobrecarga dos recursos empresariais. Você pode usá-los livremente em produção, personalizar, fazer fork e contribuir pelo GitHub. Nenhuma licença é necessária.

## Componentes Premium

Os componentes Premium do Ignite UI vêm com recursos empresariais avançados e são usados em aplicações complexas que exigem alto desempenho e funcionalidades mais ricas. Os componentes Premium incluem:

### Grades e componentes avançados

- [Data Grid](/grid/grid), [Hierarchical Grid](/hierarchicalgrid/hierarchical-grid), [Tree Grid](/treegrid/tree-grid), [Pivot Grid](/pivotgrid/pivot-grid)
- [Dock Manager](/dock-manager)
- [Query Builder](/query-builder)
- [Biblioteca de gráficos](/charts/chart-overview)
- [Biblioteca de mapas](/geo-map)
- [Biblioteca Excel](/excel-library)
- [Spreadsheet](/spreadsheet-overview)
- Medidores - [Bullet Graph](/bullet-graph), [Linear Gauge](/linear-gauge) e [Radial Gauge](/radial-gauge)

Todos os componentes Premium são marcados no cabeçalho dos seus tópicos com: <Badge variant="premium" />

Todos os componentes Premium podem ser avaliados localmente e até testados em produção com marca d'água. No entanto, é necessária uma licença comercial para implantações voltadas ao cliente e para liberar todo o potencial das grades avançadas, dos gráficos e dos demais controles Premium.

## Caminho de atualização

Comece com o Grid Lite para as necessidades essenciais e migre sem dificuldades para o Data Grid completo à medida que a complexidade da sua aplicação aumenta. Isso garante o mínimo de refatoração e uma transição tranquila para recursos de nível empresarial.
