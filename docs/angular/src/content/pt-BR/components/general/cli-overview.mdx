# Angular Schematics e Ignite UI CLI

O Ignite UI CLI e a coleção Ignite UI for Angular Schematics são duas ferramentas de scaffolding complementares para gerar projetos Angular e visualizações de componentes pré-configurados para o Ignite UI for Angular. Ambas oferecem um assistente guiado passo a passo e modos de comando não interativos. As duas produzem a mesma saída de projeto - diferem apenas na forma como se integram ao seu fluxo de trabalho.

O Ignite UI CLI não gerencia projetos Blazor ou Web Components por meio desta cadeia de ferramentas do Angular. Para o fluxo de trabalho somente do Angular com Schematics, sem uma ferramenta global separada, use `@igniteui/angular-schematics` diretamente com o Angular CLI. Nenhuma das ferramentas é necessária para usar o Ignite UI for Angular - a biblioteca pode ser instalada e configurada manualmente, conforme descrito no [guia Primeiros passos](./getting-started.mdx).

## Ignite UI CLI

O [Ignite UI CLI](https://github.com/IgniteUI/igniteui-cli) é uma ferramenta de linha de comando global e independente para criar e fazer o scaffolding de aplicações em Angular, React e jQuery. Instale-a com `npm install -g igniteui-cli` e invoque-a com o comando `ig`.

O CLI oferece um assistente guiado (`ig` ou `ig new`) e a criação de projetos não interativa (`ig new <name> --framework=angular --type=igx-ts`), o scaffolding de componentes (`ig add`), um servidor de desenvolvimento (`ig start`) e um servidor MCP integrado para integração com assistentes de IA (`ig mcp`).

Para instruções de configuração e todos os comandos disponíveis, consulte [Primeiros passos com o Ignite UI CLI](./cli/getting-started-with-cli.mdx).

## Ignite UI for Angular Schematics

Os [Ignite UI for Angular Schematics](https://github.com/IgniteUI/igniteui-cli/tree/master/packages/ng-schematics) são uma coleção de schematics que se integra ao Angular CLI. A coleção é adicionada ao seu projeto automaticamente quando você executa `ng add igniteui-angular`. Use-a com `ng new --collection="@igniteui/angular-schematics"` para criar projetos e com `ng g @igniteui/angular-schematics:component` para o scaffolding de componentes.

A coleção Schematics oferece os mesmos templates de projeto principais e as mesmas visualizações de componentes do CLI, dentro do fluxo de trabalho nativo do Angular CLI. Ela não inclui o servidor MCP - para a integração com assistentes de IA, use o Ignite UI CLI junto com o seu projeto Angular CLI.

Para instruções de configuração, consulte [Primeiros passos com o Ignite UI for Angular Schematics](./cli/getting-started-with-angular-schematics.mdx).

## Integração com assistentes de IA (MCP)

O Ignite UI CLI inclui um servidor MCP (Model Context Protocol) integrado, que conecta assistentes de programação com IA - GitHub Copilot, Claude, Cursor e outros - à documentação ao vivo dos componentes do Ignite UI e às referências de API. Depois de configurado, o seu assistente de IA pode consultar as APIs dos componentes, obter guias de configuração e gerar código preciso do Ignite UI for Angular sem sair do seu editor.

Inicie o servidor MCP com:

```cmd
ig mcp
```

Para a configuração do cliente (VS Code, Claude Desktop, Cursor) e a descrição das ferramentas disponíveis, consulte [Ignite UI CLI MCP](../ai/cli-mcp.mdx).
