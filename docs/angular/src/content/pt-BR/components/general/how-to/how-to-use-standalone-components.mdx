# Usando componentes standalone com o Ignite UI for Angular

O Angular 14 introduziu o conceito de [componentes standalone](https://angular.io/guide/standalone-components), que permite uma forma simplificada de criar aplicações, reduzindo a necessidade de usar `NgModules`. Os componentes standalone estiveram em prévia para desenvolvedores até o Angular 15. Para oferecer suporte a esse novo paradigma, todos os componentes do Ignite UI for Angular agora são exportados como `standalone` a partir da versão `16.0.0`. A partir do Angular 19, todos os componentes são standalone por padrão. Todos os `NgModules` existentes continuam sendo exportados pela biblioteca para compatibilidade com versões anteriores. No entanto, eles não declaram mais nenhum componente do Ignite UI for Angular. Em vez disso, eles importam e exportam os componentes `standalone`.

## Como usar os novos componentes standalone

A partir do Angular 16 e do Ignite UI for Angular 16.0, você pode simplesmente adicionar as importações de que o seu componente `standalone` precisa na propriedade `imports`. No exemplo a seguir, `IGX_GRID_DIRECTIVES` pode ser usado para importar todos os componentes e diretivas relacionados à grade.

```typescript
import { IGX_GRID_DIRECTIVES } from 'igniteui-angular/grids/grid';

@Component({
    selector: 'app-grid-sample',
    styleUrls: ['grid.sample.scss'],
    templateUrl: 'grid.sample.html',
    imports: [IGX_GRID_DIRECTIVES, AsyncPipe]
})
```

Mas você também pode importar individualmente todos os componentes usados pelo seu componente `standalone`. Um exemplo com `IgxGridComponent` e `IgxColumnComponent`, quando apenas esses dois são usados por outro componente, é o seguinte.

```typescript
import { IgxGridComponent, IgxColumnComponent } from 'igniteui-angular/grids/grid';

@Component({
    selector: 'app-grid-sample',
    styleUrls: ['grid.sample.scss'],
    templateUrl: 'grid.sample.html',
    imports: [IgxGridComponent, IgxColumnComponent, AsyncPipe]
})
```

Além disso, como todos os módulos existentes são preservados, mas agora apenas importam e exportam os componentes standalone, você também pode usá-los no seu componente standalone.

```typescript
// `NgModule` import of the `IgxGridModule` module, which is equivalent to IGX_GRID_DIRECTIVES in terms of exported components and directives.
import { IgxGridModule } from 'igniteui-angular/grids/grid';

@Component({
    selector: 'app-grid-sample',
    styleUrls: ['grid.sample.scss'],
    templateUrl: 'grid.sample.html',
    imports: [IgxGridModule, AsyncPipe]
})
```
