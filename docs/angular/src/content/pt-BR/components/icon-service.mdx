# Visão geral do Angular Icon Service

<div class="highlight">
O Icon Service do Ignite UI for Angular permite que os desenvolvedores adicionem novos ícones de várias fontes às suas UIs.
</div>

## Introdução

O Icon Service do Ignite UI for Angular oferece vários métodos que permitem aos usuários criar e gerenciar famílias de ícones.

O icon service pode ser importado diretamente do pacote Ignite UI for Angular.

```ts
import { IgxIconComponent } from 'igniteui-angular/icon';
import { IgxIconService } from 'igniteui-angular/core';

@Component({
    selector: 'app-root',
    standalone: true,
    imports: [ IgxIconComponent ]
})
export class AppComponent implements OnInit {
    constructor(public iconService: IgxIconService) {}
}
```

### Adicionando famílias de ícones

Por padrão, o Icon Service define a sua família padrão como `material`.

Adicionar novas famílias de ícones é feito usando o método `setFamily` do icon service. Ele cria uma entrada de família com alguns metadados que instruem o componente `igx-icon` sobre o(s) ícone(s) que ele deve renderizar.

Vamos usar um exemplo prático para explicar como o método `setFamily` funciona:

```ts
/** 
* The icon service associates a given family name (provided by the user) 
* with a specific CSS class (as documented in the providing icon font) 
* and corresponding icon name (documented in the icon font).
* NOTE: Material is already the default family.
*/ 
iconService.setFamily('material', { className: 'material-icons', type: 'liga' });
iconService.setFamily('fa-solid', { className: 'fas', type: 'font', prefix: 'fa' });
```

O exemplo acima cria duas famílias de ícones: 'material' e 'fa-solid'. Os tipos delas são diferentes: a família `material` é registrada como `liga`, enquanto a família `fa-solid` é registrada como `font`. A diferença entre os dois está em como o componente `igx-icon` os renderiza. Normalmente, o [Font Awesome](https://fontawesome.com/) usa nomes de classe para especificar pontos de código para uma família de **fontes**; por isso definimos o tipo dela como `font`. Sempre que precisarmos depender de pontos de código para renderizar ícones, devemos definir o tipo como `font`. A família [Material Icons](https://material.io/icons) continua sendo uma família de fontes; porém, a forma padrão de exibir um ícone é fornecer um nome de `ligature`, em vez de um nome de classe apontando para um ponto de código específico. Por isso, precisamos definir o tipo como `liga`. Existe um terceiro tipo de família - `svg`, reservado para famílias de ícones compostas por SVGs registrados pelo Icon Service.

Tendo registrado as duas famílias de fontes acima, agora podemos consumir os seus ícones de forma padronizada, pelo componente `igx-icon`:

```html
<igx-icon family="material" name="home"></igx-icon>
<igx-icon family="fa-solid" name="car"></igx-icon>
```


<DocsAside type="info">
Para renderizar ícones da família `material` padrão com `igx-icon`, adicione o seguinte link ao seu `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

Você deve ter notado que, para a família `material`, usamos a ligadura `name` como nome, enquanto, no caso da família `fa-solid`, especificamos o `className` como nome, que é `fa-car`, mas sem o prefixo `fa-`, já que ele foi especificado quando registramos a família de ícones na etapa anterior.

### Adicionando ícones SVG

O Icon Service do Ignite UI for Angular permite associar imagens SVG a famílias e dar nomes a elas, para que possam ser incluídas pelo componente `igx-icon` da mesma forma que os ícones baseados em fontes. Os SVGs devem ser resolvidos por strings ou por URI absoluta para o asset SVG.

```ts
// Add a new 'material' icon called 'my-icon' from an SVG file
iconService.addSvgIcon('my-icon', 'my-icon.svg', 'material');

// Add a new 'fa-solid' icon called 'my-icon' from string 
iconService.addSvgIconFromText('my-icon', '<svg>...</svg>', 'fa-solid');
```

Mais adiante, no markup:

```html
<igx-icon family="material" name="my-icon"></igx-icon>
<igx-icon family="fa-solid" name="my-icon"></igx-icon>
```

Observe que estamos adicionando ícones SVG personalizados a famílias do tipo `liga` e `font`. Isso é possível porque os métodos `addSvgIcon` e `addSvgIconFromText` registram os ícones implicitamente como do tipo `svg`, permitindo que o componente `igx-icon` renderize o SVG corretamente.

## Meta famílias

O Icon Service do Ignite UI for Angular permite criar mapas de pseudo-famílias que combinam ícones adicionados por meio da definição de uma família de ícones de fonte ou da adição de SVGs sob um mesmo guarda-chuva, para que seja mais fácil referenciá-los.

```ts
// The `setIconRef` sets an icon reference in the icon map,
// assuming material and fa-solid have been added as families,
iconService.setIconRef('home', 'my-family', { family: 'material', name: 'home' });
iconService.setIconRef('home-alt', 'my-family', { family: 'fa-solid', name: 'home' });
iconService.setIconRef('car', 'my-family', { family: 'fa-solid', name: 'car' });
```

Mais adiante, no markup:

```html
<igx-icon family="my-family" name="home"></igx-icon>
<igx-icon family="my-family" name="home-alt"></igx-icon>
<igx-icon family="my-family" name="car"></igx-icon>
```

## Obtenção de ícones

É possível obter um ícone para uma determinada `family` e um `name` de ícone, a fim de ler o `type`, `name`, `family` e `className` originais do ícone.

```ts
const { family, className, name, type } = iconService.getIcon('my-family', 'car');

console.log(family); // -> 'fa-solid'
console.log(className); // -> 'fas'
console.log(name); // -> 'fa-car'
console.log(type); // -> 'font'
```

Para aproveitar a alteração dos ícones internos por referência, em vez de criar templates personalizados, você pode fazer o seguinte para substituir os ícones de expandir/recolher nos componentes combo e select:

```ts
iconService.setIconRef('input_expand', 'default', {
    name: 'arrow_downward',
    family: 'material',
});

iconService.setIconRef('input_collapse', 'default', {
    name: 'arrow_upward',
    family: 'material',
});
```

Isso vai definir os ícones de expandir e recolher como as ligaduras `arrow_downward` e `arrow_upward`, respectivamente, da família de fontes `material`, para todos os componentes combo e select.

## API

Aqui está um resumo rápido de todos os métodos disponíveis pelo Icon Service do Ignite UI for Angular.

### Adicionar família

```ts
setFamily(name: string, meta: IconFamilyMeta): IgxIconService;
```

### Referências de ícones

Definir SOMENTE se o mapa de ícones ainda NÃO contiver o ícone:

```ts
addIconRef(name: string, family: string, icon: IconMeta): void;
```

Definir uma referência de ícone no mapa de ícones (substituída se já existir):

```ts
setIconRef(name: string, family: string, icon: IconMeta): void;
```

Obter uma referência de ícone

```ts
getIconRef(family: string, name: string): IconReference;
```

### Ícones SVG

A partir de URI:

```ts
addSvgIcon(name: string, url: string, family: string, stripMeta = false): void;
```

A partir de string:

```ts
addSvgIconFromText(name: string, iconText: string, family: string, stripMeta = false): void;
```
