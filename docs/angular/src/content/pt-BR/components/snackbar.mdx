# Visão geral do componente Angular Snackbar

<div class="highlight">
O componente Snackbar do Ignite UI for Angular fornece feedback sobre uma operação com uma mensagem de uma linha, que pode incluir uma ação. A mensagem do Snackbar aparece acima de todos os outros elementos e é posicionada no centro inferior da tela.

## Primeiros passos com o Snackbar do Ignite UI for Angular

Para começar com o componente Snackbar do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](./general/getting-started.mdx).

O próximo passo é importar o `IgxSnackbarModule` no arquivo **app.module.ts**.

```typescript
// app.module.ts

...
import { IgxSnackbarModule } from 'igniteui-angular/snackbar';
// import { IgxSnackbarModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxSnackbarModule],
    ...
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` você pode importar o `IgxSnackbarComponent` como uma dependência independente.

```typescript
// home.component.ts

import { IgxSnackbarComponent } from 'igniteui-angular/snackbar';
import { IgxButtonDirective } from 'igniteui-angular/directives';
// import { IgxSnackbarComponent, IgxButtonDirective } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <button igxButton="contained" (click)="snackbar.open()">Delete Message</button>
    <div>
        <igx-snackbar #snackbar>Message deleted</igx-snackbar>
    
</div>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxSnackbarComponent, IgxButtonDirective]
})
export class HomeComponent {}
```

Agora que você importou o módulo ou o componente Snackbar do Ignite UI for Angular, pode começar a usar o componente `igx-snackbar`.

## Usando o Angular Snackbar

### Exibindo o Snackbar

Para exibir o componente Snackbar, use o seu método <ApiLink type="Snackbar" member="open" label="open()" /> e chame-o ao clicar em um botão.

```html
{/*sample.component.html*/}

<button igxButton="contained" (click)="snackbar.open()">Delete Message</button>
<div>
    <igx-snackbar #snackbar>Message deleted</igx-snackbar>
</div>
```

Se o exemplo estiver configurado corretamente, você deve ver a demonstração. Um snackbar aparece exibindo uma mensagem de texto quando o botão é clicado.
Como você pode ver no trecho de código acima, uma forma de definir a mensagem exibida no snackbar é usar a projeção de conteúdo. Mas, se você precisar alterar o valor programaticamente, com base em alguma lógica personalizada, basta passar o valor como parâmetro para o método <ApiLink type="Snackbar" member="open" label="open()" />.

```html
{/*sample.component.html*/}

<button igxButton="contained" (click)="snackbar.open('Message deleted')">Delete Message</button>
<button igxButton="contained" (click)="snackbar.open('Message deletion was not successful. Please try again')">Delete Message</button>
<div>
    <igx-snackbar #snackbar></igx-snackbar>
</div>
```

### Ocultar/Ocultar automaticamente

Depois de aberto, o snackbar desaparece após um período especificado pela entrada <ApiLink type="Snackbar" member="displayTime" label="displayTime" />, que é definida inicialmente como 4000 milissegundos. Esse comportamento vem habilitado por padrão, mas você pode alterá-lo definindo <ApiLink type="Snackbar" member="autoHide" label="autoHide" /> como **false**. Dessa forma, o snackbar permanecerá visível. Usando o método <ApiLink type="Snackbar" member="close" label="close()" /> do snackbar, você pode fechar o componente no código.

```html
{/*sample.component.html*/}

<button igxButton="contained" (click)="snackbar.open()">Send message</button>
<div>
  <igx-snackbar #snackbar [autoHide]="false" actionText="CLOSE" (clicked)="close(snackbar)">Message sent</igx-snackbar>
</div>
```

```typescript
// sample.component.ts

public close(element) {
    element.close();
}
```

Se o exemplo estiver configurado corretamente, o primeiro snackbar aparece ao clicar no botão, mostrando a _mensagem_ e o _botão de ação_. O recurso de ocultação automática fica desativado, e o snackbar desaparece ao clicar no botão 'CLOSE'. Outro snackbar passa uma mensagem diferente pelo método <ApiLink type="Snackbar" member="open" label="open()" /> e se oculta quando o _tempo de exibição_ expira. O terceiro componente passa uma mensagem como parâmetro para o método <ApiLink type="Snackbar" member="open" label="open()" /> e adiciona um ícone usando a projeção de conteúdo.

<Sample src="/notifications/snackbar-sample-2" height={230} alt="" />

### Tempo de exibição

Use <ApiLink type="Snackbar" member="displayTime" label="displayTime" /> e defina um intervalo em milissegundos para configurar por quanto tempo o componente snackbar fica visível. Por padrão, como dissemos, ele é inicialmente definido como 4000 milissegundos.

### Personalizando o Snackbar

Também podemos personalizar o conteúdo do Snackbar para exibir elementos mais complexos do que uma mensagem e um botão. Se quisermos mostrar o snackbar durante o carregamento de um arquivo, por exemplo, uma animação de carregamento poderia ser adicionada ao seu conteúdo.

```html
{/*sample.component.html*/}
<button igxButton="contained" (click)="snackbar.open()">Load file</button>
<div>
  <igx-snackbar #snackbar displayTime="5000">File loading
    <svg id="dots" height="20px">
        <g id="dots" fill="#FFFFFF">
            <circle id="dot1" cx="5" cy="18" r="2"></circle>
            <circle id="dot2" cx="15" cy="18" r="2"></circle>
            <circle id="dot3" cx="25" cy="18" r="2"></circle>
        </g>
    </svg>
  </igx-snackbar>
</div>
```

```scss
//sample.component.scss
#dots #dot1 {
    animation: load 1s infinite;
}

#dots #dot2 {
    animation: load 1s infinite;
    animation-delay: 0.2s;
}

#dots #dot3 {
    animation: load 1s infinite;
    animation-delay: 0.4s;
}

@keyframes load {
    0% {
      opacity: 0;
    }
    50% {
      opacity: 1;
    }
    100% {
      opacity: 0;
    }
}
```

Como resultado, uma mensagem e três pontos de carregamento aparecem no snackbar.

### Snackbar em lista

Com todos os recursos principais do snackbar apresentados, podemos integrar este componente em um cenário mais interessante. Podemos usar o snackbar para fornecer uma notificação e a possibilidade de desfazer ações.

Vamos criar uma lista de contatos que podem ser excluídos. Quando um item é excluído, um snackbar é exibido, contendo uma mensagem e um botão para desfazer a ação.

```html
{/*sample.component.html*/}
<igx-list>
    <igx-list-item [isHeader]="true">Contacts</igx-list-item>

    <igx-list-item igxRipple="pink" igxRippleTarget=".igx-list__item" *ngFor="let item of navItems">
        <div class="item-container">

            <div class="contact">

                <igx-avatar [src]="item.avatar" shape="circle"></igx-avatar>
                <div class="contact__info">

                    <span class="name">{{item.text}}</span>
                
</div>
            
</div>
            <span igxIconButton="flat" igxRipple igxRippleCentered="true" (click)="delete(item)">
                <igx-icon [style.color]="'#ff5252'">delete</igx-icon>
            </span>
        
</div>

    </igx-list-item>

    <igx-snackbar actionText="Undo" (clicked)="restore()">Contact deleted</igx-snackbar>
</igx-list>
```

<DocsAside type="info">
Este componente usa Material Icons. Adicione o seguinte link ao seu `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

```typescript
//sample.component.ts

import { Component, OnInit, ViewChild } from '@angular/core';
import { IgxSnackbarComponent } from 'igniteui-angular/snackbar';
// import { IgxSnackbarComponent } from '@infragistics/igniteui-angular'; for licensed package
...
@ViewChild(IgxSnackbarComponent)
public snackbar: IgxSnackbarComponent;
public navItems: any[];
public deletedItems = [];

constructor() { }

public ngOnInit() {
    this.navItems = [
        { avatar: 'assets/images/avatar/2.jpg', text: 'Richard Mahoney'},
        { avatar: 'assets/images/avatar/4.jpg', text: 'Lisa Landers' },
        { avatar: 'assets/images/avatar/14.jpg', text: 'Marianne Taylor' },
        { avatar: 'assets/images/avatar/17.jpg', text: 'Ward Riley' }
    ];
}

public delete(item) {
    this.deletedItems.push([item, this.navItems.indexOf(item)]);
    this.navItems.splice(this.navItems.indexOf(item), 1);
    this.snackbar.open();
}

public restore() {
    const [item, index] = this.deletedItems.pop();
    this.navItems.splice(index, 0, item);
    this.snackbar.close();
}
```

### Posicionamento

Use a propriedade <ApiLink type="Snackbar" member="positionSettings" label="positionSettings" /> para configurar onde o snackbar aparece. Por padrão, ele é exibido na parte inferior da página. No exemplo abaixo, definimos que a notificação apareça na posição superior.

```html
{/*sample.component.html*/}
<button igxButton="contained" (click)="open(snackbar)">Show notification on top</button>
<igx-snackbar #snackbar>Notification displayed</igx-snackbar>
```

```typescript
// sample.component.ts
import { VerticalAlignment, HorizontalAlignment } from 'igniteui-angular/core';
// import { VerticalAlignment, HorizontalAlignment } from '@infragistics/igniteui-angular'; for licensed package
...
public open(snackbar) {
    snackbar.positionSettings.verticalDirection = VerticalAlignment.Top;
    snackbar.positionSettings.horizontalDirection = HorizontalAlignment.Right;
    snackbar.open();
}
...
```

## Estilização

### Mapa de propriedades de tema do Snackbar

Quando você modifica uma propriedade primária, todas as propriedades dependentes relacionadas são atualizadas automaticamente para refletir a mudança:

<table>
    <thead>
        <tr>
        <th>Propriedade primária</th>
        <th>Propriedade dependente</th>
        <th>Descrição</th>
        </tr>
    </thead>
    <tbody>
        <tr class="primary">
        <td><strong>$background</strong></td>
        <td>$text-color</td>
        <td>A cor do texto usada no snackbar</td>
        </tr>
        <tr class="dependent"><td></td><td>$button-color</td><td>A cor do botão usada no snackbar</td></tr>
    </tbody>
</table>

Para começar a estilizar o snackbar, precisamos importar o arquivo index, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Seguindo a abordagem mais simples, criamos um novo tema que estende o <ApiLink kind="sass" module="themes" type="function-snackbar-theme" label="snackbar-theme" code={true} /> e aceita os parâmetros `$text-color`, `$background`, `$button-color` e `$border-radius`.

```scss
$dark-snackbar: snackbar-theme(
  $text-color: #ffcd0f,
  $background: #292826,
  $button-color: #ffcd0f,
  $border-radius: 12px
);
```

<DocsAside type="info">
Em vez de definir os valores de cor diretamente, como acabamos de fazer, podemos obter mais flexibilidade em relação às cores usando as funções <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> e <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Consulte o tópico [`Palettes`](./themes/sass/palettes.mdx) para orientações detalhadas sobre como usá-las.
</DocsAside>

O último passo é **incluir** o tema do componente no nosso aplicativo.

```scss
:host {
    @include tokens($dark-snackbar);
}
```

### Estilizando com Tailwind

Você pode estilizar o snackbar usando as nossas classes utilitárias personalizadas do Tailwind. Antes, certifique-se de [configurar o Tailwind](./themes/tailwind.mdx).

Junto com a importação do tailwind na sua folha de estilos global, você pode aplicar os utilitários de tema desejados da seguinte forma:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

O arquivo de utilitários inclui as variantes de tema `light` e `dark`.

- Use as classes `light-*` para o tema claro.
- Use as classes `dark-*` para o tema escuro.
- Acrescente o nome do componente depois do prefixo, por exemplo, `light-snackbar`, `dark-snackbar`.

Depois de aplicadas, essas classes habilitam cálculos dinâmicos de tema. A partir daí, você pode substituir as variáveis CSS geradas usando `arbitrary properties`. Depois dos dois-pontos, informe qualquer formato de cor CSS válido (HEX, variável CSS, RGB etc.).

Você pode encontrar a lista completa de propriedades em <ApiLink kind="sass" module="themes" type="function-snackbar-theme" label="snackbar-theme" />. A sintaxe é a seguinte:

```html
<igx-snackbar
  class="!light-snackbar ![--background:#7B9E89]
  ![--button-color:#DD0D4B]">
  ...
</igx-snackbar>
```

<DocsAside type="info">
O ponto de exclamação (`!`) é obrigatório para garantir que a classe utilitária tenha precedência. O Tailwind aplica estilos em camadas e, sem marcar esses estilos como importantes, eles serão sobrescritos pelo tema padrão do componente.
</DocsAside>
