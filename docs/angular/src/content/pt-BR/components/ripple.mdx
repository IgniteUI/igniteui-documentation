## Primeiros passos com a diretiva Ripple do Ignite UI for Angular

Para começar com a diretiva Ripple do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](/general/getting-started).

O próximo passo é importar o `IgxRippleModule` no arquivo **app.module.ts**.

```typescript
// app.module.ts

import { IgxRippleModule } from 'igniteui-angular/directives';
// import { IgxRippleModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    imports: [
        ...
        IgxRippleModule,
        ...
    ]
})
export class AppModule {}
```

Alternativamente, a partir de `16.0.0`, você pode importar as `IgxRippleDirective` como dependências standalone.

```typescript
// home.component.ts

import { IgxRippleDirective, IgxButtonDirective } from 'igniteui-angular/directives';
// import { IgxRippleDirective, IgxButtonDirective } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: '<button igxButton="contained" igxRipple>Click Me</button>',
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IgxRippleDirective, IgxButtonDirective],
})
export class HomeComponent {}
```

Agora que você importou o módulo ou a diretiva Ripple do Ignite UI for Angular, pode começar a usar a diretiva `igxRipple`.

<DocsAside type="warning">
A <ApiLink type="RippleDirective" label="igxRipple" /> usa a Web Animation API e roda nativamente em [navegadores que a suportam.](http://caniuse.com/#feat=web-animation)
O polyfill `web-animations.min.js` está [disponível](https://github.com/web-animations/web-animations-js)
para outros navegadores.
</DocsAside>

## Usando a diretiva Ripple do Angular

### Adicionando o efeito ripple

Use a diretiva `igxRipple` para adicionar um efeito ripple ao elemento especificado:

```html
<button igxButton="contained" igxRipple>Click Me</button>
```

## Exemplos

### Cor personalizada

Você pode alterar facilmente a cor padrão do ripple usando `igxRipple`:

```html
<button igxButton="contained" igxRipple="white">White</button>
```

<Sample src="/interactions/ripple-sample-6" height={100} alt="Exemplo do Angular Ripple" />

### Efeito ripple centralizado

Por padrão, o efeito ripple começa na posição do evento de clique. Você pode alterar esse comportamento usando a propriedade <ApiLink type="RippleDirective" member="centered" label="igxRippleCentered" /> e definindo o centro do elemento como origem.

```html
<button igxButton="contained" igxRipple="white" [igxRippleCentered]="true">
  Centered
</button>
```

<Sample src="/interactions/ripple-sample-3" height={100} alt="Exemplo do Angular Ripple" />

### Duração do ripple

Podemos usar a propriedade <ApiLink type="RippleDirective" member="rippleDuration" label="igxRippleDuration" /> para alterar a duração da animação ripple, que, por padrão, é de 600 milissegundos.

```html
<button igxButton="contained" igxRipple [igxRippleDuration]="2000">
  Click Me
</button>
```

<Sample src="/interactions/ripple-sample-4" height={100} alt="Exemplo do Angular Ripple" />

### Alvo do ripple

Use a propriedade <ApiLink type="RippleDirective" member="rippleTarget" label="igxRippleTarget" /> para anexar um efeito ripple a um elemento específico dentro de um elemento pai.

```html
<div class="parent" igxRipple="white" igxRippleTarget=".child" [igxRippleCentered]="true">
  ...
  <button class="sample-button child" igxButton="contained">Read More</button>
</div>
```

Observe que, independentemente de você clicar no elemento pai ou no filho, o efeito ripple aparecerá apenas no botão.

<Sample src="/interactions/ripple-sample-2" height={350} alt="Exemplo do Angular Ripple" />

<DocsAside type="info">
O elemento filho que você quer alvejar com a propriedade `igxRippleTarget` precisa ter posicionamento relativo.
</DocsAside>

## Estilização

Primeiro, para usar as funções expostas pelo mecanismo de temas, precisamos importar para o nosso arquivo de estilos o arquivo `index`, onde ficam todas as funções e mixins de estilização:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Você pode criar facilmente um novo tema que estende o <ApiLink kind="sass" module="themes" type="function-ripple-theme" label="ripple-theme" code={true} /> e aceita os parâmetros necessários para personalizar o ripple como desejar.

```scss
$custom-ripple-theme: ripple-theme(
  $color: #383779,
);
```

A próxima etapa é passar o tema ripple personalizado:

```scss
:host {
  @include tokens($custom-ripple-theme);
}
```

<DocsAside type="info">
Uma cor definida usando a diretiva `igxRiple` tem precedência sobre uma definida por um tema personalizado.
</DocsAside>
