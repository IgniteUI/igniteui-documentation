# Dock Manager

O componente Ignite UI Dock Manager oferece meios de gerenciar o layout da sua aplicação por meio de painéis, permitindo que os usuários finais o personalizem ainda mais, fixando, redimensionando, movendo e ocultando painéis.

## Uso

O Dock Manager é um [web component](https://developer.mozilla.org/en-US/docs/Web/Web_Components) padrão e, como tal, pode ser usado em uma aplicação Angular.

Siga as etapas abaixo para adicionar o pacote do Dock Manager ao seu projeto Angular e configurá-lo para usar o componente.

Primeiro, instale o pacote `igniteui-dockmanager`

```cmd
npm install igniteui-dockmanager
```

Em seguida, inclua o schema `CUSTOM_ELEMENTS_SCHEMA` em `AppModule`:

```typescript
import { CUSTOM_ELEMENTS_SCHEMA, NgModule } from '@angular/core';

@NgModule({
    ...
    schemas: [CUSTOM_ELEMENTS_SCHEMA]
})
export class AppModule {}
```

Depois, é preciso chamar a função `defineComponents()` no arquivo `main.ts`:

```typescript
import { AppModule } from './app/app.module';
import { defineComponents } from 'igniteui-dockmanager';
import { enableProdMode } from '@angular/core';
import { environment } from '.environments/environment';
import { platformBrowserDynamic } from '@angular/platform-browser-dynamic';

if (environment.production) {
    enableProdMode();
}

platformBrowserDynamic().bootstrapModule(AppModule)
    .catch(err => console.log(err));

defineComponents(IgcDockManagerComponent);
```

Pronto, agora você pode usar o componente Dock Manager no template de um componente Angular. Para isso, basta usar o nome da tag:

```html
<igc-dockmanager>
</igc-dockmanager>
```

Para mais informações sobre o uso do componente Dock Manager, você pode consultar [este tópico]({environment:infragisticsBaseUrl}/products/ignite-ui-web-components/web-components/components/dock-manager.html).
