# Tree Grid com carregamento sob demanda

O <ApiLink type="TreeGrid" /> do Ignite UI for Angular pode ser renderizado de forma que exija a menor quantidade possível de dados do servidor, para que o usuário possa vê-lo o mais rápido possível. Depois, somente quando o usuário expande uma linha, os filhos dessa linha pai específica são carregados. Esse mecanismo, também conhecido como Carregamento sob demanda, pode ser facilmente configurado para funcionar com qualquer dado remoto.

### Uso

O recurso de carregamento sob demanda é compatível com os dois tipos de fontes de dados do Tree Grid — [`primary and foreign keys`](/treegrid/tree-grid#chaves-primárias-e-estrangeiras) ou [`child collection`](/treegrid/tree-grid#coleção-filha). Você só precisa carregar os dados do nível raiz no Tree Grid e especificar as chaves necessárias para um dos tipos de fonte de dados. Para carregar as linhas filhas quando o usuário expande uma linha, o Tree Grid oferece a propriedade de entrada de callback <ApiLink type="TreeGrid" member="loadChildrenOnDemand" label="loadChildrenOnDemand" />.

```html
<igx-tree-grid #treeGrid [data]="data" primaryKey="ID" foreignKey="ParentID"
        [loadChildrenOnDemand]="loadChildren">
        ...
</igx-tree-grid>
```


O callback <ApiLink type="TreeGrid" member="loadChildrenOnDemand" label="loadChildrenOnDemand" /> recebe dois parâmetros:

- parentID - o ID da linha pai que está sendo expandida.
- done - callback que deve ser chamado com os filhos quando eles forem obtidos do servidor.

```typescript
public loadChildren = (parentID: any, done: (children: any[]) => void) => {
    this.dataService.getData(parentID, (children) => done(children));
}
```

Depois que o usuário clica no ícone de expandir, ele é substituído por um indicador de carregamento. Quando o callback `done` é chamado, o indicador de carregamento desaparece e os filhos são carregados. O Tree Grid adiciona os filhos à fonte de dados subjacente e preenche automaticamente as chaves necessárias.

Se você tiver como informar, antes de expandir uma linha, se ela tem filhos, pode usar a propriedade de entrada <ApiLink type="TreeGrid" member="hasChildrenKey" label="hasChildrenKey" />. Assim, você pode fornecer uma propriedade booleana dos objetos de dados que indica se um indicador de expansão deve ser exibido.

```html
<igx-tree-grid #treeGrid [data]="data" primaryKey="ID" foreignKey="ParentID"
        [loadChildrenOnDemand]="loadChildren" hasChildrenKey="hasEmployees">
        ...
</igx-tree-grid>
```

Observe que definir a propriedade <ApiLink type="TreeGrid" member="hasChildrenKey" label="hasChildrenKey" /> não é obrigatório. Se você não a fornecer, os indicadores de expansão serão exibidos em cada linha. Depois de expandir uma linha que não tem filhos, você ainda precisa chamar o callback `done` com undefined ou com um array vazio. Nesse caso, depois que o indicador de carregamento desaparece, o indicador de expansão nunca aparece.

Se você quiser fornecer o seu próprio indicador de carregamento personalizado, pode criar um ng-template e marcá-lo com a diretiva `igxRowLoadingIndicator`. O trecho de código a seguir demonstra como definir esse template personalizado:

```html
<igx-tree-grid ...>

    ...

    <ng-template igxRowLoadingIndicator>
        <igx-icon fontSet="material">loop</igx-icon>
    </ng-template>
</igx-tree-grid>
```
