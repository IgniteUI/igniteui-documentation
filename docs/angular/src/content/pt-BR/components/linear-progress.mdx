# Visão geral do componente Angular Linear Progress

<div class="highlight">
O componente Linear Progress Bar Indicator do Ignite UI for Angular oferece um indicador visual do andamento de um processo da aplicação conforme ele muda. O indicador atualiza a sua aparência conforme o seu estado muda. O indicador pode ser estilizado com uma escolha de cores em listras ou em cores sólidas.
</div>

## Primeiros passos com o Linear Progress do Ignite UI for Angular

Para começar com o componente Linear Progress do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](/general/getting-started).

O próximo passo é importar o `IgxProgressBarModule` no arquivo **app.module.ts**:

```typescript
// app.module.ts

...
import { IgxProgressBarModule } from 'igniteui-angular/progressbar';
// import { IgxProgressBarModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxProgressBarModule],
    ...
})
export class AppModule {}
```

Alternativamente, a partir de `16.0.0` você pode importar o `IgxLinearProgressBarComponent` como uma dependência independente, ou usar o token [`IGX_LINEAR_PROGRESS_BAR_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/progressbar/src/progressbar/public_api.ts) para importar o componente e todos os seus componentes e diretivas de apoio.

```typescript
// home.component.ts

import { IGX_LINEAR_PROGRESS_BAR_DIRECTIVES } from 'igniteui-angular/progressbar';
// import { IGX_LINEAR_PROGRESS_BAR_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: '<igx-linear-bar [value]="progress"></igx-linear-bar>',
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IGX_LINEAR_PROGRESS_BAR_DIRECTIVES],
  /* or imports: [IgxLinearProgressBarComponent] */
})
export class HomeComponent {
  public progress = 50;
}
```

Agora que você importou o módulo ou as diretivas do Progress Bar do Ignite UI for Angular, pode começar a usar o componente `igx-linear-bar`.

## Usando o Angular Linear Progress

Para entender melhor como tudo funciona, vamos criar um exemplo simples, como o da demonstração:

```html
<igx-linear-bar [value]="100"></igx-linear-bar>
```

Depois disso, você deve ver o exemplo da demonstração no seu navegador.

### Tipos de progresso

Você pode definir o tipo da sua barra usando o atributo <ApiLink type="LinearProgressBar" member="type" label="type" />. Há cinco tipos de barras de progresso lineares: `default`, `error`, `success`, `info` e `warning`.

### Progresso com listras

Você pode deixar a barra com listras, usando a propriedade <ApiLink type="LinearProgressBar" member="striped" label="striped" /> e definindo-a como `true`.

Vamos ver como criar diferentes tipos de barras de progresso, que podem ter listras ou não.

```html
<div class="linear-container">

  <igx-linear-bar [value]="100" type="default"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="success" [striped]="true"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="error"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="info" [striped]="true"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="warning"></igx-linear-bar>
</div>
```


Então, se configurarmos tudo corretamente, você deve ver o seguinte no seu navegador:

### Progresso indeterminado

Se você quiser acompanhar um processo que não é determinado com precisão, pode definir a propriedade de entrada <ApiLink type="LinearProgressBar" member="indeterminate" label="indeterminate" /> como `true`.

### Duração da animação

A propriedade de entrada <ApiLink type="LinearProgressBar" member="animationDuration" label="animationDuration" /> é usada para especificar a duração de cada ciclo da animação.

O exemplo a seguir define a duração da animação como 5 segundos.

```html
<igx-linear-bar [striped]="false" [value]="100" [animationDuration]="5000"></igx-linear-bar>
```

### Propriedades de texto

Você pode alinhar o texto usando a propriedade <ApiLink type="LinearProgressBar" member="textAlign" label="textAlign" />. Os valores permitidos são `left`, `center` e `right`.

Para ocultar o texto, use a propriedade <ApiLink type="LinearProgressBar" member="textVisibility" label="textVisibility" /> e defina o seu valor como `false`.

Defina a propriedade <ApiLink type="LinearProgressBar" member="textTop" label="textTop" /> como `true` para mover o texto acima da barra.

A propriedade <ApiLink type="LinearProgressBar" member="text" label="text" /> pode ser usada para personalizar o valor do próprio texto.

Vamos atualizar o nosso exemplo anterior usando as propriedades de texto mencionadas. Também vamos adicionar uma barra de progresso indeterminada à mistura.

```html
<div class="linear-container">

  <igx-linear-bar type="default" [value]="100"></igx-linear-bar>
  <igx-linear-bar
    type="success"
    [value]="100"
    class="indeterminate"
    [indeterminate]="true"
    [striped]="true"
  ></igx-linear-bar>
  <igx-linear-bar
    type="error"
    [value]="100"
    [textAlign]="positionEnd"
    [text]="'Custom text'"
  ></igx-linear-bar>
  <igx-linear-bar
    type="info"
    [value]="100"
    [textVisibility]="false"
    [striped]="true"
  ></igx-linear-bar>
  <igx-linear-bar
    type="warning"
    [value]="100"
    [textTop]="true"
  ></igx-linear-bar>
</div>
```

E não se esqueça de importar o enumerador <ApiLink type="IgxTextAlign" kind="variable" /> no seu componente, se estiver usando a propriedade `textAlign`.

```typescript
import { ..., IgxTextAlign } from 'igniteui-angular/progressbar';
// import { ..., IgxTextAlign } from '@infragistics/igniteui-angular'; for licensed package
...

public positionCenter: IgxTextAlign = IgxTextAlign.CENTER;
public positionEnd: IgxTextAlign = IgxTextAlign.END;
```

<DocsAside type="info">
Se o valor da entrada <ApiLink type="LinearProgressBar" member="step" label="step" /> não estiver definido, a atualização do progresso será de **1% do valor de <ApiLink type="LinearProgressBar" member="max" label="max" />**. Se você quiser que o progresso seja mais rápido, o valor de <ApiLink type="LinearProgressBar" member="step" label="step" /> deve ser maior que (**<ApiLink type="LinearProgressBar" member="max" label="max" /> * 1%**); da mesma forma, para um progresso mais lento, o valor de <ApiLink type="LinearProgressBar" member="step" label="step" /> deve ser menor que a atualização padrão do progresso.
</DocsAside>

<DocsAside type="info">
Se o valor de <ApiLink type="LinearProgressBar" member="step" label="step" /> for definido como maior que a entrada <ApiLink type="LinearProgressBar" member="value" label="value" />, haverá apenas uma atualização, que recebe **o valor passado para a atualização do progresso**.
</DocsAside>

### Progresso dinâmico

Você pode alterar dinamicamente o valor da barra de progresso usando controles externos, como botões. Para isso, podemos vincular o valor a uma propriedade da classe:

```html
<div class="linear-container">

  <igx-linear-bar [value]="currentValue" [max]="100"></igx-linear-bar>

  <div class="button-container">

    <button igxIconButton="flat" (click)="decrementProgress()">
      <igx-icon fontSet="material">remove</igx-icon>
    </button>
    <button igxIconButton="flat" (click)="incrementProgress()">
      <igx-icon fontSet="material">add</igx-icon>
    </button>
  
</div>
</div>
```

<DocsAside type="info">
Este componente usa Material Icons. Adicione o seguinte link ao seu `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

Crie os métodos que incrementam e decrementam o valor:

```typescript
public currentValue: number;

public ngOnInit() {
    this.currentValue = 0;
}

public incrementProgress() {
    this.currentValue += 10;
    if (this.currentValue > 100) {
        this.currentValue = 100;
    }
}

public decrementProgress() {
    this.currentValue -= 10;
    if (this.currentValue < 0) {
        this.currentValue = 0;
    }
}
```

## Estilização

Para começar a estilizar a barra de progresso linear, precisamos importar o arquivo `index`, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Seguindo a abordagem mais simples, criamos um novo tema que estende o <ApiLink kind="sass" module="themes" type="function-progress-linear-theme" label="progress-linear-theme" code={true} /> e substitui os parâmetros `$fill-color-default` e `$text-color`.

```scss
$custom-theme: progress-linear-theme(
  $fill-color-default: #ecaa53,
  $text-color: #ecaa53,
);
```

### Incluindo temas

O último passo é **incluir** o tema do componente no nosso aplicativo.

```scss
:host {
  @include tokens($custom-theme);
}
```
