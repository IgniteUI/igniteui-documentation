# Visão geral do componente Angular Month Picker

<div class="highlight">
O componente Month Picker do Ignite UI for Angular oferece uma forma fácil e intuitiva de selecionar um mês e ano específicos, usando uma visualização de calendário mês-ano. O componente permite vincular o seu valor a um objeto de data, e os usuários podem alterar a parte de mês e ano do objeto de data pela UI do month picker. Ele também oferece suporte à localização.
</div>

## Primeiros passos com o Month Picker do Ignite UI for Angular

Para começar com o componente Month Picker do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](/general/getting-started).

O primeiro passo é importar o `IgxCalendarModule` no nosso arquivo **app.module.ts**.

<DocsAside type="info">
O <ApiLink type="MonthPicker" label="**IgxMonthPickerComponent**" /> também depende de [`BrowserAnimationsModule`](https://angular.io/api/platform-browser/animations/BrowserAnimationsModule), então ele também precisa ser adicionado ao AppModule:
</DocsAside>

```typescript
// app.module.ts
...
import { BrowserAnimationsModule } from '@angular/platform-browser/animations';
import { IgxCalendarModule } from 'igniteui-angular/calendar';
// import { IgxCalendarModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., BrowserAnimationsModule, IgxCalendarModule],
    ...
})
export class AppModule {}
```

Alternativamente, a partir de `16.0.0` você pode importar o `IgxMonthPickerComponent` como uma dependência independente, ou usar o token [`IGX_CALENDAR_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/calendar/src/calendar/public_api.ts) para importar o componente e todos os seus componentes e diretivas de apoio.

```typescript
// home.component.ts

import { BrowserAnimationsModule } from '@angular/platform-browser/animations';
import { IgxMonthPickerComponent } from 'igniteui-angular/calendar';
// import { IgxMonthPickerComponent } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: '<igx-month-picker></igx-month-picker>',
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [BrowserAnimationsModule, IgxMonthPickerComponent]
    /* or imports: [BrowserAnimationsModule, IGX_CALENDAR_DIRECTIVES] */
})
export class HomeComponent {}
```

Agora que você importou o módulo Calendar ou o componente Month Picker do Ignite UI for Angular, pode começar a usar o componente `igx-month-picker`.

<DocsAside type="info">
Observe que o <ApiLink type="MonthPicker" /> usa a [WebAPI Intl](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/DateTimeFormat) para a localização e a formatação de datas.
Considere usar os [polyfills apropriados](https://github.com/andyearnshaw/Intl.js/) se a sua plataforma de destino não oferecer suporte a eles.
</DocsAside>

## Usando o Month Picker do Angular

Para adicionar o Angular Month Picker em um template, use o seguinte código:

```html
{/* month-picker-sample.component.html */}

<igx-month-picker></igx-month-picker>
```

### Definindo a data

Defina uma data para <ApiLink type="MonthPicker" /> usando a entrada <ApiLink type="MonthPicker" member="value" label="value" />.

```typescript
// month-picker-sample.component.ts

public date: Date = new Date();
```

```html
{/* month-picker-sample.component.html */}

<igx-month-picker [value]="date"></igx-month-picker>
```

Para criar uma vinculação de dados bidirecional, defina `ngModel` assim:

```html
{/* month-picker-sample.component.html */}

<igx-month-picker [(ngModel)]="date"></igx-month-picker>
```

### Formatação

Altere o formato de exibição do month picker, usando as entradas <ApiLink type="MonthPicker" member="formatoptions" label="formatOptions" />.

```html
{/* month-picker-sample.component.html */}

<igx-month-picker [(ngModel)]="date" [formatOptions]="numericFormatOptions"></igx-month-picker>
```

```typescript
// month-picker-sample.component.ts

public date: Date = new Date();
public numericFormatOptions = {
    month: '2-digit'
};
```

### Localização

Use a entrada <ApiLink type="MonthPicker" member="locale" label="locale" /> para personalizar a localização do Month Picker do Ignite UI for Angular.

```html
{/* month-picker-sample.component.html */}

<igx-month-picker [(ngModel)]="date" [locale]="locale" [formatOptions]="formatOptions"></igx-month-picker>
```

```typescript
// month-picker-sample.component.ts

public date: Date = new Date();
public locale: 'fr';
public formatOptions = {
    month: 'long'
};
```

## Navegação pelo teclado

- Quando o componente **igxMonthPicker** estiver com foco, use
  - a tecla <kbd>PageUp</kbd> para ir para o ano anterior,
  - a tecla <kbd>PageDown</kbd> para ir para o próximo ano,
  - a tecla <kbd>Home</kbd> para focar o primeiro mês do ano atual,
  - a tecla <kbd>End</kbd> para focar o último mês do ano atual,
  - a tecla <kbd>Tab</kbd> para navegar pelos botões do subcabeçalho.

- Quando o botão de ano `<` (anterior) ou `>` (próximo) (no subcabeçalho) estiver com foco, use
  - a tecla <kbd>Space</kbd> ou <kbd>Enter</kbd> para rolar até o próximo ou o ano anterior ficar visível.

- Quando o botão de anos (no subcabeçalho) estiver com foco, use
  - a tecla <kbd>Space</kbd> ou <kbd>Enter</kbd> para abrir a visualização de anos,
  - as teclas de seta <kbd>Right</kbd> ou <kbd>Left</kbd> para rolar até o ano anterior/próximo ficar visível.

- Quando um mês dentro da visualização de meses estiver com foco, use
  - as teclas de seta para navegar pelos meses,
  - a tecla <kbd>Home</kbd> para focar o primeiro mês dentro da visualização de meses,
  - a tecla <kbd>End</kbd> para focar o último mês dentro da visualização de meses,
  - a tecla <kbd>Enter</kbd> para selecionar o mês com foco no momento e fechar a visualização,
  - a tecla <kbd>Tab</kbd> para navegar pelos meses.

## Estilização

Para começar a estilizar o month picker, precisamos importar o arquivo `index`, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

O month picker usa o tema do calendário; por isso, precisamos criar um novo tema que estenda o <ApiLink kind="sass" module="themes" type="function-calendar-theme" label="calendar-theme" code={true} />. Para estilizar os itens do month picker, você pode definir o parâmetro `$content-background`. Opcionalmente, você também pode definir `$header-background` se quiser substituir o restante das propriedades.
Esses dois parâmetros servem como base do tema e são usados para gerar automaticamente as cores de fundo e de primeiro plano adequadas para todos os estados de interação, como mouse sobre, selecionado e ativo.

```scss
$my-calendar-theme: calendar-theme(
  $border-radius: 15px,
  $content-background: #57a5cd,
);
```

A próxima etapa é **incluir** o tema do componente na nossa aplicação.

```scss
:host {
  @include tokens($my-calendar-theme);
}
```

### Estilizando com Tailwind

Você pode estilizar o `month picker` usando nossas classes utilitárias personalizadas do Tailwind. Certifique-se de [configurar o Tailwind](/themes/tailwind) primeiro.

Junto com a importação do tailwind na sua folha de estilos global, você pode aplicar os utilitários de tema desejados da seguinte forma:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

O arquivo de utilitários inclui as variantes de tema `light` e `dark`. O month picker é estilizado pelo tema do calendário; por isso, você deve usar a classe utilitária do calendário

- Use as classes `light-*` para o tema claro.
- Use as classes `dark-*` para o tema escuro.
- Acrescente o nome do componente depois do prefixo, por exemplo, `light-calendar`, `dark-calendar`.

Depois de aplicadas, essas classes habilitam cálculos dinâmicos de tema. A partir daí, você pode substituir as variáveis CSS geradas usando `arbitrary properties`. Depois dos dois-pontos, informe qualquer formato de cor CSS válido (HEX, variável CSS, RGB etc.).

Você pode encontrar a lista completa de propriedades em <ApiLink kind="sass" module="themes" type="function-calendar-theme" label="calendar-theme" />. A sintaxe é a seguinte:

```html
<igx-month-picker
class="!light-calendar
![--header-background:#4F6A5A]
![--content-background:#A3C7B2]">
</igx-month-picker>
```

<DocsAside type="info">
O ponto de exclamação (`!`) é obrigatório para garantir que a classe utilitária tenha precedência. O Tailwind aplica estilos em camadas e, sem marcar esses estilos como importantes, eles serão sobrescritos pelo tema padrão do componente.
</DocsAside>
