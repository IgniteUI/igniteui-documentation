# Elevações

<div class="highlight">


As elevações são usadas para estabelecer e manter limites funcionais entre árvores do Document Object Model, permitindo um melhor encapsulamento funcional. A implementação das elevações no Ignite UI for Angular segue o modelo das [Elevações do Material Design](https://material.io/design/environment/elevation.html#elevation-in-material-design).

</div>
<igc-divider></igc-divider>

## Visão geral

As sombras no Ignite UI for Angular seguem de perto as diretrizes do Material Design para estabelecer uma hierarquia de profundidade com base em 25 níveis de elevação. O tamanho da sombra projetada está relacionado ao número do nível de elevação. Quanto maior o número do nível de elevação, maior será a sombra. As elevações no Ignite UI for Angular são expostas como variáveis CSS. Cada variável armazena um conjunto de 3 `box-shadows`. Esses `box-shadows` representam os elementos umbra, penumbra e antumbra, que são as propriedades das sombras observadas no mundo real.

A seguir, uma lista das elevações em repouso usadas em vários componentes do Ignite UI for Angular no tema Material e os nomes correspondentes das variáveis CSS:

| Componente                                          | Nível de elevação padrão | Variável CSS      |
| :------------------------------------------------- | :---------------------- | :---------------- |
| banner, button, toast                              | 0                       | --ig-elevation-0  |
| badge, botões do carousel, entrada de pesquisa              | 1                       | --ig-elevation-1  |
| grupo de botões, botão contido, card, grid, switch | 2                       | --ig-elevation-2  |
| navbar, snackbar                                   | 4                       | --ig-elevation-4  |
| botão de ação flutuante,                            | 6                       | --ig-elevation-6  |
| bottom navigation, ghost chip, dropdown            | 8                       | --ig-elevation-8  |
| navdrawer                                          | 16                      | --ig-elevation-16 |
| dialog                                             | 24                      | --ig-elevation-24 |

Como você pode ver na coluna `CSS Variable`, todas as elevações são definidas no formato `--ig-elevation-[level]`. Como mencionado, o número do nível de elevação vai de 0 a 24 (inclusive).

## Uso

Para começar a usar elevações nos seus próprios componentes, basta referenciar o nome da variável do nível desejado.

```css
.floaty-element {
  box-shadow: var(--ig-elevation-6);
}
```

Alterar a elevação em um tema de componente existente funciona de forma semelhante.

```css
[igxButton="contained"] {
  --resting-shadow: var(--ig-elevation-4);
  --hover-shadow: var(--ig-elevation-12);
  --focus-shadow: var(--ig-elevation-12);
}
```

A documentação de cada tema de componente lista a elevação padrão usada em cada um dos seus estados. Se a elevação não estiver listada, o componente não usa nenhum dos níveis de elevação predefinidos.

## Definindo elevações

Atualizar as elevações padrão funciona de forma semelhante a como as cores da paleta são atualizadas. Basta reatribuir a variável a outro valor. Para elevações, certifique-se de que o valor seja um `box-shadow`.

Exemplo:

```css
/* styles.css */
:root {
    --ig-elevation-1: 0 2px 6px 0 rgba(0, 0, 0, .18);
    --ig-elevation-2: 0 3px 9px 0 rgba(0, 0, 0, .24);
}
```

Agora, todos os componentes que usam os níveis de elevação 1 e 2 terão as suas sombras atualizadas.

### Sombreamento

Você pode sobrescrever as elevações definidas globalmente apenas para um escopo específico. Já vimos que o componente button usa o nível de elevação 2 no seu estado de repouso. O nível 2 também é usado pelos componentes card e grid. Então, para alterar as sombras dos três, basta fazer o seguinte:

```css
[igxButton="contained"],
igx-grid,
igx-card {
    --ig-elevation-2: 0 3px 9px 0 rgba(0, 0, 0, .24);
}
```

Isso definirá a `--resting-shadow` no botão contido e no card, e a `--grid-shadow` no grid, com o valor atribuído a `--ig-elevation-2`;
