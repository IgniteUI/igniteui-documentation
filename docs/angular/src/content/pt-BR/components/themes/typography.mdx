# Tipografia

<div class="highlight">

A tipografia do Ignite UI for Angular é modelada com base no [Material Type System](https://material.io/design/typography/the-type-system.html#). Ela não é intrusiva e é opcional, permitindo que você modifique os estilos tipográficos apenas com CSS.
</div>

## Visão geral

O sistema tipográfico é uma **_escala tipográfica_** composta por **_13 estilos de categoria diferentes_**, usados na maioria dos componentes. Todas as categorias de escala são totalmente reutilizáveis e podem ser ajustadas pelo usuário final.

Cada tema define a sua própria escala tipográfica. Isso significa que cada um dos temas que enviamos — Material, Fluent, Bootstrap e Indigo — terá a sua própria escala tipográfica. Todos compartilham as mesmas _categorias de escala_, mas podem ter família de fonte, peso, tamanho, transformação de texto, espaçamento entre letras e altura de linha diferentes.

## Uso
>
<DocsAside type="info">
Por padrão, não aplicamos nenhum estilo tipográfico. Para usar a nossa tipografia na sua aplicação, você precisa definir a classe CSS `ig-typography` em um elemento de nível superior. Todos os seus filhos passarão a usar os nossos estilos tipográficos.
</DocsAside>

Escolhemos a [Titillium Web](https://fonts.google.com/selection?selection.family=Titillium+Web:300,400,600,700) como fonte padrão do tema Material do Ignite UI for Angular. Para usá-la, você precisa hospedá-la por conta própria ou incluí-la a partir do Google Fonts:

```html
<link
  href="https://fonts.googleapis.com/css?family=Titillium+Web:300,400,600,700"
  rel="stylesheet"
/>
```

Ative os estilos tipográficos definindo a classe `ig-typography` no elemento body.

```html
{/* index.html */}
<body class="ig-typography">
  <app-root></app-root>
</body>
```

### Alterando a família da fonte

Para alterar a família da fonte em todos os componentes, basta sobrescrever a variável CSS `--ig-typography` com outro valor de font-family;

```css
/* styles.css */
:root {
    --ig-font-family: "Open Sans", sans-serif;
}
```

## Estilos tipográficos

Os estilos tipográficos são usados internamente pela maioria dos componentes do Ignite UI for Angular. Por exemplo, a documentação diz que o componente button usa o estilo tipográfico button. Isso significa que podemos modificar a tipografia do componente button sobrescrevendo as variáveis CSS `--ig-button-*` incluídas.

Digamos que queremos que o texto do botão no tema Material fique sempre em minúsculas.

```css
:root {
    --ig-button-text-transform: lowercase;
}
```
