# Arredondamento

O Ignite UI for Angular permite personalizar a forma dos componentes ajustando o seu arredondamento, usando um valor entre 0 e 1.

## Visão geral

Muitos componentes do Ignite UI têm valores predefinidos mínimo e máximo de border-radius, que podem ser ajustados usando a variável CSS `--ig-radius-factor`.

Quando você define `--ig-radius-factor` como 0, o componente usa o seu border-radius mínimo e aparece mais em formato de bloco, com cantos retos. Quando definido como 1, o componente usa o seu border-radius máximo predefinido e aparece arredondado.

Veja a seguir uma lista dos componentes que têm valores predefinidos mínimo e máximo de border-radius e que podem ser modificados usando a variável `--ig-radius-factor`: <br/>
• [Action Strip](/action-strip) • [Button](inputs/button) • [Button Group](/inputs/button-group) • [Calendar](/calendar) • [Card](/layouts/card) • [Carousel](/layouts/carousel) • [Checkbox](/inputs/checkbox) • [Chip](/inputs/chip) • [Combo](/inputs/combo/overview) • [Date Picker](/date-picker) • [Date Range Picker](/date-range-picker) • [Grid](/grid/grid) • [Input Group](/input-group) • [Linear Progress](/linear-progress) • [List](/list) • [Month Picker](/month-picker) • [Navigation Drawer](/navdrawer) • [Radio](/inputs/radio) • [Ripple](/ripple) • [Snackbar](/snackbar) • [Switch](inputs/switch) • [Toast](/toast)

## Uso

Para alternar entre os dois valores de border-radius em um componente, direcione o seletor do elemento e defina a variável `--ig-radius-factor` como 0 ou 1:

```css
igx-chip {
   --ig-radius-factor: 0;
}
```

Isso aplicará o border-radius mínimo predefinido, resultando no componente [Chip](/inputs/chip) com cantos retos.

```css
igx-chip {
    --ig-radius-factor: 1;
}
```

E, ao definir o valor como 1, o border-radius máximo predefinido é aplicado, resultando em cantos arredondados para o componente [Chip](/inputs/chip).

Se você quiser que o border-radius fique em algum ponto entre os valores mínimo e máximo definidos, pode definir a variável `--ig-radius-factor` como um valor decimal entre 0 e 1.
Por exemplo, defini-la como `0.5` aplicará um border-radius que equivale a 50% do valor máximo permitido para o componente.

```css
igx-chip {
    --ig-radius-factor: 0.5;
}
```
