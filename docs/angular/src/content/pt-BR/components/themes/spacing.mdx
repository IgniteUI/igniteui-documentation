# Espaçamento

A configuração do espaçamento pode melhorar significativamente a representação visual de grandes volumes de dados. No Ignite UI for Angular, oferecemos um conjunto predefinido de opções para ajustar os paddings e as margens.

Em vez de usar valores fixos, usamos propriedades personalizadas do CSS para ajustar o espaçamento no nível da aplicação ou do componente.

## Como o espaçamento funciona

O Ignite UI for Angular oferece um sofisticado sistema de espaçamento, que se ajusta dinamicamente de acordo com os tamanhos dos componentes (pequeno, médio, grande). O sistema de espaçamento é construído com base em propriedades personalizadas do CSS, que permitem controlar o espaçamento no nível global ou do componente, sem escrever CSS personalizado.

## A relação entre dimensionamento e espaçamento

O sistema de espaçamento do Ignite UI está intimamente ligado ao dimensionamento dos componentes. Os componentes podem ter três tamanhos diferentes:

- **Pequeno** - espaçamento compacto para layouts densos
- **Médio** - espaçamento equilibrado padrão.  
- **Grande** - espaçamento confortável para interfaces sensíveis ao toque

O espaçamento se adapta automaticamente de acordo com o tamanho ativo, garantindo uma hierarquia visual consistente em toda a aplicação.

## Propriedades personalizadas principais do CSS

O sistema de espaçamento gira em torno de várias propriedades personalizadas principais do CSS:

### Propriedades globais de espaçamento

- `--ig-spacing` - O multiplicador base de espaçamento (padrão: 1)
- `--ig-spacing-small` - Espaçamento para componentes de tamanho pequeno
- `--ig-spacing-medium` - Espaçamento para componentes de tamanho médio.  
- `--ig-spacing-large` - Espaçamento para componentes de tamanho grande

### Propriedades de espaçamento direcional

- `--ig-spacing-inline` - Controla o espaçamento horizontal
- `--ig-spacing-block` - Controla o espaçamento vertical
- `--ig-spacing-inline-small` - Espaçamento horizontal para componentes pequenos
- `--ig-spacing-inline-medium` - Espaçamento horizontal para componentes médios
- `--ig-spacing-inline-large` - Espaçamento horizontal para componentes grandes
- `--ig-spacing-block-small` - Espaçamento vertical para componentes pequenos
- `--ig-spacing-block-medium` - Espaçamento vertical para componentes médios
- `--ig-spacing-block-large` - Espaçamento vertical para componentes grandes

## Variáveis de detecção de tamanho

Os componentes usam propriedades personalizadas do CSS para detectar automaticamente o seu tamanho atual:

- `--is-small` - Definida como 1 quando o componente é de tamanho pequeno, e como 0 nos demais casos.
- `--is-medium` - Definida como 1 quando o componente é de tamanho médio, e como 0 nos demais casos  
- `--is-large` - Definida como 1 quando o componente é de tamanho large; caso contrário, 0.
- `--component-size` - Valor numérico que indica o tamanho atual (1=pequeno, 2=médio, 3=grande).

Essas variáveis são gerenciadas automaticamente pelo sistema de temas e mudam de acordo com a configuração de tamanho do componente, controlada por `--ig-size`.

## Exemplos práticos de uso

### Controle global do espaçamento

Para deixar todos os componentes mais compactos em toda a sua aplicação:

```css
:root {
  --ig-spacing: 0.8; /* 20% less spacing */
}
```

Para aumentar o espaçamento e melhorar a acessibilidade ao toque:

```css
:root {
  --ig-spacing: 1.2; /* 20% more spacing */
}
```

### Espaçamento específico de componente

Para ajustar o espaçamento de um tipo específico de componente:

```css
.my-grid {
  --ig-spacing: 0.5; /* More compact grid, 50% of the original spacing in all sizes */
}
```

### Controle de espaçamento direcional

Para reduzir apenas o espaçamento horizontal, mantendo o espaçamento vertical normal:

```css
:root {
  --ig-spacing-inline: 0.7;
  --ig-spacing-block: 1.0;
}
```

### Espaçamento específico por tamanho

Para personalizar o espaçamento de tamanhos específicos de componentes:

```css
:root {
  --ig-spacing-small: 0.5;   /* Very tight for small components */
  --ig-spacing-medium: 1.0;  /* Normal for medium components */
  --ig-spacing-large: 1.5;   /* Extra spacious for large components */
}
```

## Como funcionam os multiplicadores de espaçamento

O sistema de espaçamento usa multiplicadores para dimensionar os valores base:

- Os valores de espaçamento dos componentes são multiplicados pelas variáveis de espaçamento ativas
- Por exemplo, se um componente tem `8px` de padding base e você define `--ig-spacing: 1.5`, o padding real passa a ser `12px`
- Multiplicadores específicos de tamanho, como `--ig-spacing-large`, substituem o `--ig-spacing` global para componentes de tamanho grande
- Multiplicadores direcionais, como `--ig-spacing-inline`, permitem dimensionar o espaçamento horizontal e vertical de forma independente

Essa abordagem em cascata garante relações de espaçamento consistentes, oferecendo um controle refinado somente por meio de propriedades personalizadas do CSS.
