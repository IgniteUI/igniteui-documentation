# Estilos de impressão

<div class="highlight">
O mecanismo de temas do Ignite UI for Angular oferece alguns estilos padrão de impressão, que garantem que os nossos componentes tenham, no mínimo, a aparência básica no papel igual à que têm na página web.
</div>
<hr/>

## Como usar os estilos de impressão

Para garantir que os componentes fiquem totalmente visíveis no papel, é preciso que eles tenham o mesmo tamanho ou sejam menores que o documento de impressão; caso contrário, serão cortados.

Por `default`, os `printing styles` são incorporados ao `compiled CSS`.
Se você não planeja imprimir, recomendamos desativá-los para reduzir o tamanho do CSS gerado.

Você pode fazer isso no seu arquivo de tema `SCSS`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';

// Turn the print styles off by setting the $print-layout param to false.
@include core($print-layout: false)

// Add the theme and the palette.
@include theme($default-palette);
```

Desde a **v13.2**, decidimos não ocultar nenhum componente por padrão, pois não sabemos quais partes você quer que fiquem visíveis no papel; deixamos essa decisão para você.

Para remover uma parte ou um componente inteiro da página impressa, você pode adicionar a classe .igx-no-print ao elemento/componente que não deseja imprimir; ou, se não tiver acesso ao DOM, pode direcionar diretamente a tag ou a classe desse elemento e definir display: none.

Digamos que você não consiga acessar um botão no DOM para colocar `.igx-no-print` nele.
Mesmo assim, você pode ocultar esse botão da impressão usando SCSS.

```scss
@media print {
    [igxButton] {
        display: none;
    }
}
```

Aqui, @media print é usado para garantir que os estilos escritos dentro dele só tenham efeito durante a impressão.

Se você quiser imprimir em preto e branco, pode usar a classe `.igx-bw-print` em qualquer elemento; esse elemento e tudo o que há dentro dele ficarão em preto e branco quando impressos.

Para imprimir o [`igx-grid`](/grid/grid), recomendamos usar o recurso [`export to excel`](/grid/export-excel) ou fazer uma captura de tela do grid e imprimi-la.
