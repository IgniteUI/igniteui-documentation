# Paletas com Sass

As paletas Sass do Ignite UI for Angular são mapas de tons de cor que a função `palette()` gera a partir de cores base, e que o mixin `palette()` emite como variáveis CSS.

## Visão geral

Uma paleta do Ignite UI for Angular é um [mapa Sass](https://sass-lang.com/documentation/values/maps) indexado por família de cores: `primary`, `secondary`, `gray`, `surface`, `info`, `success`, `warn` e `error`. Cada família é um mapa dos seus tons, e cada tema de componente lê as suas cores desses tons por meio de variáveis CSS `--ig-*`.

A função `palette()` monta o mapa inteiro a partir de cores base. Com o gerador `fitted` padrão, cada família contém estas variantes:

| Família | Variantes |
|---|---|
| `primary`, `secondary`, `info`, `success`, `warn`, `error` | `50`–`900`, `A100`, `A200`, `A400`, `A700`, `seed` |
| `gray` | `50`–`900`, `seed` |
| `surface` | `base`, `sunken`, `raised`, `overlay`, `container`, `seed` |

Toda variante tem uma variante `-contrast` correspondente, como `500-contrast`: preta ou branca, definida pelo navegador para garantir contraste legível em relação a esse tom. A cor `primary` normalmente é a cor da sua marca e estiliza elementos estáticos de destaque, como o `igx-navbar`; `secondary` estiliza elementos interativos, como botões, switches e sliders; `surface` é o fundo de componentes como cards, menus e seletores.

Para entender como os tons são posicionados, e por que a família `surface` tem papéis em vez de números, veja [Geração de paletas](../palette-generation.mdx).

## Gerar uma paleta

Chame `palette()` com as três sementes obrigatórias, `$primary`, `$secondary` e `$surface`, e depois passe o resultado para o mixin `palette()` para emiti-lo como variáveis CSS:

```scss
@use "igniteui-angular/theming" as *;

$brand-palette: palette(
  $primary: #0099ff,
  $secondary: #df1b74,
  $surface: #ffffff
);

:root {
  @include palette($brand-palette);
}
```

As sementes opcionais são `$gray`, `$info` (`#1377d5`), `$success` (`#4eb862`), `$warn` (`#faa419`) e `$error` (`#ff134a`). O mixin `theme()` inclui o mixin `palette()` para você; por isso, inclua-o diretamente somente quando emitir uma paleta por conta própria, por exemplo para restringir uma segunda paleta a uma classe.

<DocsAside type="warning">
Toda semente que você passar para `palette()` **precisa ser uma cor Sass**. Variáveis CSS não podem ser passadas como argumentos, porque a paleta é calculada em tempo de build.
</DocsAside>

O mixin `palette()` também define o nível WCAG para o qual as cores `-contrast` são escolhidas. Passe `$contrast-level` com `'a'`, `'aa'` (padrão) ou `'aaa'`:

```scss
:root {
  @include palette($brand-palette, $contrast-level: 'aaa');
}
```

Com o gerador `fitted`, cada tom é emitido como uma cor fixa:

```css
:root {
  --ig-primary-100: rgb(172, 207, 251);
  --ig-primary-500: rgb(9, 109, 183);
  --ig-primary-600: rgb(6, 89, 150);
  --ig-primary-seed: #0099ff;
  --ig-surface-base: rgb(255, 255, 255);
  --ig-surface-sunken: rgb(247, 247, 247);
  /* ... */
}
```

Como os tons são fixos, substituir uma dessas variáveis no CSS altera apenas esse tom. Para mudar uma família, altere a sua semente e refaça o build.

## Escalas

Uma escala define até onde os tons de uma família alcançam e como eles são espaçados. Passe `$scales` para `palette()` para substituir os padrões: `even` para todas as famílias, `material` para `gray`.

Informe o nome de uma predefinição para uma família, ou passe uma predefinição para todas as famílias:

```scss
// The grays follow IBM Carbon's rhythm; every other family keeps its default
$brand-palette: palette(#0099ff, #df1b74, #ffffff, $scales: ('gray': 'carbon'));

// Every family uses the tailwind preset
$brand-palette: palette(#0099ff, #df1b74, #ffffff, $scales: 'tailwind');
```

As predefinições são `even`, `material`, `tailwind` e `carbon`. [Geração de paletas](../palette-generation.mdx#scale-shapes) as compara.

Descreva uma escala em linha com estas chaves:

| Tecla | Valor | Efeito |
|---|---|---|
| `range` | Duas razões de contraste, como `1.1 14` | O contraste do tom `50` e do tom `900`. O padrão é o intervalo `even`, `1.182 18.232`. |
| `curve` | Quatro números, como `0.5 0 0.8 0.8` | Redistribui os tons ao longo do intervalo, lido como uma `cubic-bezier()` de CSS. Omita-o para um espaçamento uniforme. |
| `anchor` | `'surface'` ou `'white'` | Com que o intervalo de `gray` é medido. O padrão é `'surface'`. As outras famílias são sempre medidas em relação ao branco. |

```scss
$brand-palette: palette(
  #0099ff,
  #df1b74,
  #121212,
  $scales: (
    'primary': (range: 1.1 14, curve: 0.5 0 0.8 0.8),
    'gray': (range: 1.1 14, anchor: 'white')
  )
);
```

Uma lista simples de quatro números é lida como uma curva sobre o intervalo `even`. Um intervalo ou uma curva personalizados mudam o contraste entre os tons: verifique os pares que você usa depois de alterar algum deles.

## Geradores

A função `palette()` tem dois geradores. `fitted`, o padrão, calcula cada tom para uma meta de contraste. `legacy` posiciona a semente em `500` e deriva os outros tons com multiplicadores HSL fixos, emitidos como cores relativas de CSS de `500`:

```css
:root {
  --ig-primary-500: #0099ff;
  --ig-primary-600: hsl(from var(--ig-primary-500) h calc(s * 1.26) calc(l * 0.89));
}
```

Mantenha o gerador `legacy` para uma paleta com `$generator`, ou para todas as chamadas de `palette()` no build, configurando `$shade-generator` antes que qualquer outra coisa carregue a biblioteca:

```scss
// One palette
$brand-palette: palette(#0099ff, #df1b74, #ffffff, $generator: 'legacy');
```

```scss
// Every palette() call in the build
@use "igniteui-theming" with ($shade-generator: 'legacy');
@use "igniteui-angular/theming" as *;
```

Uma paleta `legacy` ignora o argumento `$scales`.

## Paletas predefinidas

O Ignite UI for Angular oferece paletas claras e escuras predefinidas, que combinam com os esquemas correspondentes:

- Paletas claras
  - `$light-material-palette`
  - `$light-fluent-excel-palette`
  - `$light-fluent-word-palette`
  - `$light-fluent-palette`
  - `$light-bootstrap-palette`
  - `$light-indigo-palette`
- Paletas escuras
  - `$dark-material-palette`
  - `$dark-fluent-excel-palette`
  - `$dark-fluent-word-palette`
  - `$dark-fluent-palette`
  - `$dark-bootstrap-palette`
  - `$dark-indigo-palette`

Combine qualquer paleta clara com um esquema claro, e qualquer paleta escura com um esquema escuro. As paletas predefinidas são criadas com o gerador `legacy`; por isso, um tema criado a partir de uma delas mantém os seus tons de cores relativas e responde a substituições em tempo de execução das variantes `500`.

## Cores em escala de cinza

A família `gray` fornece a maioria das cores de texto, borda e de elementos desativados, e os seus tons são definidos em relação à superfície. Passe `$gray` para escolher a cor a partir da qual os cinzas são criados:

```scss
$brand-palette: palette(
  $primary: #2ab759,
  $secondary: #f96a88,
  $surface: #222222,
  $gray: #ffffff
);
```

Quando `$gray` é omitido, a semente do cinza é preta sobre uma superfície clara e branca sobre uma superfície escura. Com a escala `material` padrão, o tom `50` é o cinza mais próximo de uma superfície branca ou quase preta, e `900` é o mais distante dela. Veja [Cinzas e a página](../palette-generation.mdx#grays-and-the-page) para saber como a âncora da escala de cinza afeta temas escuros.

## Variantes de cor

A função `color()` retorna um tom da paleta. Ela recebe até quatro argumentos: `$palette`, `$color`, `$variant` e `$opacity`.

```scss
// A reference to the CSS variable: var(--ig-primary-500)
$primary-500: color();

// var(--ig-primary-600)
$primary-600: color($variant: 600);

// The primary 600 shade at 50% opacity, as a CSS relative color
$primary-600-translucent: color($variant: 600, $opacity: 0.5);

// The surface's raised role: var(--ig-surface-raised)
$raised: color($color: 'surface', $variant: 'raised');

// The resolved color of the secondary A700 shade in $brand-palette
$secondary-a700: color($brand-palette, 'secondary', 'A700');

.panel {
  background: $raised;
  border-color: $primary-600;
}
```

Sem `$palette`, `color()` retorna uma referência à variável CSS, de modo que o valor segue a paleta que for emitida em tempo de execução. Com `$palette`, retorna a cor resolvida desse mapa. `$color` tem como padrão `primary`, e `$variant` tem como padrão `500`, ou `base` quando `$color` é `surface`.

## Cores de texto de contraste

A função `contrast-color()` retorna a cor de contraste de um tom e recebe os mesmos argumentos de `color()`:

```scss
.callout {
  background: color($color: 'primary', $variant: 600);
  color: contrast-color($color: 'primary', $variant: 600);
}
```

O resultado é uma cor relativa de CSS que o navegador resolve como preta ou branca, no nível de contraste definido pelo mixin `palette()`.

## Classes de cor

O mixin `color-classes()` gera uma classe CSS para cada tom da paleta, atribuindo-a à propriedade CSS que você escolher:

- `$prop` - A propriedade CSS à qual a cor será atribuída.
- `$prefix` - Um prefixo para os nomes das classes geradas. O padrão é `'igx'`.
- `$suffix` - Um sufixo para os nomes das classes geradas.
- `$palette` - A paleta a ser usada.

```scss
@include color-classes(
  $prop: 'background-color',
  $prefix: 'bg'
);
```

O tom `500` de `primary` se torna a classe `.bg-primary-500`:

```html
<div class="bg-primary-500">...</div>
```

## Mapas de paleta personalizados

Os temas de componentes leem apenas a forma do mapa da paleta; por isso, um mapa escrito à mão funciona desde que tenha as chaves que os temas leem. Coloque entre aspas todas as chaves, incluindo as variantes numéricas, e atribua a `surface` os seus papéis:

```scss
$handmade-palette: (
  'primary': (
    '50': #e6eff8,
    '50-contrast': black,
    // ... '100' through '900', then 'A100', 'A200', 'A400', 'A700', each with a '-contrast' entry
    '500': #6797de,
    '500-contrast': white,
  ),
  // 'secondary', 'gray', 'info', 'success', 'warn', and 'error' follow the same pattern
  'surface': (
    'base': #ffffff,
    'base-contrast': black,
    'sunken': #f7f7f7,
    'sunken-contrast': black,
    'raised': #ffffff,
    'raised-contrast': black,
    'overlay': #ffffff,
    'overlay-contrast': black,
    'container': rgba(0, 0, 0, 0.03),
    'container-contrast': black,
  ),
);
```

Os temas de componentes do Ignite UI for Angular 22.3.0 leem os tons numerados das famílias de cores e de `gray`, os tons de destaque de `primary` e `secondary`, e o papel de superfície `base`. Os outros papéis de superfície existem para os seus próprios estilos. Inclua todas as variantes listadas em [Visão geral](#visão-geral), para que os estilos que leem as demais continuem sendo resolvidos.

## Solução de problemas

**Por que substituir `--ig-primary-500` não atualiza os outros tons primários?** Uma paleta gerada com o gerador `fitted` emite cores fixas. Altere a semente passada para `palette()` e refaça o build, ou gere a paleta com `$generator: 'legacy'` para manter a derivação em tempo de execução a partir de `500`.

**Como migro referências para `--ig-surface-500` ou `color($color: 'surface', $variant: 500)`?** Os tons de superfície numerados estão obsoletos em favor dos papéis. Todas as paletas ainda os emitem; por isso, as referências continuam funcionando enquanto você migra. Use `base` para o fundo da página ou do componente, `raised` ou `overlay` para as camadas acima dele, `sunken` para as camadas assentadas nele e `container` para um preenchimento translúcido. `color($color: 'surface')` já retorna `base`.

**Por que o build exibe `Shade "gray-900" wanted 18.232:1 but its hue only reaches …`?** A escala exige mais contraste do que a cor e a sua âncora permitem, normalmente uma escala de cinza ancorada na superfície sobre uma superfície escura. O gerador usou o tom mais próximo que conseguiu alcançar. Reduza o topo de `range` ou defina `anchor: 'white'`.
