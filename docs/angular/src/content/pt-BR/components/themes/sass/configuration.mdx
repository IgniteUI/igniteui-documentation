# Configuração

<div class="highlight">
A biblioteca de temas do Ignite UI for Angular expõe várias variáveis de argumentos de entrada que permitem configurar o funcionamento do mecanismo de temas.
</div>

## Variáveis globais

Veja a seguir uma lista de variáveis globais do Sass encaminhadas no módulo principal de temas:

|    Nome da variável  |                                                      Descrição        |
| :---------------: | :---------------------------------------------------------------------: |
|    `$components`  |       Armazena um registro de todos os temas de componentes. Usado para eliminação de código não utilizado (tree-shaking). |
| `$dropped-themes` |            Armazena um registro dos temas descartados. Usado para eliminação de código não utilizado (tree-shaking).  |

## Estilização de barras de rolagem

Os temas do Ignite UI for Angular vêm com estilos personalizados de barra de rolagem, que permitem alterar a largura e/ou as cores de todas as barras de rolagem da sua aplicação. Para aplicar os estilos incluídos, certifique-se de definir a classe `ig-scrollbar` em um elemento que contenha o componente raiz da sua aplicação.

Para personalizar ainda mais a barra de rolagem, você pode criar um novo estilo de barra de rolagem com a função <ApiLink kind="sass" module="themes" type="function-scrollbar-theme" label="scrollbar-theme" code={true} />. A função aceita argumentos para alterações de estilo na barra de rolagem. Podemos personalizar o tamanho, a cor, a borda, a altura mínima da barra de rolagem... e muito mais.

```scss
// app.component.scss
// Here we set the scrollbar to have size of 16px, scrollbar thumb to be in color pink, and scrolblar track to be in color green
$my-scrollbar-theme: scrollbar-theme($sb-size: 16px, $sb-thumb-bg-color: pink, $sb-track-bg-color: green);

// We use 'tokens' mixin for generating the css variables with the new scrollbar values.

:host {
  @include tokens($my-scrollbar-theme);
}
```
