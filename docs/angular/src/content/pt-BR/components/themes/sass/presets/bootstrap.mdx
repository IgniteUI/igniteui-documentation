# Mudando do tema Material para o Bootstrap

Desde a versão `9.0`, os nossos componentes incluem um novo tema inspirado no [Bootstrap 4](https://getbootstrap.com/) e no [ng-bootstrap](https://ng-bootstrap.github.io/#/home).
Para mudar de `Material` para `Bootstrap`, você pode usar o mixin integrado <ApiLink kind="sass" module="themes" type="mixin-theme" label="theme" />.

## Tema Bootstrap claro

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
@include core();
@include theme(
  $palette: $light-bootstrap-palette,
  $schema: $light-bootstrap-schema
);

// We can also include the Indigo font and font scaling
@include typography(
  $font-family: $bootstrap-typeface,
  $type-scale: $bootstrap-type-scale
);
```

## Tema Bootstrap escuro

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
@include core();
@include theme(
  $palette: $dark-bootstrap-palette,
  $schema: $dark-bootstrap-schema
);

@include typography(
  $font-family: $bootstrap-typeface,
  $type-scale: $bootstrap-type-scale
);
```
