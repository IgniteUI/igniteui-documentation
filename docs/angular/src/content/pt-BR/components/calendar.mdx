# Visão geral do componente Angular Calendar

O Angular Calendar é um componente de UI usado para exibir datas e dias em um aplicativo. Com diversos recursos, ele permite que os usuários gerenciem facilmente as funcionalidades do calendário, arrastem e criem eventos no calendário, naveguem até uma data desejada e mostrem eventos em uma visualização mensal, semanal ou diária do calendário Angular, com um único clique.

<div class="highlight">

O componente Calendar do Ignite UI for Angular, desenvolvido como um [componente Angular](https://angular.io/guide/architecture#components) nativo, oferece formas fáceis e intuitivas de exibir informações de data, habilitar datas ou aplicar o modo de datas desabilitadas do calendário Angular. Os usuários podem escolher entre três modos de seleção diferentes - seleção única, seleção múltipla ou seleção de intervalo.
</div>

## Primeiros passos com o Calendar do Ignite UI for Angular

Para começar com o componente Calendar do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](/general/getting-started).

O próximo passo é importar o `IgxCalendarModule` no arquivo **app.module.ts**.

<DocsAside type="info">
O <ApiLink type="Calendar" label="**IgxCalendarComponent**" /> também depende de [`BrowserAnimationsModule`](https://angular.io/api/platform-browser/animations/BrowserAnimationsModule), então ele também precisa ser adicionado ao AppModule:
</DocsAside>

```typescript
// app.module.ts
...
import { BrowserAnimationsModule } from '@angular/platform-browser/animations';
import { IgxCalendarModule } from 'igniteui-angular/calendar';
// import { IgxCalendarModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., BrowserAnimationsModule, IgxCalendarModule],
    ...
})
export class AppModule {}
```

Alternativamente, a partir de `16.0.0` você pode importar o <ApiLink type="Calendar" label="IgxCalendarComponent" /> como uma dependência independente, ou usar o token [`IGX_CALENDAR_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/calendar/src/calendar/public_api.ts) para importar o componente e todos os seus componentes e diretivas de apoio.

```typescript
// home.component.ts

import { BrowserAnimationsModule } from '@angular/platform-browser/animations';
import { IGX_CALENDAR_DIRECTIVES } from 'igniteui-angular/calendar';
// import { IGX_CALENDAR_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: '<igx-calendar></igx-calendar>',
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [BrowserAnimationsModule, IGX_CALENDAR_DIRECTIVES]
    /* or imports: [BrowserAnimationsModule, IgxCalendarComponent] */
})
export class HomeComponent {}
```

Agora que você importou o módulo ou as diretivas do Calendar do Ignite UI for Angular, pode começar a usar o componente `igx-calendar`.

<DocsAside type="info">
O <ApiLink type="Calendar" /> usa a [API Web Intl](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/DateTimeFormat) para a localização e a formatação de datas.
</DocsAside>
Considere usar [polyfills apropriados](https://github.com/andyearnshaw/Intl.js/) se a sua plataforma de destino não oferecer suporte a eles.

### Localização e formatação

Pela própria natureza, a localização e a formatação são essenciais em qualquer calendário. No <ApiLink type="Calendar" label="IgxCalendarComponent" />, elas são controladas e personalizadas pelas seguintes propriedades - <ApiLink type="Calendar" member="locale" label="locale" />, <ApiLink type="Calendar" member="formatoptions" label="formatOptions" />, <ApiLink type="Calendar" member="formatViews" label="formatViews" />, <ApiLink type="Calendar" member="weekStart" label="weekStart" />.

Vamos experimentar essas propriedades junto com outras personalizações da API do <ApiLink type="Calendar" label="IgxCalendarComponent" />. A primeira coisa que precisamos definir é <ApiLink type="Calendar" member="weekStart" label="weekStart" />, que controla o primeiro dia da semana. Ele tem como padrão 0, que corresponde ao domingo; então vamos definir o valor 1 para segunda-feira. No markup abaixo, também vinculamos as propriedades `formatOptions` e <ApiLink type="Calendar" member="formatViews" label="formatViews" /> para personalizar a formatação da exibição. Por fim, vinculamos a propriedade `locale` a um valor, com base na escolha de localização do usuário:

```html
{/* app.component.html */}
<igx-select #select [(ngModel)]="locale">
    <igx-select-item *ngFor="let locale of locales" [value]="locale">
        {{ locale }}
    </igx-select-item>
</igx-select>

<igx-calendar #calendar
    [weekStart]="1"
    [locale]="locale"
    [formatOptions]="formatOptions"
    [formatViews]="formatViews">
</igx-calendar>
```

Todos os valores de propriedades devem ser definidos no arquivo AppComponent:

```typescript
// app.component.ts
@ViewChild('calendar', { read: IgxCalendarComponent }) public calendar: IgxCalendarComponent;

public formatOptions: any;
public formatViews: any;
public locales = ['EN', 'DE', 'FR', 'AR', 'ZH'];
public locale = 'EN';

public ngOnInit() {
    this.formatOptions = { day: '2-digit', month: 'long', weekday: 'long', year: 'numeric' };
    this.formatViews = { day: true, month: true, year: true };
}
```

Se tudo correu bem, agora devemos ter um calendário com a exibição de datas personalizada, que também muda a representação do idioma de acordo com a localização do usuário. Vamos dar uma olhada:

### Como desabilitar datas no Calendar Angular

Esta seção demonstra o uso da funcionalidade <ApiLink type="Calendar" member="disabledDates" label="disabledDates" />. Para isso, diferentes datas únicas ou intervalos podem ser adicionados a um array e depois passados para o descritor <ApiLink type="Calendar" member="disabledDates" label="disabledDates" />.

O <ApiLink type="DateRangeType" kind="enum" /> é usado para especificar um intervalo que será desabilitado.

Vamos criar um exemplo que desabilita as datas entre o dia 3 e o dia 8 do mês atual:

```typescript
export class CalendarSample6Component {
    @ViewChild('calendar') public calendar: IgxCalendarComponent;
    public today = new Date(Date.now());
    public range = [
        new Date(this.today.getFullYear(), this.today.getMonth(), 3),
        new Date(this.today.getFullYear(), this.today.getMonth(), 8)
    ];

    public ngOnInit() {
        this.calendar.disabledDates = [{ type: DateRangeType.Between, dateRange: this.range }];
    }
}
```

### Datas especiais

O recurso <ApiLink type="Calendar" member="specialDates" label="specialDates" /> usa quase os mesmos princípios de configuração que o <ApiLink type="Calendar" member="disabledDates" label="disabledDates" />. O que os diferencia dos `disabled` é a possibilidade de selecionar e focar em <ApiLink type="Calendar" member="specialDates" label="specialDates" />.

Vamos adicionar algumas <ApiLink type="Calendar" member="specialDates" label="specialDates" /> ao nosso `igxCalendar`. Para isso, precisamos criar um item <ApiLink type="DateRangeDescriptor" kind="interface" /> do tipo <ApiLink kind="enum" type="DateRangeType" member="Specific" /> e passar um array de datas como <ApiLink kind="interface" type="DateRangeDescriptor" member="dateRange" />:

```typescript
export class CalendarSample7Component {
    @ViewChild('calendar', { static: true })
    public calendar: IgxCalendarComponent;
    @ViewChild('alert', { static: true })
    public dialog: IgxDialogComponent;
    public range = [];

    public selectPTOdays(dates: Date[]) {
        this.range = dates;
    }

    public submitPTOdays(eventArgs) {
        this.calendar.specialDates =
            [{ type: DateRangeType.Specific, dateRange: this.range }];

        this.range.forEach((item) => {
            this.calendar.selectDate(item);
        });

        ...
    }
}
```

```html
</igx-calendar>
<igx-dialog #alert title="Request Time Off"
    leftButtonLabel="OK"
    (leftButtonSelect)="alert.close()">
</igx-dialog>
<button igxButton="contained" (click)="submitPTOdays($event)">Submit Request</button>
```

### Templates

O `igx-calendar` oferece suporte a templates para o seu cabeçalho, o título do cabeçalho, o subcabeçalho e as células de dia. Para personalizar uma parte, marque um `ng-template` dentro do calendário com a diretiva dessa parte. O token `IGX_CALENDAR_DIRECTIVES` inclui todas as diretivas de template.

| Diretiva | Parte que substitui | Renderizado |
| :--- | :--- | :--- |
| `igxCalendarHeader` | A data no cabeçalho do calendário | Quando `selection` é `single` ou `range` e <ApiLink type="Calendar" member="hasHeader" label="hasHeader" /> é `true` |
| `igxCalendarHeaderTitle` | O título acima da data no cabeçalho do calendário | Quando `selection` é `single` ou `range` e <ApiLink type="Calendar" member="hasHeader" label="hasHeader" /> é `true` |
| `igxCalendarSubheader` | O subcabeçalho com o mês e o ano, entre os botões de navegação | Em todos os modos de seleção, nas visualizações de dias, meses e anos |
| `igxCalendarDay` | O conteúdo das células de dia | Em todos os modos de seleção, para cada dia visível. Veja [Template de dia](#template-de-dia) |

A demonstração a seguir usa os quatro templates para criar um calendário de eventos. O título do cabeçalho mostra o número de eventos da data selecionada, o subcabeçalho mostra o número de eventos do mês, e cada célula de dia mostra um ponto para cada evento:

<Sample src="/scheduling/calendar-templates" height={500} alt="Exemplo de templates do Angular Calendar" />

#### Templates de cabeçalho

Os templates `igxCalendarHeader` e `igxCalendarHeaderTitle` recebem a data exibida no cabeçalho: a primeira data selecionada ou a data atual, quando nada está selecionado. O template `igxCalendarSubheader` recebe a data de visualização do calendário, então ele acompanha a navegação entre meses e anos.

O template de subcabeçalho substitui o conteúdo padrão do subcabeçalho em todas as visualizações, incluindo os botões de mês e ano que alternam entre as visualizações. Use o <ApiLink type="Calendar" member="activeView" label="activeView" /> do calendário para renderizar conteúdo adequado à visualização atual e para alternar entre as visualizações. Na demonstração acima, o subcabeçalho mostra o botão de mês apenas na visualização de dias, e o botão de ano em todas as visualizações:

```html
<igx-calendar #calendar [value]="selectedDate" (selected)="onSelection($event)">
    {/* Header title: the number of events for the selected date */}
    <ng-template igxCalendarHeaderTitle let-parts>
        @let count = getEvents(parts.date).length;
        <span>{{ count ? pluralize(count) : 'No events' }}</span>
    </ng-template>

    {/* Header: the selected date, composed from the formatted date parts */}
    <ng-template igxCalendarHeader let-parts>
        <span>{{ parts.weekday.value }}, {{ parts.month.value }} {{ parts.day.value }}</span>
    </ng-template>

    {/* Subheader: month and year buttons that switch views, plus the month's event count */}
    <ng-template igxCalendarSubheader let-parts>
        @if (calendar.activeView === 'month') {
            <span
                class="igx-calendar-picker__date"
                tabindex="0"
                role="button"
                [attr.aria-label]="(parts.date | date: 'LLLL') + ', select month'"
                (click)="calendar.activeView = 'year'"
                (keydown.enter)="calendar.activeView = 'year'">
                {{ parts.month.value }}
            </span>
        }
        <span
            class="igx-calendar-picker__date"
            tabindex="0"
            role="button"
            [attr.aria-label]="(parts.date | date: 'yyyy') + ', select year'"
            (click)="calendar.activeView = 'decade'"
            (keydown.enter)="calendar.activeView = 'decade'">
            {{ parts.year.value }}
        </span>
        @if (calendar.activeView === 'month') {
            @let monthCount = getMonthEventsCount(parts.date);
            @if (monthCount) {
                <span class="month-badge">{{ pluralize(monthCount) }}</span>
            }
        }
    </ng-template>
</igx-calendar>
```

Os botões de mês e ano reutilizam a classe `igx-calendar-picker__date`, então mantêm a estilização padrão, e definem `tabindex`, `role` e `aria-label` para continuarem acessíveis pelo teclado.

Os templates de cabeçalho, de título do cabeçalho e de subcabeçalho recebem o seguinte contexto como `$implicit`:

| Nome | Tipo | Descrição |
| :--- | :--- | :--- |
| `date` | `Date` | A data do template: a data do cabeçalho para `igxCalendarHeader` e `igxCalendarHeaderTitle`, a data de visualização para `igxCalendarSubheader`. |
| `index` | `number` | O índice da visualização mensal à qual o subcabeçalho pertence quando <ApiLink type="Calendar" member="monthsViewNumber" label="monthsViewNumber" /> é maior que `1`. A data do subcabeçalho é deslocada por essa quantidade de meses. |
| `full` | `string` | A data completa, formatada com o `locale` e o `formatOptions` do calendário. |
| `era`, `year`, `month`, `day`, `weekday` | `object` | A parte da data, formatada com o `locale` e o `formatOptions` do calendário. |

Cada parte da data é um objeto com três strings: `value` é a parte localizada, `literal` é o separador que a segue, se houver, e `combined` é os dois juntos.

#### Template de dia

Para alterar o que as células de dia do `igx-calendar` mostram, por exemplo, para adicionar indicadores de eventos, disponibilidade ou preços, marque um `ng-template` dentro do calendário com a diretiva `igxCalendarDay`. Importe `IgxCalendarDayTemplateDirective` junto com o calendário, ou use o token `IGX_CALENDAR_DIRECTIVES`, que o inclui. Se a diretiva não for importada, o atributo `igxCalendarDay` é ignorado e o calendário renderiza o conteúdo padrão do dia.

```typescript
import { IgxCalendarComponent, IgxCalendarDayTemplateDirective } from 'igniteui-angular/calendar';
// import { IgxCalendarComponent, IgxCalendarDayTemplateDirective } from '@infragistics/igniteui-angular'; for licensed package

interface CalendarEvent {
    title: string;
    type: 'meeting' | 'deadline' | 'personal';
}

@Component({
    ...
    imports: [IgxCalendarComponent, IgxCalendarDayTemplateDirective]
})
export class AppComponent {
    // Events keyed by Date.toDateString()
    public events = new Map<string, CalendarEvent[]>();

    public getEvents(date: Date): CalendarEvent[] {
        return this.events.get(date.toDateString()) ?? [];
    }

    public pluralize(count: number): string {
        return `${count} ${count === 1 ? 'event' : 'events'}`;
    }
}
```

```html
<igx-calendar>
    {/* Day: the date with a dot for each event */}
    <ng-template igxCalendarDay let-date let-formattedDate="formattedDate" let-selected="selected">
        @let events = getEvents(date);
        <span class="day" [class.day--selected]="selected">
            <span>{{ formattedDate }}</span>
            <span class="day__dots">
                @for (event of events; track $index) {
                    <span class="day__dot day__dot--{{ event.type }}"></span>
                }
            </span>
            @if (events.length) {
                {/* Readable text for screen readers, announced as the cell description */}
                <span class="visually-hidden">{{ pluralize(events.length) }}</span>
            }
        </span>
    </ng-template>
</igx-calendar>
```

Você também pode passar o template pela entrada `dayTemplate`. Um template definido pela entrada tem precedência sobre um marcado com `igxCalendarDay`:

```html
<igx-calendar [dayTemplate]="dayTemplate"></igx-calendar>

<ng-template #dayTemplate let-date>{{ date.getDate() }}</ng-template>
```

O template substitui apenas o número do dia. A célula do dia mantém sua seleção, a navegação pelo teclado, os atributos ARIA e a estilização de estado (selecionado, intervalo, atual, especial, desabilitado), então selecionar um dia com template funciona como antes, e o tema ainda desenha o estado selecionado. O template não é renderizado para dias ocultos (veja <ApiLink type="Calendar" member="hideOutsideDays" label="hideOutsideDays" />), e é usado em todas as visualizações mensais quando <ApiLink type="Calendar" member="monthsViewNumber" label="monthsViewNumber" /> é maior que `1`.

O template recebe um `IgxCalendarDayTemplateContext` com as seguintes propriedades:

| Nome | Tipo | Descrição |
| :--- | :--- | :--- |
| `$implicit`, `date` | `Date` | A data da célula do dia. |
| `formattedDate` | `string` | O texto padrão da célula do dia, formatado com `formatOptions` e `formatViews`. |
| `selected` | `boolean` | Se o dia é renderizado como selecionado. |
| `disabled` | `boolean` | Se o dia está desabilitado por meio de `disabledDates`. |
| `special` | `boolean` | Se o dia está marcado como especial por meio de `specialDates`. |
| `today` | `boolean` | Se o dia é a data atual. |
| `weekend` | `boolean` | Se o dia é um dia de fim de semana. |
| `currentMonth` | `boolean` | Se o dia pertence ao mês exibido. |
| `active` | `boolean` | Se o dia é o dia ativo (com foco pelo teclado). |
| `firstInRange` | `boolean` | Se o dia é o primeiro dia do intervalo selecionado ou pré-visualizado. |
| `lastInRange` | `boolean` | Se o dia é o último dia do intervalo selecionado ou pré-visualizado. |
| `withinRange` | `boolean` | Se o dia está dentro do intervalo selecionado. Sempre `false`, a menos que `selection` seja `range`. |
| `withinPreviewRange` | `boolean` | Se o dia está dentro do intervalo pré-visualizado enquanto um intervalo está sendo selecionado. |

<DocsAside type="info">
Leitores de tela anunciam a célula do dia por meio do seu próprio `aria-label` e leem o texto que o template renderiza como descrição da célula. Renderize um texto legível, como "3 eventos", em vez de apenas símbolos. Não coloque elementos focáveis ou interativos no template, porque um clique em qualquer parte da célula seleciona a data. Use `currentColor` ou a propriedade de contexto `selected` para manter o conteúdo legível sobre o fundo selecionado.
</DocsAside>

## Eventos do calendário

Vamos explorar os eventos emitidos pelo calendário:

- <ApiLink type="Calendar" member="selected" label="selected" /> - emitido ao selecionar data(s) no calendário.
- <ApiLink type="Calendar" member="viewDateChanged" label="viewDateChanged" /> - emitido sempre que o mês/ano apresentado é alterado - por exemplo, ao navegar até o mês `next` ou `previous`.
- <ApiLink type="Calendar" member="activeViewChanged" label="activeViewChanged" /> - emitido depois que a visualização ativa é alterada - por exemplo, depois que o usuário clica na seção `month` ou `year` do cabeçalho.

```html
{/* app.component.html */}
<igx-calendar #calendar
    (selected)="onSelection($event)"
    (viewDateChanged)="viewDateChanged($event)"
    (activeViewChanged)="activeViewChanged($event)">
</igx-calendar>
```

O evento <ApiLink type="Calendar" member="selected" label="selected" /> é adequado para criar a lógica de validação de entrada. Use o código abaixo para alertar o usuário se a seleção ultrapassar 5 dias e, em seguida, redefinir a seleção:

```typescript
    if (dates.length > 5) {

}

}

public activeViewChanged(event: CalendarView) {
    // use CalendarView[event] to get the current active view (DEFAULT, YEAR or DECADE)
}
```

## Navegação pelo teclado

Se você percorrer a página usando a _tecla Tab_, lembre-se de que, de acordo com as [recomendações de acessibilidade do W3](https://www.w3.org/TR/wai-aria-practices/#layoutGrid), o <ApiLink type="Calendar" label="IgxCalendarComponent" /> agora introduz as seguintes paradas de tabulação:

- Botão do mês anterior
- Botão de seleção de mês
- Botão de seleção de ano
- Botão do próximo mês
- Data selecionada, data atual, primeira data focável (não desabilitada) na visualização de dias

Em um Angular Calendar que contém mais de uma data selecionada, apenas a primeira data será introduzida como parada de tabulação. Por exemplo, quando o Angular Calendar de seleção múltipla está habilitado e você selecionou as datas: _13/10/2020_, _17/10/2020_ e _21/10/2020_, apenas _13/10/2020_ será acessível durante a navegação por tabulação; no Seletor de intervalo do Angular Calendar, apenas a primeira data do intervalo selecionado fará parte da _sequência de tabulação da página_.

<DocsAside type="info">
Mudança de comportamento, a partir da _v10.2.0_ - A navegação por tecla Tab na _visualização de dias_ não está mais disponível. Para navegar entre as datas na _visualização de datas_, use as _teclas de seta_.
</DocsAside>

Quando o componente `igxCalendar` está com foco, use:

- a tecla <kbd>PageUp</kbd> para ir para o mês anterior,
- a tecla <kbd>PageDown</kbd> para ir para o próximo mês,
- as teclas <kbd>Shift</kbd> + <kbd>PageUp</kbd> para ir para o ano anterior,
- as teclas <kbd>Shift</kbd> + <kbd>PageDown</kbd> para ir para o próximo ano,
- a tecla <kbd>Home</kbd> para focar o primeiro dia do mês atual ou o primeiro mês exibido
- a tecla <kbd>End</kbd> para focar o último dia do mês atual ou o último mês exibido

Quando os botões de mês `prev` ou `next` (no subcabeçalho) estiverem com foco, use:

- a tecla <kbd>Space</kbd> ou <kbd>Enter</kbd> para rolar até o próximo ou o mês anterior.

Quando o botão `months` (no subcabeçalho) estiver com foco, use:

- a tecla <kbd>Space</kbd> ou <kbd>Enter</kbd> para abrir a visualização de meses.

Quando o botão `year` (no subcabeçalho) estiver com foco, use:

- a tecla <kbd>Space</kbd> ou <kbd>Enter</kbd> para abrir a visualização de décadas.

Quando um `day` dentro do mês atual estiver com foco:

- Use as _teclas de seta_ para navegar pelos dias. Observação: as datas desabilitadas serão ignoradas.
- O foco será mantido no mês atual exibido, enquanto a navegação ocorre **a partir** do **último dia** ou **primeiro dia** do mês, **até** ele.
- A navegação pelo teclado é contínua, o que significa que ela passa por todos os meses ao navegar com as setas.
- Use a tecla <kbd>Enter</kbd> para selecionar o dia com foco no momento.

Quando um `month` dentro da visualização de meses estiver com foco, use:

- as teclas de seta para navegar pelos meses.
- a tecla <kbd>Home</kbd> para focar o primeiro mês dentro da visualização de meses.
- a tecla <kbd>End</kbd> para focar o último mês dentro da visualização de meses.
- a tecla <kbd>Enter</kbd> para selecionar o mês com foco no momento e fechar a visualização.

Quando um `year` dentro da visualização de décadas estiver com foco, use:

- as teclas <kbd>Arrow up</kbd> e <kbd>Arrow down</kbd> para navegar pelos anos,
- a tecla <kbd>Enter</kbd> para selecionar o ano com foco no momento e fechar a visualização.

<DocsAside type="info">
A partir da versão 8.2.0, a navegação pelo teclado não foca dias que estão fora do mês atual, mas altera o mês exibido.
</DocsAside>

## Orientação do calendário

As configurações de orientação permitem que os usuários escolham como o cabeçalho e a visualização do calendário são exibidos.

### Opções de orientação do cabeçalho

Você pode alterar a orientação do cabeçalho para posicionar o cabeçalho do calendário horizontalmente (acima da visualização do calendário) ou verticalmente (ao lado da visualização do calendário).
Para isso, use a propriedade <ApiLink type="Calendar" member="headerOrientation" label="headerOrientation" />, definindo-a como `horizontal` ou `vertical`, respectivamente.

### Opções de orientação da visualização

Você pode definir a orientação da visualização para posicionar os meses do calendário horizontalmente (lado a lado) ou verticalmente (um acima do outro).
Para isso, use a propriedade <ApiLink type="Calendar" member="orientation" label="orientation" />, definindo-a como `horizontal` ou `vertical`, respectivamente.

<DocsAside type="info">
Você precisa de pelo menos um calendário com duas visualizações de mês para ver essa propriedade funcionando.
</DocsAside>

```html
<igx-calendar [monthsViewNumber]="2" [headerOrientation]="headerOrientation" [orientation]="orientation"></igx-calendar>
```

```scss
$custom-calendar-theme: calendar-theme(
```

### Estilizando com Tailwind

Você pode estilizar o `calendar` usando nossas classes utilitárias personalizadas do Tailwind. Certifique-se de [configurar o Tailwind](/themes/tailwind) primeiro.

Junto com a importação do tailwind na sua folha de estilos global, você pode aplicar os utilitários de tema desejados da seguinte forma:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

O arquivo de utilitários inclui as variantes de tema `light` e `dark`.

- Use as classes `light-*` para o tema claro.
- Use as classes `dark-*` para o tema escuro.
- Acrescente o nome do componente depois do prefixo, por exemplo, `light-calendar`, `dark-calendar`.

Depois de aplicadas, essas classes habilitam cálculos dinâmicos de tema. A partir daí, você pode substituir as variáveis CSS geradas usando `arbitrary properties`. Depois dos dois-pontos, informe qualquer formato de cor CSS válido (HEX, variável CSS, RGB etc.).

Você pode encontrar a lista completa de propriedades em <ApiLink kind="sass" module="themes" type="function-calendar-theme" label="calendar-theme" />. A sintaxe é a seguinte:

```html
<igx-calendar
class="!light-calendar
![--header-background:#4F6A5A]
![--content-background:#A3C7B2]"
[weekStart]="1">
</igx-calendar>
```

<DocsAside type="info">
O ponto de exclamação (`!`) é obrigatório para garantir que a classe utilitária tenha precedência. O Tailwind aplica estilos em camadas e, sem marcar esses estilos como importantes, eles serão sobrescritos pelo tema padrão do componente.
</DocsAside>
