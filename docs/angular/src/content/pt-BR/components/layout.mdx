# Visão geral das diretivas do Angular Layout Manager

<div class="highlight">
As diretivas de layout do Ignite UI for Angular permitem que os desenvolvedores especifiquem uma direção de layout para quaisquer filhos do contêiner ao qual são aplicadas. O layout pode fluir na vertical ou na horizontal, com controles para quebra, justificação e alinhamento.
</div>

## Uso

Use a diretiva <ApiLink type="LayoutDirective" label="**igxLayout**" /> em um elemento contêiner para especificar a direção do layout dos seus filhos:

<hr/>

### Na horizontal, com direção Row

Use <ApiLink type="LayoutDirective" member="dir" label="igxLayoutDir" />`="row"`.

<Sample src="/layouts/layout-direction-row" height={180} alt="" />

<hr/>

### Na vertical, com direção Column

Use <ApiLink type="LayoutDirective" member="dir" label="igxLayoutDir" />`="column"`.

<Sample src="/layouts/layout-direction-column" height={300} alt="" />

<hr/>

<DocsAside type="info">
Ordem inversa usando <ApiLink type="LayoutDirective" member="reverse" label="igxLayoutReverse" />`="true"`.
</DocsAside>

<hr/>

### Personalize a ordem dos elementos

Personalize a ordem do elemento usando `igxFlexOrder`.

<Sample src="/layouts/layout-custom-order" height={110} alt="" />

<hr/>

### Altere o espaçamento entre os elementos

Use <ApiLink type="LayoutDirective" member="justify" label="igxLayoutJustify" />`="space-between | space-around"`.

<Sample src="/layouts/layout-content-space" height={180} alt="" />

<hr/>

### Posicione os elementos ao longo do eixo principal

Use <ApiLink type="LayoutDirective" member="justify" label="igxLayoutJustify" />`="flex-start | center | flex-end"` para especificar a posição dos elementos ao longo do eixo principal, de acordo com as suas preferências.

<Sample src="/layouts/layout-justify-content" height={180} alt="" />

<hr/>

### Posicione os elementos ao longo do eixo transversal

Use <ApiLink type="LayoutDirective" member="itemalign" label="itemAlign" />`="flex-start | center | flex-end"` para especificar a posição dos elementos ao longo do eixo transversal, de acordo com as suas preferências.

<Sample src="/layouts/layout-align-items" height={400} alt="" />

<hr/>

### Você também pode fazer os elementos quebrarem de linha

Use <ApiLink type="LayoutDirective" member="wrap" label="igxLayoutWrap" />`="wrap"`.

<Sample src="/layouts/layout-wrap" height={180} alt="" />

<DocsAside type="info">
A diretiva <ApiLink type="LayoutDirective" label="igxLayout" /> afeta as direções de fluxo para os
</DocsAside>
filhos **imediatos** do contêiner.
<hr/>

## Aninhamento

Use a diretiva <ApiLink type="FlexDirective" label="igxFlex" /> para elementos dentro de um pai <ApiLink type="LayoutDirective" label="igxLayout" /> para controlar propriedades específicas do flexbox.
