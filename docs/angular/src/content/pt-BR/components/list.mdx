# Visão geral do componente Angular List View

O componente List do Ignite UI for Angular exibe linhas de itens e oferece suporte a um ou mais itens de cabeçalho, além de pesquisa e filtragem dos itens da lista. Cada item da lista é totalmente transformável em template e oferece suporte a qualquer HTML válido ou [componente Angular](https://www.infragistics.com/products/ignite-ui-angular). O componente de lista também oferece funcionalidade de rolagem integrada, templates para os estados vazio e de carregamento, e oferece suporte à virtualização para listas grandes, usando a diretiva [`IgxForOf`](/for-of).

## Exemplo de lista Angular

O exemplo a seguir representa uma lista preenchida com contatos, com as propriedades _nome_ e _número de telefone_. O componente <ApiLink type="List" /> usa [`igx-avatar`](layouts/avatar.mdx) e [`igx-icon`](/layouts/icon) para enriquecer a experiência do usuário e expor os recursos de definir uma foto de avatar e um ícone diferente para _favoritar um contato_. Além disso, a List View expõe recursos de ordenação obtidos usando o nosso pipe de filtragem.

## Primeiros passos com a Lista do Ignite UI for Angular

Para começar com o componente List View do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](/general/getting-started).

O próximo passo é importar o `IgxListModule` no arquivo **app.module.ts**.

```typescript
// app.module.ts

import { IgxListModule } from 'igniteui-angular/list';
// import { IgxListModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxListModule],
    ...
})
export class AppModule {}
```

Alternativamente, a partir de `16.0.0` você pode importar o `IgxListComponent` como uma dependência independente, ou usar o token [`IGX_LIST_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/list/src/list/public_api.ts) para importar o componente e todos os seus componentes e diretivas de apoio.

```typescript
// home.component.ts

import { IGX_LIST_DIRECTIVES } from 'igniteui-angular/list';
// import { IGX_LIST_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-list>
        <igx-list-item isHeader="true">Header</igx-list-item>
        <igx-list-item>Item 1</igx-list-item>
        <igx-list-item>Item 2</igx-list-item>
        <igx-list-item>Item 3</igx-list-item>
    </igx-list>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_LIST_DIRECTIVES]
    /* or imports: [IgxListComponent, IgxListItemComponent] */
})
export class HomeComponent {}
```


Agora que você importou o módulo ou as diretivas da Lista do Ignite UI for Angular, pode começar a usar o componente `igx-list`.

## Usando a lista Angular

Depois, no template do nosso componente de contatos, podemos criar a nossa lista; mas e se, no momento (ou em algum momento no futuro), não houver itens nela?
Nesse caso, a lista Angular oferece um template padrão, usado quando a lista está vazia.
Sempre podemos fornecer o nosso próprio template para a aparência da lista vazia, simplesmente usando a diretiva <ApiLink type="EmptyListTemplateDirective" />. Nesse caso, o template padrão não será usado:

```html
{/*contacts.component.html*/}

<igx-list>
    <ng-template igxEmptyList>
        <div class="empty">
No contacts! :(
</div>
    </ng-template>
</igx-list>
```

E o nosso estilo para o template vazio:

```css
/* contacts.component.css */

.empty {
    color: rgba(0, 153, 255, 1);
    font-size: 25px;
    font-weight: 600;
    text-shadow: 2px 1px 2px rgba(150, 150, 150, 1);
}
```

Se tudo correu bem, é assim que a nossa lista vazia deve ficar:

<DocsAside type="info">
Este componente usa Material Icons. Adicione o seguinte link ao seu `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

- `igxListThumbnail` deve ser usada se precisarmos adicionar algum tipo de mídia no início dos nossos itens da lista. A diretiva envolverá o elemento alvo, no nosso caso igx-avatar, em um contêiner que fornece posicionamento e espaçamento padrão.
- `igxListAction` deve ser usada para itens da lista que têm algum tipo de ação ou metadados, por exemplo, switch, radio-button, checkbox etc. No nosso caso, a ação será representada por um `igx-icon`. Novamente, a diretiva envolverá o elemento alvo em um contêiner que terá o posicionamento e o espaçamento corretos.
- `igxListLine` deve ser usada se precisarmos de algum texto entre `igxListThumbnail` e `igxListAction`; a diretiva vai garantir que a posição, o espaçamento e o alinhamento do texto fiquem ótimos junto com as outras duas diretivas ao redor.

Em seguida, escutamos um evento de clique no componente [**IgxIcon**](/layouts/icon) para alternar a propriedade _isFavorite_ no nosso objeto de contato.

```typescript
// contacts.component.ts

...
toggleFavorite(item: IgxListItem) {
    const contact = this.contacts[item.index - 1];
    contact.isFavorite = !contact.isFavorite;
}
```

```typescript
public size = 'large';
public sizes;

public ngOnInit() {
    this.sizes = [
        { label: 'large', selected: this.size === 'large', togglable: true },
        { label: 'medium', selected: this.size === 'medium', togglable: true },
        { label: 'small', selected: this.size === 'small', togglable: true }
    ];
}

public selectSize(event: any) {
    this.size = this.sizes[event.index].label;
}

@HostBinding('style.--ig-size')
protected get sizeStyle() {
    return `var(--ig-size-${this.size})`;
}
```

### Rolagem dos itens da lista

Agora que temos uma lista Angular tão bonita com contatos e seus números de telefone, por que não implementar a possibilidade de ligar para um contato?
O <ApiLink type="List" /> tem a solução perfeita para isso: a rolagem dos itens da lista.
Para fazer isso, você precisa implementar as seguintes etapas:

- Habilite a rolagem usando as propriedades <ApiLink type="List" member="allowLeftPanning" label="allowLeftPanning" /> e/ou <ApiLink type="List" member="allowRightPanning" label="allowRightPanning" />
- Defina os templates para a rolagem à esquerda e/ou à direita
- Trate os eventos de rolagem do item da lista e execute a ação desejada

O exemplo a seguir demonstra como tratar a rolagem tanto para a esquerda quanto para a direita. O manipulador de evento da rolagem para a direita mostra uma mensagem toast. O manipulador de evento da rolagem para a esquerda exclui um item da <ApiLink type="List" />.

<DocsAside type="info">
Observe que a remoção de itens da lista é uma tarefa da aplicação. O próprio <ApiLink type="List" /> não pode remover itens da fonte de dados, porque o <ApiLink type="List" /> não tem referência à fonte de dados.
</DocsAside>

Aqui está o código HTML do exemplo:

```html
{/* contacts.component.html */}

<igx-list [allowLeftPanning]="true" [allowRightPanning]="true"
  (leftPan)="leftPanPerformed($event)" (rightPan)="rightPanPerformed($event)">
  <ng-template igxListItemLeftPanning>
    <div class="listItemLeftPanningStyle">

      <igx-icon [color]="white" style="margin-left:10px">delete</igx-icon>Delete
    
</div>
  </ng-template>
  <ng-template igxListItemRightPanning>
    <div class="listItemRightPanningStyle">

      <igx-icon [color]="white" style="margin-right:10px">call</igx-icon>Dial
    
</div>
  </ng-template>
  <igx-list-item isHeader="true">Contacts</igx-list-item>
  <igx-list-item #item *ngFor="let contact of contacts">
    <igx-avatar igxListThumbnail [src]="contact.photo" shape="circle"></igx-avatar>
    <h4 igxListLineTitle>{{ contact.name }}</h4>
    <p igxListLineSubTitle class="phone">{{ contact.phone }}</p>
    <igx-icon igxListAction [color]="contact.isFavorite ? 'orange' : 'lightgray'" (click)="toggleFavorite(item)">star</igx-icon>
  </igx-list-item>
</igx-list>

<igx-toast #toast></igx-toast>
```

O exemplo acima usa alguns estilos CSS que podem ser encontrados aqui:


E, por fim, aqui está o código typescript que trata os eventos de rolagem:

```typescript
// contacts.component.ts

...
@ViewChild('toast')
public toast: IgxToastComponent;

public rightPanPerformed(args) {
  args.keepItem = true;
  this.toast.message = 'Dialing ' + this.contacts[args.item.index - 1].name;
  this.toast.open();
}

public leftPanPerformed(args) {
  args.keepItem = false;
  setTimeout((idx = args.item.index - 1) => {
    this.toast.message = 'Contact ' + this.contacts[idx].name + ' removed.';
    this.toast.open();
    this.contacts.splice(idx, 1);
  }, 500);
}

...
```

<DocsAside type="info">
Ao rolar os itens da lista, existe um limiar que precisa ser atingido para que os eventos de rolagem sejam emitidos. Você pode alterar o limiar usando a propriedade <ApiLink type="List" member="panEndTriggeringThreshold" label="panEndTriggeringThreshold" /> do <ApiLink type="List" />. Por padrão, essa propriedade tem o valor de 0,5, o que significa 50% da largura do item da lista.
</DocsAside>

## Lista filtrada do Angular

A nossa lista está ótima, mas não seria ainda melhor se pudéssemos pesquisar contatos pelo nome? Podemos fazer isso facilmente usando o nosso pipe de filtragem.
Vamos fazer isso.

Vamos primeiro adicionar um campo de entrada no topo do template do nosso componente Angular e vinculá-lo a uma propriedade do nosso componente chamada _searchContact_:

```html
{/*contacts.component.html*/}

<igx-input-group type="search" class="search">
    <igx-prefix>
        <igx-icon>search</igx-icon>
    </igx-prefix>
    <input #search igxInput placeholder="Search Contacts" [(ngModel)]="searchContact"/>
    @if (search.value.length > 0) {
        <igx-suffix (click)="searchContact = null">
            <igx-icon>clear</igx-icon>
        </igx-suffix>
    }
</igx-input-group>
```

É hora de importar o `IgxFilterModule` e o `IgxInputGroupModule` no nosso arquivo app.module.ts e <ApiLink type="FilterOptions" /> no nosso componente de contatos:

```typescript
// app.module.ts
...
import { IgxFilterModule } from 'igniteui-angular/directives';
import { IgxInputGroupModule } from 'igniteui-angular/input-group';
// import { IgxFilterModule, IgxInputGroupModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    imports: [..., IgxFilterModule, IgxInputGroupModule]
})

// contacts.component.ts
...
import { IgxFilterOptions } from 'igniteui-angular/directives';
// import { IgxFilterOptions } from '@infragistics/igniteui-angular'; for licensed package

@Component({...})
export class ContactListComponent {
    public searchContact: string;
    ...
    get filterContacts(): IgxFilterOptions {
        const fo = new IgxFilterOptions();
        fo.key = 'name';
        fo.inputValue = this.searchContact;
        return fo;
    }
}
```

Depois de importar o <ApiLink type="FilterOptions" />, precisamos registrar um novo método getter que vai retornar as opções de filtragem a serem usadas pelo pipe sempre que a propriedade `searchContact` for atualizada. Para que o filtro funcione, precisamos registrar um `key` pelo qual filtrar o objeto de contato. No nosso caso, seria o `name` de cada contato. A segunda propriedade que precisa ser registrada no objeto <ApiLink type="FilterOptions" /> é o valor com o qual devemos comparar ao comparar o nome do contato. Esta seria a propriedade `searchContact` que vinculamos ao campo de entrada acima da nossa lista de contatos.

Por fim, precisamos aplicar o pipe de filtragem aos dados de contatos antes de usá-los. Então, no nosso template, simplesmente adicionamos:

```html
{/*contacts.component.html*/}

<igx-list-item *ngFor="let contact of contacts | igxFilter: filterContacts; let i = index">
    ...
</igx-list-item>
```

## Seleção de itens da lista

Os itens da lista têm uma propriedade `selected` que nos ajuda a acompanhar quais itens estão "selecionados". Essa propriedade permite identificar e gerenciar o status de seleção de cada item.

Aqui está um exemplo que ilustra como o estilo visual dos itens muda ao usar a propriedade `selected`:

<Sample src="/lists/list-item-selection" height={420} alt="" />

Por padrão, a propriedade `selected` é definida como `false`. Podemos alternar o seu valor usando uma expressão inline vinculada ao evento `(click)` de cada item da lista, alternando efetivamente o estado visual do item a cada clique.

```html
<igx-list>
    <igx-list-item [isHeader]="true">Contacts</igx-list-item>
    @for (contact of contacts | igxFilter: filterContacts; track contact) {
      <igx-list-item [selected]="contact.selected" (click)="contact.selected = !contact.selected">
        <igx-avatar igxListThumbnail [src]="contact.photo" shape="circle"></igx-avatar>
        <span igxListLineTitle>{{ contact.name }}</span>
        <span igxListLineSubTitle>{{ contact.phone }}</span>
        <igx-icon igxListAction [style.color]="contact.isFavorite ? 'orange' : 'lightgray'" igxRipple="pink"
          [igxRippleCentered]="true" (click)="toggleFavorite(contact, $event)"
        (mousedown)="mousedown($event)">star</igx-icon>
      </igx-list-item>
    }
  </igx-list>
```

O item da lista também expõe algumas variáveis CSS que você pode usar para estilizar diferentes partes dos elementos selecionados:

- `--item-background-selected`
- `--item-text-color-selected`
- `--item-title-color-selected`
- `--item-action-color-selected`
- `--item-subtitle-color-selected`
- `--item-thumbnail-color-selected`

```scss
igx-list-item {
  --item-background-selected: var(--ig-secondary-500);
  --item-title-color-selected: var(--ig-secondary-500-contrast);
  --item-subtitle-color-selected: var(--ig-info-100);
}
```

Se preferir usar a função de temas da lista, há parâmetros disponíveis que permitem estilizar o estado selecionado dos itens da lista. Você pode encontrar mais informações sobre esses parâmetros aqui: <ApiLink kind="sass" module="themes" type="function-list-theme" label="list-theme" code={true} />

## Estilização

### Mapa de propriedades de tema da lista

Quando você modifica uma propriedade primária, todas as propriedades dependentes relacionadas são atualizadas automaticamente para refletir a mudança:

| Propriedade primária | Propriedade dependente | Descrição |

### Estilizando com Tailwind

Você pode estilizar a lista usando as nossas classes utilitárias personalizadas do Tailwind. Certifique-se de [configurar o Tailwind](/themes/tailwind) primeiro.

Junto com a importação do tailwind na sua folha de estilos global, você pode aplicar os utilitários de tema desejados da seguinte forma:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

O arquivo de utilitários inclui as variantes de tema `light` e `dark`.

- Use as classes `light-*` para o tema claro.
- Use as classes `dark-*` para o tema escuro.
- Acrescente o nome do componente depois do prefixo, por exemplo, `light-list`, `dark-list`.

Depois de aplicadas, essas classes habilitam cálculos dinâmicos de tema. A partir daí, você pode substituir as variáveis CSS geradas usando `arbitrary properties`. Depois dos dois-pontos, informe qualquer formato de cor CSS válido (HEX, variável CSS, RGB etc.).

Você pode encontrar a lista completa de propriedades em <ApiLink kind="sass" module="themes" type="function-list-theme" label="list-theme" />. A sintaxe é a seguinte:

```html
<igx-list class="!light-list ![--background:#81B698] ![--item-background:#A3C7B2]">
    ...
</igx-list>
```

<DocsAside type="info">
O ponto de exclamação (`!`) é obrigatório para garantir que a classe utilitária tenha precedência. O Tailwind aplica estilos em camadas e, sem marcar esses estilos como importantes, eles serão sobrescritos pelo tema padrão do componente.
</DocsAside>
