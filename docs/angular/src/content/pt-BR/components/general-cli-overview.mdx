# Ignite UI CLI para Angular

Nossas ferramentas de CLI oferecem templates de projeto pré-configurados para o conjunto de ferramentas do Ignite UI for Angular, que ajudam você a tirar sua próxima aplicação do papel em tempo recorde. O Ignite UI CLI é uma ferramenta de linha de comando independente para criar e fazer o scaffolding de aplicações para diversos frameworks diferentes, e oferece um ganho substancial de produtividade para os desenvolvedores.

## Primeiros passos

Para começar, instale o CLI:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
npm install -g igniteui-cli
</pre>

O comando de instalação acima disponibilizará o Ignite UI CLI para criar, fazer o scaffolding e executar a sua aplicação Ignite UI for Angular.

## Adicionando componentes

Depois de criar um projeto, você pode adicionar outros templates de componentes usando **ig add** a qualquer momento. Executar esse comando sem parâmetros vai guiar você pelos templates disponíveis, usando uma navegação por teclado no CLI para adicionar o controle de sua escolha.

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig add
</pre>

Como alternativa, você pode simplesmente executar o comando **ig list** para obter a lista completa de templates compatíveis no projeto atual que você criou.

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig list
</pre>

Depois de executar **ig list** e encontrar o template de componente que você quer adicionar, você pode fazê-lo rapidamente seguindo este template na sua linha de comando:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig add [component_template] [component_name]
</pre>

O "component\_template" acima geralmente corresponde a um componente do Ignite UI for Angular ("grid", "category-chart", "linear-gauge", etc.).

Por exemplo, se você quiser adicionar um componente de data grid com template chamado "MyGridComponent" à sua aplicação, pode executar o seguinte:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig add grid MyGridComponent
</pre>

## Compilar e executar a aplicação

Para compilar e executar a aplicação Ignite UI for Angular, você pode chamar os comandos **ig build** e **ig run**:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig build
ig run
</pre>
