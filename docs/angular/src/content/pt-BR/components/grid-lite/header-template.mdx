# Personalizando o cabeçalho da coluna

Assim como os templates de célula, os cabeçalhos das colunas também podem ser personalizados para se adequar melhor ao caso de uso desejado. Você pode passar um rótulo de texto pela propriedade `header` ou fornecer um template personalizado completo.

## Personalização pelo texto do cabeçalho

Por padrão, a coluna usa a propriedade `field` para o texto do rótulo. Para personalizar o rótulo, defina a propriedade `header` com um formato mais legível para as pessoas.

```html
<igx-grid-lite-column field="price" header="Price per item"></igx-grid-lite-column>
```

<DocsAside type="info">
Quando um template de cabeçalho é informado, `header` é ignorado.
</DocsAside>

## Personalização pelo template de cabeçalho

Assim como no template de célula, você também pode informar um renderizador de template personalizado e criar o seu próprio DOM dentro do cabeçalho da coluna.

```typescript
// Import the directive for it -> IgxGridLiteHeaderTemplateDirective
import { IgxGridLiteComponent, IgxGridLiteColumnComponent, IgxGridLiteCellTemplateDirective, IgxGridLiteHeaderTemplateDirective } from 'igniteui-angular/grids/lite';

// And add it to your imports array
 imports: [
    CommonModule,
    IgxGridLiteComponent,
    IgxGridLiteColumnComponent,
    IgxGridLiteCellTemplateDirective, // for templating cells
    IgxGridLiteHeaderTemplateDirective // for templating headers
],
```

```html
<igx-grid-lite-column field="rating" dataType="number">
    {/* igxGridLiteHeader directive for templating the header */}
    <ng-template igxGridLiteHeader let-value>
        <h3>⭐ Rating ⭐</h3>
    </ng-template>

    {/* igxGridLiteCell directive for templating the cell */}
    <ng-template igxGridLiteCell let-value>
        <igc-rating [value]="value" readonly step="0.01" min="0" max="5">
        </igc-rating>
    </ng-template>
</igx-grid-lite-column>
```
