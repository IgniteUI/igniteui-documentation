# Configuração de colunas

As colunas são definidas de forma declarativa, usando componentes filhos de coluna dentro da grade. A propriedade `field` é a única obrigatória para uma coluna, pois serve como identificador da coluna. Ela também é a propriedade usada para mapear e renderizar os dados relevantes nas linhas da grade.

```html
<igx-grid-lite [data]="data">
  <igx-grid-lite-column
    field="account"
    header="Account Number"
    ...
  ></igx-grid-lite-column>
  {/* Additional columns */}
</igx-grid-lite>
```

## Configuração com base na fonte de dados

A grade oferece suporte à inferência da configuração de colunas com base na fonte de dados fornecida, quando `autoGenerate` é definido como true. Ela tenta inferir as `field` e `dataType` adequadas com base nos registros dos dados.

```typescript
const data: Record[] = [
  { entryId: "1234", source: "https://example.com", ts: 1373521917579 },
  ...
];
```

```html
<igx-grid-lite [autoGenerate]="true" [data]="data"></igx-grid-lite>
```

O trecho anterior fará com que a grade crie automaticamente colunas equivalentes a:

```html
<igx-grid-lite [data]="data">
  <igx-grid-lite-column field="entryId" dataType="string"></igx-grid-lite-column>
  <igx-grid-lite-column field="source" dataType="string"></igx-grid-lite-column>
  <igx-grid-lite-column field="ts" dataType="number"></igx-grid-lite-column>
</igx-grid-lite>
```

Útil para uma renderização rápida de alguns dados sem nenhuma personalização adicional.

<DocsAside type="info">
Esta é uma operação única, executada quando a grade é inicialmente adicionada ao DOM. Passar uma fonte de dados vazia ou uma fonte de dados vinculada tardiamente (como uma requisição HTTP) normalmente resultará em uma configuração de colunas vazia para a grade. Esta propriedade é ignorada se já existir alguma configuração de colunas na grade. Veja [o tópico de vinculação de dados](/grid-lite/binding) para informações adicionais sobre a geração automática da configuração de colunas com base na fonte de dados.
</DocsAside>

## Configuração de colunas adicional

A coluna expõe várias outras propriedades para personalização:

### Largura da coluna

Por padrão, as colunas têm uma largura de `minmax(136px, 1fr)`, que se traduz em uma largura mínima de 136px e máxima de
1 parte do espaço disponível no Grid Lite. Assim, as colunas são fluidas e responsivas, acomodando as mudanças
na largura da grade.

Para alterar a largura de uma coluna, use a propriedade `width` da coluna.

```html
<igx-grid-lite-column field="price" width="250px"></igx-grid-lite-column>
```

A propriedade aceita <a href="https://developer.mozilla.org/en-US/docs/Learn/CSS/Building_blocks/Values_and_units#numbers_lengths_and_percentages" target="_blank">unidades de comprimento CSS válidas</a>.

### Ocultando colunas

As colunas podem ser ocultadas/exibidas definindo a propriedade `hidden` da coluna.

```html
<igx-grid-lite-column field="price" hidden></igx-grid-lite-column>
```

### Redimensionamento de coluna

Cada coluna do componente Grid Lite pode ser configurada para ser redimensionável, definindo a propriedade `resizable` do elemento da coluna.

```html
<igx-grid-lite-column field="price" resizable></igx-grid-lite-column>
```

Se uma coluna estiver configurada como redimensionável, você pode arrastar a borda direita do cabeçalho da coluna para aumentar ou diminuir a largura dela. Clicar duas vezes na área de redimensionamento dispara o dimensionamento automático da coluna, que tenta definir a largura de acordo com o maior conteúdo das suas células/cabeçalho.

<DocsAside type="info">
Colunas com larguras "fluidas" (fr, %, etc.) podem se comportar de forma irregular ao redimensionar a grade, pois tentam se acomodar às novas dimensões. Dependendo do cenário da aplicação, pode ser melhor usar unidades "fixas", para que os usuários não percebam deslocamentos de layout.
</DocsAside>
