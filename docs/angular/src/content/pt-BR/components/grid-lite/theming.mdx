# Estilos e temas

O Grid Lite vem com quatro temas distintos: Bootstrap, Material, Fluent e Indigo. A grade e os seus componentes de UI já têm os temas incorporados, mas o componente precisa de uma folha de estilos global para que paletas, tipografia e outras configurações globais funcionem.

## Carregando um tema base

Dependendo do tipo do seu projeto, da configuração e da configuração de build, o método para incluir um dos arquivos abaixo varia. Se você usa um framework/ferramenta de build, consulte a documentação dele para saber como adicionar estilos externos ao seu bundle de saída.

Como regra geral, você sempre pode copiar a pasta `themes` para o seu diretório de assets e vincular o tema a partir dele no seu index.html.

```html
<link rel="stylesheet" href="./assets/themes/light/bootstrap.css">
```

| Tema     | Variante | Caminho                                                           |
| :-------- | :------ | :------------------------------------------------------------- |
| Bootstrap | Claro   | node_modules/igniteui-webcomponents/themes/light/bootstrap.css |
| Bootstrap | Escuro    | node_modules/igniteui-webcomponents/themes/dark/bootstrap.css  |
| Material  | Claro   | node_modules/igniteui-webcomponents/themes/light/material.css  |
| Material  | Escuro    | node_modules/igniteui-webcomponents/themes/dark/material.css   |
| Fluent    | Claro   | node_modules/igniteui-webcomponents/themes/light/fluent.css    |
| Fluent    | Escuro    | node_modules/igniteui-webcomponents/themes/dark/fluent.css     |
| Indigo    | Claro   | node_modules/igniteui-webcomponents/themes/light/indigo.css    |
| Indigo    | Escuro    | node_modules/igniteui-webcomponents/themes/dark/indigo.css     |

## Criando temas personalizados

Além dos temas padrão distribuídos com o pacote `igniteui-grid-lite`, você também pode criar e modificar os seus próprios temas para combinar com a identidade e a marca do seu projeto.

---

Consulte o wiki do <a href="https://github.com/IgniteUI/igniteui-theming#readme" target="_blank">pacote de temas do Ignite UI</a>
para a documentação e o uso das interfaces SCSS e CSS.

---

```scss
@use 'node_modules/igniteui-theming' as *;

// Our dark theme
$my_dark_palette: palette(
  $primary: #dab785,
  $secondary: #d5896f,
  $surface: #031d44,
  $gray: #04395e,
);

// Our light theme
$my-light-palette: palette(
  $primary: #c1292e,
  $secondary: #f1d302,
  $surface: #fdfffc,
  $gray: #235789,
);

.custom-light {
  @include palette($my_light_palette);
  @include typography('"Roboto Condensed", sans-serif', $bootstrap-type-scale);
}

.custom-dark {
  @include palette($my_dark_palette);
  @include typography('"Merriweather Sans", sans-serif', $bootstrap-type-scale);
}
```
