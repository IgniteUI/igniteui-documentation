# Vinculação de dados do Angular Grid Lite

O Grid Lite aceita um array de objetos simples como fonte de dados. Cada linha da grade é a representação renderizada de um registro de dados do array, com as células da linha controladas pela configuração das colunas.

Ao aplicar transformações de dados, como ordenação e filtragem, a grade não modifica a referência original dos dados. Ou seja, as transformações de dados não serão refletidas na fonte original. A grade não acompanha as mudanças nos objetos dentro do array de dados; por isso, a modificação direta dos objetos de dados não será refletida.

## Alterar a fonte de dados em tempo de execução

O componente oferece suporte à mudança da sua fonte de dados em tempo de execução. Se a nova fonte tiver um "formato" diferente da anterior, certifique-se de atualizar também a configuração das colunas.

```typescript
grid.data = [...{
  /** records follow */
}];
```

```html
<igx-grid-lite>
    {/* Update column configuration, add or remove columns as needed to represent the new data. */}
    <igx-grid-lite-column field="id"></igx-grid-lite-column>
</igx-grid-lite>
```

Se a grade tiver `autoGenerate` habilitado, ela vai "_inferir_" automaticamente a nova configuração de colunas quando os dados mudarem.

```typescript
grid.autoGenerate = true;

/** After the new binding the grid will infer the column collection from the bound data. */
grid.data = [];
```

Ou basta definir as propriedades correspondentes no HTML, em vez de usar um `@ViewChild` para a grade.

```html
  <igx-grid-lite
    [autoGenerate]="true"
    [data]="data">
  </igx-grid-lite>
```


<DocsAside type="info">
Os estados de ordenação e filtragem do componente Grid Lite são mantidos ao alterar a fonte de dados dessa forma.
</DocsAside>
Normalmente você vai querer redefini-los chamando <ApiLink type="GridLite" member="clearSort" label="clearSort()" /> e/ou <ApiLink type="GridLite" member="clearFilter" label="clearFilter()" />.

a coleção de colunas é redefinida e uma nova fonte de dados é vinculada à grade.
