# Data grid do Angular gratuito e de código aberto (Grid Lite)

O Ignite UI for Angular Grid Lite é um data grid do Angular leve e de alto desempenho, gratuito, de código aberto e criado para aplicações Angular modernas.

Este data grid do Angular gratuito é um data grid JavaScript de código aberto, criado como um Web Component, o que significa que você pode usá-lo sem dependências, com ou sem um framework web. Ele oferece as funcionalidades essenciais de exibição de dados, com sobrecarga mínima e o desempenho que os usuários esperam. O Angular Grid Lite foi projetado para desenvolvedores que precisam de uma apresentação de dados rápida e leve.

## O que você ganha com o nosso data grid do Angular gratuito

O nosso Angular Grid Lite gratuito e de código aberto vem com os seguintes recursos baseados em colunas: ordenação, filtragem, ocultação, redimensionamento e uma variedade de tipos de dados predefinidos. Um desempenho extremamente rápido é obtido com o uso de virtualização de linhas. Além disso, o componente oferece suporte a navegação pelo teclado e a temas por meio do [Ignite UI Theming Framework](/themes).

O Angular <a href="https://custom-elements-everywhere.com/#angular" target="_blank">oferece suporte</a> a elementos personalizados, então você pode usar o Grid Lite com facilidade.

## Instalação e configuração
Para usar o Grid Lite na sua aplicação, você pode importá-lo diretamente de `igniteui-angular` por meio deste ponto de entrada `igniteui-angular/grids/lite`. Mas também é preciso instalar o pacote `igniteui-grid-lite`, que alimenta a UI. <ApiLink type="GridLite" /> oferece as vinculações do Angular (eventos, templates, DI, detecção de mudanças, pipes), enquanto a UI visual do grid lite é renderizada por `igniteui-grid-lite`. Instalar os dois garante que o grid lite se comporte nativamente no Angular, aproveitando toda a UI de `igniteui-grid-lite`.

```shell
npm install igniteui-grid-lite
```

Antes de iniciar a aplicação, certifique-se de importar e passar o schema de elementos personalizados, como mostrado abaixo.

```typescript
// app.component.ts

import { Component } from '@angular/core';
import { IgxGridLiteComponent, IgxGridLiteColumnComponent } from 'igniteui-angular/grids/lite';

@Component({
  ...
  imports: [IgxGridLiteComponent, IgxGridLiteColumnComponent],
  template: `
    <div>
      <igx-grid-lite [data]="products">
        <igx-grid-lite-column field="id" header="ID" dataType="number"></igx-grid-lite-column>
        <igx-grid-lite-column field="name" header="Name"></igx-grid-lite-column>
        {/* Additional columns */}
      </igx-grid-lite>
    
</div>
  `
})
export class AppComponent {
  products: Products[] = [...];
}
```

## Recursos

### Desempenho integrado

Ao usar o nosso data grid do Angular gratuitamente, você pode implementar a virtualização em nível de linha. Isso permite renderizar quantidades ilimitadas de dados com rolagem suave.

### Tipos de coluna automáticos

Os tipos de coluna são gerados automaticamente com base na sua fonte de dados, com filtragem integrada baseada no tipo da coluna.

### Templates de coluna personalizados

Com o nosso controle de código aberto de data grid do Angular, você também pode oferecer qualquer tipo de UX com templates de coluna. Tudo o que você imaginar pode ser renderizado em uma coluna da grade!

### Recursos interativos

Todos os principais recursos interativos que os seus usuários esperam, como filtragem, ocultação, redimensionamento e ordenação de colunas, e muito mais!

### UX bonita e identidade visual

Este data grid do Angular gratuito (Grid Lite) vem com suporte integrado aos temas Bootstrap, Material e Fluent, além de inúmeras opções de identidade visual em paletas de cores, fontes, elevação, densidade de exibição e muito mais.

### Navegação pelo teclado completa

A navegação completa pelo teclado no estilo Excel oferece ao usuário a experiência que ele espera, com navegação pelo teclado de alto desempenho.
