# Visão geral do componente Angular Bottom Navigation

<div class="highlight">
O componente Bottom Navigation do Ignite UI for Angular permite ao usuário navegar entre vários painéis de conteúdo exibidos em uma única visualização. A navegação pelos painéis é feita pelos botões de aba localizados na parte inferior da sua aplicação.
</div>

<DocsAside type="info">
O seletor `igx-tab-bar` está obsoleto. Você pode usar <ApiLink type="BottomNav" label="igx-bottom-nav" /> no lugar. A classe `IgxTabBarComponent` foi renomeada para <ApiLink type="BottomNav" />. `IgxTabBarModule` foi renomeado para `IgxBottomNavModule`.
</DocsAside>

## Primeiros passos com o Bottom Navigation do Ignite UI for Angular

Para começar com o componente Bottom Navigation do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](./general/getting-started.mdx).

O próximo passo é importar o `IgxBottomNavModule` no arquivo **app.module.ts**.

```typescript
// app.module.ts

...
import { IgxBottomNavModule } from 'igniteui-angular/bottom-nav';
// import { IgxBottomNavModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxBottomNavModule],
    ...
})
export class AppModule {}
```

Alternativamente, a partir de `16.0.0` você pode importar o `IgxBottomNavComponent` como uma dependência independente, ou usar o token [`IGX_BOTTOM_NAV_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/bottom-nav/src/bottom-nav/public_api.ts) para importar o componente e todos os seus componentes e diretivas de apoio.

```typescript
// home.component.ts

import { IGX_BOTTOM_NAV_DIRECTIVES } from 'igniteui-angular/bottom-nav';
import { IgxIconComponent } from 'igniteui-angular/icon';
// import { IGX_BOTTOM_NAV_DIRECTIVES, IgxIconComponent } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-bottom-nav>
        <igx-bottom-nav-item>
            <igx-bottom-nav-header>
                <igx-icon>library_music</igx-icon>
            </igx-bottom-nav-header>
            <igx-bottom-nav-content>This is Item 1 content.</igx-bottom-nav-content>
        </igx-bottom-nav-item>
        <igx-bottom-nav-item>
            <igx-bottom-nav-header>
                <igx-icon>video_library</igx-icon>
            </igx-bottom-nav-header>
            <igx-bottom-nav-content>This is Item 2 content.</igx-bottom-nav-content>
        </igx-bottom-nav-item>
        <igx-bottom-nav-item>
            <igx-bottom-nav-header>
                <igx-icon>library_books</igx-icon>
            </igx-bottom-nav-header>
            <igx-bottom-nav-content>This is Item 3 content.</igx-bottom-nav-content>
        </igx-bottom-nav-item>
    </igx-bottom-nav>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_BOTTOM_NAV_DIRECTIVES, IgxIconComponent]
    /* or imports: [IgxBottomNavComponent, IgxBottomNavItemComponent, IgxBottomNavHeaderComponent, IgxBottomNavContentComponent, IgxIconComponent] */
})
export class HomeComponent {}
```

Agora que você importou o módulo ou as diretivas do Bottom Navigation do Ignite UI for Angular, pode começar a usar o componente `igx-bottom-nav`.

## Usando o Angular Bottom Navigation

O template do nosso componente inclui o Bottom Navigation e três itens. Cada item envolve um `igx-bottom-nav-header` e um componente `igx-bottom-nav-content`, que representam, respectivamente, o cabeçalho e o contêiner dos dados. Os cabeçalhos normalmente consistem em um ícone e um rótulo de texto opcional. O controle Bottom Navigation é compatível com os [**ícones**](https://material.io/icons/) do Material Design; por isso, para adotá-los na sua aplicação, basta adicionar a importação Material+Icons no arquivo 'styles.css' na pasta principal da aplicação.

<DocsAside type="info">
Se você ainda não usou o `igx-icon` na sua aplicação, certifique-se de importar o `IgxIconModule` no **app.module.ts** antes de continuar.
</DocsAside>

```css
// styles.css

...
@import url('https://fonts.googleapis.com/icon?family=Material+Icons');
...
```

```html
<igx-bottom-nav>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon>library_music</igx-icon>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>This is Item 1 content.</igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon>video_library</igx-icon>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>This is Item 2 content.</igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon>library_books</igx-icon>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>This is Item 3 content.</igx-bottom-nav-content>
    </igx-bottom-nav-item>
</igx-bottom-nav>
```

Se tudo correu bem, você deve ver o exemplo da demonstração no seu navegador.

## Personalizando o Bottom Navigation

Vamos modificar as abas adicionando rótulos ao lado dos ícones e garantir que os cabeçalhos tenham a estilização adequada.

Primeiro, defina alguns arrays de objetos para a fonte de dados no arquivo TypeScript do componente:

```typescript
public songsList: object[] = [
    { title: 'Havana', artist: 'Camila Cabello' },
    { title: 'Meant To Be', artist: 'Bebe Rexha & Florida Georgia Line' },
    { title: 'New Rules', artist: 'Dua Lipa' },
    { title: 'Wolves', artist: 'Selena Gomez & Marshmello' }
];

public moviesList: object[] = [
    { title: 'Logan', genre: 'Action, Drama, Sci-Fi' },
    { title: 'Wonder Woman', genre: 'Action, Adventure, Fantasy' },
    { title: 'Guardians of the Galaxy Vol. 2', genre: 'Action, Adventure, Sci-Fi' },
    { title: 'Star Wars: The Last Jedi', genre: 'Action, Adventure, Fantasy' }
];

public booksList: object[] = [
    { title: 'Wonder', author: 'R. J. Palacio' },
    { title: 'Milk and Honey', author: 'Rupi Kaur' },
    { title: 'Giraffes Can\'t Dance', author: 'Jeff Kinne' },
    { title: 'The Getaway', author: 'Selena Gomez & Marshmello' }
];
```

Em seguida, atualize a marcação do template do componente da seguinte forma:

```html
<igx-bottom-nav>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon igxBottomNavHeaderIcon>library_music</igx-icon>
            <span igxBottomNavHeaderLabel>Songs</span>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>
            <div class="item" *ngFor="let song of songsList">
                <span class="item-line1">{{song.title}}</span><br/>
                <span class="item-line2">{{song.artist}}</span>
            
</div>
        </igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon igxBottomNavHeaderIcon>video_library</igx-icon>
            <span igxBottomNavHeaderLabel>Movies</span>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>
            <div class="item" *ngFor="let movie of moviesList">
                <span class="item-line1">{{movie.title}}</span><br/>
                <span class="item-line2">{{movie.genre}}</span>
            
</div>
        </igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon igxBottomNavHeaderIcon>library_books</igx-icon>
            <span igxBottomNavHeaderLabel>Books</span>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>
            <div class="item" *ngFor="let book of booksList">
                <span class="item-line1">{{book.title}}</span><br/>
                <span class="item-line2">{{book.author}}</span>
            
</div>
        </igx-bottom-nav-content>
    </igx-bottom-nav-item>
</igx-bottom-nav>
```

Você provavelmente notou que, além de colocar o ícone e o span com o rótulo entre as tags de cabeçalho do item, também anexamos a eles as diretivas `igxBottomNavHeaderIcon` e `igxBottomNavHeaderLabel`. Essas diretivas denotam os respectivos elementos e aplicam a eles os estilos adequados.

Por fim, adicione ao arquivo CSS do componente as classes CSS usadas pelos elementos DIV e SPAN do template do conteúdo:

```css
.item {
    margin-bottom: 5px;
}

.item-line1 {
    font-size: 14px;
    color: gray;
}

.item-line2 {
    font-size: 12px;
    color: darkgray;
}

igx-bottom-nav-content {
    padding: 10px;
}
```

## Integração com o contêiner Router Outlet

Embora o uso principal do componente Bottom Navigation seja definir itens de aba com conteúdo, pode haver casos em que você precise definir itens de aba somente com cabeçalhos. Provavelmente, o principal cenário para esse uso é a navegação entre visualizações usando o Angular Router. O exemplo a seguir demonstra como configurar o componente Bottom Navigation para alternar entre três componentes em um único router-outlet.

Para começar, precisamos de um componente principal que hospede o componente Bottom Navigation e três componentes de visualização com algum conteúdo para fins de demonstração. Para simplificar os trechos de código, os componentes de visualização terão um template bem curto, mas sinta-se à vontade para torná-los mais distintos, se precisar. Também importe esses componentes de visualização no seu arquivo `app.module.ts`.

```typescript
// bottomnav-routing.component.ts
import { Component } from '@angular/core';

@Component({
    selector: 'app-bottomnav-routing',
    styleUrls: ['bottomnav-routing.component.scss'],
    templateUrl: 'bottomnav-routing.component.html'
})
export class BottomNavRoutingComponent { }

@Component({
    template: '<p>Item 1 Content</p>'
})
export class BottomNavRoutingView1Component { }

@Component({
    template: '<p>Item 2 Content</p>'
})
export class BottomNavRoutingView2Component { }

@Component({
    template: '<p>Item 3 Content</p>'
})
export class BottomNavRoutingView3Component { }
```

A próxima etapa é criar os mapeamentos de navegação adequados no arquivo `app-routing.module.ts`:

```typescript
import { RouterModule, Routes } from '@angular/router';

import {
    TabbarRoutingComponent,
    TabbarRoutingView1Component,
    TabbarRoutingView2Component,
    TabbarRoutingView3Component,
} from './tabbar-routing.component';

const routes: Routes = [
    {
        path: '',
        pathMatch: 'full',
        redirectTo: '/tabbar-routing'
    },
    {
        path: 'tabbar-routing',
        component: TabbarRoutingComponent,
        children: [
            { path: 'tabbar-view1', component: TabbarView1Component },
            { path: 'tabbar-view2', component: TabbarView2Component },
            { path: 'tabbar-view3', component: TabbarView3Component }
        ]
    }
];

@NgModule({
    exports: [ RouterModule ],
    imports: [ RouterModule.forChild(routes) ]
})
export class TabbarRoutingModule { }
```

Agora que todas as rotas de navegação estão configuradas, precisamos declarar o componente BottomNavigation e configurá-lo para o roteamento.
Também certifique-se de adicionar um router-outlet para renderizar a saída dos componentes de visualização.

```html
{/* bottomnav-routing.component.html */}
<router-outlet></router-outlet>

<igx-bottom-nav #tabs1>
    <igx-bottom-nav-item
        routerLinkActive
        #rla1="routerLinkActive"
        [selected]="rla1.isActive"
        >
        <igx-bottom-nav-header routerLink="tabbar-view1">
            <igx-icon igxBottomNavHeaderIcon>phone</igx-icon>
        </igx-bottom-nav-header>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item
        routerLinkActive
        #rla2="routerLinkActive"
        [selected]="rla2.isActive"
    >
        <igx-bottom-nav-header routerLink="tabbar-view2">
            <igx-icon igxBottomNavHeaderIcon>supervisor_account</igx-icon>
        </igx-bottom-nav-header>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item
        routerLinkActive
        #rla3="routerLinkActive"
        [selected]="rla3.isActive"
    >
        <igx-bottom-nav-header routerLink="tabbar-view3">
            <igx-icon igxBottomNavHeaderIcon>format_list_bulleted</igx-icon>
        </igx-bottom-nav-header>
    </igx-bottom-nav-item>
</igx-bottom-nav>
```

O código acima cria um componente BottomNavigation com três itens de aba. Todos os itens de aba têm aplicada a diretiva `RouterLinkActive`, que acompanha se a rota vinculada está ativa no momento. Observe que a diretiva `RouterLink` é aplicada no próprio elemento de cabeçalho, e não no item de aba. Se algum desses links ficar ativo, o item de aba correspondente terá a sua propriedade `selected` definida, por causa da vinculação à propriedade `isActive` da diretiva `RouterLinkActive`. Dessa forma, a aba selecionada sempre permanecerá sincronizada com o endereço atual do navegador.

Para começar a estilizar as abas, precisamos importar o arquivo `index`, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Seguindo a abordagem mais simples, criamos um novo tema que estende o <ApiLink kind="sass" module="themes" type="function-bottom-nav-theme" label="bottom-nav-theme" code={true} /> e aceita vários parâmetros que nos permitem estilizar os grupos de abas.

```scss
$dark-bottom-nav: bottom-nav-theme(
  $background: #292826,
  $icon-selected-color: #f4d45c
);
```

<DocsAside type="info">
Em vez de definir os valores de cor diretamente, como acabamos de fazer, podemos obter mais flexibilidade em relação às cores usando as funções <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> e <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Consulte o tópico [`Palettes`](./themes/sass/palettes.mdx) para orientações detalhadas sobre como usá-las.
</DocsAside>

Se dermos uma olhada no <ApiLink kind="sass" module="themes" type="function-bottom-nav-theme" label="bottom-nav-theme" code={true} />, notaremos que há ainda mais parâmetros disponíveis para estilizar o componente bottom navigation!

<DocsAside type="info">
Para estilizar componentes adicionais usados como parte do conteúdo de um item, deve ser criado um tema adicional específico para cada componente.
</DocsAside>

O último passo é **incluir** o tema do componente no nosso aplicativo.

```scss
:host {
    @include tokens($dark-bottom-nav);
}
```

### Estilizando com Tailwind

Você pode estilizar o bottom navigation usando as nossas classes utilitárias personalizadas do Tailwind. Antes, certifique-se de [configurar o Tailwind](./themes/tailwind.mdx).

Junto com a importação do Tailwind na sua folha de estilos global, você pode aplicar os utilitários de tema desejados da seguinte forma:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

O arquivo de utilitários inclui as variantes de tema `light` e `dark`.

- Use as classes `light-*` para o tema claro.
- Use as classes `dark-*` para o tema escuro.
- Acrescente o nome do componente depois do prefixo, por exemplo, `light-bottom-nav`, `dark-bottom-nav`.

Depois de aplicadas, essas classes habilitam cálculos dinâmicos de tema. A partir daí, você pode substituir as variáveis CSS geradas usando `arbitrary properties`. Depois dos dois-pontos, informe qualquer formato de cor CSS válido (HEX, variável CSS, RGB etc.).

Você pode encontrar a lista completa de propriedades em <ApiLink kind="sass" module="themes" type="function-bottom-nav-theme" label="Tema do IgxBottomNav" />. A sintaxe é a seguinte:

```html
<igx-bottom-nav
    class="!light-bottom-nav
    ![--background:#011627]
    ![--icon-selected-color:#FF8040] 
    ![--label-selected-color:#FF8040]">
    ...
</igx-bottom-nav>
```

<DocsAside type="info">
O ponto de exclamação (`!`) é obrigatório para garantir que a classe utilitária tenha precedência. O Tailwind aplica estilos em camadas e, sem marcar esses estilos como importantes, eles serão sobrescritos pelo tema padrão do componente.
</DocsAside>
