## Parágrafo

Por padrão, o Markdown adiciona parágrafos em quebras de linha duplas.
Quebras de linha simples, por si só, são apenas unidas em uma única linha.
Se você quiser ter <a href="#">quebras</a> suaves que separem uma linha, adicione dois espaços no fim da linha.

Esta linha tem uma quebra de parágrafo no fim (linha vazia depois).

Estas duas linhas devem aparecer como uma única
linha, porque não há dois espaços no fim.

A linha a seguir tem uma quebra suave no fim (dois espaços no fim)
Esta linha deve aparecer logo na linha seguinte.
Esta linha tem uma quebra de parágrafo no fim (linha vazia depois).
