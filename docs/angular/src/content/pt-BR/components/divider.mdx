# Visão geral do componente Angular Divider

<div class="highlight">
O componente divider permite que os usuários separem o conteúdo tanto na horizontal quanto na vertical.
</div>

## Exemplo de Angular Divider

Por padrão, o divider é uma linha horizontal sólida.

## Primeiros passos com o Divider do Ignite UI for Angular

Para começar com o componente Divider do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](/general/getting-started).

O próximo passo é importar o `IgxDividerModule` no arquivo **app.module.ts**.

```typescript
// app.module.ts

...
import { IgxDividerModule } from 'igniteui-angular/directives';
// import { IgxDividerModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxDividerModule],
    ...
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` você pode importar o `IgxDividerComponent` como uma dependência independente.

```typescript
// home.component.ts

import { IgxDividerComponent } from 'igniteui-angular/directives';
// import { IgxDividerComponent } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: '<igx-divider></igx-divider>',
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxDividerComponent]
})
export class HomeComponent {}
```

Agora que você importou o módulo ou o componente do Divider do Ignite UI for Angular, pode começar a usar o componente `igx-divider`.

## Usando o Angular Divider

### Divider vertical

Adicionando o atributo <ApiLink type="Divider" member="vertical" label="vertical" /> e definindo o seu valor como `true`, você pode mudar a direção do divider de horizontal para vertical.

```html
<igx-divider [vertical]="true"></igx-divider>
```

<Sample src="/layouts/divider-sample-2" height={238} alt="" />

### Divider tracejado

O estilo padrão do divider é uma linha `solid`, mas ele também pode ser `dashed`.
Para alterar a aparência padrão, basta usar o atributo <ApiLink type="Divider" member="type" label="type" /> do divider e definir o seu valor como `dashed`.

```html
<igx-divider type="dashed"></igx-divider>
```

<Sample src="/layouts/divider-sample-3" height={187} alt="" />

### Divider recuado

O divider pode ser recuado nos dois lados.
Para recuar o divider, defina o atributo <ApiLink type="Divider" member="middle" label="middle" /> do divider como `true` e informe o valor desejado de <ApiLink type="Divider" member="inset" label="inset" />; o divider começará a encolher a partir das duas extremidades.

**Lembre-se de que você precisa adicionar a unidade (px, rem, %...) no fim do valor; caso contrário, não funcionará.**

```html
// Both side
<igx-divider [middle]="true" inset="80px"></igx-divider>

// Left side only 
<igx-divider inset="40px"></igx-divider>

```

<Sample src="/layouts/divider-sample-4" height={311} alt="" />

Se o valor do atributo <ApiLink type="Divider" member="middle" label="middle" /> for definido como um valor falso, ou se o atributo for omitido, o divider será recuado apenas à esquerda.
