# Visão geral da diretiva Angular Text Highlight

A <ApiLink type="TextHighlightDirective" /> e o `IgxTextHighlightService` do Ignite UI for Angular são usados para realçar partes de um texto, oferecendo opções de pesquisa sensível a maiúsculas e minúsculas e de realce apenas de correspondências exatas. Eles permitem que o desenvolvedor mantenha um realce ativo, que pode ser qualquer uma das partes já realçadas.

## Primeiros passos com a diretiva Text Highlight do Ignite UI for Angular

Para começar com a diretiva Text Highlight do Ignite UI for Angular, primeiro é preciso instalar o Ignite UI for Angular. Em um aplicativo Angular existente, digite o seguinte comando:

```cmd
ng add igniteui-angular
```

Para uma introdução completa ao Ignite UI for Angular, leia o tópico [_primeiros passos_](./general/getting-started.mdx).

O próximo passo é importar o `IgxTextHighlightModule` no arquivo **app.module.ts**.

```typescript
// app.module.ts
...
import { IgxTextHighlightModule } from 'igniteui-angular/directives';
// import { IgxTextHighlightModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [IgxTextHighlightModule],
    ...
})
export class AppModule {}
```

Como alternativa, a partir de `16.0.0` você pode importar o `IgxTextHighlightDirective` como uma dependência independente.

```typescript
// home.component.ts

import { IgxTextHighlightDirective, IgxTextHighlightService } from 'igniteui-angular/directives';
// import { IgxTextHighlightDirective, IgxTextHighlightService } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: `
    <div
      igxTextHighlight
      [value]="html"
      [groupName]="'group1'"
      [containerClass]="'search-text'"
      class="search-text"
    >
      {{ html }}
    
</div>
  `,
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IgxTextHighlightDirective],
})
export class HomeComponent {
  constructor(public textHighlightService: IgxTextHighlightService) {}
}
```

Agora que você importou o módulo ou a diretiva Text Highlight do Ignite UI for Angular, pode começar a usar a `igxTextHighlight`.

## Usando a diretiva Angular Text Highlight

Vamos criar uma caixa de pesquisa que podemos usar para realçar partes diferentes do texto. Usaremos o componente [InputGroup](./input-group.mdx) do Ignite UI for Angular, no qual adicionaremos uma entrada de texto com botões para limpar as correspondências, localizar a próxima, localizar a anterior e um botão para definir se a pesquisa diferencia ou não maiúsculas de minúsculas. Também há um rótulo que mostra quantas correspondências foram encontradas.

```html
<div class="search-container">

  <igx-input-group type="search" class="input-group">
    <igx-prefix>
      @if (searchText.length == 0) {
        <igx-icon>search</igx-icon>
      }
      @if (searchText.length > 0) {
        <igx-icon (click)="clearSearch()">clear</igx-icon>
      }
    </igx-prefix>

    <input
      #search1
      id="search1"
      igxInput
      placeholder="Search"
      autocomplete="off"
      [(ngModel)]="searchText"
      (ngModelChange)="onTextboxChange()"
      (keydown)="searchKeyDown($event)"/>
    <igx-suffix>
      <div class="caseSensitiveButton">

        <button
          igxIconButton="flat"
          igxRipple
          igxRippleCentered="true"
          (click)="updateSearch()"
          [style.background]="caseSensitive ? 'rgb(73, 180, 254)' : 'transparent'">
          <igx-icon class="caseSensitiveIcon" fontSet="material">text_fields</igx-icon>
        </button>
      
</div>
      @if (searchText.length > 0) {
        <span>
          @if (matchCount > 0) {
            {{ index + 1 }} of {{ matchCount }} results
          }
          @if (matchCount == 0) {
            No results
          }
        </span>
      }

      <div class="searchButtons">

        <button
          igxIconButton="flat"
          igxRipple
          igxRippleCentered="true"
          (click)="findPrev()"
          [disabled]="!canMoveHighlight">
          <igx-icon fontSet="material">navigate_before</igx-icon>
        </button>
        <button
          igIconButton="flat"
          igxRipple
          igxRippleCentered="true"
          (click)="findNext()"
          [disabled]="!canMoveHighlight">
          <igx-icon fontSet="material">navigate_next</igx-icon>
        </button>
      
</div>
    </igx-suffix>
  </igx-input-group>
</div>
```

<DocsAside type="info">
Este componente usa Material Icons. Adicione o seguinte link ao seu `index.html`: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

Em seguida, adicionaremos uma div com texto e a diretiva IgxTextHighlight. Observe que, como precisamos vincular o valor da entrada ao texto da div, também usaremos interpolação para o texto da div.

```html
<div
  igxTextHighlight
  [value]="html"
  [groupName]="'group1'"
  [containerClass]="'search-text'"
  class="search-text">
   {{html}}
</div>
```

No arquivo .ts do nosso componente, primeiro precisamos adicionar os seguintes campos, que são usados nas vinculações do template do componente:

```typescript
@Component({
    ...
})
export class HomeComponent {
    public html = '...';

    @ViewChild(IgxTextHighlightDirective, {read: IgxTextHighlightDirective})
    public highlight: IgxTextHighlightDirective;

    public searchText: string = '';
    public matchCount: number = 0;
    public caseSensitive: boolean = false;
    public index: number = 0;

    public get canMoveHighlight() {
        return this.matchCount > 1;
    }
}
```

Depois, precisamos adicionar os métodos a seguir, que permitirão ao usuário aplicar os realces para o texto digitado na caixa de pesquisa e mover o realce ativo.

```typescript
@Component({
    ...
})
export class HomeComponent {
    constructor(public textHighlightService: IgxTextHighlightService) {}

    public searchKeyDown(ev) {
        if (this.searchText) {
            if (ev.key === 'Enter' || ev.key === 'ArrowDown' || ev.key === 'ArrowRight') {
                ev.preventDefault();
                this.findNext();
            } else if (ev.key === 'ArrowUp' || ev.key === 'ArrowLeft') {
                ev.preventDefault();
                this.findPrev();
            }
        }
    }

    public onTextboxChange() {
        this.index = 0;
        this.find(0);
    }

    public updateSearch() {
        this.caseSensitive = !this.caseSensitive;
        this.find(0);
    }

    public clearSearch() {
        this.searchText = '';
        this.find(0);
    }

    private findNext() {
        this.find(1);
    }

    private findPrev() {
        this.find(-1);
    }

    private find(increment: number) {
        if (this.searchText) {
            this.matchCount = this.highlight.highlight(this.searchText, this.caseSensitive);
            this.index += increment;

            this.index = this.index < 0 ? this.matchCount - 1 : this.index;
            this.index = this.index > this.matchCount - 1 ? 0 : this.index;

            if (this.matchCount) {
                this.textHighlightService.setActiveHighlight('group1', {
                    columnIndex: 0,
                    index: this.index,
                    page: 0,
                    rowIndex: 0
                });
            }
        } else {
            this.highlight.clearHighlight();
        }
    }
}
```

## Pesquisa em vários elementos

A <ApiLink type="TextHighlightDirective" label="igxTextHighlight" /> permite pesquisar em vários elementos que compartilham um único realce ativo. Isso é feito tendo o mesmo valor de <ApiLink type="TextHighlightDirective" member="groupName" label="groupName" /> em várias diretivas TextHighlight. Para configurar o exemplo, reutilizaremos a caixa de pesquisa do exemplo anterior, mas desta vez adicionaremos dois elementos div. As entradas <ApiLink type="TextHighlightDirective" member="column" label="column" /> e <ApiLink type="TextHighlightDirective" member="row" label="row" /> são úteis quando há vários elementos, e, no nosso caso, a segunda div tem um valor de linha diferente.

```html
<div
  igxTextHighlight
  [groupName]="'group1'"
  [row]="0"
  [containerClass]="'search-text'"
  [value]="firstParagraph"
  class="search-text">
   {{firstParagraph}}
</div>
<div
  igxTextHighlight
  [groupName]="'group1'"
  [row]="1"
  [containerClass]="'search-text'"
  [value]="secondParagraph"
  class="search-text">
   {{secondParagraph}}
</div>
```

No arquivo .ts, temos os campos `firstParagraph` e `secondParagraph`, que são vinculados às respectivas entradas de valor das diretivas text highlight. Além disso, agora usaremos ViewChildren em vez de ViewChild para obter todos os realces no nosso template.

```typescript
public firstParagraph = "...";

public secondParagraph = "...";

@ViewChildren(IgxTextHighlightDirective)
public highlights;
```

Todo o restante do código do arquivo .ts é idêntico ao exemplo de elemento único, com exceção do método find. Alterações nesse método são necessárias, pois agora temos vários elementos, mas o código ali pode ser usado independentemente do número de diretivas TextHighlight na sua página.

```typescript
@Component({
    ...
})
export class HomeComponent {
    constructor(public textHighlightService: IgxTextHighlightService) {}

    private find(increment: number) {
        if (this.searchText) {
            let count = 0;
            const matchesArray = [];

            this.highlights.forEach((h) => {
                count += h.highlight(this.searchText, this.caseSensitive);
                matchesArray.push(count);
            });

            this.matchCount = count;

            this.index += increment;
            this.index = this.index < 0 ? this.matchCount - 1 : this.index;
            this.index = this.index > this.matchCount - 1 ? 0 : this.index;

            if (this.matchCount) {
                let row;

                for (let i = 0; i < matchesArray.length; i++) {
                    if (this.index < matchesArray[i]) {
                        row = i;
                        break;
                    }
                }

                const actualIndex = row === 0 ? this.index : this.index - matchesArray[row - 1];

                this.textHighlightService.setActiveHighlight('group1', {
                    index: actualIndex,
                    rowIndex: row
                });
            }
        } else {
            this.highlights.forEach((h) => {
                h.clearHighlight();
            });
            this.matchCount = 0;
        }
    }
}
```

## Estilos

A diretiva <ApiLink type="TextHighlightService" /> pode ser estilizada para alterar a cor e o fundo de todas as ocorrências da string informada. Para começar, precisamos importar o arquivo `index`, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Seguindo a abordagem mais simples, criamos um novo tema que estende o <ApiLink kind="sass" module="themes" type="function-highlight-theme" label="highlight-theme" code={true} /> e aceita os parâmetros `$resting-background`, `$resting-color`, `$active-background` e `$active-color`.

```scss
$dark-highlight: highlight-theme(
  $resting-background: #ffcd0f,
  $resting-color: #292826,
  $active-background: #292826,
  $active-color: #ffcd0f,
);
```

Os parâmetros `$resting-background` e `$resting-color` serão aplicados a todas as ocorrências realçadas, exceto à string realçada ativa, que será estilizada com base nos parâmetros `$active-background` e `$active-color`.

A última etapa é **incluir** o tema recém-criado.

```scss
:host {
  @include tokens($dark-highlight);
}
```

<DocsAside type="info">
As substituições de tokens normalmente são herdadas pelo Emulated View Encapsulation, mas os seletores gerados e os seletores CSS personalizados do próximo exemplo ainda podem exigir `::ng-deep` quando tiverem como alvo elementos de realce criados fora do template do próprio componente.
</DocsAside>

### Estilos personalizados

Digamos que queremos oferecer uma estilização ainda mais rica para as partes do texto realçadas. Para isso, podemos aproveitar as entradas <ApiLink type="TextHighlightDirective" member="cssclass" label="cssClass" /> e <ApiLink type="TextHighlightDirective" member="activecssclass" label="activeCssClass" /> da diretiva <ApiLink type="TextHighlightService" />. Podemos combinar essas classes com os estilos de <ApiLink kind="sass" module="themes" type="function-highlight-theme" label="highlight-theme" code={true} /> e oferecer uma experiência incrível aos nossos usuários!

Tudo o que precisamos fazer é criar algumas classes CSS com algumas propriedades e anexá-las usando as entradas mencionadas acima:

```html
<div
  igxTextHighlight
  [cssClass]="'custom-highlight'"
  [activeCssClass]="'custom-active-highlight'">
   {{html}}
</div>
```


```scss
// cssClass
.custom-highlight {
  border: 1px solid #ffcd0f;
}
// activeCssClass
.custom-active-highlight {
  box-shadow: 0 0 3px 0 rgba(0, 0, 0, 0.75);
}
```

Como mencionado antes, podemos inclusive combiná-las com um tema:

```scss
:host {
  ::ng-deep {
    @include tokens($dark-highlight);  
    
    .custom-highlight {
      border: 1px solid #ffcd0f;
    }  

    .custom-active-highlight {
      box-shadow: 0 0 3px 0 rgba(0,0,0, .5);
    }
  }
}
```
