# Visão geral do Angular Sparkline

O componente sparkline do Ignite UI for Angular é um controle de gráfico leve. Ele foi feito para ser renderizado em uma escala pequena, como dentro de uma célula de grid, mas também pode ser renderizado sozinho.

O controle sparkline tem vários elementos visuais e recursos correspondentes que podem ser configurados e personalizados, como o tipo de gráfico, marcadores, intervalos, linhas de tendência, plotagem de valores desconhecidos e tooltips.

## Tipos de sparkline

O componente sparkline do Ignite UI for Angular oferece suporte aos seguintes tipos de sparkline:

- [`Area`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#area)
- [`Column`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#column)
- [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line)
- [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss)

O tipo é definido pela propriedade [`displayType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#displaytype). Se a propriedade [`displayType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#displaytype) não for especificada, por padrão o tipo [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line) será exibido.

O tipo sparkline [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) é um gráfico de colunas, em que o valor de cada coluna é igual ao máximo positivo (para valores positivos) ou ao mínimo negativo (para valores negativos) do conjunto de dados vinculado, frequentemente indicando uma Vitória ou uma Derrota, ou conceitos opostos semelhantes. Para que o sparkline [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) seja exibido corretamente, o conjunto de dados deve ter valores positivos e negativos.

Se o sparkline [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) for vinculado aos mesmos dados dos outros tipos, como o tipo [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line), que pode ser vinculado a uma coleção de valores numéricos, o componente sparkline selecionará dois valores da coleção - o maior e o menor - e renderizará o sparkline com base nesses valores.

```html
<igx-sparkline height="200px" width="400px"
    [dataSource]="data"
    valueMemberPath="Value"
    displayType="Area" />
```

## Marcadores

O componente sparkline do Ignite UI for Angular permite mostrar marcadores como ícones circulares coloridos nas suas séries, para indicar os pontos de dados individuais com base em coordenadas X/Y. Os marcadores podem ser definidos em sparklines dos tipos de exibição [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line), [`Area`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#area) e [`Column`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#column). O tipo [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) de sparkline não aceita marcadores no momento. Por padrão, os marcadores não são exibidos.

Os marcadores no sparkline podem ser colocados em qualquer combinação dos seguintes locais:

- `All`: exibe marcadores para todos os pontos de dados do sparkline.
- `Low`: exibe marcadores no ponto de dados de menor valor. Se houver vários pontos com o menor valor, o marcador aparecerá em cada um deles.
- `High`: exibe marcadores no ponto de dados de maior valor. Se houver vários pontos com o maior valor, o marcador aparecerá em cada um deles.
- `First`: exibe um marcador no primeiro ponto de dados do sparkline.
- `Last`: exibe um marcador no último ponto de dados do sparkline.
- `Negative`: exibe marcadores nos pontos de dados negativos plotados no sparkline.

Todos os marcadores mencionados acima podem ser personalizados pela propriedade do respectivo tipo de marcador, em termos de cor, visibilidade e tamanho. Por exemplo, os marcadores `Low` acima terão as propriedades [`lowMarkerBrush`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#lowmarkerbrush), [`lowMarkerVisibility`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#lowmarkervisibility) e [`lowMarkerSize`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#lowmarkersize).

```html
<igx-sparkline
    highMarkerVisibility="Visible"
    lowMarkerVisibility="Visible"
    firstMarkerVisibility="Visible"
    lastMarkerVisibility="Visible"
    negativeMarkerVisibility="Visible"
    markerVisibility="Collapsed"
    markerSize="10"
    firstMarkerSize="10"
    lastMarkerSize="10"
    lowMarkerSize="10"
    highMarkerSize="10"
    negativeMarkerSize="10"/>
```

## Intervalo normal

O recurso de intervalo normal do componente sparkline do Ignite UI for Angular é uma faixa horizontal que representa algum intervalo predefinido e significativo durante a visualização dos dados. O intervalo normal pode ser definido como uma área sombreada delineada com a cor desejada.

O intervalo normal pode ser mais largo que o ponto de dados máximo ou ir além dele, e também pode ser tão fino quanto o tipo de exibição [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line) do sparkline, para servir como indicador de limite, por exemplo. A largura do intervalo normal é determinada pelas três propriedades a seguir, que são as configurações mínimas necessárias para exibir o intervalo normal:

- [`normalRangeVisibility`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangevisibility): se o intervalo normal está visível ou não.
- [`normalRangeMaximum`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangemaximum): a borda inferior do intervalo.
- [`normalRangeMinimum`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangeminimum): a borda superior do intervalo.

Por padrão, o intervalo normal não é exibido. Quando ativado, ele aparece com uma aparência de cinza claro, que também pode ser configurada pela propriedade [`normalRangeFill`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangefill).

Você também pode configurar se o intervalo normal deve ser exibido na frente ou atrás das séries plotadas no seu componente sparkline, definindo a propriedade [`displayNormalRangeInFront`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#displaynormalrangeinfront).

```html
<igx-sparkline
    normalRangeVisibility="Visible"
    normalRangeMinimum="1"
    normalRangeMaximum="4"
    normalRangeFill="rgba(88, 88, 88, 0.4)"
    displayNormalRangeInFront="true" />
```

## Linhas de tendência

O componente sparkline do Ignite UI for Angular oferece suporte a uma série de linhas de tendência, que são exibidas como outra camada sobre a camada do sparkline. Para exibir um sparkline, você pode usar a propriedade [`trendLineType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#trendlinetype).

As linhas de tendência são calculadas de acordo com o algoritmo especificado pela propriedade [`trendLineType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#trendlinetype), usando os valores dos dados aos quais o gráfico está vinculado.

As linhas de tendência só podem ser exibidas uma por vez, e, por padrão, a linha de tendência não é exibida.

A seguir, uma lista das linhas de tendência suportadas:

- [`None`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#none)
- [`CubicFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#cubicfit)
- [`CumulativeAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#cumulativeaverage)
- [`ExponentialAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#exponentialaverage)
- [`ExponentialFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#exponentialfit)
- [`LinearFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#linearfit)
- [`LogarithmicFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#logarithmicfit)
- [`ModifiedAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#modifiedaverage)
- [`PowerLawFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#powerlawfit)
- [`QuadraticFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#quadraticfit)
- [`QuarticFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#quarticfit)
- [`QuinticFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#quinticfit)
- [`SimpleAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#simpleaverage)
- [`WeightedAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#weightedaverage)

O exemplo de código a seguir mostra como ativar uma linha de tendência no componente sparkline do Ignite UI for Angular:

```html
<igx-sparkline
    trendLineThickness="3"
    trendLinePeriod="5"
    trendLineType="ExponentialFit"
    trendLineBrush="gray" />
```

## Interpolação de valores desconhecidos

O componente sparkline do Ignite UI for Angular consegue detectar valores desconhecidos e renderizar o espaço correspondente a eles por meio de um algoritmo de interpolação especificado. Se os seus dados contiverem valores nulos e você não usar esse recurso, ou seja, nenhuma interpolação for especificada, o valor desconhecido não será plotado.

Para plotar os valores desconhecidos, você pode definir a propriedade [`unknownValuePlotting`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#unknownvalueplotting) do componente sparkline.

```html
<igx-sparkline
    unknownValuePlotting="LinearInterpolate" />
```

## Sparkline em grid de dados

Você pode incorporar o componente sparkline do Ignite UI for Angular em uma coluna de template de um grid de dados ou em outros componentes que oferecem suporte a templates. O exemplo de código a seguir mostra como fazer isso:

```html
<igx-grid #grid1 [data]="data | async"
[height]="'500px'" width="100%" [autoGenerate]='false' >
    {/* ... */}
    <igx-column [field]="'OrderHistory'" [width]="'160px'" header="Order History" >
        <ng-template igxCell let-val>
            <igx-sparkline height="50px" width="150px"
            [dataSource]="val"
            valueMemberPath="Sold"
            displayType="Line"
            lineThickness="2"
            brush="rgb(21, 190, 6)"  >
            </igx-sparkline>
        </ng-template>
    </igx-column>
    {/* ... */}
</igx-grid>
```
