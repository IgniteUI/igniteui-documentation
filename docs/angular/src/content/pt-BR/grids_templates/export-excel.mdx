## Exportando os dados do {ComponentTitle}

Colocar os exportadores no seu projeto exige apenas algumas linhas de código. Siga estas etapas e você terá serviços reutilizáveis que podem criar saídas Excel ou PDF sob demanda:

1. Importe o <ApiLink type="ExcelExporterService" /> e/ou o <ApiLink type="PdfExporterService" /> no seu módulo raiz.
2. Injete o exportador de que você precisar e chame o seu método `export` quando o usuário solicitar um arquivo.

```typescript
// component.ts
import { IgxExcelExporterService, IgxPdfExporterService } from 'igniteui-angular/grids/core';
// import { IgxExcelExporterService, IgxPdfExporterService } from '@infragistics/igniteui-angular/grids/core'; for licensed package

...

private excelExportService = inject(IgxExcelExporterService);
private pdfExportService = inject(IgxPdfExporterService);

```

<DocsAside type="info">
Na v12.2.1 e versões posteriores, o `IgxExcelExporterService` é fornecido no root e não precisa ser registrado no array `providers`. O exportador PDF foi introduzido em versões posteriores e está disponível como serviço injetável, sem nenhuma configuração adicional.
</DocsAside>

Para iniciar um processo de exportação, você pode usar o manipulador de um botão no template do seu componente.

<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">

```html
<{ComponentSelector} #{ComponentObjectRef} [data]="localData" [autoGenerate]="true"></{ComponentSelector}>
<button (click)="exportButtonHandler()">Export {ComponentName} to Excel</button>
<button (click)="exportPdfButtonHandler()">Export {ComponentName} to PDF</button>
```

</ComponentBlock>

<ComponentBlock for="PivotGrid">

```html
<{ComponentSelector} #{ComponentObjectRef} [data]="localData" [pivotConfiguration]="pivotConfig"></{ComponentSelector}>
<button (click)="exportButtonHandler()">Export {ComponentName} to Excel</button>
<button (click)="exportPdfButtonHandler()">Export {ComponentName} to PDF</button>
```

</ComponentBlock>

Você pode acessar qualquer um dos serviços de exportação definindo-o como dependência do construtor, e deixando o Angular fornecer uma instância. Chamar o método compartilhado <ApiLink type="ExcelExporterService" member="export" label="export" /> inicia o download, respeitando automaticamente o estado do componente, as linhas selecionadas e as regras de formatação.

Aqui está o código que executará os dois processos de exportação no arquivo TypeScript do componente:

```typescript
// component.ts
import { IgxExcelExporterService, IgxExcelExporterOptions, IgxPdfExporterService, IgxPdfExporterOptions } from 'igniteui-angular/grids/core';
import { {ComponentName}Component } from 'igniteui-angular/grids/{ComponentMainTopic}';

@ViewChild('{ComponentObjectRef}') public {ComponentObjectRef}: {ComponentName}Component;

private excelExportService = inject(IgxExcelExporterService);
private pdfExportService = inject(IgxPdfExporterService);

public exportButtonHandler() {
  this.excelExportService.export(this.{ComponentObjectRef}, new IgxExcelExporterOptions('ExportedDataFile'));
}

public exportPdfButtonHandler() {
  this.pdfExportService.export(this.{ComponentObjectRef}, new IgxPdfExporterOptions('ExportedDataFile'));
}
```

Depois de configurado, ao pressionar os respectivos botões, são baixados arquivos com os nomes `ExportedDataFile.xlsx` ou `ExportedDataFile.pdf`, preenchidos com a visualização {ComponentTitle} atual. Você pode usar nomes de arquivo amigáveis para o cliente, acrescentar carimbos de data/hora ou exibir um toast de sucesso para que os usuários saibam que a exportação foi concluída.

<DocsAside type="info">
O {ComponentTitle} exportado não será formatado como tabela, pois as tabelas do Excel não oferecem suporte a várias linhas de cabeçalho.

## Exportar todos os dados

Conjuntos de dados grandes e remotos costumam ser carregados página a página ou sob demanda, o que significa que o {ComponentTitle} pode não ter todos os registros disponíveis quando o usuário clica em **Exportar**. Para garantir uma pasta de trabalho completa, preencha o exportador com a coleção de dados inteira antes de iniciar o processo. O auxiliar `exportData` contorna o componente e trabalha diretamente com objetos simples; assim, você pode reutilizar a mesma rotina para exportações agendadas ou downloads restritos a administradores.

```ts
public exportButtonHandler() {
  this.excelExportService.exportData(this.localData, new IgxExcelExporterOptions('ExportedDataFile'));
}
```

<DocsAside type="tip">
Ao oferecer downloads em PDF para dados remotos, considere primeiro buscar o conjunto de dados completo e depois chamar `export`, para que o documento corresponda às expectativas do usuário.
</DocsAside>

## Exportar dados agrupados

O agrupamento é uma forma popular de resumir segmentos de clientes, categorias de produtos ou períodos financeiros antes de compartilhar os resultados. O exportador preserva exatamente a hierarquia de agrupamento aplicada atualmente ao {ComponentTitle}, para que os destinatários vejam o mesmo detalhamento que você vê no navegador. Basta agrupar por uma ou mais colunas e disparar a exportação — nenhuma configuração extra é necessária.

Se você precisar de dados planos no arquivo exportado, remova o agrupamento antes de chamar `export` ou trate o evento `rowExporting` para reformatar a saída.

## Exportar grid com cabeçalhos de várias colunas

Painéis costumam depender de [cabeçalhos de várias colunas](/{igPath}/multi-column-headers) para adicionar contexto — pense em uma faixa "Q1/Q2/Q3" acima das colunas de cada mês. O exportador reproduz essa estrutura para que os usuários da planilha entendam imediatamente a lógica de agrupamento. Se o seu fluxo de trabalho preferir nomes de coluna simples, altere a flag <ApiLink kind="interface" type="IGridToolbarExportEventArgs" label="opção do exportador" /> <ApiLink type="ExcelExporterOptions" member="ignoremulticolumnheaders" label="ignoreMultiColumnHeaders" /> para `true`, e a saída incluirá apenas os cabeçalhos folha.

<DocsAside type="info">
O {ComponentTitle} exportado não será formatado como tabela, pois as tabelas do Excel não oferecem suporte a várias linhas de cabeçalho.
</DocsAside>

<DocsAside type="info">

</DocsAside>

## Exportar grid com cabeçalhos de colunas congelados

Planilhas longas podem ficar difíceis de ler quando a linha de cabeçalho sai da tela. Ativar cabeçalhos congelados mantém o contexto principal — como "Customer" ou "Invoice Total" — visível no topo da planilha enquanto os usuários exploram os dados mais abaixo. Defina a flag <ApiLink kind="interface" type="IGridToolbarExportEventArgs" label="opção do exportador" /> <ApiLink type="ExcelExporterOptions" member="freezeHeaders" label="freezeHeaders" /> como `true` antes de chamar `export`, e o serviço cuidará do restante.

```typescript
public exportButtonHandler() {
    const exporterOptions = new IgxExcelExporterOptions('ExportedDataFile');
    exporterOptions.freezeHeaders = true;
    this.excelExportService.export(this.grid, exporterOptions);
}
```

</ComponentBlock>

As exportações em PDF incluem automaticamente a linha de cabeçalho das colunas no topo do documento, para que os leitores mantenham o mesmo contexto ao abrir ou imprimir o arquivo.

## Personalizando o conteúdo exportado

A maioria das equipes personaliza as exportações antes de compartilhá-las: ocultando colunas de uso interno, renomeando cabeçalhos ou ignorando linhas que se aplicam apenas a administradores. Ambos os serviços exportadores expõem eventos que permitem interceptar cada linha ou coluna e decidir como ela deve aparecer no arquivo. Inscreva-se em <ApiLink type="ExcelExporterService" member="columnexporting" label="columnExporting" /> e <ApiLink type="ExcelExporterService" member="rowexporting" label="rowExporting" /> para fazer ajustes de última hora — defina `cancel = true` para omitir um item ou altere os argumentos do evento para atualizar valores na hora.

<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">

O exemplo a seguir exclui uma coluna da exportação se o seu cabeçalho for "Age" e o seu índice for 1:

```typescript
// component.ts

this.excelExportService.columnExporting.subscribe((args: IColumnExportingEventArgs) => {
  if (args.header == 'Age' && args.columnIndex == 1) {
      args.cancel = true;
  }
});
this.excelExportService.export(this.{ComponentObjectRef}, new IgxExcelExporterOptions('ExportedDataFile'));
```

</ComponentBlock>

<ComponentBlock for="PivotGrid">

O exemplo a seguir excluirá da exportação todas as colunas cujo cabeçalho seja "Amount of Sale":

```typescript
// component.ts

this.excelExportService.columnExporting.subscribe((args: IColumnExportingEventArgs) => {
    if (args.header == 'Amount of Sale') {
        args.cancel = true;
    }
});
this.excelExportService.export(this.{ComponentObjectRef}, new IgxExcelExporterOptions('ExportedDataFile'));
```

</ComponentBlock>

Ao exportar dados do componente {ComponentTitle}, os serviços respeitam automaticamente a ordenação, a filtragem, os resumos e as colunas ocultas, para que o arquivo reflita o que o usuário vê no momento. Precisa do conjunto de dados completo? Ative as flags relevantes em <ApiLink type="ExcelExporterOptions" /> ou <ApiLink type="PdfExporterOptions" /> para incluir linhas filtradas, colunas ocultas ou metadados personalizados.

## Limitações conhecidas

Antes de disponibilizar as exportações para usuários em produção, revise as restrições de plataforma a seguir, para que você possa definir expectativas e oferecer orientações úteis dentro da sua aplicação.

<ComponentBlock for="Grid">

|Limitação|Descrição|
|--- |--- |
|Tamanho máximo da planilha|O tamanho máximo de planilha suportado pelo Excel é 1.048.576 linhas por 16.384 colunas. Considere dividir exportações muito grandes por intervalo de datas ou segmento para permanecer dentro desses limites.|
|Estilização de células|O serviço exportador do Excel não oferece suporte à exportação de um estilo personalizado aplicado diretamente a um componente de célula. Nesses cenários, recomendamos usar a biblioteca [Excel Library](/excel-library), mais completa, para formatação detalhada.|
|Layouts de PDF largos|Grids muito largos podem fazer com que as colunas do PDF sejam reduzidas para caber na página. Aplique larguras de coluna ou oculte campos de menor prioridade antes de exportar, para manter o documento legível.|
