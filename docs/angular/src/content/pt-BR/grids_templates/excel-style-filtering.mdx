## Uso

Para ativar a filtragem estilo Excel do grid, duas entradas devem ser definidas. O <ApiLink type="{ComponentApiType}" member="allowFiltering" label="allowFiltering" /> deve ser definido como `true`, e o <ApiLink type="{ComponentApiType}" member="filterMode" label="filterMode" /> deve ser definido como `excelStyleFilter`.

<ComponentBlock for="Grid">

```html
<igx-grid [data]="data" [autoGenerate]="true" [allowFiltering]="true" [filterMode]="'excelStyleFilter'">
</igx-grid>
```

</ComponentBlock>

## Interações

Para abrir o menu de filtro de uma coluna específica, deve-se clicar no ícone de filtro do Angular no cabeçalho. Além disso, você pode usar a combinação `Ctrl + Shift + L` em um cabeçalho selecionado. Se a coluna puder ser ordenada, fixada, movida, selecionada ou ocultada junto com a funcionalidade de filtragem, haverá botões disponíveis para os recursos que estiverem ativados.

Se nenhum filtro for aplicado, todos os itens da lista ficarão selecionados. Eles podem ser filtrados pela entrada acima da lista. Para filtrar os dados, você pode selecionar/desselecionar os itens da lista e clicar no botão Apply, ou pressionar `Enter`. A filtragem aplicada pelos itens da lista cria expressões de filtro com o operador `equals`, e o operador lógico entre as expressões é <ApiLink kind="enum" type="FilteringLogic" member="Or" />.

Se você digitar algo na caixa de pesquisa e aplicar o filtro, somente os itens que correspondem ao critério de pesquisa serão selecionados. No entanto, se quiser adicionar itens aos já filtrados, deve selecionar a opção `Add current selection to filter`.

Se quiser limpar o filtro, você pode marcar a opção `Select All` e depois clicar no botão Apply.

Para aplicar um filtro com expressões diferentes, você pode clicar em **Text filter**, o que abre um submenu com todos os operadores de filtro disponíveis para a coluna. Ao selecionar um deles, abre-se a caixa de diálogo de filtro personalizado, onde você pode adicionar quantas expressões quiser, com operadores de filtro e lógicos diferentes. Há também um botão de limpar, que pode limpar o filtro.

## Templates

Se você quiser personalizar ainda mais o menu de filtro estilo Excel sem desabilitar os recursos das colunas, pode usar templates personalizados. O menu de filtro estilo Excel oferece duas diretivas para templates:

- `IgxExcelStyleColumnOperationsTemplateDirective` - redefine o template da área com todas as operações da coluna, como ordenação, fixação etc.
- `IgxExcelStyleFilterOperationsTemplateDirective` - redefine o template da área com todas as operações específicas de filtro.

Você pode redefinir o template de apenas uma dessas áreas ou de ambas. Pode colocar qualquer conteúdo personalizado dentro dessas diretivas, ou usar qualquer um dos nossos componentes integrados de filtragem estilo Excel.

## Saída externa

O {ComponentTitle} [`z-index`](https://developer.mozilla.org/en-US/docs/Web/CSS/z-index) cria um contexto de empilhamento separado para cada grid no DOM. Isso garante que todos os elementos descendentes do grid sejam renderizados como pretendido, sem se sobrepor uns aos outros.
No entanto, elementos que ficam fora do grid (por exemplo, o filtro estilo Excel) entrarão em conflito com elementos externos que tenham o mesmo `z-index` (por exemplo, dois grids um abaixo do outro), resultando em renderização incorreta. A solução para esse problema é definir a propriedade <ApiLink type="{ComponentApiType}" member="outlet" label="outlet" /> como uma diretiva de saída externa, que permite que os elementos de overlay sempre apareçam no topo.

## Estilização

Para começar a estilizar a caixa de diálogo de filtragem estilo Excel, precisamos importar o arquivo `index`, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Há algumas formas de estilizar a caixa de diálogo de filtragem estilo Excel. Ela pode ser estilizada usando o <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />. A caixa de diálogo de filtragem estilo Excel herda os valores `$background`, `$foreground` e `$accent-color` definidos no <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />. Ela também oferece parâmetros dedicados para personalizar as cores do texto da caixa de diálogo.

Alternativamente, você pode usar o <ApiLink kind="sass" module="themes" type="function-excel-filtering-theme" label="excel-filtering-theme" code={true} /> dedicado, que permite estilizar completamente apenas a caixa de diálogo de filtragem estilo Excel.

A abordagem mais simples é usar o <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />:

```scss
$background: #292826;
$foreground: #eeece1;
$accent: #ffcd0f;

$custom-grid: grid-theme(
  $background: $background,
  $foreground: $foreground,
  $accent-color: $accent,
);
```

As cores de fundo e de primeiro plano da caixa de diálogo de filtragem estilo Excel são herdadas do tema do grid. Além disso, todos os componentes aninhados, como botões e caixas de seleção, herdam a cor de destaque do tema do grid.

Depois disso, estamos prontos para incluir o tema do grid recém-criado. Se quisermos fazer alterações de estilo adicionais específicas da caixa de diálogo de filtragem estilo Excel, podemos direcioná-la diretamente:

```scss
:host {
    @include tokens($custom-grid);

    igx-grid-excel-style-filtering {
        --ig-excel-filtering-background: #444;
    }
}
```

<DocsAside type="info">
Esta demonstração usa `::ng-deep` porque tanto os seletores do tema gerado quanto o seletor direto da filtragem Excel precisam alcançar elementos dentro da visualização do grid. Mover as substituições para uma folha de estilos global é uma alternativa.
</DocsAside>

```scss
:host ::ng-deep {
    @include tokens($custom-grid);

    igx-grid-excel-style-filtering {
        --ig-excel-filtering-background: #444;
    }
}
```
