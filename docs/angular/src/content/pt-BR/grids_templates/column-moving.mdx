# Reordenação e movimentação de colunas do {ComponentTitle}

O componente {ComponentTitle} do Ignite UI for Angular oferece o recurso **Movimentação de colunas**, que permite reordenar colunas por gestos padrão de arrastar e soltar com o mouse ou por toque, ou usando a API de movimentação de colunas. A movimentação de colunas funciona tanto com colunas fixadas quanto não fixadas, e com Cabeçalhos de várias colunas. Mover uma coluna para a área fixada a fixa, e vice-versa; mover uma coluna para fora da área fixada a desfixa.

<DocsAside type="info">
A reordenação entre colunas e grupos de colunas só é permitida quando estão no mesmo nível da hierarquia e ambos estão no mesmo grupo. A movimentação é permitida entre colunas/grupos de colunas, se forem colunas de nível superior.
</DocsAside>

<DocsAside type="info">
Se o cabeçalho de uma coluna tiver template e a movimentação de colunas estiver habilitada, ou se a coluna correspondente for agrupável, os elementos com template precisam ter o atributo **draggable** definido como **false**! Isso permite anexar manipuladores a qualquer evento emitido pelo elemento; caso contrário, o evento é consumido pela diretiva `igxDrag`.
</DocsAside>

<DocsAside type="info">
Se a área fixada exceder a sua largura máxima permitida (80% da largura total do {ComponentTitle}), uma dica visual informará ao usuário final que a operação de soltar é proibida e que a fixação não é possível. Isso significa que você não poderá soltar uma coluna na área fixada.
</DocsAside>

```html
<ng-template igxHeader>
    <igx-icon [attr.draggable]="false" (click)="onClick()"></igx-icon>
</ng-template>
```

O recurso de **movimentação de colunas** é habilitado por grid, o que significa que o <ApiLink type="{ComponentApiType}" /> pode ter colunas movíveis ou imóveis. Isso é feito pela entrada <ApiLink type="Grid" member="moving" label="moving" /> do <ApiLink type="Grid" label="igx-grid" />.

## API

Além da funcionalidade de arrastar e soltar, o recurso de movimentação de colunas também oferece dois métodos de API para mover uma coluna/reordenar colunas programaticamente:

<ApiLink type="Grid" member="moveColumn" label="moveColumn" /> - Move uma coluna antes ou depois de outra coluna (um alvo). O primeiro parâmetro é a coluna a ser movida, e o segundo é a coluna alvo. Também aceita um terceiro parâmetro opcional `position` (representando um valor <ApiLink type="DropPosition" kind="enum" />), que determina se a coluna deve ser colocada antes ou depois da coluna alvo.

```typescript
// Move the ID column after the Name column
const idColumn = grid.getColumnByName("ID");
const nameColumn = grid.getColumnByName("Name");

grid.moveColumn(idColumn, nameColumn, DropPosition.AfterDropTarget);
```

<ApiLink type="Column" member="move" label="move" /> - Move uma coluna para um índice visível especificado. Se o parâmetro de índice passado for inválido (for negativo ou exceder o número de colunas), ou se a coluna não puder ser movida para esse índice (se estiver dentro de outro grupo), nenhuma operação será realizada.

```typescript
// Move the ID column at 3rd position.
const idColumn = grid.getColumnByName("ID");
idColumn.move(3);
```

Observe que, ao usar a API, somente o evento <ApiLink type="{ComponentApiType}" member="columnMovingEnd" label="columnMovingEnd" /> será emitido, se a operação for bem-sucedida. Observe também que, em comparação com a funcionalidade de arrastar e soltar, usar a API não exige definir a propriedade `moving` como true.

## Eventos

Há vários eventos relacionados à movimentação de colunas, que oferecem uma forma de acessar as operações de arrastar e soltar das colunas. São eles <ApiLink type="{ComponentApiType}" member="columnMovingStart" label="columnMovingStart" />, <ApiLink type="{ComponentApiType}" member="columnMoving" label="columnMoving" /> e <ApiLink type="{ComponentApiType}" member="columnMovingEnd" label="columnMovingEnd" />.
Você pode se inscrever no evento <ApiLink type="{ComponentApiType}" member="columnMovingEnd" label="columnMovingEnd" /> do <ApiLink type="{ComponentApiType}" /> para implementar alguma lógica personalizada quando uma coluna for solta em uma nova posição. Por exemplo, você pode cancelar a remoção da coluna Category depois da coluna Change On Year(%).

<ComponentBlock for="Grid">

```html
<igx-grid #dataGrid [data]="data" [autoGenerate]="false" [moving]="true" (columnMovingEnd)="onColumnMovingEnd($event)">
    <igx-column [field]="'Category'"></igx-column>
    <igx-column [field]="'Change On Year(%)'" [dataType]="'number'" ></igx-column>
</igx-grid>
```

```typescript
public onColumnMovingEnd(event) {
    if (event.source.field === "Category" && event.target.field === "Change On Year(%)") {
        event.cancel = true;
    }
}
```

</ComponentBlock>

<ComponentBlock for="TreeGrid">

```html
<igx-tree-grid #treeGrid [data]="data" primaryKey="ID" foreignKey="ParentID" [autoGenerate]="false" [moving]="true" (columnMovingEnd)="onColumnMovingEnd($event)">
    <igx-column [field]="'Name'" dataType="string" width="250px"></igx-column>
    <igx-column [field]="'Title'" dataType="string" width="250px"></igx-column>
</igx-tree-grid>
```

```typescript
public onColumnMovingEnd(event) {

```

</ComponentBlock>

## Estilização

Para começar a estilizar os cabeçalhos de movimentação de colunas do {ComponentTitle}, precisamos importar o arquivo `index`, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Usando a abordagem mais simples, criamos um novo tema que estende o <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> e aceita os parâmetros `$ghost-header-background`, `$ghost-header-text-color` e `$ghost-header-icon-color`.

```scss
// Define dark theme for the column moving
$dark-grid-column-moving-theme: grid-theme(
  $ghost-header-text-color: #f4d45c,
  $ghost-header-background: #575757,
  $ghost-header-icon-color: #f4bb5c
);
```

<DocsAside type="info">
Em vez de definir os valores de cor diretamente, como acabamos de fazer, podemos obter mais flexibilidade em relação às cores usando as funções <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> e <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Consulte o tópico [`Palettes`](/themes/sass/palettes) para orientações detalhadas sobre como usá-las.
</DocsAside>

A última etapa é aplicar o tema do componente com `tokens()`:

```scss
:host {
  @include tokens($dark-grid-column-moving-theme);
}
```
