# Persistência do estado do {ComponentTitle} do Angular

A diretiva igxGridState permite aos desenvolvedores salvar e restaurar facilmente o estado do grid. Quando a diretiva <ApiLink type="GridStateDirective" /> é aplicada no grid, ela expõe os métodos <ApiLink type="GridStateDirective" member="getState" label="getState" /> e <ApiLink type="GridStateDirective" member="setState" label="setState" />, que os desenvolvedores podem usar para obter a persistência do estado em qualquer cenário.

## Recursos suportados

## Uso

<ApiLink type="GridStateDirective" member="getState" label="getState" /> - Este método retorna o estado do grid em uma string JSON serializada, para que os desenvolvedores possam simplesmente pegá-la e salvá-la em qualquer armazenamento de dados (banco de dados, nuvem, localStorage do navegador etc.). O método aceita como primeiro parâmetro opcional `serialize`, que determina se <ApiLink type="GridStateDirective" member="getState" label="getState" /> retornará um objeto <ApiLink type="IGridState" kind="interface" /> ou uma string JSON serializada.
O desenvolvedor pode optar por obter apenas o estado de um ou mais recursos, passando o nome do recurso ou um array com os nomes dos recursos como segundo argumento.

```typescript
// get all features` state in a serialized JSON string
const gridState = state.getState();

// get an `IGridState` object, containing all features original state objects, as returned by the grid public API
const gridState: IGridState = state.getState(false);

// get the sorting and filtering expressions
const sortingFilteringStates: IGridState = state.getState(false, ['sorting', 'filtering']);
```

<ApiLink type="GridStateDirective" member="setState" label="setState" /> - O método <ApiLink type="GridStateDirective" member="setState" label="setState" /> aceita como argumento a string JSON serializada ou o objeto <ApiLink type="IGridState" kind="interface" /> e restaurará o estado de cada recurso encontrado no objeto/string JSON.

```typescript
state.setState(gridState);
state.setState(sortingFilteringStates)
```

`options` - O objeto <ApiLink type="GridStateDirective" member="options" label="options" /> implementa a interface <ApiLink type="IGridStateOptions" kind="interface" />, ou seja, para cada chave, que é o nome de um recurso, há um valor booleano indicando se o estado desse recurso será rastreado. O método <ApiLink type="GridStateDirective" member="getState" label="getState" /> não colocará o estado desses recursos no valor retornado, e o método <ApiLink type="GridStateDirective" member="setState" label="setState" /> não restaurará o estado deles.

```typescript
public options =  { cellSelection: false; sorting: false; }
```

A API simples de usar, de ponto único, permite obter uma persistência completa do estado com poucas linhas de código. **Copie e cole o código abaixo** — ele salvará o estado do grid no objeto `sessionStorage` do navegador sempre que o usuário sair da página atual. Sempre que o usuário voltar à página principal, o estado do grid será restaurado. Não é mais preciso configurar expressões avançadas de filtragem e ordenação toda vez para obter os dados desejados — faça isso uma vez e deixe o código abaixo fazer o resto para os seus usuários:

```typescript
// app.component.ts
@ViewChild(IgxGridStateDirective, { static: true })
public state!: IgxGridStateDirective;

public ngOnInit() {
    this.router.events.pipe(take(1)).subscribe((event: NavigationStart) => {
        this.saveGridState();
    });
}

public ngAfterViewInit() {
    this.restoreGridState();
}

public saveGridState() {
    const state = this.state.getState() as string;
    window.sessionStorage.setItem('grid1-state', state);
}

public restoreGridState() {
    const state = window.sessionStorage.getItem('grid1-state');
    this.state.setState(state);
}
```

## Restaurando colunas

Quando possível, a diretiva de estado reutilizará as colunas que já existem no grid ao restaurar o estado, em vez de criar novas instâncias de coluna. O único cenário em que uma nova instância será criada é quando a coluna (ou suas filhas, no caso de grupos de colunas) não tem a propriedade `field`, de modo que não há como identificar de forma única a coluna correspondente e reutilizá-la.

Para esses cenários, as seguintes [`limitations`](/{igPath}/state-persistence#limitações) são impostas. Nesse caso, restaurar objetos complexos pode ser feito com código no nível da aplicação. Vamos mostrar como fazer isso para colunas com template:

1. Defina uma variável de referência de template (no exemplo abaixo, é `#activeTemplate`) e atribua um manipulador de evento para o evento <ApiLink type="Grid" member="columnInit" label="columnInit" />:
<ComponentBlock for="Grid">

```html
<igx-grid id="grid" #grid igxGridState (columnInit)="onColumnInit($event)">
    <igx-column [field]="'IsActive'" header="IsActive">
        <ng-template igxCell #activeTemplate let-column let-val="val">
            <igx-checkbox [checked]="val"></igx-checkbox>
        </ng-template>
    </igx-column>
    ...
</igx-grid>
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```html
<igx-hierarchical-grid id="grid" #grid igxGridState (columnInit)="onColumnInit($event)">
    <igx-column [field]="'IsActive'" header="IsActive">
        <ng-template igxCell #activeTemplate let-column let-val="val">
            <igx-checkbox [checked]="val"></igx-checkbox>
        </ng-template>
    </igx-column>
    ...
</igx-hierarchical-grid>
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```html
<igx-tree-grid id="grid" #grid igxGridState (columnInit)="onColumnInit($event)">
    <igx-column [field]="'IsActive'" header="IsActive">
        <ng-template igxCell #activeTemplate let-column let-val="val">
            <igx-checkbox [checked]="val"></igx-checkbox>
        </ng-template>
    </igx-column>
    ...
</igx-tree-grid>
```

</ComponentBlock>
2. Consulte a view do template no componente usando o decorador @ViewChild ou @ViewChildren. No manipulador do evento <ApiLink type="Grid" member="columnInit" label="columnInit" />, atribua o template à propriedade `bodyTemplate` da coluna:

```typescript
@ViewChild('activeTemplate', { static: true }) public activeTemplate: TemplateRef<any>;
public onColumnInit(column: IgxColumnComponent) {
    if (column.field === 'IsActive') {
        column.bodyTemplate = this.activeTemplate;
        column.summaries = MySummary;
        column.filters = IgxNumberFilteringOperand.instance();
    }
}
```

## Restaurando a configuração do Pivot

O <ApiLink type="GridStateDirective" /> não persiste, por padrão, funções de dimensão do pivot, formatadores de valor etc. (veja [`limitations`](/{igPath}/state-persistence#limitações)). Restaurar qualquer um deles pode ser feito com código no nível da aplicação. O `IgxPivotGrid` expõe dois eventos que podem ser usados para reatribuir quaisquer funções personalizadas que você tenha na configuração: <ApiLink type="{ComponentApiType}" member="dimensionInit" label="dimensionInit" /> e <ApiLink type="{ComponentApiType}" member="valueInit" label="valueInit" />. Vamos mostrar como fazer isso:

- Atribua manipuladores de evento para os eventos `dimensionInit` e `valueInit`:

```html
<igx-pivot-grid #grid1 [data]="data" [pivotConfiguration]="pivotConfig" [igxGridState]="options"
    (valueInit)='onValueInit($event)' (dimensionInit)='onDimensionInit($event)'>
</igx-pivot-grid>
```

> Os eventos <ApiLink type="{ComponentApiType}" member="dimensionInit" label="dimensionInit" /> e <ApiLink type="{ComponentApiType}" member="valueInit" label="valueInit" /> são emitidos para cada valor e dimensão definidos na propriedade <ApiLink type="PivotGrid" member="pivotConfiguration" label="pivotConfiguration" />.

- No manipulador do evento `valueInit`, defina todos os agregadores, formatadores e estilos personalizados:

```typescript
public onValueInit(value: IPivotValue) {
    // Needed only for custom aggregators, formatter or styles.
    if (value.member === 'AmountofSale') {
        value.aggregate.aggregator = IgxTotalSaleAggregate.totalSale;
        value.aggregateList?.forEach((aggr: IPivotAggregator) => {
            switch (aggr.key) {
                case 'SUM':
                    aggr.aggregator = IgxTotalSaleAggregate.totalSale;
                    break;
                case 'MIN':
                    aggr.aggregator = IgxTotalSaleAggregate.totalMin;
                    break;
                case 'MAX':
                    aggr.aggregator = IgxTotalSaleAggregate.totalMax;
                    break;
            }
        });
    } else if (value.member === 'Value') {
        value.formatter = (value) => value ? '$' + parseFloat(value).toFixed(3) : undefined;
        value.styles.upFontValue = (rowData: any, columnKey: any): boolean => parseFloat(rowData.aggregationValues.get(columnKey.field)) > 150
        value.styles.downFontValue = (rowData: any, columnKey: any): boolean => parseFloat(rowData.aggregationValues.get(columnKey.field)) <= 150;
    }
}
```

- No manipulador do evento `dimensionInit`, defina todas as implementações personalizadas de `memberFunction`:

```typescript
public onDimensionInit(dim: IPivotDimension) {
    switch (dim.memberName) {
        case 'AllProducts':
            dim.memberFunction = () => 'All Products';
            break;
        case 'ProductCategory':
            dim.memberFunction = (data) => data.Product.Name;
            break;
        case 'City':
            dim.memberFunction = (data) => data.Seller.City;
            break;
        case 'SellerName':
            dim.memberFunction = (data) => data.Seller.Name;
            break;
    }
}
```

## Restaurando grids filhos

O salvamento/restauração do estado dos grids filhos é controlado pela propriedade <ApiLink kind="interface" type="IGridStateOptions" member="rowIslands" /> e vem habilitado por padrão. <ApiLink type="GridStateDirective" /> usará as mesmas opções para salvar/restaurar recursos tanto do grid raiz quanto de todos os grids filhos na hierarquia. Por exemplo, se passarmos as seguintes opções:

``` html
<!-- public options = {selection: false, sorting: false, rowIslands: true} -->
<igx-grid [igxGridState]="options"></igx-grid>
```

Então a API `getState` retornará o estado de todos os grids (grid raiz e grids filhos), excluindo os recursos `selection` e `sorting`. Se, mais tarde, o desenvolvedor quiser restaurar apenas o estado de `filtering` de todos os grids, use:

```typescript
this.state.setState(state, ['filtering', 'rowIslands']);
```

</ComponentBlock>

## Restaurando estratégias do Pivot

O <ApiLink type="GridStateDirective" /> não persiste, por padrão, nem operações remotas de pivot nem estratégias personalizadas de dimensão (para mais informações, veja o exemplo [Pivot Grid Remote Operations](/{igPath}/pivot-grid-custom)) (veja [`limitations`](/{igPath}/state-persistence#limitações)). Restaurar qualquer um deles pode ser feito com código no nível da aplicação. O `IgxGridState` expõe um evento chamado <ApiLink type="GridStateDirective" member="stateParsed" label="stateParsed" />, que pode ser usado para modificar adicionalmente o estado do grid antes de ele ser aplicado. Vamos mostrar como fazer isso:

> <ApiLink type="GridStateDirective" /> só é emitido quando usamos <ApiLink type="GridStateDirective" member="setState" label="setState" /> com argumento de string.

- Defina uma estratégia de ordenação personalizada e estratégias personalizadas de dimensão de coluna e de linha do pivot:

```html
<igx-pivot-grid #grid [data]="data" [pivotConfiguration]="pivotConfigHierarchy" [defaultExpandState]='true'
    [igxGridState]="options" [sortStrategy]="customStrategy" [pivotUI]='{ showConfiguration: false }' [superCompactMode]="true" [height]="'500px'">
</igx-pivot-grid>
```

```typescript
@ViewChild(IgxGridStateDirective, { static: true })
public state!: IgxGridStateDirective;

public customStrategy = NoopSortingStrategy.instance();
public options: IGridStateOptions = {...};
public pivotConfigHierarchy: IPivotConfiguration = {
    columnStrategy: NoopPivotDimensionsStrategy.instance(),
    rowStrategy: NoopPivotDimensionsStrategy.instance(),
    columns: [...],
    rows: [...],
    values: [...],
    filters: [...]
};
```

- Restaurar o estado a partir do `sessionStorage` e aplicar as estratégias personalizadas fica assim:

```typescript
public restoreState() {
    const state = window.sessionStorage.getItem('grid-state');
    this.state.stateParsed.pipe(take(1)).subscribe(parsedState => {
        parsedState.sorting.forEach(x => x.strategy = NoopSortingStrategy.instance());
        parsedState.pivotConfiguration.rowStrategy = NoopPivotDimensionsStrategy.instance();
        parsedState.pivotConfiguration.columnStrategy = NoopPivotDimensionsStrategy.instance();
    });
    this.state.setState(state as string);
}
```

## Restaurando estratégias

O <ApiLink type="GridStateDirective" /> não persiste, por padrão, nem operações remotas nem estratégias personalizadas de dimensão (para mais informações, veja o exemplo [Grid Remote Operations](/{igPath}/remote-data-operations)) (veja [`limitations`](/{igPath}/state-persistence#limitações)). Restaurar qualquer um deles pode ser feito com código no nível da aplicação. O `IgxGridState` expõe um evento chamado <ApiLink type="GridStateDirective" member="stateParsed" label="stateParsed" />, que pode ser usado para modificar adicionalmente o estado do grid antes de ele ser aplicado. Vamos mostrar como fazer isso:

<DocsAside type="info">
<ApiLink type="GridStateDirective" /> só é emitido quando usamos <ApiLink type="GridStateDirective" member="setState" label="setState" /> com argumento de string.
</DocsAside>

- Defina uma estratégia de ordenação personalizada e estratégias personalizadas de dimensão de coluna e de linha:

```html
<igx-grid #grid 
          [data]="data" 
          [igxGridState]="options" 
          [sortStrategy]="customStrategy"
          [height]="'500px'">
</igx-grid>
```

```typescript
@ViewChild(IgxGridStateDirective, { static: true })
public state!: IgxGridStateDirective;

public customStrategy = NoopSortingStrategy.instance();
public options: IGridStateOptions = {...};
```

- Restaurar o estado a partir do `sessionStorage` e aplicar as estratégias personalizadas fica assim:

```typescript
public restoreState() {
    const state = window.sessionStorage.getItem('grid-state');
    this.state.stateParsed.pipe(take(1)).subscribe(parsedState => {
        parsedState.sorting.forEach(x => x.strategy = NoopSortingStrategy.instance());
    });
    this.state.setState(state as string);
}
```

## Limitações

<ComponentBlock for="HierarchicalGrid">

- Ao restaurar todos os recursos do grid de uma vez (usando a API `setState` sem parâmetros), as propriedades de coluna do grid raiz podem ser redefinidas para o padrão. Se isso acontecer, restaure as colunas ou o recurso de seleção de colunas separadamente, depois disso:

```typescript
state.setState(gridState);
state.setState(gridState.columns);
state.setState(gridState.columnSelection);
```

</ComponentBlock>
<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">

- O método <ApiLink type="GridStateDirective" member="getstate" label="getState" /> usa o método JSON.stringify() para converter os objetos originais em uma string JSON. JSON.stringify() não oferece suporte a funções; por isso, a diretiva [`IgxGridState`] ignorará as propriedades <ApiLink type="Column" member="formatter" label="formatter" />, <ApiLink type="Column" member="filters" label="filters" />, <ApiLink type="Column" member="summaries" label="summaries" />, <ApiLink type="Column" member="sortstrategy" label="sortStrategy" />, <ApiLink type="Column" member="cellClasses" label="cellClasses" />, <ApiLink type="Column" member="cellstyles" label="cellStyles" />, <ApiLink type="Column" member="headerTemplate" label="headerTemplate" /> e <ApiLink type="Column" member="bodyTemplate" label="bodyTemplate" /> das colunas.
</ComponentBlock>
<ComponentBlock for="PivotGrid">

- O método <ApiLink type="GridStateDirective" member="getState" label="getState" /> usa o método JSON.stringify() para converter os objetos originais em uma string JSON. JSON.stringify() não oferece suporte a funções; por isso, a diretiva <ApiLink type="GridStateDirective" /> ignorará a <ApiLink kind="interface" type="IPivotDimension" member="memberFunction" /> de dimensão do pivot, os <ApiLink kind="interface" type="IPivotValue" member="member" /> do pivot, as funções <ApiLink kind="interface" type="IPivotValue" member="aggregate" /> personalizadas <ApiLink kind="interface" type="IPivotValue" member="formatter" />,
<ApiLink kind="interface" type="IPivotValue" member="styles" /> e as estratégias de configuração do pivot: <ApiLink kind="interface" type="IPivotConfiguration" member="columnStrategy" /> e <ApiLink kind="interface" type="IPivotConfiguration" member="rowStrategy" />.
</ComponentBlock>
