# Paginação do {ComponentTitle} do Angular

A paginação é usada para dividir um grande conjunto de dados em uma sequência de páginas com conteúdo semelhante. A paginação de tabelas Angular melhora a experiência do usuário e a interação com os dados. A paginação do {ComponentTitle} é configurável por meio de um componente separado, projetado na árvore do grid com a definição de uma tag `igx-paginator`, de forma semelhante à adição de uma coluna. Como em qualquer tabela Angular, a paginação no {ComponentTitle} oferece suporte a templates para páginas personalizadas.

Adicionar um componente [`igx-paginator`](/paginator) controlará se o recurso está presente; você pode habilitá-lo/desabilitá-lo usando um simples bloco `@if` com uma propriedade de alternância. A entrada <ApiLink type="Paginator" member="perPage" label="perPage" /> controla os registros visíveis por página. Vamos atualizar o nosso {ComponentTitle} para habilitar a paginação:

```html
<{ComponentSelector} #{ComponentObjectRef} [data]="data" [height]="'500px'" [width]="'100%'">
    <igx-paginator [perPage]="10">
    </igx-paginator>
</{ComponentSelector}>
```

Exemplo:

```html
<igx-paginator #paginator [totalRecords]="20">
    <igx-paginator-content>
        <div id="numberPager" style="justify-content: center;">
            <button [disabled]="paginator.isFirstPage" (click)="paginator.previousPage()" igxButton="flat">
                PREV
            </button>
            <span>
               Page {{paginator.page}} of {{paginator.totalPages}}
            </span>
            <button [disabled]="paginator.isLastPage" (click)="paginator.nextPage()" igxButton="flat">
                NEXT
            </button>
        </div>
    </igx-paginator-content>
</igx-paginator>
```

## Paginação com Group By

As linhas de grupo participam do processo de paginação junto com as linhas de dados. Elas contam para o tamanho de página de cada página. As linhas recolhidas não são incluídas no processo de paginação.
A integração entre paginação e Group By é descrita no tópico [Group By](/{igPath}/groupby#angular-grid-group-by-com-paginação).
</ComponentBlock>

## Uso

<ComponentBlock for="Grid">

O componente `igx-paginator` é usado junto com o componente `igx-grid` no exemplo abaixo, mas você pode usá-lo com qualquer outro componente, caso precise de funcionalidade de paginação.

```html
<igx-grid #grid [data]="data">
    <igx-paginator #paginator [(page)]="grid.page" [totalRecords]="grid.totalRecords" [(perPage)]="10"
            [selectOptions]="selectOptions">
    </igx-paginator>
</igx-grid>
```

</ComponentBlock>

<ComponentBlock for="TreeGrid">

O componente `igx-paginator` é usado junto com o componente `igx-tree-grid` no exemplo abaixo, mas você pode usá-lo com qualquer outro componente, caso precise de funcionalidade de paginação.

```html
<igx-tree-grid #treeGrid [data]="data">
    <igx-paginator #paginator [(page)]="treeGrid.page" [totalRecords]="treeGrid.length" [(perPage)]="10"
            [selectOptions]="selectOptions">
    </igx-paginator>
</igx-tree-grid>
```

</ComponentBlock>

<ComponentBlock for="HierarchicalGrid">

O componente `igx-paginator` é usado junto com o componente `igx-hierarchical-grid` no exemplo abaixo, mas você pode usá-lo com qualquer outro componente, caso precise de funcionalidade de paginação.

```html
<igx-hierarchical-grid>
    <igx-column *ngFor="let c of hColumns" [field]="c.field">
    </igx-column>
    <igx-row-island [key]="'childData'" [autoGenerate]="true">
        <igx-row-island [key]="'childData'" [autoGenerate]="true">
            <igx-paginator *igxPaginator></igx-paginator>
        </igx-row-island>
        <igx-paginator *igxPaginator></igx-paginator>
    </igx-row-island>
    <igx-row-island [key]="'childData2'" [autoGenerate]="true">
        <igx-paginator *igxPaginator></igx-paginator>
    </igx-row-island>

    <igx-paginator></igx-paginator>
</igx-hierarchical-grid>
```

</ComponentBlock>

### Configuração do paginador dentro de grids filhos

Devido a certas limitações na forma como os grids filhos de um IgxHierarchicalGrid são implementados e como o escopo de DI funciona, ao definir um componente paginador dentro das tags igx-row-island, sempre use a diretiva IgxPaginator no próprio paginador. Isso garantirá que o grid filho tenha a instância correta do paginador como referência:

```html
<igx-hierarchical-grid>
    ...
    <igx-row-island>
        ...
        <igx-grid-toolbar *igxPaginator>
           ...
        </igx-grid-toolbar>
    </igx-row-island>
    ...
</igx-hierarchical-grid>
```

</ComponentBlock>

## Estilização

Para começar a estilizar o paginador, precisamos importar o arquivo `index`, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Seguindo a abordagem mais simples, criamos um novo tema que estende o <ApiLink kind="sass" module="themes" type="function-paginator-theme" label="paginator-theme" code={true} /> e aceita os parâmetros `$foreground`, `$background`, `$border-color` e `$accent-color`.

```scss
$paginator-theme: paginator-theme(
  $foreground: #ff570f,
  $background: #130425FF,
  $border-color: #ff570f,
  $accent-color: #ff570f,
);
```

Depois disso, podemos **incluir** o tema recém-criado.

```scss
igx-paginator {
  @include tokens($paginator-theme);
}
```
