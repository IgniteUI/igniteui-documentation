# Interações de área de transferência do {ComponentTitle} do Angular

As operações de copiar para a área de transferência agora estão disponíveis no {ComponentTitle}. Essa funcionalidade oferece uma forma rápida, fácil e personalizável de copiar dados do Angular Data Grid por meio da seleção de dados de várias células atual. O comportamento da área de transferência do sistema permite que o usuário copie dados do {ComponentTitle} para o Excel ou outros programas externos.

## Funcionalidade

O comportamento de cópia funciona com a interação padrão definida pelo navegador e pelo sistema operacional. Assim, para os comportamentos de copiar e colar, são estes:

- Baseado em Windows/Unix
  - <kbd>Ctrl</kbd> + <kbd>C</kbd> / <kbd>Ctrl</kbd> + <kbd>Ins</kbd> como atalho de teclado
  - <kbd>Ctrl</kbd> + <kbd>V</kbd> / <kbd>Shift</kbd> + <kbd>Ins</kbd> como atalho de teclado
  - Ação de copiar pelo menu do navegador
- macOS
  - <kbd>⌘ Cmd</kbd> + <kbd>C</kbd> como atalho de teclado
  - <kbd>⌘ Cmd</kbd> + <kbd>V</kbd> como atalho de teclado
  - Ação de copiar pelo menu do navegador

## Limitações

- Os eventos de **recortar** e **copiar** não são suportados nativamente no Internet Explorer. A exceção é o evento de **colar** (IE 11), que é emitido, mas não expõe a propriedade `clipboardData` no evento.

<DocsAside type="info">
Para `copy` células no IE 11, você pode usar a seleção pelo teclado. Mantenha `shift key` pressionada para fazer uma seleção de várias células e pressione `Ctrl + C` para copiar.
</DocsAside>

- O comportamento de cópia fica desativado enquanto o grid estiver em modo de edição.
- A versão atual deste recurso cobre apenas o comportamento do `copy` do grid. Mais adiante, planejamos expor `paste` no comportamento do grid.
<ComponentBlock for="Grid">
 Você pode usar um manipulador de colagem personalizado para configurar o comportamento de `paste`; veja o nosso [tópico Colar do Excel](/{igPath}/paste-excel).
 </ComponentBlock>


## Uso da API

Expomos a propriedade <ApiLink type="Grid" member="clipboardOptions" label="clipboardOptions" /> @Input, que oferece as seguintes opções:

- <ApiLink type="Grid" member="clipboardoptions.enabled" label="enabled" /> Ativa/desativa a cópia das células selecionadas.
- <ApiLink type="Grid" member="clipboardoptions.copyHeaders" label="copyHeaders" /> Inclui os cabeçalhos associados ao copiar.
- <ApiLink type="Grid" member="clipboardoptions.copyFormatters" label="copyFormatters" /> Aplica quaisquer formatadores de coluna existentes aos dados copiados.
- <ApiLink type="Grid" member="clipboardoptions.separator" label="separator" /> O separador de string a ser usado para formatar os dados na área de transferência. O padrão é `/t`

<DocsAside type="info">
O Excel consegue detectar automaticamente textos separados por tabulações (delimitados por tabulação `/t`) e colar os dados corretamente em colunas separadas. Quando o formato de colagem não funciona e tudo o que você cola aparece em uma única coluna, é porque o delimitador do Excel está definido para outro caractere, ou o seu texto usa espaços em vez de tabulações.
</DocsAside>

- <ApiLink type="Grid" member="gridCopy" label="gridCopy" /> Emitido quando uma operação de cópia é executada. Disparado somente se o comportamento de cópia estiver habilitado por meio de <ApiLink type="Grid" member="clipboardOptions" label="clipboardOptions" />
