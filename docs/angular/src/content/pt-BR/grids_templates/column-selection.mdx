# Seleção de colunas do {ComponentTitle} do Angular

O recurso de seleção de colunas oferece uma forma fácil de selecionar uma coluna inteira com um único clique. Ele destaca a importância de uma coluna específica, enfatizando a(s) célula(s) do cabeçalho e tudo abaixo dela. O recurso vem com uma `API` rica, que permite manipular o estado da seleção, extrair dados das frações selecionadas e realizar operações e visualizações de análise de dados.

## Uso básico

O recurso de seleção de colunas pode ser habilitado pela entrada <ApiLink type="{ComponentApiType}" member="columnSelection" label="columnSelection" />, que aceita os valores <ApiLink kind="variable" type="GridSelectionMode" />.

## Interações

O modo de seleção padrão é `none`. Se for definido como `single` ou `multiple`, todas as colunas apresentadas ficarão <ApiLink type="Column" member="selectable" label="selectable" />. Dito isso, para selecionar uma coluna, basta clicar em uma delas, que será marcada como <ApiLink type="Column" member="selected" label="selected" />. Se a coluna não for selecionável, nenhum estilo de seleção será aplicado ao cabeçalho ao passar o mouse sobre ele.

<DocsAside type="info">
[`Multi-column Headers`](/{igPath}/multi-column-headers) não se refletem na entrada <ApiLink type="Column" member="selectable" label="selectable" />. O <ApiLink type="ColumnGroup" /> fica <ApiLink type="Column" member="selectable" label="selectable" /> se pelo menos um dos seus filhos tiver o comportamento de seleção habilitado. Além disso, o componente é marcado como <ApiLink type="ColumnGroup" member="selected" label="selected" /> se todos os seus descendentes `selectable` estiverem <ApiLink type="Column" member="selected" label="selected" />.
</DocsAside>

## Combinações de teclas

<DocsAside type="info">
As combinações de teclas só estão disponíveis quando a entrada <ApiLink type="{ComponentApiType}" member="columnselection" label="columnSelection" /> do grid está definida como `multiple`.
</DocsAside>

Há dois cenários para a navegação por teclado no recurso **Seleção de colunas**:

- Seleção de várias colunas — mantendo <kbd>ctrl</kbd> + <kbd>clique</kbd> em cada célula de cabeçalho **selecionável**.
- Seleção de intervalo de colunas — mantendo <kbd>shift</kbd> + <kbd>clique</kbd>, seleciona todas as colunas **selecionáveis** entre elas.

## Manipulações pela API

A **API** oferece algumas capacidades adicionais para as colunas **não visíveis**, de modo que cada coluna **oculta** pode ser marcada como <ApiLink type="Column" member="selected" label="selected" /> definindo o **setter** correspondente.

<DocsAside type="info">
A afirmação acima também se aplica a <ApiLink type="ColumnGroup" />, exceto que, quando a propriedade <ApiLink type="ColumnGroup" member="selected" label="selected" /> é alterada, ela altera o estado dos seus descendentes.
</DocsAside>

Mais informações sobre as manipulações pela API podem ser encontradas na seção [`API References`](#api-references).

## Estilização

Antes de mergulhar nas opções de estilização, o módulo de temas precisa ser importado.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

<DocsAside type="info">
Observe que [`row selection`](/{igPath}/row-selection) e [`column selection`](/{igPath}/column-selection) não podem ser manipulados de forma independente. Eles dependem do mesmo `variables`.
</DocsAside>

Dito isso, vamos alterar os estilos de **seleção** e de **hover**.<br/>
Seguindo a abordagem mais simples, vamos definir o nosso **tema** personalizado.

<ComponentBlock for="TreeGrid">

```scss
$background: #0b0119;
$foreground: #eeece1;
$accent: #f6b560;

$grid-theme: grid-theme(
  $background: $background,
  $foreground: $foreground,
  $accent-color: $accent,
  
  $row-selected-background: #012724,
  $row-selected-text-color: $accent,
  $header-selected-text-color: $accent,
  $header-selected-background: #012427,
  
  $row-selected-hover-background: hsl(from #012427 h s 10%),
  $row-selected-hover-text-color: $accent,
);
```

</ComponentBlock>
<ComponentBlock for="Grid, HierarchicalGrid, PivotGrid">

```scss
$background: #011627;
$accent: #ecaa53;

$custom-grid-theme: grid-theme(
  $row-selected-background: $background,
  $row-selected-text-color: $accent,
  $row-selected-hover-background: hsl(from $background h s 10%),
  $row-selected-hover-text-color: $accent,
  $header-selected-text-color: $accent,
  $header-selected-background: $background,
);
```

</ComponentBlock>

O <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> aceita vários parâmetros, mas estes são os cinco responsáveis por alterar a aparência de todas as colunas selecionadas:

- **$row-selected-background** - define o fundo da fração selecionada.
- **$row-selected-text-color** - define a cor do texto da fração selecionada
- **$row-selected-hover-background** - define a cor da célula ou do grupo de células sob o mouse.
- **$row-selected-hover-text-color** - define a cor do texto da célula ou do grupo de células sob o mouse.
- **$header-selected-text-color** - define a cor do texto do cabeçalho da coluna selecionada
- **$header-selected-background** - define a cor de fundo do cabeçalho da coluna selecionada.

### Usando variáveis CSS

A última etapa é **incluir** o tema personalizado do grid.

```scss
:host {
  @include tokens($custom-grid-theme)
}
```
