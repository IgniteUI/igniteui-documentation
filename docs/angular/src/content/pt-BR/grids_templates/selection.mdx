## Opções de seleção do Angular Grid

O componente {ComponentTitle} do IgniteUI for Angular oferece três modos de seleção diferentes — [seleção de linhas](/{igPath}/row-selection), [seleção de células](/{igPath}/cell-selection) e [seleção de colunas](/{igPath}/column-selection). Por padrão, somente o modo **seleção de várias células** fica habilitado no {ComponentTitle}. Para alterar/habilitar o modo de seleção, você pode usar as propriedades <ApiLink type="Grid" member="rowSelection" label="rowSelection" />, <ApiLink type="Grid" member="cellSelection" label="cellSelection" /> ou <ApiLink type="Column" member="selectable" label="selectable" />.

### Seleção de linhas do Angular

A propriedade <ApiLink type="Grid" member="rowSelection" label="rowSelection" /> permite especificar as seguintes opções:

- none - a seleção de linhas ficará desabilitada para o {ComponentTitle}
- single - estará disponível a seleção de apenas uma linha dentro do {ComponentTitle}
- multiple - estará disponível a seleção de várias linhas usando o `Row selectors`, com uma combinação de teclas como <kbd>ctrl</kbd> + <kbd>clique</kbd>, ou pressionando a <kbd>tecla de espaço</kbd> quando uma célula estiver com foco
<ComponentBlock for="TreeGrid">
- multipleCascade - este é um modo de seleção em cascata, que resulta na seleção de todos os filhos da árvore abaixo do registro que o usuário seleciona por interação. Nesse modo, o estado de seleção de um pai depende inteiramente do estado de seleção dos seus filhos.
</ComponentBlock>

> Consulte o tópico [Seleção de linhas](/{igPath}/row-selection) para mais informações.

### Seleção de células do Angular

A propriedade <ApiLink type="Grid" member="cellSelection" label="cellSelection" /> permite especificar as seguintes opções:

- none - a seleção de células ficará desabilitada para o {ComponentTitle}
- single - estará disponível a seleção de apenas uma célula dentro do {ComponentTitle}.
- multiple - atualmente, este é o estado padrão da seleção no {ComponentTitle}. A seleção de várias células está disponível arrastando o mouse sobre as células, após um clique contínuo com o botão esquerdo.

> Consulte o tópico [Seleção de células](/{igPath}/cell-selection) para mais informações.

### Seleção de colunas do Angular

A propriedade <ApiLink type="Column" member="selectable" label="selectable` property" /> permite especificar as seguintes opções para cada **coluna**:

- false - a seleção da coluna correspondente ficará desabilitada para o {ComponentTitle}
- true - a seleção da coluna correspondente ficará habilitada para o {ComponentTitle}
- Isso leva às três variações a seguir:
- Seleção única - <kbd>clique do mouse</kbd> sobre a célula da coluna.
- Seleção de várias colunas - mantendo <kbd>ctrl</kbd> + <kbd>clique do mouse</kbd> sobre as células da coluna.
- Seleção de intervalo de colunas - mantendo <kbd>shift</kbd> + <kbd>clique do mouse</kbd>, seleciona tudo o que estiver entre elas.

> Consulte o tópico [Seleção de colunas](/{igPath}/column-selection) para mais informações.

## Menu de contexto do Grid

Usando o evento <ApiLink type="Grid" member="contextMenu" label="contextMenu" />, você pode adicionar um menu de contexto personalizado para facilitar o seu trabalho com o **IgxGrid**. Com um **clique com o botão direito** no corpo do grid, o evento emite a célula sobre a qual foi disparado. O **menu de contexto** operará com a célula emitida.

Se houver uma **seleção de várias células**, colocaremos uma lógica que verifica se a célula selecionada está na área da seleção de várias células. Se estiver, também emitiremos os valores das células selecionadas.

Basicamente, a função principal ficará assim:

```typescript
public rightClick(eventArgs: any) {
     // Prevent the default behavior of the right click
    eventArgs.event.preventDefault();
    this.multiCellArgs = {};
    // If we have multi-cell selection, check if selected cell is within the ranges
    if (this.multiCellSelection) {
        const node = eventArgs.cell.selectionNode;
        const isCellWithinRange = this.grid1.getSelectedRanges().some(range => {
            if (node.column >= range.columnStart &&
                node.column <= range.columnEnd &&
                node.row >= range.rowStart &&
                node.row <= range.rowEnd) {
                return true;
            }
            return false;
        })
        // If the cell is within a multi-cell selection range, bind all the selected cells data
        if (isCellWithinRange) {
            this.multiCellArgs = { data: this.multiCellSelection.data };
        }
    }
    // Set the position of the context menu
    this.contextmenuX = eventArgs.event.clientX;
    this.contextmenuY = eventArgs.event.clientY;
    this.clickedCell = eventArgs.cell;
    // Enable the context menu
    this.contextmenu = true;
}
```

O menu de contexto terá as seguintes funções:

- Copiar o _valor_ da célula selecionada
- Copiar o _dataRow_ da célula selecionada
- Se a célula selecionada estiver dentro de um **intervalo de seleção de várias células**, copiar todos os _dados selecionados_

```typescript
//contextmenu.component.ts

public copySelectedCellData(event) {
    const selectedData = { [this.cell.column.field]: this.cell.value };
    this.copyData(JSON.stringify({ [this.cell.column.field]: this.cell.value }));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copyRowData(event) {
    const selectedData = this.cell.row.data ;
    this.copyData(JSON.stringify(this.cell.row.data));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copySelectedCells(event) {
    const selectedData = this.selectedCells.data;
    this.copyData(JSON.stringify(selectedData));
    this.onCellValueCopy.emit({ data: selectedData });
}
```

O IgxGrid buscará os dados copiados e os colará em um elemento contêiner.

O template que vamos usar para combinar o grid com o menu de contexto:

```html
<div class="wrapper">
    <div class="grid__wrapper" (window:click)="disableContextMenu()">
        <igx-grid #grid1 [data]="data" [autoGenerate]="false" height="500px" width="100%"
            (contextMenu)="rightClick($event)" (rangeSelected)="getCells($event)"
            (selected)="cellSelection($event)">
        <!-- Columns area -->
        </igx-grid>
        @if (contextmenu==true) {
            <div>
                <contextmenu [x]="contextmenuX" [y]="contextmenuY" [cell]="clickedCell" [selectedCells]="multiCellArgs" (onCellValueCopy)="copy($event)">
                </contextmenu>
            </div>
        }
    </div>
    <div class="selected-data-area">
        <div>
           <pre>{{copiedData}}</pre>
        </div>
    </div>
</div>
```

 Selecione várias células e pressione o botão `right mouse`. O menu de contexto aparecerá e, depois de selecionar `Copy cells data`, os dados selecionados aparecerão na caixa vazia à direita.

## Problemas conhecidos e limitações

- Usar o {ComponentTitle} com a seleção habilitada no IE11 exige a importação explícita do polyfill de array em polyfill.ts da aplicação Angular. O IE11 não é mais suportado a partir da versão 13.0.0.

    ```typescript
    import 'core-js/es7/array';
    ```

- Quando o grid não tem `primaryKey` definido e os cenários de dados remotos estão habilitados (quando paginação, ordenação, filtragem ou rolagem disparam requisições a um servidor remoto para obter os dados a serem exibidos no grid), uma linha perderá o seguinte estado após a conclusão de uma requisição de dados:
  - Seleção de linha
  - Expandir/recolher linha
  - Edição de linha
  - Fixação de linha
