# Fixação de linhas do {ComponentTitle} do Angular

Uma ou várias linhas podem ser fixadas na parte superior ou inferior do Angular UI Grid. A **fixação de linhas** no Ignite UI for Angular permite que os usuários finais fixem linhas em uma ordem específica, duplicando-as em uma área especial que fica sempre visível, mesmo quando eles rolam o {ComponentTitle} verticalmente. O grid Material UI tem uma interface integrada de fixação de linhas, que é habilitada ao inicializar um componente `igxActionStrip` no contexto de {ComponentTitle}. Além disso, você pode definir uma interface personalizada e alterar o estado de fixação das linhas pela API de fixação de linhas.

## Interface de fixação de linhas

A interface integrada de fixação de linhas é habilitada adicionando um componente `igxActionStrip` com o componente `GridPinningActions`. O action strip é exibido automaticamente ao passar o mouse sobre uma linha e mostra um ícone de botão de fixar ou desafixar, conforme o estado da linha para a qual é exibido. Uma ação adicional, que permite rolar a cópia da linha fixada para a área visível, também é exibida para cada linha fixada.

<ComponentBlock for="Grid">

```html
<igx-grid [data]="data" [autoGenerate]="false">
    <igx-column *ngFor="let c of columns" [field]="c.field" [header]="c.field">
    </igx-column>

    <igx-action-strip #actionStrip>
        <igx-grid-pinning-actions></igx-grid-pinning-actions>
        <igx-grid-editing-actions></igx-grid-editing-actions>
    </igx-action-strip>
</igx-grid>
```

</ComponentBlock>

## API de fixação de linhas

A fixação de linhas é controlada pela entrada `pinned` do <ApiLink kind="interface" type="RowType"/>. Por padrão, as linhas fixadas são renderizadas na parte superior do {ComponentTitle} e permanecem fixas durante a rolagem vertical das linhas não fixadas no corpo do {ComponentTitle}.

<ComponentBlock for="Grid">

```typescript
this.grid.getRowByIndex(0).pinned = true;
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```typescript
this.treeGrid.getRowByIndex(0).pinned = true;
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```typescript
this.hierarchicalGrid.getRowByIndex(0).pinned = true;
```

</ComponentBlock>

Você também pode usar os métodos <ApiLink type="{ComponentApiType}" member="pinRow" label="pinRow" /> ou <ApiLink type="{ComponentApiType}" member="unpinRow" label="unpinRow" /> do {ComponentTitle} do <ApiLink type="{ComponentApiType}" /> para fixar ou desafixar registros pelo seu ID:

<ComponentBlock for="Grid">

```typescript
this.grid.pinRow('ALFKI');
this.grid.unpinRow('ALFKI');
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```typescript
this.treeGrid.pinRow('ALFKI');
this.treeGrid.unpinRow('ALFKI');
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```typescript
this.hierarchicalGrid.pinRow('ALFKI');
this.hierarchicalGrid.unpinRow('ALFKI');
```

</ComponentBlock>

Observe que o ID da linha é o valor da chave primária, definido pelo <ApiLink type="{ComponentApiType}" member="primaryKey" label="primaryKey" /> do grid, ou a própria instância do registro. Ambos os métodos retornam um valor booleano indicando se a operação correspondente foi bem-sucedida. Normalmente, a falha ocorre porque a linha já está no estado desejado.

Uma linha é fixada abaixo da última linha fixada. Para alterar a ordem das linhas fixadas, você pode se inscrever no evento <ApiLink type="{ComponentApiType}" member="rowPinning" label="rowPinning" /> e alterar a propriedade <ApiLink kind="interface" type="IPinRowEventArgs" member="insertAtIndex" /> dos argumentos do evento para o índice de posição desejado.

<ComponentBlock for="Grid">

```html
<igx-grid #grid1 [data]="data" [autoGenerate]="true" (rowPinning)="rowPinning($event)">
</igx-grid>
```

```typescript
public rowPinning(event) {
    event.insertAtIndex = 0;
}
```

</ComponentBlock>

## Posição da fixação

Você pode alterar a posição da fixação de linhas pela opção de configuração <ApiLink type="{ComponentApiType}" member="pinning" label="pinning" />. Ela permite definir a posição da área de fixação como Top ou Bottom.
Quando definida como Bottom, as linhas fixadas são renderizadas na parte inferior do grid, depois das linhas não fixadas. As linhas não fixadas podem ser roladas verticalmente, enquanto as linhas fixadas permanecem fixas na parte inferior.

<ComponentBlock for="Grid">

```html
<igx-grid [data]="data" [autoGenerate]="true" [pinning]="pinningConfig"></igx-grid>
```

Ao clicar no ícone personalizado, o estado de fixação da linha correspondente pode ser alterado usando os métodos de API da linha.

```typescript
public togglePinning(row: IgxGridRow, event) {
    event.preventDefault();
    if (row.pinned) {
        row.unpin();
    } else {
        row.pin();
    }
}
```

### Por meio de arrastar linhas

Digamos que você queira poder arrastar e soltar diretamente uma linha entre as linhas fixadas e não fixadas, para alterar o seu estado de fixação.
Isso pode ser obtido habilitando o recurso de arrastar linhas e fixando/desafixando as linhas pela API ao soltar.

Primeiro, o grid deve ser marcado como área de soltar usando a diretiva `igxDrop`, e a funcionalidade de arrastar linhas deve ser habilitada pela opção `rowDraggable`.

```html
<igx-grid [data]="data" [autoGenerate]="true" [rowDraggable]="true"
    [primaryKey]="'ID'" igxDrop (dropped)="onDropAllowed($event)">
</igx-grid>
```

Depois, o evento `dropped` pode ser usado para tratar a lógica de reordenação e de fixar/desafixar.

```typescript
public onDropAllowed(args) {
    const event = args.originalEvent;
    let currRowPinnedIndex;
    const currRowIndex = this.getCurrentRowIndex(this.grid.rowList.toArray(),
        { x: event.clientX, y: event.clientY });
    if (currRowIndex === -1) { return; }

    const currRowID = this.getCurrentRowID(this.grid.rowList.toArray(),
        { x: event.clientX, y: event.clientY });

    const currentRow = this.grid.rowList.toArray().find((r) => r.rowID === currRowID);
    if (currentRow.pinned) {
        currRowPinnedIndex = this.grid.pinnedRows.indexOf(this.grid.pinnedRows.find((r) => r.rowID === currRowID));
    }
    // remove the row that was dragged and place it onto its new location
    this.grid.deleteRow(args.dragData.key);
    this.data.splice(currRowIndex, 0, args.dragData.data);
    if (currentRow.pinned && !args.dragData.pinned) {
        this.grid.pinRow(args.dragData.key, currRowPinnedIndex);
    } else if (!currentRow.pinned && args.dragData.pinned) {
        this.grid.unpinRow(args.dragData.key);
    } else if (currentRow.pinned && args.dragData.pinned) {
        this.grid.unpinRow(args.dragData.key);
        this.grid.pinRow(args.dragData.key, currRowPinnedIndex);
    }
}
```

Isso permitirá reordenar as linhas e movê-las entre as coleções de linhas fixadas e não fixadas.

## Limitações da fixação de linhas

- Somente registros que existem na fonte de dados podem ser fixados.
- O estado de fixação de linhas não é exportado para o Excel. O grid é exportado como se nenhuma fixação de linhas tivesse sido aplicada.
- Devido à forma como as linhas fixadas são armazenadas internamente, para poderem aparecer tanto na área fixada quanto na não fixada do grid, a fixação de linhas não é suportada quando os registros do grid são buscados sob demanda em um endpoint remoto (virtualização remota).
- As cópias das linhas fixadas na área rolável do grid são parte integrante de como outros recursos do grid alcançam a sua funcionalidade na presença de linhas fixadas; por isso, a sua criação não pode ser desabilitada, nem elas podem ser removidas.
- Como a seleção de linhas funciona inteiramente com os IDs das linhas, selecionar linhas fixadas seleciona também as suas cópias (e vice-versa). Além disso, a seleção de intervalo (por exemplo, usando Shift + clique) dentro da área fixada funciona da mesma forma que a seleção de um intervalo de linhas na área rolável. A seleção resultante inclui todas as linhas intermediárias, mesmo que elas não estejam fixadas no momento. Obter as linhas selecionadas pela API retorna apenas uma instância de cada registro selecionado.
- Quando o grid não tem `primaryKey` definido e os cenários de dados remotos estão habilitados (quando paginação, ordenação, filtragem ou rolagem disparam requisições a um servidor remoto para obter os dados a serem exibidos no grid), uma linha perderá o seguinte estado após a conclusão de uma requisição de dados:
  - Seleção de linha
  - Expandir/recolher linha
  - Edição de linha
  - Fixação de linha


## Estilização

O {ComponentName} permite a estilização por meio da [`Ignite UI for Angular Theme Library`](/themes/sass/component-themes). A {ComponentTitle} do <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> expõe uma grande variedade de propriedades, que permitem personalizar todos os recursos do {ComponentTitle}.

A seguir, vamos percorrer os passos para personalizar a estilização da fixação de linhas do {ComponentTitle}.

### Importando a biblioteca de estilos

Para começar a personalizar o recurso de fixação de linhas, você precisa importar o arquivo `index`, onde estão todas as funções e mixins de estilização.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### Definindo um tema

Em seguida, crie um novo tema que estenda o <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> e aceite os parâmetros necessários para personalizar o recurso de fixação de linhas como desejar.

<ComponentBlock for="Grid">

```scss
$custom-theme: grid-theme(
  $pinned-border-width: 5px,
  $pinned-border-style: double,
  $pinned-border-color: #ffcd0f,
  $cell-active-border-color: #ffcd0f
);
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```scss
$custom-theme: grid-theme(
  $pinned-border-width: 1px,
  $pinned-border-style: dashed,
  $pinned-border-color: #f325e9,
);
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```scss
$background: #292826;
$foreground: #eeece1;
$accent: #ffcd0f;

$custom-grid: grid-theme(
  $background: $background,
  $foreground: $foreground,
  $accent-color: $accent,
  $pinned-border-color: $accent,
);
```

</ComponentBlock>

### Usando variáveis CSS

A última etapa é passar o tema personalizado do grid:

<ComponentBlock for="Grid, TreeGrid">

```scss
:host {
  @include tokens($custom-theme);
}
```

</ComponentBlock>

<ComponentBlock for="HierarchicalGrid">

```scss
:host {
  @include tokens($custom-grid);
}
```

</ComponentBlock>
