### Usando rowStyles

As colunas agora expõem a propriedade `rowStyles`, que permite a estilização condicional das linhas de dados. Semelhante a `rowClasses`, ela aceita um objeto literal em que as chaves são propriedades de estilo e os valores são expressões a serem avaliadas. Além disso, você pode aplicar estilização comum (sem nenhuma condição).

> A assinatura do callback tanto para `rowStyles` quanto para `rowClasses` é:

```ts
(row: RowType) => boolean
```

Vamos definir os nossos estilos:

<ComponentBlock for="Grid">

```typescript
// component.ts
public rowStyles = {
    background: (row: RowType) => (+row.data['Change'] < 0  && +row.data['Change On Year(%)'] < 0) ? '#FF000088' : '#00000000',
    border: (row: RowType) => (+row.data['Change'] < 0  && +row.data['Change On Year(%)'] < 0) ? '2px solid' : '1px solid',
    'border-color': (row: RowType) => (+row.data['Change'] < 0  && +row.data['Change On Year(%)'] < 0) ? '#FF000099' : '#E9E9E9'
};
```

```html
<!-- sample.component.html -->
<igx-grid #grid1 [data]="data | async" [height]="'500px'" width="100%"
        [autoGenerate]="false" [allowFiltering]="true" [rowStyles]="rowStyles">
    ...
</igx-grid>
```

</ComponentBlock>

O componente {ComponentName} do Ignite UI for Angular oferece duas formas de **estilização condicional de células** com base em regras personalizadas.

```ts
}
```

### Usando cellStyles

As colunas agora expõem a propriedade `cellStyles`, que permite a estilização condicional das células da coluna. Semelhante a `cellClasses`, ela aceita um objeto literal em que as chaves são propriedades de estilo e os valores são expressões a serem avaliadas. Além disso, você pode aplicar estilização comum com facilidade (sem nenhuma condição).

No [exemplo acima](#demonstração), criamos:

- Dois estilos diferentes que serão aplicados com base no índice da coluna.
- Você também alterará o `text color` com base em linhas pares/ímpares.

> A assinatura do callback de `cellStyles` é:

```ts
(rowData: any, columnKey: string, cellValue: any, rowIndex: number) => boolean
```

Vamos definir os nossos estilos:

```typescript
// component.ts
public oddColStyles = {
    background: 'linear-gradient(to right, #b993d6, #8ca6db)',
    color: (rowData, columnKey, cellValue, rowIndex) => rowIndex % 2 === 0 ? 'white' : 'gray',
    animation: '0.75s popin'
};

public evenColStyles = {
    background: 'linear-gradient(to right, #8ca6db, #b993d6)',
    color: (rowData, columnKey, cellValue, rowIndex) => rowIndex % 2 === 0 ? 'gray' : 'white',
    animation: '0.75s popin'
};
```

Em `ngOnInit`, adicionaremos a configuração `cellStyles` para cada coluna da coleção predefinida `columns`, que é usada para criar as colunas {ComponentName} dinamicamente.

```ts
public applyCSS() {
    this.columns.forEach((column, index) => {
        column.cellStyles = (index % 2 === 0 ? this.evenColStyles : this.oddColStyles);
    });
}

public updateCSS(css: string) {
    this.oddColStyles = {...this.oddColStyles, ...JSON.parse(css)};
    this.evenColStyles = {...this.evenColStyles, ...JSON.parse(css)};
    this.applyCSS();
}
```

## Problemas conhecidos e limitações

- Se houver células vinculadas à mesma condição (de colunas diferentes) e uma célula for atualizada, as outras células não serão atualizadas com base no novo valor, caso a condição seja atendida.
É preciso executar uma verificação de pipe para aplicar as alterações às demais células. O exemplo abaixo mostra como fazer isso com um `spread operator(...)` no evento <ApiLink type="Grid" member="cellEdit" label="cellEdit" />. Isso copiará o objeto original com uma nova instância, o que fará com que o pipe puro seja disparado.

```ts
public backgroundClasses = {
    myBackground: (rowData: any, columnKey: string) => {
        return rowData.Col2 < 10;
    }
};
...

editDone(evt) {
    this.backgroundClasses = {...this.backgroundClasses};
}

```

<ComponentBlock for="Grid">

```html
<igx-grid #grid1 [data]="data" height="500px" width="100%" (cellEdit)="editDone($event)">
  <igx-column field="Col1" dataType="number" [cellClasses]="backgroundClasses"></igx-column>
  <igx-column field="Col2" dataType="number" [editable]="true" [cellClasses]="backgroundClasses"></igx-column>
  <igx-column field="Col3" header="Col3" dataType="string" [cellClasses]="backgroundClasses"></igx-column>
```
