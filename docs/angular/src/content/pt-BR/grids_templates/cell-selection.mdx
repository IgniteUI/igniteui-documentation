# Seleção de células do Angular

O recurso de seleção oferece recursos avançados de seleção de dados no {ComponentTitle} baseado em Material UI. Uma variedade de eventos e ações de seleção única está disponível graças a uma API poderosa e a métodos fáceis de usar. O {ComponentTitle} agora oferece suporte a três modos de seleção de células, e você pode alternar facilmente entre eles alterando a propriedade <ApiLink type="Grid" member="cellSelection" label="cellSelection" />. Você pode desativar a seleção de células, _selecionar apenas uma célula dentro do grid_ ou _selecionar várias células no grid_, que é a opção padrão.
<ComponentBlock for="HierarchicalGrid">
 No Hierarchical Grid, você pode especificar o modo de seleção de células no nível do grid. Assim, por exemplo, no grid pai pode-se habilitar a seleção de várias células, enquanto nos grids filhos o modo de seleção de células pode ser único ou desabilitado. </ComponentBlock>Mas vamos nos aprofundar em cada uma dessas opções.

## Tipos de seleção

### {ComponentTitle} Seleção de várias células

<ComponentBlock for="HierarchicalGrid">

Este é o modo padrão de seleção de células tanto no grid pai quanto no grid filho. Tenha em mente que você pode fazer a seleção de células em um grid por vez; não é possível fazer seleção de intervalo entre grids nem ter células selecionadas em vários grids. Cada combinação de teclas relacionada à seleção de intervalo e à funcionalidade de arrastar com o mouse só pode ser usada no mesmo grid.
</ComponentBlock>
Como selecionar células:

- Com `Mouse drag` - será feita a seleção retangular de dados das células.
- Com `Ctrl key` pressionado + `Mouse drag` - serão feitas várias seleções de intervalo. Qualquer outra seleção de célula existente será mantida.
- Seleção instantânea de várias células usando a tecla Shift. Selecione uma célula e depois selecione outra célula mantendo a tecla Shift pressionada. O intervalo de células entre as duas será selecionado. Tenha em mente que, se uma segunda célula for selecionada enquanto `Shift key` estiver pressionada, o intervalo de seleção de células será atualizado com base na posição da primeira célula selecionada (ponto inicial).
- Seleção de várias células pelo teclado usando `Arrow keys` enquanto se mantém `Shift key` pressionado. O intervalo de seleção de várias células será criado com base na célula com foco.
- Seleção de várias células pelo teclado usando `Ctrl + Arrow keys` e `Ctrl + Home/End` enquanto se mantém `Shift key` pressionado. O intervalo de seleção de várias células será criado com base na célula com foco.
- Clicar com `Left Mouse key` enquanto se mantém `Ctrl key` pressionado adicionará intervalos de uma única célula à coleção de células selecionadas.
- A seleção contínua de várias células está disponível, clicando com o mouse e arrastando.

### {ComponentTitle} Seleção única

Quando você define `[cellSelection]="'single'"`, é possível ter apenas uma célula selecionada no grid por vez. Além disso, o modo `mouse drag` não funcionará, e, em vez de selecionar uma célula, será feita a seleção de texto padrão.

<DocsAside type="info">
Quando uma única célula é selecionada, o evento <ApiLink type="Grid" member="selected" label="selected" /> é emitido, independentemente de `selection mode` ser `single` ou `multiple`. No modo de seleção de várias células, quando você seleciona um intervalo de células, o evento <ApiLink type="Grid" member="rangeSelected" label="rangeSelected" /> é emitido.
</DocsAside>

### {ComponentTitle} Nenhuma seleção

Se você quiser desativar a seleção de células, basta definir a propriedade `[cellSelection]="'none'"`. Nesse modo, quando você clica sobre a célula ou tenta navegar com o teclado, a célula **não é selecionada**; apenas o `activation style` é aplicado, e ele será perdido quando você rolar ou clicar em outro elemento da página. A única forma de definir a seleção é usando os métodos de API descritos abaixo.

## Interações de navegação por teclado

### Enquanto a tecla Shift estiver pressionada

- <kbd>Shift</kbd> + <kbd>Arrow Up</kbd> para adicionar a célula acima à seleção atual.
- <kbd>Shift</kbd> + <kbd>Arrow Down</kbd> para adicionar a célula abaixo à seleção atual.
- <kbd>Shift</kbd> + <kbd>Arrow Left</kbd> para adicionar a célula à esquerda à seleção atual.
- <kbd>Shift</kbd> + <kbd>Arrow Right</kbd> para adicionar a célula à direita à seleção atual.

### Enquanto as teclas Ctrl + Shift estiverem pressionadas

- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Arrow Up</kbd> para selecionar todas as células acima da célula com foco na coluna.
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Arrow Down</kbd> para selecionar todas as células abaixo da célula com foco na coluna.
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Arrow Left</kbd> para selecionar todas as células até o início da linha.
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Arrow Right</kbd> para selecionar todas as células até o fim da linha.
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Home</kbd> para selecionar todas as células, desde a célula com foco até a primeira célula do grid
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>End</kbd> para selecionar todas as células, desde a célula com foco até a última célula do grid

<DocsAside type="info">
A rolagem contínua só é possível dentro do corpo do Grid.
</DocsAside>

<ComponentBlock for="HierarchicalGrid">

<ApiLink type="HierarchicalGrid" member="selectRange" label="selectRange(range)" /> - Seleciona um intervalo de células com a API. `rowStart` e `rowEnd` devem usar índices de linha, e `columnStart` e `columnEnd` podem usar o índice da coluna ou o valor do campo de dados da coluna.

```typescript
const range = { rowStart: 2, rowEnd: 2, columnStart: 1, columnEnd: 1 };

this.grid1.selectRange(range);

```

<DocsAside type="info">
Selecionar intervalo é uma operação aditiva. Ela não limpará a sua seleção anterior.
</DocsAside>

## Integração de recursos

A seleção de várias células é baseada em índices (seleção de elementos DOM).

- `Sorting` - Quando a ordenação é realizada, a seleção não é limpa. As células selecionadas no momento permanecem as mesmas durante a ordenação crescente ou decrescente.
- `Paging` - Na paginação, as células selecionadas serão limpas. A seleção não é mantida entre as páginas.
- `Filtering` - Quando a filtragem é realizada, a seleção não é limpa. Se a filtragem for removida, retornará às células inicialmente selecionadas.
- `Resizing` - No redimensionamento de colunas, as células selecionadas não serão limpas.
- `Hiding` - Não limpa as células selecionadas. Se a coluna for ocultada, as células da próxima coluna visível serão selecionadas.
- `Pinning` - A célula selecionada não será limpa. Igual à ocultação
- `Group by` - No agrupamento de colunas, as células selecionadas não serão limpas.

</ComponentBlock>

## Estilização

O mecanismo de temas expõe propriedades que nos permitem estilizar o **intervalo de células selecionadas**.

### Importar o tema

Para começar a estilizar a seleção, precisamos importar o arquivo `index`, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### Definir as cores

Depois disso, podemos usar as funções <ApiLink kind="sass" module="palettes" type="function-contrast-color" label="contrast-color" code={true} /> e <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Com elas, definimos as cores que queremos usar para o intervalo de seleção:

```scss
$text-color: contrast-color($color: 'primary', $variant: 900);
$background-color: color($color: "primary", $variant: 900);
$border-yellow: #f2c43c;
```

<DocsAside type="info">
Se não quisermos usar as funções `contrast-color` e `color`, podemos sempre definir os valores de cor diretamente no código.
</DocsAside>

### Criar tema personalizado

Em seguida, criamos um novo tema que estende o <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />, passando as nossas variáveis `text-color`, `background-color` e `border-yellow` como `$cell-selected-text-color`, `$cell-selected-background` e `$cell-active-border-color`, respectivamente:

```scss
$custom-grid-theme: grid-theme(
  $cell-selected-text-color: $text-color,
  $cell-active-border-color: $border-yellow,
  $cell-selected-background: $background-color
);
```

### Aplicar o tema

Depois, tudo o que precisamos fazer é incluir o mixin no estilo do nosso componente (também pode ser nos estilos da aplicação), para que o nosso {ComponentSelector} use o tema recém-criado em vez do padrão:

```scss
:host {
  @include tokens($custom-grid-theme);
}
```

Com o tema personalizado aplicado, as células selecionadas do grid são destacadas com as nossas cores de seleção:
