# Edição do {ComponentTitle} do Angular

O componente {ComponentTitle} do Ignite UI for Angular oferece uma forma fácil de realizar operações de manipulação de dados, como criar, atualizar e excluir registros. As fases de manipulação de dados são: [Edição de célula](/{igPath}/cell-editing), [Edição de linha](/{igPath}/row-editing) e [Edição em lote](/{igPath}/batch-editing). O {ComponentTitle} oferece uma API pública poderosa, que permite personalizar a forma como essas operações são realizadas. Além disso, a **edição de célula** expõe vários editores padrão com base no tipo de dado da coluna, que podem ser facilmente personalizados por meio da diretiva [igxCellEditor](/{igPath}/cell-editing#templates-de-edição-de-célula) ou das diretivas [igxRow](/{igPath}/row-editing#personalizando-o-overlay-de-edição-de-linhas).

## Configuração

Para especificar qual modo de edição deve ser habilitado, o {ComponentTitle} expõe as seguintes propriedades booleanas: <ApiLink type="Column" member="editable" label="editable" /> e <ApiLink type="Grid" member="rowEditable" label="rowEditable" />.

A propriedade **editable** permite especificar as seguintes opções:

- **false** - a edição da coluna correspondente será desabilitada; /valor padrão/
- **true** - a edição da coluna correspondente será habilitada;

>Tenha em mente que, se a coluna não for editável, você ainda pode modificar o seu valor pela API pública exposta pelo {ComponentTitle}.

A propriedade **rowEditable** permite especificar as seguintes opções:

- **false** - a edição de linha no grid correspondente será desabilitada; /valor padrão/
- **true** - a edição de linha no grid correspondente será habilitada;

No {ComponentTitle}, se você definir a propriedade rowEditable como true e a propriedade editable não for definida explicitamente em nenhuma coluna, a edição será habilitada para todas as colunas, exceto a _chave primária_.

A **edição em lote** no grid pode ser habilitada tanto para o modo de **edição de célula** quanto para o modo de **edição de linha**. Para configurar a edição em lote, é necessário fornecer ao grid um _TransactionService_.

- _Edição de célula e em lote_ - nesse cenário, cada modificação de cada célula é preservada separadamente, e as operações de desfazer/refazer estão disponíveis no nível da célula;
- _Edição de linha e em lote_ - nesse cenário, as modificações são preservadas no nível da linha; por isso, as operações de desfazer/refazer não funcionarão para cada célula modificada, mas para o conjunto de células de cada linha.

### Templates de edição

 Se você quiser usar _templates de edição_ específicos para o tipo de dado, deve especificar a propriedade <ApiLink type="Column" member="dataType" label="dataType" /> da coluna. Vamos ver agora quais são os templates padrão para cada tipo:

- Para o tipo de dado `string`, o template padrão usa <ApiLink type="InputDirective" label="igxInput" />
- Para o tipo de dado `number`, o template padrão usa <ApiLink type="InputDirective" label="igxInput" /> type="number"; portanto, se você tentar atualizar a célula com um valor que não possa ser convertido em número, a sua alteração será descartada e o valor da célula será definido como 0.
- Para o tipo de dado `date`, o template padrão usa <ApiLink type="DatePicker" label="igxDatePicker" />
- Para o tipo de dado `dateTime`, o template padrão usa <ApiLink type="DateTimeEditorDirective" />. Este editor oferece orientações de máscara para os elementos de entrada que fazem parte do objeto DateTime.
- Para o tipo de dado `date`, o template padrão usa <ApiLink type="DatePicker" />.
- Para o tipo de dado `time` -, o template padrão usa <ApiLink type="TimePicker" />.
- Para o tipo de dado `boolean`, o template padrão usa <ApiLink type="Checkbox" label="igxCheckbox" />
- Para o tipo de dado `currency`, o template padrão usa <ApiLink type="InputGroup" /> com configuração de prefixo/sufixo com base nas configurações de localidade da aplicação ou do grid.
- Para o tipo de dado `percent`, o template padrão usa <ApiLink type="InputGroup" /> com um elemento de sufixo que mostra uma prévia do valor editado em porcentagem.
- Para templates personalizados, veja o [tópico de edição de célula](/{igPath}/cell-editing#templates-de-edição-de-célula)

Todos os tipos de dados de coluna disponíveis podem ser encontrados no tópico oficial [Tipos de coluna](/{igPath}/column-types#template-padrão).

#### Editores de template padrão das colunas de data e hora

Os editores de template dos tipos de dados de coluna `date`, `dateTime` e `time` usam um formato de entrada padrão, de acordo com o `IgxGrid` do <ApiLink type="Grid" member="locale" label="locale" />.

Caso a propriedade `format` do objeto <ApiLink kind="interface" type="ColumnType" member="pipeArgs" /> seja definida na coluna, o formato de entrada dos editores será inferido a partir dela. A condição é que ela possa ser interpretada como contendo apenas partes numéricas de data e hora.

Se o formato de entrada dos editores precisar ser definido explicitamente, pode-se usar o objeto <ApiLink kind="interface" type="ColumnType" member="editorOptions" /> do tipo <ApiLink type="IColumnEditorOptions" kind="interface" />. Ele aceita uma propriedade `dateTimeFormat`, que é usada como formato de entrada para os editores dos tipos de dado de coluna `date`, `dateTime` e `time`.

```typescript
const editorOptions: IColumnEditorOptions = {
    dateTimeFormat: 'MM/dd/YYYY',
}
```

```html
<igx-column field="sampleDate" dataType="date" [editorOptions]="editorOptions"></igx-column>
```

### Argumentos e sequência de eventos

A grade expõe um grande conjunto de eventos que oferecem maior controle sobre a experiência de edição. Esses eventos são disparados durante o ciclo de vida da [**Edição de linhas**](/{igPath}/row-editing) e da [**Edição de células**](/{igPath}/cell-editing) - ao iniciar, confirmar ou cancelar a ação de edição.

 | Evento | Descrição | Argumentos | Cancelável |
|-------|-------------|-----------|-------------|
| <ApiLink type="{ComponentApiType}" member="rowEditEnter" label="rowEditEnter" /> | Se `rowEditing` estiver habilitado, é disparado quando uma linha entra no modo de edição | <ApiLink type="IGridEditEventArgs" kind="interface" /> | `true` |
| <ApiLink type="{ComponentApiType}" member="cellEditEnter" label="cellEditEnter" /> | Disparado quando uma célula **entra no modo de edição** (depois de `rowEditEnter`) | <ApiLink type="IGridEditEventArgs" kind="interface" /> | `true` |
| <ApiLink type="{ComponentApiType}" member="cellEdit" label="cellEdit" /> | Se o valor for alterado, é disparado logo **antes** de o valor de uma célula ser **confirmado** (por exemplo, ao pressionar `Enter`) | <ApiLink type="IGridEditEventArgs" kind="interface" /> | `true` |
| <ApiLink type="{ComponentApiType}" member="celleditdone" label="cellEditDone" /> | Se o valor for alterado, é disparado **depois** de uma célula ser editada e o valor da célula ser **confirmado** | <ApiLink type="IGridEditDoneEventArgs" kind="interface" /> | `false` |
| <ApiLink type="{ComponentApiType}" member="cellEditExit" label="cellEditExit" /> | Disparado quando uma célula **sai do modo de edição** | <ApiLink kind="interface" type="IGridEditEventArgs" /> | `false` |
| <ApiLink type="{ComponentApiType}" member="rowEdit" label="rowEdit" /> | Se `rowEditing` estiver habilitado, é disparado logo antes de o valor de uma linha em modo de edição ser **confirmado** (por exemplo, ao clicar no botão `Done` do Row Editing Overlay) | <ApiLink type="IGridEditEventArgs" kind="interface" /> | `true` |
| <ApiLink type="{ComponentApiType}" member="rowEditDone" label="rowEditDone" /> | Se `rowEditing` estiver habilitado, é disparado **depois** de uma linha ser editada e o valor da nova linha ser **confirmado**. | <ApiLink kind="interface" type="IGridEditEventArgs" /> | `false` |
| <ApiLink type="{ComponentApiType}" member="rowEditExit" label="rowEditExit" /> | Se `rowEditing` estiver habilitado, é disparado quando uma linha **sai do modo de edição** | <ApiLink kind="interface" type="IGridEditEventArgs" /> | `false` |

### Cancelamento de evento

- `RowEditEnter` - Nem a linha nem a célula entrarão em modo de edição.
- `CellEditEnter` - Impede a entrada na edição de célula. Se <ApiLink type="Grid" member="rowEditable" label="rowEditable" /> estiver habilitado, a edição de linha será acionada, embora a edição de célula continue proibida.
- `CellEdit` - A edição de célula/linha é permitida, mas clicar em **Done** ou pressionar **Enter** não confirma o valor nem a transação da linha. A edição de célula e a de linha não serão fechadas até que o botão **Cancel** seja clicado.
- `RowEdit` - É possível confirmar a célula, mas não a linha inteira. A linha permanecerá em modo de edição, e a transação da linha será considerada aberta. Clicar em **Done** não confirma nem fecha a linha. O botão **Cancel** fecha o processo de edição e a transação sem confirmar as alterações.

### Integração de recursos

Enquanto uma célula/linha está em modo de edição, o usuário pode interagir com o grid de várias formas. A tabela a seguir especifica como determinada interação afeta a edição atual:

| {ComponentTitle}     | Filtragem  | Ordenação | Paginação | Movimentação | Fixação | Ocultação | GroupBy | Redimensionamento | Escape | Enter | F2 | Tab | Clique na célula | Adicionar nova linha/Excluir/Editar |
| ----------------- |:---------:|:-------:|:------:|:------:|:-------:|:------:|:-------:|:--------:|:------:|:-----:|:--:|:---:|:----------:|:-----------------------:|
| Manter modo de edição    |           |      |   |   |   |   |   | ✔ |   |   |   |   |   |   |
| Sair do modo de edição    |✔         | ✔ | ✔ | ✔ | ✔ | ✔ | ✔ |   | ✔ | ✔ | ✔ | ✔ | ✔ | ✔ |
| Confirmar            |   |   |  |  |  |   |   |   |  | ✔ | ✔ | ✔ | ✔ | ✔ |
| Descartar           | ✔ | ✔ | ✔ | ✔ | ✔ | ✔ |✔ |   | ✔  |  |   |   |   |  |

Como visto na tabela, todas as interações, exceto o redimensionamento de uma coluna, encerrarão a edição e descartarão os novos valores. Se o novo valor for confirmado, isso pode ser feito pelo desenvolvedor no evento "-ing" correspondente do recurso.

Exemplo de como confirmar novos valores se o usuário tentar ordenar a coluna enquanto uma célula/linha está em modo de edição:

```html
<igx-grid #grid [data]="localData" [primaryKey]="'ProductID'" (sorting)="onSorting($event)">
...
</igx-grid>
```

```typescript
public onSorting(event: ISortingEventArgs) {
    this.grid.endEdit(true);
    // (event.owner as IgxGridComponent).endEdit(true);
}
```
