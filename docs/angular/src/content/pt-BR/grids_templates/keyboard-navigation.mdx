# Navegação por teclado do {ComponentTitle} do Angular

 A navegação por teclado no **{ComponentName}** oferece uma grande variedade de interações por teclado para o usuário. Ela melhora a acessibilidade do **{ComponentName}** e permite navegar por qualquer tipo de elemento interno (célula, linha, cabeçalho de coluna, barra de ferramentas, rodapé etc.). Esse recurso vem habilitado por padrão, e o desenvolvedor tem a opção de substituir qualquer um dos comportamentos padrão de forma simples.

A quantidade de paradas de tabulação do {ComponentName} foi reduzida, para que a navegação esteja em conformidade com os padrões de acessibilidade W3C e seja prática de usar.

Atualmente, o {ComponentName} introduz as seguintes paradas de tabulação:

- **Área de GroupBy ou da barra de ferramentas** (se habilitada);
- **Cabeçalho do {ComponentName}**;
- **Corpo do {ComponentName}**;
- **Resumos de coluna** (se habilitados);
- **Paginador do {ComponentName}** (se habilitado);

<DocsAside type="info">
Por causa dessa mudança, a navegação entre as células com <kbd>tab</kbd> e <kbd>Shift + Tab</kbd> não é mais suportada no {ComponentName}.
Ao pressionar a tecla <kbd>Tab</kbd>, as paradas de tabulação são percorridas na seguinte ordem: **GroupBy** / **Barra de ferramentas** -> **Cabeçalhos** -> **Corpo** -> **Resumos** -> **Rodapé / Paginador**.
</DocsAside>

<DocsAside type="info">
Expor qualquer elemento **focável** no corpo do **{ComponentName}** por meio de template pode introduzir **efeitos colaterais** na navegação por teclado, já que o comportamento padrão do navegador não é impedido. É responsabilidade do desenvolvedor impedi-lo ou modificá-lo adequadamente.
</DocsAside>

## Navegação pelo cabeçalho

Agora há suporte completo para _navegação por teclado_ no cabeçalho do **{ComponentName}**. Os cabeçalhos de coluna podem ser percorridos facilmente com as teclas de seta. Além disso, há várias combinações de teclas que disparam ações nas colunas, como **filtragem**, **ordenação**, **agrupamento** etc.
Quando o contêiner de cabeçalho **{ComponentName}** está com foco, as seguintes combinações de teclas estão disponíveis:

### Combinações de teclas

- <kbd>Arrow Up</kbd> navega uma célula para cima nos cabeçalhos (sem repetir). Disponível somente quando o Multi-row Layout (MRL) ou os Multi-column Headers (MCH) estão definidos
- <kbd>Arrow Down</kbd> navega uma célula para baixo nos cabeçalhos (sem quebra). Disponível somente quando o Multi-row Layout (MRL) ou os Multi-column Headers (MCH) estão definidos
- <kbd>Arrow Left</kbd> navega uma célula para a esquerda (sem repetir)
- <kbd>Arrow Right</kbd> navega uma célula para a direita (sem quebra entre linhas)
- <kbd>Ctrl + Arrow Left</kbd> navega até a célula mais à esquerda da linha; se o MRL ou o MCH estiverem habilitados, navega até a célula mais à esquerda no mesmo nível
- <kbd>Home</kbd> navega até a célula mais à esquerda da linha; se o MRL ou o MCH estiverem habilitados, navega até a célula mais à esquerda no mesmo nível
- <kbd>Ctrl + Arrow Right</kbd> navega até a célula mais à direita da linha; se o MRL ou o MCH estiverem habilitados, navega até a célula mais à direita no mesmo nível
- <kbd>End</kbd> navega até a célula mais à direita da linha; se o MRL ou o MCH estiverem habilitados, navega até a célula mais à direita no mesmo nível
- <kbd>Alt + L</kbd> abre a caixa de diálogo de Filtragem Avançada, se a Filtragem Avançada estiver habilitada
- <kbd>Ctrl + Shift + L</kbd> abre a caixa de diálogo de filtragem estilo Excel ou o filtro padrão (de linha), se a coluna for filtrável
- <kbd>Ctrl + Arrow Up</kbd> ordena o cabeçalho da coluna ativa em ordem ASC. Se a coluna já estiver ordenada em ASC, o estado de ordenação é limpo
- <kbd>Ctrl + Arrow Down</kbd> ordena o cabeçalho da coluna ativa em ordem DSC. Se a coluna já estiver ordenada em DSC, o estado de ordenação é limpo
- <kbd>Space</kbd> seleciona a coluna; se a coluna já estiver selecionada, a seleção é limpa
<ComponentBlock for="Grid">
- <kbd>Shift + Alt + Arrow Left</kbd> agrupa a coluna, se a coluna estiver marcada como agrupável
- <kbd>Shift + Alt + Arrow Right</kbd> desagrupa a coluna, se a coluna estiver marcada como agrupável
- <kbd>Alt + Arrow Left</kbd> ou <kbd>Alt + Arrow Up</kbd> recolhe o cabeçalho do grupo de colunas, se ele ainda não estiver recolhido
- <kbd>Alt + Arrow Right</kbd> ou <kbd>Alt + Arrow Down</kbd> expande o cabeçalho do grupo de colunas, se ele ainda não estiver expandido

## Navegação por teclado personalizada

Substituir o comportamento padrão de uma tecla ou de uma combinação de teclas é um dos benefícios que o recurso de **Navegação por teclado** oferece. Por exemplo: pressionar a tecla <kbd>Enter</kbd> ou <kbd>Tab</kbd> para navegar até a próxima célula ou a célula abaixo. Este ou qualquer outro cenário de navegação é facilmente obtido pela API de **Navegação por teclado**:

public childGridCreated(event: IGridCreatedEventArgs) {
    const grid = event.grid;
    event.grid.gridKeydown.subscribe((args) => {
        this.customKeydown(args, grid);
    });
}
```

public customKeydown(args: IGridKeydownEventArgs) {
    const target: IgxGridCell = args.target as IgxGridCell;
    const evt: KeyboardEvent = args.event as KeyboardEvent;
    const type = args.targetType;

    if (type === 'dataCell' && target.inEditMode && evt.key.toLowerCase() === 'tab') {
        // 1. USER INPUT VALIDATION ON TAB
    }
    if (type === 'dataCell' && evt.key.toLowerCase() === 'enter') {
        // 2. CUSTOM NAVIGATION ON ENTER KEY PRESS
    }
}
```

Com base nos valores de <ApiLink type="IGridKeydownEventArgs" kind="interface" />, identificamos dois casos em que devemos fornecer a nossa própria lógica (veja acima). Agora, usando os métodos da API, vamos executar o desejado: se o usuário pressionar a tecla <kbd>Tab</kbd> sobre uma célula em modo de edição, faremos a validação da entrada. Se o usuário pressionar a tecla <kbd>Enter</kbd> sobre uma célula, moveremos o foco para a célula da linha seguinte:
