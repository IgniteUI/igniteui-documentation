# Visão geral dos cabeçalhos de várias colunas do {ComponentTitle} do Angular

O <ApiLink type="{ComponentApiType}" /> oferece suporte a `multi-column headers`, que permitem agrupar colunas colocando-as sob um cabeçalho múltiplo comum. Cada grupo de cabeçalhos de várias colunas pode representar combinações entre outros grupos ou colunas dentro do grid Material UI.

Cada <ApiLink type="ColumnGroup" label="igx-column-group" /> oferece suporte a [`moving`](/{igPath}/column-moving), [`pinning`](/{igPath}/column-pinning) e [`hiding`](/{igPath}/column-hiding).
<DocsAside type="info">
Quando há um conjunto de colunas e grupos de colunas, a fixação funciona apenas para os pais de colunas do nível superior. Mais especificamente, a fixação por `column groups` ou `columns` aninhado não é permitida. <br />
Tenha em mente que, ao usar a fixação com Cabeçalhos de várias colunas, o grupo inteiro é fixado. <br />
A movimentação entre `columns` e `column groups` é permitida somente quando estão no mesmo nível da hierarquia e ambos estão no mesmo `group`. <br />
Quando `columns/column-groups` não estão envolvidas pelo `group` atual, o que significa que estão no **nível superior** `columns`, a movimentação é permitida entre todas as colunas visíveis.
</DocsAside>

## Template do cabeçalho de várias colunas

Cada um dos grupos de colunas do grid pode ter template definido separadamente. O grupo de colunas espera uma tag `ng-template` decorada com a diretiva `igxHeader`.
O `ng-template` recebe o objeto do grupo de colunas como contexto.

```html
...
<igx-column-group header="General Information">
    <ng-template igxHeader let-columnGroup>
        {{ columnGroup.header | uppercase }}
    </ng-template>
    ...
</igx-column-group>
...
```

Se você quiser reutilizar um único template para vários grupos de colunas, pode definir a propriedade <ApiLink type="ColumnGroup" member="headertemplate" label="headerTemplate" /> do grupo de colunas assim:

```html
<ng-template #columnGroupHeaderTemplate let-columnGroup>
    {{ columnGroup.header | uppercase }}
</ng-template>

...
<igx-column-group header="General Information" [headerTemplate]="columnGroupHeaderTemplate">
    ...
</igx-column-group>
<igx-column-group header="Address Information" [headerTemplate]="columnGroupHeaderTemplate">
    ...
</igx-column-group>
...
```

<DocsAside type="info">
Se um cabeçalho de coluna for redefinido por template e a movimentação do grid estiver habilitada, você deve definir o atributo **draggable** da coluna correspondente como **false** nos elementos com template, para que possa tratar quaisquer eventos aplicados!
</DocsAside>

```html
<ng-template igxHeader>
    <igx-icon [attr.draggable]="false" (click)="onClick()"></igx-icon>
</ng-template>
```

## Estilização

Para começar a estilizar o comportamento de ordenação, precisamos importar o arquivo `index`, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Seguindo a abordagem mais simples, criamos um novo tema que estende o <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> e aceita os parâmetros `$header-background`, `$header-text-color`, `$header-border-width`, `$header-border-style` e `$header-border-color`.

<ComponentBlock for="Grid">

```scss
$custom-theme: grid-theme(
  $header-background: #e0f3ff,
  $header-text-color: #e41c77,
  $header-border-width: 1px,
  $header-border-style: solid,
  $header-border-color: rgba(0, 0, 0, 0.08)
);
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```scss
$custom-theme: grid-theme(
  $header-background: #f1eaf6,
  $header-text-color: #8c1bdd,
  $header-border-width: 1px,
  $header-border-style: solid,
  $header-border-color: #d3b9e6,
  $cell-active-border-color: #7409c1
);
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```scss
$custom-theme: grid-theme(
  $header-background: #f8f8ed,
  $header-text-color: #7a6551,
  $header-border-style: dashed,
  $header-border-color: rgba(0, 0, 0, 0.08)
);
```

</ComponentBlock>

<DocsAside type="info">
Em vez de definir os valores de cor diretamente, como acabamos de fazer, podemos obter mais flexibilidade em relação às cores usando as funções <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> e <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Consulte o tópico [`Palettes`](/themes/sass/palettes) para orientações detalhadas sobre como usá-las.
</DocsAside>

A última etapa é aplicar o tema do componente com `tokens()`:

```scss
:host {
  @include tokens($custom-theme);
}
```
