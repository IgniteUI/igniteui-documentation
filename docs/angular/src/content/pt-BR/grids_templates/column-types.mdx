# Tipos de coluna do {ComponentTitle} do Angular

O {ComponentTitle} do Ignite UI for Angular oferece um tratamento padrão para os tipos de dados de coluna _number_, _string_, _date_, _boolean_, _currency_ e _percent_, com base nos quais a aparência dos templates padrão e de edição será definida.

## Template padrão

Se você quiser habilitar um template específico para o tipo de dado, deve definir a entrada <ApiLink type="Column" member="dataType" label="dataType" /> da coluna; caso contrário, a coluna será tratada como uma coluna de string, pois esse é o valor padrão de dataType da coluna. Vamos ver quais são os templates padrão de cada tipo.

### String

Esta coluna <ApiLink type="Column" member="dataType" label="dataType" /> não altera a aparência nem o formato do valor da célula.

### Número

Se o <ApiLink type="Column" member="dataType" label="dataType" /> for definido como _number_, o valor da célula será formatado com base nas configurações de aplicação ou de <ApiLink type="Grid" member="locale" label="locale" /> do grid, assim como quando a propriedade <ApiLink type="Column" member="pipeArgs" label="pipeArgs" /> for especificada. Então, o formato numérico será alterado com base nelas; por exemplo, pode mudar:

- Número de dígitos após o ponto decimal
- Separador decimal com `,` ou `.`

```ts
public options = {
  digitsInfo: '1.4-4',
};
public formatOptions = this.options;
```

```html
<igx-column [pipeArgs]="formatOptions" [dataType]="'number'">
</igx-column>
```

### DateTime, Date e Time

A aparência das partes da data (por exemplo, dia, mês, ano) será definida com base no formato <ApiLink type="Grid" member="locale" label="locale" /> ou na entrada <ApiLink type="Column" member="pipeArgs" label="pipeArgs" />. Os argumentos do pipe podem ser usados para especificar um [formato de data](https://angular.io/api/common/DatePipe#pre-defined-format-options) ou um [fuso horário](https://angular.io/api/common/DatePipe#parameters) personalizados:

- **format** - O valor padrão para formatar a data é 'mediumDate'. Outras opções disponíveis são 'short', 'long', 'shortDate', 'fullDate', 'longTime', 'fullTime' etc. Esta é a lista completa de todas as [opções de formato predefinidas do Angular](https://angular.io/api/common/DatePipe#pre-defined-format-options) (legado).
- **timezone** - O fuso horário local do sistema do usuário é o valor padrão. Também é possível passar o deslocamento de fuso horário, ou a abreviação padrão GMT/UTC ou de fuso horário continental dos EUA. Exemplos de fusos horários diferentes que exibirão o horário correspondente de qualquer lugar do mundo:

<DocsAside type="info">
Desde a versão 20.2.x, se a localização do Angular estiver desabilitada, a lista de opções de formato disponíveis pode ser encontrada no nosso novo [tópico de localização](../general/localization.mdx#formatting).
</DocsAside>

```ts
public formatDateOptions = {
    /** The date/time components that a date column will display, using predefined options or a custom format string. */
    /** e.g 'dd/mm/yyyy' or 'shortDate' **/
    format: 'longDate',
    /** A timezone offset (such as '+0430'), or a standard UTC/GMT or continental US timezone abbreviation. */
    timezone: 'GMT'
};
public formatOptions = this.options;
```

```html
<igx-column [pipeArgs]="formatDateOptions" [dataType]="'date'">
</igx-column>
```

Como você pode ver no exemplo, especificamos opções de formato diferentes para mostrar os formatos disponíveis para o tipo de coluna específico. Por exemplo, abaixo você encontra as opções de formato para a parte de _hora_ do objeto de data:

```ts
// Time format with equivalent example
public timeFormats = [
    { format: 'shortTime', eq: 'h:mm a' },
    { format: 'mediumTime', eq: 'h:mm:ss a' },
    { format: 'longTime', eq: 'h:mm:ss a z' },
    { format: 'fullTime', eq: 'h:mm:ss a zzzz' },
];
```

#### Edição de célula

Quando se trata de edição de célula com base no tipo de coluna, um editor diferente aparecerá:

- dateTime - será usado <ApiLink type="DateTimeEditorDirective" />. Este editor oferece orientações de máscara para os elementos de entrada que fazem parte do objeto DateTime.
- date - será usado <ApiLink type="DatePicker" />.
- time - será usado <ApiLink type="TimePicker" />.

#### Filtragem

Os mesmos editores listados acima serão usados na filtragem rápida/filtragem estilo Excel. Estes são os operandos de filtragem que cada tipo expõe:

- dateTime e date - Equals, Does Not Equal, Before, After, Today, Yesterday, This Month, Last Month, Next Month, This Year, Last Year, Next Year, Empty, Not Empty, Null, Not Null;
- hora - É, Não é, Antes, Depois, Antes ou igual, Depois ou igual, Vazio, Não vazio, Nulo, Não nulo;

#### Resumos

Os operandos de resumo disponíveis serão **Count**, **Earliest** (data/hora) e **Latest** (data/hora).

#### Ordenação

A coluna do tipo Time é ordenada com base na parte de hora do objeto; os milissegundos serão desconsiderados.
A coluna do tipo Date é ordenada com base na parte da data, desconsiderando a parte da hora.
A coluna DateTime é ordenada com base na data completa

### Booleano

O template padrão usa ícones do Material para visualizar valores booleanos: o ícone 'clear' para valores _false_ e o ícone 'check' para valores _true_. Já o template de edição usa o componente <ApiLink type="Checkbox" label="igx-checkbox" />.

```html
<igx-column [dataType]="'boolean'">
</igx-column>
```

### Moeda

#### Template padrão

O template padrão exibirá um valor numérico com o símbolo de moeda, que pode ser prefixado ou sufixado. Tanto a posição do símbolo de moeda quanto a formatação do valor numérico são baseadas na [`LOCALE_ID`](https://angular.io/api/core/LOCALE_ID) da aplicação fornecida ou em {ComponentTitle} <ApiLink type="Grid" member="locale" label="locale" />.

_Usando LOCALE_ID_

```ts

...

 @Component({
    selector: 'app-component.sample',
    templateUrl: 'grid-component.sample.html',
    providers: [{provide: LOCALE_ID, useValue: 'fr-FR' }]
})
```

_Usando a localidade do Grid_

```html
<igx-grid [locale]="'fr-FR'" [data]="data">
</igx-grid>
```

Usando a entrada <ApiLink type="Column" member="pipeArgs" label="pipeArgs" />, o usuário final pode personalizar o formato numérico por _ponto decimal_, _currencyCode_ e _display_.

```ts
public options = {
  digitsInfo: '3.4-4',
  currencyCode: 'USD',
  display: 'symbol-narrow'
};
public formatOptions = this.options;
```

```html
<igx-column field="UnitsInStock"
    [pipeArgs]="formatOptions"
    [dataType]="'currency'">
</igx-column>
```

| Parâmetro                 | Descrição                                                |
|---------------------------| -------------------------                                  |
| digitsInfo                | Representa a representação decimal do valor monetário        |
| currencyCode              | Código de moeda ISO 4217                                     |
| display*                  | Exibe o valor pelo símbolo estreito ou largo                |

*display - para a localidade padrão en-US, o código USD pode ser representado pelo símbolo estreito $ ou pelo símbolo largo US$.

Ao editar o valor da célula, o _símbolo de moeda_ ficará visível como sufixo ou prefixo. Mais informações sobre isso podem ser encontradas no tópico oficial [Edição de célula](/{igPath}/cell-editing#templates-de-edição-de-célula).

### Percentual

O template padrão mostra o equivalente percentual do valor numérico subjacente. O valor exibido na célula é o resultado de uma multiplicação pelo fator de exibição de '100' — por exemplo, como o fator padrão é 100 e o "valor" passado à célula é 0,123, o valor exibido na célula será "12.3%".

Na edição de célula, o valor será o mesmo do valor da fonte de dados — o fator de exibição é '1'. Ao editar a célula, uma prévia do valor percentual será mostrada como um elemento de sufixo. Por exemplo, ao editar '0.0547', o elemento de prévia mostrará '5.47%'.

```ts
public options = {
    /**
    * Decimal representation options, specified by a string in the following format:
    * `{minIntegerDigits}`.`{minFractionDigits}`-`{maxFractionDigits}`.
    * `minIntegerDigits`: The minimum number of integer digits before the decimal point. Default is 1.
    * `minFractionDigits`: The minimum number of digits after the decimal point. Default is 0.
    * `maxFractionDigits`: The maximum number of digits after the decimal point. Default is 3.
    */
    digitsInfo: '2.2-3'
};
public formatPercentOptions = this.options;
```

```html
<igx-column field="UnitsInStock"
    [pipeArgs]="formatPercentOptions"
    [dataType]="'percent'">
</igx-column>
```

<DocsAside type="info">
Ao usar as teclas de seta para cima/baixo, o valor será incrementado/decrementado com um passo baseado em digitsInfo - minFractionDigits (o número mínimo de dígitos após o ponto decimal. O padrão é 0)
</DocsAside>

### Imagem

O template padrão usa o valor vindo dos dados como fonte de imagem para um template de imagem padrão. O template de imagem padrão extrai o nome do arquivo de imagem e o define como o atributo `alt` da imagem, para atender ao requisito de acessibilidade. O tamanho da célula exibida é ajustado aos tamanhos das imagens renderizadas; por isso, tenha em mente que imagens grandes ainda serão renderizadas e as linhas do grid ficarão tão grandes quanto as imagens na coluna de imagem. Filtragem, ordenação e agrupamento ficam desativados por padrão em colunas do tipo imagem. Se quiser habilitá-los, você precisa fornecer estratégias personalizadas que executem as operações de dados.

```html
<igx-column [dataType]="'image'">
</igx-column>
```

Ao <ApiLink type="Grid" member="autoGenerate" label="auto-generating" /> colunas, o grid analisa os valores do primeiro registro de dados. Se um valor for do tipo string e corresponder ao padrão de uma URL que termina com uma extensão de imagem (gif, jpg, jpeg, tiff, png, webp, bmp), a coluna será automaticamente marcada como `dataType === GridColumnDataType.Image` e um template de imagem padrão será renderizado.

## Template de edição e formatador personalizados

A definição de template personalizado e de formatador de coluna sempre terá precedência sobre o tipo de dado de coluna definido:

### Template personalizado

```html
<igx-grid #grid1 [data]="data | async" [autoGenerate]="false">
    <igx-column [field]="'UnitsInStock'" [dataType]="'currency'" [pipeArgs]="formatOptions" [editable]="true">
        <ng-template igxCellEditor let-value>
            {{ value | currency:'USD':'symbol':'1.0-0'}}
        </ng-template>
    </igx-column>
</igx-grid>
```

### Formatador de coluna

```ts
 // Through column formatter property
public formatCurrency(value: number) {
    return `Dollar sign ${value.toFixed(0)}`;
}

public init(column: IgxColumnComponent) {
    switch (column.field) {
        case 'UnitsInStock':
            column.formatter = this.formatCurrency;
            break;
        default:
            return;
}
```
