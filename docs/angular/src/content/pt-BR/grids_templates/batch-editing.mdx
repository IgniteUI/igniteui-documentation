## Uso

Para começar, importe o `{ComponentName}Module` no arquivo **app.module.ts**:

```typescript
// app.module.ts

...
import { {ComponentName}Module } from 'igniteui-angular';

@NgModule({
    ...
    imports: [..., {ComponentName}Module],
    ...
})
export class AppModule {}
```

Depois, tudo o que você precisa fazer é habilitar `batchEditing` a partir do seu {ComponentTitle}:

```html
<{ComponentSelector} [data]="data" [batchEditing]="true">
  ...
</{ComponentSelector}>
```

Isso garantirá que uma instância adequada do serviço `Transaction` seja fornecida para o {ComponentSelector}. A `TransactionService` adequada é fornecida por meio de uma `TransactionFactory`. Você pode saber mais sobre essa implementação interna no tópico [transações](/transaction-classes#factory-de-transações).

Depois de habilitar a edição em lote, defina um `{ComponentName}` com uma fonte de dados vinculada e <ApiLink type="{ComponentApiType}" member="rowEditable" label="rowEditable" /> definido como true, e faça a vinculação:

```html

    [rowEditable]="true">

<button igxButton [disabled]="!grid.transactions.canUndo" (click)="undo()">Undo</button>
```

O código a seguir demonstra o uso da API do <ApiLink type="GridComponent" member="transactions" /> — desfazer, refazer e confirmar.

```typescript
export class GridBatchEditingSampleComponent {
    @ViewChild('grid', { read: IgxGridComponent }) public gridRowEditTransaction: IgxGridComponent;

    public undo() {
        /* exit edit mode and commit changes */
        this.grid.endEdit(true);
        this.grid.transactions.undo();
    }

    public redo() {
        /* exit edit mode and commit changes */
        this.grid.endEdit(true);
        this.grid.transactions.redo()
    }

    public commit() {
        this.grid.transactions.commit(this.data);
        this.toggle.close();
    }
}
```

</ComponentBlock>

```typescript
export class HierarchicalGridBatchEditingSampleComponent {
    public undo(grid: any) {
        /* exit edit mode and commit changes */
        grid.endEdit(true);
        grid.transactions.undo();
    }

    public redo(grid: any) {
        /* exit edit mode and commit changes */
        grid.endEdit(true);

    }

    public commit() {
        this.hierarchicalGrid.transactions.commit(this.data);

        });
```

<DocsAside type="info">
A API de transações não trata o fim da edição; você precisará fazê-lo por conta própria. Caso contrário, o `{ComponentTitle}` permanecerá em modo de edição. Uma forma de fazer isso é chamando <ApiLink type="Grid" member="endEdit" label="endEdit" /> no respectivo método.
</DocsAside>

<ComponentBlock for="TreeGrid">

Excluir um nó pai no `{ComponentTitle}` tem algumas particularidades. Se você estiver usando dados hierárquicos, os filhos serão excluídos ao excluir o seu pai. Se estiver usando dados planos, você pode definir o comportamento desejado usando a propriedade <ApiLink type="{ComponentApiType}" member="cascadeOnDelete" label="cascadeOnDelete" /> de `{ComponentTitle}`. Essa propriedade indica se os registros filhos devem ser excluídos quando o seu pai for excluído (por padrão, ela é definida como `true`).
</ComponentBlock>

<DocsAside type="info">
Desabilitar a propriedade <ApiLink type="{ComponentApiType}" member="rowEditable" label="rowEditable" /> fará com que `{ComponentTitle}` crie transações a cada alteração de célula e não exporá o overlay de edição de linha na UI.
</DocsAside>
