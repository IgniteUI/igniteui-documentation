# Ocultação de colunas no {ComponentTitle} do Angular

O {ComponentTitle} do Ignite UI for Angular oferece um <ApiLink type="ColumnActions" /> com um <ApiLink type="ColumnHidingDirective" />, que permite aos usuários ocultar colunas diretamente pela interface do usuário ou usando o componente Angular. O Grid da Material UI tem uma interface integrada de ocultação de colunas, que pode ser usada pela barra de ferramentas do {ComponentTitle} para alterar o estado visível das colunas. Além disso, os desenvolvedores sempre podem definir a interface de ocultação de colunas como um componente separado e posicioná-lo onde quiserem na página.

## Interface de ocultação de colunas da barra de ferramentas

A interface integrada de ocultação de colunas fica dentro de um <ApiLink type="DropDown" /> na barra de ferramentas do {ComponentTitle}. Podemos mostrar/ocultar a interface de ocultação de colunas usando exatamente esse menu suspenso.
Para isso, basta definir o <ApiLink type="GridToolbarActions" /> e o <ApiLink type="GridToolbarHiding" /> dentro de {ComponentTitle}. Também adicionaremos um título à nossa barra de ferramentas usando o <ApiLink type="GridToolbarTitle" /> e um estilo personalizado para o wrapper do nosso {ComponentTitle}.

Usando a propriedade <ApiLink type="GridToolbarHiding" member="columnsAreaMaxHeight" label="columnsAreaMaxHeight" /> do IgxGridToolbarHidingComponent, podemos definir a altura máxima da área que contém as ações de coluna. Assim, se houver muitas ações e nem todas couberem no contêiner, aparecerá uma barra de rolagem, que nos permitirá rolar até qualquer ação desejada.

```typescript
// columnHiding.component.ts

public ngAfterViewInit() {        
    this.hidingActionRef.columnsAreaMaxHeight = "200px";
}
```

Assim, podemos usá-la de acordo com os requisitos da nossa aplicação.

    ...

})

Agora vamos criar o nosso <ApiLink type="ColumnActions" />. Na nossa aplicação, vamos posicioná-lo ao lado do grid (o que não acontece com a interface de ocultação de colunas da barra de ferramentas, em que o componente fica dentro de um menu suspenso por design). ### Adicionar título e dica de filtro

Mais duas coisas que podemos fazer para enriquecer a experiência do usuário com o nosso componente de ocultação de colunas são definir as propriedades <ApiLink type="ColumnActions" member="title" label="title" /> e <ApiLink type="ColumnActions" member="filtercolumnsprompt" label="filterColumnsPrompt" />. O <ApiLink type="ColumnActions" member="title" label="title" /> é exibido no topo, e o <ApiLink type="ColumnActions" member="filterColumnsPrompt" label="filterColumnsPrompt" /> é o texto de dica exibido no campo de filtro da nossa interface de ocultação de colunas.

```html
<!--columnHiding.component.html-->

<div class="columnHidingContainer">
    <igx-column-actions igxColumnHiding #columnHidingUI [columns]="{ComponentObjectRef}.columns"
                       title="Column Hiding" filterColumnsPrompt="Type here to search">
    </igx-column-actions>
</div>
```

### Adicionar opções de ordem de exibição das colunas

Também podemos permitir que o usuário escolha a ordem de exibição das colunas na interface de ocultação de colunas. Para isso, usaremos a propriedade <ApiLink type="ColumnActions" member="columnDisplayOrder" label="columnDisplayOrder" />, que é do tipo enumeração e tem as seguintes opções:

- **Alphabetical** (ordena as colunas em ordem alfabética)
- **DisplayOrder** (ordena as colunas de acordo com a forma como são exibidas no {ComponentTitle})

Vamos criar alguns botões de opção bem desenhados para as nossas opções! Basta obter o módulo [**IgxRadio**](/inputs/radio).

```typescript
// app.module.ts

...

    ...
    IgxRadioModule    
} from 'igniteui-angular/radio';
// import { ..., IgxRadioModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxRadioModule],    
})
export class AppModule {}
```

Agora tudo o que precisamos fazer é vincular a propriedade <ApiLink type="Radio" member="checked" label="checked" /> de ambos os botões de opção, respectivamente, a condições diferentes, e tratar os seus eventos de clique.

```html
<!--columnHiding.component.html-->

<div class="columnHidingContainer">
    ...
    <div class="columnsOrderOptionsContainer">
        <igx-radio [checked]="columnHidingUI.columnDisplayOrder === 'Alphabetical'"
                   (click)="columnHidingUI.columnDisplayOrder = 'Alphabetical'">
            Alphabetical order
        </igx-radio>
        <igx-radio [checked]="columnHidingUI.columnDisplayOrder === 'DisplayOrder'"
                   (click)="columnHidingUI.columnDisplayOrder = 'DisplayOrder'">
            Display order
        </igx-radio>
    </div>
</div>
```

## Estilização

Para começar a estilizar o componente de ações de coluna, precisamos importar o arquivo index, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Usando a abordagem mais simples, criamos um novo tema que estende o <ApiLink kind="sass" module="themes" type="function-column-actions-theme" label="column-actions-theme" code={true} /> e aceita os parâmetros `$title-color` e `$background-color`.

```scss
$custom-column-actions-theme: column-actions-theme(
  $background-color: #292826,
  $title-color: #ffcd0f
);
```

Como visto, o `column-actions-theme` controla apenas as cores do contêiner de ações de coluna, mas não afeta os botões, as caixas de seleção e o input-group dentro dele. Digamos que queremos estilizar também os botões; por isso, criaremos um novo tema de botão:

```scss
$custom-button: flat-button-theme(
  $foreground: #292826, 
  $disabled-foreground: rgba(255, 255, 255, .54)
);
```

<DocsAside type="info">
Em vez de definir os valores de cor diretamente, como acabamos de fazer, podemos obter mais flexibilidade em relação às cores usando as funções <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> e <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Consulte o tópico [`Palettes`](/themes/sass/palettes) para orientações detalhadas sobre como usá-las.
</DocsAside>

Neste exemplo, alteramos apenas a cor do texto dos botões flat e a cor de botão desativado, mas o <ApiLink kind="sass" module="themes" type="function-flat-button-theme" label="flat-button-theme" code={true} /> oferece muito mais parâmetros para controlar a estilização dos botões.

A última etapa é aplicar cada tema de componente com `tokens()`:

```scss
:host {
  @include tokens($custom-column-actions-theme);
  
  .igx-column-actions {
    @include tokens($custom-button);
  }
}
```

<DocsAside type="info">
Incluímos o **flat-button-theme** criado dentro de `.igx-column-actions`, para que apenas os botões de ocultação de colunas sejam estilizados. Caso contrário, outros botões do grid também seriam afetados.
</DocsAside>

<DocsAside type="info">
Em alguns templates de componentes, o Emulated View Encapsulation ainda pode impedir que as declarações de token geradas cheguem aos elementos aninhados do Ignite UI. Se o tema não tiver efeito, use `::ng-deep` conforme mostrado abaixo ou mova o tema para uma folha de estilos global.
</DocsAside>

```scss
:host {
  @include tokens($custom-column-actions-theme);

  ::ng-deep {
    .igx-column-actions {
      @include tokens($custom-button);
    }
  }
}
```
