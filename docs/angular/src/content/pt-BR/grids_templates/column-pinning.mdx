# Fixação de colunas do {ComponentTitle} do Angular

Uma coluna ou várias colunas podem ser fixadas no lado esquerdo ou direito do Angular UI Grid. A **fixação de colunas** no Ignite UI for Angular permite que os usuários finais travem colunas em uma determinada ordem, para que continuem visíveis durante a rolagem horizontal do {ComponentTitle}. A Material UI Grid tem uma interface integrada de fixação de colunas, que pode ser usada pela barra de ferramentas do {ComponentTitle} para alterar o estado de fixação das colunas. Além disso, você pode definir uma interface personalizada e alterar o estado de fixação das colunas pela API de fixação de colunas.

## API de fixação de colunas

A fixação de colunas é controlada pela entrada `pinned` do <ApiLink type="Column" label="igx-column" />. Por padrão, as colunas fixadas são renderizadas no lado esquerdo do {ComponentTitle} e permanecem fixas durante a rolagem horizontal das colunas não fixadas no corpo do {ComponentTitle}.

<ComponentBlock for="Grid">

```html
<igx-grid #grid1 [data]="data | async" [width]="700px" [autoGenerate]="false" (columnInit)="initColumns($event)"
    (selected)="selectCell($event)">
    <igx-column [field]="Name" [pinned]="true"></igx-column>
    <igx-column [field]="AthleteNumber"></igx-column>
    <igx-column [field]="TrackProgress"></igx-column>
    <igx-paginator [perPage]="10">
    </igx-paginator>
</igx-grid>
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```html
<igx-tree-grid #treeGrid [data]="data" primaryKey="ID" foreignKey="ParentID" [autoGenerate]="false">
    <igx-column [field]="Name" [pinned]="true"></igx-column>
    <igx-column [field]="Title"></igx-column>
    <igx-column [field]="ID"></igx-column>
</igx-tree-grid>
```

</ComponentBlock>

<ComponentBlock for="HierarchicalGrid">

```html
<igx-hierarchical-grid class="hgrid" [data]="localdata" [autoGenerate]="false"
        [height]="'600px'" [width]="'800px'" #hierarchicalGrid>
    <igx-column [field]="Artist" [width]="200px" [pinned]="true"></igx-column>
    <igx-column [field]="Debut" [width]="200px"></igx-column>
</igx-hierarchical-grid>
```

</ComponentBlock>

Você também pode usar os métodos <ApiLink type="{ComponentApiType}" member="pinColumn" label="pinColumn" /> ou <ApiLink type="{ComponentApiType}" member="unpinColumn" label="unpinColumn" /> do {ComponentTitle} do <ApiLink type="{ComponentApiType}" /> para fixar ou desfixar colunas pelo nome do campo:

<ComponentBlock for="Grid">

```typescript
this.grid.pinColumn('AthleteNumber');
this.grid.unpinColumn('Name');
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```typescript
this.treeGrid.pinColumn('Title');
this.treeGrid.unpinColumn('Name');
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```typescript
this.hierarchicalGrid.pinColumn('Artist');
this.hierarchicalGrid.unpinColumn('Debut');
```

</ComponentBlock>

Ambos os métodos retornam um valor booleano indicando se a operação correspondente foi bem-sucedida. Normalmente, a falha ocorre porque a coluna já está no estado desejado.

Uma coluna é fixada à direita da coluna fixada mais à direita. Para alterar a ordem das colunas fixadas, você pode se inscrever no evento <ApiLink type="{ComponentApiType}" member="columnPin" label="columnPin" /> e alterar a propriedade <ApiLink kind="interface" type="IPinColumnEventArgs" member="insertAtIndex" /> dos argumentos do evento para o índice de posição desejado.

<ComponentBlock for="Grid">

```html
<igx-grid #grid1 [data]="data | async" [autoGenerate]="true" (columnPin)="columnPinning($event)"></igx-grid>
```

```typescript
public columnPinning(event) {
    if (event.column.field === 'Name') {
        event.insertAtIndex = 0;
    }
}
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```html
<igx-tree-grid #treeGrid [data]="data" primaryKey="ID" foreignKey="ParentID" [autoGenerate]="true" (columnPin)="columnPinning($event)"></igx-tree-grid>
```

```typescript
public columnPinning(event) {
    if (event.column.field === 'Name') {
        event.insertAtIndex = 0;
    }
}
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```html
<igx-hierarchical-grid class="hgrid" [data]="localdata" [autoGenerate]="false"
        [height]="'600px'" [width]="'800px'" 
        (columnPin)="columnPinning($event)" #hierarchicalGrid>
</igx-hierarchical-grid> 
```

```typescript
public columnPinning(event) {
    if (event.column.field === 'Artist') {
        event.insertAtIndex = 0;
    }
}
```

</ComponentBlock>

## Posição da fixação

Você pode alterar a posição da fixação de colunas pela opção de configuração <ApiLink type="{ComponentApiType}" member="pinning" label="pinning" />. Ela permite definir a posição das colunas como Start ou End.
Quando definida como End, as colunas são renderizadas no fim do grid, depois das colunas não fixadas. As colunas não fixadas podem ser roladas horizontalmente, enquanto as colunas fixadas permanecem fixas à direita.

<ComponentBlock for="Grid">

```html
<igx-grid [data]="data" [autoGenerate]="true" [pinning]="pinningConfig"></igx-grid>
```

</ComponentBlock>

<ComponentBlock for="TreeGrid">

```html
<igx-tree-grid #grid1 [data]="data" [autoGenerate]="true" [pinning]="pinningConfig"></igx-tree-grid>
```

</ComponentBlock>

<ComponentBlock for="HierarchicalGrid">

```html
<igx-hierarchical-grid #grid1 [data]="data" [autoGenerate]="true" [pinning]="pinningConfig"></igx-hierarchical-grid>
```

</ComponentBlock>

```typescript
public pinningConfig: IPinningConfig = { columns: ColumnPinningPosition.End };
```

## Interface personalizada de fixação de colunas

Você pode definir a sua interface personalizada e alterar o estado de fixação das colunas pela API relacionada.

Digamos que, em vez de uma barra de ferramentas, você queira definir ícones de fixação nos cabeçalhos das colunas, que o usuário final pode clicar para alterar o estado de fixação de uma coluna específica.
Isso pode ser feito criando um template de cabeçalho para a coluna com um ícone personalizado.

<ComponentBlock for="Grid">

```html
<igx-grid #grid1 [data]="data" [width]="'100%'" [height]="'500px'">
    <igx-column #col *ngFor="let c of columns" [field]="c.field" [header]="c.header" [width]="c.width" [pinned]='c.pinned'
        [hidden]='c.hidden' [headerClasses]="'customHeaderSyle'">
        <ng-template igxHeader>
            <div class="title-inner">
                <span style="float:left">{{col.header}}</span>
                <igx-icon class="pin-icon" fontSet="fas" name="fa-thumbtack" (click)="toggleColumn(col)"></igx-icon>
            </div>
        </ng-template>
    </igx-column>
</igx-grid>
```

</ComponentBlock>

<ComponentBlock for="TreeGrid">

```html
<ng-template igxHeader let-column #pinTemplate>
    <div class="title-inner">
        <span style="float:left">{{column.header || column.field}}</span>
        <igx-icon class="pin-icon" [class.pinned]="column.pinned" [class.unpinned]="!column.pinned" fontSet="fas" name="fa-thumbtack"
            (click)="toggleColumn(column)"></igx-icon>
```

Ao clicar no ícone personalizado, o estado de fixação da coluna correspondente pode ser alterado usando os métodos de API da coluna.

```typescript
public toggleColumn(col: ColumnType) {
    col.pinned ? col.unpin() : col.pin();
}
```

## Limitações da fixação

- Definir explicitamente larguras de colunas em porcentagem (%) faz com que o corpo do {ComponentTitle} e o conteúdo do cabeçalho fiquem desalinhados quando há colunas fixadas. Para que a fixação de colunas funcione corretamente, as larguras das colunas devem estar em pixels (px) ou ser atribuídas automaticamente pelo {ComponentTitle}.

## Estilização

O igxGrid permite a estilização por meio da [Biblioteca de temas do Ignite UI for Angular](/themes/sass/component-themes). A <ApiLink kind="sass" module="themes" type="function-grid-theme" label="theme" /> do grid expõe uma grande variedade de propriedades, que permitem personalizar todos os recursos do grid.

Nas etapas abaixo, vamos percorrer os passos para personalizar a estilização da fixação do grid.

### Importando o tema global

Para começar a personalizar o recurso de fixação, você precisa importar o arquivo `index`, onde estão todas as funções e mixins de estilização.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### Definindo um tema personalizado

Em seguida, crie um novo tema que estenda o <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} /> e aceite os parâmetros necessários para personalizar o recurso de fixação como desejar.

```scss
$custom-theme: grid-theme(
  $pinned-border-width: 5px,
  $pinned-border-style: double,
  $pinned-border-color: #ffcd0f,
  $cell-active-border-color: #ffcd0f
);
```

<DocsAside type="info">
Em vez de definir os valores de cor diretamente, como acabamos de fazer, podemos obter mais flexibilidade em relação às cores usando as funções <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> e <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} />. Consulte o tópico [`Palettes`](/themes/sass/palettes) para orientações detalhadas sobre como usá-las.
</DocsAside>

### Aplicando o tema personalizado

A forma mais fácil de aplicar o seu tema é com uma instrução `sass` `@include` no arquivo de estilos globais:

```scss
:host {
  @include tokens($custom-theme);
}
```
