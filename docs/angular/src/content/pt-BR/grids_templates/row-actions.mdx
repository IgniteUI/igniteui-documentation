# Ações de linha no Angular Hierarchical Grid

O componente hierarchical grid do Ignite UI for Angular oferece a capacidade de usar o [ActionStrip](/action-strip) e utilizar CRUD para componentes de linha/célula e fixação de linhas. O componente Action Strip pode hospedar controles de UI predefinidos para essas operações.
</ComponentBlock>

## Uso

O primeiro passo é importar o **IgxActionStripModule** no nosso arquivo **app.module.ts**:

```typescript
// app.module.ts

...
import { IgxActionStripModule } from 'igniteui-angular/action-strip';
// import { IgxActionStripModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxActionStripModule],
    ...
})
```

Os componentes de UI predefinidos `actions` são:

- <ApiLink type="GridEditingActions" /> - inclui funcionalidade e UI desenvolvidas especificamente para a edição do grid. Ele permite alternar rapidamente o modo de edição de células ou linhas, dependendo da opção <ApiLink type="Grid" member="rowEditable" label="rowEditable" />, e a exclusão de linhas do grid.

- <ApiLink type="GridPinningActions" /> - inclui funcionalidade e UI desenvolvidas especificamente para a fixação de linhas do grid. Ele permite fixar linhas rapidamente e navegar entre as linhas fixadas e as suas contrapartes desabilitadas.

Eles são adicionados dentro do `<igx-action-strip>`, e isso é tudo o que é necessário para ter um Action Strip que fornece interações padrão.

<ComponentBlock for="Grid">

```html
<igx-grid [data]="data" [rowEditable]="true" [primaryKey]="'ID'">
    <igx-column *ngFor="let c of columns" [field]="c.field">
    </igx-column>

    <igx-action-strip #actionStrip>
        <igx-grid-pinning-actions></igx-grid-pinning-actions>
        <igx-grid-editing-actions></igx-grid-editing-actions>
    </igx-action-strip>
</igx-grid>
```

</ComponentBlock>

## Implementação personalizada

Esses componentes expõem templates que oferecem flexibilidade para personalização. Por exemplo, se quisermos usar o `ActionStrip` em um cenário semelhante ao do Gmail, com ações de linha como `delete`, `edit` etc., você pode simplesmente criar um componente de botão com `igx-icon`, adicionar um evento de clique a ele e inseri-lo no componente `igx-action-strip`.

```html
<igx-grid>
    <igx-action-strip #actionstrip>
        <igx-grid-pinning-actions></igx-grid-pinning-actions>
        <button title="Edit" igxIconButton="flat" igxRipple (click)='startEdit(actionstrip.context)'>
            <igx-icon>edit</igx-icon>
        </button>
        @if (!isDeleted(actionstrip.context)) {
            <button title="Delete" igxIconButton="flat" igxRipple (click)='actionstrip.context.delete()'>
                <igx-icon>delete</igx-icon>
            </button>
        }
    </igx-action-strip>
</igx-grid>
```
