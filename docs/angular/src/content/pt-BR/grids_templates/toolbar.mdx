# Barra de ferramentas do {ComponentTitle} do Angular

O {ComponentTitle} do Ignite UI for Angular oferece uma <ApiLink type="GridToolbar" />, que é essencialmente um contêiner para operações de **UI**. A barra de ferramentas do Angular fica no topo do componente Angular, ou seja, do {ComponentTitle}, e acompanha a sua largura horizontal. O contêiner da barra de ferramentas pode hospedar controles de UI predefinidos para os seguintes recursos do {ComponentTitle}:

- Ocultação de colunas
- Fixação de colunas
- Exportação para Excel, CSV e PDF
- Filtragem avançada

ou qualquer outro conteúdo personalizado. A barra de ferramentas e os componentes de UI predefinidos oferecem suporte a eventos do Angular e expõem uma API para os desenvolvedores.

## Barra de ferramentas com grids filhos

Devido a certas limitações na forma como os grids filhos de um IgxHierarchicalGrid são implementados e como o escopo de DI funciona, ao definir um componente de barra de ferramentas dentro das tags `igx-row-island`, use a diretiva `igxGridToolbar` com a forma abreviada de template. Isso permite que os grids filhos criem as suas próprias instâncias separadas de barra de ferramentas:

```html
<igx-hierarchical-grid>
    ...
    <igx-row-island>
        <igx-grid-toolbar *igxGridToolbar>
            <igx-grid-toolbar-title>Child toolbar</igx-grid-toolbar-title>
        </igx-grid-toolbar>
    </igx-row-island>
    ...
</igx-hierarchical-grid>
```

O contexto de template da barra de ferramentas expõe implicitamente uma referência à respectiva instância do grid, que você pode usar para qualquer outra necessidade de vinculação ou lógica. Veja um exemplo abaixo.

### Com versões anteriores à 17.1.0

As versões anteriores à 17.1.0 também exigiam passar a instância do grid fornecida como propriedade de entrada da própria barra de ferramentas. Isso garante que você sempre tenha a instância correta do grid no escopo do seu template:

```html
<igx-hierarchical-grid>
    ...
    <igx-row-island>
        <!--
            You can name the binding from igxGridToolbar however you want. Just make sure to use
            it inside the template if you need to access the grid instance.
        -->
        <igx-grid-toolbar [grid]="gridRef" *igxGridToolbar="let gridRef">
            <igx-grid-toolbar-title>Child toolbar {{ gridRef.parentIsland.level }}</igx-grid-toolbar-title>
        </igx-grid-toolbar>
    </igx-row-island>
    ...
</igx-hierarchical-grid>
```

</ComponentBlock>

## Recursos

A barra de ferramentas é ótima para separar a lógica/as interações que afetam o grid como um todo.
Como mostrado acima, ela pode ser configurada para fornecer componentes padrão para controlar a ocultação de colunas, a fixação de colunas,
a filtragem avançada e a exportação de dados do grid.
Esses recursos podem ser habilitados de forma independente uns dos outros, seguindo um padrão semelhante ao do componente card do
conjunto Ignite UI for Angular.

### Título

Para definir um título para a barra de ferramentas do seu grid, use o <ApiLink type="GridToolbarTitle" />.
Os usuários podem fornecer desde um texto simples até templates mais elaborados.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-title>Grid toolbar title</igx-grid-toolbar-title>
</igx-grid-toolbar>
```

### Ações

A barra de ferramentas expõe um <ApiLink type="GridToolbarActions" label="contêiner específico" />, onde os usuários podem colocar ações/interações relacionadas ao grid pai.
Assim como na parte do título da barra de ferramentas, os usuários podem fornecer qualquer coisa dentro dessa parte do template, incluindo os componentes de interação padrão da barra de ferramentas.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <button igxButton>Action</button>
        <igx-select></igx-select>
        ...
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

Cada ação agora expõe uma forma de alterar as configurações de overlay do diálogo de ações, usando a entrada <ApiLink type="GridToolbarHiding" member="overlaySettings" label="overlaySettings" />, por exemplo:

```html
<igx-grid-toolbar-actions>
    <igx-grid-toolbar-pinning [overlaySettings]="overlaySettingsScaleCenter"></igx-grid-toolbar-pinning>
    <igx-grid-toolbar-hiding [overlaySettings]="overlaySettingsAuto"></igx-grid-toolbar-hiding>
</igx-grid-toolbar-actions>
```

```ts
public data: any[];
public positionStrategyScaleCenter = new GlobalPositionStrategy({
    openAnimation: scaleInCenter,
    closeAnimation: scaleOutCenter
});
public overlaySettingsScaleCenter = {
    positionStrategy: this.positionStrategyScaleCenter,
    scrollStrategy: new AbsoluteScrollStrategy(),
    modal: true,
    closeOnEscape: true
};

public positionStrategyAuto = new AutoPositionStrategy();
public overlaySettingsAuto = {
    positionStrategy: this.positionStrategyAuto,
    scrollStrategy: new AbsoluteScrollStrategy(),
    modal: false,
    closeOnEscape: false
};
constructor() {
    this.data = athletesData;
}
```

As overlaySettings padrão usam _ConnectedPositionStrategy_ com a estratégia de rolagem _Absolute_, _modal_ definido como false, com as interações habilitadas de _fechar com escape_ e _fechar com clique externo_.

### Fixação de colunas

<ApiLink type="GridToolbarPinning" label="Componente de fixação da barra de ferramentas" /> oferece a UI padrão para interagir com a fixação de colunas no grid.
O componente é configurado para funcionar sem ajustes com o grid pai que contém a barra de ferramentas, além de várias propriedades de entrada para personalizar a UI, como o título do componente, o placeholder da entrada do componente e a altura do próprio menu suspenso.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-pinning
            title="Grid pinned columns"
            prompt="Filter column collection"
            columnListHeight="400px"
        >
        </igx-grid-toolbar-pinning>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

### Ocultação de colunas

<ApiLink type="GridToolbarHiding" label="Componente de ocultação da barra de ferramentas" /> oferece a UI padrão para interagir com a ocultação de colunas. Expõe as mesmas propriedades de entrada para personalizar a UI, como o título do componente, o placeholder da entrada do componente e a altura do próprio menu suspenso.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-hiding
            title="Grid column hiding"
            prompt="Filter column collection"
            columnListHeight="400px"
        >
        </igx-grid-toolbar-hiding>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

### Filtragem avançada

<ApiLink type="GridToolbarAdvancedFiltering" label="Componente de filtragem avançada da barra de ferramentas" /> oferece a UI padrão para o recurso de filtragem avançada. O componente expõe uma forma de alterar o texto padrão do botão.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-advanced-filtering>Custom text for the toggle button</igx-grid-toolbar-advanced-filtering>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

### Exportação de dados

<ComponentBlock for="HierarchicalGrid">

<DocsAside type="info">
Ao exportar o Hierarchical Grid ou qualquer um dos seus grids filhos na hierarquia, os dados exportados serão uma coleção plana de linhas pertencentes ao respectivo grid (os grids filhos não serão incluídos nos dados exportados).
</DocsAside>
</ComponentBlock>

Assim como as demais ações da barra de ferramentas, a exportação é fornecida por meio de um <ApiLink type="GridToolbarExporter" label="Componente exportador da barra de ferramentas" /> pronto para uso.
O componente exportador usa o serviço correspondente ao formato de dados de destino (<ApiLink type="ExcelExporterService" label="Excel" />, <ApiLink type="CsvExporterService" label="CSV" />, <ApiLink type="PdfExporterService" label="PDF" />). Isso significa que, se o serviço correspondente não for fornecido pela cadeia de injeção de dependência, o componente
não conseguirá exportar nada.
Se você precisar relembrar a DI do Angular, consulte o [guia oficial](https://angular.io/guide/dependency-injection). Aqui está um trecho de exemplo mostrando como habilitar
todos os serviços de exportação na sua aplicação.

```typescript
// app.module.ts
import { IgxExcelExporterService, IgxCsvExporterService, IgxPdfExporterService } from 'igniteui-angular/grids/core';
// import { IgxExcelExporterService, IgxCsvExporterService, IgxPdfExporterService } from '@infragistics/igniteui-angular/grids/core'; for licensed package

@NgModule({
    ...
    providers: [IgxExcelExporterService, IgxCsvExporterService, IgxPdfExporterService ]
})
export class AppModule { ... }
```

<DocsAside type="info">
Na v12.2.1 e posteriores, os serviços de exportação são fornecidos no root, o que significa que você não precisa mais declará-los nos providers do AppModule.
</DocsAside>

O componente exportador da barra de ferramentas expõe várias propriedades de entrada para personalizar tanto a UI quanto a experiência de exportação.
Elas vão desde alterar o texto exibido até habilitar/desabilitar opções no menu suspenso ou personalizar o nome do
arquivo gerado. Para a referência completa, consulte a <ApiLink type="GridToolbarExporter" label="Documentação da API" /> do componente exportador da barra de ferramentas.

Aqui está um trecho que mostra algumas das opções que podem ser personalizadas pelo template do Angular:

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-exporter
            <!-- If active, enables the CSV export entry in the dropdown UI -->
            [exportCSV]="csvExportEnabled"
            <!-- If active, enables the excel export entry in the dropdown UI -->
            [exportExcel]="excelExportEnabled"
            <!-- If active, enables the PDF export entry in the dropdown UI -->
            [exportPDF]="pdfExportEnabled"
            <!-- The name of the generated export file without the file extension -->
            filename="exported_data"
        >
            Custom text for the exporter button
            <span excelText>Custom text for the excel export entry</span>
            <span csvText>Custom text for the CSV export entry</span>
            <span pdfText>Custom text for the PDF export entry</span>
        </igx-grid-toolbar-exporter>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

<ComponentBlock for="Grid, TreeGrid, PivotGrid">

Além de alterar o nome do arquivo exportado, o usuário pode configurar ainda mais as opções do exportador aguardando o evento <ApiLink type="{ComponentApiType}" member="toolbarExporting" label="toolbarExporting" /> e personalizando a entrada de opções nas propriedades do evento.

<DocsAside type="info">
Por padrão, ao exportar para CSV, o exportador usa vírgula como separador e a extensão '.csv' para o arquivo de saída.
Você pode personalizar esses parâmetros de exportação inscrevendo-se nos eventos do exportador ou alterando os valores dos campos de opções do exportador.
Você também pode cancelar o processo de exportação definindo o campo cancel dos argumentos do evento como true.
</DocsAside>

O trecho de código a seguir demonstra como se inscrever no evento de exportação da barra de ferramentas e configurar as opções do exportador:

```html
<{ComponentSelector} (toolbarExporting)="configureExport($event)" ></{ComponentSelector}>
```

```typescript
configureExport(args: IGridToolbarExportEventArgs) {
    const options: IgxExporterOptionsBase = args.options;
    
    options.fileName = `Report_${new Date().toDateString()}`;

    if (options instanceof IgxExcelExporterOptions) {
        options.columnWidth = 10;
    } else {
        options.fileType = CsvFileTypes.TSV;
        options.valueDelimiter = '\t';
    }

    args.exporter.columnExporting.subscribe((columnArgs: IColumnExportingEventArgs) => {
        <ComponentBlock for="Grid">

        // Don't export image fields
        columnArgs.cancel = columnArgs.header === 'Athlete' ||
                            columnArgs.header === 'Country';
        </ComponentBlock>
        <ComponentBlock for="TreeGrid">

        // Don't export image field
        columnArgs.cancel = columnArgs.header === 'Name';
        </ComponentBlock>
    });
}
```

</ComponentBlock>

## Conteúdo personalizado

<DocsAside type="info">
Isso substitui a antiga diretiva de template da barra de ferramentas. Se você estiver migrando de uma versão anterior à v11, nossas migrações cuidarão
da movimentação do conteúdo do template. No entanto, não tratamos as vinculações no template; por isso, confira novamente os arquivos de template modificados

Se a parte de ações do componente da barra de ferramentas não for suficiente para um caso de uso específico, a própria barra de ferramentas tem uma projeção de conteúdo geral, onde
os usuários podem fornecer UI adicional. Se o usuário precisar da instância do grid correspondente para chamadas de API ou vinculações, ele pode criar uma variável de referência de template.

            Clear Sort

        <igx-grid-toolbar-actions>

## Estilização

Para começar a estilizar a barra de ferramentas, precisamos importar o arquivo index, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Em seguida, crie um novo tema que estenda o <ApiLink kind="sass" module="themes" type="function-grid-toolbar-theme" label="grid-toolbar-theme" code={true} />.

```scss
$accent: #ffcd0f;

$grid-toolbar-theme: grid-toolbar-theme(
  $background: #170237,
  $border-color: $accent,
  $title-text-color: #f6d8d8,
  $item-hover-background: rgb(246 216 216 / 0.3),
);
```

A última etapa é **incluir** os temas recém-criados.

```scss
:host {
  igx-grid-toolbar {
    @include tokens($grid-toolbar-theme);
  }
}
```

<DocsAside type="info">
Em alguns templates de componentes, o Emulated View Encapsulation ainda pode impedir que as declarações de token geradas cheguem aos elementos aninhados do Ignite UI. Se o tema não tiver efeito, use `::ng-deep` conforme mostrado abaixo ou mova o tema para uma folha de estilos global.
</DocsAside>

```scss
:host ::ng-deep {
  igx-grid-toolbar {
    @include tokens($grid-toolbar-theme);
  }
}
```
