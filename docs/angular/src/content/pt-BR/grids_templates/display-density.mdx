# Tamanho do {ComponentTitle} do Angular

O design do **{ComponentName}** é baseado nas [Diretrizes do Material Design](https://material.io/design). Atualmente, oferecemos a opção de escolher entre um conjunto predefinido de opções de tamanho, que proporcionam uma visualização pequena, média ou grande, respectivamente. Ao escolher o tamanho certo para a sua tabela Material UI / grid Material UI, você pode melhorar significativamente a experiência do usuário ao interagir com grandes volumes de conteúdo.

## Uso

Como você pode ver na demonstração acima, o <ApiLink type="{ComponentApiType}" /> oferece três opções de tamanho: **small**, **medium** e **large**. O trecho de código abaixo mostra como definir o tamanho:

```html
<{ComponentSelector} #{ComponentObjectRef} [data]="data" style="--ig-size: var(--ig-size-small)">
</{ComponentSelector}>
```

Agora vamos ver em detalhes como cada opção se reflete no componente {ComponentTitle}. Quando você alterna entre os diferentes tamanhos, a altura de cada elemento {ComponentTitle} e os paddings correspondentes são alterados. Além disso, se quiser aplicar uma <ApiLink type="Column" member="width" label="**width**" /> de coluna personalizada, lembre-se de que ela deve ser maior que a soma dos paddings esquerdo e direito.

- **--ig-size-large** - este é o tamanho {ComponentTitle} padrão, com a menor intensidade e altura de linha igual a `50px`. Os paddings esquerdo e direito são `24px`; a <ApiLink type="Column" member="width" label="width" /> mínima da coluna é `80px`;
- **--ig-size-medium** - este é o tamanho intermediário, com altura de linha `40px`. Os paddings esquerdo e direito são `16px`; a <ApiLink type="Column" member="width" label="width" /> mínima da coluna é `64px`;
- **--ig-size-small** - este é o menor tamanho, com altura de linha `32px`. Os paddings esquerdo e direito são `12px`; a <ApiLink type="Column" member="width" label="width" /> mínima da coluna é `56px`;

<DocsAside type="info">
Tenha em mente que, atualmente, você **não pode** substituir nenhum dos tamanhos.
</DocsAside>

Vamos continuar com o nosso exemplo e ver na prática como cada tamanho é aplicado. Primeiro, vamos adicionar um botão que nos ajudará a alternar entre os tamanhos:

```html
<div class="density-chooser">
    <igx-buttongroup [values]="sizes"></igx-buttongroup>
</div>
```

```typescript
@ViewChild(IgxButtonGroupComponent) public buttonGroup: IgxButtonGroupComponent;
public size = 'small';
public sizes;

public ngOnInit() {
    this.sizes = [
        {
            label: 'small',
            selected: this.size === 'small',
            togglable: true
        },
        {
            label: 'medium',
            selected: this.size === 'medium',
            togglable: true
        },
        {
            label: 'large',
            selected: this.size === 'large',
            togglable: true
        }
    ];
}
```

Por fim, vamos fornecer a lógica necessária para aplicar de fato o tamanho:

```typescript
@ViewChild('{ComponentObjectRef}', { read: {ComponentName}Component })
public {ComponentObjectRef}: {ComponentName}Component;

public selectSize(event: any) {
    this.size = this.sizes[event.index].label;
}

@HostBinding('style.--ig-size')
protected get sizeStyle() {
    return `var(--ig-size-${this.size})`;
}
```

Outra opção que o <ApiLink type="{ComponentApiType}" /> oferece para alterar a altura das linhas no {ComponentTitle} é a propriedade <ApiLink type="{ComponentApiType}" member="rowheight" label="rowHeight" />. Vamos ver na prática como essa propriedade afeta o layout do {ComponentTitle} junto com a variável CSS `--ig-size`.

Tenha em mente o seguinte:

- A variável CSS `--ig-size` **NÃO** terá impacto na altura da linha **se houver <ApiLink type="{ComponentApiType}" member="rowheight" label="rowHeight" /> especificado**;
- `--ig-size` **afetará todos os demais elementos do {ComponentTitle}**, conforme descrito acima;

E agora podemos estender o nosso exemplo e adicionar a propriedade <ApiLink type="{ComponentApiType}" member="rowHeight" label="rowHeight" /> ao {ComponentTitle}:

 ```html
 <{ComponentSelector} #{ComponentObjectRef} [data]="data" [rowHeight]="'80px'" width="100%" 
 height="550px" [allowFiltering]="true">
 ..............
 </{ComponentSelector}>
 ```
