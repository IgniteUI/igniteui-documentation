# カスケード コンボを使用した Angular Grid

Grid の編集機能では、[カスケード コンボ](/inputs/combo/single-selection#値と選択)を使用できます。前の [Combo](/inputs/combo/overview) で値を選択すると、ユーザーは次の Combo で、その選択に関連するデータのみを受け取ります。

## 設定

列の編集を有効にするには、<ApiLink type="Column" member="editable" label="editable" /> プロパティが **true** に設定されていることを確認してください。

列の編集が有効になったら、[Single Select ComboBox](/inputs/combo/single-selection) を追加します。ここで 1 つの選択のみを使用できるようにするには、igxCombo を変更する代わりに [igxSimpleCombo](/inputs/combo/single-selection) を使用する必要があることに注意してください。

[Simple ComboBox](/inputs/combo/single-selection#はじめに) コンポーネントの使用を開始するには、最初に `IgxSimpleComboModule` を **app.module.ts** ファイルにインポートする必要があります。

```typescript
import { IgxSimpleComboModule } from 'igniteui-angular/simple-combo';

@NgModule({
    imports: [
        ...
        IgxSimpleComboModule,
        ...
    ]
})
export class AppModule {}
```

次に、テンプレートで、<ApiLink type="SimpleCombo" label="igx-simple-combo" /> をいくつかのデータにバインドする必要があります。

- `displayKey` - **オブジェクト配列に必要** - 項目のテキストに使用されるプロパティを指定します。<ApiLink type="SimpleCombo" member="displayKey" label="displayKey" /> に値が指定されていない場合、Simple ComboBox は指定された `valueKey` (存在する場合) を使用します。

```typescript
export class MySimpleComboComponent implements OnInit {
    public countriesData: Country[];
    public selectedCountry: Country;
    public selectedCity: City;

    public ngOnInit() {
        this.countriesData = getCountries([
            'United States',
            'Japan',
            'United Kingdom'
        ]);
    }
}
```

選択の変更を処理するには、<ApiLink type="Combo" member="selectionChanging" label="selectionChanging()" /> が必要です。発行されたイベント引数 <ApiLink type="IComboSelectionChangingEventArgs" kind="interface" /> には、変更前の選択、現在の選択、追加または削除された項目に関する情報が含まれています。したがって、前のコンボの選択に基づいて値をフィルタリングします。

```html
<igx-combo [data]="countriesData" (selectionChanging)="countryChanging($event)"></igx-combo>
```

```typescript
public countryChanging(event: IComboSelectionChangeEventArgs) {
    if (event.added.length) {
        event.newSelection = event.added;
    }
}
```

最後に、[Linear Progress](../linear-progress.mdx) を追加します。これは、データのリストを読み込む間に必要になります。
<ApiLink type="LinearProgressBar" member="id" label="id" /> は、`id` 属性の値を設定するために必要です。

```html
 <igx-linear-bar 
    [id]="'region-progress-' + cell.row.data.ID" 
    [style.visibility]="'hidden'"
    type="info" [indeterminate]="true">
</igx-linear-bar>
```
