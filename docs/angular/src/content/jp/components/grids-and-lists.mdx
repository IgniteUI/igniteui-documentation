# 最速の Angular データ グリッド
Ignite UI for Angular は、世界最速の仮想化された Angular データ グリッドを含む、Angular ネイティブのマテリアル ベースの UI コンポーネントの完全なライブラリを提供します。


## Angular Grid の例
この Angular グリッドの例では、データの検索とフィルタリング、列のソート、サイズ変更、ピン固定と非表示、行の選択、Excel と CSV へのエクスポート、水平および垂直スクロールなど、グリッドに組み込まれているさまざまな機能を利用してユーザーが _データ ビュー_ をカスタマイズする方法を確認できます。リニア プログレス バー インジケーターやスパークラインなどのコンポーネントを含むセル テンプレートの例も用意しています。

## Angular Data Grid の概要

Angular データ グリッドは、一連の行と列で表データを表示するために使用されるコンポーネントです。テーブルとも呼ばれるデータ グリッドは、Microsoft Excel などの一般的なソフトウェアによってデスクトップの世界ではよく知られています。グリッドはデスクトップ プラットフォームで長い間利用されてきましたが、最近では Angular UI などの Web アプリ UI の一部にもなっています。最新のグリッドは複雑で、データ バインディング、編集、Excel のようなフィルタリング、カスタム ソート、グループ化、行の並べ替え、行と列の固定、行の集計、Excel、CSV、PDF 形式へのエクスポートなど、さまざまな機能が含まれる場合があります。

## Angular Data Grid の利点

Angular データ グリッドは、大量のデータを保存し、すばやく処理する必要があるユース ケースで不可欠です。たとえば、大量のデータを高頻度で扱う金融や保険などの業界がこれに当たります。多くの場合、これらの企業の成功はデータ グリッドの機能とパフォーマンスに左右されます。たとえば、株式の取引判断をマイクロ秒単位で下す必要がある場合、データ グリッドが遅延やちらつきなしに動作することが不可欠です。

### データの仮想化とパフォーマンス
データ グリッドの列と行レベルの仮想化により、Angular グリッド内の無制限の行と列をシームレスにスクロールします。ローカルまたはリモートのデータソースのサポートにより、データがどこにあっても最高のパフォーマンスを得ることができます。ユーザーは、ラグ、画面のちらつき、表示の遅延のないエンタープライズ レベルの速度で Excel のようなスクロールを体験でき、パフォーマンスを損なうことなく最高のユーザー エクスペリエンス (UX) を実現できます。

### Angular グリッドのページング、ソート、フィルタリング & 検索
ユーザーがデフォルトの[ページャー](/grid/paging)を使用してデータ セットをナビゲートできるようにするか、独自のテンプレートを作成して独自のページング エクスペリエンスを提供します。単一列および複数列のソート、グリッド上の全文[検索](/grid/search)、およびデータ型に基づく [Microsoft Excel スタイルのフィルタリング](/grid/excel-style-filtering)を含むいくつかの[高度なフィルタリング](/grid/advanced-filtering) オプションを完全にサポートします。

### インライン Angular グリッド編集
列のデータ型に基づいた、[編集可能な列のデフォルトのセル テンプレート](/grid/grid#セル編集テンプレート)を提供しています。編集可能な列に独自のカスタム テンプレートを定義し、セル値の変更のコミットと破棄に関するデフォルトの動作をオーバーライドできます。

### Angular グリッドでのキーボード ナビゲーションと行/セルの選択

上、下、右、左、タブ、および Enter キーを使用して、Angular データ グリッドで Excel のような[キーボード ナビゲーション](/grid/keyboard-navigation)を有効にして、アクセシビリティ コンプライアンスを確保し、使いやすさを向上させます。マウスまたはキーボードを使用して Angular グリッドで単一または複数の行選択を切り替えて完全な行を選択または選択解除するか、グリッド ツールバーの組み込みの [すべて選択] または [すべて選択解除] チェックボックスを使用して行選択を操作できます。この機能の最新の機能強化については、<a class="no-external-icon" href="https://www.infragistics.com/community/blogs/b/engineering/posts/grid-keyboard-navigation-accessibility-">こちら</a>をご覧ください。

### Angular Grid の列のグループ化、ピン固定、集計、移動

マウス操作、タッチ、または API を使用して、列をグループ化したり、列グループを事前に設定したりできます。組み込みの列[集計](/grid/summaries)やカスタム集計テンプレートもサポートしています。移動、ドラッグ、並べ替えの操作中もインタラクティブな[列のピン固定](/grid/column-pinning)を完全にサポートしつつ、ユーザーが列をインタラクティブに[非表示](/grid/column-hiding)にしたり[移動](/grid/column-moving)したりできるようにします。

### Angular Grid の複数列ヘッダー

[複数列ヘッダー](/grid/multi-column-headers)を有効にし、共通ヘッダーで列をグループ化できます。各列グループは、その他のグループや列と組み合わせることができ、列のピン固定、グループ内でのインタラクティブな列移動、ソート、グループの非表示を完全にサポートします。

### Angular Grid のテーマ設定、スタイル設定、テンプレート化

Ignite UI for Angular では、CSS でセルの外観をカスタマイズしたり、ng-template で任意のセルのテンプレートを再定義して自由な外観で描画したりできます。マテリアル デザインを完全にサポートしており、使いやすいテーマ エンジンでブランドに合わせたエクスペリエンスにカスタマイズできます。

### Angular Grid の Excel ライブラリ

XLSX、XLS、TSV、CSV へのデータ グリッドのエクスポートを完全にサポートしています。Ignite UI for Angular の [Excel ライブラリ](/excel-library)には、300 以上の数式、テーブルのサポート、条件付き書式、チャートの作成などが含まれており、クライアント マシンに Microsoft Excel がなくてもすべて利用できます。
