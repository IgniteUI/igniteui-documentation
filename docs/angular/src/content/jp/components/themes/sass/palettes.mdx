# Sass によるパレット

Ignite UI for Angular の Sass パレットは、`palette()` 関数がシード カラーから生成し、`palette()` ミックスインが CSS 変数として出力するカラー シェードのマップです。

## 概要

Ignite UI for Angular のパレットは、カラー ファミリ (`primary`、`secondary`、`gray`、`surface`、`info`、`success`、`warn`、`error`) をキーとする [Sass マップ](https://sass-lang.com/documentation/values/maps)です。各ファミリはそのシェードのマップであり、すべてのコンポーネント テーマは、`--ig-*` CSS 変数を通じてこれらのシェードからカラーを読み取ります。

`palette()` 関数は、シード カラーからマップ全体を作成します。デフォルトの `fitted` ジェネレーターでは、各ファミリに次のバリアントが含まれます。

| ファミリ | バリアント |
|---|---|
| `primary`、`secondary`、`info`、`success`、`warn`、`error` | `50`–`900`、`A100`、`A200`、`A400`、`A700`、`seed` |
| `gray` | `50`–`900`、`seed` |
| `surface` | `base`、`sunken`、`raised`、`overlay`、`container`、`seed` |

すべてのバリアントには、`500-contrast` のような対応する `-contrast` バリアントがあります。これは黒または白で、そのシェードに対して読みやすいコントラストになるようにブラウザーが解決します。`primary` カラーは通常ブランド カラーで、`igx-navbar` などの目立つ静的要素のスタイルを設定します。`secondary` はボタン、スイッチ、スライダーなどの操作可能な要素のスタイルを設定します。`surface` はカード、メニュー、ピッカーなどのコンポーネントの背景です。

シェードの配置方法と、`surface` ファミリが数値ではなくロールを持つ理由については、[パレット生成](../palette-generation.mdx)を参照してください。

## パレットの生成

必須の 3 つのシード (`$primary`、`$secondary`、`$surface`) を指定して `palette()` を呼び出し、その結果を `palette()` ミックスインに渡して CSS 変数として出力します。

```scss
@use "igniteui-angular/theming" as *;

$brand-palette: palette(
  $primary: #0099ff,
  $secondary: #df1b74,
  $surface: #ffffff
);

:root {
  @include palette($brand-palette);
}
```

任意のシードは、`$gray`、`$info` (`#1377d5`)、`$success` (`#4eb862`)、`$warn` (`#faa419`)、`$error` (`#ff134a`) です。`theme()` ミックスインは `palette()` ミックスインを含むため、パレットを単独で出力する場合 (たとえば、2 つ目のパレットをクラスにスコープする場合) にのみ、直接含めます。

<DocsAside type="warning">
`palette()` に渡すシードは、**Sass のカラーである必要があります**。パレットはビルド時に計算されるため、CSS 変数を引数として渡すことはできません。
</DocsAside>

`palette()` ミックスインは、`-contrast` カラーが選択される WCAG レベルも設定します。`$contrast-level` に `'a'`、`'aa'` (デフォルト)、または `'aaa'` を渡します。

```scss
:root {
  @include palette($brand-palette, $contrast-level: 'aaa');
}
```

`fitted` ジェネレーターでは、すべてのシェードが固定の色として出力されます。

```css
:root {
  --ig-primary-100: rgb(172, 207, 251);
  --ig-primary-500: rgb(9, 109, 183);
  --ig-primary-600: rgb(6, 89, 150);
  --ig-primary-seed: #0099ff;
  --ig-surface-base: rgb(255, 255, 255);
  --ig-surface-sunken: rgb(247, 247, 247);
  /* ... */
}
```

シェードは固定されているため、CSS でこれらの変数のいずれかを上書きしても、そのシェードのみが変更されます。ファミリを変更するには、そのシードを変更して再ビルドします。

## スケール

スケールは、ファミリのシェードが及ぶ範囲と間隔を設定します。デフォルトを置き換えるには、`palette()` に `$scales` を渡します。デフォルトは、すべてのファミリで `even`、`gray` で `material` です。

1 つのファミリにプリセットを指定するか、すべてのファミリに 1 つのプリセットを渡します。

```scss
// The grays follow IBM Carbon's rhythm; every other family keeps its default
$brand-palette: palette(#0099ff, #df1b74, #ffffff, $scales: ('gray': 'carbon'));

// Every family uses the tailwind preset
$brand-palette: palette(#0099ff, #df1b74, #ffffff, $scales: 'tailwind');
```

プリセットは `even`、`material`、`tailwind`、`carbon` です。[パレット生成](../palette-generation.mdx#scale-shapes)でこれらを比較しています。

次のキーを使用して、スケールをインラインで記述します。

| キー | 値 | 効果 |
|---|---|---|
| `range` | `1.1 14` のような 2 つのコントラスト比 | シェード `50` とシェード `900` のコントラストです。デフォルトは `even` の範囲 `1.182 18.232` です。 |
| `curve` | `0.5 0 0.8 0.8` のような 4 つの数値 | CSS の `cubic-bezier()` のように読み取られ、範囲に沿ってシェードを再配分します。均等な間隔にする場合は省略します。 |
| `anchor` | `'surface'` または `'white'` | `gray` の範囲を何に対して測定するかを指定します。デフォルトは `'surface'` です。他のファミリは常に白に対して測定されます。 |

```scss
$brand-palette: palette(
  #0099ff,
  #df1b74,
  #121212,
  $scales: (
    'primary': (range: 1.1 14, curve: 0.5 0 0.8 0.8),
    'gray': (range: 1.1 14, anchor: 'white')
  )
);
```

4 つの数値のみのリストは、`even` の範囲に対するカーブとして読み取られます。カスタムの範囲またはカーブは、シェード間のコントラストを変更します。変更後は、使用するペアを確認してください。

## ジェネレーター

`palette()` 関数には 2 つのジェネレーターがあります。デフォルトの `fitted` は、コントラストの目標に合わせて各シェードを算出します。`legacy` は、シードを `500` に配置し、固定の HSL 乗数で他のシェードを導出して、`500` の CSS 相対カラーとして出力します。

```css
:root {
  --ig-primary-500: #0099ff;
  --ig-primary-600: hsl(from var(--ig-primary-500) h calc(s * 1.26) calc(l * 0.89));
}
```

1 つのパレットで `legacy` ジェネレーターを維持するには `$generator` を使用します。ビルド内のすべての `palette()` 呼び出しで維持するには、他のどれよりも先にライブラリが読み込まれるよう、`$shade-generator` を設定します。

```scss
// One palette
$brand-palette: palette(#0099ff, #df1b74, #ffffff, $generator: 'legacy');
```

```scss
// Every palette() call in the build
@use "igniteui-theming" with ($shade-generator: 'legacy');
@use "igniteui-angular/theming" as *;
```

`legacy` パレットは `$scales` 引数を無視します。

## 事前定義されたパレット

Ignite UI for Angular は、対応するスキーマと組み合わせて使用できる、事前定義されたライト パレットとダーク パレットを提供します。

- ライト パレット
  - `$light-material-palette`
  - `$light-fluent-excel-palette`
  - `$light-fluent-word-palette`
  - `$light-fluent-palette`
  - `$light-bootstrap-palette`
  - `$light-indigo-palette`
- ダーク パレット
  - `$dark-material-palette`
  - `$dark-fluent-excel-palette`
  - `$dark-fluent-word-palette`
  - `$dark-fluent-palette`
  - `$dark-bootstrap-palette`
  - `$dark-indigo-palette`

すべてのライト パレットをライト スキーマと、すべてのダーク パレットをダーク スキーマと組み合わせられます。事前定義されたパレットは `legacy` ジェネレーターで作成されているため、それらに基づくテーマは相対カラーのシェードを維持し、`500` バリアントの実行時の上書きに反応します。

## グレースケール カラー

`gray` ファミリは、ほとんどのテキスト、ボーダー、無効状態のカラーを提供し、そのシェードはサーフェスに対して設定されます。グレーの作成元のカラーを選択するには、`$gray` を渡します。

```scss
$brand-palette: palette(
  $primary: #2ab759,
  $secondary: #f96a88,
  $surface: #222222,
  $gray: #ffffff
);
```

`$gray` を省略すると、グレーのシードは、ライト サーフェスでは黒、ダーク サーフェスでは白になります。デフォルトの `material` スケールでは、シェード `50` は白または黒に近いサーフェスに最も近いグレー、`900` はサーフェスから最も遠いグレーです。グレー スケールのアンカーがダーク テーマにどのように影響するかについては、[グレーとページ](../palette-generation.mdx#grays-and-the-page)を参照してください。

## カラー バリアント

`color()` 関数は、パレットのシェードを返します。最大 4 つの引数 (`$palette`、`$color`、`$variant`、`$opacity`) を受け取ります。

```scss
// A reference to the CSS variable: var(--ig-primary-500)
$primary-500: color();

// var(--ig-primary-600)
$primary-600: color($variant: 600);

// The primary 600 shade at 50% opacity, as a CSS relative color
$primary-600-translucent: color($variant: 600, $opacity: 0.5);

// The surface's raised role: var(--ig-surface-raised)
$raised: color($color: 'surface', $variant: 'raised');

// The resolved color of the secondary A700 shade in $brand-palette
$secondary-a700: color($brand-palette, 'secondary', 'A700');

.panel {
  background: $raised;
  border-color: $primary-600;
}
```

`$palette` を指定しない場合、`color()` は CSS 変数への参照を返すため、値は実行時に出力されるパレットに従います。`$palette` を指定すると、そのマップから解決されたカラーを返します。`$color` のデフォルトは `primary`、`$variant` のデフォルトは `500` です (`$color` が `surface` の場合は `base`)。

## コントラスト テキスト カラー

`contrast-color()` 関数は、シェードのコントラスト カラーを返し、`color()` と同じ引数を受け取ります。

```scss
.callout {
  background: color($color: 'primary', $variant: 600);
  color: contrast-color($color: 'primary', $variant: 600);
}
```

結果は CSS 相対カラーで、`palette()` ミックスインで設定されたコントラスト レベルで、ブラウザーが黒または白に解決します。

## カラー クラス

`color-classes()` ミックスインは、パレット内のすべてのシェードに CSS クラスを生成し、選択した CSS プロパティに割り当てます。

- `$prop` - カラーを割り当てる CSS プロパティ。
- `$prefix` - 生成されるクラス名のプレフィックス。デフォルトは `'igx'` です。
- `$suffix` - 生成されるクラス名のサフィックス。
- `$palette` - 使用するパレット。

```scss
@include color-classes(
  $prop: 'background-color',
  $prefix: 'bg'
);
```

`primary` の `500` シェードは、クラス `.bg-primary-500` になります。

```html
<div class="bg-primary-500">...</div>
```

## カスタム パレット マップ

コンポーネント テーマはパレット マップの形状のみを読み取るため、テーマが読み取るキーがあれば、手動で作成したマップも機能します。数値のバリアントを含むすべてのキーを引用符で囲み、`surface` にそのロールを指定します。

```scss
$handmade-palette: (
  'primary': (
    '50': #e6eff8,
    '50-contrast': black,
    // ... '100' through '900', then 'A100', 'A200', 'A400', 'A700', each with a '-contrast' entry
    '500': #6797de,
    '500-contrast': white,
  ),
  // 'secondary', 'gray', 'info', 'success', 'warn', and 'error' follow the same pattern
  'surface': (
    'base': #ffffff,
    'base-contrast': black,
    'sunken': #f7f7f7,
    'sunken-contrast': black,
    'raised': #ffffff,
    'raised-contrast': black,
    'overlay': #ffffff,
    'overlay-contrast': black,
    'container': rgba(0, 0, 0, 0.03),
    'container-contrast': black,
  ),
);
```

Ignite UI for Angular 22.3.0 のコンポーネント テーマは、カラー ファミリと `gray` の番号付きシェード、`primary` と `secondary` のアクセント シェード、および `base` サーフェス ロールを読み取ります。その他のサーフェス ロールは、独自のスタイルで使用するためのものです。残りを読み取るスタイルも解決されるように、[概要](#概要)に記載されているすべてのバリアントを含めてください。

## トラブルシューティング

**`--ig-primary-500` を上書きしても、他のプライマリ シェードが更新されないのはなぜですか?** `fitted` ジェネレーターで生成されたパレットは、固定の色を出力します。`palette()` に渡すシードを変更して再ビルドするか、`500` からの実行時の導出を維持するために `$generator: 'legacy'` でパレットを生成してください。

**`--ig-surface-500` または `color($color: 'surface', $variant: 500)` への参照を移行するにはどうすればよいですか?** 番号付きのサーフェス シェードは、ロールを優先して非推奨になりました。すべてのパレットが引き続きそれらを出力するため、移行中も参照は動作し続けます。ページまたはコンポーネントの背景には `base`、その上のレイヤーには `raised` または `overlay`、その中に埋め込まれるレイヤーには `sunken`、半透明の塗りつぶしには `container` を使用します。`color($color: 'surface')` は、すでに `base` を返します。

**ビルドで `Shade "gray-900" wanted 18.232:1 but its hue only reaches …` と出力されるのはなぜですか?** スケールが、カラーとそのアンカーが許容するよりも高いコントラストを要求しています。通常は、ダーク サーフェス上のサーフェスにアンカーされたグレー スケールです。ジェネレーターは、到達できる最も近いシェードを使用しました。`range` の上限を下げるか、`anchor: 'white'` を設定してください。
