# コンポーネント テンプレート

コンポーネント テンプレートは、Ignite UI CLI (`ig add`) と Ignite UI Angular Schematics (`ng g @igniteui/angular-schematics:c`) が既存の Angular プロジェクトに生成する、事前設定された Angular コンポーネントのスキャフォールドです。各テンプレートは、正しいインポート、モジュール宣言、サンプル データセットを備えた動作する Angular コンポーネントを生成するため、追加の設定なしですぐに実行できます。テンプレートは、グリッド、チャート、ゲージ、マップ、レイアウト コンポーネント、メニュー、通知、データ入力コントロール、インタラクション、スケジュール コントロール、および完全なアプリケーション シナリオ向けに用意されています。

これらのテンプレートは、既存の Angular ワークスペースにコンポーネントを生成するだけで、新しい Angular プロジェクトは作成しません。新しいプロジェクトを作成するには `ig new` または `ng new` を使用してください。テンプレートは Ignite UI for Angular 専用です。React、Web Components、Blazor での同等のパターンについては、各フレームワークのドキュメントを参照してください。生成されたコードは動作する出発点となるものであり、本ページからリンクしているライブ デモとは異なる場合があります。ライブ デモには、ドキュメントの完全なサンプルが反映されています。
