# オーバーレイ スタイリング

<div class="highlight">


[`IgxOverlayService`](/overlay) は、ページ コンテンツの上にコンテンツを表示するために使用されます。[Drop Down](/drop-down)、[Combo](/inputs/combo/overview)、[Date Picker](/date-picker) など、Ignite UI for Angular の多くのコンポーネントがオーバーレイを使用しているため、オーバーレイがコンテンツを表示する方法を理解することが重要です。
他の要素の上にコンテンツを表示するために、サービスはコンテンツを特別なアウトレット コンテナーに移動します (デフォルトではドキュメントの本体の最後にアタッチされています)。この動作は、[特定のコンテナーにスコープされた](#スコープ-オーバーレイ-スタイル)スタイルに影響を与える可能性があります。
</div>
<hr/>

## オーバーレイ コンポーネントのスタイル設定

グローバル スタイルシートから出力されたテーマは、どのオーバーレイ アウトレット内のコンテンツにも影響を与えることができます。たとえば、次の [Drop Down](/drop-down#スタイル設定) テーマは、Sass のルートでユニバーサルなトークンの上書きを出力します。これらの上書きは、ドキュメントの本体にアタッチされたドロップダウン コンテンツで使用できます。

```html
{/* overlay-styling.component.html */}
<igx-drop-down #customDropDown height="350px">
    <igx-drop-down-item *ngFor="let item of items" [value]="item.id">
        {{ item.name }}
    </igx-drop-down-item>
</igx-drop-down>
```

```scss
// styles.scss
@use "igniteui-angular/theming" as *;

$my-drop-down-theme: drop-down-theme(
  $background-color: #efefef
);

@include tokens($my-drop-down-theme);
```

これらのユニバーサルな上書きはグローバルであるため、オーバーレイ サービスがドロップダウン コンテンツをアウトレットに移動した後も、ドロップダウン コンテンツはこれらの上書きを使用できます。

## スコープ コンポーネント スタイル

ローカル テーマが影響を与えられるのは、そのコンテナーから継承するオーバーレイ コンテンツ、またはテーマが生成したセレクターに一致するオーバーレイ コンテンツだけです。`body` の最後にあるデフォルトのアウトレットにアタッチされたコンテンツは、それを開いたコンポーネントの子孫ではありません。

たとえば、`igx-combo` の項目の[スタイル](/inputs/combo/overview#スタイル設定)は、ドロップダウン テーマを使用します。このコンポーネント ローカルのテーマは、Combo のアウトレットをホストの下に移動した後に有効になります。

```scss
// overlay-styling.component.scss

:host {
  @include tokens($my-drop-down-theme);
}
```

<DocsAside type="warning" title="警告">
`::ng-deep` を使用しても、デタッチされたアウトレットにトークンは継承されません。オーバーレイのテーマをグローバルに出力するか、アウトレットをテーマが適用されたコンテナーの下に移動してください。特殊なカスタマイズでスコープ モードを使用していて、アウトレットを移動しても生成されたセレクターがネストされたオーバーレイ コンテンツに一致しない場合は、アウトレットの移動に加えて `::ng-deep` も必要になることがあります。
</DocsAside>

オーバーレイ コンテナーをレンダリングする場所を制御するには、<ApiLink kind="interface" type="OverlaySettings" member="outlet" /> プロパティを使用します。

ここでは、コンテナーを配置する要素への参照を渡すことができます。

```html
<igx-combo [data]="items" valueKey="name" displayKey="name" [overlaySettings]="{ outlet: element, modal: true }">
</igx-combo>
```

```typescript
export class OverlayStylingComponent {
  ...
  constructor(public element: ElementRef) {
  }
}
```

これで、Combo の項目リストがコンポーネントのホスト**内**に適切にレンダリングされるため、カスタム テーマが有効になります。

## オーバーレイのスタイル設定

`ViewEncapsulation` がオーバーレイの `outlet` プロパティとどのように連携するかを説明しました。次に、オーバーレイ ラッパー自体のスタイルを設定する方法を示します。
<ApiLink kind="sass" module="themes" type="function-overlay-theme" label="overlay-theme" code={true} /> は、単一のプロパティ `$background-color` を公開します。このプロパティは、オーバーレイが `modal: true` に設定されている場合の背景の色に影響します。

### グローバル スタイル

オーバーレイ モーダルをスタイル設定する最も簡単な方法は、アプリのグローバル スタイルにテーマを含める方法です。

```scss
// styles.scss
$my-overlay-theme: overlay-theme(
  $background-color: rgba(0, 153, 255, 0.3)
);

@include tokens($my-overlay-theme);
```

これで、**すべて**のモーダル オーバーレイの背景が紫色になります。このテーマはグローバルに出力されるため、Angular の View Encapsulation や `::ng-deep` は関係しません。

### スコープ オーバーレイ スタイル

特定のコンテナーの下でのみオーバーレイに特定の背景を適用するには、オーバーレイのアウトレットをそのコンテナーの下に移動し、そこでテーマをスコープします。カスタム アウトレットにはいくつかの[制限](/overlay#仮定と制限)があります。オーバーフローによるクリッピング、重なり順、およびビューポートの問題を軽減するために、カスタム アウトレットは上位レベルのコンポーネントで使用してください。

```scss
// styles.scss
...
.purple {
  @include tokens($my-overlay-theme);
}
```
