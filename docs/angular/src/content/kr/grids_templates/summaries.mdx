# Angular {ComponentTitle} 요약

Ignite UI for Angular의 Angular UI 그리드에는 열 단위로 그룹 바닥글 역할을 하는 **요약** 기능이 있습니다. Angular 그리드 요약은 열 안의 데이터 유형에 따라 미리 정의된 기본 요약 항목 집합을 갖춘 별도의 컨테이너에 열 정보를 보여 줄 수 있게 하는 강력한 기능이며, {ComponentTitle}에 사용자 지정 Angular 템플릿을 구현할 수도 있습니다.

<DocsAside type="info">
열의 요약은 **모든 열 값의 함수**입니다. 단, 필터링이 적용되어 있으면 열의 요약은 **필터링된 결과 값의 함수**가 됩니다
</DocsAside>

**{ComponentTitle} 요약**은 Ignite UI for Angular에서 열 단위로도 활성화할 수 있으므로, 필요한 열에 대해서만 켤 수 있습니다. {ComponentTitle} 요약은 열의 데이터 유형에 따라 미리 정의된 기본 요약 집합을 제공하므로, 시간을 절약할 수 있습니다:

`string` 및 `boolean` <ApiLink type="Column" member="dataType" label="데이터 유형" />의 경우 다음 함수를 사용할 수 있습니다:

- count

`number`, `currency` 및 `percent` 데이터 유형의 경우 다음 함수를 사용할 수 있습니다:

- count
- min
- max
- average
- sum

`date` 데이터 유형의 경우 다음 함수를 사용할 수 있습니다:

- count
- earliest
- latest

사용 가능한 모든 열 데이터 타입은 공식 [열 타입 항목](/{igPath}/column-types#기본-템플릿)에서 찾을 수 있습니다.

**{ComponentTitle} 요약**은 <ApiLink type="Column" member="hasSummary" label="hasSummary" /> 속성을 `true`(으)로 설정하여 열 단위로 활성화합니다. 각 열의 요약은 열의 데이터 유형에 따라 해석된다는 점도 기억해야 합니다. `{ComponentSelector}`에서 기본 열 데이터 유형은 `string`이므로, `number` 또는 `date` 전용 요약을 원하면 <ApiLink type="Column" member="datatype" label="dataType" /> 속성을 `number` 또는 `date`로 지정해야 합니다. 요약 값은 그리드의 <ApiLink type="Grid" member="locale" label="locale" />과 열의 <ApiLink type="Column" member="pipeArgs" label="pipeArgs" />에 따라 지역화되어 표시된다는 점에 유의하십시오.

## 사용자 지정 {ComponentTitle} 요약

이 함수들이 요구 사항을 충족하지 못하면, 특정 열에 대해 사용자 지정 요약을 제공할 수 있습니다. 이를 위해서는 열 데이터 유형과 필요에 따라 기본 클래스 <ApiLink type="SummaryOperand" />, <ApiLink type="NumberSummaryOperand" /> 또는 <ApiLink type="DateSummaryOperand" /> 중 하나를 재정의해야 합니다. 이렇게 하면 기존 함수를 재정의하거나 새 함수를 추가할 수 있습니다. <ApiLink type="SummaryOperand" /> 클래스는 <ApiLink type="SummaryOperand" member="count" label="count" /> 메서드에 대해서만 기본 구현을 제공합니다. <ApiLink type="NumberSummaryOperand" />은(는) <ApiLink type="SummaryOperand" />을(를) 확장하며 <ApiLink type="NumberSummaryOperand" member="min" label="min" />, <ApiLink type="NumberSummaryOperand" member="max" label="max" />, <ApiLink type="NumberSummaryOperand" member="sum" label="sum" /> 및 <ApiLink type="NumberSummaryOperand" member="average" label="average" />에 대한 구현을 제공합니다. <ApiLink type="DateSummaryOperand" />은(는) <ApiLink type="SummaryOperand" />을(를) 확장하며 추가로 <ApiLink type="DateSummaryOperand" member="earliest" label="earliest" />와 <ApiLink type="DateSummaryOperand" member="latest" label="latest" />를 제공합니다.

<ComponentBlock for="Grid, TreeGrid, PivotGrid">

```typescript
import { IgxSummaryResult, IgxSummaryOperand, IgxNumberSummaryOperand, IgxDateSummaryOperand } from 'igniteui-angular/core';
// import { IgxSummaryResult, IgxSummaryOperand, IgxNumberSummaryOperand, IgxDateSummaryOperand } from '@infragistics/igniteui-angular'; for licensed package

class MySummary extends IgxNumberSummaryOperand {
    constructor() {
        super();
    }

    operate(data?: any[]): IgxSummaryResult[] {
        const result = super.operate(data);
        result.push({
            key: 'test',
            label: 'Test',
            summaryResult: data.filter(rec => rec > 10 && rec < 30).length
        });
        return result;
    }
}
```

</ComponentBlock>

### 모든 데이터에 접근하는 사용자 지정 요약

 이제 사용자 지정 열 요약 안에서 모든 {ComponentTitle} 데이터에 접근할 수 있습니다. IgxSummaryOperand의 `operate` 메서드에 선택적 매개변수 두 개가 추가되었습니다.
아래 코드 조각에서 볼 수 있듯이, operate 메서드는 다음 세 가지 매개변수를 가집니다:

- columnData - 현재 열의 값만 담은 배열을 제공합니다
- allGridData - 그리드 데이터 소스 전체를 제공합니다
- fieldName - 현재 열의 필드입니다

<ComponentBlock for="TreeGrid">

```typescript
class MySummary extends IgxNumberSummaryOperand {
    constructor() {
        super();
    }
    operate(columnData: any[], allGridData = [], fieldName?): IgxSummaryResult[] {
        const result = super.operate(allData.map(r => r[fieldName]));
        result.push({ key: 'test', label: 'Total Undelivered', summaryResult: allData.filter((rec) => rec.Discontinued).length });
        return result;
    }
}
```

### 요약 템플릿

`igxSummary`은(는) 열 요약 결과를 컨텍스트로 제공하여 열 요약을 대상으로 합니다.

```html
<igx-column ... [hasSummary]="true">
    <ng-template igxSummary let-summaryResults>
        <span> My custom summary template</span>
        <span>{{ summaryResults[0].label }} - {{ summaryResults[0].summaryResult }}</span>
    </ng-template>
</igx-column>
```

기본 요약이 정의되어 있으면, 요약 영역의 높이는 요약이 가장 많은 열과 그리드 크기를 기준으로 설계에 따라 계산됩니다. 기본값을 재정의하려면 <ApiLink type="Grid" member="summaryRowHeight" label="summaryRowHeight" /> 입력 속성을 사용하십시오. 이 속성은 숫자 값을 인수로 받으며, false 값을 설정하면 그리드 바닥글의 기본 크기 조정 동작이 적용됩니다.

## 요약 비활성화

<ApiLink type="{ComponentApiType}" member="disabledSummaries" label="disabledSummaries" /> 속성은 Ignite UI for Angular 그리드 요약 기능에 대해 열 단위로 정밀한 제어를 제공합니다. 이 속성을 사용하면 그리드의 각 열에 표시되는 요약을 사용자 지정하여, 가장 관련성이 높고 의미 있는 데이터만 표시되도록 할 수 있습니다. 예를 들어 요약 키를 배열에 지정하여 `['count', 'min', 'max']` 같은 특정 요약 유형을 제외할 수 있습니다.

이 속성은 코드를 통해 **실행 중에 동적으로** 바꿀 수도 있어, 변화하는 애플리케이션 상태나 사용자 동작에 맞게 그리드의 요약을 조정할 수 있는 유연성을 제공합니다.

다음 예제는 Ignite UI for Angular 그리드에서 `disabledSummaries` 속성을 사용하여 서로 다른 열의 요약을 관리하고, 특정 기본 요약 및 사용자 지정 요약 유형을 제외하는 방법을 보여 줍니다:

## 요약 서식 지정

기본적으로 내장 요약 피연산자가 만든 요약 결과는 그리드 <ApiLink type="Grid" member="locale" label="locale" />과 열 <ApiLink type="Column" member="pipeArgs" label="pipeArgs" />에 따라 지역화되고 서식이 지정됩니다. 사용자 지정 피연산자를 사용할 때는 `locale`과 `pipeArgs`가 적용되지 않습니다. 요약 결과의 기본 모양을 바꾸고 싶다면 <ApiLink type="Column" member="summaryFormatter" label="summaryFormatter" /> 속성을 사용하여 서식을 지정할 수 있습니다.

```typescript
public dateSummaryFormat(summary: IgxSummaryResult, summaryOperand: IgxSummaryOperand): string {
    const result = summary.summaryResult;
    if(summaryOperand instanceof IgxDateSummaryOperand && summary.key !== 'count'
        && result !== null && result !== undefined) {
        const pipe = new DatePipe('en-US');
        return pipe.transform(result,'MMM YYYY');
    }
    return result;
}
```

```html
<igx-column ... [summaryFormatter]="dateSummaryFormat"></igx-column>
```

## Group By와 함께하는 요약

열 기준으로 그룹화했다면 {ComponentTitle}은(는) <ApiLink type="{ComponentApiType}" member="summaryCalculationMode" label="summaryCalculationMode" />과 <ApiLink type="{ComponentApiType}" member="summaryPosition" label="summaryPosition" /> 속성을 사용하여 요약 위치와 계산 모드를 바꿀 수 있게 합니다. 이 두 속성과 함께 {ComponentName}은(는) <ApiLink type="{ComponentApiType}" member="showSummaryOnCollapse" label="showSummaryOnCollapse" /> 속성을 노출하며, 이는 해당 그룹 행이 접혔을 때 요약 행이 계속 보일지를 결정할 수 있게 합니다.

<ApiLink type="{ComponentApiType}" member="summaryCalculationMode" label="summaryCalculationMode" /> 속성의 사용 가능한 값은 다음과 같습니다:

- rootLevelOnly - 요약은 루트 수준에 대해서만 계산됩니다.
- childLevelsOnly - 요약은 자식 수준에 대해서만 계산됩니다.
- rootAndChildLevels - 요약은 루트 수준과 자식 수준 모두에 대해 계산됩니다. 기본값입니다.

<ApiLink type="{ComponentApiType}" member="summaryPosition" label="summaryPosition" /> 속성의 사용 가능한 값은 다음과 같습니다:

- top - 요약 행이 그룹 행의 자식 앞에 나타납니다.
- bottom - 요약 행이 그룹 행의 자식 뒤에 나타납니다. 기본값입니다.

<ApiLink type="{ComponentApiType}" member="showSummaryOnCollapse" label="showSummaryOnCollapse" /> 속성은 불리언입니다. 기본값은 **false**로 설정되어 있으며, 이는 그룹 행이 접히면 요약 행이 숨겨진다는 뜻입니다. 속성을 **true**로 설정하면 그룹 행이 접혀도 요약 행이 계속 보입니다.

<DocsAside type="info">
<ApiLink type="{ComponentApiType}" member="summaryPosition" label="summaryPosition" /> 속성은 자식 수준 요약에만 적용됩니다. 루트 수준 요약은 항상 {ComponentTitle}의 아래쪽에 고정되어 나타납니다.
</DocsAside>

## 요약 내보내기

`IgxExcelExporterOptions`에는 내보낸 데이터에 그리드의 요약을 포함할지 지정하는 <ApiLink type="ExcelExporterOptions" member="exportSummaries" label="exportSummaries" /> 옵션이 있습니다. 기본 `exportSummaries` 값은 **false**입니다.

내보낸 파일에는 시트의 각 `DataRecord`의 수준을 담은 숨겨진 열이 포함됩니다. 이 수준은 요약에서 요약 함수에 포함되어야 할 셀을 걸러 내는 데 사용됩니다.

아래 표에서 각 기본 요약에 해당하는 Excel 수식을 찾을 수 있습니다.

| 데이터 유형 | 함수 | Excel 함수 |
|:--------|:--------:|:---------------|
|`string`, `boolean` | count | ="Count: "&COUNTIF(start:end, recordLevel) |
|`number`, `currency`, `percent` | count | ="Count: "&COUNTIF(start:end, recordLevel) |
|| min| ="Min: "&MIN(IF(start:end=recordLevel, rangeStart:rangeEnd)) |
|| max | ="Max: "&MAX(IF(start:end=recordLevel, rangeStart:rangeEnd)) |
|| average | ="Avg: "&AVERAGEIF(start:end, recordLevel, rangeStart:rangeEnd) |
|| sum | ="Sum: "&SUMIF(start:end, recordLevel, rangeStart:rangeEnd) |
|`date` | count | ="Count: "&COUNTIF(start:end, recordLevel) |
|| earliest | ="Earliest: "& TEXT(MIN(IF(start:end=recordLevel, rangeStart:rangeEnd)), format) |
|| latest | ="Latest: "&TEXT(MAX(IF(start:end=recordLevel, rangeStart:rangeEnd)), format) |

### 알려진 제한 사항

|제한 사항|설명|
|--- |--- |
| 사용자 지정 요약 내보내기 | 사용자 지정 요약은 Excel 함수가 아니라 문자열로 내보내집니다. |
| 템플릿화된 요약 내보내기 | 템플릿화된 요약은 지원되지 않으며, 기본 요약으로 내보내집니다. |

## 키보드 탐색

요약 행은 다음 키보드 상호 작용으로 탐색할 수 있습니다:

- <kbd>UP</kbd> - 셀 한 칸 위로 이동합니다
- <kbd>DOWN</kbd> - 셀 한 칸 아래로 이동합니다
- <kbd>LEFT</kbd> - 셀 한 칸 왼쪽으로 이동합니다
- <kbd>RIGHT</kbd> - 셀 한 칸 오른쪽으로 이동합니다
- <kbd>CTRL</kbd> + <kbd>LEFT</kbd> 또는 <kbd>HOME</kbd> - 가장 왼쪽 셀로 이동합니다
- <kbd>CTRL</kbd> + <kbd>RIGHT</kbd> 또는 <kbd>END</kbd> - 가장 오른쪽 셀로 이동합니다
