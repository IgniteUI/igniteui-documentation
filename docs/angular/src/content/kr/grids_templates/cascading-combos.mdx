# 연쇄 콤보가 있는 Angular 그리드

그리드의 편집 기능을 사용하면 [연쇄 콤보](/inputs/combo/single-selection#value-and-selection)를 사용할 수 있습니다. 앞선 [콤보](/inputs/combo/overview)에서 값을 선택하면, 사용자는 다음 콤보에서 선택 항목과 관련된 데이터만 받게 됩니다.

## 설정

열 편집을 활성화하려면 <ApiLink type="Column" member="editable" label="editable" /> 속성이 **true**로 설정되어 있는지 확인하십시오.

열 편집을 활성화했으면, [단일 선택 콤보박스](/inputs/combo/single-selection)를 추가하기 시작할 수 있습니다. 여기서 선택 가능한 항목이 하나뿐이도록 하려면, igxCombo를 수정하는 대신 [igxSimpleCombo](/inputs/combo/single-selection)를 사용해야 한다는 점에 유의하십시오.

[Simple ComboBox 컴포넌트](/inputs/combo/single-selection#getting-started)를 시작하려면, 먼저 **app.module.ts** 파일에서 `IgxSimpleComboModule`을(를) 가져와야 합니다:

```typescript
import { IgxSimpleComboModule } from 'igniteui-angular/simple-combo';

@NgModule({
    imports: [
        ...
        IgxSimpleComboModule,
        ...
    ]
})
export class AppModule {}
```

그다음 템플릿에서 콤보의 <ApiLink type="SimpleCombo" label="igx-simple-combo" />을(를) 일부 데이터에 바인딩해야 합니다.

- `displayKey` - _객체 배열에 필요함_ - 항목의 텍스트에 사용할 속성을 지정합니다. <ApiLink type="SimpleCombo" member="displayKey" label="displayKey" />에 값을 지정하지 않으면, 단순 콤보박스는 지정된 `valueKey`(있는 경우)을 사용합니다.

```typescript
export class MySimpleComboComponent implements OnInit {
    public countriesData: Country[];
    public selectedCountry: Country;
    public selectedCity: City;

    public ngOnInit() {
        this.countriesData = getCountries([
            'United States',
            'Japan',
            'United Kingdom'
        ]);
    }
}
```

선택 변경을 처리하려면 <ApiLink type="Combo" member="selectionChanging" label="selectionChanging()" />이(가) 필요합니다. 발생하는 이벤트 인수 <ApiLink type="IComboSelectionChangingEventArgs" kind="interface" />에는 변경 전 선택, 현재 선택, 추가되거나 제거된 항목에 대한 정보가 들어 있습니다. 따라서 이전 콤보의 선택을 기준으로 값을 필터링합니다.

```html
<igx-combo [data]="countriesData" (selectionChanging)="countryChanging($event)"></igx-combo>
```

```typescript
public countryChanging(event: IComboSelectionChangeEventArgs) {
    if (event.added.length) {
        event.newSelection = event.added;
    }
}
```

마지막으로 데이터 목록을 로드하는 동안 필요한 [선형 진행률 막대](../linear-progress.mdx)를 추가합니다.
<ApiLink type="LinearProgressBar" member="id" label="id" />은(는) `id` 속성의 값을 설정하는 데 필요합니다.

```html
 <igx-linear-bar 
    [id]="'region-progress-' + cell.row.data.ID" 
    [style.visibility]="'hidden'"
    type="info" [indeterminate]="true">
</igx-linear-bar>
```
