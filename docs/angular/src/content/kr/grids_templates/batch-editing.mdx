## 사용법

시작하려면 **app.module.ts** 파일에서 `{ComponentName}Module`을(를) 가져오십시오:

```typescript
// app.module.ts

...
import { {ComponentName}Module } from 'igniteui-angular';

@NgModule({
    ...
    imports: [..., {ComponentName}Module],
    ...
})
export class AppModule {}
```

그런 다음 {ComponentTitle}에서 `batchEditing`을(를) 활성화하기만 하면 됩니다:

```html
<{ComponentSelector} [data]="data" [batchEditing]="true">
  ...
</{ComponentSelector}>
```

이렇게 하면 {ComponentSelector}에 대해 올바른 `Transaction` 서비스 인스턴스가 제공됩니다. 올바른 `TransactionService`은(는) `TransactionFactory`을(를) 통해 제공됩니다. 이 내부 구현에 대해서는 [트랜잭션 주제](/transaction-classes#transaction-factory)에서 더 자세히 알아볼 수 있습니다.

일괄 편집이 활성화된 후에는 바인딩된 데이터 소스와 <ApiLink type="{ComponentApiType}" member="rowEditable" label="rowEditable" />를 true로 설정하여 `{ComponentName}`을(를) 정의하고 바인딩하십시오:

<ComponentBlock for="Grid">

다음 코드는 <ApiLink type="GridComponent" member="transactions" /> API - 실행 취소, 다시 실행, 커밋 - 의 사용법을 보여 줍니다.

```typescript
export class GridBatchEditingSampleComponent {
    @ViewChild('grid', { read: IgxGridComponent }) public gridRowEditTransaction: IgxGridComponent;

    public undo() {
        /* exit edit mode and commit changes */
        this.grid.endEdit(true);
        this.grid.transactions.undo();
    }

    public redo() {
        /* exit edit mode and commit changes */
        this.grid.endEdit(true);
        this.grid.transactions.redo()
    }

    public commit() {
        this.grid.transactions.commit(this.data);
        this.toggle.close();
    }
}
```

</ComponentBlock>

<ComponentBlock for="HierarchicalGrid">

다음 코드는 <ApiLink type="GridComponent" member="transactions" /> API - 실행 취소, 다시 실행, 커밋 - 의 사용법을 보여 줍니다.

```typescript
...
export class HierarchicalGridBatchEditingSampleComponent {
    public undo(grid: any) {
        /* exit edit mode and commit changes */
        grid.endEdit(true);
        grid.transactions.undo();
    }

    public redo(grid: any) {
        /* exit edit mode and commit changes */
        grid.endEdit(true);
        grid.transactions.redo();
    }

    public commit() {
        this.hierarchicalGrid.transactions.commit(this.data);
        this.childGrid.hgridAPI.getChildGrids().forEach((grid) => {
            grid.transactions.commit(grid.data);
        });
        this.dialogChanges.close();
    }
}
```

</ComponentBlock>

<DocsAside type="info">
트랜잭션 API는 편집 종료를 처리하지 않으므로, 직접 처리해야 합니다. 그렇지 않으면 `{ComponentTitle}`이(가) 편집 모드에 머무르게 됩니다. 한 가지 방법은 해당 메서드에서 <ApiLink type="Grid" member="endEdit" label="endEdit" />을(를) 호출하는 것입니다.
</DocsAside>

<ComponentBlock for="TreeGrid">

`{ComponentTitle}`에서 상위 노드를 삭제할 때는 몇 가지 특이점이 있습니다. 계층형 데이터를 사용하고 있다면, 상위를 삭제할 때 자식도 함께 삭제됩니다. 평면 데이터를 사용하고 있다면, `{ComponentTitle}`의 <ApiLink type="{ComponentApiType}" member="cascadeOnDelete" label="cascadeOnDelete" /> 속성을 사용하여 원하는 동작을 설정할 수 있습니다. 이 속성은 상위 레코드가 삭제될 때 자식 레코드도 삭제해야 하는지를 나타냅니다(기본적으로 `true`(으)로 설정되어 있습니다).
</ComponentBlock>

<DocsAside type="info">
<ApiLink type="{ComponentApiType}" member="rowEditable" label="rowEditable" /> 속성을 비활성화하면 `{ComponentTitle}`이(가) 변경되어 셀 변경 시 트랜잭션을 만들며, UI에 행 편집 오버레이는 표시되지 않습니다.
</DocsAside>
