# Angular {ComponentTitle} 테마 적용

Ignite UI for Angular {ComponentTitle}은(는) 배경, 전경 및 강조 토큰에서 모든 색상을 도출하는 <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />을(를) 통해 테마가 적용됩니다. 이 세 가지 주요 토큰은 컴포넌트가 렌더링하는 모든 것에 닿습니다. 머리글, 행, 테두리, 요약, 도구 모음, 페이지네이터, 필터링 팝업까지 포함됩니다.

<DocsAside type="info">
그리드마다 별도의 테마 함수는 없습니다. Data Grid, Tree Grid, Hierarchical Grid, Pivot Grid는 모두 `grid-theme()`을(를) 읽으므로, 같은 테마가 수정 없이 이들 중 어느 것에든 적용됩니다.
</DocsAside>

## 시작하기

테마 함수와 `tokens()` 믹스인이 내보내진 테마 진입점을 가져오십시오:

```scss
@use "igniteui-angular/theming" as *;
```

그다음 테마를 선언하고, 영향을 주려는 요소에 포함하십시오:

```scss
:host {
  @include tokens(grid-theme(
    $background: #08002e,
    $accent-color: #ff7d52
  ));
}
```

이것으로 완전한 테마입니다. {ComponentTitle}은(는) 이제 코랄 강조색이 있는 어두운 인디고입니다. 텍스트, 머리글, 행 테두리, 마우스 오버 상태, 선택 색조, 팝업 장식까지 모두 자동으로 계산되었습니다.

## 주요 토큰

{ComponentTitle} 테마는 세 가지 토큰으로 만들어집니다. 다른 모든 색상은 이들로부터 도출됩니다.

| 토큰 | 제어하는 대상 |
| -- | -- |
| `$background` | 컴포넌트 전체가 바탕으로 하는 표면입니다. 다른 모든 표면과 기본 전경은 여기서 도출됩니다. |
| `$foreground` | 텍스트와 아이콘입니다. 설정하지 않으면 대비를 기준으로 `$background`에서 도출됩니다. |
| `$accent-color` | 상호 작용 색상입니다. 정렬 표시기, 선택, 마우스 오버 색조, 포커스에 사용됩니다. |

`$foreground`은(는) 주요 토큰으로 나열되어 있지만 설정할 필요는 드뭅니다. 그대로 두면 배경과의 대비를 기준으로 선택되므로, 어두운 배경에는 밝은 텍스트가, 밝은 배경에는 어두운 텍스트가 두 번째 선언 없이도 적용됩니다.

## 도출이 작동하는 방식

테마를 선언할 때, 도출된 토큰은 빌드 시점에 고정 색상으로 해석되지 않습니다. 대신 여러분이 제공한 주요 토큰에 대한 CSS 식으로 내보내집니다:

```css
.my-grid {
  --ig-grid-foreground: hsla(from color(from var(--ig-grid-background) var(--y-contrast)) h 0 l/1);
  --ig-grid-header-background: color-mix(in srgb, var(--ig-grid-foreground) 6%, var(--ig-grid-background));
  --ig-grid-row-hover-background: color-mix(in srgb, var(--ig-grid-accent-color) 8%, var(--ig-grid-row-odd-background));
  --ig-grid-sorted-header-icon-color: hsl(from var(--ig-grid-accent-color) h s l/0.7);
}
```

이로부터 두 가지 결과가 따릅니다. 주요 토큰을 바꾸면 하위의 모든 것이 다시 계산되며, 실행 중에도 CSS 사용자 지정 속성을 통해 그렇게 됩니다. 또한 어떤 값을 제공하든 이 관계는 유지되므로, 테마가 스스로와 어긋나는 일이 없습니다.

## 더 깊이 들어가기

일부 토큰은 그 자체로 도출의 기준점입니다. 이를 선언하면 배경에서 분리되며, 그 위에 놓이는 요소들은 대신 새 값에서 도출됩니다.

`$header-background`이(가) 가장 명확한 예입니다. 그대로 두면 `$background`에서 혼합되며, 머리글 텍스트는 `$foreground`을(를) 따릅니다. 이를 선언하면 머리글 텍스트는 머리글 자체와의 대비를 기준으로 다시 도출됩니다:

```scss
:host {
  @include tokens(grid-theme(
    $background: #08002e,
    $accent-color: #ff7d52,
    $header-background: #ff7d52
  ));
}
```

<DocsAside type="note">
표면이 배경을 따르지 않도록 하고 싶을 때만 이것들을 사용하십시오. 테마가 자동 도출된다고 문서화한 대부분의 토큰은 그대로 두는 것이 가장 좋습니다. 하나를 재정의하면 테마의 나머지와 맞춰지던 값이 고정되기 때문입니다.
</DocsAside>

## 구조

색상은 테마의 절반일 뿐입니다. 밀도와 둥근 정도는 `grid-theme()` 매개변수가 아니라 전역 디자인 시스템 토큰으로 제어되므로, 일반 사용자 지정 속성으로 설정합니다:

```scss
:host {
  --ig-size: var(--ig-size-small);   // small | medium | large
  --ig-radius-factor: 0;             // 0 to 1

  @include tokens(grid-theme(
    $background: #08002e,
    $accent-color: #ff7d52
  ));
}
```

그리드 선은 테마 매개변수입니다. 하나를 숨기려면 제거하지 말고, 그 뒤의 표면과 같은 색조로 칠하십시오. 그래야 테마마다 행 치수가 바뀌지 않습니다:

```scss
@include tokens(grid-theme(
  // horizontal dividers, blended away
  $row-border-color: var(--ig-grid-background),
  // vertical dividers, drawn in the same color the theme derives for rows
  $body-column-border-color-odd: hsl(from color-mix(in srgb, var(--ig-grid-foreground) 16%, var(--ig-grid-background)) h s l/0.38),
  $body-column-border-color-even: hsl(from color-mix(in srgb, var(--ig-grid-foreground) 16%, var(--ig-grid-background)) h s l/0.38)
));
```

## {ComponentTitle} 안의 컴포넌트

{ComponentTitle}은(는) 렌더링하는 컴포넌트도 테마를 적용합니다. 행 선택기, 칩, 배지, 버튼, 입력, 드롭다운, 툴팁, 페이지네이터, 도구 모음, 필터링 팝업이 여기에 포함됩니다. 이들은 자체 호스트에 토큰을 선언하며, 그 토큰은 주요 토큰에서 도출됩니다. 따라서 상위 요소에 이 컴포넌트들을 위해 설정한 토큰은 이들에게 닿지 않습니다. `.promo { @include tokens(checkbox-theme($fill-color: #ff7d52)); }`은(는) `.promo`의 체크박스 색상을 바꾸지만, 그 안에 있는 {ComponentTitle}의 행 선택기는 바꾸지 않습니다.

안쪽 컴포넌트의 색상을 바꾸려면 {ComponentTitle}의 테마를 적용하십시오. 안쪽 각 컴포넌트는 하나 이상의 주요 토큰을 따릅니다. 강조 색상은 행 선택기, 배지, 버튼, 입력에 닿고, 툴팁은 전경을 따르며, 칩은 배경과 전경을 모두 따릅니다:

```scss
.promo {
  @include tokens(grid-theme($accent-color: #ff7d52));
}
```

{ComponentTitle}의 색상을 바꾸지 않고 한 컴포넌트만 재정의하려면, 그 컴포넌트를 대상으로 하십시오. 컴포넌트 자체에 선언된 토큰이 {ComponentTitle}이(가) 선언한 토큰보다 우선합니다:

```scss
.promo igx-checkbox {
  @include tokens(checkbox-theme($fill-color: #ff7d52));
}

.promo .igx-tooltip {
  @include tokens(tooltip-theme($background: #ff7d52));
}
```

## CSS 변수

기본 모양은 도출된 것이 아니라 의도된 것입니다. 기본 상태에서 {ComponentTitle}은(는) 배경에서 색상을 계산하지 않고, 기본 팔레트를 기준으로 Ignite UI 디자인 사양과 정확히 맞춰집니다. 도출은 여러분이 자신의 테마를 선언할 때 선택하는 방식입니다.

이것은 CSS 전용 테마에 실용적인 결과를 하나 줍니다. 테마를 선언하기 전에는 재정의할 도출 식이 없으며, 컴포넌트는 `var(--ig-grid-header-background, var(--ig-gray-100))`과 그 형제들을 읽습니다. 따라서 몇 개의 사용자 지정 속성을 직접 설정해도 **캐스케이드되지 않습니다**:

```css
/* Not enough on its own: the background changes, the header stays grey. */
.my-grid {
  --ig-grid-background: #08002e;
  --ig-grid-accent-color: #ff7d52;
}
```

Sass 빌드 없이 테마를 적용하려면 **전체 토큰 집합**, 즉 기준점과 그것을 참조하는 도출 식을 선언하십시오. 각 도출 토큰은 기준점에 대한 식이므로 이 블록은 독립적입니다:

```css
.my-grid {
  --ig-grid-background: #08002e;
  --ig-grid-accent-color: #ff7d52;
  --ig-grid-foreground: hsla(from color(from var(--ig-grid-background) var(--y-contrast)) h 0 l/1);
  --ig-grid-header-background: color-mix(in srgb, var(--ig-grid-foreground) 6%, var(--ig-grid-background));
  /* … and the rest of the theme's tokens */
}
```

이것을 손으로 생성하는 것은 현실적이지 않으므로, 아래 플레이그라운드를 사용하십시오. 선택한 색상에 대한 전체 블록을 내보냅니다.

<DocsAside type="note">
가능하면 Sass 방식을 선호하십시오. `grid-theme()`은(는) 도출 토큰을 대신 작성하고 라이브러리와 맞춰 유지합니다. 손으로 관리하는 CSS 블록은 스냅샷이므로 테마의 변경을 반영하지 않습니다.
</DocsAside>
