# Angular {ComponentTitle} 다중 열 머리글 개요

<ApiLink type="{ComponentApiType}" />은(는) `multi-column headers`을(를) 지원하며, 이를 통해 공통 다중 머리글 아래에 열을 배치하여 그룹화할 수 있습니다. 각 다중 열 머리글 그룹은 Material UI 그리드 안의 다른 그룹이나 열 사이의 조합을 나타낼 수 있습니다.

모든 <ApiLink type="ColumnGroup" label="igx-column-group" />은(는) [`moving`](/{igPath}/column-moving), [`pinning`](/{igPath}/column-pinning) 및 [`hiding`](/{igPath}/column-hiding)을 지원합니다.
<DocsAside type="info">
열과 열 그룹의 집합이 있을 때, 고정은 최상위 열 상위 항목에 대해서만 작동합니다. 더 구체적으로, 중첩된 `column groups` 또는 `columns`별 고정은 허용되지 않습니다. <br />
다중 열 머리글과 함께 고정을 사용할 때는 그룹 전체가 고정된다는 점에 유의하십시오. <br />
`columns`과 `column groups` 사이의 이동은 두 항목이 계층에서 같은 수준에 있고 둘 다 같은 `group` 안에 있을 때만 허용됩니다. <br />
`columns/column-groups`이(가) 현재 `group`에 감싸이지 않은 경우, 즉 **최상위 수준**의 `columns`인 경우, 보이는 열 전체 사이에서 이동할 수 있습니다.
</DocsAside>

## 다중 열 머리글 템플릿

그리드의 각 열 그룹은 개별적으로 템플릿화할 수 있습니다. 열 그룹은 `igxHeader` 디렉티브로 장식된 `ng-template` 태그를 기대합니다.
`ng-template`에는 열 그룹 객체가 컨텍스트로 제공됩니다.

```html
...
<igx-column-group header="General Information">
    <ng-template igxHeader let-columnGroup>
        {{ columnGroup.header | uppercase }}
    </ng-template>
    ...
</igx-column-group>
...
```

여러 열 그룹에 단일 템플릿을 재사용하려면, 다음과 같이 열 그룹의 <ApiLink type="ColumnGroup" member="headertemplate" label="headerTemplate" /> 속성을 설정할 수 있습니다:

```html
<ng-template #columnGroupHeaderTemplate let-columnGroup>
    {{ columnGroup.header | uppercase }}
</ng-template>

...
<igx-column-group header="General Information" [headerTemplate]="columnGroupHeaderTemplate">
    ...
</igx-column-group>
<igx-column-group header="Address Information" [headerTemplate]="columnGroupHeaderTemplate">
    ...
</igx-column-group>
...
```

<DocsAside type="info">
열 머리글을 다시 템플릿화하고 그리드 이동이 활성화되어 있다면, 템플릿화된 요소에서 해당 열의 **draggable** 속성을 **false**로 설정해야 적용된 모든 이벤트를 처리할 수 있습니다!
</DocsAside>

```html
<ng-template igxHeader>
    <igx-icon [attr.draggable]="false" (click)="onClick()"></igx-icon>
</ng-template>
```

다음 샘플은 머리글 템플릿을 사용하여 접을 수 있는 열 그룹을 구현하는 방법을 보여 줍니다.

## 스타일링

정렬 동작의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />을(를) 확장하고 `$header-background`, `$header-text-color`, `$header-border-width`, `$header-border-style` 및 `$header-border-color` 매개변수를 받는 새 테마를 만듭니다.

<ComponentBlock for="Grid">

```scss
$custom-theme: grid-theme(
  $header-background: #e0f3ff,
  $header-text-color: #e41c77,
  $header-border-width: 1px,
  $header-border-style: solid,
  $header-border-color: rgba(0, 0, 0, 0.08)
);
```

</ComponentBlock>
<ComponentBlock for="TreeGrid">

```scss
$custom-theme: grid-theme(
  $header-background: #f1eaf6,
  $header-text-color: #8c1bdd,
  $header-border-width: 1px,
  $header-border-style: solid,
  $header-border-color: #d3b9e6,
  $cell-active-border-color: #7409c1
);
```

</ComponentBlock>
<ComponentBlock for="HierarchicalGrid">

```scss
$custom-theme: grid-theme(
  $header-background: #f8f8ed,
  $header-text-color: #7a6551,
  $header-border-style: dashed,
  $header-border-color: rgba(0, 0, 0, 0.08)
);
```

</ComponentBlock>

<DocsAside type="info">
방금 한 것처럼 색상 값을 직접 하드코딩하는 대신, <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> 및 <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} /> 함수를 사용하면 색상을 훨씬 유연하게 다룰 수 있습니다. 사용 방법에 대한 자세한 안내는 [`Palettes`](/themes/sass/palettes) 항목을 참조하십시오.
</DocsAside>

마지막 단계는 `tokens()`으로 컴포넌트 테마를 적용하는 것입니다:

```scss
:host {
  @include tokens($custom-theme);
}
```
