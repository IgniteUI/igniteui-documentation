# Angular {ComponentTitle} 열 선택

열 선택 기능은 한 번의 클릭으로 열 전체를 쉽게 선택할 수 있게 합니다. 머리글 셀과 그 아래의 모든 것에 초점을 맞춰 특정 열의 중요성을 강조합니다. 이 기능은 선택 상태를 조작하고, 선택된 부분에서 데이터를 추출하며, 데이터 분석 작업과 시각화를 수행할 수 있는 풍부한 `API`을(를) 제공합니다.

## 기본 사용법

열 선택 기능은 <ApiLink kind="variable" type="GridSelectionMode" /> 값을 받는 <ApiLink type="{ComponentApiType}" member="columnSelection" label="columnSelection" /> 입력을 통해 활성화할 수 있습니다.

## 상호 작용

기본 선택 모드는 `none`입니다. `single` 또는 `multiple`(으)로 설정하면 표시된 모든 열이 <ApiLink type="Column" member="selectable" label="selectable" />됩니다. 그렇다고 해도, 열을 선택하려면 그냥 열 하나를 클릭하면 되며, 그러면 그 열은 <ApiLink type="Column" member="selected" label="selected" />(으)로 표시됩니다. 열이 선택할 수 없는 상태라면, 마우스를 올려도 머리글에 선택 스타일이 적용되지 않습니다.

<DocsAside type="info">
[`Multi-column Headers`](/{igPath}/multi-column-headers)은(는) <ApiLink type="Column" member="selectable" label="selectable" /> 입력에 반영되지 않습니다. <ApiLink type="ColumnGroup" />은(는) 자식 중 최소 하나에 선택 동작이 활성화되어 있으면 <ApiLink type="Column" member="selectable" label="selectable" />이(가) 되며, 또한 모든 `selectable` 하위 항목이 <ApiLink type="Column" member="selected" label="selected" />이면 컴포넌트는 <ApiLink type="ColumnGroup" member="selected" label="selected" />(으)로 표시됩니다.
</DocsAside>

## 키보드 조합

<DocsAside type="info">
키보드 조합은 그리드의 <ApiLink type="{ComponentApiType}" member="columnselection" label="columnSelection" /> 입력이 `multiple`(으)로 설정된 경우에만 사용할 수 있습니다.
</DocsAside>

**열 선택** 기능의 키보드 탐색에는 두 가지 시나리오가 있습니다:

- 다중 열 선택 - 선택할 수 있는 각 **선택 가능한** 머리글 셀을 <kbd>ctrl</kbd> + <kbd>클릭</kbd>한 상태로 유지합니다.
- 범위 열 선택 - <kbd>shift</kbd> + <kbd>클릭</kbd>을 누른 상태로 유지하면 그 사이에 있는 모든 **선택 가능한** 열이 선택됩니다.

## API 조작

**API**는 **보이지 않는** 열에 대해 몇 가지 추가 기능을 제공합니다. 즉, 해당 **setter**를 설정하여 모든 **숨겨진** 열을 <ApiLink type="Column" member="selected" label="selected" />(으)로 표시할 수 있습니다.

<DocsAside type="info">
위 설명은 <ApiLink type="ColumnGroup" />에도 적용되며, 다만 <ApiLink type="ColumnGroup" member="selected" label="selected" /> 속성이 바뀌면 그 하위 항목의 상태도 바뀐다는 점이 다릅니다.
</DocsAside>

API 조작에 대한 자세한 정보는 [`API References`](#api-references) 섹션에서 찾을 수 있습니다.

## 스타일링

스타일 지정 옵션을 살펴보기 전에, 테마 모듈을 가져와야 합니다.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

<DocsAside type="info">
[`row selection`](/{igPath}/row-selection)과(와) [`column selection`](/{igPath}/column-selection)은(는) 독립적으로 조작할 수 없다는 점에 유의하십시오. 둘은 같은 `variables`에 의존합니다.
</DocsAside>

이제 **선택** 및 **마우스 오버** 스타일을 바꾸어 보겠습니다.<br/>
가장 간단한 방법으로, 사용자 지정 **테마**를 정의하겠습니다.

<ComponentBlock for="TreeGrid">

```scss
$background: #0b0119;
$foreground: #eeece1;
$accent: #f6b560;

$grid-theme: grid-theme(
  $background: $background,
  $foreground: $foreground,
  $accent-color: $accent,
  
  $row-selected-background: #012724,
  $row-selected-text-color: $accent,
  $header-selected-text-color: $accent,
  $header-selected-background: #012427,
  
  $row-selected-hover-background: hsl(from #012427 h s 10%),
  $row-selected-hover-text-color: $accent,
);
```

</ComponentBlock>
<ComponentBlock for="Grid, HierarchicalGrid, PivotGrid">

```scss
$background: #011627;
$accent: #ecaa53;

$custom-grid-theme: grid-theme(
  $row-selected-background: $background,
  $row-selected-text-color: $accent,
  $row-selected-hover-background: hsl(from $background h s 10%),
  $row-selected-hover-text-color: $accent,
  $header-selected-text-color: $accent,
  $header-selected-background: $background,
);
```

</ComponentBlock>

<ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />은(는) 여러 매개변수를 받지만, 선택된 모든 열의 모양을 바꾸는 다음 다섯 가지 매개변수가 핵심입니다:

- **$row-selected-background** - 선택된 부분의 배경을 설정합니다.
- **$row-selected-text-color** - 선택된 부분의 텍스트 색상을 설정합니다
- **$row-selected-hover-background** - 마우스 오버된 셀 또는 셀 그룹의 색상을 설정합니다.
- **$row-selected-hover-text-color** - 마우스 오버된 셀 또는 셀 그룹의 텍스트 색상을 설정합니다.
- **$header-selected-text-color** - 선택된 열 머리글의 텍스트 색상을 설정합니다
- **$header-selected-background** - 선택된 열 머리글의 배경 색상을 설정합니다.

### CSS 변수 사용하기

마지막 단계는 사용자 지정 그리드 테마를 **포함**하는 것입니다.

```scss
:host {
  @include tokens($custom-grid-theme)
}
```
