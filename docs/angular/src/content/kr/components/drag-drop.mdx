Ignite UI for Angular Drag and Drop 디렉티브를 사용하면 페이지에서 요소를 끌 수 있습니다. 지원되는 기능에는 자유 드래그, 드래그 핸들 사용, 드래그 고스트, 애니메이션 및 여러 드롭 전략이 포함됩니다.

## Ignite UI for Angular Drag and Drop 시작하기

Ignite UI for Angular Drag and Drop 디렉티브를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxDragDropModule`을 가져오는 것입니다.

```typescript
// app.module.ts

...
import { IgxDragDropModule } from 'igniteui-angular/directives';
// import { IgxDragDropModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxDragDropModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxDragDirective` 및 `IgxDropDirective`을(를) 독립형 종속성으로 가져올 수 있으며, 또는 [`IGX_DRAG_DROP_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/directives/src/directives/drag-drop/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수 있습니다.

```typescript
// home.component.ts

import { IGX_DRAG_DROP_DIRECTIVES } from 'igniteui-angular/directives';
// import { IGX_DRAG_DROP_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <div igxDrag>Drag me
</div>
    <div igxDrop>Drop here
</div>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_DRAG_DROP_DIRECTIVES]
    /* or imports: [IgxDragDirective, IgxDropDirective] */
})
export class HomeComponent {}
```

이제 Ignite UI for Angular Drag and Drop 모듈 또는 디렉티브를 가져왔으므로, `igxDrag` 및 `igxDrop` 디렉티브를 사용하기 시작할 수 있습니다.

## Angular 드래그 디렉티브 사용하기

Angular 애플리케이션 안의 요소를 페이지의 한 위치에서 다른 위치로 끌어야 할 때, <ApiLink type="DragDirective" label="igxDrag" /> 디렉티브가 이 동작을 구현하도록 설계되어 있습니다. <ApiLink type="DropDirective" label="igxDrop" /> 디렉티브와 함께 사용하면 끌린 요소의 배치도 처리할 수 있으므로 완전히 상호 작용하는 애플리케이션을 만들 수 있습니다.

### 드래그 기본 원리

최종 사용자가 어느 방향으로든 최소 5px 이상 스와이프하면 드래그 작업이 시작됩니다. 이 값은 사용자 지정할 수 있으며 <ApiLink type="DragDirective" member="dragTolerance" label="dragTolerance" /> 입력을 사용하여 변경할 수 있습니다. 그렇지 않으면 상호 작용은 클릭으로 간주되고 `dragClick` 이벤트가 트리거됩니다.

드래그가 시작되면 <ApiLink type="DragDirective" member="dragStart" label="dragStart" /> 이벤트가 트리거됩니다. 실제 이동이 일어나지 않도록 하려면 <ApiLink kind="interface" type="IDragStartEventArgs" member="cancel" /> 속성을 `true`(으)로 설정하여 이벤트를 취소할 수 있습니다.

실제 이동이 수행되기 직전에 <ApiLink type="DragDirective" member="dragMove" label="dragMove" /> 이벤트도 트리거되며, 이 이벤트에는 포인터의 마지막 위치와 다음 위치가 포함됩니다. 요소를 끌고 있는 동안 이동이 감지될 때마다 트리거됩니다.

사용자가 마우스/터치를 놓으면 드래그 고스트 요소가 DOM에서 제거되고 <ApiLink type="DragDirective" member="dragEnd" label="dragEnd" /> 이벤트가 발생합니다.

<DocsAside type="info">
<ApiLink type="DragDirective" member="dragMove" label="dragMove" /> 이벤트의 특성상 짧은 시간 안에 여러 번 트리거될 수 있으므로, 트리거될 때 수행되는 복잡한 작업에서는 성능 문제가 생길 수 있습니다.
</DocsAside>

### 고스트와 함께 드래그하기

<ApiLink type="DragDirective" label="igxDrag" /> 디렉티브는 템플릿에 추가하기만 하면 모든 DOM 요소에 적용할 수 있습니다.

```html
<div igxDrag>Drag me
</div>
```

`igxDrag` 디렉티브의 기본 동작은 기본 요소를 수정하지 않고 두고, 최종 사용자가 드래그 작업을 수행할 때 고스트 요소를 만드는 것입니다.

고스트가 페이지에 렌더링되기 전에, 추가될 고스트 요소의 정보를 담은 <ApiLink type="DragDirective" member="ghostCreate" label="ghostCreate" /> 이벤트가 트리거됩니다. 이 이벤트는 <ApiLink type="DragDirective" member="dragStart" label="dragStart" /> 이벤트 직후에 트리거됩니다. <ApiLink type="DragDirective" member="dragStart" label="dragStart" />이(가) 취소되면 고스트가 생성되지 않으며 <ApiLink type="DragDirective" member="ghostCreate" label="ghostCreate" /> 이벤트도 그에 맞춰 트리거되지 않습니다.

고스트가 제거되기 직전에 <ApiLink type="DragDirective" member="ghostDestroy" label="ghostDestroy" /> 이벤트가 트리거됩니다.

### 고스트 사용자 지정하기

고스트 요소는 기본적으로 `igxDrag`이(가) 적용된 기본 요소의 복사본입니다. <ApiLink type="DragDirective" member="ghostTemplate" label="ghostTemplate" /> 입력에 템플릿 참조를 직접 제공하여 사용자 지정할 수 있습니다.

```html
<div class="email-content flexlist"
 igxDrag
 [ghostTemplate]="customGhost">
 <div class="sender">

  {{email.sender}} 
 
</div>
 <div class="email-title">

  {{email.title}}
 
</div>
</div>
<ng-template #customGhost>
 <div class="dragGhost">

  <igx-icon fontSet="material">email</igx-icon> 
  Moving {{ draggedElements }} item{{ (draggedElements > 1 ? 's' : '')}}
 
</div>
</ng-template>

```

<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

### 고스트 없이 드래그하기

`igxDrag` 디렉티브가 적용된 기본 요소 자체를 이동하고 싶다면, <ApiLink type="DragDirective" member="ghost" label="ghost" /> 입력을 `false`(으)로 설정하면 됩니다. 이렇게 하면 추가 고스트 요소가 렌더링되지 않으며, 요소를 드래그할 때 사용자 지정 스타일을 적용해야 한다면 기본 요소에 직접 적용할 수 있습니다.

```html
<div igxDrag [ghost]="false">Drag me
</div>
```

### 핸들을 사용하여 드래그하기

기본적으로 요소 전체가 드래그 동작에 사용되므로, `igxDrag`의 하위 요소 중 드래그에 사용할 요소를 지정할 수 있습니다. 이는 `igxDragHandle` 디렉티브를 사용하여 설정할 수 있으며, `igxDrag` 안의 여러 요소에 적용할 수 있습니다.

```html
<div
    igxDrag 
    [ghost]="false"
    [dragTolerance]="0"
    (dragMove)=onDragMove($event)>
    <igx-icon igxDragHandle fontSet="material" class="dialogHandle">drag_indicator</igx-icon>
    <div class="igx-dialog__window">

    
</div>
</div>
```

### 애니메이션

요소를 드래그하는 동안에는 기본적으로 애니메이션이 적용되지 않습니다.

`igxDrag`에는 언제든지 전환 애니메이션을 적용할 수 있지만, 드래그가 끝났을 때나 요소가 현재 드래그되고 있지 않을 때 사용하는 것이 좋습니다. 이는 <ApiLink type="DragDirective" member="transitionToOrigin" label="transitionToOrigin" /> 및 <ApiLink type="DragDirective" member="transitionTo" label="transitionTo" /> 메서드를 사용하여 구현할 수 있습니다.

<ApiLink type="DragDirective" member="transitionToOrigin" label="transitionToOrigin" /> 메서드는 이름에서 알 수 있듯이, 현재 드래그 중인 요소 또는 그 고스트를 드래그가 시작된 시작 위치로 애니메이션합니다. <ApiLink type="DragDirective" member="transitionTo" label="transitionTo" /> 메서드는 요소를 페이지를 기준으로 한 특정 위치(즉 `pageX` 및 `pageY`) 또는 지정된 요소의 위치로 애니메이션합니다. 요소가 현재 드래그 중이 아니더라도 애니메이션은 실행되며, 고스트를 만들어 원하는 위치로 애니메이션합니다.

두 함수 모두 전환 애니메이션을 사용자 지정하고 지속 시간, 타이밍 함수 또는 지연을 설정하는 인수를 가지고 있습니다. 특정 시작 위치가 설정되어 있으면 그 위치에서부터 요소를 애니메이션합니다.

전환 애니메이션이 끝나면, 고스트가 만들어졌다면 제거되고 `igxDrag` 디렉티브는 초기 상태로 돌아갑니다. 고스트가 만들어지지 않았다면 요소는 현재 위치를 유지합니다. 두 경우 모두 애니메이션이 지속되는 시간에 따라 <ApiLink type="DragDirective" member="transitioned" label="transitioned" /> 이벤트가 트리거됩니다. 애니메이션이 적용되지 않으면 즉시 트리거됩니다.

요소 변형이 포함된 다른 종류의 애니메이션도 사용할 수 있습니다. 이는 다른 요소와 마찬가지로 Angular 애니메이션이나 순수 CSS 애니메이션을 사용하여 기본 `igxDrag` 요소 또는 그 고스트에 적용할 수 있습니다. 고스트에 적용하려면 사용자 지정 고스트를 정의하고 그 요소에 애니메이션을 적용해야 합니다.

드래그 핸들을 사용하여 목록의 항목 순서를 바꾸십시오. 목록 항목을 드래그하면 다른 목록 항목이 애니메이션과 함께 재정렬됩니다.

### 드래그 가능한 요소 무시하기

igxDrag가 인스턴스화된 상호 작용 가능한 하위 요소를 기본 요소 안에 두고 싶다면, <ApiLink type="DragIgnoreDirective" /> 디렉티브를 설정하여 이 요소들이 igxDrag에 의해 무시되고 드래그 동작을 수행하지 않도록 할 수 있습니다. 이렇게 하면 이 요소들은 완전히 상호 작용 가능한 상태를 유지하고 모든 마우스 이벤트를 받습니다.

```html
<div [igxDrag]="myData">
    <span>Drag me!</span>
    <igx-icon igxDragIgnore fontSet="material" (click)="remove()">bin</igx-icon>
</div>
```

## Angular 드롭 디렉티브 사용하기

<ApiLink type="DragDirective" label="igxDrag" /> 디렉티브를 사용하여 드래그 중인 요소를 특정 영역에 놓아야 할 때는 <ApiLink type="DropDirective" label="igxDrop" />를 사용하여 이 동작을 구현할 수 있습니다. 이는 요소가 적용된 요소의 경계에 들어오는지, 그리고 그 안에서 놓였는지를 판단하는 데 사용할 수 있는 이벤트를 제공합니다.

<ApiLink type="DropDirective" label="igxDrop" /> 디렉티브는 <ApiLink type="DragDirective" label="igxDrag" /> 디렉티브와 마찬가지로 모든 DOM 요소에 적용할 수 있습니다.

기본적으로 <ApiLink type="DropDirective" label="igxDrop" /> 디렉티브는 DOM에서 드래그된 요소의 위치를 수정하는 로직을 적용하지 않습니다. 따라서 <ApiLink type="DropDirective" member="dropStrategy" label="dropStrategy" />을(를) 지정하거나 사용자 지정 로직을 적용해야 합니다. 드롭 전략은 다음 섹션에서 다룹니다.

### 드롭 전략

`igxDrop`에는 네 가지 드롭 전략이 있습니다: `Default`, `Prepend`, `Insert` 및 `Append`:

- `Default` - 요소가 `igxDrop` 요소 위에 놓일 때 아무 작업도 수행하지 않으며, <ApiLink type="DefaultDropStrategy" />이라는 클래스로 구현됩니다.

- `Append` - 놓인 요소를 항상 마지막 자식으로 삽입하며, <ApiLink type="AppendDropStrategy" />이라는 클래스로 구현됩니다.

- `Prepend` - 놓인 요소를 항상 첫 번째 자식으로 삽입하며, <ApiLink type="PrependDropStrategy" />이라는 클래스로 구현됩니다.

- `Insert` - 끌린 요소를 마지막 위치에 삽입합니다. 다만 놓였을 때 요소 아래에 자식이 있었다면, `igxDrag` 인스턴스 요소는 그 자식의 위치에 삽입되고 나머지 자식들은 밀려납니다. <ApiLink type="InsertDropStrategy" />이라는 클래스로 구현됩니다.

전략은 `dropStrategy` 입력을 위에 나열된 클래스 중 하나로 설정하여 적용할 수 있습니다. 제공되는 값은 인스턴스가 아니라 타입이어야 합니다. `igxDrop`이(가) 인스턴스를 직접 만들고 관리해야 하기 때문입니다.

```typescript
public appendStrategy = IgxAppendDropStrategy;
```

```html
<div igxDrop [dropStrategy]="appendStrategy"></div>
```

#### 드롭 전략 취소하기

특정 드롭 전략을 사용할 때, <ApiLink type="DropDirective" member="dropped" label="dropped" /> 이벤트에서 `cancel` 속성을 true로 설정하면 그 동작을 취소할 수 있습니다. `dropped` 이벤트는 `igxDrop`에 한정됩니다. `igxDrop`에 드롭 전략이 적용되어 있지 않다면 이벤트를 취소해도 부작용은 없습니다.

_예:_

```html
<div igxDrag></div>
{/* ... */}
<div igxDrop (dropped)="onDropped($event)"></div>
```

```typescript
public onDropped(event) {
    event.cancel = true;
}
```

직접 드롭 로직을 구현하려면 `dropped` 이벤트에 바인딩하여 그 안에서 로직을 실행하거나 `IgxDefaultDropStrategy` 클래스를 확장하는 것을 권장합니다.

### 드래그 요소와 드롭 요소 연결하기

각각 `igxDrag` 및 `igxDrop` 디렉티브에 <ApiLink type="DragDirective" member="dragChannel" label="dragChannel" />과 <ApiLink type="DropDirective" member="dropChannel" label="dropChannel" /> 입력을 사용하면, 서로 다른 요소들이 서로 간에만 상호 작용하도록 연결할 수 있습니다. 예를 들어 `igxDrag` 요소가 사용 가능한 모든 요소가 아니라 특정 `igxDrop` 요소 위에만 놓이도록 제한해야 한다면, 같은 채널을 할당하여 쉽게 구현할 수 있습니다.

```html
<div igxDrag [dragChannel]="['Mammals', 'Land']"> Human 
</div>
<div igxDrag [dragChannel]="['Mammals', 'Water']"> Dolphin 
</div>
<div igxDrag [dragChannel]="['Insects', 'Air']"> Butterfly 
</div>
<div igxDrag [dragChannel]="['Insects', 'Land']"> Ant 
</div>

<div igxDrop [dropChannel]="['Mammals']"> Mammals 
</div>
<div igxDrop [dropChannel]="['Insects']"> Insects 
</div>
<div igxDrop [dropChannel]="['Land']"> Land 
</div>
```

## 고급 구성

`igxDrag`과 `igxDrop`를 함께 사용하면 다양한 복잡한 애플리케이션 시나리오에서 쓸 수 있으므로, 다음 예제는 칸반 보드에서 이를 사용하는 방법을 보여 줍니다.

사용자는 각 열의 카드 순서를 바꿀 수 있습니다. 이를 위해 각 카드에도 드롭 영역을 설정하여, 다른 카드가 자신의 영역에 들어오는 것을 감지하고 실행 중에 위치를 바꿀 수 있도록 합니다. 이렇게 하면 더 나은 사용자 경험을 제공합니다.

카드를 열 사이에서 옮길 수 있어야 칸반 보드라고 할 수 있습니다. 카드를 특정 위치에서 다른 열로 바로 옮길 수 있습니다. 여기서는 더미 객체를 사용하여 이를 구현합니다. 더미 객체는 카드를 놓았을 때 카드가 위치할 시각적 영역을 만듭니다. 더미 객체는 카드 드래그가 끝나거나 다른 열을 벗어나면 제거됩니다.

칸반 보드에서 항목을 끌어서 이동하십시오.
