# PDF Exporter

<div class="highlight">

Ignite UI for Angular PDF Exporter 서비스는 원시 데이터 배열과 [**IgxGrid**](/grid/grid), [**IgxTreeGrid**](/treegrid/tree-grid), [**IgxHierarchicalGrid**](/hierarchicalgrid/hierarchical-grid), [**IgxPivotGrid**](/pivotgrid/pivot-grid) 같은 고급 그리드 컴포넌트를 포함한 다양한 소스에서 PDF 형식으로 데이터를 내보내는 강력한 기능을 제공합니다. 내보내기 기능은 <ApiLink type="PdfExporterService" /> 클래스에 캡슐화되어 있으며, 여러 페이지 문서 지원, 자동 페이지 나누기, 사용자 지정 가능한 서식 옵션 등 포괄적인 기능으로 PDF 형식의 원활한 데이터 내보내기를 가능하게 합니다.

## 사용법

Ignite UI PDF Exporter를 사용하려면 먼저 컴포넌트에 <ApiLink type="PdfExporterService" />을(를) 가져오십시오:

```typescript
import { IgxPdfExporterService } from 'igniteui-angular/grids/core';

// import { IgxPdfExporterService } from '@infragistics/igniteui-angular/grids/core'; for licensed package

@Component({
  ...
})
export class AppComponent { ... }
```

내보내기 과정을 시작하려면 컴포넌트 템플릿의 버튼 클릭 핸들러를 사용할 수 있습니다.

```html
<button (click)="exportButtonHandler()">Export Data to PDF</button>
```

`inject` 함수를 사용하여 <ApiLink type="PdfExporterService" />에 접근할 수 있습니다. 데이터를 PDF 형식으로 내보내려면 내보내기 서비스의 <ApiLink type="PdfExporterService" member="exportdata" label="exportData" /> 메서드를 호출해야 합니다. 이 메서드는 첫 번째 인수로 내보낼 데이터를 받고, 두 번째 인수로 <ApiLink type="PdfExporterOptions" /> 인스턴스를 받아 내보내기 과정을 구성할 수 있게 합니다.

다음은 컴포넌트의 TypeScript 파일에서 내보내기 과정을 실행하는 코드입니다:

```typescript
// component.ts

...
import { Component, inject, signal } from '@angular/core';
import { IgxPdfExporterService, IgxPdfExporterOptions } from 'igniteui-angular/grids/core';

// import { IgxPdfExporterService, IgxPdfExporterOptions } from '@infragistics/igniteui-angular/grids/core'; for licensed package
...

public localData = signal([
  { Name: 'Eric Ridley', Age: '26' },
  { Name: 'Alanis Brook', Age: '22' },
  { Name: 'Jonathan Morris', Age: '23' }
]);

private pdfExportService = inject(IgxPdfExporterService);

public exportButtonHandler() {
  this.pdfExportService.exportData(this.localData, new IgxPdfExporterOptions('ExportedDataFile'));
}

```

모든 것이 잘 되었다면 내보내기 버튼이 보일 것입니다. 버튼을 누르면 내보내기 과정이 시작되고, 브라우저는 `localData` 배열의 데이터를 PDF 형식으로 담은 "ExportedDataFile.pdf"라는 파일을 내려받습니다.

## 내보내는 콘텐츠 사용자 지정하기

위 예제에서 PDF Exporter 서비스는 사용 가능한 모든 데이터를 내보냅니다. 하지만 행이나 열 전체를 내보내지 않고 건너뛰고 싶은 경우가 있습니다. 이를 위해 각각 열과 행에 대해 발생하는 <ApiLink type="PdfExporterService" member="columnexporting" label="columnExporting" /> 및/또는 <ApiLink type="PdfExporterService" member="rowexporting" label="rowExporting" /> 이벤트를 구독한 다음, 이벤트 인수 객체의 <ApiLink kind="interface" type="IRowExportingEventArgs" member="cancel" /> 속성을 `true`(으)로 설정하여 내보내기를 취소할 수 있습니다.

다음 예제는 헤더가 "Age"이고 인덱스가 1인 열을 내보내기에서 제외합니다:

```typescript
// component.ts

this.pdfExportService.columnExporting.subscribe((args: IColumnExportingEventArgs) => {
  if (args.header == 'Age' && args.columnIndex == 1) {
      args.cancel = true;
  }
});
this.pdfExportService.export(this.igxGrid1, new IgxPdfExporterOptions('ExportedDataFile'));
```

## PDF 내보내기 옵션

<ApiLink type="PdfExporterOptions" /> 클래스는 PDF 내보내기를 사용자 지정하기 위한 여러 속성을 제공합니다:

- **pageOrientation**: 페이지 방향(`portrait` 또는 `landscape`)을 지정합니다. 기본값은 `landscape`입니다.
- **pageSize**: 페이지 크기(`a3`, `a4`, `a5`, `letter`, `legal` 등)를 지정합니다. 기본값은 `a4`입니다.
- **showTableBorders**: 표 테두리를 표시할지 여부를 결정합니다. 기본값은 `true`입니다.
- **fontSize**: 표 콘텐츠의 글꼴 크기를 설정합니다. 기본값은 `10`입니다.
- **customFont**: 유니코드 문자 지원을 위한 사용자 지정 TrueType 글꼴(TTF)을 지정합니다. 비라틴 문자를 포함하는 데이터를 내보낼 때 필요합니다.

다음 예제는 이러한 옵션을 구성하는 방법을 보여 줍니다:

```typescript
// component.ts

public exportButtonHandler() {
  const options = new IgxPdfExporterOptions('ExportedDataFile');
  options.pageOrientation = 'portrait';
  options.pageSize = 'letter';
  options.showTableBorders = true;
  options.fontSize = 12;

  this.pdfExportService.exportData(this.localData, options);
}
```

### 유니코드 지원을 위한 사용자 지정 글꼴 구성

PDF 내보내기는 기본적으로 기본 제공 Helvetica 글꼴을 사용하며, 이 글꼴은 기본 라틴 문자만 지원합니다. 데이터에 비라틴 문자(키릴 문자, 중국어, 일본어, 아랍어, 히브리어 또는 특수 기호 등)가 포함되어 있다면, `customFont` 속성을 사용하여 사용자 지정 TrueType 글꼴(TTF)을 제공해야 합니다.

글꼴 데이터는 TTF 파일 내용의 Base64 인코딩 문자열로 제공해야 합니다. 선택 사항으로 헤더 스타일을 위한 별도의 굵은 변형도 제공할 수 있습니다.

#### TTF 파일을 Base64로 변환하기

TTF 파일을 Base64로 변환하려면 Node.js를 사용하십시오:

```javascript
const fs = require('fs');
const fontData = fs.readFileSync('path/to/font.ttf');
const base64 = fontData.toString('base64');
fs.writeFileSync('font-base64.ts', `export const MY_FONT = '${base64}';`);
```

또는 온라인 Base64 인코더 도구를 사용하여 TTF 파일을 변환할 수도 있습니다.

#### 예: 기본 사용자 지정 글꼴 사용

```typescript
// fonts/noto-sans.ts
export const NOTO_SANS_REGULAR = 'AAEAAAATAQAABAAwR0...[base64-encoded font data]...';

// component.ts
import { NOTO_SANS_REGULAR } from './fonts/noto-sans';

public exportButtonHandler() {
  const options = new IgxPdfExporterOptions('ExportedDataFile');
  options.customFont = {
    name: 'NotoSans',
    data: NOTO_SANS_REGULAR
  };

  this.pdfExportService.exportData(this.localData, options);
}
```

#### 예: 굵은 변형이 있는 사용자 지정 글꼴

```typescript
// fonts/noto-sans.ts
export const NOTO_SANS_REGULAR = 'AAEAAAATAQAABAAwR0...[base64-encoded regular font]...';
export const NOTO_SANS_BOLD = 'BBFAAAAUBQAACAAxS1...[base64-encoded bold font]...';

// component.ts
import { NOTO_SANS_REGULAR, NOTO_SANS_BOLD } from './fonts/noto-sans';

public exportButtonHandler() {
  const options = new IgxPdfExporterOptions('ExportedDataFile');
  options.customFont = {
    name: 'NotoSans',
    data: NOTO_SANS_REGULAR,
    bold: {
      name: 'NotoSans-Bold',
      data: NOTO_SANS_BOLD
    }
  };

  this.pdfExportService.export(this.igxGrid1, options);
}
```

#### 유니코드 지원에 권장되는 글꼴

다음 글꼴은 유니코드를 폭넓게 지원합니다:

- **Noto Sans**: 대부분의 유니코드 문자 체계를 포함합니다 — [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans)
- **Arial Unicode MS**: 포괄적인 유니코드 문자 지원
- **Source Han Sans**: 뛰어난 CJK(중국어, 일본어, 한국어) 지원
