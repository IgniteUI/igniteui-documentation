# Angular 시간 선택기 개요

<div class="highlight">
시간 선택기 컴포넌트를 사용하면 사용자는 드롭다운 또는 스피너가 있는 대화 상자에서 `Date` 객체의 시간 부분을 입력하거나 선택할 수 있으며, 그 값은 입력 필드에 그대로 반영됩니다. 기본 모드인 드롭다운 모드에서는 입력 필드를 편집할 수 있으며, 사용자는 선택한 시간도 편집할 수 있습니다.
</div>

<hr/>

<p>시간 선택기 컴포넌트에는 시계 버튼을 표시하기 위한 다양한 내장 템플릿과, 유효성 검사, 사용자 지정 시간 형식 지정 등의 기능이 있습니다.</p>

## Ignite UI for Angular 시간 선택기 시작하기

Ignite UI for Angular 시간 선택기 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxTimePickerModule`을 가져오는 것입니다.

<DocsAside type="info">
IgxTimePicker는 **BrowserAnimationsModule**에도 의존합니다. 이 모듈도 AppModule에 추가해야 합니다.
</DocsAside>

```typescript
// app.module.ts

...
import { BrowserAnimationsModule } from '@angular/platform-browser/animations';
import { IgxTimePickerModule } from 'igniteui-angular/time-picker';
// import { IgxTimePickerModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., BrowserAnimationsModule, IgxTimePickerModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxTimePickerComponent`을 독립형(standalone) 종속성으로 가져올 수 있으며, [`IGX_TIME_PICKER_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/time-picker/src/time-picker/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수도 있습니다.

```typescript
// home.component.ts

import { FormsModule } from '@angular/forms';
import { IGX_TIME_PICKER_DIRECTIVES } from 'igniteui-angular/time-picker';
// import { IGX_TABS_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: '<igx-time-picker [(ngModel)]="time"></igx-time-picker>',
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_TIME_PICKER_DIRECTIVES, FormsModule]
    /* or imports: [IgxTimePickerComponent, FormsModule] */
})
export class HomeComponent {
    public time: Date;
}
```

이제 Ignite UI for Angular 시간 선택기 모듈 또는 디렉티브를 가져왔으므로 `igx-time-picker` 컴포넌트를 사용할 수 있습니다.

## Angular 시간 선택기 사용하기

### 기본값

템플릿에 시간 선택기를 추가하려면 다음 코드를 사용하십시오:

```html
{/*meeting.component.html*/}
<igx-time-picker></igx-time-picker>
```

결과는 데모의 것과 같아야 합니다.

### 바인딩

Angular의 시간 선택기는 <ApiLink type="TimePicker" member="value" label="value" /> 속성 또는 `ngModel`을(를) 설정하여 `ISO 8601` 형식의 Date 객체 또는 시간만 있는 문자열 값에 바인딩할 수 있습니다.

먼저 `ISO 8601` 형식의 시간 문자열을 만드십시오:

```typescript
public time = '09:15:30';
```

그런 다음 `ngModel`을(를) 사용하여 양방향 데이터 바인딩을 만드십시오:

```html
<igx-time-picker [(ngModel)]="time"></igx-time-picker>
```

또는 템플릿에서 <ApiLink type="TimePicker" member="value" label="value" /> 입력을 설정하십시오:

```html
<igx-time-picker [value]="time"></igx-time-picker>
```

반응형 폼에서 사용하려면 선택기에 `formControlName`을(를) 설정해야 합니다

```html
<form [formGroup]="form">
    <igx-time-picker formControlName="timePicker"></igx-time-picker>
</form>
```

```typescript
export class SampleFormComponent {
    // ...
    public form: FormGroup;
    constructor(private fb: FormBuilder) {
        this.form = this.fb.group({
            timePicker: ['', Validators.required]
        });
    }
}
```

### 컴포넌트 투사

시간 선택기 컴포넌트는 <ApiLink type="InputGroup" />에서와 같이 하위 컴포넌트를 투영하는 것을 지원합니다: [`igxLabel`](/label-input), [`IgxHint`](/input-group#힌트), [`igxPrefix`](/input-group#접두사--접미사), [`igxSuffix`](/input-group#접두사--접미사), 단 <ApiLink type="InputDirective" />은 제외합니다. 이에 대한 더 자세한 정보는 [Label & Input](/label-input) 주제에서 찾을 수 있습니다.

기본 구성에서는 드롭다운/대화 상자 토글 아이콘이 접두사로 표시됩니다. 이 아이콘은 <ApiLink type="PickerToggle" /> 컴포넌트를 사용하여 바꾸거나 다시 정의할 수 있습니다. 이 아이콘은 [`igxPrefix`](/input-group#접두사--접미사) 또는 [`igxSuffix`](/input-group#접두사--접미사)로 장식할 수 있으며, 이것이 위치를 정의합니다. 각각 입력의 시작 부분 또는 끝 부분에 위치하게 됩니다.

아래 예제에서는 사용자 지정 레이블과 힌트를 추가하고, 기본 토글 아이콘의 위치를 접미사로 표시되도록 바꾸었습니다:

```html
<igx-time-picker [(ngModel)]="date" mode="dialog" [inputFormat]="'hh:mm'">
    <label igxLabel>Home Time </label>
    <igx-picker-toggle igxSuffix>
        <igx-icon>home</igx-icon>
    </igx-picker-toggle>
    <igx-hint>{{date.toLocaleString()}}</igx-hint>
</igx-time-picker>
```

<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

```typescript
public date: Date = new Date();
```

## 사용자 지정 작업 버튼

<ApiLink type="TimePicker" />은(는) 작업 버튼 사용자 지정을 지원합니다. 이를 위해 버튼들을 <ApiLink type="PickerActionsDirective" /> 디렉티브 선택기로 표시된 `ng-template`로 감싸십시오.

아래 예제에서는 'CANCEL', 'DONE', 'NOW' 작업을 위한 사용자 지정 작업 버튼을 추가합니다.

```html
{/* sample.component.html */}

<igx-time-picker #picker format="hh:mm" mode="dropdown">
    <ng-template igxTimePickerActions>
        <div class="container action-buttons">

            <button igxButton="flat" (click)="picker.cancelButtonClick()">cancel</button>
            <button igxButton="flat" (click)="picker.okButtonClick()">done</button>
            <button igxButton="flat" (click)="selectNow(picker)">now</button>
        
</div>
    </ng-template>
</igx-time-picker>
```

```typescript
// sample.component.ts
...
public selectNow(timePicker: IgxTimePickerComponent) {
    timePicker.value = new Date();
    timePicker.close();
}
...
```

이것으로 드롭다운, 사용자 지정 작업, 양방향 바인딩을 지원하는 템플릿이 적용된 시간 선택기가 완성되었습니다:

## 토글 및 지우기 아이콘 사용자 지정하기

<ApiLink type="TimePicker" />은(는) <ApiLink type="PickerToggle" />과(와) <ApiLink type="PickerClear" />으로 구성할 수 있으며, 이들은 직접 클릭 핸들러를 추가하지 않고도 토글 아이콘과 지우기 아이콘을 바꾸는 데 사용할 수 있습니다.

```html
 <igx-time-picker>
    <label igxLabel>Select time</label>
    <igx-picker-toggle igxPrefix>
        <igx-icon>snooze</igx-icon>
    </igx-picker-toggle>
    <igx-picker-clear igxSuffix>
        <igx-icon>delete</igx-icon>
    </igx-picker-clear>
</igx-time-picker>
```

### 키보드 탐색

- 사용자는 키보드의 <kbd>위쪽</kbd> 및 <kbd>아래쪽</kbd> 화살표 키를 사용하거나, 입력 필드와 드롭다운/대화 상자에서 스크롤하여 컴포넌트의 시간 부분을 탐색할 수 있습니다. 입력에서의 탐색은 <ApiLink type="TimePicker" member="minValue" label="minValue" /> 또는 <ApiLink type="TimePicker" member="maxValue" label="maxValue" />와 관계없이 가능하지만, 드롭다운/대화 상자에서의 탐색은 <ApiLink type="TimePicker" member="minValue" label="minValue" />과(와) <ApiLink type="TimePicker" member="maxValue" label="maxValue" /> 범위 안으로 제한됩니다.
- 시간 선택기 드롭다운은 토글 아이콘 클릭, <kbd>Space</kbd> 키 또는 <kbd>Alt</kbd> + <kbd>Down</kbd> 키 입력으로 열 수 있습니다. 대화 상자 모드에서는 입력을 클릭하여 열 수 있습니다.
- <kbd>Enter</kbd> 키를 누르거나 드롭다운/대화 상자 밖을 마우스로 클릭하면 선택이 적용되고 드롭다운/대화 상자가 닫힙니다.
- <kbd>Escape</kbd> 키를 누르면 선택이 취소되고 드롭다운/대화 상자가 닫힙니다.
- 드롭다운이 닫혀 있는 상태에서 새 값을 입력한 경우, 시간 선택기 밖을 클릭하거나 <kbd>Tab</kbd> 키를 눌러 포커스를 이동하면 값이 수락됩니다.

### 표시 및 입력 형식

시간 선택기 컴포넌트는 서로 다른 표시 형식과 입력 형식을 지원합니다.

표시 형식은 편집 모드일 때 값의 형식이며, 나열된 Angular [DatePipe](https://angular.io/api/common/DatePipe) 형식 중 하나일 수 있습니다. 이를 통해 `shortTime` 및 `longTime`과 같은 미리 정의된 형식 옵션을 지원할 수 있습니다.

입력 형식은 편집 모드가 아닐 때 값의 형식이며, 드롭다운/대화 상자에서 시간 부분이 표시되는 형식입니다. `inputFormat` 속성은 DatePipe가 지원하는 문자를 사용하여 구성된 형식 문자열을 받습니다. 예를 들어 `hh:mm:ss`처럼 쓰지만, `shortTime`이나 `longTime`와 같은 미리 정의된 형식 옵션은 지원하지 않습니다. `inputFormat` 속성이 정의되지 않은 경우, 기본값은 `hh:mm tt`입니다.
또는 <ApiLink type="TimePicker" member="inputFormat" label="inputFormat" /> 속성이 설정되지 않은 경우, <ApiLink type="TimePicker" member="displayFormat" label="displayFormat" />이 숫자 날짜-시간 부분만 포함하는 것으로 해석될 수 있으면 입력 형식이 그것으로부터 추론됩니다.

```html
<igx-time-picker
    [(ngModel)]="time"
    [inputFormat]="`hh:mm:ss`"
    [displayFormat]="`shortTime`">
</igx-time-picker>
```

<DocsAside type="info">
`IgxTimePicker`은(는) 이제 IME 입력을 지원합니다. 조합이 끝나면 컨트롤이 전각 숫자를 ASCII 문자로 변환합니다.
</DocsAside>

### 증가 및 감소

시간 선택기는 공개 <ApiLink type="TimePicker" member="increment" label="increment" /> 및 <ApiLink type="TimePicker" member="decrement" label="decrement" /> 메서드를 노출하며, 이 메서드들은 두 개의 선택적 매개변수, 즉 수정할 `DatePart`와 변경할 `delta`을 받습니다. 지정하지 않으면 `DatePart`의 기본값은 `Hours`이고 `delta`의 기본값은 <ApiLink type="TimePicker" member="itemsDelta" label="itemsDelta" />입니다.

두 메서드를 모두 사용하는 방법을 보여 주는 샘플은 [Date Time Editor 디렉티브](/date-time-editor#increment-decrement)에서 찾을 수 있습니다.

### 폼 및 유효성 검사

시간 선택기 컴포넌트는 핵심 FormsModule의 모든 디렉티브 [NgModel](https://angular.io/api/forms/NgModel)과 [ReactiveFormsModule](https://angular.io/api/forms/ReactiveFormsModule)(FormControl, FormGroup 등)을 지원합니다. 여기에는 [폼 검증기](https://angular.io/api/forms/Validators) 함수도 포함됩니다. 또한 컴포넌트의 [최소 및 최대 값](#최소-및-최대-값)도 폼 검증기 역할을 합니다.

[Reactive Forms 통합](/angular-reactive-form-validation) 샘플은 Reactive Forms에서 igxTimePicker를 사용하는 방법을 보여 줍니다.

#### 최소 및 최대 값

사용자 입력을 제한하려면 <ApiLink type="TimePicker" member="minValue" label="minValue" />과 <ApiLink type="TimePicker" member="maxValue" label="maxValue" />을(를) 지정할 수 있으며, 이 경우 드롭다운/대화 상자는 그 범위 안의 시간만 표시합니다. 하지만 드롭다운 모드에서는 여전히 사용자가 잘못된 시간을 입력할 수 있습니다. 이런 일이 발생하면 사용자에게 알리기 위해 <ApiLink type="TimePicker" member="validationFailed" label="validationFailed" /> 이벤트를 처리할 수 있습니다.

<DocsAside type="info">
최소/최대 값은 Date 객체이거나 `ISO 8601` 형식의 시간만 있는 문자열이어야 합니다:
</DocsAside>

```typescript
// app.module.ts

...
```

```html
<igx-time-picker
 [(ngModel)]="time"
    [itemsDelta]="{hours:2, minutes:5}"
    [inputFormat]="'hh:mm:ss tt'"
    [headerOrientation]="true"
    [minValue]="min"
    [maxValue]="max"
 (onValidationFailed)="onValidationFailed()">
 <label igxLabel>Meeting Start</label>
</igx-time-picker>

<igx-toast #toast message="Value must be between 09:15:30 AM and 06:15:30 PM"></igx-toast>

```

드롭다운은 항목 간격을 기준으로 최소/최대 범위(09:15:30 AM~06:15:30 PM) 안의 값을 표시합니다. 잘못된 시간이 입력되면 메시지를 보여 주기 위해 토스트가 추가됩니다.

<DocsAside type="info">
드롭다운/대화 상자에서 각 시간 부분에 대해 표시되는 값은 항상 0에서 시작하여 항목 간격을 기준으로 계산됩니다. <ApiLink type="TimePicker" member="minValue" label="minValue" />과(와) <ApiLink type="TimePicker" member="maxValue" label="maxValue" />이(가) 항목 간격과 맞지 않으면, 표시되는 값은 임계값과 맞는 다음/마지막 가능한 값에서 시작하거나 끝납니다.
</DocsAside>

## 스타일링

시간 선택기의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-dialog-theme" label="time-picker-theme" code={true} />을(를) 확장하고 시간 선택기의 스타일을 지정하는 매개변수를 받는 새 테마를 만듭니다.

```scss
$my-time-picker-theme: time-picker-theme(
  $text-color: #e4c8a5,
  $hover-text-color: #ecaa53,
  $selected-text-color: #ecaa53,
  $header-background: #ecaa53,
  $background-color: #011627
);
```

<DocsAside type="info">
시간 선택기 창의 콘텐츠 일부로 사용되는 추가 컴포넌트(예: [`IgxButton`](./inputs/button.mdx))의 스타일을 지정하려면, 해당 컴포넌트에 특화된 추가 테마를 만들어 대화 상자 창의 범위 안에만 두어야 합니다(그래야 애플리케이션의 나머지 부분에 영향을 주지 않습니다).
</DocsAside>

시간 선택기 창은 [`IgxOverlayService`](/overlay)을(를) 사용하므로, 사용자 지정 테마가 스타일을 지정하려는 시간 선택기 창까지 도달하도록 하기 위해, 대화 상자 창이 보일 때 DOM에 배치될 특정 아웃레트를 제공하겠습니다.

시간 선택기의 항목들은 우리 컴포넌트 `host`의 하위 요소가 **아닙니다** - 현재는 기본 오버레이 아웃레트에 표시되며, 이는 `document` 본문의 끝에 있습니다. 이를 바꾸려면 `overlaySettings`의 <ApiLink kind="interface" type="OverlaySettings" member="outlet" /> 속성을 사용합니다. `outlet`은(는) 오버레이 컨테이너가 렌더링될 위치를 제어합니다.

여기서는 컨테이너가 놓였으면 하는 요소에 대한 참조를 전달할 수 있습니다:

```html
<igx-time-picker #picker [overlaySettings]="{ outlet: element }">
</igx-time-picker>
```


```typescript
export class TimepickerStylingComponent {
    constructor(public element: ElementRef) {
    }
}
```

이제 시간 선택기의 항목들이 컴포넌트 호스트 **안에** 올바르게 렌더링되므로, 사용자 지정 테마가 적용됩니다:

<DocsAside type="info">
[`IgxOverlayService`](/overlay)을 사용하여 표시되는 요소에 테마를 제공하는 다양한 방법에 대해 더 알아보려면 [오버레이 스타일링 항목](/overlay-styling)을 참조하십시오.
</DocsAside>

```scss
:host {
    @include tokens($my-time-picker-theme);
}
```

<DocsAside type="info">
일부 컴포넌트 템플릿에서는 Emulated View Encapsulation 때문에 생성된 토큰 선언이 중첩된 Ignite UI 요소에 도달하지 못할 수 있습니다. 테마가 적용되지 않으면 아래와 같이 `::ng-deep`을(를) 사용하거나 테마를 전역 스타일시트로 옮기십시오.
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include tokens($my-time-picker-theme);
    }
}
```
