# Ignite UI for Angular에서 독립형 컴포넌트 사용하기

Angular 14는 `NgModules`의 필요성을 줄여 애플리케이션을 더 간단하게 구축하는 방법인 [독립형 컴포넌트](https://angular.io/guide/standalone-components) 개념을 도입했습니다. 독립형 컴포넌트는 Angular 15까지 개발자 미리 보기 상태였습니다. 이 새로운 패러다임을 지원하기 위해, 모든 Ignite UI for Angular 컴포넌트는 이제 버전 `16.0.0`의 `standalone`로 내보내집니다. Angular 19부터는 모든 컴포넌트가 기본적으로 독립형입니다. 기존의 모든 `NgModules`는 이전 버전과의 호환성을 위해 라이브러리에서 여전히 내보내집니다. 하지만 더 이상 Ignite UI for Angular 컴포넌트를 선언하지 않습니다. 대신 `standalone` 컴포넌트를 import하고 export합니다.

## 새로운 독립형 컴포넌트를 사용하는 방법

Angular 16과 Ignite UI for Angular 16.0부터는 `standalone` 컴포넌트에 필요한 import를 `imports` 속성에 간단히 추가할 수 있습니다. 다음 예에서 `IGX_GRID_DIRECTIVES`을(를) 사용하면 그리드 관련 컴포넌트와 디렉티브를 모두 import할 수 있습니다.

```typescript
import { IGX_GRID_DIRECTIVES } from 'igniteui-angular/grids/grid';

@Component({
    selector: 'app-grid-sample',
    styleUrls: ['grid.sample.scss'],
    templateUrl: 'grid.sample.html',
    imports: [IGX_GRID_DIRECTIVES, AsyncPipe]
})
```

또는 `standalone` 컴포넌트가 사용하는 모든 컴포넌트를 개별적으로 import할 수도 있습니다. 다른 컴포넌트가 이 두 개만 사용하는 경우 `IgxGridComponent`와 `IgxColumnComponent`을(를) import하는 예는 다음과 같습니다.

```typescript
import { IgxGridComponent, IgxColumnComponent } from 'igniteui-angular/grids/grid';

@Component({
    selector: 'app-grid-sample',
    styleUrls: ['grid.sample.scss'],
    templateUrl: 'grid.sample.html',
    imports: [IgxGridComponent, IgxColumnComponent, AsyncPipe]
})
```

또한 기존의 모든 모듈은 유지되고 이제 독립형 컴포넌트만 import하고 export하므로, 독립형 컴포넌트에서도 이를 사용할 수 있습니다.

```typescript
// `NgModule` import of the `IgxGridModule` module, which is equivalent to IGX_GRID_DIRECTIVES in terms of exported components and directives.
import { IgxGridModule } from 'igniteui-angular/grids/grid';

@Component({
    selector: 'app-grid-sample',
    styleUrls: ['grid.sample.scss'],
    templateUrl: 'grid.sample.html',
    imports: [IgxGridModule, AsyncPipe]
})
```
