# Ignite UI CLI 시작하기

Ignite UI CLI는 Ignite UI 컴포넌트용으로 미리 구성된 Angular, React 및 jQuery 프로젝트를 스캐폴딩하기 위한 독립형 전역 명령줄 도구입니다. 처음 설정할 때 쓰는 안내형 단계별 마법사, 스크립트 작업 흐름을 위한 비대화형 `new` 및 `add` 명령, 개발 서버, 그리고 AI 코딩 어시스턴트를 실시간 Ignite UI 문서에 연결하는 내장 MCP 서버를 제공합니다.

CLI는 Angular CLI를 대체하지 않으며 그와 함께 작동합니다. Ignite UI CLI로 만든 프로젝트는 표준 Angular 작업 공간이며, 스캐폴딩 이후에도 `ng` 명령과 완전히 호환됩니다.

## Ignite UI CLI 설치하기

npm을 사용하여 Ignite UI CLI를 전역으로 설치하십시오:

```cmd
npm install -g igniteui-cli
```

또는 yarn을 사용하십시오:

```cmd
yarn global add igniteui-cli
```

설치를 확인하십시오:

```cmd
ig version
```

## 새 프로젝트 만들기

Ignite UI CLI는 프로젝트 생성을 위해 두 가지 모드를 제공합니다. 하나는 안내형 대화식 마법사이고, 다른 하나는 인수를 사용하는 직접 명령입니다.

### 안내형 마법사 사용하기

안내형 마법사는 새 프로젝트를 시작하기에 권장되는 방법입니다. 프로젝트 유형, 이름, 템플릿, 테마를 선택하라는 메시지가 표시되며, 그 후 프로젝트를 자동으로 스캐폴딩하고 커밋합니다.

마법사를 실행하려면:

```cmd
ig
```

또는:

```cmd
ig new
```

### 프로젝트 직접 만들기

Angular 프로젝트를 비대화형으로 만들려면 프레임워크로 `angular`을(를), 프로젝트 유형으로 `igx-ts`를 지정하십시오:

```cmd
ig new my-app --framework=angular --type=igx-ts --template=side-nav
```

프로젝트를 만드는 동안 AI 어시스턴트와 에이전트 구성을 지정할 수도 있습니다:

```cmd
ig new my-app --framework=angular --type=igx-ts --template=side-nav --assistants generic --agents claude copilot
```

AI 구성을 완전히 건너뛰려면:

```cmd
ig new my-app --framework=angular --type=igx-ts --assistants none --agents none
```

**`ig new` 실행 중 순서:**
1. 프로젝트 파일이 생성됩니다
2. AI 구성은 새 프로젝트 디렉터리 안에서 실행됩니다(플래그가 제공되지 않으면 어시스턴트와 에이전트를 묻습니다)
3. Git이 초기화됩니다(`--skip-git`인 경우 제외)
4. 종속성이 설치됩니다(`--skip-install`인 경우 제외)

<DocsAside type="info">
Ignite UI CLI v13.1.0부터 `igx-ts` 프로젝트 유형은 기본적으로 독립형 컴포넌트가 있는 프로젝트를 생성합니다. 대신 NgModule 기반 부트스트랩을 사용하려면 `--type=igx-ts-legacy`을(를) 설정하십시오.
</DocsAside>

새 애플리케이션은 프로젝트 이름의 디렉터리에 생성됩니다. Angular용으로 다음 기본 프로젝트 템플릿을 사용할 수 있습니다:

| 템플릿 ID   | 설명                                                                                                                                      |
| :------------ | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| empty         | 라우팅과 홈 페이지가 있는 프로젝트 구조입니다. 이 템플릿에서는 인증을 사용할 수 없습니다.                                               |
| side-nav      | 사이드 내비게이션 드로어가 있는 프로젝트 구조입니다. 추가 옵션으로 인증을 지원합니다(아래 참조).                                               |
| side-nav-mini | 간결한 사이드 내비게이션 드로어가 있는 프로젝트 구조입니다. 추가 옵션으로 인증을 지원합니다(아래 참조).                                       |

대화형 마법사를 사용할 때 `side-nav` 또는 `side-nav-mini`를 선택하면 인증을 추가할지 묻는 추가 프롬프트가 나타납니다. 다음 템플릿 ID는 생성되며, 비대화형 생성을 위해 `ig new`와 함께 직접 사용할 수도 있습니다. 이 ID들은 마법사의 템플릿 목록에는 표시되지 않습니다:

| 템플릿 ID        | 설명                                                                                                                                          |
| :----------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| side-nav-auth      | 사용자 인증 모듈로 확장된 사이드 내비게이션입니다. 자세한 내용은 [Angular 인증 프로젝트 템플릿](./auth-template.mdx)을 참조하십시오.                |
| side-nav-mini-auth | 사용자 인증 모듈로 확장된 간결한 사이드 내비게이션입니다. 자세한 내용은 [Angular 인증 프로젝트 템플릿](./auth-template.mdx)을 참조하십시오.           |

프로젝트를 만들 때 다음 인수를 사용할 수 있습니다:

## 컴포넌트 템플릿 추가하기

기존 프로젝트에 [사용 가능한 Ignite UI for Angular 템플릿](./component-templates.mdx)을 추가하려면 템플릿 ID와 새 컴포넌트의 이름을 제공하십시오:

```cmd
ig add grid newGrid
```

프로젝트 디렉터리에서 사용 가능한 모든 템플릿을 나열하려면:

```cmd
ig list
```

템플릿 추가는 Ignite UI CLI, Angular Schematics 또는 `ng add`로 Ignite UI for Angular를 추가한 모든 Angular CLI 프로젝트에서 지원됩니다. 안내형 컴포넌트 마법사는 [Ignite UI CLI를 사용한 단계별 가이드](./step-by-step-guide-using-cli.mdx#뷰-추가)를 참조하십시오.

템플릿을 추가할 때 다음 인수를 사용할 수 있습니다:

<details>
  <summary><u>module</u></summary>
  <p>
    <code>--module</code>(별칭: <code>-m</code>)
  </p>
  <p>
    <i>Angular 프로젝트에서만 적용됩니다.</i>
  </p>
  <p>
    새 컴포넌트를 등록할 <code>/src/app/</code>에 상대적인 <code>module.ts</code> 파일의 경로입니다:
  </p>
  <code>ig add combo newCombo --module=myModule/myModule.module.ts</code>
</details>

<details>
  <summary><u>skip-route</u></summary>
  <p>
    <code>--skip-route</code>(별칭: <code>-srk</code>)
  </p>
  <p>
    새 컴포넌트의 앱 내비게이션 라우트 자동 생성을 건너뜁니다.
  </p>
</details>

## 애플리케이션 실행하기

`start` 명령은 애플리케이션을 빌드하고, 로컬 웹 서버를 시작하며, 기본 브라우저에서 엽니다:

```cmd
ig start
```

## AI 어시스턴트 통합(MCP)

Ignite UI CLI에는 GitHub Copilot, Claude, Cursor 등의 AI 코딩 어시스턴트를 실시간 Ignite UI 컴포넌트 문서와 API 참조에 연결하는 내장 MCP(Model Context Protocol) 서버가 포함되어 있습니다. 구성되면 AI 어시스턴트는 컨텍스트를 바꾸지 않고도 컴포넌트 API를 조회하고, 설정 가이드를 가져오며, 정확한 Ignite UI for Angular 코드를 생성할 수 있습니다.

프로젝트를 `ig new`로 만들었다면 MCP 구성과 Agent Skills는 스캐폴딩 중에 이미 생성됩니다. 기존 프로젝트로 작업 중이라면 프로젝트 루트에서 `ig ai-config`를 실행하여 MCP 서버, 스킬 파일 및 지침 파일을 한 단계에서 설정하십시오:

```cmd
ig ai-config
```

이 명령은 여러 코딩 어시스턴트와 AI 에이전트를 지원합니다:

```cmd
ig ai-config --assistants generic vscode --agents claude copilot
```

| 플래그 | 값 | 기본값 |
|------|--------|---------|
| `--assistants` | `generic`, `vscode`, `cursor`, `gemini`, `junie`, `none` | 대화형으로 묻습니다. 비대화형 모드에서는 `generic`을(를) 사용합니다 |
| `--agents` | `generic`, `claude`, `copilot`, `cursor`, `codex`, `windsurf`, `gemini`, `junie`, `none` | 대화형으로 묻습니다. 비대화형 모드에서는 `generic` + `claude`를 사용합니다 |

플래그 없이 실행하면 `ig ai-config`은(는) 대화형 모드에 들어가 SPACE로 전환하고 ENTER로 확인하여 코딩 어시스턴트와 에이전트를 선택하라는 메시지를 표시합니다. 이 프롬프트는 `ig new` 중의 마법사 단계와 같습니다:

1. **코딩 어시스턴트 선택** - MCP 서버 구성을 위한 하나 이상의 대상(일반, VS Code, Cursor, Gemini, Junie)을 선택하거나, 건너뛰려면 None을 선택하십시오.
2. **AI 에이전트 선택** - 스킬 파일과 지침 파일을 위한 하나 이상의 에이전트(일반, Claude, Copilot, Cursor, Codex, Windsurf, Gemini, Junie)를 선택하거나, 건너뛰려면 None을 선택하십시오.

대화형 모드의 기본값은 어시스턴트의 경우 **일반**, 에이전트의 경우 **일반 + Claude**입니다. 마법사 프롬프트에 대한 자세한 내용은 [Ignite UI CLI를 사용한 단계별 가이드 - AI 어시스턴트 구성](./step-by-step-guide-using-cli.mdx#ai-어시스턴트-구성)을 참조하십시오.

AI 클라이언트를 수동으로 구성하려거나 VS Code가 아닌 다른 클라이언트를 사용하려면 MCP 서버를 직접 시작하십시오:

```cmd
ig mcp
```

클라이언트 구성(VS Code, Claude Desktop, Cursor 등)과 사용 가능한 도구에 대한 전체 설명은 [Ignite UI CLI MCP](../../ai/cli-mcp.mdx)를 참조하십시오.

## Ignite UI CLI 명령

사용 가능한 Ignite UI CLI 명령의 전체 목록은 [Ignite UI CLI 위키](https://github.com/IgniteUI/igniteui-cli/wiki)에서 관리됩니다:

| 명령                                                               | 별칭 | 설명                                                                                                                                                                                          |
| :-------------------------------------------------------------------- | :---- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [ig start](https://github.com/IgniteUI/igniteui-cli/wiki/start)       |       | 애플리케이션을 빌드하고, 웹 서버를 시작하며, 기본 브라우저에서 엽니다.                                                                                                                    |
| [ig build](https://github.com/IgniteUI/igniteui-cli/wiki/build)       |       | 애플리케이션을 출력 디렉터리로 빌드합니다.                                                                                                                                                     |
| [ig generate](https://github.com/IgniteUI/igniteui-cli/wiki/generate) | g     | 지원되는 프레임워크와 프로젝트 유형에 대해 새 사용자 지정 템플릿을 생성합니다.                                                                                                                          |
| [ig help](https://github.com/IgniteUI/igniteui-cli/wiki/help)         | -h    | 사용 가능한 명령을 간단한 설명과 함께 나열합니다.                                                                                                                                                    |
| [ig config](https://github.com/IgniteUI/igniteui-cli/wiki/config)     |       | Ignite UI CLI 구성 설정을 읽고 씁니다.                                                                                                                                               |
| [ig doc](https://github.com/IgniteUI/igniteui-cli/wiki/doc)           |       | 지정된 용어에 대해 Infragistics 지식 베이스를 검색합니다.                                                                                                                                           |
| [ig list](https://github.com/IgniteUI/igniteui-cli/wiki/list)         | l     | 지정된 프레임워크와 유형의 모든 템플릿을 나열합니다. 프로젝트 폴더 안에서 실행하면, 인수로 다른 값을 제공하더라도 프로젝트의 프레임워크와 유형에 대한 템플릿을 나열합니다. |
| [ig test](https://github.com/IgniteUI/igniteui-cli/wiki/test)         |       | 현재 프로젝트의 테스트를 실행합니다.                                                                                                                                                          |
| ig version                                                            | -v    | 로컬에 설치된 Ignite UI CLI 버전을 표시하며, 로컬 설치가 없으면 전역 버전을 표시합니다.                                                                                                    |
| ig mcp                                                                |       | Ignite UI MCP 서버를 시작하여, 연결된 AI 어시스턴트에 컴포넌트 문서 검색 및 API 참조 도구를 제공합니다. [Ignite UI CLI MCP](../../ai/cli-mcp.mdx)를 참조하십시오.                          |
| ig ai-config                                                          |       | AI 코딩 어시스턴트 통합을 설정합니다. 선택한 어시스턴트와 에이전트에 대해 MCP 서버를 구성하고, 스킬 파일을 복사하며, 지침 파일을 채웁니다.                                          |
