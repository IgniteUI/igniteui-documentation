# Ignite UI CLI를 사용한 단계별 가이드

Ignite UI CLI 단계별 모드는 [Ignite UI CLI](./getting-started-with-cli.mdx) 기반 Angular 프로젝트의 프로젝트 생성, 템플릿 선택, 테마 설정, 컴포넌트 뷰 추가를 안내하는 대화형 마법사입니다. 비대화형 `ig new` 및 `ig add` 명령과 같은 작업을 다루지만, 모든 인수를 미리 요구하는 대신 각 단계에서 질문합니다.

단계별 모드는 스크립트 사용이나 비대화형 사용을 지원하지 않습니다. 이러한 용도에는 명시적 인수를 사용하는 직접 `ig new` 및 `ig add` 명령을 사용하십시오. 마법사는 `Inquirer.js`에 의존합니다. 호환성은 [지원되는 터미널](https://github.com/SBoudrias/Inquirer.js#support-os-terminals)을 참조하십시오.

마법사를 실행하려면 다음을 실행하십시오:

```bash
ig
```

또는:

```bash
ig new
```

## 새 프로젝트 만들기

먼저 애플리케이션의 이름을 입력하라는 메시지가 표시됩니다:

<Image src={igStepByStepNewProjectName} alt="단계별 새 프로젝트 이름 프롬프트" class="responsive-img" />

프레임워크로 `Angular`을(를) 선택하면 생성할 프로젝트의 유형을 고르라는 메시지가 표시됩니다:

<Image src={igStepByStepProjectTypeCli} alt="단계별 프로젝트 유형 선택" class="responsive-img" />

그다음 사용 가능한 프로젝트 템플릿 중 하나를 고르도록 안내됩니다. 기본 템플릿은 세 가지입니다: **Empty Project**, **Side Navigation**, **Side Navigation Mini**. 화살표 키로 옵션을 탐색하고 ENTER를 눌러 선택을 확인하십시오:

<Image src={igStepByStepNewProjectTemplate} alt="단계별 새 프로젝트 템플릿 선택" class="responsive-img" />

**Side Navigation** 또는 **Side Navigation Mini**를 선택하면, 마법사는 프로젝트에 [인증 모듈](./auth-template.mdx)을 추가할지 묻는 추가 단계를 표시합니다. 예를 선택하면 해당 인증 변형(`side-nav-auth` 또는 `side-nav-mini-auth`)이 생성됩니다. **Empty Project**를 선택하면 인증 프롬프트는 건너뜁니다.

<Image src={igStepByStepNewProjectQuestion} alt="단계별 인증 질문 프롬프트" class="responsive-img" />

다음 단계는 애플리케이션의 테마를 선택하는 것입니다. 기본 옵션을 선택하면 프로젝트의 `angular.json`에 기본 Ignite UI for Angular 테마가 들어 있는 미리 컴파일된 CSS 파일(`igniteui-angular.css`)이 포함됩니다. 사용자 지정 옵션은 `app/styles.scss`의 [Theming API](../../themes/sass/index.mdx)를 사용하여 색상 팔레트와 테마 구성을 생성합니다.

<Image src={igStepByStepNewProjectTheme} alt="단계별 새 프로젝트 테마 선택" class="responsive-img" />

위 단계를 마치면 애플리케이션 구조가 생성됩니다. 그런 다음 마법사는 [AI 코딩 어시스턴트 구성](#ai-어시스턴트-구성)을 요청합니다. AI 구성이 끝나면 Git 저장소가 초기화되고 프로젝트가 커밋되며, 과정을 완료할지 아니면 애플리케이션에 새 뷰를 추가할지 묻습니다:

<Image src={igStepByStepNewProjectAction} alt="단계별 새 프로젝트 작업 프롬프트" class="responsive-img" />

## 뷰 추가

Ignite UI CLI는 프로젝트에 추가할 수 있는 여러 컴포넌트 템플릿과 시나리오 템플릿을 지원합니다. 이 모드는 프로젝트 생성의 연속 단계로 활성화하거나, 아래 명령을 사용하여 기존 프로젝트 안에서 활성화할 수 있습니다.

```bash
ig add
```

카테고리별로 묶인 사용 가능한 템플릿 [목록](./component-templates.mdx#컴포넌트-템플릿)이 표시됩니다.

<Image src={igStepByStepTemplateGroup} alt="단계별 템플릿 그룹 선택" class="responsive-img" />

화살표 키로 옵션을 탐색하고 ENTER로 선택하십시오. `Custom Grid` 같은 일부 템플릿에서는 SPACE 키로 전환할 수 있는 선택적 기능 목록이 표시됩니다:

<Image src={igStepByStepComponentFeatures} alt="단계별 컴포넌트 기능 전환" class="responsive-img" />

애플리케이션에 시나리오를 추가하기로 선택하면, 사용 가능한 [시나리오 템플릿](./component-templates.mdx#시나리오-템플릿) 목록도 표시됩니다:

<Image src={igStepByStepScenarioTemplates} alt="단계별 시나리오 템플릿 선택" class="responsive-img" />

템플릿을 추가한 후에는 뷰를 더 추가할지 아니면 과정을 마칠지 묻습니다. 완료되면 남은 패키지 종속성이 설치되고 애플리케이션이 실행되어 기본 브라우저에서 열립니다.

나중에 마법사 없이 프로젝트에 Ignite UI for Angular 뷰를 더 추가하려면 직접 `add` 명령을 사용하십시오:

```bash
ig add [template] [name]
```

## AI 어시스턴트 구성

프레임워크, 프로젝트 유형, 템플릿, 테마를 선택하면 마법사는 AI 코딩 어시스턴트 통합을 구성하라는 메시지를 표시합니다. 이 단계는 `ig ai-config`과 같은 로직을 실행하지만 프로젝트 생성 흐름에 포함되어 있습니다.

### 코딩 어시스턴트 선택

MCP 서버를 구성할 코딩 어시스턴트를 선택하라는 메시지가 표시됩니다. SPACE 키로 선택을 전환하고 ENTER로 확인하십시오:

<Image src={igStepByStepAiConfigAssistants} alt="단계별 AI 구성 코딩 어시스턴트 프롬프트" class="responsive-img" />

- **일반**(Claude Code, VS Code 및 기타) - `.mcp.json`을(를) 씁니다
- **VS Code**(GitHub Copilot) - `.vscode/mcp.json`을(를) 씁니다
- **Cursor** - `.cursor/mcp.json`을(를) 씁니다
- **Gemini** - `.gemini/settings.json`을(를) 씁니다
- **JetBrains Junie** - `.junie/mcp/mcp.json`을(를) 씁니다
- **None** - MCP 구성을 건너뜁니다

기본 선택은 **일반**입니다. **None**을 선택하면 MCP 서버 구성을 완전히 건너뜁니다.

### AI 에이전트 선택

다음으로 스킬 파일과 지침을 구성할 AI 에이전트를 선택하라는 메시지가 표시됩니다:

<Image src={igStepByStepAiConfigAgents} alt="단계별 AI 구성 에이전트 프롬프트" class="responsive-img" />

- **일반** - `.agents/skills/` 및 `AGENTS.md`
- **Claude** - `.claude/skills/` 및 `.claude/CLAUDE.md`
- **Copilot** - `.github/skills/` 및 `.github/copilot-instructions.md`
- **Cursor** - `.cursor/skills/` 및 `.cursor/rules/cursor.mdc`
- **Codex** - `.codex/skills/` 및 `.codex/instructions.md`
- **Windsurf** - `.windsurf/skills/` 및 `.windsurf/rules/guidelines.md`
- **Gemini** - `.gemini/skills/` 및 `.gemini/GEMINI.md`
- **Junie** - `.junie/skills/` 및 `.junie/guidelines.md`
- **None** - 스킬 파일과 지침을 건너뜁니다

기본 선택은 **일반**과 **Claude**입니다. **None**을 선택하면 에이전트 구성을 완전히 건너뜁니다.

<DocsAside type="info">
비대화형 프로젝트 생성 중 AI 구성 프롬프트를 완전히 건너뛰려면 `ig new`에 `--assistants none --agents none`을(를) 전달하십시오. 나중에 AI 구성을 다시 실행하려면 프로젝트 루트에서 `ig ai-config`을(를) 사용하십시오.
</DocsAside>
