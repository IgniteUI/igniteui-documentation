# Ignite UI for Angular Schematics를 사용한 단계별 가이드

Ignite UI for Angular Schematics 단계별 모드는 `@igniteui/angular-schematics` 컬렉션에 내장된 대화형 마법사입니다. 프로젝트 부트스트랩, 템플릿 선택, 테마 설정을 안내한 다음, 마치기 전에 컴포넌트 뷰를 추가할 수 있게 합니다. 이 마법사는 새 프로젝트를 만들 때는 물론, [Ignite UI Angular Schematics](./getting-started-with-angular-schematics.mdx)로 이전에 만든 기존 프로젝트에 뷰를 추가할 때도 실행할 수 있습니다.

단계별 모드는 비대화형 또는 스크립트 사용을 지원하지 않습니다. 이러한 용도에는 명시적 인수를 사용하는 직접 `ng new` 및 `ng g` 명령을 사용하십시오. 마법사는 `Inquirer.js`에 의존합니다. 호환성은 [지원되는 터미널](https://github.com/SBoudrias/Inquirer.js#support-os-terminals)을 참조하십시오.

안내형 마법사를 실행하려면 다음을 실행하십시오:

```cmd
ng new --collection="@igniteui/angular-schematics"
```

## 새 프로젝트 만들기

마법사는 프로젝트를 스캐폴딩하기 전에 다음 구성 단계를 안내합니다. 템플릿으로 **Side Navigation** 또는 **Side Navigation Mini**를 선택하면 인증 단계가 추가로 나타납니다.

### 1단계: 부트스트랩 유형 선택하기

첫 번째 프롬프트는 독립형 컴포넌트를 사용할지 NgModule을 사용할지 묻습니다.

<Image src={igStepByStepProjectType} alt="단계별 프롬프트: 독립형 컴포넌트 또는 NgModule" class="responsive-img" />

독립형 컴포넌트는 Angular 17 이상의 기본값이며 새 프로젝트에 권장됩니다. NgModule은 기존 NgModule 기반 코드베이스와 통합하는 경우에만 선택하십시오.

### 2단계: 프로젝트 이름 입력하기

새 애플리케이션의 이름을 입력하십시오. 프로젝트는 같은 이름의 디렉터리에 생성됩니다.

<Image src={igStepByStepNewProjectName} alt="단계별 프롬프트: 프로젝트 이름 입력" class="responsive-img" />

### 3단계: 프로젝트 템플릿 선택하기

화살표 키로 사용 가능한 프로젝트 템플릿을 탐색하고 ENTER를 눌러 확인하십시오. 기본 템플릿은 세 가지입니다:

- **empty** - 라우팅과 홈 페이지가 있는 프로젝트 구조이며, 미리 만들어진 내비게이션은 없습니다
- **side-nav** - 미리 만들어진 사이드 내비게이션 드로어가 있는 프로젝트 구조입니다
- **side-nav-mini** - 미리 만들어진 간결한 사이드 내비게이션 드로어가 있는 프로젝트 구조입니다

<Image src={igStepByStepNewProjectTemplate} alt="단계별 프롬프트: 프로젝트 템플릿 선택" class="responsive-img" />

**side-nav** 또는 **side-nav-mini**를 선택하면, 마법사는 프로젝트에 [인증 모듈](./auth-template.mdx)을 추가할지 묻는 추가 단계를 표시합니다. 예를 선택하면 해당 인증 변형(`side-nav-auth` 또는 `side-nav-mini-auth`)이 생성됩니다. **empty**를 선택하면 인증 프롬프트는 건너뜁니다.

<Image src={igStepByStepNewProjectQuestion} alt="단계별 프롬프트: 인증 질문" class="responsive-img" />

### 4단계: 테마 선택하기

두 가지 테마 옵션을 사용할 수 있습니다:

- **default** - `angular.json`의 기본 Ignite UI for Angular Material 기반 테마가 들어 있는 미리 컴파일된 CSS 파일(`igniteui-angular.css`)을 포함합니다
- **custom** - 사용자 지정할 준비가 된 `app/styles.scss`의 [Theming API](../../themes/sass/index.mdx)를 사용하여 색상 팔레트와 테마 구성을 생성합니다

<Image src={igStepByStepNewProjectTheme} alt="단계별 프롬프트: 기본 또는 사용자 지정 테마 선택" class="responsive-img" />

위 단계를 마치면 마법사는 프로젝트 구조를 생성한 다음 [AI 코딩 어시스턴트 구성](#ai-어시스턴트-통합)을 요청합니다. AI 구성이 끝나면 Git 저장소가 초기화되고 초기 상태가 커밋됩니다. 그 후 마법사는 마칠지 아니면 컴포넌트 뷰를 추가하며 계속할지 묻습니다.

<Image src={igStepByStepNewProjectAction} alt="단계별 프롬프트: 마치기 또는 뷰 추가" class="responsive-img" />

## 컴포넌트 뷰 추가하기

Ignite UI for Angular Schematics 컬렉션은 개별 컴포넌트 템플릿과 더 정교한 시나리오 템플릿을 제공합니다. 이 모드는 프로젝트 생성의 연속 단계로도, 기존 프로젝트에서 독립된 작업으로도 사용할 수 있습니다.

기존 프로젝트에서 컴포넌트 마법사를 실행하려면 `component` 스키매틱(별칭: `c`)을 실행하십시오:

```bash
ng g @igniteui/angular-schematics:component
```

마법사는 사용 가능한 [컴포넌트 템플릿](./component-templates.mdx#컴포넌트-템플릿)을 카테고리별로 묶어 표시합니다. 화살표 키로 이동하고 ENTER를 눌러 선택하십시오.

<Image src={igStepByStepTemplateGroup} alt="단계별 프롬프트: 템플릿 카테고리 선택" class="responsive-img" />

사용자 지정 그리드 같은 일부 템플릿은 선택적 기능 목록을 제공합니다. ENTER로 확인하기 전에 SPACE 키를 사용하여 개별 옵션을 전환하십시오.

<Image src={igStepByStepComponentFeatures} alt="단계별 프롬프트: 선택적 컴포넌트 기능 전환" class="responsive-img" />

여러 컴포넌트를 결합한 더 완전한 애플리케이션 뷰를 제공하는 시나리오 템플릿도 있습니다. 목록에서 "Scenarios"를 선택하면 이를 둘러볼 수 있습니다.

<Image src={igStepByStepScenarioTemplates} alt="단계별 프롬프트: 시나리오 템플릿 선택" class="responsive-img" />

템플릿을 추가한 후 마법사는 뷰를 더 추가할지 아니면 과정을 마칠지 묻습니다. 완료되면 남은 패키지 종속성이 설치되고 애플리케이션이 실행되어 기본 브라우저에서 열립니다.

나중에 마법사 없이 프로젝트에 Ignite UI for Angular 뷰를 더 추가하려면 직접 스키매틱 명령을 사용하십시오:

```cmd
ng g @igniteui/angular-schematics:c [template] [name]
```

## AI 어시스턴트 통합

부트스트랩 유형, 프로젝트 이름, 템플릿, 테마를 선택하면 마법사는 AI 코딩 어시스턴트 통합을 구성하라는 메시지를 표시합니다. 이 단계는 `ng generate @igniteui/angular-schematics:ai-config`과 같은 로직을 실행하지만 프로젝트 생성 흐름에 포함되어 있습니다.

### 코딩 어시스턴트 선택

MCP 서버를 구성할 코딩 어시스턴트를 선택하라는 메시지가 표시됩니다. SPACE 키로 선택을 전환하고 ENTER로 확인하십시오:

<Image src={igStepByStepAiConfigAssistants} alt="단계별 프롬프트: MCP 구성용 코딩 어시스턴트 선택" class="responsive-img" />

- **일반**(Claude Code, VS Code 및 기타) - `.mcp.json`을(를) 씁니다
- **VS Code**(GitHub Copilot) - `.vscode/mcp.json`을(를) 씁니다
- **Cursor** - `.cursor/mcp.json`을(를) 씁니다
- **Gemini** - `.gemini/settings.json`을(를) 씁니다
- **JetBrains Junie** - `.junie/mcp/mcp.json`을(를) 씁니다
- **None** - MCP 구성을 건너뜁니다

기본 선택은 **일반**입니다. **None**을 선택하면 MCP 서버 구성을 완전히 건너뜁니다.

### AI 에이전트 선택

다음으로 스킬 파일과 지침을 구성할 AI 에이전트를 선택하라는 메시지가 표시됩니다:

<Image src={igStepByStepAiConfigAgents} alt="단계별 프롬프트: 스킬 파일과 지침용 AI 에이전트 선택" class="responsive-img" />

- **일반** - `.agents/skills/` 및 `AGENTS.md`
- **Claude** - `.claude/skills/` 및 `.claude/CLAUDE.md`
- **Copilot** - `.github/skills/` 및 `.github/copilot-instructions.md`
- **Cursor** - `.cursor/skills/` 및 `.cursor/rules/cursor.mdc`
- **Codex** - `.codex/skills/` 및 `.codex/instructions.md`
- **Windsurf** - `.windsurf/skills/` 및 `.windsurf/rules/guidelines.md`
- **Gemini** - `.gemini/skills/` 및 `.gemini/GEMINI.md`
- **Junie** - `.junie/skills/` 및 `.junie/guidelines.md`
- **None** - 스킬 파일과 지침을 건너뜁니다

기본 선택은 **일반**과 **Claude**입니다. **None**을 선택하면 에이전트 구성을 완전히 건너뜁니다.

Angular 스키매틱을 통해 실행하면 Ignite UI 서버와 함께 추가로 `angular-cli` MCP 서버 항목이 자동으로 포함됩니다.

<DocsAside type="info">
비대화형 프로젝트 생성 중 AI 구성 프롬프트를 완전히 건너뛰려면 `ng new`에 `--assistants none --agents none`을(를) 전달하십시오. 나중에 AI 구성을 다시 실행하려면 프로젝트 루트에서 `ng generate @igniteui/angular-schematics:ai-config`을(를) 사용하십시오.
</DocsAside>

MCP 클라이언트 구성과 사용 가능한 도구에 대한 전체 설명은 [Ignite UI CLI MCP](../../ai/cli-mcp.mdx)를 참조하십시오.
