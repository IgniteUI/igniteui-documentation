# 컴포넌트 템플릿

컴포넌트 템플릿은 기존 Angular 프로젝트에 Ignite UI CLI(`ig add`) 및 Ignite UI Angular Schematics(`ng g @igniteui/angular-schematics:c`)가 생성하는, 미리 구성된 Angular 컴포넌트 스캐폴드입니다. 각 템플릿은 올바른 import, 모듈 선언 및 샘플 데이터 세트를 포함한, 바로 동작하는 Angular 컴포넌트를 생성하므로 추가 구성 없이 실행할 수 있습니다. 템플릿은 그리드, 차트, 게이지, 지도, 레이아웃 컴포넌트, 메뉴, 알림, 데이터 입력 컨트롤, 상호 작용, 일정 관리 컨트롤 및 전체 애플리케이션 시나리오에 대해 제공됩니다.

이 템플릿은 기존 Angular 작업 공간에만 컴포넌트를 생성합니다. 새 Angular 프로젝트를 만들지는 않으므로, 그러려면 `ig new` 또는 `ng new`를 사용하십시오. 템플릿은 Ignite UI for Angular 전용입니다. React, Web Components, Blazor의 동등한 패턴은 각 프레임워크 문서에서 다룹니다. 생성된 코드는 기능적인 출발점 역할을 하며, 이 페이지에 연결된 실시간 데모(전체 문서 샘플을 반영함)와 다를 수 있습니다.
