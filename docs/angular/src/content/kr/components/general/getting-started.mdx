# Ignite UI for Angular 시작하기

[`Ignite UI for Angular`](https://github.com/IgniteUI/igniteui-angular)은(는) 데이터 그리드, 차트, 편집기, 내비게이션 컨트롤, 레이아웃 컨테이너를 포함한 100개 이상의 엔터프라이즈 UI 컴포넌트 라이브러리이며, Infragistics가 `igniteui-angular` npm 패키지로 배포합니다. 이 가이드는 세 가지 설치 방법(Ignite UI CLI, Angular Schematics, `ng add`를 사용하는 Angular CLI)을 안내하며, 로컬 데이터에서 렌더링된 동작하는 `IgxGridComponent`로 마무리합니다.

Ignite UI for Angular는 Angular 17 이상을 대상으로 하며, 기본 부트스트랩 모델은 독립형 컴포넌트입니다. Vue, React 또는 Web Components는 기본적으로 지원하지 않습니다. 해당 프레임워크는 [Ignite UI for React](https://www.infragistics.com/products/ignite-ui-react), [Ignite UI for Web Components](https://www.infragistics.com/products/ignite-ui-web-components), [Ignite UI for Blazor](https://www.infragistics.com/products/ignite-ui-blazor)를 참조하십시오.

Ignite UI for Angular는 이중 라이선스 모델로 제공됩니다. 일부 컴포넌트는 MIT 오픈 소스이며, 다른 컴포넌트는 상업용 라이선스가 필요합니다. 자세한 내용은 [Ignite UI 라이선스](./ignite-ui-licensing.mdx)와 [오픈 소스 vs 프리미엄](./open-source-vs-premium.mdx)을 참조하십시오.

## 사전 요구 사항

- Node.js 20 LTS 이상(Node.js 22 LTS 권장)
- npm 10 이상(Node.js 20에 포함), yarn 또는 pnpm
- `ng add` 설치 경로를 사용하려면 Angular CLI 17 이상
- Visual Studio Code 또는 TypeScript 언어 지원이 있는 모든 편집기

## Ignite UI for Angular 설치하기

Ignite UI for Angular는 세 가지 설치 방법을 지원합니다. 처음부터 새 프로젝트를 시작할 때는 Ignite UI CLI 또는 Angular Schematics를 사용하십시오. 기존 Angular 작업 공간에 Ignite UI for Angular를 추가할 때는 `ng add`을(를) 사용하십시오.

### Ignite UI CLI로 설치하기

Ignite UI CLI는 단일 명령으로 Ignite UI for Angular가 완전히 구성된 Angular 프로젝트를 스캐폴딩하는 독립형 명령줄 도구입니다. 전역으로 설치하십시오:

```cmd
npm install -g igniteui-cli
```

안내형 프로젝트 마법사를 실행하십시오:

```cmd
ig
```

또는 비대화형으로 프로젝트를 만드십시오:

```cmd
ig new <project-name> --framework=angular --type=igx-ts --template=side-nav
```

<DocsAside type="info">
Ignite UI CLI v13.1.0부터 `igx-ts` 프로젝트 유형은 기본적으로 독립형 컴포넌트를 사용하는 프로젝트를 생성합니다. 대신 NgModule 기반 부트스트랩을 사용하려면 `--type=igx-ts-legacy`을(를) 설정하십시오.
</DocsAside>

<DocsAside type="info">
과정 중에 아직 구성되지 않은 경우 [Infragistics npm 레지스트리에 로그인](./ignite-ui-licensing.mdx#비공개-npm-피드를-사용하도록-환경을-설정하는-방법단계별-가이드)하라는 메시지가 표시될 수 있습니다. 이는 [상업용 라이선스](./open-source-vs-premium.mdx#모든-컴포넌트-비교표)에 따라 컴포넌트를 사용할 때 적용됩니다.
</DocsAside>

모든 CLI 옵션과 프로젝트 템플릿을 자세히 보려면 [Ignite UI CLI 시작하기](./cli/getting-started-with-cli.mdx)와 [Angular Schematics 및 Ignite UI CLI](./cli-overview.mdx)를 참조하십시오.

### Angular Schematics로 설치하기

Ignite UI for Angular Schematics 컬렉션은 Angular CLI 작업 흐름에 통합되며, 별도의 전역 도구 없이 독립형 CLI와 같은 안내 경험을 제공합니다:

```cmd
npm i -g @igniteui/angular-schematics
```

안내형 마법사를 실행하십시오:

```cmd
ng new --collection="@igniteui/angular-schematics"
```

단계별 안내는 [Ignite UI for Angular Schematics를 사용한 단계별 가이드](./cli/step-by-step-guide-using-angular-schematics.mdx)를 참조하십시오.

### Angular CLI로 설치하기(`ng add`)

이미 Angular 프로젝트가 있거나 Angular CLI 안에서만 작업하려면 `ng add`을(를) 사용하여 Ignite UI for Angular를 설치하고 구성하십시오. 필요하면 먼저 새 Angular 앱을 만드십시오:

```cmd
ng new <project-name> --style=scss
```

[Ignite UI for Angular Theming 라이브러리](../themes/sass/index.mdx)가 SCSS 위에 구축되어 있고 `ng add`가 기본 테마를 자동으로 구성하므로 SCSS를 권장합니다. 그런 다음 Ignite UI for Angular를 추가하십시오:

```cmd
ng add igniteui-angular
```

<DocsAside type="info">
`ng add`은(는) `igniteui-angular`의 체험판 버전을 설치합니다. 프로젝트가 Ignite UI CLI로 스캐폴딩되었다면 이 단계는 건너뛰십시오. CLI가 이미 패키지 설정을 처리합니다. 나중에 라이선스 패키지로 전환하려면 아래의 [체험판에서 라이선스 버전으로 업그레이드](#체험판에서-라이선스-버전으로-업그레이드하기)를 참조하십시오.
</DocsAside>

#### 추가 패키지

일부 Ignite UI for Angular 컴포넌트는 별도의 npm 패키지로 제공되며 각각 독립적으로 추가합니다:

**[Grid Lite](../grid-lite/overview.mdx) - 오픈 소스(MIT)**

상업용 전체 기능 세트 없이 기본 데이터 표시만 필요한 프로젝트를 위한 가벼운 그리드입니다. API는 `IgxGrid`와 호환되므로 나중에 업그레이드할 때 변경이 최소화됩니다.

```cmd
ng add igniteui-grid-lite
```

**[Dock Manager](../dock-manager.mdx) - 프리미엄**

최종 사용자가 런타임에 패널을 고정, 크기 조정, 이동, 숨길 수 있는 패널 기반 레이아웃 컴포넌트입니다.

```cmd
ng add igniteui-dockmanager
```

## CLI 또는 Schematics로 컴포넌트 추가하기

초기 프로젝트 설정 후에는 `component` 스키매틱 또는 `add` 명령을 사용하여 Ignite UI for Angular 컴포넌트 뷰를 추가할 수 있습니다:

```cmd
ng g @igniteui/angular-schematics:component
```

```cmd
ig add
```

<DocsAside type="info">
`ig add` 명령은 Ignite UI CLI로 만든 프로젝트나, `ng add igniteui-angular`로 Ignite UI for Angular를 추가한 Angular CLI 프로젝트에서 사용할 수 있습니다.
</DocsAside>

## 컴포넌트를 수동으로 추가하기(독립형)

Angular 19부터 독립형 컴포넌트가 기본 부트스트랩 모델입니다. 다음 예제는 Schematics나 CLI를 사용하지 않고 독립형 Angular 애플리케이션에 `IgxGridComponent`을(를) 추가합니다.

일부 컴포넌트는 애니메이션을 사용하며, 이는 `bootstrapApplication` 호출에 공급자가 필요합니다. `app.config.ts`에서 이를 구성하십시오:

```typescript
// app/app.config.ts
import { ApplicationConfig, importProvidersFrom } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { provideAnimations } from '@angular/platform-browser/animations';
import { Provider } from '@angular/core';

const providers: Provider[] = [
  importProvidersFrom(BrowserModule),
  provideAnimations()
];

export const appConfig: ApplicationConfig = { providers };
```

### Grid 가져오기 및 사용하기

독립형 컴포넌트에서 `IgxGridComponent`과 `IgxColumnComponent`를 직접 가져오십시오. 이는 독립형 컴포넌트이므로 둘 다 `NgModule`이(가) 아니라 `imports` 배열에 추가하십시오:

```typescript
// app.component.ts
import { Component } from '@angular/core';
import { IgxGridComponent, IgxColumnComponent } from 'igniteui-angular';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styleUrls: ['./app.component.css'],
  imports: [IgxGridComponent, IgxColumnComponent]
})
export class AppComponent {
  localData = [
    { Name: 'John', Age: 29 },
    { Name: 'Alice', Age: 27 },
    { Name: 'Jessica', Age: 31 },
  ];
}
```

컴포넌트 템플릿에 그리드를 추가하고, `[data]`을(를) 로컬 배열에 바인딩하며 열을 명시적으로 정의하십시오:

```html
<!-- app.component.html -->
<igx-grid [data]="localData" width="600px" height="400px" [allowFiltering]="true">
  <igx-column field="Name" dataType="string"></igx-column>
  <igx-column field="Age" dataType="number"></igx-column>
</igx-grid>
```

이렇게 하면 열 필터링이 활성화된 Ignite UI for Angular Grid가 렌더링되어 로컬 데이터 세 행을 표시합니다.

### 애플리케이션 실행하기

사용 중인 설정에 맞는 명령으로 애플리케이션을 실행하십시오:

```cmd
ig start
```

또는 Angular CLI로 만든 프로젝트라면:

```cmd
ng serve
```

## 체험판에서 라이선스 버전으로 업그레이드하기

체험판 `igniteui-angular` 패키지에서 라이선스 버전으로 전환하려면 프로젝트 루트에서 업그레이드 스키매틱을 실행하십시오:

```bash
ng g @igniteui/angular-schematics:upgrade-packages
```

또는 Ignite UI CLI를 사용하여:

```bash
ig upgrade-packages
```

스키매틱은 패키지 종속성을 업데이트하고 소스 참조를 교체합니다. 아직 구성되지 않았다면 [Infragistics 비공개 npm 레지스트리에 로그인](./ignite-ui-licensing.mdx#비공개-npm-피드를-사용하도록-환경을-설정하는-방법단계별-가이드)하라는 메시지가 표시됩니다.

## AI 지원 개발

Ignite UI for Angular는 AI 지원 개발을 위한 두 가지 도구를 제공합니다.

**Agent Skills**는 GitHub Copilot, Cursor, Windsurf, Claude, JetBrains AI 같은 AI 코딩 어시스턴트에 Ignite UI 컴포넌트, API, 테마 패턴을 올바르게 사용하는 방법을 가르치는 구조화된 지식 파일입니다. 스킬은 데이터 그리드, 그리드 작업, 차팅, 테마를 다룹니다. [Ignite UI for Angular Skills](../ai/skills.mdx)를 참조하십시오.

**Ignite UI MCP 서버**는 Ignite UI CLI에 내장된 서버로, AI 어시스턴트를 편집기 안에서 실시간 Ignite UI 컴포넌트 문서와 API 참조에 직접 연결합니다. 정적 스킬과 달리 MCP 서버는 현재 API에 대한 질문에 답하고, 요청 시 설정 가이드를 가져오며, Ignite UI 컴포넌트에 대한 정확한 코드 생성을 지원합니다. CLI를 설치한 후 `ig mcp`로 시작하십시오. 클라이언트 구성과 사용 가능한 도구는 [Ignite UI CLI MCP 개요](../ai/cli-mcp.mdx)를 참조하십시오.
