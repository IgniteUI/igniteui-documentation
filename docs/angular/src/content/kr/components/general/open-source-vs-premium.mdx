# Ignite UI for Angular의 오픈 소스 vs 프리미엄

Ignite UI for Angular는 현대적이고 데이터 중심의 애플리케이션을 만들기 위한 두 가지 뚜렷한 경로인 오픈 소스 컴포넌트와 프리미엄 컴포넌트를 제공합니다. 이 이중 접근 방식은 프로젝트의 모든 단계에서 개발자에게 유연성을 보장합니다.

## 오픈 소스 컴포넌트

MIT 라이선스로 제공되는 50개 이상의 UI 컴포넌트가 있으며, 여기에는 [Grid Lite](/grid-lite/overview), Accordion, Avatar, Badge, Banner, Button, Calendar, Carousel, Checkbox, Chip, Combo, Date Picker, Drop Down, Input, List, Snackbar 등이 포함됩니다. 전체 목록은 [모든 컴포넌트 비교표](#모든-컴포넌트-비교표)에서 확인할 수 있습니다.

모든 오픈 소스 컴포넌트는 해당 항목의 헤더에 다음과 함께 표시되어 있습니다: <Badge variant="opensource" />

이 컴포넌트들은 엔터프라이즈 기능의 부담 없이 필수 기능이 필요한 가벼운 애플리케이션에 이상적입니다. 운영 환경에서 자유롭게 사용하고, 사용자 지정하고, 포크하고, GitHub를 통해 기여할 수 있습니다. 라이선스는 필요하지 않습니다.

## 프리미엄 컴포넌트

Ignite UI 프리미엄 컴포넌트는 고급 엔터프라이즈 기능을 제공하며, 고성능과 더 풍부한 기능이 필요한 복잡한 애플리케이션에 사용됩니다. 프리미엄 컴포넌트에는 다음이 포함됩니다:

### 그리드 및 고급 컴포넌트

- [데이터 그리드](/grid/grid), [계층형 그리드](/hierarchicalgrid/hierarchical-grid), [트리 그리드](/treegrid/tree-grid), [피벗 그리드](/pivotgrid/pivot-grid)
- [Dock Manager](/dock-manager)
- [Query Builder](/query-builder)
- [차팅 라이브러리](/charts/chart-overview)
- [지도 라이브러리](/geo-map)
- [Excel 라이브러리](/excel-library)
- [Spreadsheet](/spreadsheet-overview)
- 게이지 - [Bullet Graph](/bullet-graph), [Linear Gauge](/linear-gauge), [Radial Gauge](/radial-gauge)

모든 프리미엄 컴포넌트는 해당 항목의 헤더에 다음과 함께 표시되어 있습니다: <Badge variant="premium" />

모든 프리미엄 컴포넌트는 로컬에서 평가할 수 있으며, 워터마크가 표시된 상태로 운영 환경에서도 테스트할 수 있습니다. 하지만 고객이 접하는 배포와 고급 그리드, 차트 및 기타 프리미엄 컨트롤의 모든 기능을 사용하려면 상업용 라이선스가 필요합니다.

## 업그레이드 경로

기본적인 요구에는 Grid Lite로 시작하고, 애플리케이션이 복잡해짐에 따라 모든 기능을 갖춘 Data Grid로 원활하게 업그레이드하십시오. 이렇게 하면 리팩터링을 최소화하고 엔터프라이즈급 기능으로 매끄럽게 전환할 수 있습니다.
