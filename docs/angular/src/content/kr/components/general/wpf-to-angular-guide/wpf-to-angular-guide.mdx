# 데스크톱에서 웹으로 마이그레이션하기: WPF에서 Angular로의 튜토리얼

WPF에서 Angular로의 튜토리얼은 `desktop`에서 `web` 프레임워크로 원활하게 전환하기 위해 가장 먼저 해야 할 단계입니다. 이 튜토리얼은 웹 개발을 처음 시작하는 WPF 개발자를 대상으로 하며, 애플리케이션 구조, 데이터 바인딩, 이벤트, 컴포넌트 등 두 프레임워크의 차이점과 유사점을 살펴봅니다.

    <Image src={wpfToAngularGuide} alt="WPF에서 Angular로의 가이드" class="responsive-img" style="vertical-align: middle;" />
</p>

이 가이드는 다음 주제로 나뉘며 동영상 튜토리얼도 포함되어 있습니다:

## [첫 Angular 애플리케이션 만들기](/general/wpf-to-angular-guide/create-first-angular-app)

Angular를 배우는 여정을 시작하기 전에 Angular로 최신 웹 앱을 개발하기 위한 사전 요구 사항을 설치해야 합니다. 이 섹션은 Node.js 패키지 관리자 사용, Visual Studio Code IDE 설치, 최신 웹 개발에 필요한 몇 가지 기본 개념을 다룹니다. 이 주제의 [동영상 튜토리얼](https://youtu.be/dhjrAPPad54)을 확인하십시오.

## [Angular 컴포넌트로 UI 만들기](/general/wpf-to-angular-guide/create-ui-with-components)

Angular에서 UI를 만드는 것은 WPF에서 만드는 것과 매우 비슷합니다. 보통 UserControl 클래스로 표현되는 사용자 컨트롤을 사용합니다. UserControl은 마크업과 코드를 재사용 가능한 컨테이너로 묶어, 같은 인터페이스와 기능을 여러 곳에서 사용할 수 있게 합니다. Angular 컴포넌트를 이해하는 것은 이 시리즈의 나머지 부분을 이해하는 데 핵심이므로, WPF 컴포넌트가 Angular 컴포넌트로 어떻게 대응되는지 이해하는 것부터 시작하겠습니다. 이 주제의 [동영상 튜토리얼](https://youtu.be/z1SZUezpRXY)을 확인하십시오.

## [Angular의 단방향 데이터 바인딩](/general/wpf-to-angular-guide/one-way-binding)

WPF에서 가장 강력하고 널리 쓰이는 기능 중 하나는 데이터 바인딩입니다. 이는 비즈니스 로직과 뷰를 한 줄의 추가 코드도 작성하지 않고 동기화하여 개발자의 삶을 훨씬 쉽게 만들어 줍니다. 이 기능이 없다면 WPF는 그저 더 보기 좋은 Windows Forms에 불과했을 것입니다. 다행히 Angular도 데이터 바인딩을 지원합니다! 데이터 바인딩에는 단방향 바인딩과 양방향 바인딩 두 가지 유형이 있습니다. 이 섹션은 단방향 데이터 바인딩을 구현하는 방법과 WPF와 비교되는 점을 보여 줍니다. 이 주제의 [동영상 튜토리얼](https://youtu.be/fP7iVhFNTOk)을 확인하십시오.

## [Angular 이벤트](/general/wpf-to-angular-guide/angular-events)

사용자 입력 이벤트에 바인딩하는 것은 모든 앱의 핵심입니다. 어떤 방식으로든 사용자 상호 작용에 응답하지 않는 새 앱을 작성하는 것은 상상하기 어렵습니다. 이를 가장 일반적으로 하는 방법은 어떤 형태의 이벤트 시스템을 사용하는 것입니다. WPF는 라우팅된 이벤트, CLR 이벤트, 커맨드를 제공합니다. 반면 Angular에는 DOM 이벤트가 있습니다. 이 섹션에서는 DOM 이벤트와 사용자 입력을 처리하는 방법을 배웁니다. 이 주제의 [동영상 튜토리얼](https://youtu.be/V1Futz4W400)을 확인하십시오.

## [Angular의 양방향 데이터 바인딩](/general/wpf-to-angular-guide/two-way-binding)

Angular에서 단방향 바인딩은 컴포넌트 클래스에서 오는 데이터로 뷰를 업데이트합니다. WPF와 마찬가지로 반대 작업도 할 수 있습니다. 즉 뷰에서 컴포넌트 클래스를 업데이트하는 것입니다. 이 경우에는 양방향 바인딩을 사용해야 합니다. 이 섹션은 WPF의 양방향 바인딩을 비교하고 시작하기가 얼마나 쉬운지 보여 줍니다. 이 주제의 [동영상 튜토리얼](https://youtu.be/MrjTTDEj7cA)을 확인하십시오.

## [Angular 파이프로 데이터 변환하기](/general/wpf-to-angular-guide/angular-pipes)

WPF에서는 데이터를 변환하기 위해 IValueConverter를 사용하고, Angular 애플리케이션에서는 Angular 파이프를 사용합니다. 파이프는 WPF 컨버터와 매우 비슷합니다. 입력으로 데이터를 받아 표시할 원하는 출력으로 변환합니다. 이 섹션은 사전 정의된 Angular 파이프 중 일부와 앱에서 이를 사용하는 방법을 보여 줍니다. 이 주제의 [동영상 튜토리얼](https://youtu.be/Gmz5kio50FE)을 확인하십시오.

## [Angular의 구조 디렉티브](/general/wpf-to-angular-guide/structural-directives)

WPF 개발자로서 시각 트리에서 요소를 추가하거나 제거하고 싶을 때마다, 코드 비하인드에 들어가 C#을 작성하거나 바인딩과 가시성 컨버터를 조합해야 했습니다. 이는 다시 사용자 지정 로직과 정적 리소스가 필요합니다. WPF에서는 늘 그렇게 해 왔지만, Angular는 이를 훨씬 쉽게 만듭니다. 이 섹션은 구조 디렉티브가 Angular 앱에서 요소를 조작할 수 있게 하는 방법을 보여 줍니다. 이 주제의 [동영상 튜토리얼](https://youtu.be/vQe7R78Od8k)을 확인하십시오.

## [레이아웃 요소](/general/wpf-to-angular-guide/layout)

WPF에서는 애플리케이션의 요소를 배치하려면 요소를 Panel 안에 넣어야 합니다. Angular에서는 CSS를 사용합니다. 이 주제는 레이아웃을 다루며, Flexbox와 CSS Grid 같은 CSS 기능을 사용하는 방법을 설명합니다.
