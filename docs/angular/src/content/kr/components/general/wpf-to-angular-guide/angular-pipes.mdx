# Angular 파이프로 데이터 변환하기

<iframe width="100%" height="600" src="https://www.youtube.com/embed/Gmz5kio50FE">
</iframe>

Angular 파이프를 사용하면 한 값을 다른 값으로 변환할 수 있습니다. 이 기법은 WPF 컨버터와 비슷합니다.

WPF에서 한 값을 다른 값으로 변환하려면 [IValueConverter](https://docs.microsoft.com/en-us/dotnet/api/system.windows.data.ivalueconverter?view=netframework-4.8)를 사용합니다. Angular 애플리케이션에서 데이터를 변환하려면 [파이프](https://angular.io/api/core/Pipe)를 사용합니다. 파이프는 WPF 컨버터와 매우 비슷합니다. 입력으로 데이터를 받아 표시할 원하는 출력으로 변환합니다.

Angular는 가장 일반적인 데이터 변환을 위한 여러 사전 정의된 파이프를 제공합니다. 예를 들어 헤더 텍스트를 대문자로 표시하고 싶다면 [UpperCasePipe](https://angular.io/api/common/UpperCasePipe)를 사용할 수 있습니다. 파이프를 사용하는 것은 매우 간단합니다. 표현식 뒤에 파이프 연산자 `|`를 쓰고, 그 뒤에 파이프 이름을 적으면 됩니다.

```html
<h2>{{ header | uppercase }}</h2>
```

WPF 컨버터와 비교했을 때 Angular 파이프의 정말 좋은 점은 한 번에 둘 이상의 파이프를 사용할 수 있다는 것입니다. 예를 들어 [DatePipe](https://angular.io/api/common/DatePipe)와 [UpperCasePipe](https://angular.io/api/common/UpperCasePipe)를 함께 사용하여 날짜를 사용자 친화적인 형식으로 바꾸고 대문자로 만들 수 있습니다:

```html
<h2>{{ birthday | date | uppercase }}</h2>
```

그 밖에도 파이프에 매개변수를 전달할 수 있습니다. 예를 들어 [DatePipe](https://angular.io/api/common/DatePipe)에는 형식, 시간대, 로캘 같은 매개변수가 있습니다.

```html
<h2>{{ birthday | date:"MM/dd/yy" }}</h2>
```

## 자체 파이프 만들기

사전 정의된 파이프를 사용하는 것 외에도 Angular에서는 자체 파이프를 정의할 수 있습니다. 문자열을 다른 문자열로 바꾸는 WPF 컨버터의 구현을 살펴보겠습니다.

```csharp
public class ReplaceConverter : IValueConverter
{
    public string OldValue { get; set; }
    public string NewValue { get; set; }

    public object Convert(object value, Type targetType, object parameter, CultureInfo culture)
    {
        var strValue = value.ToString();
        return strValue.Replace(this.OldValue, this.NewValue);
    }

    public object ConvertBack(object value, Type targetType, object parameter, CultureInfo culture)
    {
        throw new NotImplementedException();
    }
}
```

```xml
<Window.Resources>
    <local:ReplaceConverter OldValue=" " NewValue="-" x:Key="replaceConverter"></local:ReplaceConverter>
</Window.Resources>
<Grid>
    <TextBlock Text="{Binding Path=Name, Mode=OneWay, Converter={StaticResource replaceConverter}}"></TextBlock>
</Grid>
```

Angular에서 같은 작업을 하려면 [PipeTransform](https://angular.io/api/core/PipeTransform) 인터페이스를 구현하고 [@Pipe](https://angular.io/api/core/Pipe) 데코레이터를 가진 클래스를 정의해야 합니다.

```typescript
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({
    name: 'replace'
})
export class ReplacePipe implements PipeTransform {

    transform(value: string, oldValue: string, newValue: string): string {
        return value.replace(oldValue, newValue);
    }
}
```

```html
<span>{{ name | replace:" ":"-" }}</span>
```

<DocsAside type="info">
컴포넌트의 HTML 템플릿에서 파이프를 사용할 수 있도록 모듈 선언에 파이프를 추가해야 한다는 점에 유의하십시오.
</DocsAside>

<DocsAside type="info">
Angular 파이프와 WPF 컨버터의 중요한 차이점은, WPF 컨버터에는 [ConvertBack](https://docs.microsoft.com/en-us/dotnet/api/system.windows.data.ivalueconverter.convertback?view=netframework-4.8) 메서드가 있는 반면 Angular 파이프는 단방향 바인딩에서만 동작한다는 것입니다.
</DocsAside>
