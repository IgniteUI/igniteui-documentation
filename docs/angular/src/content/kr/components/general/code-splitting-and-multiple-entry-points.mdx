# 코드 분할 및 다중 진입점

버전 21.0.0부터 Ignite UI for Angular는 다중 진입점을 지원하여, 컴포넌트의 더 나은 트리 셰이킹, 코드 분할 및 지연 로딩을 가능하게 합니다. 이 구조 개선으로 필요한 컴포넌트와 유틸리티만 import할 수 있어 애플리케이션의 번들 크기를 크게 줄일 수 있습니다.

## 개요

이전에는 모든 Ignite UI for Angular 컴포넌트가 단일 진입점(`igniteui-angular`)에서 내보내졌습니다. 편리하긴 했지만, 이 방식은 모든 컴포넌트를 하나로 묶어서 빌드 도구가 사용되지 않는 코드를 효과적으로 제거하기 어렵게 만들었습니다.

새로운 다중 진입점 구조에서는 각 컴포넌트 또는 관련 컴포넌트 그룹이 자체 전용 진입점을 가집니다. 이를 통해 최신 번들러는 다음을 수행할 수 있습니다:

- **코드 분할 활성화** - 각 컴포넌트를 필요할 때 개별적으로 지연 로드할 수 있습니다
- **초기 번들 크기 줄이기** - 초기 로드에서 애플리케이션이 실제로 필요로 하는 것만 import합니다
- **빌드 성능 향상** - 더 작은 종속성 그래프는 더 빠른 빌드로 이어집니다

## 장점

✅ **코드 분할** - 각 컴포넌트를 지연 로드할 수 있습니다  
✅ **더 작은 초기 번들** - 필요한 것만 import합니다  
✅ **더 나은 성능** - 개별 번들 크기가 줄어 로드 시간이 빨라집니다  
✅ **깔끔한 구조** - 순환 종속성이 없습니다  
✅ **완전한 이전 버전 호환성** - 기본 진입점도 여전히 동작합니다  
✅ **세분화된 그리드 import** - 필요한 그리드 유형만 로드합니다

### 그리드 진입점

그리드 컴포넌트는 최적의 코드 분할을 위해 세분화된 진입점으로 나뉩니다:

- `igniteui-angular/grids/core` - 공유 그리드 기반 구조(열, 도구 모음, 필터링, 정렬, 파이프 및 유틸리티)
- `igniteui-angular/grids/grid` - Data Grid 컴포넌트(`IgxGridComponent`)
- `igniteui-angular/grids/tree-grid` - Tree Grid 컴포넌트(`IgxTreeGridComponent`)
- `igniteui-angular/grids/hierarchical-grid` - Hierarchical Grid 컴포넌트(`IgxHierarchicalGridComponent`, `IgxRowIslandComponent`)
- `igniteui-angular/grids/pivot-grid` - Pivot Grid 컴포넌트(`IgxPivotGridComponent`, `IgxPivotDataSelectorComponent`)

## 마이그레이션

### 자동 마이그레이션

권장 방법은 `ng update` 과정 중에 import를 자동으로 마이그레이션하는 것입니다. 버전 21.0.0으로 업데이트할 때 import를 마이그레이션하라는 메시지가 표시됩니다:

```cmd
ng update igniteui-angular
```

메시지가 표시되면 최적의 번들 크기를 위해 import를 새 진입점으로 마이그레이션하도록 **"Yes"**를 선택하십시오.

또는 마이그레이션을 별도로 실행할 수 있습니다:

```cmd
ng update igniteui-angular --migrate-only --from=20.1.0 --to=21.0.0
```

### 수동 마이그레이션

수동으로 마이그레이션하고 싶거나 특정 import만 업데이트해야 한다면 다음 패턴을 따르십시오:

#### 이전 (v20.x 이하)

```typescript
import { 
  IgxGridComponent,
  IgxTreeGridComponent,
  IgxInputDirective,
  IgxBottomNavComponent,
  Direction, 
  GridBaseAPIService,
  IgxOverlayService,
  IFilteringExpression
} from 'igniteui-angular';
```

#### 이후 (v21.0.0)

```typescript
import { IgxOverlayService, IFilteringExpression } from 'igniteui-angular/core';
import { GridBaseAPIService } from 'igniteui-angular/grids/core';
import { IgxGridComponent } from 'igniteui-angular/grids/grid';
import { IgxTreeGridComponent } from 'igniteui-angular/grids/tree-grid';
import { IgxInputDirective } from 'igniteui-angular/input-group';
import { IgxBottomNavComponent } from 'igniteui-angular/bottom-nav';
import { CarouselAnimationDirection } from 'igniteui-angular/carousel';
```

### 타입 이름 변경

새 아키텍처와의 이름 충돌을 피하기 위해 일부 타입의 이름이 변경되었습니다:

- `Direction` → `CarouselAnimationDirection`(carousel 진입점에서)

```typescript
// Before
import { Direction } from 'igniteui-angular';

// After
import { CarouselAnimationDirection } from 'igniteui-angular/carousel';
```

## 이전 버전과의 호환성

기본 진입점(`igniteui-angular`)은 모든 세분화된 진입점을 다시 내보내어 **이전 버전과의 완전한 호환성**을 유지합니다. 아무런 변경 없이 기본 진입점의 import를 계속 사용할 수 있습니다:

```typescript
// This still works and will continue to work
import { IgxGridComponent, IgxButtonDirective } from 'igniteui-angular';
```

다만 더 나은 트리 셰이킹과 더 작은 번들 크기를 활용하려면 **새 진입점으로 마이그레이션하는 것을 강력히 권장합니다**.

## 사용 예

### 예 1: 간단한 컴포넌트 사용

버튼과 입력만 필요하다면 해당 진입점만 import하십시오:

```typescript
import { Component } from '@angular/core';
import { IgxButtonDirective } from 'igniteui-angular/directives';
import { 
  IgxInputGroupComponent, 
  IgxInputDirective, 
  IgxLabelDirective 
} from 'igniteui-angular/input-group';

@Component({
  selector: 'app-form',
  standalone: true,
  imports: [
    IgxButtonDirective,
    IgxInputGroupComponent,
    IgxInputDirective,
    IgxLabelDirective
  ],
  template: `
    <igx-input-group>
      <label igxLabel>Name</label>
      <input igxInput type="text" />
    </igx-input-group>
    <button igxButton="contained">Submit</button>
  `
})
export class FormComponent {}
```

### 예 2: 특정 기능이 있는 그리드

필요한 그리드 유형과 핵심 그리드 유틸리티만 import하십시오:

```typescript
import { Component } from '@angular/core';
import { IgxGridComponent } from 'igniteui-angular/grids/grid';
import { IgxGridToolbarComponent } from 'igniteui-angular/grids/core';

@Component({
  selector: 'app-data-grid',
  standalone: true,
  imports: [IgxGridComponent, IgxGridToolbarComponent],
  template: `
    <igx-grid [data]="data" [autoGenerate]="true">
      <igx-grid-toolbar></igx-grid-toolbar>
    </igx-grid>
  `
})
export class DataGridComponent {
  public data = [
    { id: 1, name: 'John' },
    { id: 2, name: 'Jane' }
  ];
}
```

### 예 3: 컴포넌트 지연 로딩

새 진입점을 사용하면 컴포넌트를 쉽게 지연 로드할 수 있습니다:

```typescript
// app.routes.ts
import { Routes } from '@angular/router';

export const routes: Routes = [
  {
    path: 'grid',
    loadComponent: () => 
      import('./features/grid/grid.component')
        .then(m => m.GridComponent)
  },
  {
    path: 'tree-grid',
    loadComponent: () => 
      import('./features/tree-grid/tree-grid.component')
        .then(m => m.TreeGridComponent)
  }
];
```

```typescript
// features/grid/grid.component.ts
import { Component } from '@angular/core';
import { IgxGridComponent } from 'igniteui-angular/grids/grid';

@Component({
  selector: 'app-grid',
  standalone: true,
  imports: [IgxGridComponent],
  template: `<igx-grid [data]="data" [autoGenerate]="true"></igx-grid>`
})
export class GridComponent {
  public data = [];
}
```

## 마이그레이션 옵션 요약

v21.0.0으로 업데이트할 때 세 가지 옵션이 있습니다:

### 옵션 1: 업데이트 중 마이그레이션(권장)

```cmd
ng update igniteui-angular
```

메시지가 표시되면 import를 마이그레이션하려면 **"Yes"**를 선택하십시오.

### 옵션 2: 기본 진입점 계속 사용하기

```cmd
ng update igniteui-angular
```

메시지가 표시되면 기본 진입점을 계속 사용하려면 **"No"**를 선택하십시오. 라이브러리는 여전히 이전 버전과 완전히 호환되지만, 최적의 번들 크기 혜택은 받을 수 없습니다.

### 옵션 3: 나중에 마이그레이션하기

마이그레이션하지 않고 업데이트하기(메시지가 표시되면 "No" 선택):

```cmd
ng update igniteui-angular
```

나중에 수동으로 마이그레이션하기:

```cmd
ng update igniteui-angular --migrate-only --from=20.1.0 --to=21.0.0
```

## 권장 사항

1. **구체적인 진입점 사용하기** - 가능한 한 가장 구체적인 진입점에서 import하십시오(예: `igniteui-angular` 대신 `igniteui-angular/grids/grid`)
2. **지연 로딩 활용하기** - 진입점을 Angular의 지연 로딩과 결합하면 성능이 더 향상됩니다
3. **필요한 것만 import하기** - 서비스 하나만 필요하다면 `core` 진입점 전체를 import하지 마십시오
4. **번들 분석기 확인하기** - [webpack-bundle-analyzer](https://www.npmjs.com/package/webpack-bundle-analyzer) 같은 도구로 번들 크기 개선을 검증하십시오
5. **정기적으로 업데이트하기** - 최신 최적화의 혜택을 받도록 Ignite UI for Angular 버전을 최신 상태로 유지하십시오
