# 지역화(i18n)

## 지역화(i18n)

<DocsAside type="info">
21.1.0부터 이 방식이 Ignite UI for Angular 컴포넌트에 지역화를 적용하는 권장 방법입니다.
</DocsAside>

새로운 지역화에서는 모든 사용 가능한 로캘에 대해 지역화 문자열과 서식 지정 요구 사항을 줄이면서 더 많은 기능을 제공합니다. 서식 지정은 이제 `Intl` API에서 도입된 표준을 기반으로 합니다.

현재 Ignite UI for Angular는 다음 언어의 리소스 문자열과 함께 제공됩니다: `Bulgarian`, `Czech`, `Danish`, `Dutch`, `English`, `French`, `German`, `Hungarian`, `Italian`, `Japanese`, `Korean`, `Norwegian`, `Polish`, `Portuguese`, `Romanian`, `Spanish`, `Swedish`, `Turkish`, `Traditional Chinese (zh-Hant)` 및 `Simplified Chinese (zh-Hans)`. 영어는 `igniteui-angular`에 기본 지역화로 포함되어 있으며, 그 외 언어는 `igniteui-angular-i18n` 패키지를 통해 사용할 수 있습니다.

### 로캘

로캘이란 지구상의 서로 다른 언어와 지역을 정의하는 일반적인 문자열을 말합니다. 우리 경우에는 [BCP 47](https://developer.mozilla.org/en-US/docs/Glossary/BCP_47_language_tag) 태그 정의를 기반으로 하며, 대부분의 기본 태그는 [IANA 언어 하위 태그 레지스트리](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry)에 설명되어 있습니다. 언어 목록은 `[ISO 639 언어 표준](https://www.loc.gov/standards/iso639-2/)을 참조하십시오.

로캘은 날짜와 숫자의 서식뿐 아니라 컴포넌트가 사용하는 지역화된 리소스 문자열에도 영향을 줍니다. Ignite UI for Angular 컴포넌트의 기본 로캘은 `en-US`입니다.

로캘을 설정하는 방법은 여러 가지가 있습니다. 전역으로 설정하거나 컴포넌트별로 설정할 수 있습니다.

#### 전역 API

`igniteui-angular` 패키지에서 제공하는 `setCurrentI18n` 메서드를 사용하여 전역으로 사용될 로캘을 설정할 수 있습니다. 이는 모든 컴포넌트에서 사용되는 서식과 등록된 리소스 문자열 모두에 영향을 줍니다. 리소스 문자열에 대한 자세한 내용은 [지역화된 리소스 문자열](#지역화된-리소스-문자열)을 참조하십시오.

```ts
setCurrentI18n('de');
```

`Intl`이(가) 지원하는 가능한 모든 로캘을 지원합니다. 유효하지 않거나 지원되지 않는 로캘을 제공하면, 유효한 로캘로 바꿀 때까지 기본 `en-US` 로캘을 사용합니다.

일반적으로 컴포넌트도 지역화되도록 사용할 태그의 언어, 지역, 스크립트 아래에 리소스를 등록해야 합니다. 자세한 내용은 [지역과 스크립트](#지역과-스크립트) 섹션을 참조하십시오.

#### `lang` 속성

이 방식을 사용하면 `HTML` 태그의 전역 `lang` 속성을 통해 지역화를 설정할 수 있습니다. 이 속성은 감시되며, 변경되면 렌더링된 모든 컴포넌트가 리소스 문자열을 현재 설정된 언어로 업데이트합니다. 사용된 태그와 관련된 모든 규칙은 위에서 설명한 것과 같습니다.

<DocsAside type="info">
이 방식은 루트 수준에서만 동작하며, 페이지의 내부 요소에는 적용되지 않습니다.
</DocsAside>

```html
<html lang="ja">
    <head>
        <title>My app</title>
    </head>
    <body></body>
</html>
```

#### Angular API

Angular에 내장된 [LOCALE_ID](https://angular.dev/api/core/LOCALE_ID) 토큰을 사용하여 애플리케이션 전체의 로캘을 설정할 수도 있습니다. 제공된 태그는 우리 API가 처리하는 방식과 비교했을 때 컴포넌트에서도 같은 방식으로 동작합니다.

#### 컴포넌트별

각 컴포넌트에는 지정할 수 있는 자체 `locale` 속성도 있으며, 이 경우 전역 로캘의 영향을 받지 않습니다.

```html
<igx-grid [data]="data" locale="ja">
    <igx-column field="ProductName" header="Product Name" [groupable]="true"></igx-column>
    <igx-column field="QuantityPerUnit" header="Quantity Per Unit" [groupable]="true"></igx-column>
</igx-grid>
```

### 형식 지정

앞에서 언급한 것처럼 로캘은 날짜, 숫자 및 이와 관련된 일부 문자열을 렌더링하는 모든 Ignite UI for Angular 컴포넌트의 서식에 영향을 줍니다. 이전에는 앱에서 사용하려면 제공되는 로캘 데이터의 [Angular 전역 변형](https://angular.dev/guide/i18n/import-global-variants)을 import해야 했습니다. 이제는 이런 필요가 없으며, 이 기능은 지역화에 기본으로 내장되어 있어서 동작하기 위해 아무것도 import하거나 등록할 필요가 없습니다.

이 기능은 방금 도입되었으므로, Angular의 방식도 여전히 사용 가능하며 이전과 같이 잘 동작하고, 이미 사용 중이라면 여전히 기본 방식입니다.

이제 시작하는 경우라면, Angular 로캘 데이터를 import해 두었더라도 새 서식을 사용하도록 `provideIgniteIntl()` 메서드를 앱 구성에 추가하기만 하면 됩니다:

```ts
export const appConfig: ApplicationConfig = {
    providers: [
        //...
        provideIgniteIntl()
    ]
};
```

### 지역화된 리소스 문자열

Ignite UI for Angular의 모든 컴포넌트는 기본적으로 영어로 렌더링되며, 위에 나열된 언어 중 어느 것으로도 렌더링할 수 있습니다. 전역으로 이를 달성하는 방법은 세 가지이고, 컴포넌트별로는 한 가지 방법이 있습니다. 현재 제공되지 않는 언어는 API를 통해 사용할 수 있는 리소스 문자열마다 사용자 지정 번역을 제공할 수 있습니다.

컴포넌트 문자열의 번역은 리소스 문자열에 저장되며, 컴포넌트가 사용할 수 있도록 지역화 시스템에 등록해야 합니다.

이를 위해 먼저 모든 언어의 지역화된 리소스 문자열을 담고 있는 `igniteui-angular-i18n` 패키지를 설치해야 합니다:

```
npm install igniteui-angular-i18n --save-dev
```

그다음 사용할 수 있게 하려는 각 언어를 등록하십시오. 예를 들어 독일어와 일본어라고 합시다:

```ts
import { IgxResourceStringsDE, IgxResourceStringsJA } from 'igniteui-angular-i18n';

registerI18n(IgxResourceStringsDE, 'de');
registerI18n(IgxResourceStringsJA, 'ja');
```

또한 이 리소스가 적용될 로캘도 제공해야 합니다. 유효한 태그가 제공되지 않으면 기본 'en-US' 로캘의 리소스가 설정됩니다.

#### 지역과 스크립트

리소스를 등록할 때 사용한 로캘의 `language + region` 또는 `language + script`를 고려합니다. 이는 가장 일반적으로 사용되기 때문입니다. 이들은 `-`로 구분되며, 지역/스크립트는 보통 두 번째나 세 번째 위치에 정의됩니다. 예를 들어 `en-US` 또는 `en-GB`, 또는 `en-Latn`입니다.

지역이나 스크립트를 사용하지 않으면, 등록한 리소스는 예를 들어 `en` 언어를 사용하는 모든 로캘에 적용됩니다. 다만 지역과 스크립트에 대한 리소스도 정의한 경우에는, 정의하지 않은 항목에 대해서만 이 경우 `en`의 리소스가 반환됩니다.

리소스를 등록할 때 스크립트는 지역보다 우선순위가 높습니다. 일반적으로 지역과 스크립트를 섞어서 동시에 사용하기보다는 둘 중 하나만 사용하는 것을 권장합니다. 그래야 설정한 로캘에 따라 어떤 리소스가 있고 어떤 것을 사용해야 하는지 관리하고 알기가 더 쉽습니다.

그래도 둘 다 사용한다면, 예를 들어 `GB` 지역과 `Latn` 스크립트를 가진 `en` 언어를 생각해 보십시오. `en-GB`와 `en-Latn`처럼 지역과 스크립트 둘 다에 리소스를 정의하고, 나중에 지역과 스크립트를 모두 `en-Latn-GB`(으)로 설정하여 로캘을 설정하면, 우리는 먼저 스크립트의 리소스를 가져옵니다. 그것이 없으면 사용 가능한 지역의 리소스를 반환합니다. 물론 로캘을 `en-Latn`(으)로 명시적으로 설정하는 경우는 예외입니다. 둘 중 어느 것도 리소스가 등록되어 있지 않다면, 사용 가능하다면 `en`의 기본값을 사용합니다.

### 컴포넌트 사용자 지정하기

앱의 특정 컴포넌트에 대해 전역으로 이미 등록된 리소스를 다른 지역화로 사용하고 싶거나, 리소스 문자열을 완전히 교체하고 싶다면 다음과 같은 방법으로 할 수 있습니다.

#### 언어와 서식

컴포넌트에 대해 전역 지역화와 다른 값을 설정하고 싶다면 `locale` 속성을 설정하면 됩니다. 이는 리소스 문자열의 언어와 서식 모두에 영향을 줍니다. 두 가지가 서로 연결되어 있기 때문입니다.

이 방식을 사용하려면 사용 가능한 리소스 문자열이 이미 전역으로 등록되어 있어야 합니다:

```ts
import { IgxResourceStringsJA } from 'igniteui-angular-i18n';

registerI18n(IgxResourceStringsJA, 'ja');
```

컴포넌트의 `locale` 속성을 설정하면 현재 사용 중인 전역 로캘을 재정의합니다:

```html
<igx-grid [data]="data" locale="ja">
    <igx-column field="ProductName" header="Product Name" [groupable]="true"></igx-column>
    <igx-column field="QuantityPerUnit" header="Quantity Per Unit" [groupable]="true"></igx-column>
</igx-grid>
```

##### 언어만 변경

로캘은 변경하지 않고 컴포넌트의 언어만 바꾸고 싶다면, `resourceStrings` 속성을 사용하여 각 컴포넌트의 리소스 문자열을 설정할 수도 있습니다. 이는 전역으로 사용되는 것을 재정의합니다:

```html
<igx-grid [data]="data" [resourceStrings]="resourcesDE">
    <igx-column field="ProductName" header="Product Name" [groupable]="true"></igx-column>
    <igx-column field="QuantityPerUnit" header="Quantity Per Unit" [groupable]="true"></igx-column>
</igx-grid>
```

재정의하는 데 사용하는 컴포넌트에 맞는 올바른 리소스 문자열 타입을 사용해야 합니다. 각 컴포넌트는 자체 리소스 문자열 집합을 가지고 있습니다. 이 경우 독일어로 된 그리드 예제입니다:

```ts
import { GridResourceStringsDE } from 'igniteui-angular-i18n';

// Inside App Component:
public resourcesDE = GridResourceStringsDE;
```

### 사용자 지정 지역화 리소스 문자열

앱을 지역화하고 싶은데 사용하는 언어의 리소스 문자열을 제공하지 않는 경우 직접 번역을 제공하고 싶다면, 언제든지 사용자 지정 리소스 문자열을 제공할 수 있습니다. 전역으로 하거나 컴포넌트별로(`resourceStrings` 속성을 사용하여) 할 수 있습니다.

<DocsAside type="info">
더 많은 언어로 [`igniteui-i18n-resources`](https://github.com/IgniteUI/igniteui-i18n/tree/master/projects/igniteui-i18n-resources) 패키지에 기여해 주십시오. `igniteui-angular-i18n`은(는) 그 언어들을 기반으로 합니다.
</DocsAside>

모든 컴포넌트에 대해 제공되는 `IResourceStrings` 타입을 사용하면, 사용되는 리소스 문자열의 타입 정보를 얻을 수 있습니다:

```ts
import { IResourceStrings } from 'igniteui-angular';

export const customResourcesForAll: IResourceStrings = {
    //...
};
registerI18n(customResourcesForAll, 'custom');
```

또는 특정 컴포넌트에 대해 따로, 이 경우 그리드에 대해 사용할 수 있습니다:

```ts
import { IGridResourceStrings } from 'igniteui-angular';

export const customGridResources: IGridResourceStrings = {
    grid_summary_count: 'गणना',
    grid_summary_min: 'न्यून',
    grid_summary_max: 'अधिक',
    grid_summary_sum: 'योग',
    grid_summary_average: 'औसत'
};

```

기본 영어를 포함하여, 이미 있는 리소스 문자열과 사용자 지정하려는 문자열을 원하는 방식으로 섞을 수도 있습니다:

```ts
import { IResourceStrings, CalendarResourceStringsEN, DatePickerResourceStringsEN } from 'igniteui-angular';

export const customResources: IResourceStrings = Object.assign(
    {},
    CalendarResourceStringsEN,
    DatePickerResourceStringsEN,
    {
        grid_summary_count: 'Custom count',
        grid_summary_min: 'Minium',
        grid_summary_max: 'Maximum',
        grid_summary_sum: 'Custom summary'
    }
);
registerI18n(customResources, 'en');

```

<DocsAside type="info">
마지막 예제들은 특정 리소스 문자열만 설정합니다. 이는 나머지 문자열이 사용 중인 컴포넌트에서 가져올 수 없는 경우 기본적으로 영어로 대체된다는 뜻입니다.
</DocsAside>

### 사용법

### npm 패키지에서 지역화된 리소스 불러오기

다음과 같이 `igniteui-angular-i18n` 패키지에서 사용 가능한 언어 중 하나로 애플리케이션을 지역화할 수 있습니다:

`npm install igniteui-angular-i18n --save-dev`을 실행하여 패키지를 설치하십시오

원하는 언어의 리소스 문자열을 import하고, 컴포넌트 인스턴스의 `resourceStrings` 입력을 사용하여 특정 컴포넌트 인스턴스의 문자열을 바꾸십시오.

```html
<igx-grid [data]="data" [resourceStrings]="resourcesDE" [locale]="locale">
    <igx-grid-toolbar>
        <igx-grid-toolbar-title>German Locale</igx-grid-toolbar-title>
    </igx-grid-toolbar>
    <igx-column field="ProductName" header="Product Name" [groupable]="true">
    </igx-column>
    <igx-column field="QuantityPerUnit" header="Quantity Per Unit" [groupable]="true">
    </igx-column>
    <igx-column field="UnitPrice" header="Unit Price" [sortable]="true" [hasSummary]="true"
        [dataType]="'currency'" [groupable]="true">
    </igx-column>
    <igx-column field="OrderDate" header="Order Date" [dataType]="'date'" [groupable]="true">
    </igx-column>
    <igx-column field="Discontinued" header="Discontinued" [dataType]="'boolean'" [groupable]="true">
    </igx-column>
</igx-grid>
```

```typescript
import { Component } from '@angular/core';
import { registerLocaleData } from '@angular/common';

import localeDE from '@angular/common/locales/de';
import { GridResourceStringsDE } from 'igniteui-angular-i18n';

@Component({
    selector: 'app-locale',
    styleUrls: ['./locale.component.scss'],
    templateUrl: 'locale.component.html'
})
export class LocaleComponent implements OnInit {
    public resourcesDE = GridResourceStringsDE;
    public locale = 'DE';
    public data: any[];

    constructor() {
        registerLocaleData(localeDE);
    }
}
```

또는 해당 리소스 객체를 전달하여 `changei18n()` 함수를 호출하면 모든 컴포넌트의 지역화를 바꿀 수 있습니다.

```typescript
// app.component.ts
import { Component, OnInit } from '@angular/core';
import { changei18n } from "igniteui-angular/core";
import { IgxResourceStringsJA } from 'igniteui-angular-i18n';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styleUrls: ['./app.component.scss']
})
export class AppComponent implements OnInit {
    public ngOnInit(): void {
        changei18n(IgxResourceStringsJA);
    }
}
```

<DocsAside type="info">
더 많은 언어로 [`igniteui-angular-i18n`](https://github.com/IgniteUI/igniteui-angular/tree/master/projects/igniteui-angular-i18n) 패키지에 자유롭게 기여해 주십시오!
</DocsAside>

#### 자체 지역화 리소스 사용하기

`changei18n` 함수는 `IResourceStrings` 객체를 받습니다. 사용하려는 언어가 `igniteui-angular-i18n` 패키지에 없거나, 특정 문자열만 바꾸고 싶다면, 필요한 언어와 컴포넌트에 대한 문자열 리소스를 담은 사용자 지정 객체를 전달할 수 있습니다. 이는 igniteui-angular 컴포넌트의 전역 i18n을 바꿉니다.

```typescript
// app.component.ts
import { Component, OnInit } from '@angular/core';
import { changei18n, IGridResourceStrings } from "igniteui-angular/core";

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styleUrls: ['./app.component.scss']
})
export class AppComponent implements OnInit {
    public partialCustomHindi: IGridResourceStrings;

    public ngOnInit(): void {
        this.partialCustomHindi = {
            igx_grid_summary_count: 'गणना',
            igx_grid_summary_min: 'न्यून',
            igx_grid_summary_max: 'अधिक',
            igx_grid_summary_sum: 'योग',
            igx_grid_summary_average: 'औसत'
        };
        // This will change all grid application instances' strings to the newly provided ones
        changei18n(this.partialCustomHindi);
    }
}
```

또는 현재 사용 가능한 모든 컴포넌트 리소스 문자열을 가져올 수 있습니다. 각 컴포넌트에는 지역화 가능한 문자열을 담은 객체가 있습니다. 이 값들을 지역화하여 바꾼 다음, 그 객체를 매개변수로 `changei18n` 함수에 전달할 수 있습니다.

```typescript
// app.component.ts
import { Component, OnInit } from '@angular/core';
import { changei18n, GridResourceStringsEN, TimePickerResourceStringsEN } from "igniteui-angular/core";

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styleUrls: ['./app.component.scss']
})
export class AppComponent implements OnInit {
    public ngOnInit(): void {
        const currentRS = {
            ...GridResourceStringsEN,
            ...TimePickerResourceStringsEN
        };

        for (const key of Object.keys(currentRS)) {
            currentRS[key] = '[Localized] '+ currentRS[key];
        }

        changei18n(currentRS);
    }
}
```

#### 특정 컴포넌트 인스턴스의 특정 문자열만 지역화하기

하나의 `igx-grid` 인스턴스만 지역화해야 한다면 방법이 있습니다. `resourceStrings` 속성을 사용하고, `IGridResourceStrings` 타입의 새 인스턴스로 설정해야 합니다.

```typescript
const newGridRes: IGridResourceStrings = {
    igx_grid_filter: '[Localized]Filter',
    igx_grid_filter_row_close: '[Localized]Close'
}

this.grid.resourceStrings = newGridRes;
```
