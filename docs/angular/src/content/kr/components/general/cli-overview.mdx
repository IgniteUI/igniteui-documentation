# Angular Schematics 및 Ignite UI CLI

Ignite UI CLI와 Ignite UI for Angular Schematics 모음은 Ignite UI for Angular용으로 미리 구성된 Angular 프로젝트와 컴포넌트 뷰를 생성하는 두 가지 상호 보완적인 스캐폴딩 도구입니다. 두 도구 모두 단계별 안내 마법사와 비대화형 명령 모드를 제공합니다. 두 도구가 만드는 프로젝트 결과물은 같으며, 작업 흐름과 통합되는 방식만 다릅니다.

Ignite UI CLI는 이 Angular 도구 체인을 통해 Blazor 또는 Web Components 프로젝트를 관리하지 않습니다. 별도의 전역 도구 없이 Angular 전용 Schematics 작업 흐름을 사용하려면 Angular CLI와 함께 `@igniteui/angular-schematics`을(를) 직접 사용하십시오. 두 도구 모두 Ignite UI for Angular를 사용하는 데 필수는 아닙니다. 라이브러리는 [시작하기 가이드](./getting-started.mdx)에 설명된 대로 수동으로 설치하고 구성할 수 있습니다.

## Ignite UI CLI

[Ignite UI CLI](https://github.com/IgniteUI/igniteui-cli)는 Angular, React 및 jQuery 전반에 걸쳐 애플리케이션을 만들고 스캐폴딩하기 위한 독립형 전역 명령줄 도구입니다. `npm install -g igniteui-cli`로 설치하고 `ig` 명령으로 호출합니다.

CLI는 안내 마법사(`ig` 또는 `ig new`), 비대화형 프로젝트 생성(`ig new <name> --framework=angular --type=igx-ts`), 컴포넌트 스캐폴딩(`ig add`), 개발 서버(`ig start`), 그리고 AI 어시스턴트 연동을 위한 내장 MCP 서버(`ig mcp`)를 제공합니다.

설정 방법과 사용 가능한 모든 명령은 [Ignite UI CLI 시작하기](./cli/getting-started-with-cli.mdx)를 참조하십시오.

## Ignite UI for Angular Schematics

[Ignite UI for Angular Schematics](https://github.com/IgniteUI/igniteui-cli/tree/master/packages/ng-schematics)는 Angular CLI에 통합되는 schematic 모음입니다. `ng add igniteui-angular`을(를) 실행하면 이 모음이 프로젝트에 자동으로 추가됩니다. 프로젝트 생성에는 `ng new --collection="@igniteui/angular-schematics"`, 컴포넌트 스캐폴딩에는 `ng g @igniteui/angular-schematics:component`로 호출합니다.

Schematics 모음은 CLI와 같은 핵심 프로젝트 템플릿과 컴포넌트 뷰를 기본 Angular CLI 작업 흐름 안에서 제공합니다. MCP 서버는 포함되지 않습니다. AI 어시스턴트 연동이 필요하면 Angular CLI 프로젝트와 함께 Ignite UI CLI를 사용하십시오.

설정 방법은 [Ignite UI for Angular Schematics 시작하기](./cli/getting-started-with-angular-schematics.mdx)를 참조하십시오.

## AI 어시스턴트 통합(MCP)

Ignite UI CLI에는 GitHub Copilot, Claude, Cursor 등의 AI 코딩 어시스턴트를 실시간 Ignite UI 컴포넌트 문서와 API 참조에 연결하는 내장 MCP(Model Context Protocol) 서버가 포함되어 있습니다. 구성되면 AI 어시스턴트는 편집기를 벗어나지 않고도 컴포넌트 API를 조회하고, 설정 가이드를 가져오며, 정확한 Ignite UI for Angular 코드를 생성할 수 있습니다.

다음 명령으로 MCP 서버를 시작하십시오:

```cmd
ig mcp
```

클라이언트 구성(VS Code, Claude Desktop, Cursor)과 사용 가능한 도구 설명은 [Ignite UI CLI MCP](../ai/cli-mcp.mdx)를 참조하십시오.
