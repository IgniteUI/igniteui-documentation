# Angular Bottom Navigation 컴포넌트 개요

<div class="highlight">
Ignite UI for Angular Bottom Navigation 컴포넌트는 사용자가 하나의 보기에 표시된 여러 콘텐츠 패널 사이를 이동할 수 있게 합니다. 패널 사이의 탐색은 애플리케이션 하단에 있는 탭 버튼으로 이루어집니다.
</div>

<DocsAside type="info">
`igx-tab-bar` 선택기는 더 이상 사용되지 않습니다. 대신 <ApiLink type="BottomNav" label="igx-bottom-nav" />을(를) 사용할 수 있습니다. `IgxTabBarComponent` 클래스의 이름은 <ApiLink type="BottomNav" />(으)로 바뀌었습니다. `IgxTabBarModule`의 이름은 `IgxBottomNavModule`(으)로 바뀌었습니다.
</DocsAside>

## Ignite UI for Angular Bottom Navigation 시작하기

Ignite UI for Angular Bottom Navigation 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](./general/getting-started.mdx) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxBottomNavModule`을 가져오는 것입니다.

```typescript
// app.module.ts

...
import { IgxBottomNavModule } from 'igniteui-angular/bottom-nav';
// import { IgxBottomNavModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxBottomNavModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxBottomNavComponent`을 독립형(standalone) 종속성으로 가져올 수 있으며, [`IGX_BOTTOM_NAV_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/bottom-nav/src/bottom-nav/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수도 있습니다.

```typescript
// home.component.ts

import { IGX_BOTTOM_NAV_DIRECTIVES } from 'igniteui-angular/bottom-nav';
import { IgxIconComponent } from 'igniteui-angular/icon';
// import { IGX_BOTTOM_NAV_DIRECTIVES, IgxIconComponent } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-bottom-nav>
        <igx-bottom-nav-item>
            <igx-bottom-nav-header>
                <igx-icon>library_music</igx-icon>
            </igx-bottom-nav-header>
            <igx-bottom-nav-content>This is Item 1 content.</igx-bottom-nav-content>
        </igx-bottom-nav-item>
        <igx-bottom-nav-item>
            <igx-bottom-nav-header>
                <igx-icon>video_library</igx-icon>
            </igx-bottom-nav-header>
            <igx-bottom-nav-content>This is Item 2 content.</igx-bottom-nav-content>
        </igx-bottom-nav-item>
        <igx-bottom-nav-item>
            <igx-bottom-nav-header>
                <igx-icon>library_books</igx-icon>
            </igx-bottom-nav-header>
            <igx-bottom-nav-content>This is Item 3 content.</igx-bottom-nav-content>
        </igx-bottom-nav-item>
    </igx-bottom-nav>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_BOTTOM_NAV_DIRECTIVES, IgxIconComponent]
    /* or imports: [IgxBottomNavComponent, IgxBottomNavItemComponent, IgxBottomNavHeaderComponent, IgxBottomNavContentComponent, IgxIconComponent] */
})
export class HomeComponent {}
```

이제 Ignite UI for Angular Bottom Navigation 모듈 또는 디렉티브를 가져왔으므로 `igx-bottom-nav` 컴포넌트를 사용할 수 있습니다.

## Angular Bottom Navigation 사용하기

컴포넌트의 템플릿에는 Bottom Navigation과 세 개의 항목이 포함됩니다. 각 항목은 각각 헤더와 데이터 컨테이너를 나타내는 `igx-bottom-nav-header`과(와) `igx-bottom-nav-content` 컴포넌트를 감쌉니다. 헤더는 보통 아이콘과 선택적인 텍스트 레이블로 구성됩니다. Bottom Navigation 컨트롤은 Material Design [**아이콘**](https://material.io/icons/)과 호환되므로, 이를 애플리케이션에 적용하려면 메인 애플리케이션 폴더의 'styles.css' 파일에 Material+Icons 가져오기를 추가하면 됩니다.

<DocsAside type="info">
지금까지 애플리케이션에서 `igx-icon`을(를) 사용하지 않았다면, 계속하기 전에 **app.module.ts**에서 `IgxIconModule`을(를) 가져왔는지 확인하십시오.
</DocsAside>

```css
// styles.css

...
@import url('https://fonts.googleapis.com/icon?family=Material+Icons');
...
```

```html
<igx-bottom-nav>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon>library_music</igx-icon>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>This is Item 1 content.</igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon>video_library</igx-icon>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>This is Item 2 content.</igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon>library_books</igx-icon>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>This is Item 3 content.</igx-bottom-nav-content>
    </igx-bottom-nav-item>
</igx-bottom-nav>
```

모든 것이 잘 되었다면 브라우저에서 데모 샘플을 볼 수 있을 것입니다.

## Bottom Navigation 사용자 지정하기

아이콘 옆에 레이블을 추가하여 탭을 수정하고, 헤더가 올바르게 스타일링되었는지 확인해 보겠습니다.

먼저 컴포넌트 TypeScript 파일에서 데이터 소스를 위한 객체 배열을 정의하십시오:

```typescript
public songsList: object[] = [
    { title: 'Havana', artist: 'Camila Cabello' },
    { title: 'Meant To Be', artist: 'Bebe Rexha & Florida Georgia Line' },
    { title: 'New Rules', artist: 'Dua Lipa' },
    { title: 'Wolves', artist: 'Selena Gomez & Marshmello' }
];

public moviesList: object[] = [
    { title: 'Logan', genre: 'Action, Drama, Sci-Fi' },
    { title: 'Wonder Woman', genre: 'Action, Adventure, Fantasy' },
    { title: 'Guardians of the Galaxy Vol. 2', genre: 'Action, Adventure, Sci-Fi' },
    { title: 'Star Wars: The Last Jedi', genre: 'Action, Adventure, Fantasy' }
];

public booksList: object[] = [
    { title: 'Wonder', author: 'R. J. Palacio' },
    { title: 'Milk and Honey', author: 'Rupi Kaur' },
    { title: 'Giraffes Can\'t Dance', author: 'Jeff Kinne' },
    { title: 'The Getaway', author: 'Selena Gomez & Marshmello' }
];
```

다음으로 컴포넌트의 템플릿 마크업을 다음과 같이 업데이트하십시오:

```html
<igx-bottom-nav>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon igxBottomNavHeaderIcon>library_music</igx-icon>
            <span igxBottomNavHeaderLabel>Songs</span>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>
            <div class="item" *ngFor="let song of songsList">
                <span class="item-line1">{{song.title}}</span><br/>
                <span class="item-line2">{{song.artist}}</span>
            
</div>
        </igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon igxBottomNavHeaderIcon>video_library</igx-icon>
            <span igxBottomNavHeaderLabel>Movies</span>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>
            <div class="item" *ngFor="let movie of moviesList">
                <span class="item-line1">{{movie.title}}</span><br/>
                <span class="item-line2">{{movie.genre}}</span>
            
</div>
        </igx-bottom-nav-content>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item>
        <igx-bottom-nav-header>
            <igx-icon igxBottomNavHeaderIcon>library_books</igx-icon>
            <span igxBottomNavHeaderLabel>Books</span>
        </igx-bottom-nav-header>
        <igx-bottom-nav-content>
            <div class="item" *ngFor="let book of booksList">
                <span class="item-line1">{{book.title}}</span><br/>
                <span class="item-line2">{{book.author}}</span>
            
</div>
        </igx-bottom-nav-content>
    </igx-bottom-nav-item>
</igx-bottom-nav>
```

항목의 헤더 태그 사이에 아이콘과 레이블이 있는 span을 배치하는 것 외에도, 이들에 `igxBottomNavHeaderIcon` 및 `igxBottomNavHeaderLabel` 디렉티브를 연결한 것을 눈치채셨을 것입니다. 이 디렉티브들은 해당 요소를 나타내고 적절한 스타일을 적용합니다.

마지막으로 콘텐츠 템플릿의 DIV 및 SPAN 요소가 사용하는 CSS 클래스를 컴포넌트의 CSS 파일에 추가하십시오:

```css
.item {
    margin-bottom: 5px;
}

.item-line1 {
    font-size: 14px;
    color: gray;
}

.item-line2 {
    font-size: 12px;
    color: darkgray;
}

igx-bottom-nav-content {
    padding: 10px;
}
```

## Router Outlet 컨테이너와의 통합

Bottom Navigation 컴포넌트의 주된 용도는 콘텐츠가 있는 탭 항목을 정의하는 것이지만, 헤더만 있는 탭 항목을 정의해야 하는 경우도 있을 수 있습니다. 아마도 이러한 사용의 주요 시나리오는 Angular Router를 사용한 보기 간 탐색일 것입니다. 다음 예제는 Bottom Navigation 컴포넌트를 구성하여 하나의 router-outlet에서 세 개의 컴포넌트를 전환하는 방법을 보여 줍니다.

먼저 Bottom Navigation 컴포넌트를 호스팅하는 메인 컴포넌트와 시연용 콘텐츠가 있는 세 개의 보기 컴포넌트가 필요합니다. 코드 조각을 간단하게 하기 위해 보기 컴포넌트는 매우 짧은 템플릿을 갖지만, 필요하다면 더 뚜렷하게 구분되도록 자유롭게 만들어도 됩니다. 또한 `app.module.ts` 파일에서 이러한 보기 컴포넌트를 가져오십시오.

```typescript
// bottomnav-routing.component.ts
import { Component } from '@angular/core';

@Component({
    selector: 'app-bottomnav-routing',
    styleUrls: ['bottomnav-routing.component.scss'],
    templateUrl: 'bottomnav-routing.component.html'
})
export class BottomNavRoutingComponent { }

@Component({
    template: '<p>Item 1 Content</p>'
})
export class BottomNavRoutingView1Component { }

@Component({
    template: '<p>Item 2 Content</p>'
})
export class BottomNavRoutingView2Component { }

@Component({
    template: '<p>Item 3 Content</p>'
})
export class BottomNavRoutingView3Component { }
```

다음 단계는 `app-routing.module.ts` 파일에 적절한 탐색 매핑을 만드는 것입니다:

```typescript
import { RouterModule, Routes } from '@angular/router';

import {
    TabbarRoutingComponent,
    TabbarRoutingView1Component,
    TabbarRoutingView2Component,
    TabbarRoutingView3Component,
} from './tabbar-routing.component';

const routes: Routes = [
    {
        path: '',
        pathMatch: 'full',
        redirectTo: '/tabbar-routing'
    },
    {
        path: 'tabbar-routing',
        component: TabbarRoutingComponent,
        children: [
            { path: 'tabbar-view1', component: TabbarView1Component },
            { path: 'tabbar-view2', component: TabbarView2Component },
            { path: 'tabbar-view3', component: TabbarView3Component }
        ]
    }
];

@NgModule({
    exports: [ RouterModule ],
    imports: [ RouterModule.forChild(routes) ]
})
export class TabbarRoutingModule { }
```

이제 모든 탐색 라우트를 설정했으므로 BottomNavigation 컴포넌트를 선언하고 라우팅하도록 구성해야 합니다.
또한 보기 컴포넌트의 출력을 렌더링하기 위한 router-outlet을 추가하십시오.

```html
{/* bottomnav-routing.component.html */}
<router-outlet></router-outlet>

<igx-bottom-nav #tabs1>
    <igx-bottom-nav-item
        routerLinkActive
        #rla1="routerLinkActive"
        [selected]="rla1.isActive"
        >
        <igx-bottom-nav-header routerLink="tabbar-view1">
            <igx-icon igxBottomNavHeaderIcon>phone</igx-icon>
        </igx-bottom-nav-header>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item
        routerLinkActive
        #rla2="routerLinkActive"
        [selected]="rla2.isActive"
    >
        <igx-bottom-nav-header routerLink="tabbar-view2">
            <igx-icon igxBottomNavHeaderIcon>supervisor_account</igx-icon>
        </igx-bottom-nav-header>
    </igx-bottom-nav-item>
    <igx-bottom-nav-item
        routerLinkActive
        #rla3="routerLinkActive"
        [selected]="rla3.isActive"
    >
        <igx-bottom-nav-header routerLink="tabbar-view3">
            <igx-icon igxBottomNavHeaderIcon>format_list_bulleted</igx-icon>
        </igx-bottom-nav-header>
    </igx-bottom-nav-item>
</igx-bottom-nav>
```

위 코드는 탭 항목 세 개가 있는 BottomNavigation 컴포넌트를 만듭니다. 모든 탭 항목에는 연결된 라우트가 현재 활성 상태인지 추적하는 `RouterLinkActive` 디렉티브가 적용되어 있습니다. 참고로 `RouterLink` 디렉티브는 탭 항목이 아니라 헤더 요소 자체에 적용됩니다. 이들 링크 중 하나가 활성화되면, `RouterLinkActive` 디렉티브의 `isActive` 속성에 바인딩되어 있으므로 해당 탭 항목의 `selected` 속성이 설정됩니다. 이렇게 하면 선택된 탭 항목이 항상 현재 브라우저 주소와 동기화된 상태를 유지합니다.

위에서 설명한 방식은 다음 샘플에서 BottomNavigation 컴포넌트를 사용한 라우팅을 보여 주는 데 사용됩니다:

탭의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-bottom-nav-theme" label="bottom-nav-theme" code={true} />을(를) 확장하고 탭 그룹의 스타일을 지정할 수 있는 다양한 매개변수를 받는 새 테마를 만듭니다.

```scss
$dark-bottom-nav: bottom-nav-theme(
  $background: #292826,
  $icon-selected-color: #f4d45c
);
```

<DocsAside type="info">
방금 한 것처럼 색상 값을 직접 하드코딩하는 대신, <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> 및 <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} /> 함수를 사용하면 색상을 훨씬 유연하게 다룰 수 있습니다. 사용 방법에 대한 자세한 안내는 [`Palettes`](./themes/sass/palettes.mdx) 항목을 참조하십시오.
</DocsAside>

<ApiLink kind="sass" module="themes" type="function-bottom-nav-theme" label="bottom-nav-theme" code={true} />을(를) 살펴보면 Bottom Navigation 컴포넌트의 스타일을 지정할 수 있는 매개변수가 훨씬 더 많다는 것을 알 수 있습니다!

<DocsAside type="info">
항목 콘텐츠의 일부로 사용되는 추가 컴포넌트의 스타일을 지정하려면, 해당 컴포넌트에 특화된 테마를 추가로 만들어야 합니다.
</DocsAside>

마지막 단계는 애플리케이션에 컴포넌트 테마를 **포함**하는 것입니다.

```scss
:host {
    @include tokens($dark-bottom-nav);
}
```

### Tailwind로 스타일링하기

사용자 지정 Tailwind 유틸리티 클래스를 사용하여 bottom navigation의 스타일을 지정할 수 있습니다. 먼저 [Tailwind를 설정](./themes/tailwind.mdx)했는지 확인하십시오.

전역 스타일시트에서 Tailwind를 가져오는 것과 함께, 다음과 같이 원하는 테마 유틸리티를 적용할 수 있습니다:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

유틸리티 파일에는 `light` 및 `dark` 테마 변형이 모두 포함되어 있습니다.

- 밝은 테마에는 `light-*` 클래스를 사용하십시오.
- 어두운 테마에는 `dark-*` 클래스를 사용하십시오.
- 접두사 뒤에 컴포넌트 이름을 붙이십시오. 예: `light-bottom-nav`, `dark-bottom-nav`.

적용하면 이 클래스는 동적 테마 계산을 가능하게 합니다. 그런 다음 `arbitrary properties`을 사용하여 생성된 CSS 변수를 재정의할 수 있습니다. 콜론 뒤에는 유효한 CSS 색상 형식(HEX, CSS 변수, RGB 등)을 입력하십시오.

속성의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-bottom-nav-theme" label="IgxBottomNav 테마" />에서 확인할 수 있습니다. 구문은 다음과 같습니다:

```html
<igx-bottom-nav
    class="!light-bottom-nav
    ![--background:#011627]
    ![--icon-selected-color:#FF8040] 
    ![--label-selected-color:#FF8040]">
    ...
</igx-bottom-nav>
```

<DocsAside type="info">
유틸리티 클래스가 우선 적용되도록 느낌표(`!`)가 필요합니다. Tailwind는 스타일을 계층으로 적용하므로, 이 스타일을 중요(important)로 표시하지 않으면 컴포넌트의 기본 테마에 의해 재정의됩니다.
</DocsAside>
