# Angular List View 컴포넌트 개요

Ignite UI for Angular List 컴포넌트는 항목의 행을 표시하며, 하나 이상의 머리글 항목과 목록 항목 검색 및 필터링을 지원합니다. 각 목록 항목은 완전히 템플릿화할 수 있으며, 유효한 HTML 또는 [Angular 컴포넌트](https://www.infragistics.com/products/ignite-ui-angular)를 지원합니다. 목록 컴포넌트는 내장 패닝 기능, 비어 있음 및 로딩 상태용 템플릿을 제공하며, [`IgxForOf`](/for-of) 디렉티브를 사용해 대형 목록의 가상화도 지원합니다.

## Angular List 예제

다음 예제는 *이름*과 _전화번호_ 속성을 가진 연락처로 채워진 목록을 보여 줍니다. <ApiLink type="List" /> 컴포넌트는 [`igx-avatar`](layouts/avatar.mdx)과(와) [`igx-icon`](/layouts/icon)을(를) 사용하여 사용자 경험을 높이고, 아바타 사진 설정과 *연락처 즐겨찾기*용 다른 아이콘을 설정하는 기능을 보여 줍니다. 또한 List View는 필터링 파이프를 사용하여 정렬 기능도 제공합니다.

## Ignite UI for Angular List 시작하기

Ignite UI for Angular List View 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxListModule`을(를) 가져오는 것입니다.

```typescript
// app.module.ts

import { IgxListModule } from 'igniteui-angular/list';
// import { IgxListModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxListModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxListComponent`을 독립형(standalone) 종속성으로 가져올 수 있으며, [`IGX_LIST_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/list/src/list/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수도 있습니다.

```typescript
// home.component.ts

import { IGX_LIST_DIRECTIVES } from 'igniteui-angular/list';
// import { IGX_LIST_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-list>
        <igx-list-item isHeader="true">Header</igx-list-item>
        <igx-list-item>Item 1</igx-list-item>
        <igx-list-item>Item 2</igx-list-item>
        <igx-list-item>Item 3</igx-list-item>
    </igx-list>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_LIST_DIRECTIVES]
    /* or imports: [IgxListComponent, IgxListItemComponent] */
})
export class HomeComponent {}
```


이제 Ignite UI for Angular List 모듈 또는 디렉티브를 가져왔으므로 `igx-list` 컴포넌트를 사용할 수 있습니다.

## Angular List 사용하기

그러면 연락처 컴포넌트의 템플릿에 목록을 만들 수 있습니다. 하지만 현재(또는 앞으로 어느 시점에) 목록에 항목이 전혀 없다면 어떻게 할까요?
이 경우 Angular 목록은 목록이 비어 있을 때 사용되는 기본 템플릿을 제공합니다.
<ApiLink type="EmptyListTemplateDirective" /> 디렉티브를 사용하면 비어 있는 목록의 모양에 대해 언제든 직접 템플릿을 제공할 수 있습니다. 이 경우 기본 템플릿은 사용되지 않습니다:

```html
{/*contacts.component.html*/}

<igx-list>
    <ng-template igxEmptyList>
        <div class="empty">
No contacts! :(
</div>
    </ng-template>
</igx-list>
```

빈 템플릿의 스타일은 다음과 같습니다:

```css
/* contacts.component.css */

.empty {
    color: rgba(0, 153, 255, 1);
    font-size: 25px;
    font-weight: 600;
    text-shadow: 2px 1px 2px rgba(150, 150, 150, 1);
}
```

모든 것이 잘 되었다면, 비어 있는 목록은 다음과 같이 보여야 합니다:

### 아바타와 아이콘 추가하기

<ApiLink type="List" /> 컴포넌트와 함께 다른 컴포넌트를 사용하여 경험을 풍부하게 하고 기능을 추가할 수 있습니다. 이름과 전화번호 값의 왼쪽에 멋진 사진 아바타를 넣을 수 있습니다. 또한 값의 오른쪽에 별 아이콘을 추가하여 사용자가 연락처를 즐겨찾기로 지정할 수 있게 할 수 있습니다. 이를 위해 [**IgxAvatar**](layouts/avatar.mdx) 및 [**IgxIcon**](/layouts/icon) 모듈을 가져와 app.module.ts 파일에서 가져오겠습니다.

```typescript
// app.module.ts

...
import { IgxListModule } from 'igniteui-angular/list';
import { IgxAvatarModule } from 'igniteui-angular/avatar';
import { IgxIconModule } from 'igniteui-angular/icon';
// import { IgxListModule, IgxAvatarModule, IgxIconModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxAvatarModule, IgxIconModule],
})
export class AppModule {}
```

좋습니다. 이제 아바타와 아이콘을 표시하도록 연락처 목록의 템플릿을 업데이트하겠습니다. 이번에도 목록 디렉티브 몇 가지를 사용하면 됩니다.

```html
{/*contacts.component.html*/}

<igx-list>
  <igx-list-item isHeader="true">
    Contacts
  </igx-list-item>
  <igx-list-item #item *ngFor="let contact of contacts;">
      <igx-avatar igxListThumbnail [src]="contact.photo" shape="circle"></igx-avatar>
      <h4 igxListLineTitle>{{ contact.name }}</h4>
      <p igxListLineSubTitle class="phone">{{ contact.phone }}</p>
      <span igxListLine>Lorem ipsum dolor sit amet, consectetur adipisicing elit. Dicta, laborum.</span>
      <igx-icon igxListAction [color]="contact.isFavorite ? 'orange' : 'lightgray'" (click)="toggleFavorite(item)">star</igx-icon>
  </igx-list-item>
</igx-list>
```

<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

- `igxListThumbnail`은(는) 목록 항목의 시작 부분에 어떤 종류의 미디어를 추가해야 할 때 사용합니다. 이 디렉티브는 대상 요소(이 경우 igx-avatar)를 기본 위치와 간격을 제공하는 컨테이너로 감쌉니다.
- `igxListAction`은(는) 스위치, 라디오 버튼, 체크박스 등 동작이나 메타데이터가 있는 목록 항목에 사용합니다. 이 예제에서 동작은 `igx-icon`(으)로 나타납니다. 이 디렉티브 역시 대상 요소를 올바른 위치와 간격을 갖는 컨테이너로 감쌉니다.
- `igxListLine`은(는) `igxListThumbnail`과(와) `igxListAction` 사이에 텍스트가 필요할 때 사용합니다. 이 디렉티브는 텍스트의 위치, 간격, 정렬이 주변의 다른 두 디렉티브와 잘 어울리도록 보장합니다.

다음으로 [**IgxIcon**](/layouts/icon) 컴포넌트의 클릭 이벤트를 수신하여 연락처 객체의 _isFavorite_ 속성을 전환합니다.

```typescript
// contacts.component.ts

...
toggleFavorite(item: IgxListItem) {
    const contact = this.contacts[item.index - 1];
    contact.isFavorite = !contact.isFavorite;
}
```

`--ig-size` CSS 사용자 지정 속성을 사용하여 사용자가 목록의 크기를 선택할 수 있게 하겠습니다. 이를 위해 `IgxButtonGroupModule`을(를) 가져와 [**IgxButtonGroup**](/inputs/button-group)을(를) 사용해 모든 크기 값을 표시합니다. 이렇게 하면 하나가 선택될 때마다 목록의 **size**를 업데이트합니다.

```typescript
// app.module.ts
...
import { IgxButtonGroupModule } from 'igniteui-angular/button-group';
// import { IgxButtonGroupModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    imports: [..., IgxButtonGroupModule]
})
```

```html
{/*contacts.component.html*/}

<igx-buttongroup [values]="sizes" (selected)="selectSize($event)"></igx-buttongroup>
...
<igx-list>
    ...
</igx-list>
```

```typescript
// contacts.component.ts

public size = 'large';
public sizes;

public ngOnInit() {
    this.sizes = [
        { label: 'large', selected: this.size === 'large', togglable: true },
        { label: 'medium', selected: this.size === 'medium', togglable: true },
        { label: 'small', selected: this.size === 'small', togglable: true }
    ];
}

public selectSize(event: any) {
    this.size = this.sizes[event.index].label;
}

@HostBinding('style.--ig-size')
protected get sizeStyle() {
    return `var(--ig-size-${this.size})`;
}
```

### 목록 항목 패닝

이제 연락처와 전화번호가 있는 멋진 Angular 목록이 준비되었으니, 연락처에 전화를 걸 수 있는 기능을 구현해 보겠습니다.
<ApiLink type="List" />에는 이를 위한 완벽한 해결책이 있습니다. 바로 목록 항목 패닝입니다.
이를 구현하려면 다음 단계를 수행해야 합니다:

- <ApiLink type="List" member="allowLeftPanning" label="allowLeftPanning" /> 및/또는 <ApiLink type="List" member="allowRightPanning" label="allowRightPanning" /> 속성을 사용하여 패닝을 활성화합니다.
- 왼쪽 및/또는 오른쪽 패닝에 대한 템플릿을 정의합니다.
- 목록 항목의 패닝 이벤트를 처리하고 원하는 동작을 수행합니다.

다음 예제는 왼쪽과 오른쪽 패닝을 모두 처리하는 방법을 보여 줍니다. 오른쪽 패닝의 이벤트 핸들러는 토스트 메시지를 표시합니다. 왼쪽 패닝의 이벤트 핸들러는 <ApiLink type="List" />에서 항목을 삭제합니다.

<DocsAside type="info">
목록 항목 삭제는 애플리케이션 작업이라는 점에 유의하십시오. <ApiLink type="List" /> 자체는 <ApiLink type="List" />이(가) 데이터 소스에 대한 참조를 가지고 있지 않기 때문에 데이터 소스에서 항목을 삭제할 수 없습니다.
</DocsAside>

다음은 예제의 HTML 코드입니다:

```html
{/* contacts.component.html */}

<igx-list [allowLeftPanning]="true" [allowRightPanning]="true"
  (leftPan)="leftPanPerformed($event)" (rightPan)="rightPanPerformed($event)">
  <ng-template igxListItemLeftPanning>
    <div class="listItemLeftPanningStyle">

      <igx-icon [color]="white" style="margin-left:10px">delete</igx-icon>Delete
    
</div>
  </ng-template>
  <ng-template igxListItemRightPanning>
    <div class="listItemRightPanningStyle">

      <igx-icon [color]="white" style="margin-right:10px">call</igx-icon>Dial
    
</div>
  </ng-template>
  <igx-list-item isHeader="true">Contacts</igx-list-item>
  <igx-list-item #item *ngFor="let contact of contacts">
    <igx-avatar igxListThumbnail [src]="contact.photo" shape="circle"></igx-avatar>
    <h4 igxListLineTitle>{{ contact.name }}</h4>
    <p igxListLineSubTitle class="phone">{{ contact.phone }}</p>
    <igx-icon igxListAction [color]="contact.isFavorite ? 'orange' : 'lightgray'" (click)="toggleFavorite(item)">star</igx-icon>
  </igx-list-item>
</igx-list>

<igx-toast #toast></igx-toast>
```

위 예제는 다음에서 찾을 수 있는 일부 CSS 스타일을 사용합니다:

```css
/* contacts.component.css */

igx-icon {

    user-select: none;
}

.listItemLeftPanningStyle {
    display: flex;
    flex-direction: row-reverse;
    background-color:orange;
    color: white;
    width: 100%;
    padding-right: 10px;
    align-items: center;
}

.listItemRightPanningStyle {
    display: flex;
    flex-direction: row;
    background-color:limegreen;
    color: white;
    width: 100%;
    padding-left: 10px;
    align-items: center;
}
```

마지막으로, 패닝 이벤트를 처리하는 TypeScript 코드는 다음과 같습니다:

```typescript
// contacts.component.ts

...
@ViewChild('toast')
public toast: IgxToastComponent;

public rightPanPerformed(args) {
  args.keepItem = true;
  this.toast.message = 'Dialing ' + this.contacts[args.item.index - 1].name;
  this.toast.open();
}

public leftPanPerformed(args) {
  args.keepItem = false;
  setTimeout((idx = args.item.index - 1) => {
    this.toast.message = 'Contact ' + this.contacts[idx].name + ' removed.';
    this.toast.open();
    this.contacts.splice(idx, 1);
  }, 500);
}

...
```

</DocsAside>

## Angular 필터 목록

목록이 잘 보이지만, 이름으로 연락처를 검색할 수 있다면 더 좋지 않을까요? 필터링 파이프를 사용하면 쉽게 구현할 수 있습니다.
그럼 해 보겠습니다.

먼저 Angular 컴포넌트 템플릿 상단에 입력 필드를 추가하고, 이를 컴포넌트의 _searchContact_ 속성에 바인딩하겠습니다:

```html
{/*contacts.component.html*/}

<igx-input-group type="search" class="search">
    <igx-prefix>
        <igx-icon>search</igx-icon>
    </igx-prefix>
    <input #search igxInput placeholder="Search Contacts" [(ngModel)]="searchContact"/>
    @if (search.value.length > 0) {
        <igx-suffix (click)="searchContact = null">
            <igx-icon>clear</igx-icon>
        </igx-suffix>
    }
</igx-input-group>
```

이제 app.module.ts 파일에서 `IgxFilterModule`과(와) `IgxInputGroupModule`을(를) 가져오고, 연락처 컴포넌트에서 <ApiLink type="FilterOptions" />을(를) 가져와야 합니다:

```typescript
// app.module.ts
...
import { IgxFilterModule } from 'igniteui-angular/directives';
import { IgxInputGroupModule } from 'igniteui-angular/input-group';
// import { IgxFilterModule, IgxInputGroupModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    imports: [..., IgxFilterModule, IgxInputGroupModule]
})

// contacts.component.ts
...
import { IgxFilterOptions } from 'igniteui-angular/directives';
// import { IgxFilterOptions } from '@infragistics/igniteui-angular'; for licensed package

@Component({...})
export class ContactListComponent {
    public searchContact: string;
    ...
    get filterContacts(): IgxFilterOptions {
        const fo = new IgxFilterOptions();
        fo.key = 'name';
        fo.inputValue = this.searchContact;
        return fo;
    }
}
```

<ApiLink type="FilterOptions" />을(를) 가져온 후에는 `searchContact` 속성이 업데이트될 때마다 파이프가 사용할 필터링 옵션을 반환하는 새 getter 메서드를 등록해야 합니다. 필터가 작동하려면 연락처 객체를 필터링할 `key`을(를) 등록해야 합니다. 이 경우에는 각 연락처의 `name`가 됩니다. <ApiLink type="FilterOptions" /> 객체에 등록해야 하는 두 번째 속성은 연락처 이름을 비교할 때 확인할 값입니다. 이것은 위의 연락처 목록 위 입력 필드에 바인딩한 `searchContact` 속성입니다.

마지막으로, 사용하기 전에 연락처 데이터에 필터링 파이프를 적용해야 합니다. 따라서 템플릿에 다음을 추가하면 됩니다:

```html
{/*contacts.component.html*/}

<igx-list-item *ngFor="let contact of contacts | igxFilter: filterContacts; let i = index">
    ...
</igx-list-item>
```

## 목록 항목 선택

목록 항목에는 어떤 항목이 "선택"되었는지 추적하는 데 도움이 되는 `selected` 속성이 있습니다. 이 속성을 사용하면 각 항목의 선택 상태를 식별하고 관리할 수 있습니다.

`selected` 속성을 사용할 때 항목의 시각적 스타일이 어떻게 바뀌는지 보여 주는 예제는 다음과 같습니다:

<Sample src="/lists/list-item-selection" height={420} alt="" />

기본적으로 `selected` 속성은 `false`(으)로 설정되어 있습니다. 각 목록 항목의 `(click)` 이벤트에 바인딩된 인라인 식을 사용하여 이 값을 전환할 수 있으며, 클릭할 때마다 항목의 시각적 상태가 효과적으로 바뀝니다.

```html
<igx-list>
    <igx-list-item [isHeader]="true">Contacts</igx-list-item>
    @for (contact of contacts | igxFilter: filterContacts; track contact) {
      <igx-list-item [selected]="contact.selected" (click)="contact.selected = !contact.selected">
        <igx-avatar igxListThumbnail [src]="contact.photo" shape="circle"></igx-avatar>
        <span igxListLineTitle>{{ contact.name }}</span>
        <span igxListLineSubTitle>{{ contact.phone }}</span>
        <igx-icon igxListAction [style.color]="contact.isFavorite ? 'orange' : 'lightgray'" igxRipple="pink"
          [igxRippleCentered]="true" (click)="toggleFavorite(contact, $event)"
        (mousedown)="mousedown($event)">star</igx-icon>
      </igx-list-item>
    }
  </igx-list>
```

목록 항목은 선택된 요소의 여러 부분을 스타일링하는 데 사용할 수 있는 CSS 변수도 몇 가지 제공합니다:

- `--item-background-selected`
- `--item-text-color-selected`
- `--item-title-color-selected`
- `--item-action-color-selected`
- `--item-subtitle-color-selected`
- `--item-thumbnail-color-selected`

```scss
igx-list-item {
  --item-background-selected: var(--ig-secondary-500);
  --item-title-color-selected: var(--ig-secondary-500-contrast);
  --item-subtitle-color-selected: var(--ig-info-100);
}
```

목록 테마 함수를 사용하고 싶다면, 목록 항목의 선택 상태를 스타일링할 수 있는 매개변수가 있습니다. 이 매개변수에 대한 자세한 내용은 다음에서 확인할 수 있습니다: <ApiLink kind="sass" module="themes" type="function-list-theme" label="list-theme" code={true} />

### Tailwind로 스타일링하기

사용자 지정 Tailwind 유틸리티 클래스를 사용하여 목록의 스타일을 지정할 수 있습니다. 먼저 [Tailwind를 설정](/themes/tailwind)했는지 확인하십시오.

전역 스타일시트에 Tailwind를 가져온 다음, 다음과 같이 원하는 테마 유틸리티를 적용할 수 있습니다:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

유틸리티 파일에는 `light` 및 `dark` 테마 변형이 모두 포함되어 있습니다.

- 밝은 테마에는 `light-*` 클래스를 사용하십시오.
- 어두운 테마에는 `dark-*` 클래스를 사용하십시오.
- 접두사 뒤에 컴포넌트 이름을 붙이십시오. 예: `light-list`, `dark-list`.

적용하면 이 클래스는 동적 테마 계산을 가능하게 합니다. 그런 다음 `arbitrary properties`을 사용하여 생성된 CSS 변수를 재정의할 수 있습니다. 콜론 뒤에는 유효한 CSS 색상 형식(HEX, CSS 변수, RGB 등)을 입력하십시오.

속성의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-list-theme" label="list-theme" />에서 확인할 수 있습니다. 구문은 다음과 같습니다:

```html
<igx-list class="!light-list ![--background:#81B698] ![--item-background:#A3C7B2]">
    ...
</igx-list>
```

<DocsAside type="info">
유틸리티 클래스가 우선 적용되도록 느낌표(`!`)가 필요합니다. Tailwind는 스타일을 계층으로 적용하므로, 이 스타일을 중요(important)로 표시하지 않으면 컴포넌트의 기본 테마에 의해 재정의됩니다.
</DocsAside>
