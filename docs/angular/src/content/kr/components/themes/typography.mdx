# 타이포그래피

<div class="highlight">

Ignite UI for Angular의 타이포그래피는 [Material Type System](https://material.io/design/typography/the-type-system.html#)을 본떠 설계되었습니다. 이는 간섭하지 않으며 선택 사항이므로, CSS만으로도 타입 스타일을 수정할 수 있습니다.
</div>

## 개요

타입 시스템은 대부분의 컴포넌트에서 사용되는 **_13개의 서로 다른 카테고리 타입 스타일_**로 구성된 **_타입 스케일_**입니다. 모든 스케일 카테고리는 완전히 재사용할 수 있으며 최종 사용자가 조정할 수 있습니다.

다음은 Ignite UI for Angular의 Material 테마에 정의된 13개 카테고리 스타일의 전체 목록입니다:

| **스케일 카테고리** | **글꼴 패밀리** | **글꼴 굵기** | **글꼴 크기** | **텍스트 변환** | **자간** | **줄 높이** | **CSS 클래스**               | **CSS 변수**   |
| :----------------- | :-------------- | :-------------- | :------------ | :----------------- | :----------------- | :-------------- | :-------------------------- | :------------------ |
| **h1**             | Titillium Web   | 300             | 6 rem         | 없음               | -.09375 rem        | 7 rem           | `ig-typography__h1`         | `--ig-h1-*`         |
| **h2**             | Titillium Web   | 300             | 3.75 rem      | 없음               | -.0312 rem         | 4.4375 rem      | `ig-typography__h2`         | `--ig-h2-*`         |
| **h3**             | Titillium Web   | 400             | 3 rem         | 없음               | 0                  | 3.5625 rem      | `ig-typography__h3`         | `--ig-h3-*`         |
| **h4**             | Titillium Web   | 400             | 2.125 rem     | 없음               | .015625 rem        | 2.5 rem         | `ig-typography__h4`         | `--ig-h4-*`         |

<igc-divider></igc-divider>

각 테마는 자체 타입 스케일을 정의합니다. 즉, 우리가 제공하는 테마인 Material, Fluent, Bootstrap, Indigo 각각은 자체 타입 스케일을 갖습니다. 이들은 모두 같은 _스케일 카테고리_를 공유하지만, 글꼴 패밀리, 굵기, 크기, 텍스트 변환, 자간, 줄 높이는 서로 다를 수 있습니다.

## 사용법
>
<DocsAside type="info">
기본적으로 우리는 어떤 타이포그래피 스타일도 적용하지 않습니다. 애플리케이션에서 우리 타이포그래피를 사용하려면 최상위 요소에 `ig-typography` CSS 클래스를 설정해야 합니다. 그러면 그 모든 하위 요소가 우리의 타이포그래피 스타일을 사용합니다.
</DocsAside>

Ignite UI for Angular의 Material 테마 기본 글꼴로 [Titillium Web](https://fonts.google.com/selection?selection.family=Titillium+Web:300,400,600,700)을 선택했습니다. 이를 사용하려면 직접 호스팅하거나 Google Fonts에서 가져와야 합니다:

```html
<link
  href="https://fonts.googleapis.com/css?family=Titillium+Web:300,400,600,700"
  rel="stylesheet"
/>
```

body 요소에 `ig-typography` 클래스를 설정하여 타이포그래피 스타일을 활성화하십시오.

```html
{/* index.html */}
<body class="ig-typography">
  <app-root></app-root>
</body>
```

### 글꼴 패밀리 바꾸기

모든 컴포넌트의 글꼴 패밀리를 바꾸려면, `--ig-typography` CSS 변수를 다른 font-family 값으로 덮어쓰기만 하면 됩니다.

```css
/* styles.css */
:root {
    --ig-font-family: "Open Sans", sans-serif;
}
```

## 타입 스타일

타입 스타일은 Ignite UI for Angular의 대부분의 컴포넌트가 내부적으로 사용합니다. 예를 들어 문서에서는 버튼 컴포넌트가 button 타입 스타일을 사용한다고 설명합니다. 즉, 포함된 `--ig-button-*` CSS 변수를 덮어써서 버튼 컴포넌트의 타이포그래피를 수정할 수 있습니다.

Material 테마에서 버튼의 텍스트를 항상 소문자로 바꾸고 싶다고 가정해 보겠습니다.

```css
:root {
    --ig-button-text-transform: lowercase;
}
```
