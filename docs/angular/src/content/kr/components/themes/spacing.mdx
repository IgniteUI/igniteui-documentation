# 간격

간격 구성은 대량의 데이터를 시각적으로 표현하는 방식을 크게 개선할 수 있습니다. Ignite UI for Angular에서는 패딩과 마진을 조정하기 위한 미리 정의된 옵션 집합을 제공합니다.

고정된 값을 사용하는 대신, 우리는 CSS 사용자 지정 속성을 사용하여 애플리케이션 또는 컴포넌트 수준에서 간격을 조정합니다.

## 간격이 작동하는 방식

Ignite UI for Angular는 컴포넌트 크기(작음, 중간, 큼)에 따라 동적으로 조정되는 정교한 간격 시스템을 제공합니다. 간격 시스템은 CSS 사용자 지정 속성을 중심으로 구축되어 있어, 사용자 정의 CSS를 작성하지 않고도 전역 또는 컴포넌트 수준에서 간격을 제어할 수 있습니다.

## 크기와 간격의 관계

Ignite UI의 간격 시스템은 컴포넌트 크기와 밀접하게 연결되어 있습니다. 컴포넌트는 세 가지 서로 다른 크기를 가질 수 있습니다:

- **작음** - 조밀한 레이아웃을 위한 촘촘한 간격
- **중간** - 기본의 균형 잡힌 간격.  
- **큼** - 터치 친화적인 인터페이스를 위한 여유 있는 간격

간격은 활성 크기에 따라 자동으로 조정되므로, 애플리케이션 전체에서 일관된 시각적 계층이 유지됩니다.

## 핵심 CSS 사용자 지정 속성

간격 시스템은 여러 주요 CSS 사용자 지정 속성을 중심으로 돌아갑니다:

### 전역 간격 속성

- `--ig-spacing` - 기본 간격 배수(기본값: 1)
- `--ig-spacing-small` - 작은 크기 컴포넌트의 간격
- `--ig-spacing-medium` - 중간 크기 컴포넌트의 간격입니다.  
- `--ig-spacing-large` - 큰 크기 컴포넌트의 간격

### 방향별 간격 속성

- `--ig-spacing-inline` - 가로 간격을 제어합니다
- `--ig-spacing-block` - 세로 간격을 제어합니다
- `--ig-spacing-inline-small` - 작은 컴포넌트의 가로 간격
- `--ig-spacing-inline-medium` - 중간 컴포넌트의 가로 간격
- `--ig-spacing-inline-large` - 큰 컴포넌트의 가로 간격
- `--ig-spacing-block-small` - 작은 컴포넌트의 세로 간격
- `--ig-spacing-block-medium` - 중간 컴포넌트의 세로 간격
- `--ig-spacing-block-large` - 큰 컴포넌트의 세로 간격

## 크기 감지 변수

컴포넌트는 CSS 사용자 지정 속성을 사용하여 현재 크기를 자동으로 감지합니다:

- `--is-small` - 컴포넌트가 작은 크기이면 1로, 그렇지 않으면 0으로 설정됩니다.
- `--is-medium` - 컴포넌트가 중간 크기이면 1로, 그렇지 않으면 0으로 설정됩니다  
- `--is-large` - 컴포넌트 크기가 large이면 1, 그렇지 않으면 0으로 설정됩니다.
- `--component-size` - 현재 크기를 나타내는 숫자 값입니다(1=작음, 2=중간, 3=큼).

이 변수들은 테마 시스템이 자동으로 관리하며, `--ig-size`(으)로 제어되는 컴포넌트의 크기 설정에 따라 바뀝니다.

## 실제 사용 예제

### 전역 간격 제어

애플리케이션 전체에서 모든 컴포넌트를 더 조밀하게 만들려면:

```css
:root {
  --ig-spacing: 0.8; /* 20% less spacing */
}
```

터치 접근성을 높이기 위해 간격을 늘리려면:

```css
:root {
  --ig-spacing: 1.2; /* 20% more spacing */
}
```

### 컴포넌트별 간격

특정 컴포넌트 유형의 간격을 조정하려면:

```css
.my-grid {
  --ig-spacing: 0.5; /* More compact grid, 50% of the original spacing in all sizes */
}
```

### 방향별 간격 제어

세로 간격은 정상으로 유지하면서 가로 간격만 줄이려면:

```css
:root {
  --ig-spacing-inline: 0.7;
  --ig-spacing-block: 1.0;
}
```

### 크기별 간격

특정 컴포넌트 크기에 대해 간격을 사용자 지정하려면:

```css
:root {
  --ig-spacing-small: 0.5;   /* Very tight for small components */
  --ig-spacing-medium: 1.0;  /* Normal for medium components */
  --ig-spacing-large: 1.5;   /* Extra spacious for large components */
}
```

## 간격 배수가 작동하는 방식

간격 시스템은 배수를 사용하여 기본 값을 조정합니다:

- 컴포넌트의 간격 값은 활성 간격 변수에 곱해집니다
- 예를 들어 컴포넌트에 기본 패딩이 `8px`이고 `--ig-spacing: 1.5`을(를) 설정하면, 실제 패딩은 `12px`이 됩니다
- `--ig-spacing-large`과 같은 크기별 배수는 큰 크기 컴포넌트에 대해 전역 `--ig-spacing`을(를) 재정의합니다
- `--ig-spacing-inline`과 같은 방향별 배수를 사용하면 가로 간격과 세로 간격을 각각 독립적으로 조정할 수 있습니다

이 캐스케이드 방식은 일관된 간격 관계를 보장하면서도, CSS 사용자 지정 속성만으로 세밀한 제어를 제공합니다.
