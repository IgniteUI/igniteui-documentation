# Sass로 팔레트 사용하기

Ignite UI for Angular Sass 팔레트는 `palette()` 함수가 시드 색상에서 생성하고 `palette()` 믹스인이 CSS 변수로 내보내는 색상 음영의 맵입니다.

## 개요

Ignite UI for Angular 팔레트는 색상 계열을 키로 하는 [Sass 맵](https://sass-lang.com/documentation/values/maps)입니다: `primary`, `secondary`, `gray`, `surface`, `info`, `success`, `warn` 및 `error`. 각 계열은 음영들의 맵이며, 모든 컴포넌트 테마는 `--ig-*` CSS 변수를 통해 이 음영들에서 색상을 읽습니다.

`palette()` 함수는 시드 색상으로부터 전체 맵을 만듭니다. 기본 `fitted` 생성기를 사용하면 각 계열에는 다음 변형이 포함됩니다:

| 계열 | 변형 |
|---|---|
| `primary`, `secondary`, `info`, `success`, `warn`, `error` | `50`–`900`, `A100`, `A200`, `A400`, `A700`, `seed` |
| `gray` | `50`–`900`, `seed` |
| `surface` | `base`, `sunken`, `raised`, `overlay`, `container`, `seed` |

모든 변형에는 일치하는 `-contrast` 변형이 있습니다. 예를 들어 `500-contrast`처럼, 이는 그 음영과의 대비를 읽을 수 있도록 브라우저가 결정한 검정 또는 흰색입니다. `primary` 색상은 보통 브랜드 색상이며 `igx-navbar`와 같은 눈에 띄는 정적 요소의 스타일을 지정합니다. `secondary`는 버튼, 스위치, 슬라이더와 같이 동작을 수행하는 요소의 스타일을 지정합니다. `surface`은(는) 카드, 메뉴, 선택기와 같은 컴포넌트의 배경입니다.

음영이 어떻게 배치되는지, 그리고 `surface` 계열이 숫자가 아닌 역할을 가지는 이유를 이해하려면 [팔레트 생성](../palette-generation.mdx)을 참조하십시오.

## 팔레트 생성하기

필수 시드 세 개, 즉 `$primary`, `$secondary`, `$surface`를 사용하여 `palette()`을(를) 호출한 다음, 그 결과를 `palette()` 믹스인에 전달하여 CSS 변수로 내보내십시오:

```scss
@use "igniteui-angular/theming" as *;

$brand-palette: palette(
  $primary: #0099ff,
  $secondary: #df1b74,
  $surface: #ffffff
);

:root {
  @include palette($brand-palette);
}
```

선택적 시드는 `$gray`, `$info`(`#1377d5`), `$success`(`#4eb862`), `$warn`(`#faa419`) 및 `$error`(`#ff134a`)입니다. `theme()` 믹스인은 `palette()` 믹스인을 자동으로 포함하므로, 팔레트를 단독으로 내보낼 때, 예를 들어 두 번째 팔레트를 클래스에 범위 지정하는 경우에만 직접 포함하면 됩니다.

<DocsAside type="warning">
`palette()`에 전달하는 모든 시드는 **Sass 색상이어야 합니다**. 팔레트는 빌드 시점에 계산되므로 CSS 변수는 인수로 전달할 수 없습니다.
</DocsAside>

`palette()` 믹스인은 `-contrast` 색상을 선택할 때 기준이 되는 WCAG 수준도 설정합니다. `$contrast-level`을(를) `'a'`, `'aa'`(기본값) 또는 `'aaa'`과 함께 전달하십시오:

```scss
:root {
  @include palette($brand-palette, $contrast-level: 'aaa');
}
```

`fitted` 생성기를 사용하면 모든 음영이 고정 색상으로 내보내집니다:

```css
:root {
  --ig-primary-100: rgb(172, 207, 251);
  --ig-primary-500: rgb(9, 109, 183);
  --ig-primary-600: rgb(6, 89, 150);
  --ig-primary-seed: #0099ff;
  --ig-surface-base: rgb(255, 255, 255);
  --ig-surface-sunken: rgb(247, 247, 247);
  /* ... */
}
```

음영이 고정되어 있으므로, CSS에서 이 변수 중 하나를 재정의하면 그 음영만 바뀝니다. 계열 전체를 바꾸려면 시드를 바꾸고 다시 빌드하십시오.

## 척도

척도는 계열의 음영이 얼마나 넓게 퍼지고 어떻게 간격을 두는지 설정합니다. 기본값을 바꾸려면 `$scales`을(를) `palette()`에 전달하십시오: 모든 계열에는 `even`, `gray`에는 `material`.

한 계열에 프리셋 이름을 지정하거나, 모든 계열에 프리셋 하나를 전달하십시오:

```scss
// The grays follow IBM Carbon's rhythm; every other family keeps its default
$brand-palette: palette(#0099ff, #df1b74, #ffffff, $scales: ('gray': 'carbon'));

// Every family uses the tailwind preset
$brand-palette: palette(#0099ff, #df1b74, #ffffff, $scales: 'tailwind');
```

프리셋은 `even`, `material`, `tailwind` 및 `carbon`입니다. [팔레트 생성](../palette-generation.mdx#scale-shapes)에서 이들을 비교합니다.

다음 키로 척도를 인라인으로 설명하십시오:

| 키 | 값 | 효과 |
|---|---|---|
| `range` | `1.1 14`과 같은 두 대비 비율 | 음영 `50`과 음영 `900`의 대비입니다. 기본값은 `even` 범위인 `1.182 18.232`입니다. |
| `curve` | `0.5 0 0.8 0.8`과 같은 네 개의 숫자 | 범위를 따라 음영을 재배치합니다. CSS `cubic-bezier()`처럼 읽습니다. 균등 간격이면 생략하십시오. |
| `anchor` | `'surface'` 또는 `'white'` | `gray` 범위를 측정하는 기준입니다. 기본값은 `'surface'`입니다. 다른 계열은 항상 흰색을 기준으로 측정합니다. |

```scss
$brand-palette: palette(
  #0099ff,
  #df1b74,
  #121212,
  $scales: (
    'primary': (range: 1.1 14, curve: 0.5 0 0.8 0.8),
    'gray': (range: 1.1 14, anchor: 'white')
  )
);
```

네 개의 숫자만 있는 목록은 `even` 범위에 대한 곡선으로 읽힙니다. 사용자 지정 범위나 곡선은 음영 사이의 대비를 바꿉니다. 하나를 바꾼 후에는 사용하는 쌍의 대비를 확인하십시오.

## 생성기

`palette()` 함수에는 두 가지 생성기가 있습니다. 기본값인 `fitted`는 각 음영을 대비 목표에 맞게 계산합니다. `legacy`는 시드를 `500`에 놓고 고정된 HSL 승수로 다른 음영을 도출하며, 이는 `500`의 CSS 상대 색상으로 내보내집니다:

```css
:root {
  --ig-primary-500: #0099ff;
  --ig-primary-600: hsl(from var(--ig-primary-500) h calc(s * 1.26) calc(l * 0.89));
}
```

`$generator`와 함께 한 팔레트에 `legacy` 생성기를 유지하거나, 라이브러리를 로드하기 전에 `$shade-generator`를 구성하여 빌드 안의 모든 `palette()` 호출에 적용하십시오:

```scss
// One palette
$brand-palette: palette(#0099ff, #df1b74, #ffffff, $generator: 'legacy');
```

```scss
// Every palette() call in the build
@use "igniteui-theming" with ($shade-generator: 'legacy');
@use "igniteui-angular/theming" as *;
```

`legacy` 팔레트는 `$scales` 인수를 무시합니다.

## 사전 정의된 팔레트

Ignite UI for Angular는 일치하는 스키마와 짝을 이루는 사전 정의된 밝은 팔레트와 어두운 팔레트를 제공합니다:

- 밝은 팔레트
  - `$light-material-palette`
  - `$light-fluent-excel-palette`
  - `$light-fluent-word-palette`
  - `$light-fluent-palette`
  - `$light-bootstrap-palette`
  - `$light-indigo-palette`
- 어두운 팔레트
  - `$dark-material-palette`
  - `$dark-fluent-excel-palette`
  - `$dark-fluent-word-palette`
  - `$dark-fluent-palette`
  - `$dark-bootstrap-palette`
  - `$dark-indigo-palette`

밝은 팔레트는 밝은 스키마와, 어두운 팔레트는 어두운 스키마와 조합하십시오. 사전 정의된 팔레트는 `legacy` 생성기로 만들어지므로, 그중 하나를 기반으로 한 테마는 상대 색상 음영을 유지하며 `500` 변형의 실행 중 재정의에 반응합니다.

## 회색조 색상

`gray` 계열은 대부분의 텍스트, 테두리, 비활성 색상을 제공하며, 그 음영은 표면을 기준으로 설정됩니다. 회색을 만드는 색상을 선택하려면 `$gray`을(를) 전달하십시오:

```scss
$brand-palette: palette(
  $primary: #2ab759,
  $secondary: #f96a88,
  $surface: #222222,
  $gray: #ffffff
);
```

`$gray`을(를) 생략하면 회색 시드는 밝은 표면에서는 검정, 어두운 표면에서는 흰색입니다. 기본 `material` 척도에서는 음영 `50`이 흰색 또는 거의 검정에 가까운 표면과 가장 가까운 회색이고, `900`가 그것에서 가장 먼 회색입니다. 회색 척도의 앵커가 어두운 테마에 어떤 영향을 주는지는 [회색과 페이지](../palette-generation.mdx#grays-and-the-page)를 참조하십시오.

## 색상 변형

`color()` 함수는 팔레트의 음영을 반환합니다. 최대 네 개의 인수를 받습니다: `$palette`, `$color`, `$variant` 및 `$opacity`.

```scss
// A reference to the CSS variable: var(--ig-primary-500)
$primary-500: color();

// var(--ig-primary-600)
$primary-600: color($variant: 600);

// The primary 600 shade at 50% opacity, as a CSS relative color
$primary-600-translucent: color($variant: 600, $opacity: 0.5);

// The surface's raised role: var(--ig-surface-raised)
$raised: color($color: 'surface', $variant: 'raised');

// The resolved color of the secondary A700 shade in $brand-palette
$secondary-a700: color($brand-palette, 'secondary', 'A700');

.panel {
  background: $raised;
  border-color: $primary-600;
}
```

`$palette`이(가) 없으면 `color()`는 CSS 변수에 대한 참조를 반환하므로, 값은 실행 중에 내보내지는 팔레트를 따릅니다. `$palette`이(가) 있으면 그 맵에서 해석된 색상을 반환합니다. `$color`의 기본값은 `primary`이고, `$variant`의 기본값은 `500`이며, `$color`가 `surface`이면 `base`이 기본값입니다.

## 대비 텍스트 색상

`contrast-color()` 함수는 음영의 대비 색상을 반환하며, `color()`와 같은 인수를 받습니다:

```scss
.callout {
  background: color($color: 'primary', $variant: 600);
  color: contrast-color($color: 'primary', $variant: 600);
}
```

결과는 `palette()` 믹스인이 설정한 대비 수준에서 브라우저가 검정 또는 흰색으로 해석하는 CSS 상대 색상입니다.

## 색상 클래스

`color-classes()` 믹스인은 팔레트의 모든 음영에 대해 CSS 클래스를 생성하고, 선택한 CSS 속성에 할당합니다:

- `$prop` - 색상을 할당할 CSS 속성입니다.
- `$prefix` - 생성되는 클래스 이름의 접두사입니다. 기본값은 `'igx'`입니다.
- `$suffix` - 생성되는 클래스 이름의 접미사입니다.
- `$palette` - 사용할 팔레트입니다.

```scss
@include color-classes(
  $prop: 'background-color',
  $prefix: 'bg'
);
```

`primary`의 `500` 음영은 `.bg-primary-500` 클래스가 됩니다:

```html
<div class="bg-primary-500">...</div>
```

## 사용자 지정 팔레트 맵

컴포넌트 테마는 팔레트 맵의 형태만 읽으므로, 테마가 읽는 키를 갖추고 있다면 직접 작성한 맵도 작동합니다. 숫자 변형을 포함하여 모든 키를 따옴표로 묶고, `surface`에 역할을 지정하십시오:

```scss
$handmade-palette: (
  'primary': (
    '50': #e6eff8,
    '50-contrast': black,
    // ... '100' through '900', then 'A100', 'A200', 'A400', 'A700', each with a '-contrast' entry
    '500': #6797de,
    '500-contrast': white,
  ),
  // 'secondary', 'gray', 'info', 'success', 'warn', and 'error' follow the same pattern
  'surface': (
    'base': #ffffff,
    'base-contrast': black,
    'sunken': #f7f7f7,
    'sunken-contrast': black,
    'raised': #ffffff,
    'raised-contrast': black,
    'overlay': #ffffff,
    'overlay-contrast': black,
    'container': rgba(0, 0, 0, 0.03),
    'container-contrast': black,
  ),
);
```

Ignite UI for Angular 22.3.0 컴포넌트 테마는 색상 계열의 번호가 매겨진 음영과, `gray`의 음영, `primary` 및 `secondary`의 강조 음영, 그리고 `base` 표면 역할을 읽습니다. 다른 표면 역할은 여러분 자신의 스타일을 위해 존재합니다. 나머지를 읽는 스타일도 여전히 해석되도록, [개요](#개요)에 나열된 모든 변형을 포함하십시오.

## 문제 해결

**`--ig-primary-500`을(를) 재정의해도 다른 기본 음영이 업데이트되지 않는 이유는 무엇입니까?** `fitted` 생성기로 생성된 팔레트는 고정 색상을 내보냅니다. `palette()`에 전달하는 시드를 바꾸고 다시 빌드하거나, `500`에서 실행 중 도출을 유지하려면 `$generator: 'legacy'`로 팔레트를 생성하십시오.

**`--ig-surface-500` 또는 `color($color: 'surface', $variant: 500)`에 대한 참조를 어떻게 이전합니까?** 번호가 매겨진 표면 음영은 역할로 대체되어 더 이상 권장되지 않습니다. 모든 팔레트는 여전히 이를 내보내므로, 이전하는 동안 참조는 계속 작동합니다. 페이지 또는 컴포넌트 배경에는 `base`를, 그 위의 레이어에는 `raised` 또는 `overlay`을, 그 안에 설정되는 레이어에는 `sunken`을, 반투명한 채우기에는 `container`을 사용하십시오. `color($color: 'surface')`는 이미 `base`을(를) 반환합니다.

**빌드에서 `Shade "gray-900" wanted 18.232:1 but its hue only reaches …`이(가) 출력되는 이유는 무엇입니까?** 척도가 색상과 그 앵커가 허용하는 것보다 더 많은 대비를 요구하기 때문입니다. 일반적으로 어두운 표면에서 표면에 고정된 회색 척도가 그런 경우입니다. 생성기는 도달할 수 있었던 가장 가까운 음영을 사용했습니다. `range`의 상단을 낮추거나 `anchor: 'white'`을(를) 설정하십시오.
