# Material에서 Fluent 테마로 전환하기

버전 `8.2`부터 우리 컴포넌트에는 [`Microsoft Fluent Design System`](https://www.microsoft.com/design/fluent/)에서 영감을 받은 새 테마가 포함되어 있습니다

`Material`에서 `Fluent`(으)로 전환하려면 내장된 <ApiLink kind="sass" module="themes" type="mixin-theme" label="theme" /> 믹스인을 사용할 수 있습니다.

Word 및 Excel 팔레트도 지원합니다. 사용하려면 두 개의 _**밝은**_ 맵 `$light-fluent-excel-palette`, `$light-fluent-word-palette` 중 하나 또는 두 개의 _**어두운**_ 맵 `dark-fluent-excel-palette`, `$light-fluent-word-palette` 중 하나를 `theme` 믹스인에 전달하기만 하면 됩니다:

## Fluent 밝은 테마

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
@include core();
@include theme(
  $palette: $light-fluent-palette, 
  $schema: $light-fluent-schema
);

// We can also include the Indigo font and font scaling
@include typography(
  $font-family: $fluent-typeface,
  $type-scale: $fluent-type-scale
);
```

## Fluent 어두운 테마

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
@include core();
@include theme(
  $palette: $dark-fluent-palette, 
  $schema: $dark-fluent-schema
);

@include typography(
  $font-family: $fluent-typeface,
  $type-scale: $fluent-type-scale
);
```
