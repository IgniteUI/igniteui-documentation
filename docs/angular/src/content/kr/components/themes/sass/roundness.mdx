# 둥근 정도

<div class="highlight">
Ignite UI for Angular에서는 컴포넌트의 둥근 정도를 0과 1 사이의 값으로 설정하여 컴포넌트의 모양을 바꿀 수 있습니다.
</div>
<igc-divider></igc-divider>

## 개요

border radius는 컴포넌트의 [테마 스키마](https://github.com/IgniteUI/igniteui-theming/blob/18f878033898e1b6a3bb0ed28993e9a4037d1a80/sass/themes/schemas/components/light/_toast.scss#L44)에 정의됩니다(아래 예제 참조). 이 방식으로 정의된 모든 컴포넌트의 border radius는 <ApiLink kind="sass" module="themes" type="mixin-theme" label="theme" /> 믹스인의 `$roundness` 매개변수나 `--ig-radius-factor`라는 단일 CSS 변수를 통해 제어할 수 있습니다.

```scss
$light-toast: extend(
    $default-elevation-toast,
    (
        ...,
        border-radius: (
            border-radius: (
                rem(26px),
                rem(0),
                rem(26px),
            ),
        ),
    )
);
```

예제에서 볼 수 있듯이, <ApiLink kind="sass" module="themes" type="function-toast-theme" label="Toast" />의 컴포넌트 스키마는 border radius를 세 값의 목록으로 정의합니다. 첫 번째 값은 기본 border radius입니다(즉, `$roundness` 또는 `--ig-radius-factor`가 선언되지 않았을 때). 두 번째 값은 허용되는 최소 border radius입니다(즉, `$roundness` 또는 `--ig-radius-factor`가 `0`(으)로 설정되었을 때). 세 번째 값은 허용되는 최대 border radius입니다(즉, `$roundness` 또는 `--ig-radius-factor`이 `1`(으)로 설정되었을 때). toast 컴포넌트에서는 기본값과 최대값이 같습니다. `$roundness` 또는 `--ig-radius factor`에 할당된 0과 1 사이의 모든 값은 toast의 border radius를 최대값의 백분율로 설정합니다. 예를 들어 값을 `.5`(으)로 설정하면 Toast 컴포넌트의 border radius는 허용되는 최대 border radius의 50%, 즉 13픽셀이 됩니다.

```scss
// Make all components sharp by setting the roundness parameter to 0.
@include theme(
    ...,
    $roundness: 0
);
```

### 사용 방법?

위 예제에서 toast의 기본값을 바꾸는 방법을 살펴보겠습니다.

결과 테마에서 toast가 여전히 `$roundness` 또는 `--ig-radius-factor` 변수의 영향을 받기를 원한다면, Ignite UI for Angular 패키지가 제공하는 `border-radius` 함수를 사용하십시오.

```scss
// Change the default, min and max values,
// while preserving customization via $roundness or --ig-radius-factor.
igx-toast {
  --border-radius: #{border-radius(rem(4px), rem(4px), rem(16px))};
}
```

`--ig-radius-factor`의 변경에 영향을 받지 않는 고정된 값을 border-radius로 원한다면, border-radius 매개변수에 직접 전달하면 됩니다.

```scss
// Will be unaffected by changes to $roundess or --ig-radius-factor.
igx-toast {
  --border-radius: rem(4px);
}
```

`border-radius` 믹스인을 사용하여 요소에 border-radius 속성을 직접 할당할 수도 있습니다.

```scss
button {
    @include border-radius(rem(4px), rem(4px), rem(16px));
}
```

이제 버튼의 `border-radius`은(는) `$roundness` 및 `--ig-radius-factor` 변수의 영향을 받습니다.

### 기준 border radius 값

아래 표는 Material 스키마에 정의된 일부 컴포넌트의 border radius 값 발췌입니다.

| **컴포넌트**         | **최소/최대 반경** | **기본 반경** |
| :-------------------- | :----------------- | :----------------- |
| **Button(Flat)**      |  0 / 20px          | 4px                |
| **Button(Contained)** |  0 / 20px          | 4px                |
| **button(Fab)**       |  12px / 28px       | 28px               |
| **button(Icon)**      |  0 / 18px          | 18px               |
| **Button-group**      |  0 / 20px          | 4px                |
| **Chip**              |  0 / 20px          | 4px                |
| **Card**              |  0 / 24px          | 4px                |
| **Carousel**          |  0 / 36px          | 0                  |
| **Dialog**            |  0 / 36px          | 4px                |
| **Drop-down**         |  0 / 20px          | 4px                |
| **Expansion panel**   |  0 / 16px          | 0                  |
| **input(Border)**     |  0 / 20px          | 4px                |
| **input(Box)**        |  0 / 20px          | 4px 4px 0 0        |
| **input(Search)**     |  0 / 20px          | 4px                |
| **List**              |  0 / 24px          | 0                  |
| **List item**         |  0 / 24px          | 0                  |
| **Navdrawer**         |  0 / 36px          | 0                  |
| **Snackbar**          |  0 / 24px          | 4px                |
| **Tooltip**           |  0 / 16px          | 4px                |
| **Toast**             |  0 / 26px          | 26px               |

각 컴포넌트의 기본 및 최소/최대 반경 값을 확인하려면 각 컴포넌트의 <ApiLink kind="sass" module="schemas" label="Schema" /> 문서를 참조하십시오.
