## 전역 변수

주 테마 모듈에서 전달되는 전역 Sass 변수의 목록은 다음과 같습니다:

|    변수 이름  |                                                      설명        |
| :---------------: | :---------------------------------------------------------------------: |
|    `$components`  |       모든 컴포넌트 테마의 레지스터를 저장합니다. 트리 셰이킹에 사용됩니다. |
| `$dropped-themes` |            제외된 테마의 레지스터를 저장합니다. 트리 셰이킹에 사용됩니다.  |

## 스크롤바 스타일 지정

Ignite UI for Angular 테마에는 애플리케이션의 모든 스크롤바의 너비 및/또는 색상을 바꿀 수 있는 사용자 지정 스크롤바 스타일이 포함되어 있습니다. 포함된 스타일을 적용하려면 루트 앱 컴포넌트를 담고 있는 요소에 `ig-scrollbar` 클래스를 설정했는지 확인하십시오.

스크롤바를 더 사용자 지정하려면 <ApiLink kind="sass" module="themes" type="function-scrollbar-theme" label="scrollbar-theme" code={true} /> 함수로 새 스크롤바 스타일을 만들 수 있습니다. 이 함수는 스크롤바의 스타일 변경을 위한 인수를 받습니다. 스크롤바의 크기, 색상, 테두리, min-height 등을 비롯해 그 밖에도 많은 것을 사용자 지정할 수 있습니다.

```scss
// app.component.scss
// Here we set the scrollbar to have size of 16px, scrollbar thumb to be in color pink, and scrolblar track to be in color green
$my-scrollbar-theme: scrollbar-theme($sb-size: 16px, $sb-thumb-bg-color: pink, $sb-track-bg-color: green);

// We use 'tokens' mixin for generating the css variables with the new scrollbar values.

:host {
  @include tokens($my-scrollbar-theme);
}
```
