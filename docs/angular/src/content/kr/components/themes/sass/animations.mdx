## Sass 애니메이션

### Keyframes 믹스인

Ignite UI for Angular의 <ApiLink kind="sass" module="animations" type="mixin-keyframes" label="keyframes" /> 믹스인은 새 keyframes 애니메이션을 등록하는 데 사용됩니다. 이 믹스인은 keyframes 애니메이션의 이름을 매개변수로 받아 전역 keyframe 등록 목록에 추가합니다. 이렇게 하면 같은 keyframes 애니메이션을 여러 번 포함하더라도 내보낸 CSS에 keyframes가 중복되지 않습니다.

예를 들어 다음과 같이 하면:

```scss
@include fade-in();
@include fade-in();
```

생성된 CSS에는 하나의 `@keyframes` 규칙만 추가됩니다:

```css
@keyframes fade-in { ... }
```

애니메이션 단계를 위한 keyframes 선택기와 keyframes의 CSS 스타일은 믹스인의 본문 안에 정의됩니다.

다음은 우리의 `animation` 믹스인과 함께 사용할 수 있는 새 애니메이션 믹스인을 만드는 예제입니다.

```scss
@mixin fade-in-bottom {
    @include keyframes(fade-in-bottom) {
        0% {
            transform: translateY(50px);
            opacity: 0;
        }

        100% {
            transform: translateY(0);
            opacity: 1;
        }
    }
} 
```

<hr/>

### 애니메이션 믹스인

<ApiLink kind="sass" module="animations" type="mixin-animation" label="animation" /> 믹스인은 매개변수로 전달된 애니메이션 속성 목록을 사용하여 요소를 애니메이션하는 그릇 역할을 합니다. 사용자는 `name`, `duration`, `delay`, `direction`, `iteration count` 등과 같은 애니메이션 속성을 지정할 수 있습니다. `animation` 믹스인에는 여러 keyframe 애니메이션을 전달할 수 있습니다.

```scss
//include the 'fade-in-top' keyframes animation mixin
@include fade-in-top();

//include the animation mixin with parameters
.my-class {
    @include animation('fade-in-top' 3s $ease-out-quad infinite);
}
```

### 사용법

Ignite UI for Angular 애니메이션은 시각 효과에 따라 8개의 범주로 묶여 있습니다 - `fade`, `flip`, `grow`, `miscellaneous`, `rotate`, `scale`, `slide` 및 `swing`. 각 그룹은 서로 다른 매개변수 집합을 받으며, 이를 통해 포함된 애니메이션의 동작을 수정할 수 있습니다. 각 애니메이션은 Angular가 제공하는 [`animation`](https://angular.io/api/animations/animation) 함수가 생성하는 [`AnimationReferenceMetadata`](https://angular.io/api/animations/AnimationReferenceMetadata) 객체입니다.

매개변수가 첨부되어 있으면 기본값으로 작동합니다. [`useAnimation`](https://angular.io/api/animations/useAnimation) 함수를 통해 애니메이션을 호출할 때, 매개변수 값을 직접 전달할 수 있습니다. 전달된 매개변수 값 중 하나라도 빠져 있다면, 기본값이 사용됩니다.

``` typescript
import { transition, trigger, useAnimation } from '@angular/animations';
import { fadeIn, fadeOut } from "igniteui-angular/animations/main";

animations: [
    trigger('fadeInOut', [
            transition('void => *', [
                useAnimation(fadeIn, {
                    params: {
                        duration: '.35s',
                        easing: 'ease-out'
                    }
                })
            ]),
            transition('* => void', [
                useAnimation(fadeOut, {
                    params: {
                        duration: '.2s',
                        easing: 'ease-out'
                    }
                })
            ])
        ])
]
```

### 타이밍 함수

Ignite UI for Angular에는 애니메이션을 점점 빠르게 또는 느리게 전환하는 데 사용할 수 있는 타이밍 함수 집합이 포함되어 있습니다. 주요 타이밍 함수 그룹은 세 가지인 `EaseIn`, `EaseOut`, `EaseInOut`이며, 각각 다음 타이밍을 포함합니다:

- quad
- cubic
- quart
- quint
- sine
- expo
- circ
- back

특정 타이밍 함수를 사용하려면 먼저 가져오십시오:

``` typescript
import { EaseOut } from "igniteui-angular/animations/easings";
```

그런 다음 어떤 애니메이션의 easing 매개변수 값으로도 사용하십시오:

``` typescript
useAnimation(fadeIn, {
    params: {
        easing: EaseOut.back
    }
});
```
