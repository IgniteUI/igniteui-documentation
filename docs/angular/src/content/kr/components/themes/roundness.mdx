# 둥근 정도

Ignite UI for Angular에서는 0과 1 사이의 값을 사용하여 둥근 정도를 조정함으로써 컴포넌트의 모양을 사용자 지정할 수 있습니다.

## 개요

많은 Ignite UI 컴포넌트에는 미리 정의된 최소 및 최대 border-radius 값이 있으며, 이는 `--ig-radius-factor` CSS 변수를 사용하여 조정할 수 있습니다.

`--ig-radius-factor`을(를) 0으로 설정하면 컴포넌트는 최소 border-radius를 사용하며, 모서리가 날카로운 더 블록 같은 모양으로 나타납니다. 1로 설정하면 컴포넌트는 미리 정의된 최대 border-radius를 사용하며, 둥글게 나타납니다.

`--ig-radius-factor` 변수를 사용하여 수정할 수 있는, 미리 정의된 최소 및 최대 border-radius 값을 가진 컴포넌트 목록은 다음과 같습니다: <br/>

## 사용법

컴포넌트의 두 border-radius 값 사이를 전환하려면, 요소 선택기를 대상으로 하고 `--ig-radius-factor` 변수를 0 또는 1 중 하나로 설정하기만 하면 됩니다:

```css
igx-chip {
   --ig-radius-factor: 0;
}
```

이렇게 하면 미리 정의된 최소 border-radius가 적용되어, [Chip](/inputs/chip) 컴포넌트의 모서리가 직선이 됩니다.

```css
igx-chip {
    --ig-radius-factor: 1;
}
```

값을 1로 설정하면 미리 정의된 최대 border-radius가 적용되어, [Chip](/inputs/chip) 컴포넌트의 모서리가 둥글어집니다.

border-radius가 정의된 최소값과 최대값 사이의 어딘가에 있기를 원한다면, `--ig-radius-factor` 변수를 0과 1 사이의 소수 값으로 설정할 수 있습니다.
예를 들어 `0.5`(으)로 설정하면 컴포넌트에서 허용되는 최대 값의 50%에 해당하는 border-radius가 적용됩니다.

```css
igx-chip {
    --ig-radius-factor: 0.5;
}
```
