# Angular Layout Manager 디렉티브 개요

<div class="highlight">
Ignite UI for Angular 레이아웃 디렉티브를 사용하면 개발자는 디렉티브가 적용된 컨테이너의 모든 자식에 대해 레이아웃 방향을 지정할 수 있습니다. 레이아웃은 세로 또는 가로로 흐를 수 있으며, 줄바꿈, 정렬, 맞춤을 위한 컨트롤을 제공합니다.
</div>

## 사용법

컨테이너 요소에 <ApiLink type="LayoutDirective" label="**igxLayout**" /> 디렉티브를 사용하여 자식의 레이아웃 방향을 지정하십시오:

<hr/>

### Row 방향으로 가로 배치

<ApiLink type="LayoutDirective" member="dir" label="igxLayoutDir" />`="row"`을(를) 사용하십시오.

<Sample src="/layouts/layout-direction-row" height={180} alt="" />

<hr/>

### Column 방향으로 세로 배치

<ApiLink type="LayoutDirective" member="dir" label="igxLayoutDir" />`="column"`을(를) 사용하십시오.

<Sample src="/layouts/layout-direction-column" height={300} alt="" />

<hr/>

<DocsAside type="info">
<ApiLink type="LayoutDirective" member="reverse" label="igxLayoutReverse" />`="true"`을(를) 사용하여 순서를 뒤집으십시오.
</DocsAside>

<hr/>

### 요소의 순서 사용자 지정하기

`igxFlexOrder`을(를) 사용하여 요소의 순서를 사용자 지정하십시오.

<Sample src="/layouts/layout-custom-order" height={110} alt="" />

<hr/>

### 요소 간격 바꾸기

<ApiLink type="LayoutDirective" member="justify" label="igxLayoutJustify" />`="space-between | space-around"`을(를) 사용하십시오.

<Sample src="/layouts/layout-content-space" height={180} alt="" />

<hr/>

### 주축을 따라 요소 배치하기

<ApiLink type="LayoutDirective" member="justify" label="igxLayoutJustify" />`="flex-start | center | flex-end"`을(를) 사용하여 주축을 따라 요소의 위치를 원하는 대로 지정하십시오.

<Sample src="/layouts/layout-justify-content" height={180} alt="" />

<hr/>

### 교차축을 따라 요소 배치하기

<ApiLink type="LayoutDirective" member="itemalign" label="itemAlign" />`="flex-start | center | flex-end"`을(를) 사용하여 교차축을 따라 요소의 위치를 원하는 대로 지정하십시오.

<Sample src="/layouts/layout-align-items" height={400} alt="" />

<hr/>

### 요소를 감쌀 수도 있습니다

<ApiLink type="LayoutDirective" member="wrap" label="igxLayoutWrap" />`="wrap"`을(를) 사용하십시오.

<Sample src="/layouts/layout-wrap" height={180} alt="" />

<DocsAside type="info">
<ApiLink type="LayoutDirective" label="igxLayout" /> 디렉티브는 그에 대한 흐름 방향에 영향을 줍니다
</DocsAside>
컨테이너의 **직접** 자식에게 적용됩니다.
<hr/>

## 중첩

<ApiLink type="LayoutDirective" label="igxLayout" /> 상위 안의 요소에 대해 <ApiLink type="FlexDirective" label="igxFlex" /> 디렉티브를 사용하여 특정 flexbox 속성을 제어하십시오.
