# Angular Tree 컴포넌트 개요

Angular Tree 컴포넌트를 사용하면 사용자는 부모-자식 관계를 가진 트리 뷰 구조로 계층형 데이터를 표현할 수 있으며, 대응하는 데이터 모델 없이 정적인 트리 뷰 구조를 정의할 수도 있습니다. 주요 목적은 최종 사용자가 계층형 데이터 구조를 시각화하고 그 안에서 탐색할 수 있게 하는 것입니다. Ignite UI for Angular Tree 컴포넌트는 필요 시 로드 기능, 항목 활성화, 내장 체크박스를 통한 이중 상태 및 삼중 상태 연쇄 선택, 내장 키보드 탐색 등도 제공합니다.

## Ignite UI for Angular Tree 시작하기

Ignite UI for Angular Tree 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 app.module 파일에서 `IgxTreeModule`을(를) 가져오는 것입니다.

```typescript
// app.module.ts

...
import { IgxTreeModule } from 'igniteui-angular/tree';
// import { IgxTreeModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxTreeModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxTreeComponent`을 독립형(standalone) 종속성으로 가져올 수 있으며, [`IGX_TREE_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/tree/src/tree/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수도 있습니다.

```typescript
// home.component.ts

import { IGX_TREE_DIRECTIVES } from 'igniteui-angular/tree';
// import { IGX_TREE_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

            Web Component Libraries

            <igx-tree-node>Open UI 5</igx-tree-node>
        </igx-tree-node>
        <igx-tree-node>
            Blazor Libraries
            <igx-tree-node>Ignite UI for Blazor</igx-tree-node>
        </igx-tree-node>
    </igx-tree>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_TREE_DIRECTIVES]
    /* or imports: [IgxTreeComponent, IgxTreeNodeComponent] */
})
export class HomeComponent {}
```

## Angular Tree 사용하기

<ApiLink type="TreeNode" />은(는) <ApiLink type="Tree" />에 속한 모든 노드를 나타냅니다.  
노드는 <ApiLink type="TreeNode" member="disabled" label="disabled" />, <ApiLink type="TreeNode" member="active" label="active" />, <ApiLink type="TreeNode" member="selected" label="selected" /> 및 <ApiLink type="TreeNode" member="expanded" label="expanded" /> 속성을 제공하며, 이를 통해 요구 사항에 따라 노드의 상태를 구성할 수 있습니다.
<ApiLink type="TreeNode" member="data" label="data" /> 속성을 사용하여 노드가 나타내는 데이터 항목에 대한 참조를 추가할 수 있습니다. <ApiLink type="Tree" member="findNodes" label="IgxTreeComponent.findNodes()" />을(를) 사용하여 노드를 검색하려면 `[data]`을(를) 바인딩해야 합니다.

### 트리 선언하기

노드는 다음 방법 중 하나를 사용하여 선언할 수 있습니다.

- 노드 계층 구조를 지정하고 데이터 집합을 반복하여 트리와 그 노드를 선언하기

```html
<igx-tree>
 <igx-tree-node *ngFor="let node of data" [data]="node" [expanded]="isNodeExpaded(node)" [selected]="isNodeSelected(node)">
  {{ node.text }}
  <img [src]="node.image" [alt]="node.imageAlt" />
  <igx-tree-node *ngFor="let child of node.children" [data]="child" [expanded]="isNodeExpaded(child)" [selected]="isNodeSelected(child)">
            {{ child.text }}
  </igx-tree-node>
 </igx-tree-node>
</igx-tree>
```

노드를 데이터 모델에 바인딩하면, 펼쳐진 상태와 선택된 상태도 기본 데이터에 반영될 수 있습니다.

```html
<igx-tree (nodeSelection)="handleSelectionEvent($event)">
 <igx-tree-node *ngFor="let node of data" [data]="node" [(expanded)]="node.expanded" [(selected)]="node.selected">
  {{ node.text }}
  <img [src]="node.image" [alt]="node.imageAlt" />
  <igx-tree-node *ngFor="let child of node.children" [data]="child">
   <a igxTreeNodeLink [href]="child.url" target="_blank">
                {{ child.text }}
            </a>
  </igx-tree-node>
 </igx-tree-node>
</igx-tree>
```

- 바인딩되지 않은 정적 노드를 만들어 트리 선언하기

트리를 렌더링하기 위해 반드시 데이터 집합이 필요한 것은 아닙니다. 기본 데이터 모델 없이도 개별 노드를 만들 수 있습니다:

```html
<igx-tree>
 <igx-tree-node [expanded]="true" [selected]="false">
  I am a parent node 1
  <img src="hard_coded_src.webb" alt="Alt Text" />  
  <igx-tree-node [expanded]="true" [selected]="false">
   I am a child node 1
   <igx-tree-node>
    <a igxTreeNodeLink href="https://google.com" target="_blank">
        I am a child node of the child
    </a>
   </igx-tree-node>
  </igx-tree-node>
 </igx-tree-node>

 <igx-tree-node [expanded]="false" [selected]="false">
  I am a parent node 2
  <img src="hard_coded_src.webb" alt="Alt Text" />
        <igx-tree-node [expanded]="false" [selected]="false">
   I am a child node 1
  </igx-tree-node>
 </igx-tree-node>

    <igx-tree-node [selected]="false" [disabled]="true">
  I am a parent node 3
 </igx-tree-node>
</igx-tree>
```

### 링크가 있는 노드

노드가 링크를 렌더링해야 할 때는 `<a>` 태그에 `IgxTreeNodeLink` 디렉티브를 추가해야 합니다. 이렇게 하면 노드의 DOM 요소에 올바른 aria 역할이 할당됩니다.

```html
<igx-tree>
 <igx-tree-node *ngFor="let node of data" [data]="node" [expanded]="isNodeExpaded(node)" [selected]="isNodeSelected(node)">
  {{ node.text }}
  <img [src]="node.image" [alt]="node.imageAlt" />
  <igx-tree-node *ngFor="let child of node.children" [data]="child">
            <a igxTreeNodeLink [href]="child.url" target="_blank">
                {{ child.text }}
            </a>
  </igx-tree-node>
 </igx-tree-node>
</igx-tree>
```

### 노드 상호 작용

<ApiLink type="TreeNode" />은(는) 다음과 같이 펼치거나 접을 수 있습니다:

- 노드의 펼침 표시기를 클릭하면 _(기본 동작)_.
- `igx-tree` <ApiLink type="Tree" member="toggleNodeOnClick" label="toggleNodeOnClick" /> 속성이 `true`(으)로 설정된 경우 노드를 클릭하면.

```html
<igx-tree [toggleNodeOnClick]="true">
 <igx-tree-node *ngFor="let node of data" [data]="node">
  {{ node.text }}
  <igx-tree-node *ngFor="let child of node.children" [data]="child">
                {{ child.text }}
  </igx-tree-node>
 </igx-tree-node>
</igx-tree>
```

기본적으로 여러 노드를 동시에 펼칠 수 있습니다. 이 동작을 바꾸어 한 번에 하나의 가지만 펼칠 수 있게 하려면 <ApiLink type="Tree" member="singleBranchExpand" label="singleBranchExpand" /> 속성을 활성화할 수 있습니다. 이렇게 하면 노드를 펼칠 때, 같은 수준에 이미 펼쳐져 있던 다른 모든 가지가 접힙니다.

```html
<igx-tree [singleBranchExpand]="true">
 <igx-tree-node *ngFor="let node of data" [data]="node">
  {{ node.text }}
  <igx-tree-node *ngFor="let child of node.children" [data]="child">
                {{ child.text }}
  </igx-tree-node>
 </igx-tree-node>
</igx-tree>
```

또한 IgxTree는 노드 상호 작용을 위해 다음 API 메서드를 제공합니다:

- <ApiLink type="TreeNode" member="expand" label="**expand**" /> - 애니메이션과 함께 노드를 펼칩니다.
- <ApiLink type="TreeNode" member="collapse" label="**collapse**" /> - 애니메이션과 함께 노드를 접습니다.
- <ApiLink type="TreeNode" member="toggle" label="**toggle**" /> - 애니메이션과 함께 노드의 펼침 상태를 전환합니다.
- <ApiLink type="Tree" member="collapseAll" label="**collapseAll**" /> - 애니메이션과 함께 지정된 노드를 접습니다. 노드를 전달하지 않으면 모든 상위 노드를 접습니다.
- <ApiLink type="Tree" member="expandAll" label="**expandAll**" /> - 애니메이션과 함께 지정된 노드를 펼친 상태로 설정합니다. 노드를 전달하지 않으면 모든 상위 노드를 펼칩니다.
- <ApiLink type="Tree" member="deselectAll" label="**deselectAll**" /> - 모든 노드의 선택을 해제합니다. 노드 배열을 전달하면 지정된 노드의 선택만 해제합니다. nodeSelection 이벤트를 발생시키지 않습니다.

### 노드 찾기

<ApiLink type="Tree" member="findNodes" label="findNodes" /> 메서드를 사용하면 IgxTree 안에서 특정 노드를 찾을 수 있습니다. 이 메서드는 지정된 데이터와 일치하는 노드들의 배열을 반환합니다.
복합 기본 키와 같은 더 복잡한 데이터 구조 시나리오에서 노드를 찾을 때는, 데이터를 기준으로 노드를 찾는 조건을 지정하기 위해 사용자 지정 비교 함수를 전달할 수 있습니다.

```html
<igx-tree>
 <igx-tree-node *ngFor="let node of data" [data]="node" [expanded]="isNodeExpaded(node)" [selected]="isNodeSelected(node)">
  {{ node.text }}
  <img [src]="node.image" alt="node.imageAlt" />
  <igx-tree-node *ngFor="let child of node.children" [data]="child" [expanded]="isNodeExpaded(child)" [selected]="isNodeSelected(child)">
            {{ child.text }}
  </igx-tree-node>
 </igx-tree-node>
</igx-tree>
```

```typescript
export class MyTreeViewComponent {
  public data: { [key: string]: any, valueKey: string } = MY_DATA;
  @ViewChild(IgxTreeComponent, { read: IgxTreeComponent })
  public tree;

  findNode(valueKey: string) {
    const comparer: IgxTreeSearchResolver =
      (data: any, node: IgxTreeNodeComponent) => node.data.valueKey === data;
    const matchingNodes: IgxTreeNode<{ [key: string]: any, valueKey: string }>[] = this.tree.findNodes(valueKey, comparer);
  }
}
```

```html
        <div class="node-header company">

            <igx-icon class="company__logo">{{ data.Logo }}</igx-icon>
            <div class="company__name">
{{ data.CompanyName }}
</div>

</div>
    </ng-template>

```

또한 <ApiLink type="Tree" member="expandIndicator" label="expandIndicator" /> 입력을 사용하면 노드의 펼침/접힘 표시기를 렌더링하는 데 사용할 사용자 지정 템플릿을 설정할 수 있습니다.

```html
<igx-tree>
    <igx-tree-node *ngFor="let node of data" [data]="node">
    </igx-tree-node>

```

## Angular Tree 선택

`igx-tree`에서 노드 선택을 설정하려면 <ApiLink type="Tree" member="selection" label="selection" /> 속성을 설정하기만 하면 됩니다. 이 속성은 다음 세 가지 모드를 받습니다: **None**, **BiState** 및 **Cascading**. 아래에서 각 모드를 더 자세히 살펴보겠습니다.

### None

`igx-tree`에서는 기본적으로 노드 선택이 비활성화되어 있습니다. 사용자는 UI 상호 작용을 통해 노드를 선택하거나 선택 해제할 수 없지만, 이러한 작업은 제공된 API 메서드를 통해 여전히 수행할 수 있습니다.

### Bi-State

`igx-tree`에서 이중 상태 노드 선택을 활성화하려면 <ApiLink type="Tree" member="selection" label="selection" /> 속성을 **BiState**로 설정하기만 하면 됩니다. 그러면 모든 노드에 체크박스가 렌더링됩니다. 각 노드에는 두 가지 상태, 즉 선택됨 또는 선택되지 않음이 있습니다. 이 모드는 다중 선택을 지원합니다.

```html
<igx-tree selection="BiState">
</igx-tree>
```

### Cascading

`igx-tree`에서 연쇄 노드 선택을 활성화하려면 선택 속성을 **Cascading**으로 설정하기만 하면 됩니다. 그러면 모든 노드에 체크박스가 렌더링됩니다.

```html
<igx-tree selection="Cascading">
</igx-tree>
```

이 모드에서 부모의 선택 상태는 전적으로 자식들의 선택 상태에 따라 달라집니다. 부모에 선택된 자식과 선택되지 않은 자식이 함께 있으면, 그 부모의 체크박스는 불확정 상태가 됩니다.

### Angular Tree 체크박스

Angular Tree 컴포넌트는 체크박스를 기본 지원하여, 사용자가 둘 이상의 항목을 선택할 수 있게 합니다.

TreeView 체크박스에는 부분적으로 선택된 상위 노드에만 적용되는 삼중 상태 모드도 있습니다. 이 모드에서는 자식 노드 중 일부만 체크되어 있을 때 상위 노드가 불확정 상태가 됩니다.

## 키보드 탐색

IgxTree의 키보드 탐색은 사용자에게 다양한 키보드 상호 작용을 제공합니다. 이 기능은 기본적으로 활성화되어 있으며, 사용자가 노드 사이를 이동할 수 있게 합니다.

IgxTree 탐색은 W3C 접근성 표준을 준수하며 사용하기 편리합니다.

**키 조합**

- <kbd>Arrow Down</kbd> - 다음으로 보이는 노드로 이동합니다. 노드를 활성 상태로 표시합니다. 마지막 노드에서는 아무 동작도 하지 않습니다
- <kbd>Ctrl + Arrow Down</kbd> - 다음으로 보이는 노드로 이동합니다. 마지막 노드에서는 아무 동작도 하지 않습니다
- <kbd>Arrow Up</kbd> - 이전으로 보이는 노드로 이동합니다. 노드를 활성 상태로 표시합니다. 첫 번째 노드에서는 아무 동작도 하지 않습니다
- <kbd>Ctrl + Arrow Up</kbd> - 이전으로 보이는 노드로 이동합니다. 첫 번째 노드에서는 아무 동작도 하지 않습니다
- <kbd>Arrow Left</kbd> - 펼쳐진 상위 노드에서는 그 노드를 접습니다. 하위 노드에 있다면 그 상위 노드로 이동합니다.
- <kbd>Arrow Right</kbd> - 펼쳐진 상위 노드에서는 그 노드의 첫 번째 자식으로 이동합니다. 접힌 상위 노드에 있다면 그 노드를 펼칩니다.
- <kbd>Home</kbd> - 첫 번째 노드로 이동합니다
- <kbd>End</kbd> - 마지막으로 보이는 노드로 이동합니다
- <kbd>Tab</kbd> - 트리 바깥의 페이지에서 다음 포커스 가능한 요소로 이동합니다
- <kbd>Shift + Tab</kbd> - 트리 바깥의 페이지에서 이전 포커스 가능한 요소로 이동합니다
- <kbd>Space</kbd> - 현재 노드의 선택을 전환합니다. 노드를 활성 상태로 표시합니다.
- <kbd>Shift + Space</kbd> - 선택이 활성화되어 있다면, Shift를 누른 상태에서 Space를 누르는 대상과 활성 노드 사이에 있는 모든 노드의 선택을 전환합니다
- <kbd>Enter</kbd> - 포커스된 노드를 활성화합니다. 노드에 링크가 있으면 그 링크를 엽니다
- <kbd>*</kbd> - 노드와 같은 수준의 모든 형제 노드를 펼칩니다

선택이 활성화되어 있을 때, 최종 사용자의 노드 선택은 렌더링된 체크박스를 통해서만 허용됩니다. 두 선택 유형 모두 다중 선택을 허용하므로, 다음과 같은 마우스 + 키보드 상호 작용을 사용할 수 있습니다:

- <kbd>클릭</kbd> - 노드 체크박스에서 수행하면, 선택이 활성화되어 있을 경우 노드의 선택을 전환합니다. 그렇지 않으면 노드에 포커스를 둡니다
- <kbd>Shift + 클릭</kbd> - 노드 체크박스에서 수행하면, 선택이 활성화되어 있을 경우 Shift를 누른 상태에서 활성 노드와 클릭한 노드 사이에 있는 모든 노드의 선택을 전환합니다

## Angular Tree 필요 시 로드

Ignite UI for Angular IgxTree는 사용자가 최대한 빨리 볼 수 있도록, 서버에서 최소한의 데이터만 가져오는 방식으로 렌더링할 수 있습니다. 이 동적 데이터 로딩 방식에서는 사용자가 노드를 펼친 후에만 해당 상위 노드의 자식들이 가져와집니다. 필요 시 로드(Load on Demand)라고도 알려진 이 메커니즘은 어떤 원격 데이터와도 쉽게 작동하도록 구성할 수 있습니다.

### Tree 테마 속성 맵

기본 속성을 수정하면, 관련된 모든 종속 속성이 변경 사항을 반영하도록 자동으로 업데이트됩니다:


| 기본 속성 | 종속 속성 | 설명 |
| --- | --- | --- |
| **$background** | $foreground | 트리 노드 콘텐츠에 사용되는 색상입니다. |
|  | $background-selected | 선택된 트리 노드에 사용되는 배경 색상입니다. |
|  | $hover-color | 마우스 오버 시 트리 노드에 사용되는 배경 색상입니다. |
|  | $background-active | 활성 트리 노드에 사용되는 배경 색상입니다. |
|  | $background-disabled | 비활성 상태의 트리 노드에 사용되는 배경 색상입니다. |
| **$background-selected** | $foreground-selected | 선택된 트리 노드의 콘텐츠에 사용되는 색상입니다. |
|  | $hover-selected-color | 마우스 오버 시 선택된 트리 노드에 사용되는 배경 색상입니다. |
| **$background-active** | $foreground-active | 활성 트리 노드의 콘텐츠에 사용되는 색상입니다. |
|  | $background-active-selected | 활성 상태이면서 선택된 트리 노드에 사용되는 배경 색상입니다. |
| **$background-active-selected** | $foreground-active-selected | 활성 상태이면서 선택된 트리 노드의 콘텐츠에 사용되는 색상입니다. |
| **$background-disabled** | $foreground-disabled | 비활성 상태의 트리 노드 콘텐츠에 사용되는 색상입니다. |

[Ignite UI for Angular 테마 기능](/themes)을 사용하면 트리의 모양을 크게 바꿀 수 있습니다. 먼저 테마 엔진이 제공하는 함수를 사용하려면 스타일 파일에서 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-tree-theme" label="tree-theme" />을(를) 확장하고 `$background` 매개변수만 제공하는 새 테마를 만듭니다. 테마가 나머지 필요한 색상을 자동으로 계산합니다. 물론 다른 속성 중 어느 것이든 재정의할 수 있습니다:

```scss
$custom-tree-theme: tree-theme(
  $background: #ecaa53,
);
```

마지막 단계는 컴포넌트의 테마를 포함하는 것입니다.

```scss
:host {
  @include tokens($custom-tree-theme);
}
```

### Tailwind로 스타일링하기

사용자 지정 Tailwind 유틸리티 클래스를 사용하여 트리의 스타일을 지정할 수 있습니다. 먼저 [Tailwind를 설정](/themes/tailwind)했는지 확인하십시오.

전역 스타일시트에서 Tailwind를 가져오는 것과 함께, 다음과 같이 원하는 테마 유틸리티를 적용할 수 있습니다:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

유틸리티 파일에는 `light` 및 `dark` 테마 변형이 모두 포함되어 있습니다.

- 밝은 테마에는 `light-*` 클래스를 사용하십시오.
- 어두운 테마에는 `dark-*` 클래스를 사용하십시오.
- 접두사 뒤에 컴포넌트 이름을 붙이십시오. 예: `light-tree`, `dark-tree`.

적용되면 이 클래스들은 동적 테마 계산을 가능하게 합니다. 그런 다음 `arbitrary properties`을(를) 사용하여 생성된 CSS 변수를 재정의할 수 있습니다. 콜론 뒤에는 유효한 CSS 색상 형식(HEX, CSS 변수, RGB 등)을 지정하십시오.

속성의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-tree-theme" label="IgxTree 테마" />에서 확인할 수 있습니다. 구문은 다음과 같습니다:

```html
<igx-tree class="tree-root">
    @for (type of data; track type) {
      <igx-tree-node class="!light-tree ![--background:#81B698]">
        {{ type.Name }}
        @for (value of type.Children; track value) {
          <igx-tree-node class="!light-tree ![--background:#81B698]">
            {{ value.Name }}
          </igx-tree-node>
        }
      </igx-tree-node>
    }
</igx-tree>
```

<DocsAside type="info">
유틸리티 클래스가 우선 적용되도록 느낌표(`!`)가 필요합니다. Tailwind는 스타일을 계층으로 적용하므로, 이 스타일을 중요(important)로 표시하지 않으면 컴포넌트의 기본 테마에 의해 재정의됩니다.
</DocsAside>

## 알려진 문제와 제한 사항

|제한 사항|설명|
|--- |--- |
| 재귀 템플릿 노드 | `igx-tree`은(는) 템플릿을 통해 igx-tree-nodes를 재귀적으로 만드는 것을 지원하지 않습니다. [자세히 알아보기](https://github.com/IgniteUI/igniteui-angular/wiki/Tree-Specification#assumptions-and-limitations). 모든 노드는 수동으로 선언해야 하므로, 매우 깊은 계층을 시각화하려면 템플릿 파일의 크기에 영향을 줍니다. 트리는 주로 레이아웃/탐색 컴포넌트로 사용하도록 만들어졌습니다. 깊이가 여러 단계이고 데이터가 동종인 계층형 데이터 소스를 시각화해야 한다면 [**IgxTreeGrid**](/treegrid/tree-grid)를 사용할 수 있습니다|
|이전 View Engine(Ivy 이전)에서 IgxTreeNodes 사용하기|Angular의 View Engine(Ivy 이전)에는 tsconfig.json에 `enableIvy: false`이(가) 설정되어 있으면 트리를 사용하지 못하게 하는 문제가 있습니다|
|FireFox에서의 Tab 탐색|트리에 스크롤바가 있을 때 키보드 탐색으로 트리에 Tab 키로 들어가면, 먼저 igx-tree-node 요소에 포커스가 갑니다. 이는 FireFox의 기본 동작이지만, 트리에 명시적인 `tabIndex = -1`을(를) 설정하면 해결할 수 있습니다.|
