# Ignite UI for Angular의 호환성 변경

이 항목은 Ignite UI for Angular의 호환성 변경 사항과 이전 코드를 최신 API에 맞게 업데이트하는 방법에 대한 정보를 제공합니다.

## 재설계된 차트 기본값

<DocsAside type="info">
다음 패키지와 컴포넌트에서 이 호환성 변경 사항은 버전 **11.2.0**에서 도입되었습니다:
</DocsAside>

- 모든 종류의 차트/시리즈가 브러시/채우기 및 외곽선에 새 색상을 사용합니다

| 이전 시리즈 브러시 외곽선 | 새 시리즈 외곽선 브러시 |
| :-------------------------- | :------------------------- |
| `Color_001=#7446B9`         | `Color_001=#8bdc5c`        |
| `Color_002=#9FB328`         | `Color_002=#8b5bb1`        |
| `Color_003=#F96232`         | `Color_003=#6db1ff`        |
| `Color_004=#2E9CA6`         | `Color_004=#f8a15f`        |
| `Color_005=#DC3F76`         | `Color_005=#ee5879`        |
| `Color_006=#FF9800`         | `Color_006=#735656`        |
| `Color_007=#3F51B5`         | `Color_007=#f7d262`        |
| `Color_008=#439C47`         | `Color_008=#8ce7d9`        |
| `Color_009=#795548`         | `Color_009=#e051a9`        |
| `Color_010=#9A9A9A`         | `Color_010=#a8a8b7`        |

- 모든 종류의 차트/시리즈가 두께 2px의 마커 외곽선을 가집니다

- Bar/Column/Waterfall 시리즈는 두께 1px의 외곽선을 가집니다(다른 시리즈는 두께 2px)

- Bar/Column/Waterfall 시리즈는 이제 둥근 모서리 대신 각진 모서리를 가집니다

- Point/Bubble/ScatterSeries/PolarScatter 시리즈의 마커는 70% 투명한 채우기를 가집니다

- Point/Bubble/ScatterSeries/PolarScatter 시리즈의 마커는 마커 외곽선과 일치하는 채우기를 가집니다. 이 시리즈에 대해 이전 스타일 동작으로 되돌리려면, 시리즈에 새 속성 `MarkerFillMode`이(가) 추가되었으며 이를 normal로 설정하면 이전 동작을 재현할 수 있습니다.

- Scatter High Density 시리즈는 min/max 열 속성에 새 색상을 사용합니다

| 이전 열 최소 색상 | 새 열 최소 색상 |
| :----------------- | :----------------- |
| `#FF7446B9`        | `#ff8b5bb1`        |

| 이전 열 최대 색상 | 새 열 최대 색상 |
| :----------------- | :----------------- |
| `#FFC62828`        | `#ffee5879`        |

- Financial/Waterfall 시리즈는 시각 요소의 음수 채우기에 새 색상을 사용합니다

| 이전 음수 브러시 | 새 음수 브러시 |
| :----------------- | :----------------- |
| `#FFC62828`        | `#ffee5879`        |

## 변경된 import 문

가져오기 문이 API 클래스와 열거형의 전체 경로 대신 패키지 이름만 사용하도록 간소화되었습니다.

<DocsAside type="info">
다음 패키지와 컴포넌트에서 이 호환성 변경 사항은 버전 **8.2.12**에서 도입되었습니다:
</DocsAside>

| 영향을 받는 패키지                                                                                                              | 영향을 받는 컴포넌트                                                                                         |
| :----------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------- |
| <a href="https://www.npmjs.com/package/igniteui-angular-excel/v/8.2.12" target="_blank">igniteui-angular-excel</a>             | [Excel 라이브러리](./excel-library.mdx)                                                                           |
| <a href="https://www.npmjs.com/package/igniteui-angular-spreadsheet/v/8.2.12" target="_blank">igniteui-angular-spreadsheet</a> | [Spreadsheet](./spreadsheet-overview.mdx)                                                                      |
| <a href="https://www.npmjs.com/package/igniteui-angular-maps/v/8.2.12" target="_blank">igniteui-angular-maps</a>               | [Geo Map](./geo-map.mdx), [Treemap](./charts/types/treemap-chart.mdx)                                             |
| <a href="https://www.npmjs.com/package/igniteui-angular-gauges/v/8.2.12" target="_blank">igniteui-angular-gauges</a>           | [Bullet Graph](./bullet-graph.mdx), [Linear Gauge](./linear-gauge.mdx), [Radial Gauge](./radial-gauge.mdx)           |
| <a href="https://www.npmjs.com/package/igniteui-angular-charts/v/8.2.12" target="_blank">igniteui-angular-charts</a>           | Category Chart, Data Chart, Donut Chart, Financial Chart], Pie Chart, [Zoom Slider](./zoomslider-overview.mdx) |
| <a href="https://www.npmjs.com/package/igniteui-angular-core/v/8.2.12" target="_blank">igniteui-angular-core</a>               | 모든 클래스와 열거형                                                                                       |

## 변경 후 코드

이제 API 클래스와 열거형의 전체 경로 대신 패키지 이름만 사용해야 합니다.

또한 Data Grid 컴포넌트와 해당 모듈의 이름도 변경되었다는 점에 유의하십시오.

```ts
// gauges:
import { IgxLinearGauge } from "igniteui-angular-gauges";
import { IgxLinearGaugeModule } from "igniteui-angular-gauges";
import { IgxLinearGraphRange } from "igniteui-angular-gauges";

import { IgxRadialGauge } from 'igniteui-angular-gauges}';
import { IgxRadialGaugeModule } from 'igniteui-angular-gauges';
import { IgxRadialGaugeRange } from 'igniteui-angular-gauges';
import { SweepDirection } from 'igniteui-angular-core';

// charts:
import { IgxFinancialChartComponent } from "igniteui-angular-charts";
import { IgxFinancialChartModule } from "igniteui-angular-charts";
import { IgxDataChartComponent } from "igniteui-angular-charts";
import { IgxDataChartCoreModule } from "igniteui-angular-charts";

// maps:
import { IgxGeographicMapComponent } from "igniteui-angular-maps";
import { IgxGeographicMapModule } from "igniteui-angular-maps";
```

## 변경 전 코드

```ts
import { IgxLinearGaugeModule } from 'igniteui-webcomponents-gauges/ES5/igx-linear-gauge-module';
import { IgxLinearGraphRange } from 'igniteui-webcomponents-gauges/ES5/igx-linear-graph-range';

import { IgxRadialGaugeComponent } from "igniteui-webcomponents-gauges/ES5/igx-radial-gauge-component";
import { IgxRadialGaugeModule } from "igniteui-webcomponents-gauges/ES5/igx-radial-gauge-module";
import { IgxRadialGaugeRange } from "igniteui-webcomponents-gauges/ES5/igx-radial-gauge-range";
import { SweepDirection } from "igniteui-webcomponents-core/ES5/SweepDirection";

// charts:
import { IgxFinancialChartComponent } from "igniteui-webcomponents-charts/ES5/igx-financial-chart-component";
import { IgxFinancialChartModule } from "igniteui-webcomponents-charts/ES5/igx-financial-chart-module";
import { IgxDataChartComponent } from "igniteui-webcomponents-charts/ES5/igx-data-chart-component";
import { IgxDataChartCoreModule } from "igniteui-webcomponents-charts/ES5/igx-data-chart-core-module";

// maps:
import { IgxGeographicMapComponent } from "igniteui-webcomponents-maps/ES5/igx-geographic-map-component";
import { IgxGeographicMapModule } from "igniteui-webcomponents-maps/ES5/igx-geographic-map-module";
```
