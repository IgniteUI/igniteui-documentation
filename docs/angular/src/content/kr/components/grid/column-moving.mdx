# Grid 열 순서 변경 및 이동

Ignite UI for Angular의 Grid 컴포넌트는 표준 마우스 끌어서 놓기 또는 터치 제스처를 통해, 또는 열 이동 API를 사용하여 열 순서를 바꿀 수 있도록 **열 이동** 기능을 제공합니다. 열 이동은 고정된 열과 고정되지 않은 열 모두에서, 그리고 다중 열 머리글과 함께 작동합니다. 열을 고정 영역으로 옮기면 그 열이 고정되고, 그 반대로 고정 영역 밖으로 옮기면 고정이 해제됩니다.

<DocsAside type="info">
열과 열 그룹 사이의 순서 변경은 두 항목이 계층에서 같은 수준에 있고 둘 다 같은 그룹 안에 있을 때만 허용됩니다. 열/열 그룹 사이의 이동은 최상위 수준의 열이라면 허용됩니다.
</DocsAside>

<DocsAside type="info">
열 머리글이 템플릿화되어 있고 열 이동이 활성화되어 있거나 해당 열이 그룹화 가능하다면, 템플릿 요소의 **draggable** 속성을 **false**로 설정해야 합니다! 이렇게 해야 요소가 발생시키는 모든 이벤트에 핸들러를 연결할 수 있으며, 그렇지 않으면 이벤트가 `igxDrag` 디렉티브에 의해 소비됩니다.
</DocsAside>

<DocsAside type="info">
고정 영역이 최대 허용 너비(전체 Grid 너비의 80%)를 초과하면, 시각적 단서로 최종 사용자에게 드롭 작업이 허용되지 않으며 고정할 수 없다는 것을 알려 줍니다. 즉, 고정 영역에 열을 드롭할 수 없습니다.
</DocsAside>

```html
<ng-template igxHeader>
    <igx-icon [attr.draggable]="false" (click)="onClick()"></igx-icon>
</ng-template>
```

## 개요

**열 이동** 기능은 그리드 단위로 활성화되므로, <ApiLink type="Grid" />은(는) 이동 가능한 열과 이동 불가능한 열을 모두 가질 수 있습니다. 이는 <ApiLink type="Grid" label="igx-grid" />의 <ApiLink type="Grid" member="moving" label="moving" /> 입력을 통해 설정합니다.

```html
<igx-grid [moving]="true"></igx-grid>
```

## API

끌어서 놓기 기능 외에도, 열 이동 기능은 열을 프로그래밍 방식으로 이동하거나 열 순서를 바꾸는 두 가지 API 메서드를 제공합니다:

<ApiLink type="Grid" member="moveColumn" label="moveColumn" /> - 열을 다른 열(대상) 앞이나 뒤로 이동합니다. 첫 번째 매개변수는 이동할 열이고, 두 번째 매개변수는 대상 열입니다. 또한 선택적인 세 번째 매개변수 `position`(<ApiLink type="DropPosition" kind="enum" /> 값을 나타냄)를 받으며, 이는 열을 대상 열 앞에 둘지 뒤에 둘지를 결정합니다.

```typescript
// Move the ID column after the Name column
const idColumn = grid.getColumnByName("ID");
const nameColumn = grid.getColumnByName("Name");

grid.moveColumn(idColumn, nameColumn, DropPosition.AfterDropTarget);
```

<ApiLink type="Column" member="move" label="move" /> - 열을 지정된 보이는 인덱스로 이동합니다. 전달된 인덱스 매개변수가 잘못되었거나(음수이거나 열 개수를 초과하는 경우), 열이 이 인덱스로 이동하는 것이 허용되지 않는 경우(다른 그룹 안인 경우), 아무 작업도 수행되지 않습니다.

```typescript
// Move the ID column at 3rd position.
const idColumn = grid.getColumnByName("ID");
idColumn.move(3);
```

API를 사용할 때는 작업이 성공한 경우에만 <ApiLink type="Grid" member="columnMovingEnd" label="columnMovingEnd" /> 이벤트가 발생한다는 점에 유의하십시오. 또한 끌어서 놓기 기능과 비교하면, API를 사용할 때는 `moving` 속성을 true로 설정할 필요가 없습니다.

## 이벤트

열 이동과 관련된 이벤트가 여러 개 있으며, 이를 통해 열의 끌어서 놓기 작업에 접근할 수 있습니다. 이 이벤트들은 <ApiLink type="Grid" member="columnMovingStart" label="columnMovingStart" />, <ApiLink type="Grid" member="columnMoving" label="columnMoving" /> 및 <ApiLink type="Grid" member="columnMovingEnd" label="columnMovingEnd" />입니다.
열이 새 위치에 놓일 때 사용자 지정 로직을 구현하려면 <ApiLink type="Grid" />의 <ApiLink type="Grid" member="columnMovingEnd" label="columnMovingEnd" /> 이벤트를 구독할 수 있습니다. 예를 들어 Change On Year(%) 열 뒤에 Category를 놓는 작업을 취소할 수 있습니다.

```html
<igx-grid #dataGrid [data]="data" [autoGenerate]="false" [moving]="true" (columnMovingEnd)="onColumnMovingEnd($event)">
    <igx-column [field]="'Category'"></igx-column>
    <igx-column [field]="'Change On Year(%)'" [dataType]="'number'" ></igx-column>
</igx-grid>
```

```typescript
public onColumnMovingEnd(event) {
    if (event.source.field === "Category" && event.target.field === "Change On Year(%)") {
        event.cancel = true;
    }
}
```

## 스타일링

Grid 열 이동 머리글의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />을(를) 확장하고 `$ghost-header-background`, `$ghost-header-text-color` 및 `$ghost-header-icon-color` 매개변수를 받는 새 테마를 만듭니다.

```scss
// Define dark theme for the column moving
$dark-grid-column-moving-theme: grid-theme(
  $ghost-header-text-color: #f4d45c,
  $ghost-header-background: #575757,
  $ghost-header-icon-color: #f4bb5c
);
```

<DocsAside type="info">
방금 한 것처럼 색상 값을 직접 하드코딩하는 대신, <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> 및 <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} /> 함수를 사용하면 색상을 훨씬 유연하게 다룰 수 있습니다. 사용 방법에 대한 자세한 안내는 [`Palettes`](/themes/sass/palettes) 항목을 참조하십시오.
</DocsAside>

마지막 단계는 `tokens()`으로 컴포넌트 테마를 적용하는 것입니다:

```scss
:host {
  @include tokens($dark-grid-column-moving-theme);
}
```
