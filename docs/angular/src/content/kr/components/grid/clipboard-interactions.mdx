# Angular Grid 클립보드 상호 작용

클립보드로 복사하기 작업은 이제 Grid에서 사용할 수 있습니다. 이 기능은 현재의 다중 셀 데이터 선택을 통해 Angular Data Grid의 데이터를 복사하는 빠르고, 쉽고, 사용자 지정 가능한 방식을 제공합니다. 시스템 클립보드 동작을 통해 사용자는 Grid의 데이터를 Excel이나 다른 외부 프로그램으로 복사할 수 있습니다.

## 기능

복사 동작은 브라우저와 운영체제가 정의한 기본 상호 작용을 따릅니다. 따라서 복사와 붙여넣기 동작은 다음과 같습니다:

- Windows/Unix 계열
  - 키보드 단축키로 <kbd>Ctrl</kbd> + <kbd>C</kbd> / <kbd>Ctrl</kbd> + <kbd>Ins</kbd>
  - 키보드 단축키로 <kbd>Ctrl</kbd> + <kbd>V</kbd> / <kbd>Shift</kbd> + <kbd>Ins</kbd>
  - 브라우저 메뉴를 통한 복사 작업
- macOS
  - 키보드 단축키로 <kbd>⌘ Cmd</kbd> + <kbd>C</kbd>
  - 키보드 단축키로 <kbd>⌘ Cmd</kbd> + <kbd>V</kbd>
  - 브라우저 메뉴를 통한 복사 작업

## 제한 사항

- Internet Explorer에서는 **잘라내기**와 **복사** 이벤트 모두 기본적으로 지원되지 않습니다. 예외는 **붙여넣기** 이벤트(IE 11)인데, 이 이벤트는 발생하지만 이벤트에서 `clipboardData` 속성을 노출하지 않습니다.

<DocsAside type="info">
IE 11에서 셀을 `copy`하려면 키보드 선택을 사용할 수 있습니다. 다중 셀 선택을 하려면 `shift key`을(를) 누른 상태를 유지하고, 복사하려면 `Ctrl + C`을(를) 누르십시오.
</DocsAside>

- 그리드가 편집 모드에 있는 동안에는 복사 동작이 비활성화됩니다.
- 이 기능의 현재 버전은 그리드 동작의 `copy`만 다룹니다. 이후에 그리드 동작 안에서 `paste`을(를) 노출할 계획입니다.

 `paste` 동작을 구성하려면 사용자 지정 붙여넣기 핸들러를 사용할 수 있습니다. [Excel에서 붙여넣기 주제](/grid/paste-excel)를 확인하십시오.
 

## API 사용법

다음 옵션을 처리하는 <ApiLink type="Grid" member="clipboardOptions" label="clipboardOptions" /> @Input 속성을 노출합니다:

- <ApiLink type="Grid" member="clipboardoptions.enabled" label="enabled" /> 선택된 셀의 복사를 활성화하거나 비활성화합니다.
- <ApiLink type="Grid" member="clipboardoptions.copyHeaders" label="copyHeaders" /> 복사할 때 관련 머리글을 포함합니다.
- <ApiLink type="Grid" member="clipboardoptions.copyFormatters" label="copyFormatters" /> 기존 열 포매터를 복사한 데이터에 적용합니다.
- <ApiLink type="Grid" member="clipboardoptions.separator" label="separator" /> 클립보드의 데이터 형식을 지정하는 데 사용할 문자열 구분자입니다. 기본값은 `/t`입니다

<DocsAside type="info">
Excel은 탭으로 구분된 텍스트(탭으로 구분된 `/t`)를 자동으로 감지하고 데이터를 별도의 열에 올바르게 붙여넣을 수 있습니다. 붙여넣기 형식이 작동하지 않고 붙여넣은 모든 내용이 한 열에 나타난다면, Excel의 구분 기호가 다른 문자로 설정되어 있거나 텍스트가 탭 대신 공백을 사용하고 있는 것입니다.
</DocsAside>

- <ApiLink type="Grid" member="gridCopy" label="gridCopy" /> 복사 작업이 실행될 때 발생합니다. <ApiLink type="Grid" member="clipboardOptions" label="clipboardOptions" />를 통해 복사 동작이 활성화된 경우에만 발생합니다
