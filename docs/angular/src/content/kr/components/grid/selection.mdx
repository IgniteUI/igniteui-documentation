## Angular Grid 선택 옵션

Ignite UI for Angular Grid 컴포넌트는 세 가지 선택 모드를 제공합니다 - [행 선택](/grid/row-selection), [셀 선택](/grid/cell-selection) 및 [열 선택](/grid/column-selection). 기본적으로 Grid에서는 **다중 셀 선택** 모드만 활성화되어 있습니다. 선택 모드를 바꾸거나 활성화하려면 <ApiLink type="Grid" member="rowSelection" label="rowSelection" />, <ApiLink type="Grid" member="cellSelection" label="cellSelection" /> 또는 <ApiLink type="Column" member="selectable" label="selectable" /> 속성을 사용할 수 있습니다.

### Angular 행 선택

<ApiLink type="Grid" member="rowSelection" label="rowSelection" /> 속성을 사용하면 다음 옵션을 지정할 수 있습니다:

- none - Grid에 대해 행 선택이 비활성화됩니다
- single - Grid 안에서 한 행만 선택할 수 있습니다
- multiple - `Row selectors`을 사용하여 다중 행 선택을 할 수 있으며, <kbd>ctrl</kbd> + <kbd>클릭</kbd>과 같은 키 조합을 사용하거나, 셀에 포커스가 있을 때 <kbd>space 키</kbd>를 한 번 누르면 됩니다

> 자세한 내용은 [행 선택 주제](/grid/row-selection)로 이동하십시오.

### Angular 셀 선택

<ApiLink type="Grid" member="cellSelection" label="cellSelection" /> 속성을 사용하면 다음 옵션을 지정할 수 있습니다:

- none - Grid에 대해 셀 선택이 비활성화됩니다
- single - Grid 안에서 한 셀만 선택할 수 있습니다.
- multiple - 현재 Grid의 선택 기본 상태입니다. 왼쪽 마우스 버튼을 계속 누른 상태에서 셀 위로 마우스를 드래그하면 다중 셀 선택이 가능합니다.

> 자세한 내용은 [셀 선택 주제](/grid/cell-selection)로 이동하십시오.

### Angular 열 선택

<ApiLink type="Column" member="selectable" label="selectable` 속성" />을(를) 사용하면 각 **열**에 대해 다음 옵션을 지정할 수 있습니다:

- false - Grid에 대해 해당 열 선택이 비활성화됩니다
- true - Grid에 대해 해당 열 선택이 활성화됩니다
- 이로 인해 다음 세 가지 변형이 생깁니다:
- 단일 선택 - 열 셀 위에서 <kbd>마우스 클릭</kbd>.
- 다중 열 선택 - 열 셀 위에서 <kbd>ctrl</kbd> + <kbd>마우스 클릭</kbd>을 누른 상태로 유지.
- 범위 열 선택 - <kbd>shift</kbd> + <kbd>마우스 클릭</kbd>을 누른 상태로 유지하면 그 사이의 모든 항목이 선택됩니다.

> 자세한 내용은 [열 선택 주제](/grid/column-selection)로 이동하십시오.

## 그리드 컨텍스트 메뉴

<ApiLink type="Grid" member="contextMenu" label="contextMenu" /> 이벤트를 사용하면 **IgxGrid**와의 작업을 돕는 사용자 지정 컨텍스트 메뉴를 추가할 수 있습니다. 그리드 본문에서 **마우스 오른쪽 클릭**을 하면, 이벤트는 그것이 발생한 셀을 발생시킵니다. **컨텍스트 메뉴**는 발생한 셀을 기준으로 작동합니다.

**다중 셀 선택**이 있으면, 선택된 셀이 다중 셀 선택 영역 안에 있는지 확인하는 로직을 두겠습니다. 그렇다면 선택된 셀들의 값도 발생시킵니다.

기본적으로 주 함수는 다음과 같습니다:

```typescript
public rightClick(eventArgs: any) {
     // Prevent the default behavior of the right click
    eventArgs.event.preventDefault();
    this.multiCellArgs = {};
    // If we have multi-cell selection, check if selected cell is within the ranges
    if (this.multiCellSelection) {
        const node = eventArgs.cell.selectionNode;
        const isCellWithinRange = this.grid1.getSelectedRanges().some(range => {
            if (node.column >= range.columnStart &&
                node.column <= range.columnEnd &&
                node.row >= range.rowStart &&
                node.row <= range.rowEnd) {
                return true;
            }
            return false;
        })
        // If the cell is within a multi-cell selection range, bind all the selected cells data
        if (isCellWithinRange) {
            this.multiCellArgs = { data: this.multiCellSelection.data };
        }
    }
    // Set the position of the context menu
    this.contextmenuX = eventArgs.event.clientX;
    this.contextmenuY = eventArgs.event.clientY;
    this.clickedCell = eventArgs.cell;
    // Enable the context menu
    this.contextmenu = true;
}
```

컨텍스트 메뉴에는 다음 기능이 있습니다:

- 선택된 셀의 _값_ 복사
- 선택된 셀의 _dataRow_ 복사
- 선택된 셀이 **다중 셀 선택 범위** 안에 있으면, 모든 _선택된 데이터_ 복사

```typescript
//contextmenu.component.ts

public copySelectedCellData(event) {
    const selectedData = { [this.cell.column.field]: this.cell.value };
    this.copyData(JSON.stringify({ [this.cell.column.field]: this.cell.value }));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copyRowData(event) {
    const selectedData = this.cell.row.data ;
    this.copyData(JSON.stringify(this.cell.row.data));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copySelectedCells(event) {
    const selectedData = this.selectedCells.data;
    this.copyData(JSON.stringify(selectedData));
    this.onCellValueCopy.emit({ data: selectedData });
}
```

IgxGrid는 복사된 데이터를 가져와 컨테이너 요소에 붙여넣습니다.

그리드와 컨텍스트 메뉴를 결합하는 데 사용할 템플릿입니다:

```html
<div class="wrapper">
    <div class="grid__wrapper" (window:click)="disableContextMenu()">
        <igx-grid #grid1 [data]="data" [autoGenerate]="false" height="500px" width="100%"
            (contextMenu)="rightClick($event)" (rangeSelected)="getCells($event)"
            (selected)="cellSelection($event)">
        <!-- Columns area -->
        </igx-grid>
        @if (contextmenu==true) {
            <div>
                <contextmenu [x]="contextmenuX" [y]="contextmenuY" [cell]="clickedCell" [selectedCells]="multiCellArgs" (onCellValueCopy)="copy($event)">
                </contextmenu>
            </div>
        }
    </div>
    <div class="selected-data-area">
        <div>
           <pre>{{copiedData}}</pre>
        </div>
    </div>
</div>
```

 여러 셀을 선택하고 `right mouse` 버튼을 누르십시오. 컨텍스트 메뉴가 나타나며, `Copy cells data`을(를) 선택하면 선택된 데이터가 오른쪽의 빈 상자에 나타납니다.

## 알려진 문제와 제한 사항

- 선택이 활성화된 상태에서 Grid을(를) IE11에서 사용하려면, Angular 애플리케이션의 polyfill.ts에서 배열 polyfill을 명시적으로 가져와야 합니다. IE11은 버전 13.0.0부터 더 이상 지원되지 않습니다.

    ```typescript
    import 'core-js/es7/array';
    ```

- 그리드에 `primaryKey`이(가) 설정되어 있지 않고 원격 데이터 시나리오가 활성화되어 있으면(페이징, 정렬, 필터링, 스크롤이 표시할 데이터를 가져오기 위해 원격 서버에 요청을 트리거할 때), 데이터 요청이 완료된 후 행은 다음 상태를 잃게 됩니다:
  - 행 선택
  - 행 펼치기/접기
  - 행 편집
  - 행 고정
