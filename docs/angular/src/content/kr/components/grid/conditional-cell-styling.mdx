# Angular Grid 조건부 스타일

IgxGrid 컴포넌트에서 사용자 지정 스타일이 필요하다면, 행 또는 셀 수준에서 그렇게 할 수 있습니다.

## Grid 조건부 행 스타일

Ignite UI for Angular의 IgxGrid 컴포넌트는 사용자 지정 규칙을 기반으로 **행의 조건부 스타일**을 지정하는 두 가지 방법을 제공합니다.

- IgxGrid 컴포넌트에 <ApiLink type="Grid" member="rowClasses" label="rowClasses" /> 입력을 설정하면;
- IgxGrid 컴포넌트에 <ApiLink type="Grid" member="rowStyles" label="rowStyles" /> 입력을 설정하면;

이 주제에서는 그 두 가지를 더 자세히 다루겠습니다.

### rowClasses 사용하기

<ApiLink type="Grid" member="rowClasses" label="rowClasses" /> 입력을 설정하고 사용자 지정 규칙을 정의하여 IgxGrid 행의 스타일을 조건부로 지정할 수 있습니다.

```html
<!-- sample.component.html -->
<igx-grid #grid [data]="data" [height]="'600px'" [width]="'100%'" [rowClasses]="rowClasses">
    ...
</igx-grid>
```

<ApiLink type="Grid" member="rowClasses" label="rowClasses" /> 입력은 키-값 쌍을 담은 객체 리터럴을 받으며, 키는 CSS 클래스의 이름이고 값은 불리언을 반환하는 콜백 함수 또는 불리언 값입니다.

```typescript
// sample.component.ts

public rowClasses = {
  activeRow: this.activeRowCondition
};

public activeRowCondition = (row: RowType) => this.grid?.navigation.activeNode?.row === row.index;
```

```scss
// sample.component.scss

::ng-deep {
 .activeRow {
  border: 2px solid #fc81b8;
  border-left: 3px solid #e41c77;
 }
}
```

<DocsAside type="info">
사용자 지정 스타일을 현재 컴포넌트와 그 하위 항목까지 강제로 적용하려면 **`::ng-deep`** 또는 **`ViewEncapsulation.None`**를 사용하십시오.
</DocsAside>

### rowStyles 사용하기

열은 이제 데이터 행의 조건부 스타일 지정을 허용하는 `rowStyles` 속성을 노출합니다. `rowClasses`와 마찬가지로 객체 리터럴을 받으며, 키는 스타일 속성이고 값은 평가할 식입니다. 또한 (조건 없이) 일반 스타일도 적용할 수 있습니다.

> `rowStyles`과(와) `rowClasses`의 콜백 시그니처는 다음과 같습니다:

```ts
(row: RowType) => boolean
```

스타일을 정의해 보겠습니다:

```typescript
// component.ts
public rowStyles = {
    background: (row: RowType) => (+row.data['Change'] < 0  && +row.data['Change On Year(%)'] < 0) ? '#FF000088' : '#00000000',
    border: (row: RowType) => (+row.data['Change'] < 0  && +row.data['Change On Year(%)'] < 0) ? '2px solid' : '1px solid',
    'border-color': (row: RowType) => (+row.data['Change'] < 0  && +row.data['Change On Year(%)'] < 0) ? '#FF000099' : '#E9E9E9'
};
```

```html
<!-- sample.component.html -->
<igx-grid #grid1 [data]="data | async" [height]="'500px'" width="100%"
        [autoGenerate]="false" [allowFiltering]="true" [rowStyles]="rowStyles">
    ...
</igx-grid>
```

## Grid 조건부 셀 스타일

## 개요

Ignite UI for Angular의 IgxGrid 컴포넌트는 사용자 지정 규칙을 기반으로 **셀의 조건부 스타일**을 지정하는 두 가지 방법을 제공합니다.

- <ApiLink type="Column" /> 입력 <ApiLink type="Column" member="cellClasses" label="cellClasses" />을(를) 키-값 쌍을 담은 객체 리터럴로 설정합니다. 키는 CSS 클래스의 이름이고 값은 불리언을 반환하는 콜백 함수 또는 불리언 값입니다. 그 결과 셀에 편리한 Material 스타일이 적용됩니다.

```ts
// component.ts file
public beatsPerMinuteClasses = {
    downFont: this.downFontCondition,
    upFont: this.upFontCondition
};
...

private downFontCondition = (rowData: any, columnKey: any): boolean => {
    return rowData[columnKey] <= 95;
}
```

```scss
// component.scss file
.upFont {
  color: red;
}

.downFont {
  color: green;
}
```

### cellClasses 사용하기

<ApiLink type="Column" /> <ApiLink type="Column" member="cellClasses" label="cellClasses" /> 입력을 설정하고 사용자 지정 규칙을 정의하여 IgxGrid 셀의 스타일을 조건부로 지정할 수 있습니다.

```html
<!-- sample.component.html -->
<igx-column field="BeatsPerMinute" dataType="number" [cellClasses]="beatsPerMinuteClasses"></igx-column>
```

<ApiLink type="Column" member="cellClasses" label="cellClasses" /> 입력은 키-값 쌍을 담은 객체 리터럴을 받으며, 키는 CSS 클래스의 이름이고 값은 불리언을 반환하는 콜백 함수 또는 불리언 값입니다.

```typescript
// sample.component.ts

private upFontCondition = (rowData: any, columnKey: any): boolean => {
    return rowData[columnKey] > 95;
}

private downFontCondition = (rowData: any, columnKey: any): boolean => {
    return rowData[columnKey] <= 95;
}

public beatsPerMinuteClasses = {
    downFont: this.downFontCondition,
    upFont: this.upFontCondition
};
```

```scss
// sample.component.scss

::ng-deep {
    .upFont {
        color: green;
    }

    .downFont {
        color: red;
    }
}
```

<DocsAside type="info">
사용자 지정 스타일을 현재 컴포넌트와 그 하위 항목까지 강제로 적용하려면 **`::ng-deep`** 또는 **`ViewEncapsulation.None`**를 사용하십시오.
</DocsAside>

- <ApiLink type="Column" /> 입력 <ApiLink type="Column" member="cellStyles" label="cellStyles" />을(를) 사용합니다. 이는 키가 스타일 속성이고 값이 평가할 식인 객체 리터럴을 받습니다.

```ts
public styles = {
    'background': 'linear-gradient(180deg, #dd4c4c 0%, firebrick 100%)',
    'text-shadow': '1px 1px 2px rgba(25,25,25,.25)',
    'animation': '0.25s ease-in-out forwards alternate popin'
};
```

> `cellStyles`과(와) `cellClasses`의 콜백 시그니처는 이제 다음과 같이 바뀌었습니다:

```ts
(rowData: any, columnKey: string, cellValue: any, rowIndex: number) => boolean
```

### cellStyles 사용하기

열은 이제 열 셀의 조건부 스타일 지정을 허용하는 `cellStyles` 속성을 노출합니다. `cellClasses`와 마찬가지로 객체 리터럴을 받으며, 키는 스타일 속성이고 값은 평가할 식입니다. 또한 (조건 없이) 일반 스타일도 쉽게 적용할 수 있습니다.

[위 샘플](#데모)에서 우리는 다음을 만들었습니다:

- 열 인덱스를 기준으로 적용되는 두 가지 서로 다른 스타일.
- 짝수/홀수 행을 기준으로 `text color`도 바꿉니다.

> `cellStyles`의 콜백 시그니처는 다음과 같습니다:

```ts
(rowData: any, columnKey: string, cellValue: any, rowIndex: number) => boolean
```

스타일을 정의해 보겠습니다:

```typescript
// component.ts
public oddColStyles = {
    background: 'linear-gradient(to right, #b993d6, #8ca6db)',
    color: (rowData, columnKey, cellValue, rowIndex) => rowIndex % 2 === 0 ? 'white' : 'gray',
    animation: '0.75s popin'
};

public evenColStyles = {
    background: 'linear-gradient(to right, #8ca6db, #b993d6)',
    color: (rowData, columnKey, cellValue, rowIndex) => rowIndex % 2 === 0 ? 'gray' : 'white',
    animation: '0.75s popin'
};
```

`ngOnInit`에서는 미리 정의된 `columns` 컬렉션의 각 열에 대해 `cellStyles` 구성을 추가하며, 이는 IgxGrid 열을 동적으로 만드는 데 사용됩니다.

```ts
// component.ts
public ngOnInit() {
    this.data = athletesData;
    this.columns = [
        { field: 'Id' },
        { field: 'Position' },
        { field: 'Name' },
        { field: 'AthleteNumber' },
        { field: 'CountryName' }
    ];

    this.applyCSS();
}
```

```ts
public applyCSS() {
    this.columns.forEach((column, index) => {
        column.cellStyles = (index % 2 === 0 ? this.evenColStyles : this.oddColStyles);
    });
}

public updateCSS(css: string) {
    this.oddColStyles = {...this.oddColStyles, ...JSON.parse(css)};
    this.evenColStyles = {...this.evenColStyles, ...JSON.parse(css)};
    this.applyCSS();
}
```

```html
// component.html
<igx-grid
    #grid1 [data]="data"
    primaryKey="ID"
    width="80%"
    height="300px">
    <igx-column *ngFor="let c of columns"
        [field]="c.field"
        [header]="c.field"
        [cellStyles]="c.cellStyles">
    </igx-column>
</igx-grid>
```

`popin` 애니메이션 정의하기

```scss
// component.scss
@keyframes popin {
    0% {
        opacity: 0.1;
        transform: scale(.75, .75);
        filter: blur(3px) invert(1);
    }

    50% {
        opacity: .5;
        filter: blur(1px);
    }

    100% {
        transform: scale(1, 1);
        opacity: 1;
        filter: none;
    }
}
```

## 알려진 문제와 제한 사항

- (서로 다른 열에서) 같은 조건에 바인딩된 셀이 있고 그중 하나가 업데이트되면, 조건이 충족되더라도 나머지 셀은 새 값에 따라 업데이트되지 않습니다.
나머지 셀에 변경 사항을 적용하려면 파이프 검사를 수행해야 합니다. 아래 예제는 <ApiLink type="Grid" member="cellEdit" label="cellEdit" /> 이벤트에서 `spread operator(...)`을(를) 사용하여 이를 수행하는 방법을 보여 줍니다. 이는 원본 객체를 새 인스턴스로 복사하여 순수 파이프가 실행되도록 합니다.

```ts
public backgroundClasses = {
    myBackground: (rowData: any, columnKey: string) => {
        return rowData.Col2 < 10;
    }
};
...

editDone(evt) {
    this.backgroundClasses = {...this.backgroundClasses};
}

```

```html
<igx-grid #grid1 [data]="data" height="500px" width="100%" (cellEdit)="editDone($event)">
  <igx-column field="Col1" dataType="number" [cellClasses]="backgroundClasses"></igx-column>
  <igx-column field="Col2" dataType="number" [editable]="true" [cellClasses]="backgroundClasses"></igx-column>
  <igx-column field="Col3" header="Col3" dataType="string" [cellClasses]="backgroundClasses"></igx-column>
</igx-grid>
```
