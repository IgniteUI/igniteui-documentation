# Angular 셀 병합

Ignite UI for Angular Grid은(는) 값이 같은 인접한 두 개 이상의 셀을 하나의 더 큰 셀로 결합하는 셀 병합 기능을 제공합니다. 병합은 열 안에서 세로로 적용되며, 중복된 값을 줄여 가독성을 높이는 데 도움이 됩니다. 이 기능은 기본적으로 데이터 값이 일치하는 경우로 셀을 병합하거나, 사용자 지정 조건을 적용하여 셀을 병합하도록 구성할 수 있습니다.

## 셀 병합 활성화 및 사용하기

그리드의 셀 병합은 두 수준에서 제어됩니다:

- 그리드 수준 병합 모드 - 병합이 언제 적용되는지를 결정합니다.
- 열 수준 병합 토글 - 어떤 열에서 셀을 병합할 수 있는지를 결정합니다.

### 그리드 병합 모드

그리드는 `GridCellMergeMode` 열거형의 값을 받는 `cellMergeMode` 속성을 노출합니다:

- `always` - 정렬 상태와 관계없이 병합 조건을 충족하는 인접한 모든 셀을 병합합니다.
- `onSort` - 열이 정렬된 경우에만 인접한 셀을 병합합니다 **(기본값)**.

```html
<igx-grid [data]="data" [cellMergeMode]="cellMergeMode">
    ...
</igx-grid>
```

```ts
protected cellMergeMode: GridCellMergeMode = 'always';
```

### 열 병합 토글

열 수준에서는 `merge` 속성으로 병합을 활성화하거나 비활성화할 수 있습니다.

```html
<igx-column field="OrderID" [merge]="true"></igx-column>
<igx-column field="ShipperName" [merge]="false"></igx-column>
```

위 예제에서:

- **OrderID** 열은 인접한 중복 값을 병합합니다.
- **ShipperName** 열은 병합 없이 정상적으로 렌더링됩니다.

### 결합 예제

```html
<igx-grid [data]="data" [cellMergeMode]="cellMergeMode" [autoGenerate]="false">
    <igx-column field="OrderID" header="Order ID" [merge]="true"></igx-column>
    <igx-column field="ShipperName" header="Shipper Name" [merge]="true"></igx-column>
    <igx-column field="Salesperson" header="Salesperson"></igx-column>
</igx-grid>
```

```ts
protected cellMergeMode: GridCellMergeMode = 'onSort';
```

여기서 그리드는 열이 정렬되었을 때만 병합하도록 설정되어 있으며, Category 열과 Product 열이 모두 병합되도록 구성되어 있습니다.

## 사용자 지정 병합 조건

내장 `always` 및 `onSort` 모드 외에도, 그리드는 `mergeStrategy` 속성을 통해 셀 병합에 대한 사용자 지정 조건을 정의할 수 있게 합니다. 이 전략은 셀을 비교하는 방식과 병합된 범위를 계산하는 방식을 모두 제어합니다.

### 병합 전략 인터페이스

사용자 지정 병합 전략은 `IGridMergeStrategy` 인터페이스를 구현해야 합니다:

```ts
export interface IGridMergeStrategy {
    merge: (
        data: any[],
        field: string,
        comparer: (prevRecord: any, currentRecord: any, field: string) => boolean,
        result: any[],
        activeRowIndex?: number,
        grid?: GridType
    ) => any[];

    comparer: (prevRecord: any, record: any, field: string) => boolean;    
}
```

- `merge` - 병합된 셀이 어떻게 만들어지는지 정의합니다.
- `comparer` - 인접한 두 레코드를 병합할지 결정하는 조건을 정의합니다.

### 기본 전략 확장하기

동작의 일부만 사용자 지정하고 싶다면(예: 비교기 로직), 내장 `DefaultMergeStrategy`을(를) 확장하고 관련 메서드를 재정의할 수 있습니다.

```ts
export class MyCustomStrategy extends DefaultMergeStrategy {
    /* Merge only cells within their respective projects */
    public override comparer(prevRecord: any, record: any, field: string): boolean {
        const a = prevRecord[field];
        const b = record[field];
        const projA = prevRecord['ProjectName'];
        const projB = record['ProjectName'];
        return a === b && projA === projB;
    }
}
```

### 사용자 지정 전략 적용하기

정의한 후에는 `mergeStrategy` 속성을 통해 전략을 그리드에 할당하십시오:

```html
<igx-grid [data]="data" [mergeStrategy]="customStrategy">
  <igx-column field="ActionID" [merge]="true"></igx-column>
  <igx-column field="ProjectName" [merge]="true"></igx-column>
</igx-grid>
```

```ts
protected customStrategy = new MyCustomStrategy();
```

## 기능 통합

병합된 셀의 특정 동작 때문에, 그리드의 다른 기능과 정확히 어떻게 연결되는지 알아 둘 필요가 있습니다:

- **펼치기/접기**: 기능(예: 마스터-디테일, 그룹화 등)이 데이터가 아닌 행을 생성하면 셀 병합이 중단되고 그룹이 나뉩니다.

- **Excel 내보내기**: 병합된 셀은 Excel로 내보낼 때도 병합된 상태로 남습니다.
- **열 고정**: 열이 고정되면 셀은 병합된 상태로 남으며 고정 영역에 표시됩니다.
- **행 고정**: 셀은 자신이 속한 영역 안에서만 병합됩니다. 즉, 고정된 행의 셀은 다른 고정된 행의 셀과만 병합되고, 고정되지 않은 행의 셀은 고정되지 않은 행의 셀과만 병합됩니다.
- **탐색/활성화**: 셀이 활성화되면 같은 행의 병합된 모든 셀은 단일 셀이 되며, 즉 병합 순서가 끊어집니다. 여기에는 키보드 탐색을 통한 활성화도 포함됩니다.

<DocsAside type="info">
병합된 셀을 클릭하면 병합 순서에서 가장 가까운 셀이 활성화됩니다.
</DocsAside>

- **업데이트/편집**: 활성화가 병합 순서를 끊으므로, 편집 모드에 있는 셀은 하나뿐입니다.
- **행 선택**: 선택된 행이 병합된 셀과 겹치면, 관련된 병합 셀 모두를 선택 항목의 일부로 표시해야 합니다.

## 제한 사항

|알려진 제한 사항| 설명|
| --- | --- |
| 셀 병합은 다중 행 레이아웃과 함께 사용할 수 없습니다. | 둘 다 결합하면 의미가 없는 복잡한 레이아웃을 만듭니다. 이런 잘못된 구성이 감지되면 경고가 표시됩니다. |
