# Angular Grid Excel 및 PDF 내보내기 서비스

<p class="highlight">

사용자에게 더 깊은 분석을 위한 스프레드시트가 필요하든, 바로 공유할 수 있는 다듬어진 PDF가 필요하든, Ignite UI 내보내기 도구는 IgxGrid에서 적합한 파일을 몇 초 만에 제공하도록 도와줍니다. <ApiLink type="ExcelExporterService" /> 또는 <ApiLink type="PdfExporterService" />을(를) 주입하고, 해당 <ApiLink type="ExcelExporterService" member="export" label="export" />/<ApiLink type="PdfExporterService" member="export" label="export" /> 메서드를 호출하면, 컴포넌트가 나머지를 처리합니다. 필터와 정렬을 반영하는 것부터 출력 형식을 만드는 것까지 모두 포함합니다.
</p>

아래 섹션에서는 설정, 사용 패턴, 그리고 각 내보내기를 맞춤 설정하는 팁을 살펴보겠습니다. 이를 통해 사용자가 어떤 파일 형식을 선호하든 바로 사용할 수 있는 데이터를 받을 수 있습니다.

## Grid의 데이터 내보내기

내보내기 도구를 프로젝트에 가져오는 데는 몇 줄의 코드만 필요합니다. 다음 단계를 따르면 요청 시 Excel 또는 PDF 출력을 만들 수 있는 재사용 가능한 서비스를 갖게 됩니다:

1. 루트 모듈에서 <ApiLink type="ExcelExporterService" /> 및/또는 <ApiLink type="PdfExporterService" />를 가져오십시오.
2. 필요한 내보내기 도구를 주입하고, 사용자가 파일을 요청할 때 그 `export` 메서드를 호출하십시오.

```typescript
// component.ts
import { IgxExcelExporterService, IgxPdfExporterService } from 'igniteui-angular/grids/core';
// import { IgxExcelExporterService, IgxPdfExporterService } from '@infragistics/igniteui-angular/grids/core'; for licensed package

...

private excelExportService = inject(IgxExcelExporterService);
private pdfExportService = inject(IgxPdfExporterService);

```

<DocsAside type="info">
v12.2.1 이후에서는 `IgxExcelExporterService`이(가) 루트에 제공되므로 `providers` 배열에 등록할 필요가 없습니다. PDF 내보내기 도구는 이후 버전에서 도입되었으며, 추가 구성 없이 주입 가능한 서비스로 사용할 수 있습니다.
</DocsAside>

내보내기 과정을 시작하려면 컴포넌트 템플릿의 버튼 핸들러를 사용할 수 있습니다.

```html
<igx-grid #grid [data]="localData" [autoGenerate]="true"></igx-grid>
<button (click)="exportButtonHandler()">Export IgxGrid to Excel</button>
<button (click)="exportPdfButtonHandler()">Export IgxGrid to PDF</button>
```

생성자 종속성으로 정의하고 Angular가 인스턴스를 제공하도록 하면 두 내보내기 도구 중 어느 것이든 접근할 수 있습니다. 공유된 <ApiLink type="ExcelExporterService" member="export" label="export" /> 메서드를 호출하면 다운로드가 시작되며, 컴포넌트 상태, 선택된 행, 서식 규칙을 자동으로 따릅니다.

다음은 컴포넌트의 TypeScript 파일에서 두 내보내기 프로세스를 모두 실행하는 코드입니다:

```typescript
// component.ts
import { IgxExcelExporterService, IgxExcelExporterOptions, IgxPdfExporterService, IgxPdfExporterOptions } from 'igniteui-angular/grids/core';
import { IgxGridComponent } from 'igniteui-angular/grids/grid';

@ViewChild('grid') public grid: IgxGridComponent;

private excelExportService = inject(IgxExcelExporterService);
private pdfExportService = inject(IgxPdfExporterService);

public exportButtonHandler() {
  this.excelExportService.export(this.grid, new IgxExcelExporterOptions('ExportedDataFile'));
}

public exportPdfButtonHandler() {
  this.pdfExportService.export(this.grid, new IgxPdfExporterOptions('ExportedDataFile'));
}
```

연결이 끝나면 해당 버튼을 누를 때 현재 Grid 보기로 채워진 `ExportedDataFile.xlsx` 또는 `ExportedDataFile.pdf` 이름의 파일이 다운로드됩니다. 고객 친화적인 파일 이름으로 바꾸거나, 타임스탬프를 붙이거나, 사용자가 내보내기가 완료되었음을 알 수 있도록 성공 토스트를 표시할 수 있습니다.

## 모든 데이터 내보내기

대규모 원격 데이터 집합은 보통 페이지별로 또는 필요할 때 로드되므로, 사용자가 **내보내기**를 클릭할 때 Grid이(가) 모든 레코드를 가지고 있지 않을 수 있습니다. 완전한 통합 문서를 보장하려면, 프로세스를 시작하기 전에 전체 데이터 컬렉션으로 내보내기 도구를 채우십시오. `exportData` 도우미는 컴포넌트를 거치지 않고 일반 객체에서 직접 작동하므로, 예약된 내보내기나 관리자 전용 다운로드에도 같은 루틴을 재사용할 수 있습니다.

```ts
public exportButtonHandler() {
  this.excelExportService.exportData(this.localData, new IgxExcelExporterOptions('ExportedDataFile'));
}
```

<DocsAside type="tip">
원격 데이터에 대해 PDF 다운로드를 제공할 때는, 먼저 전체 데이터 집합을 가져온 다음 `export`을(를) 호출하여 문서가 사용자의 기대를 반영하도록 하는 것을 고려하십시오.
</DocsAside>

## 그룹화된 데이터 내보내기

그룹화는 결과를 공유하기 전에 고객 세그먼트, 제품 범주 또는 재무 기간을 요약하는 데 널리 쓰이는 방법입니다. 내보내기 도구는 Grid에 현재 적용된 정확한 그룹화 계층을 유지하므로, 받는 사람은 여러분이 브라우저에서 보는 것과 같은 분류를 보게 됩니다. 하나 이상의 열로 그룹화하고 내보내기를 실행하기만 하면 됩니다. 추가 구성은 필요하지 않습니다.

내보낸 파일에 평평한 데이터가 필요하다면, `export`을(를) 호출하기 전에 그룹화를 해제하거나, `rowExporting` 이벤트를 처리하여 출력을 재구성하십시오.

## 다중 열 머리글 그리드 내보내기

대시보드는 맥락을 더하기 위해 보통 [다중 열 머리글](/grid/multi-column-headers)에 의존합니다. 개별 월 열 위에 있는 "Q1/Q2/Q3" 띠를 생각해 보십시오. 내보내기 도구는 이 구조를 그대로 반영하므로, 스프레드시트 사용자는 그룹화 논리를 바로 이해할 수 있습니다. 후속 작업 흐름에서 단순한 열 이름을 선호한다면, <ApiLink kind="interface" type="IGridToolbarExportEventArgs" label="내보내기 도구 옵션" /> <ApiLink type="ExcelExporterOptions" member="ignoremulticolumnheaders" label="ignoreMultiColumnHeaders" /> 플래그를 `true`(으)로 바꾸면 출력에는 최하위 머리글만 포함됩니다.

<DocsAside type="info">
Excel 표는 여러 행 머리글을 지원하지 않으므로, 내보낸 Grid은(는) 표 형식으로 서식이 지정되지 않습니다.
</DocsAside>

<Sample src="/grid/multi-column-headers-export" height={800} alt="Angular 다중 열 머리글 내보내기" />

## 고정된 열 머리글이 있는 그리드 내보내기

긴 시트는 머리글 행이 화면 밖으로 스크롤되면 읽기 어려워질 수 있습니다. 고정 머리글을 활성화하면, 사용자가 아래쪽 데이터를 살펴보는 동안에도 "Customer"나 "Invoice Total" 같은 핵심 맥락이 워크시트 맨 위에 계속 보입니다. `export`을(를) 호출하기 전에 <ApiLink kind="interface" type="IGridToolbarExportEventArgs" label="내보내기 도구 옵션" /> <ApiLink type="ExcelExporterOptions" member="freezeHeaders" label="freezeHeaders" /> 플래그를 `true`(으)로 설정하면, 나머지는 서비스가 처리합니다.

```typescript
public exportButtonHandler() {
    const exporterOptions = new IgxExcelExporterOptions('ExportedDataFile');
    exporterOptions.freezeHeaders = true;
    this.excelExportService.export(this.grid, exporterOptions);
}
```

PDF 내보내기는 문서 맨 위에 열 머리글 행을 자동으로 포함하므로, 독자가 파일을 열거나 인쇄할 때도 같은 맥락을 유지합니다.

## 내보내는 콘텐츠 사용자 지정하기

대부분의 팀은 공유하기 전에 내보내기를 맞춤 설정합니다. 내부용 열을 숨기거나, 머리글 이름을 바꾸거나, 관리자에게만 해당하는 행을 건너뛰는 것 등입니다. 두 내보내기 서비스 모두 모든 행이나 열을 가로채어 파일에 어떻게 표시할지 결정할 수 있게 하는 이벤트를 노출합니다. 막바지 조정을 하려면 <ApiLink type="ExcelExporterService" member="columnexporting" label="columnExporting" /> 및 <ApiLink type="ExcelExporterService" member="rowexporting" label="rowExporting" />를 구독하십시오. 항목을 생략하려면 `cancel = true`을(를) 설정하거나, 이벤트 인수를 조정하여 즉시 값을 업데이트할 수 있습니다.

다음 예제는 헤더가 "Age"이고 인덱스가 1인 열을 내보내기에서 제외합니다:

```typescript
// component.ts

this.excelExportService.columnExporting.subscribe((args: IColumnExportingEventArgs) => {
  if (args.header == 'Age' && args.columnIndex == 1) {
      args.cancel = true;
  }
});
this.excelExportService.export(this.grid, new IgxExcelExporterOptions('ExportedDataFile'));
```

Grid 컴포넌트에서 데이터를 내보낼 때, 서비스는 정렬, 필터링, 요약, 숨겨진 열을 자동으로 따르므로 파일은 사용자가 현재 보는 내용을 반영합니다. 대신 전체 데이터 집합이 필요하다면, <ApiLink type="ExcelExporterOptions" /> 또는 <ApiLink type="PdfExporterOptions" />에서 관련 플래그를 바꾸어 필터링된 행, 숨겨진 열 또는 사용자 지정 메타데이터를 포함하십시오.

## 알려진 제한 사항

내보내기를 실제 운영 사용자에게 배포하기 전에, 다음 플랫폼 제약 사항을 검토하여 기대치를 설정하고 앱 안에서 유용한 안내를 제공하십시오.

|제한 사항|설명|
|--- |--- |
|워크시트 최대 크기|Excel이 지원하는 최대 워크시트 크기는 1,048,576행 × 16,384열입니다. 이 제한 안에 머무르도록, 매우 큰 내보내기는 날짜 범위나 세그먼트별로 나누는 것을 고려하십시오.|
|셀 스타일 지정|Excel 내보내기 서비스는 셀 컴포넌트에 직접 적용된 사용자 지정 스타일의 내보내기를 지원하지 않습니다. 이런 경우에는 세밀한 서식을 위해 더 풍부한 [Excel 라이브러리](/excel-library)를 사용하는 것을 권장합니다.|
|넓은 PDF 레이아웃|매우 넓은 그리드는 PDF의 열이 페이지에 맞도록 줄어들게 할 수 있습니다. 문서를 읽기 쉽게 유지하려면, 내보내기 전에 열 너비를 적용하거나 우선순위가 낮은 필드를 숨기십시오.|
