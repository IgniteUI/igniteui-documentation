# Angular Grid 열 숨기기

Ignite UI for Angular Grid은(는) <ApiLink type="ColumnActions" />가 있는 <ApiLink type="ColumnHidingDirective" />을(를) 제공하며, 이를 통해 사용자는 사용자 인터페이스를 통해 직접 또는 Angular 컴포넌트를 사용하여 열 숨기기를 수행할 수 있습니다. Material UI Grid에는 내장된 열 숨기기 UI가 있으며, 이는 Grid의 도구 모음을 통해 사용하여 열의 표시 상태를 바꿀 수 있습니다. 또한 개발자는 열 숨기기 UI를 별도의 컴포넌트로 정의하여 페이지의 원하는 위치에 항상 배치할 수 있습니다.

## Grid 설정

먼저 Grid을(를) 만들고 데이터에 바인딩하겠습니다. 또한 열에 대해 필터링과 정렬을 모두 활성화하겠습니다.

```html
<!--columnHiding.component.html-->

<igx-grid #grid id="grid" [data]="data" [autoGenerate]="false" width="100%" height="560px" columnWidth="200px" [allowFiltering]="true">
    <igx-column [field]="'ID'" dataType="string" [sortable]="true" [hidden]="true"></igx-column>
    <igx-column [field]="'ContactName'" dataType="string" [sortable]="true" [hidden]="true"></igx-column>
    <igx-column [field]="'ContactTitle'" dataType="string" [sortable]="true"></igx-column>
    <igx-column [field]="'City'" dataType="string" [sortable]="true"></igx-column>
    <igx-column [field]="'CompanyName'" dataType="string" [sortable]="true"></igx-column>
    <igx-column [field]="'Fax'" dataType="string" [sortable]="true"></igx-column>
    <igx-column [field]="'Address'" dataType="string" [sortable]="true"></igx-column>
    <igx-column [field]="'PostalCode'" dataType="string" [sortable]="true"></igx-column>
    <igx-column [field]="'Country'" dataType="string" [sortable]="true"></igx-column>
    <igx-column [field]="'Phone'" dataType="string" [sortable]="true"></igx-column>
</igx-grid>
```

## 도구 모음의 열 숨기기 UI

내장 열 숨기기 UI는 Grid의 도구 모음에 있는 <ApiLink type="DropDown" /> 안에 배치됩니다. 이 드롭다운을 사용하여 열 숨기기 UI를 표시하거나 숨길 수 있습니다.
이를 위해서는 Grid 안에서 <ApiLink type="GridToolbarActions" />과 <ApiLink type="GridToolbarHiding" />을(를) 모두 설정하기만 하면 됩니다. 또한 <ApiLink type="GridToolbarTitle" />을(를) 사용하여 도구 모음에 제목을 추가하고, Grid의 래퍼에 사용자 지정 스타일을 추가하겠습니다.

```html
<!--columnHiding.component.html-->

<div class="grid__wrapper">
    <igx-grid ...>
        <igx-grid-toolbar>
            <igx-grid-toolbar-title>Employees</igx-grid-toolbar-title>
            <igx-grid-toolbar-actions>
                <igx-grid-toolbar-hiding></igx-grid-toolbar-hiding>
            </igx-grid-toolbar-actions>
        </igx-grid-toolbar>
        ...
    </igx-grid>
</div>
```

```css
/* columnHiding.component.css */

.grid__wrapper {
    margin: 10px;
}
```

Grid은(는) 도구 모음의 열 숨기기 UI를 사용할 때 유용한 몇 가지 속성을 제공합니다.
`igx-grid-toolbar-hiding` <ApiLink type="GridToolbarHiding" member="title" label="title" /> 속성을 사용하여 도구 모음의 드롭다운 버튼 안에 표시되는 제목을 설정하겠습니다.

```html
<!--columnHiding.component.html-->

<div class="grid__wrapper">
    <igx-grid>
        <igx-grid-toolbar>
            <igx-grid-toolbar-title>Employees</igx-grid-toolbar-title>
            <igx-grid-toolbar-actions>
                <igx-grid-toolbar-hiding #hidingActionRef title="Column Hiding"></igx-grid-toolbar-hiding>
            </igx-grid-toolbar-actions>
        </igx-grid-toolbar>
    </igx-grid>
</div>
```

IgxGridToolbarHidingComponent의 <ApiLink type="GridToolbarHiding" member="columnsAreaMaxHeight" label="columnsAreaMaxHeight" /> 속성을 사용하면 열 작업을 담고 있는 영역의 최대 높이를 설정할 수 있습니다. 이렇게 하면 작업이 많아서 모두 컨테이너에 맞지 않을 때 스크롤바가 나타나, 원하는 작업으로 스크롤할 수 있습니다.

```typescript
// columnHiding.component.ts

public ngAfterViewInit() {        
    this.hidingActionRef.columnsAreaMaxHeight = "200px";
}
```

열 숨기기 UI의 확장된 기능 집합을 사용하려면 IgxColumnActionsComponent의 <ApiLink type="ColumnActions" member="columnsAreaMaxHeight" label="columnsAreaMaxHeight" /> 속성을 사용할 수 있습니다. 이렇게 하면 애플리케이션의 요구 사항에 맞게 사용할 수 있습니다.

위 코드의 결과는 이 문서 시작 부분의 Angular 열 숨기기 예제 섹션에서 볼 수 있습니다.

## 사용자 지정 열 숨기기 UI

열 숨기기 UI인 <ApiLink type="ColumnActions" />을(를) 수동으로 정의하고 싶다고 가정해 봅시다. 그 목적을 알 수 있도록 <ApiLink type="ColumnHidingDirective" />을(를) 추가하고, 페이지의 어디에든 배치하겠습니다. 하지만 먼저 `IgxColumnActionsModule`을(를) 가져와야 합니다.

```typescript
// app.module.ts

...

    ...
    IgxColumnActionsModule 
} from 'igniteui-angular/grids/core';
// import { ..., IgxColumnActionsModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxColumnActionsModule],
})
export class AppModule {}
```

이제 <ApiLink type="ColumnActions" />을(를) 만들어 보겠습니다. 우리 애플리케이션에서는 이것을 그리드 옆에 배치하겠습니다(설계상 컴포넌트가 드롭다운 안에 있는 도구 모음의 열 숨기기 UI와는 다른 경우입니다). 또한 컴포넌트의 <ApiLink type="ColumnActions" member="columns" label="columns" /> 속성을 Grid의 열로 설정하고, 애플리케이션을 더 멋지게 보이게 하기 위해 사용자 지정 스타일을 포함하겠습니다!

```html
<!--columnHiding.component.html-->

<div class="columnHidingContainer">
    <igx-column-actions igxColumnHiding #columnHidingUI [columns]="grid.columns">
    </igx-column-actions>
</div>
<div class="gridContainer">
    <igx-grid #grid [data]="data" [autoGenerate]="false" width="100%" height="500px" columnWidth="200px">
        ...
    </igx-grid>
</div>
```

```css
/* columnHiding.component.css */

.grid__wrapper {
    margin: 15px;
    display: flex;
    flex-direction: row;
}

.columnHidingContainer {
    min-width: 250px;
    height: 560px;
    display: flex;
    flex-direction: column;
    padding-left: 20px;
    padding-right: 20px;
    border: 1px gray;
    border-radius: 10px;
    box-shadow: 1px 1px 2px 2px rgba(50, 50, 50, 0.25);
    igx-column-actions {
        height: 460px;
    }
}

.columnsOrderOptionsContainer {
    margin-top: 20px;
    margin-bottom: 20px;
}

.gridContainer {
    width: 100%;
    min-width: 200px;
    display: flex;
    flex-direction: column;
    margin-left: 30px;    
}
```

### 제목과 필터 안내 문구 추가

열 숨기기 컴포넌트의 사용자 경험을 더 풍부하게 하기 위해 할 수 있는 몇 가지가 더 있습니다. <ApiLink type="ColumnActions" member="title" label="title" />과 <ApiLink type="ColumnActions" member="filtercolumnsprompt" label="filterColumnsPrompt" /> 속성을 설정하는 것입니다. <ApiLink type="ColumnActions" member="title" label="title" />은(는) 위쪽에 표시되고, <ApiLink type="ColumnActions" member="filterColumnsPrompt" label="filterColumnsPrompt" />은(는) 열 숨기기 UI의 필터 입력에 표시되는 안내 문구입니다.

```html
<!--columnHiding.component.html-->

<div class="columnHidingContainer">
    <igx-column-actions igxColumnHiding #columnHidingUI [columns]="grid.columns"
                       title="Column Hiding" filterColumnsPrompt="Type here to search">
    </igx-column-actions>
</div>
```

### 열 표시 순서 옵션 추가

열 숨기기 UI에서 사용자가 열의 표시 순서를 선택하도록 할 수도 있습니다. 이를 위해 열거형 유형의 속성인 <ApiLink type="ColumnActions" member="columnDisplayOrder" label="columnDisplayOrder" />을(를) 사용하며, 다음 옵션이 있습니다:

- **Alphabetical**(열을 알파벳순으로 정렬)
- **DisplayOrder**(열을 Grid에 표시되는 방식에 따라 정렬)

옵션을 위해 세련된 라디오 버튼을 몇 개 만들어 보겠습니다! [**IgxRadio**](/inputs/radio) 모듈만 가져오면 됩니다.

```typescript
// app.module.ts

...

    ...
    IgxRadioModule    
} from 'igniteui-angular/radio';
// import { ..., IgxRadioModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxRadioModule],    
})
export class AppModule {}
```

이제 남은 일은 두 라디오 버튼 각각의 <ApiLink type="Radio" member="checked" label="checked" /> 속성을 서로 다른 조건에 바인딩하고, 클릭 이벤트를 처리하는 것뿐입니다.

```html
<!--columnHiding.component.html-->

<div class="columnHidingContainer">
    ...
    <div class="columnsOrderOptionsContainer">
        <igx-radio [checked]="columnHidingUI.columnDisplayOrder === 'Alphabetical'"
                   (click)="columnHidingUI.columnDisplayOrder = 'Alphabetical'">
            Alphabetical order
        </igx-radio>
        <igx-radio [checked]="columnHidingUI.columnDisplayOrder === 'DisplayOrder'"
                   (click)="columnHidingUI.columnDisplayOrder = 'DisplayOrder'">
            Display order
        </igx-radio>
    </div>
</div>
```

### 열 숨기기 비활성화

<ApiLink type="Column" member="disableHiding" label="disableHiding" /> 속성을 true로 설정하기만 하면, 열 숨기기 UI를 통해 사용자가 열을 숨기지 못하도록 쉽게 막을 수 있습니다.

```html
<!--columnHiding.component.html-->

<div class="gridContainer">
    <igx-grid ... >
        ...
        <igx-column [field]="'ContactName'" dataType="string" [sortable]="true" [disableHiding]="true"></igx-column>
        <igx-column [field]="'ContactTitle'" dataType="string" [sortable]="true" [disableHiding]="true"></igx-column>
        ...
    </igx-grid>
</div>
```

## 스타일링

열 작업 컴포넌트의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 index 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-column-actions-theme" label="column-actions-theme" code={true} />을(를) 확장하고 `$title-color` 및 `$background-color` 매개변수를 받는 새 테마를 만듭니다.

```scss
$custom-column-actions-theme: column-actions-theme(
  $background-color: #292826,
  $title-color: #ffcd0f
);
```

보시다시피 `column-actions-theme`은(는) 열 작업 컨테이너의 색상만 제어하며, 그 안의 버튼, 체크박스, 입력 그룹에는 영향을 주지 않습니다. 버튼의 스타일도 지정하고 싶다고 해 보겠습니다. 그래서 새 버튼 테마를 만들겠습니다:

```scss
$custom-button: flat-button-theme(
  $foreground: #292826, 
  $disabled-foreground: rgba(255, 255, 255, .54)
);
```

<DocsAside type="info">
방금 한 것처럼 색상 값을 직접 하드코딩하는 대신, <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> 및 <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} /> 함수를 사용하면 색상을 훨씬 유연하게 다룰 수 있습니다. 사용 방법에 대한 자세한 안내는 [`Palettes`](/themes/sass/palettes) 항목을 참조하십시오.
</DocsAside>

이 예제에서는 flat 버튼의 텍스트 색상과 버튼 비활성화 색상만 바꾸었지만, <ApiLink kind="sass" module="themes" type="function-flat-button-theme" label="flat-button-theme" code={true} />은(는) 버튼 스타일을 제어하는 훨씬 많은 매개변수를 제공합니다.

마지막 단계는 `tokens()`으로 각 컴포넌트 테마를 적용하는 것입니다:

```scss
:host {
  @include tokens($custom-column-actions-theme);
  
  .igx-column-actions {
    @include tokens($custom-button);
  }
}
```

<DocsAside type="info">
생성한 **flat-button-theme**을 `.igx-column-actions` 안에 포함하여, 열 숨기기 버튼만 스타일이 지정되도록 하겠습니다. 그렇지 않으면 그리드의 다른 버튼도 영향을 받습니다.
</DocsAside>

<DocsAside type="info">
일부 컴포넌트 템플릿에서는 Emulated View Encapsulation 때문에 생성된 토큰 선언이 중첩된 Ignite UI 요소에 도달하지 못할 수 있습니다. 테마가 적용되지 않으면 아래와 같이 `::ng-deep`을(를) 사용하거나 테마를 전역 스타일시트로 옮기십시오.
</DocsAside>

```scss
:host {
  @include tokens($custom-column-actions-theme);

  ::ng-deep {
    .igx-column-actions {
      @include tokens($custom-button);
    }
  }
}
```

## API 참조

이 문서에서는 Grid 도구 모음의 내장 열 숨기기 UI를 사용하는 방법을 배웠고, 이를 별도의 컴포넌트로도 정의했습니다. 사용자가 서로 다른 열 순서 중에서 선택할 수 있는 UI를 소개했고, 사용자 지정 제목과 필터 안내 문구도 설정했습니다. 또한 추가 Ignite UI for Angular 컴포넌트인 [**IgxRadio**](/inputs/radio) 버튼도 사용했습니다.
