# Angular Grid 행 고정

하나 또는 여러 행을 Angular UI Grid의 위쪽 또는 아래쪽에 고정할 수 있습니다. Ignite UI for Angular의 **행 고정**은 최종 사용자가 특정 순서로 행을 고정할 수 있게 하며, 이때 행은 특별한 영역에 복제되어 Grid을(를) 세로로 스크롤해도 항상 보입니다. Material UI Grid에는 내장된 행 고정 UI가 있으며, 이는 Grid의 맥락에서 `igxActionStrip` 컴포넌트를 초기화하여 활성화합니다. 또한 사용자 지정 UI를 정의하고 행 고정 API를 통해 행의 고정 상태를 바꿀 수도 있습니다.

## 행 고정 UI

내장 행 고정 UI는 `GridPinningActions` 컴포넌트와 함께 `igxActionStrip` 컴포넌트를 추가하여 활성화합니다. Action strip은 행 위에 마우스를 올리면 자동으로 표시되며, 그 행의 상태에 따라 고정 또는 고정 해제 버튼 아이콘을 보여 줍니다. 고정된 각 행에는 고정된 행의 복사본을 화면에 보이도록 스크롤하는 추가 작업도 표시됩니다.

```html
<igx-grid [data]="data" [autoGenerate]="false">
    <igx-column *ngFor="let c of columns" [field]="c.field" [header]="c.field">
    </igx-column>

    <igx-action-strip #actionStrip>
        <igx-grid-pinning-actions></igx-grid-pinning-actions>
        <igx-grid-editing-actions></igx-grid-editing-actions>
    </igx-action-strip>
</igx-grid>
```

## 행 고정 API

행 고정은 <ApiLink kind="interface" type="RowType"/>의 `pinned` 입력을 통해 제어됩니다. 고정된 행은 기본적으로 Grid의 위쪽에 렌더링되며, Grid 본문에서 고정되지 않은 행을 세로로 스크롤해도 고정된 상태를 유지합니다.

```typescript
this.grid.getRowByIndex(0).pinned = true;
```

또한 <ApiLink type="Grid" />의 Grid의 <ApiLink type="Grid" member="pinRow" label="pinRow" /> 또는 <ApiLink type="Grid" member="unpinRow" label="unpinRow" /> 메서드를 사용하여 ID로 레코드를 고정하거나 고정 해제할 수 있습니다:

```typescript
this.grid.pinRow('ALFKI');
this.grid.unpinRow('ALFKI');
```

행 ID는 그리드의 <ApiLink type="Grid" member="primaryKey" label="primaryKey" />로 정의된 기본 키 값이거나 레코드 인스턴스 자체라는 점에 유의하십시오. 두 메서드 모두 각 작업의 성공 여부를 나타내는 불리언 값을 반환합니다. 보통 실패하는 이유는 해당 행이 이미 원하는 상태이기 때문입니다.

행은 마지막으로 고정된 행 아래에 고정됩니다. 고정된 행의 순서를 바꾸려면 <ApiLink type="Grid" member="rowPinning" label="rowPinning" /> 이벤트를 구독하고, 이벤트 인수의 <ApiLink kind="interface" type="IPinRowEventArgs" member="insertAtIndex" /> 속성을 원하는 위치 인덱스로 바꾸면 됩니다.

```html
<igx-grid #grid1 [data]="data" [autoGenerate]="true" (rowPinning)="rowPinning($event)">
</igx-grid>
```

```typescript
public rowPinning(event) {
    event.insertAtIndex = 0;
}
```

## 고정 위치

<ApiLink type="Grid" member="pinning" label="pinning" /> 구성 옵션을 통해 행 고정 위치를 바꿀 수 있습니다. 이를 통해 고정 영역의 위치를 Top 또는 Bottom으로 설정할 수 있습니다.
Bottom으로 설정하면 고정된 행은 고정되지 않은 행 다음에 그리드의 아래쪽에 렌더링됩니다. 고정되지 않은 행은 세로로 스크롤할 수 있고, 고정된 행은 아래쪽에 고정된 상태를 유지합니다.

```html
<igx-grid [data]="data" [autoGenerate]="true" [pinning]="pinningConfig"></igx-grid>
```

```typescript
public pinningConfig: IPinningConfig = { rows: RowPinningPosition.Bottom };
```

## 사용자 지정 행 고정 UI

사용자 지정 UI를 정의하고 관련 API를 통해 행의 고정 상태를 바꿀 수 있습니다.

### 아이콘이 있는 추가 열을 통해

작업 strip 대신, 최종 사용자가 클릭하여 특정 행의 고정 상태를 바꿀 수 있는 고정 아이콘을 모든 행에 표시하고 싶다고 해 보겠습니다.
이는 사용자 지정 아이콘이 들어 있는 셀 템플릿을 가진 추가 열을 추가하여 할 수 있습니다.

```html
<igx-grid [data]="data" [primaryKey]="'ID'" [autoGenerate]="false">
    <igx-column width="70px">
        <ng-template igxCell let-cell="cell" let-val>
            <igx-icon class="pin-icon" (mousedown)="togglePinning(cell.row, $event)">
                {{cell.row.pinned ? 'lock' : 'lock_open'}}
            </igx-icon>
        </ng-template>
    </igx-column>
    <igx-column *ngFor="let c of columns" [field]="c.field" [header]="c.field">
    </igx-column>
</igx-grid>
```

사용자 지정 아이콘을 클릭하면 행의 API 메서드를 사용하여 관련 행의 고정 상태를 바꿀 수 있습니다.

```typescript
public togglePinning(row: IgxGridRow, event) {
    event.preventDefault();
    if (row.pinned) {
        row.unpin();
    } else {
        row.pin();
    }
}
```

### 행 끌기를 통해

고정된 행과 고정되지 않은 행 사이에서 행을 직접 끌어서 놓아 고정 상태를 바꿀 수 있도록 하고 싶다고 해 보겠습니다.
이는 행 끌기 기능을 활성화하고, 드롭할 때 API로 행을 고정하거나 고정 해제하여 달성할 수 있습니다.

먼저 `igxDrop` 디렉티브를 사용하여 그리드를 드롭 영역으로 표시하고, `rowDraggable` 옵션을 통해 행 끌기 기능을 활성화해야 합니다.

```html
<igx-grid [data]="data" [autoGenerate]="true" [rowDraggable]="true"
    [primaryKey]="'ID'" igxDrop (dropped)="onDropAllowed($event)">
</igx-grid>
```

그다음 `dropped` 이벤트를 사용하여 재정렬과 고정/고정 해제 로직을 처리할 수 있습니다.

```typescript
public onDropAllowed(args) {
    const event = args.originalEvent;
    let currRowPinnedIndex;
    const currRowIndex = this.getCurrentRowIndex(this.grid.rowList.toArray(),
        { x: event.clientX, y: event.clientY });
    if (currRowIndex === -1) { return; }

    const currRowID = this.getCurrentRowID(this.grid.rowList.toArray(),
        { x: event.clientX, y: event.clientY });

    const currentRow = this.grid.rowList.toArray().find((r) => r.rowID === currRowID);
    if (currentRow.pinned) {
        currRowPinnedIndex = this.grid.pinnedRows.indexOf(this.grid.pinnedRows.find((r) => r.rowID === currRowID));
    }
    // remove the row that was dragged and place it onto its new location
    this.grid.deleteRow(args.dragData.key);
    this.data.splice(currRowIndex, 0, args.dragData.data);
    if (currentRow.pinned && !args.dragData.pinned) {
        this.grid.pinRow(args.dragData.key, currRowPinnedIndex);
    } else if (!currentRow.pinned && args.dragData.pinned) {
        this.grid.unpinRow(args.dragData.key);
    } else if (currentRow.pinned && args.dragData.pinned) {
        this.grid.unpinRow(args.dragData.key);
        this.grid.pinRow(args.dragData.key, currRowPinnedIndex);
    }
}
```

이렇게 하면 행의 순서를 바꾸고, 행을 고정된 행 컬렉션과 고정되지 않은 행 컬렉션 사이에서 옮길 수 있습니다.

## 행 고정 제한 사항

- 데이터 소스에 존재하는 레코드만 고정할 수 있습니다.
- 행 고정 상태는 Excel로 내보내지지 않습니다. 그리드는 행 고정이 적용되지 않은 것처럼 내보내집니다.
- 고정된 행은 그리드의 고정 영역과 고정되지 않은 영역 모두에 나타날 수 있도록 내부적으로 저장되는 방식 때문에, 그리드의 레코드를 요청 시 원격 엔드포인트에서 가져올 때(원격 가상화) 행 고정은 지원되지 않습니다.
- 그리드의 스크롤 가능한 영역에 있는 고정된 행의 복사본은, 고정된 행이 있을 때 다른 그리드 기능이 동작하는 방식의 필수적인 부분이므로, 그 생성은 비활성화할 수 없고 제거할 수도 없습니다.
- 행 선택은 전적으로 행 ID를 기준으로 작동하므로, 고정된 행을 선택하면 그 복사본도 함께 선택됩니다(그 반대도 마찬가지입니다). 또한 고정 영역 안에서의 범위 선택(예: Shift + 클릭)은 스크롤 가능한 영역에서 행 범위를 선택하는 것과 같은 방식으로 작동합니다. 결과 선택에는 현재 고정되어 있지 않더라도 그 사이의 모든 행이 포함됩니다. API로 선택된 행을 가져오면 선택된 각 레코드의 인스턴스는 하나씩만 반환됩니다.
- 그리드에 `primaryKey`이(가) 설정되어 있지 않고 원격 데이터 시나리오가 활성화되어 있으면(페이징, 정렬, 필터링, 스크롤이 표시할 데이터를 가져오기 위해 원격 서버에 요청을 트리거할 때), 데이터 요청이 완료된 후 행은 다음 상태를 잃게 됩니다:
  - 행 선택
  - 행 펼치기/접기
  - 행 편집
  - 행 고정

## 스타일링

IgxGrid은(는) [`Ignite UI for Angular Theme Library`](/themes/sass/component-themes)을(를) 통한 스타일 지정을 허용합니다. Grid의 <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />은(는) 매우 다양한 속성을 노출하여, Grid의 모든 기능을 사용자 지정할 수 있게 합니다.

아래에서는 Grid의 행 고정 스타일을 사용자 지정하는 단계를 살펴보겠습니다.

### 스타일 라이브러리 가져오기

행 고정 기능의 사용자 지정을 시작하려면 모든 스타일 함수와 믹스인이 있는 `index` 파일을 가져와야 합니다.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### 테마 정의하기

다음으로 <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />을(를) 확장하고 행 고정 기능을 원하는 대로 사용자 지정하는 데 필요한 매개변수를 받는 새 테마를 만듭니다.

```scss
$custom-theme: grid-theme(
  $pinned-border-width: 5px,
  $pinned-border-style: double,
  $pinned-border-color: #ffcd0f,
  $cell-active-border-color: #ffcd0f
);
```

### CSS 변수 사용하기

마지막 단계는 사용자 지정 그리드 테마를 전달하는 것입니다:

```scss
:host {
  @include tokens($custom-theme);
}
```
