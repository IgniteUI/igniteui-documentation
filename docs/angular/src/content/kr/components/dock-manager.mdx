# Dock Manager

Ignite UI Dock Manager 컴포넌트는 패널을 통해 애플리케이션의 레이아웃을 관리하는 수단을 제공하며, 최종 사용자가 패널을 고정하고, 크기를 조정하고, 이동하고, 숨겨서 레이아웃을 더 사용자 지정할 수 있도록 합니다.

## 사용법

Dock Manager는 표준 [웹 컴포넌트](https://developer.mozilla.org/en-US/docs/Web/Web_Components)이며, 따라서 Angular 애플리케이션에서 사용할 수 있습니다.

Dock Manager 패키지를 Angular 프로젝트에 추가하고 컴포넌트를 사용할 수 있도록 설정하려면 아래 단계를 따르십시오.

먼저 `igniteui-dockmanager` 패키지를 설치하십시오

```cmd
npm install igniteui-dockmanager
```

그런 다음 `AppModule`에 `CUSTOM_ELEMENTS_SCHEMA` 스키마를 포함하십시오:

```typescript
import { CUSTOM_ELEMENTS_SCHEMA, NgModule } from '@angular/core';

@NgModule({
    ...
    schemas: [CUSTOM_ELEMENTS_SCHEMA]
})
export class AppModule {}
```

다음으로 `main.ts` 파일에서 `defineComponents()` 함수를 호출해야 합니다:

```typescript
import { AppModule } from './app/app.module';
import { defineComponents } from 'igniteui-dockmanager';
import { enableProdMode } from '@angular/core';
import { environment } from '.environments/environment';
import { platformBrowserDynamic } from '@angular/platform-browser-dynamic';

if (environment.production) {
    enableProdMode();
}

platformBrowserDynamic().bootstrapModule(AppModule)
    .catch(err => console.log(err));

defineComponents(IgcDockManagerComponent);
```

이것으로 끝입니다. 이제 Angular 컴포넌트 템플릿에서 Dock Manager 컴포넌트를 사용할 준비가 되었습니다. 사용하려면 태그 이름을 사용하기만 하면 됩니다:

```html
<igc-dockmanager>
</igc-dockmanager>
```

Dock Manager 컴포넌트의 사용법에 대한 자세한 정보는 [이 항목]({environment:infragisticsBaseUrl}/products/ignite-ui-web-components/web-components/components/dock-manager.html)을 참조하십시오.

Ignite UI for Angular 컴포넌트를 호스팅하는 패널과 함께 Dock Manager 컴포넌트를 사용하는 더 고급 예제는 [데이터 분석 샘플](/general/data-analysis#dockmanager로-데이터-분석하기)의 이 버전을 참조하십시오.
