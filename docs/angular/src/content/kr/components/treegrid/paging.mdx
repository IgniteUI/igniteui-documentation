# Angular Tree Grid 페이지네이션

페이지네이션은 많은 양의 데이터를 비슷한 콘텐츠를 가진 일련의 페이지로 나누는 데 사용됩니다. Angular 테이블 페이지네이션은 사용자 경험과 데이터 상호 작용을 개선합니다. Tree Grid 페이지네이션은 열을 추가하는 것과 비슷하게, `igx-paginator` 태그를 정의하여 그리드 트리에 투영된 별도의 컴포넌트를 통해 구성할 수 있습니다. 모든 Angular 테이블과 마찬가지로, Tree Grid의 페이지네이션은 사용자 지정 페이지를 위한 템플릿을 지원합니다.

## Angular 페이지네이션 예제

다음 예제는 Tree Grid 페이지네이션을 보여 주며, `items per page`의 사용 옵션과 페이징을 활성화하는 방법을 보여 줍니다. 사용자는 "Go to last page" 및 "Go to first page" 버튼을 통해 Tree Grid 페이지 사이를 빠르게 이동할 수도 있습니다.

<Sample src="/tree-grid/treegrid-paging" height={550} alt="Angular 페이지네이션 예제" />

[`igx-paginator`](/paginator) 컴포넌트를 추가하면 그 기능이 존재할지 제어합니다. 토글 속성이 있는 간단한 `@if` 블록으로 기능을 활성화하거나 비활성화할 수 있습니다. <ApiLink type="Paginator" member="perPage" label="perPage" /> 입력은 페이지당 보이는 레코드 수를 제어합니다. Tree Grid을(를) 업데이트하여 페이징을 활성화해 보겠습니다:

```html
<igx-tree-grid #treeGrid [data]="data" [height]="'500px'" [width]="'100%'">
    <igx-paginator [perPage]="10">
    </igx-paginator>
</igx-tree-grid>
```

예:

```html
<igx-paginator #paginator [totalRecords]="20">
    <igx-paginator-content>
        <div id="numberPager" style="justify-content: center;">
            <button [disabled]="paginator.isFirstPage" (click)="paginator.previousPage()" igxButton="flat">
                PREV
            </button>
            <span>
               Page {{paginator.page}} of {{paginator.totalPages}}
            </span>
            <button [disabled]="paginator.isLastPage" (click)="paginator.nextPage()" igxButton="flat">
                NEXT
            </button>
        </div>
    </igx-paginator-content>
</igx-paginator>
```

## 사용법

아래 예제에서는 `igx-paginator` 컴포넌트를 `igx-tree-grid` 컴포넌트와 함께 사용하지만, 페이징 기능이 필요하다면 다른 어떤 컴포넌트와도 사용할 수 있습니다.

```html
<igx-tree-grid #treeGrid [data]="data">
    <igx-paginator #paginator [(page)]="treeGrid.page" [totalRecords]="treeGrid.length" [(perPage)]="10"
            [selectOptions]="selectOptions">
    </igx-paginator>
</igx-tree-grid>
```

## 원격 페이징

원격 페이징은 데이터 가져오기를 담당하는 서비스와, Grid 구성 및 데이터 구독을 담당하는 컴포넌트를 선언하여 구현할 수 있습니다.

더 자세한 정보는 [`Tree Grid Remote Data Operations`](/treegrid/remote-data-operations#원격-페이징) 주제를 확인하십시오.

## 스타일링

paginator의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-paginator-theme" label="paginator-theme" code={true} />을(를) 확장하고 `$foreground`, `$background`, `$border-color` 및 `$accent-color` 매개변수를 받는 새 테마를 만듭니다.

```scss
$paginator-theme: paginator-theme(
  $foreground: #ff570f,
  $background: #130425FF,
  $border-color: #ff570f,
  $accent-color: #ff570f,
);
```

그다음 새로 만든 테마를 **포함**할 수 있습니다.

```scss
igx-paginator {
  @include tokens($paginator-theme);
}
```
