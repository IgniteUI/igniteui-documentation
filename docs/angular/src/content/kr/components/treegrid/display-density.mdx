# Angular Tree Grid 크기

**IgxTreeGrid** 디자인은 [Material Design 지침](https://material.io/design)을 기반으로 합니다. 현재 작은, 중간, 큰 보기를 각각 제공하는 미리 정의된 크기 옵션 집합 중에서 선택할 수 있는 옵션을 제공합니다. Material UI 테이블/Material UI 그리드에 맞는 크기를 선택하면, 많은 양의 콘텐츠와 상호 작용할 때 사용자 경험을 크게 개선할 수 있습니다.

## 사용법

위 데모에서 볼 수 있듯이, <ApiLink type="TreeGrid" />은(는) 세 가지 크기 옵션, 즉 **작음**, **중간**, **큼**을 제공합니다. 아래 코드 조각은 크기를 설정하는 방법을 보여 줍니다:

```html
<igx-tree-grid #treeGrid [data]="data" style="--ig-size: var(--ig-size-small)">
</igx-tree-grid>
```

이제 각 옵션이 Tree Grid 컴포넌트에 어떻게 반영되는지 자세히 살펴보겠습니다. 서로 다른 크기로 바꾸면 각 Tree Grid 요소의 높이와 해당 패딩이 바뀝니다. 또한 사용자 지정 열 <ApiLink type="Column" member="width" label="**width**" />을(를) 적용하고 싶다면, 그 값은 왼쪽과 오른쪽 패딩의 합보다 커야 한다는 점을 고려하십시오.

- **--ig-size-large** - 가장 낮은 밀도이며 행 높이가 `50px`인 기본 Tree Grid 크기입니다. 왼쪽 및 오른쪽 패딩은 `24px`이고, 최소 열 <ApiLink type="Column" member="width" label="width" />은(는) `80px`입니다;
- **--ig-size-medium** - `40px` 행 높이를 가진 중간 크기입니다. 왼쪽 및 오른쪽 패딩은 `16px`이고, 최소 열 <ApiLink type="Column" member="width" label="width" />은(는) `64px`입니다;
- **--ig-size-small** - `32px` 행 높이를 가진 가장 작은 크기입니다. 왼쪽 및 오른쪽 패딩은 `12px`이고, 최소 열 <ApiLink type="Column" member="width" label="width" />은(는) `56px`입니다;

<DocsAside type="info">
현재는 어떤 크기도 재정의할 수 **없다는** 점을 기억하십시오.
</DocsAside>

이제 샘플을 계속 진행하면서 각 크기가 실제로 적용되는 모습을 보겠습니다. 먼저 각 크기 사이를 전환하는 데 도움이 되는 버튼을 추가하겠습니다:

```html
<div class="density-chooser">
    <igx-buttongroup [values]="sizes"></igx-buttongroup>
</div>
```

```typescript
@ViewChild(IgxButtonGroupComponent) public buttonGroup: IgxButtonGroupComponent;
public size = 'small';
public sizes;

public ngOnInit() {
    this.sizes = [
        {
            label: 'small',
            selected: this.size === 'small',
            togglable: true
        },
        {
            label: 'medium',
            selected: this.size === 'medium',
            togglable: true
        },
        {
            label: 'large',
            selected: this.size === 'large',
            togglable: true
        }
    ];
}
```

마지막으로 실제로 크기를 적용하기 위한 로직을 제공하겠습니다:

```typescript
@ViewChild('treeGrid', { read: IgxTreeGridComponent })
public treeGrid: IgxTreeGridComponent;

public selectSize(event: any) {
    this.size = this.sizes[event.index].label;
}

@HostBinding('style.--ig-size')
protected get sizeStyle() {
    return `var(--ig-size-${this.size})`;
}
```

<ApiLink type="TreeGrid" />이(가) Tree Grid의 행 높이를 바꿀 수 있게 하는 또 다른 옵션은 <ApiLink type="TreeGrid" member="rowheight" label="rowHeight" /> 속성입니다. 그러면 이 속성이 Tree Grid 레이아웃에 `--ig-size` CSS 변수와 함께 어떻게 영향을 주는지 실제로 보겠습니다.

다음 사항을 기억하십시오:

- `--ig-size` CSS 변수는 **지정된 <ApiLink type="TreeGrid" member="rowheight" label="rowHeight" />가 있으면** 행 높이에 **영향을 주지 않습니다**;
- `--ig-size`은(는) 위에서 설명한 것처럼 **Tree Grid의 나머지 모든 요소에 영향을 줍니다**;

이제 샘플을 확장하여 Tree Grid에 <ApiLink type="TreeGrid" member="rowHeight" label="rowHeight" /> 속성을 추가할 수 있습니다:

 ```html
 <igx-tree-grid #treeGrid [data]="data" [rowHeight]="'80px'" width="100%" 
 height="550px" [allowFiltering]="true">
 ..............
 </igx-tree-grid>
 ```
