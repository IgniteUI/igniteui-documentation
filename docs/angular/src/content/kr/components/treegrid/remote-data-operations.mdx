# Angular Tree Grid 원격 데이터 작업

Ignite UI for Angular Tree Grid은(는) 원격 가상화, 원격 정렬, 원격 필터링 등 원격 데이터 작업을 지원합니다. 이를 통해 개발자는 서버에서 이러한 작업을 수행하고, 생성된 데이터를 가져와 Tree Grid에 표시할 수 있습니다.

## Angular Tree Grid 원격 데이터 작업 개요 예제

<Sample src="/tree-grid/treegrid-remote-filtering" height={550} alt="Angular Tree Grid 원격 데이터 작업 개요 예제" />

기본적으로 Tree Grid은(는) 데이터 작업을 수행하기 위해 자체 로직을 사용합니다.
Tree Grid이(가) 노출하는 특정 입력과 이벤트를 활용하여 이러한 작업을 원격으로 수행하고, 그 결과 데이터를 Tree Grid에 전달할 수 있습니다.

### 원격 필터링

원격 필터링을 제공하려면, 받은 인수에 따라 적절한 요청을 하도록 <ApiLink type="TreeGrid" member="filteringExpressionsTreeChange" label="filteringExpressionsTreeChange" /> 출력을 구독해야 합니다. <ApiLink type="TreeGrid" member="primaryKey" label="primaryKey" />와 <ApiLink type="TreeGrid" member="foreignKey" label="foreignKey" />을(를) 제공하여 평면 컬렉션을 Tree Grid의 데이터 소스로 사용해 보겠습니다.

또한 **rxjs**의 `debounceTime` 함수를 활용합니다. 이 함수는 원본 Observable에서 다른 발행 없이 특정 시간이 지난 후에만 값을 발행합니다. 이렇게 하면 사용자가 중간에 끼어들지 않고 지정된 시간이 지났을 때만 원격 작업이 트리거됩니다.

```typescript
const DEBOUNCE_TIME = 300;
...
public ngAfterViewInit() {
    ...
    this.treeGrid.filteringExpressionsTreeChange.pipe(
        debounceTime(DEBOUNCE_TIME),
        takeUntil(this.destroy$)
    ).subscribe(() => {
        this.processData();
    });
}
```

원격 필터링이 제공되는 경우 보통 Tree Grid의 내장 필터링은 필요하지 않습니다. Tree Grid의 <ApiLink type="TreeGrid" member="filterStrategy" label="filterStrategy" /> 입력을 `NoopFilteringStrategy` 인스턴스로 설정하여 이를 비활성화할 수 있습니다.

```html
<!-- tree-grid-remote-filtering-sample.html -->

<igx-tree-grid #treeGrid [data]="remoteData | async" primaryKey="ID" foreignKey="ParentID"
               [autoGenerate]="false"
               [filterStrategy]="noopFilterStrategy"
               [allowFiltering]="true">
    <igx-column [field]="'Name'" dataType="string"></igx-column>
    <igx-column [field]="'Title'" dataType="string"></igx-column>
    <igx-column [field]="'Age'" dataType="number"></igx-column>
</igx-tree-grid>
```

```typescript
// tree-grid-remote-filtering-sample.ts

public noopFilterStrategy = NoopFilteringStrategy.instance();

public processData() {
    this.treeGrid.isLoading = true;

    const filteringExpr = this.treeGrid.filteringExpressionsTree;

    this._remoteService.getData(filteringExpr, () => {
        this.treeGrid.isLoading = false;
    });
}
```

원격 필터링은 평면 컬렉션에 직접 수행해야 합니다. 또한 상위 항목이 필터링과 일치하는지와 관계없이, 필터링 조건과 일치하는 모든 레코드의 상위 항목을 모두 포함해야 합니다(계층 구조를 온전하게 유지하기 위해서입니다). 결과는 아래에서 볼 수 있습니다:

</DocsAside>

### 고유 열 값 전략

Excel 스타일 필터링 대화 상자 안의 목록 항목은 각 열의 고유 값을 나타냅니다. Tree Grid은(는) 기본적으로 데이터 소스를 기준으로 이 값들을 생성합니다. 원격 필터링의 경우, 그리드 데이터에는 서버의 모든 데이터가 들어 있지 않습니다. 고유 값을 수동으로 제공하고 필요할 때 로드하려면, Tree Grid의 <ApiLink type="TreeGrid" member="uniqueColumnValuesStrategy" label="uniqueColumnValuesStrategy" /> 입력을 활용할 수 있습니다. 이 입력은 실제로 세 개의 인수를 제공하는 메서드입니다:

- **column** - 해당 열 인스턴스입니다.
- **filteringExpressionsTree** - 해당 열을 기준으로 축소된 필터링 식 트리입니다.
- **done** - 서버에서 새로 생성된 열 값을 가져왔을 때 그 값과 함께 호출해야 하는 콜백입니다.

개발자는 **column** 및 **filteringExpressionsTree** 인수가 제공하는 정보를 기준으로 필요한 고유 열 값을 수동으로 생성한 다음 **done** 콜백을 호출할 수 있습니다.

<DocsAside type="info">
<ApiLink type="TreeGrid" member="uniqueColumnValuesStrategy" label="uniqueColumnValuesStrategy" /> 입력이 제공되면, Excel 스타일 필터링의 기본 고유 값 생성 프로세스는 사용되지 않습니다.
</DocsAside>

```html
<igx-tree-grid #treeGrid [data]="data" [filterMode]="'excelStyleFilter'" [uniqueColumnValuesStrategy]="columnValuesStrategy">
    ...
</igx-tree-grid>
```

```typescript
public columnValuesStrategy = (column: ColumnType,
                               columnExprTree: IFilteringExpressionsTree,
                               done: (uniqueValues: any[]) => void) => {
    // Get specific column data.
    this.remoteValuesService.getColumnData(column, columnExprTree, uniqueValues => done(uniqueValues));
}
```

## 원격 페이징

이 샘플에서는 하위 레코드가 얼마나 많든 상관없이 페이지마다 특정 수의 루트 레코드를 표시하는 방법을 보여 줍니다. 레벨(루트 또는 하위)과 관계없이 특정 수의 레코드를 표시하는 Tree Grid의 내장 페이징 알고리즘을 취소하려면 <ApiLink type="Paginator" member="perPage" label="perPage" /> 속성을 `Number.MAX_SAFE_INTEGER`(으)로 설정해야 합니다.

```html
<igx-tree-grid #treeGrid ...>
        <igx-paginator [perPage]="maxPerPage">
        </igx-paginator>
...
```

```typescript
public maxPerPage = Number.MAX_SAFE_INTEGER;
```

이제 `igx-paginator`이(가) 제공하는 기본 페이징 템플릿을 사용하거나, 직접 _사용자 지정 페이징 템플릿_을 설정할 수 있습니다. 먼저 _기본 페이징 템플릿_을 사용하여 원격 페이징을 설정하는 데 무엇이 필요한지 살펴보겠습니다.

### 기본 템플릿을 사용하는 원격 페이징

_기본 페이징 템플릿_을 사용하려면 Paginator의 <ApiLink type="Paginator" member="totalRecords" label="totalRecords" /> 속성을 설정해야 합니다. 그래야 그리드가 원격 레코드 전체를 기준으로 _전체 페이지 수_를 계산할 수 있습니다. 원격 페이지네이션을 수행할 때 Paginator는 현재 페이지의 데이터만 그리드에 전달하므로, 그리드는 제공된 데이터 소스를 페이지로 나누려고 하지 않습니다. 따라서 그리드의 <ApiLink type="TreeGrid" member="pagingMode" label="pagingMode" /> 속성을 _GridPagingMode.remote_로 설정해야 합니다. 또한 원격 서비스에서 데이터를 가져오기 위해 <ApiLink type="Paginator" member="pagingDone" label="pagingDone" /> 또는 <ApiLink type="Paginator" member="perPageChange" label="perPageChange" /> 이벤트를 구독해야 하며, 어떤 이벤트를 사용할지는 사용 사례에 따라 다릅니다.

```html
<igx-tree-grid #treeGrid [data]="data | async" childDataKey="Content" [pagingMode]="mode">
    <igx-column field="Name"></igx-column>
    ...
    <igx-paginator [(page)]="page" [(perPage)]="perPage" [totalRecords]="totalCount"
        (pagingDone)="paginate($event.current)">
    </igx-paginator>
</igx-tree-grid>
```

```typescript
public totalCount = 0;
public data: Observable<any[]>;
public mode = GridPagingMode.remote;
public isLoading = true;
@ViewChild('grid1', { static: true }) public grid1: IgxGridComponent;

private _dataLengthSubscriber;

public set perPage(val: number) {
    this._perPage = val;
    this.paginate(0);
}

public ngOnInit() {
    this.data = this.remoteService.remoteData.asObservable();

    this._dataLengthSubscriber = this.remoteService.getDataLength().subscribe((data: any) => {
        this.totalCount = data;
        this.grid1.isLoading = false;
    });
}

public ngAfterViewInit() {
    const skip = this.page * this.perPage;
    this.remoteService.getData(skip, this.perPage);
}

public paginate(page: number) {
    this.page = page;
    const skip = this.page * this.perPage;
    const top = this.perPage;

    this.remoteService.getData(skip, top);
}
```

### 사용자 지정 igx-paginator-content가 있는 원격 페이징

사용자 지정 paginator 콘텐츠를 정의할 때는, 요청된 페이지에 대한 데이터만 가져오도록 콘텐츠를 정의하고, 선택된 페이지와 항목 <ApiLink type="Paginator" member="perPage" label="perPage" />에 따라 원격 서비스에 올바른 **skip** 및 **top** 매개변수를 전달해야 합니다. 예제 구성을 쉽게 하기 위해 `<igx-paginator>`을(를) 사용하겠습니다. 그리고 소개된 <ApiLink type="PageSizeSelector" />와 <ApiLink type="PageNavigation" />도 함께 사용합니다 - `igx-page-size`은(는) 페이지당 드롭다운과 레이블을 추가하고, `igx-page-nav`은(는) 탐색 작업 버튼과 레이블을 추가합니다.

```html
<igx-paginator #paginator
    [totalRecords]="totalCount"
    [(perPage)]="perPage"
    [selectOptions]="selectOptions"
    (pageChange)="paginate($event)">
    <igx-paginator-content>
        <igx-page-size></igx-page-size>
        [This is my custom content]
        <igx-page-nav></igx-page-nav>
    </igx-paginator-content>
</igx-paginator>
```

```typescript
public paginate(page: number) {
    this.page = page;
    const skip = this.page * this.perPage;
    const top = this.perPage;

    this.remoteService.getData(skip, top);
}
```

<DocsAside type="info">
원격 페이징이 올바르게 구성되려면 `GridPagingMode.Remote`을(를) 설정해야 합니다:
</DocsAside>

```html
<igx-tree-grid #treeGrid [data]="data | async" childDataKey="Content"
        expansionDepth="0" width="100%" height="540px" [pagingMode]="mode"></igx-tree-grid>
...
public mode = GridPagingMode.Remote;
```

마지막 단계는 요구 사항에 따라 paginator 콘텐츠를 선언하는 것입니다.

```html
<igx-paginator-content>
    <igx-page-size></igx-page-size>
    [This is my custom content]
    <igx-page-nav></igx-page-nav>
</igx-paginator-content>
```

## 알려진 문제와 제한 사항

- 그리드에 `primaryKey`이(가) 설정되어 있지 않고 원격 데이터 시나리오가 활성화되어 있으면(페이징, 정렬, 필터링, 스크롤이 표시할 데이터를 가져오기 위해 원격 서버에 요청을 트리거할 때), 데이터 요청이 완료된 후 행은 다음 상태를 잃게 됩니다:
  - 행 선택
  - 행 펼치기/접기
  - 행 편집
  - 행 고정
- 원격 데이터 시나리오에서 그리드에 `primaryKey`이(가) 설정되어 있으면, 현재 데이터 뷰 밖에 있는 행에 대해 <ApiLink kind="interface" type="IRowSelectionEventArgs" member="oldSelection" /> 이벤트 인수는 행 데이터 객체 전체를 담지 않습니다. 이 경우 `rowSelectionChanging.oldSelection` 객체는 `primaryKey` 필드 하나만 가집니다. 현재 데이터 뷰에 있는 나머지 행에 대해서는 `rowSelectionChanging.oldSelection`에 행 데이터 전체가 들어 있습니다.
