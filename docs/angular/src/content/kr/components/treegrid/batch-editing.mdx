# Angular Tree Grid 일괄 편집 및 트랜잭션

IgxTreeGrid의 일괄 편집 기능은 <ApiLink kind="interface" type="HierarchicalTransactionService" />를 기반으로 합니다. `igxHierarchicalTransactionService`의 개요와 그 구현 세부 사항은 [`Transaction Service class hierarchy`](../transaction-classes.mdx) 주제를 따라 확인하십시오.

다음은 Tree Grid 컴포넌트에서 일괄 편집을 활성화하는 방법에 대한 자세한 예제입니다.

## Angular Tree Grid 일괄 편집 및 트랜잭션 예제

다음 샘플은 treeGrid에 <ApiLink type="TreeGrid" member="batchEditing" label="batchEditing" />가 활성화되어 있고 행 편집도 활성화된 시나리오를 보여 줍니다. 후자는 행 편집 전체가 확정된 후에 트랜잭션이 추가되도록 보장합니다.

<Sample src="/tree-grid/treegrid-batchediting" height={600} alt="Angular Tree Grid 일괄 편집 및 트랜잭션 예제" />

<DocsAside type="info">
트랜잭션 상태는 업데이트, 추가, 삭제된 모든 행과 그 마지막 상태로 구성됩니다.
</DocsAside>

## 사용법

시작하려면 **app.module.ts** 파일에서 `IgxTreeGridModule`을(를) 가져오십시오:

```typescript
// app.module.ts

...
import { IgxTreeGridModule } from 'igniteui-angular';

@NgModule({
    ...
    imports: [..., IgxTreeGridModule],
    ...
})
export class AppModule {}
```

그런 다음 Tree Grid에서 `batchEditing`을(를) 활성화하기만 하면 됩니다:

```html
<igx-tree-grid [data]="data" [batchEditing]="true">
  ...
</igx-tree-grid>
```

이렇게 하면 igx-tree-grid에 대해 올바른 `Transaction` 서비스 인스턴스가 제공됩니다. 올바른 `TransactionService`은(는) `TransactionFactory`을(를) 통해 제공됩니다. 이 내부 구현에 대해서는 [트랜잭션 주제](/transaction-classes#transaction-factory)에서 더 자세히 알아볼 수 있습니다.

일괄 편집이 활성화된 후에는 바인딩된 데이터 소스와 <ApiLink type="TreeGrid" member="rowEditable" label="rowEditable" />를 true로 설정하여 `IgxTreeGrid`을(를) 정의하고 바인딩하십시오:

```html
<igx-tree-grid #treeGrid [batchEditing]="true" [data]="data" primaryKey="employeeID" foreignKey="PID"
    width ="100%" height ="500px" rowEditable=true>
    ...
</igx-tree-grid>
...
    <button igxButton (click)="addRow()">Add Root Level Row</button>
    <button igxButton [disabled]="!treeGrid.transactions.canUndo" (click)="undo()">Undo</button>
    <button igxButton [disabled]="!treeGrid.transactions.canRedo" (click)="redo()">Redo</button>
    <button igxButton [disabled]="treeGrid.transactions.getAggregatedChanges(false).length < 1"
        (click)="openCommitDialog()">Commit</button>
...
```

다음 코드는 <ApiLink kind="interface" type="HierarchicalTransactionService" /> API - 실행 취소, 다시 실행, 커밋 - 의 사용법을 보여 줍니다.

```typescript
export class TreeGridBatchEditingSampleComponent {
    @ViewChild('treeGrid', { read: IgxTreeGridComponent }) public treeGrid: IgxTreeGridComponent;

    public undo() {
        /* exit edit mode and commit changes */
        this.treeGrid.endEdit(true);
        this.treeGrid.transactions.undo();
    }

    public redo() {
        /* exit edit mode and commit changes */
        this.treeGrid.endEdit(true);
        this.treeGrid.transactions.redo();
    }

    public commit() {
        this.treeGrid.transactions.commit(this.data);
        this.dialog.close();
    }
}
```

<DocsAside type="info">
트랜잭션 API는 편집 종료를 처리하지 않으므로, 직접 처리해야 합니다. 그렇지 않으면 `Tree Grid`이(가) 편집 모드에 머무르게 됩니다. 한 가지 방법은 해당 메서드에서 <ApiLink type="Grid" member="endEdit" label="endEdit" />을(를) 호출하는 것입니다.
</DocsAside>

`Tree Grid`에서 상위 노드를 삭제할 때는 몇 가지 특이점이 있습니다. 계층형 데이터를 사용하고 있다면, 상위를 삭제할 때 자식도 함께 삭제됩니다. 평면 데이터를 사용하고 있다면, `Tree Grid`의 <ApiLink type="TreeGrid" member="cascadeOnDelete" label="cascadeOnDelete" /> 속성을 사용하여 원하는 동작을 설정할 수 있습니다. 이 속성은 상위 레코드가 삭제될 때 자식 레코드도 삭제해야 하는지를 나타냅니다(기본적으로 `true`(으)로 설정되어 있습니다).

<DocsAside type="info">
<ApiLink type="TreeGrid" member="rowEditable" label="rowEditable" /> 속성을 비활성화하면 `Tree Grid`이(가) 변경되어 셀 변경 시 트랜잭션을 만들며, UI에 행 편집 오버레이는 표시되지 않습니다.
</DocsAside>
