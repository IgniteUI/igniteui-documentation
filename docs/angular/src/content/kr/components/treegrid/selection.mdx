# Angular Tree Grid 선택

Ignite UI for Angular Tree Grid을(를) 사용하면 다양한 이벤트, 풍부한 API 또는 단일 선택 같은 간단한 마우스 상호 작용으로 데이터를 쉽게 선택할 수 있습니다.

## Angular Grid 선택 옵션

Ignite UI for Angular Tree Grid 컴포넌트는 세 가지 선택 모드를 제공합니다 - [행 선택](/treegrid/row-selection), [셀 선택](/treegrid/cell-selection) 및 [열 선택](/treegrid/column-selection). 기본적으로 Tree Grid에서는 **다중 셀 선택** 모드만 활성화되어 있습니다. 선택 모드를 바꾸거나 활성화하려면 <ApiLink type="Grid" member="rowSelection" label="rowSelection" />, <ApiLink type="Grid" member="cellSelection" label="cellSelection" /> 또는 <ApiLink type="Column" member="selectable" label="selectable" /> 속성을 사용할 수 있습니다.

### Angular 행 선택

<ApiLink type="Grid" member="rowSelection" label="rowSelection" /> 속성을 사용하면 다음 옵션을 지정할 수 있습니다:

- none - Tree Grid에 대해 행 선택이 비활성화됩니다
- single - Tree Grid 안에서 한 행만 선택할 수 있습니다
- multiple - `Row selectors`을 사용하여 다중 행 선택을 할 수 있으며, <kbd>ctrl</kbd> + <kbd>클릭</kbd>과 같은 키 조합을 사용하거나, 셀에 포커스가 있을 때 <kbd>space 키</kbd>를 한 번 누르면 됩니다

- multipleCascade - 연쇄 선택 모드입니다. 사용자가 상호 작용으로 선택한 레코드 아래 트리의 모든 자식이 선택됩니다. 이 모드에서 부모의 선택 상태는 전적으로 자식들의 선택 상태에 따라 달라집니다.

> 자세한 내용은 [행 선택 주제](/treegrid/row-selection)로 이동하십시오.

### Angular 셀 선택

<ApiLink type="Grid" member="cellSelection" label="cellSelection" /> 속성을 사용하면 다음 옵션을 지정할 수 있습니다:

- none - Tree Grid에 대해 셀 선택이 비활성화됩니다
- single - Tree Grid 안에서 한 셀만 선택할 수 있습니다.
- multiple - 현재 Tree Grid의 선택 기본 상태입니다. 왼쪽 마우스 버튼을 계속 누른 상태에서 셀 위로 마우스를 드래그하면 다중 셀 선택이 가능합니다.

> 자세한 내용은 [셀 선택 주제](/treegrid/cell-selection)로 이동하십시오.

### Angular 열 선택

<ApiLink type="Column" member="selectable" label="selectable` 속성" />을(를) 사용하면 각 **열**에 대해 다음 옵션을 지정할 수 있습니다:

- false - Tree Grid에 대해 해당 열 선택이 비활성화됩니다
- true - Tree Grid에 대해 해당 열 선택이 활성화됩니다
- 이로 인해 다음 세 가지 변형이 생깁니다:
- 단일 선택 - 열 셀 위에서 <kbd>마우스 클릭</kbd>.
- 다중 열 선택 - 열 셀 위에서 <kbd>ctrl</kbd> + <kbd>마우스 클릭</kbd>을 누른 상태로 유지.
- 범위 열 선택 - <kbd>shift</kbd> + <kbd>마우스 클릭</kbd>을 누른 상태로 유지하면 그 사이의 모든 항목이 선택됩니다.

> 자세한 내용은 [열 선택 주제](/treegrid/column-selection)로 이동하십시오.

## 알려진 문제와 제한 사항

- 선택이 활성화된 상태에서 Tree Grid을(를) IE11에서 사용하려면, Angular 애플리케이션의 polyfill.ts에서 배열 polyfill을 명시적으로 가져와야 합니다. IE11은 버전 13.0.0부터 더 이상 지원되지 않습니다.

    ```typescript
    import 'core-js/es7/array';
    ```

- 그리드에 `primaryKey`이(가) 설정되어 있지 않고 원격 데이터 시나리오가 활성화되어 있으면(페이징, 정렬, 필터링, 스크롤이 표시할 데이터를 가져오기 위해 원격 서버에 요청을 트리거할 때), 데이터 요청이 완료된 후 행은 다음 상태를 잃게 됩니다:
  - 행 선택
  - 행 펼치기/접기
  - 행 편집
  - 행 고정
