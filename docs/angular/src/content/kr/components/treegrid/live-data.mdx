# Angular Tree Grid 실시간 데이터 업데이트

Tree Grid 컴포넌트는 초당 수천 건의 업데이트를 처리하면서도 사용자 상호 작용에 반응성을 유지할 수 있습니다.

## Angular 실시간 데이터 업데이트 예제

아래 샘플은 모든 레코드가 초당 여러 번 업데이트될 때 Tree Grid의 성능을 보여 줍니다. UI 컨트롤을 사용하여 로드할 레코드 수와 업데이트 빈도를 선택하십시오.
같은 데이터를 [꺾은선형 차트](/charts/types/line-chart)에 넣으면 Ignite UI for Angular의 강력한 차트 기능을 체험할 수 있습니다. `Chart` 버튼은 선택된 행의 `Category Prices per Region` 데이터를 보여 주며, `Chart` 열 버튼은 현재 행에 대해 같은 데이터를 보여 줍니다.
