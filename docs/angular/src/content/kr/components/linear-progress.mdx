# Angular Linear Progress 컴포넌트 개요

<div class="highlight">
Ignite UI for Angular Linear Progress Bar Indicator 컴포넌트는 애플리케이션 프로세스가 변화할 때 그 진행 상황을 시각적으로 보여 줍니다. 표시기는 상태가 바뀔 때 모양이 업데이트됩니다. 표시기는 줄무늬 또는 단색으로 여러 색상을 선택하여 스타일을 지정할 수 있습니다.
</div>

## Ignite UI for Angular Linear Progress 시작하기

Ignite UI for Angular Linear Progress 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxProgressBarModule`을 가져오는 것입니다:

```typescript
// app.module.ts

...
import { IgxProgressBarModule } from 'igniteui-angular/progressbar';
// import { IgxProgressBarModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxProgressBarModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxLinearProgressBarComponent`을 독립형(standalone) 종속성으로 가져올 수 있으며, [`IGX_LINEAR_PROGRESS_BAR_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/progressbar/src/progressbar/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수도 있습니다.

```typescript
// home.component.ts

import { IGX_LINEAR_PROGRESS_BAR_DIRECTIVES } from 'igniteui-angular/progressbar';
// import { IGX_LINEAR_PROGRESS_BAR_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: '<igx-linear-bar [value]="progress"></igx-linear-bar>',
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IGX_LINEAR_PROGRESS_BAR_DIRECTIVES],
  /* or imports: [IgxLinearProgressBarComponent] */
})
export class HomeComponent {
  public progress = 50;
}
```

이제 Ignite UI for Angular Progress Bar 모듈 또는 디렉티브를 가져왔으므로, `igx-linear-bar` 컴포넌트를 사용하기 시작할 수 있습니다.

## Angular Linear Progress 사용하기

모든 것이 어떻게 동작하는지 더 잘 이해하려면, 데모와 같은 간단한 예제를 만들어 보겠습니다:

```html
<igx-linear-bar [value]="100"></igx-linear-bar>
```

그 후 브라우저에서 데모 샘플을 볼 수 있을 것입니다.

### 진행률 유형

<ApiLink type="LinearProgressBar" member="type" label="type" /> 속성을 사용하여 막대의 유형을 설정할 수 있습니다. 선형 진행률 막대에는 다섯 가지 유형이 있습니다 - `default`, `error`, `success`, `info`, `warning`.

### 줄무늬 진행률

<ApiLink type="LinearProgressBar" member="striped" label="striped" /> 속성을 `true`(으)로 설정하면 막대에 줄무늬를 줄 수 있습니다.

줄무늬가 있거나 없을 수 있는 여러 유형의 진행률 막대를 만드는 방법을 살펴보겠습니다.

```html
<div class="linear-container">

  <igx-linear-bar [value]="100" type="default"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="success" [striped]="true"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="error"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="info" [striped]="true"></igx-linear-bar>
  <igx-linear-bar [value]="100" type="warning"></igx-linear-bar>
</div>
```


모든 것을 올바르게 설정했다면 브라우저에서 다음을 볼 수 있을 것입니다:

### 불확정 진행률

정확하게 결정되지 않은 과정을 추적하려면 <ApiLink type="LinearProgressBar" member="indeterminate" label="indeterminate" /> 입력 속성을 `true`로 설정할 수 있습니다.

### 애니메이션 지속 시간

<ApiLink type="LinearProgressBar" member="animationDuration" label="animationDuration" /> 입력 속성은 애니메이션 주기가 얼마나 걸려야 하는지 지정하는 데 사용됩니다.

다음 예제에서는 애니메이션 지속 시간을 5초로 설정합니다.

```html
<igx-linear-bar [striped]="false" [value]="100" [animationDuration]="5000"></igx-linear-bar>
```

### 텍스트 속성

<ApiLink type="LinearProgressBar" member="textAlign" label="textAlign" /> 속성을 사용하여 텍스트를 정렬할 수 있습니다. 허용되는 값은 `left`, `center`, `right`입니다.

텍스트를 숨기려면 <ApiLink type="LinearProgressBar" member="textVisibility" label="textVisibility" /> 속성을 사용하고 값을 `false`(으)로 설정하십시오.

텍스트를 막대 위로 옮기려면 <ApiLink type="LinearProgressBar" member="textTop" label="textTop" /> 속성을 `true`(으)로 설정하십시오.

<ApiLink type="LinearProgressBar" member="text" label="text" /> 속성을 사용하여 텍스트 자체의 값을 사용자 지정할 수 있습니다.

앞서 만든 예제를 위의 텍스트 속성을 사용하도록 업데이트해 보겠습니다. 또한 불확정 진행률 막대도 함께 추가하겠습니다.

```html
<div class="linear-container">

  <igx-linear-bar type="default" [value]="100"></igx-linear-bar>
  <igx-linear-bar
    type="success"
    [value]="100"
    class="indeterminate"
    [indeterminate]="true"
    [striped]="true"
  ></igx-linear-bar>
  <igx-linear-bar
    type="error"
    [value]="100"
    [textAlign]="positionEnd"
    [text]="'Custom text'"
  ></igx-linear-bar>
  <igx-linear-bar
    type="info"
    [value]="100"
    [textVisibility]="false"
    [striped]="true"
  ></igx-linear-bar>
  <igx-linear-bar
    type="warning"
    [value]="100"
    [textTop]="true"
  ></igx-linear-bar>
</div>
```

`textAlign` 속성을 사용하는 경우 컴포넌트에서 <ApiLink type="IgxTextAlign" kind="variable" /> 열거형을 가져오는 것을 잊지 마십시오.

```typescript
import { ..., IgxTextAlign } from 'igniteui-angular/progressbar';
// import { ..., IgxTextAlign } from '@infragistics/igniteui-angular'; for licensed package
...

public positionCenter: IgxTextAlign = IgxTextAlign.CENTER;
public positionEnd: IgxTextAlign = IgxTextAlign.END;
```

<DocsAside type="info">
<ApiLink type="LinearProgressBar" member="step" label="step" /> 입력 값이 정의되지 않은 경우, 진행률 업데이트는 **<ApiLink type="LinearProgressBar" member="max" label="max" /> 값의 1%**입니다. 진행을 더 빠르게 하려면 <ApiLink type="LinearProgressBar" member="step" label="step" /> 값이 (**<ApiLink type="LinearProgressBar" member="max" label="max" /> * 1%**)보다 커야 합니다. 반대로 더 느리게 진행하려면 <ApiLink type="LinearProgressBar" member="step" label="step" /> 값이 기본 진행률 업데이트보다 작아야 합니다.
</DocsAside>

<DocsAside type="info">
<ApiLink type="LinearProgressBar" member="step" label="step" /> 값을 <ApiLink type="LinearProgressBar" member="value" label="value" /> 입력보다 크게 정의하면 업데이트가 한 번만 일어나며, 이때 **진행률 업데이트로 전달된 값**이 적용됩니다.
</DocsAside>

### 동적 진행률

버튼 같은 외부 컨트롤을 사용하여 진행률 막대의 값을 동적으로 바꿀 수 있습니다. 이를 위해 값을 클래스 속성에 바인딩하겠습니다:

```html
<div class="linear-container">

  <igx-linear-bar [value]="currentValue" [max]="100"></igx-linear-bar>

  <div class="button-container">

    <button igxIconButton="flat" (click)="decrementProgress()">
      <igx-icon fontSet="material">remove</igx-icon>
    </button>
    <button igxIconButton="flat" (click)="incrementProgress()">
      <igx-icon fontSet="material">add</igx-icon>
    </button>
  
</div>
</div>
```

<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

값을 증가시키고 감소시키는 메서드를 만드십시오:

```typescript
public currentValue: number;

public ngOnInit() {
    this.currentValue = 0;
}

public incrementProgress() {
    this.currentValue += 10;
    if (this.currentValue > 100) {
        this.currentValue = 100;
    }
}

public decrementProgress() {
    this.currentValue -= 10;
    if (this.currentValue < 0) {
        this.currentValue = 0;
    }
}
```

## 스타일링

선형 진행률 막대의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-progress-linear-theme" label="progress-linear-theme" code={true} />을(를) 확장하고 `$fill-color-default` 및 `$text-color` 매개변수를 재정의하는 새 테마를 만듭니다.

```scss
$custom-theme: progress-linear-theme(
  $fill-color-default: #ecaa53,
  $text-color: #ecaa53,
);
```

### 테마 포함하기

마지막 단계는 애플리케이션에 컴포넌트 테마를 **포함**하는 것입니다.

```scss
:host {
  @include tokens($custom-theme);
}
```
