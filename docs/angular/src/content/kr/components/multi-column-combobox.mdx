# Angular Multi-Column Combo Box 개요

Multi-Column Combo Box는 데이터 객체의 속성에 대한 열을 자동으로 생성합니다. 이 컴포넌트는 드롭다운 안에 데이터 그리드와 비슷하게 대량의 데이터를 시각화하는 콤보박스라는 점에서 독특합니다.

## 사용법

### 데이터 소스 바인딩

Multi-Column Combo Box 컴포넌트에 객체를 표시하려면 `DataSource` 속성을 바인딩해야 합니다. 이는 복합 객체의 배열 형태로 바인딩할 수 있습니다. 다음 코드는 데이터 소스 속성을 바인딩하는 방법을 보여 줍니다.

### 표시 값과 데이터 값 설정하기

Multi-Column Combo Box에 바인딩된 `DataSource`의 여러 속성을 구성하여, 선택 시 컨트롤의 표시 텍스트와 기본 값으로 사용할 수 있습니다. 이를 위해 컨트롤의 `TextField` 및 `ValueField` 속성을 각각 이러한 값으로 나타내려는 데이터 항목의 속성 이름으로 설정합니다.

### 정렬 모드 구성하기

사용자는 드롭다운에서 열 머리글을 클릭하여 Multi-Column Combo Box에 표시되는 열을 정렬할 수 있습니다. 정렬 구성 방식도 수정할 수 있습니다. 열을 하나 또는 여러 열로 정렬하도록 제한하거나, 오름차순과 내림차순으로 제한하거나, 세 가지 상태(tri-state)로 설정할 수 있습니다. 이는 컴포넌트의 `SortMode` 속성을 설정하여 구성합니다.
