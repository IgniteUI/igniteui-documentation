# Angular Expansion Panel 컴포넌트 개요

Ignite UI for Angular는 개발자에게 가장 유용하고 사용하기 쉬운 레이아웃 컴포넌트 중 하나인 Expansion Panel을 제공합니다. 이 기능이 풍부한 컴포넌트는 펼치고 접을 수 있는 상세 요약 보기를 만드는 데 사용됩니다. 콘텐츠에는 Angular Expansion Panel 애니메이션, 텍스트, 아이콘, 헤더, 작업 막대 및 기타 요소를 포함할 수 있습니다.
<div class="highlight">

Ignite UI Expansion Panel <ApiLink type="ExpansionPanel" label="igx-expansion-panel" />은(는) 접힌 상태 또는 펼쳐진 상태 두 가지로 렌더링할 수 있는 가벼운 Angular 아코디언 컴포넌트입니다. Angular Expansion Panel은 마우스 클릭 또는 키보드 상호 작용으로 전환할 수 있습니다. 여러 Angular Expansion Panel을 결합하여 Angular 아코디언을 만들 수도 있습니다.
</div>

## Ignite UI for Angular Expansion Panel 시작하기

Ignite UI for Angular Drop Down 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxExpansionPanelModule`을 가져오는 것입니다.

```typescript
// app.module.ts
...
import { IgxExpansionPanelModule } from 'igniteui-angular/expansion-panel';
// import { IgxExpansionPanelModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxExpansionPanelModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxExpansionPanelComponent`을 독립형(standalone) 종속성으로 가져올 수 있으며, [`IGX_EXPANSION_PANEL_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/expansion-panel/src/expansion-panel/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수도 있습니다.

```typescript
// home.component.ts

import { IGX_EXPANSION_PANEL_DIRECTIVES } from 'igniteui-angular/expansion-panel';
// import { IGX_EXPANSION_PANEL_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-expansion-panel>
        <igx-expansion-panel-header>
            <igx-expansion-panel-title>
            Golden Retriever
            </igx-expansion-panel-title>
            <igx-expansion-panel-description>
            Medium-large gun dog
            </igx-expansion-panel-description>
        </igx-expansion-panel-header>
        <igx-expansion-panel-body>
            The Golden Retriever is a medium-large gun dog that retrieves shot waterfowl, 
            such as ducks and upland game birds, during hunting and shooting parties. 
            The name "retriever" refers to the breed's ability to retrieve shot game undamaged due to their soft mouth. 
            Golden retrievers have an instinctive love of water, and are easy to train to basic or advanced obedience standards.
        </igx-expansion-panel-body>
    </igx-expansion-panel>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_EXPANSION_PANEL_DIRECTIVES]
    /* or imports: [IgxExpansionPanelComponent, IgxExpansionPanelHeaderComponent, IgxExpansionPanelTitleDirective, IgxExpansionPanelDescriptionDirective, IgxExpansionPanelBodyComponent] */
})
export class HomeComponent {}
```

이제 Ignite UI for Angular Expansion Panel 모듈 또는 디렉티브를 가져왔으므로, `igx-expansion-panel` 컴포넌트를 사용하기 시작할 수 있습니다.

## Angular Expansion Panel 사용하기

아래 표는 Angular Expansion Panel에서 사용할 수 있는 모든 마크업 부분을 보여 줍니다.

|                      태그 이름     |                                                                                             설명               |
| :-------------------------------: | :-------------------------------------------------------------------------------------------------------------------: |
|           `igx-expansion-panel`   |                                                                 컴포넌트 호스트이며, 헤더와 본문을 저장합니다.          |
|     `igx-expansion-panel-header`  |  컴포넌트 헤더를 저장합니다. 항상 표시됩니다. 제목과 설명, 그리고 추가 콘텐츠를 저장합니다  |
|      `igx-expansion-panel-title`  |                                                                        Expansion Panel의 제목을 설정하는 데 사용합니다.           |
| `igx-expansion-panel-description` |  짧은 요약을 제공하는 데 사용할 수 있습니다. 제목이 설정된 경우 설명은 항상 제목 뒤에 표시됩니다. |
|       `igx-expansion-panel-icon`  |                                                           기본 펼치기/접기 아이콘을 변경하는 데 사용합니다.          |
|       `igx-expansion-panel-body`  |                               펼칠 수 있는 컨테이너이며, 패널이 펼쳐진 경우에만 표시됩니다.      |

## 속성 바인딩과 이벤트

패널의 현재 상태에 따라 `igx-expansion-panel-description`을(를) 표시하거나 숨기도록 컴포넌트에 로직을 추가할 수 있습니다.  
이를 위해 설명을 컨트롤의 <ApiLink type="ExpansionPanel" member="collapsed" label="collapsed" /> 속성에 바인딩하면 됩니다:

```typescript
// in expansion-panel.component.ts
import { IgxExpansionPanelComponent } from 'igniteui-angular/expansion-panel';
// import { IgxExpansionPanelComponent } from '@infragistics/igniteui-angular'; for licensed package

@Component({...})
export class ExpansionPanelComponent {
    @ViewChild(IgxExpansionPanelComponent, {read: IgxExpansionPanelComponent})
    public panel: IgxExpansionPanelComponent;
}
```

```html
{/* in expansion-component.component.html */}
<igx-expansion-panel>
    <igx-expansion-panel-header>
        Golden Retriever
        @if (panel.collapsed) {
            <igx-expansion-panel-description>
                Medium-large gun dog
            </igx-expansion-panel-description>
        }
    </igx-expansion-panel-header>
    ...
</igx-expansion-panel>
```

다음 코드 샘플은 컴포넌트가 접힌 상태일 때만 짧은 설명을 표시합니다.
컴포넌트 상태에 따라 더 복잡한 기능을 추가하려면 이벤트 이미터에 바인딩할 수도 있습니다.

```typescript
// in expansion-panel.component.ts

@Component({...})
export class ExpansionPanelComponent {
    ...
    public handleExpansion(args: {event: Event}): void {
        ... // Some functionality
    }
}
```

```html
{/* in expansion-component.component.html */}
<igx-expansion-panel (onExpanded)="handleExpansion($event)" (contentCollapsed)="handleCollapse($event)"></igx-expansion-panel>
```

## 컴포넌트 사용자 지정

<ApiLink type="ExpansionPanel" />을(를) 사용하면 <ApiLink type="ExpansionPanelHeader" label="헤더" />을(를) 쉽게 사용자 지정할 수 있습니다.
헤더 아이콘의 위치는 `igx-expansion-panel-header`의 <ApiLink type="ExpansionPanelHeader" member="iconPosition" label="iconPosition" /> 입력을 통해 구성할 수 있습니다. 아이콘 위치에 가능한 옵션은 **left**, **right**, **none**입니다. 다음 코드 샘플은 컴포넌트의 버튼을 _오른쪽_에 배치하도록 구성하는 방법을 보여 줍니다.

```html
{/* in expansion-component.component.html */}
<igx-expansion-panel>
    <igx-expansion-panel-header [iconPosition]="'right'"></igx-expansion-panel-header>
    ...
</igx-expansion-panel>
```

<DocsAside type="info">
<ApiLink type="ExpansionPanelHeader" member="iconPosition" label="iconPosition" /> 속성은 `RTL`와 함께 동작합니다. 예를 들어 **right**에 표시되도록 설정된 아이콘은 RTL이 켜져 있으면 헤더의 가장 왼쪽 부분에 표시됩니다.
</DocsAside>

컨트롤의 토글 상태에 대한 기본 아이콘은 템플릿으로 만들 수 있습니다.
`igx-expansion-panel-icon` 태그에 콘텐츠를 전달하면 됩니다:

```html
{/* in expansion-component.component.html */}
<igx-expansion-panel>
    <igx-expansion-panel-header [iconPosition]="'right'">
        ...
        <igx-expansion-panel-icon>
            @if (panel.collapsed) {
                <span class="example-icon">Show More</span>
            } @else {
                <span class="example-icon">Show Less</span>
            }
        </igx-expansion-panel-icon>
    </igx-expansion-panel-header>   
    ...
</igx-expansion-panel>
```

이제 Angular Expansion Panel은 패널이 접혀 있을 때 "Show More"를, 완전히 펼쳐지면 "Show Less"를 렌더링합니다.

`IgxExpansionPanel` 컨트롤은 `igx-expansion-panel-body` 안에 다양한 종류의 콘텐츠를 추가할 수 있도록 합니다. [`IgxGrid`](/grid/grid), [`IgxCombo`](/inputs/combo/overview), 차트, 심지어 다른 Expansion Panel도 렌더링할 수 있습니다!

간단하게 하기 위해 Expansion Panel의 본문에 기본 마크업을 추가하겠습니다.

```html
{/* in expansion-panel.component.html */}
...
<igx-expansion-panel-body>
    <div class="example-content">

        <img [src]="imgSource" alt="dog-image">
        The Golden Retriever is a medium-large gun dog that retrieves shot waterfowl, such as ducks and upland game birds, during hunting and shooting parties. The name "retriever" refers to the breed's ability to retrieve shot game undamaged due to their soft mouth. Golden retrievers have an instinctive love of water, and are easy to train to basic or advanced obedience standards.
        <a igxButton="outlined" target="_blank" [href]="readMore">Read more</a>
    
</div>
</igx-expansion-panel-body>
...
```

## 스타일링

### Expansion Panel 테마 속성 매핑

`$header-background` 및 `$body-background` 속성을 변경하면 다음 종속 속성이 자동으로 업데이트됩니다:

| 기본 속성 | 종속 속성 | 설명 |
| --- | --- | --- |
| **$header-background** | $header-title-color | 패널 헤더 제목 텍스트의 색상입니다. |
|  | $header-icon-color | 패널 헤더 아이콘의 색상입니다. |
|  | $header-description-color | 패널 헤더 설명 텍스트의 색상입니다. |
|  | $header-focus-background | 패널 헤더 포커스 배경색입니다. |
|  | $disabled-text-color | 패널의 비활성화된 텍스트 색상입니다. |
|  | $disabled-description-color | 패널의 비활성화된 헤더 설명 텍스트 색상입니다. |
| **$body-background** | $body-color | 패널 본문 텍스트의 색상입니다. |

### 팔레트와 색상

먼저 나중에 컴포넌트에 전달할 수 있는 사용자 지정 팔레트를 만듭니다:

```scss
// In real life, this should be in our main sass file so we can share the palette between all components. 
// In our case, it's in the component SCSS file "expansion-styling.component.scss".

@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';

// Add your brand colors.
$my-primary-color:#353a4b;
$my-secondary-color: #ffd351;
$my-surface-color: #efefef;

// Create custom palette.
$my-color-palette: palette(
  $primary: $my-primary-color,
  $secondary: $my-secondary-color,
  $surface: $my-surface-color
);
```

### 컴포넌트 테마 만들기

이제 컴포넌트 테마를 만들고 위 스니펫의 `$my-color-palette` 팔레트를 전달하겠습니다.

```scss
// In expansion-styling.component.scss
// Create expansion panel theme.
$custom-panel-theme: expansion-panel-theme(
  // Styling parameters.
  $header-background: color($my-color-palette, "primary", 700),
  $header-focus-background: color($my-color-palette, "primary", 700),
  $header-title-color: color($my-color-palette, "secondary"),
  $header-icon-color: color($my-color-palette, "secondary"),
  $body-background: color($my-color-palette, "primary", 700),
  $body-color: color($my-color-palette, "secondary", 100),
  $border-radius: .5
);
```

팔레트를 만드는 대신 expansion-panel-theme 함수의 인수로 색상을 직접 지정할 수도 있습니다. `title-color`, `icon-color` 또는 다른 전경 속성이 명시적으로 제공되지 않으면, 배경과 대비가 더 좋은 쪽인 검은색 또는 흰색으로 자동 할당됩니다.

```scss
$custom-panel-theme: expansion-panel-theme(
  $header-background: #353a4b,
  $header-focus-background: #353a4b,
  $header-title-color: #ffd351,
  $header-icon-color: #ffd351,
  ...
);
```

<DocsAside type="info">
[`theming`](/themes/sass/component-themes) 엔진을 통해 스타일을 지정할 수 있는 모든 매개변수를 보려면 <ApiLink kind="sass" module="themes" type="function-expansion-panel-theme" label="API 문서" code={true} />을(를) 확인하십시오
</DocsAside>

### Tailwind로 스타일링하기

사용자 지정 Tailwind 유틸리티 클래스를 사용하여 expansion panel의 스타일을 지정할 수 있습니다. 먼저 [Tailwind를 설정](/themes/tailwind)했는지 확인하십시오.

전역 스타일시트에 Tailwind를 가져온 다음, 다음과 같이 원하는 테마 유틸리티를 적용할 수 있습니다:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

유틸리티 파일에는 `light` 및 `dark` 테마 변형이 모두 포함되어 있습니다.

- 밝은 테마에는 `light-*` 클래스를 사용하십시오.
- 어두운 테마에는 `dark-*` 클래스를 사용하십시오.
- 접두사 뒤에 컴포넌트 이름을 붙이십시오. 예: `light-expansion-panel`, `dark-expansion-panel`.

적용하면 이 클래스는 동적 테마 계산을 가능하게 합니다. 그런 다음 `arbitrary properties`을 사용하여 생성된 CSS 변수를 재정의할 수 있습니다. 콜론 뒤에는 유효한 CSS 색상 형식(HEX, CSS 변수, RGB 등)을 입력하십시오.

속성의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-expansion-panel-theme" label="expansion-panel-theme" />에서 확인할 수 있습니다. 구문은 다음과 같습니다:

```html
<igx-expansion-panel
  class="!light-expansion-panel
  ![--header-background:#4F6A5A]
  ![--body-background:#A3C7B2]"
>
  ...
</igx-expansion-panel>
```

<DocsAside type="info">
유틸리티 클래스가 우선 적용되도록 느낌표(`!`)가 필요합니다. Tailwind는 스타일을 계층으로 적용하므로, 이 스타일을 중요(important)로 표시하지 않으면 컴포넌트의 기본 테마에 의해 재정의됩니다.
</DocsAside>

## Angular Expansion Panel 애니메이션

### 특정 애니메이션 사용하기

컴포넌트를 펼치고 접을 때 기본 애니메이션 대신 다른 애니메이션을 사용할 수 있습니다.
앞에서 설명한 대로 `app.module.ts`에 igxExpansionPanel이 이미 가져와져 있다고 가정하면, 사용자 지정 애니메이션 설정 객체를 만들어 Ignite UI for Angular Expansion Panel에서 사용하도록 설정할 수 있습니다. 이 방식에는 [`useAnimation`](https://angular.io/api/animations/useAnimation) 메서드와 사용할 특정 애니메이션이 필요하므로, 이들을 먼저 가져오고 다음과 같이 애니메이션 설정을 정의하겠습니다:

```typescript
// in expansion-panel.component.ts
import { useAnimation } from '@angular/animations';
import { IgxExpansionPanelComponent } from 'igniteui-angular/expansion-panel';
import { slideInLeft, slideOutRight } from 'igniteui-angular/animations';
// import { IgxExpansionPanelComponent, slideInLeft, slideOutRight } from '@infragistics/igniteui-angular'; for licensed package

@Component({...})
export class ExpansionPanelComponent {
    @ViewChild(IgxExpansionPanelComponent, {read: IgxExpansionPanelComponent})
    public panel: IgxExpansionPanelComponent;

    public animationSettingsCustom = {
        closeAnimation: useAnimation(slideOutRight, {
            params: {
                duration: '100ms',
                toPosition: 'translateX(25px)'
            }
        }),
        openAnimation: useAnimation(slideInLeft, {
            params: {
                duration: '500ms',
                fromPosition: 'translateX(-15px)',
                startOpacity: 0.1
            }
        })
    };

    public collapsed() {
        return this.panel && this.panel.collapsed;
    }
}
```
