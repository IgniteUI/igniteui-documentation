# Angular Toast 컴포넌트 개요

<div class="highlight">
Ignite UI for Angular Toast 컴포넌트는 자동으로 숨겨지고, 상호 작용이 없으며, 사용자가 닫을 수 없는 정보 및 경고 메시지를 제공합니다. 알림은 페이지의 아래, 가운데 또는 위에 표시할 수 있습니다.

## Ignite UI for Angular Toast 시작하기

Ignite UI for Angular Toast 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](./general/getting-started.mdx) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxToastModule`을 가져오는 것입니다.

```typescript
// app.module.ts

...
import { IgxToastModule } from 'igniteui-angular/toast';
// import { IgxToastModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxToastModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxToastComponent`을(를) 독립형 종속성으로 가져올 수 있습니다.

```typescript
// home.component.ts

import { IgxToastComponent } from 'igniteui-angular/toast';
import { IgxButtonDirective } from 'igniteui-angular/directives';
// import { IgxToastComponent, IgxButtonDirective } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <button igxButton="contained" (click)="toast.open()">Show notification</button>
    <igx-toast #toast>Notification displayed</igx-toast>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxToastComponent, IgxButtonDirective]
    /* or imports: [IgxTimePickerComponent, IgxButtonDirective] */
})
export class HomeComponent {
    public time: Date;
}
```

이제 Ignite UI for Angular Toast 모듈 또는 컴포넌트를 가져왔으므로 `igx-toast` 컴포넌트를 사용할 수 있습니다.

## Angular Toast 사용하기

### 토스트 표시하기

토스트 컴포넌트를 표시하려면 버튼 클릭 시 <ApiLink type="Toast" member="open" label="open()" /> 메서드를 호출하십시오. 토스트 콘텐츠는 요소 안에 전달할 수 있습니다.

```html
{/*sample.component.html*/}

<button igxButton="contained" (click)="toast.open()">Show notification</button>
<igx-toast #toast>Notification displayed</igx-toast>
```

토스트 콘텐츠를 설정하는 또 다른 방법은 <ApiLink type="Toast" member="open" label="open()" /> 메서드에 메시지를 매개변수로 직접 전달하는 것입니다.

```html
{/*sample.component.html*/}

<button igxButton="contained" (click)="toast.open('Notification displayed')">Show notification</button>
<igx-toast #toast></igx-toast>
```

<ApiLink type="Toast" member="open" label="open()" /> 메서드는 AppComponent 파일에서도 사용하여 메시지 값을 관리할 수 있습니다.

```typescript
// app.component.ts
@ViewChild('toast', { read: IgxToastComponent }) public toast: IgxToastComponent;

public message: any;

public ngOnInit() {
    this.message = 'Display message';
}

public showMessage() {
    this.toast.open(this.message);
}
```

## 예제

### 숨기기/자동 숨기기

열리면 토스트는 <ApiLink type="Toast" member="displayTime" label="displayTime" /> 입력으로 지정된 기간이 지난 후 사라집니다. 이 입력은 처음에 4000밀리초로 설정되어 있습니다. 이 동작은 기본적으로 활성화되어 있지만, <ApiLink type="Toast" member="autoHide" label="autoHide" />을(를) **false**로 설정하여 바꿀 수 있습니다. 이렇게 하면 토스트가 계속 보입니다. 토스트의 <ApiLink type="Toast" member="close" label="close()" /> 메서드를 사용하면 컴포넌트를 닫을 수 있습니다.

```html
{/*sample.component.html*/}

<button igxButton="contained" (click)="toast.open()">Show Toast</button>
<button igxButton="contained" (click)="toast.close()">Hide Toast</button>
<igx-toast #toast [autoHide]="false">Notification displayed</igx-toast>
```

샘플이 올바르게 구성되었다면 _Show 버튼_을 클릭할 때 토스트가 나타납니다. 첫 번째 컴포넌트는 자동 숨기기 기능이 비활성화되어 있어, 'Hide' 버튼을 클릭해야 토스트가 사라집니다.
나머지 두 컴포넌트에서는 <ApiLink type="Toast" member="open" label="open()" /> 메서드를 통해 서로 다른 메시지를 전달하고 콘텐츠 프로젝션을 사용하는 방법을 실제로 확인할 수 있습니다.

### 표시 시간

<ApiLink type="Toast" member="displayTime" label="displayTime" />을(를) 사용하고 밀리초 단위의 간격으로 설정하여 토스트 컴포넌트가 보이는 시간을 구성하십시오.

```html
{/*sample.component.html*/}

<button igxButton="contained" (click)="toast.open()">Show notification</button>
<igx-toast #toast displayTime="1000">Notification displayed</igx-toast>
```

샘플이 올바르게 구성되었다면 토스트가 더 빨리 자동으로 숨겨집니다.

<Sample src="/notifications/toast-sample-4/" height={200} iframeOnly />

### 위치 지정

<ApiLink type="Toast" member="positionSettings" label="positionSettings" /> 속성을 사용하여 토스트가 나타나는 위치를 구성하십시오. 기본적으로 페이지 하단에 표시됩니다. 아래 샘플에서는 알림이 상단 위치에 나타나도록 설정합니다.

```html
{/*sample.component.html*/}
<div>
    <button igxButton="contained" (click)="open(toast)">Show notification on top</button>
    <igx-toast #toast>Notification displayed</igx-toast>
</div>
```

```typescript
// sample.component.ts
import { VerticalAlignment } from 'igniteui-angular/core';
// import { VerticalAlignment } from '@infragistics/igniteui-angular'; for licensed package
...
public open(toast) {
    toast.positionSettings.verticalDirection = VerticalAlignment.Top;
    toast.open();
}
...
```

## 스타일링

### Toast 테마 속성 맵

기본 속성을 수정하면, 관련된 모든 종속 속성이 변경 사항을 반영하도록 자동으로 업데이트됩니다:

<table>
  <thead>
    <tr>
      <th>기본 속성</th>
      <th>종속 속성</th>
      <th>설명</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>$background</strong></td>
      <td>$text-color</td>
      <td>토스트에 사용되는 텍스트 색상입니다.</td>
    </tr>
    <tr>
      <td><strong>$text-color</strong></td>
      <td>$border-color</td>
      <td>토스트에 사용되는 테두리 색상입니다.</td>
    </tr>
  </tbody>
</table>

토스트의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 index 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-toast-theme" label="toast-theme" code={true} />을(를) 확장하고 `$background`, `$text-color` 및 `$border-radius` 매개변수를 제공하는 새 테마를 만듭니다.

```scss
$custom-toast-theme: toast-theme(
  $text-color: #ffcd0f,
  $background: #292826,
  $border-radius: 12px
);
```

<DocsAside type="info">
방금 한 것처럼 색상 값을 직접 하드코딩하는 대신, <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> 및 <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} /> 함수를 사용하면 색상을 훨씬 유연하게 다룰 수 있습니다. 사용 방법에 대한 자세한 안내는 [`Palettes`](./themes/sass/palettes.mdx) 항목을 참조하십시오.
</DocsAside>

마지막 단계는 사용자 지정 토스트 테마를 전달하는 것입니다:

```scss
:host {
  @include tokens($custom-toast-theme);
}
```

### Tailwind로 스타일링하기

사용자 지정 Tailwind 유틸리티 클래스를 사용하여 토스트의 스타일을 지정할 수 있습니다. 먼저 [Tailwind를 설정](./themes/tailwind.mdx)했는지 확인하십시오.

전역 스타일시트에서 Tailwind를 가져오는 것과 함께, 다음과 같이 원하는 테마 유틸리티를 적용할 수 있습니다:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

유틸리티 파일에는 `light` 및 `dark` 테마 변형이 모두 포함되어 있습니다.

- 밝은 테마에는 `light-*` 클래스를 사용하십시오.
- 어두운 테마에는 `dark-*` 클래스를 사용하십시오.
- 접두사 뒤에 컴포넌트 이름을 붙이십시오. 예: `light-toast`, `dark-toast`.

적용하면 이 클래스는 동적 테마 계산을 가능하게 합니다. 그런 다음 `arbitrary properties`을 사용하여 생성된 CSS 변수를 재정의할 수 있습니다. 콜론 뒤에는 유효한 CSS 색상 형식(HEX, CSS 변수, RGB 등)을 입력하십시오.

속성의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-toast-theme" label="IgxToast 테마" />에서 확인할 수 있습니다. 구문은 다음과 같습니다:

```html
<igx-toast
  class="!light-toast ![--background:#90B69F]">
  ...
</igx-toast>
```

<DocsAside type="info">
유틸리티 클래스가 우선 적용되도록 느낌표(`!`)가 필요합니다. Tailwind는 스타일을 계층으로 적용하므로, 이 스타일을 중요(important)로 표시하지 않으면 컴포넌트의 기본 테마에 의해 재정의됩니다.
</DocsAside>
