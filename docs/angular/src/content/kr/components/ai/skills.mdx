# Ignite UI for Angular Agent Skills

Ignite UI for Angular에는 **[Agent Skills](https://agentskills.io/)**가 포함되어 있습니다. 이는 AI 코딩 어시스턴트(GitHub Copilot, Cursor, Windsurf, Claude, Gemini CLI, JetBrains Junie 등)에 Ignite UI for Angular 사용 방법을 알려 주는 구조화된 지식 파일입니다. 이 스킬 파일은 컴포넌트, 그리드, 데이터 작업 및 테마에 대해 상황에 맞는 지침을 제공하여, AI 어시스턴트가 모범 사례를 따르는 정확하고 관용적인 코드를 생성할 수 있도록 합니다.

<DocsAside type="info">
AI 도구 환경은 빠르게 변화하고 있습니다. 도구와 IDE가 업데이트되면 스킬 탐색 위치와 배포 옵션이 바뀔 수 있습니다. 최신 정보는 사용 중인 특정 도구 또는 에이전트의 공식 문서를 항상 참조하십시오.
</DocsAside>

## 사용 가능한 스킬

스킬 파일은 Ignite UI for Angular 저장소의 [`skills/`](https://github.com/IgniteUI/igniteui-angular/tree/master/skills) 디렉터리에 있습니다:

| 스킬 | 경로 | 설명 |
|:------|:-----|:------------|
| 컴포넌트 및 레이아웃 | [`skills/igniteui-angular-components/SKILL.md`](https://github.com/IgniteUI/igniteui-angular/blob/master/skills/igniteui-angular-components/SKILL.md) | 독립형 컴포넌트, 폼 컨트롤, 오버레이, 레이아웃 |
| 데이터 그리드 | [`skills/igniteui-angular-grids/SKILL.md`](https://github.com/IgniteUI/igniteui-angular/blob/master/skills/igniteui-angular-grids/SKILL.md) | Grid, Tree Grid, Hierarchical Grid, Pivot Grid, 정렬, 필터링, 그룹화, 페이징, 원격 데이터 |
| 테마 및 스타일링 | [`skills/igniteui-angular-theming/SKILL.md`](https://github.com/IgniteUI/igniteui-angular/blob/master/skills/igniteui-angular-theming/SKILL.md) | 팔레트, 타이포그래피, 고도(elevation), 컴포넌트 테마, MCP 서버 |
| 이미지 디자인에서 생성 | [`skills/igniteui-angular-generate-from-image-design/SKILL.md`](https://github.com/IgniteUI/igniteui-angular/blob/master/skills/igniteui-angular-generate-from-image-design/SKILL.md) | Ignite UI 컴포넌트를 사용하여 스크린샷, 목업 및 와이어프레임으로부터 Angular 앱을 만듭니다 |

<DocsAside type="info">
Ignite UI for Angular **21.1.0**부터 이 스킬은 에이전트의 스킬 경로(예: `.claude/skills`, `.agents/skills`, `.cursor/rules/`)에 배치되면 자동으로 검색됩니다. 이 릴리스에는 이러한 스킬을 프로젝트에 자동으로 추가하는 선택적 마이그레이션이 포함되어 있습니다.
</DocsAside>

## 스킬 위치

각 AI 코딩 도구는 특정 디렉터리에서 스킬을 찾습니다. AI 어시스턴트가 스킬을 찾아 자동으로 사용할 수 있도록 스킬 파일을 적절한 위치에 배치하십시오. 일반 `.agents/skills/` 규칙은 여러 도구에서 지원되며, 각 도구에는 고유한 디렉터리도 있습니다.

### 일반(`.agents/skills/`)

`.agents/skills/` 디렉터리는 [Copilot이 포함된 VS Code](https://code.visualstudio.com/docs/copilot/customization/agent-skills), [OpenAI Codex](https://developers.openai.com/codex/skills), [Cursor](https://cursor.com/docs/skills), [Gemini CLI](https://geminicli.com/docs/cli/skills/#skill-discovery-tiers), [Antigravity](https://antigravity.google/docs/skills), [Windsurf](https://docs.windsurf.com/windsurf/cascade/skills#skill-scopes)를 포함한 여러 도구가 지원하는 에이전트 간 공통 규칙입니다. 스킬 디렉터리를 프로젝트 루트의 `.agents/skills/`에 복사하십시오:

```
.agents/
  skills/
    igniteui-angular-components/
      SKILL.md
    igniteui-angular-grids/
      SKILL.md
    igniteui-angular-theming/
      SKILL.md
    igniteui-angular-generate-from-image-design/
      SKILL.md
```

모든 프로젝트에서 사용할 수 있는 사용자 수준(전역) 스킬을 원하면 대신 `~/.agents/skills/`을 사용하십시오.

### GitHub Copilot

[GitHub Copilot](https://docs.github.com/en/copilot/concepts/agents/about-agent-skills)은 다음 위치에서 스킬을 찾습니다:

| 범위 | 위치 |
|:------|:---------|
| 프로젝트 | `.github/skills/`, `.claude/skills/` |
| 개인 | `~/.copilot/skills/`, `~/.claude/skills/`(Copilot 코딩 에이전트 및 GitHub Copilot CLI 전용) |

> **팁:** [VS Code](https://code.visualstudio.com/docs/copilot/customization/agent-skills)에서는 이 위치에 일반 `.agents/skills/` 및 `~/.agents/skills/`도 포함되며, `chat.agentSkillsLocations` 설정을 사용하여 추가 스킬 위치를 구성할 수 있습니다.

### Claude

[Claude](https://code.claude.com/docs/en/skills#where-skills-live)는 다음 위치에서 스킬을 찾습니다:

| 범위 | 위치 |
|:------|:---------|
| 프로젝트 | `.claude/skills/` |
| 개인 | `~/.claude/skills/` |

### Cursor

[Cursor](https://cursor.com/docs/skills#skill-directories)는 다음 위치에서 스킬을 찾습니다:

| 범위 | 위치 |
|:------|:---------|
| 프로젝트 | `.agents/skills/`, `.cursor/skills/` |
| 사용자(전역) | `~/.cursor/skills/` |

### Gemini CLI 및 Antigravity

[Gemini CLI](https://geminicli.com/docs/cli/skills/#skill-discovery-tiers)와 [Antigravity](https://antigravity.google/docs/skills)는 다음 위치에서 스킬을 찾습니다:

| 범위 | 위치 |
|:------|:---------|
| 워크스페이스 | `.gemini/skills/`, `.agents/skills/` |
| 사용자 | `~/.gemini/skills/`, `~/.agents/skills/` |

> **팁:** Gemini CLI에서 `/skills` 슬래시 명령을 사용하면 설치된 스킬을 보고 관리할 수 있습니다.

### Junie(JetBrains IDE)

[Junie](https://junie.jetbrains.com/docs/agent-skills.html)는 다음 위치에서 스킬을 찾습니다:

| 범위 | 위치 |
|:------|:---------|
| 프로젝트 | `.junie/skills/` |
| 사용자 | `~/.junie/skills/` |

### Windsurf

[Windsurf](https://docs.windsurf.com/windsurf/cascade/skills#skill-scopes)는 다음 위치에서 스킬을 찾습니다:

| 범위 | 위치 |
|:------|:---------|
| 워크스페이스 | `.windsurf/skills/`, `.agents/skills/` |
| 전역 | `~/.codeium/windsurf/skills/`, `~/.agents/skills/` |

## 스킬 설치하기

아래 옵션 중 하나를 사용하여 스킬 파일을 내려받고 AI 어시스턴트의 적절한 [스킬 위치](#스킬-위치)에 배치하십시오.

### **옵션 A - Ignite UI CLI 사용**

`ai-config` 명령은 한 단계에서 MCP 서버를 구성하고, 프레임워크별 스킬 파일을 각 에이전트의 skills 디렉터리에 복사하며, 지침 파일을 설정합니다. `--assistants`를 사용하여 MCP 구성을 받을 코딩 어시스턴트를 선택하고, `--agents`를 사용하여 스킬 파일을 받을 에이전트를 선택하십시오. 기존 파일은 내용이 변경된 경우에만 업데이트됩니다. 매개변수를 지정하지 않으면 명령이 대화형 모드로 들어가 어시스턴트와 에이전트를 선택하라는 메시지를 표시합니다. 사용 가능한 옵션은 아래 표를 참조하십시오.

```bash
ig ai-config --assistants generic --agents claude
```

여러 에이전트를 한 번에 대상으로 하려면 여러 값과 함께 `--agents`을 사용하십시오:

```bash
ig ai-config --assistants generic vscode --agents claude copilot cursor
```

| 플래그 | 값 | 기본값 |
|------|--------|---------|
| `--assistants` | `generic`, `vscode`, `cursor`, `gemini`, `junie`, `none` | 대화형으로 입력 요청 |
| `--agents` | `generic`, `claude`, `copilot`, `cursor`, `codex`, `windsurf`, `gemini`, `junie`, `none` | 대화형으로 입력 요청 |

**Angular Schematics 사용:**

```bash
ng generate @igniteui/angular-schematics:ai-config --assistants cursor --agents claude copilot
```

이 명령은 Ignite UI 서버와 함께 `@angular/cli` MCP 서버도 등록합니다.

<DocsAside type="info">
`ai-config`을 실행하지 않고 Ignite UI for Angular를 수동으로 설치했으며 스킬을 복사하고 싶다면, 스킬 파일은 `node_modules` 아래에서도 사용할 수 있습니다. 프로젝트(예: `.agents/skills/`)에 복사하려면 다음을 실행하십시오:
</DocsAside>

**macOS / Linux / Windows (PowerShell)**

```bash
cp -r node_modules/igniteui-angular/skills/. .agents/skills/
```

**Windows (명령 프롬프트)**

```cmd
robocopy node_modules\igniteui-angular\skills .agents\skills /E
```

또는 필요에 따라 개별 스킬 디렉터리를 복사할 수 있습니다:

**macOS / Linux / Windows (PowerShell)**

```bash
cp -r node_modules/igniteui-angular/skills/igniteui-angular-components .agents/skills/
cp -r node_modules/igniteui-angular/skills/igniteui-angular-grids .agents/skills/
cp -r node_modules/igniteui-angular/skills/igniteui-angular-theming .agents/skills/
cp -r node_modules/igniteui-angular/skills/igniteui-angular-generate-from-image-design .agents/skills/
```

**Windows (명령 프롬프트)**

```cmd
robocopy node_modules\igniteui-angular\skills\igniteui-angular-components .agents\skills\igniteui-angular-components /E
robocopy node_modules\igniteui-angular\skills\igniteui-angular-grids .agents\skills\igniteui-angular-grids /E
robocopy node_modules\igniteui-angular\skills\igniteui-angular-theming .agents\skills\igniteui-angular-theming /E
robocopy node_modules\igniteui-angular\skills\igniteui-angular-generate-from-image-design .agents\skills\igniteui-angular-generate-from-image-design /E
```

### **옵션 B - `GitHub CLI` 사용**

GitHub CLI를 사용하여 Ignite UI for Angular 저장소에서 스킬 파일을 직접 내려받을 수 있습니다. 설치 과정을 시작하려면 프로젝트 루트에서 다음 명령을 실행하십시오:

```bash
gh skill install IgniteUI/igniteui-angular
```

설치할 스킬과 프로젝트의 스킬 파일을 받을 대상 에이전트를 선택하라는 메시지가 표시됩니다. 그런 다음 CLI가 선택한 에이전트에 따라 선택한 스킬을 내려받아 배치합니다.

나중에 스킬을 업데이트하려면 다음 명령을 실행하십시오:

```bash
gh skill update IgniteUI/igniteui-angular
```

### **옵션 C - `gemini skills` CLI 사용**

`gemini skills install` 명령은 Git 저장소에서 스킬을 직접 설치합니다. 두 가지 범위를 지원합니다:

- **사용자 범위**(기본값) - 사용자 계정에 전역으로 스킬을 설치하여 모든 프로젝트에서 사용할 수 있게 합니다. 스킬은 `~/.gemini/skills/` 또는 `~/.agents/skills/`에 배치됩니다.
- **워크스페이스 범위** - 현재 프로젝트 디렉터리의 `.agents/skills/` 아래에 로컬로 스킬을 설치하여 해당 프로젝트에만 적용되도록 합니다.

**사용자 범위에 설치(기본값):**

```bash
gemini skills install https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-components
gemini skills install https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-grids
gemini skills install https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-theming
gemini skills install https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-generate-from-image-design
```

**워크스페이스 범위에 설치:**

```bash
gemini skills install --scope workspace https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-components
gemini skills install --scope workspace https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-grids
gemini skills install --scope workspace https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-theming
gemini skills install --scope workspace https://github.com/IgniteUI/igniteui-angular.git --path skills/igniteui-angular-generate-from-image-design
```

설치가 끝나면 스킬 파일은 해당 위치에서 사용할 수 있으며, 호환되는 AI 어시스턴트가 자동으로 찾아 사용합니다.

### **옵션 D - `npx skills` CLI 사용**

`skills` CLI는 스킬을 프로젝트에 직접 내려받아 설치하는 대화형 도구입니다. 프로젝트 루트에서 다음 명령을 실행하십시오:

```bash
npx skills add IgniteUI/igniteui-angular
```

CLI는 다음 작업을 위해 일련의 질문으로 안내합니다:

1. 설치할 스킬(컴포넌트, 테마 등)을 선택합니다.
2. 프로젝트에서 스킬 파일을 둘 대상 위치(예: `.agents/skills/`, `.github/skills/`)를 선택합니다.
3. 선택한 스킬 파일을 자동으로 내려받아 기록합니다.

완료되면 스킬을 바로 사용할 수 있으며, 파일을 수동으로 복사할 필요가 없습니다.

> **참고:** Node.js와 인터넷 연결이 필요합니다. 이 명령은 [IgniteUI/igniteui-angular](https://github.com/IgniteUI/igniteui-angular) 저장소에서 최신 스킬 파일을 가져옵니다.

## Theming MCP 서버

**테마 스킬**에는 `igniteui-theming` MCP 서버의 설정 지침이 포함되어 있으며, 이 서버는 팔레트 생성 및 컴포넌트 테마 스캐폴딩과 같은 실시간 테마 도구를 AI 어시스턴트에 제공합니다. VS Code, Cursor, Claude Desktop 및 JetBrains IDE의 구성 단계는 [테마 스킬 파일](https://github.com/IgniteUI/igniteui-angular/blob/master/skills/igniteui-angular-theming/SKILL.md)을 참조하십시오.

Theming MCP에 대한 자세한 내용은 [Ignite UI Theming MCP](/ai/theming-mcp) 문서를 참조하십시오.
