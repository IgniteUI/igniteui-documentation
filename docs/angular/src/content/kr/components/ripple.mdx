## Ignite UI for Angular Ripple 디렉티브 시작하기

Ignite UI for Angular Ripple 디렉티브를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxRippleModule`을(를) 가져오는 것입니다.

```typescript
// app.module.ts

import { IgxRippleModule } from 'igniteui-angular/directives';
// import { IgxRippleModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    imports: [
        ...
        IgxRippleModule,
        ...
    ]
})
export class AppModule {}
```

또는 `16.0.0`부터는 `IgxRippleDirective`을(를) 독립형 종속성으로 가져올 수 있습니다.

```typescript
// home.component.ts

import { IgxRippleDirective, IgxButtonDirective } from 'igniteui-angular/directives';
// import { IgxRippleDirective, IgxButtonDirective } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: '<button igxButton="contained" igxRipple>Click Me</button>',
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IgxRippleDirective, IgxButtonDirective],
})
export class HomeComponent {}
```

이제 Ignite UI for Angular Ripple 모듈 또는 디렉티브를 가져왔으므로 `igxRipple` 디렉티브를 사용할 수 있습니다.

<DocsAside type="warning">
<ApiLink type="RippleDirective" label="igxRipple" />은(는) Web Animation API를 사용하며, [이를 지원하는 브라우저](http://caniuse.com/#feat=web-animation)에서 네이티브로 실행됩니다.
다른 브라우저에서는 `web-animations.min.js` 폴리필을 [사용할 수 있습니다](https://github.com/web-animations/web-animations-js).
</DocsAside>

## Angular Ripple 디렉티브 사용하기

### 물결 효과 추가하기

지정된 요소에 물결 효과를 추가하려면 `igxRipple` 디렉티브를 사용하십시오:

```html
<button igxButton="contained" igxRipple>Click Me</button>
```

## 예제

### 사용자 지정 색상

`igxRipple`을(를) 사용하여 기본 물결 색상을 쉽게 바꿀 수 있습니다:

```html
<button igxButton="contained" igxRipple="white">White</button>
```

<Sample src="/interactions/ripple-sample-6" height={100} alt="Angular Ripple 예제" />

### 가운데 물결 효과

기본적으로 물결 효과는 클릭 이벤트가 발생한 위치에서 시작합니다. <ApiLink type="RippleDirective" member="centered" label="igxRippleCentered" /> 속성을 사용하고 요소의 가운데를 원점으로 설정하면 이 동작을 바꿀 수 있습니다.

```html
<button igxButton="contained" igxRipple="white" [igxRippleCentered]="true">
  Centered
</button>
```

<Sample src="/interactions/ripple-sample-3" height={100} alt="Angular Ripple 예제" />

### 물결 지속 시간

<ApiLink type="RippleDirective" member="rippleDuration" label="igxRippleDuration" /> 속성을 사용하여 물결 애니메이션의 지속 시간을 바꿀 수 있으며, 기본값은 600밀리초입니다.

```html
<button igxButton="contained" igxRipple [igxRippleDuration]="2000">
  Click Me
</button>
```

<Sample src="/interactions/ripple-sample-4" height={100} alt="Angular Ripple 예제" />

### 물결 대상

<ApiLink type="RippleDirective" member="rippleTarget" label="igxRippleTarget" /> 속성을 사용하면 상위 요소 안의 특정 요소에 물결 효과를 연결할 수 있습니다.

```html
<div class="parent" igxRipple="white" igxRippleTarget=".child" [igxRippleCentered]="true">
  ...
  <button class="sample-button child" igxButton="contained">Read More</button>
</div>
```

상위 요소를 클릭하든 하위 요소를 클릭하든, 물결 효과는 버튼에만 나타납니다.

<Sample src="/interactions/ripple-sample-2" height={350} alt="Angular Ripple 예제" />

<DocsAside type="info">
`igxRippleTarget` 속성으로 대상으로 삼으려는 하위 요소는 상대 위치(relative)로 설정되어 있어야 합니다.
</DocsAside>

## 스타일링

먼저 테마 엔진이 제공하는 함수를 사용하려면, 모든 스타일 함수와 믹스인이 있는 `index` 파일을 스타일 파일에 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

<ApiLink kind="sass" module="themes" type="function-ripple-theme" label="ripple-theme" code={true} />을(를) 확장하고 물결을 원하는 대로 사용자 지정하는 데 필요한 매개변수를 받는 새 테마를 쉽게 만들 수 있습니다.

```scss
$custom-ripple-theme: ripple-theme(
  $color: #383779,
);
```

다음 단계는 사용자 지정 물결 테마를 전달하는 것입니다:

```scss
:host {
  @include tokens($custom-ripple-theme);
}
```

<DocsAside type="info">
`igxRiple` 디렉티브를 사용하여 설정한 색상은 사용자 지정 테마에서 설정한 색상보다 우선합니다.
</DocsAside>
