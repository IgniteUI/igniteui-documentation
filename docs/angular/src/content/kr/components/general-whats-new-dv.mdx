# Ignite UI for Angular의 새로운 기능

이 항목은 Ignite UI for Angular의 호환성 변경 사항과 이전 코드를 최신 API에 맞게 업데이트하는 방법에 대한 정보를 제공합니다.

## 차트 기능

이번 릴리스는 모든 차트 컴포넌트에 대해 여러 새롭고 개선된 시각 디자인 및 구성 옵션을 도입합니다. 예를 들어 Data Chart, Category Chart, Financial Chart가 있습니다.

### 재설계된 차트 기본값

- 모든 차트의 시리즈/마커에 새로운 색상 팔레트

| ----------------------------------------------------------------- | ----------------------------------------------------------------- |
| <Image src={chartdefaults3} alt="차트 기본값 3" class="responsive-img" /> | <Image src={chartdefaults4} alt="차트 기본값 4" class="responsive-img" /> |

<hr/>

- Bar/Column/Waterfall 시리즈가 둥근 모서리 대신 각진 모서리를 갖도록 변경되었습니다
- Scatter High Density 시리즈의 min/max 열 속성 색상이 변경되었습니다
- Financial/Waterfall 시리즈의 시각 요소 음수 채우기 색상이 변경되었습니다
- 마커 두께가 1px에서 2px로 변경되었습니다
- PointSeries, BubbleSeries, ScatterSeries, PolarScatterSeries의 마커 채우기가 마커 외곽선과 일치하도록 변경되었습니다
  - 참고: 이 변경을 되돌리려면 `MarkerFillMode` 속성을 Normal로 설정하면 됩니다
- TimeXAxis 및 OrdinalTimeXAxis에 대한 압축된 레이블 표시
- 새로운 마커 속성:
  - `MarkerFillMode` - 'MatchMarkerOutline'으로 설정할 수 있으며, 이 경우 마커가 외곽선에 따라 달라집니다
  - `MarkerFillOpacity` - 0부터 1 사이의 값으로 설정할 수 있습니다
  - `MarkerOutlineMode` - 'MatchMarkerBrush'로 설정할 수 있으며, 이 경우 마커의 외곽선이 채우기 브러시 색상에 따라 달라집니다
- 새로운 시리즈 `OutlineMode` 속성:
  - 시리즈 외곽선의 표시 여부를 전환하도록 설정할 수 있습니다. 참고로 Data Chart에서는 이 속성이 시리즈에 있습니다
- 새로운 플롯 영역 여백 속성:
  - `PlotAreaMarginLeft`
  - `PlotAreaMarginTop`
  - `PlotAreaMarginRight`
  - `PlotAreaMarginBottom`
  - `ComputedPlotAreaMarginMode`
  - 플롯 영역 여백 속성은 차트가 기본 확대/축소 수준일 때 뷰포트에 도입되는 번짐 영역을 정의합니다. 일반적인 용도는 축과 첫 번째/마지막 데이터 점 사이에 공간을 두는 것입니다. 참고로 아래에 나열된 `ComputedPlotAreaMarginMode`은(는) 마커가 활성화되면 여백을 자동으로 설정합니다. 나머지 속성은 두께를 나타내는 `Double`을(를) 지정하도록 설계되었으며, PlotAreaMarginLeft 등은 차트의 네 면 모든 공간을 조정합니다.
- 새로운 강조 표시 속성
  - `HighlightingMode` - 마우스가 올라간 시리즈 또는 올라가지 않은 시리즈를 흐리게 또는 밝게 할지 설정합니다
  - `HighlightingBehavior` - 마우스 위치(예: 항목 바로 위 또는 가장 가까운 항목)에 따라 시리즈를 강조 표시할지 설정합니다
  - 참고로 이전 릴리스에서는 강조 표시가 마우스 오버 시 흐려지는 효과로만 제한되어 있었습니다.
- 다음 시리즈에 강조 표시가 추가되었습니다:
  - Stacked
  - Scatter
  - Polar
  - Radial
  - Shape
- 다음 시리즈에 주석 레이어가 추가되었습니다:
  - Stacked
  - Scatter
  - Polar
  - Radial
  - Shape
- 스택형 시리즈 내부의 개별 스택 조각에 대해 데이터 소스를 재정의하는 기능이 추가되었습니다
- Stacked, Scatter, Range, Polar, Radial, Shape 시리즈에 사용자 지정 스타일 이벤트가 추가되었습니다
- 세로 확대/축소를 시리즈 콘텐츠에 자동으로 동기화하는 기능이 추가되었습니다
- 처음 표시되는 레이블에 따라 차트의 가로 여백을 자동으로 넓히는 기능이 추가되었습니다

### 차트 범례 기능

- ItemLegend에 가로 방향이 추가되었습니다
  - 다음 차트 유형은 가로 방향의 ItemLegend를 사용할 수 있습니다:
    - Bubble
    - Donut
    - Pie
- `LegendHighlightingMode` - 범례 항목 위에 마우스를 올리면 시리즈 강조 표시가 활성화됩니다

### 지리 지도 기능(CTP)

- 지도를 감싸서 표시하는 기능(가로로 무한 스크롤)이 추가되었습니다  
- 좌표 원점을 감싸는 동안 일부 지도 시리즈의 표시를 이동하는 기능이 추가되었습니다  
- Shape 시리즈의 강조 표시 기능이 추가되었습니다
- Shape 시리즈에 대한 일부 주석 레이어 기능이 추가되었습니다
