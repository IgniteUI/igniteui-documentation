# 스크롤 전략

스크롤 전략은 제공된 `IgxOverlayService`에서 스크롤이 어떻게 처리될지 결정합니다. 스크롤 전략은 네 가지가 있습니다:

1. **NoOperation** - 아무 작업도 하지 않습니다.
2. **Block** - 이벤트가 취소되며 컴포넌트는 창과 함께 스크롤되지 않습니다.
3. **Close** - 허용 오차를 사용하며, 허용 오차를 초과하면 스크롤 시 펼쳐진 컴포넌트를 닫습니다.
4. **Absolute** - 모든 것을 스크롤합니다.

## 사용법

모든 스크롤 전략에는 다음 메서드가 있습니다:

- <ApiLink kind="interface" type="IScrollStrategy" member="initialize" /> - 스크롤 전략을 초기화합니다. 문서의 참조, 오버레이 서비스, 렌더링된 컴포넌트의 id가 필요합니다
- <ApiLink kind="interface" type="IScrollStrategy" member="attach" /> - 스크롤 전략을 지정된 요소 또는 문서에 연결합니다
- <ApiLink kind="interface" type="IScrollStrategy" member="detach" /> - 스크롤 전략을 분리합니다

```typescript
this.scrollStrategy.initialize(document, overlayService, id);
this.scrollStrategy.attach();
this.scrollStrategy.detach();
```

### 시작하기

스크롤 전략은 <ApiLink type="OverlayService" member="attach" label="overlay.attach()" /> 메서드를 호출할 때 <ApiLink kind="interface" type="OverlaySettings" /> 매개변수의 속성으로 전달됩니다:

```typescript
// Initializing and using overlay settings
const overlaySettings: OverlaySettings = {
    positionStrategy: new GlobalPositionStrategy(),
    scrollStrategy: new AbsoluteScrollStrategy(), //Passes the scroll strategy
    modal: true,
    closeOnOutsideClick: true
}
const overlayId = overlay.attach(dummyElement, overlaySettings); 
```

<igc-divider></igc-divider>

오버레이가 사용하는 스크롤 전략을 변경하려면, 오버레이에 전달되는 <ApiLink kind="interface" type="OverlaySettings" /> 객체의 <ApiLink kind="interface" type="IScrollStrategy" /> 속성을 재정의하십시오. 전략이 이미 연결되어 있었다면, 이전에 생성된 ID를 분리해야 합니다:

```typescript
// overlaySettings is an existing object of type OverlaySettings
// to override the scroll strategy
const newOverlaySettings = Object.assing({}, overlaySettings);
Object.assing(newOverlaySettings, {
    scrollStrategy: new CloseScrollStrategy()
})
const overlayId = overlay.attach(dummyElement, newOverlaySettings);
overlay.show(overlayId);
```

## Modal

<ApiLink kind="interface" type="OverlaySettings" /> 객체는 불리언 속성(<ApiLink kind="interface" type="OverlaySettings" member="modal" />)을 전달하는 것도 허용합니다. 이 속성은 오버레이가 표시되는 방식을 제어합니다:

- <ApiLink kind="interface" type="OverlaySettings" member="modal" /> 속성이 `false`이면, 요소는 DOM 전경에 연결되지만 모든 요소는 여전히 활성 상태이며 상호 작용할 수 있습니다. 예를 들어 스크롤, 클릭 등이 가능합니다.
- <ApiLink kind="interface" type="OverlaySettings" member="modal" /> 속성이 `true`이면, 요소는 DOM 전경에 연결되고 그 뒤를 오버레이 차단기가 감싸서 모든 이벤트의 전파를 막습니다:
