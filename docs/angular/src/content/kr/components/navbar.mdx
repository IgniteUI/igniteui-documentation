# Angular Navbar 컴포넌트 개요

Ignite UI for Angular <ApiLink type="Navbar" />은(는) 사용자에게 애플리케이션 안의 현재 위치를 알려 주고, 브라우저의 "뒤로" 버튼처럼 뒤로 이동하도록 돕는 애플리케이션 머리글 컴포넌트입니다. Navigation Bar는 검색이나 즐겨찾기 같은 빠른 작업으로 이동하는 링크도 제공할 수 있어, 사용자가 잘못된 라우트나 상태로 이동하지 않고 애플리케이션을 원활하게 탐색하도록 돕습니다. 이 바는 배치된 컨테이너의 맨 위에 놓입니다.

## Ignite UI for Angular Navbar 시작하기

Ignite UI for Angular Navbar 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](./general/getting-started.mdx) 항목을 읽어 보십시오.

첫 번째 단계는 **app.module.ts** 파일 안에서 `IgxNavbarModule`을(를) 가져오는 것입니다.

```typescript
// app.module.ts

import { IgxNavbarModule } from 'igniteui-angular/navbar';
// import { IgxNavbarModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxNavbarModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxNavbarComponent`을 독립형(standalone) 종속성으로 가져올 수 있으며, [`IGX_NAVBAR_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/navbar/src/navbar/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수도 있습니다.

```typescript
// home.component.ts

import { IGX_NAVBAR_DIRECTIVES } from 'igniteui-angular/navbar';
// import { IGX_NAVBAR_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: '<igx-navbar title="Ignite UI for Angular"></igx-navbar>',
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IGX_NAVBAR_DIRECTIVES],
  /* or imports: [IgxNavbarComponent] */
})
export class HomeComponent {}
```

이제 Ignite UI for Angular Navbar 모듈 또는 디렉티브를 가져왔으므로 `igx-navbar` 컴포넌트를 사용할 수 있습니다.

## Angular Navbar 사용하기

그런 다음 컴포넌트의 템플릿에 다음 코드를 추가하여 제목이 있는 기본 navbar를 표시하십시오:

```html
{/*navbar.component.html*/}

<igx-navbar title="Ignite UI for Angular"> </igx-navbar>
```

### 메뉴 버튼 추가하기

메뉴 버튼을 추가하기 위해, `actionButtonIcon` 속성을 사용하여 작업 버튼을 표시하고 다음과 같이 메뉴 아이콘을 사용하도록 설정하겠습니다:

```html
{/*navbar.component.html*/}

<igx-navbar title="Sample App" actionButtonIcon="menu" [isActionButtonVisible]="true"></igx-navbar>
```

<DocsAside type="info">
<ApiLink type="Navbar" member="actionButtonIcon" label="actionButtonIcon" />은(는) 설계상 Material 글꼴 세트를 사용합니다.
</DocsAside>

### 아이콘 버튼 추가하기

검색, 즐겨찾기 등의 옵션을 추가하여 앱을 조금 더 기능적으로 만들 수 있습니다. 이를 위해 [**IgxIconButton**](./icon-button.mdx) 및 [**IgxIcon**](./layouts/icon.mdx) 모듈을 가져와 **app.module.ts** 파일에서 가져오겠습니다.

```typescript
// app.module.ts

...
import { IgxNavbarModule } from 'igniteui-angular/navbar';
import { IgxIconButtonDirective } from 'igniteui-angular/directives';
import { IgxIconModule } from 'igniteui-angular/icon';
// import { IgxNavbarModule, IgxButtonModule, IgxIconModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxIconButtonDirective, IgxIconModule],
})
export class AppModule {}
```

다음으로, 앱이 제공하려는 각 옵션에 대해 아이콘 버튼을 사용하도록 템플릿을 업데이트해야 합니다:

```html
{/*navbar.component.html*/}

<igx-navbar title="Sample App">
  <button igxIconButton="flat">
    <igx-icon>search</igx-icon>
  </button>
  <button igxIconButton="flat">
    <igx-icon>favorite</igx-icon>
  </button>
  <button igxIconButton="flat">
    <igx-icon>more_vert</igx-icon>
  </button>
</igx-navbar>
```

<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

### 사용자 지정 작업 추가하기

### 탐색 아이콘 추가하기

뒤로 이동하는 아이콘이 있는 navbar를 만들려면 몇 가지 단계를 따라야 합니다. 먼저 `actionButtonIcon` 속성을 사용하여 Material 글꼴 세트에서 적절한 아이콘을 고를 수 있습니다. 그다음 이전에 방문한 페이지가 있는지 간단히 확인하고, 그 결과를 <ApiLink type="Navbar" member="isActionButtonVisible" label="isActionButtonVisible" /> 속성에 전달할 수 있습니다. 마지막 단계는 뒤로 이동하는 메서드를 만들고 이를 <ApiLink type="Navbar" member="action" label="action" /> 속성에 연결하는 것입니다.

```html
{/*navbar.component.html*/}

<igx-navbar
  title="Ignite UI for Angular"
  actionButtonIcon="arrow_back"
  [isActionButtonVisible]="canGoBack()"
  (action)="navigateBack()"
>
</igx-navbar>
```

```typescript
export class NavbarSample3Component {
  constructor(private _location: Location) {}

  public ngOnInit() {}

  public navigateBack() {
    this._location.back();
  }

  public canGoBack() {
    return window.history.length > 0;
  }
}
```

### 사용자 지정 제목 추가하기

navbar 제목에 사용자 지정 콘텐츠를 제공하려면 `igx-navbar-title` 또는 `igxNavbarTitle` 디렉티브를 사용할 수 있습니다. 이들은 `title` 입력 속성으로 제공되는 기본 navbar 제목을 대체합니다. 아래 샘플은 이미지가 있는 링크를 포함하는 사용자 지정 제목을 보여 줍니다:

```html
{/*navbar.component.html*/}

<div class="sample-column">

  <igx-navbar>
    <igx-navbar-action>
      <button igxIconButton="flat">
        <igx-icon>menu</igx-icon>
      </button>
    </igx-navbar-action>

    <div igxNavbarTitle>
      <a href="https://www.infragistics.com/products/ignite-ui-angular" target="_blank">
        <img
          src="https://static.infragistics.com/marketing/Website/products/ignite-ui-landing/ignite-ui-logo.svg"
          width="120px"
          height="50px"
          alt
          style="margin-top: 7px;"
        />
      </a>
    
</div>

    <button igxIconButton="flat">
      <igx-icon>search</igx-icon>
    </button>
    <button igxIconButton="flat">
      <igx-icon>favorite</igx-icon>
    </button>
    <button igxIconButton="flat">
      <igx-icon>more_vert</igx-icon>
    </button>
  </igx-navbar>
```

## 스타일링

### Navbar 테마 속성 맵

기본 속성을 수정하면, 관련된 모든 종속 속성이 변경 사항을 반영하도록 자동으로 업데이트됩니다:

| 기본 속성 | 종속 속성 | 설명 |
| --- | --- | --- |
| **$background** | $text-color | navbar의 텍스트 색상입니다 |
|  | $idle-icon-color | navbar의 유휴 아이콘 색상입니다 |
|  | $hover-icon-color | navbar의 마우스 오버 아이콘 색상입니다 |
|  | $border-color (indigo 변형에서만 변경됨) | navbar의 테두리 색상입니다 |
| **$idle-icon-color** | $hover-icon-color | navbar의 마우스 오버 아이콘 색상입니다 |

navbar의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-navbar-theme" label="navbar-theme" code={true} />을(를) 확장하고 `$background` 및 `$idle-icon-color` 매개변수만 제공하는 새 테마를 만듭니다. 이 테마는 다양한 상호 작용 상태에 필요한 배경색과 전경색을 자동으로 계산합니다. 필요하다면 세부적인 모양 제어를 위해 특정 속성을 직접 재정의할 수도 있습니다.

```scss
$custom-navbar-theme: navbar-theme(
  $background: #011627,
  $idle-icon-color: #ecaa53,
);
```

<DocsAside type="info">
방금 한 것처럼 색상 값을 직접 하드코딩하는 대신, <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> 및 <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} /> 함수를 사용하면 색상을 훨씬 유연하게 다룰 수 있습니다. 사용 방법에 대한 자세한 안내는 [`Palettes`](./themes/sass/palettes.mdx) 항목을 참조하십시오.
</DocsAside>

마지막 단계는 새로 만든 테마를 `tokens` 믹스인에 전달하는 것입니다:

```scss
:host {
  @include tokens($custom-navbar-theme);
}
```

### Tailwind로 스타일링하기

사용자 지정 Tailwind 유틸리티 클래스를 사용하여 navbar의 스타일을 지정할 수 있습니다. 먼저 [Tailwind를 설정](./themes/tailwind.mdx)했는지 확인하십시오.

전역 스타일시트에 Tailwind를 가져온 다음, 다음과 같이 원하는 테마 유틸리티를 적용할 수 있습니다:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

유틸리티 파일에는 `light` 및 `dark` 테마 변형이 모두 포함되어 있습니다.

- 밝은 테마에는 `light-*` 클래스를 사용하십시오.
- 어두운 테마에는 `dark-*` 클래스를 사용하십시오.
- 접두사 뒤에 컴포넌트 이름을 붙이십시오. 예: `light-navbar`, `dark-navbar`.

적용하면 이 클래스는 동적 테마 계산을 가능하게 합니다. 그런 다음 `arbitrary properties`을 사용하여 생성된 CSS 변수를 재정의할 수 있습니다. 콜론 뒤에는 유효한 CSS 색상 형식(HEX, CSS 변수, RGB 등)을 입력하십시오.

속성의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-navbar-theme" label="navbar-theme" />에서 확인할 수 있습니다. 구문은 다음과 같습니다:

```html
<igx-navbar class="!light-navbar ![--background:#7B9E89] ![--text-color:#121E17]" title="Sample App">
  ...
</igx-navbar>
```

<DocsAside type="info">
유틸리티 클래스가 우선 적용되도록 느낌표(`!`)가 필요합니다. Tailwind는 스타일을 계층으로 적용하므로, 이 스타일을 중요(important)로 표시하지 않으면 컴포넌트의 기본 테마에 의해 재정의됩니다.
</DocsAside>
