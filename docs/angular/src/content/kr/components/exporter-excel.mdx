# Excel Exporter

<div class="highlight">

Ignite UI for Angular Excel Exporter 서비스는 원시 데이터(배열) 또는 [**IgxGrid**](/grid/grid), [**IgxTreeGrid**](/treegrid/tree-grid), [**IgxHierarchicalGrid**](/hierarchicalgrid/hierarchical-grid) 컴포넌트에서 Microsoft® Excel® 형식으로 데이터를 내보낼 수 있습니다. 내보내기 기능은 <ApiLink type="ExcelExporterService" /> 클래스에 캡슐화되어 있으며, 데이터는 MS Excel 표 형식으로 내보내집니다. 이 형식은 필터링, 정렬 등의 기능을 지원합니다.

## 사용법

IgniteUI Excel Exporter를 사용하려면 먼저 app.module.ts 파일에서 <ApiLink type="ExcelExporterService" />을(를) 가져오고 `providers` 배열에 서비스를 추가하십시오:

```typescript
// app.module.ts

...
import { IgxExcelExporterService } from 'igniteui-angular/grids/core';
// import { IgxExcelExporterService } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
  providers: [ IgxExcelExporterService ]
})

export class AppModule {}
```

<DocsAside type="info">
v12.2.1 이후에는 내보내기 서비스가 root에 제공되므로, 더 이상 AppModule providers에 선언할 필요가 없습니다.
</DocsAside>

내보내기 과정을 시작하려면 컴포넌트 템플릿의 버튼 핸들러를 사용할 수 있습니다.

```html
<button (click)="exportButtonHandler()">Export Data to Excel</button>
```

컴포넌트의 생성자에서 <ApiLink type="ExcelExporterService" /> 타입의 인수를 정의하면 내보내기 서비스에 접근할 수 있으며, Angular 프레임워크가 서비스의 인스턴스를 제공합니다. 데이터를 MS Excel 형식으로 내보내려면 내보내기 서비스의 <ApiLink type="ExcelExporterService" member="exportdata" label="exportData" /> 메서드를 호출해야 합니다. 이 메서드는 첫 번째 인수로 내보낼 데이터를 받고, 두 번째 인수는 <ApiLink type="ExcelExporterOptions" /> 타입이며 내보내기 과정을 구성할 수 있게 합니다.

다음은 컴포넌트의 TypeScript 파일에서 내보내기 과정을 실행하는 코드입니다:

```typescript
// component.ts

...
import { IgxExcelExporterService, IgxExcelExporterOptions } from 'igniteui-angular/grids/core';
// import { IgxExcelExporterService, IgxExcelExporterOptions } from '@infragistics/igniteui-angular'; for licensed package
...

public localData = [
  { Name: 'Eric Ridley', Age: '26' },
  { Name: 'Alanis Brook', Age: '22' },
  { Name: 'Jonathan Morris', Age: '23' }
];

constructor(private excelExportService: IgxExcelExporterService) {
}

public exportButtonHandler() {
  this.excelExportService.exportData(this.localData, new IgxExcelExporterOptions('ExportedDataFile'));
}

```

모든 것이 잘 되었다면 내보내기 버튼이 보일 것입니다. 버튼을 누르면 내보내기 과정이 시작되고, 브라우저는 `localData` 배열의 데이터를 MS Excel 형식으로 담은 "ExportedDataFile.xlsx"라는 파일을 내려받습니다.

## 내보내는 콘텐츠 사용자 지정하기

위 예제에서 Excel Exporter 서비스는 사용 가능한 모든 데이터를 내보냈습니다. 하지만 행이나 열 전체를 내보내지 않고 건너뛰고 싶을 때가 있습니다. 이를 위해 각 열과 각 행에 대해 각각 발생하는 <ApiLink type="ExcelExporterService" member="columnexporting" label="columnExporting" /> 및/또는 <ApiLink type="ExcelExporterService" member="rowexporting" label="rowExporting" /> 이벤트에 연결하고, 이벤트 인수 객체의 <ApiLink kind="interface" type="IRowExportingEventArgs" member="cancel" /> 속성을 `true`(으)로 설정하여 해당 이벤트를 취소할 수 있습니다.

다음 예제는 헤더가 "Age"이고 인덱스가 1인 열을 내보내기에서 제외합니다:

```typescript
// component.ts

this.excelExportService.columnExporting.subscribe((args: IColumnExportingEventArgs) => {
  if (args.header == 'Age' && args.columnIndex == 1) {
      args.cancel = true;
  }
});
this.excelExportService.export(this.igxGrid1, new IgxExcelExporterOptions('ExportedDataFile'));
```
