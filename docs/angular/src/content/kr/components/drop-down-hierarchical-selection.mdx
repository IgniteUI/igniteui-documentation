# 다중 선택 계층 드롭다운

다음 샘플은 사용자가 트리 형태의 계층 드롭다운 목록에서 단일 또는 여러 옵션을 선택할 수 있는 다중 선택 계층 드롭다운을 만드는 방법을 보여 줍니다.

## 항목 개요

드롭다운 목록에는 <ApiLink type="DropDown" />과 드롭다운을 열고 닫는 <ApiLink type="ToggleActionDirective" />를 사용합니다.

드롭다운에 계층 데이터를 표시하려면 <ApiLink type="Tree" /> 또는 <ApiLink type="TreeGrid" />를 사용할 수 있습니다.

<ApiLink type="Chip" />은(는) 선택된 항목을 표시하는 데 사용됩니다.

## 선택

목록에서 선택된 노드/행을 표시하려면, 선택 변경을 알리는 이벤트를 처리하고 `selectedNodes` / `selectedRows` 배열을 채우는 <ApiLink type="Chip" />을(를) 사용하십시오. 이는 IgxTreeComponent의 <ApiLink type="Tree" member="nodeSelection" label="nodeSelection" /> 이벤트와 IgxTreeGridComponent의 <ApiLink type="TreeGrid" member="rowSelectionChanging" label="rowSelectionChanging" /> 이벤트를 구독하여 할 수 있습니다.

DOM에서 칩을 제거하고 트리/그리드에서 항목 선택을 해제하려면 IgxChipComponent의 <ApiLink type="Chip" member="remove" label="remove" /> 이벤트를 처리해야 합니다.

또한 칩을 삭제할 때 드롭다운이 닫히지 않도록 막는 방법으로, 이벤트의 composite path에서 `igx-chip` 노드를 확인한 다음 `IgxDropDownComponent`의 <ApiLink type="DropDown" member="closing" label="closing" /> 이벤트 핸들러에서 이벤트를 취소할 수 있습니다.
