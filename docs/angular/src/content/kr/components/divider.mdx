## Ignite UI for Angular Divider 시작하기

Ignite UI for Angular Divider 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxDividerModule`을 가져오는 것입니다.

```typescript
// app.module.ts

...
import { IgxDividerModule } from 'igniteui-angular/directives';
// import { IgxDividerModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxDividerModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxDividerComponent`을(를) 독립형 종속성으로 가져올 수 있습니다.

```typescript
// home.component.ts

import { IgxDividerComponent } from 'igniteui-angular/directives';
// import { IgxDividerComponent } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: '<igx-divider></igx-divider>',
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxDividerComponent]
})
export class HomeComponent {}
```

이제 Ignite UI for Angular Divider 모듈 또는 컴포넌트를 가져왔으므로, `igx-divider` 컴포넌트를 사용하기 시작할 수 있습니다.

## Angular Divider 사용하기

### 세로 Divider

<ApiLink type="Divider" member="vertical" label="vertical" /> 속성을 추가하고 그 값을 `true`(으)로 설정하면 Divider의 방향을 가로에서 세로로 바꿀 수 있습니다.

```html
<igx-divider [vertical]="true"></igx-divider>
```

<Sample src="/layouts/divider-sample-2" height={238} alt="" />

### 점선 Divider

Divider의 기본 스타일은 `solid` 선이지만, `dashed`으로도 설정할 수 있습니다.
기본 모양을 바꾸려면 Divider의 <ApiLink type="Divider" member="type" label="type" /> 속성을 사용하고 그 값을 `dashed`(으)로 설정하십시오.

```html
<igx-divider type="dashed"></igx-divider>
```

<Sample src="/layouts/divider-sample-3" height={187} alt="" />

### 들여쓰기 Divider

Divider는 양쪽에 설정할 수 있습니다.
Divider를 들여쓰려면 Divider의 <ApiLink type="Divider" member="middle" label="middle" /> 속성을 `true`(으)로 설정하고 원하는 <ApiLink type="Divider" member="inset" label="inset" /> 값을 지정하십시오. 그러면 Divider가 양쪽 끝에서 줄어들기 시작합니다.

**값 끝에 단위(px, rem, % 등)를 붙여야 한다는 점을 기억하십시오. 그렇지 않으면 동작하지 않습니다.**

```html
// Both side
<igx-divider [middle]="true" inset="80px"></igx-divider>

// Left side only 
<igx-divider inset="40px"></igx-divider>

```

<Sample src="/layouts/divider-sample-4" height={311} alt="" />

<ApiLink type="Divider" member="middle" label="middle" /> 속성의 값이 false 값으로 설정되었거나 속성이 아예 생략된 경우, Divider는 왼쪽에만 들여쓰기가 적용됩니다.
