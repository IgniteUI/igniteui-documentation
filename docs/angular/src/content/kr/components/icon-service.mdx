# Angular Icon Service 개요

<div class="highlight">
Ignite UI for Angular Icon Service를 사용하면 개발자는 다양한 소스의 새 아이콘을 UI에 추가할 수 있습니다.
</div>

## 소개

Ignite UI for Angular Icon Service는 사용자가 아이콘 계열을 만들고 관리할 수 있도록 여러 메서드를 제공합니다.

아이콘 서비스는 Ignite UI for Angular 패키지에서 직접 import할 수 있습니다.

```ts
import { IgxIconComponent } from 'igniteui-angular/icon';
import { IgxIconService } from 'igniteui-angular/core';

@Component({
    selector: 'app-root',
    standalone: true,
    imports: [ IgxIconComponent ]
})
export class AppComponent implements OnInit {
    constructor(public iconService: IgxIconService) {}
}
```

### 아이콘 계열 추가하기

기본적으로 Icon Service는 기본 계열을 `material`(으)로 설정합니다.

새 아이콘 계열을 추가하려면 아이콘 서비스의 `setFamily` 메서드를 사용합니다. 이 메서드는 `igx-icon` 컴포넌트가 렌더링해야 할 아이콘에 대해 알려 주는 메타데이터가 포함된 계열 항목을 만듭니다.

`setFamily` 메서드가 어떻게 동작하는지 설명하기 위해 실제 예를 사용해 보겠습니다:

```ts
/** 
* The icon service associates a given family name (provided by the user) 
* with a specific CSS class (as documented in the providing icon font) 
* and corresponding icon name (documented in the icon font).
* NOTE: Material is already the default family.
*/ 
iconService.setFamily('material', { className: 'material-icons', type: 'liga' });
iconService.setFamily('fa-solid', { className: 'fas', type: 'font', prefix: 'fa' });
```

위 예는 두 개의 아이콘 계열 'material'과 'fa-solid'를 만듭니다. 이들의 유형은 다른데, `material` 계열은 `liga`(으)로, `fa-solid` 계열은 `font`(으)로 등록됩니다. 둘의 차이점은 `igx-icon` 컴포넌트가 이들을 렌더링하는 방식입니다. 일반적으로 [Font Awesome](https://fontawesome.com/)은 클래스 이름을 사용하여 **글꼴** 계열의 코드 포인트를 지정하므로, 그래서 유형을 `font`(으)로 설정했습니다. 아이콘을 렌더링하기 위해 코드 포인트에 의존해야 할 때마다 유형을 `font`(으)로 설정해야 합니다. [Material Icons](https://material.io/icons) 계열도 여전히 글꼴 계열이지만, 아이콘을 표시하는 표준 방식은 특정 코드 포인트를 가리키는 클래스 이름이 아니라 `ligature` 이름을 제공하는 것입니다. 따라서 유형을 `liga`(으)로 설정해야 합니다. 세 번째 계열 유형인 `svg`도 있으며, 이는 아이콘 서비스를 통해 등록된 SVG로 구성되는 아이콘 계열을 위해 예약되어 있습니다.

위의 두 글꼴 계열을 등록했으므로, 이제 `igx-icon` 컴포넌트를 통해 표준화된 방식으로 그 아이콘을 사용할 수 있습니다:

```html
<igx-icon family="material" name="home"></igx-icon>
<igx-icon family="fa-solid" name="car"></igx-icon>
```


<DocsAside type="info">
`igx-icon`로 기본 `material` 계열의 아이콘을 렌더링하려면, `index.html`에 다음 링크를 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

`material` 계열의 경우 이름으로 리가처 `name`를 사용했고, `fa-solid` 계열의 경우 이름으로 `className`를 지정했다는 것을 눈치채셨을 것입니다. 이 이름은 `fa-car`이지만, 이전 단계에서 아이콘 계열을 등록할 때 지정한 `fa-` 접두사는 뺍니다.

### SVG 아이콘 추가하기

Ignite UI for Angular Icon Service를 사용하면 SVG 이미지를 계열과 연결하고 이름을 지정할 수 있으므로, 글꼴 기반 아이콘과 같은 방식으로 `igx-icon` 컴포넌트를 통해 포함할 수 있습니다. SVG는 문자열이나 SVG 에셋의 절대 URI를 통해 해석되어야 합니다.

```ts
// Add a new 'material' icon called 'my-icon' from an SVG file
iconService.addSvgIcon('my-icon', 'my-icon.svg', 'material');

// Add a new 'fa-solid' icon called 'my-icon' from string 
iconService.addSvgIconFromText('my-icon', '<svg>...</svg>', 'fa-solid');
```

나중에 마크업에서:

```html
<igx-icon family="material" name="my-icon"></igx-icon>
<igx-icon family="fa-solid" name="my-icon"></igx-icon>
```

`liga` 및 `font` 유형의 계열에 사용자 지정 SVG 아이콘을 추가하고 있다는 점에 유의하십시오. 이는 `addSvgIcon` 및 `addSvgIconFromText` 메서드가 아이콘을 암시적으로 `svg` 유형으로 등록하여 `igx-icon` 컴포넌트가 SVG를 올바르게 렌더링할 수 있기 때문에 가능합니다.

## 메타 계열

Ignite UI for Angular Icon Service를 사용하면 글꼴 아이콘 계열을 설정하거나 공통 상위 아래 SVG를 추가하여 추가된 아이콘을 결합하는 가상 계열 맵을 만들 수 있으므로, 아이콘을 더 쉽게 참조할 수 있습니다.

```ts
// The `setIconRef` sets an icon reference in the icon map,
// assuming material and fa-solid have been added as families,
iconService.setIconRef('home', 'my-family', { family: 'material', name: 'home' });
iconService.setIconRef('home-alt', 'my-family', { family: 'fa-solid', name: 'home' });
iconService.setIconRef('car', 'my-family', { family: 'fa-solid', name: 'car' });
```

나중에 마크업에서:

```html
<igx-icon family="my-family" name="home"></igx-icon>
<igx-icon family="my-family" name="home-alt"></igx-icon>
<igx-icon family="my-family" name="car"></igx-icon>
```

## 아이콘 가져오기

주어진 `family`과 아이콘 `name`에 대한 아이콘을 가져와서 원래 아이콘의 `type`, `name`, `family`, `className`을(를) 읽을 수 있습니다.

```ts
const { family, className, name, type } = iconService.getIcon('my-family', 'car');

console.log(family); // -> 'fa-solid'
console.log(className); // -> 'fas'
console.log(name); // -> 'fa-car'
console.log(type); // -> 'font'
```

iconService.setIconRef('input_expand', 'default', {

## API

Ignite UI for Angular Icon Service에서 사용할 수 있는 모든 메서드의 간단한 요약은 다음과 같습니다.

### 계열 추가

```ts
setFamily(name: string, meta: IconFamilyMeta): IgxIconService;
```

### 아이콘 참조

아이콘 맵에 아직 없는 경우에만 설정:

```ts
addIconRef(name: string, family: string, icon: IconMeta): void;
```

아이콘 맵에 아이콘 참조를 설정합니다(이미 있으면 덮어씁니다):

```ts
setIconRef(name: string, family: string, icon: IconMeta): void;
```

아이콘 참조 가져오기

```ts
getIconRef(family: string, name: string): IconReference;
```

### SVG 아이콘

URI에서:

```ts
addSvgIcon(name: string, url: string, family: string, stripMeta = false): void;
```

문자열에서:

```ts
addSvgIconFromText(name: string, iconText: string, family: string, stripMeta = false): void;
```
