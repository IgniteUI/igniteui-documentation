# Angular Snackbar 컴포넌트 개요

<div class="highlight">
Ignite UI for Angular Snackbar 컴포넌트는 한 줄 메시지로 작업에 대한 피드백을 제공하며, 여기에는 작업 버튼을 포함할 수 있습니다. Snackbar 메시지는 다른 모든 요소 위에 나타나며 화면 하단 가운데에 위치합니다.
</div>

## Ignite UI for Angular Snackbar 시작하기

Ignite UI for Angular Snackbar 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](./general/getting-started.mdx) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxSnackbarModule`을 가져오는 것입니다.

```typescript
// app.module.ts

...
import { IgxSnackbarModule } from 'igniteui-angular/snackbar';
// import { IgxSnackbarModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxSnackbarModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxSnackbarComponent`을(를) 독립형 종속성으로 가져올 수 있습니다.

```typescript
// home.component.ts

import { IgxSnackbarComponent } from 'igniteui-angular/snackbar';
import { IgxButtonDirective } from 'igniteui-angular/directives';
// import { IgxSnackbarComponent, IgxButtonDirective } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <button igxButton="contained" (click)="snackbar.open()">Delete Message</button>
    <div>
        <igx-snackbar #snackbar>Message deleted</igx-snackbar>
    
</div>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxSnackbarComponent, IgxButtonDirective]
})
export class HomeComponent {}
```

이제 Ignite UI for Angular Snackbar 모듈 또는 컴포넌트를 가져왔으므로 `igx-snackbar` 컴포넌트를 사용할 수 있습니다.

## Angular Snackbar 사용하기

### Snackbar 표시하기

Snackbar 컴포넌트를 표시하려면 버튼 클릭 시 <ApiLink type="Snackbar" member="open" label="open()" /> 메서드를 호출하십시오.

```html
{/*sample.component.html*/}

<button igxButton="contained" (click)="snackbar.open()">Delete Message</button>
<div>
    <igx-snackbar #snackbar>Message deleted</igx-snackbar>
</div>
```

샘플이 올바르게 구성되었다면 데모 샘플을 볼 수 있을 것입니다. 버튼을 클릭하면 텍스트 메시지를 표시하는 snackbar가 나타납니다.
위 코드 조각에서 볼 수 있듯이, snackbar에 표시되는 메시지를 설정하는 한 가지 방법은 콘텐츠 프로젝션을 사용하는 것입니다. 하지만 어떤 사용자 지정 로직에 따라 값을 프로그래밍 방식으로 바꿔야 한다면, <ApiLink type="Snackbar" member="open" label="open()" /> 메서드에 값을 매개변수로 전달하면 됩니다.

```html
{/*sample.component.html*/}

<button igxButton="contained" (click)="snackbar.open('Message deleted')">Delete Message</button>
<button igxButton="contained" (click)="snackbar.open('Message deletion was not successful. Please try again')">Delete Message</button>
<div>
    <igx-snackbar #snackbar></igx-snackbar>
</div>
```

### 숨기기/자동 숨기기

열리면 snackbar는 <ApiLink type="Snackbar" member="displayTime" label="displayTime" /> 입력으로 지정된 기간이 지난 후 사라집니다. 이 입력은 처음에 4000밀리초로 설정되어 있습니다. 이 동작은 기본적으로 활성화되어 있지만, <ApiLink type="Snackbar" member="autoHide" label="autoHide" />을(를) **false**로 설정하여 바꿀 수 있습니다. 이렇게 하면 snackbar가 계속 보이게 됩니다. snackbar의 <ApiLink type="Snackbar" member="close" label="close()" /> 메서드를 사용하면 코드에서 컴포넌트를 닫을 수 있습니다.

```html
{/*sample.component.html*/}

<button igxButton="contained" (click)="snackbar.open()">Send message</button>
<div>
  <igx-snackbar #snackbar [autoHide]="false" actionText="CLOSE" (clicked)="close(snackbar)">Message sent</igx-snackbar>
</div>
```

```typescript
// sample.component.ts

public close(element) {
    element.close();
}
```

샘플이 올바르게 구성되었다면, 버튼을 클릭할 때 첫 번째 snackbar가 나타나며 _메시지_와 _작업 버튼_이 모두 표시됩니다. 자동 숨기기 기능은 비활성화되어 있으며, snackbar는 'CLOSE' 버튼을 클릭해야 사라집니다. 다른 snackbar는 <ApiLink type="Snackbar" member="open" label="open()" /> 메서드를 통해 다른 메시지를 전달하고, _표시 시간_이 지나면 숨겨집니다. 세 번째 컴포넌트는 <ApiLink type="Snackbar" member="open" label="open()" /> 메서드에 매개변수로 메시지를 전달하고, 콘텐츠 프로젝션을 사용하여 아이콘을 추가합니다.

<Sample src="/notifications/snackbar-sample-2" height={230} alt="" />

### 표시 시간

<ApiLink type="Snackbar" member="displayTime" label="displayTime" />을(를) 사용하고 밀리초 단위의 간격으로 설정하여 snackbar 컴포넌트가 보이는 시간을 구성하십시오. 앞서 말했듯이 기본값은 처음에 4000밀리초로 설정되어 있습니다.

### Snackbar 사용자 지정하기

메시지와 버튼보다 더 복잡한 요소를 표시하도록 Snackbar의 콘텐츠를 사용자 지정할 수도 있습니다. 예를 들어 파일을 로드하는 동안 snackbar를 표시하고 싶다면, 콘텐츠에 로딩 애니메이션을 추가할 수 있습니다.

```html
{/*sample.component.html*/}
<button igxButton="contained" (click)="snackbar.open()">Load file</button>
<div>
  <igx-snackbar #snackbar displayTime="5000">File loading
    <svg id="dots" height="20px">
        <g id="dots" fill="#FFFFFF">
            <circle id="dot1" cx="5" cy="18" r="2"></circle>
            <circle id="dot2" cx="15" cy="18" r="2"></circle>
            <circle id="dot3" cx="25" cy="18" r="2"></circle>
        </g>
    </svg>
  </igx-snackbar>
</div>
```

```scss
//sample.component.scss
#dots #dot1 {
    animation: load 1s infinite;
}

#dots #dot2 {
    animation: load 1s infinite;
    animation-delay: 0.2s;
}

#dots #dot3 {
    animation: load 1s infinite;
    animation-delay: 0.4s;
}

@keyframes load {
    0% {
      opacity: 0;
    }
    50% {
      opacity: 1;
    }
    100% {
      opacity: 0;
    }
}
```

그 결과 snackbar에 메시지와 세 개의 로딩 점이 나타납니다.

### 목록 안의 Snackbar

주요 snackbar 기능을 모두 다루었으므로, 이 컴포넌트를 더 흥미로운 시나리오에 통합할 수 있습니다. snackbar를 사용하여 알림을 제공하고 작업을 되돌릴 수 있는 기능을 제공할 수 있습니다.

삭제할 수 있는 연락처 목록을 만들어 보겠습니다. 항목이 삭제되면 메시지와 작업을 되돌리는 버튼이 들어 있는 snackbar가 표시됩니다.

```html
{/*sample.component.html*/}
<igx-list>
    <igx-list-item [isHeader]="true">Contacts</igx-list-item>

    <igx-list-item igxRipple="pink" igxRippleTarget=".igx-list__item" *ngFor="let item of navItems">
        <div class="item-container">

            <div class="contact">

                <igx-avatar [src]="item.avatar" shape="circle"></igx-avatar>
                <div class="contact__info">

                    <span class="name">{{item.text}}</span>
                
</div>
            
</div>
            <span igxIconButton="flat" igxRipple igxRippleCentered="true" (click)="delete(item)">
                <igx-icon [style.color]="'#ff5252'">delete</igx-icon>
            </span>
        
</div>

    </igx-list-item>

    <igx-snackbar actionText="Undo" (clicked)="restore()">Contact deleted</igx-snackbar>
</igx-list>
```

<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

```typescript
//sample.component.ts

import { Component, OnInit, ViewChild } from '@angular/core';
import { IgxSnackbarComponent } from 'igniteui-angular/snackbar';
// import { IgxSnackbarComponent } from '@infragistics/igniteui-angular'; for licensed package
...
@ViewChild(IgxSnackbarComponent)
public snackbar: IgxSnackbarComponent;
public navItems: any[];
public deletedItems = [];

constructor() { }

public ngOnInit() {
    this.navItems = [
        { avatar: 'assets/images/avatar/2.jpg', text: 'Richard Mahoney'},
        { avatar: 'assets/images/avatar/4.jpg', text: 'Lisa Landers' },
        { avatar: 'assets/images/avatar/14.jpg', text: 'Marianne Taylor' },
        { avatar: 'assets/images/avatar/17.jpg', text: 'Ward Riley' }
    ];
}

public delete(item) {
    this.deletedItems.push([item, this.navItems.indexOf(item)]);
    this.navItems.splice(this.navItems.indexOf(item), 1);
    this.snackbar.open();
}

public restore() {
    const [item, index] = this.deletedItems.pop();
    this.navItems.splice(index, 0, item);
    this.snackbar.close();
}
```

### 위치 지정

<ApiLink type="Snackbar" member="positionSettings" label="positionSettings" /> 속성을 사용하여 snackbar가 나타나는 위치를 구성할 수 있습니다. 기본적으로 페이지 하단에 표시됩니다. 아래 샘플에서는 알림이 상단 위치에 나타나도록 설정합니다.

```html
{/*sample.component.html*/}
<button igxButton="contained" (click)="open(snackbar)">Show notification on top</button>
<igx-snackbar #snackbar>Notification displayed</igx-snackbar>
```

```typescript
// sample.component.ts
import { VerticalAlignment, HorizontalAlignment } from 'igniteui-angular/core';
// import { VerticalAlignment, HorizontalAlignment } from '@infragistics/igniteui-angular'; for licensed package
...
public open(snackbar) {
    snackbar.positionSettings.verticalDirection = VerticalAlignment.Top;
    snackbar.positionSettings.horizontalDirection = HorizontalAlignment.Right;
    snackbar.open();
}
...
```

## 스타일링

### Snackbar 테마 속성 맵

기본 속성을 수정하면, 관련된 모든 종속 속성이 변경 사항을 반영하도록 자동으로 업데이트됩니다:

<table>
    <thead>
        <tr>
        <th>기본 속성</th>
        <th>종속 속성</th>
        <th>설명</th>
        </tr>
    </thead>
    <tbody>
        <tr class="primary">
        <td><strong>$background</strong></td>
        <td>$text-color</td>
        <td>snackbar에 사용되는 텍스트 색상입니다</td>
        </tr>
        <tr class="dependent"><td></td><td>$button-color</td><td>snackbar에 사용되는 버튼 색상입니다</td></tr>
    </tbody>
</table>

snackbar의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 index 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-snackbar-theme" label="snackbar-theme" code={true} />을(를) 확장하고 `$text-color`, `$background`, `$button-color` 및 `$border-radius` 매개변수를 받는 새 테마를 만듭니다.

```scss
$dark-snackbar: snackbar-theme(
  $text-color: #ffcd0f,
  $background: #292826,
  $button-color: #ffcd0f,
  $border-radius: 12px
);
```

<DocsAside type="info">
방금 한 것처럼 색상 값을 직접 하드코딩하는 대신, <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> 및 <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} /> 함수를 사용하면 색상을 훨씬 유연하게 다룰 수 있습니다. 사용 방법에 대한 자세한 안내는 [`Palettes`](./themes/sass/palettes.mdx) 항목을 참조하십시오.
</DocsAside>

마지막 단계는 애플리케이션에 컴포넌트 테마를 **포함**하는 것입니다.

```scss
:host {
    @include tokens($dark-snackbar);
}
```

### Tailwind로 스타일링하기

사용자 지정 Tailwind 유틸리티 클래스를 사용하여 snackbar의 스타일을 지정할 수 있습니다. 먼저 [Tailwind를 설정](./themes/tailwind.mdx)했는지 확인하십시오.

전역 스타일시트에 Tailwind를 가져온 다음, 다음과 같이 원하는 테마 유틸리티를 적용할 수 있습니다:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

유틸리티 파일에는 `light` 및 `dark` 테마 변형이 모두 포함되어 있습니다.

- 밝은 테마에는 `light-*` 클래스를 사용하십시오.
- 어두운 테마에는 `dark-*` 클래스를 사용하십시오.
- 접두사 뒤에 컴포넌트 이름을 붙이십시오. 예: `light-snackbar`, `dark-snackbar`.

적용하면 이 클래스는 동적 테마 계산을 가능하게 합니다. 그런 다음 `arbitrary properties`을 사용하여 생성된 CSS 변수를 재정의할 수 있습니다. 콜론 뒤에는 유효한 CSS 색상 형식(HEX, CSS 변수, RGB 등)을 입력하십시오.

속성의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-snackbar-theme" label="snackbar-theme" />에서 확인할 수 있습니다. 구문은 다음과 같습니다:

```html
<igx-snackbar
  class="!light-snackbar ![--background:#7B9E89]
  ![--button-color:#DD0D4B]">
  ...
</igx-snackbar>
```

<DocsAside type="info">
유틸리티 클래스가 우선 적용되도록 느낌표(`!`)가 필요합니다. Tailwind는 스타일을 계층으로 적용하므로, 이 스타일을 중요(important)로 표시하지 않으면 컴포넌트의 기본 테마에 의해 재정의됩니다.
</DocsAside>
