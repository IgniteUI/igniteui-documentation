# Angular Tile Manager 개요

Tile Manager 컴포넌트는 개별 타일에 콘텐츠를 표시할 수 있게 합니다. 사용자는 타일의 순서를 바꾸고 크기를 조정하여 이 타일들과 상호 작용할 수 있으며, 자신의 선호에 따라 콘텐츠의 레이아웃과 모양을 자유롭게 사용자 지정할 수 있습니다. 이러한 유연성은 콘텐츠를 보고 관리하는 더 개인화되고 효율적인 방법을 제공하여 사용자 경험을 향상시킵니다.

## Ignite UI for Angular Tile Manager 시작하기

Ignite UI Tile Manager는 표준 [웹 컴포넌트](https://developer.mozilla.org/en-US/docs/Web/Web_Components)이므로 Angular 애플리케이션에서 사용할 수 있습니다.

사용을 시작하려면 먼저 다음 명령을 실행하여 Ignite UI for Web Components 패키지를 설치해야 합니다:

```cmd
npm install igniteui-webcomponents --save
```

다음으로, `main.ts` 파일이나 `IgcTileManager`을(를) 사용하는 컴포넌트 `.ts` 파일에서 `IgcTileManagerComponent` 인수와 함께 `defineCustomElements()` 함수를 호출해야 합니다.

```ts
import { defineComponents, IgcTileManagerComponent } from 'igniteui-webcomponents';

defineComponents(IgcTileManagerComponent);
```

컴포넌트 구성에 `CUSTOM_ELEMENTS_SCHEMA` 스키마도 포함해야 합니다

```typescript
import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';

@Component({
    schemas: [CUSTOM_ELEMENTS_SCHEMA]
})
export class AppComponent {
```

이제 Angular Tile Manager의 기본 구성을 시작할 수 있습니다.

## 사용법

Tile Manager는 기본 타일 레이아웃 동작을 제공하며, 최대화 상태 또는 일반 상태의 타일 배치를 관리합니다. 타일은 서로 독립적으로 크기를 정할 수 있으며, 복잡한 레이아웃을 구성하는 데 사용할 수 있습니다. 최종 사용자는 타일을 끌어서 놓아 순서를 바꿀 수 있어, 유연하고 직관적인 경험을 제공합니다.

Tile Manager는 사용할 수 있는 두 가지 컴포넌트를 제공합니다:

- `IgcTileComponent` - Tile Manager 안에 표시되는 개별 타일을 나타내는 컴포넌트입니다.
- `IgcTileManagerComponent` - 모든 타일 컴포넌트를 담고 있는 기본 컴포넌트로, 전체 타일 레이아웃의 컨테이너 역할을 합니다.

```html
<igc-tile-manager>
  <igc-tile>
    <p>Tile 1</p>
  </igc-tile>
  <igc-tile>
    <p>Tile 2</p>
  </igc-tile>
  <igc-tile>
    <p>Tile 3</p>
  </igc-tile>
</igc-tile-manager>
```
