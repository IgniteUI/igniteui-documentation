# Angular Text Highlight 디렉티브 개요

Ignite UI for Angular의 <ApiLink type="TextHighlightDirective" />과(와) `IgxTextHighlightService`은(는) 텍스트의 일부를 강조하는 데 사용되며, 대소문자 구분 검색과 정확히 일치하는 항목만 강조하는 옵션을 제공합니다. 이를 통해 개발자는 이미 강조된 부분 중 어느 것이든 활성 강조를 유지할 수 있습니다.

## Ignite UI for Angular Text Highlight 디렉티브 시작하기

Ignite UI for Angular Text Highlight 디렉티브를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](./general/getting-started.mdx) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxTextHighlightModule`을 가져오는 것입니다.

```typescript
// app.module.ts
...
import { IgxTextHighlightModule } from 'igniteui-angular/directives';
// import { IgxTextHighlightModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [IgxTextHighlightModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxTextHighlightDirective`을(를) 독립형 종속성으로 가져올 수 있습니다.

```typescript
// home.component.ts

import { IgxTextHighlightDirective, IgxTextHighlightService } from 'igniteui-angular/directives';
// import { IgxTextHighlightDirective, IgxTextHighlightService } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: `
    <div
      igxTextHighlight
      [value]="html"
      [groupName]="'group1'"
      [containerClass]="'search-text'"
      class="search-text"
    >
      {{ html }}
    
</div>
  `,
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IgxTextHighlightDirective],
})
export class HomeComponent {
  constructor(public textHighlightService: IgxTextHighlightService) {}
}
```

이제 Ignite UI for Angular Text Highlight 모듈 또는 디렉티브를 가져왔으므로 `igxTextHighlight`을(를) 사용할 수 있습니다.

## Angular Text Highlight 디렉티브 사용하기

텍스트의 여러 부분을 강조하는 데 사용할 수 있는 검색 상자를 만들어 보겠습니다. Ignite UI for Angular의 [InputGroup](./input-group.mdx) 컴포넌트를 사용하며, 여기에 텍스트 입력과 일치 항목 지우기, 다음 찾기, 이전 찾기 버튼, 그리고 검색에서 대소문자를 구분할지 지정하는 버튼을 추가합니다. 또한 찾은 일치 항목의 개수를 표시하는 레이블도 있습니다.

```html
<div class="search-container">

  <igx-input-group type="search" class="input-group">
    <igx-prefix>
      @if (searchText.length == 0) {
        <igx-icon>search</igx-icon>
      }
      @if (searchText.length > 0) {
        <igx-icon (click)="clearSearch()">clear</igx-icon>
      }
    </igx-prefix>

    <input
      #search1
      id="search1"
      igxInput
      placeholder="Search"
      autocomplete="off"
      [(ngModel)]="searchText"
      (ngModelChange)="onTextboxChange()"
      (keydown)="searchKeyDown($event)"/>
    <igx-suffix>
      <div class="caseSensitiveButton">

        <button
          igxIconButton="flat"
          igxRipple
          igxRippleCentered="true"
          (click)="updateSearch()"
          [style.background]="caseSensitive ? 'rgb(73, 180, 254)' : 'transparent'">
          <igx-icon class="caseSensitiveIcon" fontSet="material">text_fields</igx-icon>
        </button>
      
</div>
      @if (searchText.length > 0) {
        <span>
          @if (matchCount > 0) {
            {{ index + 1 }} of {{ matchCount }} results
          }
          @if (matchCount == 0) {
            No results
          }
        </span>
      }

      <div class="searchButtons">

        <button
          igxIconButton="flat"
          igxRipple
          igxRippleCentered="true"
          (click)="findPrev()"
          [disabled]="!canMoveHighlight">
          <igx-icon fontSet="material">navigate_before</igx-icon>
        </button>
        <button
          igIconButton="flat"
          igxRipple
          igxRippleCentered="true"
          (click)="findNext()"
          [disabled]="!canMoveHighlight">
          <igx-icon fontSet="material">navigate_next</igx-icon>
        </button>
      
</div>
    </igx-suffix>
  </igx-input-group>
</div>
```

<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

그다음 텍스트가 있는 div와 IgxTextHighlight 디렉티브를 추가합니다. 값 입력을 div의 텍스트에 바인딩해야 하므로 div의 텍스트에도 보간을 사용한다는 점에 유의하십시오.

```html
<div
  igxTextHighlight
  [value]="html"
  [groupName]="'group1'"
  [containerClass]="'search-text'"
  class="search-text">
   {{html}}
</div>
```

컴포넌트의 .ts 파일에는 먼저 컴포넌트 템플릿의 바인딩에 사용되는 다음 필드를 추가해야 합니다:

```typescript
@Component({
    ...
})
export class HomeComponent {
    public html = '...';

    @ViewChild(IgxTextHighlightDirective, {read: IgxTextHighlightDirective})
    public highlight: IgxTextHighlightDirective;

    public searchText: string = '';
    public matchCount: number = 0;
    public caseSensitive: boolean = false;
    public index: number = 0;

    public get canMoveHighlight() {
        return this.matchCount > 1;
    }
}
```

다음으로 사용자가 검색 상자에 입력한 텍스트에 강조를 적용하고 활성 강조를 이동할 수 있게 하는 다음 메서드를 추가해야 합니다.

```typescript
@Component({
    ...
})
export class HomeComponent {
    constructor(public textHighlightService: IgxTextHighlightService) {}

    public searchKeyDown(ev) {
        if (this.searchText) {
            if (ev.key === 'Enter' || ev.key === 'ArrowDown' || ev.key === 'ArrowRight') {
                ev.preventDefault();
                this.findNext();
            } else if (ev.key === 'ArrowUp' || ev.key === 'ArrowLeft') {
                ev.preventDefault();
                this.findPrev();
            }
        }
    }

    public onTextboxChange() {
        this.index = 0;
        this.find(0);
    }

    public updateSearch() {
        this.caseSensitive = !this.caseSensitive;
        this.find(0);
    }

    public clearSearch() {
        this.searchText = '';
        this.find(0);
    }

    private findNext() {
        this.find(1);
    }

    private findPrev() {
        this.find(-1);
    }

    private find(increment: number) {
        if (this.searchText) {
            this.matchCount = this.highlight.highlight(this.searchText, this.caseSensitive);
            this.index += increment;

            this.index = this.index < 0 ? this.matchCount - 1 : this.index;
            this.index = this.index > this.matchCount - 1 ? 0 : this.index;

            if (this.matchCount) {
                this.textHighlightService.setActiveHighlight('group1', {
                    columnIndex: 0,
                    index: this.index,
                    page: 0,
                    rowIndex: 0
                });
            }
        } else {
            this.highlight.clearHighlight();
        }
    }
}
```

## 여러 요소에 걸친 검색

<ApiLink type="TextHighlightDirective" label="igxTextHighlight" />을(를) 사용하면 모두 하나의 활성 강조를 공유하는 여러 요소에 걸쳐 검색할 수 있습니다. 이는 여러 TextHighlight 디렉티브에 같은 <ApiLink type="TextHighlightDirective" member="groupName" label="groupName" /> 값을 지정하여 이루어집니다. 샘플을 설정하기 위해 이전 샘플의 검색 상자를 재사용하되, 이번에는 div 요소 두 개를 추가합니다. <ApiLink type="TextHighlightDirective" member="column" label="column" /> 및 <ApiLink type="TextHighlightDirective" member="row" label="row" /> 입력은 요소가 여러 개일 때 유용하며, 이 경우 두 번째 div는 다른 행 값을 가집니다.

```html
<div
  igxTextHighlight
  [groupName]="'group1'"
  [row]="0"
  [containerClass]="'search-text'"
  [value]="firstParagraph"
  class="search-text">
   {{firstParagraph}}
</div>
<div
  igxTextHighlight
  [groupName]="'group1'"
  [row]="1"
  [containerClass]="'search-text'"
  [value]="secondParagraph"
  class="search-text">
   {{secondParagraph}}
</div>
```

.ts 파일에는 텍스트 강조 디렉티브의 각 값 입력에 바인딩되는 `firstParagraph` 및 `secondParagraph` 필드가 있습니다. 또한 이제 템플릿에서 모든 강조를 가져오기 위해 ViewChild 대신 ViewChildren을 사용합니다.

```typescript
public firstParagraph = "...";

public secondParagraph = "...";

@ViewChildren(IgxTextHighlightDirective)
public highlights;
```

.ts 파일의 나머지 코드는 find 메서드를 제외하고 단일 요소 예제와 동일합니다. 이제 요소가 여러 개이므로 이 메서드를 변경해야 하지만, 페이지에 있는 TextHighlight 디렉티브의 수와 관계없이 그곳의 코드를 그대로 사용할 수 있습니다.

```typescript
@Component({
    ...
})
export class HomeComponent {
    constructor(public textHighlightService: IgxTextHighlightService) {}

    private find(increment: number) {
        if (this.searchText) {
            let count = 0;
            const matchesArray = [];

            this.highlights.forEach((h) => {
                count += h.highlight(this.searchText, this.caseSensitive);
                matchesArray.push(count);
            });

            this.matchCount = count;

            this.index += increment;
            this.index = this.index < 0 ? this.matchCount - 1 : this.index;
            this.index = this.index > this.matchCount - 1 ? 0 : this.index;

            if (this.matchCount) {
                let row;

                for (let i = 0; i < matchesArray.length; i++) {
                    if (this.index < matchesArray[i]) {
                        row = i;
                        break;
                    }
                }

                const actualIndex = row === 0 ? this.index : this.index - matchesArray[row - 1];

                this.textHighlightService.setActiveHighlight('group1', {
                    index: actualIndex,
                    rowIndex: row
                });
            }
        } else {
            this.highlights.forEach((h) => {
                h.clearHighlight();
            });
            this.matchCount = 0;
        }
    }
}
```

## 스타일

<ApiLink type="TextHighlightService" /> 디렉티브는 주어진 문자열이 나타나는 모든 곳의 색상과 배경을 바꾸는 방식으로 스타일을 지정할 수 있습니다. 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-highlight-theme" label="highlight-theme" code={true} />을(를) 확장하고 `$resting-background`, `$resting-color`, `$active-background` 및 `$active-color` 매개변수를 받는 새 테마를 만듭니다.

```scss
$dark-highlight: highlight-theme(
  $resting-background: #ffcd0f,
  $resting-color: #292826,
  $active-background: #292826,
  $active-color: #ffcd0f,
);
```

`$resting-background` 및 `$resting-color` 매개변수는 활성 강조 문자열을 제외한 모든 강조된 일치 항목에 적용되며, 활성 강조 문자열은 `$active-background` 및 `$active-color` 매개변수를 기준으로 스타일이 지정됩니다.

마지막 단계는 새로 만든 테마를 **포함**하는 것입니다.

```scss
:host {
  @include tokens($dark-highlight);
}
```

<DocsAside type="info">
토큰 재정의는 보통 에뮬레이션된 뷰 캡슐화를 통해 상속되지만, 생성된 선택기와 다음 예제의 사용자 지정 CSS 선택기가 컴포넌트 자체 템플릿 밖에서 만들어진 강조 요소를 대상으로 하면 여전히 `::ng-deep`을(를) 필요로 할 수 있습니다.
</DocsAside>

### 사용자 지정 스타일

강조된 텍스트 부분에 더 풍부한 스타일을 주고 싶다고 가정해 보겠습니다. 이를 위해 <ApiLink type="TextHighlightService" /> 디렉티브의 <ApiLink type="TextHighlightDirective" member="cssclass" label="cssClass" /> 및 <ApiLink type="TextHighlightDirective" member="activecssclass" label="activeCssClass" /> 입력을 활용할 수 있습니다. 이 클래스들을 <ApiLink kind="sass" module="themes" type="function-highlight-theme" label="highlight-theme" code={true} />의 스타일과 결합하면 사용자에게 멋진 경험을 제공할 수 있습니다!

해야 할 일은 몇 가지 속성을 가진 CSS 클래스를 몇 개 만들고, 위의 입력을 사용하여 이를 연결하는 것뿐입니다:

```html
<div
  igxTextHighlight
  [cssClass]="'custom-highlight'"
  [activeCssClass]="'custom-active-highlight'">
   {{html}}
</div>
```


```scss
// cssClass
.custom-highlight {
  border: 1px solid #ffcd0f;
}
// activeCssClass
.custom-active-highlight {
  box-shadow: 0 0 3px 0 rgba(0, 0, 0, 0.75);
}
```

앞서 언급했듯이, 이들을 테마와 결합할 수도 있습니다:

```scss
:host {
  ::ng-deep {
    @include tokens($dark-highlight);  
    
    .custom-highlight {
      border: 1px solid #ffcd0f;
    }  

    .custom-active-highlight {
      box-shadow: 0 0 3px 0 rgba(0,0,0, .5);
    }
  }
}
```
