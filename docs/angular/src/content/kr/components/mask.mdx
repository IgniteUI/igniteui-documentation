# Angular Mask Directive 개요

**텍스트 입력 필드**에 <ApiLink type="MaskDirective" label="igxMask" /> 디렉티브를 적용하면 개발자는 구성 가능한 마스크 규칙을 기준으로 사용자 입력을 제어하고 표시되는 값의 형식을 지정할 수 있습니다. 다양한 입력 옵션을 제공하며 사용과 구성이 쉽습니다.

## Ignite UI for Angular Mask 시작하기

Ignite UI for Angular Mask 디렉티브를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxMaskModule`과(와) `IgxInputGroupModule`을(를) 가져오는 것입니다.

<DocsAside type="info">
<ApiLink type="MaskDirective" label="igxMask" /> 디렉티브는 **text** 유형의 입력에 사용됩니다.
</DocsAside>

```typescript
// app.module.ts

...
import { IgxMaskModule } from 'igniteui-angular/input-group';
import { IgxInputGroupModule } from 'igniteui-angular/input-group';
// import { IgxMaskModule, IgxInputGroupModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxMaskModule, IgxInputGroupModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxMaskDirective`을(를) 독립형 종속성으로 가져올 수 있습니다.

```typescript
// home.component.ts

import { IgxMaskDirective, IGX_INPUT_GROUP_DIRECTIVES } from 'igniteui-angular/input-group';
// import { IgxMaskDirective, IGX_INPUT_GROUP_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-input-group>
        <igx-prefix>
            <igx-icon>phone</igx-icon>
        </igx-prefix>
        <label igxLabel>Phone</label>
        <input igxInput type="text" [igxMask]="'(####) 00-00-00 Ext. 9999'"/>
    </igx-input-group>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxMaskDirective, IGX_INPUT_GROUP_DIRECTIVES]
})
export class HomeComponent {}
```


<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

이제 Ignite UI for Angular Mask 모듈 또는 디렉티브를 가져왔으므로 `igxMask` 디렉티브를 사용할 수 있습니다.

## Angular Mask 사용하기

### 지원되는 기본 제공 마스크 규칙

<hr/>

| 마스크 문자 | 설명                                         |
| :------------- | :-------------------------------------------------- |
| 0              | 숫자(0-9)가 필요합니다                              |
| 9              | 숫자(0-9) 또는 공백이 필요합니다                   |
| #              | 숫자(0-9), 더하기(+) 또는 빼기(-) 기호가 필요합니다 |
| L              | 문자(a-Z)가 필요합니다                             |
| ?              | 문자(a-Z) 또는 공백이 필요합니다                  |
| A              | 영숫자(0-9, a-Z)가 필요합니다                 |
| a              | 영숫자(0-9, a-Z) 또는 공백이 필요합니다      |
| &              | 키보드의 모든 문자(공백 제외)            |
| C              | 키보드의 모든 문자                              |

### 입력에 마스크 적용하기

다음 예제에서는 내선 번호가 포함된 전화번호 마스크를 입력에 적용합니다.

```html
{/*sample.component.html*/}

<igx-input-group>
    <igx-prefix>
        <igx-icon>phone</igx-icon>
    </igx-prefix>
    <label igxLabel>Phone</label>
    <input igxInput type="text" [igxMask]="'(####) 00-00-00 Ext. 9999'"/>
</igx-input-group>
```

올바르게 구성되었다면 브라우저에서 데모 샘플을 볼 수 있을 것입니다.

<DocsAside type="info">
`IgxMaskDirective`은(는) IME 입력을 지원하며, 조합이 끝나면 마스크를 업데이트합니다.
</DocsAside>

### 형식이 지정된 값/원시 값에 바인딩

특정 마스크를 적용했을 때 폼에 바인딩할 입력 값(형식이 지정된 값 또는 원시 값)을 구성하려면 <ApiLink type="MaskDirective" member="includeLiterals" label="includeLiterals" /> 입력을 사용합니다. 기본적으로 <ApiLink type="MaskDirective" member="includeLiterals" label="includeLiterals" />은(는) *false*로 설정되어 있으며 원시 값이 사용됩니다.

```html
{/*sample.component.html*/}

<igx-switch [(ngModel)]="includeLiterals" (change)="clear()">
    Include Literals
</igx-switch>

<igx-input-group>
    <label igxLabel>
        Social Security Number
    </label>
    <input #ssn name="socialSecurityNumber" type="text"
        igxInput
        [igxMask]="'###-##-####'"
        [(ngModel)]="socialSecurityNumber"
        [includeLiterals]="includeLiterals" />
</igx-input-group>

@if (socialSecurityNumber.length > 0) {
    <p>Value: {{ socialSecurityNumber }}</p>
}
```

```typescript
// sample.component.ts

public socialSecurityNumber: string = '123-45-6789';
public includeLiterals: boolean = true;

public clear() {
    if (this.includeLiterals === false){
        this.socialSecurityNumber = '123-45-6789';
    } else {
        this.socialSecurityNumber = '';
    }
}
```

### 마스크가 적용된 값 검증하기

입력에 마스크를 설정하는 것 외에도 입력된 값을 검증할 수 있습니다. 다음 예제는 Mask 디렉티브와 Snack Bar 컴포넌트를 사용하여 마스크, 검증 및 잘못된 데이터에 대한 알림을 구현합니다.

```html
{/*sample.component.html*/}

<igx-input-group>
    <label igxLabel for="birthday">Birthday</label>
    <input igxInput #dateInput [igxMask]="'00/00/0000'" [igxTextSelection]="true" name="birthday" type="text"
        (blur)="validateDate(dateInput, snackbar)" />
</igx-input-group>

<igx-snackbar #snackbar></igx-snackbar>
```

```typescript
// sample.component.ts

public validateDate(dateInput, snackbar) {
    if (!this.isDateValid(dateInput.value)) {
        this.notify(snackbar, 'Invalid Date', dateInput);
    }
}

private isDateValid(date) {
    return (new Date(date).toLocaleString() !== 'Invalid Date');
}

private notify(snackbar, message, input) {
    snackbar.message = message;
    snackbar.show();
}
```

### 텍스트 선택

<ApiLink type="TextSelectionDirective" />을(를) 사용하면 포커스 시 컴포넌트가 모든 입력 텍스트를 선택하도록 강제할 수 있습니다. `igxTextSelection`에 대한 자세한 정보는 [Label & Input](/label-input#포커스--텍스트-선택)에서 확인할 수 있습니다.

**app.module.ts** 파일에서 `IgxTextSelectionModule`을(를) 가져오십시오:

```typescript
...
import { ..., IgxTextSelectionModule } from 'igniteui-angular/input-group';
// import { ..., IgxTextSelectionModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxTextSelectionModule]
    ...
})
export class AppModule {}
```

그런 다음 템플릿에 다음을 추가하십시오:

```html
<igx-input-group>
    <input igxInput [igxMask]="'###-##-####'" [igxTextSelection]="true"/>
</igx-input-group>
```

이 작동 방식은 앞의 샘플에서 확인할 수 있습니다.

<DocsAside type="info">
컴포넌트가 올바르게 동작하려면 `igxMask` 디렉티브 다음에 `igxTextSelection`을(를) 설정하는 것이 매우 중요합니다. 두 디렉티브 모두 입력의 `focus` 이벤트에서 동작하므로, 텍스트 선택은 마스크가 설정된 후에 이루어져야 하기 때문입니다.
</DocsAside>

### 포커스 및 블러 시 추가 형식 지정 적용하기

기본 마스크 동작 외에도 사용자는 직접 만든 사용자 지정 파이프를 구현하고 <ApiLink type="MaskDirective" member="focusedValuePipe" label="focusedValuePipe" /> 및 <ApiLink type="MaskDirective" member="displayValuePipe" label="displayValuePipe" /> 입력 속성을 활용하여, 입력이 포커스를 얻거나 잃을 때 값을 원하는 출력으로 변환할 수 있습니다. 이는 기본 모델 값에는 영향을 주지 않습니다. 이것이 어떻게 가능한지 보여 드리겠습니다!

표시되는 값의 끝에 '%' 기호를 추가하거나 제거하는 두 개의 파이프를 구현하십시오:

```typescript
@Pipe({ name: 'displayFormat' })
export class DisplayFormatPipe implements PipeTransform {
    public transform(value: any): string {
        if (value !== null && value !== undefined) {
            value = value.toString().trim();
            if (!value.endsWith('%')) {
                value += ' %';
            }
        }
        return value;
    }
}

@Pipe({ name: 'inputFormat' })
export class InputFormatPipe implements PipeTransform {
    public transform(value: any): string {
        if (value !== null && value !== undefined) {
            value = value.toString().replace(/%/g, '').trim();
        }
        return value;
    }
}
```

다음과 같이 각 파이프의 인스턴스를 <ApiLink type="MaskDirective" member="focusedValuePipe" label="focusedValuePipe" /> 및 <ApiLink type="MaskDirective" member="displayValuePipe" label="displayValuePipe" /> 입력 속성에 전달하십시오:

```typescript
public value = 100;
public displayFormat = new DisplayFormatPipe();
public inputFormat = new InputFormatPipe();
```

```html
<igx-input-group>
    <label igxLabel>Increase</label>
    <input
        igxInput
        type="text"
        [(ngModel)]="value"
        [igxMask]="'000'"
        [igxTextSelection]="true"
        [focusedValuePipe]="inputFormat"
        [displayValuePipe]="displayFormat"
    />
</igx-input-group>
```

그 결과, 블러 시(즉, 사용자가 입력 밖을 클릭할 때) 값 끝에 '%' 기호가 추가되고, 입력에 포커스가 가면 제거됩니다!

### 자리 표시자 추가하기

사용자는 기본 입력 placeholder 속성과 같은 역할을 하는 <ApiLink type="MaskDirective" member="placeholder" label="placeholder" /> 입력 속성도 활용할 수 있습니다. <ApiLink type="MaskDirective" member="placeholder" label="placeholder" />에 값을 지정하지 않으면 마스크에 설정된 값이 사용됩니다.

```typescript
value = null;
```

```html
<igx-input-group>
    <label igxLabel>Date</label>
    <input igxInput
    type="text"
    [(ngModel)]="value"
    [igxMask]="'00/00/0000'"
    [placeholder]="'dd/mm/yyyy'"/>
</igx-input-group>
```
