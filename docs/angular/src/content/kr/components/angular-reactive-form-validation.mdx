# Angular 반응형 폼 유효성 검사

## Angular의 반응형 폼이란 무엇입니까?

Angular의 반응형 폼은 기본 폼 객체 모델에 직접 접근할 수 있게 하며, 폼 입력을 처리하는 불변적이고 명시적인 방식을 제공합니다. 입력 값이 시간에 따라 바뀔 때, 폼의 상태는 고정되거나 유연하지 않은 방식에 의존하지 않고 반응형 폼이 관리합니다.

즉, 데이터 모델에 변경이 발생할 때마다 이른바 옵저버블 연산자가 기존 데이터 모델을 계속 갱신하는 대신 새로운 데이터 모델을 반환합니다. 이 방식은 폼의 상태를 깨끗하게 유지합니다.

Angular 반응형 폼은 다음과 같은 특성 덕분에 매우 확장성 있고, 재사용 가능하며, 견고한 것으로 여겨집니다:

**불변성**

Angular의 반응형 폼은 불변 또는 고정된 데이터 구조를 제공합니다. 기반 모델의 상태가 변경되면 갱신된 이 모델의 새로운 "버전"을 얻게 됩니다. 값은 새로워지지만, 어느 시점에서든 모든 (UI) 컨트롤과 일관되게 맞춰진 상태를 유지합니다.

**뛰어난 테스트 용이성**

반응형 폼을 사용하면 테스트가 매우 간단하며 설정이 적게 필요합니다. 대규모 애플리케이션에서는 이점이 매우 큽니다. 입력 스트림에 동기적으로 접근할 수 있고, UI를 렌더링하지 않고도 폼과 데이터 모델을 테스트할 수 있습니다.

**예측 가능성**

반응형 폼은 폼의 모든 고유한 변경을 추적하는 옵저버블 스트림을 기반으로 하며, (잘 구조화된 데이터 흐름 덕분에) 입력 값에 동기적으로 접근할 수 있게 합니다. 이는 결과적으로 반응형 폼을 매우 예측 가능하게 만듭니다.

**일관되고 구조화된 데이터 흐름**

Angular 반응형 폼의 데이터 흐름은 폼 로직이 컴포넌트 클래스에 의해 주도되므로 잘 구조화되어 있습니다. 이를 통해 컴포넌트 클래스의 FormControl 인스턴스에 검증자 함수를 직접 추가할 수 있습니다. 변경이 발생할 때마다 Angular가 이 함수들을 호출합니다.


## Angular 폼 유효성 검사란 무엇입니까?

Angular 폼 유효성 검사는 웹 폼에 사용자가 입력한 값이 올바르고 완전한지 확인하는 필수적인 기술 과정입니다. 템플릿 기반 방식 또는 Angular 반응형 폼으로 유효성 검사를 관리할 수 있습니다. 입력된 내용에 따라 폼은 사용자가 진행하도록 하거나, 데이터 입력에서 어디가 잘못되었는지 알 수 있도록 구체적인 오류 메시지를 표시합니다.

실패한 검증자에 따라 화면의 오류 메시지는 무엇이 잘못되었는지, 정확히 무엇을 입력하거나 다시 입력해야 하는지 피드백을 제공합니다. 일반적으로 앱은 회원 가입, 로그인, 온라인 프로필 업데이트, 민감한 정보 제출 등과 같은 데이터 입력 작업을 위해 폼을 사용합니다.

Angular는 웹 폼에 입력된 사용자 데이터가 정확하고 완전한지 확인하기 위해, 폼 입력 값이 변경될 때마다 폼 유효성 검사를 실행합니다. 이를 올바르게 수행하기 위해 Angular는 변경이 일어날 때마다 실행되는 검증자 목록을 호출합니다.

UI에서 사용자 입력에 대한 유효성 검사는 템플릿 기반 폼 또는 Angular 반응형 폼으로 수행할 수 있습니다. 두 방식 모두 다음 기본 클래스를 기반으로 합니다:

- FormControl
- FormGroup
- FormArray
- ControlValueAccessor

## Angular 반응형 폼 유효성 검사

반응형 폼은 시간에 따라 값이 바뀌는 폼 입력을 관리하기 위한 모델 중심 방식을 제공합니다. 반응형 폼은 컴포넌트 클래스를 기반으로 하므로, Angular 반응형 폼 유효성 검사는 컴포넌트 클래스의 폼 컨트롤 모델에 검증자 함수를 직접 추가하여 이루어집니다.

값이 유효하면 검증자는 `null`을(를) 반환합니다. 값이 유효하지 않으면 검증자는 오류 집합을 생성하며, 화면에 구체적인 오류 메시지를 표시할 수 있습니다.

`required`, `minlength`, `maxlength` 등과 같은 내장 검증자가 있습니다. 또한 직접 검증자를 만들 수도 있습니다.

간단한 사용자 지정 반응형 폼 검증자는 다음과 같이 작성할 수 있습니다:

```typescript
import { Directive, OnInit } from '@angular/core';
import { Validator, NG_VALIDATORS, AbstractControl, ValidationErrors } from '@angular/forms';

@Directive({
    selector: '[dateValueValidator]',
    providers: [{ provide: NG_VALIDATORS, useExisting: DateValueValidatorDirective, multi: true }]
})
export class DateValueValidatorDirective implements Validator {
    public validate(control: AbstractControl): ValidationErrors | null {
        if (!this.isDate(control.value)) {
            return { value: true };
        }

        return null;
    }

    private isDate(value: unknown): value is Date {
        return value instanceof Date
            && !isNaN(value.getTime());
    }
}
```

검증자는 비동기적으로 작성할 수도 있습니다:

```typescript
import { Directive, OnInit } from '@angular/core';
import { AsyncValidator, NG_ASYNC_VALIDATORS, AbstractControl, ValidationErrors } from '@angular/forms';
import { Observable, of } from 'rxjs';

@Directive({
    selector: '[dateValueAsyncValidator]',
    providers: [{ provide: NG_ASYNC_VALIDATORS, useExisting: DateValueAsyncValidatorDirective, multi: true }]
})
export class DateValueAsyncValidatorDirective implements AsyncValidator {
    public validate(control: AbstractControl): Observable<ValidationErrors | null> {
        if (!this.isDate(control.value)) {
            return of({ value: true });
        }

        return of(null);
    }

    private isDate(value: unknown): value is Date {
        return value instanceof Date
            && !isNaN(value.getTime());
    }
}
```

## Angular 반응형 폼 유효성 검사 예제

이 Angular 폼 유효성 검사 예제로 실제 반응형 폼 유효성 검사를 설정하는 방법을 살펴보겠습니다.

영화 예매를 위한 일반적인 예약 폼의 간단한 데모입니다. 하나 이상의 폼 입력이 불완전할 때 어떤 일이 일어나는지, 그리고 구체적인 오류 메시지가 어떻게 표시되는지 확인할 수 있습니다.

이 Angular 반응형 폼 유효성 검사 예제에서 필수 항목은 영화, 이름, 이메일, 장르입니다. 이 항목을 모두 입력하지 않으면 예매를 진행할 수 없으며 `book button`은(는) 비활성화된 상태로 남습니다.

따라서 영화 제목, 이름, 전화번호, 이메일 값을 입력하면 초록색으로 강조 표시됩니다. 하지만 `favorite genre`을(를) 선택하지 않으면 해당 필드가 빨간색으로 강조 표시되어 값 입력이 불완전함을 나타냅니다. 모든 값이 올바르게 설정되면 필드가 초록색으로 바뀌어 올바른 입력임을 나타냅니다. 그 후 `book button`이(가) 활성화되어 폼을 성공적으로 제출할 수 있습니다.

## Angular 폼 그룹 유효성 검사

폼 그룹은 캡슐화된 컨트롤의 상태에 접근할 수 있도록 여러 관련 `FormControlls`을(를) 묶은 것입니다. Angular 폼 그룹 유효성 검사는 그룹 컨트롤 또는 폼의 값과 폼 컨트롤 상태의 유효성 검사를 추적하는 데 도움이 됩니다. `FormGroup`은(는) `FormControl`과(와) 함께 사용됩니다.

## Angular 폼 사용자 지정 유효성 검사가 필요한 이유는 무엇입니까?

사용자 지정 검증자를 사용하면 다양한 기능을 처리하고, 폼의 값이 특정 기준을 충족하는지 확인할 수 있습니다. 내장 검증자만 사용해서는 이것이 불가능한 경우가 있습니다. 전화번호나 특정 비밀번호 패턴을 검증하려면 사용자 지정 검증자를 만들고 Angular 폼 사용자 지정 유효성 검사에 의존하는 것이 가장 좋습니다.

반응형 폼에서는 이러한 검증자를 만드는 것이 새 함수를 작성하는 것만큼 쉽습니다. 그리고 Angular의 반응형 폼과 같은 모델 중심 폼의 경우, 사용자 지정 검증 함수를 만들어 `FormControl` 생성자에 전달합니다.

아래에서 반응형 폼에 사용자 지정 폼 검증자를 작성하고 구현하는 방법을 확인할 수 있습니다.

```typescript
import { FormGroup, FormControl, Validators, ValidatorFn, ValidationErrors } from '@angular/forms';
import { Component, OnInit } from '@angular/core';

@Component({/* ... */})
export class MyComponent implements OnInit {
    public form: FormGroup;

    public ngOnInit(): void {
        this.form = new FormGroup({
            datePicker: new FormControl('', [Validators.required, this.dateValidator(new Date())])
        });
    }

    private dateValidator(val: Date): ValidatorFn {
        return (control: AbstractControl): ValidationErrors | null => {
            if (this.isDate(control.value)
                || this.valGreaterThanDate(control.value, val)) {
                return { value: true };
            }

            return null;
        }
    }

    private valGreaterThanDate(value: Date, date: Date): boolean {
        const value1 = new Date(value).setHours(0, 0, 0, 0);
        const value2 = new Date(date).setHours(0, 0, 0, 0);
        return value.getTime() > date.getTime();
    }

    private isDate(value: unknown): value is Date {
        return value instanceof Date
            && !isNaN(value.getTime());
    }
}
```
