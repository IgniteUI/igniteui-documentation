# Angular Chat 개요

Chat 컴포넌트는 애플리케이션에서 대화형 인터페이스를 만들기 위한 완전한 솔루션을 제공합니다. 고객 지원 도구, 공동 작업 공간 또는 챗봇 어시스턴트를 만들든, Chat 컴포넌트는 필요한 구성 요소를 제공합니다. 즉, 텍스트 메시지 보내기와 받기, 파일 첨부 업로드, 빠른 답장 추천 항목 표시, 상대방이 응답을 입력하는 동안 입력 표시기 표시가 가능합니다.

정적인 메시지 목록과 달리 Chat 컴포넌트는 상호 작용이 가능하며 **실시간 통신**을 위해 설계되었습니다. 입력, 렌더링 및 사용자 상호 작용을 관리하며, 메시지와 첨부 파일이 표시되는 방식을 완전히 제어할 수 있습니다. 또한 레이아웃이나 시각 요소의 모든 부분을 재정의할 수 있는 광범위한 렌더링 API를 제공합니다.

## 설치

시작하려면 Ignite UI for Angular 패키지와 UI를 구동하는 Ignite UI for Web Component 패키지를 함께 설치하십시오:

```cmd
npm install igniteui-angular igniteui-webcomponents
```

<ApiLink type="Chat" />은(는) Angular 바인딩(이벤트, 템플릿, DI, 변경 감지, 파이프)을 제공하며, 시각적 채팅 UI는 Web Component가 렌더링합니다. 두 가지를 모두 설치하면 채팅이 Angular에서 네이티브로 동작하면서도 Web Component의 전체 UI를 활용할 수 있습니다.

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

설치한 후에는 프로젝트에서 컴포넌트를 가져올 수 있습니다:

```ts
import { Component } from '@angular/core';
import { IgxChatComponent } from "igniteui-angular/chat";

@Component({
  ...
})
export class AppComponent { ... }
```

## 사용법
채팅 옵션을 정의하고 템플릿에 바인딩하십시오:

```ts
import { IgxChatComponent, IgxChatOptions } from "igniteui-angular/chat";

public options: IgxChatOptions  = {
  currentUserId: 'me',
  headerText: 'Support Chat',
};
```

```html
<igx-chat 
    [options]="options"
    [messages]="messages">
</igx-chat>
```

여기서 `currentUserId` 속성은 컴포넌트에 어떤 메시지가 "발신"(현재 사용자가 보낸 메시지)이고 어떤 메시지가 "수신"(다른 사람이 보낸 메시지)인지 알려 줍니다. `headerText`은(는) 채팅 창의 제목을 제공합니다.

렌더링되면 바인딩된 메시지 배열을 업데이트하여 프로그래밍 방식으로 메시지를 추가할 수 있습니다:

```ts
public addMessage() {    
    const newMessage = {
      id: '1',
      sender: 'me',
      text: 'Hello! How can I help you?',
      timestamp: Date.now().toString()
    };
    this.messages = [...this.messages, newMessage ];
}
```

이 방식을 사용하면 서버 엔드포인트, 챗봇 엔진 또는 공동 작업 앱 백엔드와 같은 자체 데이터 소스에 Chat을 쉽게 연결할 수 있습니다.

### 입력
Chat 컴포넌트는 상태와 구성을 제어할 수 있는 몇 가지 주요 속성을 제공합니다:

| 이름              | 설명                                                                                                                                                          |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `messages`        | 채팅에 표시되는 메시지의 양방향 배열(`IgcChatMessage[]`)입니다. 사용자가 메시지를 보내면 Chat이 제공된 컬렉션을 업데이트합니다.                     |
| `draftMessage`    | 아직 전송되지 않은 현재 메시지로, `text`과(와) 선택적 `attachments`을(를) 포함하는 객체로 표현됩니다. 메시지 초안을 저장하거나 복원하는 데 유용합니다.            |
| `options`         | 현재 사용자 ID, 입력 자리 표시자, 허용되는 파일 형식, 빠른 답장 추천 항목, 입력 표시 동작 등 채팅 구성(<ApiLink type="ChatOptions" />)입니다. |
| `templates` | 메시지 콘텐츠, 입력, 첨부 파일 및 채팅 UI의 기타 부분을 위한 사용자 지정 Angular 템플릿(<ApiLink type="ChatTemplates" />)입니다.                                   |

이 속성들을 사용하면 Chat의 UI를 애플리케이션 상태 및 백엔드와 간단하게 동기화할 수 있습니다.

#### 양방향 메시지 컬렉션

`messages` 컬렉션은 양방향입니다. 애플리케이션이 표시할 메시지를 제공하면, 대화가 계속되면서 Chat이 원래 컬렉션을 업데이트합니다. 사용자가 메시지를 보낸 후에는 컬렉션에 대한 참조를 가진 코드가 새로 만들어진 메시지에 접근할 수 있습니다. 이는 `[(messages)]`를 사용하는 Angular 양방향 바인딩이 아니라 컬렉션에 대한 제자리 업데이트입니다.

`messageCreated` 이벤트는 저장 또는 기타 부수 효과에 대한 알림입니다. 생성된 메시지를 컬렉션에 다시 추가하지 마십시오.

원래 컬렉션이 변경되지 않아야 한다면 Chat에 얕은 복사본을 전달하십시오:

```ts
public messages = [...this.originalMessages];
```

기존 메시지 객체는 여전히 공유됩니다. 이 객체들도 독립적으로 유지되어야 한다면, 복사된 컬렉션을 만들 때 각 메시지의 새 인스턴스를 만드십시오.

### 첨부 파일
현대의 대화는 텍스트만으로 이루어지는 경우가 드뭅니다. Chat 컴포넌트에는 사용자가 이미지, 문서 및 기타 파일을 공유할 수 있도록 파일 첨부 기능이 기본으로 포함되어 있습니다.
기본적으로 입력 영역에는 첨부 버튼이 있습니다. `acceptedFiles` 속성을 설정하여 허용할 파일 형식을 제어할 수 있습니다:

```ts
public options: IgxChatOptions = {
  acceptedFiles: "image/*,.pdf",
};
```

이 예제에서 사용자는 이미지와 PDF 파일만 업로드할 수 있습니다.
사용 사례에 첨부 파일이 필요하지 않다면 쉽게 끌 수 있습니다:

```ts
public options: IgxChatOptions = {
  disableInputAttachments: true,
};
```

### 추천 항목
빠른 답장 추천 항목은 사용자가 탭하여 즉시 답장할 수 있는 미리 정의된 응답을 제공합니다. 이 기능은 챗봇, 고객 서비스 흐름 또는 사용자를 구조화된 과정에서 안내할 때 특히 유용합니다.
문자열 배열을 suggestions 속성에 바인딩하여 추천 항목을 제공할 수 있습니다. `suggestionsPosition` 속성을 사용하면 추천 항목이 표시되는 위치를 입력 영역 아래 또는 메시지 목록 아래 중에서 제어할 수 있습니다.

```ts
public options: IgxChatOptions = {
  currentUserId: "me",
  suggestions: ['Yes', 'No', 'Maybe later'],
  suggestionsPosition: "below-input"
};
```

이 방식은 반복적인 답변을 입력할 필요를 줄여 사용자 상호 작용을 간소화하고, 안내된 대화에서 전반적인 경험을 개선합니다.

### 입력 표시기
참여자가 상대방이 입력 중인 것을 볼 수 있으면 대화가 더 자연스럽게 느껴집니다. Chat 컴포넌트는 옵션 객체의 `isTyping` 속성을 통해 이 동작을 제공합니다.
true로 설정하면 채팅은 메시지 아래에 은은한 입력 표시기를 표시합니다:

```ts
public options: IgxChatOptions = {
  isTyping: true
};
```

이 기능은 일반적으로 프로그래밍 방식으로 전환되며, 예를 들어 백엔드 서비스에서 입력 이벤트를 받을 때 사용합니다.

### 사용자 지정 템플릿
Chat 컴포넌트는 기본 UI로 바로 사용할 수 있지만, 많은 애플리케이션은 모양과 느낌을 사용자 지정해야 합니다. 예를 들어 읽음 확인을 추가하거나, 아바타를 표시하거나, 입력 영역을 음성 녹음 버튼으로 바꾸고 싶을 수 있습니다.
Chat 컴포넌트는 Angular 템플릿을 사용하여 이 요구를 해결합니다. 템플릿은 `templates` 입력을 통해 제공되며 강한 타입의 Angular 디렉티브를 사용합니다.

#### 사용 가능한 템플릿
Chat의 다음 부분을 사용자 지정할 수 있습니다:
- 메시지 수준: message, messageHeader, messageContent, messageAttachments, messageActions
- 첨부 파일 수준: attachment, attachmentHeader, attachmentContent
- 입력 수준: input, inputActions, inputActionsStart, inputActionsEnd, inputAttachments, fileUploadButton, sendButton
- 추천 항목: suggestionPrefix
- 기타: typingIndicator

이 세분화 수준 덕분에 전체 채팅 레이아웃을 다시 작성하지 않고도 한 부분만 조정할 수 있습니다(예: 첨부 파일의 모양).

#### 사용자 지정 메시지 콘텐츠

```html
<igx-chat
        [options]="options"
        [messages]="messages"
        [templates]="{ messageContent: messageContent }">
</igx-chat>
<ng-template #messageContent let-message igxChatMessageContext>
  <div class="custom-message">

    <strong>{{ message.sender }}:</strong> {{ message.text }}
  
</div>
</ng-template>
```

여기서:
- `let-message`은(는) 메시지 객체를 노출합니다.
- <ApiLink type="ChatMessageContextDirective" label="igxChatMessageContext" /> 디렉티브는 메시지 템플릿의 올바른 타입 지정을 보장합니다.

#### 사용자 지정 입력 영역
기본적으로 채팅 입력은 텍스트 영역입니다. 음성 입력 버튼을 추가하는 등 보다 맞춤화된 환경을 제공하려면 이를 재정의할 수 있습니다:

```html
<igx-chat
  [options]="options"
  [templates]="{ input: customInput }">
</igx-chat>

<ng-template #customInput let-input igxChatInputContext>
  <div class="custom-input">

    <textarea [(ngModel)]="input.value"></textarea>
    <button (click)="speechToText()">🎤</button>
  
</div>
</ng-template>
```

#### 입력 작업 확장하기
Chat 컴포넌트는 기본 작업(업로드 및 전송)을 유지하면서 추가 컨트롤로 확장하고 싶을 때 유용한 두 가지 템플릿을 제공합니다:
- `inputActionsStart` – 기본 제공 업로드 버튼 뒤에 사용자 지정 콘텐츠를 삽입할 수 있습니다.
- `inputActionsEnd` – 기본 제공 전송 버튼 뒤에 사용자 지정 콘텐츠를 삽입할 수 있습니다.

예를 들어 업로드 버튼 뒤에 음성 녹음 버튼을 추가하거나, 전송 버튼 뒤에 추가 옵션 메뉴를 추가할 수 있습니다.
다음 예제에서는 기본 업로드 버튼을 유지하면서 그 옆에 마이크 버튼을 추가합니다. 반대편에서는 기본 전송 버튼을 제거하고 사용자 지정 Ask 버튼과 "더보기" 메뉴로 바꿉니다:

```html
<igx-chat
  [options]="options"
  [templates]="{
    inputActionsStart: inputStart,
    inputActionsEnd: inputEnd
  }">
</igx-chat>

<ng-template #inputStart>
  <button class="icon-btn">🎤</button>
</ng-template>

<ng-template #inputEnd>
  <button (click)="ask()">Ask</button>
  <button class="icon-btn">⋮</button>
</ng-template>
```

이 설정에서:
- 업로드 버튼은 그대로 유지됩니다.
- 그 뒤에 마이크 버튼이 추가됩니다(inputActionsStart).
- 기본 전송 버튼은 제거되고, 사용자 지정 Ask 버튼과 "더보기" 아이콘으로 대체됩니다(inputActionsEnd).

이 방식은 입력 영역을 처음부터 다시 만들지 않고도 작업을 추가, 제거 또는 재정렬할 수 있도록 하여 채팅 입력 막대를 완전히 유연하게 구성할 수 있게 합니다.

### Markdown 지원
Chat 컴포넌트는 `fromMarkdown` 파이프를 통해 Markdown 콘텐츠를 기본으로 지원합니다. 이 파이프는 메시지 텍스트를 안전한 HTML로 변환합니다. 이를 통해 서식이 있는 텍스트, 링크, 목록, 심지어 구문 강조가 적용된 코드 블록이 포함된 메시지를 표시할 수 있으며, 렌더링되는 모든 HTML은 보안을 위해 정화됩니다.

Markdown 렌더링은 성능상의 이유로 비동기적으로 수행되므로, `fromMarkdown` 파이프는 Angular의 `async` 파이프와 함께 사용해야 합니다.

예제 — 템플릿 안에서 Markdown 렌더링:

```html
<ng-template #messageContent let-message igxChatMessageContext>
    <div [innerHTML]="message.text | fromMarkdown | async"></div>
</ng-template>
```

이 예제에서:
- 각 메시지의 text 속성은 [marked](https://github.com/markedjs/marked) 라이브러리를 사용하여 Markdown으로 파싱됩니다.
- 렌더러는 [DOMPurify](https://github.com/cure53/DOMPurify)를 사용하여 출력을 정화합니다.
- 링크는 안전한 rel 속성과 함께 자동으로 새 탭에서 열립니다.

#### 구문 강조
`fromMarkdown` 파이프는 코드 블록의 구문 강조도 지원합니다. 메시지에 펜스 코드(```js...```)가 포함되면, VS Code에서 사용하는 고품질 코드 강조기인 [Shiki](https://shiki.matsu.io/)로 렌더링됩니다. 기본적으로 github-light 테마로 JavaScript, TypeScript, HTML 및 CSS에 대한 강조를 포함합니다.

예제 — 메시지에 다음이 포함된 경우:

```markdown
Here is a JavaScript example:
\`\`\`ts
function greet(name: string) {
  return `Hello, ${name}!`;
}
\`\`\`
```

채팅 메시지 안의 출력은 다음과 같이 표시됩니다:
- 자동 구문 강조
- 테마 인식 스타일링(github-light / github-dark)
- 적절한 들여쓰기와 고정폭 글꼴
- 추가 구성은 필요하지 않습니다. 기본 테마가 자동으로 로드됩니다.

### 출력(이벤트)
애플리케이션 로직과 통합하려면 Chat 컴포넌트는 다음 이벤트 집합을 발생시킵니다:
- messageCreated – 새 메시지가 생성될 때.
- messageReact – 메시지에 반응이 있을 때.
- attachmentClick – 첨부 파일을 클릭할 때.
- attachmentAdded – 첨부 파일이 추가될 때.
- attachmentRemoved – 첨부 파일이 제거될 때.
- attachmentDrag – 첨부 파일을 끌고 있는 동안.
- attachmentDrop – 첨부 파일을 놓을 때.
- typingChange – 입력 상태가 바뀔 때.
- inputFocus / inputBlur – 입력 포커스 이벤트.
- inputChange – 입력 값이 바뀔 때.

이 이벤트를 수신하여 백엔드와 동기화할 수 있습니다:

```html
<igx-chat
        [options]="options"
        [messages]="messages"
        (messageCreated)="onMessageCreated($event)">
</igx-chat>
```

### 슬롯

| 슬롯 이름             | 설명                                                              |
| :-------------------- | :----------------------------------------------------------------------- |
| `prefix`              | 채팅 제목 앞에 콘텐츠(예: 아바타 또는 아이콘)를 삽입하는 슬롯입니다. |
| `title`               | 채팅 제목 콘텐츠를 재정의하는 슬롯입니다.                              |
| `actions`             | 헤더 작업(예: 버튼, 메뉴)을 삽입하는 슬롯입니다.                |
| `suggestions-header`  | 추천 항목 목록에 대한 사용자 지정 헤더를 렌더링하는 슬롯입니다.             |
| `suggestions`         | 빠른 답장 추천 항목의 사용자 지정 목록을 렌더링하는 슬롯입니다.             |
| `suggestions-actions` | 추가 작업을 렌더링하는 슬롯입니다.                                   |
| `suggestion`          | 개별 추천 항목 하나를 렌더링하는 슬롯입니다.                             |
| `empty-state`         | 메시지가 없을 때 표시되는 슬롯입니다.                                   |

이 슬롯을 사용하면 헤더 또는 추천 항목 영역에 사용자 지정 UI를 삽입할 수 있습니다:

```html
<igx-chat>
  <span slot="actions">
    <button class="icon">⚙️</button>
  </span>
</igx-chat>
```

#### 루트 스타일 적용(adoptRootStyles)

Chat 컴포넌트의 옵션에는 고급 스타일링 시나리오를 위한 특별한 플래그가 있습니다:

| 옵션            | 타입      | 기본값 | 설명                                                                                                                                                                                                                                    |
| :---------------- | :-------- | :------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `adoptRootStyles` | `boolean` | false   | `true`인 경우, 컴포넌트의 Shadow DOM 안에 렌더링된 콘텐츠(예: 사용자 지정 렌더러에서 렌더링된 콘텐츠)가 문서의 루트에서 스타일을 상속할 수 있습니다. 이는 스타일링을 위한 빠른 임시 방법이지만 운영 환경에서는 **권장되지 않습니다**. |

이 속성은 사용자 지정 렌더링 템플릿에 전역 CSS를 적용할 때 Shadow DOM 캡슐화를 다루고 싶지 않은 경우에 유용할 수 있습니다.
그러나 다음과 같은 절충점이 있습니다:
- ✅ 편의성: (문서의) 전역 스타일이 사용자 지정 메시지 렌더러에 영향을 줄 수 있습니다.
- ⚠ 위험: 캡슐화를 깨뜨려, 전역 CSS가 의도치 않게 내부 시각 요소를 바꾸는 스타일 누출을 일으킬 수 있습니다.
- 🔒 일회성 설정: 이 옵션은 초기화 시에만 설정할 수 있습니다. 실행 중에 변경해도 효과가 없습니다.

이 속성을 사용하기 전에 표준 Web Component 스타일링 방식을 사용하는 것을 강력히 권장합니다:
- CSS 변수 및 ::part API – 노출된 파트와 변수를 통해 사용자 지정하는 것을 우선하십시오.
- `<link>` 요소 – 더 큰 스타일시트는 Shadow DOM 안에 삽입하십시오.
- 인라인 `<style>` 태그 – 작고 범위가 한정된 스타일 재정의에 사용하십시오.

### 채팅 테마

**CSS 파트**와 **슬롯** 외에도, Chat 컴포넌트에는 테마 엔진이 노출하는 <ApiLink kind="sass" module="themes" type="function-chat-theme" label="chat-theme" code={true} /> 함수가 있습니다.

테마 함수를 사용하여 Chat 컴포넌트의 스타일을 지정하려면, 먼저 모든 테마 함수와 `tokens()` 믹스인을 내보내는 테마 모듈을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

그런 다음 <ApiLink kind="sass" module="themes" type="function-chat-theme" label="chat-theme" code={true} />을(를) 확장하고 `$header-background`, `$sent-message-background`, `$received-message-background` 매개변수를 제공하는 새 테마를 만듭니다. 이 매개변수 값을 기준으로 `$header-color`, `$sent-message-color`, `$received-message-color`은(는) 배경과 대비가 더 좋은 쪽에 따라 자동으로 검은색 또는 흰색으로 설정됩니다.

```scss
$custom-chat-theme: chat-theme(
  $header-background: #4a4a4a,
  $sent-message-background: #fb8500,
  $received-message-background: #e2d8c9
);
```

마지막으로 애플리케이션에 사용자 지정 테마를 **포함**하십시오:

```scss
:host {
  @include tokens($custom-chat-theme);
}
```
