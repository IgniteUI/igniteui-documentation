# Angular용 Ignite UI CLI

CLI 도구는 Ignite UI for Angular 도구 세트에 맞게 미리 구성된 프로젝트 템플릿을 제공하여, 다음 애플리케이션을 최단 시간에 시작할 수 있도록 돕습니다. Ignite UI CLI는 다양한 프레임워크용 애플리케이션을 만들고 스캐폴딩하기 위한 독립형 명령줄 도구이며, 개발자의 생산성을 크게 높여 줍니다.

## 시작하기

시작하려면 CLI를 설치하십시오:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
npm install -g igniteui-cli
</pre>

위 설치 명령을 실행하면 Ignite UI CLI를 사용하여 Ignite UI for Angular 애플리케이션을 만들고, 스캐폴딩하고, 실행할 수 있습니다.

## 새 프로젝트 만들기

Ignite UI CLI를 사용하여 Ignite UI for Angular 컨트롤을 사용하도록 구성된 애플리케이션을 만들려면 명령줄에서 다음 템플릿을 사용할 수 있습니다:

## 컴포넌트 추가하기

프로젝트를 만든 후에는 언제든지 **ig add**를 사용하여 추가 컴포넌트 템플릿을 추가할 수 있습니다. 이 명령을 매개변수 없이 실행하면 키보드 탐색 CLI를 통해 사용 가능한 템플릿을 안내받아 원하는 컨트롤을 추가할 수 있습니다.

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig add
</pre>

또는 **ig list** 명령을 실행하여 만든 현재 프로젝트에서 지원되는 모든 템플릿의 전체 목록을 확인할 수 있습니다.

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig list
</pre>

**ig list**를 실행하여 추가하려는 컴포넌트 템플릿을 찾은 후에는 명령줄에서 다음 템플릿을 따라 빠르게 추가할 수 있습니다:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig add [component_template] [component_name]
</pre>

위의 "component\_template"은 일반적으로 Ignite UI for Angular 컴포넌트와 일치합니다("grid", "category-chart", "linear-gauge" 등).

예를 들어 "MyGridComponent"라는 템플릿 데이터 그리드 컴포넌트를 애플리케이션에 추가하려면 다음을 실행할 수 있습니다:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig add grid MyGridComponent
</pre>

## 애플리케이션 빌드 및 실행하기

Ignite UI for Angular 애플리케이션을 빌드하고 실행하려면 **ig build** 및 **ig run** 명령을 호출할 수 있습니다:

<pre style="background:#141414;color:white;display:inline-block;padding:16x;margin-top:10px;font-family:'Consolas';border-radius:5px;width:100%">
ig build
ig run
</pre>

## Ignite UI CLI 명령

사용 가능한 Ignite UI CLI 명령의 전체 목록과 플래그 전달 등 사용법은 [Ignite UI CLI 위키 페이지](https://github.com/IgniteUI/igniteui-cli/wiki)에서 확인할 수 있습니다:

| 명령                                                               | 별칭 | 설명                                                                                                                                                                                                     |
| :-------------------------------------------------------------------- | :---- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [ig start](https://github.com/IgniteUI/igniteui-cli/wiki/start)       |       | 애플리케이션을 빌드하고, 웹 서버를 시작하며, 기본 브라우저에서 애플리케이션을 엽니다.                                                                                                                   |
| [ig build](https://github.com/IgniteUI/igniteui-cli/wiki/build)       |       | 애플리케이션을 출력 디렉터리로 빌드합니다                                                                                                                                                                 |
| [ig generate](https://github.com/IgniteUI/igniteui-cli/wiki/generate) | g     | 지원되는 프레임워크와 프로젝트 유형에 대해 새 사용자 지정 템플릿을 생성합니다                                                                                                                                      |
| [ig help](https://github.com/IgniteUI/igniteui-cli/wiki/help)         | -h    | 사용 가능한 명령을 나열하고 각 명령이 하는 일에 대한 간단한 설명을 제공합니다.                                                                                                                                  |
| [ig config](https://github.com/IgniteUI/igniteui-cli/wiki/config)     |       | Ignite UI CLI 구성 설정을 읽고 씁니다.                                                                                                                                  |
| [ig doc](https://github.com/IgniteUI/igniteui-cli/wiki/doc)           |       | 지정된 검색어에 대한 정보를 Infragistics 지식 베이스에서 검색합니다                                                                                                                              |
| [ig list](https://github.com/IgniteUI/igniteui-cli/wiki/list)         | l     | 지정된 프레임워크와 유형의 모든 템플릿을 나열합니다. 프로젝트 폴더 안에서 명령을 실행하면, 다른 값을 입력하더라도 프로젝트의 프레임워크와 유형에 대한 모든 템플릿을 나열합니다. |
| [ig test](https://github.com/IgniteUI/igniteui-cli/wiki/test)         |       | 현재 프로젝트의 테스트를 실행합니다.                                                                                                                                                                     |
| [ig ai-config](https://github.com/IgniteUI/igniteui-cli/wiki/ai-config) |    | AI 코딩 어시스턴트 통합을 설정합니다. MCP 서버를 구성하고, 스킬 파일을 복사하며, 지침 파일을 채웁니다.                                                                                           |
| ig version                                                            | -v    | 로컬에 설치된 Ignite UI CLI 버전을 표시하며, 로컬 설치가 없으면 전역 버전을 표시합니다                                                                                                                                  |
