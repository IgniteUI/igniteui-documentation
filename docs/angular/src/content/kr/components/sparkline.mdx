# Angular Sparkline 개요

Ignite UI for Angular 스파크라인 컴포넌트는 가벼운 차트 컨트롤입니다. 그리드 셀 안과 같은 작은 규모의 레이아웃에서 렌더링하도록 만들어졌지만, 단독으로도 렌더링할 수 있습니다.

스파크라인 컨트롤에는 차트 유형, 마커, 범위, 추세선, 알 수 없는 값 표시, 툴팁 등 구성하고 사용자 지정할 수 있는 여러 시각적 요소와 그에 해당하는 기능이 있습니다.

Angular 스파크라인 컴포넌트를 사용하려면 다음 모듈을 가져와야 합니다:

```ts
// app.module.ts
import { IgxSparklineModule } from 'igniteui-angular-charts';
import { IgxSparklineCoreModule } from 'igniteui-angular-charts';
import { SparklineDisplayType } from 'igniteui-angular-charts';

@NgModule({
    imports: [ IgxSparklineCoreModule, IgxSparklineModule ]
})
export class AppModule {}
```

## 스파크라인 유형

Ignite UI for Angular 스파크라인 컴포넌트는 다음 유형의 스파크라인을 지원합니다:

- [`Area`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#area)
- [`Column`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#column)
- [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line)
- [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss)

유형은 [`displayType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#displaytype) 속성을 설정하여 정의됩니다. [`displayType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#displaytype) 속성을 지정하지 않으면 기본적으로 [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line) 유형이 표시됩니다.

[`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) 스파크라인 유형은 세로 막대형 차트 유형으로, 각 막대의 값은 바인딩된 데이터 세트의 양의 최댓값(양수 값의 경우) 또는 음의 최솟값(음수 값의 경우)과 같습니다. 이는 흔히 승/패 또는 비슷한 대립 개념을 나타냅니다. [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) 스파크라인이 올바르게 표시되려면 데이터 세트에 양수 값과 음수 값이 모두 있어야 합니다.

[`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) 스파크라인이 [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line) 유형처럼 다른 유형과 같은 데이터에 바인딩된 경우(숫자 값의 컬렉션에 바인딩할 수 있음), 스파크라인 컴포넌트는 컬렉션에서 두 값, 즉 가장 높은 값과 가장 낮은 값을 선택하고 이 값을 바탕으로 스파크라인을 렌더링합니다.

```html
<igx-sparkline height="200px" width="400px"
    [dataSource]="data"
    valueMemberPath="Value"
    displayType="Area" />
```

## 마커

Ignite UI for Angular 스파크라인 컴포넌트를 사용하면 X/Y 좌표를 기준으로 개별 데이터 점을 나타내는 원형 색상 아이콘으로 시리즈에 마커를 표시할 수 있습니다. 마커는 [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line), [`Area`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#area), [`Column`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#column) 표시 유형의 스파크라인에 설정할 수 있습니다. [`WinLoss`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#winloss) 유형의 스파크라인은 현재 마커를 지원하지 않습니다. 기본적으로 마커는 표시되지 않습니다.

스파크라인의 마커는 다음 위치의 어떤 조합으로도 배치할 수 있습니다:

- `All`: 스파크라인의 모든 데이터 점에 마커를 표시합니다.
- `Low`: 가장 낮은 값의 데이터 점에 마커를 표시합니다. 가장 낮은 값을 가진 점이 여러 개이면 해당 값을 가진 각 점에 표시됩니다.
- `High`: 가장 높은 값의 데이터 점에 마커를 표시합니다. 가장 높은 값을 가진 점이 여러 개이면 해당 값을 가진 각 점에 표시됩니다.
- `First`: 스파크라인의 첫 번째 데이터 점에 마커를 표시합니다.
- `Last`: 스파크라인의 마지막 데이터 점에 마커를 표시합니다.
- `Negative`: 스파크라인에 그려진 음수 데이터 점에 마커를 표시합니다.

위에서 언급한 모든 마커는 관련 마커 유형의 속성을 사용하여 색상, 가시성, 크기 측면에서 사용자 지정할 수 있습니다. 예를 들어 위의 `Low` 마커는 [`lowMarkerBrush`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#lowmarkerbrush), [`lowMarkerVisibility`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#lowmarkervisibility), [`lowMarkerSize`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#lowmarkersize) 속성을 갖습니다.

```html
<igx-sparkline
    highMarkerVisibility="Visible"
    lowMarkerVisibility="Visible"
    firstMarkerVisibility="Visible"
    lastMarkerVisibility="Visible"
    negativeMarkerVisibility="Visible"
    markerVisibility="Collapsed"
    markerSize="10"
    firstMarkerSize="10"
    lastMarkerSize="10"
    lowMarkerSize="10"
    highMarkerSize="10"
    negativeMarkerSize="10"/>
```

## 정상 범위

Ignite UI for Angular 스파크라인 컴포넌트의 정상 범위 기능은 데이터를 시각화할 때 미리 정의된 의미 있는 범위를 나타내는 가로 띠입니다. 정상 범위는 원하는 색상으로 윤곽이 그려진 음영 영역으로 설정할 수 있습니다.

정상 범위는 최대 데이터 점보다 넓거나 그보다 더 바깥까지 확장될 수 있으며, 예를 들어 임계값 표시기로 쓰이도록 스파크라인의 [`Line`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/sparklinedisplaytype.html#line) 표시 유형처럼 얇을 수도 있습니다. 정상 범위의 너비는 정상 범위를 표시하는 데 필요한 최소 설정 역할을 하는 다음 세 가지 속성에 의해 결정됩니다:

- [`normalRangeVisibility`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangevisibility): 정상 범위가 보이는지 여부입니다.
- [`normalRangeMaximum`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangemaximum): 범위의 아래쪽 경계입니다.
- [`normalRangeMinimum`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangeminimum): 범위의 위쪽 경계입니다.

기본적으로 정상 범위는 표시되지 않습니다. 활성화하면 정상 범위가 밝은 회색으로 나타나며, 이는 [`normalRangeFill`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#normalrangefill) 속성을 사용하여 구성할 수도 있습니다.

[`displayNormalRangeInFront`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#displaynormalrangeinfront) 속성을 설정하여 스파크라인 컴포넌트에서 정상 범위를 그려진 시리즈 앞에 표시할지 뒤에 표시할지도 구성할 수 있습니다.

```html
<igx-sparkline
    normalRangeVisibility="Visible"
    normalRangeMinimum="1"
    normalRangeMaximum="4"
    normalRangeFill="rgba(88, 88, 88, 0.4)"
    displayNormalRangeInFront="true" />
```

## 추세선

Ignite UI for Angular 스파크라인 컴포넌트는 실제 스파크라인 레이어 위에 다른 레이어로 표시되는 다양한 추세선을 지원합니다. 스파크라인을 표시하려면 [`trendLineType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#trendlinetype) 속성을 사용할 수 있습니다.

추세선은 차트가 바인딩된 데이터의 값을 사용하여 [`trendLineType`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#trendlinetype) 속성으로 지정된 알고리즘에 따라 계산됩니다.

추세선은 한 번에 하나만 표시할 수 있으며, 기본적으로 추세선은 표시되지 않습니다.

지원되는 추세선의 목록은 아래에서 확인할 수 있습니다:

- [`None`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#none)
- [`CubicFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#cubicfit)
- [`CumulativeAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#cumulativeaverage)
- [`ExponentialAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#exponentialaverage)
- [`ExponentialFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#exponentialfit)
- [`LinearFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#linearfit)
- [`LogarithmicFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#logarithmicfit)
- [`ModifiedAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#modifiedaverage)
- [`PowerLawFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#powerlawfit)
- [`QuadraticFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#quadraticfit)
- [`QuarticFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#quarticfit)
- [`QuinticFit`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#quinticfit)
- [`SimpleAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#simpleaverage)
- [`WeightedAverage`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/enums/trendlinetype.html#weightedaverage)

## 알 수 없는 값 보간

Ignite UI for Angular 스파크라인 컴포넌트는 알 수 없는 값을 감지하고, 지정된 보간 알고리즘을 통해 알 수 없는 값의 공간을 렌더링할 수 있습니다. 데이터에 null 값이 포함되어 있는데 이 기능을 사용하지 않는다면, 즉 보간이 지정되지 않았다면 알 수 없는 값은 그려지지 않습니다.

알 수 없는 값을 그리려면 스파크라인 컴포넌트의 [`unknownValuePlotting`]({environment:dvApiBaseUrl}/products/ignite-ui-angular/api/docs/typescript/latest/classes/igxsparklinecomponent.html#unknownvalueplotting) 속성을 설정할 수 있습니다.

```html
<igx-sparkline
    unknownValuePlotting="LinearInterpolate" />
```
