# 스타일과 테마

Grid Lite는 Bootstrap, Material, Fluent, Indigo의 네 가지 뚜렷한 테마를 제공합니다. 그리드와 그 UI 컴포넌트에는 테마가 내장되어 있지만, 팔레트, 타이포그래피 및 기타 전역 구성이 작동하려면 컴포넌트에 전역 스타일시트가 필요합니다.

## 기본 테마 로드하기

프로젝트 유형, 설정 및 빌드 구성에 따라 아래 파일 중 하나를 포함하는 방법은 달라집니다. 프레임워크나 빌드 도구를 사용한다면, 출력 번들에 외부 스타일을 추가하는 방법은 해당 도구의 문서를 참조하십시오.

일반적으로 `themes` 폴더를 assets 디렉터리에 복사하고 index.html에서 그곳의 테마를 연결하면 됩니다.

```html
<link rel="stylesheet" href="./assets/themes/light/bootstrap.css">
```

| 테마     | 변형 | 경로                                                           |
| :-------- | :------ | :------------------------------------------------------------- |
| Bootstrap | 밝음   | node_modules/igniteui-webcomponents/themes/light/bootstrap.css |
| Bootstrap | 어두움    | node_modules/igniteui-webcomponents/themes/dark/bootstrap.css  |
| Material  | 밝음   | node_modules/igniteui-webcomponents/themes/light/material.css  |
| Material  | 어두움    | node_modules/igniteui-webcomponents/themes/dark/material.css   |
| Fluent    | 밝음   | node_modules/igniteui-webcomponents/themes/light/fluent.css    |
| Fluent    | 어두움    | node_modules/igniteui-webcomponents/themes/dark/fluent.css     |
| Indigo    | 밝음   | node_modules/igniteui-webcomponents/themes/light/indigo.css    |
| Indigo    | 어두움    | node_modules/igniteui-webcomponents/themes/dark/indigo.css     |

## 사용자 지정 테마 만들기

`igniteui-grid-lite` 패키지와 함께 제공되는 기본 테마 외에도, 프로젝트의 정체성과 브랜딩에 맞게 자체 테마를 만들고 수정할 수 있습니다.

---

SCSS와 CSS 인터페이스의 문서와 사용법은 <a href="https://github.com/IgniteUI/igniteui-theming#readme" target="_blank">Ignite UI 테마 패키지</a> 위키를
참조하십시오.

---

```scss
@use 'node_modules/igniteui-theming' as *;

// Our dark theme
$my_dark_palette: palette(
  $primary: #dab785,
  $secondary: #d5896f,
  $surface: #031d44,
  $gray: #04395e,
);

// Our light theme
$my-light-palette: palette(
  $primary: #c1292e,
  $secondary: #f1d302,
  $surface: #fdfffc,
  $gray: #235789,
);

.custom-light {
  @include palette($my_light_palette);
  @include typography('"Roboto Condensed", sans-serif', $bootstrap-type-scale);
}

.custom-dark {
  @include palette($my_dark_palette);
  @include typography('"Merriweather Sans", sans-serif', $bootstrap-type-scale);
}
```
