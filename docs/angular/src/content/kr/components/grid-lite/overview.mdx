# 무료 및 오픈 소스 Angular 데이터 그리드(Grid Lite)

Ignite UI for Angular Grid Lite는 무료로 사용할 수 있는 오픈 소스이며 최신 Angular 애플리케이션을 위해 만들어진, 가볍고 고성능인 Angular 데이터 그리드입니다.

이 무료 Angular 데이터 그리드는 Web Component로 만들어진 오픈 소스 JavaScript 데이터 그리드입니다. 즉 웹 프레임워크와 함께 또는 없이, 종속성 없이 사용할 수 있습니다. 최소한의 오버헤드와 사용자가 기대하는 성능으로 필수적인 데이터 표시 기능을 제공합니다. Angular Grid Lite는 빠르고 가벼운 데이터 표시가 필요한 개발자를 위해 설계되었습니다.

## 무료 Angular 데이터 그리드에서 얻을 수 있는 것

무료 오픈 소스 Angular Grid Lite에는 열 기반 기능인 정렬, 필터링, 숨기기, 크기 조정과 다양한 사전 정의된 데이터 타입이 포함되어 있습니다. 행 가상화를 사용하여 매우 빠른 성능을 제공합니다. 또한 이 컴포넌트는 키보드 탐색과 [Ignite UI 테마 프레임워크](/themes)를 통한 테마 지정을 지원합니다.

Angular는 사용자 지정 요소를 <a href="https://custom-elements-everywhere.com/#angular" target="_blank">지원</a>하므로 Grid Lite를 쉽게 사용할 수 있습니다.

## 설치 및 설정
애플리케이션에서 Grid Lite를 사용하려면 `igniteui-angular`에서 `igniteui-angular/grids/lite` 진입점을 통해 직접 import할 수 있습니다. 하지만 UI를 구동하는 `igniteui-grid-lite` 패키지도 설치해야 합니다. <ApiLink type="GridLite" />는 Angular 바인딩(이벤트, 템플릿, DI, 변경 감지, 파이프)을 제공하며, 시각적인 Grid Lite UI는 `igniteui-grid-lite`가 렌더링합니다. 두 가지를 모두 설치하면 Grid Lite가 Angular에서 네이티브로 동작하면서 전체 `igniteui-grid-lite` UI를 활용할 수 있습니다.

```shell
npm install igniteui-grid-lite
```

애플리케이션을 시작하기 전에 아래와 같이 사용자 지정 요소 스키마를 import하고 전달했는지 확인하십시오.

```typescript
// app.component.ts

import { Component } from '@angular/core';
import { IgxGridLiteComponent, IgxGridLiteColumnComponent } from 'igniteui-angular/grids/lite';

@Component({
  ...
  imports: [IgxGridLiteComponent, IgxGridLiteColumnComponent],
  template: `
    <div>
      <igx-grid-lite [data]="products">
        <igx-grid-lite-column field="id" header="ID" dataType="number"></igx-grid-lite-column>
        <igx-grid-lite-column field="name" header="Name"></igx-grid-lite-column>
        {/* Additional columns */}
      </igx-grid-lite>
    
</div>
  `
})
export class AppComponent {
  products: Products[] = [...];
}
```

## 기능

### 내장된 성능

이 Angular 데이터 그리드를 무료로 사용하면 행 수준 가상화를 구현할 수 있습니다. 이를 통해 부드러운 스크롤과 함께 무제한의 데이터를 렌더링할 수 있습니다.

### 자동 열 타입

열 타입은 데이터 소스를 기반으로 자동 생성되며, 열 타입에 따른 내장 필터링이 제공됩니다.

### 사용자 지정 열 템플릿

오픈 소스 Angular 데이터 그리드 컨트롤로도 열 템플릿을 사용하여 어떤 유형의 UX든 제공할 수 있습니다. 상상할 수 있는 모든 것을 그리드 열에 렌더링할 수 있습니다!

### 대화형 기능

열 필터링, 열 숨기기, 열 크기 조정, 열 정렬 등 사용자가 기대하는 핵심 대화형 기능을 모두 제공합니다!

### 아름다운 UX와 브랜딩

이 무료 Angular 데이터 그리드(Grid Lite)에는 Bootstrap, Material, Fluent를 위한 내장 테마 지원과 함께 색상 팔레트, 글꼴, 고도, 표시 밀도 등의 무한한 브랜딩 옵션이 포함되어 있습니다.

### 풍부한 키보드 탐색

완전한 Excel 스타일의 키보드 탐색으로, 고성능 키보드 탐색과 함께 사용자가 기대하는 경험을 제공합니다.

## Grid Lite는 무료이고 오픈 소스인 Angular 데이터 그리드입니까?

네. Ignite UI Grid Lite는 MIT 라이선스로 배포되는 무료 오픈 소스 Angular 데이터 그리드입니다. 라이선스 수수료 없이 상업용 또는 개인 프로젝트에서 사용할 수 있습니다. 이는 Ignite UI를 더 개방적이고 투명하며 접근하기 쉽게 만들려는 우리 이니셔티브의 일부입니다.

- MIT 라이선스

- 상업적 사용 무료

- 커뮤니티 주도 개발

- 기능 제한 없음

하지만 프로젝트가 커지고 기능과 복잡성이 늘어나 엔터프라이즈급 애플리케이션이 필요해지면, 원활한 업그레이드 전략이 있습니다. 무료 Angular 데이터 그리드(Grid Lite)에서 모든 기능을 갖춘 고급 Data Grid로의 전환을 더 간단하고 빠르게 해 줍니다.

Angular는 사용자 지정 요소를 지원하므로 Grid Lite를 쉽게 사용할 수 있습니다.
