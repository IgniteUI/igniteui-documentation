# 열 구성

열은 선언적으로 그리드 안의 열 자식 컴포넌트를 사용하여 정의합니다. `field` 속성은 열에 필요한 유일한 속성이며, 열의 식별자 역할을 합니다. 또한 그리드 행에서 관련 데이터를 매핑하고 렌더링하는 데 사용되는 속성이기도 합니다.

```html
<igx-grid-lite [data]="data">
  <igx-grid-lite-column
    field="account"
    header="Account Number"
    ...
  ></igx-grid-lite-column>
  {/* Additional columns */}
</igx-grid-lite>
```

## 데이터 소스를 기반으로 한 구성

`autoGenerate`이(가) true로 설정되면 그리드는 제공된 데이터 소스를 기반으로 열 구성을 추론할 수 있습니다. 데이터의 레코드를 기반으로 적절한 `field`와 `dataType`을(를) 추론하려고 시도합니다.

```typescript
const data: Record[] = [
  { entryId: "1234", source: "https://example.com", ts: 1373521917579 },
  ...
];
```

```html
<igx-grid-lite [autoGenerate]="true" [data]="data"></igx-grid-lite>
```

앞의 스니펫은 그리드가 다음과 같은 열을 자동으로 생성하는 결과를 낳습니다:

```html
<igx-grid-lite [data]="data">
  <igx-grid-lite-column field="entryId" dataType="string"></igx-grid-lite-column>
  <igx-grid-lite-column field="source" dataType="string"></igx-grid-lite-column>
  <igx-grid-lite-column field="ts" dataType="number"></igx-grid-lite-column>
</igx-grid-lite>
```

추가 사용자 지정 없이 데이터를 빠르게 렌더링하는 데 유용합니다.

<DocsAside type="info">
이것은 그리드가 처음 DOM에 추가될 때 실행되는 일회성 작업입니다. 빈 데이터 소스를 전달하거나 나중에 바인딩되는 데이터 소스(예: HTTP 요청)를 사용하면 보통 그리드의 열 구성이 비어 있게 됩니다. 그리드에 이미 열 구성이 있으면 이 속성은 무시됩니다. 데이터 소스를 기반으로 열 구성을 자동 생성하는 것에 대한 추가 정보는 [데이터 바인딩 항목](/grid-lite/binding)을 참조하십시오.
</DocsAside>

## 추가 열 구성

열은 사용자 지정을 위한 여러 속성을 더 노출합니다:

### 열 너비

기본적으로 열의 너비는 `minmax(136px, 1fr)`이며, 이는 최소 너비 136px, 최대 너비는 Grid Lite에서 사용 가능한 공간의
1 부분에 해당합니다. 이렇게 하면 열이 유연해져서 그리드 너비의 변화에 맞춰 반응합니다.

열의 너비를 변경하려면 열의 `width` 속성을 사용하십시오.

```html
<igx-grid-lite-column field="price" width="250px"></igx-grid-lite-column>
```

이 속성은 <a href="https://developer.mozilla.org/en-US/docs/Learn/CSS/Building_blocks/Values_and_units#numbers_lengths_and_percentages" target="_blank">유효한 CSS 길이 단위</a>를 받습니다.

### 열 숨기기

열의 `hidden` 속성을 설정하여 열을 숨기거나 표시할 수 있습니다.

```html
<igx-grid-lite-column field="price" hidden></igx-grid-lite-column>
```

### 열 크기 조정

Grid Lite 컴포넌트의 각 열은 열 요소의 `resizable` 속성을 설정하여 크기를 조정할 수 있도록 구성할 수 있습니다.

```html
<igx-grid-lite-column field="price" resizable></igx-grid-lite-column>
```

열이 크기 조정 가능하도록 설정되어 있으면 열 헤더의 오른쪽 가장자리를 드래그하여 열 너비를 늘리거나 줄일 수 있습니다. 크기 조정 영역을 두 번 클릭하면 열의 자동 크기 조정이 실행되며, 셀과 헤더의 가장 큰 콘텐츠에 맞춰 너비를 설정하려고 시도합니다.

<DocsAside type="info">
"fluid" 너비(fr, % 등)를 가진 열은 그리드 크기를 조정할 때 새 크기에 맞추려고 하므로 불규칙하게 동작할 수 있습니다. 애플리케이션 시나리오에 따라서는 사용자가 레이아웃 이동을 겪지 않도록 "hard" 단위를 사용하는 편이 나을 수 있습니다.
</DocsAside>
