# Angular Circular Progress 컴포넌트 개요

<div class="highlight">
Ignite UI for Angular Circular Progress Indicator 컴포넌트는 애플리케이션 프로세스가 변화하는 모습을 시각적으로 표시합니다. 원형 표시기는 상태가 바뀔 때 모양이 업데이트됩니다.
</div>

## Ignite UI for Angular Circular Progress 시작하기

Ignite UI for Angular Circular Progress 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxProgressBarModule`을 가져오는 것입니다:

```typescript
// app.module.ts

...
import { IgxProgressBarModule } from 'igniteui-angular/progressbar';
// import { IgxProgressBarModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxProgressBarModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxCircularProgressBarComponent`을 독립형(standalone) 종속성으로 가져올 수 있으며, [`IGX_CIRCULAR_PROGRESS_BAR_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/progressbar/src/progressbar/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수도 있습니다.

```typescript
// home.component.ts

import { IGX_CIRCULAR_PROGRESS_BAR_DIRECTIVES } from 'igniteui-angular/progressbar';
// import { IGX_CIRCULAR_PROGRESS_BAR_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-home',
  template: `
    <igx-circular-bar
      [value]="100"
      [animate]="true"
      class="custom-size"
    ></igx-circular-bar>
  `,
  styleUrls: ['home.component.scss'],
  standalone: true,
  imports: [IGX_CIRCULAR_PROGRESS_BAR_DIRECTIVES],
  /* or imports: [IgxCircularProgressBarComponent] */
})
export class HomeComponent {}
```

이제 Ignite UI for Angular Progress Bar 모듈 또는 디렉티브를 가져왔으므로, `igx-circular-bar` 컴포넌트를 사용하기 시작할 수 있습니다.

## Angular Circular Progress 사용하기

모든 것이 어떻게 동작하는지 더 잘 이해하려면, 데모와 같은 간단한 예제를 만들어 보겠습니다:

```html
<igx-circular-bar [value]="100" [animate]="true" class="custom-size"></igx-circular-bar>
```

그 후 브라우저에서 데모 샘플이 보여야 합니다.

<DocsAside type="info">
**igx-circular-bar**는 단계마다 <ApiLink type="CircularProgressBar" member="progressChanged" label="progressChanged" /> 이벤트를 발생시키며, 이 이벤트는 다음과 같은 객체 `{currentValue: 65, previousValue: 64}`을(를) 출력합니다.
</DocsAside>
<DocsAside type="info">
<ApiLink type="CircularProgressBar" member="step" label="step" /> 값이 정의되지 않은 경우 기본 진행률은 업데이트 주기마다 **<ApiLink type="CircularProgressBar" member="max" label="max" /> 값의 1%**씩 증가합니다. 업데이트 속도를 변경하려면 <ApiLink type="CircularProgressBar" member="step" label="step" /> 값을 정의해야 합니다.
</DocsAside>

### 불확정 진행률

정확하게 결정되지 않은 과정을 추적하려면 <ApiLink type="CircularProgressBar" member="indeterminate" label="indeterminate" /> 입력 속성을 `true`로 설정할 수 있습니다.

```html
<igx-circular-bar [animate]="false" [indeterminate]="true" [textVisibility]="false"></igx-circular-bar>
```

<DocsAside type="info">
<ApiLink type="CircularProgressBar" member="textVisibility" label="textVisibility" /> 속성을 `false`로 설정하면 원형 진행률 막대의 텍스트를 숨길 수 있습니다.
</DocsAside>

### 동적 진행률

버튼과 같은 외부 컨트롤을 사용하여 진행률 값을 동적으로 바꿀 수 있습니다. 이를 위해 값을 클래스 속성에 바인딩할 수 있습니다:

```html
<div class="sample-content">

  <igx-circular-bar
    [value]="currentValue"
    [max]="100"
    [animate]="true"
    class="custom-size">
  </igx-circular-bar>
  <div class="button-container">

    <button igxIconButton="flat" (click)="decrementProgress()">
      <igx-icon fontSet="material">remove</igx-icon>
    </button>
    <button igxIconButton="flat" (click)="incrementProgress()">
      <igx-icon fontSet="material">add</igx-icon>
    </button>
  
</div>
</div>
```

<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

값을 증가 및 감소시키는 메서드를 추가하십시오:

```typescript
@Component({...})
export class HomeComponent {
    public currentValue: number;

    public ngOnInit() {
        this.currentValue = 0;
    }

    public incrementProgress() {
        this.currentValue += 10;
        if (this.currentValue > 100) {
            this.currentValue = 100;
        }
    }

    public decrementProgress() {
        this.currentValue -= 10;
        if (this.currentValue < 0) {
            this.currentValue = 0;
        }
    }
}
```

스타일을 추가하십시오:

```scss
.custom-size {
  --diameter: 100px;
}

.sample-content {
  width: 300px;
  display: flex;
  align-items: center;
  margin: 30px;
}
```

### 그라데이션 진행률

진행률 막대를 사용자 지정하는 한 가지 방법은 단색 대신 색상 그라데이션을 사용하는 것입니다.
이는 두 가지 방법 중 하나로 할 수 있습니다. 즉 <ApiLink type="CircularProgressBar" member="gradientTemplate" label="IgxProgressBarGradientDirective" /> 디렉티브를 사용하거나, 최대 두 개의 색상 정지점을 지원하는 사용자 지정 테마를 구현하는 것입니다.

사용자 지정 테마로 두 개의 색상 정지점만 있는 그라데이션을 만들려면, 색상 목록을 만들어 `$fill-color-default` 테마 매개변수에 전달해야 합니다:

```scss
$colors: #695cf9, #ef017c;

$custom-theme: progress-circular-theme(
  $fill-color-default: $colors,
);
```

원형 진행률 막대의 스타일링에 대해서는 [`Styling Section`](#스타일링)에서 자세히 알아볼 수 있습니다.

두 개보다 많은 색상 정지점을 가진 그라데이션을 제공하려면, 다음과 같이 `igx-circular-bar`의 `ng-template`에 디렉티브를 사용해야 합니다:

```html
<div class="sample-content">

  <igx-circular-bar
    [value]="currentValue"
    [max]="100"
    [animate]="true"
    class="custom-size">
    <ng-template igxProgressBarGradient let-id>
      <svg:linearGradient [id]="id" gradientTransform="rotate(90)">
        <stop offset="0%" stop-color="#ff9a40" />
        <stop offset="50%" stop-color="#1eccd4" />
        <stop offset="100%" stop-color="#ff0079" />
      </svg:linearGradient>
    </ng-template>
  </igx-circular-bar>

  <div class="button-container">

    <button igxIconButton="flat" (click)="removeProgress()">
      <igx-icon fontSet="material">remove</igx-icon>
    </button>
    <button igxIconButton="flat" (click)="addProgress()">
      <igx-icon fontSet="material">add</igx-icon>
    </button>
  
</div>
</div>
```

## 스타일링

원형 진행률 막대의 스타일링을 시작하려면, 모든 테마 함수와 `tokens()` 믹스인을 내보내는 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 단순한 방법으로, <ApiLink kind="sass" module="themes" type="function-progress-circular-theme" label="progress-circular-theme" code={true} />을(를) 확장하고 `$base-circle-color` 및 `$fill-color-default` 매개변수를 받는 새 테마를 만듭니다.

```scss
$custom-theme: progress-circular-theme(
  $fill-color-default: rgb(32, 192, 17),
  $diameter: 50px
);
```

마지막 단계는 애플리케이션에 컴포넌트 테마를 **포함**하는 것입니다.

```scss
:host {
  @include tokens($custom-theme);
}
```
