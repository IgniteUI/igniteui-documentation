# Angular Icon Button 개요

Ignite UI for Angular Icon Button 디렉티브는 어떤 아이콘이든 완전히 동작하는 버튼으로 바꾸기 위한 것입니다. `igxIconButton`은(는) flat, outlined, contained 세 가지 유형으로 제공되며, 기본값은 contained입니다.

## Ignite UI for Angular Icon Button 시작하기

Ignite UI for Angular Icon Button 디렉티브를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 `IgxIconButtonDirective`을(를) 독립형 종속성으로 가져오는 것입니다:

```typescript
// home.component.ts

...
import { IgxIconButtonDirective } from 'igniteui-angular/directives';
// import { IgxIconButtonDirective } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
        <button igxIconButton="outlined">
            <igx-icon>home</igx-icon>
        </button>`,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxIconButtonDirective]
})
export class HomeComponent {}
```


<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

이제 Ignite UI for Angular Icon Button 디렉티브를 가져왔으므로, 요소에 `igxIconButton` 디렉티브를 사용하기 시작할 수 있습니다.

## Angular Icon Button 유형

### Flat Icon Button

컴포넌트 템플릿에 간단한 flat 아이콘 버튼을 추가하려면 <ApiLink type="IconButtonDirective" label="igxIconButton" /> 디렉티브를 사용하십시오:

```html
<button igxIconButton="flat">
    <igx-icon>edit</igx-icon>
</button>
```

<Sample src="/data-entries/flat-icon-button" height={70} iframeOnly />

### Contained Icon Button

contained 아이콘 버튼을 만들려면 `igxIconButton` 속성의 값을 바꾸기만 하면 됩니다. 유형을 선택하지 않으면 기본적으로 `contained`(으)로 설정된다는 점에 유의하십시오.

```html
<button igxIconButton>
    <igx-icon>favorite</igx-icon>
</button>
```

<Sample src="/data-entries/contained-icon-button" height={70} iframeOnly />

### Outlined Icon Button

마찬가지로 outlined 유형으로 전환할 수 있습니다:

```html
<button igxIconButton="outlined">
    <igx-icon>more_vert</igx-icon>
</button>
```

<Sample src="/data-entries/outlined-icon-button" height={70} iframeOnly />

## 예제

### Disabled Icon Button

아이콘 버튼을 비활성화하려면 <ApiLink type="IconButtonDirective" member="disabled" label="disabled" /> 속성을 사용할 수 있습니다. 이 샘플에서는 `igxIconButton` 디렉티브와 함께 다른 아이콘 계열의 아이콘을 사용하는 방법도 보여 줍니다:

```html
<button igxIconButton="flat" disabled>
    <igx-icon family="fa" name="fa-home"></igx-icon>
</button>
```

<Sample src="/data-entries/disabled-icon-button" height={70} iframeOnly />

### SVG 아이콘

Material 아이콘 외에도 `igxIconButton` 디렉티브는 SVG 이미지를 아이콘으로 사용하는 것을 지원합니다. 이를 위해 먼저 <ApiLink type="IconService" /> 의존성을 주입한 다음, <ApiLink type="IconService" member="addSvgIcon" label="addSvgIcon" /> 메서드를 사용하여 SVG 파일을 캐시로 가져와야 합니다. 자세한 정보는 아이콘 항목의 [SVG 섹션](/layouts/icon#svg-icons)을 참조하십시오.

```typescript
constructor(private _iconService: IgxIconService) { }

public ngOnInit() {
    // register custom SVG icon
    this._iconService.addSvgIcon('rain', 'assets/images/card/icons/rain.svg', 'weather-icons');
}
```

```html
<button igxIconButton>
    <igx-icon family="weather-icons" name="rain"></igx-icon>
</button>
```

<Sample src="/data-entries/svg-icon-button" height={70} iframeOnly />

### 크기

사용자는 `--ig-size` 사용자 지정 CSS 속성을 사용하여 미리 정의된 `igxIconButton` 크기 세 가지 중 하나를 선택할 수 있습니다. 기본적으로 컴포넌트의 크기는 medium으로 설정됩니다.

```scss
  --focus-background: #ecaa53;
  --focus-border-color: #0116276c;
  --active-foreground: #011627dc;
  --active-background: #ecaa53;
}
```

모든 유형의 아이콘 버튼 스타일을 지정하기 위해 사용 가능한 매개변수의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-icon-button-theme" label="icon-button-theme" code={true} /> 섹션을 참조하십시오.

`flat`, `outlined`, `contained` 중 특정 유형의 버튼만 스타일을 지정할 수도 있습니다.
이를 위해 새 유형별 테마 함수 <ApiLink kind="sass" module="themes" type="function-flat-icon-button-theme" label="flat-icon-button-theme" code={true} />, <ApiLink kind="sass" module="themes" type="function-outlined-icon-button-theme" label="outlined-icon-button-theme" code={true} />, <ApiLink kind="sass" module="themes" type="function-contained-icon-button-theme" label="contained-icon-button-theme" code={true} />를 사용할 수 있습니다

SCSS에서 사용자 지정 테마를 정의하기 위해 `contained-icon-button-theme` 함수를 사용하는 예는 다음과 같습니다:

```scss
@use "igniteui-angular/theming" as *;

$custom-contained: contained-icon-button-theme(
    $background: #ECAA53,
);
```

이렇게 하면 hover, focus, active 같은 다양한 상태에 맞는 전경 및 배경 색상을 포함하여 완전히 테마가 적용된 `contained icon button`이(가) 생성됩니다.

### Tailwind로 스타일링하기

사용자 지정 Tailwind 유틸리티 클래스를 사용하여 아이콘 버튼의 스타일을 지정할 수 있습니다. 먼저 [Tailwind를 설정](/themes/tailwind)했는지 확인하십시오.

전역 스타일시트에 Tailwind를 가져온 다음, 다음과 같이 원하는 테마 유틸리티를 적용할 수 있습니다:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

유틸리티 파일에는 `light` 및 `dark` 테마 변형이 모두 포함되어 있습니다.

- 밝은 테마에는 `light-*` 클래스를 사용하십시오.
- 어두운 테마에는 `dark-*` 클래스를 사용하십시오.
- 접두사 뒤에 컴포넌트 이름을 붙이십시오. 예: `light-icon-button`, `dark-icon-button`.

적용하면 이 클래스는 동적 테마 계산을 가능하게 합니다. 그런 다음 `arbitrary properties`을 사용하여 생성된 CSS 변수를 재정의할 수 있습니다. 콜론 뒤에는 유효한 CSS 색상 형식(HEX, CSS 변수, RGB 등)을 입력하십시오.

속성의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-icon-button-theme" label="icon-button-theme" />에서 확인할 수 있습니다. 구문은 다음과 같습니다:

```html
<button igxIconButton class="!light-icon-button ![--icon-color:#FF4E00]">
  <igx-icon>edit</igx-icon>
</button>
```

<DocsAside type="info">
유틸리티 클래스가 우선 적용되도록 느낌표(`!`)가 필요합니다. Tailwind는 스타일을 계층으로 적용하므로, 이 스타일을 중요(important)로 표시하지 않으면 컴포넌트의 기본 테마에 의해 재정의됩니다.
</DocsAside>
