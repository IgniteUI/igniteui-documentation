# 오버레이 스타일 지정

<div class="highlight">


[`IgxOverlayService`](/overlay)은(는) 페이지 콘텐츠 위에 콘텐츠를 표시하는 데 사용됩니다. 많은 Ignite UI for Angular 컴포넌트가 오버레이를 사용합니다. 예를 들어 [드롭다운](/drop-down), [콤보](/inputs/combo/overview), [날짜 선택기](/date-picker) 등이 있으므로, 오버레이가 콘텐츠를 어떻게 표시하는지 이해하는 것이 중요합니다.
다른 요소 위에 콘텐츠를 표시하기 위해 서비스는 콘텐츠를 특수한 아웃레트 컨테이너(기본적으로 문서 body의 끝에 연결됨)로 옮깁니다. 이 동작은 [특정 컨테이너에 범위가 지정된](#범위가-지정된-오버레이-스타일) 스타일에 영향을 줄 수 있습니다.
</div>
<hr/>

## 오버레이 컴포넌트 스타일 지정하기

전역 스타일시트에서 내보낸 테마는 모든 오버레이 아웃레트의 콘텐츠에 영향을 줄 수 있습니다. 예를 들어 다음 [드롭다운](/drop-down#스타일링) 테마는 Sass 루트에서 범용 토큰 재정의를 내보내며, 이는 문서 body에 연결된 드롭다운 콘텐츠에서 사용할 수 있습니다:

```html
{/* overlay-styling.component.html */}
<igx-drop-down #customDropDown height="350px">
    <igx-drop-down-item *ngFor="let item of items" [value]="item.id">
        {{ item.name }}
    </igx-drop-down-item>
</igx-drop-down>
```

```scss
// styles.scss
@use "igniteui-angular/theming" as *;

$my-drop-down-theme: drop-down-theme(
  $background-color: #efefef
);

@include tokens($my-drop-down-theme);
```

이러한 범용 재정의는 전역이므로, 오버레이 서비스가 드롭다운 콘텐츠를 아웃레트로 옮긴 후에도 드롭다운 콘텐츠가 이를 사용할 수 있습니다.

## 범위가 지정된 컴포넌트 스타일

로컬 테마는 자신의 컨테이너에서 상속받거나 생성된 선택기와 일치하는 오버레이 콘텐츠에만 영향을 줄 수 있습니다. `body` 끝에 있는 기본 아웃레트에 연결된 콘텐츠는 이를 연 컴포넌트의 하위 요소가 아닙니다.

예를 들어 `igx-combo` 항목 [스타일](/inputs/combo/overview#styling)은 드롭다운 테마를 사용합니다. 이 컴포넌트 로컬 테마는 콤보 아웃레트가 호스트 아래로 옮겨진 후에 적용됩니다:

```scss
// overlay-styling.component.scss

:host {
  @include tokens($my-drop-down-theme);
}
```

<DocsAside type="warning">
`::ng-deep`은(는) 분리된 아웃레트로 토큰이 상속되도록 하지 않습니다. 오버레이 테마를 전역으로 내보내거나, 아웃레트를 테마가 적용된 컨테이너 아래로 옮겨야 합니다. 특별한 사용자 지정이 범위 모드를 사용하고 생성된 선택기가 중첩된 오버레이 콘텐츠와 여전히 일치하지 않는다면, 아웃레트를 옮긴 후 `::ng-deep`도 필요할 수 있습니다.
</DocsAside>

오버레이 컨테이너가 렌더링될 위치를 제어하려면 <ApiLink kind="interface" type="OverlaySettings" member="outlet" /> 속성을 사용하십시오.

여기서는 컨테이너가 놓였으면 하는 요소에 대한 참조를 전달할 수 있습니다:

```html
<igx-combo [data]="items" valueKey="name" displayKey="name" [overlaySettings]="{ outlet: element, modal: true }">
</igx-combo>
```

```typescript
export class OverlayStylingComponent {
  ...
  constructor(public element: ElementRef) {
  }
}
```

이제 콤보의 항목 목록이 컴포넌트 호스트 **안에** 올바르게 렌더링되므로, 사용자 지정 테마가 적용됩니다:

## 오버레이 스타일 지정하기

지금까지 `ViewEncapsulation`이(가) 오버레이의 `outlet` 속성과 함께 어떻게 작동하는지 살펴보았으니, 이제 오버레이 래퍼 자체의 스타일을 지정하는 방법을 살펴보겠습니다.
<ApiLink kind="sass" module="themes" type="function-overlay-theme" label="overlay-theme" code={true} />은(는) `$background-color` 속성 하나만 제공하며, 이는 오버레이가 `modal: true`(으)로 설정되었을 때 배경의 색상에 영향을 줍니다.

### 전역 스타일

모달 오버레이의 스타일을 지정하는 가장 쉬운 방법은 앱의 전역 스타일에 해당 테마를 포함하는 것입니다:

```scss
// styles.scss
$my-overlay-theme: overlay-theme(
  $background-color: rgba(0, 153, 255, 0.3)
);

@include tokens($my-overlay-theme);
```

이제 **모든** 모달 오버레이에 보라색 색조가 적용됩니다. 이 테마는 전역으로 내보내지므로 Angular 뷰 캡슐화와 `::ng-deep`은(는) 관여하지 않습니다.

### 범위가 지정된 오버레이 스타일

오버레이에 특정 컨테이너 아래에서만 특정 배경을 주려면, 아웃레트를 그 컨테이너 아래로 옮기고 테마의 범위를 그곳으로 지정하십시오. 사용자 지정 아웃레트에는 몇 가지 [제한 사항](/overlay#가정-및-제한-사항)이 있습니다. 오버플로 잘림, 쌓임 순서, 뷰포트 문제를 줄이려면 상위 수준 컴포넌트에서 사용하십시오:

```scss
// styles.scss
...
.purple {
  @include tokens($my-overlay-theme);
}
```
