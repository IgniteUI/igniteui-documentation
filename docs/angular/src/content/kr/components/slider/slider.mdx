# Angular Slider 컴포넌트 개요

<div class="highlight">
Ignite UI for Angular Slider는 트랙을 따라 썸을 움직여 주어진 범위에서 선택할 수 있게 하는 폼 컴포넌트입니다. 트랙은 연속형 또는 단계형으로 정의할 수 있으며, 사용자가 단일 값과 범위(하한 및 상한 값) 슬라이더 유형 중에서 선택할 수 있도록 슬라이더를 구성할 수 있습니다.
</div>

## Ignite UI for Angular Slider 시작하기

Ignite UI for Angular Slider 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxSliderModule`을 가져오는 것입니다.

```typescript
// app.module.ts

import { IgxSliderModule } from 'igniteui-angular/slider';
// import { IgxSliderModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxSliderModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxSliderComponent`을 독립형(standalone) 종속성으로 가져올 수 있으며, [`IGX_SLIDER_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/slider/src/slider/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수도 있습니다.

```typescript
// home.component.ts

import { FormsModule } from '@angular/forms';
import { IGX_SLIDER_DIRECTIVES } from 'igniteui-angular/slider';
// import { IGX_SLIDER_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: '<igx-slider [minValue]="0" [maxValue]="100" [step]="10" [(ngModel)]="task.completion"></igx-slider>',
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_SLIDER_DIRECTIVES, FormsModule]
    /* or imports: [IgxSliderComponent, FormsModule] */
})
export class HomeComponent {
    public task: Task;
}
```

이제 Ignite UI for Angular Slider 모듈 또는 디렉티브를 가져왔으므로 `igx-slider` 컴포넌트를 사용할 수 있습니다.

## Angular Slider 사용하기

### 이산형 슬라이더

기본적으로 Slider 컴포넌트는 이산형으로 설정되어 있습니다. 이산형 슬라이더는 숫자 레이블(말풍선)로 현재 값을 시각화합니다. 말풍선은 슬라이더 썸에 마우스를 올리면 표시될 수 있습니다.  
사용자에게 의미 있는 값만 추적하도록 미리 정의된 단계와 함께 슬라이더를 사용할 수도 있습니다.  

다음 예제에서는 0%에서 100%까지의 값을 표시하는 이산형 슬라이더를 정의하며, <ApiLink type="Slider" member="step" label="step" />은(는) 증감 단위당 10%로 설정됩니다.  
또한 입력 컴포넌트와 양방향 바인딩을 허용하기 위해 Angular [`ngModel`](https://angular.io/guide/built-in-directives#ngModel)을(를) 사용하여 슬라이더 <ApiLink type="Slider" member="value" label="value" />을(를) 컴포넌트의 "completion" 속성에 바인딩합니다.

```html
{/*sample.component.html*/}

<igx-slider [minValue]="0" [maxValue]="100" [step]="10" [(ngModel)]="task.completion"></igx-slider>
<igx-input-group type="border">
    <input igxInput id="percentInput" type="number" [(ngModel)]="task.completion" />
    <label igxLabel for="percentInput">Task Completion</label>
    <igx-suffix>%</igx-suffix>
</igx-input-group>
```

```typescript
// sample.component.ts 
import { Component, ViewChild } from '@angular/core';
import { IgxInputDirective } from 'igniteui-angular/input-group';
import { IgxSliderComponent } from 'igniteui-angular/slider';
// import { IgxInputDirective, IgxSliderComponent } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-sample',
    styleUrls: ['./sample.component.scss'],
    templateUrl: './sample.component.html'
})
export class SampleComponent {
    public task = {
        completion: 10
    };

    constructor() { }
}
```

이제 두 컴포넌트 사이의 양방향 데이터 바인딩을 볼 수 있을 것입니다.

### 연속형 슬라이더

먼저 <ApiLink type="Slider" member="continuous" label="continuous" /> 입력을 true로 설정하여 슬라이더 유형을 지정하십시오. 다음으로 <ApiLink type="Slider" member="minValue" label="minValue" />과(와) <ApiLink type="Slider" member="maxValue" label="maxValue" />을(를) 사용하여 최솟값과 최댓값을 정의하십시오.  

<DocsAside type="info">
연속형 슬라이더에는 트랙 위의 단계 표시기와 상호 작용 중 보이는 썸 레이블이 없습니다.
</DocsAside>

```html
{/*sample.component.html*/}

<igx-slider 
    id="slider" 
    [minValue]="0" 
    [maxValue]="100" 
    [continuous]=true 
    [(ngModel)]="volume">
    </igx-slider>
<label igxLabel for="slider">Volume: {{volume}}</label>
```

또한 슬라이더 <ApiLink type="Slider" member="value" label="value" />을(를) 컴포넌트의 "volume" 속성에 바인딩하겠습니다.

```typescript
// sample.component.ts 

// Set an initial value
public volume = 20;
```

샘플이 올바르게 구성되었다면, 슬라이더 썸을 끌 때 아래의 레이블이 업데이트되고 슬라이더 값은 지정된 최솟값과 최댓값 사이로 제한되어야 합니다:

### 범위 슬라이더

먼저 슬라이더 <ApiLink type="Slider" member="type" label="type" />을(를) `Range`(으)로 설정하십시오. 다음으로 슬라이더 값을 `lower`과(와) `upper` 값의 속성을 가진 객체에 바인딩합니다.

```html
{/*sample.component.html*/}

<igx-slider 
    [type]="sliderType.RANGE" 
    [minValue]="0" 
    [maxValue]="1000" 
    [(lowerValue)]="priceRange.lower"
    [(upperValue)]="priceRange.upper">
</igx-slider>

<igx-input-group type="border">
    <label igxLabel for="lowerRange">From</label>
    <igx-prefix>$</igx-prefix>
    <input igxInput id="lowerRange" type="number" [(ngModel)]="priceRange.lower" />
</igx-input-group>

<igx-input-group type="border">
    <label igxLabel for="upperRange">To</label>
    <igx-prefix>$</igx-prefix>
    <input igxInput id="upperRange" type="number" [(ngModel)]="priceRange.upper" />
</igx-input-group>
```

```typescript
// sample.component.ts
import { Component } from '@angular/core';
import { IgxSliderType } from 'igniteui-angular/slider';
// import { IgxSliderType } from '@infragistics/igniteui-angular'; for licensed package

@Component({
  selector: 'app-sample',
  styleUrls: ['./sample.component.scss'],
  templateUrl: './sample.component.html'
})
export class SampleComponent {
  public sliderType = IgxSliderType;
  public priceRange = {
      lower: 200,
      upper: 800
  };

  constructor() { }
}
```

<Sample src="/interactions/slider-sample-4" height={200} alt="" />

<DocsAside type="info">
RANGE 유형의 슬라이더를 사용할 때 `ngModel`에 바인딩하면 슬라이더에서 모델을 업데이트하는 방향으로만 작동합니다. 두 값 모두에 양방향 바인딩을 사용하려면 `lowerValue` 및 `upperValue` 바인딩을 활용할 수 있습니다.
</DocsAside>

경우에 따라 최솟값과 최댓값에 가까운 값은 적절하지 않을 수 있습니다. <ApiLink type="Slider" member="minValue" label="minValue" />과(와) <ApiLink type="Slider" member="maxValue" label="maxValue" />을(를) 설정하는 것과 함께 사용자의 선택을 제한하는 유용한 범위를 추가로 제공할 수 있습니다.
이는 <ApiLink type="Slider" member="lowerBound" label="lowerBound" />과(와) <ApiLink type="Slider" member="upperBound" label="upperBound" />을(를) 설정하여 할 수 있습니다. 이제 사용자는 0에서 100까지의 범위와 900에서 1000까지의 범위에서 썸을 움직일 수 없게 됩니다.

```html
{/*sample.component.html*/}

<igx-slider 
    [type]="sliderType.RANGE" 
    [minValue]="0" 
    [maxValue]="1000"
    [(lowerValue)]="priceRange.lower"
    [(upperValue)]="priceRange.upper"
    [lowerBound]="100" 
    [upperBound]="900">
</igx-slider>
```

### 레이블 모드

지금까지는 썸에 숫자만 보았지만, 정보를 표시하는 또 다른 방법으로 기본 값의 배열을 사용할 수 있습니다.
<DocsAside type="info">
기본 값 배열에는 최소 두 개의 값이 있어야 하며, 그렇지 않으면 `labelsView`이(가) 활성화되지 않습니다.
</DocsAside>

앞의 규칙에 맞는 정의가 준비되면, 이를 `labels` **입력** 속성에 전달할 수 있습니다. 이 속성은 데이터를 처리하여 `track`에 고르게 분배합니다. 이제 레이블 값은 컬렉션에 정의한 모든 기본 값을 나타냅니다. 이 값들은 <ApiLink type="Slider" member="lowerLabel" label="lowerLabel" /> 또는 <ApiLink type="Slider" member="upperLabel" label="upperLabel" />을(를) 요청하여 API를 통해 언제든지 접근할 수 있습니다.

<DocsAside type="info">
<ApiLink type="Slider" member="labelsView" label="labelsView" />이(가) 활성화되면 <ApiLink type="Slider" member="maxValue" label="maxValue" />, <ApiLink type="Slider" member="minValue" label="minValue" /> 및 <ApiLink type="Slider" member="step" label="step" /> 입력에 대한 제어권이 넘어간다는 점을 고려하십시오.
</DocsAside>

`labelsView`이(가) 활성화되었을 때 `slider`이(가) 업데이트 과정을 처리하는 방식도 중요한 요소입니다.
이는 단순히 컬렉션의 `index(es)`으로 작동하며, 이는 `value`, `lowerBound` 및 `upperBound` **속성**이 이들을 따르거나 설정(`index(es)`)하여 `track`을(를) 제어한다는 뜻입니다.

```html
{/*sample.component.html*/}
<igx-slider #slider3 [type]="sliderType" [labels]="labels" [lowerBound]="1" [upperBound]="5">
    <ng-template igxSliderThumbFrom let-value let-labels="labels">
        <span class="ellipsis">{{ labels[value.lower] }}</span>
    </ng-template>
    <ng-template igxSliderThumbTo let-value let-labels="labels">
        <span class="ellipsis">{{ labels[value.upper] }}</span>
    </ng-template>
</igx-slider>
```

```typescript
// sample.component.ts
public sliderType: SliderType = SliderType.RANGE;
public labels = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday'];
```

<Sample src="/interactions/slider-sample-6" height={160} alt="" />

위 샘플에서 볼 수 있듯이 `boundaries`을(를) 설정하는 것은 여전히 유효한 작업입니다. <ApiLink type="Slider" member="lowerbound" label="lowerBound" />과(와) <ApiLink type="Slider" member="upperbound" label="upperBound" />을(를) 지정하면 슬라이드할 수 있는 범위가 제한됩니다.

### 레이블 템플릿화

위의 시연에서는 <ApiLink type="ThumbFromTemplateDirective" /> 및 <ApiLink type="ThumbToTemplateDirective" /> 디렉티브를 모두 사용하여 사용자 지정 `label` 템플릿을 제공하는 방법을 의도적으로 보여 주었습니다. 직관적으로 <ApiLink type="ThumbFromTemplateDirective" />은(는) <ApiLink type="Slider" member="lowerLabel" label="lowerLabel" />에, <ApiLink type="ThumbToTemplateDirective" />은(는) <ApiLink type="Slider" member="upperLabel" label="upperLabel" />에 대응한다고 가정할 수 있습니다. <br/>
여기서 <ApiLink type="Slider" member="context" label="context" />은(는) 암묵적으로 `value` **입력** 속성에 대한 참조를 제공하고, `labelsView`이(가) 활성화된 경우 명시적으로 `labels` **입력**에 대한 참조를 제공합니다.

```html
  <ng-template igxSliderThumbFrom let-value let-labels="labels">
    <span class="ellipsis">{{ labels[value.lower] }}</span>
  </ng-template>
  <ng-template igxSliderThumbTo let-value let-labels="labels">
      <span class="ellipsis">{{ labels[value.upper] }}</span>
  </ng-template>
```

## 슬라이더 눈금 표시 및 레이블

**슬라이더 눈금 표시**는 특정 기간, 요일 등과 같이 데이터를 시각화하는 새롭고 더 매력적인 방법을 제공합니다. 이 새로운 기능을 사용하면 사용자가 Angular Slider와 상호 작용하지 않고도 어떤 데이터 범위가 표현되고 있는지 볼 수 있습니다. **눈금 표시**와 **눈금 레이블**의 위치와 방향을 제어하는 데 매우 유연합니다. **눈금**은 **켜거나 끌** 수 있으며, **주**, **보조** 또는 **둘 다**로 전환할 수 있습니다. 또한 이 기능으로 **주**, **보조** **눈금 레이블** 또는 둘 다를 **켜거나 끌** 수 있습니다. **눈금 레이블**은 방향을 **가로**에서 **세로**(**위에서 아래**(90) 또는 **아래에서 위**(-90))로 바꿀 수 있습니다.

### 눈금 활성화하기

<ApiLink type="Slider" member="showTicks" label="showTicks" />을(를) **true**로 설정하여 슬라이더의 **눈금**을 활성화할 수 있습니다.
<ApiLink type="Slider" member="primaryTicks" label="primaryTicks" />을(를) 사용하여 주 눈금의 개수를 설정하십시오.  
보조 눈금의 개수는 <ApiLink type="Slider" member="secondaryTicks" label="SecondaryTicks" />을(를) 사용하여 설정하십시오.

```html
{/*sample.component.html*/}

<igx-slider 
    id="slider" 
    [maxValue]="100" 
    [step]="10"
    [showTicks]="true" 
    [primaryTicks]="3" 
    [secondaryTicks]="4">
</igx-slider>
```

```typescript
// sample.component.ts 

// Change slider type initial value
public type = SliderType.RANGE;
```

### 레이블 방향과 가시성

다음 샘플에서는 <ApiLink type="Slider" member="secondaryTickLabels" label="secondaryTickLabels" />을(를) **false**로 설정하여 모든 **보조 레이블**을 비활성화합니다.  

```html
<igx-slider
    [step]="10"
    [type]="type"
    [maxValue]="100"
    [continuous]="true"
    [showTicks]="true"
    [primaryTicks]="3"
    [secondaryTicks]="4"
    [secondaryTickLabels]="false"
    [tickLabelsOrientation]="labelsOrientation">
</igx-slider>
```

또한 <ApiLink type="TickLabelsOrientation" kind="variable" label="TickLabelsOrientation" />을(를) <ApiLink kind="variable" type="TickLabelsOrientation" />(으)로 설정하여 표시 가능한 모든 레이블을 회전시킵니다

```typescript
... 
{
    public type = SliderType.RANGE:
    public labelsOrientation = TickLabelsOrientation.BottomToTop;
}
...
```

### 눈금 위치

이제 **눈금**의 위치를 바꾸는 방법을 살펴보겠습니다.

```html
<div class="slider-container">

    <igx-slider
        [maxValue]="20"
        [showTicks]="true"
        [secondaryTicks]="21"
        [primaryTickLabels]="false"
        [ticksOrientation]="ticksOrientation">
    </igx-slider>
</div>
```

위치 변경은 <ApiLink type="Slider" member="ticksOrientation" label="ticksOrientation" /> 입력에서 비롯되며, 이는 **Bottom**(기본값)에서 **Mirror**로 바뀝니다.
이렇게 하면 **눈금**의 시각화가 대칭을 이루어 슬라이더의 위와 아래에 표시됩니다.

```typescript

  // The available options are: Top, Bottom and Mirror
  public ticksOrientation = TicksOrientation.Mirror;
```

<Sample src="/interactions/slider-secondary-ticks-mirror" height={160} alt="" />

### 방향

> <ApiLink type="Slider" member="ticksOrientation" label="ticksOrientation" />이(가) **Top** 또는 **Mirror**로 설정되어 있고 표시되는 **눈금 레이블**이 있으면, **썸 레이블**은 의도적으로 숨겨집니다. 이는 나쁜 사용자 경험과 두 레이블이 겹치는 것을 방지합니다.

<igx-slider

여기서는 <ApiLink type="Slider" member="primaryTicks" label="primaryTicks" /> 입력을 설정하지 않았는데, 이는 어떤 방식으로도 반영되지 않기 때문입니다. 컬렉션의 **길이**가 이를 우선합니다. 그렇다고 <ApiLink type="Slider" member="secondaryTicks" label="secondaryTicks" />을(를) 설정할 수 없다는 뜻은 아닙니다. 모든 **보조 눈금**은 (**레이블** 없이) 비어 있을 것입니다.

### 템플릿 레이블

마지막으로 **눈금 레이블**에 사용자 지정 템플릿을 제공하는 방법과 `IgxTicksComponent` 템플릿 컨텍스트가 제공하는 내용을 살펴보겠습니다.

```html
<igx-slider
    [showTicks]="true"
    [primaryTicks]="3"
    [secondaryTicks]="3">
    <ng-template igxSliderTickLabel let-value let-primary="isPrimary" let-idx="index">
        {{ tickLabel(value, primary, idx) }}
    </ng-template>
</igx-slider>
```

`ng-template`에 <ApiLink type="TickLabelTemplateDirective" />을(를) 적용하면 모든 **눈금 레이블**에 템플릿이 할당됩니다.

<DocsAside type="info">
컨텍스트는 각 눈금마다 실행됩니다.
</DocsAside>

즉, 다음에 대한 참조를 제공합니다:

- 각 해당 눈금의 **값**
- 해당 눈금이 **주** 눈금인지 여부.
- **눈금** 인덱스.
- 그리고 있다면 <ApiLink type="Slider" member="labels" label="labels" /> 컬렉션.

```typescript
  public tickLabel(value, primary, index) {
      if (primary) {
          return Math.round(value);
      }

      return value;
  }
```

위의 **tickLabel** 콜백에서는 모든 **주** 눈금의 **값**을 반올림하고 있습니다.

### Tailwind로 스타일링하기

사용자 지정 Tailwind 유틸리티 클래스를 사용하여 `slider`의 스타일을 지정할 수 있습니다. 먼저 [Tailwind를 설정](../themes/tailwind.mdx)했는지 확인하십시오.

전역 스타일시트에 Tailwind를 가져온 다음, 다음과 같이 원하는 테마 유틸리티를 적용할 수 있습니다:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

유틸리티 파일에는 `light` 및 `dark` 테마 변형이 모두 포함되어 있습니다.

- 밝은 테마에는 `light-*` 클래스를 사용하십시오.
- 어두운 테마에는 `dark-*` 클래스를 사용하십시오.
- 접두사 뒤에 컴포넌트 이름을 붙이십시오. 예: `light-slider`, `dark-slider`.

적용하면 이 클래스는 동적 테마 계산을 가능하게 합니다. 그런 다음 `arbitrary properties`을 사용하여 생성된 CSS 변수를 재정의할 수 있습니다. 콜론 뒤에는 유효한 CSS 색상 형식(HEX, CSS 변수, RGB 등)을 입력하십시오.

속성의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-slider-theme" label="IgxSlider 테마" />에서 확인할 수 있습니다. 구문은 다음과 같습니다:

```html
<igx-slider
class="!light-slider ![--thumb-color:#7B9E89]"
>
</igx-slider>
```

<DocsAside type="info">
유틸리티 클래스가 우선 적용되도록 느낌표(`!`)가 필요합니다. Tailwind는 스타일을 계층으로 적용하므로, 이 스타일을 중요(important)로 표시하지 않으면 컴포넌트의 기본 테마에 의해 재정의됩니다.
</DocsAside>
