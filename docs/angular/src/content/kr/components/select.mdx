# Angular Select 컴포넌트 개요

Angular Select는 미리 정의된 값 목록에서 단일 값을 선택하는 데 사용되는 폼 컴포넌트입니다. Angular Select 컴포넌트는 기본 HTML select 요소와 동일한 기능을 제공하지만, 훨씬 더 많은 사용자 지정 옵션을 제공합니다. 이는 <ApiLink type="DropDown" />을(를) 기반으로 하며, 템플릿화, 가상화, 드롭다운 목록 항목 사용자 지정을 포함한 모든 기능을 지원합니다.

## Ignite UI for Angular Select 시작하기

Ignite UI for Angular Select 컴포넌트를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxSelectModule`을(를) 가져오는 것입니다.

```typescript
// app.module.ts
...
import { IgxSelectModule } from 'igniteui-angular/select';
// import { IgxSelectModule } from '@infragistics/igniteui-angular'; for licensed package
@NgModule({
    ...
    imports: [..., IgxSelectModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxSelectComponent`을 독립형(standalone) 종속성으로 가져올 수 있으며, [`IGX_SELECT_DIRECTIVES`](https://github.com/IgniteUI/igniteui-angular/blob/master/projects/igniteui-angular/select/src/select/public_api.ts) 토큰을 사용하여 컴포넌트와 모든 지원 컴포넌트 및 디렉티브를 가져올 수도 있습니다.

```typescript
// home.component.ts

import { FormsModule } from '@angular/forms';
import { IGX_SELECT_DIRECTIVES } from 'igniteui-angular/select';
// import { IGX_SELECT_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-select [(ngModel)]="selected">
        <label igxLabel>Simple Select</label>
        <igx-select-item value="Orange">Orange</igx-select-item>
        <igx-select-item value="Apple">Apple</igx-select-item>
        <igx-select-item value="Banana">Banana</igx-select-item>
        <igx-select-item value="Mango">Mango</igx-select-item>
    </igx-select>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IGX_SELECT_DIRECTIVES, FormsModule]
    /* or imports: [IgxSelectComponent, IgxSelectItemComponent, IgxLabelDirective, FormsModule] */
})
export class HomeComponent {
    public selected: string;
}
```

이제 Ignite UI for Angular Select 모듈 또는 디렉티브를 가져왔으므로 `igx-select` 컴포넌트를 사용할 수 있습니다.

## Angular Select 사용하기

`igx-select`과(와) 함께 선택할 항목 목록을 추가하십시오. `igx-select`에 들어 있는 항목을 표시하기 위해 <ApiLink type="SelectItem" label="igx-select-item" />을(를) 사용합니다.

```html
<igx-select>
    <label igxLabel>Simple Select</label>
    <igx-select-item value="Orange">Orange</igx-select-item>
    <igx-select-item value="Apple">Apple</igx-select-item>
    <igx-select-item value="Banana">Banana</igx-select-item>
    <igx-select-item value="Mango">Mango</igx-select-item>
</igx-select>
```

<DocsAside type="info">
이 컴포넌트는 Material Icons를 사용합니다. 다음 링크를 `index.html`에 추가하십시오: `<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">`
</DocsAside>

또 다른 방법은 [*ngFor](https://angular.io/api/common/NgForOf) 구조 디렉티브를 사용하여 표시하려는 항목 컬렉션을 사용하는 것입니다:

```typescript
public items: string[] = ['Orange', 'Apple', 'Banana', 'Mango'];
```

```html
<igx-select [(ngModel)]="selected">
    <label igxLabel>Simple Select</label>
    <igx-select-item *ngFor="let item of items" [value]="item">
        {{item}}
    </igx-select-item>
</igx-select>
```

기본적으로 Select 컴포넌트는 항목 요소의 `innerText`을(를) 입력 필드에 사용합니다. 더 복잡한 항목 템플릿의 경우, `text` 속성을 명시적으로 설정하여 이 항목이 선택되었을 때 입력 필드에 무엇을 표시할지 지정할 수 있습니다. 예를 들어:

```html
<igx-select>
    <igx-select-item *ngFor="let item of items" [value]="item.value" [text]="item.text">
        {{item.text}} ( {{item.count}} )
    </igx-select-item>
</igx-select>
```

더 정교한 항목 템플릿에서 `text` 속성이 어떻게 동작하는지 보려면, 아래의 **그룹이 있는 Select** 섹션의 그룹화 샘플을 확인하십시오.

### 입력 속성

Select 컴포넌트는 [Input Group](/input-group)에 적용할 수 있는 다음 디렉티브를 지원합니다:

- `igxLabel` - `for` 속성을 설정할 필요가 없습니다. Angular Select 입력과의 연결은 `aria-labelledby`을(를) 통해 자동으로 처리됩니다.
- `igx-prefix`/`igxPrefix`
- `igx-suffix`/`igxSuffix` - 내장 토글 버튼 접미사는 항상 마지막에 표시된다는 점에 유의하십시오.
- `igx-hint`/`igxHint`

```html
<igx-select [(ngModel)]="selected">
    <label igxLabel>Pick a fruit</label>
    <igx-prefix>
        <span class="bio-prefix">BIO</span>
    </igx-prefix>
    @if (selected) {
        <igx-suffix>
            <igx-icon (click)="clearSelection($event)">clear</igx-icon>
        </igx-suffix>
    }
    <igx-hint>Choose a banana</igx-hint>
    <igx-select-item *ngFor="let item of items" [value]="item">
        {{item}}
    </igx-select-item>
</igx-select>
```

### 선택 항목 그룹화

항목 그룹을 시각적으로 구분하기 위해 select 컴포넌트는 항목을 `<igx-select-item-group>`(으)로 감싸서 항목 그룹화를 지원합니다.
이는 컴포넌트를 선언하기 위해 반복할 수 있는 계층형 데이터에서 가장 잘 작동합니다. 다음 예제에서 각 그룹에는 `label`과(와) `items` 컬렉션이 있습니다:

```typescript
public greengrocery: Array<{ label: string, items: Array<{ type: string, origin: string }> }> = [
    { label: 'Fruits', items: [
            { type: 'Apple', origin: 'local' },
            { type: 'Orange', origin: 'import' },
            { type: 'Banana', origin: 'import'}
        ]
    },
    { label: 'Vegetables', items: [
            { type: 'Cucumber', origin: 'local' },
            { type: 'Potato', origin: 'import' },
            { type: 'Pepper', origin: 'local' }
        ]
    }
];
```

그다음 템플릿 파일에서 객체를 반복하고 그에 따라 항목에 접근할 수 있습니다:

```html
<igx-select #select>
    <label igxLabel>Select With Groups</label>
    <igx-select-item-group *ngFor="let group of greengrocery" [label]="group.label">
        <igx-select-item *ngFor="let item of group.items" [value]="item.type" [text]="item.type">
            {{item.type}}
            @if (item.origin === 'local') {
                <igx-icon title="Local product">local_shipping</igx-icon>
            } @else {
                <igx-icon title="Import product">flight</igx-icon>
            }
        </igx-select-item>
    </igx-select-item-group>
</igx-select>
```

### 머리글 및 바닥글

현재 Select 컴포넌트에는 기본 머리글 및 바닥글 템플릿이 없습니다. 하지만 각각 `igxSelectHeader` 또는 `igxSelectFooter`로 표시하여 머리글이나 바닥글 템플릿을 추가할 수 있습니다. 이들은 사용자 지정 템플릿이므로 스타일도 직접 정의해야 합니다.
이 예제에서는 머리글과 바닥글 ng-template이 모두 정의되어 있습니다. 머리글에는 <ApiLink type="ButtonGroup" label="igx-buttongroup" />을(를) 통해 구현된 기본 필터링이 있습니다. 바닥글에는 배송 방법을 기준으로 한 모든 항목의 정적 요약이 있습니다.

```html
<igx-select>
    <label igxLabel>Pick your fruit</label>
    <igx-select-item *ngFor="let fruit of fruits" [value]="fruit.type" [text]="fruit.type" [ngSwitch]="fruit.delivery">
        {{fruit.type}}
        <igx-icon *ngSwitchCase="'flight'">flight</igx-icon>
        <igx-icon *ngSwitchCase="'train'">train</igx-icon>
        <igx-icon *ngSwitchCase="'boat'">directions_boat</igx-icon>
    </igx-select-item>
    <ng-template igxSelectHeader>
        <div class="custom-select-header">

            <span class="sample-template-heading">DELIVERY METHOD</span>
            <igx-buttongroup (click)="filter($event.target.title)">
                    <button igxButton title="flight"><igx-icon title="flight">flight</igx-icon></button>
                    <button igxButton title="train"><igx-icon title="train">train</igx-icon></button>
                    <button igxButton title="boat"><igx-icon title="boat">directions_boat</igx-icon></button>
            </igx-buttongroup>
        
</div>
    </ng-template>
    <ng-template igxSelectFooter>
        <div class="custom-select-footer">

            <span class="sample-template-heading">TOTAL</span>
            <div class="sample-template-icons">

                <span class="sample-template-icons__item">
                    <igx-icon
                        title="flight"
                        [class.important-icon]="selected === 'flight'"
                    >flight</igx-icon>
                    {{flightCount}}
                </span>
                <span class="sample-template-icons__item">
                    <igx-icon
                        title="train"
                        [class.important-icon]="selected === 'train'"
                    >train</igx-icon>
                    {{trainCount}}
                </span>
                <span class="sample-template-icons__item">
                    <igx-icon
                        title="boat"
                        [class.important-icon]="selected === 'boat'"
                    >directions_boat
                    </igx-icon>
                    {{boatCount}}
                </span>
            
</div>
        
</div>
    </ng-template>
</igx-select>
```

```html
<igx-select #select>

    </ng-template>
    ...
</igx-select>
```

## 키보드 탐색

- Select에 포커스가 있을 때 `Space`, `Enter` 또는 `ALT + Up/Down Arrow` 키를 눌러 `igx-select`을(를) 여십시오.
- `ALT + Up/Down Arrow` 조합 또는 `Enter`, `Space`, `Esc` 또는 `Tab` 키 중 하나를 사용하여 `igx-select`을(를) 닫으십시오.
- `Up/Down Arrow` 키를 사용하면 항목 사이를 이동할 수 있습니다.
- `Home` 또는 `End` 키를 사용하면 목록의 첫 번째 항목과 마지막 항목으로 이동합니다.
- 해당 키를 누르면 특정 문자로 시작하는 목록 항목 사이를 이동할 수 있습니다.
- 이동하려는 항목의 처음 몇 글자를 빠르게 입력하면 특정 항목으로 이동할 수 있습니다.
- `Enter` 또는 `Space` 키를 사용하여 항목을 선택하십시오

<DocsAside type="info">
`igx-select`은(는) _단일_ 항목 선택만 지원합니다.
</DocsAside>

## 사용자 지정 오버레이 설정

사용자 지정 <ApiLink type="OverlaySettings" kind="interface" />을(를) 만들 수 있습니다. 이를 위해 먼저 다음과 같이 템플릿을 정의하십시오:

```html
<igx-select [overlaySettings]="customOverlaySettings">
    <igx-select-item *ngFor="let item of items">
        {{item}}
    </igx-select-item>
</igx-select>
```

- 여기서 `overlaySettings` 속성은 사용자 지정 설정에 바인딩됩니다.

클래스 안에는 다음과 비슷한 내용이 들어갑니다:

```typescript
export class MyClass implements OnInit {
    @ViewChild(IgxSelectComponent)
    public select: IgxSelectComponent;
    public items: string[] = ['Orange', 'Apple', 'Banana', 'Mango', 'Tomato'];
    public customOverlaySettings: OverlaySettings;

    public ngOnInit(): void {
        const positionSettings: PositionSettings = {
            closeAnimation: scaleOutBottom,
            horizontalDirection: HorizontalAlignment.Right,
            horizontalStartPoint: HorizontalAlignment.Left,
            openAnimation: scaleInTop,
            verticalDirection: VerticalAlignment.Bottom,
            verticalStartPoint: VerticalAlignment.Bottom
        };
        this.customOverlaySettings = {
            target: this.select.inputGroup.element.nativeElement,
            positionStrategy: new ConnectedPositioningStrategy(
                positionSettings
            ),
            scrollStrategy: new AbsoluteScrollStrategy()
        };
    }
}
```

<ApiLink kind="interface" type="PositionSettings" /> 객체를 만들어 <ApiLink type="ConnectedPositioningStrategy" />에 직접 전달하는 것을 볼 수 있습니다. 이렇게 할 필요는 없지만, 사용자 지정 위치를 정의하고 싶으므로 이를 사용하여 전략의 기본 설정을 재정의합니다.

- 모든 설정은 [_ngOnInit_](https://angular.io/api/core/OnInit) 훅 안에서 설정할 수 있으며, 이는 컴포넌트가 생성될 때 템플릿에 자동으로 반영됩니다.

<Sample src="/data-entries/select-sample-4" height={260} alt="" />

사용자 지정 <ApiLink type="OverlaySettings" kind="interface" /> 객체를 <ApiLink type="Select" member="open" label="IgxSelectComponent" />의 open 함수에도 전달할 수 있으며, 이 경우 템플릿은 다음과 같아야 합니다:

```html
<igx-select>
    <igx-select-item *ngFor="let item of items">
        {{item}}
    </igx-select-item>
</igx-select>

<button (click)="onClick($event)"></button>
```

그리고 클래스에는 다음이 들어 있습니다:

```typescript
export class MyClass implements OnInit {
    /* -- */
    private otherCustomOverlaySettings: OverlaySettings = {
        positionStrategy: new GlobalPositionStrategy(),
        scrollStrategy: new AbsoluteScrollStrategy()
    }
    onClick(event: MouseEvent): void {
        this.select.open(this.otherCustomOverlaySettings)
    }
    /* -- */
}
```

<DocsAside type="info">
`open` 함수의 인수와 템플릿 양쪽에 사용자 지정 설정을 전달하면, `igx-select`은(는) `open` 함수에서 제공된 설정을 사용합니다. 하지만 설정을 `opening` 또는 `opened`와 같은 내부 이벤트에 바인딩하면, `igx-select`은(는) 템플릿에서 제공된 설정을 사용합니다.
</DocsAside>

## 스타일링

### Select 테마 속성 맵

기본 속성을 수정하면, 관련된 모든 종속 속성이 변경 사항을 반영하도록 자동으로 업데이트됩니다:

| 기본 속성 | 종속 속성 | 설명 |
| --- | --- | --- |
| **$toggle-button-background** | $toggle-button-foreground | 토글 버튼의 전경 색상입니다 |
|  | $toggle-button-foreground-filled | 토글 버튼이 채워져 있을 때의 전경 색상입니다 |
|  | $toggle-button-background-focus | 포커스되었을 때의 배경 색상입니다 |
|  | $toggle-button-background-focus--border (bootstrap/indigo) | 테두리 변형(Bootstrap/Indigo)에서 포커스되었을 때의 배경입니다 |
|  | $toggle-button-foreground-focus | 토글 버튼이 포커스되었을 때의 전경 색상입니다 |

모든 컴포넌트에는 고유한 테마 함수가 있습니다.

Select 컴포넌트의 스타일을 지정하려면 이를 포함하는 컴포넌트의 스타일도 지정해야 합니다. 이 경우 <ApiLink kind="sass" module="themes" type="function-input-group-theme" label="input-group-theme" />과(와) <ApiLink kind="sass" module="themes" type="function-drop-down-theme" label="drop-down-theme" />입니다.
이 두 컴포넌트의 스타일을 어떻게 지정하는지 더 잘 이해하려면 [`Input Group`](/input-group#스타일링) 및 [`Drop Down`](/drop-down#스타일링) 스타일 지정 섹션을 참조하십시오.

Select 컴포넌트의 버튼 스타일만 지정하는 데 사용되는 <ApiLink kind="sass" module="themes" type="function-select-theme" label="select-theme" code={true} /> 함수도 있습니다. <br/>
Select 컴포넌트 버튼의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink kind="sass" module="themes" type="function-select-theme" label="select-theme" code={true} />을(를) 확장하고 `$toggle-button-background` 매개변수만 제공하는 새 테마를 만듭니다. 테마 함수는 이 단일 값을 기준으로 다양한 상태에 대한 모든 배경색과 전경색을 자동으로 계산합니다.

```scss
$custom-select-theme: select-theme(
  $toggle-button-background: #57a5cd,
);
```

마지막 단계는 애플리케이션에 사용자 지정 라디오 테마를 전달하는 것입니다:

```scss
:host {
    @include tokens($custom-select-theme);
}
```

### Tailwind로 스타일링하기

사용자 지정 Tailwind 유틸리티 클래스를 사용하여 select의 스타일을 지정할 수 있습니다. 먼저 [Tailwind를 설정](/themes/tailwind)했는지 확인하십시오.

전역 스타일시트에 Tailwind를 가져온 다음, 다음과 같이 원하는 테마 유틸리티를 적용할 수 있습니다:

```scss
@import "tailwindcss";
...
@use 'igniteui-theming/tailwind/utilities/material.css';
```

유틸리티 파일에는 `light` 및 `dark` 테마 변형이 모두 포함되어 있습니다.

- 밝은 테마에는 `light-*` 클래스를 사용하십시오.
- 어두운 테마에는 `dark-*` 클래스를 사용하십시오.
- 접두사 뒤에 컴포넌트 이름을 붙이십시오. 예: `light-select`, `dark-select`.

적용하면 이 클래스는 동적 테마 계산을 가능하게 합니다. 그런 다음 `arbitrary properties`을 사용하여 생성된 CSS 변수를 재정의할 수 있습니다. 콜론 뒤에는 유효한 CSS 색상 형식(HEX, CSS 변수, RGB 등)을 입력하십시오.

속성의 전체 목록은 <ApiLink kind="sass" module="themes" type="function-select-theme" label="select-theme" />에서 확인할 수 있습니다. 구문은 다음과 같습니다:

```html
<igx-select
  class="!light-select ![--toggle-button-background:#99BAA6]">
  ...
</igx-select>
```

<DocsAside type="info">
유틸리티 클래스가 우선 적용되도록 느낌표(`!`)가 필요합니다. Tailwind는 스타일을 계층으로 적용하므로, 이 스타일을 중요(important)로 표시하지 않으면 컴포넌트의 기본 테마에 의해 재정의됩니다.
</DocsAside>
