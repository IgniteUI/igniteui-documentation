# 가장 빠른 Angular 데이터 그리드
Ignite UI for Angular는 세계에서 가장 빠른 가상화 Angular 데이터 그리드를 포함하여 Angular 네이티브이고 Material 기반인 UI 컴포넌트의 완전한 라이브러리를 제공합니다.


## Angular 그리드 예제
이 angular 그리드 예제에서는 사용자가 데이터 검색과 필터링, 열 정렬, 크기 조정, 고정과 숨기기, 행 선택, Excel과 CSV 내보내기, 가로 및 세로 스크롤 등 그리드에 내장된 다양한 기능을 활용하여 *데이터 보기*를 사용자 지정하는 방법을 볼 수 있습니다. 선형 진행률 막대 표시기와 스파크라인 같은 컴포넌트를 포함하는 셀 템플릿 예제도 제공합니다.

## Angular 데이터 그리드란 무엇입니까?

Angular 데이터 그리드는 표 형식 데이터를 행과 열의 집합으로 표시하는 데 사용되는 컴포넌트입니다. 데이터 그리드는 테이블이라고도 하며, Microsoft Excel 같은 인기 소프트웨어 덕분에 데스크톱 세계에서 잘 알려져 있습니다. 그리드는 데스크톱 플랫폼에서 오래전부터 사용되었지만, 최근에는 Angular UI 같은 웹 앱 UI의 일부가 되었습니다. 최신 그리드는 복잡할 수 있으며, 데이터 바인딩, 편집, Excel과 비슷한 필터링, 사용자 지정 정렬, 그룹화, 행 재정렬, 행과 열 고정, 행 집계, Excel, CSV, PDF 형식으로의 내보내기 등 다양한 기능을 포함할 수 있습니다.

## Angular 데이터 그리드를 사용하는 이유는 무엇입니까?

Angular 데이터 그리드는 대량의 데이터를 저장하고 빠르게 정렬해야 하는 사용 사례에서 필수적입니다. 이는 고용량, 고속 데이터를 자주 사용하는 금융이나 보험 같은 산업을 포함할 수 있습니다. 이러한 기업의 성공은 종종 이런 데이터 그리드의 기능과 성능에 달려 있습니다. 예를 들어 주식 결정을 마이크로초 단위로 내려야 할 때는, 데이터 그리드가 지연이나 깜빡임 없이 동작하는 것이 반드시 필요합니다.

Ignite UI for Angular 데이터 그리드는 고용량 및 실시간 데이터만을 위한 것이 아닙니다. 이는 직접 구현하기에는 그렇게 적은 코드로 얻을 수 없는 기능을 제공하는 기능이 풍부한 Angular 그리드입니다.

### 데이터 가상화와 성능
데이터 그리드의 열 및 행 수준 가상화를 통해 Angular 그리드에서 무제한의 행과 열을 끊김 없이 스크롤하십시오. 로컬 또는 원격 데이터 소스를 지원하므로 데이터가 어디에 있든 최고의 성능을 얻을 수 있습니다. 사용자는 엔터프라이즈 속도로 Excel과 비슷한 스크롤을 경험하게 됩니다. 지연, 화면 깜빡임, 시각적 지연이 없어 성능을 희생하지 않으면서 최고의 사용자 경험(UX)을 제공합니다.

### Angular 그리드 페이징, 정렬, 필터링, 검색
기본 [페이저](/grid/paging)를 사용하여 사용자가 데이터 세트를 탐색하게 하거나, 자신만의 페이징 경험을 위해 직접 템플릿을 만들 수 있습니다. 단일 열 및 다중 열 정렬을 완벽하게 지원하며, 그리드에 대한 전체 텍스트 [검색](/grid/search)과 데이터 타입 기반 [Microsoft Excel 스타일 필터링](/grid/excel-style-filtering)을 포함한 여러 [고급 필터링](/grid/advanced-filtering) 옵션을 제공합니다.

### Angular 그리드 인라인 편집
열의 데이터 타입에 기반한 편집 가능한 열의 [기본 셀 템플릿](/grid/grid#셀-편집-템플릿)을 제공합니다. 편집 가능한 열에 대해 자체 사용자 지정 템플릿을 정의하고, 셀 값 변경을 확정하거나 취소하는 기본 동작을 재정의할 수 있습니다.

### Angular 그리드의 키보드 탐색과 행/셀 선택

위, 아래, 오른쪽, 왼쪽, Tab, Enter 키를 사용하여 Angular 데이터 그리드에서 Excel과 비슷한 [키보드 탐색](/grid/keyboard-navigation)을 제공함으로써 접근성 준수를 보장하고 사용성을 개선하십시오. 마우스나 키보드를 사용하여 Angular 그리드에서 단일 또는 다중 행 선택을 전환해 전체 행을 선택하거나 선택 해제할 수 있으며, 그리드 도구 모음의 내장 전체 선택/전체 선택 해제 체크박스를 사용하여 행 선택을 다룰 수도 있습니다. <a class="no-external-icon" href="https://www.infragistics.com/community/blogs/b/engineering/posts/grid-keyboard-navigation-accessibility-">이 기능의 최신 개선 사항에 대해 알아보십시오</a>.

### Angular 그리드 접근성과 ARIA 지원

Ignite UI for Angular의 Angular 컴포넌트는 각각 최신 접근성 가이드라인과 사양에 따라 구현되었습니다. Angular 컴포넌트는 OS 또는 브라우저가 제공하는 접근성 기술인 화면 낭독기로 테스트되었습니다. 우리 팀은 가이드라인이 구현되었을 뿐 아니라, 시각 장애가 있는 사용자에게 전달되는 실제 콘텐츠가 실제로 소비 가능하고 사용하기 쉬운지도 확인합니다. Ignite UI for Angular 데이터 그리드는 a11y 키보드 접근성, ARIA, 접근 가능한 색상 팔레트를 갖춰 완전히 접근 가능합니다. <a class="no-external-icons" href="https://www.infragistics.com/community/blogs/b/engineering/posts/grid-keyboard-navigation-accessibility">자세히 알아보기</a>.

### Angular 그리드의 열 그룹화, 고정, 요약, 이동

마우스 상호 작용, 터치 또는 우리 API를 통해 열 또는 미리 설정된 열 그룹을 그룹화하며, 내장 열 [요약](/grid/summaries) 또는 사용자 지정 요약 템플릿을 지원합니다. 사용자가 대화형으로 열을 [숨기거나](/grid/column-hiding) [이동](/grid/column-moving)할 수 있게 하며, 이동, 드래그, 재정렬 작업 중 대화형 [열 고정](/grid/column-pinning)을 완전히 지원합니다.
