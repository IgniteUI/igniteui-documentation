# Angular Date Time Editor 디렉티브

<div class="highlight">
Ignite UI for Angular Date Time Editor 디렉티브를 사용하면 사용자가 선택한 입력 요소에서 날짜와 시간을 설정하고 편집할 수 있습니다. 사용자는 편집 가능한 마스크 입력을 사용하여 날짜 또는 시간 부분을 편집할 수 있습니다. 또한 원하는 표시 및 입력 형식을 지정할 수 있으며, 유효성 검사를 위해 최소값과 최대값을 사용할 수 있습니다.
</div>

## Angular Date Time Editor 디렉티브 시작하기

Ignite UI for Angular Date Time Editor 디렉티브를 시작하려면 먼저 Ignite UI for Angular를 설치해야 합니다. 기존 Angular 애플리케이션에서 다음 명령을 입력하십시오:

```cmd
ng add igniteui-angular
```

Ignite UI for Angular에 대한 전체 소개는 [_시작하기_](/general/getting-started) 항목을 읽어 보십시오.

다음 단계는 **app.module.ts** 파일에서 `IgxDateTimeEditorModule`을 가져오는 것입니다.

```typescript
// app.module.ts

...
import { IgxDateTimeEditorModule } from 'igniteui-angular/directives';
// import { IgxDateTimeEditorModule } from '@infragistics/igniteui-angular'; for licensed package

@NgModule({
    ...
    imports: [..., IgxDateTimeEditorModule],
    ...
})
export class AppModule {}
```

또는 `16.0.0` 버전부터는 `IgxDateTimeEditorDirective`을(를) 독립형 종속성으로 가져올 수 있습니다.

```typescript
// home.component.ts

import { IgxDateTimeEditorDirective } from 'igniteui-angular/directives';
import { IGX_INPUT_GROUP_DIRECTIVES } from 'igniteui-angular/input-group';
// import { IgxDateTimeEditorDirective, IGX_INPUT_GROUP_DIRECTIVES } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'app-home',
    template: `
    <igx-input-group>
        <input type="text" igxInput igxDateTimeEditor [value]="date" />
    </igx-input-group>
    `,
    styleUrls: ['home.component.scss'],
    standalone: true,
    imports: [IgxDateTimeEditorDirective, IGX_INPUT_GROUP_DIRECTIVES]
})
export class HomeComponent {
    public date = new Date();
}
```

이제 Ignite UI for Angular Date Time Editor 모듈 또는 디렉티브를 가져왔으므로, `igxDateTimeEditor` 디렉티브를 사용하기 시작할 수 있습니다.

## Angular Date Time Editor 디렉티브 사용하기

입력을 날짜 시간 편집기로 사용하려면 igxDateTimeEditor 디렉티브를 설정하고 유효한 날짜 객체를 값으로 지정하십시오. 완전한 편집기 모양과 느낌을 주려면 입력을 [igx-input-group](/input-group)으로 감싸십시오. 이렇게 하면 다음 디렉티브 <ApiLink type="InputDirective" label="igxInput" />, [`igxLabel`](/label-input), [`igx-prefix`](/input-group#접두사--접미사), [`igx-suffix`](/input-group#접두사--접미사), [`igx-hint`](/input-group#힌트)를 활용할 수 있을 뿐 아니라, 폼 입력을 다룰 때의 일반적인 시나리오도 처리할 수 있습니다.

### 바인딩

Date 객체를 <ApiLink type="DateTimeEditorDirective" member="value" label="value" />로 설정하는 기본 구성 시나리오:

```typescript
public date = new Date();
```

```html
<igx-input-group>
    <input type="text" igxInput igxDateTimeEditor [value]="date" />
</igx-input-group>
```

양방향 데이터 바인딩을 만들려면 `ngModel`을(를) 설정하십시오:

```html
<igx-input-group>
    <input type="text" igxInput igxDateTimeEditor [(ngModel)]="date"/>
</igx-input-group>
```

#### <a name="iso">ISO 문자열에 바인딩하기</a>

`IgxDateTimeEditorDirective`은(는) [`ISO 8601`](https://tc39.es/ecma262/#sec-date-time-string-format) 문자열을 받습니다.

문자열은 전체 `ISO` 문자열일 수 있으며, 형식은 `YYYY-MM-DDTHH:mm:ss.sssZ`입니다. 또는 날짜만 있는 부분과 시간만 있는 부분으로 나뉠 수도 있습니다.

##### 날짜만

날짜만 있는 문자열을 디렉티브에 바인딩하는 경우 형식 - `YYYY-MM-DD`을(를) 따라야 합니다. 이는 문자열 값을 디렉티브에 바인딩할 때에만 적용되며, 편집기에 값을 입력할 때에는 <ApiLink type="DateTimeEditorDirective" member="inputFormat" label="inputFormat" />이(가) 여전히 사용되고 같은 형식일 필요는 없습니다. 또한 날짜만 있는 문자열을 바인딩할 때 디렉티브는 시간을 `T00:00:00`(으)로 강제하여 시간 이동을 방지합니다.

##### 시간만

시간만 있는 문자열은 보통 `ECMA` 사양에 정의되어 있지 않지만, 디렉티브가 시간만 필요한 시나리오에 통합될 수 있도록 24시간 형식 - `HH:mm:ss`을(를) 지원합니다. 12시간 형식은 지원되지 않습니다. 이는 _바인딩된 값에만_ 적용된다는 점에도 유의하십시오.

##### 전체 ISO 문자열

전체 `ISO` 문자열이 바인딩되면, 디렉티브는 [`Date.parse`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/parse#date_time_string_format)에서 요구하는 모든 요소가 제공된 경우에만 이를 파싱합니다.

`InvalidDate`을(를) 포함하여 모든 false 값은 `null`(으)로 파싱됩니다. 날짜만, 시간만 또는 전체 `ISO` 문자열이 불완전하면 `InvalidDate`(으)로 파싱됩니다.

### 키보드 탐색

Date Time Editor 디렉티브는 직관적인 키보드 탐색을 제공하므로, 마우스를 사용하지 않고도 값을 쉽게 증가 또는 감소시키거나 여러 DatePart 사이를 이동할 수 있습니다.

- <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>Arrow Left</kbd> / <kbd>Right</kbd> - 날짜 구역 사이를 이동합니다. <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>Right</kbd>를 누르면 구역의 끝으로 이동합니다. 이미 끝에 있으면 다음 구역이 있는 경우 그 구역의 끝으로 이동합니다. 반대 방향에서도 비슷한 방식으로 동작합니다.

- <kbd>Arrow Up</kbd> / <kbd>Down</kbd> - 날짜 부분을 증가/감소시킵니다. 관련 <ApiLink type="DateTimeEditorDirective" member="spinLoop" label="spinLoop" />을 참조하십시오

- <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>;</kbd> - 편집기에 현재 날짜와 시간을 설정합니다.

## 예제

### 표시 및 입력 형식

<ApiLink type="DateTimeEditorDirective" />은(는) 서로 다른 표시 및 입력 형식을 지원합니다.

Angular의 [`DatePipe`](https://angular.io/api/common/DatePipe)을(를) 사용하므로, `shortDate` 및 `longDate`와 같은 사전 정의된 형식 옵션을 지원할 수 있습니다. `DatePipe`가 지원하는 문자를 사용하여 구성된 형식 문자열(예: `EE/MM/yyyy`)도 받을 수 있습니다. `shortDate`, `longDate` 등의 형식은 <ApiLink type="DateTimeEditorDirective" member="displayFormat" label="displayFormat" />로만 사용할 수 있다는 점에 유의하십시오. 또한 <ApiLink type="DateTimeEditorDirective" member="displayFormat" label="displayFormat" />이(가) 제공되지 않으면, 편집기는 <ApiLink type="DateTimeEditorDirective" member="inputformat" label="inputFormat" />을(를) <ApiLink type="DateTimeEditorDirective" member="displayFormat" label="displayFormat" />(으)로 사용합니다.
또는 <ApiLink type="DateTimeEditorDirective" member="inputFormat" label="inputFormat" /> 속성이 설정되지 않은 경우, 입력 형식은 숫자 날짜-시간 부분만 포함하는 것으로 파싱할 수 있으면 <ApiLink type="DateTimeEditorDirective" member="displayFormat" label="displayFormat" />로부터 추론됩니다.

특정 입력 형식을 설정하려면 문자열로 IgxDateTimeEditor 디렉티브에 전달하십시오. 이렇게 하면 기대되는 사용자 입력 형식과 편집기의 [마스크](/mask)가 모두 설정됩니다. 또한 <ApiLink type="DateTimeEditorDirective" member="inputFormat" label="inputFormat" />은(는) 로캘을 기준으로 하므로, 제공되지 않으면 편집기는 브라우저가 사용하는 로캘을 기본으로 사용합니다.

```html
<igx-input-group>
    <input type="text" igxInput [displayFormat]="'shortDate'" [igxDateTimeEditor]="'dd/MM/yyyy'" [(ngModel)]="date"/>
</igx-input-group>
```

아래 표는 디렉티브의 <ApiLink type="DateTimeEditorDirective" member="inputFormat" label="inputFormat" />이(가) 지원하는 형식을 보여 줍니다:

|  형식 | 설명                                                                 |
| :------ | :-------------------------------------------------------------------------- |
| `d`     | 날짜. 편집 중에는 앞에 0이 붙습니다.                    |
| `dd`    | 앞에 0이 명시적으로 설정된 날짜.                                   |
| `M`     | 월. 편집 중에는 앞에 0이 붙습니다.                   |
| `MM`    | 앞에 0이 명시적으로 설정된 월.                                  |
| `yy`    | 짧은 연도 형식.                                                          |
| `yyyy`  | 전체 연도 형식.                                                           |
| `h`     | 12시간 형식의 시. 편집 중에는 앞에 0이 붙습니다. |
| `hh`    | 앞에 0이 명시적으로 설정된 12시간 형식의 시.                |
| `H`     | 24시간 형식의 시. 편집 중에는 앞에 0이 붙습니다. |
| `HH`    | 앞에 0이 명시적으로 설정된 24시간 형식의 시.               |
| `m`     | 분. 편집 중에는 앞에 0이 붙습니다.                 |
| `mm`    | 앞에 0이 명시적으로 설정된 분.                                |
| `tt`    | 12시간 형식의 AM/PM 구역.                                           |

<DocsAside type="info">
`IgxDateTimeEditorDirective` 디렉티브는 IME 입력을 지원합니다. 아시아 언어로 입력할 때 컨트롤은 입력 방식 조합과 후보 목록을 컨트롤의 편집 영역에 직접 표시하고, 조합이 끝나면 주변 텍스트를 즉시 다시 배치합니다.
</DocsAside>

### 최소 및 최대 값

입력을 제한하고 ngModel의 유효성을 제어하려면 <ApiLink type="DateTimeEditorDirective" member="minValue" label="minValue" /> 및 <ApiLink type="DateTimeEditorDirective" member="maxValue" label="maxValue" /> 속성을 지정할 수 있습니다.

```typescript
public minDate = new Date(2020, 1, 15);
public maxDate = new Date(2020, 11, 1);
```

```html
<igx-input-group>
    <input type="text" igxInput igxDateTimeEditor [minValue]="minDate" [maxValue]="maxDate" [(ngModel)]="date"/>
</igx-input-group>

```

<ApiLink type="DateTimeEditorDirective" member="minValue" label="minValue" /> 및 <ApiLink type="DateTimeEditorDirective" member="minValue" label="minValue" /> 입력은 `string` 타입일 수도 있습니다. [ISO 문자열에 바인딩](#iso)을 참조하십시오.

### <a name="increment-decrement"></a> 증가 및 감소

<ApiLink type="DateTimeEditorDirective" label="igxDateTimeEditor" /> 디렉티브는 공개된 <ApiLink type="DateTimeEditorDirective" member="increment" label="increment" /> 및 <ApiLink type="DateTimeEditorDirective" member="decrement" label="decrement" /> 메서드를 노출합니다. 이 메서드들은 현재 설정된 날짜와 시간의 특정 <ApiLink type="DatePart" kind="enum" />을(를) 증가 또는 감소시키며, 여러 방식으로 사용할 수 있습니다.

첫 번째 시나리오에서는 메서드에 특정 <ApiLink type="DatePart" kind="enum" />을(를) 전달하지 않으면, 지정된 <ApiLink type="DateTimeEditorDirective" member="inputFormat" label="inputFormat" /> 및 내부 디렉티브 구현에 따라 기본 <ApiLink type="DatePart" kind="enum" />이(가) 증가 또는 감소합니다. 두 번째 시나리오에서는 다양한 요구 사항에 맞게 조작할 <ApiLink type="DatePart" kind="enum" />을(를) 명시적으로 지정할 수 있습니다.
또한 두 메서드 모두 증가/감소 단계를 설정하는 데 사용할 수 있는 `number` 타입의 선택적 `delta` 매개변수를 받습니다.

또한 <ApiLink type="DateTimeEditorDirective" member="spinDelta" label="spinDelta" />은(는) <ApiLink type="DateTimeEditorDirective" label="DatePartDeltas" /> 타입의 입력 속성이며, 각 날짜-시간 구역에 서로 다른 증감값을 적용하는 데 사용할 수 있습니다. 이는 키보드로 값을 돌릴 때와 <ApiLink type="DateTimeEditorDirective" member="increment" label="increment" /> 및 <ApiLink type="DateTimeEditorDirective" member="decrement" label="decrement" /> 메서드로 값을 돌릴 때 모두 적용되되, 해당 메서드에 `delta` 매개변수가 제공되지 않은 경우에만 적용됩니다. 제공되면 <ApiLink type="DateTimeEditorDirective" member="spinDelta" label="spinDelta" />보다 우선하기 때문입니다.

### Angular 폼에서

Date Time Editor 디렉티브는 핵심 FormsModule [`NgModel`](https://angular.io/api/forms/NgModel) 및 [`ReactiveFormsModule`](https://angular.io/api/forms/ReactiveFormsModule)(FormControl, FormGroup 등)의 모든 폼 디렉티브를 지원합니다. 여기에는 [Forms `Validators`](https://angular.io/api/forms/Validators) 함수도 포함됩니다. 다음 예제는 템플릿 기반 폼에서 `required` 검증자를 사용하는 방법을 보여 줍니다.

<DocsAside type="info">
필요한 경우 `validationFailed` 이벤트를 처리하고 사용 가능한 인수의 `newValue` 속성을 변경하여 유효한 상태로 되돌릴 수 있습니다.
</DocsAside>

템플릿 기반 폼 예제:

```html
<form>
    <igx-input-group>
        <input igxInput type="text" [(ngModel)]="date" name="form" required
            (valueChanged)="onValueChanged($event)" (validationFailed)="onValidationFailed($event)"
            [igxDateTimeEditor]="'dd/MM/yyyy'" [minValue]="minDate" [maxValue]="maxDate" [isSpinLoop]="false" />
    </igx-input-group>
</form>
<hr/>
```

### 텍스트 선택

<ApiLink type="TextSelectionDirective" />을(를) 사용하면 포커스 시 컴포넌트가 모든 입력 텍스트를 선택하도록 강제할 수 있습니다. <ApiLink type="TextSelectionDirective" />에 대한 자세한 정보는 [Label & Input](/label-input#포커스--텍스트-선택)에서 확인할 수 있습니다.

```html
<igx-input-group>
    <input igxInput [igxDateTimeEditor]="'dd/MM/yyyy'" [igxTextSelection]="true"/>
</igx-input-group>
```

<DocsAside type="info">
컴포넌트가 올바르게 동작하려면 <ApiLink type="DateTimeEditorDirective" label="igxDateTimeEditor" /> 디렉티브 다음에 <ApiLink type="TextSelectionDirective" />을(를) 설정하는 것이 매우 중요합니다. 두 디렉티브 모두 입력의 `focus` 이벤트에서 동작하므로, 텍스트 선택은 마스크가 설정된 후에 이루어져야 하기 때문입니다.
</DocsAside>
