# Angular Pivot Grid 도구 모음

Ignite UI for Angular의 Pivot Grid은(는) 본질적으로 **UI** 작업을 위한 컨테이너인 <ApiLink type="GridToolbar" />을(를) 제공합니다. Angular 도구 모음은 Angular 컴포넌트의 상단, 즉 Pivot Grid에 위치하며 그 가로 크기와 맞습니다. 도구 모음 컨테이너는 Pivot Grid의 다음 기능을 위한 미리 정의된 UI 컨트롤을 담을 수 있습니다:

- 열 숨기기
- 열 고정
- Excel, CSV 및 PDF로 내보내기
- 고급 필터링

또는 그 밖의 임의의 사용자 지정 콘텐츠도 가능합니다. 도구 모음과 미리 정의된 UI 컴포넌트는 Angular 이벤트를 지원하며 개발자를 위한 API를 노출합니다.

위 코드 조각에서 볼 수 있듯이, 미리 정의된 `actions` UI 컴포넌트는 <ApiLink type="GridToolbarActions" label="<igx-grid-toolbar-actions>` container" />로 감싸져 있습니다. 이렇게 하면 도구 모음 제목은 도구 모음의 왼쪽에, 작업은 도구 모음의 오른쪽에 정렬됩니다.

기본 UI 컴포넌트 각각을 전체적으로 보려면, 아래의 **기능** 섹션을 계속 읽으십시오.

## 기능

도구 모음은 그리드 전체에 영향을 주는 로직과 상호 작용을 분리하는 데 적합합니다.
위에서 보았듯이, 그리드의 열 숨기기, 열 고정, 고급 필터링, 데이터 내보내기를 위한 기본 컴포넌트를 제공하도록 구성할 수 있습니다.
이 기능들은 Ignite UI for Angular 제품군의 card 컴포넌트와 비슷한 패턴을 따라 서로 독립적으로 활성화할 수 있습니다.
도구 모음의 주요 기능은 각각에 대한 예제 코드와 함께 아래에 나열되어 있습니다.

### 제목

그리드 도구 모음의 제목은 <ApiLink type="GridToolbarTitle" />을(를) 사용하여 설정합니다.
사용자는 단순한 텍스트부터 더 복잡한 템플릿까지 무엇이든 제공할 수 있습니다.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-title>Grid toolbar title</igx-grid-toolbar-title>
</igx-grid-toolbar>
```

### 작업

도구 모음은 상위 그리드와 관련된 작업/상호 작용을 배치할 수 있는 <ApiLink type="GridToolbarActions" label="특정 컨테이너" />을(를) 노출합니다.
도구 모음 제목 부분과 마찬가지로, 사용자는 그 템플릿 부분 안에 기본 도구 모음 상호 작용 컴포넌트를 포함하여 무엇이든 제공할 수 있습니다.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <button igxButton>Action</button>
        <igx-select></igx-select>
        ...
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

각 작업은 이제 <ApiLink type="GridToolbarHiding" member="overlaySettings" label="overlaySettings" /> 입력을 사용하여 작업 대화 상자의 오버레이 설정을 바꿀 수 있는 방법을 노출합니다. 예:

```html
<igx-grid-toolbar-actions>
    <igx-grid-toolbar-pinning [overlaySettings]="overlaySettingsScaleCenter"></igx-grid-toolbar-pinning>
    <igx-grid-toolbar-hiding [overlaySettings]="overlaySettingsAuto"></igx-grid-toolbar-hiding>
</igx-grid-toolbar-actions>
```

```ts
public data: any[];
public positionStrategyScaleCenter = new GlobalPositionStrategy({
    openAnimation: scaleInCenter,
    closeAnimation: scaleOutCenter
});
public overlaySettingsScaleCenter = {
    positionStrategy: this.positionStrategyScaleCenter,
    scrollStrategy: new AbsoluteScrollStrategy(),
    modal: true,
    closeOnEscape: true
};

public positionStrategyAuto = new AutoPositionStrategy();
public overlaySettingsAuto = {
    positionStrategy: this.positionStrategyAuto,
    scrollStrategy: new AbsoluteScrollStrategy(),
    modal: false,
    closeOnEscape: false
};
constructor() {
    this.data = athletesData;
}
```

기본 overlaySettings는 _ConnectedPositionStrategy_를 _Absolute_ 스크롤 전략과 함께 사용하며, _modal_은 false로 설정되어 있고, _Esc 키로 닫기_와 _외부 클릭으로 닫기_ 상호 작용이 활성화되어 있습니다.

### 열 고정

<ApiLink type="GridToolbarPinning" label="도구 모음 열 고정 컴포넌트" />은(는) 그리드의 열 고정과 상호 작용하는 기본 UI를 제공합니다.
이 컴포넌트는 도구 모음을 포함하는 상위 그리드와 함께 바로 작동하도록 설정되어 있으며, 컴포넌트 제목, 컴포넌트 입력의 자리 표시자, 드롭다운 자체의 높이처럼 UI를 사용자 지정하기 위한 여러 입력 속성도 있습니다.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-pinning
            title="Grid pinned columns"
            prompt="Filter column collection"
            columnListHeight="400px"
        >
        </igx-grid-toolbar-pinning>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

### 열 숨기기

<ApiLink type="GridToolbarHiding" label="도구 모음 숨기기 컴포넌트" />은(는) 열 숨기기와 상호 작용하는 기본
UI를 제공합니다. UI를 사용자 지정하기 위해 컴포넌트 제목, 컴포넌트 입력의 자리 표시자, 드롭다운 자체의 높이 같은 같은 입력 속성을 노출합니다.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-hiding
            title="Grid column hiding"
            prompt="Filter column collection"
            columnListHeight="400px"
        >
        </igx-grid-toolbar-hiding>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

### 고급 필터링

<ApiLink type="GridToolbarAdvancedFiltering" label="도구 모음 고급 필터링 컴포넌트" />은(는) 고급 필터링 기능의 기본 UI를 제공합니다. 이 컴포넌트는 버튼의 기본 텍스트를 바꾸는 방법을 노출합니다.

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>

    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

### 데이터 내보내기

도구 모음의 다른 작업과 마찬가지로, 내보내기도 기본으로 <ApiLink type="GridToolbarExporter" label="도구 모음 내보내기 컴포넌트" />을(를) 통해 제공됩니다.
내보내기 컴포넌트는 대상 데이터 형식(<ApiLink type="ExcelExporterService" label="Excel" />, <ApiLink type="CsvExporterService" label="CSV" />, <ApiLink type="PdfExporterService" label="PDF" />)에 맞는 서비스를 사용합니다. 즉, 해당 서비스가 의존성 주입 체인을 통해 제공되지 않으면, 컴포넌트는
아무것도 내보낼 수 없습니다.
Angular의 DI를 다시 확인하고 싶다면 [공식 가이드](https://angular.io/guide/dependency-injection)를 보십시오. 다음은 애플리케이션에서 모든 내보내기 서비스를 활성화하는 방법을 보여 주는 샘플 코드 조각입니다.

```typescript
// app.module.ts
import { IgxExcelExporterService, IgxCsvExporterService, IgxPdfExporterService } from 'igniteui-angular/grids/core';
// import { IgxExcelExporterService, IgxCsvExporterService, IgxPdfExporterService } from '@infragistics/igniteui-angular/grids/core'; for licensed package

@NgModule({
    ...
    providers: [IgxExcelExporterService, IgxCsvExporterService, IgxPdfExporterService ]
})
export class AppModule { ... }
```

<DocsAside type="info">
v12.2.1 이후에는 내보내기 서비스가 root에 제공되므로, 더 이상 AppModule providers에 선언할 필요가 없습니다.
</DocsAside>

도구 모음 내보내기 컴포넌트는 UI와 내보내기 경험을 모두 사용자 지정하기 위한 여러 입력 속성을 노출합니다.
표시 텍스트를 바꾸는 것부터 드롭다운의 옵션을 활성화하거나 비활성화하고, 생성되는 파일의 이름을 사용자 지정하는 것까지 다양합니다. 전체 참조는 도구 모음 내보내기 컴포넌트의 <ApiLink type="GridToolbarExporter" label="API 문서" />을(를) 확인하십시오.

Angular 템플릿으로 사용자 지정할 수 있는 몇 가지 옵션을 보여 주는 코드 조각은 다음과 같습니다:

```html
<igx-grid-toolbar>
    <igx-grid-toolbar-actions>
        <igx-grid-toolbar-exporter
            <!-- If active, enables the CSV export entry in the dropdown UI -->
            [exportCSV]="csvExportEnabled"
            <!-- If active, enables the excel export entry in the dropdown UI -->
            [exportExcel]="excelExportEnabled"
            <!-- If active, enables the PDF export entry in the dropdown UI -->
            [exportPDF]="pdfExportEnabled"
            <!-- The name of the generated export file without the file extension -->
            filename="exported_data"
        >
            Custom text for the exporter button
            <span excelText>Custom text for the excel export entry</span>
            <span csvText>Custom text for the CSV export entry</span>
            <span pdfText>Custom text for the PDF export entry</span>
        </igx-grid-toolbar-exporter>
    </igx-grid-toolbar-actions>
</igx-grid-toolbar>
```

내보낸 파일 이름을 바꾸는 것 외에도, 사용자는 <ApiLink type="PivotGrid" member="toolbarExporting" label="toolbarExporting" /> 이벤트를 기다리고 이벤트 속성의 options 항목을 사용자 지정하여 내보내기 옵션을 더 구성할 수 있습니다.

<DocsAside type="info">
기본적으로 CSV로 내보낼 때 내보내기는 쉼표 구분자를 사용하고 출력 파일에 '.csv' 확장자를 사용합니다.
내보내기의 이벤트를 구독하거나 내보내기 옵션 필드의 값을 바꾸어 이 내보내기 매개변수를 사용자 지정할 수 있습니다.
이벤트 인수의 cancel 필드를 true로 설정하여 내보내기 과정을 취소할 수도 있습니다.
</DocsAside>

다음 코드 조각은 도구 모음 내보내기 이벤트를 구독하고 내보내기 옵션을 구성하는 방법을 보여 줍니다:

```html
<igx-pivot-grid (toolbarExporting)="configureExport($event)" ></igx-pivot-grid>
```

```typescript
configureExport(args: IGridToolbarExportEventArgs) {
    const options: IgxExporterOptionsBase = args.options;
    
    options.fileName = `Report_${new Date().toDateString()}`;

    if (options instanceof IgxExcelExporterOptions) {
        options.columnWidth = 10;
    } else {
        options.fileType = CsvFileTypes.TSV;
        options.valueDelimiter = '\t';
    }

    args.exporter.columnExporting.subscribe((columnArgs: IColumnExportingEventArgs) => {
        
        
    });
}
```

## 내보내기 표시기

기본 도구 모음 내보내기 컴포넌트를 사용할 때는 내보내기 작업이 일어날 때마다, 작업이 진행되는 동안 도구 모음에 진행 표시기가 표시됩니다.

## 사용자 지정 콘텐츠

<DocsAside type="info">
이것은 이전의 도구 모음 템플릿 디렉티브를 대체합니다. v11 이전 버전에서 마이그레이션하는 경우 우리 마이그레이션 도구가
템플릿 콘텐츠를 옮기는 작업을 처리합니다. 하지만 템플릿 안의 바인딩은 처리하지 않으므로, 마이그레이션이 끝난 후 수정된 템플릿 파일을 꼭 다시 확인하십시오.
</DocsAside>

도구 모음 컴포넌트의 작업 부분이 특정 사용 사례에 충분하지 않으면, 도구 모음 자체에 일반 콘텐츠 프로젝션이 있어 사용자가 추가 UI를 제공할 수 있습니다. 사용자가 API 호출이나 바인딩을 위해 해당 그리드 인스턴스가 필요하다면, 템플릿 참조 변수를 만들 수 있습니다.

다음은 샘플 코드 조각입니다:

```html
<igx-pivot-grid #gridRef ...>

    ...
    <igx-grid-toolbar>
        <igx-grid-toolbar-title>{{ titleBinding }}</igx-grid-toolbar-title>

        <!--
            Everything between the toolbar tags except the default toolbar components/directives
            will be projected as custom content.
         -->
        <button igxButton="flat" igxRipple (click)="#gridRef.clearSort()">
            <igx-icon fontSet="material">clear</igx-icon>
            Clear Sort
        </button>

        <igx-grid-toolbar-actions>
            ...
        </igx-grid-toolbar-actions>
    </igx-grid-toolbar>

</igx-pivot-grid>
```

## 스타일링

도구 모음의 스타일을 지정하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 index 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

다음으로 <ApiLink kind="sass" module="themes" type="function-grid-toolbar-theme" label="grid-toolbar-theme" code={true} />을(를) 확장하는 새 테마를 만듭니다.

```scss
$accent: #ffcd0f;

$grid-toolbar-theme: grid-toolbar-theme(
  $background: #170237,
  $border-color: $accent,
  $title-text-color: #f6d8d8,
  $item-hover-background: rgb(246 216 216 / 0.3),
);
```

마지막 단계는 새로 만든 테마를 **포함**하는 것입니다.

```scss
:host {
  igx-grid-toolbar {
    @include tokens($grid-toolbar-theme);
  }
}
```

<DocsAside type="info">
일부 컴포넌트 템플릿에서는 Emulated View Encapsulation 때문에 생성된 토큰 선언이 중첩된 Ignite UI 요소에 도달하지 못할 수 있습니다. 테마가 적용되지 않으면 아래와 같이 `::ng-deep`을(를) 사용하거나 테마를 전역 스타일시트로 옮기십시오.
</DocsAside>

```scss
:host ::ng-deep {
  igx-grid-toolbar {
    @include tokens($grid-toolbar-theme);
  }
}
```
