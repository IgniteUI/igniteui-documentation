# Angular 다중 행 레이아웃

다중 행 레이아웃은 `igxGridComponent`의 렌더링 기능을 확장합니다. 이 기능을 사용하면 하나의 데이터 레코드를 여러 개의 보이는 행으로 나눌 수 있습니다.

## Angular 다중 행 레이아웃 예제

<Sample src="/grid/grid-multi-row-layout" height={755} alt="Angular 다중 행 레이아웃 예제" />

다중 행 레이아웃의 선언은 <ApiLink type="ColumnLayout" label="igx-column-layout" /> 컴포넌트를 통해 이루어집니다. 각 `igx-column-layout` 컴포넌트는 하나 이상의 `igx-column` 컴포넌트를 포함하는 블록으로 간주해야 합니다. 일부 그리드 기능은 블록 수준에서 작동합니다(아래 "기능 통합" 섹션에 나열됨). 예를 들어 가상화는 블록을 사용하여 가상 청크를 결정하므로, 레이아웃이 허용한다면 성능을 위해 열을 더 많은 `igx-column-layout` 블록으로 나누십시오. 다중 행 레이아웃을 구성할 때는 이 블록 바깥에 열이 있어서는 안 되며 `IgxColumnGroupComponent`을(를) 사용해서도 안 됩니다. 다중 행 레이아웃은 [그리드 레이아웃 명세](https://www.w3.org/TR/css-grid-1/) 위에 구현되며, 그 요구 사항을 따라야 합니다.

`IgxColumnComponent`은(는) 각 셀의 위치와 범위를 결정하는 네 가지 `@Input` 속성을 노출합니다:

- <ApiLink type="Column" member="colStart" label="colStart" /> - 필드가 시작되는 열 인덱스입니다. 이 속성은 **필수**입니다.
- <ApiLink type="Column" member="rowStart" label="rowStart" /> - 필드가 시작되는 행 인덱스입니다. 이 속성은 **필수**입니다.
- <ApiLink type="Column" member="colEnd" label="colEnd" /> - 현재 필드가 끝나야 하는 열 인덱스입니다. colStart와 colEnd 사이의 열 개수가 그 필드가 걸치는 열의 개수를 결정합니다. 이 속성은 **선택 사항**입니다. 설정하지 않으면 기본값은 `colStart + 1`입니다.
- <ApiLink type="Column" member="rowEnd" label="rowEnd" /> - 현재 필드가 끝나야 하는 행 인덱스입니다. rowStart와 rowEnd 사이의 행 개수가 그 필드가 걸치는 행의 개수를 결정합니다. 이 속성은 **선택 사항**입니다. 설정하지 않으면 기본값은 `rowStart + 1`입니다.

```html
<igx-column-layout>
 <igx-column [rowStart]="1" [colStart]="1" [rowEnd]="3" field="ID"></igx-column>
</igx-column-layout>
<igx-column-layout>
 <igx-column [rowStart]="1" [colStart]="1" [colEnd]="3" field="CompanyName"></igx-column>
 <igx-column [rowStart]="2" [colStart]="1" [colEnd]="2" field="ContactName"></igx-column>
 <igx-column [rowStart]="2" [colStart]="2" [colEnd]="3" field="ContactTitle"></igx-column>
</igx-column-layout>
<igx-column-layout>
 <igx-column [rowStart]="1" [colStart]="1" [colEnd]="3" field="Country"></igx-column>
 <igx-column [rowStart]="1" [colStart]="3" [colEnd]="5" field="Region"></igx-column>
 <igx-column [rowStart]="1" [colStart]="5" [colEnd]="7" field="PostalCode"></igx-column>
 <igx-column [rowStart]="2" [colStart]="1" [colEnd]="4" field="City"></igx-column>
 <igx-column [rowStart]="2" [colStart]="4" [colEnd]="7" field="Address"></igx-column>
</igx-column-layout>
<igx-column-layout>
    <igx-column [rowStart]="1" [colStart]="1" field="Phone"></igx-column>
    <igx-column [rowStart]="2" [colStart]="1" field="Fax"></igx-column>
</igx-column-layout>
```

<DocsAside type="info">

</DocsAside>

## 기능 통합

다중 행 레이아웃의 완전히 다른 렌더링 방식 때문에, 일부 열 기능은 `igx-column-layout` 컴포넌트에서만 작동합니다. 그런 기능으로는 열 고정과 열 숨기기가 있습니다. 정렬과 그룹화 같은 다른 기능은 `igx-column` 컴포넌트에서 같은 방식으로 작동합니다.

- 필터링 - Excel 스타일 필터링만 지원됩니다. `filterMode`을(를) 명시적으로 `FilterMode.quickFilter`(으)로 설정해도 효과가 없습니다.
- 페이징 - 시각적 행이 아니라 레코드를 기준으로 작동합니다.
- Group By - 다중 행 레이아웃에서는 `hideGroupedColumns` 옵션이 효과가 없습니다. 그룹화된 열은 항상 보입니다.

다음 기능은 현재 **지원되지 않습니다**:

- 열 이동
- 다중 열 머리글
- Excel로 내보내기
- 요약

## 키보드 탐색

다중 행 레이아웃이 있는 IgxGridComponent는 기본 제공 키보드 탐색을 제공합니다.

### 가로 탐색

- <kbd>Arrow Left</kbd> 또는 <kbd>Arrow Right</kbd> - 정의된 열 레이아웃과 관계없이, 현재 행 안에서 왼쪽/오른쪽의 인접한 셀로 이동합니다. 현재 셀이 여러 행에 걸쳐 있다면, <kbd>Arrow Left</kbd>과 <kbd>Arrow Right</kbd>은 다른 인접 셀로 이미 이동하지 않은 한, 같은 `rowStart`를 가진 가장 가까운 왼쪽과 오른쪽 첫 번째 셀로 이동해야 합니다. 탐색은 시작 탐색 셀을 저장하고, 가능하면 같은 `rowStart`를 가진 셀로 이동합니다.
- <kbd>Ctrl</kbd> + <kbd>Arrow Left</kbd>(<kbd>HOME</kbd>) 또는 <kbd>Ctrl</kbd> + <kbd>Arrow Right</kbd>(<kbd>END</kbd>) - 행의 시작 또는 끝으로 이동하고, 시작 탐색 셀에 맞춰 셀을 선택합니다.

### 세로 탐색

- <kbd>Arrow Up</kbd> 또는 <kbd>Arrow Down</kbd> - 시작 위치를 기준으로 위/아래 셀로 이동하며, 행의 영향을 받지 않습니다. 현재 셀이 여러 열에 걸쳐 있다면, 시작 탐색 셀에 맞춰 다음 활성 셀이 선택됩니다.
- <kbd>Ctrl</kbd> + <kbd>Arrow Up</kbd> 또는 <kbd>Ctrl</kbd> + <kbd>아래</kbd> - 같은 열에서 첫 번째 행 또는 마지막 행으로 이동하고 포커스를 적용합니다.
- <kbd>Ctrl</kbd> + <kbd>Home</kbd> 또는 <kbd>Ctrl</kbd> + <kbd>End</kbd> - 첫 번째 행으로 이동하여 첫 번째 셀에 포커스를 두거나, 마지막 행으로 이동하여 마지막 셀에 포커스를 둡니다.

<DocsAside type="info">
여러 행 또는 열에 걸쳐 있는 셀 사이의 탐색은 시작 탐색 셀을 기준으로 이루어지며, 반대 방향의 키를 사용하여 시작 셀로 되돌아갈 수 있습니다. 그룹 행을 탐색할 때도 같은 방식을 사용합니다.
</DocsAside>

<DocsAside type="info">
선택과 다중 셀 선택은 레이아웃을 기준으로 작동합니다. 즉, 셀이 활성화되면 그 레이아웃이 선택됩니다. 또한 드래그 선택 같은 다중 선택의 모든 기능이 적용되며, 셀 단위가 아니라 레이아웃 단위로 작동합니다.
</DocsAside>

### 사용자 지정 키보드 탐색

그리드는 특정 키를 누를 때의 기본 탐색 동작을 사용자 지정할 수 있게 합니다. `going to the next cell` 또는 `cell below` 같은 동작은 강력한 키보드 탐색 API로 쉽게 처리할 수 있습니다:

- <ApiLink type="Grid" member="gridKeydown" label="gridKeydown" />이(가) 노출됩니다. 이 이벤트는 <ApiLink type="IGridKeydownEventArgs" kind="interface" />을(를) 발생시킵니다. 이 이벤트는 위에 언급한 키보드 키 조합을 통해서만 사용할 수 있으며, 다른 모든 키 동작에는 `keydown` 이벤트 `(keydown)="onKeydown($event)"`를 사용할 수 있습니다
- <ApiLink type="Grid" member="navigateTo" label="navigateTo" /> - 이 메서드는 제공된 `rowindex`와 `visibleColumnIndex`을 기준으로 위치로 이동할 수 있게 합니다

아래 데모는 Excel에서 관찰되는 동작과 비슷하게, <kbd>Enter</kbd> 및 <kbd>Shift</kbd> + <kbd>Enter</kbd> 키로 아래/위 탐색을 추가합니다.

## 레이아웃 구성기

열 레이아웃을 구성할 때는 적절한 <ApiLink type="Column" member="colStart" label="colStart" /> 및 <ApiLink type="Column" member="colEnd" label="colEnd" /> 또는 <ApiLink type="Column" member="rowStart" label="rowStart" /> 및 <ApiLink type="Column" member="rowEnd" label="rowEnd" />를 계산하고 설정하기가 어려울 수 있습니다. 특히 한 레이아웃에 열이 많을 때 그렇습니다. 그래서 이를 쉽게 할 수 있도록, 그리고 적용되었을 때 igxGrid 안에서 어떻게 보일지 비슷하게 미리 볼 수 있도록 작은 구성기를 만들었습니다. 이 구성기에서 다음과 같은 상호 작용을 할 수 있습니다:

- 전체 구성의 행 개수를 설정합니다. 모든 레이아웃은 같은 행 개수를 가져야 합니다.
- `Add Layout` 칩을 클릭하여 열 레이아웃을 추가/제거하거나, 레이아웃 칩을 좌우로 끌어서 순서를 바꿉니다.
- 열 수와 각 열의 너비처럼 레이아웃별로 특정 설정을 지정합니다. 이 설정은 현재 선택된 레이아웃을 가리킵니다.
- 레이아웃 미리 보기에서 열 셀의 크기를 조정하여 더 많은 열/행에 걸치게 하거나, `Delete` 버튼을 사용해 지웁니다.
- 원하는 위치로 열 칩을 끌어서 미리 보기에서 열을 설정합니다.
- `Add Column` 칩을 사용하여 새 열을 추가/제거합니다.
- 전체 구성의 템플릿 출력을 igxGrid 안에 배치할 준비가 된 상태로 얻거나, 예를 들어 [`NgForOf`](https://angular.io/api/common/NgForOf)을(를) 사용하여 템플릿에서 파싱하여 쓸 수 있는 JSON 표현을 얻을 수 있습니다.

기본적으로 이전 샘플과 같은 열을 설정해 두었지만, 지워서 원하는 구성에 맞게 설정할 수 있습니다.

## 스타일링

igxGrid는 [`Ignite UI for Angular Theme Library`](/themes/sass/component-themes)을(를) 통한 스타일 지정을 허용합니다. <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />은(는) 그리드의 모든 기능을 사용자 지정할 수 있게 하는 매우 다양한 속성을 노출합니다.

아래 단계에서는 그리드의 다중 행 레이아웃 스타일을 사용자 지정하는 과정을 살펴보겠습니다.

### 전역 테마 가져오기

다중 행 레이아웃 기능의 사용자 지정을 시작하려면 모든 스타일 함수와 믹스인이 있는 `index` 파일을 가져와야 합니다.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### 사용자 지정 테마 정의하기

다음으로, <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />을(를) 확장하고 기능 레이아웃을 원하는 대로 사용자 지정하는 데 필요한 매개변수를 받는 새 테마를 만듭니다.

```scss
$custom-theme: grid-theme(
  $cell-active-border-color: #ffcd0f,
  $cell-selected-background: #6f6f6f,
  $cell-selected-text-color: #ffcd0f,
  $row-hover-background: #fde069,
  $row-selected-background: #8d8d8d,
  $header-background: #494949,
  $header-text-color: #fff,
  $sorted-header-icon-color: #ffcd0f,
  $sortable-header-icon-hover-color: #e9bd0d
);
```

<DocsAside type="info">
방금 한 것처럼 색상 값을 직접 하드코딩하는 대신, <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> 및 <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} /> 함수를 사용하면 색상을 훨씬 유연하게 다룰 수 있습니다. 사용 방법에 대한 자세한 안내는 [`Palettes`](/themes/sass/palettes) 항목을 참조하십시오.
</DocsAside>

### 사용자 지정 테마 적용하기

테마를 적용하는 가장 쉬운 방법은 전역 스타일 파일에 `sass` `@include` 문을 추가하는 것입니다:  

```scss
:host {
  @include tokens($custom-theme);
}
```

사용자 지정 테마가 특정 컴포넌트에만 영향을 주도록 하려면, 방금 정의한 모든 스타일을 전역 스타일 파일에서 사용자 지정 컴포넌트의 스타일 파일로 옮기십시오(`index` 파일의 가져오기도 포함).

이렇게 하면 Angular의 [ViewEncapsulation](https://angular.io/api/core/Component#encapsulation) 덕분에 스타일이 사용자 지정 컴포넌트에만 적용됩니다.
