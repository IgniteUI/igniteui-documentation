# Angular Pivot Grid 일괄 편집 및 트랜잭션

다음은 Pivot Grid 컴포넌트에서 일괄 편집을 활성화하는 방법에 대한 자세한 예제입니다.

## Angular Pivot Grid 일괄 편집 및 트랜잭션 예제

다음 샘플은 pivotGrid에 <ApiLink type="PivotGrid" member="batchEditing" label="batchEditing" />가 활성화되어 있고 행 편집도 활성화된 시나리오를 보여 줍니다. 후자는 행 편집 전체가 확정된 후에 트랜잭션이 추가되도록 보장합니다.

<DocsAside type="info">
트랜잭션 상태는 업데이트, 추가, 삭제된 모든 행과 그 마지막 상태로 구성됩니다.
</DocsAside>

## 사용법

시작하려면 **app.module.ts** 파일에서 `IgxPivotGridModule`을(를) 가져오십시오:

```typescript
// app.module.ts

...
import { IgxPivotGridModule } from 'igniteui-angular';

@NgModule({
    ...
    imports: [..., IgxPivotGridModule],
    ...
})
export class AppModule {}
```

그런 다음 Pivot Grid에서 `batchEditing`을(를) 활성화하기만 하면 됩니다:

```html
<igx-pivot-grid [data]="data" [batchEditing]="true">
  ...
</igx-pivot-grid>
```

이렇게 하면 igx-pivot-grid에 대해 올바른 `Transaction` 서비스 인스턴스가 제공됩니다. 올바른 `TransactionService`은(는) `TransactionFactory`을(를) 통해 제공됩니다. 이 내부 구현에 대해서는 [트랜잭션 주제](/transaction-classes#transaction-factory)에서 더 자세히 알아볼 수 있습니다.

일괄 편집이 활성화된 후에는 바인딩된 데이터 소스와 <ApiLink type="PivotGrid" member="rowEditable" label="rowEditable" />를 true로 설정하여 `IgxPivotGrid`을(를) 정의하고 바인딩하십시오:

<DocsAside type="info">
트랜잭션 API는 편집 종료를 처리하지 않으므로, 직접 처리해야 합니다. 그렇지 않으면 `Pivot Grid`이(가) 편집 모드에 머무르게 됩니다. 한 가지 방법은 해당 메서드에서 <ApiLink type="Grid" member="endEdit" label="endEdit" />을(를) 호출하는 것입니다.
</DocsAside>

<DocsAside type="info">
<ApiLink type="PivotGrid" member="rowEditable" label="rowEditable" /> 속성을 비활성화하면 `Pivot Grid`이(가) 변경되어 셀 변경 시 트랜잭션을 만들며, UI에 행 편집 오버레이는 표시되지 않습니다.
</DocsAside>
