# Angular 셀 선택

선택 기능은 Material UI 기반 Hierarchical Grid에서 풍부한 데이터 선택 기능을 제공합니다. 강력한 API와 사용하기 쉬운 메서드 덕분에 다양한 이벤트와 단일 선택 작업을 사용할 수 있습니다. Hierarchical Grid은(는) 이제 셀 선택을 위한 세 가지 모드를 지원하며, <ApiLink type="Grid" member="cellSelection" label="cellSelection" /> 속성을 바꾸면 이들 사이를 쉽게 전환할 수 있습니다. 셀 선택을 비활성화할 수도 있고, _그리드 안에서 하나의 셀만 선택_하거나 _그리드 안에서 여러 셀을 선택_할 수 있습니다. 후자가 기본 옵션입니다.

 Hierarchical Grid에서는 그리드 수준에서 셀 선택 모드를 지정할 수 있습니다. 예를 들어 상위 그리드에서는 다중 셀 선택을 활성화하고, 하위 그리드에서는 셀 선택 모드를 단일 또는 비활성화로 설정할 수 있습니다. 하지만 이 각 옵션을 더 깊이 살펴보겠습니다.

## 선택 유형

### Hierarchical Grid 다중 셀 선택

이는 상위 그리드와 하위 그리드 모두에서 기본 셀 선택 모드입니다. 한 번에 하나의 그리드에서만 셀 선택을 할 수 있다는 점을 기억하십시오. 그리드 간 범위 선택이나 여러 그리드에 걸친 선택 셀은 할 수 없습니다. 범위 선택과 마우스 드래그 기능과 관련된 각 키 조합은 같은 그리드 안에서만 사용할 수 있습니다.

셀을 선택하는 방법:

- `Mouse drag`(으)로 - 셀의 직사각형 데이터 선택이 수행됩니다.
- `Ctrl key` 키를 누른 상태에서 `Mouse drag` - 여러 범위 선택이 수행됩니다. 기존의 다른 셀 선택은 유지됩니다.
- Shift 키를 사용한 즉시 다중 셀 선택. 셀 하나를 선택한 다음 Shift 키를 누른 상태에서 다른 셀 하나를 선택합니다. 두 셀 사이의 셀 범위가 선택됩니다. `Shift key`을(를) 누른 상태에서 두 번째 셀을 다시 선택하면, 셀 선택 범위는 처음 선택한 셀의 위치(시작점)를 기준으로 업데이트된다는 점을 기억하십시오.
- `Shift key`을(를) 누른 상태에서 `Arrow keys`을(를) 사용한 키보드 다중 셀 선택. 포커스된 셀을 기준으로 다중 셀 선택 범위가 만들어집니다.
- `Shift key`을(를) 누른 상태에서 `Ctrl + Arrow keys` 및 `Ctrl + Home/End`을(를) 사용한 키보드 다중 셀 선택. 포커스된 셀을 기준으로 다중 셀 선택 범위가 만들어집니다.
- `Ctrl key`을(를) 누른 상태에서 `Left Mouse key`로 클릭하면 단일 셀 범위가 선택된 셀 모음에 추가됩니다.
- 마우스로 클릭한 채 끌면 연속된 다중 셀 선택이 가능합니다.

### Hierarchical Grid 단일 선택

`[cellSelection]="'single'"`을(를) 설정하면 그리드에서 한 번에 선택된 셀을 하나만 가질 수 있습니다. 또한 `mouse drag` 모드는 작동하지 않으며, 셀을 선택하는 대신 기본 텍스트 선택이 이루어집니다.

<DocsAside type="info">
단일 셀이 선택되면 `selection mode`이(가) `single`이든 `multiple`이든 상관없이 <ApiLink type="Grid" member="selected" label="selected" /> 이벤트가 발생합니다. 다중 셀 선택 모드에서 셀 범위를 선택하면 <ApiLink type="Grid" member="rangeSelected" label="rangeSelected" /> 이벤트가 발생합니다.
</DocsAside>

### Hierarchical Grid 선택 없음

셀 선택을 비활성화하려면 `[cellSelection]="'none'"` 속성을 설정하기만 하면 됩니다. 이 모드에서는 셀을 클릭하거나 키보드로 탐색하려고 해도 셀이 **선택되지 않으며**, `activation style`만 적용되고 페이지의 다른 요소를 스크롤하거나 클릭하면 사라집니다. 선택을 정의하는 유일한 방법은 아래에 설명된 API 메서드를 사용하는 것입니다.

## 스타일링

테마 엔진은 **선택된 셀 범위**의 스타일을 지정할 수 있는 속성을 노출합니다.

### 테마 가져오기

선택 영역의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### 색상 정의하기

가져오기가 끝나면 <ApiLink kind="sass" module="palettes" type="function-contrast-color" label="contrast-color" code={true} />과(와) <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} /> 함수를 사용할 수 있습니다. 이들을 사용하여 선택 범위에 사용할 색상을 정의합니다:

```scss
$text-color: contrast-color($color: 'primary', $variant: 900);
$background-color: color($color: "primary", $variant: 900);
$border-yellow: #f2c43c;
```

<DocsAside type="info">
`contrast-color`과(와) `color` 함수를 사용하고 싶지 않다면 언제든 색상 값을 하드코딩할 수 있습니다.
</DocsAside>

### 사용자 지정 테마 만들기

다음으로 <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />을(를) 확장하는 새 테마를 만듭니다. 우리의 `text-color`, `background-color` 및 `border-yellow` 변수를 각각 `$cell-selected-text-color`, `$cell-selected-background` 및 `$cell-active-border-color`로 전달합니다:

```scss
$custom-grid-theme: grid-theme(
  $cell-selected-text-color: $text-color,
  $cell-active-border-color: $border-yellow,
  $cell-selected-background: $background-color
);
```

### 테마 적용하기

그다음 해야 할 일은 컴포넌트의 스타일(앱 스타일에 있어도 됨)에 믹스인을 포함하는 것뿐입니다. 그래야 우리의 igx-hierarchical-grid이 기본 테마 대신 새로 만든 테마를 사용합니다:

```scss
:host {
  @include tokens($custom-grid-theme);
}
```

사용자 지정 테마를 적용하면 선택된 그리드 셀이 우리가 선택한 색상으로 강조 표시됩니다:
