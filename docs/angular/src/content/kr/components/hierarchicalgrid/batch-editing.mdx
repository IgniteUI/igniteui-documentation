# Angular Hierarchical Grid 일괄 편집 및 트랜잭션

IgxHierarchicalGrid의 일괄 편집 기능은 <ApiLink type="TransactionService" />를 기반으로 합니다. `igxTransactionService`의 개요와 그 구현 세부 사항은 [`Transaction Service class hierarchy`](../transaction-classes.mdx) 주제를 따라 확인하십시오.

<ApiLink kind="interface" type="HierarchicalTransactionService" />을(를) <ApiLink type="HierarchicalGrid" label="IgxHierarchicalGrid" />와 함께 사용하되 각 island마다 별도의 트랜잭션 로그를 누적하려면, 대신 서비스 팩토리를 제공해야 합니다. 하나가 내보내져 있으며 <ApiLink kind="interface" type="HierarchicalTransactionService" />(으)로 바로 사용할 수 있습니다.

다음은 Hierarchical Grid 컴포넌트에서 일괄 편집을 활성화하는 방법에 대한 자세한 예제입니다.

## Angular Hierarchical Grid 일괄 편집 및 트랜잭션 예제

다음 샘플은 hierarchicalGrid에 <ApiLink type="HierarchicalGrid" member="batchEditing" label="batchEditing" />가 활성화되어 있고 행 편집도 활성화된 시나리오를 보여 줍니다. 후자는 행 편집 전체가 확정된 후에 트랜잭션이 추가되도록 보장합니다.

<DocsAside type="info">
트랜잭션 상태는 업데이트, 추가, 삭제된 모든 행과 그 마지막 상태로 구성됩니다.
</DocsAside>

## 사용법

시작하려면 **app.module.ts** 파일에서 `IgxHierarchicalGridModule`을(를) 가져오십시오:

```typescript
// app.module.ts

...
import { IgxHierarchicalGridModule } from 'igniteui-angular';

@NgModule({
    ...
    imports: [..., IgxHierarchicalGridModule],
    ...
})
export class AppModule {}
```

그런 다음 Hierarchical Grid에서 `batchEditing`을(를) 활성화하기만 하면 됩니다:

```html
<igx-hierarchical-grid [data]="data" [batchEditing]="true">
  ...
</igx-hierarchical-grid>
```

이렇게 하면 igx-hierarchical-grid에 대해 올바른 `Transaction` 서비스 인스턴스가 제공됩니다. 올바른 `TransactionService`은(는) `TransactionFactory`을(를) 통해 제공됩니다. 이 내부 구현에 대해서는 [트랜잭션 주제](/transaction-classes#transaction-factory)에서 더 자세히 알아볼 수 있습니다.

일괄 편집이 활성화된 후에는 바인딩된 데이터 소스와 <ApiLink type="HierarchicalGrid" member="rowEditable" label="rowEditable" />를 true로 설정하여 `IgxHierarchicalGrid`을(를) 정의하고 바인딩하십시오:

```html
<igx-hierarchical-grid #hierarchicalGrid [batchEditing]="true" [data]="data" [primaryKey]="'Artist'"
    [height]="'580px'" [width]="'100%'" [rowEditable]="true" >
    ...
    <igx-row-island #childGrid [key]="'Albums'" [primaryKey]="'Album'" [rowEditable]="true">
        <igx-grid-toolbar></igx-grid-toolbar>
        ...
        <ng-template igxToolbarCustomContent let-grid="grid">
            <button igxButton [disabled]="!grid.transactions.canUndo" (click)="undo(grid)">Undo</button>
            <button igxButton [disabled]="!grid.transactions.canRedo" (click)="redo(grid)">Redo</button>
        </ng-template>
    </igx-row-island>
</igx-hierarchical-grid>
...
<div class="buttons-row">
    <div class="buttons-wrapper">
        <button igxButton [disabled]="!undoEnabledParent" (click)="undo(hierarchicalGrid)">Undo Parent</button>
        <button igxButton [disabled]="!redoEnabledParent" (click)="redo(hierarchicalGrid)">Redo Parent</button>
    </div>
</div>
...

```

다음 코드는 <ApiLink type="GridComponent" member="transactions" /> API - 실행 취소, 다시 실행, 커밋 - 의 사용법을 보여 줍니다.

```typescript
...
export class HierarchicalGridBatchEditingSampleComponent {
    public undo(grid: any) {
        /* exit edit mode and commit changes */
        grid.endEdit(true);
        grid.transactions.undo();
    }

    public redo(grid: any) {
        /* exit edit mode and commit changes */
        grid.endEdit(true);
        grid.transactions.redo();
    }

    public commit() {
        this.hierarchicalGrid.transactions.commit(this.data);
        this.childGrid.hgridAPI.getChildGrids().forEach((grid) => {
            grid.transactions.commit(grid.data);
        });
        this.dialogChanges.close();
    }
}
```

<DocsAside type="info">
트랜잭션 API는 편집 종료를 처리하지 않으므로, 직접 처리해야 합니다. 그렇지 않으면 `Hierarchical Grid`이(가) 편집 모드에 머무르게 됩니다. 한 가지 방법은 해당 메서드에서 <ApiLink type="Grid" member="endEdit" label="endEdit" />을(를) 호출하는 것입니다.
</DocsAside>

<DocsAside type="info">
<ApiLink type="HierarchicalGrid" member="rowEditable" label="rowEditable" /> 속성을 비활성화하면 `Hierarchical Grid`이(가) 변경되어 셀 변경 시 트랜잭션을 만들며, UI에 행 편집 오버레이는 표시되지 않습니다.
</DocsAside>
