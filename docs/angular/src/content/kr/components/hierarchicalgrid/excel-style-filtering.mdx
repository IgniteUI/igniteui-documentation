# Angular Hierarchical Grid의 Excel 필터링

그리드 Excel 필터링은 Hierarchical Grid과 같은 모든 Angular 테이블에 Excel과 같은 필터링 UI를 제공합니다.

## Angular Hierarchical Grid Excel 스타일 필터링 예제

<Sample src="/hierarchical-grid/hierarchical-grid-excel-style-filtering-sample-1" height={950} alt="Angular Hierarchical Grid Excel 스타일 필터링 예제" />

## 사용법

그리드 Excel 필터링을 켜려면 두 입력을 설정해야 합니다. <ApiLink type="HierarchicalGrid" member="allowFiltering" label="allowFiltering" />은(는) `true`(으)로, <ApiLink type="HierarchicalGrid" member="filterMode" label="filterMode" />은(는) `excelStyleFilter`(으)로 설정해야 합니다.

```html
<igx-hierarchical-grid [data]="data" [autoGenerate]="true" [allowFiltering]="true" [filterMode]="'excelStyleFilter'">
</igx-hierarchical-grid>
```

## 상호 작용

특정 열의 필터 메뉴를 열려면 머리글의 Angular 필터 아이콘을 클릭해야 합니다. 또한 선택한 머리글에서 `Ctrl + Shift + L` 조합을 사용할 수도 있습니다. 열이 필터링 기능과 함께 정렬, 고정, 이동, 선택 또는 숨기기가 가능하다면, 활성화된 기능에 대한 버튼이 사용 가능하게 됩니다.

필터가 적용되지 않은 경우, 목록의 모든 항목이 선택되어 있습니다. 목록 위의 입력에서 항목을 필터링할 수 있습니다. 데이터를 필터링하려면 목록의 항목을 선택/선택 해제한 다음 적용 버튼을 클릭하거나 `Enter`을(를) 누르면 됩니다. 목록 항목을 통해 적용된 필터는 `equals` 연산자를 가진 필터 식을 만들며, 식 사이의 논리 연산자는 <ApiLink kind="enum" type="FilteringLogic" member="Or" />입니다.

검색 상자에 무언가를 입력하고 필터를 적용하면, 검색 조건과 일치하는 항목만 선택됩니다. 하지만 현재 필터링된 항목에 항목을 추가하고 싶다면 `Add current selection to filter` 옵션을 선택해야 합니다.

필터를 지우고 싶다면 `Select All` 옵션을 체크한 다음 적용 버튼을 클릭하면 됩니다.

다른 식으로 필터를 적용하려면 **텍스트 필터**를 클릭하면 됩니다. 그러면 해당 열에서 사용할 수 있는 모든 필터 연산자가 있는 하위 메뉴가 열립니다. 그중 하나를 선택하면 사용자 지정 필터 대화 상자가 열리며, 여기서 서로 다른 필터 및 논리 연산자로 원하는 만큼 많은 식을 추가할 수 있습니다. 필터를 지울 수 있는 지우기 버튼도 있습니다.

## 메뉴 기능 구성하기

정렬, 고정, 숨기기 기능은 해당 입력을 사용하여 필터 메뉴에서 제거할 수 있습니다: <ApiLink type="Column" member="sortable" label="sortable" />, <ApiLink type="Column" member="selected" label="selected" />, <ApiLink type="Column" member="disablePinning" label="disablePinning" />, <ApiLink type="Column" member="disableHiding" label="disableHiding" />.

```html
<igx-hierarchical-grid class="hgrid" [data]="localdata" [autoGenerate]="false" [moving]="true" [allowFiltering]='true' filterMode="excelStyleFilter"
    [height]="'650px'" [width]="'100%'" [rowHeight]="'65px'" #hierarchicalGrid>
    <igx-column field="Artist" [filterable]='true' [sortable]="true"></igx-column>
    <igx-column field="Photo" [filterable]='false'>
        <ng-template igxCell let-cell="cell">
            <div class="cell__inner_2">
                <img [src]="cell.value" class="photo" />
            </div>
        </ng-template>
    </igx-column>
    <igx-column field="Debut" [filterable]='true' [disablePinning]="true" [disableHiding]="true"></igx-column>
    <igx-column field="Grammy Nominations" [filterable]='true' [dataType]="'number'" [sortable]="false"></igx-column>
    <igx-column field="Grammy Awards" [filterable]='true' [dataType]="'number'"></igx-column>

    <igx-row-island [key]="'Albums'" [autoGenerate]="false" [allowFiltering]='true' filterMode="excelStyleFilter">
        <igx-column field="Album" [filterable]='true'></igx-column>
        <igx-column field="Launch Date" [filterable]='true' [dataType]="'date'"></igx-column>
        <igx-column field="Billboard Review" [filterable]='true' [dataType]="'number'"></igx-column>
        <igx-column field="US Billboard 200" [filterable]='true' [dataType]="'number'"></igx-column>
    <igx-row-island [key]="'Songs'" [autoGenerate]="false" >
            <igx-column field="No."></igx-column>
            <igx-column field="Title"></igx-column>
            <igx-column field="Released"></igx-column>
            <igx-column field="Genre"></igx-column>
    </igx-row-island>
    </igx-row-island>

    <igx-row-island [key]="'Tours'" [autoGenerate]="false">
        <igx-column field="Tour"></igx-column>
        <igx-column field="Started on"></igx-column>
        <igx-column field="Location"></igx-column>
        <igx-column field="Headliner"></igx-column>
    </igx-row-island>
</igx-hierarchical-grid>
```

아래 샘플에서 'Artist' 열은 세 가지 기능이 모두 활성화되어 있고, 'Debut'는 세 가지가 모두 비활성화되어 있으며, 'Grammy Nominations'에는 고정과 숨기기만 있습니다.

## 템플릿

열 기능을 비활성화하지 않고 Excel 스타일 필터 메뉴를 더 사용자 지정하려면 사용자 지정 템플릿을 사용할 수 있습니다. Excel 스타일 필터 메뉴는 템플릿화를 위한 두 가지 디렉티브를 제공합니다:

- `IgxExcelStyleColumnOperationsTemplateDirective` - 정렬, 고정 등 모든 열 작업이 있는 영역을 다시 템플릿화합니다.
- `IgxExcelStyleFilterOperationsTemplateDirective` - 모든 필터 전용 작업이 있는 영역을 다시 템플릿화합니다.

이 영역 중 하나만 다시 템플릿화하거나 둘 다 다시 템플릿화할 수 있습니다. 이 디렉티브 안에 사용자 지정 콘텐츠를 넣을 수도 있고, 우리의 내장 Excel 스타일 필터링 컴포넌트 중 어느 것이든 사용할 수도 있습니다.

다음 코드는 <ApiLink type="ExcelStyleHeader" />, <ApiLink type="ExcelStyleSorting" /> 및 <ApiLink type="ExcelStyleSearch" /> 컴포넌트를 사용하여 사용자 지정 Excel 스타일 필터 메뉴를 정의하는 방법을 보여 줍니다.

```html
<igx-hierarchical-grid class="hgrid" [data]="localdata" [autoGenerate]="false" [allowFiltering]='true' filterMode="excelStyleFilter"
    [height]="'650px'" [width]="'100%'" [rowHeight]="'65px'" #hierarchicalGrid>
    
    <igx-grid-excel-style-filtering [minHeight]="'380px'" [maxHeight]="'500px'">
        <igx-excel-style-column-operations>
            <igx-excel-style-header
                [showPinning]="true"
                [showHiding]="true"
            >
            </igx-excel-style-header>

            <igx-excel-style-sorting></igx-excel-style-sorting>
        </igx-excel-style-column-operations>

        <igx-excel-style-filter-operations>
            <igx-excel-style-search></igx-excel-style-search>
        </igx-excel-style-filter-operations>
    </igx-grid-excel-style-filtering>

    ...

    <igx-row-island [key]="'Albums'" [autoGenerate]="false" [allowFiltering]='true' filterMode="excelStyleFilter">
        <igx-grid-excel-style-filtering [minHeight]="'380px'" [maxHeight]="'500px'">
            <igx-excel-style-column-operations>
                <igx-excel-style-header
                    [showPinning]="true"
                    [showHiding]="true"
                >
                </igx-excel-style-header>

                <igx-excel-style-sorting></igx-excel-style-sorting>
            </igx-excel-style-column-operations>

            <igx-excel-style-filter-operations>
                <igx-excel-style-search></igx-excel-style-search>
            </igx-excel-style-filter-operations>
        </igx-grid-excel-style-filtering>
        ....
    </igx-row-island>
</igx-hierarchical-grid>
```

`igxExcelStyleHeaderIcon` 디렉티브를 사용하여 열 머리글의 Excel 스타일 필터링 아이콘도 다시 템플릿화할 수 있습니다:

```html
<igx-hierarchical-grid ...>
    <ng-template igxExcelStyleHeaderIcon>
        <igx-icon>filter_alt</igx-icon>
    </ng-template>
</igx-hierarchical-grid>
```

## 고유 열 값 전략

Excel 스타일 필터링 대화 상자 안의 목록 항목은 각 열의 고유 값을 나타냅니다.

이 값들은 수동으로 제공하거나 필요 시 로드할 수 있으며, 이는 [`Hierarchical Grid Remote Data Operations`](/hierarchicalgrid/remote-data-operations#고유-열-값-전략) 주제에서 보여 줍니다.

## 외부 Excel 스타일 필터링

위 데모에서 본 것처럼, Excel 스타일 필터링 대화 상자의 기본 모양은 Hierarchical Grid 안에 있습니다. 따라서 이 대화 상자는 필터를 구성할 때만 보입니다. 그 대화 상자를 항상 보이게 유지하는 방법도 있습니다. 그리드 외부에서 독립형 컴포넌트로 사용할 수 있습니다. 아래 데모에서 Excel 스타일 필터링은 Hierarchical Grid와 별도로 선언되어 있습니다.

### 사용법

Excel 스타일 필터링 컴포넌트를 구성하려면, 그 <ApiLink type="Column" label="column" /> 속성을 Hierarchical Grid의 열 중 하나로 설정해야 합니다. 위 샘플에서는 <ApiLink type="Column" label="column" /> 속성을 Hierarchical Grid의 열을 표시하는 IgxSelectComponent의 값에 바인딩했습니다.

```html
<igx-select #gridColums value="Artist">
   <label igxLabel>Columns:</label>
   <igx-select-item *ngFor="let c of hierarchicalgrid1.columns" [value]="c.field">
       {{ c.field }}
   </igx-select-item>
</igx-select>

<igx-grid-excel-style-filtering [column]="hierarchicalgrid1.getColumnByName(gridColums.value)">
</igx-grid-excel-style-filtering>
```

## 외부 아웃레트

Hierarchical Grid의 [`z-index`](https://developer.mozilla.org/en-US/docs/Web/CSS/z-index)는 DOM의 각 그리드에 대해 별도의 쌓임 맥락을 만듭니다. 이렇게 하면 그리드의 모든 하위 요소가 의도한 대로 렌더링되며, 서로 겹치지 않습니다.
하지만 그리드 바깥으로 나가는 요소(예: Excel 스타일 필터)는 같은 `z-index`를 가진 바깥 요소(예: 그리드 두 개가 위아래로 놓인 경우)와 충돌하여 잘못된 렌더링이 발생합니다. 이 문제의 해결책은 <ApiLink type="HierarchicalGrid" member="outlet" label="outlet" /> 속성을 외부 아웃레트 디렉티브로 설정하는 것입니다. 이렇게 하면 오버레이 요소가 항상 맨 위에 나타날 수 있습니다.

## 스타일링

Excel 스타일 필터링 대화 상자의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Excel 스타일 필터링 대화 상자의 스타일을 지정하는 방법은 몇 가지가 있습니다. <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />을(를) 사용하여 스타일을 지정할 수 있습니다. Excel 스타일 필터링 대화 상자는 <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />에 정의된 `$background`, `$foreground` 및 `$accent-color` 값을 상속합니다. 또한 대화 상자의 텍스트 색상을 사용자 지정하기 위한 전용 매개변수도 제공합니다.

또는 전용 <ApiLink kind="sass" module="themes" type="function-excel-filtering-theme" label="excel-filtering-theme" code={true} />을(를) 사용할 수 있으며, 이를 통해 Excel 스타일 필터링 대화 상자만 완전히 스타일링할 수 있습니다.

가장 간단한 방법은 <ApiLink kind="sass" module="themes" type="function-grid-theme" label="grid-theme" code={true} />을(를) 사용하는 것입니다:

```scss
$background: #292826;
$foreground: #eeece1;
$accent: #ffcd0f;

$custom-grid: grid-theme(
  $background: $background,
  $foreground: $foreground,
  $accent-color: $accent,
);
```

Excel 스타일 필터링 대화 상자의 배경색과 전경색은 그리드 테마에서 상속됩니다. 또한 버튼이나 체크박스 같은 모든 중첩 컴포넌트는 그리드 테마의 강조 색상을 상속합니다.

그다음 새로 만든 그리드 테마를 포함할 준비가 됩니다. Excel 스타일 필터링 대화 상자에만 해당하는 추가 스타일 변경을 원하면, 그것을 직접 대상으로 할 수 있습니다:

```scss
:host {
    @include tokens($custom-grid);

    igx-grid-excel-style-filtering {
        --ig-excel-filtering-background: #444;
    }
}
```

<DocsAside type="info">
이 샘플은 `::ng-deep`을(를) 사용하는데, 생성된 테마 선택기와 직접적인 Excel 필터링 선택기 모두 그리드의 뷰 안에 있는 요소에 도달해야 하기 때문입니다. 재정의를 전역 스타일시트로 옮기는 것도 대안입니다.
</DocsAside>

```scss
:host ::ng-deep {
    @include tokens($custom-grid);

    igx-grid-excel-style-filtering {
        --ig-excel-filtering-background: #444;
    }
}
```
