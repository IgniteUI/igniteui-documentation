# Angular Hierarchical Grid 원격 데이터 작업

Ignite UI for Angular Hierarchical Grid은(는) 원격 가상화, 원격 정렬, 원격 필터링 등 원격 데이터 작업을 지원합니다. 이를 통해 개발자는 서버에서 이러한 작업을 수행하고, 생성된 데이터를 가져와 Hierarchical Grid에 표시할 수 있습니다.

{/*TODO*/}

기본적으로 Hierarchical Grid은(는) 데이터 작업을 수행하기 위해 자체 로직을 사용합니다.
Hierarchical Grid이(가) 노출하는 특정 입력과 이벤트를 활용하여 이러한 작업을 원격으로 수행하고, 그 결과 데이터를 Hierarchical Grid에 전달할 수 있습니다.

## 고유 열 값 전략

Excel 스타일 필터링 대화 상자 안의 목록 항목은 각 열의 고유 값을 나타냅니다. Hierarchical Grid은(는) 기본적으로 데이터 소스를 기준으로 이 값들을 생성합니다. 원격 필터링의 경우, 그리드 데이터에는 서버의 모든 데이터가 들어 있지 않습니다. 고유 값을 수동으로 제공하고 필요할 때 로드하려면, Hierarchical Grid의 <ApiLink type="HierarchicalGrid" member="uniqueColumnValuesStrategy" label="uniqueColumnValuesStrategy" /> 입력을 활용할 수 있습니다. 이 입력은 실제로 세 개의 인수를 제공하는 메서드입니다:

- **column** - 해당 열 인스턴스입니다.
- **filteringExpressionsTree** - 해당 열을 기준으로 축소된 필터링 식 트리입니다.
- **done** - 서버에서 새로 생성된 열 값을 가져왔을 때 그 값과 함께 호출해야 하는 콜백입니다.

개발자는 **column** 및 **filteringExpressionsTree** 인수가 제공하는 정보를 기준으로 필요한 고유 열 값을 수동으로 생성한 다음 **done** 콜백을 호출할 수 있습니다.

<DocsAside type="info">
<ApiLink type="HierarchicalGrid" member="uniqueColumnValuesStrategy" label="uniqueColumnValuesStrategy" /> 입력이 제공되면, Excel 스타일 필터링의 기본 고유 값 생성 프로세스는 사용되지 않습니다.
</DocsAside>

```html
<igx-hierarchical-grid #hierarchicalGrid [primaryKey]="'Artist'" [data]="data" [filterMode]="'excelStyleFilter'"
                       [uniqueColumnValuesStrategy]="singersColumnValuesStrategy">
    ...
    <igx-row-island [primaryKey]="'Album'" [allowFiltering]="true" [filterMode]="'excelStyleFilter'"
                    [uniqueColumnValuesStrategy]="albumsColumnValuesStrategy">
        ...
    </igx-row-island>
</igx-hierarchical-grid>
```

```typescript
public singersColumnValuesStrategy = (column: ColumnType,
                                      columnExprTree: IFilteringExpressionsTree,
                                      done: (uniqueValues: any[]) => void) => {
// Get specific column data for the singers.
this.remoteValuesService.getColumnData(
    null, 'Singers', column, columnExprTree, uniqueValues => done(uniqueValues));
}

public albumsColumnValuesStrategy = (column: ColumnType,
                                     columnExprTree: IFilteringExpressionsTree,
                                     done: (uniqueValues: any[]) => void) => {
// Get specific column data for the albums of a specific singer.
const parentRowId = (column.grid as any).foreignKey;
this.remoteValuesService.getColumnData(
    parentRowId, 'Albums', column, columnExprTree, uniqueValues => done(uniqueValues));
}
```

## 원격 페이징

페이징 기능은 원격 데이터와 함께 작동할 수 있습니다. 이를 보여 주기 위해 먼저 데이터 가져오기를 담당할 서비스를 선언하겠습니다. 페이지 수를 계산하려면 전체 데이터 항목 수가 필요합니다. 이 로직을 서비스에 추가하겠습니다.

```typescript
@Injectable()
export class RemotePagingService {
    public remoteData: BehaviorSubject<any[]>;
    public dataLenght: BehaviorSubject<number> = new BehaviorSubject(0);
    public url = 'https://www.igniteui.com/api/products';

    constructor(private http: HttpClient) {
        this.remoteData = new BehaviorSubject([]) as any;
    }

    public getData(index?: number, perPage?: number): any {
        let qS = '';

        if (perPage) {
            qS = `?$skip=${index}&$top=${perPage}&$count=true`;
        }

        this.http
            .get(`${this.url + qS}`).pipe(
                map((data: any) => data)
            ).subscribe((data) => this.remoteData.next(data));
    }

    public getDataLength(): any {
        return this.http.get(this.url).pipe(
            map((data: any) => data.length)
        );
    }
}
```

서비스를 선언한 후에는 Hierarchical Grid 구성과 데이터 구독을 담당할 컴포넌트를 만들어야 합니다.

```typescript
export class HGridRemotePagingSampleComponent implements OnInit, AfterViewInit, OnDestroy {
    public data: BehaviorSubject<any> = new BehaviorSubject([]);
    private _dataLengthSubscriber;

    constructor(private remoteService: RemotePagingService) {}

    public ngOnInit() {
        this.data = this.remoteService.remoteData.asObservable();

        this._dataLengthSubscriber = this.remoteService.getDataLength().subscribe((data) => {
            this.totalCount = data;
            this.grid1.isLoading = false;
        });
    }

    public ngOnDestroy() {
        if (this._dataLengthSubscriber) {
            this._dataLengthSubscriber.unsubscribe();
        }
    }
}
```

이제 `igx-paginator`이(가) 제공하는 기본 페이징 템플릿을 사용하거나, 직접 _사용자 지정 페이징 템플릿_을 설정할 수 있습니다. 먼저 _기본 페이징 템플릿_을 사용하여 원격 페이징을 설정하는 데 무엇이 필요한지 살펴보겠습니다.

### 기본 템플릿을 사용하는 원격 페이징

_기본 페이징 템플릿_을 사용하려면 Paginator의 <ApiLink type="Paginator" member="totalRecords" label="totalRecords" /> 속성을 설정해야 합니다. 그래야 그리드가 원격 레코드 전체를 기준으로 _전체 페이지 수_를 계산할 수 있습니다. 원격 페이지네이션을 수행할 때 Paginator는 현재 페이지의 데이터만 그리드에 전달하므로, 그리드는 제공된 데이터 소스를 페이지로 나누려고 하지 않습니다. 따라서 그리드의 <ApiLink type="HierarchicalGrid" member="pagingMode" label="pagingMode" /> 속성을 _GridPagingMode.remote_로 설정해야 합니다. 또한 원격 서비스에서 데이터를 가져오기 위해 <ApiLink type="Paginator" member="pagingDone" label="pagingDone" /> 또는 <ApiLink type="Paginator" member="perPageChange" label="perPageChange" /> 이벤트를 구독해야 하며, 어떤 이벤트를 사용할지는 사용 사례에 따라 다릅니다.

```html
<igx-hierarchical-grid #hierarchicalGrid [primaryKey]="'CustomerID'" [pagingMode]="mode">
    <igx-column field="CustomerID"></igx-column>
    ...
    <igx-paginator [(page)]="page" [(perPage)]="perPage" [totalRecords]="totalCount"
        (pagingDone)="paginate($event.current)" (perPageChange)="getFirstPage()">
    </igx-paginator>
</igx-hierarchical-grid>
```

```typescript
public totalCount = 0;
public data: Observable<any[]>;
public mode = GridPagingMode.remote;
public isLoading = true;
@ViewChild('grid1', { static: true }) public grid1: IgxGridComponent;

private _dataLengthSubscriber;

public set perPage(val: number) {
    this._perPage = val;
    this.paginate(0);
}

public ngOnInit() {
    this.data = this.remoteService.remoteData.asObservable();

    this._dataLengthSubscriber = this.remoteService.getDataLength().subscribe((data: any) => {
        this.totalCount = data;
        this.grid1.isLoading = false;
    });
}

public ngAfterViewInit() {
    const skip = this.page * this.perPage;
    this.remoteService.getData(skip, this.perPage);
}

public paginate(page: number) {
    this.page = page;
    const skip = this.page * this.perPage;
    const top = this.perPage;

    this.remoteService.getData(skip, top);
}
```

### 사용자 지정 igx-paginator-content가 있는 원격 페이징

사용자 지정 paginator 콘텐츠를 정의할 때는, 요청된 페이지에 대한 데이터만 가져오도록 콘텐츠를 정의하고, 선택된 페이지와 항목 <ApiLink type="Paginator" member="perPage" label="perPage" />에 따라 원격 서비스에 올바른 **skip** 및 **top** 매개변수를 전달해야 합니다. 예제 구성을 쉽게 하기 위해 `<igx-paginator>`을(를) 사용하겠습니다. 그리고 소개된 <ApiLink type="PageSizeSelector" />와 <ApiLink type="PageNavigation" />도 함께 사용합니다 - `igx-page-size`은(는) 페이지당 드롭다운과 레이블을 추가하고, `igx-page-nav`은(는) 탐색 작업 버튼과 레이블을 추가합니다.

```html
<igx-paginator #paginator
    [totalRecords]="totalCount"
    [(perPage)]="perPage"
    [(page)]="page"
    [selectOptions]="selectOptions"
    (pageChange)="paginate($event)"
    (perPageChange)="perPageChange($event)">
    <igx-paginator-content>
        <igx-page-size></igx-page-size>
        [This is my custom content]
        <igx-page-nav></igx-page-nav>
    </igx-paginator-content>
</igx-paginator>
```

```typescript
@ViewChild('hierarchicalGrid', { static: true }) public hierarchicalGrid: IgxHierarchicalGridComponent;

public ngOnInit(): void {
    this._dataLengthSubscriber = this.remoteService.getDataLength(
        { parentID: null, rootLevel: true, key: 'Customers' }).subscribe((length) => {
            this.totalCount = length;
        });
}

public ngAfterViewInit() {
    this.hierarchicalGrid.isLoading = true;
    this._dataSubscriber = this.remoteService.getData({parentID: null, rootLevel: true, key: 'Customers' }, 0, this.perPage)
        .subscribe((data) => {
            this.hierarchicalGrid.isLoading = false;
            this.data.next(data);
        },(error) => {
                this.hierarchicalGrid.emptyGridMessage = error.message;
                this.hierarchicalGrid.isLoading = false;
                this.hierarchicalGrid.cdr.detectChanges();
            }
        );
}

```

원격 페이징이 올바르게 구성되려면 `GridPagingMode.Remote`을(를) 설정해야 합니다:
</DocsAside>

```html
<igx-hierarchical-grid #hierarchicalGrid [data]="data | async" [primaryKey]="'CustomerID'"
    [height]="'550px'" [width]="'100%'" [pagingMode]="mode"></igx-hierarchical-grid>
...
```

## 알려진 문제와 제한 사항

- 그리드에 `primaryKey`이(가) 설정되어 있지 않고 원격 데이터 시나리오가 활성화되어 있으면(페이징, 정렬, 필터링, 스크롤이 표시할 데이터를 가져오기 위해 원격 서버에 요청을 트리거할 때), 데이터 요청이 완료된 후 행은 다음 상태를 잃게 됩니다:
  - 행 선택
  - 행 펼치기/접기
  - 행 편집
  - 행 고정
- 원격 데이터 시나리오에서 그리드에 `primaryKey`이(가) 설정되어 있으면, 현재 데이터 뷰 밖에 있는 행에 대해 <ApiLink kind="interface" type="IRowSelectionEventArgs" member="oldSelection" /> 이벤트 인수는 행 데이터 객체 전체를 담지 않습니다. 이 경우 `rowSelectionChanging.oldSelection` 객체는 `primaryKey` 필드 하나만 가집니다. 현재 데이터 뷰에 있는 나머지 행에 대해서는 `rowSelectionChanging.oldSelection`에 행 데이터 전체가 들어 있습니다.
