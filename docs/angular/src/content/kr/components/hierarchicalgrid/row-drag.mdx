# Angular Hierarchical Grid의 행 끌기

Ignite UI for Angular Hierarchical Grid에서 **RowDrag**는 루트 `igx-hierarchical-grid` 컴포넌트에서 초기화되며, <ApiLink type="HierarchicalGrid" member="rowDraggable" label="rowDraggable" /> 입력을 통해 구성할 수 있습니다. 행 끌기를 활성화하면 사용자가 행을 끌기 시작할 수 있는 행 끌기 핸들이 제공됩니다.

## 구성

`igx-hierarchical-grid`에서 행 끌기를 활성화하려면, 그리드의 <ApiLink type="HierarchicalGrid" member="rowDraggable" label="rowDraggable" />을(를) **`true`**(으)로 설정하기만 하면 됩니다. 이것이 활성화되면 각 행에 행 끌기 핸들이 표시됩니다. 이 핸들을 사용하여 행 끌기를 시작할 수 있습니다.

```html
<igx-hierarchical-grid [rowDraggable]="true">
 ...
</igx-hierarchical-grid>
```

끌기 핸들을 클릭하고 버튼을 누른 채 _커서를 움직이면_ 그리드의 <ApiLink type="HierarchicalGrid" member="rowDragStart" label="rowDragStart" /> 이벤트가 발생합니다. 언제든 클릭을 떼면 <ApiLink type="HierarchicalGrid" member="rowDragEnd" label="rowDragEnd" /> 이벤트가 발생합니다.

아래에서 `igx-hierarchical-grid`이(가) 행 끌기를 지원하도록 구성하는 방법과 드롭 이벤트를 올바르게 처리하는 방법에 대한 단계별 안내를 찾을 수 있습니다.

이 예제에서는 그리드에서 지정된 영역으로 행을 끌고, 드롭할 때 그 행을 그리드에서 제거하는 것을 다룹니다.

### 드롭 영역

행 끌기를 활성화하는 것은 꽤 쉬웠지만, 이제 행을 _드롭_하는 방법을 구성해야 합니다.
[`igxDrop` 디렉티브](/drag-drop)를 사용하여 행을 드롭할 위치를 정의할 수 있습니다.

먼저 앱 모듈에서 `IgxDragDropModule`을(를) 가져와야 합니다:

```typescript
import { ..., IgxDragDropModule } from 'igniteui-angular/directives';
// import { ..., IgxDragDropModule } from '@infragistics/igniteui-angular'; for licensed package
...
@NgModule({
    imports: [..., IgxDragDropModule]
})
```

그다음 템플릿에서 디렉티브의 선택자를 사용하여 드롭 영역을 정의합니다:

```html
<div class="drop-area" igxDrop (enter)="onEnterAllowed($event)" (leave)="onLeaveAllowed($event)"
(dropped)="onDropAllowed($event)">
    <igx-icon>delete</igx-icon>
    <div>Drag a row here to delete it</div>
</div>
```

<ApiLink type="HierarchicalGrid" member="rowDragEnd" label="rowDragEnd" /> 이벤트의 `animation` 매개변수를 사용하여, 행이 드롭 불가능한 영역에 드롭될 때 애니메이션을 활성화할 수 있습니다. true로 설정하면, 드롭 불가능한 영역 위에 드롭되었을 때 끌린 행이 원래 위치로 애니메이션되며 돌아갑니다.

다음과 같이 애니메이션을 활성화할 수 있습니다:

```typescript
export class IgxHierarchicalGridRowDragComponent {

    public onRowDragEnd(args) {
        args.animation = true;
    }

}
```

### 드롭 영역 이벤트 핸들러

템플릿에서 드롭 영역을 정의했으면, 컴포넌트의 `.ts` 파일에서 `igxDrop`의 <ApiLink type="DropDirective" member="enter" label="enter" />, <ApiLink type="DropDirective" member="leave" label="leave" /> 및 <ApiLink type="DropDirective" member="dropped" label="dropped" /> 이벤트에 대한 핸들러를 선언해야 합니다.

먼저 `enter`과 `leave` 핸들러를 살펴보겠습니다. 이 메서드들에서는 사용자에게 행을 드롭할 수 있는 영역 위에 있다는 것을 알리기 위해 끌기 _고스트_의 아이콘만 바꾸려고 합니다:

```typescript
export class IgxHierarchicalGridRowDragComponent {
    public onEnterAllowed(args) {
        this.changeGhostIcon(args.drag.ghostElement, DragIcon.ALLOW);
    }

    public onLeaveAllowed(args) {
        this.changeGhostIcon(args.drag.ghostElement, DragIcon.DEFAULT);
    }

    private changeGhostIcon(ghost, icon: string) {
        if (ghost) {
            const currentIcon = ghost.querySelector('.igx-grid__drag-indicator > igx-icon');
            if (currentIcon) {
                currentIcon.innerText = icon;
            }
        }
    }
}
```

`changeGhostIcon` **private** 메서드는 끌기 고스트 안의 아이콘만 바꿉니다. 이 메서드의 로직은 아이콘을 담은 요소를 찾고(끌기 표시기 컨테이너에 적용된 `igx-grid__drag-indicator` 클래스를 사용하여), 그 요소의 내부 텍스트를 전달된 텍스트로 바꿉니다.
아이콘 자체는 [`material` 글꼴 세트](https://material.io/tools/icons/)에서 가져오며, 별도의 **`enum`**에 정의되어 있습니다:

```typescript
enum DragIcon {
    DEFAULT = 'drag_indicator',
    ALLOW = 'remove'
}
```

다음으로, 사용자가 실제로 드롭 영역 안에서 행을 _드롭_할 때 무엇이 일어나야 하는지 정의해야 합니다.

```typescript
export class IgxHierarchicalGridRowDragComponent {

    public onDropAllowed(args: IDropDroppedEventArgs) {
        const draggedRow: RowType = args.dragData;
        draggedRow.delete();
    }

}
```

행이 드롭되면, 행의 <ApiLink type="HierarchicalGridRow" label="delete()" /> 메서드를 호출하기만 하면 됩니다

<DocsAside type="info">
이벤트 인수(`args.dragData.data`)나 다른 행 속성의 행 데이터를 사용할 때는, 행 전체가 인수에 참조로 전달된다는 점에 유의하십시오. 따라서 원본 그리드의 데이터와 구별하고 싶다면 필요한 데이터를 복제해야 합니다.
</DocsAside>

### 끌기 아이콘 템플릿화하기

행 끌기 핸들 아이콘은 그리드의 <ApiLink type="HierarchicalGrid" member="dragIndicatorIconTemplate" label="dragIndicatorIconTemplate" />을(를) 사용하여 템플릿화할 수 있습니다. 우리가 만들고 있는 예제에서는 아이콘을 기본 아이콘(`drag_indicator`)에서 `drag_handle`(으)로 바꾸겠습니다.
이를 위해 `igxDragIndicatorIcon`를 사용하여 `igx-hierarchical-grid`의 본문 안에 템플릿을 전달할 수 있습니다:

```html
<igx-hierarchical-grid>
...
    <ng-template igxDragIndicatorIcon>
        <igx-icon>drag_handle</igx-icon>
    </ng-template>
...
</igx-hierarchical-grid>
```

새 아이콘 템플릿을 설정했으면, `changeIcon` 메서드로 올바르게 바뀌도록 `DragIcon enum`의 `DEFAULT` 아이콘도 조정해야 합니다:

```typescript
enum DragIcon {
    DEFAULT = "drag_handle",
    ...
}
```

## 애플리케이션 데모

### 행 재정렬 데모

그리드의 행 끌기 이벤트와 `igxDrop` 디렉티브의 도움으로, 행을 끌어서 순서를 바꿀 수 있는 그리드를 만들 수 있습니다.

모든 작업이 그리드 본문 _안에서_ 일어나므로, `igxDrop` 디렉티브를 그곳에 연결해야 합니다:

```html
<igx-hierarchical-grid #grid [data]="localData" [primaryKey]="'id'"
    [rowDraggable]="true" (rowDragStart)="rowDragStart($event)" igxDrop (dropped)="rowDrop($event)">
    ...
</igx-hierarchical-grid>
```

<DocsAside type="info">
그리드에 `primaryKey`이(가) 지정되어 있는지 확인하십시오! 로직에는 행을 올바르게 재정렬할 수 있도록 행의 고유 식별자가 필요합니다.
</DocsAside>

`rowDraggable`을(를) 활성화하고 드롭 영역을 정의한 후에는, 드롭 이벤트에 대한 간단한 핸들러를 구현해야 합니다. 행을 끌 때 다음을 확인하십시오:

- 행이 펼쳐져 있는가? 그렇다면 접으십시오.
- 행이 그리드 안에 드롭되었는가?
- 그렇다면 끌린 행은 _다른_ 어떤 행 위에 드롭되었는가?
- _대상_ 행을 찾았으면, `data` 배열에서 두 레코드의 위치를 서로 바꾸십시오
- 행이 처음에 선택되어 있었는가? 그렇다면 선택된 상태로 표시하십시오.

아래에서 컴포넌트의 `.ts` 파일에 이것이 구현된 모습을 볼 수 있습니다:

```typescript
export class HGridRowReorderComponent {
    public rowDragStart(args: any): void {
        const targetRow = args.dragData;
        if (targetRow.expanded) {
            targetRow.expanded = false;
        }
    }

    public rowDrop(args: IDropDroppedEventArgs): void {
        const targetRow = args.dragData;
        const event = args.originalEvent;
        const cursorPosition: Point = { x: event.clientX, y: event.clientY };
        this.moveRow(targetRow, cursorPosition);
    }

    private moveRow(draggedRow: RowType, cursorPosition: Point): void {
        // const parent: IgxHierarchicalGridComponent = (draggedRow as any).grid;
        // const parent = args.drag.ghostContext.grid;
        const parent = this.hGrid;
        const rowIndex: number = this.getTargetRowIndex(parent.rowList.toArray(), cursorPosition);
        if (rowIndex === -1) { return; }
        const wasSelected = draggedRow.selected;
        draggedRow.delete();
        parent.data.splice(rowIndex, 0, draggedRow.data);
        if (wasSelected) {
            parent.selectRows([parent.rowList.toArray()
                .find((r) => r.rowID === draggedRow.key).rowID], false);
        }
    }

    private getTargetRowIndex(rowListArr: RowType[], cursorPosition: Point): number {
        const targetElem: IgxHierarchicalRowComponent = this.catchCursorPosOnElem(rowListArr, cursorPosition);
        return rowListArr.indexOf(rowListArr.find((r) => r.rowData.id === targetElem.rowData.id));
    }

    private catchCursorPosOnElem(rowListArr: any[], cursorPosition: Point)
        : IgxHierarchicalRowComponent {
        for (const row of rowListArr) {
            const rowRect = row.nativeElement.getBoundingClientRect();
            if (cursorPosition.y > rowRect.top + window.scrollY && cursorPosition.y < rowRect.bottom + window.scrollY &&
                cursorPosition.x > rowRect.left + window.scrollX && cursorPosition.x < rowRect.right + window.scrollX) {
                return row;
            } else if (row === rowListArr[rowListArr.length - 1] && cursorPosition.y > rowRect.bottom) {
                return row;
            }
        }
    }
}
```

이 몇 가지 간단한 단계로, 끌어서 놓기를 통해 행의 순서를 바꿀 수 있는 그리드를 구성했습니다! 위 코드가 실제로 작동하는 모습은 다음 데모에서 볼 수 있습니다.

행 선택도 활성화되어 있으며, 끌린 행을 드롭할 때 선택 상태가 유지된다는 점에 유의하십시오.
