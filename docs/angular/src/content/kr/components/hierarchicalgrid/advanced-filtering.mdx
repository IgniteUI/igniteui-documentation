# Angular Hierarchical Grid 고급 필터링

고급 필터링은 Hierarchical Grid과 같은 모든 [Angular 테이블](https://www.infragistics.com/products/ignite-ui-angular/angular/components/grid/grid)에서 모든 열에 걸쳐 필터링 조건이 있는 그룹을 만들 수 있는 대화 상자를 제공합니다.

## 상호 작용

고급 필터링 대화 상자를 열려면 그리드 도구 모음의 **고급 필터링** 버튼을 클릭해야 합니다. 이 대화 상자는 <ApiLink type="QueryBuilder" /> 컴포넌트를 사용하여 필터링 로직을 생성, 표시 및 편집합니다. 상호 작용 과정의 세부 사항은 [`Query Builder topic`](../query-builder.mdx#getting-started-with-ignite-ui-for-angular-query-builder)을(를) 참조하십시오.

필터링 조건과 그룹을 준비했으면 데이터를 필터링하기 위해 **적용** 버튼을 클릭해야 합니다. 고급 필터를 수정했지만 변경 사항을 유지하고 싶지 않다면 **취소** 버튼을 클릭해야 합니다. **필터 지우기** 버튼을 클릭하여 고급 필터를 지울 수도 있습니다.

## 사용법

고급 필터링을 활성화하려면 <ApiLink type="HierarchicalGrid" member="allowAdvancedFiltering" label="allowAdvancedFiltering" /> 입력 속성을 `true`(으)로 설정해야 합니다.

```html
<igx-hierarchical-grid [data]="data" [autoGenerate]="true" [allowAdvancedFiltering]="true">
    <igx-grid-toolbar></igx-grid-toolbar>
</igx-hierarchical-grid>
```

고급 필터링은 <ApiLink type="HierarchicalGrid" member="advancedFilteringExpressionsTree" label="advancedFilteringExpressionsTree" /> 입력 속성에 저장되는 <ApiLink type="FilteringExpressionsTree" />을(를) 생성합니다. 이 속성을 사용하여 고급 필터링의 초기 상태를 설정할 수 있습니다.

```TypeScript
ngAfterViewInit(): void {
    const tree = new FilteringExpressionsTree(FilteringLogic.Or);
    tree.filteringOperands.push({
        fieldName: 'Artist',
        condition: IgxStringFilteringOperand.instance().condition('startsWith'),
        conditionName: IgxStringFilteringOperand.instance().condition('startsWith').name,
        searchVal: 'A'
    });
    const subTree = new FilteringExpressionsTree(FilteringLogic.And);
    subTree.filteringOperands.push({
        fieldName: 'GrammyAwards',
        condition: IgxNumberFilteringOperand.instance().condition('greaterThanOrEqualTo'),
        conditionName: IgxNumberFilteringOperand.instance().condition('greaterThanOrEqualTo').name,
        searchVal: 1
    });
    subTree.filteringOperands.push({
        fieldName: 'Debut',
        condition: IgxNumberFilteringOperand.instance().condition('lessThan'),
        conditionName: IgxNumberFilteringOperand.instance().condition('lessThan').name,
        searchVal: 2000
    });
    tree.filteringOperands.push(subTree);
    this.hierarchicalGrid.advancedFilteringExpressionsTree = tree;
}
```

`IgxHierarchicalGrid`의 고급 필터링은 _IN / NOT-IN_ 연산자를 사용하여 자식 그리드 데이터를 기준으로 루트 그리드 데이터를 필터링하는 데 사용할 수 있습니다. 이렇게 하면 더 복잡한 필터링 로직을 정의하기 위해 하위 쿼리를 만들 수 있습니다. 이 기능에 대한 자세한 정보는 [`Query Builder's Using Sub-Queries section`](../query-builder-model.mdx#using-sub-queries)에서 찾을 수 있습니다. 하위 쿼리가 있는 <ApiLink type="FilteringExpressionsTree" /> 샘플은 다음과 같습니다:

```TypeScript
ngAfterViewInit(): void {
    const albumsTree = new FilteringExpressionsTree(FilteringLogic.And, undefined, 'Albums', ['Artist']);
    albumsTree.filteringOperands.push({
        fieldName: 'LaunchDate',
        condition: IgxDateFilteringOperand.instance().condition('after'),
        conditionName: IgxDateFilteringOperand.instance().condition('after').name,
        searchVal: new Date(2017, 1, 1)
    });
    const tree = new FilteringExpressionsTree(FilteringLogic.And);
    tree.filteringOperands.push({
        fieldName: 'Artist',
        condition: IgxStringFilteringOperand.instance().condition('inQuery'),
        conditionName: IgxStringFilteringOperand.instance().condition('inQuery').name,
        searchTree: albumsTree
    });
    this.hierarchicalGrid.advancedFilteringExpressionsTree = tree;
}
```

원격 데이터를 사용하는 경우, 고급 필터링 대화 상자는 `IgxHierarchicalGrid`과(와) 그 row island에 선언된 열에서 필드를 가져옵니다. 자식 데이터가 아직 로드되지 않은 row island도 포함됩니다. 자세한 안내는 [`Load on Demand`](../hierarchicalgrid/load-on-demand.mdx) 주제를 참조하십시오.

Hierarchical Grid 도구 모음을 표시하고 싶지 않다면 <ApiLink type="HierarchicalGrid" member="openAdvancedFilteringDialog" label="openAdvancedFilteringDialog" /> 및 <ApiLink type="HierarchicalGrid" member="closeAdvancedFilteringDialog" label="closeAdvancedFilteringDialog" /> 메서드를 사용하여 고급 필터링 대화 상자를 프로그래밍 방식으로 열고 닫을 수 있습니다.

<DocsAside type="info">
Hierarchical Grid에서 `quickFilter`/`excelStyleFilter` 및 고급 필터링 사용자 인터페이스를 모두 활성화할 수 있습니다. 두 필터링 사용자 인터페이스는 서로 독립적으로 작동합니다. Hierarchical Grid의 최종 필터링 결과는 두 필터의 결과가 교차한 것입니다.
</DocsAside>

## 외부 고급 필터링

위 데모에서 보았듯이, 고급 필터링 대화 상자는 Hierarchical Grid 위의 오버레이에 호스팅됩니다. 대화 상자의 설정이 준비되면 적용 또는 닫기 동작이 그 대화 상자를 숨깁니다. 그 대화 상자를 항상 보이게 유지하는 방법, 즉 독립형 컴포넌트로 사용하는 방법도 있습니다. 아래 데모에서는 고급 필터링 대화 상자가 Hierarchical Grid와 별도로 선언되어 있습니다.

### 사용법

Hierarchical Grid의 바깥에서 작동하도록 고급 필터링을 구성하는 것은 매우 쉽습니다. 대화 상자를 만들고 그 <ApiLink type="GridToolbarAdvancedFiltering" member="grid" label="grid" /> 속성을 설정하기만 하면 됩니다:

```html
<igx-advanced-filtering-dialog [grid]="hierarchicalGrid">
</igx-advanced-filtering-dialog>
```

[드래그 앤 드롭 App Builder™](https://www.infragistics.com/products/appbuilder)가 디자인에서 Angular 코드까지의 전체 과정을 어떻게 간소화할 수 있는지도 확인할 수 있습니다.

## 스타일링

고급 필터링 대화 상자의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내진 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

고급 필터링 대화 상자는 <ApiLink type="QueryBuilder" /> 컴포넌트를 사용하므로, <ApiLink kind="sass" module="themes" type="query-builder-theme" label="query-builder-theme" code={true} />를 사용하여 그 스타일을 지정할 수 있습니다. 헤더 제목의 스타일을 지정하려면, <ApiLink kind="sass" module="themes" type="query-builder-theme" label="query-builder-theme" code={true} />을(를) 확장하고 `$header-foreground` 매개변수를 설정하는 사용자 지정 테마를 만들 수 있습니다.

```scss
$custom-query-builder: query-builder-theme(
  $background: #1f2836,
  $foreground: #f5f6e6,
  $accent-color: #f5f6e6
);
```

<DocsAside type="info">
방금 한 것처럼 색상 값을 직접 하드코딩하는 대신, <ApiLink kind="sass" module="palettes" type="function-palette" label="palette" code={true} /> 및 <ApiLink kind="sass" module="palettes" type="function-color" label="color" code={true} /> 함수를 사용하면 색상을 훨씬 유연하게 다룰 수 있습니다. 사용 방법에 대한 자세한 안내는 [`Palettes`](/themes/sass/palettes) 항목을 참조하십시오.
</DocsAside>

마지막 단계는 애플리케이션에 컴포넌트 테마를 **포함**하는 것입니다.

```scss
igx-advanced-filtering-dialog {
  @include tokens($custom-query-builder);
}
```

<DocsAside type="info">
생성한 **query-builder-theme**을 `igx-advanced-filtering-dialog` 안에 포함하여, 이 사용자 지정 테마가 고급 필터링 대화 상자 안에 중첩된 query builder에만 영향을 주도록 하겠습니다. 그렇지 않으면 애플리케이션의 다른 query builder 컴포넌트에도 영향이 갑니다.
</DocsAside>

<DocsAside type="info">
일부 컴포넌트 템플릿에서는 Emulated View Encapsulation 때문에 생성된 토큰 선언이 중첩된 Ignite UI 요소에 도달하지 못할 수 있습니다. 테마가 적용되지 않으면 아래와 같이 `::ng-deep`을(를) 사용하거나 테마를 전역 스타일시트로 옮기십시오.
</DocsAside>

```scss
:host {
  ::ng-deep {
    igx-advanced-filtering-dialog {
      @include tokens($custom-query-builder);
    }
  }
}
```
