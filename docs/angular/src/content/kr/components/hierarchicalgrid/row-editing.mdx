# Angular Hierarchical Grid 행 편집

Hierarchical Grid은(는) 인라인 편집을 통해 데이터를 조작하는 편리한 방법과, Angular CRUD 작업을 위한 강력한 API를 제공합니다. 행을 클릭한 다음 **Enter 키**를 누르거나, 수정해야 할 행을 마우스로 더블 클릭하면 됩니다.

## Angular Hierarchical Grid 행 편집 예제

다음 샘플은 Hierarchical Grid에서 행 편집을 활성화하는 방법을 보여 줍니다. 셀 값을 바꾼 다음 같은 행의 다른 셀을 클릭하거나 그쪽으로 이동해도, **완료** 버튼으로 확인하거나 **취소** 버튼으로 버리기 전까지는 행 값이 업데이트되지 않습니다.

<DocsAside type="info">
행이 편집 모드에 있을 때 다른 행의 셀을 클릭하면, 완료 버튼을 누른 것처럼 동작하여 이전 행의 모든 변경 사항을 제출합니다. 새로 포커스를 받은 셀이 편집 가능하면 새 행도 편집 모드에 들어가고, 셀이 편집 불가능하면 이전 행만 편집 모드를 벗어납니다.

## 행 편집 사용법

시작하려면 **app.module.ts** 파일에서 `IgxHierarchicalGridModule`을(를) 가져오십시오:

```typescript
// app.module.ts

...
import { IgxHierarchicalGridModule } from 'igniteui-angular';

@NgModule({
    ...
    imports: [..., IgxHierarchicalGridModule],
    ...
})
export class AppModule {}
```

그다음 바인딩된 데이터 소스를 가진 Hierarchical Grid을(를) 정의하고 <ApiLink type="HierarchicalGrid" member="rowEditable" label="rowEditable" />을(를) true로 설정하십시오:

```html
<igx-hierarchical-grid [data]="localdata" [autoGenerate]="false" [rowEditable]="true">
    <igx-column field="Artist" [editable]="true" [dataType]="'string'"></igx-column>
    <igx-column field="HasGrammyAward" [editable]="true" [dataType]="'boolean'">
    </igx-column>
    <igx-column field="Debut" [editable]="true" [dataType]="'number'"></igx-column>
    <igx-column field="GrammyNominations" [editable]="true" [dataType]="'number'" [hasSummary]="true"></igx-column>
    <igx-column field="GrammyAwards" [editable]="true" [dataType]="'number'"
    [hasSummary]="true"></igx-column>
    <igx-column width="10%">
        <ng-template igxCell let-cell="cell">
            <button igxIconButton="flat" (click)="removeRow(cell.cellID.rowIndex)">
                <igx-icon>delete</igx-icon>
            </button>
        </ng-template>
    </igx-column>

    <igx-row-island [key]="'Albums'" #layout1 [autoGenerate]="false">
        <igx-column field="Album" [editable]="true" [dataType]="'string'"></igx-column>
        <igx-column field="Launch Date" [editable]="true" [dataType]="'date'"></igx-column>
        <igx-column field="Billboard Review" [editable]="true" [dataType]="'number'"></igx-column>
        <igx-column field="US Billboard 200" [editable]="true" [dataType]="'number'"></igx-column>
        <igx-row-island [key]="'Songs'" [autoGenerate]="false">
            <igx-column field="No."></igx-column>
            <igx-column field="Title"></igx-column>
            <igx-column field="Released"></igx-column>
            <igx-column field="Genre"></igx-column>
        </igx-row-island>
    </igx-row-island>
</igx-hierarchical-grid>
```

<DocsAside type="info">
행 편집 작업에는 기본 키를 설정하는 것이 필수입니다.
</DocsAside>

<DocsAside type="info">
개별 열에 대해 편집을 활성화할 필요는 없습니다. Hierarchical Grid에서 <ApiLink type="HierarchicalGrid" member="rowEditable" label="rowEditable" /> 속성을 사용하면, `field` 속성이 정의된 모든 행에서 기본 키를 제외하고 편집할 수 있게 됩니다. 특정 열의 편집을 비활성화하려면, 그 열의 <ApiLink type="Column" member="editable" label="editable" /> 입력을 `false`(으)로 설정하십시오.
</DocsAside>

```typescript
import { IgxRowIslandComponent, IgxHierarchicalGridComponent } from 'igniteui-angular/grids/hierarchical-grid';
// import { IgxRowIslandComponent, IgxHierarchicalGridComponen } from '@infragistics/igniteui-angular'; for licensed package

@Component({
    selector: 'hierarchical-grid-row-editing',
    styleUrls: ['./hierarchical-grid-row-editing.component.scss'],
    templateUrl: 'hierarchical-grid-row-editing.component.html'
})

export class HGridRowEditingSampleComponent implements OnInit {
    public localdata;

    @ViewChild('layout1')
    layout1: IgxRowIslandComponent;

    @ViewChild('hierarchicalGrid')
    hierarchicalGrid: IgxHierarchicalGridComponent;

    constructor() {
        this.localdata = SINGERS;
    }
}
```

<DocsAside type="info">
Hierarchical Grid은(는) 행 상태가 제출되거나 취소될 때까지 보류 중인 셀 변경 사항을 보관하는 공급자 <ApiLink type="BaseTransactionService" />를 내부적으로 사용합니다.
</DocsAside>

## 위치 지정

- 오버레이의 기본 위치는 편집 모드에 있는 행의 아래입니다

- 행 아래에 공간이 없으면 오버레이는 행의 위에 나타납니다.

- 위 또는 아래에 한번 표시되면, 오버레이는 닫힐 때까지 스크롤하는 동안 그 위치를 유지합니다.

## 동작

- 행이 편집 모드에 있는 동안 같은 행의 셀을 클릭하면 편집이 계속됩니다.

- "Done" 버튼을 클릭하면 행 편집이 끝나고, 변경 사항은 데이터 소스에 제출되거나, 가능하다면 트랜잭션에 제출됩니다. 또한 행은 편집 모드를 벗어납니다.

- "Cancel" 버튼을 클릭하면 행의 현재 모든 변경 사항이 되돌아가고, 행은 편집 모드를 벗어납니다.

- 행이 편집 모드에 있을 때 다른 행의 셀을 클릭하면, 현재 행 편집을 끝내고 새 행의 변경 사항을 제출합니다("Done" 버튼을 클릭한 것과 같은 동작). 새로 포커스를 받은 셀이 편집 가능하면 새 행도 편집 모드에 들어가고, 셀이 편집 불가능하면 이전 행만 편집 모드를 벗어납니다.

- 행이 편집 모드에 있고 Hierarchical Grid이(가) 스크롤되어 그 행이 보이는 영역 밖으로 나가더라도, 그 행은 여전히 편집 모드에 있습니다. Hierarchical Grid가 다시 스크롤되어 그 행이 다시 보이게 되면, 행은 여전히 편집 모드에 있습니다. Hierarchical Grid 바깥을 클릭해도 그 셀은 여전히 편집 모드에 남습니다.

- _정렬_, _필터링_, _검색_ 및 _숨기기_ 작업을 수행하면, 행의 현재 모든 변경 사항이 되돌아가고 행은 편집 모드를 벗어납니다.

- _페이징_, _크기 조정_, _고정_ 및 _이동_ 작업을 수행하면 편집 모드를 벗어나고 최신 값을 제출합니다.

- 행 편집이 끝날 때까지 수정된 각 셀에는 편집 스타일이 적용됩니다. 이는 Hierarchical Grid에 트랜잭션이 제공되지 않은 경우의 동작입니다. 트랜잭션을 사용할 수 있는 경우에는 모든 변경 사항이 커밋될 때까지 셀 편집 스타일이 적용됩니다.

## 키보드 탐색

- `Enter` 및 `F2`는 행 편집 모드에 들어갑니다

- `Esc`은(는) 행 편집 모드를 벗어나며, 행이 편집 모드에 있는 동안 이루어진 어떤 셀 변경 사항도 제출하지 않습니다.

- `Tab`은(는) 포커스를 행의 편집 가능한 한 셀에서 다음 셀로 옮기고, 가장 오른쪽 편집 가능한 셀에서는 CANCEL 및 DONE 버튼으로 옮깁니다. DONE 버튼에서의 탐색은 현재 편집 중인 행의 가장 왼쪽 편집 가능한 셀로 이동합니다.

## 기능 통합

- 데이터를 바꾸는 모든 작업은 행 편집 작업을 끝내고 현재 행 변경 사항을 제출합니다. 여기에는 정렬, 그룹화 또는 필터링 기준 변경, 페이징 등의 작업이 포함됩니다.

- 행 편집이 끝나면 요약이 업데이트됩니다. 정렬, 필터링 등 다른 기능에도 같은 내용이 적용됩니다.

## 행 편집 오버레이 사용자 지정하기

### 텍스트 사용자 지정하기

`igxRowEditTextDirective`을(를) 사용하면 행 편집 오버레이의 텍스트를 사용자 지정할 수 있습니다.
`rowChangesCount` 속성이 노출되며, 이 속성은 변경된 셀의 개수를 보관합니다.

```html
<ng-template igxRowEditText let-rowChangesCount>
 Changes: {{rowChangesCount}}
</ng-template>
 ```

### 버튼 사용자 지정하기

`igxRowEditActionsDirective`을(를) 사용하면 행 편집 오버레이의 버튼을 사용자 지정할 수 있습니다.
버튼이 키보드 탐색의 일부가 되기를 원한다면, 각 버튼에 `igxRowEditTabStopDirective`를 설정해야 합니다.

 ```html
 <ng-template igxRowEditActions let-endRowEdit>
 <button igxButton igxRowEditTabStop (click)="endRowEdit(false)">Cancel</button>
 <button igxButton igxRowEditTabStop (click)="endRowEdit(true)">Apply</button>
</ng-template>
 ```

## 스타일링

[Ignite UI for Angular 테마 라이브러리](/themes)를 사용하면 행 편집 오버레이의 모양을 크게 바꿀 수 있습니다.
행 편집 오버레이는 복합 요소입니다. 그 UI는 여러 다른 컴포넌트로 구성됩니다:
    - 콘텐츠를 렌더링하기 위한 [`igx-banner`](/banner)
    - [`igx-button`](inputs/button)은(는) 기본 템플릿(`Done` 및 `Cancel` 버튼용)에서 렌더링됩니다.

아래 예제에서는 이 두 컴포넌트의 스타일 지정 옵션인 [`button styling`](inputs/button#styling) 및 [`banner-styling`](/banner#스타일링)를 사용하여 IgxHierarchicalGrid의 행 편집 경험을 사용자 지정하겠습니다.
또한 현재 셀의 편집기와 배경의 스타일도 지정하여 더 두드러지게 만들겠습니다.

셀 스타일 지정에 대해서는 [셀 스타일 지정 섹션](/hierarchicalgrid/cell-editing#스타일링)에서 더 자세히 알아볼 수 있습니다.

### 테마 가져오기

행 편집 배너의 스타일을 지정하는 가장 쉬운 방법은 `app`의 전역 스타일 파일(보통 `styles.scss`)에 스타일을 정의하는 것입니다.
가장 먼저 해야 할 일은 `themes/index` 파일을 가져오는 것입니다. 이를 통해 Ignite UI for Angular Sass 프레임워크의 강력한 도구에 접근할 수 있습니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

테마 파일을 가져왔으면 사용자 지정 테마를 만들 수 있습니다.

#### 테마 정의하기

이제 행 편집의 배경에 영향을 주고, 미리 정의된 팔레트 중 하나인 `$purple-palette`를 사용하는 사용자 지정 <ApiLink kind="sass" module="themes" type="function-banner-theme" label="배너 테마" code={true} />을 정의할 수 있습니다:

```scss
$banner-theme: banner-theme(
  $banner-background: #e3e3e3,
  $banner-message-color: color($purple-palette, "secondary", 600)
);
```

여기서는 색상을 생성하기 위해 `my-banner-palette`을(를) 테마 라이브러리가 노출하는 <ApiLink kind="sass" module="palettes" type="function-color" label="igx-color" code={true} />와 함께 사용하고 있습니다.

### 테마 포함하기

이제 남은 일은 Sass `@include` 문으로 테마를 적용하는 것입니다. 새로 정의한 `$banner-theme`을(를) <ApiLink kind="sass" module="themes" type="mixin-tokens" label="토큰 믹스인" code={true} />을(를) 통해 전달합니다:

```scss
:host {
  @include tokens($banner-theme);
}
```

### 컴포넌트 스타일

행 편집 오버레이는 다른 많은 컴포넌트의 테마를 사용하므로, 전역 스타일로 스타일을 지정하면 애플리케이션의 다른 부분(예: 배너, 버튼 등)에도 영향을 줄 수 있습니다. 이를 막는 가장 좋은 방법은 배너 테마를 그것이 적용되는 특정 컴포넌트의 스타일 파일에 범위 지정하는 것입니다.

<DocsAside type="info">
일부 컴포넌트 템플릿에서는 Emulated View Encapsulation 때문에 생성된 토큰 선언이 중첩된 Ignite UI 요소에 도달하지 못할 수 있습니다. 테마가 적용되지 않으면 아래와 같이 `::ng-deep`을(를) 사용하거나 테마를 전역 스타일시트로 옮기십시오.
</DocsAside>

```scss
// custom.component.scss

:host {
  ::ng-deep {
    @include tokens($banner-theme);
  }
}
```

위 구문을 사용하면 사용자 지정 배너 테마가 그리드의 행 편집 오버레이에 올바르게 적용됩니다.

### 사용자 지정 템플릿

행 편집 오버레이를 더 사용자 지정하기 위해, `Done`과 `Cancel` 버튼의 스타일을 따로 지정할 수 있도록 사용자 지정 템플릿을 전달할 수 있습니다:

```html
<!-- in component.html -->
<igx-hierarchical-grid>
    <ng-template igxRowEditActions let-endRowEdit>
        <div class="custom-buttons">
            <button igxIconButton="flat" class="custom-button" igxRowEditTabStop (click)="endRowEdit(false)">
                <igx-icon>clear</igx-icon>
            </button>
            <button igxIconButton="flat" class="custom-button" igxRowEditTabStop (click)="endRowEdit(true)">
                <igx-icon>check</igx-icon>
            </button>
        </div>
    </ng-template>
</igx-hierarchical-grid>
```

사용자 지정 버튼을 정의한 후에는 <ApiLink kind="sass" module="themes" type="function-flat-icon-button-theme" label="flat-icon-button-theme" code={true} />을(를) 사용하여 그 스타일을 지정할 수 있습니다. `igx-icon-button` 스타일 지정에 대한 자세한 내용은 [아이콘 버튼 스타일 지정 문서](/icon-button#아이콘-버튼-스타일링)에서 확인할 수 있습니다. `Done`과(와) `Cancel`에 대해 사용자 지정 테마를 만들 수 있습니다:

```scss
// custom.component.scss
...

$button-theme: flat-icon-button-theme(
  $background: #e3e3e3,
  $foreground: #423589
);

...
.custom-buttons {
  @include tokens($button-theme);
}
```

배너와 버튼에만 적용되도록 `@include` 구문을 `.custom-buttons` 안에 범위 지정합니다. 대상은 `Done`과 `Cancel` 버튼입니다.

## 알려진 문제와 제한 사항

- 그리드에 `primaryKey`이(가) 설정되어 있지 않고 원격 데이터 시나리오가 활성화되어 있으면(페이징, 정렬, 필터링, 스크롤이 표시할 데이터를 가져오기 위해 원격 서버에 요청을 트리거할 때), 데이터 요청이 완료된 후 행은 다음 상태를 잃게 됩니다:
  - 행 선택
  - 행 펼치기/접기
  - 행 편집
  - 행 고정
