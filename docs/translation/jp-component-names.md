# Japanese readings of component names

The JP sync workflows use this list when they translate component names. The JP team has reviewed every reading.

- Match the longest name first. For example, "Date Range Picker" is one name, not "Date" plus "Range Picker".
- A name marked "(none)" has no reading. Keep it in English everywhere, and add no parentheses to the H1.
- For a name not in this list, reuse the reading that the existing Japanese pages use.
