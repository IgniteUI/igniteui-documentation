# What's New in 2023 Volume 2

This topic presents the new features for the Ignite UI™ 2023 Volume 2 release.

### Ignite UI for Asp.Net Core

Infragistics Ignite UI for Asp.Net Core now supports ASP.NET Core for .NET 8 projects. For more information see the [Using Ignite UI for Asp.Net Core](./using-igniteui-controls-in-asp.net-core-project.mdx) topic.

### Ignite UI for Asp.Net Core Tag Helpers

Ignite UI for Asp.Net Core Tag Helpers now support ASP.NET Core for .NET 8 projects. For more information see the [Using Ignite UI for Asp.Net Core Tag Helpers](./using-ignite-ui-tag-helpers.mdx) topic.
