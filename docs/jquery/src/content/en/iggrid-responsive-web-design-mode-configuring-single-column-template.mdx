## Single Column Template Overview

The responsive Single Column Template allows you to define a custom template that renders the data from a row into a single column based on the current layout mode (tablet or phone).

The Single Column Template is available in Ignite UI for jQuery 15.1 and later.

This allows you to create a specialized look for the data in the grid when it's rendered on small devices.

<Image src={imgConfiguringSingleColumnTemaplte} alt="Employee igGrid in the Desktop profile next to the same data as single-column cards with photo and details" />

<DocsAside type="note">
  The RWD Single Column Template feature is supported only with the Paging grid feature. All other grid features are currently not supported with this mode.
</DocsAside>

## Single Column Template Configuration

The templates per specific profile are specified via the <ApiLink type="igGridResponsive" member="options:singleColumnTemplate" pkg="core" label="singleColumnTemplate" /> option of the Responsive Web Design Mode feature. Different templates can be specified based on the current layout mode (tablet or phone) in order to further customize the way the data is presented.
