# Chart Types

## Overview

The Category Chart simplifies assignment of the type of rendering compared to the Data Chart. In order to select how data should be displayed it is enough to set the `chartType` property of this chart. Below listed all of the types that the Category Chart supports.

Special case is the `auto` setting of that property. If `auto` is used the chart will analyze assigned data and will assign the most suitable chart type.

Default value of that property is `line`.

## Supported chart types

| Property Value | Description                                                                        | Example                                       |
| -------------- | ---------------------------------------------------------------------------------- | --------------------------------------------- |
| `line`         | Specifies category line series with markers at each data point                     | <Image src={imgChartTypeLine} alt="" />       |
| `area`         | Specifies category area series                                                     | <Image src={imgChartTypeArea} alt="" />       |
| `column`       | Specifies category column chart with vertical rectangles at each data point        | <Image src={imgChartTypeColumn} alt="" />     |
| `point`        | Specifies category point chart with markers at each data point                     | <Image src={imgChartTypePoint} alt="" />      |
| `stepLine`     | Specifies category step line chart                                                 | <Image src={imgChartTypeStepline} alt="" />   |
| `stepArea`     | Specifies category step area chart                                                 | <Image src={imgChartTypeSteparea} alt="" />   |
| `spline`       | Specifies category spline line series with markers at each data point              | <Image src={imgChartTypeSpline} alt="" />     |
| `splineArea`   | Specifies category spline area series                                              | <Image src={imgChartTypeSplinearea} alt="" /> |
| `waterfall`    | Specifies category waterfall chart                                                 | <Image src={imgChartTypeWaterfall} alt="" />  |
| `auto`         | Specifies automatic selection of chart type based on suggestions from Data Adapter |                                               |
