### igTileManager

| Issue                                                                                                    | Description                                                                                                                                                                                               | Status                                                                       |
| -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `igTileManager` not working properly for browsers not supporting the box-sizing model                    | This box-sizing model ensures that the box grows inwards instead of outwards. Otherwise positioning of tiles that have paddings and borders and any other outer height/width modifiers is very difficult. | <Image src={imgNegative} alt="" />                                           |
| jQuery versions lower than 1.8.0 are not supported.                                                      | There are certain limitations in JQuery versions earlier than 1.8.0 that prevent the `igTileManager` control from working properly.                                                                       | <Image src={imgNegative} alt="" />                                           |
