## <a id="scroll-general" />igScroll – General

### <a id="initially-hidden" />When initializing igScroll on a initially hidden element scrolling does not work

When initializing the igScroll on a hidden element, after showing the element the scrollbars don't show and scrolling does not work.

<DocsAside type="note" title="Workaround">
  The <ApiLink type="igScroll" member="options:scrollHeight" pkg="core" label="scrollHeight" />/<ApiLink type="igScroll" member="options:scrollWidth" pkg="core" label="scrollWidth" /> options should be set to the related container height and width after the container is shown.
</DocsAside>
