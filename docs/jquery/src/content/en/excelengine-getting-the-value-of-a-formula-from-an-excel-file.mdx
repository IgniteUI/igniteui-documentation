# Getting the Value of a Formula from an Excel File

In order to get the evaluated value of an Excel Cell that is represented by a Formula, you simply access the <ApiLink type="WorksheetCell" member="Value" pkg="documents-excel" label="Value" /> property of the <ApiLink type="WorksheetCell" pkg="documents-excel" label="WorksheetCell" />.

The example code below shows you how to access a particular Excel Worksheet Cell that is populated by an Excel Formula.

**In Visual Basic:**

```vb
lblValue.Text = theWorksheet.Rows[1].Cells[4].Value;
```

**In C#:**

```csharp
lblValue.Text = theWorksheet.Rows[1].Cells[4].Value;
```
