# Configuring igPivotGrid

## Topic Overview

### Purpose

This topic discusses how to configure the `igPivotGrid`™ control.

## Basic Configuration

The following table lists the basic options that need to be defined in order to display the data in a pivot table.

For the igPivotGrid:

| Option                                                                                   | Description                                                        |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| <ApiLink type="igPivotGrid" member="options:dataSource" pkg="core" label="dataSource" /> | An instance of $.ig.OlapXmlaDataSource or $.ig.OlapFlatDataSource. |

The **$.ig.OlapXmlaDataSource** component handles the communication with a Microsoft® SQL Server Analysis Services (SSAS) server configured with the msmdpump.dll HTTP data provider. The relevant basic settings for it are:

| Option                                                                                                | Description                                                                                                        |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| <ApiLink type="OlapXmlaDataSource" member="options:options.serverUrl" pkg="core" label="serverUrl" /> | The URL of the XMLA server.                                                                                        |
| <ApiLink type="OlapXmlaDataSource" member="options:options.catalog" pkg="core" label="catalog" />     | The catalog name.                                                                                                  |
| <ApiLink type="OlapXmlaDataSource" member="options:options.cube" pkg="core" label="cube" />           | The name of the cube in the data source.                                                                           |
| <ApiLink type="OlapXmlaDataSource" member="options:options.rows" pkg="core" label="rows" />           | A list of hierarchy names separated by comma (,). These will be the hierarchies in the rows of the data source.    |
| <ApiLink type="OlapXmlaDataSource" member="options:options.columns" pkg="core" label="columns" />     | A list of hierarchy names separated by comma (,). These will be the hierarchies in the columns of the data source. |
| <ApiLink type="OlapXmlaDataSource" member="options:options.measures" pkg="core" label="measures" />   | A list of measure names separated by comma (,). These will be the measures of the data source.                     |

You can refer to the following basic sample with an example configuration.

- [Binding to Xmla Data Source](\{environment:samplesBrowserUrl}/pivot-grid/binding-to-xmla-data-source)

For the OlapFlatDataSource:

| Option                                                                                                  | Description                                                                                                        |
| ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| <ApiLink type="OlapFlatDataSource" member="options:options.dataSource" pkg="core" label="dataSource" /> | Specifies any valid data source accepted by $.ig.DataSource, or an instance of an $.ig.DataSource itself.          |
| <ApiLink type="OlapFlatDataSource" member="options:options.metadata" pkg="core" label="metadata" />     | An object containing processing instructions for the $.ig.DataSource data.                                         |
| <ApiLink type="OlapFlatDataSource" member="options:options.metadata.cube" pkg="core" label="metadata.cube" />                                                                                           | Metadata used for the creation of the cube.                                                                        |
| <ApiLink type="OlapFlatDataSource" member="options:options.metadata.cube.measuresDimension" pkg="core" label="metadata.cube.measuresDimension" />                                                                         | An object providing information about the measures' root node.                                                     |
| <ApiLink type="OlapFlatDataSource" member="options:options.metadata.cube.dimensions" pkg="core" label="metadata.cube.dimensions" />                                                                                | An array of dimension metadata objects.                                                                            |
| <ApiLink type="OlapFlatDataSource" member="options:options.rows" pkg="core" label="rows" />             | A list of hierarchy names separated by comma (,). These will be the hierarchies in the rows of the data source.    |
| <ApiLink type="OlapFlatDataSource" member="options:options.columns" pkg="core" label="columns" />       | A list of hierarchy names separated by comma (,). These will be the hierarchies in the columns of the data source. |
| <ApiLink type="OlapFlatDataSource" member="options:options.measures" pkg="core" label="measures" />     | list of measure names separated by comma (,). These will be the measures of the data source.                       |

### Drag and Drop custom elements

The following steps will guide you through the process of implementing dragging and dropping of custom elements in the igPivotGrid.

#### Steps

1. Define elements with the data-type and data-name attributes.

   The data-type should be set to the type of element, could be: Dimension, Hierarchy, Measure or Level. The data-name should be the related value. For exampe:

   ```html
   <div
       class="ui-igpivot-metadataitem ui-state-default ui-corner-all custom-draggable"
       data-type="Hierarchy"
       data-name="[Seller].[Seller]"
   >
       <span>Hierarchy: Seller</span>
   </div>
   <div
       class="ui-igpivot-metadataitem ui-state-default ui-corner-all custom-draggable"
       data-type="Measure"
       data-name="[Measures].[UnitsSold]"
   >
       <span>Measure: Units Sold</span>
   </div>
   ```

2. Make the defined elements draggable using jQuery UI's [draggable](https://jqueryui.com/draggable/) Interactions.
