# Setting PageOrientation when publishing a Report

When publishing a PDF or XPS document, the Orientation of the page can be set by the <ApiLink type="ISection" member="PageOrientation" pkg="documents-reports" label="PageOrientation" /> property. When the <ApiLink type="Report" member="Publish" pkg="documents-reports" label="Report.Publish(" />) method is used, the PageOrientation needs to be directly set on each Section <ApiLink type="ISection" pkg="documents-reports" label="ISection()" /> that you add to the Report.

**In C#:**

```csharp
Infragistics.Documents.Reports.Report.Report r = new Report();

//Adding a section to the Report
Infragistics.Documents.Reports.Report.Section.ISection s = r.AddSection();

 s.PageOrientation = PageOrientation.Portrait;

 //Adding Text to the Section
 Infragistics.Documents.Reports.Report.Text.IText t = s.AddText();

 t.AddContent(”Test Text”);


 string theFile = @”c:test.pdf”;

 r.Publish(theFile, FileFormat.PDF);
```
