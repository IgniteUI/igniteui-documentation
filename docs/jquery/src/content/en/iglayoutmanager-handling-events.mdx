## Handling Events – Conceptual Overview

### Handling events summary

Attaching event handler functions to the `igLayoutManager` control is commonly done upon the initialization of the control.

When using the Ignite UI for MVC, it is necessary to assign event handlers at run-time because you cannot define event handlers within the HTML helper.

jQuery supports the following methods for assigning event handlers:

- bind()
- delegate()
- live()
- on()

The `igLayoutManager` supports the following events:

- <ApiLink type="igLayoutManager" member="events:itemRendering" pkg="core" label="itemRendering" /> –fired after an item has been rendered in the container the items
- <ApiLink type="igLayoutManager" member="events:itemRendered" pkg="core" label="itemRendered" /> –fired after all items are rendered
- <ApiLink type="igLayoutManager" member="events:rendered" pkg="core" label="rendered" /> –fired before an item is going to accommodate 100% of the container's width or height

For details on how to handle events, refer to the [Using Events in Ignite UI for jQuery](./using-events-in-igniteui-for-jquery.mdx) topic.

## <a id="example-jquery" />Code Example: Handling the itemRendered Event Upon Initialization in jQuery

### Description

This example assigns an event handling function to the <ApiLink type="igLayoutManager" member="events:itemRendered" pkg="core" label="itemRendered" /> event upon initialization in jQuery.

### Code

**In JavaScript:**

```js
$(".selector").igLayoutManager({
    itemRendered: function (evt, ui) {
        // Handle event
    }
});
```

## <a id="example-asp-net" />Code Example: Handling the itemRendered Event Upon Initialization in ASP.NET MVC

### Description

This example assigns an event handling function to the <ApiLink type="igLayoutManager" member="events:itemRendered" pkg="core" label="itemRendered" /> event upon initialization using the Ignite UI for MVC.

### Code

**In Razor (MVC):**

```razor
@(Html.Infragistics().LayoutManager()
        .AddClientEvent("iglayoutmanageritemrendered", "itemRenderedHandler")
        .Render());
```
