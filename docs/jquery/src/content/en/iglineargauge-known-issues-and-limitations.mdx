## igLinearGauge

### <a id="single-needle-supported" />Only one needle supported

The igLinearGauge control supports only one needle.

<DocsAside type="note" title="Workaround">
  The effect of displaying multiple needles can be achieved by overlaying several instances of the control.
</DocsAside>

### <a id="no-collisions-detection" />No label collisions detection

The `igLinearGauge` control does not provide means for detecting label collisions. As a result, when the space to visualize the labels is not sufficient, label collisions may occur.

<DocsAside type="note" title="Workaround">
  Make sure that in the container of the control there is sufficient space to display the labels properly.
</DocsAside>
