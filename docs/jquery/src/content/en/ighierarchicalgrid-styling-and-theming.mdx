# Styling igHierarchicalGrid

## Topic Overview

### Purpose

This topic demonstrates how to style the igHierarchicalGrid™ using themes, the Theme Switcher tool, and its internal animation properties.

## Introduction

All the jQuery controls use the jQuery UI CSS Framework class conventions. The igHierarchicalGrid and all its features also are styled following these standards. That’s why you can easily integrate the Hierarchical Grid with third-part tools for styling controls, like Theme Switcher. In this topic you will also learn how to use the available animation properties of the igHierarchicalGrid, but first which are the needed resource you have to include so that control displays properly.

## Styling Using Themes

### Required CSS and Themes

The Ignite UI for jQuery™ Hierarchical grid, like other jQuery widgets, utilizes the jQuery UI CSS Framework for styling. Included in Ignite UI for jQuery are custom jQuery UI themes called Infragistics and Metro. These themes provide a professional and attractive design to all Infragistics and standard jQuery UI widgets.

In addition to the Infragistics and Metro themes, there is a structure directory, which is required for the basic CSS layout of the Infragistics widgets.

### Adding Required Themes to a Website

The Infragistics and Metro themes are located in the css folder of the Ignite UI for jQuery npm package (see [Using Ignite UI for jQuery npm packages](./using-ignite-ui-npm-packages.mdx)). To add the themes to your application, copy the whole css folder (including structure and themes directories) into your site’s location.

<DocsAside type="note">
  When using Infragistics Loader, the folder structure must be preserved. Thus the loader will work as expected. If some of the themes are not used they can be deleted, but the structure should remain the same.
</DocsAside>

## Infragistics and Metro Themes

The Infragistics Theme is a custom theme which includes all of the styles typically found in a jQuery UI theme. This theme may be replaced by a different theme but for the jQuery widgets to display correctly a reference to file `{IG Resources root}/css/structure/infragistics.css` is required..

Metro theme is implementation of the clean, modern and fast Metro design language. It has the same requirements for `{IG Resources root}/css/structure/infragistics.css` like Infragistics theme.

When using a theme other than the Infragistics (or Metro) theme, the igHierarchicalGrid has some additional styling points that may need customization to achieve a complete design (depending on the igHierarchicalGrid’s enabled features and theme).

The igHierarchicalGrid control requires having a link to the stylesheet of a standard jQuery UI theme. For the IG Theme, you must include reference to the theme’s stylesheet in the page:

#### Listing 1: Manual CSS reference to Infragistics theme

**In HTML:**

```html
<link
    href="css/themes/infragistics/infragistics.theme.css"
    rel="stylesheet"
    type="text/css"
/>
<link
    href="css/structure/modules/infragistics.ui.grid.css"
    rel="stylesheet"
    type="text/css"
/>
```

#### Listing 2: CSS reference to Infragistics theme in ASP.NET MVC

**In Razor:**

```razor
@using Infragistics.Web.Mvc
<!DOCTYPE html>
<html>
<head>
<link
    href="@Url.Content("~/css/themes/infragistics/infragistics.theme.css")"
    rel="stylesheet"
    type="text/css" />
<link
    href="@Url.Content("~/css/structure/modules/infragistics.ui.grid.css")"
    rel="stylesheet"
    type="text/css" />
```

### Changing the colors dynamically

Because the igHierarchicalGrid follows the convention of the jQuery UI CSS Framework, you can apply the Theme Switcher tool to change the colors IgHierarchicalGrid dynamically. The Theme Switcher is a third party tool that can style controls which use the jQuery UI CSS Framework class conventions (See Theme Switcher for details.) Such a control is also the Hierarchical Grid.

## Using Animations

### Animation reference

The IgHierarchicalGrid has a set of properties that allow you to modify the expand and collapse animation, as well as change the text the tooltip displays (in both expanded and collapsed states. The table below provides a reference for the animation management properties for both jQuery and MVC.

| jQuery Property                                                                                                            | MVC Property                                                                                             | Description                                       |
| -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| <ApiLink type="igHierarchicalGrid" member="options:expandCollapseAnimations" pkg="core" label="expandCollapseAnimation" /> | <ApiLink type="GridModel" member="ExpandCollapseAnimations" pkg="mvc" label="ExpandCollapseAnimation" /> | Enables/disables the expand/collapse animation.   |
| <ApiLink type="igHierarchicalGrid" member="options:animationDuration" pkg="core" label="animationDuration" />              | <ApiLink type="GridModel" member="AnimationDuration" pkg="mvc" label="AnimationDuration" />              | Sets the length of the animation in milliseconds. |

| <ApiLink type="igHierarchicalGrid" member="options:locale.collapseTooltip" pkg="core" label="collapseTooltip" />           | <ApiLink type="GridModel" member="CollapseTooltip" pkg="mvc" label="CollapseTooltip" />                  | Tooltip upon hovering over an collapsed cell.     |

### Animation code example

The code example below demonstrates how to set the animation properties of the igHierarchicalGrid. The following picture shows an expand animation in progress.

<Image src={imgIgHierarchicalGridStylingAndTheming01} alt="igHierarchicalGrid with a child grid sliding open under the first row and a custom expand tooltip on the button" />

In jQuery

```js
$("#grid1").igHierarchicalGrid({
    expandCollapseAnimations: true,
    animationDuration: 1000,
    expandTooltip: "Custom expand tooltip",
    collapseTooltip: "Custom collapse tooltip"
});
```

In MVC

```razor
@(Html.Infragistics()
    .Grid(Model)
    .ID("grid1")
    .ExpandCollapseAnimations(true)
    .AnimationDuration(1000)
    .ExpandTooltip("Custom expand Text")
    .CollapseTooltip("Custom collapse Text")
    .DataBind()
    .Render())
```
