## Enable and Configure igDialog Header

The `igDialog` API proposes several API properties for modifying its header.

### Property Settings

The following table maps the desired header features to property settings:

| In order to:                           | Use this property:                                                                                             | And set it to: |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------- | -------------- |
| Show the igDialog header               | <ApiLink type="igDialog" member="options:showHeader" pkg="core" label="showHeader" />                          | true           |
| Set the igDialog header title          | <ApiLink type="igDialog" member="options:headerText" pkg="core" label="headerText" />                          | “HEADER”       |
| Set the igDialog header image          | <ApiLink type="igDialog" member="options:imageClass" pkg="core" label="imageClass" />                          | “clsImage”     |
| Set the igDialog close button title    | <ApiLink type="igDialog" member="options:locale.closeButtonTitle" pkg="core" label="closeButtonTitle" />       | “X”            |
| Set the igDialog minimize button title | <ApiLink type="igDialog" member="options:locale.minimizeButtonTitle" pkg="core" label="minimizeButtonTitle" /> | “MIN”          |
| Set the igDialog maximize button title | <ApiLink type="igDialog" member="options:locale.maximizeButtonTitle" pkg="core" label="maximizeButtonTitle" /> | “MAX”          |
| Set the igDialog pin button title      | <ApiLink type="igDialog" member="options:locale.pinButtonTitle" pkg="core" label="pinButtonTitle" />           | “PIN”          |
| Set the igDialog unpin button title    | <ApiLink type="igDialog" member="options:locale.unpinButtonTitle" pkg="core" label="unpinButtonTitle" />       | “UNPIN”        |
| Set the igDialog restore button title  | <ApiLink type="igDialog" member="options:locale.restoreButtonTitle" pkg="core" label="restoreButtonTitle" />   | “RESTORE”      |

## Enable and Configure igDialog Footer

The `igDialog` API proposes two API properties for modifying its footer.

### Property Settings

The following table maps the desired header features to property settings:

| In order to:                    | Use this property:                                                                    | And set it to: |
| ------------------------------- | ------------------------------------------------------------------------------------- | -------------- |
| Show the `igDialog` footer      | <ApiLink type="igDialog" member="options:showFooter" pkg="core" label="showFooter" /> | true           |
| Set the `igDialog` footer title | <ApiLink type="igDialog" member="options:footerText" pkg="core" label="footerText" /> | “FOOTER”       |
