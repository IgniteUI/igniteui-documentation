# Method Reference (igDialog)

## Topic Overview

### Purpose

The topic that introduces the user to the igDialog™ control’s methods.

## Method Reference

The following table summarizes the purpose and functionality of the igDialog control’s featured methods:

| Method                                                                                  | Description                                                                                                                                                                                |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <ApiLink type="igDialog" member="methods:state" pkg="core" label="state" />             | Gets the state of the editor.                                                                                                                                                              |
| <ApiLink type="igDialog" member="methods:mainElement" pkg="core" label="mainElement" /> | Gets the reference to a dynamically created DIV element, which represents dialog.                                                                                                          |
| <ApiLink type="igDialog" member="methods:content" pkg="core" label="content" />         | Retrieves the `igDialog` content container or sets its content to be the new content provided. This is the inner container of the dialog window excluding headers, resizing handlers, etc. |
| <ApiLink type="igDialog" member="methods:close" pkg="core" label="close" />             | Closes the `igDialog`, if it is opened.                                                                                                                                                    |
| <ApiLink type="igDialog" member="methods:open" pkg="core" label="open" />               | Opens the `igDialog`, if it is closed.                                                                                                                                                     |
| <ApiLink type="igDialog" member="methods:minimize" pkg="core" label="minimize" />       | Minimizes the `igDialog`, if it is opened.                                                                                                                                                 |
| <ApiLink type="igDialog" member="methods:maximize" pkg="core" label="maximize" />       | Maximizes the `igDialog`, if it is opened.                                                                                                                                                 |
| <ApiLink type="igDialog" member="methods:pin" pkg="core" label="pin" />                 | Pins the `igDialog`, if it is not pinned.                                                                                                                                                  |
| <ApiLink type="igDialog" member="methods:unpin" pkg="core" label="unpin" />             | Unpins the `igDialog`, if it is pinned.                                                                                                                                                    |
| <ApiLink type="igDialog" member="methods:getTopModal" pkg="core" label="getTopModal" /> | Gets reference to the top modal dialog.                                                                                                                                                    |
| <ApiLink type="igDialog" member="methods:isTopModal" pkg="core" label="isTopModal" />   | Returns if dialog is modal and is currently active.                                                                                                                                        |
| <ApiLink type="igDialog" member="methods:moveToTop" pkg="core" label="moveToTop" />     | Moves dialog to the top.                                                                                                                                                                   |
| <ApiLink type="igDialog" member="methods:destroy" pkg="core" label="destroy" />         | Destroys the `igDialog` control.                                                                                                                                                           |
