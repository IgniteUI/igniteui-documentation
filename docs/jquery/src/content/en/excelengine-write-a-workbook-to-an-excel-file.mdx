# Write a Workbook to an Excel File

After setting all options and cell values, the last thing you need to do with your workbook is write it to a file so it can be opened in Microsoft® Excel®. This is easily performed with the <ApiLink type="Workbook" member="Save" pkg="documents-excel" label="Save" /> method of <ApiLink type="Workbook" pkg="documents-excel" label="Workbook" /> object. You can write the workbook to a stream or have it automatically create an xls file for itself.

<DocsAside type="note">
  Before saving a workbook, it must contain at least one visible worksheet; otherwise, an exception will be thrown when the Save method is called.
</DocsAside>

The following code shows how to write your workbook to a file once you are done creating it.

**In Visual Basic:**

```vb
workbook.Save("C:Orders.xls")
```

**In C#:**

```csharp
workbook.Save( "C:Orders.xls" );
```
