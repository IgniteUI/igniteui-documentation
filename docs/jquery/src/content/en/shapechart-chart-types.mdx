# Chart Types

## Overview

In order to select how data should be displayed it is enough to set the igShapeChart property of this chart. Below are all of the types that the Shape Chart supports.

Special case is the `Auto` setting of that property. If `Auto` is used the chart will analyze assigned data and will assign the most suitable chart type.

The default value of that property is determined by the size of the underlying ItemsSource bound to the category chart.  

## Supported Chart Types

<div class="document-table-container">
  | Property Value | Description                                                                                                                | Example                                           |
  | -------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
  | `Area`         | Specifies area chart with colored surface based on a triangulation of X/Y data with numeric values assigned to each point. | <Image src={imgShapechartArea01} alt="igShapeChart Area chart with a rectangle shaded from light to dark purple from left to right" />        |
  | `Bubble`       | Specifies bubble chart with proportional markers at X/Y data                                                               | <Image src={imgShapechartBubble01} alt="igShapeChart Bubble chart with two small and two large circle markers sized by value" />      |
  | `Contour`      | Specifies area chart with colored lines based on a triangulation of X/Y data with numeric values assigned to each point.   | <Image src={imgShapechartContour01} alt="igShapeChart Contour chart with diagonal purple contour lines filling a rectangular region" />     |
  | `HighDensity`  | Specifies high density chart with colored bitmap pixels at X/Y data based on density of nearby points                      | <Image src={imgShapechartHighdensity01} alt="igShapeChart HighDensity chart with four dense clusters of purple points, darkest at their centers" /> |
  | `Line`         | Specifies line chart with small markers at X/Y data and connected with lines                                               | <Image src={imgShapechartLine01} alt="igShapeChart Line chart with two series of markers connected by straight lines, purple circles and green triangles" />        |
  | `Point`        | Specifies point chart with small markers at X/Y data                                                                       | <Image src={imgShapechartPoint01} alt="igShapeChart Point chart with four purple circle markers and four green triangle markers" />       |
  | `Polygon`      | Specifies polygon chart with polygons defined by X/Y data                                                                  | <Image src={imgShapechartPolygon01} alt="igShapeChart Polygon chart with four filled purple rectangles" />     |
  | `Polyline`     | Specifies polyline chart with polylines defined by X/Y data                                                                | <Image src={imgShapechartPolyline01} alt="igShapeChart Polyline chart with four rectangles drawn as purple outlines" />    |
  | `Spline`       | Specifies spline chart with small markers at X/Y data and connected with splines                                           | <Image src={imgShapechartSpline01} alt="igShapeChart Spline chart with two series of markers connected by curved lines, purple circles and green triangles" />      |
  | `Auto`         | Specifies automatic selection of chart type based on suggestion from internal Data Adapter.                                |                                                   |
</div>
