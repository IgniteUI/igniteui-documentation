# Report Graphics

Report graphics give oomph to your reports through several graphical elements such as Brushes, Colors, Fonts, and Images. Use report graphics to augment layout elements. For example, use a brush and pen to color the background and borders of an element, respectively. You can also add color and modify fonts on [pattern content](./documentengine-pattern-content.mdx "Explains the available pattern content items available in the document engine.") such as Tables, Lists, and Text. Any layout or content element can by affected by report graphics in some way or another.
