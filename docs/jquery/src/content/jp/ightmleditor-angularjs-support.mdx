# AngularJS サポート (igHtmlEditor)

## トピックの概要

本トピックは、AngularJS で `igHtmlEditor` を構成する方法について説明します。各コントロールは、対応する AngularJS ディレクティブがあり、`igHtmlEditor` も同様です。AngularJS `igHtmlEditor`　ディレクティブの概要です。

### 要件

このサンプルを実行するために以下が必要です。

- 必要となる Ignite UI for jQuery の JavaScript と CSS ファイル
- Ignite UI AngularJS ディレクティブ

### 詳細

サンプルでは、`igHtmlEditor` が AngularJS ディレクティブで初期化されています。 `igHtmlEditor` のデータソースは AngularJS コントローラーの変数に保存されます。データを保持する同じ変数は HTML `textarea` にバインドされます。データを `textarea` から更新する場合、`igHtmlEditor` のコンテンツが直ちに更新されます。
