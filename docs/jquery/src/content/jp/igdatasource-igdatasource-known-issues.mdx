# 既知の問題と制限 (igDataSource)

## 既知の問題

指定された任意の入力 XML で使用する名前空間は 1 つだけです。複数の名前空間は XPath 経由で移動できないため、複数の名前空間を使用するとデータ変換が失敗するために、この制限があります。
