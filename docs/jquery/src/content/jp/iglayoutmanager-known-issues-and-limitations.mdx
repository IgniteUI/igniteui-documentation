| 問題                                                          | 説明                                                                                          | 状態                                 |

| Grid と Border レイアウト内の項目は、IE 7 と重複しています                      | IE 7 は box-sizing:border-box をサポートしていません。この制約のため、Grid レイアウトと Border レイアウトの重複が発生します。         | <Image src={imgNegative} alt="既知の回避策はありません" /> |
| [スクロールバーのあるグリッド レイアウトの項目の幅が、IE9 で正しく表示されません。](#grid-layout) | IE9 で、position: absolute, box-sizing: border-box を設定している場合、スクロールバーを持つ要素の幅を正しく計算できない問題があります。 | <Image src={imgPositive} alt="回避策" /> |

### <a id="grid-layout" />スクロールバーのあるグリッド レイアウトの項目の幅が、IE9 で正しく表示されません。

問題を回避するには、 IE9 で項目でスクロールバーを使用しないよう設定します。スタイルを `.ig-layout-item {overflow: hidden}` に設定します。
