# Excel ファイルから数式の値を取得

Formula で表現された Excel の Cell の評価した値を取得するには、単純に <ApiLink type="WorksheetCell" pkg="documents-excel" label="WorksheetCell" /> の <ApiLink type="WorksheetCell" member="Value" pkg="documents-excel" label="Value" /> プロパティにアクセスします。

以下のコード例は、Excel 数式によって移植される特定の Excel ワークシート セルのアクセス方法を示します。

**Visual Basic の場合:**

```vb
lblValue.Text = theWorksheet.Rows[1].Cells[4].Value;
```

**C# の場合:**

```csharp
lblValue.Text = theWorksheet.Rows[1].Cells[4].Value;
```
