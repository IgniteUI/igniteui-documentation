以下のコードはこの例を実装します。

**HTML の場合:**

```html
<head>
    ...
    <script type="text/jscript">
         $(function () {
           $("#barcode").igQRCodeBarcode({
                 width: "150px",
                 height: "150px",
                 data: "http://www.infragistics.com",
                 backingBrush: "yellow",
                 barBrush: "blue",
                 backingStrokeThickness:"5",
                 backingOutline: "green"
            });
        });
    </script>
</head>
<body>
    <div id="barcode"></div>
</body>
```
