## パフォーマンス バーの構成

#### パフォーマンス バーの外観構成の概要

パフォーマンス バーはスケール範囲の先頭から開始しなければなりません。終了位置のみ構成可能です。終了位置でバーの長さを効果的に構成できます。終了位置は <ApiLink type="igBulletGraph" member="options:value" pkg="core" label="value" /> プロパティで処理されます。

スケール全域のディメンションでの位置は、<ApiLink type="igBulletGraph" member="options:valueInnerExtent" pkg="core" label="valueInnerExtent" /> および <ApiLink type="igBulletGraph" member="options:valueOuterExtent" pkg="core" label="valueOuterExtent" /> プロパティにより、グラフ領域の端に対して構成できます。パフォーマンス バーの位置を構成すると幅も定義されます。

<Image src={imgIgBulletGraphConfiguringThePerformanceBar1} alt="" />

バーのルック アンド フィールは、各プロパティ (<ApiLink type="igBulletGraph" member="options:valueBrush" pkg="core" label="valueBrush" />、<ApiLink type="igBulletGraph" member="options:valueOutline" pkg="core" label="valueOutline" /> および <ApiLink type="igBulletGraph" member="options:valueStrokeThickness" pkg="core" label="valueStrokeThickness" />) を使用して塗りつぶし色、境界線の色および境界線の線幅をカスタマイズできます。

### 例

以下のスクリーンショットは、以下の設定の結果 `igBulletGraph` の外観がどのようになるか示しています。

| プロパティ                                                                                                          | 値           |
| -------------------------------------------------------------------------------------------------------------- | ----------- |
| <ApiLink type="igBulletGraph" member="options:value" pkg="core" label="value" />                               | *“85”*      |
| <ApiLink type="igBulletGraph" member="options:valueBrush" pkg="core" label="valueBrush" />                     | *'#FFA500'* |
| <ApiLink type="igBulletGraph" member="options:valueInnerExtent" pkg="core" label="valueInnerExtent" />         | *“0.3”*     |
| <ApiLink type="igBulletGraph" member="options:valueOuterExtent" pkg="core" label="valueOuterExtent" />         | *“0.8”*     |
| <ApiLink type="igBulletGraph" member="options:valueOutline" pkg="core" label="valueOutline" />                 | *'#A52A2A'* |
| <ApiLink type="igBulletGraph" member="options:valueStrokeThickness" pkg="core" label="valueStrokeThickness" /> | *“3”*       |

<Image src={imgIgBulletGraphConfiguringThePerformanceBar2} alt="" />

以下のコードはこの例を実装します。

**JavaScript の場合:**

```js
$(function () {
    $("#bulletGraph").igBulletGraph({
        width: "300",
        height: "100",
        value: "85",
        valueBrush: "#FFA500",
        valueInnerExtent: "0.3",
        valueOuterExtent: "0.8",
        valueOutline: "A52A2A",
        valueStrokeThickness: "3"
    });
});
```
