# Word 文書の作成

このトピックは、forward-only の <ApiLink type="WordDocumentWriter" pkg="documents-io" label="WordDocumentWriter" /> ストリーマー オブジェクトを使用して、Word 文書を作成する方法を示します。`WordDocumentWriter` オブジェクトの静的な Create メソッドは、新しい Word 文書を作成します。

以下のスクリーンショットは、テキストとハイパーリンクで作成された Word 文書を表示します。

<Image src={imgWordCreateAWordDocument01} alt="「段落とトピック センテンス」の行とその下のハイパーリンクを持つ Word 文書" />

`Author`、`Title`、`Subject` などのドキュメントのさまざまなプロパティは、`WordDocumentWriter` オブジェクトの <ApiLink type="WordDocumentWriter" member="DocumentProperties" pkg="documents-io" label="DocumentProperties" /> プロパティを使用して設定できます。Office ボタンをクリックして、\[準備] > \[プロパティ] セクションを指定することによって、Word 2007 でこれらの情報にアクセスできます。Word 2010 で同様に、\[ファイル] タブをクリックすることによって、Backstage ビューの右側からドキュメント プロパティにアクセスできます。

Word 文書への書き出しを開始するには、<ApiLink type="WordDocumentWriter" member="StartDocument" pkg="documents-io" label="StartDocument" /> メソッドを使用し、これは <ApiLink type="WordDocumentWriter" member="EndDocument" pkg="documents-io" label="EndDocument" /> メソッドへの対応する呼び出しとバランスを取らなければなりません。

Paragraph は揃えて配置またはインデントが可能なテキスト ブロックを表示する機能を提供します。段落を始めるには <ApiLink type="WordDocumentWriter" member="StartParagraph" pkg="documents-io" label="StartParagraph" /> メソッドを使用します。<ApiLink type="WordDocumentWriter" member="AddTextRun" pkg="documents-io" label="AddTextRun" /> メソッドはコンテンツを段落に追加する方法を提供します。コンテンツが追加されたら、段落は <ApiLink type="WordDocumentWriter" member="EndParagraph" pkg="documents-io" label="EndParagraph" /> メソッドを使用して閉じなければなりません。

<DocsAside type="note" title="注">
  `Infragistics.Web.Documents.IO` アセンブリへの参照が以下のコードに必要とされます。
</DocsAside>

<DocsAside type="note" title="注">
  Word 文書を作成するために `WordDocumentWriter` オブジェクトを使用する時には、Dispose メソッドまたは Close メソッドのいずれかを使用してストリーマー オブジェクトを破棄または閉じなければなりません。
</DocsAside>

**C# の場合:**

```csharp
using Infragistics.Documents.Word;

// Create a new instance of the WordDocumentWriter class
// using the static 'Create' method.
WordDocumentWriter docWriter = WordDocumentWriter.Create(@"C:\TestWordDoc.docx");
// Use inches as the unit of measure
docWriter.Unit = UnitOfMeasurement.Inch;
// Set the document properties, such as title, author, etc.
docWriter.DocumentProperties.Title = "Sample Document";
docWriter.DocumentProperties.Author = string.Format("Infragistics.{0}",
    SystemInformation.UserName);
// Start the document...note that each call to
// StartDocument must be balanced with a corresponding call to EndDocument.
docWriter.StartDocument();
//  Start a paragraph
docWriter.StartParagraph();
//  Add a text run for the title
docWriter.AddTextRun("Paragraphs and Topic Sentences");
// Add a new line
docWriter.AddNewLine();
//  Add a Hyperlink
docWriter.AddHyperlink("http://www.infragistics.com", "Infragistics Inc.");
//  End the paragraph
docWriter.EndParagraph();
//  End Document
docWriter.EndDocument();
// Close the writer
docWriter.Close();
```
