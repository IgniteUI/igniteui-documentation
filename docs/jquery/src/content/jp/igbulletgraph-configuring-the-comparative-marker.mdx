## 比較マーカーの構成

#### 比較マーカー構成の概要

比較マーカーは、パフォーマンス バーが示す値と比較された値をスケールに表示します。比較値は、目標売上高などの目標値または値の超過限度を示す制限値 (体温計の37℃の発熱の目安) にすることができます。

比較目盛マーカーが示す値およびスケール上の位置は、<ApiLink type="igBulletGraph" member="options:targetValue" pkg="core" label="targetValue" /> プロパティで設定します。比較マーカーは、そのスケール全域で位置やサイズ (<ApiLink type="igBulletGraph" member="options:targetValueInnerExtent" pkg="core" label="targetValueInnerExtent" /> および <ApiLink type="igBulletGraph" member="options:targetValueOuterExtent" pkg="core" label="targetValueOuterExtent" />)、幅 (<ApiLink type="igBulletGraph" member="options:targetValueBreadth" pkg="core" label="targetValueBreadth" />) およびルック アンド フィール (塗りつぶし色 - <ApiLink type="igBulletGraph" member="options:targetValueBrush" pkg="core" label="targetValueBrush" />、境界線の線幅 - <ApiLink type="igBulletGraph" member="options:targetValueStrokeThickness" pkg="core" label="targetValueStrokeThickness" />、境界線の色 - <ApiLink type="igBulletGraph" member="options:targetValueOutline" pkg="core" label="targetValueOutline" />) に関して各プロパティでカスタマイズできます。

以下のコードはこの例を実装します。

**JavaScript の場合:**

```js
$(function () {
    $("#bulletGraph").igBulletGraph({
        height: "70",
        width: "300",
        targetValue: "70",
        targetValueBreadth: "10",
        targetValueBrush: "#FFFF00",
        targetValueOutline: "#006400",
        targetValueStrokeThickness: "2",
        targetValueInnerExtent: "0.3",
        targetValueOuterExtent: "0.8"
    });
});
```
