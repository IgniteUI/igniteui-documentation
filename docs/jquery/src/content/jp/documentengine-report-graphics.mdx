# レポート グラフィックス

レポート グラフィックスは、Brushes、Colors、Fonts、および Images などのいくつかのグラフィックス要素によってレポートを魅力的なものにします。レポート グラフィックスを使用して、レイアウト 要素を強化します。たとえば、ブラシとペンを使用して、要素の背景と境界線にそれぞれ色を付けます。Tables、Lists、Text などの[パターン コンテンツ](./documentengine-pattern-content.mdx)にカラーを追加してフォントを変更することも可能です。任意のレイアウトまたはコンテンツ 要素はレポート グラフィックスによって何らかの影響を受ける場合があります。

レポート グラフィックスの詳細は以下のリンクをクリックしてください。

- [ブラシ](./documentengine-brushes.mdx)
- [キャンバス](./documentengine-canvas.mdx)
- [色](./documentengine-colors.mdx)
- [フォント](./documentengine-fonts.mdx)
- [ペン](./documentengine-pens.mdx)
- [図形](./documentengine-shapes.mdx)
