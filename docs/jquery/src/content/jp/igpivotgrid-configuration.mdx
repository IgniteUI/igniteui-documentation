# igPivotGrid の構成

## トピックの概要

### 目的

このトピックでは、`igPivotGrid`™ コントロールを構成する方法を説明します。

## 基本構成

次の表に、ピボット表にデータを表示するために定義する必要のある基本オプションを示します。

igPivotGrid の場合:

| オプション                                                                                    | 説明                                                           |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| <ApiLink type="igPivotGrid" member="options:dataSource" pkg="core" label="dataSource" /> | $.ig.OlapXmlaDataSource または $.ig.OlapFlatDataSource のインスタンス。 |

**$.ig.OlapXmlaDataSource** コンポーネントは、msmdpump.dll HTTP データ プロバイダーで構成された Microsoft® SQL Server Analysis Services (SSAS) サーバーとのコミュニケーションを処理します。 関連する基本設定は次のとおりです。

| オプション                                                                                                 | 説明                                             |
| ----------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| <ApiLink type="OlapXmlaDataSource" member="options:options.serverUrl" pkg="core" label="serverUrl" /> | XMLA サーバーの URL。                                |
| <ApiLink type="OlapXmlaDataSource" member="options:options.catalog" pkg="core" label="catalog" />     | カタログ名。                                         |
| <ApiLink type="OlapXmlaDataSource" member="options:options.cube" pkg="core" label="cube" />           | データ ソース内のキューブの名前。                              |
| <ApiLink type="OlapXmlaDataSource" member="options:options.rows" pkg="core" label="rows" />           | コンマ (,) で区切られた階層名のリスト。これは、データ ソースの行の階層になります。   |
| <ApiLink type="OlapXmlaDataSource" member="options:options.columns" pkg="core" label="columns" />     | コンマ (,) で区切られた階層名のリスト。これは、データ ソースの列の階層になります。   |
| <ApiLink type="OlapXmlaDataSource" member="options:options.measures" pkg="core" label="measures" />   | コンマ (,) で区切られたメジャー名のリスト。これは、データ ソースのメジャーになります。 |

構成の例を示す次の基本サンプルを参照してください。

- [XMLA データ ソースへのバインド](\{environment:samplesBrowserUrl}/pivot-grid/binding-to-xmla-data-source)

**$.ig.OlapFlatDataSource** コンポーネントは、フラットなデータ コレクション上で多次元の (OLAP のような) 解析を実行します。 関連する基本設定は次のとおりです。

OlapFlatDataSource の場合:

| ------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |

| <ApiLink type="OlapFlatDataSource" member="options:options.metadata" pkg="core" label="metadata" />     | $ .ig.DataSource データの処理命令を含むオブジェクト。                                   |
| <ApiLink type="OlapFlatDataSource" member="options:options.metadata.cube" pkg="core" label="metadata.cube" />                                                                                           | キューブの作成に使用されるメタデータ。                                                   |
| <ApiLink type="OlapFlatDataSource" member="options:options.metadata.cube.measuresDimension" pkg="core" label="metadata.cube.measuresDimension" />                                                                         | メジャーのルート ノードについての情報を提供するオブジェクト。                                       |
| <ApiLink type="OlapFlatDataSource" member="options:options.metadata.cube.dimensions" pkg="core" label="metadata.cube.dimensions" />                                                                                | 次元メタデータ オブジェクトの配列。                                                    |
| <ApiLink type="OlapFlatDataSource" member="options:options.rows" pkg="core" label="rows" />             | コンマ (,) で区切られた階層名のリスト。これは、データ ソースの行の階層になります。                          |
| <ApiLink type="OlapFlatDataSource" member="options:options.columns" pkg="core" label="columns" />       | コンマ (,) で区切られた階層名のリスト。これは、データ ソースの列の階層になります。                          |
| <ApiLink type="OlapFlatDataSource" member="options:options.measures" pkg="core" label="measures" />     | コンマ (,) で区切られたメジャー名のリスト。これは、データ ソースのメジャーになります。                        |

### カスタム要素のドラッグ アンド ドロップ

次の手順では、igPivotGrid でカスタム要素のドラッグ アンド ドロップを実装する方法を示します。

#### 手順

1. Data-type 属性および data-name 属性を持つ要素を定義します。

   データ型は、要素の型に設定する必要があります。次元、階層、メジャーまたはレベル。データ名は関連する値でなければなりません。 たとえば、

   ```html
   <div
       class="ui-igpivot-metadataitem ui-state-default ui-corner-all custom-draggable"
       data-type="Hierarchy"
       data-name="[Seller].[Seller]"
   >
       <span>Hierarchy: Seller</span>
   </div>
   <div
       class="ui-igpivot-metadataitem ui-state-default ui-corner-all custom-draggable"
       data-type="Measure"
       data-name="[Measures].[UnitsSold]"
   >
       <span>Measure: Units Sold</span>
   </div>
   ```

2. jQuery UI の[ドラッグ可能な](https://jqueryui.com/draggable/)インタラクションを使用して、定義された要素をドラッグ可能にします。

このような例を示す次の基本サンプルを参照してください。
