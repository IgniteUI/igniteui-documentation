# 2020 Volume 2 の新機能

このトピックは、Ignite UI™ 2020 Volume 2 リリースの新機能について説明します。

### Ignite UI for Asp.Net Core

Infragistics Ignite UI for Asp.Net Core で ASP.NET Core 5 プロジェクトがサポートされるようになりました。詳細情報は、[Ignite UI for Asp.Net Core の使用](./using-igniteui-controls-in-asp.net-core-project.mdx)トピックを参照してください。

### Ignite UI for Asp.Net Core タグ ヘルパー

Ignite UI for Asp.Net Core タグ ヘルパーで ASP.NET Core 5 プロジェクトがサポートされます。詳細情報は、[Ignite UI for Asp.Net Core タグ ヘルパーの使用](./using-ignite-ui-tag-helpers.mdx)トピックを参照してください。

### Infragistics Documents

Infragistics Documents アセンブリが ASP.NET Core 5 プロジェクトで利用可能になりました。
