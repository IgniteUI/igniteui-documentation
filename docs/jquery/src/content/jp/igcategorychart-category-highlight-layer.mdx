# カテゴリ ハイライト レイヤー

Category Highlight Layer は、カテゴリ上にポインタをホバー時にチャートのカテゴリを強調表示します。

## カテゴリ ハイライト レイヤー

カテゴリ ハイライト レイヤーは、`isCategoryHighlightingEnabled` オプションを true に設定して有効にできます。

以下のコード スニペットは、`igCategoryChart` で Category Highlight Layer を有効にする方法を示します。

*In HTML:*

```html
$(function () { $("chart1").igCategoryChart({ isCategoryHighlightingEnabled:
true }); });
```
