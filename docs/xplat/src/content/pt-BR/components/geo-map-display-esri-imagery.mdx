# {Platform} Exibindo imagens dos mapas da Esri

O `ArcGISOnlineMapImagery` é um serviço gratuito de mapeamento de imagens geográficas criado pela empresa <a href="https://www.esri.com/" target="_blank">Esri</a>. Ele oferece mais de 40 estilos de blocos de imagens geográficas do mundo e alguns blocos temáticos dos EUA. Este serviço de imagens geográficas pode ser acessado diretamente no site <a href="https://services.arcgisonline.com/ArcGIS/rest/services" target="_blank">www.arcgisonline.com</a>.

## Utilitário da Esri
Como alternativa, você pode usar o [EsriUtility](./geo-map-resources-esri.mdx), que define todos os estilos fornecidos pelos servidores de imagens da Esri.

<PlatformBlock for="Angular">

```ts
import { IgxGeographicMapComponent } from 'igniteui-angular-maps';
import { IgxArcGISOnlineMapImagery } from 'igniteui-angular-maps';
import { EsriUtility, EsriStyle } from './EsriUtility';
// ...
public geoMap: IgxGeographicMapComponent;

const tileSource = new IgxArcGISOnlineMapImagery();
tileSource.mapServerUri = EsriUtility.getUri(EsriStyle.WorldOceansMap);

this.geoMap.backgroundContent = tileSource;
```

</PlatformBlock>

<PlatformBlock for="React">

```ts
import { IgrGeographicMap } from 'igniteui-react-maps';
import { IgrArcGISOnlineMapImagery } from 'igniteui-react-maps';
import { EsriUtility, EsriStyle } from './EsriUtility';
// ...
const tileSource = new IgrArcGISOnlineMapImagery();
tileSource.mapServerUri = EsriUtility.getUri(EsriStyle.WorldOceansMap);

const geoMap = new IgrGeographicMap({ name: "geoMap" });
geoMap.backgroundContent = tileSource;
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
import { IgcGeographicMap } from 'igniteui-webcomponents-maps';
import { IgcArcGISOnlineMapImagery } from 'igniteui-webcomponents-maps';
import { EsriUtility, EsriStyle } from './EsriUtility';
// ...

const geoMap = document.getElementById("geoMap") as IgcGeographicMapComponent

```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
@using IgniteUI.Blazor.Controls


<IgbGeographicMap Height="100%" Width="100%"
    Zoomable="true"
    BackgroundContent="EsriImagery" />

protected override void OnInitialized()
{
    IgbArcGISOnlineMapImagery imagery = new IgbArcGISOnlineMapImagery()
    {
        MapServerUri = EsriStyle.WorldOceansMap
    };

    this.EsriImagery = imagery;
}
```

</PlatformBlock>
