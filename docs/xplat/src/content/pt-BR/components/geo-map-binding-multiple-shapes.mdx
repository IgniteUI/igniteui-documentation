# {Platform} Vinculando e sobrepondo vários arquivos de forma

No mapa {ProductName}, você pode adicionar vários objetos de série geográfica para sobrepor alguns arquivos de forma com dados geoespaciais. Por exemplo, `GeographicSymbolSeries` para plotar as localizações geográficas de portos, o `GeographicPolylineSeries` para plotar rotas entre portos e o `GeographicShapeSeries` para plotar as formas dos países.

## {Platform} Exemplo de vinculação e sobreposição de vários arquivos de forma


<Sample src="/maps/geo-map/binding-multiple-shapes" height={500} alt="{Platform} Exemplo de vinculação e sobreposição de vários arquivos de forma" />




Este tópico guia você, passo a passo, até a exibição de várias séries geográficas no componente de mapa. Todas as séries geográficas plotam dados geoespaciais carregados de arquivos de forma usando a classe `ShapefileRecord`. Consulte o tópico [Vinculando arquivos de forma](./geo-map-binding-shp-file.mdx) para mais informações sobre o objeto `ShapefileRecord`.

- `GeographicSymbolSeries` – exibe as localizações das principais cidades
- `GeographicPolylineSeries` – exibe as rotas entre os principais portos
- `GeographicShapeSeries` – exibe as formas dos países do mundo

Você pode usar séries geográficas nas combinações acima ou em outras combinações para plotar os dados desejados.

## Importando componentes

Primeiro, vamos importar os componentes e módulos necessários:

```json-snippet id="shapes" source="/maps/geo-map/binding-multiple-shapes" channel="bindingImports,handlersImports"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "height": "100%",
            "width": "100%",
            "zoomable": true,
            "series": [
                {
                    "type": "GeographicShapeSeries",
                    "name": "polygonSeries",
                    "shapeMemberPath": "points",
                    "shapeFill": "rgb(150, 150, 150)",
                    "shapeStroke": "Black",
                    "shapeStrokeThickness": 1
                },
                {
                    "type": "GeographicPolylineSeries",
                    "name": "lineSeries",
                    "shapeMemberPath": "points",
                    "shapeStroke": "rgba(147, 15, 180, 0.5)",
                    "thickness": 3
                },
                {
                    "type": "GeographicSymbolSeries",
                    "name": "symbolSeries",
                    "longitudeMemberPath": "longitude",
                    "latitudeMemberPath": "latitude",
                    "markerType": "Circle",
                    "markerOutline": "rgb(2, 102, 196)",
                    "markerBrush": "White"
                }
            ]
        }
    },
    "onViewInit": [
        "MapMultipleShapesLoad"
    ]
}
```

## Fundo do mapa

Além disso, talvez você queira ocultar a imagem geográfica do conteúdo de fundo do mapa, se os seus arquivos de forma já fornecerem contexto geográfico suficiente para o seu aplicativo (por exemplo, a forma dos países).

```json-snippet code="allCode"
{
    "type": "GeographicMap",
    "name": "geoMap",
    "height": "100%",
    "width": "100%",
    "backgroundContent": null
}
```
