# Visão geral da biblioteca Excel de {Platform}

A biblioteca Excel {Platform} da Infragistics permite trabalhar com dados de planilha usando objetos de planilha conhecidos do Microsoft® Excel®, como <ApiLink type="Workbook" />, <ApiLink type="Worksheet" />, <ApiLink type="WorksheetCell" label="Cell" />, <ApiLink type="Formula" /> e muitos outros. A biblioteca Excel {Platform} da Infragistics facilita representar os dados do seu aplicativo em uma planilha do Excel, bem como transferir dados do Excel para o seu aplicativo.

## Implementação dos módulos


- **IgxExcelCoreModule** – contém o modelo de objetos e grande parte da infraestrutura do Excel
- **IgxExcelFunctionsModule** – contém a maioria das funções para avaliação de fórmulas, como Sum, Average, Min, Max etc. A ausência desse módulo não causará problemas na interpretação de fórmulas, se a fórmula for calculada. Por exemplo, se você aplicar uma fórmula como "=SUM(A1:A5)" e pedir o Value da célula, receberá um erro #NAME! como retorno. Não é uma exceção lançada - é um objeto que representa um erro específico, já que as fórmulas podem resultar em erros.
- **IgxExcelXlsModule** – contém a lógica de carregamento e salvamento de arquivos do tipo xls (e relacionados), ou seja, os WorkbookFormats relacionados ao Excel 97 a 2003.
- **IgxExcelXlsxModule** – contém a lógica de carregamento e salvamento de arquivos do tipo xlsx (e relacionados), ou seja, os WorkbookFormats relacionados ao Excel 2007 e ao StrictOpenXml.
- **IgxExcelModule** – referencia os outros 4 módulos e, por isso, basicamente garante que toda a funcionalidade seja carregada/disponibilizada.

## Requisitos

Para usar a biblioteca excel {Platform}, você precisa adicionar o pacote NuGet da Biblioteca Excel, desta forma:

```cmd
> dotnet add package IgniteUI.Blazor.Documents.Excel
```

Adicione a seguinte instrução using:

```razor
@using Infragistics.Documents.Excel
```

Se você estiver usando um projeto Blazor WebAssembly (WASM), há algumas etapas extras:

- Adicione uma referência ao script a seguir no arquivo wwwroot/index.html:

```razor
<script src="_content/IgniteUI.Blazor.Documents.Excel/excel.js"></script>
```

- Defina o <ApiLink type="Workbook" member="InProcessRuntime" label="Workbook.InProcessRuntime" /> estático como o runtime atual. Isso pode ser feito usando o código a seguir:

```razor
@using Microsoft.JSInterop

@code {

    [Inject]
    public IJSRuntime Runtime { get; set; }

    protected override void OnInitialized()
    {
        base.OnInitialized();
        Workbook.InProcessRuntime = (IJSInProcessRuntime)this.Runtime;
    }
}
```

<PlatformBlock for="Blazor">

```csharp
protected override void OnInitialized()
{
    var memoryStream = new System.IO.MemoryStream();
    workbook.Save(memoryStream);

    memoryStream.Position = 0;
    var bytes = memoryStream.ToArray();
    this.SaveFile(bytes, "fileName.xlsx", string.Empty);
}

private void SaveFile(byte[] bytes, string fileName, string mime)
{
    if (this.Runtime is WebAssemblyJSRuntime wasmRuntime)
      wasmRuntime.InvokeUnmarshalled<string, string, byte[], bool>("BlazorDownloadFileFast", fileName, mime, bytes);
    else if (this.Runtime is IJSInProcessRuntime inProc)
      inProc.InvokeVoid("BlazorDownloadFile", fileName, mime, bytes);
}
```

</PlatformBlock>

## Gerenciando o heap

Por causa do tamanho da biblioteca Excel, recomenda-se desabilitar a geração de source map.

Modifique `angular.json` definindo a opção `vendorSourceMap` em architect => build => options e em serve => options:

```ts
    "architect": {
        "build": {
          "builder": "...",
          "options": {
            "vendorSourceMap": false,
            "outputPath": "dist",
            "index": "src/index.html",
            "main": "src/main.ts",
            "tsConfig": "src/tsconfig.app.json",
                  // ...
          },
              // ...
        },
        "serve": {
          "builder": "...",
          "options": {
            "vendorSourceMap": false,
            "browserTarget": "my-app:build"
          },
              // ...
        },
        // ...
      }
```
