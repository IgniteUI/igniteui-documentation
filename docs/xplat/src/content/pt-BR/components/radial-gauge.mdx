# Visão geral do {Platform} Radial Gauge

O componente radial gauge do {Platform} oferece vários elementos visuais, como ponteiro, marcas de graduação, faixas e rótulos, para criar um formato e uma escala predefinidos. O `RadialGauge` também tem suporte integrado a transições animadas. Essa animação pode ser facilmente personalizada definindo a propriedade `transitionDuration`.

## Uso

O código a seguir demonstra como criar um radial gauge com um ponteiro e três faixas comparativas na escala.

```json-snippet
{
    "type": "RadialGauge",
    "height": "400px",
    "width": "400px",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 25,
    "interval": 5,
    "ranges": [
        { "type": "RadialGaugeRange", "startValue": 0,  "endValue": 30,  "brush": "red" },
        { "type": "RadialGaugeRange", "startValue": 30, "endValue": 60,  "brush": "yellow" },
        { "type": "RadialGaugeRange", "startValue": 60, "endValue": 100, "brush": "green" }
    ]
}
```


## Fundo

O componente radial gauge vem com uma forma de fundo desenhada atrás da escala, que funciona como plano de fundo do radial gauge.

O elemento de fundo representa o plano de fundo e a borda do componente radial gauge. Ele é sempre o primeiro elemento renderizado, e todos os demais elementos, como ponteiro, rótulos e marcas de graduação, ficam sobrepostos a ele.

O fundo pode ser circular ou ajustado. Um formato circular cria um medidor de círculo de 360 graus, enquanto um formato ajustado cria um segmento de arco preenchido que abrange as propriedades `scaleStartAngle` e `scaleEndAngle`. Isso pode ser definido pela propriedade `backingShape`.

```json-snippet source="/gauges/radial-gauge/backing"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "backingShape": "Fitted",
    "backingBrush": "#FCFCFC",
    "backingOutline": "DodgerBlue",
    "backingOversweep": 5,
    "backingCornerRadius": 10,
    "backingStrokeThickness": 5,
    "backingOuterExtent": 0.8,
    "backingInnerExtent": 0.15,
    "scaleStartAngle": 135,
    "scaleEndAngle": 45
}
```

## Escala

A escala é um elemento visual que destaca toda a faixa de valores do medidor, que pode ser criada informando os valores de `minimumValue` e `maximumValue`. Junto com o fundo, ela define o formato geral do medidor. As propriedades `scaleStartAngle` e `scaleEndAngle` definem os limites do arco da escala, enquanto a propriedade `scaleSweepDirection` especifica se a escala avança no sentido horário ou anti-horário. Você pode personalizar a aparência da escala definindo as propriedades `scaleBrush`, `scaleStartExtent` e `scaleEndExtent`.

```json-snippet source="/gauges/radial-gauge/scale"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "scaleStartAngle": 135,
    "scaleEndAngle": 45,
    "scaleBrush": "DodgerBlue",
    "scaleSweepDirection": "Clockwise",
    "scaleOversweep": 1,
    "scaleOversweepShape": "Fitted",
    "scaleStartExtent": 0.45,
    "scaleEndExtent": 0.575
}
```


<Sample src="/gauges/radial-gauge/scale" height={320} alt="Escala do {Platform} radial gauge" />



## Rótulos e títulos

Os rótulos do radial gauge são elementos visuais que exibem valores numéricos em um intervalo especificado entre os valores das propriedades `minimumValue` e `maximumValue`. Você pode posicionar os rótulos definindo a propriedade `labelExtent` como uma fração, em que 0 representa o centro do medidor e 1 representa a extensão externa do fundo do medidor. Além disso, você pode personalizar os rótulos definindo várias propriedades de estilo, como `fontBrush` e `RadialGauge.FontFamily/RadialGauge.FontSize/RadialGauge.FontStyle/RadialGauge.FontWeight`.

Cada um desses rótulos do ponteiro tem vários atributos de estilo que podem ser aplicados para alterar a fonte, o ângulo, o pincel e a distância em relação ao centro do medidor, como `titleExtent`, `titleAngle`, `SubtitleFontSize`, `highlightLabelBrush`.

```json-snippet source="/gauges/radial-gauge/labels"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "labelInterval": 10,
    "labelExtent": 0.65,
    "font": "11px Verdana",
    "fontBrush": "DodgerBlue"
}
```


<Sample src="/gauges/radial-gauge/labels" height={320} alt="Rótulos do {Platform} radial gauge" />


## Título e subtítulo

As propriedades `titleText` e `subtitleText` estão disponíveis e podem ser usadas para exibir texto personalizado para o ponteiro. Alternativamente, `titleDisplaysValue` e `subtitleDisplaysValue`, quando definidas como true, exibirão o valor do ponteiro e substituirão `titleText` e `subtitleText`. Assim, você pode usar texto personalizado no título e mostrar o valor no subtítulo, e vice-versa.

Se o ponteiro de destaque for exibido, como explicado abaixo, o texto personalizado pode ser mostrado por meio de `highlightLabelText`; caso contrário, `highlightLabelDisplaysValue` pode ser habilitado para exibir o seu valor.

```json-snippet
{
    "type": "RadialGauge",
    "titleText": "Global Sales",
    "subtitleText": "2024"
}
```


## Escalonamento óptico

Os rótulos e títulos do radial gauge podem alterar o seu escalonamento. Para habilitar isso, primeiro defina `opticalScalingEnabled` como true. Depois, você pode definir `opticalScalingSize`, que controla o tamanho em que os rótulos têm 100% de escalonamento óptico. Os rótulos terão fontes maiores quando o tamanho do medidor for maior. Por exemplo, os rótulos terão um tamanho de fonte 200% maior quando essa propriedade for definida como 500 e o tamanho do medidor em px for dobrado, por exemplo para 1000.

## Marcas de escala

As marcas de graduação são linhas finas que irradiam do centro do radial gauge. Há dois tipos de marcas de graduação: principais e secundárias. As marcas principais são exibidas no `RadialGauge.interval` entre as propriedades `minimumValue` e `maximumValue`. Use a propriedade `minorTickCount` para especificar o número de marcas secundárias exibidas entre cada marca principal. Você pode controlar o comprimento das marcas definindo uma fração (entre 0 e 1) nas propriedades `tickStartExtent`, `tickEndExtent`, `minorTickStartExtent` e `minorTickEndExtent`.

```json-snippet source="/gauges/radial-gauge/tickmarks"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "tickStartExtent": 0.45,
    "tickEndExtent": 0.575,
    "tickStrokeThickness": 2,
    "tickBrush": "DodgerBlue",
    "minorTickCount": 4,
    "minorTickStartExtent": 0.575,
    "minorTickEndExtent": 0.5,
    "minorTickStrokeThickness": 1,
    "minorTickBrush": "DarkViolet"
}
```


<Sample src="/gauges/radial-gauge/tickmarks" height={320} alt="Marcas de graduação do {Platform} radial gauge" />



## Faixas

Uma faixa destaca um conjunto de valores contínuos delimitado pelas propriedades `minimumValue` e `maximumValue` especificadas. Você pode adicionar várias faixas ao radial gauge informando seus valores inicial e final. Cada faixa tem algumas propriedades de personalização, como `RadialGaugeRange.brush` e `RadialGaugeRange.outline`. Alternativamente, você pode definir as propriedades `rangeBrushes` e `rangeOutlines` como uma lista de cores para as faixas.

```json-snippet source="/gauges/radial-gauge/ranges"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "rangeBrushes":  [ "red", "yellow", "green" ],
    "rangeOutlines": [ "red", "yellow", "green" ],
    "ranges": [
        { "type": "RadialGaugeRange", "startValue": 5,  "endValue": 15, "brush": "red" },
        { "type": "RadialGaugeRange", "startValue": 15, "endValue": 35, "brush": "yellow" },
        { "type": "RadialGaugeRange", "startValue": 35, "endValue": 45, "brush": "green" }
    ]
}
```


<Sample src="/gauges/radial-gauge/ranges" height={320} alt="Faixas do {Platform} radial gauge" />



## Ponteiro

Os ponteiros do radial gauge são elementos visuais usados para indicar o valor definido do medidor. Os ponteiros estão disponíveis em um dos vários formatos predefinidos. O ponteiro pode ter um formato de pivô, posicionado no centro do medidor. O formato do pivô também assume um dos formatos predefinidos. Formatos de pivô que incluem um overlay ou um underlay podem ter um pincel de pivô separado aplicado ao formato.

Os formatos e as tampas de ponteiro compatíveis são definidos pelas propriedades `needleShape` e `needlePivotShape`.

Você pode habilitar um modo interativo do medidor (usando a propriedade `isNeedleDraggingEnabled`), e o usuário final poderá alterar o valor arrastando o ponteiro entre os valores das propriedades `minimumValue` e `maximumValue`.

```json-snippet source="/gauges/radial-gauge/needle"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "isNeedleDraggingEnabled": true,
    "isNeedleDraggingConstrained": true,
    "needleShape": "NeedleWithBulb",
    "needleBrush": "DodgerBlue",
    "needleOutline": "DodgerBlue",
    "needleEndExtent": 0.475,
    "needleStrokeThickness": 1,
    "needlePivotShape": "CircleOverlay",
    "needlePivotBrush": "#9F9FA0",
    "needlePivotOutline": "#9F9FA0",
    "needlePivotWidthRatio": 0.2,
    "needlePivotStrokeThickness": 1
}
```


<Sample src="/gauges/radial-gauge/needle" height={320} alt="Ponteiro do {Platform} radial gauge" />


## Destacar o ponteiro

O radial gauge pode ser modificado para mostrar um segundo ponteiro. Isso fará com que a `RadialGauge.value` do ponteiro principal apareça com menor opacidade. Para habilitar isso, primeiro defina `highlightValueDisplayMode` como Overlay e depois aplique um `highlightValue`.

```json-snippet source="/gauges/radial-gauge/highlight-needle"
{
    "type": "RadialGauge",
    "height": "100%",
    "width": "100%",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 30,
    "interval": 10,
    "labelInterval": 10,
    "labelExtent": 0.65,
    "isHighlightNeedleDraggingEnabled": true,
    "highlightValueDisplayMode": "Overlay",
    "highlightValue": 50,
    "highlightLabelDisplaysValue": true,
    "highlightLabelSnapsToNeedlePivot": true
}
```
