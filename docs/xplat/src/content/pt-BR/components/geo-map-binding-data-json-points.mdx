# {Platform} Vinculando arquivos JSON com localizações geográficas

Com o mapa {ProductName}, você pode plotar dados geográficos carregados de vários tipos de arquivo. Por exemplo, você pode carregar localizações geográficas de um arquivo JavaScript Object Notation (JSON).

## Exemplo de dados
Aqui está um exemplo de dados de um arquivo JSON:

```json
[
    { "cap": false, "pop":  0.47, "lat":  68.96, "lon":   33.09, "country": "Russia" ,    "name": "Murmansk" },
    { "cap": true,  "pop":  1.65, "lat":  53.90, "lon":   27.58, "country": "Byelarus" ,  "name": "Minsk" },
    { "cap": true,  "pop":  0.58, "lat":  54.69, "lon":   25.28, "country": "Lithuania" , "name": "Vilnius" },
 // ...
]
```

## Trecho de código
O código a seguir carrega e vincula <PlatformBlock for="Web">`GeographicHighDensityScatterSeries`</PlatformBlock><PlatformBlock for="WinUI, Uno">`GeographicSymbolSeries`</PlatformBlock> no componente de mapa a um array de objetos criado a partir do arquivo JSON carregado com as localizações geográficas:

```json-snippet id="jsonMap" source="/maps/geo-map/binding-data-json-points"
{
    "descriptions": {
        "content": { "type": "GeographicMap", "name": "geoMap", "height": "100%", "width": "100%", "zoomable": true }
    },
    "onViewInit": [ "MapBindingDataJsonPointsOnViewInit" ]
}
```
