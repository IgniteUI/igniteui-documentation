# {Platform} Trabalhando com sparklines

A biblioteca Excel {Platform} da Infragistics oferece suporte à adição de sparklines a uma planilha do Excel. Eles podem ser usados para mostrar representações visuais simples das tendências dos dados em uma região de células de dados da sua planilha. Por exemplo, se você quiser ver os seus dados do Excel em uma determinada região de células visualizados como um gráfico sparkline simples de colunas ou linhas, este recurso pode ajudar você a conseguir isso.

## Sparklines compatíveis
A seguir está uma lista dos tipos de sparkline predefinidos compatíveis.

- Linha
- Coluna
- Empilhado (Vitória/Derrota)

O código a seguir demonstra como adicionar programaticamente sparklines a uma planilha, por meio da coleção sparklineGroups:

```ts
var workbook: Workbook;
var sheet1 = workbook.worksheets().add("Sparklines");
var sheet2 = workbook.worksheets().add("Data");
sheet1.sparklineGroups().add(SparklineType.Line, "Sparklines!A1:A1", "Data!A2:A11");
sheet1.sparklineGroups().add(SparklineType.Column, "Sparklines!B1:B1", "Data!A2:A11");
workbook.save(workbook, "Sparklines.xlsx");
```
