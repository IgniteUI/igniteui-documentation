# {Platform} Conexões do mundo

Este tópico de recursos apresenta a implementação do utilitário de dados para gerar localizações de aeroportos, rotas de voo e linhas de grade geográficas. Você pode usar essas fontes de dados como ponto de referência para criar os seus próprios dados geográficos. Observe que este utilitário depende dos scripts [WorldUtil](./geo-map-resources-world-util.mdx) e [WorldLocations](./geo-map-resources-world-locations.mdx).

## Trecho de código

```json-snippet source="/maps/geo-map/binding-multiple-sources" channel="WorldConnections"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "series": [
                {
                    "type": "GeographicPolylineSeries",
                    "name": "lineSeries",
                    "dataSourceRef": "WorldFlights",
                    "$dataSourceRef": "+doc:WorldConnections",
                    "shapeMemberPath": "Points"
                }
            ]
        }
    }
}
```
