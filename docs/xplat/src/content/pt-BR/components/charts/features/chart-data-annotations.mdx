# Anotações de dados de gráfico de {Platform} <Badge variant="preview" />

No gráfico {Platform}, as camadas de anotação de dados permitem anotar os dados plotados no Data Chart com linhas inclinadas, linhas verticais/horizontais (também chamadas de fatias do eixo), faixas verticais/horizontais (destinadas a um eixo específico), retângulos e até paralelogramos (também chamados de bandas). Com suporte à vinculação de dados, você pode criar quantas anotações quiser para personalizar seus gráficos. Além disso, você pode combinar diferentes camadas de anotação e sobrepor texto dentro da área de plotagem para anotar eventos, padrões e regiões importantes nos seus dados.

<DocsAside type="info">
Esses recursos foram projetados para oferecer suporte a eixos cartesianos e, atualmente, não oferecem suporte a eixos de raio ou angulares.
</DocsAside>

Por exemplo, você pode anotar preços de ações com eventos e padrões do mercado de ações.

## Exemplo de camada de fatia de anotação de dados de {Platform}

No {Platform}, a `DataAnnotationSliceLayer` renderiza várias linhas verticais ou horizontais que fatiam o gráfico em vários valores de um eixo no componente `DataChart`. Essa camada de anotação de dados é frequentemente usada para anotar eventos importantes (por exemplo, relatórios trimestrais da empresa) no eixo X, ou valores importantes no eixo Y. Definir a propriedade TargetAxis como eixo Y fará a camada de anotação de dados ser renderizada como fatias horizontais, e definir a propriedade TargetAxis como eixo X fará a camada ser renderizada como fatias verticais. Assim como todas as séries, a DataAnnotationSliceLayer também oferece suporte à vinculação de dados, por meio da propriedade `DataSource`, que pode ser definida como uma coleção de itens de dados que devem ter pelo menos 1 coluna de dados numérica mapeada na propriedade `annotationValueMemberPath`.

Por exemplo, você pode usar a DataAnnotationSliceLayer para anotar preços de ações com eventos importantes, como desdobramento de ações e resultados de balanços.

<Sample src="/charts/data-chart/data-annotation-slice-layer" height={500} alt="Exemplo de camada de fatia de anotação de dados de {Platform}" />


## Exemplo de camada de faixa de anotação de dados de {Platform}

No {Platform}, a `DataAnnotationStripLayer` renderiza várias faixas verticais ou horizontais entre 2 valores de um eixo no componente `DataChart`. Essa camada de anotação de dados pode ser usada para anotar a duração de eventos (por exemplo, uma queda do mercado de ações) no eixo X, ou uma faixa importante de valores no eixo Y. Definir a propriedade TargetAxis como eixo Y fará a camada de anotação de dados ser renderizada como faixas horizontais, e definir a propriedade TargetAxis como eixo X fará a camada ser renderizada como faixas verticais. Assim como todas as séries, a `DataAnnotationStripLayer` também oferece suporte à vinculação de dados, por meio da propriedade `DataSource`, que pode ser definida como uma coleção de itens de dados que devem ter pelo menos 1 coluna de dados numérica mapeada na propriedade AnnotationValueMemberPath.

Por exemplo, você pode usar a `DataAnnotationStripLayer` para anotar o gráfico com quedas do mercado de ações e mudanças nas taxas de juros federais.

## Exemplo de camada de linha de anotação de dados de {Platform}

No {Platform}, a `DataAnnotationLineLayer` renderiza várias linhas entre 2 pontos na área de plotagem do componente `DataChart`. Essa camada de anotação de dados pode ser usada para anotar um gráfico de ações com o crescimento e a queda dos preços das ações. Assim como todas as séries, a DataAnnotationLineLayer também oferece suporte à vinculação de dados, por meio da propriedade `DataSource`, que pode ser definida como uma coleção de itens de dados que devem ter pelo menos 4 colunas de dados numéricas representando as coordenadas x/y do ponto inicial e do ponto final das linhas. Os pontos iniciais devem ser mapeados usando as propriedades `startValueXMemberPath` e `startValueYMemberPath`, e os pontos finais devem ser mapeados usando as propriedades `endValueXMemberPath` e `endValueYMemberPath`.

Por exemplo, você pode usar a DataAnnotationLineLayer para anotar padrões de crescimento e queda nos preços das ações e as máximas e mínimas de 52 semanas dos preços das ações no eixo Y.

<Sample src="/charts/data-chart/data-annotation-line-layer" height={500} alt="Exemplo de camada de linha de anotação de dados de {Platform}" />


## Exemplo de camada de retângulo de anotação de dados de {Platform}

No {Platform}, a `DataAnnotationRectLayer` renderiza vários retângulos definidos por pontos inicial e final na área de plotagem do componente `DataChart`. Essa camada de anotação de dados pode ser usada para anotar uma região da área de plotagem, como padrões de baixa nos preços das ações. Assim como todas as séries, a DataAnnotationRectLayer também oferece suporte à vinculação de dados, por meio da propriedade `DataSource`, que pode ser definida como uma coleção de itens de dados que devem ter pelo menos 4 colunas de dados numéricas representando as coordenadas x/y do ponto inicial e do ponto final dos retângulos. Os pontos iniciais devem ser mapeados usando as propriedades `startValueXMemberPath` e `startValueYMemberPath`, e os pontos finais devem ser mapeados usando as propriedades `endValueXMemberPath` e `endValueYMemberPath`.

Por exemplo, você pode usar a DataAnnotationRectLayer para anotar padrões de baixa e lacunas nos preços das ações no eixo Y.

## Exemplo de camada de banda de anotação de dados de {Platform}

No {Platform}, a `DataAnnotationBandLayer` renderiza vários retângulos inclinados (paralelogramo de forma livre) entre 2 pontos na área de plotagem do componente `DataChart`. Essa camada de anotação de dados pode ser usada para anotar uma faixa de crescimento e queda nos preços das ações. Assim como todas as séries, a DataAnnotationBandLayer também oferece suporte à vinculação de dados, por meio da propriedade `DataSource`, que pode ser definida como uma coleção de itens de dados que devem ter pelo menos 4 colunas de dados numéricas representando as coordenadas x/y do ponto inicial e do ponto final das linhas. Os pontos iniciais devem ser mapeados usando as propriedades `startValueXMemberPath` e `startValueYMemberPath`, e os pontos finais devem ser mapeados usando as propriedades `endValueXMemberPath` e `endValueYMemberPath`. Além disso, você pode especificar a espessura/tamanho do retângulo inclinado vinculando uma coluna de dados numérica à propriedade AnnotationBreadthMemberPath.

Por exemplo, você pode usar a DataAnnotationBandLayer para anotar uma faixa de crescimento nos preços das ações.

## Referências da API

A seguir está uma lista dos membros de API mencionados nas seções acima:

- `targetAxis`: esta propriedade especifica em qual eixo deve estar habilitada a DataAnnotationBandLayer, a DataAnnotationLineLayer ou a DataAnnotationRectLayer.
- `DataSource`: esta propriedade vincula dados à camada de anotação para definir a forma exata.
- `startValueXMemberPath`: esta propriedade é um mapeamento para o nome da coluna de dados com as posições x do início da DataAnnotationBandLayer, da DataAnnotationLineLayer ou da DataAnnotationRectLayer.
- `startValueYMemberPath`: esta propriedade é um mapeamento para o nome da coluna de dados com as posições y do início da DataAnnotationBandLayer, da DataAnnotationLineLayer ou da DataAnnotationRectLayer.
- `endValueXMemberPath`: esta propriedade é um mapeamento para a coluna de dados com as posições x do fim da DataAnnotationBandLayer, da DataAnnotationLineLayer ou da DataAnnotationRectLayer.
- `endValueYMemberPath`: esta propriedade é um mapeamento para a coluna de dados com as posições y do fim da DataAnnotationBandLayer, da DataAnnotationLineLayer ou da DataAnnotationRectLayer.
- `startLabelXMemberPath`: esta propriedade é um mapeamento para a coluna de dados que representa o rótulo de sobreposição da posição inicial do xAxis ao longo do eixo.
- `startLabelXDisplayMode` | `startLabelYDisplayMode` | `endLabelXDisplayMode` | `endLabelYDisplayMode` | `centerLabelXDisplayMode`: estas propriedades especificam o que os rótulos de anotação devem exibir no início, no fim ou no centro da forma da anotação, por exemplo, o valor de dado mapeado, o rótulo de dado mapeado, o valor do eixo, ou ocultar um determinado rótulo de anotação.
- `startLabelYMemberPath`: esta propriedade é um mapeamento para a coluna de dados que representa o rótulo do eixo da posição inicial de `DataAnnotationBandLayer`, `DataAnnotationLineLayer`, `DataAnnotationRectLayer` no eixo Y.
- `endLabelYMemberPath`: esta propriedade é um mapeamento para a coluna de dados que representa o rótulo do eixo da posição final de `DataAnnotationBandLayer`, `DataAnnotationLineLayer`, `DataAnnotationRectLayer` no eixo Y.
