# Anotações de gráfico de {Platform}

As interações de hover e as anotações do gráfico {Platform} são implementadas por meio de camadas de interação de hover, que são séries adicionadas à coleção de séries. Essas camadas dependem da posição do cursor. Cada uma dessas camadas de anotação oferece uma interação de hover diferente, que pode ser usada individualmente ou combinada com outras para oferecer interações de hover poderosas.

## Camada de linha de mira de {Platform}

A `CrosshairLayer` é renderizada como linhas cruzadas que se interceptam no valor real de cada série que elas são configuradas para destacar, com cada série renderizando um conjunto separado de linhas.

Os tipos de linha de mira incluem:
- Horizontal
- Vertical
- Ambas

As linhas de mira do gráfico também podem ser configuradas para se ajustar aos pontos de dados, definindo a propriedade `crosshairsSnapToData` como true; caso contrário, as linhas de mira serão interpoladas entre os pontos de dados. Anotações também podem ser habilitadas para exibir o valor da linha de mira ao longo do eixo.

Você pode configurar a camada de linha de mira para que ela seja exibida somente em uma série específica, já que, por padrão, ela destaca todas as séries do controle de gráfico. Para isso, defina a propriedade `targetSeries`.

Por padrão, a cor das linhas de mira é mais clara do que a série com a qual elas interagem. No entanto, essa configuração padrão pode ser substituída para que você escolha uma cor para as linhas de mira. Isso é feito definindo a propriedade `CrosshairLayer.brush` da Camada de linha de mira.

## Camada de valor final de {Platform}

O `FinalValueLayer` do controle `DataChart` oferece uma visão rápida, ao longo do eixo, do valor final exibido em uma série.

Você pode configurar essa anotação para destacar uma série específica, caso queira ter várias camadas de valor final com configurações diferentes. Isso pode ser feito definindo a propriedade `targetSeries`.

Você também pode personalizar essa anotação definindo as seguintes propriedades:

- `axisAnnotationBackground`: esta propriedade é usada para escolher o pincel da cor de fundo da anotação. O padrão é usar o pincel da série.
- `axisAnnotationTextColor`: esta propriedade é usada para escolher o pincel da cor do texto da anotação.
- `axisAnnotationOutline`: esta propriedade é usada para escolher o pincel da cor do contorno da anotação.

O exemplo a seguir mostra como estilizar a anotação da camada de valor final definindo as propriedades listadas acima.

<Sample src="/charts/data-chart/final-value-layer-styling" height={500} alt="Estilização da camada de valor final de {Platform}" />




```json-snippet source="/charts/category-chart/annotations-final-value"
{
    "type": "CategoryChart",
    "name": "chart",
    "dataSourceRef": "TemperatureAnnotatedData",
    "finalValueAnnotationsVisible": true,
    "finalValueAnnotationsBackground": "dodgerblue",
    "finalValueAnnotationsTextColor": "white",
    "finalValueAnnotationsPrecision": 0
}
```


## Camada de callout de {Platform}

A `CalloutLayer` exibe anotações de dados existentes ou novos no controle de gráfico. As anotações aparecem ao lado dos valores de dados indicados na fonte de dados.

Use as anotações de callout para exibir informações adicionais, como observações ou detalhes específicos sobre os pontos de dados, que você queira destacar para os seus usuários.

Você pode configurar os callouts para destacar uma série específica, caso queira ter várias camadas de callout com configurações diferentes. Isso pode ser feito definindo a propriedade `targetSeries`.

Você também pode personalizar essa anotação definindo as seguintes propriedades:

- `calloutLeaderBrush`: esta propriedade é usada para escolher o pincel das linhas guia dos callouts da camada.
- `calloutOutline`: esta propriedade é usada para escolher o pincel da cor do contorno da anotação.
- `calloutBackground`: esta propriedade é usada para escolher o pincel da cor de fundo da anotação. O padrão é usar o pincel da série.
- `calloutTextColor`: esta propriedade é usada para escolher o pincel da cor do texto da anotação.
- `calloutStrokeThickness`: esta propriedade é usada para escolher a espessura do fundo dos callouts.
- `calloutCornerRadius`: esta propriedade é usada para arredondar os cantos dos callouts.
- `allowedPositions`: esta propriedade é usada para escolher quais posições a camada de callout pode usar. Por exemplo, superior, inferior

O exemplo a seguir mostra como estilizar as anotações da camada de callout definindo as propriedades listadas acima:

<Sample src="/charts/data-chart/callout-layer-styling" height={500} alt="Estilização da camada de callout de {Platform}" />




```json-snippet source="/charts/category-chart/annotations-custom" channel="auto"
{
    "type": "CategoryChart",
    "name": "chart",
    "dataSourceRef": "TemperatureAnnotatedData",
    "calloutsVisible": true,
    "calloutsDataSourceRef": "TemperatureAnnotatedData",
    "calloutsXMemberPath": "Index",
    "calloutsYMemberPath": "Temperature",
    "calloutsLabelMemberPath": "TempInfo",
    "calloutsAllowedPositions": [ "Top", "Bottom" ]
}
```
