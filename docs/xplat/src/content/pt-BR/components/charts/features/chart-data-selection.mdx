# Seleção de gráfico de {Platform}

O recurso de seleção {ProductName} do Data Chart de {Platform} permite que os usuários selecionem, destaquem, contornem e, inversamente, desmarquem interativamente uma ou várias séries dentro de um gráfico. Isso oferece muitas possibilidades diferentes de como os usuários interagem com os dados apresentados, de formas mais significativas.

## Configurando a seleção

O comportamento padrão do `selectionMode` é desativado e exige que você opte por uma das opções a seguir. Há vários modos de seleção disponíveis no `DataChart`:

- **Auto**
- **None**
- **Brighten**
- **FadeOthers**
- **GrayscaleOthers**
- **FocusColorThickOutline**
- **FocusColorOutline**
- **SelectionColorThickOutline**
- **SelectionColorOutline**
- **FocusColorFill**
- **SelectionColorFill**
- **ThickOutline**

`Brighten` esmaecerá o item selecionado, enquanto `FadeOthers` causará o efeito oposto.
`GrayscaleOthers` se comportará de forma semelhante a `FadeOthers`, mas mostra uma cor cinza para o restante das séries. Observe que isso substituirá qualquer configuração de `selectionBrush`.
`SelectionColorOutline` e `SelectionColorThickOutline` desenharão uma borda ao redor da série.

Em conjunto, está disponível um `selectionBehavior` para oferecer maior controle sobre quais itens são selecionados. O comportamento padrão de Auto é `PerSeriesAndDataItemMultiSelect`.

- **Auto**
- **PerDataItemMultiSelect**
- **PerDataItemSingleSelect**
- **PerSeriesAndDataItemMultiSelect**
- **PerSeriesAndDataItemSingleSelect**
- **PerSeriesAndDataItemGlobalSingleSelect**
- **PerSeriesMultiSelect**
- **PerSeriesSingleSelect**

## Configurando a seleção múltipla

Outros modos de seleção oferecem vários métodos de seleção. Por exemplo, usar `selectionBehavior` com `PerDataItemMultiSelect` afetará todas as séries de toda a categoria quando houver várias séries, permitindo a seleção entre categorias. Em comparação com `PerDataItemSingleSelect`, apenas uma única categoria de itens pode ser selecionada por vez. Isso é útil quando várias séries estão vinculadas a fontes de dados diferentes e oferece maior controle da seleção entre categorias.
`PerSeriesAndDataItemGlobalSingleSelect` permite a seleção de uma única série em todas as categorias de cada vez.

## Seleção programática
A seleção do gráfico também pode ser configurada em código, em que os itens selecionados no gráfico podem ser exibidos na inicialização ou em tempo de execução. Isso pode ser feito adicionando itens à `SelectedSeriesItems` do `CategoryChart`. A propriedade `ChartSelection.matcher` do objeto `ChartSelection` permite selecionar uma série com base em um "matcher", o que é ideal quando você não tem acesso à série real do gráfico. Se você souber as propriedades que a sua fonte de dados contém, pode usar o `ValueMemberPath` que a série teria.

O matcher é ideal para usar em gráficos, como o `CategoryChart`, quando você não tem acesso à série real, como a `DataChart`. Nesse caso, se você souber as propriedades que a sua fonte de dados continha, poderá deduzir os ValueMemberPaths que a série teria. Por exemplo, se a sua fonte de dados tiver as propriedades numéricas Nuclear, Coal, Oil, Solar, saberá que há séries criadas para cada uma dessas propriedades.
