# Sobreposições de gráfico de {Platform}

A {Platform} `DataChart` permite posicionar linhas horizontais ou verticais em um único valor numérico que você define pelo uso do `ValueOverlay`. Isso pode ajudar você a visualizar dados como a média ou a mediana de uma série específica.

## Propriedades da sobreposição de valor de {Platform}

Diferentemente de outros tipos de série, que usam um `DataSource` para a vinculação de dados, a sobreposição de valor usa uma propriedade `Value` para vincular um único valor numérico. Além disso, a sobreposição de valor exige que você defina um único `ValueOverlay.axis` para usar. Se você usar um eixo X, a sobreposição de valor será uma linha vertical, e, se usar um eixo Y, ela será uma linha horizontal.

Ao usar um eixo X ou Y numérico, a propriedade `Value` deve refletir o valor numérico real no eixo onde você quer que a sobreposição de valor seja desenhada. Ao usar um eixo X ou Y de categoria, a `Value` deve refletir o índice da categoria em que você quer que a sobreposição de valor apareça.

Ao usar a sobreposição de valor com um eixo angular numérico, ela aparecerá como uma linha a partir do centro do gráfico; e, ao usar um eixo de raio numérico, ela aparecerá como um círculo.

As propriedades de aparência de `ValueOverlay` são herdadas de `Series`; assim, `ValueOverlay.brush` e `ValueOverlay.thickness`, por exemplo, estão disponíveis e funcionam da mesma forma que em outros tipos de série.

Também é possível mostrar uma anotação de eixo em um `ValueOverlay`, para exibir o valor da sobreposição no eixo ao qual ela pertence. Para isso, você pode definir a propriedade `isAxisAnnotationEnabled` como true.

## Camada de valor de {Platform}

Os componentes de gráfico {Platform} também oferecem a capacidade de usar linhas de valor para destacar diferentes pontos focais dos seus dados, como valores mínimo, máximo e médio.

Aplicar a `ValueLayer` no <PlatformBlock for="Web">componentes `CategoryChart` e `FinancialChart`</PlatformBlock><PlatformBlock for="WinUI, Uno">componente `CategoryChart`</PlatformBlock> é feito definindo a propriedade `valueLines` no gráfico. Essa propriedade recebe uma coleção da enumeração `ValueLayerValueMode`. Você pode combinar várias camadas de valor no mesmo gráfico, adicionando várias enumerações `ValueLayerValueMode` à coleção `valueLines` do gráfico.

No `DataChart`, isso é feito adicionando um `ValueLayer` à coleção `Series` do gráfico e, em seguida, definindo a propriedade `ValueLayer` como uma das enumerações `ValueLayerValueMode`. Cada uma dessas enumerações e o que ela significa está listada abaixo:

- `Auto`: o modo de valor padrão da enumeração `ValueLayerValueMode`.
- `Average`: aplica potencialmente várias linhas de valor para destacar o valor médio de cada série plotada no gráfico.
- `GlobalAverage`: aplica uma única linha de valor para destacar a média de todos os valores das séries no gráfico.
- `GlobalMaximum`: aplica uma única linha de valor para destacar o valor máximo absoluto de todos os valores das séries no gráfico.
- `GlobalMinimum`: aplica uma única linha de valor para destacar o valor mínimo absoluto de todos os valores das séries no gráfico.
- `Maximum`: aplica potencialmente várias linhas de valor para destacar o valor máximo de cada série plotada no gráfico.
- `Minimum`: aplica potencialmente várias linhas de valor para destacar o valor mínimo de cada série plotada no gráfico.

Se você quiser impedir que uma série específica seja considerada ao usar o elemento `ValueLayer`, pode definir a propriedade `targetSeries` na camada. Isso força a camada a atingir apenas as séries que você definir. Você pode ter quantos elementos `ValueLayer` quiser dentro de um único `DataChart`.

## Texto de sobreposição do gráfico <Badge variant="preview" />

O {Platform} `ValueOverlay`, o `ValueLayer` e todas as Camadas de anotação de dados podem renderizar texto de sobreposição personalizado dentro da área de plotagem do componente DataChart. Você pode usar esse texto de sobreposição para anotar eventos importantes (por exemplo, relatórios trimestrais da empresa) no eixo X, ou valores importantes no eixo Y, em relação às camadas.

Por exemplo, você pode usar o `DataAnnotationSliceLayer`, o `ValueOverlay` e o `ValueLayer` para exibir texto de sobreposição.

<Sample src="/charts/data-chart/data-annotation-multiple-with-overlay-text" height={600} alt="Texto de sobreposição múltiplo de {Platform}" />
