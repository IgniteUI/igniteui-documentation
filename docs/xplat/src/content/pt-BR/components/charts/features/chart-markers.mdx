# Marcadores de gráfico de {Platform}

Nos gráficos {ProductName}, os marcadores são elementos visuais que exibem os valores dos pontos de dados na área de plotagem do gráfico. Os marcadores ajudam os usuários finais a identificar imediatamente o valor de um ponto de dados, mesmo que ele fique entre as linhas de grade principais ou secundárias.

## Exemplo de marcador de gráfico de {Platform}

No exemplo a seguir, o [Gráfico de linhas](../types/line-chart.mdx) compara a geração de eletricidade renovável dos países Europa, China e EUA entre os anos de 2009 e 2019, com marcadores habilitados ao definir a propriedade `markerTypes` com o valor de enumeração `MarkerType.Circle`.

As cores dos marcadores também são gerenciadas definindo as propriedades `markerBrushes` e `markerOutlines` no exemplo abaixo. Os marcadores e o `chartType` também são configuráveis neste exemplo, usando as listas suspensas.

## Tamanho do marcador de gráfico de {Platform}

Você pode controlar as dimensões exatas, em pixels independentes de dispositivo, dos marcadores de pontos de dados, definindo a propriedade `MarkerSize` em qualquer série que ofereça suporte a marcadores. Isso oferece controle preciso sobre o tamanho em que os marcadores aparecem na tela, independentemente do modelo ou estilo de marcador usado.

Por padrão, o tamanho dos marcadores é determinado pelo modelo de marcador da série. Quando você define `MarkerSize` como um valor numérico específico, todos os marcadores dessa série são renderizados exatamente com essa largura e altura em pixels independentes de dispositivo. Definir `MarkerSize` de volta como `\\NaN` restaura o tamanho padrão controlado pelo modelo.

A propriedade `MarkerSize` está disponível em todos os tipos de série derivados de `MarkerSeries`, incluindo `LineSeries`, `SplineSeries`, `AreaSeries`, `ColumnSeries`, `ScatterSeries`, `ScatterLineSeries`, `ScatterSplineSeries` e os tipos de série polar/radial.

Os exemplos de código a seguir mostram como definir `MarkerSize` como 30 pixels independentes de dispositivo em um `ScatterLineSeries` no controle `DataChart`:

```json-snippet
{
    "type": "DataChart",
    "$styleOptions": { "preferNameBindings": true },
    "axes": [
        { "type": "NumericXAxis", "name": "xAxis" },
        { "type": "NumericYAxis", "name": "yAxis" }
    ],
    "series": [
        {
            "type": "ScatterLineSeries",
            "name": "scatterLineSeries",
            "xAxisRef": "xAxis",
            "yAxisRef": "yAxis",
            "xMemberPath": "X",
            "yMemberPath": "Y",
            "markerType": "Circle",
            "markerSize": 30
        }
    ]
}
```


Para restaurar os marcadores ao tamanho padrão controlado pelo modelo, defina `MarkerSize` como `\\NaN` (ou remova o atributo na marcação):

```json-snippet
{
    "type": "DataChart",
    "axes": [
        { "type": "CategoryXAxis", "name": "xAxis", "dataSourceRef": "CountryRenewableElectricity", "label": "Year" },
        { "type": "NumericYAxis", "name": "yAxis" }
    ],
    "series": [
        {
            "type": "LineSeries",
            "$type": "+doc:markup",
            "$markerType": "+doc:markup",
            "$markerSize": "+doc:markup",
            "xAxisRef": "xAxis",
            "yAxisRef": "yAxis",
            "dataSourceRef": "CountryRenewableElectricity",
            "valueMemberPath": "America",
            "markerType": "Circle",
            "markerSize": null
        }
    ]
}
```

## Tipo de marcador de marca de seleção (checkmark) de gráfico de {Platform}

Os gráficos {ProductName} incluem uma opção `MarkerType.Checkmark`. Esse marcador renderiza um ícone de marca de seleção em formato de V dentro de um círculo, nos pontos de dados do seu gráfico.

Você pode aplicar o tipo de marcador `Checkmark` a uma série individual definindo a propriedade `MarkerType` dela como `MarkerType.Checkmark`. Para usar a forma de marca de seleção em todas as séries do gráfico ao mesmo tempo, defina a propriedade `MarkerAutomaticBehavior` do gráfico como `MarkerAutomaticBehavior.Checkmark`.

<PlatformBlock for="WPF">

A propriedade `SeriesViewer.CheckmarkMarkerTemplate` define o modelo de marcador usado nas séries com tipo de marcador de marca de seleção, e pode ser usada para personalizar a aparência dele em todo o gráfico.

</PlatformBlock>
