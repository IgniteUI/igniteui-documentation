# Linhas de tendência de gráfico de {Platform}

Nos gráficos {ProductName}, as linhas de tendência ajudam a identificar uma tendência ou a encontrar padrões nos dados. As linhas de tendência são sempre renderizadas à frente dos pontos de dados vinculados ao gráfico e são compatíveis com o `CategoryChart`<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> e com o `DataChart` (exceto para séries empilhadas, séries de formas e séries de intervalo).

As linhas de tendência vêm desativadas por padrão, mas você pode habilitá-las definindo a propriedade `trendLineType`. Além disso, você pode modificar várias propriedades de aparência das linhas de tendência, como o pincel, o período e a espessura.

As linhas de tendência também podem receber um array de traços depois de habilitadas. Isso é feito definindo a propriedade `trendLineDashArray` como um array de números. O array numérico descreve o comprimento dos traços da linha de tendência.

## Camada de linha de tendência de gráfico de {Platform}

A `TrendLineLayer` é um tipo de série projetado para exibir um único tipo de linha de tendência para uma série-alvo. A diferença em relação aos recursos de linha de tendência existentes nos tipos de série atuais é que, como a `TrendLineLayer` é um tipo de série, você pode adicionar mais de uma delas à coleção `Series` do gráfico, para ter várias linhas de tendência associadas à mesma série. Você também pode fazer a linha de tendência aparecer na legenda, o que não era possível antes.

## Uso da camada de linha de tendência

A `TrendLineLayer` precisa receber um `targetSeries` e um `trendLineType` para funcionar corretamente. Os diferentes tipos de linha de tendência disponíveis são os mesmos das linhas de tendência disponíveis nas séries.

Se você quiser mostrar a `TrendLineLayer` na legenda, pode fazer isso definindo a propriedade `useLegend` como `true`.

## Estilizando a camada de linha de tendência

Por padrão, a `TrendLineLayer` é renderizada com a mesma cor da sua `targetSeries`, em uma linha tracejada. Isso pode ser configurado usando as várias propriedades de estilo da `TrendLineLayer`.

Para alterar a cor da linha de tendência desenhada, você pode definir a propriedade `TrendLineLayer.brush`. Como alternativa, você também pode definir a propriedade `useIndex` como `true`, que usará a paleta `DomainChart.brushes` do gráfico com base no índice em que a `TrendLineLayer` está posicionada na coleção `Series` do gráfico.

Você também pode modificar a forma como a `TrendLineLayer` aparece usando as propriedades `appearanceMode` e `shiftAmount`. A propriedade `shiftAmount` recebe um valor entre -1,0 e 1,0 para determinar quanto de um "deslocamento" aplicar às opções que terminam em "Shift".

As opções da propriedade `appearanceMode` são as seguintes:

- `Auto`: o padrão é a enumeração DashPattern.
- `BrightnessShift`: a linha de tendência usará o pincel `targetSeries` e modificará o brilho dele com base no `shiftAmount` informado.
- `DashPattern`: a linha de tendência aparecerá como uma linha tracejada. A frequência dos traços pode ser modificada usando a propriedade `dashArray` do `TrendLineLayer`.
- `OpacityShift`: a linha de tendência usará o pincel `targetSeries` e modificará a opacidade dele com base no `shiftAmount` informado.
- `SaturationShift`: a linha de tendência usará o pincel `targetSeries` e modificará a saturação dele com base no `shiftAmount` informado.
