## Navegação do gráfico com interações do usuário

Se o zoom está ativado por padrão depende do gráfico que você está usando. Se estiver usando `CategoryChart`, ele está ativado por padrão, mas não está no `DataChart`. Para habilitar ou desabilitar a navegação na interface, você precisa definir as propriedades `isHorizontalZoomEnabled` e/ou `isVerticalZoomEnabled` do gráfico, dependendo da direção em que deseja habilitar ou desabilitar o zoom.

Também é possível aplicar zoom ou deslocar simplesmente clicando com o mouse ou usando o toque. A propriedade `defaultInteraction` do data chart determina o que acontece nos eventos de clique do mouse ou de toque. Essa propriedade tem como padrão `DragZoom`; quando definida assim, com o zoom habilitado, clicar e arrastar fará aparecer um retângulo de pré-visualização sobre a área de plotagem, que se tornará a área ampliada do gráfico. Essa propriedade `defaultInteraction` também pode ser definida como `DragPan`, para permitir o deslocamento, ou como `InteractionState.None`, para impedir essas operações.

## Navegação do gráfico com toque, mouse e teclado

A navegação no data chart {Platform} pode ser feita com toque, mouse ou teclado. As operações a seguir podem ser executadas com toque, mouse ou teclado por padrão:

- **Deslocamento**: usando as teclas de seta <kbd>🡐</kbd> <kbd>🡒</kbd> <kbd>🡑</kbd> <kbd>🡓</kbd> do teclado ou mantendo pressionada a tecla <kbd>SHIFT</kbd>, clicando e arrastando com o mouse, ou pressionando e movendo o dedo na tela por toque.
- **Aproximar (zoom in)**: usando a tecla <kbd>PAGE UP</kbd> do teclado, girando a roda do mouse para cima ou fazendo o gesto de pinça para aproximar por toque.
- **Afastar (zoom out)**: usando a tecla <kbd>PAGE DOWN</kbd> do teclado, girando a roda do mouse para baixo ou fazendo o gesto de pinça para afastar por toque.
- **Ajustar à área de plotagem do gráfico**: usando a tecla <kbd>HOME</kbd> do teclado. Não há operação com mouse ou toque para isso.
- **Zoom por área**: clique e arraste o mouse dentro da área de plotagem com a propriedade `defaultInteraction` definida com o seu valor padrão - `DragZoom`.

As operações de zoom e deslocamento também podem ser habilitadas usando teclas modificadoras, definindo as propriedades `dragModifier` e `panModifier`, respectivamente. Essas propriedades podem ser definidas com as seguintes teclas modificadoras e, quando pressionadas, a operação correspondente será executada:

| Valor do modificador | Tecla correspondente |
| ---------------|------------------ |
| `Shift`        | <kbd>SHIFT</kbd> |
| `Control`      | <kbd>CTRL</kbd> |
| `Windows`      | <kbd>WIN</kbd> |
| `Apple`        | <kbd>APPLE</kbd> |
| `None`         | sem teclas |

## Navegação do gráfico com barras de rolagem

O gráfico pode ser rolado habilitando as propriedades `verticalViewScrollbarMode` e `horizontalViewScrollbarMode`.

Elas podem ser configuradas com as seguintes opções

- `Persistent` - As barras de rolagem permanecem sempre visíveis enquanto o gráfico estiver ampliado, e desaparecem quando totalmente afastado.
- `Fading` - As barras de rolagem desaparecem após o uso e reaparecem quando o mouse estiver perto da posição delas.
- `FadeToLine` - As barras de rolagem são reduzidas a uma linha mais fina quando o zoom não está em uso.
- `None` - Padrão, nenhuma barra de rolagem é exibida.

## Navegação do gráfico por código

<DocsAside type="info">
A navegação do gráfico por código só pode ser usada com o controle `DataChart`.
</DocsAside>

O data chart {Platform} oferece várias propriedades de navegação que são atualizadas sempre que uma operação de zoom ou deslocamento acontece no gráfico. Você também pode definir cada uma dessas propriedades para aplicar zoom ou deslocar o data chart programaticamente. A seguir está uma lista dessas propriedades:

- `windowPositionHorizontal`: um valor numérico que descreve a porção X do retângulo de visualização de conteúdo exibido pelo data chart.
- `windowPositionVertical`: um valor numérico que descreve a porção Y do retângulo de visualização de conteúdo exibido pelo data chart.
- `windowRect`: um objeto `{RectType}` que representa um retângulo com a porção do gráfico que está atualmente visível. Por exemplo, um `windowRect` de "0, 0, 1, 1" seria a totalidade do data chart.
- `windowScaleHorizontal`: um valor numérico que descreve a porção de largura do retângulo de visualização de conteúdo exibido pelo data chart.
- `windowScaleVertical`: um valor numérico que descreve a porção de altura do retângulo de visualização de conteúdo exibido pelo data chart.
