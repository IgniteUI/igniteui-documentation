# Animações de gráfico de {Platform}

As animações permitem suavizar a entrada da série quando ela carrega uma nova fonte de dados. A animação disponível depende do tipo de série envolvida. Por exemplo, a série de colunas é animada subindo a partir do eixo X, e a série de linhas é animada sendo desenhada a partir da origem do eixo Y.

As animações estão desativadas nos gráficos {ProductName}, mas podem ser habilitadas definindo a propriedade `isTransitionInEnabled` como true. A partir daí, você pode definir a propriedade `transitionInDuration` para determinar quanto tempo a animação deve levar para ser concluída, e `transitionInMode` para determinar o tipo de animação que ocorre.
