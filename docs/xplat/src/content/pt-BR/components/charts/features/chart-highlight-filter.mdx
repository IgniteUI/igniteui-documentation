# Filtro de destaque de gráfico de {Platform}

Os componentes de gráfico {ProductName} oferecem suporte a uma sobreposição de destaque de dados, que pode aprimorar a visualização das séries plotadas nesses gráficos, permitindo que você veja um subconjunto dos dados plotados. Quando habilitado, ele destaca um subconjunto dos dados, enquanto exibe o conjunto total com opacidade reduzida no caso de séries de colunas e áreas, e com uma linha tracejada no caso de séries de linhas. Isso pode ajudar você a visualizar, por exemplo, valores-alvo em comparação com valores reais no seu conjunto de dados. Este recurso é demonstrado no exemplo a seguir:

<Sample src="/charts/data-chart/chart-highlight-filter-multiple-series" height={500} alt="Exemplo de filtro de destaque de {Platform}" />


Observe que o recurso de destaque de dados é compatível com o `DataChart` e o `CategoryChart`, mas é configurado de formas diferentes nesses controles, devido à natureza do funcionamento de cada um. Uma coisa permanece igual nesse recurso: é preciso definir a propriedade `highlightedValuesDisplayMode` como `SeriesHighlightedValuesDisplayMode.Overlay` se você quiser ver o destaque. A seguir, explicamos as diferentes configurações do recurso de filtro de destaque.

## Usando o filtro de destaque com o DataChart

No `DataChart`, grande parte da API do filtro de destaque acontece nas próprias séries, principalmente definindo a propriedade `highlightedDataSource` como uma coleção que representa um subconjunto dos dados que você quer destacar. A quantidade de itens em `highlightedDataSource` precisa corresponder à quantidade de dados vinculados a `DataSource` da série que você quer destacar e, no caso de séries de categoria, ele usará por padrão o `ValueMemberPath` que você definiu como caminho de destaque. O exemplo no início desta página usa o `highlightedDataSource` no `DataChart` para mostrar a sobreposição.

Caso o schema não corresponda entre o `highlightedDataSource` e o `DataSource` da série, você pode configurar isso usando a propriedade `HighlightedValueMemberPath` na série. Além disso, se quiser usar o `DataSource` da própria série como fonte de destaque e tiver um caminho no seu item de dados que represente o subconjunto, você pode fazer isso. Basta definir a propriedade `HighlightedValueMemberPath` como esse caminho e não fornecer um `highlightedDataSource`.

A opacidade reduzida dos tipos de série de colunas e áreas pode ser configurada definindo a propriedade `highlightedValuesFadeOpacity` na série. Você também pode definir a propriedade `highlightedValuesDisplayMode` como `SeriesHighlightedValuesDisplayMode.Hidden` se não quiser ver a sobreposição de forma alguma.

A parte da série exibida pelo filtro de destaque será representada separadamente nas camadas de legenda e de dica de ferramenta do gráfico. Você pode configurar o título que ela recebe na dica de ferramenta e na legenda definindo a propriedade `highlightedTitleSuffix`. Isso acrescentará o valor que você informar ao final do `chartTitle` da série.

Se o `DataLegend` ou o `DataToolTipLayer` for usado, as séries destacadas aparecerão agrupadas. Isso pode ser gerenciado definindo a propriedade `highlightedValuesDataLegendGroup` na série, para categorizá-las adequadamente.

## Usando o filtro de destaque no CategoryChart

O filtro de destaque do `CategoryChart` acontece no gráfico, definindo a propriedade `initialHighlightFilter`. Como o `CategoryChart` considera, por padrão, todas as propriedades do seu item de dados subjacente, você também precisará definir o `initialGroups` no gráfico, para que os dados possam ser agrupados e agregados de uma forma que permita ter um subconjunto dos dados para filtrar. Você pode definir a propriedade `initialGroups` como um caminho de valor no seu item de dados subjacente, para agrupar por um caminho que tenha valores duplicados.
