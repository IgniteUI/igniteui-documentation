# Dicas de ferramenta de gráfico de {Platform}

Nos gráficos {Platform}, as dicas de ferramenta fornecem detalhes sobre os dados vinculados, e são renderizadas em pop-ups quando o usuário final passa o mouse sobre os pontos de dados. As dicas de ferramenta são compatíveis com o `CategoryChart`<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> e com os controles `DataChart`.

## Tipos de dica de ferramenta do gráfico de {Platform}

O gráfico {Platform} oferece três tipos de dicas de ferramenta, que você pode usar com as dicas de ferramenta habilitadas, definindo a propriedade `DomainChart.toolTipType`. O exemplo a seguir mostra o [Gráfico de colunas](../types/column-chart.mdx) com uma caixa de combinação que você pode usar para alterar o tipo de dica de ferramenta.

<Sample src="/charts/category-chart/column-chart-with-tooltips" height={500} alt="Exemplo de tipos de dicas de ferramenta de {Platform}" />




A propriedade `DomainChart.toolTipType` é configurável e pode ser definida com uma das seguintes opções:

| Valor da propriedade     | Descrição  |
| -------------------|----------------|
| Dica de ferramenta `Default` | Exibe uma dica de ferramenta para um único item quando o ponteiro está posicionado sobre ele.  |
| Dica de ferramenta `Data` | Exibe as dicas de ferramenta de dados de todas as séries do gráfico.  |
| Dica de ferramenta `Item`    | Exibe uma dica de ferramenta para cada item de dados na categoria sobre a qual o ponteiro está posicionado.  |
| Dica de ferramenta `Category` | Exibe uma dica de ferramenta agrupada para todos os pontos de dados na categoria sobre a qual o ponteiro está posicionado.  |


## Modelo de dica de ferramenta do gráfico de {Platform}

Se nenhum dos tipos integrados de dica de ferramenta atender às suas necessidades, você pode criar as suas próprias dicas de ferramenta para exibir e estilizar o título da série, os valores dos dados e os valores dos eixos. As seções a seguir demonstram como fazer isso nos diferentes tipos de gráfico {Platform}.
