# Título e subtítulo do gráfico de {Platform}

O recurso de título e subtítulo do controle de gráfico permite adicionar informações à seção superior dos gráficos {Platform}.

## Referências da API

Ao adicionar um título ou subtítulo ao controle de gráfico, o conteúdo do gráfico é redimensionado automaticamente para acomodar as informações de título e subtítulo.

| Nome da propriedade         | Tipo da propriedade   |     Descrição  |
| ----------------------|------------------|------------|
| `ChartTitle`          | string |  Conteúdo de texto do título.  |
| `titleTextColor`      | string |  Cor do texto do título.  |
| `titleAlignment`      | HorizontalAlignment |  Alinhamento horizontal do título.  |
| `titleTextStyle`      | string | Estilo da fonte do título, por exemplo, Italic Bold 8pt Times New Roman  |
| `titleTopMargin`      | número | Margem superior do título.  |
| `titleLeftMargin`     | número | Margem esquerda do título.  |
| `titleRightMargin`    | número | Margem direita do título.  |
| `titleBottomMargin`   | número | Margem inferior do título.  |
| `CategoryChart.subtitle`            | string |  Conteúdo de texto do título.  |
| `subtitleTextColor`   | string |  Cor do texto do título.  |
| `subtitleAlignment`   | HorizontalAlignment |  Alinhamento horizontal do título.  |
| `subtitleTextStyle`   | string | Estilo da fonte do título, por exemplo, Italic Bold 8pt Times New Roman  |
| `subtitleTopMargin`   | número | Margem superior do título.  |
| `subtitleLeftMargin`  | número | Margem esquerda do título.  |
| `subtitleRightMargin` | número | Margem direita do título.  |
| `subtitleBottomMargin`| número | Margem inferior do título.  |
