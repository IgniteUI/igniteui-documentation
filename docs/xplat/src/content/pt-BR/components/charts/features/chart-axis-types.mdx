# Tipos de eixo de {Platform}

O Category Chart de {ProductName} usa apenas um `CategoryXAxis` e um tipo `NumericYAxis`.<PlatformBlock for="Web"> Da mesma forma, o Financial Chart de {ProductName} usa apenas um `TimeXAxis` e um tipo `NumericYAxis`.</PlatformBlock> No entanto, o Data Chart de {ProductName} oferece suporte a vários tipos de eixo, que você pode posicionar em qualquer lado do gráfico definindo a [localização do eixo](chart-axis-layouts.mdx#exemplo-de-localizações-de-eixo), ou até mesmo dentro do gráfico, usando as propriedades de [cruzamento de eixos](chart-axis-layouts.mdx#exemplo-de-cruzamento-de-eixos). Este tópico aborda cada um deles, quais eixos e séries são compatíveis entre si, e algumas propriedades específicas dos eixos exclusivos.

## Eixos cartesianos

O `DataChart` com eixos cartesianos permite plotar dados nas direções horizontal (eixo X) e vertical (eixo Y), com 3 tipos de eixo X
(`CategoryXAxis`, `NumericXAxis` e `TimeXAxis`) e 2 tipos de eixo Y (`CategoryYAxis` e `NumericYAxis`).

### Eixo X de categoria

O `CategoryXAxis` trata os seus dados como uma sequência de itens de dados categóricos. Ele pode exibir quase qualquer tipo de dado, incluindo textos e números. Se você estiver plotando números nesse eixo, é importante lembrar que ele é um eixo discreto, e não contínuo. Isso significa que cada item de dados categórico será posicionado equidistante do anterior. Os itens também serão plotados na ordem em que aparecem na fonte de dados do eixo.

O `CategoryXAxis` exige que você forneça um `DataSource` e um `NumericYAxis.label` para plotar dados com ele. Ele é geralmente usado com o `NumericYAxis` para plotar o seguinte tipo de série:

### Eixo X numérico

O `NumericXAxis` trata os seus dados como itens de dados numéricos com variação contínua. Os rótulos desse eixo são posicionados na horizontal, ao longo do eixo X. A localização dos rótulos do `NumericXAxis` depende da propriedade `BubbleSeries.xMemberPath` das várias [Séries de dispersão](../types/scatter-chart.mdx) que ele oferece suporte, se combinado com um `NumericYAxis`. Alternativamente, se combinado com o `CategoryXAxis`, esses rótulos serão posicionados de acordo com o `valueMemberPath` de `BarSeries`, `RangeBarSeries`, `StackedBarSeries` e `Stacked100BarSeries`.

O `NumericXAxis` é compatível com o seguinte tipo de série:

- `BarSeries`
- `RangeBarSeries`
- `BubbleSeries`<PlatformBlock for="Web">
- `HighDensityScatterSeries`</PlatformBlock>

- `ScatterLineSeries`
- `ScatterSplineSeries`
- `ScatterAreaSeries`
- `ScatterContourSeries`
- `ScatterPolylineSeries`
- `ScatterPolygonSeries`
- `StackedBarSeries`
- `Stacked100BarSeries`

### Eixo Y numérico

O `NumericYAxis` trata os seus dados como itens de dados numéricos com variação contínua. Os rótulos desse eixo são posicionados na vertical, ao longo do eixo Y. A localização dos rótulos do `NumericYAxis` depende da propriedade `yMemberPath` das várias [ScatterSeries](../types/scatter-chart.mdx) que ele oferece suporte, se combinado com um `NumericXAxis`. Alternativamente, se combinado com o `CategoryYAxis`, esses rótulos serão posicionados de acordo com o `valueMemberPath` da categoria ou das séries empilhadas mencionadas na tabela acima. Se você estiver usando uma das séries financeiras, eles serão posicionados de acordo com os caminhos Open/High/Low/Close e o tipo de série que você estiver usando.

O `NumericYAxis` é compatível com o seguinte tipo de série:

### Eixo X de tempo

O `TimeXAxis` trata os seus dados como uma sequência de itens de dados, ordenados por data. Os rótulos desse tipo de eixo são datas, que podem ser formatadas e organizadas de acordo com intervalos de data. O intervalo de datas desse eixo é determinado pelos valores de data em uma coluna de dados mapeada usando a sua `dateTimeMemberPath`. Isso, junto com um `DataSource`, é necessário para plotar dados com este tipo de eixo.
<PlatformBlock for="Web">
O `TimeXAxis` é o tipo de eixo X no componente `FinancialChart`.</PlatformBlock>

#### Interrupções no eixo X de tempo

O `TimeXAxis` tem a opção de excluir intervalos de dados usando `TimeXAxis.breaks`. Como resultado, os rótulos e os dados plotados não aparecerão no intervalo excluído. Por exemplo, dias úteis/não úteis, feriados e/ou fins de semana. Uma instância de `TimeAxisBreak` pode ser adicionada à coleção `TimeXAxis.breaks` do eixo e configurada usando um `TimeAxisBreak.start`, `TimeAxisBreak.end` e `NumericYAxis.interval` exclusivos.

#### Formatação no eixo X de tempo

O `TimeXAxis` tem a propriedade `labelFormats`, que representa uma coleção de objetos `TimeAxisLabelFormat`. Cada `TimeAxisLabelFormat` adicionado à coleção é responsável por atribuir um `TimeAxisLabelFormat.format` e um `TimeAxisLabelFormat.range` exclusivos. Isso pode ser especialmente útil para detalhar dados de anos até milissegundos e ajustar os rótulos de acordo com o intervalo de tempo exibido pelo gráfico.

A propriedade `TimeAxisLabelFormat.format` do `TimeAxisLabelFormat` especifica qual formato usar para um determinado intervalo visível. A propriedade `TimeAxisLabelFormat.range` do `TimeAxisLabelFormat` especifica o intervalo visível em que os formatos dos rótulos do eixo mudarão para outro formato. Por exemplo, se você tiver dois elementos `TimeAxisLabelFormat`, um com intervalo definido como 10 dias e outro como 5 horas, assim que o intervalo visível do eixo ficar menor que 10 dias, ele mudará para o formato de 5 horas.

#### Intervalos no eixo X de tempo

O `TimeXAxis` substitui a propriedade convencional `NumericYAxis.interval` dos eixos de categoria e numérico por uma coleção `TimeXAxis.intervals` do tipo `TimeAxisInterval`. Cada `TimeAxisInterval` adicionado à coleção é responsável por atribuir um `NumericYAxis.interval`, `TimeAxisLabelFormat.range` e `intervalType` exclusivos. Isso pode ser especialmente útil para detalhar dados de anos até milissegundos, de modo a oferecer espaçamento único entre os rótulos, de acordo com o intervalo de tempo exibido pelo gráfico. A descrição dessas propriedades está abaixo:

- `NumericYAxis.interval`: especifica o intervalo a ser usado. Isso está vinculado à propriedade `intervalType`. Por exemplo, se o `intervalType` estiver definido como `Days`, o valor numérico especificado em `NumericYAxis.interval` será em dias.
- `TimeAxisLabelFormat.range`: especifica o intervalo visível em que o intervalo do eixo mudará para outro intervalo. Por exemplo, se você tiver dois TimeAxisInterval, um com intervalo definido como 10 dias e outro como 5 horas, assim que o intervalo visível do eixo ficar menor que 10 dias, ele mudará para o intervalo cujo alcance é de 5 horas.
- `intervalType`: especifica a unidade de tempo para a propriedade `NumericYAxis.interval`.

## Eixos polares

O `DataChart` com eixos polares permite plotar dados para fora (eixo de raio) a partir do centro do gráfico e ao redor (eixo angular) do centro do gráfico.

### Eixo angular de categoria

O `CategoryAngleAxis` trata os seus dados como uma sequência de itens de dados de categoria. Os rótulos desse eixo são posicionados ao longo da borda de um círculo, de acordo com a posição deles nessa sequência. Esse tipo de eixo pode exibir quase qualquer tipo de dado, incluindo textos e números.

O `CategoryAngleAxis` é geralmente usado com o `NumericRadiusAxis` para plotar [Séries radiais](../types/radial-chart.mdx).

### Eixo angular de categoria proporcional

O `ProportionalCategoryAngleAxis` trata os seus dados como uma sequência de itens de dados de categoria. Os rótulos desse eixo são posicionados ao longo da borda de um círculo, de acordo com a posição deles nessa sequência. Esse tipo de eixo pode exibir quase qualquer tipo de dado, incluindo textos e números.

O `ProportionalCategoryAngleAxis` é geralmente usado com o `NumericRadiusAxis` para plotar um gráfico de pizza, por exemplo, [Séries radiais](../types/radial-chart.mdx).

### Eixo angular numérico

O `NumericAngleAxis` trata os seus dados como itens de dados numéricos com variação contínua. Os rótulos desse eixo são posicionados ao longo de uma linha radial que começa no centro do gráfico circular. A localização dos rótulos no `NumericAngleAxis` varia de acordo com o valor da coluna de dados mapeada pela propriedade `radiusMemberPath` do objeto [Série polar](../types/polar-chart.mdx), ou pela propriedade `valueMemberPath` do objeto [Série radial](../types/radial-chart.mdx).

O `NumericAngleAxis` pode ser usado com o `CategoryAngleAxis` para plotar [Séries radiais](../types/radial-chart.mdx), ou com o `NumericRadiusAxis` para plotar [Séries polares](../types/polar-chart.mdx), respectivamente.

O `NumericRadiusAxis` trata os dados como itens de dados numéricos com variação contínua. Os rótulos desse eixo são posicionados ao redor do gráfico circular. A localização dos rótulos varia de acordo com o valor de uma coluna de dados mapeada pela propriedade `AngleMemberPath` da série polar correspondente.
