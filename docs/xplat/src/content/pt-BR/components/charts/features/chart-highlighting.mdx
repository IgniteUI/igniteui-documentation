# Modos e comportamentos de destaque do gráfico de {Platform}

Todos os gráficos {Platform} oferecem suporte a uma variedade de opções de destaque. `highlightingMode` pode ser definido para clarear ou esmaecer quando o mouse estiver sobre uma série ou item de dados renderizado na área de plotagem. `highlightingBehavior` pode ser definido para o item de dados diretamente sob o cursor ou o mais próximo, para disparar o efeito de destaque. Os modos e comportamentos de destaque são compatíveis com os controles `CategoryChart`<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> e `DataChart`, e eles têm a mesma API para usar o recurso de destaque.

# Destaque de legenda de gráfico de {Platform}

Todos os gráficos {Platform} oferecem suporte a destaque pela legenda. `legendHighlightingMode` pode ser habilitado para que, quando o mouse estiver sobre um item marcador da legenda, a série renderizada seja destacada na área de plotagem. O destaque pela legenda é compatível com o `CategoryChart`<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> e `DataChart`, e eles têm a mesma API para usar o recurso de destaque.

## Camadas de destaque

O {ProductName} `CategoryChart` pode habilitar três tipos de destaque ao passar o mouse sobre itens de dados.

1. O destaque de série realça o ponto de dados individual representado por um marcador ou coluna quando o ponteiro está posicionado sobre ele. Isso é habilitado definindo a propriedade `isSeriesHighlightingEnabled` como true.

2. O destaque de item realça os itens de uma série, desenhando uma forma em faixa na posição deles ou renderizando um marcador na posição deles. Isso é habilitado definindo a propriedade `isItemHighlightingEnabled` como true.

3. O destaque de categoria atinge todos os eixos de categoria do gráfico. Eles desenham uma forma que ilumina a área do eixo mais próxima da posição do ponteiro. Isso é habilitado definindo a propriedade `isCategoryHighlightingEnabled` como true.
