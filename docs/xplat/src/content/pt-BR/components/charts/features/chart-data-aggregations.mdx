# Agregações de dados de {Platform}

No controle {ProductName} `CategoryChart`, o recurso de Agregações de dados permite agrupar os dados do gráfico pelos valores exclusivos de um membro de dados no eixo X e, em seguida, ordenar esses grupos. Depois, você pode aplicar resumos, que serão refletidos no intervalo do eixo Y e exibidos na dica de ferramenta ao passar o mouse sobre a série.

## Exemplo de agregações de dados de {Platform}

O exemplo a seguir mostra um [Gráfico de colunas](../types/column-chart.mdx) que agrupa pelo membro País no eixo X, e que pode ser alterado para outras propriedades de cada item de dados, como Produto, MonthName e Year, para agregar os dados de vendas. Também há uma opção de resumo e de ordenação para obter a ordem desejada para a propriedade agrupada.

Observe que as funções abreviadas encontradas nas listas suspensas de `initialSummaries` e `groupSorts` devem ser aplicadas conforme mostrado para obter um resultado correto com base na propriedade que você atribuir. Por exemplo: Sum(sales) as Sales | Sales Desc

<Sample src="/charts/category-chart/data-aggregations" height={500} alt="Exemplo de agregações de dados de {Platform}" />


```json-snippet source="/charts/category-chart/data-aggregations"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "CategoryChart",
    "name": "chart",
            "dataSourceRef": "SalesData",
            "initialGroups": "Country",
            "initialSummaries": "Sum(Sales) as Sales",
            "groupSorts": "Sales Desc"
        }
    }
}
```
