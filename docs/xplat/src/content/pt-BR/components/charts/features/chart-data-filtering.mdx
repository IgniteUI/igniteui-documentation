# Filtragem de dados de gráfico de {Platform}

A filtragem de dados permite consultar grandes volumes de dados para analisar e plotar um pequeno subconjunto de registros por meio de expressões de filtro, sem precisar modificar manualmente a fonte de dados vinculada ao gráfico.

Uma lista completa de expressões e palavras-chave válidas para formar uma string de consulta pode ser encontrada aqui:

[Expressões de filtro](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/webservices/use-filter-expressions-in-odata-uris)

> OBSERVAÇÃO: qualquer filtro incorreto aplicado resultará em um gráfico vazio.

## Exemplo de filtro de dados de gráfico de {Platform}

O exemplo a seguir mostra um [Gráfico de colunas](../types/column-chart.mdx) das taxas anuais de natalidade ao longo de várias décadas. A lista suspensa permite selecionar uma década, o que insere uma expressão por meio da propriedade `initialFilter`, atualizando o visual do gráfico e filtrando as outras décadas.

<Sample src="/charts/category-chart/data-filter" height={500} alt="Exemplo de filtro de dados de {Platform}" />



A propriedade `initialFilter` é uma string que exige a seguinte sintaxe para filtrar corretamente. O valor exige conjuntos de parênteses que incluem a definição da expressão de filtro, a coluna e o valor associados ao(s) registro(s) filtrado(s).

Por exemplo, para mostrar todos os países que começam com a letra B:

"(startswith(Country, 'B'))"

Por exemplo, concatenando mais de uma expressão:

"(startswith(Country, 'B') and endswith(Country, 'L') and contains(Product, 'Royal Oak') and contains(Date, '3/1/20'))"
