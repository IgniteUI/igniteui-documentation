# Sparkline {Platform}

O Sparkline {ProductName} é um controle de gráfico leve. Ele foi projetado para ser renderizado em um layout de pequena escala, como dentro de uma célula de grade, mas também pode ser renderizado sozinho. O `Sparkline` tem vários elementos visuais e recursos correspondentes que podem ser configurados e personalizados, como o tipo de gráfico, marcadores, faixas, linhas de tendência, plotagem de valores desconhecidos e dicas de ferramenta.

## Recomendações para o Sparkline

### O gráfico Sparkline é adequado para o seu projeto?
O principal benefício do controle Sparkline, em comparação com outros controles de gráfico, é que ele pode ser renderizado em um espaço limitado, como uma célula de grade, com todos os seus elementos visuais exibidos.

O Sparkline {Platform} pode marcar os pontos de dados com ícones elípticos para indicar os valores mais altos, mais baixos, primeiros, últimos e negativos. Os marcadores podem ser personalizados com a forma, a cor ou a imagem desejadas.

### Casos de uso do Sparkline
- Você tem um espaço compacto para exibir um gráfico.
- Você quer mostrar tendências em uma série de valores, como a receita semanal.

### Boas práticas para o Sparkline
- Sempre comece o eixo Y (eixo à esquerda ou à direita) em 0, para que a comparação dos dados seja precisa.
- Ordene os dados de série temporal da esquerda para a direita.
- Use atributos visuais, como linhas sólidas, para mostrar uma série de dados.

### Quando não usar o Sparkline
- Você precisa analisar os dados em detalhe.
- Você precisa exibir todos os rótulos dos pontos de dados. Ele só permite mostrar os valores alto e baixo no eixo Y, e os valores primeiro e último no eixo X.

### Estrutura de dados do Sparkline
- Exige dados unidimensionais.
- O conjunto de dados deve conter pelo menos dois campos numéricos.
- O texto nos campos da fonte de dados pode ser usado para exibir o primeiro e o último rótulo no eixo X.

## Tipos de sparkline
O Sparkline {Platform} oferece suporte aos seguintes tipos de sparkline, definindo a propriedade `displayType` de acordo:

- `Line`: exibe o tipo de gráfico de linhas do Sparkline com dados numéricos, conectando os pontos de dados com segmentos de reta. É preciso fornecer pelo menos dois pontos de dados para visualizar os dados no Sparkline.
- `Area`: exibe o tipo de gráfico de área do Sparkline com dados numéricos. É semelhante ao tipo de linha, com a etapa adicional de fechar a área depois que cada linha é desenhada. É preciso fornecer pelo menos dois pontos de dados para visualizar os dados no Sparkline.
- `Column`: exibe o tipo de gráfico de colunas do Sparkline com dados numéricos. Alguns o chamam de barras verticais. Esse tipo pode renderizar um único ponto de dados, mas exigirá especificar a propriedade de intervalo mínimo (minimum) no Sparkline, para que o ponto de dados único seja visível; caso contrário, o valor será tratado como o mínimo e não ficará visível.
- `WinLoss`: este tipo é semelhante, visualmente, ao tipo de gráfico de colunas, em que o valor de cada coluna é igual ao máximo positivo (para valores positivos) ou ao mínimo negativo (para valores negativos) do conjunto de dados. A ideia é indicar um cenário de ganho ou perda. Para que o gráfico Win/Loss seja exibido corretamente, o conjunto de dados deve ter valores positivos e negativos. Se o Sparkline Win/Loss estiver vinculado aos mesmos dados dos outros tipos, como o tipo Linha, que pode ser vinculado a uma coleção de valores numéricos, o Sparkline {Platform} selecionará dois valores da coleção — o maior e o menor — e renderizará o sparkline com base nesses valores.

## Marcadores

O Sparkline {Platform} permite mostrar marcadores como ícones coloridos circulares na série, para indicar os pontos de dados individuais com base em coordenadas X/Y. Os marcadores podem ser definidos nos sparklines dos tipos `Line`, `Area` e `Column`. O tipo `WinLoss` de sparkline não aceita marcadores no momento. Por padrão, os marcadores não são exibidos, mas podem ser habilitados definindo a propriedade de visibilidade de marcador correspondente.

Os marcadores no sparkline podem ser colocados em qualquer combinação dos seguintes locais:

- `MarkerVisibility`: exibe marcadores para todos os pontos de dados do sparkline.
- `LowMarkerVisibility`: exibe marcadores no ponto de dados de menor valor. Se houver vários pontos com o menor valor, o marcador aparecerá em cada um deles.
- `HighMarkerVisibility`: exibe marcadores no ponto de dados de maior valor. Se houver vários pontos com o maior valor, o marcador aparecerá em cada um deles.
- `FirstMarkerVisibility`: exibe um marcador no primeiro ponto de dados do sparkline.
- `LastMarkerVisibility`: exibe um marcador no último ponto de dados do sparkline.
- `NegativeMarkerVisibility`: exibe marcadores nos pontos de dados negativos plotados no sparkline.

Todos os marcadores mencionados acima podem ser personalizados usando a propriedade do tipo de marcador correspondente, em termos de cor, visibilidade e tamanho. Por exemplo, os marcadores `\\Low` acima terão as propriedades `lowMarkerBrush`, `lowMarkerVisibility` e `lowMarkerSize`.

## Intervalo normal

O recurso de intervalo normal do Sparkline {Platform} é uma faixa horizontal que representa algum intervalo predefinido e significativo quando os dados são visualizados. O intervalo normal pode ser definido como uma área sombreada delineada com a cor desejada.

O intervalo normal pode ser mais largo do que o ponto de dados máximo, ou ir além dele, e também pode ser tão fino quanto o tipo de exibição `Line` do sparkline, para servir como indicador de limite, por exemplo. A largura do intervalo normal é determinada pelas três propriedades a seguir, que são as configurações mínimas necessárias para exibir o intervalo normal:

- `NormalRangeVisibility`: se o intervalo normal está visível.
- `NormalRangeMaximum`: a borda inferior do intervalo.
- `NormalRangeMinimum`: a borda superior do intervalo.

Por padrão, o intervalo normal não é exibido. Quando habilitado, o intervalo normal aparece com aparência em cinza-claro, que também pode ser configurada usando a propriedade `normalRangeFill`.

Você também pode configurar se o intervalo normal deve ser exibido na frente ou atrás das séries plotadas no seu Sparkline {Platform}, definindo a propriedade `displayNormalRangeInFront`.

## Linhas de tendência

O Sparkline {Platform} oferece suporte a uma série de linhas de tendência, que são exibidas como outra camada sobre a camada do sparkline. Para exibir um sparkline, você pode usar a propriedade `TrendLineType`.

As linhas de tendência são calculadas de acordo com o algoritmo especificado pela propriedade `TrendLineType`, usando os valores dos dados aos quais o gráfico está vinculado.

As linhas de tendência só podem ser exibidas uma por vez, e, por padrão, a linha de tendência não é exibida.

## Interpolação de valores desconhecidos

O Sparkline {Platform} pode detectar valores desconhecidos e renderizar o espaço para esses valores por meio de um algoritmo de interpolação especificado. Se os seus dados contiverem valores nulos e você não usar esse recurso, ou seja, sem especificar nenhuma interpolação, o valor desconhecido não será plotado.

Para plotar os valores desconhecidos, você pode definir a propriedade `unknownValuePlotting` do Sparkline {Platform}. O exemplo abaixo mostra as diferenças entre os valores da propriedade `unknownValuePlotting`, permitindo ativá-la ou desativá-la com uma caixa de seleção:
