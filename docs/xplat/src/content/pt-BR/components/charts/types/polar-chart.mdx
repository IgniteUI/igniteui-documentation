# Gráfico polar de {Platform}
O Gráfico polar {ProductName} usa o sistema de coordenadas polares (ângulo, raio), em vez do sistema de coordenadas cartesianas (x, y), para plotar dados no gráfico. Em outras palavras, o Gráfico polar reúne conceitos de [Séries de dispersão](scatter-chart.mdx) e os envolve em um círculo, em vez de esticar os pontos de dados horizontalmente. Ele é frequentemente usado para plotar dados científicos (por exemplo, direção e velocidade do vento, direção e intensidade de um campo magnético, localização de objetos no sistema solar) e pode destacar o desvio dos dados coletados em relação aos resultados previstos.

## Gráfico de área polar de {Platform}
O Gráfico de área polar é renderizado usando uma coleção de polígonos que conectam os pontos de dados, e usa os mesmos conceitos de plotagem de dados do [Gráfico de área de categoria](area-chart.mdx#exemplo-de-gráfico-de-área-de-{PlatformLower}), com a diferença de que a visualização envolve os pontos de dados em um círculo, em vez de esticá-los horizontalmente. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `PolarAreaSeries`, como mostrado no exemplo abaixo:

## Gráfico de marcadores polar de {Platform}
O Gráfico de marcadores polar é renderizado usando uma coleção de marcadores que representam os pontos de dados no sistema de coordenadas polares (ângulo/raio). Este gráfico usa os mesmos conceitos de plotagem de dados do [Gráfico de marcadores de dispersão](scatter-chart.mdx#gráfico-de-dispersão-com-marcadores-de-{PlatformLower}), com a diferença de que a visualização envolve os pontos de dados em torno de um círculo, em vez de esticá-los horizontalmente.
