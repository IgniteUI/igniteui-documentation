# Gráfico de bolhas de {Platform}
O Gráfico de bolhas {ProductName} é um tipo de [Gráfico de dispersão](scatter-chart.mdx) que exibe marcadores com escala variável para representar a relação entre itens de várias séries de dados distintas, ou para plotar itens de dados usando coordenadas x e y. Essas coordenadas do ponto de dados são determinadas por duas colunas de dados numéricas. O Gráfico de bolhas chama a atenção para intervalos irregulares ou agrupamentos de dados. Este gráfico é frequentemente usado para plotar dados científicos e pode destacar o desvio dos dados coletados em relação aos resultados previstos. O Gráfico de bolhas tem muitas das características do [Gráfico de marcadores de dispersão](scatter-chart.mdx#gráfico-de-dispersão-com-marcadores-de-{PlatformLower}), mas com a opção de ter vários tamanhos de escala de raio.

## Estilização do Gráfico de bolhas de {Platform}
No Gráfico de bolhas {Platform}, você pode personalizar a forma dos marcadores de bolha usando a propriedade `markerType`, o tamanho deles com a propriedade `radiusScale` e a aparência deles usando as propriedades `markerBrush`, `markerOutline` e `markerThickness`. Além disso, você também pode colorir os marcadores de bolha com base em uma coluna de dados, usando as propriedades `fillMemberPath` e `fillScale`.
