# Gráfico de linhas de {Platform}

O Gráfico de linhas {ProductName}, ou diagrama de linhas, é um tipo de gráfico de categoria que mostra os valores contínuos de dados, representados por pontos conectados por segmentos de reta de uma ou mais grandezas ao longo de um período. Ele é frequentemente usado para mostrar tendências e realizar análises comparativas. O eixo Y (rótulos à esquerda) mostra um valor numérico, enquanto o eixo X (rótulos na parte inferior) mostra uma série temporal ou uma categoria de comparação. Você pode incluir um ou mais conjuntos de dados para comparar, que serão renderizados como várias linhas no gráfico.

## Recomendações para o Gráfico de linhas

### Os Gráficos de linhas {Platform} são adequados para o seu projeto?

- Diferentemente de um [gráfico de área](area-chart.mdx), o gráfico de linhas não preenche a área entre o eixo X (eixo inferior) e a linha.
- O gráfico de linhas {Platform} é idêntico ao {Platform} [gráfico de splines](spline-chart.mdx) em todos os aspectos, exceto que a linha que conecta os pontos de dados não tem interpolação spline nem suavização para uma apresentação melhor dos dados.

Um Gráfico de linhas inclui várias variantes, de acordo com os seus dados ou com a forma como você quer contar a história correta com eles. Elas incluem:

- Gráfico de linhas em camadas
- Gráfico de linhas empilhado
- Gráfico de linhas em degraus
- Gráfico de linhas polar
- Gráfico de linhas empilhado 100

### Casos de uso do Gráfico de linhas

Há vários casos de uso comuns para escolher um Gráfico de linhas:

- Você tem um conjunto de dados grande e de alto volume, que se adapta bem às interações do gráfico, como deslocamento, zoom e detalhamento (drill-down).
- Você precisa comparar as tendências ao longo do tempo.
- Você quer mostrar a diferença entre 2 ou mais séries de dados.
- Você quer mostrar comparações cumulativas de parte do todo de categorias distintas.
- Você precisa mostrar tendências de dados de uma ou mais categorias para análise comparativa.
- Você precisa visualizar dados detalhados de série temporal.

### Boas práticas para o Gráfico de linhas

- Sempre comece o eixo Y (eixo à esquerda ou à direita) em 0, para que a comparação dos dados seja precisa.
- Ordene os dados de série temporal da esquerda para a direita.
- Use atributos visuais, como linhas sólidas, para mostrar uma série de dados.

### Quando não usar o Gráfico de linhas

- Você tem muitas séries de dados (mais de 7 ou 10). Seu objetivo é garantir que o gráfico seja legível.
- Os dados de série temporal têm valores semelhantes (dados do mesmo período), o que torna impossível diferenciar as linhas sobrepostas.

### Estrutura de dados do Gráfico de linhas

- A fonte de dados deve ser um array ou uma lista de itens de dados (para uma única série).
- A fonte de dados deve ser um array de arrays ou uma lista de listas (para várias séries).
- A fonte de dados deve conter pelo menos um item de dados.
- Todos os itens de dados devem conter pelo menos uma coluna de dados (texto ou data e hora).
- Todos os itens de dados devem conter pelo menos uma coluna de dados numérica.

## Gráfico de linhas empilhado 100% de {Platform}

O Gráfico de linhas empilhado 100% é idêntico ao Gráfico de linhas empilhado em todos os aspectos, exceto pelo tratamento dos valores no eixo y. Em vez de apresentar uma representação direta dos dados, o Gráfico de linhas empilhado 100% apresenta os dados em termos de percentual da soma de todos os valores de um ponto de dados. ## Gráfico de linhas radial de {Platform}

O Gráfico de linhas radial pertence a um grupo de gráficos radiais e tem o formato de um polígono não preenchido, delimitado por uma coleção de linhas retas que conectam os pontos de dados. Este tipo de gráfico usa o mesmo conceito de plotagem de dados do Gráfico de linhas, mas envolve os pontos de dados em torno de um eixo circular, em vez de esticá-los horizontalmente.

## Gráfico de linhas polar de {Platform}

O Gráfico de linhas polar pertence a um grupo de gráficos polares e é renderizado usando uma coleção de linhas retas que conectam os pontos de dados no sistema de coordenadas polares (ângulo/raio). Os Gráficos de linhas polares usam os mesmos conceitos de plotagem de dados do [Gráfico de linhas de dispersão](scatter-chart.mdx), com a diferença de que a visualização envolve os pontos de dados em um círculo, em vez de esticá-los horizontalmente.
