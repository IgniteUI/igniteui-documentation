# Gráfico radial de {Platform}

O Gráfico radial {ProductName} recebe dados e os renderiza como uma coleção de pontos de dados envoltos em um círculo (em vez de se estenderem ao longo de uma linha horizontal). O Gráfico radial também mapeia uma lista de categorias do mínimo ao máximo da extensão do gráfico, e oferece suporte aos mecanismos de agrupamento de categorias.

## Gráfico de área radial de {Platform}

O Gráfico de área radial {Platform} tem o formato de um polígono preenchido, delimitado por uma coleção de linhas retas que conectam os pontos de dados. Este tipo de gráfico usa o mesmo conceito de plotagem de dados do [Gráfico de área](area-chart.mdx), mas envolve os pontos de dados em torno de um eixo circular, em vez de esticá-los horizontalmente. Você pode criar este tipo de gráfico no `DataChart` vinculando os seus dados a `RadialAreaSeries`, como mostrado no exemplo abaixo.

<Sample src="/charts/data-chart/radial-area-chart" height={600} alt="Gráfico de área radial de {Platform}" />




## Gráfico de colunas radial de {Platform}

O Gráfico de colunas radial é visualizado usando uma coleção de retângulos que se estendem do centro do gráfico em direção às posições dos pontos de dados. Ele usa os mesmos conceitos de plotagem de dados do [Gráfico de colunas](column-chart.mdx), mas envolve os pontos de dados em torno de um círculo, em vez de esticá-los horizontalmente. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `RadialColumnSeries`, como mostrado no exemplo abaixo:

<Sample src="/charts/data-chart/radial-column-chart" height={600} alt="Gráfico de colunas radial de {Platform}" />




## Gráfico de linhas radial de {Platform}

O Gráfico de linhas radial {Platform} é renderizado como uma coleção de linhas retas que conectam os pontos de dados. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a `RadialLineSeries`, como mostrado no exemplo abaixo:

## Gráfico de pizza radial de {Platform}

O Gráfico de pizza radial usa fatias de pizza que se estendem do centro do gráfico em direção às posições dos pontos de dados. Este tipo de gráfico reúne conceitos de categorização de várias séries de pontos de dados e os envolve em torno de um eixo circular, em vez de esticar os pontos de dados ao longo de uma linha horizontal. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `RadialPieSeries`, como mostrado no exemplo abaixo:

## Configurações do Gráfico radial de {Platform}

Além disso, os rótulos podem ser configurados para aparecer próximos ou afastados do gráfico. Isso pode ser configurado com a propriedade `CategoryAngleAxis.labelMode` do `CategoryAngleAxis`.
