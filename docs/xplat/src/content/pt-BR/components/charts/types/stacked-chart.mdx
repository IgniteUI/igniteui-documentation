# Gráfico empilhado de {Platform}

O Gráfico empilhado {ProductName} pertence a um grupo especial de gráficos que renderizam vários valores de itens de dados como áreas/polígonos, barras, colunas, linhas ou splines empilhados. Os Gráficos empilhados padrão renderizam os valores reais dos itens de dados, enquanto os Gráficos empilhados 100% renderizam os valores como porcentagem do total.

## Tipos de gráfico empilhado de {Platform}

As seções a seguir demonstram tipos individuais de Gráficos empilhados de {ProductName}.

## Gráfico de área empilhado de {Platform}

Os Gráficos de área empilhados são renderizados usando uma coleção de pontos conectados por segmentos de reta, com a área abaixo da linha preenchida e empilhada uma sobre a outra. Os Gráficos de área empilhados seguem todos os mesmos requisitos do [Gráfico de área](./area-chart.mdx); a única diferença é que, visualmente, as áreas sombreadas ficam empilhadas umas sobre as outras.

Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `StackedAreaSeries`, como mostrado no exemplo abaixo.

## Gráfico de barras empilhado de {Platform}

Um Gráfico de barras empilhado, ou diagrama de barras empilhado, é um tipo de gráfico de categoria usado para comparar a composição de diferentes categorias de dados, exibindo fragmentos de tamanhos diferentes nas barras horizontais do gráfico. O comprimento de cada barra, ou pilha de fragmentos, é proporcional ao valor total dela.

O Gráfico de barras empilhado difere do [Gráfico de barras](./bar-chart.mdx) porque os pontos de dados que representam os seus dados são empilhados lado a lado, horizontalmente, para agrupar visualmente os dados. Cada pilha pode conter valores positivos e negativos. Todos os valores positivos são agrupados no lado positivo do eixo X, e todos os valores negativos são agrupados no lado negativo do eixo X.

Neste exemplo de Gráfico de barras empilhado, temos um eixo X numérico (rótulos na parte inferior do gráfico) e um eixo Y de categoria (rótulos à esquerda do gráfico). Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `StackedBarSeries`, como mostrado no exemplo abaixo.

<Sample src="/charts/data-chart/stacked-bar-chart" height={600} alt="Gráfico de barras empilhado de {Platform}" />

## Gráfico de barras empilhado 100% de {Platform}

O Gráfico de barras empilhado 100% {Platform} é idêntico ao gráfico de barras empilhado {Platform} em todos os aspectos, exceto pelo tratamento dos valores no eixo X (rótulos na parte inferior do gráfico). Em vez de apresentar uma representação direta dos dados, o gráfico de barras empilhado 100% apresenta os dados em termos de percentual da soma de todos os valores de um ponto de dados.

Neste exemplo de Gráfico de barras empilhado 100%, os valores de Energy Product são mostrados como um valor de 100% de todos os dados nos fragmentos das barras horizontais. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `Stacked100BarSeries`, como mostrado no exemplo abaixo.

<Sample src="/charts/data-chart/stacked-100-bar-chart" height={600} alt="Gráfico de barras empilhado 100 de {Platform}" />

## Gráfico de colunas empilhado de {Platform}

O Gráfico de colunas empilhado é idêntico ao [Gráfico de colunas](./column-chart.mdx) em todos os aspectos, exceto que as séries são representadas umas sobre as outras, em vez de lado a lado. O Gráfico de colunas empilhado é usado para mostrar a comparação de resultados entre séries. Cada fragmento empilhado na coleção representa um elemento visual em cada pilha. Cada pilha pode conter valores positivos e negativos. Todos os valores positivos são agrupados no lado positivo do eixo Y, e todos os valores negativos são agrupados no lado negativo do eixo Y. O Gráfico de colunas empilhado usa os mesmos conceitos de plotagem de dados do Gráfico de barras empilhado, mas os pontos de dados são empilhados ao longo de uma linha vertical (eixo Y), em vez de ao longo de uma linha horizontal (eixo X).

Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `StackedColumnSeries`, como mostrado no exemplo abaixo.

<Sample src="/charts/data-chart/stacked-column-chart" height={600} alt="Gráfico de colunas empilhado de {Platform}" />

O Gráfico de colunas empilhado 100% é idêntico ao Gráfico de colunas empilhado em todos os aspectos, exceto pelo tratamento dos valores no eixo Y. Em vez de apresentar uma representação direta dos dados, o Gráfico de colunas empilhado 100% apresenta os dados em termos de percentual da soma de todos os valores de um ponto de dados.
