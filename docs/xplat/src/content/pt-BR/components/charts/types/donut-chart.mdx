# Gráfico de rosca de {Platform}
O Gráfico de rosca {ProductName} é semelhante ao [Gráfico de pizza](pie-chart.mdx), ilustrando proporcionalmente as ocorrências de uma variável. O gráfico de rosca pode exibir várias variáveis em anéis concêntricos e oferece suporte integrado para a visualização de dados hierárquicos. Os anéis podem ser vinculados a um item de dados diferente ou podem compartilhar uma fonte de dados comum.

## Recomendações para o Gráfico de rosca de {Platform}

### Os Gráficos de rosca {Platform} são adequados para o seu projeto?
Os Gráficos de rosca são adequados para conjuntos de dados pequenos e são fáceis de ler em uma rápida olhada. Gráficos de rosca são apenas um tipo de visualização de parte do todo. Outros incluem:

- [Pizza](pie-chart.mdx)
- [Área empilhada](area-chart.mdx)
- [Área empilhada 100% (área de porcentagem empilhada)](area-chart.mdx)
- [Barras empilhadas](bar-chart.mdx)
- [Barras 100% empilhadas (barra de porcentagem empilhada)](bar-chart.mdx)
- [Treemap](treemap-chart.mdx)
- [Cascata](column-chart.mdx)

O Gráfico de rosca {Platform} inclui recursos interativos que oferecem ao visualizador ferramentas para analisar os dados, como:

- Legendas
- Explosão de fatias
- Seleção de fatias
- Animações do gráfico

### Boas práticas para Gráficos de rosca
- Usar vários conjuntos de dados para exibir os seus dados em uma exibição de anéis.
- Colocar informações como valores ou rótulos dentro do furo da rosca, para uma explicação rápida dos dados.
- Comparar fatias ou segmentos como valores percentuais em proporção a um valor total ou a um todo.
- Mostrar como um grupo de categorias se divide em segmentos menores.
- Garantir que os segmentos de dados somem 100%.
- Garantir que a paleta de cores seja distinguível entre os segmentos/fatias das partes.

### Quando não usar um Gráfico de rosca
- Comparar a variação ao longo do tempo: use um gráfico de [Barras](bar-chart.mdx), [Linhas](line-chart.mdx) ou [Área](area-chart.mdx).
- Exigir uma comparação precisa dos dados: use um gráfico de [Barras](bar-chart.mdx), [Linhas](line-chart.mdx) ou [Área](area-chart.mdx).
- Você tem mais de 6 ou 8 segmentos (grande volume de dados): considere um gráfico de [Barras](bar-chart.mdx), [Linhas](line-chart.mdx) ou [Área](area-chart.mdx), se ele funcionar para a história dos seus dados.
- Seria mais fácil para o visualizador perceber a diferença de valor em um gráfico de [Barras](bar-chart.mdx).
- Você tem dados negativos, o que não pode ser representado em um gráfico de rosca.

## Gráfico de rosca de {Platform} - Seleção de fatias
O Gráfico de rosca de {Platform} tem a capacidade de selecionar fatias ao clicar. Opcionalmente, você pode aplicar um único estilo visual personalizado às fatias selecionadas. O evento `sliceClick` é disparado quando o usuário clica em uma fatia. Habilitar a seleção de fatias permite modificar a seleção da fatia ao clicar.
