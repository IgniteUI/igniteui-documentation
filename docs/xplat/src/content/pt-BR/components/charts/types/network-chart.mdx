# Gráfico de rede de {Platform}
O Gráfico de rede {ProductName}, também chamado de grafo de rede ou gráfico de polilinha, visualiza relações complexas entre uma grande quantidade de elementos. Esta visualização exibe estruturas de grafos não direcionados e direcionados. Ela também mostra as relações entre entidades, representadas por nós redondos, e as linhas mostram as relações entre elas.

As seções a seguir apresentam exemplos de vários tipos de Gráficos de rede.

## Gráfico polar de rede de {Platform}
Este exemplo demonstra como criar um Gráfico polar de rede usando `PolarScatterSeries` (para renderizar os marcadores dos nós) e `PolarLineSeries` (para renderizar as conexões entre os nós) no controle `DataChart`.
