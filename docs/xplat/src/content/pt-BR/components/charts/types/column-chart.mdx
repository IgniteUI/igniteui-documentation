# Gráfico de colunas de {Platform}

O Gráfico de colunas {ProductName}, ou gráfico de barras verticais, está entre os tipos de gráfico de categoria mais comuns, usados para comparar rapidamente frequência, contagem, total ou média de dados em diferentes categorias, com os dados codificados por colunas de larguras iguais, mas alturas diferentes. Essas colunas se estendem da parte inferior à superior do gráfico, em direção aos valores dos pontos de dados. Este gráfico enfatiza a quantidade de variação ao longo de um período ou compara vários itens. O Gráfico de colunas é muito semelhante ao [Gráfico de barras](bar-chart.mdx), exceto que o Gráfico de colunas é renderizado com orientação vertical (de cima para baixo), enquanto o [Gráfico de barras](bar-chart.mdx) tem orientação horizontal (da esquerda para a direita) ou rotação de 90 graus no sentido horário.

## Recomendações para Gráficos de colunas

### Casos de uso de Gráficos de colunas

Há vários casos de uso para Gráficos de colunas. Quando você:

- Precisa comparar valores de dados de categorias relacionadas.
- Precisa comparar dados ao longo de um período.
- Precisa exibir valores negativos e positivos no mesmo conjunto de dados.
- Você tem um conjunto de dados grande e de alto volume, que se adapta bem às interações do gráfico, como deslocamento, zoom e detalhamento (drill-down).

### Boas práticas para Gráficos de colunas

- Sempre comece o eixo Y (eixo à esquerda ou à direita) em 0, para que a comparação dos dados seja precisa.
- Ordene os dados de série temporal da esquerda para a direita.

### Quando não usar Gráficos de colunas

- Você tem muitas séries de dados (mais de 10 ou 12). Seu objetivo é garantir que o gráfico seja legível.

### Estrutura de dados de Gráficos de colunas

- O modelo de dados deve conter pelo menos uma propriedade numérica.
- O modelo de dados pode conter uma propriedade de string de opções ou de data e hora para os rótulos.
- A fonte de dados deve conter pelo menos um item de dados.

## Gráfico em cascata de {Platform}

O Gráfico em cascata pertence a um grupo de gráficos de categoria e é renderizado usando uma coleção de colunas verticais que mostram a diferença entre pontos de dados consecutivos. As colunas são codificadas por cor para distinguir as variações positivas e negativas do valor. O Gráfico em cascata tem aparência semelhante ao [Gráfico de colunas de intervalo](column-chart.mdx#gráfico-de-colunas-de-intervalo-de-{PlatformLower}), mas exige apenas uma coluna de dados numérica, em vez de duas colunas para cada ponto de dados.

Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `WaterfallSeries`, como mostrado no exemplo abaixo:

## Gráfico de colunas empilhado de {Platform}

O Gráfico de colunas empilhado é semelhante ao [Gráfico de colunas de categoria](column-chart.mdx#exemplo-de-gráfico-de-colunas-de-{PlatformLower}) em todos os aspectos, exceto que as séries são representadas umas sobre as outras, em vez de lado a lado. O Gráfico de colunas empilhado é usado para mostrar a comparação de resultados entre séries. Cada fragmento empilhado na coleção representa um elemento visual em cada pilha. Cada pilha pode conter valores positivos e negativos. Todos os valores positivos são agrupados no lado positivo do eixo Y, e todos os valores negativos são agrupados no lado negativo do eixo Y. O Gráfico de colunas empilhado usa os mesmos conceitos de plotagem de dados do [Gráfico de barras empilhado](stacked-chart.mdx#gráfico-de-barras-empilhado-de-{PlatformLower}), mas os pontos de dados são empilhados ao longo de uma linha vertical (eixo Y), em vez de ao longo de uma linha horizontal (eixo X).

Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `StackedBarSeries`, como mostrado no exemplo abaixo:

## Gráfico de colunas de intervalo de {Platform}

O Gráfico de colunas de intervalo {Platform} pertence a um grupo de gráficos de intervalo e é renderizado usando retângulos verticais que podem aparecer no meio da área de plotagem do gráfico, em vez de se estenderem a partir da parte inferior, como o tradicional [Gráfico de colunas de categoria](column-chart.mdx#exemplo-de-gráfico-de-colunas-de-{PlatformLower}). Este tipo de série enfatiza a quantidade de variação entre valores baixos e valores altos no mesmo ponto de dados ao longo de um período, ou compara vários itens. Os valores de intervalo são representados no eixo Y, e as categorias são exibidas no eixo X.

O Gráfico de colunas de intervalo é idêntico ao [Gráfico de área de intervalo](area-chart.mdx#gráfico-de-área-de-intervalo-de-{PlatformLower}) em todos os aspectos, exceto que os intervalos são representados como um conjunto de colunas verticais, em vez de uma área preenchida.

Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `RangeColumnSeries`, como mostrado no exemplo abaixo:

<Sample src="/charts/data-chart/range-column-chart" height={600} alt="Gráfico de colunas de intervalo de {Platform}" />




## Gráfico de colunas radial de {Platform}

O Gráfico de colunas radial pertence a um grupo de [Gráficos radiais](radial-chart.mdx) e é visualizado usando uma coleção de retângulos que se estendem do centro do gráfico em direção às posições dos pontos de dados.
