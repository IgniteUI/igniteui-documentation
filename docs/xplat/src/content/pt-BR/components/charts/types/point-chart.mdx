# Gráfico de pontos de {Platform}
O Gráfico de pontos {ProductName} renderiza uma coleção de pontos. Os valores são representados no eixo y (rótulos à esquerda), e as categorias são exibidas no eixo x (rótulos na parte inferior). Esses gráficos enfatizam a quantidade de variação ao longo de um período ou comparam vários itens, bem como a relação entre partes de um todo, exibindo o total dos valores plotados.

## Exemplo de Gráfico de pontos de {Platform}
Você pode criar o Gráfico de pontos {Platform} no `CategoryChart` vinculando os seus dados à propriedade `dataSource` e definindo a propriedade `chartType` como a enumeração **Point**, como mostrado no exemplo abaixo.

## Gráfico de pontos de {Platform} com série única
No exemplo a seguir, o Gráfico de pontos {Platform} plota uma única fonte de dados, selecionando automaticamente uma coluna de dados numérica para o eixo y e uma coluna de dados não numérica para o eixo x.

## Gráfico de pontos de {Platform} com várias séries
Como o Gráfico de pontos {Platform} permite combinar várias séries e comparar ou ver como elas mudam ao longo do tempo, vejamos como é fácil fazer isso. Tudo o que precisamos fazer é vincular a uma fonte de dados que contenha os dados da China e dos EUA, e o gráfico de pontos será atualizado automaticamente para incluir os dados adicionais.
