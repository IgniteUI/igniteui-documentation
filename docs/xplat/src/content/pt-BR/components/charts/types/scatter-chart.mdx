# Gráficos de dispersão de {Platform}

O Gráfico de dispersão {ProductName} pertence a um grupo de gráficos que mostram a relação entre itens de séries distintas de dados, ou que plotam itens de dados usando coordenadas x e y numéricas. Esses gráficos chamam a atenção para intervalos irregulares ou agrupamentos de dados. Eles são frequentemente usados para plotar dados científicos e podem destacar o desvio dos dados coletados em relação aos resultados previstos. Além disso, você pode usá-los para organizar os dados cronologicamente (mesmo que os dados não estejam em ordem cronológica).

## Gráfico de dispersão com marcadores de {Platform}

O Gráfico de marcadores de dispersão {Platform} é renderizado como uma coleção de marcadores, cada um com um par de valores X/Y numéricos que determina a sua posição no sistema de coordenadas cartesianas. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `ScatterSeries`, como mostrado no exemplo abaixo:

## Gráfico de alta densidade de dispersão de {Platform}

Use o Gráfico de dispersão de alta densidade (HD) de {Platform} para vincular e exibir dados de dispersão que vão de milhares a milhões de pontos de dados, com pouco tempo de carregamento. Como esse tipo de gráfico foi projetado para uma quantidade tão grande de pontos, ele é visualizado como pontos minúsculos, e não como marcadores de tamanho normal, e exibe as áreas com mais dados usando uma densidade de cor maior, que representa um agrupamento de pontos de dados. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `HighDensityScatterSeries`, como mostrado no exemplo abaixo:

<Sample src="/charts/data-chart/type-scatter-hd-series" height={600} alt="Gráfico Scatter HD de {Platform}" />

## Gráfico de área de dispersão de {Platform}

O Gráfico de área de dispersão {Platform} desenha uma superfície colorida com base em uma triangulação dos dados de X e Y, com um valor de dado numérico atribuído a cada ponto. Este gráfico é útil para renderizar mapas de calor, intensidade de campo magnético ou intensidade de Wi-Fi em um escritório. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `ScatterAreaSeries`, como mostrado no exemplo abaixo:
