# Gráfico composto / combinado de {Platform}

O Gráfico composto {ProductName}, também chamado de Gráfico combinado, é uma visualização que combina diferentes tipos de gráfico na mesma área de plotagem. Ele é muito útil para apresentar duas séries de dados que têm escalas muito diferentes e podem ser expressas em unidades diferentes. O exemplo mais comum é dólares em um eixo e porcentagem no outro.
