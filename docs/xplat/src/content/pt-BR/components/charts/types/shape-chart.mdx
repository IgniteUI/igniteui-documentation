# Gráficos de formas de {Platform}

Os Gráficos de formas {ProductName} são um grupo de gráficos que recebem um array de formas (array ou arrays de pontos X/Y) e as renderizam como uma coleção de polígonos ou polilinhas no sistema de coordenadas cartesianas (x, y). Eles são frequentemente usados para destacar regiões em dados científicos, ou podem ser usados para plotar diagramas, plantas ou até mesmo plantas baixas de edifícios.

## Gráfico de polígonos de dispersão de {Platform}

O Gráfico de polígonos de dispersão {Platform} renderiza um array, ou array de arrays, de polígonos no sistema de coordenadas cartesianas (x, y), usando `ScatterPolygonSeries` no controle `DataChart`. Este gráfico pode ser usado para formas preenchidas de diagramas, plantas ou até mesmo plantas baixas de edifícios.

Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `ScatterPolygonSeries`, como mostrado no exemplo abaixo:

## Gráfico de polilinha de dispersão de {Platform}

O Gráfico de polilinha de dispersão {Platform} renderiza um array, ou array de arrays, de polilinhas no sistema de coordenadas cartesianas (x, y), usando `ScatterPolylineSeries` no controle `DataChart`. Este gráfico pode ser usado para os contornos de diagramas, plantas ou até mesmo plantas baixas de edifícios. Além disso, ele pode visualizar relações complexas entre uma grande quantidade de elementos.

Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `ScatterPolylineSeries`, como mostrado no exemplo abaixo:
