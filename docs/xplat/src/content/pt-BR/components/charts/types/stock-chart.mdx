# Gráfico de ações de {Platform}

O Gráfico de ações {ProductName}, às vezes chamado de Gráfico financeiro {Platform} ou Gráfico de candlestick, é uma visualização composta que renderiza dados de cotação de ações, ou dados de preços, em uma exibição interativa de série temporal. O Gráfico de ações mostra os preços de uma ação ao longo do tempo em um eixo X de série temporal. Além disso, esse gráfico mostra informações dos dados de cotação de uma empresa, como preço de abertura, preço máximo, preço mínimo e preço de fechamento (OHLC), por um período configurável. O Gráfico de ações oferece várias formas de visualizar e interpretar os dados, incluindo modos de exibição para preço e volume, além de uma série de indicadores de ações.

## Recomendações para o Gráfico de ações

### Os Gráficos de ações {Platform} são adequados para o seu projeto?

O gráfico de ações típico representa os dados de cotação em um gráfico de candlestick, que é usado para a análise técnica das faixas de preço. Um gráfico de candlestick compara os preços máximo e mínimo de um dia com a abertura e o fechamento do símbolo da ação.

- O corpo do gráfico de candlestick mostra os valores de negociação de abertura e fechamento (O/C).
- Os pavios do gráfico de candlestick mostram os preços máximo e mínimo negociados (H/L).
- A distância entre o topo e a base do valor da ação é a faixa do dia do preço da ação.
- O valor do gráfico de candlestick fica vazado quando o ativo fechou acima da abertura.
- O valor do gráfico de candlestick fica preenchido quando o ativo fechou abaixo da abertura.
- Uma vela preta ou vermelha representa um preço com fechamento mais baixo do que o fechamento da vela anterior.
- Uma vela branca ou verde representa um fechamento mais alto do que o fechamento da vela anterior.

O Gráfico de ações pode ser configurado para exibir um dos seguintes:

- Gráfico de candlestick
- Bar Chart
- Column Chart
- Line Chart

Como o Gráfico de ações foi feito para permitir que o usuário realize funções de análise de dados, ele inclui elementos interativos, como:

- Filtros por período
- Exibição de preços
- Exibição de volume
- Exibição de indicadores
- Linhas de tendência
- Exibição de navegação / barra de zoom

### Estrutura de dados do Gráfico de ações

- A fonte de dados deve ser um array ou uma lista de itens de dados.
- A fonte de dados deve conter pelo menos um item de dados.
- Todos os itens de dados devem conter pelo menos uma coluna de data e hora (ou de texto) que represente a data dos dados de cotação.
- Todos os itens de dados devem conter 1 coluna numérica para os gráficos de Barra, Linha e Coluna.
- Todos os itens de dados devem conter 4 colunas numéricas para Abertura, Máxima, Mínima, Fechamento (OHLC), em um gráfico de candlestick.
- Todos os itens de dados devem conter 5 colunas numéricas para Abertura, Máxima, Mínima, Fechamento e Volume, em um gráfico de candlestick.

## Anotações de gráfico de {Platform}

A Camada de anotação de linha de mira fornece linhas cruzadas que se encontram no valor real de cada série-alvo. Os tipos de linha de mira incluem: Horizontal, Vertical e Ambas. As linhas de mira também podem ser configuradas para se ajustar aos pontos de dados, definindo a propriedade `DomainChart.CrosshairsSnapToData` como true; caso contrário, as linhas de mira serão interpoladas entre os pontos de dados. Anotações também podem ser habilitadas para exibir o valor da linha de mira ao longo do eixo.

A Camada de valor final oferece uma visão rápida, ao longo do eixo, do valor final exibido em uma série.

A Camada de callout exibe um callout nas posições X/Y.

Observação: ao usar o modo de eixo X ordinal, o CalloutsXMemberPath deve apontar para o índice numérico do item; caso contrário, o CalloutsXMemberPath deve apontar para o valor de tempo.

## Painéis do gráfico de {Platform}

Os seguintes painéis estão disponíveis:

- Painel de preços - renderiza preços usando linha, candlestick, barra (OHLC), linhas de tendência e sobreposições financeiras.
- Painel de indicadores - renderiza todos os indicadores financeiros em um gráfico separado, enquanto as sobreposições BollingerBands e PriceChannel são renderizadas no Painel de preços porque compartilham o mesmo intervalo de valores no eixo Y.
- Painel de volume - renderiza os volumes das ações usando os tipos de gráfico Coluna, Linha e Área, abaixo de todos os painéis acima.
- Painel de zoom - controla o zoom de todos os painéis e é sempre renderizado na parte inferior do gráfico.

### Painel de indicadores
Os indicadores financeiros são frequentemente usados por traders para medir variações e mostrar tendências nos preços das ações. Esses indicadores geralmente são exibidos abaixo do painel de preços, porque não compartilham a mesma escala do eixo Y.

Por padrão, os painéis de indicadores não são exibidos. A barra de ferramentas permite ao usuário final selecionar qual indicador exibir em tempo de execução.

### Painel de volume
O painel de volume representa a quantidade de ações negociadas em um determinado período. Volume baixo indica pouco interesse, enquanto volume alto indica grande interesse, com muitas negociações. Isso pode ser exibido com os tipos de gráfico de colunas, linhas ou áreas. A barra de ferramentas permite ao usuário final exibir o painel de volume selecionando um tipo de gráfico para renderizar os dados em tempo de execução.
