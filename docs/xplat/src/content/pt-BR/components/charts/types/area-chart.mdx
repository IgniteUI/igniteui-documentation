# Gráfico de área de {Platform}

O Gráfico de área {ProductName} é renderizado como uma coleção de pontos conectados por segmentos de reta, com a área abaixo da linha preenchida. Os valores são representados no eixo y (rótulos à esquerda), e as categorias são exibidas no eixo x (rótulos na parte inferior). Este gráfico enfatiza a quantidade de variação ao longo de um período ou compara vários itens, bem como a relação entre partes de um todo, exibindo o total dos valores plotados. Por isso, geralmente são cronológicos, mostrando uma variação de quantidade, por exemplo, o acúmulo de uma commodity ao longo do tempo.

## Recomendações para o Gráfico de área

### Casos de uso do Gráfico de área

Há vários casos de uso comuns para escolher um Gráfico de área:

- Você tem um conjunto de dados grande e de alto volume, que se adapta bem às interações do gráfico, como deslocamento, zoom e detalhamento (drill-down).
- Você precisa comparar as tendências dos seus dados ao longo do tempo.
- Você quer mostrar a diferença entre 2 ou mais séries de dados.
- Você quer mostrar comparações cumulativas de parte do todo de categorias distintas.
- Você precisa mostrar tendências de dados de uma ou mais categorias para análise comparativa.
- Você precisa visualizar detalhes de dados de série temporal.

### Boas práticas para o Gráfico de área

- Sempre comece o eixo Y (eixo à esquerda ou à direita) em 0, para que a comparação dos dados seja precisa.
- Ordene os dados de série temporal da esquerda para a direita.
- Use cores transparentes para garantir que os dados plotados atrás de outra série não fiquem bloqueados.

### Quando não usar Gráficos de área

- Você tem muitas séries de dados (mais de 7 ou 10). Seu objetivo é garantir que o gráfico seja legível.
- Os dados de série temporal têm valores semelhantes (dados do mesmo período). Isso torna impossível diferenciar as áreas sombreadas sobrepostas.

### Estrutura de dados do Gráfico de área

- A fonte de dados deve ser um array ou uma lista de itens de dados (para uma única série).
- A fonte de dados deve ser um array de arrays ou uma lista de listas (para várias séries).
- A fonte de dados deve conter dois ou mais itens de dados para renderizar uma linha entre eles.
- Todos os itens de dados devem conter pelo menos uma coluna de dados (texto ou data e hora).
- Todos os itens de dados devem conter pelo menos uma coluna de dados numérica.

Os valores são representados no eixo y e as categorias são exibidas no eixo x. O gráfico de área em degraus enfatiza a quantidade de variação ao longo de um período ou compara vários itens. ## Gráfico de área empilhado de {Platform}

O Gráfico de área empilhado {Platform} é renderizado usando uma coleção de pontos conectados por segmentos de reta, com a área abaixo da linha preenchida e empilhada uma sobre a outra. Os Gráficos de área empilhados seguem todos os mesmos requisitos dos Gráficos de área; a única diferença é que, visualmente, as áreas sombreadas ficam empilhadas umas sobre as outras. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a `StackedAreaSeries`, como mostrado no exemplo abaixo.

## Gráfico de área de spline empilhado 100% de {Platform}

O Gráfico de área de spline empilhado 100% {Platform} é idêntico ao Gráfico de área de spline empilhado em todos os aspectos, exceto pelo tratamento dos valores no eixo y. Em vez de apresentar uma representação direta dos dados, o Gráfico de área de spline empilhado 100% apresenta os dados em termos de percentual da soma de todos os valores de um determinado ponto de dados. Às vezes, o gráfico representa parte de um todo que muda ao longo do tempo. Por exemplo, o consumo de energia de um país em relação às fontes de que ela é produzida. Nesses casos, representar todos os elementos empilhados de forma igual pode ser uma ideia melhor. ## Gráfico de área radial de {Platform}

O Gráfico de área radial {Platform} pertence a um grupo de [Gráficos radiais](radial-chart.mdx) e tem o formato de um polígono preenchido, delimitado por uma coleção de linhas retas que conectam os pontos de dados. Este tipo de gráfico usa o mesmo conceito de plotagem de dados do Gráfico de área, mas envolve os pontos de dados em torno de um eixo circular, em vez de esticá-los horizontalmente. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a `RadialAreaSeries`, como mostrado no exemplo abaixo.

## Gráfico de área polar de {Platform}

O Gráfico de área polar {Platform} pertence a um grupo de [Gráficos polares](polar-chart.mdx) e tem o formato de um polígono preenchido, em que os vértices ou cantos ficam nas coordenadas polares (ângulo/raio) dos pontos de dados e são conectados por uma linha reta; em seguida, a área representada pelos pontos conectados é preenchida. O Gráfico de área polar usa os mesmos conceitos de plotagem de dados do Gráfico de marcadores de dispersão, mas, em vez de esticar os pontos e a área preenchida ao longo de uma linha horizontal, envolve os pontos em torno de um círculo e preenche a área desenhada. Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a `PolarAreaSeries`, como mostrado no exemplo abaixo.


<Sample src="/charts/data-chart/polar-area-chart" height={600} alt="Gráfico de área polar de {Platform}" />
