# Gráfico de pirâmide de {Platform}

O Gráfico de pirâmide {ProductName}, também chamado de pirâmide etária ou pirâmide populacional, é uma ilustração gráfica que mostra a distribuição de vários grupos etários em uma população, formando o formato de uma pirâmide quando a população está crescendo. Ele também é usado em ecologia para determinar a distribuição etária geral de uma população, indicando a capacidade reprodutiva e a probabilidade de continuidade de uma espécie.
