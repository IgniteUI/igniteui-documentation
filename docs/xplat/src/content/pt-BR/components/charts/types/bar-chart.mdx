# Gráfico de barras de {Platform}
O Gráfico de barras {ProductName}, ou diagrama de barras, ou gráfico de barras horizontais, está entre os tipos de gráfico de categoria mais comuns, usados para comparar rapidamente frequência, contagem, total ou média de dados em diferentes categorias, com os dados codificados por barras horizontais de mesma altura, mas com comprimentos diferentes. Este gráfico é ideal para mostrar variações no valor de um item ao longo do tempo. Os dados são representados por um conjunto de retângulos que se estendem da esquerda para a direita do gráfico, em direção aos valores dos pontos de dados. O Gráfico de barras é muito semelhante ao [Gráfico de colunas](column-chart.mdx), exceto que o Gráfico de barras é renderizado com uma rotação de 90 graus no sentido horário e, por isso, tem orientação horizontal (da esquerda para a direita), enquanto o [Gráfico de colunas](column-chart.mdx) tem orientação vertical (de cima para baixo)

## Recomendações para o Gráfico de barras

### Os Gráficos de barras {Platform} são adequados para o seu projeto?
O Gráfico de barras {Platform} inclui várias variantes, de acordo com os seus dados ou com a forma como você quer contar a história correta com eles. Elas incluem:

- Gráfico de barras agrupado
- Gráfico de barras empilhado
- Gráfico de barras polar
- Gráfico de barras empilhado 100

### Casos de uso do Gráfico de barras
Há vários casos de uso comuns para escolher um Gráfico de barras:

- Você precisa mostrar tendências ao longo do tempo ou a variação de um valor numérico em uma categoria de dados.
- Você precisa comparar valores de dados de 1 ou mais séries de dados.
- Você quer mostrar uma comparação de parte do todo.
- Você quer mostrar a porcentagem das categorias com os maiores ou menores valores.
- Analisar vários pontos de dados agrupados em subcategorias (Barras empilhadas).

Esses casos de uso são comumente usados nos seguintes cenários:

- Gestão de vendas.
- Gestão de estoque.
- Gráficos de ações.
- Qualquer valor de texto comparado a um valor numérico ou a um valor de série temporal.

### Boas práticas para o Gráfico de barras
- Comece o seu eixo numérico em 0.
- Use uma única cor para as barras.
- Certifique-se de que o espaço que separa cada barra seja metade da largura da própria barra.
- Certifique-se de que, ao classificar ou comparar categorias (itens) ordenadas, elas estejam em ordem crescente ou decrescente.
- Alinhe à direita os valores das categorias no eixo Y (rótulos à esquerda do gráfico), para facilitar a leitura.

### Quando não usar o Gráfico de barras
- Você tem dados demais, de modo que o eixo Y não cabe no espaço ou não fica legível.
- Você precisa de uma análise detalhada de série temporal: considere um [Gráfico de linhas](line-chart.mdx) com uma série temporal para este tipo de dado.

### Estrutura de dados do Gráfico de barras
- A fonte de dados deve ser um array ou uma lista de itens de dados.
- A fonte de dados deve conter pelo menos um item de dados.
- A lista deve conter pelo menos uma coluna de dados (texto ou data e hora).
- A lista deve conter pelo menos uma coluna de dados numérica.

## Gráfico de barras empilhado de {Platform}

Um Gráfico de barras empilhado, ou diagrama de barras empilhado, é um tipo de gráfico de categoria usado para comparar a composição de diferentes categorias de dados, exibindo fragmentos de tamanhos diferentes nas barras horizontais do gráfico. O comprimento de cada barra, ou pilha de fragmentos, é proporcional ao valor total dela.

O Gráfico de barras empilhado difere do Gráfico de barras porque os pontos de dados que representam os seus dados são empilhados lado a lado, horizontalmente, para agrupar visualmente os dados. Cada pilha pode conter valores positivos e negativos. Todos os valores positivos são agrupados no lado positivo do eixo X, e todos os valores negativos são agrupados no lado negativo do eixo X.

Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `StackedBarSeries`, como mostrado no exemplo abaixo:

O Gráfico de barras empilhado 100% {Platform} é idêntico ao Gráfico de barras empilhado {Platform} em todos os aspectos, exceto no tratamento dos valores do eixo X (rótulos na parte inferior do gráfico). ## Gráfico de barras de intervalo de {Platform}

O Gráfico de barras de intervalo {Platform} pertence a um grupo de gráficos de intervalo e é renderizado usando retângulos horizontais que podem aparecer no meio da área de plotagem do gráfico, em vez de se estenderem a partir da esquerda, como o tradicional [Gráfico de barras de categoria](bar-chart.mdx#exemplo-de-gráfico-de-barras-de-{PlatformLower}). Este tipo de série enfatiza a quantidade de variação entre valores baixos e valores altos no mesmo ponto de dados ao longo de um período, ou compara vários itens.

Os valores de intervalo são representados no eixo X, e as categorias são exibidas no eixo Y. Como cada barra visualiza um valor baixo e um valor alto, este gráfico é útil em cenários como mostrar faixas de temperatura diária, preços mínimos e máximos, ou quaisquer medições limitadas em que um único valor não seja suficiente.

O Gráfico de barras de intervalo é idêntico ao [Gráfico de colunas de intervalo](column-chart.mdx#gráfico-de-colunas-de-intervalo-de-{PlatformLower}) em todos os aspectos, exceto que os intervalos são representados como um conjunto de barras horizontais, em vez de colunas verticais.

Você pode criar este tipo de gráfico no controle `DataChart` vinculando os seus dados a uma `RangeBarSeries`. A série lê os valores baixos e altos de `LowMemberPath` e `HighMemberPath`, e normalmente usa uma `NumericXAxis` com uma `CategoryYAxis`, como mostrado no exemplo abaixo:
