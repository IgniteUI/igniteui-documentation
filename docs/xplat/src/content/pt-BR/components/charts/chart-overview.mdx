## Categoria<PlatformBlock for="Web"> e Financial</PlatformBlock> Chart x Data Chart

O {Platform} Category<PlatformBlock for="Web"> e Financial</PlatformBlock> Chart é o que chamamos de gráficos específicos de domínio. É um wrapper em torno do Data Chart de {Platform} que pressupõe que o seu domínio seja uma categoria<PlatformBlock for="Web">, ou uma série de preços financeiros</PlatformBlock>.

Escolher esses gráficos específicos de domínio permite simplificar a API e deduzir muitas configurações sobre os dados para configurar automaticamente o cenário do gráfico, sem precisar definir explicitamente atributos como eixos, séries e anotações. Em contraste, o data chart é muito explícito, e cada parte crítica do gráfico precisa ser definida.

Os gráficos de domínio usam um data chart em sua base; por isso, as mesmas otimizações de desempenho se aplicam a ambos. A diferença está em tentar tornar as coisas muito fáceis de especificar para o desenvolvedor ou em ser o mais flexível possível. O Data Chart de {Platform} é mais detalhado, liberando todos os recursos de gráficos de que você precisa, e permitindo combinar qualquer número de séries, eixos ou anotações, por exemplo. Para o category<PlatformBlock for="Web"> e o financial</PlatformBlock> gráficos, pode haver uma situação que não pode ser feita facilmente e para a qual o data chart é mais adequado, como uma série com uma série de dispersão e um eixo X numérico.

Pode ser difícil saber qual gráfico escolher no início. É fundamental entender o tipo de série e quantos recursos adicionais você quer apresentar. Para uma série category<PlatformBlock for="Web"> ou financial</PlatformBlock> mais leve e básica, recomendamos usar um dos gráficos de domínio. Para cenários mais avançados, recomendamos usar o Data Chart de {Platform}, por exemplo, para apresentar algo diferente do que é coberto por `CategoryChart.chartType`, como uma série empilhada ou de dispersão, ou dados numéricos ou baseados em tempo.<PlatformBlock for="Web"> Vale notar que o Financial Chart de {Platform} cobre apenas os tipos de série de coluna, barra OHLC, candlestick e linha.</PlatformBlock>

Tornamos o {Platform} Category<PlatformBlock for="Web"> e Financial</PlatformBlock> Chart mais fácil de usar. A boa notícia é que você sempre pode mudar para o data chart no futuro.

### Gráfico de barras de {Platform}

O Gráfico de barras {Platform}, ou gráfico de barras horizontais, está entre os tipos de gráfico de categoria mais comuns, usados para comparar rapidamente frequência, contagem, total ou média de dados em diferentes categorias, com os dados representados por barras horizontais de largura igual e comprimentos diferentes. Eles são ideais para mostrar variações no valor de um item ao longo do tempo, distribuição de dados e classificação de dados ordenados (do maior para o menor, do pior para o melhor). Os dados são representados por um conjunto de retângulos que se estendem da esquerda para a direita do gráfico, em direção aos valores dos pontos de dados. Saiba mais sobre nosso [gráfico de barras](types/bar-chart.mdx)

### Gráfico de pizza de {Platform}

O Gráfico de pizza {Platform}, ou gráfico de setores, é um tipo de gráfico de parte do todo muito comum. Gráficos de parte do todo mostram como as categorias (partes) de um conjunto de dados somam um valor total (o todo). As categorias são exibidas proporcionalmente às outras categorias, com base no percentual do valor em relação ao total analisado. Um gráfico de pizza representa os valores dos dados como setores de um gráfico circular. Cada setor, ou fatia da pizza, tem um comprimento de arco proporcional ao valor de dados correspondente. Os valores totais representados pelas fatias formam um valor inteiro, como 100 ou 100%. Gráficos de pizza são perfeitos para conjuntos de dados pequenos e são fáceis de ler em uma rápida olhada. Saiba mais sobre nosso [gráfico de pizza](types/pie-chart.mdx)

### Gráfico de linhas de {Platform}

O Gráfico de linhas {Platform}, ou gráfico de linhas, é um tipo de gráfico de linha de categoria que mostra os valores contínuos de dados representados por pontos conectados por segmentos de reta de uma ou mais grandezas ao longo de um período, para exibir tendências e realizar análises comparativas. O eixo Y (rótulos à esquerda) mostra um valor numérico, enquanto o eixo X (rótulos na parte inferior) mostra uma série temporal ou uma categoria de comparação. Você pode incluir um ou mais conjuntos de dados para comparar, que serão renderizados como várias linhas no gráfico. Saiba mais sobre nosso [gráfico de linhas](types/line-chart.mdx)

O gráfico de rosca tem uma abertura circular no centro, onde pode ser exibido um título ou a explicação de uma categoria. Gráficos de rosca podem ter vários anéis concêntricos, com suporte integrado para visualizar dados hierárquicos. Saiba mais sobre nosso [gráfico de rosca](types/donut-chart.mdx)

### Gráfico Sparkline de {Platform}

### Gráfico de bolhas de {Platform}

O Gráfico de bolhas {Platform}, ou gráfico de bolhas, é usado para mostrar dados compostos por três valores numéricos. Dois dos valores são plotados como um ponto de interseção em um sistema de coordenadas cartesianas (X, Y), e o terceiro valor é renderizado como o tamanho do diâmetro do ponto. Isso dá nome ao Gráfico de bolhas: uma visualização de bolhas de tamanhos variados ao longo das coordenadas X e Y do gráfico. O gráfico de bolhas {Platform} é usado para mostrar relações de correlação entre dados, com as diferenças de valor representadas pelo tamanho. Você também pode usar uma quarta dimensão de dados, normalmente a cor, para diferenciar ainda mais os valores no seu gráfico de bolhas. ### Gráfico de dispersão de {Platform}

O Gráfico de dispersão {Platform}, ou gráfico de pontos, é usado para mostrar a relação entre dois valores, plotando os dados em um sistema de coordenadas cartesianas (X, Y). Cada ponto de dados é renderizado como o ponto de interseção do valor dos dados nos eixos X e Y. Gráficos de dispersão chamam a atenção para intervalos irregulares ou agrupamentos de dados. Eles podem destacar o desvio dos dados coletados em relação aos resultados previstos, e são frequentemente usados para plotar dados científicos e estatísticos. O gráfico de dispersão {Platform} organiza e plota os dados em ordem cronológica (mesmo que os dados não estejam em ordem cronológica antes da vinculação) nos eixos X e Y. Saiba mais sobre nosso [gráfico de dispersão](types/scatter-chart.mdx).

## Principais recursos dos gráficos de {Platform}

Mostre como os seus dados mudam ao longo do tempo com o Eixo de tempo integrado. Alteramos dinamicamente as escalas de tempo e os formatos dos rótulos conforme você interage com o gráfico.<PlatformBlock for="Web"> Incluímos um Gráfico financeiro completo, com todos os recursos que você espera dos seus gráficos financeiros, como os do Yahoo Finance ou do Google Finance.</PlatformBlock>

### Gráficos dinâmicos

Visualize seus dados criando um novo [Gráfico composto](types/composite-chart.mdx) e sobrepondo várias séries em um único gráfico. No gráfico, você pode exibir e sobrepor várias colunas para criar colunas empilhadas.

Visualize seus dados criando novas visões compostas e sobrepondo várias séries em um único gráfico. No gráfico, você pode criar [dicas de ferramenta personalizadas](features/chart-tooltips.mdx#modelo-de-dica-de-ferramenta-do-gráfico-de-{PlatformLower}) com imagens, vinculação de dados e até combinar as dicas de ferramenta de várias séries em uma única dica.

### Gráficos em tempo real de alto desempenho

Exiba milhares de pontos de dados com atualizações em milissegundos, em tempo real, com dados ao vivo em streaming. Você não vai sentir atrasos, cintilação de tela nem demoras visuais, mesmo ao interagir com o gráfico em um dispositivo de toque. Para uma demonstração, consulte o tópico [Gráfico com alta frequência](features/chart-performance.mdx#gráfico-de-{PlatformLower}-com-alta-frequência).

### Tratamento de dados de grande volume

Para uma demonstração, consulte o tópico [Gráfico com grande volume](features/chart-performance.mdx#gráfico-de-{PlatformLower}-com-grande-volume).
