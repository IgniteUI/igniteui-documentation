# Elevações no {ProductName}

A implementação das elevações no {ProductName} é inspirada nas [elevações do Material Design](https://material.io/design/environment/elevation.html#elevation-in-material-design). Elas são usadas para estabelecer e manter limites funcionais entre árvores do Document Object Model, permitindo um melhor encapsulamento funcional.

## Visão geral

As sombras do {ProductName} seguem de perto as diretrizes do Material Design para estabelecer hierarquia de profundidade com base em 25 níveis de elevação. O tamanho da sombra projetada está relacionado ao número do nível de elevação: quanto maior o número, maior a sombra. As elevações no {ProductName} são expostas como variáveis CSS. Cada variável armazena um conjunto de 3 `box-shadows`. Esses `box-shadows` representam os elementos umbra, penumbra e antumbra, que são as propriedades das sombras observadas no mundo real.

Aqui está uma lista das elevações de repouso usadas em vários componentes do {ProductName} no tema Bootstrap, e os nomes correspondentes das variáveis CSS:

| Componente                                       | Nível de elevação padrão | Variável CSS       |
| ----------------------------------------------- | ----------------------- | ------------------ |
| Botão                                          | 0                       | --ig-elevation-0  |
| Card elevado                                   | 2                       | --ig-elevation-2  |
| Toast, Snackbar                                 | 10                      | --ig-elevation-10 |
| Navdrawer                                       | 16                      | --ig-elevation-16 |

Como você pode ver na coluna **Variável CSS**, todas as elevações são definidas no formato `--ig-elevation-[level]`. Como mencionado, o número do nível de elevação vai de 0 a 24 (inclusive).

## Uso

Para começar a usar elevações nos seus próprios componentes, basta referenciar o nome da variável do nível desejado:

```css
.custom-element {
  box-shadow: var(--ig-elevation-6);
}
```

Alterar a elevação em um tema de componente existente funciona de forma semelhante:

```css
igc-navbar {
  box-shadow: var(--ig-elevation-8);
}
```

## Definindo elevações

Atualizar as elevações padrão funciona de forma semelhante a atualizar as cores da paleta. Basta atribuir novamente a variável a um valor diferente. Com elevações, certifique-se de que o valor seja `box-shadow`.

Exemplo:

```css
:root {
  --ig-elevation-1: 0 2px 6px 0 rgba(0, 0, 0, .18);
  --ig-elevation-2: 0 3px 9px 0 rgba(0, 0, 0, .24);
}
```

Agora, todos os componentes que usam os níveis de elevação 1 e 2 terão as suas sombras atualizadas.

### Sombreamento

Você pode sobrescrever as elevações definidas globalmente apenas para um escopo específico. Já vimos que o Snackbar e o Toast usam o nível de elevação 10. Para alterar as sombras dos dois, basta fazer o seguinte:

```css
igc-snackbar,
igc-toast {
  --ig-elevation-10: 0 3px 9px 0 rgba(0, 0, 0, .24);
}
```

Isso definirá as sombras do toast e do snackbar como o valor atribuído a `--ig-elevation-10`.

## Usando o fator de elevação

Além dos níveis de elevação, o {ProductName} expõe uma variável CSS que facilita controlar o fator de elevação global. O valor padrão é 1, o que significa que todas as sombras dos componentes serão iguais às definidas nos temas dos componentes. Se quiser remover todas as sombras, basta alterar o valor da propriedade para 0:

```css
:root {
  --ig-elevation-factor: 0;
}
```

O `--ig-elevation-factor` também pode ser definido como um valor decimal ou como um valor maior que 1. Quanto maior o valor, maior será a sombra.
