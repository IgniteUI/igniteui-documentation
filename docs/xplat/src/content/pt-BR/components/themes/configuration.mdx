# Personalizando temas no {ProductName}

Os temas em {ProductName} podem ser personalizados alterando várias variáveis CSS. Ao sobrescrever essas variáveis, você pode personalizar as paletas, a tipografia, as elevações, o arredondamento, o tamanho e o espaçamento.

## Visão geral

As seções a seguir abordam paletas, tipografia e elevações; esta trata das opções que afetam a estilização dos componentes em nível global, por meio da alteração de uma única variável.


## Arredondamento

Todos os componentes definem algum tipo de arredondamento (border-radius). Enquanto alguns componentes oferecem atributos para definir o formato do componente, como o avatar e o badge, outros, como o botão, definem o seu border-radius internamente, como parte do tema. Nesses casos, você pode ajustar o border-radius desses componentes modificando o valor da variável CSS `--ig-radius-factor`. Você pode modificá-la globalmente no escopo `:root`, ou componente por componente. A variável aceita um número racional entre 0 e 1. Definir o valor como 0 efetivamente define o border radius como 0. Definir o valor como 1 define o border radius para o border radius inicial predefinido. Qualquer valor entre 0 e 1, como 0.5, por exemplo, define o border radius como 50% do border radius padrão definido na folha de estilo do componente.

Exemplos:

```css
/* Set the border-radius for all components to 50% of their default value. */
:root {
  --ig-radius-factor: .5;
}
```

```css
/* Set the border-radius of the button component to 0. */
igc-button {
  --ig-radius-factor: 0;
}
```

## Elevação

Assim como o raio global, alguns componentes definem uma elevação interna (box-shadow). Deixar todos os componentes planos pode ser trabalhoso se for feito sobrescrevendo o box-shadow de cada um. Você pode modificar o comportamento do box-shadow de todos os componentes alterando a variável CSS `--ig-elevation-factor`. A variável aceita um número racional entre 0 e 1. Definir o valor como 0 efetivamente define o box-shadow de todos os componentes como none. Definir o valor como 1 define o valor de elevação para os valores iniciais predefinidos de box-shadow. Qualquer valor entre 0 e 1, como 0.5, por exemplo, define a intensidade do box-shadow como 50% do valor original definido na folha de estilo do componente.

```css
/* Set the elevation for all components to 50% of their original box-shadow values. */
:root {
  --ig-elevation-factor: .5;
}
```

## Tamanho

Alguns componentes oferecem suporte a tamanhos variáveis — `small`, `medium` e `large`, com um tamanho padrão definido na folha de estilo do componente. Você pode alterar o tamanho de todos os componentes simultaneamente ou individualmente, usando a variável CSS `--ig-size`. Os valores possíveis são `var(--ig-size-small)`, `var(--ig-size-medium)` ou `var(--ig-size-large)`;

Para definir um tamanho específico para todos os componentes da sua aplicação, defina a variável `--ig-size` no escopo `:root`.

Exemplo:

```css
:root {
  --ig-size: var(--ig-size-small);
}
```

Como alternativa, se quiser direcionar apenas um componente específico, limite a variável ao seletor de tag do componente.

```css
igc-avatar {
  --ig-size: var(--ig-size-medium);
}
```

## Espaçamento

Espaçamento refere-se aos paddings e margens internos dos componentes, definidos pelo tema do componente. O espaçamento pode ser horizontal (inline) e vertical (block). Tornamos fácil controlar como os vários elementos recebem padding dentro de um componente, sem precisar sobrescrever manualmente todos os valores de padding e margin de cada componente. Isso é feito pela variável CSS `--ig-spacing`. Você pode definir o valor como qualquer número racional positivo, e o espaçamento será escalado de acordo. O valor padrão é 1, que representa o padding/margin horizontal/vertical padrão definido na folha de estilo do componente. Alterar o valor para 1,5 escalará todo o espaçamento em 1,5 vez, ou 150%. Por outro lado, definir o valor como 0 agrupará tudo e reduzirá todo o espaçamento ao equivalente a nenhum padding/margin. A alteração do fator de espaçamento funciona em conjunto com a propriedade de tamanho e será escalada de acordo.

Alguns componentes permitem alterar o espaçamento somente em uma direção (horizontal ou vertical), enquanto outros permitem especificar valores de espaçamento separados nas duas direções.

Para alterar o espaçamento de todos os componentes, você pode sobrescrever o seu valor no escopo `:root`.

Exemplo:

```css
/* Increase the spacing for all components to 150%. */
:root {
  --ig-spacing: 1.5;
}
```

Para alterar o espaçamento de um único componente, limite a variável ao seletor de tag do componente.

```css
/* Reduce the spacing for the drop-down elements to 50% of their original value. */
igc-dropdown {
  --ig-spacing: 0.5;
}
```

Como mencionado antes, você pode controlar individualmente o espaçamento horizontal e vertical dos componentes que o suportam. Isso pode ser feito modificando as variáveis `--ig-spacing-inline` (horizontal) e `--ig-spacing-block` (vertical). O princípio é o mesmo da variável `--ig-spacing`. Modificar somente a variável `--ig-spacing` alterará o espaçamento nas duas direções na mesma medida.
