# Tipografia no {ProductName}

A tipografia no {ProductName} é inspirada no [Material Type System](https://material.io/design/typography/the-type-system.html#). Ela é discreta e opcional, permitindo modificar os estilos de tipo somente com CSS.

## Visão geral

O sistema tipográfico é uma **_escala tipográfica_** composta por **_13 estilos de categoria diferentes_**, usados na maioria dos componentes. Todas as categorias de escala são totalmente reutilizáveis e podem ser ajustadas pelo usuário final.

Cada tema define a sua própria escala tipográfica. Isso significa que cada um dos temas que enviamos — Material, Fluent, Bootstrap e Indigo — terá a sua própria escala tipográfica. Todos compartilham as mesmas _categorias de escala_, mas podem ter família de fonte, peso, tamanho, transformação de texto, espaçamento entre letras e altura de linha diferentes.

## Uso

### Alterando a família da fonte

Para alterar a família da fonte em todos os componentes, basta sobrescrever a variável CSS `--ig-font-family`:

```css
:root {
  --ig-font-family: 'Helvetica Neue', sans-serif;
}
```

### Alterando os estilos de tipo

Os estilos de tipo são usados internamente pela maioria dos componentes do {ProductName}. Por exemplo, o componente `igc-button` usa o estilo de tipo de botão.
Para alterar qualquer propriedade de estilo de tipo, precisamos sobrescrever a variável CSS correspondente:

```css
:root {
  --ig-button-font-size: 22px;
  --ig-button-line-height: 26px;
  --ig-button-text-transform: lowercase;
}
```

Lembre-se de que isso atualizará os estilos globais de tipografia dos botões. Se quiser aplicar essas alterações a um botão específico, você pode usar um seletor de classe.
