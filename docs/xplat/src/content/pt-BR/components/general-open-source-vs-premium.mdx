# Código aberto x Premium no {ProductName}

O {ProductName} oferece dois caminhos distintos para criar aplicativos modernos orientados a dados: Componentes de código aberto e Componentes Premium. Essa abordagem dupla garante flexibilidade para os desenvolvedores em cada etapa do projeto.

## Componentes de código aberto

Há mais de 50 componentes de UI disponíveis sob a licença MIT, incluindo [Grid Lite](../components/grid-lite/overview.mdx), Accordion, Avatar, Badge, Banner, Button, Calendar, Carousel, Checkbox, Chip, Combo, Date Picker, Drop Down, Input, List, Snackbar e outros. Você pode encontrar a lista completa na [Tabela comparativa de todos os componentes](#tabela-de-comparação-de-todos-os-componentes).

Todos os componentes de código aberto são marcados no cabeçalho dos seus tópicos com: <Badge variant="opensource" />

Eles são ideais para aplicações leves que precisam de funcionalidades essenciais sem a sobrecarga dos recursos empresariais. Você pode usá-los livremente em produção, personalizar, fazer fork e contribuir pelo GitHub. Nenhuma licença é necessária.

Os componentes Premium do Ignite UI vêm com recursos empresariais avançados e são usados em aplicações complexas que exigem alto desempenho e funcionalidades mais ricas. Os componentes Premium incluem:

## Caminho de atualização

Comece com o Grid Lite para as necessidades essenciais e migre sem dificuldades para o Data Grid completo à medida que a complexidade da sua aplicação aumenta. Isso garante o mínimo de refatoração e uma transição tranquila para recursos de nível empresarial.
