# Guia passo a passo usando o Ignite UI CLI

O modo passo a passo do Ignite UI CLI é um assistente interativo que guia você pela criação do projeto, pela seleção de modelos, pela definição do tema e pela adição de visões de componentes para projetos {ProductName}. Ele cobre as mesmas operações dos comandos não interativos `ig new` e `ig add`, mas pergunta a cada etapa, em vez de exigir todos os argumentos de antemão.

O modo passo a passo não oferece suporte a uso por scripts ou não interativo; para isso, use os comandos `ig new` e `ig add` com argumentos explícitos. O assistente depende de `Inquirer.js`; consulte [terminais compatíveis](https://github.com/SBoudrias/Inquirer.js#support-os-terminals) para verificar a compatibilidade. Para a referência completa do CLI, consulte a [Visão geral do Ignite UI CLI](./general-cli-overview.mdx).

Para ativar o assistente, execute:

```cmd
ig
```

ou:

```cmd
ig new
```

## Criar um novo projeto

O assistente percorre, em sequência, a escolha do nome do projeto, a seleção do framework e do tipo, a escolha do modelo e a definição do tema. Cada etapa mostra as suas opções como uma lista interativa: navegue com as teclas de seta e confirme com ENTER.

### Digite um nome para o projeto

Primeiro, você será solicitado a informar um nome para o seu aplicativo. O projeto é criado dentro de uma pasta com o mesmo nome.

### Selecione um framework

Navegue pelas opções com as teclas de seta e pressione ENTER para confirmar:

Selecione **React** para montar um projeto pré-configurado para {ProductName}.
</PlatformBlock>

<PlatformBlock for="WebComponents">
Selecione **Web Components** para montar um projeto pré-configurado para {ProductName}.
</PlatformBlock>

<PlatformBlock for="Blazor">
Selecione **Blazor** para montar um projeto pré-configurado para {ProductName}.
</PlatformBlock>

### Selecione um tipo de projeto

<PlatformBlock for="React">
Selecione **Ignite UI for React TS** como tipo de projeto.
</PlatformBlock>

<PlatformBlock for="WebComponents">

### Selecione um modelo de projeto

Escolha um dos modelos de projeto disponíveis. Navegue pelas opções com as teclas de seta e pressione ENTER para confirmar:

| Side Navigation  | Estrutura de projeto com uma gaveta de navegação lateral     |
| Side Navigation Mini | Estrutura de projeto com uma gaveta de navegação lateral compacta |
</PlatformBlock>

Se você selecionar **Side Navigation** ou **Side Navigation Mini**, o assistente exibe uma etapa adicional perguntando se deseja adicionar autenticação ao projeto. Ao responder sim, é gerada a variante de autenticação correspondente (`side-nav-auth` ou `side-nav-mini-auth`). Se você selecionar **Empty**, a pergunta sobre autenticação é pulada.

### Selecione um tema

Escolha um tema para o seu aplicativo:

- A opção **default** inclui um arquivo CSS pré-compilado com o tema padrão {ProductName}.
- A opção **custom** gera uma paleta de cores e uma configuração de tema baseadas em Sass, usando a [API de temas](./themes/overview.mdx).

### Configurar as ferramentas de IA

Depois do tema, o assistente pergunta sobre a configuração dos assistentes de codificação com IA. Primeiro, selecione quais assistentes devem receber a configuração do servidor MCP:

```bash
? Which AI coding assistants do you want to configure MCP servers for? (Press <space> to select)
❯◉ VS Code (GitHub Copilot)
 ◉ Cursor
 ◯ Generic (.mcp.json)
 ◯ Gemini CLI
 ◯ JetBrains (AI Assistant)
 ◯ None
```

Em seguida, selecione quais agentes de IA devem receber os arquivos de skill:

```bash
? Which AI agents should receive skill files? (Press <space> to select)
❯◉ GitHub Copilot (.agents/skills/)
 ◉ Claude (.claude/skills/)
 ◉ Cursor (.cursor/rules/)
 ◯ Codex (.codex/)
 ◯ Windsurf (.windsurfrules)
 ◯ Gemini CLI (.gemini/)
 ◯ JetBrains Junie (.junie/guidelines/)
 ◯ None
```

Navegue pelas opções com as teclas de seta, alterne as seleções com a BARRA DE ESPAÇO e confirme com ENTER. Selecionar **None** nas duas perguntas ignora totalmente a configuração de IA.

Para pular essas perguntas no modo não interativo, passe as opções `--assistants` e `--agents` diretamente para `ig new`:

```cmd
ig new my-app --framework=react --type=igr-ts --template=side-nav --assistants vscode --agents copilot claude
```

Para mais detalhes sobre os valores disponíveis das opções, consulte [Visão geral do Ignite UI CLI](./general-cli-overview.mdx#configuração-de-ia-durante-a-criação-do-projeto).

### Concluir ou continuar

Depois de concluir as etapas acima, a estrutura do projeto é gerada, um repositório Git é inicializado e o projeto recebe um commit. Em seguida, você será perguntado se deseja concluir o processo ou adicionar uma nova visão ao seu aplicativo.

## Adicionar visão

O Ignite UI CLI oferece suporte a vários modelos de componente que podem ser adicionados a um projeto existente. Este modo está disponível como continuação da criação do projeto ou dentro de um projeto existente, usando:

```cmd
ig add
```

Você receberá uma lista dos modelos de componente disponíveis, agrupados por categoria. Use as teclas de seta para navegar pelos grupos e ENTER para selecionar. Para alguns modelos, como `Custom Grid`, você receberá uma lista de recursos opcionais que podem ser ativados ou desativados com a BARRA DE ESPAÇO antes de confirmar a sua seleção.

Depois de selecionar um grupo, escolha um modelo específico na lista e informe um nome para o novo componente. Se você optar por adicionar um modelo de cenário, também verá uma lista dos modelos de cenário disponíveis.

Depois de adicionar um modelo, você será perguntado se deseja adicionar mais visões ou concluir o processo. Ao concluir, as dependências de pacotes restantes são instaladas, e o aplicativo é compilado e aberto no seu navegador padrão.

Para adicionar mais visões a um projeto depois, sem o assistente, use o comando direto `add`:

```cmd
ig add [template] [name]
```

Por exemplo:

```cmd
ig add grid MyGrid
```

<DocsAside type="info">
Seu arquivo de rotas será atualizado com o caminho para a nova página gerada. Por exemplo, um componente chamado `MyGrid` poderá ser acessado em `/my-grid`.
</DocsAside>

## Execute a aplicação

Quando o seu projeto estiver concluído, execute-o a qualquer momento com:

```cmd
ig start
```

Isso compila o projeto, inicia um servidor Web local e abre o aplicativo no seu navegador padrão.
