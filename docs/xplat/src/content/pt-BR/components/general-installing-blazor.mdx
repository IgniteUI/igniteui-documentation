# Instalando o Ignite UI for Blazor

O Ignite UI for Blazor é distribuído por meio de pacotes NuGet. Para usar os componentes do Ignite UI for Blazor em seus aplicativos Blazor, você precisa primeiro instalar os pacotes NuGet apropriados.

Há três formas de instalar o Ignite UI for Blazor usando o NuGet:
- [Usando o Visual Studio](#usando-o-visual-studio)
- [Usando a CLI do .NET](#usando-a-cli-do-net)
- [Usando o Gerenciador de Pacotes](#usando-o-gerenciador-de-pacotes)

Usuários licenciados devem usar os pacotes NuGet oficiais licenciados do Ignite UI for Blazor, fornecidos no [Infragistics Private NuGet Feed](./general-nuget-feed.mdx).

<DocsAside type="info">
Os usuários trial podem instalar o pacote NuGet **IgniteUI.Blazor.Trial**, disponível em [NuGet.org](https://www.nuget.org/packages/IgniteUI.Blazor.Trial).
</DocsAside>

## Usando o Visual Studio

Clique com o botão direito na Solução ou no Projeto e selecione **Gerenciar pacotes NuGet para a solução**.

<Image src={nugetManagePackages} alt="nuget-manage-packages" />

Na caixa de diálogo do gerenciador de pacotes, abra a guia **Procurar**, selecione a fonte de pacotes **Infragistics** e instale o pacote NuGet **IgniteUI.Blazor** no projeto.

<Image src={nugetPackageManagerBrowse} alt="nuget-package-manager-browse" />

<DocsAside type="info">
Se você não tiver uma fonte de pacotes da Infragistics disponível, saiba como adicioná-la lendo o tópico [Feed NuGet da Infragistics](./general-nuget-feed.mdx).
</DocsAside>

## Usando a CLI do .NET

```cmd
> dotnet add package IgniteUI.Blazor --version {PackageVerLatestShort}
```

## Usando o Gerenciador de Pacotes

```cmd
PM> Install-Package IgniteUI.Blazor -Version {PackageVerLatestShort}
```
