# Visão geral do Pivot Grid {Platform}

O Pivot Grid {Platform} é usado para totalizar e representar dados multidimensionais volumosos em um formato de tabela cruzada. O resumo dos dados pode ser facilmente e rapidamente ordenado, agrupado ou filtrado. Esses dados podem incluir somas, médias e outras estatísticas. Os usuários finais podem modificar o layout da tabela dinâmica por meio de operações de arrastar e soltar, de acordo com as suas necessidades.

O Pivot Grid {Platform} apresenta os dados em uma tabela dinâmica e ajuda os usuários a realizar análises complexas sobre o conjunto de dados fornecido. Este controle sofisticado de Pivot Grid é usado para organizar, resumir e filtrar grandes volumes de dados, que são exibidos depois em um formato de tabela cruzada. Os principais recursos de um Pivot Grid {Platform} são dimensões de linha, dimensões de coluna, agregações e filtros.

O <ApiLink type="PivotGrid" /> permite que os usuários configurem e exibam os seus dados em uma estrutura de tabela dinâmica multidimensional.
As linhas e colunas representam grupos de dados distintos, e os valores das células representam agregações. Isso permite análises complexas com base em um conjunto de dados simples e plano. O <ApiLink type="PivotGrid" /> é uma tabela dinâmica rica em recursos, que oferece configuração fácil das diferentes dimensões e valores, além de operações adicionais sobre eles, como filtragem e ordenação.

Ele é definido por três dimensões principais: **linhas**, **colunas** e **valores**. As **linhas** e as **colunas** definem a estrutura agrupada exibida nas linhas e colunas da grade. Os **valores** definem os campos de agregação e a agregação que será usada para calcular e exibir os valores relacionados dos grupos.

Um filtro também pode ser definido por meio da propriedade de configuração **filters**. Ele pode ser usado para campos que você não quer adicionar como dimensão ou valor, mas cujos valores relacionados você gostaria de filtrar pela interface.

### Configuração das dimensões

Cada configuração básica de dimensão requer um <ApiLink type="PivotDimension" member="memberName" label="MemberName" /> que corresponda a um campo dos **dados** fornecidos.

Podem ser definidas várias dimensões irmãs, o que cria um grupo aninhado mais complexo na área de dimensão de linha ou coluna correspondente.

As dimensões podem ser reordenadas ou movidas de uma área para outra, por meio dos chips correspondentes, usando arrastar e soltar.

Uma dimensão também pode descrever uma hierarquia expansível pela propriedade <ApiLink type="PivotDimension" member="childLevel" label="ChildLevel" />, por exemplo:

### Configuração dos valores

A configuração de um valor requer um **membro** que corresponda a um campo dos **dados** fornecidos, ou pode definir uma função **agregadora** personalizada para cenários mais complexos. Por padrão, há 4 agregações predefinidas que podem ser usadas, dependendo do tipo de dado do campo:

- `PivotNumericAggregate` - para campos numéricos.
  Contém as seguintes funções de agregação: `SUM`, `AVG`, `MIN`, `MAX`, `COUNT`.
- `PivotDateAggregate` - para campos de data.
  Contém as seguintes funções de agregação: `LATEST`, `EARLIEST`, `COUNT`.
- `PivotTimeAggregate` - para campos de hora.
  Contém as seguintes funções de agregação: `LATEST`, `EARLIEST`, `COUNT`.
- `PivotAggregate` - para quaisquer outros tipos de dados. Esta é a agregação base.
  Contém as seguintes funções de agregação: `COUNT`.

A função de agregação atual pode ser alterada em tempo de execução pelo menu suspenso do chip de valor. Por padrão, ele exibe uma lista das agregações disponíveis com base no tipo de dado do campo. Uma lista personalizada de agregações também pode ser definida pela propriedade <ApiLink type="PivotValue" member="aggregateList" label="AggregateList" />, por exemplo:

### Propriedade Enable

<ApiLink type="PivotGrid" member="pivotConfiguration" label="PivotConfiguration" /> é a interface que descreve o estado atual do componente <ApiLink type="PivotGrid" />. Com ela, o desenvolvedor pode declarar campos dos dados como **linhas**, **colunas**, **filtros** ou **valores**. A configuração permite habilitar ou desabilitar cada um desses elementos separadamente. Somente os elementos habilitados são incluídos no estado atual do Pivot Grid. O componente <ApiLink type="PivotDataSelector" /> usa a mesma configuração e mostra uma lista de todos os elementos, habilitados e desabilitados. Para cada um deles, há uma caixa de seleção no estado apropriado. Os usuários finais podem ajustar facilmente o estado da tabela dinâmica alternando os diferentes elementos por essas caixas de seleção.
A propriedade `Enable` controla se um determinado <ApiLink type="PivotDimension" /> ou <ApiLink type="PivotValue" /> está ativo e participa da visualização dinâmica renderizada pelo Pivot Grid.

### Geração automática de configuração
A propriedade <ApiLink type="PivotGrid" member="autoGenerateConfig" label="AutoGenerateConfig" /> gera automaticamente dimensões e valores com base nos campos da fonte de dados:

- Campos numéricos:
  - Criado como <ApiLink type="PivotValue" /> usando o agregador `PivotNumericAggregate.sum`.
  - Adicionado à coleção de valores e ativado por padrão.

- Campos não numéricos:
  - Criado como <ApiLink type="PivotDimension" />.
  - Desativado por padrão.
  - Adicionado à coleção de colunas.

- Campos de data (somente o primeiro campo `date` é ativado; os demais campos `date` seguem a regra de campos não numéricos):
  - Criado como <ApiLink type="PivotDateDimension" />
  - Ativado por padrão
  - adicionado à coleção de linhas.

Este recurso permite que os desenvolvedores criem rapidamente uma visualização dinâmica sem especificar manualmente dimensões e valores. Com um seletor de tabela dinâmica ao lado do pivot grid, os usuários podem ativar e reordenar dimensões e valores conforme necessário.

### Chaves de cálculo de valores dinâmicos

O Pivot Grid oferece uma personalização dos campos de chaves de objeto que ele usa para fazer seus cálculos dinâmicos.
Uma visão mais detalhada de como elas são usadas pode ser vista abaixo, nos dados de exemplo, onde você já pode ver os valores agregados:

```json
[
  {
    ProductCategory: 'All', AllProducts: 'All Products', All: 1000, 'All-Bulgaria': 774, 'All-USA': 829, 'All-Uruguay': 524,
    AllProducts_records: [
      { ProductCategory: 'Clothing', 'All-Bulgaria': 774, 'All-USA': 296, 'All-Uruguay': 456 },
      { ProductCategory: 'Bikes', 'All-Uruguay': 68 },
      { ProductCategory: 'Accessories', 'All-USA': 293 },
      { ProductCategory: 'Components', 'All-USA': 240 }
    ]
  }
];
```

Todas essas chaves são armazenadas na propriedade **pivotKeys**, que faz parte do <ApiLink type="PivotGrid" member="pivotConfiguration" label="PivotConfiguration" /> e pode ser usada para alterar as chaves dinâmicas padrão.
- **children** - Campo que armazena os filhos para a construção da hierarquia. Ele representa um mapa dos valores agrupados e de todos os pivotGridRecords baseados nesse valor. Pode ser usado em cenários muito específicos, quando é preciso fazer algo durante a criação das hierarquias. Não é necessário alterá-lo para o uso comum.
- **records** - Campo que armazena a referência aos registros de dados originais. Pode ser visto no exemplo acima - **AllProducts_records**. Evite definir campos nos dados com o mesmo nome desta propriedade. Se os seus registros de dados tiverem uma propriedade **records**, você pode especificar um valor diferente e único para ela usando **pivotKeys**.
- **aggregations** - Campo que armazena os valores de agregação. Ele é aplicado durante a criação das hierarquias e também não deve ser alterado em cenários comuns.
- **level** - Campo que armazena o nível da dimensão com base na sua hierarquia. Evite definir campos nos dados com o mesmo nome desta propriedade. Se os seus registros de dados tiverem uma propriedade **level**, você pode especificar um valor diferente e único para ela usando **pivotKeys**.
- **columnDimensionSeparator** - Separador usado na geração dos valores únicos dos campos de coluna. É o traço (**-**) do valor de exemplo - **All-Bulgaria**.
- **rowDimensionSeparator** - Separador usado na geração dos valores únicos dos campos de linha. Ele é usado na criação dos campos **records** e **level**.

Os valores padrão são:

```razor
    level: 'level',
    rowDimensionSeparator: '_',
    columnDimensionSeparator: '-'
  };
}
```

</PlatformBlock>

<DocsAside type="info">
Se os valores dos seus campos de dados contiverem as chaves padrão, certifique-se de alterar os separadores correspondentes para outros símbolos que você não esteja usando. Caso contrário, isso pode causar comportamento inesperado no cálculo e na exibição dos valores agregados.
</DocsAside>
<PlatformBlock for="Blazor">

Ao sobrescrever o <ApiLink type="PivotConfiguration" member="pivotKeys" label="PivotKeys" /> no Blazor, atualmente você precisará definir todas as outras chaves, pois atribuir um novo objeto PivotKeys substitui completamente as padrão:

```razor
@code {
  var pivotConfiguration = new IgbPivotConfiguration();
  pivotConfiguration.PivotKeys = new IgbPivotKeys()
  {
    Aggregations = "aggregations",
    Records = "records",
    Children = "children",
    Level = "level",
    RowDimensionSeparator = "_",
    ColumnDimensionSeparator = "^"
  };
}
```

</PlatformBlock>

## Problemas conhecidos e limitações

|Limitação|Descrição|
|--- |--- |
| Definir colunas de forma declarativa não é suportado. | O Pivot grid gera as suas colunas com base na configuração de <ApiLink type="PivotGrid" member="columns" label="Columns" />; por isso, defini-las de forma declarativa, como no grid base, não é suportado. Essas colunas são desconsideradas. |
| Definir valores duplicados de <ApiLink type="PivotDimension" member="memberName" label="MemberName" /> ou <ApiLink type="PivotValue" member="member" label="Member" /> para dimensões/valores. | Essas propriedades devem ser únicas para cada dimensão/valor. A duplicação pode resultar em perda de dados no resultado final. |
| A seleção de linhas só é suportada no modo **Single**. | A seleção múltipla não é suportada no momento. |

<PlatformBlock for="Angular">
| Mesclagem dos membros da dimensão diferencia maiúsculas de minúsculas| O Pivot Grid cria grupos e mescla os valores iguais (diferenciando maiúsculas de minúsculas). Mas as dimensões fornecem <ApiLink type="PivotDimension" member="memberFunction" label="MemberFunction" /> e isso pode ser alterado ali; o resultado de <ApiLink type="PivotDimension" member="memberFunction" label="MemberFunction" /> é comparado e usado como valor de exibição.|
</PlatformBlock>
