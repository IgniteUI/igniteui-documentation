# Fixação de linhas {Platform}

 A {ProductName} Data Table / Data Grid permite a fixação de linhas usando chaves ou os itens da fonte de dados subjacente. Quando uma linha é fixada, ela é duplicada no topo do data grid {PlatformLower} e permanece fixa ali com fundo cinza claro, enquanto a linha real é renderizada com baixa opacidade.

## Exemplo de fixação de linhas do {Platform}


<Sample src="/grids/data-grid/row-pinning" height={600} alt="Exemplo de fixação de linhas do {Platform}" />



<div class="divider--half"></div>

Você pode fixar linhas no data grid {Platform} adicionando o item de dados subjacente da linha de destino à coleção pinnedItems da grade {Platform}.

## Trecho de código

<PlatformBlock for="React">

```ts
public onGridRef(grid: IgrDataGrid) {
    this.grid = grid;
    this.grid.pinnedItems.add(this.data[2]);
    this.grid.pinnedItems.add(this.data[4]);
}
```
