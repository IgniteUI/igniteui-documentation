# Carregar e salvar o layout da grade {Platform}

A {ProductName} Data Table / Data Grid oferece suporte a carregar e salvar o layout da grade. Isso é feito chamando os métodos `m:LoadLayout` e `m:SaveLayout` da grade. Esses recursos são úteis quando um usuário final pode mover, ordenar e agrupar colunas e quer preservar o estado da grade, podendo recuperar o layout e retomar o trabalho mais tarde.
