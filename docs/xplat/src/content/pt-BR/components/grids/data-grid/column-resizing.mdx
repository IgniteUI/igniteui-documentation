# Redimensionamento de colunas da grade {Platform}

O {ProductName} Data Grid oferece suporte à capacidade de redimensionar colunas, com flexibilidade sobre como você deseja exibir suas colunas em relação à largura de cada uma.

## Exemplo de redimensionamento de colunas da grade {Platform}


<Sample src="/grids/data-grid/column-resizing" height={600} alt="Exemplo de redimensionamento de colunas da grade {Platform}" />



<div class="divider--half"></div>

O redimensionamento de colunas no {ProductName} DataGrid vem ativado por padrão e pode ser controlado usando a propriedade `ColumnResizingMode` da grade. Essa propriedade tem três opções. Cada opção é explicada abaixo:

- `Deferred`: a opção padrão. Ao redimensionar, um separador aparecerá, mostrando o quanto a coluna ficará maior ou menor ao ser redimensionada.
- `Immediate`: ao redimensionar, não haverá separador. A largura da coluna acompanhará o ponteiro enquanto você arrasta a borda da coluna, redimensionando-a de acordo.
- `None`: as colunas não podem ser redimensionadas.

Quando o redimensionamento de colunas está definido como `Deferred`, o separador que aparece pode ter cor e largura alteradas usando as propriedades `ColumnResizingSeparatorBackground` e `ColumnResizingSeparatorWidth` da grade, respectivamente.

Você também pode animar as colunas enquanto são redimensionadas, mas somente quando o modo de redimensionamento estiver definido como `Deferred`. Isso é feito definindo a propriedade `ColumnResizingAnimationMode` como `Interpolate`.

Cada coluna da grade pode ser determinada individualmente quanto a poder ser redimensionada ou não. Se quiser habilitar ou desabilitar o redimensionamento em uma coluna específica, você pode definir a propriedade <b>IsResizingEnabled</b> dessa coluna.

Ao redimensionar uma coluna de largura star, ela será convertida em uma coluna de largura fixa.

## Trecho de código

O trecho de código a seguir demonstra como implementar o redimensionamento de colunas no data grid {Platform}, em que a coluna <b>Street</b>, neste caso, não poderá ser redimensionada. Nesse caso, o separador de redimensionamento terá 5 pixels de largura e as colunas redimensionáveis serão animadas ao serem redimensionadas:

```json-snippet source="/grids/data-grid/column-resizing"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "autoGenerateColumns": false,
            "columnResizingMode": "Deferred",
            "columnResizingAnimationMode": "Interpolate",
            "columnResizingSeparatorWidth": 5,
            "height": "100%",
            "width": "100%",
            "columns": [
                {
                    "type": "TextColumn",
                    "field": "FirstName"
                },
                {
                    "type": "TextColumn",
                    "field": "LastName"
                },
                {
                    "type": "TextColumn",
                    "field": "Street",
                    "isResizingEnabled": false
                },
                {
                    "type": "TextColumn",
                    "field": "City"
                }
            ],
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
