# Visão geral do seletor de colunas da grade {Platform}

O {ProductName} Data Grid oferece suporte à capacidade de mostrar e ocultar colunas pela interface, por meio do componente `DataGridToolbar` ou do componente `ColumnChooser`, que oferece flexibilidade para posicioná-lo em qualquer lugar da página. A propriedade `IsHidden` das colunas também pode ser usada para ocultar ou mostrar rapidamente uma única coluna por código, para geração manual de colunas, e o valor de `IsHidden` refletirá no componente `ColumnChooser`. Qualquer uma das abordagens pode ser usada de forma intercambiável para alterar o estado visível das colunas.

## Interface do seletor de colunas na barra de ferramentas

A interface do seletor de colunas está acessível dentro do componente `DataGridToolbar`, separada da grade. Para isso, basta definir a propriedade `ColumnChooser` da barra de ferramentas como true. A barra de ferramentas exibirá um `Button` que, ao ser clicado, mostrará a interface do seletor de colunas. Esse botão também exibe o total de colunas ocultas. Se a barra de ferramentas não for criada, habilitar a propriedade `ColumnChooser` não terá efeito e ocultará o botão.

O `DataGridToolbar` oferece propriedades adicionais, como adicionar um título à barra de ferramentas usando a propriedade `ToolbarTitle`, colocar texto no `Button` definindo a propriedade `ColumnChooserText` e adicionar um cabeçalho de título à interface do seletor de colunas definindo `ColumnChooserTitle`.

O seletor de colunas pode ser configurado com animações definindo as propriedades `ColumnHidingAnimationMode` e `ColumnShowingAnimationMode` da grade.
