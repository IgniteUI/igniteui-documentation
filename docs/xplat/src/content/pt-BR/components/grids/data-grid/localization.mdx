# Localização da grade {Platform}

A {ProductName} Data Table / Data Grid oferece suporte à localização das strings de recursos específicas do pop-up de opções de coluna e dos resumos. Observe que isso não se destina nem tem capacidade para traduzir os dados.

<PlatformBlock for="Blazor">
O Data Grid contém <ApiLink raw type="DataGrid" member="SetCustomizedStringAsync" /> para atribuir strings associadas às opções de coluna. A propriedade `ActualDataSource` da grade também tem esse método para atribuir as strings de recursos necessárias para os resumos.
</PlatformBlock>
