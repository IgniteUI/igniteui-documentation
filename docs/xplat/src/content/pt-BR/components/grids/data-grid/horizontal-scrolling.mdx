# Rolagem horizontal {Platform}

A {ProductName} Data Table / Data Grid oferece suporte à rolagem horizontal, que é habilitada quando a largura total das colunas é maior que a largura do data grid {Platform}.

## Definindo a largura padrão das colunas

```json-snippet id="scrolling" source="/grids/data-grid/column-scrolling"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "defaultColumnMinWidth": 120,
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
