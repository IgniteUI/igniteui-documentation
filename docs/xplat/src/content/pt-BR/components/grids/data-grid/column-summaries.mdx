# Resumos de colunas {Platform}

A {ProductName} Data Table / Data Grid oferece suporte a totais de colunas. Em alguns casos, seus usuários finais podem se sentir sobrecarregados com a quantidade de dados exibidos na grade e, muitas vezes, podem estar procurando um resumo dos dados. Eles também podem querer obter informações adicionais a partir dos dados de uma coluna específica. Os totais ajudam seus usuários finais a alcançar isso, e você pode habilitá-los definindo a propriedade `SummaryScope`.

## Propriedade de escopo dos resumos

O data grid {Platform} oferece 4 configurações de total que você pode definir usando a propriedade `SummaryScope`. Elas estão listadas e descritas abaixo:

- `Root`: exibe um total geral de todas as linhas da grade para a coluna à qual o total se aplica.
- `Groups`: é específico para linhas agrupadas e mostra o total geral de todas as linhas de um grupo específico.
- `Both`: usará simultaneamente as opções `Groups` e `Root`.
- `None`: desabilita os resumos da grade.

## Propriedade de modo de exibição dos resumos de grupo

O data grid {Platform} permite configurar os locais onde os resumos são exibidos. Você pode configurar isso usando a propriedade `GroupSummaryDisplayMode`. As diferentes opções dessa propriedade estão listadas e descritas abaixo:

- **List**: renderiza os resumos de grupo em uma lista simples no cabeçalho do grupo abrangente.
- **Cells**: renderiza o cabeçalho do grupo como células, e os valores dos resumos são renderizados dentro das células, alinhados com a coluna correspondente. Nesta opção, a grade exibe apenas um total por coluna.
- **RowTop**: renderiza os resumos de grupo como linhas de total no topo do grupo.
- **RowBottom**: renderiza os resumos de grupo como linhas de total na base do grupo.
- **None**: desabilita a renderização dos resumos de grupo.
