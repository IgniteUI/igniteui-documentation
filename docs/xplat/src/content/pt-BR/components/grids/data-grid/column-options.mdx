# Visão geral das opções de coluna da grade {Platform}

O {ProductName} Data Grid oferece suporte à capacidade de agrupar, ocultar, ordenar, mover, fixar, filtrar e ordenar colunas diretamente por uma interface exposta em cada cabeçalho de coluna.

Para habilitar a interface de opções de coluna, você pode definir a propriedade `IsColumnOptionsEnabled` da grade como true.

## Configurações das opções de coluna

A filtragem pode ser ativada ou desativada por coluna, definindo a propriedade `IsFilteringEnabled` da coluna. Definir true ou false mostrará ou ocultará a seção de filtragem na interface de opções da coluna.

A ordenação pode ser ativada ou desativada para toda a grade se a propriedade `HeaderClickAction` for aplicada. Definir isso como `None`, por exemplo, remove completamente a ordenação da grade, o que se reflete na interface de opções de cada coluna. Já definir `SortByOneColumnOnly`, por exemplo, continuará permitindo que apenas uma coluna seja ordenada por vez.

## Trecho de código

O código a seguir demonstra como habilitar programaticamente a interface de opções de coluna e ajustar a filtragem e a ordenação nessa interface, ajustando a grade e a coluna.

```json-snippet source="/grids/data-grid/column-options"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "ProductOrders",
            "headerClickAction": "SortByOneColumnOnly",
            "isColumnOptionsEnabled": true,
            "height": "100%",
            "width": "100%",
            "columns": [
                {
                    "type": "TextColumn",
                    "field": "ID",
                    "isFilteringEnabled": false
                }
            ],
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
