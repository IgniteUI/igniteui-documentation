# Edição na grade {Platform}

A {ProductName} Data Table / Data Grid oferece suporte à edição de células e linhas com atualização em lote. Observe que, por enquanto, isso se limita a colunas sem template.

## Visão geral

A edição no data grid {Platform} é configurada usando a opção `EditMode` da grade {Platform}. Essa propriedade aceita três opções diferentes, listadas abaixo:

- `None`: a edição não está habilitada.
- `Cell`: permite que as células entrem em modo de edição e confirma o valor ao sair do modo de edição.
- `CellBatch`: permite que as células entrem em modo de edição, mas as alterações ficam em cache até serem confirmadas.
- `Row`: permite que as linhas entrem em modo de edição e confirma o valor ao sair.

Quando definido como `CellBatch`, para confirmar as alterações é preciso executar o método `m:commitEdits` da grade. A grade deixará as células em itálico até que sejam confirmadas, dando controle sobre quando as alterações são enviadas de volta à fonte de dados.

Além disso, o tratamento de erros pode ser feito conectando-se ao evento `CellValueChanging` e inspecionando os novos valores antes de serem confirmados. A grade expõe um método `m:setEditError` que pode exibir uma mensagem de erro. Isso mantém a célula em modo de edição até que um valor válido seja informado. Caso contrário, o método `m:rejectEdit` da grade pode ser executado para reverter o valor inválido. Se nenhum valor inválido for encontrado, você também pode confirmar as alterações chamando o método `m:acceptEdit` da grade.

As confirmações podem ser aprovadas ou recusadas no nível da grade, conectando-se a `DataCommitting` por meio dos métodos `m:acceptCommit` ou `m:rejectCommit`, passando o argumento do evento `commitID` como parâmetro. Esse evento também expõe uma coleção `changes` que armazena todas as modificações antes de serem confirmadas. Por exemplo, você pode verificar se uma confirmação veio de uma operação de adição, atualização ou exclusão pela propriedade `TransactionType` exposta na coleção `changes` e executar um `m:acceptCommit` ou um `m:rejectCommit` quando necessário.

## Edição estilo Excel

`EditOnKeyPress` permite que você comece a editar imediatamente ao digitar, de forma semelhante ao comportamento do Excel. Além disso, você pode definir a propriedade `EditModeClickAction` como `SingleClick` para permitir que os usuários editem células rapidamente enquanto navegam para outras células. Por padrão, é necessário clicar duas vezes para entrar no modo de edição.

## Trecho de código

A seguir, mostra-se como configurar a edição no data grid e confirmar os dados.

```json-snippet source="/grids/data-grid/cell-editing"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "activationMode": "Cell",
            "editMode": "CellBatch",
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```

## Validação de erros e integridade das confirmações

A seguir, mostra-se como incorporar tratamento de erros verificando se as células estão vazias ao sair do modo de edição e aceitando apenas confirmações de células atualizadas.

```json-snippet source="/grids/data-grid/cell-editing"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "activationMode": "Cell",
            "editMode": "CellBatch",
            "cellValueChangingRef": "DataGridValidateCellEdit",
            "dataCommittingRef": "DataGridCommitUpdatesOnly",
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
