# Visão geral da movimentação de colunas da grade {Platform}

O {ProductName} Data Grid oferece suporte à capacidade de mover colunas, dando flexibilidade sobre como você deseja exibir suas colunas em relação à ordem das colunas mostradas.

## Exemplo de movimentação de colunas da grade {Platform}


<Sample src="/grids/data-grid/column-moving" height={600} alt="Exemplo de movimentação de colunas da grade {Platform}" />



<div class="divider--half"></div>

A movimentação de colunas no {ProductName} Data Grid vem ativada por padrão e pode ser controlada definindo a propriedade `ColumnMovingMode` da grade. Essa propriedade tem duas opções, `Deferred` ou `None`. `Deferred` permitirá a movimentação de colunas, enquanto `None` desabilitará a movimentação de colunas em toda a grade.

Quando a movimentação de colunas está definida como `Deferred`, um separador aparece durante a movimentação de uma coluna. Ao soltar o ponteiro do mouse, a coluna movida ocupará o lugar da coluna posicionada à direita do separador. Esse separador também pode ter largura e cor personalizadas usando as propriedades `ColumnMovingSeparatorWidth` e `ColumnMovingSeparatorBackground`, respectivamente.

Você também pode animar as movimentações de colunas, se quiser. Isso pode ser feito definindo a propriedade `ColumnMovingAnimationMode` da grade. As animações não vêm ativadas por padrão.

## Trecho de código

A seguir, mostra-se como implementar a movimentação de colunas no {ProductName} Data Grid, com movimentação diferida, animações habilitadas e um separador de 5px de largura:

```json-snippet source="/grids/data-grid/column-moving"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "columnMovingMode": "Deferred",
            "columnMovingAnimationMode": "SlideOver",
            "columnMovingSeparatorWidth": 5,
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
