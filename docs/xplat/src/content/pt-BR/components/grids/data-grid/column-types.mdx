# Tipos de coluna {Platform}

A {ProductName} Data Table / Data Grid oferece suporte a 5 tipos de coluna, além de um tipo de coluna de Template, dando total flexibilidade sobre a forma como seus dados são exibidos no data grid {Platform}. Os tipos de coluna suportados são: coluna de texto, coluna numérica, coluna de DateTime, coluna de imagem, ComboBox e template.

Cada coluna se vincula aos dados definindo a propriedade `Field` como o nome da propriedade correspondente nos itens da sua fonte de dados subjacente, vinculada ao data grid {Platform}.

## Coluna de texto

O data grid {Platform} é usado para exibir texto formatado nas células associadas. Este é o tipo de coluna padrão usado para exibir dados do tipo string.

## Coluna numérica

A `NumericColumn` é usada para exibir um valor numérico formatado nas células associadas e permite controlar a posição das casas decimais dentro das células e a exibição de dígitos fracionários.

## Coluna DateTime

A `DateTimeColumn` é usada para exibir objetos Date nas células associadas e permite controlar a formatação dos objetos Date como você preferir.

## Coluna de imagem

A `ImageColumn` é usada para exibir uma imagem dentro de uma célula e oferece opções de personalização do estiramento da imagem nas células por meio da opção `ImageStretchOption`.

Você também pode escolher o tipo de recurso da sua imagem definindo a opção `ImageResourceType`.

## Coluna ComboBox

A `ComboBoxColumn` é usada para exibir uma lista suspensa da qual os usuários finais podem selecionar um único item.

O data binding pode ser feito usando um array de objetos complexos por meio da propriedade `DataSource` da coluna.

A propriedade `TextField` determina qual valor é mostrado quando os usuários fazem uma seleção.

A propriedade `ValueField` determina o valor vinculado do item de dados subjacente selecionado. Isso é necessário se a sua lista de objetos tiver várias propriedades.

## Coluna de template

A `TemplateColumn` é usada em conjunto com um template de célula. Ela permite aplicar um template personalizado à célula da coluna. Isso é feito tratando o evento `CellUpdating` da coluna de template.

Os argumentos do evento `CellUpdating` expõem o `TemplateColumn` que dispara o evento, além de um parâmetro `TemplateCellUpdatingEventArgs`. Esse parâmetro de argumentos do evento expõe uma propriedade `Content`: o contêiner nativo que será colocado dentro da célula associada da coluna, cujo tipo depende da plataforma. Você pode então atualizar ou adicionar conteúdo a esse contêiner.

O `TemplateCellUpdatingEventArgs` também expõe uma propriedade `CellInfo` que você pode usar para obter um objeto `TemplateCellInfo`. Esse objeto expõe informações sobre a célula e a linha, como o índice, o item de dados subjacente e a aparência da célula.
