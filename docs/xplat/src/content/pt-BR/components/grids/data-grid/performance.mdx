# {Platform} Alto desempenho com dados ao vivo

O {ProductName} Data Table / Data Grid é otimizado para alto desempenho em cenários com dados ao vivo. Com carregamento rápido, rolagem suave, sem atraso e sem cintilação de tela, você pode rolar sem interrupção por um número ilimitado de linhas e colunas na sua aplicação com data grid {Platform}, com virtualização completa das colunas e linhas da grade.

## Exemplo de alto desempenho com dados ao vivo do {Platform}

Este exemplo demonstra esse desempenho vinculando milhares de registros financeiros ao data grid {Platform}, agrupando-os por 1 coluna (por exemplo, Territory) e atualizando ao vivo várias colunas a cada poucos milissegundos. Você pode alterar várias opções em tempo real, e o desempenho do Data Grid continua sem atraso, sem cintilação de tela ou demora visual
