# Visão geral da ordenação da grade {Platform}

A {ProductName} Data Table / Data Grid oferece suporte à ordenação de colunas ascendente e descendente, com configurações de coluna única, múltiplas colunas e ordenação de colunas em três estados.

## Trecho de código

Você pode ordenar por uma ou várias colunas, em ordem ascendente ou descendente, no data grid {Platform}, usando a propriedade `HeaderClickAction`. Se TriState estiver habilitado, você pode remover a ordenação aplicada a uma coluna.

- `SortByMultipleColumns`
- `SortByMultipleColumnsTriState`
- `SortByOneColumnOnly`
- `SortByOneColumnOnlyTriState`

```json-snippet source="/grids/data-grid/column-sorting"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "RealEstateData",
            "headerClickAction": "SortByMultipleColumns",
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```

## Ordenação pela API

<PlatformBlock for="React">

```ts
import { IgrColumnSortDescription } from 'igniteui-react-data-grids';
import { ListSortDirection } from 'igniteui-react-core';
```


```ts
public onGridRef(grid: IgrDataGrid) {
    this.grid = grid;
}
// ...
let colSortDesc = new IgrColumnSortDescription();
colSortDesc.field = "UnitsInStock";
colSortDesc.sortDirection = ListSortDirection.Descending;
this.grid.sortDescriptions.add(colSortDesc);
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
import { IgcColumnSortDescription } from 'igniteui-webcomponents-data-grids';

let grid1 = (document.getElementById("grid") as IgcDataGridComponent);
grid1.dataSource = data;
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
@code {
    // Using the ref property above:
    private IgbDataGrid grid;
    private IgbDataGrid DataGridRef
    {
        get { return grid; }
        set
        {
            grid = value;
            OnGridRefChanged();
            StateHasChanged();
        }
    }

    private void OnGridRefChanged()
    {
        if (this.DataGridRef != null)
        {
            this.DataGridRef.SortDescriptions.Add(new ColumnSortDescription()
            {
                Field = "Property",
                SortDirection = ListSortDirection.Descending
            });
        }
    }
}
```

</PlatformBlock>
