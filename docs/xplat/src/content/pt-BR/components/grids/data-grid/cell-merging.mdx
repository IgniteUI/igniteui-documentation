# Mesclagem de células da grade {Platform}

A {ProductName} Data Table / Data Grid oferece suporte à mesclagem de células. Você pode optar por participar e detectar quando registros irmãos adjacentes de uma coluna específica contêm o mesmo valor. Enquanto as células não estiverem ativas, selecionadas ou em modo de edição, o valor é exibido ao longo das células.

## Visão geral

A mesclagem de células no data grid {Platform} pode ser configurada usando a opção `MergedCellMode` de toda a grade {Platform} ou de colunas individuais. Essa propriedade pode ser definida com uma das opções a seguir, listadas abaixo:

- `Never`: a grade ou a coluna nunca mesclará células. Este é o comportamento padrão.
- `Always`: a grade ou a coluna sempre tentará mesclar células.
- `OnlyWhenSorted`: a grade ou a coluna só tentará mesclar células quando uma coluna estiver ordenada.

Observe que, independentemente do valor dessa propriedade, as células só podem ser mescladas entre registros irmãos.

A mesclagem de células pode ser avaliada com base em os dados estarem formatados ou não, usando a propriedade `MergedCellEvaluationCriteria`. Isso se aplica a toda a grade ou a colunas individuais e pode ser definido com uma das opções a seguir, listadas abaixo:

- `RawValue`: mescla células de linhas adjacentes quando os valores brutos das células são iguais. Este é o valor padrão.
- `FormattedText`: mescla células de linhas adjacentes quando o valor formatado das células é igual.
