# Destaque na grade {Platform}

A {ProductName} Data Table / Data Grid oferece suporte à configuração da aparência do destaque de linhas.

## Visão geral

O destaque de registros nos dados do {Platform} pode ser ativado ou desativado definindo a propriedade booleana `IsRowHoverEnabled` da grade {Platform}. Observe que isso já vem habilitado por padrão.

Além disso, a cor pode ser configurada definindo a propriedade string `RowHoverBackground` com um valor hexadecimal.

## Trecho de código

O exemplo a seguir demonstra como habilitar o destaque de linhas no data grid {Platform} e aplica a cor azul:

```json-snippet source="/grids/data-grid/row-highlighting"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "isRowHoverEnabled": true,
            "rowHoverBackground": "#bfbfff",
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```

## Referências da API
