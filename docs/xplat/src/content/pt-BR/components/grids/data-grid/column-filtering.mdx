# Visão geral da filtragem da grade {Platform}

A {ProductName} Data Table / Data Grid inclui filtragem de colunas, com uma linha de filtro e uma API que permite executar condições de ordenação expressivas com base no tipo de dado da coluna filtrada.

Como visto acima, definir a propriedade `FilterUIType` como FilterRow habilitará, na interface, a linha de filtro de registros, na qual o usuário pode especificar critérios de filtro para filtrar os registros. Os registros que não correspondem aos critérios de filtro especificados ficam ocultos.

A filtragem também fica exposta nas opções de coluna da interface: basta passar o mouse sobre um campo e clicar nas reticências verticais. Isso é obtido ao definir `FilterUIType` como ColumnOptions. Consulte o exemplo abaixo.

## Operadores de filtro

As colunas podem receber um `FilterOperand` personalizado que aparecerá no dropdown de operandos da linha de filtro. O requisito principal é garantir que o operando receba um `DisplayName` e usar o evento `FilterRequested` do operando para aplicar um `FilterFactory`, que é responsável por atribuir o operador e o valor com os quais você deseja filtrar a coluna, por exemplo, StartsWith com o valor "A".

Além disso, a propriedade `FilterLogicalOperator` da grade é responsável por indicar como os filtros entre campos são combinados:

- Operador lógico `And`. Para que haja correspondência, todas as condições precisam ser atendidas.
- Operador lógico `Or`. Para que haja correspondência, pelo menos uma das condições precisa ser atendida.
