# Agrupamento de linhas {Platform}

<PlatformBlock for="Angular,React,WebComponents,Blazor">

A {ProductName} Data Table / Data Grid permite agrupar linhas em um grupo de linhas com um ‘cabeçalho fixo’. Isso é semelhante ao recurso Group By do Microsoft Outlook, uma forma fácil de agrupar visualmente os dados com base nos seus próprios critérios.

## Área Group-By

Defina a propriedade `IsGroupByAreaVisible` do DataGrid como True, conforme mostrado no exemplo acima, para a interface do usuário. A área de group-by oferece aos usuários mais opções para agrupar e ordenar colunas sem interagir diretamente com o DataGrid. Os grupos podem ser posicionados e reordenados de acordo com as necessidades dos usuários. Essa área também é preenchida quando as colunas são adicionadas programaticamente como `GroupDescriptions` no DataGrid.

## Grupos hierárquicos

A propriedade `GroupHeaderDisplayMode` permite que os grupos sejam hierárquicos. Por padrão, cada descrição de grupo adicionada é agregada em conjunto. Definir `GroupHeaderDisplayMode` como `Split` criará um cabeçalho de seção para cada grupo definido na propriedade `GroupDescriptions` do `DataGrid`.


```json-snippet id="groupHeaderDisplayMode" source="/grids/data-grid/row-group-descriptions" channel="code"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "groupHeaderDisplayMode": "Split",
            "height": "100%",
            "width": "100%"
        }
    }
}
```

```json-snippet ref="groupHeaderDisplayMode" source="/grids/data-grid/row-group-descriptions"
```

## Grupos recolhíveis

Além disso, o `DataGrid` pode exibir um botão de alternância em cada seção de grupo, para que o usuário final expanda ou recolha os dados agrupados por meio da propriedade `IsGroupCollapsable`.

```json-snippet id="isGroupCollapsable" source="/grids/data-grid/row-grouping" channel="code"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "isGroupCollapsable": true,
            "height": "100%",
            "width": "100%"
        }
    }
}
```


## Resumo

Para sua conveniência, todos os trechos de código acima estão combinados em um único bloco de código abaixo, que você pode copiar facilmente para o seu projeto.


```json-snippet id="groupingSummary" source="/grids/data-grid/row-group-descriptions" channel="code"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "isGroupCollapsable": true,
            "groupHeaderDisplayMode": "Split",
            "height": "100%",
            "width": "100%",
            "groupDescriptions": [
                {
                    "type": "ColumnGroupDescription",
                    "field": "Country",
                    "displayName": "Location",
                    "sortDirection": "Descending"
                },
                {
                    "type": "ColumnGroupDescription",
                    "field": "City",
                    "displayName": "City"
                },
                {
                    "type": "ColumnGroupDescription",
                    "field": "Income",
                    "displayName": "Income"
                }
            ]
        }
    }
}
```
