# Grade Master-Detail {Platform}

O componente <ApiLink type="Grid" /> oferece suporte à especificação de um template de detalhes que exibe informações adicionais de uma determinada linha, expandindo/recolhendo o seu conteúdo. Quando especificado, cada registro atua como mestre, que, ao ser expandido, mostra um template de detalhes personalizável com os dados contextuais do registro atual.

Este modo é útil quando você precisa exibir dados no estilo master-detail em uma estrutura hierárquica.

## Configuração

Para configurar o <ApiLink type="Grid" /> para exibir no modo master-detail, você precisa especificar um template para a grade:


<PlatformBlock for="Angular">
```html
<{ComponentSelector}>
         <ng-template GridDetail let-dataItem>
              <!-- Custom detail template content here -->
        </ng-template>
</{ComponentSelector}>
```
</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
constructor() {
  var grid = this.grid = document.getElementById('grid') as IgcGridComponent;
  this._bind = () => {
    grid.data = this.customersData;
    grid.detailTemplate = this.masterDetailTemplate;
  }
  this._bind();
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
    <IgbGrid DetailTemplateScript="DetailTemplate"  AutoGenerate=true  Data=northwindEmployees></IgbGrid>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrGrid detailTemplate={masterDetailTemplate} autoGenerate={false} data={nwindData}></IgrGrid>
```

</PlatformBlock>

O contexto do template são os dados do registro mestre, para que os valores do registro mestre possam ser exibidos no template de detalhes. Por exemplo:

<PlatformBlock for="Angular">
```html
<{ComponentSelector}>
         <ng-template GridDetail let-dataItem>
            @if (dataItem.Category) {
                <div>
                    <header>{{dataItem.Category.CategoryName}}</header>
                    <span>{{dataItem.Category.Description}}</span>
                </div>
            }
        </ng-template>
</{ComponentSelector}>
```
</PlatformBlock>

## Navegação pelo teclado

- Quando o foco está em uma linha de detalhes:

  - <kbd>🡑</kbd> - navega uma linha para cima, focando uma célula da linha anterior.
  - <kbd>🡓</kbd> - navega uma linha para baixo, focando uma célula da próxima linha.
  - <kbd>TAB</kbd> - permite que o foco se mova para o próximo elemento focável dentro do template, se houver elementos focáveis; caso contrário, move para a próxima linha da grade.
  - <kbd>SHIFT</kbd> + <kbd>TAB</kbd> - move o foco para a linha anterior.

- Quando o foco está em uma linha de dados com expansor:
  - <kbd>ALT</kbd> + <kbd>🡒</kbd> ou <kbd>ALT</kbd> + <kbd>🡓</kbd> - expande a linha.
  - <kbd>ALT</kbd> + <kbd>🡐</kbd> ou <kbd>ALT</kbd> + <kbd>🡑</kbd> - recolhe a linha.

## Problemas conhecidos e limitações


|Limitações conhecidas| Descrição|
| --- | --- |
| A navegação com Tab dentro do template de detalhes personalizado pode não atualizar a posição de rolagem da grade mestre caso o próximo elemento focado esteja fora da janela de visualização.| A navegação com Tab dentro do template de detalhes personalizado fica a cargo do navegador. |
| O template de detalhes não será exportado para o Excel.| Como o template de detalhes pode conter qualquer tipo de conteúdo, não é possível exportá-lo para o Excel por padrão.|
| O recurso de pesquisa não destacará elementos do template de detalhes. | |
