## O que é uma Grid {Platform}?

O {Platform} data grid é um componente usado para exibir dados tabulares em uma série de linhas e colunas. Data grids, também conhecidos como tabelas, são bem conhecidos no mundo desktop com softwares populares como o Microsoft Excel. Embora as grades estejam disponíveis em plataformas desktop há muito tempo, elas se tornaram recentemente parte das interfaces de aplicações web, como a interface do {Platform}. Grades modernas podem ser complexas e incluir uma série de funcionalidades, como data binding, edição, filtragem estilo Excel, ordenação personalizada, agrupamento, reordenação de linhas, congelamento de linhas e colunas, agregação de linhas e exportação para os formatos Excel, CSV e PDF.


## Por que usar uma Grid {Platform}?

Data grids {Platform} são essenciais em casos de uso em que grandes volumes de dados precisam ser armazenados e ordenados rapidamente. Isso pode incluir setores como o financeiro ou o de seguros, que usam com frequência dados de alto volume e alta velocidade. Muitas vezes, o sucesso dessas empresas depende da funcionalidade e do desempenho desses data grids. Quando decisões sobre ações precisam ser tomadas em microssegundos, por exemplo, é imperativo que o data grid tenha desempenho sem atraso nem cintilação.
