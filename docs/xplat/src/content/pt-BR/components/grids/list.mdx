# Visão geral do {Platform} List

O elemento {ProductName} List é extremamente útil para apresentar um grupo de itens. Você pode criar uma lista simples de itens de texto ou uma mais complexa, contendo um array de diferentes elementos de layout. O componente <ApiLink pkg="core" type="List" /> exibe linhas de itens e também oferece suporte a um ou mais cabeçalhos. Cada item da lista é totalmente personalizável por template e aceita qualquer HTML válido ou outros componentes.

## Exemplo de {Platform} List

O exemplo a seguir representa uma lista preenchida com contatos que têm as propriedades nome e número de telefone. O componente <ApiLink pkg="core" type="List" /> demonstrado abaixo usa os elementos <ApiLink pkg="core" type="Avatar" /> e <ApiLink pkg="core" type="Button" /> para enriquecer a experiência do usuário e expor os recursos de definir uma imagem de avatar e botões para as ações de texto e de ligação.

O slot `start` serve para adicionar algum tipo de mídia antes de todo o restante do conteúdo dos itens da lista. O elemento de destino, no nosso caso o componente <ApiLink pkg="core" type="Avatar" />, também receberá uma posição e um espaçamento padrão.

O slot `end` serve para itens da lista que têm algum tipo de ação ou metadado, representado, por exemplo, por um switch, um botão, uma caixa de seleção etc. Usaremos componentes <ApiLink pkg="core" type="Button" />.

Vamos também permitir que o usuário altere o tamanho da lista usando a variável CSS `--ig-size`. Adicionaremos alguns botões de rádio para exibir todos os valores de tamanho. Assim, sempre que um for selecionado, alteraremos o tamanho da lista.

### Elementos recomendados para os slots

Ao colocar conteúdo nos slots `title` e `subtitle`, recomendamos usar elementos `<span>` em vez de elementos de título (`<h1>`–`<h6>`). Os elementos de título têm estilos próprios (como tamanho de fonte, altura de linha e margens) que podem interferir na tipografia e no layout pretendidos para o componente. Usar um `<span>` fornece um contêiner neutro que herda os estilos do componente de forma limpa.

Para obter os melhores resultados, recomendamos usar o componente [`<igc-avatar>`](../layouts/avatar.mdx) para o slot `start`, que se destina a conteúdo de mídia. Para o slot `end`, que se destina a ações, recomendamos componentes como [`<igc-button>`](../inputs/button.mdx), [`<igc-switch>`](../inputs/switch.mdx), [`<igc-checkbox>`](../inputs/checkbox.mdx) etc., dependendo do tipo de conteúdo que você quer exibir. No entanto, para esses dois slots, você também pode usar elementos HTML simples, como `<img>` para o slot `start` e `<button>` ou outro elemento interativo para o slot `end`, desde que sejam adequados ao conteúdo que você quer exibir.

## Estilização

O <ApiLink pkg="core" type="List" /> expõe várias partes CSS, dando controle total sobre o seu estilo:

|Nome|Descrição|
|--|--|
| `start` | O contêiner inicial. |
| `end` | O contêiner final. |
| `content` | O contêiner do cabeçalho e do conteúdo personalizado. |
| `header` | O contêiner do título e do subtítulo. |
| `title` | O contêiner do título. |
| `subtitle` | O contêiner do subtítulo. |

```css
igc-list-header {
  font-size: 20px;
  font-weight: 700;
  color: var(--ig-primary-700);
}

igc-list-item::part(title) {
  font-size: 18px;
  color: var(--ig-primary-600);
}

igc-list-item::part(subtitle) {
  color: var(--ig-primary-300);
}
```
