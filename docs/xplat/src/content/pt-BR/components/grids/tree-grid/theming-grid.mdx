# Tema da grade {Platform}
Com o CSS de temas do {Platform}, a grade {ProductName} pode ser facilmente personalizada para combinar com a identidade da sua marca.
Além dos temas e paletas predefinidos, você pode personalizar ainda mais a aparência do seu data grid usando um conjunto alternativo de propriedades customizadas CSS.

<Sample src="/grids/grid/overview-dark" height={500} alt="Exemplo de tema escuro da grade {Platform}" />



<PlatformBlock for="Blazor">
```razor
<head>
    <link href="_content/IgniteUI.Blazor/themes/grid/dark/bootstrap.css" rel="stylesheet" />
</head>
```
</PlatformBlock>
