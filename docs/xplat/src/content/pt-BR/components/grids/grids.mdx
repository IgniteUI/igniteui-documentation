# O Data Grid {Platform} mais rápido


<PlatformBlock for="React">



Um data grid ou data table {Platform} é um componente usado para exibir dados tabulares em uma série de linhas e colunas. Data grids, também conhecidos como tabelas, são bem conhecidos no mundo desktop com softwares populares como o Microsoft Excel. Embora as grades estejam disponíveis em plataformas desktop há muito tempo, elas só recentemente passaram a fazer parte das interfaces de aplicações web, como a interface do {Platform}. Grades e tabelas modernas podem ser complexas e incluir uma série de recursos e funcionalidades, como data binding, edição, filtragem estilo Excel, ordenação personalizada, agrupamento, reordenação de linhas, congelamento de linhas e colunas, agregação de linhas e exportação para os formatos Excel, CSV e PDF.

</PlatformBlock>

<PlatformBlock for="WebComponents">

Um data grid {Platform}, também conhecido como data table {Platform}, é um componente de visualização de dados que permite vincular e exibir seus dados como uma série de linhas e colunas. Eles são um tanto novos no mundo das interfaces de aplicações web, embora estejam disponíveis em plataformas desktop há bastante tempo, em muitas formas diferentes, como o Microsoft Excel. Essas grades e tabelas geralmente podem ser bastante complexas, incluindo funcionalidades como seleção de células e linhas, filtragem, edição, ocultação de linhas e colunas, resumos de colunas, pesquisa e a capacidade de exibir seus dados em colunas específicas por tipo.

</PlatformBlock>

<PlatformBlock for="Blazor">

Uma data table {Platform}, mais comumente conhecida como data grid {Platform}, é um componente que permite visualizar os seus dados vinculados como uma série de linhas e colunas. Esses data grids são acessíveis há bastante tempo em plataformas relacionadas ao desktop, como WPF e Windows Forms, mas só recentemente passaram a estar disponíveis para o desenvolvimento de aplicações web. As aplicações web modernas usam tabelas e data grids ricos em recursos, com capacidade de data binding, seleção de células e linhas, edição de células e linhas com validação de erros, resumos de colunas, agrupamento interativo no estilo Outlook, filtragem no estilo Microsoft Excel e linhas e colunas virtualizadas, para que você possa carregar potencialmente milhões de registros.

</PlatformBlock>

## Por que usar um Data Grid {Platform}?

Data grids {Platform} são essenciais em casos de uso em que grandes volumes de dados precisam ser armazenados e ordenados rapidamente. Isso pode incluir setores como serviços financeiros, bancos e seguros, que costumam usar dados de alto volume e alta velocidade. O sucesso dessas empresas depende dos recursos, da funcionalidade e do desempenho desses data grids. Quando decisões sobre ações precisam ser tomadas em microssegundos, por exemplo, é imperativo que o data grid tenha desempenho sem atraso nem cintilação.
