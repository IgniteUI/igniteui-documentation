# Fixação de linhas do {Platform} {ComponentTitle}

O recurso de Fixação de linhas do {ProductName} em {Platform} {ComponentTitle} permite fixar uma ou várias linhas no topo ou na base da grade. A fixação de linhas permite que os usuários fixem linhas em uma ordem específica, duplicando-as em uma área especial que fica sempre visível, mesmo quando eles rolam a <ApiLink type="{ComponentName}" /> verticalmente. O {Platform} {ComponentTitle} tem uma interface de fixação de linhas integrada, que é habilitada inicializando um componente <ApiLink type="ActionStrip" /> no contexto de {ComponentTitle}. Além disso, você pode definir uma interface personalizada e alterar o estado de fixação das linhas pela API de Fixação de linhas.

A interface integrada de fixação de linhas é habilitada adicionando um componente <ApiLink type="ActionStrip" /> com o componente <ApiLink type="GridPinningActions" />. Uma ação adicional, que permite rolar a cópia da linha fixada para a área visível, também é exibida para cada linha fixada.

## API de fixação de linhas

A fixação de linhas é controlada pela entrada <ApiLink type="RowDirective" member="pinned" /> do `Row`. Por padrão, as linhas fixadas são renderizadas na parte superior do <ApiLink type="{ComponentName}" /> e permanecem fixas durante a rolagem vertical das linhas não fixadas no corpo do <ApiLink type="{ComponentName}" />.

<PlatformBlock for="Angular, WebComponents">
```typescript
this.grid.getRowByIndex(0).pinned = true;
```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
gridRef.current.getRowByIndex(0).pinned = true;
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```csharp
this.Grid.PinRowAsync("ALFKI", 0);
```
</PlatformBlock>

Você também pode usar os métodos <ApiLink type="{ComponentName}" member="pinRow" label="PinRow" /> ou <ApiLink type="{ComponentName}" member="unpinRow" label="UnpinRow" /> do <ApiLink type="{ComponentName}" /> para fixar ou desafixar registros pelo ID:

<PlatformBlock for="Angular, WebComponents">
```typescript
this.grid.pinRow('ALFKI');
this.grid.unpinRow('ALFKI');
```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
gridRef.current.pinRow('ALFKI');
gridRef.current.unpinRow('ALFKI');
```
</PlatformBlock>
<PlatformBlock for="Blazor">
```csharp
this.Grid.PinRowAsync("ALFKI", 0);
this.Grid.UnpinRowAsync("ALFKI");
```
</PlatformBlock>

Observe que o ID da linha é o valor da chave primária, definido pelo <ApiLink type="{ComponentName}" member="primaryKey" /> do grid, ou a própria instância do registro. Ambos os métodos retornam um valor booleano indicando se a operação correspondente foi bem-sucedida. Normalmente, a falha ocorre porque a linha já está no estado desejado.

Uma linha é fixada abaixo da última linha fixada. Para alterar a ordem das linhas fixadas, você pode se inscrever no evento <ApiLink type="{ComponentName}" member="rowPinning" /> e alterar a propriedade <ApiLink type="PinRowEventArgs" /> dos argumentos do evento para o índice de posição desejado.

## Posição da fixação

Você pode alterar a posição da fixação de linhas pela opção de configuração <ApiLink type="{ComponentName}" member="pinning" />. Ela permite definir a posição da área de fixação como Top ou Bottom.
Quando definida como Bottom, as linhas fixadas são renderizadas na parte inferior do grid, depois das linhas não fixadas. As linhas não fixadas podem ser roladas verticalmente, enquanto as linhas fixadas permanecem fixas na parte inferior.

### Via arrasto de linha

Digamos que você queira poder arrastar e soltar diretamente uma linha entre as linhas fixadas e não fixadas, para alterar o seu estado de fixação.
Isso pode ser obtido habilitando o recurso de arrastar linhas e fixando/desafixando as linhas pela API ao soltar.

Primeiro, o grid deve ser marcado como área de soltar usando a diretiva `igxDrop`, e a funcionalidade de arrastar linhas deve ser habilitada pela opção `rowDraggable`.

```html
<igx-grid [data]="data" [autoGenerate]="true" [rowDraggable]="true"
    [primaryKey]="'ID'" igxDrop (dropped)="onDropAllowed($event)">
</igx-grid>
```

Depois, o evento `dropped` pode ser usado para tratar a lógica de reordenação e de fixar/desafixar.

```typescript
public onDropAllowed(args) {
    const event = args.originalEvent;
    let currRowPinnedIndex;
    const currRowIndex = this.getCurrentRowIndex(this.grid.rowList.toArray(),
        { x: event.clientX, y: event.clientY });
    if (currRowIndex === -1) { return; }

    const currRowID = this.getCurrentRowID(this.grid.rowList.toArray(),
        { x: event.clientX, y: event.clientY });

    const currentRow = this.grid.rowList.toArray().find((r) => r.rowID === currRowID);
    if (currentRow.pinned) {
        currRowPinnedIndex = this.grid.pinnedRows.indexOf(this.grid.pinnedRows.find((r) => r.rowID === currRowID));
    }
    // remove the row that was dragged and place it onto its new location
    this.grid.deleteRow(args.dragData.key);
    this.data.splice(currRowIndex, 0, args.dragData.data);
    if (currentRow.pinned && !args.dragData.pinned) {
        this.grid.pinRow(args.dragData.key, currRowPinnedIndex);
    } else if (!currentRow.pinned && args.dragData.pinned) {
        this.grid.unpinRow(args.dragData.key);
    } else if (currentRow.pinned && args.dragData.pinned) {
        this.grid.unpinRow(args.dragData.key);
        this.grid.pinRow(args.dragData.key, currRowPinnedIndex);
    }
}
```

Isso permitirá reordenar as linhas e movê-las entre as coleções de linhas fixadas e não fixadas.

## Limitações da fixação de linhas

- Somente registros que existem na fonte de dados podem ser fixados.
- O estado de fixação de linhas não é exportado para o Excel. O grid é exportado como se nenhuma fixação de linhas tivesse sido aplicada.
- As cópias das linhas fixadas na área rolável do grid são parte integrante de como outros recursos do grid alcançam a sua funcionalidade na presença de linhas fixadas; por isso, a sua criação não pode ser desabilitada, nem elas podem ser removidas.
- Como a Seleção de linhas funciona inteiramente com IDs de linha, selecionar linhas fixadas também seleciona suas cópias (e vice-versa). Além disso, a seleção por intervalo (por exemplo, usando <kbd>SHIFT</kbd> + clique) dentro da área fixada funciona da mesma forma que selecionar um intervalo de linhas na área rolável. A seleção resultante inclui todas as linhas entre elas, mesmo que não estejam fixadas no momento. Obter as linhas selecionadas pela API retorna apenas uma instância de cada registro selecionado.

<PlatformBlock for="Angular">
- Devido à forma como as linhas fixadas são armazenadas internamente, para poderem aparecer tanto na área fixada quanto na não fixada do grid, a fixação de linhas não é suportada quando os registros do grid são buscados sob demanda em um endpoint remoto (virtualização remota).
- Quando o grid não tem <ApiLink type="{ComponentName}" member="primaryKey" /> definido e os cenários de dados remotos estão habilitados (quando paginação, ordenação, filtragem ou rolagem disparam requisições a um servidor remoto para obter os dados a serem exibidos no grid), uma linha perderá o seguinte estado após a conclusão de uma requisição de dados:
  - Seleção de linha
  - Expandir/recolher linha
  - Edição de linha
  - Fixação de linha

</PlatformBlock>

## Estilização

O <ApiLink type="{ComponentName}" /> permite estilização por meio da [{ProductName} Theme Library](../themes/styles.mdx). O {ComponentTitle} de <ApiLink type="function-grid-theme" label="theme" kind="sass" module="index.html" /> expõe uma grande variedade de propriedades, que permitem personalizar todos os recursos do {ComponentTitle}.

A seguir, vamos percorrer os passos para personalizar a estilização da fixação de linhas do {ComponentTitle}.

### Importando a biblioteca de estilos

Para começar a personalizar o recurso de fixação de linhas, você precisa importar o arquivo `index`, onde estão todas as funções e mixins de estilização.

```scss
@use "igniteui-{Platform}/theming" as *;

// IMPORTANT: Prior to {ProductName} version 13 use:
// @import '~igniteui-{Platform}/lib/core/styles/themes/index';
```

### Definindo um tema

Em seguida, crie um novo tema que estenda o <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" /> e aceite os parâmetros necessários para personalizar o recurso de fixação de linhas como desejar.

```scss
$custom-grid-theme: grid-theme(
    /* Pinning properties that affect styling */
    $pinned-border-width: 5px,
    $pinned-border-style: double,
    $pinned-border-color: #FFCD0F,
    $cell-active-border-color: #FFCD0F
    /* add other features properties here... */
);
```

### Usando variáveis CSS

```scss

```

### Usando Mixins

Para estilizar componentes no Internet Explorer 11, é preciso usar uma abordagem diferente, já que ele não oferece suporte a variáveis CSS.

Se o componente usar um ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), é necessário `penetrate` essa encapsulação usando `::ng-deep`. Porém, para evitar que o tema personalizado vaze para outros componentes, certifique-se de incluir o seletor `:host` antes de `::ng-deep`:

```scss
:host {
    ::ng-deep {
        // Pass the custom grid theme to the `igx-grid` mixin
        @include grid($custom-grid-theme);
    }
}
```
