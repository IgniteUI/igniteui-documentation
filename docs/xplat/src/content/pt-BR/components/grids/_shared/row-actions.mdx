# Ações de linha em {Platform} {ComponentTitle}

O recurso de Ações de linha do {ProductName} em {Platform} {ComponentTitle} permite que os desenvolvedores usem um <ApiLink type="ActionStrip" /> e aproveitem o CRUD para componentes de linha e célula, além da fixação de linhas. Há vários controles de interface predefinidos para essas operações, aplicáveis a uma linha específica da <ApiLink type="{ComponentName}" />: edição e fixação.

## Uso

<PlatformBlock for="Angular">
O primeiro passo é importar o **IgxActionStripModule** no nosso arquivo **app.module.ts**:

```typescript
// app.module.ts
import { IgxActionStripModule } from 'igniteui-angular';

@NgModule({
    imports: [..., IgxActionStripModule],
})
```

</PlatformBlock>

Os componentes de interface de ações predefinidos são:

- <ApiLink type="GridEditingActions" /> - inclui funcionalidade e interface projetadas especificamente para a edição de <ApiLink type="{ComponentName}" />. Permite alternar rapidamente o modo de edição de células ou linhas, dependendo da opção <ApiLink type="{ComponentName}" member="rowEditable" />, e a exclusão de linhas da <ApiLink type="{ComponentName}" />.

- <ApiLink type="GridPinningActions" /> - inclui funcionalidade e interface projetadas especificamente para a fixação de linhas de <ApiLink type="{ComponentName}" />. Permite fixar linhas rapidamente e navegar entre as linhas fixadas e suas contrapartes desabilitadas.

Eles são adicionados dentro do <ApiLink type="{ComponentName}" />, e isso é tudo o que é necessário para ter um <ApiLink type="ActionStrip" /> que oferece interações padrão.

<PlatformBlock for="Angular">
```html

    <igx-column *ngFor="let c of columns" [field]="c.field">
    </igx-column>

    <igx-action-strip #actionStrip>
        <igx-grid-pinning-actions></igx-grid-pinning-actions>
```

## Implementação personalizada

Esses componentes expõem templates que oferecem flexibilidade para personalização. Por exemplo, se quisermos usar o <ApiLink type="ActionStrip" /> em um cenário semelhante ao do Gmail, com ações de linha como **excluir**, **editar** etc., você pode simplesmente criar um componente de botão com ícone, adicionar a ele um evento de clique e inseri-lo no <ApiLink type="ActionStrip" />.


<PlatformBlock for="Angular">
```html
<{ComponentSelector}>
    <igx-action-strip #actionstrip>
        <igx-grid-pinning-actions></igx-grid-pinning-actions>
        <button title="Edit" igxButton="icon" igxRipple (click)='startEdit(actionstrip.context)'>
            <igx-icon>edit</igx-icon>
        </button>
        @if (!isDeleted(actionstrip.context)) {
            <button title="Delete" igxButton="icon" igxRipple (click)='actionstrip.context.delete()'>
                <igx-icon>delete</igx-icon>
            </button>
        }
    </igx-action-strip>
</{ComponentSelector}>
```
</PlatformBlock>

<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">
<PlatformBlock for="Blazor">
```razor
<div class="grid__wrapper">
    <{ComponentSelector} Data=northwindEmployees>

            </IgbGridEditingActions>

```
</PlatformBlock>
