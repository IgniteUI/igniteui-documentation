# Barra de ferramentas do {Platform} {ComponentTitle}

A {ProductName} Toolbar em é um contêiner para operações de interface na {Platform} {ComponentTitle}. A barra de ferramentas {Platform} fica no topo do componente {Platform}, ou seja, <ApiLink type="{ComponentName}" />, e acompanha o tamanho horizontal dele. O contêiner da barra de ferramentas pode abrigar qualquer conteúdo personalizado ou um conjunto de controles de interface predefinidos. O conjunto padrão para a {Platform} {ComponentTitle} inclui:

- Ocultação de colunas
- Fixação de colunas
- Exportação para Excel
- Filtragem avançada

A barra de ferramentas e os componentes de interface predefinidos oferecem suporte a eventos {Platform} e expõem uma API para os desenvolvedores.

## Barra de ferramentas com grades filhas

<PlatformBlock for="Angular">
Devido a certas limitações na forma como as grades filhas de um IgxHierarchicalGrid são implementadas e como funciona o escopo de DI, há uma ressalva ao usar a barra de ferramentas no escopo de grades filhas. Ao definir um componente de barra de ferramentas dentro das tags `igx-row-island`, sempre use o IgxGridToolbar e passe a instância de grade fornecida como propriedade de input para a própria barra de ferramentas.
Isso garante que você sempre tenha a instância correta da grade no escopo do seu template:

```html
<igx-hierarchical-grid>
    <!--...-->
    <igx-row-island>
        <!--
            You can name the binding from igxGridToolbar however you want. Just make sure to use
            it inside the template if you need to access the grid instance.
        -->
        <igx-grid-toolbar [grid]="gridRef" *igxGridToolbar="let gridRef">
            <igx-grid-toolbar-title>Child toolbar {{ gridRef.parentIsland.level }}</igx-grid-toolbar-title>
        </igx-grid-toolbar>
    </igx-row-island>
    <!--...-->
</igx-hierarchical-grid>
```

</PlatformBlock>

<PlatformBlock for="WebComponents, React">

Isso permite que as grades filhas criem suas próprias instâncias separadas da barra de ferramentas:

public data: any[];
public positionStrategyScaleCenter = new GlobalPositionStrategy({
    openAnimation: scaleInCenter,

public overlaySettingsScaleCenter = {
    positionStrategy: this.positionStrategyScaleCenter,
    scrollStrategy: new AbsoluteScrollStrategy(),
    modal: true,
    closeOnEscape: true

public positionStrategyAuto = new AutoPositionStrategy();

    modal: false,

constructor() {

As overlaySettings padrão usam **ConnectedPositionStrategy** com a estratégia de rolagem **Absolute**, **modal** definido como false, com as interações habilitadas de **fechar com escape** e **fechar com clique externo**.

Se você precisar de uma revisão sobre DI no {Platform}, consulte o [guia oficial](https://{Platform}.io/guide/dependency-injection). Aqui está um trecho de exemplo mostrando como habilitar todos os serviços de exportação para a sua aplicação.

```typescript

import { IgxExcelExporterService, IgxCsvExporterService } from 'igniteui-{Platform}';

@NgModule({
    //...
    providers: [IgxExcelExporterService, IgxCsvExporterService ]
})
export class AppModule { ... }
```

<DocsAside type="info">
Na v12.2.1 e posteriores, os serviços de exportação são fornecidos no root, o que significa que você não precisa mais declará-los nos providers do AppModule.

## Estilização

Para começar a estilizar a barra de ferramentas, precisamos importar o arquivo index, onde ficam todas as funções de tema e os mixins de componente:

```scss
@use "igniteui-{Platform}/theming" as *;

// IMPORTANT: Prior to {ProductName} version 13 use:
// @import '~igniteui-{Platform}/lib/core/styles/themes/index';
```

Primeiro, vamos criar uma nova paleta.

```scss
$my-dark-palette: palette(
    $primary: #2466ff,
    $secondary: #FFCD0F,
    $surface: #2a2b2f,
    $grays: #fff,
);

$my-dark-color: color($my-dark-palette, 'surface');
```

Agora, crie um novo tema que estenda o <ApiLink type="function-grid-toolbar-theme" label="grid-toolbar-theme" kind="sass" module="index.html" /> e modifique os parâmetros `$background-color` e `$title-text-color`.

```scss
$dark-grid-toolbar-theme: grid-toolbar-theme(
    $background-color: $my-dark-color,
    $title-text-color: color($my-dark-palette, 'secondary'),
    $dropdown-background: $my-dark-color,
);
```

Para aplicar tema aos menus de ações de coluna da barra de ferramentas, precisamos alterar o tema do componente `column-actions-theme`.

```scss
$dark-column-actions-theme: column-actions-theme(
    $title-color: color($my-dark-palette, 'secondary'),
    $background-color: color($my-dark-palette, 'surface')
);
```

Como as ações de coluna usam outros componentes - igx-button, igx-checkbox e igx-input-group -, precisamos alterar os temas deles para combinar com o nosso novo tema da barra de ferramentas.

```scss
$dark-button-theme: outlined-button-theme(
    $background: color($my-dark-palette, 'secondary'),
    $hover-background: color($my-dark-palette, 'gray', 100),
    $hover-foreground: color($my-dark-palette, 'secondary')
);

$dark-checkbox-theme: checkbox-theme(
    $tick-color: $my-dark-color,
);

$dark-input-group-theme: input-group-theme(
    $filled-text-color: color($my-dark-palette, 'secondary')
);
```

A última etapa é **incluir** os temas recém-criados.

```scss
:host {
    @include grid-toolbar($dark-grid-toolbar-theme);
    @include column-actions($dark-column-actions-theme);
    @include checkbox($dark-checkbox-theme);
    @include input-group($dark-input-group-theme);
    @include button($dark-button-theme);
}
```

<DocsAside type="info">
Se `$legacy-support` estiver definido como `false(default)`, inclua as variáveis CSS do componente assim:
</DocsAside>

```scss
:host {
    @include tokens($dark-grid-toolbar-theme);
    @include tokens($dark-column-actions-theme);
    @include tokens($dark-checkbox-theme);
    @include tokens($dark-input-group-theme);
    @include tokens($dark-button-theme);
}
```

<DocsAside type="info">
Se o componente estiver usando um ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), é necessário `penetrate` esse encapsulamento usando `::ng-deep`:
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid-toolbar($dark-grid-toolbar-theme);
        @include column-actions($dark-column-actions-theme);
        @include checkbox($dark-checkbox-theme);
        @include input-group($dark-input-group-theme);
        @include button($dark-button-theme);
    }
}
```
