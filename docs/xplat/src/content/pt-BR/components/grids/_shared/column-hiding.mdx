# Ocultação de colunas do {Platform} {ComponentTitle}

<PlatformBlock for="Angular">
O {ProductName} <ApiLink type="{ComponentName}" /> oferece um <ApiLink type="ColumnActionsComponent" /> com um `ColumnHidingDirective`, que permite aos usuários ocultar colunas diretamente pela interface do usuário ou usando o componente {Platform}.
</PlatformBlock>

O {ProductName} tem uma interface integrada de ocultação de colunas, que pode ser usada pela barra de ferramentas {Platform} {ComponentTitle} para alterar o estado visível das colunas. Os desenvolvedores têm a flexibilidade de definir a interface de ocultação de colunas em qualquer lugar da página, conforme necessário. O recurso de ocultação de colunas do {Platform} {ComponentTitle} é especialmente útil quando se quer diminuir o tamanho da grade e eliminar a necessidade de navegar com Tab por campos redundantes.

## Interface de ocultação de colunas da barra de ferramentas

A interface integrada de ocultação de colunas fica dentro de um <ApiLink pkg="core" type="Dropdown" /> na barra de ferramentas do <ApiLink type="{ComponentName}" />. Podemos exibir/ocultar a interface de ocultação de colunas usando exatamente essa lista suspensa.

Para isso, basta definir tanto <ApiLink type="GridToolbarActions" /> quanto <ApiLink type="GridToolbarHiding" /> dentro de <ApiLink type="{ComponentName}" />.

<ComponentBlock for="Grid">
<PlatformBlock for="Angular">
```html
<igx-grid [data]="localdata">
    <igx-grid-toolbar>
        <igx-grid-toolbar-actions>
            <igx-grid-toolbar-hiding></igx-grid-toolbar-hiding>
        </igx-grid-toolbar-actions>
    </igx-grid-toolbar>
</igx-grid>
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```razor
<{ComponentSelector} Data=northwindEmployees>
```

O <ApiLink type="{ComponentName}" /> oferece algumas propriedades úteis quando se trata de usar a interface de ocultação de colunas da barra de ferramentas.

Usando a propriedade <ApiLink type="GridToolbarHiding" member="title" label="Title" />, definimos o título exibido dentro do botão suspenso da barra de ferramentas.
</PlatformBlock>

<PlatformBlock for="React, Blazor, WebComponents">
O <ApiLink type="{ComponentName}" /> oferece algumas propriedades úteis quando se trata de usar a interface de ocultação de colunas da barra de ferramentas.

Usando as propriedades <ApiLink type="GridToolbarHiding" member="title" label="Title" /> e <ApiLink type="GridToolbarHiding" member="prompt" label="Prompt" />, definimos o título e o texto de orientação do filtro exibidos dentro da lista suspensa da barra de ferramentas.
</PlatformBlock>

### Adicionar opções de ordem de exibição de colunas

Também podemos permitir que o usuário escolha a ordem de exibição das colunas na interface de ocultação de colunas. Para isso, usaremos a propriedade `ColumnDisplayOrder`, que é do tipo enumeração e tem as seguintes opções:

## Estilização

Para começar a estilizar o componente de ações de coluna, precisamos importar o arquivo de índice, onde ficam todas as funções de tema e os mixins dos componentes:

```scss
@use "igniteui-{Platform}/theming" as *;

// IMPORTANT: Prior to {ProductName} version 13 use:
// @import '~igniteui-{Platform}/lib/core/styles/themes/index';
```

Usando a abordagem mais simples, criamos um novo tema que estende o `column-actions-theme` e aceita os parâmetros `$title-color` e `$background-color`.

```scss
$custom-column-actions-theme: column-actions-theme(
    $background-color: steelblue,
    $title-color: gold
);
```

Como visto, o `column-actions-theme` controla apenas as cores do contêiner de ações de coluna, mas não afeta os botões, as caixas de seleção e o input-group dentro dele. Digamos que queremos estilizar também os botões; por isso, criaremos um novo tema de botão:

```scss
$custom-button: flat-button-theme($foreground: gold, $disabled-foreground: black);
```

Neste exemplo, alteramos apenas a cor do texto dos botões flat e a cor de botão desativado, mas o `flat-button-theme` oferece muito mais parâmetros para controlar a estilização dos botões.

A última etapa é **incluir** os mixins dos componentes, cada um com o seu tema correspondente:

```scss
@include column-actions($custom-column-actions-theme);
.igx-column-actions {
    @include button($custom-button);
}
```

> **Observação**
>Limitamos o mixin **igx-button** dentro de `.igx-column-actions`, para que apenas os botões de ocultação de colunas sejam estilizados. Caso contrário, outros botões da grade também seriam afetados.

 > **Observação**
 >Se o componente estiver usando um ViewEncapsulation `Emulated`, é necessário `penetrate` esse encapsulamento usando `::ng-deep`:

```scss
:host {
    ::ng-deep {
        @include column-actions($custom-column-actions-theme);
        .igx-column-actions {
            @include button($custom-button);
        }
    }
}
```

### Definindo uma paleta de cores

Em vez de fixar os valores de cor como acabamos de fazer, podemos obter mais flexibilidade em relação às cores usando as funções `igx-palette` e `igx-color`.

`igx-palette` gera uma paleta de cores com base nas cores primária e secundária que são passadas:

```scss
$yellow-color: gold;
$blue-color: steelblue;

$custom-palette: palette($primary: $blue-color, $secondary: $yellow-color);
```

E então, com `igx-color`, podemos obter facilmente uma cor da paleta.

```scss
$custom-column-actions-theme: column-actions-theme(
    $title-color: color($custom-palette, "secondary", 400),
    $background-color: color($custom-palette, "primary", 200)
);

$custom-button: flat-button-theme(
    $foreground: color($custom-palette, "secondary", 400),
    $disabled-foreground: black
);
```

> **Observação**
>As funções `igx-color` e `igx-palette` são poderosas para gerar e obter cores. Consulte o tópico [Paletas](../themes/sass/palettes.mdx) para orientações detalhadas sobre como usá-las.

### Usando schemas

Indo além do mecanismo de temas, você pode criar uma estrutura robusta e flexível que se beneficia dos [**schemas**](themes/sass/schemas.mdx). Um **schema** é uma receita de tema.

```scss
// Extending the dark column actions schema
$custom-column-actions-schema: extend($_dark-column-actions,
    (
        title-color:(
           color: ("secondary", 400)
        ),
        background-color:(
           color: ("primary", 200)
        )
    )
);
// Extending the dark button schema
$custom-button-schema: extend($_dark-button,
    (
        flat-text-color:(
           color: ("secondary", 500)
        ),
        disabled-color:(
           color: ("primary", 700)
        )
    )
);
```

Para aplicar os nossos schemas personalizados, precisamos **estender** um dos globais `light` ou `dark`, o que basicamente indica os componentes com um schema personalizado, e depois adicioná-lo aos temas dos respectivos componentes:

```scss
// Extending the global dark-schema
$custom-dark-schema: extend($dark-schema,(
    igx-column-actions: $custom-column-actions-schema,
    igx-button: $custom-button-schema
));

// Defining column-actions-theme with the global dark schema
$custom-column-actions-theme: column-actions-theme(
  $schema: $custom-dark-schema
);

// Defining flat-button-theme with the global dark schema
$custom-button: flat-button-theme(
  $schema: $custom-dark-schema
);
```

Não se esqueça de incluir os temas da mesma forma como foi demonstrado acima.
