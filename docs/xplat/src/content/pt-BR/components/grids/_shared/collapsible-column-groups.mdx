## Uso

**Grupos de colunas recolhíveis** fazem parte do recurso de cabeçalhos de várias colunas, que oferece uma forma de recolher/expandir um grupo de colunas para um conjunto menor de dados. Quando um grupo de colunas é recolhido, um subconjunto das colunas é mostrado ao usuário final, e as outras colunas filhas do grupo ficam ocultas. Cada coluna recolhida/expandida pode ser vinculada à fonte de dados do grid, ou pode não estar vinculada e, portanto, ser calculada.

Para definir um grupo de colunas como recolhível, é preciso definir a propriedade <ApiLink type="ColumnGroup" member="collapsible" /> em <ApiLink type="ColumnGroup" /> como **true**.

É preciso definir a propriedade <ApiLink type="ColumnState" member="visibleWhenCollapsed" /> para pelo menos duas colunas filhas. Pelo menos uma coluna deve estar visível quando o grupo está recolhido (<ApiLink type="ColumnState" member="visibleWhenCollapsed" /> definido como **true**), e pelo menos uma coluna deve estar oculta quando o grupo está expandido (<ApiLink type="ColumnState" member="visibleWhenCollapsed" /> definido como `false`); caso contrário, a **funcionalidade de recolher será desabilitada**. Se <ApiLink type="ColumnState" member="visibleWhenCollapsed" /> não for especificado para algumas das colunas filhas, essa coluna ficará sempre visível, independentemente de o estado do pai estar expandido ou recolhido.

Vejamos a marcação abaixo:

Resumindo, cada coluna filha tem três estados:
- Pode ficar sempre visível, independentemente do estado expandido do seu pai.
- Pode ficar visível quando o seu pai está recolhido.
- Pode ficar oculta quando o seu pai está recolhido.

O estado inicial do grupo de colunas especificado como recolhível é <ApiLink type="ColumnGroup" member="expanded" /> definido como **true**, mas você pode alterar esse comportamento facilmente definindo-o como **false**.

<PlatformBlock for="Blazor">
```razor
 <IgbColumnGroup @ref="infoColumn" Header="Customer Information" Collapsible="true">
    <IgbColumn Field="CustomerName" Header="Full name" VisibleWhenCollapsed="true"></IgbColumn>
    <IgbColumn Field="CustomerID" Header="Customer ID" VisibleWhenCollapsed="false"></IgbColumn>
    <IgbColumn Field="FirstName" Header="First Name" VisibleWhenCollapsed="false"></IgbColumn>
    <IgbColumn Field="LastName" Header="Last Name" VisibleWhenCollapsed="false"></IgbColumn>
    <IgbColumnGroup @ref="addressColumn" Header="Customer Address">
        <IgbColumn Field="Country" Header="Country" Sortable="true"></IgbColumn>
        <IgbColumn Field="City" Header="City" Sortable="true"></IgbColumn>
    </IgbColumnGroup>
 </IgbColumnGroup>

@code {
    private IgbColumnGroup infoColumn;
    private IgbColumnGroup addressColumn;

    public RenderFragment<IgbColumnTemplateContext> ColumnIndicatorTemplate = (context) =>
    {
        string icon = context.Column.Expanded ? "remove" : "add";
        return @<IgbIcon IconName="@icon" Collection="material"></IgbIcon>;
    };

    protected override void OnAfterRender(bool firstRender)
    {
        this.infoColumn.CollapsibleIndicatorTemplate = this.ColumnIndicatorTemplate;
        this.addressColumn.CollapsibleIndicatorTemplate = this.ColumnIndicatorTemplate;
    }
}

```
</PlatformBlock>

### Usando a propriedade

Você pode definir um template personalizado de expandir/recolher e fornecê-lo a cada grupo de colunas recolhível usando a propriedade <ApiLink type="ColumnGroup" member="collapsibleIndicatorTemplate" />. Veja a marcação abaixo:

```html
<ng-template #indTemplate let-column="column">
    <igx-icon [attr.draggable]="false" >{{column.expanded ? 'remove' : 'add'}} </igx-icon>
</ng-template>
<igx-column-group header="Customer Information" [collapsible]="true" [collapsibleIndicatorTemplate]="indTemplate">
    <igx-column field="CustomerName" header="Fullname" [dataType]="'string'" [visibleWhenCollapsed]="true"></igx-column>
    <igx-column field="CustomerID" header="Customer ID" [dataType]="'string'" [visibleWhenCollapsed]="false"></igx-column>
    <igx-column-group header="Customer Address" [collapsible]="true" [collapsibleIndicatorTemplate]="indTemplate">
        <igx-column field="Country" header="Country" [dataType]="'string'" [sortable]="true" [visibleWhenCollapsed]="true"></igx-column>
        <igx-column field="City" header="City" [dataType]="'string'" [sortable]="true" [visibleWhenCollapsed]="false"></igx-column>
    </igx-column-group>
</igx-column-group>
```

> **Observação**
> Tenha em mente que a opção de grupo inicialmente recolhido tem precedência sobre a coluna oculta - se você declarou a sua coluna como oculta usando a propriedade
> hidden e tiver um grupo definido onde a mesma coluna deve ser exibida, a coluna será exibida.
