## Exemplo de edição em lote e transações do {Platform} {ComponentTitle}

O exemplo a seguir demonstra um cenário em que o <ApiLink type="{ComponentName}" /> tem <ApiLink type="{ComponentName}" member="batchEditing" /> habilitado e a edição de linha habilitada. Esta última garantirá que a transação seja adicionada depois que a edição de toda a linha for confirmada.

## Uso

Você precisa habilitar a <ApiLink type="{ComponentName}" member="batchEditing" /> a partir do seu {ComponentTitle}:

<PlatformBlock for="WebComponents">
```html
<{ComponentSelector} [data]="data" [batchEditing]="true">
</{ComponentSelector}>
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```razor
<{ComponentSelector} Data=data BatchEditing="true">
</{ComponentSelector}>
```
</PlatformBlock>

Isso garantirá que uma instância adequada do serviço `Transaction` seja fornecida ao <ApiLink type="{ComponentName}" />. O <ApiLink type="TransactionService" /> adequado é fornecido por meio de um `TransactionFactory`.

<PlatformBlock for="Angular">
Você pode saber mais sobre essa implementação interna no [tópico de transações](../transaction-classes.mdx#transaction-factory).

</PlatformBlock>

Depois de habilitar a edição em lote, defina um <ApiLink type="{ComponentName}" /> com uma fonte de dados vinculada e <ApiLink type="{ComponentName}" member="rowEditable" /> definido como true, e faça a vinculação:

<ComponentBlock for="Grid">
<PlatformBlock for="Angular">
```html
<igx-grid #grid [batchEditing]="true" [data]="data" [primaryKey]="'ProductID'" width="100%" height="500px"
    [rowEditable]="true">
</igx-grid>

<button igxButton [disabled]="!grid.transactions.canUndo" (click)="undo()">Undo</button>
<button igxButton [disabled]="!grid.transactions.canRedo" (click)="redo()">Redo</button>
<button igxButton [disabled]="grid.transactions.getAggregatedChanges(false).length < 1"
    (click)="openCommitDialog(dialogGrid)">Commit</button>

```
</PlatformBlock>

<PlatformBlock for="Blazor">
```razor
<IgbGrid @ref="grid" BatchEditing="true" Data=data PrimaryKey=primaryKey Width="100%" Height="500px"

    {
        this.grid.transactions.commit(this.data);
    }

    private void OnUndoClick(MouseEventArgs e)
    {
        this.grid.transactions.undo();

    {
        this.grid.transactions.redo();
    }
}

constructor() {
    var grid = this.grid = document.getElementById('grid') as IgcGridComponent;
    var undo = this.undo = document.getElementById('undo') as HTMLButtonElement;
    var redo = this.redo = document.getElementById('redo') as HTMLButtonElement;
    var commit = this.commit = document.getElementById('commit') as HTMLButtonElement;
}

this._bind = () => {
    grid.data = this.data;
    undo.addEventListener('click', this.OnUndoClick);
    redo.addEventListener('click', this.OnRedoClick);
    commit.addEventListener('click', this.OnCommitClick);
}
this._bind();

private OnCommitClick() {
    if (this.grid.transactions.getAggregatedChanges(false).length > 0)
        this.grid.transactions.commit(this.data);
}

private OnUndoClick() {
    if (this.grid.transactions.canUndo)
        this.grid.transactions.undo();
}

private OnRedoClick() {
    if (this.grid.transactions.canRedo)
        this.grid.transactions.redo();
}
```

<DocsAside type="info">
A API de transações não trata o fim da edição; você precisará fazê-lo por conta própria. Caso contrário, o `{ComponentName}` permanecerá em modo de edição. Uma forma de fazer isso é chamando `EndEdit` no respectivo método.
</DocsAside>

<ComponentBlock for="TreeGrid">
Excluir um nó pai no <ApiLink type="{ComponentName}" /> tem algumas particularidades. Se você estiver usando dados hierárquicos, os filhos serão excluídos quando o pai for excluído. Se estiver usando dados planos, você pode definir o comportamento desejado usando a propriedade `CascadeOnDelete` de <ApiLink type="{ComponentName}" />. Essa propriedade indica se os registros filhos devem ser excluídos quando o pai for excluído (por padrão, ela é definida como **true**).
</ComponentBlock>

<DocsAside type="info">
Desabilitar a propriedade <ApiLink type="{ComponentName}" member="rowEditable" /> fará com que `{ComponentName}` crie transações a cada alteração de célula e não exporá o overlay de edição de linha na UI.
</DocsAside>
