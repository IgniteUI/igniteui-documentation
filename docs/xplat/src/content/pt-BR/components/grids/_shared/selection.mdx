# {Platform} {ComponentTitle} visão geral da seleção

Com o recurso de Seleção do {ProductName} em {Platform} {ComponentTitle}, você pode interagir e manipular dados facilmente com interações simples do mouse. Há três modos de seleção disponíveis:

- Seleção de linhas
- Seleção de células
- Seleção de colunas

Com a propriedade <ApiLink type="{ComponentName}" member="rowSelection" />, você pode especificar:

- None
- Única
- Seleção múltipla

## Opções de seleção do {Platform} {ComponentTitle}

<ComponentBlock for="Grid, HierarchicalGrid">
O componente {ProductName} <ApiLink type="{ComponentName}" /> oferece três modos de seleção diferentes: [Seleção de linhas](row-selection.mdx), [Seleção de células](cell-selection.mdx) e [Seleção de colunas](column-selection.mdx). Por padrão, somente o modo **Seleção de várias células** fica habilitado na <ApiLink type="{ComponentName}" />. Para alterar ou habilitar o modo de seleção, você pode usar as propriedades <ApiLink type="{ComponentName}" member="rowSelection" />, <ApiLink type="{ComponentName}" member="cellSelection" /> ou <ApiLink type="Column" member="selectable" />.

</ComponentBlock>

### Seleção de linhas do {Platform} {ComponentTitle}

A propriedade <ApiLink type="{ComponentName}" member="rowSelection" /> permite especificar as seguintes opções:

- `None` - a seleção de linhas ficaria desabilitada para a <ApiLink type="{ComponentName}" />.
- `Single` - ficaria disponível a seleção de apenas uma linha dentro da <ApiLink type="{ComponentName}" />.
- `Multiple` - a seleção de várias linhas ficaria disponível usando os seletores de linha, com uma combinação de teclas como <kbd>CTRL</kbd> + <kbd>click</kbd>, ou pressionando a <kbd>tecla de espaço</kbd> quando uma célula estiver com foco.

<ComponentBlock for="TreeGrid, HierarchicalGrid">
- `MultipleCascade` - é um modo de seleção em cascata, que resulta na seleção de todos os filhos na árvore abaixo do registro que o usuário seleciona por interação. Nesse modo, o estado de seleção de um pai depende inteiramente do estado de seleção de seus filhos.

</ComponentBlock>

> Consulte o tópico [Seleção de linhas](row-selection.mdx) para mais informações.

### Seleção de células do {Platform} {ComponentTitle}

A propriedade <ApiLink type="{ComponentName}" member="cellSelection" /> permite especificar as seguintes opções:

- `None` - a seleção de células ficaria desabilitada para a <ApiLink type="{ComponentName}" />.
- `Single` - ficaria disponível a seleção de apenas uma célula dentro da <ApiLink type="{ComponentName}" />.
- `Multiple` - atualmente, este é o estado padrão da seleção na <ApiLink type="{ComponentName}" />. A seleção de várias células está disponível arrastando o mouse sobre as células, após clicar continuamente com o botão esquerdo do mouse.

<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">
> Consulte o tópico [Seleção de células](cell-selection.mdx) para mais informações.

</ComponentBlock>

### Seleção de colunas do {Platform} {ComponentTitle}

A propriedade <ApiLink type="Column" member="selectable" /> permite especificar as seguintes opções para cada <ApiLink type="Column" />. A seleção de colunas correspondente será habilitada ou desabilitada se essa propriedade for definida como true ou false, respectivamente.

Isso leva às três variações a seguir:

- Seleção única - <kbd>clique do mouse</kbd> sobre a célula da coluna.
- Seleção de múltiplas colunas - mantendo <kbd>CTRL</kbd> + <kbd>clique do mouse</kbd> sobre as células da coluna.
- Seleção de intervalo de colunas - mantendo <kbd>SHIFT</kbd> + <kbd>clique do mouse</kbd>, seleciona tudo o que está entre elas.

> Consulte o tópico [Seleção de colunas](column-selection.mdx) para mais informações.

</ComponentBlock>

## Menu de contexto do {Platform} {ComponentTitle}

Usando o evento <ApiLink type="{ComponentName}" member="contextMenu" />, você pode adicionar um menu de contexto personalizado para facilitar seu trabalho com <ApiLink type="{ComponentName}" />. Com um **clique com o botão direito** no corpo da grade, o evento emite a célula na qual foi disparado. O **menu de contexto** operará com a célula emitida.

Se houver uma **seleção de várias células**, colocaremos uma lógica que verifica se a célula selecionada está na área da seleção de várias células. Se estiver, também emitiremos os valores das células selecionadas.

Basicamente, a função principal ficará assim:

<PlatformBlock for="Angular">
```typescript
public rightClick(eventArgs: any) {
     // Prevent the default behavior of the right click
    eventArgs.event.preventDefault();
    this.multiCellArgs = {};
    // If we have multi-cell selection, check if selected cell is within the ranges
    if (this.multiCellSelection) {
        const node = eventArgs.cell.selectionNode;
        const isCellWithinRange = this.grid1.getSelectedRanges().some(range => {
            if (node.column >= range.columnStart &&
                node.column <= range.columnEnd &&
                node.row >= range.rowStart &&
                node.row <= range.rowEnd) {
                return true;
            }
            return false;
        })
        // If the cell is within a multi-cell selection range, bind all the selected cells data
        if (isCellWithinRange) {
            this.multiCellArgs = { data: this.multiCellSelection.data };
        }
    }
    // Set the position of the context menu
    this.contextmenuX = eventArgs.event.clientX;
    this.contextmenuY = eventArgs.event.clientY;
    this.clickedCell = eventArgs.cell;
    // Enable the context menu
    this.contextmenu = true;
}
```

O menu de contexto terá as seguintes funções:

- Copiar o _valor_ da célula selecionada.
- Copiar o _dataRow_ da célula selecionada.
- Se a célula selecionada estiver dentro de um **intervalo de seleção de várias células**, copiar todos os _dados selecionados_.

//contextmenu.component.ts

public copySelectedCellData(event) {
    const selectedData = { [this.cell.column.field]: this.cell.value };
    this.copyData(JSON.stringify({ [this.cell.column.field]: this.cell.value }));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copyRowData(event) {
    const selectedData = this.cell.row.data ;
    this.copyData(JSON.stringify(this.cell.row.data));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copySelectedCells(event) {
    const selectedData = this.selectedCells.data;
    this.copyData(JSON.stringify(selectedData));
    this.onCellValueCopy.emit({ data: selectedData });
}

    public copySelectedRowData() {

        this.copyData(selectedData);

        selectedDataArea.innerText = JSON.stringify(selectedData);
        this.toggleContextMenu();
    }


    public copySelectedData() {
        const selectedData = this.grid.getSelectedData();
        this.copyData(selectedData);
        const selectedDataArea = document.getElementById('selectedArea');
        selectedDataArea.innerText = JSON.stringify(selectedData);

        this.toggleContextMenu();
    }

    private copyData(data: any[]) {
        const tempElement = document.createElement('input');
        document.body.appendChild(tempElement);
        tempElement.setAttribute('id', 'temp_id');
        (document.getElementById('temp_id') as HTMLInputElement).value = JSON.stringify(data);
        tempElement.select();
        document.execCommand('copy');
        document.body.removeChild(tempElement);
    }

## Problemas conhecidos e limitações

<PlatformBlock for="Angular">
- Usar o <ApiLink type="{ComponentName}" /> com a Seleção habilitada no IE11 exige a importação explícita do polyfill de array no arquivo polyfill.ts da aplicação {Platform}. O IE11 não é mais suportado a partir da versão 13.0.0.

```typescript
import "core-js/es7/array";
```

</PlatformBlock>

Quando o grid não tem <ApiLink type="{ComponentName}" member="primaryKey" /> definido e os cenários de dados remotos estão habilitados (quando paginação, ordenação, filtragem ou rolagem disparam requisições a um servidor remoto para obter os dados a serem exibidos no grid), uma linha perderá o seguinte estado após a conclusão de uma requisição de dados:

- Seleção de linha
- Expandir/recolher linha
- Edição de linha
- Fixação de linha
