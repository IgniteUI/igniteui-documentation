# Filtragem avançada do {Platform} {ComponentTitle}

A filtragem avançada do {ProductName} em {Platform} {ComponentTitle} permite manipular os dados com uma caixa de diálogo em que você pode criar grupos diferentes com condições de filtro em todas as colunas da <ApiLink type="{ComponentName}" />.

## Exemplo de filtragem avançada do {Platform} {ComponentTitle}

<Sample src="/{ComponentSample}/advanced-filtering-options" height={530} alt="Exemplo de filtragem avançada do {Platform} {ComponentTitle}" />

## Interação

Para abrir a caixa de diálogo de filtragem avançada, clique no botão **Advanced Filtering** na barra de ferramentas da grade. Se nenhum filtro avançado estiver aplicado, comece criando um grupo de condições de filtro vinculadas por **AND** ou **OR**. Depois, você pode adicionar condições de filtro ou subgrupos.

Para adicionar uma condição de filtro, você precisa selecionar qualquer uma das colunas <ApiLink type="Column" member="filterable" />, um operando baseado no <ApiLink type="Column" member="dataType" /> da coluna e um valor, caso o operando não seja unário. Depois que a condição é confirmada, aparece um chip com as informações da condição. Ao passar o mouse ou clicar no chip, você tem as opções de modificá-lo ou adicionar outra condição ou grupo logo depois dele.

Se você selecionar mais de um chip de condição de filtro, aparece um menu de contexto com opções para criar um grupo ou excluir os filtros. Se você optar por criar um grupo com as condições selecionadas, o grupo recém-criado aparecerá onde a condição selecionada mais acima estava posicionada.

Para selecionar um grupo, você também pode clicar na sua linha vertical, que é colorida de acordo com a condição de vinculação **AND** ou **OR**. Se um único grupo estiver selecionado, você recebe um menu de contexto com opções para alterar a sua lógica de filtragem, desagrupá-lo ou excluí-lo.

Para filtrar os dados depois de criar as condições e os grupos de filtragem, clique no botão **Apply**. Se você modificou o filtro avançado, mas não quer manter as alterações, clique no botão **Cancel**. Você também pode limpar o filtro avançado clicando no botão **Clear Filter**.

A filtragem avançada gera um <ApiLink type="{ComponentName}" member="filteringExpressionsTree" />, que é armazenado na propriedade de entrada <ApiLink type="{ComponentName}" member="advancedFilteringExpressionsTree" />. Você pode usar a propriedade <ApiLink type="{ComponentName}" member="advancedFilteringExpressionsTree" /> para definir um estado inicial da filtragem avançada.

<PlatformBlock for="Angular">
```typescript
ngAfterViewInit(): void {
    const tree = new FilteringExpressionsTree(FilteringLogic.And);
    tree.filteringOperands.push({
        fieldName: 'ID',
        condition: IgxStringFilteringOperand.instance().condition('contains'),
        searchVal: 'a',
        ignoreCase: true
    });
    const subTree = new FilteringExpressionsTree(FilteringLogic.Or);
    subTree.filteringOperands.push({
        fieldName: 'ContactTitle',
        condition: IgxStringFilteringOperand.instance().condition('doesNotContain'),
        searchVal: 'b',
        ignoreCase: true
    });
    subTree.filteringOperands.push({
        fieldName: 'CompanyName',
        condition: IgxStringFilteringOperand.instance().condition('startsWith'),
        searchVal: 'c',
        ignoreCase: true
    });
    tree.filteringOperands.push(subTree);

    this.@@igObjectRef.advancedFilteringExpressionsTree = tree;
}

```

</PlatformBlock>

## Filtragem avançada externa

## Estilização

Para começar a estilizar a caixa de diálogo de Filtragem Avançada, precisamos importar o arquivo **index**, onde ficam todas as funções de tema e os mixins dos componentes:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

A caixa de diálogo de filtragem avançada obtém a cor de fundo do tema da grade, usando o parâmetro **filtering-row-background**. Para alterar o fundo, precisamos criar um tema personalizado:

```scss
$custom-grid: grid-theme(
    $filtering-row-background: #FFCD0F
);
```

Como há outros componentes dentro da caixa de diálogo de filtragem avançada, como botões, chips, listas suspensas e entradas, precisamos criar um tema separado para cada um:

```scss
$custom-button: flat-button-theme(
    $disabled-foreground: gray,

);

$custom-button-group: button-group-theme(
    $item-background:  #292826,

);

$custom-input-group: input-group-theme(
    $box-background: #4a4a4a,

);

$custom-chip: chip-theme(
    $background: #FFCD0F,

);

$custom-drop-down: drop-down-theme(
    $background-color: #292826,

);
```

Neste exemplo, alteramos apenas alguns parâmetros dos componentes listados, mas os temas <ApiLink type="function-flat-button-theme" label="flat-button-theme" kind="sass" module="index.html" />, <ApiLink type="function-button-group-theme" label="button-group-theme" kind="sass" module="index.html" />, <ApiLink type="function-chip-theme" label="chip-theme" kind="sass" module="index.html" />, <ApiLink type="function-drop-down-theme" label="drop-down-theme" kind="sass" module="index.html" /> e <ApiLink type="function-input-group-theme" label="input-group-theme" kind="sass" module="index.html" /> oferecem muito mais parâmetros para controlar a estilização de cada um.

A última etapa é **incluir** os mixins dos componentes, cada um com o seu tema correspondente. Também adicionaremos alguns estilos para outros elementos dentro da caixa de diálogo de filtragem avançada.

```scss
@include grid($custom-grid);
igx-advanced-filtering-dialog {
    @include button($custom-button);
    @include button-group($custom-button-group);
    @include input-group($custom-input-group);
    @include chip($custom-chip);
    @include drop-down($custom-drop-down);
    .igx-filter-empty__title {
        color: #FFCD0F
    }
    .igx-advanced-filter__header {
        color: #FFCD0F
    }
    .igx-filter-tree__expression-actions igx-icon {
        color: #FFCD0F
    }
    .igx-filter-tree__expression-actions igx-icon:hover {
        color: #ffe482
    }
    .igx-filter-tree__expression-actions igx-icon:focus {
        color: #ffe482
    }
    .igx-filter-contextual-menu {
        border: 1px solid #FFCD0F
    }
    .igx-filter-contextual-menu__close-btn {
        position: absolute !important;
        background: #292826 !important;
        border-color: #FFCD0F !important;
    }
    .igx-input-group__input::placeholder {
        color: gray;
    }
}
```

<DocsAside type="info">
Limitamos a maioria dos mixins dos componentes dentro de `igx-advanced-filtering-dialog`, para que esses temas personalizados afetem apenas os componentes aninhados na caixa de diálogo de filtragem avançada. Caso contrário, outros botões, chips, entradas e listas suspensas da aplicação também seriam afetados.
</DocsAside>

### Definindo uma paleta de cores

Em vez de fixar os valores de cor como acabamos de fazer, podemos obter mais flexibilidade em relação às cores usando as funções <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" /> e <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />.

`igx-palette` gera uma paleta de cores com base nas cores primária e secundária que são passadas:

```scss
$yellow-color: #FFCD0F;
$black-color: #292826;
$dark-palette: palette($primary: $yellow-color, $secondary: $black-color);
```

E então, com <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />, podemos obter facilmente uma cor da paleta.

```scss
$custom-grid: grid-theme(
    $filtering-row-background: color($dark-palette, "secondary", 400)
);

$custom-button: flat-button-theme(
    $disabled-foreground: color($dark-palette, "secondary", 100),

);

$custom-button-group: button-group-theme(
    $item-background: color($dark-palette, "secondary", 400),

);

$custom-input-group: input-group-theme(
    $box-background: color($dark-palette, "secondary", 200),

);

$custom-chip: chip-theme(
    $background: color($dark-palette, "primary", 400),

);

$custom-drop-down: drop-down-theme(
    $background-color: color($dark-palette, "secondary", 400),

);
```

<DocsAside type="info">
As funções `igx-color` e `igx-palette` são poderosas para gerar e obter cores. Consulte o tópico [Paletas](../themes/sass/palettes.mdx) para orientações detalhadas sobre como usá-las.
</DocsAside>

### Usando schemas

Indo além do mecanismo de temas, você pode criar uma estrutura robusta e flexível que se beneficia dos [**schemas**](../themes/sass/schemas.mdx). Um **schema** é uma receita de tema.

Estenda um dos dois schemas predefinidos fornecidos para cada componente, neste caso - os schemas <ApiLink type="variable-_light-grid" label="light-grid" kind="sass" module="index.html" />, <ApiLink type="variable-_light-button" label="light-button" kind="sass" module="index.html" />, <ApiLink type="variable-_light-button-group" label="light-button-group" kind="sass" module="index.html" />, <ApiLink type="variable-_light-chip" label="light-chip" kind="sass" module="index.html" />, <ApiLink type="variable-_light-input-group" label="light-input-group" kind="sass" module="index.html" /> e <ApiLink type="variable-_light-drop-down" label="light-drop-down" kind="sass" module="index.html" />:

```scss
$grid-dark-palette: palette($primary: #11bd7b, $secondary: #e32057, $info: $black-color);

$custom-grid-schema: extend($_light-grid,
    (
        filtering-row-background:(
           color: ("info")
        )
    )
);

$custom-button-schema: extend($_light-button,
    (
        disabled-color:(
           color: ("secondary", 100)
        ),

    )
);

$custom-button-group-schema: extend($_light-button-group,
    (
        item-background:(
           color: ("secondary", 400)
        ),

    )
);

$custom-input-group-schema: extend($_light-input-group,
    (
        box-background:(
           color: ("secondary", 200)
        ),

    )
);

$custom-chip-schema: extend($_light-chip,
    (
        background:(
           color: ("primary", 400)
        ),

    )
);

$custom-drop-down-schema: extend($_light-drop-down,
    (
        background-color:(
           color: ("secondary", 400)
        ),

    )
);
```

Para aplicar os nossos schemas personalizados, precisamos **estender** um dos globais (<ApiLink type="variable-light-schema" label="light" kind="sass" module="index.html" /> ou <ApiLink type="variable-dark-schema" label="dark" kind="sass" module="index.html" />), o que basicamente indica os componentes com um schema personalizado, e depois adicioná-lo aos temas dos respectivos componentes:

```scss
$custom-light-schema: extend($light-schema,(
    igx-grid: $custom-grid-schema,
    igx-button: $custom-button-schema,
    igx-button-group: $custom-button-group-schema,
    igx-input-group: $custom-input-group-schema,
    igx-chip: $custom-chip-schema,
    igx-drop-down: $custom-drop-down-schema
));

$custom-grid: grid-theme(
    $schema: $custom-light-schema
);

$custom-button: flat-button-theme(
    $schema: $custom-light-schema
);

$custom-button-group: button-group-theme(
    $schema: $custom-light-schema
);

$custom-input-group: input-group-theme(
    $schema: $custom-light-schema
);

$custom-chip: chip-theme(
    $schema: $custom-light-schema
);

$custom-drop-down: drop-down-theme(
    $schema: $custom-light-schema
);
```

Não se esqueça de incluir os temas da mesma forma como foi demonstrado acima.
