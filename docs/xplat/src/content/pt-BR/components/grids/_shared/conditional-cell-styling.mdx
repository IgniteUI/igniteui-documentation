# Estilização condicional do {Platform} {ComponentTitle}

O recurso de Estilização condicional do {ProductName} em {Platform} {ComponentTitle} permite estilização personalizada no nível da linha ou da célula. A funcionalidade de Estilização condicional do <ApiLink type="{ComponentName}" /> é usada para realçar visualmente dados que atendem a determinados critérios, facilitando para os usuários identificar informações importantes ou tendências na grade.

## Estilização condicional de linhas do {ComponentTitle}

O componente <ApiLink type="{ComponentName}" /> em {ProductName} oferece duas formas de **estilização condicional de linhas** com base em regras personalizadas.

- Definindo a entrada <ApiLink type="{ComponentName}" member="rowClasses" /> no componente <ApiLink type="{ComponentName}" />;
- Definindo a entrada <ApiLink type="{ComponentName}" member="rowStyles" /> no componente <ApiLink type="{ComponentName}" />;

Mais adiante neste tópico, abordaremos as duas com mais detalhes.

### Usando classes de linha

Você pode estilizar condicionalmente as linhas do <ApiLink type="{ComponentName}" /> definindo a entrada <ApiLink type="{ComponentName}" member="rowClasses" /> e definindo regras personalizadas.

### Usando estilos de linha

O controle <ApiLink type="{ComponentName}" /> expõe a propriedade <ApiLink type="{ComponentName}" member="rowStyles" />, que permite a estilização condicional das linhas de dados. Assim como em <ApiLink type="{ComponentName}" member="rowClasses" />, ela aceita um objeto literal em que as chaves são propriedades de estilo e os valores são expressões a serem avaliadas. Além disso, você pode aplicar estilização comum (sem condições).

> A assinatura do callback tanto para <ApiLink type="{ComponentName}" member="rowStyles" /> quanto para <ApiLink type="{ComponentName}" member="rowClasses" /> é:

<PlatformBlock for="Angular">

</PlatformBlock>

<PlatformBlock for="WebComponents">

</PlatformBlock>

### Usando estilos de célula

As colunas expõem a propriedade <ApiLink type="Column" member="cellStyles" label="CellStyles" />, que permite a estilização condicional das células da coluna. Assim como em <ApiLink type="Column" member="cellClasses" />, ela aceita um objeto literal em que as chaves são propriedades de estilo e os valores são expressões a serem avaliadas. Além disso, você pode aplicar estilização comum com facilidade (sem condições).


Vamos definir os nossos estilos:

```ts
public ngOnInit() {

        { field: 'CountryName' }
    ];

    this.applyCSS();
}

public applyCSS() {

}

public updateCSS(css: string) {
    this.oddColStyles = {...this.oddColStyles, ...JSON.parse(css)};
    this.evenColStyles = {...this.evenColStyles, ...JSON.parse(css)};
    this.applyCSS();
}
```

## Problemas conhecidos e limitações

- Se houver células vinculadas à mesma condição (de colunas diferentes) e uma célula for atualizada, as outras células não serão atualizadas com base no novo valor, se a condição for atendida.

<PlatformBlock for="Angular, WebComponents">
Deve-se fazer uma verificação para aplicar as alterações às demais células. O exemplo abaixo mostra como fazer isso.

```ts
public backgroundClasses = {
    myBackground: (rowData: any, columnKey: string) => {
        return rowData.Col2 < 10;
    }
};

public editDone(evt) {
    this.Col1.cellClasses = {...this.backgroundClasses};
}
```

```html

  <igx-column field="Col2" dataType="number" [editable]="true" [cellClasses]="backgroundClasses"></igx-column>
```
