# Seleção de células do {Platform} {ComponentTitle}

A seleção de células do {ProductName} em {Platform} {ComponentTitle} oferece recursos avançados de seleção de dados e uma API poderosa no componente <ApiLink type="{ComponentName}" />. O {Platform} {ComponentTitle} oferece suporte a três modos de seleção:

- {ComponentTitle} Seleção de várias células
- {ComponentTitle} Seleção única
- {ComponentTitle} Sem seleção

<ComponentBlock for="HierarchicalGrid">
No <ApiLink type="{ComponentName}" />, você pode especificar o modo de seleção de células no nível da grade. Por exemplo, na grade pai pode ser habilitada a seleção de várias células, mas nas grades filhas o modo de seleção de células pode ser único ou desabilitado.
</ComponentBlock>

Vamos nos aprofundar em cada uma dessas opções.

## Tipos de seleção

### {ComponentTitle} Seleção de várias células

<ComponentBlock for="HierarchicalGrid">
Este é o modo de seleção de células padrão, tanto na grade pai quanto nas filhas. Tenha em mente que você pode fazer a seleção de células uma grade por vez, e não é possível fazer seleção de intervalo entre grades nem ter células selecionadas em várias grades. Cada combinação de teclas relacionada à seleção de intervalo e à funcionalidade de arrastar com o mouse só pode ser usada na mesma grade.
</ComponentBlock>

Como selecionar células:
- Com **arrastar com o mouse** - é realizada a seleção retangular de dados das células.
- Com a tecla <kbd>CTRL</kbd> pressionada + **arrastar com o mouse** - são realizadas seleções de múltiplos intervalos. Qualquer outra seleção de células existente será mantida.
- Seleção instantânea de várias células usando a tecla <kbd>SHIFT</kbd>. Selecione uma célula e, em seguida, selecione outra célula mantendo a tecla <kbd>SHIFT</kbd> pressionada. O intervalo de células entre as duas será selecionado. Tenha em mente que, se uma segunda célula for selecionada enquanto a tecla <kbd>SHIFT</kbd> estiver pressionada, o intervalo de seleção será atualizado com base na posição da primeira célula selecionada (ponto de partida).
- Seleção de várias células pelo teclado, usando as teclas de <kbd>seta</kbd> enquanto a tecla <kbd>SHIFT</kbd> está pressionada. O intervalo de seleção de várias células será criado com base na célula em foco.
- Seleção de várias células pelo teclado, usando as teclas <kbd>CTRL</kbd> + <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> e <kbd>CTRL</kbd> + <kbd>HOME</kbd>/<kbd>END</kbd> enquanto a tecla <kbd>SHIFT</kbd> está pressionada. O intervalo de seleção de várias células será criado com base na célula em foco.
- Clicar com o botão **esquerdo do mouse** enquanto a tecla <kbd>CTRL</kbd> está pressionada adiciona intervalos de uma única célula à coleção de células selecionadas.
- A seleção contínua de várias células está disponível, clicando com o mouse e arrastando.

### {ComponentTitle} Seleção única

Quando você define <ApiLink type="{ComponentName}" member="cellSelection" /> como **single**, passa a ser possível ter apenas uma célula selecionada na grade por vez. Além disso, o modo **arrastar com o mouse** não funciona, e em vez de selecionar uma célula, faz a seleção de texto padrão.

> Quando uma única célula é selecionada, o evento <ApiLink type="Column" member="selected" /> é emitido, independentemente de o **modo de seleção** ser **single** ou **multiple**. No modo de seleção de várias células, quando você seleciona um intervalo de células, o evento <ApiLink type="{ComponentName}" member="rangeSelected" /> é emitido.

### {ComponentTitle} Sem seleção

Se você quiser desabilitar a seleção de células, basta definir <ApiLink type="{ComponentName}" member="cellSelection" /> como **none**. Nesse modo, ao clicar sobre a célula ou navegar com o teclado, a célula **não é selecionada**; apenas o **estilo de ativação** é aplicado, e ele se perde quando você rola a página ou clica em outro elemento. A única forma de definir a seleção é usando os métodos da API descritos abaixo.

## Interações de navegação pelo teclado

### Enquanto a tecla Shift está pressionada

- <kbd>SHIFT</kbd> + <kbd>↑</kbd> para adicionar a célula acima à seleção atual.
- <kbd>SHIFT</kbd> + <kbd>↓</kbd> para adicionar a célula abaixo à seleção atual.
- <kbd>SHIFT</kbd> + <kbd>←</kbd> para adicionar a célula à esquerda à seleção atual.
- <kbd>SHIFT</kbd> + <kbd>→</kbd> para adicionar a célula à direita à seleção atual.

### Enquanto as teclas Ctrl + Shift estão pressionadas

- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>↑</kbd> para selecionar todas as células acima da célula em foco na coluna.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>↓</kbd> para selecionar todas as células abaixo da célula em foco na coluna.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>←</kbd> para selecionar todas as células até o início da linha.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>→</kbd> para selecionar todas as células até o fim da linha.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>HOME</kbd> para selecionar todas as células, da célula em foco até a primeira célula da grade
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>END</kbd> para selecionar todas as células, da célula em foco até a última célula da grade

<DocsAside type="info">
A rolagem contínua só é possível dentro do corpo do Grid.
</DocsAside>

## Uso da API

A seguir estão os métodos que você pode usar para selecionar intervalos, limpar a seleção ou obter os dados das células selecionadas.

### Selecionar intervalo

<ApiLink type="{ComponentName}" member="selectRange" /> - seleciona um intervalo de células com a API. rowStart e rowEnd devem usar índices de linha, e columnStart e columnEnd podem usar índice de coluna ou o valor do campo de dados da coluna.

<PlatformBlock for="WebComponents">
```ts
const range = { rowStart: 2, rowEnd: 2, columnStart: 1, columnEnd: 1 };
this.grid.selectRange(range);
```
</PlatformBlock>

```tsx
gridRef.current.selectRange(range)
```
</PlatformBlock>
</ComponentBlock>

### Obter os dados selecionados

<PlatformBlock for="Blazor">
<ApiLink type="{ComponentName}" member="getSelectedData" /> retorna um array dos dados selecionados no formato Dictionary. Exemplos abaixo:

```razor
<{ComponentSelector} @ref=grid  CellSelection="GridSelectionMode.Multiple" AutoGenerate=true></<{ComponentSelector}>

@code {
    private {ComponentSelector} grid;

    private async void GetSelectedData()
    {
        object[] data = await this.grid.GetSelectedDataAsync(true, true);
    }
}
```

</PlatformBlock>

<PlatformBlock for="Angular, WebComponents, React">
<ApiLink type="{ComponentName}" member="getSelectedData" /> retornará um array dos dados selecionados, em um formato que depende da seleção. Exemplos abaixo:

- Se três células individuais diferentes forem selecionadas:

```typescript
expectedData = [
    { CompanyName: 'Infragistics' },
    { Name: 'Michael Langdon' },
    { ParentID: 147 }

```

- Se três células de uma mesma coluna forem selecionadas:

```typescript
expectedData = [
    { Address: 'Obere Str. 57'},
    { Address: 'Avda. de la Constitución 2222'},
    { Address: 'Mataderos 2312'}
];
```

- Se três células forem selecionadas com arrastar o mouse, em uma linha e três colunas:

```typescript
expectedData = [
    { Address: 'Avda. de la Constitución 2222', City: 'México D.F.', ContactTitle: 'Owner' }
];
```

- Se três células forem selecionadas com arrastar o mouse, em duas linhas e três colunas:

```typescript
expectedData = [
    { ContactTitle: 'Sales Agent', Address: 'Cerrito 333', City: 'Buenos Aires'},
    { ContactTitle: 'Marketing Manager', Address: 'Sierras de Granada 9993', City: 'México D.F.'}
```

- Se dois intervalos sobrepostos forem selecionados, o formato será:


## Integração de recursos

A seleção de várias células é baseada em índices (seleção de elementos DOM).

- <ApiLink type="{ComponentName}" member="sortingExpressions" label="Sorting" /> - Quando a ordenação é realizada, a seleção não é limpa. As células selecionadas no momento permanecem as mesmas durante a ordenação crescente ou decrescente.
- <ApiLink type="{ComponentName}" member="pagingMode" label="Paging" /> - Na paginação, as células selecionadas serão limpas. A seleção não é mantida entre as páginas.
- <ApiLink type="{ComponentName}" member="allowFiltering" label="Filtering" /> - Quando a filtragem é realizada, a seleção não é limpa. Se a filtragem for removida, retornará às células inicialmente selecionadas.
- <ApiLink type="Column" member="resizable" label="Resizing" /> - No redimensionamento de colunas, as células selecionadas não serão limpas.
- <ApiLink type="Column" member="hidden" label="Hiding" /> - Não limpa as células selecionadas. Se a coluna for ocultada, as células da próxima coluna visível serão selecionadas.
- <ApiLink type="{ComponentName}" member="pinning" /> - A célula selecionada não será limpa. Igual à ocultação
- <ApiLink type="{ComponentName}" member="groupingExpressions" label="GroupBy" /> - No agrupamento de colunas, as células selecionadas não serão limpas.

## Diretrizes de estilização

O mecanismo de temas expõe propriedades que permitem estilizar o **intervalo de células selecionadas**.

### Importar o tema

Para começar a estilizar a seleção, precisamos importar o arquivo `index`, onde ficam todas as funções de tema e os mixins dos componentes:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### Definir as cores

Depois disso, podemos usar as funções <ApiLink type="function-igx-contrast-color" label="igx-contrast-color" kind="sass" module="index.html" /> e <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />. Com elas, definimos as cores que queremos usar para o intervalo de seleção:

```scss
    $text-color:contrast-color($default-palette, 'primary', 900);
    $background-color: color($default-palette, "primary", 900);
    $border-yellow: #f2c43c;
```

### Criar um tema personalizado

Em seguida, criamos um novo tema que estende o <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" />, passando as nossas variáveis `text-color`, `background-color` e `border-yellow` como `$cell-selected-text-color`, `$cell-selected-background` e `$cell-active-border-color`, respectivamente:

```scss
$custom-grid-theme: grid-theme(
    $cell-selected-text-color: $text-color,
    $cell-active-border-color: $border-yellow,
    $cell-selected-background: $background-color
);
```

### Aplicar o tema

Depois disso, basta incluir o mixin no estilo do nosso componente (também pode ser nos estilos do aplicativo), para que o @@igSelector use o tema recém-criado em vez do padrão:

```scss
    @include grid($custom-grid-theme);
```

 <DocsAside type="info">
 Se o componente estiver usando um [ViewEncapsulation Emulated](../themes/styles.mdx#view-encapsulation), é necessário atravessar esse encapsulamento usando `::ng-deep`.
 Limitamos o estilo sob o seletor `:host`, para não afetar outras grades que possamos ter no aplicativo.
 </DocsAside>

 ```scss
    :host {
        ::ng-deep {
            @include grid($custom-grid-theme);
        }
    }
```


Com o tema personalizado aplicado, as células selecionadas do grid são destacadas com as nossas cores de seleção:
