# Filtro de pesquisa do {Platform} {ComponentTitle}

O recurso de Filtro de pesquisa do {ProductName} em {Platform} {ComponentTitle} permite localizar valores na coleção de dados. Facilitamos a configuração dessa funcionalidade, que pode ser implementada com uma caixa de pesquisa, botões, navegação por teclado e outros recursos úteis para uma experiência de usuário ainda melhor. Embora os navegadores ofereçam nativamente a funcionalidade de pesquisa de conteúdo, na maioria das vezes a <ApiLink type="{ComponentName}" /> virtualiza as colunas e linhas que estão fora da área visível. Nesses casos, a pesquisa nativa do navegador não consegue pesquisar os dados das células virtualizadas, já que elas não fazem parte do DOM. Estendemos a grade baseada na tabela Material da {Platform} com uma **API de pesquisa** que permite pesquisar no **conteúdo virtualizado** do <ApiLink type="{ComponentName}" />.

Os métodos `FindNext` e `FindPrev` têm três argumentos:

- `Text`: **string** (o texto que estamos procurando)
- (opcional) <PlatformBlock for="Angular"><ApiLink type="ISearchInfo" member="caseSensitive" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="SearchInfo" member="caseSensitive" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="SearchInfo" member="caseSensitive" /></PlatformBlock>: **boolean** (a pesquisa deve diferenciar maiúsculas de minúsculas ou não; o valor padrão é false)
- (opcional) <PlatformBlock for="Angular"><ApiLink type="ISearchInfo" member="exactMatch" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="SearchInfo" member="exactMatch" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="SearchInfo" member="exactMatch" /></PlatformBlock>: **boolean** (a pesquisa deve ser por correspondência exata ou não; o valor padrão é false)

Ao pesquisar por correspondência exata, a API de pesquisa destacará como resultados apenas os valores de célula que correspondem integralmente ao <ApiLink type="{ComponentName}" member="findNext" />, levando também em conta a diferenciação de maiúsculas e minúsculas. Por exemplo, as strings '_software_' e '_Software_' são uma correspondência exata quando a diferenciação de maiúsculas e minúsculas é ignorada.

Os métodos acima retornam um valor **number** (a quantidade de vezes que o <ApiLink type="{ComponentName}" /> contém a string informada).

### Exibir a quantidade de resultados

Vamos exibir também a posição da ocorrência atual, junto com a contagem total de resultados! Podemos fazer isso usando a propriedade do grid <ApiLink type="{ComponentName}" member="lastSearchInfo" />. Essa propriedade é atualizada automaticamente ao usar os métodos **find**.

- O valor `LastSearchInfo.MatchInfoCache.Length` da grade nos dará a quantidade total de resultados.

### Adicionar pesquisa por teclado

Também podemos permitir que os usuários naveguem pelos resultados usando as teclas de seta do teclado e a tecla <kbd>ENTER</kbd>. Para isso, podemos tratar o evento **keydown** do nosso input de pesquisa, impedindo a movimentação padrão do cursor do input com o método `PreventDefault`, e invocar os métodos `FindNext`/`FindPrev` de acordo com a tecla pressionada pelo usuário.

<PlatformBlock for="Angular">
```html
<input #search1 id="search1" placeholder="Search" [(ngModel)]="searchText" (ngModelChange)="@@igObjectRef.findNext(searchText, caseSensitive, exactMatch)"
       (keydown)="searchKeyDown($event)" />
```

```typescript
public searchKeyDown(ev) {
    if (ev.key === 'Enter') {
        ev.preventDefault();
        this.@@igObjectRef.findNext(this.searchText, this.caseSensitive, this.exactMatch);
    } else if (ev.key === 'ArrowUp' || ev.key === 'ArrowLeft') {
        ev.preventDefault();
        this.@@igObjectRef.findPrev(this.searchText, this.caseSensitive, this.exactMatch);
    }
}
```

</PlatformBlock>

### Persistência

E se quisermos filtrar e ordenar nosso <ApiLink type="{ComponentName}" /> ou até adicionar e remover registros? Depois dessas operações, os destaques da nossa pesquisa atual são atualizados automaticamente e se mantêm sobre qualquer texto que corresponda ao <ApiLink type="{ComponentName}" member="findNext" />! Além disso, a pesquisa funcionará com a paginação e manterá os destaques ao longo das alterações da propriedade `PerPage` do <ApiLink type="{ComponentName}" />.

## Limitações conhecidas


|Limitação|Descrição|
|--- |--- |
|Pesquisando em células com template|Os realces da funcionalidade de pesquisa funcionam somente para os templates de célula padrão. Se você tiver uma coluna com template de célula personalizado, os realces não funcionarão; por isso, deve usar abordagens alternativas, como um formatador de coluna, ou definir a propriedade <ApiLink type="Column" member="searchable" label="Searchable" /> da coluna como false.|
|Virtualização remota| A pesquisa não funcionará corretamente ao usar virtualização remota|
|Células com texto cortado| Quando o texto da célula é grande demais para caber e o texto procurado é cortado pelas reticências, ainda rolaremos até a célula e a incluiremos na contagem de correspondências, mas nada será realçado |
