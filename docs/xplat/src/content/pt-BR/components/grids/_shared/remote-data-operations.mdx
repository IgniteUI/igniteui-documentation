## Virtualização remota

## Rolagem infinita

 Um padrão popular para cenários que exigem buscar dados em blocos a partir de um endpoint é a chamada rolagem infinita. Para grids de dados, ela se caracteriza pelo aumento contínuo dos dados carregados, disparado pelo usuário final ao rolar até o fim. Os próximos parágrafos explicam como você pode usar a API disponível para obter facilmente a rolagem infinita no <ApiLink type="{ComponentName}" />.

Para implementar a rolagem infinita, você precisa buscar os dados em blocos. Os dados já buscados devem ser armazenados localmente, e você precisa determinar o tamanho de um bloco e quantos blocos existem. Também precisa acompanhar o índice da última linha de dados visível no grid. Dessa forma, usando as propriedades <ApiLink type="ForOfState" member="chunkSize" /> e <ApiLink type="ForOfState" member="chunkSize" />, você pode determinar se o usuário está rolando para cima, e precisa mostrar dados já buscados, ou se está rolando para baixo, e você precisa buscar mais dados do endpoint.




A primeira coisa a fazer é buscar o primeiro bloco de dados. Definir a propriedade <ApiLink type="{ComponentName}" member="totalItemCount" /> é importante, pois permite que a grade dimensione corretamente sua barra de rolagem.

<PlatformBlock for="Angular">
```typescript
public ngAfterViewInit() {
    this._remoteService.loadDataForPage(this.page, this.pageSize, (request) => {
        if (request.data) {
            this.grid.totalItemCount = this.page * this.pageSize;
            this.grid.data = this._remoteService.getCachedData({startIndex: 0, chunkSize: 10});
            this.totalItems = request.data['@odata.count'];
            this.totalPageCount = Math.ceil(this.totalItems / this.pageSize);
            this.grid.isLoading = false;
        }
    });
}
```

```typescript
public handlePreLoad() {
    const isLastChunk = this.grid.totalItemCount ===
                        this.grid.virtualizationState.startIndex + this.grid.virtualizationState.chunkSize;
    // when last chunk reached load another page of data
    if (isLastChunk) {
        if (this.totalPageCount === this.page) {
            this.grid.data = this._remoteService.getCachedData(this.grid.virtualizationState);
```

## Ordenação/filtragem remota

Para fornecer ordenação e filtragem remotas, você precisa se inscrever nas saídas <ApiLink type="{ComponentName}" member="dataPreLoad" />, <ApiLink type="{ComponentName}" member="sortingExpressionsChange" /> e <ApiLink type="{ComponentName}" member="filteringExpressionsTreeChange" />, para fazer a requisição apropriada com base nos argumentos recebidos, além de definir a propriedade pública <ApiLink type="{ComponentName}" /> <ApiLink type="{ComponentName}" member="totalItemCount" /> com as informações correspondentes vindas do serviço.

Também vamos aproveitar a função **rxjs** `debounceTime`, que emite um valor do Observable de origem somente depois que determinado intervalo de tempo passou sem outra emissão da origem. Assim, a operação remota só será disparada quando o tempo especificado tiver passado sem que o usuário a interrompa.

```typescript
const DEBOUNCE_TIME = 300;
public ngAfterViewInit() {
    this.grid.dataPreLoad.pipe(
        debounceTime(DEBOUNCE_TIME),
        takeUntil(this.destroy$)
    ).subscribe(() => {
        this.processData();
    });

    this.grid.filteringExpressionsTreeChange.pipe(
        debounceTime(DEBOUNCE_TIME),
        takeUntil(this.destroy$)
    ).subscribe(() => {
        this.processData(true);
    });

    this.grid.sortingExpressionsChange.pipe(
        debounceTime(DEBOUNCE_TIME),
        takeUntil(this.destroy$)
    ).subscribe(() => {
        this.processData();
    });
}
```

## Estratégia de valores exclusivos da coluna

Os itens da lista dentro da caixa de diálogo de filtragem estilo Excel representam os valores exclusivos da respectiva coluna. Por padrão, o <ApiLink type="{ComponentName}" /> gera esses valores com base na sua fonte de dados. No caso de filtragem remota, os dados do grid não contêm todos os dados do servidor. Para fornecer os valores exclusivos manualmente e carregá-los sob demanda, podemos aproveitar a entrada <ApiLink type="{ComponentName}" /> do <ApiLink type="{ComponentName}" member="uniqueColumnValuesStrategy" label="UniqueColumnValuesStrategy" />. Essa entrada é, na prática, um método que recebe três argumentos:

- <ApiLink type="Column" />  - A instância da coluna correspondente.
- <ApiLink type="FilteringExpressionsTree" /> - A árvore de expressões de filtragem, reduzida com base na coluna correspondente.
- `Done` - Callback que deve ser chamado com os novos valores da coluna quando eles forem obtidos do servidor.

O desenvolvedor pode gerar manualmente os valores únicos necessários da coluna com base nas informações fornecidas pelos argumentos <ApiLink type="Column" /> e <ApiLink type="FilteringExpressionsTree" /> e, em seguida, invocar o callback `Done`.

<DocsAside type="info">
Quando a entrada `UniqueColumnValuesStrategy` é fornecida, o processo padrão de geração de valores exclusivos na filtragem estilo Excel não será usado.
</DocsAside>

## Paginação remota

<ComponentBlock for="Grid">
O recurso de paginação pode operar com dados remotos. Para demonstrar isso, primeiro vamos declarar o nosso serviço, responsável pela obtenção dos dados. Precisaremos da contagem de todos os itens de dados para calcular a quantidade de páginas. Essa lógica será adicionada ao nosso serviço.

<PlatformBlock for="Angular">
```typescript
@Injectable()
export class RemotePagingService {
    public remoteData: BehaviorSubject<any[]>;
    public dataLenght: BehaviorSubject<number> = new BehaviorSubject(0);
    public url = 'https://www.igniteui.com/api/products';

    constructor(private http: HttpClient) {
        this.remoteData = new BehaviorSubject([]) as any;
    }

    public getData(index?: number, perPage?: number): any {
        let qS = '';

        if (perPage) {
            qS = `?$skip=${index}&$top=${perPage}&$count=true`;
        }

        this.http
            .get(`${this.url + qS}`).pipe(
                map((data: any) => data)
            ).subscribe((data) => this.remoteData.next(data));
    }

    public getDataLength(): any {
        return this.http.get(this.url).pipe(
            map((data: any) => data.length)
        );
    }
}

```

```ts
export class RemotePagingService {
    public static CUSTOMERS_URL = `https://data-northwind.indigo.design/Customers/GetCustomersWithPage`;
    constructor() {}

    public static getDataWithPaging(pageIndex?: number, pageSize?: number) {
        return fetch(RemotePagingService.buildUrl(RemotePagingService.CUSTOMERS_URL, pageIndex, pageSize))
        .then((result) => result.json())
        .catch((error) => console.error(error.message));
    }

    private static buildUrl(baseUrl: string, pageIndex?: number, pageSize?: number) {
        let qS = "";
        if (baseUrl) {
                qS += `${baseUrl}`;
        }

        // Add pageIndex and size to the query string if they are defined
        if (pageIndex !== undefined) {
            qS += `?pageIndex=${pageIndex}`;
            if (pageSize !== undefined) {
                qS += `&size=${pageSize}`;
            }
        } else if (pageSize !== undefined) {
            qS += `?perPage=${pageSize}`;
        }

        return `${qS}`;
    }
}
```

O recurso de paginação pode operar com dados remotos. Para demonstrar isso, primeiro vamos declarar o nosso serviço, responsável pela obtenção dos dados. Precisaremos da contagem de todos os itens de dados para calcular a quantidade de páginas. Essa lógica será adicionada ao nosso serviço.


```typescript
@Injectable()
export class RemotePagingService {
    public remoteData: BehaviorSubject<any[]>;
    public dataLenght: BehaviorSubject<number> = new BehaviorSubject(0);
    public url = 'https://www.igniteui.com/api/products';

    constructor(private http: HttpClient) {
        this.remoteData = new BehaviorSubject([]) as any;
    }

    public getData(index?: number, perPage?: number): any {
        let qS = '';

        if (perPage) {
            qS = `?$skip=${index}&$top=${perPage}&$count=true`;
        }

        this.http
            .get(`${this.url + qS}`).pipe(
                map((data: any) => data)
            ).subscribe((data) => this.remoteData.next(data));
    }

    public getDataLength(): any {
        return this.http.get(this.url).pipe(
            map((data: any) => data.length)
        );
    }
}
```

```ts
            if (pageSize !== undefined) {
                qS += `&size=${pageSize}`;

            qS += `?perPage=${pageSize}`;
```

### Paginação remota com template padrão

Se quiser usar o template de paginação padrão, você precisa definir a propriedade <ApiLink type="GridBaseDirective" member="totalRecords" label="TotalRecords" /> do Paginator; só assim a grade poderá calcular o número total de páginas com base no total de registros remotos. Ao realizar uma paginação remota, o Paginator passará à grade apenas os dados da página atual, então a grade não tentará paginar a fonte de dados fornecida. Por isso, devemos definir a propriedade <ApiLink type="GridBaseDirective" member="pagingMode" label="PagingMode" /> da grade como <ApiLink type="GridPagingMode" member="Remote" label="GridPagingMode.Remote" />. Também é necessário assinar os eventos `PagingDone` ou `PerPageChange` para buscar os dados do seu serviço remoto; qual deles usar depende do caso de uso.

A seguir, os métodos que definimos para implementar as nossas próprias ações de página `next` e `previous`.

```typescript
@ViewChild('grid1', { static: true }) public grid1: IgxGridComponent;

public ngAfterViewInit() {
    this.grid1.isLoading = true;
    this.remoteService.getData(0, this.perPage);
}

public nextPage() {
    this.firstPage = false;
    this.page++;
    const skip = this.page * this.perPage;
    const top = this.perPage;
    this.remoteService.getData(skip, top);
    if (this.page + 1 >= this.totalPages) {
        this.lastPage = true;
    }
    this.setNumberOfPagingItems(this.page, this.totalPages);
}

public previousPage() {
    this.lastPage = false;
    this.page--;
    const skip = this.page * this.perPage;
    const top = this.perPage;
    this.remoteService.getData(skip, top);
    if (this.page <= 0) {
        this.firstPage = true;
    }
    this.setNumberOfPagingItems(this.page, this.totalPages);
}

public paginate(page: number, recalculate = false) {
    this.page = page;
    const skip = this.page * this.perPage;
    const top = this.perPage;
    if (recalculate) {
        this.totalPages = Math.ceil(this.totalCount / this.perPage);
    }
    this.setNumberOfPagingItems(this.page, this.totalPages);
    this.remoteService.getData(skip, top);
    this.buttonDeselection(this.page, this.totalPages);
}
```

### Paginação remota com edição em lote

Com os exemplos até aqui, esclarecemos como configurar o <ApiLink type="{ComponentName}" /> com dados remotos. Agora, vamos focar em habilitar a edição em lote no grid, seguindo o [tópico/guia de Edição em Lote](batch-editing.mdx).

Antes de continuar com o exemplo, vale esclarecer o caso de uso atual. Quando a paginação é feita no servidor, o grid contém apenas os dados da página atual; se adicionarmos novas linhas, as linhas recém-adicionadas (com Edição em Lote) serão concatenadas com os dados atuais do grid. Portanto, se o servidor não retornar dados para determinada página, a fonte de dados do grid será composta somente pelas linhas recém-adicionadas, que o grid paginará com base nas configurações de paginação definidas (page, perPage).

Para tratar corretamente esse caso de uso, precisamos implementar uma lógica personalizada.

Primeiro, precisamos saber o número total de registros que estão no servidor. Com base nisso, calculamos o número total de páginas de dados no servidor e, a partir desse valor, implementaremos a lógica de paginação personalizada.

```typescript
public paginate(page: number) {
    this.grid1.endEdit(true);
    if (page > this._totalPagesOnServer) {
        if (this.page !== this._totalPagesOnServer) {
            const skipEl = this._totalPagesOnServer * this.perPage;
            this.remoteService.getData(skipEl, this.perPage);
        }
        this.page = page - this._totalPagesOnServer;
        this.page = page;
        return;
    } else {
        this.page = 0;
    }
    this.page = page;
    const skip = this.page * this.perPage;
    this.remoteService.getData(skip, this.perPage);
}
```
