# Navegação por teclado do {Platform} {ComponentTitle}

 O recurso de Navegação por teclado de {ProductName} em {Platform} {ComponentTitle} oferece uma grande variedade de interações por teclado para o usuário. Ele aumenta a acessibilidade do <ApiLink type="{ComponentName}" /> e permite que o usuário navegue por qualquer tipo de elemento interno (célula, linha, cabeçalho de coluna, barra de ferramentas, rodapé etc.). Esse recurso vem ativado por padrão, e o desenvolvedor tem a opção de substituir qualquer um dos comportamentos padrão de forma simples.

A quantidade de paradas de tabulação do <ApiLink type="{ComponentName}" /> foi reduzida, para que a navegação esteja em conformidade com os padrões de acessibilidade W3C e seja prática de usar.

Atualmente, o <ApiLink type="{ComponentName}" /> introduz as seguintes paradas de tabulação:

- **Área de GroupBy ou da barra de ferramentas** (se ativada).
- **Cabeçalho de {ComponentTitle}**.
- **Corpo de {ComponentTitle}**.
- **Resumos de coluna** (se ativados).
- **Paginador de {ComponentTitle}** (se ativado).


<DocsAside type="info">
Devido a essa mudança, a navegação entre células com <kbd>TAB</kbd> e <kbd>SHIFT</kbd> + <kbd>TAB</kbd> não é mais suportada no <ApiLink type="{ComponentName}" />.
Ao pressionar a tecla <kbd>TAB</kbd>, os pontos de parada de tabulação agora seguem esta ordem: **GroupBy** / **Barra de ferramentas** -> **Cabeçalhos** -> **Corpo** -> **Resumos** -> **Rodapé / Paginador**.
</DocsAside>

<DocsAside type="info">
Expor qualquer elemento **focável** no corpo de <ApiLink type="{ComponentName}" /> por meio de template pode introduzir **efeitos colaterais** na navegação por teclado, já que o comportamento padrão do navegador não é impedido.
É responsabilidade do desenvolvedor impedir ou modificar isso de forma adequada.
</DocsAside>

## Navegação pelo cabeçalho

Agora há suporte completo de **navegação por teclado** no cabeçalho de <ApiLink type="{ComponentName}" />. Os cabeçalhos de coluna podem ser percorridos facilmente com as setas do teclado. Além disso, há várias combinações de teclas que disparam ações nas colunas, como **filtragem**, **ordenação**, **agrupamento** etc.
Quando o contêiner do cabeçalho de <ApiLink type="{ComponentName}" /> estiver com foco, as seguintes combinações de teclas estarão disponíveis:

### Combinações de teclas

- <kbd>↑</kbd> navega uma célula para cima nos cabeçalhos (sem repetição). Disponível somente quando o Multi-row Layout (MRL) ou os Multi-column Headers (MCH) estão definidos.
- <kbd>↓</kbd> navega uma célula para baixo nos cabeçalhos (sem quebra). Disponível somente quando o Multi-row Layout (MRL) ou os Multi-column Headers (MCH) estão definidos.
- <kbd>←</kbd> navega uma célula para a esquerda (sem repetição).
- <kbd>→</kbd> navega uma célula para a direita (sem quebra entre linhas).
- <kbd>CTRL</kbd> + <kbd>←</kbd> navega até a célula mais à esquerda da linha; se MRL ou MCH estiverem ativados, navega até a célula mais à esquerda no mesmo nível.
- <kbd>HOME</kbd> navega até a célula mais à esquerda da linha; se MRL ou MCH estiverem ativados, navega até a célula mais à esquerda no mesmo nível.
- <kbd>CTRL</kbd> + <kbd>→</kbd> navega até a célula mais à direita da linha; se MRL ou MCH estiverem ativados, navega até a célula mais à direita no mesmo nível.
- <kbd>END</kbd> navega até a célula mais à direita da linha; se MRL ou MCH estiverem ativados, navega até a célula mais à direita no mesmo nível.
- <kbd>ALT</kbd> + <kbd>L</kbd> abre o diálogo de Filtragem avançada, se a Filtragem avançada estiver ativada.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>L</kbd> abre o diálogo de Filtragem estilo Excel ou o filtro padrão (de linha), se a coluna for filtrável.
- <kbd>CTRL</kbd> + <kbd>↑</kbd> ordena o cabeçalho de coluna ativo em ordem ASC. Se a coluna já estiver ordenada em ASC, o estado de ordenação é limpo.
- <kbd>CTRL</kbd> + <kbd>↓</kbd> ordena o cabeçalho de coluna ativo em ordem DSC. Se a coluna já estiver ordenada em DSC, o estado de ordenação é limpo.
- <kbd>SPACE</kbd> seleciona a coluna. Se a coluna já estiver selecionada, a seleção é limpa.
<ComponentBlock for="Grid">
- <kbd>SHIFT</kbd> + <kbd>ALT</kbd> + <kbd>←</kbd> agrupa a coluna, se ela estiver marcada como agrupável.
</ComponentBlock>
- <kbd>SHIFT</kbd> + <kbd>ALT</kbd> + <kbd>→</kbd> desagrupa a coluna, se ela estiver marcada como agrupável.
- <kbd>ALT</kbd> + <kbd>←</kbd> ou <kbd>ALT</kbd> + <kbd>↑</kbd> recolhe o cabeçalho do grupo de colunas, se ele já não estiver recolhido.
- <kbd>ALT</kbd> + <kbd>→</kbd> ou <kbd>ALT</kbd> + <kbd>↓</kbd> expande o cabeçalho do grupo de colunas, se ele já não estiver expandido.

## Navegação por teclado personalizada

Sobrescrever o comportamento padrão para uma tecla ou combinação de teclas é um dos benefícios que o recurso de **Navegação por teclado** oferece. Por exemplo: pressione a tecla <kbd>ENTER</kbd> ou <kbd>TAB</kbd> para navegar até a próxima célula ou a célula abaixo. Esse cenário, ou qualquer outro cenário de navegação, é facilmente obtido pela API de **Navegação por teclado**:

<PlatformBlock for="Blazor">
| API | Descrição | Argumentos |

| <ApiLink type="{ComponentName}" member="gridKeydown" /> | Um evento emitido quando qualquer uma das teclas/combinações de teclas descritas acima é pressionada. Pode ser cancelado. Para qualquer outra tecla/combinação de teclas, use o evento padrão `onkeydown`. | <ApiLink type="GridKeydownEventArgs" /> |
| <ApiLink type="{ComponentName}" member="activeNodeChange" /> | Um evento emitido quando o nó ativo é alterado. Você pode usá-lo para determinar a posição de foco ativa (cabeçalho, tbody etc.), o índice da coluna, o índice da linha ou o nível aninhado. | <ApiLink type="ActiveNodeChangeEventArgs" /> |
</PlatformBlock>
