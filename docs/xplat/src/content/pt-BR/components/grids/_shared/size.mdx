# Tamanho do {Platform} {ComponentTitle}

O recurso de Tamanho do {ProductName} em {Platform} {ComponentTitle} permite controlar o espaçamento e o layout dos dados dentro da <ApiLink type="{ComponentName}" />. Ao alterar `--ig-size`, você pode melhorar significativamente a experiência do usuário ao interagir com grandes quantidades de conteúdo. Eles podem escolher entre três opções de tamanho:
- `--ig-size-large`
- `--ig-size-medium`
- `--ig-size-small`

## Exemplo de tamanho do {Platform} {ComponentTitle}

<Sample src="/{ComponentSample}/layout-display-density" height={620} alt="Exemplo de tamanho do {Platform} {ComponentTitle}" />



## Uso

Como você pode ver na demo acima, o <ApiLink type="{ComponentName}" /> oferece três opções de tamanho: **small**, **medium** e **large**. O trecho de código abaixo mostra como definir `--ig-size` diretamente no elemento ou como parte de uma classe CSS:

```css
.gridSize {
    --ig-size: var(--ig-size-medium);
}
```

E agora vamos ver em detalhes como cada opção se reflete no componente <ApiLink type="{ComponentName}" />. Ao alternar entre as diferentes opções de tamanho, a altura de cada elemento <ApiLink type="{ComponentName}" /> e os respectivos paddings serão alterados. Além disso, se quiser aplicar uma <ApiLink type="{ComponentName}" member="width" /> de coluna personalizada, lembre-se de que ela deve ser maior que a soma dos paddings esquerdo e direito:

- **large** - este é o tamanho padrão de <ApiLink type="{ComponentName}" />, com a menor intensidade e altura de linha igual a `50px`. Os paddings esquerdo e direito são `24px`; a <ApiLink type="{ComponentName}" member="width" /> mínima da coluna é `80px`;
- **medium** - este é o tamanho de intensidade média, com altura de linha `40px`. Os paddings esquerdo e direito são `16px`; a <ApiLink type="{ComponentName}" member="width" /> mínima da coluna é `64px`;
- **small** - este é o tamanho de maior intensidade, com altura de linha `32px`. Os paddings esquerdo e direito são `12px`; a <ApiLink type="{ComponentName}" member="width" /> mínima da coluna é `56px`;

<DocsAside type="info">
Tenha em mente que, atualmente, você **não pode** substituir nenhum dos tamanhos.
</DocsAside>

Outra opção que o <ApiLink type="{ComponentName}" /> oferece para alterar a altura das linhas na <ApiLink type="{ComponentName}" /> é a propriedade <ApiLink type="{ComponentName}" member="rowHeight" />. Então vamos ver em ação como essa propriedade afeta o layout da <ApiLink type="{ComponentName}" /> junto com o `--ig-size`.

Tenha em mente o seguinte:

- A variável CSS `--ig-size` não terá impacto na altura da linha **se houver <ApiLink type="{ComponentName}" member="rowHeight" /> especificado**.
- `--ig-size` **afetará todos os demais elementos da {ComponentTitle}**, conforme descrito acima.

Agora podemos estender nosso exemplo e adicionar a propriedade <ApiLink type="{ComponentName}" member="rowHeight" /> à <ApiLink type="{ComponentName}" />:
