# {Platform}  {ComponentTitle} Visão geral do redimensionamento de colunas

O recurso de redimensionamento de colunas do {ProductName} em {Platform} {ComponentTitle} permite que os usuários ajustem facilmente a largura das colunas da <ApiLink type="{ComponentName}" />. Por padrão, eles verão um indicador temporário de redimensionamento enquanto a operação de arrastar está em andamento. Há várias opções de redimensionamento disponíveis: redimensionar colunas em pixels/percentuais, restringir o redimensionamento de colunas, ajustar automaticamente as colunas com clique duplo e ajustar automaticamente as colunas na inicialização.

Por padrão, se uma coluna não tiver largura definida, ela ocupa o espaço disponível com a largura definida em pixels.

<DocsAside type="info">
Há uma pequena diferença na forma como o redimensionamento funciona para colunas definidas em pixels e em porcentagens.
</DocsAside>

**Pixels**

Redimensionar colunas com largura em pixels funciona adicionando ou subtraindo diretamente, do tamanho da coluna, a quantidade horizontal do movimento do mouse.

**Porcentagens**

Ao redimensionar colunas com largura em porcentagens, a quantidade horizontal do movimento do mouse em pixels se traduz, aproximadamente, na sua quantidade percentual em relação à largura do grid. As colunas permanecem responsivas, e qualquer redimensionamento futuro do grid ainda será refletido nas colunas.

## Ajustar automaticamente as colunas com clique duplo

Cada coluna pode ser **dimensionada automaticamente** com um clique duplo na borda direita do cabeçalho: a coluna será dimensionada para o valor de célula visível mais longo, incluindo o próprio cabeçalho. Esse comportamento vem habilitado por padrão, sem necessidade de configuração adicional. No entanto, a coluna não será dimensionada automaticamente se <ApiLink type="ColumnState" member="maxWidth" /> estiver definido nessa coluna e a nova largura exceder esse valor <ApiLink type="ColumnState" member="maxWidth" />. Nesse caso, a coluna será dimensionada de acordo com o valor predefinido de <ApiLink type="ColumnState" member="maxWidth" />.

Você também pode dimensionar uma coluna automaticamente de forma dinâmica, usando o método <ApiLink type="Column" member="autosize" /> exposto em <ApiLink type="Column" />.

## Estilização

Para começar a estilizar a linha de redimensionamento da coluna <ApiLink type="{ComponentName}" />, precisamos importar o arquivo de índice, onde ficam todas as funções de tema e os mixins dos componentes:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

A forma mais simples de conseguir isso é criar um novo tema que estenda o <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" /> e aceite vários parâmetros, além do parâmetro `$resize-line-color`.

```scss
$custom-grid-theme: grid-theme(
    $resize-line-color: #0288D1
);
```

 <DocsAside type="info">
 Se o componente estiver usando um ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), é necessário `penetrate` esse encapsulamento usando `::ng-deep`.
 </DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid($custom-grid-theme);
    }
}
```

### Definindo uma paleta de cores
Em vez de fixar os valores de cor no código, podemos obter mais flexibilidade em relação às cores usando as funções <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" /> e <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />.

`igx-palette` gera uma paleta de cores com base na cor primária e na secundária especificadas:

```scss
$primary-color: #0288D1;
$secondary-color: #BDBDBD;

$custom-theme-palette: palette($primary: $primary-color, $secondary: $secondary-color);
```

E então, com <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />, podemos obter facilmente a cor da paleta.

```scss
$custom-grid-theme: grid-theme(
    $palette: $custom-theme-palette,
    $resize-line-color: color($custom-theme-palette, 'secondary', 500)
);
```

<DocsAside type="info">
As funções `igx-color` e `igx-palette` são poderosas para gerar e obter cores. Consulte o tópico [Paletas](../themes/sass/palettes.mdx) para orientações detalhadas sobre como usá-las.
</DocsAside>

### Usando schemas
Indo além do mecanismo de temas, você pode criar uma estrutura robusta e flexível que se beneficia dos [**schemas**](../themes/sass/schemas.mdx). Um **schema** é uma receita de tema.

Estenda o schema predefinido fornecido para cada componente, neste caso - o schema <ApiLink type="variable-_light-grid" label="light-grid" kind="sass" module="index.html" />:

```scss
// Extending the light grid schema
$light-grid-schema: extend($_light-grid,
    (
        resize-line-color: (
           color: ('secondary', 500)
            ),
        header-background: (
           color: ("primary", 100)
            ),
        header-text-color: (
           color: ("primary", 600)
            )
    )
);
```

Para aplicar o nosso schema personalizado, precisamos **estender** um dos globais (<ApiLink type="variable-light-schema" label="light" kind="sass" module="index.html" /> ou <ApiLink type="variable-dark-schema" label="dark" kind="sass" module="index.html" />), o que basicamente indica os componentes com um schema personalizado, e depois adicioná-lo ao tema do respectivo componente:

```scss
// Extending the global light-schema
$custom-light-grid-schema: extend($light-schema,(
    igx-grid: $light-grid-schema
));

// Specifying the palette and schema of the custom grid theme
$custom-grid-theme: grid-theme(
    $palette: $custom-theme-palette,
    $schema: $custom-light-grid-schema
);
```

Não se esqueça de incluir o tema da mesma forma como foi demonstrado acima.
