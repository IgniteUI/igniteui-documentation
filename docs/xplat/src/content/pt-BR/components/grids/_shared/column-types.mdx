# {Platform} {ComponentTitle} Visão geral dos tipos de coluna

O {Platform} {ComponentTitle} oferece um tratamento padrão para os tipos de dados de coluna **number**, **string**, **date**, **boolean**, **currency** e **percent**, com base nos quais a aparência dos templates padrão e de edição será definida.

## Template padrão do {Platform} {ComponentTitle}

Se você quiser habilitar um template específico para o tipo de dado, deve definir a entrada <ApiLink type="Column" member="dataType" /> da coluna; caso contrário, a coluna será tratada como uma coluna de texto, pois esse é o valor padrão de <ApiLink type="Column" member="dataType" /> da coluna.

As seções a seguir descrevem os templates padrão de cada <ApiLink type="Column" member="dataType" />.

### String

Esta coluna <ApiLink type="Column" member="dataType" /> não altera a aparência nem o formato do valor da célula.

### Número

Se o <ApiLink type="Column" member="dataType" /> for definido como **number**, o valor da célula será formatado com base nas configurações de aplicação ou de <ApiLink pkg="core" type="DatePicker" member="locale" label="Locale" /> do grid, assim como quando a propriedade <ApiLink type="Column" member="pipeArgs" /> for especificada. Então, o formato numérico será alterado com base nelas; por exemplo, pode mudar:

- Número de dígitos após o ponto decimal
- Separador decimal com `,` ou `.`

### DateTime, Date e Time

A aparência das partes da data (por exemplo, dia, mês, ano) será definida com base no formato <ApiLink pkg="core" type="DatePicker" member="locale" label="Locale" /> ou na entrada <ApiLink type="Column" member="pipeArgs" />. Os argumentos do pipe podem ser usados para especificar um formato de data ou um fuso horário personalizado:

- **format** - o valor padrão para formatar a data é `'mediumDate'`. Outras opções disponíveis são `'short'`, `'long'`, `'shortDate'`, `'fullDate'`, `'longTime'`, `'fullTime'` e outras.
- **timezone** - O fuso horário local do sistema do usuário é o valor padrão. Também é possível passar o deslocamento de fuso horário, ou a abreviação padrão GMT/UTC ou de fuso horário continental dos EUA. Exemplos de fusos horários diferentes que exibirão o horário correspondente de qualquer lugar do mundo:

#### Edição de células

Quando se trata de edição de célula com base no tipo de coluna, um editor diferente aparecerá:
- `DateTime` - será usado <ApiLink pkg="core" type="DatePicker" />. Este editor fornecerá as orientações de máscara para os elementos de entrada que fazem parte do objeto `DateTime`.
- `Date` - será usado <ApiLink pkg="core" type="DatePicker" />.
- `Time` - será usado <ApiLink pkg="core" type="DateTimeInput" />.

#### Filtragem

Os mesmos editores listados acima serão usados na filtragem rápida/filtragem estilo Excel. Estes são os operandos de filtragem que cada tipo expõe:
- `DateTime` e `Date` - Igual a, Diferente de, Antes de, Depois de, Hoje, Ontem, Este mês, Mês passado, Próximo mês, Este ano, Ano passado, Próximo ano, Vazio, Não vazio, Nulo, Não nulo;
- `Time` - Em, Não em, Antes de, Depois de, Em ou antes de, Em ou depois de, Vazio, Não vazio, Nulo, Não nulo;

#### Resumos

Os operandos de resumo disponíveis serão **Count**, **Earliest** (data/hora) e **Latest** (data/hora).

#### Ordenação

- `Time`: a coluna é ordenada com base na parte de hora do objeto; os milissegundos serão desconsiderados.
- `Date`: a coluna é ordenada com base na parte da data, desconsiderando a parte da hora.
- `DateTime`: a coluna é ordenada com base na data completa.

### Imagem

O template padrão usa o valor vindo dos dados como fonte de imagem para um template de imagem padrão. O template de imagem padrão extrai o nome do arquivo de imagem e o define como o atributo `alt` da imagem, para atender ao requisito de acessibilidade. O tamanho da célula exibida é ajustado aos tamanhos das imagens renderizadas; por isso, tenha em mente que imagens grandes ainda serão renderizadas e as linhas do grid ficarão tão grandes quanto as imagens na coluna de imagem. Filtragem, ordenação e agrupamento ficam desativados por padrão em colunas do tipo imagem. Se quiser habilitá-los, você precisa fornecer estratégias personalizadas que executem as operações de dados.

### Percentual

O template padrão mostra o equivalente percentual do valor numérico subjacente. O valor exibido na célula é o resultado de uma multiplicação pelo fator de exibição de '100' — por exemplo, como o fator padrão é 100 e o "valor" passado à célula é 0,123, o valor exibido na célula será "12.3%".

Na edição de célula, o valor será o mesmo do valor da fonte de dados — o fator de exibição é '1'. Ao editar a célula, uma prévia do valor percentual será mostrada como um elemento de sufixo. Por exemplo, ao editar '0.0547', o elemento de prévia mostrará '5.47%'.

<PlatformBlock for="Angular">
```ts
public options = {
    /**
    * Decimal representation options, specified by a string in the following format:
    * `{minIntegerDigits}`.`{minFractionDigits}`-`{maxFractionDigits}`.
    * `minIntegerDigits`: The minimum number of integer digits before the decimal point. Default is 1.
    * `minFractionDigits`: The minimum number of digits after the decimal point. Default is 0.
    * `maxFractionDigits`: The maximum number of digits after the decimal point. Default is 3.
    */
    digitsInfo: '2.2-3'
};
public formatPercentOptions = this.options;
```
