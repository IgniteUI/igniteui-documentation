# Atualizações de dados em tempo real do {Platform} {ComponentTitle}

O recurso de atualização de dados em tempo real do {ProductName} em {Platform} {ComponentTitle} é usado para ativar atualizações em tempo real ou quase em tempo real dos dados exibidos na grade. Isso é extremamente útil em aplicações em que os dados mudam constantemente, como monitores do mercado de ações, placares esportivos ao vivo ou painéis de IoT (Internet das Coisas). O <ApiLink type="{ComponentName}" /> pode lidar com milhares de atualizações por segundo, mantendo-se responsivo às interações do usuário.

## Vinculação e atualização de dados

Um serviço fornece dados ao componente quando a página é carregada e quando o controle deslizante é usado para buscar uma determinada quantidade de registros. Em um cenário real, os dados atualizados seriam consumidos do serviço; aqui, os dados são atualizados no código. Isso é feito para manter a demonstração simples e focada no seu objetivo principal: demonstrar o desempenho do grid.

## Templates
A atualização da visualização funciona da mesma forma para colunas com template padrão e para colunas com template personalizado. No entanto, recomenda-se manter os templates personalizados relativamente simples. À medida que o número de elementos no template cresce, o impacto negativo no desempenho também aumenta.

## Feed de dados ao vivo com o Dock Manager e os componentes igxGrid
O objetivo desta demonstração é apresentar um painel financeiro com fluxo de dados em tempo real, usando um back-end de hub [SignalR](https://dotnet.microsoft.com/apps/aspnet/signalr).
Como você pode ver, o componente igxGrid lida com facilidade com as atualizações de alta frequência vindas do servidor. O código da aplicação ASP.NET Core usando SignalR pode ser encontrado neste [repositório público no GitHub](https://github.com/IgniteUI/finjs-web-api).

### Iniciar a conexão com o hub

O signal-r.service cuida da conectividade e das atualizações dos parâmetros gerenciáveis expostos: **frequência**, **volume** e **alternância do estado de atualização ao vivo** (Start/Stop).

```ts
this.hubConnection = new signalR.HubConnectionBuilder()
        .configureLogging(signalR.LogLevel.Trace)
        .withUrl('https://www.infragistics.com/angular-apis/webapi/streamHub')
        .build();
    this.hubConnection
        .start()
        .then(() => {
            this.hasRemoteConnection = true;
            this.registerSignalEvents();
            this.broadcastParams(interval, volume, live, updateAll);
        })
        .catch(() => {});
```

Com base na frequência especificada, um total de 30 novas atualizações será recebido pelos grids do servidor. Classes específicas de cellStyle são aplicadas às três colunas que tratam das alterações (Price, Change e Change in percent).

### Frequência de atualização e volume de dados

Usando o painel de Ações à esquerda, você pode gerenciar a frequência do feed de dados e o volume dos dados solicitados. Todos os grids usam a mesma fonte de dados. Sinta-se à vontade para usar os outros elementos de ação para **parar o feed de dados**, alterar o **tema da aplicação** ou adicionar **dinamicamente um contêiner DockSlot** com um igxGrid.

Usamos o método `updateParameters` para solicitar um novo conjunto de dados com determinada frequência. Esse método faz parte da [implementação do stream hub](https://github.com/IgniteUI/finjs-web-api/blob/master/WebAPI/Models/StreamHub.cs#L18) do SignalR.

```ts
this.hubConnection.invoke('updateparameters', frequency, volume, live, updateAll)
    .then(() => console.log('requestLiveData', volume))
    .catch(err => {
        console.error(err);
    });
```
