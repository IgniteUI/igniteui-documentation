# {Platform} {ComponentTitle} visão geral da paginação

O recurso de Paginação do {ProductName} em {Platform} {ComponentTitle} é usado para dividir um grande conjunto de dados em uma sequência de páginas com conteúdo semelhante. A paginação de grade no React melhora a experiência do usuário e a interação com os dados. A paginação do <ApiLink type="{ComponentName}" /> é configurável por meio de um componente separado, projetado na árvore da grade pela definição de uma tag <ApiLink type="Paginator" />, de forma semelhante à adição de uma coluna. Como em qualquer tabela {Platform}, a paginação no {Platform} {ComponentTitle} oferece suporte a template para páginas personalizadas.

## Paginação com Group By

As linhas de grupo participam do processo de paginação junto com as linhas de dados. Elas contam para o tamanho da página em cada página. Linhas recolhidas não são incluídas no processo de paginação.

A integração entre Paginação e Group By é descrita no tópico [Group By](groupby.mdx#{PlatformLower}-grid-group-by-with-paging).

## Estilização da paginação em {Platform}

Para começar a estilizar o paginador, precisamos importar o arquivo `index`, onde ficam todas as funções de tema e os mixins de componente:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Usando a abordagem mais simples, criamos um novo tema que estende o `PaginatorTheme` e aceita os parâmetros `$text-color`, `$background-color` e `$border-color`.

```scss
$dark-paginator: paginator-theme(
    $text-color: #F4D45C,
    $background-color: #575757,
    $border-color: #292826
);
```

Como visto, `PaginatorTheme` controla apenas as cores do contêiner de paginação, mas não afeta os botões da interface do paginador. Os botões do paginador são botões de ícone planos; então, para estilizá-los, crie um novo tema de botão de ícone:

```scss
$dark-button: flat-icon-button-theme(
    $foreground: #FFCD0F,
    $hover-foreground: #292826,
    $hover-background: #FFCD0F,
    $focus-foreground: #292826,
    $focus-background: #FFCD0F,
    $disabled-foreground: #16130C
);
```

Neste exemplo, alteramos apenas a cor e o fundo do ícone e a cor do botão desabilitado, mas o `flat-icon-button-theme` oferece muito mais parâmetros para controlar o estilo do botão.

A última etapa é **incluir** os mixins dos componentes, cada um com o seu tema correspondente:

```scss
@include grid-paginator($dark-grid-paginator);
.igx-grid-paginator__pager {
    @include button($dark-button);
}
```

<DocsAside type="info">
Restringimos o mixin <ApiLink pkg="core" type="Button" /> a `.igx-paginator__pager`, para que apenas os botões do paginador sejam estilizados. Caso contrário, outros botões da grade também seriam afetados.
</DocsAside>

<DocsAside type="info">
Se o componente estiver usando um ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), é necessário `penetrate` esse encapsulamento usando `::ng-deep`:
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include paginator($dark-paginator);
        .igx-paginator__pager {
            @include button($dark-button);
        }
    }
}
```

### Definindo uma paleta de cores

Em vez de fixar os valores de cor como acabamos de fazer, podemos obter mais flexibilidade em relação às cores usando as funções `Palette` e <ApiLink pkg="core" type="Color" />.

`Palette` gera uma paleta de cores com base nas cores primária e secundária que são passadas:

```scss
$yellow-color: #F9D342;
$black-color: #292826;

$dark-palette: palette($primary: $black-color, $secondary: $yellow-color);
```

E então, com <ApiLink pkg="core" type="Color" />, podemos obter facilmente uma cor da paleta.

```scss
$dark-paginator: paginator-theme(
    $text-color: color($dark-palette, "secondary", 400),
    $background-color: color($dark-palette, "primary", 200),
    $border-color: color($dark-palette, "primary", 500)
);

$dark-button: flat-icon-button-theme(
    $foreground: color($dark-palette, "secondary", 700),
    $hover-foreground: color($dark-palette, "primary", 500),
    $hover-background: color($dark-palette, "secondary", 500),
    $focus-foreground: color($dark-palette, "primary", 500),
    $focus-background: color($dark-palette, "secondary", 500),
    $disabled-foreground: color($dark-palette, "primary", 700)
);
```

<DocsAside type="info">
As funções <ApiLink pkg="core" type="Color" /> e `Palette` são poderosas para gerar e obter cores. Consulte o tópico [Paletas](../themes/sass/palettes.mdx) para orientações detalhadas sobre como usá-las.
</DocsAside>

### Usando schemas

 Avançando com o mecanismo de temas, você pode construir uma estrutura robusta e flexível que se beneficia de [schemas](../themes/sass/schemas.mdx). Um schema é uma receita de tema.

Estenda um dos dois schemas predefinidos fornecidos para cada componente; neste caso, os schemas `DarkPagination` e `DarkButton`:

```scss
// Extending the dark paginator schema
$dark-paginator-schema: extend($_dark-pagination,
        (
            text-color:(
               color: ("secondary", 400)
            ),
            background-color:(
               color: ("primary", 200)
            ),
            border-color:(
               color: ("primary", 500)
            )
        )
);
// Extending the dark button schema
$dark-button-schema: extend($_dark-button,
        (
            icon-color:(
               color: ("secondary", 700)
            ),
            icon-hover-color:(
               color: ("primary", 500)
            ),
            icon-hover-background:(
               color: ("secondary", 500)
            ),
            icon-focus-color:(
               color: ("primary", 500)
            ),
            icon-focus-background:(
               color: ("secondary", 500)
            ),
            disabled-color:(
               color: ("primary", 700)
            )
        )
);
```

Para aplicar os nossos schemas personalizados, precisamos **estender** um dos globais `Light` ou `Dark`, o que basicamente indica os componentes com um schema personalizado, e depois adicioná-lo aos temas dos respectivos componentes:

```scss
// Extending the global dark-schema
$custom-dark-schema: extend($dark-schema,(
    igx-paginator: $dark-paginator-schema,
    igx-button: $dark-button-schema
));

// Definingpaginator-theme with the global dark schema
$dark-paginator: paginator-theme(
  $schema: $custom-dark-schema
);

// Defining flat-icon-button-theme with the global dark schema
$dark-button: flat-icon-button-theme(
  $schema: $custom-dark-schema
);
```

Não se esqueça de incluir os temas da mesma forma como foi demonstrado acima.
