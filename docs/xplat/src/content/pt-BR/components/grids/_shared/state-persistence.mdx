## Uso

<PlatformBlock for="Angular">
O método <ApiLink type="GridState" member="getState" /> retorna o estado da grade em uma string JSON serializada, para que os desenvolvedores possam simplesmente pegá-la e salvá-la em qualquer armazenamento de dados (banco de dados, nuvem, localStorage do navegador etc.). O método aceita como primeiro parâmetro opcional `Serialize`, que determina se <ApiLink type="GridState" member="getState" /> retornará um objeto <ApiLink type="IGridState" /> ou uma string JSON serializada.

O desenvolvedor pode optar por obter apenas o estado de um ou mais recursos, passando o nome do recurso ou um array com os nomes dos recursos como segundo argumento.
</PlatformBlock>

<PlatformBlock for="React, WebComponents">
O método <ApiLink type="GridState" member="getState" /> retorna o estado da grade em um objeto <ApiLink type="GridStateInfo" />, contendo todas as informações de estado. Etapas adicionais podem ser necessárias para salvá-lo.
</PlatformBlock>

<PlatformBlock for="React, WebComponents">

O desenvolvedor pode optar por obter apenas o estado de um ou mais recursos, passando como argumento um array com os nomes dos recursos. Um array vazio resultará no uso das opções de estado padrão.
</PlatformBlock>

A API simples de usar, de ponto único, permite obter uma persistência completa do estado com poucas linhas de código. **Copie e cole o código abaixo** — ele salvará o estado do grid no objeto `LocalStorage` do navegador sempre que o usuário sair da página atual. Sempre que o usuário voltar à página principal, o estado do grid será restaurado. Não é mais preciso configurar expressões avançadas de filtragem e ordenação toda vez para obter os dados desejados — faça isso uma vez e deixe o código abaixo fazer o resto para os seus usuários:

<PlatformBlock for="Angular">
```typescript
@ViewChild(IgxGridStateDirective, { static: true })
public state!: IgxGridStateDirective;

public ngOnInit() {
    this.router.events.pipe(take(1)).subscribe((event: NavigationStart) => {
        this.saveGridState();
    });
}

public ngAfterViewInit() {
    this.restoreGridState();
}

public saveGridState() {
    const state = this.state.getState() as string;
    window.sessionStorage.setItem('grid1-state', state);
}

public restoreGridState() {
    const state = window.sessionStorage.getItem('grid1-state');
    this.state.setState(state);
}

```
</PlatformBlock>

<PlatformBlock for="WebComponents">
```typescript
constructor() {
    window.addEventListener("load", () => { this.restoreGridState(); });
    window.addEventListener("beforeunload", () => { this.saveGridState(); });
}

// Using methods that work with IgcGridStateInfo object.
public saveGridState() {
    const state = this.gridState.getState();
    window.localStorage.setItem('grid-state', JSON.stringify(state));
}

public restoreGridState() {
    const state = window.localStorage.getItem('grid-state');
    if (state) {
        this.gridState.applyState(JSON.parse(state));
    }
}

// Or using string alternative methods.
public saveGridStateString() {
    const state = this.gridState.getStateAsString();
    window.localStorage.setItem('grid-state', state);
}

public restoreGridStateString() {
    const state = window.localStorage.getItem('grid-state');
    if (state) {
        this.gridState.applyStateFromString(state);
    }
}
```

</PlatformBlock>

## Restaurando colunas

<ApiLink type="GridState" /> não persiste, por padrão, templates de colunas, formatadores de colunas etc. (veja as [limitações](state-persistence.mdx#limitações)). Restaurar qualquer um desses pode ser feito com código no nível da aplicação. Vamos mostrar como fazer isso para colunas com template:

constructor() {
    var grid = this.grid = document.getElementById('grid') as IgcGridComponent;
    var isActiveCol = this.isActive = document.getElementById('isActive') as IgcColumnComponent;
    this.onColumnInit = this.onColumnInit.bind(this);

    this._bind = () => {
        grid.data = this.data;
        grid.addEventListener("columnInit", this.onColumnInit);
        isActiveCol.bodyTemplate = this.activeTemplate;
    }
    this._bind();
}

public activeTemplate = (ctx: IgcCellTemplateContext) => {
    return html`<igc-checkbox checked="${ctx.cell.value}"></igc-checkbox>`;

## Limitações

<ComponentBlock for="HierarchicalGrid">
- Ao restaurar todos os recursos da grade de uma só vez (usando a API `applyState` sem parâmetros), as propriedades de coluna da grade raiz podem ser redefinidas para o padrão. Se isso acontecer, restaure as colunas ou o recurso de seleção de colunas separadamente depois disso:

```typescript
state.applyState(gridState);
state.applyState(gridState.columns);
state.applyState(gridState.columnSelection);
```

</ComponentBlock>
