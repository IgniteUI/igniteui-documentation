# Filtragem estilo Excel em {Platform} {ComponentTitle}

O {Platform} {ComponentTitle} expõe um recurso de filtragem estilo Excel, com uma interface de filtro semelhante à do Excel. Ele simplifica o trabalho com grandes conjuntos de dados. A ideia principal é ajudar o usuário a filtrar os dados mais relevantes, eliminando as entradas irrelevantes.

## Uso

Para ativar a filtragem estilo Excel do componente <ApiLink type="{ComponentName}" />, dois inputs devem ser definidos. A propriedade <ApiLink type="{ComponentName}" member="allowFiltering" /> deve ser definida como **true**, e a propriedade <ApiLink type="{ComponentName}" member="filterMode" /> deve ser definida com o valor `ExcelStyleFilter`.

## Interações

Para abrir o menu de filtro de uma coluna específica, clique no ícone de filtro {Platform} no cabeçalho. Além disso, você pode usar a combinação <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>L</kbd> sobre um cabeçalho selecionado. Se a coluna puder ser ordenada, fixada, movida, selecionada ou ocultada junto com a filtragem, haverá botões disponíveis para os recursos que estiverem ativados.

Se nenhum filtro for aplicado, todos os itens da lista ficarão selecionados. Eles podem ser filtrados pelo input acima da lista. Para filtrar os dados, selecione ou desmarque os itens da lista e clique no botão Aplicar ou pressione <kbd>ENTER</kbd>. A filtragem aplicada pelos itens da lista cria expressões de filtro com o operador `equals`, e o operador lógico entre as expressões é `OR`.

Se você digitar algo na caixa de pesquisa e aplicar o filtro, apenas os itens que correspondem ao critério de pesquisa serão selecionados. Para adicionar itens aos que já estão filtrados, selecione a opção **Adicionar seleção atual ao filtro**.

Para limpar o filtro, marque a opção **Selecionar tudo** e clique no botão Aplicar.

Para aplicar um filtro com expressões diferentes, você pode clicar em **Text filter**, o que abre um submenu com todos os operadores de filtro disponíveis para a coluna. Ao selecionar um deles, abre-se a caixa de diálogo de filtro personalizado, onde você pode adicionar quantas expressões quiser, com operadores de filtro e lógicos diferentes. Há também um botão de limpar, que pode limpar o filtro.

## Templates

<PlatformBlock for="Angular">
Se você quiser personalizar ainda mais o menu de filtro estilo Excel sem desabilitar os recursos das colunas, pode usar templates personalizados. O menu de filtro estilo Excel oferece duas diretivas para templates:
- `IgxExcelStyleColumnOperationsTemplateDirective` - redefine o template da área com todas as operações da coluna, como ordenação, fixação etc.
- `IgxExcelStyleFilterOperationsTemplateDirective` - redefine o template da área com todas as operações específicas de filtro.

Você pode redefinir o template de apenas uma dessas áreas ou de ambas. Pode colocar qualquer conteúdo personalizado dentro dessas diretivas, ou usar qualquer um dos nossos componentes integrados de filtragem estilo Excel.

O código a seguir demonstra como definir um menu de filtro estilo Excel personalizado usando os componentes `excel-style-header`, `excel-style-sorting` e `excel-style-search`.

</PlatformBlock>

<PlatformBlock for="WebComponents, Blazor, React">

## Saída externa

O [z-index](https://developer.mozilla.org/en-US/docs/Web/CSS/z-index) do {ComponentTitle} cria um contexto de empilhamento separado para cada grade no DOM. Isso garante que todos os elementos descendentes da grade sejam renderizados como esperado, sem se sobrepor uns aos outros.
No entanto, elementos que ficam fora da grade (por exemplo, o filtro estilo Excel) entram em conflito com elementos externos que tenham o mesmo `z-index` (por exemplo, duas grades uma sob a outra), resultando em renderização incorreta. A solução para esse problema é definir a propriedade `Outlet` como uma diretiva de saída externa, que permite que os elementos de sobreposição sempre apareçam por cima.

## Estilização

Para começar a estilizar o diálogo de Filtragem estilo Excel, precisamos importar o arquivo `index`, onde ficam todas as funções de tema e os mixins de componente:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

O diálogo de filtragem estilo Excel herda sua cor de fundo do tema da grade, usando o parâmetro `filtering-row-background`. Para alterar o fundo, precisamos criar um tema personalizado:

```scss
$custom-grid: grid-theme(
    $filtering-row-background: #FFCD0F
);
```

Obviamente, há muito mais componentes dentro do diálogo de filtragem estilo Excel, como botões, caixas de seleção, uma lista e até um drop-down. Para estilizá-los, precisamos criar um tema separado para cada um:

```scss
$dark-button: flat-button-theme(
    $background: #FFCD0F,
    $foreground: #292826,
    $hover-background: #292826,
    $hover-foreground: #FFCD0F
);

$dark-input-group: input-group-theme(
    $box-background: #FFCD0F,
    $idle-text-color: #292826,
    $focused-text-color: #292826,
    $filled-text-color: #292826
);

$custom-list: list-theme(
    $background: #FFCD0F
);

$custom-checkbox: checkbox-theme(
    $empty-color: #292826,
    $fill-color: #292826,
    $tick-color: #FFCD0F,
    $label-color: #292826
);

$custom-drop-down: drop-down-theme(
    $background-color: #FFCD0F,
    $item-text-color: #292826,
    $hover-item-background: #292826,
    $hover-item-text-color: #FFCD0F
);
```

Neste exemplo, alteramos apenas alguns parâmetros dos componentes listados, mas os temas <ApiLink type="function-flat-button-theme" label="flat-button-theme" kind="sass" module="index.html" />, <ApiLink type="function-checkbox-theme" label="checkbox-theme" kind="sass" module="index.html" />, <ApiLink type="function-drop-down-theme" label="drop-down-theme" kind="sass" module="index.html" />, <ApiLink type="function-input-group-theme" label="input-group-theme" kind="sass" module="index.html" /> e <ApiLink type="function-list-theme" label="list-theme" kind="sass" module="index.html" /> oferecem muito mais parâmetros para controlar a estilização de cada um.

O último passo é **incluir** os mixins de componente, cada um com seu respectivo tema. Também definiremos a propriedade color para o placeholder do input.

```scss
@include drop-down($custom-drop-down);
@include grid($custom-grid);
.igx-excel-filter, .igx-excel-filter__secondary {
    @include button($dark-button);
    @include input-group($dark-input-group);
    @include list($custom-list);
    @include checkbox($custom-checkbox);
    .igx-input-group__input::placeholder {
        color: #FFCD0F;
    }
}
```

<DocsAside type="info">
Restringimos a maioria dos mixins dos componentes a `.igx-excel-filter` e `.igx-excel-filter__secondary`, para que esses temas personalizados afetem apenas os componentes aninhados no diálogo de filtragem estilo Excel e em todos os seus subdiálogos. Caso contrário, outros botões, caixas de seleção, input-groups e listas também seriam afetados.
</DocsAside>

<DocsAside type="info">
Se o componente estiver usando um ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), é necessário `penetrate` esse encapsulamento usando `::ng-deep`:
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include drop-down($custom-drop-down);
        @include grid($custom-grid);
        .igx-excel-filter, .igx-excel-filter__secondary {
            @include button($dark-button);
            @include input-group($dark-input-group);
            @include list($custom-list);
            @include checkbox($custom-checkbox);
            .igx-input-group__input::placeholder {
                color: #FFCD0F;
            }
        }
    }
}
```

### Definindo uma paleta de cores

Em vez de fixar os valores de cor como acabamos de fazer, podemos obter mais flexibilidade em relação às cores usando as funções <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" /> e <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />.

`igx-palette` gera uma paleta de cores com base nas cores primária e secundária que são passadas:

```scss
$yellow-color: #FFCD0F;
$black-color: #292826;

$dark-palette: palette($primary: $black-color, $secondary: $yellow-color);
```

E então, com <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />, podemos obter facilmente uma cor da paleta.

```scss
$custom-grid: grid-theme(
    $filtering-row-background: #FFCD0F
);

$dark-button: flat-button-theme(
    $background: color($dark-palette, "secondary", 400),
    $foreground: color($dark-palette, "primary", 400),
    $hover-background: color($dark-palette, "primary", 400),
    $hover-foreground: color($dark-palette, "secondary", 400)
);

$dark-input-group: input-group-theme(
    $box-background: color($dark-palette, "secondary", 400),
    $idle-text-color: color($dark-palette, "primary", 400),
    $focused-text-color: color($dark-palette, "primary", 400),
    $filled-text-color: color($dark-palette, "primary", 400)
);

$custom-list: list-theme(
    $background: color($dark-palette, "secondary", 400)
);

$custom-checkbox: checkbox-theme(
    $empty-color: color($dark-palette, "primary", 400),
    $fill-color: color($dark-palette, "primary", 400),
    $tick-color: color($dark-palette, "secondary", 400),
    $label-color: color($dark-palette, "primary", 400)
);

$custom-drop-down:drop-down-theme(
    $background-color: color($dark-palette, "secondary", 400),
    $item-text-color: color($dark-palette, "primary", 400),
    $hover-item-background: color($dark-palette, "primary", 400),
    $hover-item-text-color: color($dark-palette, "secondary", 400)
);
```

<DocsAside type="info">
As funções `igx-color` e `igx-palette` são poderosas para gerar e obter cores. Consulte o tópico [Paletas](../themes/sass/palettes.mdx) para orientações detalhadas sobre como usá-las.
</DocsAside>

### Usando schemas

Indo além do mecanismo de temas, você pode criar uma estrutura robusta e flexível que se beneficia dos [**schemas**](../themes/sass/schemas.mdx). Um **schema** é uma receita de tema.

Estenda um dos dois schemas predefinidos fornecidos para cada componente, neste caso - os schemas <ApiLink type="variable-_light-grid" label="light-grid" kind="sass" module="index.html" />, <ApiLink type="variable-_light-input-group" label="light-input-group" kind="sass" module="index.html" />, <ApiLink type="variable-_light-button" label="light-button" kind="sass" module="index.html" />, <ApiLink type="variable-_light-list" label="light-list" kind="sass" module="index.html" />, <ApiLink type="variable-_light-checkbox" label="light-checkbox" kind="sass" module="index.html" /> e <ApiLink type="variable-_light-drop-down" label="light-drop-down" kind="sass" module="index.html" />:

```scss
$custom-grid-schema: extend($_light-grid,
    (
        filtering-row-background:(
           color: ("secondary", 400)
        )
    )
);

$custom-button-schema: extend($_light-button,
    (
        flat-background:(
           color: ("secondary", 400)
        ),
        flat-text-color:(
           color: ("primary", 400)
        ),
        flat-hover-background:(
           color: ("primary", 400)
        ),
        flat-hover-text-color:(
           color: ("secondary", 400)
        ),

        raised-background:(
           color: ("secondary", 400)
        ),
        raised-text-color:(
           color: ("primary", 400)
        ),
        raised-hover-background:(
           color: ("primary", 400)
        ),
        raised-hover-text-color:(
           color: ("secondary", 400)
        )
    )
);

$custom-input-group-schema: extend($_light-input-group,
    (
        box-background:(
           color: ("secondary", 400)
        ),
        idle-text-color:(
           color: ("primary", 400)
        ),
        focused-text-color:(
           color: ("primary", 400)
        ),
        filled-text-color:(
           color: ("primary", 400)
        )
    )
);

$custom-list-schema: extend($_light-list,
    (
        background:(
           color: ("secondary", 400)
        )
    )
);

$custom-checkbox-schema: extend($_light-checkbox,
    (
        empty-color:(
           color: ("primary", 400)
        ),
        fill-color:(
           color: ("primary", 400)
        ),
        tick-color:(
           color: ("secondary", 400)
        ),
        label-color:(
           color: ("primary", 400)
        )
    )
);

$custom-drop-down-schema: extend($_light-drop-down,
    (
        background-color:(
           color: ("secondary", 400)
        ),
        item-text-color:(
           color: ("primary", 400)
        ),
        hover-item-background:(
           color: ("primary", 400)
        ),
        hover-item-text-color:(
           color: ("secondary", 400)
        )

```

Para aplicar os nossos schemas personalizados, precisamos **estender** um dos globais (<ApiLink type="variable-light-schema" label="light" kind="sass" module="index.html" /> ou <ApiLink type="variable-dark-schema" label="dark" kind="sass" module="index.html" />), o que basicamente indica os componentes com um schema personalizado, e depois adicioná-lo aos temas dos respectivos componentes:

```scss
$custom-light-schema: extend($light-schema,(
   grid: $custom-grid-schema,
   button: $custom-button-schema,
   input-group: $custom-input-group-schema,
   list: $custom-list-schema,
   checkbox: $custom-checkbox-schema,
   drop-down: $custom-drop-down-schema
));

$custom-grid: grid-theme(
    $schema: $custom-light-schema
);

$custom-button: flat-button-theme(
    $schema: $custom-light-schema
);

$custom-input-group: input-group-theme(
    $schema: $custom-light-schema
);

$custom-list: list-theme(
    $schema: $custom-light-schema
);

$custom-checkbox: checkbox-theme(
    $schema: $custom-light-schema
);

$custom-drop-down: drop-down-theme(
    $schema: $custom-light-schema
);
```

Não se esqueça de incluir os temas da mesma forma como foi demonstrado acima.
