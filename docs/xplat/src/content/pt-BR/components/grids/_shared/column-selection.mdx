# {Platform} {ComponentTitle} Visão geral da seleção de colunas

O recurso de Seleção de colunas do {Platform} {ComponentTitle} em {ProductName} oferece uma forma simplificada e semelhante à do Excel para selecionar e destacar uma coluna inteira com um único clique. Ele pode ser habilitado pela entrada <ApiLink type="{ComponentName}" member="columnSelection" />. Graças a uma API rica, o recurso permite manipular facilmente o estado da seleção, extrair dados das frações selecionadas, realizar operações de análise de dados e criar visualizações.

## Uso básico

O recurso de seleção de colunas pode ser habilitado pela entrada <ApiLink type="{ComponentName}" member="columnSelection" />, que aceita os valores <ApiLink type="GridSelectionMode" />.

## Interações

O modo de seleção padrão é `None`. Se for definido como `Single` ou `Multiple`, todas as colunas apresentadas ficarão <ApiLink type="Column" member="selectable" />. Dito isso, para selecionar uma coluna, basta clicar em uma delas, o que a marcará como <ApiLink type="Column" member="selected" />. Se a coluna não for selecionável, nenhum estilo de seleção será aplicado ao cabeçalho ao passar o mouse sobre ele.

<DocsAside type="info">
O recurso [Cabeçalhos de várias colunas](multi-column-headers.mdx) não se reflete na entrada <ApiLink type="{ComponentName}" member="selectable" />. O <ApiLink type="ColumnGroupComponent" /> fica <ApiLink type="{ComponentName}" member="selectable" /> se pelo menos um dos seus filhos tiver o comportamento de seleção habilitado. Além disso, o componente é marcado como <ApiLink type="{ComponentName}" member="selected" /> se todos os seus descendentes <ApiLink type="{ComponentName}" member="selectable" /> estiverem <ApiLink type="{ComponentName}" member="selected" />.
</DocsAside>

## Combinações de teclas

<DocsAside type="info">
As combinações de teclas só estão disponíveis quando a entrada <ApiLink type="{ComponentName}" member="columnSelection" /> do grid está definida como `multiple`.
</DocsAside>

Há dois cenários para a navegação por teclado no recurso **Seleção de colunas**:
- Seleção de várias colunas - mantendo pressionadas <kbd>CTRL</kbd> + <kbd>clique</kbd> em cada célula de cabeçalho **selecionável**.
- Seleção de intervalo de colunas - mantendo pressionadas <kbd>SHIFT</kbd> + <kbd>clique</kbd> seleciona todas as colunas **selecionáveis** entre elas.

## Manipulações pela API

A **API** oferece algumas capacidades adicionais para as colunas **não visíveis**, de modo que cada coluna **oculta** pode ser marcada como <ApiLink type="Column" member="selected" /> definindo o **setter** correspondente.

<DocsAside type="info">
A afirmação acima também se aplica a <ApiLink type="ColumnGroupComponent" />, exceto que, quando a propriedade <ApiLink type="{ComponentName}" member="selected" /> é alterada, ela altera o estado dos seus descendentes.
</DocsAside>

Mais informações sobre as manipulações pela API podem ser encontradas na seção [Referências da API](#referências-da-api).

Além dos temas predefinidos, a grade pode ser personalizada ainda mais definindo algumas das propriedades CSS disponíveis. Para criar um tema completo a partir de apenas algumas cores, consulte o [tópico de temas](theming.mdx).

## Estilização

Antes de mergulhar nas opções de estilização, é preciso importar o módulo principal e todos os mixins dos componentes.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```


<ComponentBlock for="Grid">
>Observe que a [seleção de linhas](row-selection.mdx) e a [seleção de colunas](column-selection.mdx) não podem ser manipuladas de forma independente. Elas dependem do mesmo `variables`.
</ComponentBlock>

Dito isso, vamos alterar os estilos de **seleção** e de **hover**. <br/>

Seguindo a abordagem mais simples, vamos definir o nosso **tema** personalizado.

<ComponentBlock for="TreeGrid">
```scss
$custom-grid-theme: grid-theme(
    $row-selected-background: #011627,
    $row-selected-text-color: #ECAA53,
    $row-selected-hover-background: #011627,
    $header-selected-text-color: #ECAA53,
    $header-selected-background: #011627,
    $expand-icon-color: #ECAA53,
    $expand-icon-hover-color: #B64B80
);
```

</ComponentBlock>

<ComponentBlock for="Grid, HierarchicalGrid">
```scss
$custom-grid-theme: grid-theme(
    $row-selected-background: #011627,
    $row-selected-text-color: #ECAA53,
    $row-selected-hover-background: #011627,
    $header-selected-text-color: #ECAA53,
    $header-selected-background: #011627
);
```

</ComponentBlock>

<ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" /> aceita vários parâmetros, mas estes são os cinco responsáveis por alterar a aparência de todas as colunas selecionadas:
- **$row-selected-background** - define o fundo da fração selecionada.
- **$row-selected-text-color** - define a cor do texto da fração selecionada
- **$row-selected-hover-background** - define a cor da célula ou do conjunto de células sob o ponteiro.
- **$header-selected-text-color** - define a cor do texto do cabeçalho da coluna selecionada
- **$header-selected-background** - define a cor de fundo do cabeçalho da coluna selecionada.


### Usando variáveis CSS
A última etapa é incluir o tema `{ComponentSelector}` personalizado.

```scss
@include tokens($custom-grid-theme);
```

### Substituindo o tema base
Para estilizar componentes no Internet Explorer 11, precisamos usar uma abordagem diferente, pois ele não oferece suporte a variáveis CSS.

<DocsAside type="info">
Se o componente estiver usando o ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), é necessário `penetrate` esse encapsulamento usando `::ng-deep`. Para evitar que o tema personalizado vaze para outros componentes, certifique-se de ter incluído o seletor `:host` antes de `::ng-deep`.
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid($custom-column-selection-theme);
    }
}
```
