# Grade Hierárquica com carregamento sob demanda

O Ignite UI for {Platform} <ApiLink type="HierarchicalGrid" /> permite uma renderização rápida, solicitando a quantidade mínima de dados a serem recuperados do servidor, para que o usuário possa ver o resultado na tela e interagir com os dados visíveis o mais rápido possível. Inicialmente, apenas os dados da grade raiz são recuperados e renderizados; somente depois que o usuário expande uma linha que contém uma grade filha é que ele recebe os dados dessa grade filha específica. Esse mecanismo, também conhecido como Load on Demand, pode ser facilmente configurado para funcionar com qualquer dado remoto.

Este tópico demonstra como configurar o Load on Demand criando um Remote Service Provider que se comunica com um serviço remoto já disponível. Aqui está a demo funcionando; depois, passaremos por ela passo a passo e descreveremos o processo de criação.

## Remote Service Provider

Primeiro, vamos preparar nosso provedor de serviço para que estejamos prontos para obter os dados de que a grade hierárquica precisará.

### Obtendo dados básicos


<PlatformBlock for="Angular">


Vamos nos comunicar com o nosso serviço de backend pelo protocolo HTTP, usando a interface XMLHttpRequest que os navegadores fornecem. Para fazer isso com mais facilidade, usaremos o módulo [`HttpClient`](https://angular.io/api/common/http/HttpClient) do Angular, que oferece uma API HTTP de cliente simplificada. Assim, para obter os dados, precisaremos deste método simples no nosso serviço:

```typescript
public getData(dataState): Observable<any[]> {
    return this.http.get(this.buildUrl(dataState)).pipe(
        map(response => response),
    );
}
```

Como você pode ver, `this.http` será uma referência ao nosso módulo `HttpCLient`, e `buildUrl()` será o método que gerará nossa URL com base nos dados que recebemos. Mapeamos a resposta e retornamos um Observable, já que isso é executado de forma assíncrona. Assim, podemos assiná-lo depois, processá-lo mais na aplicação e passá-lo à nossa grade.

</PlatformBlock>

### Montando a URL da requisição

Em seguida, definiremos como montar nossa URL para a requisição GET. É aqui que poderemos obter os dados para a nossa grade principal, mas também para qualquer grade filha dentro dela. Usaremos os dados de `Customers` deste [tópico](https://data-northwind.indigo.design/swagger/index.html) para o nosso nível raiz e `Orders` e `Details` para os níveis inferiores. O que primeiro precisamos é da `key` da nossa tabela, para determinar de onde obter os dados da grade desejada: a chave primária da linha pai e o seu ID único.


<PlatformBlock for="Angular">


Vamos definir tudo isso em uma interface chamada `IDataState`. Um exemplo:

```typescript
export interface IDataState {
    key: string;
    parentID: any;
    parentKey: string;
    rootLevel: boolean;
}

//...
public buildUrl(dataState: IDataState): string {
    let qS = "";
    if (dataState) {
        if (dataState.rootLevel) {
            qS += `${dataState.key}`;
        } else {
            qS += `${dataState.parentKey}/${dataState.parentID}/${dataState.key}`;
        }
    }
    return `${this.url}${qS}`;
}
//...
```

import { HttpClient } from '@angular/common/http';

import { map } from 'rxjs/operators';

    key: string;

    parentKey: string;
    rootLevel: boolean;

@Injectable()
export class RemoteLoDService {
    public url = `https://data-northwind.indigo.design/`;

    constructor(private http: HttpClient) { }

    public getData(dataState: IDataState): Observable<any[]> {

Definir os dados de qualquer filho que tenha sido expandido é um pouco diferente. Quando uma linha é expandida pela primeira vez, uma nova <ApiLink type="HierarchicalGrid" /> filha é renderizada para ela, e precisamos obter a referência da grade recém-criada para definir os seus dados. Por isso, cada componente <ApiLink type="RowIsland" /> fornece o evento `GridCreated`, disparado quando uma nova grade filha é criada para aquela ilha de linhas específica. Podemos usar isso para obter a referência de que precisamos para a nova grade, solicitar os seus dados ao serviço e aplicá-los.

Podemos usar um único método para todas as ilhas de linhas, pois construímos nosso serviço de forma que ele precise apenas da informação de se é o nível raiz, da chave da ilha de linhas, da chave primária da linha pai e do seu identificador único. Todas essas informações podem ser acessadas diretamente pelos argumentos do evento ou pela ilha de linhas responsável por disparar o evento.

Esta última etapa visa melhorar a experiência do usuário, informando que os dados ainda estão sendo carregados, para que ele não precise olhar para uma grade vazia nesse meio-tempo. Por isso, o <ApiLink type="HierarchicalGrid" /> oferece suporte a um indicador de carregamento que pode ser exibido enquanto a grade estiver vazia. Se novos dados forem recebidos, o indicador de carregamento será ocultado e os dados serão renderizados.

### Configuração do indicador de carregamento

O <ApiLink type="HierarchicalGrid" /> pode exibir um indicador de carregamento definindo a propriedade <ApiLink type="GridBaseDirective" member="isLoading" label="IsLoading" /> como **true** enquanto não houver dados. Precisamos defini-la inicialmente para a grade raiz e também ao criar novas grades filhas, até que os dados delas sejam carregados. Poderíamos sempre defini-la como **true** no nosso template, mas queremos ocultá-la e mostrar que a grade não tem dados caso o serviço retorne um array vazio, definindo-a como **false**.

Neste caso, a versão final da nossa configuração ficaria assim:


<PlatformBlock for="Angular">


```typescript
import { AfterViewInit, Component, ViewChild } from "@angular/core";
import {
    IGridCreatedEventArgs,
    IgxHierarchicalGridComponent,
    IgxRowIslandComponent
} from "igniteui-angular";
import { RemoteLoDService } from "../services/remote-lod.service";

@Component({
    providers: [RemoteLoDService],
    selector: "app-hierarchical-grid-lod",
    styleUrls: ["./hierarchical-grid-lod.component.scss"],
    templateUrl: "./hierarchical-grid-lod.component.html"
})
export class HierarchicalGridLoDSampleComponent implements AfterViewInit {
    @ViewChild("hGrid")
    public hGrid: IgxHierarchicalGridComponent;

    constructor(private remoteService: RemoteLoDService) { }

    public ngAfterViewInit() {
        this.hGrid.isLoading = true;
        this.remoteService.getData({ parentID: null, rootLevel: true, key: "Customers" }).subscribe((data) => {
            this.hGrid.isLoading = false;
            this.hGrid.data = data;
            this.hGrid.cdr.detectChanges();
        });
    }

    public gridCreated(event: IGridCreatedEventArgs, _parentKey: string) {
        const dataState = {
            key: event.owner.key,
            parentID: event.parentID,
            parentKey: _parentKey,
            rootLevel: false
        };
        event.grid.isLoading = true;
        this.remoteService.getData(dataState).subscribe(
            (data) => {
                event.grid.isLoading = false;
                event.grid.data = data;
                event.grid.cdr.detectChanges();
            }
        );
    }
}
```
