## Uso

O <ApiLink pkg="core" type="DateRangePicker" /> permite que os usuários selecionem uma data de início e uma de fim, seja escolhendo um intervalo de datas em um dropdown/pop-up de calendário, seja digitando diretamente nos campos de entrada, um para a data de início e outro para a de fim. O picker oferece dois modos para exibir os valores de data: entrada única e duas entradas. Ambos oferecem recursos de edição e máscara.

Quando o calendário está visível, um intervalo de datas pode ser selecionado escolhendo a data de início e a de fim. Selecionar uma data define a data de início e a de fim e, quando uma segunda data é escolhida, ela define a data de fim. Se um intervalo já estiver selecionado, clicar em qualquer outra data no calendário inicia uma nova seleção de intervalo.

### Valor

Além de ser selecionado ou digitado pelo usuário, o valor do intervalo do <ApiLink pkg="core" type="DateRangePicker" /> também pode ser definido pela propriedade <ApiLink pkg="core" type="DateRangePicker" member="value" />. É importante observar que o valor deve seguir o formato: **`{ start: startDate, end: endDate }`**, em que `startDate` e `endDate` são objetos `Date` que representam o intervalo selecionado.

<PlatformBlock for="WebComponents">

```ts
let dateRange = document.querySelector('igc-date-range-picker') as IgcDateRangePickerComponent;
let startDate = new Date(2025, 4, 6);
let endDate = new Date(2025, 4, 8);
dateRange.value = { start: startDate, end: endDate }
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const dateRangeRef = useRef<IgrDateRangePicker>();
let startDate = new Date(2025, 4, 6);
let endDate = new Date(2025, 4, 8);
useEffect (() => {
  dateRangeRef.current.value = { start: startDate, end: endDate }
}, [])

return (
  <IgrDateRangePicker ref={dateRangeRef} />
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
 <IgbDateRangePicker Value="@Range" Label="Date Range"/>

 @code {
    public IgbDateRangeValue Range = new IgbDateRangeValue()
    {
        Start = DateTime.Today,
        End = DateTime.Today.AddDays(3)
    };
}
```

</PlatformBlock>

<PlatformBlock for="WebComponents, React">

### Navegação pelo teclado

O <ApiLink pkg="core" type="DateRangePicker" /> oferece uma navegação pelo teclado intuitiva, permitindo que os usuários incrementem, decrementem ou pulem facilmente entre as diferentes partes do componente, sem precisar usar o mouse.

|Teclas|Descrição|
|----|-----------|
| <kbd>←</kbd> | Move o cursor um caractere para a esquerda |
| <kbd>→</kbd> | Move o cursor um caractere para a direita |
| <kbd>CTRL</kbd> + <kbd>ArrowLeft</kbd> | Move o cursor para o início da seção atual da máscara de entrada ou para o início da seção anterior, se ele já estiver no início |
| <kbd>CTRL</kbd> + <kbd>ArrowRight</kbd> | Move o cursor para o fim da seção atual da máscara de entrada ou para o fim da próxima, se ele já estiver no fim |
| <kbd>ArrowUp</kbd> | Incrementa em um passo a parte "focada" da máscara de entrada |
| <kbd>ArrowDown</kbd> | Decrementa em um passo a parte "focada" da máscara de entrada |
| <kbd>HOME</kbd> | Move o cursor para o início da máscara de entrada |
| <kbd>END</kbd> | Move o cursor para o fim da máscara de entrada |
| <kbd>CTRL</kbd> + <kbd>;</kbd> | Define a data atual como valor do componente |
| <kbd>ALT</kbd> + <kbd>↓</kbd> | Abre a lista suspensa do calendário |
| <kbd>ALT</kbd> + <kbd>↑</kbd> | Fecha a lista suspensa do calendário |

Você também pode navegar dentro do pop-up de calendário pelo teclado. A navegação é a mesma do componente <ApiLink pkg="core" type="Calendar" />.

|Teclas|Descrição|
|----|-----------|
| <kbd>↑</kbd> / <kbd>↓</kbd> / <kbd>←</kbd> / <kbd>→</kbd>| Navega pelos dias do mês |
| <kbd>ENTER</kbd> | Seleciona o dia em foco |
| <kbd>PAGE UP</kbd> | Vai para a visão do mês anterior |
| <kbd>PAGE DOWN</kbd> | Vai para a visão do próximo mês |
| <kbd>SHIFT</kbd> + <kbd>PAGE UP</kbd> | Vai para o ano anterior |
| <kbd>SHIFT</kbd> + <kbd>PAGE DOWN</kbd> | Vai para o próximo ano |
| <kbd>HOME</kbd> | Foca o primeiro dia do mês atual que está visível (ou o mês mais antigo, quando mais de uma visão de mês é exibida) |
| <kbd>END</kbd> | Foca o último dia do mês atual que está visível (ou o mês mais recente, quando mais de uma visão de mês é exibida). |
| <kbd>Escape</kbd> | Fecha o pop-up do calendário |

### Intervalos personalizados e predefinidos

Você também pode adicionar chips de intervalo de datas personalizados ao pop-up do calendário para uma seleção de intervalo mais rápida, usando a propriedade <ApiLink pkg="core" type="DateRangePicker" member="customRanges" />. Por exemplo, você pode criar um chip de intervalo personalizado para selecionar rapidamente o intervalo dos próximos 7 dias, terminando na data atual. Além disso, ao definir a propriedade <ApiLink pkg="core" type="DateRangePicker" member="usePredefinedRanges" />, um conjunto de chips de intervalos predefinidos será exibido junto com os personalizados.

<PlatformBlock for="WebComponents">

```ts
const today = new Date();

const nextSeven = new Date(
  today.getFullYear(),
  today.getMonth(),
  today.getDate() + 7
);
const nextWeek: CustomDateRange[] = [
  {
    label: 'Next 7 days',
    dateRange: {
      start: today,
      end: nextSeven
    }
  }
]

const dateRange = document.querySelector('igc-date-range-picker') as IgcDateRangePickerComponent;
dateRange.customRanges = nextWeek;
dateRange.usePredefinedRanges = true;
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx

);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

### Datas desabilitadas e especiais

Você também pode definir datas desabilitadas no calendário para restringir o intervalo de datas que o usuário pode escolher. Para definir as datas desabilitadas, use a propriedade <ApiLink pkg="core" type="DateRangePicker" member="disabledDates" />.

<PlatformBlock for="WebComponents">

```ts
let dateRange = document.querySelector('igc-date-range-picker') as IgcDateRangePickerComponent;

const minDate = new Date(2025, 4, 1);
const maxDate = new Date(2025, 4, 31);

dateRange.disabledDates = [
  {
    type: DateRangeType.Between,
    dateRange: [minDate, maxDate]
  }
] as DateRangeDescriptor[];
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx

const minDate = new Date(2025, 4, 5);
const maxDate = new Date(2025, 4, 15);
useEffect (() => {
  dateRangeRef.current.disabledDates = [
    {
      type: DateRangeType.Between,
      dateRange: [minDate, maxDate]
    }
  ] as DateRangeDescriptor[];
}, [])

return (
  <IgrDateRangePicker ref={dateRangeRef} />
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDateRangePicker DisabledDates="@DisabledDates" />

@code {

        new IgbDateRangeDescriptor
    {
        RangeType = DateRangeType.Between,
        DateRange = new DateTime[] { new DateTime(DateTime.Today.Year, DateTime.Today.Month, 5), new DateTime(DateTime.Today.Year, DateTime.Today.Month, 8) },
    }];
}
```

</PlatformBlock>

Você pode ver mais informações sobre todas as possibilidades que a propriedade <ApiLink pkg="core" type="DateRangePicker" member="disabledDates" /> oferece aqui: [Datas desabilitadas](./calendar.mdx#datas-desabilitadas)

Você também pode fazer o mesmo se quiser definir uma ou mais datas especiais no calendário; a única diferença é que, nesse caso, você deve usar a propriedade <ApiLink pkg="core" type="DateRangePicker" member="specialDates" />. [Datas especiais](./calendar.mdx#datas-especiais)

### Slots

Você também pode adicionar conteúdo personalizado e modificar a aparência do componente <ApiLink pkg="core" type="DateRangePicker" /> usando os slots disponíveis.

Os slots `prefix` e `suffix` permitem inserir conteúdo personalizado antes ou depois do campo de entrada (disponível somente no modo de entrada única):

<PlatformBlock for="WebComponents">

```html
<igc-date-range-picker>
  <igc-icon slot="prefix" name="down_arrow_icon"></igc-icon>
  <igc-icon slot="suffix" name="upload_icon"></igc-icon>
</igc-date-range-picker>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrDateRangePicker>
  <IgrIcon slot='prefix' name='down_arrow_icon'></IgrIcon>
  <IgrIcon slot='suffix' name='upload_icon'></IgrIcon>
</IgrDateRangePicker>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDateRangePicker>
    <IgbIcon @ref="DropDownIcon" slot="prefix" IconName="dropdown" Collection="material"></IgbIcon>
    <IgbIcon @ref="UploadIcon" slot="suffix" IconName="upload" Collection="material"></IgbIcon>
</IgbDateRangePicker>
```

</PlatformBlock>

No modo de duas entradas, você pode usar os slots `prefix-start`, `prefix-end`, `suffix-start` e `suffix-end` para direcionar as entradas individualmente. Para todos os slots dos tipos `prefix-` e `suffix-`, recomendamos usar um elemento `<span>` para texto simples, símbolos ou emojis, e um componente [`<igc-icon>`](../layouts/icon.mdx) para ícones.

Outro conjunto útil de slots são `clear-icon` e `calendar-icon`, que permitem personalizar os ícones dos botões de limpar e de calendário nos campos de entrada. Para esses slots, também recomendamos usar um elemento `<span>` para símbolos ou emojis, e um componente [`<igc-icon>`](../layouts/icon.mdx) para ícones.

<PlatformBlock for="WebComponents">

```html
<igc-date-range-picker>
  <igc-icon slot="clear-icon" name="apps_icon"></igc-icon>
  <igc-icon slot="calendar-icon" name="bin_icon"></igc-icon>
</igc-date-range-picker>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrDateRangePicker>
  <IgrIcon slot="clear-icon" name="apps_icon"></IgrIcon>
  <IgrIcon slot="calendar-icon" name="bin_icon"></IgrIcon>
</IgrDateRangePicker>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDateRangePicker>

</IgbDateRangePicker>
```

</PlatformBlock>

No modo de duas entradas, você também pode personalizar o texto padrão "to" entre os campos usando o slot `separator`. Para o melhor resultado, recomendamos usar um elemento `<span>` para esse slot.

O slot `actions` permite inserir um botão de ação personalizado com a sua própria lógica. Por exemplo, o botão abaixo alterna a coluna de números de semana no calendário. Recomendamos usar o componente [`<igc-button>`](../inputs/button.mdx) ao adicionar conteúdo ao slot `actions`.

<PlatformBlock for="WebComponents">

```html
<igc-date-range-picker id="DateRange">
  <igc-button slot="actions" onclick="DateRange.showWeekNumbers = true">Toggle Week Numbers</igc-button>
</igc-date-range-picker>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const dateRangeRef = useRef<IgrDateRangePicker>();
const toggleWeekNumbers = () => {
  dateRangeRef.current.showWeekNumbers = !dateRangeRef.current.showWeekNumbers;
};

return (
  <IgrDateRangePicker ref={dateRangeRef}>
    <IgrButton slot="actions" onClick={toggleWeekNumbers}>Toggle Week Numbers</IgrButton>
  </IgrDateRangePicker>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDateRangePicker Mode="PickerMode.Dialog" ShowWeekNumbers="@ShowWeekNumbers">
    <IgbButton slot="actions" @onclick="() => ShowWeekNumbers = !ShowWeekNumbers">Toggle week numbers</IgbButton>
</IgbDateRangePicker>

@code {
    private bool ShowWeekNumbers;
}
```

</PlatformBlock>

Além dos slots que já abordamos, os slots a seguir também estão disponíveis no componente <ApiLink pkg="core" type="DateRangePicker" />:

|Nome|Descrição|
|--|--|
| `title` | Renderiza o conteúdo do título do calendário. Aplicável somente no modo de diálogo. |
| `helper-text` | Renderiza conteúdo abaixo do(s) campo(s) de entrada. |
| `header-date` | Substitui o texto padrão da data/intervalo atual no cabeçalho do calendário. Aplicável somente no modo de diálogo. |
| `clear-icon-start` | Ícone de limpar personalizado para a entrada de início (modo de duas entradas). |
| `clear-icon-end` | Ícone de limpar personalizado para a entrada de fim (modo de duas entradas). |
| `calendar-icon-start` | Ícone de calendário personalizado para a entrada de início (modo de duas entradas). |
| `calendar-icon-end` | Ícone de calendário personalizado para a entrada de fim (modo de duas entradas). |
| `calendar-icon-open` | Ícone ou conteúdo exibido quando o picker está aberto (aplica-se às duas entradas no modo de duas entradas). |
| `calendar-icon-open-start` | Ícone ou conteúdo para o estado aberto da entrada de início (modo de duas entradas).|
| `calendar-icon-open-end` | Ícone ou conteúdo para o estado aberto da entrada de fim (modo de duas entradas). |

Para os slots `title`, `helper-text` e `header-date`, recomendamos usar um elemento `<span>`. Um `<span>` oferece um contêiner neutro que herda os estilos do componente de forma limpa, sem carregar propriedades de estilo próprias que possam interferir na tipografia e no layout pretendidos para o componente.

E para os slots dos tipos `clear-icon-` e `calendar-icon-`, recomendamos usar um elemento `<span>` para símbolos ou emojis, e um componente [`<igc-icon>`](../layouts/icon.mdx) para ícones.

## Estilização

Como o componente <ApiLink pkg="core" type="DateRangePicker" /> usa o componente <ApiLink pkg="core" type="Calendar" />, ele também herda as partes CSS do Calendar, permitindo estilizar os dois componentes de forma integrada. Você pode encontrar a lista completa das partes CSS expostas do Calendar aqui: [Estilização do Calendar](./calendar.mdx#estilização). Além das partes CSS do Calendar, o <ApiLink pkg="core" type="DateRangePicker" /> também expõe algumas partes CSS exclusivas que você pode usar para personalizar a sua aparência:

|Nome|Descrição|
|--|--|
| `separator` | O elemento separador entre as duas entradas. |
| `ranges` | O wrapper que renderiza os intervalos personalizados e predefinidos. |
| `label` | O wrapper do rótulo que renderiza conteúdo acima da entrada de destino. |
| `container` | O wrapper principal que contém todos os elementos de input principais. |
| `input` | O elemento de input nativo. |
| `prefix` | O wrapper do prefixo. |
| `suffix` | O wrapper do sufixo. |
| `calendar-icon` | O wrapper do ícone de calendário para o estado fechado. |
| `calendar-icon-start` | O wrapper do ícone de calendário para o estado fechado da entrada de início (duas entradas). |
| `calendar-icon-end` | O wrapper do ícone de calendário para o estado fechado da entrada de fim (duas entradas). |
| `calendar-icon-open` | O wrapper do ícone de calendário para o estado aberto. |
| `calendar-icon-open-start` | O wrapper do ícone de calendário para o estado aberto da entrada de início (duas entradas). |
| `calendar-icon-open-end` | O wrapper do ícone de calendário para o estado aberto da entrada de fim (duas entradas). |
| `clear-icon` | O wrapper do ícone de limpar (entrada única). |
| `clear-icon-start` | O wrapper do ícone de limpar da entrada de início (duas entradas). |
| `clear-icon-end` | O wrapper do ícone de limpar da entrada de fim (duas entradas). |
| `actions` | O wrapper das ações. |
| `helper-text` | O wrapper do texto de ajuda que renderiza conteúdo abaixo da entrada de destino. |

```css
igc-date-range-picker::part(label) {
  color: var(--ig-gray-600);
}

igc-date-range-picker::part(calendar-icon-start),
igc-date-range-picker::part(calendar-icon-end) {
  background-color: var(--ig-primary-500);
  color: var(--ig-primary-500-contrast);
}

igc-date-range-picker::part(calendar-icon-open-start),
igc-date-range-picker::part(calendar-icon-open-end) {
  background-color: var(--ig-primary-700);
  color: var(--ig-primary-700-contrast);
}

igc-date-range-picker::part(clear-icon-start),
igc-date-range-picker::part(clear-icon-end) {
  background-color: var(--ig-error-500);
  color: var(--ig-error-500-contrast);
}
```
