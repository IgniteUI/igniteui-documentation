## Uso

O trecho de código a seguir mostra como executar comandos relacionados à área de transferência no controle {Platform} <ApiLink type="Spreadsheet" />:

```ts
public cut(): void {
    this.spreadsheet.executeAction(SpreadsheetAction.Cut);
}

public copy(): void {
    this.spreadsheet.executeAction(SpreadsheetAction.Copy);
}

public paste(): void {
    this.spreadsheet.executeAction(SpreadsheetAction.Paste);
}
```
