# {Platform} Imagens do Azure Maps <Badge variant="preview" />

O {Platform} `AzureMapsImagery` é um serviço de mapeamento de imagens geográficas fornecido pela Microsoft®. Ele oferece vários estilos de blocos de imagens geográficas do mundo. Este serviço de imagens geográficas pode ser acessado diretamente no site <a href="https://azure.microsoft.com/en-us/products/azure-maps" target="_blank">www.azure.microsoft.com</a>. O componente de mapa {ProductName} pode exibir imagens geográficas do Azure Maps no conteúdo de fundo do mapa, usando a classe `AzureMapsImagery`.

## {Platform} Sobrepondo imagens do Azure Maps - visão geral

Ao trabalhar com o `GeographicTileSeries`, você pode combinar **sobreposições** (trânsito, clima, rótulos) sobre um **estilo de mapa base**, como, por exemplo, **Satellite**, **Road** ou **DarkGrey**. Usando **TerraOverlay** com, por exemplo, **Satellite** para visualizar o terreno.

- **Estilos base**: Satellite, Road, Terra e DarkGrey fornecem os blocos de fundo principais.
- **Estilos de sobreposição**: as imagens de trânsito e de clima (por exemplo, `TrafficRelativeOverlay`, `WeatherRadarOverlay`) são feitas para ser sobrepostas a um estilo base, atribuindo-as a uma série de blocos.
- **Estilos híbridos**: variantes como `HybridRoadOverlay` e `HybridDarkGreyOverlay` já combinam um estilo base com sobreposições (rótulos, estradas etc.), por isso você não precisa gerenciar várias camadas manualmente.

Esse modelo permite criar mapas mais ricos, por exemplo:
- Exibir **imagens de satélite** com uma **TrafficOverlay** para destacar congestionamentos em imagens do mundo real.
- Usar **Terra** com **WeatherRadarOverlay** para visualizar o terreno com precipitação.
- Aplicar **DarkGrey** com **LabelsRoadOverlay** para uma visão voltada a painéis, com alto contraste.

## {Platform} Sobrepondo imagens do Azure Maps - exemplo de código
O trecho de código a seguir mostra como exibir blocos de imagens geográficas sobre uma imagem de fundo, combinando, por exemplo, o trânsito com um mapa cinza-escuro, para o {Platform} `GeographicMap` usando as classes `AzureMapsImagery` e `GeographicTileSeries`.

```json-snippet channel="auto" include="bindingFields"

{
    "type": "GeographicMap",
    "$styleOptions": { "directAssignment": true },
    "name": "azureMap",
    "$setInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "$assignInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "backgroundContent": {
        "type": "AzureMapsImagery",
        "name": "azureImagery",
        "apiKey": "YOUR_AZURE_MAPS_API_KEY",
        "imageryStyle": "DarkGrey"
    },
    "series": [
        {
            "type": "GeographicTileSeries",
            "name": "imagerySeries",
            "$setInCode": {
                "tileImagery": [
                    "angular",
                    "react",
                    "webComponents",
                    "blazor",
                    "winUI",
                    "wpf"
                ]
            },
            "$assignInCode": {
                "tileImagery": [
                    "angular",
                    "react",
                    "webComponents",
                    "blazor",
                    "winUI",
                    "wpf"
                ]
            },
            "tileImagery": {
                "type": "AzureMapsImagery",
                "name": "trafficImagery",
                "apiKey": "YOUR_AZURE_MAPS_API_KEY",
                "imageryStyle": "TrafficAbsoluteOverlay"
            }
        }
    ]
}

```

## Propriedades
A tabela a seguir resume as propriedades da classe `AzureMapsImagery`:

| Nome da propriedade  | Tipo da propriedade   | Descrição   |
|----------------|-----------------|---------------|
|`apiKey`|string|Representa a propriedade para definir uma chave de API exigida pelo serviço de imagens do Azure Maps. Você deve obter essa chave no site <a href="https://azure.microsoft.com/en-us/products/azure-maps" target="_blank">azure.microsoft.com</a>.|
|`imageryStyle`|`AzureMapsImageryStyle`|Representa a propriedade para definir o estilo de mapa dos blocos de imagens do Azure Maps. Esta propriedade pode ser definida com os seguintes valores de enumeração `AzureMapsImageryStyle`:<ul><li>Satellite - especifica o estilo de mapa Satellite sem sobreposição de estradas ou rótulos</li><li>Road - especifica o estilo de mapa Aerial com sobreposição de estradas e rótulos</li><li>DarkGrey - especifica um estilo de mapa base cinza-escuro, para contraste e destaque de sobreposições</li><li>TerraOverlay - especifica um estilo de mapa de terreno com relevo sombreado para destacar elevação e características da paisagem</li><li>LabelsRoadOverlay - uma das várias sobreposições de rótulos de cidades, sem sobreposição aérea</li><li>HybridRoadOverlay - fundo de satélite combinado com sobreposições de estradas e rótulos</li><li>HybridDarkGreyOverlay - fundo de satélite combinado com sobreposições de rótulos cinza-escuros</li><li>LabelsDarkGreyOverlay - uma das várias sobreposições de rótulos de cidades sobre um mapa base cinza-escuro</li><li>TrafficDelayOverlay - exibe atrasos no trânsito e áreas de congestionamento em tempo real</li><li>TrafficAbsoluteOverlay - exibe as velocidades atuais do trânsito como valores absolutos</li><li>TrafficReducedOverlay - exibe o fluxo de trânsito reduzido com visualização baseada em luz</li><li>TrafficRelativeOverlay - exibe as velocidades do trânsito em relação às condições normais</li><li>TrafficRelativeDarkOverlay - exibe as velocidades do trânsito em relação às condições normais sobre um mapa base escuro, para maior contraste</li><li>WeatherRadarOverlay - exibe imagens de radar de precipitação quase em tempo real</li><li>WeatherInfraredOverlay - exibe imagens de satélite infravermelho da cobertura de nuvens</li></ul> |
