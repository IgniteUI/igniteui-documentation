# Visão geral do Banner do {Platform}

O componente Banner do {ProductName} oferece uma forma fácil de exibir uma mensagem de destaque aos usuários da aplicação, de maneira menos transitória que um snackbar e menos intrusiva que um dialog. Ele também pode indicar ações a tomar com base no contexto da mensagem.

### Mostrar o banner

Para exibir o componente de banner, use o método <ApiLink pkg="core" type="Banner" member="show" label="Show" /> e chame-o ao clicar em um botão. O banner aparece em relação ao local onde o elemento foi inserido no template da página, deslocando todo o restante do conteúdo. Normalmente, ele mostra algum conteúdo não intrusivo que exige interação mínima do usuário para ser descartado.

<PlatformBlock for="WebComponents">

```html
<igc-button onclick="banner.show()">Show Banner</igc-button>

<igc-banner id="banner">
    You are currently offline.
</igc-banner>
```

</PlatformBlock>

### Vinculação a eventos

O componente banner emite os eventos `Closing` e `Closed` quando é fechado. O evento `Closing` é cancelável: ele usa a interface [`CustomEvent`](https://developer.mozilla.org/docs/Web/API/CustomEvent), e o objeto emitido tem a sua propriedade `cancelable` definida como **true**. Se cancelarmos o evento `Closing`, a ação final correspondente e o evento não serão disparados: o banner não será fechado e o evento `Closed` não será emitido.

Para cancelar o evento de fechamento, chame o método [`preventDefault`](https://developer.mozilla.org/en-US/docs/Web/API/Event/preventDefault).

<PlatformBlock for="WebComponents">

```html
<igc-banner id="banner">
    ...
</igc-banner>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
const banner = document.getElementById('banner') as IgcBannerComponent;

banner.addEventListener('igcClosing', (event) => {
  event.preventDefault();
});
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrBanner onClosing={(event) => event.preventDefault()}>
    ...
</IgrBanner>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbBanner id="banner">
    ...
</IgbBanner>

@code {
    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender)
        {
            await JS.InvokeVoidAsync("handleClosing");
        }
    }
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">


```javascript
//In JavaScript:
function handleClosing() {
    const banner = document.getElementById('banner');

    banner.addEventListener('igcClosing', (event) => {
        event.preventDefault();
    });
}
```

</PlatformBlock>

<DocsAside type="info">
Se as alterações acima forem aplicadas, o banner nunca será fechado, pois o evento de fechamento é sempre cancelado.
</DocsAside>

## Exemplo avançado

Vamos criar um banner com dois botões personalizados: um para dispensar a notificação e outro para ativar a conexão. Podemos passar manipuladores de ação personalizados usando o slot `actions`:

<PlatformBlock for="WebComponents">

```html
<igc-banner id="banner">
    <igc-icon slot="prefix" name="signal_wifi_off"></igc-icon>
    You have lost connection to the internet. This app is offline.
    <div slot="actions">
        <igc-button onclick="banner.hide()">
            <igc-ripple></igc-ripple>
            Continue Offline
        </igc-button>
        <igc-button id="button">
            <igc-ripple></igc-ripple>
            Turn On Wifi
        </igc-button>
    </div>
</igc-banner>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrBanner ref={bannerRef}>
    <IgrIcon slot="prefix" name="signal_wifi_off"></IgrIcon>
    <span>You have lost connection to the internet. This app is offline.</span>
    <div slot="actions">
        <IgrButton variant="flat" onClick={() => bannerRef.current.hide()}>
            <IgrRipple />
            <span>Continue Offline</span>
        </IgrButton>
        <IgrButton variant="flat" onClick={refreshBanner}>
            <IgrRipple />
            <span>Turn On Wifi</span>
        </IgrButton>
    </div>
</IgrBanner>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbBanner @ref="bannerRef">
    <IgbIcon IconName="signal_wifi_off" Collection="material" slot="prefix"></IgbIcon>
    You have lost connection to the internet. This app is offline.
    <div slot="actions">
        <IgbButton Variant="ButtonVariant.Flat" @onclick="HideBanner">
            Continue Offline
            <IgbRipple />
        </IgbButton>
        <IgbButton Variant="ButtonVariant.Flat" @onclick="RefreshBanner">
            Turn On Wifi
            <IgbRipple />
        </IgbButton>
    </div>
</IgbBanner>

@code {
    private IgbBanner bannerRef;

    private void HideBanner()
    {
        this.bannerRef.HideAsync();
    }
}
```

</PlatformBlock>

> De acordo com as diretrizes do [Material Design](https://material.io/design/components/banners.html#anatomy) do Google, um banner deve ter no máximo 2 botões. O <ApiLink pkg="core" type="Banner" /> não limita explicitamente o número de elementos sob o slot `actions`, mas é altamente recomendado usar até 2 se você quiser aderir às diretrizes do material design.


A opção de dispensar (**Continuar offline**) não precisa de nenhuma lógica adicional, então pode simplesmente chamar o método <ApiLink pkg="core" type="Banner" member="hide" label="Hide" />. Já a ação de confirmação (**Ligar o Wi-Fi**) exige alguma lógica adicional; por isso, precisamos defini-la no componente. Em seguida, adicionaremos um listener de evento para o evento `click`. O último passo é chamar o método `refreshBanner()` a cada mudança, o que alternará o banner conforme o valor de `wifiState`.

A navbar terá um ícone de Wi-Fi, e também adicionaremos um listener de evento para o seu evento `click`. Como o método `refreshBanner()` é chamado a cada mudança, o ícone não só alternará o banner, como também mudará de acordo com o estado da conexão:

<PlatformBlock for="WebComponents">

```html
<igc-navbar>
  <h1>Gallery</h1>
  <igc-icon id="icon" slot="end" name="signal_wifi_off"></igc-icon>
</igc-navbar>

<igc-banner id="banner">
    ...
    <div slot="actions">
        ...
        <igc-button id="button">
            <igc-ripple></igc-ripple>
            Turn On Wifi
        </igc-button>
    </div>
</igc-banner>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
private banner: IgcBannerComponent;
private icon: IgcIconComponent;
private button: IgcButtonComponent;

private wifiState: boolean = false;

constructor() {
    this.banner = document.getElementById('banner') as IgcBannerComponent;
    this.icon = document.getElementById('icon') as IgcIconComponent;
    this.button = document.getElementById('button') as IgcButtonComponent;

    this.icon.addEventListener('click', () => this.refreshBanner());
    this.button.addEventListener('click', () => this.refreshBanner());
}

public refreshBanner() {
    if (!this.wifiState) {
        this.icon.name = 'signal_wifi_4_bar';
        this.banner.hide();
    } else {
        this.icon.name = 'signal_wifi_off';
        this.banner.show();
    }
    this.wifiState = !this.wifiState;
}
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const bannerRef = useRef<IgrBanner>(null);
const iconRef = useRef<IgrIcon>(null);

const [wifiState, setWifiState] = useState(false);
const [iconName, setIconName] = useState("signal_wifi_off");

const refreshBanner = () => {
    const nextWifiState = !wifiState;
    setWifiState(nextWifiState);
    setIconName(nextWifiState ? "signal_wifi_4_bar" : "signal_wifi_off");

    if (nextWifiState) {
        bannerRef.current.hide();
    } else {
        bannerRef.current.show();
    }
}

return(
    <>
        <IgrNavbar>
            <h1>Gallery</h1>
            <IgrIcon ref={iconRef} name={iconName} slot="end" onClick={refreshBanner}></IgrIcon>
        </IgrNavbar>

        <IgrBanner ref={bannerRef}>
            ...
            <div slot="actions">
                ...
                <IgrButton variant="flat" onClick={refreshBanner}>
                    <IgrRipple />
                    <span>Turn On Wifi</span>
                </IgrButton>
            </div>
        </IgrBanner>
    </>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbNavbar>
    <h1>Gallery</h1>
    <IgbIcon @ref="iconRef" IconName="@iconName" Collection="material" slot="end" @onclick="RefreshBanner"></IgbIcon>
</IgbNavbar>

<IgbBanner @ref="bannerRef">
    ...
    <div slot="actions">
        ...
        <IgbButton Variant="ButtonVariant.Flat" @onclick="RefreshBanner">
            Turn On Wifi
            <IgbRipple />
        </IgbButton>
    </div>
</IgbBanner>

```

## Estilização

O componente <ApiLink pkg="core" type="Banner" /> expõe várias partes CSS que dão controle total sobre o seu estilo:

|Nome|Descrição|
|--|--|
| `base` | O wrapper base do componente banner. |
| `spacer` | O wrapper interno que define o espaço ao redor do banner. |
| `message` | A parte que contém o texto e a ilustração. |
| `illustration` | A parte que contém o ícone/ilustração do banner. |
| `content` | A parte que contém o conteúdo de texto do banner. |
| `actions` | A parte que contém os botões de ação do banner. |

```css
igc-banner::part(spacer) {
  background: var(--ig-surface-600);
}

igc-banner::part(illustration) {
  color: var(--ig-surface-600-contrast);
}

igc-banner::part(content) {
  color: var(--ig-gray-900);
}
```
