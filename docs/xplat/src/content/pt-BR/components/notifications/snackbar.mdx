## Exemplos

### Tempo de exibição

Use a propriedade <ApiLink pkg="core" type="Snackbar" member="displayTime" label="DisplayTime" /> para configurar por quanto tempo o componente snackbar fica visível. Por padrão, ela é definida como 4000 milissegundos.

<Sample src="/notifications/snackbar/display-time" height={230} alt="Exemplo de tempo de exibição do Snackbar do {Platform}" />




### Texto da ação

Por padrão, o componente snackbar é ocultado automaticamente após um período especificado por <ApiLink pkg="core" type="Snackbar" member="displayTime" label="DisplayTime" />. Você pode usar a propriedade <ApiLink pkg="core" type="Snackbar" member="keepOpen" label="KeepOpen" /> para alterar esse comportamento. Dessa forma, o snackbar permanecerá visível. Usando o <ApiLink pkg="core" type="Snackbar" member="actionText" label="ActionText" /> do snackbar, você pode exibir um botão de ação dentro do componente.

<Sample src="/notifications/snackbar/action-text" height={230} alt="Exemplo de texto de ação do Snackbar do {Platform}" />




## Estilização

O componente <ApiLink pkg="core" type="Snackbar" /> expõe várias partes CSS para dar controle total sobre a sua estilização:

|Nome|Descrição|
|--|--|
| `base` | O wrapper base do componente snackbar. |
| `message` | A mensagem do snackbar. |
| `action` | O botão de ação padrão do snackbar. |
| `action-container` | A área que contém as ações. |

```css
igc-snackbar::part(base) {
  background: var(--ig-primary-500);
  border-color: var(--ig-primary-800);
  color: white;
}
```
