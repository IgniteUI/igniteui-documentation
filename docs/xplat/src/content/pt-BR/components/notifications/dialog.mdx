# Visão geral do Dialog do {Platform}

O componente Dialog do {ProductName} é usado para exibir algumas informações ou solicitar ao usuário uma ação ou confirmação. Ele é exibido em uma janela modal, o que significa que o usuário não pode interagir com a aplicação principal até que determinada ação seja executada para fechar o diálogo.

A forma mais simples de exibir o componente dialog é usar o seu método <ApiLink pkg="core" type="Dialog" member="show" label="Show" /> e chamá-lo em um clique de botão.

<PlatformBlock for="Blazor">

```razor
<div class="container vertical">
    <IgbButton @onclick="OnDialogShow" Variant=@ButtonVariant.Contained>Show Dialog</IgbButton>
    <IgbDialog @ref="DialogRef" Title="Confirmation">
        <p>Are you sure you want to delete the Annual_Report_2016.pdf and Annual_Report_2017.pdf files?</p>
        <IgbButton slot="footer" @onclick="OnDialogHide" Variant=@ButtonVariant.Flat>Cancel</IgbButton>
        <IgbButton slot="footer" @onclick="OnDialogHide" Variant=@ButtonVariant.Flat>OK</IgbButton>
    </IgbDialog>
</div>

@code {
    public IgbDialog DialogRef;
    public async Task OnDialogShow()
    {
        if (this.DialogRef != null)
            await this.DialogRef.ShowAsync();
    }
    public async Task OnDialogHide()
    {
        if (this.DialogRef != null)
            await this.DialogRef.HideAsync();
    }
}
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton variant="contained" clicked={this.onDialogShow}>
    <span>Show Dialog</span>
</IgrButton>

<IgrDialog ref={this.onDialogRef}>
    <span>Dialog Message</span>
</IgrDialog>

public onDialogRef(dialog: IgrDialog) {
    if (!dialog) { return; }
    this.dialogRef = dialog;
}

public onDialogShow() {
    if (this.dialogRef) {
        this.dialogRef.show();
    }
}
```

O componente <ApiLink pkg="core" type="Dialog" /> fornece uma propriedade <ApiLink pkg="core" type="Dialog" member="open" label="Open" />, que permite configurar o seu estado de acordo com o cenário da sua aplicação.

Use a propriedade <ApiLink pkg="core" type="Dialog" member="title" label="Title" /> para definir o título do dialog. No entanto, se algum conteúdo for fornecido no slot `title`, ele terá precedência sobre a propriedade.

Botões de ação ou informações adicionais podem ser colocados na parte inferior do dialog por meio do slot `footer`. Se nenhum conteúdo for adicionado ali, será exibido um botão `OK` padrão, que fecha o Dialog quando clicado. Caso não queira que esse botão apareça, você pode definir a propriedade <ApiLink pkg="core" type="Dialog" member="hideDefaultAction" label="HideDefaultAction" /> como **true**. O valor padrão é **false**.

### Fechamento

Por padrão, o Dialog é fechado automaticamente quando o usuário pressiona `ESC`. Você pode impedir esse comportamento usando a propriedade <ApiLink pkg="core" type="Dialog" member="keepOpenOnEscape" label="KeepOpenOnEscape" />. O valor padrão é **false**. Se houver um dropdown aberto (ou qualquer outro elemento que deva tratar `ESC` internamente) no dialog, pressionar `ESC` uma vez fechará o dropdown, e pressioná-lo novamente fechará o dialog.

Use a propriedade <ApiLink type="OverlaySettings" member="closeOnOutsideClick" label="CloseOnOutsideClick" /> para configurar se o dialog deve ser fechado ao clicar fora dele. O valor padrão é **false**.

## Estilização

O componente <ApiLink pkg="core" type="Dialog" /> expõe várias partes CSS para dar controle total sobre o seu estilo:

|Nome|Descrição|
|--|--|
| `base` | O wrapper base do dialog. |
| `title` | O contêiner do título. |
| `footer` | O contêiner do rodapé. |
| `content` | O contêiner do conteúdo. |

```css
igc-dialog::part(content) {
  background: var(--ig-secondary-800);
  color: var(--ig-secondary-800-contrast);
}

igc-dialog::part(title),
igc-dialog::part(footer) {
  background: var(--ig-secondary-800);
  color: var(--ig-warn-500);
}
```
