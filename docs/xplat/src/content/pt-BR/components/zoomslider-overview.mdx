# Visão geral do Zoom Slider do {Platform}

O controle {Platform} ZoomSlider oferece funcionalidade de zoom para controles que suportam intervalos. O ZoomSlider tem uma barra de rolagem horizontal, uma miniatura de todo o intervalo e uma janela de intervalo de zoom redimensionável. O ZoomSlider não pode funcionar como controle independente; ele atua como um aprimoramento para controles baseados em intervalos, como o DataChart ou o CategoryChart.

## Uso

| Nome do recurso        | Descrição |
| --------------------|----------------------- |
| Navegação pela barra de rolagem       | Os usuários podem alterar a escala e rolar por intervalos de dados usando os recursos integrados da barra de rolagem do ZoomSlider. |
| Deslocamento e zoom       | Os usuários podem ajustar a escala de exibição arrastando as bordas da alça para fazer a exibição atual cobrir um intervalo maior (reduzir o zoom) ou um intervalo menor (aumentar o zoom). |
| Múltiplas opções de interação do usuário       | Todas as interações de mouse são suportadas de forma redundante por toque e, na maioria delas, também pelo teclado. Para detalhes, consulte Interações do usuário e usabilidade. |
| Suporte a toque       |  Em dispositivos com suporte a toque, os usuários podem aproveitar toda a funcionalidade do ZoomSlider. Todas as interações de mouse são suportadas em ambiente de toque. |
| Extensibilidade       | O controle ZoomSlider oferece suporte ao controle DataChart imediatamente, sem configuração adicional. |
| Janela de intervalo de zoom configurável       | A largura e a posição iniciais da janela de intervalo de zoom, bem como o seu tamanho mínimo, são configuráveis. |

