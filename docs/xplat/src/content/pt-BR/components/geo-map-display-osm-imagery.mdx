# {Platform} Exibindo imagens do Open Street Maps

O {Platform} `OpenStreetMapImagery` é um serviço gratuito de mapeamento de imagens geográficas criado colaborativamente por colaboradores do OpenStreetMap© de todo o mundo. Ele oferece blocos de imagens geográficas do mundo somente no estilo de mapa de estradas, sem opções de configuração. Este serviço de imagens geográficas pode ser acessado diretamente no site <a href="http://www.openstreetmap.org" target="_blank">www.OpenStreetMap.org</a>.
Por padrão, o componente de mapa {ProductName} já exibe imagens geográficas do Open Street Maps. Por isso, não é preciso configurar o controle para exibir imagens geográficas do Open Street Maps.

## Trecho de código
Este exemplo de código define explicitamente `backgroundContent` do componente de mapa como o objeto `OpenStreetMapImagery`, que fornece imagens geográficas dos colaboradores do OpenStreetMap©.

```json-snippet source="/maps/geo-map/display-osm-imagery"
{
    "type": "GeographicMap",
    "$setInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "$assignInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "backgroundContent": {
        "type": "OpenStreetMapImagery",
        "name": "osmImagery"
    },
    "$type": "+doc:markup"
}
```
