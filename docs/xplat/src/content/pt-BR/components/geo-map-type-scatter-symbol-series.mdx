# Mapa de símbolos geográfico de {Platform}

No componente de mapa {Platform}, você pode usar o `GeographicSymbolSeries` para exibir dados geoespaciais usando pontos ou marcadores em um contexto geográfico. Este tipo de série geográfica é frequentemente usado para renderizar uma coleção de localizações geográficas, como cidades, aeroportos, terremotos ou pontos de interesse.

## Requisitos de dados
De forma semelhante a outros tipos de séries geográficas no componente de mapa, o `GeographicSymbolSeries` tem a propriedade `dataSource`, que pode ser vinculada a um array de objetos. Além disso, cada item de dados desse objeto deve ter duas colunas de dados numéricas que armazenam uma localização geográfica (longitude e latitude). Essas colunas de dados são então mapeadas para as propriedades `latitudeMemberPath` e `longitudeMemberPath`. O `GeographicSymbolSeries` usa os valores dessas colunas de dados mapeadas para plotar os elementos de símbolo no componente de mapa geográfico.

## Trecho de código
O código a seguir mostra como vincular o `GeographicSymbolSeries` às localizações de cidades carregadas de um arquivo de forma usando o `ShapefileRecord`.

```json-snippet source="/maps/geo-map/type-scatter-symbol-series" code="allCode"
{
    "type": "GeographicMap",
    "name": "geoMap",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicSymbolSeries",
            "name": "citiesSeries",
            "dataSourceRef": "WorldCities",
            "markerType": "Circle",
            "latitudeMemberPath": "Y",
            "longitudeMemberPath": "X",
            "markerBrush": "White",
            "markerOutline": "Gray"
        },
        {
            "type": "GeographicSymbolSeries",
            "name": "capitalsSeries",
            "dataSourceRef": "WorldCapitals",
            "markerType": "Circle",
            "latitudeMemberPath": "Y",
            "longitudeMemberPath": "X",
            "markerBrush": "White",
            "markerOutline": "rgb(32, 146, 252)"
        }
    ]
}
```
