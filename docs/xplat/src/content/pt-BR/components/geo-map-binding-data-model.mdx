# {Platform} Vinculando modelos de dados geográficos

O componente de mapa {ProductName} foi projetado para exibir dados geoespaciais de arquivos de forma e/ou localizações geográficas de modelos de dados sobre mapas de imagens geográficas. A propriedade `dataSource` das séries geográficas é usada para vincular modelos de dados. Essa propriedade pode ser vinculada a um array de objetos personalizados.

## {Platform} Exemplo de vinculação de modelos de dados geográficos


<Sample src="/maps/geo-map/binding-data-model" height={500} alt="{Platform} Exemplo de vinculação de modelos de dados geográficos" />




A tabela a seguir resume as estruturas de dados exigidas para cada tipo de série geográfica:

| Série geográfica  | Propriedades   | Descrição   |
|--------------|---------------| ---------------|
| `GeographicSymbolSeries` | `longitudeMemberPath`, `latitudeMemberPath`   | Especifica os nomes de 2 coordenadas numéricas de longitude e latitude |<PlatformBlock for="Web">
| `GeographicHighDensityScatterSeries` | `longitudeMemberPath`, `latitudeMemberPath`   | Especifica os nomes de 2 coordenadas numéricas de longitude e latitude |</PlatformBlock>
| `GeographicProportionalSymbolSeries` | `longitudeMemberPath`, `latitudeMemberPath`, `radiusMemberPath`   | Especifica os nomes de 2 coordenadas numéricas de longitude e latitude e 1 coluna numérica para o tamanho/raio dos símbolos |<PlatformBlock for="Angular, React, WebComponents, Blazor">
| `GeographicScatterAreaSeries` | `longitudeMemberPath`, `latitudeMemberPath`, `colorMemberPath`   | Especifica os nomes de 2 coordenadas numéricas de longitude e latitude e 1 coluna numérica para a triangulação dos valores |</PlatformBlock>
| `GeographicContourLineSeries` | `longitudeMemberPath`, `latitudeMemberPath`, `valueMemberPath`   | Especifica os nomes de 2 coordenadas numéricas de longitude e latitude e 1 coluna numérica para a triangulação dos valores |
|`GeographicShapeSeries`|`shapeMemberPath`|Especifica o nome da coluna de dados dos itens `dataSource` que contém os pontos geográficos das formas. Esta propriedade deve ser mapeada para um array de arrays de objetos com as propriedades x e y. |
|`GeographicPolylineSeries`|`shapeMemberPath`|Especifica o nome da coluna de dados dos itens `dataSource` que contém as coordenadas geográficas das linhas. Esta propriedade deve ser mapeada para um array de arrays de objetos com as propriedades x e y. |

## Trecho de código
O código a seguir mostra como vincular o `GeographicSymbolSeries` a um modelo de dados personalizado que contém as localizações geográficas de algumas cidades do mundo, armazenadas com coordenadas de longitude e latitude. Além disso, usamos o `GeographicPolylineSeries` para plotar o caminho geográfico mais curto entre essas localizações, usando a matemática do grande círculo de `\MapGeodesics`, mostrada por completo com o código abaixo

```json-snippet source="/maps/geo-map/binding-data-model"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "$type": "+doc:markup",
            "height": "100%",
            "width": "100%",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapBindingDataModelOnViewInit"
    ]
}
```

