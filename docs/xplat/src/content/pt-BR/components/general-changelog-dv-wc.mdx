### Melhorias

#### {PackageCharts}

- Foi adicionada a opção `Checkmark` à enumeração `MarkerType`. Use `MarkerType.Checkmark` em uma série para exibir um ícone de marca de seleção em forma de V dentro de um círculo. - Foi adicionado suporte a `MarkerSize` nas séries de gráfico com marcadores habilitados, para controlar as dimensões dos marcadores em pixels independentes de dispositivo, e para restaurar o dimensionamento baseado em modelo com `NaN`.

### {PackageGrids} (Grades)
- <ApiLink type="IgcGrid" />, <ApiLink type="IgcTreeGrid" />, <ApiLink type="IgcHierarchicalGrid" />
- Foi introduzido um novo recurso de mesclagem de células, que permite configurar e mesclar células de uma coluna com base nos mesmos dados ou em outra condição personalizada, em uma única célula.

        Pode ser habilitado nas colunas individuais:

<PlatformBlock for="WebComponents">

```html
        <igc-column field="field" merge="true"></igc-column>
```

</PlatformBlock>
        A mesclagem pode ser configurada no nível da grade para se aplicar:
  - `onSort` - somente quando a coluna estiver ordenada.
  - `always` - sempre, independentemente das operações de dados.

<PlatformBlock for="WebComponents">

```html
        <igc-grid cellMergeMode="always">
        </igc-grid>
```

</PlatformBlock>

        O padrão `cellMergeMode` é `onSort`.

        A funcionalidade pode ser modificada definindo um `mergeStrategy` personalizado na grade, caso sejam necessárias outras condições ou lógica de mesclagem para um cenário personalizado.

        Também é possível definir um `mergeComparer` nas colunas individuais, caso seja necessário um tratamento personalizado para um campo de dados específico.

- Foi adicionada a possibilidade de fixar colunas individuais em um lado específico (início ou fim da grade), para que agora seja possível fixar de ambos os lados. Isso pode ser feito de forma declarativa, definindo a propriedade `pinningPosition` na coluna:

<PlatformBlock for="WebComponents">

```html
        <igc-column field="Col1" pinned="true" pinningPosition="pinningPosition">
        </igc-column>
```

</PlatformBlock>

        ```ts
        pinningPosition = ColumnPinningPosition.End;
        ```

        Ou com a API, por meio de parâmetro opcional:

        ```ts
        grid.pinColumn('Col1', 0, ColumnPinningPosition.End);
        grid.pinColumn('Col2', 0, ColumnPinningPosition.Start);
        ```

        Se a propriedade `pinningPosition` não for definida em uma coluna, a coluna usará por padrão a posição especificada nas opções `pinning` da grade para `columns`.

- **Melhorias de ordenação**
  - Eficiência aprimorada do algoritmo de ordenação usando a transformação de Schwartz. Essa é uma técnica, também conhecida como decorate-sort-undecorate, que evita recalcular as chaves de ordenação, associando-as temporariamente aos registros de dados originais.
  - Algoritmos de ordenação refatorados de recursivos para iterativos.
- **Melhorias de agrupamento**
  - Algoritmo de agrupamento refatorado de recursivo para iterativo.
  - Operações de agrupamento otimizadas.

## **{PackageVerChanges-25-1-SEP}**

### {PackageMaps}

#### <Badge variant="preview" /> Suporte a imagens do Azure Map

O <ApiLink type="IgcGeographicMap" /> agora oferece suporte a imagens de mapa baseadas no Azure, permitindo que os desenvolvedores exibam mapas detalhados e dinâmicos em vários tipos de aplicativo. Você pode combinar várias camadas de mapa, visualizar dados geográficos e criar experiências de mapeamento interativas com facilidade.

Observação: o suporte às imagens do Bing Maps está sendo descontinuado. As chaves corporativas existentes ainda podem ser usadas para acessar o Bing Maps, garantindo que os seus aplicativos atuais continuem funcionando enquanto você faz a transição para os mapas do Azure.

Conheça alguns dos mapas do Azure disponíveis publicamente [aqui](https://azure.microsoft.com/en-us/products/azure-maps).

### {PackageCharts}

#### <Badge variant="preview" /> Novos eventos de rótulos de eixo

Os seguintes eventos foram adicionados a <ApiLink type="IgcDataChart" /> para permitir detectar diferentes operações nos rótulos do eixo:

- `LabelMouseDown`
- `LabelMouseUp`
- `LabelMouseEnter`
- `LabelMouseLeave`
- `LabelMouseMove`
- `LabelMouseClick`

#### <Badge variant="preview" /> Eixo companheiro

Foram adicionadas as propriedades `CompanionAxis` aos eixos X e Y, que permitem criar rapidamente um clone de um eixo existente. Quando habilitado usando a propriedade <ApiLink type="CategoryAngleAxis" member="companionAxisEnabled" label="CompanionAxisEnabled" />, o eixo clonado ficará, por padrão, na posição oposta do gráfico, e você poderá então configurar as propriedades desse eixo.

#### <Badge variant="preview" /> Contornos internos do RadialPieSeries

Há uma nova propriedade chamada <ApiLink type="RadialPieSeries" member="useInsetOutlines" label="UseInsetOutlines" /> para controlar como os contornos das <ApiLink type="RadialPieSeries" /> são renderizados. Definir este valor como **true** fará os contornos ficarem dentro da forma da fatia, enquanto o valor **false** (padrão) fará os contornos ficarem metade para dentro e metade para fora da borda da forma da fatia.

**Mudanças que quebram compatibilidade**

- Foi feita uma correção de um problema em que as propriedades <ApiLink type="ChartMouseEventArgs" member="plotAreaPosition" label="PlotAreaPosition" /> e <ApiLink type="ChartMouseEventArgs" member="chartPosition" label="ChartPosition" /> da classe <ApiLink type="ChartMouseEventArgs" /> estavam invertidas. Isso mudará os valores que <ApiLink type="ChartMouseEventArgs" member="plotAreaPosition" label="PlotAreaPosition" /> e <ApiLink type="ChartMouseEventArgs" member="chartPosition" label="ChartPosition" /> retornam.
