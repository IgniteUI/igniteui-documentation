# Visão geral do Spreadsheet do {Platform}

O componente Spreadsheet do {Platform} (visualizador de Excel) é leve, rico em recursos e oferece todas as opções necessárias para operar, visualizar e editar todos os tipos de dados de planilha, sejam científicos, comerciais, financeiros e outros. Todas as informações podem ser apresentadas em um formato tabular intuitivo e fácil de navegar entre células, painéis e planilhas. O <ApiLink type="Spreadsheet" /> é complementado por uma interface flexível semelhante à do Excel, gráficos detalhados e recursos como ativação, edição de células, formatação condicional, estilização, seleção e área de transferência.

## Funcionalidade

- Recursos

Assim como na planilha do Excel, você pode aplicar filtragem, ordenação, mover células, personalizar a cor das células, usar atalhos de teclado e até calcular fórmulas.

## Uso do Spreadsheet

- Desempenho

O spreadsheet é compatível com todos os navegadores modernos e otimizado para modelos de planilha complexos e volumosos, garantindo funcionamento impecável e simplicidade.

- Layout flexível e fácil personalização

Você pode selecionar, adicionar, remover e ativar ou desativar os recursos que quiser, e configurar as planilhas React instantaneamente, de modo que tudo atenda às necessidades dos usuários finais. Há também bibliotecas configuráveis, alternativas de estilização e formatação, opções de visibilidade e muitos temas para escolher.

- Interface conveniente, semelhante à do Excel

Assim como ao operar dados no Excel, o nosso componente spreadsheet oferece todas as operações conhecidas de área de transferência do Excel: copiar, colar e recortar. Você não precisa de treinamento adicional nem de novas habilidades para começar a usá-lo imediatamente. Ele também oferece opções de ordenação, navegação completa pelo teclado, valores e fórmulas, arrastar células, edição de colunas e linhas, filtragem, formatação de números e redimensionamento. O mecanismo de cálculo inteligente e rápido alimenta até as estimativas mais complexas. Sem dependências do Excel.

- Operações de dados

Colete e gerencie dados científicos, comerciais, de engenharia, financeiros e educacionais. Prepare e crie análises, grids avançados, relatórios, formulários de entrada de dados, orçamentos, cenários de previsão e planilhas personalizadas. Tudo isso graças à API completa.

- Processamento de dados rápido e seguro

Com o nosso spreadsheet, o processamento de dados é 100% seguro e protegido…

- Importação e exportação de Excel e CSV

Com a funcionalidade integrada de importação e exportação do Excel, você pode carregar e abrir documentos do Excel instantaneamente, visualizá-los sob demanda, adicionar alterações e salvá-los. Além disso, exporte sem esforço as suas planilhas Excel .xlsx concluídas.

## Dependências

Ao instalar o componente spreadsheet {Platform}, os pacotes core e excel também precisam ser instalados.

```cmd
npm install --save {PackageCore}
npm install --save {PackageExcel}
npm install --save {PackageSpreadsheet}
```

<DocsAside type="info">

No trecho de código a seguir, uma classe externa [ExcelUtility](./excel-utility.mdx) é usada para salvar e carregar um <ApiLink type="Spreadsheet" member="workbook" label="Workbook" />.
</DocsAside>

A seguir, é demonstrado como carregar uma pasta de trabalho no spreadsheet {Platform}

<PlatformBlock for="Angular">

```ts
import { IgxSpreadsheetComponent } from 'igniteui-angular-spreadsheet';
import { ExcelUtility } from 'ExcelUtility';

// ...

@ViewChild("spreadsheet", { read: IgxSpreadsheetComponent })
public spreadsheet: IgxSpreadsheetComponent;

ngOnInit() {
    const excelFile = '../../assets/Sample1.xlsx';
    ExcelUtility.loadFromUrl(excelFile).then((w) => {
      this.spreadsheet.workbook = w;
    });
}
```

</PlatformBlock>

<PlatformBlock for="React">

```ts
import { IgrSpreadsheet } from 'igniteui-react-spreadsheet';
import { ExcelUtility } from 'ExcelUtility';

// ...

public spreadsheet : IgrSpreadsheet = new IgrSpreadsheet({})

ngOnInit() {
    const excelFile = '../../assets/Sample1.xlsx';
    ExcelUtility.loadFromUrl(excelFile).then((w) => {
      this.spreadsheet.workbook = w;
    });
}
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
import { IgcSpreadsheetComponent } from 'igniteui-webcomponents-spreadsheet';
import { Workbook } from 'igniteui-webcomponents-excel';
import { ExcelUtility } from "./ExcelUtility";

// ...

let spreadsheet = (document.getElementById("spreadsheet") as IgcSpreadsheetComponent);

const excelFile = '../../assets/Sample1.xlsx';
ExcelUtility.loadFromUrl(excelFile).then((w: Workbook) => {
    spreadsheet.workbook = w;
});
```

</PlatformBlock>
