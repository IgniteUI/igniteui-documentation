# {Platform} Estilização de formas em séries de formas geográficas

Este tópico explica como aplicar estilização personalizada às `GeographicShapeSeries` no {Platform} `GeographicMap`.

## {Platform} Exemplo de estilização de formas em séries de formas geográficas


<Sample src="/maps/geo-map/shape-styling" height={500} alt="{Platform} Exemplo de estilização de formas em séries de formas geográficas" />




As quatro classes de estilização usadas em cada seção — **ShapeRandomStyling**, **ShapeScaleStyling**, **ShapeRangeStyling** e **ShapeComparisonStyling** — vêm do [Utilitário de estilização de formas](./geo-map-resources-shape-styling-utility.mdx), que publica o arquivo a ser copiado para o seu próprio projeto.

## Importações necessárias

A estilização de formas exige que você importe as seguintes classes:

```json-snippet id="shapeStyling" source="/maps/geo-map/shape-styling" channel="bindingImports,handlersImports"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true,
            "series": [
                {
                    "type": "GeographicShapeSeries",
                    "name": "shapeSeries",
                    "isCustomShapeStyleAllowed": true,
                    "assigningShapeStyleRef": "ShapeFileStyling"
                }
            ]
        }
    },
    "onViewInit": [ "ShapeFileOnViewInit" ]
}
```


## Estilização aleatória de formas

Este trecho de código cria instâncias de **ShapeRandomStyling** que atribuirão aleatoriamente cores de preenchimento aos países do mundo.

```json-snippet source="/maps/geo-map/shape-styling-random" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeRandomStyling"
    ]
}
```

## Estilização de escala de formas

Este trecho de código cria instâncias de **ShapeScaleStyling** que atribuirão cores de preenchimento às formas dos países com base na população, em escala logarítmica.

```json-snippet source="/maps/geo-map/shape-styling-scale" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeScaleStyling"
    ]
}
```

## Estilização de intervalos de formas

Este trecho de código cria instâncias de **ShapeRangeStyling** que atribuirão cores às formas dos países com base em faixas de população.

```json-snippet source="/maps/geo-map/shape-styling-range" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeRangeStyling"
    ]
}
```

## Estilização de comparação de formas

Este trecho de código cria instâncias de **ShapeComparisonStyling** que atribuirão cores aos países com base no nome da região deles no mundo.

```json-snippet source="/maps/geo-map/shape-styling-comparison" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeComparisonStyling"
    ]
}
```
