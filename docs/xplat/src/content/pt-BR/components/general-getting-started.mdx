## Usando o Ignite UI CLI

Para criar um aplicativo do zero e configurá-lo para usar o Ignite UI React, você pode usar o Ignite UI CLI. O primeiro passo é instalar o respectivo pacote globalmente, da seguinte forma:

```cmd
npm install -g igniteui-cli
```

Se você quiser uma experiência guiada pelas opções disponíveis, pode iniciar o modo passo a passo, que ajudará você a criar e configurar o seu novo aplicativo. Para iniciar o guia, basta executar o comando `ig`:

```cmd
ig
```

Em seguida, escolha `\React` como framework e `Ignite UI for React TS` como tipo de projeto. Selecione **Side Navigation** ou **Side Navigation Mini** para começar com um layout de navegação. Depois de selecionar um dos modelos de navegação, o assistente pergunta se deseja adicionar autenticação. O modelo **Empty** não mostra a opção de autenticação. Depois, você pode adicionar um componente/visão específico ou selecionar `Complete & Run`.

Ou crie um projeto diretamente com um único comando, por exemplo:

```cmd
ig new <project-name> --framework=react --type=igr-ts --template=side-nav
```

Para um passo a passo do assistente e do fluxo do complemento de autenticação, consulte [Guia passo a passo usando o Ignite UI CLI](./general-step-by-step-guide-using-cli.mdx). Para a referência completa de todos os comandos do CLI, IDs de modelo e uso direto do modelo de autenticação, consulte a [Visão geral do CLI](./general-cli-overview.mdx).

Se você adicionou um componente Grid durante as perguntas, depois que o aplicativo estiver em execução você deverá ver algo semelhante ao seguinte:

<Image src={igCliGrid} alt="" />

<DocsAside type="info">
Lembre-se de que, por padrão, o Ignite UI CLI instala a versão Trial do componente Grid do Ignite UI for React, que está sob [licença comercial](./general-open-source-vs-premium.mdx#tabela-de-comparação-de-todos-os-componentes).
</DocsAside>

Como alternativa, você pode usar frameworks populares como Next.js, Vite ou Expo, conforme recomendado pela equipe do React. A seguir estão instruções passo a passo para criar aplicativos React com o Ignite UI for React usando um desses métodos.

## Usando o Vite CLI

### Criando um novo projeto React

Todos os frameworks populares para desenvolvimento em React oferecem poderosas ferramentas de CLI para gerar a estrutura inicial de um aplicativo React.

1 - Abra o **VS Code**, selecione o menu **Terminal** e depois a opção **Novo Terminal**.

2 - Digite o comando a seguir na janela do terminal:

```cmd
npm create vite@latest
```

Em seguida, siga as perguntas para escolher um nome para o projeto, React como framework, se deseja usar TypeScript, e outras opções oferecidas pelo Vite. Consulte este <a href="https://react.dev/learn/creating-a-react-app" target="_blank">tópico</a> para mais informações sobre as diferentes formas de criar a base de um aplicativo React.

### Adicionando um componente Grid do Ignite UI React

#### Instalação do pacote
Para adicionar o componente [**Grid**](./grids/data-grid.mdx) do Ignite UI React ao aplicativo, você precisa instalar o pacote `igniteui-react-grids`:

```cmd
npm install igniteui-react-grids --save
```

#### Importando módulos de componente

Em seguida, podemos importar os módulos necessários dos componentes que queremos usar. Vamos fazer isso para os componentes Grid e Column, que também usaremos no modelo. Também precisamos importar um dos temas.

```ts
import { IgrGrid, IgrColumn } from 'igniteui-react-grids';
import 'igniteui-react-grids/grids/themes/light/bootstrap.css';
```

#### Usando componentes

Agora estamos prontos para usar o componente de grade {ProductName} na nossa marcação! Vamos defini-lo:

```tsx
// App.tsx
function App() {
  const data = [
    { name: "John", age: 30 },
    { name: "Jane", age: 25 },
    { name: "Bob", age: 35 }
  ];

  return (
    <div style={{ height: "100%", width: "100%" }}>
      <IgrGrid
        data={data}
        autoGenerate={false}>
        <IgrColumn
          field="name"
          header="Name"
          dataType="string">
        </IgrColumn>
        <IgrColumn
          field="age"
          header="Age"
          dataType="number">
        </IgrColumn>
      </IgrGrid>
    </div>
  );
}
```

### Executando o aplicativo

Por fim, podemos executar o nosso novo aplicativo:

```cmd
npm run dev
```

Depois de executar este comando, o seu projeto será compilado e servido localmente no seu computador. Ele será aberto automaticamente no seu navegador padrão, e você poderá usar os componentes {ProductName} no seu projeto. O resultado final deve mostrar uma grade de dados com dados de exemplo:

## Instalar os polyfills

Execute este comando para instalar os polyfills dos web components:

```bash
npm install @webcomponents/custom-elements
```

Em seguida, importe os polyfills dos web components no index.js:

```ts
import '@webcomponents/custom-elements/custom-elements.min';
import '@webcomponents/custom-elements/src/native-shim.js';
```

## Instalar o Ignite UI for Web Components
Para usar os Web Components do Ignite UI no seu aplicativo, você deve instalar o pacote `igniteui-webcomponents`:

```cmd
npm install igniteui-webcomponents
```

Em seguida, você precisará importar os componentes que deseja usar no seu arquivo `\index.ts`. Você pode importar um ou mais componentes usando a função `\defineComponents`, assim:

```ts
import { defineComponents, IgcAvatarComponent, IgcBadgeComponent } from 'igniteui-webcomponents';

defineComponents(IgcAvatarComponent, IgcBadgeComponent);
```

Você também pode importar todos os componentes usando a função `\defineAllComponents`:

```ts
import { defineAllComponents } from 'igniteui-webcomponents';

defineAllComponents();
```

<DocsAside type="info">
Importar todos os componentes aumentará o tamanho do bundle do seu aplicativo. Por isso, recomendamos importar apenas os componentes que você realmente usa.
</DocsAside>

A última etapa é importar o CSS necessário para os nossos componentes, para que sejam estilizados corretamente:

```ts
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

Depois que os componentes forem importados, você poderá usá-los no seu HTML:

```html
<igc-avatar initials="AZ"></igc-avatar>
<igc-badge></igc-badge>
```

## Instalar os pacotes de gráficos e de mapas

### Passo 1 - Crie o projeto de Web Components

1 - Abra uma linha de comando e crie um diretório chamado **wc-html**

3 - Inicialize o **npm** no diretório

```cmd
npm init -y
```

4 - Instale o empacotador **webpack** e a **webpack cli** como dependências de desenvolvimento

```cmd
npm install webpack webpack-cli --save-dev
```

<DocsAside type="info">
O webpack é um empacotador de módulos. Seu principal objetivo é empacotar arquivos JavaScript para uso em um navegador, mas ele também é capaz de transformar, empacotar ou agrupar praticamente qualquer recurso ou ativo.
</DocsAside>

5 - Abra o projeto no **VS Code**

```cmd
code .
```

6 - Crie um novo arquivo chamado **index.html** com este código:

```html
<html>
    <head>
        <title>Getting Started with Ignite UI for Web Components</title>
    </head>
    <body>

    </body>
</html>
```

7 - Crie uma nova pasta chamada **src** e, dentro dela, crie um novo arquivo chamado **index.js**. A estrutura do seu projeto deve ficar assim:

<Image src={wcProject} alt="wc-project" />

8 - Atualize o arquivo **package.json** para incluir um script de build usando o **webpack**

```json
  "scripts": {
    "build": "webpack ./src/index.js -o ./dist/ --output-filename index.bundle.js"
  },
```

<DocsAside type="info">
Este script usará o webpack para empacotar o arquivo **index.js** em outro arquivo chamado **index.bundle.js** e o colocará em uma pasta chamada **dist**.

Se ocorrer um problema de **JavaScript heap out of memory** durante a compilação, você pode aumentar o tamanho do heap usando este comando de build:
</DocsAside>

```json
"scripts": {
    "build": "node --max_old_space_size=8192 node_modules/webpack/bin/webpack src/index.js -o dist/index.bundle.js"
},
```

### Etapa 3 - Instalar o Ignite UI for Web Components e o lit-html

1 - Instale o Ignite UI for Web Components usando o **npm**. Neste exemplo, vamos instalar o web component Map:

```cmd

```

2 - Importe os módulos do Mapa geográfico e o **ModuleManager** no arquivo **index.js**:

```ts
import { IgcGeographicMapModule } from 'igniteui-webcomponents-maps';
import { IgcDataChartInteractivityModule } from 'igniteui-webcomponents-charts';

import { ModuleManager } from 'igniteui-webcomponents-core';
```

```ts
ModuleManager.register(
```

## Desenvolvimento assistido por IA

O Ignite UI oferece um conjunto de ferramentas de IA em três partes - **Agent Skills**, o **servidor Ignite UI CLI MCP** e o **servidor Ignite UI Theming MCP** - que fundamenta os assistentes de codificação com IA em APIs de componentes, caminhos de importação e design tokens corretos. Depois de conectado, o seu assistente de IA pode montar projetos, adicionar e modificar componentes, responder perguntas de documentação e gerar código {ProductName} preciso, sem sair do seu editor.

Execute `ig ai-config` na raiz do seu projeto para copiar as {ProductName} Agent Skills e gravar a configuração do servidor Ignite UI MCP em `.vscode/mcp.json`, em uma única etapa.

Para uma visão geral das três camadas e as instruções de configuração, consulte [Desenvolvimento assistido por IA com o Ignite UI](./ai/ai-assisted-development-overview.mdx). Para o guia completo de configuração do cliente do CLI MCP, consulte [Ignite UI CLI MCP](./ai/cli-mcp.mdx). ## Gráficos e diagramas
{ProductName} contém uma biblioteca de [Gráficos e diagramas](./charts/chart-overview.mdx) que permite visualizar qualquer tipo de dado por meio de mais de 65 tipos de séries e combinações de gráficos, para criar gráficos e painéis interativos e impressionantes. Criada para ser rápida e bonita, projetada para funcionar em todos os navegadores modernos e com suporte completo a toque e interatividade, você pode criar rapidamente visuais responsivos em qualquer dispositivo.

## Medidores
{ProductName} oferece os componentes [Radial Gauge](./radial-gauge.mdx), [Linear Gauge](./linear-gauge.mdx) e [Bullet Graph](./bullet-graph.mdx), usados para ilustrar dados de forma fácil e intuitiva. O [Radial Gauge](./radial-gauge.mdx) tem várias opções de personalização para criar um formato e uma escala predefinidos. O [Linear Gauge](./linear-gauge.mdx) oferece uma visão simples de um valor comparado a uma escala e a um ou mais intervalos. Ele oferece suporte a uma escala, um conjunto de marcas de escala e um conjunto de rótulos. O componente [Bullet Graph](./bullet-graph.mdx) permite criar visualizações de dados, substituindo os medidores usados em painéis por gráficos de barras simples.

## Mapas
O componente {ProductName} [Mapa geográfico](./geo-map.mdx) traz a capacidade de visualizar dados geográficos no seu aplicativo. Ele pode renderizar conjuntos de dados compostos por muitas localizações geográficas, em forma de marcadores, linhas, polígonos ou até mesmo bitmaps interativos. Permite sobrepor várias camadas de mapa com dados geográficos, marcar localizações geográficas específicas e exibir informações usando marcadores e cores personalizados.

## Grades e entradas
{ProductName} oferece vários componentes de [Grade](./grids/grids-header.mdx) que permitem vincular e exibir dados com pouca configuração, na forma de [Grid Lite](./grid-lite/overview.mdx) - um componente de grade leve, sob licença MIT, [Data Grid](./grids/data-grid.mdx) - um componente de grade com muitos recursos, sob licença comercial, [List](./grids/list.mdx), [Tree](./grids/tree.mdx) e até mesmo [Spreadsheet](./spreadsheet-overview.mdx).

## Botões, entradas, layouts e menus
{ProductName} oferece vários tipos de [Botões](./inputs/button.mdx), [Entradas](./inputs/input.mdx), [Menus](./menus/navbar.mdx) e [Layouts](./layouts/tabs.mdx), que permitem criar aplicativos Web modernos usando encapsulamento e o conceito de componentes reutilizáveis, sem dependências. ## Instalar o Ignite UI for Blazor

O Ignite UI for Blazor é distribuído por meio de pacotes NuGet. Instale o **IgniteUI.Blazor** do [Infragistics NuGet Feed](./general-nuget-feed.mdx) ou o **IgniteUI.Blazor.Trial** do [NuGet.org](https://www.nuget.org/packages/IgniteUI.Blazor.Trial).

Em um Blazor Web App com o modo de renderização WebAssembly ou Auto, basta instalá-lo no projeto cliente, pois o projeto de servidor o recebe pela referência do projeto.

Para obter mais informações sobre como instalar o Ignite UI for Blazor usando o NuGet, leia o tópico [Instalando o Ignite UI for Blazor](./general-installing-blazor.mdx).

## Registrar o Ignite UI for Blazor

1 - Abra o arquivo **Program.cs** e registre o serviço do Ignite UI for Blazor chamando a função **builder.Services.AddIgniteUIBlazor**. Em um Blazor Web App com o modo de renderização WebAssembly ou Auto, faça isso no **Program.cs** dos projetos de servidor e de cliente:

```csharp
builder.Services.AddIgniteUIBlazor();
```

2 - Adicione o namespace **IgniteUI.Blazor.Controls** no arquivo **_Imports.razor** (em ambos os projetos, quando houver um projeto cliente):

```razor
@using IgniteUI.Blazor.Controls
```

3 - Adicione a folha de estilos no elemento **`<head>`** do arquivo **Components/App.razor**:

```razor
<head>
    <link rel="stylesheet" href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" />
</head>
```

Para aplicativos .NET 9 ou posteriores, recomenda-se usar a propriedade de coleção **Assets**:

```razor
<head>
    <link rel="stylesheet" href="@Assets["_content/IgniteUI.Blazor/themes/light/bootstrap.css"]" />
</head>
```

4 - Adicione a referência ao script antes do script do Blazor no arquivo **Components/App.razor**. Referencie-o diretamente, não por meio de **Assets**:

```razor
<script src="_content/IgniteUI.Blazor/app.bundle.js"></script>
<script src="@Assets["_framework/blazor.web.js"]"></script>
```

### Módulos do componente

Chamar `builder.Services.AddIgniteUIBlazor()` é tudo o que a maioria dos aplicativos precisa: cada componente carrega os seus recursos de cliente na primeira vez em que é renderizado. Registre os módulos explicitamente para:

- ter os recursos de um componente prontos quando o aplicativo iniciar, antes de o componente ser renderizado pela primeira vez;
- usar um componente que é criado somente no cliente, por exemplo, por um template JavaScript, em que nenhum componente Razor solicita o seu módulo;
- habilitar recursos que nenhum componente solicita por conta própria, como a interatividade dos gráficos (<ApiLink raw type="DataChartInteractivityModule" />) ou os pacotes `*FullModule`, tudo no pacote **{PackageCore}**.

Liste os módulos em `\AddIgniteUIBlazor`, que os carrega quando o runtime do Ignite UI é iniciado:

```csharp
builder.Services.AddIgniteUIBlazor(
    typeof(IgbBadgeModule),
    typeof(IgbDataChartInteractivityModule)
);
```

Ou registre um módulo depois, com o runtime injetado:

```razor
@inject IIgniteUIBlazor IgniteUIBlazor

@code {
    protected override void OnInitialized()
    {
        IgbBadgeModule.Register(IgniteUIBlazor);
    }
}
```
