# {Platform} Usando pastas de trabalho

O Excel Engine {Platform} da Infragistics permite salvar dados no Microsoft® Excel® e carregar dados dele. Você pode criar pastas de trabalho e planilhas, inserir dados e exportar os dados para o Excel usando as várias classes da biblioteca. O Excel Engine {Platform} da Infragistics facilita exportar os dados do seu aplicativo como uma planilha Excel, bem como importar dados do Excel para o seu aplicativo.

## Alterar a fonte padrão

Primeiro, crie uma nova instância de <ApiLink type="IWorkbookFont" />. Em seguida, adicione a nova fonte à coleção <ApiLink type="Workbook" member="styles" label="Styles" /> do <ApiLink type="Workbook" />. Esse estilo contém as propriedades padrão de todas as células da pasta de trabalho, a menos que sejam especificadas de outra forma em uma linha, coluna ou célula. Alterar as propriedades do estilo alterará as propriedades padrão de formato de célula da pasta de trabalho.

```ts
var workbook = new Workbook();
var font: IWorkbookFont;
font = workbook.styles().normalStyle.styleFormat.font;
font.name = "Times New Roman";
font.height = 16 * 20;
```

<PlatformBlock for="Blazor">

```razor
var workbook = new Workbook();
var font = workbook.Styles.NormalStyle.StyleFormat.Font;
font.Name = "Times New Roman";
font.Height = 16 * 20;
```

</PlatformBlock>

## Definindo as propriedades da pasta de trabalho

As propriedades de documento do Microsoft Excel® fornecem informações para ajudar a organizar e acompanhar seus documentos. Você pode usar a biblioteca Excel {Platform} da Infragistics para definir essas propriedades, usando a propriedade <ApiLink type="Workbook" member="documentProperties" label="DocumentProperties" /> do objeto <ApiLink type="Workbook" />. As propriedades disponíveis são:

- <ApiLink type="DocumentProperties" member="author" label="Author" />

- <ApiLink type="DocumentProperties" member="title" label="Title" />

- <ApiLink type="DocumentProperties" member="subject" label="Subject" />

- <ApiLink type="DocumentProperties" member="keywords" label="Keywords" />

- <ApiLink type="DocumentProperties" member="category" label="Category" />

- <ApiLink type="DocumentProperties" member="status" label="Status" />

- <ApiLink type="DocumentProperties" member="comments" label="Comments" />

- <ApiLink type="DocumentProperties" member="company" label="Company" />

- <ApiLink type="DocumentProperties" member="manager" label="Manager" />

O código a seguir demonstra como criar uma pasta de trabalho e definir as suas propriedades de documento `title` e `status`.

```ts
var workbook = new Workbook();
workbook.documentProperties.title = "Expense Report";
workbook.documentProperties.status = "Complete";
```

<PlatformBlock for="Blazor">

```razor
var workbook = new Workbook();
workbook.DocumentProperties.Title = "Expense Report";
workbook.DocumentProperties.Status = "Complete";
```

</PlatformBlock>

## Proteção da pasta de trabalho

O recurso de proteção da pasta de trabalho permite proteger a estrutura da pasta de trabalho. Ou seja, a capacidade de um usuário adicionar, renomear, excluir, ocultar e reordenar as planilhas dessa pasta de trabalho.

A proteção não é aplicada pelo modelo de objetos do Excel Engine da Infragistics. Cabe à interface que visualiza esse modelo de objetos respeitar essas configurações de proteção e permitir ou restringir ao usuário a execução das operações correspondentes.

A proteção é aplicada a uma pasta de trabalho invocando o seu método `protect`.

Quando uma <ApiLink type="Workbook" /> é protegida sem senha, o usuário final pode desproteger a <ApiLink type="Workbook" /> no Excel sem precisar fornecer uma senha. Para desproteger uma <ApiLink type="Workbook" /> programaticamente, pode-se usar o método `unprotect`.

Quando uma <ApiLink type="Workbook" /> é protegida, os valores das propriedades da instância <ApiLink type="WorkbookProtection" /> obtida da propriedade `protection` desta <ApiLink type="Workbook" /> indicam as operações desabilitadas.

Se <ApiLink type="Workbook" member="isProtected" label="IsProtected" /> já for true, o método `protect` será ignorado.

```ts
var workbook = new Workbook();
workbook.protect(false, false);
```

<PlatformBlock for="Blazor">

```razor
var workbook = new Workbook();
workbook.Protect(false, false);
```

</PlatformBlock>

Verifica se uma pasta de trabalho tem proteção. Esta propriedade somente leitura retorna true se a pasta de trabalho tiver qualquer proteção definida usando as sobrecargas do método Protect.

```ts
var workbook = new Workbook();
var protect = workbook.isProtected;
```

<PlatformBlock for="Blazor">

```razor
var workbook = new Workbook();
var protect = workbook.IsProtected;
```

</PlatformBlock>

Esta propriedade somente leitura retorna um objeto do tipo WorkbookProtection, que contém propriedades para obter cada configuração de proteção individualmente.

```ts
var workbook = new Workbook();
var protection = workbook.protection;
```

<PlatformBlock for="Blazor">

```razor
var workbook = new Workbook();
var protect = workbook.Protection;
```

</PlatformBlock>
