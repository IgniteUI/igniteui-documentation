## Formato de arquivos de forma

O controle {Platform} `GeographicMap` usa o formato popular [Shape Files](http://en.wikipedia.org/wiki/Shapefile#Overview) como uma das fontes de dados geoespaciais. Os arquivos de forma geralmente vêm acompanhados de outros tipos de arquivo, normalmente com as extensões **.shp**, **.shx** e **.dbf**.

A tabela a seguir traz informações básicas e a finalidade de cada tipo de arquivo de forma.

| Extensão do arquivo | Descrição |
| ---------------|------------ |
| `.shp` | Um arquivo de forma contém itens de dados vetoriais geoespaciais que descrevem pontos, polilinhas e polígonos. Nesse arquivo, pontos podem descrever cidades, polilinhas podem descrever estradas e polígonos podem descrever as formas/fronteiras de países em um contexto geográfico. |
| `.shx` | Um arquivo de índice de forma contém um índice para consulta rápida dos itens de dados vetoriais geoespaciais. |
| `.dbf` | Um arquivo de banco de dados de forma contém uma tabela em que cada linha corresponde a um item de dados geoespacial de um arquivo de forma (.shp). No arquivo de banco de dados de forma, colunas de texto podem descrever atributos dos itens de dados geoespaciais, como nomes (de países, regiões, cidades), e colunas numéricas podem descrever valores (população de países, localização de cidades). |



Consulte os recursos a seguir para obter informações detalhadas e especificações sobre como os dados geoespaciais são armazenados em arquivos de forma.

- [ESRI - Descrição técnica do arquivo de forma](http://www.esri.com/library/whitepapers/pdfs/shapefile.pdf)

- [Wikipédia - Descrição do arquivo de forma](http://en.wikipedia.org/wiki/Shapefile#Overview)
