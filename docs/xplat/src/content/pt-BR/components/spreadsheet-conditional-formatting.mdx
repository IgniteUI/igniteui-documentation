# Formatação condicional do Spreadsheet do {Platform}

O componente {Platform} <ApiLink type="Spreadsheet" /> permite formatar condicionalmente as células de uma planilha. Isso permite destacar diferentes partes dos seus dados com base em uma condição.

## Visão geral da formatação condicional

Você pode configurar a formatação condicional de uma planilha específica usando os muitos métodos `\Add` expostos na coleção <ApiLink type="Worksheet" member="conditionalFormats" label="ConditionalFormats" /> dessa planilha. O primeiro parâmetro desses métodos `\Add` é a região em forma de string da planilha à qual você deseja aplicar a formatação condicional.

Muitas das formatações condicionais que você pode adicionar à sua planilha têm uma propriedade <ApiLink type="WorksheetCell" member="cellFormat" label="CellFormat" /> que determina a aparência das células quando a condição dessa formatação é verdadeira. Por exemplo, você pode usar as propriedades ligadas a essa propriedade <ApiLink type="WorksheetCell" member="cellFormat" label="CellFormat" />, como <ApiLink type="IWorksheetCellFormat" member="fill" label="Fill" /> e <ApiLink type="IWorksheetCellFormat" member="font" label="Font" />, para determinar as configurações de fundo e de fonte das suas células, respectivamente.

Quando uma formatação condicional é criada e um <ApiLink type="WorksheetCell" member="cellFormat" label="CellFormat" /> é aplicado, há um subconjunto de propriedades atualmente compatível com a célula da planilha. As propriedades atualmente respeitadas em <ApiLink type="WorksheetCell" member="cellFormat" label="CellFormat" /> são <ApiLink type="IWorksheetCellFormat" member="fill" label="Fill" />, propriedades de `\Border`, <ApiLink type="IWorksheetCellFormat" member="formatString" label="FormatString" /> e algumas propriedades de <ApiLink type="IWorksheetCellFormat" member="font" label="Font" />, como tachado, sublinhado, itálico, negrito e cor. Muitas delas podem ser vistas no trecho de código abaixo.

Há algumas formatações condicionais que não têm uma propriedade <ApiLink type="WorksheetCell" member="cellFormat" label="CellFormat" />, porque a sua visualização nas células se comporta de forma diferente. Essas formatações condicionais são <ApiLink type="DataBarConditionalFormat" />, <ApiLink type="ColorScaleConditionalFormat" /> e <ApiLink type="IconSetConditionalFormat" />.

Ao carregar uma pasta de trabalho existente do Excel, as formatações são preservadas quando essa pasta de trabalho é carregada. O mesmo vale ao salvar a pasta de trabalho em um arquivo do Excel.

A seguir, a lista das formatações condicionais compatíveis com o controle {Platform} <ApiLink type="Spreadsheet" />:

- <ApiLink type="AverageConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addAverageCondition" label="AddAverageCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor da célula estar acima ou abaixo da média ou do desvio padrão do intervalo associado.
- <ApiLink type="BlanksConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addBlanksCondition" label="AddBlanksCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor da célula não estar definido.
- <ApiLink type="ColorScaleConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addColorScaleCondition" label="AddColorScaleCondition" />, esta formatação condicional expõe propriedades que controlam a coloração de uma célula da planilha com base no valor da célula em relação aos valores de limite mínimo, médio e máximo.
- <ApiLink type="DataBarConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addDataBarCondition" label="AddDataBarCondition" />, esta formatação condicional expõe propriedades que exibem barras de dados em uma célula da planilha com base no valor da célula em relação ao intervalo de valores associado.
- <ApiLink type="DateTimeConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addDateTimeCondition" label="AddDateTimeCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor de data da célula cair dentro de um determinado intervalo de tempo.
- <ApiLink type="DuplicateConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addDuplicateCondition" label="AddDuplicateCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor da célula ser único ou duplicado no intervalo associado.
- <ApiLink type="ErrorsConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addErrorsCondition" label="AddErrorsCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor da célula ser válido.
- <ApiLink type="FormulaConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addFormulaCondition" label="AddFormulaCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor da célula atender aos critérios definidos por uma fórmula.
- <ApiLink type="IconSetConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addIconSetCondition" label="AddIconSetCondition" />, esta formatação condicional expõe propriedades que exibem ícones em uma célula da planilha com base no valor da célula em relação aos valores de limite.
- <ApiLink type="NoBlanksConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addNoBlanksCondition" label="AddNoBlanksCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor da célula estar definido.
- <ApiLink type="NoErrorsConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addNoErrorsCondition" label="AddNoErrorsCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor da célula ser válido.
- <ApiLink type="OperatorConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addOperatorCondition" label="AddOperatorCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor da célula atender aos critérios definidos por um operador lógico.
- <ApiLink type="RankConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addRankCondition" label="AddRankCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor da célula estar entre os primeiros ou últimos valores do intervalo associado.
- <ApiLink type="TextOperatorConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addTextCondition" label="AddTextCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor de texto da célula atender aos critérios definidos por uma string e por um valor <ApiLink type="FormatConditionTextOperator" /> informados nos parâmetros do método <ApiLink type="ConditionalFormatCollection" member="addTextCondition" label="AddTextCondition" />.
- <ApiLink type="UniqueConditionalFormat" />: adicionada pelo método <ApiLink type="ConditionalFormatCollection" member="addUniqueCondition" label="AddUniqueCondition" />, esta formatação condicional expõe propriedades que controlam os atributos visuais de uma célula da planilha com base em o valor da célula ser único no intervalo associado.

## Trecho de código

O trecho de código a seguir demonstra como adicionar cada uma das formatações condicionais a uma planilha no controle <ApiLink type="Spreadsheet" />:

```ts
let sheet = this.spreadsheet.activeWorksheet;

let red = new Color();
red.colorString = "#ff0000";

let blue = new Color();
blue.colorString = "#0000ff";

let green = new Color();
green.colorString = "#00ff00";

let gray = new Color();
gray.colorString = "#d3d3d3";

let avgFormat = sheet.conditionalFormats().addAverageCondition("A1:A10", FormatConditionAboveBelow.AboveAverage);
avgFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(red);

let blanksFormat = sheet.conditionalFormats().addBlanksCondition("B1:B10");
blanksFormat.cellFormat.fill = CellFill.createSolidFill(new WorkbookColorInfo(gray));

let colorFormat = sheet.conditionalFormats().addColorScaleCondition("C1:C10", ColorScaleType.ThreeColor);
colorFormat.minimumThreshold.formatColor = new WorkbookColorInfo(red);
colorFormat.midpointThreshold.formatColor = new WorkbookColorInfo(blue);
colorFormat.maximumThreshold.formatColor = new WorkbookColorInfo(green);

let dataBarFormat = sheet.conditionalFormats().addDataBarCondition("D1:D10");

let dateTimeFormat = sheet.conditionalFormats().addDateTimeCondition("E1:E10", FormatConditionTimePeriod.NextWeek);
dateTimeFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(red);

let duplicateFormat = sheet.conditionalFormats().addDuplicateCondition("F1:F10");
duplicateFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(blue);

let errorFormat = sheet.conditionalFormats().addErrorsCondition("G1:G10");
errorFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(green);

let formulaFormat = sheet.conditionalFormats().addFormulaCondition("H1:H10", "=H1>2");
formulaFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(red);

let iconFormat = sheet.conditionalFormats().addIconSetCondition("I1:I10", FormatConditionIconSet.IconSet3TrafficLights1);

let noBlanksFormat = sheet.conditionalFormats().addNoBlanksCondition("J1:J10");
noBlanksFormat.cellFormat.fill = CellFill.createSolidFill(new WorkbookColorInfo(gray));

let noErrorFormat = sheet.conditionalFormats().addErrorsCondition("K1:K10");
noErrorFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(red);

let operatorFormat = sheet.conditionalFormats().addOperatorCondition("L1:L10", FormatConditionOperator.Greater);
operatorFormat.setOperand1(500);
operatorFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(blue);

let rankFormat = sheet.conditionalFormats().addRankCondition("M1:M10", FormatConditionTopBottom.Top, 5);
rankFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(green);

let textFormat = sheet.conditionalFormats().addTextCondition("N1:N10", "A", FormatConditionTextOperator.Contains);
textFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(red);

let uniqueFormat = sheet.conditionalFormats().addUniqueCondition("O1:O10");
uniqueFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(blue);
```
