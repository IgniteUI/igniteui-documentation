# Mapa de polilinhas geográfico de {Platform}

No componente de mapa {Platform}, você pode usar o `GeographicPolylineSeries` para exibir dados geoespaciais usando polilinhas, em um contexto geográfico. Este tipo de série geográfica é frequentemente usado para renderizar estradas ou conexões entre localizações geográficas, como cidades ou aeroportos.

## {Platform} Exemplo de mapa de polilinhas geográfico


<Sample src="/maps/geo-map/type-shape-polyline-series" height={500} alt="{Platform} Exemplo de uso da série de polilinhas de forma" />




O `GeographicPolylineSeries` funciona de forma muito semelhante ao `GeographicShapeSeries`, exceto que os dados geoespaciais são renderizados com polilinhas, em vez de polígonos.

## Requisitos de dados
De forma semelhante a outros tipos de séries geográficas no controle, o `GeographicPolylineSeries` tem a propriedade `dataSource`, que pode ser vinculada a um array de objetos. Além disso, cada item de dados desse objeto deve ter uma coluna de dados que armazena uma ou várias formas, usando um array de arrays de objetos com valores x e y que representam localizações geográficas. Essa coluna de dados é então mapeada para a propriedade `ShapeMemberPath`. O `GeographicPolylineSeries` usa os pontos dessa coluna de dados mapeada para plotar polilinhas no controle.

Quando as formas vêm diretamente de um arquivo de forma e não precisam ser remodeladas antes, a série pode receber um `ShapefileDataSource` próprio, que lê os pontos dos registros por conta própria. É isso que o código abaixo faz; o [Vinculando arquivos de forma](./geo-map-binding-shp-file.mdx) aborda o outro caminho, em que um manipulador transforma cada registro em um objeto seu e mapeia o `ShapeMemberPath` para ele.

## Trecho de código
O código a seguir dá ao `GeographicPolylineSeries` um `ShapefileDataSource` apontando para um arquivo de forma de estradas americanas, e desenha todas as estradas contidas nele.

```json-snippet source="/maps/geo-map/type-shape-polyline-series"
{
    "type": "GeographicMap",
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicPolylineSeries",
            "name": "GeographicPolylineSeries1",
            "shapefileDataSource": {
                "type": "ShapeDataSource",
                "shapefileSource": "https://static.infragistics.com/xplatform/shapes/AmericanRoads.shp",
                "databaseSource": "https://static.infragistics.com/xplatform/shapes/AmericanRoads.dbf"
            },
            "outline": "Red"
        }
    ]
}
```
