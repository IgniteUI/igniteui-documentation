# Visão geral do {Platform} Linear Progress

O componente {ProductName} Linear Progress Indicator oferece um indicador visual do processo de uma aplicação conforme ele muda. O indicador <ApiLink pkg="core" type="LinearProgress" /> atualiza a sua aparência conforme o seu estado muda. Além disso, você pode estilizar este componente com uma escolha de cores em listras ou em cores sólidas.

### Tipos de progresso

Você pode definir o tipo do seu indicador usando o atributo <ApiLink pkg="core" type="LinearProgress" member="variant" label="Variant" />. Há cinco tipos de indicadores de progresso linear: **primary** (padrão), **error**, **success**, **info** e **warning**.

<PlatformBlock for="React">

```tsx
<IgrLinearProgress value="100" variant="success"></IgrLinearProgress>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-linear-progress value="100" variant="success"></igc-linear-progress>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbLinearProgress Value=100 Variant=@ProgressBaseVariant.Success />
```

</PlatformBlock>

### Progresso indeterminado

Se quiser acompanhar um processo que não é determinado com precisão, você pode definir a propriedade <ApiLink pkg="core" type="LinearProgress" member="indeterminate" label="Indeterminate" />.

### Duração da animação

A propriedade <ApiLink pkg="core" type="LinearProgress" member="animationDuration" label="AnimationDuration" /> é usada para especificar quanto tempo deve durar o ciclo da animação. Ela recebe como valor um número que representa a duração da animação em milissegundos.

<PlatformBlock for="React">

```tsx

```

</PlatformBlock>


</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

```

</PlatformBlock>

### Propriedades de texto

Você pode alinhar o valor padrão usando a propriedade <ApiLink pkg="core" type="LinearProgress" member="labelAlign" label="LabelAlign" />. Os valores permitidos são **top**, **bottom**, **top-start**, **top-end**, **bottom-start** e **bottom-end**.

Para ocultar o rótulo padrão do indicador de progresso, use o atributo <ApiLink pkg="core" type="LinearProgress" member="hideLabel" label="HideLabel" />.

A propriedade <ApiLink pkg="core" type="LinearProgress" member="labelFormat" label="LabelFormat" /> pode ser usada para personalizar o rótulo padrão do <ApiLink pkg="core" type="LinearProgress" />.

## Estilização

O componente <ApiLink pkg="core" type="LinearProgress" /> expõe partes CSS para quase todos os seus elementos internos:

|Nome|Descrição|
|--|--|
| `track`         | A área de trilha do anel de progresso. |
| `fill`          | A área do indicador de progresso. |
| `striped`       | O indicador de progresso listrado. |
| `label`         | O rótulo do indicador de progresso. |
| `value`         | O valor do rótulo do progresso. |
| `indeterminate` | O estado indeterminado do progresso. |
| `primary`       | O estado primary do indicador de progresso. |
| `danger`        | O estado error do indicador de progresso. |
| `warning`       | O estado warning do indicador de progresso. |
| `info`          | O estado info do indicador de progresso. |
| `success`       | O estado success do indicador de progresso. |

Usando essas partes CSS, temos quase controle total sobre a estilização do Linear Progress.

<Sample src="/inputs/linear-progress-indicator/styling" height={80} alt="Estilização do Linear Progress {Platform}" />


```css
igc-linear-progress::part(track){
  background-color: var(--ig-gray-300)
}

igc-linear-progress::part(fill){
  background-color: var(--ig-primary-300)
}

igc-linear-progress::part(label){
  color: var(--ig-primary-300)
}
```
