# Visão geral do Circular Progress {Platform}

O componente {ProductName} Circular Progress Indicator oferece um indicador visual do processo de uma aplicação conforme ele muda. O indicador circular atualiza a sua aparência conforme o seu estado muda.

## Uso

<PlatformBlock for="WebComponents">

### Tipos de progresso

Você pode definir o tipo do seu indicador usando o atributo <ApiLink pkg="core" type="CircularProgress" member="variant" label="Variant" />. Há cinco tipos de indicadores de progresso circular: **primary** (padrão), **error**, **success**, **info** e **warning**.

<PlatformBlock for="React">

```tsx
<IgrCircularProgress value="100" variant="success"></IgrCircularProgress>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-circular-progress value="100" variant="success"></igc-circular-progress>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCircularProgress Value=100 Variant=@ProgressBaseVariant.Success  />
```

</PlatformBlock>

### Progresso indeterminado

Se quiser acompanhar um processo que não é determinado com precisão, você pode definir a propriedade <ApiLink pkg="core" type="CircularProgress" member="indeterminate" label="Indeterminate" />. Além disso, você pode ocultar o rótulo padrão do {ProductName} <ApiLink pkg="core" type="CircularProgress" /> definindo a propriedade <ApiLink pkg="core" type="CircularProgress" member="hideLabel" label="HideLabel" />, e personalizar o rótulo padrão do indicador de progresso pela propriedade exposta <ApiLink pkg="core" type="CircularProgress" member="labelFormat" label="LabelFormat" />.

```tsx
<IgrCircularProgress value="100" indeterminate="true"></IgrCircularProgress>
```

</PlatformBlock>

</PlatformBlock>

### Progresso com gradiente

A barra de progresso pode ser personalizada para usar um gradiente de cores em vez de uma cor sólida, usando o slot `gradient` e o componente <ApiLink pkg="core" type="CircularGradient" />, que define os pontos de parada do gradiente.

<Sample src="/inputs/circular-progress-indicator/dynamic" height={200} alt="Exemplo dinâmico de Circular Progress {Platform}" />

<DocsAside type="info">
Para cada <ApiLink pkg="core" type="CircularGradient" /> definido como slot `gradient` de {ProductName} <ApiLink pkg="core" type="CircularProgress" />, seria criado um elemento [SVG stop](https://developer.mozilla.org/en-US/docs/Web/SVG/Element/stop). Os valores passados como `color`, `offset` e `opacity` seriam definidos como stop-color, offset e stop-opacity do elemento SVG, sem validações adicionais.
</DocsAside>

## Estilização

O componente <ApiLink pkg="core" type="CircularProgress" /> expõe partes CSS para quase todos os seus elementos internos:

|Nome|Descrição|
|--|--|
| `svg`               | O elemento SVG de progresso.                 |
| `gradient_start`     | A cor inicial do gradiente linear do progresso. |
| `gradient_end`       | A cor final do gradiente linear do progresso.   |
| `track`              | A área de trilha do anel de progresso.           |
| `fill`               | A área do indicador de progresso.              |
| `label`              | O rótulo do progresso.                       |
| `value`              | O valor do rótulo do progresso.                 |
| `indeterminate`      | O estado indeterminado do progresso.         |
| `primary`            | O estado primary do indicador de progresso.     |
| `danger`             | O estado error do indicador de progresso.       |
| `warning`            | O estado warning do indicador de progresso.     |
| `info`               | O estado info do indicador de progresso.        |
| `success`            | O estado success do indicador de progresso.     |

Usando essas partes CSS, temos quase controle total sobre a estilização do Circular Progress.

```css

igc-circular-progress {
  margin: 20px;
  --diameter: 50px;
}

igc-circular-progress::part(gradient_end),
igc-circular-progress::part(gradient_start) {
  stop-color: var(--ig-success-200);
}

igc-circular-progress::part(track) {
  stroke: var(--ig-gray-400);
}

```
