# Dica de ferramenta {Platform}

O componente Tooltip {ProductName} oferece uma forma de exibir um tooltip para um elemento específico. Um tooltip é um popup que exibe informações relacionadas a um elemento, geralmente quando o elemento recebe foco pelo teclado ou quando o mouse passa sobre ele.

### Posicionamento

O <ApiLink pkg="core" type="Tooltip" /> também pode ser posicionado em relação ao seu elemento alvo com facilidade. Basta usar a propriedade <ApiLink pkg="core" type="Tooltip" member="placement" label="Placement" /> junto com uma das <PlatformBlock for="Angular,React,WebComponents"><ApiLink pkg="core" type="PopoverPlacement" /></PlatformBlock><PlatformBlock for="Blazor"><a href="https://staging.infragistics.com/api/blazor/IgniteUI.Blazor.Lite/0.0.1/enums/PopoverPlacement"><code>PopoverPlacement</code></a></PlatformBlock> opções.

Se a propriedade <ApiLink pkg="core" type="Tooltip" member="placement" label="Placement" /> não for definida, o valor padrão é `Bottom`, que posiciona o <ApiLink pkg="core" type="Tooltip" /> abaixo do elemento alvo.

Além disso, você pode tornar o <ApiLink pkg="core" type="Tooltip" /> "fixo" usando a propriedade <ApiLink pkg="core" type="Tooltip" member="sticky" label="Sticky" />, que adiciona um botão de fechar e mantém o <ApiLink pkg="core" type="Tooltip" /> visível até que o usuário o feche manualmente — clicando no botão de fechar ou pressionando a tecla `Esc`. Esse comportamento sobrescreve o comportamento padrão de hover, impedindo que o <ApiLink pkg="core" type="Tooltip" /> desapareça quando o usuário para de passar o mouse sobre o elemento alvo.

O <ApiLink pkg="core" type="Tooltip" /> também inclui um indicador de seta opcional, que pode ser configurado pela propriedade <ApiLink pkg="core" type="Tooltip" member="withArrow" label="WithArrow" />. A seta conecta visualmente o tooltip ao seu elemento âncora, e a sua posição se ajusta automaticamente com base no <ApiLink pkg="core" type="Tooltip" member="placement" label="Placement" /> do tooltip.

<PlatformBlock for="WebComponents">

```html
<igc-button id="target-button">Hover me</igc-button>
<igc-tooltip anchor="target-button" placement="top-start" sticky with-arrow>
  Congrats you've hovered the button!
</igc-tooltip>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton id="target-button">Hover me</IgrButton>
<IgrTooltip anchor="target-button" placement="top-start" sticky withArrow={true}>
  Congrats you have hovered the button!
</IgrTooltip>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbButton id="target-button">Hover me</IgbButton>
<IgbTooltip Anchor="target-button" Placement="PopoverPlacement.TopStart" Sticky="true" DisableArrow="true">
  Congrats you have hovered the button!
</IgbTooltip>
```

</PlatformBlock>

### Gatilhos

Por padrão, o <ApiLink pkg="core" type="Tooltip" /> é acionado somente enquanto o mouse está sobre o elemento alvo. No entanto, você pode alterar esse comportamento usando as propriedades <ApiLink pkg="core" type="Tooltip" member="showTriggers" label="ShowTriggers" /> e <ApiLink pkg="core" type="Tooltip" member="hideTriggers" label="HideTriggers" />, que permitem controlar quando o <ApiLink pkg="core" type="Tooltip" /> aparece e desaparece. Essas propriedades aceitam nomes de eventos como valores — como `click`, `focus` ou `keypress` —, permitindo acionar o <ApiLink pkg="core" type="Tooltip" /> em diferentes cenários.

### Propriedades adicionais

Além das propriedades que já vimos, o componente <ApiLink pkg="core" type="Tooltip" /> oferece várias propriedades adicionais que permitem configurar ainda mais o seu comportamento, a sua posição e a sua aparência.

|Nome|Tipo|Descrição|
|--|--|--|
| <ApiLink pkg="core" type="Tooltip" member="open" label="Open" /> | boolean | Determina se o tooltip está visível. |
| <ApiLink pkg="core" type="Tooltip" member="withArrow" label="WithArrow" /> | boolean | Determina se um indicador de seta deve ser renderizado para o tooltip. |
| <ApiLink pkg="core" type="Tooltip" member="offset" label="Offset" /> | número | Define a distância, em pixels, entre o tooltip e o seu <ApiLink pkg="core" type="Tooltip" member="anchor" label="Anchor" />. |

### Métodos

Além das suas propriedades configuráveis, o <ApiLink pkg="core" type="Tooltip" /> também expõe três métodos que você pode usar:

|Nome|Descrição|
|--|--|
| <ApiLink pkg="core" type="Tooltip" member="show" label="Show" /> | Exibe o tooltip se ele ainda não estiver sendo mostrado. Se um alvo for informado, define o alvo como um <ApiLink pkg="core" type="Tooltip" member="anchor" label="Anchor" /> transitório. |
| <ApiLink pkg="core" type="Tooltip" member="hide" label="Hide" /> | Oculta o tooltip se ele ainda não estiver oculto. |
| <ApiLink pkg="core" type="Tooltip" member="toggle" label="Toggle" /> |  Alterna o tooltip entre os estados mostrado e oculto. |

## Suporte a acessibilidade e ARIA

O <ApiLink pkg="core" type="Tooltip" /> foi construído com acessibilidade em mente e inclui os seguintes atributos ARIA:

- `role` - Quando o tooltip está no seu comportamento padrão, `role="tooltip"` é aplicado. Se a propriedade <ApiLink pkg="core" type="Tooltip" member="sticky" label="Sticky" /> estiver ativada, o papel muda para `status`.
- `inert` - alternado dinamicamente de acordo com a visibilidade. Quando o tooltip está oculto, ele fica inerte.
- `aria-atomic` - definido como true, garantindo que todo o conteúdo do tooltip seja anunciado quando ele muda.
- `aria-live` - definido como polite, indicando aos leitores de tela que as atualizações devem ser anunciadas somente quando o usuário estiver ocioso.

## Estilização

O componente <ApiLink pkg="core" type="Tooltip" /> expõe duas partes CSS que você pode usar para estilização:

|Nome|Descrição|
|--|--|
| `base` | O wrapper base do componente tooltip. |
| `top, right, bottom, left ...` | A área que contém a seta do tooltip. O nome da parte corresponde ao valor da propriedade de posicionamento do tooltip. |

```css
igc-tooltip::part(base) {
  background-color: var(--ig-primary-500);
  color: var(--ig-primary-500-contrast);
}

igc-tooltip::part(bottom) {
  border-bottom-color: var(--ig-primary-500);
}
```
