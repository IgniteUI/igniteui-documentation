# Radio Group

O Radio {Platform} e o Radio Group são componentes que permitem que os usuários selecionem exatamente uma opção de um conjunto de opções mutuamente exclusivas. Cada radio button representa uma opção, e o Radio Group dispõe os radio buttons em um layout vertical ou horizontal.

## Primeiros passos

Para usar o Radio {Platform} e o Radio Group, siga o <PlatformBlock for="Angular">[{ProductName} Primeiros passos](../general/getting-started.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[{ProductName} Primeiros passos](../general-getting-started.mdx)</PlatformBlock> tópico para a configuração básica do projeto e, em seguida, importe ou registre os componentes para a sua plataforma de destino.

<PlatformBlock for="WebComponents">

Importe o <ApiLink pkg="core" type="Radio" /> e o <ApiLink pkg="core" type="RadioGroup" />, um tema e registre os componentes:

```ts
import { defineComponents, IgcRadioComponent, IgcRadioGroupComponent } from 'igniteui-webcomponents';
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcRadioComponent, IgcRadioGroupComponent);
```

</PlatformBlock>

<PlatformBlock for="React">

Importe os wrappers do <ApiLink pkg="core" type="Radio" /> e do <ApiLink pkg="core" type="RadioGroup" /> e um tema:

```tsx
import { IgrRadio, IgrRadioGroup } from 'igniteui-react';
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Registre os serviços de {ProductName}:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

Registrar o <ApiLink pkg="core" type="RadioGroupModule" />, o módulo de recursos do cliente do <ApiLink pkg="core" type="RadioGroup" />, é **opcional**: o componente carrega seus recursos na primeira vez em que é renderizado. Listá-lo em `builder.Services.AddIgniteUIBlazor(typeof(IgbRadioGroupModule))` pode ser usado para pré-carregar recursos ou para oferecer suporte a elementos criados apenas no cliente; ele também registra os elementos de rádio dentro do grupo. Um <ApiLink pkg="core" type="Radio" /> usado sozinho tem o seu próprio módulo, <ApiLink pkg="core" type="RadioModule" /> (veja [Módulos de componente](../general-getting-started.mdx#módulos-do-componente)).

Em seguida, adicione a folha de estilos do tema à sua página host:

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```

</PlatformBlock>

<PlatformBlock for="Angular">

Importe o componente <ApiLink type="Radio" /> e a diretiva <ApiLink type="RadioGroupDirective" />:

```ts
import { IgxRadioComponent, IgxRadioGroupDirective } from 'igniteui-angular/radio';
```

Adicione ambos à coleção `imports` do seu componente, ou adicione a coleção `IGX_RADIO_GROUP_DIRECTIVES`, que os contém, e então use os elementos `igx-radio-group` e `igx-radio` no seu template.

</PlatformBlock>

Após o registro, coloque os componentes Radio {Platform} dentro de um Radio Group e dê ao grupo um `name`, para que os usuários possam selecionar apenas uma das opções. Defina `value` em cada radio button para identificar a opção selecionada.

```html

  <igc-radio value="banana">Banana</igc-radio>
  <igc-radio value="mango">Mango</igc-radio>
</igc-radio-group>
```

</PlatformBlock>

</PlatformBlock>

## Uso

### Layout

O Radio {Platform} posiciona o seu rótulo depois do controle de rádio por padrão. Defina a propriedade <ApiLink pkg="core" type="Radio" member="labelPosition" label="labelPosition" /> como `before` para posicionar o rótulo antes do controle. Em um Radio Group vertical, os radio buttons com o rótulo antes do controle se alinham ao fim do grupo.

<PlatformBlock for="React,WebComponents,Blazor">

Posicione os radio buttons como filhos diretos do Radio Group. Radio buttons dentro de um elemento wrapper não fazem parte do grupo, e o grupo não os dispõe.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-radio-group name="color">
  <igc-radio value="yellow" label-position="before" checked>Yellow</igc-radio>
  <igc-radio value="orange" label-position="before">Orange</igc-radio>
</igc-radio-group>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrRadioGroup name="color">
  <IgrRadio value="yellow" labelPosition="before" checked={true}>Yellow</IgrRadio>
  <IgrRadio value="orange" labelPosition="before">Orange</IgrRadio>
</IgrRadioGroup>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbRadioGroup name="color">
    <IgbRadio Value="yellow" LabelPosition="ToggleLabelPosition.Before" Checked="true">Yellow</IgbRadio>
    <IgbRadio Value="orange" LabelPosition="ToggleLabelPosition.Before">Orange</IgbRadio>
</IgbRadioGroup>
```

</PlatformBlock>

<PlatformBlock for="Angular">

```html
<igx-radio-group name="color" alignment="vertical" value="yellow">
  <igx-radio value="yellow" labelPosition="before">Yellow</igx-radio>
  <igx-radio value="orange" labelPosition="before">Orange</igx-radio>
</igx-radio-group>
```

</PlatformBlock>

<PlatformBlock for="Angular,React,WebComponents">

Um radio button também pode ser rotulado por um elemento externo a ele. Referencie o elemento com `aria-labelledby` quando precisar de controle total sobre onde o rótulo fica e como ele se parece.

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

</PlatformBlock>

### Formulários

O Radio {Platform} envia o `value` do radio button selecionado sob o `name` do grupo. Defina a propriedade <ApiLink pkg="core" type="Radio" member="required" label="required" /> em um radio button do grupo para exigir uma seleção antes de o formulário ser enviado.

<PlatformBlock for="React,WebComponents,Blazor">

Para mostrar uma mensagem quando a seleção estiver ausente, coloque-a no slot `value-missing` de um radio button. A seleção obrigatória torna inválidos todos os radio buttons do grupo; por isso, coloque a mensagem no último radio button para exibi-la abaixo do grupo.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<form>
  <igc-radio-group name="fruit">
    <igc-radio value="apple" required>Apple</igc-radio>
    <igc-radio value="banana">Banana</igc-radio>
    <igc-radio value="orange">
      Orange
      <span slot="value-missing">Choose a fruit.</span>
    </igc-radio>
  </igc-radio-group>
</form>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<form>
  <IgrRadioGroup name="fruit">
    <IgrRadio value="apple" required={true}>Apple</IgrRadio>
    <IgrRadio value="banana">Banana</IgrRadio>
    <IgrRadio value="orange">
      Orange
      <span slot="value-missing">Choose a fruit.</span>
    </IgrRadio>
  </IgrRadioGroup>
</form>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbRadioGroup name="fruit">
    <IgbRadio Value="apple" Required="true">Apple</IgbRadio>
    <IgbRadio Value="banana">Banana</IgbRadio>
    <IgbRadio Value="orange">
        Orange
        <span slot="value-missing">Choose a fruit.</span>
    </IgbRadio>
</IgbRadioGroup>
```

<DocsAside type="warning" title="Warning">
O componente <ApiLink pkg="core" type="Radio" /> não funciona com um elemento `<form>` HTML padrão no Blazor. Use o componente `EditForm` do Blazor no lugar.
</DocsAside>

</PlatformBlock>

<PlatformBlock for="Angular">

O Radio Group funciona com formulários orientados por template e reativos. Vincule o valor selecionado com `ngModel` ou com um controle de formulário em `igx-radio-group`:

```html
<form [formGroup]="fruitsForm">
  <igx-radio-group name="fruit" alignment="vertical" formControlName="favoriteFruit">
    <igx-radio value="apple">Apple</igx-radio>
    <igx-radio value="banana">Banana</igx-radio>
    <igx-radio value="orange">Orange</igx-radio>
  </igx-radio-group>
</form>
```

</PlatformBlock>

### Faça/Não faça

Ao estender um Radio Group com itens adicionais, certifique-se de que eles estejam alinhados de forma consistente e formem uma única coluna. Evite layouts em várias colunas, bem como situações em que mais de um elemento Radio esteja ligado ao mesmo tempo.

## Acessibilidade

O Radio {Platform} renderiza um input de rádio nativo; por isso, as tecnologias assistivas anunciam cada radio button com a sua função, o seu rótulo e o seu estado marcado.

### Interação por teclado

O Radio Group {Platform} move o foco e a seleção entre os seus radio buttons habilitados com as teclas de seta. Radio buttons desabilitados são ignorados.

| Tecla | Ação |
| --- | --- |
| Tab / Shift+Tab | Move o foco para dentro ou para fora do Radio Group. |
| Seta para baixo / Seta para a direita | Move o foco para o próximo radio button habilitado e o liga. A partir do último radio button, move para o primeiro. Em layouts da direita para a esquerda, Seta para a direita move para o radio button anterior. |
| Seta para cima / Seta para a esquerda | Move o foco para o radio button habilitado anterior e o liga. A partir do primeiro radio button, move para o último. Em layouts da direita para a esquerda, Seta para a esquerda move para o próximo radio button. |
| Space | Liga o radio button com foco. |
<PlatformBlock for="React,WebComponents,Blazor">| Enter | Envia o formulário que contém o radio button. |</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Quando um radio button do grupo está ligado, ele é a única parada de tabulação do grupo. Quando nenhum dos radio buttons está ligado, cada um deles é uma parada de tabulação.

</PlatformBlock>

<PlatformBlock for="Blazor">

No `IgniteUI.Blazor` 26.1, limpar a seleção no código não deixa nenhuma parada de tabulação no grupo. Veja [Limitações conhecidas](#limitações-conhecidas).

</PlatformBlock>

### Leitores de tela / ARIA

- Cada Radio {Platform} renderiza um `<input type="radio">` nativo, que expõe a função de rádio, o estado marcado e os estados desabilitado e obrigatório.<PlatformBlock for="Angular"> O input também define `aria-invalid` a partir da propriedade `invalid`.</PlatformBlock>
- O conteúdo do rótulo do radio button é o seu nome acessível.<PlatformBlock for="Angular,React,WebComponents"> Quando o rótulo estiver fora do componente, conecte-o com `aria-labelledby`.</PlatformBlock>

<PlatformBlock for="React,WebComponents">

- O Radio Group renderiza a função `radiogroup` e define `aria-orientation` a partir da sua `alignment`.

</PlatformBlock>

<PlatformBlock for="Blazor">

- O Radio Group renderiza a função `radiogroup`. Na versão `IgniteUI.Blazor` 26.1, ele não define `aria-orientation`.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

- Dê ao Radio Group um nome acessível, por exemplo, com `aria-labelledby` apontando para a pergunta que ele responde.

</PlatformBlock>

<PlatformBlock for="Angular">

- O elemento `igx-radio-group` não renderiza a função `radiogroup`. Adicione `role="radiogroup"` e um nome acessível, por exemplo com `aria-labelledby`, quando o grupo precisar ser anunciado como uma única pergunta.

</PlatformBlock>

Verifique o Radio {Platform} e o Radio Group renderizados em relação aos requisitos de acessibilidade da sua aplicação.

## Limitações conhecidas

</PlatformBlock>

<PlatformBlock for="Blazor">

O Radio {Platform} e o Radio Group têm as seguintes limitações conhecidas:

- O Radio não funciona com um elemento `<form>` HTML padrão no Blazor. Use o componente `EditForm` do Blazor no lugar.
- Na versão `IgniteUI.Blazor` 26.1, um radio button não pode ser rotulado por um elemento externo a ele. `IgbRadio` não tem o parâmetro `AriaLabelledBy`, e um atributo `aria-labelledby` não dá ao radio button um nome acessível. Coloque o texto do rótulo dentro do radio button.
- Na versão `IgniteUI.Blazor` 26.1, limpar a seleção no código tira todos os radio buttons da ordem de tabulação. Usuários de teclado não conseguem chegar ao grupo até que um clique do mouse ou o seu código ligue novamente um dos seus radio buttons.

</PlatformBlock>

<PlatformBlock for="Angular">

O Radio {Platform} e o Radio Group têm a seguinte limitação conhecida:

- O elemento `igx-radio-group` não renderiza a função `radiogroup`. Adicione a função e um nome acessível ao elemento por conta própria.

</PlatformBlock>
