## Dependências

Registre os serviços de {ProductName}:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

Registrar o <ApiLink pkg="core" type="InputModule" />, o módulo de recursos do cliente do componente Input, é **opcional**: o componente carrega seus recursos na primeira vez em que é renderizado. Listá-lo em `builder.Services.AddIgniteUIBlazor(typeof(IgbInputModule))` pode ser usado para pré-carregar recursos ou para oferecer suporte a elementos criados apenas no cliente (veja [Módulos de componente](../general-getting-started.mdx#módulos-do-componente)).

</PlatformBlock>

O seguinte deve ser colocado na página host da aplicação (**wwwroot/index.html** em uma aplicação Blazor WebAssembly independente ou Blazor Hybrid, **Pages/_Host.cshtml** em uma aplicação Blazor Server, **Components/App.razor** em uma aplicação Blazor Web App):

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```

## Prefixo e sufixo

Com os slots `prefix` e `suffix`, podemos adicionar conteúdos diferentes antes e depois do conteúdo principal do <ApiLink pkg="core" type="Input" />. ## Estilização

O componente <ApiLink pkg="core" type="Input" /> expõe partes CSS para quase todos os seus elementos internos. A tabela a seguir lista todas as partes CSS expostas:

|Nome|Descrição|
|--|--|
| `container` | O wrapper principal que contém todos os elementos de input principais. |
| `input` | O elemento de input nativo. |
| `label` | O elemento de rótulo nativo. |
| `prefix` | O wrapper do prefixo. |
| `suffix` | O wrapper do sufixo. |
| `helper-text` | O wrapper do texto de ajuda. |

```scss
igc-input::part(input) {
  background-color: var(--ig-primary-100);
  border-color: var(--ig-secondary-500);
  box-shadow: none;
}

igc-input::part(label) {
  color: var(--ig-gray-700);
}

igc-input::part(prefix),
igc-input::part(suffix) {
  color: var(--ig-primary-600-contrast);
  background-color: var(--ig-primary-600);
  border-color: var(--ig-secondary-600);
}
```
