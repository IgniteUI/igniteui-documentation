# Visão geral do Color Editor {Platform} <Badge variant="preview" />
O Color Editor {ProductName} é um componente de seletor de cor leve. O Color Editor pode ser aberto clicando no ícone de pincel. Os valores rgba e hex da cor desejada podem ser obtidos na parte inferior. Esses valores são atualizados quando os três controles deslizantes são modificados. A caixa central é projetada para ajustar a saturação e o brilho, junto com dois controles deslizantes adjacentes para ajustar os valores de rgb e de luminância. O valor de rgb varia entre 1 e 255. O valor de luminosidade varia entre 0 e 1.

## Uso

A forma mais simples de começar a usar o `ColorEditor` é a seguinte:


```json-snippet source="/inputs/color-editor/overview" code="allCode"
{
    "type": "ColorEditor",
    "name": "colorEditor"
}
```

## Vinculação a eventos

O componente Color Editor dispara os seguintes eventos:

- valueChanged
- valueChanging

```json-snippet source="/inputs/color-editor/overview" code="allCode"
{
    "type": "ColorEditor",
    "name": "colorEditor",
    "valueChangedRef": "ColorEditorValueChanged"
}
```

O handler recebe o editor e um `ColorEditorPanelSelectedValueChangedEventArgs`, cujo `newValue` carrega a cor que acabou de ser escolhida:

```json-snippet source="/inputs/color-editor/overview" channel="handlersImports...handler"
{
    "type": "ColorEditor",
    "name": "colorEditor",
    "valueChangedRef": "ColorEditorValueChanged",
    "$valueChangedRef": "+doc:handler"
}
```
