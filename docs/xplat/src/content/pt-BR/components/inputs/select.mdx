# Select {Platform}

O componente Select {ProductName} permite uma única seleção em uma lista de itens, colocada em um dropdown. Este controle de formulário oferece uma navegação rápida pela lista de itens, incluindo a seleção, com base na correspondência de um ou mais caracteres.

### Select

O componente <ApiLink pkg="core" type="Select" /> pode ser usado dentro de um componente `Form`; por isso, ele expõe uma propriedade <ApiLink pkg="core" type="Select" member="name" label="Name" /> para ser registrada.

Ele também tem as propriedades <ApiLink pkg="core" type="Select" member="label" label="Label" /> e <ApiLink pkg="core" type="Select" member="placeholder" label="Placeholder" />. A propriedade <ApiLink pkg="core" type="Select" member="outlined" label="Outlined" /> serve somente para fins de estilização, no caso do tema Material.

Além do slot padrão, o componente oferece outros slots, incluindo `header`, `footer`, `helper-text`, `prefix`, `suffix` e `toggle-icon`. Ao colocar conteúdo nos slots, recomendamos usar um elemento `<span>` para texto simples, símbolos ou emojis, e um componente [`<igc-icon>`](../layouts/icon.mdx) para ícones.

O tamanho do componente pode ser alterado usando a variável CSS `--ig-size`.

### Item

O componente <ApiLink pkg="core" type="SelectItem" /> permite que os usuários especifiquem declarativamente uma lista de opções usada pelo controle <ApiLink pkg="core" type="Select" />. Cada item fornece uma propriedade <ApiLink pkg="core" type="SelectItem" member="value" label="Value" /> que representa o dado que ele carrega ao ser selecionado. O <ApiLink pkg="core" type="SelectItem" /> tem um slot padrão que permite especificar o conteúdo de texto do item. Esse conteúdo de texto será usado como valor quando a propriedade <ApiLink pkg="core" type="SelectItem" member="value" label="Value" /> não estiver presente no <ApiLink pkg="core" type="SelectItem" />.

Você também pode fornecer conteúdo personalizado a ser renderizado antes ou depois do conteúdo do <ApiLink pkg="core" type="SelectItem" /> usando os slots `prefix` e `suffix`. Assim como no componente <ApiLink pkg="core" type="Select" />, recomendamos usar um elemento `<span>` ao adicionar texto simples, símbolos ou emojis, e um componente [`<igc-icon>`](../layouts/icon.mdx) ao adicionar ícones aos slots `prefix` e `suffix`.

Você pode predefinir um item selecionado definindo a propriedade <ApiLink pkg="core" type="SelectItem" member="selected" label="Selected" />. Também pode desabilitar alguns ou todos os itens por meio da propriedade <ApiLink pkg="core" type="SelectItem" member="disabled" label="Disabled" />.

### Grupo

Vários <ApiLink pkg="core" type="SelectItem" />s podem ser colocados entre os colchetes de abertura e de fechamento de um componente <ApiLink pkg="core" type="SelectGroup" />, para que os usuários os vejam agrupados visualmente. O <ApiLink pkg="core" type="SelectGroup" /> pode ser rotulado pelo seu slot `label` e desabilitado pela sua propriedade <ApiLink pkg="core" type="SelectGroup" member="disabled" label="Disabled" />. Recomendamos usar um elemento `<span>` para o slot `label`.

<DocsAside type="info">
Tenha em mente que, se um grupo do select estiver desabilitado, você não poderá habilitar itens separados dele.
</DocsAside>

## Validação

Além disso, o <ApiLink pkg="core" type="Select" /> oferece suporte à maioria das propriedades do <ApiLink pkg="core" type="Input" />, como <ApiLink pkg="core" type="Select" member="required" label="Required" />, <ApiLink pkg="core" type="Select" member="disabled" label="Disabled" />, <ApiLink pkg="core" type="Select" member="autofocus" label="Autofocus" /> etc. O componente também expõe um método vinculado à sua validação:

- `reportValidity` - verifica a validade e dá foco ao componente se ele for inválido.

## Navegação pelo teclado

Quando o select está com foco e a lista de opções **não está visível**:

- Abra o <ApiLink pkg="core" type="Input" member="select" label="Select" /> usando a combinação <kbd>ALT</kbd> + <kbd>↑</kbd> <kbd>↓</kbd> ou clicando na tecla <kbd>SPACE</kbd> ou <kbd>ENTER</kbd>.
- Feche o <ApiLink pkg="core" type="Input" member="select" label="Select" /> usando a combinação <kbd>ALT</kbd> + <kbd>↑</kbd> ou <kbd>↓</kbd>, ou qualquer uma das teclas <kbd>ENTER</kbd>, <kbd>SPACE</kbd>, <kbd>ESC</kbd> ou <ApiLink pkg="core" type="Tab" />.
- Usar as teclas <kbd>←</kbd> <kbd>→</kbd> seleciona o item anterior da lista.
- Usar as teclas <kbd>↑</kbd> <kbd>↓</kbd> seleciona o próximo item da lista.
- Usar as teclas <kbd>HOME</kbd> ou <kbd>END</kbd> seleciona o primeiro ou o último item da lista.
- Digitar caracteres consulta a lista de itens e seleciona o que mais se aproxima da entrada atual do usuário.

Quando o select está com foco e a lista de opções está **visível**:

- Usar as teclas <kbd>ENTER</kbd> ou <kbd>SPACE</kbd> seleciona um item e fecha a lista.
- Usar as teclas <kbd>←</kbd> <kbd>→</kbd> ativa o item anterior da lista.
- Usar as teclas <kbd>↑</kbd> <kbd>↓</kbd> ativa o próximo item da lista.
- Usar as teclas <kbd>HOME</kbd> ou <kbd>END</kbd> ativa o primeiro ou o último item da lista.

<DocsAside type="info">
O componente <ApiLink pkg="core" type="Input" member="select" label="Select" /> oferece suporte apenas à seleção **única** de itens.
</DocsAside>

## Estilização

Você pode alterar a aparência do componente {ProductName} <ApiLink pkg="core" type="Select" /> e dos seus itens, usando as partes CSS expostas listadas abaixo:

**Componente Select**

| Nome da parte | Descrição |
| ---------|------------ |
| `input` | O igc-input encapsulado. |
| `label` | O rótulo de texto encapsulado. |
| `list` | Um wrapper que contém a lista de opções. |
| `prefix`  | Um wrapper de prefixo que renderiza conteúdo antes do input. |
| `suffix` | Um wrapper de sufixo que renderiza conteúdo depois do input. |
| `toggle-icon` | Um wrapper do ícone de alternância que renderiza conteúdo dentro do wrapper de sufixo. |
| `helper-text` | Um wrapper do texto de ajuda que renderiza conteúdo abaixo do input. |

**Componente Select Item**

| Nome da parte | Descrição |
| ---------|------------ |
| `content` | O wrapper principal que contém o conteúdo de texto de um item. |
| `prefix`  | Um wrapper de prefixo que renderiza conteúdo antes do wrapper principal. |
| `suffix` | Um wrapper de sufixo que renderiza conteúdo depois do wrapper principal. |

**Componente Select Group**

| Nome da parte | Descrição |
| ---------|------------ |
| `label` | Um wrapper de rótulo que renderiza conteúdo acima dos itens do grupo do select. |

```css
igc-select::part(base) {
  background: var(--ig-primary-50);
}

igc-select-item[active] {
  background: var(--ig-secondary-300);
}

igc-select::part(input) {
  background-color: var(--ig-primary-50);
}

igc-select::part(prefix),
igc-select::part(suffix) {
  color: var(--ig-secondary-500-contrast);
  background: var(--ig-secondary-500);
}
```
