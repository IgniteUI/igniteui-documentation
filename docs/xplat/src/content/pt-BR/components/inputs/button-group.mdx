# Componente Button Group

<PlatformBlock for="Angular">
O componente Button Group {Platform} é usado para organizar botões com a diretiva <ApiLink type="IgxButtonDirective" label="IgxButton" /> em grupos de botões estilizados, com alinhamento horizontal/vertical, seleção única/múltipla e alternância.
</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">
O componente Button Group {Platform} é usado para organizar <ApiLink pkg="core" type="ToggleButton" />s em grupos de botões estilizados, com alinhamento horizontal/vertical, seleção única/múltipla e alternância.
</PlatformBlock>

## Anatomia

O Button Group {Platform} organiza botões de alternância relacionados em um único grupo, com um contêiner compartilhado e itens de botão individuais.

O Button Group {Platform} contém botões de alternância, e cada botão pode conter um ícone e um rótulo.

```text
Button Group
└── Toggle Button
    ├── Icon
    └── Label
```

### Seleção
Para configurar a seleção do Button Group {ProductName}, use a propriedade de seleção específica da plataforma.

<PlatformBlock for="Angular">
Para {Platform}, use a propriedade <ApiLink pkg="core" type="ButtonGroup" member="selectionMode" label="selectionMode" />. Os modos disponíveis são:
</PlatformBlock>

<PlatformBlock for="React,WebComponents">
Para {Platform}, use a propriedade <ApiLink pkg="core" type="ButtonGroup" member="selection" label="selection" />. Os modos disponíveis são:
</PlatformBlock>

<PlatformBlock for="Blazor">
Para {Platform}, use a propriedade <ApiLink pkg="IgniteUI.Blazor" type="IgbButtonGroup" member="selection" label="selection" />. Os modos disponíveis são:
</PlatformBlock>

- **single** - modo de seleção padrão do grupo de botões. Um único botão pode ser selecionado/desmarcado pelo usuário.
- **single-required** - imita o comportamento de um grupo de rádio. Apenas um botão pode ser selecionado e, após a seleção inicial, a desmarcação não é possível pela interação do usuário.
- **multiple** - vários botões do grupo podem ser selecionados e desmarcados.

### Botões de alternância personalizados

<PlatformBlock for="Angular">

Para o Angular, use o input `values` para fornecer um array de botões personalizados. Cada item pode definir propriedades como `label`, `icon`, `selected`, `disabled` e `togglable`.

Defina os valores dos botões na classe do componente:

```ts
interface IButton {
    label?: string;
    icon?: string;
    disabled?: boolean;
    togglable?: boolean;
    selected?: boolean;
    color?: string;
}

public bordersButtons: IButton[] = [
    { icon: 'border_top', selected: true },
    { icon: 'border_right' },
    { icon: 'border_bottom' },
    { icon: 'border_left' }
];
```

```html
<igx-buttongroup [selectionMode]="'multi'" [values]="bordersButtons"></igx-buttongroup>
```

## Acessibilidade

O Button Group {Platform} organiza Toggle Buttons relacionados e expõe o estado selecionado e o estado desabilitado de cada botão.

### Interação por teclado

O Button Group delega a interação por teclado aos Toggle Buttons que ele contém. Cada Toggle Button renderiza um botão nativo, então o comportamento padrão de teclado de botões ativa o item com foco e atualiza sua seleção de acordo com o modo de seleção configurado.

| Tecla | Ação |
| --- | --- |
| Tab / Shift+Tab | Move o foco para o Toggle Button habilitado seguinte ou anterior do grupo. |
| Enter / Space | Ativa o Toggle Button com foco e o seleciona ou desmarca de acordo com o modo de seleção configurado. |

Quando o Button Group está desabilitado, ele desabilita os Toggle Buttons que contém, para que não sejam interativos por teclado.

### Leitores de tela / ARIA

O Button Group expõe uma relação de grupo, e cada Toggle Button expõe seu estado por meio da semântica nativa de botão.

<PlatformBlock for="WebComponents, React, Blazor">

- O contêiner do grupo usa `role="group"` e reflete o estado desabilitado do grupo por meio de `aria-disabled`.
- Cada Toggle Button renderiza um `button` nativo com `aria-pressed` para o estado de seleção e `aria-disabled` para o estado desabilitado.
- O grupo emite `igcSelect` e `igcDeselect` depois que a interação do usuário altera a seleção de um Toggle Button. O detalhe do evento é o `value` do Toggle Button.
- Forneça texto visível ou um `aria-label` para cada Toggle Button, especialmente para controles somente com ícone.

</PlatformBlock>

<PlatformBlock for="Angular">

- O contêiner do grupo usa `role="group"`.
- O Angular atualiza o valor `aria-pressed` de cada botão contido quando a seleção muda e desabilita os botões filhos quando o grupo está desabilitado.
- O grupo emite `selected` e `deselected` quando um usuário altera a seleção. Cada evento fornece o Toggle Button selecionado e o seu índice.
- Forneça texto visível, um `igxLabel` ou outro nome acessível para cada botão somente com ícone.

</PlatformBlock>

### Conformidade de acessibilidade

A Infragistics documenta o suporte de acessibilidade do {ProductName} para as áreas das diretrizes da Seção 508 e da WCAG 2.1 no tópico [Conformidade de acessibilidade](../interactivity/accessibility-compliance.mdx).

| Critério | Como o componente atende |
| -- | -- |
| [2.1.1 Teclado](https://www.w3.org/WAI/WCAG21/Understanding/keyboard) | Cada Toggle Button usa um botão nativo, então o comportamento de seleção do grupo fica disponível pela ativação padrão de botões pelo teclado. |
| [4.1.2 Nome, função, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | O grupo expõe `role="group"`. Os Toggle Buttons expõem a semântica nativa de botão e atualizam `aria-pressed` quando a seleção muda; os Toggle Buttons do xplat também expõem `aria-disabled`. |

Suas responsabilidades:

- Dê a cada Toggle Button um rótulo visível claro ou um nome acessível, especialmente quando ele contém apenas um ícone.

## Solução de problemas

Use esta seção para conferir os limites e as decisões comuns antes de tratar o Button Group como um toggle único, um campo de formulário ou um grupo de ações.

### Por que selectedItems não seleciona um botão?

Garanta que cada Toggle Button tenha um atributo `value` exclusivo. A propriedade `selectedItems` depende desses valores.

### Limitações conhecidas

O Button Group {Platform} coordena os Toggle Buttons, mas não substitui os rótulos individuais ou os nomes acessíveis deles.

- O comportamento de seleção depende do modo `selection` configurado.
- A propriedade `selectedItems` depende de atributos `value` exclusivos nos Toggle Buttons contidos.
- O Button Group não fornece rótulos nem ícones para os seus botões; defina o conteúdo de cada Toggle Button separadamente.

Sim. Cada item de botão pode conter um ícone, um rótulo ou ambos. Mantenha o padrão de conteúdo consistente em todo o grupo e forneça um rótulo visível ou um nome acessível quando um ícone sozinho não explicar a opção.
</FaqItem>

<FaqItem question="Posso exibir um Button Group na vertical?">
Sim. Defina a propriedade de alinhamento específica da plataforma como a opção vertical. Use o alinhamento horizontal quando as opções relacionadas devem ser apresentadas em uma única linha.
</FaqItem>
