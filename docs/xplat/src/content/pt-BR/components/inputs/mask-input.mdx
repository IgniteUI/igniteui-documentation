## Visão geral do {Platform} Mask Input

O {ProductName} Mask Input é um campo de input que permite ao desenvolvedor controlar a entrada do usuário e formatar o valor visível, com base em regras configuráveis. Ele oferece diferentes opções de input e facilidade de uso e de configuração.

### Regras de máscara
A tabela abaixo mostra as regras de máscara integradas suportadas:

| Caractere de máscara | Descrição |
| :--- | :--- |
| 0 | Caractere de dígito [0-9]. A entrada é obrigatória. |
| 9 | Caractere de dígito [0-9]. A entrada é opcional. |
| # | Caractere de dígito [0-9], mais o sinal de adição (+) ou de subtração (-). A entrada é obrigatória. |
| L | Caractere de letra. A entrada é obrigatória. |
| ? | Caractere de letra. A entrada é opcional. |
| A | Caractere alfanumérico (letra ou dígito). A entrada é obrigatória. |
| a | Caractere alfanumérico (letra ou dígito). A entrada é opcional. |
| & | Qualquer caractere do teclado. A entrada é obrigatória. |
| C | Qualquer caractere do teclado. A entrada é opcional. |
| \ | Escapa um sinalizador da máscara e o transforma em um literal. |

Esses sinalizadores também participam da validação do componente; ou seja, o input fica inválido se algumas, mas não todas, as posições obrigatórias forem preenchidas (nenhuma posição preenchida, ou valor vazio, continua sendo responsabilidade de <ApiLink pkg="core" type="MaskInput" member="required" label="required" />). Isso se aplica tanto a inputs independentes quanto a inputs incluídos em um formulário.

### Aplicando a máscara

Aplicar a máscara é bem simples. Basta fornecer um padrão predeterminado à propriedade <ApiLink pkg="core" type="MaskInput" member="mask" label="Mask" /> do input.

No exemplo abaixo, aplicaremos uma máscara para um número de telefone com código de ramal.

<PlatformBlock for="WebComponents">

```html
<igc-mask-input id="mask-input" mask="(####) 00-00-00 Ext. 9999">
    <igc-icon name="phone" slot="prefix"></igc-icon>
    <span slot="helper-text">Phone number</span>
</igc-mask-input>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrMaskInput mask="(####) 00-00-00 Ext. 9999">
    <span slot="prefix">
        <IgrIcon ref={iconPhoneRef} name="phone" collection="material"></IgrIcon>
    </span>
    <span slot="helper-text">Phone number</span>
</IgrMaskInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbMaskInput @ref="MaskInputRef" Mask="(####) 00-00-00 Ext. 9999">
    <IgbIcon IconName="phone" Collection="material" slot="prefix"></IgbIcon>
    <span slot="helper-text">Phone number</span>
</IgbMaskInput>
```

</PlatformBlock>

### Caractere de prompt

Os desenvolvedores podem personalizar o símbolo de prompt usado nas partes não preenchidas da máscara. Para isso, basta fornecer qualquer caractere à propriedade <ApiLink pkg="core" type="MaskInput" member="prompt" label="Prompt" />:

<PlatformBlock for="WebComponents">

```html
<igc-mask-input id="mask-input" mask="(####) 00-00-00 Ext. 9999" prompt="-"></igc-mask-input>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrMaskInput mask="(####) 00-00-00 Ext. 9999" prompt="-"></IgrMaskInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbMaskInput @ref="MaskInputRef" Mask="(####) 00-00-00 Ext. 9999" Prompt="-"></IgbMaskInput>
```

</PlatformBlock>

Por padrão, o caractere `prompt` é o **sublinhado**.

### Placeholder

Os desenvolvedores também podem usar a propriedade <ApiLink pkg="core" type="MaskInput" member="placeholder" label="Placeholder" />, que tem a mesma finalidade do atributo placeholder nativo de input. Se nenhum valor for informado para o placeholder, o valor da máscara é usado em seu lugar.

<PlatformBlock for="WebComponents">

```html
<igc-mask-input id="mask-input" mask="00/00/0000" placeholder="dd/MM/yyyy"></igc-mask-input>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrMaskInput mask="00/00/0000" placeholder="dd/MM/yyyy"></IgrMaskInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbMaskInput @ref="MaskInputRef" Mask="00/00/0000" Placeholder="dd/MM/yyyy"></IgbMaskInput>
```

</PlatformBlock>

### Modos de valor

O <ApiLink pkg="core" type="MaskInput" /> expõe a propriedade <ApiLink pkg="core" type="MaskInput" member="valueMode" label="ValueMode" />, que permite escolher entre as opções `raw` e `withFormatting` para configurar qual valor do input (formatado ou bruto) será vinculado no seu formulário quando uma máscara específica for aplicada. Por padrão, <ApiLink pkg="core" type="MaskInput" member="valueMode" label="ValueMode" /> é definido como `raw`. Experimente você mesmo no exemplo abaixo:

## Estilização

O componente <ApiLink pkg="core" type="MaskInput" /> expõe partes CSS para quase todos os seus elementos internos. A tabela a seguir lista todas as partes CSS expostas:

|Nome|Descrição|
|--|--|
| `container` | O wrapper principal que contém todos os elementos de input principais. |
| `input` | O elemento de input nativo. |
| `label` | O elemento de rótulo nativo. |
| `prefix` | O wrapper do prefixo. |
| `suffix` | O wrapper do sufixo. |
| `helper-text` | O wrapper do texto de ajuda. |

```css
igc-mask-input::part(input) {
  background-color: var(--ig-primary-100);
  border-color: var(--ig-secondary-500);
  box-shadow: none;
}

igc-mask-input::part(input)::placeholder {
  color: var(--ig-primary-100-contrast);
}
```

## Premissas e limitações

- O input mascarado não expõe um atributo _type_, pois é sempre um input do tipo **text**.
- O comportamento de desfazer/refazer não é suportado no momento.
