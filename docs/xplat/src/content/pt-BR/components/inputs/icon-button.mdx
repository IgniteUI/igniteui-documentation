# Visão geral do Icon Button {Platform}

O componente Icon Button {ProductName} permite que os desenvolvedores usem ícones registrados como botões na sua aplicação. Ele herda todos os recursos do componente [icon](../layouts/icon.mdx), mas também acrescenta recursos do componente [button](./button.mdx).

## Uso


<PlatformBlock for="WebComponents">


Primeiro, você precisa instalar o {ProductName} executando o seguinte comando:

```cmd
npm install {PackageWebComponents}
```

Antes de usar o <ApiLink pkg="core" type="IconButton" />, você precisa registrá-lo da seguinte forma:

```ts
import { defineComponents, IgcIconButtonComponent } from "igniteui-webcomponents";
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcIconButtonComponent);
```

Para uma introdução completa ao {ProductName}, leia o tópico [**Primeiros passos**](../general-getting-started.mdx).


</PlatformBlock>



<PlatformBlock for="React">


Primeiro, você precisa instalar o pacote npm correspondente {ProductName} executando o seguinte comando:

```cmd
npm install igniteui-react
```

Em seguida, você precisará importar o <ApiLink pkg="core" type="IconButton" />, o CSS necessário e registrar o seu módulo, assim:

```tsx
import { IgrIconButton } from 'igniteui-react';
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

</PlatformBlock>



<PlatformBlock for="Blazor">


Registre os serviços de {ProductName}:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

O registro de <ApiLink pkg="core" type="IconButtonModule" />, o módulo de recurso do cliente de <ApiLink pkg="core" type="IconButton" />, é **opcional**: o componente carrega seus recursos na primeira vez em que é renderizado. Listá-lo em `builder.Services.AddIgniteUIBlazor(typeof(IgbIconButtonModule))` pode ser usado para pré-carregar recursos ou para dar suporte a elementos criados somente no cliente (veja [Módulos do componente](../general-getting-started.mdx#módulos-do-componente)).

Você também precisará vincular um arquivo CSS adicional para aplicar o estilo ao componente <ApiLink pkg="core" type="IconButton" />. O seguinte deve ser colocado na página host da aplicação (**wwwroot/index.html** em uma aplicação Blazor WebAssembly independente ou Blazor Hybrid, **Pages/_Host.cshtml** em uma aplicação Blazor Server, **Components/App.razor** em uma aplicação Blazor Web App):

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```


</PlatformBlock>

## Exemplos

### Variante

Assim como os componentes de botão comuns, o icon button oferece suporte a várias variantes: `flat` (padrão), `contained` e `outlined`; para alterar o tipo do icon button, defina o atributo <ApiLink pkg="core" type="IconButton" member="variant" label="variant" /> do icon button.

<Sample src="/inputs/icon-button/variant" height={100} alt="Exemplo de Icon Button {Platform}" />



<PlatformBlock for="React">

```tsx
<IgrIconButton name="search" variant="contained"></IgrIconButton>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-icon-button name="search" variant="contained"></igc-icon-button>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton IconName="search" Variant="@IconButtonVariant.Contained" Collection="material" />
```

</PlatformBlock>

### Tamanho

O tamanho do botão pode ser alterado usando a variável CSS `--ig-size` com qualquer um dos três tamanhos suportados: `--ig-size-small`, `--ig-size-medium`, `--ig-size-large` (padrão).

<Sample src="/inputs/icon-button/size" height={100} alt="Exemplo de Icon Button {Platform}" />



<PlatformBlock for="React">

```tsx
<IgrIconButton className="size-medium" name="thumb-up"></IgrIconButton>
```

</PlatformBlock>

```css

    --ig-size: var(--ig-size-medium);
}
```
</PlatformBlock>

<PlatformBlock for="WebComponents">
```css

    --ig-size: var(--ig-size-medium);
}
```
</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton class="size-medium" IconName="thumb-up" Collection="material" />
```

</PlatformBlock>

### Tipo

O componente icon button mudará a sua estrutura interna de `<button>` para um elemento do tipo `<a>` quando o atributo <ApiLink pkg="core" type="IconButton" member="href" label="href" /> for definido. Nesse caso, o icon button pode ser considerado um link comum. Definir o atributo <ApiLink pkg="core" type="IconButton" member="href" label="href" /> também permitirá definir os atributos <ApiLink pkg="core" type="IconButton" member="rel" label="rel" />, <ApiLink pkg="core" type="IconButton" member="target" label="target" /> e <ApiLink pkg="core" type="IconButton" member="download" label="download" /> do icon button.

<PlatformBlock for="WebComponents">

```html
<igc-icon-button
  name="thumb-up"
  collection="material"
  href="https://duckduckgo.com"
  target="_blank">
</igc-icon-button>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrIconButton name="thumb-up" collection="material" href="https://duckduckgo.com" target="_blank">
</IgrIconButton>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton IconName="thumb-up" Collection="material" Href="https://duckduckgo.com" Target="_blank" />
```

</PlatformBlock>

### Espelhado

Alguns ícones precisam ter uma aparência um pouco diferente quando usados no modo Right-to-Left (RTL). Por isso, fornecemos um atributo `mirrored` que, quando definido, inverte horizontalmente o icon button.

<PlatformBlock for="React">

```tsx
<IgrIconButton name="thumb-up" mirrored={true}></IgrIconButton>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-icon-button name="thumb-up" mirrored></igc-icon-button>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton IconName="thumb-up" Collection="material" Mirrored="true" />
```

</PlatformBlock>

## Estilização

O componente <ApiLink pkg="core" type="IconButton" /> expõe duas partes CSS - `base` e `icon` - que permitem estilizar o elemento wrapper (`<button>` ou `<a>`) e o elemento `<igc-icon>` envolvido.

```css
igc-icon-button[variant="contained"]:not([disabled])::part(base) {
  padding: 12px;
  background-color: var(--ig-success-500);
}

igc-icon-button::part(icon) {
  --size: 22px;
  color: var(--ig-success-500-contrast);
}
```
