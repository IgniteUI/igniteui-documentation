# Componente Badge

O componente Badge {Platform} é fornecido pelo pacote {ProductName} específico da plataforma e é usado em conjunto com avatares, menus de navegação ou outros componentes de uma aplicação quando é necessária uma notificação visual. Os badges geralmente são projetados com estilos predefinidos para comunicar informações, sucesso, avisos ou erros.

## Uso

Use o Badge {Platform} para exibir um indicador curto de status, categoria, contagem ou notificação junto com outro componente.

<PlatformBlock for="Angular">

Vamos ver como o exemplo da demo é feito. É um badge de sucesso simples sobre um avatar. Para construí-lo, importe o `IgxAvatarModule` junto com o `IgxBadgeModule`:

```typescript
import { IgxBadgeModule } from 'igniteui-angular/badge';
import { IgxAvatarModule } from 'igniteui-angular/avatar';
```

Adicione os dois módulos à coleção `imports` do componente, ou importe os componentes standalone. Depois, adicione os componentes ao seu template:

```html
<div class="wrapper">
  <igx-avatar icon="person" shape="circle" size="small"></igx-avatar>
  <igx-badge icon="check" type="success"></igx-badge>
</div>
```

Use um wrapper com posicionamento relativo para colocar o Badge sobre o avatar:

```scss
.wrapper {
  position: relative;
  margin-top: 15px;
}

igx-badge {
  position: absolute;
  bottom: 0;
  left: 28px;
}
```

### Tipo

O Badge pode ter diferentes tipos de conteúdo, como um número ou um ícone.

Use o input `[value]` para exibir texto ou uma contagem numérica dentro do Badge:

```html
<igx-badge [value]="model.value"></igx-badge>
```

Use o input `[icon]` para exibir um ícone dentro do Badge:

```html
<igx-badge icon="check" type="success"></igx-badge>
```

Quando `[icon]` e `[value]` são definidos, o Badge exibe os dois simultaneamente:

```html
<igx-badge icon="check" value="5" type="success"></igx-badge>
```

Você também pode projetar o conteúdo diretamente. Ao projetar um ícone e um texto ao mesmo tempo, envolva o texto para manter o padding correto:

```html
<igx-badge>
  <igx-icon>bluetooth</igx-icon>
  <span>Bluetooth</span>
</igx-badge>
```

### Faça/Não faça

**Quando usar:** use um Badge para comunicar um status curto, categoria, contagem ou estado de notificação junto com outro componente. Use `dot` quando o indicador não precisar de texto visível.

**Quando não usar:** não use um Badge como controle principal de uma ação, como substituto de uma mensagem de validação de formulário, ou quando o status não puder ser compreendido pelo conteúdo do badge, pelo contexto ao redor ou pelo rótulo de acessibilidade.

## Propriedades

| --- | --- | --- | --- |

| <ApiLink pkg="core" type="Badge" member="outlined" label="outlined" /> | boolean | `false` | Exibe um contorno ao redor do Badge. |

| <ApiLink pkg="core" type="Badge" member="cssClass" label="cssClass" /> | string | — | Aplica uma classe CSS personalizada. |

## Acessibilidade

O Badge {Platform} é um recurso visual de status não interativo, que comunica uma contagem curta, um estado ou uma notificação.

### Interação por teclado

O Badge não recebe foco, não trata entradas de teclado e não expõe eventos de interação do componente.

| Tecla | Ação |
| -- | -- |
| n/a | O Badge não é interativo por teclado. |

### Leitores de tela / ARIA

O host do Badge usa `role="status"` para expor o seu conteúdo como informação de status.

<PlatformBlock for="WebComponents, React, Blazor">

- O componente define `aria-roledescription` para identificar o Badge e o seu `variant` atual.
- Adicione um `aria-label` quando um Badge sem texto, incluindo um Badge `dot`, comunicar um status que não esteja disponível de outra forma para tecnologias assistivas.
- Mantenha o conteúdo do Badge ou o rótulo de acessibilidade específico para o item decorado, como `3 unread messages`, e não apenas `3`.

</PlatformBlock>

<PlatformBlock for="Angular">

- O componente é inicializado com `role="status"` e `aria-label="badge"`.
- O Angular deriva `aria-roledescription` do tipo do Badge e do seu ícone ou valor. Defina o input `label` quando `badge` não for um nome acessível significativo.
- Adicione um `label` significativo para um Badge sem texto ou um Badge `dot` quando o seu status não estiver disponível de outra forma para tecnologias assistivas.

</PlatformBlock>

### Conformidade de acessibilidade

A Infragistics documenta o suporte de acessibilidade do {ProductName} para as áreas das diretrizes da Seção 508 e da WCAG 2.1 no tópico [Conformidade de acessibilidade](../interactivity/accessibility-compliance.mdx).

| Critério | Como o componente atende |
| -- | -- |
| [4.1.2 Nome, função, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value.html) | O Badge expõe a função semântica `status`. A implementação xplat também expõe uma descrição de função baseada na variante atual; o Angular expõe um rótulo acessível e uma descrição de função baseada no seu tipo e conteúdo. |

Suas responsabilidades:

- Forneça um nome acessível que explique o status quando o Badge não tiver texto significativo, especialmente em badges `dot`.
- Não use a cor do Badge como única indicação de status; combine-a com texto, um ícone ou outro recurso acessível.
- Mantenha contraste suficiente entre o primeiro plano e o fundo do Badge ao sobrescrever os estilos do tema.

## Solução de problemas

Use esta seção para conferir os limites e as decisões comuns antes de tratar o Badge como um controle interativo ou como a única indicação de status.

### Por que a minha cor de fundo personalizada não altera o Badge?

A `variant` selecionada tem precedência sobre a variável CSS `--background-color`. Para usar uma cor de fundo personalizada, evite definir uma variante que aplique a sua própria cor de fundo.

### Por que o meu Badge de ponto não exibe conteúdo?

A propriedade `dot` renderiza o Badge como um indicador mínimo e não oferece suporte a conteúdo. Use um Badge comum quando precisar exibir texto ou outro conteúdo inline.

### Limitações conhecidas

O Badge {Platform} tem as seguintes limitações independentes de plataforma.

- Um Badge de ponto é apenas um indicador e não pode exibir texto nem ícone.
- A estilização do Badge e os nomes de variante/tipo diferem entre o Angular e os outros frameworks suportados. Use os exemplos específicos de cada plataforma e os links da API nesta página, em vez de copiar um atributo de um framework para outro.
- O Badge é um indicador visual de status e não oferece interação por teclado própria.

## Perguntas frequentes

<Faq>

  <FaqItem question="Um Badge pode exibir ícone e texto ao mesmo tempo?">
    Sim. Use a área de conteúdo do Badge para o texto e o conteúdo de ícone compatível para o indicador visual. Mantenha a combinação curta para que continue sendo um rótulo compacto de status ou categoria.
  </FaqItem>

  <FaqItem question="Como exibo um ponto de notificação sem conteúdo?">
    Defina a propriedade ou o atributo `dot` específico da plataforma. Um Badge de ponto é renderizado intencionalmente sem texto ou outro conteúdo.
  </FaqItem>

  <FaqItem question="Quando devo usar um Badge de ponto em vez de um Badge de texto?">
    Use um Badge de ponto quando o status for comunicado apenas pela presença. Use um Badge de texto quando os usuários precisarem entender o status, a categoria ou a contagem sem depender de cor ou posição.
  </FaqItem>

  <FaqItem question="Qual pacote devo instalar para o Badge?">
    Use `igniteui-angular` para Angular, `igniteui-react` para React, `igniteui-webcomponents` para Web Components e `IgniteUI.Blazor` para Blazor. Mantenha os pacotes relacionados do Ignite UI na mesma versão de release.
  </FaqItem>

</Faq>
