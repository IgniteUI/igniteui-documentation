# Visão geral do Ripple {Platform}

O componente Ripple {ProductName} cria uma animação em resposta a um toque ou a um clique do mouse.

## Uso


<PlatformBlock for="WebComponents">


Primeiro, você precisa instalar o {ProductName} executando o seguinte comando:

```cmd
npm install {PackageWebComponents}
```

Antes de usar o <ApiLink pkg="core" type="Ripple" />, você precisa registrá-lo da seguinte forma:

```ts
import { defineComponents, IgcRippleComponent } from "igniteui-webcomponents";
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcRippleComponent);
```

Para uma introdução completa ao {ProductName}, leia o tópico [**Primeiros passos**](../general-getting-started.mdx).

</PlatformBlock>



<PlatformBlock for="React">


Primeiro, você precisa instalar o pacote npm correspondente {ProductName} executando o seguinte comando:

```cmd
npm install igniteui-react
```

Em seguida, você precisará importar o <ApiLink pkg="core" type="Ripple" /> e o CSS necessário, assim:

```tsx
import { IgrRipple } from 'igniteui-react';
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

</PlatformBlock>



<PlatformBlock for="Blazor">



Registre os serviços de {ProductName}:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

O registro de <ApiLink pkg="core" type="RippleModule" />, o módulo de recurso do cliente de <ApiLink pkg="core" type="Ripple" />, é **opcional**: o componente carrega seus recursos na primeira vez em que é renderizado. Listá-lo em `builder.Services.AddIgniteUIBlazor(typeof(IgbRippleModule))` pode ser usado para pré-carregar recursos ou para dar suporte a elementos criados somente no cliente (veja [Módulos do componente](../general-getting-started.mdx#módulos-do-componente)).

Você também precisará vincular um arquivo CSS adicional para aplicar o estilo ao componente <ApiLink pkg="core" type="Ripple" />. O seguinte deve ser colocado na página host da aplicação (**wwwroot/index.html** em uma aplicação Blazor WebAssembly independente ou Blazor Hybrid, **Pages/_Host.cshtml** em uma aplicação Blazor Server, **Components/App.razor** em uma aplicação Blazor Web App):

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```


</PlatformBlock>


A forma mais simples de começar a usar o <ApiLink pkg="core" type="Ripple" /> é a seguinte:

<PlatformBlock for="WebComponents">

```html
<igc-button>
  <igc-ripple></igc-ripple>
  Ripple Button
</igc-button>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton>
  <IgrRipple></IgrRipple>
  <span>Ripple Button</span>
</IgrButton>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbButton Variant="@ButtonVariant.Contained">
    Ripple Button
    <IgbRipple></IgbRipple>
</IgbButton>
```

</PlatformBlock>

Você pode adicionar o componente <ApiLink pkg="core" type="Ripple" /> a qualquer elemento web, desde que a sua propriedade CSS `position` esteja definida com um valor diferente de `static`;

## Exemplos

### Color

Você pode alterar a cor do ripple definindo a propriedade CSS `--color` com qualquer cor CSS válida:

```css
igc-ripple {
  --color: olive;
}
```
