# Visão geral do Text Area {Platform}

O Text Area {ProductName} representa um controle de edição de texto simples e de múltiplas linhas, útil quando você quer permitir que os usuários insiram uma quantidade considerável de texto livre, por exemplo, um comentário em uma avaliação ou em um formulário de feedback.

## Prefixo, sufixo e texto de ajuda

Com os slots `prefix` e `suffix`, podemos adicionar conteúdos diferentes antes e depois do conteúdo principal do Text Area. O slot `helper-text` fornece uma dica posicionada abaixo do Text Area. Ao colocar conteúdo nos slots, recomendamos usar um elemento `<span>` para texto simples, símbolos ou emojis, e um componente [`<igc-icon>`](../layouts/icon.mdx) para ícones. No exemplo a seguir, vamos criar um novo campo Text Area com um prefixo de ícone e um texto de ajuda como dica:

<PlatformBlock for="WebComponents">

```html
<igc-textarea label="Your feedback">
    <igc-icon name="feedback" slot="prefix"></igc-icon>
    <span slot="helper-text">Give us a short description of what you liked/disliked</span>
</igc-textarea>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrTextarea label="Your feedback">
    <IgrIcon name="feedback" slot="prefix"></IgrIcon>
    <span slot="helper-text">Give us a short description of what you liked/disliked</span>
</IgrTextarea>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbTextarea Label="Your feedback">
    <IgbIcon IconName="feedback" Collection="material" slot="prefix"></IgbIcon>
    <span slot="helper-text">Give us a short description of what you liked/disliked</span>
</IgbTextarea>
```

</PlatformBlock>

## Redimensionamento do Text Area

Há três opções diferentes de redimensionamento do <ApiLink pkg="core" type="Textarea" />. Quando definido como `none`, o text area não é redimensionado e usa uma barra de rolagem para mostrar o texto que excede o espaço. Quando definido como `vertical` (a opção padrão), o text area permite que o usuário o redimensione verticalmente. Quando definido como `auto`, o text area mostra toda a entrada do usuário de uma vez. O texto que excede o espaço quebra para uma nova linha e expande o text area automaticamente.

## Estilização

O componente <ApiLink pkg="core" type="Textarea" /> expõe partes CSS para quase todos os seus elementos internos. A tabela a seguir lista todas as partes CSS expostas:

|Nome|Descrição|
|--|--|
| `container` | O wrapper principal que contém todos os elementos de input principais. |
| `input` | O elemento de input nativo. |
| `label` | O elemento de rótulo nativo. |
| `prefix` | O wrapper do prefixo. |
| `suffix` | O wrapper do sufixo. |
| `helper-text` | O wrapper do texto de ajuda. |

```css
igc-textarea::part(input) {
  background-color: var(--ig-info-100);
  border-color: var(--ig-primary-400);
}

igc-textarea::part(label) {
  color: var(--ig-gray-800);
}

igc-textarea::part(prefix),
igc-textarea::part(suffix) {
  color: var(--ig-primary-500-contrast);
  border-color: var(--ig-primary-500);
  background-color: var(--ig-primary-500);
}
```
