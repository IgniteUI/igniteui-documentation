# Visão geral do {Platform} Date Time Input

O {ProductName} Date Time Input permite que o usuário defina e edite a data e a hora em um elemento de input escolhido. O usuário pode editar as partes de data e de hora usando um input mascarado editável. Além disso, é possível especificar um formato de exibição e de entrada desejado, bem como valores mínimo e máximo para usar a validação.

<PlatformBlock for="WebComponents, React">



O <ApiLink pkg="core" type="DateTimeInput" /> também aceita strings [ISO 8601](https://tc39.es/ecma262/#sec-date-time-string-format).

A string pode ser uma string `ISO` completa, no formato `YYYY-MM-DDTHH:mm:ss.sssZ`, ou pode ser separada em partes somente de data e somente de hora.

#### Somente data
Se uma string somente de data for vinculada à propriedade <ApiLink pkg="core" type="DateTimeInput" member="value" label="Value" /> do componente, ela precisa estar no formato `YYYY-MM-DD`. O <ApiLink pkg="core" type="DateTimeInput" member="inputFormat" label="InputFormat" /> continua sendo usado ao digitar valores no input e não precisa estar no mesmo formato. Além disso, ao vincular uma string somente de data, a diretiva evita deslocamentos de horário, forçando a hora a ser `T00:00:00`.

#### Somente hora
Strings somente de hora normalmente não são definidas na especificação `ECMA`; porém, para permitir que a diretiva seja integrada a cenários que exigem soluções somente de hora, ela oferece suporte ao formato de 24 horas - `HH:mm:ss`. O formato de 12 horas não é suportado.

#### String ISO completa
Se for vinculada uma string `ISO` completa, a diretiva a analisa somente se todos os elementos exigidos por [Date.parse](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/parse#date_time_string_format) forem fornecidos.

Todos os valores falsy, incluindo `InvalidDate`, serão analisados como `null`. Strings incompletas somente de data, somente de hora ou `ISO` completas serão analisadas como `InvalidDate`.


</PlatformBlock>


### Navegação pelo teclado

O <ApiLink pkg="core" type="DateTimeInput" /> tem uma navegação por teclado intuitiva, que facilita incrementar, decrementar ou pular entre diferentes `DateParts`, entre outras ações, sem precisar tocar no mouse.

|Teclas|Descrição|
|----|-----------|
| <kbd>←</kbd> | Mover um caractere para o início |
| <kbd>→</kbd> | Mover um caractere para o fim |
| <kbd>HOME</kbd> | Mover para o início |
| <kbd>END</kbd> | Mover para o fim |
| <kbd>CTRL</kbd> / <kbd>CMD</kbd> + <kbd>←</kbd> | Mover para o início da seção de data/hora - a atual ou a da esquerda |
| <kbd>CTRL</kbd> / <kbd>CMD</kbd> + <kbd>→</kbd> | Mover para o fim da seção de data/hora - a atual ou a da direita |
| Com foco em uma parte de data/hora + <kbd>↓</kbd> | Decrementa uma parte de data/hora |
| Com foco em uma parte de data/hora + <kbd>↑</kbd> | Incrementa uma parte de data/hora |
| <kbd>CTRL</kbd> / <kbd>CMD</kbd> + <kbd>;</kbd> | Define a data/hora atual como o valor do editor |

## Definindo formatos

O <ApiLink pkg="core" type="DateTimeInput" /> oferece suporte a diferentes formatos de exibição e de entrada.

Ele usa [Intl.DateTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat), que permite oferecer suporte a opções de formato predefinidas, como `long` e `short`, `medium` e `full`. Além disso, pode aceitar uma string personalizada montada a partir de caracteres suportados, como `dd-MM-yy`. Também, se nenhum <ApiLink pkg="core" type="DateTimeInput" member="displayFormat" label="DisplayFormat" /> for informado, o componente usará o <ApiLink pkg="core" type="DateTimeInput" member="inputFormat" label="InputFormat" /> dessa forma.

### Formato de entrada
A tabela abaixo mostra os formatos suportados pelo <ApiLink pkg="core" type="DateTimeInput" member="inputFormat" label="InputFormat" /> do componente:

|Formato|Descrição|
|-------|----------|
| `d` | Dia, que será completado com um zero à esquerda durante a edição. |
| `dd` | Dia com zero à esquerda definido explicitamente. |
| `M` | Mês, que será completado com um zero à esquerda durante a edição. |
| `MM` | Mês com zero à esquerda definido explicitamente. |
| `yy` | Formato de ano curto. |
| `yyyy` | Formato de ano completo. |
| `h` | Horas no formato de 12 horas, que serão completadas com um zero à esquerda durante a edição. |
| `hh` | Horas no formato de 12 horas com zero à esquerda definido explicitamente. |
| `H` | Horas no formato de 24 horas, que serão completadas com um zero à esquerda durante a edição. |
| `HH` | Horas no formato de 24 horas, com zero à esquerda definido explicitamente. |
| `m` | Minutos, que serão completados com um zero à esquerda durante a edição. |
| `mm` | Minutos com zero à esquerda definido explicitamente. |
| `tt` | Seção AM/PM para o formato de 12 horas. |

Para definir um formato de entrada específico, passe-o como string para o <ApiLink pkg="core" type="DateTimeInput" />. Isso definirá tanto o formato de entrada esperado do usuário quanto o `mask`. Além disso, o <ApiLink pkg="core" type="DateTimeInput" member="inputFormat" label="InputFormat" /> é baseado no locale; por isso, se nenhum for informado, o editor usará `dd/MM/yyyy` por padrão.

## Incrementar/decrementar

O <ApiLink pkg="core" type="DateTimeInput" /> expõe os métodos públicos <ApiLink pkg="core" type="DateTimeInput" member="stepUp" label="StepUp" /> e <ApiLink pkg="core" type="DateTimeInput" member="stepDown" label="StepDown" />. Eles incrementam ou decrementam uma <ApiLink pkg="core" type="DatePart" /> específica da data e da hora definidas no momento, e podem ser usados de algumas formas.

No primeiro cenário, se nenhum DatePart específico for passado ao método, um DatePart padrão será incrementado ou decrementado, com base no <ApiLink pkg="core" type="DateTimeInput" member="inputFormat" label="InputFormat" /> especificado e na implementação interna do componente. No segundo cenário, você pode especificar explicitamente qual DatePart manipular, já que isso pode atender a requisitos diferentes. Além disso, ambos os métodos aceitam um parâmetro opcional `delta` do tipo number, que pode ser usado para definir o passo de stepUp/stepDown.


<PlatformBlock for="WebComponents, Blazor">



Além disso, <ApiLink pkg="core" type="DateTimeInput" member="spinDelta" label="SpinDelta" /> é uma propriedade que pode ser usada para aplicar um delta diferente a cada segmento de data e hora. Ele será aplicado ao girar com o teclado, a roda do mouse ou com os métodos <ApiLink pkg="core" type="DateTimeInput" member="stepUp" label="StepUp" /> e <ApiLink pkg="core" type="DateTimeInput" member="stepDown" label="StepDown" />, desde que estes não recebam o parâmetro delta, pois este terá precedência sobre <ApiLink pkg="core" type="DateTimeInput" member="spinDelta" label="SpinDelta" />.


</PlatformBlock>


<PlatformBlock for="WebComponents">

```ts
const input = document.getElementById('dateTimeInput') as IgcDateTimeInputComponent;

const spinDelta: DatePartDeltas = {
  date: 2,
  month: 3,
  year: 10,
};

input.spinDelta = spinDelta;
```

</PlatformBlock>
