### Faça/Não faça

**Quando usar:** use Switch para uma configuração imediata de ligado/desligado, que entra em vigor quando o usuário a altera.

**Quando não usar:** use [Checkbox](./checkbox.mdx) quando os usuários selecionarem uma ou mais opções para um envio de formulário posterior, ou [Button](./button.mdx) quando o controle representar uma ação ou um comando alternável.

## Estilização

O {Platform} Switch usa partes CSS e variáveis CSS para estilizar o seu trilho, o thumb e o rótulo.

<PlatformBlock for="Angular">

### Temas em Sass

Para começar a estilizar o switch, importe o arquivo `index`, onde são exportadas todas as funções de tema e o mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;
```

Em seguida, crie um novo tema que estenda <ApiLink kind="sass" module="themes" type="function-switch-theme" label="switch-theme" code={true} />. Fornecer `$thumb-off-color` e `$thumb-on-color` basta para obter um switch totalmente estilizado, porque o tema gera as demais cores a partir delas:

```scss
$custom-switch-theme: switch-theme(
    $thumb-off-color: #7cadd5,
    $thumb-on-color: #ecaa53,
);
```

Por fim, inclua o tema personalizado na sua aplicação:

```scss
:host {
  @include tokens($custom-switch-theme);
}
```

### Estilizando com Tailwind

Você pode estilizar o switch usando as classes utilitárias do Tailwind do Ignite UI. Certifique-se de [configurar o Tailwind](/themes/tailwind) primeiro e, em seguida, importe o arquivo de utilitários na sua folha de estilos global:

Use `light-switch` ou `dark-switch` para o tema correspondente e sobrescreva as variáveis CSS geradas com propriedades arbitrárias. Você encontra a lista completa de propriedades em <ApiLink kind="sass" module="themes" type="function-switch-theme" label="Tema do IgxSwitch" />:


O ponto de exclamação (`!`) torna a classe utilitária importante, para que ela tenha precedência sobre o tema do componente.

### Temas em Sass

Use o sistema de temas {ProductName} para estilizar o Switch de forma consistente com o restante da sua aplicação.

Importe as funções de tema antes de criar um tema personalizado de Switch:

```scss
@use "igniteui-theming" as *;
```

Crie um tema com `switch-theme` e inclua-o na folha de estilos global. Os parâmetros de track e de thumb são usados como base para as cores dos estados de interação relacionados:

```scss
$custom-switch: switch-theme(
    $track-on-color: #57a5cd,
);

igc-switch {
    @include switch($custom-switch);
}
```

O mesmo tema se aplica diretamente aos Web Components e ao elemento `igc-switch` subjacente renderizado pelos wrappers de React e Blazor.

### Variáveis CSS

Use as variáveis CSS a seguir para personalizar as cores e os estados de interação do Switch. Defina-as no elemento Switch para aplicar os estilos ao seu trilho, ao thumb e ao rótulo:

| Propriedade primária | Propriedade dependente | Descrição |
| --- | --- | --- |
| `--track-on-color` | `--track-on-hover-color` | Fundo do trilho quando o switch está marcado. |
|  | `--track-off-color` | Fundo do trilho quando o switch está desmarcado. |
| `--thumb-on-color` | `--thumb-off-color` | Cor do thumb nos estados marcado e desmarcado. |
| `--label-color` | `--label-disabled-color` | Cor do rótulo nos estados padrão e desabilitado. |

### Partes de estilo

| Parte | Componente | o que estiliza |

| `control` | <ApiLink pkg="core" type="Switch" /> | O elemento de input do switch. |

### Estilização personalizada

O exemplo a seguir altera as cores do trilho e do thumb para os estados marcado e desmarcado:

| Seletor | Declaração | Efeito |
| --- | --- | --- |
| `igc-switch` | `--track-on-color`, `--track-off-color` | Altera o fundo do trilho para os estados marcado e desmarcado. |
| `igc-switch` | `--thumb-on-color`, `--thumb-off-color` | Altera a cor do thumb para os estados marcado e desmarcado. |

```css
igc-switch {
  --thumb-on-color: white;
  --thumb-off-color: var(--ig-success-500);
  --track-on-color: var(--ig-success-500); /* Background color when checked */
  --track-off-color: white; /* Background color when unchecked */
  --track-on-hover-color: var(--ig-success-500); /* Background hover color when checked */
}
```

## Acessibilidade

O Switch {Platform} expõe um estado binário e oferece suporte a um nome acessível por meio do seu rótulo ou dos atributos ARIA.

### Interação por teclado

| Tecla | Ação |
| --- | --- |
| Tab / Shift+Tab | Move o foco para o switch ou para longe dele. |
| Space | Alterna o switch com foco. |

### Leitores de tela / ARIA

O Switch renderiza um controle interativo com um estado marcado binário. Forneça conteúdo de rótulo visível ou um nome acessível com `aria-label` ou `aria-labelledby`, e mantenha o rótulo específico para a configuração controlada pelo switch.

<PlatformBlock for="WebComponents, React, Blazor">

- O controle expõe o seu estado marcado e o seu estado desabilitado para as tecnologias assistivas.
- O evento `igcChange` é emitido quando o estado marcado muda.

</PlatformBlock>

### Conformidade de acessibilidade

A Infragistics documenta o suporte de acessibilidade do {ProductName} para as áreas das diretrizes da Seção 508 e da WCAG 2.1 no tópico [Conformidade de acessibilidade](../interactivity/accessibility-compliance.mdx).

| Critério | Como o componente atende |

## Solução de problemas

Use esta seção para conferir os limites e as decisões comuns antes de tratar o Switch como um campo de formulário, um comando interativo ou um controle de configuração.

### Por que o Switch não é enviado com o meu formulário?

O Switch é associado a formulários, mas exige um `name` e um `value` para contribuir com um valor quando o formulário é enviado. Defina as duas propriedades e use a integração com formulários suportada pela sua plataforma de destino.

### Por que o Switch não é anunciado corretamente por um leitor de tela?

O Switch precisa de um nome acessível. Adicione conteúdo de rótulo visível ou referencie um rótulo externo com `aria-labelledby`; use `aria-label` quando o texto visível não estiver disponível.

### Limitações conhecidas

O Switch {Platform} tem as seguintes limitações independentes de plataforma:

- Um Switch representa uma configuração binária; use outro controle quando os usuários precisarem de múltiplas escolhas ou de uma seleção de formulário adiada.
- Um Switch não fornece um nome acessível automaticamente quando não tem rótulo nem atributo ARIA de nomeação.

## Perguntas frequentes

<Faq>
  <FaqItem question="Como defino o Switch no estado inicial ligado ou desligado?">
    Defina a propriedade <ApiLink pkg="core" type="Switch" member="checked" label="checked" /> como `true` para o estado ligado ou como `false` para o estado desligado. A propriedade usa um valor booleano na sintaxe de React, Web Components e Blazor.
  </FaqItem>
  <FaqItem question="Como posiciono o rótulo do Switch?">
    Coloque o texto do rótulo dentro do Switch e defina a propriedade <ApiLink pkg="core" type="Switch" member="labelPosition" label="labelPosition" /> como `before` ou `after`. A posição padrão do rótulo é `after`.
  </FaqItem>
  <FaqItem question="Como envio o valor de um Switch com um formulário?">
    Defina as duas propriedades <ApiLink pkg="core" type="Switch" member="name" label="name" /> e <ApiLink pkg="core" type="Switch" member="value" label="value" />. No Blazor, use o componente `EditForm` em vez de um `form` HTML padrão.
  </FaqItem>
  <FaqItem question="Como torno um Switch obrigatório ou inválido?">
    Defina a propriedade <ApiLink pkg="core" type="Switch" member="required" label="required" /> quando a configuração precisar ser selecionada, e defina <ApiLink pkg="core" type="Switch" member="invalid" label="invalid" /> quando o controle estiver em estado inválido. Use <ApiLink pkg="core" type="Switch" member="disabled" label="disabled" /> quando os usuários não puderem alterar a configuração.
  </FaqItem>
</Faq>
