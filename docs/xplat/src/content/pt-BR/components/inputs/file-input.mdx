# Visão geral do {Platform} File Input

O componente {ProductName} File Input oferece uma forma interativa para os usuários selecionarem e enviarem arquivos. Ele estende a funcionalidade base de <ApiLink pkg="core" type="Input" /> acrescentando recursos específicos para arquivos, como seleção de arquivos, exibição dos nomes dos arquivos selecionados e suporte ao envio de vários arquivos.

## Exemplo de {Platform} File Input

<Sample src="/inputs/file-input/overview" height={120} alt="Exemplo de visão geral do {Platform} File Input" />

## Uso

O componente <ApiLink type="FileInput" /> permite que os usuários selecionem arquivos do seu dispositivo e os enviem para uma aplicação web. Ele exibe os nomes dos arquivos selecionados e oferece opções de personalização para o botão de procurar e para o texto "No file chosen". O componente também fornece propriedades, métodos e slots que podem ser usados para configurar melhor o seu comportamento conforme as suas necessidades.

## Configuração

### Propriedades

O componente <ApiLink type="FileInput" /> oferece uma variedade de propriedades que permitem configurar o seu comportamento conforme requisitos específicos. Essas propriedades dão controle sobre a funcionalidade, a aparência e a validação do input.

- <ApiLink pkg="core" type="Input" member="value" label="Value" /> - Define o valor atual do campo de input de arquivo.
- <ApiLink pkg="core" type="Input" member="disabled" label="Disabled" /> - Desabilita o input de arquivo, impedindo a interação do usuário.
- <ApiLink pkg="core" type="Input" member="required" label="Required" /> - Marca o input como obrigatório. O envio do formulário será bloqueado a menos que um arquivo seja selecionado.
- <ApiLink pkg="core" type="Input" member="invalid" label="Invalid" /> - Indica que o valor do input é inválido; usado para acionar os estados visuais de erro.
- `Multiple` - Permite a seleção de vários arquivos.
- `Accept` - Define os tipos de arquivo que podem ser selecionados. O valor dessa propriedade precisa ser uma lista de formatos de arquivo separados por vírgula (por exemplo, .jpg, .png, .gif).
- <ApiLink pkg="core" type="Input" member="autofocus" label="Autofocus" /> - Dá foco automaticamente ao campo de input de arquivo quando a página é carregada.
- <ApiLink pkg="core" type="Input" member="label" label="Label" /> - Define o texto do rótulo associado ao elemento de input de arquivo.
- <ApiLink pkg="core" type="Input" member="placeholder" label="Placeholder" /> - Fornece o texto de placeholder exibido quando nenhum arquivo está selecionado.

<PlatformBlock for="WebComponents">

```html
<igc-file-input
  label="Files Input"
  accept=".jpg, .png, .gif"
  placeholder="Files missing"
  required
  multiple>
</igc-file-input>
```

</PlatformBlock>

### Métodos

Além das suas propriedades configuráveis, há quatro métodos úteis herdados do componente <ApiLink pkg="core" type="Input" /> que você pode usar no componente <ApiLink type="FileInput" />:

- `Focus` - Define o foco no elemento de input de arquivo.
- `Blur` - Remove o foco do elemento de input de arquivo.
- <ApiLink pkg="core" type="Input" member="reportValidity" label="ReportValidity" /> - Verifica a validade do input e exibe uma mensagem de validação se ele for inválido.
- <ApiLink pkg="core" type="Input" member="setCustomValidity" label="SetCustomValidity" /> - Define uma mensagem de validação personalizada. Se a mensagem informada não estiver vazia, o input será marcado como inválido.

### Slots

O componente <ApiLink type="FileInput" /> também expõe vários slots que podem ser usados para personalizar a sua aparência e o seu comportamento.

- `prefix` e `suffix` - Permitem inserir conteúdo antes ou depois da área principal do input.
- `helper-text` - Exibe uma dica ou mensagem instrucional abaixo do input. Útil para fornecer orientação adicional, como dicas de formatação ou requisitos do campo.
- `file-selector-text` - Permite personalizar o texto exibido no botão de seleção de arquivos.
- `file-missing-text` - Define o texto exibido no campo de input quando nenhum arquivo foi selecionado.
- `value-missing` - Renderiza conteúdo personalizado quando a validação do campo obrigatório falha (ou seja, quando um arquivo é exigido, mas não foi informado).
- `invalid` – Permite renderizar conteúdo personalizado quando o input está em estado inválido.
- `custom-error` - Exibe conteúdo quando uma mensagem de validação personalizada é definida usando o método <ApiLink type="FileInput" member="setCustomValidity" label="setCustomValidity()" />.

Ao colocar conteúdo nos slots, recomendamos usar um elemento `<span>` para texto simples, símbolos ou emojis, e um componente [`<igc-icon>`](../layouts/icon.mdx) para ícones.

## Limitações

O componente <ApiLink type="FileInput" /> tem atualmente as seguintes limitações:
- As strings padrão do botão "Browse" e da mensagem "No file chosen" não são localizadas automaticamente. Essas strings permanecem as mesmas em todos os locales, mas podem ser personalizadas manualmente usando os slots apropriados ou o binding do placeholder.
- Os arquivos não podem ser definidos manualmente pela propriedade `value`. A seleção de arquivos só pode ser feita pelo seletor de arquivos. Você pode, no entanto, passar uma string vazia `''` para redefinir o campo.

## Suporte a acessibilidade e ARIA

O componente <ApiLink type="FileInput" /> é focável e interativo, garantindo acessibilidade completa por teclado e por leitor de tela. O componente pode ser rotulado usando o atributo <ApiLink type="FileInput" member="label" label="Label" />, que aproveita o elemento nativo `<label>` para fornecer um rótulo semanticamente correto e acessível.

Para seguir as boas práticas de acessibilidade, o componente também aplica os atributos ARIA relevantes:

- `aria-invalid` - Definido como "true" quando o input está em estado inválido.
- `aria-describedby` - Vinculado automaticamente ao elemento de texto de ajuda, quando ele está presente, para que as tecnologias assistivas anunciem a informação adicional.

## Estilização

O componente <ApiLink type="FileInput" /> expõe partes CSS que podemos usar para estilização. A tabela a seguir lista todas as partes CSS expostas:

|Nome|Descrição|
|--|--|
| `container` | O wrapper principal que contém todos os elementos de input principais. |
| `input` | O elemento de input nativo. |
| `label` | O elemento de rótulo nativo. |
| `file-names` | O wrapper dos nomes de arquivos. |
| `file-selector-button` | O botão de procurar. |
| `prefix` | O wrapper do prefixo. |
| `suffix` | O wrapper do sufixo. |
| `helper-text` | O wrapper do texto de ajuda. |


```scss
igc-file-input::part(file-names) {
  background-color: var(--ig-primary-50);
  color: var(--ig-gray-400);
}

igc-file-input::part(suffix) {
  color: var(--ig-primary-700-contrast);
  background-color: var(--ig-primary-700);
}

igc-file-input::part(label) {
  color: var(--ig-gray-600);
}
```
