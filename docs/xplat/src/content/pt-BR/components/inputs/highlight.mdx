# Visão geral do {Platform} Highlight

O {ProductName} Highlight é usado para destacar partes do conteúdo da página, tornando-as mais perceptíveis para o usuário. É um componente leve, que pode ser usado em combinação com outros componentes para criar uma experiência de usuário mais interativa e envolvente.

<igc-divider></igc-divider>

## Uso

Para usar o componente <ApiLink pkg="core" type="Highlight" />, basta envolver com as suas tags o conteúdo que você quer pesquisar. O componente pesquisa o conteúdo de todos os elementos aninhados dentro das <PlatformBlock for="WebComponents">`<igc-highlight>`</PlatformBlock><PlatformBlock for="React">`<IgrHighlight>`</PlatformBlock><PlatformBlock for="Blazor">`<IgbHighlight>`</PlatformBlock> tags, e destaca todas as correspondências da string especificada.

<DocsAside type="note">
O componente <ApiLink pkg="core" type="Highlight" /> pesquisa apenas os nós de texto do DOM. Ele não pesquisa valores de input nem conteúdo definido pela propriedade CSS `content`.
</DocsAside>

### Correspondência com diferenciação de maiúsculas e minúsculas

O componente <ApiLink pkg="core" type="Highlight" /> também expõe um atributo <ApiLink type="BaseSearchInfo" member="caseSensitive" label="case-sensitive" />. O seu valor padrão é `false`, o que habilita a correspondência sem diferenciar maiúsculas de minúsculas. Ao defini-lo como `true`, você pode habilitar a correspondência com diferenciação de maiúsculas e minúsculas.

O trecho a seguir:

<PlatformBlock for="WebComponents">
```html
<igc-highlight search-text='lorem' case-sensitive='true'>
    <p>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</p>
</igc-highlight>
```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
<IgrHighlight search-text='lorem' case-sensitive={true}>
    <p>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</p>
</IgrHighlight>
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```razor
<IgbHighlight SearchText="lorem" CaseSensitive="true">
    <p>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</p>
</IgbHighlight>
```
</PlatformBlock>

Isso retorna 0 correspondências, porque o texto pesquisado "lorem" está em minúsculas, enquanto o texto do conteúdo é **Lorem**, com o **L** em maiúscula.

### Usando o Highlight com um input de pesquisa

O caso de uso mais comum é vincular o componente <ApiLink pkg="core" type="Highlight" /> a um componente de input de pesquisa <ApiLink pkg="core" type="Input" />, para que as correspondências sejam destacadas em tempo real conforme o usuário digita.

Para vincular os dois, você pode escutar o evento `igcInput` do componente <ApiLink pkg="core" type="Input" /> e definir o atributo <ApiLink type="BaseSearchInfo" member="searchText" label="search-text" /> do componente <ApiLink pkg="core" type="Highlight" /> com o valor do input sempre que o evento for disparado (você também pode usar o evento padrão `input`).

<PlatformBlock for="WebComponents">
Primeiro, você precisa acessar o componente <ApiLink type="Highlight" /> para manipular as suas propriedades:

```ts
const highlight = document.querySelector('igc-highlight') as IgcHighlightComponent;
```

Em seguida, crie uma função que atualiza o texto de pesquisa sempre que o evento `igcInput` é disparado:

```ts
const onInput = ({ detail }: CustomEvent<string>) => {
    highlight.searchText = detail;
};

document.querySelector('igc-input')?.addEventListener('igcInput', onInput);
```

```html
<igc-input label="Search"></igc-input>
<igc-highlight>
    <p>
      Lorem ipsum dolor sit, amet consectetur adipisicing elit. Quae doloribus odit id excepturi ipsum provident eaque dignissimos beatae!
    </p>
</igc-highlight>
```

</PlatformBlock>

<PlatformBlock for="React">
Primeiro, você precisa acessar o componente <ApiLink type="Highlight" /> para manipular as suas propriedades. A forma mais fácil de fazer isso é por meio de uma referência:

```tsx
import { useRef } from 'react';
```

```tsx
const highlightRef = useRef<IgrHighlight>(null);
```

```tsx
<IgrHighlight ref={highlightRef}>
    ...
</IgrHighlight>
```

Em seguida, crie uma função que atualiza o texto de pesquisa, chamada sempre que o evento `igcInput` é disparado:

```tsx
const onInput = ({ detail }: CustomEvent<string>) => {
    highlightRef.current.searchText = detail;
};
```

```tsx
<IgrInput label="Search" onigcInput={onInput}></IgrInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">
Primeiro, você precisa adicionar a propriedade searchText:

```razor

```

Em seguida, crie uma função que atualiza o texto de pesquisa sempre que o evento `igcInput` é disparado:

```razor
private void OnValueChanging(string newValue)
{
    searchText = newValue;
}
```

```razor
<IgbInput Label="Search" ValueChanging="OnValueChanging"></IgbInput>
<IgbHighlight SearchText="@searchText">
    <p>
        Lorem ipsum dolor sit, amet consectetur adipisicing elit. Quae doloribus
        odit id excepturi ipsum provident eaque dignissimos beatae! Rerum vero
        distinctio libero, quasi magni quod natus nesciunt doloremque temporibus
        voluptate?
    </p>
</IgbHighlight>
```

</PlatformBlock>

### Métodos

O componente também expõe dois métodos para navegar pelas correspondências da pesquisa. O método <ApiLink pkg="core" type="Highlight" member="next" label="next()" /> avança para a próxima correspondência, enquanto o método <ApiLink pkg="core" type="Highlight" member="previous" label="previous()" /> volta para a anterior.

Com eles, podemos tornar a pesquisa mais interativa adicionando dois botões para navegar entre as correspondências:

<PlatformBlock for="WebComponents">
```ts
const highlight = document.querySelector('igc-highlight') as IgcHighlightComponent;

const prev = () => {
    highlight.previous();
};

const next = () => {
    highlight.next();
};

document.querySelector('#prev-btn')?.addEventListener('click', prev);
document.querySelector('#next-btn')?.addEventListener('click', next);

```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
const highlightRef = useRef<IgrHighlight>(null);

const prev = () => {
    highlightRef.current?.previous();
};

const next = () => {
    highlightRef.current?.next();
};
```

</PlatformBlock>

### Recursos adicionais

<PlatformBlock for="WebComponents">
O componente também expõe duas propriedades somente leitura para acompanhar o estado das correspondências: <ApiLink type="Highlight" member="size" label="size" /> retorna o número total de correspondências, e <ApiLink type="Highlight" member="current" label="current" /> retorna o índice da correspondência ativa.

Elas são úteis para construir um indicador de status da pesquisa que mostra ao usuário em qual correspondência ele está e quantas correspondências existem no total.

Aqui está um exemplo simples de como usar essas propriedades para criar um status de pesquisa:

```ts
const highlight = document.querySelector('igc-highlight') as IgcHighlightComponent;
const status = document.querySelector('#helper-text') as HTMLParagraphElement;

const updateStatus = () => {
    status.textContent = highlight.size
      ? `${highlight.current + 1} of ${highlight.size} match${highlight.size === 1 ? '' : 'es'}`
      : '';
}

```

</PlatformBlock>

<PlatformBlock for="React">
O componente também expõe duas propriedades somente leitura para acompanhar o estado das correspondências: <ApiLink type="Highlight" member="size" label="size" /> retorna o número total de correspondências, e <ApiLink type="Highlight" member="current" label="current" /> retorna o índice da correspondência ativa.

Elas são úteis para construir um indicador de status da pesquisa que mostra ao usuário em qual correspondência ele está e quantas correspondências existem no total.

<PlatformBlock for="Blazor">
O componente também expõe dois métodos assíncronos para acompanhar o estado das correspondências: GetSizeAsync() retorna o número total de correspondências, e GetCurrentAsync() retorna o índice da correspondência ativa.

Esses métodos são úteis para construir um indicador de status da pesquisa que mostra ao usuário em qual correspondência ele está e quantas correspondências existem no total.

Aqui está um exemplo simples de como usar esses métodos para criar um status de pesquisa:

```razor
private async Task UpdateStatus()
{
    var size = (int)await HighlightRef.GetSizeAsync();
    var current = (int)await HighlightRef.GetCurrentAsync();
    helperText = $"{current + 1} of {size} match{(size == 1 ? "" : "es")}";
}
```

</PlatformBlock>

## Estilização

O componente <ApiLink pkg="core" type="Highlight" /> expõe quatro variáveis CSS que podem ser usadas para estilizar o componente inteiro:
- `--foreground` A cor do texto de um nó de texto destacado.
- `--background` A cor de fundo de um nó de texto destacado.
- `--foreground-active` A cor do texto do nó de texto destacado ativo.
- `--background-active` A cor de fundo do nó de texto destacado ativo.

```css
igc-highlight {
    --background: var(--ig-gray-700);
    --foreground: var(--ig-gray-700-contrast);
    --background-active: var(--ig-warn-500);
    --foreground-active: var(--ig-warn-500-contrast);
}
```
