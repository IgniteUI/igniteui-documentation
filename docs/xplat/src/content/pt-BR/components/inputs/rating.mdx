# Rating

O Rating {ProductName} é um componente associado a formulários que permite aos usuários visualizar e selecionar uma pontuação em uma escala de estrelas ou símbolos personalizados.

<PlatformBlock for="Angular">

No Angular, o Rating é o web component `igc-rating` de `igniteui-webcomponents`. Vincule-o aos formulários do Angular com `IgcFormControlDirective`.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

O Rating oferece suporte a meia estrela e a outros valores fracionários, pré-visualização ao passar o mouse, seleção única de símbolos distintos e entrada completa pelo teclado.

</PlatformBlock>

## Anatomia

O Rating é composto por Label e Value, em que o Value é o número da escala de avaliação. O rótulo aparece quando você define `label`. Defina `max` para alterar a quantidade de símbolos (5 por padrão).

O elemento `igc-rating` renderiza o rótulo e um slider que contém os símbolos. Sem símbolos projetados, ele renderiza uma estrela para cada ponto de `max`:

```text
igc-rating
└─ #shadow-root
   ├─ label[part="label"]                    // hidden when label isn't set
   └─ div[part="base"][role="slider"]
      ├─ div[part="symbols"]                 // aria-hidden="true"
      │  └─ slot[name="symbol"]              // projected igc-rating-symbol elements
      │     └─ igc-rating-symbol × max       // default stars when nothing is projected
      │        └─ #shadow-root
      │           ├─ div[part="symbol full"]   // star_filled icon, clipped to the value
      │           └─ div[part="symbol empty"]  // star_outlined icon, clipped to the rest
      └─ label[part="value-label"]
         └─ slot[name="value-label"]         // hidden when the slot is empty
```

Cada `igc-rating-symbol` renderiza o seu slot padrão na parte `full` e o seu slot `empty` na parte `empty`.

## Uso

Use o Rating {Platform} para coletar uma pontuação para um produto, um serviço ou uma experiência, ou para mostrar uma pontuação média que os usuários não podem alterar.

### Pré-visualização ao passar o mouse

Defina `hoverPreview` para preencher os símbolos até o valor sob o ponteiro antes de o usuário clicar. Quando o ponteiro sai dos símbolos, o Rating {Platform} mostra o seu valor novamente. Um Rating somente leitura ou desabilitado não mostra pré-visualização.

<PlatformBlock for="WebComponents">

Enquanto a pré-visualização está ativa, o Rating emite `igcHover` com o valor sob o ponteiro:

```html
<igc-rating hover-preview label="Rate this article"></igc-rating>
<span id="hint"></span>
```

```ts
const rating = document.querySelector('igc-rating')!;
const hint = document.getElementById('hint')!;

rating.addEventListener('igcHover', (event) => {
  hint.textContent = `${event.detail} stars`;
});
```

</PlatformBlock>

<PlatformBlock for="React">

Enquanto a pré-visualização está ativa, o Rating chama `onHover` com o valor sob o ponteiro:

```tsx
<IgrRating
  hoverPreview={true}
  label="Rate this article"
  onHover={(e: CustomEvent<number>) => setHint(`${e.detail} stars`)}
/>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Enquanto a pré-visualização está ativa, o Rating dispara `Hover` com o valor sob o ponteiro:

```razor
<IgbRating HoverPreview="true" Label="Rate this article" Hover="OnHover" />

@code {
    private string Hint { get; set; }

    private void OnHover(IgbNumberEventArgs e)
    {
        Hint = $"{e.Detail} stars";
    }
}
```

</PlatformBlock>

<PlatformBlock for="Angular">

Enquanto a pré-visualização está ativa, o Rating emite `igcHover` com o valor sob o ponteiro:

```html
<igc-rating hover-preview label="Rate this article" (igcHover)="onHover($event)"></igc-rating>
```

```ts
public hint = '';

public onHover(event: Event) {
    this.hint = `${(event as CustomEvent<number>).detail} stars`;
}
```

</PlatformBlock>

### Layout

A propriedade `label` renderiza um rótulo visível acima dos símbolos e dá nome ao Rating {Platform} para as tecnologias assistivas. Para mostrar conteúdo personalizado ao lado dos símbolos, como a pontuação atual, coloque-o no slot `value-label`:

```html
</igc-rating>
```

Atualize o conteúdo do slot no handler `igcChange` para mantê-lo sincronizado com o valor.

</PlatformBlock>

### Estado vazio/cheio

O `value` do Rating {Platform} define o quanto os seus símbolos estão preenchidos. Um valor de 0, o padrão, mostra todos os símbolos vazios, e um valor igual a `max` mostra todos os símbolos cheios.

<PlatformBlock for="WebComponents">

Defina o valor e o máximo como atributos, e escute `igcChange` para obter o valor que o usuário seleciona:

```html
<igc-rating value="3" max="10" label="Rate this movie"></igc-rating>
```

```ts
const rating = document.querySelector('igc-rating')!;

rating.addEventListener('igcChange', (event) => {
  console.log(`New rating: ${event.detail}`);
});
```

</PlatformBlock>

<PlatformBlock for="React">

Mantenha o valor no estado e atualize-o no handler `onChange`:

```tsx
import { useState } from 'react';
import { IgrRating } from 'igniteui-react';

export default function MovieRating() {
  const [score, setScore] = useState(3);

  return (
    <IgrRating
      value={score}
      max={10}
      label="Rate this movie"
      onChange={(e: CustomEvent<number>) => setScore(e.detail)}
    />
  );
}
```

</PlatformBlock>

### Tamanho

O Rating está disponível em três tamanhos: Small, Medium e Large. Os tamanhos small, medium e large renderizam símbolos de 18px, 24px e 36px, e o Rating {Platform} usa o tamanho medium por padrão. Defina a variável CSS `--ig-size` como `--ig-size-small`, `--ig-size-medium` ou `--ig-size-large` para escolher um tamanho. Para um tamanho fora destas predefinições, defina `--ig-rating-symbol-size`:

```css
.rating-small {
  --ig-size: var(--ig-size-small);
}

.rating-large {
  --ig-size: var(--ig-size-large);
}

.rating-custom {
  --ig-rating-symbol-size: 3rem;
}
```

### Símbolos

Por padrão, o Rating {Platform} renderiza ícones de estrela. Para usar outros símbolos, coloque um <PlatformBlock for="Angular">elemento `igc-rating-symbol`</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor"><ApiLink pkg="core" type="RatingSymbol" /></PlatformBlock> para cada ponto da escala dentro do Rating. Cada símbolo de avaliação mostra o seu conteúdo do slot padrão na parte do símbolo que o valor cobre, e o conteúdo do seu slot `empty` no restante; por isso, preencha os dois slots, mesmo com o mesmo conteúdo. A quantidade de símbolos de avaliação define `max`, e o Rating ignora o `max` que você definiu.

```html
    <igc-rating-symbol>
      <igc-icon name="favorite" collection="material"></igc-icon>
      <igc-icon name="favorite_border" collection="material" slot="empty"></igc-icon>
    </igc-rating-symbol>
  }
</igc-rating>
```

</PlatformBlock>

O Rating colore os ícones e o texto com as cores de símbolo cheio e vazio do tema. Ele renderiza conteúdo diferente de um Icon no slot `empty` em escala de cinza; por isso, o mesmo emoji nos dois slots parece selecionado ou vazio.

## Estilização

O Rating {Platform} obtém as suas cores e o tamanho dos símbolos do tema. Altere-os com as variáveis CSS a seguir:

| Variável | o que muda |
| --- | --- |
| `--ig-rating-symbol-full-color` | A cor dos símbolos cheios: as estrelas padrão, os ícones e o texto. |
| `--ig-rating-symbol-empty-color` | A cor dos símbolos vazios. |
| `--ig-rating-label-color` | A cor do rótulo. |
| `--ig-rating-value-label` | A cor do rótulo do valor. |
| `--ig-rating-symbol-size` | O tamanho dos símbolos. |
| `--ig-size` | A predefinição de tamanho: `--ig-size-small`, `--ig-size-medium` ou `--ig-size-large`. |
| `--ig-rating-disabled-full-symbol-color` | A cor dos símbolos cheios quando a avaliação está desabilitada. |
| `--ig-rating-disabled-empty-symbol-color` | A cor dos símbolos vazios quando a avaliação está desabilitada. |
| `--ig-rating-disabled-label-color` | A cor do rótulo e do rótulo do valor quando a avaliação está desabilitada. |
| `--ig-rating-symbol-full-filter` | O filtro CSS dos símbolos cheios que não são ícones, como emojis, quando a avaliação está desabilitada. |
| `--ig-rating-symbol-empty-filter` | O filtro CSS dos símbolos vazios que não são ícones, como emojis, quando a avaliação está desabilitada. |

O elemento `igc-rating` expõe as partes CSS a seguir:

| Parte | o que estiliza |
| --- | --- |
| `base` | O slider que contém os símbolos e o rótulo do valor. |
| `label` | O rótulo. |
| `value-label` | O contêiner do slot `value-label`. |
| `symbols` | O contêiner de todos os símbolos. |
| `symbol` | Cada símbolo padrão. |
| `full` | A camada cheia de cada símbolo padrão. |
| `empty` | A camada vazia de cada símbolo padrão. |

O elemento `igc-rating` exporta as partes `symbol`, `full` e `empty` apenas das suas estrelas padrão. Para estilizar os símbolos de avaliação projetados, use as partes `symbol`, `full` e `empty` do elemento `igc-rating-symbol`.

## Acessibilidade

O Rating {Platform} é um slider: os usuários o alcançam com a tecla Tab, alteram o seu valor com as teclas de seta, e ouvem o valor por meio dos seus atributos ARIA.

### Interação por teclado

O Rating {Platform} é uma única parada de tabulação, porque somente o elemento slider dentro dele, a parte `base`, recebe o foco. Um Rating desabilitado sai da ordem de tabulação. Um Rating somente leitura permanece na ordem de tabulação, mas ignora as teclas a seguir, que mantêm as suas ações padrão do navegador, como a rolagem da página.

| Tecla | Ação |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Move o foco para o elemento focável seguinte ou anterior. O Rating não trata essas teclas; por isso, nunca prende o foco. |
| <kbd>Seta para a direita</kbd> | Aumenta o valor em um passo. Em um layout da direita para a esquerda, diminui. |
| <kbd>Seta para a esquerda</kbd> | Diminui o valor em um passo. Em um layout da direita para a esquerda, aumenta. |
| <kbd>Seta para cima</kbd> | Aumenta o valor em um passo. |
| <kbd>Seta para baixo</kbd> | Diminui o valor em um passo. |
| <kbd>Home</kbd> | Define o valor como um passo, o menor valor que um clique pode selecionar. |
| <kbd>End</kbd> | Define o valor como o valor máximo. |

O Rating {Platform} trata estas teclas em `keydown`:

- Ele impede a sua ação padrão, para que as teclas de seta, Home e End não rolem a página enquanto o Rating tem o foco.
- Uma tecla que você mantém pressionada repete a sua ação.
- Uma tecla que você pressiona junto com Shift, Ctrl, Alt ou Meta não faz nada.
- O valor permanece entre 0 e o valor máximo. Uma tecla que levaria o valor além de um limite mantém o valor e não emite evento.
- Cada tecla que altera o valor emite o evento de mudança.

Com o ponteiro, um clique seleciona o valor sob o ponteiro, arredondado para o próximo passo. Um Rating somente leitura ou desabilitado ignora cliques.

### Leitores de tela / ARIA

O Rating {Platform} renderiza um elemento focável, a parte `base`, com a função `slider`. O seu `tabindex` é `0`, ou `-1` quando o Rating está desabilitado, e ele carrega os atributos de valor a seguir:

| Atributo | Valor |
| --- | --- |
| `aria-valuemin` | `0` |
| `aria-valuemax` | O valor máximo |
| `aria-valuenow` | O valor, incluindo frações como `4.3` |
| `aria-valuetext` | "3 of 5" por padrão, ou o texto `valueFormat` |

<PlatformBlock for="React,WebComponents,Angular">

Com o `igniteui-webcomponents` 7.3.0 e posteriores, o slider também define `aria-disabled` e `aria-readonly` para expor os estados desabilitado e somente leitura. Com a versão 7.4.1 e posteriores, o slider obtém o seu nome acessível do primeiro dos seguintes:

1. O atributo `aria-labelledby` do host.
2. Um elemento `<label>` que é vinculado por meio de `for`, ou que envolve o Rating. Um clique no rótulo dá foco ao slider.
3. A propriedade `label`, que renderiza um rótulo visível que o slider referencia por meio de `aria-labelledby`.
4. O atributo `aria-label` do host. O slider o ignora quando a propriedade `label` está definida.

</PlatformBlock>

<PlatformBlock for="Blazor">

A propriedade `Label` renderiza um rótulo visível que o slider referencia por meio de `aria-labelledby`, o que dá ao slider o seu nome acessível.

</PlatformBlock>

O Rating {Platform} também se comporta da seguinte forma para as tecnologias assistivas:

- A parte `symbols` define `aria-hidden="true"`; por isso, os símbolos, incluindo ícones e emojis projetados, ficam ocultos e não precisam de alternativas textuais. O valor chega às tecnologias assistivas somente por meio de `aria-valuenow` e `aria-valuetext`.
- O slot `value-label` é renderizado dentro do slider. Os leitores de tela leem o valor a partir de `aria-valuetext`; por isso, descreva o valor com `valueFormat`, e não com o conteúdo do slot.
- O Rating não usa uma região ao vivo. Um valor alterado chega às tecnologias assistivas somente pelos atributos do slider.
- O Rating não define `aria-invalid`; por isso, uma mensagem de validação personalizada não é exposta como estado inválido.

A Infragistics documenta o suporte de acessibilidade do {ProductName} para as áreas das diretrizes da Seção 508 e da WCAG 2.1 no tópico [Conformidade de acessibilidade](../interactivity/accessibility-compliance.mdx).

| Critério | Como o componente atende |
| --- | --- |
| [1.1.1 Conteúdo não textual](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content) | Os símbolos ficam ocultos das tecnologias assistivas, e o slider expõe o valor como texto por meio de `aria-valuetext`. |
| [1.3.1 Informações e relações](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships) | O rótulo visível da propriedade `label` é associado ao slider por meio de `aria-labelledby`. |

Suas responsabilidades:

- Dê nome a cada Rating com a propriedade `label`<PlatformBlock for="React,WebComponents,Angular">, a um elemento `<label>` associado, ou a `aria-label`</PlatformBlock>. Veja [Layout](#layout).
- Defina `valueFormat` quando "3 of 5" não descrever a escala, ou quando a página usar outro idioma.
- Com símbolos personalizados, faça os símbolos cheios e vazios diferirem em forma ou preenchimento, e não apenas na cor, e mantenha uma razão de contraste de pelo menos 3:1 em relação ao fundo, conforme exige o [1.4.11 Contraste de conteúdo não textual](https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast).
- Ao reestilizar a parte `base`, mantenha um indicador de foco visível.
- Mantenha os alvos de ponteiro grandes o suficiente. Cada valor é um alvo tão largo quanto um símbolo, ou meio símbolo, com um passo de 0.5. O tamanho small renderiza símbolos de 18px, abaixo dos 24 por 24 pixels CSS de [2.5.8 Tamanho do alvo (mínimo)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum); por isso, prefira os tamanhos medium ou large para entrada por ponteiro e por toque.
- Não coloque informações apenas na pré-visualização ao passar o mouse, porque os usuários de teclado não as veem.
- Quando você validar a avaliação com uma mensagem de validação personalizada, mostre também a mensagem como texto ao lado do Rating, conforme exige o [3.3.1 Identificação de erro](https://www.w3.org/WAI/WCAG21/Understanding/error-identification), porque o Rating não define `aria-invalid`.

Diferenças em relação ao [padrão WAI-ARIA slider](https://www.w3.org/WAI/ARIA/apg/patterns/slider/):

- <kbd>Home</kbd> define o valor como um passo, em vez de `aria-valuemin`, que é 0. Use <kbd>Seta para baixo</kbd> para chegar a 0.
- O Rating não oferece suporte a <kbd>Page Up</kbd> e <kbd>Page Down</kbd>, que o padrão lista como teclas opcionais.

## Solução de problemas

Use estas respostas quando um Rating {Platform} não se comportar como esperado.

### Por que o evento de mudança não é disparado quando defino o valor?

O Rating {Platform} emite o evento de mudança somente para a entrada do usuário: um clique ou uma tecla. Definir o valor no código, ou chamar os métodos de passo, altera o valor sem o evento; por isso, atualize o seu próprio estado no lugar em que define o valor.

### Por que um clique no valor atual não redefine a avaliação?

O Rating {Platform} mantém o valor em um clique no valor atual, a menos que você defina `allowReset`. Antes do `igniteui-webcomponents` 4.7.0, um clique no valor atual sempre redefinia a avaliação; defina `allowReset` para manter esse comportamento após uma atualização.

### Por que o evento de hover não é disparado?

O Rating {Platform} emite o evento de hover somente enquanto `hoverPreview` está ligado, e não quando o Rating é somente leitura ou está desabilitado. Defina `hoverPreview` para receber o evento.
