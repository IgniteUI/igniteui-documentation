## Uso

Defina `value` com qualquer string para renderizar um código QR legível. O componente escolhe o modo de codificação mais compacto (numérico, alfanumérico ou de bytes) e a menor versão de QR que cabe no valor. Limpar `value` remove o SVG.

### Correção de erros

Use `errorLevel` para escolher o nível de correção de erros: `L`, `M` (padrão), `Q` ou `H`. Níveis mais altos recuperam mais informações de um código danificado ou coberto, mas produzem um código mais denso. Use `version` para fixar uma versão de QR de `1` a `40` quando precisar de dimensões de módulo previsíveis; deixe-a sem definir para usar a menor versão que cabe em `value`.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-qr-code
  value="https://www.infragistics.com"
  version="4"
  error-level="H">
</igc-qr-code>
```

</PlatformBlock>

### Logo central

Defina `logoSrc` para renderizar uma imagem no centro do código; o componente mascara os módulos abaixo dela. `logoSize` define o tamanho do logo como uma razão, de `0` a `1`, da maior área segura para o logo, que é 9% do código no nível `H`. `logoMargin` adiciona espaço em branco ao redor do logo, em pixels.

O logo nunca cobre mais do que o `errorLevel` atual permite. No nível `M` padrão, valores de `logoSize` acima de cerca de `0.44` são renderizados no mesmo tamanho limitado; por isso, defina `errorLevel` como `H` para o maior logo.

`logoSrc` aceita URLs comuns e URIs `data:image/*`. Fontes com esquemas inseguros (como `javascript:` ou `vbscript:`) e URIs `data:` que não são de imagem são rejeitadas, e nenhum logo é renderizado.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-qr-code
  value="https://www.infragistics.com"
  error-level="H"
  logo-src="/assets/logo.png"
  logo-size="0.5"
  logo-margin="4">
</igc-qr-code>
```

</PlatformBlock>

### Exportação

Chame `toImage()` para exportar o QR code como um arquivo PNG, JPEG, WebP ou SVG, ou `toBlob()` para obtê-lo como um `Blob` SVG. Ambos os métodos resolvem as cores do tema e incorporam o logo, de modo que a exportação corresponde ao código renderizado.

```ts
const qrCode = document.querySelector('igc-qr-code') as IgcQrCodeComponent;

// Downloads a 512×512 PNG from a 256px QR code.
await qrCode.toImage({ format: 'png', scale: 2, fileName: 'my-qr-code', download: true });
```

</PlatformBlock>

### Faça/Não faça

**Quando usar:** os QR codes oferecem aos usuários uma ponte rápida entre um material impresso ou uma tela estática e uma ação digital, como abrir uma página, baixar um aplicativo ou verificar um link.

**Quando não usar:** evite QR codes para informações que precisam ser legíveis sem um leitor, ou quando um botão, um link direto ou uma URL curta atendem melhor ao destino.

## Métodos

| Nome | Retorna | Descrição |
| -- | -- | -- |
| `toBlob()` | `Promise<Blob>` | Serializa o QR code em um blob `image/svg+xml`, com as cores do tema resolvidas e o logo incorporado. Rejeita quando `value` não está definido. |
| `toImage(options?)` | `Promise<File>` | Exporta o QR code como um arquivo de imagem. `options` aceita `format` (`'png'` padrão, `'jpeg'`, `'webp'` ou `'svg'`), `scale` (padrão `1`), `fileName` (padrão `'qr-code'`) e `download` (padrão `false`). Rejeita quando `value` não está definido ou as opções são inválidas. |

A aparência do QR Code {Platform} é controlada por variáveis CSS, partes CSS e pelo sistema de temas.

### Variáveis de estilo

| Variável | o que muda |
| -- | -- |
| `--ig-qr-code-background` | A cor de fundo do QR code. O padrão é `white`. |
| `--ig-qr-code-dark-color` | A cor dos módulos de dados e, a menos que sejam sobrescritas, as cores dos quadrados e dos pontos dos cantos. O padrão é `black`. |
| `--ig-qr-code-corner-square-color` | A cor dos quadrados externos dos cantos do padrão de localização. Usa `--ig-qr-code-dark-color` como alternativa. |
| `--ig-qr-code-corner-dot-color` | A cor dos pontos internos dos cantos do padrão de localização. Usa `--ig-qr-code-dark-color` como alternativa. |

### Partes de estilo

| Parte | o que estiliza |
| -- | -- |
| `background` | O retângulo de fundo do QR code. |
| `dots` | Os módulos de dados (pontos) do QR code. |
| `corner-square` | Os quadrados externos dos cantos do padrão de localização. |
| `corner-dot` | Os pontos internos dos cantos do padrão de localização. |

### Temas em Sass

Crie um tema com `qr-code-theme()` e passe-o para o mixin `tokens`.

```scss
@use "igniteui-theming/sass/themes" as *;

$custom-qr-code-theme: qr-code-theme(
  $background: #ffffff,
  $dark-color: #1a1a2e,
  $corner-square-color: #c0392b,
  $corner-dot-color: #1a1a2e
);

:root {
  @include tokens($custom-qr-code-theme);
}
```

### Variáveis CSS

Defina as variáveis CSS do componente diretamente quando precisar de estilização local, sem uma etapa de build com Sass.

```css
igc-qr-code {
  --ig-qr-code-background: var(--ig-gray-50);
  --ig-qr-code-dark-color: var(--ig-primary-800);
```

## Acessibilidade

O QR Code {Platform} é um gráfico estático que os leitores de tela anunciam por meio do `<title>` do seu SVG.

### Interação por teclado

O QR Code não é focável e não responde à entrada pelo teclado.

### Leitores de tela / ARIA

O `<svg>` renderizado tem `role="img"` e um `<title>` que os leitores de tela anunciam. O título tem como padrão `QR code: <value>`; defina `aria-label` para anunciar uma frase mais significativa.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-qr-code
  value="https://www.infragistics.com/products"
  aria-label="Scan to visit our product page">
</igc-qr-code>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrQrCode
  value="https://www.infragistics.com/products"
  ariaLabel="Scan to visit our product page">
</IgrQrCode>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbQrCode
  Value="https://www.infragistics.com/products"
  AriaLabel="Scan to visit our product page">
```

</PlatformBlock>

### Conformidade de acessibilidade

A Infragistics documenta o suporte de acessibilidade do {ProductName} para as áreas das diretrizes da Seção 508 e da WCAG 2.1 no tópico [Conformidade de acessibilidade](../interactivity/accessibility-compliance.mdx).

| Critério | Como o componente atende |
| -- | -- |
| [1.1.1 Conteúdo não textual](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content) | O `<title>` do SVG fornece uma alternativa textual, obtida de `aria-label` ou derivada de `value`. |
| [1.4.11 Contraste de conteúdo não textual](https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast) | Os módulos pretos padrão sobre um fundo branco superam a razão de contraste de 3:1 exigida para objetos gráficos. |
| [4.1.2 Nome, função, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | O SVG expõe `role="img"` com o `<title>` como seu nome acessível. |

Suas responsabilidades:

- Combine o QR Code com uma chamada para ação curta e visível, para que os usuários que enxergam saibam o que acontecerá depois de escanear.
- Forneça um `aria-label` quando o `value` codificado for opaco (por exemplo, um token ou um identificador curto), para que o texto anunciado seja significativo.
- Mantenha contraste suficiente entre a cor dos módulos e o fundo ao sobrescrever as variáveis CSS, para que os leitores consigam ler o código com confiabilidade.

## Solução de problemas

As orientações de solução de problemas do QR Code {Platform} seguem o formato problema → causa → correção para problemas comuns de integração e de renderização.

### Por que o meu QR code não é lido?

O contraste entre os módulos e o fundo é baixo demais, o código é pequeno demais na tela, ou a margem da zona silenciosa é pequena demais. Restaure as cores `black` padrão em `white`, aumente `size`, e use um `margin` de pelo menos `4` módulos para uma leitura confiável.

### Por que o meu logo é menor do que o logoSize que defini?

O logo é limitado à área segura do `errorLevel` atual. Defina `errorLevel` como `H` para permitir o maior logo.

### Por que o meu logo não aparece?

`logoSrc` usa uma fonte rejeitada (um esquema inseguro ou uma URI `data:` que não é de imagem), ou a imagem não foi carregada. Use uma URL de imagem válida ou uma URI `data:image/*`; atribuir depois uma fonte válida renderiza o logo.

### Por que o meu QR code não mudou automaticamente para um tema escuro?

As cores do QR Code não se invertem com o tema claro/escuro global, porque códigos claros sobre fundo escuro não são lidos de forma confiável. Para alterá-las na variante escura da sua interface, defina `--ig-qr-code-background` e `--ig-qr-code-dark-color` explicitamente.

## Limitações conhecidas

O QR Code {Platform} tem as seguintes limitações.

- O QR Code não tem slots nem eventos.
- A estrutura visual do QR Code segue um layout fixo e padronizado, e não é espelhada em contextos Right-to-Left.

<PlatformBlock for="WebComponents, Angular">

- As exportações omitem um logo carregado de uma URL de origem cruzada que não envia cabeçalhos CORS.

</PlatformBlock>

## Perguntas frequentes

<Faq>
  <FaqItem question="Quais dados posso codificar em um QR Code?" indicatorPosition="end">
    A propriedade `value` aceita qualquer string. Usos comuns incluem URLs, texto simples, referências de pagamento, tokens de configuração de uso único, credenciais de Wi-Fi e cargas de vCard. O componente seleciona automaticamente o modo de codificação mais compacto (numérico, alfanumérico ou de bytes) que cabe na entrada.
  </FaqItem>

  <FaqItem question="Preciso de uma conexão com a internet ou de uma biblioteca externa para renderizar um QR Code?" indicatorPosition="end">
    Não. O componente QR Code gera o SVG inteiramente no cliente, a partir da string `value`, sem depender de bibliotecas externas de geração de QR. A única requisição de rede é para a imagem do logo central, carregada de uma URL.
  </FaqItem>

  <FaqItem question="Quão grande pode ser o logo central sem quebrar o código?" indicatorPosition="end">
    A razão `logoSize` (padrão `0.4`) é uma fração da maior área segura para o logo, que é 9% do código no nível de erro `H`. O QR Code limita o logo à área segura do `errorLevel` atual, para que o código continue legível. Defina `errorLevel` como `H` para permitir o maior logo.
  </FaqItem>

  <FaqItem question="Qual pacote fornece o QR Code?" indicatorPosition="end">
    <PlatformBlock for="WebComponents, Angular">O QR Code vem no pacote `igniteui-webcomponents`, na versão 7.3.0 ou posterior.</PlatformBlock>
    <PlatformBlock for="Angular">Aplicações Angular o instalam diretamente, porque o `igniteui-angular` não inclui o QR Code.</PlatformBlock>
    <PlatformBlock for="React, Blazor">O QR Code vem no pacote `{PackageCommon}`.</PlatformBlock>
  </FaqItem>
</Faq>
