# Combo de seleção única

O Combo de seleção única {ProductName} é um Combo no qual os usuários selecionam uma opção e filtram a lista suspensa pesquisável digitando no campo de input.

<PlatformBlock for="Angular">

O Combo de seleção única do Angular é o Combo simples, o componente `igx-simple-combo`. Ele faz o binding, agrupa e aplica template às suas opções como o Combo, e permite que os usuários digitem no campo de input para filtrar a lista ou informar um valor personalizado.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Defina <PlatformBlock for="React,WebComponents"><ApiLink type="Combo" member="singleSelect" label="singleSelect" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink pkg="core" type="Combo<T>" member="SingleSelect" label="SingleSelect" /></PlatformBlock> no Combo {Platform} para alterá-lo para seleção única. O campo de input se torna editável e filtra a lista conforme os usuários digitam, o input de pesquisa do dropdown fica oculto e as opções não mostram caixas de seleção.

</PlatformBlock>

<DocsAside type="info">
O Combo tem duas opções de layout: Combo com seleção única (Combo simples) e Combo (seleção múltipla).
</DocsAside>

## Uso

Use o Combo de seleção única {Platform} quando os usuários escolherem exatamente uma opção de uma lista que precisem pesquisar, como um país ou uma cidade.

### Tipo (tema Material)

No tema Material, o Input do Combo simples oferece a escolha entre um tipo com borda, para uma percepção mais estruturada sobre fundos de cor sólida, e um tipo em caixa, mais adequado quando colocado sobre uma imagem vívida para melhorar a legibilidade. Os temas Bootstrap, Fluent e Indigo desenham os dois tipos da mesma forma; por isso, os outros exemplos deste tópico mostram o tipo em caixa somente no tema Material.

### Tamanho

```css
.small {
  --ig-size: var(--ig-size-small);
}

.large {
  --ig-size: var(--ig-size-large);
}
```

### Estados de interação

### Estados de validação

Todo designer experiente usa restrições com sabedoria para limitar a entrada do usuário e evitar estados inválidos; daí a disponibilidade de estilos de validação. Por meio dos estilos de validação disponíveis, o Input do Combo é consistente com o padrão <PlatformBlock for="Angular">[Input](../../input-group.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Input](../input.mdx)</PlatformBlock> e preparado para designs sofisticados que exibem visuais de sucesso, aviso e erro.

<PlatformBlock for="React,WebComponents,Blazor">

O Combo {Platform} é associado a formulários. Defina `required` para exigir um item selecionado, e `invalid` para exibir o estado de erro. Coloque a orientação ou a mensagem de erro no slot `helper-text`. No modo de seleção única, o valor do formulário é o valor `valueKey` do item selecionado. O Combo não tem estados de sucesso ou de aviso integrados. O exemplo mostra os estados de sucesso e de aviso como Combos inválidos que usam a cor de sucesso ou de aviso do tema no lugar da cor de erro.

</PlatformBlock>

### Tamanho do dropdown

### Valor e seleção

O Combo de seleção única {Platform} mantém um item selecionado e o expõe por meio do seu valor e da sua API de seleção.

<PlatformBlock for="React,WebComponents,Blazor">

A `value` mantém o item selecionado como um array com um elemento: o seu valor `valueKey`, ou a referência do objeto quando não há `valueKey`. Defina-a para selecionar um item quando o Combo for renderizado pela primeira vez. O método `select` seleciona um único item e desmarca o anterior; por isso, passe um item. O método `deselect` o desmarca. Chamado sem um item, `select` limpa a seleção no modo de seleção única:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
// select the item matching the 'BG' value of the value key field
combo.select('BG');

// deselect it
combo.deselect('BG');

console.log(combo.value); // ['BG'] while Bulgaria is selected, [] after the deselection
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
// select the item matching the 'BG' value of the value key field
comboRef.current?.select('BG');

// deselect it
comboRef.current?.deselect('BG');

console.log(comboRef.current?.value); // ['BG'] while Bulgaria is selected, [] after the deselection
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCombo T="string" @ref="Combo" SingleSelect="true" Data="Countries" ValueKey="Id" DisplayKey="Name" />

@code {

    public void SelectBulgaria() => Combo.Select(new object[] { "BG" });

    public void DeselectBulgaria() => Combo.Deselect(new object[] { "BG" });
}
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

O seu detalhe contém o novo valor, os itens alterados e o tipo da mudança, e cancelá-lo mantém a seleção.

</PlatformBlock>

<PlatformBlock for="Angular">

O Combo simples do Angular oferece suporte a binding bidirecional com `[(ngModel)]` e funciona em formulários orientados por template e reativos. O valor vinculado é um único item: o seu valor `valueKey`, ou a referência do objeto quando não há `valueKey`. A propriedade <ApiLink type="SimpleCombo" member="selection" label="selection" /> retorna o item selecionado, o método <ApiLink type="SimpleCombo" member="select" label="select" /> seleciona um item, e o método <ApiLink type="SimpleCombo" member="deselect" label="deselect" /> limpa a seleção:

```ts
    public combo: IgxSimpleComboComponent;

    public selectedCountry = 'BG';

    public selectBelgium(): void {
        this.combo.select('BE');

    public clear(): void {
        this.combo.deselect();
    }
}
```

O Combo simples do Angular emite <ApiLink type="SimpleCombo" member="selectionChanging" label="selectionChanging" /> antes de a seleção mudar, e <ApiLink type="SimpleCombo" member="selectionChanged" label="selectionChanged" /> depois disso. Os argumentos do evento contêm o valor antigo e o novo, o item antigo e o novo, e o texto de exibição do campo de input; definir `cancel` em `selectionChanging` mantém a seleção:

```html
<igx-simple-combo [data]="countries" valueKey="id" displayKey="name" (selectionChanging)="onCountryChanging($event)"></igx-simple-combo>
```

```ts
public onCountryChanging(event: ISimpleComboSelectionChangingEventArgs): void {
    if (event.newValue === 'BY') {
        event.cancel = true;
    }
}
```

O evento `selectionChanging` também conduz um cenário em cascata, no qual a seleção de um Combo simples carrega os dados do próximo, por exemplo, um combo de país, de região e de cidade. Trate o evento `selectionChanging` de cada Combo simples para carregar os dados do próximo e limpar a sua seleção:

```html
<igx-simple-combo #country
    [data]="countriesData"
    (selectionChanging)="countryChanging($event)"
    placeholder="Choose Country..."
    [(ngModel)]="selectedCountry"
    displayKey="name">
</igx-simple-combo>
<igx-simple-combo #region
    [data]="regionData"
    (selectionChanging)="regionChanging($event)"
    placeholder="Choose Region..."
    [(ngModel)]="selectedRegion"
    displayKey="name"
    [disabled]="regionData.length === 0">
</igx-simple-combo>
<igx-simple-combo #city
    [data]="citiesData"
    placeholder="Choose City..."
    [(ngModel)]="selectedCity"
    displayKey="name"
    [disabled]="citiesData.length === 0">
</igx-simple-combo>
```

```ts
export class SimpleComboCascadingComponent implements OnInit {
    public selectedCountry: Country;
    public selectedRegion: Region;
    public selectedCity: City;
    public countriesData: Country[];
    public regionData: Region[] = [];
    public citiesData: City[] = [];

    public ngOnInit(): void {
        this.countriesData = getCountries(['United States', 'Japan', 'United Kingdom']);
    }

    public countryChanging(e: ISimpleComboSelectionChangingEventArgs) {
        this.selectedCountry = e.newSelection as Country;
        this.regionData = getCitiesByCountry([this.selectedCountry?.name])
            .map(c => ({ name: c.region, country: c.country }))
            .filter((v, i, a) => a.findIndex(r => r.name === v.name) === i);
        this.selectedRegion = null;
        this.selectedCity = null;
        this.citiesData = [];
    }

    public regionChanging(e: ISimpleComboSelectionChangingEventArgs) {
        this.selectedRegion = e.newSelection as Region;
        this.citiesData = getCitiesByCountry([this.selectedCountry?.name])
            .filter(c => c.region === this.selectedRegion?.name);
        this.selectedCity = null;
    }
}
```

O tópico [Grade com Combos em cascata](../../grid/cascading-combos.mdx) mostra o mesmo cenário na edição de células do Data Grid.

</PlatformBlock>

### Filtragem

Digitar no campo de input do Combo de seleção única {Platform} abre o dropdown e filtra a lista para as opções que contêm o texto. A primeira correspondência se torna a opção ativa; por isso, <kbd>Enter</kbd> a seleciona.

<PlatformBlock for="React,WebComponents,Blazor">

Defina `disableFiltering` para manter a lista inteira enquanto os usuários digitam. O objeto `filteringOptions` define a chave pela qual o texto filtra, e se a filtragem diferencia maiúsculas de minúsculas e considera diacríticos. Quando o Combo perde o foco sem uma opção selecionada, o campo de input é limpo.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
combo.filteringOptions = { filterKey: 'name', caseSensitive: false, matchDiacritics: true };
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrCombo singleSelect filteringOptions={{ filterKey: 'name', caseSensitive: false, matchDiacritics: true }} />
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCombo T="string" SingleSelect="true" DisableFiltering="true" Data="Countries" ValueKey="Id" DisplayKey="Name" />
```

</PlatformBlock>

<PlatformBlock for="Angular">

Defina <ApiLink type="SimpleCombo" member="disableFiltering" label="disableFiltering" /> para manter a lista inteira enquanto os usuários digitam, e <ApiLink type="SimpleCombo" member="showSearchCaseIcon" label="showSearchCaseIcon" /> para exibir um botão no campo de input que alterna a filtragem com diferenciação de maiúsculas e minúsculas. O input <ApiLink type="SimpleCombo" member="filteringOptions" label="filteringOptions" /> define a chave pela qual o texto filtra e se a filtragem diferencia maiúsculas de minúsculas, e <ApiLink type="SimpleCombo" member="filterFunction" label="filterFunction" /> substitui a filtragem por uma própria. Quando o Combo simples perde o foco sem uma opção selecionada, o campo de input é limpo:

```html
<igx-simple-combo [data]="countries" displayKey="name" [showSearchCaseIcon]="true"
                  [filteringOptions]="{ filteringKey: 'name', caseSensitive: false }">
</igx-simple-combo>
```

Defina <ApiLink type="SimpleCombo" member="allowCustomValues" label="allowCustomValues" /> para permitir que os usuários informem um valor que não está na lista. Quando o texto não corresponde a nenhuma opção, o dropdown mostra um botão de adicionar item, e <kbd>Enter</kbd> nele adiciona o texto como um novo item e o seleciona. O Combo simples emite <ApiLink type="SimpleCombo" member="addition" label="addition" /> antes de adicionar o item:

```html
<igx-simple-combo [data]="countries" displayKey="name" valueKey="id" [allowCustomValues]="true" (addition)="onAddition($event)"></igx-simple-combo>
```

</PlatformBlock>

### Faça/Não faça

Ao usar o Combo simples, o seu input e o seu dropdown devem ter a mesma largura, e as suas bordas esquerda e direita devem coincidir. Quanto à forma como o dropdown é exibido quando o Combo simples recebe foco, mostre-o sempre por cima do conteúdo que vem depois do Combo simples que dispara a sua exibição. Os Combos não empurram o conteúdo como os painéis de expansão fazem.

### Temas em Sass

Ao modificar uma propriedade primária, todas as propriedades dependentes relacionadas são atualizadas automaticamente para refletir a mudança. O parâmetro primário da <PlatformBlock for="Angular"><ApiLink kind="sass" module="themes" type="function-combo-theme" label="combo-theme" code={true} /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">`combo-theme`</PlatformBlock> função é `$toggle-button-background`, a partir do qual o tema deriva as cores do botão de alternância em todos os estados. );

```scss
$custom-drop-down-theme: drop-down-theme(
  $background-color: #e6f2ff,
  $selected-item-background: #4ca7e3
);

:host {
  @include tokens($custom-combo-theme);
  @include tokens($custom-drop-down-theme);
}
```

O Combo simples do Angular exibe o seu dropdown em um overlay. Dependendo da encapsulação de view e de onde está o outlet do overlay, um tema incluído em `:host` pode não chegar ao dropdown. Veja o tópico [Estilização do overlay](../../overlay-styling.mdx).

</PlatformBlock>

## Acessibilidade

O Combo de seleção única {Platform} usa as funções do padrão WAI-ARIA combobox: o campo de input editável é um `combobox` que controla uma `listbox` de opções, e os usuários filtram a lista digitando e selecionam uma opção pelo teclado.

### Interação por teclado

<PlatformBlock for="React,WebComponents,Blazor">

O campo de input do Combo de seleção única {Platform} é uma parada de tabulação, e o foco permanece nele enquanto os usuários digitam. As teclas a seguir funcionam enquanto o Combo tem o foco:

| Tecla | Ação |
| --- | --- |
| Caracteres imprimíveis | No campo de input, abre o dropdown, filtra a lista e ativa a primeira correspondência. |
| <kbd>Seta para baixo</kbd> / <kbd>Alt</kbd> + <kbd>Seta para baixo</kbd> | No campo de input, abre o dropdown, move o foco para a lista e ativa a primeira opção. Na lista, ativa a próxima opção. |
| <kbd>Seta para cima</kbd> | No campo de input, fecha o dropdown. Na lista, ativa a opção anterior. A partir da primeira opção, fecha o dropdown e move o foco para o campo de input. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Na lista, ativa a primeira ou a última opção. |
| <kbd>Space</kbd> | Na lista, seleciona a opção ativa, ou a desmarca quando ela já está selecionada. |
| <kbd>Enter</kbd> | Com uma opção ativa, a seleciona, fecha o dropdown e move o foco para o campo de input com o seu texto selecionado. |
| <kbd>Escape</kbd> | Quando o dropdown está aberto, fecha-o e move o foco para o campo de input. Quando o dropdown está fechado, limpa a seleção. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Quando o dropdown está aberto, seleciona a opção ativa, fecha o dropdown e move o foco para o próximo ou o anterior elemento focável. |

Um Combo desabilitado ignora essas teclas.

</PlatformBlock>

<PlatformBlock for="Angular">

O campo de input do Combo simples do Angular é uma parada de tabulação, e o foco permanece nele enquanto os usuários digitam. As teclas a seguir funcionam enquanto o Combo simples tem o foco:

| Tecla | Ação |
| --- | --- |
| Caracteres imprimíveis | No campo de input, abre o dropdown, filtra a lista e dá foco à primeira correspondência. |
| <kbd>Seta para baixo</kbd> / <kbd>Alt</kbd> + <kbd>Seta para baixo</kbd> | No Combo simples fechado, abre o dropdown. No Combo simples aberto, move o foco para a lista: para a opção selecionada ou para a primeira opção. Na lista, move para a próxima opção, e da última opção para o botão de adicionar item quando ele é exibido. |
| <kbd>Seta para cima</kbd> | Na lista, move para a opção anterior. A partir da primeira opção, move o foco de volta para o campo de input e seleciona o seu texto. |
| <kbd>Alt</kbd> + <kbd>Seta para cima</kbd> | Na lista, fecha o dropdown e move o foco para o campo de input. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Na lista, move para a primeira ou a última opção. |
| <kbd>Space</kbd> | Na lista, seleciona ou desmarca a opção com foco. |
| <kbd>Enter</kbd> | No campo de input, com uma opção com foco que corresponde ao texto, seleciona-a e fecha o dropdown. Na lista, seleciona a opção com foco, fecha o dropdown e move o foco para o campo de input. No botão de adicionar item, adiciona o texto do campo de input como um novo item e o seleciona. |
| <kbd>Backspace</kbd> / <kbd>Delete</kbd> | No campo de input, limpa a seleção. |
| <kbd>Escape</kbd> | Quando o dropdown está aberto, fecha-o. Quando o dropdown está fechado, limpa a seleção e mantém o foco no campo de input. |

### Leitores de tela / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

O Combo de seleção única {Platform} renderiza as funções e os atributos a seguir:

| Elemento | Função | Atributos |
| --- | --- | --- |
| O campo de input | `combobox` | `aria-haspopup="listbox"`, `aria-expanded`, `aria-disabled`, `aria-controls` que aponta para a lista e, com um texto de ajuda, `aria-describedby` que aponta para ela |
| A parte `list` | `listbox` | `aria-multiselectable="false"`, `aria-labelledby` que aponta para o campo de input, e `aria-activedescendant` que aponta para a opção ativa |
| Cada parte `item` | `option` | `aria-selected`, `aria-posinset` e `aria-setsize` |
| A parte `clear-icon` | `button` | `aria-label` das strings de recurso |

O Combo de seleção única {Platform} também se comporta da seguinte forma para as tecnologias assistivas:

- O campo de input obtém o seu nome acessível a partir do `label`. Sem um rótulo, ele recebe um nome das strings de recurso que informa se uma opção está selecionada.
- O campo de input é editável, e o texto que os usuários digitam é o filtro da lista.
- A opção ativa é anunciada por meio de `aria-activedescendant` enquanto o foco permanece na lista.
- O conteúdo do dropdown fechado é `inert`.

</PlatformBlock>

## Limitações conhecidas

<PlatformBlock for="React,WebComponents,Blazor">

- O modo de seleção única oculta o input de pesquisa do dropdown; por isso, `placeholderSearch`, `caseSensitiveIcon` e `autofocusList` não têm efeito.
- O Combo {Platform} não adiciona valores personalizados. Quando o texto do campo de input não corresponde a nenhuma opção, o Combo limpa o campo de input ao perder o foco.

</PlatformBlock>

<PlatformBlock for="Angular">

- Quando o Combo simples do Angular é vinculado a um array de primitivos que contém `undefined`, a lista não mostra `undefined`. Quando o campo `valueKey` de um objeto é `undefined`, a lista mostra o item, mas os usuários não conseguem selecioná-lo.
- Quando o Combo simples do Angular é vinculado com `ngModel` e está `required`, os valores `null`, `undefined` e `''` não podem ser selecionados.
- Quando o Combo simples do Angular é vinculado a um serviço remoto e tem uma seleção predefinida, o campo de input fica em branco até que os dados sejam carregados.
- A lista usa o [Virtual Scroll](../../layouts/virtual-scroll.mdx#limitações-conhecidas); por isso, as limitações dele se aplicam. A lista renderiza somente as opções visíveis, e o código que consulta o DOM encontra apenas essas opções.

</PlatformBlock>

## Perguntas frequentes

Estas perguntas cobrem cenários comuns de configuração, seleção e uso do Combo de seleção única {Platform}.

<Faq>
  <FaqItem question="Como faço o Combo selecionar um único item?" indicatorPosition="end">
    <PlatformBlock for="Angular">Use o Combo simples do Angular, o componente `igx-simple-combo`, em vez do Combo. O Combo simples seleciona um item e permite que os usuários digitem no campo de input para filtrar a lista.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">Defina `singleSelect` no Combo {Platform}. O Combo então seleciona um item por vez, permite que os usuários digitem no campo de input para filtrar a lista, e oculta o input de pesquisa e as caixas de seleção do dropdown.</PlatformBlock>
  </FaqItem>
  <FaqItem question="Como defino o item selecionado do Combo de seleção única?" indicatorPosition="end">
    <PlatformBlock for="Angular">Vincule o Combo simples do Angular com `[(ngModel)]` ou com um controle de formulário a um único valor `valueKey`, ou chame o método `select` com o item. Sem um `valueKey`, o Combo simples usa uma referência ao objeto no seu `data`.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">Defina a `value` do Combo {Platform} como um array com o valor `valueKey` do item, ou chame o método `select` com o item. Sem um `valueKey`, o Combo {Platform} usa uma referência ao objeto no seu `data`.</PlatformBlock>
  </FaqItem>
  <FaqItem question="Os usuários podem informar um valor que não está na lista?" indicatorPosition="end">
    <PlatformBlock for="Angular">Sim. Defina `allowCustomValues` no Combo simples do Angular, e o dropdown mostra um botão de adicionar item quando o texto não corresponde a nenhuma opção. O Combo simples adiciona o texto como um novo item e o seleciona.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">Não. O Combo {Platform} seleciona opções somente da sua `data`. Quando o texto no campo de input não corresponde a nenhuma opção, o Combo limpa o campo de input ao perder o foco.</PlatformBlock>
  </FaqItem>
  <FaqItem question="Por que digitar no Combo de seleção única não filtra a lista?" indicatorPosition="end">
    <PlatformBlock for="Angular">O Combo simples do Angular filtra pelo campo `displayKey`. Verifique se `disableFiltering` não está definido, e se `filteringOptions` ou `filterFunction` correspondem ao campo que a lista mostra.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">O Combo {Platform} filtra pelo campo `displayKey`, ou pelo `filterKey` do seu `filteringOptions`. Verifique se `disableFiltering` não está definido, e se a chave nomeia um campo das opções.</PlatformBlock>
  </FaqItem>
  <FaqItem question="Devo usar o Combo de seleção única ou o Select?" indicatorPosition="end">
    Use o Combo de seleção única {Platform} quando a lista for longa e os usuários precisarem pesquisá-la digitando. Use o Select {Platform} para uma lista curta da qual os usuários escolhem uma opção sem pesquisar.
  </FaqItem>
</Faq>
