# Combo

O Combo {ProductName} é um componente que combina um campo de input com uma lista suspensa pesquisável, permitindo que os usuários filtrem as opções digitando e selecionem um ou mais itens.

<PlatformBlock for="Angular">

O Combo do Angular é o componente `igx-combo`. Ele mostra as suas opções em uma lista suspensa virtualizada e oferece suporte a filtragem, agrupamento, valores personalizados e binding bidirecional com formulários do Angular.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

O Combo mostra as suas opções em uma lista virtualizada; por isso, a lista pode conter milhares de opções. O Combo oferece suporte a filtragem com diferenciação de maiúsculas e minúsculas, agrupamento e binding a dados complexos.

</PlatformBlock>

   ├─ igc-popover
   │  ├─ igc-input#target[slot="anchor"]            // the input field, exported as the "input" part

   │  │  ├─ span[part="clear-icon"]                  // shown when the Combo has a value
   │  │  ├─ slot[name="suffix"]

   │  └─ div[part="list-wrapper"]                    // the dropdown
   │     ├─ div[part="filter-input"]
   │     │  └─ igc-input[part="search-input"]        // hidden with disable-filtering or single-select
   │     ├─ div[part="header"]
   │     │  └─ slot[name="header"]
   │     ├─ igc-virtual-scroll#dropdown[part="list"][role="listbox"]
   │     │  ├─ igc-combo-header[part="group-header"] // one for each group
   │     │  └─ igc-combo-item[part="item"]           // one for each option
   │     ├─ div[part="empty"]                        // shown when the list has no options
   │     │  └─ slot[name="empty"]
   │     └─ div[part="footer"]

## Uso

Use o Combo {Platform} quando os usuários escolherem uma ou mais opções em uma lista longa e precisarem pesquisá-la, como uma lista de cidades ou países.

### Tipo (tema Material)

No tema Material, o Input do Combo oferece a escolha entre um tipo com borda, para uma percepção mais estruturada sobre fundos de cor sólida, e um tipo em caixa, mais adequado quando colocado sobre uma imagem vívida para melhorar a legibilidade. Os temas Bootstrap, Fluent e Indigo desenham os dois tipos da mesma forma; por isso, os outros exemplos deste tópico mostram o tipo em caixa somente no tema Material.

### Estados de validação

Todo designer experiente usa restrições com sabedoria para limitar a entrada do usuário e evitar estados inválidos; daí a disponibilidade de estilos de validação. Por meio dos estilos de validação disponíveis, o Input do Combo é consistente com o padrão <PlatformBlock for="Angular">[Input](../../input-group.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Input](../input.mdx)</PlatformBlock> e preparado para designs sofisticados que exibem visuais de sucesso, aviso e erro.

<PlatformBlock for="React,WebComponents,Blazor">

O {Platform} Combo é associado a formulários. Defina `required` para exigir pelo menos um item selecionado, e `invalid` para exibir o estado de erro. Coloque a orientação ou a mensagem de erro no slot `helper-text`. O Combo também expõe os métodos `checkValidity`, `reportValidity` e `setCustomValidity` da API de validação de restrições. O Combo não tem estados de sucesso ou de aviso integrados. O exemplo mostra os estados de sucesso e de aviso como Combos inválidos que usam a cor de sucesso ou de aviso do tema no lugar da cor de erro.

</PlatformBlock>

### Input de pesquisa do dropdown

O dropdown do Combo {Platform} contém um input de pesquisa que filtra as opções conforme os usuários digitam.

<PlatformBlock for="React,WebComponents,Blazor">

Defina o texto do input de pesquisa vazio com `placeholderSearch`, exiba um botão que alterna a filtragem com diferenciação de maiúsculas e minúsculas com `caseSensitiveIcon`, e oculte o input de pesquisa com `disableFiltering`. O objeto `filteringOptions` define a chave pela qual a pesquisa filtra e se a filtragem diferencia maiúsculas de minúsculas e considera diacríticos:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-combo placeholder-search="Search cities" case-sensitive-icon></igc-combo>
```

```ts
combo.filteringOptions = { filterKey: 'name', caseSensitive: false, matchDiacritics: true };
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrCombo
  placeholderSearch="Search cities"
  caseSensitiveIcon
  filteringOptions={{ filterKey: 'name', caseSensitive: false, matchDiacritics: true }}
/>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCombo T="object" PlaceholderSearch="Search cities" CaseSensitiveIcon="true" />
```

</PlatformBlock>

<PlatformBlock for="Angular">

### Vinculação de dados

O Combo {Platform} monta a sua lista de opções a partir do array ao qual você o vincula com `data`. Quando o array contém objetos, defina as chaves que o Combo usa:

<PlatformBlock for="React,WebComponents">

- <ApiLink type="Combo" member="valueKey" label="valueKey" /> - o campo que identifica uma opção. O valor e a API de seleção do Combo o utilizam. Quando você o omite, o Combo usa referências aos objetos.
- <ApiLink type="Combo" member="displayKey" label="displayKey" /> - o campo que a lista e o campo de input mostram. Quando você o omite, o Combo usa o `valueKey`.
- <ApiLink type="Combo" member="groupKey" label="groupKey" /> - o campo que agrupa as opções. Cada grupo recebe um cabeçalho, e <ApiLink type="Combo" member="groupSorting" label="groupSorting" /> ordena os grupos em ordem crescente ou decrescente. Veja [Agrupamento](./features.mdx#agrupamento) no tópico Recursos do Combo.

</PlatformBlock>

<PlatformBlock for="Blazor">

- <ApiLink pkg="core" type="Combo<T>" member="ValueKey" label="ValueKey" /> - o campo que identifica uma opção. O valor e a API de seleção do Combo o utilizam. Quando você o omite, o Combo usa referências aos objetos.
- <ApiLink pkg="core" type="Combo<T>" member="DisplayKey" label="DisplayKey" /> - o campo que a lista e o campo de input mostram. Quando você o omite, o Combo usa o `ValueKey`.
- <ApiLink pkg="core" type="Combo<T>" member="GroupKey" label="GroupKey" /> - o campo que agrupa as opções. Cada grupo recebe um cabeçalho, e <ApiLink pkg="core" type="Combo<T>" member="GroupSorting" label="GroupSorting" /> ordena os grupos em ordem crescente ou decrescente. Veja [Agrupamento](./features.mdx#agrupamento) no tópico Recursos do Combo.

O parâmetro de tipo `T` do Combo do Blazor é o tipo dos seus valores. Defina-o como o tipo do campo `ValueKey`, ou como o tipo das opções quando você não define um `ValueKey`. Ao vincular o `Value` com `@bind-Value`, o Razor infere `T` a partir do campo vinculado.

</PlatformBlock>

<PlatformBlock for="Angular">

- <ApiLink type="Combo" member="valueKey" label="valueKey" /> - o campo que identifica uma opção. O valor e a seleção do Combo o utilizam. Quando você o omite, o Combo usa referências aos objetos.
- <ApiLink type="Combo" member="displayKey" label="displayKey" /> - o campo que a lista e o campo de input mostram. Quando você o omite, o Combo usa o `valueKey`.
- <ApiLink type="Combo" member="groupKey" label="groupKey" /> - o campo que agrupa as opções. Cada grupo recebe um cabeçalho, e <ApiLink type="Combo" member="groupSortingDirection" label="groupSortingDirection" /> ordena os grupos. Veja [Agrupamento](./features.mdx#agrupamento) no tópico Recursos do Combo.

</PlatformBlock>

<PlatformBlock for="Angular,React,WebComponents">

Para vincular a dados carregados de um serviço remoto, veja [Binding remoto](./features.mdx#binding-remoto) no tópico Recursos do Combo.

</PlatformBlock>

Quando o array contém valores primitivos, como strings ou números, não defina `valueKey` nem `displayKey`. O Combo usa os próprios valores.

### Valor e seleção

O Combo {Platform} expõe os seus itens selecionados por meio do seu valor e de métodos que selecionam e desmarcam itens por código.

<PlatformBlock for="React,WebComponents,Blazor">

A `value` mantém os itens selecionados como os seus valores `valueKey`, ou como referências de objeto quando não há `valueKey`. Defina-a para selecionar itens quando o Combo for renderizado pela primeira vez. Os métodos `select` e `deselect` recebem um array de itens; com um array vazio, selecionam ou desmarcam todos os itens:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
// select and deselect items by their ids, because the valueKey is 'id'
combo.select(['BG01', 'BG02']);
combo.deselect(['BG01']);

// select and deselect all items
combo.select();
combo.deselect();

console.log(combo.value); // the ids of the selected items
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
// select and deselect items by their ids, because the valueKey is 'id'
comboRef.current?.select(['BG01', 'BG02']);
comboRef.current?.deselect(['BG01']);

// select and deselect all items
comboRef.current?.select([]);
comboRef.current?.deselect([]);

console.log(comboRef.current?.value); // the ids of the selected items
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
@code {
    private IgbCombo<string> Combo;

    public void SelectCities() => Combo.Select(new object[] { "BG01", "BG02" });

    public void DeselectAll() => Combo.Deselect(new object[] { });
}
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Para permitir que o usuário selecione um único item e digite no campo de input para filtrar a lista, use o modo [Seleção única](./single-selection.mdx).

</PlatformBlock>

<PlatformBlock for="Angular">

O Combo do Angular oferece suporte a binding bidirecional com `[(ngModel)]` e funciona em formulários orientados por template e reativos. A propriedade <ApiLink type="Combo" member="selection" label="selection" /> retorna os itens selecionados, e os métodos <ApiLink type="Combo" member="select" label="select" />, <ApiLink type="Combo" member="deselect" label="deselect" />, <ApiLink type="Combo" member="selectAllItems" label="selectAllItems" /> e <ApiLink type="Combo" member="deselectAllItems" label="deselectAllItems" /> a alteram:

```html
<igx-combo [data]="cities" displayKey="name" valueKey="id" [(ngModel)]="selectedCities"></igx-combo>
```

```ts
export class CitiesComponent {
    @ViewChild(IgxComboComponent, { static: true })
    public combo: IgxComboComponent;

    public selectedCities: string[] = ['BG01', 'UK01'];

    public selectFavorites(): void {
        this.combo.select(['UK01', 'BG01']);
    }
}
```

O Combo do Angular emite <ApiLink type="Combo" member="selectionChanging" label="selectionChanging" /> antes de a seleção mudar, evento que você pode cancelar, e <ApiLink type="Combo" member="selectionChanged" label="selectionChanged" /> depois que a seleção é confirmada.

Para permitir que o usuário selecione um único item e digite no campo de input, use o [Combo simples](./single-selection.mdx).

</PlatformBlock>

### Faça/Não faça

Ao usar o Combo, o seu input e o seu dropdown devem ter a mesma largura, e as suas bordas esquerda e direita devem coincidir. Quanto à forma como o dropdown é exibido quando o Combo recebe foco, mostre-o sempre por cima do conteúdo que vem depois do Combo que dispara a sua exibição. Os Combos não empurram o conteúdo como os painéis de expansão fazem.

### Temas em Sass

Ao modificar uma propriedade primária, todas as propriedades dependentes relacionadas são atualizadas automaticamente para refletir a mudança. O parâmetro primário da <PlatformBlock for="Angular"><ApiLink kind="sass" module="themes" type="function-combo-theme" label="combo-theme" code={true} /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">`combo-theme`</PlatformBlock> função é `$toggle-button-background`, a partir do qual o tema deriva as cores da alternância de botão em todos os estados. Crie os temas do Combo, do seu dropdown e das suas caixas de seleção, e inclua-os com o mixin `tokens()`, que emite as variáveis CSS correspondentes no escopo em que for incluído.

<PlatformBlock for="Angular">

```scss

  $toggle-button-background: #e0e0e0
);

$custom-drop-down-theme: drop-down-theme(
  $background-color: #e6f2ff
);

$custom-checkbox-theme: checkbox-theme(
  $fill-color: #005dcc,
  $empty-color: #005dcc
);

:host {
  @include tokens($custom-combo-theme);
  @include tokens($custom-drop-down-theme);
  @include tokens($custom-checkbox-theme);
}
```

O Combo do Angular exibe o seu dropdown em um overlay. Dependendo da encapsulação de view e de onde está o outlet do overlay, um tema incluído em `:host` pode não chegar ao dropdown. Veja o tópico [Estilização do overlay](../../overlay-styling.mdx).

</PlatformBlock>

## Acessibilidade

O Combo {Platform} usa as funções do padrão WAI-ARIA combobox: o campo de input é um `combobox` que controla uma `listbox` de opções, e os usuários abrem a lista, percorrem-na e selecionam opções pelo teclado.

### Interação por teclado

<PlatformBlock for="React,WebComponents,Blazor">

O campo de input do Combo {Platform} é uma parada de tabulação. Quando o dropdown abre, o input de pesquisa recebe o foco, ou a lista quando `autofocusList` está definido ou o input de pesquisa está oculto. No modo de seleção única, o foco permanece no campo de input. As teclas a seguir funcionam enquanto o Combo tem o foco:

| Tecla | Ação |
| --- | --- |
| <kbd>Seta para baixo</kbd> | No campo de input, abre o dropdown, e no modo de seleção única também move o foco para a lista e ativa a primeira opção. No input de pesquisa, move o foco para a lista e ativa a primeira opção. Na lista, ativa a próxima opção. |
| <kbd>Alt</kbd> + <kbd>Seta para baixo</kbd> | No campo de input, faz o mesmo que <kbd>Seta para baixo</kbd>. |
| <kbd>Seta para cima</kbd> | No campo de input, fecha o dropdown. No input de pesquisa, fecha o dropdown e move o foco para o campo de input. Na lista, ativa a opção anterior. A partir da primeira opção, move o foco para o input de pesquisa, ou fecha o dropdown e move o foco para o campo de input quando o input de pesquisa está oculto. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Na lista, ativa a primeira ou a última opção. |
| <kbd>Space</kbd> | Na lista, seleciona ou desmarca a opção ativa. |
| <kbd>Enter</kbd> | Com uma opção ativa, fecha o dropdown e move o foco para o campo de input. No modo de seleção única, também seleciona a opção ativa. |
| <kbd>Escape</kbd> | Quando o dropdown está aberto, fecha-o e move o foco para o campo de input. Quando o dropdown está fechado, limpa a seleção. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Fecha o dropdown e move o foco para o próximo ou o anterior elemento focável. No modo de seleção única, também seleciona a opção ativa. |

Um Combo desabilitado ignora essas teclas.

</PlatformBlock>

<PlatformBlock for="Angular">

O campo de input do Combo do Angular é uma parada de tabulação. As teclas a seguir funcionam enquanto o Combo tem o foco:

| Tecla | Ação |

| <kbd>Seta para cima</kbd> / <kbd>Alt</kbd> + <kbd>Seta para cima</kbd> | No input de pesquisa, fecha o dropdown e move o foco para o Combo. Na lista, move para a opção anterior. A partir da primeira opção, move o foco de volta para o input de pesquisa, ou fecha o dropdown e move o foco para o Combo quando não há input de pesquisa. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Na lista, move para a primeira ou a última opção. |
| <kbd>Space</kbd> | Na lista, seleciona ou desmarca a opção ativa. |
| <kbd>Enter</kbd> | Na lista, confirma a seleção e fecha o dropdown. No botão de adicionar item, adiciona o texto do input de pesquisa como um novo item e o seleciona. |

### Leitores de tela / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

O Combo {Platform} renderiza as funções e os atributos a seguir:

| Elemento | Função | Atributos |
| --- | --- | --- |
| O campo de input | `combobox` | `aria-haspopup="listbox"`, `aria-expanded`, `aria-disabled`, `aria-controls` que aponta para a lista e, com um texto de ajuda, `aria-describedby` que aponta para ela |
| A parte `list` | `listbox` | `aria-multiselectable` (`false` no modo de seleção única), `aria-labelledby` que aponta para o campo de input, e `aria-activedescendant` que aponta para a opção ativa |
| Cada parte `item` | `option` | `aria-selected`, `aria-posinset` e `aria-setsize` |
| A parte `clear-icon` | `button` | `aria-label` das strings de recurso |

O Combo {Platform} também se comporta da seguinte forma para as tecnologias assistivas:

- O campo de input obtém o seu nome acessível a partir do `label`. Sem um rótulo, ele recebe um nome das strings de recurso que informa se há opções selecionadas.
- A opção ativa é anunciada por meio de `aria-activedescendant` enquanto o foco permanece na lista.
- O conteúdo do dropdown fechado é `inert`.

</PlatformBlock>

<PlatformBlock for="Angular">

O Combo do Angular renderiza as funções e os atributos a seguir:

| Elemento | Função | Atributos |
| --- | --- | --- |
| O input do campo de input | `combobox` | `aria-haspopup="listbox"`, `aria-expanded`, `aria-controls` que aponta para a lista, `aria-labelledby` e `aria-label` |
| O input de pesquisa | `searchbox` | `aria-autocomplete="list"` e `aria-label="search"` |
| O dropdown | `listbox` | `aria-labelledby` que aponta para o elemento `igxLabel` ou para o elemento `ariaLabelledBy` |
| O contêiner das opções | — | `aria-multiselectable="true"` e `aria-activedescendant` que aponta para a opção ativa |
| Cada opção | `option` | `aria-selected` |
| Cada cabeçalho de grupo | `group` | — |
| O botão de adicionar item | `button` | `aria-label` das strings de recurso |

O campo de input obtém o seu nome acessível a partir do `igxLabel` ou do input <ApiLink type="Combo" member="ariaLabelledBy" label="ariaLabelledBy" />. Sem eles, recebe um nome das strings de recurso que informa se há opções selecionadas.

## Limitações conhecidas

- O campo de input que mostra os itens selecionados não é editável. No Firefox, o cursor fica visível nele.
- Quando o Combo do Angular é vinculado a um array de primitivos que contém `undefined`, a lista não mostra `undefined`. Quando o campo `valueKey` de um objeto é `undefined`, a lista mostra o item, mas os usuários não conseguem selecioná-lo.
- Quando o Combo do Angular é vinculado a um serviço remoto e tem uma seleção predefinida, o campo de input fica em branco até que os dados sejam carregados.
- A lista usa o [Virtual Scroll](../../layouts/virtual-scroll.mdx#limitações-conhecidas); por isso, as limitações dele se aplicam. A lista renderiza somente as opções visíveis, e o código que consulta o DOM encontra apenas essas opções.

  <FaqItem question="Como defino os itens selecionados do Combo?" indicatorPosition="end">
    <PlatformBlock for="Angular">Vincule o Combo do Angular com `[(ngModel)]` ou com um controle de formulário a um array de valores `valueKey`, ou chame o método `select` com os itens. Sem um `valueKey`, o Combo do Angular usa referências aos objetos no seu `data`.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">Defina `value` do Combo {Platform} como um array de valores `valueKey`, ou chame o método `select` com os itens. Sem um `valueKey`, o Combo {Platform} usa referências aos objetos no seu `data`.</PlatformBlock>
  </FaqItem>
  <FaqItem question="O Combo pode permitir apenas um item selecionado?" indicatorPosition="end">
    <PlatformBlock for="Angular">O Combo do Angular sempre permite a seleção múltipla. Use o Combo simples quando os usuários precisarem selecionar um único item; ele também permite que os usuários digitem no campo de input para filtrar a lista.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">Sim. Defina `singleSelect` no Combo {Platform}, e os usuários selecionam um item e filtram a lista pelo campo de input, em vez do input de pesquisa. Veja o tópico [Seleção única](./single-selection.mdx).</PlatformBlock>
  </FaqItem>
  <FaqItem question="Como agrupo as opções do Combo?" indicatorPosition="end">
    Defina `groupKey` do Combo {Platform} como o campo que guarda o grupo de cada opção. O Combo {Platform} mostra um cabeçalho para cada grupo e ordena os grupos.
  </FaqItem>
  <FaqItem question="Devo usar o Combo ou o Select?" indicatorPosition="end">
    Use o Combo {Platform} quando a lista for longa, os usuários precisarem pesquisá-la ou selecionarem mais de uma opção. Use o Select {Platform} para uma lista curta da qual os usuários escolhem uma única opção sem pesquisar.
  </FaqItem>
</Faq>
