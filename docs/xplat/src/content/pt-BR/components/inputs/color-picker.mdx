# Componente Color Picker <Badge variant="new" />

O {ProductName} Color Picker é um componente associado a formulários que permite escolher e editar uma cor por meio de um dropdown interativo, com uma área de gradiente, controles deslizantes de matiz e alfa, troca de formato, conta-gotas e amostras predefinidas.

## Demo ao vivo

A demo do Color Picker {Platform} mostra a âncora no modo `input`, que pré-visualiza a cor atualmente selecionada e abre um dropdown no qual você pode editar ou selecionar outra cor.

### Modo

A propriedade <ApiLink pkg="core" type="ColorPicker" member="mode" label="mode" /> controla a apresentação da âncora. Seu valor padrão, `default`, renderiza um botão de acionamento que pré-visualiza a cor atual; `input` renderiza um campo de texto editável com um prefixo de amostra de cor. Ambas as âncoras abrem o mesmo dropdown do seletor.

### Formato

Use a propriedade <ApiLink pkg="core" type="ColorPicker" member="format" label="format" /> para controlar como a cor é serializada. Os valores suportados são `hex`, `rgb` e `hsl`. Alterar o formato serializa novamente a cor existente sem alterá-la; por isso, nenhum evento `igcInput` ou `igcChange` é emitido.

<PlatformBlock for="WebComponents, Angular">


### Validação

Marque o controle como <ApiLink pkg="core" type="ColorPicker" member="required" label="required" /> para falhar na validação do formulário quando nenhuma cor for selecionada. O componente oferece suporte à API padrão associada a formulários — <ApiLink pkg="core" type="ColorPicker" member="checkValidity" label="checkValidity" />, <ApiLink pkg="core" type="ColorPicker" member="reportValidity" label="reportValidity" /> e <ApiLink pkg="core" type="ColorPicker" member="setCustomValidity" label="setCustomValidity" />.

Exiba mensagens de ajuda e de validação abaixo da âncora por meio destes slots:

- `helper-text` – exibe uma dica ou mensagem instrucional abaixo da âncora.
- `value-missing` – renderiza conteúdo personalizado quando a validação do campo obrigatório falha.
- `invalid` – renderiza conteúdo personalizado quando o componente está em estado inválido.
- `custom-error` – exibe conteúdo quando uma mensagem de validação personalizada é definida usando <ApiLink pkg="core" type="ColorPicker" member="setCustomValidity" label="setCustomValidity()" />.

### Faça/Não faça

**Quando usar:** use o Color Picker quando os usuários precisarem informar ou editar uma cor arbitrária por meio de um editor visual, e o valor precisar participar do envio e da validação do formulário. Sempre forneça um rótulo claro, e prefira o modo `input` quando o seletor estiver ao lado de outros campos do formulário.

**Quando não usar:** quando os usuários escolherem apenas entre um pequeno conjunto fixo de cores, apresente esse conjunto como botões comuns ou como um select.

## Usando o Color Picker em formulários do Angular

Para usar o web component Color Picker em um formulário do Angular e vinculá-lo com `formControlName` ou `ngModel`, o Angular exige uma implementação da sua interface `ControlValueAccessor`. O {ProductName} fornece uma como a `IgcFormControlDirective`, que se associa aos web components suportados pelo seletor de elemento. A partir da versão 22.2.0, ele oferece suporte a `igc-color-picker` além de `igc-rating`.

Importe o `IgcFormControlDirective` junto com o `ReactiveFormsModule`, ou o `FormsModule` se você vincular com `ngModel`:

```ts
import { ReactiveFormsModule } from '@angular/forms';
import { IgcFormControlDirective } from 'igniteui-angular/directives';
// import { IgcFormControlDirective } from '@infragistics/igniteui-angular/directives'; for licensed package

@Component({
    imports: [ReactiveFormsModule, IgcFormControlDirective],
    schemas: [CUSTOM_ELEMENTS_SCHEMA]
})

export class LabelFormComponent {...}
```

Em seguida, vincule o Color Picker a um `FormControl` com `formControlName`. O controle recebe a cor no `format` ativo e é atualizado quando o foco sai do Color Picker com uma cor diferente:

```html
<form [formGroup]="labelForm">
  <igc-color-picker formControlName="color" label="Label color" required></igc-color-picker>
</form>
```

A diretiva trata apenas o binding do valor. Mantenha `CUSTOM_ELEMENTS_SCHEMA` se você usar o binding de propriedade do Angular para outras propriedades do Color Picker, como `[swatches]="swatches"`.

## Acessibilidade

O Color Picker {Platform} é um controle associado a formulários que pode ser operado pelo teclado. A âncora é um botão com rótulo (modo padrão) ou um input editável (modo de input), e o seletor aberto mantém o foco dentro de si.

### Interação por teclado

As combinações de teclas abaixo são ignoradas enquanto o componente estiver `disabled`.

| Tecla | Ação |
| -- | -- |
| `Alt` + `ArrowDown` | Alterna o dropdown do seletor. |
| `Alt` + `ArrowUp` | Fecha o dropdown do seletor e devolve o foco para a âncora. |
| `Escape` | Fecha o dropdown do seletor e devolve o foco para a âncora. |
| Teclas `Arrow` | Quando o marcador da área de gradiente está com foco, move o marcador um passo na direção pressionada. |
| `ArrowUp` / `ArrowDown` | Quando o input alfa está com foco, aumenta ou diminui a opacidade em 1%. |
| `Tab` | Move o foco entre os elementos interativos dentro do seletor aberto. |

### Leitores de tela / ARIA

- A âncora define `aria-haspopup="dialog"` e `aria-expanded`, e referencia o contêiner do texto de ajuda por meio de `aria-describedby`, para que as mensagens de ajuda e de validação sejam anunciadas.
- O dropdown do seletor tem `role="dialog"` e o nome acessível `Color picker`.
- O marcador da área de gradiente tem `role="slider"` e anuncia os dois eixos por meio de `aria-valuetext` (por exemplo, `Saturation 50%, brightness 80%`).
- Os controles deslizantes de matiz e alfa são elementos `input[type="range"]` nativos, rotulados por meio de `aria-label` (`Hue`, `Alpha slider`).
- O seletor de formato e o input do valor da cor têm rótulos visualmente ocultos; os botões de copiar e de conta-gotas expõem texto visualmente oculto.
- Cada botão de amostra expõe a sua cor por meio de `aria-label`.
- Enquanto o seletor está aberto, o foco fica preso dentro dele; o conteúdo do seletor fica `inert` quando fechado e é excluído da ordem de tabulação.

## Solução de problemas

As orientações de solução de problemas do Color Picker {Platform} seguem o formato problema → causa → correção para problemas comuns de integração e de plataforma.

### Por que o meu valor de cor foi limpo ou voltou ao anterior?

Atribuir uma string vazia, apenas com espaços ou inválida a `value` limpa a cor, em vez de manter o valor anterior. Uma string inválida digitada no input de cor volta à cor atual. Atribua uma string de cor CSS válida e certifique-se de que o ambiente oferece suporte a `OffscreenCanvas` (veja Limitações conhecidas).

### Por que o valor emitido está em um formato diferente do que eu digitei?

O valor é sempre serializado no `format` ativo; por isso, uma string digitada não volta byte a byte igual. Por exemplo, digitar `red` com `format="hex"` produz `#ff0000`. Defina `format` com a notação que você espera ler de volta.

### Por que nenhum `igcInput` é emitido enquanto eu digito uma cor?

O input de cor confirma uma cor digitada quando ela muda, e não a cada tecla pressionada; e uma cor digitada não emite `igcInput`. Escute `igcChange`, que é disparado quando o foco sai do componente com uma cor diferente.

### Limitações conhecidas

- O botão de conta-gotas fica habilitado somente em navegadores que implementam a API [`EyeDropper`](https://developer.mozilla.org/en-US/docs/Web/API/EyeDropper). O suporte é detectado uma vez, quando o componente é criado.
- Copiar para a área de transferência depende de `navigator.clipboard` e de um contexto seguro (HTTPS ou `localhost`); onde a API não estiver disponível ou a permissão for negada, nada acontece, sem aviso.
- O componente interpreta cada string de cor por meio de um contexto 2D `OffscreenCanvas`. Onde `OffscreenCanvas` não estiver disponível, todos os valores são resolvidos como vazios.
- Os rótulos acessíveis integrados, como `Hue`, `Alpha slider`, `Open color picker` e `Copy color value to clipboard`, estão somente em inglês e não são localizados.
