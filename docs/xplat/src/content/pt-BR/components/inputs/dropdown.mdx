# Componente Dropdown List {Platform} - Visão geral

Rico em recursos, o Dropdown List {Platform} oferece filtragem, acessibilidade, valores pré-selecionados, data binding flexível, agrupamento, personalização da interface e muito mais, prontos para uso. Na prática, este componente substitui de forma eficaz e simples as tags select do HTML, permitindo que os usuários escolham rapidamente um valor não editável em um conjunto predefinido de opções.

O componente Dropdown do Ignite UI for {Platform} exibe uma lista alternável de valores predefinidos e permite que os usuários selecionem facilmente um único item com um clique. Pode ser configurado rapidamente para atuar como um menu dropdown {Platform}, ou você pode usá-lo simplesmente para apresentar informações visuais mais úteis, agrupando dados. Além disso, com o agrupamento, você pode usar dados planos e hierárquicos.

Com o nosso componente, você obtém todas as funções e opções de personalização de que o seu projeto precisa: personalizações de estilo, opções de posicionamento do Dropdown {Platform}, templates e a capacidade de alterar o que e como é exibido no cabeçalho, no rodapé, no corpo, na lista etc.

### Alvo

O Dropdown List {Platform} é posicionado em relação ao seu alvo. O slot `target` permite fornecer um componente integrado que alterna a propriedade `open` ao clicar. Em alguns casos, você pode querer usar um alvo externo ou outro evento para alternar a abertura do Dropdown. Isso pode ser feito usando os métodos <ApiLink pkg="core" type="Dropdown" member="show" label="Show" />, <ApiLink pkg="core" type="Dropdown" member="hide" label="Hide" /> e <ApiLink pkg="core" type="Dropdown" member="toggle" label="Toggle" />, que permitem informar o alvo como parâmetro. Por padrão, o Dropdown List usa o posicionamento CSS `absolute`. Você precisará definir o <ApiLink kind="interface" type="OverlaySettings" member="positionStrategy" label="PositionStrategy" /> do Dropdown {Platform} como `fixed` quando o elemento alvo estiver dentro de um contêiner fixo, mas o Dropdown não estiver. O Dropdown List é dimensionado automaticamente de acordo com o seu conteúdo; se quiser que a lista tenha a mesma largura do alvo, defina a propriedade <ApiLink pkg="core" type="Dropdown" member="sameWidth" label="SameWidth" /> como `true`.

### Posição

O posicionamento preferido do Dropdown {Platform} pode ser definido usando a propriedade <ApiLink pkg="core" type="Dropdown" member="placement" label="Placement" />. O posicionamento padrão do Dropdown é `bottom-start`. A propriedade <ApiLink pkg="core" type="Dropdown" member="flip" label="Flip" /> determina se o posicionamento deve ser invertido quando não há espaço suficiente para exibir o Dropdown no posicionamento especificado. A distância entre a lista do Dropdown {Platform} e o seu alvo pode ser especificada usando a propriedade <ApiLink pkg="core" type="Dropdown" member="distance" label="Distance" />.

<Sample src="/inputs/dropdown/position" height={520} alt="Exemplo de posição do Dropdown {Platform}" />

### Seleção

O <ApiLink pkg="core" type="Dropdown" /> emite o evento `Change` quando o usuário seleciona um item. O método <ApiLink pkg="core" type="Dropdown" member="select" label="Select" /> do Dropdown permite selecionar um item pelo seu índice ou pelo seu valor.

### Item

O <ApiLink pkg="core" type="DropdownItem" /> representa um item selecionável na lista do Dropdown. Você pode predefinir um item selecionado definindo a propriedade <ApiLink pkg="core" type="DropdownItem" member="selected" label="Selected" />. Também pode desabilitar um item para que ele não possa ser selecionado, usando a propriedade <ApiLink pkg="core" type="DropdownItem" member="disabled" label="Disabled" />.

O <ApiLink pkg="core" type="DropdownItem" /> tem um slot padrão que permite especificar o conteúdo do item. Você também pode fornecer conteúdo personalizado a ser renderizado antes ou depois do conteúdo usando os slots `prefix` e `suffix`.
Recomendamos usar um elemento `<span>` ao adicionar texto simples, símbolos ou emojis, e um componente [`<igc-icon>`](../layouts/icon.mdx) ao adicionar ícones aos slots `prefix` e `suffix`.

<PlatformBlock for="WebComponents">

```html
<igc-dropdown>
  <igc-button slot="target">Countries</igc-button>
  <igc-dropdown-item>
    <igc-icon slot="prefix" name="place"></igc-icon>
    Germany
    <span slot="suffix">DE</span>
  </igc-dropdown-item>
  ...
</igc-dropdown>
```

</PlatformBlock>

### Estratégia de rolagem

A propriedade <ApiLink kind="interface" type="OverlaySettings" member="scrollStrategy" label="ScrollStrategy" /> determina o comportamento do componente durante a rolagem do contêiner do elemento alvo. O valor padrão é `scroll`, o que significa que o Dropdown será rolado junto com o seu alvo. Definir a propriedade como `block` bloqueará a rolagem se o Dropdown estiver aberto. Você também pode defini-la como `close`, o que significa que o Dropdown será fechado automaticamente ao rolar.

### Manter aberto

Por padrão, o Dropdown é fechado automaticamente quando o usuário clica fora dele ou seleciona um item. Você pode impedir esse comportamento usando as propriedades <ApiLink pkg="core" type="Dropdown" member="keepOpenOnOutsideClick" label="KeepOpenOnOutsideClick" /> e <ApiLink pkg="core" type="Dropdown" member="keepOpenOnSelect" label="KeepOpenOnSelect" />.

## Estilização

Você pode alterar a aparência do Dropdown e dos seus itens usando as partes CSS expostas. O <ApiLink pkg="core" type="Dropdown" /> expõe as partes `base` e `list`, o <ApiLink pkg="core" type="DropdownItem" /> expõe as partes `prefix`, `content` e `suffix`, e o <ApiLink pkg="core" type="DropdownGroup" /> expõe a parte `label`.

```css
igc-dropdown::part(list) {
  height: 220px;
}

igc-dropdown-item[selected] {
  background: var(--ig-success-300);
}

igc-dropdown-group::part(label) {
  display: flex;
  justify-content: center;
}
```
