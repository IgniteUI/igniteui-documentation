# Visão geral do Navigation Drawer do {Platform}

O Navigation Drawer do {ProductName} oferece navegação lateral que pode ser expandida ou recolhida dentro do conteúdo. Uma versão mini oferece acesso rápido à navegação mesmo quando fechada. Seu conteúdo é totalmente personalizável, ao mesmo tempo que oferece estilização padrão para os itens de menu.

## Integração com a Navbar

Embora qualquer conteúdo possa ser colocado no drawer, o <ApiLink pkg="core" type="NavDrawerItem" /> está disponível para aplicar estilização pronta para uso aos itens.

Para enriquecer um pouco o nosso componente, podemos usá-lo em conjunto com o <ApiLink pkg="core" type="Navbar" />. Assim, obtemos uma aparência mais completa e podemos usar os métodos do drawer. Veja como fazer isso no próximo exemplo:

<PlatformBlock for="WebComponents">

```html
<igc-navbar>
  <igc-icon slot="start" name="menu" id="menu"></igc-icon>
  <h2>Home</h2>
</igc-navbar>

<igc-nav-drawer id="navDrawer">
    <igc-nav-drawer-header-item>
        Sample Drawer
    </igc-nav-drawer-header-item>
    <igc-nav-drawer-item>
        <igc-icon slot="icon" name="home"></igc-icon>
        <span slot="content">Home</span>
    </igc-nav-drawer-item>
    <igc-nav-drawer-item>
        <igc-icon slot="icon" name="search"></igc-icon>
        <span slot="content">Search</span>
    </igc-nav-drawer-item>
</igc-nav-drawer>
```

</PlatformBlock>

<PlatformBlock for="Blazor">


Vamos também adicionar alguns botões de opção para exibir todos os valores de <ApiLink pkg="core" type="NavDrawer" member="position" label="position" />. Assim, sempre que um deles for selecionado, alteraremos a posição do drawer.

<PlatformBlock for="WebComponents">

```ts
// ...
import { defineComponents, IgcNavDrawerComponent, IgcRadioComponent, IgcRadioGroupComponent } from 'igniteui-webcomponents';

this.navDrawer = document.getElementById('navDrawer') as IgcNavDrawerComponent;
this.radioGroup = document.getElementById('radio-group') as IgcRadioGroupComponent;
this.radioGroup.addEventListener('click', (radio: any) => {
    this.navDrawer.position = radio.target.value;
});
```

</PlatformBlock>

```html
</igc-radio-group>
```

</PlatformBlock>

Por fim, precisamos de uma forma de abrir e fechar o nosso navigation drawer. Há algumas maneiras de fazer isso, mas, para este exemplo, faremos o seguinte:

<PlatformBlock for="WebComponents">

```ts
// ...
const menu = document.getElementById('menu');
const navDrawer = document.querySelector('igc-nav-drawer') as IgcNavDrawerComponent;

menu!.addEventListener('click', () => {
    navDrawer.show();
})

document.getElementById('root')!.onclick = (e) => {
    if (e.target != document.getElementById('navDrawer')) {
        navDrawer.hide();
    }
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
public void OnMenuIconClick()
{
    if (this.NavDrawerRef != null)
    {
        this.NavDrawerRef.Show();
    }
}
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
public onMenuIconClick() {
    if (this.navDrawerRef) {
        this.navDrawerRef.show();
    }
}
```

</PlatformBlock>

## Variante mini

Com a variante mini, o Navigation Drawer muda de largura em vez de fechar. Ela serve para manter a navegação rápida sempre disponível, deixando apenas os ícones. Para isso, basta configurar o slot `mini` do drawer.

<PlatformBlock for="WebComponents">

```html
<igc-nav-drawer position="start">
    <igc-nav-drawer-header-item>Sample Drawer</igc-nav-drawer-header-item>
    <igc-nav-drawer-item>
        <igc-icon slot="icon" name="home"></igc-icon>
        <span slot="content">Home</span>
    </igc-nav-drawer-item>
    <igc-nav-drawer-item>
        <igc-icon slot="icon" name="search"></igc-icon>
        <span slot="content">Search</span>
    </igc-nav-drawer-item>
    <div slot="mini">
        <igc-nav-drawer-item>
            <igc-icon slot="icon" name="home"></igc-icon>
        </igc-nav-drawer-item>
        <igc-nav-drawer-item>
            <igc-icon slot="icon" name="search"></igc-icon>
        </igc-nav-drawer-item>
    </div>
</igc-nav-drawer>
```

</PlatformBlock>

<PlatformBlock for="Blazor">


## Estilização

O <ApiLink pkg="core" type="NavDrawer" /> expõe várias partes CSS - `base`, `main` e `mini`, dando a você controle total sobre a estilização delas.

```scss
igc-nav-drawer::part(base) {
  background: var(--ig-secondary-500);
}

igc-nav-drawer-item::part(base) {
  color: var(--ig-secondary-500-contrast);
}

igc-nav-drawer-item::part(base):hover {
  background-color: var(--ig-gray-800);
}

igc-nav-drawer-item[active]::part(base) {
  background: var(--ig-warn-500);
  color: var(--ig-warn-500-contrast);
}

igc-nav-drawer-header-item {
  color: var(--ig-warn-500);
}
```
