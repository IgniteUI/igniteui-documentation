# Visão geral do Toolbar do {Platform}

O componente Toolbar do {Platform} é um contêiner complementar para operações de UI, usado principalmente com os nossos componentes de gráfico. A toolbar se atualiza dinamicamente com um conjunto predefinido de propriedades e itens de ferramenta quando é vinculada aos componentes `DataChart` ou `CategoryChart`. Você poderá criar ferramentas personalizadas para o seu projeto, permitindo que os usuários finais façam alterações e oferecendo um número ilimitado de possibilidades de personalização.

## Uso

### Ações de ferramenta

A seguir, uma lista dos diferentes itens `ToolAction` que você pode adicionar à Toolbar.

- `ToolActionButton`
- `ToolActionCheckbox`
- `ToolActionIconButton`
- `ToolActionIconMenu`
- `ToolActionLabel`
- `ToolActionNumberInput`
- `ToolActionRadio`
- `ToolActionSubPanel`

Cada uma dessas ferramentas expõe um evento `OnCommand` disparado por clique do mouse. Observe que o `ToolActionIconMenu` é um wrapper para outras ferramentas, que também podem ser envolvidas dentro de um `ToolActionIconMenu`.

Ferramentas novas e existentes podem ser reposicionadas e marcadas como ocultas usando as propriedades `overlayId`, `beforeId` e `afterId` do objeto `ToolAction`. ToolActions também expõe uma propriedade `ToolAction.visibility`.

O exemplo a seguir demonstra alguns recursos. Primeiro, você pode agrupar ferramentas no `ToolActionSubPanel`, inclusive ocultando ferramentas integradas como as ações de ferramenta do menu **ZoomReset** e **AnalyzeMenu**. Neste exemplo, uma nova instância da ação de ferramenta **ZoomReset** é criada dentro do **ZoomMenu**, usando a propriedade `afterId` e atribuindo-a a **ZoomOut** para ser precisa quanto à sua posição. Ela também é destacada pela propriedade `isHighlighted` da ferramenta.

### Integração com o Data Chart do {Platform}

O {Platform} Toolbar contém uma propriedade `Target`. Ela é usada para vincular um componente, como o `DataChart`, conforme mostrado no código abaixo:

```json-snippet source="/charts/toolbar/layout-actions-for-data-chart"
{
    "descriptions": {
        "aboveContentLeft": {
            "type": "Toolbar",
            "name": "toolbar",
            "targetRef": "chart",
            "orientation": "Horizontal"
        },
        "content": {
            "type": "DataChart",
            "name": "chart",
            "isHorizontalZoomEnabled": true,
            "isVerticalZoomEnabled": true
        }
    }
}
```

Vários itens `ToolAction` e menus predefinidos ficam disponíveis quando o `DataChart` é vinculado à Toolbar. Veja a lista das ações de ferramenta {Platform} `DataChart` integradas e dos seus `overlayId` associados:

Ações de zoom

- `\ZoomMenu`: um `ToolActionIconMenu` que expõe três itens `ToolActionLabel` para invocar os métodos `m:zoomIn` e `m:zoomOut` do gráfico, para aumentar ou diminuir o nível de zoom do gráfico, incluindo `\ZoomReset`, um `ToolActionLabel` que invoca o método `m:resetZoom` do gráfico para redefinir o nível de zoom para a sua posição padrão.

Ações de tendência

- `\AnalyzeMenu`: um `ToolActionIconMenu` que contém várias opções para configurar diferentes aspectos do gráfico.
- `\AnalyzeHeader`: um cabeçalho de subseção.
  - `\LinesMenu`: um submenu que contém várias ferramentas para mostrar diferentes linhas horizontais tracejadas no gráfico.
  - `\LinesHeader`: um cabeçalho de seção de submenu para as três ferramentas a seguir:
    - `\\MaxValue`: um `ToolActionCheckbox` que exibe uma linha horizontal tracejada ao longo do yAxis, no valor máximo da série.
    - `\\MinValue`: um `ToolActionCheckbox` que exibe uma linha horizontal tracejada ao longo do yAxis, no valor mínimo da série.
    - `\Average`: um `ToolActionCheckbox` que exibe uma linha horizontal tracejada ao longo do yAxis, no valor médio da série.
  - `\TrendsMenu`: um submenu que contém ferramentas para aplicar várias linhas de tendência à área de plotagem do `DataChart`.
  - `\TrendsHeader`: um cabeçalho de seção de submenu para as três ferramentas a seguir:
    - **Exponential**: um `ToolActionRadio` que define o `trendLineType` de cada série do gráfico como **ExponentialFit**.
    - **Linear**: um `ToolActionRadio` que define o `trendLineType` de cada série do gráfico como **LinearFit**.
    - **Logarithmic**: um `ToolActionRadio` que define o `trendLineType` de cada série do gráfico como **LogarithmicFit**.
- `\HelpersHeader`: um cabeçalho de subseção.
  - `\SeriesAvg`: um `ToolActionCheckbox` que adiciona ou remove uma `ValueLayer` na coleção de séries do gráfico, usando o `ValueLayerValueMode` do tipo `Average`.
  - `\ValueLabelsMenu`: um submenu que contém várias ferramentas para mostrar diferentes anotações na área de plotagem do `DataChart`.
  - `\ValueLabelsHeader`: um cabeçalho de seção de submenu para as ferramentas a seguir:
    - `\ShowValueLabels`: um `ToolActionCheckbox` que alterna a exibição dos valores dos pontos de dados usando uma `CalloutLayer`.
    - `\ShowLastValueLabel`: um `ToolActionCheckbox` que alterna as anotações do valor final do eixo, usando uma `FinalValueLayer`.
- `\ShowCrosshairs`: um `ToolActionCheckbox` que alterna as anotações de crosshair ao passar o mouse, por meio da propriedade `crosshairsDisplayMode` do gráfico.
- `\ShowGridlines`: um `ToolActionCheckbox` que alterna linhas de grade extras aplicando uma `MajorStroke` ao eixo X.

Ação Salvar como imagem

- `\CopyAsImage`: um `ToolActionLabel` que expõe uma opção para copiar o gráfico para a área de transferência.
- `\CopyHeader`: um cabeçalho de subseção.

### Ícones SVG

Ao adicionar ferramentas manualmente, os ícones podem ser atribuídos com o método `m:RegisterIconFromText`. Há três parâmetros a passar para esse método. O primeiro é o nome da coleção de ícones definida na ferramenta, por exemplo `iconCollectionName`. O segundo é o nome do ícone definido na ferramenta, por exemplo `iconName`, seguido da adição da string SVG.

### Ícones com Data URL

Da mesma forma que ao adicionar SVG, você também pode adicionar uma imagem de ícone a partir de uma URL, por meio de `m:registerIconFromDataURL`. O terceiro parâmetro do método é usado para informar uma string de URL.

O código a seguir registra um ícone de cada forma, uma string SVG e uma URL, em duas coleções:

```json-snippet source="/charts/toolbar/custom-actions-for-data-chart" channel="handler" item="ToolbarCustomIconOnViewInit"
{
    "descriptions": {
        "aboveContentLeft": {
            "type": "Toolbar",
            "name": "toolbar"
        }
    },
    "onInit": [
        "ToolbarCustomIconOnViewInit"
    ]
}
```

Uma ferramenta então solicita um ícone registrado pela coleção e pelo nome sob o qual ele foi registrado:

```json-snippet source="/charts/toolbar/layout-actions-for-data-chart"
{
    "type": "ToolActionLabel",
    "title": "Custom Icon",
    "iconName": "CustomIcon",
    "iconCollectionName": "CustomCollection"
}
```

### Orientação vertical

Por padrão, a Toolbar do {Platform} é exibida na horizontal, mas ela também pode ser exibida na vertical, definindo a propriedade `Toolbar.orientation`.

```json-snippet source="/charts/toolbar/layout-in-vertical-orientation"
{
    "type": "Toolbar",
    "name": "toolbar",
    "orientation": "Vertical"
}
```

### Editor de cores

Você pode adicionar uma ferramenta personalizada de editor de cores à Toolbar do {Platform}, que também funcionará com o evento Command para aplicar estilização personalizada à sua aplicação.

```json-snippet source="/charts/toolbar/color-editor-support"
{
    "descriptions": {
        "aboveContentLeft": {
            "type": "Toolbar",
            "name": "toolbar",
            "targetRef": "chart",
            "actions": [
                {
                    "type": "ToolActionColorEditor",
                    "title": "Series Brush",
                    "name": "colorEditorTool",
                    "commandId": "ToggleSeriesBrush"
                }
            ]
        },
        "content": {
            "type": "DataChart",
            "name": "chart",
            "isHorizontalZoomEnabled": true
        }
    }
}
```
