# Visão geral da Navbar do {Platform}

A {ProductName} Navbar informa o usuário sobre a sua posição atual em um aplicativo. A barra de navegação também pode oferecer links para ações rápidas, como pesquisa ou favoritos, ajudando os usuários a percorrer a aplicação com fluidez, sem tentar acessar rotas ou estados inválidos. A barra fica no topo do contêiner em que é colocada.

### Conteúdo

Você pode aprimorar o componente <ApiLink pkg="core" type="Navbar" /> adicionando <ApiLink pkg="core" type="Icon" /> ou outros componentes nas posições inicial ou final como conteúdo, permitindo que os usuários naveguem diretamente para locais-chave pela barra:

<PlatformBlock for="WebComponents">

```html
<igc-navbar>
    <igc-icon name="home" slot="start"></igc-icon>
    <h2>Sample App</h2>
    <igc-icon name="search" slot="end"></igc-icon>
    ...
</igc-navbar>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```Razor
<IgbNavbar>
    <IgbIcon @ref="@HomeIcon" slot="start" IconName="home" Collection="material" />
    <h3>Sample App</h3>
    <IgbIcon @ref="@SearchIcon" slot="end" IconName="search" Collection="material" />
    ...
</IgbNavbar>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx

    </div>
```

## Estilização

O componente <ApiLink pkg="core" type="Navbar" /> expõe várias partes CSS, dando a você controle total sobre o seu estilo:

|Nome|Descrição|
|--|--|
| `base` | O wrapper base da barra de navegação. |
| `start` | O contêiner de ícone alinhado à esquerda. |
| `middle` | O contêiner do título da barra de navegação. |
| `end` | O contêiner dos ícones de ação alinhados à direita. |

```css
igc-icon {
  color: var(--ig-primary-500);
}

igc-navbar {
  background-color: var(--ig-secondary-200);
}

igc-navbar::part(middle) {
  font-family: Titillium Web, sans-serif;
  color: var(--ig-primary-500);;
}
```
