# {Platform} Visão geral das séries geográficas

No componente de mapa {ProductName}, as séries geográficas são elementos visuais do mapa que exibem dados geoespaciais como pontos (por exemplo, localizações de cidades), polilinhas (por exemplo, conexões de estradas) ou polígonos (formas de países), em um contexto geográfico.
A propriedade Series do componente de mapa é uma coleção de objetos de série geográfica. Essa propriedade permite renderizar um número ilimitado de séries geográficas na mesma área de plotagem. Quando vários objetos de série geográfica são adicionados à propriedade Series, cada série sucessiva é sobreposta à anterior, da primeira até a última. Por isso, as séries geográficas podem ser entendidas como camadas de mapa que podem ser empilhadas umas sobre as outras e/ou sobre as imagens geográficas.

Todos os tipos de séries geográficas são sempre renderizados sobre os blocos de imagens geográficas. No entanto, às vezes as séries geográficas (por exemplo, com arquivos de forma detalhados do mundo) podem fornecer contexto geográfico suficiente para um aplicativo, e as imagens geográficas não são desejadas no controle de mapa.
