# Tabs

O componente {ProductName} Tabs organiza conteúdos relacionados no mesmo nível hierárquico em abas e mostra o conteúdo da aba selecionada.

<PlatformBlock for="Angular">

O seletor do componente Tabs do Angular é `igx-tabs`. Cada `igx-tab-item` dentro dele contém um cabeçalho de aba e o conteúdo que o componente Tabs mostra quando a aba é selecionada.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Cada aba contém o seu cabeçalho e o seu conteúdo em um único elemento. O componente Tabs oferece suporte à navegação pelo teclado e mostra botões de rolagem quando os cabeçalhos das abas não cabem.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

O elemento `igc-tabs` renderiza a faixa de cabeçalhos e os botões de rolagem. Cada `igc-tab` renderiza o seu próprio cabeçalho e conteúdo, e o componente Tabs posiciona o conteúdo de todas as abas abaixo da faixa de cabeçalhos<PlatformBlock for="WebComponents">, ou ao lado dela quando os cabeçalhos das abas formam uma coluna</PlatformBlock>:

```text
igc-tabs[role="tablist"]
└─ #shadow-root
   └─ div[part="tabs"]                                 // the scrollable header strip
      └─ div[part="inner"]
         ├─ igc-icon-button[part="start-scroll-button"] // rendered when the headers overflow
         ├─ slot                                       // the igc-tab elements
         │  └─ igc-tab
         │     └─ #shadow-root
         │        ├─ div[part="tab-header"][role="tab"]
         │        │  └─ div[part="base"]
         │        │     ├─ slot[name="prefix"][part="prefix"]
         │        │     ├─ div[part="content"]
         │        │     │  └─ slot[name="label"]        // falls back to the label property
         │        │     └─ slot[name="suffix"][part="suffix"]
         │        └─ div[part="tab-body"][role="tabpanel"] // visible only for the selected tab
         │           └─ slot                           // the content of the tab
         ├─ igc-icon-button[part="end-scroll-button"]   // rendered when the headers overflow
         └─ div[part="selected-indicator"]
            └─ span                                    // follows the selected tab header
```

</PlatformBlock>

<PlatformBlock for="Angular">

O elemento `igx-tabs` renderiza a faixa de cabeçalhos a partir do `igx-tab-header` de cada item de aba e a área de conteúdo a partir do `igx-tab-content` de cada item de aba:

```text
igx-tabs.igx-tabs
├─ div.igx-tabs-header
│  ├─ button.igx-tabs-header-button                 // start scroll button, hidden when the headers fit
│  ├─ div.igx-tabs-header__content
│  │  └─ div.igx-tabs-header__wrapper[role="tablist"]
│  │     ├─ div.igx-tabs-header-scroll
│  │     │  └─ igx-tab-header[role="tab"]          // one for each igx-tab-item
│  │     │     ├─ [igxPrefix]
│  │     │     ├─ div.igx-tab-header__inner        // [igxTabHeaderIcon] above [igxTabHeaderLabel]
│  │     │     └─ [igxSuffix]
│  │     └─ div.igx-tabs-header__active-indicator
│  └─ button.igx-tabs-header-button                 // end scroll button, hidden when the headers fit
└─ div.igx-tabs-content
   └─ igx-tab-content[role="tabpanel"]             // one for each igx-tab-item; renders its content only when selected
```

</PlatformBlock>

## Uso

Use o {Platform} Tabs para organizar diferentes visões das mesmas informações ou para alternar entre conjuntos de dados semelhantes ou relacionados.

### Tipo

As abas estão disponíveis em dois tipos: Short, que mostra somente texto por padrão, com a opção de ter ícones de prefixo e sufixo; e Tall, que também tem um terceiro ícone adicional acima do texto.

<PlatformBlock for="React,WebComponents,Blazor">

Para uma aba short, defina o `label` da aba. Para uma aba tall, coloque um Icon e um `<span>` no slot `label`, e o componente Tabs mostra o ícone acima do texto. O slot `label` tem precedência sobre a propriedade `label`. Registre os ícones primeiro, conforme descrito no tópico [Icon](./icon.mdx):

</PlatformBlock>

### Responsividade

As abas podem ser Content Fit, para preencher o espaço horizontal disponível adaptando a largura, ou Fixed, com botões de rolagem para navegar por um grande número de itens de aba. Isso permite caber mais conteúdo do que é normalmente possível com o outro modo no mesmo espaço total.

O <PlatformBlock for="Angular"><ApiLink pkg="core" type="Tabs" member="tabAlignment" label="tabAlignment" /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor"><ApiLink pkg="core" type="Tabs" member="alignment" label="alignment" /></PlatformBlock> A propriedade define como o componente {Platform} Tabs organiza os cabeçalhos das abas:

- `start` (padrão): cada cabeçalho de aba tem a largura do seu conteúdo, e os cabeçalhos começam na borda inicial do Tabs.
- `center`: cada cabeçalho de aba tem a largura do seu conteúdo, e os cabeçalhos ficam centralizados.
- `end`: cada cabeçalho de aba tem a largura do seu conteúdo, e os cabeçalhos terminam na borda final do Tabs.
- `justify`: os cabeçalhos das abas se estendem para preencher a largura do Tabs. Use-o para o modo Content Fit.

```html
<igc-tabs alignment="justify">

</igc-tabs>
```

</PlatformBlock>

Um botão de rolagem desloca a faixa até o próximo cabeçalho de aba que está fora da visão, na sua direção, e fica desabilitado quando a faixa chega a essa extremidade. Quando o usuário seleciona uma aba, o componente Tabs desloca o seu cabeçalho para a área visível.

### Estados

Os itens de aba oferecem suporte aos estados Ativo, Inativo, Ativo e hover, Inativo e hover e Desabilitado. Em Tabs há sempre uma aba ativa e um número qualquer de abas inativas e desabilitadas.

Defina `selected` em uma aba para torná-la a aba ativa, e `disabled` para desativá-la. Os usuários não podem selecionar uma aba desabilitada, e a navegação pelo teclado a ignora.<PlatformBlock for="React,WebComponents,Blazor"> Quando você desabilita a aba selecionada, o componente {Platform} Tabs seleciona a primeira aba habilitada.</PlatformBlock>

</igc-tabs>

### Seleção

<PlatformBlock for="WebComponents">

O componente {Platform} Tabs emite `igcChange` com a aba recém-selecionada quando o usuário seleciona uma aba com um clique ou com uma tecla. Para selecionar uma aba pelo código, chame <ApiLink pkg="core" type="Tabs" member="select" label="select" /> com a aba, ou com o seu `id` ou `label`. Leia a aba selecionada em <ApiLink pkg="core" type="Tabs" member="selectedTab" label="selectedTab" />:

```html
<igc-tabs>
  <igc-tab id="overview" label="Overview"></igc-tab>
  <igc-tab id="details" label="Details"></igc-tab>
</igc-tabs>
```

```ts
const tabs = document.querySelector('igc-tabs')!;

tabs.addEventListener('igcChange', (event) => {
  console.log(`Selected: ${event.detail.label}`);
});

tabs.select('details');
console.log(tabs.selectedTab?.label); // "Details"
```

</PlatformBlock>

<PlatformBlock for="React">

O componente {Platform} Tabs chama `onChange` com a aba recém-selecionada quando o usuário seleciona uma aba com um clique ou com uma tecla. Para selecionar uma aba pelo código, chame <ApiLink pkg="core" type="Tabs" member="select" label="select" /> com a aba, ou com o seu `id` ou `label`:

```tsx
import { useRef } from 'react';
import { IgrTab, IgrTabs } from 'igniteui-react';

export default function ProfileTabs() {
  const tabsRef = useRef<IgrTabs>(null);

  return (

        <IgrTab label="Overview" />
        <IgrTab label="Details" />
      </IgrTabs>
      <button onClick={() => tabsRef.current?.select('Details')}>Show details</button>
    </>
  );
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

<PlatformBlock for="React,WebComponents,Blazor">

Selecionar uma aba pelo código, ou definir `selected` em uma aba, altera a seleção sem o evento de mudança. O componente Tabs ignora abas desabilitadas e valores que não correspondem a nenhuma aba.

</PlatformBlock>

<PlatformBlock for="Angular">

Vincule <ApiLink pkg="core" type="Tabs" member="selectedIndex" label="selectedIndex" /> para ler e definir o índice da aba selecionada. O componente Tabs do Angular emite <ApiLink pkg="core" type="Tabs" member="selectedIndexChanging" label="selectedIndexChanging" /> antes de a seleção mudar, e você pode cancelar a mudança no seu manipulador:

```html
<igx-tabs [(selectedIndex)]="selectedIndex" (selectedIndexChanging)="onSelectedIndexChanging($event)">
  <igx-tab-item>
    <igx-tab-header><span igxTabHeaderLabel>Profile</span></igx-tab-header>
    <igx-tab-content>The profile form.</igx-tab-content>
  </igx-tab-item>
  <igx-tab-item>
    <igx-tab-header><span igxTabHeaderLabel>Billing</span></igx-tab-header>
    <igx-tab-content>The billing form.</igx-tab-content>
  </igx-tab-item>
</igx-tabs>
```

```ts
import { ITabsSelectedIndexChangingEventArgs } from 'igniteui-angular/tabs';

public selectedIndex = 0;
public hasUnsavedChanges = false;

public onSelectedIndexChanging(event: ITabsSelectedIndexChangingEventArgs) {
    if (this.hasUnsavedChanges) {
        event.cancel = true;
    }
}
```

Depois que a seleção muda, o componente Tabs do Angular emite <ApiLink pkg="core" type="Tabs" member="selectedItemChange" label="selectedItemChange" /> com o item de aba anterior e o novo. Esses eventos também são disparados quando você define `selectedIndex` pelo código.

</PlatformBlock>

### Ativação

Por padrão, o componente {Platform} Tabs seleciona uma aba assim que as teclas de seta, Home ou End movem o foco para o seu cabeçalho. ### Faça/Não faça

As abas são adequadas para organizar informações; evite usá-las para desenhar fluxos de trabalho e ações que seguem uma sequência lógica, por exemplo um processo de checkout ou um assistente de configuração. Ao usar abas short, nunca combine uma aba de texto com uma aba de ícone na mesma barra. Escolha um dos dois modos de conteúdo e use-o de forma consistente em todos os itens da barra.

<DoDont
  doSrc={tabsDoInformation}
  doAlt="Abas chamadas Produtos, Carrinho e Pedidos acima da imagem de um produto"
  dontSrc={tabsDoNotWorkflow}
  dontAlt="Abas chamadas Extras, Pagamento e Endereço usadas como as etapas de um fluxo de pedido"
>
<Fragment slot="do">

Use abas para organizar informações relacionadas.

</Fragment>
<Fragment slot="dont">

Evite abas para as etapas de um fluxo de trabalho sequencial, como um processo de checkout.

</Fragment>
</DoDont>

<DoDont
  doSrc={tabsDoContent}
  doAlt="Abas chamadas Podcasts, Playlists e Gêneros, todas com rótulos de texto"
  dontSrc={tabsDoNotMixedContent}
  dontAlt="Abas que combinam os rótulos de texto Podcasts e Playlists com uma aba de ícone de nota musical"
>

Use o mesmo modo de conteúdo, texto ou ícones, para todas as abas de uma barra.

</Fragment>

### Temas em Sass

Quando você altera uma propriedade primária, todas as propriedades dependentes relacionadas são atualizadas automaticamente para refletir a mudança. ## Acessibilidade

O componente {Platform} Tabs usa os papéis do padrão de abas WAI-ARIA: os usuários chegam aos cabeçalhos das abas com a tecla Tab, movem-se entre eles com as teclas de seta e selecionam uma aba para mostrar o seu conteúdo.

### Interação por teclado

<PlatformBlock for="React,WebComponents,Blazor">

A faixa de cabeçalhos do componente {Platform} Tabs é uma única parada de tabulação: apenas o cabeçalho da aba selecionada está na ordem de tabulação, ou o primeiro cabeçalho de aba habilitado quando nenhuma aba está selecionada. O conteúdo da aba selecionada é a próxima parada de tabulação. As teclas a seguir funcionam enquanto um cabeçalho de aba tem o foco:

| Tecla | Ação |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Move o foco para fora da faixa de cabeçalhos, para o conteúdo da aba selecionada ou para o elemento focável anterior. O componente Tabs não trata essas teclas. |
| <kbd>Seta para a direita</kbd> | Move o foco para o próximo cabeçalho de aba habilitado, e do último para o primeiro. Em um layout da direita para a esquerda, move-o para o anterior. Com a ativação `auto`, também seleciona a aba.<PlatformBlock for="WebComponents"> Em uma coluna de cabeçalhos de aba, o componente Tabs não trata esta tecla.</PlatformBlock> |
| <kbd>Seta para a esquerda</kbd> | Move o foco para o cabeçalho de aba habilitado anterior, e do primeiro para o último. Em um layout da direita para a esquerda, move-o para o próximo. Com a ativação `auto`, também seleciona a aba.<PlatformBlock for="WebComponents"> Em uma coluna de cabeçalhos de aba, o componente Tabs não trata esta tecla.</PlatformBlock> |
<PlatformBlock for="WebComponents">| <kbd>Seta para baixo</kbd> | Em uma coluna de cabeçalhos de aba, move o foco para o próximo cabeçalho de aba habilitado, e do último para o primeiro. Com a ativação `auto`, também seleciona a aba. |
| <kbd>Seta para cima</kbd> | Em uma coluna de cabeçalhos de aba, move o foco para o cabeçalho de aba habilitado anterior, e do primeiro para o último. Com a ativação `auto`, também seleciona a aba. |
</PlatformBlock>| <kbd>Home</kbd> | Move o foco para o primeiro cabeçalho de aba habilitado. Com a ativação `auto`, também seleciona a aba. |
| <kbd>End</kbd> | Move o foco para o último cabeçalho de aba habilitado. Com a ativação `auto`, também seleciona a aba. |
| <kbd>Enter</kbd> / <kbd>Espaço</kbd> | Seleciona a aba em foco. |

O componente {Platform} Tabs trata estas teclas em `keydown`:

- Ele impede a ação padrão delas, para que as teclas de seta que movem o foco, Home, End e Espaço não rolem a página.
- Uma tecla que você mantém pressionada não repete a sua ação.
- Uma tecla que você pressiona junto com Shift, Ctrl, Alt ou Meta não faz nada.
- O componente Tabs rola o cabeçalho que recebe o foco para a área visível.

Com um ponteiro, um clique em um cabeçalho de aba foca e seleciona a aba. Uma aba desabilitada ignora cliques. Os botões de rolagem não estão na ordem de tabulação.

</PlatformBlock>

### Leitores de tela / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

O componente {Platform} Tabs renderiza os papéis e atributos a seguir:

| Elemento | Função | Atributos |
| --- | --- | --- |
| `igc-tabs` | `tablist` | `aria-orientation="horizontal"`<PlatformBlock for="WebComponents">, ou `aria-orientation="vertical"` em uma coluna de cabeçalhos de aba</PlatformBlock>, definido pelos internals do elemento |
| A parte `tab-header` de cada aba | `tab` | `aria-selected`, `aria-disabled`, `aria-controls` que aponta para o conteúdo da aba, `aria-posinset` e `aria-setsize` |
| A parte `tab-body` de cada aba | `tabpanel` | `aria-labelledby` que aponta para o cabeçalho da aba |

O componente {Platform} Tabs também se comporta da forma a seguir para a tecnologia assistiva:

- Uma aba obtém o seu nome acessível do conteúdo do cabeçalho: a propriedade `label` ou o slot `label`, e o conteúdo dos slots `prefix` e `suffix`.
- O conteúdo das abas que não estão selecionadas fica oculto e `inert`, para que a tecnologia assistiva e o teclado o ignorem.
- Os atributos `aria-posinset` e `aria-setsize` de cada cabeçalho de aba informam aos leitores de tela a posição da aba no conjunto, como "2 de 3".
- O componente Tabs não usa uma região ativa (live region). Uma seleção alterada chega à tecnologia assistiva pelo estado `aria-selected` e pelo foco.

</PlatformBlock>

<PlatformBlock for="Angular">

O componente Tabs do Angular renderiza os papéis e atributos a seguir:

| Elemento | Função | Atributos |
| --- | --- | --- |
| O elemento `div.igx-tabs-header__wrapper` no cabeçalho | `tablist` | `aria-orientation="horizontal"`, ou `aria-orientation="vertical"` em uma coluna de cabeçalhos de aba |
| `igx-tab-header` | `tab` | `aria-selected`, `aria-disabled` e, quando o item de aba tem conteúdo, um `id` e um `aria-controls` que aponta para o conteúdo |
| `igx-tab-content` | `tabpanel` | `aria-labelledby` que aponta para o cabeçalho do item de aba |

O componente Tabs do Angular também se comporta da forma a seguir para a tecnologia assistiva:

- Uma aba obtém o seu nome acessível do conteúdo do seu `igx-tab-header`.
- O componente Tabs renderiza somente o conteúdo do item de aba selecionado; por isso, o conteúdo dos outros itens de aba não está no DOM.
- Itens de aba sem `igx-tab-content`, como as abas que controlam o roteador, não recebem `id` nem `aria-controls`.
- O componente Tabs não usa uma região ativa (live region). Uma seleção alterada chega à tecnologia assistiva pelo estado `aria-selected` e pelo foco.

</PlatformBlock>

A Infragistics documenta o suporte de acessibilidade do {ProductName} para as áreas das diretrizes da Seção 508 e da WCAG 2.1 no tópico [Conformidade de acessibilidade](../interactivity/accessibility-compliance.mdx).

| [1.4.1 Uso de cor](https://www.w3.org/WAI/WCAG21/Understanding/use-of-color) | Nos temas Material, Fluent e Indigo, o cabeçalho da aba selecionada exibe uma linha indicadora abaixo dele<PlatformBlock for="Angular,WebComponents">, ou ao lado dele em uma coluna de cabeçalhos de aba</PlatformBlock>, de modo que a seleção não dependa somente da cor. |
| [2.1.1 Teclado](https://www.w3.org/WAI/WCAG21/Understanding/keyboard) | As teclas de seta, Home e End movem o foco entre os cabeçalhos das abas, e Enter e Espaço selecionam a aba em foco<PlatformBlock for="Angular"> com a ativação `manual`</PlatformBlock>. |

| [2.4.3 Ordem de foco](https://www.w3.org/WAI/WCAG21/Understanding/focus-order) | A faixa de cabeçalhos é uma única parada de tabulação, seguida pelo conteúdo da aba selecionada. |
| [2.4.7 Foco visível](https://www.w3.org/WAI/WCAG21/Understanding/focus-visible) | O cabeçalho de aba em foco assume as cores de hover do tema, para se destacar dos outros cabeçalhos de aba. |
| [4.1.2 Nome, função, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | Cada cabeçalho de aba expõe o papel `tab`, um nome a partir do seu conteúdo e os seus estados selecionado e desabilitado por meio de `aria-selected` e `aria-disabled`. |

Suas responsabilidades:

- Dê a cada aba um rótulo de texto que nomeie o seu conteúdo. Uma aba obtém o seu nome acessível do conteúdo do cabeçalho; por isso, um cabeçalho somente com ícone precisa apenas de uma alternativa textual. Consulte [Tipo](#tipo).
- Ao sobrescrever as cores do tema, mantenha uma razão de contraste de pelo menos 3:1 entre o indicador selecionado e o fundo, como exige o [1.4.11 Contraste de elementos não textuais](https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast), e mantenha o cabeçalho de aba em foco distinto dos demais cabeçalhos.

<PlatformBlock for="Angular">- Mantenha um item de aba selecionado, para que os usuários de teclado possam chegar à faixa de cabeçalhos, e defina a ativação `manual` para as abas que controlam o roteador.</PlatformBlock>
