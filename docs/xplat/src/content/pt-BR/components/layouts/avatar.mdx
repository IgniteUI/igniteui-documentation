# Componente Avatar

O {ProductName} Avatar representa um usuário, uma entidade ou um objeto com uma imagem, iniciais ou conteúdo personalizado.

Use o avatar para oferecer uma identidade visual compacta em listas, cartões, menus de perfil e feeds de atividade.

## Uso

Renderize um avatar com uma fonte de imagem, iniciais ou conteúdo personalizado no slot padrão.

### Variantes

<PlatformBlock for="WebComponents, React, Blazor">

Defina somente a fonte de conteúdo que pretende exibir. O avatar renderiza <ApiLink pkg="core" type="Avatar" member="initials" label="Initials" /> quando definidos; caso contrário, renderiza o conteúdo do slot padrão. Ele também renderiza um elemento de imagem enquanto <ApiLink pkg="core" type="Avatar" member="src" label="Src" /> estiver definido e carregar com sucesso.

</PlatformBlock>

<PlatformBlock for="Angular">

Defina somente a fonte de conteúdo que pretende exibir. O avatar do Angular renderiza primeiro `src`, depois `icon` e, por fim, `initials`, e recorre ao conteúdo personalizado projetado quando nenhuma dessas entradas está definida.

</PlatformBlock>

### Faça/Não faça

**Quando usar:** use o avatar quando uma interface precisar de uma pequena representação de uma pessoa, organização, objeto ou conta, como uma imagem de perfil, iniciais ou um ícone. Mantenha uma estratégia de avatar consistente na mesma região da interface para que identidades repetidas sejam fáceis de identificar.

<PlatformBlock for="WebComponents, React, Blazor">

**Quando não usar:** use o componente [Badge](../inputs/badge.mdx) quando precisar mostrar uma contagem, um status ou um indicador de notificação, em vez de representar uma entidade. Os badges também podem decorar avatares quando identidade e status precisam aparecer juntos.

</PlatformBlock>

## Acessibilidade

O avatar é um elemento visual de identidade não interativo, com semântica de imagem acessível.

### Interação por teclado

O avatar não recebe foco e não tem interação por teclado.

| Tecla | Ação |
| -- | -- |
| n/a | O avatar não é interativo pelo teclado. |

### Leitores de tela / ARIA

O avatar é inicializado com semântica de imagem e um rótulo acessível padrão de `avatar`.

<PlatformBlock for="WebComponents, React, Blazor">

- Defina `alt` quando uma imagem `src` representar uma pessoa, entidade ou objeto específico.
- Adicione um `aria-label` explícito quando o conteúdo personalizado projetado precisar de um nome acessível diferente.
- Considere avatares decorativos redundantes quando o texto ao lado já identificar a mesma entidade.

</PlatformBlock>

<PlatformBlock for="Angular">

- Use o texto ao redor para identificar a pessoa, a entidade ou o objeto representado quando um avatar de imagem transmitir identidade.
- Considere avatares decorativos redundantes quando o texto ao lado já identificar a mesma entidade.

</PlatformBlock>

### Conformidade de acessibilidade

A Infragistics documenta o suporte de acessibilidade do {ProductName} para as áreas das diretrizes da Seção 508 e da WCAG 2.1 no tópico [Conformidade de acessibilidade](../interactivity/accessibility-compliance.mdx).

<PlatformBlock for="WebComponents, React, Blazor">

| Critério | Como o componente atende |
| -- | -- |
| [1.1.1 Conteúdo não textual](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content) | O avatar tem um rótulo acessível, e avatares de imagem podem receber um texto alternativo específico por meio de `alt`. |
| [4.1.2 Nome, função, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | O componente é inicializado com semântica de imagem e expõe informações ARIA relacionadas ao conteúdo. |

</PlatformBlock>

<PlatformBlock for="Angular">

| Critério | Como o componente atende |
| -- | -- |
| [1.1.1 Conteúdo não textual](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content) | O avatar tem um rótulo acessível e pode ser combinado com o texto ao redor que identifica a entidade representada. |
| [4.1.2 Nome, função, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | O componente é inicializado com `role="img"` e um rótulo acessível padrão. |

</PlatformBlock>

Suas responsabilidades:

- Mantenha contraste suficiente entre o fundo do avatar e a cor do texto ou do ícone ao sobrescrever estilos.
- Evite repetir o mesmo anúncio de identidade quando o texto ao lado já nomear a pessoa ou a entidade.

<PlatformBlock for="WebComponents, React, Blazor">

- Forneça um rótulo descritivo ou um texto de `alt` quando o avatar transmitir identidade.

</PlatformBlock>

<PlatformBlock for="Angular">

- Garanta que o texto próximo identifique a entidade representada quando a imagem do avatar transmitir identidade.

</PlatformBlock>

## Solução de problemas

Use esta seção para verificar limites e decisões comuns antes de tratar o Avatar como um componente interativo ou de status.

### Limitações conhecidas

O avatar é um elemento básico de identidade visual e não adiciona, por si só, comportamento de interação, status ou notificação.

- Use um contêiner interativo, como um botão ou um item de lista, quando a entidade representada precisar ser clicável.
- Use um badge com o avatar quando precisar mostrar status, contagens ou indicadores de notificação.

## Perguntas frequentes

<Faq>
  <FaqItem question="Quando devo usar o Avatar em vez do Badge?" indicatorPosition="end">
    Use o Avatar quando a interface precisar representar uma pessoa, uma conta, uma organização ou um objeto. Use o Badge quando a interface precisar mostrar uma contagem, um status ou um indicador de notificação.
  </FaqItem>

  <FaqItem question="O Avatar adiciona interação por teclado?" indicatorPosition="end">
    Não. O Avatar não é interativo e não recebe foco por conta própria. Coloque-o dentro de um componente interativo quando a entidade representada precisar de uma ação.
  </FaqItem>

  <FaqItem question="Como devo rotular avatares de imagem para leitores de tela?" indicatorPosition="end">
    Forneça um texto alternativo significativo quando a imagem do avatar identificar uma entidade específica. Evite repetir a mesma identidade quando o texto ao lado já nomear essa entidade.
  </FaqItem>
</Faq>
