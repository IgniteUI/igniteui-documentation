# Ícone

O {ProductName} Icon é um componente que renderiza um ícone nomeado de um conjunto de ícones registrado, como uma coleção de ícones SVG personalizados.

<PlatformBlock for="Angular">

Por padrão, o Icon do Angular renderiza os ligatures do Material Icons. Registre ícones SVG e outras fontes de ícones com o `IgxIconService` para usá-los da mesma forma.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Registre os ícones SVG pelo nome em uma coleção e, em seguida, exiba cada ícone em um tamanho baseado no tema, na cor do texto ao redor.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

O {Platform} Icon renderiza um elemento `igc-icon`, que desenha o SVG registrado no seu shadow root e não expõe partes CSS:

```text
igc-icon                 // host - inline box sized by --size
└─ #shadow-root
   └─ svg                // the registered SVG, 1em × 1em, filled with the current color
```

</PlatformBlock>

<PlatformBlock for="Angular">

O elemento `igx-icon` renderiza um dos seguintes, dependendo do tipo da sua família de ícones:

```text
igx-icon.igx-icon[aria-hidden="true"]   // host - also carries the family class, e.g. .material-icons
├─ ligature text                        // `liga` family - the icon name, e.g. home
├─ div > svg                            // SVG icon registered with IgxIconService
└─ ng-content                           // projected ligature text when `name` isn't set
```

Para uma família `font`, as classes no host desenham o glifo, e o elemento não tem conteúdo.

</PlatformBlock>

## Uso

Use o {Platform} Icon para adicionar um símbolo reconhecível a rótulos, botões, itens de lista e navegação, ou para mostrar um status de relance.

<PlatformBlock for="React,WebComponents,Blazor">

### Nome e coleção

O {Platform} Icon desenha o SVG registrado sob o seu nome na sua coleção. A coleção padrão é `default`. Todos os ícones da página compartilham um único registro; assim, um ícone registrado uma vez fica disponível para todos os Icons, e um Icon que é renderizado antes de o seu SVG ser registrado é atualizado assim que você o registrar.

</PlatformBlock>

<PlatformBlock for="WebComponents">

Registre a marcação SVG com <ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" />, ou busque um arquivo SVG de uma URL com <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" />:

```ts
import { registerIcon, registerIconFromText } from 'igniteui-webcomponents';

const searchIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

registerIconFromText('search', searchIcon, 'material');
registerIcon('build', '/icons/build.svg', 'material');
```

Em seguida, defina o mesmo nome e a mesma coleção em cada ícone:

```html
<igc-icon name="search" collection="material"></igc-icon>
<igc-icon name="build" collection="material"></igc-icon>
```

</PlatformBlock>

<PlatformBlock for="React">

Registre a marcação SVG com <ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" />, ou busque um arquivo SVG de uma URL com <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" />. Em seguida, defina o mesmo nome e a mesma coleção em cada ícone:

```tsx
import { useEffect } from 'react';
import { IgrIcon, registerIcon, registerIconFromText } from 'igniteui-react';

const searchIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

export default function SearchToolbar() {
  useEffect(() => {
    registerIconFromText('search', searchIcon, 'material');
    registerIcon('build', '/icons/build.svg', 'material');
  }, []);

  return (
    <>
      <IgrIcon name="search" collection="material" />
      <IgrIcon name="build" collection="material" />
    </>
  );
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Registre a marcação SVG com o método <ApiLink pkg="core" type="Icon" member="RegisterIconFromTextAsync" label="RegisterIconFromTextAsync" />, ou busque um arquivo SVG de uma URL com <ApiLink pkg="core" type="Icon" member="RegisterIconAsync" label="RegisterIconAsync" />. Chame-os em um `IgbIcon` referenciado depois que ele estiver pronto e, em seguida, defina o mesmo `IconName` e `Collection` em cada ícone:

```razor
<IgbIcon @ref="SearchIcon" IconName="search" Collection="material" />
<IgbIcon IconName="build" Collection="material" />

@code {
    private IgbIcon SearchIcon { get; set; }

    private const string SearchSvg = "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'><path d='M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z'/></svg>";

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender && SearchIcon != null)
        {
            await SearchIcon.EnsureReady();
            await SearchIcon.RegisterIconFromTextAsync("search", SearchSvg, "material");
            await SearchIcon.RegisterIconAsync("build", "/icons/build.svg", "material");
        }
    }
}
```

### Nome e família

O Icon do Angular busca o seu <ApiLink pkg="core" type="Icon" member="name" label="name" /> no seu <ApiLink pkg="core" type="Icon" member="family" label="family" />. A família `material` padrão renderiza os ligatures do Material Icons; por isso, o nome é o ligature, como `home` ou `favorite`:

```html
<igx-icon name="home"></igx-icon>
<igx-icon name="favorite"></igx-icon>
```

Você também pode projetar o ligature como conteúdo:

```html
<igx-icon>bluetooth</igx-icon>
```

### Ícones SVG

Registre ícones SVG com o <ApiLink pkg="core" type="IconService" /> e, em seguida, defina o nome e a família no ícone. O método <ApiLink pkg="core" type="IconService" member="addSvgIcon" label="addSvgIcon" /> busca um arquivo SVG de uma URL, e <ApiLink pkg="core" type="IconService" member="addSvgIconFromText" label="addSvgIconFromText" /> registra a marcação SVG:

```ts
import { Component, OnInit, inject } from '@angular/core';
import { IgxIconComponent, IgxIconService } from 'igniteui-angular/icon';

const searchIcon =
    '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

@Component({
    selector: 'app-filter-icons',
    template: `
        <igx-icon name="contains" family="filter-icons"></igx-icon>
        <igx-icon name="search" family="filter-icons"></igx-icon>
    `,
    imports: [IgxIconComponent]
})
export class FilterIconsComponent implements OnInit {
    private iconService = inject(IgxIconService);

    public ngOnInit() {
        this.iconService.addSvgIcon('contains', 'assets/images/svg/contains.svg', 'filter-icons');
        this.iconService.addSvgIconFromText('search', searchIcon, 'filter-icons');
    }
}
```

Quando um ícone SVG e um ligature compartilham o mesmo nome e a mesma família, o ícone renderiza o SVG.

### Famílias de fontes

Use <ApiLink pkg="core" type="IconService" member="setFamily" label="setFamily" /> para adicionar outra fonte de ícones, como [Material Symbols](https://fonts.google.com/icons), como uma família. Carregue primeiro a folha de estilo da fonte:

```html
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" rel="stylesheet" />
```

Associe o nome da família à classe CSS da fonte e defina o tipo dela como `liga`:

```ts
this.iconService.setFamily('material-symbols', { className: 'material-symbols-outlined', type: 'liga' });
```

Em seguida, defina a família no ícone. O Material Symbols é uma fonte variável; por isso, você pode ajustar configurações como preenchimento e peso:

```html
<igx-icon family="material-symbols" name="diamond" class="custom-icon"></igx-icon>
```

```scss
.custom-icon {
  font-variation-settings: "FILL" 0, "wght" 200, "GRAD" 0, "opsz" 40;
}
```

O tópico [Serviço de ícones](../icon-service.mdx) aborda famílias do tipo `font`, prefixos de nome e referências de ícones.

</PlatformBlock>

### Referências de ícones

Uma referência de ícone aponta o nome de um ícone para outro ícone registrado. Componentes como o Combo e o Date Picker renderizam seus ícones integrados por meio de referências na coleção `default`, e uma referência que você definir tem precedência sobre eles. Por exemplo, aponte a referência `input_clear` para o seu próprio ícone para substituir o ícone de limpar desses dois componentes:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
import { registerIconFromText, setIconRef } from 'igniteui-webcomponents';

const closeIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z"/></svg>';

registerIconFromText('close', closeIcon, 'my-icons');
setIconRef('input_clear', 'default', { name: 'close', collection: 'my-icons' });
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
import { registerIconFromText, setIconRef } from 'igniteui-react';

const closeIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z"/></svg>';

registerIconFromText('close', closeIcon, 'my-icons');
setIconRef('input_clear', 'default', { name: 'close', collection: 'my-icons' });
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIcon @ref="CloseIcon" IconName="close" Collection="my-icons" />

@code {
    private IgbIcon CloseIcon { get; set; }

    private const string CloseSvg = "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'><path d='M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z'/></svg>";

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender && CloseIcon != null)
        {
            await CloseIcon.EnsureReady();
            await CloseIcon.RegisterIconFromTextAsync("close", CloseSvg, "my-icons");
            await CloseIcon.SetIconRefAsync("input_clear", "default", new IgbIconMeta()
            {
                Name = "close",
                Collection = "my-icons",
            });
        }
    }
}
```

</PlatformBlock>

### Tamanho

O {Platform} Icon oferece suporte às predefinições de tamanho pequeno, médio e grande do tema, e usa a predefinição grande por padrão. Defina a variável CSS `--ig-size` como `--ig-size-small`, `--ig-size-medium` ou `--ig-size-large` para escolher uma predefinição:

```css
.small {
  --ig-size: var(--ig-size-small);
}

.medium {
  --ig-size: var(--ig-size-medium);
}
```

### Ativo

Defina <ApiLink pkg="core" type="Icon" member="active" label="active" /> como `false` para mostrar o ícone como inativo. Um ícone inativo usa a cor desabilitada do tema com opacidade reduzida:

### Nome acessível

Oculte um ícone decorativo das tecnologias assistivas e dê a um ícone que transmite significado por si só um nome acessível que descreva esse significado.

<PlatformBlock for="React,WebComponents,Blazor">

Defina `aria-label` no ícone para nomeá-lo. O elemento `<title>` de um SVG registrado também nomeia o ícone. Defina `aria-hidden="true"` em um ícone decorativo ao lado de texto visível:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-icon name="warning" collection="material" aria-label="Warning"></igc-icon>

<span>
  <igc-icon name="search" collection="material" aria-hidden="true"></igc-icon>
  Search
</span>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrIcon name="warning" collection="material" aria-label="Warning" />

<span>
  <IgrIcon name="search" collection="material" aria-hidden="true" />
  Search
</span>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIcon IconName="warning" Collection="material" aria-label="Warning" />

<span>
    <IgbIcon IconName="search" Collection="material" aria-hidden="true" />
    Search

```

</PlatformBlock>

<PlatformBlock for="Angular">

O Icon do Angular fica oculto das tecnologias assistivas por padrão, porque a sua entrada <ApiLink pkg="core" type="Icon" member="ariaHidden" label="ariaHidden" /> define `aria-hidden="true"`. Para expor um ícone que transmite significado, defina `ariaHidden` como `false` e adicione o papel `img` e um `aria-label`:

```html
<igx-icon name="warning" [ariaHidden]="false" role="img" aria-label="Warning"></igx-icon>
```

</PlatformBlock>

## Acessibilidade

O {Platform} Icon é um elemento visual não interativo que decora o conteúdo próximo ou transmite significado por si só.

### Interação por teclado

O {Platform} Icon não recebe foco e não tem interação por teclado: não define `tabindex` e não trata eventos de teclado nem de ponteiro. Use o <PlatformBlock for="Angular">[Icon Button](../icon-button.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Icon Button](../inputs/icon-button.mdx)</PlatformBlock> quando os usuários precisarem ativar um ícone pelo teclado.

| Tecla | Ação |
| --- | --- |
| n/a | O Icon não é interativo pelo teclado. |

### Leitores de tela / ARIA

O {Platform} Icon não faz anúncios por conta própria. O que a tecnologia assistiva informa depende do nome acessível do ícone:

<PlatformBlock for="React,WebComponents">

- O ícone define o seu papel e o seu nome acessível por meio dos internals do elemento, e não por atributos no elemento `igc-icon`.
- Um elemento `<title>` que é filho direto do `<svg>` raiz do ícone registrado se torna o nome acessível do ícone.
- Um atributo `aria-label` ou `aria-labelledby` no ícone dá nome a um ícone cujo SVG não tem title, e tem precedência sobre o title.
- Com o `igniteui-webcomponents` 7.3.0 ou posterior, o ícone declara o papel `img` somente quando tem um nome acessível; assim, um ícone sem nome não é exposto como uma imagem sem nome.
- O ícone verifica se há um nome acessível ao resolver o seu SVG: quando `name` ou `collection` muda, quando o tema muda ou quando um ícone é registrado. Defina `aria-label` ou `aria-labelledby` na marcação inicial.
- A opção de registro `stripMeta` remove os elementos `<title>` e `<desc>` do SVG armazenado, mas o ícone mantém o texto do title como seu nome acessível.

</PlatformBlock>

<PlatformBlock for="Blazor">

- Um elemento `<title>` que é filho direto do `<svg>` raiz do ícone registrado se torna o nome acessível do ícone.
- Um atributo `aria-label` no ícone dá nome a um ícone cujo SVG não tem title, e tem precedência sobre o title.
- Um atributo `aria-hidden="true"` oculta um ícone decorativo da tecnologia assistiva.

</PlatformBlock>

<PlatformBlock for="Angular">

- O ícone define `aria-hidden="true"` por padrão, por meio da sua entrada `ariaHidden`; assim, a tecnologia assistiva o ignora. Somente um `aria-label` não expõe um ícone oculto.
- O ícone não define papel. Quando você define `ariaHidden` como `false` sem um papel e um rótulo, os leitores de tela leem um ícone de ligature como o seu texto, como `home`.
- Defina `ariaHidden` como `false`, adicione o papel `img` e adicione um `aria-label` para expor um ícone que transmite significado.
- A entrada `active` altera apenas a estilização. O estado inativo não é exposto à tecnologia assistiva.

</PlatformBlock>

## Solução de problemas

Use estas respostas quando um {Platform} Icon não for renderizado ou não tiver a aparência esperada.

### Por que o meu ícone está vazio?

<PlatformBlock for="React,WebComponents,Blazor">

O {Platform} Icon desenha somente um SVG registrado sob o mesmo nome e na mesma coleção. Verifique as causas a seguir:

- O nome ou a coleção não correspondem exatamente ao registro. A coleção padrão é `default`.
- A marcação SVG está malformada. O registro lança o erro `SVG element not found or malformed SVG string.` quando o texto não tem um elemento `<svg>` raiz ou não pode ser analisado.
- A requisição de um arquivo SVG falhou. O registro a partir de uma URL falha para uma resposta que não é OK; por isso, verifique o console do navegador e o painel de rede. Um arquivo de outra origem também exige um servidor que permita requisições de origem cruzada.

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

Durante a renderização no servidor, o ícone não renderiza SVG. Ele desenha o SVG depois de carregar no navegador.

</PlatformBlock>

<PlatformBlock for="Angular">

Verifique as causas a seguir:

- Um ícone de ligature precisa da fonte da sua família, como o Material Icons para a família `material` padrão. Verifique se a folha de estilo da fonte é carregada.
- Um ícone SVG precisa do mesmo nome e da mesma família do seu registro.
- `addSvgIcon` precisa de `HttpClient` para buscar o arquivo. Verifique no painel de rede se há uma requisição com falha.
- O serviço armazena em cache os ícones SVG somente no navegador; por isso, ícones SVG não são renderizados durante a renderização no servidor.

</PlatformBlock>

### Por que o meu ícone SVG não assume a cor do tema?

O {Platform} Icon aplica a sua cor ao elemento `<svg>` raiz, e os elementos filhos herdam essa cor como preenchimento. Um elemento filho com cor fixa mantém essa cor:

```html
<svg viewBox="0 0 24 24">
  <path fill="#050d42" d="..." />
</svg>
```

Remova as cores fixas dos elementos filhos ou defina a cor no elemento `<svg>` raiz, onde o tema a sobrescreve. Para colorir parte de um ícone de propósito, use uma variável de cor do tema, como `fill="var(--ig-primary-500)"`.

### Por que aparece uma dica de ferramenta quando passo o mouse sobre um ícone?

Os navegadores exibem o elemento `<title>` de um SVG como uma dica de ferramenta nativa.

<PlatformBlock for="React,WebComponents">

Registre o ícone com a opção `stripMeta` para remover os elementos `<title>` e `<desc>` do SVG armazenado. O ícone mantém o texto do title como seu nome acessível:

```ts
registerIconFromText('search', searchIcon, { collection: 'material', stripMeta: true });
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Remova o elemento `<title>` da marcação SVG antes de registrá-la e defina `aria-label` nos ícones que precisam de um nome acessível.

</PlatformBlock>

<PlatformBlock for="Angular">

Passe `true` como o argumento `stripMeta` de `addSvgIcon` ou `addSvgIconFromText` para remover os elementos `<title>` e `<desc>` do SVG armazenado em cache:

```ts
this.iconService.addSvgIcon('contains', 'assets/images/svg/contains.svg', 'filter-icons', true);
```

</PlatformBlock>

### Limitações conhecidas

O {Platform} Icon tem as seguintes limitações:

- O Icon é um elemento visual não interativo: não recebe foco nem trata entradas de teclado.
- As cores do tema chegam ao elemento `<svg>` raiz e aos elementos filhos que herdam o seu preenchimento. Elementos filhos com cores fixas as mantêm.
<PlatformBlock for="React,WebComponents,Blazor">- O Icon desenha somente ícones SVG registrados. Fontes de ícones e ligatures não são compatíveis.</PlatformBlock><PlatformBlock for="Angular">- O Icon do Angular não tem opção para espelhar um ícone em layouts da direita para a esquerda.</PlatformBlock>
