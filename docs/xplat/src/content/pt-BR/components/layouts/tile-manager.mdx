# Visão geral do {Platform} Tile Manager

O componente {ProductName} Tile Manager permite exibir conteúdo em tiles individuais. Ele permite que os usuários interajam com esses tiles reorganizando e redimensionando-os, dando-lhes liberdade para personalizar o layout e a aparência do conteúdo de acordo com suas preferências. Essa flexibilidade melhora a experiência do usuário ao oferecer uma forma mais personalizada e eficiente de visualizar e gerenciar o conteúdo.

## Uso

O <ApiLink pkg="core" type="TileManager" /> oferece um comportamento base de layout de tiles, gerenciando a posição dos tiles nos estados maximizado ou normal. Os tiles podem ser dimensionados de forma independente uns dos outros e usados para formar layouts complexos. Os usuários finais podem reordenar os tiles arrastando-os e soltando-os, o que oferece uma experiência flexível e intuitiva.

O Tile Manager oferece dois componentes que podemos usar:

- <ApiLink pkg="core" type="Tile" /> - Este componente representa um bloco individual exibido dentro do Tile Manager.
- <ApiLink pkg="core" type="TileManager" /> - Este é o componente principal, que contém todos os componentes de bloco e serve como contêiner de todo o layout de blocos.

## Layout

### Colunas e linhas

Podemos especificar o número de colunas da grade do nosso Tile Manager. Para isso, basta definir a propriedade <ApiLink pkg="core" type="TileManager" member="columnCount" label="ColumnCount" /> com o número desejado de colunas. Se o número for menor que um ou se a propriedade não for definida, o Tile Manager criará tantas colunas quantas couberem, com cada coluna tendo pelo menos 200px de largura e se expandindo para dividir igualmente o espaço disponível. Quando as dimensões da viewport mudarem, os tiles também se reorganizarão para aproveitar melhor o espaço.

## Componente Tile

O componente Tile tem propriedades que podem ser definidas individualmente para cada tile. Algumas delas incluem:

- A propriedade <ApiLink pkg="core" type="Tile" member="colSpan" label="ColSpan" /> especifica em quantas colunas o tile se estenderá no layout, permitindo controlar o seu tamanho horizontal.
- A propriedade <ApiLink pkg="core" type="Tile" member="rowSpan" label="RowSpan" /> determina em quantas linhas o tile se estenderá verticalmente, ajustando a altura do tile dentro do layout.
- A propriedade <ApiLink type="ColumnState" member="colStart" label="ColStart" /> especifica a coluna inicial em que o tile é posicionado.
- A propriedade <ApiLink pkg="core" type="Tile" member="rowStart" label="RowStart" /> especifica a linha inicial em que o tile é posicionado.
- A propriedade <ApiLink pkg="core" type="Tile" member="disableFullscreen" label="DisableFullscreen" /> oculta o botão de ação padrão de tela cheia.
- A propriedade <ApiLink pkg="core" type="Tile" member="disableMaximize" label="DisableMaximize" /> oculta o botão de ação padrão de alternância de maximizar.
- A propriedade <ApiLink pkg="core" type="Tile" member="disableResize" label="DisableResize" /> impede que o tile seja redimensionado pelo usuário.

O componente Tile também expõe vários slots que você pode usar:

| Nome do slot | Descrição |
| ---------|------------ |
| `title` | Conteúdo do cabeçalho do tile. |
| `fullscreen-action` | Substitui o conteúdo padrão da ação de tela cheia. |
| `maximize-action` | Substitui o conteúdo padrão da ação de maximizar. |
| `actions` | Conteúdo personalizado renderizado depois das ações padrão. |
| `side-adorner` | Substitui o adorno padrão de redimensionamento horizontal. |
| `corner-adorner` | Substitui o adorno padrão de redimensionamento diagonal. |
| `bottom-adorner` | Substitui o adorno padrão de redimensionamento vertical. |

Ao usar o slot `title`, recomendamos usar um elemento `<span>` em vez de elementos de título (`<h1>`–`<h6>`). Elementos de título têm estilos próprios (como tamanho de fonte, altura de linha e margens) que podem interferir na tipografia e no layout pretendidos para o componente. Usar um `<span>` oferece um contêiner neutro que herda os estilos do componente de forma limpa.

Ao usar os slots `fullscreen-action`, `maximize-action`, `actions`, `side-adorner`, `corner-adorner` e `bottom-adorner`, recomendamos usar um componente [`<igc-icon>`](../layouts/icon.mdx) ou [`<igc-icon-button>`](../inputs/icon-button.mdx) para ícones personalizados.

## Redimensionamento

O redimensionamento no Tile Manager é uma funcionalidade que permite redimensionar os tiles usando três adornos de redimensionamento diferentes.

- **Adorno lateral**: ajusta a largura modificando a extensão de colunas.
- **Adorno inferior**: ajusta a altura modificando a extensão de linhas.
- **Adorno de canto**: ajusta largura e altura ao mesmo tempo.

Para garantir um redimensionamento suave, um elemento fantasma é usado em vez de modificar diretamente as dimensões do tile. Esse elemento aparece sobre o tile original, exibindo as dimensões atuais quando o redimensionamento começa, e se atualiza em tempo real conforme o usuário arrasta qualquer uma das alças de redimensionamento.

<DocsAside type="info">
Se o elemento fantasma ultrapassar o espaço disponível da grade, ele se ajustará automaticamente à maior extensão possível dentro dos limites da grade.
</DocsAside>

O Tile Manager se reorganiza automaticamente quando um tile muda de tamanho, garantindo que haja o mínimo de espaço vazio. Por isso, ao expandir um tile, os tiles adjacentes podem ser empurrados para novas posições, enquanto ao diminuir surgem espaços que outros tiles podem ocupar dinamicamente. Isso garante que o Tile Manager fique o mais compacto possível, sem tiles sobrepostos, e que todas as movimentações permaneçam dentro da estrutura de grade definida.

Podemos usar a propriedade <ApiLink pkg="core" type="TileManager" member="resizeMode" label="ResizeMode" /> para controlar como o redimensionamento é aplicado no Tile Manager. Ela pode ser definida como `none`, `hover` ou `always`, o que determina quando os adornos de redimensionamento ficam visíveis. O valor padrão é `none`, e o tile não pode ser redimensionado.

### Encaixe

Os tiles são redimensionados em unidades inteiras da grade, o que significa que só podem crescer ou diminuir por colunas ou linhas inteiras. O elemento fantasma se encaixa na coluna ou linha seguinte ao ultrapassar a metade ao expandir, e na anterior ao diminuir além da metade. Isso se aplica a todos os adornos (inferior, lateral e de canto), garantindo que os tiles sempre fiquem alinhados à grade.

Os espaçamentos da grade também são considerados, mantendo o layout consistente durante o redimensionamento.

### Limitações

Há várias restrições e limitações no processo de redimensionamento:

- Um tile não pode ser redimensionado para um tamanho menor que a sua largura ou altura mínima definidas (<ApiLink pkg="core" type="TileManager" member="minColumnWidth" label="MinColumnWidth" />, <ApiLink pkg="core" type="TileManager" member="minRowHeight" label="MinRowHeight" />).
- Um tile não pode ultrapassar o espaço horizontal máximo disponível na grade.

## Reordenar

Você pode reordenar os tiles no Tile Manager usando o recurso de arrastar e soltar. Por padrão, os tiles não são arrastáveis. Para habilitar essa funcionalidade, defina a propriedade <ApiLink pkg="core" type="TileManager" member="dragMode" label="DragMode" /> no Tile Manager como `tile` ou `tile-header`.

- Com a opção `tile`, você pode clicar e manter pressionado em qualquer ponto de um tile individual para começar a arrastá-lo.
- Com a opção `tile-header`, você só pode clicar e manter pressionado na seção de cabeçalho do tile para começar o arrasto.

<DocsAside type="info">
Enquanto o tile estiver no estado maximizado ou em tela cheia, ele não pode ser arrastado.
</DocsAside>

Assim como no redimensionamento, ao iniciar o arrastar e soltar, um elemento fantasma aparece sob o tile que você agarrou. Conforme você arrasta o tile, o elemento fantasma se move junto e reordena os outros tiles dinamicamente, em tempo real. Isso permite visualizar como a grade de tiles ficará quando você soltar o tile.

## Serialização

O Tile Manager oferece métodos que ajudam a gerenciar o layout dos tiles:

- O método <ApiLink pkg="core" type="TileManager" member="saveLayout" label="SaveLayout" /> permite salvar a disposição atual dos tiles no Tile Manager. Ele captura a ordem, o tamanho e a posição atuais de todos os tiles, para que você possa restaurar depois exatamente essa configuração.
- O método <ApiLink pkg="core" type="TileManager" member="loadLayout" label="LoadLayout" /> permite carregar um layout salvo anteriormente. Quando chamado, ele restaura os tiles exatamente como estavam quando o layout foi salvo, incluindo sua ordem, tamanho e posição.

## Estilização

Você também pode personalizar a aparência dos dois componentes - <ApiLink pkg="core" type="TileManager" /> e <ApiLink pkg="core" type="Tile" />.
O <ApiLink pkg="core" type="TileManager" /> expõe apenas uma propriedade CSS - `base`, que pode ser usada para estilizar o wrapper base do Tile Manager.
O <ApiLink pkg="core" type="Tile" /> expõe várias propriedades CSS que podemos usar:

| Nome da parte | Descrição |
| ---------|------------ |
| `base` | O contêiner que envolve o componente de tile. |
| `header` | O contêiner do cabeçalho do tile, incluindo as partes de título e de ações. |
| `title` | O contêiner do título. |
| `actions` | O contêiner de ações. |
| `content-container` | O contêiner que envolve o slot padrão do tile. |
| `trigger-side` | O adorno horizontal. |
| `trigger` | O adorno diagonal |
| `trigger-bottom` | O adorno vertical. |

Usando essas partes CSS, você pode personalizar a aparência dos dois componentes da seguinte forma:

```css
igc-tile-manager::part(base) {
  background-color: var(--ig-surface-900);
}

igc-tile::part(content-container) {
  color: var(--ig-secondary-200);
}

igc-tile::part(header) {
  background-color: var(--ig-gray-300);
}

igc-tile::part(title) {
  color: var(--ig-primary-400);
}

igc-tile:nth-child(n+2)::part(trigger-side),
igc-tile:nth-child(n+2)::part(trigger-bottom) {
  background-color: var(--ig-success-500);
}

igc-tile:nth-child(n+2)::part(trigger) {
  background-color: var(--ig-error-500);
}
```

Você também pode trocar o ícone dos adornos por um personalizado usando os slots `side-adorner`, `corner-adorner` e `bottom-adorner`. Por exemplo:

<PlatformBlock for="WebComponents">

```html
<igc-tile>
  <igc-icon slot="side-adorner" class="side" name="indicator"></igc-icon>
  <igc-icon slot="corner-adorner" class="corner" name="indicator"></igc-icon>
  <igc-icon slot="bottom-adorner" class="bottom" name="indicator"></igc-icon>
  <span slot="title">Tile header</span>
</igc-tile>
```

</PlatformBlock>
