# Visão geral do {Platform} Stepper

O componente {Platform} Stepper oferece um fluxo de trabalho no estilo assistente e é usado para mostrar o progresso por meio de etapas numeradas. Ele permite que os desenvolvedores dividam um conteúdo extenso em uma sequência de etapas lógicas, ajudando os usuários finais a percorrer o processo inteiro com mais facilidade. O {Platform} Stepper é exibido como uma linha vertical ou horizontal. O {Platform} Stepper tem vários recursos, como validação de etapas, estilização, orientação e navegação pelo teclado.

## Como usar o {Platform} Stepper
O <ApiLink pkg="core" type="Step" /> é a representação de cada etapa que pertence ao <ApiLink pkg="core" type="Stepper" />. As etapas oferecem as propriedades <ApiLink pkg="core" type="Step" member="Invalid" label="Step.Invalid" />, <ApiLink pkg="core" type="Step" member="Active" label="Step.Active" />, <ApiLink pkg="core" type="Step" member="Optional" label="Step.Optional" />, <ApiLink pkg="core" type="Step" member="Disabled" label="Step.Disabled" /> e <ApiLink pkg="core" type="Step" member="Complete" label="Step.Complete" />, que permitem configurar os estados das etapas de acordo com a sua regra de negócio.

Para cada etapa, o usuário pode configurar o indicador, o título e o subtítulo usando os slots `indicator`, `title` e `subtitle`.

Para os slots `title` e `subtitle`, recomendamos usar elementos `<span>` em vez de elementos de título (`<h1>`–`<h6>`). Usar um `<span>` oferece um contêiner neutro que herda os estilos do componente de forma limpa.

Para o slot `indicator`, também recomendamos usar um elemento `<span>` para indicadores de símbolo ou emoji, e um componente [`<igc-icon>`](../layouts/icon.mdx) para indicadores de ícone.

### Orientação do {Platform} Stepper

Você pode personalizar a orientação do stepper pela propriedade exposta <ApiLink pkg="core" type="Stepper" member="orientation" label="Orientation" />. Ela pode ser definida como **horizontal** ou **vertical**.

**Orientação horizontal do Stepper**

**horizontal** é o valor padrão da propriedade de orientação <ApiLink pkg="core" type="Stepper" />.

Quando o stepper {Platform} está orientado na horizontal, você pode determinar se o conteúdo das etapas será exibido acima ou abaixo dos cabeçalhos das etapas. Isso é feito definindo a propriedade booleana <ApiLink pkg="core" type="Stepper" /> <ApiLink pkg="core" type="Stepper" member="contentTop" label="ContentTop" />, cujo valor padrão é **false**. Quando ativada, o conteúdo das etapas é exibido acima dos cabeçalhos.

**Orientação vertical do Stepper**

Você pode alternar facilmente do layout horizontal para o vertical. Para alterar a orientação padrão, defina a propriedade <ApiLink pkg="core" type="Stepper" member="orientation" label="Orientation" /> como **vertical**.

### Estados das etapas

O {Platform} <ApiLink pkg="core" type="Stepper" /> oferece suporte a cinco estados de etapa, e cada um deles aplica estilos diferentes por padrão:

- **active** - determina se a etapa é a que está exibida no momento. Por design, se o usuário não definir explicitamente como **true** o atributo active de alguma etapa, a etapa ativa inicial será a primeira etapa não desabilitada.
- **disabled** - determina se a etapa é intransitável. Por padrão, o atributo disabled de uma etapa é definido como **false**.
- **invalid** - determina se a etapa é válida. Com base no seu valor, decide-se se o usuário poderá avançar no modo linear do stepper. O valor padrão é **false**.
- **optional** - por padrão, o atributo optional de uma etapa é definido como **false**. Se a validade de uma etapa no stepper linear não for exigida, o atributo optional pode ser ativado para permitir avançar independentemente da validade da etapa.
- **complete** - por padrão, o atributo complete de uma etapa retorna **false**. No entanto, o usuário pode substituir esse comportamento padrão definindo o atributo complete conforme necessário. Quando uma etapa é marcada como concluída, não só o estilo do cabeçalho da etapa é alterado por padrão, como também o estilo da linha de progresso entre a etapa concluída e a próxima.

### {Platform} Stepper linear

O {Platform} <ApiLink pkg="core" type="Stepper" /> permite definir o fluxo das suas etapas usando a propriedade <ApiLink pkg="core" type="Stepper" member="linear" label="Linear" />. Por padrão, linear é **false**, e o usuário pode selecionar qualquer etapa não desabilitada no <ApiLink pkg="core" type="Stepper" />.

<PlatformBlock for="WebComponents">

```html
<igc-stepper linear="true">
    <igc-step>
        <span slot="title">Step 1</span>
    </igc-step>
    <igc-step>
        <span slot="title">Step 2</span>
    </igc-step>
</igc-stepper>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

        <span slot="title">Step 1</span>
    </IgbStep>
     <IgbStep>
        <span slot="title">Step 2</span>
    </IgbStep>
</IgbStepper>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx

    <IgrStep>
        <span slot="title">Step 1</span>
    </IgrStep>
     <IgrStep>
```

Quando a propriedade linear é definida como **true**, o stepper exige que a etapa atual, não opcional, seja válida antes de avançar para a próxima.

Se a etapa atual, não opcional, não for válida, você não poderá avançar para a próxima etapa até validar a atual.

<DocsAside type="info">
A validade das etapas opcionais não é levada em conta para avançar.
</DocsAside>

### Interações com as etapas

<ApiLink pkg="core" type="Stepper" /> oferece os seguintes métodos de API para interações com as etapas:
- **navigateTo** – ativa a etapa do índice informado.
- **next** - ativa a próxima etapa não desabilitada.
- **prev** – ativa a etapa anterior não desabilitada.
- **reset** – redefine o stepper para o seu estado inicial.

<DocsAside type="info">
O método reset redefine o stepper para o seu estado inicial, ou seja, ativa a primeira etapa. Ele não limpa o conteúdo das etapas; isso deve ser feito manualmente.
</DocsAside>

### Personalizando as etapas

O {ProductName} Stepper permite configurar diferentes opções para títulos, indicadores e outros elementos.

Isso pode ser feito pela propriedade <ApiLink pkg="core" type="Stepper" member="stepType" label="StepType" /> de <ApiLink pkg="core" type="Stepper" />. Ela aceita os valores a seguir:
- Completo **(valor padrão)**
- Indicador
- Título

**full**

Se títulos e subtítulos forem definidos, com essa configuração tanto os indicadores quanto os títulos serão renderizados.

O usuário também pode definir a posição do título das etapas, que pode ficar antes, depois, acima ou abaixo do indicador da etapa.
O usuário pode configurar a posição do título usando a propriedade <ApiLink pkg="core" type="Stepper" member="titlePosition" label="TitlePosition" />. Ela aceita os valores a seguir:
- undefined **(valor padrão)**
- end
- start
- bottom
- top

Quando o {Platform} <ApiLink pkg="core" type="Stepper" /> está orientado na horizontal e a posição do título **não está definida**, os títulos são exibidos **abaixo** dos indicadores.

Quando a orientação é definida como vertical e a posição do título **não está definida**, os títulos são exibidos **depois** dos indicadores.

<DocsAside type="info">
A propriedade **titlePosition** se aplica **somente** quando a propriedade stepType do stepper é definida como **full**.
</DocsAside>

**indicator**

Se quiser exibir apenas os indicadores das etapas, defina a opção stepType como **indicator**.

O indicador de etapa aceita qualquer conteúdo, porém com a restrição de que seu tamanho será sempre de **24 pixels**. Por isso, recomendamos usar <ApiLink pkg="core" type="Icon" /> ou <ApiLink pkg="core" type="Avatar" /> como indicadores de etapa.

**Título**

Se quiser exibir apenas os títulos das etapas, defina a opção stepType como **title**.

Dessa forma, se subtítulos forem definidos, eles também serão renderizados abaixo do título da etapa.

<DocsAside type="info">
Este contêiner pode ser personalizado com um novo template conforme a sua necessidade, sem restrições de tamanho. Por exemplo, você pode adicionar dentro dele um indicador com tamanho maior que 24 pixels.
</DocsAside>

### Altura dinâmica da etapa

Quando o <ApiLink pkg="core" type="Stepper" /> está orientado na horizontal, a altura da área de conteúdo é determinada pela etapa com mais conteúdo. Todas as outras etapas compartilham essa altura fixa, o que pode deixar espaço vazio visível nas etapas com menos conteúdo.

Para substituir a altura fixa e fazer com que a área de conteúdo se adapte ao conteúdo da etapa ativa, defina a variável CSS **--body-grid-rows** como **0fr** (o padrão é **1fr**):

```css
igc-stepper {
  --body-grid-rows: 0fr;
}
```

### Animações do Stepper

As animações do {Platform} <ApiLink pkg="core" type="Stepper" /> oferecem aos usuários finais uma experiência agradável ao interagir com as etapas definidas. As opções de animação disponíveis variam conforme a orientação do stepper.

Quando o stepper está orientado na horizontal, ele é configurado para usar a animação `slide` por padrão. Também oferece suporte a `fade` como alternativa. As animações são configuradas pela entrada <ApiLink pkg="core" type="Stepper" member="horizontalAnimation" label="HorizontalAnimation" />.

Em um layout orientado na vertical, o tipo de animação pode ser definido pela propriedade <ApiLink pkg="core" type="Stepper" member="verticalAnimation" label="VerticalAnimation" />. Por padrão, o valor é `grow`, e o usuário pode defini-lo também como `fade`.

Definir `none` nas duas entradas de tipo de animação desativa as animações do stepper.

O componente <ApiLink pkg="core" type="Stepper" /> também permite configurar a duração da transição entre as etapas. Isso é feito pela propriedade <ApiLink pkg="core" type="Stepper" member="animationDuration" label="AnimationDuration" />, que recebe um número como argumento e é comum às duas orientações. O valor padrão é 320ms.

## Navegação pelo teclado

O {ProductName} Stepper oferece aos usuários finais uma grande variedade de interações pelo teclado. Esse recurso vem habilitado por padrão e permite que os usuários naveguem facilmente pelas etapas.
A navegação do {Platform} <ApiLink pkg="core" type="Stepper" /> está em conformidade com os [padrões de acessibilidade do W3](https://www.w3.org/WAI/ARIA/apg/patterns/tabpanel/) e é prática de usar.

**Combinações de teclas**

- <kbd>TAB</kbd> - move o foco para o próximo elemento focável
- <kbd>SHIFT</kbd> + <kbd>TAB</kbd> - move o foco para o elemento focável anterior
- <kbd>↓</kbd> - move o foco para o cabeçalho da próxima etapa acessível quando o stepper estiver **orientado na vertical**
- <kbd>↑</kbd> - move o foco para o cabeçalho da etapa acessível anterior quando o stepper estiver **orientado na vertical**
- <kbd>←</kbd> - move o foco para o cabeçalho da etapa acessível anterior, em ambas as orientações
- <kbd>→</kbd> - move o foco para o cabeçalho da próxima etapa acessível, em ambas as orientações
- <kbd>HOME</kbd> - move o foco para o cabeçalho da PRIMEIRA etapa habilitada do stepper
- <kbd>END</kbd> - move o foco para o cabeçalho da ÚLTIMA etapa habilitada do stepper
- <kbd>ENTER</kbd> ou <kbd>SPACE</kbd> - ativa a etapa em foco

## Estilização do {Platform} Stepper

Você pode alterar a aparência do <ApiLink pkg="core" type="Step" /> usando algumas das partes CSS expostas listadas abaixo:

| Nome da parte | Descrição |
| ---------|------------ |
| `header-container` | Wrapper do cabeçalho da etapa e dos seus separadores. |
| `disabled` | Indica um estado desabilitado. Aplica-se a header-container. |
| `complete-start` | Indica um estado concluído da etapa atual. Aplica-se a header-container. |
| `complete-end` | Indica um estado concluído da etapa anterior. Aplica-se a header-container. |
| `optional` | Indica um estado opcional. Aplica-se a header-container. |
| `invalid` | Indica um estado inválido. Aplica-se a header-container. |
| `top` | Indica que o título deve ficar acima do indicador. Aplica-se a header-container. |
| `bottom` | Indica que o título deve ficar abaixo do indicador. Aplica-se a header-container. |
| `start` | Indica que o título deve ficar antes do indicador. Aplica-se a header-container. |
| `end` | Indica que o título deve ficar depois do indicador. Aplica-se a header-container. |
| `header` | Wrapper do indicador e do texto da etapa. |
| `indicator` | O indicador da etapa. |
| `text` | Wrapper do título e do subtítulo da etapa. |
| `empty` | Indica que nenhum título e nenhum subtítulo foram informados para a etapa. Aplica-se a text. |
| `title` | O título da etapa. |
| `subtitle` | O subtítulo da etapa. |
| `body` | Wrapper do conteúdo da etapa. |
| `content` | O conteúdo das etapas. |

Usando essas partes CSS, podemos personalizar a aparência do componente <ApiLink pkg="core" type="Stepper" /> assim:

```css
igc-step::part(title) {
  color: var(--ig-primary-500);
}
igc-step[active]::part(indicator) {
  background-color: var(--ig-primary-500);
}
igc-step::part(indicator) {
  background-color: var(--ig-surface-500);
}
```
