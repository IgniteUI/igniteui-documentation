# Componente Breadcrumbs <Badge variant="new" />

O componente {ProductName} Breadcrumbs renderiza uma trilha ordenada de itens de navegação separados por um ícone configurável, comunicando a localização do usuário na hierarquia do site e oferecendo um caminho de volta às páginas de nível superior.

## Anatomia

O componente {Platform} Breadcrumbs é formado por um par de elementos: um contêiner que gerencia o estado compartilhado e é renderizado como uma lista ARIA, e um ou mais itens filhos que renderizam conteúdo arbitrário inserido em slot, seguido de um separador.

```text
<igc-breadcrumbs role="list">
  <igc-breadcrumb role="listitem">
    ├── ::part(label)
    │   ├── slot="prefix"                 // optional prefix content
    │   ├── default slot                  // main content, typically <a>
    │   └── slot="suffix"                 // optional suffix content
    └── ::part(separator)                 // hidden on the last item
        └── slot="separator"              // per-item override
  </igc-breadcrumb>
  <!-- more <igc-breadcrumb> items ... -->
  <igc-breadcrumb current role="listitem" aria-current="page">
    <!-- last item, no trailing separator -->
  </igc-breadcrumb>
</igc-breadcrumbs>
```

## Uso

### Página atual

Marque o item que representa a página visualizada no momento com a <PlatformBlock for="WebComponents, Angular">[`current`]({environment:infragisticsBaseUrl}/api/webcomponents/igniteui-webcomponents/latest/classes/IgcBreadcrumbComponent#current)</PlatformBlock><PlatformBlock for="React, Blazor"><ApiLink pkg="core" type="Breadcrumb" member="current" label="current" /></PlatformBlock> propriedade. O item a reflete como um atributo e define `aria-current="page"`, para que os leitores de tela anunciem a página atual.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-breadcrumbs>
  <igc-breadcrumb><a href="/home">Home</a></igc-breadcrumb>
  <igc-breadcrumb current><a href="/home/dashboard">Dashboard</a></igc-breadcrumb>
</igc-breadcrumbs>
```

</PlatformBlock>

### Separador compartilhado

Use o <PlatformBlock for="WebComponents, Angular">[`separator`]({environment:infragisticsBaseUrl}/api/webcomponents/igniteui-webcomponents/latest/classes/IgcBreadcrumbsComponent#separator)</PlatformBlock><PlatformBlock for="React, Blazor"><ApiLink pkg="core" type="Breadcrumbs" member="separator" label="separator" /></PlatformBlock> propriedade no contêiner para definir um ícone de separador compartilhado para todos os itens da trilha. O valor é o nome de um ícone da coleção de ícones registrada, e o contêiner o propaga para cada item.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-breadcrumbs separator="slash">
  <igc-breadcrumb><a href="/home">Home</a></igc-breadcrumb>
  <igc-breadcrumb><a href="/home/products">Products</a></igc-breadcrumb>
  <igc-breadcrumb><a href="/home/products/laptops">Laptops</a></igc-breadcrumb>
  <igc-breadcrumb current><a href="/home/products/laptops/gaming">Gaming Laptop</a></igc-breadcrumb>
</igc-breadcrumbs>
```

</PlatformBlock>

### Substituição do separador por item

O separador também pode ser substituído para um único item, inserindo conteúdo no slot `separator` desse item. Isso é útil para combinar separadores de texto (como `/` ou `›`) com ícones, ou para usar um separador totalmente diferente em cada limite.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-breadcrumbs>
  <igc-breadcrumb>
    <a href="/home">Home</a>
    <span slot="separator">/</span>
  </igc-breadcrumb>
  <igc-breadcrumb current><a href="/home/settings">Settings</a></igc-breadcrumb>
</igc-breadcrumbs>
```

</PlatformBlock>

### Faça/Não faça

Use breadcrumbs para orientar os usuários em aplicações com muito conteúdo e pelo menos três níveis de hierarquia, oferecendo um caminho claro e de baixo atrito para voltar às páginas pai. Não use breadcrumbs em estruturas de site planas, de nível único, onde criam poluição visual desnecessária, nem em processos sequenciais passo a passo, nos quais indicadores de progresso são necessários.

## Acessibilidade

O {Platform} Breadcrumbs segue o padrão ARIA de navegação em trilha. O contêiner expõe o papel ARIA `list`, cada item expõe o papel `listitem`, e o item atual é anunciado com `aria-current="page"`.

### Marco de navegação acessível

Envolva a trilha em um elemento `<nav>` com um `aria-label`, para que a tecnologia assistiva o exponha como um marco de navegação. O rótulo pertence ao `<nav>`, não à lista, conforme o padrão ARIA de breadcrumb.

```html
    <igc-breadcrumb><a href="/">Root</a></igc-breadcrumb>
    <igc-breadcrumb current><a href="/products">Products</a></igc-breadcrumb>
  </igc-breadcrumbs>
</nav>
```

</PlatformBlock>

### Interação por teclado

Os componentes Breadcrumbs não implementam tratamento de teclado personalizado; a navegação depende do comportamento nativo do conteúdo interativo inserido em slot:

| Tecla | Ação |
| -- | -- |
| `Tab` / `Shift` + `Tab` | Move o foco entre os elementos interativos (normalmente links) inseridos em slot em cada item do breadcrumb. |
| `Enter` / `Space` | Ativa o link em foco, seguindo o comportamento nativo do elemento inserido em slot. |

### Leitores de tela / ARIA

- O host `Breadcrumbs` tem `role="list"`.
- Cada host `Breadcrumb` tem `role="listitem"`.
- Definir `current` como `true` aplica `aria-current="page"` ao host; defini-lo de volta como `false` remove o atributo.
- Definir `disabled` como `true` aplica `aria-disabled="true"` ao host.
- Os ícones de separador são decorativos e não são anunciados pelos leitores de tela.

### Conformidade de acessibilidade

A Infragistics documenta o suporte de acessibilidade do {ProductName} para as áreas das diretrizes da Seção 508 e da WCAG 2.1 no tópico [Conformidade de acessibilidade](../interactivity/accessibility-compliance.mdx).

| Critério | Como o componente atende |
| -- | -- |
| [1.3.1 Informações e relações](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships) | O contêiner e os itens expõem os papéis `list` / `listitem`, e o item atual expõe `aria-current="page"`. |
| [2.4.8 Localização](https://www.w3.org/WAI/WCAG21/Understanding/location) | A trilha comunica visual e programaticamente a localização da página atual dentro da hierarquia do site. |
| [4.1.2 Nome, função, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | O wrapper `<nav>` carrega o nome acessível; os papéis `list`/`listitem` carregam a semântica estrutural. |

Suas responsabilidades:

- Envolva o contêiner Breadcrumbs em um elemento `<nav>` e defina um `aria-label` descritivo, como `"Breadcrumb"` ou `"Product category"`.
- Marque exatamente um item como `current` por trilha, para que os leitores de tela anunciem uma única página atual.
- Forneça um rótulo de texto significativo dentro de cada âncora inserida em slot; não dependa apenas de ícones de prefixo para comunicar o destino.

## Solução de problemas

As orientações de solução de problemas do {Platform} Breadcrumbs seguem o formato problema → causa → correção para problemas comuns de integração e renderização.

### Por que o meu separador não aparece em alguns itens?

O separador é ocultado automaticamente no último item da trilha, o que é o comportamento esperado pelo padrão ARIA de breadcrumb. Se ele estiver ausente em um item inesperado, verifique se esse item é o último filho visível do contêiner.

### Por que o nome do ícone personalizado que defini em 'separator' não está sendo renderizado?

O ícone do separador precisa estar registrado no registro de ícones. Registre o ícone antes de renderizar a trilha, ou use o ícone padrão `tree_expand` que acompanha o tema.

### Por que a trilha não quebra linha em RTL?

A quebra de linha não é específica de RTL: ela acontece sempre que a largura total do conteúdo excede a largura do contêiner. Em contextos RTL, a ordem visual é invertida e o ícone do separador é espelhado automaticamente; se a trilha ainda transbordar, verifique se algum elemento pai impede o contêiner de ocupar sua largura natural.

## Limitações conhecidas

O {Platform} Breadcrumbs tem as seguintes limitações independentes de plataforma.

- Os componentes Breadcrumbs não implementam tratamento de teclado personalizado; a ativação depende do elemento interativo inserido em slot em cada item (geralmente uma âncora).
- Os Breadcrumbs não renderizam um marco `<nav>` próprio; a aplicação que os usa deve fornecer o wrapper `<nav aria-label="...">`.
- O contêiner não trunca trilhas longas automaticamente. Combine a quebra de linha natural do flex com sua própria estratégia de overflow (por exemplo, recolher itens intermediários em um menu) quando for necessária uma trilha em uma única linha em larguras estreitas.

## Perguntas frequentes

<Faq>
  <FaqItem question="Como altero o ícone do separador entre os itens?" indicatorPosition="end">
    Defina a propriedade `separator` do contêiner Breadcrumbs com o nome de qualquer ícone registrado; o contêiner propaga o ícone para cada item descendente. Para substituir o separador de um único item, insira o conteúdo de substituição no slot `separator` desse item.
  </FaqItem>

  <FaqItem question="Preciso ocultar manualmente o último separador?" indicatorPosition="end">
    Não. O item do Breadcrumb oculta automaticamente o separador final quando ele é o último item da trilha, então você pode renderizar os itens em um laço sem nenhum tratamento especial.
  </FaqItem>

  <FaqItem question="O componente Breadcrumbs renderiza ele mesmo um marco `<nav>`?" indicatorPosition="end">
    Não. O Breadcrumbs é renderizado como uma `list` ARIA de `listitem` filhos. Seguindo o padrão ARIA de breadcrumb, a aplicação que o usa envolve o contêiner em `<nav aria-label="Breadcrumb">` (ou em um rótulo mais específico), para que o nome acessível fique no marco e não na lista.
  </FaqItem>

  <FaqItem question="Como marco a página atual?" indicatorPosition="end">
    Defina a propriedade `current` no item do Breadcrumb que representa a página visualizada no momento. O item reflete `current` como atributo e aplica `aria-current="page"` no host, para que os leitores de tela anunciem qual entrada é a página atual.
  </FaqItem>

  <FaqItem question="Qual pacote devo instalar para o Breadcrumbs?" indicatorPosition="end">

  </FaqItem>
</Faq>
