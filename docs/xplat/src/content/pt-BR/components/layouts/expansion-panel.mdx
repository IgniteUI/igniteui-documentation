# Visão geral do {Platform} Expansion Panel

O {ProductName} Expansion Panel é um componente accordion leve que pode ser renderizado em dois estados: recolhido ou expandido. O expansion panel pode ser alternado com um clique do mouse ou por interações com o teclado.

## Personalização do componente
O controle <ApiLink pkg="core" type="ExpansionPanel" /> permite adicionar todo tipo de conteúdo ao seu corpo. Ele pode renderizar [input](../inputs/input.mdx), gráficos e até outros expansion panels!

O <ApiLink pkg="core" type="ExpansionPanel" /> permite personalizar facilmente o cabeçalho pelos slots expostos `title`, `subTitle` e `indicator`.

A posição do indicador de expansão pode ser configurada pela propriedade <ApiLink pkg="core" type="ExpansionPanel" member="indicatorPosition" label="IndicatorPosition" /> do Expansion Panel. As opções possíveis são **start**, **end** ou **none**.

### Elementos recomendados para os slots

Ao inserir conteúdo nos slots `title` e `subtitle`, recomendamos usar elementos `<span>` em vez de elementos de título (`<h1>`–`<h6>`). Elementos de título têm estilos próprios (como tamanho de fonte, altura de linha e margens) que podem interferir na tipografia e no layout pretendidos para o componente. Usar um `<span>` oferece um contêiner neutro que herda os estilos do componente de forma limpa.

O slot `indicator` é destinado a conteúdo do tipo ícone. Recomendamos usar o componente [`<igc-icon>`](../layouts/icon.mdx) para essa finalidade. Alternativamente, se você não quiser usar um ícone para o indicador, um elemento `<span>` pode ser usado para exibir texto, símbolos ou emojis.

<PlatformBlock for="WebComponents">

```html
<igc-expansion-panel>
  <span slot="title">Golden Retriever</span>
  <span slot="subtitle">Medium-large gun dog</span>
  <igc-icon slot="indicator" name="arrow_forward"></igc-icon>
</igc-expansion-panel>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrExpansionPanel>
  <span slot="title">Golden Retriever</span>
  <span slot="subtitle">Medium-large gun dog</span>
```

## Navegação pelo teclado

A navegação pelo teclado do {ProductName} Expansion Panel está em conformidade com os padrões de acessibilidade do W3C e é prática de usar.

**Combinações de teclas**

- <kbd>ALT</kbd> + <kbd>↓</kbd> - expande o painel em foco
- <kbd>ALT</kbd> + <kbd>↑</kbd> - recolhe o painel em foco
- <kbd>SPACE</kbd>/<kbd>ENTER</kbd> - alterna o estado de expansão do painel em foco

## Estilização

O componente <ApiLink pkg="core" type="ExpansionPanel" /> expõe várias partes CSS, dando a você controle total sobre o seu estilo:

|Nome|Descrição|
|--|--|
| `header` | O contêiner do indicador de expansão, do título e do subtítulo. |
| `title` | O contêiner do título. |
| `subtitle` | O contêiner do subtítulo. |
| `indicator` | O contêiner do indicador. |
| `content` | O wrapper do conteúdo do expansion panel. |

```css
igc-expansion-panel {
  background-color: var(--ig-secondary-900);
  color: var(--ig-secondary-900-contrast);
}

igc-button::part(base) {
  color: var(--ig-secondary-900-contrast);
}

igc-button::part(base)::before {
  background-color: var(--ig-warn-500);
}

igc-expansion-panel::part(indicator) {
  color: var(--ig-warn-500);
}

igc-expansion-panel::part(header) {
  background-color: var(--ig-secondary-900);
}

igc-expansion-panel::part(title),
igc-expansion-panel::part(subtitle) {
  color: var(--ig-warn-500);
}
```
