# Componente Carousel

O {ProductName} Carousel é um componente de layout em slides para apresentar imagens, cards ou outro conteúdo com controles de navegação e indicadores.

Use o Carousel quando os usuários precisarem percorrer um pequeno conjunto de slides relacionados, um de cada vez, com animação opcional, navegação personalizada e transições automáticas.

## Primeiros passos

O {Platform} Carousel requer o componente carousel, o componente slide e a folha de estilo do tema antes de você declarar os slides.

<PlatformBlock for="Angular">

Instale o {ProductName} e configure o tema a partir do tópico [Primeiros passos](../general/getting-started.mdx) antes de adicionar o Carousel a uma aplicação.

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

Instale o {ProductName} e configure o tema a partir do tópico [Primeiros passos](../general-getting-started.mdx) antes de adicionar o Carousel a uma aplicação.

</PlatformBlock>

<PlatformBlock for="WebComponents">

Importe e registre o componente <ApiLink pkg="core" type="Carousel" /> e o seu tema.

```ts
import { defineComponents, IgcCarouselComponent } from "igniteui-webcomponents";
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcCarouselComponent);
```

</PlatformBlock>

<PlatformBlock for="React">

Importe os componentes wrapper do Carousel e a folha de estilo do tema.

```tsx
import { IgrCarousel, IgrCarouselSlide } from 'igniteui-react';
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Registre os serviços de {ProductName}:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

Registrar <ApiLink pkg="core" type="CarouselModule" />, o módulo de recursos do cliente do Carousel, é **opcional**: o componente carrega seus recursos na primeira renderização. Listá-lo em `builder.Services.AddIgniteUIBlazor(typeof(IgbCarouselModule))` pode ser usado para pré-carregar recursos ou para oferecer suporte a elementos criados somente no cliente (consulte [Módulos de componentes](../general-getting-started.mdx#módulos-do-componente)).

Adicione a folha de estilo do tema à página hospedeira da aplicação.

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```

</PlatformBlock>

<PlatformBlock for="Angular">

Importe as diretivas do Carousel e a folha de estilo do tema do Ignite UI.

```ts
import { Component } from '@angular/core';
import { IGX_CAROUSEL_DIRECTIVES } from 'igniteui-angular/carousel';

@Component({
    selector: 'app-carousel-sample',
    imports: [IGX_CAROUSEL_DIRECTIVES],

                <img src="assets/images/carousel/ignite-ui-angular-indigo-design.png" alt="Ignite UI Indigo Design" />
            </igx-slide>
        </igx-carousel>
    `,
})
export class CarouselSampleComponent {}
```

</PlatformBlock>

## Uso

O {Platform} Carousel é configurado colocando componentes de slide dentro do host e, em seguida, ativando o comportamento de navegação, indicadores e transição de que o seu layout precisa.

<DocsAside type="info">
Se nenhum slide ativo for definido, o primeiro fica ativo por padrão. Se vários slides estiverem ativos na renderização inicial ou em atualizações posteriores, é usado o último slide ativo.
</DocsAside>

## Acessibilidade

O {Platform} Carousel expõe a semântica de carousel, slide e indicador para usuários de teclado e de tecnologias assistivas.

### Interação por teclado

| Tecla | Ação |
| --- | --- |
| <kbd>Espaço</kbd> ou <kbd>Enter</kbd> | Ativa o botão de navegação em foco. |
| <kbd>Seta para a esquerda</kbd> | Move o foco do indicador para o indicador de slide anterior, ou para o próximo indicador no modo da direita para a esquerda. |
| <kbd>Seta para a direita</kbd> | Move o foco do indicador para o próximo indicador de slide, ou para o indicador anterior no modo da direita para a esquerda. |
| <kbd>Home</kbd> | Move o foco do indicador para o primeiro indicador de slide, ou para o último indicador no modo da direita para a esquerda. |
| <kbd>End</kbd> | Move o foco do indicador para o último indicador de slide, ou para o primeiro indicador no modo da direita para a esquerda. |

### Leitores de tela / ARIA

O Carousel fornece papéis e estados ARIA para o host, os slides, os indicadores e os controles de navegação.

| Elemento | Papel ou atributo | Finalidade |
| --- | --- | --- |
| Host do Carousel | `role="region"` e `aria-roledescription="carousel"` | Identifica o Carousel como uma região de conteúdo navegável. |
| Contêiner de slides | `aria-live="polite"` ou `aria-live="off"` | Anuncia as mudanças de slide quando a reprodução automática não está ativa. |
| Slide | `role="tabpanel"`, `aria-roledescription="slide"` e `aria-label` | Identifica cada slide e a sua posição no conjunto. |
| Contêiner de indicadores | `role="tablist"` | Agrupa os indicadores de slide. |
| Indicador | `role="tab"`, `aria-label` e `aria-selected` | Identifica o slide representado pelo indicador e se ele está selecionado. |
| Botões de navegação | `aria-label` | Nomeia as ações de slide anterior e próximo. |

## Perguntas frequentes

<Faq>
  <FaqItem question="O carousel deve rodar automaticamente?" indicatorPosition="end">
    Prefira a navegação manual sempre que possível. Se um carousel girar automaticamente, ofereça uma forma clara de pausar e retomar, para que os usuários tenham tempo suficiente para ler e interagir com cada slide.
  </FaqItem>
  <FaqItem question="O que deve acontecer quando alguém passa o ponteiro sobre um carousel ou o recebe o foco?" indicatorPosition="end">
    Pause a rotação automática enquanto o usuário estiver lendo ou interagindo com o carousel. Não a retome até que o usuário escolha explicitamente continuar.
  </FaqItem>
  <FaqItem question="Quantos slides um carousel deve conter?" indicatorPosition="end">
    Mantenha o conjunto pequeno e focado. Uma coleção curta de slides relacionados é mais fácil de descobrir e de examinar do que uma sequência longa com conteúdo oculto.
  </FaqItem>
  <FaqItem question="Um slide pode conter formulários, botões ou várias ações?" indicatorPosition="end">
    Sim, quando o conteúdo interativo tem uma ordem de foco previsível e o slide não muda enquanto o usuário interage com ele. Mantenha as ações concentradas na tarefa principal do slide.
  </FaqItem>
  <FaqItem question="Os pontos indicadores devem ser interativos?" indicatorPosition="end">
    Torne os indicadores interativos quando eles representarem navegação direta para slides individuais. Isso dá ao usuário uma forma de chegar a um conteúdo específico sem selecionar repetidamente anterior ou próximo.
  </FaqItem>
  <FaqItem question="Quando devo usar um layout estático em vez de um carousel?" indicatorPosition="end">
    Use uma lista estática, uma grade, abas ou um stepper quando os usuários precisarem comparar itens, ler todos os itens ou encontrar um item específico imediatamente. O carousel funciona melhor para uma sequência compacta de conteúdo relacionado.
  </FaqItem>
</Faq>
