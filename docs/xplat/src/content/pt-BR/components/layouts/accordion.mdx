O componente {ProductName} Accordion é um componente de layout para organizar painéis de conteúdo expansíveis em um único contêiner vertical.

### Expansão programática

<PlatformBlock for="Angular">

Use <ApiLink type="Accordion" member="collapseAll" label="collapseAll()" /> e <ApiLink type="Accordion" member="expandAll" label="expandAll()" /> para recolher ou expandir os painéis do accordion programaticamente.

<DocsAside type="info">
Chamar <ApiLink type="Accordion" member="expandAll" label="expandAll()" /> expande somente o último painel habilitado quando <ApiLink type="Accordion" member="singleBranchExpand" label="singleBranchExpand" /> é `true`.
</DocsAside>

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

Use <ApiLink pkg="core" type="Accordion" member="hideAll" label="HideAll" /> e <ApiLink pkg="core" type="Accordion" member="showAll" label="ShowAll" /> para recolher ou expandir todos os painéis disponíveis programaticamente.

<DocsAside type="info">
Chamar <ApiLink pkg="core" type="Accordion" member="showAll" label="ShowAll" /> expande todos os painéis, mesmo quando <ApiLink pkg="core" type="Accordion" member="singleExpand" label="SingleExpand" /> é `true`.
</DocsAside>

</PlatformBlock>

### Faça/Não faça

**Quando usar:** use o accordion quando precisar organizar conteúdo secundário, entradas de perguntas frequentes, grupos de configurações ou outras seções verticais relacionadas que o usuário expande sob demanda. Mantenha os títulos dos painéis curtos e descritivos, e ative o comportamento de expansão única quando os usuários devem se concentrar em uma seção por vez.

<PlatformBlock for="Angular">

**Quando não usar:** use o [Expansion Panel](../expansion-panel.mdx) quando precisar de uma única seção expansível independente, em vez de um contêiner coordenado que gerencia vários painéis juntos. Não use um accordion para ocultar conteúdo primário essencial nem para agrupar seções não relacionadas.

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

**Quando não usar:** use o [Expansion Panel](./expansion-panel.mdx) quando precisar de uma única seção expansível independente, em vez de um contêiner coordenado que gerencia vários painéis juntos. Não use um accordion para ocultar conteúdo primário essencial nem para agrupar seções não relacionadas.

</PlatformBlock>

## Propriedades

O accordion expõe controles no nível do contêiner; o estado específico de cada painel é configurado em cada <ApiLink pkg="core" type="ExpansionPanel" />.

<PlatformBlock for="Angular">

| Nome | Tipo | Padrão | Descrição |
| -- | -- | -- | -- |
| <ApiLink type="Accordion" member="singleBranchExpand" label="singleBranchExpand" /> | `boolean` | `false` | Controla se um ou vários painéis podem permanecer expandidos ao mesmo tempo. |
| <ApiLink type="Accordion" member="panels" label="panels" /> | `QueryList<IgxExpansionPanelComponent>` | n/a | Retorna a coleção de painéis de expansão filhos no accordion. |

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

| Nome | Tipo | Padrão | Descrição |
| -- | -- | -- | -- |
| <ApiLink pkg="core" type="Accordion" member="singleExpand" label="SingleExpand" /> | `boolean` | `false` | Controla se um ou vários painéis podem permanecer expandidos ao mesmo tempo. |
| <ApiLink pkg="core" type="Accordion" member="panels" label="Panels" /> | <ApiLink pkg="core" type="ExpansionPanel" label="ExpansionPanel[]" /> | n/a | Retorna a coleção de painéis de expansão filhos no accordion. |

</PlatformBlock>

### Leitores de tela / ARIA

A semântica de acessibilidade do accordion é fornecida pelos seus painéis de expansão filhos e pelos cabeçalhos deles.

- Cada cabeçalho de painel expõe `role="button"`, `aria-expanded` e `aria-controls`.
- Cada corpo de painel expõe `role="region"` e um rótulo por meio de `aria-labelledby` ou `aria-label`.
- Use um título claro para cada painel, para que as tecnologias assistivas possam anunciar um rótulo significativo.
- Mantenha o conteúdo interativo dentro dos corpos dos painéis em uma ordem de tabulação lógica.

As evidências de conformidade do accordion vêm dos componentes <ApiLink pkg="core" type="ExpansionPanel" /> filhos, que fornecem os cabeçalhos e as regiões interativos.

## Perguntas frequentes

<Faq>
  <FaqItem question="Vários painéis do accordion devem poder ficar abertos ao mesmo tempo?" indicatorPosition="end">
    Permita que vários painéis permaneçam abertos quando os usuários precisarem comparar ou cruzar o conteúdo deles. Use o comportamento de expansão única quando o fluxo de trabalho for mais claro com uma seção ativa por vez.
  </FaqItem>
  <FaqItem question="Quando devo evitar usar um accordion?" indicatorPosition="end">
    Evite usar um accordion para conteúdo essencial, longo ou que exija comparação, que os usuários precisam ler de uma vez. Use títulos claros, uma página separada ou outro layout quando ocultar o conteúdo dificultaria encontrá-lo ou compará-lo.
  </FaqItem>
  <FaqItem question="Como devo escrever os cabeçalhos do accordion?" indicatorPosition="end">
    Use cabeçalhos curtos e descritivos que identifiquem claramente o conteúdo revelado por cada painel. Os usuários devem conseguir examinar os cabeçalhos e decidir qual seção abrir.
  </FaqItem>
  <FaqItem question="Um cabeçalho de accordion pode conter outros botões ou links?" indicatorPosition="end">
    Evite colocar outros controles interativos dentro de um cabeçalho de accordion. Mantenha as ações secundárias fora do cabeçalho, para que o acionador do painel continue claro e não contenha elementos interativos aninhados.
  </FaqItem>
</Faq>
