### Divider recuado

O <ApiLink pkg="core" type="Divider" /> pode ser definido em ambos os lados. Para `inset` o divider, defina o atributo <ApiLink pkg="core" type="Divider" member="middle" label="Middle" /> como true em combinação com a variável CSS `--inset`. Isso encurtará a linha divisória dos dois lados. O valor padrão do atributo <ApiLink pkg="core" type="Divider" member="middle" label="Middle" /> é false.

```css
/* DividerStyles.css */
.withInset{
    --inset: 100px;
    --color:red;
}
```

<PlatformBlock for="WebComponents">

```html
// Both side
<igc-divider middle="true" class="withInset"></igc-divider>
// Left side only
<igc-divider></igc-divider>
```

</PlatformBlock>


<PlatformBlock for="React">

```tsx
// Both side
<IgrDivider middle="true" className="withInset"></IgrDivider>
// Left side only
<IgrDivider  className="withInset"></IgrDivider>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
// Both side
<IgbDivider Middle="True" class="withInset"></IgbDivider>
// Left side only
<IgbDivider class="withInset"></IgbDivider>
```

</PlatformBlock>

## Variáveis CSS
### Recuo
A variável CSS `--inset` encurta o divider pelo valor informado a partir do início. Se middle estiver definido, o encurtamento ocorre dos dois lados.

### Color
A variável CSS `--color` define a cor do divider.
