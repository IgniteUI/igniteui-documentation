# Visão geral do mapa {Platform}

O componente de mapa {ProductName} permite exibir dados que contêm localizações geográficas, a partir de view models, ou dados geoespaciais carregados de arquivos de forma, sobre mapas de imagens geográficas.

## Exemplo de mapa {Platform}

O exemplo a seguir demonstra como exibir dados no `GeographicMap` usando `GeographicProportionalSymbolSeries`, também conhecida como Série de bolhas.

O componente de mapa permite renderizar imagens geográficas do Bing Maps™ e do Open Street Maps.

</PlatformBlock>

<PlatformBlock for="WinUI, Uno">

O componente de mapa permite renderizar imagens geográficas do Open Street Maps.

</PlatformBlock>

O mapa permite plotar dezenas de milhares de pontos de dados e atualizá-los a cada poucos milissegundos, para que o controle possa lidar com os seus feeds em tempo real.

A propriedade Series do mapa é usada para oferecer suporte à renderização de um número ilimitado de séries geográficas. Essa propriedade é uma coleção de objetos de série geográfica, e qualquer tipo de série geográfica pode ser adicionado a ela. Por exemplo, `GeographicSymbolSeries` pode ser adicionado para plotar localizações geográficas, como cidades, e o `GeographicPolylineSeries` para plotar conexões (por exemplo, estradas) entre essas localizações geográficas.

O mapa oferece comportamentos de navegação personalizáveis para navegar pelo conteúdo do mapa usando o mouse, o teclado ou código.

## Módulos do componente

<PlatformBlock for="Angular, React, WebComponents">

O `GeographicMap` exige os seguintes módulos; porém, o DataChartInteractivityModule é necessário apenas para interações com o mouse, como deslocar e ampliar o conteúdo do mapa.

</PlatformBlock>

<PlatformBlock for="Blazor">

As interações do mouse no mapa, como deslocamento e zoom, vêm de <ApiLink raw type="DataChartInteractivityModule" />, que nenhum componente solicita por conta própria; por isso, ele precisa ser registrado. <ApiLink raw type="GeographicMapModule" /> é opcional: o `GeographicMap` o carrega na primeira vez em que é renderizado (veja [Módulos do componente](general-getting-started.mdx#módulos-do-componente)).

</PlatformBlock>

```json-snippet source="/maps/geo-map/type-scatter-bubble-series" channel="modulesImports...moduleRegistration" exclude="Xaml"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "map"
        }
    },
    "modules": [
        "maps/GeographicMapModule",
        "charts/DataChartInteractivityModule"
    ],
    "$modules": [
        "+doc:modulesImports",
        "+doc:moduleRegistration"
    ]
}
```

</PlatformBlock>


## Uso

Configure o mapa geográfico e habilite o zoom com o exemplo a seguir.

```json-snippet
{
    "type": "GeographicMap",
    "height": "100%",
    "width": "100%",
    "zoomable": true
}
```
