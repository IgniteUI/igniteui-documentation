# Feed NuGet da Infragistics

A Infragistics oferece um feed NuGet privado para que usuários licenciados consumam e adicionem pacotes NuGet licenciados do Ignite UI for Blazor aos seus aplicativos por meio do NuGet Package Manager.

Este tópico contém as seguintes seções:

- Adicionando o feed NuGet da Infragistics com o Visual Studio
- Adicionando o feed NuGet da Infragistics com a CLI do NuGet

## Adicionando com o Visual Studio

1 - No Visual Studio, selecione **Ferramentas → Gerenciador de Pacotes NuGet → Configurações do Gerenciador de Pacotes**.

<Image src={nugetPackageManagerSettingMenuItem} alt="nuget-package-manager-setting-menu-item" />

2 - Na seção **Fontes de pacotes**, adicione uma nova fonte de pacotes clicando no **ícone de mais** no canto superior direito da caixa de diálogo.
- Defina o Nome como **Infragistics**
- Defina a Fonte como **https://packages.infragistics.com/nuget/licensed/v3/index.json** se preferir usar a versão 3 do protocolo NuGet. Caso contrário, defina-a como **https://packages.infragistics.com/nuget/licensed/**

<DocsAside type="info">
Para mais detalhes sobre usar a v3 ou uma versão anterior, consulte: **https://devblogs.microsoft.com/nuget/nuget-3-what-and-why/**. O protocolo v3 se aplica apenas ao usar versões mais recentes dos clientes NuGet (posteriores a 2015). Clientes NuGet mais antigos podem ou não ser compatíveis com a v3.
</DocsAside>

Clique no botão **Atualizar** e depois em **OK** para fechar a caixa de diálogo.

<Image src={nugetPackageManagerPackageSourcesIgServer} alt="nuget-package-manager-package-sources-ig-server" />

<DocsAside type="info">
Ao adicionar um pacote NuGet dessa fonte pela primeira vez, você será solicitado a informar as suas credenciais da Infragistics.
</DocsAside>

## Adicionando com a CLI do NuGet

1 - Baixe o [executável mais recente do Nuget](https://dist.nuget.org/win-x86-commandline/latest/nuget.exe). Instrua o seu navegador a salvar o arquivo em uma pasta de sua escolha. O arquivo não é um instalador; você não verá nada se executá-lo diretamente pelo navegador.
2 - Abra um prompt de comando no caminho da pasta do arquivo `nuget.exe` que você acabou de baixar.
3 - Execute o comando a seguir

```cmd
//nuget protocol v3
nuget sources add -name "Infragistics" -source "https://packages.infragistics.com/nuget/licensed/v3/index.json" -username "your login email" -password "your password"

//nuget protocol v2
nuget sources add -name "Infragistics" -source "https://packages.infragistics.com/nuget/licensed" -username "your login email" -password "your password"
```

<DocsAside type="info">
A senha será armazenada criptografada no arquivo de configuração do NuGet e só poderá ser descriptografada no mesmo contexto de usuário em que foi criptografada. O local padrão do arquivo de configuração pode ser encontrado aqui `%AppData%\NuGet\NuGet.config`
</DocsAside>
