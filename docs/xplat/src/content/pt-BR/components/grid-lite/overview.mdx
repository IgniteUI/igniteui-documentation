## O que você obtém com a nossa grade de dados {Platform} gratuita

O nosso {Platform} Grid Lite gratuito e de código aberto vem com os seguintes recursos por coluna: ordenação, filtragem, ocultação, redimensionamento e vários tipos de dados predefinidos. O desempenho ultrarrápido é obtido com a virtualização de linhas. Além disso, o componente oferece suporte à navegação por teclado e a temas por meio do [Ignite UI Theming Framework](../themes/overview.mdx).

### Instalar o IgniteUI.Blazor.GridLite

O {GridLiteTitle} é distribuído no pacote [IgniteUI.Blazor.GridLite](https://www.nuget.org/packages/IgniteUI.Blazor.GridLite), licenciado sob MIT, no NuGet.org. O código-fonte está no [GitHub]({GithubLinkLite}).

No Visual Studio, abra o gerenciador de pacotes NuGet selecionando **Ferramentas** → **Gerenciador de Pacotes NuGet** → **Gerenciar pacotes NuGet para a solução**. Pesquise e instale o pacote NuGet **IgniteUI.Blazor.GridLite**.

Ou instale pelo Console do Gerenciador de Pacotes:

```cmd
Install-Package IgniteUI.Blazor.GridLite
```

Ou pela CLI do .NET:

```cmd
dotnet add package IgniteUI.Blazor.GridLite
```

### Usando o Grid Lite

1 - Adicione o namespace **IgniteUI.Blazor.Controls** no arquivo **_Imports.razor**:

```razor
@using IgniteUI.Blazor.Controls
```

2 - Adicione uma folha de estilos de tema à página hospedeira: **Components/App.razor** em um Blazor Web App, ou **wwwroot/index.html** em um aplicativo Blazor WebAssembly independente.

Se o aplicativo também usar o pacote `IgniteUI.Blazor.Lite` ou `IgniteUI.Blazor`, mantenha a [folha de estilos de tema](../themes/overview.mdx) desse pacote; ela também estiliza a grade. Caso contrário, vincule um dos temas que o pacote `IgniteUI.Blazor.GridLite` distribui:

```razor
<head>
    <link href="_content/IgniteUI.Blazor.GridLite/themes/light/bootstrap.css" rel="stylesheet" />
</head>
```

Os temas são `themes/{light|dark}/{bootstrap|material|fluent|indigo}.css`; veja [Estilos e temas](./theming.mdx).

A grade não precisa de registro de serviço nem de tag script. Em um Blazor Web App, renderize-a em um modo de renderização interativo.

3 - Adicione o componente Grid Lite à sua página Razor:

```razor
<IgbGridLite Data="data" AutoGenerate="true">
</IgbGridLite>

@code {
    private object[] data = new object[]
    {
        new { Name = "John", Age = 30, City = "New York" },
        new { Name = "Jane", Age = 25, City = "Los Angeles" },
        new { Name = "Bob", Age = 35, City = "Chicago" }
    };
}
```
