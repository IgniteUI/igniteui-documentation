# Operações de ordenação

<PlatformBlock for="React, WebComponents">


O {GridLiteTitle} oferece suporte a operações de ordenação na sua fonte de dados. A ordenação de dados é controlada por coluna, permitindo ter colunas ordenáveis e não ordenáveis, enquanto a própria grade controla determinados comportamentos de ordenação. Por padrão, a ordenação em uma coluna está desabilitada, a menos que seja configurada explicitamente com a propriedade `sortable` da coluna.

</PlatformBlock>


<PlatformBlock for="Blazor">

## Ordenação simples e múltipla

<PlatformBlock for="React, WebComponents">


O {GridLiteTitle} oferece suporte tanto à ordenação simples quanto à ordenação por várias colunas. A ordenação por várias colunas vem habilitada por padrão e pode ser configurada pela propriedade `sortingOptions` da grade. A propriedade `mode` aceita `'single'` ou `'multiple'` como valores.

</PlatformBlock>



<PlatformBlock for="Blazor">


O {GridLiteTitle} oferece suporte tanto à ordenação simples quanto à ordenação por várias colunas. A ordenação por várias colunas vem habilitada por padrão e pode ser configurada pela propriedade <ApiLink type="SortingOptions" /> da grade. A propriedade <ApiLink type="SortingOptions" member="mode" label="Mode" /> aceita <ApiLink type="GridLiteSortingMode" member="Single" label="GridLiteSortingMode.Single" /> ou <ApiLink type="GridLiteSortingMode" member="Multiple" label="GridLiteSortingMode.Multiple" /> como valores.

</PlatformBlock>



<PlatformBlock for="WebComponents">


```typescript
// Enable single-column sorting
grid.sortingOptions = { mode: 'single' };
```

</PlatformBlock>


<PlatformBlock for="React">


```tsx
// Enable single-column sorting
gridRef.current.sortingOptions = { mode: 'single' };

// or directly in the JSX
<IgrGridLite sortingOptions={{ mode: 'single' }}/>
```

</PlatformBlock>



<PlatformBlock for="Blazor">

```razor

@code {

    private IgbGridLiteSortingOptions sortingOptions = new() { Mode = GridLiteSortingMode.Single };
```

</PlatformBlock>


<DocsAside type="info">
O comportamento de ordenação simples/por várias colunas controla como os usuários finais interagem com o {GridLiteTitle}. A ordenação pela API com várias expressões continua funcionando quando a ordenação simples está habilitada.
</DocsAside>

### Ordenação em três estados
O {GridLiteTitle} oferece suporte à ordenação em três estados, e ela está sempre habilitada. Os usuários percorrem os seguintes estados de direção ao clicar nos cabeçalhos de colunas ordenáveis:



<PlatformBlock for="React, WebComponents">


```
ascending -> descending -> none -> ascending
```

onde `none` é o estado inicial dos dados, ou seja, sem nenhuma ordenação aplicada pela grade.

</PlatformBlock>


<PlatformBlock for="Blazor">


```
Ascending -> Descending -> None -> Ascending
```

onde `None` é o estado inicial dos dados, ou seja, sem nenhuma ordenação aplicada pela grade.

</PlatformBlock>


### Indicadores de ordenação

Quando a ordenação de várias colunas está habilitada, os cabeçalhos das colunas exibem um indicador de ordenação, que é um número que representa a ordem em que as operações de ordenação foram aplicadas.

## Modelo de ordenação


<PlatformBlock for="React, WebComponents">


O bloco de construção das operações de ordenação na {GridLiteTitle} é o `SortingExpression<T>`, que tem as seguintes propriedades:

</PlatformBlock>


<PlatformBlock for="Blazor">


O bloco de construção das operações de ordenação na {GridLiteTitle} é o <ApiLink type="IgbGridLiteSortingExpression" />, que tem as seguintes propriedades:

</PlatformBlock>



```typescript
type SortingExpression<T> = {
  /**
   * The `key` of the target column for the sort operation.
   */
  key: keyof T;
  /**
   * The sort direction for the operation.
   */
  direction: 'ascending' | 'descending' | 'none';
  /**
   * Should the operation be case sensitive. Applies to the default string type.
   * If not explicitly passed, it will use the value from the target column sort configuration if applicable.
   */
  caseSensitive?: boolean;
  /**
   * Specifies a custom comparer function for the operation.
   * Will use the value from the target column sort configuration if applicable.
   */
  comparer?: SortComparer<T, T[keyof T]>;
};
```

<PlatformBlock for="Blazor">

```csharp
public class IgbGridLiteSortingExpression
{
    /// <summary>
    /// The target column.
    /// </summary>
    public required string Key { get; set; }

    /// <summary>
    /// Sort direction for this operation.
    /// </summary>
    public GridLiteSortingDirection Direction { get; set; }

    /// <summary>
    /// Whether the sort operation should be case sensitive.
    /// If not provided, the value is resolved based on the column sort configuration.
    /// </summary>
    public bool? CaseSensitive { get; set; }
}
```

</PlatformBlock>

A grade consome essas expressões para os métodos e a configuração da sua API de ordenação, e as produz para os eventos e para o seu estado de ordenação quando
um usuário final interage com o componente. Veja abaixo mais informações.

## API de ordenação


<PlatformBlock for="React, WebComponents">


O {GridLiteTitle} expõe duas abordagens principais para aplicar operações de ordenação pela sua API: pelos métodos `sort()`/`clearSort()` ou pela propriedade `sortingExpressions`.

O método `sort()` aceita uma única expressão ou um array de expressões de ordenação e depois ordena os dados da grade com base nessas expressões.

</PlatformBlock>



<PlatformBlock for="Blazor">


O {GridLiteTitle} expõe duas abordagens principais para aplicar operações de ordenação pela sua API: pelos métodos `SortAsync()`/`ClearSortAsync()` ou pela propriedade `SortingExpressions`.

O método `SortAsync()` aceita uma única expressão ou uma coleção de expressões de ordenação e, em seguida, ordena os dados da grade com base nessas expressões.

</PlatformBlock>



<PlatformBlock for="WebComponents">


```typescript
// Single
grid.sort({ key: 'price', direction: 'descending' });

// Multiple
grid.sort([
  { key: 'price', direction: 'descending' },
  { key: 'name', direction: 'descending' },
]);
```

</PlatformBlock>


<PlatformBlock for="React">


```typescript
// Single
gridRef.current.sort({ key: 'price', direction: 'descending' });

// Multiple
gridRef.current.sort([
  { key: 'price', direction: 'descending' },
  { key: 'name', direction: 'descending' },
]);
```

</PlatformBlock>



<PlatformBlock for="Blazor">

```razor
// Single
await grid.SortAsync(new IgbGridLiteSortingExpression { Key = "Price", Direction = GridLiteSortingDirection.Descending });

// Multiple
await grid.SortAsync(new IgbGridLiteSortingExpression[]
{
    new IgbGridLiteSortingExpression { Key = "Price", Direction = GridLiteSortingDirection.Descending },
    new IgbGridLiteSortingExpression { Key = "Name", Direction = GridLiteSortingDirection.Descending }
});
```

</PlatformBlock>


<PlatformBlock for="React, WebComponents">


O método `clearSort()`, como o nome indica, limpa o estado de ordenação de uma única coluna ou de toda a grade, dependendo
dos argumentos informados.

</PlatformBlock>


<PlatformBlock for="Blazor">


O método `ClearSortAsync()`, como o nome indica, limpa o estado de ordenação de uma única coluna ou de toda a grade, dependendo
dos argumentos informados.

</PlatformBlock>



<PlatformBlock for="WebComponents">


```typescript
// Clear the sort state for the `price` column.
grid.clearSort('price');

// Clear the sort state of the grid.
grid.clearSort();
```

</PlatformBlock>


<PlatformBlock for="React">


```typescript
// Clear the sort state for the `price` column.
gridRef.current.clearSort('price');

// Clear the sort state of the grid.
gridRef.current.clearSort();
```

</PlatformBlock>


<PlatformBlock for="Blazor">

```razor

// Clear the sort state of the grid.
await grid.ClearSortAsync();
```

</PlatformBlock>

### Estado inicial de ordenação


<PlatformBlock for="React, WebComponents">


A propriedade `sortingExpressions` tem um comportamento muito semelhante à chamada do método `sort()`. Ela expõe uma forma declarativa de controlar o
estado de ordenação na grade, mas a propriedade mais útil é a capacidade de definir o estado inicial de ordenação quando o {GridLiteTitle} é renderizado pela primeira vez.

</PlatformBlock>



<PlatformBlock for="Blazor">


A propriedade `SortingExpressions` tem um comportamento muito semelhante à chamada do método `SortAsync()`. Ela expõe uma forma declarativa de controlar o
estado de ordenação na grade, mas a propriedade mais útil é a capacidade de definir o estado inicial de ordenação quando o {GridLiteTitle} é renderizado pela primeira vez.

</PlatformBlock>



<PlatformBlock for="WebComponents">


Por exemplo, aqui está um exemplo baseado em Lit:

```typescript
{
  sortState: SortingExpression<Products>[] = [
    { key: 'price', direction: 'descending' },
    { key: 'name', direction: 'ascending', caseSensitive: true },
  ];

  render() {
    return html`<igc-grid-lite .sortingExpressions=${sortState}></igc-grid-lite>`
  }
}
```

</PlatformBlock>


<PlatformBlock for="React">


Aqui está um exemplo:

```tsx
const sortState: SortingExpression<Products>[] = [
  { key: 'price', direction: 'descending' },
  { key: 'name', direction: 'ascending', caseSensitive: true },
];

return (
  <IgrGridLite sortingExpressions={sortState} />
);
```

</PlatformBlock>



<PlatformBlock for="Blazor">


Por exemplo:

```razor
<IgbGridLite Data="@data" SortingExpressions="sortState" />

@code {
    private IgbGridLiteSortingExpression[] sortState = new[]
    {
        new IgbGridLiteSortingExpression { Key = "Price", Direction = GridLiteSortingDirection.Descending },
        new IgbGridLiteSortingExpression { Key = "Name", Direction = GridLiteSortingDirection.Ascending, CaseSensitive = true }
    };
}
```

</PlatformBlock>


<PlatformBlock for="React, WebComponents">

Ela pode ser usada para obter o estado de ordenação atual do componente e fazer processamento adicional, dependendo de outro estado da sua aplicação.

</PlatformBlock>

<PlatformBlock for="Blazor">

O parâmetro `SortingExpressions` define o estado de ordenação; ele não acompanha as mudanças que os usuários fazem pela interface. Para acompanhar o estado de ordenação, trate o evento `Sorted`: o seu `Expression` é a expressão de ordenação da coluna que foi ordenada.

</PlatformBlock>


<PlatformBlock for="WebComponents">


```typescript
const state = grid.sortingExpressions;
// Save the current sort state
saveUserSortState(state);
```

</PlatformBlock>


<PlatformBlock for="React">


```typescript
const state = gridRef.current.sortingExpressions;
// Save the current sort state
saveUserSortState(state);
```

</PlatformBlock>


<PlatformBlock for="Blazor">

```razor
<IgbGridLite Data="@data" Sorted="OnSorted" />

@code {
    private void OnSorted(IgbGridLiteSortedEventArgs args)
    {
        // Save the sort state of the column
        SaveUserSortState(args.Expression);
    }
}
```

</PlatformBlock>

## Eventos


<PlatformBlock for="React, WebComponents">


Quando uma operação de ordenação é realizada pela interface, o componente emite um evento personalizado `sorting`. A propriedade `detail` é a expressão de ordenação que será aplicada pelo {GridLiteTitle}. O evento pode ser cancelado e, se for cancelado, interromperá a operação de ordenação atual.

Depois que a grade aplica o novo estado de ordenação, um evento `sorted` é emitido. Ele contém a expressão que foi usada na última operação de ordenação, e não é cancelável.

<PlatformBlock for="WebComponents">
```typescript
grid.addEventListener('sorting', (event: CustomEvent<SortingExpression<T>>) => { ... });
grid.addEventListener('sorted', (event: CustomEvent<SortingExpression<T>>) => { ... });
```
</PlatformBlock>
<PlatformBlock for="React">
```typescript
gridRef.current.addEventListener('sorting', (event: CustomEvent<SortingExpression<T>>) => { ... });
gridRef.current.addEventListener('sorted', (event: CustomEvent<SortingExpression<T>>) => { ... });
```
</PlatformBlock>


</PlatformBlock>



<PlatformBlock for="Blazor">


Quando uma operação de ordenação é realizada pela interface, o componente dispara o evento `Sorting` com a expressão de ordenação da operação. É uma notificação: não pode cancelar nem alterar a operação.

Depois que a grade aplica o novo estado de ordenação, um evento `Sorted` é disparado. Ele contém a expressão usada na última operação de ordenação.

```razor
<IgbGridLite Sorting="OnSorting" Sorted="OnSorted" />

@code {

    {
        // Handle sorting event
    }

    private void OnSorted(IgbGridLiteSortedEventArgs args)
    {
        // Handle sorted event
    }
}
```

</PlatformBlock>

## Operações de ordenação remota

Nos casos em que a ordenação precisa ser feita remotamente, ou em que você quer salvar o estado/dados atuais em algum servidor, o {GridLiteTitle} expõe um hook no qual você pode implementar e personalizar esse comportamento.

<PlatformBlock for="React, WebComponents">
Usando a propriedade `dataPipelineConfiguration`, você pode fornecer um hook personalizado, que será chamado sempre que uma operação de ordenação estiver prestes a ser executada. O callback recebe um objeto <ApiLink type="DataPipelineParams" />.

```typescript
export type DataPipelineParams<T extends object> = {
  /**
   * The current data state of the grid.
   */
  data: T[];
  /**
   * The grid component itself.
   */
  grid: IgcGridLite<T>;
  /**
   * The type of data operation being performed.
   */
  type: 'sort' | 'filter';
};
```

<PlatformBlock for="WebComponents">
```typescript
grid.dataPipelineConfiguration = { sort: (params: DataPipelineParams<T>) => T[] | Promise<T[]> };
```
</PlatformBlock>
<PlatformBlock for="React">
```typescript
gridRef.current.dataPipelineConfiguration = { sort: (params: DataPipelineParams<T>) => T[] | Promise<T[]> };
```
</PlatformBlock>
</PlatformBlock>
