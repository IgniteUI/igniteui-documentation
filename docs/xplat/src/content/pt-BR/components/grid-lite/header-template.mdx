# Personalizando o cabeçalho da coluna

Assim como os templates de célula, os cabeçalhos das colunas também podem ser personalizados para se adequar melhor ao caso de uso desejado. Você pode passar um rótulo de texto pela propriedade `header` ou fornecer um template personalizado completo.

## Personalização pelo texto do cabeçalho

<PlatformBlock for="React, WebComponents">
Por padrão, a coluna usa a propriedade `field` para o texto do rótulo. Para personalizar o rótulo, defina a propriedade `header` com um formato mais legível para as pessoas.
</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-grid-lite-column field="price" header="Price per item"></igc-grid-lite-column>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
return (
  <IgrGridLite>
    <IgrGridLiteColumn field="price" header="Price per item"></IgrGridLiteColumn>
  </IgrGridLite>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">
Por padrão, a coluna usa a propriedade <ApiLink type="Column" member="field" label="Field" /> para o texto do rótulo. Para personalizar o rótulo, defina a propriedade <ApiLink type="Column" member="header" label="Header" /> com um formato mais legível para as pessoas.


```razor
<IgbGridLiteColumn Field="Price" Header="Price per item" />
```


</PlatformBlock>

<DocsAside type="info">
Quando `headerTemplate` é informado, `header` é ignorado.
</DocsAside>

## Personalização pelo template de cabeçalho

Assim como no template de célula, você também pode informar um renderizador de template personalizado e criar o seu próprio DOM dentro do cabeçalho da coluna.

<PlatformBlock for="WebComponents">


```typescript
import { html } from 'lit';


const column = document.querySelector('igc-grid-lite-column');
column.headerTemplate = () => html`<h3>⭐ Rating ⭐</h3>`;
```

</PlatformBlock>
<PlatformBlock for="React">


```tsx
const ratingHeaderTemplate = (ctx: IgrHeaderContext) => (
  <h3>{"⭐ Rating ⭐"}</h3>
);


return (
  <IgrGridLite>
    <IgrGridLiteColumn field="rating" headerTemplate={ratingHeaderTemplate}></IgrGridLiteColumn>
  </IgrGridLite>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">


```razor
<!-- Templates TBD in Blazor -->
<IgbGridLiteColumn Field="Rating"></IgbGridLiteColumn>
```

</PlatformBlock>
