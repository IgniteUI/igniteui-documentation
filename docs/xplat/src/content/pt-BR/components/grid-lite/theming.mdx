# Estilos e temas

O {GridLiteTitle} vem com quatro temas distintos: Bootstrap, Material, Fluent e Indigo. A grade e os seus componentes de UI já trazem os temas incorporados, mas o componente exige uma folha de estilos global para que as paletas, a tipografia e outras configurações globais funcionem.

## Carregando um tema base

<PlatformBlock for="Blazor">

Se o aplicativo também usar o pacote `IgniteUI.Blazor.Lite` ou `IgniteUI.Blazor`, mantenha a [folha de estilos de tema](../themes/overview.mdx) desse pacote. Ela também estiliza a grade, por isso o aplicativo não precisa das folhas de estilos abaixo.

Um aplicativo que usa apenas o {GridLiteTitle} vincula um dos temas que o pacote `IgniteUI.Blazor.GridLite` distribui, na página hospedeira: **Components/App.razor** em um Blazor Web App, ou **wwwroot/index.html** em um aplicativo Blazor WebAssembly independente.

```html
<link href="_content/IgniteUI.Blazor.GridLite/themes/light/bootstrap.css" rel="stylesheet" />
```

| Tema     | Variante | Caminho                                                       |
| --------- | ------- | ---------------------------------------------------------- |
| Bootstrap | Claro   | _content/IgniteUI.Blazor.GridLite/themes/light/bootstrap.css |
| Bootstrap | Escuro    | _content/IgniteUI.Blazor.GridLite/themes/dark/bootstrap.css  |
| Material  | Claro   | _content/IgniteUI.Blazor.GridLite/themes/light/material.css  |
| Material  | Escuro    | _content/IgniteUI.Blazor.GridLite/themes/dark/material.css   |
| Fluent    | Claro   | _content/IgniteUI.Blazor.GridLite/themes/light/fluent.css    |
| Fluent    | Escuro    | _content/IgniteUI.Blazor.GridLite/themes/dark/fluent.css     |
| Indigo    | Claro   | _content/IgniteUI.Blazor.GridLite/themes/light/indigo.css    |
| Indigo    | Escuro    | _content/IgniteUI.Blazor.GridLite/themes/dark/indigo.css     |

</PlatformBlock>

<PlatformBlock for="React, WebComponents">

Dependendo do tipo do seu projeto, da configuração e da configuração de build, o método para incluir um dos arquivos abaixo varia. Se você usa um framework/ferramenta de build, consulte a documentação dele para saber como adicionar estilos externos ao seu bundle de saída.

Como regra geral, você sempre pode copiar a pasta `themes` para o seu diretório de assets e vincular o tema a partir dele no seu index.html.

```html
<link rel="stylesheet" href="./assets/themes/light/bootstrap.css">
```

| Tema     | Variante | Caminho                                                           |
| --------- | ------- | -------------------------------------------------------------- |
| Bootstrap | Claro   | node_modules/igniteui-webcomponents/themes/light/bootstrap.css |
| Bootstrap | Escuro    | node_modules/igniteui-webcomponents/themes/dark/bootstrap.css  |
| Material  | Claro   | node_modules/igniteui-webcomponents/themes/light/material.css  |
| Material  | Escuro    | node_modules/igniteui-webcomponents/themes/dark/material.css   |
| Fluent    | Claro   | node_modules/igniteui-webcomponents/themes/light/fluent.css    |
| Fluent    | Escuro    | node_modules/igniteui-webcomponents/themes/dark/fluent.css     |
| Indigo    | Claro   | node_modules/igniteui-webcomponents/themes/light/indigo.css    |
| Indigo    | Escuro    | node_modules/igniteui-webcomponents/themes/dark/indigo.css     |

</PlatformBlock>

## Criando temas personalizados

Além dos temas padrão distribuídos com o pacote {GridLiteTitle}, você pode personalizar ainda mais a aparência da sua grade de dados usando um conjunto alternativo de propriedades personalizadas CSS.

```css
.grid-sample {
  --header-background: #494949;
  --header-text-color: #f2c43c;
  --cell-active-border-color: #f2c43c;
  --row-hover-background: #707070;
  --row-hover-text-color: #f2c43c;
}
```
