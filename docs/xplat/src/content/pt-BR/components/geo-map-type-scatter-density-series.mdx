# Mapa de alta densidade geográfico de {Platform}

No componente de mapa {Platform}, você pode usar o `GeographicHighDensityScatterSeries` para vincular e exibir dados de dispersão que vão de centenas a milhões de pontos de dados, exigindo pouquíssimo tempo de carregamento.

## {Platform} Exemplo de mapa de alta densidade geográfico


<Sample src="/maps/geo-map/type-scatter-density-series" height={400} alt="{Platform} Exemplo de uso da série de dispersão de alta densidade" />




A demonstração acima mostra a série `GeographicHighDensityScatterSeries` no componente de mapa vinculada a centenas ou até milhares de pontos de dados que representam a densidade populacional da Austrália. A área de plotagem do mapa, com os pontos de dados mais densamente povoados representados como aglomerações de pixels vermelhos, e os pontos de dados dispersos representados por pixels azuis separados.

Como há tantos pontos de dados, a série exibe os dados de dispersão como pontos minúsculos, e não como marcadores de tamanho normal, e exibe as áreas com mais dados usando uma densidade de cor maior, que representa um agrupamento de pontos de dados.

## Requisitos de dados
Assim como outros tipos de séries de dispersão no controle de mapa, a série `GeographicHighDensityScatterSeries` tem a propriedade `dataSource`, que pode ser vinculada a um array de objetos. Além disso, cada item de dados na fonte de itens deve ter duas colunas de dados que armazenam as coordenadas geográficas de longitude e latitude, e usa as propriedades `longitudeMemberPath` e `latitudeMemberPath` para mapear essas colunas de dados.

### Vinculação de dados
A tabela a seguir resume as propriedades da série GeographicHighDensityScatterSeries usadas na vinculação de dados.

| Propriedade|Tipo|Descrição |
| ---|---|--- |
| `dataSource`|qualquer|Obtém ou define a fonte de itens |
| `longitudeMemberPath`|string|Usa a propriedade DataSource para determinar a localização dos valores de longitude nos itens atribuídos |
| `latitudeMemberPath`|string|Usa a propriedade DataSource para determinar a localização dos valores de latitude nos itens atribuídos |

## Escala de cores de calor
A escala de cores de calor, um recurso opcional, determina o padrão de cores dentro da série. A tabela a seguir resume as propriedades usadas para determinar a escala de cores.

| Propriedade |Tipo|Descrição |
| ---|---|--- |
| `heatMinimum`|Double|Define o valor double que representa a extremidade mínima da escala de cores |
| `heatMaximum`|Double|Define o valor double que representa a extremidade máxima da escala de cores |
| `heatMinimumColor`|Color|Define a cor de densidade de pontos usada na extremidade inferior da escala de cores |
| `heatMaximumColor`|Color|Define a cor de densidade de pontos usada na extremidade superior da escala de cores |
