# {Platform} 縦向きチャート

{ProductName} の縦向きカテゴリ シリーズは、おなじみの折れ線、スプライン、ポイント、ステップ、エリア、ウォーターフォール チャートを横向きに倒して描画します。[棒チャート](bar-chart.mdx)と同じ配置で、カテゴリは `CategoryYAxis` に沿ってチャートの縦方向に並び、値は `NumericXAxis` に沿って横方向に並びます。各シリーズは、既に使用している可能性のある横向きシリーズに対応する縦向きのシリーズで、そのオプションを共有します。たとえば、`VerticalLineSeries` は `LineSeries` に、`VerticalAreaSeries` は `AreaSeries` に対応します。

## 縦向きチャートの推奨事項

### {Platform} 縦向きチャートはプロジェクトに適していますか?

カテゴリを左から右よりも上から下に読む方が読みやすい場合は、チャートを横向きに倒します。

- カテゴリが、水深、高度、建物の階数などの物理的な縦方向の次元である。
- アンケートの質問、製品機能、アカウント名など、カテゴリ ラベルが長い。縦方向に並べると、ラベルを回転させたり切り詰めたりせずに、軸の幅いっぱいを各ラベルに使用できます。
- 1 日の時間帯など、カテゴリが多く、チャートの横幅よりも縦幅に余裕がある。
- チャートを、行を揃えたい棒チャートまたは表の横に配置する。

### 縦向きチャートのユース ケース

- 水深や高度によって値が変化する、海洋、土壌、大気のプロファイル。
- カテゴリ名が長いアンケートやランキングの結果。
- 1 日の時間帯や 1 年の月など、上から下に読むタイムライン。
- ステップ名が長い利益ブリッジなどのウォーターフォール チャート。
- 棒の上に目標値や平均値を重ねて描画する棒チャート。

### 縦向きチャートを使用しない場合

- 株価など、カテゴリが左から右へ進むと読み手が想定する時系列である。横向きの[折れ線チャート](line-chart.mdx)または[エリア チャート](area-chart.mdx)を使用してください。
- 個別のカテゴリの大きさを比較する必要がある。[棒チャート](bar-chart.mdx)は各値を棒の長さで示すため、ポイントの位置よりも比較しやすくなります。

### 縦向きチャートのデータ構造

- データ ソースは、データ項目の配列またはリストである必要があります。
- 各項目には、`CategoryYAxis` 上の行のラベルとなる、文字列や日付などのカテゴリが必要です。
- 各シリーズは、`valueMemberPath` を通じて 1 つの数値フィールドを読み取ります。

## {Platform} 縦向きチャートの軸

縦向きシリーズは、カテゴリに `CategoryYAxis` を、値に `NumericXAxis` を使用します。カテゴリ軸をシリーズと同じデータにバインドし、`label` でカテゴリ フィールドを指定します。カテゴリ軸の `isInverted` を設定すると、カテゴリが上から下に並びます。設定しない場合は最初の項目が下になるため、高度には適しますが水深には適しません。

```json-snippet source="/charts/data-chart/vertical-line-chart"
{
    "descriptions": {
        "content": {
            "type": "DataChart",
            "name": "chart",
            "axes": [
                {
                    "type": "CategoryYAxis",
                    "name": "yAxis",
                    "label": "Depth",
                    "dataSourceRef": "OceanTemperatureByDepth",
                    "interval": 1,
                    "isInverted": true
                },
                {
                    "type": "NumericXAxis",
                    "name": "xAxis",
                    "title": "Temperature (°C)"
                }
            ],
            "series": [
                {
                    "type": "VerticalLineSeries",
                    "name": "VerticalLineSeries1",
                    "title": "Summer",
                    "xAxisRef": "xAxis",
                    "yAxisRef": "yAxis",
                    "dataSourceRef": "OceanTemperatureByDepth",
                    "valueMemberPath": "Summer",
                    "markerType": "Circle",
                    "thickness": 2
                }
            ]
        }
    }
}
```

## {Platform} 縦向き折れ線チャート

`VerticalLineSeries` は、[上記の例](#{PlatformLower}-vertical-chart-example)のように、隣り合うカテゴリの値を直線で結びます。`LineSeries` と同じマーカー、太さ、ブラシのオプションを使用できます。

## {Platform} 縦向きスプライン チャート

`VerticalSplineSeries` は、値を滑らかな曲線で結びます。次の例は、地面を下にして高度ごとの気温をプロットするため、カテゴリ軸は反転されません。

<Sample src="/charts/data-chart/vertical-spline-chart" height={600} alt="{Platform} Vertical Spline Chart" />

```json-snippet source="/charts/data-chart/vertical-spline-chart"
{
    "type": "DataChart",
    "series": [
        {
            "type": "VerticalSplineSeries",
            "$type": "+doc:markup",
            "title": "Standard Atmosphere",
            "valueMemberPath": "Standard",
            "markerType": "Circle",
            "$markerType": "+doc:markup"
        }
    ]
}
```

## {Platform} 縦向きポイント チャート

`VerticalPointSeries` は、値を結ばずに各値のマーカーを描画します。これは、次のアンケートの機能のように、順序のないカテゴリに適しています。2 つのポイント シリーズを並べると、2 組の結果を行ごとに比較できます。

<Sample src="/charts/data-chart/vertical-point-chart" height={600} alt="{Platform} Vertical Point Chart" />

## {Platform} 縦向きステップ折れ線チャート

`VerticalStepLineSeries` は、次のカテゴリまで各値を保持してから次の値へ段階的に移動します。これは、金利のように、決まった時点で変化し、その間は変わらない値に適しています。

<Sample src="/charts/data-chart/vertical-step-line-chart" height={600} alt="{Platform} Vertical Step Line Chart" />

## {Platform} 縦向きエリア チャート

`VerticalAreaSeries` は、線と値軸の間の領域を塗りつぶします。エリアが重なる場合は、背面のシリーズが見えるように `areaFillOpacity` を小さくします。

<Sample src="/charts/data-chart/vertical-area-chart" height={600} alt="{Platform} Vertical Area Chart" />

```json-snippet source="/charts/data-chart/vertical-area-chart"
{
    "type": "DataChart",
    "series": [
        {
            "type": "VerticalAreaSeries",
            "$type": "+doc:markup",
            "title": "1990",
            "valueMemberPath": "Year1990",
            "areaFillOpacity": 0.5,
            "$areaFillOpacity": "+doc:markup"
        }
    ]
}
```

## {Platform} 縦向きスプライン エリア チャート

`VerticalSplineAreaSeries` は、滑らかな曲線の下の領域を塗りつぶします。次の例は、上を午前 0 時として、1 日を通したウェブサイトの訪問数を示します。

<Sample src="/charts/data-chart/vertical-spline-area-chart" height={600} alt="{Platform} Vertical Spline Area Chart" />

## {Platform} 縦向きステップ エリア チャート

`VerticalStepAreaSeries` は、階段状の線の下の領域を塗りつぶすため、各カテゴリが 1 つの帯として表示されます。

<Sample src="/charts/data-chart/vertical-step-area-chart" height={600} alt="{Platform} Vertical Step Area Chart" />

## {Platform} 縦向きウォーターフォール チャート

`VerticalWaterfallSeries` は、各カテゴリを前の値から自身の値までの棒として描画するため、累計が増減の連続として読み取れます。各値は変化量ではなく、そのステップ後の累計です。前の値から下がる棒には、`negativeBrush` と `negativeOutline` が使用されます。

<Sample src="/charts/data-chart/vertical-waterfall-chart" height={600} alt="{Platform} Vertical Waterfall Chart" />

```json-snippet source="/charts/data-chart/vertical-waterfall-chart"
{
    "type": "DataChart",
    "series": [
        {
            "type": "VerticalWaterfallSeries",
            "$type": "+doc:markup",
            "valueMemberPath": "Total",
            "brush": "#2E7D32",
            "$brush": "+doc:markup",
            "outline": "#2E7D32",
            "$outline": "+doc:markup",
            "negativeBrush": "#C62828",
            "$negativeBrush": "+doc:markup",
            "negativeOutline": "#C62828",
            "$negativeOutline": "+doc:markup"
        }
    ]
}
```

## {Platform} 縦向きシリーズと棒シリーズの組み合わせ

縦向きシリーズは `BarSeries` と軸を共有するため、同じチャート内で棒の上に重ねて描画できます。次の例は、各地域の実績売上の `BarSeries` の上に、売上目標を `VerticalLineSeries` として描画します。

<Sample src="/charts/data-chart/vertical-chart-combined" height={600} alt="{Platform} Vertical Line Series over a Bar Series" />

```json-snippet source="/charts/data-chart/vertical-chart-combined"
{
    "type": "DataChart",
    "series": [
        {
            "type": "BarSeries",
            "$type": "+doc:markup",
            "title": "Actual",
            "valueMemberPath": "Actual"
        },
        {
            "type": "VerticalLineSeries",
            "$type": "+doc:markup",
            "title": "Target",
            "valueMemberPath": "Target",
            "markerType": "Diamond"
        }
    ]
}
```

## {Platform} 縦向きチャートのツールチップ

`DataToolTipLayer` を追加すると、カーソル位置のカテゴリを説明できます。既定では、ツールチップの末尾にシリーズの値の合計が表示されます。これは、デスクトップとモバイルの訪問数のようにシリーズが合算できる場合には便利ですが、夏と冬の気温のように別々の測定値である場合には不要です。これを表示しない場合は、`summaryType` を `None` に設定します。

```json-snippet source="/charts/data-chart/vertical-line-chart"
{
    "type": "DataChart",
    "series": [
        {
            "type": "DataToolTipLayer",
            "$type": "+doc:markup",
            "summaryType": "None",
            "$summaryType": "+doc:markup"
        }
    ]
}
```
