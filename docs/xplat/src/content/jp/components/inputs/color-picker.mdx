# Color Picker コンポーネント <Badge variant="new" />

{ProductName} Color Picker は、グラデーション キャンバス、色相と透明度のスライダー、フォーマットの切り替え、スポイト、定義済みのスウォッチを備えたインタラクティブなドロップダウンを通じて、ユーザーが色を選択および編集できるフォーム関連コンポーネントです。

## ライブ デモ

{Platform} Color Picker のデモは、現在選択されている色をプレビューし、別の色を編集または選択できるドロップダウンを開く `input` モードのアンカーを示します。

<strong>5. サフィックス コンテナー:</strong> アクション ボタンなどのサフィックス要素のコンテナー。<br />
<strong>6. ヒント:</strong> 入力型 Color Picker のヒント テキスト。<br /></span>

<span class="ig-typography__body-2" style="display: block; margin-bottom: 24px;"><strong>B - デフォルト Color Picker</strong><br /><br />
<strong>1. カラー アンカー:</strong> ピッカー ドロップダウンをトリガーします。<br />
<strong>2. フィル:</strong> 現在選択されている色を表示します。<br />
<strong>3. ラベル:</strong> Color Picker のラベル。<br />
<strong>4. ヒント:</strong> Color Picker のヒント テキスト。<br /></span>

<span class="ig-typography__body-2" style="display: block; margin-bottom: 24px;"><strong>C - Color Picker ドロップダウン</strong><br /><br />
<strong>1. Color Picker ドロップダウン:</strong> すべての色選択コントロールを含むポップオーバー。<br />
<strong>2. グラデーション キャンバス:</strong> ドラッグ可能なマーカーを持つ HSV の彩度/明度エリア。<br />
<strong>3. Color Picker マーカー:</strong> グラデーション キャンバス上で現在選択されている色を示すドラッグ可能なマーカー。<br />
<strong>4. 色相スライダー:</strong> 基本色用の範囲スライダー。<br />
<strong>5. 色相スライダー ハンドル:</strong> 色相スライダー上で現在選択されている色相を示すドラッグ可能なマーカー。<br />
<strong>6. コピー ボタン:</strong> 現在選択されている色をクリップボードにコピーします。<br />
<strong>7. スポイト ボタン:</strong> 画面から色を選択するためのスポイト ツールをアクティブにします。<br />
<strong>8. 透明度スライダー:</strong> `show-alpha` が設定されている場合に表示されるオプションの不透明度スライダー。<br />
<strong>9. 透明度スライダー ハンドル:</strong> 透明度スライダー上で現在選択されている透明度の値を示すドラッグ可能なマーカー。<br />
<strong>10. 不透明度の値:</strong> 透明度スライダー上で現在選択されている不透明度の値。<br />
<strong>11. フォーマット スイッチャー:</strong> 色のフォーマット (`hex`、`rgb`、`hsl`) を選択するためのドロップダウン。<br />
<strong>12. 色の値:</strong> 選択されたフォーマット (`hex`、`rgb`、`hsl`) に従って表示される現在選択されている色の値。<br />
<strong>13. スウォッチ:</strong> 定義済みの色のスウォッチのオプションのグリッド。<br /></span>

### 検証

色が選択されていない場合にフォームの検証を失敗させるには、コントロールを <ApiLink pkg="core" type="ColorPicker" member="required" label="required" /> としてマークします。このコンポーネントは、標準のフォーム関連 API (<ApiLink pkg="core" type="ColorPicker" member="checkValidity" label="checkValidity" />、<ApiLink pkg="core" type="ColorPicker" member="reportValidity" label="reportValidity" />、<ApiLink pkg="core" type="ColorPicker" member="setCustomValidity" label="setCustomValidity" />) をサポートします。

以下のスロットを使用して、アンカーの下にヘルパーと検証メッセージを表示します。

- `helper-text` – アンカーの下にヒントまたは説明メッセージを表示します。
- `value-missing` – 必須フィールドの検証が失敗した場合にカスタム コンテンツをレンダリングします。
- `invalid` – コンポーネントが無効な状態のときにカスタム コンテンツをレンダリングします。
- `custom-error` – <ApiLink pkg="core" type="ColorPicker" member="setCustomValidity" label="setCustomValidity()" /> を使用してカスタム検証メッセージが設定されている場合にコンテンツを表示します。

```html

  <span slot="value-missing">A color is required.</span>
</igc-color-picker>
```

</PlatformBlock>

## Angular フォームでの Color Picker の使用

Angular フォームで Color Picker Web コンポーネントを使用し、`formControlName` または `ngModel` でバインドするには、Angular は `ControlValueAccessor` インターフェイスの実装を必要とします。{ProductName} は、対応する Web コンポーネントに要素セレクターでアタッチする `IgcFormControlDirective` としてこれを提供します。バージョン 22.2.0 以降、`igc-rating` に加えて `igc-color-picker` もサポートされます。

`IgcFormControlDirective` を `ReactiveFormsModule` (または `ngModel` でバインドする場合は `FormsModule`) と一緒にインポートします。

```ts
import { ReactiveFormsModule } from '@angular/forms';
import { IgcFormControlDirective } from 'igniteui-angular/directives';
// import { IgcFormControlDirective } from '@infragistics/igniteui-angular/directives'; for licensed package

@Component({
    imports: [ReactiveFormsModule, IgcFormControlDirective],
    schemas: [CUSTOM_ELEMENTS_SCHEMA]
})

export class LabelFormComponent {...}
```

次に、`formControlName` を使用して Color Picker を `FormControl` にバインドします。コントロールはアクティブな `format` で色を受け取り、フォーカスが異なる色で Color Picker から離れると更新されます。

```html
<form [formGroup]="labelForm">
  <igc-color-picker formControlName="color" label="Label color" required></igc-color-picker>
</form>
```

<DocsAside type="info">
このディレクティブは値のバインドのみを処理します。`[swatches]="swatches"` など、他の Color Picker プロパティに Angular プロパティ バインディングを使用する場合は、`CUSTOM_ELEMENTS_SCHEMA` を維持してください。
</DocsAside>

## アクセシビリティ

{Platform} Color Picker は、キーボードで操作可能なフォーム関連コントロールです。アンカーはラベル付きボタン (デフォルト モード) または編集可能な入力 (入力モード) であり、開いたピッカーはフォーカスをトラップします。

### キーボード操作

以下のキー バインディングは、コンポーネントが `disabled` の間はスキップされます。

| キー | アクション |
| -- | -- |
| `Alt` + `ArrowDown` | ピッカー ドロップダウンを切り替えます。 |
| `Alt` + `ArrowUp` | ピッカー ドロップダウンを閉じ、フォーカスをアンカーに戻します。 |
| `Escape` | ピッカー ドロップダウンを閉じ、フォーカスをアンカーに戻します。 |
| 矢印キー | グラデーション キャンバスのマーカーにフォーカスがある場合、押された方向に 1 ステップずつマーカーを移動します。 |
| `ArrowUp` / `ArrowDown` | 透明度の入力にフォーカスがある場合、不透明度を 1% 増減します。 |
| `Tab` | 開いたピッカー内のインタラクティブな要素間でフォーカスを移動します。 |

### スクリーン リーダー / ARIA

- アンカーは `aria-haspopup="dialog"` と `aria-expanded` を設定し、`aria-describedby` を通じてヘルパー テキスト コンテナーを参照するため、ヘルパーと検証メッセージがアナウンスされます。
- ピッカー ドロップダウンには `role="dialog"` とアクセシブルな名前 `Color picker` があります。
- グラデーション キャンバスのマーカーには `role="slider"` があり、`aria-valuetext` を通じて両方の軸をアナウンスします (例: `Saturation 50%, brightness 80%`)。
- 色相と透明度のスライダーは、`aria-label` (`Hue`、`Alpha slider`) でラベル付けされたネイティブの `input[type="range"]` 要素です。
- フォーマット スイッチャーと色の値の入力には視覚的に非表示のラベルが付いており、コピーとスポイトのボタンには視覚的に非表示のテキストが公開されています。
- 各スウォッチ ボタンは `aria-label` を通じてその色を公開します。
- ピッカーが開いている間、フォーカスはその中にトラップされます。閉じている間、ピッカーのコンテンツは `inert` であり、タブ順序から除外されます。

## トラブルシューティング

{Platform} Color Picker のトラブルシューティング ガイダンスは、一般的な統合およびプラットフォームの問題について、問題 → 原因 → 修正の形式に従います。

### 色の値がクリアされたり元に戻ったりするのはなぜですか?

空、空白のみ、または無効な文字列を `value` に割り当てると、前の値を保持する代わりに色がクリアされます。色の入力に入力された無効な文字列は、代わりに現在の色に戻ります。有効な CSS カラー文字列を割り当て、環境が `OffscreenCanvas` をサポートしていることを確認してください (既知の制限を参照)。

### 発生する値が入力したものと異なるフォーマットになるのはなぜですか?

値は常にアクティブな `format` でシリアル化されるため、入力文字列はバイト単位でラウンドトリップしません。たとえば、`format="hex"` で `red` と入力すると `#ff0000` が生成されます。読み戻すことが予想される表記法に `format` を設定してください。

### 色を入力しても `igcInput` が発生しないのはなぜですか?

色の入力は、すべてのキーストロークではなく、変更されたときに入力された色をコミットするため、入力された色は `igcInput` を発生させません。フォーカスが異なる色でコンポーネントから離れたときに発生する `igcChange` をリッスンしてください。

### 既知の制限事項

- スポイト ボタンは、[`EyeDropper`](https://developer.mozilla.org/en-US/docs/Web/API/EyeDropper) API を実装しているブラウザーでのみ有効になります。サポートは、コンポーネントが作成されたときに一度検出されます。
- クリップボードへのコピーは `navigator.clipboard` と安全なコンテキスト (HTTPS または `localhost`) に依存します。API が利用できない場所や権限が拒否された場所では、何も実行されません。
- このコンポーネントは、すべての色の文字列を `OffscreenCanvas` の 2D コンテキストを通じて解析します。`OffscreenCanvas` が利用できない場合、すべての値は空になります。
- `Hue`、`Alpha slider`、`Open color picker`、`Copy color value to clipboard` などの組み込みのアクセシブルなラベルは英語のみで、ローカライズされていません。
