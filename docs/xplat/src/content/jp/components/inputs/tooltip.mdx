# Tooltip (ツールチップ)

{ProductName} Tooltip は、ユーザーが要素を操作している間 (たとえば要素にマウスを置いている間)、その要素に関する補足情報を要素の横の小さなポップアップに表示するコンポーネントです。

<PlatformBlock for="Angular">

Angular Tooltip は 1 組のディレクティブです。`igxTooltip` ディレクティブは情報を保持する要素に指定し、`igxTooltipTarget` ディレクティブはツールチップが説明する要素に指定します。ユーザーがその要素にマウスを置くと、ツールチップが表示されます。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Tooltip は `anchor` プロパティでアンカー要素に添付され、内部に配置したテキストまたはコンテンツを表示し、アンカーの横に自身を配置します。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

`igc-tooltip` 要素は、コンテンツ、閉じるボタン、矢印のコンテナーを持つポップオーバーをレンダリングします。

```text
igc-tooltip                                   // role="tooltip", or role="status" when sticky
└─ #shadow-root
   └─ igc-popover                             // positions the tooltip next to the anchor
      └─ div[part="base"]                     // part="base simple-text" when the message property is shown
         ├─ slot                              // the content of the tooltip, falls back to the message property
         ├─ slot[name="close-button"]         // rendered only when the tooltip is sticky
         └─ div#arrow[part="bottom"]          // rendered only with the arrow, the part follows the placement
```

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Tooltip が開いている間、オーバーレイは `igxTooltip` ディレクティブを持つ要素を、DOM 内の元の位置にあるラッパーに移動し、ページの最前面レイヤーに配置します。

```text
div.igx-overlay__wrapper[popover="manual"]
└─ div.igx-overlay__content
   └─ [igxTooltip].igx-tooltip                // role="tooltip", or role="status" when sticky
      ├─ your content
      ├─ span.igx-tooltip--bottom[data-arrow] // hidden unless hasArrow is set, the class follows the placement
      └─ igx-tooltip-close-button             // rendered only when the tooltip is sticky
```

ツールチップが閉じている間、要素は `igx-tooltip--hidden` クラスと `aria-hidden="true"` を持ったまま元の位置に残ります。

</PlatformBlock>

## 使用方法

{Platform} Tooltip は、別のコンポーネントやその目的を説明する追加情報を、ユーザー インターフェイス上に一時的に表示するために使用します。ユーザーの操作によって表示され、一定時間後またはユーザーの操作によって非表示になる場合があります。

### バリエーション

表示する要素に応じて、Tooltip には次のタイプがあります。

- 矢印あり、閉じるボタンなしの Tooltip
- 矢印あり、閉じるボタンありの Tooltip
- 矢印なし、閉じるボタンなしの Tooltip
- 矢印なし、閉じるボタンありの Tooltip

<PlatformBlock for="React,WebComponents,Blazor">

矢印を表示するには、<ApiLink pkg="core" type="Tooltip" member="withArrow" label="withArrow" /> を設定します。閉じるボタンを表示するには、<ApiLink pkg="core" type="Tooltip" member="sticky" label="sticky" /> を設定します。スティッキー ツールチップは、ポインターがアンカーから離れるなどの非表示トリガーを無視し、ユーザーが閉じるボタンをクリックするか Escape キーを押すまで開いたままになります。

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-tooltip anchor="arrow-target" with-arrow>Tooltip message</igc-tooltip>
<igc-tooltip anchor="sticky-target" with-arrow sticky>Tooltip message</igc-tooltip>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrTooltip anchor="arrow-target" withArrow={true}>Tooltip message</IgrTooltip>
<IgrTooltip anchor="sticky-target" withArrow={true} sticky={true}>Tooltip message</IgrTooltip>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

<IgbTooltip Anchor="sticky-target" WithArrow="true" Sticky="true">Tooltip message</IgbTooltip>
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

既定の閉じるボタンを置き換えるには、`close-button` スロットに独自の要素を配置します。スロット内のどこをクリックしてもツールチップが閉じるため、ネイティブの `button` を使用すると、キーボード ユーザーも閉じる操作を行えます。

</PlatformBlock>

```html
    Tooltip message
    <button slot="close-button" type="button" aria-label="Close">Got it</button>
```

</PlatformBlock>

<PlatformBlock for="Angular">

矢印を表示するには、ターゲットに <ApiLink type="TooltipTargetDirective" member="hasArrow" label="hasArrow" /> を設定します。閉じるボタンを表示するには、<ApiLink type="TooltipTargetDirective" member="sticky" label="sticky" /> を設定します。スティッキー ツールチップは、ポインターがターゲットから離れるなどの非表示トリガーを無視し、ユーザーが閉じるボタンをクリックするか Escape キーを押すまで開いたままになります。閉じるボタンのアイコンを置き換えるには、<ApiLink type="TooltipTargetDirective" member="closeTemplate" label="closeButtonTemplate" /> にテンプレートを渡します。このテンプレートは、ツールチップがスティッキーの間のみレンダリングされます。

### 位置

ターゲットに対する位置に応じて、Tooltip には次のタイプがあります。

- 上: Tooltip はターゲットの上に表示されます。
- 右: Tooltip はターゲットの右に表示されます。
- 左: Tooltip はターゲットの左に表示されます。
- 下: Tooltip はターゲットの下に表示されます。

<PlatformBlock for="React,WebComponents,Blazor">

ツールチップの位置を指定するには、<ApiLink pkg="core" type="Tooltip" member="placement" label="placement" /> を設定します。既定値は `bottom` です。`top`、`right`、`bottom`、`left` の各値には、ツールチップをアンカーの開始位置または終了位置に揃える `-start` と `-end` のバリエーションもあります。ツールチップが選択した側に収まらない場合は、反対側に反転します。ツールチップとアンカーの間の距離を変更するには、<ApiLink pkg="core" type="Tooltip" member="offset" label="offset" /> を設定します。既定値は `6` ピクセルです。

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-tooltip anchor="target" placement="top">Tooltip message Top</igc-tooltip>
<igc-tooltip anchor="target" placement="right-start" offset="12">Tooltip message Right</igc-tooltip>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrTooltip anchor="target" placement="top">Tooltip message Top</IgrTooltip>
```

</PlatformBlock>

```ts
    horizontalStartPoint: HorizontalAlignment.Center,
    verticalDirection: VerticalAlignment.Top,
    verticalStartPoint: VerticalAlignment.Top
};
```

### 矢印の位置

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Tooltip の矢印は `placement` に従います。`top`、`right`、`bottom`、`left` では、矢印はアンカーの中央を指します。`-start` と `-end` の配置では、矢印はツールチップの開始側または終了側に移動します。ツールチップが反対側に反転すると、矢印も一緒に移動します。

</PlatformBlock>

</PlatformBlock>

```tsx

  This is a tooltip message. This tooltip shows a long message.
</IgrTooltip>
```

</PlatformBlock>

<PlatformBlock for="Blazor">


<PlatformBlock for="Angular">

Angular Tooltip は、ターゲットの `positionSettings` から矢印の位置を決定します。矢印は、次の定義済みの位置のいずれかに一致します。表には、各位置の `horizontalDirection`、`horizontalStartPoint`、`verticalDirection`、`verticalStartPoint` の値を示します。設定がいずれにも一致しない場合、矢印は既定の `bottom` 位置と同様に、ツールチップの上部中央に配置されます。

| 位置 | 水平 | 水平の開始点 | 垂直 | 垂直の開始点 |
| --- | --- | --- | --- | --- |
| top | `Center` | `Center` | `Top` | `Top` |
| top-start | `Right` | `Left` | `Top` | `Top` |
| top-end | `Left` | `Right` | `Top` | `Top` |
| bottom | `Center` | `Center` | `Bottom` | `Bottom` |
| bottom-start | `Right` | `Left` | `Bottom` | `Bottom` |
| bottom-end | `Left` | `Right` | `Bottom` | `Bottom` |
| right | `Right` | `Right` | `Middle` | `Middle` |
| right-start | `Right` | `Right` | `Bottom` | `Top` |
| right-end | `Right` | `Right` | `Top` | `Bottom` |
| left | `Left` | `Left` | `Middle` | `Middle` |
| left-start | `Left` | `Left` | `Bottom` | `Top` |
| left-end | `Left` | `Left` | `Top` | `Bottom` |

水平の値は `HorizontalAlignment` から、垂直の値は `VerticalAlignment` から取得されます。矢印は <ApiLink type="TooltipPositionStrategy" /> でのみ動作するため、`overlaySettings` で渡す `positionStrategy` はこれを継承する必要があります。矢印を独自に配置するには、`TooltipPositionStrategy` を継承して `positionArrow` メソッドをオーバーライドします。このメソッドは、矢印要素と、矢印の方向および矢印とツールチップのサイズを持つ `ArrowFit` オブジェクトを受け取ります。

```ts
import { ArrowFit, TooltipPositionStrategy } from 'igniteui-angular/directives';
import { HorizontalAlignment, OverlaySettings, PositionSettings, VerticalAlignment } from 'igniteui-angular/core';

export class CustomArrowStrategy extends TooltipPositionStrategy {
    constructor(settings?: PositionSettings) {
        super(settings);
    }

    public override positionArrow(arrow: HTMLElement, arrowFit: ArrowFit): void {
        Object.assign(arrow.style, {
            left: '-0.25rem',
            transform: 'rotate(-45deg)',
            [arrowFit.direction!]: '-0.25rem'
        });
    }
}

public overlaySettings: OverlaySettings = {
    positionStrategy: new CustomArrowStrategy({
        horizontalDirection: HorizontalAlignment.Right,
        horizontalStartPoint: HorizontalAlignment.Right,
        verticalDirection: VerticalAlignment.Bottom,
        verticalStartPoint: VerticalAlignment.Bottom
    })
};
```

```html
<igx-icon [igxTooltipTarget]="customTooltip" [hasArrow]="true" [overlaySettings]="overlaySettings">info</igx-icon>
<span #customTooltip="tooltip" igxTooltip>Tooltip message</span>
```

### コードでの表示と非表示

<PlatformBlock for="React,WebComponents">

次のメソッドで {Platform} Tooltip を表示および非表示にします。これらのメソッドは遅延を無視し、開く際と閉じる際のイベントを発行しません。

- <ApiLink pkg="core" type="Tooltip" member="show" label="show" /> はツールチップを表示します。要素または要素の `id` を渡すと、ツールチップが非表示になるまで、`anchor` の代わりにその要素の横にツールチップを表示します。
- <ApiLink pkg="core" type="Tooltip" member="hide" label="hide" /> はツールチップを非表示にします。
- <ApiLink pkg="core" type="Tooltip" member="toggle" label="toggle" /> は、ツールチップが非表示の場合は表示し、表示されている場合は非表示にします。

各メソッドは、ツールチップの状態が変わると `true` に解決される Promise を返します。<ApiLink pkg="core" type="Tooltip" member="open" label="open" /> プロパティでもツールチップを表示および非表示にできます。

</PlatformBlock>

<PlatformBlock for="Blazor">

次のメソッドで Blazor Tooltip を表示および非表示にします。これらのメソッドは遅延を無視し、開く際と閉じる際のイベントを発生させません。

- <ApiLink pkg="core" type="Tooltip" member="ShowAsync" label="ShowAsync" /> はツールチップを表示します。要素の `id` を渡すと、ツールチップが非表示になるまで、`Anchor` の代わりにその要素の横にツールチップを表示します。
- <ApiLink pkg="core" type="Tooltip" member="HideAsync" label="HideAsync" /> はツールチップを非表示にします。
- <ApiLink pkg="core" type="Tooltip" member="ToggleAsync" label="ToggleAsync" /> は、ツールチップが非表示の場合は表示し、表示されている場合は非表示にします。

各メソッドは、ツールチップの状態が変わると `true` を返します。<ApiLink pkg="core" type="Tooltip" member="Open" label="Open" /> パラメーターでもツールチップを表示および非表示にできます。

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html

<igc-button id="copy-button" variant="flat">Copy</igc-button>
```

```ts
  document.getElementById(id)!.addEventListener('pointerenter', (event) => {
    tooltip.show(event.currentTarget as Element);
  });
  document.getElementById(id)!.addEventListener('pointerleave', () => tooltip.hide());
}
```

ユーザーがトリガーまたは閉じるボタンでツールチップを表示または非表示にすると、{Platform} Tooltip は、表示する前に opening イベントを、アニメーションの終了後に opened イベントを、非表示にする際に closing イベントと closed イベントを発行します。opening イベントまたは closing イベントをキャンセルすると、ツールチップは現在の状態のままになります。Escape キーは closed イベントのみを発行します。

<ApiLink pkg="core" type="Tooltip" member="Opening" label="Opening" /> コールバックと <ApiLink pkg="core" type="Tooltip" member="Closing" label="Closing" /> コールバックは、ブラウザーが処理した後に実行されるため、イベントをキャンセルできません。キャンセルするには、`OpeningScript` または `ClosingScript` に、`igRegisterScript` で登録した JavaScript 関数の名前を設定します。closing イベントについては [Dialog](../notifications/dialog.mdx) トピックで説明しています。`_content/IgniteUI.Blazor/app.bundle.js` スクリプトが `igRegisterScript` を定義するため、他の用途で必要ないアプリでも、関数を登録するスクリプトより前にホスト ページで参照してください。

</PlatformBlock>

- <ApiLink type="TooltipTargetDirective" member="showTooltip" label="showTooltip" /> はターゲットの横にツールチップを表示し、<ApiLink type="TooltipTargetDirective" member="tooltipShow" label="tooltipShow" /> を発行します。
- <ApiLink type="TooltipTargetDirective" member="hideTooltip" label="hideTooltip" /> はツールチップを非表示にします。


`igxTooltipTarget` ディレクティブは `tooltipTarget` としてエクスポートされます。<ApiLink type="TooltipTargetDirective" member="tooltipHidden" label="tooltipHidden" /> プロパティは、ツールチップが非表示かどうかを返します。ツールチップを無効にするには、<ApiLink type="TooltipTargetDirective" member="tooltipDisabled" label="tooltipDisabled" /> を設定します。トリガーと `showTooltip` はツールチップを表示しなくなりますが、`hideTooltip` は引き続きツールチップを非表示にします。

ターゲットは、表示の遅延が始まる前に <ApiLink type="TooltipTargetDirective" member="tooltipShow" label="tooltipShow" /> を、ツールチップが閉じ始めるときに <ApiLink type="TooltipTargetDirective" member="tooltipHide" label="tooltipHide" /> を発行します。ハンドラーで `cancel` を `true` に設定すると、ツールチップは現在の状態のままになります。


```ts
}
```

### オーバーレイの構成

Angular Tooltip は[オーバーレイ サービス](../overlay.mdx)を通じて開きます。ターゲットの <ApiLink type="TooltipTargetDirective" member="positionSettings" label="positionSettings" /> は、位置のほかに、開く際と閉じる際のアニメーションおよび `offset` を設定します。ターゲットの <ApiLink type="TooltipTargetDirective" member="overlaySettings" label="overlaySettings" /> は、スクロール ストラテジや Escape キーで閉じる動作など、その他のオーバーレイ設定を変更します。渡した設定は、ツールチップの既定値を上書きします。

```ts
import { useAnimation } from '@angular/animations';
import { slideInTop, slideOutBottom } from 'igniteui-angular/animations';
import { CloseScrollStrategy, HorizontalAlignment, OverlaySettings, PositionSettings, VerticalAlignment } from 'igniteui-angular/core';

public positionSettings: PositionSettings = {
    horizontalDirection: HorizontalAlignment.Center,
    horizontalStartPoint: HorizontalAlignment.Center,
    verticalDirection: VerticalAlignment.Top,
    verticalStartPoint: VerticalAlignment.Top,
    openAnimation: useAnimation(slideInTop, { params: { duration: '300ms' } }),
    closeAnimation: useAnimation(slideOutBottom, { params: { duration: '300ms' } }),
    offset: 10
};

public overlaySettings: OverlaySettings = {
    scrollStrategy: new CloseScrollStrategy(),
    closeOnEscape: false
};
```

```html

```

既定では、ツールチップは、ページのスクロール中もターゲットの横に維持する `AbsoluteScrollStrategy` を使用し、Escape キーで閉じます。

</PlatformBlock>

### 推奨と非推奨

要素の Tooltip を表示する場合は、適切な配置が重要です。Tooltip は、説明する要素の近くに、インターフェイスを妨げたりユーザーの気を散らしたりすることなく表示する必要があります。位置は、最大限の視認性を確保し、画面内に完全に収まるようにします。既定では、Tooltip は要素のすぐ下に中央揃えで表示されます。ただし、この配置で一部が切れてしまう場合は、Tooltip 全体が表示されるように位置を変更する必要があります。Tooltip は、重要な情報を伝えるために使用しないでください。

<DoDont
  doSrc={tooltipDoPosition}
  doAlt="日付入力を覆わずに、その入力を説明する下部のツールチップ"
  dontSrc={tooltipDoNotPosition}
  dontAlt="説明対象の日付入力のラベルを覆っているツールチップ"
>
<Fragment slot="do">

Tooltip は説明する要素の近くに配置し、必要に応じて位置を変更して、メッセージ全体が画面内に表示されるようにします。

</Fragment>
<Fragment slot="dont">

Tooltip が画面外で切れる位置、主要な UI を隠す位置、説明対象の項目を覆う位置に配置しないでください。

</Fragment>
</DoDont>

### Sass テーマ

プライマリ プロパティを変更すると、関連するすべての依存プロパティが自動的に更新されて変更が反映されます。<PlatformBlock for="Angular"><ApiLink kind="sass" module="themes" type="function-tooltip-theme" label="tooltip-theme" code={true} /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">`tooltip-theme`</PlatformBlock> 関数のプライマリ パラメーターは `$background` で、テーマはこれからテキストの色を導出します。この関数でテーマを作成し、`tokens()` ミックスインでインクルードします。これにより、インクルードしたスコープに対応する `--ig-tooltip-*` 変数が出力されます。

```scss
}
```

## アクセシビリティ

{Platform} Tooltip はアンカーを説明するものであり、それ自体はフォーカスを受け取りません。このセクションでは、ツールチップがレンダリングして処理する内容を、そのテンプレートとイベント ハンドラーの定義に従って示します。

### キーボード操作

<PlatformBlock for="React,WebComponents">

{Platform} Tooltip は、アンカーで表示および非表示のトリガーを待ち受けます。`igniteui-webcomponents` 7.3.0 以降では、既定のトリガーに `focusin` と `focusout` が含まれるため、ボタンや入力など、アンカーがフォーカス可能な場合は次のキーが機能します。

| キー | 操作 |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | フォーカスがアンカーに移動すると、`showDelay` の後にツールチップが表示されます。フォーカスがアンカーから移動すると、ツールチップがスティッキーでない限り、`hideDelay` の後に非表示になります。 |
| <kbd>Escape</kbd> | ツールチップが表示されている間、ウィンドウの `keydown` リスナーが、フォーカスの位置に関係なく、最後に開いたツールチップを非表示にします。ツールチップがスティッキーの場合も同様です。ツールチップは closed イベントのみを発行するため、この閉じる操作はキャンセルできません。 |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | アンカーでは、`click` が既定の非表示トリガーであるため、アンカーが発行する `click` でツールチップが非表示になります。スティッキー ツールチップの既定の閉じるボタンでは、遅延なしでツールチップが非表示になります。 |

スティッキー ツールチップの既定の閉じるボタンは `igc-tooltip` 要素のシャドウ ルート内のネイティブの `button` であるため、その要素の DOM 内の位置でタブ順に含まれます。たとえば、ツールチップがアンカーの直後にある場合は、アンカーの直後になります。

</PlatformBlock>

<PlatformBlock for="Blazor">

Blazor Tooltip は、アンカーに設定した表示および非表示のトリガーを待ち受けます。次のキーが機能します。

| キー | 操作 |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | [トリガー](#トリガー)で説明するように、トリガーに `focusin` と `focusout` が含まれる場合に、ツールチップを表示および非表示にします。 |
| <kbd>Escape</kbd> | ツールチップが表示されている間、ウィンドウの `keydown` リスナーが、フォーカスの位置に関係なく、最後に開いたツールチップを非表示にします。ツールチップがスティッキーの場合も同様です。ツールチップは closed イベントのみを発生させるため、この閉じる操作はキャンセルできません。 |

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Tooltip は、次のポインター操作も処理します。

- ツールチップが表示されている間、ツールチップ自体で `pointerenter` と `pointerleave` を待ち受けます。ポインターがツールチップ上にあるとツールチップは開いたままになり、ポインターがツールチップから離れると、ツールチップがスティッキーでない限り、`hideDelay` の後に非表示になります。
- 表示の遅延が終了する前にアンカーをクリックすると、`click` が表示トリガーでない限り、表示がキャンセルされます。
- `close-button` スロット内のどこをクリックしても、スティッキー ツールチップが非表示になります。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Tooltip は、ターゲットで表示および非表示のトリガーを待ち受けます。既定のトリガーは `pointerenter`、`pointerleave`、`click` であるため、[トリガー](#トリガー)で説明するように `focusin` と `focusout` を追加するまで、ツールチップはキーボード フォーカスでは表示されません。次のキーが機能します。

| キー | 操作 |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | `focusin` と `focusout` のトリガーを使用している場合、フォーカスがターゲットに移動すると `showDelay` の後にツールチップが表示され、フォーカスが移動すると、ツールチップがスティッキーでない限り、180 ミリ秒に `hideDelay` を加えた後に非表示になります。 |
| <kbd>Escape</kbd> | ツールチップを閉じ、キャンセル可能な `tooltipHide` を発行します。オーバーレイ サービスはドキュメント全体で Escape キーを待ち受けるため、フォーカスの位置に関係なくキーが機能し、最前面で開いているオーバーレイのみを閉じます。 |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | ボタンなど、`click` を発行するターゲットでは、`click` が既定の非表示トリガーであるため、クリックでツールチップが非表示になります。 |

スティッキー ツールチップの閉じるボタン `igx-tooltip-close-button` はクリックのみを処理します。`tabindex` もロールもないため、キーボード ユーザーは Escape キーでスティッキー ツールチップを閉じます。

Angular Tooltip は、次のポインター操作も処理します。

- ツールチップ自体で `pointerenter` と `pointerleave` を待ち受けます。ポインターがツールチップ上にあるとツールチップは開いたままになり、ポインターがツールチップから離れると、ツールチップがスティッキーでない限り、遅延の後に非表示になります。
- 表示の遅延が終了する前にポインターがターゲットから離れると、ツールチップは表示されません。
- 表示の遅延が終了する前にターゲットをクリックすると、`click` が表示トリガーでない限り、表示がキャンセルされます。
- 閉じるボタンをクリックすると、`hideDelay` の後にスティッキー ツールチップが非表示になります。

</PlatformBlock>

### スクリーン リーダー / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Tooltip は、次のロールと属性をレンダリングします。

| 要素 | ロール | 属性 |
| --- | --- | --- |
| `igc-tooltip` | `tooltip`、スティッキーの間は `status` | `ElementInternals` で設定される `aria-live="polite"` と `aria-atomic="true"`。表示または非表示のアニメーションの再生中は `inert`。 |
| `igc-popover` | — | ツールチップが非表示の間は `inert`。そのコンテナーは、ページの最前面レイヤーで `popover="manual"` 要素として開きます。 |
| 既定の閉じるアイコン | — | `aria-hidden="true"`。 |<PlatformBlock for="React,WebComponents">
| アンカー | — | `igniteui-webcomponents` 7.3.0 以降での、ツールチップの `id` を持つ `aria-describedby`。ツールチップに `id` がない場合は `igc-tooltip-1` などの `id` を生成し、アンカーが既に持つ参照に追加し、アンカーの説明をやめると削除します。 |
| `button[part="close-button"]` | `button` | `igniteui-webcomponents` 7.3.0 以降での、`type="button"` と `aria-label="Close"`。 |</PlatformBlock>

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

{Platform} Tooltip は、支援技術に次の情報を公開します。

- アンカーの `aria-describedby` により、ツールチップのコンテンツがアンカーのアクセシブルな説明になります。ツールチップは表示されている間のみコンテンツをレンダリングするため、説明にコンテンツが含まれるのはツールチップが開いている間のみです。
- スティッキー ツールチップのアンカーの説明には、既定の閉じるボタンの名前である "Close" も含まれます。
- ツールチップが非表示の間も、`igc-tooltip` 要素はロールを持ったままアクセシビリティ ツリーに残り、そのコンテンツはレンダリングされません。
- スティッキー ツールチップは、ライブ リージョンである `status` ロールを持ちます。`aria-live="polite"` と `aria-atomic="true"` により、コンテンツが変更されると、支援技術がコンテンツ全体を通知します。

</PlatformBlock>

<PlatformBlock for="Blazor">

Blazor Tooltip は、支援技術に次の情報を公開します。

- ツールチップは `tooltip` ロールを持ち、スティッキーの間は、`aria-live="polite"` と `aria-atomic="true"` を持つライブ リージョンである `status` ロールを持ちます。
- ツールチップが非表示の間も、`igc-tooltip` 要素はロールを持ったままアクセシビリティ ツリーに残り、そのコンテンツはレンダリングされません。
- ツールチップをアンカーの説明にするには、ツールチップに `id` を設定し、アンカーの `aria-describedby` をその `id` に設定します。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Tooltip は、次のロールと属性をレンダリングします。

| 要素 | ロール | 属性 |
| --- | --- | --- |
| `[igxTooltip]` | `tooltip`、スティッキーの間は `status` | `id`。設定しない場合は `igx-tooltip-0` 以降。ツールチップが閉じている間は `aria-hidden="true"` と `igx-tooltip--hidden` クラス。 |
| `igx-tooltip-close-button` | — | ロールも `tabindex` もありません。既定の `igx-icon` は `aria-hidden="true"` を持ちます。 |
| `[igxTooltipTarget]` | — | ARIA 属性はありません。 |

ターゲットの `tooltip` 入力が作成するプレーン テキストのツールチップは、同じ属性を持つ `span[igxTooltip]` をレンダリングします。

Angular Tooltip は、支援技術に次の情報を公開します。

- ツールチップは `tooltip` ロールを持ちます。スティッキーの間は、ターゲットがライブ リージョンである `status` ロールを設定します。
- ツールチップが閉じている間は、`aria-hidden="true"` と `igx-tooltip--hidden` クラスにより、アクセシビリティ ツリーから除外されます。
- 閉じるボタンにはロールもアクセシブルな名前もないため、支援技術はこれをボタンとして公開しません。
- ターゲットはツールチップを参照しません。ツールチップをターゲットのアクセシブルな説明にするには、ターゲットの `aria-describedby` をツールチップの `id` に設定します。

```html
<button igxButton="outlined" [igxTooltipTarget]="saveTooltip" aria-describedby="save-tooltip">Save</button>
<span #saveTooltip="tooltip" igxTooltip id="save-tooltip">Save the changes to the server</span>
```

</PlatformBlock>
