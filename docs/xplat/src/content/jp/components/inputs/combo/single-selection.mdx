# Single Selection Combo (単一選択コンボ)

{ProductName} Single Selection Combo は、ユーザーが 1 つのオプションを選択し、入力フィールドに入力して検索可能なドロップダウン リストをフィルタリングできる Combo です。

<PlatformBlock for="Angular">

Angular の単一選択 Combo は Simple Combo (`igx-simple-combo` コンポーネント) です。Combo と同様にオプションのバインド、グループ化、テンプレート化ができ、ユーザーは入力フィールドに入力してリストをフィルタリングしたり、カスタム値を入力したりできます。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Combo で <PlatformBlock for="React,WebComponents"><ApiLink type="Combo" member="singleSelect" label="singleSelect" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink pkg="core" type="Combo<T>" member="SingleSelect" label="SingleSelect" /></PlatformBlock> を設定すると、単一選択に切り替わります。入力フィールドが編集可能になり、ユーザーの入力に応じてリストがフィルタリングされます。ドロップダウンの検索入力は非表示になり、オプションにチェックボックスは表示されません。

</PlatformBlock>

<DocsAside type="info">
Combo には 2 つのレイアウト オプションがあります。単一選択の Combo (Simple Combo) と Combo (複数選択) です。
</DocsAside>

単一選択モードでは、`igc-combo` 要素は編集可能な入力フィールドをレンダリングし、ドロップダウンの検索入力を非表示にして、チェックボックスなしでオプションをレンダリングします。

```text
igc-combo[single-select]
└─ #shadow-root
   ├─ igc-popover
   │  ├─ igc-input#target[slot="anchor"]            // the editable input field, exported as the "input" part
   │  │  ├─ slot[name="prefix"]
   │  │  ├─ span[part="clear-icon"]                  // shown when the Combo has a value
   │  │  ├─ slot[name="suffix"]
   │  │  └─ span[part="toggle-icon"]
   │  └─ div[part="list-wrapper"]                    // the dropdown
   │     ├─ div[part="filter-input"][hidden]         // the search input is hidden
   │     ├─ div[part="header"]
   │     │  └─ slot[name="header"]
   │     ├─ igc-virtual-scroll#dropdown[part="list"][role="listbox"]
   │     │  ├─ igc-combo-header[part="group-header"] // one for each group
   │     │  └─ igc-combo-item[part="item"][hide-checkbox] // one for each option
   │     ├─ div[part="empty"]                        // shown when the list has no options
   │     │  └─ slot[name="empty"]
   │     └─ div[part="footer"]
   │        └─ slot[name="footer"]
   └─ igc-validator#combo-helper-text               // the helper text and the validation messages, exported as the "helper-text" part
```

</PlatformBlock>

```text
│  ├─ igx-suffix                                // the case-sensitive icon, shown with showSearchCaseIcon
│  ├─ igx-suffix.igx-combo__toggle-button
│  └─ igx-hint
└─ igx-combo-drop-down                          // the dropdown, shown in an overlay

         ├─ div.igx-combo__content              // the options
         │  └─ igx-combo-item[role="option"]    // role="group" for the group headers
         ├─ div.igx-combo__add                  // the empty message and the add item button
         │  └─ igx-combo-add-item[role="button"] // shown with allowCustomValues
         └─ [igxComboFooter] template
```

## 使用方法

国や都市など、ユーザーが検索する必要があるリストから 1 つのオプションだけを選ぶ場合は、{Platform} Single Selection Combo を使用します。

### タイプ (Material テーマ)

Material テーマでは、Simple Combo の入力で、単色の背景上でより構造的に見える境界線タイプと、鮮やかな画像の上に配置したときに読みやすさを高めるのに最適なボックス タイプのどちらかを選択できます。Bootstrap、Fluent、Indigo テーマでは両方のタイプが同じ見た目で描画されるため、このトピックのその他のサンプルでは、ボックス タイプを Material テーマでのみ表示しています。

### サイズ

Combo には、大、中、小の 3 つのサイズがあります。ドロップダウンは、選択したサイズに合わせて自動的に寸法を調整します。サイズは `--ig-size` CSS 変数で設定します。

```css
.small {
  --ig-size: var(--ig-size-small);
}

.large {
  --ig-size: var(--ig-size-large);
}
```

### インタラクション状態

Combo コンポーネントは、有効なバリアントに対して 5 つの状態 (アイドル、アイドル & ホバー、入力済み、入力済み & ホバー、フォーカス) と、3 つの検証状態 (成功、警告、エラー) をサポートします。

入力フィールドまたはトグルをクリックするとドロップダウンが開き、入力フィールドに入力するとドロップダウンが開いてリストがフィルタリングされます。コードでドロップダウンを開閉するには、<PlatformBlock for="React,WebComponents">`open` プロパティ、または `show`、`hide`、`toggle` メソッド</PlatformBlock><PlatformBlock for="Blazor">`Open` パラメーター、または `ShowAsync`、`HideAsync`、`ToggleAsync` メソッド</PlatformBlock><PlatformBlock for="Angular">`open`、`close`、`toggle` メソッド</PlatformBlock>を使用します。

<PlatformBlock for="WebComponents">

```ts
const combo = document.getElementById('countries') as IgcComboComponent;

await combo.show();
await combo.hide();
await combo.toggle();
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const comboRef = useRef<IgrCombo>(null);

const open = () => comboRef.current?.show();
const close = () => comboRef.current?.hide();
const toggle = () => comboRef.current?.toggle();

return <IgrCombo ref={comboRef} singleSelect data={countries} valueKey="id" displayKey="name" />;
```

</PlatformBlock>

### 値と選択

{Platform} Single Selection Combo は 1 つの選択項目を保持し、その値と選択 API を通じて公開します。

<PlatformBlock for="React,WebComponents,Blazor">

`value` は、選択項目を 1 要素の配列として保持します。要素は、その `valueKey` の値、または `valueKey` がない場合はオブジェクト参照です。Combo が最初にレンダリングされるときに項目を選択するには、これを設定します。`select` メソッドは 1 つの項目を選択して前の項目の選択を解除するため、1 つの項目を渡します。`deselect` メソッドは選択を解除します。項目を指定せずに呼び出すと、単一選択モードでは `select` が選択をクリアします。

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
// select the item matching the 'BG' value of the value key field
combo.select('BG');

// deselect it
combo.deselect('BG');

console.log(combo.value); // ['BG'] while Bulgaria is selected, [] after the deselection
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx

```

</PlatformBlock>

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Combo は、ユーザーが選択を変更する前に <PlatformBlock for="WebComponents">`igcChange`</PlatformBlock><PlatformBlock for="React">`onChange`</PlatformBlock><PlatformBlock for="Blazor">`Change`</PlatformBlock> を発行します。イベントの詳細には、新しい値、変更された項目、および変更の種類が含まれており、このイベントをキャンセルすると選択は維持されます。

```ts
        this.combo.select('BE');

}
```

Angular Simple Combo は、選択が変更される前に <ApiLink type="SimpleCombo" member="selectionChanging" label="selectionChanging" /> を、変更された後に <ApiLink type="SimpleCombo" member="selectionChanged" label="selectionChanged" /> を発行します。イベント引数には、古い値と新しい値、古い項目と新しい項目、および入力フィールドの表示テキストが含まれており、`selectionChanging` で `cancel` を設定すると選択は維持されます。


```ts
public onCountryChanging(event: ISimpleComboSelectionChangingEventArgs): void {
    if (event.newValue === 'BY') {
        event.cancel = true;
    }
}
```

`selectionChanging` イベントは、カスケード シナリオでも使用されます。カスケード シナリオでは、ある Simple Combo の選択によって次の Simple Combo のデータが読み込まれます (国、地域、都市の Combo など)。各 Simple Combo の `selectionChanging` イベントを処理して、次の Simple Combo のデータを読み込み、その選択をクリアします。

```html
<igx-simple-combo #country
    [data]="countriesData"
    (selectionChanging)="countryChanging($event)"
    placeholder="Choose Country..."
    [(ngModel)]="selectedCountry"
    displayKey="name">
</igx-simple-combo>
<igx-simple-combo #region
    [data]="regionData"
    (selectionChanging)="regionChanging($event)"
    placeholder="Choose Region..."
    [(ngModel)]="selectedRegion"
    displayKey="name"
    [disabled]="regionData.length === 0">
</igx-simple-combo>
<igx-simple-combo #city
    [data]="citiesData"
    placeholder="Choose City..."
    [(ngModel)]="selectedCity"
    displayKey="name"
    [disabled]="citiesData.length === 0">
</igx-simple-combo>
```

```ts
export class SimpleComboCascadingComponent implements OnInit {
    public selectedCountry: Country;
    public selectedRegion: Region;
    public selectedCity: City;
    public countriesData: Country[];
    public regionData: Region[] = [];
    public citiesData: City[] = [];

    public ngOnInit(): void {
        this.countriesData = getCountries(['United States', 'Japan', 'United Kingdom']);
    }

    public countryChanging(e: ISimpleComboSelectionChangingEventArgs) {
        this.selectedCountry = e.newSelection as Country;
        this.regionData = getCitiesByCountry([this.selectedCountry?.name])
            .map(c => ({ name: c.region, country: c.country }))
            .filter((v, i, a) => a.findIndex(r => r.name === v.name) === i);
        this.selectedRegion = null;
        this.selectedCity = null;
        this.citiesData = [];
    }

    public regionChanging(e: ISimpleComboSelectionChangingEventArgs) {
        this.selectedRegion = e.newSelection as Region;
        this.citiesData = getCitiesByCountry([this.selectedCountry?.name])
            .filter(c => c.region === this.selectedRegion?.name);
        this.selectedCity = null;
    }
}
```

### フィルタリング

{Platform} Single Selection Combo の入力フィールドに入力すると、ドロップダウンが開き、入力したテキストを含むオプションにリストがフィルタリングされます。最初の一致がアクティブなオプションになるため、<kbd>Enter</kbd> キーで選択できます。

<PlatformBlock for="React,WebComponents,Blazor">

ユーザーの入力中にリスト全体を維持するには、`disableFiltering` を設定します。`filteringOptions` オブジェクトは、フィルタリングに使用するキー、およびフィルタリングで大文字と小文字を区別するかどうか、発音区別記号を照合するかどうかを設定します。選択されたオプションがない状態で Combo がフォーカスを失うと、入力フィールドはクリアされます。

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
combo.filteringOptions = { filterKey: 'name', caseSensitive: false, matchDiacritics: true };
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrCombo singleSelect filteringOptions={{ filterKey: 'name', caseSensitive: false, matchDiacritics: true }} />
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCombo T="string" SingleSelect="true" DisableFiltering="true" Data="Countries" ValueKey="Id" DisplayKey="Name" />
```

</PlatformBlock>

<PlatformBlock for="Angular">

ユーザーの入力中にリスト全体を維持するには <ApiLink type="SimpleCombo" member="disableFiltering" label="disableFiltering" /> を設定し、大文字と小文字を区別するフィルタリングを切り替えるボタンを入力フィールドに表示するには <ApiLink type="SimpleCombo" member="showSearchCaseIcon" label="showSearchCaseIcon" /> を設定します。<ApiLink type="SimpleCombo" member="filteringOptions" label="filteringOptions" /> 入力は、フィルタリングに使用するキーと、フィルタリングで大文字と小文字を区別するかどうかを設定し、<ApiLink type="SimpleCombo" member="filterFunction" label="filterFunction" /> はフィルタリングを独自の処理に置き換えます。選択されたオプションがない状態で Simple Combo がフォーカスを失うと、入力フィールドはクリアされます。

```html

                  [filteringOptions]="{ filteringKey: 'name', caseSensitive: false }">
</igx-simple-combo>
```

リストにない値をユーザーが入力できるようにするには、<ApiLink type="SimpleCombo" member="allowCustomValues" label="allowCustomValues" /> を設定します。テキストがどのオプションにも一致しない場合、ドロップダウンに項目追加ボタンが表示され、そのボタンで <kbd>Enter</kbd> キーを押すと、テキストが新しい項目として追加されて選択されます。Simple Combo は、項目を追加する前に <ApiLink type="SimpleCombo" member="addition" label="addition" /> を発行します。

```html
<igx-simple-combo [data]="countries" displayKey="name" valueKey="id" [allowCustomValues]="true" (addition)="onAddition($event)"></igx-simple-combo>
```

</PlatformBlock>

### 推奨 / 非推奨

Simple Combo を使用する場合、その入力とドロップダウンは同じ幅にし、左右の境界線を揃える必要があります。Simple Combo にフォーカスが当たったときのドロップダウンは、表示をトリガーした Simple Combo の後に続くコンテンツの上に常に重ねて表示する必要があります。Combo は、展開パネルのようにコンテンツを押し下げることはありません。

## スタイル設定

Simple Combo は、入力とドロップダウンの両方の要素を組み合わせた柔軟なスタイル設定を提供します。入力テキスト要素の色、境界線のスタイルと色のオプションがあります。ドロップダウンについては、背景色を変更したり、Simple Combo ドロップダウン内の項目に関するさまざまなオプションで背景色とテキスト色を変更したりできます。

{Platform} Single Selection Combo のトグル ボタンとクリア ボタンの色は、次の CSS 変数で変更できます。

| 変数 | 変更内容 |
| --- | --- |
| `--ig-combo-toggle-button-background` | トグル ボタンの背景。 |
| `--ig-combo-toggle-button-foreground` | トグル ボタンのアイコンの色。 |
| `--ig-combo-toggle-button-foreground-filled` | Combo に値があるときのトグル ボタンのアイコンの色。 |
| `--ig-combo-toggle-button-background-focus` | Combo がフォーカスされているときのトグル ボタンの背景。 |
| `--ig-combo-toggle-button-foreground-focus` | Combo がフォーカスされているときのトグル ボタンのアイコンの色。 |
| `--ig-combo-toggle-button-background-disabled` | Combo が無効なときのトグル ボタンの背景。 |
| `--ig-combo-toggle-button-foreground-disabled` | Combo が無効なときのトグル ボタンのアイコンの色。 |
| `--ig-combo-clear-button-background` | クリア ボタンの背景。 |

### Sass テーマ

プライマリ プロパティを変更すると、関連するすべての依存プロパティが自動的に更新され、変更が反映されます。<PlatformBlock for="Angular"><ApiLink kind="sass" module="themes" type="function-combo-theme" label="combo-theme" code={true} /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">`combo-theme`</PlatformBlock> 関数のプライマリ パラメーターは `$toggle-button-background` で、テーマはこれからすべての状態のトグル ボタンの色を導出します。Combo とそのドロップダウンのテーマを作成し、`tokens()` ミックスインでインクルードします。このミックスインは、インクルードしたスコープに対応する CSS 変数を出力します。

<PlatformBlock for="Angular">

```scss
@use "igniteui-angular/theming" as *;

$custom-combo-theme: combo-theme(
  $toggle-button-background: #e0e0e0
);

$custom-drop-down-theme: drop-down-theme(
  $background-color: #e6f2ff,
  $selected-item-background: #4ca7e3
);

:host {
  @include tokens($custom-combo-theme);
  @include tokens($custom-drop-down-theme);
}
```

Angular Simple Combo は、オーバーレイにドロップダウンを表示します。ビューのカプセル化とオーバーレイ アウトレットの場所によっては、`:host` の下にインクルードしたテーマがドロップダウンに適用されない場合があります。[オーバーレイのスタイル設定](../../overlay-styling.mdx)トピックを参照してください。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Sass 関数は `igniteui-theming` パッケージに含まれています。Sass のセットアップについては、[テーマ](../../themes/overview.mdx)トピックを参照してください。

```scss
@use "igniteui-theming" as *;

$custom-combo-theme: combo-theme(
  $toggle-button-background: #e0e0e0
);

$custom-drop-down-theme: drop-down-theme(
  $background-color: #e6f2ff,
  $selected-item-background: #4ca7e3
);

:root {
  @include tokens($custom-combo-theme);
  @include tokens($custom-drop-down-theme);
}
```

</PlatformBlock>

## アクセシビリティ

{Platform} Single Selection Combo は、WAI-ARIA コンボボックス パターンのロールを使用します。編集可能な入力フィールドはオプションの `listbox` を制御する `combobox` であり、ユーザーは入力でリストをフィルタリングし、キーボードでオプションを選択します。

### キーボード操作

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Single Selection Combo の入力フィールドはタブ ストップであり、ユーザーが入力している間もフォーカスは入力フィールドに留まります。Combo にフォーカスがある間は、次のキーが機能します。

| キー | 操作 |
| --- | --- |
| 印字可能な文字 | 入力フィールドで、ドロップダウンを開き、リストをフィルタリングし、最初の一致をアクティブにします。 |
| <kbd>Arrow Down</kbd> / <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> | 入力フィールドでは、ドロップダウンを開き、フォーカスをリストに移動し、最初のオプションをアクティブにします。リストでは、次のオプションをアクティブにします。 |
| <kbd>Arrow Up</kbd> | 入力フィールドでは、ドロップダウンを閉じます。リストでは、前のオプションをアクティブにします。最初のオプションからは、ドロップダウンを閉じてフォーカスを入力フィールドに移動します。 |
| <kbd>Home</kbd> / <kbd>End</kbd> | リストで、最初または最後のオプションをアクティブにします。 |
| <kbd>Space</kbd> | リストで、アクティブなオプションを選択し、選択済みの場合は選択を解除します。 |
| <kbd>Enter</kbd> | アクティブなオプションがある場合、それを選択し、ドロップダウンを閉じて、テキストを選択した状態でフォーカスを入力フィールドに移動します。 |
| <kbd>Escape</kbd> | ドロップダウンが開いているときは、閉じてフォーカスを入力フィールドに移動します。ドロップダウンが閉じているときは、選択をクリアします。 |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | ドロップダウンが開いているときは、アクティブなオプションを選択し、ドロップダウンを閉じて、フォーカスを次または前のフォーカス可能な要素に移動します。 |

無効な Combo はこれらのキーを無視します。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Simple Combo の入力フィールドはタブ ストップであり、ユーザーが入力している間もフォーカスは入力フィールドに留まります。Simple Combo にフォーカスがある間は、次のキーが機能します。

| キー | 操作 |
| --- | --- |
| 印字可能な文字 | 入力フィールドで、ドロップダウンを開き、リストをフィルタリングし、最初の一致にフォーカスします。 |
| <kbd>Arrow Down</kbd> / <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> | 閉じている Simple Combo では、ドロップダウンを開きます。開いている Simple Combo では、フォーカスをリストの選択済みオプション、または最初のオプションに移動します。リストでは、次のオプションに移動し、最後のオプションからは、項目追加ボタンが表示されている場合はそのボタンに移動します。 |
| <kbd>Arrow Up</kbd> | リストで、前のオプションに移動します。最初のオプションからは、フォーカスを入力フィールドに戻し、そのテキストを選択します。 |
| <kbd>Alt</kbd> + <kbd>Arrow Up</kbd> | リストで、ドロップダウンを閉じてフォーカスを入力フィールドに移動します。 |
| <kbd>Home</kbd> / <kbd>End</kbd> | リストで、最初または最後のオプションに移動します。 |
| <kbd>Space</kbd> | リストで、フォーカスされているオプションを選択または選択解除します。 |
| <kbd>Enter</kbd> | テキストに一致するフォーカスされたオプションがある入力フィールドでは、それを選択してドロップダウンを閉じます。リストでは、フォーカスされているオプションを選択し、ドロップダウンを閉じて、フォーカスを入力フィールドに移動します。項目追加ボタンでは、入力フィールドのテキストを新しい項目として追加して選択します。 |
| <kbd>Backspace</kbd> / <kbd>Delete</kbd> | 入力フィールドで、選択をクリアします。 |
| <kbd>Escape</kbd> | ドロップダウンが開いているときは、閉じます。ドロップダウンが閉じているときは、選択をクリアし、フォーカスを入力フィールドに維持します。 |
| <kbd>Tab</kbd> | ドロップダウンが開いているときは、テキストに一致するフォーカスされたオプションを選択し、ドロップダウンを閉じて、フォーカスを次のフォーカス可能な要素に移動します。 |

</PlatformBlock>

### スクリーン リーダー / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Single Selection Combo は、次のロールと属性をレンダリングします。

| 要素 | ロール | 属性 |
| --- | --- | --- |
| 入力フィールド | `combobox` | `aria-haspopup="listbox"`、`aria-expanded`、`aria-disabled`、リストを指す `aria-controls`、およびヘルパー テキストがある場合はそれを指す `aria-describedby` |
| `list` パーツ | `listbox` | `aria-multiselectable="false"`、入力フィールドを指す `aria-labelledby`、およびアクティブなオプションを指す `aria-activedescendant` |
| 各 `item` パーツ | `option` | `aria-selected`、`aria-posinset`、`aria-setsize` |
| `clear-icon` パーツ | `button` | リソース文字列からの `aria-label` |

{Platform} Single Selection Combo は、支援技術に対して次のようにも動作します。

- 入力フィールドは、`label` からアクセシブル名を取得します。ラベルがない場合は、オプションが選択されているかどうかを示すリソース文字列から名前を取得します。
- 入力フィールドは編集可能であり、ユーザーが入力したテキストがリストのフィルターになります。
- フォーカスがリストにある間、アクティブなオプションは `aria-activedescendant` を通じて読み上げられます。
- 閉じているドロップダウンのコンテンツは `inert` です。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Simple Combo は、次のロールと属性をレンダリングします。

| 要素 | ロール | 属性 |
| --- | --- | --- |
| 入力フィールドの入力 | `combobox` | `aria-haspopup="listbox"`、`aria-autocomplete="list"`、`aria-readonly="false"`、`aria-expanded`、リストを指す `aria-controls`、`aria-labelledby`、`aria-label` |
| ドロップダウン | `listbox` | `igxLabel` または `ariaLabelledBy` 要素を指す `aria-labelledby` |
| オプションのコンテナー | — | フォーカスされているオプションを指す `aria-activedescendant` |
| 各オプション | `option` | `aria-selected` |
| 各グループ ヘッダー | `group` | — |
| クリア ボタン | — | リソース文字列からの `aria-label` |
| 項目追加ボタン | `button` | リソース文字列からの `aria-label` |

入力フィールドは、`igxLabel` または <ApiLink type="SimpleCombo" member="ariaLabelledBy" label="ariaLabelledBy" /> 入力からアクセシブル名を取得します。これらがない場合は、オプションが選択されているかどうかを示すリソース文字列から名前を取得します。

</PlatformBlock>

| 基準 | コンポーネントの準拠方法 |
| --- | --- |
| [1.3.1 情報及び関係性](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships) | `combobox`、`listbox`、`option` ロールが構造を公開し、リストは<PlatformBlock for="Angular">`igxLabel` または `ariaLabelledBy` 要素</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">入力フィールド</PlatformBlock>によってラベル付けされます。 |
| [2.1.1 キーボード](https://www.w3.org/WAI/WCAG21/Understanding/keyboard) | 入力でリストがフィルタリングされ、矢印キーでドロップダウンを開いてオプション間を移動でき、Enter キーでアクティブなオプションを選択します。 |
| [2.1.2 キーボード トラップなし](https://www.w3.org/WAI/WCAG21/Understanding/no-keyboard-trap) | Tab キーでドロップダウンが閉じ、フォーカスが Combo の外に移動します。 |

開発者の責任:

- すべての Combo に、ユーザーが何を選択するかを示すラベルを付けます。[タイプ (Material テーマ)](#タイプ-material-テーマ)を参照してください。
- テーマの色をオーバーライドする場合は、[1.4.11 非テキストのコントラスト](https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast)で要求されているとおり、境界線とフォーカス インジケーターに 3:1 以上のコントラスト比を維持します。
- エラー メッセージは、色だけでなくヘルパー テキストに表示します。[検証状態](#検証状態)を参照してください。

## 既知の制限

<PlatformBlock for="React,WebComponents,Blazor">

- 単一選択モードではドロップダウンの検索入力が非表示になるため、`placeholderSearch`、`caseSensitiveIcon`、`autofocusList` は効果がありません。
- {Platform} Combo はカスタム値を追加しません。入力フィールドのテキストがどのオプションにも一致しない場合、Combo はフォーカスを失ったときに入力フィールドをクリアします。

</PlatformBlock>

<PlatformBlock for="Angular">

- Angular Simple Combo が `undefined` を含むプリミティブの配列にバインドされている場合、リストには `undefined` が表示されません。オブジェクトの `valueKey` フィールドが `undefined` の場合、リストには項目が表示されますが、ユーザーは選択できません。
- Angular Simple Combo が `ngModel` にバインドされていて `required` の場合、`null`、`undefined`、`''` の値は選択できません。
- Angular Simple Combo がリモート サービスにバインドされていて、事前定義された選択がある場合、データが読み込まれるまで入力フィールドは空白のままです。
- リストは [Virtual Scroll](../../layouts/virtual-scroll.mdx#既知の制限) を使用するため、その制限が適用されます。リストは表示範囲内のオプションのみをレンダリングするため、DOM を照会するコードは、それらのオプションしか見つけられません。

</PlatformBlock>
