# {Platform} Combo (コンボ)

{ProductName} Combo (コンボ) は、入力フィールドと検索可能なドロップダウン リストを組み合わせたコンポーネントで、ユーザーは入力してオプションをフィルタリングし、1 つ以上の項目を選択できます。

<PlatformBlock for="Angular">

Angular Combo は `igx-combo` コンポーネントです。仮想化されたドロップダウン リストにオプションを表示し、フィルタリング、グループ化、カスタム値、および Angular フォームとの双方向バインディングをサポートします。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Combo は仮想化されたリストにオプションを表示するため、リストに数千のオプションを含めることができます。Combo は、大文字と小文字を区別するフィルタリング、グループ化、および複雑なデータへのバインディングをサポートします。

</PlatformBlock>

`igc-combo` 要素は、入力フィールドとドロップダウン リストをポップオーバー内に、その下にヘルパー テキストをレンダリングします:

```text
igc-combo
└─ #shadow-root
   ├─ igc-popover
   │  ├─ igc-input#target[slot="anchor"]            // the input field, exported as the "input" part
   │  │  ├─ slot[name="prefix"]
   │  │  ├─ span[part="clear-icon"]                  // shown when the Combo has a value
   │  │  ├─ slot[name="suffix"]
   │  │  └─ span[part="toggle-icon"]
   │  └─ div[part="list-wrapper"]                    // the dropdown
   │     ├─ div[part="filter-input"]
   │     │  └─ igc-input[part="search-input"]        // hidden with disable-filtering or single-select
   │     ├─ div[part="header"]
   │     │  └─ slot[name="header"]
   │     ├─ igc-virtual-scroll#dropdown[part="list"][role="listbox"]
   │     │  ├─ igc-combo-header[part="group-header"] // one for each group
   │     │  └─ igc-combo-item[part="item"]           // one for each option
   │     ├─ div[part="empty"]                        // shown when the list has no options
   │     │  └─ slot[name="empty"]
   │     └─ div[part="footer"]
   │        └─ slot[name="footer"]
   └─ igc-validator[part="helper-text"]              // the helper text and the validation messages
```

</PlatformBlock>

```text
├─ igx-input-group

         │  └─ igx-combo-item[role="option"]    // role="group" for the group headers
         ├─ div.igx-combo__add                  // the empty message and the add item button
         │  └─ igx-combo-add-item[role="button"] // shown with allowCustomValues
         └─ [igxComboFooter] template
```

## 使用方法

### 検証状態

経験豊富なデザイナーは、ユーザー入力を制限して無効な状態を避けるために制約を適切に使用します。そのため、検証スタイルが用意されています。利用可能な検証スタイルにより、Combo の入力は標準の <PlatformBlock for="Angular">[入力](../../input-group.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[入力](../input.mdx)</PlatformBlock>と一貫性を保ち、成功、警告、エラーの視覚効果を表示する高度なデザインにも対応します。

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Combo はフォームに関連付けられています。少なくとも 1 つの項目の選択を必須にするには `required` を設定し、エラー状態を表示するには `invalid` を設定します。ガイダンスまたはエラー メッセージは `helper-text` スロットに配置します。Combo は、制約検証 API の `checkValidity`、`reportValidity`、`setCustomValidity` メソッドも公開します。Combo には組み込みの成功状態と警告状態がないため、サンプルではこれら 2 つの状態に CSS クラスでスタイルを設定しています。

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-combo outlined required invalid placeholder="Country">
  <span slot="helper-text">Please select a different region</span>
</igc-combo>
```

</PlatformBlock>

### データ バインディング

{Platform} Combo は、`data` にバインドした配列からオプションのリストを構築します。配列にオブジェクトが含まれる場合は、Combo が使用するキーを設定します:

<PlatformBlock for="React,WebComponents">

- <ApiLink type="Combo" member="valueKey" label="valueKey" /> - オプションを識別するフィールドです。Combo の値と選択 API で使用されます。省略した場合、Combo はオブジェクトへの参照を使用します。
- <ApiLink type="Combo" member="displayKey" label="displayKey" /> - リストと入力フィールドに表示するフィールドです。省略した場合、Combo は `valueKey` を使用します。
- <ApiLink type="Combo" member="groupKey" label="groupKey" /> - オプションをグループ化するフィールドです。各グループにヘッダーが表示され、<ApiLink type="Combo" member="groupSorting" label="groupSorting" /> でグループを昇順または降順に並べ替えます。

</PlatformBlock>

<PlatformBlock for="Blazor">

- <ApiLink pkg="core" type="Combo<T>" member="ValueKey" label="ValueKey" /> - オプションを識別するフィールドです。Combo の値と選択 API で使用されます。省略した場合、Combo はオブジェクトへの参照を使用します。
- <ApiLink pkg="core" type="Combo<T>" member="DisplayKey" label="DisplayKey" /> - リストと入力フィールドに表示するフィールドです。省略した場合、Combo は `ValueKey` を使用します。
- <ApiLink pkg="core" type="Combo<T>" member="GroupKey" label="GroupKey" /> - オプションをグループ化するフィールドです。各グループにヘッダーが表示され、<ApiLink pkg="core" type="Combo<T>" member="GroupSorting" label="GroupSorting" /> でグループを昇順または降順に並べ替えます。

Blazor Combo の `T` 型パラメーターは、その値の型です。`ValueKey` フィールドの型に設定するか、`ValueKey` を設定しない場合はオプションの型に設定します。`@bind-Value` で `Value` をバインドすると、Razor はバインドされたフィールドから `T` を推論します。

</PlatformBlock>

<PlatformBlock for="Angular">

- <ApiLink type="Combo" member="valueKey" label="valueKey" /> - オプションを識別するフィールドです。Combo の値と選択で使用されます。省略した場合、Combo はオブジェクトへの参照を使用します。
- <ApiLink type="Combo" member="displayKey" label="displayKey" /> - リストと入力フィールドに表示するフィールドです。省略した場合、Combo は `valueKey` を使用します。
- <ApiLink type="Combo" member="groupKey" label="groupKey" /> - オプションをグループ化するフィールドです。各グループにヘッダーが表示され、<ApiLink type="Combo" member="groupSortingDirection" label="groupSortingDirection" /> でグループを並べ替えます。

リモート サービスから読み込まれるデータにバインドするには、[リモート バインディング](../../combo-remote.mdx)トピックを参照してください。

</PlatformBlock>

配列に文字列や数値などのプリミティブ値が含まれる場合は、`valueKey` と `displayKey` を設定しないでください。Combo は値そのものを使用します。

### 値と選択

{Platform} Combo は、選択された項目を値を通じて公開し、コードで項目を選択および選択解除するメソッドを提供します。

<PlatformBlock for="React,WebComponents,Blazor">

`value` は、選択された項目を `valueKey` の値として、または `valueKey` がない場合はオブジェクト参照として保持します。Combo の初回レンダリング時に項目を選択するには、これを設定します。`select` および `deselect` メソッドは項目の配列を受け取ります。項目なしで呼び出すと、すべての項目を選択または選択解除します:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
// select and deselect items by their ids, because the valueKey is 'id'
combo.select(['BG01', 'BG02']);
combo.deselect(['BG01']);

// select and deselect all items
combo.select();
combo.deselect();

console.log(combo.value); // the ids of the selected items
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
// select and deselect items by their ids, because the valueKey is 'id'
comboRef.current.select(['BG01', 'BG02']);
comboRef.current.deselect(['BG01']);

// select and deselect all items
comboRef.current.select([]);
comboRef.current.deselect([]);

console.log(comboRef.current.value); // the ids of the selected items
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
@code {
    private IgbCombo<object> Combo;

    public void SelectCities() => Combo.Select(new object[] { "BG01", "BG02" });

    public void DeselectAll() => Combo.Deselect(new object[] { });
}
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

ユーザーが単一の項目を選択し、入力フィールドに入力してリストをフィルタリングできるようにするには、[単一選択](./single-selection.mdx)モードを使用します。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Combo は `[(ngModel)]` による双方向バインディングをサポートし、テンプレート駆動フォームとリアクティブ フォームで動作します。<ApiLink type="Combo" member="selection" label="selection" /> プロパティは選択された項目を返し、<ApiLink type="Combo" member="select" label="select" />、<ApiLink type="Combo" member="deselect" label="deselect" />、<ApiLink type="Combo" member="selectAllItems" label="selectAllItems" />、<ApiLink type="Combo" member="deselectAllItems" label="deselectAllItems" /> メソッドで変更します:

```html
<igx-combo [data]="cities" displayKey="name" valueKey="id" [(ngModel)]="selectedCities"></igx-combo>
```

```ts
export class CitiesComponent {
    @ViewChild(IgxComboComponent, { static: true })
    public combo: IgxComboComponent;

    public selectedCities: string[] = ['BG01', 'UK01'];

    public selectFavorites(): void {
        this.combo.select(['UK01', 'BG01']);
    }
}
```

Angular Combo は、選択が変更される前にキャンセル可能な <ApiLink type="Combo" member="selectionChanging" label="selectionChanging" /> を発行し、選択が確定した後に <ApiLink type="Combo" member="selectionChanged" label="selectionChanged" /> を発行します。

ユーザーが単一の項目を選択し、入力フィールドに入力できるようにするには、[シンプル コンボ](./single-selection.mdx)を使用します。

</PlatformBlock>

### 推奨事項と非推奨事項

Combo を使用する場合、入力とドロップダウンは同じ幅にし、左右の境界線を揃える必要があります。Combo にフォーカスがあるときのドロップダウンの表示については、Combo による表示のトリガーに続くコンテンツの上に常に表示する必要があります。Combo は、展開パネルのようにコンテンツを押し下げることはありません。

<DoDont
  doSrc={comboDoAlignment}
  doAlt="ドロップダウンの幅が入力と同じで、その下のフィールドを覆っている、開いた Country コンボ"
  dontSrc={comboDoNotAlignment}
  dontAlt="ドロップダウンが入力より狭く、右にずれている、開いた Country コンボ"
>
<Fragment slot="do">

入力とドロップダウンの幅が同じで、左右の境界線が揃うように、ドロップダウンを入力に合わせます。

</Fragment>
<Fragment slot="dont">

ドロップダウンが入力より狭い、または位置がずれていると、両者の視覚的なつながりが損なわれるため避けてください。

</Fragment>
</DoDont>

## スタイル設定

Combo には、入力とドロップダウンの各部分を組み合わせた柔軟なスタイル設定が用意されています。入力テキスト要素の色、枠線のスタイルと色を変更できます。ドロップダウンでは、背景色を変更したり、検索入力や、背景色とテキスト色を持つ項目など、Combo ドロップダウン内の項目に関するさまざまなオプションを使用したりできます。

### Sass テーマ

プライマリ プロパティを変更すると、関連するすべての依存プロパティが自動的に更新され、変更が反映されます。<PlatformBlock for="Angular"><ApiLink kind="sass" module="themes" type="function-combo-theme" label="combo-theme" code={true} /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">`combo-theme`</PlatformBlock> 関数のプライマリ パラメーターは `$toggle-button-background` で、テーマはここからすべての状態のトグル ボタンの色を導出します。Combo、そのドロップダウン、およびそのチェックボックスのテーマを作成し、`tokens()` ミックスインでインクルードします。このミックスインは、インクルードしたスコープに、対応する CSS 変数を出力します。

<PlatformBlock for="Angular">

```scss
@use "igniteui-angular/theming" as *;

$custom-combo-theme: combo-theme(
  $toggle-button-background: #e0e0e0
);

$custom-drop-down-theme: drop-down-theme(
  $background-color: #e6f2ff
);

$custom-checkbox-theme: checkbox-theme(
  $fill-color: #005dcc,
  $empty-color: #005dcc
);

:host {
  @include tokens($custom-combo-theme);
  @include tokens($custom-drop-down-theme);
  @include tokens($custom-checkbox-theme);
}
```

Angular Combo は、ドロップダウンをオーバーレイに表示します。ビューのカプセル化とオーバーレイ アウトレットの場所によっては、`:host` 配下にインクルードしたテーマがドロップダウンに適用されない場合があります。[オーバーレイのスタイル設定](../../overlay-styling.mdx)トピックを参照してください。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Sass 関数は `igniteui-theming` パッケージから提供されます。Sass のセットアップについては、[テーマ](../../themes/overview.mdx)トピックを参照してください。

```scss

  @include tokens($custom-drop-down-theme);
  @include tokens($custom-checkbox-theme);

```

</PlatformBlock>

## アクセシビリティ

{Platform} Combo は、WAI-ARIA の combobox パターンのロールを使用します。入力フィールドはオプションの `listbox` を制御する `combobox` であり、ユーザーはキーボードでリストを開き、移動し、オプションを選択します。

### キーボード操作

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Combo の入力フィールドはタブ ストップです。ドロップダウンが開くと、検索入力にフォーカスが移ります。`autofocusList` が設定されている場合、または検索入力が非表示の場合は、リストにフォーカスが移ります。単一選択モードでは、フォーカスは入力フィールドに留まります。Combo にフォーカスがある間は、次のキーが機能します:

| キー | 動作 |
| --- | --- |
| <kbd>Arrow Down</kbd> | 入力フィールドではドロップダウンを開き、単一選択モードではフォーカスをリストに移して最初のオプションをアクティブにします。検索入力では、フォーカスをリストに移して最初のオプションをアクティブにします。リストでは、次のオプションをアクティブにします。 |
| <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> | 入力フィールドでは、<kbd>Arrow Down</kbd> と同じ動作をします。 |
| <kbd>Arrow Up</kbd> | 入力フィールドでは、ドロップダウンを閉じます。検索入力では、ドロップダウンを閉じてフォーカスを入力フィールドに移します。リストでは、前のオプションをアクティブにします。最初のオプションからは、フォーカスを検索入力に移します。検索入力が非表示の場合は、ドロップダウンを閉じてフォーカスを入力フィールドに移します。 |
| <kbd>Home</kbd> / <kbd>End</kbd> | リストでは、最初または最後のオプションをアクティブにします。 |
| <kbd>Space</kbd> | リストでは、アクティブなオプションを選択または選択解除します。 |
| <kbd>Enter</kbd> | アクティブなオプションがある場合は、ドロップダウンを閉じてフォーカスを入力フィールドに移します。単一選択モードでは、アクティブなオプションも選択します。 |
| <kbd>Escape</kbd> | ドロップダウンが開いている場合は、ドロップダウンを閉じてフォーカスを入力フィールドに移します。ドロップダウンが閉じている場合は、選択をクリアします。 |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | ドロップダウンを閉じて、フォーカスを次または前のフォーカス可能な要素に移します。単一選択モードでは、アクティブなオプションも選択します。 |

無効な Combo は、これらのキーを無視します。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Combo の入力フィールドはタブ ストップです。Combo にフォーカスがある間は、次のキーが機能します:

| キー | 動作 |
| --- | --- |
| <kbd>Arrow Down</kbd> / <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> | 閉じている Combo では、ドロップダウンを開いてフォーカスを検索入力に移します。検索入力では、フォーカスを最初のオプションに移します。リストが空でカスタム値が許可されている場合は、項目の追加ボタンに移します。リストでは、次のオプションに移動し、最後のオプションからは、項目の追加ボタンが表示されている場合はそこに移動します。 |
| <kbd>Arrow Up</kbd> / <kbd>Alt</kbd> + <kbd>Arrow Up</kbd> | 検索入力では、ドロップダウンを閉じてフォーカスを Combo に移します。リストでは、前のオプションに移動します。最初のオプションからは、フォーカスを検索入力に戻します。検索入力がない場合は、ドロップダウンを閉じてフォーカスを Combo に移します。 |
| <kbd>Home</kbd> / <kbd>End</kbd> | リストでは、最初または最後のオプションに移動します。 |

| <kbd>Escape</kbd> | ドロップダウンが開いている場合は、ドロップダウンを閉じてフォーカスを Combo に維持します。ドロップダウンが閉じている場合は、選択をクリアします。 |

### スクリーン リーダー / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Combo は、次のロールと属性をレンダリングします:

| 要素 | ロール | 属性 |
| --- | --- | --- |
| 入力フィールド | `combobox` | `aria-haspopup="listbox"`、`aria-expanded`、`aria-disabled`、リストを指す `aria-controls`、およびヘルパー テキストがある場合はそれを指す `aria-describedby` |
| `list` パーツ | `listbox` | `aria-multiselectable` (単一選択モードでは `false`)、入力フィールドを指す `aria-labelledby`、およびアクティブなオプションを指す `aria-activedescendant` |
| 各 `item` パーツ | `option` | `aria-selected`、`aria-posinset`、および `aria-setsize` |
| `clear-icon` パーツ | `button` | リソース文字列からの `aria-label` |

{Platform} Combo は、支援技術に対して次のように動作します:

- 入力フィールドは、`label` からアクセシブル名を取得します。ラベルがない場合は、オプションが選択されているかどうかを示すリソース文字列から名前を取得します。
- フォーカスがリストにある間、アクティブなオプションは `aria-activedescendant` を通じて読み上げられます。
- 閉じているドロップダウンのコンテンツは `inert` です。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Combo は、次のロールと属性をレンダリングします:

| 要素 | ロール | 属性 |
| --- | --- | --- |
| 入力フィールドの入力 | `combobox` | `aria-haspopup="listbox"`、`aria-expanded`、リストを指す `aria-controls`、`aria-labelledby`、および `aria-label` |
| 検索入力 | `searchbox` | `aria-autocomplete="list"` および `aria-label="search"` |
| ドロップダウン | `listbox` | `igxLabel` または `ariaLabelledBy` 要素を指す `aria-labelledby` |
| オプションのコンテナー | — | `aria-multiselectable="true"`、およびアクティブなオプションを指す `aria-activedescendant` |
| 各オプション | `option` | `aria-selected` |
| 各グループ ヘッダー | `group` | — |
| 項目の追加ボタン | `button` | リソース文字列からの `aria-label` |

入力フィールドは、`igxLabel` または <ApiLink type="Combo" member="ariaLabelledBy" label="ariaLabelledBy" /> 入力プロパティからアクセシブル名を取得します。これらがない場合は、オプションが選択されているかどうかを示すリソース文字列から名前を取得します。

</PlatformBlock>

- すべての Combo に、ユーザーが選択する内容を示すラベルを付けます。[タイプ](#タイプ)を参照してください。

- エラー メッセージは、色だけでなくヘルパー テキストに表示します。[検証状態](#検証状態)を参照してください。

## 既知の制限事項

- 選択された項目を表示する入力フィールドは編集できません。Firefox では、カーソルが表示されます。
- Angular Combo が `undefined` を含むプリミティブの配列にバインドされている場合、リストに `undefined` は表示されません。オブジェクトの `valueKey` フィールドが `undefined` の場合、リストに項目は表示されますが、ユーザーは選択できません。
- Angular Combo がリモート サービスにバインドされていて、事前定義された選択がある場合、データが読み込まれるまで入力フィールドは空白のままです。
- リストは[仮想スクロール](../../layouts/virtual-scroll.mdx#known-limitations)を使用するため、その制限が適用されます。リストは表示範囲内のオプションのみをレンダリングするため、DOM を照会するコードは、それらのオプションしか見つけられません。

</PlatformBlock>
