# Combo (コンボ) コンポーネントの機能

{Platform} Combo は、ローカル データへのバインド、ユーザーの入力に応じたオプションのフィルタリング、データ フィールドによるグループ化に対応し、無効にすることもできます。

<PlatformBlock for="Angular">

Combo は、リモート サービスからデータをチャンク単位で読み込んだり、カスタム値を受け入れたり、カスタム オーバーレイ設定でリストを表示したりすることもできます。

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

Combo は、リモート サービスからオプションを 1 ページずつ読み込むこともできます。

</PlatformBlock>

### リモート バインディング

Combo は、リモート サービスからデータをチャンク単位で読み込めます。ユーザーがスクロールした位置の項目を <ApiLink type="Combo" member="dataPreLoad" label="dataPreLoad" /> イベントで要求し、サービスはそれらの項目のみを返します。次のサンプルは、ユーザーのスクロールや検索に合わせて、リモート サービスから製品を読み込みます。

<Sample src="/lists/combo-remote" showThemePicker height={560} noBorder={false} spacing="md" alt="リモート サービスから製品をチャンク単位で読み込む {Platform} Combo" />

#### リモート サービスの定義

リモート サービスは、サーバーから項目をオンデマンドで読み込みます。Combo は <ApiLink type="Combo" member="virtualizationState" label="virtualizationState" /> プロパティを公開しており、読み込む最初の項目のインデックスと読み込む項目数を保持します。サーバー上のすべての項目に合わせてスクロール バーのサイズを設定するには、<ApiLink type="Combo" member="totalItemCount" label="totalItemCount" /> プロパティに項目の合計数を設定します。

次のサービスには、Combo の状態と検索テキストからリクエストを作成し、読み込んだ項目を Observable で発行する `getData()` メソッドがあります。

```typescript
import { HttpClient } from '@angular/common/http';
import { Injectable, inject } from '@angular/core';
import { IForOfState } from 'igniteui-angular/directives';
// import { IForOfState } from '@infragistics/igniteui-angular/directives'; for licensed package
import { BehaviorSubject } from 'rxjs';

@Injectable()
export class RemoteNWindService {
    private http = inject(HttpClient);
    private url = 'https://services.odata.org/V4/Northwind/Northwind.svc/Products';

    public remoteData = new BehaviorSubject<any[]>([]);

    public getData(state: IForOfState, searchText: string, cb?: (data: any) => void) {
        return this.http.get(this.buildUrl(state, searchText)).subscribe((data: any) => {
            this.remoteData.next(data.value);
            cb?.(data);
        });
    }

    // Requests the chunk of items the Combo shows, and the total count of the matching items.
    private buildUrl(state: IForOfState, searchText: string): string {
        let query = `?$skip=${state.startIndex}&$top=${state.chunkSize}&$count=true`;
        if (searchText) {
            // Double the apostrophes for OData, then encode the text for the URL.
            const text = encodeURIComponent(searchText.replace(/'/g, "''"));
            query += `&$filter=contains(ProductName, '${text}')`;
        }
        return `${this.url}${query}`;
    }
}
```

#### ComboBox をリモート サービスにバインド

サービスの Observable を `async` パイプで Combo にバインドし、Combo が <ApiLink type="Combo" member="dataPreLoad" label="dataPreLoad" /> を発生させたとき、または検索テキストが変更されたときに、新しい項目のチャンクを要求します。

```html
<igx-combo #remoteCombo
    [data]="rData | async"
    valueKey="ProductID"
    displayKey="ProductName"
    (dataPreLoad)="onDataPreLoad()"
    (searchInputUpdate)="onSearchInputUpdate($event)">
    <label igxLabel>Products</label>
</igx-combo>
```

```typescript
// The size of the first chunk, requested before the Combo reports how many items it shows.
const FIRST_CHUNK_SIZE = 10;

// The component lists RemoteNWindService in its providers, and the application
// providers include provideHttpClient(), which the service needs.
export class ComboRemoteComponent implements OnInit {
    @ViewChild('remoteCombo', { static: true })
    public remoteCombo: IgxComboComponent;

    private remoteService = inject(RemoteNWindService);
    public rData = this.remoteService.remoteData;
    private searchText = '';

    public ngOnInit() {
        this.loadChunk({ startIndex: 0, chunkSize: FIRST_CHUNK_SIZE });
    }

    // The Combo asks for the next chunk while the user scrolls.
    public onDataPreLoad() {
        this.loadChunk(this.remoteCombo.virtualizationState);
    }

    // The server filters the items: request the first chunk of the matching ones.
    public onSearchInputUpdate(event: IComboSearchInputEventArgs) {
        this.searchText = event.searchText;
        this.loadChunk({ startIndex: 0, chunkSize: FIRST_CHUNK_SIZE });
    }

    private loadChunk(state: IForOfState) {
        this.remoteService.getData(state, this.searchText, (data) => {
            // The total count sizes the scrollbar for all the items, not only the loaded chunk.
            this.remoteCombo.totalItemCount = data['@odata.count'];
        });
    }
}
```

#### 選択の処理

チャンク単位で読み込まれるリモート データに Combo をバインドし、データ項目がオブジェクトである場合は、<ApiLink type="Combo" member="valueKey" label="valueKey" /> プロパティを設定します。設定しないと、[Combo トピック](./overview.mdx#データ-バインディング)で説明しているように、Combo は選択された項目と読み込まれた項目を参照で比較します。サービスがチャンクを読み込むたびに新しいオブジェクトが作成されるため、Combo は選択された項目をそれらと照合できません。

<DocsAside type="info">
Combo をリモート データにバインドするときは、`valueKey` プロパティに、各項目で一意となるプロパティを設定します。
</DocsAside>

#### Combo をリモート サービスにバインド

`igniteui-webcomponents/extras/combo-data-source` から `bindComboDataSource()` をインポートし、Combo と `load()` 関数を持つソースを渡します。バインディングは、`searchText`、`caseSensitive`、`startIndex`、`count` を保持するリクエストと `AbortSignal` を指定して、ページごとに `load()` を呼び出します。`load()` からは、そのページの項目と、一致する項目の合計数を返してください。

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-combo id="combo" label="Products" value-key="ProductID" display-key="ProductName"></igc-combo>
```

```ts
import { defineComponents, IgcComboComponent } from 'igniteui-webcomponents';
import { bindComboDataSource } from 'igniteui-webcomponents/extras/combo-data-source';

defineComponents(IgcComboComponent);

interface Product {
    ProductID: number;
    ProductName: string;
}

const url = 'https://services.odata.org/V4/Northwind/Northwind.svc/Products';
const combo = document.getElementById('combo') as IgcComboComponent<Product>;

const binding = bindComboDataSource(combo, {
    // Loads one page of the products that match the search text.
    load: async ({ searchText, startIndex, count }, signal) => {
        let query = `?$skip=${startIndex}&$top=${count}&$count=true`;
        if (searchText) {
            // Double the apostrophes for OData, then encode the text for the URL.
            const text = encodeURIComponent(searchText.replace(/'/g, "''"));
            query += `&$filter=contains(ProductName, '${text}')`;
        }

        // The signal lets a newer search abort this request.
        const response = await fetch(`${url}${query}`, { signal });
        const data = await response.json();
        return { items: data.value, totalCount: data['@odata.count'] };
    }
}, {
    // The service returns up to 20 products per request.
    pageSize: 20
});
```

</PlatformBlock>

<PlatformBlock for="React">

React では、`IgrCombo` の `ref` が保持する要素を渡し、コンポーネントのアンマウント時にバインディングを破棄します。

```tsx
import { useEffect, useRef } from "react";
import { IgrCombo } from "igniteui-react";
import { bindComboDataSource } from "igniteui-webcomponents/extras/combo-data-source";

const url = "https://services.odata.org/V4/Northwind/Northwind.svc/Products";

export default function RemoteCombo() {
  const comboRef = useRef<IgrCombo>(null);

  useEffect(() => {
    const binding = bindComboDataSource(comboRef.current!, {
      // Loads one page of the products that match the search text.
      load: async ({ searchText, startIndex, count }, signal) => {
        let query = `?$skip=${startIndex}&$top=${count}&$count=true`;
        if (searchText) {
          // Double the apostrophes for OData, then encode the text for the URL.
          const text = encodeURIComponent(searchText.replace(/'/g, "''"));
          query += `&$filter=contains(ProductName, '${text}')`;
        }

        // The signal lets a newer search abort this request.
        const response = await fetch(`${url}${query}`, { signal });
        const data = await response.json();
        return { items: data.value, totalCount: data["@odata.count"] };
      }
    }, {
      // The service returns up to 20 products per request.
      pageSize: 20
    });

    return () => binding.dispose();
  }, []);

  return <IgrCombo ref={comboRef} label="Products" valueKey="ProductID" displayKey="ProductName" />;
}
```

<PlatformBlock for="React,WebComponents">

バインディングは Combo をリモート フィルタリングに切り替え、次のようにリクエストを行います。

- 項目のないリストをユーザーが開いたときに最初のページを読み込み、ユーザーが検索入力への入力を止めた後にも最初のページを読み込み直します。
- ユーザーが読み込み済みの項目の末尾付近までスクロールすると、次のページを追加します。
- `load()` が `fetch()` に渡すシグナルによって、新しい検索で古くなったリクエストを中止します。
- Combo の `totalItemCount` プロパティに合計数を設定し、検索の待機中またはページの読み込み中は `loading` プロパティを設定します。

Combo が保持する項目数が `totalItemCount` より少ない間、リストはまだ読み込まれていない各項目のプレースホルダーを表示するため、スクロール バーには結果の全長が反映されます。`loading` が設定されている間、Combo はトグル アイコンの代わりにスピナーを表示します。スピナーは `loading` スロットで置き換え、スピナーとプレースホルダーのスタイルは `loading` および `placeholder` CSS パーツで設定します。

`bindComboDataSource()` の 3 番目の引数でバインディングを構成します。

| オプション | 既定値 | 説明 |
|---|---|---|
| `pageSize` | `50` | 1 回のリクエストで読み込む項目の最小数。ソースはこれより少ない数 (サーバーのページ上限までなど) を返すこともでき、その場合 Combo は残りを要求します。 |
| `debounce` | `300` | 入力が止まってから検索を読み込むまでの待機時間 (ミリ秒)。 |
| `loadOnOpen` | `true` | 項目のないリストをユーザーが開いたときに最初のページを読み込むかどうか。 |
| `onError` | - | 失敗したリクエストのエラーを受け取ります。Combo は読み込み済みの項目を保持します。 |

`bindComboDataSource()` は、2 つのメソッドを持つバインディングを返します。`refresh()` は現在の検索の最初のページを再度読み込みます。コードで `filteringOptions.caseSensitive` を変更した後に呼び出してください。`dispose()` はリスナーを削除し、進行中のリクエストを中止して、Combo のフィルタリング モードを元に戻します。

#### リモート フィルタリング モード

`bindComboDataSource()` は Combo のパブリック API のみを使用します。リクエストを自分で行うには、<ApiLink type="Combo" member="filteringOptions" label="filteringOptions" /> の `mode` に `remote` を設定します。

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
combo.filteringOptions = { mode: 'remote' };
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
// In an effect, once the Combo has rendered.
comboRef.current!.filteringOptions = { mode: "remote" };
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

リモート モードでは、Combo は検索をサービスに任せます。

- Combo はオプションをフィルタリングしなくなります。`igcSearchInput` イベントの `detail.searchText` を読み取り、サーバーで検索して、<ApiLink type="Combo" member="data" label="data" /> に結果の最初のページを設定します。一致の判定はサーバーが行うため、検索と一緒に `filteringOptions.caseSensitive` を送信してください。
- ユーザーが `data` の末尾付近までスクロールすると、`igcDataRequest` イベントが `detail.startIndex` から `detail.count` 件の追加項目を要求します。それらを `data` に追加します。
- `totalItemCount` に結果の合計数を設定し、リクエストの実行中は `loading` を設定します。

#### 選択の処理

Combo がリモート データを読み込む場合は、<ApiLink type="Combo" member="valueKey" label="valueKey" /> を設定します。ページごとに新しいオブジェクトが作成され、Combo は選択された項目とそれらのオブジェクトをそのキーの値で照合します。新しい `data` を設定しても選択は保持されます。検索結果に選択された項目が含まれない場合も選択されたままとなり、後のページや検索に含まれると再び選択済みとして表示されます。

保存済みフィルターの値など、どのページにもまだ項目が読み込まれていない値を選択するには、`bindComboDataSource()` のソースに `resolve()` 関数を追加します。バインディングはそれらの値を指定して `resolve()` を呼び出し、返された項目を選択します。

Combo は、選択された項目をサーバーが削除したのか、その項目を含むページをまだ送信していないだけなのかを判別できません。ライブ データを再度読み込むときは、サーバーに存在しなくなった選択済み項目に対して <ApiLink type="Combo" member="deselect" label="deselect()" /> を呼び出してください。

</PlatformBlock>

### カスタム オーバーレイ設定

Combo は項目のリストをオーバーレイに表示します。オーバーレイは、<ApiLink kind="interface" type="OverlaySettings" label="OverlaySettings" /> を <ApiLink type="Combo" member="overlaySettings" label="overlaySettings" /> 入力プロパティに渡して構成できます。Combo はこれらの設定を既定値にマージするため、変更したい設定のみを指定します。次の設定では、リストをモーダルにして背後のページを暗くし、ユーザーがリストの外側をクリックしたときにリストを閉じます。

```typescript
import { OverlaySettings } from 'igniteui-angular/core';
// import { OverlaySettings } from '@infragistics/igniteui-angular/core'; for licensed package

export class ComboOverlayComponent {
    public overlaySettings: OverlaySettings = {
        modal: true,
        closeOnOutsideClick: true
    };
}
```

```html
<igx-combo [data]="people" [overlaySettings]="overlaySettings"></igx-combo>
```

### フィルタリング

{Platform} Combo は、ユーザーがドロップダウンの検索入力に入力するのに合わせて、オプションのリストをフィルタリングします。フィルタリングは既定で有効です。<ApiLink type="Combo" member="disableFiltering" label="disableFiltering" /> を設定するとフィルタリングが無効になり、検索入力も非表示になります。

<PlatformBlock for="Angular">

ユーザーが検索の大文字と小文字の区別を切り替えられるようにするには、<ApiLink type="Combo" member="showSearchCaseIcon" label="showSearchCaseIcon" /> を設定します。これにより、Combo の検索入力に大文字と小文字を区別するアイコンが表示されます。フィルタリングが無効な間は検索入力が非表示のため、このアイコンは効果がありません。

```html
<!-- Shows the case-sensitive icon in the search input -->
<igx-combo [showSearchCaseIcon]="true"></igx-combo>

<!-- Turns filtering off, which also hides the search input -->
<igx-combo [disableFiltering]="true"></igx-combo>
```

</PlatformBlock>

</PlatformBlock>


</PlatformBlock>

#### フィルタリング オプション

<ApiLink type="Combo" member="filteringOptions" label="filteringOptions" /> プロパティは、{Platform} Combo が検索テキストを照合する方法を構成します。

<PlatformBlock for="Angular">

- `filteringKey` - 検索対象のデータ フィールド。既定値は `displayKey` で設定されたフィールドです。
- `caseSensitive` - 検索で大文字と小文字を区別するかどうか。既定値は `false` です。大文字と小文字を区別するアイコンがこの値を切り替えます。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

- `filterKey` - 検索対象のデータ フィールド。既定値は `displayKey` で設定されたフィールドです。
- `caseSensitive` - 検索で大文字と小文字を区別するかどうか。既定値は `false` です。大文字と小文字を区別するアイコンがこの値を切り替えます。
- `matchDiacritics` - アクセント付き文字を自身にのみ一致させるかどうか。`true` の場合、`é` は `e` に一致しません。既定値は `false` です。

</PlatformBlock>

<PlatformBlock for="Blazor">

Blazor では、これらのオプションを `IgbFilteringOptions` オブジェクトで `FilterKey`、`CaseSensitive`、`MatchDiacritics` として設定します。

</PlatformBlock>

次のスニペットでは、各州の名前ではなく地域を検索対象にし、大文字と小文字を区別して検索します。

<PlatformBlock for="Angular">

```typescript
import { IComboFilteringOptions } from 'igniteui-angular/combo';
// import { IComboFilteringOptions } from '@infragistics/igniteui-angular/combo'; for licensed package

export class ComboDemo {
    public filteringOptions: IComboFilteringOptions = {
        filteringKey: 'region',
        caseSensitive: true

}
```

```html
<igx-combo [filteringOptions]="filteringOptions"></igx-combo>
```

</PlatformBlock>

```razor
        CaseSensitive = true
    };

```

</PlatformBlock>


</PlatformBlock>

#### 並べ替え方向

<PlatformBlock for="Angular">

<ApiLink type="Combo" member="groupSortingDirection" label="groupSortingDirection" /> プロパティは、Combo 内のグループの順序を設定します。`SortingDirection.Asc` (既定) は昇順、`SortingDirection.Desc` は降順に並べ替え、`SortingDirection.None` は各グループの先頭の項目がデータ内に現れる順にグループを並べます。各グループ内の項目は、データ内の順序のままです。

```typescript
import { SortingDirection } from 'igniteui-angular/core';
// import { SortingDirection } from '@infragistics/igniteui-angular/core'; for licensed package

export class ComboDemo {
    public groupSortingDirection = SortingDirection.Desc;
}
```

```html
<igx-combo groupKey="region" [groupSortingDirection]="groupSortingDirection"></igx-combo>
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

<ApiLink type="Combo" member="groupSorting" label="groupSorting" /> プロパティは、{Platform} Combo 内のグループの順序を設定します。`asc` (既定) は昇順、`desc` は降順に並べ替え、`none` は各グループの先頭の項目がデータ内に現れる順にグループを並べます。各グループ内の項目は、データ内の順序のままです。

</PlatformBlock>
