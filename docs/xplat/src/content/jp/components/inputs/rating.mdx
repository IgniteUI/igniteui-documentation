# Rating (評価)

{ProductName} Rating は、ユーザーが星またはカスタム シンボルのスケールでスコアを表示および選択できるフォーム関連のコンポーネントです。

<PlatformBlock for="Angular">

Angular では、Rating は `igniteui-webcomponents` の `igc-rating` Web コンポーネントです。`IgcFormControlDirective` を使用して Angular フォームにバインドします。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Rating は、半星などの小数値、ホバー プレビュー、個別シンボルの単一選択、およびキーボードによる完全な入力をサポートします。

</PlatformBlock>

## 構造

Rating はラベルと値で構成されます。値は評価スケールの数値です。ラベルは `label` を設定すると表示されます。`max` を設定すると、シンボルの数を変更できます (既定値は 5)。

`igc-rating` 要素は、ラベルと、シンボルを保持するスライダーをレンダリングします。シンボルが投影されていない場合は、`max` の各ポイントに対して 1 つの星をレンダリングします。

```text
igc-rating
└─ #shadow-root
   ├─ label[part="label"]                    // hidden when label isn't set
   └─ div[part="base"][role="slider"]
      ├─ div[part="symbols"]                 // aria-hidden="true"
      │  └─ slot[name="symbol"]              // projected igc-rating-symbol elements
      │     └─ igc-rating-symbol × max       // default stars when nothing is projected
      │        └─ #shadow-root
      │           ├─ div[part="symbol full"]   // star_filled icon, clipped to the value
      │           └─ div[part="symbol empty"]  // star_outlined icon, clipped to the rest
      └─ label[part="value-label"]
         └─ slot[name="value-label"]         // hidden when the slot is empty
```

各 `igc-rating-symbol` は、既定のスロットを `full` パートに、`empty` スロットを `empty` パートにレンダリングします。

## 使用方法

{Platform} Rating は、製品、サービス、または体験のスコアを収集する場合や、ユーザーが変更できない平均スコアを表示する場合に使用します。

### ホバー プレビュー

`hoverPreview` を設定すると、ユーザーがクリックする前に、ポインターの下の値までシンボルが塗りつぶされます。ポインターがシンボルから離れると、{Platform} Rating は元の値を表示します。読み取り専用または無効な Rating では、プレビューは表示されません。

<PlatformBlock for="WebComponents">

プレビューがオンの間、Rating はポインターの下の値とともに `igcHover` を発行します。

```html
<igc-rating hover-preview label="Rate this article"></igc-rating>
<span id="hint"></span>
```

```ts
const rating = document.querySelector('igc-rating')!;
const hint = document.getElementById('hint')!;

rating.addEventListener('igcHover', (event) => {
  hint.textContent = `${event.detail} stars`;
});
```

</PlatformBlock>

<PlatformBlock for="React">

プレビューがオンの間、Rating はポインターの下の値とともに `onHover` を呼び出します。

```tsx
<IgrRating
  hoverPreview={true}
  label="Rate this article"
  onHover={(e: CustomEvent<number>) => setHint(`${e.detail} stars`)}
/>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

プレビューがオンの間、Rating はポインターの下の値とともに `Hover` を発生させます。

```razor
<IgbRating HoverPreview="true" Label="Rate this article" Hover="OnHover" />

@code {
    private string Hint { get; set; }

    private void OnHover(IgbNumberEventArgs e)
    {
        Hint = $"{e.Detail} stars";
    }
}
```

</PlatformBlock>

<PlatformBlock for="Angular">

プレビューがオンの間、Rating はポインターの下の値とともに `igcHover` を発行します。

```html
<igc-rating hover-preview label="Rate this article" (igcHover)="onHover($event)"></igc-rating>
```

```ts
public hint = '';

public onHover(event: Event) {
    this.hint = `${(event as CustomEvent<number>).detail} stars`;
}
```

</PlatformBlock>

### レイアウト

`label` プロパティは、シンボルの上に表示ラベルをレンダリングし、支援技術に対して {Platform} Rating に名前を付けます。現在のスコアなど、シンボルの横にカスタム コンテンツを表示するには、`value-label` スロットに配置します。

</PlatformBlock>

### 空/満たされた状態

{Platform} Rating の `value` は、シンボルがどの程度満たされるかを設定します。既定値の 0 ではすべてのシンボルが空になり、`max` と等しい値ではすべてのシンボルが満たされます。

<PlatformBlock for="WebComponents">

```html

```

```ts
const rating = document.querySelector('igc-rating')!;

rating.addEventListener('igcChange', (event) => {
  console.log(`New rating: ${event.detail}`);
});
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
      value={score}
      max={10}
      label="Rate this movie"

}
```

### サイズ

### シンボル

既定では、{Platform} Rating は星のアイコンをレンダリングします。他のシンボルを使用するには、スケールの各ポイントに対して <PlatformBlock for="Angular">`igc-rating-symbol` 要素</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor"><ApiLink pkg="core" type="RatingSymbol" /></PlatformBlock> を 1 つずつ Rating の内側に配置します。各評価シンボルは、値が覆う部分に既定のスロット コンテンツを、残りの部分に `empty` スロット コンテンツを表示します。そのため、同じコンテンツであっても両方のスロットを埋めてください。評価シンボルの数が `max` を設定し、Rating は設定した `max` を無視します。

<PlatformBlock for="WebComponents">

次の Rating は、登録済みのハート アイコンを使用します。最初に、[Icon](../layouts/icon.mdx) トピックで説明されているようにアイコンを登録します。


### フォーム

Rating を `ngModel` または `formControlName` にバインドするには、Angular の `ControlValueAccessor` インターフェイスの実装が必要です。{ProductName} は、これをスタンドアロンの `IgcFormControlDirective` として提供しており、`ngModel` または `formControlName` を持つ `igc-rating` 要素にアタッチされます。`FormsModule` または `ReactiveFormsModule` とともにインポートします。

```ts
        <form>
```

</PlatformBlock>

## アクセシビリティ

{Platform} Rating はスライダーです。ユーザーは Tab キーで移動し、矢印キーで値を変更し、ARIA 属性を通じて値を聞き取ります。

### キーボード操作

{Platform} Rating は、内部のスライダー要素 (`base` パート) のみがフォーカスを受け取るため、タブ ストップは 1 つです。無効な Rating はタブ順序から外れます。読み取り専用の Rating はタブ順序に残りますが、次のキーを無視するため、ページのスクロールなど、ブラウザーの既定の動作がそのまま維持されます。

| キー | 動作 |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | 次または前のフォーカス可能な要素にフォーカスを移動します。Rating はこれらのキーを処理しないため、フォーカスがトラップされることはありません。 |
| <kbd>Arrow Right</kbd> | 値を 1 ステップ増やします。右から左のレイアウトでは減らします。 |
| <kbd>Arrow Left</kbd> | 値を 1 ステップ減らします。右から左のレイアウトでは増やします。 |
| <kbd>Arrow Up</kbd> | 値を 1 ステップ増やします。 |
| <kbd>Arrow Down</kbd> | 値を 1 ステップ減らします。 |
| <kbd>Home</kbd> | 値を 1 ステップに設定します。これはクリックで選択できる最小値です。 |
| <kbd>End</kbd> | 値を最大値に設定します。 |

{Platform} Rating は、`keydown` でこれらのキーを次のように処理します。

- 既定の動作を防止するため、Rating にフォーカスがある間、矢印キー、Home、End でページはスクロールしません。
- キーを押し続けると、その動作が繰り返されます。
- Shift、Ctrl、Alt、Meta と同時に押したキーは何も行いません。
- 値は 0 から最大値の間に保たれます。値が境界を超えるキーは、値を保持し、イベントを発行しません。
- 値を変更する各キーは、変更イベントを発行します。

ポインターでは、クリックすると、ポインターの下の値が次のステップに切り上げられて選択されます。読み取り専用または無効な Rating は、クリックを無視します。

### スクリーン リーダー / ARIA

{Platform} Rating は、`slider` ロールを持つフォーカス可能な要素 (`base` パート) を 1 つレンダリングします。その `tabindex` は `0` で、Rating が無効な場合は `-1` になり、次の値の属性を持ちます。

| 属性 | 値 |
| --- | --- |
| `aria-valuemin` | `0` |
| `aria-valuemax` | 最大値 |
| `aria-valuenow` | `4.3` などの小数を含む値 |
| `aria-valuetext` | 既定では "3 of 5"、または `valueFormat` のテキスト |

<PlatformBlock for="React,WebComponents,Angular">

`igniteui-webcomponents` 7.3.0 以降では、スライダーは `aria-disabled` と `aria-readonly` も設定して、無効状態と読み取り専用状態を公開します。7.4.1 以降では、スライダーは次のうち最初に該当するものからアクセシブルな名前を取得します。

1. ホストの `aria-labelledby` 属性。
2. `for` でバインドされた、または Rating を囲んでいる `<label>` 要素。ラベルをクリックするとスライダーにフォーカスが移ります。
3. `label` プロパティ。スライダーが `aria-labelledby` で参照する表示ラベルをレンダリングします。
4. ホストの `aria-label` 属性。`label` プロパティが設定されている場合、スライダーはこれを無視します。

</PlatformBlock>

<PlatformBlock for="Blazor">

`Label` プロパティは、スライダーが `aria-labelledby` で参照する表示ラベルをレンダリングし、これによりスライダーにアクセシブルな名前が付きます。

</PlatformBlock>

{Platform} Rating は、支援技術に対して次のようにも動作します。

- `symbols` パートは `aria-hidden="true"` を設定するため、投影されたアイコンや絵文字を含むシンボルは非表示になり、代替テキストは不要です。値は、`aria-valuenow` と `aria-valuetext` を通じてのみ支援技術に伝わります。
- `value-label` スロットはスライダーの内部にレンダリングされます。スクリーン リーダーは `aria-valuetext` から値を読み上げるため、スロットのコンテンツではなく `valueFormat` で値を説明してください。
- Rating はライブ リージョンを使用しません。変更された値は、スライダーの属性を通じてのみ支援技術に伝わります。
- Rating は `aria-invalid` を設定しないため、カスタム検証メッセージは無効状態として公開されません。

### アクセシビリティ準拠

Infragistics は、{ProductName} のアクセシビリティ サポートについて、Section 508 と WCAG 2.1 ガイドライン領域を[アクセシビリティ準拠](../interactivity/accessibility-compliance.mdx)トピックで説明しています。

| 基準 | コンポーネントの準拠方法 |
| --- | --- |
| [1.1.1 Non-text Content](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content) | シンボルは支援技術から非表示になり、スライダーは `aria-valuetext` を通じて値をテキストとして公開します。 |
| [1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships) | `label` プロパティの表示ラベルは、`aria-labelledby` を通じてスライダーに関連付けられます。 |
| [1.4.1 Use of Color](https://www.w3.org/WAI/WCAG21/Understanding/use-of-color) | 既定のシンボルは、スケールの選択された部分に塗りつぶされた星を、それ以外に枠線の星を表示するため、値が色だけに依存しません。 |
| [2.1.1 Keyboard](https://www.w3.org/WAI/WCAG21/Understanding/keyboard) | 矢印キー、Home、End で値が変更されるため、ユーザーはポインターなしで評価できます。 |
| [2.1.2 No Keyboard Trap](https://www.w3.org/WAI/WCAG21/Understanding/no-keyboard-trap) | Rating はタブ ストップが 1 つで、Tab キーを処理しないため、Tab と Shift + Tab でフォーカスを外に移動できます。 |
| [2.4.7 Focus Visible](https://www.w3.org/WAI/WCAG21/Understanding/focus-visible) | Rating テーマは、フォーカスされたスライダーからブラウザーのフォーカス インジケーターを削除しません。 |
| [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | スライダーは、`slider` ロール、`aria-valuenow` と `aria-valuetext` による値、および指定した名前を公開します。<PlatformBlock for="React,WebComponents,Angular">`igniteui-webcomponents` 7.3.0 以降では、無効状態と読み取り専用状態も公開します。</PlatformBlock> |

ユーザー側の責任:

- すべての Rating に名前を付けます (`label` プロパティ<PlatformBlock for="React,WebComponents,Angular">、関連付けられた `<label>` 要素、または `aria-label`</PlatformBlock>)。[レイアウト](#レイアウト)を参照してください。
- "3 of 5" がスケールを説明していない場合や、ページが別の言語を使用する場合は、`valueFormat` を設定します。
- カスタム シンボルでは、満たされたシンボルと空のシンボルを、色だけでなく形や塗りつぶしでも区別できるようにし、[1.4.11 Non-text Contrast](https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast) の要件に従って、背景に対して 3:1 以上のコントラスト比を維持します。
- `base` パートのスタイルを変更する場合は、表示されるフォーカス インジケーターを維持します。
- ポインターのターゲットを十分な大きさに保ちます。各値は、1 つのシンボルの幅、またはステップが 0.5 の場合はシンボルの半分の幅のターゲットです。小サイズは 18px のシンボルをレンダリングし、[2.5.8 Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum) の 24 x 24 CSS ピクセルを下回るため、ポインターおよびタッチ入力には中サイズまたは大サイズを推奨します。
- キーボード ユーザーには見えないため、ホバー プレビューだけに情報を載せないでください。
- カスタム検証メッセージで Rating を検証する場合は、Rating は `aria-invalid` を設定しないため、[3.3.1 Error Identification](https://www.w3.org/WAI/WCAG21/Understanding/error-identification) の要件に従って、Rating の横にメッセージをテキストとして表示してください。

[WAI-ARIA スライダー パターン](https://www.w3.org/WAI/ARIA/apg/patterns/slider/)との相違点:

- <kbd>Home</kbd> は、値を `aria-valuemin` (0) ではなく 1 ステップに設定します。0 にするには <kbd>Arrow Down</kbd> を使用します。
- Rating は、パターンでオプションのキーとされている <kbd>Page Up</kbd> と <kbd>Page Down</kbd> をサポートしません。

## トラブルシューティング

{Platform} Rating が期待どおりに動作しない場合は、次の回答を参照してください。

### 値を設定しても change イベントが発生しないのはなぜですか?

{Platform} Rating は、ユーザー入力 (クリックまたはキー) に対してのみ change イベントを発行します。コードで値を設定したり、ステップ メソッドを呼び出したりすると、イベントなしで値が変更されるため、値を設定する場所で独自の状態を更新してください。

### 現在の値をクリックしても Rating がリセットされないのはなぜですか?

{Platform} Rating は、`allowReset` を設定しない限り、現在の値をクリックしても値を保持します。`igniteui-webcomponents` 4.7.0 より前は、現在の値をクリックすると常に Rating がリセットされました。アップグレード後もその動作を維持するには、`allowReset` を設定します。

### hover イベントが発生しないのはなぜですか?

{Platform} Rating は、`hoverPreview` がオンの間のみ hover イベントを発行し、Rating が読み取り専用または無効な場合は発行しません。イベントを受け取るには `hoverPreview` を設定します。
