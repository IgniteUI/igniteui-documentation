# Chip コンポーネント

{ProductName} Chip は、タグ、フィルター、人物を表すコンパクトな要素で、ユーザーが選択または削除できます。

Chip は、選択可能、削除可能、またはその両方にすることができ、ラベルの前後にアイコンやその他のコンテンツを表示できます。

### 前提条件とバージョンの互換性

{Platform} Chip の一部の機能は、アプリケーションが使用するパッケージのバージョンに依存します。

<PlatformBlock for="WebComponents">

- `outlined` プロパティは {PackageWebComponents} 7.3.0 以降で使用できます。
- `action` パーツと `remove` パーツは 7.3.1 以降で使用できます。以前のバージョンでは、`base` パーツが選択ボタンであり、削除アイコンはその内部にレンダリングされます。
- `start` スロットと `end` スロットは 7.3.1 以降でドキュメント化されています。以前のバージョンではレンダリングされますが、ドキュメント化されていません。

</PlatformBlock>

<PlatformBlock for="React">

`igniteui-react` パッケージを `igniteui-webcomponents` のテーマ スタイルシートと併用します。React Chip は `igc-chip` Web コンポーネントをラップするため、使用可能なプロパティ、スロット、パーツは `igniteui-react` が使用する `igniteui-webcomponents` のバージョンに従います。

</PlatformBlock>

<PlatformBlock for="Blazor">

`IgniteUI.Blazor` パッケージを使用します。`IgniteUI.Blazor` 26.1 には、Chip の以前のバージョンが含まれています:

- `IgbChip` は、`Outlined`、`Locale`、`ResourceStrings` プロパティを公開しません。
- `base` パーツが選択ボタンであり、削除アイコンはその内部にレンダリングされます。Chip には `action` パーツも `remove` パーツもありません。
- フォーカス スタイルは `--ig-chip-focus-outline-color` と `--ig-chip-focus-selected-outline-color` を読み取ります。
- キーボードとスクリーン リーダーの動作は、[アクセシビリティ](#アクセシビリティ)で説明されているとおり異なります。

</PlatformBlock>

<PlatformBlock for="Angular">

`igniteui-angular` パッケージを使用します。`outlined` 入力は 22.2.0 以降で使用できます。

</PlatformBlock>

## 使用方法

{Platform} Chip にラベルを追加し、レイアウトに応じてアイコン、タイプ、サイズ、選択または削除を追加します。

</PlatformBlock>

<PlatformBlock for="Angular">

### サイズ

<PlatformBlock for="WebComponents, React, Blazor">

```tsx
  <IgrChip key={tag} removable onRemove={() => setTags((current) => current.filter((item) => item !== tag))}>
```

```ts

  { id: 'angular', text: 'Angular' },
```

### Chips エリア

<PlatformBlock for="Angular">

<ApiLink pkg="core" type="ChipsArea" /> コンポーネントを使用して、Chip のコレクションを整理します。

<Sample src="/data-display/chip-area" showThemePicker height={165} alt="{Platform} Chips エリアの例" />

Chips エリア内では、矢印キーで Chip 間のフォーカスを移動します。ユーザーが `draggable` な Chip を別の Chip の上にドラッグするか、<kbd>Shift</kbd> と矢印キーを押すと、Chips エリアは新しい順序とともに `reorder` を発生させます。また、選択された Chip とともに `selectionChange` も発生させます。Chips エリア自体は Chip を並べ替えないため、`reorder` ハンドラーで新しい順序をデータに適用してください。

```html
<igx-chips-area (reorder)="onReorder($event)">
  @for (chip of chips; track chip.id) {
    <igx-chip [id]="chip.id" [draggable]="true">{{ chip.text }}</igx-chip>
  }
</igx-chips-area>
```

```ts
import { IChipsAreaReorderEventArgs } from 'igniteui-angular/chips';

public onReorder(event: IChipsAreaReorderEventArgs) {
  this.chips = event.chipsArray.map((chip) => this.chips.find((item) => item.id === chip.id)!);
}
```

## アクセシビリティ

{Platform} Chip は、キーボード操作をサポートし、その状態を支援技術に公開します。

### キーボード操作

キーボード ユーザーは <kbd>Tab</kbd> で各 Chip に移動し、Chip が削除可能な場合は続けてその削除コントロールに移動します。無効な Chip はスキップされます。

<PlatformBlock for="WebComponents, React">

| キー | アクション |
| -- | -- |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | 選択ボタンでは、`selectable` が設定されている場合に `selected` を切り替え、選択イベントを発生させます。削除コントロールでは、削除イベントを発生させます。 |

</PlatformBlock>

<PlatformBlock for="Blazor">

| キー | アクション |
| -- | -- |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | 削除可能な Chip では、`Selectable` が設定されている場合に `Selected` を切り替え、選択イベントを発生させます。削除アイコンでは、削除イベントを発生させます。 |

`IgniteUI.Blazor` 26.1 では、削除可能でない Chip で <kbd>Space</kbd> を押しても選択は切り替わらず、<kbd>Enter</kbd> を押すと選択が切り替わり、削除イベントも発生します。

</PlatformBlock>

<PlatformBlock for="Angular">

| キー | アクション |
| -- | -- |
| <kbd>Space</kbd> | Chip で、`selectable` が設定されている場合に `selected` を切り替えます。 |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | 削除コントロールで、`remove` を発生させます。 |
| <kbd>Delete</kbd> | 削除可能な Chip で、`remove` を発生させます。 |

</PlatformBlock>

### スクリーン リーダー / ARIA

{Platform} Chip は、ネイティブ セマンティクスと ARIA 属性を通じて状態を公開します<PlatformBlock for="WebComponents, React, Angular">。また、アクセシブルな名前はそのコンテンツから取得されます</PlatformBlock>。

<PlatformBlock for="WebComponents, React">

- 選択コントロールはネイティブの `button` です。`selectable` が設定されている場合、`aria-pressed` が `selected` 状態を反映します。
- デフォルトの選択アイコンは、`aria-pressed` が選択状態を既に伝えているため、支援技術からは非表示になります。
- デフォルトの削除アイコンは、`role="button"`、`tabindex="0"`、およびデフォルトが "remove chip" の `aria-label` を持つ個別のコントロールです。
- 無効な Chip はネイティブ ボタンを無効にするため、支援技術は Chip を利用不可として報告します。

</PlatformBlock>

<PlatformBlock for="Blazor">

- Chip はネイティブの `button` です。`Selectable` が設定されている場合、`aria-pressed` が `Selected` 状態を反映します。
- デフォルトの選択アイコンには、`aria-label` "select chip" があります。
- デフォルトの削除アイコンは、`role="button"`、`tabindex="0"`、`aria-label` "remove chip" を持ち、Chip のボタン内にレンダリングされるため、入れ子になったコントロールです。
- アイコンがボタン内にレンダリングされるため、Chip のアクセシブルな名前にはそれらのラベルが含まれます (例: "Chip remove chip")。
- 無効な Chip はネイティブ ボタンを無効にするため、支援技術は Chip を利用不可として報告します。

</PlatformBlock>

<PlatformBlock for="Angular">

- Chip ホストには `role="option"` があり、`aria-selected` が `selected` 状態を反映します。
- `igx-chips-area` 要素には `role="listbox"` と `aria-label` "chip area" があります。
- デフォルトの選択アイコンと削除アイコンには、アクセシブルなラベルがあります。
- 無効な Chip はタブ順序から除外されますが、無効状態を公開する ARIA 属性はありません。

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Angular">

デフォルト アイコンのラベルは、[ローカライズ](#ローカライズ)で示すように変更できます。

</PlatformBlock>

## トラブルシューティング

変更やアップグレードの後に Chip が期待どおりに動作しない、または表示されない場合は、このセクションを参照してください。

### 削除アイコンをクリックしても Chip がページに残るのはなぜですか?

削除イベントはアプリケーションに通知するだけです。[Chip の削除](#chip-の削除)に示すように、イベント ハンドラーで Chip を削除してください。

<PlatformBlock for="WebComponents, React">

### アップグレード後に `::part(base)` のスタイルが変わったのはなぜですか?

`igniteui-webcomponents` 7.3.1 以降、`base` パーツは Chip のラッパー、選択ボタンは `action` パーツ、削除コントロールは `remove` パーツになりました。ボタンを対象にしていたスタイルは、`::part(action)` に移動してください。

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Angular">

### フォーカス アウトライン変数が適用されなくなったのはなぜですか?

</PlatformBlock>

<PlatformBlock for="WebComponents, React">

`--ig-chip-focus-outline-color` 変数と `--ig-chip-focus-selected-outline-color` 変数は、`igniteui-webcomponents` 7.3.0 で `--ig-chip-focus-shadow-color` と `--ig-chip-focus-selected-shadow-color` に置き換えられました。スタイル内の変数名を変更してください。

</PlatformBlock>

<PlatformBlock for="Angular">

`igniteui-angular` 22.2.0 では、`chip-theme` の `$focus-outline-color` パラメーターと `$focus-selected-outline-color` パラメーターが `$focus-shadow-color` と `$focus-selected-shadow-color` に置き換えられました。スタイル内のパラメーター、および対応する `--ig-chip-*` 変数の名前を変更してください。

</PlatformBlock>
