# Radio Group (ラジオ グループ)

{Platform} Radio と Radio Group は、相互に排他的なオプションのセットからユーザーが 1 つのオプションのみを選択できるようにするコンポーネントです。各ラジオ ボタンは 1 つのオプションを表し、Radio Group はラジオ ボタンを縦方向または横方向のレイアウトで配置します。

## 使用方法

### レイアウト

{Platform} Radio は、既定でラベルをラジオ コントロールの後に配置します。ラベルをコントロールの前に配置するには、<ApiLink pkg="core" type="Radio" member="labelPosition" label="labelPosition" /> プロパティを `before` に設定します。縦方向の Radio Group では、ラベルがコントロールの前にあるラジオ ボタンはグループの終端側に揃えられます。

<PlatformBlock for="React,WebComponents,Blazor">

ラジオ ボタンは Radio Group の直接の子として配置します。ラッパー要素内に配置した Radio はグループの一部にならず、グループによってレイアウトされません。

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-radio-group name="color">
  <igc-radio value="yellow" label-position="before" checked>Yellow</igc-radio>
  <igc-radio value="orange" label-position="before">Orange</igc-radio>
</igc-radio-group>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrRadioGroup name="color">
  <IgrRadio value="yellow" labelPosition="before" checked={true}>Yellow</IgrRadio>
  <IgrRadio value="orange" labelPosition="before">Orange</IgrRadio>
</IgrRadioGroup>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbRadioGroup name="color">

    <IgbRadio Value="orange" LabelPosition="ToggleLabelPosition.Before">Orange</IgbRadio>

```

</PlatformBlock>

<PlatformBlock for="Angular">

```html

  <igx-radio value="orange" labelPosition="before">Orange</igx-radio>
</igx-radio-group>
```

</PlatformBlock>

<PlatformBlock for="Angular,React,WebComponents">

### フォーム

{Platform} Radio は、選択されたラジオ ボタンの `value` を、グループの `name` に指定した名前で送信します。フォームの送信前に選択を必須にするには、グループ内のラジオ ボタンに <ApiLink pkg="core" type="Radio" member="required" label="required" /> プロパティを設定します。

<PlatformBlock for="React,WebComponents,Blazor">

選択されていないときにメッセージを表示するには、ラジオ ボタンの `value-missing` スロットにメッセージを配置します。必須の選択が行われていないと、グループ内のすべてのラジオ ボタンが無効 (invalid) になるため、メッセージをグループの下に表示するには、最後のラジオ ボタンに配置します。

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
    <igc-radio value="apple" required>Apple</igc-radio>
    <igc-radio value="banana">Banana</igc-radio>
    <igc-radio value="orange">
      Orange
      <span slot="value-missing">Choose a fruit.</span>
    </igc-radio>
  </igc-radio-group>
</form>
```

</PlatformBlock>

### Sass テーマ

<PlatformBlock for="Angular"><ApiLink kind="sass" module="themes" type="function-radio-theme" label="radio-theme" code={true} /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">`radio-theme`</PlatformBlock> 関数でテーマを作成し、`tokens` ミックスインで含めます。テーマが残りの色を `$empty-color` と `$fill-color` から派生させるため、この 2 つを設定するだけでラジオ ボタンのスタイルを完全に設定できます。

<PlatformBlock for="Angular">

```scss
}
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">


| プライマリ パラメーター | 依存パラメーター | 変更内容 |

| `$fill-color` | `$fill-color-hover`, `$fill-hover-border-color`, `$focus-border-color` (Bootstrap), `$focus-outline-color` (Bootstrap), `$focus-outline-color-filled` (Indigo) | チェック済みのラジオ ボタンの境界線とドット。 |

| `$error-color` | `$error-color-hover`, `$focus-outline-color-error` | 無効 (invalid) 状態のラベル、境界線、ドット。 |

## アクセシビリティ

{Platform} Radio はネイティブのラジオ入力をレンダリングするため、支援技術は各ラジオ ボタンをそのロール、ラベル、チェック状態とともに読み上げます。

### キーボード操作

{Platform} Radio Group では、矢印キーを使用して、有効なラジオ ボタン間でフォーカスと選択が移動します。無効なラジオ ボタンはスキップされます。

| キー | 動作 |
| --- | --- |
| Tab / Shift+Tab | Radio Group にフォーカスを移動するか、Radio Group からフォーカスを外します。 |
| Arrow Down / Arrow Right | 次の有効なラジオ ボタンにフォーカスを移動し、そのラジオ ボタンをオンにします。最後のラジオ ボタンからは最初のラジオ ボタンに移動します。右から左のレイアウトでは、Arrow Right で前のラジオ ボタンに移動します。 |
| Arrow Up / Arrow Left | 前の有効なラジオ ボタンにフォーカスを移動し、そのラジオ ボタンをオンにします。最初のラジオ ボタンからは最後のラジオ ボタンに移動します。右から左のレイアウトでは、Arrow Left で次のラジオ ボタンに移動します。 |
| Space | フォーカスされているラジオ ボタンをオンにします。 |
<PlatformBlock for="React,WebComponents,Blazor">| Enter | ラジオ ボタンを含むフォームを送信します。 |</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

グループ内のラジオ ボタンがオンの場合、そのラジオ ボタンがグループ内の唯一のタブ ストップになります。どのラジオ ボタンもオンでない場合は、各ラジオ ボタンがタブ ストップになります。

</PlatformBlock>

<PlatformBlock for="Blazor">

`IgniteUI.Blazor` 26.1 では、コードで選択をクリアすると、グループにタブ ストップがなくなります。[既知の制限](#既知の制限)を参照してください。

</PlatformBlock>

### スクリーン リーダー / ARIA

- 各 {Platform} Radio はネイティブの `<input type="radio">` をレンダリングし、radio ロール、チェック状態、無効状態、必須状態を公開します。<PlatformBlock for="Angular">入力要素は、`invalid` プロパティに基づいて `aria-invalid` も設定します。</PlatformBlock>
- ラジオ ボタンのラベル コンテンツが、そのアクセシブルな名前になります。<PlatformBlock for="Angular,React,WebComponents">ラベルがコンポーネントの外部にある場合は、`aria-labelledby` で関連付けます。</PlatformBlock>

<PlatformBlock for="React,WebComponents">

- Radio Group は `radiogroup` ロールをレンダリングし、`alignment` に基づいて `aria-orientation` を設定します。

</PlatformBlock>

<PlatformBlock for="Blazor">

- Radio Group は `radiogroup` ロールをレンダリングします。`IgniteUI.Blazor` 26.1 では、`aria-orientation` は設定されません。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

- Radio Group にアクセシブルな名前を付けます。たとえば、グループが回答する質問を `aria-labelledby` で参照します。

</PlatformBlock>

<PlatformBlock for="Angular">

- `igx-radio-group` 要素は `radiogroup` ロールをレンダリングしません。グループを 1 つの質問として読み上げる必要がある場合は、`role="radiogroup"` と、`aria-labelledby` などによるアクセシブルな名前を追加します。

</PlatformBlock>

### アクセシビリティ準拠

レンダリングされた {Platform} Radio と Radio Group が、アプリケーションのアクセシビリティ要件を満たしていることを確認してください。

| 基準 | コンポーネントが要件をサポートする方法 |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| [2.1.1 Keyboard](https://www.w3.org/WAI/WCAG21/Understanding/keyboard) | ユーザーは、矢印キーと Space キーを使用して有効なラジオ ボタン間を移動し、ラジオ ボタンをオンにします。 |
| [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | 各ラジオ ボタンは、ネイティブのラジオ入力を通じて、ラベルをアクセシブルな名前として公開し、radio ロールとチェック状態も公開します。 |

ユーザー側の責任:

- すべてのラジオ ボタンに意味のあるラベル コンテンツを指定し、Radio Group にアクセシブルな名前を付けます。
- Radio の色をカスタマイズする場合は、フォーカス リングを表示したままにし、十分なコントラストを維持します。
- エラーが色だけで伝わることのないように、Radio が無効 (invalid) な場合は検証メッセージを表示します。<PlatformBlock for="React,WebComponents,Blazor">[フォーム](#フォーム)で示したように、`value-missing` スロットを使用します。</PlatformBlock><PlatformBlock for="Angular">周囲のフォームにメッセージを表示します。</PlatformBlock>
- レンダリングされた Radio Group を、キーボードによる移動と、ユーザーが利用する支援技術でテストします。

<PlatformBlock for="Angular,Blazor">

## 既知の制限

</PlatformBlock>

<PlatformBlock for="Blazor">

{Platform} Radio と Radio Group には、次の既知の制限があります。

- Blazor では、Radio は標準の HTML `<form>` 要素では動作しません。代わりに Blazor の `EditForm` コンポーネントを使用してください。
- `IgniteUI.Blazor` 26.1 では、ラジオ ボタンの外部にある要素でラジオ ボタンにラベルを付けることはできません。`IgbRadio` には `AriaLabelledBy` パラメーターがなく、`aria-labelledby` 属性を指定してもラジオ ボタンにアクセシブルな名前は付きません。ラベル テキストはラジオ ボタンの内部に配置してください。
- `IgniteUI.Blazor` 26.1 では、コードで選択をクリアすると、すべてのラジオ ボタンがタブ順序から外れます。マウス クリックまたはコードによってグループ内のいずれかのラジオ ボタンが再びオンになるまで、キーボード ユーザーはグループに到達できません。

</PlatformBlock>

<PlatformBlock for="Angular">

{Platform} Radio と Radio Group には、次の既知の制限があります。

- `igx-radio-group` 要素は `radiogroup` ロールをレンダリングしません。要素にロールとアクセシブルな名前を手動で追加してください。

</PlatformBlock>
