# {Platform} オープン ストリート マップ画像の表示

{Platform} <ApiLink type="OpenStreetMapImagery" /> は、世界中の OpenStreetMap© のコントリビューターが共同で作成した無料の地理的画像マッピングサービスです。これは、構成オプションなしで、道路地図スタイル限定で世界の地理的画像を提供します。この地理的画像サービスは、<a href="http://www.openstreetmap.org" target="_blank">www.OpenStreetMap.org</a> に直接アクセスして利用できます。
デフォルトでは、{ProductName} マップ コンポーネントには、Open Street Maps の地理的画像が既に表示されています。したがって、Open Street Maps から地理的画像を表示するように、コントロールを構成する必要はありません。

## コード スニペット
このコード例では、マップ コンポーネントの <ApiLink type="GeographicMap" member="backgroundContent" label="BackgroundContent" /> を OpenStreetMap© コントリビューターの地理画像を提供する <ApiLink type="OpenStreetMapImagery" /> オブジェクトに明示的に設定します。

```json-snippet source="/maps/geo-map/display-osm-imagery"
{
    "type": "GeographicMap",
    "$setInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "$assignInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "backgroundContent": {
        "type": "OpenStreetMapImagery",
        "name": "osmImagery"
    },
    "$type": "+doc:markup"
}
```
