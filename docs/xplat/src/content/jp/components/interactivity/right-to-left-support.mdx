# 右から左 (RTL) サポート

{ProductName} コンポーネントは右から左 (RTL) のレイアウトをサポートします。ページに `dir="rtl"` を設定すると、コンポーネントのレイアウトとキーボード操作の大部分が反転します。RTL 用の別のテーマは必要ありません。

## 概要

{ProductName} は、標準の HTML `dir` 属性から方向を取得します。方向を設定するプロパティを持つコンポーネントはなく、テーマの RTL 版もありません。既に読み込んでいるテーマが両方の方向に対応します。

| レイヤー | 方向に従う仕組み |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **スタイル** | コンポーネントのスタイルは、`margin-inline-start` などの CSS 論理プロパティと方向セレクターを使用するため、方向が変わるとすぐにレイアウトが反転します。 |
| **操作** | Carousel、Slider、Stepper、Tabs など、水平方向のキーボード操作またはポインター操作を持つコンポーネントは、ユーザーが操作したときに方向を読み取ります。RTL では、<kbd>Arrow Left</kbd> キーと <kbd>Arrow Right</kbd> キーが読み順の方向に従います。 |

一部のコンポーネントは、方向に部分的にしか従いません。{Platform} での該当コンポーネントは、[既知の制限](#既知の制限)に記載されています。

## はじめる前に

**RTL はレイアウトを反転するもので、テキストを翻訳するものではありません。** `dir` 属性が変更するのは読み順の方向のみです。<PlatformBlock for="Angular">コンポーネントの文字列を別の言語で表示するには、[ローカライゼーション](../general/localization.mdx)を参照してください。</PlatformBlock><PlatformBlock for="React,WebComponents">コンポーネントの文字列を別の言語で表示するには、[ローカライゼーション](../localization.mdx)を参照してください。</PlatformBlock>

**方向は 1 か所で設定します。** アプリケーション全体の場合は、`body` 要素に `dir="rtl"` を設定します。ページの一部のみを反転するには、[ページの一部に RTL を適用する](#ページの一部に-rtl-を適用する)で説明しているように、代わりにコンテナーに設定します。

**独自のコンテンツにも論理プロパティが必要です。** コンポーネントは自動的に反転しますが、`margin-left` などの物理プロパティで記述したスタイルは、配置した位置に留まります。[RTL 向けに独自のコンテンツのスタイルを設定する](#rtl-向けに独自のコンテンツのスタイルを設定する)を参照してください。

## 次のステップ

- ホスト ページに設定して、[アプリケーション全体で RTL を有効にします](#アプリケーション全体で-rtl-を有効にする)。
- ユーザーが言語を変更したときに、[実行時に方向を切り替えます](#実行時に方向を切り替える)。
- アプリケーションで使用するコンポーネントの[既知の制限](#既知の制限)を確認します。

## 利用可能なツール

| ツール | 場所 | 機能 |
| -------------------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `dir` 属性 | 任意の HTML 要素 (通常は `body`) | 要素とその内部のすべての方向を設定します。`rtl`、`ltr`、`auto` を受け付けます。 |
| CSS 論理プロパティ | 独自のスタイルシート | `padding-left` の代わりに `padding-inline-start` を使用するなど、読み順の方向を基準にコンテンツを配置します。 |
| `:dir(rtl)` 擬似クラス | 独自のスタイルシート | `dir` 属性が要素自体と祖先要素のどちらにある場合でも、方向が右から左である要素に一致します。 |

## 一般的なワークフロー

### アプリケーション全体で RTL を有効にする

ホスト ページの `body` 要素に `dir="rtl"` を設定します。ページ上のすべての {ProductName} コンポーネントが右から左にレンダリングされます。

<PlatformBlock for="Angular">

`src/index.html` で属性を設定します:

```html
<!doctype html>
<html lang="ar">
  <head>
    <meta charset="utf-8" />
    <title>My App</title>
  </head>
  <body dir="rtl">
    <app-root></app-root>
  </body>
</html>
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

アプリケーションの `index.html` で属性を設定します:

```html
<!doctype html>
<html lang="ar">
  <head>
    <meta charset="utf-8" />
    <title>My App</title>
  </head>
  <body dir="rtl">
    <!-- application content -->
  </body>
</html>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

ホスト ページの `body` 要素に属性を設定します。ホスト ページは、Blazor Web App では `Components/App.razor`、Blazor WebAssembly アプリでは `wwwroot/index.html`、Blazor Server アプリでは `Pages/_Host.cshtml` です。Blazor Web App の場合:

```razor
<!DOCTYPE html>
<html lang="ar">
<head>
    <meta charset="utf-8" />
    <base href="/" />
    <HeadOutlet />
</head>
<body dir="rtl">
    <Routes />
    <script src="_content/IgniteUI.Blazor/app.bundle.js"></script>
    <script src="_framework/blazor.web.js"></script>
</body>
</html>
```

</PlatformBlock>

### 実行時に方向を切り替える

ユーザーが別の言語を選択したときなど、アプリケーションの実行中に方向を変更するには、`body` 要素の `dir` 属性を設定します。コンポーネントのスタイルはすぐに更新され、コンポーネントは次にユーザーが操作したときに新しい方向を読み取ります。

<PlatformBlock for="Angular">

```ts
import { Component, DOCUMENT, inject } from '@angular/core';

@Component({
    selector: 'app-root',
    templateUrl: './app.component.html'
})
export class AppComponent {
    private readonly document = inject(DOCUMENT);

    public setDirection(dir: 'ltr' | 'rtl') {
        this.document.body.dir = dir;
    }
}
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
function setDirection(dir: 'ltr' | 'rtl') {
  document.body.dir = dir;
}
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
function setDirection(dir: 'ltr' | 'rtl') {
  document.body.dir = dir;
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

JavaScript 相互運用を使用して属性を設定します:

```razor
@inject IJSRuntime JS

<button @onclick='() => SetDirection("rtl")'>Right to left</button>
<button @onclick='() => SetDirection("ltr")'>Left to right</button>

@code {
    private async Task SetDirection(string dir)
    {
        await JS.InvokeVoidAsync("document.body.setAttribute", "dir", dir);
    }
}
```

</PlatformBlock>

### ページの一部に RTL を適用する

アラビア語やヘブライ語のコンテンツを含むパネルなど、ページの一部のみを反転するには、その部分を含む要素に `dir="rtl"` を設定し、`body` は左から右のままにします。要素内のコンポーネントは、その要素の方向に従います。

次のサンプルでは、`dir="rtl"` を設定したコンテナーに Calendar を配置しています。**Change Directionality** を選択すると、コンテナーの方向が右から左と左から右の間で切り替わります。

### 方向を示す Icon を反転する

ほとんどのアイコンはどちらの方向でも同じように見えるため、アイコンは自動的には反転しません。矢印など、読み順の方向を指すアイコンの場合は、<ApiLink pkg="core" type="Icon" member="mirrored" label="mirrored" /> を設定すると、右から左のレイアウトでアイコンが水平方向に反転します。[Icon](../layouts/icon.mdx#反転-mirrored) と [Icon Button](../inputs/icon-button.mdx#mirrored-ミラー化済み) がこれをサポートしています。

</PlatformBlock>

<PlatformBlock for="Angular">

### 方向を示す Icon を反転する

アイコンは自動的には反転せず、Angular Icon にはアイコンを反転するオプションがありません。右から左のレイアウトで方向を示すアイコンには、`arrow_forward` の代わりに `arrow_back` など、読み順の方向を指すアイコンを使用します。

</PlatformBlock>

### RTL 向けに独自のコンテンツのスタイルを設定する

独自のコンテンツのスタイルを CSS 論理プロパティで記述すると、コンポーネントと一緒に反転します。一方の方向にのみ適用するルールには、`:dir(rtl)` 擬似クラスを使用します:

```css
.toolbar {
  padding-inline-start: 16px; /* left in LTR, right in RTL */
}

.next-icon:dir(rtl) {
  transform: scaleX(-1);
}
```

## 既知の制限

{ProductName} では、次のコンポーネントは方向に部分的にしか従いません。

## トラブルシューティング

<PlatformBlock for="React,WebComponents,Blazor">

### Carousel の矢印が逆方向を指すのはなぜですか?

Carousel と Navigation Drawer は、`body` 要素の方向と自身の `dir` 属性を組み合わせます。`dir="rtl"` が `html` 要素にのみ設定されている場合は左から右にレンダリングされ、`body` 要素とコンポーネントの両方に設定されている場合は 2 つが打ち消し合います。`dir="rtl"` は 1 か所で設定してください。ページ全体の場合は `body` 要素に、右から左のコンテナー内のコンポーネントの場合はそのコンポーネントに設定します。

</PlatformBlock>

<PlatformBlock for="Angular">

### `$direction: rtl` のコンパイルが失敗するのはなぜですか?

`core()` ミックスイン (バージョン 13.1.0 より前は `igx-core()`) には、`$direction` パラメーターがなくなりました。通常のテーマが両方の方向をサポートするため、バージョン 13.2.0 でこのパラメーターは RTL 専用の `*-rtl.css` テーマ ファイルとともに削除されました。`@include igx-core($direction: rtl)` または `@include core($direction: rtl)` を `@include core()` に置き換え、通常のテーマ ファイルを使用し、[アプリケーション全体で RTL を有効にする](#アプリケーション全体で-rtl-を有効にする)で説明しているように `dir` 属性を設定してください。`ng update` を実行して 13.2.0 以降に更新すると、これら 2 つの変更が Sass に自動的に適用されます。

### 実行時の方向の変更にコンポーネントが従わないのはなぜですか?

21.2.0 より前のバージョンでは、アプリケーションの起動時に `body` 要素または `html` 要素から方向を 1 回だけ読み取ります。これらのバージョンでは、アプリケーションがブートストラップされる前に `dir` 属性を設定するか、21.2.0 以降に更新してください。21.2.0 以降では、ユーザーが操作するたびにコンポーネントが方向を読み取ります。

</PlatformBlock>

### RTL で独自のコンテンツが左側に残るのはなぜですか?

`margin-left` や `float: left` などの物理プロパティを使用するスタイルは反転しません。[RTL 向けに独自のコンテンツのスタイルを設定する](#rtl-向けに独自のコンテンツのスタイルを設定する)で示しているように、`margin-inline-start` や `float: inline-start` などの論理プロパティに置き換えてください。

</FaqItem>
