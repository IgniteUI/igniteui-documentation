# {Platform} 地理バブル マップ

{Platform} マップ コンポーネントでは、<ApiLink type="GeographicProportionalSymbolSeries" /> を使用して、アプリケーションのデータで指定された地理的位置にバブルまたは相対マーカーをプロットできます。このマップ シリーズは、百貨店、倉庫、オフィスなど、特定のビジネス ケースに応じたポイントをハイライト表示する場合に役立ちます。また、動的な車両追跡のためにフリート管理システムまたは GPS システムでこの地図シリーズを使用することができます。

## 構成の概要
 マップコントロールの他のタイプの散布シリーズと同様に、<ApiLink type="GeographicProportionalSymbolSeries" /> シリーズには、オブジェクトの配列にバインドできる <ApiLink type="GeographicMap" member="dataSource" label="DataSource" /> プロパティがあります。また、項目ソースの各項目は、地理経度および緯度を表す 2 つのデータ列があります。<ApiLink type="GeographicProportionalSymbolSeries" member="longitudeMemberPath" label="LongitudeMemberPath" /> と <ApiLink type="GeographicProportionalSymbolSeries" member="latitudeMemberPath" label="LatitudeMemberPath" /> プロパティを使用してこのデータ列をマップします。<ApiLink type="GeographicProportionalSymbolSeries" member="radiusScale" label="RadiusScale" /> と <ApiLink type="GeographicProportionalSymbolSeries" member="radiusMemberPath" label="RadiusMemberPath" /> は、バブルの半径を設定します。

以下の表に、データ バインドに使用される GeographicHighDensityScatterSeries シリーズのプロパティをまとめています。

| プロパティ|タイプ|概要 |
| ---|---|--- |
| <ApiLink type="GeographicMap" member="dataSource" label="DataSource" />|any|項目のソースを取得または設定します |
| <ApiLink type="GeographicProportionalSymbolSeries" member="longitudeMemberPath" label="LongitudeMemberPath" />|string|DataSource プロパティを使用して、割り当てられた商品の経度の値の場所を特定します。 |
| <ApiLink type="GeographicProportionalSymbolSeries" member="latitudeMemberPath" label="LatitudeMemberPath" />|string|DataSource プロパティを使用して、割り当てられた商品の緯度値の場所を決定します。 |
| <ApiLink type="GeographicProportionalSymbolSeries" member="radiusMemberPath" label="RadiusMemberPath" />|string|シリーズの半径値を取得するために使用するパスを設定します。 |
| <ApiLink type="GeographicProportionalSymbolSeries" member="radiusScale" label="RadiusScale" />|<ApiLink type="SizeScale" />|現在のバブル シリーズの半径スケール プロパティを取得または設定します。 |
| <ApiLink type="SizeScale" member="minimumValue" label="MinimumValue" />|any|値のサブ範囲を計算するための最小値を設定します。 |
| <ApiLink type="SizeScale" member="maximumValue" label="MaximumValue" />|any|値のサブ範囲を計算するための最大値を設定します。 |

## コード スニペット

```json-snippet source="/maps/geo-map/type-scatter-bubble-series"
{
    "type": "GeographicMap",
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicProportionalSymbolSeries",
            "name": "WorldCitiesSeries",
            "dataSourceRef": "WorldCities",
            "markerType": "Circle",
            "radiusScale": {
                "type": "SizeScale",
                "minimumValue": 4,
                "maximumValue": 60
            },
            "fillScale": {
                "type": "ValueBrushScale",
                "brushes": [
                    "rgba(14, 194, 14, 0.4)",
                    "rgba(252, 170, 32, 0.4)",
                    "rgba(252, 32, 32, 0.4)"
                ],
                "minimumValue": 0,
                "maximumValue": 30
            },
            "fillMemberPath": "Population",
            "radiusMemberPath": "Population",
            "latitudeMemberPath": "Y",
            "longitudeMemberPath": "X",
            "markerOutline": "rgba(0,0,0,0.3)"
        }
    ]
}
```
