# {Platform} シェイプ スタイリング ユーティリティ

リソース トピックは、{Platform} `XamGeographicMap` コンポーネントで `GeographicShapeSeries` の UI 要素のスタイリングに役立つユーティリティの実装を提供します。

## 必要なインポート

```json-snippet source="/maps/geo-map/shape-styling" channel="handlersImports"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap"
        }
    },
    "onViewInit": [
        "MapShapeRandomStyling"
    ],
    "$onViewInit": "+doc:handlersImports"
}
```
