# {Platform} ヒート画像の表示

{ProductName} マップ コントロールには、Shape ファイルをタイル シリーズにロードして地理空間データをロードすることにより、<ApiLink type="ShapefileRecord" /> によって生成される `ShapeFileRecord` を使用して、ヒートマップ画像を表示する機能があります。

このトピックを読み進めるための前提条件として、[シェープ ファイルを地理的データにバインディング](./geo-map-binding-shp-file.mdx)をお読みください。

## {Platform} ヒート画像の表示の例

<Sample src="/maps/geo-map/display-heat-imagery" height={500} alt="{Platform} ヒート画像の表示の例" />




<ApiLink type="ShapefileRecord" /> がそのシェイプ ファイルを読み込むと、そのデータを <ApiLink type="ShapefileRecord" /> オブジェクトに変換します。これらのオブジェクトは、<ApiLink type="ShapefileRecord" /> の `GetPointData()` メソッドから取得でき、
<ApiLink type="TileGeneratorMapImagery" member="tileGenerator" label="TileGenerator" />
プロパティに割り当てられた <ApiLink type="HeatTileGenerator" /> で <ApiLink type="TileGeneratorMapImagery" /> オブジェクトを使用してヒートマップを作成するために使用できます。この <ApiLink type="TileGeneratorMapImagery" /> は、<ApiLink type="GeographicTileSeries" member="tileImagery" label="TileImagery" /> ソースとして <ApiLink type="GeographicTileSeries" /> で使用できます。

<ApiLink type="HeatTileGenerator" /> オブジェクトは、<ApiLink type="HeatTileGenerator" member="xValues" label="XValues" />、<ApiLink type="HeatTileGenerator" member="yValues" label="YValues" />、<ApiLink type="HeatTileGenerator" member="values" label="Values" /> の 3 つの値パスを持つように機能します。これらの使用方法の例として、人口に関する情報を持つ形状ファイルの場合、<ApiLink type="HeatTileGenerator" member="xValues" label="XValues" /> を経度、<ApiLink type="HeatTileGenerator" member="yValues" label="YValues" /> を緯度、<ApiLink type="HeatTileGenerator" member="values" label="Values" /> を人口データとみなすことができます。これらの各プロパティは、`number[]` を取得します。

ヒートマップ機能を使用する際の地理的タイルシリーズの表示は、<ApiLink type="HeatTileGenerator" member="minimumColor" label="MinimumColor" /> プロパティと <ApiLink type="HeatTileGenerator" member="maximumColor" label="MaximumColor" /> プロパティを <ApiLink type="HeatTileGenerator" /> の <ApiLink type="HeatTileGenerator" member="values" label="Values" /> プロパティに割り当てるコレクションの最小値と最大値に対応する色を記述する「rgba」文字列に設定することでカスタマイズできます。これをさらにカスタマイズするには、ジェネレーターの <ApiLink type="HeatTileGenerator" member="scaleColors" label="ScaleColors" /> プロパティを設定して、色を説明する文字列のコレクションを含めます。これにより、<ApiLink type="HeatTileGenerator" /> に、マップに表示される値に使用する色がわかります。<ApiLink type="HeatTileGenerator" member="blurRadius" label="BlurRadius" />、<ApiLink type="HeatTileGenerator" member="maxBlurRadius" label="MaxBlurRadius" />、<ApiLink type="HeatTileGenerator" member="useBlurRadiusAdjustedForZoom" label="UseBlurRadiusAdjustedForZoom" /> プロパティを使用して、<ApiLink type="HeatTileGenerator" member="scaleColors" label="ScaleColors" /> コレクション内の色が一緒にぼやける方法をカスタマイズすることもできます。

<ApiLink type="HeatTileGenerator" /> は対数スケールも使用できます。これを使用する場合は、<ApiLink type="HeatTileGenerator" member="useLogarithmicScale" label="UseLogarithmicScale" /> プロパティを **true** に設定できます。

## Web Worker

また、<ApiLink type="HeatTileGenerator" /> は、Web Worker が、別のスレッドでシェイプ ファイルからタイル イメージをロードする際の重いリフティングをサポートしています。これにより、ヒートマップ機能を使用する際に地理マップのパフォーマンスが大幅に向上します。ジェネレーターでWebワーカーを使用するには、<ApiLink type="HeatTileGenerator" member="useWebWorkers" label="UseWebWorkers" /> プロパティを **true** に設定し、<ApiLink type="HeatTileGenerator" member="webWorkerInstance" label="WebWorkerInstance" /> プロパティを Web Worker のインスタンスに設定できます。
