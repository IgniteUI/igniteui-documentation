# {Platform} ラジアル ゲージの概要

{Platform} Radial Gauge コンポーネントは、針、目盛り、範囲、ラベルなどの視覚要素をサポートし、定義済みの図形やスケールを表示できます。<ApiLink type="RadialGauge" /> には、アニメーション化されたトランジションのサポートも組み込まれています。アニメーションは、<ApiLink type="RadialGauge" member="transitionDuration" label="TransitionDuration" /> プロパティの設定で簡単にカスタマイズできます。

## 使用方法

以下のコードは針およびスケールで 3 つの比較範囲を含むラジアル ゲージを作成する方法を紹介します。

```json-snippet
{
    "type": "RadialGauge",
    "height": "400px",
    "width": "400px",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 25,
    "interval": 5,
    "ranges": [
        { "type": "RadialGaugeRange", "startValue": 0,  "endValue": 30,  "brush": "red" },
        { "type": "RadialGaugeRange", "startValue": 30, "endValue": 60,  "brush": "yellow" },
        { "type": "RadialGaugeRange", "startValue": 60, "endValue": 100, "brush": "green" }
    ]
}
```


## バッキング

ゲージには、スケールの後ろ側に描かれた背景図形があり、図形はゲージの背景として動作します。

バッキング要素はラジアル ゲージ コントロールの背景と境界線を表します。常に最初に描画される要素で針、ラベルやメモリなどの残りの要素はその上のオーバーレイです。

バッキングは、円形またはフィットにできます。円形の場合は 360 度の円形のゲージが作成されますが、一方フィット図形の場合は <ApiLink type="RadialGauge" member="scaleStartAngle" label="ScaleStartAngle" /> および <ApiLink type="RadialGauge" member="scaleEndAngle" label="ScaleEndAngle" /> プロパティで円弧部分が塗りつぶされます。これには、<ApiLink type="RadialGauge" member="backingShape" label="BackingShape" /> プロパティを設定します。

```json-snippet source="/gauges/radial-gauge/backing"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "backingShape": "Fitted",
    "backingBrush": "#FCFCFC",
    "backingOutline": "DodgerBlue",
    "backingOversweep": 5,
    "backingCornerRadius": 10,
    "backingStrokeThickness": 5,
    "backingOuterExtent": 0.8,
    "backingInnerExtent": 0.15,
    "scaleStartAngle": 135,
    "scaleEndAngle": 45
}
```

## スケール

スケールは視覚要素で、<ApiLink type="RadialGauge" member="minimumValue" label="MinimumValue" /> と <ApiLink type="RadialGauge" member="maximumValue" label="MaximumValue" /> 値を設定してゲージの値範囲全体をハイライト表示できます。バッキングとともにゲージの全体的な図形を定義します。<ApiLink type="RadialGauge" member="scaleStartAngle" label="ScaleStartAngle" /> と <ApiLink type="RadialGauge" member="scaleEndAngle" label="ScaleEndAngle" /> プロパティは、スケールの円弧の境界線を定義します。<ApiLink type="RadialGauge" member="scaleSweepDirection" label="ScaleSweepDirection" /> プロパティが、スケールが時計回りまたは反時計回りのどちらの方向に動くかを指定します。<ApiLink type="RadialGauge" member="scaleBrush" label="ScaleBrush" />、<ApiLink type="RadialGauge" member="scaleStartExtent" label="ScaleStartExtent" />、<ApiLink type="RadialGauge" member="scaleEndExtent" label="ScaleEndExtent" /> プロパティを設定してスケールの外観をカスタマイズできます。

```json-snippet source="/gauges/radial-gauge/scale"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "scaleStartAngle": 135,
    "scaleEndAngle": 45,
    "scaleBrush": "DodgerBlue",
    "scaleSweepDirection": "Clockwise",
    "scaleOversweep": 1,
    "scaleOversweepShape": "Fitted",
    "scaleStartExtent": 0.45,
    "scaleEndExtent": 0.575
}
```


<Sample src="/gauges/radial-gauge/scale" height={320} alt="{Platform} ラジアル ゲージのスケール" />



## ラベルとタイトル

ゲージ ラベルは <ApiLink type="RadialGauge" member="minimumValue" label="MinimumValue" /> と <ApiLink type="RadialGauge" member="maximumValue" label="MaximumValue" /> の値の間で指定された間隔で数値を表示する視覚要素です。0 はゲージ中央、1 はゲージ バッキングの外側範囲を表す <ApiLink type="RadialGauge" member="labelExtent" label="LabelExtent" /> プロパティで小数を使用してラベルの配置を設定できます。<ApiLink type="RadialGauge" member="fontBrush" label="FontBrush" /> や <ApiLink type="RadialGauge" member="font" label="Font" /> など、さまざまなスタイル プロパティを設定してラベルをカスタマイズできます。

これらの針のラベルにはそれぞれ、<ApiLink type="RadialGauge" member="titleExtent" label="TitleExtent" />、<ApiLink type="RadialGauge" member="titleAngle" label="TitleAngle" />、`SubtitleFontSize`、<ApiLink type="RadialGauge" member="highlightLabelBrush" label="HighlightLabelBrush" /> など、フォント、角度、ブラシ、ゲージの中心からの距離を変更するために適用できるさまざまなスタイル属性があります。

```json-snippet source="/gauges/radial-gauge/labels"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "labelInterval": 10,
    "labelExtent": 0.65,
    "font": "11px Verdana",
    "fontBrush": "DodgerBlue"
}
```


<Sample src="/gauges/radial-gauge/labels" height={320} alt="{Platform} ラジアル ゲージのラベル" />


## タイトルとサブタイトル

<ApiLink type="RadialGauge" member="titleText" label="TitleText" /> プロパティと <ApiLink type="RadialGauge" member="subtitleText" label="SubtitleText" /> プロパティが使用可能であり、どちらも針のカスタム テキストを表示するために使用できます。あるいは、<ApiLink type="RadialGauge" member="titleDisplaysValue" label="TitleDisplaysValue" /> と <ApiLink type="RadialGauge" member="subtitleDisplaysValue" label="SubtitleDisplaysValue" /> を true に設定すると、針の値が表示され、<ApiLink type="RadialGauge" member="titleText" label="TitleText" /> と <ApiLink type="RadialGauge" member="subtitleText" label="SubtitleText" /> がオーバーライドされます。したがって、タイトルにカスタム テキストを使用しながらサブタイトルで値を表示したり、その逆を行ったりすることができます。

以下に説明するように針のハイライトが表示されている場合は、<ApiLink type="RadialGauge" member="highlightLabelText" label="HighlightLabelText" /> を介してカスタム テキストを表示できます。それ以外の場合は、<ApiLink type="RadialGauge" member="highlightLabelDisplaysValue" label="HighlightLabelDisplaysValue" /> を有効にしてその値を表示できます。

```json-snippet
{
    "type": "RadialGauge",
    "titleText": "Global Sales",
    "subtitleText": "2024"
}
```

## オプティカル スケーリング

ラジアル ゲージのラベルとタイトルにより、スケーリングを変更できます。これを有効にするには、まず <ApiLink type="RadialGauge" member="opticalScalingEnabled" label="OpticalScalingEnabled" /> を true に設定します。次に、ラベルが 100% のオプティカル スケーリングを持つサイズを管理する <ApiLink type="RadialGauge" member="opticalScalingSize" label="OpticalScalingSize" /> を設定できます。ゲージのサイズが大きくなると、ラベルのフォントも大きくなります。たとえば、このプロパティが 500 に設定され、ゲージのピクセル単位のサイズが 2 倍の 1000 になると、ラベルのフォント サイズは 200% 大きくなります。

<Sample src="/gauges/radial-gauge/optical-scaling" height={500} alt="{Platform} ラジアル ゲージのオプティカル スケーリング" />


## 目盛

目盛は、ラジアル ゲージの中央から放射状に表示される細い線です。目盛には、主目盛および副目盛の 2 種類があり、主目盛りは <ApiLink type="RadialGauge" member="minimumValue" label="MinimumValue" /> と <ApiLink type="RadialGauge" member="maximumValue" label="MaximumValue" /> の間の <ApiLink type="RadialGauge" member="interval" label="Interval" /> に表示されます。また <ApiLink type="RadialGauge" member="minorTickCount" label="MinorTickCount" /> プロパティは、隣接する 2 つの主目盛間の副目盛の数を指定します。目盛りの長さは、<ApiLink type="RadialGauge" member="tickStartExtent" label="TickStartExtent" />、<ApiLink type="RadialGauge" member="tickEndExtent" label="TickEndExtent" />、<ApiLink type="RadialGauge" member="minorTickStartExtent" label="MinorTickStartExtent" />、<ApiLink type="RadialGauge" member="minorTickEndExtent" label="MinorTickEndExtent" /> に少数値 (0 から 1 の間) を設定して制御できます。

```json-snippet source="/gauges/radial-gauge/tickmarks"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "tickStartExtent": 0.45,
    "tickEndExtent": 0.575,
    "tickStrokeThickness": 2,
    "tickBrush": "DodgerBlue",
    "minorTickCount": 4,
    "minorTickStartExtent": 0.575,
    "minorTickEndExtent": 0.5,
    "minorTickStrokeThickness": 1,
    "minorTickBrush": "DarkViolet"
}
```


<Sample src="/gauges/radial-gauge/tickmarks" height={320} alt="{Platform} ラジアル ゲージの目盛" />



## 範囲

範囲に <ApiLink type="RadialGauge" member="minimumValue" label="MinimumValue" /> や <ApiLink type="RadialGauge" member="maximumValue" label="MaximumValue" /> プロパティで指定した連続値の境界をハイライト表示します。開始値と終了値を指定してゲージに複数の範囲を追加でき、各範囲には、<ApiLink type="RadialGaugeRange" member="brush" label="Brush" /> や <ApiLink type="RadialGaugeRange" member="outline" label="Outline" /> などのカスタマイズ プロパティがあります。または、<ApiLink type="RadialGauge" member="rangeBrushes" label="RangeBrushes" /> や <ApiLink type="RadialGauge" member="rangeOutlines" label="RangeOutlines" /> プロパティを範囲の色リストに設定することもできます。

```json-snippet source="/gauges/radial-gauge/ranges"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "rangeBrushes":  [ "red", "yellow", "green" ],
    "rangeOutlines": [ "red", "yellow", "green" ],
    "ranges": [
        { "type": "RadialGaugeRange", "startValue": 5,  "endValue": 15, "brush": "red" },
        { "type": "RadialGaugeRange", "startValue": 15, "endValue": 35, "brush": "yellow" },
        { "type": "RadialGaugeRange", "startValue": 35, "endValue": 45, "brush": "green" }
    ]
}
```


<Sample src="/gauges/radial-gauge/ranges" height={320} alt="{Platform} ラジアル ゲージの範囲" />



## 針

ゲージ針は、ゲージの設定値を示す視覚要素です。針は、あらかじめ定義されたいくつかの図形の中から選択でき、ピボット図形をゲージの中心に配置できます。またピボット図形は、事前に定義された図形の 1 つを使用します。オーバーレイとアンダーレイを含むピボット図形には、図形に適用する別のピボット ブラシがあります。

サポートされている針の形とキャップは、<ApiLink type="RadialGauge" member="needleShape" label="NeedleShape" /> と <ApiLink type="RadialGauge" member="needlePivotShape" label="NeedlePivotShape" /> プロパティで設定します。

ゲージのインタラクティブ モードを有効 (<ApiLink type="RadialGauge" member="isNeedleDraggingEnabled" label="IsNeedleDraggingEnabled" /> プロパティを使用) にするとユーザーは <ApiLink type="RadialGauge" member="minimumValue" label="MinimumValue" /> と <ApiLink type="RadialGauge" member="maximumValue" label="MaximumValue" /> の値間で針をドラッグして値を変更できるようになります。

```json-snippet source="/gauges/radial-gauge/needle"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "isNeedleDraggingEnabled": true,
    "isNeedleDraggingConstrained": true,
    "needleShape": "NeedleWithBulb",
    "needleBrush": "DodgerBlue",
    "needleOutline": "DodgerBlue",
    "needleEndExtent": 0.475,
    "needleStrokeThickness": 1,
    "needlePivotShape": "CircleOverlay",
    "needlePivotBrush": "#9F9FA0",
    "needlePivotOutline": "#9F9FA0",
    "needlePivotWidthRatio": 0.2,
    "needlePivotStrokeThickness": 1
}
```

## 針のハイライト

ラジアル ゲージを変更して、2 番目の針を表示できます。これにより、メイン針の <ApiLink type="RadialGauge" member="value" label="Value" /> の不透明度が低く表示されます。これを有効にするには、まず <ApiLink type="RadialGauge" member="highlightValueDisplayMode" label="HighlightValueDisplayMode" /> を Overlay に設定し、次に <ApiLink type="RadialGauge" member="highlightValue" label="HighlightValue" /> を適用します。

```json-snippet source="/gauges/radial-gauge/highlight-needle"
{
    "type": "RadialGauge",
    "height": "100%",
    "width": "100%",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 30,
    "interval": 10,
    "labelInterval": 10,
    "labelExtent": 0.65,
    "isHighlightNeedleDraggingEnabled": true,
    "highlightValueDisplayMode": "Overlay",
    "highlightValue": 50,
    "highlightLabelDisplaysValue": true,
    "highlightLabelSnapsToNeedlePivot": true
}
```
