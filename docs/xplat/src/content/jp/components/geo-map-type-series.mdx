# {Platform} 地理的シリーズの概要

{ProductName} マップ コンポーネントでは、地理的シリーズは、地理的なデータをポイント (都市の位置など)、ポリライン (道路の接続など)、またはポリゴン (国の形状) として地理的コンテキストで表示する地図の視覚的要素です。
マップ コンポーネントの Series プロパティは、地理的シリーズ オブジェクトのコレクションです。このプロパティを使用すると、同じプロット領域に地理的シリーズを数の制限なく描画できます。Series プロパティに複数の地理的シリーズ オブジェクトを追加すると、最初のシリーズから最後のシリーズへと順に、後のシリーズが前のシリーズの上に重ねて描画されます。そのため、地理的シリーズは、互いの上や地理的画像の上に積み重ねることができるマップ レイヤーと考えるとわかりやすくなります。

地理的シリーズのすべてのタイプは、常に地理的画像タイルの上に描画されます。ただし、地理的シリーズ (世界の詳細なシェイプ ファイルを使用したものなど) だけでアプリケーションに十分な地理的コンテキストを提供でき、マップ コントロールに地理的画像が不要な場合もあります。
