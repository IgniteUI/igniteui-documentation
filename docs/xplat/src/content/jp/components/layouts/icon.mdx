# Icon (アイコン)

{ProductName} Icon は、カスタム SVG アイコンのコレクションなどの登録済みアイコン セットから、名前付きアイコンを表示するコンポーネントです。

<PlatformBlock for="Angular">

既定では、Angular Icon は Material Icons のリガチャを表示します。SVG アイコンやその他のアイコン フォントを `IgxIconService` で登録すると、同じ方法で使用できます。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

SVG アイコンをコレクション内に名前で登録し、各アイコンをテーマベースのサイズで、周囲のテキストの色で表示します。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Icon は `igc-icon` 要素を描画します。この要素は、登録された SVG をシャドウ ルート内に描画し、CSS パーツを公開しません:

```text
igc-icon                 // host - inline box sized by --size
└─ #shadow-root
   └─ svg                // the registered SVG, 1em × 1em, filled with the current color
```

</PlatformBlock>

<PlatformBlock for="Angular">

`igx-icon` 要素は、アイコン ファミリのタイプに応じて、次のいずれかを描画します:

```text
igx-icon.igx-icon[aria-hidden="true"]   // host - also carries the family class, e.g. .material-icons
├─ ligature text                        // `liga` family - the icon name, e.g. home
├─ div > svg                            // SVG icon registered with IgxIconService
└─ ng-content                           // projected ligature text when `name` isn't set
```

`font` ファミリの場合、ホスト上のクラスがグリフを描画し、要素にはコンテンツがありません。

</PlatformBlock>

## 使用方法

{Platform} Icon を使用して、ラベル、ボタン、リスト項目、ナビゲーションにわかりやすいシンボルを追加したり、ステータスをひと目で示したりします。

<PlatformBlock for="React,WebComponents,Blazor">

### 名前とコレクション

{Platform} Icon は、コレクション内の名前で登録された SVG を描画します。コレクションの既定値は `default` です。ページ上のすべてのアイコンは 1 つのレジストリを共有するため、一度登録したアイコンはすべての Icon で使用でき、SVG が登録される前に描画された Icon は、登録された時点ですぐに更新されます。

</PlatformBlock>

<PlatformBlock for="WebComponents">

SVG マークアップを <ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" /> で登録するか、URL から SVG ファイルを <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" /> で取得します:

```ts
import { registerIcon, registerIconFromText } from 'igniteui-webcomponents';

const searchIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

registerIconFromText('search', searchIcon, 'material');
registerIcon('build', '/icons/build.svg', 'material');
```

次に、各アイコンに同じ名前とコレクションを設定します:

```html
<igc-icon name="search" collection="material"></igc-icon>
<igc-icon name="build" collection="material"></igc-icon>
```

</PlatformBlock>

<PlatformBlock for="React">

SVG マークアップを <ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" /> で登録するか、URL から SVG ファイルを <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" /> で取得します。次に、各アイコンに同じ名前とコレクションを設定します:

```tsx
import { useEffect } from 'react';
import { IgrIcon, registerIcon, registerIconFromText } from 'igniteui-react';

const searchIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

export default function SearchToolbar() {
  useEffect(() => {
    registerIconFromText('search', searchIcon, 'material');
    registerIcon('build', '/icons/build.svg', 'material');
  }, []);

  return (
    <>
      <IgrIcon name="search" collection="material" />
      <IgrIcon name="build" collection="material" />
    </>
  );
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

SVG マークアップを <ApiLink pkg="core" type="Icon" member="RegisterIconFromTextAsync" label="RegisterIconFromTextAsync" /> メソッドで登録するか、URL から SVG ファイルを <ApiLink pkg="core" type="Icon" member="RegisterIconAsync" label="RegisterIconAsync" /> で取得します。参照した `IgbIcon` の準備ができた後にこれらを呼び出し、各アイコンに同じ `IconName` と `Collection` を設定します:

```razor
<IgbIcon @ref="SearchIcon" IconName="search" Collection="material" />
<IgbIcon IconName="build" Collection="material" />

@code {
    private IgbIcon SearchIcon { get; set; }

    private const string SearchSvg = "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'><path d='M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z'/></svg>";

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender && SearchIcon != null)
        {
            await SearchIcon.EnsureReady();
            await SearchIcon.RegisterIconFromTextAsync("search", SearchSvg, "material");
            await SearchIcon.RegisterIconAsync("build", "/icons/build.svg", "material");
        }
    }
}
```

</PlatformBlock>

### 名前とファミリ

Angular Icon は、その <ApiLink pkg="core" type="Icon" member="name" label="name" /> を <ApiLink pkg="core" type="Icon" member="family" label="family" /> 内で検索します。既定の `material` ファミリは Material Icons のリガチャを表示するため、名前は `home` や `favorite` などのリガチャです:

```html
<igx-icon name="home"></igx-icon>
<igx-icon name="favorite"></igx-icon>
```

リガチャをコンテンツとして投影することもできます:

```html
<igx-icon>bluetooth</igx-icon>
```

### SVG アイコン

SVG アイコンを <ApiLink pkg="core" type="IconService" /> で登録し、アイコンに名前とファミリを設定します。<ApiLink pkg="core" type="IconService" member="addSvgIcon" label="addSvgIcon" /> メソッドは URL から SVG ファイルを取得し、<ApiLink pkg="core" type="IconService" member="addSvgIconFromText" label="addSvgIconFromText" /> は SVG マークアップを登録します:

```ts
import { Component, OnInit, inject } from '@angular/core';
import { IgxIconComponent, IgxIconService } from 'igniteui-angular/icon';

const searchIcon =
    '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

@Component({
    selector: 'app-filter-icons',
    template: `
        <igx-icon name="contains" family="filter-icons"></igx-icon>
        <igx-icon name="search" family="filter-icons"></igx-icon>
    `,
    imports: [IgxIconComponent]
})
export class FilterIconsComponent implements OnInit {
    private iconService = inject(IgxIconService);

    public ngOnInit() {
        this.iconService.addSvgIcon('contains', 'assets/images/svg/contains.svg', 'filter-icons');
        this.iconService.addSvgIconFromText('search', searchIcon, 'filter-icons');
    }
}
```

SVG アイコンとリガチャが同じ名前とファミリを共有している場合、アイコンは SVG を表示します。

### フォント ファミリ

<ApiLink pkg="core" type="IconService" member="setFamily" label="setFamily" /> を使用して、[Material Symbols](https://fonts.google.com/icons) などの別のアイコン フォントをファミリとして追加します。最初にフォントのスタイルシートを読み込みます:

```html
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" rel="stylesheet" />
```

ファミリ名をフォントの CSS クラスにマップし、そのタイプを `liga` に設定します:

```ts
this.iconService.setFamily('material-symbols', { className: 'material-symbols-outlined', type: 'liga' });
```

次に、アイコンにファミリを設定します。Material Symbols はバリアブル フォントであるため、塗りつぶしや太さなどの設定を調整できます:

```html
<igx-icon family="material-symbols" name="diamond" class="custom-icon"></igx-icon>
```

```scss
.custom-icon {
  font-variation-settings: "FILL" 0, "wght" 200, "GRAD" 0, "opsz" 40;
}
```

`font` タイプのファミリ、名前のプレフィックス、アイコン参照については、[Icon Service](../icon-service.mdx) トピックを参照してください。

### アイコン参照

アイコン参照は、アイコン名を別の登録済みアイコンに関連付けます。Combo や Date Picker などのコンポーネントは、`default` コレクション内の参照を通じて組み込みアイコンを表示し、設定した参照が優先されます。たとえば、`input_clear` 参照を独自のアイコンに関連付けると、これら 2 つのコンポーネントのクリア アイコンを置き換えることができます:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
import { registerIconFromText, setIconRef } from 'igniteui-webcomponents';

const closeIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z"/></svg>';

registerIconFromText('close', closeIcon, 'my-icons');
setIconRef('input_clear', 'default', { name: 'close', collection: 'my-icons' });
```

</PlatformBlock>

<PlatformBlock for="React">


<PlatformBlock for="Blazor">

```razor
<IgbIcon @ref="CloseIcon" IconName="close" Collection="my-icons" />

@code {
    private IgbIcon CloseIcon { get; set; }

    private const string CloseSvg = "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'><path d='M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z'/></svg>";

                Name = "close",
                Collection = "my-icons",
            });
        }
    }
}
```

### サイズ

{Platform} Icon は、テーマの小、中、大のサイズ プリセットをサポートし、既定では大のプリセットを使用します。`--ig-size` CSS 変数を `--ig-size-small`、`--ig-size-medium`、または `--ig-size-large` に設定して、プリセットを選択します:

```css
.small {
  --ig-size: var(--ig-size-small);
}

.medium {
  --ig-size: var(--ig-size-medium);
}
```

### アクティブ (Active)

<ApiLink pkg="core" type="Icon" member="active" label="active" /> を `false` に設定すると、アイコンが非アクティブとして表示されます。非アクティブなアイコンは、テーマの無効状態の色を使用し、不透明度を下げて表示されます:

### アクセシブルな名前

</PlatformBlock>

## アクセシビリティ

{Platform} Icon は、近くのコンテンツを装飾するか、それ自体で意味を伝える、対話型ではない視覚要素です。

### キーボード操作

{Platform} Icon はフォーカスを受け取らず、キーボード操作はありません。`tabindex` を設定せず、キーボード イベントやポインター イベントを処理しません。ユーザーがキーボードでアイコンを操作する必要がある場合は、<PlatformBlock for="Angular">[Icon Button](../icon-button.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Icon Button](../inputs/icon-button.mdx)</PlatformBlock> を使用します。

| キー | アクション |
| --- | --- |
| n/a | Icon はキーボードで操作できません。 |

### スクリーン リーダー / ARIA

{Platform} Icon は、それ自体では何もアナウンスしません。支援技術が報告する内容は、アイコンのアクセシブルな名前によって決まります:

<PlatformBlock for="React,WebComponents">

- アイコンは、`igc-icon` 要素の属性ではなく、ElementInternals を通じてロールとアクセシブルな名前を設定します。
- 登録されたアイコンのルート `<svg>` の直接の子である `<title>` 要素が、アイコンのアクセシブルな名前になります。
- アイコンの `aria-label` 属性または `aria-labelledby` 属性は、タイトルのない SVG のアイコンに名前を付け、タイトルより優先されます。
- `igniteui-webcomponents` 7.3.0 以降では、アイコンはアクセシブルな名前がある場合にのみ `img` ロールを宣言するため、名前のないアイコンが名前のない画像として公開されることはありません。
- アイコンは、SVG を解決するときにアクセシブルな名前を確認します。これは、`name` または `collection` が変更されたとき、テーマが変更されたとき、またはアイコンが登録されたときです。`aria-label` または `aria-labelledby` は初期のマークアップで設定してください。
- `stripMeta` 登録オプションは、保存される SVG から `<title>` 要素と `<desc>` 要素を削除しますが、アイコンはタイトルのテキストをアクセシブルな名前として保持します。

</PlatformBlock>

<PlatformBlock for="Blazor">

- 登録されたアイコンのルート `<svg>` の直接の子である `<title>` 要素が、アイコンのアクセシブルな名前になります。
- アイコンの `aria-label` 属性は、タイトルのない SVG のアイコンに名前を付け、タイトルより優先されます。
- `aria-hidden="true"` 属性は、装飾的なアイコンを支援技術から隠します。

</PlatformBlock>

<PlatformBlock for="Angular">

- アイコンは、`ariaHidden` 入力を通じて既定で `aria-hidden="true"` を設定するため、支援技術はアイコンを無視します。`aria-label` だけでは、隠されたアイコンは公開されません。
- アイコンはロールを設定しません。ロールとラベルなしで `ariaHidden` を `false` に設定すると、スクリーン リーダーはリガチャ アイコンを `home` などのテキストとして読み上げます。
- 意味を伝えるアイコンを公開するには、`ariaHidden` を `false` に設定し、`img` ロールと `aria-label` を追加します。
- `active` 入力はスタイルのみを変更します。非アクティブな状態は支援技術に公開されません。

</PlatformBlock>

## トラブルシューティング

{Platform} Icon が表示されない場合や、期待どおりに表示されない場合は、次の回答を参照してください。

### アイコンが空なのはなぜですか?

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Icon は、同じ名前とコレクションで登録された SVG のみを描画します。次の原因を確認します:

- 名前またはコレクションが登録と正確に一致していません。コレクションの既定値は `default` です。
- SVG マークアップの形式が正しくありません。テキストにルートの `<svg>` 要素がない場合や解析できない場合、登録は `SVG element not found or malformed SVG string.` エラーをスローします。
- SVG ファイルのリクエストが失敗しました。URL からの登録は、OK ではない応答で失敗するため、ブラウザーのコンソールとネットワーク パネルを確認します。別のオリジンのファイルには、クロスオリジン リクエストを許可するサーバーも必要です。

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

サーバー側レンダリング中、アイコンは SVG を描画しません。ブラウザーで読み込まれた後に SVG を描画します。

</PlatformBlock>

<PlatformBlock for="Angular">

次の原因を確認します:

- リガチャ アイコンには、既定の `material` ファミリの Material Icons など、そのファミリのフォントが必要です。フォントのスタイルシートが読み込まれていることを確認します。
- SVG アイコンには、登録と同じ名前とファミリが必要です。
- `addSvgIcon` がファイルを取得するには `HttpClient` が必要です。失敗したリクエストがないかネットワーク パネルを確認します。
- サービスは SVG アイコンをブラウザーでのみキャッシュするため、サーバー側レンダリング中は SVG アイコンが表示されません。

</PlatformBlock>

### SVG アイコンにテーマの色が適用されないのはなぜですか?

{Platform} Icon はルートの `<svg>` 要素に色を適用し、子要素はそれを塗りつぶしとして継承します。色がハードコードされている子要素は、その色を保持します:

```html
<svg viewBox="0 0 24 24">
  <path fill="#050d42" d="..." />
</svg>
```

子要素からハードコードされた色を削除するか、テーマがオーバーライドするルートの `<svg>` 要素に色を設定します。アイコンの一部を意図的に着色するには、`fill="var(--ig-primary-500)"` などのテーマ カラー変数を使用します。

### アイコンにカーソルを合わせるとツールチップが表示されるのはなぜですか?

ブラウザーは、SVG の `<title>` 要素をネイティブのツールチップとして表示します。

<PlatformBlock for="React,WebComponents">

`stripMeta` オプションを指定してアイコンを登録すると、保存される SVG から `<title>` 要素と `<desc>` 要素が削除されます。アイコンはタイトルのテキストをアクセシブルな名前として保持します:

```ts
registerIconFromText('search', searchIcon, { collection: 'material', stripMeta: true });
```

</PlatformBlock>

<PlatformBlock for="Blazor">

登録する前に SVG マークアップから `<title>` 要素を削除し、アクセシブルな名前が必要なアイコンには `aria-label` を設定します。

</PlatformBlock>

<PlatformBlock for="Angular">

`addSvgIcon` または `addSvgIconFromText` の `stripMeta` 引数に `true` を渡すと、キャッシュされた SVG から `<title>` 要素と `<desc>` 要素が削除されます:

```ts
this.iconService.addSvgIcon('contains', 'assets/images/svg/contains.svg', 'filter-icons', true);
```

</PlatformBlock>

### 既知の制限事項

{Platform} Icon には次の制限事項があります:

- Icon は対話型ではない視覚要素です。フォーカスを受け取らず、キーボード入力も処理しません。
- テーマの色は、ルートの `<svg>` 要素と、その塗りつぶしを継承する子要素に適用されます。色がハードコードされている子要素は、その色を保持します。
<PlatformBlock for="React,WebComponents,Blazor">- Icon は登録された SVG アイコンのみを描画します。アイコン フォントとリガチャはサポートされていません。</PlatformBlock><PlatformBlock for="Angular">- Angular Icon には、右から左へのレイアウトでアイコンを反転するオプションがありません。</PlatformBlock>

## FAQ

これらの質問では、{Platform} Icon の一般的なセットアップ、アクセシビリティ、および使用シナリオについて説明します。

<Faq>
  <FaqItem question="Icon に Material Icons は含まれていますか?" indicatorPosition="end">
    <PlatformBlock for="Angular">はい。Material Icons フォントが読み込まれている場合、Angular Icon は既定の `material` ファミリを通じて Material Icons のリガチャを表示します。`ng add igniteui-angular` コマンドがそのフォントを追加します。その他のアイコン フォントと SVG アイコンは、`IgxIconService` で登録します。</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">いいえ。{Platform} Icon は、名前で登録した SVG アイコンを描画するため、必要な各 Material アイコンを SVG マークアップまたはファイルから登録してください。{Platform} Icon はアイコン フォントやリガチャをサポートしていません。</PlatformBlock>
  </FaqItem>
  <FaqItem question="カスタム SVG アイコンを追加するにはどうすればよいですか?" indicatorPosition="end">
    <PlatformBlock for="Angular">SVG を `IgxIconService` の `addSvgIcon` または `addSvgIconFromText` メソッドで登録し、Angular Icon に同じ `name` と `family` を設定します。サービスが SVG をキャッシュするため、その名前とファミリを持つすべての Angular Icon が SVG を表示します。</PlatformBlock><PlatformBlock for="React,WebComponents">SVG ファイルの URL を指定して `registerIcon` を呼び出すか、SVG マークアップを指定して `registerIconFromText` を呼び出し、{Platform} Icon に同じ `name` と `collection` を設定します。ページ上のすべての {Platform} Icon は 1 つのレジストリを共有するため、登録したアイコンはどこでも使用できます。</PlatformBlock><PlatformBlock for="Blazor">参照された `IgbIcon` の `RegisterIconAsync` または `RegisterIconFromTextAsync` メソッドを呼び出し、Blazor Icon に同じ `IconName` と `Collection` を設定します。ページ上のすべての Blazor Icon は 1 つのレジストリを共有するため、登録したアイコンはどこでも使用できます。</PlatformBlock>
  </FaqItem>
  <FaqItem question="アイコンをスクリーン リーダーで利用できるようにするにはどうすればよいですか?" indicatorPosition="end">
    <PlatformBlock for="Angular">Angular Icon は、`aria-hidden="true"` により、既定ではスクリーン リーダーから隠されます。それ自体で意味を伝えるアイコンには、`[ariaHidden]="false"` を設定し、`role="img"` を追加し、意味を説明する `aria-label` を追加します。</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">それ自体で意味を伝える {Platform} Icon には、`aria-label` でアクセシブルな名前を付けるか、`<title>` 要素を含む SVG を登録します。表示されているテキストの横にある装飾的な {Platform} Icon は、`aria-hidden="true"` で隠します。</PlatformBlock>
  </FaqItem>
  <FaqItem question="Icon をクリック可能にできますか?" indicatorPosition="end">
    {Platform} Icon はフォーカスを受け取らず、キーボード入力も処理しないため、Icon にクリック ハンドラーを設定すると、キーボード ユーザーが除外されます。アクションには、フォーカス可能なボタン内にアイコンを配置する {Platform} Icon Button を使用します。
  </FaqItem>
  <FaqItem question="Icon は右から左へのレイアウトをサポートしていますか?" indicatorPosition="end">
    <PlatformBlock for="Angular">Angular Icon には、アイコンを反転するオプションがありません。右から左へのレイアウトで方向を示すアイコンには、`arrow_forward` の代わりに `arrow_back` など、読み順の方向を指すアイコンを使用します。</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">はい。{Platform} Icon の `mirrored` プロパティを設定すると、矢印などの方向を示すアイコンが、右から左へのレイアウトで水平方向に反転します。方向を示さないアイコンは反転する必要はありません。</PlatformBlock>
  </FaqItem>
</Faq>
