# Tabs (タブ)

{ProductName} Tabs コンポーネントは、同じ階層レベルの関連するコンテンツをタブに整理し、選択したタブのコンテンツを表示します。

<PlatformBlock for="Angular">

Angular Tabs コンポーネントのセレクターは `igx-tabs` です。その中の各 `igx-tab-item` は、タブ ヘッダーと、タブが選択されたときに Tabs コンポーネントが表示するコンテンツを保持します。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

各タブは、ヘッダーとコンテンツを 1 つの要素に保持します。Tabs コンポーネントはキーボード ナビゲーションをサポートし、タブ ヘッダーが収まらない場合にスクロール ボタンを表示します。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

`igc-tabs` 要素は、ヘッダー ストリップとスクロール ボタンをレンダリングします。各 `igc-tab` は自身のヘッダーとコンテンツをレンダリングし、Tabs コンポーネントはすべてのタブのコンテンツをヘッダー ストリップの下<PlatformBlock for="WebComponents">、またはタブ ヘッダーが列になる場合はその横</PlatformBlock>に配置します:

```text
igc-tabs[role="tablist"]
└─ #shadow-root
   └─ div[part="tabs"]                                 // the scrollable header strip
      └─ div[part="inner"]
         ├─ igc-icon-button[part="start-scroll-button"] // rendered when the headers overflow
         ├─ slot                                       // the igc-tab elements
         │  └─ igc-tab
         │     └─ #shadow-root
         │        ├─ div[part="tab-header"][role="tab"]
         │        │  └─ div[part="base"]
         │        │     ├─ slot[name="prefix"][part="prefix"]
         │        │     ├─ div[part="content"]
         │        │     │  └─ slot[name="label"]        // falls back to the label property
         │        │     └─ slot[name="suffix"][part="suffix"]
         │        └─ div[part="tab-body"][role="tabpanel"] // visible only for the selected tab
         │           └─ slot                           // the content of the tab
         ├─ igc-icon-button[part="end-scroll-button"]   // rendered when the headers overflow
         └─ div[part="selected-indicator"]
            └─ span                                    // follows the selected tab header
```

</PlatformBlock>

<PlatformBlock for="Angular">

`igx-tabs` 要素は、各タブ項目の `igx-tab-header` からヘッダー ストリップを、各タブ項目の `igx-tab-content` からコンテンツ領域をレンダリングします:

```text
igx-tabs.igx-tabs
├─ div.igx-tabs-header
│  ├─ button.igx-tabs-header-button                 // start scroll button, hidden when the headers fit
│  ├─ div.igx-tabs-header__content
│  │  └─ div.igx-tabs-header__wrapper[role="tablist"]
│  │     ├─ div.igx-tabs-header-scroll
│  │     │  └─ igx-tab-header[role="tab"]          // one for each igx-tab-item
│  │     │     ├─ [igxPrefix]
│  │     │     ├─ div.igx-tab-header__inner        // [igxTabHeaderIcon] above [igxTabHeaderLabel]
│  │     │     └─ [igxSuffix]
│  │     └─ div.igx-tabs-header__active-indicator
│  └─ button.igx-tabs-header-button                 // end scroll button, hidden when the headers fit
└─ div.igx-tabs-content
   └─ igx-tab-content[role="tabpanel"]             // one for each igx-tab-item; renders its content only when selected
```

</PlatformBlock>

## はじめに

## 使用方法

{Platform} Tabs を使用して、同じ情報の異なるビューを整理したり、類似または関連するデータ セットを切り替えたりします。

### タイプ

Tabs には 2 つのタイプがあります。Short は既定ではテキストのみを表示し、プレフィックス アイコンとサフィックス アイコンを追加することもできます。Tall は、テキストの上にさらに 3 つ目のアイコンを表示します。

<PlatformBlock for="React,WebComponents,Blazor">

Short タブにするには、タブの `label` を設定します。Tall タブにするには、代わりに Icon と `<span>` を `label` スロットに配置すると、Tabs コンポーネントはテキストの上にアイコンを表示します。`label` スロットは `label` プロパティより優先されます。[Icon](./icon.mdx) トピックで説明されているように、最初にアイコンを登録します:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html

  <igc-tab label="Cart"></igc-tab>
  <igc-tab label="Shipping"></igc-tab>
</igc-tabs>
```

### レスポンシブ対応

Tabs は、幅を調整して使用可能な水平方向のスペースを埋める Content Fit にすることも、多数のタブ項目間を移動するためのスクロール ボタンを備えた Fixed にすることもできます。これにより、もう一方のモードと同じ合計スペースで、通常より多くのコンテンツを収めることができます。

<PlatformBlock for="Angular"><ApiLink pkg="core" type="Tabs" member="tabAlignment" label="tabAlignment" /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor"><ApiLink pkg="core" type="Tabs" member="alignment" label="alignment" /></PlatformBlock> プロパティは、{Platform} Tabs コンポーネントがタブ ヘッダーを配置する方法を設定します:

- `start` (既定): 各タブ ヘッダーはコンテンツと同じ幅になり、ヘッダーは Tabs の開始端から並びます。
- `center`: 各タブ ヘッダーはコンテンツと同じ幅になり、ヘッダーは中央に配置されます。
- `end`: 各タブ ヘッダーはコンテンツと同じ幅になり、ヘッダーは Tabs の終了端に揃います。
- `justify`: タブ ヘッダーは Tabs の幅を埋めるように伸びます。Content Fit モードで使用します。

<PlatformBlock for="WebComponents">

```html
<igc-tabs alignment="justify">
  <igc-tab label="Podcasts"></igc-tab>
  <igc-tab label="Playlists"></igc-tab>
  <igc-tab label="Genres"></igc-tab>
</igc-tabs>
```

</PlatformBlock>

```razor
    <IgbTab Label="Podcasts" />
```

タブ ヘッダーが収まらない場合、{Platform} Tabs コンポーネントはヘッダー ストリップの両端にスクロール ボタンを表示します。これが Fixed モードです。スクロール ボタンは、その方向で表示範囲外にある次のタブ ヘッダーまでストリップをスクロールし、ストリップがその端までスクロールされると無効になります。ユーザーがタブを選択すると、Tabs コンポーネントはそのヘッダーが表示されるようにスクロールします。

### 状態

タブの `selected` を設定するとそのタブがアクティブなタブになり、`disabled` を設定するとオフになります。ユーザーは無効なタブを選択できず、キーボード ナビゲーションでもスキップされます。<PlatformBlock for="React,WebComponents,Blazor"> 選択されているタブを無効にすると、{Platform} Tabs コンポーネントは最初の有効なタブを選択します。</PlatformBlock>

### 選択

<PlatformBlock for="WebComponents">

{Platform} Tabs コンポーネントは、ユーザーがクリックまたはキーでタブを選択すると、新しく選択されたタブとともに `igcChange` を発行します。コードでタブを選択するには、タブ、またはその `id` もしくは `label` を指定して <ApiLink pkg="core" type="Tabs" member="select" label="select" /> を呼び出します。選択されているタブは <ApiLink pkg="core" type="Tabs" member="selectedTab" label="selectedTab" /> から読み取ります:

```html
<igc-tabs>
  <igc-tab id="overview" label="Overview"></igc-tab>
  <igc-tab id="details" label="Details"></igc-tab>
</igc-tabs>
```

```ts
const tabs = document.querySelector('igc-tabs')!;

tabs.addEventListener('igcChange', (event) => {
  console.log(`Selected: ${event.detail.label}`);
});

tabs.select('details');
console.log(tabs.selectedTab?.label); // "Details"
```

</PlatformBlock>

<PlatformBlock for="React">

{Platform} Tabs コンポーネントは、ユーザーがクリックまたはキーでタブを選択すると、新しく選択されたタブとともに `onChange` を呼び出します。コードでタブを選択するには、タブ、またはその `id` もしくは `label` を指定して <ApiLink pkg="core" type="Tabs" member="select" label="select" /> を呼び出します:

```tsx
import { useRef } from 'react';
import { IgrTab, IgrTabs } from 'igniteui-react';

export default function ProfileTabs() {
  const tabsRef = useRef<IgrTabs>(null);

  return (
    <>
      <IgrTabs ref={tabsRef} onChange={(e: CustomEvent<IgrTab>) => console.log(e.detail.label)}>
        <IgrTab label="Overview" />
        <IgrTab label="Details" />
      </IgrTabs>
      <button onClick={() => tabsRef.current?.select('Details')}>Show details</button>
    </>
  );
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

{Platform} Tabs コンポーネントは、ユーザーがクリックまたはキーでタブを選択すると、新しく選択されたタブとともに `Change` を発生させます。コードでタブを選択するには、タブの `id` または `Label` を指定して <ApiLink pkg="core" type="Tabs" member="SelectAsync" label="SelectAsync" /> を呼び出します:

```razor
<IgbTabs @ref="Tabs" Change="OnTabChange">
    <IgbTab Label="Overview" />
    <IgbTab Label="Details" />
</IgbTabs>

<button @onclick="ShowDetails">Show details</button>

@code {
    private IgbTabs Tabs { get; set; }

    private async Task ShowDetails()
    {
        await Tabs.SelectAsync("Details");
    }

    private void OnTabChange(IgbTabComponentEventArgs e)
    {
        Console.WriteLine(e.Detail.Label);
    }
}
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

コードでタブを選択するか、タブの `selected` を設定すると、change イベントなしで選択が変更されます。Tabs コンポーネントは、無効なタブとどのタブにも一致しない値を無視します。

</PlatformBlock>

<PlatformBlock for="Angular">

選択されているタブのインデックスを読み取って設定するには、<ApiLink pkg="core" type="Tabs" member="selectedIndex" label="selectedIndex" /> をバインドします。Angular Tabs コンポーネントは、選択が変更される前に <ApiLink pkg="core" type="Tabs" member="selectedIndexChanging" label="selectedIndexChanging" /> を発行し、そのハンドラーで変更をキャンセルできます:

```html
<igx-tabs [(selectedIndex)]="selectedIndex" (selectedIndexChanging)="onSelectedIndexChanging($event)">
  <igx-tab-item>
    <igx-tab-header><span igxTabHeaderLabel>Profile</span></igx-tab-header>
    <igx-tab-content>The profile form.</igx-tab-content>
  </igx-tab-item>
  <igx-tab-item>
    <igx-tab-header><span igxTabHeaderLabel>Billing</span></igx-tab-header>
    <igx-tab-content>The billing form.</igx-tab-content>
  </igx-tab-item>
</igx-tabs>
```

```ts
import { ITabsSelectedIndexChangingEventArgs } from 'igniteui-angular/tabs';

public selectedIndex = 0;
public hasUnsavedChanges = false;

public onSelectedIndexChanging(event: ITabsSelectedIndexChangingEventArgs) {
    if (this.hasUnsavedChanges) {
        event.cancel = true;
    }
}
```

選択が変更された後、Angular Tabs コンポーネントは、変更前と変更後のタブ項目とともに <ApiLink pkg="core" type="Tabs" member="selectedItemChange" label="selectedItemChange" /> を発行します。これらのイベントは、コードで `selectedIndex` を設定した場合にも発生します。

</PlatformBlock>

### 推奨事項と非推奨事項

Tabs は情報を整理するのに適しており、チェックアウト プロセスや構成ウィザードのような、論理的な順序で進むワークフローやアクションの設計には使用しないでください。Short タブを使用する場合、同じバーでテキスト タブとアイコン タブを組み合わせないでください。2 つのコンテンツ モードのいずれかを選択し、バー内のすべての項目で一貫して使用します。

## アクセシビリティ

{Platform} Tabs コンポーネントは、WAI-ARIA タブ パターンのロールを使用します。ユーザーは Tab キーでタブ ヘッダーに移動し、矢印キーでヘッダー間を移動し、タブを選択してそのコンテンツを表示します。

### キーボード操作

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Tabs コンポーネントのヘッダー ストリップは単一のタブ ストップです。タブ順序に含まれるのは、選択されているタブ ヘッダーのみ、またはタブが選択されていない場合は最初の有効なタブ ヘッダーです。選択されているタブのコンテンツが次のタブ ストップです。タブ ヘッダーにフォーカスがある間は、次のキーが機能します:

| キー | 動作 |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | フォーカスをヘッダー ストリップの外へ、選択されているタブのコンテンツまたは前のフォーカス可能な要素に移動します。Tabs コンポーネントはこれらのキーを処理しません。 |
| <kbd>Arrow Right</kbd> | フォーカスを次の有効なタブ ヘッダーに移動し、最後のヘッダーからは最初のヘッダーに移動します。右から左へのレイアウトでは、前のヘッダーに移動します。`auto` アクティブ化では、そのタブも選択します。<PlatformBlock for="WebComponents">タブ ヘッダーの列では、Tabs コンポーネントはこのキーを処理しません。</PlatformBlock> |
| <kbd>Arrow Left</kbd> | フォーカスを前の有効なタブ ヘッダーに移動し、最初のヘッダーからは最後のヘッダーに移動します。右から左へのレイアウトでは、次のヘッダーに移動します。`auto` アクティブ化では、そのタブも選択します。<PlatformBlock for="WebComponents">タブ ヘッダーの列では、Tabs コンポーネントはこのキーを処理しません。</PlatformBlock> |
<PlatformBlock for="WebComponents">| <kbd>Arrow Down</kbd> | タブ ヘッダーの列では、フォーカスを次の有効なタブ ヘッダーに移動し、最後のヘッダーからは最初のヘッダーに移動します。`auto` アクティブ化では、そのタブも選択します。 |
| <kbd>Arrow Up</kbd> | タブ ヘッダーの列では、フォーカスを前の有効なタブ ヘッダーに移動し、最初のヘッダーからは最後のヘッダーに移動します。`auto` アクティブ化では、そのタブも選択します。 |

{Platform} Tabs コンポーネントは、`keydown` でこれらのキーを次のように処理します:

- 既定の動作を抑止するため、フォーカスを移動する矢印キー、Home、End、Space でページはスクロールしません。
- 押し続けたキーは、動作を繰り返しません。
- Shift、Ctrl、Alt、Meta キーと同時に押したキーは、何も行いません。
- Tabs コンポーネントは、フォーカスを受け取ったヘッダーが表示されるようにスクロールします。

ポインターでは、タブ ヘッダーをクリックすると、そのタブにフォーカスが移動して選択されます。無効なタブはクリックを無視します。スクロール ボタンはタブ順序に含まれません。

</PlatformBlock>

### スクリーン リーダー / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Tabs コンポーネントは、次のロールと属性をレンダリングします:

| 要素 | ロール | 属性 |
| --- | --- | --- |
| `igc-tabs` | `tablist` | `aria-orientation="horizontal"`<PlatformBlock for="WebComponents">。タブ ヘッダーの列では `aria-orientation="vertical"`</PlatformBlock>。要素の内部機能を通じて設定されます |
| 各タブの `tab-header` パーツ | `tab` | `aria-selected`、`aria-disabled`、タブのコンテンツを指す `aria-controls`、`aria-posinset`、`aria-setsize` |
| 各タブの `tab-body` パーツ | `tabpanel` | タブのヘッダーを指す `aria-labelledby` |

{Platform} Tabs コンポーネントは、支援技術に対して次のように動作します:

- タブは、ヘッダーのコンテンツ (`label` プロパティまたは `label` スロット、および `prefix` スロットと `suffix` スロットのコンテンツ) からアクセシブル名を取得します。
- 選択されていないタブのコンテンツは非表示かつ `inert` になるため、支援技術とキーボードはそれをスキップします。
- 各タブ ヘッダーの `aria-posinset` 属性と `aria-setsize` 属性により、スクリーン リーダーにセット内のタブの位置 (「3 個中 2 番目」など) が伝えられます。
- Tabs コンポーネントはライブ リージョンを使用しません。選択の変更は、`aria-selected` 状態とフォーカスを通じて支援技術に伝わります。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Tabs コンポーネントは、次のロールと属性をレンダリングします:

| 要素 | ロール | 属性 |
| --- | --- | --- |
| ヘッダー内の `div.igx-tabs-header__wrapper` 要素 | `tablist` | `aria-orientation="horizontal"`。タブ ヘッダーの列では `aria-orientation="vertical"` |
| `igx-tab-header` | `tab` | `aria-selected`、`aria-disabled`、およびタブ項目にコンテンツがある場合は `id` とコンテンツを指す `aria-controls` |
| `igx-tab-content` | `tabpanel` | タブ項目のヘッダーを指す `aria-labelledby` |

Angular Tabs コンポーネントは、支援技術に対して次のように動作します:

- タブは、`igx-tab-header` のコンテンツからアクセシブル名を取得します。
- Tabs コンポーネントは選択されているタブ項目のコンテンツのみをレンダリングするため、他のタブ項目のコンテンツは DOM に存在しません。
- ルーターを操作するタブなど、`igx-tab-content` のないタブ項目には、`id` と `aria-controls` が設定されません。
- Tabs コンポーネントはライブ リージョンを使用しません。選択の変更は、`aria-selected` 状態とフォーカスを通じて支援技術に伝わります。

</PlatformBlock>

| [2.4.3 フォーカス順序](https://www.w3.org/WAI/WCAG21/Understanding/focus-order) | ヘッダー ストリップは単一のタブ ストップで、その次が選択されているタブのコンテンツです。 |
| [2.4.7 フォーカスの可視化](https://www.w3.org/WAI/WCAG21/Understanding/focus-visible) | フォーカスされたタブ ヘッダーにはテーマのホバー色が適用されるため、他のタブ ヘッダーと区別できます。 |
| [4.1.2 名前 (name)・役割 (role)・値 (value)](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | 各タブ ヘッダーは、`tab` ロール、コンテンツからの名前、および `aria-selected` と `aria-disabled` による選択状態と無効状態を公開します。 |

ユーザーの責任:

- すべてのタブに、そのコンテンツを示すテキスト ラベルを指定します。タブはヘッダーのコンテンツからアクセシブル名を取得するため、アイコンのみのヘッダーにはテキストの代替が必要です。[タイプ](#タイプ)を参照してください。
- テーマの色をオーバーライドする場合は、[1.4.11 非テキストのコントラスト](https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast)で求められているように、選択インジケーターと背景の間で 3:1 以上のコントラスト比を維持し、フォーカスされたタブ ヘッダーが他のヘッダーと区別できるようにします。
- 順次プロセスのステップに Tabs を使用しないでください。ステップの順序を伝える Stepper を使用します。
<PlatformBlock for="Angular">- キーボード ユーザーがヘッダー ストリップに到達できるように、タブ項目を選択された状態に保ち、ルーターを操作するタブには `manual` アクティブ化を設定します。</PlatformBlock>

## 関連コンポーネント

{Platform} Tabs コンポーネントは、一度に関連するコンテンツの 1 つのセクションを表示します。コンテンツに異なる構造が必要な場合は、次のコンポーネントを使用します:

- <PlatformBlock for="Angular">[Stepper](../stepper.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Stepper](./stepper.mdx)</PlatformBlock> - チェックアウト プロセスなど、ユーザーが一連のステップを完了する場合は、Stepper (ステッパー) を使用します。
- [Accordion](./accordion.mdx) - ユーザーが縦方向のリストの複数のセクションを同時に展開する必要がある場合は、Accordion (アコーディオン) を使用します。
<PlatformBlock for="Angular">- [Bottom Navigation](../tabbar.mdx) - モバイル アプリのトップレベルのビューを画面下部から切り替えるには、Bottom Navigation を使用します。</PlatformBlock>

## FAQ

これらの質問では、{Platform} Tabs の一般的なセットアップ、アクセシビリティ、使用シナリオを取り上げます。

<Faq>
  <FaqItem question="コードでタブを選択するにはどうすればよいですか?" indicatorPosition="end">
    <PlatformBlock for="Angular">Angular Tabs の `selectedIndex` プロパティを設定するか、タブ項目の `selected` 入力を `true` に設定します。Angular Tabs コンポーネントは、これらの変更に対しても `selectedIndexChanging` と `selectedItemChange` を発行します。</PlatformBlock><PlatformBlock for="React,WebComponents">{Platform} Tabs の `select` メソッドを、タブ、またはタブの `id` もしくは `label` を指定して呼び出すか、タブの `selected` を設定します。{Platform} Tabs コンポーネントは、コードで行った選択に対して change イベントを発行しません。</PlatformBlock><PlatformBlock for="Blazor">Blazor Tabs の `SelectAsync` メソッドを、タブの `id` または `Label` を指定して呼び出すか、タブの `Selected` を設定します。Blazor Tabs コンポーネントは、コードで行った選択に対して `Change` を発生させません。</PlatformBlock>
  </FaqItem>
  <FaqItem question="ユーザーが別のタブに切り替えられないようにできますか?" indicatorPosition="end">
    <PlatformBlock for="Angular">はい。Angular Tabs の `selectedIndexChanging` イベントを処理し、`cancel` を `true` に設定して現在のタブを維持します。たとえば、タブ内のフォームに未保存の変更がある場合です。タブを常に使用不可にするには、タブ項目の `disabled` を設定します。</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">{Platform} Tabs コンポーネントの change イベントは、選択が変更された後に発行されるため、キャンセルできません。ユーザーが開いてはならないタブには `disabled` を設定し、使用可能になったときに有効にします。</PlatformBlock>
  </FaqItem>
  <FaqItem question="Tabs コンポーネントは、非表示のタブのコンテンツを DOM に保持しますか?" indicatorPosition="end">
    <PlatformBlock for="Angular">いいえ。Angular Tabs コンポーネントは、選択されているタブ項目のコンテンツを DOM に追加し、他のタブ項目のコンテンツを DOM から削除します。`document.querySelector` などの DOM を照会するコードは、選択されているタブ項目のコンテンツのみを検出します。</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">はい。{Platform} Tabs コンポーネントはすべてのタブのコンテンツを DOM に保持し、選択されていないタブのコンテンツを非表示にして `inert` にするため、そのタブが選択されるまで、ユーザーと支援技術はそれにアクセスできません。</PlatformBlock>
  </FaqItem>
  <FaqItem question="チェックアウトなどの段階的なプロセスに Tabs を使用すべきですか?" indicatorPosition="end">
    いいえ。{Platform} Tabs コンポーネントは、ユーザーが任意の順序で開くことができる関連情報を整理するものであり、ステップの順序を伝えません。チェックアウトや構成ウィザードなどの順次プロセスには、{Platform} Stepper を使用します。
  </FaqItem>
  <PlatformBlock for="Angular,WebComponents"><FaqItem question="縦方向のタブを作成するにはどうすればよいですか?" indicatorPosition="end">
    {Platform} Tabs の `headerPosition` プロパティ<PlatformBlock for="WebComponents"> (HTML では `header-position` 属性)</PlatformBlock>を `start` または `end` に設定すると、タブ ヘッダーがコンテンツの前または後ろに列として表示されます。{Platform} Tabs のサイズを固定するには、高さを指定します。
  </FaqItem></PlatformBlock>
</Faq>
