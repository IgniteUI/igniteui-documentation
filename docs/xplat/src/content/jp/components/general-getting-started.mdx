## Ignite UI CLI の使用

アプリケーションを最初から作成し、Ignite UI React  を使用するように構成するには、Ignite UI CLI を使用できます。最初の手順には、以下のように各パッケージをグローバルにインストールします。
</PlatformBlock>

<PlatformBlock for="React">

```cmd
npm install -g igniteui-cli
```

</PlatformBlock>

<PlatformBlock for="React">
使用可能なオプションをガイド付きで体験したい場合は、新しいアプリケーションの作成とセットアップに役立つ手順モードを初期化できます。ガイドを開始するには、`ig` コマンドを実行します。
</PlatformBlock>

<PlatformBlock for="React">

```cmd
ig
```

</PlatformBlock>

<PlatformBlock for="React">
次に、フレームワークとして `React` を選択し、プロジェクト タイプとして `Ignite UI for React TS` を選択します。ナビゲーション レイアウトで始めるには **Side Navigation** または **Side Navigation Mini** を選択します。これらのナビゲーション テンプレートを選択すると、認証を追加するかどうかを確認するプロンプトが表示されます。**Empty** テンプレートでは認証プロンプトは表示されません。その後、特定のコンポーネント/ビューを追加するか、`Complete & Run` を選択します。

または、プロジェクトを直接作成することもできます。例:
</PlatformBlock>

<PlatformBlock for="React">

```cmd
ig new <project-name> --framework=react --type=igr-ts --template=side-nav
```

</PlatformBlock>

<PlatformBlock for="React">
コマンド、テンプレート ID、直接認証テンプレートの全リファレンスについては、[CLI の概要](./general-cli-overview.mdx)を参照してください。

### Ignite UI React Grid コンポーネントの追加

</PlatformBlock>

<PlatformBlock for="React">

```cmd
npm install igniteui-react-grids --save
```

</PlatformBlock>

<PlatformBlock for="React">
#### コンポーネント モジュールのインポート

次に、使いたいコンポーネントの必要なモジュールをインポートします。テンプレートでも使用する Grid コンポーネントと Column コンポーネントに対しても、同じことを実行してみましょう。テーマの 1 つをインポートする必要もあります。
</PlatformBlock>

<PlatformBlock for="React">

```ts

import 'igniteui-react-grids/grids/themes/light/bootstrap.css';
```

</PlatformBlock>

<PlatformBlock for="React">
#### コンポーネントの使用

マークアップに {ProductName} グリッド コンポーネントを使用する準備が整いました。以下のように定義します。
</PlatformBlock>

<PlatformBlock for="React">

```tsx
// App.txs
function App() {
  const data = [
    { name: "John", age: 30 },
    { name: "Jane", age: 25 },
    { name: "Bob", age: 35 }
  ];

  return (
    <div style={{ height: "100%", width: "100%" }}>
      <IgrGrid
        data={data}
        autoGenerate={false}>
        <IgrColumn
          field="name"
          header="Name"
          dataType="string">
        </IgrColumn>
        <IgrColumn
          field="age"
          header="Age"
          dataType="number">
        </IgrColumn>
      </IgrGrid>
    </div>
  );
}
```

</PlatformBlock>

# {ProductName} パッケージの概要

{ProductName} は、React 向けの UI コンポーネント、デザイン ツールキット、関連サービスを包括的に提供するスイートです。デスクトップ ブラウザー、モバイル環境、PWA (Progressive Web App) など、あらゆる React アプリケーションでモダンかつ高パフォーマンスな開発を実現できるよう、開発者を強力にサポートします。

</PlatformBlock>

<PlatformBlock for="WebComponents, React">

## チャートおよびグラフ
{ProductName} には、[チャートとグラフ](./charts/chart-overview.mdx)のライブラリが含まれており、65 種類以上のシチャート リーズと組み合わせを通じて、あらゆる種類のデータを魅力的でインタラクティブなグラフとダッシュボードに視覚化できるライブラリです。速度と美しさを追求し、すべてのモダンブラウザーで動作するように設計されており、完全なタッチ操作とインタラクティブ機能により、あらゆるデバイスでレスポンシブなビジュアルをすばやく構築できます。

## ゲージ
{ProductName} は、簡単かつ直感的な方法でデータを示すために使用される[ラジアル ゲージ](./radial-gauge.mdx)、[リニア ゲージ](./linear-gauge.mdx)と[バレット グラフ](./bullet-graph.mdx) コンポーネントを提供します。[ラジアル ゲージ](./radial-gauge.mdx)には、定義済みの形状とスケールを作成するためのさまざまなカスタマイズ オプションがあります。[リニア ゲージ](./linear-gauge.mdx)は、スケールおよび 1 つ以上の範囲と比較した値の単純なビューを提供します。1 つのスケール、1 セットの目盛り、および 1 セットのラベルをサポートします。[バレット グラフ](./bullet-graph.mdx) コンポーネントを使用すると、ダッシュボードで使用されるメーターやゲージを単純な棒チャートに置き換えて、データの視覚化を作成できます。

## マップ
{ProductName} [地理マップ](./geo-map.mdx) コンポーネントは、アプリケーションで地理データを視覚化する機能を提供します。マーカー、線、多角形、さらにはインタラクティブなビットマップの形状で、多くの地理的位置で構成されるデータ セットを描画できます。複数のマップ レイヤーを地理データでオーバーレイし、特定の地理的位置をマークし、カスタム マーカーと色を使用して情報を表示できます。

## グリッドと入力
{ProductName} は、少ない構成でデータをバインドして表示できる複数の[グリッド](./grids/grids-header.mdx) コンポーネントを提供します。[グリッド ライト](./grid-lite/overview.mdx) - MIT ライセンスの下にある軽量グリッド コンポーネント、[データ グリッド](./grids/data-grid.mdx) - 商用ライセンスの下にある機能豊富なグリッド コンポーネント、[リスト](./grids/list.mdx)、[ツリー](./grids/tree.mdx)、さらには [スプレッドシート](./spreadsheet-overview.mdx)の形式で提供されます。

## ボタン、入力、レイアウト、メニュー
{ProductName} は、依存関係のないアプローチでカプセル化と再利用可能なコンポーネントの概念を使用して、最新の Web アプリケーションを構築できるようにするさまざまなタイプの[ボタン](./inputs/button.mdx)、[入力](./inputs/input.mdx)、[メニュー](./menus/navbar.mdx)、[レイアウト](./layouts/tabs.mdx)を提供します。[ストーリーブックはこちら](https://igniteui.github.io/igniteui-webcomponents)をご覧くださ。これらのコンポーネントは [Indigo Design System](https://jp.infragistics.com/products/appbuilder/ui-toolkit) に基づいており、[App Builder](https://appbuilder.indigo.design/) によって完全にサポートされており、Figma 用のすぐに使用できる UI キットによって支えられています。

以下の手順では、新しい Blazor Server プロジェクトを作成する方法を説明します。Ignite UI for Blazor を既存のアプリケーションに追加する場合は、[**Ignite UI for Blazor パッケージをインストール**](#ignite-ui-for-blazor-のインストール) セクションに移動します。

Visual Studio 2022 を起動し、開始ページで **[新しいプロジェクトの作成]** をクリックし、**Blazor Server App** テンプレートを選択して、**[次へ]** をクリックします。

<Image src={newBlazorProjectConfigureServer} alt="new-blazor-configure-server" />

<Image src={newBlazorProjectInfoServer} alt="new-blazor-info-server" />

### Ignite UI for Blazor のインストール

Ignite UI for Blazor は、NuGet パッケージで提供されます。Blazor アプリケーションで Ignite UI for Blazor コンポーネントを使用するには、最初に適切な NuGet パッケージをインストールする必要があります。

Visual Studio で、**[ツール]** → **[NuGet パッケージ マネージャー]** → **[ソリューションの NuGet パッケージの管理]** を選択して、NuGet パッケージ マネージャーを開きます。**IgniteUI.Blazor** NuGet パッケージを検索してインストールします。

NuGet を使用した Ignite UI for Blazor のインストールの詳細については、[Ignite UI for Blazor のインストール](./general-installing-blazor.mdx) トピックを参照してください。

## {ProductName} を使用した作業の開始

このトピックでは、Visual Studio および {ProductName} を使用して {Platform} アプリケーションを作成するための手順を説明します。

### 前提条件

- **Windows アプリケーション開発** ワークロードを含む Visual Studio 2022
- **Windows App SDK** (プロジェクト テンプレートが `Microsoft.WindowsAppSDK` パッケージとしてインストールします)
- `net9.0-windows10.0.19041.0` 以降を対象とするプロジェクト

### 新しい {Platform} プロジェクトの作成

Visual Studio 2022 を起動し、開始ページで **[新しいプロジェクトの作成]** をクリックし、**Blank App, Packaged (WinUI 3 in Desktop)** テンプレートを選択して、**[次へ]** をクリックします。プロジェクト名と場所を指定して、**[作成]** をクリックします。

### {ProductName} のインストール

{ProductName} は NuGet パッケージとして提供されます。Visual Studio で **[ツール]** → **[NuGet パッケージ マネージャー]** → **[ソリューションの NuGet パッケージの管理]** を選択し、使用するコントロールのパッケージをインストールします。以下のすべてのパッケージには **Infragistics.WinUI.Core** が必要です。

| パッケージ | コントロール | 宣言する名前空間 |
| --- | --- | --- |
| `Infragistics.WinUI.Core` | 以下のすべてに必要 | `Infragistics.Controls` |
| `Infragistics.WinUI.Charts` | チャートおよびグラフ | `Infragistics.Controls.Charts` |
| `Infragistics.WinUI.DataGrid` | データ グリッド | `Infragistics.Controls.Grids` |
| `Infragistics.WinUI.Gauges` | 放射、線形、およびブレット ゲージ | `Infragistics.Controls.Gauges` |
| `Infragistics.WinUI.Maps` | 地理マップ | `Infragistics.Controls.Maps` |
| `Infragistics.WinUI.Inputs` | 入力およびエディター | `Infragistics.Controls.Inputs` |
| `Infragistics.WinUI.Layouts` | ツールバーおよびレイアウト パネル | `Infragistics.Controls.Layouts` |
| `Infragistics.WinUI.Dashboards` | ダッシュボード タイル | `Infragistics.Controls.Dashboards` |
| `Infragistics.WinUI.Sparkline` | スパークライン | `Infragistics.Controls.Charts` |
| `Infragistics.WinUI.TreeMap` | ツリーマップ | `Infragistics.Controls.Charts` |
| `Infragistics.WinUI.DataVisualization` | ビジュアライゼーション コントロールの共通サポート | — |
| `Infragistics.WinUI.SkiaSharp` | オプションの SkiaSharp レンダリング バックエンド | — |

ライセンス ユーザーは、これらのパッケージを Infragistics のプライベート NuGet フィードから取得します。Visual Studio の **[ツール]** → **[NuGet パッケージ マネージャー]** → **[パッケージ マネージャー設定]** で、ソースに `https://packages.infragistics.com/nuget/licensed/v3/index.json` を指定してパッケージ ソースとして追加します。

### 名前空間の追加

コントロールの各パッケージは独自の名前空間に属しており、XAML ファイルでは使用するものを宣言します。{Platform} では `using:` 形式を使用します。

```xaml
<Window
    xmlns:ig="using:Infragistics.Controls"
    xmlns:igCharts="using:Infragistics.Controls.Charts"
    xmlns:igDataGrids="using:Infragistics.Controls.Grids"
    xmlns:igGauges="using:Infragistics.Controls.Gauges"
    xmlns:igMaps="using:Infragistics.Controls.Maps"
    xmlns:igDashboards="using:Infragistics.Controls.Dashboards"
    xmlns:igInputs="using:Infragistics.Controls.Inputs"
    xmlns:igLayouts="using:Infragistics.Controls.Layouts">
</Window>
```

宣言が必要なのは、ファイルで実際に使用するものだけです。これらのトピックのコード スニペットはすべてこれらのプレフィックスで記述されているため、`igDataGrids:XamDataGrid` を示すスニペットには上記の `igDataGrids` の宣言が必要です。

### コントロールの作成

パッケージをインストールして名前空間を宣言すれば、コントロールは他の要素と同じようにマークアップで記述できます。以下は、上記で宣言した `igGauges` プレフィックスを使用して、ウィンドウに放射ゲージを追加します。

```json-snippet source="/gauges/radial-gauge/needle"
{
    "type": "RadialGauge",
    "name": "gauge",
    "value": 50,
    "minimumValue": 0,
    "maximumValue": 80,
    "interval": 10
}
```

プロジェクトを実行すると、ゲージがスケール、目盛り、および 50 を指す針を描画します。各コントロールのトピックは、このようなブロックから始まり、そのトピックが扱うプロパティを追加していきます。

## {ProductName} を使用した作業の開始

{ProductName} は、専用のパッケージ セットを通じて Uno Platform で動作します。コントロール、そのプロパティ、および XAML は WinUI のトピックで示しているものと同じで、異なるのはプロジェクトの作成方法と、提供されるパッケージです。

### 前提条件

Uno Platform には、単一の Visual Studio ワークロードではなく独自のソリューション テンプレートと前提条件チェックがあり、いずれもこのトピックより速く変化します。プロジェクトの作成と `uno-check` の実行については、Uno Platform の [Getting Started](https://platform.uno/docs/articles/get-started.html) を参照し、その後このトピックに戻って {ProductName} を追加してください。

### {ProductName} のインストール

{ProductName} は NuGet パッケージとして提供されます。以下のすべてのパッケージには **Infragistics.Uno.Core** が必要です。

| パッケージ | コントロール | 宣言する名前空間 |
| --- | --- | --- |
| `Infragistics.Uno.Core` | 以下のすべてに必要 | `Infragistics.Controls` |
| `Infragistics.Uno.Charts` | チャートおよびグラフ | `Infragistics.Controls.Charts` |
| `Infragistics.Uno.DataGrid` | データ グリッド | `Infragistics.Controls.Grids` |
| `Infragistics.Uno.Gauges` | 放射、線形、およびブレット ゲージ | `Infragistics.Controls.Gauges` |
| `Infragistics.Uno.DataVisualization` | ビジュアライゼーション コントロールの共通サポート | — |

WebAssembly ヘッドでは、代わりに `Infragistics.Uno.Wasm.*` パッケージ (**Infragistics.Uno.Wasm.Core**、**Infragistics.Uno.Wasm.Charts**、**Infragistics.Uno.Wasm.DataVisualization**) を使用します。

これは WinUI よりも狭いセットです。地理マップ、ダッシュボード タイル、入力、レイアウト、スパークライン、ツリーマップには Uno のパッケージがないため、これらを扱うトピックには Uno のコードがありません。

ライセンス ユーザーは、これらのパッケージを Infragistics のプライベート NuGet フィードから取得します。Visual Studio の **[ツール]** → **[NuGet パッケージ マネージャー]** → **[パッケージ マネージャー設定]** で、ソースに `https://packages.infragistics.com/nuget/licensed/v3/index.json` を指定してパッケージ ソースとして追加します。

### 名前空間の追加

Uno は WinUI と同じ `using:` 形式と同じ名前空間を使用します。

```xaml
<Page
    xmlns:ig="using:Infragistics.Controls"
    xmlns:igCharts="using:Infragistics.Controls.Charts"
    xmlns:igDataGrids="using:Infragistics.Controls.Grids"
    xmlns:igGauges="using:Infragistics.Controls.Gauges">
</Page>
```

宣言が必要なのは、ファイルで実際に使用するものだけです。これらのトピックのコード スニペットはすべてこれらのプレフィックスで記述されています。
