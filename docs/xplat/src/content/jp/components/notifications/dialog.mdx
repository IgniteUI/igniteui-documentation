# Dialog (ダイアログ)

{ProductName} Dialog は、ユーザーが操作を完了するか閉じるまで続行できないモーダル ウィンドウで、メッセージ、確認、またはフォームを表示するコンポーネントです。

<PlatformBlock for="Angular">

Angular Dialog は `igx-dialog` コンポーネントです。タイトル、メッセージ、および最大 2 つの組み込みボタン、またはプロジェクションしたタイトル、コンテンツ、アクションを表示します。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Dialog はネイティブの `dialog` 要素に基づいています。タイトル、メッセージ、コンテンツ、およびフッターのアクション ボタンを表示し、ユーザーが Escape キーを押すと閉じます。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

`igc-dialog` 要素は、背景 (バックドロップ) と、ヘッダー、コンテンツ セクション、フッターを持つネイティブの `dialog` 要素をレンダリングします:

```text
igc-dialog
└─ #shadow-root
   ├─ div[part="backdrop"]                       // the backdrop behind the open dialog
   └─ dialog[part="base"][role="dialog"]         // opened as a modal dialog
      ├─ header[part="title"]                    // hidden when the dialog has no title
      │  └─ slot[name="title"]                   // falls back to the title property
      ├─ section[part="content"]
      │  ├─ slot[name="message"]                 // hidden when empty
      │  └─ slot                                 // the content of the dialog
      └─ footer[part="footer"]
         └─ slot[name="footer"]                  // falls back to the default OK button
```

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Dialog が開いている間、オーバーレイは `igx-dialog` 要素の内側に、ページの最上位レイヤーでレンダリングします:

```text
igx-dialog
└─ div.igx-overlay__wrapper--modal[popover="manual"]  // the backdrop of a modal dialog
   └─ div.igx-overlay__content--modal
      └─ div.igx-dialog[tabindex="0"]                 // keeps the focus inside the dialog
         └─ div.igx-dialog__window[role]
            ├─ div.igx-dialog__window-title           // the title, or the projected igx-dialog-title
            ├─ div.igx-dialog__window-content
            │  └─ span.igx-dialog__window-message      // the message, or the projected content
            └─ div.igx-dialog__window-actions          // the built-in buttons, or the projected igx-dialog-actions
```

</PlatformBlock>

<PlatformBlock for="Angular">

プロジェクトで {ProductName} をまだ使用していない場合は、`ng add igniteui-angular` を実行します。次に、`IGX_DIALOG_DIRECTIVES` トークンをインポートし、コンポーネントの `imports` に追加します。このトークンには、<ApiLink pkg="core" type="Dialog" />、`igx-dialog-title` ディレクティブ、`igx-dialog-actions` ディレクティブが含まれます。ダイアログの組み込みボタンには追加のインポートは不要です。次の例では、ダイアログを開くボタン用に `IgxButtonDirective` をインポートしています:

```ts
import { Component } from '@angular/core';
import { IGX_DIALOG_DIRECTIVES } from 'igniteui-angular/dialog';
import { IgxButtonDirective } from 'igniteui-angular/directives';
// import { IGX_DIALOG_DIRECTIVES } from '@infragistics/igniteui-angular/dialog'; for licensed package

@Component({
    selector: 'app-home',
    template: `
        <button igxButton="contained" (click)="dialog.open()">Delete file</button>

        <igx-dialog #dialog
            title="Delete File"
            message="Are you sure you want to delete this file?"
            leftButtonLabel="Cancel"
            (leftButtonSelect)="dialog.close()"
            rightButtonLabel="Delete"
            (rightButtonSelect)="dialog.close()">
        </igx-dialog>
    `,
    imports: [IGX_DIALOG_DIRECTIVES, IgxButtonDirective]
})
export class HomeComponent {}
```

組み込みボタンは、Angular Dialog を自動的には閉じません。`leftButtonSelect` イベントと `rightButtonSelect` イベントのハンドラーで `close()` を呼び出します。

</PlatformBlock>

## 使用方法

{Platform} Dialog は、ユーザーにメッセージやアラートを表示して適切な操作を行えるようにする場合や、ログインなど、続行する前に直ちに対応が必要なフォームを提示する場合に使用します。Dialog はモーダルで表示されるため、ユーザーは次に進む前に Dialog を完了するか閉じる必要があります。

### 種類

Dialog は、確認ボタンのみのアラート、キャンセルと確認を持つメッセージ、またはユーザーのアカウントへのログインなど、直ちに対応が必要な操作のコンテナーとして使用できます。ボタン領域はテンプレート化できるため、たとえばボタンを調整できます。

<PlatformBlock for="React,WebComponents,Blazor">

アラートの場合は `footer` スロットを空のままにすると、{Platform} Dialog はダイアログを閉じる既定の OK ボタンを表示します。確認の場合は、キャンセル ボタンと確認ボタンを `footer` スロットに配置します。カスタム ダイアログの場合は、コントロールをダイアログのコンテンツに配置します:

</PlatformBlock>

### タイトルとコンテンツ

<PlatformBlock for="React,WebComponents,Blazor">

<ApiLink pkg="core" type="Dialog" member="title" label="title" /> プロパティは、ダイアログ ヘッダーのテキストを設定します。アイコンなどの他のコンテンツをヘッダーに表示するには、`title` スロットに配置します。このスロットはプロパティより優先されます。短いメッセージは `message` スロットに配置します。{Platform} Dialog は、このメッセージを他のコンテンツの上に表示し、幅を 40 文字に制限します。ダイアログに配置するその他の内容はすべてコンテンツになります:

</PlatformBlock>

```html
</igc-dialog>
```

</PlatformBlock>

```tsx
<IgrDialog>

</IgrDialog>
```

</PlatformBlock>

<PlatformBlock for="Angular">

<ApiLink pkg="core" type="Dialog" member="title" label="title" /> プロパティと <ApiLink pkg="core" type="Dialog" member="message" label="message" /> プロパティは、ダイアログ ヘッダーとダイアログ本文のテキストを設定します。アイコンなどの他のコンテンツをヘッダーに表示するには、`igx-dialog-title` 要素、または `igxDialogTitle` ディレクティブを持つ要素をプロジェクションします。ダイアログに配置するその他の内容はすべてコンテンツになります。`title` を設定すると、Angular Dialog はプロジェクションされたタイトルを無視し、`message` を設定すると、プロジェクションされたコンテンツを無視します:

```html
<igx-dialog #dialog>

    <span>Delete File</span>
  </igx-dialog-title>
  <p>Are you sure you want to delete Annual_Report_2026.pdf?</p>
  <igx-dialog-actions>
    <button igxButton="flat" (click)="dialog.close()">Cancel</button>
    <button igxButton="contained" (click)="dialog.close()">Delete</button>
  </igx-dialog-actions>
</igx-dialog>
```

### アクション ボタン

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Dialog のアクション ボタンは `footer` スロットに配置します。スロットが空の場合、ダイアログはダイアログを閉じて closing イベントを発生させる既定の OK ボタンを表示します。ダイアログのコンテンツに独自のボタンがある場合などに既定のボタンを非表示にするには、<ApiLink pkg="core" type="Dialog" member="hideDefaultAction" label="hideDefaultAction" /> を設定します。`footer` スロットにコンテンツがある場合、このプロパティは効果がありません:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-dialog title="Processing" hide-default-action>
  <p>Exporting the report. This can take a few seconds.</p>
</igc-dialog>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrDialog title="Processing" hideDefaultAction={true}>
  <p>Exporting the report. This can take a few seconds.</p>
</IgrDialog>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDialog Title="Processing" HideDefaultAction="true">
    <p>Exporting the report. This can take a few seconds.</p>
</IgbDialog>
```

</PlatformBlock>

<PlatformBlock for="Angular">

<ApiLink pkg="core" type="Dialog" member="leftButtonLabel" label="leftButtonLabel" /> プロパティと <ApiLink pkg="core" type="Dialog" member="rightButtonLabel" label="rightButtonLabel" /> プロパティは組み込みボタンを追加し、各ボタンはラベルが設定されている場合にのみレンダリングされます。`leftButtonType` プロパティと `rightButtonType` プロパティはボタンのバリアント (既定は `flat`) を設定し、`leftButtonRipple` プロパティと `rightButtonRipple` プロパティはリップルの色を設定します。組み込みボタンをクリックすると <ApiLink pkg="core" type="Dialog" member="leftButtonSelect" label="leftButtonSelect" /> または <ApiLink pkg="core" type="Dialog" member="rightButtonSelect" label="rightButtonSelect" /> が発生し、`close()` を呼び出すまでダイアログは開いたままになります:

```html
<igx-dialog #dialog
    title="Delete File"
    message="Are you sure you want to delete this file?"
    leftButtonLabel="Cancel"
    (leftButtonSelect)="dialog.close()"
    rightButtonLabel="Delete"
    rightButtonType="contained"
    (rightButtonSelect)="deleteFile(); dialog.close()">
</igx-dialog>
```

その他のボタンは、`igx-dialog-actions` 要素、または `igxDialogActions` ディレクティブを持つ要素を使用してダイアログにプロジェクションします。ボタン ラベルを設定すると、Angular Dialog はプロジェクションされたアクションを無視します。

</PlatformBlock>

### 開閉

<PlatformBlock for="React,WebComponents,Blazor">

次のメソッドで {Platform} Dialog を開閉します。これらのメソッドは、開くアニメーションと閉じるアニメーションを再生します:

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

- <ApiLink pkg="core" type="Dialog" member="show" label="show" /> はダイアログを開きます。
- <ApiLink pkg="core" type="Dialog" member="hide" label="hide" /> はダイアログを閉じます。
- <ApiLink pkg="core" type="Dialog" member="toggle" label="toggle" /> は、ダイアログが閉じているときは開き、開いているときは閉じます。

各メソッドは、ダイアログがすでに要求された状態にある場合、`false` に解決される Promise を返します。<ApiLink pkg="core" type="Dialog" member="open" label="open" /> プロパティでもダイアログを開閉できますが、アニメーションは再生されません。

</PlatformBlock>

<PlatformBlock for="Blazor">

- <ApiLink pkg="core" type="Dialog" member="ShowAsync" label="ShowAsync" /> はダイアログを開きます。
- <ApiLink pkg="core" type="Dialog" member="HideAsync" label="HideAsync" /> はダイアログを閉じます。
- <ApiLink pkg="core" type="Dialog" member="ToggleAsync" label="ToggleAsync" /> は、ダイアログが閉じているときは開き、開いているときは閉じます。

各メソッドは、ダイアログがすでに要求された状態にある場合、`false` を返します。<ApiLink pkg="core" type="Dialog" member="Open" label="Open" /> パラメーターでもダイアログを開閉できますが、アニメーションは再生されず、ユーザーがダイアログを閉じても値は変更されません。状態を同期するには、メソッドを使用します。

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

これらのメソッドと `open` プロパティは、closing イベントを発生させません。コードを使用せずにダイアログを開閉するには、[Invoker Commands API](https://developer.mozilla.org/en-US/docs/Web/API/Invoker_Commands_API) をサポートするブラウザーで、ボタンに `command` 属性と `commandfor` 属性を追加します。`command` には `--show`、`--hide`、または `--toggle` を設定し、`commandfor` にはダイアログの `id` を設定します:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-button command="--show" commandfor="delete-dialog">Delete file</igc-button>

<igc-dialog id="delete-dialog" title="Delete File">
  <p>Are you sure you want to delete this file?</p>
  <igc-button slot="footer" variant="flat" command="--hide" commandfor="delete-dialog">Cancel</igc-button>
</igc-dialog>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton command="--show" commandfor="delete-dialog">Delete file</IgrButton>

<IgrDialog id="delete-dialog" title="Delete File">
  <p>Are you sure you want to delete this file?</p>
  <IgrButton slot="footer" variant="flat" command="--hide" commandfor="delete-dialog">Cancel</IgrButton>
</IgrDialog>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbButton Command="--show" Commandfor="delete-dialog">Delete file</IgbButton>

<IgbDialog id="delete-dialog" Title="Delete File">
    <p>Are you sure you want to delete this file?</p>
    <IgbButton slot="footer" Variant="ButtonVariant.Flat" Command="--hide" Commandfor="delete-dialog">Cancel</IgbButton>
</IgbDialog>
```

</PlatformBlock>

<PlatformBlock for="Angular">

次のメソッドで Angular Dialog を開閉します。これらのメソッドは、開くアニメーションと閉じるアニメーションを再生します:

- <ApiLink pkg="core" type="Dialog" member="open" label="open" /> はダイアログを開きます。[位置とアニメーション](#位置とアニメーション)で説明するように、任意のオーバーレイ設定を指定できます。
- <ApiLink pkg="core" type="Dialog" member="close" label="close" /> はダイアログを閉じます。
- <ApiLink pkg="core" type="Dialog" member="toggle" label="toggle" /> は、ダイアログが閉じているときは開き、開いているときは閉じます。

コンポーネントのプロパティからダイアログを制御するには、<ApiLink pkg="core" type="Dialog" member="isOpen" label="isOpen" /> を双方向にバインドします。ユーザーがダイアログを閉じると、プロパティは `false` に変わります:

```html
<button igxButton="contained" (click)="showDialog = true">Delete file</button>

<igx-dialog [(isOpen)]="showDialog"
    title="Delete File"
    message="Are you sure you want to delete this file?"
    leftButtonLabel="Cancel"
    (leftButtonSelect)="showDialog = false">
</igx-dialog>
```

Angular Dialog は、開く前と閉じる前に <ApiLink pkg="core" type="Dialog" member="opening" label="opening" /> と <ApiLink pkg="core" type="Dialog" member="closing" label="closing" /> を発生させ、アニメーションの終了後に <ApiLink pkg="core" type="Dialog" member="opened" label="opened" /> と <ApiLink pkg="core" type="Dialog" member="closed" label="closed" /> を発生させます。これらのイベントは、コードでダイアログを開閉した場合にも発生します。ダイアログを現在の状態のままにするには、`opening` または `closing` のハンドラーで `cancel` を `true` に設定します。

</PlatformBlock>

### Escape キーと外部クリックによる閉じる動作

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Dialog は、ユーザーが Escape キーを押すと閉じます。未保存の作業を保護している間など、開いたままにするには、<ApiLink pkg="core" type="Dialog" member="keepOpenOnEscape" label="keepOpenOnEscape" /> を設定します。ユーザーが背景をクリックしたときにダイアログを閉じるには、<ApiLink pkg="core" type="Dialog" member="closeOnOutsideClick" label="closeOnOutsideClick" /> を設定します:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-dialog title="Edit Profile" keep-open-on-escape>
  ...
</igc-dialog>

<igc-dialog title="Shortcuts" close-on-outside-click>
  ...
</igc-dialog>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrDialog title="Edit Profile" keepOpenOnEscape={true}>
  ...
</IgrDialog>

<IgrDialog title="Shortcuts" closeOnOutsideClick={true}>
  ...
</IgrDialog>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDialog Title="Edit Profile" KeepOpenOnEscape="true">
    ...
</IgbDialog>

<IgbDialog Title="Shortcuts" CloseOnOutsideClick="true">
    ...
</IgbDialog>
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

ユーザーが Escape キー、背景のクリック、既定の OK ボタン、または送信されたフォームでダイアログを閉じると、{Platform} Dialog は閉じる前に closing イベントを発生させ、閉じるアニメーションの終了後に closed イベントを発生させます。ダイアログを開いたままにするには、closing イベントをキャンセルします:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
const dialog = document.querySelector('igc-dialog')!;

dialog.addEventListener('igcClosing', (event) => {
  if (event.target === dialog && hasUnsavedChanges) {
    event.preventDefault();
  }
});
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrDialog
  title="Edit Profile"
  onClosing={(event: CustomEvent<void>) => {
    if (event.target === event.currentTarget && hasUnsavedChanges) {
      event.preventDefault();
    }
  }}>
  ...
</IgrDialog>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

<ApiLink pkg="core" type="Dialog" member="Closing" label="Closing" /> コールバックは、ブラウザーがイベントを処理した後に実行されるため、閉じる動作をキャンセルできません。キャンセルするには、<ApiLink pkg="core" type="Dialog" member="ClosingScript" label="ClosingScript" /> に、`igRegisterScript` で登録した JavaScript 関数の名前を設定します:

```razor
<IgbDialog Title="Edit Profile" ClosingScript="onDialogClosing">
    ...
</IgbDialog>
```

```javascript
// In JavaScript
function onDialogClosing(event) {
    if (event.target === event.currentTarget && window.hasUnsavedChanges) {
        event.preventDefault();
    }
}

igRegisterScript("onDialogClosing", onDialogClosing, false);
```

`_content/IgniteUI.Blazor/app.bundle.js` スクリプトが `igRegisterScript` を定義しているため、他の用途でこのスクリプトを必要としないアプリでも、関数を登録するスクリプトの前に、ホスト ページでこのスクリプトを参照します:

```html
<script src="_content/IgniteUI.Blazor/app.bundle.js"></script>
<script src="_framework/blazor.webassembly.js"></script>
<script src="dialog-events.js"></script>
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Select など、開閉するダイアログ内のコンポーネントは、ダイアログまでバブリングする独自の `igcClosing` イベントと `igcClosed` イベントを発生させます。上記の例のように、イベントを処理する前に、イベントのターゲットがダイアログであることを確認してください。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Dialog は、ユーザーが Escape キーを押すと閉じます。未保存の作業を保護している間など、開いたままにするには、<ApiLink pkg="core" type="Dialog" member="closeOnEscape" label="closeOnEscape" /> を `false` に設定します。ユーザーがダイアログの外側をクリックしたときにダイアログを閉じるには、<ApiLink pkg="core" type="Dialog" member="closeOnOutsideSelect" label="closeOnOutsideSelect" /> を `true` に設定します。ダイアログはこれらのプロパティを開くときに読み取るため、ダイアログが開いている間の変更は、次に開くときに反映されます:

```html
<igx-dialog title="Edit Profile" [closeOnEscape]="false">
  ...
</igx-dialog>

<igx-dialog title="Shortcuts" [closeOnOutsideSelect]="true">
  ...
</igx-dialog>
```

その他の場合にダイアログを開いたままにするには、`closing` イベントをキャンセルします。その `event` 引数には、ダイアログを閉じるキーボード イベントまたはポインター イベントが含まれ、`close()` を呼び出した場合は `undefined` になります:

```html
<igx-dialog title="Edit Profile" (closing)="onClosing($event)">
  ...
</igx-dialog>
```

```ts
import { IDialogCancellableEventArgs } from 'igniteui-angular/dialog';

public hasUnsavedChanges = false;

public onClosing(args: IDialogCancellableEventArgs) {
    if (args.event && this.hasUnsavedChanges) {
        args.cancel = true;
    }
}
```

</PlatformBlock>

### フォーム

<PlatformBlock for="React,WebComponents,Blazor">

ユーザーがフォームを送信したときにダイアログを閉じるには、`method="dialog"` を指定した `form` 要素を {Platform} Dialog のコンテンツに配置します。ダイアログは closing イベントを発生させるため、閉じる動作をキャンセルでき、フォームをサーバーには送信しません。デザイン ガイダンスで推奨されているように送信ボタンをフッターに配置するには、ボタンをフォームに関連付けます:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-dialog id="sign-in" title="Sign In">
  <form id="sign-in-form" method="dialog">
    <igc-input name="username" label="Username" required></igc-input>
    <igc-input name="password" label="Password" type="password" required></igc-input>
  </form>
  <igc-button slot="footer" variant="flat" command="--hide" commandfor="sign-in">Cancel</igc-button>
  <igc-button slot="footer" variant="flat" type="submit" form="sign-in-form">Sign In</igc-button>
</igc-dialog>
```

</PlatformBlock>

<PlatformBlock for="React">

`IgrButton` の `form` プロパティは読み取り専用であるため、ボタンのクリック ハンドラーからフォームを送信します:

```tsx
const dialogRef = useRef<IgrDialog>(null);
const formRef = useRef<HTMLFormElement>(null);

<IgrDialog ref={dialogRef} title="Sign In">
  <form ref={formRef} method="dialog">
    <IgrInput name="username" label="Username" required={true} />
    <IgrInput name="password" label="Password" type="password" required={true} />
  </form>
  <IgrButton slot="footer" variant="flat" onClick={() => dialogRef.current?.hide()}>Cancel</IgrButton>
  <IgrButton slot="footer" variant="flat" onClick={() => formRef.current?.requestSubmit()}>Sign In</IgrButton>
</IgrDialog>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDialog @ref="Dialog" Title="Sign In">
    <form id="sign-in-form" method="dialog">
        <IgbInput name="username" Label="Username" Required="true" />
        <IgbInput name="password" Label="Password" type="password" Required="true" />
    </form>
    <IgbButton slot="footer" Variant="ButtonVariant.Flat" @onclick="HideDialog">Cancel</IgbButton>
    <IgbButton slot="footer" Variant="ButtonVariant.Flat" DisplayType="ButtonBaseType.Submit" form="sign-in-form">Sign In</IgbButton>
</IgbDialog>
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

ネイティブの `button` 要素または `input` 要素がフォームを送信すると、{Platform} Dialog は <ApiLink pkg="core" type="Dialog" member="returnValue" label="returnValue" /> をその要素の `value` に設定します。どのボタンがダイアログを閉じたかを確認するには、closed イベントのハンドラーで `returnValue` を読み取ります。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Dialog は、ダイアログ内のフォームが送信されても閉じません。フォームの `submit` イベントを処理し、`close()` を呼び出します:

```html
<igx-dialog #signIn title="Sign In">
  <form id="sign-in-form" (submit)="onSignIn($event, signIn)">
    <igx-input-group>
      <label igxLabel for="username">Username</label>
      <input igxInput id="username" name="username" type="text" required />
    </igx-input-group>
    <igx-input-group>
      <label igxLabel for="password">Password</label>
      <input igxInput id="password" name="password" type="password" required />
    </igx-input-group>
  </form>
  <igx-dialog-actions>
    <button igxButton="flat" type="button" (click)="signIn.close()">Cancel</button>
    <button igxButton="flat" type="submit" form="sign-in-form">Sign In</button>
  </igx-dialog-actions>
</igx-dialog>
```

```ts
import { IgxDialogComponent } from 'igniteui-angular/dialog';

public onSignIn(event: SubmitEvent, dialog: IgxDialogComponent) {
    event.preventDefault();
    // Send the credentials.
    dialog.close();
}
```

</PlatformBlock>

### 位置とアニメーション

既定では、Angular Dialog はフェード アニメーションでページの中央に開きます。位置とアニメーションを変更するには、<ApiLink pkg="core" type="Dialog" member="positionSettings" label="positionSettings" /> を設定します。ダイアログはグローバル位置ストラテジを使用するため、位置を変更するのは `horizontalDirection` と `verticalDirection` のみで、省略した設定は既定値のままです:

```ts
import { slideInTop, slideOutTop } from 'igniteui-angular/animations';
import { HorizontalAlignment, PositionSettings, VerticalAlignment } from 'igniteui-angular/core';

public positionSettings: PositionSettings = {
    horizontalDirection: HorizontalAlignment.Center,
    verticalDirection: VerticalAlignment.Top,
    openAnimation: slideInTop,
    closeAnimation: slideOutTop
};
```

```html
<igx-dialog title="Notification" [positionSettings]="positionSettings">
  ...
</igx-dialog>
```

ダイアログは既定でモーダルです。背景を表示し、その背景はページ上のクリックをブロックします。背景なしでダイアログを表示してページを操作可能なままにするには、<ApiLink pkg="core" type="Dialog" member="isModal" label="isModal" /> を `false` に設定します。1 回の表示のみオーバーレイ設定を変更するには、`open()` に設定を渡します。渡した設定は、その表示に限りダイアログの既定値を上書きし、プロパティは変更しません:

```ts
this.dialog.open({ modal: false, closeOnOutsideClick: true });
```

</PlatformBlock>

### 推奨事項 / 非推奨事項

ダイアログのタイトルとボタン ラベルは連携して、ダイアログの目的と各アクションの結果を伝えます。両方を明確な表現にすると、ユーザーは何を確認しているかを理解し、自信を持って判断できます。

<DoDont
  doSrc={dialogDoLabels}
  doAlt="タイトルが Delete File で、[Cancel] ボタンと [Delete] ボタンを持つダイアログ"
  dontSrc={dialogDoNotLabels}
  dontAlt="タイトルが Are you sure? で、[No] ボタンと [Yes] ボタンを持つダイアログ"
>
<Fragment slot="do">

具体的なタイトルと、アクションとその結果を明確に示すボタン ラベルを使用して、ユーザーが何を確認しているかを正確にわかるようにします。

</Fragment>
<Fragment slot="dont">

あいまいなタイトルや「Yes/No」のような曖昧なラベルは避けます。実際に何が起こるかがユーザーに伝わらず、混乱や間違いにつながります。

</Fragment>
</DoDont>

<DoDont
  doSrc={dialogDoActions}
  doAlt="ボタン領域に [Cancel] ボタンと [Sign In] ボタンを持つ Sign In ダイアログ"
  dontSrc={dialogDoNotActions}
  dontAlt="[Cancel] ボタンと [Sign In] ボタンに加えて、本文に [Log In] ボタンを持つ Sign In ダイアログ"
>
<Fragment slot="do">

カスタム Dialog を設計する場合は、すべてのアクション ボタンをダイアログ専用のボタン領域に配置し、本文セクションはコンテンツ専用にします。

</Fragment>
<Fragment slot="dont">

カスタム Dialog を設計する場合は、本文セクションにボタンを配置するのを避け、アクションには既存のダイアログ ボタンを使用します。

</Fragment>
</DoDont>

## アクセシビリティ

{Platform} Dialog は、ユーザーがキーボードで開いたり閉じたりするモーダル ウィンドウにコンテンツを表示します。このセクションでは、ダイアログのテンプレートとイベント ハンドラーが定義する、ダイアログがレンダリングして処理する内容を説明します。

### キーボード操作

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Dialog は、ネイティブの `dialog` 要素を `showModal()` で開き、`close()` で閉じるため、ブラウザーがフォーカスを管理します:

- ダイアログが開くと、フォーカスは DOM 順で最初のフォーカス可能な要素 (コンテンツ内のコントロール、`footer` スロットのボタン、または既定の OK ボタン) に移動します。ダイアログにフォーカス可能な要素がない場合、フォーカスはダイアログ自体に移動します。
- ダイアログが開いている間、ページの残りの部分は inert になり、キーボードやポインターは届きません。
- ダイアログが閉じると、フォーカスはダイアログが開く前にフォーカスを持っていた要素に戻ります。

ダイアログが開いている間は、次のキーが機能します:

| キー | 動作 |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | ダイアログ内の次または前のフォーカス可能な要素にフォーカスを移動します。ダイアログはこれらのキーを処理しません。ページが inert であるため、ブラウザーがダイアログ内の最後の要素からブラウザー コントロールへ、次に最初の要素へとフォーカスを移動します。 |
| <kbd>Escape</kbd> | ブラウザーがネイティブの `dialog` に `cancel` イベントを送信します。{Platform} Dialog はネイティブの閉じる動作を防止して closing イベントを発生させ、そのイベントをキャンセルしない場合に閉じます。`keepOpenOnEscape` を指定するとダイアログは開いたままになり、Escape キーの繰り返しなどでブラウザーがネイティブの `dialog` を閉じた場合は、ダイアログがそれを再度開きます。 |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | フォーカスされたボタンをアクティブにします。既定の OK ボタンはダイアログを閉じて closing イベントを発生させます。 |

{Platform} Dialog は、次のポインター操作とフォーム操作も処理します:

- ボックスの外側でのネイティブの `dialog` のクリック (背景のクリック) は、`closeOnOutsideClick` が設定されている場合にダイアログを閉じます。ダイアログはポインターの位置を確認するため、ダイアログ内で押して背景で離した場合も閉じます。
- 既定のスロット内の `method="dialog"` のフォームからの `submit` イベントはダイアログを閉じます。ただし、`submit` イベントを防止するか、closing イベントをキャンセルした場合を除きます。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Dialog は、次のようにフォーカスを管理します:

- 組み込みボタンを持つダイアログが開くと、各ボタンに `isOpen` にバインドされた `igxFocus` ディレクティブが設定され、右側のボタン (右側のボタンがない場合は左側のボタン) にフォーカスが移動します。
- 組み込みボタンのないダイアログが開くと、フォーカスは `div.igx-dialog` コンテナーに移動します。代わりにコンテンツ内の最初のコントロールにフォーカスするには、そのコントロールに `[igxFocus]="dialog.isOpen"` を追加します。
- ダイアログが開いている間、`div.igx-dialog` コンテナー上の `igxFocusTrap` ディレクティブが Tab キーと Shift + Tab キーを処理します。
- ダイアログが閉じても、フォーカスはダイアログを開いた要素に戻りません。

ダイアログが開いている間は、次のキーが機能します:

| キー | 動作 |
| --- | --- |
| <kbd>Tab</kbd> | ダイアログ内の次のフォーカス可能な要素にフォーカスを移動し、最後の要素から最初の要素に移動します。 |
| <kbd>Shift</kbd> + <kbd>Tab</kbd> | ダイアログ内の前のフォーカス可能な要素にフォーカスを移動し、最初の要素から最後の要素に移動します。 |
| <kbd>Escape</kbd> | `closeOnEscape` が `true` の場合、ダイアログを閉じて `closing` と `closed` を発生させます。オーバーレイ サービスはドキュメント全体で Escape キーを待ち受けるため、フォーカスがどこにあってもキーが機能し、最前面で開いているオーバーレイのみを閉じます。 |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | フォーカスされたボタンをアクティブにします。組み込みボタンは `leftButtonSelect` または `rightButtonSelect` を発生させ、ダイアログは閉じません。 |

フォーカス トラップは `focusTrap` が `true` の場合にのみ機能し、Tab キーと Shift + Tab キーを次のように処理します:

- `a[href], button, input, textarea, select, details, [tabindex]:not([tabindex="-1"])` セレクターで、ダイアログ内のフォーカス可能な要素を検索します。無効な要素と `aria-hidden="true"` を持つ要素の内容はスキップし、Web コンポーネントのシャドウ ルートの内部は検索しません。
- DOM 順にフォーカスを移動するため、正の `tabindex` 値は無視され、最後の要素から最初の要素へ、またその逆へとラップします。
- ダイアログにフォーカス可能な要素がない場合、フォーカスを `div.igx-dialog` コンテナーに保持します。

Angular Dialog は、次のポインター操作も処理します:

- モーダル ダイアログでは、`closeOnOutsideSelect` が `true` の場合、背景のクリックでダイアログが閉じます。ダイアログ内で押して背景で離した場合も、背景のクリックとして扱われます。
- `isModal` が `false` のダイアログでは、`closeOnOutsideSelect` が `true` の場合、ダイアログの外側のどこをクリックしても閉じます。
- ダイアログは内部でのクリックの伝播を停止するため、ドキュメント上のクリック ハンドラーはそれらを受け取りません。

</PlatformBlock>

### スクリーン リーダー / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Dialog は、次のロールと属性をレンダリングします:

| 要素 | ロール | 属性 |
| --- | --- | --- |
| `div[part="backdrop"]` | — | ダイアログが閉じている間は `aria-hidden="true"`。要素は空で装飾用です。 |
| `dialog[part="base"]` | `dialog` | `title` パーツを指す `aria-labelledby`。`igc-dialog` 要素に `aria-label` を設定すると、ダイアログはその `aria-label` を持ち、`aria-labelledby` には `title` パーツの `id` の代わりにラベル テキストが設定されるため、`aria-label` がダイアログの名前になります。 |
| `header[part="title"]` | — | `aria-labelledby` が指す `id`。ダイアログにタイトルがない場合は非表示です。 |
| 既定の OK ボタン | `button` | 名前は「OK」です。 |

{Platform} Dialog は、支援技術に次の情報を公開します:

- ダイアログが開いている間はモーダルな `dialog` となり、その外側のページのコンテンツはアクセシビリティ ツリーに含まれません。ダイアログが閉じている間は、ダイアログはアクセシビリティ ツリーに含まれません。
- ダイアログは、`title` プロパティまたは `title` スロットからアクセシブルな名前を取得します。`igc-dialog` 要素の `aria-label` はタイトルより優先され、タイトルも `aria-label` もないダイアログにはアクセシブルな名前がありません。
- ダイアログは `aria-describedby` を設定しないため、メッセージとコンテンツはアクセシブルな説明にはなりません。
- ダイアログはライブ リージョンを使用しません。支援技術は、フォーカスが移動することで開いているダイアログを検出します。

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Dialog は、次のロールと属性をレンダリングします:

| 要素 | ロール | 属性 |
| --- | --- | --- |
| `igx-dialog` | — | `id` (既定では `igx-dialog-0` 以降)、および `tabindex="-1"`。 |
| `div.igx-overlay__wrapper--modal` | — | `popover="manual"`。開いているダイアログをページの最上位レイヤーでレンダリングします。 |
| `div.igx-dialog` | — | `tabindex="0"`。ダイアログが閉じている間は `aria-hidden="true"`。 |
| `div.igx-dialog__window` | 2 つの組み込みボタンがある場合は `dialog`、1 つの場合は `alertdialog`、組み込みボタンがない場合は `alert` | `titleId` を指す `aria-labelledby`。 |
| `div.igx-dialog__window-title` | — | `aria-labelledby` が指す `id`。`titleId` に設定されます。`title` を設定した場合にレンダリングされます。 |
| 組み込みボタン | `button` | `type="button"`、および `leftButtonLabel` または `rightButtonLabel` からの名前。 |

Angular Dialog は、支援技術に次の情報を公開します:

- ダイアログのロールは組み込みボタンによって決まり、`role` プロパティは読み取り専用です。サインイン フォームのように、組み込みボタンのないカスタム ダイアログのロールは `alert` です。
- ダイアログは、`title` プロパティからアクセシブルな名前を取得します。プロジェクションされた `igx-dialog-title` には `titleId` が設定されないため、プロジェクションされたタイトルを持つダイアログには、タイトルに `[id]="dialog.titleId"` をバインドしない限りアクセシブルな名前がありません。
- ダイアログは `aria-modal` を設定せず、最上位レイヤーはページの残りの部分を inert にしないため、支援技術はモーダル ダイアログの背後のページに引き続きアクセスできます。
- ダイアログは `aria-describedby` を設定しないため、メッセージとコンテンツはアクセシブルな説明にはなりません。
- ダイアログが閉じている間、そのコンテナーは `aria-hidden="true"` を持ち、非表示になります。

</PlatformBlock>

## トラブルシューティング

ここでは、{Platform} Dialog で最もよく発生する問題について、その原因と解決方法を説明します。

<PlatformBlock for="React,WebComponents">

### フォームを送信した後に returnValue が空になるのはなぜですか?

{Platform} Dialog は、フォームの送信者から `returnValue` を設定しますが、送信者になれるのはネイティブの `button` 要素または `input` 要素のみです。Ignite UI Button は送信者なしでフォームを送信するため、`returnValue` は以前の値のままです。ネイティブの送信ボタンを使用するか、フォームが送信される前に Ignite UI Button のクリック ハンドラーで `returnValue` を設定します。

</PlatformBlock>

<PlatformBlock for="Blazor">

### Show() でエラーが発生するのはなぜですか?

`Show`、`Hide`、`Toggle` メソッドは、`ShowAsync`、`HideAsync`、`ToggleAsync` の同期バージョンです。ブラウザーのダイアログ メソッドは Promise を返すため、Blazor WebAssembly では、ダイアログは開閉しますが同期呼び出しで例外がスローされ、Blazor Server では失敗します ([igniteui-blazor#512](https://github.com/IgniteUI/igniteui-blazor/issues/512))。代わりに `Async` メソッドを使用します。

</PlatformBlock>

<PlatformBlock for="Angular">

### カスタム ダイアログがスクリーン リーダーでアラートとして読み上げられるのはなぜですか?

Angular Dialog は組み込みボタンからロールを設定し、`leftButtonLabel` と `rightButtonLabel` のないダイアログには `alert` ロールが設定されます。`role` プロパティは読み取り専用です。ダイアログがアクションの確認またはキャンセルのみを行う場合は、`dialog` ロールまたは `alertdialog` ロールが設定される組み込みボタンを使用します。

### closeOnEscape の変更が反映されないのはなぜですか?

Angular Dialog は、開くときに `closeOnEscape`、`closeOnOutsideSelect`、`isModal` をオーバーレイに渡すため、ダイアログが開いている間の変更は次に開くときに適用されます ([igniteui-angular#12537](https://github.com/IgniteUI/igniteui-angular/issues/12537))。開いているダイアログの動作を変更するには、代わりに `closing` イベントをキャンセルします。

</PlatformBlock>

### 既知の制限事項

<PlatformBlock for="React,WebComponents,Blazor">

- `command` 属性と `commandfor` 属性は、[Invoker Commands API](https://developer.mozilla.org/en-US/docs/Web/API/Invoker_Commands_API) をサポートするブラウザーでのみ機能します。
- `message` スロットは、コンテンツの幅を 40 文字に制限します。

</PlatformBlock>

<PlatformBlock for="Blazor">

- ユーザーがダイアログを閉じても `Open` パラメーターは変更されず、Blazor Dialog には `OpenChanged` コールバックがありません。
- `Closing` コールバックは閉じる動作をキャンセルできません。[Escape キーと外部クリックによる閉じる動作](#escape-キーと外部クリックによる閉じる動作)で説明するように、`ClosingScript` を使用します。
- `ReturnValue` パラメーターはブラウザー内のダイアログには反映されず、フォームが戻り値を設定しても変更されません ([igniteui-blazor#300](https://github.com/IgniteUI/igniteui-blazor/issues/300))。

</PlatformBlock>

<PlatformBlock for="Angular">

- ダイアログは、閉じたときにフォーカスをダイアログを開いた要素に戻しません。
- モーダル ダイアログは、支援技術に対してページの残りの部分を inert にしません。
- フォーカス トラップは DOM 順にフォーカスを移動し、正の `tabindex` 値を無視します ([igniteui-angular#13299](https://github.com/IgniteUI/igniteui-angular/issues/13299))。
- ダイアログは内部でのクリックの伝播を停止するため、ドキュメントのクリックで閉じるダイアログ内のサードパーティ製メニューは開いたままになります ([igniteui-angular#13849](https://github.com/IgniteUI/igniteui-angular/issues/13849))。
- ダイアログはグローバル位置ストラテジを使用するため、位置設定の `minSize` は効果がありません。

</PlatformBlock>
