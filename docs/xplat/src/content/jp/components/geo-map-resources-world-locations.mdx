# {Platform} 世界の場所

## コード スニペット

```json-snippet source="/maps/geo-map/binding-multiple-sources" channel="WorldLocations"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "series": [
                {
                    "type": "GeographicPolylineSeries",
                    "name": "lineSeries",
                    "dataSourceRef": "WorldFlights",
                    "$dataSourceRef": "+doc:WorldLocations",
                    "shapeMemberPath": "Points"
                }
            ]
        }
    }
}
```
