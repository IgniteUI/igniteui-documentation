# {ProductName} 変更ログ



{ProductName} の各バージョンのすべての重要な変更は、このページに記載されています。

## **{PackageVerLatest}**

### {PackageGrids} (グリッド)

- <ApiLink type="Grid" />、<ApiLink type="TreeGrid" />、<ApiLink type="HierarchicalGrid" />、<ApiLink type="PivotGrid" />
  - Excel スタイル フィルタリングの検索リストで <ApiLink type="VirtualScroll" /> コンポーネントを使用するようになりました。リストは各行のレンダリング時にその行を測定し、測定したサイズで推定サイズを置き換えます。
  - Excel スタイル フィルタリングの検索リストのマークアップが変更されました。内部の表示コンテナーと垂直スクロールバー ヘルパーの代わりに、仮想スクロール ホストとアイテム ラッパーが使用されます。これらの要素に直接アクセスするアプリケーションとテストを更新してください。
  - Excel スタイル フィルタリングの内部仮想スクロール コンテナーに、ネストされたリスト ロールがなくなりました。リストボックスとそのオプションは変更されません。
  - `rowStyles`、`headerStyles`、`headerGroupStyles` プロパティの型が `GridStyleCSSProperty | null` になりました。以前の型は `any` でした。
  - スクロールバーで、`::-webkit-scrollbar-*` 疑似要素の代わりに標準の `scrollbar-color` および `scrollbar-width` CSS プロパティを使用するようになりました。
  - グリッド、列アクション、および Excel スタイル フィルタリング メニューのスクロールバーは、ホストの背景色と前景色を使用します。

**重大な変更**

- **テーマ**
  - `--ig-grid-summary-border-width` および `--ig-grid-summary-pinned-border-width` CSS 変数が削除されました。集計セルはグリッドの罫線幅を使用します。ヘッダーの罫線幅がセルの区切りを、ピン固定の罫線幅がピン固定の罫線を設定します。
  - 集計の罫線のスタイルと色は、引き続き `--ig-grid-summary-border-style`、`--ig-grid-summary-pinned-border-style`、`--ig-grid-summary-border-color`、`--ig-grid-summary-pinned-border-color` で設定できます。
  - 標準のスクロールバー プロパティは 2 つの色と 3 つの幅キーワードのみを受け入れるため、ほとんどのスクロールバー テーマ変数は効果がなくなりました。`--sb-thumb-bg-color` と `--sb-track-bg-color` は引き続き機能します。ホバー、罫線、コーナー、最小高さの変数は効果がありません。
  - `scrollbar-width` は `auto`、`thin`、`none` のみを受け入れるため、`--sb-size` はスクロールバーの太さを設定しなくなりました。スクロールバーを細くするには、スクロールバー変数を宣言する要素に `--sb-width: thin` を設定します。スクロール要素に `scrollbar-width: thin` を直接設定することもできます。

**動作変更**

- **スクロールバー**
  - 標準の CSS プロパティでは、スクロールバーの矢印ボタンのスタイル設定や表示はできません。`scrollbar-width: thin` は、矢印ボタンを表示するプラットフォームでそれらを削除します。
  - 64 より前のバージョンの Firefox は `scrollbar-color` と `scrollbar-width` をサポートしません。これらのバージョンでは、プラットフォームの既定の色とサイズでスクロールバーが表示されます。
- **PDF エクスポート**
  - 集計行の背景が、ヘッダー行と同じになりました。ヘッダーの背景と同様に、この背景は `showTableBorders` オプションで制御されます。
  - <ApiLink type="PivotGrid" /> エクスポートの行ディメンション セルにもこの背景が適用されます。
  - 連続するレコードで行ディメンションの値が繰り返される場合、<ApiLink type="PivotGrid" /> エクスポートでは、その値が 1 つの結合セルに 1 回だけ表示されるようになりました。グリッドも行ヘッダーを同じ方法で結合します。
  - 値は同じ親ディメンションの下でのみ結合されます。たとえば、2 つの異なる都市の同じ日付には 2 つのセルが作成されます。
  - 結合セルがページの下端を超える場合、セルはページの終わりで止まり、次のページのヘッダーの下に続きます。

#### 新しいコンポーネント

{ProductName} に、`igniteui-webcomponents` 7.3.0 および 7.4.0 の次のコンポーネントが含まれるようになりました:

- [Breadcrumbs](./layouts/breadcrumbs.mdx) (<ApiLink type="Breadcrumbs" /> および <ApiLink type="Breadcrumb" />) - ナビゲーション パスを表示します。
- [Color Picker](./inputs/color-picker.mdx) (<ApiLink type="ColorPicker" />) - ユーザーが色を選択できます。さまざまな色形式とカスタム パレットをサポートします。
- [QR Code](./inputs/qr-code.mdx) (<ApiLink type="QrCode" />) - `value` プロパティから QR コードを SVG としてレンダリングします。データを数字、英数字、またはバイト モードでエンコードします。
- Virtual Scroll (<ApiLink type="VirtualScroll" />) - ビューポート内のアイテムと、`overScan` で設定された数の追加アイテムのみをレンダリングします。大規模なリストや無制限のリストに使用します。
  - このコンポーネントは、垂直方向と水平方向、および右から左 (RTL) のレイアウトをサポートします。
  - アイテムのサイズは、固定、`estimatedItemSize` による推定、または可変にできます。コンポーネントはレンダリングされた各アイテムを測定し、推定値を補正します。
  - まだ測定されていないアイテムには、`estimatedItemSize` の代わりに測定済みサイズの平均が使用されます。これにより、スクロールバーが実際のコンテンツと一致します。
  - このコンポーネントはアイテム要素をリサイクルします。レンダリング ウィンドウ内に残るアイテムは、その要素を保持します。ウィンドウから出るアイテムの要素は、ウィンドウに入るアイテムを表示します。
  - `keyFunction` プロパティはアイテムのキーを返します。キーがあると、`data` 内でアイテムが移動してもその要素が保持されます。`keyFunction` がない場合は、インデックスがキーになります。
  - アイテム テンプレートがバインドしない DOM 状態は、要素に残ります。たとえば、`checked` バインドのないチェックボックスの状態です。この状態はアイテム テンプレートでバインドしてください。
  - このコンポーネントは、ブラウザーの最大スクロール サイズより大きいリストでも正しく動作します。

  - `icon` CSS パートは、<ApiLink type="Icon" /> がバッジの唯一のコンテンツである場合にのみ適用されます。これはドキュメントと一致します。

  - コンポーネントは、インジケーター コンテナー、ナビゲーション ボタン、アクティブなスライド内の最初のフォーカス可能な要素の順でフォーカスを委任するようになりました。

  - <ApiLink type="Tile" /> がサイズ変更ハンドルを直接レンダリングするようになりました。`trigger-side`、`trigger`、`trigger-bottom` CSS パートの名前は変わりません。

  - React スキルを、エージェントが自力では見つけられないフレームワーク固有の情報に絞りました。スキルの合計サイズは以前の約半分です。

  - スキルの README に、Grid Lite からプレミアム グリッドへの移行スキルが記載されるようになりました。

#### 新機能

- #### Button Group
  - 単一選択モード (`single` および `single-required`) で、ラジオ グループのキーボード パターンを使用するようになりました:
    - グループは 1 つのタブ ストップです。
    - 矢印キーでフォーカスと選択が一緒に移動します。無効なボタンはスキップされ、両端で折り返します。
    - `alignment="horizontal"` では、ArrowLeft と ArrowRight がテキストの方向に選択を移動します。`alignment="vertical"` では、ArrowUp と ArrowDown が選択を移動します。
    - `multiple` モードは変更されません。各ボタンはタブ ストップのままです。
  - 単一選択モードで、`radio` ボタンを持つ `radiogroup` が公開されるようになりました。以前は `aria-pressed` を持つトグル ボタンが公開されていました。
  - <ApiLink type="ButtonGroup" /> ホストに `radiogroup` または `group` ロールと無効状態が設定されるようになりました。ホストの `aria-label` または `aria-labelledby` でグループに名前を付けます。
  - 単一選択モードでは、`alignment` がラジオ グループの `aria-orientation` を設定します。
  - <ApiLink type="ToggleButton" /> の `focused` CSS パートがドキュメント化されました。
- #### Calendar、Date Picker、Date Range Picker
  - <ApiLink type="Calendar" /> が `label-inner`、`months-row`、`years-row` CSS パートをエクスポートするようになりました。ピッカーはこれらを `calendar-label-inner`、`months-row`、`years-row` としてエクスポートします。
- #### Chip
  - 新しい `outlined` プロパティ。`true` に設定すると、アウトライン付きのチップが表示されます。
  - `start` および `end` スロットと、新しい `action` および `remove` CSS パートがドキュメント化されました。
- #### Combo、Color Picker、Date Picker、Date Range Picker、Dropdown、Select、Tooltip
  - 新しい `scrollStrategy` プロパティ。コンテナーがスクロールされたときのポップアップの動作を設定します:
    - `hide` (既定) は、アンカーが完全に表示範囲外にある間、ポップアップを非表示にします。
    - `scroll` は、ポップアップを表示したままアンカー上に保持します。
    - `close` は、スクロールのたびにコンポーネントを閉じます。これにより `sticky` ツールチップも閉じられます。
  - 日付ピッカーは、`dialog` モードでは `scrollStrategy` を無視します。
- #### Dropdown
  - ターゲット要素に `aria-haspopup="listbox"` が設定されるようになりました。以前は `aria-haspopup="true"` でした。
  - リストが開いている間、ターゲットの `aria-activedescendant` がアクティブなアイテムを指します。スクリーン リーダーはこのアイテムを読み上げます。
- #### Icon
  - `registerIcon` と `registerIconFromText` が、3 番目の引数として `RegisterIconOptions` オブジェクトを受け入れるようになりました。従来のコレクション文字列も引き続き機能します。
  - `stripMeta: true` は、保存される SVG から `<title>` と `<desc>` 要素を削除します。これにより、ホバー時のブラウザー標準のツールチップが表示されなくなります。
  - タイトル テキストは、ホストの <ApiLink type="Icon" /> 要素の `aria-label` として引き続き利用できます。
- #### Mask Input、Date Time Input、Date Range Picker
  - マスク エディターで元に戻す/やり直しがサポートされました:
    - 元に戻す: `Ctrl + Z` または `Cmd + Z`。
    - やり直し: `Ctrl + Y`、`Ctrl + Shift + Z` または `Cmd + Shift + Z`。
  - 連続して入力された文字は 1 つの元に戻すステップです。連続した削除も 1 つの元に戻すステップです。
  - キャレットの移動、貼り付け、ドロップ、切り取り、日付部分のスピン、IME 入力は、それぞれ新しいステップを開始します。
  - 復元されたステップは `onInput` を発行します。双方向バインディングは元に戻す操作に追従します。
  - フォーカスが変わっても履歴は保持されます。値をプログラムで設定した場合、フォームがコントロールをリセットした場合、または `mask`、`prompt`、`inputFormat` が変更された場合、コンポーネントは履歴をクリアします。
- #### Splitter
  - 新しい `startCollapsed` および `endCollapsed` プロパティ。各ペインの折りたたみ状態を取得および設定します。
  - 新しい `onLayoutChanged` イベント。ユーザーによるサイズ変更または展開状態の変更後にコンポーネントが発行します。
  - `onLayoutChanged` のペイロードには、現在のレイアウト (`startSize`、`endSize`、`startCollapsed`、`endCollapsed`) が含まれます。
- #### Tabs
  - 新しい `selectedTab` プロパティ。選択されている <ApiLink type="Tab" /> 要素、または `null` を返します。
  - `select()` が、`id` に加えてタブの `label` も受け入れるようになりました。`selected` の値を `select()` に渡すことができます。
  - タブ ヘッダーに `aria-posinset` と `aria-setsize` が設定されました。ストリップには `aria-orientation` が設定されます。
  - 選択されているパネルがフォーカス可能になりました。フォーカス可能な要素のないパネル コンテンツにも、キーボード ユーザーが到達できます。
  - タブが選択されていない場合でも、ストリップはタブ ストップを保持します。
  - コンポーネントは、中間スロットを通過する <ApiLink type="Tab" /> 要素を検出するようになりました。別のコンポーネントで <ApiLink type="Tabs" /> をラップできます。
- #### Tooltip
  - アンカーが `aria-describedby` でツールチップを参照するようになりました。スクリーン リーダーはツールチップのコンテンツをアンカーの説明として読み上げます。
  - `sticky` モードでは、既定の閉じる操作はラベル付きの `<button>` です。キーボードで到達して使用できます。新しい `close-button` CSS パートでこれを公開します。
- #### Popover
  - Popover ベースのコンポーネントは、サポートするブラウザー (Chrome および Edge 133 以降、Firefox 147 以降、Safari 26 以降) でネイティブの CSS アンカー位置指定を使用するようになりました。
  - その他のブラウザーは引き続き `@floating-ui/dom` を使用します。必要な場合にのみ読み込まれます。
- #### テーマ
  - Material、Bootstrap、Fluent、Indigo テーマのすべてのコンポーネントに `forced-colors: active` スタイルが追加されました。
  - Windows ハイ コントラスト モードでは、コンポーネントはシステム カラー (`CanvasText`、`Highlight`、`GrayText`、`LinkText`) を使用します。無効、ホバー、フォーカス、選択の各状態は互いに区別されたままです。

#### 重大な変更

- #### Chip
  - `part="base"` は単純なラッパーになりました。選択コントロールは新しい `action` パートに、削除コントロールは新しい `remove` パートに移動しました。
  - 操作可能な面に対する `::part(base)` ルールを `::part(action)` に移してください。
  - `focus-outline-color` および `focus-selected-outline-color` CSS 変数が、`focus-shadow-color` および `focus-selected-shadow-color` に置き換えられました。
- #### AI 支援開発 - スキル
  - `grid-lite-to-igr-grid-migration` スキルの名前を `igniteui-react-migrate-grid-lite-to-premium` に変更しました。新しい名前は、他のスキルと同様に `igniteui-react-` プレフィックスを使用します。
  - 名前が変更されたスキルを新しいフォルダー名で再インストールし、古いフォルダーを削除してください。
  - 各スキルの `reference/` フォルダーの名前を `references/` に変更しました。リンクが機能するよう、`igniteui-react-components`、`igniteui-react-customize-theme`、`igniteui-react-generate-from-image-design` のスキルを再インストールしてください。

#### 動作変更

- #### Combo、Color Picker、Date Picker、Date Range Picker、Dropdown、Select、Tooltip
  - アンカーが完全に表示範囲外にある間、ポップアップが非表示になりました。以前はポップアップが表示されたままでした。以前の動作を維持するには、`scrollStrategy="scroll"` を設定します。
- #### Dropdown、Select、Tooltip
  - ポップアップは、表示範囲内に留まるためにビューポートの端に沿って移動しなくなりました。反対側に反転するだけです。
- #### Button Group
  - 無効なグループは、そのボタンに `disabled` を設定しなくなりました。ボタンはグループの無効状態を継承します。
  - 独自の `disabled` を持つボタンは、グループを再び有効にしても無効のままです。無効なグループに追加したボタンも無効になります。
  - 単一選択モードでは、ボタンは個別のタブ ストップではなくなりました。「新機能」セクションのキーボード パターンを参照してください。
- #### Calendar、Date Picker、Date Range Picker
  - `weekStart` が設定されていない場合、週は `locale` の週の最初の日から始まります。コンポーネントはこの日を `Intl.Locale.prototype.getWeekInfo()` から取得します。
  - たとえば、週は `bg` では月曜日、`en` では日曜日から始まります。
  - 明示的な `weekStart` が優先されます。ロケールの値を再び使用するには、`weekStart` を `undefined` に設定します。`getWeekInfo()` のないブラウザーでは日曜日が使用されます。
  - ヘッダーの日付と月/年のナビゲーションは、`locale` のフィールド順を使用します。たとえば `ja` では、年ボタンが月ボタンの前に表示されます。年ビューは引き続き単純な数値を表示します。
- #### Date Time Input、Date Picker、Date Range Picker
  - コンポーネントは、ユーザーの入力中に `value` を変更しなくなりました。`value` は、`onChange` イベントとともにコミット時にのみ変更されます。コンポーネントは、従来どおりブラー時に `onChange` を発行します。
  - 以前は、キーストロークごとに `value` が変更され、変更を通知するイベントはありませんでした。
  - たとえば <ApiLink type="Grid" /> の編集テンプレートなどで、`value` を外部からバインドできるようになりました。
  - `onInput` イベントの `detail` には、入力された値が含まれます。日付部分のスピンまたは `Ctrl + ;` の結果も含まれます。
  - フォーカスされているエディターでは、日付部分のスピンもブラー時のコミットまで待機します。
  - フォーカスされていないコンポーネントでは、`stepUp()` と `stepDown()` は `value` をすぐに変更します。`clear()`、`setRangeText()`、および直接の代入も `value` をすぐに変更します。
  - ピッカーでは、ユーザーの入力中、カレンダーは引き続き入力された日付に追従します。
- #### Dropdown
  - ユーザーがすでに選択されているアイテムを選択しても、コンポーネントは `onChange` を発行しなくなりました。リストは引き続き閉じます。
- #### Tabs
  - スクロール ボタンは、完全には表示されていない最も近いタブまでスクロールするようになりました。以前は 180px の固定ステップでスクロールしていました。
  - スクロール ボタンの下にあるタブは、表示されていないものとして扱われます。1 回クリックするごとに、タブがちょうど 1 つずつ追加で表示されます。
- #### Tooltip
  - 非表示トリガーで閉じるツールチップは、正確に `hideDelay` だけ待機するようになりました。以前は、ドキュメント化されていない 180ms が追加で待機されていました。
  - `sticky` モードでは、既定の閉じるボタンはツールチップをすぐに非表示にします。`hideDelay` を待機しません。
  - 既定の `showTriggers` と `hideTriggers` に `focusin` と `focusout` が含まれるようになりました。アンカーがキーボード フォーカスを受け取るとツールチップが開き、フォーカスがアンカーから離れると閉じます。

- [Grid Lite](./grid-lite/overview.mdx) (<ApiLink type="GridLite" />): `igniteui-grid-lite` を 0.9.0 から 0.11.0 に更新しました。この更新には [0.10.0](https://github.com/IgniteUI/igniteui-grid-lite/blob/master/CHANGELOG.md#0100---2026-08-26) と [0.11.0](https://github.com/IgniteUI/igniteui-grid-lite/blob/master/CHANGELOG.md#0110---2026-09-25) のリリースが含まれます。

#### 新機能

- グリッドが `ElementInternals` を通じて完全な ARIA グリッド パターンを実装しました: ロール、行と列の数とインデックス、`aria-sort`、`aria-selected`。フィルター行は 2 番目のヘッダー行です。

#### 変更

- 行の仮想化で <ApiLink type="VirtualScroll" /> コンポーネントを使用するようになりました。ビューポート外でレンダリングされる行が減りました。`@lit-labs/virtualizer` 依存関係を削除しました。

  - 離れたスクロール位置へのジャンプが 8 倍高速になりました。
  - ソートが 8 倍高速になりました。
  - セル テンプレートを使用する場合、改善は同等かそれ以上です。
- 列を指定しないナビゲーションは、現在の列を保持します。
- セルのアクティブ化で、影響を受ける 2 つの行のみが更新されるようになりました。以前はすべての表示行が更新されていました。
- 列が変更されたとき、行はセルを再利用します。ソートは 1 つの共有コレーターを使用します。`ResizeObserver` がスクロールバーのオフセットを制御します。
- キャンセル可能な `onSorting` および `onFiltering` イベントは、状態が変更される前に発生します。リスナーは式をキャンセルまたは変更できます。
- `onSorted` および `onFiltered` イベントは、データ ビューの更新後に発生します。

<PlatformBlock for="React">

        <IgrColumn field="field" merge={true}></IgrColumn>

  - `onSort` - 列がソートされた場合のみ。
  - `always` - データ操作に関係なく常に。

<PlatformBlock for="React">

```tsx
        <IgrGrid cellMergeMode="always">
        </IgrGrid>
```

</PlatformBlock>

        既定の `cellMergeMode` は `onSort` です。

<PlatformBlock for="React">

```tsx
        <IgrColumn field="Col1" pinned={true} pinningPosition="pinningPosition">
        </IgrColumn>
```

</PlatformBlock>

        ```ts
        pinningPosition = ColumnPinningPosition.End;
        ```

        または、API でオプションのパラメーターを使用して行うこともできます:

        ```ts
        grid.pinColumn('Col1', 0, ColumnPinningPosition.End);
        grid.pinColumn('Col2', 0, ColumnPinningPosition.Start);
        ```

        列に `pinningPosition` プロパティが設定されていない場合、その列はグリッドの `pinning` オプションの `columns` で指定された位置になります。
