# Tailwind CSS と {ProductName} の統合

{ProductName} は、CSS 変数を通じてテーマを完全にカスタマイズできます。このガイドでは、Tailwind CSS をプロジェクトに統合し、`igniteui-theming` パッケージが提供するカスタム ユーティリティ クラスを活用する方法を紹介します。これらのクラスは {ProductName} のデザイン トークンをユーティリティとして公開し、カラー・シャドウ・タイポグラフィの一貫したスタイリングを可能にします。

## Tailwind のセットアップ

<PlatformBlock for="Angular">

Tailwind とその PostCSS プラグインをインストールします。

```cmd
npm install tailwindcss @tailwindcss/postcss postcss --force
```

次に、プロジェクトのルートに `.postcssrc.json` ファイルを作成し、PostCSS 構成に `@tailwindcss/postcss` プラグインを追加します。

```json
{
  "plugins": {
    "@tailwindcss/postcss": {}
  }
}
```

</PlatformBlock>
<PlatformBlock for="React, WebComponents, Blazor">

まず、[公式の Tailwind インストール ガイド](https://tailwindcss.com/docs/installation)に従って、選択したビルド ツールまたはフレームワークに応じて Tailwind CSS をインストールします。

</PlatformBlock>

Tailwind をセットアップしたら、Tailwind と Ignite UI テーマ設定の両方をグローバル スタイルシート<PlatformBlock for="Angular"> (`styles.css` または `styles.scss`)</PlatformBlock>にインポートします。

```css
@import "tailwindcss";
@import "igniteui-theming/tailwind/themes/base";
```

プロジェクトでスタイル設定に Sass を使用している場合は、最初に Ignite UI 構成を読み込みます。Sass では、`@use` ルールを `@import` などのほかのどのルールよりも前に書く必要があるためです。

```scss
@use "igniteui-theming/tailwind/themes/base.css";
@import "tailwindcss";
```

## Ignite UI カスタム ユーティリティ クラスの使用

`igniteui-theming` パッケージには、Ignite UI のデザイン トークンをユーティリティ クラスとして公開する Tailwind のカスタム設定が含まれています。これには以下が含まれます:

- カラーとコントラスト カラー

- エレベーション (シャドウ)

- タイポグラフィ スタイル

それぞれの使い方を見ていきましょう。

### カラー ユーティリティ クラス

当社のカラー ユーティリティ クラスは、各 Ignite UI テーマのトークンを活用しています。これらを HTML に直接適用できます。

<PlatformBlock for="Angular, WebComponents, Blazor">

```html
<h1 class="bg-primary-500 text-primary-500-contrast">This is a title</h1>
```

</PlatformBlock>

<PlatformBlock for="React">

```html
<h1 className="bg-primary-500 text-primary-500-contrast">This is a title</h1>
```

</PlatformBlock>

Tailwind の完全なカラー システムは [Tailwind カラーのドキュメント](https://tailwindcss.com/docs/color)で確認でき、Ignite UI が提供するクラス名を使って適用できます。

### シャドウ ユーティリティ クラス

定義済みの[エレベーション レベル](elevations.mdx) (0 ～ 24) のいずれかを使用して深度を追加できます。

<PlatformBlock for="Angular, WebComponents, Blazor">

```html
<div class="shadow-elevation-8">Elevated container</div>
```

</PlatformBlock>

<PlatformBlock for="React">

```html
<div className="shadow-elevation-8">Elevated container</div>
```

</PlatformBlock>

Tailwind が提供するすべてのシャドウ関連のユーティリティ クラスは、[Tailwind ボックス シャドウのドキュメント](https://tailwindcss.com/docs/box-shadow)で見つけることができます。

### タイポグラフィ カスタム ユーティリティ スタイル

フォントを適用するには、トップ レベルの要素に `font-ig` クラスを追加します。`text-base` ユーティリティ クラスを使用して基本フォント サイズを定義することもできます。
各タイポグラフィ レベル (例: h1、h2、body-1) ごとにカスタム ユーティリティ クラスを提供しています。以下のように使用してください。

<PlatformBlock for="Angular, WebComponents, Blazor">

```html
<p class="type-style-h3">This paragraph gets the h3 styles</p>
```

</PlatformBlock>

<PlatformBlock for="React">

```html
<p className="type-style-h3">This paragraph gets the h3 styles</p>
```

</PlatformBlock>

各クラスは、[Ignite UI のタイプ スケール](typography.mdx)に応じて、必要なすべてのフォント設定、間隔、サイズを適用します。

<PlatformBlock for="Angular">

<DocsAside type="info" title="情報">
これらのカスタム タイポグラフィ ユーティリティは、`ig-typography` の外でのみ動作します。トップ レベルの要素に `ig-typography` CSS クラスを設定する必要がある場合、これらのスタイルは適用されません。
</DocsAside>

</PlatformBlock>

## まとめ

わずか数ステップの設定で、Tailwind のユーティリティ ファースト アプローチと Ignite UI の堅牢なデザイン システムを組み合わせることができます。この統合により、カラー・エレベーション・タイポグラフィのトークンを直接 HTML で活用し、一貫性のあるテーマ付き UI コンポーネントを迅速に構築できます。
