# {Platform} Geographic Symbol Map

In {Platform} map component, you can use the <ApiLink type="GeographicSymbolSeries" /> to display geo-spatial data using points or markers in a geographic context. This type of geographic series is often used to render a collection of geographic locations such as cities, airports, earthquakes, or points of interests.

## Data Requirements
Similarly to other types of geographic series in the map component, the <ApiLink type="GeographicSymbolSeries" /> has the `dataSource` property which can be bound to an array of objects. In addition, each data item in this object must have two numeric data columns that store a geographic location (longitude and latitude). These data columns are then mapped to the `latitudeMemberPath` and `longitudeMemberPath` properties. The `GeographicSymbolSeries` uses values of these mapped data columns to plot symbol elements in the geographic map component.

## Code Snippet
The following code shows how to bind the <ApiLink type="GeographicSymbolSeries" /> to locations of cities loaded from a shape file using the <ApiLink type="ShapefileRecord" />.

```json-snippet source="/maps/geo-map/type-scatter-symbol-series"
{
    "type": "GeographicMap",
    "name": "geoMap",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicSymbolSeries",
            "name": "citiesSeries",
            "dataSourceRef": "WorldCities",
            "markerType": "Circle",
            "latitudeMemberPath": "Y",
            "longitudeMemberPath": "X",
            "markerBrush": "White",
            "markerOutline": "Gray"
        },
        {
            "type": "GeographicSymbolSeries",
            "name": "capitalsSeries",
            "dataSourceRef": "WorldCapitals",
            "markerType": "Circle",
            "latitudeMemberPath": "Y",
            "longitudeMemberPath": "X",
            "markerBrush": "White",
            "markerOutline": "rgb(32, 146, 252)"
        }
    ]
}
```
