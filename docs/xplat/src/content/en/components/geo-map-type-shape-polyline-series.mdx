# {Platform} Geographic Polyline Map

In {Platform} map component, you can use the `GeographicPolylineSeries` to display geo-spatial data using polylines in a geographic context. This type of geographic series is often used to render roads or connections between geographic locations such as cities or airports.

## {Platform} Geographic Polyline Map Example


<Sample src="/maps/geo-map/type-shape-polyline-series" height={500} alt="{Platform} Using Shape Polyline Series Example" />




The `GeographicPolylineSeries` works a lot like the `GeographicShapeSeries` except that geo-spatial data is rendered with polylines instead of polygons.

## Data Requirements
Similarly to other types of geographic series in the control, the `GeographicPolylineSeries` has the `dataSource` property which can be bound to an array of objects. In addition, each data item in this object must have one data column that stores single/multiple shapes using an array of arrays of objects with x and y values representing geographic locations. This data column is then mapped to the `ShapeMemberPath` property. The `GeographicPolylineSeries` uses points of this mapped data column to plot polylines in the control.

When the shapes come straight from a shape file and need no reshaping first, the series can be given a `ShapefileDataSource` of its own instead, and it reads the points out of the records itself. That is what the code below does; [Binding Shape Files](./geo-map-binding-shp-file.mdx) covers the other route, where a handler turns each record into an object of your own and maps `ShapeMemberPath` to it.

## Code Snippet
The following code gives the `GeographicPolylineSeries` a `ShapefileDataSource` pointing at a shape file of American roads, and draws every road in it.

```json-snippet source="/maps/geo-map/type-shape-polyline-series"
{
    "type": "GeographicMap",
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicPolylineSeries",
            "name": "GeographicPolylineSeries1",
            "shapefileDataSource": {
                "type": "ShapeDataSource",
                "shapefileSource": "https://static.infragistics.com/xplatform/shapes/AmericanRoads.shp",
                "databaseSource": "https://static.infragistics.com/xplatform/shapes/AmericanRoads.dbf"
            },
            "outline": "Red"
        }
    ]
}
```
