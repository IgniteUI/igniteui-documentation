# Breadcrumbs Component <Badge variant="new" />

The {ProductName} Breadcrumbs component renders an ordered trail of navigation items separated by a configurable icon, communicating a user's location within a site's hierarchy and providing a way back to higher-level pages.

## Anatomy

The {Platform} Breadcrumbs component is a pair of elements: a container that manages shared state and renders as an ARIA list, and one or more item children that render arbitrary slotted content followed by a separator.

<span class="ig-typography__body-2" style="display: block; margin-bottom: 24px;"><strong>1. Container:</strong> The `Breadcrumbs` element that groups the trail as an ARIA `list` and holds the shared separator icon.<br />
<strong>2. Item:</strong> A `Breadcrumb` element that renders as an ARIA `listitem`, containing the main content (typically a link).<br />
<strong>3. Prefix slot:</strong> Optional content rendered before the main content, such as an icon.<br />
<strong>4. Suffix slot:</strong> Optional content rendered after the main content.<br />
<strong>5. Separator:</strong> An icon (or slotted content) rendered after each item except the last.<br />
<strong>6. Current item:</strong> The item marked with `current` — visually distinguished and announced with `aria-current="page"`.</span>

<PlatformBlock for="WebComponents, React, Blazor">

```text
<nav aria-label="Breadcrumb">
  <igc-breadcrumbs role="list">
    <igc-breadcrumb role="listitem">
      ├── ::part(label)
      │   ├── slot="prefix"                 // optional prefix content
      │   ├── default slot                  // main content, typically <a>
      │   └── slot="suffix"                 // optional suffix content
      └── ::part(separator)                 // hidden on the last item
          └── slot="separator"              // per-item override
    </igc-breadcrumb>
    <!-- more <igc-breadcrumb> items ... -->
    <igc-breadcrumb current role="listitem" aria-current="page">
      <!-- last item, no trailing separator -->
    </igc-breadcrumb>
  </igc-breadcrumbs>
</nav>
```

</PlatformBlock>

<PlatformBlock for="Angular">

```text
<nav aria-label="Breadcrumb">
  <igx-breadcrumbs role="list">
    <igx-breadcrumb role="listitem">
      ├── label                             // wraps prefix, default, and suffix
      │   ├── slot="prefix"                 // optional prefix content
      │   ├── default slot                  // main content, typically <a>
      │   └── slot="suffix"                 // optional suffix content
      └── separator                         // hidden on the last item
          └── slot="separator"              // per-item override
    </igx-breadcrumb>
    <!-- more <igx-breadcrumb> items ... -->
    <igx-breadcrumb current role="listitem" aria-current="page">
      <!-- last item, no trailing separator -->
    </igx-breadcrumb>
  </igx-breadcrumbs>
</nav>
```

</PlatformBlock>

## Getting Started

To use the {Platform} Breadcrumbs, follow the [{ProductName} Getting Started](../general-getting-started.mdx) topic for the basic project setup, then register the components for your target platform.

### Prerequisites and Version Compatibility

Use a supported version of the {ProductName} package for your target framework. Keep the framework package, the Breadcrumbs package, and the theme package on the same release version. The examples below identify the framework and package used by each code block so that the snippets remain self-contained when read without the surrounding page context.

<PlatformBlock for="WebComponents">

For Web Components using the **{PackageWebComponents}** package, install the package:

```cmd
npm install {PackageWebComponents}
```

Import the <ApiLink pkg="core" type="Breadcrumbs" /> and <ApiLink pkg="core" type="Breadcrumb" />, their theme CSS, and register both components:

```ts
import { defineComponents, IgcBreadcrumbsComponent, IgcBreadcrumbComponent } from 'igniteui-webcomponents';
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcBreadcrumbsComponent, IgcBreadcrumbComponent);
```

</PlatformBlock>


## Usage

Compose a trail by slotting one <ApiLink pkg="core" type="Breadcrumb" /> per level inside a <ApiLink pkg="core" type="Breadcrumbs" /> container. Each item accepts arbitrary content in its default slot — most commonly an anchor element that handles the actual navigation.

<PlatformBlock for="WebComponents">

```html

  <igc-breadcrumb><a href="/">Root</a></igc-breadcrumb>
  <igc-breadcrumb><a href="/docs">Docs</a></igc-breadcrumb>
  <igc-breadcrumb current><a href="/docs/breadcrumbs">Breadcrumbs</a></igc-breadcrumb>
```

### Current Page

Mark the item that represents the currently viewed page with the <ApiLink pkg="core" type="Breadcrumb" member="current" label="current" /> property. The component reflects `current` as an attribute and applies `aria-current="page"` to the host, so screen readers announce which item is the current page.

<PlatformBlock for="WebComponents">

```html
<igc-breadcrumbs>
  <igc-breadcrumb><a href="/home">Home</a></igc-breadcrumb>
  <igc-breadcrumb current><a href="/home/dashboard">Dashboard</a></igc-breadcrumb>
</igc-breadcrumbs>
```

</PlatformBlock>

Update `current` at runtime after a client-side navigation to move the marker to the newly active item:

<PlatformBlock for="WebComponents, React, Blazor">

```ts
const items = document.querySelectorAll('igc-breadcrumb');
for (const item of items) {
  item.current = false;
}
items[items.length - 1].current = true;
```

</PlatformBlock>

<PlatformBlock for="Angular">

```ts
const items = document.querySelectorAll('igx-breadcrumb');
for (const item of items) {
  (item as any).current = false;
}
(items[items.length - 1] as any).current = true;
```

</PlatformBlock>

### Shared Separator

Use the <ApiLink pkg="core" type="Breadcrumbs" member="separator" label="separator" /> property on the container to set a shared separator icon for every item in the trail. The value is an icon name from the registered icon collection; the container propagates it to each descendant item through context.

### Per-Item Separator Override

Override the separator for a single item by slotting content into that item's `separator` slot. This is useful for mixing text separators (such as `/` or `›`) with icons, or for using an entirely different icon at one boundary.

<PlatformBlock for="WebComponents">

```html
<igc-breadcrumbs>
  <igc-breadcrumb>
    <a href="/home">Home</a>
    <span slot="separator">/</span>
  </igc-breadcrumb>
  <igc-breadcrumb current><a href="/home/settings">Settings</a></igc-breadcrumb>
```

### Wrapping and Long Trails

The container renders its items on a single wrapping row using flex layout. When a trail is longer than the available width, the items wrap to the next line automatically — no additional configuration is required.

### Do/Don't

**When to use:** Use Breadcrumbs to show a user's location within a hierarchical structure — a folder path, a category tree, a nested settings area, or a wizard step location — and to provide a way back to higher levels through the slotted links.

**When not to use:** Use the [Navbar](./navbar.mdx) or [Navigation Drawer](./navigation-drawer.mdx) when you need a primary navigation surface with tabs, groups, or expanded actions rather than a linear hierarchy trail.

## Accessibility

The {Platform} Breadcrumbs follows the ARIA breadcrumb navigation pattern. The container exposes the ARIA `list` role, each item exposes the `listitem` role, and the current item is announced with `aria-current="page"`.

### Keyboard Interaction

The Breadcrumbs components do not implement custom keyboard handling — navigation relies on the native behavior of the interactive content slotted into each item (typically an anchor).

| Key | Action |
| -- | -- |
| `Tab` / `Shift` + `Tab` | Moves focus between the interactive elements (typically links) slotted into each breadcrumb item. |
| `Enter` / `Space` | Activates the currently focused link, following the native behavior of the slotted element. |

### Screen Readers / ARIA

<PlatformBlock for="WebComponents, React, Blazor">

- The <ApiLink pkg="core" type="Breadcrumbs" /> host has `role="list"`.
- Each <ApiLink pkg="core" type="Breadcrumb" /> host has `role="listitem"`.
- Setting `current` to `true` applies `aria-current="page"` to the host; setting it back to `false` removes the attribute.
- Wrap the trail in `<nav aria-label="Breadcrumb">` (or a domain-specific label) so assistive technology exposes it as a navigation landmark. The label belongs on the `<nav>`, not on the list.
- The separator icons are decorative and are not announced by screen readers.

</PlatformBlock>

### Accessibility Compliance

Infragistics documents {ProductName} accessibility support for Section 508 and WCAG 2.1 guideline areas in the [Accessibility Compliance](../interactivity/accessibility-compliance.mdx) topic.

| Criterion | How the component complies |
| -- | -- |
| [1.3.1 Info and Relationships](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships) | The container and items expose the `list` / `listitem` roles, and the current item exposes `aria-current="page"`. |
| [2.4.8 Location](https://www.w3.org/WAI/WCAG21/Understanding/location) | The trail visually and programmatically communicates the current page's location within the site hierarchy. |
| [4.1.2 Name, Role, Value](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | The `<nav>` wrapper carries the accessible name; the `list`/`listitem` roles carry the structural semantics. |

Your responsibilities:

- Wrap the Breadcrumbs container in a `<nav>` element and set a descriptive `aria-label`, such as `"Breadcrumb"` or `"Product category"`.
- Mark exactly one item as `current` per trail so screen readers announce a single current page.
- Provide a meaningful text label inside each slotted anchor; do not rely on prefix icons alone to communicate the destination.

## Troubleshooting

The {Platform} Breadcrumbs troubleshooting guidance follows a problem → cause → fix format for common integration and rendering issues.

### Why is my separator not visible on some items?

The separator is automatically hidden on the last item in the trail — this is the intended behavior for the ARIA breadcrumb pattern. If it is missing from an unexpected item, check whether that item is the last visible child of the container.

### Why is the custom icon name I set on `separator` not rendering?

The separator icon must be registered with the icon registry (in the same collection used by the surrounding UI). Register the icon before rendering the trail, or fall back to the default `tree_expand` icon that ships with the theme.

### Why does the trail not wrap in RTL?

Wrapping is not RTL-specific — it happens whenever the total content width exceeds the container width. In RTL contexts, the visual order is reversed and the separator icon is mirrored automatically; if the trail still overflows, check whether a parent element is preventing the container from taking up its natural width.

### Why is `aria-current` not being announced?

`aria-current="page"` is applied only when the item's `current` property is `true`. If you mutate items after a client-side navigation, make sure to set `current = false` on the previous item before setting `current = true` on the new one, so exactly one item is announced as the current page.

## Known Limitations

The {Platform} Breadcrumbs has the following platform-independent limitations.

- The Breadcrumbs components do not implement custom keyboard handling — activation depends on the interactive element slotted into each item (usually an anchor).
- The Breadcrumbs do not render a `<nav>` landmark of their own; the consuming application must provide the `<nav aria-label="...">` wrapper.
- The container does not truncate long trails automatically. Combine the natural flex wrapping with your own overflow strategy (e.g. collapsing intermediate items into a menu) when a single-line trail is required at narrow widths.

## FAQ

<Faq>
  <FaqItem question="How do I change the separator icon between items?" indicatorPosition="end">
    Set the `separator` property on the Breadcrumbs container to the name of any registered icon; the container propagates the icon to every descendant item. To override the separator for a single item, slot the replacement content into that item's `separator` slot.
  </FaqItem>

  <FaqItem question="Do I need to manually hide the last separator?" indicatorPosition="end">
    No. The Breadcrumb item automatically hides its trailing separator when it is the last item in the trail, so you can render the items in a loop without any special-casing.
  </FaqItem>

  <FaqItem question="Does the Breadcrumbs component render a `<nav>` landmark itself?" indicatorPosition="end">
    No. The Breadcrumbs renders as an ARIA `list` of `listitem` children. Following the ARIA breadcrumb pattern, the consuming application wraps the container in `<nav aria-label="Breadcrumb">` (or a more specific label) so the accessible name lives on the landmark rather than on the list.
  </FaqItem>

  <FaqItem question="How do I mark the current page?" indicatorPosition="end">
    Set the `current` property on the Breadcrumb item that represents the currently viewed page. The item reflects `current` as an attribute and applies `aria-current="page"` on the host, so screen readers announce which entry is the current page.
  </FaqItem>

  <FaqItem question="Which package should I install for Breadcrumbs?" indicatorPosition="end">
    Use `igniteui-angular` for Angular, `igniteui-react` for React, `igniteui-webcomponents` for Web Components, and `IgniteUI.Blazor` for Blazor. Keep related Ignite UI packages on the same release version.
  </FaqItem>
