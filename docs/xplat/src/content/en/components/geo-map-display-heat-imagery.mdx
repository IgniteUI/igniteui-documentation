# {Platform} Displaying Heat Imagery

The {ProductName} map control has the ability to show heat-map imagery through the use of the <ApiLink type="ShapefileRecord" /> that are generated by a <ApiLink type="ShapefileRecord" /> by loading geo-spatial data by loading shape files to a tile series.

It is highly recommended that you review the [Binding Shape Files with Geo-Spatial Data](./geo-map-binding-shp-file.mdx) topic as a pre-requisite to this topic.

## {Platform} Displaying Heat Imagery Example

<Sample src="/maps/geo-map/display-heat-imagery" height={500} alt="{Platform} Displaying Heat Imagery Example" />




When a <ApiLink type="ShapefileRecord" /> loads its shape files, it converts that data into <ApiLink type="ShapefileRecord" /> objects. These objects can be retrieved from the `GetPointData()` method of the <ApiLink type="ShapefileRecord" /> and can then be used to create a heat-map through usage of a <ApiLink type="TileGeneratorMapImagery" /> object with a <ApiLink type="HeatTileGenerator" /> assigned to its <ApiLink type="TileGenerator" /> property. This <ApiLink type="TileGeneratorMapImagery" /> can then be used in a <ApiLink type="GeographicTileSeries" /> as its `tileImagery` source.

The <ApiLink type="HeatTileGenerator" /> object works such that it has three value paths, <ApiLink type="XValues" />, `yValues` and `Values`. As an example of how these could be used, in the case of a shape file that has information about population, you could consider the <ApiLink type="XValues" /> to be longitude, `yValues` to be latitude, and `Values` to be the population data. Each of these properties takes a `number[]`.

The display of the geographic tile series when using the heat-map functionality can be customized by setting the `minimumColor` and `maximumColor` properties to "rgba" strings that describe colors that you wish to correspond to the minimum and maximum values of the collection that you assign to the `Values` property of the <ApiLink type="HeatTileGenerator" />. You can further customize this by setting the `scaleColors` property of the generator to contain a collection of strings that describe colors, as this will tell the <ApiLink type="HeatTileGenerator" /> what colors to use for the displayed values in the map. It is also possible to customize how colors in your `scaleColors` collection blur together by using the `blurRadius`, `maxBlurRadius`, and `useBlurRadiusAdjustedForZoom` properties.

The <ApiLink type="HeatTileGenerator" /> can also use a logarithmic scale. If you want to use this, you can set the `useLogarithmicScale` property to **true**.

## Web Worker

The <ApiLink type="HeatTileGenerator" /> also has support for web workers to do the heavy lifting of the loading of the tile imagery from your shape file on a separate thread. This can greatly improve the performance of your geographic map when using the heat-map functionality. In order to use a web worker with the generator, you can set the `useWebWorkers` property to **true** and then set the `webWorkerInstance` property to an instance of your web worker.

<PlatformBlock for="Angular">

```ts
// heatworker.worker.ts
import { HeatTileGeneratorWebWorker } from 'igniteui-angular-core';

const worker: Worker = self as any;
worker.onmessage = HeatTileGeneratorWebWorker.onmessage;
HeatTileGeneratorWebWorker.postmessage = heatWorkerPostMessage;
function heatWorkerPostMessage() {
  (self as any).postMessage.apply(self, Array.prototype.slice.call(arguments));
}
HeatTileGeneratorWebWorker.start();
export default {} as typeof Worker & (new () => Worker);

```

            "width": "100%",
            "zoomable": true

        "MapDisplayHeatImageryOnViewInit"
