# Tailwind CSS Integration with {ProductName}

{ProductName} offers full theming customization through CSS variables. In this guide, you'll learn how to integrate Tailwind CSS into your project and enhance it with custom utility classes provided by the `igniteui-theming` package. These classes expose {ProductName} design tokens for colors, shadows, and typography, enabling a seamless utility-first styling experience.

## Overview

## Tailwind Setup

<PlatformBlock for="Angular">

Install Tailwind and its PostCSS plugin:

```cmd
npm install tailwindcss @tailwindcss/postcss postcss --force
```

Then create a `.postcssrc.json` file in the root of your project and add the `@tailwindcss/postcss` plugin to your PostCSS configuration:

```json
{
  "plugins": {
    "@tailwindcss/postcss": {}
  }
}
```

</PlatformBlock>
<PlatformBlock for="React, WebComponents, Blazor">

Start by installing Tailwind CSS, according to your chosen build tool or framework by following the [official Tailwind installation guide](https://tailwindcss.com/docs/installation).

</PlatformBlock>

Once Tailwind is set up, import both Tailwind and the Ignite UI theming configuration in your global stylesheet<PlatformBlock for="Angular"> (`styles.css` or `styles.scss`)</PlatformBlock>:

```css
@import "tailwindcss";
@import "igniteui-theming/tailwind/themes/base";
```

If your project uses Sass for styling, load the Ignite UI configuration first. Sass requires every `@use` rule to come before any other rule, including `@import`:

```scss
@use "igniteui-theming/tailwind/themes/base.css";
@import "tailwindcss";
```

## Using Ignite UI Custom Utility Classes

The `igniteui-theming` package includes a custom Tailwind configuration that exposes Ignite UI design tokens through utility classes. These include support for:

- Colors and contrast colors

- Elevation (shadows)

- Typography styles

Let’s look at how to use each.

### Color Utility Classes

Our color utility classes are powered by tokens from each Ignite UI theme. You can apply them directly in your HTML:

<PlatformBlock for="Angular, WebComponents, Blazor">

```html
<h1 class="bg-primary-500 text-primary-500-contrast">This is a title</h1>
```

</PlatformBlock>

<PlatformBlock for="React">

```html
<h1 className="bg-primary-500 text-primary-500-contrast">This is a title</h1>
```

</PlatformBlock>

You can explore Tailwind’s full color system in the [Tailwind color documentation](https://tailwindcss.com/docs/color), and apply it using the Ignite UI-provided class names.

### Shadow utility classes

You can add depth using any of the predefined [elevation levels](elevations.mdx) (from 0 to 24):

<PlatformBlock for="Angular, WebComponents, Blazor">

```html
<div class="shadow-elevation-8">Elevated container</div>
```

</PlatformBlock>

<PlatformBlock for="React">

```html
<div className="shadow-elevation-8">Elevated container</div>
```

</PlatformBlock>

You can find all the shadow-related utility classes provided by Tailwind in the [Tailwind box shadow documentation](https://tailwindcss.com/docs/box-shadow).

### Typography custom utility styles

To apply the font, add the `font-ig` class to a top-level element. You can also define the base font size using the `text-base` utility class.
We provide custom utility classes for each typography level (e.g., h1, h2, body-1). Use them like so:

<PlatformBlock for="Angular, WebComponents, Blazor">

```html
<p class="type-style-h3">This paragraph gets the h3 styles</p>
```

</PlatformBlock>

<PlatformBlock for="React">

```html
<p className="type-style-h3">This paragraph gets the h3 styles</p>
```

</PlatformBlock>

Each class applies all necessary font settings, spacing, and sizing according to the [Ignite UI type scale](typography.mdx).

<PlatformBlock for="Angular">

<DocsAside type="info">
These custom typography utilities only work outside of `ig-typography`. If you have to set the `ig-typography` CSS class on a top-level element, these styles won't apply.
</DocsAside>

</PlatformBlock>
