# Icon

The {ProductName} Icon is a component that renders a named icon from a registered icon set, such as a collection of custom SVG icons.

<PlatformBlock for="Angular">

By default, the Angular Icon renders Material Icons ligatures. Register SVG icons and other icon fonts with the `IgxIconService` to use them the same way.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Register SVG icons by name in a collection, then display each icon at a theme-based size in the color of the surrounding text.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

The {Platform} Icon renders an `igc-icon` element, which draws the registered SVG in its shadow root and exposes no CSS parts:

```text
igc-icon                 // host - inline box sized by --size
└─ #shadow-root
   └─ svg                // the registered SVG, 1em × 1em, filled with the current color
```

</PlatformBlock>

<PlatformBlock for="Angular">

The `igx-icon` element renders one of the following, depending on the type of its icon family:

```text
igx-icon.igx-icon[aria-hidden="true"]   // host - also carries the family class, e.g. .material-icons
├─ ligature text                        // `liga` family - the icon name, e.g. home
├─ div > svg                            // SVG icon registered with IgxIconService
└─ ng-content                           // projected ligature text when `name` isn't set
```

For a `font` family, the classes on the host draw the glyph, and the element has no content.

</PlatformBlock>

## Usage

Use the {Platform} Icon to add a recognizable symbol to labels, buttons, list items, and navigation, or to show a status at a glance.

<PlatformBlock for="React,WebComponents,Blazor">

### Name and Collection

The {Platform} Icon draws the SVG that is registered under its name in its collection. The collection defaults to `default`. All icons on the page share one registry, so an icon that you register once is available to every Icon, and an Icon that renders before its SVG is registered updates as soon as you register it.

</PlatformBlock>

<PlatformBlock for="WebComponents">

Register SVG markup with <ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" />, or fetch an SVG file from a URL with <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" />:

```ts
import { registerIcon, registerIconFromText } from 'igniteui-webcomponents';

const searchIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

registerIconFromText('search', searchIcon, 'material');
registerIcon('build', '/icons/build.svg', 'material');
```

Then set the same name and collection on each icon:

```html
<igc-icon name="search" collection="material"></igc-icon>
<igc-icon name="build" collection="material"></igc-icon>
```

</PlatformBlock>

<PlatformBlock for="React">

Register SVG markup with <ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" />, or fetch an SVG file from a URL with <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" />. Then set the same name and collection on each icon:

```tsx
import { useEffect } from 'react';
import { IgrIcon, registerIcon, registerIconFromText } from 'igniteui-react';

const searchIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

export default function SearchToolbar() {
  useEffect(() => {
    registerIconFromText('search', searchIcon, 'material');
    registerIcon('build', '/icons/build.svg', 'material');
  }, []);

  return (
    <>
      <IgrIcon name="search" collection="material" />
      <IgrIcon name="build" collection="material" />
    </>
  );
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Register SVG markup with the <ApiLink pkg="core" type="Icon" member="RegisterIconFromTextAsync" label="RegisterIconFromTextAsync" /> method, or fetch an SVG file from a URL with <ApiLink pkg="core" type="Icon" member="RegisterIconAsync" label="RegisterIconAsync" />. Call them on a referenced `IgbIcon` after it's ready, then set the same `IconName` and `Collection` on each icon:

```razor
<IgbIcon @ref="SearchIcon" IconName="search" Collection="material" />
<IgbIcon IconName="build" Collection="material" />

@code {
    private IgbIcon SearchIcon { get; set; }

    private const string SearchSvg = "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'><path d='M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z'/></svg>";

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender && SearchIcon != null)
        {
            await SearchIcon.EnsureReady();
            await SearchIcon.RegisterIconFromTextAsync("search", SearchSvg, "material");
            await SearchIcon.RegisterIconAsync("build", "/icons/build.svg", "material");
        }
    }
}
```

</PlatformBlock>

### Name and Family

The Angular Icon looks up its <ApiLink pkg="core" type="Icon" member="name" label="name" /> in its <ApiLink pkg="core" type="Icon" member="family" label="family" />. The default `material` family renders Material Icons ligatures, so the name is the ligature, such as `home` or `favorite`:

```html
<igx-icon name="home"></igx-icon>
<igx-icon name="favorite"></igx-icon>
```

You can also project the ligature as content:

```html
<igx-icon>bluetooth</igx-icon>
```

### SVG Icons

Register SVG icons with the <ApiLink pkg="core" type="IconService" />, then set their name and family on the icon. The <ApiLink pkg="core" type="IconService" member="addSvgIcon" label="addSvgIcon" /> method fetches an SVG file from a URL, and <ApiLink pkg="core" type="IconService" member="addSvgIconFromText" label="addSvgIconFromText" /> registers SVG markup:

```ts
import { Component, OnInit, inject } from '@angular/core';
import { IgxIconComponent, IgxIconService } from 'igniteui-angular/icon';

const searchIcon =
    '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

@Component({
    selector: 'app-filter-icons',
    template: `
        <igx-icon name="contains" family="filter-icons"></igx-icon>
        <igx-icon name="search" family="filter-icons"></igx-icon>
    `,
    imports: [IgxIconComponent]
})
export class FilterIconsComponent implements OnInit {
    private iconService = inject(IgxIconService);

    public ngOnInit() {
        this.iconService.addSvgIcon('contains', 'assets/images/svg/contains.svg', 'filter-icons');
        this.iconService.addSvgIconFromText('search', searchIcon, 'filter-icons');
    }
}
```

When an SVG icon and a ligature share the same name and family, the icon renders the SVG.

### Font Families

Use <ApiLink pkg="core" type="IconService" member="setFamily" label="setFamily" /> to add another icon font, such as [Material Symbols](https://fonts.google.com/icons), as a family. Load the font stylesheet first:

```html
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" rel="stylesheet" />
```

Map the family name to the CSS class of the font and set its type to `liga`:

```ts
this.iconService.setFamily('material-symbols', { className: 'material-symbols-outlined', type: 'liga' });
```

Then set the family on the icon. Material Symbols is a variable font, so you can adjust settings such as fill and weight:

```html
<igx-icon family="material-symbols" name="diamond" class="custom-icon"></igx-icon>
```

```scss
.custom-icon {
  font-variation-settings: "FILL" 0, "wght" 200, "GRAD" 0, "opsz" 40;
}
```

The [Icon Service](../icon-service.mdx) topic covers families of the `font` type, name prefixes, and icon references.

</PlatformBlock>

### Icon References

An icon reference points an icon name to another registered icon. Components such as the Combo and the Date Picker render their built-in icons through references in the `default` collection, and a reference that you set takes precedence over them. For example, point the `input_clear` reference to your own icon to replace the clear icon of these two components:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
import { registerIconFromText, setIconRef } from 'igniteui-webcomponents';

const closeIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z"/></svg>';

registerIconFromText('close', closeIcon, 'my-icons');
setIconRef('input_clear', 'default', { name: 'close', collection: 'my-icons' });
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
import { registerIconFromText, setIconRef } from 'igniteui-react';

const closeIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z"/></svg>';

```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIcon @ref="CloseIcon" IconName="close" Collection="my-icons" />

@code {
    private IgbIcon CloseIcon { get; set; }

    private const string CloseSvg = "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'><path d='M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z'/></svg>";
```

### Size

The {Platform} Icon supports the small, medium, and large size presets of the theme, and uses the large preset by default. Set the `--ig-size` CSS variable to `--ig-size-small`, `--ig-size-medium`, or `--ig-size-large` to choose a preset:

```css
.small {
  --ig-size: var(--ig-size-small);
}

.medium {
  --ig-size: var(--ig-size-medium);
}
```

### Active

### Accessible Name

Hide a decorative icon from assistive technology, and give an icon that conveys meaning on its own an accessible name that describes that meaning.

<PlatformBlock for="React,WebComponents,Blazor">

</PlatformBlock>

<PlatformBlock for="Angular">

The Angular Icon is hidden from assistive technology by default, because its <ApiLink pkg="core" type="Icon" member="ariaHidden" label="ariaHidden" /> input sets `aria-hidden="true"`. To expose an icon that conveys meaning, set `ariaHidden` to `false`, and add the `img` role and an `aria-label`:

## Methods

The {Platform} Icon draws icons that you register with the following API.

<PlatformBlock for="React,WebComponents">

Register icons with the following functions, which you import from **{PackageCommon}**. Pass a <ApiLink pkg="core" type="RegisterIconOptions" kind="interface" label="RegisterIconOptions" /> object instead of the collection name to set the `collection` and `stripMeta` options together.

| Function | Description |
| --- | --- |
| <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" /> | Fetches an SVG file from a URL and registers it under a name in a collection. Returns a promise that rejects when the request fails. |
| <ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" /> | Registers SVG markup under a name in a collection. |
| <ApiLink pkg="core" type="setIconRef" kind="function" label="setIconRef" /> | Points an icon name in a collection to another registered icon. |

</PlatformBlock>

<PlatformBlock for="Blazor">

Register icons with the following methods of an `IgbIcon` instance. Each method also has a synchronous version without the `Async` suffix.

| Method | Description |
| --- | --- |
| <ApiLink pkg="core" type="Icon" member="RegisterIconAsync" label="RegisterIconAsync" /> | Fetches an SVG file from a URL and registers it under a name in a collection. |
| <ApiLink pkg="core" type="Icon" member="RegisterIconFromTextAsync" label="RegisterIconFromTextAsync" /> | Registers SVG markup under a name in a collection. |
| <ApiLink pkg="core" type="Icon" member="SetIconRefAsync" label="SetIconRefAsync" /> | Points an icon name in a collection to the icon that an `IgbIconMeta` describes. |

</PlatformBlock>

<PlatformBlock for="Angular">

Register icons and families with the following methods of the <ApiLink pkg="core" type="IconService" />, which is provided in the application root.

## Accessibility

The {Platform} Icon is a non-interactive visual that either decorates nearby content or conveys meaning on its own.

### Keyboard Interaction

The {Platform} Icon doesn't receive focus and has no keyboard interaction: it sets no `tabindex` and handles no keyboard or pointer events. Use the <PlatformBlock for="Angular">[Icon Button](../icon-button.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Icon Button](../inputs/icon-button.mdx)</PlatformBlock> when users must activate an icon with the keyboard.

| Key | Action |
| --- | --- |
| n/a | The Icon is not keyboard interactive. |

### Screen Readers / ARIA

The {Platform} Icon makes no announcements of its own. What assistive technology reports depends on the accessible name of the icon:

<PlatformBlock for="React,WebComponents">

- The icon sets its role and accessible name through element internals, not through attributes on the `igc-icon` element.
- A `<title>` element that is a direct child of the root `<svg>` of the registered icon becomes the accessible name of the icon.
- An `aria-label` or `aria-labelledby` attribute on the icon names an icon whose SVG has no title, and takes precedence over the title.
- With `igniteui-webcomponents` 7.3.0 and later, the icon declares the `img` role only when it has an accessible name, so an icon without a name isn't exposed as an unnamed image.
- The icon checks for an accessible name when it resolves its SVG: when `name` or `collection` changes, when the theme changes, or when an icon is registered. Set `aria-label` or `aria-labelledby` in the initial markup.
- The `stripMeta` registration option removes the `<title>` and `<desc>` elements from the stored SVG, but the icon keeps the title text as its accessible name.

</PlatformBlock>

<PlatformBlock for="Blazor">

- A `<title>` element that is a direct child of the root `<svg>` of the registered icon becomes the accessible name of the icon.
- An `aria-label` attribute on the icon names an icon whose SVG has no title, and takes precedence over the title.
- An `aria-hidden="true"` attribute hides a decorative icon from assistive technology.

</PlatformBlock>

<PlatformBlock for="Angular">

- The icon sets `aria-hidden="true"` by default through its `ariaHidden` input, so assistive technology ignores it. An `aria-label` alone doesn't expose a hidden icon.
- The icon sets no role. When you set `ariaHidden` to `false` without a role and a label, screen readers read a ligature icon as its text, such as `home`.
- Set `ariaHidden` to `false`, add the `img` role, and add an `aria-label` to expose an icon that conveys meaning.
- The `active` input changes only the styling. The inactive state isn't exposed to assistive technology.

</PlatformBlock>

### Accessibility Compliance

Infragistics documents {ProductName} accessibility support for Section 508 and WCAG 2.1 guideline areas in the [Accessibility Compliance](../interactivity/accessibility-compliance.mdx) topic.

| --- | --- |

- Give every icon that conveys meaning on its own an accessible name, and keep decorative icons hidden. See [Accessible Name](#accessible-name).

<PlatformBlock for="Angular">- Don't rely on the inactive styling alone to convey a state, as [1.4.1 Use of Color](https://www.w3.org/WAI/WCAG21/Understanding/use-of-color) requires. ## Troubleshooting

Use these answers when a {Platform} Icon doesn't render or doesn't look as expected.

### Why is my icon empty?

<PlatformBlock for="React,WebComponents,Blazor">

The {Platform} Icon draws only an SVG that is registered under the same name and collection. Check the following causes:

- The name or the collection doesn't match the registration exactly. The collection defaults to `default`.
- The SVG markup is malformed. Registration throws the `SVG element not found or malformed SVG string.` error when the text has no root `<svg>` element or doesn't parse.
- The request for an SVG file failed. The registration from a URL fails for a non-OK response, so check the browser console and the network panel. A file on another origin also needs a server that allows cross-origin requests.

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

During server-side rendering, the icon renders no SVG. It draws the SVG after it loads in the browser.

</PlatformBlock>

<PlatformBlock for="Angular">

Check the following causes:

- A ligature icon needs the font of its family, such as Material Icons for the default `material` family. Check that the font stylesheet loads.
- An SVG icon needs the same name and family as its registration.
- `addSvgIcon` needs `HttpClient` to fetch the file. Check the network panel for a failed request.
- The service caches SVG icons only in the browser, so SVG icons don't render during server-side rendering.

</PlatformBlock>

### Why doesn't my SVG icon take the theme color?

The {Platform} Icon applies its color to the root `<svg>` element, and the child elements inherit it as their fill. A child element with a hardcoded color keeps that color:

```html
<svg viewBox="0 0 24 24">
  <path fill="#050d42" d="..." />
</svg>
```

Remove hardcoded colors from the child elements, or set the color on the root `<svg>` element, where the theme overrides it. To color part of an icon on purpose, use a theme color variable, such as `fill="var(--ig-primary-500)"`.

### Why does a tooltip appear when I hover an icon?

Browsers show the `<title>` element of an SVG as a native tooltip.

<PlatformBlock for="React,WebComponents">

Register the icon with the `stripMeta` option to remove the `<title>` and `<desc>` elements from the stored SVG. The icon keeps the title text as its accessible name:

```ts
registerIconFromText('search', searchIcon, { collection: 'material', stripMeta: true });
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Remove the `<title>` element from the SVG markup before you register it, and set `aria-label` on icons that need an accessible name.

</PlatformBlock>

<PlatformBlock for="Angular">

Pass `true` as the `stripMeta` argument of `addSvgIcon` or `addSvgIconFromText` to remove the `<title>` and `<desc>` elements from the cached SVG:

```ts
this.iconService.addSvgIcon('contains', 'assets/images/svg/contains.svg', 'filter-icons', true);
```

</PlatformBlock>

### Known Limitations

The {Platform} Icon has the following limitations:

- The Icon is a non-interactive visual: it doesn't receive focus or handle keyboard input.
- Theme colors reach the root `<svg>` element and the child elements that inherit its fill. Child elements with hardcoded colors keep them.
<PlatformBlock for="React,WebComponents,Blazor">- The Icon draws registered SVG icons only. Icon fonts and ligatures aren't supported.</PlatformBlock><PlatformBlock for="Angular">- The Angular Icon has no option to mirror an icon for right-to-left layouts.</PlatformBlock>
