# {Platform} Geographic Polygon Map

In {Platform} map component, you can use the <ApiLink type="GeographicShapeSeries" /> to display geo-spatial data using shape polygons in a geographic context. This type of geographic series is often used to render shapes of countries or regions defined by geographic locations.

## {Platform} Geographic Polygon Map Example


<Sample src="/maps/geo-map/type-shape-polygon-series" height={500} alt="{Platform} Using Shape Polygon Series Example" />




The <ApiLink type="GeographicShapeSeries" /> works a lot like the <ApiLink type="GeographicPolylineSeries" /> except that geo-spatial data is rendered with polygons instead of polylines.

## Data Requirements
Similar to other types of geographic series in the map control, the <ApiLink type="GeographicShapeSeries" /> has the <ApiLink type="GeographicMap" member="dataSource" label="DataSource" /> property which can be bound to an array of objects. In addition, each data item in this object must have one data column that stores single/multiple shapes using an array of arrays of objects with x and y values representing geographic locations. This data column is then mapped to the `ShapeMemberPath` property. The `GeographicShapeSeries` uses points of this mapped data column to plot polygons in the map control.

## Code Snippet
The following code demonstrates how to bind the <ApiLink type="GeographicShapeSeries" /> to shapes of countries in the world loaded from a shape file using the <ApiLink type="ShapefileRecord" />.

```json-snippet source="/maps/geo-map/type-shape-polygon-series"
{
    "type": "GeographicMap",
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicShapeSeries",
            "name": "GeographicShapeSeries1",
            "shapefileDataSource": {
                "type": "ShapeDataSource",
                "shapefileSource": "https://static.infragistics.com/xplatform/shapes/world_countries_all.shp",
                "databaseSource": "https://static.infragistics.com/xplatform/shapes/world_countries_all.dbf"
            },
            "outline": "black",
            "thickness": 0.5,
            "markerCollisionAvoidance": "Omit"
        }
    ]
}
```
