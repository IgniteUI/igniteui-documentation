# {Platform} Binding CSV Files with Geographic Locations

With the {ProductName} map component, you can plot geographic data loaded from various file types. For example, you can load geographic locations from a comma separated values (CSV) file.

## Code Snippet
The following code loads and binds <ApiLink type="GeographicHighDensityScatterSeries" /> in the map component to an array of objects created from loaded CSV file with geographic locations.


```json-snippet id="csvMap" source="/maps/geo-map/binding-data-csv"
{
    "descriptions": {
        "content": { "type": "GeographicMap", "height": "100%", "width": "100%", "zoomable": true }
    },
    "onViewInit": [ "MapBindingDataCsvOnViewInit" ]
}
```

```json-snippet ref="csvMap" channel="eventHandlers"
```
