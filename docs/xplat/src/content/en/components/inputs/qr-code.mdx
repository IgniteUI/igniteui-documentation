# QR Code Component <Badge variant="new" />

The {ProductName} QR Code renders a scannable QR (Quick Response) code as an inline SVG, generated on the client from any string value, with customizable size, error correction, and center logo.

## Usage

Set the <ApiLink pkg="core" type="QrCode" member="value" label="value" /> property to any string to render a scannable QR code. The component selects the most compact encoding mode (numeric, alphanumeric, or byte) and the smallest QR version that fits the value automatically. Clearing `value` removes the SVG entirely.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-qr-code value="https://www.infragistics.com"></igc-qr-code>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrQrCode value="https://www.infragistics.com"></IgrQrCode>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbQrCode Value="https://www.infragistics.com"></IgbQrCode>
```

</PlatformBlock>

### Version and Error Correction

Use the <ApiLink pkg="core" type="QrCode" member="errorLevel" label="errorLevel" /> property to choose between `L`, `M`, `Q`, and `H` error correction levels. Higher levels are more resilient to damage or obstruction but produce a larger, denser code. Use the <ApiLink pkg="core" type="QrCode" member="version" label="version" /> property to pin a specific QR version between `1` and `40` when you need predictable code dimensions; leave it unset to let the component pick the smallest version that fits the value.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-qr-code
  value="https://www.infragistics.com"
  version="4"
  error-level="H">
</igc-qr-code>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrQrCode
  value="https://www.infragistics.com"
  version={4}
  errorLevel="H">
</IgrQrCode>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbQrCode
  Value="https://www.infragistics.com"
  Version="4"
  ErrorLevel="QrCodeErrorLevel.H">
</IgbQrCode>
```

</PlatformBlock>

Neither property changes the encoded data.

### Center Logo

Add a branded center image with the <ApiLink pkg="core" type="QrCode" member="logoSrc" label="logoSrc" /> property. The component automatically masks the modules beneath the image so the code stays scannable. Use <ApiLink pkg="core" type="QrCode" member="logoSize" label="logoSize" /> — a ratio between `0` and `1` — to control how much of the safe area the logo covers, and <ApiLink pkg="core" type="QrCode" member="logoMargin" label="logoMargin" /> to add whitespace around the logo in pixels.

When `errorLevel` is not explicitly set, the component automatically escalates to the smallest error correction level that keeps the code scannable at the requested `logoSize`.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-qr-code
  value="https://www.infragistics.com"
  logo-src="/assets/logo.png"
  logo-size="0.5"
  logo-margin="4">
</igc-qr-code>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrQrCode
  value="https://www.infragistics.com"
  logoSrc="/assets/logo.png"
  logoSize={0.5}
  logoMargin={4}>
</IgrQrCode>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbQrCode
  Value="https://www.infragistics.com"
  LogoSrc="/assets/logo.png"
  LogoSize="0.5"
  LogoMargin="4">
</IgbQrCode>
```

</PlatformBlock>

For safety, `logoSrc` values that use unsafe schemes (such as `javascript:` or `vbscript:`) or non-image `data:` URIs are rejected — no image is rendered. Regular URLs and `data:image/*` URIs are accepted.

### Accessible Labeling

The rendered `<svg>` has `role="img"` and includes a `<title>` element that is announced by screen readers. The default title is `QR code: <value>`. Provide a custom `aria-label` to override the announced text with a more descriptive phrase.

### Do/Don't

Use QR codes when users need a fast bridge from print or static screens to a digital action, such as opening a page, downloading an app, or verifying a link. Do not use them for information that must be readable without a scanner, or when the destination is better served by a direct button, link, or short URL.

The {Platform} QR Code appearance is controlled through CSS variables, CSS parts and the theming system.

### Styling Variables

| Variable | What it changes |
| -- | -- |
| `--ig-qr-code-background` | The background color of the QR code. Defaults to `white`. |
| `--ig-qr-code-dark-color` | The color of the data modules, and the corner square/dot colors unless overridden. Defaults to `black`. |
| `--ig-qr-code-corner-square-color` | The color of the outer finder-pattern corner squares. Falls back to `--ig-qr-code-dark-color`. |
| `--ig-qr-code-corner-dot-color` | The color of the inner finder-pattern corner dots. Falls back to `--ig-qr-code-dark-color`. |

### Style Parts

| Part | What it styles |
| -- | -- |
| `background` | The background rectangle of the QR code. |
| `dots` | The data modules (dots) of the QR code. |
| `corner-square` | The outer finder-pattern corner squares. |
| `corner-dot` | The inner finder-pattern corner dots. |

### Sass Theming

Use the {ProductName} theme system to style the QR Code consistently with the rest of your application. Wrap the QR Code inside a section that scopes the CSS custom properties, or set them directly on the host.

```scss
@use "igniteui-theming/sass/themes" as *;

$custom-qr-code-theme: qr-code-theme(
  $background: #1a1a2e,
  $dark-color: #a0c4ff,
  $corner-square-color: #ff6b6b,
  $corner-dot-color: #ffd93d
);

:root {
  @include tokens($custom-qr-code-theme);
}
```

## Accessibility

The {Platform} QR Code is a static, non-interactive graphic that is announced by screen readers through an SVG `<title>` element.

### Screen Readers / ARIA

- The rendered `<svg>` element has `role="img"` and contains a `<title>` element describing the code.
- The default `<title>` content is `QR code: <value>`.
- Set `aria-label` to override the announced text with a more descriptive phrase such as "Scan to visit our product page".

## Troubleshooting

The {Platform} QR Code troubleshooting guidance follows a problem → cause → fix format for common integration and rendering issues.

### Why is my QR code not scanning?

Contrast between the modules and the background is too low, the code is too small on screen, or the quiet-zone margin is too small. Restore the default `black` on `white` colors, increase `size`, and use a `margin` of at least `4` modules for reliable scanning.

### Why does adding a logo make the code stop scanning?

The requested `logoSize` covers more of the code than the current `errorLevel` can compensate for. Lower `logoSize`, or leave `errorLevel` unset and let the component escalate automatically to the smallest level that fits the logo.

### Why is my logo not showing up?

`logoSrc` points to an unsafe scheme (such as `javascript:` or `vbscript:`), a non-image `data:` URI, or an image that failed to load. Replace the source with a valid image URL or a `data:image/*` URI; assigning a valid source afterwards recovers the rendered logo.

### Why did my QR code not switch to a dark theme automatically?

QR Code colors do not automatically invert with the global light/dark theme, because inverted codes are not universally scannable. Set `--ig-qr-code-background` and `--ig-qr-code-dark-color` explicitly for the dark variant of your UI.

### Why does the code disappear when I clear the value?

The component renders nothing when `value` is not set. Assigning any non-empty string to `value` re-renders the SVG.

## Known Limitations

The {Platform} QR Code has the following platform-independent limitations.

- The component does not automatically invert its colors when the global theme switches to a dark variant; light-on-dark QR codes must be configured explicitly through the CSS variables.
- The QR Code is a purely presentational graphic — it has no methods, events, or slots and does not participate in the tab order.
- QR Code visual structure follows a fixed, standardized layout and is not mirrored in Right-to-Left contexts.
- Unsafe `logoSrc` schemes (`javascript:`, `vbscript:`) and non-image `data:` URIs are rejected; no image is rendered in those cases.
