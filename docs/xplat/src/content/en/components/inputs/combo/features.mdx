# Combo Component Features

The {Platform} Combo binds to local data, filters its options as the user types, groups them by a data field, and can be disabled.

<PlatformBlock for="Angular">

The Combo can also load its data from a remote service in chunks, accept custom values, and show its list with custom overlay settings.

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

The Combo can also load its options from a remote service one page at a time.

</PlatformBlock>

### Remote Binding

The Combo can load its data from a remote service in chunks: it requests the items the user scrolls to through the <ApiLink type="Combo" member="dataPreLoad" label="dataPreLoad" /> event, and the service returns only those items. The sample below loads products from a remote service while the user scrolls and searches:

<Sample src="/lists/combo-remote" showThemePicker height={560} noBorder={false} spacing="md" alt="{Platform} Combo that loads products from a remote service in chunks" />

#### Define Remote Service

A remote service loads the items on demand from a server. The Combo exposes its <ApiLink type="Combo" member="virtualizationState" label="virtualizationState" /> property, which holds the index of the first item to load and the number of items to load. To size the scrollbar for all the items on the server, set the <ApiLink type="Combo" member="totalItemCount" label="totalItemCount" /> property to their total count.

The following service has a `getData()` method that builds the request from the state of the Combo and its search text, and emits the loaded items through an observable:

```typescript
import { HttpClient } from '@angular/common/http';
import { Injectable, inject } from '@angular/core';
import { IForOfState } from 'igniteui-angular/directives';
// import { IForOfState } from '@infragistics/igniteui-angular/directives'; for licensed package
import { BehaviorSubject } from 'rxjs';

@Injectable()
export class RemoteNWindService {
    private http = inject(HttpClient);
    private url = 'https://services.odata.org/V4/Northwind/Northwind.svc/Products';

    public remoteData = new BehaviorSubject<any[]>([]);

    public getData(state: IForOfState, searchText: string, cb?: (data: any) => void) {
        return this.http.get(this.buildUrl(state, searchText)).subscribe((data: any) => {
            this.remoteData.next(data.value);
            cb?.(data);
        });
    }

    // Requests the chunk of items the Combo shows, and the total count of the matching items.
    private buildUrl(state: IForOfState, searchText: string): string {
        let query = `?$skip=${state.startIndex}&$top=${state.chunkSize}&$count=true`;
        if (searchText) {
            // Double the apostrophes for OData, then encode the text for the URL.
            const text = encodeURIComponent(searchText.replace(/'/g, "''"));
            query += `&$filter=contains(ProductName, '${text}')`;
        }
        return `${this.url}${query}`;
    }
}
```

#### Binding ComboBox to Remote Service

Bind the observable of the service to the Combo with the `async` pipe, and request a new chunk of items whenever the Combo raises <ApiLink type="Combo" member="dataPreLoad" label="dataPreLoad" /> or the search text changes:

```html
<igx-combo #remoteCombo
    [data]="rData | async"
    valueKey="ProductID"
    displayKey="ProductName"
    (dataPreLoad)="onDataPreLoad()"
    (searchInputUpdate)="onSearchInputUpdate($event)">
    <label igxLabel>Products</label>
</igx-combo>
```

```typescript
// The size of the first chunk, requested before the Combo reports how many items it shows.
const FIRST_CHUNK_SIZE = 10;

// The component lists RemoteNWindService in its providers, and the application
// providers include provideHttpClient(), which the service needs.
export class ComboRemoteComponent implements OnInit {
    @ViewChild('remoteCombo', { static: true })
    public remoteCombo: IgxComboComponent;

    private remoteService = inject(RemoteNWindService);
    public rData = this.remoteService.remoteData;
    private searchText = '';

    public ngOnInit() {
        this.loadChunk({ startIndex: 0, chunkSize: FIRST_CHUNK_SIZE });
    }

    // The Combo asks for the next chunk while the user scrolls.
    public onDataPreLoad() {
        this.loadChunk(this.remoteCombo.virtualizationState);
    }

    // The server filters the items: request the first chunk of the matching ones.
    public onSearchInputUpdate(event: IComboSearchInputEventArgs) {
        this.searchText = event.searchText;
        this.loadChunk({ startIndex: 0, chunkSize: FIRST_CHUNK_SIZE });
    }

    private loadChunk(state: IForOfState) {
        this.remoteService.getData(state, this.searchText, (data) => {
            // The total count sizes the scrollbar for all the items, not only the loaded chunk.
            this.remoteCombo.totalItemCount = data['@odata.count'];
        });
    }
}
```

#### Handling Selection

When the Combo is bound to remote data that loads in chunks, and the data items are objects, set the <ApiLink type="Combo" member="valueKey" label="valueKey" /> property. Without it, the Combo compares the selected items with the loaded items by reference, as described in the [Combo topic](./overview.mdx#data-binding). Every chunk the service loads creates new objects, so the Combo can't match the selected items with them.

<DocsAside type="info">
When binding the Combo to remote data, set the `valueKey` property to a property that is unique to each item.
</DocsAside>

#### Binding the Combo to a Remote Service

Import `bindComboDataSource()` from `igniteui-webcomponents/extras/combo-data-source`, and pass it the Combo and a source with a `load()` function. The binding calls `load()` for each page with a request that holds `searchText`, `caseSensitive`, `startIndex` and `count`, and with an `AbortSignal`. Return the items of the page and the total count of the matching items:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-combo id="combo" label="Products" value-key="ProductID" display-key="ProductName"></igc-combo>
```

```ts
import { defineComponents, IgcComboComponent } from 'igniteui-webcomponents';
import { bindComboDataSource } from 'igniteui-webcomponents/extras/combo-data-source';

defineComponents(IgcComboComponent);

interface Product {
    ProductID: number;
    ProductName: string;
}

const url = 'https://services.odata.org/V4/Northwind/Northwind.svc/Products';
const combo = document.getElementById('combo') as IgcComboComponent<Product>;

const binding = bindComboDataSource(combo, {
    // Loads one page of the products that match the search text.
    load: async ({ searchText, startIndex, count }, signal) => {
        let query = `?$skip=${startIndex}&$top=${count}&$count=true`;
        if (searchText) {
            // Double the apostrophes for OData, then encode the text for the URL.
            const text = encodeURIComponent(searchText.replace(/'/g, "''"));
            query += `&$filter=contains(ProductName, '${text}')`;
        }

        // The signal lets a newer search abort this request.
        const response = await fetch(`${url}${query}`, { signal });
        const data = await response.json();
        return { items: data.value, totalCount: data['@odata.count'] };
    }
}, {
    // The service returns up to 20 products per request.
    pageSize: 20
});
```

</PlatformBlock>

<PlatformBlock for="React">

In React, pass the element that the `ref` of `IgrCombo` holds, and dispose the binding when the component unmounts:

```tsx
import { useEffect, useRef } from "react";
import { IgrCombo } from "igniteui-react";
import { bindComboDataSource } from "igniteui-webcomponents/extras/combo-data-source";

const url = "https://services.odata.org/V4/Northwind/Northwind.svc/Products";

export default function RemoteCombo() {
  const comboRef = useRef<IgrCombo>(null);

  useEffect(() => {
    const binding = bindComboDataSource(comboRef.current!, {
      // Loads one page of the products that match the search text.
      load: async ({ searchText, startIndex, count }, signal) => {
        let query = `?$skip=${startIndex}&$top=${count}&$count=true`;
        if (searchText) {
          // Double the apostrophes for OData, then encode the text for the URL.
          const text = encodeURIComponent(searchText.replace(/'/g, "''"));
          query += `&$filter=contains(ProductName, '${text}')`;
        }

        // The signal lets a newer search abort this request.
        const response = await fetch(`${url}${query}`, { signal });
        const data = await response.json();
        return { items: data.value, totalCount: data["@odata.count"] };
      }
    }, {
      // The service returns up to 20 products per request.
      pageSize: 20
    });

    return () => binding.dispose();
  }, []);

  return <IgrCombo ref={comboRef} label="Products" valueKey="ProductID" displayKey="ProductName" />;
}
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

The binding switches the Combo to remote filtering and makes the requests:

- It loads the first page when the user opens a list that has no items, and again after the user stops typing in the search input.
- It appends the next page when the user scrolls near the end of the loaded items.
- It aborts a request that a newer search makes stale, through the signal that `load()` passes to `fetch()`.
- It sets the `totalItemCount` property of the Combo to the total count, and its `loading` property while a search waits or a page loads.

While the Combo holds fewer items than `totalItemCount`, its list shows a placeholder for each item to load, so the scrollbar shows the full length of the results. While `loading` is set, the Combo shows a spinner in place of its toggle icon. Replace the spinner through the `loading` slot, and style the spinner and the placeholders through the `loading` and `placeholder` CSS parts.

The third argument of `bindComboDataSource()` configures the binding:

| Option | Default | Description |
|---|---|---|
| `pageSize` | `50` | The smallest number of items that a request loads. A source can return fewer, for example up to the page limit of the server, and the Combo then requests the rest. |
| `debounce` | `300` | The pause in the typing, in milliseconds, before a search loads. |
| `loadOnOpen` | `true` | Whether the first page loads when the user opens a list that has no items. |
| `onError` | - | Receives the error of a failed request. The Combo keeps its items. |

`bindComboDataSource()` returns a binding with two methods. `refresh()` loads the first page of the current search again; call it after you change `filteringOptions.caseSensitive` in code. `dispose()` removes the listeners, aborts the requests in flight, and gives the Combo back its filtering mode.

#### Remote Filtering Mode

`bindComboDataSource()` uses only the public API of the Combo. To make the requests yourself, set the `mode` of <ApiLink type="Combo" member="filteringOptions" label="filteringOptions" /> to `remote`:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts

```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
// In an effect, once the Combo has rendered.
comboRef.current!.filteringOptions = { mode: "remote" };
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

In remote mode, the Combo leaves the search to your service:

- The Combo no longer filters its options. Read `detail.searchText` of the `igcSearchInput` event, search on the server, and set <ApiLink type="Combo" member="data" label="data" /> to the first page of the results. The server does the matching, so send `filteringOptions.caseSensitive` with the search.
- When the user scrolls near the end of `data`, the `igcDataRequest` event asks for `detail.count` more items at `detail.startIndex`. Append them to `data`.
- Set `totalItemCount` to the total count of the results, and `loading` while a request runs.

#### Handling Selection

Set <ApiLink type="Combo" member="valueKey" label="valueKey" /> when the Combo loads remote data. Each page creates new objects, and the Combo matches the selected items with them by the value of that key. A new `data` keeps the selection: the selected items stay selected when a search returns results that don't hold them, and show as selected again when a later page or search holds them.

To select values whose items no page has loaded yet, such as the values of a saved filter, add a `resolve()` function to the source of `bindComboDataSource()`. The binding calls it with those values, and selects the items it returns.

The Combo can't tell whether the server deleted a selected item or only hasn't sent its page. When you load live data again, call <ApiLink type="Combo" member="deselect" label="deselect()" /> for the selected items that the server no longer has.

</PlatformBlock>

#### Filtering Options

<PlatformBlock for="Angular">

- `caseSensitive` - whether the search is case-sensitive. Defaults to `false`. The case-sensitive icon toggles this value.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

### Scroll Strategy

The <ApiLink type="Combo" member="scrollStrategy" label="scrollStrategy" /> property sets what the dropdown of the {Platform} Combo does when a container around the Combo scrolls while the dropdown is open: `hide` (the default) hides the dropdown while the input is out of view, `scroll` keeps the dropdown open and attached to the input, and `close` closes it.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-combo scroll-strategy="close"></igc-combo>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrCombo scrollStrategy="close" />
```

</PlatformBlock>
