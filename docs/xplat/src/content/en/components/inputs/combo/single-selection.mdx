# Single Selection Combo

The {ProductName} Single Selection Combo is a Combo in which users select one option and filter the searchable dropdown list by typing in the input field.

<PlatformBlock for="Angular">

The Angular single selection Combo is the Simple Combo, the `igx-simple-combo` component. It binds, groups, and templates its options like the Combo, and lets users type in the input field to filter the list or to enter a custom value.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Set <PlatformBlock for="React,WebComponents"><ApiLink type="Combo" member="singleSelect" label="singleSelect" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink pkg="core" type="Combo<T>" member="SingleSelect" label="SingleSelect" /></PlatformBlock> on the {Platform} Combo to switch it to single selection. The input field becomes editable and filters the list as users type, the search input of the dropdown is hidden, and the options show no checkboxes.

</PlatformBlock>

<DocsAside type="info">
The Combo has two layout options: Combo with Single Select (Simple Combo) and Combo (Multiple Select).
</DocsAside>

In the single selection mode, the `igc-combo` element renders an editable input field, hides the search input of the dropdown, and renders the options without checkboxes:

```text
igc-combo[single-select]
└─ #shadow-root
   ├─ igc-popover
   │  ├─ igc-input#target[slot="anchor"]            // the editable input field, exported as the "input" part
   │  │  ├─ slot[name="prefix"]
   │  │  ├─ span[part="clear-icon"]                  // shown when the Combo has a value
   │  │  ├─ slot[name="suffix"]
   │  │  └─ span[part="toggle-icon"]
   │  └─ div[part="list-wrapper"]                    // the dropdown
   │     ├─ div[part="filter-input"][hidden]         // the search input is hidden
   │     ├─ div[part="header"]
   │     │  └─ slot[name="header"]
   │     ├─ igc-virtual-scroll#dropdown[part="list"][role="listbox"]
   │     │  ├─ igc-combo-header[part="group-header"] // one for each group
   │     │  └─ igc-combo-item[part="item"][hide-checkbox] // one for each option
   │     ├─ div[part="empty"]                        // shown when the list has no options
   │     │  └─ slot[name="empty"]
   │     └─ div[part="footer"]
   │        └─ slot[name="footer"]
   └─ igc-validator#combo-helper-text               // the helper text and the validation messages, exported as the "helper-text" part
```

</PlatformBlock>

## Usage

Use the {Platform} Single Selection Combo when users pick exactly one option from a list that they need to search, such as a country or a city.

### Type

The Simple Combo Input provides selection between a border type for a more structured perception on solid color backgrounds, and a boxed type that is most appropriate when placed on top of a vivid image to improve readability.

<PlatformBlock for="React,WebComponents,Blazor">

The {Platform} Combo uses the box type by default. Set `outlined` for the border type. The box type is a style of the Material theme: in the Bootstrap, Fluent, and Indigo themes, both types look the same, so the samples show the box type only in the Material theme.

</PlatformBlock>

### Interaction States

The Combo component supports five states for the enabled variants: Idle, Idle & Hover, Filled, Filled & Hover and Focused, as well as three validation states: Success, Warn, and Error.

Clicking the input field or the toggle opens the dropdown, and typing in the input field opens it and filters the list. To open and close the dropdown in code, use the <PlatformBlock for="React,WebComponents">`open` property or the `show`, `hide`, and `toggle` methods</PlatformBlock><PlatformBlock for="Blazor">`Open` parameter or the `ShowAsync`, `HideAsync`, and `ToggleAsync` methods</PlatformBlock><PlatformBlock for="Angular">`open`, `close`, and `toggle` methods</PlatformBlock>:

<PlatformBlock for="WebComponents">

```ts
const combo = document.getElementById('countries') as IgcComboComponent;

await combo.show();
await combo.hide();
await combo.toggle();
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const comboRef = useRef<IgrCombo>(null);

const open = () => comboRef.current?.show();
const close = () => comboRef.current?.hide();
const toggle = () => comboRef.current?.toggle();

return <IgrCombo ref={comboRef} singleSelect data={countries} valueKey="id" displayKey="name" />;
```

</PlatformBlock>

### Validation States

Every experienced designer uses constraints wisely to limit the user input and avoid invalid states, hence the availability of validation styles. <PlatformBlock for="React,WebComponents,Blazor">

In the single selection mode, the form value is the `valueKey` value of the selected item. The Combo has no built-in success or warn state, so the sample styles these two states with CSS classes.

### Value and Selection

The {Platform} Single Selection Combo holds one selected item, and exposes it through its value and its selection API.

<PlatformBlock for="React,WebComponents,Blazor">

The `value` holds the selected item as an array with one element: its `valueKey` value, or the object reference when there is no `valueKey`. Set it to select an item when the Combo first renders. The `select` method selects a single item and deselects the previous one, so pass one item; the `deselect` method deselects it. Called without an item, `select` clears the selection in the single selection mode:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
// select the item matching the 'BG' value of the value key field
combo.select('BG');

// deselect it
combo.deselect('BG');

console.log(combo.value); // ['BG'] while Bulgaria is selected, [] after the deselection
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
// select the item matching the 'BG' value of the value key field
comboRef.current?.select('BG');

// deselect it
comboRef.current?.deselect('BG');

console.log(comboRef.current?.value); // ['BG'] while Bulgaria is selected, [] after the deselection
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCombo T="string" @ref="Combo" SingleSelect="true" Data="Countries" ValueKey="Id" DisplayKey="Name" />

@code {
    private IgbCombo<string> Combo;

    public void SelectBulgaria() => Combo.Select(new object[] { "BG" });

    public void DeselectBulgaria() => Combo.Deselect(new object[] { "BG" });
}
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

The Combo emits <PlatformBlock for="WebComponents">`igcChange`</PlatformBlock><PlatformBlock for="React">`onChange`</PlatformBlock><PlatformBlock for="Blazor">`Change`</PlatformBlock> before the user changes the selection. Its detail holds the new value, the changed items, and the type of the change, and canceling it keeps the selection.

</PlatformBlock>

<PlatformBlock for="Angular">

The Angular Simple Combo supports two-way binding with `[(ngModel)]` and works in template-driven and reactive forms. The bound value is a single item: its `valueKey` value, or the object reference when there is no `valueKey`. The <ApiLink type="SimpleCombo" member="selection" label="selection" /> property returns the selected item, the <ApiLink type="SimpleCombo" member="select" label="select" /> method selects an item, and the <ApiLink type="SimpleCombo" member="deselect" label="deselect" /> method clears the selection:

```html

```

```ts
export class CountriesComponent {
    @ViewChild(IgxSimpleComboComponent, { static: true })
    public combo: IgxSimpleComboComponent;

    public selectedCountry = 'BG';

    public selectBelgium(): void {
        this.combo.select('BE');
    }

    public clear(): void {
        this.combo.deselect();
    }
}
```

The Angular Simple Combo emits <ApiLink type="SimpleCombo" member="selectionChanging" label="selectionChanging" /> before the selection changes, and <ApiLink type="SimpleCombo" member="selectionChanged" label="selectionChanged" /> after it. The event arguments hold the old and the new value, the old and the new item, and the display text of the input field, and setting `cancel` in `selectionChanging` keeps the selection:

```html
<igx-simple-combo [data]="countries" valueKey="id" displayKey="name" (selectionChanging)="onCountryChanging($event)"></igx-simple-combo>
```

```ts
public onCountryChanging(event: ISimpleComboSelectionChangingEventArgs): void {
    if (event.newValue === 'BY') {
        event.cancel = true;
    }
}
```

The `selectionChanging` event also drives a cascading scenario, in which the selection of one Simple Combo loads the data of the next one, for example a country, a region, and a city combo. Handle the `selectionChanging` event of each Simple Combo to load the data of the next one and to clear its selection:

```html
<igx-simple-combo #country
    [data]="countriesData"
    (selectionChanging)="countryChanging($event)"
    placeholder="Choose Country..."
    [(ngModel)]="selectedCountry"
    displayKey="name">
</igx-simple-combo>
<igx-simple-combo #region
    [data]="regionData"
    (selectionChanging)="regionChanging($event)"
    placeholder="Choose Region..."
    [(ngModel)]="selectedRegion"
    displayKey="name"
    [disabled]="regionData.length === 0">
</igx-simple-combo>
<igx-simple-combo #city
    [data]="citiesData"
    placeholder="Choose City..."
    [(ngModel)]="selectedCity"
    displayKey="name"
    [disabled]="citiesData.length === 0">
</igx-simple-combo>
```

```ts
export class SimpleComboCascadingComponent implements OnInit {
    public selectedCountry: Country;
    public selectedRegion: Region;
    public selectedCity: City;
    public countriesData: Country[];
    public regionData: Region[] = [];
    public citiesData: City[] = [];

    public ngOnInit(): void {
        this.countriesData = getCountries(['United States', 'Japan', 'United Kingdom']);
    }

    public countryChanging(e: ISimpleComboSelectionChangingEventArgs) {
        this.selectedCountry = e.newSelection as Country;
        this.regionData = getCitiesByCountry([this.selectedCountry?.name])
            .map(c => ({ name: c.region, country: c.country }))
            .filter((v, i, a) => a.findIndex(r => r.name === v.name) === i);
        this.selectedRegion = null;
        this.selectedCity = null;
        this.citiesData = [];
    }

    public regionChanging(e: ISimpleComboSelectionChangingEventArgs) {
        this.selectedRegion = e.newSelection as Region;
        this.citiesData = getCitiesByCountry([this.selectedCountry?.name])
            .filter(c => c.region === this.selectedRegion?.name);
        this.selectedCity = null;
    }
}
```

The [Grid with Cascading Combos](../../grid/cascading-combos.mdx) topic shows the same scenario in the cell editing of the Data Grid.

</PlatformBlock>

### Filtering

Typing in the input field of the {Platform} Single Selection Combo opens the dropdown and filters the list to the options that contain the text. The first match becomes the active option, so <kbd>Enter</kbd> selects it.

<PlatformBlock for="React,WebComponents,Blazor">

Set `disableFiltering` to keep the whole list while users type. The `filteringOptions` object sets the key that the text filters by, and whether the filtering is case-sensitive and matches diacritics. When the Combo loses the focus without a selected option, the input field is cleared.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
combo.filteringOptions = { filterKey: 'name', caseSensitive: false, matchDiacritics: true };
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrCombo singleSelect filteringOptions={{ filterKey: 'name', caseSensitive: false, matchDiacritics: true }} />
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCombo T="string" SingleSelect="true" DisableFiltering="true" Data="Countries" ValueKey="Id" DisplayKey="Name" />
```

</PlatformBlock>

<PlatformBlock for="Angular">

Set <ApiLink type="SimpleCombo" member="disableFiltering" label="disableFiltering" /> to keep the whole list while users type, and <ApiLink type="SimpleCombo" member="showSearchCaseIcon" label="showSearchCaseIcon" /> to show a button in the input field that toggles case-sensitive filtering. The <ApiLink type="SimpleCombo" member="filteringOptions" label="filteringOptions" /> input sets the key that the text filters by and whether the filtering is case-sensitive, and <ApiLink type="SimpleCombo" member="filterFunction" label="filterFunction" /> replaces the filtering with your own. When the Simple Combo loses the focus without a selected option, the input field is cleared:

```html

</igx-simple-combo>
```

Set <ApiLink type="SimpleCombo" member="allowCustomValues" label="allowCustomValues" /> to let users enter a value that is not in the list. When the text matches no option, the dropdown shows an add item button, and <kbd>Enter</kbd> on it adds the text as a new item and selects it. The Simple Combo emits <ApiLink type="SimpleCombo" member="addition" label="addition" /> before it adds the item:

```html

```

</PlatformBlock>

### Do/Don't

When using the Simple Combo, its input and dropdown should have the same width and their left and right borders should match. Regarding how the dropdown is shown when the Simple Combo is focused, you should always show it on top of the content that follows the Simple Combo triggering its display. Combos don't push content like expansion panels do.

<DoDont
  doSrc={comboDoAlignment}

  dontSrc={comboDoNotAlignment}
  dontAlt="An open Country combo whose dropdown is narrower than its input and shifted to the right"

Align the dropdown with the input so both have the same width and matching left and right borders.

</Fragment>

## Accessibility

The {Platform} Single Selection Combo uses the roles of the WAI-ARIA combobox pattern: the editable input field is a `combobox` that controls a `listbox` of options, and users filter the list by typing and select an option with the keyboard.

### Keyboard Interaction

<PlatformBlock for="React,WebComponents,Blazor">

The input field of the {Platform} Single Selection Combo is a tab stop, and the focus stays in it while users type. The following keys work while the Combo has the focus:

| Key | Action |
| --- | --- |
| Printable characters | In the input field, open the dropdown, filter the list, and activate the first match. |
| <kbd>Arrow Down</kbd> / <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> | In the input field, opens the dropdown, moves the focus to the list, and activates the first option. In the list, activates the next option. |
| <kbd>Arrow Up</kbd> | In the input field, closes the dropdown. In the list, activates the previous option. From the first option, closes the dropdown and moves the focus to the input field. |
| <kbd>Home</kbd> / <kbd>End</kbd> | In the list, activates the first or the last option. |
| <kbd>Space</kbd> | In the list, selects the active option, or deselects it when it is selected. |
| <kbd>Enter</kbd> | With an active option, selects it, closes the dropdown, and moves the focus to the input field with its text selected. |
| <kbd>Escape</kbd> | When the dropdown is open, closes it and moves the focus to the input field. When the dropdown is closed, clears the selection. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | When the dropdown is open, selects the active option, closes the dropdown, and moves the focus to the next or the previous focusable element. |

A disabled Combo ignores these keys.

</PlatformBlock>

<PlatformBlock for="Angular">

The input field of the Angular Simple Combo is a tab stop, and the focus stays in it while users type. The following keys work while the Simple Combo has the focus:

| Key | Action |
| --- | --- |
| Printable characters | In the input field, open the dropdown, filter the list, and focus the first match. |
| <kbd>Arrow Down</kbd> / <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> | In the closed Simple Combo, opens the dropdown. In the open Simple Combo, moves the focus to the list: to the selected option, or to the first option. In the list, moves to the next option, and from the last option to the add item button when it is shown. |
| <kbd>Arrow Up</kbd> | In the list, moves to the previous option. From the first option, moves the focus back to the input field and selects its text. |
| <kbd>Alt</kbd> + <kbd>Arrow Up</kbd> | In the list, closes the dropdown and moves the focus to the input field. |
| <kbd>Home</kbd> / <kbd>End</kbd> | In the list, moves to the first or the last option. |
| <kbd>Space</kbd> | In the list, selects or deselects the focused option. |
| <kbd>Enter</kbd> | In the input field with a focused option that matches the text, selects it and closes the dropdown. In the list, selects the focused option, closes the dropdown, and moves the focus to the input field. On the add item button, adds the text of the input field as a new item and selects it. |
| <kbd>Backspace</kbd> / <kbd>Delete</kbd> | In the input field, clears the selection. |
| <kbd>Escape</kbd> | When the dropdown is open, closes it. When the dropdown is closed, clears the selection and keeps the focus on the input field. |
| <kbd>Tab</kbd> | When the dropdown is open, selects the focused option that matches the text, closes the dropdown, and moves the focus to the next focusable element. |

</PlatformBlock>

### Screen Readers / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

The {Platform} Single Selection Combo renders the following roles and attributes:

| Element | Role | Attributes |
| --- | --- | --- |
| The input field | `combobox` | `aria-haspopup="listbox"`, `aria-expanded`, `aria-disabled`, `aria-controls` that points to the list, and, with a helper text, `aria-describedby` that points to it |
| The `list` part | `listbox` | `aria-multiselectable="false"`, `aria-labelledby` that points to the input field, and `aria-activedescendant` that points to the active option |
| Each `item` part | `option` | `aria-selected`, `aria-posinset`, and `aria-setsize` |
| The `clear-icon` part | `button` | `aria-label` from the resource strings |

The {Platform} Single Selection Combo also behaves as follows for assistive technology:

- The input field takes its accessible name from the `label`. Without a label, it gets a name from the resource strings that says whether an option is selected.
- The input field is editable, and the text that users type is the filter of the list.
- The active option is announced through `aria-activedescendant` while the focus stays in the list.
- The content of the closed dropdown is `inert`.

</PlatformBlock>

<PlatformBlock for="Angular">

The Angular Simple Combo renders the following roles and attributes:

| Element | Role | Attributes |
| --- | --- | --- |
| The input of the input field | `combobox` | `aria-haspopup="listbox"`, `aria-autocomplete="list"`, `aria-readonly="false"`, `aria-expanded`, `aria-controls` that points to the list, `aria-labelledby`, and `aria-label` |
| The dropdown | `listbox` | `aria-labelledby` that points to the `igxLabel` or to the `ariaLabelledBy` element |
| The container of the options | — | `aria-activedescendant` that points to the focused option |
| Each option | `option` | `aria-selected` |
| Each group header | `group` | — |
| The clear button | — | `aria-label` from the resource strings |
| The add item button | `button` | `aria-label` from the resource strings |

The input field takes its accessible name from the `igxLabel` or from the <ApiLink type="SimpleCombo" member="ariaLabelledBy" label="ariaLabelledBy" /> input. Without them, it gets a name from the resource strings that says whether an option is selected.

</PlatformBlock>

## Known Limitations

<PlatformBlock for="React,WebComponents,Blazor">

- The single selection mode hides the search input of the dropdown, so `placeholderSearch`, `caseSensitiveIcon`, and `autofocusList` have no effect.
- The {Platform} Combo doesn't add custom values. When the text in the input field matches no option, the Combo clears the input field when it loses the focus.

</PlatformBlock>

<PlatformBlock for="Angular">

- When the Angular Simple Combo is bound to an array of primitives that contains `undefined`, the list doesn't show `undefined`. When the `valueKey` field of an object is `undefined`, the list shows the item, but users can't select it.
- When the Angular Simple Combo is bound with `ngModel` and is `required`, the `null`, `undefined`, and `''` values can't be selected.
- When the Angular Simple Combo is bound to a remote service and has a predefined selection, the input field stays blank until the data loads.
- The list uses the [Virtual Scroll](../../layouts/virtual-scroll.mdx#known-limitations), so its limitations apply. The list renders only the options in view, and code that queries the DOM finds only those options.

</PlatformBlock>

## FAQ

These questions cover common {Platform} Single Selection Combo setup, selection, and usage scenarios.

<Faq>
  <FaqItem question="How do I make the Combo select a single item?" indicatorPosition="end">
    <PlatformBlock for="Angular">Use the Angular Simple Combo, the `igx-simple-combo` component, instead of the Combo. The Simple Combo selects one item and lets users type in its input field to filter the list.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">Set `singleSelect` on the {Platform} Combo.   </FaqItem>
  <FaqItem question="How do I set the selected item of the Single Selection Combo?" indicatorPosition="end">
    <PlatformBlock for="Angular">Bind the Angular Simple Combo with `[(ngModel)]` or a form control to a single `valueKey` value, or call the `select` method with the item.   </FaqItem>
  <FaqItem question="Can users enter a value that is not in the list?" indicatorPosition="end">
    <PlatformBlock for="Angular">Yes. Set `allowCustomValues` on the Angular Simple Combo, and the dropdown shows an add item button when the text matches no option.
