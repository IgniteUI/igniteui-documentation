# Combo Templates

The {ProductName} Combo Templates replace the default content of the Combo areas: the items, the group headers, the header and the footer of the list, the empty list, the toggle and the clear icons, and the input field.

<PlatformBlock for="Angular">

The Angular Combo takes each template as an `ng-template` element with one of its template directives, placed inside the `igx-combo` element. The directives come with the `IGX_COMBO_DIRECTIVES` token, as the [Combo](./overview.mdx#getting-started) topic shows, together with the `igxLabel`, `igx-prefix`, `igx-suffix`, and `igx-hint` elements that template the input field.

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

The {Platform} Combo renders its items and group headers through the <ApiLink type="Combo" member="itemTemplate" label="itemTemplate" /> and <ApiLink type="Combo" member="groupHeaderTemplate" label="groupHeaderTemplate" /> properties, and takes the content of the other areas through its slots. Use a `<span>` for simple text or symbols, and an [Icon](../../layouts/icon.mdx) for icons. The `header` and `footer` slots also accept the `<header>` and `<footer>` elements.

</PlatformBlock>

<PlatformBlock for="Blazor">

The Blazor Combo renders its items and group headers through JavaScript template functions that the <ApiLink pkg="core" type="Combo<T>" member="ItemTemplateScript" label="ItemTemplateScript" /> and <ApiLink pkg="core" type="Combo<T>" member="GroupHeaderTemplateScript" label="GroupHeaderTemplateScript" /> parameters reference by name, and takes the content of the other areas through its slots. Use a `<span>` for simple text or symbols, and an [Icon](../../layouts/icon.mdx) for icons. The `header` and `footer` slots also accept the `<header>` and `<footer>` elements.

</PlatformBlock>

## Types

The {Platform} Combo has a template for each area that it renders. <PlatformBlock for="Angular">Reference each template through its directive, and read the item and the keys of the Combo from the template context.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">The following sections show the property or the slot that takes each template.</PlatformBlock>

The snippets bind the Combo to destinations that have an `id`, a `name`, a `country`, a `countryCode`, a `region`, and a UTC `offset`, with `id` as the `valueKey`, `name` as the `displayKey`, and `region` as the `groupKey`.<PlatformBlock for="Blazor"> The Blazor snippets use the same fields in Pascal case: `Id`, `Name`, `Country`, `CountryCode`, `Region`, and `Offset`.</PlatformBlock>

### Item Template

The item template renders the content of each option in the list. By default, an option shows its `displayKey` value, and the checkbox of the option stays in front of the template content.

<PlatformBlock for="React,WebComponents,Blazor">

The item and the group header templates render inside the shadow DOM of the Combo, where the styles of the page don't reach. Style their containers through the `item` and `group-header` CSS parts, and lay out their content with inline styles. The Combo lays out each root element of a template as a block, so wrap the content of a template in a single element.

</PlatformBlock>

<PlatformBlock for="Angular">

Use the `igxComboItem` directive. The template receives the item as its implicit value, together with the `valueKey`, the `displayKey`, and the `data` of the Combo:

```html
<igx-combo [data]="destinations" valueKey="id" displayKey="name" groupKey="region">
    <ng-template igxComboItem let-destination let-key="displayKey">
        <span class="destination">
            <img class="flag" [src]="'https://dl.infragistics.com/x/img/flags/' + destination.countryCode + '.png'" alt="" />
            {{ destination[key] }} — {{ destination.country }} · {{ destination.id }} · {{ destination.offset }}
        </span>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

Set the <ApiLink type="Combo" member="itemTemplate" label="itemTemplate" /> property to a function that receives the item and returns a `lit-html` template:

```ts
import { IgcComboComponent, ComboItemTemplate } from 'igniteui-webcomponents';
import { html } from 'lit-html';

const itemTemplate: ComboItemTemplate<Destination> = ({ item }) => html`
    <span>
        <img src="https://dl.infragistics.com/x/img/flags/${item.countryCode}.png" alt="" style="width: 1.25rem;" />
        ${item.name} — ${item.country} · ${item.id} · ${item.offset}
    </span>
`;

const combo = document.querySelector('igc-combo') as IgcComboComponent<Destination>;
combo.itemTemplate = itemTemplate;
```

</PlatformBlock>

<PlatformBlock for="React">

Pass a function that receives the item and returns its content to the <ApiLink type="Combo" member="itemTemplate" label="itemTemplate" /> property:

```tsx
import { IgrCombo, ComboTemplateProps } from 'igniteui-react';

const renderItem = ({ item }: ComboTemplateProps<Destination>) => (
    <span>
        <img src={`https://dl.infragistics.com/x/img/flags/${item.countryCode}.png`} alt="" style={{ width: '1.25rem' }} />
        {item.name} — {item.country} · {item.id} · {item.offset}
    </span>
);

<IgrCombo data={destinations} valueKey="id" displayKey="name" groupKey="region" itemTemplate={renderItem} />
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Define the template in a JavaScript file under `wwwroot`, for example `templates.js`. The template is a function that receives the item and returns a template made with the `html` tag of `igTemplating`, and `igRegisterScript` registers it under the name that the Combo references:

```js
const html = window.igTemplating.html;

const itemTemplate = ({ item }) => html`
    <span>
        <img src="https://dl.infragistics.com/x/img/flags/${item.CountryCode}.png" alt="" style="width: 1.25rem;" />
        ${item.Name} — ${item.Country} · ${item.Id} · ${item.Offset}
    </span>
`;

igRegisterScript("ComboItemTemplate", itemTemplate, false);
```

Include the file in `wwwroot/index.html`. The script calls `igRegisterScript` while the page loads, so include `app.bundle.js` before the Blazor script:

```html
<body>
    <script src="_content/IgniteUI.Blazor/app.bundle.js"></script>
    <script src="_framework/blazor.webassembly.js"></script>
    <script src="templates.js"></script>
</body>
```

Then set the <ApiLink pkg="core" type="Combo<T>" member="ItemTemplateScript" label="ItemTemplateScript" /> parameter to the name of the template:

```razor
<IgbCombo T="string" Data="Destinations" ValueKey="Id" DisplayKey="Name" GroupKey="Region" ItemTemplateScript="ComboItemTemplate" />
```

</PlatformBlock>

### Header Item Template

The header item template renders the header of each group when the Combo has a `groupKey`. By default, a group header shows the group value. The template receives a header record, not a data item: its `groupKey` field holds the group value, so a count of the options in the group comes from the data of the Combo, as the `citiesIn` method of the snippets does.

<PlatformBlock for="Angular">

Use the `igxComboHeaderItem` directive. The template receives the header record as its implicit value, together with the `groupKey`, the `valueKey`, the `displayKey`, and the `data` of the Combo:

```html
<igx-combo [data]="destinations" valueKey="id" displayKey="name" groupKey="region">
    <ng-template igxComboHeaderItem let-header let-key="groupKey">
        <span class="region">
            <strong>{{ header[key] }}</strong>
            <span class="region-count">{{ citiesIn(header[key]) }} cities</span>
        </span>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

Set the <ApiLink type="Combo" member="groupHeaderTemplate" label="groupHeaderTemplate" /> property:

```ts
const groupHeaderTemplate: ComboItemTemplate<Destination> = ({ item }) => html`
    <span style="display: flex; gap: 0.5rem; width: 100%;">
        <strong>${item.region}</strong>
        <span style="margin-inline-start: auto;">${citiesIn(item.region)} cities</span>
    </span>
`;

combo.groupHeaderTemplate = groupHeaderTemplate;
```

</PlatformBlock>

<PlatformBlock for="React">

Pass the function to the <ApiLink type="Combo" member="groupHeaderTemplate" label="groupHeaderTemplate" /> property:

```tsx
const renderGroupHeader = ({ item }: ComboTemplateProps<Destination>) => (
    <span style={{ display: 'flex', gap: '0.5rem', width: '100%' }}>
        <strong>{item.region}</strong>
        <span style={{ marginInlineStart: 'auto' }}>{citiesIn(item.region)} cities</span>
    </span>
);

<IgrCombo data={destinations} valueKey="id" displayKey="name" groupKey="region" groupHeaderTemplate={renderGroupHeader} />
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Register the template in `templates.js`, and set the <ApiLink pkg="core" type="Combo<T>" member="GroupHeaderTemplateScript" label="GroupHeaderTemplateScript" /> parameter to its name:

```js
const groupHeaderTemplate = ({ item }) => html`
    <span style="display: flex; gap: 0.5rem; width: 100%;">
        <strong>${item.Region}</strong>
        <span style="margin-inline-start: auto;">${citiesIn(item.Region)} cities</span>
    </span>
`;

igRegisterScript("ComboGroupHeaderTemplate", groupHeaderTemplate, false);
```

```razor
<IgbCombo T="string" Data="Destinations" ValueKey="Id" DisplayKey="Name" GroupKey="Region" GroupHeaderTemplateScript="ComboGroupHeaderTemplate" />
```

</PlatformBlock>

### Header Template

The header template renders content between the search input and the list of options, such as a title of the list or an action that applies to it. The Combo renders no header by default.

<PlatformBlock for="Angular">

Use the `igxComboHeader` directive. The snippet adds a button that selects the options that the search input shows, through the <ApiLink type="Combo" member="selectAllItems" label="selectAllItems" /> method:

```html
<igx-combo #combo [data]="destinations" valueKey="id" displayKey="name" groupKey="region">
    <ng-template igxComboHeader>
        <div class="list-header">
            <span>Destinations by region</span>
            <button igxButton="flat" (click)="combo.selectAllItems()">Select all</button>
        </div>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

Pass the content to the `header` slot. The snippet adds a button that selects all options, through the <ApiLink type="Combo" member="select" label="select" /> method called without an argument. Register the Button component, as the [Button](../button.mdx) topic shows:

```html
<igc-combo id="destinations" value-key="id" display-key="name" group-key="region">
    <header slot="header" class="list-header">
        <span>Destinations by region</span>
        <igc-button id="select-all" variant="flat">Select all</igc-button>
    </header>
</igc-combo>
```

```ts
const combo = document.getElementById('destinations') as IgcComboComponent<Destination>;

document.getElementById('select-all').addEventListener('click', () => combo.select());
```

</PlatformBlock>

<PlatformBlock for="React">

Pass the content to the `header` slot. The snippet adds a button that selects all options, through the <ApiLink type="Combo" member="select" label="select" /> method called without an argument:

```tsx
const comboRef = useRef<IgrCombo>(null);

<IgrCombo ref={comboRef} data={destinations} valueKey="id" displayKey="name" groupKey="region">
    <header slot="header" className="list-header">
        <span>Destinations by region</span>
        <IgrButton variant="flat" onClick={() => comboRef.current?.select()}>Select all</IgrButton>
    </header>
</IgrCombo>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Pass the content to the `header` slot. The snippet adds a button that selects all options by setting the bound value to the `Id` values of all destinations:

```razor
<IgbCombo @bind-Value="SelectedDestinations" Data="Destinations" ValueKey="Id" DisplayKey="Name" GroupKey="Region">
    <header slot="header" class="list-header">
        <span>Destinations by region</span>
        <IgbButton Variant="ButtonVariant.Flat" @onclick="SelectAll">Select all</IgbButton>
    </header>
</IgbCombo>

@code {
    private string[] SelectedDestinations { get; set; } = [];

    private void SelectAll() => SelectedDestinations = Destinations.Select(d => d.Id).ToArray();
}
```

</PlatformBlock>

### Footer Template

The footer template renders content below the list of options, such as a summary of the selection or an action that applies to it. The Combo renders no footer by default.

<PlatformBlock for="Angular">

Use the `igxComboFooter` directive. The snippet shows the number of selected items from the <ApiLink type="Combo" member="selection" label="selection" /> property, and clears the selection through the <ApiLink type="Combo" member="deselectAllItems" label="deselectAllItems" /> method:

```html
<igx-combo #combo [data]="destinations" valueKey="id" displayKey="name" groupKey="region">
    <ng-template igxComboFooter>
        <div class="list-footer">
            <span>{{ combo.selection.length }} selected</span>
            <button igxButton="flat" (click)="combo.deselectAllItems()">Clear</button>
        </div>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

Pass the content to the `footer` slot. The snippet shows the number of selected items from the `igcChange` event, and clears the selection through the <ApiLink type="Combo" member="deselect" label="deselect" /> method called without an argument:

```html
<igc-combo id="destinations" value-key="id" display-key="name" group-key="region">
    <footer slot="footer" class="list-footer">
        <span id="selected-count">0 selected</span>
        <igc-button id="clear" variant="flat">Clear</igc-button>
    </footer>
</igc-combo>
```

```ts
const count = document.getElementById('selected-count');

combo.addEventListener('igcChange', (e) => {
    count.textContent = `${e.detail.newValue.length} selected`;
});

document.getElementById('clear').addEventListener('click', () => combo.deselect());
```

</PlatformBlock>

<PlatformBlock for="React">

Pass the content to the `footer` slot. The snippet keeps the selected values in the state, and clears the selection through the <ApiLink type="Combo" member="deselect" label="deselect" /> method called without an argument:

```tsx
const [selected, setSelected] = useState<string[]>([]);

<IgrCombo ref={comboRef} data={destinations} valueKey="id" displayKey="name" groupKey="region"
    onChange={(e) => setSelected(e.detail.newValue as string[])}>
    <footer slot="footer" className="list-footer">
        <span>{selected.length} selected</span>
        <IgrButton variant="flat" onClick={() => comboRef.current?.deselect()}>Clear</IgrButton>
    </footer>
</IgrCombo>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Pass the content to the `footer` slot. The snippet shows the number of selected items from the bound value, and clears the selection by setting it to an empty array:

```razor
<IgbCombo @bind-Value="SelectedDestinations" Data="Destinations" ValueKey="Id" DisplayKey="Name" GroupKey="Region">
    <footer slot="footer" class="list-footer">
        <span>@SelectedDestinations.Length selected</span>
        <IgbButton Variant="ButtonVariant.Flat" @onclick="() => SelectedDestinations = []">Clear</IgbButton>
    </footer>
</IgbCombo>
```

</PlatformBlock>

### Empty Template

The empty template renders in place of the list when the search text matches no option, or when the Combo has no data. By default, the Combo shows a message that the list is empty.

<PlatformBlock for="Angular">

Use the `igxComboEmpty` directive. The template has no context, so read the search text from the <ApiLink type="Combo" member="searchValue" label="searchValue" /> property of the Combo through a template reference. When <ApiLink type="Combo" member="allowCustomValues" label="allowCustomValues" /> is set, the add item stays below the empty content:

```html
<igx-combo #combo [data]="destinations" valueKey="id" displayKey="name" [allowCustomValues]="true">
    <ng-template igxComboEmpty>
        <span class="empty-list">No city matches "{{ combo.searchValue }}". Add it below, or try another spelling.</span>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

Pass the content to the `empty` slot:

```html
<igc-combo value-key="id" display-key="name" group-key="region">

```

</PlatformBlock>

### Add Template

The add template renders the add item that the Angular Combo shows below the empty list content when <ApiLink type="Combo" member="allowCustomValues" label="allowCustomValues" /> is set and the search text matches no option. By default, the add item is a button with an "Add item" label. Clicking the add item, or pressing <kbd>Enter</kbd> on it, emits the cancelable <ApiLink type="Combo" member="addition" label="addition" /> event, adds an item whose `valueKey` and `displayKey` fields hold the search text, and selects it.

Use the `igxComboAddItem` directive, and read the search text from the <ApiLink type="Combo" member="searchValue" label="searchValue" /> property through a template reference:

```html
<igx-combo #combo [data]="destinations" valueKey="id" displayKey="name" [allowCustomValues]="true">
    <ng-template igxComboAddItem>
        <button igxButton="outlined">Add "{{ combo.searchValue }}" as a destination</button>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

### Toggle Icon Template

The toggle icon template replaces the icon of the toggle button in the input field, which opens and closes the dropdown.

<PlatformBlock for="Angular">

Use the `igxComboToggleIcon` directive. The template also receives whether the dropdown is collapsed as its implicit value, for an icon that changes with the state. Register the icon first, as the [Icon](../../layouts/icon.mdx) topic shows:

```html
<igx-combo [data]="destinations" valueKey="id" displayKey="name">
    <ng-template igxComboToggleIcon>
        <igx-icon family="material" name="flight"></igx-icon>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

Pass the icon to the `toggle-icon` slot. The slot content shows both when the dropdown is closed and when it is open. Register the icon first, as the [Icon](../../layouts/icon.mdx) topic shows:

```ts
import { registerIconFromText } from 'igniteui-webcomponents';

registerIconFromText('flight', flightIcon, 'material');
```

```html
<igc-combo value-key="id" display-key="name">
    <igc-icon slot="toggle-icon" name="flight" collection="material"></igc-icon>
</igc-combo>
```

</PlatformBlock>

<PlatformBlock for="React">

Pass the icon to the `toggle-icon` slot. The slot content shows both when the dropdown is closed and when it is open. Register the icon first, as the [Icon](../../layouts/icon.mdx) topic shows:

```tsx
import { IgrCombo, IgrIcon, registerIconFromText } from 'igniteui-react';

registerIconFromText('flight', flightIcon, 'material');

<IgrCombo data={destinations} valueKey="id" displayKey="name">

</IgrCombo>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Pass the icon to the `toggle-icon` slot. The slot content shows both when the dropdown is closed and when it is open. Register the icon first, as the [Icon](../../layouts/icon.mdx) topic shows:

```razor
<IgbCombo T="string" Data="Destinations" ValueKey="Id" DisplayKey="Name">

</IgbCombo>

@code {

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender && this.IconRef != null)
        {

            await this.IconRef.RegisterIconFromTextAsync("flight", FlightIcon, "material");
        }
    }
}
```

</PlatformBlock>

### Templated Input

The input field of the Combo takes a label, content before and after its text, and a helper text below it, the way the <PlatformBlock for="Angular">[Input Group](../../input-group.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Input](../input.mdx)</PlatformBlock> does.

<PlatformBlock for="Angular">

Add the label with the `igxLabel` directive, the content before and after the text with the `igx-prefix` and `igx-suffix` elements, and the helper text with the `igx-hint` element. The suffix content renders before the clear and the toggle buttons:

```html
<igx-combo #combo [data]="destinations" valueKey="id" displayKey="name" placeholder="Pick one or more cities">
    <label igxLabel>Destinations</label>
    <igx-prefix><igx-icon>place</igx-icon></igx-prefix>
    <igx-suffix><igx-badge [value]="combo.selection.length"></igx-badge></igx-suffix>
    <igx-hint>{{ combo.selection.length }} of {{ destinations.length }} destinations selected</igx-hint>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

Set the `label` attribute, pass the content before and after the text to the `prefix` and `suffix` slots, and the helper text to the `helper-text` slot. The `suffix` slot renders after the clear icon and before the toggle icon:

```html
<igc-combo value-key="id" display-key="name" label="Destinations" placeholder="Pick one or more cities">
    <igc-icon slot="prefix" name="place" collection="material"></igc-icon>
    <igc-badge slot="suffix">2</igc-badge>
    <span slot="helper-text">2 of 19 destinations selected</span>
</igc-combo>
```

</PlatformBlock>

<PlatformBlock for="React">

Set the `label` property, pass the content before and after the text to the `prefix` and `suffix` slots, and the helper text to the `helper-text` slot. The `suffix` slot renders after the clear icon and before the toggle icon:

```tsx
<IgrCombo data={destinations} valueKey="id" displayKey="name" label="Destinations" placeholder="Pick one or more cities">
    <IgrIcon slot="prefix" name="place" collection="material" />
    <IgrBadge slot="suffix">{selected.length}</IgrBadge>
    <span slot="helper-text">{selected.length} of {destinations.length} destinations selected</span>
</IgrCombo>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Set the `Label` parameter, pass the content before and after the text to the `prefix` and `suffix` slots, and the helper text to the `helper-text` slot. The `suffix` slot renders after the clear icon and before the toggle icon:

```razor
<IgbCombo @bind-Value="SelectedDestinations" Data="Destinations" ValueKey="Id" DisplayKey="Name" Label="Destinations" Placeholder="Pick one or more cities">
```
