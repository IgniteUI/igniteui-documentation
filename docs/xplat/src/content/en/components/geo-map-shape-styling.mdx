# {Platform} Shape Styling on Geographic Shape Series

This topic explains how to apply custom styling to the <ApiLink type="GeographicShapeSeries" /> in the {Platform} <ApiLink type="GeographicMap" />.

## Required Imports

Shape styling requires that you import the following classes:

```json-snippet id="shapeStyling" source="/maps/geo-map/shape-styling" channel="bindingImports,handlersImports"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true,
            "series": [
                {
                    "type": "GeographicShapeSeries",
                    "name": "shapeSeries",
                    "isCustomShapeStyleAllowed": true,
                    "assigningShapeStyleRef": "ShapeFileStyling"
                }
            ]
        }
    },
    "onViewInit": [ "ShapeFileOnViewInit" ]
}
```


## Shape Random Styling

This code snippet creates instances of **ShapeRandomStyling** that will randomly assign fill colors to the countries of the world.

```json-snippet source="/maps/geo-map/shape-styling-random" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeRandomStyling"
    ]
}
```
