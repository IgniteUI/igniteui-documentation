# {Platform} Chart Markers

In {ProductName}, markers are visual elements that display the values of data points in the chart's plot area. Markers help your end-users immediately identify a data point's value even if the value falls between major or minor grid lines.

## {Platform} Chart Marker Size

You can control the exact device-independent pixel dimensions of data point markers by setting the `MarkerSize` property on any series that supports markers. This gives you precise control over how large markers appear on screen, regardless of the marker template or style being used.

By default, marker sizing is determined by the series marker template. When you set `MarkerSize` to a specific numeric value, all markers in that series render at that exact device-independent pixel width and height. Setting `MarkerSize` back to `NaN` restores the default template-driven sizing.

The `MarkerSize` property is available on all series types that derive from `MarkerSeries`, including `LineSeries`, `SplineSeries`, `AreaSeries`, `ColumnSeries`, `ScatterSeries`, `ScatterLineSeries`, `ScatterSplineSeries`, and polar/radial series types.

The following code examples show how to set `MarkerSize` to 30 device-independent pixels on a `ScatterLineSeries` in the `XamDataChart` control:

<PlatformBlock for="Blazor">

```razor
<IgbDataChart>
    <IgbScatterLineSeries
        MarkerSize="30"
        MarkerType="Circle"
        XMemberPath="X"
        YMemberPath="Y"
        XAxisName="xAxis"
        YAxisName="yAxis" />
</IgbDataChart>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx

    <IgrScatterLineSeries
        markerSize={30}
        markerType="Circle"
        xMemberPath="X"
        yMemberPath="Y"
        xAxisName="xAxis"
        yAxisName="yAxis" />
</IgrDataChart>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-data-chart>
    <igc-scatter-line-series
        marker-size="30"
        marker-type="Circle"
```

## {Platform} Chart Checkmark Marker Type

The {ProductName} charts include a `Checkmark` option in the `MarkerType` enum. This marker renders a V-shaped checkmark icon inside a circle on data points in your chart.

You can apply the `Checkmark` marker type to an individual series by setting its `MarkerType` property to `MarkerType.Checkmark`. To use the checkmark shape for all series in the chart simultaneously, set the chart's `MarkerAutomaticBehavior` property to `MarkerAutomaticBehavior.Checkmark`.

The `SeriesViewer.CheckmarkMarkerTemplate` property defines the marker template used for series with a checkmark marker type, and can be used to customize its appearance across the chart.

## {Platform} Chart Marker SVG Templates

Instead of writing a marker template in code, you can draw markers from an SVG by setting the `MarkerTemplateSVG` property of a series to the SVG's markup. Setting it sets the series' `MarkerTemplate` to a template that draws the SVG, so the same icon files you use elsewhere in your app can be used as markers. Setting `MarkerTemplateSVG` to null or an empty string removes the template it set; a template you set directly on `MarkerTemplate` replaces it.

<PlatformBlock for="Blazor">

```razor
<IgbDataChart>
    <IgbLineSeries
        ValueMemberPath="Value"
        XAxisName="xAxis"
        YAxisName="yAxis"
        MarkerTemplateSVG="@StarSVG" />
</IgbDataChart>

@code {
    private string StarSVG = "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24' width='20' height='20'>" +
        "<path fill='currentColor' stroke='currentColor' d='M12 2l3 7h7l-5.5 4.5L18.5 21 12 16.5 5.5 21l2-7.5L2 9h7z'/></svg>";
}
```

</PlatformBlock>

<PlatformBlock for="Angular">

```html
<igx-data-chart>
    <igx-line-series
        valueMemberPath="Value"
        [xAxis]="xAxis"
        [yAxis]="yAxis"
        [markerTemplateSVG]="starSVG">
    </igx-line-series>
</igx-data-chart>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const starSVG = "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24' width='20' height='20'>" +
    "<path fill='currentColor' stroke='currentColor' d='M12 2l3 7h7l-5.5 4.5L18.5 21 12 16.5 5.5 21l2-7.5L2 9h7z'/></svg>";

<IgrDataChart>
    <IgrLineSeries
        valueMemberPath="Value"

```

</PlatformBlock>

### Size and Position

Each marker is drawn centered on its data point at the SVG's own size: its `width` and `height` attributes, or its `viewBox` size if those aren't set, in device-independent pixels. Setting the series' `MarkerSize` draws every marker at that size instead. The SVG's `viewBox` is fitted into the marker's area as its `preserveAspectRatio` attribute says; by default it's scaled uniformly and centered.

### Colors

The SVG is painted the way a browser paints it, with one addition: `currentColor` stands for the colors of the item the marker belongs to.

- `fill="currentColor"` fills with the marker brush, the same brush a built-in marker is filled with, including per-item colors from `MarkerBrush`, palettes and highlighting.
- `stroke="currentColor"` strokes with the marker outline, at the marker thickness unless the SVG sets a `stroke-width`.
- Colors written in the SVG are used as they are. A fill that isn't specified is black, and a stroke that isn't specified isn't drawn, as in a browser. If the SVG sets the `color` property itself, `currentColor` uses that color instead.

To draw markers that follow the series' colors the way the built-in markers do, use `fill="currentColor"` for the marker's body and `stroke="currentColor"` for its outline. Outline icon sets that are drawn with `stroke="currentColor"`, such as Lucide and Feather icons, take the series' outline color without changes.

<DocsAside type="info">
Line, spline and area series draw hollow markers by default: their marker brush is white and their marker outline is the series color. Icons filled with `fill="currentColor"`, such as Heroicons solid or Bootstrap icons, are therefore white on those series unless you set `MarkerBrush`.
</DocsAside>

### Legend Badges

The `LegendItemBadgeTemplateSVG` property of a series draws its legend badge from an SVG in the same way. The SVG fills the badge's area, and `currentColor` takes the series' legend badge brush and outline. When a series draws markers from `MarkerTemplateSVG` and its legend badge shows the series' marker, the badge shows the SVG marker too.

### Supported SVG

Marker SVGs support paths, the basic shapes (`rect`, `circle`, `ellipse`, `line`, `polyline` and `polygon`), groups, nested `svg` elements, `use` and `symbol`, transforms, `style` elements with simple selectors, presentation attributes and `style` attributes, all CSS color formats, opacity, `fill-rule`, and stroke caps, joins and dashes. Gradients and patterns are drawn with their first stop color, and text, images, filters, masks and clip paths aren't drawn.
