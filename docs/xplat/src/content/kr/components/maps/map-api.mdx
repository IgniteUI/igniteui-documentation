# {Platform} Geographic Map API

{Platform} `GeographicMap`에는 다음 API 멤버가 있습니다:

- `Zoomable`
- `m:ZoomToGeographic`
- `WorldRect`
- `WindowRect`
- `WindowScale`
- `m:GetGeographicFromZoom`
- `m:GetGeographicPoint`
- `m:GetPixelPoint`

## {Platform} Geographic Symbol 시리즈 API

{Platform} `GeographicSymbolSeries`(Geographic Marker 시리즈)에는 다음 API 멤버가 있습니다:

- `LatitudeMemberPath`
- `LongitudeMemberPath`
- `GeographicSymbolSeries.MarkerType`
- `MarkerBrush`
- `MarkerOutline`

## {Platform} Geographic Bubble 시리즈 API

{Platform} `GeographicProportionalSymbolSeries`(Geographic Bubble 시리즈)에는 다음 API 멤버가 있습니다:

- `GeographicSymbolSeries.LatitudeMemberPath`
- `GeographicSymbolSeries.LongitudeMemberPath`
- `RadiusMemberPath`
- `RadiusScale`
- `FillScale`
- `FillMemberPath`
