## 시작하기

{Platform} 스위치를 사용하려면  <PlatformBlock for="Angular">[{ProductName} 시작하기](../general/getting-started.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[{ProductName} 시작하기](../general-getting-started.mdx)</PlatformBlock> 기본 프로젝트 설정 항목을 참조한 다음, 대상 플랫폼에 맞게 컴포넌트를 등록하십시오.

<ApiLink pkg="core" type="Switch" /> 컴포넌트의 핵심은 켜짐과 꺼짐 상태를 전환하는 것입니다. 기본 스타일은 Material Design 가이드라인의 선택 컨트롤 사양에 따라 적용됩니다.

<PlatformBlock for="Angular">

**igniteui-angular** 패키지를 사용하는 Angular의 경우, 패키지를 설치하십시오:

```cmd
npm install igniteui-angular
```

그다음 `IgxSwitchComponent`를 import하십시오:

```ts
import { IgxSwitchComponent } from 'igniteui-angular/switch';
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

**{PackageWebComponents}** 패키지를 사용하는 Web Components의 경우 패키지를 설치하십시오:

```cmd
npm install {PackageWebComponents}
```

그다음 <ApiLink pkg="core" type="Switch" />, 테마 CSS를 import하고 컴포넌트를 등록하십시오:

```ts
import { defineComponents, IgcSwitchComponent } from "igniteui-webcomponents";
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcSwitchComponent);
```

</PlatformBlock>

<PlatformBlock for="React">

**igniteui-react** 패키지를 사용하는 React의 경우 패키지를 설치하십시오:

```cmd
npm install igniteui-react
```

그다음 스위치 래퍼와 테마 CSS를 import하십시오:

```tsx
import { IgrSwitch } from 'igniteui-react';
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

</PlatformBlock>

<PlatformBlock for="Blazor">

{ProductName} 서비스를 등록합니다:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

스위치의 클라이언트 리소스 모듈인 <ApiLink pkg="core" type="SwitchModule" />를 등록하는 것은 **선택 사항**입니다. 컴포넌트는 처음 렌더링될 때 자체 리소스를 로드합니다. `builder.Services.AddIgniteUIBlazor(typeof(IgbSwitchModule))`에 나열하면 리소스를 미리 로드하거나, 클라이언트에서만 생성되는 요소를 지원하는 데 사용할 수 있습니다([컴포넌트 모듈](../general-getting-started.mdx#컴포넌트-모듈) 참조).

그다음 애플리케이션의 호스트 페이지(독립 실행형 Blazor WebAssembly 또는 Blazor Hybrid 앱에서는 **wwwroot/index.html**, Blazor Server 앱에서는 **Pages/_Host.cshtml**, Blazor Web App에서는 **Components/App.razor**)에 추가 CSS 파일을 연결하십시오:

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```

</PlatformBlock>

## 스타일링

{Platform} 스위치는 CSS 파트와 CSS 변수를 사용하여 트랙, 썸, 레이블의 스타일을 지정합니다.

<PlatformBlock for="Angular">

### Sass 테마 지정

스위치의 스타일 지정을 시작하려면 모든 테마 함수와 `tokens()` 믹스인이 내보내지는 `index` 파일을 import하십시오:

```scss
@use "igniteui-angular/theming" as *;
```

그다음 <ApiLink kind="sass" module="themes" type="function-switch-theme" label="switch-theme" code={true} />를 확장하는 새 테마를 만드십시오. `$thumb-off-color`와 `$thumb-on-color`를 제공하면 완전히 스타일이 지정된 스위치를 얻기에 충분합니다. 테마가 나머지 색상을 이 값들로부터 생성하기 때문입니다:

```scss
$custom-switch-theme: switch-theme(
    $thumb-off-color: #7cadd5,
    $thumb-on-color: #ecaa53,
);
```

마지막으로 사용자 지정 테마를 애플리케이션에 포함하십시오:

```scss
:host {
  @include tokens($custom-switch-theme);
}
```

## 접근성

{Platform} 스위치는 이진 상태를 노출하며, 레이블이나 ARIA 어트리뷰트를 통해 접근 가능한 이름을 지원합니다.

### 키보드 상호 작용

| 키 | 동작 |
| --- | --- |
| Tab / Shift+Tab | 스위치로 또는 스위치에서 포커스를 옮깁니다. |
| Space | 포커스된 스위치를 토글합니다. |

### 화면 읽기 프로그램 / ARIA

스위치는 이진 체크 상태를 가진 대화형 컨트롤을 렌더링합니다. `aria-label` 또는 `aria-labelledby`로 보이는 레이블 콘텐츠나 접근 가능한 이름을 제공하고, 레이블은 스위치가 제어하는 설정에 맞게 구체적으로 유지하십시오.

<PlatformBlock for="WebComponents, React, Blazor">

- 컨트롤은 체크 상태와 비활성화 상태를 보조 기술에 노출합니다.
- 체크 상태가 바뀌면 `igcChange` 이벤트가 발생합니다.

</PlatformBlock>

Infragistics는 [접근성 준수](../interactivity/accessibility-compliance.mdx) 항목에서 Section 508 및 WCAG 2.1 지침 영역에 대한 {ProductName} 접근성 지원을 문서화합니다.

## 문제 해결

스위치를 폼 필드, 대화형 명령, 설정 컨트롤로 다루기 전에 이 섹션에서 경계와 일반적인 결정을 확인하십시오.

### 스위치가 폼과 함께 제출되지 않는 이유는 무엇입니까?

스위치는 폼에 연결되지만, 폼이 제출될 때 값을 제공하려면 `name`와 `value`가 모두 필요합니다. 두 속성을 모두 설정하고, 대상 플랫폼이 지원하는 폼 연동 방식을 사용하십시오.

### 화면 읽기 프로그램이 스위치를 올바르게 읽지 않는 이유는 무엇입니까?

스위치에는 접근 가능한 이름이 필요합니다. 보이는 레이블 콘텐츠를 추가하거나 `aria-labelledby`로 외부 레이블을 참조하십시오. 보이는 텍스트를 사용할 수 없을 때는 `aria-label`를 사용하십시오.

### 알려진 제한 사항

{Platform} 스위치에는 다음과 같은 플랫폼에 독립적인 제한 사항이 있습니다:

- 스위치는 하나의 이진 설정을 나타냅니다. 사용자가 여러 선택지를 고르거나 나중에 폼에서 선택해야 할 때는 다른 컨트롤을 사용하십시오.
- 스위치에 레이블이나 ARIA 이름 지정 어트리뷰트가 없으면 접근 가능한 이름이 자동으로 제공되지 않습니다.

## FAQ

<Faq>
  <FaqItem question="스위치의 초기 켜짐 또는 꺼짐 상태는 어떻게 설정합니까?">
    켜짐 상태에는 <ApiLink pkg="core" type="Switch" member="checked" label="checked" /> 속성을 `true`로, 꺼짐 상태에는 `false`로 설정하십시오. 이 속성은 React, Web Components, Blazor 문법에서 불리언 값을 사용합니다.
  </FaqItem>
  <FaqItem question="스위치 레이블의 위치는 어떻게 정합니까?">
    레이블 텍스트를 스위치 안에 넣고, <ApiLink pkg="core" type="Switch" member="labelPosition" label="labelPosition" /> 속성을 `before` 또는 `after`로 설정하십시오. 기본 레이블 위치는 `after`입니다.
  </FaqItem>
  <FaqItem question="스위치 값을 폼과 함께 제출하려면 어떻게 합니까?">
    <ApiLink pkg="core" type="Switch" member="name" label="name" />와 <ApiLink pkg="core" type="Switch" member="value" label="value" /> 속성을 모두 설정하십시오. Blazor에서는 표준 HTML `form` 대신 `EditForm` 컴포넌트를 사용하십시오.
  </FaqItem>
  <FaqItem question="스위치를 필수 또는 유효하지 않음으로 만들려면 어떻게 합니까?">
    설정을 반드시 선택해야 할 때는 <ApiLink pkg="core" type="Switch" member="required" label="required" /> 속성을 설정하고, 컨트롤이 유효하지 않은 상태일 때는 <ApiLink pkg="core" type="Switch" member="invalid" label="invalid" />를 설정하십시오. 사용자가 설정을 바꿀 수 없어야 할 때는 <ApiLink pkg="core" type="Switch" member="disabled" label="disabled" />를 사용하십시오.
  </FaqItem>
