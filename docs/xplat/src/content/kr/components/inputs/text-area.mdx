# {Platform} 텍스트 영역 개요

{ProductName} 텍스트 영역은 여러 줄 일반 텍스트 편집 컨트롤이며, 예를 들어 리뷰나 피드백 폼의 댓글처럼 사용자가 상당한 양의 자유 형식 텍스트를 입력하도록 할 때 유용합니다.

## 종속성

<PlatformBlock for="Blazor">



{ProductName} 서비스를 등록합니다:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

텍스트 영역의 클라이언트 리소스 모듈인 <ApiLink pkg="core" type="TextareaModule" />를 등록하는 것은 **선택 사항**입니다. 컴포넌트는 처음 렌더링될 때 자체 리소스를 로드합니다. `builder.Services.AddIgniteUIBlazor(typeof(IgbTextareaModule))`에 나열하면 리소스를 미리 로드하거나, 클라이언트에서만 생성되는 요소를 지원하는 데 사용할 수 있습니다([컴포넌트 모듈](../general-getting-started.mdx#컴포넌트-모듈) 참조).

<ApiLink pkg="core" type="Textarea" /> 컴포넌트에 스타일을 적용하려면 추가 CSS 파일도 연결해야 합니다. 다음 내용을 애플리케이션의 호스트 페이지에 넣어야 합니다(독립 실행형 Blazor WebAssembly 또는 Blazor Hybrid 앱에서는 **wwwroot/index.html**, Blazor Server 앱에서는 **Pages/_Host.cshtml**, Blazor Web App에서는 **Components/App.razor**):

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

시작하려면 typescript 파일에서 <ApiLink pkg="core" type="Textarea" />를 import하고, 다음과 같이 [defineComponents()]({environment:wcApiUrl}/index.html#defineComponents) 함수를 호출하여 컴포넌트를 등록해야 합니다:

```ts
import { defineComponents, IgcTextareaComponent } from 'igniteui-webcomponents';
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcTextareaComponent);
```

{ProductName}에 대한 전체 소개는 [**시작하기**](../general-getting-started.mdx) 항목을 읽어 보십시오.

</PlatformBlock>

## 접두사, 접미사, 도움말 텍스트

`prefix` 및 `suffix` 슬롯을 사용하면 텍스트 영역의 주 콘텐츠 앞뒤에 서로 다른 콘텐츠를 추가할 수 있습니다. `helper-text` 슬롯은 텍스트 영역 아래에 배치되는 힌트를 제공합니다. 콘텐츠를 슬롯에 넣을 때는 간단한 텍스트, 기호, 이모지에는 `<span>` 요소를, 아이콘에는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다. 다음 샘플에서는 아이콘 접두사와 힌트로서의 도움말 텍스트가 있는 새 텍스트 영역 필드를 만들겠습니다:

<PlatformBlock for="WebComponents">

```html
<igc-textarea label="Your feedback">
    <igc-icon name="feedback" slot="prefix"></igc-icon>
    <span slot="helper-text">Give us a short description of what you liked/disliked</span>
</igc-textarea>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrTextarea label="Your feedback">
    <IgrIcon name="feedback" slot="prefix"></IgrIcon>
    <span slot="helper-text">Give us a short description of what you liked/disliked</span>
</IgrTextarea>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbTextarea Label="Your feedback">
    <IgbIcon IconName="feedback" Collection="material" slot="prefix"></IgbIcon>
    <span slot="helper-text">Give us a short description of what you liked/disliked</span>
</IgbTextarea>
```

</PlatformBlock>

## 텍스트 영역 크기 조정

<ApiLink pkg="core" type="Textarea" />에는 세 가지 크기 조정 옵션이 있습니다. `none`로 설정하면 텍스트 영역의 크기가 조정되지 않고, 넘치는 텍스트는 스크롤바로 보여 줍니다. `vertical`(기본 옵션)로 설정하면 사용자가 텍스트 영역을 세로로 크기 조정할 수 있습니다. `auto`로 설정하면 텍스트 영역이 사용자 입력 전체를 한꺼번에 보여 줍니다. 넘치는 텍스트는 새 줄로 줄바꿈되고, 텍스트 영역은 자동으로 늘어납니다.

## 스타일링

<ApiLink pkg="core" type="Textarea" /> 컴포넌트는 거의 모든 내부 요소에 대한 CSS 파트를 노출합니다. 아래 표는 노출된 모든 CSS 파트를 나열합니다:

|이름|설명|
|--|--|
| `container` | 모든 주요 입력 요소를 담는 기본 래퍼입니다. |
| `input` | 네이티브 input 요소입니다. |
| `label` | 네이티브 label 요소입니다. |
| `prefix` | 접두사 래퍼입니다. |
| `suffix` | 접미사 래퍼입니다. |
| `helper-text` | 도움말 텍스트 래퍼입니다. |

```css
igc-textarea::part(input) {
  background-color: var(--ig-info-100);
  border-color: var(--ig-primary-400);
}

igc-textarea::part(label) {
  color: var(--ig-gray-800);
}

igc-textarea::part(prefix),
igc-textarea::part(suffix) {
  color: var(--ig-primary-500-contrast);
  border-color: var(--ig-primary-500);
  background-color: var(--ig-primary-500);
}
```
