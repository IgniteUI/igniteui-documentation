## 종속성

{ProductName} 서비스를 등록합니다:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

입력 컴포넌트의 클라이언트 리소스 모듈인 <ApiLink pkg="core" type="InputModule" />를 등록하는 것은 **선택 사항**입니다. 컴포넌트는 처음 렌더링될 때 자체 리소스를 로드합니다. `builder.Services.AddIgniteUIBlazor(typeof(IgbInputModule))`에 나열하면 리소스를 미리 로드하거나, 클라이언트에서만 생성되는 요소를 지원하는 데 사용할 수 있습니다([컴포넌트 모듈](../general-getting-started.mdx#컴포넌트-모듈) 참조).

</PlatformBlock>

<PlatformBlock for="Blazor">


<ApiLink pkg="core" type="Input" /> 컴포넌트에 스타일을 적용하려면 추가 CSS 파일도 연결해야 합니다. 다음 내용을 애플리케이션의 호스트 페이지에 넣어야 합니다(독립 실행형 Blazor WebAssembly 또는 Blazor Hybrid 앱에서는 **wwwroot/index.html**, Blazor Server 앱에서는 **Pages/_Host.cshtml**, Blazor Web App에서는 **Components/App.razor**):

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

시작하려면 typescript 파일에서 <ApiLink pkg="core" type="Input" />를 import하고, 다음과 같이 [defineComponents()]({environment:wcApiUrl}/index.html#defineComponents) 함수를 호출하여 컴포넌트를 등록해야 합니다:

```ts
import { defineComponents, IgcInputComponent } from 'igniteui-webcomponents';
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcInputComponent);
```

{ProductName}에 대한 전체 소개는 [**시작하기**](../general-getting-started.mdx) 항목을 읽어 보십시오.

</PlatformBlock>

## 접두사 & 접미사

`prefix` 및 `suffix` 슬롯을 사용하면 <ApiLink pkg="core" type="Input" />의 기본 콘텐츠 앞뒤에 서로 다른 콘텐츠를 추가할 수 있습니다. 간단한 텍스트, 기호, 이모지를 추가할 때는 `<span>` 요소를, `prefix` 및 `suffix` 슬롯에 아이콘을 추가할 때는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다. 다음 샘플에서는 텍스트 접두사와 아이콘 접미사가 있는 새 입력 필드를 만들겠습니다:

## 입력 크기 조정

`--ig-size` CSS 변수를 사용하여 사용자가 <ApiLink pkg="core" type="Input" />의 크기를 바꿀 수 있게 할 수 있습니다. 이를 위해 모든 크기 값을 표시하는 라디오 버튼을 추가하겠습니다. 이렇게 하면 하나가 선택될 때마다 입력의 크기가 바뀝니다:

<Sample src="/inputs/input/size" height={320} alt="{Platform} 입력 크기 조정 예제" />

위 샘플에서는 다음 어트리뷰트의 사용법을 보여 드렸습니다:
- `required` - 입력을 필수로 표시하는 데 사용됩니다
- `disabled` - 입력을 비활성화하는 데 사용됩니다
- `readonly` - 입력을 읽기 전용으로 표시하는 데 사용됩니다

어트리뷰트의 전체 목록은 <ApiLink pkg="core" type="Input" /> API에서 확인할 수 있습니다.

</PlatformBlock>

## 스타일링

<ApiLink pkg="core" type="Input" /> 컴포넌트는 거의 모든 내부 요소에 대한 CSS 파트를 노출합니다. 아래 표는 노출된 모든 CSS 파트를 나열합니다:

|이름|설명|
|--|--|
| `container` | 모든 주요 입력 요소를 담는 기본 래퍼입니다. |
| `input` | 네이티브 input 요소입니다. |
| `label` | 네이티브 label 요소입니다. |
| `prefix` | 접두사 래퍼입니다. |
| `suffix` | 접미사 래퍼입니다. |
| `helper-text` | 도움말 텍스트 래퍼입니다. |

```scss
igc-input::part(input) {
  background-color: var(--ig-primary-100);
  border-color: var(--ig-secondary-500);
  box-shadow: none;
}

igc-input::part(label) {
  color: var(--ig-gray-700);
}

igc-input::part(prefix),
igc-input::part(suffix) {
  color: var(--ig-primary-600-contrast);
  background-color: var(--ig-primary-600);
  border-color: var(--ig-secondary-600);
}
```
