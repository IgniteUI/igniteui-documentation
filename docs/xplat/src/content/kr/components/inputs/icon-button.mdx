# {Platform} 아이콘 버튼 개요

{ProductName} 아이콘 버튼 컴포넌트를 사용하면 개발자가 등록된 아이콘을 애플리케이션의 버튼으로 사용할 수 있습니다. [아이콘](../layouts/icon.mdx) 컴포넌트의 모든 기능을 포함하며, [버튼](./button.mdx) 컴포넌트의 기능도 추가로 제공합니다.

## 사용법


<PlatformBlock for="WebComponents">


먼저 다음 명령을 실행하여 {ProductName}를 설치해야 합니다:

```cmd
npm install {PackageWebComponents}
```

<ApiLink pkg="core" type="IconButton" />를 사용하기 전에 다음과 같이 등록해야 합니다:

```ts
import { defineComponents, IgcIconButtonComponent } from "igniteui-webcomponents";
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcIconButtonComponent);
```

{ProductName}에 대한 전체 소개는 [**시작하기**](../general-getting-started.mdx) 항목을 읽어 보십시오.


</PlatformBlock>



<PlatformBlock for="React">


먼저 다음 명령을 실행하여 해당 {ProductName} npm 패키지를 설치해야 합니다:

```cmd
npm install igniteui-react
```

그다음 다음과 같이 <ApiLink pkg="core" type="IconButton" />, 필요한 CSS를 import하고 모듈을 등록해야 합니다:

```tsx
import { IgrIconButton } from 'igniteui-react';
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

</PlatformBlock>



<PlatformBlock for="Blazor">


{ProductName} 서비스를 등록합니다:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

<ApiLink pkg="core" type="IconButton" />의 클라이언트 리소스 모듈인 <ApiLink pkg="core" type="IconButtonModule" /> 등록은 **선택 사항**입니다. 컴포넌트는 처음 렌더링될 때 리소스를 로드합니다. `builder.Services.AddIgniteUIBlazor(typeof(IgbIconButtonModule))`에 나열하면 리소스를 미리 로드하거나 클라이언트에서만 생성되는 요소를 지원할 수 있습니다([컴포넌트 모듈](../general-getting-started.mdx#컴포넌트-모듈) 참조).

<ApiLink pkg="core" type="IconButton" /> 컴포넌트에 스타일을 적용하려면 추가 CSS 파일도 연결해야 합니다. 다음 내용을 애플리케이션의 호스트 페이지에 넣어야 합니다(독립 실행형 Blazor WebAssembly 또는 Blazor Hybrid 앱에서는 **wwwroot/index.html**, Blazor Server 앱에서는 **Pages/_Host.cshtml**, Blazor Web App에서는 **Components/App.razor**):

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```


</PlatformBlock>

<ApiLink pkg="core" type="IconButton" />를 사용하기 시작하는 가장 간단한 방법은 다음과 같습니다:


</PlatformBlock>

<PlatformBlock for="React">

</PlatformBlock>

## 예제

### 변형

일반 버튼 컴포넌트와 마찬가지로 아이콘 버튼도 여러 변형을 지원합니다 - `flat`(기본값), `contained`, `outlined`. 아이콘 버튼 유형을 바꾸려면 아이콘 버튼의 <ApiLink pkg="core" type="IconButton" member="variant" label="variant" /> 어트리뷰트를 설정하십시오.

<Sample src="/inputs/icon-button/variant" height={100} alt="{Platform} 아이콘 버튼 예제" />



<PlatformBlock for="React">

```tsx
<IgrIconButton name="search" variant="contained"></IgrIconButton>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-icon-button name="search" variant="contained"></igc-icon-button>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton IconName="search" Variant="@IconButtonVariant.Contained" Collection="material" />
```

</PlatformBlock>

### 크기

`--ig-size` CSS 변수를 지원되는 세 가지 크기 중 하나로 설정하여 버튼 크기를 바꿀 수 있습니다: `--ig-size-small`, `--ig-size-medium`, `--ig-size-large`(기본값).

<Sample src="/inputs/icon-button/size" height={100} alt="{Platform} 아이콘 버튼 예제" />



<PlatformBlock for="React">

```tsx
<IgrIconButton className="size-medium" name="thumb-up"></IgrIconButton>
```

</PlatformBlock>
<PlatformBlock for="React, Blazor">
```css
.size-medium {
    --ig-size: var(--ig-size-medium);
}
```
</PlatformBlock>

<PlatformBlock for="WebComponents">
```css
igc-icon-button {
    --ig-size: var(--ig-size-medium);
}
```
</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton class="size-medium" IconName="thumb-up" Collection="material" />
```

</PlatformBlock>

### 타입

<ApiLink pkg="core" type="IconButton" member="href" label="href" /> 어트리뷰트가 설정되면 아이콘 버튼은 내부 구조를 `<button>`에서 `<a>` 유형의 요소로 바꿉니다. 이 경우 아이콘 버튼은 일반 링크처럼 생각할 수 있습니다. <ApiLink pkg="core" type="IconButton" member="href" label="href" /> 어트리뷰트를 설정하면 아이콘 버튼의 <ApiLink pkg="core" type="IconButton" member="rel" label="rel" />, <ApiLink pkg="core" type="IconButton" member="target" label="target" />, <ApiLink pkg="core" type="IconButton" member="download" label="download" /> 어트리뷰트도 설정할 수 있습니다.

<PlatformBlock for="WebComponents">

```html
<igc-icon-button
  name="thumb-up"
  collection="material"
  href="https://duckduckgo.com"
  target="_blank">
</igc-icon-button>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrIconButton name="thumb-up" collection="material" href="https://duckduckgo.com" target="_blank">
</IgrIconButton>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton IconName="thumb-up" Collection="material" Href="https://duckduckgo.com" Target="_blank" />
```

</PlatformBlock>

### 좌우 반전

일부 아이콘은 RTL(오른쪽에서 왼쪽) 모드에서 사용할 때 조금 다르게 보여야 합니다. 이 때문에 설정하면 아이콘 버튼을 가로로 뒤집는 `mirrored` 어트리뷰트를 제공합니다.

<PlatformBlock for="React">

```tsx
<IgrIconButton name="thumb-up" mirrored={true}></IgrIconButton>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-icon-button name="thumb-up" mirrored></igc-icon-button>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton IconName="thumb-up" Collection="material" Mirrored="true" />
```

</PlatformBlock>

## 스타일링

<ApiLink pkg="core" type="IconButton" /> 컴포넌트는 감싸는 요소(`<button>` 또는 `<a>`)와 감싸진 `<igc-icon>` 요소의 스타일을 지정할 수 있는 두 CSS 파트 - `base`와 `icon`를 노출합니다.

```css
igc-icon-button[variant="contained"]:not([disabled])::part(base) {
  padding: 12px;
  background-color: var(--ig-success-500);
}

igc-icon-button::part(icon) {
  --size: 22px;
  color: var(--ig-success-500-contrast);
}
```
