# {Platform} 드롭다운 목록 컴포넌트 - 개요

기능이 풍부한 {Platform} 드롭다운 목록은 필터링, 접근성, 미리 선택된 값, 유연한 데이터 바인딩, 그룹화, UI 사용자 지정 등을 기본으로 제공합니다. 이 컴포넌트가 실제로 하는 일은 HTML select 태그를 효과적이고 쉽게 대체하여, 사용자가 미리 정의된 여러 옵션 중에서 편집할 수 없는 값을 빠르게 고를 수 있게 하는 것입니다.

Ignite UI for {Platform} 드롭다운 컴포넌트는 미리 정의된 값의 토글 목록을 표시하며, 사용자가 클릭 한 번으로 단일 옵션 항목을 쉽게 선택할 수 있게 합니다. {Platform} 드롭다운 메뉴로 동작하도록 빠르게 구성할 수 있으며, 데이터를 그룹화하여 더 유용한 시각 정보를 전달하는 데에도 사용할 수 있습니다. 또한 그룹화를 사용하면 평면 데이터와 계층형 데이터를 모두 사용할 수 있습니다.

이 컴포넌트에는 프로젝트에 필요한 모든 기능과 사용자 지정 옵션이 있습니다. 스타일 사용자 지정, {Platform} 드롭다운 배치 옵션, 템플릿, 머리글, 바닥글, 본문, 목록 등에 표시되는 내용과 방식을 바꾸는 기능이 포함됩니다.

### 대상

{Platform} 드롭다운 목록은 대상을 기준으로 상대적으로 배치됩니다. `target` 슬롯은 클릭할 때 `open` 속성을 토글하는 내장 컴포넌트를 제공할 수 있게 합니다. 경우에 따라서는 외부 대상을 사용하거나 다른 이벤트로 드롭다운을 여는 것을 토글하고 싶을 수 있습니다. 이는 대상을 매개변수로 전달할 수 있는 <ApiLink pkg="core" type="Dropdown" member="show" label="Show" />, <ApiLink pkg="core" type="Dropdown" member="hide" label="Hide" />, <ApiLink pkg="core" type="Dropdown" member="toggle" label="Toggle" /> 메서드로 달성할 수 있습니다. 기본적으로 드롭다운 목록은 `absolute` CSS 위치를 사용합니다. 대상 요소가 고정 컨테이너 안에 있지만 드롭다운은 그렇지 않을 때는 {Platform} 드롭다운의 <ApiLink kind="interface" type="OverlaySettings" member="positionStrategy" label="PositionStrategy" />을 `fixed`로 설정해야 합니다. 드롭다운 목록은 콘텐츠를 기준으로 자동으로 크기가 정해집니다. 목록이 대상과 같은 너비를 가지게 하려면 <ApiLink pkg="core" type="Dropdown" member="sameWidth" label="SameWidth" /> 속성을 `true`로 설정해야 합니다.

### 위치

{Platform} 드롭다운의 선호 배치는 <ApiLink pkg="core" type="Dropdown" member="placement" label="Placement" /> 속성으로 설정할 수 있습니다. 드롭다운의 기본 배치는 `bottom-start`입니다. <ApiLink pkg="core" type="Dropdown" member="flip" label="Flip" /> 속성은 지정된 배치로 드롭다운을 표시할 공간이 부족할 때 배치를 뒤집을지 여부를 결정합니다. {Platform} 드롭다운 목록과 대상 사이의 거리는 <ApiLink pkg="core" type="Dropdown" member="distance" label="Distance" /> 속성으로 지정할 수 있습니다.

<Sample src="/inputs/dropdown/position" height={520} alt="{Platform} 드롭다운 위치 예제" />

### 선택

<ApiLink pkg="core" type="Dropdown" />는 사용자가 항목을 선택하면 `Change` 이벤트를 발생시킵니다. 드롭다운의 <ApiLink pkg="core" type="Dropdown" member="select" label="Select" /> 메서드를 사용하면 인덱스 또는 값으로 항목을 선택할 수 있습니다.

### 항목

<ApiLink pkg="core" type="DropdownItem" />는 드롭다운 목록에서 선택할 수 있는 항목을 나타냅니다. <ApiLink pkg="core" type="DropdownItem" member="selected" label="Selected" /> 속성을 설정하여 선택된 항목을 미리 정의할 수 있습니다. 또한 <ApiLink pkg="core" type="DropdownItem" member="disabled" label="Disabled" /> 속성을 사용하여 항목을 비활성화하면 선택할 수 없게 할 수 있습니다.

<ApiLink pkg="core" type="DropdownItem" />는 항목의 콘텐츠를 지정할 수 있는 기본 슬롯을 가집니다. `prefix` 및 `suffix` 슬롯을 사용하면 콘텐츠 앞이나 뒤에 렌더링될 사용자 지정 콘텐츠도 제공할 수 있습니다.
간단한 텍스트, 기호 또는 이모지를 추가할 때는 `<span>` 요소를 사용하고, `prefix` 및 `suffix` 슬롯에 아이콘을 추가할 때는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다.

<PlatformBlock for="WebComponents">

```html
<igc-dropdown>
  <igc-button slot="target">Countries</igc-button>
  <igc-dropdown-item>
    <igc-icon slot="prefix" name="place"></igc-icon>
    Germany
    <span slot="suffix">DE</span>
  </igc-dropdown-item>
  ...
</igc-dropdown>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrDropdown>
  <IgrButton slot="target"><span>Countries</span></IgrButton>
  <IgrDropdownItem>
    <IgrIcon slot="prefix" name="place"></IgrIcon>
    <span>Germany</span>
    <span slot="suffix">DE</span>
  </IgrDropdownItem>
</IgrDropdown>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDropdown>
  <IgbButton slot="target">Countries</IgbButton>
  <IgbDropdownItem>
    <IgbIcon slot="prefix" IconName="place" Collection="material"></IgbIcon>

  </IgbDropdownItem>
</IgbDropdown>
```

</PlatformBlock>

<ApiLink pkg="core" type="DropdownItem" member="value" label="Value" /> 속성을 사용하면 항목에 사용자 지정 값을 제공할 수 있습니다. <ApiLink pkg="core" type="DropdownItem" member="value" label="Value" />가 설정되지 않으면 항목의 텍스트 콘텐츠로 해석됩니다.

### 스크롤 전략

<ApiLink kind="interface" type="OverlaySettings" member="scrollStrategy" label="ScrollStrategy" /> 속성은 대상 요소의 컨테이너가 스크롤되는 동안 컴포넌트의 동작을 결정합니다. 기본값은 `scroll`이며, 드롭다운이 대상과 함께 스크롤된다는 뜻입니다. 이 속성을 `block`로 설정하면 드롭다운이 열려 있을 때 스크롤을 막습니다. 또한 이 속성을 `close`로 설정하면 스크롤 시 드롭다운이 자동으로 닫힙니다.

### 열어 두기

기본적으로 드롭다운은 사용자가 바깥을 클릭하거나 항목을 선택하면 자동으로 닫힙니다. <ApiLink pkg="core" type="Dropdown" member="keepOpenOnOutsideClick" label="KeepOpenOnOutsideClick" /> 및 <ApiLink pkg="core" type="Dropdown" member="keepOpenOnSelect" label="KeepOpenOnSelect" /> 속성을 사용하면 이 동작을 막을 수 있습니다.

## 스타일링

노출된 CSS 파트를 사용하면 드롭다운과 그 항목의 모양을 바꿀 수 있습니다. <ApiLink pkg="core" type="Dropdown" />는 `base`와 `list` 파트를, <ApiLink pkg="core" type="DropdownItem" />는 `prefix`, `content`, `suffix` 파트를, <ApiLink pkg="core" type="DropdownGroup" />는 `label` 파트를 노출합니다.

```css
igc-dropdown::part(list) {
  height: 220px;
}

igc-dropdown-item[selected] {
  background: var(--ig-success-300);
}

igc-dropdown-group::part(label) {
  display: flex;
  justify-content: center;
}
```
