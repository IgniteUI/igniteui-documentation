# {Platform} 색상 편집기 개요 <Badge variant="preview" />
{ProductName} 색상 편집기는 가벼운 색상 선택 컴포넌트입니다. 색상 편집기는 브러시 아이콘을 클릭하면 팝업으로 열 수 있습니다. 아래쪽에서 원하는 색상의 rgba 값과 hex 값을 모두 얻을 수 있습니다. 이 값들은 세 개의 슬라이더를 수정하면 업데이트됩니다. 가운데 상자는 채도와 명도를 조정하도록 설계되었으며, 옆의 두 슬라이더는 rgb 값과 밝기 값을 조정합니다. Rgb는 (1-255) 사이의 값을 가지며, 밝기는 (0-1) 사이의 값을 가집니다.

## 사용법

`ColorEditor`를 사용하기 시작하는 가장 간단한 방법은 다음과 같습니다:


```json-snippet source="/inputs/color-editor/overview" code="allCode"
{
    "type": "ColorEditor",
    "name": "colorEditor"
}
```

## 이벤트에 바인딩하기

색상 편집기 컴포넌트는 다음 이벤트를 발생시킵니다:

- valueChanged
- valueChanging

```json-snippet source="/inputs/color-editor/overview" code="allCode"
{
    "type": "ColorEditor",
    "name": "colorEditor",
    "valueChangedRef": "ColorEditorValueChanged"
}
```

핸들러에는 편집기와 `ColorEditorPanelSelectedValueChangedEventArgs`가 전달되며, 그 `newValue`에는 방금 선택한 색상이 들어 있습니다:

```json-snippet source="/inputs/color-editor/overview" channel="handlersImports...handler"
{
    "type": "ColorEditor",
    "name": "colorEditor",
    "valueChangedRef": "ColorEditorValueChanged",
    "$valueChangedRef": "+doc:handler"
}
```
