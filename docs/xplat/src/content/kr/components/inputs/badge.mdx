# 배지 컴포넌트

{Platform} 배지 컴포넌트는 플랫폼별 {ProductName} 패키지에서 제공되며, 시각적 알림이 필요할 때 애플리케이션의 아바타, 탐색 메뉴 또는 다른 컴포넌트와 함께 사용됩니다. 배지는 보통 정보, 성공, 경고, 오류를 전달하기 위해 미리 정의된 스타일로 설계됩니다.

```text
<igc-badge>
└── ::part(base)
  └── default slot content
</igc-badge>
```

## 사용법

{Platform} 배지를 사용하여 다른 컴포넌트와 함께 짧은 상태, 카테고리, 개수 또는 알림 표시기를 표시하십시오.

<PlatformBlock for="Angular">

데모 샘플이 어떻게 만들어졌는지 살펴봅시다. 아바타 위에 있는 간단한 성공 배지입니다. 이를 만들려면 `IgxAvatarModule`을 `IgxBadgeModule`와 함께 import하십시오:

```typescript
import { IgxBadgeModule } from 'igniteui-angular/badge';
import { IgxAvatarModule } from 'igniteui-angular/avatar';
```

두 모듈을 컴포넌트의 `imports` 컬렉션에 추가하거나, 독립 실행형 컴포넌트를 import하십시오. 그다음 컴포넌트를 템플릿에 추가하십시오:

```html
<div class="wrapper">
  <igx-avatar icon="person" shape="circle" size="small"></igx-avatar>
  <igx-badge icon="check" type="success"></igx-badge>
</div>
```

상대 위치 지정된 래퍼를 사용하여 배지를 아바타 위에 배치하십시오:

```scss
.wrapper {
  position: relative;
  margin-top: 15px;
}

igx-badge {
  position: absolute;
  bottom: 0;
  left: 28px;
}
```

### 타입

배지는 숫자나 아이콘과 같은 다양한 유형의 콘텐츠를 담을 수 있습니다.

`[value]` 입력을 사용하여 배지 안에 텍스트나 숫자 개수를 표시하십시오:

```html
<igx-badge [value]="model.value"></igx-badge>
```

`[icon]` 입력을 사용하여 배지 안에 아이콘을 표시하십시오:

```html
<igx-badge icon="check" type="success"></igx-badge>
```

`[icon]`와 `[value]`가 모두 설정되면, 배지는 둘을 동시에 표시합니다:

```html
<igx-badge icon="check" value="5" type="success"></igx-badge>
```

콘텐츠를 직접 프로젝션할 수도 있습니다. 아이콘과 텍스트를 모두 프로젝션할 때는 올바른 여백을 유지하기 위해 텍스트를 감싸십시오:

```html
<igx-badge>
  <igx-icon>bluetooth</igx-icon>
  <span>Bluetooth</span>
</igx-badge>
```

#### Icon
Angular 배지는 Material Icons 외에도 Material Icons Extended와 다른 사용자 지정 아이콘 세트를 지원합니다. `IgxIconService`로 사용자 지정 아이콘을 등록한 다음, 그 이름과 아이콘 세트를 지정하십시오:

```ts
this._iconService.addSvgIconFromText(heartMonitor.name, heartMonitor.value, 'imx-icons');
```

```html
<igx-badge icon="heart-monitor" iconSet="imx-icons"></igx-badge>
```

#### 점

Ignite UI for Angular 배지는 <ApiLink pkg="core" type="Badge" member="dot" label="dot" /> 속성을 설정하여 알림을 위한 최소한의 점 표시기로도 렌더링할 수 있습니다. 점 배지는 콘텐츠를 지원하지 않지만 외곽선을 가질 수 있으며, 사용 가능한 점 유형 중 어떤 것이든 사용할 수 있습니다(예: `primary`, `success`, `info`).

콘텐츠 없이 최소한의 알림 표시기를 렌더링하려면 <ApiLink pkg="core" type="Badge" member="dot" label="dot" /> 속성을 설정하십시오:

```html
<igx-badge dot></igx-badge>
```

### 크기

`--size` CSS 변수로 배지 크기를 제어하십시오. `16px`보다 작은 텍스트 배지의 경우 글꼴 크기와 줄 높이도 함께 조정하십시오:

```scss
igx-badge {
  --size: 12px;

  font-size: calc(var(--size) / 2);
  line-height: normal;
}
```

<Sample src="/data-display/badge-size" showThemePicker height={316} position="center" alt="Angular 배지 크기 예제" />

### Shape

배지 모양은 <ApiLink pkg="core" type="Badge" member="shape" label="shape" /> 속성으로 `rounded`(기본값) 또는 `square`로 설정할 수 있습니다.

```html
<igx-badge icon="check" type="success" shape="square"></igx-badge>
```

<Sample src="/data-display/badge-shape" showThemePicker height={212} position="center" alt="Angular 배지 모양 예제" />

배지 모양이 `square`인 경우, `--border-radius` CSS 변수로 사용자 지정 테두리 반경을 설정하여 더 사용자 지정할 수 있습니다.

## 접근성

{Platform} 배지는 짧은 개수, 상태 또는 알림을 전달하는 상호 작용이 없는 상태 시각 요소입니다.

### 키보드 상호 작용

배지는 포커스를 받지 않으며, 키보드 입력을 처리하지 않고, 컴포넌트 상호 작용 이벤트를 노출하지 않습니다.

| 키 | 동작 |
| -- | -- |
| n/a | 배지는 키보드로 상호 작용할 수 없습니다. |

### 화면 읽기 프로그램 / ARIA

배지 호스트는 콘텐츠를 상태 정보로 노출하기 위해 `role="status"`을 사용합니다.

<PlatformBlock for="WebComponents, React, Blazor">

- 컴포넌트는 배지와 그 현재 `variant`를 식별하기 위해 `aria-roledescription`를 설정합니다.
- `dot` 배지를 포함하여 텍스트가 없는 배지가 보조 기술에 달리 전달되지 않는 상태를 전달할 때는 `aria-label`을 추가하십시오.
- 배지 콘텐츠 또는 접근성 레이블은 장식하는 항목에 맞게 구체적으로 유지하십시오. 예를 들어 `3`만이 아니라 `3 unread messages`처럼 작성하십시오.

</PlatformBlock>

<PlatformBlock for="Angular">

- 컴포넌트는 `role="status"`와 `aria-label="badge"`로 초기화됩니다.
- Angular는 배지 유형과 그 아이콘 또는 값으로부터 `aria-roledescription`를 도출합니다. `badge`가 의미 있는 접근성 이름이 아닐 때는 `label` 입력을 설정하십시오.
- 텍스트가 없는 배지나 `dot` 배지의 상태가 보조 기술에 달리 전달되지 않는 경우에는 의미 있는 `label`을 추가하십시오.

</PlatformBlock>

### 접근성 준수

Infragistics는 [접근성 준수](../interactivity/accessibility-compliance.mdx) 항목에서 Section 508 및 WCAG 2.1 지침 영역에 대한 {ProductName} 접근성 지원을 문서화합니다.

| 기준 | 컴포넌트가 준수하는 방식 |
| -- | -- |
| [4.1.2 이름, 역할, 값](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value.html) | 배지는 의미 체계상의 `status` 역할을 노출합니다. xplat 구현은 현재 변형을 기준으로 한 역할 설명도 노출하며, Angular는 유형과 콘텐츠를 기준으로 한 접근성 레이블과 역할 설명을 노출합니다. |

사용자의 책임:

- 배지에 의미 있는 텍스트가 없을 때, 특히 `dot` 배지의 경우 상태를 설명하는 접근 가능한 이름을 제공하십시오.
- 배지 색상을 상태를 나타내는 유일한 표시로 사용하지 마십시오. 텍스트, 아이콘 또는 다른 접근 가능한 신호와 함께 사용하십시오.
- 테마 스타일을 재정의할 때 배지의 전경과 배경 사이에 충분한 대비를 유지하십시오.

## 문제 해결

배지를 상호 작용 컨트롤로 보거나 상태를 나타내는 유일한 표시로 보기 전에, 이 섹션에서 경계와 일반적인 결정을 확인하십시오.

### 사용자 지정 배경색을 지정해도 배지 색이 바뀌지 않는 이유는 무엇입니까?

선택된 `variant`가 `--background-color` CSS 변수보다 우선합니다. 사용자 지정 배경색을 사용하려면, 자체 배경색을 적용하는 변형을 설정하지 마십시오.

### 점 배지에 콘텐츠가 표시되지 않는 이유는 무엇입니까?

`dot` 속성은 배지를 최소한의 표시기로 렌더링하며 콘텐츠를 지원하지 않습니다. 텍스트나 다른 인라인 콘텐츠를 표시해야 할 때는 일반 배지를 사용하십시오.

### 알려진 제한 사항

{Platform} 배지에는 다음과 같은 플랫폼에 독립적인 제한 사항이 있습니다.

- 점 배지는 표시기일 뿐이며, 텍스트나 아이콘을 표시할 수 없습니다.
- 배지의 스타일 지정과 변형/유형 이름은 Angular와 지원되는 다른 프레임워크 사이에서 다릅니다. 프레임워크 간에 속성을 복사하지 말고, 이 페이지의 플랫폼별 예제와 API 링크를 사용하십시오.
- 배지는 시각적 상태 표시기이며, 자체적인 키보드 상호 작용을 제공하지 않습니다.

## FAQ

<Faq>

  <FaqItem question="배지에 아이콘과 텍스트를 모두 표시할 수 있습니까?">
    예. 배지의 콘텐츠 영역에는 텍스트를, 시각적 표시기에는 지원되는 아이콘 콘텐츠를 사용하십시오. 간결한 상태나 카테고리 레이블로 유지되도록 조합을 짧게 유지하십시오.
  </FaqItem>

  <FaqItem question="콘텐츠 없이 알림 점을 표시하려면 어떻게 합니까?">
    플랫폼별 `dot` 속성 또는 어트리뷰트를 설정하십시오. 점 배지는 의도적으로 텍스트나 다른 콘텐츠 없이 렌더링됩니다.
  </FaqItem>

  <FaqItem question="텍스트 배지 대신 점 배지를 사용해야 하는 경우는 언제입니까?">
    상태가 존재 여부만으로 전달될 때는 점 배지를 사용하십시오. 사용자가 색상이나 위치에 의존하지 않고도 상태, 카테고리 또는 개수를 이해해야 할 때는 텍스트 배지를 사용하십시오.
  </FaqItem>

  <FaqItem question="배지에는 어떤 패키지를 설치해야 합니까?">
    Angular에는 `igniteui-angular`, React에는 `igniteui-react`, Web Components에는 `igniteui-webcomponents`, Blazor에는 `IgniteUI.Blazor`를 사용하십시오. 관련 Ignite UI 패키지는 같은 릴리스 버전으로 유지하십시오.
  </FaqItem>

</Faq>
