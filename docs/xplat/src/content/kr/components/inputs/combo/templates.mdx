# 콤보 템플릿

{ProductName} 콤보 템플릿은 콤보 영역의 기본 콘텐츠, 즉 항목, 그룹 머리글, 목록의 머리글과 바닥글, 빈 목록, 토글 및 지우기 아이콘, 입력 필드를 대체합니다.

<PlatformBlock for="Angular">

Angular 콤보는 각 템플릿을 템플릿 디렉티브 중 하나가 있는 `ng-template` 요소로 받아, `igx-combo` 요소 안에 배치합니다. 디렉티브는 [콤보](./overview.mdx#시작하기) 항목에 나온 대로 `IGX_COMBO_DIRECTIVES` 토큰과 함께 제공되며, 입력 필드를 템플릿화하는 `igxLabel`, `igx-prefix`, `igx-suffix`, `igx-hint` 요소도 함께 제공됩니다.

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

{Platform} 콤보는 항목과 그룹 머리글을 <ApiLink type="Combo" member="itemTemplate" label="itemTemplate" />와 <ApiLink type="Combo" member="groupHeaderTemplate" label="groupHeaderTemplate" /> 속성을 통해 렌더링하며, 다른 영역의 콘텐츠는 슬롯을 통해 받습니다. 간단한 텍스트나 기호에는 `<span>`를, 아이콘에는 [Icon](../../layouts/icon.mdx)을 사용하십시오. `header` 및 `footer` 슬롯은 `<header>` 및 `<footer>` 요소도 받습니다.

</PlatformBlock>

<PlatformBlock for="Blazor">

Blazor 콤보는 항목과 그룹 머리글을 <ApiLink pkg="core" type="Combo<T>" member="ItemTemplateScript" label="ItemTemplateScript" /> 및 <ApiLink pkg="core" type="Combo<T>" member="GroupHeaderTemplateScript" label="GroupHeaderTemplateScript" /> 매개변수가 이름으로 참조하는 JavaScript 템플릿 함수를 통해 렌더링하며, 다른 영역의 콘텐츠는 슬롯을 통해 받습니다. 간단한 텍스트나 기호에는 `<span>`를, 아이콘에는 [Icon](../../layouts/icon.mdx)을 사용하십시오. `header` 및 `footer` 슬롯은 `<header>` 및 `<footer>` 요소도 받습니다.

</PlatformBlock>

## 유형

{Platform} 콤보는 렌더링하는 영역마다 템플릿이 하나씩 있습니다. <PlatformBlock for="Angular">각 템플릿은 디렉티브를 통해 참조하고, 항목과 콤보의 키는 템플릿 컨텍스트에서 읽으십시오.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">다음 절은 각 템플릿을 받는 속성이나 슬롯을 보여 줍니다.</PlatformBlock>

스니펫은 `id`, `name`, `country`, `countryCode`, `region`, UTC `offset`를 가진 목적지에 콤보를 바인딩합니다. `id`는 `valueKey`, `name`는 `displayKey`, `region`는 `groupKey`로 사용됩니다.<PlatformBlock for="Blazor"> Blazor 스니펫은 같은 필드를 파스칼 케이스로 사용합니다: `Id`, `Name`, `Country`, `CountryCode`, `Region`, `Offset`.</PlatformBlock>

### 항목 템플릿

항목 템플릿은 목록의 각 옵션 콘텐츠를 렌더링합니다. 기본적으로 옵션은 `displayKey` 값을 보여 주며, 옵션의 체크박스는 템플릿 콘텐츠 앞에 남습니다.

<PlatformBlock for="React,WebComponents,Blazor">

항목 템플릿과 그룹 머리글 템플릿은 콤보의 shadow DOM 안에 렌더링되므로, 페이지의 스타일이 닿지 않습니다. 그 컨테이너의 스타일은 `item` 및 `group-header` CSS 파트로 지정하고, 콘텐츠의 배치는 인라인 스타일로 하십시오. 콤보는 템플릿의 각 루트 요소를 블록으로 배치하므로, 템플릿의 콘텐츠는 하나의 요소로 감싸십시오.

</PlatformBlock>

<PlatformBlock for="Angular">

`igxComboItem` 디렉티브를 사용하십시오. 템플릿은 항목을 암시적 값으로 받으며, 콤보의 `valueKey`, `displayKey`, `data`도 함께 받습니다:

```html
<igx-combo [data]="destinations" valueKey="id" displayKey="name" groupKey="region">
    <ng-template igxComboItem let-destination let-key="displayKey">
        <span class="destination">
            <img class="flag" [src]="'https://dl.infragistics.com/x/img/flags/' + destination.countryCode + '.png'" alt="" />
            {{ destination[key] }} — {{ destination.country }} · {{ destination.id }} · {{ destination.offset }}
        </span>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

<ApiLink type="Combo" member="itemTemplate" label="itemTemplate" /> 속성을 항목을 받아 `lit-html` 템플릿을 반환하는 함수로 설정하십시오:

```ts
import { IgcComboComponent, ComboItemTemplate } from 'igniteui-webcomponents';
import { html } from 'lit-html';

const itemTemplate: ComboItemTemplate<Destination> = ({ item }) => html`
    <span>
        <img src="https://dl.infragistics.com/x/img/flags/${item.countryCode}.png" alt="" style="width: 1.25rem;" />
        ${item.name} — ${item.country} · ${item.id} · ${item.offset}
    </span>
`;

const combo = document.querySelector('igc-combo') as IgcComboComponent<Destination>;
combo.itemTemplate = itemTemplate;
```

</PlatformBlock>

<PlatformBlock for="React">

항목을 받아 그 콘텐츠를 반환하는 함수를 <ApiLink type="Combo" member="itemTemplate" label="itemTemplate" /> 속성에 전달하십시오:

```tsx
import { IgrCombo, ComboTemplateProps } from 'igniteui-react';

const renderItem = ({ item }: ComboTemplateProps<Destination>) => (
    <span>
        <img src={`https://dl.infragistics.com/x/img/flags/${item.countryCode}.png`} alt="" style={{ width: '1.25rem' }} />
        {item.name} — {item.country} · {item.id} · {item.offset}
    </span>
);

<IgrCombo data={destinations} valueKey="id" displayKey="name" groupKey="region" itemTemplate={renderItem} />
```

</PlatformBlock>

<PlatformBlock for="Blazor">

`wwwroot` 아래의 JavaScript 파일에, 예를 들어 `templates.js`에 템플릿을 정의하십시오. 템플릿은 항목을 받아 `igTemplating`의 `html` 태그로 만든 템플릿을 반환하는 함수이며, `igRegisterScript`는 콤보가 참조하는 이름으로 이를 등록합니다:

```js
const html = window.igTemplating.html;

const itemTemplate = ({ item }) => html`
    <span>
        <img src="https://dl.infragistics.com/x/img/flags/${item.CountryCode}.png" alt="" style="width: 1.25rem;" />
        ${item.Name} — ${item.Country} · ${item.Id} · ${item.Offset}
    </span>
`;

igRegisterScript("ComboItemTemplate", itemTemplate, false);
```

파일을 `wwwroot/index.html`에 포함하십시오. 이 스크립트는 페이지가 로드되는 동안 `igRegisterScript`를 호출하므로, `app.bundle.js`를 Blazor 스크립트보다 먼저 포함하십시오:

```html
<body>
    <script src="_content/IgniteUI.Blazor/app.bundle.js"></script>
    <script src="_framework/blazor.webassembly.js"></script>
    <script src="templates.js"></script>
</body>
```

그다음 <ApiLink pkg="core" type="Combo<T>" member="ItemTemplateScript" label="ItemTemplateScript" /> 매개변수를 템플릿의 이름으로 설정하십시오:

```razor
<IgbCombo T="string" Data="Destinations" ValueKey="Id" DisplayKey="Name" GroupKey="Region" ItemTemplateScript="ComboItemTemplate" />
```

</PlatformBlock>

### 머리글 항목 템플릿

머리글 항목 템플릿은 콤보에 `groupKey`가 있을 때 각 그룹의 머리글을 렌더링합니다. 기본적으로 그룹 머리글은 그룹 값을 보여 줍니다. 템플릿은 데이터 항목이 아니라 머리글 레코드를 받습니다. 그 `groupKey` 필드에 그룹 값이 들어 있으므로, 그룹 옵션의 개수는 스니펫의 `citiesIn` 메서드가 하는 것처럼 콤보의 데이터에서 가져옵니다.

<PlatformBlock for="Angular">

`igxComboHeaderItem` 디렉티브를 사용하십시오. 템플릿은 머리글 레코드를 암시적 값으로 받으며, 콤보의 `groupKey`, `valueKey`, `displayKey`, `data`도 함께 받습니다:

```html
<igx-combo [data]="destinations" valueKey="id" displayKey="name" groupKey="region">
    <ng-template igxComboHeaderItem let-header let-key="groupKey">
        <span class="region">
            <strong>{{ header[key] }}</strong>
            <span class="region-count">{{ citiesIn(header[key]) }} cities</span>
        </span>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

<ApiLink type="Combo" member="groupHeaderTemplate" label="groupHeaderTemplate" /> 속성을 설정하십시오:

```ts
const groupHeaderTemplate: ComboItemTemplate<Destination> = ({ item }) => html`
    <span style="display: flex; gap: 0.5rem; width: 100%;">
        <strong>${item.region}</strong>
        <span style="margin-inline-start: auto;">${citiesIn(item.region)} cities</span>
    </span>
`;

combo.groupHeaderTemplate = groupHeaderTemplate;
```

</PlatformBlock>

<PlatformBlock for="React">

함수를 <ApiLink type="Combo" member="groupHeaderTemplate" label="groupHeaderTemplate" /> 속성에 전달하십시오:

```tsx
const renderGroupHeader = ({ item }: ComboTemplateProps<Destination>) => (
    <span style={{ display: 'flex', gap: '0.5rem', width: '100%' }}>
        <strong>{item.region}</strong>
        <span style={{ marginInlineStart: 'auto' }}>{citiesIn(item.region)} cities</span>
    </span>
);

<IgrCombo data={destinations} valueKey="id" displayKey="name" groupKey="region" groupHeaderTemplate={renderGroupHeader} />
```

</PlatformBlock>

<PlatformBlock for="Blazor">

`templates.js`에 템플릿을 등록하고, <ApiLink pkg="core" type="Combo<T>" member="GroupHeaderTemplateScript" label="GroupHeaderTemplateScript" /> 매개변수를 그 이름으로 설정하십시오:

```js
const groupHeaderTemplate = ({ item }) => html`
    <span style="display: flex; gap: 0.5rem; width: 100%;">
        <strong>${item.Region}</strong>
        <span style="margin-inline-start: auto;">${citiesIn(item.Region)} cities</span>
    </span>
`;

igRegisterScript("ComboGroupHeaderTemplate", groupHeaderTemplate, false);
```

```razor
<IgbCombo T="string" Data="Destinations" ValueKey="Id" DisplayKey="Name" GroupKey="Region" GroupHeaderTemplateScript="ComboGroupHeaderTemplate" />
```

</PlatformBlock>

### 헤더 템플릿

머리글 템플릿은 검색 입력과 옵션 목록 사이에 콘텐츠를 렌더링합니다. 예를 들어 목록의 제목이나 목록에 적용되는 동작이 있습니다. 콤보는 기본적으로 머리글을 렌더링하지 않습니다.

<PlatformBlock for="Angular">

`igxComboHeader` 디렉티브를 사용하십시오. 스니펫은 <ApiLink type="Combo" member="selectAllItems" label="selectAllItems" /> 메서드를 통해 검색 입력이 보여 주는 옵션을 선택하는 버튼을 추가합니다:

```html
<igx-combo #combo [data]="destinations" valueKey="id" displayKey="name" groupKey="region">
    <ng-template igxComboHeader>
        <div class="list-header">
            <span>Destinations by region</span>
            <button igxButton="flat" (click)="combo.selectAllItems()">Select all</button>
        </div>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

콘텐츠를 `header` 슬롯에 전달하십시오. 스니펫은 인수 없이 호출된 <ApiLink type="Combo" member="select" label="select" /> 메서드를 통해 모든 옵션을 선택하는 버튼을 추가합니다. [Button](../button.mdx) 항목에 나온 대로 Button 컴포넌트를 등록하십시오:

```html
<igc-combo id="destinations" value-key="id" display-key="name" group-key="region">
    <header slot="header" class="list-header">
        <span>Destinations by region</span>
        <igc-button id="select-all" variant="flat">Select all</igc-button>
    </header>
</igc-combo>
```

```ts
const combo = document.getElementById('destinations') as IgcComboComponent<Destination>;

document.getElementById('select-all').addEventListener('click', () => combo.select());
```

</PlatformBlock>

<PlatformBlock for="React">

콘텐츠를 `header` 슬롯에 전달하십시오. 스니펫은 인수 없이 호출된 <ApiLink type="Combo" member="select" label="select" /> 메서드를 통해 모든 옵션을 선택하는 버튼을 추가합니다:

```tsx
const comboRef = useRef<IgrCombo>(null);

<IgrCombo ref={comboRef} data={destinations} valueKey="id" displayKey="name" groupKey="region">
    <header slot="header" className="list-header">
        <span>Destinations by region</span>
        <IgrButton variant="flat" onClick={() => comboRef.current?.select()}>Select all</IgrButton>
    </header>
</IgrCombo>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

콘텐츠를 `header` 슬롯에 전달하십시오. 스니펫은 바인딩된 값을 모든 목적지의 `Id` 값으로 설정하여 모든 옵션을 선택하는 버튼을 추가합니다:

```razor
<IgbCombo @bind-Value="SelectedDestinations" Data="Destinations" ValueKey="Id" DisplayKey="Name" GroupKey="Region">
    <header slot="header" class="list-header">
        <span>Destinations by region</span>
        <IgbButton Variant="ButtonVariant.Flat" @onclick="SelectAll">Select all</IgbButton>
    </header>
</IgbCombo>

@code {
    private string[] SelectedDestinations { get; set; } = [];

    private void SelectAll() => SelectedDestinations = Destinations.Select(d => d.Id).ToArray();
}
```

</PlatformBlock>

### 바닥글 템플릿

바닥글 템플릿은 옵션 목록 아래에 콘텐츠를 렌더링합니다. 예를 들어 선택 요약이나 그 선택에 적용되는 동작이 있습니다. 콤보는 기본적으로 바닥글을 렌더링하지 않습니다.

<PlatformBlock for="Angular">

`igxComboFooter` 디렉티브를 사용하십시오. 스니펫은 <ApiLink type="Combo" member="selection" label="selection" /> 속성에서 선택된 항목의 개수를 보여 주고, <ApiLink type="Combo" member="deselectAllItems" label="deselectAllItems" /> 메서드를 통해 선택을 지웁니다:

```html
<igx-combo #combo [data]="destinations" valueKey="id" displayKey="name" groupKey="region">
    <ng-template igxComboFooter>
        <div class="list-footer">
            <span>{{ combo.selection.length }} selected</span>
            <button igxButton="flat" (click)="combo.deselectAllItems()">Clear</button>
        </div>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

콘텐츠를 `footer` 슬롯에 전달하십시오. 스니펫은 `igcChange` 이벤트에서 선택된 항목의 개수를 보여 주고, 인수 없이 호출된 <ApiLink type="Combo" member="deselect" label="deselect" /> 메서드를 통해 선택을 지웁니다:

```html
<igc-combo id="destinations" value-key="id" display-key="name" group-key="region">
    <footer slot="footer" class="list-footer">
        <span id="selected-count">0 selected</span>
        <igc-button id="clear" variant="flat">Clear</igc-button>
    </footer>
</igc-combo>
```

```ts
const count = document.getElementById('selected-count');

combo.addEventListener('igcChange', (e) => {
    count.textContent = `${e.detail.newValue.length} selected`;
});

document.getElementById('clear').addEventListener('click', () => combo.deselect());
```

</PlatformBlock>

<PlatformBlock for="React">

콘텐츠를 `footer` 슬롯에 전달하십시오. 스니펫은 선택된 값을 상태에 유지하고, 인수 없이 호출된 <ApiLink type="Combo" member="deselect" label="deselect" /> 메서드를 통해 선택을 지웁니다:

```tsx
const [selected, setSelected] = useState<string[]>([]);

<IgrCombo ref={comboRef} data={destinations} valueKey="id" displayKey="name" groupKey="region"
    onChange={(e) => setSelected(e.detail.newValue as string[])}>
    <footer slot="footer" className="list-footer">
        <span>{selected.length} selected</span>
        <IgrButton variant="flat" onClick={() => comboRef.current?.deselect()}>Clear</IgrButton>
    </footer>
</IgrCombo>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

콘텐츠를 `footer` 슬롯에 전달하십시오. 스니펫은 바인딩된 값에서 선택된 항목의 개수를 보여 주고, 빈 배열로 설정하여 선택을 지웁니다:

```razor
<IgbCombo @bind-Value="SelectedDestinations" Data="Destinations" ValueKey="Id" DisplayKey="Name" GroupKey="Region">
    <footer slot="footer" class="list-footer">
        <span>@SelectedDestinations.Length selected</span>
        <IgbButton Variant="ButtonVariant.Flat" @onclick="() => SelectedDestinations = []">Clear</IgbButton>
    </footer>
</IgbCombo>
```

</PlatformBlock>

### 빈 템플릿

빈 템플릿은 검색 텍스트와 일치하는 옵션이 없거나 콤보에 데이터가 없을 때 목록 대신 렌더링됩니다. 기본적으로 콤보는 목록이 비어 있다는 메시지를 보여 줍니다.

<PlatformBlock for="Angular">

`igxComboEmpty` 디렉티브를 사용하십시오. 템플릿에는 컨텍스트가 없으므로, 템플릿 참조를 통해 콤보의 <ApiLink type="Combo" member="searchValue" label="searchValue" /> 속성에서 검색 텍스트를 읽으십시오. <ApiLink type="Combo" member="allowCustomValues" label="allowCustomValues" />가 설정되면 항목 추가가 빈 콘텐츠 아래에 남습니다:

```html
<igx-combo #combo [data]="destinations" valueKey="id" displayKey="name" [allowCustomValues]="true">
    <ng-template igxComboEmpty>
        <span class="empty-list">No city matches "{{ combo.searchValue }}". Add it below, or try another spelling.</span>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

콘텐츠를 `empty` 슬롯에 전달하십시오:

```html
<igc-combo value-key="id" display-key="name" group-key="region">
    <span slot="empty" class="empty-list">No city matches your search. Try another spelling.</span>
</igc-combo>
```

</PlatformBlock>

<PlatformBlock for="React">

콘텐츠를 `empty` 슬롯에 전달하십시오:

```tsx
<IgrCombo data={destinations} valueKey="id" displayKey="name" groupKey="region">
    <span slot="empty" className="empty-list">No city matches your search. Try another spelling.</span>
</IgrCombo>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

콘텐츠를 `empty` 슬롯에 전달하십시오:

```razor
<IgbCombo T="string" Data="Destinations" ValueKey="Id" DisplayKey="Name" GroupKey="Region">
    <span slot="empty" class="empty-list">No city matches your search. Try another spelling.</span>
```

### 추가 템플릿

추가 템플릿은 <ApiLink type="Combo" member="allowCustomValues" label="allowCustomValues" />가 설정되고 검색 텍스트와 일치하는 옵션이 없을 때 Angular 콤보가 빈 목록 콘텐츠 아래에 표시하는 항목 추가를 렌더링합니다. 기본적으로 항목 추가는 "Add item" 레이블이 있는 버튼입니다. 항목 추가를 클릭하거나 그 위에서 <kbd>Enter</kbd>를 누르면, 취소 가능한 <ApiLink type="Combo" member="addition" label="addition" /> 이벤트가 발생하고, `valueKey`와 `displayKey` 필드에 검색 텍스트를 담은 항목이 추가되며, 그 항목이 선택됩니다.

`igxComboAddItem` 디렉티브를 사용하고, 템플릿 참조를 통해 <ApiLink type="Combo" member="searchValue" label="searchValue" /> 속성에서 검색 텍스트를 읽으십시오:

```html
<igx-combo #combo [data]="destinations" valueKey="id" displayKey="name" [allowCustomValues]="true">
    <ng-template igxComboAddItem>
        <button igxButton="outlined">Add "{{ combo.searchValue }}" as a destination</button>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

### 토글 아이콘 템플릿

토글 아이콘 템플릿은 입력 필드의 토글 버튼 아이콘을 대체합니다. 이 버튼은 드롭다운을 열고 닫습니다.

<PlatformBlock for="Angular">

`igxComboToggleIcon` 디렉티브를 사용하십시오. 템플릿은 드롭다운이 접혀 있는지 여부도 암시적 값으로 받으므로, 상태에 따라 바뀌는 아이콘을 만들 수 있습니다. [아이콘](../../layouts/icon.mdx) 항목에 나온 대로 아이콘을 먼저 등록하십시오:

```html
<igx-combo [data]="destinations" valueKey="id" displayKey="name">
    <ng-template igxComboToggleIcon>
        <igx-icon family="material" name="flight"></igx-icon>
    </ng-template>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

아이콘을 `toggle-icon` 슬롯에 전달하십시오. 슬롯 콘텐츠는 드롭다운이 닫혀 있을 때와 열려 있을 때 모두 표시됩니다. [아이콘](../../layouts/icon.mdx) 항목에 나온 대로 아이콘을 먼저 등록하십시오:

```ts
import { registerIconFromText } from 'igniteui-webcomponents';

registerIconFromText('flight', flightIcon, 'material');
```

```html
<igc-combo value-key="id" display-key="name">
    <igc-icon slot="toggle-icon" name="flight" collection="material"></igc-icon>
</igc-combo>
```

</PlatformBlock>

<PlatformBlock for="React">

아이콘을 `toggle-icon` 슬롯에 전달하십시오. 슬롯 콘텐츠는 드롭다운이 닫혀 있을 때와 열려 있을 때 모두 표시됩니다. [아이콘](../../layouts/icon.mdx) 항목에 나온 대로 아이콘을 먼저 등록하십시오:

</PlatformBlock>

<PlatformBlock for="Blazor">

아이콘을 `toggle-icon` 슬롯에 전달하십시오. 슬롯 콘텐츠는 드롭다운이 닫혀 있을 때와 열려 있을 때 모두 표시됩니다. [아이콘](../../layouts/icon.mdx) 항목에 나온 대로 아이콘을 먼저 등록하십시오:

```razor

    <IgbIcon slot="toggle-icon" @ref="IconRef" IconName="flight" Collection="material" />
</IgbCombo>

@code {

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender && this.IconRef != null)

            await this.IconRef.EnsureReady();

}
```

</PlatformBlock>

### 템플릿화된 입력

콤보의 입력 필드는 레이블, 텍스트 앞뒤의 콘텐츠, 그 아래의 도움말 텍스트를 받을 수 있습니다. 그 방식은 <PlatformBlock for="Angular">[Input Group](../../input-group.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[입력](../input.mdx)</PlatformBlock> 과 같습니다.

<PlatformBlock for="Angular">

`igxLabel` 디렉티브로 레이블을, `igx-prefix`와 `igx-suffix` 요소로 텍스트 앞뒤의 콘텐츠를, `igx-hint` 요소로 도움말 텍스트를 추가하십시오. 접미사 콘텐츠는 지우기 버튼과 토글 버튼 앞에 렌더링됩니다:

```html
<igx-combo #combo [data]="destinations" valueKey="id" displayKey="name" placeholder="Pick one or more cities">
    <label igxLabel>Destinations</label>
    <igx-prefix><igx-icon>place</igx-icon></igx-prefix>
    <igx-suffix><igx-badge [value]="combo.selection.length"></igx-badge></igx-suffix>
    <igx-hint>{{ combo.selection.length }} of {{ destinations.length }} destinations selected</igx-hint>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

`label` 어트리뷰트를 설정하고, 텍스트 앞뒤의 콘텐츠를 `prefix`와 `suffix` 슬롯에, 도움말 텍스트를 `helper-text` 슬롯에 전달하십시오. `suffix` 슬롯은 지우기 아이콘 뒤, 토글 아이콘 앞에 렌더링됩니다:

```html
<igc-combo value-key="id" display-key="name" label="Destinations" placeholder="Pick one or more cities">
    <igc-icon slot="prefix" name="place" collection="material"></igc-icon>
    <igc-badge slot="suffix">2</igc-badge>
    <span slot="helper-text">2 of 19 destinations selected</span>
</igc-combo>
```

</PlatformBlock>

<PlatformBlock for="React">

`label` 속성을 설정하고, 텍스트 앞뒤의 콘텐츠를 `prefix`와 `suffix` 슬롯에, 도움말 텍스트를 `helper-text` 슬롯에 전달하십시오. `suffix` 슬롯은 지우기 아이콘 뒤, 토글 아이콘 앞에 렌더링됩니다:

```tsx
<IgrCombo data={destinations} valueKey="id" displayKey="name" label="Destinations" placeholder="Pick one or more cities">
    <IgrIcon slot="prefix" name="place" collection="material" />
    <IgrBadge slot="suffix">{selected.length}</IgrBadge>
    <span slot="helper-text">{selected.length} of {destinations.length} destinations selected</span>
</IgrCombo>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

`Label` 매개변수를 설정하고, 텍스트 앞뒤의 콘텐츠를 `prefix`와 `suffix` 슬롯에, 도움말 텍스트를 `helper-text` 슬롯에 전달하십시오. `suffix` 슬롯은 지우기 아이콘 뒤, 토글 아이콘 앞에 렌더링됩니다:

```razor
<IgbCombo @bind-Value="SelectedDestinations" Data="Destinations" ValueKey="Id" DisplayKey="Name" Label="Destinations" Placeholder="Pick one or more cities">
    <IgbIcon slot="prefix" IconName="place" Collection="material" />
    <IgbBadge slot="suffix">@SelectedDestinations.Length</IgbBadge>
    <span slot="helper-text">@SelectedDestinations.Length of @Destinations.Count destinations selected</span>
</IgbCombo>
```

</PlatformBlock>
