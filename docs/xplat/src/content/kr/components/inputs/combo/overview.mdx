# Combo

{ProductName} 콤보는 입력 필드와 검색 가능한 드롭다운 목록을 결합한 컴포넌트이며, 사용자가 입력으로 옵션을 필터링하고 하나 이상의 항목을 선택할 수 있게 합니다.

<PlatformBlock for="Angular">

Angular 콤보는 `igx-combo` 컴포넌트입니다. 옵션을 가상화된 드롭다운 목록에 표시하며, 필터링, 그룹화, 사용자 지정 값, Angular 폼과의 양방향 바인딩을 지원합니다.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

콤보는 옵션을 가상화된 목록에 표시하므로, 목록은 수천 개의 옵션을 담을 수 있습니다. 콤보는 대소문자 구분 필터링, 그룹화, 복합 데이터 바인딩을 지원합니다.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

`igc-combo` 요소는 입력 필드와 드롭다운 목록을 팝오버에 렌더링하고, 그 아래에 도움말 텍스트를 렌더링합니다:

```text
igc-combo
└─ #shadow-root
   ├─ igc-popover
   │  ├─ igc-input#target[slot="anchor"]            // the input field, exported as the "input" part
   │  │  ├─ slot[name="prefix"]
   │  │  ├─ span[part="clear-icon"]                  // shown when the Combo has a value
   │  │  ├─ slot[name="suffix"]
   │  │  └─ span[part="toggle-icon"]
   │  └─ div[part="list-wrapper"]                    // the dropdown
   │     ├─ div[part="filter-input"]
   │     │  └─ igc-input[part="search-input"]        // hidden with disable-filtering or single-select
   │     ├─ div[part="header"]
   │     │  └─ slot[name="header"]
   │     ├─ igc-virtual-scroll#dropdown[part="list"][role="listbox"]
   │     │  ├─ igc-combo-header[part="group-header"] // one for each group
   │     │  └─ igc-combo-item[part="item"]           // one for each option
   │     ├─ div[part="empty"]                        // shown when the list has no options
   │     │  └─ slot[name="empty"]
   │     └─ div[part="footer"]
   │        └─ slot[name="footer"]
   └─ igc-validator[part="helper-text"]              // the helper text and the validation messages
```

</PlatformBlock>

<PlatformBlock for="Angular">

`igx-combo` 요소는 입력 필드를 입력 그룹에 렌더링하고, 드롭다운 목록을 오버레이에 렌더링합니다:

```text
igx-combo
├─ igx-input-group
│  ├─ [igxLabel]
│  ├─ igx-prefix
│  ├─ input[igxInput][role="combobox"]          // read-only, shows the selected items
│  ├─ igx-suffix.igx-combo__clear-button        // shown when the Combo has a value
│  ├─ igx-suffix.igx-combo__toggle-button
│  └─ igx-hint
└─ igx-combo-drop-down                          // the dropdown, shown in an overlay
   └─ div.igx-drop-down__list-scroll[role="listbox"]
      └─ div.igx-combo
         ├─ div.igx-combo__search               // hidden with disableFiltering
         │  └─ input[igxInput][role="searchbox"]
         ├─ [igxComboHeader] template
         ├─ div.igx-combo__content              // the options
         │  └─ igx-combo-item[role="option"]    // role="group" for the group headers
         ├─ div.igx-combo__add                  // the empty message and the add item button
         │  └─ igx-combo-add-item[role="button"] // shown with allowCustomValues
         └─ [igxComboFooter] template
```

</PlatformBlock>

```ts
    selector: 'app-home',
    template: `
        <igx-combo [data]="cities" valueKey="id" displayKey="name" placeholder="Cities"></igx-combo>
    `,
    imports: [IGX_COMBO_DIRECTIVES]
})
export class HomeComponent {
    public cities = [
        { id: 'BG01', name: 'Sofia' },
        { id: 'BG02', name: 'Plovdiv' },
        { id: 'BG03', name: 'Varna' }
    ];
}
```

## 사용법

사용자가 도시나 국가 목록처럼 긴 목록에서 하나 이상의 옵션을 고르고 검색해야 할 때 {Platform} 콤보를 사용하십시오.

### 유형(Material 테마)

Material 테마에서 콤보 입력은 단색 배경 위에서 더 구조화된 인식을 위한 테두리 유형과, 생생한 이미지 위에 놓여 가독성을 높이기에 가장 적합한 상자 유형 중에서 선택할 수 있습니다. Bootstrap, Fluent, Indigo 테마에서는 두 유형을 같은 방식으로 그리므로, 이 항목의 다른 샘플은 Material 테마에서만 상자 유형을 보여 줍니다.

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} 콤보는 기본적으로 상자 유형을 사용합니다. 테두리 유형을 원하면 `outlined`를 설정하십시오:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<!-- Border type -->
<igc-combo outlined label="Label" placeholder="Select a value"></igc-combo>

<!-- Box type -->
<igc-combo label="Label" placeholder="Select a value"></igc-combo>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
{/* Border type */}
<IgrCombo outlined label="Label" placeholder="Select a value" />

{/* Box type */}
<IgrCombo label="Label" placeholder="Select a value" />
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

<IgbCombo T="object" Outlined="true" Label="Label" Placeholder="Select a value" />

@* Box type *@
<IgbCombo T="object" Label="Label" Placeholder="Select a value" />
```

</PlatformBlock>

<PlatformBlock for="Angular">

Angular 콤보는 기본적으로 상자 유형을 사용합니다. 테두리 유형을 원하면 <ApiLink type="Combo" member="type" label="type" /> 입력을 `border`로 설정하십시오. 레이블은 `igxLabel` 디렉티브로, 왼쪽 아이콘은 `igx-prefix`로 추가하십시오:

```html
<!-- Border type -->
<igx-combo type="border" placeholder="Select a value" [data]="options">
  <label igxLabel>Label</label>
  <igx-prefix><igx-icon>language</igx-icon></igx-prefix>
</igx-combo>

<!-- Box type -->
<igx-combo type="box" placeholder="Select a value" [data]="options">
  <label igxLabel>Label</label>
</igx-combo>
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

### 크기

콤보는 큼, 보통, 작음의 세 가지 크기로 제공됩니다. 드롭다운은 선택한 크기 변형에 맞춰 크기를 자동으로 조정합니다. `--ig-size` CSS 변수로 크기를 설정하십시오:

```css
.small {
  --ig-size: var(--ig-size-small);
}

.large {
  --ig-size: var(--ig-size-large);
}
```

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} 콤보는 기본적으로 보통 크기입니다.

### 유효성 검사 상태

숙련된 디자이너는 모두 사용자 입력을 제한하고 잘못된 상태를 피하기 위해 제약을 현명하게 사용하므로, 유효성 검사 스타일이 있는 것입니다. 사용 가능한 유효성 검사 스타일을 통해 콤보 입력은 표준 <PlatformBlock for="Angular">[입력](../../input-group.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[입력](../input.mdx)</PlatformBlock> 과 일관되며, 성공, 경고, 오류 시각 효과를 보여 주는 정교한 디자인에 맞게 준비되어 있습니다.

### 데이터 바인딩

{Platform} 콤보는 `data`에 바인딩하는 배열로 옵션 목록을 만듭니다. 배열이 객체를 담고 있을 때는 콤보가 사용할 키를 설정하십시오:

<PlatformBlock for="React,WebComponents">

- <ApiLink type="Combo" member="valueKey" label="valueKey" /> - 옵션을 식별하는 필드입니다. 콤보의 값과 선택 API가 이를 사용합니다. 생략하면 콤보는 객체에 대한 참조를 사용합니다.
- <ApiLink type="Combo" member="displayKey" label="displayKey" /> - 목록과 입력 필드가 표시하는 필드입니다. 생략하면 콤보는 `valueKey`를 사용합니다.
- <ApiLink type="Combo" member="groupKey" label="groupKey" /> - 옵션을 그룹화하는 필드입니다. 각 그룹에는 머리글이 생기며, <ApiLink type="Combo" member="groupSorting" label="groupSorting" />는 그룹을 오름차순 또는 내림차순으로 정렬합니다. 콤보 기능 항목의 [그룹화](./features.mdx#그룹화)를 참조하십시오.

</PlatformBlock>

<PlatformBlock for="Blazor">

- <ApiLink pkg="core" type="Combo<T>" member="ValueKey" label="ValueKey" /> - 옵션을 식별하는 필드입니다. 콤보의 값과 선택 API가 이를 사용합니다. 생략하면 콤보는 객체에 대한 참조를 사용합니다.
- <ApiLink pkg="core" type="Combo<T>" member="DisplayKey" label="DisplayKey" /> - 목록과 입력 필드가 표시하는 필드입니다. 생략하면 콤보는 `ValueKey`를 사용합니다.
- <ApiLink pkg="core" type="Combo<T>" member="GroupKey" label="GroupKey" /> - 옵션을 그룹화하는 필드입니다. 각 그룹에는 머리글이 생기며, <ApiLink pkg="core" type="Combo<T>" member="GroupSorting" label="GroupSorting" />는 그룹을 오름차순 또는 내림차순으로 정렬합니다. 콤보 기능 항목의 [그룹화](./features.mdx#그룹화)를 참조하십시오.

Blazor 콤보의 `T` 타입 매개변수는 그 값의 타입입니다. `ValueKey` 필드의 타입으로 설정하거나, `ValueKey`를 설정하지 않은 경우에는 옵션의 타입으로 설정하십시오. `Value`를 `@bind-Value`로 바인딩하면 Razor가 바인딩된 필드로부터 `T`를 추론합니다.

</PlatformBlock>

<PlatformBlock for="Angular">

- <ApiLink type="Combo" member="valueKey" label="valueKey" /> - 옵션을 식별하는 필드입니다. 콤보의 값과 선택이 이를 사용합니다. 생략하면 콤보는 객체에 대한 참조를 사용합니다.
- <ApiLink type="Combo" member="displayKey" label="displayKey" /> - 목록과 입력 필드가 표시하는 필드입니다. 생략하면 콤보는 `valueKey`를 사용합니다.

</PlatformBlock>

### 값과 선택

{Platform} 콤보는 선택된 항목을 값을 통해 노출하며, 코드에서 항목을 선택하고 선택 해제하는 메서드도 노출합니다.

<PlatformBlock for="React,WebComponents,Blazor">

`value`는 선택된 항목을 그 `valueKey` 값으로 담거나, `valueKey`가 없을 때는 객체 참조로 담습니다. 콤보가 처음 렌더링될 때 항목을 선택하도록 설정하십시오. `select` 및 `deselect` 메서드는 항목 배열을 받으며, 빈 배열을 전달하면 모든 항목을 선택하거나 선택 해제합니다:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
// select and deselect items by their ids, because the valueKey is 'id'
combo.select(['BG01', 'BG02']);
combo.deselect(['BG01']);

// select and deselect all items
combo.select();
combo.deselect();

console.log(combo.value); // the ids of the selected items
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx

comboRef.current?.deselect(['BG01']);

// select and deselect all items
comboRef.current?.select([]);
comboRef.current?.deselect([]);

console.log(comboRef.current?.value); // the ids of the selected items
```

</PlatformBlock>

```razor
@code {

    public void SelectCities() => Combo.Select(new object[] { "BG01", "BG02" });

}
```

### 사용 여부

콤보를 사용할 때 입력과 드롭다운은 같은 너비여야 하며 왼쪽과 오른쪽 테두리가 일치해야 합니다. 콤보가 포커스될 때 드롭다운이 표시되는 방식은, 항상 콤보 표시를 트리거하는 콘텐츠 위에 드롭다운을 표시해야 합니다. 콤보는 확장 패널처럼 콘텐츠를 밀어내지 않습니다.

## 스타일링

### Sass 테마 지정

기본 속성을 수정하면 관련된 모든 종속 속성이 자동으로 업데이트되어 변경을 반영합니다. 함수의 기본 매개변수는 <PlatformBlock for="Angular"><ApiLink kind="sass" module="themes" type="function-combo-theme" label="combo-theme" code={true} /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">`combo-theme`</PlatformBlock> 함수는 `$toggle-button-background`입니다. 테마는 이를 기준으로 모든 상태에서 토글 버튼의 색상을 도출합니다. Combo, 해당 드롭다운, 체크박스의 테마를 만든 다음, 포함하는 범위에 일치하는 CSS 변수를 내보내는 `tokens()` 믹스인을 사용하여 포함하십시오.

<PlatformBlock for="Angular">

```scss
@use "igniteui-angular/theming" as *;

$custom-combo-theme: combo-theme(
  $toggle-button-background: #e0e0e0
);

$custom-drop-down-theme: drop-down-theme(
  $background-color: #e6f2ff
);

$custom-checkbox-theme: checkbox-theme(
  $fill-color: #005dcc,
  $empty-color: #005dcc
);

:host {
  @include tokens($custom-combo-theme);
  @include tokens($custom-drop-down-theme);
  @include tokens($custom-checkbox-theme);
}
```

Angular 콤보는 드롭다운을 오버레이에 표시합니다. 뷰 캡슐화와 오버레이 아웃렛의 위치에 따라 `:host` 아래에 포함된 테마가 드롭다운에 닿지 않을 수 있습니다. [오버레이 스타일 지정](../../overlay-styling.mdx) 항목을 참조하십시오.

</PlatformBlock>

## 접근성

{Platform} 콤보는 WAI-ARIA combobox 패턴의 역할을 사용합니다. 입력 필드는 옵션 `listbox`를 제어하는 `combobox`이며, 사용자는 키보드로 목록을 열고, 이동하고, 옵션을 선택합니다.

### 키보드 상호 작용

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} 콤보의 입력 필드는 탭 정지 지점입니다. 드롭다운이 열리면 검색 입력이 포커스를 받으며, `autofocusList`가 설정되었거나 검색 입력이 숨겨진 경우에는 목록이 포커스를 받습니다. 단일 선택 모드에서는 포커스가 입력 필드에 남습니다. 콤보가 포커스를 가진 동안 다음 키가 동작합니다:

| 키 | 동작 |
| --- | --- |
| <kbd>아래 화살표</kbd> | 입력 필드에서는 드롭다운을 엽니다. 단일 선택 모드에서는 포커스를 목록으로 옮기고 첫 번째 옵션을 활성화합니다. 검색 입력에서는 포커스를 목록으로 옮기고 첫 번째 옵션을 활성화합니다. 목록에서는 다음 옵션을 활성화합니다. |
| <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> | 입력 필드에서는 <kbd>Arrow Down</kbd>와 같이 동작합니다. |
| <kbd>위 화살표</kbd> | 입력 필드에서는 드롭다운을 닫습니다. 검색 입력에서는 드롭다운을 닫고 포커스를 입력 필드로 옮깁니다. 목록에서는 이전 옵션을 활성화합니다. 첫 번째 옵션에서는 포커스를 검색 입력으로 옮기거나, 검색 입력이 숨겨져 있으면 드롭다운을 닫고 포커스를 입력 필드로 옮깁니다. |
| <kbd>Home</kbd> / <kbd>End</kbd> | 목록에서 첫 번째 또는 마지막 옵션을 활성화합니다. |
| <kbd>Space</kbd> | 목록에서 활성 옵션을 선택하거나 선택 해제합니다. |
| <kbd>Enter</kbd> | 활성 옵션이 있으면 드롭다운을 닫고 포커스를 입력 필드로 옮깁니다. 단일 선택 모드에서는 활성 옵션도 선택합니다. |
| <kbd>Escape</kbd> | 드롭다운이 열려 있으면 드롭다운을 닫고 포커스를 입력 필드로 옮깁니다. 드롭다운이 닫혀 있으면 선택을 지웁니다. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | 드롭다운을 닫고 포커스를 다음 또는 이전 포커스 가능 요소로 옮깁니다. 단일 선택 모드에서는 활성 옵션도 선택합니다. |

비활성화된 콤보는 이 키들을 무시합니다.

</PlatformBlock>

<PlatformBlock for="Angular">

| 키 | 동작 |

| <kbd>Enter</kbd> | 목록에서는 선택을 확정하고 드롭다운을 닫습니다. 항목 추가 버튼에서는 검색 입력의 텍스트를 새 항목으로 추가하고 그 항목을 선택합니다. |
| <kbd>Escape</kbd> | 드롭다운이 열려 있으면 드롭다운을 닫고 포커스는 콤보에 둡니다. 드롭다운이 닫혀 있으면 선택을 지웁니다. |
| <kbd>탭</kbd> | 드롭다운을 닫고 포커스를 다음 포커스 가능 요소로 옮깁니다. |

### 화면 읽기 프로그램 / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} 콤보는 다음 역할과 어트리뷰트를 렌더링합니다:

| 요소 | 역할 | 어트리뷰트 |
| --- | --- | --- |
| 입력 필드 | `combobox` | `aria-haspopup="listbox"`, `aria-expanded`, `aria-disabled`, 목록을 가리키는 `aria-controls`, 그리고 도움말 텍스트가 있으면 이를 가리키는 `aria-describedby` |
| `list` 파트 | `listbox` | `aria-multiselectable`(단일 선택 모드에서는 `false`), 입력 필드를 가리키는 `aria-labelledby`, 활성 옵션을 가리키는 `aria-activedescendant` |
| 각 `item` 파트 | `option` | `aria-selected`, `aria-posinset`, `aria-setsize` |
| `clear-icon` 파트 | `button` | 리소스 문자열의 `aria-label` |

{Platform} 콤보는 보조 기술에 대해 다음과 같이 동작합니다:

- 입력 필드는 `label`에서 접근 가능한 이름을 가져옵니다. 레이블이 없으면 옵션이 선택되었는지를 알려 주는 리소스 문자열에서 이름을 가져옵니다.
- 포커스가 목록에 머무는 동안 활성 옵션은 `aria-activedescendant`을 통해 읽힙니다.
- 닫힌 드롭다운의 콘텐츠는 `inert`입니다.

</PlatformBlock>

<PlatformBlock for="Angular">

Angular 콤보는 다음 역할과 어트리뷰트를 렌더링합니다:

| 요소 | 역할 | 어트리뷰트 |
| --- | --- | --- |
| 입력 필드의 input | `combobox` | `aria-haspopup="listbox"`, `aria-expanded`, 목록을 가리키는 `aria-controls`, `aria-labelledby`, `aria-label` |
| 검색 입력 | `searchbox` | `aria-autocomplete="list"` 및 `aria-label="search"` |
| 드롭다운 | `listbox` | `igxLabel` 또는 `ariaLabelledBy` 요소를 가리키는 `aria-labelledby` |

| 각 옵션 | `option` | `aria-selected` |
| 각 그룹 머리글 | `group` | — |
| 항목 추가 버튼 | `button` | 리소스 문자열의 `aria-label` |

## 알려진 제한 사항

- 선택된 항목을 보여 주는 입력 필드는 편집할 수 없습니다. Firefox에서는 그 안에 커서가 보입니다.
- Angular 콤보가 `undefined`를 포함하는 기본 타입 배열에 바인딩되면, 목록은 `undefined`를 표시하지 않습니다. 객체의 `valueKey` 필드가 `undefined`이면 목록에 항목이 표시되지만 사용자가 선택할 수 없습니다.
- Angular 콤보가 원격 서비스에 바인딩되고 미리 정의된 선택이 있으면, 데이터가 로드될 때까지 입력 필드는 비어 있습니다.
- 목록은 [가상 스크롤](../../layouts/virtual-scroll.mdx#알려진-제한-사항)을 사용하므로, 그 제한이 적용됩니다. 목록은 보이는 옵션만 렌더링하며, DOM을 조회하는 코드는 그 옵션만 찾습니다.
