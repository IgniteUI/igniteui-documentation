# 단일 선택 콤보

{ProductName} 단일 선택 콤보는 사용자가 옵션 하나를 선택하고, 입력 필드에 입력하여 검색 가능한 드롭다운 목록을 필터링하는 콤보입니다.

<PlatformBlock for="Angular">

Angular 단일 선택 콤보는 간단한 콤보이며, `igx-simple-combo` 컴포넌트입니다. 콤보와 마찬가지로 옵션을 바인딩하고, 그룹화하고, 템플릿화하며, 사용자가 입력 필드에 입력하여 목록을 필터링하거나 사용자 지정 값을 입력할 수 있게 합니다.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

상호 작용을 막으려면 <PlatformBlock for="React,WebComponents"><ApiLink type="Combo" member="singleSelect" label="singleSelect" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink pkg="core" type="Combo<T>" member="SingleSelect" label="SingleSelect" /></PlatformBlock> {Platform} 콤보에서 단일 선택으로 전환하려면 설정하십시오. 입력 필드는 편집 가능해지고 사용자가 입력하는 동안 목록을 필터링하며, 드롭다운의 검색 입력은 숨겨지고, 옵션에는 체크박스가 표시되지 않습니다.

</PlatformBlock>

<DocsAside type="info">
콤보에는 두 가지 레이아웃 옵션이 있습니다: 단일 선택 콤보(간단한 콤보)와 콤보(다중 선택).
</DocsAside>

단일 선택 모드에서 `igc-combo` 요소는 편집 가능한 입력 필드를 렌더링하고, 드롭다운의 검색 입력을 숨기며, 옵션을 체크박스 없이 렌더링합니다:

```text
igc-combo[single-select]
└─ #shadow-root
   ├─ igc-popover
   │  ├─ igc-input#target[slot="anchor"]            // the editable input field, exported as the "input" part
   │  │  ├─ slot[name="prefix"]
   │  │  ├─ span[part="clear-icon"]                  // shown when the Combo has a value
   │  │  ├─ slot[name="suffix"]
   │  │  └─ span[part="toggle-icon"]
   │  └─ div[part="list-wrapper"]                    // the dropdown
   │     ├─ div[part="filter-input"][hidden]         // the search input is hidden
   │     ├─ div[part="header"]
   │     │  └─ slot[name="header"]
   │     ├─ igc-virtual-scroll#dropdown[part="list"][role="listbox"]
   │     │  ├─ igc-combo-header[part="group-header"] // one for each group
   │     │  └─ igc-combo-item[part="item"][hide-checkbox] // one for each option
   │     ├─ div[part="empty"]                        // shown when the list has no options
   │     │  └─ slot[name="empty"]
   │     └─ div[part="footer"]
   │        └─ slot[name="footer"]
   └─ igc-validator#combo-helper-text               // the helper text and the validation messages, exported as the "helper-text" part
```

</PlatformBlock>

```text
         └─ [igxComboFooter] template
```

```ts
const combo = document.getElementById('countries') as IgcComboComponent;

combo.data = [

    { id: 'BG', name: 'Bulgaria' }
```

```ts
export class HomeComponent {

        { id: 'BY', name: 'Belarus' },
        { id: 'BE', name: 'Belgium' },

    ];
}
```

## 사용법

국가나 도시처럼 사용자가 검색해야 하는 목록에서 정확히 옵션 하나를 고르는 경우에는 {Platform} 단일 선택 콤보를 사용하십시오.

### 유형(Material 테마)

Material 테마에서 간단한 콤보 입력은 단색 배경 위에서 더 구조화된 인식을 위한 테두리 유형과, 생생한 이미지 위에 놓여 가독성을 높이기에 가장 적합한 상자 유형 중에서 선택할 수 있습니다. Bootstrap, Fluent, Indigo 테마에서는 두 유형을 같은 방식으로 그리므로, 이 항목의 다른 샘플은 Material 테마에서만 상자 유형을 보여 줍니다.

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} 콤보는 기본적으로 상자 유형을 사용합니다. 테두리 유형을 원하면 `outlined`를 설정하십시오:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<!-- Border type -->
<igc-combo single-select outlined label="Label" placeholder="Select a value"></igc-combo>

<!-- Box type -->
<igc-combo single-select label="Label" placeholder="Select a value"></igc-combo>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
{/* Border type */}
<IgrCombo singleSelect outlined label="Label" placeholder="Select a value" />

{/* Box type */}
<IgrCombo singleSelect label="Label" placeholder="Select a value" />
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
@* Border type *@
<IgbCombo T="object" SingleSelect="true" Outlined="true" Label="Label" Placeholder="Select a value" />

@* Box type *@
<IgbCombo T="object" SingleSelect="true" Label="Label" Placeholder="Select a value" />
```

</PlatformBlock>

<PlatformBlock for="Angular">

Angular 간단한 콤보는 기본적으로 상자 유형을 사용합니다. 테두리 유형을 원하면 <ApiLink type="SimpleCombo" member="type" label="type" /> 입력을 `border`로 설정하십시오. 레이블은 `igxLabel` 디렉티브로, 왼쪽 아이콘은 `igx-prefix`로 추가하십시오. `IGX_SIMPLE_COMBO_DIRECTIVES` 토큰은 둘 다 담고 있지만 아이콘은 담고 있지 않으므로, `IgxIconComponent`를 컴포넌트의 `imports`에 추가하십시오:

```html
<!-- Border type -->
<igx-simple-combo type="border" placeholder="Select a value" [data]="options">
  <label igxLabel>Label</label>
  <igx-prefix><igx-icon>language</igx-icon></igx-prefix>
</igx-simple-combo>

<!-- Box type -->
<igx-simple-combo type="box" placeholder="Select a value" [data]="options">
  <label igxLabel>Label</label>
</igx-simple-combo>
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

`label` 속성으로 레이블을 추가하고, `prefix` 슬롯에 왼쪽 아이콘을 추가하십시오. [아이콘](../../layouts/icon.mdx) 항목에 설명된 대로 아이콘을 먼저 등록하십시오.

</PlatformBlock>

### 값과 선택

{Platform} 단일 선택 콤보는 선택된 항목 하나를 담고 있으며, 이를 값과 선택 API를 통해 노출합니다.

<PlatformBlock for="React,WebComponents,Blazor">

`value`는 선택된 항목을 원소가 하나인 배열로 담습니다. 그 원소는 `valueKey` 값이거나, `valueKey`가 없으면 객체 참조입니다. 콤보가 처음 렌더링될 때 항목을 선택하도록 설정하십시오. `select` 메서드는 단일 항목을 선택하고 이전 항목을 선택 해제하므로, 항목 하나만 전달하십시오. `deselect` 메서드는 그 항목을 선택 해제합니다. 항목 없이 호출하면 `select`는 단일 선택 모드에서 선택을 지웁니다:

</PlatformBlock>



```ts
public onCountryChanging(event: ISimpleComboSelectionChangingEventArgs): void {
    if (event.newValue === 'BY') {
        event.cancel = true;
    }
}
```

`selectionChanging` 이벤트는 연쇄 시나리오도 구동합니다. 한 간단한 콤보의 선택이 다음 콤보의 데이터를 로드하는 경우로, 예를 들어 국가, 지역, 도시 콤보가 있습니다. 각 간단한 콤보의 `selectionChanging` 이벤트를 처리하여 다음 콤보의 데이터를 로드하고 그 선택을 지우십시오:

```html
<igx-simple-combo #country
    [data]="countriesData"
    (selectionChanging)="countryChanging($event)"
    placeholder="Choose Country..."
    [(ngModel)]="selectedCountry"
    displayKey="name">
</igx-simple-combo>
<igx-simple-combo #region
    [data]="regionData"
    (selectionChanging)="regionChanging($event)"
    placeholder="Choose Region..."
    [(ngModel)]="selectedRegion"
    displayKey="name"
    [disabled]="regionData.length === 0">
</igx-simple-combo>
<igx-simple-combo #city
    [data]="citiesData"
    placeholder="Choose City..."
    [(ngModel)]="selectedCity"
    displayKey="name"
    [disabled]="citiesData.length === 0">
</igx-simple-combo>
```

```ts
export class SimpleComboCascadingComponent implements OnInit {
    public selectedCountry: Country;
    public selectedRegion: Region;
    public selectedCity: City;
    public countriesData: Country[];
    public regionData: Region[] = [];
    public citiesData: City[] = [];

    public ngOnInit(): void {
        this.countriesData = getCountries(['United States', 'Japan', 'United Kingdom']);
    }

    public countryChanging(e: ISimpleComboSelectionChangingEventArgs) {
        this.selectedCountry = e.newSelection as Country;
        this.regionData = getCitiesByCountry([this.selectedCountry?.name])
            .map(c => ({ name: c.region, country: c.country }))
            .filter((v, i, a) => a.findIndex(r => r.name === v.name) === i);
        this.selectedRegion = null;
        this.selectedCity = null;
        this.citiesData = [];
    }

    public regionChanging(e: ISimpleComboSelectionChangingEventArgs) {
        this.selectedRegion = e.newSelection as Region;
        this.citiesData = getCitiesByCountry([this.selectedCountry?.name])
            .filter(c => c.region === this.selectedRegion?.name);
        this.selectedCity = null;
    }
}
```

[연쇄 콤보가 있는 그리드](../../grid/cascading-combos.mdx) 항목은 데이터 그리드의 셀 편집에서 같은 시나리오를 보여 줍니다.

### 필터링

{Platform} 단일 선택 콤보의 입력 필드에 입력하면 드롭다운이 열리고, 목록이 텍스트를 포함하는 옵션으로 필터링됩니다. 첫 번째 일치 항목이 활성 옵션이 되므로, <kbd>Enter</kbd>를 누르면 그 항목이 선택됩니다.

</PlatformBlock>

</PlatformBlock>

<PlatformBlock for="Blazor">


사용자가 입력하는 동안 전체 목록을 유지하려면 <ApiLink type="SimpleCombo" member="disableFiltering" label="disableFiltering" />을, 입력 필드에 대소문자 구분 필터링을 전환하는 버튼을 표시하려면 <ApiLink type="SimpleCombo" member="showSearchCaseIcon" label="showSearchCaseIcon" />를 설정하십시오. <ApiLink type="SimpleCombo" member="filteringOptions" label="filteringOptions" /> 입력은 텍스트가 기준으로 삼는 키와 필터링이 대소문자를 구분하는지 여부를 설정하며, <ApiLink type="SimpleCombo" member="filterFunction" label="filterFunction" />는 필터링을 직접 구현한 것으로 대체합니다. 간단한 콤보가 선택된 옵션 없이 포커스를 잃으면 입력 필드가 지워집니다:

```html
<igx-simple-combo [data]="countries" displayKey="name" [showSearchCaseIcon]="true"
                  [filteringOptions]="{ filteringKey: 'name', caseSensitive: false }">
</igx-simple-combo>
```

사용자가 목록에 없는 값을 입력할 수 있게 하려면 <ApiLink type="SimpleCombo" member="allowCustomValues" label="allowCustomValues" />을 설정하십시오. 텍스트와 일치하는 옵션이 없으면 드롭다운에 항목 추가 버튼이 표시되며, 그 버튼에서 <kbd>Enter</kbd>를 누르면 텍스트가 새 항목으로 추가되고 선택됩니다. 간단한 콤보는 항목을 추가하기 전에 <ApiLink type="SimpleCombo" member="addition" label="addition" />를 발생시킵니다:

```html
<igx-simple-combo [data]="countries" displayKey="name" valueKey="id" [allowCustomValues]="true" (addition)="onAddition($event)"></igx-simple-combo>
```

### 사용 여부

간단한 콤보를 사용할 때 입력과 드롭다운은 같은 너비여야 하며 왼쪽과 오른쪽 테두리가 일치해야 합니다. 간단한 콤보가 포커스될 때 드롭다운이 표시되는 방식은, 항상 콤보 표시를 트리거하는 콘텐츠 위에 드롭다운을 표시해야 합니다. 콤보는 확장 패널처럼 콘텐츠를 밀어내지 않습니다.

  dontSrc={comboDoNotAlignment}

## 스타일링

간단한 콤보는 입력과 드롭다운 부분을 결합한 스타일 유연성을 제공합니다. 입력 텍스트 요소의 색상, 테두리 스타일과 색상을 설정할 수 있습니다. 드롭다운은 배경색을 바꾸거나, 배경 및 텍스트 색상이 있는 간단한 콤보 드롭다운의 항목과 관련된 여러 옵션을 사용할 수 있습니다.

다음 CSS 변수로 {Platform} 단일 선택 콤보의 토글 버튼과 지우기 버튼 색상을 바꾸십시오:

| 변수 | 변경되는 내용 |
| --- | --- |
| `--ig-combo-toggle-button-background` | 토글 버튼의 배경입니다. |
| `--ig-combo-toggle-button-foreground` | 토글 버튼의 아이콘 색상입니다. |
| `--ig-combo-toggle-button-foreground-filled` | 콤보에 값이 있을 때 토글 버튼의 아이콘 색상입니다. |
| `--ig-combo-toggle-button-background-focus` | 콤보가 포커스되었을 때 토글 버튼의 배경입니다. |
| `--ig-combo-toggle-button-foreground-focus` | 콤보가 포커스되었을 때 토글 버튼의 아이콘 색상입니다. |
| `--ig-combo-toggle-button-background-disabled` | 콤보가 비활성화되었을 때 토글 버튼의 배경입니다. |
| `--ig-combo-toggle-button-foreground-disabled` | 콤보가 비활성화되었을 때 토글 버튼의 아이콘 색상입니다. |
| `--ig-combo-clear-button-background` | 지우기 버튼의 배경입니다. |
| `--ig-combo-clear-button-foreground` | 지우기 버튼의 아이콘 색상입니다. |
| `--ig-combo-empty-list-placeholder-color` | 빈 목록이 표시하는 텍스트의 색상입니다. |

입력 필드는 `--ig-input-group-*` 변수에서 색상을 가져오고, 드롭다운은 `--ig-drop-down-*` 변수에서 가져오므로, 이 모두를 콤보에서 설정할 수 있습니다. 단일 선택 모드에는 체크박스가 표시되지 않으므로 `--ig-checkbox-*` 변수는 효과가 없습니다.

### Sass 테마 지정

기본 속성을 수정하면 관련된 모든 종속 속성이 자동으로 업데이트되어 변경을 반영합니다. 함수의 기본 매개변수는 <PlatformBlock for="Angular"><ApiLink kind="sass" module="themes" type="function-combo-theme" label="combo-theme" code={true} /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">`combo-theme`</PlatformBlock> 함수의 기본 매개변수는 `$toggle-button-background`이며, 테마는 이 매개변수로부터 모든 상태에서 토글 버튼의 색상을 도출합니다. 콤보와 그 드롭다운의 테마를 만든 다음, 포함된 위치의 범위에서 일치하는 CSS 변수를 내보내는 `tokens()` 믹스인으로 포함하십시오.

<PlatformBlock for="Angular">

```scss
@use "igniteui-angular/theming" as *;

$custom-combo-theme: combo-theme(
  $toggle-button-background: #e0e0e0
);

$custom-drop-down-theme: drop-down-theme(
  $background-color: #e6f2ff,
  $selected-item-background: #4ca7e3
);

:host {
  @include tokens($custom-combo-theme);
  @include tokens($custom-drop-down-theme);
}
```

Angular 간단한 콤보는 드롭다운을 오버레이에 표시합니다. 뷰 캡슐화와 오버레이 아웃렛의 위치에 따라 `:host` 아래에 포함된 테마가 드롭다운에 닿지 않을 수 있습니다. [오버레이 스타일 지정](../../overlay-styling.mdx) 항목을 참조하십시오.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Sass 함수는 `igniteui-theming` 패키지에서 제공됩니다. Sass 설정은 [테마 지정](../../themes/overview.mdx) 항목을 참조하십시오.

```scss
  @include tokens($custom-drop-down-theme);
}
```

</PlatformBlock>

## 접근성

{Platform} 단일 선택 콤보는 WAI-ARIA combobox 패턴의 역할을 사용합니다. 편집 가능한 입력 필드는 옵션 `listbox`를 제어하는 `combobox`이며, 사용자는 입력하여 목록을 필터링하고 키보드로 옵션을 선택합니다.

### 키보드 상호 작용

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} 단일 선택 콤보의 입력 필드는 탭 정지 지점이며, 사용자가 입력하는 동안 포커스는 그 안에 머뭅니다. 콤보가 포커스를 가진 동안 다음 키가 동작합니다:

| 키 | 동작 |
| --- | --- |
| 출력 가능한 문자 | 입력 필드에서는 드롭다운을 열고, 목록을 필터링하며, 첫 번째 일치 항목을 활성화합니다. |
| <kbd>Arrow Down</kbd> / <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> | 입력 필드에서는 드롭다운을 열고, 포커스를 목록으로 옮기며, 첫 번째 옵션을 활성화합니다. 목록에서는 다음 옵션을 활성화합니다. |
| <kbd>위 화살표</kbd> | 입력 필드에서는 드롭다운을 닫습니다. 목록에서는 이전 옵션을 활성화합니다. 첫 번째 옵션에서는 드롭다운을 닫고 포커스를 입력 필드로 옮깁니다. |
| <kbd>Home</kbd> / <kbd>End</kbd> | 목록에서 첫 번째 또는 마지막 옵션을 활성화합니다. |
| <kbd>Space</kbd> | 목록에서는 활성 옵션을 선택하고, 이미 선택되어 있으면 선택을 해제합니다. |
| <kbd>Enter</kbd> | 활성 옵션이 있으면 그 옵션을 선택하고, 드롭다운을 닫으며, 텍스트가 선택된 상태로 포커스를 입력 필드로 옮깁니다. |
| <kbd>Escape</kbd> | 드롭다운이 열려 있으면 드롭다운을 닫고 포커스를 입력 필드로 옮깁니다. 드롭다운이 닫혀 있으면 선택을 지웁니다. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | 드롭다운이 열려 있으면 활성 옵션을 선택하고, 드롭다운을 닫은 다음, 포커스를 다음 또는 이전 포커스 가능 요소로 옮깁니다. |

비활성화된 콤보는 이 키들을 무시합니다.

</PlatformBlock>

<PlatformBlock for="Angular">

Angular 간단한 콤보의 입력 필드는 탭 정지 지점이며, 사용자가 입력하는 동안 포커스는 그 안에 머뭅니다. 간단한 콤보가 포커스를 가진 동안 다음 키가 동작합니다:

| 키 | 동작 |
| --- | --- |
| 출력 가능한 문자 | 입력 필드에서는 드롭다운을 열고, 목록을 필터링하며, 첫 번째 일치 항목에 포커스를 줍니다. |
| <kbd>Arrow Down</kbd> / <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> | 닫혀 있는 간단한 콤보에서는 드롭다운을 엽니다. 열려 있는 간단한 콤보에서는 포커스를 목록으로 옮깁니다. 선택된 옵션 또는 첫 번째 옵션으로 옮깁니다. 목록에서는 다음 옵션으로 이동하며, 마지막 옵션에서는 표시되는 경우 항목 추가 버튼으로 이동합니다. |

| <kbd>Alt</kbd> + <kbd>Arrow Up</kbd> | 목록에서는 드롭다운을 닫고 포커스를 입력 필드로 옮깁니다. |
| <kbd>Home</kbd> / <kbd>End</kbd> | 목록에서 첫 번째 또는 마지막 옵션으로 이동합니다. |
| <kbd>Space</kbd> | 목록에서는 포커스된 옵션을 선택하거나 선택 해제합니다. |
| <kbd>Enter</kbd> | 텍스트와 일치하는 포커스된 옵션이 있는 입력 필드에서는 그 옵션을 선택하고 드롭다운을 닫습니다. 목록에서는 포커스된 옵션을 선택하고, 드롭다운을 닫은 다음, 포커스를 입력 필드로 옮깁니다. 항목 추가 버튼에서는 입력 필드의 텍스트를 새 항목으로 추가하고 선택합니다. |
| <kbd>Backspace</kbd> / <kbd>Delete</kbd> | 입력 필드에서는 선택을 지웁니다. |
| <kbd>Escape</kbd> | 드롭다운이 열려 있으면 닫습니다. 드롭다운이 닫혀 있으면 선택을 지우고 포커스는 입력 필드에 둡니다. |
| <kbd>탭</kbd> | 드롭다운이 열려 있으면 텍스트와 일치하는 포커스된 옵션을 선택하고, 드롭다운을 닫은 다음, 포커스를 다음 포커스 가능 요소로 옮깁니다. |

</PlatformBlock>

### 화면 읽기 프로그램 / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} 단일 선택 콤보는 다음 역할과 어트리뷰트를 렌더링합니다:

| 요소 | 역할 | 어트리뷰트 |
| --- | --- | --- |
| 입력 필드 | `combobox` | `aria-haspopup="listbox"`, `aria-expanded`, `aria-disabled`, 목록을 가리키는 `aria-controls`, 그리고 도움말 텍스트가 있으면 이를 가리키는 `aria-describedby` |
| `list` 파트 | `listbox` | `aria-multiselectable="false"`, 입력 필드를 가리키는 `aria-labelledby`, 활성 옵션을 가리키는 `aria-activedescendant` |
| 각 `item` 파트 | `option` | `aria-selected`, `aria-posinset`, `aria-setsize` |
| `clear-icon` 파트 | `button` | 리소스 문자열의 `aria-label` |

{Platform} 단일 선택 콤보는 보조 기술에 대해 다음과 같이 동작합니다:

- 입력 필드는 `label`에서 접근 가능한 이름을 가져옵니다. 레이블이 없으면 옵션이 선택되었는지를 알려 주는 리소스 문자열에서 이름을 가져옵니다.
- 입력 필드는 편집 가능하며, 사용자가 입력하는 텍스트가 목록의 필터가 됩니다.
- 포커스가 목록에 머무는 동안 활성 옵션은 `aria-activedescendant`을 통해 읽힙니다.
- 닫힌 드롭다운의 콘텐츠는 `inert`입니다.

</PlatformBlock>

<PlatformBlock for="Angular">

Angular 간단한 콤보는 다음 역할과 어트리뷰트를 렌더링합니다:

| 요소 | 역할 | 어트리뷰트 |
| --- | --- | --- |
| 입력 필드의 input | `combobox` | `aria-haspopup="listbox"`, `aria-autocomplete="list"`, `aria-readonly="false"`, `aria-expanded`, 목록을 가리키는 `aria-controls`, `aria-labelledby`, `aria-label` |
| 드롭다운 | `listbox` | `igxLabel` 또는 `ariaLabelledBy` 요소를 가리키는 `aria-labelledby` |
| 옵션의 컨테이너 | — | 포커스된 옵션을 가리키는 `aria-activedescendant` |
| 각 옵션 | `option` | `aria-selected` |
| 각 그룹 머리글 | `group` | — |
| 지우기 버튼 | — | 리소스 문자열의 `aria-label` |
| 항목 추가 버튼 | `button` | 리소스 문자열의 `aria-label` |

</PlatformBlock>

## 알려진 제한 사항

<PlatformBlock for="React,WebComponents,Blazor">

- 단일 선택 모드에서는 드롭다운의 검색 입력이 숨겨지므로, `placeholderSearch`, `caseSensitiveIcon`, `autofocusList`는 효과가 없습니다.
- {Platform} 콤보는 사용자 지정 값을 추가하지 않습니다. 입력 필드의 텍스트와 일치하는 옵션이 없으면, 콤보는 포커스를 잃을 때 입력 필드를 지웁니다.

</PlatformBlock>

<PlatformBlock for="Angular">

- Angular 간단한 콤보가 `undefined`를 포함하는 기본 타입 배열에 바인딩되면, 목록은 `undefined`를 표시하지 않습니다. 객체의 `valueKey` 필드가 `undefined`이면 목록에 항목이 표시되지만 사용자가 선택할 수 없습니다.
- Angular 간단한 콤보가 `ngModel`로 바인딩되고 `required`이면, `null`, `undefined`, `''` 값은 선택할 수 없습니다.
- Angular 간단한 콤보가 원격 서비스에 바인딩되고 미리 정의된 선택이 있으면, 데이터가 로드될 때까지 입력 필드는 비어 있습니다.
- 목록은 [가상 스크롤](../../layouts/virtual-scroll.mdx#알려진-제한-사항)을 사용하므로, 그 제한이 적용됩니다. 목록은 보이는 옵션만 렌더링하며, DOM을 조회하는 코드는 그 옵션만 찾습니다.

</PlatformBlock>
