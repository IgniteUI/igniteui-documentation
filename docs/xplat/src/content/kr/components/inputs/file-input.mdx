# {Platform} 파일 입력 개요

{ProductName} 파일 입력 컴포넌트는 사용자가 파일을 선택하고 업로드할 수 있는 대화형 방식을 제공합니다. 파일 선택, 선택된 파일 이름 표시, 여러 파일 업로드 지원 같은 파일 전용 기능을 추가하여 기본 <ApiLink pkg="core" type="Input" /> 기능을 확장합니다.

## {Platform} 파일 입력 예제

<Sample src="/inputs/file-input/overview" height={120} alt="{Platform} 파일 입력 개요 예제" />

## 사용법

<ApiLink type="FileInput" /> 컴포넌트를 사용하면 사용자가 기기에서 파일을 선택하고 웹 애플리케이션에 업로드할 수 있습니다. 선택된 파일의 이름을 표시하며, 찾아보기 버튼과 "No file chosen" 텍스트에 대한 사용자 지정 옵션을 제공합니다. 또한 속성, 메서드, 슬롯을 제공하여 필요에 맞게 동작을 더 구성할 수 있습니다.

## 구성

### 속성

<ApiLink type="FileInput" /> 컴포넌트는 특정 요구 사항에 따라 동작을 구성할 수 있는 다양한 속성을 제공합니다. 이 속성들은 입력의 기능, 모양, 유효성 검사를 제어할 수 있게 합니다.

- <ApiLink pkg="core" type="Input" member="value" label="Value" /> - 파일 입력 필드의 현재 값을 설정합니다.
- <ApiLink pkg="core" type="Input" member="disabled" label="Disabled" /> - 파일 입력을 비활성화하여 사용자 상호 작용을 막습니다.
- <ApiLink pkg="core" type="Input" member="required" label="Required" /> - 입력을 필수로 표시합니다. 파일이 선택되지 않으면 폼 제출이 막힙니다.
- <ApiLink pkg="core" type="Input" member="invalid" label="Invalid" /> - 입력 값이 유효하지 않음을 나타내며, 시각적 오류 상태를 트리거하는 데 사용됩니다.
- `Multiple` - 여러 파일의 선택을 허용합니다.
- `Accept` - 선택할 수 있는 파일의 유형을 정의합니다. 이 속성의 값은 쉼표로 구분된 파일 형식 목록(예: .jpg, .png, .gif)이어야 합니다.
- <ApiLink pkg="core" type="Input" member="autofocus" label="Autofocus" /> - 페이지가 로드될 때 파일 입력 필드에 자동으로 포커스를 줍니다.
- <ApiLink pkg="core" type="Input" member="label" label="Label" /> - 파일 입력 요소와 연결된 레이블 텍스트를 설정합니다.
- <ApiLink pkg="core" type="Input" member="placeholder" label="Placeholder" /> - 파일이 선택되지 않았을 때 표시되는 플레이스홀더 텍스트를 제공합니다.

<PlatformBlock for="WebComponents">

```html
<igc-file-input
  label="Files Input"
  accept=".jpg, .png, .gif"
  placeholder="Files missing"
  required
  multiple>
</igc-file-input>
```

</PlatformBlock>

### 메서드

구성 가능한 속성 외에도, <ApiLink type="FileInput" /> 컴포넌트에서 사용할 수 있도록 <ApiLink pkg="core" type="Input" /> 컴포넌트에서 상속된 유용한 메서드가 네 가지 있습니다:

- `Focus` - 파일 입력 요소에 포커스를 설정합니다.
- `Blur` - 파일 입력 요소에서 포커스를 제거합니다.
- <ApiLink pkg="core" type="Input" member="reportValidity" label="ReportValidity" /> - 입력의 유효성을 확인하고, 입력이 유효하지 않으면 유효성 검사 메시지를 표시합니다.
- <ApiLink pkg="core" type="Input" member="setCustomValidity" label="SetCustomValidity" /> - 사용자 지정 유효성 검사 메시지를 설정합니다. 제공된 메시지가 비어 있지 않으면 입력이 유효하지 않음으로 표시됩니다.

### 슬롯

<ApiLink type="FileInput" /> 컴포넌트는 모양과 동작을 사용자 지정하는 데 사용할 수 있는 여러 슬롯도 노출합니다.

- `prefix` 및 `suffix` - 기본 입력 영역의 앞이나 뒤에 콘텐츠를 삽입할 수 있게 합니다.
- `helper-text` - 입력 아래에 힌트나 안내 메시지를 표시합니다. 형식 지정 팁이나 필드 요구 사항처럼 추가 안내를 제공하는 데 유용합니다.
- `file-selector-text` - 파일 선택 버튼에 표시되는 텍스트를 사용자 지정할 수 있게 합니다.
- `file-missing-text` - 파일이 선택되지 않았을 때 입력 필드에 표시되는 텍스트를 설정합니다.
- `value-missing` - 필수 필드 유효성 검사가 실패하면 사용자 지정 콘텐츠를 렌더링합니다(즉, 파일이 필요하지만 제공되지 않은 경우).
- `invalid` – 입력이 유효하지 않은 상태일 때 사용자 지정 콘텐츠를 렌더링할 수 있게 합니다.
- `custom-error` - <ApiLink type="FileInput" member="setCustomValidity" label="setCustomValidity()" /> 메서드를 사용하여 사용자 지정 유효성 검사 메시지가 설정되면 콘텐츠를 표시합니다.

슬롯에 콘텐츠를 넣을 때는 간단한 텍스트, 기호, 이모지에는 `<span>` 요소를, 아이콘에는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다.

## 통합

<ApiLink type="FileInput" /> 컴포넌트는 HTML Form 요소와 매끄럽게 통합됩니다. 위에서 설명한 메서드와 속성을 사용하면 표준 HTML 폼 안에서 그 동작과 유효성 검사를 효과적으로 관리할 수 있습니다.

## 제한 사항

<ApiLink type="FileInput" /> 컴포넌트에는 현재 다음과 같은 제한 사항이 있습니다:
- "Browse" 버튼과 "No file chosen" 메시지의 기본 문자열은 자동으로 지역화되지 않습니다. 이 문자열은 모든 로캘에서 같게 유지되지만, 적절한 슬롯이나 플레이스홀더 바인딩을 사용하여 수동으로 사용자 지정할 수 있습니다.
- `value` 속성을 통해 파일을 수동으로 설정할 수 없습니다. 파일 선택은 파일 선택기를 통해서만 할 수 있습니다. 다만 필드를 재설정하려면 빈 문자열 `''`를 전달할 수 있습니다.

## 접근성 및 ARIA 지원

<ApiLink type="FileInput" /> 컴포넌트는 포커스를 받을 수 있고 상호 작용 가능하므로, 키보드와 화면 읽기 프로그램 접근성을 모두 보장합니다. 이 컴포넌트는 <ApiLink type="FileInput" member="label" label="Label" /> 어트리뷰트로 레이블을 지정할 수 있으며, 이는 의미적으로 올바르고 접근 가능한 레이블을 제공하기 위해 기본 `<label>` 요소를 활용합니다.

접근성 모범 사례를 지원하기 위해, 컴포넌트는 관련 ARIA 속성도 적용합니다:

- `aria-invalid` - 입력이 유효하지 않은 상태일 때 "true"로 설정됩니다.
- `aria-describedby` - 도움말 텍스트 요소가 있으면 그것에 자동으로 연결되어, 보조 기술이 추가 정보를 읽을 수 있게 합니다.

## 스타일링

<ApiLink type="FileInput" /> 컴포넌트는 스타일 지정에 사용할 수 있는 CSS 파트를 노출합니다. 노출된 모든 CSS 파트는 다음 표에 나와 있습니다:

|이름|설명|
|--|--|
| `container` | 모든 주요 입력 요소를 담는 기본 래퍼입니다. |
| `input` | 네이티브 input 요소입니다. |
| `label` | 네이티브 label 요소입니다. |
| `file-names` | 파일 이름 래퍼입니다. |
| `file-selector-button` | 찾아보기 버튼입니다. |
| `prefix` | 접두사 래퍼입니다. |
| `suffix` | 접미사 래퍼입니다. |
| `helper-text` | 도움말 텍스트 래퍼입니다. |


```scss
igc-file-input::part(file-names) {
  background-color: var(--ig-primary-50);
  color: var(--ig-gray-400);
}

igc-file-input::part(suffix) {
  color: var(--ig-primary-700-contrast);
  background-color: var(--ig-primary-700);
}

igc-file-input::part(label) {
  color: var(--ig-gray-600);
}
```
