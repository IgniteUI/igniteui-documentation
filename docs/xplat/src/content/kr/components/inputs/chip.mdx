# 칩 컴포넌트

{ProductName} 칩은 태그, 필터 또는 사람을 나타내는 간결한 요소이며, 사용자가 선택하거나 제거할 수 있습니다.

칩은 선택 가능하거나, 제거 가능하거나, 둘 다일 수 있으며, 레이블 앞뒤에 아이콘이나 다른 콘텐츠를 표시할 수 있습니다.

### 사전 요구 사항 및 버전 호환성

일부 {Platform} 칩 기능은 애플리케이션이 사용하는 패키지 버전에 따라 달라집니다.

<PlatformBlock for="WebComponents">

- `outlined` 속성은 {PackageWebComponents} 7.3.0 이상에서 사용할 수 있습니다.
- `action` 및 `remove` 파트는 7.3.1 이상에서 사용할 수 있습니다. 이전 버전에서는 `base` 파트가 선택 버튼이며 제거 아이콘이 그 안에 렌더링됩니다.
- `start` 및 `end` 슬롯은 7.3.1 이상에서 문서화되어 있습니다. 이전 버전에서도 렌더링되지만 문서화되어 있지 않습니다.

</PlatformBlock>

<PlatformBlock for="React">

`igniteui-react` 패키지는 `igniteui-webcomponents`의 테마 스타일시트와 함께 사용하십시오. React 칩은 `igc-chip` 웹 컴포넌트를 감싸므로, 사용 가능한 속성, 슬롯, 파트는 `igniteui-react`가 사용하는 `igniteui-webcomponents` 버전을 따릅니다.

</PlatformBlock>

<PlatformBlock for="Blazor">

`IgniteUI.Blazor` 패키지를 사용하십시오. `IgniteUI.Blazor` 26.1에는 이전 버전의 칩이 포함되어 있습니다:

- `IgbChip`은 `Outlined`, `Locale`, `ResourceStrings` 속성을 노출하지 않습니다.
- `base` 파트는 선택 버튼이며, 제거 아이콘은 그 안에 렌더링됩니다. 칩에는 `action` 또는 `remove` 파트가 없습니다.
- 포커스 스타일은 `--ig-chip-focus-outline-color`와 `--ig-chip-focus-selected-outline-color`를 읽습니다.
- [접근성](#접근성)에 설명된 대로, 키보드 및 화면 읽기 프로그램 동작이 다릅니다.

</PlatformBlock>

<PlatformBlock for="Angular">

`igniteui-angular` 패키지를 사용하십시오. `outlined` 입력은 22.2.0 이상에서 사용할 수 있습니다.

</PlatformBlock>

## 사용법

{Platform} 칩에 레이블을 추가한 다음, 레이아웃에 따라 아이콘, 유형, 크기, 선택 또는 제거 기능을 추가하십시오.

### 레이아웃

{Platform} 칩은 레이블 주변의 콘텐츠 템플릿을 지원합니다. <PlatformBlock for="WebComponents, React, Blazor">`prefix` 및 `suffix` 슬롯에 콘텐츠를 넣으십시오</PlatformBlock><PlatformBlock for="Angular">`igxPrefix` 및 `igxSuffix` 디렉티브로 콘텐츠를 표시하십시오</PlatformBlock> 레이블 앞뒤에 텍스트나 [아이콘](../layouts/icon.mdx)처럼 표시하려는 콘텐츠를 넣으십시오. 칩 안의 아이콘은 칩 크기를 따르므로, 큼, 보통, 작음의 세 가지 크기로도 제공됩니다.

레이블은 기본 슬롯에 넣으십시오. `start` 슬롯은 접두사 콘텐츠 앞에, `end` 슬롯은 접미사 콘텐츠 앞에 렌더링됩니다. 기본 선택 아이콘과 제거 아이콘을 대체하려면 `select` 및 `remove` 슬롯을 사용하십시오.

</PlatformBlock>

### 크기

{Platform} 칩은 세 가지 크기로 제공됩니다:

- 큼: 동작 트리거처럼 상호 작용이 필요한 시나리오에 적합합니다.
- 보통: 이메일 작성기의 수신자 필드처럼 짧은 영역에 적합합니다.
- 작음: 그리드 셀의 값처럼 데이터가 밀집된 시나리오에 적합합니다.

    private readonly List<string> Tags = new() { "Angular", "React", "Blazor" };

```ts
import { IBaseChipEventArgs } from 'igniteui-angular/chips';

public chips = [
  { id: 'angular', text: 'Angular' },
  { id: 'react', text: 'React' },
  { id: 'blazor', text: 'Blazor' },

public onRemove(event: IBaseChipEventArgs) {
  this.chips = this.chips.filter((chip) => chip.id !== event.owner.id);
}
```

### 칩 영역

<PlatformBlock for="Angular">

칩의 컬렉션을 정리하려면 <ApiLink pkg="core" type="ChipsArea" /> 컴포넌트를 사용하십시오.

<Sample src="/data-display/chip-area" showThemePicker height={165} alt="{Platform} 칩 영역 예제" />

칩 영역 안에서는 화살표 키로 칩 사이의 포커스를 이동합니다. 사용자가 `draggable` 칩을 다른 칩 위로 끌거나 <kbd>Shift</kbd> 키와 화살표 키를 누르면, 칩 영역은 새 순서와 함께 `reorder`를 발생시킵니다. 또한 선택된 칩과 함께 `selectionChange`도 발생시킵니다. 칩 영역은 칩 순서를 직접 바꾸지 않으므로, 새 순서는 `reorder` 핸들러에서 데이터에 적용하십시오.

```html
<igx-chips-area (reorder)="onReorder($event)">
  @for (chip of chips; track chip.id) {
    <igx-chip [id]="chip.id" [draggable]="true">{{ chip.text }}</igx-chip>
  }
</igx-chips-area>
```

```ts
import { IChipsAreaReorderEventArgs } from 'igniteui-angular/chips';

public onReorder(event: IChipsAreaReorderEventArgs) {
  this.chips = event.chipsArray.map((chip) => this.chips.find((item) => item.id === chip.id)!);
}
```

</PlatformBlock>

### 화면 읽기 프로그램 / ARIA

{Platform} 칩은 기본 의미 체계와 ARIA 속성을 통해 상태를 노출하며<PlatformBlock for="WebComponents, React, Angular">, 접근 가능한 이름은 콘텐츠에서 가져옵니다</PlatformBlock>.

<PlatformBlock for="WebComponents, React">

- 선택 컨트롤은 기본 `button`입니다. `selectable`가 설정되면 `aria-pressed`는 `selected` 상태를 반영합니다.
- `aria-pressed`가 이미 선택 상태를 전달하므로, 기본 선택 아이콘은 보조 기술에서 숨겨집니다.
- 기본 제거 아이콘은 `role="button"`, `tabindex="0"`, 기본값이 "remove chip"인 `aria-label`를 가진 별도의 컨트롤입니다.
- 비활성화된 칩은 기본 버튼을 비활성화하므로, 보조 기술은 칩을 사용할 수 없다고 보고합니다.

</PlatformBlock>

<PlatformBlock for="Blazor">

- 칩은 기본 `button`입니다. `Selectable`가 설정되면 `aria-pressed`는 `Selected` 상태를 반영합니다.
- 기본 선택 아이콘에는 `aria-label` "select chip"이 있습니다.
- `role="button"`와 `tabindex="0"`, 그리고 "remove chip"인 `aria-label`를 가진 기본 제거 아이콘은 칩의 버튼 안에 렌더링되므로 중첩된 컨트롤입니다.
- 아이콘이 버튼 안에 렌더링되므로, 칩의 접근 가능한 이름에 그 레이블이 포함됩니다. 예를 들어 "Chip remove chip"처럼 됩니다.
- 비활성화된 칩은 기본 버튼을 비활성화하므로, 보조 기술은 칩을 사용할 수 없다고 보고합니다.

</PlatformBlock>

<PlatformBlock for="Angular">

- 칩 호스트에는 `role="option"`가 있으며, `aria-selected`는 `selected` 상태를 반영합니다.
- `igx-chips-area` 요소에는 `role="listbox"`와 `aria-label` "chip area"가 있습니다.
- 기본 선택 아이콘과 제거 아이콘에는 접근 가능한 레이블이 있습니다.
- 비활성화된 칩은 탭 순서에서 제외되지만, 비활성화 상태를 노출하는 ARIA 속성은 없습니다.

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Angular">

[지역화](#현지화)에 나온 대로 기본 아이콘의 레이블을 바꿀 수 있습니다.

</PlatformBlock>

사용자의 책임:

- 모든 칩에 그것이 나타내는 항목을 식별하는 텍스트 레이블을 주십시오.
- remove 이벤트 핸들러에서 칩을 제거한 후에는, 포커스를 다음 칩처럼 논리적인 위치로 옮기십시오.
- 테마 색상을 재정의할 때 칩 배경과 텍스트 및 아이콘 사이의 충분한 대비를 유지하십시오.
- 칩의 스타일을 다시 지정할 때도 보이는 포커스 표시기를 유지하십시오.
- 작은 크기나 사용자 지정 `--ig-chip-size`을 사용할 때도 칩과 제거 컨트롤이 탭하기에 충분히 크도록 유지하십시오.

<PlatformBlock for="WebComponents, React, Blazor">

- [레이아웃](#레이아웃)에 설명된 대로, 사용자 지정 `remove` 슬롯 콘텐츠는 포커스를 받을 수 있고 레이블이 있도록 유지하십시오.

</PlatformBlock>

<PlatformBlock for="Angular">

- 사용자가 선택하는 칩은 `igx-chips-area` 안에 두어, 그 `option` 역할이 `listbox` 부모를 갖도록 하십시오.
- [레이아웃](#레이아웃)에 설명된 대로, 사용자 지정 선택 및 제거 아이콘 템플릿에 레이블을 붙이십시오.

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

- `igniteui-webcomponents` 7.4.1 이하를 기반으로 한 릴리스에서는 칩 요소에 설정된 `aria-label`가 선택 버튼에 전달되지 않으므로, 칩의 접근 가능한 이름이 바뀌지 않습니다. 대신 콘텐츠를 통해 칩의 이름을 지정하십시오.

</PlatformBlock>

- 비활성화 상태는 ARIA로 노출되지 않으므로, 화면 읽기 프로그램은 비활성화된 칩을 비활성화되었다고 알리지 않습니다. 사용자가 이 상태를 알아야 할 때는 근처 텍스트에서 상태를 설명하십시오.

## 문제 해결

변경이나 업그레이드 후에 칩이 예상대로 동작하거나 보이지 않을 때 이 섹션을 사용하십시오.

### 제거 아이콘을 클릭한 후에도 칩이 페이지에 남아 있는 이유는 무엇입니까?

remove 이벤트는 애플리케이션에 알리기만 합니다. [칩 제거](#제거-가능한-칩)에 나온 대로 이벤트 핸들러에서 칩을 제거하십시오.

<PlatformBlock for="WebComponents, React">

### 업그레이드 후 `::part(base)` 스타일이 바뀐 이유는 무엇입니까?

`igniteui-webcomponents` 7.3.1부터 `base` 파트는 칩 래퍼이고, 선택 버튼은 `action` 파트이며, 제거 컨트롤은 `remove` 파트에 있습니다. 버튼을 대상으로 하던 스타일은 `::part(action)`로 옮기십시오.

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Angular">

### 포커스 윤곽선 변수가 더 이상 적용되지 않는 이유는 무엇입니까?

</PlatformBlock>

<PlatformBlock for="WebComponents, React">

`--ig-chip-focus-outline-color`과 `--ig-chip-focus-selected-outline-color` 변수는 `igniteui-webcomponents` 7.3.0에서 `--ig-chip-focus-shadow-color`과 `--ig-chip-focus-selected-shadow-color`로 바뀌었습니다. 스타일의 변수 이름을 바꾸십시오.

</PlatformBlock>

<PlatformBlock for="Angular">

`igniteui-angular` 22.2.0에서는 `chip-theme`의 `$focus-outline-color`와 `$focus-selected-outline-color` 매개변수가 `$focus-shadow-color`와 `$focus-selected-shadow-color`로 바뀌었습니다. 스타일에서 매개변수와 일치하는 `--ig-chip-*` 변수의 이름을 바꾸십시오.

</PlatformBlock>
