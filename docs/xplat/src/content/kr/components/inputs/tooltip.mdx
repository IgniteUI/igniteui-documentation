# {Platform} 툴팁

{ProductName} 툴팁 컴포넌트는 특정 요소에 대한 툴팁을 표시하는 방법을 제공합니다. 툴팁은 보통 요소가 키보드 포커스를 받거나 마우스가 그 위에 올라갈 때, 요소와 관련된 정보를 표시하는 팝업입니다.

### 배치

<ApiLink pkg="core" type="Tooltip" />는 대상 요소를 기준으로 쉽게 배치할 수도 있습니다. <ApiLink pkg="core" type="Tooltip" member="placement" label="Placement" /> 속성과 함께 <PlatformBlock for="Angular,React,WebComponents"><ApiLink pkg="core" type="PopoverPlacement" /></PlatformBlock><PlatformBlock for="Blazor"><a href="https://staging.infragistics.com/api/blazor/IgniteUI.Blazor.Lite/0.0.1/enums/PopoverPlacement"><code>PopoverPlacement</code></a></PlatformBlock> 옵션 중 하나를 사용하면 됩니다.

<ApiLink pkg="core" type="Tooltip" member="placement" label="Placement" /> 속성을 설정하지 않으면 기본값은 `Bottom`이며, 이는 <ApiLink pkg="core" type="Tooltip" />를 대상 요소 아래에 배치합니다.

또한 <ApiLink pkg="core" type="Tooltip" member="sticky" label="Sticky" /> 속성을 사용하여 <ApiLink pkg="core" type="Tooltip" />를 "고정(sticky)"으로 만들 수 있습니다. 이렇게 하면 닫기 버튼이 추가되고, 사용자가 직접 닫을 때까지 — 닫기 버튼을 클릭하거나 `Esc` 키를 누를 때까지 — <ApiLink pkg="core" type="Tooltip" />가 보이게 유지됩니다. 이 동작은 기본 마우스 오버 동작을 재정의하여, 사용자가 대상 요소 위에서 마우스를 떼도 <ApiLink pkg="core" type="Tooltip" />가 사라지지 않게 합니다.

<ApiLink pkg="core" type="Tooltip" />에는 <ApiLink pkg="core" type="Tooltip" member="withArrow" label="WithArrow" /> 속성으로 구성할 수 있는 선택 사항인 화살표 표시기도 있습니다. 화살표는 툴팁을 앵커 요소와 시각적으로 연결하며, 그 위치는 툴팁의 <ApiLink pkg="core" type="Tooltip" member="placement" label="Placement" />를 기준으로 자동으로 조정됩니다.

<PlatformBlock for="WebComponents">

```html
<igc-button id="target-button">Hover me</igc-button>
<igc-tooltip anchor="target-button" placement="top-start" sticky with-arrow>
  Congrats you've hovered the button!
</igc-tooltip>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton id="target-button">Hover me</IgrButton>
<IgrTooltip anchor="target-button" placement="top-start" sticky withArrow={true}>
  Congrats you have hovered the button!
</IgrTooltip>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbButton id="target-button">Hover me</IgbButton>
<IgbTooltip Anchor="target-button" Placement="PopoverPlacement.TopStart" Sticky="true" DisableArrow="true">
  Congrats you have hovered the button!
</IgbTooltip>
```

</PlatformBlock>

### 추가 속성

앞에서 다룬 속성 외에도 <ApiLink pkg="core" type="Tooltip" /> 컴포넌트는 동작, 위치, 모양을 더 구성할 수 있는 다양한 추가 속성을 제공합니다.

|이름|타입|설명|
|--|--|--|
| <ApiLink pkg="core" type="Tooltip" member="open" label="Open" /> | boolean | 툴팁이 보이는지 여부를 결정합니다. |
| <ApiLink pkg="core" type="Tooltip" member="withArrow" label="WithArrow" /> | boolean | 툴팁에 화살표 표시기를 렌더링할지 여부를 결정합니다. |
| <ApiLink pkg="core" type="Tooltip" member="offset" label="Offset" /> | 숫자 | 툴팁과 <ApiLink pkg="core" type="Tooltip" member="anchor" label="Anchor" /> 사이의 픽셀 거리를 설정합니다. |

### 메서드

구성 가능한 속성 외에도 <ApiLink pkg="core" type="Tooltip" />는 사용할 수 있는 메서드 세 가지를 노출합니다:

|이름|설명|
|--|--|
| <ApiLink pkg="core" type="Tooltip" member="show" label="Show" /> | 툴팁이 이미 보이지 않는 상태라면 툴팁을 표시합니다. 대상이 제공되면 그것을 임시 <ApiLink pkg="core" type="Tooltip" member="anchor" label="Anchor" />로 설정합니다. |
| <ApiLink pkg="core" type="Tooltip" member="hide" label="Hide" /> | 툴팁이 이미 숨겨져 있지 않다면 숨깁니다. |
| <ApiLink pkg="core" type="Tooltip" member="toggle" label="Toggle" /> |  툴팁을 보이는 상태와 숨겨진 상태 사이에서 토글합니다. |

## 접근성 및 ARIA 지원

<ApiLink pkg="core" type="Tooltip" />는 접근성을 고려하여 만들어졌으며 다음 ARIA 어트리뷰트를 포함합니다:

- `role` - 툴팁이 기본 동작일 때는 `role="tooltip"`이(가) 적용됩니다. <ApiLink pkg="core" type="Tooltip" member="sticky" label="Sticky" /> 속성이 활성화되면 역할이 `status`(으)로 바뀝니다.
- `inert` - 가시성에 따라 동적으로 토글됩니다. 툴팁이 숨겨지면 inert가 됩니다.
- `aria-atomic` - true로 설정되어, 변경될 때 툴팁의 전체 콘텐츠가 알려지도록 합니다.
- `aria-live` - polite로 설정되어, 사용자가 유휴 상태일 때만 업데이트를 알리도록 화면 읽기 프로그램에 지시합니다.

## 스타일링

<ApiLink pkg="core" type="Tooltip" /> 컴포넌트는 스타일 지정에 사용할 수 있는 CSS 파트 두 개를 노출합니다:

|이름|설명|
|--|--|
| `base` | 툴팁 컴포넌트의 기본 래퍼입니다. |
| `top, right, bottom, left ...` | 툴팁 화살표를 담는 영역입니다. 파트 이름은 툴팁 배치 속성의 값과 일치합니다. |

```css
igc-tooltip::part(base) {
  background-color: var(--ig-primary-500);
  color: var(--ig-primary-500-contrast);
}

igc-tooltip::part(bottom) {
  border-bottom-color: var(--ig-primary-500);
}
```
