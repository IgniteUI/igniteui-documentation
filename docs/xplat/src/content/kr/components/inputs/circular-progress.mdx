# {Platform} 원형 진행률 개요

{ProductName} 원형 진행률 표시기 컴포넌트는 애플리케이션 프로세스가 변하는 모습을 시각적으로 보여 주는 표시기를 제공합니다. 원형 표시기는 상태가 바뀔 때 자신의 모양을 업데이트합니다.

## 사용법

<PlatformBlock for="WebComponents">

먼저 다음 명령을 실행하여 {ProductName}를 설치해야 합니다:

```cmd
npm install {PackageWebComponents}
```

그다음 다음과 같이 <ApiLink pkg="core" type="CircularProgress" />, 필요한 CSS를 import하고 모듈을 등록해야 합니다:


</PlatformBlock>

<PlatformBlock for="React">

```cmd
npm install igniteui-react
```

그다음 다음과 같이 <ApiLink pkg="core" type="CircularProgress" />, 필요한 CSS를 import하고 모듈을 등록해야 합니다:

### 진행률 유형

<ApiLink pkg="core" type="CircularProgress" member="variant" label="Variant" /> 속성을 사용하여 표시기의 유형을 설정할 수 있습니다. 원형 진행률 표시기 유형은 다섯 가지입니다 - **primary**(기본값), **error**, **success**, **info**, **warning**.

<PlatformBlock for="React">

```tsx

```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-circular-progress value="100" variant="success"></igc-circular-progress>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

```

</PlatformBlock>

### 그라데이션 진행률

단색 대신 색상 그라데이션을 사용하도록 진행률 표시줄을 사용자 지정할 수 있습니다. 이를 위해 `gradient` 슬롯과 그라데이션 정지점을 정의하는 <ApiLink pkg="core" type="CircularGradient" /> 컴포넌트를 사용하십시오.

<Sample src="/inputs/circular-progress-indicator/dynamic" height={200} alt="{Platform} 원형 진행률 동적 예제" />

<DocsAside type="info">
{ProductName} <ApiLink pkg="core" type="CircularProgress" />의 `gradient` 슬롯으로 정의된 각 <ApiLink pkg="core" type="CircularGradient" />에 대해 [SVG stop](https://developer.mozilla.org/en-US/docs/Web/SVG/Element/stop) 요소가 만들어집니다. `color`, `offset`, `opacity`로 전달된 값은 추가 검증 없이 SVG 요소의 stop-color, offset, stop-opacity로 설정됩니다.
</DocsAside>

```tsx
    </IgrCircularGradient>
</IgrCircularProgress>
```

## 스타일링

<ApiLink pkg="core" type="CircularProgress" /> 컴포넌트는 거의 모든 내부 요소에 대한 CSS 파트를 노출합니다:

|이름|설명|
|--|--|
| `svg`               | 진행률 SVG 요소입니다.                 |
| `gradient_start`     | 진행률 linear-gradient의 시작 색상입니다. |
| `gradient_end`       | 진행률 linear-gradient의 끝 색상입니다.   |
| `track`              | 진행률 링의 트랙 영역입니다.           |
| `fill`               | 진행률 표시기 영역입니다.              |
| `label`              | 진행률 레이블입니다.                       |
| `value`              | 진행률 레이블 값입니다.                 |
| `indeterminate`      | 진행률 불확정 상태입니다.         |
| `primary`            | 진행률 표시기 primary 상태입니다.     |
| `danger`             | 진행률 표시기 error 상태입니다.       |
| `warning`            | 진행률 표시기 warning 상태입니다.     |
| `info`               | 진행률 표시기 info 상태입니다.        |
| `success`            | 진행률 표시기 success 상태입니다.     |

이 CSS 파트를 사용하면 원형 진행률의 스타일을 거의 완전히 제어할 수 있습니다.

```css

igc-circular-progress {
  margin: 20px;
  --diameter: 50px;
}

igc-circular-progress::part(gradient_end),
igc-circular-progress::part(gradient_start) {
  stop-color: var(--ig-success-200);
}

igc-circular-progress::part(track) {
  stroke: var(--ig-gray-400);
}

```
