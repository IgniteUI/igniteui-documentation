# Rating

{ProductName} 평점은 사용자가 별 또는 사용자 지정 기호 척도에서 점수를 보고 선택할 수 있게 하는 폼 연결 컴포넌트입니다.

<PlatformBlock for="Angular">

Angular에서 평점은 `igniteui-webcomponents`의 `igc-rating` 웹 컴포넌트입니다. `IgcFormControlDirective`로 Angular 폼에 바인딩하십시오.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

평점은 반 별과 그 밖의 소수 값, 마우스 오버 미리 보기, 구별되는 기호의 단일 선택, 완전한 키보드 입력을 지원합니다.

</PlatformBlock>

평점은 레이블과 값으로 구성되며, 값은 척도의 숫자입니다. `label`를 설정하면 레이블이 표시됩니다. 기호 개수(기본값 5)를 바꾸려면 `max`를 설정하십시오.

`igc-rating` 요소는 레이블과 기호를 담는 슬라이더를 렌더링합니다. 프로젝션된 기호가 없으면 `max`의 각 점마다 별 하나를 렌더링합니다:

```text
igc-rating
└─ #shadow-root
   ├─ label[part="label"]                    // hidden when label isn't set
   └─ div[part="base"][role="slider"]
      ├─ div[part="symbols"]                 // aria-hidden="true"
      │  └─ slot[name="symbol"]              // projected igc-rating-symbol elements
      │     └─ igc-rating-symbol × max       // default stars when nothing is projected
      │        └─ #shadow-root
      │           ├─ div[part="symbol full"]   // star_filled icon, clipped to the value
      │           └─ div[part="symbol empty"]  // star_outlined icon, clipped to the rest
      └─ label[part="value-label"]
         └─ slot[name="value-label"]         // hidden when the slot is empty
```

각 `igc-rating-symbol`는 기본 슬롯을 `full` 파트에, `empty` 슬롯을 `empty` 파트에 렌더링합니다.

## 사용법

제품, 서비스, 경험에 대한 점수를 수집하거나 사용자가 바꿀 수 없는 평균 점수를 보여 줄 때 {Platform} 평점을 사용하십시오.

### 마우스 오버 미리 보기

사용자가 클릭하기 전에 포인터 아래 값까지 기호를 채우려면 `hoverPreview`를 설정하십시오. 포인터가 기호 밖으로 나가면 {Platform} 평점은 다시 자신의 값을 보여 줍니다. 읽기 전용이나 비활성화된 평점은 미리 보기를 보여 주지 않습니다.

<PlatformBlock for="WebComponents">

미리 보기가 켜져 있는 동안 평점은 포인터 아래 값과 함께 `igcHover`를 발생시킵니다:

```html
<igc-rating hover-preview label="Rate this article"></igc-rating>
<span id="hint"></span>
```

```ts
const rating = document.querySelector('igc-rating')!;
const hint = document.getElementById('hint')!;

rating.addEventListener('igcHover', (event) => {
  hint.textContent = `${event.detail} stars`;
});
```

</PlatformBlock>

<PlatformBlock for="React">

미리 보기가 켜져 있는 동안 평점은 포인터 아래 값과 함께 `onHover`를 호출합니다:

```tsx
<IgrRating
  hoverPreview={true}
  label="Rate this article"
  onHover={(e: CustomEvent<number>) => setHint(`${e.detail} stars`)}
/>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

미리 보기가 켜져 있는 동안 평점은 포인터 아래 값과 함께 `Hover`를 발생시킵니다:

```razor
<IgbRating HoverPreview="true" Label="Rate this article" Hover="OnHover" />

@code {
    private string Hint { get; set; }

    private void OnHover(IgbNumberEventArgs e)
    {
        Hint = $"{e.Detail} stars";
    }
}
```

</PlatformBlock>

<PlatformBlock for="Angular">

미리 보기가 켜져 있는 동안 평점은 포인터 아래 값과 함께 `igcHover`를 발생시킵니다:

```html
<igc-rating hover-preview label="Rate this article" (igcHover)="onHover($event)"></igc-rating>
```

```ts
public hint = '';

public onHover(event: Event) {
    this.hint = `${(event as CustomEvent<number>).detail} stars`;
}
```

</PlatformBlock>

### 레이아웃

`label` 속성은 기호 위에 보이는 레이블을 렌더링하고, 보조 기술을 위해 {Platform} 평점의 이름을 지정합니다. 현재 점수처럼 기호 옆에 사용자 지정 콘텐츠를 보여 주려면 `value-label` 슬롯에 넣으십시오:

<PlatformBlock for="WebComponents">

```html
<igc-rating value="4" label="Rate this product">
  <span slot="value-label">4 of 5</span>
</igc-rating>
```

값과 동기화되도록 `igcChange` 핸들러에서 슬롯 콘텐츠를 업데이트하십시오.

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrRating value={score} label="Rate this product" onChange={(e: CustomEvent<number>) => setScore(e.detail)}>
  <span slot="value-label">{score} of 5</span>
</IgrRating>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbRating @bind-Value="Score" Label="Rate this product">
    <span slot="value-label">@Score of 5</span>
</IgbRating>
```

</PlatformBlock>

<PlatformBlock for="Angular">

```html
<igc-rating [value]="score" label="Rate this product" (igcChange)="onScoreChange($event)">
  <span slot="value-label">{{ score }} of 5</span>
</igc-rating>
```

</PlatformBlock>

모든 {Platform} 평점에 접근 가능한 이름을 부여하고, 척도에 맞는 말로 그 값을 설명하십시오.

<PlatformBlock for="React,WebComponents,Angular">

평점에 보이는 `label`가 없으면 그것에 `aria-label`를 설정하거나, `igniteui-webcomponents` 7.4.1 이상에서는 `<label>` 요소를 그것과 연결하십시오. 보조 기술은 기본적으로 값을 "3 of 5"로 읽습니다. 이 텍스트를 바꾸려면 `valueFormat`를 설정하십시오. 평점은 `{0}`을 값으로, `{1}`을 `max`로 바꾸며, 이렇게 하면 텍스트를 지역화할 수도 있습니다.

</PlatformBlock>

</PlatformBlock>

### 비어 있음/채워짐 상태

{Platform} 평점의 `value`는 기호가 얼마나 채워져 있는지를 설정합니다. 기본값인 0은 모든 기호를 비워 보여 주고, `max`와 같은 값은 모든 기호를 채워 보여 줍니다.

<PlatformBlock for="WebComponents">

값과 최댓값을 어트리뷰트로 설정하고, 사용자가 선택한 값을 얻으려면 `igcChange`를 구독하십시오:

```html
<igc-rating value="3" max="10" label="Rate this movie"></igc-rating>
```

```ts
const rating = document.querySelector('igc-rating')!;

rating.addEventListener('igcChange', (event) => {
  console.log(`New rating: ${event.detail}`);
});
```

</PlatformBlock>

<PlatformBlock for="React">

값을 상태에 보관하고 `onChange` 핸들러에서 업데이트하십시오:

```tsx
import { useState } from 'react';
import { IgrRating } from 'igniteui-react';

export default function MovieRating() {
  const [score, setScore] = useState(3);

  return (
    <IgrRating
      value={score}
      max={10}
      label="Rate this movie"
      onChange={(e: CustomEvent<number>) => setScore(e.detail)}
    />
  );
}
```

## 접근성

{Platform} 평점은 슬라이더입니다. 사용자는 Tab 키로 도달하고, 화살표 키로 값을 바꾸며, ARIA 어트리뷰트를 통해 값을 들을 수 있습니다.

### 키보드 상호 작용

{Platform} 평점은 하나의 탭 정지 지점입니다. 포커스를 받는 것은 그 안의 슬라이더 요소인 `base` 파트뿐이기 때문입니다. 비활성화된 평점은 탭 순서에서 빠집니다. 읽기 전용 평점은 탭 순서에 남지만 다음 키를 무시하므로, 페이지 스크롤 같은 기본 브라우저 동작이 그대로 유지됩니다.

| 키 | 동작 |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | 다음 또는 이전 포커스 가능 요소로 포커스를 옮깁니다. 평점은 이 키들을 처리하지 않으므로 포커스를 가두지 않습니다. |
| <kbd>오른쪽 화살표</kbd> | 값을 한 단계 증가시킵니다. 오른쪽에서 왼쪽으로 쓰는 레이아웃에서는 감소시킵니다. |
| <kbd>왼쪽 화살표</kbd> | 값을 한 단계 감소시킵니다. 오른쪽에서 왼쪽으로 쓰는 레이아웃에서는 증가시킵니다. |
| <kbd>위 화살표</kbd> | 값을 한 단계 증가시킵니다. |
| <kbd>아래 화살표</kbd> | 값을 한 단계 감소시킵니다. |
| <kbd>Home</kbd> | 클릭으로 선택할 수 있는 가장 낮은 값인 한 단계로 값을 설정합니다. |
| <kbd>End</kbd> | 값을 최댓값으로 설정합니다. |

{Platform} 평점은 `keydown`에서 다음 키를 처리합니다:

- 기본 동작을 막으므로, 평점에 포커스가 있는 동안 화살표 키, Home, End가 페이지를 스크롤하지 않습니다.
- 누르고 있는 키는 그 동작을 반복합니다.
- Shift, Ctrl, Alt, Meta와 함께 누른 키는 아무 동작도 하지 않습니다.
- 값은 0과 최댓값 사이에 머뭅니다. 값을 경계 너머로 옮기는 키는 값을 유지하며 이벤트를 발생시키지 않습니다.
- 값을 바꾸는 각 키는 change 이벤트를 발생시킵니다.

포인터를 사용할 때 클릭은 포인터 아래 값을 다음 단계로 올림하여 선택합니다. 읽기 전용이나 비활성화된 평점은 클릭을 무시합니다.

### 화면 읽기 프로그램 / ARIA

{Platform} 평점은 포커스를 받을 수 있는 요소 하나, 즉 `base` 파트를 `slider` 역할로 렌더링합니다. 그 `tabindex`는 `0`이며, 평점이 비활성화되면 `-1`이 됩니다. 또한 다음 값 어트리뷰트를 가집니다:

| 어트리뷰트 | 값 |
| --- | --- |
| `aria-valuemin` | `0` |
| `aria-valuemax` | 최댓값 |
| `aria-valuenow` | `4.3`와 같은 소수를 포함한 값 |
| `aria-valuetext` | 기본적으로 "3 of 5", 또는 `valueFormat` 텍스트 |

<PlatformBlock for="React,WebComponents,Angular">

`igniteui-webcomponents` 7.3.0 이상에서는 슬라이더가 `aria-disabled`와 `aria-readonly`도 설정하여 비활성화 상태와 읽기 전용 상태를 노출합니다. 7.4.1 이상에서는 슬라이더가 다음 중 첫 번째 것에서 접근 가능한 이름을 가져옵니다:

1. 호스트의 `aria-labelledby` 어트리뷰트입니다.
2. `for`를 통해 바인딩되거나 평점을 감싸는 `<label>` 요소입니다. 레이블을 클릭하면 슬라이더에 포커스가 갑니다.
3. `label` 속성입니다. 보이는 레이블을 렌더링하며, 슬라이더는 `aria-labelledby`를 통해 이를 참조합니다.
4. 호스트의 `aria-label` 어트리뷰트입니다. `label` 속성이 설정되면 슬라이더는 이를 무시합니다.

</PlatformBlock>

<PlatformBlock for="Blazor">

`Label` 속성은 보이는 레이블을 렌더링하며, 슬라이더는 `aria-labelledby`를 통해 이를 참조하여 접근 가능한 이름을 얻습니다.

</PlatformBlock>

{Platform} 평점은 보조 기술에 대해 다음과 같이 동작합니다:

- `symbols` 파트는 `aria-hidden="true"`를 설정하므로, 프로젝션된 아이콘과 이모지를 포함한 기호는 숨겨지며 텍스트 대체 수단이 필요하지 않습니다. 값은 `aria-valuenow`와 `aria-valuetext`를 통해서만 보조 기술에 전달됩니다.
- `value-label` 슬롯은 슬라이더 안에 렌더링됩니다. 화면 읽기 프로그램은 `aria-valuetext`에서 값을 읽으므로, 슬롯 콘텐츠 대신 `valueFormat`로 값을 설명하십시오.
- 평점은 라이브 영역을 사용하지 않습니다. 바뀐 값은 슬라이더 어트리뷰트를 통해서만 보조 기술에 전달됩니다.
- 평점은 `aria-invalid`을 설정하지 않으므로, 사용자 지정 유효성 검사 메시지는 유효하지 않은 상태로 노출되지 않습니다.

사용자의 책임:

- 모든 평점에 `label` 속성으로 이름을 지정하십시오<PlatformBlock for="React,WebComponents,Angular">, 연결된 `<label>` 요소, 또는 `aria-label`</PlatformBlock>. [레이아웃](#레이아웃)을 참조하십시오.
- "3 of 5"가 척도를 설명하지 않거나, 페이지가 다른 언어를 사용할 때는 `valueFormat`를 설정하십시오.
- 사용자 지정 기호를 사용할 때는 채워진 기호와 빈 기호가 색상만이 아니라 모양이나 채움에서도 다르게 하고, [1.4.11 비텍스트 대비](https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast)가 요구하는 대로 배경과 최소 3:1의 대비 비율을 유지하십시오.
- `base` 파트의 스타일을 다시 지정할 때는 보이는 포커스 표시기를 유지하십시오.
- 포인터 대상을 충분히 크게 유지하십시오. 각 값은 기호 하나만큼 넓은 대상이며, 0.5 단계일 때는 기호 반 개만큼 넓은 대상입니다. 작음 크기는 18px 기호를 렌더링하는데, 이는 [2.5.8 대상 크기(최소)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)의 CSS 픽셀 24×24보다 작으므로, 포인터와 터치 입력에는 보통 또는 큼 크기를 선호하십시오.
- 마우스 오버 미리 보기에만 정보를 넣지 마십시오. 키보드 사용자는 그것을 보지 못하기 때문입니다.
- 사용자 지정 유효성 검사 메시지로 평점을 검증할 때는, 평점이 `aria-invalid`를 설정하지 않으므로 [3.3.1 오류 식별](https://www.w3.org/WAI/WCAG21/Understanding/error-identification)이 요구하는 대로 평점 옆에 텍스트로도 메시지를 보여 주십시오.

[WAI-ARIA 슬라이더 패턴](https://www.w3.org/WAI/ARIA/apg/patterns/slider/)과의 차이점:

- <kbd>Home</kbd>은 값을 `aria-valuemin`(0)이 아니라 한 단계로 설정합니다. 0에 도달하려면 <kbd>Arrow Down</kbd>를 사용하십시오.
- 평점은 패턴이 선택 사항 키로 나열하는 <kbd>Page Up</kbd>과 <kbd>Page Down</kbd>을 지원하지 않습니다.

## 문제 해결

{Platform} 평점이 예상대로 동작하지 않을 때 이 답변들을 사용하십시오.

### 값을 설정하면 change 이벤트가 발생하지 않는 이유는 무엇입니까?

{Platform} 평점은 사용자 입력, 즉 클릭이나 키에 대해서만 change 이벤트를 발생시킵니다. 코드에서 값을 설정하거나 단계 메서드를 호출하면 이벤트 없이 값이 바뀌므로, 값을 설정하는 곳에서 자신의 상태를 업데이트하십시오.

### 현재 값을 클릭해도 평점이 재설정되지 않는 이유는 무엇입니까?

{Platform} 평점은 `allowReset`를 설정하지 않는 한, 현재 값을 클릭해도 값을 유지합니다. `igniteui-webcomponents` 4.7.0 이전에는 현재 값을 클릭하면 항상 평점이 재설정되었습니다. 업그레이드 후에도 그 동작을 유지하려면 `allowReset`를 설정하십시오.

### 마우스 오버 이벤트가 발생하지 않는 이유는 무엇입니까?

{Platform} 평점은 `hoverPreview`가 켜져 있을 때만 마우스 오버 이벤트를 발생시키며, 읽기 전용이거나 비활성화된 평점에서는 발생시키지 않습니다. 이벤트를 받으려면 `hoverPreview`를 설정하십시오.
