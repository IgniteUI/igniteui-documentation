## {Platform} 마스크 입력 개요

{ProductName} 마스크 입력은 구성 가능한 규칙에 따라 개발자가 사용자 입력을 제어하고 보이는 값의 형식을 지정할 수 있게 하는 입력 필드입니다. 다양한 입력 옵션을 제공하며, 사용과 구성이 쉽습니다.

### 마스크 규칙
아래 표는 지원되는 기본 제공 마스크 규칙을 보여 줍니다:

| 마스크 문자 | 설명 |
| :--- | :--- |
| 0 | 숫자 문자 [0-9]. 입력이 필수입니다. |
| 9 | 숫자 문자 [0-9]. 입력이 선택 사항입니다. |
| # | 숫자 문자 [0-9], 플러스(+) 또는 마이너스(-) 기호. 입력이 필수입니다. |
| L | 문자 문자. 입력이 필수입니다. |
| ? | 문자 문자. 입력이 선택 사항입니다. |
| A | 영숫자(문자 또는 숫자) 문자. 입력이 필수입니다. |
| a | 영숫자(문자 또는 숫자) 문자. 입력이 선택 사항입니다. |
| & | 키보드의 임의 문자. 입력이 필수입니다. |
| C | 키보드의 임의 문자. 입력이 선택 사항입니다. |
| \ | 마스크 플래그를 이스케이프하여 문자 그대로의 문자로 만듭니다. |

이 플래그는 컴포넌트 유효성 검사에도 참여합니다. 즉, 필수 위치 중 일부만 채워져 있으면 입력이 유효하지 않게 됩니다(아무 위치도 채워지지 않은 빈 값은 여전히 <ApiLink pkg="core" type="MaskInput" member="required" label="required" />의 책임입니다). 이는 독립형 입력과 폼에 포함된 입력 모두에 적용됩니다.

### 마스크 적용하기

마스크를 적용하는 것은 매우 간단합니다. 미리 정해진 패턴을 입력의 <ApiLink pkg="core" type="MaskInput" member="mask" label="Mask" /> 속성에 제공하기만 하면 됩니다.

아래 예제에서는 내선 번호가 있는 전화번호에 마스크를 적용하겠습니다.

<PlatformBlock for="WebComponents">

```html
<igc-mask-input id="mask-input" mask="(####) 00-00-00 Ext. 9999">
    <igc-icon name="phone" slot="prefix"></igc-icon>
    <span slot="helper-text">Phone number</span>
</igc-mask-input>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrMaskInput mask="(####) 00-00-00 Ext. 9999">
    <span slot="prefix">
        <IgrIcon ref={iconPhoneRef} name="phone" collection="material"></IgrIcon>
    </span>
    <span slot="helper-text">Phone number</span>
</IgrMaskInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbMaskInput @ref="MaskInputRef" Mask="(####) 00-00-00 Ext. 9999">
    <IgbIcon IconName="phone" Collection="material" slot="prefix"></IgbIcon>
    <span slot="helper-text">Phone number</span>
</IgbMaskInput>
```

</PlatformBlock>

### 프롬프트 문자

개발자는 마스크의 채워지지 않은 부분에 쓰이는 프롬프트 기호를 사용자 지정할 수 있습니다. 이를 위해서는 <ApiLink pkg="core" type="MaskInput" member="prompt" label="Prompt" /> 속성에 원하는 문자를 제공하기만 하면 됩니다:

<PlatformBlock for="WebComponents">

```html
<igc-mask-input id="mask-input" mask="(####) 00-00-00 Ext. 9999" prompt="-"></igc-mask-input>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrMaskInput mask="(####) 00-00-00 Ext. 9999" prompt="-"></IgrMaskInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbMaskInput @ref="MaskInputRef" Mask="(####) 00-00-00 Ext. 9999" Prompt="-"></IgbMaskInput>
```

</PlatformBlock>

기본적으로 `prompt` 문자는 **밑줄**입니다.

### 플레이스홀더

개발자는 네이티브 input의 placeholder 어트리뷰트와 같은 역할을 하는 <ApiLink pkg="core" type="MaskInput" member="placeholder" label="Placeholder" /> 속성을 활용할 수도 있습니다. 플레이스홀더에 값을 제공하지 않으면 마스크 값이 그대로 사용됩니다.

<PlatformBlock for="WebComponents">

```html
<igc-mask-input id="mask-input" mask="00/00/0000" placeholder="dd/MM/yyyy"></igc-mask-input>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrMaskInput mask="00/00/0000" placeholder="dd/MM/yyyy"></IgrMaskInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbMaskInput @ref="MaskInputRef" Mask="00/00/0000" Placeholder="dd/MM/yyyy"></IgbMaskInput>
```

</PlatformBlock>

### 값 모드

<ApiLink pkg="core" type="MaskInput" />는 <ApiLink pkg="core" type="MaskInput" member="valueMode" label="ValueMode" /> 속성을 노출하며, 특정 마스크가 적용되었을 때 폼에 바인딩할 입력 값(형식이 지정된 값 또는 원시 값)을 `raw`와 `withFormatting` 옵션 중에서 선택하도록 설정할 수 있게 합니다. 기본적으로 <ApiLink pkg="core" type="MaskInput" member="valueMode" label="ValueMode" />는 `raw`로 설정되어 있습니다. 아래 예제에서 직접 확인해 보십시오:

## 스타일링

<ApiLink pkg="core" type="MaskInput" /> 컴포넌트는 거의 모든 내부 요소에 대한 CSS 파트를 노출합니다. 아래 표는 노출된 모든 CSS 파트를 나열합니다:

|이름|설명|
|--|--|
| `container` | 모든 주요 입력 요소를 담는 기본 래퍼입니다. |
| `input` | 네이티브 input 요소입니다. |
| `label` | 네이티브 label 요소입니다. |
| `prefix` | 접두사 래퍼입니다. |
| `suffix` | 접미사 래퍼입니다. |
| `helper-text` | 도움말 텍스트 래퍼입니다. |

```css
igc-mask-input::part(input) {
  background-color: var(--ig-primary-100);
  border-color: var(--ig-secondary-500);
  box-shadow: none;
}

igc-mask-input::part(input)::placeholder {
  color: var(--ig-primary-100-contrast);
}
```

## 가정 및 제한 사항

- 마스크 입력은 항상 **text** 유형의 input이므로, _type_ 어트리뷰트를 노출하지 않습니다.
- 실행 취소/다시 실행 동작은 현재 지원되지 않습니다.
