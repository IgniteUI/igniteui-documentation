# QR 코드 컴포넌트 <Badge variant="new" />

## 사용법

`value`를 아무 문자열로 설정하면 스캔 가능한 QR 코드가 렌더링됩니다. 컴포넌트는 가장 간결한 인코딩 모드(숫자, 영숫자 또는 바이트)와 값을 담을 수 있는 가장 작은 QR 버전을 선택합니다. `value`를 지우면 SVG가 제거됩니다.

### 오류 정정

`errorLevel`을 사용하여 `L`, `M`(기본값), `Q`, `H` 오류 정정 수준 중에서 선택하십시오. 수준이 높을수록 손상되거나 가려진 코드를 더 많이 복구할 수 있지만 코드는 더 촘촘해집니다. 모듈 크기를 예측 가능하게 해야 할 때는 `version`을 사용해 `1`에서 `40` 사이의 QR 버전을 고정하십시오. 그렇지 않으면 설정하지 않은 상태로 두어 `value`를 담을 수 있는 가장 작은 버전을 사용하십시오.

```html
  version="4"
  error-level="H">
</igc-qr-code>
```

### 가운데 로고

`logoSrc`를 설정하면 코드의 가운데에 이미지가 렌더링되며, 컴포넌트는 그 아래의 모듈을 가립니다. `logoSize`는 가장 큰 안전 로고 영역에 대한 비율로 로고 크기를 설정하며, 이 비율은 `0`부터 `1`까지입니다. 이 안전 영역은 `H` 수준에서 코드의 9%입니다. `logoMargin`은 로고 주변에 픽셀 단위의 여백을 추가합니다.

로고는 현재 `errorLevel`이 허용하는 범위를 넘어 코드를 가리지 않습니다. 기본 `M` 수준에서는 약 `0.44`를 넘는 `logoSize` 값도 같은 제한된 크기로 렌더링되므로, 가장 큰 로고를 원하면 `errorLevel`를 `H`로 설정하십시오.

`logoSrc`은 일반 URL과 `data:image/*` URI를 받습니다. 안전하지 않은 스킴(예: `javascript:` 또는 `vbscript:`)을 가진 소스와 이미지가 아닌 `data:` URI는 거부되며, 로고는 렌더링되지 않습니다.

```html
  logo-size="0.5"
  logo-margin="4">
</igc-qr-code>
```

</PlatformBlock>

### 내보내기

`toImage()`을 호출하면 QR 코드를 PNG, JPEG, WebP, SVG 파일로 내보내고, `toBlob()`를 호출하면 SVG `Blob`로 가져올 수 있습니다. 두 메서드 모두 테마 색상을 해석하고 로고를 인라인으로 넣으므로, 내보낸 결과는 렌더링된 코드와 일치합니다.

```ts
const qrCode = document.querySelector('igc-qr-code') as IgcQrCodeComponent;

// Downloads a 512×512 PNG from a 256px QR code.
await qrCode.toImage({ format: 'png', scale: 2, fileName: 'my-qr-code', download: true });
```

</PlatformBlock>

### 사용 여부

**사용할 때:** QR 코드는 인쇄물이나 정적 화면에서 페이지 열기, 앱 다운로드, 링크 확인처럼 디지털 동작으로 사용자를 빠르게 이어 줍니다.

### Sass 테마 지정

`qr-code-theme()`로 테마를 만들고 `tokens` 믹스인에 전달하십시오.

```scss
@use "igniteui-theming/sass/themes" as *;

$custom-qr-code-theme: qr-code-theme(
  $background: #ffffff,
  $dark-color: #1a1a2e,
  $corner-square-color: #c0392b,
  $corner-dot-color: #1a1a2e
);

:root {
  @include tokens($custom-qr-code-theme);
}
```

### CSS 변수

Sass 빌드 단계 없이 로컬 스타일이 필요하면 컴포넌트 CSS 변수를 직접 설정하십시오.

```css
igc-qr-code {

  fill: var(--ig-success-500);
}
```

## 접근성

{Platform} QR 코드는 화면 읽기 프로그램이 SVG의 `<title>`를 통해 읽는 정적 그래픽입니다.

### 키보드 상호 작용

QR 코드는 포커스를 받을 수 없으며 키보드 입력에 반응하지 않습니다.

### 화면 읽기 프로그램 / ARIA

렌더링된 `<svg>`에는 `role="img"`와 화면 읽기 프로그램이 읽는 `<title>`가 있습니다. 제목의 기본값은 `QR code: <value>`입니다. 더 의미 있는 문구를 읽히려면 `aria-label`을 설정하십시오.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-qr-code
  value="https://www.infragistics.com/products"
  aria-label="Scan to visit our product page">
</igc-qr-code>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrQrCode
  value="https://www.infragistics.com/products"
  ariaLabel="Scan to visit our product page">
</IgrQrCode>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbQrCode
  Value="https://www.infragistics.com/products"
  AriaLabel="Scan to visit our product page">
</IgbQrCode>
```

</PlatformBlock>

### 접근성 준수

Infragistics는 [접근성 준수](../interactivity/accessibility-compliance.mdx) 항목에서 Section 508 및 WCAG 2.1 지침 영역에 대한 {ProductName} 접근성 지원을 문서화합니다.

| 기준 | 컴포넌트가 준수하는 방식 |
| -- | -- |
| [1.1.1 비텍스트 콘텐츠](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content) | SVG `<title>`는 텍스트 대체 수단을 제공하며, 이는 `aria-label`에서 가져오거나 `value`로부터 도출됩니다. |
| [1.4.11 비텍스트 대비](https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast) | 흰색 배경 위의 기본 검은색 모듈은 그래픽 객체에 대한 3:1 대비 비율을 넘습니다. |
| [4.1.2 이름, 역할, 값](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | SVG는 `<title>`를 접근 가능한 이름으로 하여 `role="img"`을 노출합니다. |

사용자의 책임:

- 시각적 사용자가 스캔 후 무슨 일이 일어날지 알 수 있도록, QR 코드에 짧고 보이는 행동 유도 문구를 함께 제공하십시오.
- 인코딩된 `value`가 불투명할 때(예: 토큰이나 짧은 식별자), 읽히는 텍스트가 의미 있도록 `aria-label`을 제공하십시오.
- CSS 변수를 재정의할 때는 스캐너가 코드를 안정적으로 읽을 수 있도록 모듈 색상과 배경 사이의 대비를 충분히 유지하십시오.

## 문제 해결

{Platform} QR 코드 문제 해결 안내는 흔한 통합 및 렌더링 문제를 문제 → 원인 → 해결 형식으로 설명합니다.

### QR 코드가 스캔되지 않는 이유는 무엇입니까?

모듈과 배경 사이의 대비가 너무 낮거나, 화면에서 코드가 너무 작거나, 여백 영역이 너무 작을 수 있습니다. `white`의 `black` 색상을 기본값으로 되돌리고, `size`을 늘리며, 안정적인 스캔을 위해 `margin`을 최소 `4` 모듈 이상으로 사용하십시오.

### 설정한 logoSize보다 로고가 작은 이유는 무엇입니까?

로고는 현재 `errorLevel`의 안전 영역으로 제한됩니다. 가장 큰 로고를 허용하려면 `errorLevel`를 `H`로 설정하십시오.

### 로고가 나타나지 않는 이유는 무엇입니까?

`logoSrc`가 거부된 소스(안전하지 않은 스킴 또는 이미지가 아닌 `data:` URI)를 사용하거나, 이미지를 불러오지 못했습니다. 유효한 이미지 URL이나 `data:image/*` URI를 사용하십시오. 이후에 유효한 소스를 할당하면 로고가 렌더링됩니다.

### QR 코드가 다크 테마로 자동 전환되지 않은 이유는 무엇입니까?

밝은 글씨에 어두운 배경의 코드는 안정적으로 스캔되지 않으므로, QR 코드 색상은 전역 밝은/어두운 테마에 따라 반전되지 않습니다. UI의 다크 변형에 맞게 바꾸려면 `--ig-qr-code-background`과 `--ig-qr-code-dark-color`를 명시적으로 설정하십시오.

## 알려진 제한 사항

{Platform} QR 코드에는 다음과 같은 제한 사항이 있습니다.

- QR 코드에는 슬롯이나 이벤트가 없습니다.
- QR 코드의 시각 구조는 고정된 표준 레이아웃을 따르며, 오른쪽에서 왼쪽으로 쓰는 맥락에서도 좌우 반전되지 않습니다.

## FAQ

<Faq>
  <FaqItem question="QR 코드에는 어떤 데이터를 인코딩할 수 있습니까?" indicatorPosition="end">
    `value` 속성은 어떤 문자열이든 받습니다. 흔한 용도로는 URL, 일반 텍스트, 결제 참조, 일회용 설정 토큰, Wi-Fi 자격 증명, vCard 페이로드가 있습니다. 컴포넌트는 입력에 맞는 가장 간결한 인코딩 모드(숫자, 영숫자 또는 바이트)를 자동으로 선택합니다.
  </FaqItem>

  <FaqItem question="QR 코드를 렌더링하려면 인터넷 연결이나 외부 라이브러리가 필요합니까?" indicatorPosition="end">
    아니요. QR 코드 컴포넌트는 `value` 문자열로부터 SVG를 클라이언트에서 완전히 생성하며, 외부 QR 생성 라이브러리에 의존하지 않습니다. 유일한 네트워크 요청은 URL에서 불러오는 가운데 로고 이미지를 위한 것입니다.
  </FaqItem>

  <FaqItem question="코드를 깨뜨리지 않으면서 가운데 로고를 얼마나 크게 만들 수 있습니까?" indicatorPosition="end">
    `logoSize` 비율(기본값 `0.4`)은 가장 큰 안전 로고 영역에 대한 비율이며, 이 영역은 `H` 오류 정정 수준에서 코드의 9%입니다. QR 코드는 현재 `errorLevel`의 안전 영역으로 로고를 제한하므로 코드가 스캔 가능한 상태를 유지합니다. 가장 큰 로고를 허용하려면 `errorLevel`를 `H`로 설정하십시오.
  </FaqItem>
