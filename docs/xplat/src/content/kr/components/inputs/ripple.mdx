## 사용법


<PlatformBlock for="WebComponents">


먼저 다음 명령을 실행하여 {ProductName}를 설치해야 합니다:

```cmd
npm install {PackageWebComponents}
```

<ApiLink pkg="core" type="Ripple" />를 사용하기 전에 다음과 같이 등록해야 합니다:

```ts
import { defineComponents, IgcRippleComponent } from "igniteui-webcomponents";
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcRippleComponent);
```

{ProductName}에 대한 전체 소개는 [**시작하기**](../general-getting-started.mdx) 항목을 읽어 보십시오.

</PlatformBlock>



<PlatformBlock for="React">


먼저 다음 명령을 실행하여 해당 {ProductName} npm 패키지를 설치해야 합니다:

```cmd
npm install igniteui-react
```

그다음 다음과 같이 <ApiLink pkg="core" type="Ripple" />와 필요한 CSS를 import해야 합니다:

```tsx
import { IgrRipple } from 'igniteui-react';
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

</PlatformBlock>



<PlatformBlock for="Blazor">



{ProductName} 서비스를 등록합니다:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

<ApiLink pkg="core" type="Ripple" />의 클라이언트 리소스 모듈인 <ApiLink pkg="core" type="RippleModule" /> 등록은 **선택 사항**입니다. 컴포넌트는 처음 렌더링될 때 리소스를 로드합니다. `builder.Services.AddIgniteUIBlazor(typeof(IgbRippleModule))`에 나열하면 리소스를 미리 로드하거나 클라이언트에서만 생성되는 요소를 지원할 수 있습니다([컴포넌트 모듈](../general-getting-started.mdx#컴포넌트-모듈) 참조).

<ApiLink pkg="core" type="Ripple" /> 컴포넌트에 스타일을 적용하려면 추가 CSS 파일도 연결해야 합니다. 다음 내용을 애플리케이션의 호스트 페이지에 넣어야 합니다(독립 실행형 Blazor WebAssembly 또는 Blazor Hybrid 앱에서는 **wwwroot/index.html**, Blazor Server 앱에서는 **Pages/_Host.cshtml**, Blazor Web App에서는 **Components/App.razor**):

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```


</PlatformBlock>


<ApiLink pkg="core" type="Ripple" />를 사용하기 시작하는 가장 간단한 방법은 다음과 같습니다:

<PlatformBlock for="WebComponents">

```html
<igc-button>
  <igc-ripple></igc-ripple>
  Ripple Button
</igc-button>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton>
  <IgrRipple></IgrRipple>
  <span>Ripple Button</span>
</IgrButton>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbButton Variant="@ButtonVariant.Contained">
    Ripple Button
    <IgbRipple></IgbRipple>
</IgbButton>
```

</PlatformBlock>

CSS `position` 속성이 `static` 이외의 다른 값으로 설정되어 있다면, <ApiLink pkg="core" type="Ripple" /> 컴포넌트를 어떤 웹 요소에든 추가할 수 있습니다.

## 예제

### Color

`--color` CSS 속성을 유효한 CSS 색상으로 설정하면 물결의 색상을 바꿀 수 있습니다:

```css
igc-ripple {
  --color: olive;
}
```
