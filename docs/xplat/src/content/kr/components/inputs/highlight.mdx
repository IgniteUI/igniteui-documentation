# {Platform} 강조 표시 개요

{ProductName} 강조 표시는 사용자에게 더 잘 드러나도록 페이지 콘텐츠의 일부를 강조 표시하는 데 사용됩니다. 다른 컴포넌트와 함께 사용하여 더 대화형이고 매력적인 사용자 경험을 만들 수 있는 가벼운 컴포넌트입니다.

<igc-divider></igc-divider>

## 사용법

<ApiLink pkg="core" type="Highlight" /> 컴포넌트를 사용하려면 검색하려는 콘텐츠를 그 태그로 감싸기만 하면 됩니다. 컴포넌트는 <PlatformBlock for="WebComponents">`<igc-highlight>`</PlatformBlock><PlatformBlock for="React">`<IgrHighlight>`</PlatformBlock><PlatformBlock for="Blazor">`<IgbHighlight>`</PlatformBlock> 태그 안에 중첩된 모든 요소의 콘텐츠를 검색하고, 지정된 문자열의 모든 일치 항목을 강조 표시합니다.

<DocsAside type="note">
<ApiLink pkg="core" type="Highlight" /> 컴포넌트는 DOM 텍스트 노드만 검색합니다. 입력 값이나 CSS `content` 속성으로 설정된 콘텐츠는 검색하지 않습니다.
</DocsAside>

### 대소문자 구분 일치

<ApiLink pkg="core" type="Highlight" /> 컴포넌트는 <ApiLink type="BaseSearchInfo" member="caseSensitive" label="case-sensitive" /> 어트리뷰트도 노출합니다. 기본값은 `false`이며, 이는 대소문자를 구분하지 않는 일치를 활성화합니다. 이를 `true`로 설정하면 대소문자를 구분하는 일치를 활성화할 수 있습니다.

다음 스니펫은:

<PlatformBlock for="WebComponents">
```html
<igc-highlight search-text='lorem' case-sensitive='true'>
    <p>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</p>
</igc-highlight>
```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
<IgrHighlight search-text='lorem' case-sensitive={true}>
    <p>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</p>
</IgrHighlight>
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```razor
<IgbHighlight SearchText="lorem" CaseSensitive="true">
    <p>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</p>
</IgbHighlight>
```
</PlatformBlock>

검색 텍스트 "lorem"이 소문자인 반면 콘텐츠의 텍스트는 대문자 **L**이 있는 **Lorem**이므로, 0개의 일치 항목을 반환합니다.

### 검색 입력과 함께 강조 표시 사용하기

가장 일반적인 사용 사례는 <ApiLink pkg="core" type="Highlight" /> 컴포넌트를 검색 <ApiLink pkg="core" type="Input" /> 컴포넌트에 바인딩하여, 사용자가 입력하는 동안 검색 일치 항목을 실시간으로 강조 표시하는 것입니다.

두 컴포넌트를 함께 바인딩하려면 <ApiLink pkg="core" type="Input" /> 컴포넌트의 `igcInput` 이벤트를 구독하고, 이벤트가 발생할 때마다 <ApiLink pkg="core" type="Highlight" /> 컴포넌트의 <ApiLink type="BaseSearchInfo" member="searchText" label="search-text" /> 어트리뷰트를 입력 값으로 설정하면 됩니다(표준 `input` 이벤트를 사용할 수도 있습니다).

<PlatformBlock for="WebComponents">
먼저 속성을 조작하려면 <ApiLink type="Highlight" /> 컴포넌트에 액세스해야 합니다:

```ts
const highlight = document.querySelector('igc-highlight') as IgcHighlightComponent;
```

그다음 `igcInput` 이벤트가 발생할 때마다 검색 텍스트를 업데이트하는 함수를 만드십시오:

```ts
const onInput = ({ detail }: CustomEvent<string>) => {
    highlight.searchText = detail;
};

document.querySelector('igc-input')?.addEventListener('igcInput', onInput);
```

```html
<igc-input label="Search"></igc-input>
<igc-highlight>
    <p>
      Lorem ipsum dolor sit, amet consectetur adipisicing elit. Quae doloribus odit id excepturi ipsum provident eaque dignissimos beatae!
    </p>
</igc-highlight>
```

</PlatformBlock>

<PlatformBlock for="React">
먼저 속성을 조작하려면 <ApiLink type="Highlight" /> 컴포넌트에 액세스해야 합니다. 가장 쉬운 방법은 참조를 사용하는 것입니다:

```tsx
import { useRef } from 'react';
```

```tsx
const highlightRef = useRef<IgrHighlight>(null);
```

```tsx
<IgrHighlight ref={highlightRef}>
    ...
</IgrHighlight>
```

그다음 `igcInput` 이벤트가 발생할 때마다 호출되는, 검색 텍스트를 업데이트하는 함수를 만드십시오:

```tsx
const onInput = ({ detail }: CustomEvent<string>) => {
    highlightRef.current.searchText = detail;
};
```

```tsx
<IgrInput label="Search" onigcInput={onInput}></IgrInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">
먼저 searchText 속성을 추가해야 합니다:

```razor
private string searchText = "";
```

그다음 `igcInput` 이벤트가 발생할 때마다 검색 텍스트를 업데이트하는 함수를 만드십시오:

```razor
private void OnValueChanging(string newValue)
{
    searchText = newValue;
}
```

```razor
<IgbInput Label="Search" ValueChanging="OnValueChanging"></IgbInput>
<IgbHighlight SearchText="@searchText">
    <p>
        Lorem ipsum dolor sit, amet consectetur adipisicing elit. Quae doloribus
        odit id excepturi ipsum provident eaque dignissimos beatae! Rerum vero
        distinctio libero, quasi magni quod natus nesciunt doloremque temporibus
        voluptate?
    </p>
</IgbHighlight>
```

</PlatformBlock>

### 메서드

컴포넌트는 검색 일치 항목을 탐색하는 두 메서드도 노출합니다. <ApiLink pkg="core" type="Highlight" member="next" label="next()" /> 메서드는 다음 일치 항목으로 이동하고, <ApiLink pkg="core" type="Highlight" member="previous" label="previous()" /> 메서드는 이전 일치 항목으로 이동합니다.

이 메서드들로 일치 항목 사이를 이동하는 버튼을 두 개 추가하여 검색을 더 대화형으로 만들 수 있습니다:

<PlatformBlock for="WebComponents">
```ts
const highlight = document.querySelector('igc-highlight') as IgcHighlightComponent;

const prev = () => {
    highlight.previous();
};

const next = () => {
    highlight.next();
};

document.querySelector('#prev-btn')?.addEventListener('click', prev);
document.querySelector('#next-btn')?.addEventListener('click', next);

```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
const highlightRef = useRef<IgrHighlight>(null);

const prev = () => {
    highlightRef.current?.previous();
};

const next = () => {
    highlightRef.current?.next();
};
```

</PlatformBlock>

<PlatformBlock for="Blazor">
```razor

private async Task Prev()

}

private async Task Next()

    if (HighlightRef != null)

}

```

</PlatformBlock>

### 추가 기능

<PlatformBlock for="WebComponents">
컴포넌트는 일치 상태를 추적하기 위한 읽기 전용 속성 두 개도 노출합니다. <ApiLink type="Highlight" member="size" label="size" />는 전체 일치 항목 수를, <ApiLink type="Highlight" member="current" label="current" />는 활성 일치 항목의 인덱스를 반환합니다.

이 속성들은 사용자가 현재 몇 번째 일치 항목에 있는지, 그리고 전체 일치 항목이 몇 개인지 보여 주는 검색 상태 표시기를 만들 때 유용합니다.

다음은 이 속성들을 사용하여 검색 상태를 만드는 방법의 간단한 예입니다:

```ts
const highlight = document.querySelector('igc-highlight') as IgcHighlightComponent;
const status = document.querySelector('#helper-text') as HTMLParagraphElement;

const updateStatus = () => {
    status.textContent = highlight.size
      ? `${highlight.current + 1} of ${highlight.size} match${highlight.size === 1 ? '' : 'es'}`
      : '';
}

```

</PlatformBlock>

<PlatformBlock for="React">
컴포넌트는 일치 상태를 추적하기 위한 읽기 전용 속성 두 개도 노출합니다. <ApiLink type="Highlight" member="size" label="size" />는 전체 일치 항목 수를, <ApiLink type="Highlight" member="current" label="current" />는 활성 일치 항목의 인덱스를 반환합니다.

이 속성들은 사용자가 현재 몇 번째 일치 항목에 있는지, 그리고 전체 일치 항목이 몇 개인지 보여 주는 검색 상태 표시기를 만들 때 유용합니다.

다음은 이 속성들을 사용하여 검색 상태를 만드는 방법의 간단한 예입니다:

```tsx
const highlightRef = useRef<IgrHighlight>(null);
const statusRef = useRef<HTMLParagraphElement>(null);

const updateStatus = () => {
    const highlight = highlightRef.current;
    const status = statusRef.current;

    status.textContent = highlight.size
      ? `${highlight.current + 1} of ${highlight.size} match${highlight.size === 1 ? '' : 'es'}`
      : '';
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">
컴포넌트는 일치 상태를 추적하기 위한 비동기 메서드 두 개도 노출합니다. GetSizeAsync()는 전체 일치 항목 수를, GetCurrentAsync()는 활성 일치 항목의 인덱스를 반환합니다.

이 메서드들은 사용자가 현재 몇 번째 일치 항목에 있는지, 그리고 전체 일치 항목이 몇 개인지 보여 주는 검색 상태 표시기를 만들 때 유용합니다.

다음은 이 메서드들을 사용하여 검색 상태를 만드는 방법의 간단한 예입니다:

```razor
private async Task UpdateStatus()
{
    var size = (int)await HighlightRef.GetSizeAsync();
    var current = (int)await HighlightRef.GetCurrentAsync();
    helperText = $"{current + 1} of {size} match{(size == 1 ? "" : "es")}";
}
```

</PlatformBlock>

## 스타일링

<ApiLink pkg="core" type="Highlight" /> 컴포넌트는 전체 컴포넌트의 스타일을 지정하는 데 사용할 수 있는 CSS 변수 네 개를 노출합니다:
- `--foreground` 강조 표시된 텍스트 노드의 텍스트 색상입니다.
- `--background` 강조 표시된 텍스트 노드의 배경색입니다.
- `--foreground-active` 활성 강조 표시된 텍스트 노드의 텍스트 색상입니다.
- `--background-active` 활성 강조 표시된 텍스트 노드의 배경색입니다.

```css
igc-highlight {
    --background: var(--ig-gray-700);
    --foreground: var(--ig-gray-700-contrast);
    --background-active: var(--ig-warn-500);
    --foreground-active: var(--ig-warn-500-contrast);
}
```
