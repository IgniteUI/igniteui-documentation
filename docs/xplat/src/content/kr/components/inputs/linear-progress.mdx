# {Platform} 선형 진행률 개요

{ProductName} 선형 진행률 표시기 컴포넌트는 애플리케이션 프로세스가 변하는 모습을 시각적으로 보여 주는 표시기를 제공합니다. <ApiLink pkg="core" type="LinearProgress" /> 표시기는 상태가 바뀔 때 자신의 모양을 업데이트합니다. 또한 줄무늬나 단색으로 색상을 선택해 이 컴포넌트의 스타일을 지정할 수 있습니다.

### 진행률 유형

<ApiLink pkg="core" type="LinearProgress" member="variant" label="Variant" /> 속성을 사용하여 표시기의 유형을 설정할 수 있습니다. 선형 진행률 표시기 유형은 다섯 가지입니다 - **primary**(기본값), **error**, **success**, **info**, **warning**.


</PlatformBlock>

<PlatformBlock for="WebComponents">

```html

```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

```

</PlatformBlock>

## 스타일링

<ApiLink pkg="core" type="LinearProgress" /> 컴포넌트는 거의 모든 내부 요소에 대한 CSS 파트를 노출합니다:

|이름|설명|
|--|--|
| `track`         | 진행률 링의 트랙 영역입니다. |
| `fill`          | 진행률 표시기 영역입니다. |
| `striped`       | 진행률 줄무늬 표시기입니다. |
| `label`         | 진행률 표시기 레이블입니다. |
| `value`         | 진행률 레이블 값입니다. |
| `indeterminate` | 진행률 불확정 상태입니다. |
| `primary`       | 진행률 표시기 primary 상태입니다. |
| `danger`        | 진행률 표시기 error 상태입니다. |
| `warning`       | 진행률 표시기 warning 상태입니다. |
| `info`          | 진행률 표시기 info 상태입니다. |
| `success`       | 진행률 표시기 success 상태입니다. |

이 CSS 파트를 사용하면 선형 진행률의 스타일을 거의 완전히 제어할 수 있습니다.

<Sample src="/inputs/linear-progress-indicator/styling" height={80} alt="{Platform} 선형 진행률 스타일 지정" />


```css
igc-linear-progress::part(track){
  background-color: var(--ig-gray-300)
}

igc-linear-progress::part(fill){
  background-color: var(--ig-primary-300)
}

igc-linear-progress::part(label){
  color: var(--ig-primary-300)
}
```
