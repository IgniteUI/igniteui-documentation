# Radio Group

{Platform} 라디오와 라디오 그룹은 사용자가 상호 배타적인 옵션 집합에서 정확히 하나의 옵션을 선택할 수 있게 하는 컴포넌트입니다. 각 라디오 버튼은 하나의 옵션을 나타내며, 라디오 그룹은 라디오 버튼을 세로 또는 가로 레이아웃으로 배열합니다.

{Platform} 라디오와 라디오 그룹을 사용하려면  <PlatformBlock for="Angular">[{ProductName} 시작하기](../general/getting-started.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[{ProductName} 시작하기](../general-getting-started.mdx)</PlatformBlock> 기본 프로젝트 설정 항목을 참조한 다음, 대상 플랫폼에 맞게 컴포넌트를 import하거나 등록하십시오.

</PlatformBlock>

<PlatformBlock for="Blazor">

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

<ApiLink pkg="core" type="RadioGroup" />의 클라이언트 리소스 모듈인 <ApiLink pkg="core" type="RadioGroupModule" />을 등록하는 것은 **선택 사항**입니다. 컴포넌트는 처음 렌더링될 때 리소스를 로드합니다. `builder.Services.AddIgniteUIBlazor(typeof(IgbRadioGroupModule))`에 포함하면 리소스를 미리 로드하거나 클라이언트에서만 생성된 요소를 지원하는 데 사용할 수 있으며, 그룹 내 라디오 요소도 등록합니다. 단독으로 사용되는 <ApiLink pkg="core" type="Radio" />에는 자체 모듈 <ApiLink pkg="core" type="RadioModule" />이 있습니다([컴포넌트 모듈](../general-getting-started.mdx#컴포넌트-모듈) 참조).


</PlatformBlock>

## 사용법

### 레이아웃

{Platform} 라디오는 기본적으로 레이블을 라디오 컨트롤 뒤에 배치합니다. 레이블을 컨트롤 앞에 두려면 <ApiLink pkg="core" type="Radio" member="labelPosition" label="labelPosition" /> 속성을 `before`로 설정하십시오. 세로 라디오 그룹에서는 레이블이 컨트롤 앞에 있는 라디오 버튼이 그룹의 끝에 맞춰 정렬됩니다.

<PlatformBlock for="React,WebComponents,Blazor">

라디오 버튼은 라디오 그룹의 직접 자식으로 배치하십시오. 래퍼 요소 안의 라디오 버튼은 그룹의 일부가 아니며, 그룹이 그 배치를 결정하지 않습니다.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-radio-group name="color">
  <igc-radio value="yellow" label-position="before" checked>Yellow</igc-radio>
  <igc-radio value="orange" label-position="before">Orange</igc-radio>
</igc-radio-group>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrRadioGroup name="color">
  <IgrRadio value="yellow" labelPosition="before" checked={true}>Yellow</IgrRadio>
  <IgrRadio value="orange" labelPosition="before">Orange</IgrRadio>
</IgrRadioGroup>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbRadioGroup name="color">
    <IgbRadio Value="yellow" LabelPosition="ToggleLabelPosition.Before" Checked="true">Yellow</IgbRadio>
    <IgbRadio Value="orange" LabelPosition="ToggleLabelPosition.Before">Orange</IgbRadio>
</IgbRadioGroup>
```

</PlatformBlock>

<PlatformBlock for="Angular">

```html
<igx-radio-group name="color" alignment="vertical" value="yellow">
  <igx-radio value="yellow" labelPosition="before">Yellow</igx-radio>
  <igx-radio value="orange" labelPosition="before">Orange</igx-radio>
</igx-radio-group>
```

</PlatformBlock>

<PlatformBlock for="Angular,React,WebComponents">

라디오 버튼은 그 바깥의 요소로도 레이블을 붙일 수 있습니다. 레이블이 놓이는 위치와 모양을 완전히 제어해야 할 때는 `aria-labelledby`로 그 요소를 참조하십시오.

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

</PlatformBlock>

<PlatformBlock for="WebComponents">

</PlatformBlock>

### 상호 작용 상태

{Platform} 라디오는 포인터가 위에 있을 때 마우스 오버 상태를, 키보드 포커스를 받으면 포커스 링을 보여 줍니다. 유효하지 않은 상태를 보여 주려면 <ApiLink pkg="core" type="Radio" member="invalid" label="invalid" /> 속성을 설정하십시오. 이때 라디오 컨트롤은 테마의 오류 색상으로 그려집니다.

<PlatformBlock for="WebComponents">

</PlatformBlock>


</PlatformBlock>

</PlatformBlock>

</PlatformBlock>

### 비활성화 상태

{Platform} 라디오를 비활성화하려면 <ApiLink pkg="core" type="Radio" member="disabled" label="disabled" /> 속성을 설정하십시오. 비활성화된 라디오 버튼은 선택할 수 없으며, 키보드 탐색에서 건너뜁니다.

### 폼

{Platform} 라디오는 선택된 라디오 버튼의 `value`를 그룹의 `name` 아래에 제출합니다. 폼이 제출되기 전에 선택을 필수로 하려면 그룹의 라디오 버튼 중 하나에 <ApiLink pkg="core" type="Radio" member="required" label="required" /> 속성을 설정하십시오.

<PlatformBlock for="React,WebComponents,Blazor">

## 접근성

{Platform} 라디오는 네이티브 라디오 input을 렌더링하므로, 보조 기술은 각 라디오 버튼을 역할, 레이블, 체크 상태와 함께 읽습니다.

### 키보드 상호 작용

{Platform} 라디오 그룹은 화살표 키로 활성화된 라디오 버튼 사이에서 포커스와 선택을 옮깁니다. 비활성화된 라디오 버튼은 건너뜁니다.

| 키 | 동작 |
| --- | --- |
| Tab / Shift+Tab | 라디오 그룹 안이나 밖으로 포커스를 옮깁니다. |
| 아래 화살표 / 오른쪽 화살표 | 다음 활성화된 라디오 버튼으로 포커스를 옮기고 그것을 켭니다. 마지막 라디오 버튼에서는 첫 번째 라디오 버튼으로 이동합니다. 오른쪽에서 왼쪽으로 쓰는 레이아웃에서는 오른쪽 화살표가 이전 라디오 버튼으로 이동합니다. |
| 위 화살표 / 왼쪽 화살표 | 이전 활성화된 라디오 버튼으로 포커스를 옮기고 그것을 켭니다. 첫 번째 라디오 버튼에서는 마지막 라디오 버튼으로 이동합니다. 오른쪽에서 왼쪽으로 쓰는 레이아웃에서는 왼쪽 화살표가 다음 라디오 버튼으로 이동합니다. |
| Space | 포커스된 라디오 버튼을 켭니다. |
<PlatformBlock for="React,WebComponents,Blazor">| Enter | 라디오 버튼을 포함하는 폼을 제출합니다. |</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

그룹의 라디오 버튼 중 하나가 켜져 있으면, 그것이 그룹의 유일한 탭 정지 지점입니다. 라디오 버튼 중 어느 것도 켜져 있지 않으면 각 버튼이 탭 정지 지점입니다.

</PlatformBlock>

<PlatformBlock for="Blazor">

`IgniteUI.Blazor` 26.1에서는 코드로 선택을 지우면 그룹에 탭 정지 지점이 남지 않습니다. [알려진 제한 사항](#알려진-제한-사항)을 참조하십시오.

</PlatformBlock>

### 화면 읽기 프로그램 / ARIA

- 각 {Platform} 라디오는 네이티브 `<input type="radio">`를 렌더링하며, 이는 라디오 역할, 체크 상태, 비활성화와 필수 상태를 노출합니다.<PlatformBlock for="Angular"> input은 또한 `invalid` 속성의 `aria-invalid`도 설정합니다.</PlatformBlock>
- 라디오 버튼의 레이블 콘텐츠가 접근 가능한 이름입니다.<PlatformBlock for="Angular,React,WebComponents"> 레이블이 컴포넌트 바깥에 있다면, `aria-labelledby`로 연결하십시오.</PlatformBlock>

<PlatformBlock for="React,WebComponents">

- 라디오 그룹은 `radiogroup` 역할을 렌더링하고, `alignment`로부터 `aria-orientation`를 설정합니다.

</PlatformBlock>

<PlatformBlock for="Blazor">

- 라디오 그룹은 `radiogroup` 역할을 렌더링합니다. `IgniteUI.Blazor` 26.1에서는 `aria-orientation`를 설정하지 않습니다.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

- 라디오 그룹에 접근 가능한 이름을 부여하십시오. 예를 들어 그것이 답하는 질문을 가리키는 `aria-labelledby`을 사용하십시오.

</PlatformBlock>

<PlatformBlock for="Angular">

- `igx-radio-group` 요소는 `radiogroup` 역할을 렌더링하지 않습니다. 그룹을 하나의 질문으로 읽히게 해야 할 때는 `role="radiogroup"`와 접근 가능한 이름을 추가하십시오. 예를 들어 `aria-labelledby`를 사용할 수 있습니다.

</PlatformBlock>

렌더링된 {Platform} 라디오와 라디오 그룹을 애플리케이션의 접근성 요구 사항에 맞춰 확인하십시오.

- 모든 라디오 버튼에 의미 있는 레이블 콘텐츠를 제공하고, 라디오 그룹에 접근 가능한 이름을 부여하십시오.
- 라디오 색상을 사용자 지정할 때는 포커스 링이 보이도록 유지하고 충분한 대비를 보존하십시오.
- 라디오가 유효하지 않을 때는 유효성 검사 메시지를 보여 주어, 오류가 색상만으로 전달되지 않게 하십시오.<PlatformBlock for="React,WebComponents,Blazor"> [폼](#폼)에 나온 대로 `value-missing` 슬롯을 사용하십시오.</PlatformBlock><PlatformBlock for="Angular"> 주변 폼에 그것을 표시하십시오.</PlatformBlock>
- 렌더링된 라디오 그룹을 키보드 탐색과 사용자가 의존하는 보조 기술로 테스트하십시오.
