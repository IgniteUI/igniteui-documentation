### Select

<ApiLink pkg="core" type="Select" /> 컴포넌트는 `Form` 컴포넌트 안에서 사용할 수 있으므로, 등록할 때 쓰는 <ApiLink pkg="core" type="Select" member="name" label="Name" /> 속성을 노출합니다.

<ApiLink pkg="core" type="Select" member="label" label="Label" />와 <ApiLink pkg="core" type="Select" member="placeholder" label="Placeholder" /> 속성도 있습니다. <ApiLink pkg="core" type="Select" member="outlined" label="Outlined" /> 속성은 Material 테마에서 스타일링 목적으로만 사용됩니다.

기본 슬롯 외에도 이 컴포넌트는 `header`, `footer`, `helper-text`, `prefix`, `suffix`, `toggle-icon` 같은 여러 슬롯을 제공합니다. 슬롯에 콘텐츠를 넣을 때는 간단한 텍스트, 기호, 이모지에는 `<span>` 요소를, 아이콘에는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다.

`--ig-size` CSS 변수를 사용하여 컴포넌트 크기를 바꿀 수 있습니다.

### 항목

<ApiLink pkg="core" type="SelectItem" /> 컴포넌트는 사용자가 <ApiLink pkg="core" type="Select" /> 컨트롤이 사용할 옵션 목록을 선언적으로 지정할 수 있게 합니다. 각 항목은 선택 시 담고 있는 데이터를 나타내는 <ApiLink pkg="core" type="SelectItem" member="value" label="Value" /> 속성을 제공합니다. <ApiLink pkg="core" type="SelectItem" />에는 항목의 텍스트 콘텐츠를 지정할 수 있는 기본 슬롯이 있습니다. <ApiLink pkg="core" type="SelectItem" />에 <ApiLink pkg="core" type="SelectItem" member="value" label="Value" /> 속성이 없으면 이 텍스트 콘텐츠가 값으로 사용됩니다.

<ApiLink pkg="core" type="SelectItem" /> 콘텐츠 앞이나 뒤에 렌더링될 사용자 지정 콘텐츠도 `prefix`와 `suffix` 슬롯으로 제공할 수 있습니다. <ApiLink pkg="core" type="Select" /> 컴포넌트와 마찬가지로, 간단한 텍스트, 기호, 이모지에는 `<span>` 요소를, `prefix`와 `suffix` 슬롯에 아이콘을 추가할 때는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다.

<ApiLink pkg="core" type="SelectItem" member="selected" label="Selected" /> 속성을 설정하여 선택된 항목을 미리 정의할 수 있습니다. <ApiLink pkg="core" type="SelectItem" member="disabled" label="Disabled" /> 속성으로 일부 또는 모든 항목을 비활성화할 수도 있습니다.

### 그룹

<ApiLink pkg="core" type="SelectGroup" /> 컴포넌트의 여는 괄호와 닫는 괄호 사이에 여러 <ApiLink pkg="core" type="SelectItem" />를 배치하여, 사용자가 시각적으로 함께 묶어 볼 수 있게 할 수 있습니다. <ApiLink pkg="core" type="SelectGroup" />는 `label` 슬롯으로 레이블을 붙일 수 있고, <ApiLink pkg="core" type="SelectGroup" member="disabled" label="Disabled" /> 속성으로 비활성화할 수 있습니다. `label` 슬롯에는 `<span>` 요소를 사용하는 것을 권장합니다.

## 검증

또한 <ApiLink pkg="core" type="Select" />는 <ApiLink pkg="core" type="Select" member="required" label="Required" />, <ApiLink pkg="core" type="Select" member="disabled" label="Disabled" />, <ApiLink pkg="core" type="Select" member="autofocus" label="Autofocus" /> 같은 대부분의 <ApiLink pkg="core" type="Input" /> 속성을 지원합니다. 이 컴포넌트는 유효성 검사에 바인딩된 메서드도 노출합니다:

- `reportValidity` - 유효성을 확인하고, 유효하지 않으면 컴포넌트에 포커스를 줍니다.

## 키보드 탐색

select에 포커스가 있고 옵션 목록이 **보이지 않을 때**:

- <kbd>ALT</kbd> + <kbd>↑</kbd> <kbd>↓</kbd> 조합을 사용하거나 <kbd>SPACE</kbd> 또는 <kbd>ENTER</kbd> 키를 눌러 <ApiLink pkg="core" type="Input" member="select" label="Select" />를 여십시오.
- <kbd>ALT</kbd> + <kbd>↑</kbd> 또는 <kbd>↓</kbd> 조합이나, <kbd>ENTER</kbd>, <kbd>SPACE</kbd>, <kbd>ESC</kbd> 또는 <ApiLink pkg="core" type="Tab" /> 키 중 하나를 사용하여 <ApiLink pkg="core" type="Input" member="select" label="Select" />를 닫으십시오.
- <kbd>←</kbd> <kbd>→</kbd> 키를 사용하면 목록에서 이전 항목이 선택됩니다.
- <kbd>↑</kbd> <kbd>↓</kbd> 키를 사용하면 목록에서 다음 항목이 선택됩니다.
- <kbd>HOME</kbd> 또는 <kbd>END</kbd> 키를 사용하면 목록에서 첫 번째 또는 마지막 항목이 선택됩니다.
- 문자를 입력하면 항목 목록을 조회하고, 현재 사용자 입력과 가장 가깝게 일치하는 항목을 선택합니다.

select에 포커스가 있고 옵션 목록이 **보일** 때:

- <kbd>ENTER</kbd> 또는 <kbd>SPACE</kbd> 키를 사용하면 항목이 선택되고 목록이 닫힙니다.
- <kbd>←</kbd> <kbd>→</kbd> 키를 사용하면 목록에서 이전 항목이 활성화됩니다.
- <kbd>↑</kbd> <kbd>↓</kbd> 키를 사용하면 목록에서 다음 항목이 활성화됩니다.
- <kbd>HOME</kbd> 또는 <kbd>END</kbd> 키를 사용하면 목록에서 첫 번째 또는 마지막 항목이 활성화됩니다.

<DocsAside type="info">
<ApiLink pkg="core" type="Input" member="select" label="Select" /> 컴포넌트는 항목의 **단일** 선택만 지원합니다.
</DocsAside>

## 스타일링

아래 나열된 노출된 CSS 파트를 사용하면 {ProductName} <ApiLink pkg="core" type="Select" /> 컴포넌트와 그 항목의 모양을 바꿀 수 있습니다:

**Select 컴포넌트**

| 파트 이름 | 설명 |
| ---------|------------ |
| `input` | 캡슐화된 igc-input입니다. |
| `label` | 캡슐화된 텍스트 레이블입니다. |
| `list` | 옵션 목록을 담는 래퍼입니다. |
| `prefix`  | 입력 앞에 콘텐츠를 렌더링하는 접두사 래퍼입니다. |
| `suffix` | 입력 뒤에 콘텐츠를 렌더링하는 접미사 래퍼입니다. |
| `toggle-icon` | 접미사 래퍼 안에 콘텐츠를 렌더링하는 토글 아이콘 래퍼입니다. |
| `helper-text` | 입력 아래에 콘텐츠를 렌더링하는 도움말 텍스트 래퍼입니다. |

**Select Item 컴포넌트**

| 파트 이름 | 설명 |
| ---------|------------ |
| `content` | 항목의 텍스트 콘텐츠를 담는 기본 래퍼입니다. |
| `prefix`  | 기본 래퍼 앞에 콘텐츠를 렌더링하는 접두사 래퍼입니다. |
| `suffix` | 기본 래퍼 뒤에 콘텐츠를 렌더링하는 접미사 래퍼입니다. |

**Select Group 컴포넌트**

| 파트 이름 | 설명 |
| ---------|------------ |
| `label` | select 그룹 항목 위에 콘텐츠를 렌더링하는 레이블 래퍼입니다. |

```css
igc-select::part(base) {
  background: var(--ig-primary-50);
}

igc-select-item[active] {
  background: var(--ig-secondary-300);
}

igc-select::part(input) {
  background-color: var(--ig-primary-50);
}

igc-select::part(prefix),
igc-select::part(suffix) {
  color: var(--ig-secondary-500-contrast);
  background: var(--ig-secondary-500);
}
```
