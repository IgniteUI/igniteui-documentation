# {Platform} 쿼리 빌더 개요

{ProductName} 쿼리 빌더는 개발자가 지정된 데이터 세트에 대해 복잡한 데이터 필터링 쿼리를 만들 수 있는 풍부한 UI를 제공합니다. 이 컴포넌트로 식 트리를 만들고 식 사이에 AND/OR 조건을 지정할 수 있으며, 편집기와 조건 목록은 각 필드의 데이터 유형에 따라 결정됩니다. 그런 다음 식 트리를 백엔드가 지원하는 형식의 쿼리로 쉽게 변환할 수 있습니다.

## {Platform} 쿼리 빌더 사용하기

초기에 식 트리가 설정되지 않은 경우, 먼저 엔티티와 쿼리가 반환해야 할 필드를 선택하여 시작합니다. 그다음 조건이나 하위 그룹을 추가할 수 있습니다.

조건을 추가하려면 필드를 선택하고, 필드의 데이터 유형에 따른 연산자를 선택한 후, 연산자가 단항이 아니라면 값을 입력합니다. `In` 및 `Not In` 연산자를 사용하면 단순히 값을 제공하는 대신 다른 엔티티에 대한 조건으로 내부 쿼리를 만들 수 있습니다. 조건이 확정되면 조건 정보가 담긴 칩이 나타납니다. 칩을 클릭하거나 마우스를 올리면 칩을 수정하거나, 바로 뒤에 다른 조건이나 그룹을 추가하는 옵션을 사용할 수 있습니다.

각 그룹 위에 있는 (AND 또는 OR) 버튼을 클릭하면, 그룹 유형을 바꾸거나 그 안의 조건을 그룹 해제할 수 있는 메뉴가 열립니다.

모든 조건은 특정 엔터티의 특정 필드와 관련되므로, 엔터티를 바꾸면 미리 설정된 모든 조건과 그룹이 초기화됩니다.

<ApiLink type="QueryBuilder" member="entities" label="Entities" /> 속성을 엔터티 이름과 그 필드 배열을 설명하는 배열로 설정하여 컴포넌트를 사용하기 시작할 수 있습니다. 각 필드는 이름과 데이터 유형으로 정의됩니다. 필드가 선택되면 데이터 유형에 따라 해당 피연산자가 자동으로 할당됩니다.
쿼리 빌더에는 <ApiLink type="QueryBuilder" member="expressionTree" label="ExpressionTree" /> 속성이 있습니다. 이를 사용하여 컨트롤의 초기 상태를 설정하고 사용자가 지정한 필터링 로직에 액세스할 수 있습니다.

```ts
private queryBuilder: IgcQueryBuilderComponent;
public entities: any[] = [];
public ordersFields: any[] = [];
public expressionTree!: IgcExpressionTree;

constructor() {
  this.queryBuilder = document.getElementById('queryBuilder') as IgcQueryBuilderComponent;
  this.initFields();
}

private initFields(): void {
  this.ordersFields = [
    { field: 'orderId', dataType: 'number' },
    { field: 'customerId', dataType: 'string' },
    { field: 'orderDate', dataType: 'date' }
  ];

  this.entities = [
    { name: 'Orders', fields: this.ordersFields }
  ];

  const tree = new IgcFilteringExpressionsTree();
  tree.operator = FilteringLogic.And;
  tree.entity = 'Orders';

  this.expressionTree = tree;
  this.queryBuilder.entities = this.entities;
  this.queryBuilder.expressionTree = this.expressionTree;
}
```

<ApiLink type="ExpressionTree" />는 바인딩 가능한 속성입니다. 즉 최종 사용자가 조건을 만들고, 편집하고, 제거하여 UI를 바꿀 때 알림을 받으려면 `ExpressionTreeChange` 이벤트를 구독할 수 있습니다.

```ts
this.queryBuilder.addEventListener('expressionTreeChange', (e: CustomEvent<IgcExpressionTree>) => {
  this.expressionTree = e.detail;
  this.onExpressionTreeChange();
});
```

```tsx
const queryBuilderRef = useRef<IgrQueryBuilder>(null);

const ordersFields: Field[] = [
  { field: 'orderId', dataType: 'number' },
  { field: 'customerId', dataType: 'string' },
  { field: 'orderDate', dataType: 'date' }

const entities: Entity[] = [
  { name: 'Orders', fields: ordersFields }
];

const onExpressionTreeChange = (newTree: IgrFilteringExpressionsTree) => {
  // Handle expression tree changes
  console.log('Expression tree changed:', newTree);
};

const handleExpressionTreeChange = (event: CustomEvent<IgrFilteringExpressionsTree>) => {
  onExpressionTreeChange(event.detail);
};

useEffect(() => {
  const tree = new IgrFilteringExpressionsTree();
  tree.operator = FilteringLogic.And;
  tree.entity = 'Orders';

  if (queryBuilderRef.current) {
    const queryBuilder = queryBuilderRef.current;
    queryBuilder.entities = entities as any;
    queryBuilder.expressionTree = tree;
    queryBuilder.addEventListener('expressionTreeChange', handleExpressionTreeChange);
  }

  return () => {
    if (queryBuilderRef.current) {
      queryBuilderRef.current.removeEventListener('expressionTreeChange', handleExpressionTreeChange);
    }
  };
}, []);

return (
  <div className="container sample">
    <IgrQueryBuilder ref={queryBuilderRef} id="queryBuilder"></IgrQueryBuilder>
  </div>
);
```

## 식 끌어다 놓기

조건 칩은 마우스 끌기 앤 드롭 또는 키보드 순서 변경 방식으로 쉽게 위치를 바꿀 수 있습니다. 이를 통해 사용자는 쿼리 로직을 동적으로 조정할 수 있습니다.

- 칩을 끌어도 조건이나 내용은 바뀌지 않고, 위치만 바뀝니다.
- 칩은 그룹과 하위 그룹을 따라서도 끌 수 있습니다. 예를 들어 식 끌어다 놓기 기능으로 식을 그룹화하거나 그룹 해제할 수 있습니다.
이미 있는 조건을 그룹화하려면, 먼저 'add' 그룹 버튼으로 새 그룹을 추가합니다. 그런 다음 끌어서 필요한 식을 그 그룹으로 옮깁니다. 그룹을 해제하려면 모든 조건을 현재 그룹 밖으로 끌어내면 되며, 마지막 조건이 옮겨지면 그룹은 삭제됩니다.

<DocsAside type="info">
한 쿼리 트리의 칩은 다른 트리로 끌 수 없습니다. 예를 들어 상위에서 내부로, 또는 그 반대로 끌 수 없습니다.
</DocsAside>

## 키보드 상호 작용

**키 조합**

- <kbd>Tab</kbd> / <kbd>Shift + Tab</kbd> - 다음/이전 칩, 끌기 표시기, 제거 버튼, 'add' 식 버튼으로 이동합니다.
- <kbd>Arrow Down</kbd>/<kbd>Arrow Up</kbd> - 칩의 끌기 표시기에 포커스가 있을 때 칩을 위/아래로 이동할 수 있습니다.
- <kbd>Space</kbd> / <kbd>Enter</kbd> - 포커스된 식이 편집 모드로 들어갑니다. 칩을 옮긴 상태라면 새 위치를 확정합니다.
- <kbd>Esc</kbd> - 칩의 순서 변경이 취소되고 원래 위치로 돌아갑니다.

<DocsAside type="info">
키보드 순서 변경은 마우스 끌어다 놓기와 같은 기능을 제공합니다. 칩을 옮긴 후에는 사용자가 새 위치를 확정하거나 순서 변경을 취소해야 합니다.
</DocsAside>

<DocsAside type="info">
`SearchValueTemplate`를 사용할 때는 엔터티의 모든 필드 유형에 대한 템플릿을 제공해야 하며, 그렇지 않으면 쿼리 빌더가 올바르게 동작하지 않습니다. 특정 사용자 지정 템플릿이 다루지 않는 필드나 조건을 처리하는 기본/대체 템플릿을 구현하는 것은 필수입니다. 이것이 없으면 사용자는
</DocsAside>
해당 필드의 조건을 편집할 수 없습니다.


<PlatformBlock for="WebComponents">


```ts
constructor() {
  this.queryBuilder = document.getElementById('queryBuilder') as IgcQueryBuilderComponent;
  this.queryBuilder.searchValueTemplate = (ctx) => this.buildSearchValueTemplate(ctx);
}

private buildSearchValueTemplate(ctx: IgcQueryBuilderSearchValueContext) {
  const field = ctx.selectedField?.field;
  const condition = ctx.selectedCondition;
  const matchesEqualityCondition = condition === 'equals' || condition === 'doesNotEqual';

  if (!ctx.implicit) {
      ctx.implicit = { value: null };
  }

  // Custom template for Region field
  if (field === 'Region' && matchesEqualityCondition) {
      return this.buildRegionSelect(ctx);
  }

  // Custom template for OrderStatus field
  if (field === 'OrderStatus' && matchesEqualityCondition) {
      return this.buildStatusRadios(ctx);
  }

  // Custom template for date fields
  if (ctx.selectedField?.dataType === 'date') {
      return this.buildDatePicker(ctx);
  }

  // Custom template for time fields
  if (ctx.selectedField?.dataType === 'time') {
      return this.buildTimeInput(ctx);
  }

  // Default template for all other fields (string, number, boolean, etc.)
  // This ensures all fields have a functioning editor
  return this.buildDefaultInput(ctx);
}
```

```ts
// Template
private buildRegionSelect(ctx: IgcQueryBuilderSearchValueContext) {
  const currentValue = ctx?.implicit?.value?.value ?? '';

  return html`
    <igc-select
      placeholder="Region"
      .value=${currentValue}
      @igcChange=${(event: CustomEvent<{ value: string }>) => {
        const region = this.regionOptions.find(o => o.value === event.detail.value);
        ctx.implicit.value = region ?? null;
      }}>
      ${this.regionOptions.map(option => html`
        <igc-select-item value=${option.value}>${option.text}</igc-select-item>
      `)}
    </igc-select>
  `;
}
```

```ts
// Field definition
{ field: 'OrderStatus', dataType: 'number' }

// Template
private buildStatusRadios(ctx: IgcQueryBuilderSearchValueContext) {
  const currentValue = ctx.implicit?.value?.toString() ?? '';

  return html`
    <igc-radio-group
      .alignment=${"horizontal"}
      .value=${currentValue}
      @igcChange=${(event: CustomEvent<{ value: string }>) => {
        ctx.implicit.value = Number(event.detail.value);
      }}>
      ${this.statusOptions.map(option => html`
        <igc-radio
          name="status"
          value=${option.value}
          ?checked=${option.value.toString() === currentValue}>
          ${option.text}
        </igc-radio>
      `)}
    </igc-radio-group>
  `;
}
```

```ts
// Field definition
{ field: 'OrderDate', dataType: 'date' }

// Template
private buildDatePicker(ctx: IgcQueryBuilderSearchValueContext) {
  const currentValue = ctx.implicit?.value instanceof Date
    ? ctx.implicit.value
    : ctx.implicit?.value ? new Date(ctx.implicit.value) : null;

  const allowedConditions = ['equals', 'doesNotEqual', 'before', 'after'];
```
