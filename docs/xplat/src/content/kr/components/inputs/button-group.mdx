# 버튼 그룹 컴포넌트

<PlatformBlock for="Angular">
{Platform} 버튼 그룹 컴포넌트는 <ApiLink type="IgxButtonDirective" label="IgxButton" /> 디렉티브가 있는 버튼을 가로/세로 정렬, 단일/다중 선택, 토글이 가능한 스타일 버튼 그룹으로 정리하는 데 사용됩니다.
</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">
{Platform} 버튼 그룹 컴포넌트는 <ApiLink pkg="core" type="ToggleButton" />를 가로/세로 정렬, 단일/다중 선택, 토글이 가능한 스타일 버튼 그룹으로 정리하는 데 사용됩니다.
</PlatformBlock>

## 구조

{Platform} 버튼 그룹은 관련된 토글 버튼을 공유 컨테이너와 개별 버튼 항목이 있는 하나의 그룹으로 정리합니다.

### 선택
{ProductName} 버튼 그룹의 선택을 구성하려면 플랫폼별 선택 속성을 사용하십시오.

<PlatformBlock for="Angular">
{Platform}의 경우 <ApiLink pkg="core" type="ButtonGroup" member="selectionMode" label="selectionMode" /> 속성을 사용하십시오. 사용 가능한 모드는 다음과 같습니다:
</PlatformBlock>

<PlatformBlock for="React,WebComponents">
{Platform}의 경우 <ApiLink pkg="core" type="ButtonGroup" member="selection" label="selection" /> 속성을 사용하십시오. 사용 가능한 모드는 다음과 같습니다:
</PlatformBlock>

<PlatformBlock for="Blazor">
{Platform}의 경우 <ApiLink pkg="IgniteUI.Blazor" type="IgbButtonGroup" member="selection" label="selection" /> 속성을 사용하십시오. 사용 가능한 모드는 다음과 같습니다:
</PlatformBlock>

- **single** - 버튼 그룹의 기본 선택 모드입니다. 사용자가 단일 버튼을 선택하거나 선택 해제할 수 있습니다.
- **single-required** - 라디오 그룹의 동작을 모방합니다. 하나의 버튼만 선택할 수 있으며, 초기 선택이 이루어진 후에는 사용자 상호 작용으로 선택을 해제할 수 없습니다.
- **multiple** - 그룹 안의 여러 버튼을 선택하거나 선택 해제할 수 있습니다.

아래 샘플은 노출된 <ApiLink pkg="core" type="ButtonGroup" /> 선택 모드를 보여 줍니다:

<PlatformBlock for="Angular">

Angular 선택 모드는 `single`, `singleRequired`, `multi`입니다.

선택 동작을 구성하려면 Angular `selectionMode` 입력을 설정하십시오:

```html
<igx-buttongroup [selectionMode]="'multi'">
    <button igxButton selected>Bold</button>
    <button igxButton>Italic</button>
    <button igxButton>Underline</button>
</igx-buttongroup>
```

```scss
$custom-button-group: button-group-theme(

:host {

}
```

### Sass 테마 지정

## 접근성

{Platform} 버튼 그룹은 관련된 토글 버튼을 정리하며, 각 버튼의 선택 상태와 비활성화 상태를 노출합니다.

### 키보드 상호 작용

버튼 그룹은 키보드 상호 작용을 포함된 토글 버튼에 위임합니다. 각 토글 버튼은 기본 button 요소를 렌더링하므로, 표준 버튼 키보드 동작이 포커스된 항목을 활성화하고 구성된 선택 모드에 따라 선택 상태를 업데이트합니다.

| 키 | 동작 |
| --- | --- |
| Tab / Shift+Tab | 그룹에서 다음 또는 이전의 활성화된 토글 버튼으로 포커스를 이동합니다. |
| Enter / Space | 포커스된 토글 버튼을 활성화하고, 구성된 선택 모드에 따라 선택하거나 선택 해제합니다. |

버튼 그룹이 비활성화되면 포함된 토글 버튼도 비활성화되어 키보드로 상호 작용할 수 없습니다.

### 화면 읽기 프로그램 / ARIA

버튼 그룹은 그룹 관계를 노출하며, 각 토글 버튼은 기본 button 의미 체계를 통해 자신의 상태를 노출합니다.

<PlatformBlock for="WebComponents, React, Blazor">

- 그룹 컨테이너는 `role="group"`를 사용하며, `aria-disabled`를 통해 그룹의 비활성화 상태를 반영합니다.
- 각 토글 버튼은 선택 상태에 대해 `aria-pressed`, 비활성화 상태에 대해 `aria-disabled`가 있는 기본 `button`를 렌더링합니다.
- 사용자 상호 작용으로 토글 버튼의 선택이 바뀌면, 그룹은 `igcSelect`와 `igcDeselect`를 발생시킵니다. 이벤트 세부 정보는 토글 버튼의 `value`입니다.
- 모든 토글 버튼에 보이는 텍스트 또는 `aria-label`을 제공하십시오. 특히 아이콘만 있는 컨트롤의 경우에 그렇습니다.

</PlatformBlock>

<PlatformBlock for="Angular">

- 그룹 컨테이너는 `role="group"`를 사용합니다.
- Angular는 선택이 바뀔 때 포함된 각 버튼의 `aria-pressed` 값을 업데이트하고, 그룹이 비활성화되면 자식 버튼을 비활성화합니다.
- 사용자가 선택을 바꾸면 그룹은 `selected`와 `deselected`를 발생시킵니다. 각 이벤트는 선택된 토글 버튼과 그 인덱스를 제공합니다.
- 아이콘만 있는 모든 버튼에는 보이는 텍스트, `igxLabel` 또는 다른 접근 가능한 이름을 제공하십시오.

</PlatformBlock>

### 접근성 준수

Infragistics는 [접근성 준수](../interactivity/accessibility-compliance.mdx) 항목에서 Section 508 및 WCAG 2.1 지침 영역에 대한 {ProductName} 접근성 지원을 문서화합니다.

| 기준 | 컴포넌트가 준수하는 방식 |
| -- | -- |
| [2.1.1 키보드](https://www.w3.org/WAI/WCAG21/Understanding/keyboard) | 각 토글 버튼은 기본 button을 사용하므로, 그룹의 선택 동작은 표준 버튼 키보드 활성화를 통해 사용할 수 있습니다. |
| [4.1.2 이름, 역할, 값](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | 그룹은 `role="group"`를 노출합니다. 토글 버튼은 기본 button 의미 체계를 노출하며 선택이 바뀌면 `aria-pressed`를 업데이트합니다. xplat 토글 버튼은 `aria-disabled`도 노출합니다. |

사용자의 책임:

- 특히 아이콘만 포함하는 경우에는, 각 토글 버튼에 명확한 보이는 레이블이나 접근 가능한 이름을 부여하십시오.
- 사용자가 하나 또는 여러 옵션을 선택할 수 있는지 이해할 수 있도록, 그룹 선택 모드를 컨트롤의 목적에 맞게 유지하십시오.
- 그룹이나 선택된 상태를 사용자 지정할 때도 논리적인 버튼 순서와 충분한 색상 대비를 유지하십시오.

## 문제 해결

버튼 그룹을 단일 토글, 폼 필드 또는 동작 그룹으로 보기 전에, 이 섹션에서 경계와 일반적인 결정을 확인하십시오.

### selectedItems가 버튼을 선택하지 않는 이유는 무엇입니까?

모든 토글 버튼에 고유한 `value` 어트리뷰트가 있는지 확인하십시오. `selectedItems` 속성은 그 값에 따라 달라집니다.

### 알려진 제한 사항

{Platform} 버튼 그룹은 토글 버튼들을 조정하지만, 각 버튼의 개별 레이블이나 접근 가능한 이름을 대체하지는 않습니다.

- 선택 동작은 구성된 `selection` 모드에 따라 달라집니다.
- `selectedItems` 속성은 포함된 토글 버튼에 있는 고유한 `value` 어트리뷰트에 따라 달라집니다.
- 버튼 그룹은 버튼의 레이블이나 아이콘을 제공하지 않습니다. 각 토글 버튼의 콘텐츠는 따로 정의하십시오.

각 버튼 항목에 고유한 값을 부여한 다음, 처음에 선택되어야 하는 항목을 식별하기 위해 플랫폼별 선택 항목 설정을 사용하십시오. 고유한 값을 사용하면 그룹이 지원되는 모든 플랫폼에서 선택을 일관되게 추적할 수 있습니다.
</FaqItem>

<FaqItem question="버튼 그룹에서 아이콘과 레이블을 사용할 수 있습니까?">
예. 각 버튼 항목에는 아이콘, 레이블 또는 둘 다를 포함할 수 있습니다. 그룹 전체에서 콘텐츠 패턴을 일관되게 유지하고, 아이콘만으로 옵션을 설명할 수 없는 경우에는 보이는 레이블이나 접근 가능한 이름을 제공하십시오.
</FaqItem>

<FaqItem question="버튼 그룹을 세로로 표시할 수 있습니까?">
예. 플랫폼별 정렬 속성을 세로 옵션으로 설정하십시오. 관련 선택지를 한 줄에 표시해야 할 때는 가로 정렬을 사용하십시오.
</FaqItem>

</Faq>
