# 색상 선택기 컴포넌트 <Badge variant="new" />

{ProductName} 색상 선택기는 폼과 연결된 컴포넌트로, 그라데이션 캔버스, 색조 및 알파 슬라이더, 형식 전환, 스포이트, 미리 정의된 색상 견본이 있는 대화형 드롭다운을 통해 사용자가 색상을 고르고 편집할 수 있게 합니다.

## 라이브 데모

{Platform} 색상 선택기 데모는 현재 선택된 색상을 미리 보여 주고, 색상을 편집하거나 다른 색상을 고를 수 있는 드롭다운을 여는 앵커를 `input` 모드로 보여 줍니다.

## 구조

{Platform} 색상 선택기는 색상 선택 표면을 담은 팝오버 드롭다운을 여는 앵커로 구성됩니다. 이 표면에는 그라데이션 캔버스, 색조 및 알파 슬라이더, 형식을 인식하는 색상 입력, 동작 버튼, 선택 사항인 견본 그리드가 있습니다.

<span class="ig-typography__body-2" style="display: block; margin-bottom: 24px;"><strong>A - 입력 색상 선택기</strong><br /><br />
<strong>1. 입력 모드:</strong> `mode="input"`로 렌더링된 색상 선택기입니다.<br />
<strong>2. 색상 앵커/채우기:</strong> 선택기 드롭다운을 열고 현재 선택된 색상을 보여 줍니다.<br />
<strong>3. 레이블:</strong> 입력 색상 선택기의 레이블입니다.<br />
<strong>4. 플레이스홀더:</strong> 입력이 비어 있을 때 표시되는 활성 형식의 패턴으로, 예를 들어 `#rrggbb`와 같습니다.<br />
<strong>5. 접미사 컨테이너:</strong> 동작 버튼 같은 접미사 요소를 담는 컨테이너입니다.<br />
<strong>6. 힌트:</strong> 입력 색상 선택기의 힌트 텍스트입니다.<br /></span>

<span class="ig-typography__body-2" style="display: block; margin-bottom: 24px;"><strong>B - 기본 색상 선택기</strong><br /><br />
<strong>1. 색상 앵커:</strong> 선택기 드롭다운을 엽니다.<br />
<strong>2. 채우기:</strong> 현재 선택된 색상을 보여 줍니다.<br />
<strong>3. 레이블:</strong> 색상 선택기의 레이블입니다.<br />
<strong>4. 힌트:</strong> 색상 선택기의 힌트 텍스트입니다.<br /></span>

<span class="ig-typography__body-2" style="display: block; margin-bottom: 24px;"><strong>C - 색상 선택기 드롭다운</strong><br /><br />
<strong>1. 색상 선택기 드롭다운:</strong> 모든 색상 선택 컨트롤을 담은 팝오버입니다.<br />
<strong>2. 그라데이션 캔버스:</strong> 끌 수 있는 마커가 있는 HSV 채도/명도 영역입니다.<br />
<strong>3. 색상 선택기 마커:</strong> 그라데이션 캔버스에서 현재 선택된 색상을 나타내는 끌 수 있는 마커입니다.<br />
<strong>4. 색조 슬라이더:</strong> 기본 색상을 위한 범위 슬라이더입니다.<br />
<strong>5. 색조 슬라이더 핸들:</strong> 색조 슬라이더에서 현재 선택된 색조를 나타내는 끌 수 있는 마커입니다.<br />
<strong>6. 복사 버튼:</strong> 현재 선택된 색상을 클립보드에 복사합니다.<br />
<strong>7. 스포이트 버튼:</strong> 화면에서 색상을 고르는 스포이트 도구를 활성화합니다.<br />
<strong>8. 알파 슬라이더:</strong> `show-alpha`가 설정되면 표시되는 선택 사항인 불투명도 슬라이더입니다.<br />
<strong>9. 알파 슬라이더 핸들:</strong> 알파 슬라이더에서 현재 선택된 알파 값을 나타내는 끌 수 있는 마커입니다.<br />
<strong>10. 불투명도 값:</strong> 알파 슬라이더에서 현재 선택된 불투명도 값입니다.<br />
<strong>11. 형식 전환기:</strong> 색상 형식(`hex`, `rgb`, `hsl`)을 선택하는 드롭다운입니다.<br />
<strong>12. 색상 값:</strong> 선택된 형식(`hex`, `rgb`, `hsl`)에 따라 표시되는 현재 선택된 색상 값입니다.<br />
<strong>13. 견본:</strong> 미리 정의된 색상 견본의 선택 사항인 그리드입니다.<br /></span>

### 검증

색상이 선택되지 않았을 때 폼 유효성 검사가 실패하도록 컨트롤을 <ApiLink pkg="core" type="ColorPicker" member="required" label="required" />로 표시하십시오. 이 컴포넌트는 표준 폼 연결 API인 <ApiLink pkg="core" type="ColorPicker" member="checkValidity" label="checkValidity" />, <ApiLink pkg="core" type="ColorPicker" member="reportValidity" label="reportValidity" />, <ApiLink pkg="core" type="ColorPicker" member="setCustomValidity" label="setCustomValidity" />를 지원합니다.

- `helper-text` – 앵커 아래에 힌트나 안내 메시지를 표시합니다.
- `value-missing` – 필수 필드 유효성 검사가 실패하면 사용자 지정 콘텐츠를 렌더링합니다.

- `custom-error` – <ApiLink pkg="core" type="ColorPicker" member="setCustomValidity" label="setCustomValidity()" />를 사용하여 사용자 지정 유효성 검사 메시지가 설정되면 콘텐츠를 표시합니다.

## Angular 폼에서 색상 선택기 사용하기

Angular 폼에서 색상 선택기 웹 컴포넌트를 사용하고 `formControlName` 또는 `ngModel`로 바인딩하려면, Angular는 `ControlValueAccessor` 인터페이스의 구현이 필요합니다. {ProductName}는 이를 `IgcFormControlDirective`로 제공하며, 이는 요소 선택자로 지원되는 웹 컴포넌트에 연결됩니다. 22.2.0 버전부터는 `igc-rating`에 더해 `igc-color-picker`도 지원합니다.

`IgcFormControlDirective`를 `ReactiveFormsModule`와 함께 import하거나, `ngModel`로 바인딩하는 경우 `FormsModule`를 import하십시오:

```ts
import { ReactiveFormsModule } from '@angular/forms';
import { IgcFormControlDirective } from 'igniteui-angular/directives';
// import { IgcFormControlDirective } from '@infragistics/igniteui-angular/directives'; for licensed package

@Component({
    imports: [ReactiveFormsModule, IgcFormControlDirective],
    schemas: [CUSTOM_ELEMENTS_SCHEMA]
})

export class LabelFormComponent {...}
```

그다음 `formControlName`로 색상 선택기를 `FormControl`에 바인딩하십시오. 컨트롤은 활성 `format` 형식의 색상을 받으며, 포커스가 색상 선택기를 떠날 때 다른 색상으로 업데이트됩니다:

```html
<form [formGroup]="labelForm">
  <igc-color-picker formControlName="color" label="Label color" required></igc-color-picker>
</form>
```

<DocsAside type="info">
이 디렉티브는 값 바인딩만 처리합니다. `[swatches]="swatches"` 같은 다른 색상 선택기 속성에 Angular 속성 바인딩을 사용한다면 `CUSTOM_ELEMENTS_SCHEMA`를 유지하십시오.
</DocsAside>

다음 샘플은 필수 유효성 검사가 있는 반응형 폼에서 색상 선택기를 사용합니다:

## 접근성

{Platform} 색상 선택기는 키보드로 조작할 수 있고 폼과 연결되는 컨트롤입니다. 앵커는 레이블이 있는 버튼(기본 모드)이거나 편집 가능한 입력(입력 모드)이며, 열린 선택기는 포커스를 가둡니다.

### 키보드 상호 작용

컴포넌트가 `disabled` 상태일 때는 아래 키 조작이 건너뛰어집니다.

| 키 | 동작 |
| -- | -- |
| `Alt` + `ArrowDown` | 선택기 드롭다운을 토글합니다. |
| `Alt` + `ArrowUp` | 선택기 드롭다운을 닫고 포커스를 앵커로 되돌립니다. |
| `Escape` | 선택기 드롭다운을 닫고 포커스를 앵커로 되돌립니다. |
| `Arrow` 키 | 그라데이션 캔버스 마커에 포커스가 있을 때, 누른 방향으로 마커를 한 단계씩 이동합니다. |
| `ArrowUp` / `ArrowDown` | 알파 입력에 포커스가 있을 때 불투명도를 1%씩 늘리거나 줄입니다. |
| `Tab` | 열린 선택기 안의 상호 작용 요소 사이에서 포커스를 이동합니다. |

### 화면 읽기 프로그램 / ARIA

- 앵커는 `aria-haspopup="dialog"`와 `aria-expanded`를 설정하고, `aria-describedby`를 통해 도움말 텍스트 컨테이너를 참조하여 도움말과 유효성 검사 메시지가 읽히도록 합니다.
- 선택기 드롭다운에는 `role="dialog"`와 접근 가능한 이름 `Color picker`가 있습니다.
- 그라데이션 캔버스 마커에는 `role="slider"`가 있으며, `aria-valuetext`를 통해 두 축을 모두 읽습니다(예: `Saturation 50%, brightness 80%`).
- 색조 및 알파 슬라이더는 기본 `input[type="range"]` 요소이며, `aria-label`를 통해 레이블이 지정됩니다(`Hue`, `Alpha slider`).
- 형식 전환기와 색상 값 입력에는 시각적으로 숨겨진 레이블이 있으며, 복사 및 스포이트 버튼은 시각적으로 숨겨진 텍스트를 노출합니다.
- 각 견본 버튼은 `aria-label`를 통해 자신의 색상을 노출합니다.
- 선택기가 열려 있는 동안에는 포커스가 그 안에 갇힙니다. 닫혀 있을 때 선택기 콘텐츠는 `inert` 상태이며 탭 순서에서 제외됩니다.

### 접근성 준수

Infragistics는 [접근성 준수](../interactivity/accessibility-compliance.mdx) 항목에서 Section 508 및 WCAG 2.1 지침 영역에 대한 {ProductName} 접근성 지원을 문서화합니다.

| 기준 | 컴포넌트가 준수하는 방식 |
| -- | -- |
| [1.3.1 정보와 관계](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships) | 컴포넌트는 `aria-describedby`와 슬롯 프로젝션을 통해 레이블, 도움말 텍스트, 유효성 검사 메시지를 노출합니다. |
| [2.1.1 키보드](https://www.w3.org/WAI/WCAG21/Understanding/keyboard) | 선택기를 열고 닫는 것, 그라데이션 마커, 슬라이더, 입력, 형식 전환기, 견본은 모두 키보드로 조작할 수 있습니다. |
| [4.1.2 이름, 역할, 값](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | 앵커는 `aria-haspopup`와 `aria-expanded`를 노출하고, 마커는 값과 함께 `role="slider"`를 노출하며, 슬라이더는 접근 가능한 레이블을 노출하고, 견본은 `aria-label`를 통해 색상을 노출합니다. |

사용자의 책임:

- 화면 읽기 프로그램이 앵커를 식별할 수 있도록 `label` 속성 또는 프로젝션된 레이블을 통해 접근 가능한 레이블을 제공하십시오.
- 필수 또는 유효하지 않음 상태를 전달하는 데 색상만 사용하지 마십시오. 유효성 검사 슬롯이나 도움말 텍스트를 사용하십시오.
- 앵커와 선택기 표면의 테마 스타일을 재정의할 때 충분한 대비를 유지하십시오.

## 문제 해결

{Platform} 색상 선택기 문제 해결 안내는 흔한 통합 및 플랫폼 문제를 문제 → 원인 → 해결 형식으로 설명합니다.

### 색상 값이 지워지거나 되돌아간 이유는 무엇입니까?

`value`에 빈 문자열, 공백만 있는 문자열 또는 잘못된 문자열을 할당하면 이전 값을 유지하지 않고 색상이 지워집니다. 색상 입력에 입력한 잘못된 문자열은 대신 현재 색상으로 되돌아갑니다. 유효한 CSS 색상 문자열을 할당하고, 실행 환경이 `OffscreenCanvas`를 지원하는지 확인하십시오(알려진 제한 사항 참조).

### 내보내진 값이 제가 입력한 것과 다른 형식인 이유는 무엇입니까?

값은 항상 활성 `format`로 직렬화되므로, 입력 문자열이 바이트 단위로 그대로 돌아오지 않습니다. 예를 들어 `format="hex"` 설정에서 `red`를 입력하면 `#ff0000`가 생성됩니다. 다시 읽을 때 기대하는 표기법으로 `format`를 설정하십시오.

### 색상을 입력하는 동안 `igcInput`가 발생하지 않는 이유는 무엇입니까?

색상 입력은 키를 누를 때마다가 아니라 값이 바뀔 때 입력된 색상을 커밋하며, 입력된 색상은 `igcInput`를 발생시키지 않습니다. 포커스가 다른 색상과 함께 컴포넌트를 떠날 때 발생하는 `igcChange`를 구독하십시오.

### 알려진 제한 사항

- 스포이트 버튼은 [`EyeDropper`](https://developer.mozilla.org/en-US/docs/Web/API/EyeDropper) API를 구현하는 브라우저에서만 활성화됩니다. 지원 여부는 컴포넌트가 생성될 때 한 번 감지됩니다.
- 클립보드 복사는 `navigator.clipboard`와 보안 컨텍스트(HTTPS 또는 `localhost`)에 따라 달라지며, API를 사용할 수 없거나 권한이 거부된 환경에서는 아무 일도 일어나지 않습니다.
- 컴포넌트는 모든 색상 문자열을 `OffscreenCanvas` 2D 컨텍스트를 통해 파싱합니다. `OffscreenCanvas`를 사용할 수 없는 환경에서는 모든 값이 빈 값으로 처리됩니다.
- `Hue`, `Alpha slider`, `Open color picker`, `Copy color value to clipboard` 같은 기본 제공 접근 가능한 레이블은 영어만 제공되며 지역화되지 않습니다.
