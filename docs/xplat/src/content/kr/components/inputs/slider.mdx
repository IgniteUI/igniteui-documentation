# {Platform} 슬라이더 및 범위 슬라이더 개요

{Platform} 슬라이더 및 범위 슬라이더 컴포넌트는 썸을 트랙을 따라 움직여 주어진 범위에서 선택할 수 있게 합니다. 트랙은 연속형 또는 단계형으로 정의할 수 있으며, 단일 슬라이더와 범위 슬라이더 중에서 고를 수 있습니다.

### 값

Slider와 Range Slider 컴포넌트의 주요 차이점은 Slider 컴포넌트는 썸이 하나인 반면, Range Slider 컴포넌트는 썸이 두 개라는 것입니다. Slider 컴포넌트의 썸 하나는 <ApiLink pkg="core" type="Slider" member="value" label="Value" /> 속성을 표시합니다. Range Slider 컴포넌트의 썸 두 개는 각각 <ApiLink pkg="core" type="RangeSlider" member="lower" label="Lower" />와 <ApiLink pkg="core" type="RangeSlider" member="upper" label="Upper" /> 값 속성을 표시합니다.

두 슬라이더 모두 값 중 하나가 바뀔 때마다 이벤트 두 개를 발생시킵니다. <ApiLink pkg="core" type="Input" /> 이벤트는 키보드나 드래그 상호 작용으로 값이 바뀔 때마다 발생하며, `Change` 이벤트는 드래그가 끝나거나 키보드 상호 작용으로 값 변경이 확정될 때 발생합니다.


<Sample src="/inputs/slider/value" height={250} alt="{Platform} 슬라이더 값 예제" />




슬라이더 썸을 드래그하는 동안 툴팁에 값이 표시됩니다. <ApiLink pkg="core" type="Slider" member="hideTooltip" label="HideTooltip" /> 속성을 사용하여 이 툴팁을 숨길 수 있습니다.

### 비활성화

슬라이더의 <ApiLink pkg="core" type="Slider" member="disabled" label="Disabled" /> 속성을 사용하면 사용자 상호 작용을 비활성화할 수 있습니다.

<Sample src="/inputs/slider/disabled" height={120} alt="{Platform} 슬라이더 비활성화 예제" />




### 제약 조건

슬라이더 트랙에는 최솟값과 최댓값이 있으며, 이는 <ApiLink pkg="core" type="Slider" member="min" label="Min" /> 및 <ApiLink pkg="core" type="Slider" member="max" label="Max" /> 속성으로 구성합니다. 또한 <ApiLink pkg="core" type="RangeSlider" member="lowerBound" label="LowerBound" /> 및 <ApiLink pkg="core" type="RangeSlider" member="upperBound" label="UpperBound" /> 속성으로 썸 드래그를 제한할 수 있습니다.

<Sample src="/inputs/slider/constraints" height={120} alt="{Platform} 슬라이더 제약 조건 예제" />




### 단계

<ApiLink pkg="core" type="Slider" member="step" label="Step" /> 속성은 값이 따라야 하는 슬라이더의 세분성을 지정합니다. 기본적으로 슬라이더 트랙은 연속형으로 보입니다. 슬라이더의 <ApiLink pkg="core" type="Slider" member="discreteTrack" label="DiscreteTrack" /> 속성을 **true**로 설정하면 트랙에 단계가 표시됩니다.

<Sample src="/inputs/slider/discrete" height={120} alt="{Platform} 슬라이더 이산 트랙 예제" />




<ApiLink pkg="core" type="Slider" member="step" label="Step" /> 속성이 `0`로 설정되면 단계가 적용되지 않으며, 슬라이더 범위의 모든 값이 허용됩니다. 이 경우 <ApiLink pkg="core" type="Slider" member="discreteTrack" label="DiscreteTrack" />가 **true**로 설정되어 있어도 슬라이더는 연속형으로 보입니다.

### 눈금 표시

슬라이더 컴포넌트는 눈금 표시와 레이블을 보여 줄 수 있습니다. 슬라이더 컴포넌트는 주 눈금과 보조 눈금, 두 가지 눈금 유형을 지원합니다. 주 눈금을 표시하려면 <ApiLink pkg="core" type="Slider" member="primaryTicks" label="PrimaryTicks" /> 속성을 `1`보다 큰 값으로 설정해야 합니다. 주 눈금 개수는 트랙 위에 고르게 배분됩니다. 보조 눈금을 표시하려면 <ApiLink pkg="core" type="Slider" member="secondaryTicks" label="SecondaryTicks" /> 속성을 `0`보다 큰 값으로 설정해야 합니다. <ApiLink pkg="core" type="Slider" member="secondaryTicks" label="SecondaryTicks" />의 값은 두 주 눈금 사이에 있는 보조 눈금의 개수를 지정합니다.

<Sample src="/inputs/slider/ticks" height={150} alt="{Platform} 슬라이더 눈금 예제" />




또한 <ApiLink pkg="core" type="Slider" member="tickOrientation" label="TickOrientation" /> 속성을 사용하여 눈금의 방향을 설정할 수 있습니다. 기본적으로 <ApiLink pkg="core" type="Slider" member="tickOrientation" label="TickOrientation" /> 값은 `end`이며, 이는 눈금을 슬라이더 트랙 아래에 표시합니다. `start`로 설정하면 트랙 위에 표시되며, `mirror`로 설정하면 트랙 위와 아래에 대칭으로 표시됩니다.

기본적으로 눈금 표시에는 값과 함께 레이블이 나타납니다. <ApiLink pkg="core" type="Slider" member="tickLabelRotation" label="SliderTickLabelRotation" /> 속성을 사용하여 눈금 레이블의 회전을 바꿀 수 있습니다. 또한 <ApiLink pkg="core" type="Slider" member="hidePrimaryLabels" label="HidePrimaryLabels" />와 <ApiLink pkg="core" type="Slider" member="hideSecondaryLabels" label="HideSecondaryLabels" /> 속성으로 주 눈금과 보조 눈금의 레이블을 숨길 수 있습니다.

<Sample src="/inputs/slider/tick-labels" height={150} alt="{Platform} 슬라이더 눈금 레이블 예제" />




### 값 형식

썸과 눈금 레이블의 값을 형식화하려면, 슬라이더는 <ApiLink pkg="core" type="Slider" member="valueFormat" label="ValueFormat" />, <ApiLink pkg="core" type="Slider" member="valueFormatOptions" label="ValueFormatOptions" />, <ApiLink pkg="core" type="Slider" member="locale" label="Locale" /> 속성을 제공합니다. <ApiLink pkg="core" type="Slider" member="valueFormatOptions" label="ValueFormatOptions" />는 <ApiLink pkg="core" type="Slider" member="locale" label="Locale" />를 고려하여 소수 자릿수와 유효 숫자 수, 스타일(decimal, currency, percent, unit), 표기법 등을 지정할 수 있게 합니다. <ApiLink pkg="core" type="Slider" member="valueFormat" label="ValueFormat" />는 형식 옵션이 적용된 값으로 대체될 `{0}` 식별자를 담을 수 있는 문자열입니다.

<Sample src="/inputs/slider/value-format" height={230} alt="{Platform} 슬라이더 값 형식 예제" />




### 레이블

경우에 따라서는 슬라이더 값을 문자열 값으로 형식화하고 싶을 수 있습니다. 즉 값 **[0, 1, 2]**을 **['Low', 'Medium', 'High']**에 대응시키는 것입니다. 이런 시나리오를 위해 슬라이더 안에 <ApiLink pkg="core" type="SliderLabel" /> 요소를 정의할 수 있습니다. 슬라이더 레이블의 텍스트 콘텐츠가 썸과 눈금 레이블에 사용됩니다. 슬라이더 레이블을 제공하면 <ApiLink pkg="core" type="Slider" member="min" label="Min" />, <ApiLink pkg="core" type="Slider" member="max" label="Max" />, <ApiLink pkg="core" type="Slider" member="step" label="Step" /> 속성이 자동으로 계산되어, 제공된 레이블에 대응하지 않는 값을 허용하지 않는다는 점에 유의하십시오. 'Low', 'Medium', 'High' 레이블의 경우 <ApiLink pkg="core" type="Slider" member="min" label="Min" />는 `0`로, <ApiLink pkg="core" type="Slider" member="max" label="Max" />는 `2`로, <ApiLink pkg="core" type="Slider" member="step" label="Step" />은 `1`로 설정됩니다.

<Sample src="/inputs/slider/labels" height={150} alt="{Platform} 슬라이더 레이블 예제" />




## 스타일링

<ApiLink pkg="core" type="Slider" /> 컴포넌트는 거의 모든 내부 요소에 대한 CSS 파트를 노출합니다. 아래 표는 노출된 모든 CSS 파트를 나열합니다:

|이름|설명|
|--|--|
| `base` | 슬라이더의 기본 래퍼입니다. |
| `ticks` | 눈금 컨테이너입니다. |
| `tick-group` | 눈금 그룹 컨테이너입니다. |
| `tick` | 눈금 요소입니다. |
| `tick-label` | 눈금 레이블 요소입니다. |
| `tick-label-inner` | 눈금 레이블의 내부 요소입니다. |
| `thumbs` | 썸 컨테이너입니다. |
| `thumb` | 썸 요소입니다. |
| `thumb-label` | 썸 툴팁의 레이블 컨테이너입니다. |
| `thumb-label-inner` | 썸 툴팁의 레이블 요소입니다. |
| `track` | 트랙 컨테이너입니다. |
| `steps` | 트랙 단계 요소입니다. |
| `inactive` | 트랙의 비활성 요소입니다. |
| `fill` | 트랙의 채워진 부분입니다. |
