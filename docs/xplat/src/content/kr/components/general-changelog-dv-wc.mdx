### {PackageGrids}(그리드)
- <ApiLink type="IgcGrid" />, <ApiLink type="IgcTreeGrid" />, <ApiLink type="IgcHierarchicalGrid" />
- 같은 데이터나 다른 사용자 지정 조건을 기준으로 열의 셀을 구성하여 하나의 셀로 병합할 수 있는 새 셀 병합 기능을 도입했습니다.

        개별 열에서 활성화할 수 있습니다:

<PlatformBlock for="WebComponents">

```html
        <igc-column field="field" merge="true"></igc-column>
```

</PlatformBlock>
        병합은 그리드 수준에서 다음 중 하나에 적용되도록 구성할 수 있습니다:
  - `onSort` - 열이 정렬된 경우에만.
  - `always` - 데이터 작업과 관계없이 항상.

<PlatformBlock for="WebComponents">

```html
        <igc-grid cellMergeMode="always">
        </igc-grid>
```

</PlatformBlock>

        기본 `cellMergeMode`는 `onSort`입니다.

        사용자 지정 시나리오에 다른 병합 조건이나 로직이 필요하다면, 그리드에 사용자 지정 `mergeStrategy`를 설정하여 이 기능을 수정할 수 있습니다.

        특정 데이터 필드에 맞춤 처리가 필요하다면 개별 열에 `mergeComparer`를 설정할 수도 있습니다.

- 개별 열을 그리드의 특정 쪽(시작 또는 끝)에 고정할 수 있게 되어, 이제 양쪽에서 고정할 수 있습니다. 이는 열의 `pinningPosition` 속성을 설정하여 선언적으로 수행할 수 있습니다:

<PlatformBlock for="WebComponents">

```html
        <igc-column field="Col1" pinned="true" pinningPosition="pinningPosition">
        </igc-column>
```

</PlatformBlock>

        ```ts
        pinningPosition = ColumnPinningPosition.End;
        ```

        또는 API를 통해 선택적 매개변수로:

        ```ts
        grid.pinColumn('Col1', 0, ColumnPinningPosition.End);
        grid.pinColumn('Col2', 0, ColumnPinningPosition.Start);
        ```

        열에 `pinningPosition` 속성이 설정되지 않으면, 열은 그리드의 `columns`에 대한 `pinning` 옵션에 지정된 위치를 기본값으로 사용합니다.

- **정렬 개선**
  - Schwartzian 변환을 사용하여 정렬 알고리즘의 효율을 개선했습니다. 이는 decorate-sort-undecorate라고도 알려진 기법으로, 정렬 키를 원본 데이터 레코드와 임시로 연결하여 정렬 키를 다시 계산하지 않도록 합니다.
  - 정렬 알고리즘을 재귀에서 반복 방식으로 리팩터링했습니다.
- **그룹화 개선**
  - 그룹화 알고리즘을 재귀에서 반복 방식으로 리팩터링했습니다.
  - 그룹화 작업을 최적화했습니다.

### {PackageMaps}

#### <Badge variant="preview" /> Azure Map 이미지 지원

<ApiLink type="IgcGeographicMap" />는 이제 Azure 기반 지도 이미지를 지원하므로, 개발자는 여러 유형의 애플리케이션에서 상세하고 동적인 지도를 표시할 수 있습니다. 여러 지도 레이어를 결합하고, 지리 데이터를 시각화하며, 대화형 지도 경험을 손쉽게 만들 수 있습니다.

참고: Bing Maps 이미지 지원은 단계적으로 종료되고 있습니다. 기존 엔터프라이즈 키로 여전히 Bing Maps에 접근할 수 있으므로, Azure 지도로 전환하는 동안 현재 애플리케이션이 계속 작동합니다.

공개적으로 사용할 수 있는 일부 [Azure 지도는 여기에서 확인할 수 있습니다](https://azure.microsoft.com/en-us/products/azure-maps).
