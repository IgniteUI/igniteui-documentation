# {ProductName} 변경 로그



{ProductName}의 각 버전에 대한 주요 변경 사항은 이 페이지에 기록되어 있습니다.

## **{PackageVerLatest}**

### {PackageGrids}(그리드)

- <ApiLink type="Grid" />, <ApiLink type="TreeGrid" />, <ApiLink type="HierarchicalGrid" />, <ApiLink type="PivotGrid" />
  - Excel 스타일 필터링 검색 목록은 이제 <ApiLink type="VirtualScroll" /> 컴포넌트를 사용합니다. 목록은 행이 렌더링될 때 각 행을 측정합니다. 측정된 크기가 추정 크기를 대체합니다.
  - Excel 스타일 필터링 검색 목록의 마크업이 바뀌었습니다. 가상 스크롤 호스트와 그 항목 래퍼가 내부 표시 컨테이너와 세로 스크롤바 도우미를 대체합니다. 이 요소에 직접 접근하는 애플리케이션과 테스트를 업데이트하십시오.
  - Excel 스타일 필터링의 내부 가상 스크롤 컨테이너에는 더 이상 중첩된 list 역할이 없습니다. listbox와 그 옵션은 바뀌지 않습니다.
  - `rowStyles`, `headerStyles` 및 `headerGroupStyles` 속성의 유형이 이제 `GridStyleCSSProperty | null`입니다. 이전에는 유형이 `any`였습니다.
  - 스크롤바는 이제 표준 `scrollbar-color` 및 `scrollbar-width` CSS 속성을 사용합니다. 이전에는 `::-webkit-scrollbar-*` 의사 요소를 사용했습니다.
  - 그리드, 열 작업, Excel 스타일 필터링 메뉴의 스크롤바는 호스트의 배경색과 전경색을 사용합니다.

**호환성 깨짐 변경**

- **테마 지정**
  - `--ig-grid-summary-border-width` 및 `--ig-grid-summary-pinned-border-width` CSS 변수를 제거했습니다. 요약 셀은 이제 그리드의 테두리 두께를 사용합니다. 헤더 테두리 두께가 셀 구분선을 설정하고, 고정 테두리 두께가 고정 테두리를 설정합니다.
  - 요약 테두리 스타일과 색상은 여전히 `--ig-grid-summary-border-style`, `--ig-grid-summary-pinned-border-style`, `--ig-grid-summary-border-color`, `--ig-grid-summary-pinned-border-color`로 설정할 수 있습니다.
  - 표준 스크롤바 속성은 두 가지 색상과 세 가지 너비 키워드만 받으므로, 대부분의 스크롤바 테마 변수는 이제 효과가 없습니다. `--sb-thumb-bg-color`와 `--sb-track-bg-color`는 계속 작동합니다. hover, border, corner, 최소 높이 변수는 효과가 없습니다.
  - `scrollbar-width`는 `auto`, `thin` 또는 `none`만 받으므로 `--sb-size`는 더 이상 스크롤바 두께를 설정하지 않습니다. 더 얇은 스크롤바를 원하면 스크롤바 변수를 선언하는 요소에 `--sb-width: thin`를 설정하십시오. 스크롤되는 요소에 `scrollbar-width: thin`를 직접 설정할 수도 있습니다.

**동작 변경**

- **스크롤바**
  - 표준 CSS 속성으로는 스크롤바 화살표 버튼을 스타일링하거나 표시할 수 없습니다. `scrollbar-width: thin`는 화살표 버튼을 표시하는 플랫폼에서 화살표 버튼을 제거합니다.
  - 64 이전 버전의 Firefox는 `scrollbar-color`와 `scrollbar-width`를 지원하지 않습니다. 이 버전에서는 플랫폼의 기본 색상과 크기로 스크롤바가 표시됩니다.
- **PDF 내보내기**
  - 요약 행이 이제 헤더 행과 같은 배경을 갖습니다. 헤더 배경과 마찬가지로 `showTableBorders` 옵션이 이 배경을 제어합니다.
  - <ApiLink type="PivotGrid" /> 내보내기의 행 차원 셀에도 이 배경이 적용됩니다.
  - 연속된 레코드에서 행 차원 값이 반복되면, <ApiLink type="PivotGrid" /> 내보내기는 이제 값을 하나의 병합된 셀에 한 번만 표시합니다. 그리드도 행 머리글을 같은 방식으로 병합합니다.
  - 값은 같은 상위 차원 아래에서만 병합됩니다. 예를 들어 서로 다른 두 도시 아래의 같은 날짜는 두 개의 셀이 됩니다.
  - 병합된 셀이 페이지 하단을 넘으면 셀은 페이지 끝에서 멈춥니다. 셀은 다음 페이지에서 머리글 아래로 계속됩니다.

#### 새 컴포넌트

{ProductName}에 이제 `igniteui-webcomponents` 7.3.0 및 7.4.0의 다음 컴포넌트가 포함됩니다:

- [Breadcrumbs](./layouts/breadcrumbs.mdx)(<ApiLink type="Breadcrumbs" /> 및 <ApiLink type="Breadcrumb" />) - 탐색 경로를 표시합니다.
- [Color Picker](./inputs/color-picker.mdx)(<ApiLink type="ColorPicker" />) - 사용자가 색상을 선택할 수 있게 합니다. 다양한 색상 형식과 사용자 지정 팔레트를 지원합니다.
- [QR Code](./inputs/qr-code.mdx)(<ApiLink type="QrCode" />) - `value` 속성의 QR 코드를 SVG로 렌더링합니다. 숫자, 영숫자 또는 바이트 모드로 데이터를 인코딩합니다.
- 가상 스크롤(<ApiLink type="VirtualScroll" />) - 뷰포트에 있는 항목과 `overScan`가 설정하는 추가 항목 수만 렌더링합니다. 크거나 끝이 없는 목록에 사용하십시오.
  - 컴포넌트는 세로 및 가로 방향, 그리고 오른쪽에서 왼쪽(RTL) 레이아웃을 지원합니다.
  - 항목 크기는 고정, `estimatedItemSize`로 추정, 또는 가변으로 설정할 수 있습니다. 컴포넌트는 렌더링된 각 항목을 측정하고 추정치를 보정합니다.
  - 아직 측정되지 않은 항목은 `estimatedItemSize` 대신 측정된 평균 크기를 사용합니다. 그러면 스크롤바가 실제 콘텐츠와 일치합니다.
  - 컴포넌트는 항목 요소를 재활용합니다. 렌더링된 창에 남아 있는 항목은 자신의 요소를 유지합니다. 창에서 나가는 항목의 요소는 창에 들어오는 항목을 표시합니다.
  - `keyFunction` 속성은 항목의 키를 반환합니다. 키가 있으면 항목이 `data`에서 이동해도 자신의 요소를 유지합니다. `keyFunction`가 없으면 인덱스가 키가 됩니다.
  - 항목 템플릿이 바인딩하지 않은 DOM 상태는 요소와 함께 유지됩니다. 예는 `checked` 바인딩이 없는 체크박스의 상태입니다. 항목 템플릿에서 이 상태를 바인딩하십시오.
  - 컴포넌트는 브라우저의 최대 스크롤 크기보다 큰 목록에서도 올바르게 작동합니다.

- `igniteui-dockmanager`를 2.2.1로, `igniteui-grid-lite`를 0.11.0으로 업데이트했습니다. Dock Manager와 Grid Lite 항목을 참조하십시오.
- #### 라이브러리
  - `@lit-labs/virtualizer` 종속성을 제거했습니다. 이제 <ApiLink type="VirtualScroll" /> 컴포넌트가 가상화를 수행합니다. <ApiLink type="Combo" /> 목록도 이를 사용합니다.

  - 이제 컴포넌트는 `role="img"`을 갖습니다. 이전에는 `image`였는데, 이는 현재 도구가 지원하지 않는 ARIA 1.3 값입니다.
  - 접근 가능한 이름은 `alt`에서 가져옵니다. `alt`가 설정되지 않으면 이름은 `initials`에서 가져옵니다. 역할 설명은 항상 `avatar`입니다.
  - 이전에는 이름이 항상 "avatar"였고, `alt` 또는 `initials`가 역할 설명을 설정했습니다.

  - 역할 설명은 항상 `badge`입니다. 보조 기술은 더 이상 `variant`를 읽지 않습니다.
  - `icon` CSS 파트는 <ApiLink type="Icon" />가 배지의 유일한 콘텐츠일 때만 적용됩니다. 이는 문서와 일치합니다.

- #### Chip
  - `onRemove` 이벤트의 유형은 더 이상 불리언 `detail`를 선언하지 않습니다. 이 이벤트에는 이 세부 정보가 한 번도 없었습니다.

  - React 스킬을 에이전트가 스스로 찾을 수 없는 프레임워크별 사실로 줄였습니다. 스킬의 전체 크기는 이전 크기의 약 절반입니다.
  - 참조 파일을 `COMPONENTS`, `USAGE`, `DATAVIZ`, `MCP`, `TROUBLESHOOTING`로 합쳤습니다. 중복된 설정 및 테마 지정 안내를 제거했습니다.
  - 스킬은 이제 MCP 도구의 명명된 인수 스키마를 문서화합니다. 문서 도구는 `framework`을, API 도구는 `platform`를 받습니다.
  - `get_project_setup_guide`를 추가했습니다. 존재하지 않는 `get_theming_guidance`를 `read_resource`로 바꾸었습니다.
  - 스킬은 이제 다크 모드를 `--ig-theme-variant`와 `configureTheme()`가 제어하는 전역 스위치로 문서화합니다. 사용자 지정 속성으로 페이지의 일부에만 다크 모드를 적용할 수는 없습니다.
  - 팔레트 재정의를 바로잡았습니다. 모든 음영은 `500` 음영에서 가져옵니다. 예: `--ig-primary-500`. `--ig-primary-h`, `-s`, `-l` 토큰은 존재하지 않습니다.
  - Excel/CSV 내보내기 가져오기 경로를 `igniteui-react-grids`로 바로잡았습니다. 폼 제출 핸들러 유형을 `React.FormEvent`로, 이벤트 핸들러 유형을 생성된 `Igr*EventArgs` 별칭으로 바로잡았습니다.
  - 그리드 마이그레이션 안내에서 지원 중단된 `IgrGridModule.register()`를 제거했습니다. 존재하지 않는 `--ig-button-foreground` 토큰 예제를 바꾸었습니다.
  - 모든 스킬에 `license: MIT`를 추가했습니다. 각 스킬 설명에 이제 `WHEN TO USE:`와 `WHEN NOT TO USE:` 섹션이 있어 에이전트가 올바른 스킬을 선택합니다.
  - 스킬 README에 이제 Grid Lite에서 프리미엄 그리드로의 마이그레이션 스킬이 나열됩니다.

#### 새 기능

- #### Button Group
  - 단일 선택 모드(`single` 및 `single-required`)는 이제 라디오 그룹 키보드 패턴을 사용합니다:
    - 그룹은 하나의 탭 정지점입니다.
    - 화살표 키는 포커스와 선택을 함께 이동합니다. 비활성화된 버튼은 건너뛰며, 양 끝에서 순환합니다.
    - `alignment="horizontal"`에서는 ArrowLeft와 ArrowRight가 텍스트 방향으로 선택을 이동합니다. `alignment="vertical"`에서는 ArrowUp과 ArrowDown이 선택을 이동합니다.
    - `multiple` 모드는 변경되지 않습니다. 각 버튼은 여전히 탭 정지점입니다.
  - 단일 선택 모드는 이제 `radio` 버튼이 있는 `radiogroup`를 노출합니다. 이전에는 `aria-pressed`가 있는 토글 버튼을 노출했습니다.
  - <ApiLink type="ButtonGroup" /> 호스트는 이제 `radiogroup` 또는 `group` 역할과 비활성화 상태를 가집니다. 호스트의 `aria-label` 또는 `aria-labelledby`가 그룹의 이름을 지정합니다.
  - 단일 선택 모드에서 `alignment`는 라디오 그룹의 `aria-orientation`를 설정합니다.
  - <ApiLink type="ToggleButton" />의 `focused` CSS 파트가 이제 문서화되었습니다.
- #### Calendar, Date Picker, Date Range Picker
  - <ApiLink type="Calendar" />는 이제 `label-inner`, `months-row`, `years-row` CSS 파트를 내보냅니다. 선택기는 이를 `calendar-label-inner`, `months-row`, `years-row`로 내보냅니다.
- #### Chip
  - 새 `outlined` 속성입니다. 윤곽선이 있는 칩을 표시하려면 `true`로 설정하십시오.
  - `start` 및 `end` 슬롯과 새 `action` 및 `remove` CSS 파트가 이제 문서화되었습니다.
- #### Combo, Color Picker, Date Picker, Date Range Picker, Dropdown, Select, Tooltip
  - 새 `scrollStrategy` 속성입니다. 컨테이너가 스크롤될 때 팝업의 동작을 설정합니다:
    - `hide`(기본값)은 앵커가 완전히 보이지 않으면 팝업을 숨깁니다.
    - `scroll`는 팝업을 계속 보이게 하고 앵커 위에 유지합니다.
    - `close`는 스크롤할 때마다 컴포넌트를 닫습니다. 이는 `sticky` 툴팁도 닫습니다.
  - 날짜 선택기는 `dialog` 모드에서 `scrollStrategy`를 무시합니다.
- #### Dropdown
  - 대상 요소는 이제 `aria-haspopup="listbox"`를 가집니다. 이전에는 `aria-haspopup="true"`였습니다.
  - 목록이 열려 있는 동안 대상의 `aria-activedescendant`는 활성 항목을 가리킵니다. 화면 낭독기는 이 항목을 알립니다.
- #### Icon
  - `registerIcon`와 `registerIconFromText`는 이제 세 번째 인수로 `RegisterIconOptions` 객체를 받습니다. 일반 컬렉션 문자열도 계속 작동합니다.
  - `stripMeta: true`는 저장된 SVG에서 `<title>`와 `<desc>` 요소를 제거합니다. 이는 호버 시 브라우저 기본 툴팁을 방지합니다.
  - 제목 텍스트는 호스트 <ApiLink type="Icon" /> 요소의 `aria-label`로 계속 제공됩니다.
- #### Mask Input, Date Time Input, Date Range Picker
  - 마스크 편집기가 이제 실행 취소와 다시 실행을 지원합니다:
    - 실행 취소: `Ctrl + Z` 또는 `Cmd + Z`.
    - 다시 실행: `Ctrl + Y`, `Ctrl + Shift + Z` 또는 `Cmd + Shift + Z`.
  - 연속해서 입력한 문자는 하나의 실행 취소 단계입니다. 연속된 삭제도 하나의 실행 취소 단계입니다.
  - 캐럿 이동, 붙여넣기, 놓기, 잘라내기, 날짜 부분 회전, IME 조합은 각각 새 단계를 시작합니다.
  - 복원된 단계는 `onInput`를 발생시킵니다. 양방향 바인딩은 실행 취소를 따릅니다.
  - 포커스가 바뀌어도 기록은 유지됩니다. 값을 프로그래밍 방식으로 설정하거나, 폼이 컨트롤을 재설정하거나, `mask`, `prompt` 또는 `inputFormat`가 바뀌면 컴포넌트는 기록을 지웁니다.
- #### Splitter
  - 새 `startCollapsed` 및 `endCollapsed` 속성입니다. 각 창의 접힘 상태를 가져오고 설정합니다.
  - 새 `onLayoutChanged` 이벤트입니다. 컴포넌트는 사용자가 크기를 조정하거나 확장 상태가 바뀐 후 이를 발생시킵니다.
  - `onLayoutChanged` 페이로드에는 현재 레이아웃이 포함됩니다: `startSize`, `endSize`, `startCollapsed`, `endCollapsed`.
- #### Tabs
  - 새 `selectedTab` 속성입니다. 선택된 <ApiLink type="Tab" /> 요소를 반환하거나, `null`을 반환합니다.
  - `select()`는 이제 탭의 `id`뿐만 아니라 `label`도 받습니다. `selected`의 값을 다시 `select()`에 전달할 수 있습니다.
  - 탭 헤더에 `aria-posinset`와 `aria-setsize`가 추가되었습니다. 스트립에는 `aria-orientation`가 있습니다.
  - 선택된 패널은 포커스를 받을 수 있습니다. 키보드 사용자는 포커스 가능한 요소가 없는 패널 콘텐츠에도 접근할 수 있습니다.
  - 선택된 탭이 없으면 스트립은 탭 정지점을 유지합니다.
  - 컴포넌트는 이제 중간 슬롯을 통해 들어온 <ApiLink type="Tab" /> 요소를 찾습니다. 다른 컴포넌트가 <ApiLink type="Tabs" />를 감쌀 수 있습니다.
- #### Tooltip
  - 앵커는 이제 `aria-describedby`로 툴팁을 참조합니다. 화면 낭독기는 툴팁 콘텐츠를 앵커의 설명으로 알립니다.
  - `sticky` 모드에서 기본 닫기 동작은 레이블이 있는 `<button>`입니다. 키보드로 접근하고 사용할 수 있습니다. 새 `close-button` CSS 파트가 이를 노출합니다.
- #### Popover
  - Popover 기반 컴포넌트는 이제 이를 지원하는 브라우저에서 네이티브 CSS 앵커 위치 지정을 사용합니다: Chrome 및 Edge 133 이상, Firefox 147 이상, Safari 26 이상.
  - 다른 브라우저는 계속 `@floating-ui/dom`를 사용합니다. 필요한 경우에만 로드합니다.
- #### 테마
  - 모든 컴포넌트에 이제 Material, Bootstrap, Fluent, Indigo 테마의 `forced-colors: active` 스타일이 있습니다.
  - Windows 고대비 모드에서 컴포넌트는 시스템 색상(`CanvasText`, `Highlight`, `GrayText`, `LinkText`)을 사용합니다. 비활성, 호버, 포커스, 선택 상태는 서로 다르게 유지됩니다.

#### 호환되지 않는 변경 사항

- #### Chip
  - `part="base"`는 이제 단순한 래퍼입니다. 선택 컨트롤은 새 `action` 파트로 옮겨졌습니다. 제거 컨트롤은 새 `remove` 파트로 옮겨졌습니다.
  - 상호 작용 표면의 `::part(base)` 규칙을 `::part(action)`로 옮기십시오.
  - `focus-shadow-color`와 `focus-selected-shadow-color`가 `focus-outline-color` 및 `focus-selected-outline-color` CSS 변수를 대체합니다.
- #### AI 지원 개발 - 스킬
  - `grid-lite-to-igr-grid-migration` 스킬의 이름을 `igniteui-react-migrate-grid-lite-to-premium`로 바꾸었습니다. 새 이름은 다른 스킬과 마찬가지로 `igniteui-react-` 접두사를 사용합니다.
  - 새 폴더 이름으로 이름이 바뀐 스킬을 다시 설치하고, 이전 폴더는 삭제하십시오.
  - 각 스킬의 `reference/` 폴더 이름을 `references/`로 바꾸었습니다. 링크가 작동하도록 이 스킬들을 다시 설치하십시오: `igniteui-react-components`, `igniteui-react-customize-theme`, `igniteui-react-generate-from-image-design`.

#### 동작 변경

- #### Combo, Color Picker, Date Picker, Date Range Picker, Dropdown, Select, Tooltip
  - 이제 앵커가 완전히 보이지 않으면 팝업이 숨겨집니다. 이전에는 팝업이 계속 보였습니다. 이전 동작을 유지하려면 `scrollStrategy="scroll"`를 설정하십시오.
- #### Dropdown, Select, Tooltip
  - 팝업은 더 이상 보이도록 뷰포트 가장자리를 따라 움직이지 않습니다. 반대쪽으로 뒤집히기만 합니다.
- #### Button Group
  - 비활성화된 그룹은 더 이상 버튼에 `disabled`를 설정하지 않습니다. 버튼은 비활성화 상태를 상속합니다.
  - 자체 `disabled`가 있는 버튼은 그룹을 다시 활성화해도 비활성 상태를 유지합니다. 비활성화된 그룹에 추가한 버튼도 비활성화됩니다.
  - 단일 선택 모드에서 버튼은 더 이상 별도의 탭 정지점이 아닙니다. 새 기능의 키보드 패턴을 참조하십시오.
- #### Calendar, Date Picker, Date Range Picker
  - `weekStart`가 설정되지 않으면 주는 `locale`의 주 첫 번째 날부터 시작합니다. 컴포넌트는 이 요일을 `Intl.Locale.prototype.getWeekInfo()`에서 가져옵니다.
  - 예를 들어 주는 `bg`에서는 월요일부터, `en`에서는 일요일부터 시작합니다.
  - 명시적인 `weekStart`가 우선합니다. 로캘 값을 다시 사용하려면 `weekStart`를 `undefined`로 설정하십시오. `getWeekInfo()`를 지원하지 않는 브라우저는 일요일을 사용합니다.
  - 헤더 날짜와 월 및 연도 탐색은 `locale`의 필드 순서를 사용합니다. 예를 들어 `ja`에서는 연도 버튼이 월 버튼보다 앞에 옵니다. 연도 보기는 계속 일반 숫자를 표시합니다.
- #### Date Time Input, Date Picker, Date Range Picker
  - 컴포넌트는 사용자가 입력하는 동안 `value`를 바꾸지 않습니다. `value`는 확정(commit) 시점에만, `onChange` 이벤트와 함께 바뀝니다. 컴포넌트는 이전과 같이 포커스를 잃을 때 `onChange`를 발생시킵니다.
  - 이전에는 `value`가 키 입력마다 바뀌었고, 이 변경을 알리는 이벤트가 없었습니다.
  - 이제 <ApiLink type="Grid" />의 편집 템플릿 등에서 외부에서 `value`를 바인딩할 수 있습니다.
  - `onInput` 이벤트의 `detail`에는 입력된 값이 들어 있습니다. 날짜 부분 회전이나 `Ctrl + ;`의 결과도 포함됩니다.
  - 포커스된 편집기에서 날짜 부분을 회전하면 포커스를 잃을 때의 확정도 기다립니다.
  - 포커스가 없는 컴포넌트에서는 `stepUp()`와 `stepDown()`가 `value`를 즉시 바꿉니다. `clear()`, `setRangeText()`, 그리고 직접 할당도 `value`를 즉시 바꿉니다.
  - 선택기에서는 사용자가 입력하는 동안 달력이 계속 입력된 날짜를 따라갑니다.
- #### Dropdown
  - 사용자가 이미 선택된 항목을 선택해도 컴포넌트는 더 이상 `onChange`를 발생시키지 않습니다. 목록은 여전히 닫힙니다.
- #### Tabs
  - 스크롤 버튼은 이제 완전히 보이지 않는 가장 가까운 탭까지 스크롤합니다. 이전에는 고정된 180px 단위로 스크롤했습니다.
  - 스크롤 버튼 아래에 있는 탭은 보이지 않는 것으로 계산됩니다. 한 번 클릭하면 정확히 탭 하나가 더 표시됩니다.
- #### Tooltip
  - 숨김 트리거로 닫히는 툴팁은 이제 정확히 `hideDelay` 동안 기다립니다. 이전에는 문서화되지 않은 추가 180ms를 기다렸습니다.
  - `sticky` 모드에서 기본 닫기 버튼은 툴팁을 즉시 숨깁니다. `hideDelay`를 기다리지 않습니다.
  - 기본 `showTriggers`와 `hideTriggers`에는 이제 `focusin`와 `focusout`가 포함됩니다. 툴팁은 앵커가 키보드 포커스를 받으면 열리고, 포커스가 앵커를 떠나면 닫힙니다.

- [Grid Lite](./grid-lite/overview.mdx)(<ApiLink type="GridLite" />): `igniteui-grid-lite`를 0.9.0에서 0.11.0으로 업데이트했습니다. 이 업데이트에는 [0.10.0](https://github.com/IgniteUI/igniteui-grid-lite/blob/master/CHANGELOG.md#0100---2026-08-26) 및 [0.11.0](https://github.com/IgniteUI/igniteui-grid-lite/blob/master/CHANGELOG.md#0110---2026-09-25) 릴리스가 포함됩니다.

#### 새 기능

- 그리드는 이제 `ElementInternals`을 통해 전체 ARIA 그리드 패턴을 구현합니다: 역할, 행과 열의 개수 및 인덱스, `aria-sort` 및 `aria-selected`. 필터 행은 두 번째 헤더 행입니다.
- 키보드 탐색과 클릭은 이제 DOM 포커스를 활성 셀로 옮깁니다. 화면 낭독기가 셀을 알립니다.
- 새 공개 `columns` setter입니다.

#### 변경됨

- 행 가상화는 이제 <ApiLink type="VirtualScroll" /> 컴포넌트를 사용합니다. 뷰포트 밖에 렌더링되는 행이 줄어듭니다. `@lit-labs/virtualizer` 종속성을 제거했습니다.
- 800px 높이의 그리드에서 10,000개 행과 20개 열로 0.10.0과 비교한 성능입니다:
  - 부드러운 스크롤이 60fps로 실행됩니다. 이전에는 30fps로 실행되었습니다.
  - 먼 스크롤 위치로 이동하는 작업이 8배 빨라졌습니다.
  - 정렬이 8배 빨라졌습니다.
  - 셀 템플릿을 사용하면 개선 폭이 같거나 더 큽니다.
- 열 없이 탐색하면 현재 열을 유지합니다.
- 셀 활성화는 이제 영향을 받는 두 행만 업데이트합니다. 이전에는 보이는 모든 행을 업데이트했습니다.
- 열이 바뀌면 행이 셀을 재사용합니다. 정렬은 하나의 공유 collator를 사용합니다. `ResizeObserver`가 스크롤바 오프셋을 제어합니다.
- 취소 가능한 `onSorting` 및 `onFiltering` 이벤트는 상태가 바뀌기 전에 발생합니다. 리스너는 식을 취소하거나 바꿀 수 있습니다.
- `onSorted` 및 `onFiltered` 이벤트는 데이터 뷰가 업데이트된 후에 발생합니다.

#### 사용 중단됨

- `navigateTo(row, column?, activate?)`의 위치 인수입니다. `navigateTo(row, options)`를 사용하십시오.

        <IgrGrid cellMergeMode="always">
        </IgrGrid>
```

</PlatformBlock>

        <IgrColumn field="Col1" pinned={true} pinningPosition="pinningPosition">
        </IgrColumn>
```

</PlatformBlock>

        pinningPosition = ColumnPinningPosition.End;
        ```

        grid.pinColumn('Col1', 0, ColumnPinningPosition.End);
        grid.pinColumn('Col2', 0, ColumnPinningPosition.Start);
        ```
