# {Platform} Toolbar 개요

{Platform} Toolbar 컴포넌트는 주로 차트 컴포넌트와 함께 사용하는 UI 작업용 보조 컨테이너입니다. `DataChart` 또는 `CategoryChart` 컴포넌트에 연결되면 도구 모음은 미리 설정된 속성과 도구 항목으로 동적으로 업데이트됩니다. 프로젝트용 사용자 지정 도구를 만들어 최종 사용자가 변경할 수 있게 할 수 있으므로, 사실상 무한한 사용자 지정이 가능합니다.

## 사용법

### 도구 작업

다음은 도구 모음에 추가할 수 있는 다양한 `ToolAction` 항목 목록입니다.

- `ToolActionButton`
- `ToolActionCheckbox`
- `ToolActionIconButton`
- `ToolActionIconMenu`
- `ToolActionLabel`
- `ToolActionNumberInput`
- `ToolActionRadio`
- `ToolActionSubPanel`

이 도구들은 각각 마우스 클릭으로 발생하는 `OnCommand` 이벤트를 노출합니다. 참고로 `ToolActionIconMenu`은(는) 다른 도구를 감싸는 래퍼이며, 그 도구는 `ToolActionIconMenu` 안에도 감쌀 수 있습니다.

새 도구와 기존 도구는 `ToolAction` 객체의 `overlayId`, `beforeId` 및 `afterId` 속성을 사용하여 위치를 바꾸고 숨김으로 표시할 수 있습니다. ToolActions는 `ToolAction.visibility` 속성도 노출합니다.

다음 예제는 몇 가지 기능을 보여 줍니다. 먼저 `ToolActionSubPanel`에서 도구를 함께 묶을 수 있으며, 여기에는 **ZoomReset** 및 **AnalyzeMenu** 메뉴 도구 작업과 같은 기본 제공 도구를 숨기는 것도 포함됩니다. 이 예제에서는 `afterId` 속성을 사용하여 **ZoomMenu** 안에 **ZoomReset** 도구 작업의 새 인스턴스를 만들고, 배치를 정확히 맞추기 위해 이를 **ZoomOut**에 할당합니다. 또한 도구의 `isHighlighted` 속성을 통해 강조 표시됩니다.

### {Platform} Data Chart 통합

{Platform} Toolbar에는 `Target` 속성이 있습니다. 이 속성은 아래 코드에서 보는 것처럼 `DataChart` 같은 컴포넌트를 연결하는 데 사용됩니다:

```json-snippet source="/charts/toolbar/layout-actions-for-data-chart"
{
    "descriptions": {
        "aboveContentLeft": {
            "type": "Toolbar",
            "name": "toolbar",
            "targetRef": "chart",
            "orientation": "Horizontal"
        },
        "content": {
            "type": "DataChart",
            "name": "chart",
            "isHorizontalZoomEnabled": true,
            "isVerticalZoomEnabled": true
        }
    }
}
```

`DataChart`이(가) Toolbar와 연결되면 기존 `ToolAction` 항목과 메뉴가 여러 개 사용할 수 있게 됩니다. 기본 제공 {Platform} `DataChart` 도구 작업과 그 관련 `overlayId` 목록은 다음과 같습니다:

확대/축소 작업

- `\ZoomMenu`: 차트의 확대/축소 수준을 높이거나 낮추기 위해 차트의 `m:zoomIn` 및 `m:zoomOut` 메서드를 호출하는 세 개의 `ToolActionLabel` 항목을 노출하는 `ToolActionIconMenu`입니다. 여기에는 `\ZoomReset`도 포함되며, 이는 차트의 `m:resetZoom` 메서드를 호출하여 확대/축소 수준을 기본 위치로 되돌리는 `ToolActionLabel`입니다.

추세 작업

- `\AnalyzeMenu`: 차트의 여러 옵션을 구성하는 여러 옵션을 포함하는 `ToolActionIconMenu`입니다.
- `\AnalyzeHeader`: 하위 섹션 헤더입니다.
  - `\LinesMenu`: 차트에 서로 다른 점선 가로선을 표시하는 여러 도구를 포함하는 하위 메뉴입니다.
  - `\LinesHeader`: 다음 세 도구에 대한 하위 메뉴 섹션 헤더입니다:
    - `\\MaxValue`: 시리즈의 최댓값 위치에 yAxis를 따라 점선 가로선을 표시하는 `ToolActionCheckbox`입니다.
    - `\\MinValue`: 시리즈의 최솟값 위치에 yAxis를 따라 점선 가로선을 표시하는 `ToolActionCheckbox`입니다.
    - `\Average`: 시리즈의 평균값 위치에 yAxis를 따라 점선 가로선을 표시하는 `ToolActionCheckbox`입니다.
  - `\TrendsMenu`: `DataChart` 플롯 영역에 다양한 추세선을 적용하는 도구를 포함하는 하위 메뉴입니다.
  - `\TrendsHeader`: 다음 세 도구에 대한 하위 메뉴 섹션 헤더입니다:
    - **Exponential**: 차트의 각 시리즈에 `trendLineType`을(를) **ExponentialFit**으로 설정하는 `ToolActionRadio`입니다.
    - **Linear**: 차트의 각 시리즈에 `trendLineType`을(를) **LinearFit**으로 설정하는 `ToolActionRadio`입니다.
    - **Logarithmic**: 차트의 각 시리즈에 `trendLineType`을(를) **LogarithmicFit**으로 설정하는 `ToolActionRadio`입니다.
- `\HelpersHeader`: 하위 섹션 헤더입니다.
  - `\SeriesAvg`: `Average` 타입의 `ValueLayerValueMode`를 사용하여 차트의 시리즈 컬렉션에 `ValueLayer`을(를) 추가하거나 제거하는 `ToolActionCheckbox`입니다.
  - `\ValueLabelsMenu`: `DataChart`의 플롯 영역에 다양한 주석을 표시하는 여러 도구를 포함하는 하위 메뉴입니다.
  - `\ValueLabelsHeader`: 다음 도구에 대한 하위 메뉴 섹션 헤더입니다:
    - `\ShowValueLabels`: `CalloutLayer`을(를) 사용하여 데이터 포인트 값을 켜고 끄는 `ToolActionCheckbox`입니다.
    - `\ShowLastValueLabel`: `FinalValueLayer`을(를) 사용하여 마지막 값 축 주석을 켜고 끄는 `ToolActionCheckbox`입니다.
- `\ShowCrosshairs`: 차트의 `crosshairsDisplayMode` 속성을 통해 마우스 오버 십자선 주석을 켜고 끄는 `ToolActionCheckbox`입니다.
- `\ShowGridlines`: X축에 `MajorStroke`을(를) 적용하여 추가 눈금선을 켜고 끄는 `ToolActionCheckbox`입니다.

이미지로 저장 작업

- `\CopyAsImage`: 차트를 클립보드에 복사하는 옵션을 노출하는 `ToolActionLabel`입니다.
- `\CopyHeader`: 하위 섹션 헤더입니다.

### SVG 아이콘

도구를 수동으로 추가할 때 `m:RegisterIconFromText` 메서드를 사용하여 아이콘을 할당할 수 있습니다. 이 메서드에는 세 개의 매개변수를 전달합니다. 첫 번째는 도구에 정의된 아이콘 컬렉션 이름이며, 예를 들어 `iconCollectionName`입니다. 두 번째는 도구에 정의된 아이콘 이름이며, 예를 들어 `iconName`입니다. 그다음에 SVG 문자열을 추가합니다.

### 데이터 URL 아이콘

SVG를 추가하는 것과 비슷하게, `m:registerIconFromDataURL`을(를) 통해 URL에서 아이콘 이미지를 추가할 수도 있습니다. 이 메서드의 세 번째 매개변수에 문자열 URL을 입력합니다.

다음 코드는 SVG 문자열과 URL이라는 두 가지 방식으로 아이콘을 각각 등록하여 두 개의 컬렉션에 넣습니다:

```json-snippet source="/charts/toolbar/custom-actions-for-data-chart" channel="handler" item="ToolbarCustomIconOnViewInit"
{
    "descriptions": {
        "aboveContentLeft": {
            "type": "Toolbar",
            "name": "toolbar"
        }
    },
    "onInit": [
        "ToolbarCustomIconOnViewInit"
    ]
}
```

그다음 도구는 등록된 컬렉션과 그 아이콘이 등록된 이름으로 등록된 아이콘을 요청합니다:

```json-snippet source="/charts/toolbar/layout-actions-for-data-chart"
{
    "type": "ToolActionLabel",
    "title": "Custom Icon",
    "iconName": "CustomIcon",
    "iconCollectionName": "CustomCollection"
}
```

### Color Editor

{Platform} Toolbar에 사용자 지정 색 편집기 도구를 추가할 수 있으며, 이 도구는 Command 이벤트와 함께 작동하여 애플리케이션에 사용자 지정 스타일을 적용할 수도 있습니다.

```json-snippet source="/charts/toolbar/color-editor-support"
{
    "descriptions": {
        "aboveContentLeft": {
            "type": "Toolbar",
            "name": "toolbar",
            "targetRef": "chart",
            "actions": [
                {
                    "type": "ToolActionColorEditor",
                    "title": "Series Brush",
                    "name": "colorEditorTool",
                    "commandId": "ToggleSeriesBrush"
                }
            ]
        },
        "content": {
            "type": "DataChart",
            "name": "chart",
            "isHorizontalZoomEnabled": true
        }
    }
}
```
