# {Platform} Navbar 개요

{ProductName} Navbar는 앱에서 사용자의 현재 위치를 알려 줍니다. 탐색 모음은 검색이나 즐겨찾기 같은 빠른 작업으로 가는 링크도 제공할 수 있어, 사용자가 잘못된 경로나 상태로 이동하지 않고도 애플리케이션을 원활하게 탐색하도록 돕습니다. 이 모음은 배치된 컨테이너의 맨 위에 놓입니다.

### 콘텐츠

시작 또는 끝 위치의 콘텐츠로 <ApiLink pkg="core" type="Icon" /> 또는 다른 컴포넌트를 추가하여 <ApiLink pkg="core" type="Navbar" /> 컴포넌트를 강화하면, 사용자가 모음에서 주요 위치로 바로 이동할 수 있습니다:

<PlatformBlock for="WebComponents">

```html
<igc-navbar>
    <igc-icon name="home" slot="start"></igc-icon>
    <h2>Sample App</h2>
    <igc-icon name="search" slot="end"></igc-icon>
    ...
</igc-navbar>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```Razor
<IgbNavbar>
    <IgbIcon @ref="@HomeIcon" slot="start" IconName="home" Collection="material" />
    <h3>Sample App</h3>
    <IgbIcon @ref="@SearchIcon" slot="end" IconName="search" Collection="material" />
    ...
</IgbNavbar>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
 <IgrNavbar>
    <div slot="start">
        <IgrIcon name="home" collection="material" />
    </div>
    <h2>Sample App</h2>
    <div slot="end">
        <IgrIcon name="search" collection="material" />
    </div>
    ...
</IgrNavbar>

```

</PlatformBlock>

## 스타일링

<ApiLink pkg="core" type="Navbar" /> 컴포넌트는 여러 CSS 파트를 노출하므로 스타일을 완전히 제어할 수 있습니다:

|이름|설명|
|--|--|
| `base` | 탐색 모음의 기본 래퍼입니다. |
| `start` | 왼쪽 정렬 아이콘 컨테이너입니다. |
| `middle` | 탐색 모음 제목 컨테이너입니다. |
| `end` | 오른쪽 정렬 작업 아이콘 컨테이너입니다. |

```css
igc-icon {
  color: var(--ig-primary-500);
}

igc-navbar {
  background-color: var(--ig-secondary-200);
}

igc-navbar::part(middle) {
  font-family: Titillium Web, sans-serif;
  color: var(--ig-primary-500);;
}
```
