# {Platform} Navigation Drawer 개요

{ProductName} Navigation Drawer는 콘텐츠 안에서 펼치거나 접을 수 있는 측면 탐색을 제공합니다. 미니 버전은 닫혀 있어도 탐색에 빠르게 접근할 수 있게 합니다. 콘텐츠는 완전히 사용자 지정할 수 있으며, 기본 메뉴 항목 스타일도 제공합니다.

## Navbar 통합

드로어에는 어떤 콘텐츠든 제공할 수 있지만, <ApiLink pkg="core" type="NavDrawerItem" />을(를) 사용하면 항목에 기본 제공 스타일을 바로 적용할 수 있습니다.

컴포넌트를 조금 더 보강하기 위해 <ApiLink pkg="core" type="Navbar" />과(와) 함께 사용할 수 있습니다. 이렇게 하면 더 완성된 모습을 얻고 드로어의 메서드를 사용할 수 있습니다. 다음 예제에서 이를 사용하는 방법을 살펴보겠습니다:

        Sample Drawer

        <igc-icon slot="icon" name="home"></igc-icon>
        <span slot="content">Home</span>
    </igc-nav-drawer-item>
    <igc-nav-drawer-item>
        <igc-icon slot="icon" name="search"></igc-icon>

마지막으로 탐색 드로어를 열고 닫는 방법이 필요합니다. 이를 구현하는 방법은 여러 가지가 있지만, 이 예제에서는 다음과 같이 하겠습니다:

<PlatformBlock for="WebComponents">

```ts
// ...
const menu = document.getElementById('menu');
const navDrawer = document.querySelector('igc-nav-drawer') as IgcNavDrawerComponent;

menu!.addEventListener('click', () => {
    navDrawer.show();
})

document.getElementById('root')!.onclick = (e) => {
    if (e.target != document.getElementById('navDrawer')) {
        navDrawer.hide();
    }
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
public void OnMenuIconClick()
{
    if (this.NavDrawerRef != null)
    {
        this.NavDrawerRef.Show();
    }
}
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
public onMenuIconClick() {
    if (this.navDrawerRef) {
        this.navDrawerRef.show();
    }
}
```

</PlatformBlock>

## 스타일링

<ApiLink pkg="core" type="NavDrawer" />은(는) 여러 CSS 파트(`base`, `main`, `mini`)를 노출하므로 스타일을 완전히 제어할 수 있습니다.

```scss
igc-nav-drawer::part(base) {
  background: var(--ig-secondary-500);
}

igc-nav-drawer-item::part(base) {
  color: var(--ig-secondary-500-contrast);
}

igc-nav-drawer-item::part(base):hover {
  background-color: var(--ig-gray-800);
}

igc-nav-drawer-item[active]::part(base) {
  background: var(--ig-warn-500);
  color: var(--ig-warn-500-contrast);
}

igc-nav-drawer-header-item {
  color: var(--ig-warn-500);
}
```
