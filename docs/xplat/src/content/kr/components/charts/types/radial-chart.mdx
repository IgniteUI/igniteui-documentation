# {Platform} 방사형 차트

{ProductName} 방사형 차트는 데이터를 받아 (수평선을 따라 늘이는 대신) 원 주위에 감싸인 데이터 지점의 모음으로 렌더링합니다. 방사형 차트는 또한 카테고리 목록을 차트 범위의 최솟값에서 최댓값까지 매핑하며, 카테고리 그룹화 메커니즘을 지원합니다.

## {Platform} 방사형 영역 차트

{Platform} 방사형 영역 차트는 데이터 지점을 잇는 직선 모음으로 둘러싸인 채워진 다각형 모양입니다. 이 차트 유형은 [영역 차트](area-chart.mdx)와 같은 데이터 플롯 개념을 사용하지만, 데이터 지점을 수평으로 늘이는 대신 원형 축 주위에 배치합니다. 아래 예제와 같이 데이터를 `RadialAreaSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다.

<Sample src="/charts/data-chart/radial-area-chart" height={600} alt="{Platform} 방사형 영역 차트" />




## {Platform} 방사형 열 차트

방사형 열 차트는 차트 중심에서 데이터 지점의 위치를 향해 뻗는 직사각형 모음을 사용하여 시각화됩니다. 이는 [열 차트](column-chart.mdx)와 같은 데이터 플롯 개념을 사용하지만, 데이터 지점을 수평으로 늘이는 대신 원 주위에 배치합니다. 아래 예제와 같이 데이터를 `RadialColumnSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

<Sample src="/charts/data-chart/radial-column-chart" height={600} alt="{Platform} 방사형 열 차트" />




## {Platform} 방사형 선 차트

{Platform} 방사형 선 차트는 데이터 지점을 잇는 직선 모음으로 렌더링됩니다. 이 차트 유형은 [선 차트](line-chart.mdx)와 같은 데이터 플롯 개념을 사용하지만, 데이터 지점을 수평으로 늘이는 대신 원형 축 주위에 배치합니다. 아래 예제와 같이 데이터를 `RadialLineSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

<Sample src="/charts/data-chart/radial-line-chart" height={600} alt="{Platform} 방사형 선 차트" />




## {Platform} 방사형 파이 차트

방사형 파이 차트는 차트 중심에서 데이터 지점의 위치를 향해 뻗는 파이 조각을 사용합니다. 이 차트 유형은 여러 데이터 지점 시리즈를 범주화하는 개념을 가져와, 데이터 지점을 수평선을 따라 늘이는 대신 원형 축 주위에 배치합니다. 아래 예제와 같이 데이터를 `RadialPieSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:
