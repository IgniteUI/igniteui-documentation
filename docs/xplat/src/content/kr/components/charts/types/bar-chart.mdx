# {Platform} 막대 차트
{ProductName} 막대 차트, 막대 그래프 또는 수평 막대 차트는 서로 다른 카테고리의 데이터 빈도, 개수, 합계 또는 평균을 빠르게 비교하는 데 사용되는 가장 일반적인 카테고리 차트 유형 중 하나이며, 데이터는 높이는 같지만 길이가 다른 수평 막대로 인코딩됩니다. 이 차트는 시간에 따른 항목 값의 변화를 보여 주는 데 이상적입니다. 데이터는 차트의 왼쪽에서 오른쪽으로, 데이터 지점의 값을 향해 뻗는 직사각형 모음으로 표현됩니다. 막대 차트는 [열 차트](column-chart.mdx)와 매우 비슷하지만, 막대 차트는 시계 방향으로 90도 회전하여 렌더링되므로 수평 방향(왼쪽에서 오른쪽)을 가지며, [열 차트](column-chart.mdx)는 수직 방향(위와 아래)을 가집니다.

## 막대 차트 권장 사항

### {Platform} 막대 차트가 프로젝트에 적합합니까?
{Platform} 막대 차트는 데이터나 데이터로 올바른 이야기를 전달하려는 방식에 따라 여러 변형을 포함합니다. 여기에는 다음이 포함됩니다:

- 그룹 막대 차트
- 누적 막대 차트
- 극좌표 막대 차트
- 누적 100 막대 차트

### 막대 차트 사용 사례
막대 차트를 선택하는 일반적인 사용 사례는 다음과 같습니다:

- 데이터 카테고리에서 시간에 따른 추세나 숫자 값의 변화를 보여 줘야 하는 경우.
- 하나 이상의 데이터 시리즈의 데이터 값을 비교해야 하는 경우.
- 부분 대 전체 비교를 보여 주고 싶은 경우.
- 카테고리의 상위 또는 하위 백분율을 보여 주고 싶은 경우.
- 하위 카테고리로 그룹화된 여러 데이터 지점을 분석하는 경우(누적 막대).

이러한 사용 사례는 일반적으로 다음 시나리오에서 사용됩니다:

- 판매 관리.
- 재고 관리.
- 주식 차트.
- 숫자 값 또는 시계열 값과 비교하는 모든 문자열 값.

### 막대 차트 모범 사례
- 숫자 축은 0에서 시작하십시오.
- 막대에는 단일 색상을 사용하십시오.
- 각 막대를 구분하는 간격이 막대 자체 너비의 1/2인지 확인하십시오.
- 순위를 매기거나 순서가 있는 카테고리(항목)를 비교할 때는 오름차순 또는 내림차순으로 정렬되어 있는지 확인하십시오.
- 가독성을 위해 Y축(차트 왼쪽 레이블)의 카테고리 값은 오른쪽 정렬하십시오.

### 막대 차트를 사용하지 말아야 하는 경우
- 데이터가 너무 많아서 Y축이 공간에 맞지 않거나 읽을 수 없습니다.
- 상세한 시계열 분석이 필요한 경우 - 이 유형의 데이터에는 시계열이 있는 [선 차트](line-chart.mdx)를 고려하십시오.

### 막대 차트 데이터 구조
- 데이터 소스는 배열 또는 데이터 항목의 목록이어야 합니다.
- 데이터 소스에는 최소 하나의 데이터 항목이 있어야 합니다.
- 목록에는 최소 하나의 데이터 열(문자열 또는 날짜-시간)이 있어야 합니다.
- 목록에는 최소 하나의 숫자 데이터 열이 있어야 합니다.

## {Platform} 누적 막대 차트

누적 막대 차트(또는 누적 막대 그래프)는 차트의 수평 막대에 크기가 다른 조각을 표시하여 서로 다른 데이터 카테고리의 구성을 비교하는 데 사용되는 카테고리 차트 유형입니다. 각 막대 또는 조각의 쌓인 길이는 전체 값에 비례합니다.

누적 막대 차트는 데이터를 시각적으로 묶기 위해 데이터 지점을 가로로 나란히 쌓는다는 점에서 막대 차트와 다릅니다. 각 스택에는 양수 값과 음수 값이 모두 포함될 수 있습니다. 모든 양수 값은 X축의 양의 쪽에 묶이고, 모든 음수 값은 X축의 음의 쪽에 묶입니다.

## {Platform} 범위 막대 차트

{Platform} 범위 막대 차트는 범위 차트 그룹에 속하며, 전통적인 [카테고리 막대 차트](bar-chart.mdx#{PlatformLower}-막대-차트-예제)처럼 왼쪽에서 뻗어 나오는 대신 차트의 플롯 영역 가운데에 나타날 수 있는 수평 직사각형으로 렌더링됩니다. 이 시리즈 유형은 일정 기간 동안 같은 데이터 지점의 낮은 값과 높은 값 사이의 변화량을 강조하거나 여러 항목을 비교합니다.

범위 값은 X축에 표시되고 카테고리는 Y축에 표시됩니다. 각 막대는 낮은 값과 높은 값을 모두 시각화하므로, 일별 기온 범위, 최저 및 최고 가격, 또는 단일 값으로는 충분하지 않은 제한된 측정값을 보여 주는 시나리오에 유용합니다.

범위 막대 차트는 범위가 수직 열이 아니라 수평 막대 세트로 표현된다는 점을 제외하고는 모든 측면에서 [범위 열 차트](column-chart.mdx#{PlatformLower}-범위-열-차트)와 동일합니다.

아래 예제와 같이 데이터를 `RangeBarSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다. 이 시리즈는 `LowMemberPath`와 `HighMemberPath`에서 낮은 값과 높은 값을 읽으며, 일반적으로 `CategoryYAxis`와 함께 `NumericXAxis`를 사용합니다:
