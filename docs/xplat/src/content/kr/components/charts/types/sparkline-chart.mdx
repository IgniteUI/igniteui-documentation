# {Platform} 스파크라인

{ProductName} 스파크라인은 경량 차트 컨트롤입니다. 그리드 셀처럼 소규모 레이아웃에 렌더링하도록 설계되었지만 단독으로도 렌더링할 수 있습니다. `Sparkline`에는 차트 유형, 마커, 범위, 추세선, 알 수 없는 값 플로팅, 툴팁 등 구성하고 사용자 지정할 수 있는 여러 시각 요소와 해당 기능이 있습니다.

## 스파크라인 권장 사항

### 스파크라인 차트가 프로젝트에 적합합니까?
다른 차트 컨트롤과 비교했을 때 스파크라인 컨트롤의 주요 장점은 그리드 셀처럼 제한된 공간에서도 모든 시각 요소를 표시하며 렌더링할 수 있다는 것입니다.

{Platform} 스파크라인은 타원형 아이콘으로 데이터 지점을 표시하여 가장 높은 값, 가장 낮은 값, 첫 번째 값, 마지막 값, 음수 값을 나타낼 수 있습니다. 마커는 원하는 모양, 색상 또는 이미지로 사용자 지정할 수 있습니다.

### 스파크라인 사용 사례
- 차트를 표시할 공간이 좁은 경우.
- 주간 매출과 같은 일련의 값에서 추세를 보여 주고 싶은 경우.

### 스파크라인 모범 사례
- 데이터 비교가 정확하도록 Y축(왼쪽 또는 오른쪽 축)은 항상 0에서 시작하십시오.
- 시계열 데이터는 왼쪽에서 오른쪽으로 정렬하십시오.
- 일련의 데이터를 보여 주려면 실선과 같은 시각적 속성을 사용하십시오.

### 스파크라인을 사용하지 말아야 하는 경우
- 데이터를 자세히 분석해야 하는 경우.
- 데이터 지점의 모든 레이블을 표시해야 하는 경우. Y축에서는 최고 값과 최저 값만, X축에서는 첫 번째 값과 마지막 값만 표시할 수 있습니다.

### 스파크라인 데이터 구조
- 1차원 데이터가 필요합니다.
- 데이터 세트에는 최소 두 개의 숫자 필드가 포함되어야 합니다.
- 데이터 소스 필드의 텍스트를 사용하여 X축의 첫 번째 레이블과 마지막 레이블을 표시할 수 있습니다.

## 스파크라인 유형
{Platform}는 `displayType` 속성을 적절히 설정하여 다음 유형의 스파크라인을 지원합니다:

- `Line`: 숫자 데이터로 스파크라인의 선 차트 유형을 표시하며, 데이터 지점을 선분으로 연결합니다. 스파크라인에서 데이터를 시각화하려면 최소 두 개의 데이터 지점이 필요합니다.
- `Area`: 숫자 데이터로 스파크라인의 영역 차트 유형을 표시합니다. 각 선이 그려진 후 영역을 닫는 단계가 추가된 선 유형과 비슷합니다. 스파크라인에서 데이터를 시각화하려면 최소 두 개의 데이터 지점이 필요합니다.
- `Column`: 숫자 데이터로 스파크라인의 열 차트 유형을 표시합니다. 세로 막대라고도 합니다. 이 유형은 단일 데이터 지점도 렌더링할 수 있지만, 제공된 단일 데이터 지점이 보이도록 스파크라인에서 최소 값 범위 속성(minimum)을 지정해야 합니다. 그렇지 않으면 값이 최솟값으로 처리되어 보이지 않습니다.
- `WinLoss`: 이 유형은 시각적 외관이 열 차트 유형과 비슷하며, 각 열의 값이 데이터 세트의 양의 최댓값(양수 값의 경우) 또는 음의 최솟값(음수 값의 경우)과 같습니다. 이는 승리 또는 패배 시나리오를 나타내기 위한 것입니다. 승/패 차트가 올바르게 표시되려면 데이터 세트에 양수 값과 음수 값이 모두 있어야 합니다. 승/패 스파크라인을 숫자 값의 컬렉션에 바인딩할 수 있는 선 유형 같은 다른 유형과 같은 데이터에 바인딩하면, {Platform} 스파크라인은 컬렉션에서 두 값(가장 높은 값과 가장 낮은 값)을 선택하고 그 값을 기준으로 스파크라인을 렌더링합니다.

## 마커

{Platform} 스파크라인에서는 X/Y 좌표에 따라 개별 데이터 지점을 나타내기 위해 시리즈 위에 원형 색상 아이콘으로 마커를 표시할 수 있습니다. 마커는 `Line`, `Area`, `Column` 표시 유형의 스파크라인에 설정할 수 있습니다. `WinLoss` 유형의 스파크라인은 현재 마커를 지원하지 않습니다. 기본적으로 마커는 표시되지 않지만, 해당 마커 가시성 속성을 설정하여 활성화할 수 있습니다.

스파크라인의 마커는 다음 위치의 어떤 조합으로도 배치할 수 있습니다:

- `MarkerVisibility`: 스파크라인의 모든 데이터 점에 마커를 표시합니다.
- `LowMarkerVisibility`: 가장 낮은 값의 데이터 점에 마커를 표시합니다. 가장 낮은 값을 가진 점이 여러 개이면 해당 값을 가진 각 점에 표시됩니다.
- `HighMarkerVisibility`: 가장 높은 값의 데이터 점에 마커를 표시합니다. 가장 높은 값을 가진 점이 여러 개이면 해당 값을 가진 각 점에 표시됩니다.
- `FirstMarkerVisibility`: 스파크라인의 첫 번째 데이터 점에 마커를 표시합니다.
- `LastMarkerVisibility`: 스파크라인의 마지막 데이터 점에 마커를 표시합니다.
- `NegativeMarkerVisibility`: 스파크라인에 그려진 음수 데이터 점에 마커를 표시합니다.

위에서 언급한 모든 마커는 관련 마커 유형의 속성을 사용하여 색상, 가시성, 크기 측면에서 사용자 지정할 수 있습니다. 예를 들어 위의 `\\Low` 마커에는 `lowMarkerBrush`, `lowMarkerVisibility`, `lowMarkerSize` 속성이 있습니다.

## 정상 범위

{Platform} 스파크라인의 정상 범위 기능은 데이터를 시각화할 때 미리 정의된 의미 있는 범위를 나타내는 가로 띠입니다. 정상 범위는 원하는 색상으로 윤곽선을 그린 음영 영역으로 설정할 수 있습니다.

정상 범위는 최대 데이터 지점보다 넓거나 그 이상일 수 있으며, 예를 들어 임계값 표시기 역할을 하도록 스파크라인의 `Line` 표시 유형처럼 얇게 만들 수도 있습니다. 정상 범위의 너비는 정상 범위를 표시하는 데 필요한 최소 설정 역할을 하는 다음 세 가지 속성으로 결정됩니다:

- `NormalRangeVisibility`: 정상 범위가 보이는지 여부입니다.
- `NormalRangeMaximum`: 범위의 아래쪽 경계입니다.
- `NormalRangeMinimum`: 범위의 위쪽 경계입니다.

기본적으로 정상 범위는 표시되지 않습니다. 활성화하면 정상 범위가 밝은 회색 외관으로 나타나며, 이는 `normalRangeFill` 속성을 사용하여 구성할 수도 있습니다.

`displayNormalRangeInFront` 속성을 설정하여 {Platform} 스파크라인에서 정상 범위를 플롯된 시리즈의 앞에 표시할지 뒤에 표시할지도 구성할 수 있습니다.

## 추세선

{Platform} 스파크라인은 실제 스파크라인 레이어 위에 또 다른 레이어로 표시되는 다양한 추세선을 지원합니다. 스파크라인을 표시하려면 `TrendLineType` 속성을 사용할 수 있습니다.

추세선은 차트가 바인딩된 데이터의 값을 사용하여 `TrendLineType` 속성에 지정된 알고리즘에 따라 계산됩니다.

추세선은 한 번에 하나만 표시할 수 있으며, 기본적으로 추세선은 표시되지 않습니다.

## 알 수 없는 값 보간

{Platform} 스파크라인은 알 수 없는 값을 감지하고, 지정된 보간 알고리즘을 통해 알 수 없는 값의 공간을 렌더링할 수 있습니다. 데이터에 null 값이 포함되어 있는데 이 기능을 사용하지 않으면, 즉 보간을 지정하지 않으면 알 수 없는 값은 플롯되지 않습니다.
