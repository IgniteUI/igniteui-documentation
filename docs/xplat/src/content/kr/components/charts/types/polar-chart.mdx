# {Platform} 극좌표 차트
{ProductName} 극좌표 차트는 차트에서 데이터를 플롯하기 위해 직교 좌표계(x, y) 대신 극좌표계(각도, 반지름)를 사용합니다. 즉, 극좌표 차트는 [산점 시리즈](scatter-chart.mdx)의 개념을 가져와 데이터 지점을 수평으로 늘이는 대신 원 주위에 배치합니다. 과학 데이터(예: 풍향과 풍속, 자기장의 방향과 세기, 태양계의 물체 위치)를 플롯하는 데 자주 사용되며, 수집된 데이터가 예측 결과에서 벗어나는 정도를 강조할 수 있습니다.

## {Platform} 극좌표 영역 차트
극좌표 영역 차트는 데이터 지점을 잇는 다각형 모음으로 렌더링되며, 데이터 플롯 개념은 [카테고리 영역 차트](area-chart.mdx#{PlatformLower}-영역-차트-예제)와 같지만 데이터 지점을 수평으로 늘이는 대신 원 주위에 배치한다는 차이가 있습니다. 아래 예제와 같이 데이터를 `PolarAreaSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

## {Platform} 극좌표 스플라인 영역 차트
극좌표 스플라인 영역 차트도 다각형 모음으로 렌더링되지만, [극좌표 영역 차트](polar-chart.mdx#{PlatformLower}-극좌표-영역-차트)처럼 직선이 아니라 데이터 지점을 잇는 곡선 스플라인을 사용합니다. 아래 예제와 같이 데이터를 `PolarAreaSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

## {Platform} 극좌표 마커 차트
극좌표 마커 차트는 극좌표(각도/반지름) 좌표계에서 데이터 지점을 나타내는 마커 모음으로 렌더링됩니다. 이 차트는 [산점 마커 차트](scatter-chart.mdx#{PlatformLower}-산점도-마커-차트)와 같은 데이터 플롯 개념을 사용하지만, 데이터 지점을 수평으로 늘이는 대신 원 주위에 배치한다는 차이가 있습니다. 아래 예제와 같이 데이터를 `PolarScatterSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

<Sample src="/charts/data-chart/polar-scatter-chart" height={600} alt="{Platform} 극좌표 마커 차트" />

## {Platform} 극좌표 선 차트
