# {Platform} 계단형 차트

{ProductName} 계단형 차트는 연속된 수직선과 수평선으로 연결된 점들의 모음으로 렌더링되는 카테고리 차트 그룹에 속합니다. 값은 y축에 표시되고 카테고리는 x축에 표시됩니다. 계단형 차트는 일정 기간 동안의 변화량을 강조하거나 여러 항목을 비교합니다.

## {Platform} 계단형 영역 차트

아래 예제와 같이 `chartType` 속성을 `StepArea` 열거형으로 설정하여 `CategoryChart` 컨트롤에서 {Platform} 계단형 영역 차트를 만들 수 있습니다.

<Sample src="/charts/category-chart/step-area-multiple-sources" height={600} alt="{Platform} 다중 소스 계단형 영역 차트" />

## {Platform} 계단형 선 차트

{Platform} 계단형 선 차트는 선 아래 영역이 채워진다는 점을 제외하면 계단형 영역 차트와 매우 비슷합니다.

아래 예제와 같이 데이터를 바인딩하고 `chartType` 속성을 `StepLine` 값으로 설정하여 `CategoryChart` 컨트롤에서 계단형 선 차트를 만들 수 있습니다.

## {Platform} 계단형 차트 스타일 지정

다른 시리즈를 복합하는 등 더 많은 기능이 있는 계단형 차트가 필요하다면, 아래 시연된 것처럼 `CategoryChart` 컨트롤에서 `markerTypes`, `markerBrushes`, `markerOutlines`, 선의 `DomainChart.brushes`, 선의 `DomainChart.outlines` 속성을 구성할 수 있습니다.
