# {Platform} 누적 차트

{ProductName} 누적 차트는 데이터 항목의 여러 값을 누적 영역/다각형, 막대, 열, 선 또는 스플라인으로 렌더링하는 특별한 차트 그룹에 속합니다. 표준 누적 차트는 데이터 항목의 실제 값을 렌더링하고, 누적 100% 차트는 값을 총합에 대한 백분율로 렌더링합니다.

## {Platform} 누적 영역 차트

누적 영역 차트는 선 세그먼트로 연결된 점들의 모음으로 렌더링되며, 선 아래 영역이 채워지고 서로 위에 쌓입니다. 누적 영역 차트는 [영역 차트](./area-chart.mdx)와 같은 모든 요구 사항을 따르며, 차이점은 시각적으로 음영 영역이 서로 위에 쌓인다는 것뿐입니다.

아래 예제와 같이 데이터를 `StackedAreaSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다.

## {Platform} 누적 막대 차트

누적 막대 차트(또는 누적 막대 그래프)는 차트의 수평 막대에 크기가 다른 조각을 표시하여 서로 다른 데이터 카테고리의 구성을 비교하는 데 사용되는 카테고리 차트 유형입니다. 각 막대 또는 조각의 쌓인 길이는 전체 값에 비례합니다.

누적 막대 차트는 데이터를 시각적으로 묶기 위해 데이터 지점을 가로로 나란히 쌓는다는 점에서 [막대 차트](./bar-chart.mdx)와 다릅니다. 각 스택에는 양수 값과 음수 값이 모두 포함될 수 있습니다. 모든 양수 값은 X축의 양의 쪽에 묶이고, 모든 음수 값은 X축의 음의 쪽에 묶입니다.

이 누적 막대 차트 예제에서는 숫자 X축(차트 하단 레이블)과 카테고리 Y축(차트 왼쪽 레이블)을 사용합니다. 아래 예제와 같이 데이터를 `StackedBarSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다.

<Sample src="/charts/data-chart/stacked-bar-chart" height={600} alt="{Platform} 누적 막대 차트" />

## {Platform} 누적 100% 막대 차트

{Platform} 누적 100% 막대 차트는 X축(차트 하단 레이블)의 값을 처리하는 방식을 제외하고는 모든 측면에서 {Platform} 누적 막대 차트와 동일합니다. 누적 100% 막대 차트는 데이터를 직접 표현하는 대신, 데이터 지점의 모든 값 합계에 대한 백분율로 데이터를 표시합니다.

이 누적 100% 막대 차트 예제에서는 에너지 제품 값이 수평 막대의 조각에 있는 모든 데이터의 100% 값으로 표시됩니다. 아래 예제와 같이 데이터를 `Stacked100BarSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다.

<Sample src="/charts/data-chart/stacked-100-bar-chart" height={600} alt="{Platform} 누적 100 막대 차트" />

## {Platform} 누적 열 차트

누적 열 차트는 시리즈를 옆이 아니라 서로 위에 표시한다는 점을 제외하면 모든 측면에서 [열 차트](./column-chart.mdx)와 동일합니다. 누적 열 차트는 시리즈 간 비교 결과를 보여 주는 데 사용됩니다. 모음 안의 각 쌓인 조각은 각 스택에서 하나의 시각 요소를 나타냅니다. 각 스택에는 양수 값과 음수 값이 모두 포함될 수 있습니다. 모든 양수 값은 Y축의 양의 쪽에 묶이고, 모든 음수 값은 Y축의 음의 쪽에 묶입니다. 누적 열 차트는 누적 막대 차트와 같은 데이터 플롯 개념을 사용하지만, 데이터 지점이 수평선(X축)을 따라 쌓이는 대신 수직선(Y축)을 따라 쌓입니다.

아래 예제와 같이 데이터를 `StackedColumnSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다.
