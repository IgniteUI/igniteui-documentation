# {Platform} 간트 차트

{ProductName} 간트 차트는 다양한 카테고리를 시계열로 시각화하는 막대 차트의 한 유형입니다. 간트 차트는 시간 기간 블록에서 시작 시간과 종료 시간을 보여 줍니다. 활동(작업 또는 이벤트)을 시간에 대해 표시하는 가장 인기 있고 유용한 방법 중 하나로 프로젝트 관리에서 자주 사용됩니다. 차트의 왼쪽에는 활동 목록이 있고 위쪽에는 적절한 시간 척도가 있습니다. 각 활동은 막대로 표현되며, 막대의 위치와 길이는 활동의 시작 날짜, 기간, 종료 날짜를 반영합니다.
