# {Platform} 영역 차트

{ProductName} 영역 차트는 직선 세그먼트로 연결된 점들의 모음으로 렌더링되며, 선 아래 영역이 채워집니다. 값은 y축(왼쪽 레이블)에 표시되고 카테고리는 x축(하단 레이블)에 표시됩니다. 이 차트는 플롯된 값의 합계를 표시하여 일정 기간 동안의 변화량이나 여러 항목의 비교, 그리고 부분과 전체의 관계를 강조합니다. 따라서 대개 시간순으로 되어 있으며, 예를 들어 시간에 따른 상품의 누적과 같이 양의 변화를 보여 줍니다.

## 영역 차트 권장 사항

### 영역 차트 사용 사례

영역 차트를 선택하는 일반적인 사용 사례는 다음과 같습니다:

- 이동, 확대/축소, 드릴다운과 같은 차트 상호 작용에 잘 맞는 대용량 데이터 세트가 있는 경우.
- 시간에 따른 데이터의 추세를 비교해야 하는 경우.
- 2개 이상의 데이터 시리즈 간의 차이를 보여 주고 싶은 경우.
- 뚜렷한 카테고리 간의 누적된 부분 대 전체 비교를 보여 주고 싶은 경우.
- 비교 분석을 위해 하나 이상의 카테고리에 대한 데이터 추세를 보여 줄 필요가 있는 경우.
- 세부적인 시계열 데이터를 시각화해야 하는 경우.

### 영역 차트 모범 사례

- 데이터 비교가 정확하도록 Y축(왼쪽 또는 오른쪽 축)은 항상 0에서 시작하십시오.
- 시계열 데이터는 왼쪽에서 오른쪽으로 정렬하십시오.
- 다른 시리즈 뒤에 플롯된 데이터가 가려지지 않도록 투명한 색상을 사용하십시오.

### 영역 차트를 사용하지 말아야 하는 경우

- 데이터 시리즈가 많습니다(7개 또는 10개를 초과). 차트를 읽기 쉽게 유지하는 것이 목표입니다.
- 시계열 데이터의 값이 비슷합니다(같은 기간의 데이터). 이 경우 겹치는 음영 영역을 구분할 수 없습니다.

### 영역 차트 데이터 구조

- 데이터 소스는 배열 또는 데이터 항목의 목록이어야 합니다(단일 시리즈의 경우).
- 데이터 소스는 배열의 배열 또는 목록의 목록이어야 합니다(여러 시리즈의 경우).
- 데이터 항목 사이에 선을 렌더링하려면 데이터 소스에 두 개 이상의 데이터 항목이 있어야 합니다.
- 모든 데이터 항목에는 최소 하나의 데이터 열(문자열 또는 날짜-시간)이 있어야 합니다.
- 모든 데이터 항목에는 최소 하나의 숫자 데이터 열이 있어야 합니다.

## {Platform} 계단형 영역 차트

{Platform} 누적 100% 스플라인 영역 차트는 y축 값을 처리하는 방식을 제외하고는 모든 측면에서 누적 스플라인 영역 차트와 동일합니다. 누적 100% 스플라인 영역 차트는 데이터를 직접 표현하는 대신, 특정 데이터 지점의 모든 값 합계에 대한 백분율로 데이터를 표시합니다. 이 차트는 때때로 시간에 따라 변하는 전체의 일부를 나타냅니다. 예를 들어 한 국가의 에너지 소비량을 생산 원천별로 나타내는 경우입니다. 이러한 경우에는 쌓인 모든 요소를 동일하게 표현하는 것이 더 나을 수 있습니다. 아래 예제와 같이 데이터를 `Stacked100SplineAreaSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다.

## {Platform} 극좌표 영역 차트

{Platform} 극좌표 영역 차트는 [극좌표 차트](polar-chart.mdx) 그룹에 속하며, 꼭짓점 또는 모서리가 데이터 지점의 극좌표(각도/반지름) 좌표에 위치하고 직선으로 연결된 후 연결된 지점으로 표현된 영역을 채우는 채워진 다각형 모양입니다. 극좌표 영역 차트는 산점 마커 차트와 같은 데이터 플롯 개념을 사용하지만, 지점을 수평선을 따라 늘이고 영역을 채우는 대신 지점을 원 주위에 배치하고 그려진 영역을 채웁니다. 아래 예제와 같이 데이터를 `PolarAreaSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다.
