# {Platform} 도형 차트

{ProductName} 도형 차트는 도형의 배열(X/Y 점의 배열 또는 배열의 배열)을 받아 직교(x, y) 좌표계에서 다각형 또는 폴리라인의 모음으로 렌더링하는 차트 그룹입니다. 과학 데이터에서 영역을 강조하는 데 자주 사용되며, 다이어그램, 청사진, 심지어 건물의 평면도를 플롯하는 데에도 사용할 수 있습니다.

## {Platform} 산점도 다각형 차트

{Platform} 산점 다각형 차트는 `DataChart` 컨트롤의 `ScatterPolygonSeries`를 사용하여 직교(x, y) 좌표계에서 다각형의 배열 또는 배열의 배열을 렌더링합니다. 이 차트는 플롯 다이어그램, 청사진, 심지어 건물의 평면도 도형을 채우는 데 사용할 수 있습니다.

아래 예제와 같이 데이터를 `ScatterPolygonSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

## {Platform} 산점 폴리라인 차트

{Platform} 산점 폴리라인 차트는 `DataChart` 컨트롤의 `ScatterPolylineSeries`를 사용하여 직교(x, y) 좌표계에서 폴리라인의 배열 또는 배열의 배열을 렌더링합니다. 이 차트는 플롯 다이어그램, 청사진, 심지어 건물의 평면도의 윤곽선에 사용할 수 있습니다. 또한 많은 수의 요소 간의 복잡한 관계를 시각화할 수 있습니다.
