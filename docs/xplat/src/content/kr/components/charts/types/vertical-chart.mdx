# {Platform} 세로 차트

{ProductName} 세로 카테고리 시리즈는 익숙한 선, 스플라인, 점, 계단형, 영역, 폭포 차트를 옆으로 눕혀 그립니다. 카테고리는 `CategoryYAxis`에서 차트를 따라 아래로 내려가고, 값은 `NumericXAxis`에서 가로로 펼쳐집니다. 이는 [막대 차트](bar-chart.mdx)와 같은 배열입니다. 각 시리즈는 이미 사용 중일 수 있는 가로 시리즈의 세로 대응물이며 옵션을 공유합니다. `VerticalLineSeries`는 `LineSeries`를 반영하고, `VerticalAreaSeries`은 `AreaSeries`를 반영하는 식입니다.

## 세로 차트 권장 사항

### {Platform} 세로 차트가 프로젝트에 적합합니까?

카테고리를 왼쪽에서 오른쪽보다 위에서 아래로 읽는 것이 더 나은 경우 차트를 옆으로 눕히십시오:

- 카테고리가 깊이, 고도 또는 건물의 층처럼 물리적인 세로 차원인 경우.
- 설문 질문, 제품 기능 또는 계정 이름처럼 카테고리 레이블이 긴 경우. 차트를 따라 내려가면서 각 레이블이 회전되거나 잘리지 않고 축의 전체 너비를 얻습니다.
- 하루의 시간처럼 카테고리가 많고, 차트가 가로보다 세로로 더 많은 공간을 가지는 경우.
- 차트가 행을 맞춰야 하는 막대 차트나 표 옆에 놓이는 경우.

### 세로 차트 사용 사례

- 값이 깊이나 고도에 따라 변하는 해양, 토양 또는 대기 프로필.
- 카테고리 이름이 긴 설문 및 순위 결과.
- 하루의 시간이나 한 해의 월처럼 위에서 아래로 읽는 타임라인.
- 단계 이름이 긴 이익 브리지 및 기타 폭포 차트.
- 막대 위에 목표 또는 평균이 그려진 막대 차트.

### 세로 차트를 사용하지 말아야 하는 경우

- 카테고리가 주가처럼 독자가 왼쪽에서 오른쪽으로 진행된다고 기대하는 시계열인 경우. 가로 [선 차트](line-chart.mdx) 또는 [영역 차트](area-chart.mdx)를 사용하십시오.
- 별도 카테고리의 크기를 비교해야 하는 경우. [막대 차트](bar-chart.mdx)는 각 값을 막대의 길이로 보여 주므로, 점의 위치를 비교하는 것보다 더 쉽게 비교할 수 있습니다.

### 세로 차트 데이터 구조

- 데이터 소스는 배열 또는 데이터 항목의 목록이어야 합니다.
- 각 항목에는 `CategoryYAxis`에서 해당 행에 레이블을 붙이는 문자열이나 날짜 같은 카테고리가 있어야 합니다.
- 각 시리즈는 `valueMemberPath`를 통해 하나의 숫자 필드를 읽습니다.

## {Platform} 세로 차트 축

세로 시리즈는 카테고리에 `CategoryYAxis`를, 값에 `NumericXAxis`를 받습니다. 카테고리 축을 시리즈와 같은 데이터에 바인딩하고, `label`로 카테고리 필드의 이름을 지정하십시오. 카테고리를 위에서 아래로 진행하려면 카테고리 축에서 `isInverted`를 설정하십시오. 설정하지 않으면 첫 번째 항목이 아래쪽에 있으며, 이는 고도에는 맞지만 깊이에는 맞지 않습니다.

```json-snippet source="/charts/data-chart/vertical-line-chart"
{
    "descriptions": {
        "content": {
            "type": "DataChart",
            "name": "chart",
            "axes": [
                {
                    "type": "CategoryYAxis",
                    "name": "yAxis",
                    "label": "Depth",
                    "dataSourceRef": "OceanTemperatureByDepth",
                    "interval": 1,
                    "isInverted": true
                },
                {
                    "type": "NumericXAxis",
                    "name": "xAxis",
                    "title": "Temperature (°C)"
                }
            ],
            "series": [
                {
                    "type": "VerticalLineSeries",
                    "name": "VerticalLineSeries1",
                    "title": "Summer",
                    "xAxisRef": "xAxis",
                    "yAxisRef": "yAxis",
                    "dataSourceRef": "OceanTemperatureByDepth",
                    "valueMemberPath": "Summer",
                    "markerType": "Circle",
                    "thickness": 2
                }
            ]
        }
    }
}
```

## {Platform} 세로 선 차트

`VerticalLineSeries`는 [위의 예제](#{PlatformLower}-세로-차트-예제)처럼 인접한 카테고리의 값을 직선으로 연결합니다. `LineSeries`와 같은 마커, 두께 및 브러시 옵션을 받습니다.

## {Platform} 세로 스플라인 차트

`VerticalSplineSeries`는 값을 부드러운 곡선으로 연결합니다. 아래 예제는 지면이 아래쪽에 있도록 고도에 대해 기온을 플롯하므로, 카테고리 축을 뒤집지 않습니다.

<Sample src="/charts/data-chart/vertical-spline-chart" height={600} alt="{Platform} 세로 스플라인 차트" />

```json-snippet source="/charts/data-chart/vertical-spline-chart"
{
    "type": "DataChart",
    "series": [
        {
            "type": "VerticalSplineSeries",
            "$type": "+doc:markup",
            "title": "Standard Atmosphere",
            "valueMemberPath": "Standard",
            "markerType": "Circle",
            "$markerType": "+doc:markup"
        }
    ]
}
```

## {Platform} 세로 계단형 선 차트

`VerticalStepLineSeries`는 다음 카테고리까지 각 값을 유지한 다음 다음 값으로 계단처럼 넘어갑니다. 이는 설정된 시점에 바뀌고 그 사이에는 그대로 유지되는 값, 예를 들어 금리에 적합합니다.

## {Platform} 세로 영역 차트

`VerticalAreaSeries`는 선과 값 축 사이의 공간을 채웁니다. 영역이 겹칠 때는 `areaFillOpacity`를 낮추어 뒤에 있는 시리즈가 보이도록 하십시오.

<Sample src="/charts/data-chart/vertical-area-chart" height={600} alt="{Platform} 세로 영역 차트" />

```json-snippet source="/charts/data-chart/vertical-area-chart"
{
    "type": "DataChart",
    "series": [
        {
            "type": "VerticalAreaSeries",
            "$type": "+doc:markup",
            "title": "1990",
            "valueMemberPath": "Year1990",
            "areaFillOpacity": 0.5,
            "$areaFillOpacity": "+doc:markup"
        }
    ]
}
```

`VerticalStepAreaSeries`는 계단형 선 아래 공간을 채우므로, 각 카테고리가 하나의 단단한 띠로 읽힙니다.

<Sample src="/charts/data-chart/vertical-step-area-chart" height={600} alt="{Platform} 세로 계단형 영역 차트" />

## {Platform} 세로 폭포 차트

`VerticalWaterfallSeries`는 각 카테고리를 이전 값에서 자기 값까지의 막대로 그리므로, 누적 합계가 이익과 손실의 연속으로 읽힙니다. 각 값은 변화량이 아니라 그 단계 이후의 누적 합계입니다. 이전 값보다 떨어지는 막대는 `negativeBrush`와 `negativeOutline`를 사용합니다.

<Sample src="/charts/data-chart/vertical-waterfall-chart" height={600} alt="{Platform} 세로 폭포 차트" />

```json-snippet source="/charts/data-chart/vertical-waterfall-chart"
{
    "type": "DataChart",
    "series": [
        {
            "type": "VerticalWaterfallSeries",
            "$type": "+doc:markup",
            "valueMemberPath": "Total",
            "brush": "#2E7D32",
            "$brush": "+doc:markup",
            "outline": "#2E7D32",
            "$outline": "+doc:markup",
            "negativeBrush": "#C62828",
            "$negativeBrush": "+doc:markup",
            "negativeOutline": "#C62828",
            "$negativeOutline": "+doc:markup"
        }
    ]
}
```

## {Platform} 세로 시리즈와 막대 시리즈 결합

세로 시리즈는 `BarSeries`와 축을 공유하므로, 같은 차트에서 막대 위에 그릴 수 있습니다. 아래 예제는 각 지역의 매출 목표를 실제 매출의 `BarSeries` 위에 `VerticalLineSeries`로 그립니다.

<Sample src="/charts/data-chart/vertical-chart-combined" height={600} alt="{Platform} 막대 시리즈 위의 세로 선 시리즈" />

```json-snippet source="/charts/data-chart/vertical-chart-combined"
{
    "type": "DataChart",
    "series": [
        {
            "type": "BarSeries",
            "$type": "+doc:markup",
            "title": "Actual",
            "valueMemberPath": "Actual"
        },
        {
            "type": "VerticalLineSeries",
            "$type": "+doc:markup",
            "title": "Target",
            "valueMemberPath": "Target",
            "markerType": "Diamond"
        }
    ]
}
```

## {Platform} 세로 차트 툴팁

커서 아래의 카테고리를 설명하는 `DataToolTipLayer`를 추가하십시오. 기본적으로 툴팁은 시리즈 값의 합계로 끝나며, 이는 데스크톱과 모바일 방문처럼 시리즈가 합산되는 경우에는 유용하지만, 여름과 겨울 기온처럼 별도의 측정값인 경우에는 유용하지 않습니다. 이를 제외하려면 `summaryType`를 `None`로 설정하십시오.

```json-snippet source="/charts/data-chart/vertical-line-chart"
{
    "type": "DataChart",
    "series": [
        {
            "type": "DataToolTipLayer",
            "$type": "+doc:markup",
            "summaryType": "None",
            "$summaryType": "+doc:markup"
        }
    ]
}
```
