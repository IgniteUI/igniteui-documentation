# {Platform} 데이터 파이 차트
{ProductName} 데이터 파이 차트는 데이터 세트의 카테고리(부분)가 합쳐져 총합(전체) 값을 이루는 방식을 보여 주는 부분과 전체 차트입니다. 카테고리는 원형 또는 파이 모양 그래프의 섹션으로 렌더링됩니다. 각 섹션, 즉 파이 조각은 기본 데이터 값에 비례하는 호 길이를 가집니다. 카테고리는 분석 중인 총 값에 대한 값 백분율에 따라 100 또는 100%의 부분으로 다른 카테고리와 비례하여 표시됩니다.

## {Platform} 데이터 파이 차트 예제
문자열과 숫자 데이터 값으로 데이터 항목을 바인딩하여 `DataPieChart`에서 {Platform} 파이 차트를 만들 수 있습니다. 이 데이터 값은 시각화의 100%가 되도록 합산됩니다.

## {Platform} 데이터 파이 차트 권장 사항
파이 차트는 소규모 데이터 세트에 적합하며 한눈에 읽기 쉽습니다. 파이 차트는 도넛(링) 차트, 깔때기 차트, 누적 영역 차트, 누적 막대 차트, 트리맵과 같은 부분 대 전체 시각화의 한 유형일 뿐입니다.

{Platform} 데이터 파이 차트에는 뷰어가 데이터를 분석할 수 있는 도구를 제공하는 대화형 기능이 포함되어 있습니다. 예:

- 범례
- 조각 선택
- 조각 강조
- 차트 애니메이션

파이 차트 모범 사례:

- 총 값 또는 전체에 비례하여 백분율 값으로 조각이나 세그먼트를 비교합니다.
- 카테고리 그룹이 더 작은 세그먼트로 어떻게 나뉘는지 보여 줍니다.
- 작고 계층적이지 않은 데이터 세트(6~8개 미만의 데이터 세그먼트)를 제시합니다.
- 데이터 세그먼트의 합계가 100%가 되도록 합니다.
- 데이터를 가장 큰(가장 높은) 값에서 가장 작은(가장 낮은) 값 순서로 배열합니다.
- 12시 위치에서 시작하여 시계 방향으로 진행하는 것과 같은 표준 표현 기법을 사용합니다.
- 부분의 세그먼트/조각이 구별될 수 있도록 색상 팔레트를 확인합니다.
- 읽기 쉽도록 세그먼트 안의 데이터 레이블과 범례 중 무엇을 사용할지 고려합니다.
- 이해하기 쉬운 정도에 따라 파이 대신 막대나 링과 같은 대안 차트를 선택합니다.
- 비교 분석을 위해 여러 파이 차트를 나란히 배치하는 것을 피합니다.

다음 경우에는 파이 차트를 사용하지 마십시오:

- 시간에 따른 변화를 비교하는 경우 - 막대, 선 또는 영역 차트를 사용하십시오.
- 정밀한 데이터 비교가 필요한 경우 - 막대, 선 또는 영역 차트를 사용하십시오.
- 세그먼트가 6개 또는 8개를 초과하는 경우(데이터 양이 많음) - 데이터 이야기에 적합하다면 막대, 선 또는 영역 차트를 고려하십시오.
- 막대 차트에서 값 차이를 뷰어가 더 쉽게 인지할 수 있는 경우.

## {Platform} 데이터 파이 차트 범례
범례는 각 지점이 총합에 기여하는 정도를 알 수 있도록 각 지점에 대한 정보를 표시하는 데 사용됩니다.

파이 차트 옆에 범례를 표시하려면 ItemLegend를 만들어 `DataPieChart.legend` 속성에 할당해야 합니다. ItemLegend는 기본적으로 항목을 세로 방향으로 표시하지만, `orientation` 속성을 설정하여 변경할 수 있습니다.

범례에 표시되는 레이블은 기본적으로 `DataPieChart`에서 각 조각에 표시되는 레이블과 같은 내용을 표시하지만, 차트의 `legendSliceLabelContentMode` 속성을 사용하여 수정할 수 있습니다. 이 속성은 열거형을 노출하며, 이를 통해 차트의 각 조각에 대해 범례 내용으로 레이블, 값, 백분율 또는 이들의 임의의 조합을 표시할 수 있습니다.

ItemLegend 배지도 수정할 수 있습니다. 기본적으로 연결된 차트 조각의 색상과 일치하는 채워진 원으로 표시됩니다. 차트의 `legendItemBadgeShape` 속성을 사용하여 이를 구성할 수 있으며, 원, 선, 막대, 열 등으로 설정할 수 있습니다.

## {Platform} 파이 차트 기타 카테고리
때로는 파이 차트의 기본 데이터에 작은 값을 가진 많은 항목이 포함될 수 있습니다. 이 경우 기타 카테고리를 사용하면 여러 데이터 값을 하나의 조각으로 자동 집계할 수 있습니다.

`DataPieChart`의 기타 카테고리에는 차트에 기타 조각이 표시되는 방식을 구성할 수 있게 하는 세 가지 주요 구성 가능 속성인 `othersCategoryType`, `othersCategoryThreshold`, `othersCategoryText`가 있습니다. 각각은 아래에 설명되어 있습니다:

`othersCategoryType` 속성은 `DataPieChart`의 `othersCategoryThreshold` 속성과 함께 작동합니다. `othersCategoryType`의 경우 `othersCategoryThreshold`를 숫자로 평가할지 백분율로 평가할지 정의할 수 있습니다. 예를 들어 숫자를 선택하고 `othersCategoryThreshold`를 5로 설정하면, 값이 5보다 작은 모든 조각이 기타 카테고리의 일부가 됩니다. 백분율 유형에서 같은 값 5를 사용하면, `DataPieChart`의 총 값에 대해 5퍼센트보다 작은 모든 값이 기타 카테고리의 일부가 됩니다.

차트의 기타 조각에 포함된 기본 데이터 항목을 가져오려면 차트의 `m:getOthersContext` 메서드를 사용할 수 있습니다. 이 메서드의 반환 유형은 `OthersCategoryContext.items` 속성을 노출하는 `OthersCategoryContext`입니다. `OthersCategoryContext.items` 속성은 기타 조각의 항목을 포함하는 배열을 반환합니다. 또한 기타 조각을 클릭하면 `SeriesClick` 이벤트의 이벤트 인수에 있는 `Item` 속성도 이 `OthersCategoryContext`를 반환합니다.

기본적으로 기타 조각은 "Others"라는 레이블로 표시됩니다. 차트의 `othersCategoryText` 속성을 수정하여 이를 변경할 수 있습니다.

### {Platform} 기타 조각 스타일 지정
다음 속성을 사용하여 집계된 기타 조각을 다른 조각과 별도로 스타일링할 수 있습니다:

- `othersCategoryBrush`
  기타 조각에 사용되는 채우기(브러시)를 설정합니다.

- `othersCategoryOutline`
  기타 조각에 사용되는 윤곽선(획)을 설정합니다.

이 속성들은 기타 조각(존재하는 경우)에만 영향을 줍니다. 다른 모든 조각은 일반 팔레트와 항목별 색상 지정 동작을 계속 사용합니다.

<DocsAside type="info">
기타 조각은 차트가 이를 생성하도록 구성된 경우에만 렌더링됩니다(예: `othersCategoryThreshold`이 `0`보다 크고 적절한 `othersCategoryType`가 있는 경우). 기타 조각이 없으면 `othersCategoryBrush`와 `othersCategoryOutline`는 보이는 효과가 없습니다.
</DocsAside>

`DataPieChart`에 기타 카테고리가 표시되지 않도록 하려면 `othersCategoryThreshold`를 0으로 설정할 수 있습니다.

## {Platform} 데이터 파이 차트 선택
`DataPieChart`는 차트에 플롯된 조각을 마우스로 클릭하여 조각 선택을 지원합니다. 이는 아래에 설명된 차트의 `selectionBehavior` 및 `selectionMode` 속성을 활용하여 구성할 수 있습니다:

`selectionBehavior`의 주요 두 가지 옵션은 각각 단일 선택과 다중 선택을 활성화하는 `PerDataItemSingleSelect`와 `PerDataItemMultiSelect`입니다.

`selectionMode` 속성은 파이 차트 조각이 선택되었을 때 반응하는 방식을 결정하는 열거형을 노출합니다. 다음은 그 열거형의 옵션과 각 옵션의 동작입니다:

- `Brighten`: 선택된 조각이 강조 표시됩니다.
- `FadeOthers`: 선택된 조각은 같은 색상을 유지하고 다른 조각은 흐려집니다.
- `FocusColorFill`: 선택된 조각의 배경이 차트의 FocusBrush로 변경됩니다.
- `FocusColorOutline`: 선택된 조각에는 차트의 FocusBrush로 정의된 색상의 윤곽선이 표시됩니다.
- `FocusColorThickOutline`: 선택된 조각에는 차트의 FocusBrush로 정의된 색상의 윤곽선이 표시됩니다. 이 윤곽선의 두께는 컨트롤의 Thickness 속성을 통해서도 구성할 수 있습니다.
- `GrayscaleOthers`: 선택되지 않은 조각에는 회색 색상 필터가 적용됩니다.
- `None`: 선택된 조각에는 아무런 효과가 없습니다.
- `SelectionColorFill`: 선택된 조각의 배경이 차트의 SelectionBrush로 변경됩니다.
- `SelectionColorOutline`: 선택된 조각에는 차트의 SelectionBrush로 정의된 색상의 윤곽선이 표시됩니다.
- `SelectionColorThickOutline`: 선택된 조각에는 차트의 FocusBrush로 정의된 색상의 윤곽선이 표시됩니다. 이 윤곽선의 두께는 컨트롤의 Thickness 속성을 통해서도 구성할 수 있습니다.
- `ThickOutline`: 선택된 조각에는 차트의 Thickness 속성에 따라 두께가 결정되는 윤곽선이 적용됩니다.

조각이 선택되면 기본 데이터 항목이 차트의 SelectedSeriesItems 컬렉션에 추가됩니다. 따라서 DataPieChart는 조각이 선택되어 이 컬렉션이 변경되는 시점을 감지할 수 있도록 SelectedSeriesItemsChanged 이벤트를 노출합니다.

## {Platform} 데이터 파이 차트 강조
`DataPieChart`는 마우스 오버 강조를 지원하며, 별도의 데이터 소스를 제공하여 구성할 수 있는 강조 오버레이도 지원합니다.

먼저 `highlightingBehavior` 열거형 속성이 조각을 강조하는 방식을 결정합니다. 다음은 그 속성의 옵션과 각 옵션의 동작입니다:

- `DirectlyOver`: 마우스가 조각 바로 위에 있을 때만 조각이 강조됩니다.
- `NearestItems`: 마우스 위치에서 가장 가까운 조각이 강조됩니다.
- `NearestItemsAndSeries`: 마우스 위치에서 가장 가까운 조각과 시리즈가 강조됩니다.
- `NearestItemsRetainMainShapes`: 마우스 위치에서 가장 가까운 항목이 강조되며, 시리즈의 주요 도형은 강조를 낮추지 않습니다.

`highlightingMode` 열거형 속성은 데이터 파이 차트 조각이 강조될 때 반응하는 방식을 결정합니다. 다음은 그 속성의 옵션과 각 옵션의 동작입니다:

- `Brighten`: 마우스 위치가 시리즈 위에 있거나 근처에 있으면 시리즈의 색상이 밝아집니다.
- `FadeOthers`: 마우스 위치가 시리즈 위에 있거나 근처에 있으면 시리즈는 색상을 유지하고, 다른 시리즈는 흐리게 표시됩니다.
- `None`: 시리즈와 조각은 강조되지 않습니다.

마우스 강조 외에도 `DataPieChart`는 데이터의 일부를 표시할 수 있는 강조 필터 기능을 제공합니다. 이는 컨트롤에 `highlightedDataSource`를 지정하고 `highlightedValuesDisplayMode` 속성을 `SeriesHighlightedValuesDisplayMode.Overlay`로 설정하여 적용합니다. `highlightedDataSource`는 `DataPieChart`의 `dataSource` 속성에 할당된 데이터의 일부를 기대합니다.

이러한 조건이 충족되면 부분 집합의 값이 강조 표시되고 나머지 전체 데이터 세트는 흐려집니다. 이는 사실상 부분 집합에 대한 강조를 만들며, 같은 컨트롤 안에서 데이터의 부분 집합을 더 쉽게 시각화할 수 있게 합니다.

## {Platform} 데이터 파이 차트 애니메이션
`DataPieChart`는 조각이 보이도록 애니메이션하는 것뿐만 아니라 값이 변경될 때도 조각을 애니메이션하는 기능을 지원합니다.

`isTransitionInEnabled` 속성을 **true**로 설정하면 파이 차트가 보일 때 애니메이션되도록 할 수 있습니다. 수행되는 애니메이션 유형은 원하는 애니메이션 유형으로 `transitionInMode` 열거형 속성을 설정하여 구성할 수 있습니다. 또한 `transitionInSpeedType` 속성을 인덱스, 값, 일반 또는 무작위에 따라 크기가 조정되도록 설정할 수도 있습니다. 이 애니메이션의 지속 시간은 밀리초 단위의 숫자를 받는 `transitionInDuration` 속성으로 제어할 수 있습니다.

데이터 변경을 애니메이션하려면 `animateSeriesWhenAxisRangeChanges` 속성을 **true**로 설정하면 됩니다. 이 변경의 지속 시간은 `transitionDuration` 속성을 설정하여 구성할 수도 있습니다.
