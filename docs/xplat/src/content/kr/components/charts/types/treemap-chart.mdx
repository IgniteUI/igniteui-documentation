# {Platform} 트리맵

{ProductName} 트리맵 차트는 계층형(트리 구조) 데이터를 중첩된 노드 모음으로 표시합니다. 트리의 각 가지에는 트리맵 노드가 주어지며, 이 노드는 하위 가지를 나타내는 더 작은 노드로 채워집니다. 각 노드의 사각형 면적은 데이터의 지정된 차원에 비례합니다. 노드는 종종 색상으로 구분되어 데이터의 별도 차원을 보여 줍니다.

## 트리맵 권장 사항

### {Platform} 트리맵이 프로젝트에 적합합니까?

색상과 크기 차원이 트리 구조와 어떤 방식으로든 연관되어 있을 때, 다른 방법으로는 찾기 어려운 패턴을 쉽게 볼 수 있는 경우가 많습니다. 트리맵의 두 번째 장점은 구조상 공간을 효율적으로 사용한다는 것입니다. 그 결과 화면에 수천 개의 항목을 동시에 읽기 쉽게 표시할 수 있습니다.

- 트리맵은 데이터 포인트를 분류하고 값의 상대적 차이를 전달하는 데 종종 부족한 파이 차트 및 기타 영역 차트 형식보다 효과적입니다.
- 트리맵은 드릴다운 시나리오를 위해 설계되었습니다. 더 효율적인 데이터 분석을 위해 더 작은 사각형으로 표현된 데이터 세트를 계속 드릴다운할 수 있습니다.
- 트리맵은 수치 양을 전달하도록 설계되지 않았으며, 의도는 상대적 순위를 보여 주는 것입니다.

다른 데이터 시각화와 마찬가지로 트리맵 차트 시각화도 특정 시나리오에서 사용해야 합니다. 막대 차트나 선 차트 같은 시각화와 같은 문제를 해결하지 않습니다. 트리맵은 더 복잡하고 풍부한 데이터 표시를 위한 것입니다.

### 트리맵 사용 사례

트리맵을 선택하는 일반적인 사용 사례는 여러 가지가 있습니다. 다음과 같은 경우입니다:

- 드릴다운 계층형 데이터가 있는 경우(가지와 하위 가지가 있는 트리로 구성된 데이터).
- 카테고리(가지)와 하위 카테고리(하위 가지) 사이의 상대적 가중치 및 비교 값의 계층을 보여 주고 싶은 경우.
- 컴팩트하고 공간 효율적인 시각화가 필요한 대용량 데이터 세트를 표시하고 싶은 경우.
- 정확한 값 없이 한눈에 볼 수 있는 빠른 데이터 분석을 제공하고 싶은 경우. 사각형의 상대적 크기는 패턴이나 이상값을 매우 빠르게 식별하는 데 도움이 됩니다.
- 공간을 효율적으로 사용하고 싶은 경우. 트리맵은 화면에 수천 개의 항목을 동시에 읽기 쉽게 표시할 수 있습니다.

### 트리맵을 사용하지 말아야 하는 경우

- 정확한 값이 필요한 데이터 이야기를 전달하는 경우
- 데이터 값에 음수가 있는 경우
- 데이터가 평평하고 계층 구조가 없는 경우
- 데이터의 크기가 서로 비슷한 경우

### 트리맵 데이터 구조

- 데이터 소스는 배열 또는 데이터 항목의 목록이어야 합니다
- 데이터 소스에는 최소 하나의 데이터 항목이 있어야 합니다. 그렇지 않으면 맵이 노드를 렌더링하지 않습니다.
- 모든 데이터 항목에는 `labelMemberPath` 속성에 매핑되어야 하는 최소 하나의 데이터 열(예: 문자열)이 있어야 합니다.
- 모든 데이터 항목에는 `valueMemberPath` 속성을 사용하여 매핑되어야 하는 최소 하나의 숫자 데이터 열이 있어야 합니다.
- 데이터를 체계적인 타일로 분류하려면 선택적으로 `parentIdMemberPath`와 `idMemberPath`를 사용할 수 있습니다.

### 레이아웃 유형

트리맵 차트는 데이터의 상대적 가중치를 표시합니다. 데이터 항목의 레이아웃을 결정하는 데 여러 알고리즘을 사용합니다:

- `SliceAndDice` - 레이아웃 알고리즘은 종횡비를 희생하더라도 초기 순서를 유지하는 것을 목표로 합니다.
- `Squarified` - 레이아웃 타일링 알고리즘은 `SliceAndDice`보다 종횡비가 더 좋고, Squarified보다 순서를 더 잘 유지합니다.
- `Stripped` - 레이아웃 유형 알고리즘은 가장 좋은 종횡비를 얻지만 객체가 크기 순으로 배열됩니다.

트리맵을 사용하면 요구 사항에 가장 적합한 알고리즘을 선택할 수 있으며, 기본값은 Squarified 방식입니다. 또한 두 가지 메커니즘을 사용하여 노드에 색을 입힐 수 있습니다:

- 같은 값을 가진 항목에 색을 입히는 그룹 기반 메커니즘
- 지도의 단계구분도와 비슷하게, 노드의 값에 따라 노드 색상을 매핑하는 척도 기반 메커니즘.

### 레이아웃 방향

`layoutOrientation` 속성을 사용하면 계층 구조의 노드가 확장되는 방향을 설정할 수 있습니다.

`layoutOrientation` 속성은 SliceAndDice 및 Strip 레이아웃 유형과 함께 작동한다는 점에 유의하십시오.

- `Horizontal` - 하위 노드가 수평으로 쌓입니다(SliceAndDice).
- `Vertical` - 하위 노드가 수직으로 쌓입니다(SliceAndDice).

## {Platform} 트리맵 백분율 기반 강조 표시

- `highlightedDataSource`: 강조된 값을 읽을 데이터 소스를 지정합니다. null이면 강조된 값은 ItemsSource 속성에서 읽습니다.
- `highlightedValueMemberPath`: 강조된 값을 읽을 데이터 소스의 속성 이름을 지정합니다.
- `highlightedValueOpacity`: 강조된 값 뒤에 있는 일반 값의 불투명도를 제어합니다.
- `highlightedValuesDisplayMode`: 강조된 값을 활성화하거나 비활성화합니다.
  - Auto: 트리맵이 사용할 모드를 결정합니다.
  - Overlay: 트리맵은 일반 값 위에 강조된 값을 표시하며, 일반 값에는 약간의 불투명도가 적용됩니다.
  - Hidden: 트리맵은 강조된 값을 표시하지 않습니다.
