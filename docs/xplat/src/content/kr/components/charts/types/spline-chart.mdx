# {Platform} 스플라인 차트

{ProductName} 스플라인 차트는 부드러운 스플라인 곡선으로 연결된 점들의 모음으로 렌더링되는 카테고리 차트 그룹에 속합니다. 값은 y축에 표시되고 카테고리는 x축에 표시됩니다. 스플라인 차트는 일정 기간 동안의 변화량이나 여러 항목의 비교, 그리고 플롯된 값의 합계를 표시하여 부분과 전체의 관계를 강조합니다. 스플라인 차트는 데이터 지점을 잇는 선에 데이터 표현을 개선하기 위한 스플라인 보간과 평활화가 있다는 점을 제외하면 모든 측면에서 [선 차트](./line-chart.mdx)와 동일합니다.

다음 예제는 데이터를 바인딩하고 `chartType` 속성을 `Spline` 열거형으로 설정하여 `CategoryChart` 컨트롤에서 {Platform} 스플라인 차트를 만드는 방법을 보여 줍니다.

## {Platform} 단일 시리즈 스플라인 차트

스플라인 차트는 아래 예제와 같이 2009년 이후 10년 동안 유럽에서 생산된 재생 가능 전기량과 같이 시간에 따른 값의 변화를 보여 줄 때 자주 사용됩니다.

아래 예제와 같이 데이터를 바인딩하고 `chartType` 속성을 `Spline`로 설정하여 `CategoryChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

## {Platform} 다중 시리즈 스플라인 차트

스플라인 차트를 사용하면 여러 시리즈를 결합하여 비교하거나 시간에 따라 어떻게 변하는지 확인할 수 있습니다. 중국과 미국의 데이터를 포함하는 데이터 소스에 바인딩하기만 하면, 차트가 추가 데이터에 맞게 자동으로 업데이트됩니다.

아래 예제와 같이 데이터를 바인딩하고 `chartType` 속성을 `Spline`로 설정하여 `CategoryChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

## {Platform} 누적 스플라인 차트

누적 스플라인 차트는 아래 예제에서 보여 드린 것처럼 여러 해 동안 지역 간에 생산된 재생 가능 전기량과 같이 시간에 따른 값의 변화를 보여 줄 때 자주 사용됩니다.

아래 예제와 같이 데이터를 `StackedSplineSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

## {Platform} 누적 100% 스플라인 차트

누적 100% 스플라인 차트는 y축 값을 처리하는 방식을 제외하고는 모든 측면에서 누적 스플라인 차트와 동일합니다. 누적 100% 스플라인 차트는 데이터를 직접 표현하는 대신, 데이터 지점의 모든 값 합계에 대한 백분율로 데이터를 표시합니다. 아래 예제는 태블릿, 휴대폰, 개인용 컴퓨터를 통한 부서별 온라인 쇼핑 트래픽 연구를 보여 줍니다.

아래 예제와 같이 데이터를 `Stacked100SplineSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:
