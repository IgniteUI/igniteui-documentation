# {Platform} 네트워크 차트
{ProductName} 네트워크 차트는 네트워크 그래프 또는 폴리라인 차트라고도 하며, 많은 수의 요소 간의 복잡한 관계를 시각화합니다. 이 시각화는 방향이 없는 그래프와 방향이 있는 그래프 구조를 모두 표시합니다. 또한 둥근 노드로 표시된 개체 간의 관계를 보여 주며, 선은 그들 사이의 관계를 나타냅니다.

다음 섹션에서는 다양한 유형의 네트워크 차트 예제를 제공합니다.

## {Platform} 네트워크 극좌표 차트
이 예제는 `DataChart` 컨트롤에서 `PolarScatterSeries`(노드 마커 렌더링용)와 `PolarLineSeries`(노드 연결 렌더링용)를 사용하여 네트워크 극좌표 차트를 만드는 방법을 보여 줍니다.
