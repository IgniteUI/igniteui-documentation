# {Platform} 산점도 차트

{ProductName} 산점도 차트는 서로 다른 데이터 시리즈의 항목 간 관계를 보여 주거나, 숫자 x 및 y 좌표로 데이터 항목을 플롯하는 차트 그룹에 속합니다. 이 차트들은 고르지 않은 간격이나 데이터 군집에 주의를 집중시킵니다. 과학 데이터를 플롯하는 데 자주 사용되며, 수집된 데이터가 예측 결과에서 벗어나는 정도를 강조할 수 있습니다. 또한 데이터를 시간순으로 정리하는 데 사용할 수 있습니다(데이터가 시간순이 아니더라도).

## {Platform} 산점도 마커 차트

{Platform} 산점 마커 차트는 직교 좌표계에서 위치를 결정하는 숫자 X/Y 값 쌍을 각각 가진 마커의 모음으로 렌더링됩니다. 아래 예제와 같이 데이터를 `ScatterSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

<Sample src="/charts/data-chart/scatter-point-chart" height={600} alt="{Platform} 산점도 마커 차트" />




## {Platform} 산점 선 차트

{Platform} 산점 선 차트는 직선으로 연결된 마커의 모음으로 렌더링되며, 각 마커는 직교 좌표계에서 위치를 결정하는 숫자 X/Y 값 쌍을 가집니다. 아래 예제와 같이 데이터를 `ScatterLineSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

<Sample src="/charts/data-chart/scatter-line-chart" height={600} alt="{Platform} 산점 선 차트" />




## {Platform} 산점 스플라인 차트

{Platform} 산점 스플라인 차트는 곡선 스플라인으로 연결된 마커의 모음으로 렌더링되며, 각 마커는 직교 좌표계에서 위치를 결정하는 숫자 X/Y 값 쌍을 가집니다. 아래 예제와 같이 데이터를 `ScatterSplineSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

## {Platform} 산점 고밀도 차트

{Platform} 산점 고밀도(HD) 차트를 사용하면 수천에서 수백만 개의 데이터 포인트에 이르는 산점 데이터를 로딩 시간을 매우 짧게 하면서 바인딩하고 표시할 수 있습니다. 이 차트 유형은 많은 수의 점을 위해 설계되었으므로, 크기가 큰 마커 대신 작은 점으로 시각화되며, 데이터 포인트의 군집을 나타내는 더 높은 색상 밀도로 가장 많은 데이터가 있는 영역을 표시합니다. 아래 예제와 같이 데이터를 `HighDensityScatterSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

<Sample src="/charts/data-chart/type-scatter-hd-series" height={600} alt="{Platform} 산점 HD 차트" />
</PlatformBlock>



## {Platform} 산점 영역 차트

{Platform} 산점 영역 차트는 X 및 Y 데이터의 삼각분할을 기반으로 각 점에 숫자 데이터 값이 할당된 색상 표면을 그립니다. 이 차트는 히트맵, 자기장 세기, 사무실의 Wi-Fi 세기를 렌더링하는 데 유용합니다. 아래 예제와 같이 데이터를 `ScatterAreaSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

<Sample src="/charts/data-chart/type-scatter-area-series" height={600} alt="{Platform} 산점 영역 차트" />
