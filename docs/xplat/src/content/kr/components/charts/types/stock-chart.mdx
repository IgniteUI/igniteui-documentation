# {Platform} 주식 차트

{ProductName} 주식 차트는 때때로 {Platform} 금융 차트 또는 캔들스틱 차트라고도 하며, 주식 시세 데이터 또는 가격 데이터를 대화형 시계열 디스플레이로 렌더링하는 복합 시각화입니다. 주식 차트는 시계열 X축에 시간에 따른 종목의 주가를 보여 줍니다. 또한 이 차트는 구성 가능한 기간 동안 회사 종목 데이터의 시가, 고가, 저가, 종가(OHLC) 같은 정보를 보여 줍니다. 주식 차트는 가격과 거래량의 표시 모드, 그리고 다양한 주식 지표를 포함하여 데이터를 시각화하고 해석하는 여러 방법을 제공합니다.

## 주식 차트 권장 사항

### {Platform} 주식 차트가 프로젝트에 적합합니까?

일반적인 주식 차트는 가격 범위의 기술적 분석에 사용되는 캔들스틱 차트에 종목 데이터를 표시합니다. 캔들스틱 차트는 하루의 고가와 저가를 종목 기호의 시가 및 종가와 비교합니다.

- 캔들스틱 차트의 몸통은 시가와 종가(O/C)를 보여 줍니다.
- 캔들스틱 차트의 심지는 고가와 저가(H/L)를 보여 줍니다.
- 종목 값의 위와 아래 사이 거리는 종목 가격의 하루 범위입니다.
- 자산이 시가보다 높게 마감하면 캔들스틱 차트의 종목 값은 속이 빈 상태로 표시됩니다.
- 자산이 시가보다 낮게 마감하면 캔들스틱 차트의 종목 값은 채워진 상태로 표시됩니다.
- 검은색 또는 빨간색 캔들은 이전 캔들의 종가보다 낮은 종가를 가진 가격을 나타냅니다.
- 흰색 또는 초록색 캔들은 이전 캔들의 종가보다 높은 종가를 나타냅니다.

주식 차트는 다음 중 하나를 표시하도록 설정할 수 있습니다:

- 캔들스틱 차트
- 막대형 차트
- 세로 막대형 차트
- 꺾은선형 차트

주식 차트는 사용자가 데이터 분석 기능을 수행할 수 있도록 설계되었으므로, 다음과 같은 대화형 요소를 포함합니다:

- 시간 기반 필터
- 가격 보기
- 거래량 보기
- 지표 보기
- 추세선
- 탐색 / 줌 바 보기

### 주식 차트 데이터 구조

- 데이터 소스는 배열 또는 데이터 항목의 목록이어야 합니다.
- 데이터 소스에는 최소 하나의 데이터 항목이 있어야 합니다.
- 모든 데이터 항목에는 종목 데이터의 날짜를 나타내는 최소 하나의 날짜-시간(또는 문자열) 열이 있어야 합니다.
- 막대, 선, 열 차트의 경우 모든 데이터 항목에는 숫자 열이 1개 있어야 합니다.
- 캔들스틱 차트의 경우 모든 데이터 항목에는 시가, 고가, 저가, 종가(OHLC)를 위한 숫자 열이 4개 있어야 합니다.
- 캔들스틱 차트의 경우 모든 데이터 항목에는 시가, 고가, 저가, 종가, 거래량을 위한 숫자 열이 5개 있어야 합니다.

## {Platform} 차트 주석

십자선 주석 레이어는 대상으로 한 모든 시리즈의 실제 값에서 만나는 교차선을 제공합니다. 십자선 유형에는 수평, 수직, 둘 다가 있습니다. 십자선은 `DomainChart.CrosshairsSnapToData` 속성을 true로 설정하여 데이터 지점에 맞춰지도록 구성할 수도 있으며, 그렇지 않으면 십자선이 데이터 지점 사이에서 보간됩니다. 축을 따라 십자선의 값을 표시하도록 주석을 활성화할 수도 있습니다.

최종 값 레이어는 시리즈에 표시되는 마지막 값을 축을 따라 빠르게 보여 줍니다.

콜아웃 레이어는 X/Y 위치에 콜아웃을 표시합니다.

참고: 서수 X축 모드를 사용할 때 CalloutsXMemberPath는 항목의 숫자 인덱스를 가리켜야 하며, 그렇지 않으면 CalloutsXMemberPath는 시간 값을 가리켜야 합니다.

## {Platform} 차트 창

다음 창을 사용할 수 있습니다:

- 가격 창 - 선, 캔들스틱, 막대(OHLC), 추세선 및 금융 오버레이를 사용하여 가격을 렌더링합니다.
- 지표 창 - 모든 금융 지표를 별도의 차트에 렌더링합니다. 다만 BollingerBands와 PriceChannel 오버레이는 Y축에서 같은 값 범위를 공유하므로 가격 창에 렌더링됩니다.
- 볼륨 창 - 위의 모든 창 아래에 열, 선, 영역 차트 유형을 사용하여 주식 거래량을 렌더링합니다.
- 줌 창 - 모든 창의 확대/축소를 제어하며, 항상 차트 하단에 렌더링됩니다.

### 지표 창
금융 지표는 트레이더가 주가의 변화를 측정하고 추세를 보여 주기 위해 자주 사용합니다. 이 지표들은 Y축 척도를 공유하지 않으므로 보통 가격 창 아래에 표시됩니다.

기본적으로 지표 창은 표시되지 않습니다. 도구 모음을 통해 최종 사용자가 실행 시 표시할 지표를 선택할 수 있습니다.

### 볼륨 창
볼륨 창은 특정 기간 동안 거래된 주식 수를 나타냅니다. 거래량이 적으면 관심이 적다는 뜻이고, 거래량이 많으면 거래가 많아 관심이 높다는 뜻입니다. 이는 열, 선 또는 영역 차트 유형을 사용하여 표시할 수 있습니다. 도구 모음을 사용하면 최종 사용자가 실행 시 데이터를 렌더링할 차트 유형을 선택하여 볼륨 창을 표시할 수 있습니다. 창을 표시하려면 다음 코드에서 보여 주는 것처럼 볼륨 유형을 설정해야 합니다:
