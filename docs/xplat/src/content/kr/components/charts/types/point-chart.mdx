# {Platform} 점 차트
{ProductName} 점 차트는 점들의 모음을 렌더링합니다. 값은 y축(왼쪽 레이블)에 표시되고 카테고리는 x축(하단 레이블)에 표시됩니다. 이 차트들은 플롯된 값의 합계를 표시하여 일정 기간 동안의 변화량이나 여러 항목의 비교, 그리고 부분과 전체의 관계를 강조합니다.

## {Platform} 점 차트 예제
아래 예제와 같이 데이터를 `dataSource` 속성에 바인딩하고 `chartType` 속성을 **Point** 열거형으로 설정하여 `CategoryChart` 컨트롤에서 {Platform} 점 차트를 만들 수 있습니다.

<Sample src="/charts/category-chart/point-chart-multiple-sources" height={600} alt="{Platform} 점 차트 예제" />

## {Platform} 단일 시리즈 점 차트
다음 예제에서 {Platform} 점 차트는 y축에 숫자 데이터 열을, x축에 비숫자 데이터 열을 자동으로 선택하여 단일 데이터 소스를 플롯합니다.

<Sample src="/charts/category-chart/point-chart-single-source" height={600} alt="{Platform} 단일 시리즈 점 차트" />

## {Platform} 다중 시리즈 점 차트
{Platform} 점 차트를 사용하면 여러 시리즈를 결합하여 비교하거나 시간에 따라 어떻게 변하는지 확인할 수 있으므로, 이것이 얼마나 쉬운지 살펴보겠습니다. 중국과 미국의 데이터를 포함하는 데이터 소스에 바인딩하기만 하면, 점 차트가 추가 데이터에 맞게 자동으로 업데이트됩니다.

<Sample src="/charts/category-chart/point-chart-multiple-sources" height={600} alt="{Platform} 다중 시리즈 점 차트" />
