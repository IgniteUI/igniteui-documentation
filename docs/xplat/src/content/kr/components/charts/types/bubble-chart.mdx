# {Platform} 버블 차트
{ProductName} 버블 차트는 여러 개의 뚜렷한 데이터 시리즈에 있는 항목 간의 관계를 나타내기 위해 가변 크기 조정이 적용된 마커를 표시하거나, x 및 y 좌표를 사용하여 데이터 항목을 플롯하는 [산점도 차트](scatter-chart.mdx)의 한 유형입니다. 데이터 지점의 이러한 좌표는 두 개의 숫자 데이터 열로 결정됩니다. 버블 차트는 고르지 않은 간격이나 데이터 군집에 주의를 집중시킵니다. 이 차트는 과학 데이터를 플롯하는 데 자주 사용되며, 수집된 데이터가 예측 결과에서 벗어나는 정도를 강조할 수 있습니다. 버블 차트는 [산점 마커 차트](scatter-chart.mdx#{PlatformLower}-산점도-마커-차트)의 많은 특성을 가지고 있으며, 다양한 반지름 크기를 선택할 수 있는 옵션이 추가되어 있습니다.

## {Platform} 버블 차트 스타일 지정
{Platform} 버블 차트에서는 `markerType` 속성을 사용하여 버블 마커의 모양을, `radiusScale` 속성으로 크기를, `markerBrush`, `markerOutline`, `markerThickness` 속성으로 외관을 사용자 지정할 수 있습니다. 또한 `fillMemberPath`와 `fillScale` 속성을 사용하여 데이터 열을 기준으로 버블 마커의 색상을 지정할 수도 있습니다. 이 예제에서는 위 속성들의 사용법을 보여 줍니다.
