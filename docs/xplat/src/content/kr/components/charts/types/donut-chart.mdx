# {Platform} 도넛 차트
{ProductName} 도넛 차트는 [파이 차트](pie-chart.mdx)와 비슷하게 변수의 발생 비율을 비례하여 나타냅니다. 도넛 차트는 여러 변수를 동심원 고리로 표시할 수 있으며, 계층형 데이터를 시각화하는 기능이 내장되어 있습니다. 고리는 서로 다른 데이터 항목에 바인딩하거나 공통 데이터 소스를 공유할 수 있습니다.

## {Platform} 도넛 차트 권장 사항

### {Platform} 도넛 차트가 프로젝트에 적합합니까?
도넛 차트는 소규모 데이터 세트에 적합하며 한눈에 읽기 쉽습니다. 도넛 차트는 부분 대 전체 시각화의 한 유형일 뿐입니다. 다른 유형은 다음과 같습니다:

- [파이](pie-chart.mdx)
- [누적 영역](area-chart.mdx)
- [누적 100% 영역(누적 백분율 영역)](area-chart.mdx)
- [누적 막대](bar-chart.mdx)
- [누적 100% 막대(누적 백분율 막대)](bar-chart.mdx)
- [트리맵](treemap-chart.mdx)
- [폭포](column-chart.mdx)

{Platform} 도넛 차트에는 뷰어가 데이터를 분석할 수 있는 도구를 제공하는 대화형 기능이 포함되어 있습니다. 예:

- 범례
- 조각 분리
- 조각 선택
- 차트 애니메이션

### 도넛 차트 모범 사례
- 여러 데이터 세트를 사용하여 고리 형태로 데이터를 표시합니다.
- 데이터를 빠르게 설명할 수 있도록 도넛의 가운데 구멍 안에 값이나 레이블과 같은 정보를 배치합니다.
- 총 값 또는 전체에 비례하여 백분율 값으로 조각이나 세그먼트를 비교합니다.
- 카테고리 그룹이 더 작은 세그먼트로 어떻게 나뉘는지 보여 줍니다.
- 데이터 세그먼트의 합계가 100%가 되도록 합니다.
- 부분의 세그먼트/조각이 구별될 수 있도록 색상 팔레트를 확인합니다.

### 도넛 차트를 사용하지 말아야 하는 경우
- 시간에 따른 변화를 비교하는 경우 - [막대](bar-chart.mdx), [선](line-chart.mdx) 또는 [영역](area-chart.mdx) 차트를 사용하십시오.
- 정밀한 데이터 비교가 필요한 경우 - [막대](bar-chart.mdx), [선](line-chart.mdx) 또는 [영역](area-chart.mdx) 차트를 사용하십시오.
- 조각이 6개 또는 8개를 초과하는 경우(데이터 양이 많음) - 데이터 이야기에 적합하다면 [막대](bar-chart.mdx), [선](line-chart.mdx) 또는 [영역](area-chart.mdx) 차트를 고려하십시오.
- [막대](bar-chart.mdx) 차트에서는 값 차이를 뷰어가 더 쉽게 인지할 수 있습니다.
- 음수 데이터가 있는 경우 도넛 차트로 표현할 수 없습니다.

## {Platform} 도넛 차트 - 조각 선택
{Platform} 도넛 차트는 클릭하여 조각을 선택할 수 있습니다. 선택적으로 선택된 조각에 단일 사용자 지정 시각 스타일을 적용할 수 있습니다. 사용자가 조각을 클릭하면 `sliceClick` 이벤트가 발생합니다. 조각 선택을 활성화하면 클릭 시 조각의 선택 상태를 수정할 수 있습니다. 다음 샘플은 조각 선택을 활성화하고 선택된 조각 색상을 회색으로 설정하는 방법을 보여 줍니다.
