# {Platform} 파이 차트
{ProductName} 파이 차트(또는 파이 그래프)는 데이터 세트의 카테고리(부분)가 합쳐져 총합(전체) 값을 이루는 방식을 보여 주는 부분과 전체 차트입니다. 카테고리는 원형 또는 파이 모양 그래프의 섹션으로 렌더링됩니다. 각 섹션, 즉 파이 조각은 기본 데이터 값에 비례하는 호 길이를 가집니다. 카테고리는 분석 중인 총 값에 대한 값 백분율에 따라 100 또는 100%의 부분으로 다른 카테고리와 비례하여 표시됩니다.

## {Platform} 파이 차트 예제
문자열과 숫자 데이터 값으로 데이터 항목을 바인딩하여 `PieChart`에서 {Platform} 파이 차트를 만들 수 있습니다. 이 데이터 값은 시각화의 100%가 되도록 합산됩니다. 이 경우 예제는 부서별 예산 지출의 전체 내역을 보여 줍니다.

## {Platform} 파이 차트 권장 사항
파이 차트는 소규모 데이터 세트에 적합하며 한눈에 읽기 쉽습니다. 파이 차트는 부분 대 전체 시각화의 한 유형일 뿐입니다. 다른 유형은 다음과 같습니다:

- Pie
- 도넛(링)
- 깔때기
- Stacked Area
- 누적 100% 영역(누적 백분율 영역)
- 누적 막대
- 누적 100% 막대(누적 백분율 막대)
- 트리맵
- Waterfall

{Platform} 파이 차트에는 뷰어가 데이터를 분석할 수 있는 도구를 제공하는 대화형 기능이 포함되어 있습니다. 예:

- 범례
- 조각 분리
- 조각 선택
- 차트 애니메이션

파이 차트 모범 사례:

- 총 값 또는 전체에 비례하여 백분율 값으로 조각이나 세그먼트를 비교합니다.
- 카테고리 그룹이 더 작은 세그먼트로 어떻게 나뉘는지 보여 줍니다.
- 작고 계층적이지 않은 데이터 세트(6~8개 미만의 데이터 세그먼트)를 제시합니다.
- 데이터 세그먼트의 합계가 100%가 되도록 합니다.
- 데이터를 가장 큰(가장 높은) 값에서 가장 작은(가장 낮은) 값 순서로 배열합니다.
- 12시 위치에서 시작하여 시계 방향으로 진행하는 것과 같은 표준 표현 기법을 사용합니다.
- 부분의 세그먼트/조각이 구별될 수 있도록 색상 팔레트를 확인합니다.
- 읽기 쉽도록 세그먼트 안의 데이터 레이블과 범례 중 무엇을 사용할지 고려합니다.
- 이해하기 쉬운 정도에 따라 파이 대신 막대나 링과 같은 대안 차트를 선택합니다.
- 비교 분석을 위해 여러 파이 차트를 나란히 배치하는 것을 피합니다.

다음 경우에는 파이 차트를 사용하지 마십시오:

- 시간에 따른 변화를 비교하는 경우 - 막대, 선 또는 영역 차트를 사용하십시오.
- 정밀한 데이터 비교가 필요한 경우 - 막대, 선 또는 영역 차트를 사용하십시오.
- 세그먼트가 6개 또는 8개를 초과하는 경우(데이터 양이 많음) - 데이터 이야기에 적합하다면 막대, 선 또는 영역 차트를 고려하십시오.
- 막대 차트에서 값 차이를 뷰어가 더 쉽게 인지할 수 있는 경우.

## {Platform} 파이 차트 범례
범례는 각 지점이 총합에 기여하는 정도를 알 수 있도록 각 지점에 대한 정보를 표시하는 데 사용됩니다. 범례를 클릭하여 해당 지점을 접을 수 있습니다.

파이 차트 옆에 범례를 표시하려면 ItemLegend를 만들어 `PieChart.legend` 속성에 할당해야 합니다. 그런 다음 `legendLabelMemberPath`를 사용하여 데이터 모델의 어떤 속성을 각 파이 조각에 대해 범례 안에 표시할지 지정할 수 있습니다.

추가로 `legendItemTemplate` 및 `legendItemBadgeTemplate` 속성과 ItemLegend의 다양한 글꼴 속성을 사용하여 범례 항목의 모양을 더 사용자 지정할 수 있습니다.

## {Platform} 파이 차트 기타 카테고리
때로는 파이 차트의 기본 데이터에 작은 값을 가진 많은 항목이 포함될 수 있습니다. 이 경우 기타 카테고리를 사용하면 여러 데이터 값을 하나의 조각으로 자동 집계할 수 있습니다

아래 샘플에서는 `othersCategoryThreshold`이 2로, `othersCategoryType`가 Number로 설정되어 있습니다. 따라서 값이 2 이하인 항목은 "Others" 카테고리에 할당됩니다.

`othersCategoryType`를 Percent로 설정하면 `othersCategoryThreshold`는 값이 아니라 백분율로 해석됩니다. 즉, 값이 모든 항목 값 합계의 2% 미만인 항목이 Others 카테고리에 할당됩니다. 애플리케이션에 가장 적합한 `othersCategoryType`를 사용할 수 있습니다.

## {Platform} 파이 차트 선택
파이 차트는 기본 동작으로 마우스 클릭을 통한 조각 선택을 지원합니다. `selectedItems` 속성을 사용하여 선택된 조각을 결정할 수 있습니다. 그러면 선택된 조각이 강조 표시됩니다.

파이 차트가 사용할 모드를 설정하는 `selectionMode`라는 속성이 있습니다. 기본값은 `Single`입니다. 선택을 비활성화하려면 이 속성을 `Manual`로 설정하십시오.

파이 차트는 세 가지 다른 선택 모드를 지원합니다.

- Single - 모드가 single로 설정되면 한 번에 하나의 조각만 선택할 수 있습니다. 새 조각을 선택하면 이전에 선택된 조각은 선택이 해제되고 새 조각이 선택됩니다.
- Multiple - 모드가 Multiple로 설정되면 여러 조각을 동시에 선택할 수 있습니다. 조각을 클릭하면 선택되며, 다른 조각을 클릭하면 그 조각도 선택되고 이전 조각은 선택된 상태로 남습니다.
- Manual - 모드가 Manual로 설정되면 선택이 비활성화됩니다.

파이 차트에는 선택과 관련된 이벤트가 4개 있습니다:
- SelectedItemChanging
- SelectedItemChanged
- SelectedItemsChanging
- SelectedItemsChanged

"Changing"으로 끝나는 이벤트는 취소 가능한 이벤트이며, 이벤트 인수 속성 `Cancel`을 true로 설정하면 조각 선택을 중단할 수 있다는 의미입니다. true로 설정하면 연결된 속성이 업데이트되지 않으며 조각이 선택되지 않습니다. 이는 내부 데이터에 따라 사용자가 특정 조각을 선택하지 못하게 하려는 시나리오에 유용합니다.

기타 조각을 클릭하는 시나리오에서는 파이 차트가 `PieSliceOthersContext`라는 객체를 반환합니다. 이 객체에는 기타 조각에 포함된 데이터 항목의 목록이 들어 있습니다.

## {Platform} 파이 차트 애니메이션
`radiusFactor` 속성을 설정하여 파이 차트를 부드럽게 애니메이션할 수 있으며, 이는 차트의 반지름을 확대/축소합니다. 또한 `startAngle` 속성을 설정하면 회전하는 동안 차트 각도가 계속 증가하도록 차트를 기울일 수 있습니다.

아래 코드에서 radiusFactor는 차트 크기를 0.25%씩 키우고, startAngle은 차트를 1도씩 회전시킵니다. radiusFactor와 startAngle이 최대 한계에 도달하면 애니메이션 플래그를 재설정하고 인터벌을 지워 애니메이션을 중지합니다.
