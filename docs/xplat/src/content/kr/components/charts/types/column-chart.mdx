# {Platform} 열 차트

{ProductName} 열 차트, 열 그래프 또는 수직 막대 차트는 서로 다른 카테고리의 데이터 빈도, 개수, 합계 또는 평균을 빠르게 비교하는 데 사용되는 가장 일반적인 카테고리 차트 유형 중 하나이며, 데이터는 너비는 같지만 높이가 다른 열로 인코딩됩니다. 이 열들은 차트의 아래에서 위로, 데이터 지점의 값을 향해 뻗어 있습니다. 이 차트는 일정 기간 동안의 변화량을 강조하거나 여러 항목을 비교합니다. 열 차트는 [막대 차트](bar-chart.mdx)와 매우 비슷하지만, 열 차트는 수직 방향(위와 아래)으로 렌더링되는 반면 [막대 차트](bar-chart.mdx)는 수평 방향(왼쪽에서 오른쪽) 또는 시계 방향 90도 회전 방향을 가집니다.

## 열 차트 권장 사항

### 열 차트 사용 사례

열 차트에는 여러 사용 사례가 있습니다. 다음과 같은 경우입니다:

- 관련된 카테고리의 데이터 값을 비교해야 하는 경우.
- 일정 기간 동안의 데이터를 비교해야 하는 경우.
- 같은 데이터 세트에서 양수 값뿐만 아니라 음수 값도 표시해야 하는 경우.
- 이동, 확대/축소, 드릴다운과 같은 차트 상호 작용에 잘 맞는 대용량 데이터 세트가 있는 경우.

### 열 차트 모범 사례

- 데이터 비교가 정확하도록 Y축(왼쪽 또는 오른쪽 축)은 항상 0에서 시작하십시오.
- 시계열 데이터는 왼쪽에서 오른쪽으로 정렬하십시오.

### 열 차트를 사용하지 말아야 하는 경우

- 데이터 시리즈가 많습니다(10개 또는 12개를 초과). 차트를 읽기 쉽게 유지하는 것이 목표입니다.

### 열 차트 데이터 구조

- 데이터 모델에는 최소 하나의 숫자 속성이 있어야 합니다.
- 데이터 모델에는 레이블을 위한 옵션 문자열 또는 날짜-시간 속성이 포함될 수 있습니다.
- 데이터 소스에는 최소 하나의 데이터 항목이 있어야 합니다.

## 고급 열 차트 유형

다음 섹션에서는 간소화된 API를 갖춘 `CategoryChart` 컨트롤 대신 `DataChart` 컨트롤을 사용하여 만들 수 있는 더 고급 유형의 {Platform} 열 차트를 설명합니다.


## {Platform} 폭포 차트

폭포 차트는 카테고리 차트 그룹에 속하며, 연속된 데이터 지점 간의 차이를 보여 주는 수직 열 모음으로 렌더링됩니다. 열은 값의 양수 변화와 음수 변화를 구분하도록 색상으로 구분됩니다. 폭포 차트는 외관이 [범위 열 차트](column-chart.mdx#{PlatformLower}-범위-열-차트)와 비슷하지만, 데이터 지점마다 두 개의 열이 아니라 하나의 숫자 데이터 열만 필요합니다.

아래 예제와 같이 데이터를 `WaterfallSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

## {Platform} 누적 열 차트

누적 열 차트는 시리즈를 옆이 아니라 서로 위에 표시한다는 점을 제외하면 모든 측면에서 [카테고리 열 차트](column-chart.mdx#{PlatformLower}-열-차트-예제)와 비슷합니다. 누적 열 차트는 시리즈 간 비교 결과를 보여 주는 데 사용됩니다. 모음 안의 각 쌓인 조각은 각 스택에서 하나의 시각 요소를 나타냅니다. 각 스택에는 양수 값과 음수 값이 모두 포함될 수 있습니다. 모든 양수 값은 Y축의 양의 쪽에 묶이고, 모든 음수 값은 Y축의 음의 쪽에 묶입니다. 누적 열 차트는 [누적 막대 차트](stacked-chart.mdx#{PlatformLower}-누적-막대-차트)와 같은 데이터 플롯 개념을 사용하지만, 데이터 지점이 수평선(X축)을 따라 쌓이는 대신 수직선(Y축)을 따라 쌓입니다.

아래 예제와 같이 데이터를 `StackedBarSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

<Sample src="/charts/data-chart/stacked-column-chart" height={600} alt="{Platform} 누적 열 차트" />




## {Platform} 누적 100% 열 차트

누적 100% 열 차트는 Y축 값을 처리하는 방식을 제외하고는 모든 측면에서 [누적 열 차트](stacked-chart.mdx#{PlatformLower}-누적-열-차트)와 동일합니다. 누적 100 열 차트는 데이터를 직접 표현하는 대신, 데이터 지점의 모든 값 합계에 대한 백분율로 데이터를 표시합니다.

## {Platform} 범위 열 차트

{Platform} 범위 열 차트는 범위 차트 그룹에 속하며, 전통적인 [카테고리 열 차트](column-chart.mdx#{PlatformLower}-열-차트-예제)처럼 아래에서 뻗어 나오는 대신 차트의 플롯 영역 가운데에 나타날 수 있는 수직 직사각형으로 렌더링됩니다. 이 시리즈 유형은 일정 기간 동안 같은 데이터 지점의 낮은 값과 높은 값 사이의 변화량을 강조하거나 여러 항목을 비교합니다. 범위 값은 Y축에 표시되고 카테고리는 X축에 표시됩니다.

범위 열 차트는 범위가 채워진 영역이 아니라 수직 열 세트로 표현된다는 점을 제외하면 모든 측면에서 [범위 영역 차트](area-chart.mdx#{PlatformLower}-범위-영역-차트)와 동일합니다.

아래 예제와 같이 데이터를 `RangeColumnSeries`에 바인딩하여 `DataChart` 컨트롤에서 이 유형의 차트를 만들 수 있습니다:

## {Platform} 방사형 열 차트

방사형 열 차트는 [방사형 차트](radial-chart.mdx) 그룹에 속하며, 차트 중심에서 데이터 지점의 위치를 향해 뻗는 직사각형 모음을 사용하여 시각화됩니다. 이는 [카테고리 열 차트](column-chart.mdx#{PlatformLower}-열-차트-예제)와 같은 데이터 플롯 개념을 사용하지만, 데이터 지점을 수평으로 늘이는 대신 원 주위에 배치합니다.
