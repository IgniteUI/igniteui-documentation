# {Platform} 선 차트

{ProductName} 선 차트 또는 선 그래프는 일정 기간 동안 하나 이상의 수량에 대한 연속 데이터 값을 직선 세그먼트로 연결된 점으로 나타내는 카테고리 차트의 한 유형입니다. 추세를 보여 주고 비교 분석을 수행하는 데 자주 사용됩니다. Y축(왼쪽 레이블)은 숫자 값을 보여 주고, X축(하단 레이블)은 시계열 또는 비교 카테고리를 보여 줍니다. 비교할 데이터 세트를 하나 이상 포함할 수 있으며, 이 경우 차트에 여러 선으로 렌더링됩니다.

## 선 차트 권장 사항

### {Platform} 선 차트가 프로젝트에 적합합니까?

- [영역 차트](area-chart.mdx)와 달리, 선 차트는 X축(하단 축)과 선 사이의 영역을 채우지 않습니다.
- {Platform} 선 차트는 데이터 포인트를 잇는 선에 데이터 표현을 개선하기 위한 스플라인 보간과 평활화가 없다는 점을 제외하면 모든 측면에서 {Platform} [스플라인 차트](spline-chart.mdx)와 동일합니다.

선 차트는 데이터나 데이터로 올바른 이야기를 전달하려는 방식에 따라 여러 변형을 포함합니다. 여기에는 다음이 포함됩니다:

- 레이어 선 차트
- 누적 선 차트
- 계단형 선 차트
- 극좌표 선 차트
- 누적 100 선 차트

### 선 차트 사용 사례

선 차트를 선택하는 일반적인 사용 사례는 다음과 같습니다:

- 이동, 확대/축소, 드릴다운과 같은 차트 상호 작용에 잘 맞는 대용량 데이터 세트가 있는 경우.
- 시간에 따른 추세를 비교해야 하는 경우.
- 2개 이상의 데이터 시리즈 간의 차이를 보여 주고 싶은 경우.
- 뚜렷한 카테고리 간의 누적된 부분 대 전체 비교를 보여 주고 싶은 경우.
- 비교 분석을 위해 하나 이상의 카테고리에 대한 데이터 추세를 보여 줄 필요가 있는 경우.
- 상세한 시계열 데이터를 시각화해야 하는 경우.

### 선 차트 모범 사례

- 데이터 비교가 정확하도록 Y축(왼쪽 또는 오른쪽 축)은 항상 0에서 시작하십시오.
- 시계열 데이터는 왼쪽에서 오른쪽으로 정렬하십시오.
- 일련의 데이터를 보여 주려면 실선과 같은 시각적 속성을 사용하십시오.

### 선 차트를 사용하지 말아야 하는 경우

- 데이터 시리즈가 많습니다(7개 또는 10개를 초과). 차트를 읽기 쉽게 유지하는 것이 목표입니다.
- 시계열 데이터의 값이 비슷하면(같은 기간의 데이터), 겹치는 선을 구별할 수 없게 됩니다.

### 선 차트 데이터 구조

- 데이터 소스는 배열 또는 데이터 항목의 목록이어야 합니다(단일 시리즈의 경우).
- 데이터 소스는 배열의 배열 또는 목록의 목록이어야 합니다(여러 시리즈의 경우).
- 데이터 소스에는 최소 하나의 데이터 항목이 있어야 합니다.
- 모든 데이터 항목에는 최소 하나의 데이터 열(문자열 또는 날짜-시간)이 있어야 합니다.
- 모든 데이터 항목에는 최소 하나의 숫자 데이터 열이 있어야 합니다.

## {Platform} 방사형 선 차트

방사형 선 차트는 방사형 차트 그룹에 속하며, 데이터 지점을 연결하는 직선 모음으로 둘러싸인 채우지 않은 다각형 모양입니다. 이 차트 유형은 선 차트와 같은 데이터 플롯 개념을 사용하지만, 데이터 지점을 수평으로 늘이는 대신 원형 축 주위에 배치합니다.

## {Platform} 극좌표 선 차트
