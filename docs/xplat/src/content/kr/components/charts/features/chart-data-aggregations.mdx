# {Platform} 데이터 집계

{ProductName} `CategoryChart` 컨트롤에서 데이터 집계 기능을 사용하면 X축의 데이터 멤버 고유 값으로 차트의 데이터를 그룹화한 후 해당 그룹을 정렬할 수 있습니다. 그런 다음 요약을 적용할 수 있으며, 이는 Y축의 범위에 반영되고 시리즈 위에 마우스를 올리면 툴팁에 표시됩니다.

## {Platform} 데이터 집계 예제

다음 예제는 X축의 Country 멤버로 그룹화된 [열 차트](../types/column-chart.mdx)를 보여 줍니다. 각 데이터 항목 내의 Product, MonthName, Year 등 다른 속성으로 변경하여 판매 데이터를 집계할 수 있습니다. 또한 그룹화된 속성에 원하는 순서를 지정하기 위해 요약 및 정렬 옵션을 사용할 수 있습니다.

`initialSummaries`와 `groupSorts`의 드롭다운에 있는 축약 함수는 할당한 속성에 따라 올바른 결과를 얻기 위해 표시된 대로 적용해야 합니다. 예: Sum(sales) as Sales | Sales Desc

<Sample src="/charts/category-chart/data-aggregations" height={500} alt="{Platform} 데이터 집계 예제" />


```json-snippet source="/charts/category-chart/data-aggregations"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "CategoryChart",
    "name": "chart",
            "dataSourceRef": "SalesData",
            "initialGroups": "Country",
            "initialSummaries": "Sum(Sales) as Sales",
            "groupSorts": "Sales Desc"
        }
    }
}
```
