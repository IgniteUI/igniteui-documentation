# {Platform} 차트 강조 필터

{ProductName} 차트 컴포넌트는 플롯된 데이터의 일부만 볼 수 있도록 하여, 해당 차트에 플롯된 시리즈의 시각화를 향상시키는 데이터 강조 오버레이를 지원합니다. 활성화하면 데이터의 일부를 강조하면서, 열 및 영역 시리즈 유형에서는 불투명도를 낮추고 선 시리즈 유형에서는 점선으로 전체 데이터 세트를 표시합니다. 이를 통해 데이터 세트의 목표 값과 실제 값을 비교하는 것과 같은 내용을 시각화할 수 있습니다. 이 기능은 다음 예제에서 시연됩니다:

<Sample src="/charts/data-chart/chart-highlight-filter-multiple-series" height={500} alt="{Platform} 강조 필터 예제" />


데이터 강조 기능은 `DataChart` 및 `CategoryChart`에서 지원되지만, 두 컨트롤의 작동 방식 특성상 구성 방법이 다릅니다. 그럼에도 이 기능에서 변하지 않는 한 가지는, 강조 표시를 보려면 `highlightedValuesDisplayMode` 속성을 `SeriesHighlightedValuesDisplayMode.Overlay`로 설정해야 한다는 것입니다. 다음에서는 강조 필터 기능의 여러 구성 방법을 설명합니다.

## DataChart에서 강조 필터 사용

`DataChart`에서는 강조 필터 API의 대부분이 시리즈 자체에서 이루어지며, 주로 강조하려는 데이터의 일부를 나타내는 컬렉션으로 `highlightedDataSource` 속성을 설정합니다. `highlightedDataSource`의 항목 수는 강조하려는 시리즈의 `DataSource`에 바인딩된 데이터 수와 일치해야 하며, 카테고리 시리즈의 경우 기본적으로 정의한 `ValueMemberPath`를 강조 경로로 사용합니다. 이 페이지 상단의 샘플은 `DataChart`의 `highlightedDataSource`를 사용하여 오버레이를 표시합니다.

`highlightedDataSource`와 시리즈의 `DataSource` 사이에 스키마가 일치하지 않는 경우, 시리즈의 `HighlightedValueMemberPath` 속성을 사용하여 이를 구성할 수 있습니다. 또한 데이터 항목에 부분 집합을 나타내는 경로가 있다면, 시리즈 자체의 `DataSource`를 강조 소스로 사용할 수도 있습니다. 이는 `HighlightedValueMemberPath` 속성을 해당 경로로 설정하고 `highlightedDataSource`를 제공하지 않으면 됩니다.

열 및 영역 시리즈 유형의 불투명도 감소는 시리즈의 `highlightedValuesFadeOpacity` 속성을 설정하여 구성할 수 있습니다. 오버레이를 전혀 보고 싶지 않다면 `highlightedValuesDisplayMode` 속성을 `SeriesHighlightedValuesDisplayMode.Hidden`로 설정할 수도 있습니다.

강조 필터로 표시되는 시리즈 부분은 차트의 범례 및 툴팁 레이어에 별도로 표시됩니다. `highlightedTitleSuffix`를 설정하여 툴팁과 범례에 주어지는 제목을 구성할 수 있습니다. 이는 시리즈의 `chartTitle` 끝에 입력한 값을 덧붙입니다.

`DataLegend` 또는 `DataToolTipLayer`를 사용하면 강조된 시리즈가 그룹으로 표시됩니다. 이는 시리즈의 `highlightedValuesDataLegendGroup` 속성을 설정하여 적절하게 분류함으로써 관리할 수 있습니다.

## CategoryChart에서 강조 필터 사용

`CategoryChart` 강조 필터는 차트의 `initialHighlightFilter` 속성을 설정하여 이루어집니다. `CategoryChart`는 기본적으로 기본 데이터 항목의 모든 속성을 고려하므로, 데이터의 일부를 필터링할 수 있도록 데이터를 그룹화하고 집계할 수 있게 차트에서도 `initialGroups`를 정의해야 합니다. 기본 데이터 항목의 값 경로를 `initialGroups`로 설정하면, 중복 값이 있는 경로를 기준으로 그룹화할 수 있습니다.
