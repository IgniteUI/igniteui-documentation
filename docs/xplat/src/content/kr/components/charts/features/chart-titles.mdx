# {Platform} 차트 제목 및 부제목

차트 컨트롤의 제목 및 부제목 기능을 사용하면 {Platform} 차트의 상단 영역에 정보를 추가할 수 있습니다.

## 예제

<Sample src="/charts/category-chart/line-chart-with-titles" height={600} alt="{Platform} 차트 제목 및 부제목 예제" />


## API 참조

차트 컨트롤에 제목이나 부제목을 추가하면 차트의 콘텐츠가 제목과 부제목 정보를 수용하도록 자동으로 크기가 조정됩니다.

| 속성 이름         | 속성 유형   |     설명  |
| ----------------------|------------------|------------|
| `ChartTitle`          | string |  제목의 텍스트 콘텐츠입니다.  |
| `titleTextColor`      | string |  제목의 텍스트 색상입니다.  |
| `titleAlignment`      | HorizontalAlignment |  제목의 가로 정렬입니다.  |
| `titleTextStyle`      | string | 제목의 글꼴 스타일입니다. 예: Italic Bold 8pt Times New Roman  |
| `titleTopMargin`      | 숫자 | 제목의 위쪽 여백입니다.  |
| `titleLeftMargin`     | 숫자 | 제목의 왼쪽 여백입니다.  |
| `titleRightMargin`    | 숫자 | 제목의 오른쪽 여백입니다.  |
| `titleBottomMargin`   | 숫자 | 제목의 아래쪽 여백입니다.  |
| `CategoryChart.subtitle`            | string |  제목의 텍스트 콘텐츠입니다.  |
| `subtitleTextColor`   | string |  제목의 텍스트 색상입니다.  |
| `subtitleAlignment`   | HorizontalAlignment |  제목의 가로 정렬입니다.  |
| `subtitleTextStyle`   | string | 제목의 글꼴 스타일입니다. 예: Italic Bold 8pt Times New Roman  |
| `subtitleTopMargin`   | 숫자 | 제목의 위쪽 여백입니다.  |
| `subtitleLeftMargin`  | 숫자 | 제목의 왼쪽 여백입니다.  |
| `subtitleRightMargin` | 숫자 | 제목의 오른쪽 여백입니다.  |
| `subtitleBottomMargin`| 숫자 | 제목의 아래쪽 여백입니다.  |
