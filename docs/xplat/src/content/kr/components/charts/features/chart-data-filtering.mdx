# {Platform} 차트 데이터 필터링

데이터 필터링을 사용하면 차트에 바인딩된 데이터 소스를 수동으로 수정하지 않고도 필터 식을 통해 대용량 데이터를 쿼리하여 작은 데이터 항목 하위 집합을 분석하고 플롯할 수 있습니다.

쿼리 문자열을 구성하는 데 사용할 수 있는 유효한 식과 키워드의 전체 목록은 다음에서 확인할 수 있습니다:

[필터 식](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/webservices/use-filter-expressions-in-odata-uris)

> 참고: 잘못된 필터를 적용하면 차트가 비어 있게 됩니다.

## {Platform} 차트 데이터 필터 예제

다음 예제는 여러 10년 동안의 연간 출생률을 [열 차트](../types/column-chart.mdx)로 나타냅니다. 드롭다운에서 10년을 선택하면 `initialFilter` 속성을 통해 식이 삽입되어 차트 시각 요소가 업데이트되고 다른 10년은 필터링되어 제외됩니다.

<Sample src="/charts/category-chart/data-filter" height={500} alt="{Platform} 데이터 필터 예제" />



`initialFilter` 속성은 올바르게 필터링되려면 다음 구문이 필요한 문자열입니다. 이 값에는 필터링되는 레코드와 연결된 필터 식 정의, 열, 값을 모두 포함하는 괄호 세트가 필요합니다.

예: B로 시작하는 모든 국가를 표시하려면:

"(startswith(Country, 'B'))"

예: 둘 이상의 식 연결하기:

"(startswith(Country, 'B') and endswith(Country, 'L') and contains(Product, 'Royal Oak') and contains(Date, '3/1/20'))"
