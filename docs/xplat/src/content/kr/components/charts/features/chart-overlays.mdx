# {Platform} 차트 오버레이

{Platform} `DataChart`를 사용하면 `ValueOverlay`를 통해 정의한 단일 숫자 값에 수평 또는 수직 선을 배치할 수 있습니다. 이를 통해 특정 시리즈의 평균이나 중앙값과 같은 데이터를 시각화할 수 있습니다.

## {Platform} 값 오버레이 속성

데이터 바인딩에 `DataSource`를 사용하는 다른 시리즈 유형과 달리, 값 오버레이는 단일 숫자 값을 바인딩하기 위해 `Value` 속성을 사용합니다. 또한 값 오버레이를 사용하려면 단일 `ValueOverlay.axis`를 정의해야 합니다. X축을 사용하면 값 오버레이는 수직선이 되며, Y축을 사용하면 수평선이 됩니다.

숫자 X축 또는 Y축을 사용할 때 `Value` 속성은 값 오버레이를 그리려는 축의 실제 숫자 값을 반영해야 합니다. 카테고리 X축 또는 Y축을 사용할 때 `Value`는 값 오버레이가 나타나야 하는 카테고리의 인덱스를 반영해야 합니다.

숫자 각도 축과 함께 값 오버레이를 사용하면 차트 중심에서 시작하는 선으로 나타나며, 숫자 반지름 축과 함께 사용하면 원으로 나타납니다.

`ValueOverlay`의 모양 속성은 `Series`에서 상속되므로, 예를 들어 `ValueOverlay.brush`와 `ValueOverlay.thickness`를 사용할 수 있으며 다른 시리즈 유형에서와 같은 방식으로 작동합니다.

`ValueOverlay`에서 소유 축에 오버레이 값을 표시하는 축 주석을 표시할 수도 있습니다. 이를 표시하려면 `isAxisAnnotationEnabled` 속성을 true로 설정하십시오.

## {Platform} 값 레이어

{Platform} 차팅 컴포넌트는 값 선을 사용하여 최솟값, 최댓값, 평균 값처럼 데이터의 여러 주요 지점을 강조하는 기능도 제공합니다.

`ValueLayer`를 다음에서 적용하려면 <PlatformBlock for="Web">`CategoryChart` 및 `FinancialChart` 컴포넌트</PlatformBlock><PlatformBlock for="WinUI, Uno">`CategoryChart` 컴포넌트</PlatformBlock> 차트의 `valueLines` 속성을 설정하면 됩니다. 이 속성은 `ValueLayerValueMode` 열거형의 컬렉션을 받습니다. 차트의 `valueLines` 컬렉션에 여러 `ValueLayerValueMode` 열거형을 추가하면 같은 차트에서 여러 값 레이어를 자유롭게 조합할 수 있습니다.

`DataChart`에서는 차트의 `Series` 컬렉션에 `ValueLayer`를 추가한 다음, `ValueLayer` 속성을 `ValueLayerValueMode` 열거형 중 하나로 설정하여 이를 수행합니다. 각 열거형과 그 의미는 아래에 나열되어 있습니다:

- `Auto`: `ValueLayerValueMode` 열거형의 기본 값 모드입니다.
- `Average`: 차트에 플롯된 각 시리즈의 평균 값을 강조하기 위해 여러 값 선을 적용할 수 있습니다.
- `GlobalAverage`: 차트 내 모든 시리즈 값의 평균을 강조하기 위해 단일 값 선을 적용합니다.
- `GlobalMaximum`: 차트 내 모든 시리즈 값의 절댓값 최댓값을 강조하기 위해 단일 값 선을 적용합니다.
- `GlobalMinimum`: 차트의 모든 시리즈 값 중 절댓값 최솟값을 강조하기 위해 단일 값 선을 적용합니다.
- `Maximum`: 차트에 플롯된 각 시리즈의 최댓값을 강조하기 위해 여러 값 선을 적용할 수 있습니다.
- `Minimum`: 차트에 플롯된 각 시리즈의 최솟값을 강조하기 위해 여러 값 선을 적용할 수 있습니다.

`ValueLayer` 요소를 사용할 때 특정 시리즈가 고려되지 않도록 하려면, 레이어의 `targetSeries` 속성을 설정할 수 있습니다. 이렇게 하면 레이어가 정의한 시리즈를 대상으로 강제됩니다. 단일 `DataChart` 안에 원하는 만큼 많은 `ValueLayer` 요소를 둘 수 있습니다.

## 차트 오버레이 텍스트 <Badge variant="preview" />

{Platform} `ValueOverlay`, `ValueLayer` 및 모든 데이터 주석 레이어는 DataChart 컴포넌트의 플롯 영역 안에 사용자 지정 오버레이 텍스트를 렌더링할 수 있습니다. 이 오버레이 텍스트를 사용하여 레이어와 관련하여 x축의 중요한 이벤트(예: 회사 분기 보고서) 또는 y축의 중요한 값에 주석을 달 수 있습니다.

예를 들어 `DataAnnotationSliceLayer`, `ValueOverlay`, `ValueLayer`를 사용하여 오버레이 텍스트를 표시할 수 있습니다.
