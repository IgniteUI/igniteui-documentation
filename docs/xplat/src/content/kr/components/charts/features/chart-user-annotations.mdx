# {Platform} 차트 사용자 주석 레이어 <Badge variant="preview" />

{ProductName}에서는 사용자 주석 기능을 사용하여 런타임에 슬라이스, 스트립, 포인트 주석으로 `DataChart`에 주석을 달 수 있습니다. 이를 통해 최종 사용자는 슬라이스 주석을 사용하여 회사 분기 보고서와 같은 단일 중요 이벤트를 짚거나, 스트립 주석을 사용하여 기간이 있는 이벤트를 짚는 등 플롯에 세부 정보를 추가할 수 있습니다. 또한 포인트 주석을 사용하여 플롯된 시리즈의 개별 지점을 짚거나, 이 세 가지를 임의로 조합할 수도 있습니다.

이는 `Toolbar`의 사용 가능한 도구와 직접 통합되어 있습니다. 다음 항목에서는 `Toolbar`를 사용하여 차트의 플롯 영역에 사용자 주석을 추가하는 방법과, 이러한 사용자 주석을 프로그래밍 방식으로 추가하는 방법을 예제와 함께 설명합니다.

<Sample src="/charts/data-chart/user-annotation-layer" height={500} alt="{Platform} 추세선 예제" />


<DocsAside type="info">
이 기능은 X축과 Y축을 지원하도록 설계되었으며, 현재 방사형 축과 각도 축은 지원하지 않습니다.
</DocsAside>

## 도구 모음에서 사용자 주석 사용하기

`Toolbar`에는 "Annotate Chart"와 "Delete Note"라는 레이블이 있는 두 가지 도구가 포함된 주석 메뉴 항목이 표시됩니다. 이 메뉴 항목이 나타나려면 먼저 해당 차트의 `isUserAnnotationsEnabled` 속성을 `true`로 설정해야 합니다.

열린 후 나타나는 "Annotate Chart" 옵션을 사용하면 `DataChart`의 플롯 영역에 주석을 달 수 있습니다. 이는 슬라이스, 스트립 또는 포인트 주석을 추가하여 수행할 수 있습니다. X축 또는 Y축의 레이블을 클릭하면 슬라이스 주석을 추가할 수 있습니다. 플롯 영역에서 클릭하고 드래그하면 스트립 주석을 추가할 수 있습니다. 또한 차트에 플롯된 시리즈의 지점을 클릭하면 포인트 주석을 추가할 수 있습니다.

<Image src={dataChartUserAnnotationCreate} alt="{Platform} user-annotation-create" class="responsive-img" />

"Delete Note" 메뉴 항목을 선택한 다음 슬라이스 또는 스트립 사용자 주석의 축 주석을 클릭하거나, 포인트 사용자 주석의 해당 데이터 지점을 클릭하여 이전에 추가한 주석을 삭제할 수 있습니다.

<Image src={dataChartUserAnnotationDelete} alt="{Platform} user-annotation-delete" class="responsive-img" />

`Toolbar`를 통해 이러한 사용자 주석 중 하나를 추가하면 `DataChart`는 `UserAnnotationInformationRequested`라는 이벤트를 발생시켜 사용자 주석에 대한 자세한 정보를 제공할 수 있게 합니다. 이 이벤트의 인수에는 `UserAnnotationInformation` 객체를 반환하는 `AnnotationInfo` 속성이 있으며, 이를 통해 주석에 추가할 여러 측면을 구성할 수 있습니다.

아래 표는 `UserAnnotationInformation`의 구성 가능한 여러 속성을 자세히 설명합니다:

| 속성 | 타입 | 설명 |
|------------|---------|-------------|
|`annotationData`|`string`|이 속성은 사용자 주석에 대한 추가 정보를 허용합니다. 이 속성은 주석 툴팁에 추가 정보를 표시하도록 `UserAnnotationToolTipContentUpdating` 이벤트와 함께 사용하도록 설계되었습니다.|
|`annotationId`|`string`|이 읽기 전용 속성은 사용자 주석의 고유 문자열 ID를 반환합니다.|
|`badgeColor`|`string`|이 속성은 사용자 주석의 배지에 사용할 색상을 가져오거나 설정합니다.|
|`badgeImageUri`|`string`|이 속성은 사용자 주석의 배지에 사용할 이미지 경로를 가져오거나 설정합니다.|
|`dialogSuggestedXLocation`|`double`|이 속성은 사용자 주석이 추가된 위치를 기준으로 대화 상자를 표시하기 위해 권장되는 X 위치를 가져옵니다.|
|`dialogSuggestedYLocation`|`double`|이 속성은 사용자 주석이 추가된 위치를 기준으로 대화 상자를 표시하기 위해 권장되는 Y 위치를 가져옵니다.|
|`UserStripAnnotation.label`|`string`|이 속성은 사용자 주석에 표시될 레이블을 가져오거나 설정합니다.|
|`mainColor`|`string`|이 속성은 사용자 주석의 배경을 채우는 데 사용할 색상을 가져오거나 설정합니다.|

`UserAnnotationInformationRequested` 이벤트를 통해 주석을 수정한 후에는 `DataChart`의 `m:finishAnnotationFlow` 메서드를 호출하여 주석 생성을 마치고 변경 사항을 커밋해야 합니다. 또는 위에서 언급한 대로 `UserAnnotationInformationRequested` 이벤트 인수의 `AnnotationInfo` 매개변수에서 얻을 수 있는 주석의 `annotationId`를 전달하여 `m:cancelAnnotationFlow`를 호출하면 주석 생성을 취소할 수도 있습니다. 이렇게 하면 주석이 플롯 영역에서 제거됩니다.

## 프로그래밍 방식으로 사용자 주석 사용하기

`UserAnnotationLayer`를 프로그래밍 방식으로 사용할 때는 `DataChart`에서 두 가지 다른 메서드를 호출하여 차트를 사용자 주석을 추가하거나 제거할 수 있는 모드로 전환할 수 있습니다. 이 메서드는 각각 `m:startCreatingAnnotation` 및 `m:startDeletingAnnotation`라는 이름입니다.

`m:startCreatingAnnotation`를 호출한 후에는 X축 또는 Y축의 레이블을 클릭하여 슬라이스 주석을 추가하거나, 플롯 영역에서 클릭하고 드래그한 후 마우스 버튼을 놓아 스트립 주석을 추가하거나, 차트에 플롯된 시리즈의 데이터 지점을 클릭하여 포인트 주석을 추가할 수 있습니다.

이러한 사용자 주석 중 하나를 추가하면 `UserAnnotationInformationRequested` 이벤트가 발생하며, 이를 통해 사용자 주석에 대한 자세한 정보를 제공할 수 있습니다. 이 이벤트의 인수에는 `UserAnnotationInformation` 객체를 반환하는 `AnnotationInfo` 속성이 있으며, 이를 통해 주석에 추가할 여러 측면을 구성할 수 있습니다.

`UserAnnotationInformationRequested` 이벤트를 통해 주석을 수정한 후에는 `DataChart`의 `m:finishAnnotationFlow` 메서드를 호출하여 주석 생성을 마치고 변경 사항을 커밋해야 합니다. 또는 위에서 언급한 대로 `UserAnnotationInformationRequested` 이벤트 인수의 `AnnotationInfo` 매개변수에서 얻을 수 있는 주석의 `annotationId`를 전달하여 `m:cancelAnnotationFlow`를 호출하면 주석 생성을 취소할 수도 있습니다. 이렇게 하면 주석이 플롯 영역에서 제거됩니다.

사용자 주석이 차트에 추가되면 `Series` 컬렉션에 `UserAnnotationLayer`로 나타납니다. `UserAnnotationLayer`에는 플롯 영역에 추가된 주석 유형에 따라 `UserSliceAnnotation`, `UserStripAnnotation`, `UserPointAnnotation` 요소를 저장할 수 있는 `UserAnnotationLayer.annotations` 컬렉션이 있습니다.

## 사용자 주석 툴팁

각 사용자 주석은 마우스를 올렸을 때 툴팁을 표시하여 주석에 더 자세한 내용을 추가할 수 있습니다.

차트는 툴팁이 표시될 때 사용자 주석의 툴팁 내용을 업데이트하기 위해 처리할 수 있는 `UserAnnotationToolTipContentUpdating` 이벤트를 노출합니다. 이 이벤트의 인수는 두 가지 속성인 `Content`와 `AnnotationInfo`를 노출합니다.

툴팁은 `UserAnnotationInformationRequested` 이벤트와 함께 작동하도록 설계되었으므로, 해당 이벤트의 `UserAnnotationInformation.AnnotationData` 속성을 통해 사용자 주석에 더 자세한 내용을 제공할 수 있습니다. `UserAnnotationToolTipContentUpdating` 이벤트의 이벤트 인수에 있는 `AnnotationInfo` 속성은 해당 이벤트에서 수정할 수 있는 `UserAnnotationInformationRequested`의 `AnnotationInfo` 속성과 같은 인스턴스가 됩니다. 이를 통해 주석 생성 시 사용자 주석에 제공된 정보를 활용하고 툴팁 안에 더 많은 정보를 제공할 수 있습니다.
