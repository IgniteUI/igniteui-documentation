# {Platform} 차트 데이터 주석 <Badge variant="preview" />

{Platform} 차트에서 데이터 주석 레이어를 사용하면 데이터 차트에 플롯된 데이터에 경사선, 수직/수평선(일명 축 슬라이스), 수직/수평 띠(특정 축을 대상으로 함), 사각형, 심지어 평행사변형(일명 밴드)으로 주석을 달 수 있습니다. 데이터 바인딩을 지원하므로 원하는 만큼 많은 주석을 만들어 차트를 사용자 지정할 수 있습니다. 또한 서로 다른 주석 레이어를 결합할 수 있으며, 플롯 영역 안에 텍스트를 겹쳐 표시하여 데이터의 중요한 이벤트, 패턴, 영역에 주석을 달 수 있습니다.

<DocsAside type="info">
이 기능은 직교 축을 지원하도록 설계되었으며, 현재 반지름 축과 각도 축은 지원하지 않습니다.
</DocsAside>

예를 들어 주가에 주식 이벤트와 패턴으로 주석을 달 수 있습니다.

## {Platform} 데이터 주석 슬라이스 레이어 예제

{Platform}에서 `DataAnnotationSliceLayer`는 `DataChart` 컴포넌트의 축 여러 값에서 차트를 자르는 여러 수직 또는 수평선을 렌더링합니다. 이 데이터 주석 레이어는 x축의 중요한 이벤트(예: 회사 분기 보고서) 또는 y축의 중요한 값에 주석을 달 때 자주 사용됩니다. TargetAxis 속성을 y축으로 설정하면 데이터 주석 레이어가 수평 슬라이스로 렌더링되고, TargetAxis 속성을 x축으로 설정하면 수직 슬라이스로 렌더링됩니다. 모든 시리즈와 마찬가지로 DataAnnotationSliceLayer는 `DataSource` 속성을 통한 데이터 바인딩도 지원합니다. 이 속성은 `annotationValueMemberPath` 속성에 매핑된 숫자 데이터 열이 하나 이상 있어야 하는 데이터 항목 컬렉션으로 설정할 수 있습니다.

예를 들어 DataAnnotationSliceLayer를 사용하여 주가에 주식 분할이나 실적 보고서 결과와 같은 중요한 이벤트로 주석을 달 수 있습니다.

## {Platform} 데이터 주석 스트립 레이어 예제

{Platform}에서 `DataAnnotationStripLayer`는 `DataChart` 컴포넌트의 축에서 두 값 사이에 여러 수직 또는 수평 띠를 렌더링합니다. 이 데이터 주석 레이어는 x축의 이벤트 기간(예: 주식 시장 폭락)이나 y축의 중요한 값 범위에 주석을 달 때 사용할 수 있습니다. TargetAxis 속성을 y축으로 설정하면 데이터 주석 레이어가 수평 띠로 렌더링되고, TargetAxis 속성을 x축으로 설정하면 수직 띠로 렌더링됩니다. 모든 시리즈와 마찬가지로 `DataAnnotationStripLayer`도 `DataSource` 속성을 통한 데이터 바인딩을 지원합니다. 이 속성은 AnnotationValueMemberPath 속성에 매핑된 숫자 데이터 열이 하나 이상 있어야 하는 데이터 항목 컬렉션으로 설정할 수 있습니다.

예를 들어 `DataAnnotationStripLayer`를 사용하여 차트에 주식 시장 폭락과 연방 금리 변동으로 주석을 달 수 있습니다.

<Sample src="/charts/data-chart/data-annotation-strip-layer" height={500} alt="{Platform} 데이터 주석 스트립 레이어 예제" />


## {Platform} 데이터 주석 선 레이어 예제

{Platform}에서 `DataAnnotationLineLayer`는 `DataChart` 컴포넌트의 플롯 영역에 있는 두 점 사이에 여러 선을 렌더링합니다. 이 데이터 주석 레이어는 주가의 상승과 하락으로 주식 차트에 주석을 달 때 사용할 수 있습니다. 모든 시리즈와 마찬가지로 DataAnnotationLineLayer도 `DataSource` 속성을 통한 데이터 바인딩을 지원합니다. 이 속성은 선의 시작점과 끝점의 x/y 좌표를 나타내는 숫자 데이터 열이 최소 4개 있어야 하는 데이터 항목 컬렉션으로 설정할 수 있습니다. 시작점은 `startValueXMemberPath` 및 `startValueYMemberPath` 속성을 사용하여 매핑하고, 끝점은 `endValueXMemberPath` 및 `endValueYMemberPath` 속성을 사용하여 매핑해야 합니다.

예를 들어 DataAnnotationLineLayer를 사용하여 주가의 상승 및 하락 패턴과 y축의 주가 52주 최고가 및 최저가에 주석을 달 수 있습니다.

## {Platform} 데이터 주석 사각형 레이어 예제

{Platform}에서 `DataAnnotationRectLayer`는 `DataChart` 컴포넌트의 플롯 영역에 있는 시작점과 끝점으로 정의된 여러 사각형을 렌더링합니다. 이 데이터 주석 레이어는 주가의 약세 패턴처럼 플롯 영역의 특정 영역에 주석을 달 때 사용할 수 있습니다. 모든 시리즈와 마찬가지로 DataAnnotationRectLayer도 `DataSource` 속성을 통한 데이터 바인딩을 지원합니다. 이 속성은 사각형의 시작점과 끝점의 x/y 좌표를 나타내는 숫자 데이터 열이 최소 4개 있어야 하는 데이터 항목 컬렉션으로 설정할 수 있습니다. 시작점은 `startValueXMemberPath` 및 `startValueYMemberPath` 속성을 사용하여 매핑하고, 끝점은 `endValueXMemberPath` 및 `endValueYMemberPath` 속성을 사용하여 매핑해야 합니다.

예를 들어 DataAnnotationRectLayer를 사용하여 y축의 주가에 있는 약세 패턴과 간격에 주석을 달 수 있습니다.

## {Platform} 데이터 주석 밴드 레이어 예제

{Platform}에서 `DataAnnotationBandLayer`는 `DataChart` 컴포넌트의 플롯 영역에 있는 두 점 사이에 여러 기울어진 사각형(자유 형식 평행사변형)을 렌더링합니다. 이 데이터 주석 레이어는 주가의 상승 및 하락 범위에 주석을 달 때 사용할 수 있습니다. 모든 시리즈와 마찬가지로 DataAnnotationBandLayer도 `DataSource` 속성을 통한 데이터 바인딩을 지원합니다. 이 속성은 선의 시작점과 끝점의 x/y 좌표를 나타내는 숫자 데이터 열이 최소 4개 있어야 하는 데이터 항목 컬렉션으로 설정할 수 있습니다. 시작점은 `startValueXMemberPath` 및 `startValueYMemberPath` 속성을 사용하여 매핑하고, 끝점은 `endValueXMemberPath` 및 `endValueYMemberPath` 속성을 사용하여 매핑해야 합니다. 또한 AnnotationBreadthMemberPath 속성에 숫자 데이터 열을 바인딩하여 기울어진 사각형의 두께/크기를 지정할 수 있습니다.

예를 들어 DataAnnotationBandLayer를 사용하여 주가의 상승 범위에 주석을 달 수 있습니다.

## API 참조

다음은 위 섹션에서 언급된 API 멤버 목록입니다:

- `targetAxis`: 이 속성은 DataAnnotationBandLayer, DataAnnotationLineLayer, DataAnnotationRectLayer가 활성화될 축을 지정합니다.
- `DataSource`: 이 속성은 정확한 모양을 제공하기 위해 주석 레이어에 데이터를 바인딩합니다.
- `startValueXMemberPath`: 이 속성은 DataAnnotationBandLayer, DataAnnotationLineLayer, DataAnnotationRectLayer의 시작 x 위치가 있는 데이터 열 이름에 대한 매핑입니다.
- `startValueYMemberPath`: 이 속성은 DataAnnotationBandLayer, DataAnnotationLineLayer, DataAnnotationRectLayer의 시작 y 위치가 있는 데이터 열 이름에 대한 매핑입니다.
- `endValueXMemberPath`: 이 속성은 DataAnnotationBandLayer, DataAnnotationLineLayer, DataAnnotationRectLayer의 끝 x 위치가 있는 데이터 열에 대한 매핑입니다.
- `endValueYMemberPath`: 이 속성은 DataAnnotationBandLayer, DataAnnotationLineLayer, DataAnnotationRectLayer의 끝 y 위치가 있는 데이터 열에 대한 매핑입니다.
- `startLabelXMemberPath`: 이 속성은 축을 따라 xAxis의 시작 위치에 대한 오버레이 레이블을 나타내는 데이터 열에 대한 매핑입니다.
- `startLabelXDisplayMode` | `startLabelYDisplayMode` | `endLabelXDisplayMode` | `endLabelYDisplayMode` | `centerLabelXDisplayMode`: 이 속성들은 주석 도형의 시작, 끝 또는 중앙에 주석 레이블로 무엇을 표시할지 지정합니다. 예: 매핑된 데이터 값, 매핑된 데이터 레이블, 축 값, 또는 특정 주석 레이블 숨기기.
- `startLabelYMemberPath`: 이 속성은 y축에서 `DataAnnotationBandLayer`, `DataAnnotationLineLayer`, `DataAnnotationRectLayer`의 시작 위치에 대한 축 레이블을 나타내는 데이터 열에 대한 매핑입니다.
- `endLabelYMemberPath`: 이 속성은 y축에서 `DataAnnotationBandLayer`, `DataAnnotationLineLayer`, `DataAnnotationRectLayer`의 끝 위치에 대한 축 레이블을 나타내는 데이터 열에 대한 매핑입니다.
