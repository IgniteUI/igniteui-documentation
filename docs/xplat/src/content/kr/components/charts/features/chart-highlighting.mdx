# {Platform} 차트 강조 모드 및 동작

모든 {Platform} 차트는 다양한 강조 옵션을 지원합니다. 마우스가 플롯 영역에 렌더링된 시리즈 또는 데이터 항목 위에 있을 때 `highlightingMode`를 밝게 또는 흐리게 설정할 수 있습니다. 강조 효과를 트리거하기 위해 `highlightingBehavior`를 정확히 위에 있는 데이터 항목 또는 가장 가까운 데이터 항목으로 설정할 수 있습니다. 강조 모드와 동작은 `CategoryChart`<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> 및 `DataChart` 컨트롤에서 지원되며, 강조 기능을 사용하는 API도 동일합니다.

## 강조 레이어

{ProductName} `CategoryChart`는 데이터 항목 위에 마우스를 올릴 때 세 가지 유형의 강조를 활성화할 수 있습니다.

1. 시리즈 강조는 포인터가 위치하면 마커 또는 열로 표현된 단일 데이터 지점을 강조합니다. 이는 `isSeriesHighlightingEnabled` 속성을 true로 설정하여 활성화합니다.

2. 항목 강조는 시리즈의 항목을 해당 위치에 띠 모양으로 그리거나 해당 위치에 마커를 렌더링하여 강조합니다. 이는 `isItemHighlightingEnabled` 속성을 true로 설정하여 활성화합니다.

3. 카테고리 강조는 차트의 모든 카테고리 축을 대상으로 합니다. 포인터 위치에서 가장 가까운 축 영역을 밝히는 도형을 그립니다. 이는 `isCategoryHighlightingEnabled` 속성을 true로 설정하여 활성화합니다.
