## 사용자 상호 작용을 통한 차트 탐색

기본적으로 확대/축소가 켜져 있는지는 사용하는 차트에 따라 다릅니다. `CategoryChart`를 사용하면 기본적으로 켜져 있지만, `DataChart`에는 해당하지 않습니다. UI에서 탐색을 활성화하거나 비활성화하려면, 확대/축소를 활성화하거나 비활성화할 방향에 따라 차트의 `isHorizontalZoomEnabled` 및/또는 `isVerticalZoomEnabled` 속성을 설정해야 합니다.

마우스 클릭이나 터치로도 간단히 확대/축소하거나 이동할 수 있습니다. 데이터 차트의 `defaultInteraction` 속성은 마우스 클릭 또는 터치 이벤트에서 무슨 일이 일어날지 결정합니다. 이 속성의 기본값은 `DragZoom`이며, 이 값으로 설정하고 확대/축소가 활성화되어 있으면 클릭하고 드래그할 때 플롯 영역 위에 미리 보기 사각형이 표시되며, 이것이 차트의 확대 영역이 됩니다. 이 `defaultInteraction` 속성은 이동을 허용하려면 `DragPan`로, 이러한 작업을 방지하려면 `InteractionState.None`로도 설정할 수 있습니다.

## 터치, 마우스, 키보드를 통한 차트 탐색

{Platform} 데이터 차트에서 탐색은 터치, 마우스 또는 키보드로 수행할 수 있습니다. 기본적으로 터치, 마우스 또는 키보드 작업으로 다음 작업을 호출할 수 있습니다:

- **이동**: 키보드의 <kbd>🡐</kbd> <kbd>🡒</kbd> <kbd>🡑</kbd> <kbd>🡓</kbd> 화살표 키를 사용하거나 <kbd>SHIFT</kbd> 키를 누른 상태에서 마우스로 클릭하고 드래그하거나, 터치로 손가락을 누르고 움직입니다.
- **확대**: 키보드의 <kbd>PAGE UP</kbd> 키를 사용하거나, 마우스 휠을 위로 돌리거나, 터치로 핀치하여 확대합니다.
- **축소**: 키보드의 <kbd>PAGE DOWN</kbd> 키를 사용하거나, 마우스 휠을 아래로 돌리거나, 터치로 핀치하여 축소합니다.
- **차트 플롯 영역에 맞추기**: 키보드의 <kbd>HOME</kbd> 키를 사용합니다. 이에 대한 마우스 또는 터치 작업은 없습니다.
- **영역 확대**: `defaultInteraction` 속성을 기본값인 `DragZoom`로 설정한 상태에서 플롯 영역 안에서 마우스를 클릭하고 드래그합니다.

`dragModifier` 및 `panModifier` 속성을 설정하여 수정자 키를 사용해 확대/축소 및 이동 작업을 활성화할 수도 있습니다. 이 속성들은 다음 수정자 키 중 하나로 설정할 수 있으며, 키를 누르면 해당 작업이 실행됩니다:

| 수정자 값 | 해당 키 |
| ---------------|------------------ |
| `Shift`        | <kbd>SHIFT</kbd> |
| `Control`      | <kbd>CTRL</kbd> |
| `Windows`      | <kbd>WIN</kbd> |
| `Apple`        | <kbd>APPLE</kbd> |
| `None`         | 키 없음 |

## 스크롤바를 사용한 차트 탐색

`verticalViewScrollbarMode` 및 `horizontalViewScrollbarMode` 속성을 활성화하여 차트를 스크롤할 수 있습니다.

다음 옵션으로 구성할 수 있습니다

- `Persistent` - 차트가 확대된 상태에서는 스크롤바가 항상 표시되며, 완전히 축소되면 사라집니다.
- `Fading` - 스크롤바는 사용 후 사라지며, 마우스가 해당 위치 근처에 있으면 다시 나타납니다.
- `FadeToLine` - 확대/축소를 사용하지 않을 때 스크롤바가 더 얇은 선으로 줄어듭니다.
- `None` - 기본값이며, 스크롤바가 표시되지 않습니다.

## 코드를 통한 차트 탐색

<DocsAside type="info">
차트의 코드 탐색은 `DataChart` 컨트롤에서만 사용할 수 있습니다.
</DocsAside>

{Platform} 데이터 차트는 차트에서 확대/축소 또는 이동 작업이 수행될 때마다 업데이트되는 여러 탐색 속성을 제공합니다. 이러한 속성 각각을 설정하여 프로그래밍 방식으로 데이터 차트를 확대/축소하거나 이동할 수도 있습니다. 다음은 이러한 속성의 목록입니다:

- `windowPositionHorizontal`: 데이터 차트가 표시하는 콘텐츠 뷰 사각형의 X 부분을 설명하는 숫자 값입니다.
- `windowPositionVertical`: 데이터 차트가 표시하는 콘텐츠 뷰 사각형의 Y 부분을 설명하는 숫자 값입니다.
- `windowRect`: 현재 보이는 차트 부분을 나타내는 사각형을 표현하는 `{RectType}` 객체입니다. 예를 들어 "0, 0, 1, 1"의 `windowRect`는 데이터 차트 전체를 의미합니다.
- `windowScaleHorizontal`: 데이터 차트가 표시하는 콘텐츠 뷰 사각형의 너비 부분을 설명하는 숫자 값입니다.
- `windowScaleVertical`: 데이터 차트가 표시하는 콘텐츠 뷰 사각형의 높이 부분을 설명하는 숫자 값입니다.
