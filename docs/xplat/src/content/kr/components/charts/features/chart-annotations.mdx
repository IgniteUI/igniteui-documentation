# {Platform} 차트 주석

{Platform} 차트의 호버 상호 작용과 주석은 시리즈 컬렉션에 추가되는 시리즈인 호버 상호 작용 레이어를 통해 구현됩니다. 이 레이어는 커서 위치에 따라 달라집니다. 각 주석 레이어는 서로 다른 호버 상호 작용을 제공하며, 개별적으로 사용하거나 다른 레이어와 결합하여 강력한 호버 상호 작용을 구현할 수 있습니다.

## {Platform} 십자선 레이어

`CrosshairLayer`는 구성된 대상 시리즈 각각의 실제 값에서 교차하는 십자선으로 렌더링되며, 각 시리즈는 별도의 선 세트로 렌더링됩니다.

십자선 유형은 다음과 같습니다:
- 수평
- 수직
- 둘 다

`crosshairsSnapToData` 속성을 true로 설정하면 차트의 십자선이 데이터 포인트에 맞춰지도록 구성할 수 있으며, 그렇지 않으면 십자선이 데이터 포인트 사이에서 보간됩니다. 축을 따라 십자선의 값을 표시하도록 주석을 활성화할 수도 있습니다.

기본적으로 십자선 레이어는 차트 컨트롤의 모든 시리즈를 대상으로 하지만, 특정 시리즈 하나에만 표시되도록 십자선 레이어를 구성할 수 있습니다. 이렇게 하려면 `targetSeries` 속성을 설정하십시오.

기본적으로 십자선 선의 색상은 상호 작용하는 시리즈보다 밝은 색상입니다. 하지만 이 기본 설정을 재정의하여 십자선 선에 사용할 색상을 직접 선택할 수 있습니다. 이는 십자선 레이어의 `CrosshairLayer.brush` 속성을 설정하여 수행합니다.

다음 예제는 단일 시리즈를 대상으로 하고, 유형을 수직으로 설정하며, 브러시 색상을 지정하여 십자선 레이어를 구성하는 방법을 보여 줍니다.

## {Platform} 최종 값 레이어

`DataChart` 컨트롤의 `FinalValueLayer`는 시리즈에 표시되는 마지막 값을 축을 따라 빠르게 보여 줍니다.

서로 다른 구성을 가진 여러 최종 값 레이어를 두려면, 이 주석이 특정 시리즈를 대상으로 하도록 구성할 수 있습니다. 이는 `targetSeries` 속성을 설정하여 수행할 수 있습니다.

다음 속성을 설정하여 이 주석을 사용자 지정할 수도 있습니다:

- `axisAnnotationBackground`: 이 속성은 주석 배경색에 사용할 브러시를 선택하는 데 사용됩니다. 기본값은 시리즈 브러시입니다.
- `axisAnnotationTextColor`: 이 속성은 주석 텍스트 색상에 사용할 브러시를 선택하는 데 사용됩니다.
- `axisAnnotationOutline`: 이 속성은 주석 윤곽선 색상에 사용할 브러시를 선택하는 데 사용됩니다.

다음 예제는 위에 나열된 속성을 설정하여 최종 값 레이어 주석의 스타일을 지정하는 방법을 보여 줍니다.

<Sample src="/charts/data-chart/final-value-layer-styling" height={500} alt="{Platform} 최종 값 레이어 스타일" />




```json-snippet source="/charts/category-chart/annotations-final-value"
{
    "type": "CategoryChart",
    "name": "chart",
    "dataSourceRef": "TemperatureAnnotatedData",
    "finalValueAnnotationsVisible": true,
    "finalValueAnnotationsBackground": "dodgerblue",
    "finalValueAnnotationsTextColor": "white",
    "finalValueAnnotationsPrecision": 0
}
```


## {Platform} 콜아웃 레이어

`CalloutLayer`는 차트 컨트롤에 기존 또는 새 데이터의 주석을 표시합니다. 주석은 데이터 소스의 해당 데이터 값 옆에 나타납니다.

사용자에게 짚어 주고 싶은 메모나 데이터 포인트의 구체적인 세부 정보처럼 추가 정보를 표시하려면 콜아웃 주석을 사용하십시오.

서로 다른 구성을 가진 여러 콜아웃 레이어를 두려면, 콜아웃이 특정 시리즈를 대상으로 하도록 구성할 수 있습니다. 이는 `targetSeries` 속성을 설정하여 수행합니다.

다음 속성을 설정하여 이 주석을 사용자 지정할 수도 있습니다:

- `calloutLeaderBrush`: 이 속성은 레이어 콜아웃의 지시선에 사용할 브러시를 선택하는 데 사용됩니다.
- `calloutOutline`: 이 속성은 주석 윤곽선 색상에 사용할 브러시를 선택하는 데 사용됩니다.
- `calloutBackground`: 이 속성은 주석 배경색에 사용할 브러시를 선택하는 데 사용됩니다. 기본값은 시리즈 브러시입니다.
- `calloutTextColor`: 이 속성은 주석 텍스트 색상에 사용할 브러시를 선택하는 데 사용됩니다.
- `calloutStrokeThickness`: 이 속성은 콜아웃 배경의 두께를 선택하는 데 사용됩니다.
- `calloutCornerRadius`: 이 속성은 콜아웃의 모서리를 둥글게 만드는 데 사용됩니다.
- `allowedPositions`: 이 속성은 콜아웃 레이어가 사용할 수 있는 위치를 선택하는 데 사용됩니다. 예: top, bottom

다음 예제는 위에 나열된 속성을 설정하여 콜아웃 레이어 주석의 스타일을 지정하는 방법을 보여 줍니다:

<Sample src="/charts/data-chart/callout-layer-styling" height={500} alt="{Platform} 콜아웃 레이어 스타일" />




```json-snippet source="/charts/category-chart/annotations-custom" channel="auto"
{
    "type": "CategoryChart",
    "name": "chart",
    "dataSourceRef": "TemperatureAnnotatedData",
    "calloutsVisible": true,
    "calloutsDataSourceRef": "TemperatureAnnotatedData",
    "calloutsXMemberPath": "Index",
    "calloutsYMemberPath": "Temperature",
    "calloutsLabelMemberPath": "TempInfo",
    "calloutsAllowedPositions": [ "Top", "Bottom" ]
}
```
