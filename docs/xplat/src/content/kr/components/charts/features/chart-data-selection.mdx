# {Platform} 차트 선택

{Platform} 데이터 차트의 {ProductName} 선택 기능을 사용하면 사용자가 차트 내 하나 또는 여러 시리즈를 대화형으로 선택, 강조, 윤곽선 표시할 수 있으며, 그 반대로 선택을 해제할 수도 있습니다. 이를 통해 사용자가 제시된 데이터와 상호 작용하는 방식을 더 의미 있게 만드는 다양한 가능성이 생깁니다.

## 선택 구성

기본 동작에서 `selectionMode`는 꺼져 있으며, 다음 옵션 중 하나를 선택해야 합니다. `DataChart`에는 여러 선택 모드가 있습니다:

- **Auto**
- **None**
- **Brighten**
- **FadeOthers**
- **GrayscaleOthers**
- **FocusColorThickOutline**
- **FocusColorOutline**
- **SelectionColorThickOutline**
- **SelectionColorOutline**
- **FocusColorFill**
- **SelectionColorFill**
- **ThickOutline**

`Brighten`는 선택된 항목을 흐리게 표시하고, `FadeOthers`는 반대 효과를 나타냅니다.
`GrayscaleOthers`는 `FadeOthers`와 비슷하게 동작하지만, 나머지 시리즈에 회색을 표시합니다. 이는 모든 `selectionBrush` 설정을 재정의한다는 점에 유의하십시오.
`SelectionColorOutline`와 `SelectionColorThickOutline`는 시리즈 주위에 테두리를 그립니다.

함께 사용할 수 있는 `selectionBehavior`를 통해 어떤 항목을 선택할지 더 세밀하게 제어할 수 있습니다. Auto의 기본 동작은 `PerSeriesAndDataItemMultiSelect`입니다.

- **Auto**
- **PerDataItemMultiSelect**
- **PerDataItemSingleSelect**
- **PerSeriesAndDataItemMultiSelect**
- **PerSeriesAndDataItemSingleSelect**
- **PerSeriesAndDataItemGlobalSingleSelect**
- **PerSeriesMultiSelect**
- **PerSeriesSingleSelect**

## 색상 채우기를 통한 선택 구성

다음 예제는 `SelectionColorFill`와 `SeriesSelectionBehavior.Auto` 선택 동작, 즉 `PerSeriesAndDataItemMultiSelect`의 조합을 보여 줍니다. 색상 채우기는 전체 시리즈 항목의 배경색을 변경하므로 유용한 시각적 단서를 제공합니다. 각 항목을 클릭하면 항목이 녹색에서 보라색으로 바뀌는 것을 볼 수 있습니다.

## 다중 선택 구성

다른 선택 모드는 다양한 선택 방법을 제공합니다. 예를 들어 `PerDataItemMultiSelect`와 함께 `selectionBehavior`를 사용하면 여러 시리즈가 있을 때 카테고리 전체의 모든 시리즈에 영향을 주면서도 카테고리 간 선택은 허용합니다. `PerDataItemSingleSelect`와 비교하면 한 번에 하나의 카테고리 항목만 선택할 수 있습니다. 이는 여러 시리즈가 서로 다른 데이터 소스에 바인딩되어 있고 카테고리 간 선택을 더 세밀하게 제어해야 할 때 유용합니다.
`PerSeriesAndDataItemGlobalSingleSelect`는 한 번에 모든 카테고리에 걸쳐 단일 시리즈 선택을 허용합니다.

## 프로그래밍 방식 선택
차트 선택은 코드로도 구성할 수 있으며, 시작 시 또는 런타임에 차트에서 선택된 항목을 볼 수 있습니다. 이는 `CategoryChart`의 `SelectedSeriesItems`에 항목을 추가하여 달성할 수 있습니다. `ChartSelection` 객체의 `ChartSelection.matcher` 속성을 사용하면 "매처"를 기준으로 시리즈를 선택할 수 있으며, 차트에서 실제 시리즈에 접근할 수 없을 때 이상적입니다. 데이터 소스에 포함된 속성을 알고 있다면, 시리즈가 사용하게 될 `ValueMemberPath`를 사용할 수 있습니다.

매처는 `DataChart`처럼 실제 시리즈에 접근할 수 없는 경우, `CategoryChart` 같은 차트에서 사용하기에 이상적입니다. 이 경우 데이터 소스에 포함된 속성을 알고 있다면 시리즈가 가질 ValueMemberPaths를 추정할 수 있습니다. 예를 들어 데이터 소스에 숫자 속성 Nuclear, Coal, Oil, Solar가 있다면, 이 각 속성에 대해 시리즈가 생성된다는 것을 알 수 있습니다. Solar 값에 바인딩된 시리즈를 강조하려면, 다음 속성을 설정한 매처를 사용하여 `selectedSeriesItems` 컬렉션에 ChartSelection 객체를 추가할 수 있습니다
