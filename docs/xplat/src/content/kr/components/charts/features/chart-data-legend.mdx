# {Platform} 데이터 범례

{ProductName}에서 `DataLegend`는 `Legend`를 매우 사용자 지정할 수 있는 버전으로, 시리즈의 값을 표시하고 시리즈 행과 값 열을 필터링하며 값의 스타일과 서식을 지정하는 많은 구성 속성을 제공합니다. 이 범례는 `CategoryChart`의 플롯 영역 안에서 마우스를 움직이면 업데이트됩니다.<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> 그리고 `DataChart`. 또한 사용자의 마우스 포인터가 플롯 영역을 벗어날 때 마지막으로 호버한 지점을 기억하는 지속 상태를 가지고 있습니다. 이 내용은 세 가지 유형의 행(헤더, 시리즈, 요약)과 네 가지 유형의 열(제목, 레이블, 값, 단위)을 사용하여 표시됩니다.

## {Platform} 데이터 범례 행

`DataLegend`의 행에는 헤더 행, 시리즈 행, 요약 행이 포함됩니다. 헤더 행은 호버된 지점의 축 레이블을 표시하며, `headerText` 속성을 사용하여 변경할 수 있습니다.

<Sample src="/charts/category-chart/data-legend" height={450} alt="{Platform} 카테고리 차트 데이터 범례 예제" />


### 헤더 행

헤더 행은 카테고리 시리즈와 금융 시리즈 위에 마우스를 올릴 때 x축의 현재 레이블을 표시합니다. x축이 날짜를 표시하는 경우 `headerFormatDate` 및 `headerFormatTime` 속성을 사용하여 `DataLegend`의 날짜와 시간 서식을 지정할 수 있습니다. 다른 유형의 시리즈에서는 `DataLegend`가 헤더 행을 렌더링하지 않습니다.

### 시리즈 행

시리즈 행은 차트에 플롯된 각 시리즈를 나타냅니다. 이 행에는 범례 배지, 시리즈 제목, 시리즈의 실제 값 또는 축약된 값, 그리고 지정된 경우 축약 기호 또는 측정 단위가 표시됩니다. `includedSeries` 또는 `excludedSeries` 속성을 시리즈 인덱스(1, 2, 3) 또는 시리즈 제목(Tesla, Microsoft)의 컬렉션으로 설정하여 시리즈 행을 필터링할 수 있습니다.

### 요약 행

마지막으로 모든 시리즈 값의 합계를 표시하는 요약 행이 있습니다. 기본 요약 제목은 범례의 `summaryTitleText` 속성을 사용하여 변경할 수 있습니다. 또한 `summaryType` 속성을 사용하여 요약 행에 시리즈 값의 `Total`, `Min`, `Max`, `Average` 중 무엇을 표시할지 사용자 지정할 수 있습니다.

## {Platform} 데이터 범례 열

`DataLegend`의 열에는 시리즈 제목, 레이블, 데이터 열의 값, 그리고 값과 연결된 선택적 단위가 포함됩니다. 차트의 일부 시리즈는 레이블, 값, 단위에 대해 여러 열을 가질 수 있습니다.

<PlatformBlock for="Angular, React, WebComponents, Blazor">
예를 들어 금융 가격 시리즈에는 **High**, **Low**, **Open**, **Close** 데이터 열이 있으며, 이는 `DataLegend`에서 `includedColumns` 또는 `excludedColumns` 속성을 사용하여 필터링할 수 있습니다.

<Sample src="/charts/financial-chart/data-legend" height={450} alt="{Platform} 금융 차트 데이터 범례 예제" />
</PlatformBlock>




`includedColumns` 및 `excludedColumns` 속성에 값을 설정하는 방법은 시리즈 유형과 각 시리즈가 지원하는 데이터 열의 수에 따라 다릅니다. 예를 들어 `includedColumns` 속성을 **Open** 및 **Close** 문자열의 컬렉션으로 설정하면, 차트가 금융 시리즈를 플롯할 때 범례에 주식 가격의 시가와 종가 값만 표시됩니다. 다음 표는 데이터 범례에서 열을 필터링하는 데 사용할 수 있는 모든 열 이름을 나열합니다.

|  시리즈 유형  | 열 이름 |
| -----------------|-------------- |
| 카테고리 시리즈  | 값 |
| 방사형 시리즈    | 값 |
| 극좌표 시리즈     | Radius, Angle |
| 버블 시리즈    | X, Y, Radius |
| 산점도 시리즈   | X, Y |
| 범위 시리즈     | High, Low |
| 금융 시리즈 | High, Low, Open, Close, Change, TypicalPrice, Volume |

OHLC 가격의 **TypicalPrice**와 백분율 **Change**는 금융 시리즈에서 자동으로 계산되므로 데이터 소스에 포함할 필요가 없습니다.

### 제목 열

제목 열은 범례 배지와 시리즈 제목을 표시하며, 이는 차트에 플롯된 여러 `Series`의 `chartTitle` 속성에서 가져옵니다.

### 레이블 열

레이블 열은 값 열의 왼쪽에 짧은 이름을 표시합니다. 예를 들어 **Open** 주가의 경우 "O"입니다. `labelDisplayMode` 속성을 사용하여 이 열의 표시 여부를 전환할 수 있습니다.

### 값 열

값 열은 시리즈 값을 축약된 텍스트로 표시합니다. 이 속성을 `Shared`로 설정하여 모든 숫자에 같은 축약을 적용하도록 `valueFormatAbbreviation` 속성을 사용해 서식을 지정할 수 있습니다. 또는 `Independent`, `Kilo`, `Million` 등 다른 축약을 선택할 수도 있습니다. 축약된 값의 정밀도는 각각 최소 및 최대 자릿수를 위한 `valueFormatMinFractions`와 `valueFormatMaxFractions`로 제어합니다.


### 단위 열

단위 열은 값 열의 오른쪽에 축약 기호를 표시합니다. 단위 기호는 `valueFormatAbbreviation` 속성에 따라 달라집니다. 예를 들어 `Million` 축약의 경우 "M"입니다.

### 열 사용자 지정

각 시리즈에서 **MemberAsLegendLabel** 및 **MemberAsLegendUnit**으로 끝나는 속성을 사용하여 **레이블** 및 **단위** 열에 표시되는 텍스트를 사용자 지정할 수 있습니다. 다음 표는 **레이블** 및 **단위** 열의 가능한 사용자 지정 예를 보여 줍니다.

|  시리즈 유형 | 시리즈 속성 |
| ------|---- |
| 카테고리 시리즈 | ValueMemberAsLegendLabel="$" <br /> ValueMemberAsLegendUnit="M" |
| 방사형 시리즈 | ValueMemberAsLegendLabel="Distance:" <br /> ValueMemberAsLegendUnit="KM" |
| 극좌표 시리즈 | RadiusMemberAsLegendLabel="Radius:" <br /> RadiusMemberAsLegendUnit="KM" <br /> AngleMemberAsLegendLabel="Angle:" <br /> AngleMemberAsLegendUnit="°" |
| 범위 시리즈 | HighMemberAsLegendLabel="H:" <br /> HighMemberAsLegendUnit="K" <br /> LowMemberAsLegendLabel="L:" <br /> LowMemberAsLegendUnit="K" |
| 금융 시리즈 | OpenMemberAsLegendLabel="O:" <br /> OpenMemberAsLegendUnit="K" <br /> HighMemberAsLegendLabel="H:" <br /> HighMemberAsLegendUnit="K" <br /> LowMemberAsLegendLabel="L:" <br /> LowMemberAsLegendUnit="K" <br /> CloseMemberAsLegendLabel="C:" <br /> CloseMemberAsLegendUnit="K" <br /> |

또한 `DataLegend`의 `UnitsText` 속성을 사용하여 모든 단위 열에 표시되는 텍스트를 변경할 수 있습니다.

## {Platform} 데이터 범례 스타일 지정 및 이벤트

범례의 그룹화 부분을 포함하여 여러 속성이 노출되어 있습니다.

- `GroupRowMarginLeft/GroupRowMarginTop/GroupRowMarginRight/GroupRowMarginBottom`
- `GroupTextMarginLeft/GroupTextMarginTop/GroupTextMarginRight/GroupTextMarginBottom`
- `groupTextColor`
- `GroupTextFontSize/GroupTextFontFamily/GroupTextFontStyle/GroupTextFontWeight`
- `HeaderTextMarginLeft/HeaderTextMarginTop/HeaderTextMarginRight/HeaderTextMarginBottom`
- `headerTextColor`
- `HeaderTextFontSize/HeaderTextFontFamily/HeaderTextFontStyle/HeaderTextFontWeight`

`DataLegend`에는 해당 행을 렌더링할 때 발생하는 여러 이벤트가 있으며, 값이 업데이트되는 마우스 상호 작용 중에도 발생합니다. 이러한 이벤트는 용도에 대한 설명과 함께 아래에 나열됩니다:

- `styleGroupRow`: 이 이벤트는 그룹 행에 표시되는 텍스트의 스타일을 지정하기 위해 각 그룹마다 발생합니다.
- `styleHeaderRow`: 이 이벤트는 헤더 행을 렌더링할 때 발생합니다.
- `styleSeriesRow`: 이 이벤트는 각 시리즈 행마다 한 번씩 발생하며, 이를 통해 시리즈 값의 조건부 스타일 지정이 가능합니다.
- `styleSeriesColumn`: 이 이벤트는 각 시리즈 열마다 한 번씩 발생하며, 이를 통해 차트 내 시리즈의 여러 열에 대한 조건부 스타일 지정이 가능합니다.
- `styleSummaryRow`: 이 이벤트는 요약 행을 렌더링할 때 한 번 발생합니다.
- `styleSummaryColumn`: 이 이벤트는 요약 열을 렌더링할 때 한 번 발생합니다.

일부 이벤트는 인수로 `DataLegendStylingRowEventArgs` 매개변수를 노출하며, 이를 통해 각 항목의 텍스트, 텍스트 색상, 행 전체의 가시성을 사용자 지정할 수 있습니다. 이벤트 인수는 이벤트별 속성도 노출합니다. 예를 들어 `StyleSeriesRow` 이벤트는 각 시리즈마다 발생하므로, 이벤트 인수는 시리즈를 나타내는 행의 시리즈 인덱스와 시리즈 제목을 반환합니다.

`StyleSummaryColumn` 및 `StyleSeriesColumn` 이벤트는 시리즈의 각 필드를 사용자 지정하기 위해 인수로 `DataLegendStylingColumnEventArgs` 매개변수를 노출합니다. 이벤트 인수는 열 인덱스 및 열과 관련된 값 멤버 속성 등 이벤트별 속성도 노출합니다.
