# {Platform} 차트 추세선

{ProductName} 차트에서 추세선은 추세를 파악하거나 데이터의 패턴을 찾는 데 도움을 줍니다. 추세선은 항상 차트에 바인딩된 데이터 지점 앞에 렌더링되며 `CategoryChart`에서 지원됩니다<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> 및 `DataChart`(누적 시리즈, 도형 시리즈, 범위 시리즈 제외).

추세선은 기본적으로 꺼져 있지만 `trendLineType` 속성을 설정하여 활성화할 수 있습니다. 또한 브러시, 기간, 두께 등 추세선의 여러 모양 속성을 수정할 수 있습니다.

추세선은 활성화된 후 대시 배열을 적용할 수도 있습니다. 이는 `trendLineDashArray` 속성을 숫자 배열로 설정하여 수행합니다. 숫자 배열은 추세선 대시의 길이를 설명합니다.

## {Platform} 차트 추세선 레이어

`TrendLineLayer`는 대상 시리즈에 대해 단일 추세선 유형을 표시하도록 설계된 시리즈 유형입니다. 기존 시리즈 유형의 추세선 기능과의 차이점은 `TrendLineLayer`가 시리즈 유형이므로 차트의 `Series` 컬렉션에 여러 개를 추가하여 같은 시리즈에 여러 추세선을 연결할 수 있다는 것입니다. 또한 추세선을 범례에 표시할 수 있는데, 이는 이전에는 불가능했습니다.

## 추세선 레이어 사용

`TrendLineLayer`가 제대로 작동하려면 `targetSeries`와 `trendLineType`를 제공해야 합니다. 사용 가능한 추세선 유형은 시리즈에서 사용할 수 있는 추세선과 같습니다.

`TrendLineLayer`를 범례에 표시하려면 `useLegend` 속성을 `true`로 설정하면 됩니다.

## 추세선 레이어 스타일 지정

기본적으로 `TrendLineLayer`는 `targetSeries`와 같은 색상으로 점선을 렌더링합니다. 이는 `TrendLineLayer`의 다양한 스타일 지정 속성을 사용하여 구성할 수 있습니다.

그려지는 추세선의 색상을 변경하려면 `TrendLineLayer.brush` 속성을 설정할 수 있습니다. 또는 `useIndex` 속성을 `true`로 설정할 수도 있으며, 이 경우 `TrendLineLayer`가 차트의 `Series` 컬렉션에 놓인 인덱스를 기준으로 차트의 `DomainChart.brushes` 팔레트에서 색상을 가져옵니다.

`TrendLineLayer`의 표시 방식은 `appearanceMode` 및 `shiftAmount` 속성으로도 수정할 수 있습니다. `shiftAmount` 속성은 -1.0에서 1.0 사이의 값을 사용하여, "Shift"로 끝나는 옵션에 "이동"을 얼마나 적용할지 결정합니다.

`appearanceMode` 속성의 옵션은 다음과 같습니다:

- `Auto`: 기본적으로 DashPattern 열거형이 사용됩니다.
- `BrightnessShift`: 추세선은 `targetSeries` 브러시를 사용하고, 제공된 `shiftAmount`에 따라 밝기를 수정합니다.
- `DashPattern`: 추세선은 점선으로 나타납니다. 점선의 빈도는 `TrendLineLayer`의 `dashArray` 속성을 사용하여 수정할 수 있습니다.
- `OpacityShift`: 추세선은 `targetSeries` 브러시를 사용하고, 제공된 `shiftAmount`에 따라 불투명도를 수정합니다.
- `SaturationShift`: 추세선은 `targetSeries` 브러시를 사용하고, 제공된 `shiftAmount`에 따라 채도를 수정합니다.
