# {Platform} 차트 툴팁

{Platform} 차트에서 툴팁은 바인딩된 데이터에 대한 세부 정보를 제공하며, 최종 사용자가 데이터 지점 위에 마우스를 올리면 팝업으로 렌더링됩니다. 툴팁은 `CategoryChart`에서 지원됩니다<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> 및 `DataChart` 컨트롤.

## {Platform} 차트 툴팁 유형

{Platform} 차트는 `DomainChart.toolTipType` 속성을 설정하여 툴팁을 활성화하면 사용할 수 있는 세 가지 유형의 툴팁을 제공합니다. 다음 예제는 툴팁 유형을 변경하는 데 사용할 수 있는 콤보 상자가 있는 [열 차트](../types/column-chart.mdx)를 보여 줍니다.

<Sample src="/charts/category-chart/column-chart-with-tooltips" height={500} alt="{Platform} 툴팁 유형 예제" />




`DomainChart.toolTipType` 속성은 구성 가능하며 다음 옵션 중 하나로 설정할 수 있습니다:

| 속성 값     | 설명  |
| -------------------|----------------|
| `Default` 툴팁 | 포인터가 단일 항목 위에 있을 때 해당 항목의 툴팁을 표시합니다.  |
| `Data` 툴팁 | 차트의 모든 시리즈에 대한 데이터 툴팁을 표시합니다.  |
| `Item` 툴팁    | 포인터가 위치한 카테고리의 각 데이터 항목에 대한 툴팁을 표시합니다.  |
| `Category` 툴팁 | 포인터가 위치한 카테고리의 모든 데이터 지점에 대한 그룹화된 툴팁을 표시합니다.  |


## {Platform} 차트 툴팁 템플릿

내장된 툴팁 유형 중 요구 사항에 맞는 것이 없다면, 직접 툴팁을 만들어 시리즈 제목, 데이터 값, 축 값을 표시하고 스타일을 지정할 수 있습니다. 다음 섹션에서는 여러 유형의 {Platform} 차트에서 이를 수행하는 방법을 보여 줍니다.
