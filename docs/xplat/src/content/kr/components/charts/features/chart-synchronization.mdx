# {Platform} 차트 동기화

{ProductName} 데이터 차트는 여러 차트 간에 확대/축소, 이동, 십자선 이벤트의 조정과 관련하여 동기화를 지원합니다. 데이터 소스가 축과 관련하여 비슷하거나 같다고 가정하면, 여러 차트의 같은 영역을 함께 시각화하는 데 도움이 될 수 있습니다.

## 차트 동기화 속성

차트 동기화에는 네 가지 옵션이 있습니다. 가로로만 동기화하거나, 세로로만 동기화하거나, 둘 다 동기화하거나, 기본값인 동기화하지 않음을 선택할 수 있습니다.

차트 세트를 동기화하려면 `syncChannel` 속성에 같은 이름을 할당한 다음, `synchronizeHorizontally` 및 `synchronizeVertically` 속성을 해당 불리언 값으로 설정하여 차트를 가로 및/또는 세로로 동기화할지 지정하십시오.

세로 및/또는 가로로 동기화하려면 각각 `isHorizontalZoomEnabled` 및/또는 `isVerticalZoomEnabled` 속성을 **true**로 설정해야 합니다. 다른 차트에 의존하는 동기화된 차트는 이 속성 설정과 관계없이 여전히 확대/축소됩니다.
