# {Platform} 축 눈금선

모든 {ProductName} 차트에는 X축과 Y축에 렌더링되는 축 선의 모양과 주 눈금선 및 보조 눈금선, 눈금 표시의 빈도를 수정할 수 있는 기능이 내장되어 있습니다.

<DocsAside type="info">
아래 예제는 `CategoryChart`에도 적용할 수 있습니다<PlatformBlock for="Web"> 및 `FinancialChart`</PlatformBlock> 컨트롤에도 적용할 수 있습니다.
</DocsAside>

축 주 눈금선은 축 레이블의 위치에서 Y축을 따라 수평으로, 또는 X축을 따라 수직으로 뻗는 긴 선이며, 차트의 플롯 영역을 가로질러 렌더링됩니다. 축 보조 눈금선은 축 주 눈금선 사이에 렌더링되는 선입니다.

축 눈금 표시는 {Platform} 차트의 모든 주 선 위치에서 각 레이블마다 모든 수평 및 수직 축을 따라 표시됩니다.

## {Platform} 축 눈금선 속성

축 간격 속성을 설정하면 축에 주 눈금선과 축 레이블이 얼마나 자주 렌더링될지 지정됩니다. 마찬가지로 축 보조 간격 속성은 축에 보조 눈금선이 얼마나 자주 렌더링될지 지정합니다.

보조 간격에 해당하는 보조 눈금선을 표시하려면 축에서 `xAxisMinorStroke` 및 `xAxisMinorStrokeThickness` 속성을 설정해야 합니다. 보조 눈금선은 기본 색상이나 두께가 없으므로, 먼저 값을 지정하지 않으면 표시되지 않습니다.

다음 속성을 설정하여 {Platform} 차트에 눈금선이 표시되는 방식을 사용자 지정할 수 있습니다:

| 축 시각 요소           | 타입    | 속성 이름                                               | 설명 |
| -----------------------|---------|--------------------------------------------------------------|---------------- |
| 주 획 색상     | string  | `xAxisMajorStroke` <br /> `yAxisMajorStroke`                   | 이 속성은 축 주 눈금선의 색상을 설정합니다. |
| 보조 획 색상     | string  | `xAxisMinorStroke` <br /> `yAxisMinorStroke`                   | 이 속성은 축 보조 눈금선의 색상을 설정합니다. |
| 주 획 두께 | 숫자  | `xAxisMajorStrokeThickness` <br /> `yAxisMajorStrokeThickness` | 이 속성은 축 주 눈금선의 두께를 픽셀 단위로 설정합니다. |
| 보조 획 두께 | 숫자  | `xAxisMinorStrokeThickness` <br /> `yAxisMinorStrokeThickness` | 이 속성은 축 보조 눈금선의 두께를 픽셀 단위로 설정합니다. |
| 주 간격         | 숫자  | `xAxisInterval` <br /> `yAxisInterval`                         | 이 속성은 축 주 눈금선과 레이블 사이의 간격을 설정합니다. |
| 보조 간격         | 숫자  | `xAxisMinorInterval` <br /> `yAxisMinorInterval`               | 이 속성은 사용하는 경우 축 보조 눈금선 사이의 간격을 설정합니다. |
| 축 선 획 색상 | string  | `xAxisStroke` <br /> `yAxisStroke`                   | 이 속성은 축 선의 색상을 설정합니다. |
| 축 획 두께  | 숫자  | `xAxisStrokeThickness` <br /> `yAxisStrokeThickness` | 이 속성은 축 선의 두께를 픽셀 단위로 설정합니다. |

위 표의 주 간격과 보조 간격에 대해 참고할 점은, 주 간격 값은 축 레이블의 간격도 함께 설정하여 간격과 연결된 축 지점에 레이블을 하나씩 표시한다는 것입니다. 보조 간격 눈금선은 항상 주 눈금선 사이에 렌더링되므로, 보조 간격 속성은 항상 주 간격 속성 값보다 훨씬 작게(보통 2~5배 작게) 설정해야 합니다.

카테고리 축에서 간격은 첫 번째 항목과 마지막 카테고리 항목 사이의 인덱스로 표현됩니다. 일반적으로 모든 축 레이블이 축에 맞고 다른 축 레이블에 잘리지 않도록, 주 간격 값은 카테고리 항목 전체 개수의 10~20%와 같아야 합니다. 보조 간격은 주 간격 속성의 분수로 표현됩니다. 이 값은 일반적으로 0.25에서 0.5 사이여야 합니다.

숫자 축에서 간격 값은 축 최솟값과 축 최댓값 사이의 double 값으로 표현됩니다. 기본적으로 숫자 축은 축의 최솟값과 최댓값을 기준으로 적절하고 깔끔한 간격을 자동으로 계산하여 찾습니다.

날짜-시간 축에서 이 값은 축 최솟값과 축 최댓값 사이의 시간 범위로 표현됩니다.

## {Platform} 축 눈금 표시 예제

`xAxisTickLength`와 `yAxisTickLength` 속성을 0보다 큰 값으로 설정하면 축 눈금 표시가 활성화됩니다. 이 속성은 눈금 표시를 형성하는 선분의 길이를 지정합니다.

눈금 표시는 항상 축 선에서 뻗어 나와 레이블 방향을 가리킵니다. 레이블이 겹치지 않도록 레이블은 눈금 표시 길이 값만큼 오프셋됩니다. 예를 들어 `yAxisTickLength` 속성을 5로 설정하면 축 레이블이 그 양만큼 왼쪽으로 이동합니다.

## {Platform} 축 눈금 표시 속성

다음 속성을 설정하여 {Platform} 차트에서 축 눈금 표시가 표시되는 방식을 사용자 지정할 수 있습니다:

| 축 시각 요소           | 타입    | 속성 이름                                             | 설명 |
| -----------------------|---------|------------------------------------------------------------|------------------------- |
| 눈금 획 색상      | string  | `xAxisTickStroke` <br /> `yAxisTickStroke`                   | 이 속성은 눈금 표시의 색상을 설정합니다. |
| 눈금 획 두께  | 숫자  | `xAxisTickStrokeThickness` <br /> `yAxisTickStrokeThickness` | 이 속성은 축 눈금 표시의 두께를 설정합니다. |
| 눈금 획 길이     | 숫자  | `xAxisTickLength` <br /> `yAxisTickLength`                   | 이 속성은 축 눈금 표시의 길이를 설정합니다. |
