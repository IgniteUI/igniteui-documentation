# {Platform} 차트 애니메이션

애니메이션을 사용하면 새 데이터 소스를 로드할 때 시리즈가 부드럽게 나타나도록 할 수 있습니다. 사용 가능한 애니메이션은 관련된 시리즈의 유형에 따라 다릅니다. 예를 들어 열 시리즈는 x축에서 올라오며 애니메이션되고, 선 시리즈는 y축 원점에서 그려지며 애니메이션됩니다.

{ProductName} 차트에서는 애니메이션이 비활성화되어 있지만, `isTransitionInEnabled` 속성을 true로 설정하여 활성화할 수 있습니다. 이후 `transitionInDuration` 속성으로 애니메이션이 완료되는 데 걸리는 시간을 설정하고, `transitionInMode`로 진행되는 애니메이션 유형을 결정할 수 있습니다.

## {Platform} 차트 애니메이션 예제

다음 예제는 기본 `transitionInMode`가 "Auto"로 설정된 애니메이션이 적용된 [선 차트](../types/line-chart.mdx)를 보여 줍니다. 이 예제 상단의 드롭다운과 슬라이더를 사용하면 각각 `transitionInMode`와 `transitionInDuration`를 수정할 수 있으므로, 다양한 속도에서 지원되는 애니메이션이 어떻게 보이는지 확인할 수 있습니다.
