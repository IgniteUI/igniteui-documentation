# {Platform} 차트 및 그래프 개요

{ProductName} 차트 및 그래프는 웹, 모바일, 데스크톱 앱을 위한 눈에 띄는 대화형 차트와 대시보드를 구현할 수 있는 광범위한 데이터 시각화 라이브러리입니다. 속도와 아름다움을 위해 만들어졌고, 모든 최신 플랫폼에서 작동하도록 설계되었으며, 완전한 터치와 상호 작용을 지원하므로 어떤 기기에서든 다음 앱에 반응형 시각 요소를 빠르고 쉽게 구축할 수 있습니다.

{ProductName} 차트는 카테고리 시리즈, 금융 시리즈, 극좌표 시리즈, 방사형 시리즈, 범위 시리즈, 산점도 시리즈, 도형 시리즈, 지리 공간 시리즈를 포함하여 65개가 넘는 시리즈 유형과 조합을 지원하므로 모든 유형의 데이터를 시각화할 수 있습니다. 어떤 종류의 비교를 하든, 또는 어떤 데이터 이야기를 전하려 하든 다음 방식 중 하나로 데이터를 표현할 수 있습니다:

- 시간에 따른 변화
- 비교
- 상관관계
- 분포
- 지리 공간
- 개요 + 세부 정보
- 부분 대 전체
- 순위

Infragistics {Platform} 차팅으로 가장 까다로운 시각화를 구현하십시오!

## {Platform} 차트 및 그래프 유형

{Platform} 제품은 단일 차트 표시부터 대화형 대시보드까지 모든 시나리오에 적합한 65개가 넘는 다양한 차트 및 그래프 유형을 제공합니다. 웹, 모바일, 데스크톱 앱을 위해 파이, 막대, 영역, 선, 점, 누적, 도넛, 산점도, 게이지, 극좌표, 트리맵, 주식, 금융, 지리 공간 맵 등 {Platform} 차트를 만들 수 있습니다. 다른 제품과 비교했을 때 {Platform} 차트의 장점은 다음과 같은 기능을 완벽하게 지원한다는 점입니다:

- 반응형 웹 디자인 내장
- 마우스, 키보드, 터치를 이용한 대화형 이동 및 확대/축소
- 차트 애니메이션의 완전한 제어
- 차트 드릴다운 이벤트
- 실시간 스트리밍 지원
- 대용량(수백만 개의 데이터 포인트) 지원
- 추세선 및 기타 데이터 분석 기능
축, 마커, 시리즈, 범례, 주석 레이어의 모듈식 설계로 구성된 {Platform} 차트를 사용하면 모든 유형의 데이터 이야기를 쉽게 설계하고 렌더링할 수 있습니다. 단일 데이터 시리즈로 간단한 차트를 만들거나, 여러 데이터 시리즈와 복합 뷰의 여러 축으로 더 복잡한 데이터 이야기를 구성할 수 있습니다.

## 카테고리<PlatformBlock for="Web"> 및 금융</PlatformBlock> 차트와 데이터 차트 비교

{Platform} 카테고리<PlatformBlock for="Web"> 및 금융</PlatformBlock> 차트는 도메인 전용 차트라고 부릅니다. 이는 {Platform} 데이터 차트를 감싸는 래퍼로, 도메인이 카테고리<PlatformBlock for="Web">, 또는 금융 가격 시리즈라고 가정합니다</PlatformBlock>.

이러한 특정 도메인 차트를 선택하면 API를 간소화하고, 데이터에 대한 많은 인터페이스를 그려 차트 시나리오를 자동으로 구성할 수 있습니다. 축, 시리즈, 주석 같은 속성을 명시적으로 정의하지 않아도 됩니다. 반면 데이터 차트는 매우 명시적이어서 차트의 모든 중요한 부분을 정의해야 합니다.

도메인 차트는 핵심적으로 데이터 차트를 사용하므로 두 차트 모두 같은 성능 최적화가 적용됩니다. 차이점은 개발자가 지정하기 쉽게 만드는 데 중점을 둘지, 아니면 최대한 유연하게 만드는 데 중점을 둘지에 있습니다. {Platform} 데이터 차트는 더 장황하지만 필요한 모든 차트 기능을 활용할 수 있으며, 예를 들어 여러 시리즈, 축, 주석을 자유롭게 조합할 수 있습니다. 카테고리<PlatformBlock for="Web"> 및 금융</PlatformBlock> 차트의 경우, 숫자 x축을 가진 산점도 시리즈와 함께 시리즈를 구성하는 등 쉽게 수행할 수 없는 상황이 있을 수 있으며, 이때는 데이터 차트가 더 적합합니다.

처음에는 어떤 차트를 선택해야 할지 알기 어려울 수 있습니다. 시리즈의 유형과 추가로 표시하려는 기능이 몇 개인지 이해하는 것이 중요합니다. 더 가볍고 기본적인 카테고리<PlatformBlock for="Web"> 또는 금융</PlatformBlock> 시리즈에는 도메인 차트 중 하나를 사용하는 것을 권장합니다. 더 고급 시나리오, 예를 들어 `CategoryChart.chartType`가 다루는 것 외의 내용(누적 시리즈나 산점도 시리즈, 또는 숫자 또는 시간 기반 데이터 표시)에는 {Platform} 데이터 차트를 사용하는 것을 권장합니다.<PlatformBlock for="Web"> {Platform} 금융 차트는 열, OHLC 막대, 캔들스틱, 선 시리즈 유형만 다룬다는 점에 유의하십시오.</PlatformBlock>

{Platform} 카테고리<PlatformBlock for="Web"> 및 금융</PlatformBlock> 차트를 더 쉽게 사용할 수 있도록 개선했습니다. 좋은 소식은 앞으로 언제든지 데이터 차트로 전환할 수 있다는 것입니다.

### {Platform} 막대 차트

{Platform} 막대 차트(또는 막대 그래프)는 가장 일반적인 카테고리 차트 유형 중 하나로, 서로 다른 카테고리의 데이터 빈도, 개수, 합계 또는 평균을 빠르게 비교하는 데 사용됩니다. 너비가 같고 길이가 다른 수평 막대로 데이터가 인코딩됩니다. 시간에 따른 항목 값의 변화, 데이터 분포, 정렬된 데이터 순위(높은 순에서 낮은 순, 최악에서 최선) 표시에 이상적입니다. 데이터는 차트의 왼쪽에서 오른쪽으로, 데이터 포인트의 값을 향해 뻗는 직사각형 모음으로 표현됩니다. ### {Platform} 파이 차트

{Platform} 파이 차트(또는 파이 그래프)는 부분과 전체의 관계를 나타내는 매우 일반적인 차트 유형입니다. 부분-전체 차트는 데이터 세트의 카테고리(부분)가 합쳐져 총합(전체) 값을 이루는 방식을 보여 줍니다. 카테고리는 분석 중인 총 값에 대한 값 백분율에 따라 다른 카테고리와 비례하여 표시됩니다. 파이 차트는 데이터 값을 원형 또는 파이 모양 그래프의 조각으로 렌더링합니다. 각 조각(파이 슬라이스)의 호 길이는 기본 데이터 값에 비례합니다. 파이 슬라이스가 나타내는 총 값은 100 또는 100%와 같은 전체 값을 나타냅니다. 파이 차트는 소규모 데이터 세트에 적합하며 한눈에 읽기 쉽습니다. [파이 차트](types/pie-chart.mdx)에 대해 자세히 알아보십시오.

### {Platform} 선 차트

{Platform} 선 차트(또는 선 그래프)는 일정 기간 동안 하나 이상의 수량에 대한 연속 데이터 값을 직선 세그먼트로 연결된 점으로 나타내는 카테고리 선 그래프의 한 유형으로, 추세를 보여 주고 비교 분석을 수행하는 데 사용됩니다. Y축(왼쪽 레이블)은 숫자 값을 보여 주고, X축(하단 레이블)은 시계열 또는 비교 카테고리를 보여 줍니다. 비교할 데이터 세트를 하나 이상 포함할 수 있으며, 이 경우 차트에 여러 선으로 렌더링됩니다. [선 차트](types/line-chart.mdx)에 대해 자세히 알아보십시오.

### {Platform} 도넛 차트

{Platform} 도넛 차트(또는 도넛 그래프)는 파이 차트의 한 변형으로, 원 안에서 변수의 발생 비율을 비례하여 나타내 전체의 부분을 표현합니다. 도넛 차트는 파이 차트 중앙에 원형 구멍이 있으며, 이곳에 제목이나 카테고리 설명을 표시할 수 있습니다. 도넛 차트는 여러 개의 동심원 고리를 지원하며, 계층형 데이터를 시각화하는 기능이 내장되어 있습니다. [도넛 차트](types/donut-chart.mdx)에 대해 자세히 알아보십시오.

### {Platform} 영역 차트

{Platform} 영역 차트는 점들을 직선 세그먼트로 연결하고 선 아래 영역을 채워서 렌더링합니다. 값은 y축(왼쪽 레이블)에 표시되고 카테고리는 x축(하단 레이블)에 표시됩니다. 영역 차트는 일정 기간 동안의 변화량이나 여러 항목의 비교를 강조하며, 플롯된 값의 합계를 표시하여 부분과 전체의 관계도 보여 줍니다. [영역 차트](types/area-chart.mdx)에 대해 자세히 알아보십시오.

### {Platform} 버블 차트

### {Platform} 금융 / 주식 차트

{Platform} 금융 또는 주식 차트는 주식 데이터와 금융 데이터를 시계열 차트로 렌더링하는 복합 시각화로, 일/주/월 필터, 차트 유형 선택, 거래량 유형 선택, 지표 선택, 추세선 선택 같은 도구 모음의 대화형 시각 요소를 포함합니다. 사용자 지정을 위해 설계된 {Platform} 주식 차트는 데이터를 더 쉽게 시각화하고 해석할 수 있도록 어떤 방식으로든 사용자 지정할 수 있습니다. 금융 차트는 날짜-시간 데이터를 X축(하단 레이블)을 따라 렌더링하며, 시가, 고가, 저가, 종가, 거래량 같은 필드를 보여 줍니다. 시계열 데이터를 렌더링하는 차트 유형은 막대, 캔들, 열 또는 선이 될 수 있습니다.
