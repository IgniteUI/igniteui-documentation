# {Platform} 지도 개요

{ProductName} 지도 컴포넌트를 사용하면 뷰 모델의 지리적 위치나 지리 이미지 지도 위에 셰이프 파일에서 불러온 지리 공간 데이터가 포함된 데이터를 표시할 수 있습니다.

## {Platform} 지도 예제

다음 샘플은 버블 시리즈라고도 하는 `GeographicProportionalSymbolSeries`를 사용하여 `GeographicMap`에서 데이터를 표시하는 방법을 보여 줍니다.

지도 컴포넌트를 사용하면 Bing Maps™와 Open Street Maps의 지리 이미지를 렌더링할 수 있습니다.

</PlatformBlock>

<PlatformBlock for="WinUI, Uno">

지도 컴포넌트를 사용하면 Open Street Maps의 지리 이미지를 렌더링할 수 있습니다.

</PlatformBlock>

지도는 수만 개의 데이터 포인트를 플롯하고 몇 밀리초마다 업데이트할 수 있으므로, 컨트롤이 실시간 피드를 처리할 수 있습니다.

지도의 Series 속성은 무제한 개수의 지리 시리즈를 렌더링하는 것을 지원하는 데 사용됩니다. 이 속성은 지리 시리즈 객체의 컬렉션이며, 어떤 유형의 지리 시리즈든 추가할 수 있습니다. 예를 들어 도시 같은 지리적 위치를 플롯하기 위해 `GeographicSymbolSeries`을, 이 지리적 위치들 사이의 연결(예: 도로)을 플롯하기 위해 `GeographicPolylineSeries`를 추가할 수 있습니다.

지도는 마우스, 키보드 또는 코드 비하인드를 사용하여 지도 콘텐츠를 탐색할 수 있는 사용자 지정 가능한 탐색 동작을 제공합니다.

## 컴포넌트 모듈

<PlatformBlock for="Angular, React, WebComponents">

`GeographicMap`에는 다음 모듈이 필요합니다. 다만 DataChartInteractivityModule은 지도 콘텐츠의 패닝과 줌 같은 마우스 상호 작용에만 필요합니다.

</PlatformBlock>

<PlatformBlock for="Blazor">

패닝과 줌 같은 지도의 마우스 상호 작용은 <ApiLink raw type="DataChartInteractivityModule" />에서 오며, 이는 어떤 컴포넌트도 단독으로 요청하지 않으므로 등록해야 합니다. <ApiLink raw type="GeographicMapModule" />는 선택 사항입니다. `GeographicMap`가 처음 렌더링될 때 이를 로드하기 때문입니다([컴포넌트 모듈](general-getting-started.mdx#컴포넌트-모듈) 참조).

</PlatformBlock>

```json-snippet source="/maps/geo-map/type-scatter-bubble-series" channel="modulesImports...moduleRegistration" exclude="Xaml"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "map"
        }
    },
    "modules": [
        "maps/GeographicMapModule",
        "charts/DataChartInteractivityModule"
    ],
    "$modules": [
        "+doc:modulesImports",
        "+doc:moduleRegistration"
    ]
}
```

</PlatformBlock>


## 사용법

다음 예제와 같이 지리 지도를 구성하고 확대/축소를 활성화하십시오.

```json-snippet
{
    "type": "GeographicMap",
    "height": "100%",
    "width": "100%",
    "zoomable": true
}
```
