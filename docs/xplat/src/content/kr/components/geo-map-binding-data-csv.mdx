# 지리적 위치가 있는 {Platform} CSV 파일 바인딩

## 코드 조각
다음 코드는 지리적 위치가 있는 불러온 CSV 파일에서 만든 객체 배열에 `GeographicHighDensityScatterSeries`를 로드하고 지도 컴포넌트에 바인딩합니다.


```json-snippet id="csvMap" source="/maps/geo-map/binding-data-csv"
{
    "descriptions": {
        "content": { "type": "GeographicMap", "name": "geoMap", "height": "100%", "width": "100%", "zoomable": true }
    },
    "onViewInit": [ "MapBindingDataCsvOnViewInit" ]
}
```

```json-snippet ref="csvMap" channel="eventHandlers"
```


## API 참조
`GeographicHighDensityScatterSeries`
