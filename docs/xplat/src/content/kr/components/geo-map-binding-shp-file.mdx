# {Platform} 지리 공간 데이터가 있는 셰이프 파일 바인딩

{ProductName} 지도 컴포넌트에서 `ShapeDataSource` 클래스는 셰이프 파일에서 지리 공간 데이터(점/위치, 폴리라인, 다각형)를 불러와 `ShapefileRecord` 객체의 컬렉션으로 변환합니다.

다음 표는 셰이프 파일을 불러오기 위한 `ShapeDataSource` 클래스의 속성을 설명합니다.


| 속성 | 타입 | 설명   |
|----------|------|---------------|
| `ShapefileSource` | string |지리 공간 데이터 항목을 포함하는 셰이프 파일(.shp)의 Uri를 지정합니다.|
|`DatabaseSource` | string |지리 공간 데이터 항목의 데이터 테이블을 포함하는 셰이프 데이터베이스 파일(.dbf)의 Uri를 지정합니다.|

두 소스 속성이 모두 null이 아닌 값으로 설정되면 `ShapeDataSource` 객체의 ImportAsync 메서드가 호출되며, 이 메서드는 셰이프 파일을 가져와 읽고, 마지막으로 변환을 수행합니다. 이 작업이 완료되면 `ShapeDataSource`가 `ShapefileRecord` 객체로 채워지고 `ImportCompleted` 이벤트가 발생하여 셰이프 파일에서 지리 공간 데이터를 불러오고 변환하는 과정이 끝났음을 알립니다.

## 셰이프 파일 불러오기
다음 코드는 세계 해저 케이블 경로를 포함하는 셰이프 파일을 불러오기 위한 `ShapeDataSource` 객체의 인스턴스를 만듭니다. 또한 지도 컴포넌트에 데이터를 바인딩하기 위한 전제 조건으로 `ImportCompleted` 이벤트를 처리하는 방법도 보여 줍니다.

```json-snippet source="/maps/geo-map/binding-shp-file" channel="handlersImports,bindingFields...supportingTypes...handler" item="MapBindingShpFileLoad"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "map",
            "height": "100%",
            "width": "100%",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapBindingShpFileLoad"
    ]
}
```

## 셰이프 파일 바인딩
지도 컴포넌트에서 지리 시리즈는 셰이프 파일에서 불러온 지리 공간 데이터를 표시하는 데 사용됩니다. 모든 유형의 지리 시리즈에는 객체의 배열에 바인딩할 수 있는 `dataSource` 속성이 있습니다. `ShapeDataSource`가 만들어 내는 것은 그러한 배열의 예입니다. 각 항목이 `ShapefileRecord`이기 때문입니다.

`ShapefileRecord` 클래스는 지리 공간 데이터를 저장하는 속성을 제공하며, 다음 표에 나열되어 있습니다.

| 속성     | 설명   |
|--------------|---------------|<PlatformBlock for="Angular, React, WebComponents, WinUI, Uno">
|<PlatformBlock for="Angular, React, WebComponents"><ApiLink raw type="ShapefileRecord" prefixed={true} suffix={false} member="points" /></PlatformBlock><PlatformBlock for="WinUI, Uno"><ApiLink raw type="ShapefileRecord" prefixed={false} suffix={false} member="Points" /></PlatformBlock>|셰이프 파일(.shp)에서 불러온 하나의 지리 공간 도형에 있는 모든 점을 포함합니다. 예를 들어 셰이프 파일의 일본 국가는 점 객체의 목록의 목록으로 표현되며, 여기서<ul><li>첫 번째 점 목록은 홋카이도 섬의 모양을 설명합니다</li><li>두 번째 점 목록은 혼슈 섬의 모양을 설명합니다</li><li>세 번째 점 목록은 규슈 섬의 모양을 설명합니다</li><li>네 번째 점 목록은 시코쿠 섬의 모양을 설명합니다</li></ul>|</PlatformBlock>
| <PlatformBlock for="Angular, React, WebComponents"><ApiLink raw type="ShapefileRecord" prefixed={true} suffix={false} member="fieldValues" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink raw type="ShapefileRecord" prefixed={true} suffix={false} member="FieldValues" /></PlatformBlock><PlatformBlock for="WinUI, Uno"><ApiLink raw type="ShapefileRecord" prefixed={false} suffix={false} member="Fields" /></PlatformBlock> |열 이름으로 구분된 셰이프 데이터베이스 파일(.dbf)의 데이터 행 하나를 포함합니다. 예를 들어 일본의 한 현에 대한 인구, 면적, 현청 소재지 이름 등의 데이터가 포함됩니다.|

적절한 데이터 열이 매핑되어 있다면, 이 데이터 구조는 대부분의 지리 시리즈에서 사용하기에 적합합니다.

## 코드 조각
이 코드 예제는 `ShapeDataSource`를 사용하여 셰이프 파일을 로드했다고 가정합니다.
다음 코드는 맵 컴포넌트의 `GeographicPolylineSeries`를 해당 소스가 생성한 레코드에 바인딩하고, 각 <PlatformBlock for="Angular, React, WebComponents"><ApiLink raw type="ShapefileRecord" prefixed={true} suffix={false} member="points" /></PlatformBlock><PlatformBlock for="WinUI, Uno"><ApiLink raw type="ShapefileRecord" prefixed={false} suffix={false} member="Points" /></PlatformBlock><PlatformBlock for="Blazor">`\Points`</PlatformBlock> `ShapefileRecord`의 속성을 `shapeMemberPath`를 통해 매핑합니다.

```json-snippet source="/maps/geo-map/binding-shp-file"
{
    "type": "GeographicMap",
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicPolylineSeries",
            "name": "lineSeries",
            "shapeMemberPath": "points",
            "shapeFilterResolution": 0.0,
            "shapeStrokeThickness": 3,
            "shapeStroke": "rgb(82, 82, 82, 0.4)"
        }
    ]
}
```
