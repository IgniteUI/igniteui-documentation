# Ignite UI for Blazor 설치하기

Ignite UI for Blazor는 NuGet 패키지로 제공됩니다. Blazor 애플리케이션에서 Ignite UI for Blazor 컴포넌트를 사용하려면 먼저 적절한 NuGet 패키지를 설치해야 합니다.

NuGet을 사용하여 Ignite UI for Blazor를 설치하는 방법은 세 가지입니다:
- [Visual Studio 사용하기](#visual-studio-사용하기)
- [.NET CLI 사용하기](#net-cli-사용하기)
- [패키지 관리자 사용하기](#패키지-관리자-사용하기)

라이선스를 가진 사용자는 [Infragistics 비공개 NuGet 피드](./general-nuget-feed.mdx)에서 제공되는 공식 라이선스 Ignite UI for Blazor NuGet 패키지를 사용해야 합니다.

<DocsAside type="info">
체험판 사용자는 [NuGet.org](https://www.nuget.org/packages/IgniteUI.Blazor.Trial)에서 찾을 수 있는 **IgniteUI.Blazor.Trial** NuGet 패키지를 설치할 수 있습니다.
</DocsAside>

## Visual Studio 사용하기

솔루션 또는 프로젝트를 마우스 오른쪽 버튼으로 클릭하고 **솔루션용 NuGet 패키지 관리**를 선택하십시오.

<Image src={nugetManagePackages} alt="nuget-manage-packages" />

패키지 관리자 대화 상자에서 **찾아보기** 탭을 열고, **Infragistics** 패키지 원본을 선택하고, **IgniteUI.Blazor** NuGet 패키지를 프로젝트에 설치하십시오.

<Image src={nugetPackageManagerBrowse} alt="nuget-package-manager-browse" />

<DocsAside type="info">
Infragistics 패키지 원본을 사용할 수 없다면, [Infragistics NuGet 피드 항목](./general-nuget-feed.mdx)을 읽고 추가하는 방법을 확인하십시오.
</DocsAside>

## .NET CLI 사용하기

```cmd
> dotnet add package IgniteUI.Blazor --version {PackageVerLatestShort}
```

## 패키지 관리자 사용하기

```cmd
PM> Install-Package IgniteUI.Blazor -Version {PackageVerLatestShort}
```
