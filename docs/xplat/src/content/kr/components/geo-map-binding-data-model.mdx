# {Platform} 지리 데이터 모델 바인딩

{ProductName} 지도 컴포넌트는 지리 공간 이미지 지도에 셰이프 파일의 지리 공간 데이터나 데이터 모델의 지리적 위치를 표시하도록 설계되었습니다. 지리 시리즈의 `dataSource` 속성은 데이터 모델에 바인딩하는 용도로 사용됩니다. 이 속성은 사용자 지정 객체의 배열에 바인딩할 수 있습니다.

## {Platform} 지리 데이터 모델 바인딩 예제


<Sample src="/maps/geo-map/binding-data-model" height={500} alt="{Platform} 지리 데이터 모델 바인딩 예제" />




다음 표는 각 유형의 지리 시리즈에 필요한 데이터 구조를 요약합니다:

| 지리 시리즈  | 속성   | 설명   |
|--------------|---------------| ---------------|
| `GeographicSymbolSeries` | `longitudeMemberPath`, `latitudeMemberPath`   | 숫자형 경도 및 위도 좌표 2개의 이름을 지정합니다 |<PlatformBlock for="Web">
| `GeographicHighDensityScatterSeries` | `longitudeMemberPath`, `latitudeMemberPath`   | 숫자형 경도 및 위도 좌표 2개의 이름을 지정합니다 |</PlatformBlock>
| `GeographicProportionalSymbolSeries` | `longitudeMemberPath`, `latitudeMemberPath`, `radiusMemberPath`   | 숫자형 경도 및 위도 좌표 2개와 기호의 크기/반지름을 위한 숫자 열 1개의 이름을 지정합니다 |<PlatformBlock for="Angular, React, WebComponents, Blazor">
| `GeographicScatterAreaSeries` | `longitudeMemberPath`, `latitudeMemberPath`, `colorMemberPath`   | 숫자형 경도 및 위도 좌표 2개와 값의 삼각분할을 위한 숫자 열 1개의 이름을 지정합니다 |</PlatformBlock>
| `GeographicContourLineSeries` | `longitudeMemberPath`, `latitudeMemberPath`, `valueMemberPath`   | 숫자형 경도 및 위도 좌표 2개와 값의 삼각분할을 위한 숫자 열 1개의 이름을 지정합니다 |
|`GeographicShapeSeries`|`shapeMemberPath`|`dataSource` 항목 중 도형의 지리적 지점을 포함하는 데이터 열의 이름을 지정합니다. 이 속성은 x와 y 속성을 가진 객체의 배열의 배열에 매핑되어야 합니다. |
|`GeographicPolylineSeries`|`shapeMemberPath`|`dataSource` 항목 중 선의 지리적 좌표를 포함하는 데이터 열의 이름을 지정합니다. 이 속성은 x와 y 속성을 가진 객체의 배열의 배열에 매핑되어야 합니다. |

## 코드 조각
다음 코드는 경도와 위도 좌표로 저장된 세계 일부 도시의 지리적 위치를 포함하는 사용자 지정 데이터 모델에 `GeographicSymbolSeries`를 바인딩하는 방법을 보여 줍니다. 또한 `GeographicPolylineSeries`를 사용하여 `\MapGeodesics`의 대권 수학으로 이 위치들 사이의 최단 지리 경로를 플롯합니다. 전체 내용은 아래 코드에 나와 있습니다

```json-snippet source="/maps/geo-map/binding-data-model"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "$type": "+doc:markup",
            "height": "100%",
            "width": "100%",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapBindingDataModelOnViewInit"
    ]
}
```

```json-snippet source="/maps/geo-map/binding-data-model" channel="handlersImports...supportingTypes...handler" item="MapBindingDataModelOnViewInit"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "height": "100%",
            "width": "100%",
            "zoomable": true
        }
    },
    "$onViewInit": "+doc:handler",
    "onViewInit": [
        "MapBindingDataModelOnViewInit"
    ]
}
```
