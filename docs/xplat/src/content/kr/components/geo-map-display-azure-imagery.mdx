# Azure Maps <Badge variant="preview" />의 {Platform} 이미지

{Platform} `AzureMapsImagery`는 Microsoft®가 제공하는 지리 이미지 매핑 서비스입니다. 세계의 여러 스타일의 지리 이미지 타일을 제공합니다. 이 지리 이미지 서비스는 <a href="https://azure.microsoft.com/en-us/products/azure-maps" target="_blank">www.azure.microsoft.com</a> 웹사이트에서 직접 접근할 수 있습니다. {ProductName} 지도 컴포넌트는 `AzureMapsImagery` 클래스를 사용하여 지도 배경 콘텐츠에 Azure Maps의 지리 이미지를 표시할 수 있습니다.

## {Platform} Azure Maps의 이미지 표시 - 코드 예제
다음 코드 조각은 `AzureMapsImagery` 클래스를 사용하여 {Platform} `GeographicMap`에 Azure Maps의 지리 이미지 타일을 표시하는 방법을 보여 줍니다.

```json-snippet channel="auto" include="bindingFields"

{
    "type": "GeographicMap",
    "$styleOptions": { "directAssignment": true },
    "name": "azureMap",
    "$setInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "$assignInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "backgroundContent": {
        "type": "AzureMapsImagery",
        "name": "azureImagery",
        "apiKey": "YOUR_AZURE_MAPS_API_KEY",
        "imageryStyle": "Satellite"
    }
}

```

## {Platform} Azure Maps의 이미지 겹쳐 놓기 - 개요

`GeographicTileSeries`를 사용할 때, **기본 지도 스타일**(예: **Satellite**, **Road**, **DarkGrey**) 위에 **오버레이**(교통, 날씨, 레이블)를 결합할 수 있습니다. 지형을 시각화하려면 예를 들어 **Satellite**와 함께 **TerraOverlay**를 사용하십시오.

- **기본 스타일**: Satellite, Road, Terra, DarkGrey는 핵심 배경 타일을 제공합니다.
- **오버레이 스타일**: 교통 및 날씨 이미지(예: `TrafficRelativeOverlay`, `WeatherRadarOverlay`)는 타일 시리즈에 할당하여 기본 스타일 위에 겹치도록 설계되어 있습니다.
- **하이브리드 스타일**: `HybridRoadOverlay` 및 `HybridDarkGreyOverlay` 같은 변형은 이미 기본 스타일과 오버레이(레이블, 도로 등)를 결합하므로, 여러 레이어를 수동으로 관리할 필요가 없습니다.

이 설계로 더 풍부한 지도를 만들 수 있습니다. 예를 들면 다음과 같습니다:
- 실제 이미지에서 혼잡을 강조하기 위해 **TrafficOverlay**와 함께 **위성 이미지**를 표시합니다.
- 강수와 함께 지형을 시각화하기 위해 **Terra**를 **WeatherRadarOverlay**와 함께 사용합니다.
- 대시보드에 적합하고 대비가 강한 보기를 위해 **DarkGrey**를 **LabelsRoadOverlay**와 함께 적용합니다.

## {Platform} Azure Maps의 이미지 겹쳐 놓기 - 코드 예제
다음 코드 조각은 `AzureMapsImagery`와 `GeographicTileSeries` 클래스를 사용하여 {Platform} `GeographicMap`에서, 예를 들어 교통 정보를 어두운 회색 지도 위의 배경 이미지에 결합하여 그 위에 지리 이미지 타일을 표시하는 방법을 보여 줍니다.

```json-snippet channel="auto" include="bindingFields"

{
    "type": "GeographicMap",
    "$styleOptions": { "directAssignment": true },
    "name": "azureMap",
    "$setInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "$assignInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "backgroundContent": {
        "type": "AzureMapsImagery",
        "name": "azureImagery",
        "apiKey": "YOUR_AZURE_MAPS_API_KEY",
        "imageryStyle": "DarkGrey"
    },
    "series": [
        {
            "type": "GeographicTileSeries",
            "name": "imagerySeries",
            "$setInCode": {
                "tileImagery": [
                    "angular",
                    "react",
                    "webComponents",
                    "blazor",
                    "winUI",
                    "wpf"
                ]
            },
            "$assignInCode": {
                "tileImagery": [
                    "angular",
                    "react",
                    "webComponents",
                    "blazor",
                    "winUI",
                    "wpf"
                ]
            },
            "tileImagery": {
                "type": "AzureMapsImagery",
                "name": "trafficImagery",
                "apiKey": "YOUR_AZURE_MAPS_API_KEY",
                "imageryStyle": "TrafficAbsoluteOverlay"
            }
        }
    ]
}

```

## 속성
다음 표는 `AzureMapsImagery` 클래스의 속성을 요약합니다:

| 속성 이름  | 속성 유형   | 설명   |
|----------------|-----------------|---------------|
|`apiKey`|string|Azure Maps 이미지 서비스에 필요한 API 키를 설정하는 속성을 나타냅니다. 이 키는 <a href="https://azure.microsoft.com/en-us/products/azure-maps" target="_blank">azure.microsoft.com</a> 웹사이트에서 얻어야 합니다.|
|`imageryStyle`|`AzureMapsImageryStyle`|Azure Maps 이미지 타일의 지도 스타일을 설정하는 속성을 나타냅니다. 이 속성은 다음 `AzureMapsImageryStyle` 열거형 값으로 설정할 수 있습니다:<ul><li>Satellite - 도로나 레이블 오버레이가 없는 위성 지도 스타일을 지정합니다</li><li>Road - 도로와 레이블 오버레이가 있는 항공 지도 스타일을 지정합니다</li><li>DarkGrey - 대비와 강조 오버레이를 위한 어두운 회색 기본 지도 스타일을 지정합니다</li><li>TerraOverlay - 고도와 지형 특징을 강조하는 음영 기복이 있는 지형 지도 스타일을 지정합니다</li><li>LabelsRoadOverlay - 항공 오버레이 없이 도시 레이블만 있는 여러 오버레이 중 하나입니다</li><li>HybridRoadOverlay - 도로 및 레이블 오버레이와 결합된 위성 배경입니다</li><li>HybridDarkGreyOverlay - 어두운 회색 레이블 오버레이와 결합된 위성 배경입니다</li><li>LabelsDarkGreyOverlay - 어두운 회색 기본 지도 위의 도시 레이블 여러 오버레이 중 하나입니다</li><li>TrafficDelayOverlay - 교통 지연과 혼잡 구역을 실시간으로 표시합니다</li><li>TrafficAbsoluteOverlay - 현재 교통 속도를 절댓값으로 표시합니다</li><li>TrafficReducedOverlay - 빛 기반 시각화로 감소된 교통 흐름을 표시합니다</li><li>TrafficRelativeOverlay - 정상 상태와 비교한 교통 속도를 표시합니다</li><li>TrafficRelativeDarkOverlay - 대비를 높이기 위해 어두운 기본 지도 위에 정상 상태와 비교한 교통 속도를 표시합니다</li><li>WeatherRadarOverlay - 강수의 거의 실시간 레이더 이미지를 표시합니다</li><li>WeatherInfraredOverlay - 구름 덮개의 적외선 위성 이미지를 표시합니다</li></ul> |
