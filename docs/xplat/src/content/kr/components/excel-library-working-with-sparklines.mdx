# {Platform} 스파크라인 사용하기

Infragistics {Platform} Excel 라이브러리는 Excel 워크시트에 스파크라인을 추가하는 기능을 지원합니다. 이를 사용하면 워크시트의 데이터 셀 영역에 걸친 데이터 추세를 간단한 시각적 표현으로 보여 줄 수 있습니다. 예를 들어 특정 셀 영역의 Excel 데이터를 간단한 열 또는 선 스파크라인 차트로 보고 싶다면, 이 기능이 그렇게 할 수 있도록 도와줍니다.

## 지원되는 스파크라인
다음은 지원되는 사전 정의된 스파크라인 유형의 목록입니다.

- Line
- Column
- 누적(승/패)

다음 코드는 sparklineGroups 컬렉션을 통해 워크시트에 스파크라인을 프로그래밍 방식으로 추가하는 방법을 보여 줍니다:

```ts
var workbook: Workbook;
var sheet1 = workbook.worksheets().add("Sparklines");
var sheet2 = workbook.worksheets().add("Data");
sheet1.sparklineGroups().add(SparklineType.Line, "Sparklines!A1:A1", "Data!A2:A11");
sheet1.sparklineGroups().add(SparklineType.Column, "Sparklines!B1:B1", "Data!A2:A11");
workbook.save(workbook, "Sparklines.xlsx");
```
