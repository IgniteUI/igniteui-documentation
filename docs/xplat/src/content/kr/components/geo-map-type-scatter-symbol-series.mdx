# {Platform} 지리 기호 지도

{Platform} 지도 컴포넌트에서는 `GeographicSymbolSeries`를 사용하여 지리적 맥락에서 점 또는 마커를 사용해 지리 공간 데이터를 표시할 수 있습니다. 이 유형의 지리 시리즈는 도시, 공항, 지진, 관심 지점 같은 지리적 위치의 모음을 렌더링하는 데 자주 사용됩니다.

## 데이터 요구 사항
지도 컴포넌트의 다른 유형의 지리 시리즈와 마찬가지로, `GeographicSymbolSeries`에도 객체의 배열에 바인딩할 수 있는 `dataSource` 속성이 있습니다. 또한 이 객체의 각 데이터 항목에는 지리적 위치(경도와 위도)를 저장하는 두 개의 숫자 데이터 열이 있어야 합니다. 이 데이터 열은 그다음 `latitudeMemberPath`와 `longitudeMemberPath` 속성에 매핑됩니다. `GeographicSymbolSeries`는 이 매핑된 데이터 열의 값을 사용하여 지리 지도 컴포넌트에 기호 요소를 플롯합니다.

## 코드 조각
다음 코드는 `ShapefileRecord`를 사용하여 셰이프 파일에서 불러온 도시의 위치에 `GeographicSymbolSeries`를 바인딩하는 방법을 보여 줍니다.

```json-snippet source="/maps/geo-map/type-scatter-symbol-series" code="allCode"
{
    "type": "GeographicMap",
    "name": "geoMap",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicSymbolSeries",
            "name": "citiesSeries",
            "dataSourceRef": "WorldCities",
            "markerType": "Circle",
            "latitudeMemberPath": "Y",
            "longitudeMemberPath": "X",
            "markerBrush": "White",
            "markerOutline": "Gray"
        },
        {
            "type": "GeographicSymbolSeries",
            "name": "capitalsSeries",
            "dataSourceRef": "WorldCapitals",
            "markerType": "Circle",
            "latitudeMemberPath": "Y",
            "longitudeMemberPath": "X",
            "markerBrush": "White",
            "markerOutline": "rgb(32, 146, 252)"
        }
    ]
}
```
