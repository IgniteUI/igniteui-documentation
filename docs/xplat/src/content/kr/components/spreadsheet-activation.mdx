# {Platform} Spreadsheet 활성화

{Platform} Spreadsheet 컴포넌트는 컨트롤에서 현재 활성 셀, 패널 및 워크시트를 확인할 수 있는 속성을 노출합니다. 이는 사용자가 컨트롤에서 어디를 탐색하거나 편집하고 있는지 파악하는 데 도움이 되므로 유용합니다.

## 활성화 개요

{Platform} <ApiLink type="Spreadsheet" /> 컨트롤의 활성화는 스프레드시트의 현재 <ApiLink type="Workbook" />의 셀, 패널 및 워크시트에 나뉘어 있습니다. 세 가지 "활성" 속성은 다음과 같습니다:

- <ApiLink type="Spreadsheet" member="activeCell" label="ActiveCell" />: 스프레드시트의 활성 셀을 반환하거나 설정합니다. 설정하려면 <ApiLink type="SpreadsheetCell" />의 새 인스턴스를 만들고 열과 행, 또는 셀의 문자열 주소처럼 그 셀에 대한 정보를 전달해야 합니다.
- <ApiLink type="Spreadsheet" member="activePane" label="ActivePane" />: 스프레드시트 컨트롤의 현재 활성 워크시트에서 활성 패널을 반환합니다.
- <ApiLink type="Spreadsheet" member="activeWorksheet" label="ActiveWorksheet" />: 스프레드시트 컨트롤의 <ApiLink type="Workbook" />에서 활성 워크시트를 반환하거나 설정합니다. 스프레드시트에 연결된 <ApiLink type="Workbook" />의 기존 워크시트로 설정하여 바꿀 수 있습니다.

## 코드 조각

다음 코드 조각은 <ApiLink type="Spreadsheet" /> 컨트롤에서 셀과 워크시트의 활성화를 설정하는 방법을 보여 줍니다:

```ts
this.spreadsheet.activeWorksheet = this.spreadsheet.workbook.worksheets(1);

this.spreadsheet.activeCell = new SpreadsheetCell("C5");
```
