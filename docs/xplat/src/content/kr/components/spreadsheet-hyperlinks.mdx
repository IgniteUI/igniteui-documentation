# {Platform} Spreadsheet 하이퍼링크

{Platform} Spreadsheet 컴포넌트는 Excel 통합 문서에 이미 있는 하이퍼링크를 표시하고, 웹사이트, 파일 디렉터리, 심지어 통합 문서의 다른 워크시트로 연결되는 새 하이퍼링크를 삽입할 수 있게 합니다.

## {Platform} Spreadsheet 하이퍼링크 예제


<Sample src="/excel/spreadsheet/hyperlinks" height={500} alt="{Platform} Spreadsheet 하이퍼링크 예제" />




## 하이퍼링크 개요

하이퍼링크는 하이퍼링크를 배치할 워크시트의 `\Hyperlinks` 컬렉션에 접근하여 <ApiLink type="Spreadsheet" /> 컨트롤에 추가합니다. 이 컬렉션에는 <ApiLink type="WorksheetHyperlink" /> 객체를 받는 `\Add` 메서드가 있으며, 여기서 셀 주소, 이동할 하이퍼링크 URL, 표시 텍스트, 그리고 선택적으로 마우스를 올릴 때 표시할 툴팁을 정의할 수 있습니다.

## 종속성

하이퍼링크를 사용하도록 {Platform} 스프레드시트 컨트롤을 설정할 때는 다음과 같이 <ApiLink type="WorksheetHyperlink" /> 클래스를 가져와야 합니다:

```ts

```


</PlatformBlock>


## 코드 조각

다음 코드 조각은 {Platform} <ApiLink type="Spreadsheet" /> 컨트롤에서 현재 보고 있는 워크시트에 하이퍼링크를 추가하는 방법을 보여 줍니다:

```ts
this.spreadsheet.activeWorksheet.hyperlinks().add(new WorksheetHyperlink("A1", "http://www.infragistics.com", "Infragistics", "Infragistics Home Page"));
```
