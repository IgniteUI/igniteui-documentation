# {Platform} Expansion Panel 개요

{ProductName} Expansion Panel은 접힌 상태 또는 펼쳐진 상태의 두 가지 상태로 렌더링할 수 있는 경량 아코디언 컴포넌트입니다. 확장 패널은 마우스 클릭이나 키보드 상호 작용으로 전환할 수 있습니다.

## 컴포넌트 사용자 지정
<ApiLink pkg="core" type="ExpansionPanel" /> 컨트롤은 본문 안에 모든 종류의 콘텐츠를 추가할 수 있습니다. [입력](../inputs/input.mdx), 차트, 그리고 다른 확장 패널까지 렌더링할 수 있습니다!

<ApiLink pkg="core" type="ExpansionPanel" />은(는) 노출된 `title`, `subTitle` 및 `indicator` 슬롯을 통해 헤더를 쉽게 사용자 지정할 수 있습니다.

확장 표시기의 위치는 Expansion Panel의 <ApiLink pkg="core" type="ExpansionPanel" member="indicatorPosition" label="IndicatorPosition" /> 속성으로 구성할 수 있습니다. 가능한 옵션은 **start**, **end** 또는 **none**입니다.

다음 코드 샘플은 컴포넌트의 버튼을 **오른쪽**에 배치하도록 구성하는 방법을 보여 줍니다.

<Sample src="/layouts/expansion-panel/component-customization" height={460} alt="{Platform} Expansion Panel 사용자 지정" />

### 슬롯에 권장되는 요소

`title` 및 `subtitle` 슬롯에 콘텐츠를 배치할 때는 제목 요소(`<h1>`–`<h6>`) 대신 `<span>` 요소를 사용하는 것을 권장합니다. 제목 요소에는 컴포넌트가 의도한 타이포그래피와 레이아웃을 방해할 수 있는 글꼴 크기, 줄 높이, 여백 같은 기본 스타일이 있습니다. `<span>`를 사용하면 컴포넌트 스타일을 깔끔하게 상속받는 중립적인 컨테이너를 얻을 수 있습니다.

`indicator` 슬롯은 아이콘과 같은 콘텐츠를 위한 것입니다. 이 용도로는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다. 또는 표시기에 아이콘을 사용하지 않으려면 `<span>` 요소를 사용하여 텍스트, 기호 또는 이모지를 표시할 수 있습니다.

<PlatformBlock for="WebComponents">

```html
<igc-expansion-panel>
  <span slot="title">Golden Retriever</span>
  <span slot="subtitle">Medium-large gun dog</span>
  <igc-icon slot="indicator" name="arrow_forward"></igc-icon>
</igc-expansion-panel>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrExpansionPanel>
  <span slot="title">Golden Retriever</span>
  <span slot="subtitle">Medium-large gun dog</span>
  <IgrIcon slot="indicator" name="arrow_forward"></IgrIcon>
</IgrExpansionPanel>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbExpansionPanel>
  <span slot="title">Golden Retriever</span>
  <span slot="subtitle">Medium-large gun dog</span>
  <IgbIcon slot="indicator" IconName="arrow_forward" Collection="material"></IgbIcon>
</IgbExpansionPanel>
```

</PlatformBlock>

## 키보드 탐색

{ProductName} Expansion Panel의 키보드 탐색은 W3C 접근성 표준을 준수하며 사용하기 편리합니다.

**키 조합**

- <kbd>ALT</kbd> + <kbd>↓</kbd> - 포커스가 있는 패널을 펼칩니다.
- <kbd>ALT</kbd> + <kbd>↑</kbd> - 포커스가 있는 패널을 접습니다.
- <kbd>SPACE</kbd>/<kbd>ENTER</kbd> - 포커스가 있는 패널의 확장 상태를 전환합니다.

## 스타일링

<ApiLink pkg="core" type="ExpansionPanel" /> 컴포넌트는 여러 CSS 파트를 노출하므로 스타일을 완전히 제어할 수 있습니다:

|이름|설명|
|--|--|
| `header` | 확장 표시기, 제목 및 부제목의 컨테이너입니다. |
| `title` | 제목 컨테이너. |
| `subtitle` | 부제목 컨테이너. |
| `indicator` | 표시기 컨테이너입니다. |
| `content` | 확장 패널의 콘텐츠 래퍼입니다. |

```css
igc-expansion-panel {
  background-color: var(--ig-secondary-900);
  color: var(--ig-secondary-900-contrast);
}

igc-button::part(base) {
  color: var(--ig-secondary-900-contrast);
}

igc-button::part(base)::before {
  background-color: var(--ig-warn-500);
}

igc-expansion-panel::part(indicator) {
  color: var(--ig-warn-500);
}

igc-expansion-panel::part(header) {
  background-color: var(--ig-secondary-900);
}

igc-expansion-panel::part(title),
igc-expansion-panel::part(subtitle) {
  color: var(--ig-warn-500);
}
```
