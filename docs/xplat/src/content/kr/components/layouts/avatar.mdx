# Avatar 컴포넌트

{ProductName} Avatar는 이미지, 이니셜 또는 사용자 지정 콘텐츠로 사용자, 개체 또는 항목을 나타냅니다.

목록, 카드, 프로필 메뉴, 활동 피드에서 간결한 시각적 ID를 제공하려면 아바타를 사용하십시오.

## 사용법

이미지 소스, 이니셜 또는 기본 슬롯의 사용자 지정 콘텐츠로 아바타를 렌더링하십시오.

### 변형

<PlatformBlock for="WebComponents, React, Blazor">

표시하려는 콘텐츠 소스만 설정하십시오. 아바타는 <ApiLink pkg="core" type="Avatar" member="initials" label="Initials" />이(가) 설정되면 이를 렌더링하고, 그렇지 않으면 기본 슬롯 콘텐츠를 렌더링합니다. 또한 <ApiLink pkg="core" type="Avatar" member="src" label="Src" />이(가) 설정되어 있고 성공적으로 로드되는 동안에는 이미지 요소도 렌더링합니다.

</PlatformBlock>

<PlatformBlock for="Angular">

표시하려는 콘텐츠 소스만 설정하십시오. Angular 아바타는 `src`을(를) 먼저, 그다음 `icon`을(를), 그다음 `initials`을(를) 렌더링하며, 이들 입력이 모두 설정되지 않은 경우 프로젝션된 사용자 지정 콘텐츠로 대체합니다.

</PlatformBlock>

## 속성

<PlatformBlock for="WebComponents, React, Blazor">

| 이름 | 타입 | 기본값 | 설명 |
| -- | -- | -- | -- |
| <ApiLink pkg="core" type="Avatar" member="alt" label="Alt" /> | `string` | n/a | 이미지 아바타의 대체 텍스트를 설정합니다. |
| <ApiLink pkg="core" type="Avatar" member="initials" label="Initials" /> | `string` | n/a | 표시되는 이미지가 없을 때 렌더링되는 텍스트 이니셜을 설정합니다. |
| <ApiLink pkg="core" type="Avatar" member="shape" label="Shape" /> | `"square" \| "rounded" \| "circle"` | `"square"` | 아바타 모양을 설정합니다. |
| <ApiLink pkg="core" type="Avatar" member="src" label="Src" /> | `string` | n/a | 이미지 소스 URL을 설정합니다. |

</PlatformBlock>

아바타 모양은 테마 변수와 플랫폼별 스타일 지정 후크로 제어됩니다.

<PlatformBlock for="WebComponents, React, Blazor">

토큰 수준의 변경에는 아바타 CSS 변수를 사용하고, 렌더링된 래퍼, 이미지, 아이콘 또는 이니셜을 대상으로 하려면 CSS 파트를 사용하십시오.

| 변수 | 변경되는 내용 |
| -- | -- |
| `--ig-avatar-background` | 아바타 배경색입니다. |
| `--ig-avatar-color` | 텍스트 및 이니셜 색입니다. |
| `--ig-avatar-icon-color` | 슬롯에 배치된 아이콘 색입니다. |
| `--ig-avatar-border-radius` | 둥근 아바타에 사용되는 테두리 반경입니다. |
| `--ig-avatar-size` | 아바타의 너비와 높이입니다. |
| `--ig-size` | 미리 정의된 아바타 크기를 도출하는 데 사용되는 공통 컴포넌트 크기 토큰입니다. |

| CSS 파트 | 설명 |
| -- | -- |
| `base` | 아바타 래퍼입니다. |
| `icon` | 아이콘 래퍼입니다. |
| `initials` | 이니셜 래퍼입니다. |
| `image` | 이미지 요소입니다. |

</PlatformBlock>

## 접근성

아바타는 포커스를 받지 않으며 키보드 상호 작용도 없습니다.

### 화면 읽기 프로그램 / ARIA

아바타는 이미지 시맨틱과 `avatar`이라는 기본 접근성 레이블로 초기화됩니다.

<PlatformBlock for="WebComponents, React, Blazor">

- `src` 이미지가 특정 사람, 개체 또는 항목을 나타내는 경우 `alt`을(를) 설정하십시오.
- 프로젝션된 사용자 지정 콘텐츠에 다른 접근성 이름이 필요한 경우 명시적인 `aria-label`을(를) 추가하십시오.
- 인접한 텍스트가 이미 같은 개체를 식별하고 있다면 장식용 아바타는 중복으로 간주하십시오.

- 인접한 텍스트가 이미 같은 개체를 식별하고 있다면 장식용 아바타는 중복으로 간주하십시오.

## 문제 해결

아바타를 대화형 또는 상태 컴포넌트로 다루기 전에 이 섹션에서 경계와 일반적인 결정 사항을 확인하십시오.

### 알려진 제한 사항

아바타는 ID를 나타내는 기본 시각 요소이며, 그 자체로 상호 작용, 상태 또는 알림 동작을 추가하지 않습니다.

- 나타내는 개체를 클릭할 수 있어야 한다면 버튼이나 목록 항목처럼 대화형 컨테이너를 사용하십시오.
- 상태, 개수 또는 알림 표시기를 보여 줘야 할 때는 아바타와 함께 배지를 사용하십시오.
