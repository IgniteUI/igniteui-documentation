# Breadcrumbs 컴포넌트 <Badge variant="new" />

{ProductName} Breadcrumbs 컴포넌트는 구성 가능한 아이콘으로 구분되는 순서가 있는 탐색 항목 경로를 렌더링하여, 사이트 계층 구조에서 사용자의 위치를 보여 주고 상위 수준 페이지로 돌아갈 방법을 제공합니다.

<strong>2. Breadcrumbs 항목 아이콘(선택 사항):</strong> 레이블의 오른쪽 또는 왼쪽에 표시할 수 있습니다.<br />
<strong>3. 구분자:</strong> 개별 항목을 나누고 계층 구조의 방향을 나타내는 시각 요소입니다.<br />
<strong>4. 현재 항목:</strong> 탐색 경로에서 활성 수준을 나타내며, 일반적으로 클릭할 수 없습니다.</span>

```text
<igc-breadcrumbs role="list">
  <igc-breadcrumb role="listitem">
    ├── ::part(label)
    │   ├── slot="prefix"                 // optional prefix content
    │   ├── default slot                  // main content, typically <a>
    │   └── slot="suffix"                 // optional suffix content
    └── ::part(separator)                 // hidden on the last item
        └── slot="separator"              // per-item override
  </igc-breadcrumb>
  <!-- more <igc-breadcrumb> items ... -->
  <igc-breadcrumb current role="listitem" aria-current="page">
    <!-- last item, no trailing separator -->
  </igc-breadcrumb>
</igc-breadcrumbs>
```

## 사용법

### 현재 페이지

현재 보고 있는 페이지를 나타내는 항목에 다음을 표시하십시오 <PlatformBlock for="WebComponents, Angular">[`current`]({environment:infragisticsBaseUrl}/api/webcomponents/igniteui-webcomponents/latest/classes/IgcBreadcrumbComponent#current)</PlatformBlock><PlatformBlock for="React, Blazor"><ApiLink pkg="core" type="Breadcrumb" member="current" label="current" /></PlatformBlock> 속성입니다. 항목은 이를 속성으로 반영하고 `aria-current="page"`을(를) 설정하므로 스크린 리더가 현재 페이지를 알려 줍니다.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-breadcrumbs>
  <igc-breadcrumb><a href="/home">Home</a></igc-breadcrumb>
  <igc-breadcrumb current><a href="/home/dashboard">Dashboard</a></igc-breadcrumb>
```

</PlatformBlock>

### 공유 구분자

컴포넌트 템플릿에 간단한 포함 버튼을 추가하려면 <PlatformBlock for="WebComponents, Angular">[`separator`]({environment:infragisticsBaseUrl}/api/webcomponents/igniteui-webcomponents/latest/classes/IgcBreadcrumbsComponent#separator)</PlatformBlock><PlatformBlock for="React, Blazor"><ApiLink pkg="core" type="Breadcrumbs" member="separator" label="separator" /></PlatformBlock> 경로의 모든 항목에 공유 구분자 아이콘을 설정하려면 컨테이너의 속성을 사용하십시오. 값은 등록된 아이콘 컬렉션의 아이콘 이름이며, 컨테이너가 이 값을 각 항목에 전달합니다.

<PlatformBlock for="WebComponents, Angular">

```html

  <igc-breadcrumb><a href="/home/products">Products</a></igc-breadcrumb>
  <igc-breadcrumb><a href="/home/products/laptops">Laptops</a></igc-breadcrumb>
  <igc-breadcrumb current><a href="/home/products/laptops/gaming">Gaming Laptop</a></igc-breadcrumb>
</igc-breadcrumbs>
```

</PlatformBlock>

### 항목별 구분자 재정의

항목의 `separator` 슬롯에 콘텐츠를 배치하면 해당 항목 하나에 대해 구분자를 재정의할 수도 있습니다. 텍스트 구분자(예: `/` 또는 `›`)를 아이콘과 섞어 쓰거나, 각 경계마다 다른 구분자를 사용하려는 경우에 유용합니다.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-breadcrumbs>
  <igc-breadcrumb>
    <a href="/home">Home</a>
    <span slot="separator">/</span>
  </igc-breadcrumb>
  <igc-breadcrumb current><a href="/home/settings">Settings</a></igc-breadcrumb>
</igc-breadcrumbs>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrBreadcrumbs>
  <IgrBreadcrumb>

</IgrBreadcrumbs>
```

</PlatformBlock>

</PlatformBlock>

## 접근성

{Platform} Breadcrumbs는 ARIA breadcrumb 탐색 패턴을 따릅니다. 컨테이너는 ARIA `list` 역할을 노출하고, 각 항목은 `listitem` 역할을 노출하며, 현재 항목은 `aria-current="page"`로 알려 줍니다.

### 접근 가능한 탐색 랜드마크

보조 기술이 탐색 랜드마크로 인식할 수 있도록 경로를 `aria-label`를 가진 `<nav>` 요소로 감싸십시오. ARIA breadcrumb 패턴에 따라 레이블은 목록이 아니라 `<nav>`에 두어야 합니다.

<PlatformBlock for="WebComponents, Angular">

```html
<nav aria-label="Breadcrumb">
  <igc-breadcrumbs>
    <igc-breadcrumb><a href="/">Root</a></igc-breadcrumb>
    <igc-breadcrumb current><a href="/products">Products</a></igc-breadcrumb>
  </igc-breadcrumbs>
</nav>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<nav aria-label="Breadcrumb">
  <IgrBreadcrumbs>
    <IgrBreadcrumb><a href="/">Root</a></IgrBreadcrumb>
    <IgrBreadcrumb current={true}><a href="/products">Products</a></IgrBreadcrumb>
  </IgrBreadcrumbs>
</nav>
```

</PlatformBlock>

### 키보드 상호 작용

Breadcrumbs 컴포넌트는 사용자 지정 키보드 처리를 구현하지 않으며, 탐색은 슬롯에 배치된 대화형 콘텐츠의 기본 동작에 의존합니다:

| 키 | 동작 |
| -- | -- |
| `Tab` / `Shift` + `Tab` | 각 breadcrumb 항목에 슬롯으로 배치된 대화형 요소(보통 링크) 사이에서 포커스를 이동합니다. |
| `Enter` / `Space` | 슬롯에 배치된 요소의 기본 동작에 따라 현재 포커스가 있는 링크를 활성화합니다. |

### 화면 읽기 프로그램 / ARIA

- `Breadcrumbs` 호스트는 `role="list"`을(를) 가집니다.
- 각 `Breadcrumb` 호스트는 `role="listitem"`을(를) 가집니다.
- `current`을(를) `true`(으)로 설정하면 호스트에 `aria-current="page"`이(가) 적용되며, 다시 `false`(으)로 설정하면 속성이 제거됩니다.
- `disabled`을(를) `true`(으)로 설정하면 호스트에 `aria-disabled="true"`이(가) 적용됩니다.
- 구분자 아이콘은 장식용이며 스크린 리더가 알려 주지 않습니다.

### 접근성 준수

Infragistics는 [접근성 준수](../interactivity/accessibility-compliance.mdx) 항목에서 Section 508 및 WCAG 2.1 지침 영역에 대한 {ProductName} 접근성 지원을 문서화합니다.

| 기준 | 컴포넌트가 준수하는 방식 |
| -- | -- |
| [1.3.1 정보와 관계](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships) | 컨테이너와 항목은 `list` / `listitem` 역할을 노출하며, 현재 항목은 `aria-current="page"`을(를) 노출합니다. |
| [2.4.8 위치](https://www.w3.org/WAI/WCAG21/Understanding/location) | 경로는 사이트 계층 구조 안에서 현재 페이지의 위치를 시각적으로, 그리고 프로그래밍 방식으로 전달합니다. |
| [4.1.2 이름, 역할, 값](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | `<nav>` 래퍼가 접근성 이름을 가지며, `list`/`listitem` 역할이 구조적 시맨틱을 담당합니다. |

사용자의 책임:

- Breadcrumbs 컨테이너를 `<nav>` 요소로 감싸고, `"Breadcrumb"` 또는 `"Product category"`처럼 설명적인 `aria-label`을(를) 설정하십시오.
- 스크린 리더가 하나의 현재 페이지만 알리도록, 경로마다 정확히 하나의 항목만 `current`(으)로 표시하십시오.
- 슬롯에 배치된 각 앵커 안에 의미 있는 텍스트 레이블을 제공하십시오. 목적지를 전달하는 데 접두사 아이콘에만 의존하지 마십시오.

## 문제 해결

{Platform} Breadcrumbs 문제 해결 지침은 일반적인 통합 및 렌더링 문제에 대해 문제 → 원인 → 해결 형식을 따릅니다.

### 일부 항목에서 구분자가 보이지 않는 이유는 무엇입니까?

구분자는 경로의 마지막 항목에서 자동으로 숨겨지며, 이는 ARIA breadcrumb 패턴에 따른 의도된 동작입니다. 예상하지 못한 항목에서 구분자가 없다면 해당 항목이 컨테이너의 마지막 보이는 자식인지 확인하십시오.

### 'separator'에 설정한 사용자 지정 아이콘 이름이 렌더링되지 않는 이유는 무엇입니까?

구분자 아이콘은 아이콘 레지스트리에 등록되어 있어야 합니다. 경로를 렌더링하기 전에 아이콘을 등록하거나, 테마에 포함된 기본 `tree_expand` 아이콘으로 대체하십시오.

### RTL에서 경로가 줄 바꿈되지 않는 이유는 무엇입니까?

줄 바꿈은 RTL에만 해당하는 동작이 아니며, 전체 콘텐츠 너비가 컨테이너 너비를 초과할 때마다 발생합니다. RTL 환경에서는 시각적 순서가 뒤집히고 구분자 아이콘이 자동으로 반전됩니다. 그래도 경로가 넘친다면 상위 요소가 컨테이너가 자연스러운 너비를 가지지 못하게 막고 있는지 확인하십시오.

## 알려진 제한 사항

{Platform} Breadcrumbs에는 다음과 같은 플랫폼 독립적인 제한 사항이 있습니다.

- Breadcrumbs 컴포넌트는 사용자 지정 키보드 처리를 구현하지 않습니다. 활성화는 각 항목에 슬롯으로 배치된 대화형 요소(보통 앵커)에 따라 달라집니다.
- Breadcrumbs는 자체 `<nav>` 랜드마크를 렌더링하지 않으며, 이를 사용하는 애플리케이션이 `<nav aria-label="...">` 래퍼를 제공해야 합니다.
- 컨테이너는 긴 경로를 자동으로 잘라 내지 않습니다. 좁은 너비에서 한 줄 경로가 필요한 경우에는 기본 flex 줄 바꿈과 자체 넘침 전략(예: 중간 항목을 메뉴로 접기)을 결합하십시오.

## FAQ

<Faq>
  <FaqItem question="항목 사이의 구분자 아이콘은 어떻게 변경합니까?" indicatorPosition="end">
    Breadcrumbs 컨테이너의 `separator` 속성을 등록된 아이콘 이름으로 설정하십시오. 컨테이너가 모든 하위 항목에 아이콘을 전달합니다. 단일 항목의 구분자만 재정의하려면 해당 항목의 `separator` 슬롯에 대체 콘텐츠를 배치하십시오.
  </FaqItem>

  <FaqItem question="마지막 구분자를 직접 숨겨야 합니까?" indicatorPosition="end">
    아니요. Breadcrumb 항목은 경로의 마지막 항목일 때 끝 구분자를 자동으로 숨기므로, 특별한 처리 없이 반복문으로 항목을 렌더링할 수 있습니다.
  </FaqItem>

  <FaqItem question="Breadcrumbs 컴포넌트가 `<nav>` 랜드마크를 직접 렌더링합니까?" indicatorPosition="end">
    아니요. Breadcrumbs는 `listitem` 자식 요소를 가진 ARIA `list`로 렌더링됩니다. ARIA breadcrumb 패턴에 따라, 이를 사용하는 애플리케이션이 컨테이너를 `<nav aria-label="Breadcrumb">`(또는 더 구체적인 레이블)으로 감싸서 접근 가능한 이름이 목록이 아니라 랜드마크에 있도록 해야 합니다.
  </FaqItem>

  <FaqItem question="현재 페이지는 어떻게 표시합니까?" indicatorPosition="end">
    현재 보고 있는 페이지를 나타내는 Breadcrumb 항목에 `current` 속성을 설정하십시오. 항목은 `current`를 특성으로 반영하고 호스트에 `aria-current="page"`를 적용하므로 스크린 리더가 어느 항목이 현재 페이지인지 알려 줍니다.
  </FaqItem>

  <FaqItem question="Breadcrumbs를 설치하려면 어떤 패키지를 설치해야 합니까?" indicatorPosition="end">
    <PlatformBlock for="WebComponents, Angular">Breadcrumbs는 `igniteui-webcomponents` 패키지 7.4.0 이상에 포함되어 있습니다.</PlatformBlock>
    <PlatformBlock for="Angular">`igniteui-angular`에는 Breadcrumbs가 포함되어 있지 않으므로 Angular 애플리케이션은 이를 직접 설치합니다.</PlatformBlock>
    <PlatformBlock for="React, Blazor">Breadcrumbs는 `{PackageCommon}` 패키지에 포함되어 있습니다.</PlatformBlock>
  </FaqItem>
</Faq>
