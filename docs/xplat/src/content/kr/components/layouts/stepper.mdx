# {Platform} Stepper 개요

{Platform} Stepper 컴포넌트는 마법사 같은 워크플로를 제공하며, 번호가 매겨진 단계를 통해 진행 상황을 보여 주는 데 사용됩니다. 개발자는 긴 콘텐츠를 논리적인 단계의 순서로 나눌 수 있으며, 이를 통해 최종 사용자가 전체 과정을 더 쉽게 탐색할 수 있습니다. {Platform} Stepper는 세로 또는 가로 선으로 표시됩니다. {Platform} Stepper에는 단계 유효성 검사, 스타일 지정, 방향 및 키보드 탐색 같은 여러 기능이 있습니다.

### {Platform} Stepper의 방향

노출된 <ApiLink pkg="core" type="Stepper" member="orientation" label="Orientation" /> 속성으로 stepper 방향을 사용자 지정할 수 있습니다. **가로** 또는 **세로**로 설정할 수 있습니다.

**가로 Stepper 방향**

**가로**가 <ApiLink pkg="core" type="Stepper" /> 방향 속성의 기본값입니다.

{Platform} stepper가 가로 방향일 때는 단계 콘텐츠를 단계 헤더 위에 표시할지 아래에 표시할지 정할 수 있습니다. 이는 기본값이 **false**인 <ApiLink pkg="core" type="Stepper" /> <ApiLink pkg="core" type="Stepper" member="contentTop" label="ContentTop" /> 불리언 속성을 설정하여 구성할 수 있습니다. 이 속성을 활성화하면 단계 콘텐츠가 단계 헤더 위에 표시됩니다.

### 단계 상태

{Platform} <ApiLink pkg="core" type="Stepper" />는 다섯 가지 단계 상태를 지원하며, 각 상태는 기본적으로 다른 스타일을 적용합니다:

- **active** - 단계가 현재 표시 중인지 여부를 결정합니다. 설계상 사용자가 어떤 단계의 active 속성을 명시적으로 **true**로 설정하지 않으면, 처음 활성화되는 단계는 비활성화되지 않은 첫 번째 단계입니다.
- **disabled** - 단계와 상호 작용할 수 없는지 여부를 결정합니다. 기본적으로 단계의 disabled 속성은 **false**로 설정되어 있습니다.
- **invalid** - 단계가 유효한지 여부를 결정합니다. 이 값에 따라 선형 stepper 모드에서 사용자가 앞으로 이동할 수 있는지 결정됩니다. 기본값은 **false**입니다.
- **optional** - 기본적으로 단계의 optional 속성은 **false**로 설정되어 있습니다. 선형 stepper에서 단계의 유효성이 필요하지 않다면 optional 속성을 활성화하여 단계의 유효성과 관계없이 앞으로 이동할 수 있습니다.
- **complete** - 기본적으로 단계의 complete 속성은 **false**를 반환합니다. 하지만 사용자는 필요에 따라 complete 속성을 설정하여 이 기본 완료 동작을 재정의할 수 있습니다. 단계가 완료로 표시되면 기본적으로 단계 헤더의 스타일이 바뀔 뿐 아니라, 완료된 단계와 다음 단계 사이 진행 선의 스타일도 바뀝니다.

현재 선택 사항이 아닌 단계가 유효하지 않으면, 현재 단계를 검증하기 전에는 다음 단계로 넘어갈 수 없습니다.

<DocsAside type="info">
앞으로 이동하기 위해 선택 사항 단계의 유효성은 고려되지 않습니다.
</DocsAside>

### 단계 상호 작용

<ApiLink pkg="core" type="Stepper" />은(는) 단계 상호 작용을 위해 다음 API 메서드를 제공합니다:
- **navigateTo** – 지정된 인덱스의 단계를 활성화합니다.
- **next** - 비활성화되지 않은 다음 단계를 활성화합니다.
- **prev** – 비활성화되지 않은 이전 단계를 활성화합니다.
- **reset** – stepper를 초기 상태로 재설정합니다.

<DocsAside type="info">
reset 메서드는 stepper를 초기 상태, 즉 첫 번째 단계를 활성화한 상태로 재설정합니다. 단계의 콘텐츠는 지우지 않습니다. 이는 직접 처리해야 합니다.
</DocsAside>

### 단계 사용자 지정하기

{ProductName} Stepper를 사용하면 제목, 표시기 등에 대해 다양한 옵션을 구성할 수 있습니다.

이는 <ApiLink pkg="core" type="Stepper" />의 <ApiLink pkg="core" type="Stepper" member="stepType" label="StepType" /> 속성으로 설정할 수 있습니다. 다음 값을 사용합니다:
- 전체 **(기본값)**
- 표시기
- 제목

**full**

제목과 부제목이 정의되어 있으면, 이 설정에서는 표시기와 제목이 모두 렌더링됩니다.

사용자는 단계의 제목 위치도 정의할 수 있으므로, 단계 표시기의 앞, 뒤, 위 또는 아래에 배치할 수 있습니다.
사용자는 <ApiLink pkg="core" type="Stepper" member="titlePosition" label="TitlePosition" /> 속성을 사용하여 제목 위치를 구성할 수 있습니다. 다음 값을 사용합니다:
- undefined **(기본값)**
- end
- start
- bottom
- top

{Platform} <ApiLink pkg="core" type="Stepper" />가 가로 방향이고 제목 위치가 **정의되지 않은** 경우, 제목은 표시기 **아래**에 표시됩니다.

방향이 세로로 설정되고 제목 위치가 **정의되지 않은** 경우, 제목은 표시기 **뒤**에 표시됩니다.

<DocsAside type="info">
**titlePosition** 속성은 stepper의 stepType 속성이 **full**로 설정된 경우 **에만** 적용됩니다.
</DocsAside>

**indicator**

단계에 대해 표시기만 표시하려면 stepType 옵션을 **indicator**로 설정하십시오.

단계 표시기는 어떤 콘텐츠도 지원하지만, 크기는 항상 **24픽셀**이라는 제약이 있습니다. 이를 고려하여 단계 표시기로는 <ApiLink pkg="core" type="Icon" /> 또는 <ApiLink pkg="core" type="Avatar" />을(를) 사용하는 것을 권장합니다.

**제목**

단계에 대해 제목만 표시하려면 stepType 옵션을 **title**로 설정하십시오.

이렇게 하면 부제목이 정의되어 있을 경우, 부제목도 단계 제목 아래에 렌더링됩니다.

<DocsAside type="info">
이 컨테이너는 크기 제한 없이 필요에 따라 다시 템플릿화할 수 있습니다. 예를 들어 그 안에 24픽셀보다 큰 표시기를 추가할 수 있습니다.
</DocsAside>

### 동적 단계 높이

<ApiLink pkg="core" type="Stepper" />이(가) 가로 방향일 때 콘텐츠 영역의 높이는 콘텐츠가 가장 많은 단계에 의해 결정됩니다. 다른 모든 단계는 이 고정 높이를 공유하므로, 콘텐츠가 적은 단계에서는 빈 공간이 보일 수 있습니다.

고정 높이를 재정의하고 콘텐츠 영역이 활성 단계의 콘텐츠에 맞춰 조정되도록 하려면 **--body-grid-rows** CSS 변수를 **0fr**(기본값은 **1fr**)로 설정하십시오:

```css
igc-stepper {
  --body-grid-rows: 0fr;
}
```

### Stepper 애니메이션

{Platform} <ApiLink pkg="core" type="Stepper" /> 애니메이션은 최종 사용자가 정의된 단계와 상호 작용할 때 아름다운 경험을 제공합니다. 사용 가능한 애니메이션 옵션은 stepper의 방향에 따라 다릅니다.

stepper가 가로 방향이면 기본적으로 `slide` 애니메이션을 사용하도록 구성됩니다. 대안으로 `fade`도 지원합니다. 애니메이션은 <ApiLink pkg="core" type="Stepper" member="horizontalAnimation" label="HorizontalAnimation" /> 입력으로 구성합니다.

세로 방향 레이아웃에서는 <ApiLink pkg="core" type="Stepper" member="verticalAnimation" label="VerticalAnimation" /> 속성으로 애니메이션 유형을 정의할 수 있습니다. 기본값은 `grow`로 설정되어 있으며, 사용자는 `fade`으로도 설정할 수 있습니다.

두 애니메이션 유형 입력 모두를 `none`(으)로 설정하면 stepper 애니메이션이 비활성화됩니다.

<ApiLink pkg="core" type="Stepper" /> 컴포넌트에서는 단계 사이 전환 지속 시간도 구성할 수 있습니다. 이는 숫자를 인수로 받는 <ApiLink pkg="core" type="Stepper" member="animationDuration" label="AnimationDuration" /> 속성으로 설정하며, 두 방향에 공통으로 적용됩니다. 기본값은 320ms입니다.

## 키보드 탐색

{ProductName} Stepper는 최종 사용자에게 다양한 키보드 상호 작용을 제공합니다. 이 기능은 기본적으로 활성화되어 있으며, 최종 사용자가 단계 사이를 쉽게 이동할 수 있게 합니다.
{Platform} <ApiLink pkg="core" type="Stepper" /> 탐색은 [W3 접근성 표준](https://www.w3.org/WAI/ARIA/apg/patterns/tabpanel/)을 준수하며 사용하기 편리합니다.

**키 조합**

- <kbd>TAB</kbd> - 다음 탭 가능한 요소로 포커스를 이동합니다.
- <kbd>SHIFT</kbd> + <kbd>TAB</kbd> - 이전 탭 가능한 요소로 포커스를 이동합니다.
- <kbd>↓</kbd> - stepper가 **세로 방향**일 때 다음 접근 가능한 단계의 헤더로 포커스를 이동합니다.
- <kbd>↑</kbd> - stepper가 **세로 방향**일 때 이전 접근 가능한 단계의 헤더로 포커스를 이동합니다.
- <kbd>←</kbd> - 두 방향 모두에서 이전 접근 가능한 단계의 헤더로 포커스를 이동합니다.
- <kbd>→</kbd> - 두 방향 모두에서 다음 접근 가능한 단계의 헤더로 포커스를 이동합니다.
- <kbd>HOME</kbd> - stepper에서 첫 번째 활성화된 단계의 헤더로 포커스를 이동합니다.
- <kbd>END</kbd> - stepper에서 마지막 활성화된 단계의 헤더로 포커스를 이동합니다.
- <kbd>ENTER</kbd> 또는 <kbd>SPACE</kbd> - 현재 포커스가 있는 단계를 활성화합니다.

## {Platform} Stepper 스타일 지정

아래 나열된 노출된 CSS 파트 중 일부를 사용하여 <ApiLink pkg="core" type="Step" />의 모양을 바꿀 수 있습니다:

| 파트 이름 | 설명 |
| ---------|------------ |
| `header-container` | 단계 헤더와 구분선을 감싸는 래퍼입니다. |
| `disabled` | 비활성 상태를 나타냅니다. header-container에 적용됩니다. |
| `complete-start` | 현재 단계의 완료 상태를 나타냅니다. header-container에 적용됩니다. |
| `complete-end` | 이전 단계의 완료 상태를 나타냅니다. header-container에 적용됩니다. |
| `optional` | 선택적 상태를 나타냅니다. header-container에 적용됩니다. |
| `invalid` | 유효하지 않은 상태를 나타냅니다. header-container에 적용됩니다. |
| `top` | 제목이 표시기 위에 있어야 함을 나타냅니다. header-container에 적용됩니다. |
| `bottom` | 제목이 표시기 아래에 있어야 함을 나타냅니다. header-container에 적용됩니다. |
| `start` | 제목이 표시기 앞에 있어야 함을 나타냅니다. header-container에 적용됩니다. |
| `end` | 제목이 표시기 뒤에 있어야 함을 나타냅니다. header-container에 적용됩니다. |
| `header` | 단계의 표시기와 텍스트를 감싸는 래퍼입니다. |
| `indicator` | 단계의 표시기입니다. |
| `text` | 단계의 제목과 부제목을 감싸는 래퍼입니다. |
| `empty` | 단계에 제목과 부제목이 제공되지 않았음을 나타냅니다. text에 적용됩니다. |
| `title` | 단계의 제목입니다. |
| `subtitle` | 단계의 부제목입니다. |
| `body` | 단계 콘텐츠를 감싸는 래퍼입니다. |
| `content` | 단계의 콘텐츠입니다. |

이러한 CSS 파트를 사용하면 다음과 같이 <ApiLink pkg="core" type="Stepper" /> 컴포넌트의 모양을 사용자 지정할 수 있습니다:

```css
igc-step::part(title) {
  color: var(--ig-primary-500);
}
igc-step[active]::part(indicator) {
  background-color: var(--ig-primary-500);
}
igc-step::part(indicator) {
  background-color: var(--ig-surface-500);
}
```
