# Icon

{ProductName} Icon은 사용자 지정 SVG 아이콘 모음과 같은 등록된 아이콘 세트에서 이름 있는 아이콘을 렌더링하는 컴포넌트입니다.

<PlatformBlock for="Angular">

기본적으로 Angular Icon은 Material Icons 리가처를 렌더링합니다. SVG 아이콘과 기타 아이콘 글꼴을 같은 방식으로 사용하려면 `IgxIconService`을(를) 사용하여 등록하십시오.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

컬렉션에 이름으로 SVG 아이콘을 등록한 다음, 각 아이콘을 테마 기반 크기와 주변 텍스트의 색으로 표시하십시오.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Icon은 등록된 SVG를 shadow root에 그리고 CSS 파트를 노출하지 않는 `igc-icon` 요소를 렌더링합니다:

```text
igc-icon                 // host - inline box sized by --size
└─ #shadow-root
   └─ svg                // the registered SVG, 1em × 1em, filled with the current color
```

</PlatformBlock>

<PlatformBlock for="Angular">

`igx-icon` 요소는 아이콘 제품군의 유형에 따라 다음 중 하나를 렌더링합니다:

```text
igx-icon.igx-icon[aria-hidden="true"]   // host - also carries the family class, e.g. .material-icons
├─ ligature text                        // `liga` family - the icon name, e.g. home
├─ div > svg                            // SVG icon registered with IgxIconService
└─ ng-content                           // projected ligature text when `name` isn't set
```

`font` 제품군의 경우 호스트의 클래스가 글리프를 그리며, 요소에는 콘텐츠가 없습니다.

</PlatformBlock>

## 사용법

레이블, 버튼, 목록 항목 및 탐색에 식별하기 쉬운 기호를 추가하거나, 상태를 한눈에 보여 주려면 {Platform} Icon을 사용하십시오.

<PlatformBlock for="React,WebComponents,Blazor">

### 이름과 컬렉션

{Platform} Icon은 컬렉션 안의 이름으로 등록된 SVG를 그립니다. 컬렉션의 기본값은 `default`입니다. 페이지의 모든 아이콘은 하나의 레지스트리를 공유하므로, 한 번 등록한 아이콘은 모든 Icon에서 사용할 수 있으며, SVG가 등록되기 전에 렌더링된 Icon도 등록되는 즉시 업데이트됩니다.

</PlatformBlock>

<PlatformBlock for="WebComponents">

<ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" />로 SVG 마크업을 등록하거나 <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" />로 URL에서 SVG 파일을 가져오십시오:

```ts
import { registerIcon, registerIconFromText } from 'igniteui-webcomponents';

const searchIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

registerIconFromText('search', searchIcon, 'material');
registerIcon('build', '/icons/build.svg', 'material');
```

그다음 각 아이콘에 같은 이름과 컬렉션을 설정하십시오:

```html
<igc-icon name="search" collection="material"></igc-icon>
<igc-icon name="build" collection="material"></igc-icon>
```

</PlatformBlock>

<PlatformBlock for="React">

<ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" />로 SVG 마크업을 등록하거나 <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" />로 URL에서 SVG 파일을 가져오십시오. 그다음 각 아이콘에 같은 이름과 컬렉션을 설정하십시오:

```tsx
export default function SearchToolbar() {
  useEffect(() => {
    registerIconFromText('search', searchIcon, 'material');
    registerIcon('build', '/icons/build.svg', 'material');
  }, []);

  return (
    <>
      <IgrIcon name="search" collection="material" />
      <IgrIcon name="build" collection="material" />
    </>
  );
}
```

### 이름과 제품군

Angular Icon은 <ApiLink pkg="core" type="Icon" member="family" label="family" />에서 <ApiLink pkg="core" type="Icon" member="name" label="name" />을(를) 찾습니다. 기본 `material` 제품군은 Material Icons 리가처를 렌더링하므로, `home` 또는 `favorite`처럼 이름이 곧 리가처가 됩니다:

```html
<igx-icon name="home"></igx-icon>
<igx-icon name="favorite"></igx-icon>
```

리가처를 콘텐츠로 프로젝션할 수도 있습니다:

```html
<igx-icon>bluetooth</igx-icon>
```

### SVG 아이콘

<ApiLink pkg="core" type="IconService" />로 SVG 아이콘을 등록한 다음 아이콘에 이름과 제품군을 설정하십시오. <ApiLink pkg="core" type="IconService" member="addSvgIcon" label="addSvgIcon" /> 메서드는 URL에서 SVG 파일을 가져오고, <ApiLink pkg="core" type="IconService" member="addSvgIconFromText" label="addSvgIconFromText" />은(는) SVG 마크업을 등록합니다:

```ts
import { Component, OnInit, inject } from '@angular/core';
import { IgxIconComponent, IgxIconService } from 'igniteui-angular/icon';

const searchIcon =
    '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

@Component({
    selector: 'app-filter-icons',
    template: `
        <igx-icon name="contains" family="filter-icons"></igx-icon>
        <igx-icon name="search" family="filter-icons"></igx-icon>
    `,
    imports: [IgxIconComponent]
})
export class FilterIconsComponent implements OnInit {
    private iconService = inject(IgxIconService);

    public ngOnInit() {
        this.iconService.addSvgIcon('contains', 'assets/images/svg/contains.svg', 'filter-icons');
        this.iconService.addSvgIconFromText('search', searchIcon, 'filter-icons');
    }
}
```

SVG 아이콘과 리가처가 같은 이름과 제품군을 공유하면, 아이콘은 SVG를 렌더링합니다.

### 글꼴 제품군

[Material Symbols](https://fonts.google.com/icons)처럼 다른 아이콘 글꼴을 제품군으로 추가하려면 <ApiLink pkg="core" type="IconService" member="setFamily" label="setFamily" />을(를) 사용하십시오. 먼저 글꼴 스타일시트를 로드하십시오:

```html
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" rel="stylesheet" />
```

제품군 이름을 글꼴의 CSS 클래스에 매핑하고 해당 유형을 `liga`(으)로 설정하십시오:

```ts
this.iconService.setFamily('material-symbols', { className: 'material-symbols-outlined', type: 'liga' });
```

그다음 아이콘에 제품군을 설정하십시오. Material Symbols는 가변 글꼴이므로 채우기와 두께 같은 설정을 조정할 수 있습니다:

```html
<igx-icon family="material-symbols" name="diamond" class="custom-icon"></igx-icon>
```

```scss
.custom-icon {
  font-variation-settings: "FILL" 0, "wght" 200, "GRAD" 0, "opsz" 40;
}
```

[Icon Service](../icon-service.mdx) 항목에서는 `font` 유형의 제품군, 이름 접두사 및 아이콘 참조를 다룹니다.

</PlatformBlock>

### 아이콘 참조

아이콘 참조는 아이콘 이름이 다른 등록된 아이콘을 가리키도록 합니다. Combo 및 Date Picker 같은 컴포넌트는 `default` 컬렉션의 참조를 통해 내장 아이콘을 렌더링하며, 사용자가 설정한 참조가 이를 우선합니다. 예를 들어 이 두 컴포넌트의 지우기 아이콘을 대체하려면 `input_clear` 참조가 사용자 자신의 아이콘을 가리키도록 하십시오:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
import { registerIconFromText, setIconRef } from 'igniteui-webcomponents';

const closeIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z"/></svg>';

registerIconFromText('close', closeIcon, 'my-icons');
setIconRef('input_clear', 'default', { name: 'close', collection: 'my-icons' });
```

</PlatformBlock>

### 키보드 상호 작용

{Platform} Icon은 포커스를 받지 않으며 키보드 상호 작용도 없습니다. `tabindex`을(를) 설정하지 않고 키보드나 포인터 이벤트도 처리하지 않습니다. 사용자가 키보드로 아이콘을 활성화해야 할 때는 다음 <PlatformBlock for="Angular">[Icon Button](../icon-button.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Icon Button](../inputs/icon-button.mdx)</PlatformBlock> 을(를) 사용하십시오.

| 키 | 동작 |
| --- | --- |
| n/a | Icon은 키보드로 상호 작용할 수 없습니다. |

### 화면 읽기 프로그램 / ARIA

{Platform} Icon은 자체적으로 알리는 내용이 없습니다. 보조 기술이 보고하는 내용은 아이콘의 접근 가능한 이름에 따라 달라집니다:

<PlatformBlock for="React,WebComponents">

- 아이콘은 `igc-icon` 요소의 속성이 아니라 요소 내부(element internals)를 통해 역할과 접근 가능한 이름을 설정합니다.
- 등록된 아이콘의 루트 `<svg>`의 직계 자식인 `<title>` 요소가 아이콘의 접근 가능한 이름이 됩니다.
- 아이콘의 `aria-label` 또는 `aria-labelledby` 속성은 SVG에 title이 없는 아이콘에 이름을 붙이며, title보다 우선합니다.
- `igniteui-webcomponents` 7.3.0 이상에서는 아이콘이 접근 가능한 이름이 있을 때만 `img` 역할을 선언하므로, 이름이 없는 아이콘이 이름 없는 이미지로 노출되지 않습니다.
- 아이콘은 SVG를 확인할 때 접근 가능한 이름을 검사합니다. 즉 `name` 또는 `collection`가 변경될 때, 테마가 변경될 때, 또는 아이콘이 등록될 때입니다. 초기 마크업에 `aria-label` 또는 `aria-labelledby`를 설정하십시오.
- `stripMeta` 등록 옵션은 저장된 SVG에서 `<title>` 및 `<desc>` 요소를 제거하지만, 아이콘은 title 텍스트를 접근 가능한 이름으로 유지합니다.

</PlatformBlock>

<PlatformBlock for="Blazor">

- 등록된 아이콘의 루트 `<svg>`의 직계 자식인 `<title>` 요소가 아이콘의 접근 가능한 이름이 됩니다.
- 아이콘의 `aria-label` 속성은 SVG에 title이 없는 아이콘에 이름을 붙이며, title보다 우선합니다.
- `aria-hidden="true"` 속성은 장식용 아이콘을 보조 기술에서 숨깁니다.

</PlatformBlock>

<PlatformBlock for="Angular">

- 아이콘은 `ariaHidden` 입력을 통해 기본적으로 `aria-hidden="true"`을(를) 설정하므로 보조 기술이 이를 무시합니다. `aria-label`만으로는 숨겨진 아이콘이 노출되지 않습니다.
- 아이콘은 역할을 설정하지 않습니다. 역할과 레이블 없이 `ariaHidden`을(를) `false`(으)로 설정하면, 스크린 리더는 리가처 아이콘을 `home`처럼 텍스트로 읽습니다.
- 의미를 전달하는 아이콘을 노출하려면 `ariaHidden`을(를) `false`(으)로 설정하고, `img` 역할을 추가한 다음 `aria-label`을(를) 추가하십시오.
- `active` 입력은 스타일만 변경합니다. 비활성 상태는 보조 기술에 노출되지 않습니다.

</PlatformBlock>

## 문제 해결

{Platform} Icon이 렌더링되지 않거나 예상과 다르게 보일 때 다음 답변을 사용하십시오.

### 아이콘이 비어 있는 이유는 무엇입니까?

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Icon은 같은 이름과 컬렉션으로 등록된 SVG만 그립니다. 다음 원인을 확인하십시오:

- 이름 또는 컬렉션이 등록된 값과 정확히 일치하지 않습니다. 컬렉션의 기본값은 `default`입니다.
- SVG 마크업이 잘못되었습니다. 텍스트에 루트 `<svg>` 요소가 없거나 파싱되지 않으면 등록 시 `SVG element not found or malformed SVG string.` 오류가 발생합니다.
- SVG 파일 요청이 실패했습니다. URL에서 등록할 때 OK가 아닌 응답이면 실패하므로, 브라우저 콘솔과 네트워크 패널을 확인하십시오. 다른 출처의 파일도 교차 출처 요청을 허용하는 서버가 필요합니다.

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

서버 측 렌더링 중에는 아이콘이 SVG를 렌더링하지 않습니다. 브라우저에서 로드된 후에 SVG를 그립니다.

</PlatformBlock>

<PlatformBlock for="Angular">

다음 원인을 확인하십시오:

- 리가처 아이콘은 제품군의 글꼴이 필요합니다. 예를 들어 기본 `material` 제품군은 Material Icons 글꼴이 필요합니다. 글꼴 스타일시트가 로드되는지 확인하십시오.
- SVG 아이콘은 등록할 때와 같은 이름과 제품군이 필요합니다.
- `addSvgIcon`은(는) 파일을 가져오기 위해 `HttpClient`이(가) 필요합니다. 실패한 요청이 있는지 네트워크 패널을 확인하십시오.
- 서비스는 SVG 아이콘을 브라우저에서만 캐시하므로, 서버 측 렌더링 중에는 SVG 아이콘이 렌더링되지 않습니다.

</PlatformBlock>

### SVG 아이콘이 테마 색을 따르지 않는 이유는 무엇입니까?

{Platform} Icon은 루트 `<svg>` 요소에 색을 적용하며, 자식 요소는 이를 fill로 상속합니다. 색이 하드코딩된 자식 요소는 그 색을 유지합니다:

```html
<svg viewBox="0 0 24 24">
  <path fill="#050d42" d="..." />
</svg>
```

자식 요소에서 하드코딩된 색을 제거하거나, 테마가 재정의하는 루트 `<svg>` 요소에 색을 설정하십시오. 아이콘의 일부에 의도적으로 색을 주려면 `fill="var(--ig-primary-500)"` 같은 테마 색 변수를 사용하십시오.

### 아이콘에 마우스를 올리면 툴팁이 나타나는 이유는 무엇입니까?

브라우저는 SVG의 `<title>` 요소를 기본 툴팁으로 표시합니다.

<PlatformBlock for="React,WebComponents">

저장된 SVG에서 `<title>` 및 `<desc>` 요소를 제거하려면 `stripMeta` 옵션으로 아이콘을 등록하십시오. 아이콘은 title 텍스트를 접근 가능한 이름으로 유지합니다:

```ts
registerIconFromText('search', searchIcon, { collection: 'material', stripMeta: true });
```

</PlatformBlock>

<PlatformBlock for="Blazor">

등록하기 전에 SVG 마크업에서 `<title>` 요소를 제거하고, 접근 가능한 이름이 필요한 아이콘에는 `aria-label`을(를) 설정하십시오.

</PlatformBlock>

<PlatformBlock for="Angular">

캐시된 SVG에서 `<title>` 및 `<desc>` 요소를 제거하려면 `addSvgIcon` 또는 `addSvgIconFromText`의 `stripMeta` 인수로 `true`을(를) 전달하십시오:

```ts
this.iconService.addSvgIcon('contains', 'assets/images/svg/contains.svg', 'filter-icons', true);
```

</PlatformBlock>

### 알려진 제한 사항

{Platform} Icon에는 다음 제한 사항이 있습니다:

- Icon은 비대화형 시각 요소입니다. 포커스를 받지 않으며 키보드 입력을 처리하지 않습니다.
- 테마 색은 루트 `<svg>` 요소와 그 fill을 상속하는 자식 요소에 적용됩니다. 색이 하드코딩된 자식 요소는 그 색을 유지합니다.
<PlatformBlock for="React,WebComponents,Blazor">- Icon은 등록된 SVG 아이콘만 그립니다. 아이콘 글꼴과 리가처는 지원되지 않습니다.</PlatformBlock><PlatformBlock for="Angular">- Angular Icon에는 오른쪽에서 왼쪽으로 쓰는 레이아웃에서 아이콘을 뒤집는 옵션이 없습니다.</PlatformBlock>
