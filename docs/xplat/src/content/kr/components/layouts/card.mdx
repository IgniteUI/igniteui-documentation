# Card

{ProductName} Card는 관련된 미디어, 텍스트 및 작업을 하나의 유연한 콘텐츠 컨테이너에 정리합니다.

제품, 문서, 연락처, 위치 또는 대시보드 항목처럼 하나의 주제에 대한 콘텐츠를 묶으려면 카드를 사용하십시오.

## 시작하기

{Platform} Card를 사용하려면  <PlatformBlock for="Angular">[{ProductName} 시작하기](../general/getting-started.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[{ProductName} 시작하기](../general-getting-started.mdx)</PlatformBlock> 기본 프로젝트 설정 항목을 참조한 다음, 대상 플랫폼에 맞게 컴포넌트를 등록하십시오.

<PlatformBlock for="React,WebComponents">

**{PackageCommon}** 패키지를 사용하는 {Platform}의 경우, 패키지를 설치하십시오:

```cmd
npm install {PackageCommon}
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

그다음 <ApiLink pkg="core" type="Card" />, 테마 CSS를 import하고 컴포넌트를 등록해야 합니다. 예:

```ts
import { defineComponents, IgcCardComponent } from 'igniteui-webcomponents';
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcCardComponent);
```

카드를 등록하면 카드 헤더, 미디어, 콘텐츠 및 작업 하위 컴포넌트도 함께 등록됩니다. 아바타, 버튼, 아이콘 버튼처럼 카드 콘텐츠에서 사용하는 다른 컴포넌트도 등록하십시오:

```ts
import {
  defineComponents,
  IgcAvatarComponent,
  IgcButtonComponent,
  IgcCardComponent,
  IgcIconButtonComponent,
} from 'igniteui-webcomponents';

defineComponents(IgcCardComponent, IgcAvatarComponent, IgcButtonComponent, IgcIconButtonComponent);
```

</PlatformBlock>

<PlatformBlock for="React">

그다음 다음과 같이 Card 래퍼와 테마 CSS를 가져와야 합니다:

```tsx
import {
  IgrCard,
  IgrCardActions,
  IgrCardContent,
  IgrCardHeader,
  IgrCardMedia,
} from 'igniteui-react';
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

`IgrAvatar`, `IgrButton`, `IgrIconButton`처럼 카드 콘텐츠에서 사용하는 다른 래퍼도 가져오십시오.

</PlatformBlock>

<PlatformBlock for="Blazor">

{ProductName} 서비스를 등록합니다:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

<ApiLink pkg="core" type="Card" />의 클라이언트 리소스 모듈인 <ApiLink pkg="core" type="CardModule" /> 등록은 **선택 사항**입니다. 컴포넌트는 처음 렌더링될 때 리소스를 로드합니다. `builder.Services.AddIgniteUIBlazor(typeof(IgbCardModule))`에 나열하면 리소스를 미리 로드하거나 클라이언트에서만 생성되는 요소를 지원할 수 있습니다([컴포넌트 모듈](../general-getting-started.mdx#컴포넌트-모듈) 참조).

<ApiLink pkg="core" type="Card" /> 컴포넌트에 스타일을 적용하려면 추가 CSS 파일도 연결해야 합니다. 다음 내용을 애플리케이션의 호스트 페이지에 넣어야 합니다(독립 실행형 Blazor WebAssembly 또는 Blazor Hybrid 앱에서는 **wwwroot/index.html**, Blazor Server 앱에서는 **Pages/_Host.cshtml**, Blazor Web App에서는 **Components/App.razor**):

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```

</PlatformBlock>

import { IGX_CARD_DIRECTIVES } from 'igniteui-angular/card';

### 헤더 슬롯

헤더 슬롯을 사용하여 썸네일, 제목, 부제목 및 추가 헤더 콘텐츠를 정의하십시오.

<PlatformBlock for="WebComponents">

```html
<igc-card-header>
  <igc-avatar slot="thumbnail" initials="TS"></igc-avatar>
  <h3 slot="title">Title</h3>
  <span slot="subtitle">Subtitle</span>
</igc-card-header>
```

</PlatformBlock>

<PlatformBlock for="Angular">

```html
<igx-card-header>
  <div igxCardThumbnail>
    <igx-icon>place</igx-icon>
  </div>
  <h3 igxCardHeaderTitle>Title</h3>
  <span igxCardHeaderSubtitle>Subtitle</span>
</igx-card-header>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrCardHeader>
  <IgrAvatar slot="thumbnail" initials="TS" />
  <h3 slot="title">Title</h3>
  <span slot="subtitle">Subtitle</span>
</IgrCardHeader>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCardHeader>
  <IgbAvatar slot="thumbnail" Initials="TS" />
  <h3 slot="title">Title</h3>
  <span slot="subtitle">Subtitle</span>
</IgbCardHeader>
```

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

카드가 문서 개요에서 올바른 위치를 차지하도록 `title` 슬롯에 `<h3>` 같은 제목 요소를 전달하고, `subtitle`에는 `<span>` 같은 중립적인 인라인 요소를 사용하십시오. 헤더는 슬롯 콘텐츠의 여백과 글꼴을 재설정하므로 제목도 카드의 타이포그래피를 유지합니다.

</PlatformBlock>

<PlatformBlock for="Angular">

카드가 문서 개요에서 올바른 위치를 차지하도록 `<h3>` 같은 제목 요소에 `igxCardHeaderTitle`을(를) 적용하고, `<span>` 같은 중립적인 인라인 요소에 `igxCardHeaderSubtitle`을(를) 적용하십시오.

</PlatformBlock>

### 작업 방향

<PlatformBlock for="WebComponents, React, Blazor">

<ApiLink pkg="core" type="CardActions" member="orientation" label="orientation" /> 속성을 사용하여 <ApiLink pkg="core" type="CardActions" /> 콘텐츠를 가로 또는 세로로 배치하십시오. 작업은 기본적으로 가로로 배치되므로, 세로로 쌓으려면 `orientation`을(를) `vertical`(으)로 설정하십시오.

</PlatformBlock>

<PlatformBlock for="Angular">

작업을 세로로 배치해야 할 때는 `igx-card-actions`에 `vertical`을(를) 설정하십시오.

</PlatformBlock>

</PlatformBlock>

## 접근성

카드는 컨테이너입니다. 그룹화와 미디어 시맨틱은 카드 영역에서 오며, 키보드 조작 가능성과 접근 가능한 이름은 그 안에 배치하는 콘텐츠에서 나옵니다.

### 키보드 상호 작용

카드와 헤더, 미디어, 콘텐츠 및 작업 영역은 키 핸들러를 선언하지 않으며 탭 순서에도 포함되지 않습니다. 포커스는 DOM 순서에 따라 그 안에 배치한 포커스 가능한 콘텐츠를 통해 이동합니다.

| 키 | 동작 |
| -- | -- |
| <kbd>탭</kbd> | 콘텐츠 또는 작업 영역의 버튼이나 링크처럼 카드 안의 다음 포커스 가능한 요소로 포커스를 이동합니다. |
| <kbd>Shift</kbd> + <kbd>Tab</kbd> | 카드 안의 이전 포커스 가능한 요소로 포커스를 이동합니다. |

작업 영역은 항상 시작 영역, 가운데 콘텐츠, 끝 영역 순으로 렌더링됩니다. 작업을 세로 레이아웃으로 전환해도 DOM 순서는 바뀌지 않고 스타일만 달라지므로, 키보드와 스크린 리더의 순서는 그대로 유지됩니다.

### 화면 읽기 프로그램 / ARIA

<PlatformBlock for="Angular">

- 카드 호스트는 `role="group"`과(와) 생성된 `id`을(를) `igx-card-1` 형태로 렌더링합니다. 정보 구조에 다른 그룹화 역할이 더 적합하다면 `role` 입력을 설정하고, 그룹이 접근 가능한 이름을 갖도록 `aria-labelledby`로 카드 제목을 참조하십시오.
- `igx-card-media`은(는) 미디어 영역 전체를 하나의 이미지로 노출하고 하위 요소를 프레젠테이션 요소로 만드는 `role="img"`을(를) 렌더링하므로, 내부 이미지의 `alt` 속성으로는 이름을 붙일 수 없습니다. 영역 자체에 `aria-label` 또는 `aria-labelledby`로 이름을 붙이거나, 미디어가 장식용이라면 `role` 입력을 `presentation`(으)로 설정하십시오.

- 카드 전체가 하나의 작업을 실행하는 경우에는 컨테이너에 클릭 핸들러를 붙이지 말고 단일 대화형 요소를 사용하십시오. 그래야 작업이 역할과 이름을 유지합니다.
