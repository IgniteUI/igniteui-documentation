## 시작하기

<PlatformBlock for="Angular">

Angular 애플리케이션에 설치된 {ProductName} 버전으로 아코디언을 사용하십시오. 독립 실행형 아코디언 디렉티브를 가져오기 전에 공통 [시작하기](../general/getting-started.mdx) 토픽을 완료하십시오.

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

애플리케이션에 설치된 {ProductName} 버전과 함께 아코디언을 사용하십시오. 프레임워크별 가져오기 또는 등록을 추가하기 전에 공통 [시작하기](../general-getting-started.mdx) 항목을 완료하십시오.

</PlatformBlock>

<PlatformBlock for="Angular">

컴포넌트를 사용하기 전에 독립형 아코디언 디렉티브를 가져오십시오.

```ts
import { Component } from '@angular/core';
import { IGX_ACCORDION_DIRECTIVES } from 'igniteui-angular/accordion';

@Component({
  selector: 'app-accordion',
  imports: [IGX_ACCORDION_DIRECTIVES],
  templateUrl: './accordion.component.html',
})
export class AccordionComponent {}
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

사용하기 전에 아코디언과 확장 패널 컴포넌트를 등록하십시오.

```ts
import {
  defineComponents,
  IgcAccordionComponent,
  IgcExpansionPanelComponent,
} from 'igniteui-webcomponents';

defineComponents(IgcAccordionComponent, IgcExpansionPanelComponent);
```

</PlatformBlock>

<PlatformBlock for="React">

아코디언을 렌더링하기 전에 React 래퍼와 테마 스타일시트를 가져오십시오.

```tsx

import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

</PlatformBlock>

<PlatformBlock for="Blazor">

{ProductName} 서비스를 등록합니다:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

아코디언의 클라이언트 리소스 모듈인 <ApiLink pkg="core" type="AccordionModule" />을(를) 등록하는 것은 **선택 사항**입니다. 컴포넌트는 처음 렌더링될 때 리소스를 로드합니다. `builder.Services.AddIgniteUIBlazor(typeof(IgbAccordionModule))`에 나열하면 리소스를 미리 로드하거나 클라이언트에서만 만들어지는 요소를 지원할 수 있습니다([컴포넌트 모듈](../general-getting-started.mdx#컴포넌트-모듈) 참조).

호스트 페이지에 테마 스타일시트를 추가하십시오.


### 프로그래밍 방식 확장

<PlatformBlock for="Angular">

<ApiLink type="Accordion" member="collapseAll" label="collapseAll()" />과(와) <ApiLink type="Accordion" member="expandAll" label="expandAll()" />을(를) 사용하여 코드에서 아코디언 패널을 접거나 펼칩니다.

<DocsAside type="info">
<ApiLink type="Accordion" member="singleBranchExpand" label="singleBranchExpand" />이(가) `true`일 때 <ApiLink type="Accordion" member="expandAll" label="expandAll()" />을(를) 호출하면 마지막으로 활성화된 패널만 확장됩니다.
</DocsAside>

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

### 사용 여부

### 화면 읽기 프로그램 / ARIA

아코디언의 접근성 시맨틱은 자식 확장 패널과 그 헤더를 통해 제공됩니다.

- 각 패널 헤더는 `role="button"`, `aria-expanded`, `aria-controls`을(를) 노출합니다.
- 각 패널 본문은 `role="region"`을(를) 노출하며, `aria-labelledby` 또는 `aria-label`을(를) 통해 레이블을 제공합니다.
- 보조 기술이 의미 있는 레이블을 읽을 수 있도록 각 패널에 명확한 제목 텍스트를 사용하십시오.
- 패널 본문 안의 대화형 콘텐츠는 논리적인 탭 순서를 유지하십시오.

Infragistics는 {ProductName}의 Section 508 및 WCAG 2.1 지침 영역에 대한 접근성 지원을 [접근성 준수](../interactivity/accessibility-compliance.mdx) 항목에 문서화합니다. 아코디언의 준수 근거는 대화형 헤더와 영역을 제공하는 자식 <ApiLink pkg="core" type="ExpansionPanel" /> 컴포넌트에서 나옵니다.
