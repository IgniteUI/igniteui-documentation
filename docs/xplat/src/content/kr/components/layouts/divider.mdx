
### 들여쓰기 Divider

<ApiLink pkg="core" type="Divider" />은(는) 양쪽에 설정할 수 있습니다. 구분선을 `inset`하려면 `--inset` CSS 변수와 함께 <ApiLink pkg="core" type="Divider" member="middle" label="Middle" /> 속성을 true로 설정하십시오. 그러면 구분선이 양쪽에서 줄어듭니다. <ApiLink pkg="core" type="Divider" member="middle" label="Middle" /> 속성의 기본값은 false입니다.

```css
/* DividerStyles.css */
.withInset{
    --inset: 100px;
    --color:red;
}
```

<PlatformBlock for="WebComponents">

```html
// Both side
<igc-divider middle="true" class="withInset"></igc-divider>
// Left side only
<igc-divider></igc-divider>
```

</PlatformBlock>


<PlatformBlock for="React">

```tsx
// Both side
<IgrDivider middle="true" className="withInset"></IgrDivider>
// Left side only
<IgrDivider  className="withInset"></IgrDivider>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
// Both side
<IgbDivider Middle="True" class="withInset"></IgbDivider>
// Left side only
<IgbDivider class="withInset"></IgbDivider>
```

</PlatformBlock>

## CSS 변수
### 인셋
`--inset` CSS 변수는 시작 지점에서 지정한 값만큼 구분선을 줄입니다. 가운데가 설정되면 양쪽에서 줄어듭니다.

### Color
`--color` CSS 변수는 구분선의 색을 설정합니다.
