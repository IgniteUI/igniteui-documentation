# {Platform} Splitter 개요

{ProductName} Splitter는 콘텐츠를 `start`과(와) `end`의 두 영역으로 나누는 크기 조정 가능한 분할 패널 레이아웃을 제공합니다. 사용자는 스플리터 막대를 끌거나, 키보드 단축키를 사용하거나, 내장 컨트롤로 패널을 접고 펼칠 수 있습니다. 스플리터를 중첩하여 복잡한 대시보드형 레이아웃을 만들 수도 있습니다.

## {Platform} Splitter 사용하기

`start` 및 `end` 슬롯을 사용하여 패널 콘텐츠를 배치하십시오:

<PlatformBlock for="WebComponents">

```html
<igc-splitter style="height: 400px;">
  <div slot="start">Start pane content</div>
  <div slot="end">End pane content</div>
</igc-splitter>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrSplitter>
  <div slot="start">Start pane content</div>
  <div slot="end">End pane content</div>
</IgrSplitter>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbSplitter>
  <div slot="start">Start pane content</div>
  <div slot="end">End pane content</div>
</IgbSplitter>
```

</PlatformBlock>

Splitter 컴포넌트의 `start` 및 `end` 슬롯에는 `<div>` 또는 `<section>`나 `<article>` 같은 시맨틱 요소를 사용하는 것을 권장합니다.

### 방향

패널 방향을 제어하려면 <ApiLink pkg="core" type="Splitter" member="orientation" label="Orientation" /> 속성을 설정하십시오:

- `horizontal`(기본값): 시작 패널과 끝 패널이 왼쪽과 오른쪽에 렌더링됩니다.
- `vertical`: 시작 패널과 끝 패널이 위와 아래에 렌더링됩니다.

<PlatformBlock for="WebComponents">

```html
<igc-splitter orientation="vertical" style="height: 400px;">
  <div slot="start">Top pane</div>
  <div slot="end">Bottom pane</div>
</igc-splitter>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrSplitter orientation="vertical">
  <div slot="start">Top pane</div>
  <div slot="end">Bottom pane</div>
</IgrSplitter>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbSplitter Orientation="SplitterOrientation.Vertical">
  <div slot="start">Top pane</div>
  <div slot="end">Bottom pane</div>
</IgbSplitter>
```

</PlatformBlock>

### 접기 및 크기 조정

다음 속성을 사용하여 상호 작용을 제어하십시오:

- <ApiLink pkg="core" type="Splitter" member="disableResize" label="DisableResize" />: 패널 크기 조정을 비활성화합니다.
- <ApiLink pkg="core" type="Splitter" member="disableCollapse" label="DisableCollapse" />: 패널 접기를 비활성화합니다.
- <ApiLink pkg="core" type="Splitter" member="hideDragHandle" label="HideDragHandle" />: 끌기 핸들을 숨깁니다.
- <ApiLink pkg="core" type="Splitter" member="hideCollapseButtons" label="HideCollapseButtons" />: 접기 및 펼치기 버튼을 숨깁니다.

프로그래밍 방식으로 패널을 접거나 펼칠 수도 있습니다:

<PlatformBlock for="WebComponents">

```ts
const splitter = document.querySelector('igc-splitter') as IgcSplitterComponent;

splitter.toggle('start'); // collapse start pane
splitter.toggle('start'); // expand start pane
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
import { useRef } from 'react';

const splitterRef = useRef<IgrSplitterComponent>(null);

const toggleStartPane = () => {
  splitterRef.current?.toggle('start');
};
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbSplitter @ref="SplitterRef">
  <div slot="start">Start pane</div>
  <div slot="end">End pane</div>
</IgbSplitter>

@code {
    private IgbSplitter SplitterRef;

    public async Task ToggleStartPane()
    {
      this.SplitterRef.Toggle(PanePosition.Start);
    }
}
```

</PlatformBlock>

## 이벤트

Splitter는 크기 조정 작업 중에 다음 이벤트를 발생시킵니다:

<PlatformBlock for="WebComponents">

- `igcResizeStart`: 크기 조정이 시작될 때 한 번 발생합니다.
- `igcResizing`: 크기 조정 중에 계속 발생합니다.
- `igcResizeEnd`: 크기 조정이 끝날 때 한 번 발생합니다.

이벤트 세부 정보에는 진행 중인 이벤트와 종료 이벤트에 대한 현재 `startPanelSize`, `endPanelSize`, `delta`이(가) 포함됩니다.

</PlatformBlock>

<PlatformBlock for="React, Blazor">

- <ApiLink type="Splitter" member="onResizeStart" label="ResizeStart" />: 크기 조정이 시작될 때 한 번 발생합니다.
- <ApiLink type="Splitter" member="onResizing" label="Resizing" />: 크기 조정 중에 계속 발생합니다.
- <ApiLink type="Splitter" member="onResizeEnd" label="ResizeEnd" />: 크기 조정이 끝날 때 한 번 발생합니다.

이벤트 세부 정보에는 진행 중인 이벤트와 종료 이벤트에 대한 현재 `StartPanelSize`, `EndPanelSize`, `Delta`이(가) 포함됩니다.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
const splitter = document.querySelector('igc-splitter');

splitter?.addEventListener('igcResizeEnd', (event: CustomEvent) => {
  console.log(event.detail.startPanelSize, event.detail.endPanelSize, event.detail.delta);
});
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const handleResizeEnd = (event: CustomEvent<IgcSplitterResizeEventArgs>) => {
  console.log(event.detail.startPanelSize, event.detail.endPanelSize, event.detail.delta);
};

<IgrSplitter onResizeEnd={handleResizeEnd}>
  <div slot="start">Start pane</div>
  <div slot="end">End pane</div>
</IgrSplitter>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbSplitter ResizeEnd="OnResizeEnd">
  <div slot="start">Start pane</div>
  <div slot="end">End pane</div>
</IgbSplitter>

@code {
    public void OnResizeEnd(IgbSplitterResizeEventArgs e)
    {
        Console.WriteLine($"StartPanelSize: {e.Detail.StartPanelSize}, EndPanelSize: {e.Detail.EndPanelSize}");
    }
}
```

</PlatformBlock>

## 키보드 탐색

스플리터 막대에 포커스가 있을 때:

| 키 | 설명 |
| ---- | ----------- |
| <kbd>Arrow Left</kbd> / <kbd>Arrow Right</kbd> | 가로 방향에서 패널 크기 조정 |
| <kbd>Arrow Up</kbd> / <kbd>Arrow Down</kbd> | 세로 방향에서 패널 크기 조정 |
| <kbd>Home</kbd> | 시작 패널을 최소 크기로 맞춤 |
| <kbd>End</kbd> | 시작 패널을 최대 크기로 맞춤 |
| <kbd>Ctrl</kbd> + <kbd>Arrow Left</kbd> / <kbd>Arrow Up</kbd> | 시작 패널을 접거나 펼침 |
| <kbd>Ctrl</kbd> + <kbd>Arrow Right</kbd> / <kbd>Arrow Down</kbd> | 끝 패널을 접거나 펼침 |

## 스타일링

<ApiLink pkg="core" type="Splitter" /> 컴포넌트는 스타일 지정을 위해 다음 CSS 파트를 노출합니다:

| 이름 | 설명 |
| ---- | ----------- |
| `splitter-bar` | 패널 사이의 끌 수 있는 구분선입니다. |
| `drag-handle` | 스플리터 막대의 끌기 핸들 요소입니다. |
| `start-pane` | 시작 패널 컨테이너입니다. |
| `end-pane` | 끝 패널 컨테이너입니다. |
| `start-collapse-btn` | 시작 패널을 접는 버튼입니다. |
| `end-collapse-btn` | 끝 패널을 접는 버튼입니다. |
| `start-expand-btn` | 시작 패널을 펼치는 버튼입니다. |
| `end-expand-btn` | 끝 패널을 펼치는 버튼입니다. |

다음을 포함한 테마 CSS 변수도 지원합니다:

- `--bar-color`
- `--handle-color`
- `--expander-color`
- `--bar-color-active`
- `--handle-color-active`
- `--expander-color-active`
- `--focus-color`
- `--size`

```css
igc-splitter {
  --bar-color: #011627;
  --handle-color: #ecaa53;
  --expander-color: #ecaa53;
  --bar-color-active: #011627;
  --handle-color-active: #ecaa53;
  --expander-color-active: #ecaa53;
  --focus-color: #ecaa53;
}
```
