# Tabs

{ProductName} Tabs 컴포넌트는 같은 계층 수준의 관련 콘텐츠를 탭으로 정리하고 선택된 탭의 콘텐츠를 표시합니다.

<PlatformBlock for="Angular">

Angular Tabs 컴포넌트의 선택기는 `igx-tabs`입니다. 그 안의 각 `igx-tab-item`는 탭 헤더와, 탭이 선택되었을 때 Tabs 컴포넌트가 표시하는 콘텐츠를 가집니다.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

각 탭은 헤더와 콘텐츠를 하나의 요소 안에 가집니다. Tabs 컴포넌트는 키보드 탐색을 지원하며, 탭 헤더가 들어가지 않을 때는 스크롤 버튼을 표시합니다.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

`igc-tabs` 요소는 헤더 스트립과 스크롤 버튼을 렌더링합니다. 각 `igc-tab`는 자신의 헤더와 콘텐츠를 렌더링하며, Tabs 컴포넌트는 모든 탭의 콘텐츠를 헤더 스트립 아래에 배치합니다<PlatformBlock for="WebComponents">, 탭 헤더가 열을 이루는 경우에는 그 옆에 배치합니다</PlatformBlock>:

```text
igc-tabs[role="tablist"]
└─ #shadow-root
   └─ div[part="tabs"]                                 // the scrollable header strip
      └─ div[part="inner"]
         ├─ igc-icon-button[part="start-scroll-button"] // rendered when the headers overflow
         ├─ slot                                       // the igc-tab elements
         │  └─ igc-tab
         │     └─ #shadow-root
         │        ├─ div[part="tab-header"][role="tab"]
         │        │  └─ div[part="base"]
         │        │     ├─ slot[name="prefix"][part="prefix"]
         │        │     ├─ div[part="content"]
         │        │     │  └─ slot[name="label"]        // falls back to the label property
         │        │     └─ slot[name="suffix"][part="suffix"]
         │        └─ div[part="tab-body"][role="tabpanel"] // visible only for the selected tab
         │           └─ slot                           // the content of the tab
         ├─ igc-icon-button[part="end-scroll-button"]   // rendered when the headers overflow
         └─ div[part="selected-indicator"]
            └─ span                                    // follows the selected tab header
```

</PlatformBlock>

<PlatformBlock for="Angular">

`igx-tabs` 요소는 각 탭 항목의 `igx-tab-header`에서 헤더 스트립을, 각 탭 항목의 `igx-tab-content`에서 콘텐츠 영역을 렌더링합니다:

```text
igx-tabs.igx-tabs
├─ div.igx-tabs-header
│  ├─ button.igx-tabs-header-button                 // start scroll button, hidden when the headers fit
│  ├─ div.igx-tabs-header__content
│  │  └─ div.igx-tabs-header__wrapper[role="tablist"]
│  │     ├─ div.igx-tabs-header-scroll
│  │     │  └─ igx-tab-header[role="tab"]          // one for each igx-tab-item
│  │     │     ├─ [igxPrefix]
│  │     │     ├─ div.igx-tab-header__inner        // [igxTabHeaderIcon] above [igxTabHeaderLabel]
│  │     │     └─ [igxSuffix]
│  │     └─ div.igx-tabs-header__active-indicator
│  └─ button.igx-tabs-header-button                 // end scroll button, hidden when the headers fit
└─ div.igx-tabs-content
   └─ igx-tab-content[role="tabpanel"]             // one for each igx-tab-item; renders its content only when selected
```

</PlatformBlock>

```

import { Component } from '@angular/core';
import { IGX_TABS_DIRECTIVES } from 'igniteui-angular/tabs';

                </igx-tab-header>

            </igx-tab-item>

                </igx-tab-header>

            </igx-tab-item>
        </igx-tabs>
    `,
    imports: [IGX_TABS_DIRECTIVES]
})
export class HomeComponent {}
```

## 사용법

같은 정보의 서로 다른 보기를 정리하거나 비슷하거나 관련된 데이터 세트 사이를 전환하려면 {Platform} Tabs를 사용하십시오.

### 타입

탭에는 두 가지 유형이 있습니다. Short는 기본적으로 텍스트만 표시하며 접두사 및 접미사 아이콘을 선택적으로 추가할 수 있습니다. Tall은 텍스트 위에 추가로 세 번째 아이콘도 표시합니다.

<PlatformBlock for="React,WebComponents,Blazor">

짧은 탭에는 탭의 `label`을(를) 설정하십시오. 긴 탭에는 대신 `label` 슬롯에 Icon과 `<span>`을(를) 배치하면 Tabs 컴포넌트가 텍스트 위에 아이콘을 표시합니다. `label` 슬롯이 `label` 속성보다 우선합니다. [Icon](./icon.mdx) 항목에 설명된 대로 먼저 아이콘을 등록하십시오:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-tabs>

</igc-tabs>

    <igc-icon slot="label" name="shopping_basket" collection="material"></igc-icon>
    <span slot="label">Cart</span>
  </igc-tab>
  <igc-tab>
    <igc-icon slot="label" name="delivery" collection="material"></igc-icon>
    <span slot="label">Shipping</span>
  </igc-tab>
</igc-tabs>
```

짧은 탭에는 `igx-tab-header` 안에 <ApiLink pkg="core" type="TabHeaderLabelDirective" label="igxTabHeaderLabel" /> 디렉티브를 사용하는 `<span>`을(를) 배치하십시오. 긴 탭에는 <ApiLink pkg="core" type="TabHeaderIconDirective" label="igxTabHeaderIcon" /> 디렉티브를 사용하는 `igx-icon`도 추가하면 Tabs 컴포넌트가 텍스트 위에 아이콘을 표시합니다. 컴포넌트의 `imports`에 `IGX_TABS_DIRECTIVES`과(와) 함께 `IgxIconComponent`을(를) 추가하십시오:

```html
<igx-tabs>
  <igx-tab-item>
    <igx-tab-header>
      <igx-icon igxTabHeaderIcon>shopping_basket</igx-icon>
      <span igxTabHeaderLabel>Cart</span>
    </igx-tab-header>
    <igx-tab-content>The cart content.</igx-tab-content>
  </igx-tab-item>
  <igx-tab-item>
    <igx-tab-header>
      <igx-icon igxTabHeaderIcon>local_shipping</igx-icon>
      <span igxTabHeaderLabel>Shipping</span>
    </igx-tab-header>
    <igx-tab-content>The shipping content.</igx-tab-content>
  </igx-tab-item>
</igx-tabs>
```

레이블 앞뒤에 아이콘이나 배지 같은 콘텐츠를 표시하려면 `igxPrefix` 및 `igxSuffix` 디렉티브를 사용하여 `igx-tab-header`에 추가하십시오. 아래 배지에는 `imports`에 `IgxBadgeComponent`도 필요합니다:

```html
<igx-tab-header>
  <igx-icon igxPrefix>inbox</igx-icon>
  <span igxTabHeaderLabel>Inbox</span>
  <igx-badge igxSuffix [value]="12"></igx-badge>
</igx-tab-header>
```

### 반응형 동작

Tabs는 너비를 조정하여 사용 가능한 가로 공간을 채우는 Content Fit으로 설정하거나, 많은 탭 항목을 탐색하기 위한 스크롤 버튼이 있는 Fixed로 설정할 수 있습니다. 이 방식은 같은 전체 공간에서 다른 모드로는 일반적으로 가능한 것보다 더 많은 콘텐츠를 담을 수 있게 합니다.

- `justify`: 탭 헤더가 Tabs의 너비를 채우도록 늘어납니다. Content Fit 모드에서 사용하십시오.

### Sass 테마 지정

기본 속성을 변경하면 관련된 모든 종속 속성이 변경 사항을 반영하도록 자동으로 업데이트됩니다. 다음 <PlatformBlock for="Angular"><ApiLink kind="sass" module="themes" type="function-tabs-theme" label="tabs-theme" code={true} /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">`tabs-theme`</PlatformBlock> 함수의 기본 매개변수는 `$item-background`이며, 테마는 이로부터 모든 탭 상태의 색을 도출합니다. 또한 `$item-active-color`은(는) 표시기 색을 도출하는 데 사용됩니다. 함수로 테마를 만들고, 이를 `tokens()` 믹스인으로 포함하십시오. 이 믹스인은 포함된 범위에 일치하는 `--ig-tabs-*` 변수를 생성합니다.

<PlatformBlock for="Angular">

```scss
@use "igniteui-angular/theming" as *;

$custom-tabs-theme: tabs-theme(
  $item-background: #292826,
  $item-active-color: #f4d45c
);

:host {
  @include tokens($custom-tabs-theme);
}
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Sass 함수는 `igniteui-theming` 패키지에서 제공됩니다. Sass 설정은 [테마 지정](../themes/overview.mdx) 항목을 참조하십시오.

```scss

```

## 접근성

{Platform} Tabs 컴포넌트는 WAI-ARIA 탭 패턴의 역할을 사용합니다. 사용자는 Tab 키로 탭 헤더에 도달하고, 화살표 키로 탭 사이를 이동하며, 탭을 선택해 콘텐츠를 표시합니다.

### 키보드 상호 작용

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Tabs 컴포넌트의 헤더 스트립은 하나의 탭 정지 지점입니다. 선택된 탭 헤더만 탭 순서에 포함되며, 선택된 탭이 없으면 비활성화되지 않은 첫 번째 탭 헤더가 포함됩니다. 선택된 탭의 콘텐츠가 다음 탭 정지 지점입니다. 탭 헤더에 포커스가 있을 때 다음 키가 작동합니다:

- 이 키들의 기본 동작을 막으므로, 포커스를 이동하는 화살표 키, Home, End, Space가 페이지를 스크롤하지 않습니다.
- 누르고 있는 키는 동작을 반복하지 않습니다.
- Shift, Ctrl, Alt, Meta와 함께 누른 키는 아무 동작도 하지 않습니다.
- Tabs 컴포넌트는 포커스를 받는 헤더가 보이도록 스크롤합니다.

포인터를 사용하면 탭 헤더를 클릭하여 탭에 포커스를 주고 선택합니다. 비활성화된 탭은 클릭을 무시합니다. 스크롤 버튼은 탭 순서에 포함되지 않습니다.

### 화면 읽기 프로그램 / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

{Platform} Tabs 컴포넌트는 다음 역할과 속성을 렌더링합니다:

| 요소 | 역할 | 어트리뷰트 |
| --- | --- | --- |
| `igc-tabs` | `tablist` | `aria-orientation="horizontal"`<PlatformBlock for="WebComponents">, 또는 탭 헤더 열에서는 `aria-orientation="vertical"`</PlatformBlock>, 요소 내부(element internals)를 통해 설정됩니다 |
| 각 탭의 `tab-header` 파트 | `tab` | 탭의 콘텐츠, `aria-posinset`, `aria-setsize`을(를) 가리키는 `aria-selected`, `aria-disabled`, `aria-controls` |
| 각 탭의 `tab-body` 파트 | `tabpanel` | 탭의 헤더를 가리키는 `aria-labelledby` |

{Platform} Tabs 컴포넌트는 보조 기술에 대해 다음과 같이 동작합니다:

- 탭은 헤더 콘텐츠에서 접근 가능한 이름을 가져옵니다. 즉 `label` 속성 또는 `label` 슬롯, 그리고 `prefix` 및 `suffix` 슬롯의 콘텐츠입니다.
- 선택되지 않은 탭의 콘텐츠는 숨겨지고 `inert`이(가) 설정되므로, 보조 기술과 키보드가 이를 건너뜁니다.
- 각 탭 헤더의 `aria-posinset` 및 `aria-setsize` 속성은 스크린 리더에 "3개 중 2번째"와 같이 세트 안에서 탭의 위치를 알려 줍니다.
- Tabs 컴포넌트는 라이브 영역을 사용하지 않습니다. 변경된 선택은 `aria-selected` 상태와 포커스를 통해 보조 기술에 전달됩니다.

</PlatformBlock>

<PlatformBlock for="Angular">

Angular Tabs 컴포넌트는 다음 역할과 속성을 렌더링합니다:

| 요소 | 역할 | 어트리뷰트 |
| --- | --- | --- |
| 헤더에 있는 `div.igx-tabs-header__wrapper` 요소 | `tablist` | `aria-orientation="horizontal"`, 또는 탭 헤더 열에서는 `aria-orientation="vertical"` |
| `igx-tab-header` | `tab` | `aria-selected`, `aria-disabled`, 그리고 탭 항목에 콘텐츠가 있을 때는 콘텐츠를 가리키는 `id`과(와) `aria-controls` |
| `igx-tab-content` | `tabpanel` | 탭 항목의 헤더를 가리키는 `aria-labelledby` |

Angular Tabs 컴포넌트는 보조 기술에 대해 다음과 같이 동작합니다:

- 탭은 `igx-tab-header`의 콘텐츠에서 접근 가능한 이름을 가져옵니다.
- Tabs 컴포넌트는 선택된 탭 항목의 콘텐츠만 렌더링하므로, 다른 탭 항목의 콘텐츠는 DOM에 없습니다.
- 라우터를 구동하는 탭처럼 `igx-tab-content`이(가) 없는 탭 항목에는 `id`과(와) `aria-controls`이(가) 설정되지 않습니다.
- Tabs 컴포넌트는 라이브 영역을 사용하지 않습니다. 변경된 선택은 `aria-selected` 상태와 포커스를 통해 보조 기술에 전달됩니다.

</PlatformBlock>

| 기준 | 컴포넌트가 준수하는 방식 |

사용자의 책임:

- 모든 탭에 콘텐츠를 나타내는 텍스트 레이블을 제공하십시오. 탭은 헤더 콘텐츠에서 접근 가능한 이름을 가져오므로, 아이콘만 있는 헤더에는 텍스트 대체 수단이 필요합니다. [유형](#타입)을 참조하십시오.

- 순차적인 프로세스의 단계에는 Tabs를 사용하지 마십시오. 단계의 순서를 전달하는 Stepper를 사용하십시오.

Angular Tabs의 `selectedIndexChanging` 이벤트를 처리하고, 예를 들어 탭 안의 양식에 저장되지 않은 변경 사항이 있는 동안 현재 탭을 유지하려면 `cancel`을(를) `true`(으)로 설정하십시오. 탭을 항상 사용할 수 없게 하려면 탭 항목에 `disabled`을(를) 설정하십시오.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">{Platform} Tabs 컴포넌트는 선택이 바뀐 후에 change 이벤트를 발생시키므로, {Platform} Tabs 컴포넌트의 change 이벤트는 취소할 수 없습니다. 사용자가 열면 안 되는 탭에는 `disabled`을(를) 설정하고, 사용할 수 있게 되면 활성화하십시오.</PlatformBlock>
