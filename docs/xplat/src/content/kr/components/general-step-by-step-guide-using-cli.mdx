# Ignite UI CLI를 사용한 단계별 가이드

Ignite UI CLI 단계별 모드는 {ProductName} 프로젝트의 프로젝트 생성, 템플릿 선택, 테마 지정, 컴포넌트 뷰 추가를 안내하는 대화형 마법사입니다. 비대화형 `ig new` 및 `ig add` 명령과 같은 작업을 다루지만, 모든 인수를 미리 요구하는 대신 각 단계에서 질문합니다.

단계별 모드는 스크립트나 비대화형 사용을 지원하지 않습니다. 이를 위해서는 명시적인 인수와 함께 `ig new` 및 `ig add` 명령을 사용하십시오. 마법사는 `Inquirer.js`에 의존합니다. 호환성은 [지원되는 터미널](https://github.com/SBoudrias/Inquirer.js#support-os-terminals)을 참조하십시오. 전체 CLI 참조는 [Ignite UI CLI 개요](./general-cli-overview.mdx)를 참조하십시오.

마법사를 실행하려면 다음을 실행하십시오:

```cmd
ig
```

또는:

```cmd
ig new
```

## 새 프로젝트 만들기

마법사는 프로젝트 이름 지정, 프레임워크와 유형 선택, 템플릿 선택, 테마 지정을 순서대로 안내합니다. 각 단계는 옵션을 대화형 목록으로 표시하며, 화살표 키로 이동하고 ENTER로 확인합니다.

### 프로젝트 이름 입력

먼저 애플리케이션의 이름을 입력하라는 메시지가 표시됩니다. 프로젝트는 같은 이름의 디렉터리 안에 만들어집니다.

### 프로젝트 템플릿 선택

**Side Navigation** 또는 **Side Navigation Mini**를 선택하면, 마법사는 프로젝트에 인증을 추가할지 묻는 추가 단계를 보여 줍니다. 예라고 답하면 해당 인증 변형(`side-nav-auth` 또는 `side-nav-mini-auth`)이 생성됩니다. **Empty**를 선택하면 인증 프롬프트는 건너뜁니다.

### 테마 선택

애플리케이션의 테마를 선택하십시오:

- **default** 옵션은 기본 {ProductName} 테마가 포함된 사전 컴파일된 CSS 파일을 포함합니다.
- **custom** 옵션은 [Theming API](./themes/overview.mdx)를 사용하여 Sass 기반 색상 팔레트와 테마 구성을 생성합니다.

### AI 도구 구성

테마 지정 후 마법사는 AI 코딩 어시스턴트를 구성하라고 요청합니다. 먼저 MCP 서버 구성을 받을 어시스턴트를 선택하십시오:

```bash
? Which AI coding assistants do you want to configure MCP servers for? (Press <space> to select)
❯◉ VS Code (GitHub Copilot)
 ◉ Cursor
 ◯ Generic (.mcp.json)
 ◯ Gemini CLI
 ◯ JetBrains (AI Assistant)
 ◯ None
```

다음으로 스킬 파일을 받을 AI 에이전트를 선택하십시오:

```bash
? Which AI agents should receive skill files? (Press <space> to select)
❯◉ GitHub Copilot (.agents/skills/)
 ◉ Claude (.claude/skills/)
 ◉ Cursor (.cursor/rules/)
 ◯ Codex (.codex/)
 ◯ Windsurf (.windsurfrules)
 ◯ Gemini CLI (.gemini/)
 ◯ JetBrains Junie (.junie/guidelines/)
 ◯ None
```

화살표 키로 옵션을 이동하고, SPACE로 선택을 전환하며, ENTER로 확인하십시오. 두 항목 모두에서 **None**을 선택하면 AI 구성을 완전히 건너뜁니다.

비대화형 모드에서 이러한 프롬프트를 건너뛰려면 `ig new`에 `--assistants` 및 `--agents` 플래그를 직접 전달하십시오:

```cmd
ig new my-app --framework=react --type=igr-ts --template=side-nav --assistants vscode --agents copilot claude
```

사용 가능한 플래그 값에 대한 자세한 내용은 [Ignite UI CLI 개요](./general-cli-overview.mdx#프로젝트-생성-중-ai-구성)를 참조하십시오.

### 완료하거나 계속하기

위 단계를 완료하면 프로젝트 구조가 생성되고, Git 저장소가 초기화되며, 프로젝트가 커밋됩니다. 그런 다음 프로세스를 완료할지 아니면 애플리케이션에 새 뷰를 추가할지 묻습니다.

## 뷰 추가

Ignite UI CLI는 기존 프로젝트에 추가할 수 있는 여러 컴포넌트 템플릿을 지원합니다. 이 모드는 프로젝트 생성의 연속으로, 또는 다음을 사용하여 기존 프로젝트 안에서 사용할 수 있습니다:

```cmd
ig add
```

카테고리별로 묶인 사용 가능한 컴포넌트 템플릿 목록이 표시됩니다. 화살표 키로 그룹 사이를 이동하고 ENTER로 선택하십시오. `Custom Grid` 같은 일부 템플릿의 경우, 선택을 확인하기 전에 SPACE 키로 켜거나 끌 수 있는 선택적 기능 목록이 표시됩니다.

그룹을 선택한 다음, 목록에서 특정 템플릿을 고르고 새 컴포넌트의 이름을 입력하십시오. 시나리오 템플릿을 선택하면 사용 가능한 시나리오 템플릿 목록도 표시됩니다.

템플릿을 추가한 후에는 뷰를 더 추가할지 아니면 프로세스를 완료할지 묻습니다. 완료하면 남은 패키지 종속성이 설치되고, 애플리케이션이 빌드되어 기본 브라우저에서 열립니다.

나중에 마법사 없이 프로젝트에 뷰를 더 추가하려면 직접 `add` 명령을 사용하십시오:

```cmd
ig add [template] [name]
```

예를 들면:

```cmd
ig add grid MyGrid
```

<DocsAside type="info">
라우팅 파일에는 새로 생성된 페이지의 경로가 업데이트됩니다. 예를 들어 `MyGrid`라는 컴포넌트는 `/my-grid`에서 이동할 수 있습니다.
</DocsAside>

## 애플리케이션 실행하기

프로젝트가 완료되면 언제든지 다음으로 실행하십시오:

```cmd
ig start
```

이 명령은 프로젝트를 빌드하고, 로컬 웹 서버를 시작하며, 기본 브라우저에서 애플리케이션을 엽니다.

</PlatformBlock>
