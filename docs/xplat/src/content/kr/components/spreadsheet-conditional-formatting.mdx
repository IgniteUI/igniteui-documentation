# {Platform} Spreadsheet 조건부 서식

## 조건부 서식 개요

워크시트의 <ApiLink type="Worksheet" member="conditionalFormats" label="ConditionalFormats" /> 컬렉션에서 노출되는 여러 `\Add` 메서드를 사용하여 특정 워크시트의 조건부 서식을 구성할 수 있습니다. 이러한 `\Add` 메서드의 첫 번째 매개변수는 조건부 서식을 적용할 워크시트의 문자열 영역입니다.

워크시트에 추가할 수 있는 많은 조건부 서식에는 해당 조건부 서식의 조건이 참일 때 셀이 보이는 방식을 결정하는 <ApiLink type="WorksheetCell" member="cellFormat" label="CellFormat" /> 속성이 있습니다. 예를 들어 이 <ApiLink type="WorksheetCell" member="cellFormat" label="CellFormat" /> 속성에 연결된 <ApiLink type="IWorksheetCellFormat" member="fill" label="Fill" /> 및 <ApiLink type="IWorksheetCellFormat" member="font" label="Font" /> 같은 속성을 사용하면 각각 셀의 배경과 글꼴 설정을 정할 수 있습니다.

조건부 서식이 만들어지고 <ApiLink type="WorksheetCell" member="cellFormat" label="CellFormat" />이(가) 적용되면, 워크시트 셀이 현재 지원하는 속성의 하위 집합이 있습니다. <ApiLink type="WorksheetCell" member="cellFormat" label="CellFormat" />에서 현재 적용되는 속성은 <ApiLink type="IWorksheetCellFormat" member="fill" label="Fill" />, `\Border` 속성, <ApiLink type="IWorksheetCellFormat" member="formatString" label="FormatString" />, 그리고 취소선, 밑줄, 기울임꼴, 굵게, 색 같은 일부 <ApiLink type="IWorksheetCellFormat" member="font" label="Font" /> 속성입니다. 이들 중 다수는 아래 코드 조각에서 볼 수 있습니다.

셀에서 시각화가 다르게 동작하므로 <ApiLink type="WorksheetCell" member="cellFormat" label="CellFormat" /> 속성이 없는 조건부 서식도 몇 가지 있습니다. 이러한 조건부 서식은 <ApiLink type="DataBarConditionalFormat" />, <ApiLink type="ColorScaleConditionalFormat" />, <ApiLink type="IconSetConditionalFormat" />입니다.

Excel에서 기존 통합 문서를 불러오면 해당 통합 문서를 불러올 때 서식이 유지됩니다. 통합 문서를 Excel 파일로 저장할 때도 마찬가지입니다.

다음은 {Platform} <ApiLink type="Spreadsheet" /> 컨트롤에서 지원되는 조건부 서식 목록입니다:

- <ApiLink type="AverageConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addAverageCondition" label="AddAverageCondition" /> 메서드를 사용하여 추가되며, 셀 값이 관련 범위의 평균 또는 표준 편차보다 위에 있는지 아래에 있는지에 따라 워크시트 셀의 시각적 속성을 제어하는 속성을 노출합니다.
- <ApiLink type="BlanksConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addBlanksCondition" label="AddBlanksCondition" /> 메서드를 사용하여 추가되며, 셀 값이 설정되지 않았는지에 따라 워크시트 셀의 시각적 속성을 제어하는 속성을 노출합니다.
- <ApiLink type="ColorScaleConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addColorScaleCondition" label="AddColorScaleCondition" /> 메서드를 사용하여 추가되며, 셀 값이 최솟값, 중간값, 최댓값 임계값과 비교되는 상대 값인지에 따라 워크시트 셀의 색을 제어하는 속성을 노출합니다.
- <ApiLink type="DataBarConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addDataBarCondition" label="AddDataBarCondition" /> 메서드를 사용하여 추가되며, 셀 값이 관련 값 범위에 대해 상대적인 값인지에 따라 워크시트 셀에 데이터 막대를 표시하는 속성을 노출합니다.
- <ApiLink type="DateTimeConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addDateTimeCondition" label="AddDateTimeCondition" /> 메서드를 사용하여 추가되며, 셀의 날짜 값이 주어진 시간 범위 안에 있는지에 따라 워크시트 셀의 시각적 속성을 제어하는 속성을 노출합니다.
- <ApiLink type="DuplicateConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addDuplicateCondition" label="AddDuplicateCondition" /> 메서드를 사용하여 추가되며, 셀 값이 관련 범위에서 고유한지 중복되는지에 따라 워크시트 셀의 시각적 속성을 제어하는 속성을 노출합니다.
- <ApiLink type="ErrorsConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addErrorsCondition" label="AddErrorsCondition" /> 메서드를 사용하여 추가되며, 셀 값이 유효한지에 따라 워크시트 셀의 시각적 속성을 제어하는 속성을 노출합니다.
- <ApiLink type="FormulaConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addFormulaCondition" label="AddFormulaCondition" /> 메서드를 사용하여 추가되며, 셀 값이 수식으로 정의된 조건을 충족하는지에 따라 워크시트 셀의 시각적 속성을 제어하는 속성을 노출합니다.
- <ApiLink type="IconSetConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addIconSetCondition" label="AddIconSetCondition" /> 메서드를 사용하여 추가되며, 셀 값이 임계값에 대해 상대적인 값인지에 따라 워크시트 셀에 아이콘을 표시하는 속성을 노출합니다.
- <ApiLink type="NoBlanksConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addNoBlanksCondition" label="AddNoBlanksCondition" /> 메서드를 사용하여 추가되며, 셀 값이 설정되었는지에 따라 워크시트 셀의 시각적 속성을 제어하는 속성을 노출합니다.
- <ApiLink type="NoErrorsConditionalFormat" />: <ApiLink type="ConditionalFormatCollection" member="addNoErrorsCondition" label="AddNoErrorsCondition" /> 메서드를 사용하여 추가되며, 셀 값이 유효한지에 따라 워크시트 셀의 시각적 속성을 제어하는 속성을 노출합니다.

## 코드 조각

다음 코드 조각은 <ApiLink type="Spreadsheet" /> 컨트롤의 스프레드시트에 각 조건부 서식을 추가하는 방법을 보여 줍니다:

```ts
let sheet = this.spreadsheet.activeWorksheet;

let red = new Color();
red.colorString = "#ff0000";

let blue = new Color();
blue.colorString = "#0000ff";

let green = new Color();
green.colorString = "#00ff00";

let gray = new Color();
gray.colorString = "#d3d3d3";

let avgFormat = sheet.conditionalFormats().addAverageCondition("A1:A10", FormatConditionAboveBelow.AboveAverage);
avgFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(red);

let blanksFormat = sheet.conditionalFormats().addBlanksCondition("B1:B10");
blanksFormat.cellFormat.fill = CellFill.createSolidFill(new WorkbookColorInfo(gray));

let colorFormat = sheet.conditionalFormats().addColorScaleCondition("C1:C10", ColorScaleType.ThreeColor);
colorFormat.minimumThreshold.formatColor = new WorkbookColorInfo(red);
colorFormat.midpointThreshold.formatColor = new WorkbookColorInfo(blue);
colorFormat.maximumThreshold.formatColor = new WorkbookColorInfo(green);

let dataBarFormat = sheet.conditionalFormats().addDataBarCondition("D1:D10");

let dateTimeFormat = sheet.conditionalFormats().addDateTimeCondition("E1:E10", FormatConditionTimePeriod.NextWeek);
dateTimeFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(red);

let duplicateFormat = sheet.conditionalFormats().addDuplicateCondition("F1:F10");
duplicateFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(blue);

let errorFormat = sheet.conditionalFormats().addErrorsCondition("G1:G10");
errorFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(green);

let formulaFormat = sheet.conditionalFormats().addFormulaCondition("H1:H10", "=H1>2");
formulaFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(red);

let iconFormat = sheet.conditionalFormats().addIconSetCondition("I1:I10", FormatConditionIconSet.IconSet3TrafficLights1);

let noBlanksFormat = sheet.conditionalFormats().addNoBlanksCondition("J1:J10");
noBlanksFormat.cellFormat.fill = CellFill.createSolidFill(new WorkbookColorInfo(gray));

let noErrorFormat = sheet.conditionalFormats().addErrorsCondition("K1:K10");
noErrorFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(red);

let operatorFormat = sheet.conditionalFormats().addOperatorCondition("L1:L10", FormatConditionOperator.Greater);
operatorFormat.setOperand1(500);
operatorFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(blue);

let rankFormat = sheet.conditionalFormats().addRankCondition("M1:M10", FormatConditionTopBottom.Top, 5);
rankFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(green);

let textFormat = sheet.conditionalFormats().addTextCondition("N1:N10", "A", FormatConditionTextOperator.Contains);
textFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(red);

let uniqueFormat = sheet.conditionalFormats().addUniqueCondition("O1:O10");
uniqueFormat.cellFormat.font.colorInfo = new WorkbookColorInfo(blue);
```
