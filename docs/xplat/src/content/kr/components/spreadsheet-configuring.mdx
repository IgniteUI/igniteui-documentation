## 셀 편집 구성

사용자가 셀 값을 편집하고 새 입력을 확인하면, <ApiLink type="Spreadsheet" /> 컨트롤은 스프레드시트의 구성에 따라 <kbd>ENTER</kbd> 키를 누를 때 현재 활성 셀에 인접한 셀로 이동할 수 있습니다.

이 <kbd>ENTER</kbd> 키 탐색을 활성화하려면 <ApiLink type="Spreadsheet" member="isEnterKeyNavigationEnabled" label="IsEnterKeyNavigationEnabled" /> 속성을 **true**로 설정할 수 있습니다. false로 설정하면 <kbd>ENTER</kbd> 키를 눌러도 활성 셀이 그대로 유지됩니다.

<ApiLink type="Spreadsheet" member="enterKeyNavigationDirection" label="EnterKeyNavigationDirection" /> 속성을 `\Down`, `\Up`, `\Left` 또는 `\Right`으로 설정하면 <kbd>ENTER</kbd> 키를 눌렀을 때 이동하는 인접 셀의 방향도 구성할 수 있습니다.

다음 코드 조각은 위 내용을 보여 줍니다:

<PlatformBlock for="Angular">

```html
<igx-spreadsheet isEnterKeyNavigationEnabled=true
    enterKeyNavigationDirection="Left">
</igx-spreadsheet>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-spreadsheet is-enter-key-navigation-enabled="true"
    enter-key-navigation-direction="Left">
</igc-spreadsheet>
```

</PlatformBlock>

<PlatformBlock for="React">
```ts
import { SpreadsheetEnterKeyNavigationDirection } from 'igniteui-react-spreadsheet';
```


</PlatformBlock>

<PlatformBlock for="WebComponents">
```ts
import { SpreadsheetEnterKeyNavigationDirection } from 'igniteui-webcomponents-spreadsheet';
```


</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrSpreadsheet isEnterKeyNavigationEnabled={true} enterKeyNavigationDirection={SpreadsheetEnterKeyNavigationDirection.Left} />
```

</PlatformBlock>

```ts
this.spreadsheet.isEnterKeyNavigationEnabled = true;
this.spreadsheet.enterKeyNavigationDirection = SpreadsheetEnterKeyNavigationDirection.Left;
```

## 탐색 구성

<ApiLink type="Spreadsheet" /> 컨트롤은 컨트롤이 "끝 모드"에 있는지 여부를 구성하여 워크시트 셀 사이의 탐색을 구성할 수 있게 합니다. 끝 모드는 화살표 키를 누르면 활성 셀이 현재 셀에서, 누른 화살표 키의 방향에 따라 인접한 셀에 데이터가 있는 행이나 열의 끝으로 이동하는 기능입니다. 이 기능은 큰 데이터 블록의 끝으로 매우 빠르게 이동하는 데 유용합니다.

예를 들어 끝 모드에 있을 때 100x100 크기의 큰 데이터 블록 안을 클릭하고 <kbd>→</kbd> 화살표 키를 누르면, 현재 행에서 데이터가 있는 가장 오른쪽 열의 끝으로 이동합니다. 이 작업 후 <ApiLink type="Spreadsheet" />은(는) 끝 모드에서 빠져나옵니다.

끝 모드는 사용자가 <kbd>END</kbd> 키를 누를 때 런타임에 적용되지만, 스프레드시트 컨트롤의 <ApiLink type="Spreadsheet" member="isInEndMode" label="IsInEndMode" /> 속성을 설정하여 프로그래밍 방식으로도 구성할 수 있습니다.

다음 코드 조각은 위 내용을 보여 주며, <ApiLink type="Spreadsheet" />은(는) 끝 모드에서 시작합니다:


## 보호 구성

<ApiLink type="Spreadsheet" />은(는) 워크시트 단위로 통합 문서의 보호를 따릅니다. 워크시트의 보호는 워크시트에서 보호하려면 `Protect()` 메서드를, 보호를 해제하려면 `Unprotect()` 메서드를 호출하여 구성할 수 있습니다.

아래 코드를 사용하여 <ApiLink type="Spreadsheet" /> 컨트롤의 현재 활성 워크시트에서 보호를 활성화하거나 비활성화할 수 있습니다:

```ts
this.spreadsheet.activeWorksheet.protect();
this.spreadsheet.activeWorksheet.unprotect();
```

## 선택 구성

<ApiLink type="Spreadsheet" /> 컨트롤은 사용자가 수정 키(<kbd>SHIFT</kbd> 또는 <kbd>CTRL</kbd>)를 누를 때 컨트롤에서 허용되는 선택 유형을 구성할 수 있게 합니다. 이는 스프레드시트의 <ApiLink type="Spreadsheet" member="selectionMode" label="SelectionMode" /> 속성을 다음 값 중 하나로 설정하여 수행합니다:

- `\AddToSelection`: 모드에 들어간 후 첫 번째 화살표 키 탐색으로 범위가 추가되면, 마우스로 드래그할 때 <kbd>CTRL</kbd> 키를 누르고 있지 않아도 새 셀 범위가 <ApiLink type="SpreadsheetSelection" /> 객체의 <ApiLink type="SpreadsheetSelection" member="cellRanges" label="CellRanges" /> 컬렉션에 추가됩니다. 모드에 들어가려면 <kbd>SHIFT</kbd> + <kbd>F8</kbd>을 누르면 됩니다.
- `\ExtendSelection`: 마우스로 셀을 선택하거나 키보드로 이동하면 <ApiLink type="SpreadsheetSelection" /> 객체의 <ApiLink type="SpreadsheetSelection" member="cellRanges" label="CellRanges" /> 컬렉션에서 활성 셀을 나타내는 선택 범위가 업데이트됩니다.
- `\Normal`: 셀이나 셀 범위를 선택하려고 마우스를 드래그하면 선택이 대체됩니다. 마찬가지로 키보드로 이동하면 새 선택이 만들어집니다. <kbd>CTRL</kbd> 키를 누른 상태에서 마우스를 사용하면 새 범위를 추가할 수 있고, <kbd>SHIFT</kbd> 키를 누른 상태에서 마우스로 클릭하거나 화살표 키 같은 키보드로 이동하면 활성 셀을 포함하는 선택 범위를 바꿀 수 있습니다.

이
<ApiLink type="SpreadsheetSelection" />
위 설명에 나온 객체는 <ApiLink type="Spreadsheet" /> 컨트롤의 <ApiLink type="Spreadsheet" member="activeSelection" label="ActiveSelection" /> 속성을 사용하여 가져올 수 있습니다.

다음 코드 조각은 선택 모드 구성을 보여 줍니다:

<PlatformBlock for="Angular">

```html
<igx-spreadsheet selectionMode="ExtendSelection"></igx-spreadsheet>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-spreadsheet selection-mode="ExtendSelection"></igc-spreadsheet>
```

</PlatformBlock>

<PlatformBlock for="React">
```ts

```


</PlatformBlock>

<PlatformBlock for="WebComponents">
```ts

```


</PlatformBlock>

<PlatformBlock for="React">

```tsx

```

</PlatformBlock>

```ts
this.spreadsheet.selectionMode = SpreadsheetCellSelectionMode.ExtendSelection;
```

<ApiLink type="Spreadsheet" /> 컨트롤의 선택도 프로그래밍 방식으로 설정하거나 가져올 수 있습니다. 단일 선택의 경우 <ApiLink type="Spreadsheet" member="activeCell" label="ActiveCell" /> 속성을 설정할 수 있습니다. 다중 선택은 다음을 통해 이루어집니다
<ApiLink type="SpreadsheetSelection" />
객체는 <ApiLink type="Spreadsheet" /> 컨트롤의 <ApiLink type="Spreadsheet" member="activeSelection" label="ActiveSelection" /> 속성이 반환하는 객체입니다.

이
<ApiLink type="SpreadsheetSelection" />
객체에는 새 <ApiLink type="SpreadsheetCellRange" /> 객체 형태로 스프레드시트의 선택에 셀 범위를 프로그래밍 방식으로 추가할 수 있는 `AddCellRange()` 메서드가 있습니다.

다음 코드 조각은 셀 범위를 스프레드시트의 선택에 추가하는 방법을 보여 줍니다:

```ts
this.spreadsheet.activeSelection.addCellRange(new SpreadsheetCellRange(2, 2, 5, 5));
```

## 탭 막대 영역 구성

<ApiLink type="Spreadsheet" /> 컨트롤은 현재 활성 <ApiLink type="Spreadsheet" member="workbook" label="Workbook" />의 <ApiLink type="Workbook" member="windowOptions" label="WindowOptions" />에서 `\TabBarWidth` 및 `\TabBarVisibility` 속성을 통해 탭 막대 영역의 표시 여부와 너비 구성을 각각 따릅니다.

탭 막대 영역은 컨트롤에서 워크시트 이름을 탭으로 시각화하는 영역입니다.

다음 코드 조각을 사용하여 탭 막대의 표시 여부와 너비를 구성할 수 있습니다:

```ts
this.spreadsheet.workbook.windowOptions.tabBarVisible = false;

this.spreadsheet.workbook.windowOptions.tabBarWidth = 200;
```

## 확대/축소 수준 구성
