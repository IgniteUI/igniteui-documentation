# 지리적 위치가 있는 {Platform} JSON 파일 바인딩

{ProductName} 지도를 사용하면 다양한 파일 형식에서 불러온 지리 데이터를 플롯할 수 있습니다. 예를 들어 JavaScript Object Notation(JSON) 파일에서 지리적 위치를 불러올 수 있습니다.

## 데이터 예제
다음은 JSON 파일의 데이터 예제입니다:

```json
[
    { "cap": false, "pop":  0.47, "lat":  68.96, "lon":   33.09, "country": "Russia" ,    "name": "Murmansk" },
    { "cap": true,  "pop":  1.65, "lat":  53.90, "lon":   27.58, "country": "Byelarus" ,  "name": "Minsk" },
    { "cap": true,  "pop":  0.58, "lat":  54.69, "lon":   25.28, "country": "Lithuania" , "name": "Vilnius" },
 // ...
]
```

## 코드 조각
다음 코드는 다음을 불러와 바인딩합니다 <PlatformBlock for="Web">`GeographicHighDensityScatterSeries`</PlatformBlock><PlatformBlock for="WinUI, Uno">`GeographicSymbolSeries`</PlatformBlock> 지도 컴포넌트에 지리적 위치가 있는 불러온 JSON 파일에서 만든 객체 배열로:

```json-snippet id="jsonMap" source="/maps/geo-map/binding-data-json-points"
{
    "descriptions": {
        "content": { "type": "GeographicMap", "name": "geoMap", "height": "100%", "width": "100%", "zoomable": true }
    },
    "onViewInit": [ "MapBindingDataJsonPointsOnViewInit" ]
}
```

```json-snippet ref="jsonMap" channel="eventHandlers"
```
