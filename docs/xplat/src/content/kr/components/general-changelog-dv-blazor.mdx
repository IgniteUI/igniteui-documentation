## **{PackageVerLatest}**

### 개선 사항

#### {PackageCharts}

- `Axis` 및 `XYChart` 파생 차트 전체에 축 가시성 속성을 추가하여, 스타일 재정의 없이 개별 축 요소를 전환할 수 있습니다:
  - `AreLabelsVisible` - 레이블 패널이 레이아웃 슬롯을 유지하는 동안 눈금 레이블 텍스트를 숨깁니다.
  - `AreTickMarksVisible` - 눈금 표시 선을 숨깁니다.
  - `AreAnnotationsVisible` - 축 주석(예: `FinalValueLayer` 배지)을 숨깁니다.
  - `IsLabelPanelVisible` - 레이블 패널 전체를 범위 0으로 축소합니다.
  - 해당 차트 수준 전달 속성 `XAxisAreLabelsVisible`, `XAxisAreTickMarksVisible`, `XAxisAreAnnotationsVisible`, `XAxisIsLabelPanelVisible`, `YAxisAreLabelsVisible`, `YAxisAreTickMarksVisible`, `YAxisAreAnnotationsVisible`, `YAxisIsLabelPanelVisible`이 `IgbCategoryChart`, `IgbFinancialChart` 및 기타 `XYChart` 파생 차트에 추가되었습니다.

- 시리즈에 `LegendItemBadgeMarkerSizeScaling`를 추가했습니다. 이는 범례 배지가 시리즈 `MarkerSize`에 따라 크기가 조정되는 방식을 제어합니다. 지원되는 값은 `Auto`(기본값, 1배와 2배 사이에서 배지를 보간), `None`(배지가 기본 크기를 유지), `Linear`(배지가 `MarkerSize`에 직접 비례하여 크기 조정)입니다. 확정된 크기는 읽기 전용 `ActualLegendItemBadgeMarkerWidth` 및 `ActualLegendItemBadgeMarkerHeight` 속성으로 노출됩니다.

- `IgbLinearGraphRange`(`IgbLinearGauge` 및 `IgbBulletGraph`에서 사용)와 `IgbRadialGaugeRange`에 `StartInset` 및 `EndInset`를 추가했습니다. 이 속성들은 장치 독립 픽셀로 측정된 거리만큼 범위의 시작 및 끝 가장자리를 안쪽으로 줄여, 게이지의 크기나 값 범위와 관계없이 인접한 범위 사이에 일관된 간격을 만듭니다. 둘 다 기본값은 `0`이므로, 안쪽 여백을 설정하지 않으면 범위는 계속 빈틈없이 맞닿습니다.

#### {PackageGrids}(그리드)

- 내부 Ignite UI for Angular 참조를 21.2에서 22.0으로 업데이트하여 `IgbGrid`, `IgbTreeGrid`, `IgbHierarchicalGrid`, `IgbRowIsland`의 생성된 모델을 새로 고쳤으며, 새로운 `GridBase`, `HierarchicalGridBase`, `RowIslandBase` 공유 표면을 포함합니다.

#### **모든 그리드**

- **셀 병합**
  - 같은 데이터 또는 다른 사용자 지정 조건에 따라 열의 셀을 구성하고 하나의 셀로 병합할 수 있는 새 셀 병합 기능을 도입했습니다. 개별 열에서 활성화할 수 있습니다:

```razor
<IgbColumn Field="field" Merge="true"></IgbColumn>
```

  - `OnSort` - 열이 정렬된 경우에만.
  - `Always` - 데이터 작업과 관계없이 항상.
  기본 <ApiLink type="GridBaseDirective" member="cellMergeMode" label="CellMergeMode" />는 `OnSort`입니다.
<PlatformBlock for="Blazor">

```razor
<IgbGrid CellMergeMode="GridCellMergeMode.Always">
</IgbGrid>
```

</PlatformBlock>

  - 개별 열을 그리드의 특정 쪽(시작 또는 끝)에 고정할 수 있게 되어, 이제 양쪽에서 고정할 수 있습니다. 이는 열의 <ApiLink type="Column" member="pinningPosition" label="PinningPosition" /> 속성을 설정하여 선언적으로 수행할 수 있습니다:
<PlatformBlock for="Blazor">

```razor
<IgbColumn Field="Col1" Pinned="true" PinningPosition="ColumnPinningPosition.End">
</IgbColumn>
```

</PlatformBlock>
  - 또는:
<PlatformBlock for="Blazor">

```razor
col.PinningPosition = ColumnPinningPosition.End;
col.Pinned = true;

col.PinningPosition = ColumnPinningPosition.Start;
col.Pinned = true;
```

</PlatformBlock>
  - 열에 <ApiLink type="Column" member="pinningPosition" label="PinningPosition" /> 속성이 설정되지 않으면, 열은 그리드의 열 고정 옵션에 지정된 위치를 기본값으로 사용합니다.

  - 그룹화 알고리즘을 재귀에서 반복 방식으로 리팩터링했습니다.
