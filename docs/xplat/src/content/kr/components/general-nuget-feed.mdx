# Infragistics NuGet 피드

Infragistics는 라이선스 사용자가 NuGet 패키지 관리자를 통해 라이선스가 부여된 Ignite UI for Blazor NuGet 패키지를 사용하고 애플리케이션에 추가할 수 있도록 비공개 NuGet 피드를 제공합니다.

이 항목에는 다음 섹션이 포함되어 있습니다:

- Visual Studio로 Infragistics NuGet 피드 추가하기
- NuGet CLI로 Infragistics NuGet 피드 추가하기

## Visual Studio로 추가하기

1 - Visual Studio에서 **도구 → NuGet 패키지 관리자 → 패키지 관리자 설정**을 선택하십시오.

<Image src={nugetPackageManagerSettingMenuItem} alt="nuget-package-manager-setting-menu-item" />

2 - **패키지 원본** 섹션에서 대화 상자 오른쪽 위의 **더하기 아이콘**을 클릭하여 새 패키지 원본을 추가하십시오.
- 이름을 **Infragistics**로 설정하십시오
- NuGet 프로토콜 버전 3을 사용하려면 Source를 **https://packages.infragistics.com/nuget/licensed/v3/index.json** 주소로 설정하십시오. 그렇지 않으면 **https://packages.infragistics.com/nuget/licensed/** 주소로 설정해야 합니다

<DocsAside type="info">
v3을 사용할지 이전 버전을 사용할지에 대한 자세한 내용은 **https://devblogs.microsoft.com/nuget/nuget-3-what-and-why/** 페이지를 참조하십시오. 프로토콜 v3은 최신 버전의 NuGet 클라이언트(2015년 이후)를 사용할 때만 적용됩니다. 이전 NuGet 클라이언트는 v3과 호환될 수도 있고 호환되지 않을 수도 있습니다.
</DocsAside>

**업데이트** 버튼을 클릭한 다음 **확인**을 클릭하여 대화 상자를 닫으십시오.

<Image src={nugetPackageManagerPackageSourcesIgServer} alt="nuget-package-manager-package-sources-ig-server" />

<DocsAside type="info">
이 원본에서 처음으로 NuGet 패키지를 추가하면 Infragistics 자격 증명을 입력하라는 메시지가 표시됩니다.
</DocsAside>

## NuGet CLI로 추가하기

1 - [최신 Nuget 실행 파일](https://dist.nuget.org/win-x86-commandline/latest/nuget.exe)을 다운로드하십시오. 브라우저가 파일을 원하는 폴더에 저장하도록 지시하십시오. 이 파일은 설치 프로그램이 아니므로, 브라우저에서 직접 실행해도 아무것도 보이지 않습니다.
2 - 방금 다운로드한 `nuget.exe` 파일의 폴더 경로에서 명령 프롬프트를 여십시오.
3 - 다음 명령을 실행하십시오

```cmd
//nuget protocol v3
nuget sources add -name "Infragistics" -source "https://packages.infragistics.com/nuget/licensed/v3/index.json" -username "your login email" -password "your password"

//nuget protocol v2
nuget sources add -name "Infragistics" -source "https://packages.infragistics.com/nuget/licensed" -username "your login email" -password "your password"
```

<DocsAside type="info">
암호는 NuGet 구성 파일에 암호화되어 저장되며, 암호화된 것과 같은 사용자 컨텍스트에서만 복호화할 수 있습니다. 구성 파일의 기본 위치는 `%AppData%\NuGet\NuGet.config`에서 확인할 수 있습니다
</DocsAside>
