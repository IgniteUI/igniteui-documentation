# {Platform} 지리 시리즈 개요

{ProductName} 지도 컴포넌트에서 지리 시리즈는 지리 공간 데이터를 지리적 맥락에서 점(예: 도시의 위치), 폴리라인(예: 도로 연결), 또는 다각형(예: 국가의 모양)으로 표시하는 지도의 시각 요소입니다.
지도 컴포넌트의 Series 속성은 지리 시리즈 객체의 컬렉션입니다. 이 속성은 같은 플롯 영역에서 무제한 개수의 지리 시리즈를 렌더링하는 것을 지원하는 데 사용됩니다. 지리 시리즈 객체가 Series 속성에 추가되면, 각 연속 시리즈는 첫 번째 시리즈부터 마지막 시리즈까지 이전 시리즈 위에 겹쳐집니다. 따라서 지리 시리즈는 서로 위에 또는 지리 이미지 위에 쌓을 수 있는 지도 레이어로 더 잘 이해할 수 있습니다.

모든 유형의 지리 시리즈는 항상 지리 이미지 타일 위에 렌더링됩니다. 하지만 때로는 지리 시리즈(예: 세계의 상세한 셰이프 파일)가 애플리케이션에 충분한 지리적 맥락을 제공하므로, 지도 컨트롤에서 지리 이미지가 필요하지 않을 수 있습니다.
