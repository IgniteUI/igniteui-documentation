# 지리 셰이프 시리즈의 {Platform} 셰이프 스타일 지정

이 항목은 {Platform} `GeographicMap`의 `GeographicShapeSeries`에 사용자 지정 스타일을 적용하는 방법을 설명합니다.

## 지리 셰이프 시리즈의 {Platform} 셰이프 스타일 지정 예제


<Sample src="/maps/geo-map/shape-styling" height={500} alt="지리 셰이프 시리즈의 {Platform} 셰이프 스타일 지정 예제" />




각 섹션이 사용하는 네 가지 스타일 클래스 — **ShapeRandomStyling**, **ShapeScaleStyling**, **ShapeRangeStyling**, **ShapeComparisonStyling** — 는 [Shape Styling Utility](./geo-map-resources-shape-styling-utility.mdx)에서 가져오며, 이 유틸리티는 자신의 프로젝트에 복사할 파일을 게시합니다.

## 필요한 import

셰이프 스타일 지정을 하려면 다음 클래스를 import해야 합니다:

```json-snippet id="shapeStyling" source="/maps/geo-map/shape-styling" channel="bindingImports,handlersImports"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true,
            "series": [
                {
                    "type": "GeographicShapeSeries",
                    "name": "shapeSeries",
                    "isCustomShapeStyleAllowed": true,
                    "assigningShapeStyleRef": "ShapeFileStyling"
                }
            ]
        }
    },
    "onViewInit": [ "ShapeFileOnViewInit" ]
}
```


## Shape Random Styling

이 코드 조각은 세계 국가에 채우기 색상을 무작위로 할당하는 **ShapeRandomStyling**의 인스턴스를 만듭니다.

```json-snippet source="/maps/geo-map/shape-styling-random" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeRandomStyling"
    ]
}
```

## Shape Scale Styling

이 코드 조각은 로그 척도로 조정된 인구를 기준으로 국가의 모양에 채우기 색상을 할당하는 **ShapeScaleStyling**의 인스턴스를 만듭니다.

```json-snippet source="/maps/geo-map/shape-styling-scale" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeScaleStyling"
    ]
}
```
