### 작업 텍스트

기본적으로 스낵바 컴포넌트는 <ApiLink pkg="core" type="Snackbar" member="displayTime" label="DisplayTime" />에 지정된 시간이 지나면 자동으로 숨겨집니다. 이 동작을 바꾸려면 <ApiLink pkg="core" type="Snackbar" member="keepOpen" label="KeepOpen" /> 속성을 사용할 수 있습니다. 이렇게 하면 스낵바가 계속 보입니다. 스낵바 <ApiLink pkg="core" type="Snackbar" member="actionText" label="ActionText" />을(를) 사용하면 컴포넌트 안에 작업 버튼을 표시할 수 있습니다.

<Sample src="/notifications/snackbar/action-text" height={230} alt="{Platform} Snackbar 작업 텍스트 예제" />




## 스타일링

<ApiLink pkg="core" type="Snackbar" /> 컴포넌트는 스타일을 완전히 제어할 수 있도록 여러 CSS 파트를 노출합니다:

|이름|설명|
|--|--|
| `base` | 스낵바 컴포넌트의 기본 래퍼입니다. |
| `message` | 스낵바 메시지입니다. |
| `action` | 기본 스낵바 작업 버튼입니다. |
| `action-container` | 작업을 담는 영역입니다. |

```css
igc-snackbar::part(base) {
  background: var(--ig-primary-500);
  border-color: var(--ig-primary-800);
  color: white;
}
```
