# {Platform} Dialog 개요

{ProductName} Dialog 컴포넌트는 일부 정보를 표시하거나 사용자에게 작업 또는 확인을 요청하는 데 사용됩니다. 모달 창에 표시되므로, 대화 상자를 닫는 특정 작업이 수행되기 전까지 사용자는 기본 앱과 상호 작용할 수 없습니다.

대화 상자 컴포넌트를 표시하는 가장 간단한 방법은 버튼 클릭 시 <ApiLink pkg="core" type="Dialog" member="show" label="Show" /> 메서드를 호출하는 것입니다.

<PlatformBlock for="Blazor">

```razor
<div class="container vertical">
    <IgbButton @onclick="OnDialogShow" Variant=@ButtonVariant.Contained>Show Dialog</IgbButton>
    <IgbDialog @ref="DialogRef" Title="Confirmation">
        <p>Are you sure you want to delete the Annual_Report_2016.pdf and Annual_Report_2017.pdf files?</p>
        <IgbButton slot="footer" @onclick="OnDialogHide" Variant=@ButtonVariant.Flat>Cancel</IgbButton>
        <IgbButton slot="footer" @onclick="OnDialogHide" Variant=@ButtonVariant.Flat>OK</IgbButton>
    </IgbDialog>
</div>

@code {
    public IgbDialog DialogRef;
    public async Task OnDialogShow()
    {
        if (this.DialogRef != null)
            await this.DialogRef.ShowAsync();
    }
    public async Task OnDialogHide()
    {
        if (this.DialogRef != null)
            await this.DialogRef.HideAsync();
    }
}
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html

    <igc-button slot="footer" onclick="dialog.close()" variant="flat">Cancel</igc-button>
    <igc-button slot="footer" onclick="dialog.close()" variant="flat">OK</igc-button>

```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton variant="contained" clicked={this.onDialogShow}>
    <span>Show Dialog</span>
</IgrButton>

<IgrDialog ref={this.onDialogRef}>
    <span>Dialog Message</span>
</IgrDialog>

public onDialogRef(dialog: IgrDialog) {
    if (!dialog) { return; }
    this.dialogRef = dialog;
}

public onDialogShow() {
    if (this.dialogRef) {
        this.dialogRef.show();
    }
}
```

</PlatformBlock>

<ApiLink pkg="core" type="Dialog" /> 컴포넌트는 <ApiLink pkg="core" type="Dialog" member="open" label="Open" /> 속성을 제공하며, 이를 통해 애플리케이션 시나리오에 맞게 상태를 구성할 수 있습니다.

<ApiLink pkg="core" type="Dialog" member="title" label="Title" /> 속성을 사용하여 대화 상자의 제목을 설정하십시오. 다만 `title` 슬롯에 콘텐츠가 제공되면 해당 슬롯이 속성보다 우선합니다.

`footer` 슬롯을 통해 대화 상자의 아래쪽 부분에 작업 버튼이나 추가 정보를 배치할 수 있습니다. 여기에 콘텐츠를 추가하지 않으면 클릭 시 Dialog를 닫는 기본 `OK` 버튼이 표시됩니다. 이 버튼을 표시하지 않으려면 <ApiLink pkg="core" type="Dialog" member="hideDefaultAction" label="HideDefaultAction" /> 속성을 **true**로 설정하십시오. 기본값은 **false**입니다.

### 닫기

기본적으로 사용자가 `ESC`을(를) 누르면 Dialog가 자동으로 닫힙니다. <ApiLink pkg="core" type="Dialog" member="keepOpenOnEscape" label="KeepOpenOnEscape" /> 속성을 사용하여 이 동작을 막을 수 있습니다. 기본값은 **false**입니다. 대화 상자 안에 열린 드롭다운(또는 내부에서 `ESC`을(를) 처리해야 하는 다른 요소)이 있으면, `ESC`을(를) 한 번 누르면 드롭다운이 닫히고 다시 누르면 대화 상자가 닫힙니다.

대화 상자 바깥을 클릭할 때 대화 상자를 닫을지 구성하려면 <ApiLink type="OverlaySettings" member="closeOnOutsideClick" label="CloseOnOutsideClick" /> 속성을 사용하십시오. 기본값은 **false**입니다.

## 스타일링

<ApiLink pkg="core" type="Dialog" /> 컴포넌트는 스타일을 완전히 제어할 수 있도록 여러 CSS 파트를 노출합니다:

|이름|설명|
|--|--|
| `base` | 대화 상자의 기본 래퍼입니다. |
| `title` | 제목 컨테이너. |
| `footer` | 푸터 컨테이너입니다. |
| `content` | 콘텐츠 컨테이너입니다. |

```css
igc-dialog::part(content) {
  background: var(--ig-secondary-800);
  color: var(--ig-secondary-800-contrast);
}

igc-dialog::part(title),
igc-dialog::part(footer) {
  background: var(--ig-secondary-800);
  color: var(--ig-warn-500);
}
```
