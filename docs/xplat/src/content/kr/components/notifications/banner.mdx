# {Platform} Banner 개요

{ProductName} Banner 컴포넌트는 스낵바보다 덜 순간적이고 대화 상자보다 덜 방해되는 방식으로 애플리케이션 사용자에게 눈에 띄는 메시지를 쉽게 표시하는 방법을 제공합니다. 또한 메시지의 맥락에 따라 취해야 할 작업을 나타낼 수도 있습니다.

### Banner 표시하기

Banner 컴포넌트를 표시하려면 <ApiLink pkg="core" type="Banner" member="show" label="Show" /> 메서드를 사용하고 버튼 클릭 시 호출하십시오. Banner는 요소가 페이지 템플릿에 삽입된 위치를 기준으로 나타나며 다른 모든 콘텐츠를 밀어냅니다. 일반적으로 사용자가 최소한의 상호 작용으로 닫을 수 있는, 방해되지 않는 콘텐츠를 표시합니다.

<PlatformBlock for="WebComponents">

```html
<igc-button onclick="banner.show()">Show Banner</igc-button>

<igc-banner id="banner">
    You are currently offline.
</igc-banner>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton onClick={() => bannerRef.current.show()}>
    <span>Show Banner</span>
</IgrButton>

<IgrBanner ref={bannerRef}>
    <span>You are currently offline.</span>
</IgrBanner>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbButton @onclick="ShowBanner">Show Banner</IgbButton>

<IgbBanner @ref="bannerRef">
    You are currently offline.
</IgbBanner>

@code {

    private void ShowBanner()
    {
        this.bannerRef.ShowAsync();
    }
}
```

</PlatformBlock>

### 이벤트에 바인딩하기

배너 컴포넌트는 닫힐 때 `Closing`과(와) `Closed` 이벤트를 발생시킵니다. `Closing` 이벤트는 취소할 수 있습니다. 이 이벤트는 [`CustomEvent`](https://developer.mozilla.org/docs/Web/API/CustomEvent) 인터페이스를 사용하며, 발생한 객체의 `cancelable` 속성은 **true**로 설정되어 있습니다. `Closing` 이벤트를 취소하면 해당 최종 작업과 이벤트는 실행되지 않습니다. 즉 배너는 닫히지 않으며 `Closed` 이벤트도 발생하지 않습니다.

닫기 이벤트를 취소하려면 [`preventDefault`](https://developer.mozilla.org/en-US/docs/Web/API/Event/preventDefault) 메서드를 호출하십시오.

<PlatformBlock for="WebComponents">

```html
<igc-banner id="banner">
    ...
</igc-banner>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
const banner = document.getElementById('banner') as IgcBannerComponent;

banner.addEventListener('igcClosing', (event) => {
  event.preventDefault();
});
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrBanner onClosing={(event) => event.preventDefault()}>
    ...
</IgrBanner>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbBanner id="banner">
    ...
</IgbBanner>

@code {
    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender)
        {
            await JS.InvokeVoidAsync("handleClosing");
        }
    }
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">


```javascript
//In JavaScript:
function handleClosing() {
    const banner = document.getElementById('banner');

    banner.addEventListener('igcClosing', (event) => {
        event.preventDefault();
    });
}
```

</PlatformBlock>

<DocsAside type="info">
위의 변경 사항을 적용하면 닫기 이벤트가 항상 취소되므로 배너는 절대 닫히지 않습니다.
</DocsAside>

## 고급 예제

알림을 닫는 버튼 하나와 연결을 켜는 버튼 하나, 이렇게 두 개의 사용자 지정 버튼이 있는 배너를 만들어 보겠습니다. `actions` 슬롯을 사용하여 사용자 지정 작업 핸들러를 전달할 수 있습니다:

> Google의 [Material Design](https://material.io/design/components/banners.html#anatomy) 지침에 따르면 배너에는 최대 버튼 2개만 있어야 합니다. <ApiLink pkg="core" type="Banner" />은(는) `actions` 슬롯 아래의 요소 수를 명시적으로 제한하지 않지만, Material Design 지침을 따르려면 최대 2개까지 사용하는 것을 강력히 권장합니다.


해제 옵션(**오프라인 계속**)은 추가 로직이 필요 없으므로 <ApiLink pkg="core" type="Banner" member="hide" label="Hide" /> 메서드를 호출하기만 하면 됩니다. 그러나 확인 작업(**Wifi 켜기**)에는 추가 로직이 필요하므로 컴포넌트에서 정의해야 합니다. 그다음 `click` 이벤트에 대한 이벤트 리스너를 추가합니다. 마지막 단계는 변경될 때마다 `refreshBanner()` 메서드를 호출하는 것입니다. 이 메서드는 `wifiState`에 따라 배너를 전환합니다.

navbar에는 Wifi 아이콘이 있으며, 이 아이콘의 `click` 이벤트에도 이벤트 리스너를 추가합니다. 변경될 때마다 `refreshBanner()` 메서드가 호출되므로, 아이콘은 배너를 전환할 뿐 아니라 연결 상태에 따라 모양도 바꿉니다:

<PlatformBlock for="WebComponents">

```html
<igc-navbar>
  <h1>Gallery</h1>
  <igc-icon id="icon" slot="end" name="signal_wifi_off"></igc-icon>
</igc-navbar>

<igc-banner id="banner">
    ...
    <div slot="actions">
        ...
        <igc-button id="button">
            <igc-ripple></igc-ripple>
            Turn On Wifi
        </igc-button>
    </div>
</igc-banner>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
private banner: IgcBannerComponent;
private icon: IgcIconComponent;
private button: IgcButtonComponent;

private wifiState: boolean = false;

constructor() {
    this.banner = document.getElementById('banner') as IgcBannerComponent;
    this.icon = document.getElementById('icon') as IgcIconComponent;
    this.button = document.getElementById('button') as IgcButtonComponent;

    this.icon.addEventListener('click', () => this.refreshBanner());
    this.button.addEventListener('click', () => this.refreshBanner());
}

public refreshBanner() {
    if (!this.wifiState) {
        this.icon.name = 'signal_wifi_4_bar';
        this.banner.hide();
    } else {
        this.icon.name = 'signal_wifi_off';
        this.banner.show();
    }
    this.wifiState = !this.wifiState;
}
```

</PlatformBlock>

## 스타일링

<ApiLink pkg="core" type="Banner" /> 컴포넌트는 스타일을 완전히 제어할 수 있도록 여러 CSS 파트를 노출합니다:

|이름|설명|
|--|--|
| `base` | 배너 컴포넌트의 기본 래퍼입니다. |
| `spacer` | 배너 주변의 공간을 설정하는 내부 래퍼입니다. |
| `message` | 텍스트와 일러스트레이션을 담는 파트입니다. |
| `illustration` | 배너 아이콘/일러스트레이션을 담는 파트입니다. |
| `content` | 배너 텍스트 콘텐츠를 담는 파트입니다. |
| `actions` | 배너 작업 버튼을 담는 파트입니다. |

```css
igc-banner::part(spacer) {
  background: var(--ig-surface-600);
}

igc-banner::part(illustration) {
  color: var(--ig-surface-600-contrast);
}

igc-banner::part(content) {
  color: var(--ig-gray-900);
}
```
