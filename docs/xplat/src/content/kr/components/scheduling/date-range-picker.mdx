# {Platform} Date Range Picker 개요

{ProductName} Date Range Picker는 텍스트 입력과 달력 팝업을 포함하는 가벼운 컴포넌트로, 사용자가 시작일과 종료일을 쉽게 선택할 수 있게 합니다. 다양한 애플리케이션 요구 사항에 맞게 높은 수준으로 사용자 지정할 수 있으며, 날짜 범위 제한, 구성 가능한 날짜 형식 등의 기능을 제공합니다.

## 사용법

<ApiLink pkg="core" type="DateRangePicker" />을(를) 사용하면 사용자가 드롭다운/달력 팝업에서 날짜 범위를 고르거나, 시작 날짜 입력 필드와 종료 날짜 입력 필드에 직접 입력하여 시작일과 종료일을 선택할 수 있습니다. picker는 날짜 값을 표시하는 두 가지 모드인 단일 입력과 두 개 입력을 제공합니다. 둘 다 편집과 마스킹 기능을 제공합니다.

달력이 보이는 동안에는 시작일과 종료일을 모두 선택하여 날짜 범위를 고를 수 있습니다. 날짜를 선택하면 시작일과 종료일이 모두 설정되며, 두 번째 날짜를 고르면 종료일이 설정됩니다. 이미 범위가 선택된 상태에서 달력의 다른 날짜를 클릭하면 새 범위 선택이 시작됩니다.

### 값

사용자가 선택하거나 입력하는 것 외에도 <ApiLink pkg="core" type="DateRangePicker" />의 범위 값은 <ApiLink pkg="core" type="DateRangePicker" member="value" /> 속성을 사용하여 설정할 수도 있습니다. 값은 **`{ start: startDate, end: endDate }`** 형식을 따라야 한다는 점에 유의하십시오. 여기서 `startDate`과(와) `endDate`은(는) 선택된 범위를 나타내는 `Date` 객체입니다.

<PlatformBlock for="WebComponents">

```ts
let dateRange = document.querySelector('igc-date-range-picker') as IgcDateRangePickerComponent;
let startDate = new Date(2025, 4, 6);
let endDate = new Date(2025, 4, 8);
dateRange.value = { start: startDate, end: endDate }
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const dateRangeRef = useRef<IgrDateRangePicker>();
let startDate = new Date(2025, 4, 6);
let endDate = new Date(2025, 4, 8);
useEffect (() => {
  dateRangeRef.current.value = { start: startDate, end: endDate }
}, [])

return (
  <IgrDateRangePicker ref={dateRangeRef} />
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
 <IgbDateRangePicker Value="@Range" Label="Date Range"/>

 @code {
    public IgbDateRangeValue Range = new IgbDateRangeValue()
    {
        Start = DateTime.Today,
        End = DateTime.Today.AddDays(3)
    };
}
```

</PlatformBlock>

<PlatformBlock for="WebComponents, React">

### 읽기 전용 및 편집 불가

<ApiLink pkg="core" type="DateRangePicker" />을(를) 읽기 전용으로 만들 수도 있습니다. 이렇게 하면 입력과 달력 선택 모두를 통해 범위 값을 바꿀 수 없고, 키보드 탐색도 비활성화되며, 달력과 지우기 아이콘이 시각적으로 비활성화된 것처럼 보입니다. 이는 범위를 value 속성으로 할당하고 표시 전용으로 쓰려는 경우에 유용합니다. 이 동작을 활성화하려면 <ApiLink pkg="core" type="DateRangePicker" member="readOnly" /> 속성을 설정하기만 하면 됩니다.

### 키보드 탐색

<ApiLink pkg="core" type="DateRangePicker" />은(는) 직관적인 키보드 탐색을 지원하여, 사용자가 마우스를 사용하지 않고도 값을 쉽게 증가 또는 감소시키거나 컴포넌트의 여러 부분 사이를 이동할 수 있습니다.

|키|설명|
|----|-----------|
| <kbd>←</kbd> | 커서를 한 글자 왼쪽으로 이동합니다 |
| <kbd>→</kbd> | 커서를 한 글자 오른쪽으로 이동합니다 |
| <kbd>CTRL</kbd> + <kbd>ArrowLeft</kbd> | 커서를 현재 입력 마스크 구역의 시작 부분으로 이동하고, 이미 시작 부분에 있으면 이전 구역의 시작 부분으로 이동합니다 |
| <kbd>CTRL</kbd> + <kbd>ArrowRight</kbd> | 커서를 현재 입력 마스크 구역의 끝으로 이동하고, 이미 끝에 있으면 다음 구역의 끝으로 이동합니다 |
| <kbd>ArrowUp</kbd> | 입력 마스크에서 현재 "포커스된" 부분을 한 단계 증가시킵니다 |
| <kbd>ArrowDown</kbd> | 입력 마스크에서 현재 "포커스된" 부분을 한 단계 감소시킵니다 |
| <kbd>HOME</kbd> | 커서를 입력 마스크의 시작 부분으로 이동합니다 |
| <kbd>END</kbd> | 커서를 입력 마스크의 끝으로 이동합니다 |
| <kbd>CTRL</kbd> + <kbd>;</kbd> | 현재 날짜를 컴포넌트의 값으로 설정합니다 |
| <kbd>ALT</kbd> + <kbd>↓</kbd> | 캘린더 드롭다운을 엽니다 |
| <kbd>ALT</kbd> + <kbd>↑</kbd> | 캘린더 드롭다운을 닫습니다 |

키보드로 달력 팝업 안에서도 이동할 수 있습니다. 이동 방식은 <ApiLink pkg="core" type="Calendar" /> 컴포넌트와 같습니다.

|키|설명|
|----|-----------|
| <kbd>↑</kbd> / <kbd>↓</kbd> / <kbd>←</kbd> / <kbd>→</kbd>| 월의 날짜를 이동합니다 |
| <kbd>ENTER</kbd> | 현재 포커스가 있는 날짜를 선택합니다 |
| <kbd>PAGE UP</kbd> | 이전 달 보기로 이동합니다 |
| <kbd>PAGE DOWN</kbd> | 다음 달 보기로 이동합니다 |
| <kbd>SHIFT</kbd> + <kbd>PAGE UP</kbd> | 이전 연도로 이동합니다 |
| <kbd>SHIFT</kbd> + <kbd>PAGE DOWN</kbd> | 다음 연도로 이동합니다 |
| <kbd>HOME</kbd> | 보이는 현재 월의 첫 번째 날(여러 달 보기가 표시되면 가장 이른 월)에 포커스를 줍니다 |
| <kbd>END</kbd> | 보이는 현재 월의 마지막 날(여러 달 보기가 표시되면 가장 늦은 월)에 포커스를 줍니다. |
| <kbd>Escape</kbd> | 달력 팝업을 닫습니다 |

### 달력 레이아웃과 서식 지정

여러 속성을 사용하여 팝업 달력을 더 사용자 지정할 수 있습니다:

|이름|타입|설명|
|--|--|--|

### 최소 및 최대

### 사용자 지정 및 미리 정의된 날짜 범위

<ApiLink pkg="core" type="DateRangePicker" member="customRanges" /> 속성을 사용하면 범위를 더 빠르게 선택할 수 있도록 캘린더 팝업에 사용자 지정 날짜 범위 칩을 추가할 수도 있습니다. 예를 들어 오늘 날짜로 끝나는 향후 7일 범위를 빠르게 선택하는 사용자 지정 날짜 범위 칩을 만들 수 있습니다. 또한 <ApiLink pkg="core" type="DateRangePicker" member="usePredefinedRanges" /> 속성을 설정하면 사용자 지정 칩과 함께 사전 정의된 범위 칩 집합이 표시됩니다.

<PlatformBlock for="WebComponents">

```ts
const today = new Date();

const nextSeven = new Date(
  today.getFullYear(),
  today.getMonth(),
  today.getDate() + 7
);
const nextWeek: CustomDateRange[] = [
  {
    label: 'Next 7 days',
    dateRange: {
      start: today,
      end: nextSeven
    }
  }
]

const dateRange = document.querySelector('igc-date-range-picker') as IgcDateRangePickerComponent;
dateRange.customRanges = nextWeek;
dateRange.usePredefinedRanges = true;
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx

```

</PlatformBlock>

### 비활성화된 날짜 및 특별 날짜

캘린더에서 비활성화된 날짜를 설정하여 사용자가 고를 수 있는 날짜 범위를 좁힐 수도 있습니다. 비활성화된 날짜를 설정하려면 <ApiLink pkg="core" type="DateRangePicker" member="disabledDates" /> 속성을 사용할 수 있습니다.

<PlatformBlock for="WebComponents">

```ts
let dateRange = document.querySelector('igc-date-range-picker') as IgcDateRangePickerComponent;

const minDate = new Date(2025, 4, 1);
const maxDate = new Date(2025, 4, 31);

dateRange.disabledDates = [
  {
    type: DateRangeType.Between,
    dateRange: [minDate, maxDate]
  }
] as DateRangeDescriptor[];
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const dateRangeRef = useRef<IgrDateRangePicker>();
const minDate = new Date(2025, 4, 5);
const maxDate = new Date(2025, 4, 15);
useEffect (() => {
  dateRangeRef.current.disabledDates = [
    {
      type: DateRangeType.Between,
      dateRange: [minDate, maxDate]
    }
  ] as DateRangeDescriptor[];
}, [])

return (
  <IgrDateRangePicker ref={dateRangeRef} />
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDateRangePicker DisabledDates="@DisabledDates" />

@code {
    public IgbDateRangeDescriptor[] DisabledDates = [
        new IgbDateRangeDescriptor
    {
        RangeType = DateRangeType.Between,
        DateRange = new DateTime[] { new DateTime(DateTime.Today.Year, DateTime.Today.Month, 5), new DateTime(DateTime.Today.Year, DateTime.Today.Month, 8) },
    }];
}
```

</PlatformBlock>

<ApiLink pkg="core" type="DateRangePicker" member="disabledDates" /> 속성이 제공하는 모든 가능성에 대한 자세한 내용은 여기에서 확인할 수 있습니다: [비활성화된 날짜](./calendar.mdx#비활성화된-날짜)

캘린더에 하나 이상의 특별한 날짜를 설정하려는 경우에도 같은 방법을 사용할 수 있습니다. 차이점은 대신 <ApiLink pkg="core" type="DateRangePicker" member="specialDates" /> 속성을 사용해야 한다는 것입니다. [특별한 날짜](./calendar.mdx#특별한-날짜)

### 슬롯

사용 가능한 슬롯을 사용하여 사용자 지정 콘텐츠를 추가하고 <ApiLink pkg="core" type="DateRangePicker" /> 컴포넌트의 모양을 수정할 수도 있습니다.

`prefix` 및 `suffix` 슬롯을 사용하면 입력 필드 앞이나 뒤에 사용자 지정 콘텐츠를 삽입할 수 있습니다(단일 입력 모드에서만 사용 가능):

<PlatformBlock for="WebComponents">

```html
<igc-date-range-picker>
  <igc-icon slot="prefix" name="down_arrow_icon"></igc-icon>
  <igc-icon slot="suffix" name="upload_icon"></igc-icon>
</igc-date-range-picker>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx

```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

</IgbDateRangePicker>
```

</PlatformBlock>

두 개 입력 모드에서는 대신 `prefix-start`, `prefix-end`, `suffix-start`, `suffix-end` 슬롯을 사용하여 개별 입력을 대상으로 지정할 수 있습니다. 모든 `prefix-` 및 `suffix-` 유형 슬롯에는 간단한 텍스트, 기호 또는 이모지에 `<span>` 요소를, 아이콘에는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다.

유용한 슬롯의 또 다른 세트는 `clear-icon`과 `calendar-icon`입니다. 이 슬롯을 사용하면 입력 필드의 지우기 버튼과 달력 버튼 아이콘을 사용자 지정할 수 있습니다. 이 슬롯에서도 기호나 이모지에는 `<span>` 요소를, 아이콘에는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다.

```html
</igc-date-range-picker>
```

</PlatformBlock>

<PlatformBlock for="React">


`actions` 슬롯을 사용하면 자체 로직이 있는 사용자 지정 작업 버튼을 삽입할 수 있습니다. 예를 들어 아래 버튼은 달력의 주 번호 열을 켜고 끕니다. `actions` 슬롯에 콘텐츠를 추가할 때는 [`<igc-button>`](../inputs/button.mdx) 컴포넌트를 사용하는 것을 권장합니다.

```razor
}
```

이미 다룬 슬롯 외에도 <ApiLink pkg="core" type="DateRangePicker" /> 컴포넌트에서는 다음 슬롯을 사용할 수 있습니다:

|이름|설명|
|--|--|
| `title` | 달력 제목의 콘텐츠를 렌더링합니다. 대화 상자 모드에서만 적용됩니다. |
| `helper-text` | 입력 필드 아래의 콘텐츠를 렌더링합니다. |
| `header-date` | 달력 헤더의 기본 현재 날짜/범위 텍스트를 대체합니다. 대화 상자 모드에서만 적용됩니다. |
| `clear-icon-start` | 시작 입력(두 개 입력 모드)의 사용자 지정 지우기 아이콘입니다. |
| `clear-icon-end` | 종료 입력(두 개 입력 모드)의 사용자 지정 지우기 아이콘입니다. |
| `calendar-icon-start` | 시작 입력(두 개 입력 모드)의 사용자 지정 달력 아이콘입니다. |
| `calendar-icon-end` | 종료 입력(두 개 입력 모드)의 사용자 지정 달력 아이콘입니다. |
| `calendar-icon-open` | picker가 열려 있을 때 표시되는 아이콘 또는 콘텐츠입니다(두 개 입력 모드에서는 두 입력 모두에 적용됩니다). |
| `calendar-icon-open-start` | 시작 입력(두 개 입력 모드)의 열린 상태에 대한 아이콘 또는 콘텐츠입니다.|
| `calendar-icon-open-end` | 종료 입력(두 개 입력 모드)의 열린 상태에 대한 아이콘 또는 콘텐츠입니다. |

`title`, `helper-text`, `header-date` 슬롯에는 `<span>` 요소를 사용하는 것을 권장합니다. `<span>`은(는) 컴포넌트의 의도한 타이포그래피와 레이아웃을 방해할 수 있는 기본 스타일 속성을 가지지 않은 채, 컴포넌트 스타일을 깔끔하게 상속받는 중립적인 컨테이너를 제공합니다.

`clear-icon-` 및 `calendar-icon-` 유형 슬롯에는 기호나 이모지에 `<span>` 요소를, 아이콘에는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다.

| <ApiLink pkg="core" type="DateRangePicker" member="clear" label="Clear" /> | 입력 필드를 지워 사용자 입력을 모두 제거합니다. |

| <ApiLink pkg="core" type="DateRangePicker" member="setCustomValidity" label="SetCustomValidity" /> | 사용자 지정 검증 메시지를 설정합니다. 제공된 메시지가 비어 있지 않으면 입력이 유효하지 않음으로 표시됩니다. |

## 스타일링

<ApiLink pkg="core" type="DateRangePicker" /> 컴포넌트는 <ApiLink pkg="core" type="Calendar" /> 컴포넌트를 사용하므로 달력의 CSS 파트도 상속하여 두 컴포넌트의 스타일을 매끄럽게 지정할 수 있습니다. 노출된 달력 CSS 파트의 전체 목록은 여기에서 확인할 수 있습니다: [달력 스타일 지정](./calendar.mdx#스타일링). 달력의 CSS 파트 외에도 <ApiLink pkg="core" type="DateRangePicker" />은(는) 모양을 사용자 지정하는 데 사용할 수 있는 고유한 CSS 파트도 노출합니다:

|이름|설명|
|--|--|
| `separator` | 두 입력 사이의 구분자 요소입니다. |
| `ranges` | 사용자 지정 범위와 미리 정의된 범위를 렌더링하는 래퍼입니다. |
| `label` | 대상 입력 위에 콘텐츠를 렌더링하는 레이블 래퍼입니다. |
| `container` | 모든 주요 입력 요소를 담는 기본 래퍼입니다. |
| `input` | 네이티브 input 요소입니다. |
| `prefix` | 접두사 래퍼입니다. |
| `suffix` | 접미사 래퍼입니다. |
| `calendar-icon` | 닫힌 상태의 달력 아이콘 래퍼입니다. |
| `calendar-icon-start` | 시작 입력(두 개 입력)의 닫힌 상태에 대한 달력 아이콘 래퍼입니다. |
| `calendar-icon-end` | 종료 입력(두 개 입력)의 닫힌 상태에 대한 달력 아이콘 래퍼입니다. |
| `calendar-icon-open` | 열린 상태의 달력 아이콘 래퍼입니다. |
| `calendar-icon-open-start` | 시작 입력(두 개 입력)의 열린 상태에 대한 달력 아이콘 래퍼입니다. |
| `calendar-icon-open-end` | 종료 입력(두 개 입력)의 열린 상태에 대한 달력 아이콘 래퍼입니다. |
| `clear-icon` | 지우기 아이콘 래퍼입니다(단일 입력). |
| `clear-icon-start` | 시작 입력(두 개 입력)의 지우기 아이콘 래퍼입니다. |
| `clear-icon-end` | 종료 입력(두 개 입력)의 지우기 아이콘 래퍼입니다. |
| `actions` | 작업 래퍼입니다. |
| `helper-text` | 대상 입력 아래에 콘텐츠를 렌더링하는 도움말 텍스트 래퍼입니다. |

```css
igc-date-range-picker::part(label) {
  color: var(--ig-gray-600);
}

igc-date-range-picker::part(calendar-icon-start),
igc-date-range-picker::part(calendar-icon-end) {

igc-date-range-picker::part(calendar-icon-open-start),

  background-color: var(--ig-error-500);
```
