# {Platform} Calendar 개요

{ProductName} Calendar 컴포넌트는 가볍고 구성하기 쉽습니다. 날짜와 요일을 표시하는 데 사용되며, 최종 사용자에게 월간 또는 연간 보기를 제공하는 가장 좋은 방법이기도 합니다. {ProductName} Calendar 컨트롤을 사용하면 사용자가 이동할 수 있는 최소 및 최대 날짜 범위를 제한할 수 있습니다.

Ignite UI for {ProductName} Calendar는 날짜 정보를 표시하는 쉽고 직관적인 방법을 제공합니다. 단일 또는 다중 날짜 선택 모드, 날짜 범위 강조 및 선택, 키보드 탐색, 주 번호 활성화, 크기 및 간격 옵션 등 다양한 기능을 갖추고 있습니다.

### 헤더 옵션

기본적으로 {ProductName} Calendar 컴포넌트는 선택된 날짜 정보를 담은 헤더 영역을 렌더링합니다. <ApiLink type="Calendar" member="hasHeader" /> 속성을 **false**로 설정하면 헤더를 숨길 수 있습니다. <ApiLink pkg="core" type="Calendar" member="headerOrientation" /> 속성을 사용하여 헤더의 `vertical` 또는 `horizontal` 방향을 구성할 수도 있습니다.

<DocsAside type="info">
<ApiLink pkg="core" type="Calendar" member="selection" />이(가) multiple로 설정되어 있으면 {ProductName} Calendar 헤더는 렌더링되지 않습니다.
</DocsAside>

<DocsAside type="info">
{ProductName} Calendar의 DOM 속성은 `camelCase` 명명 규칙을 사용하고, 이에 대응하는 HTML 속성은 `kebab-case`을 사용합니다. 예를 들어 <ApiLink pkg="core" type="Calendar" member="headerOrientation" label="HeaderOrientation" /> 속성은 `header-orientation` 속성에 대응합니다.
</DocsAside>

{ProductName} Calendar 컴포넌트는 헤더의 제목을 사용자 지정할 수 있는 `title` 슬롯을 노출합니다.

### 현지화 및 형식 지정

### 비활성화된 날짜

경우에 따라 최종 사용자가 선택할 수 없는 비활성화된 날짜를 달력에 표시하고 싶을 수 있습니다. 이 기능은 <ApiLink pkg="core" type="Calendar" member="disabledDates" /> 속성을 사용하여 구현합니다. <ApiLink pkg="core" type="Calendar" member="disabledDates" /> 속성은 <ApiLink pkg="core" type="DateRangeDescriptor" /> 객체의 배열입니다. 각 설명자에는 <ApiLink type="Type" />와 선택적인 <ApiLink type="SparklineGroup" member="dateRange" label="DateRange" />가 있으며, 후자는 `Date` 객체의 배열입니다.

<ApiLink type="Type" /> 속성에 사용할 수 있는 옵션은 다음과 같습니다:

- `After` - <ApiLink type="SparklineGroup" member="dateRange" label="DateRange" />의 첫 번째 날짜 이후의 날짜를 비활성화합니다.
- `Before` - <ApiLink type="SparklineGroup" member="dateRange" label="DateRange" />의 첫 번째 날짜 이전의 날짜를 비활성화합니다.
- `Between` - <ApiLink type="SparklineGroup" member="dateRange" label="DateRange" />의 첫 번째 날짜와 두 번째 날짜 사이의 날짜를 비활성화합니다.
- `Specific` - <ApiLink type="SparklineGroup" member="dateRange" label="DateRange" /> 배열에 지정된 날짜를 비활성화합니다.
- `Weekdays` - 모든 평일을 비활성화합니다.
- `Weekends` - 모든 주말을 비활성화합니다.

현재 달의 3일부터 8일까지의 날짜를 비활성화하는 샘플을 만들어 보겠습니다:

```ts
const today = new Date(Date.now());
const range = [
    new Date(today.getFullYear(), today.getMonth(), 3),
    new Date(today.getFullYear(), today.getMonth(), 8)
];

this.calendar.disabledDates = [{ type: DateRangeType.Between, dateRange: range }];
```

## 키보드 탐색

<kbd>TAB</kbd> 키로 페이지를 이동한다면 [W3 접근성 권장 사항](https://www.w3.org/TR/wai-aria-practices/#layoutGrid)에 따라 <ApiLink pkg="core" type="Calendar" />에는 다음 탭 정지 지점이 있다는 점을 기억해야 합니다:

- 월 선택 버튼
- 연도 선택 버튼
- 이전 버튼
- 다음 버튼
- 활성 날짜 요소

<ApiLink pkg="core" type="Calendar" /> 컴포넌트의 **일/월/연도**에 포커스가 있을 때는 다음을 사용하십시오:

- 이전 월/연도/연도 페이지로 이동하려면 <kbd>PAGE UP</kbd> 키를 사용하십시오.
- 다음 월/연도/연도 페이지로 이동하려면 <kbd>PAGE DOWN</kbd> 키를 사용하십시오.
- 현재 월의 첫 번째 날/보이는 첫 번째 월/보이는 첫 번째 연도로 포커스를 이동하려면 <kbd>HOME</kbd> 키를 사용하십시오.
- 현재 월의 마지막 날/보이는 마지막 월/보이는 마지막 연도로 포커스를 이동하려면 <kbd>END</kbd> 키를 사용하십시오.
- 날짜/월/연도 사이를 이동하려면 <kbd>화살표</kbd> 키를 사용하십시오. 첫 번째 항목 이전이나 마지막 항목 이후로 이동하면 보기가 이전/다음 월/연도/연도 페이지로 바뀝니다.

`days` 보기 안의 **날짜**에 포커스가 있을 때는 다음을 사용하십시오:

- 이전 연도로 이동하려면 <kbd>SHIFT</kbd> + <kbd>PAGE UP</kbd> 키를 사용하십시오.
- 다음 연도로 이동하려면 <kbd>SHIFT</kbd> + <kbd>PAGE DOWN</kbd> 키를 사용하십시오.
- 현재 포커스가 있는 날짜를 선택하려면 <kbd>SPACE</kbd> 또는 <kbd>ENTER</kbd> 키를 사용하십시오.

`months` 보기 안의 **월**에 포커스가 있을 때는 다음을 사용하십시오:

- 현재 포커스가 있는 월로 <ApiLink pkg="core" type="Calendar" member="activeDate" />을(를) 바꾸고 `days` 보기로 전환하려면 <kbd>SPACE</kbd> 또는 <kbd>ENTER</kbd> 키를 사용하십시오.

`years` 보기 안의 **연도**에 포커스가 있을 때는 다음을 사용하십시오:

- 현재 포커스가 있는 연도로 <ApiLink pkg="core" type="Calendar" member="activeDate" />을(를) 바꾸고 `months` 보기로 전환하려면 <kbd>SPACE</kbd> 또는 <kbd>ENTER</kbd> 키를 사용하십시오.

(부제목의) **이전** 또는 **다음** 버튼에 포커스가 있을 때는 다음을 사용하십시오:

- 이전/다음 월/연도/연도 페이지로 전환하려면 <kbd>SPACE</kbd> 또는 <kbd>ENTER</kbd> 키를 사용하십시오.

(부제목의) **월** 버튼에 포커스가 있을 때는 다음을 사용하십시오:

- `months` 보기로 전환하려면 <kbd>SPACE</kbd> 또는 <kbd>ENTER</kbd> 키를 사용하십시오.

(부제목의) **연도** 버튼에 포커스가 있을 때는 다음을 사용하십시오:

- `years` 보기로 전환하려면 <kbd>SPACE</kbd> 또는 <kbd>ENTER</kbd> 키를 사용하십시오.
