# {Platform} Date Picker 컴포넌트 개요

{ProductName} Date Picker는 수동 텍스트 입력이나 팝업으로 열리는 달력 대화 상자에서 날짜 값을 선택하여 날짜를 입력하는 데 사용되는 기능이 풍부한 컴포넌트입니다. 가볍고 사용하기 쉬우며, 사용자는 월, 연도, 십 년이라는 여러 보기 옵션으로 원하는 날짜로 이동할 수 있습니다. 또한 최소 및 최대 날짜 제약과 필수 필드 같은 일반적인 검증 속성도 지원합니다.

{ProductName} Date Picker 컴포넌트를 사용하면 사용자가 월 보기 달력 드롭다운이나 편집 가능한 입력 필드를 통해 단일 날짜를 선택할 수 있습니다. {Platform} Date Picker는 달력에서만 선택하는 대화 상자 모드, 로캘을 인식하고 사용자 지정할 수 있는 날짜 서식 지정, 그리고 검증 통합도 지원합니다.

### 컴포넌트 투사

입력의 주 콘텐츠 앞뒤에 다른 콘텐츠를 추가할 수 있도록 `prefix` 및 `suffix` 슬롯을 사용할 수 있습니다. 슬롯에 콘텐츠를 배치할 때는 `prefix` 및 `suffix` 슬롯에 간단한 텍스트, 기호 또는 이모지를 추가할 때는 `<span>` 요소를, 아이콘을 추가할 때는 [`<igc-icon>`](../layouts/icon.mdx) 컴포넌트를 사용하는 것을 권장합니다.

입력 아래에 힌트를 표시하는 `helper-text` 슬롯도 노출되어 있습니다. `helper-text` 슬롯에 콘텐츠를 배치할 때는 `<span>` 요소를 사용하는 것을 권장합니다.

<PlatformBlock for="WebComponents">

```html
<igc-date-picker id="DatePicker">
    <igc-icon slot="suffix" name="arrow_upward" collection="material" class="small" onclick="DatePicker.stepUp()"></igc-icon>
</igc-date-picker>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrDatePicker>
    <IgrIcon
        slot="suffix"
        name="arrow_upward"
        collection="material"
        className="small"
        onClick={() => datePickerRef.current.stepUp(DatePart.Month)}>
    </IgrIcon>
</IgrDatePicker>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDatePicker @ref="DatePicker">
    <IgbIcon
        Slot="suffix"
        IconName="arrow_upward"
        Collection="bootstrap"
        Class="small"
        @onclick="() => DatePicker.StepUp(DatePart.Month)">
    </IgbIcon>
</IgbDatePicker>
```

</PlatformBlock>

위 스니펫은 기본 지우기 아이콘 바로 뒤, 입력의 끝에 추가 아이콘을 하나 더 추가합니다. 접두사와 접미사는 차례로 쌓일 수 있으므로 기본 토글 아이콘은 제거되지 않습니다.

### 키보드 탐색

<ApiLink pkg="core" type="DatePicker" />은(는) 직관적인 키보드 탐색을 제공하므로, 마우스를 건드리지 않고도 값을 증가 또는 감소시키거나 여러 DateParts 사이를 쉽게 이동할 수 있습니다.

|키|설명|
|----|-----------|
| <kbd>←</kbd> | 한 글자 앞으로 이동 |
| <kbd>→</kbd> | 한 글자 뒤로 이동 |
| <kbd>HOME</kbd> | 처음으로 이동 |
| <kbd>END</kbd> | 끝으로 이동 |
| <kbd>CTRL</kbd> / <kbd>CMD</kbd> + <kbd>←</kbd> | 날짜/시간 구역의 시작으로 이동 - 현재 구역 또는 왼쪽 구역 |
| <kbd>CTRL</kbd> / <kbd>CMD</kbd> + <kbd>→</kbd> | 날짜/시간 구역의 끝으로 이동 - 현재 구역 또는 오른쪽 구역 |
| 날짜/시간 부분에 포커스 + <kbd>↓</kbd> | 날짜/시간 부분을 감소시킵니다 |
| 날짜/시간 부분에 포커스 + <kbd>↑</kbd> | 날짜/시간 부분을 증가시킵니다 |
| <kbd>CTRL</kbd> / <kbd>CMD</kbd> + <kbd>;</kbd> | 현재 날짜/시간을 편집기의 값으로 설정합니다 |
| <kbd>ESC</kbd> | 캘린더 팝업을 닫고 입력 필드에 포커스를 줍니다 |

### 표시 및 입력 형식

<ApiLink pkg="core" type="DatePicker" member="inputFormat" /> 및 <ApiLink pkg="core" type="DatePicker" member="displayFormat" />는 picker의 편집기가 지정된 형식을 따르도록 설정할 수 있는 속성입니다. <ApiLink pkg="core" type="DatePicker" member="inputFormat" />은(는) 로캘을 기반으로 하므로, 제공하지 않으면 picker는 브라우저가 사용하는 형식을 기본값으로 사용합니다.

참고로 Date Picker 컴포넌트는 앞에 0이 없는 형식으로 제공된 `date` 및 `month` 부분에 항상 앞자리 0을 추가합니다. 예를 들어 `d/M/yy`은(는) `dd/MM/yy`이(가) 됩니다. 이는 편집 중에만 적용됩니다.

<ApiLink pkg="core" type="DatePicker" member="displayFormat" />은(는) picker가 포커스를 받지 않을 때 입력을 서식 지정하는 데 사용됩니다. <ApiLink pkg="core" type="DatePicker" member="displayFormat" />을(를) 제공하지 않으면 picker는 <ApiLink pkg="core" type="DatePicker" member="inputFormat" />을(를) <ApiLink pkg="core" type="DatePicker" member="displayFormat" />로 사용합니다.

이에 대한 자세한 내용은 <ApiLink pkg="core" type="DateTimeInput" /> 형식 섹션에서 확인할 수 있습니다.

### 양식에서

<ApiLink pkg="core" type="DatePicker" />은(는) 양식 요소에서 사용할 수 있으며, 컴포넌트의 <ApiLink pkg="core" type="DatePicker" member="min" /> 및 <ApiLink pkg="core" type="DatePicker" member="max" /> 속성은 양식 검증 도구 역할을 합니다.

<PlatformBlock for="WebComponents">

양식에서는 컴포넌트의 `igcChange` 이벤트를 처리하여 레이블의 값을 업데이트할 수 있습니다.

</PlatformBlock>

<PlatformBlock for="React">

양식에서는 컴포넌트의 `change` 이벤트를 처리하여 레이블의 값을 업데이트할 수 있습니다.

</PlatformBlock>

<PlatformBlock for="Blazor">

양식에서는 컴포넌트의 값을 `@bind-Value`에 바인딩하십시오. 샘플에서 picker는 필수이며, 양식의 `@onsubmit` 핸들러는 페이지를 다시 로드하지 않고 제출된 날짜를 표시합니다. 기본 재설정 버튼은 change 이벤트를 발생시키지 않고 picker를 초기 값으로 되돌리므로, `@onreset` 핸들러가 바인딩된 필드를 지웁니다.

</PlatformBlock>

### 캘린더 전용 설정

<ApiLink pkg="core" type="DatePicker" />은(는) Date Picker가 노출하는 속성을 통해 달력의 일부 설정을 변경할 수 있습니다. 이 중에는 picker가 펼쳐질 때 두 개 이상의 달력을 표시할 수 있게 하는 <ApiLink pkg="core" type="DatePicker" member="visibleMonths" />, 한 주의 시작 요일을 결정하는 <ApiLink type="FieldPipeArgs" member="weekStart" />, 연중 각 주의 번호를 표시하는 <ApiLink pkg="core" type="DatePicker" member="showWeekNumbers" /> 등이 있습니다.
