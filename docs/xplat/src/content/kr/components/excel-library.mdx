# {Platform} Excel 라이브러리 개요

Infragistics {Platform} Excel 라이브러리를 사용하면 <ApiLink type="Workbook" />, <ApiLink type="Worksheet" />, <ApiLink type="WorksheetCell" label="Cell" />, <ApiLink type="Formula" /> 등 익숙한 Microsoft® Excel® 스프레드시트 객체로 스프레드시트 데이터를 다룰 수 있습니다. Infragistics {Platform} Excel 라이브러리를 사용하면 애플리케이션의 데이터를 Excel 스프레드시트로 쉽게 표현하고, Excel에서 애플리케이션으로 데이터를 옮길 수 있습니다.

## 모듈 구현


- **IgxExcelCoreModule** – 객체 모델과 Excel 기반 구조의 대부분을 포함합니다.
- **IgxExcelFunctionsModule** – Sum, Average, Min, Max 등 수식 계산을 위한 대부분의 함수를 포함합니다. 계산될 수식이라면 이 모듈이 없어도 수식 파싱에 문제가 생기지 않습니다. 예를 들어 "=SUM(A1:A5)" 같은 수식을 적용하고 셀의 Value를 요청하면 #NAME! 오류가 반환됩니다. 이는 예외를 던지는 것이 아니라, 수식이 오류를 결과로 낼 수 있으므로 특정 오류를 나타내는 객체입니다.
- **IgxExcelXlsModule** – xls(및 관련) 유형 파일, 즉 Excel97to2003 관련 WorkbookFormat의 불러오기 및 저장 로직을 포함합니다.
- **IgxExcelXlsxModule** – xlsx(및 관련) 유형 파일, 즉 Excel2007 관련 및 StrictOpenXml WorkbookFormat의 불러오기 및 저장 로직을 포함합니다.
- **IgxExcelModule** – 나머지 4개 모듈을 참조하므로, 기본적으로 모든 기능이 로드되고 사용 가능하도록 보장합니다.


</PlatformBlock>

## 요구 사항

{Platform} Excel 라이브러리를 사용하려면 다음과 같이 Excel Library NuGet 패키지를 추가해야 합니다:

```cmd
> dotnet add package IgniteUI.Blazor.Documents.Excel
```

다음 using 문을 추가하십시오:

```razor
@using Infragistics.Documents.Excel
```

Blazor WebAssembly(WASM) 프로젝트를 사용하는 경우 몇 가지 추가 단계가 있습니다:

- wwwroot/index.html 파일에 다음 스크립트에 대한 참조를 추가하십시오:

```razor
<script src="_content/IgniteUI.Blazor.Documents.Excel/excel.js"></script>
```

- 정적 <ApiLink type="Workbook" member="InProcessRuntime" label="Workbook.InProcessRuntime" />를 현재 런타임으로 설정하십시오. 이는 다음 코드를 사용하여 수행할 수 있습니다:

```razor
@using Microsoft.JSInterop

@code {

    [Inject]
    public IJSRuntime Runtime { get; set; }

    protected override void OnInitialized()
    {
        base.OnInitialized();
        Workbook.InProcessRuntime = (IJSInProcessRuntime)this.Runtime;
    }
}
```

<PlatformBlock for="Blazor">

```csharp
protected override void OnInitialized()
{
    var memoryStream = new System.IO.MemoryStream();
    workbook.Save(memoryStream);

    memoryStream.Position = 0;
    var bytes = memoryStream.ToArray();
    this.SaveFile(bytes, "fileName.xlsx", string.Empty);
}

private void SaveFile(byte[] bytes, string fileName, string mime)
{
    if (this.Runtime is WebAssemblyJSRuntime wasmRuntime)
      wasmRuntime.InvokeUnmarshalled<string, string, byte[], bool>("BlazorDownloadFileFast", fileName, mime, bytes);
    else if (this.Runtime is IJSInProcessRuntime inProc)
      inProc.InvokeVoid("BlazorDownloadFile", fileName, mime, bytes);
}
```

</PlatformBlock>

## 힙 관리

Excel 라이브러리의 크기 때문에 소스 맵 생성을 비활성화하는 것을 권장합니다.

architect => build => options 및 serve => options에서 `vendorSourceMap` 옵션을 설정하여 `angular.json`를 수정하십시오:

```ts
    "architect": {
        "build": {
          "builder": "...",
          "options": {
            "vendorSourceMap": false,
            "outputPath": "dist",
            "index": "src/index.html",
            "main": "src/main.ts",
            "tsConfig": "src/tsconfig.app.json",
                  // ...
          },
              // ...
        },
        "serve": {
          "builder": "...",
          "options": {
            "vendorSourceMap": false,
            "browserTarget": "my-app:build"
          },
              // ...
        },
        // ...
      }
```
