# {Platform} Open Street Maps의 이미지 표시

{Platform} `OpenStreetMapImagery`는 전 세계 OpenStreetMap© 기여자들이 함께 만든 무료 지리 이미지 매핑 서비스입니다. 구성 옵션 없이 도로 지도 스타일로만 세계의 지리 이미지 타일을 제공합니다. 이 지리 이미지 서비스는 <a href="http://www.openstreetmap.org" target="_blank">www.OpenStreetMap.org</a> 웹사이트에서 직접 접근할 수 있습니다.
기본적으로 {ProductName} 지도 컴포넌트는 이미 Open Street Maps의 지리 이미지를 표시합니다. 따라서 Open Street Maps의 지리 이미지를 표시하기 위해 컨트롤을 구성할 필요는 없습니다.

## 코드 조각
이 코드 예제는 지도 컴포넌트의 `backgroundContent`를 OpenStreetMap© 기여자들의 지리 이미지를 제공하는 `OpenStreetMapImagery` 객체로 명시적으로 설정합니다.

```json-snippet source="/maps/geo-map/display-osm-imagery"
{
    "type": "GeographicMap",
    "$setInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "$assignInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "backgroundContent": {
        "type": "OpenStreetMapImagery",
        "name": "osmImagery"
    },
    "$type": "+doc:markup"
}
```
