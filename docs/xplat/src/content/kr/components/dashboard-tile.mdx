# {Platform} 대시보드 타일 <Badge variant="preview" />

{Platform} 대시보드 타일은 DataSource 컬렉션/배열 또는 단일 데이터 지점을 분석하여 표시하기에 가장 적합한 시각화를 결정하는 자동 데이터 시각화 컴포넌트입니다. 그다음 내장된 `Toolbar`에서 다양한 방식으로 표시되는 시각화를 변경할 수 있는 추가 도구 세트를 제공합니다.

제공된 데이터의 형태에 따라 카테고리 차트, 방사형 및 극좌표 차트, 산점도 차트, 지리 맵, 방사형 및 선형 게이지, 금융 차트, 누적 차트 등 다양한 시각화를 표시하도록 선택할 수 있습니다(이에 국한되지 않음).

도구 모음의 차트 유형 메뉴와 상호 작용하면 가능성이 높은 후보 목록에서 다른 시각화를 선택할 수 있습니다.

## 사용법

대시보드 타일의 `DashboardTile.DataSource` 속성에 무엇을 바인딩하느냐에 따라 기본적으로 보이는 시각화가 결정됩니다. 컨트롤이 바인딩된 데이터를 평가한 후 {ProductName} 툴셋에서 표시할 시각화를 선택하기 때문입니다. 대시보드 타일에 표시되도록 포함된 데이터 시각화 컨트롤은 다음과 같습니다:

- [{IgPrefix}CategoryChart](./charts/chart-overview.mdx)
- [{IgPrefix}DataChart](./charts/chart-overview.mdx)
- [{IgPrefix}DataPieChart](./charts/types/data-pie-chart.mdx)
- [{IgPrefix}GeographicMap](./geo-map.mdx)
- [{IgPrefix}Linear Gauge](./linear-gauge.mdx)
- [{IgPrefix}RadialGauge](./radial-gauge.mdx)

<PlatformBlock for="WinUI,Uno">

빌드와 패키징은 명시적으로 참조되지 않은 시각화 유형을 제거할 수 있습니다. 필요한 것을 유지하려면 App.xaml.cs의 App 생성자에서 해당 기능을 등록하십시오:

```csharp
public App()
{ 
    WinUIDataChartDashboardTileFeature.Register();
    WinUIPieChartDashboardTileFeature.Register();
    WinUIRadialGaugeDashboardTileFeature.Register();
    WinUILinearGaugeDashboardTileFeature.Register();
    WinUIGeographicMapDashboardTileFeature.Register();

    this.InitializeComponent();
}
```

</PlatformBlock>

기본적으로 선택되는 데이터 시각화는 주로 바인딩한 `DashboardTile.DataSource`의 스키마와 개수에 따라 달라집니다. 예를 들어 단일 숫자 값을 바인딩하면 `RadialGauge`를 얻게 되고, 서로 쉽게 구별되는 값-레이블 쌍의 컬렉션을 바인딩하면 아마 `DataPieChart`를 얻게 됩니다. 값 경로가 더 많은 `DashboardTile.DataSource`를 바인딩하면, 주로 바인딩된 컬렉션의 개수에 따라 여러 열 시리즈 또는 선 시리즈가 있는 `DataChart`를 받게 됩니다. 또한 `ShapeDataSource` 또는 지리 점처럼 보이는 데이터에 바인딩하여 `GeographicMap`를 받을 수도 있습니다.

`DashboardTile.DataSource`를 바인딩할 때 단일 시각화에 고정되지 않으며, `VisualizationType` 속성을 설정하여 컨트롤에 특정 시각화를 보고 싶다고 알릴 수 있습니다. 예를 들어 선 차트를 특별히 보고 싶다면 다음과 같이 대시보드 타일을 정의할 수 있습니다:

```json-snippet
{
    "type": "DashboardTile",
    "name": "dashboard",
    "visualizationType": "LineChart"
}
```

시각화 또는 시각화의 속성은 컨트롤 상단의 `Toolbar`를 사용하여 구성할 수도 있습니다. 이 `Toolbar`에는 현재 시각화의 기본 도구와 아래에 강조된 대시보드 타일 전용 도구 네 가지가 추가되어 있습니다:

<Image src={dashboardTileToolbar} alt="대시보드 타일 도구 모음" />

왼쪽에서 오른쪽으로:

- 첫 번째 도구는 컨트롤에 제공된 `DashboardTile.DataSource`를 데이터 그리드로 표시합니다. 이는 토글 도구이므로, 그리드를 표시한 후 다시 클릭하면 시각화로 돌아갑니다.
- 두 번째 도구를 사용하면 현재 데이터 시각화의 설정을 구성할 수 있습니다.
- 세 번째 도구를 사용하면 현재 시각화를 변경하여 다른 시리즈 유형을 플롯하거나 완전히 다른 유형의 시각화를 표시할 수 있습니다. 이는 위에서 언급한 `VisualizationType` 속성을 설정하여 컨트롤에서 설정할 수 있습니다.
- 마지막 도구를 사용하면 컨트롤에 포함될 기본 데이터 항목의 속성을 구성할 수 있습니다. 컨트롤의 `includedProperties` 또는 `excludedProperties` 컬렉션을 설정하여 구성할 수 있습니다.
