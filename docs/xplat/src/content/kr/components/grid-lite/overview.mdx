### IgniteUI.Blazor.GridLite 설치

{GridLiteTitle}는 NuGet.org의 MIT 라이선스 [IgniteUI.Blazor.GridLite](https://www.nuget.org/packages/IgniteUI.Blazor.GridLite) 패키지에 포함되어 있습니다. 소스는 [GitHub]({GithubLinkLite})에 있습니다.

Visual Studio에서 **도구** → **NuGet 패키지 관리자** → **솔루션용 NuGet 패키지 관리**를 선택하여 NuGet 패키지 관리자를 여십시오. **IgniteUI.Blazor.GridLite** NuGet 패키지를 검색하여 설치하십시오.

또는 패키지 관리자 콘솔을 통해 설치하십시오:

```cmd
Install-Package IgniteUI.Blazor.GridLite
```

또는 .NET CLI를 통해 설치하십시오:

```cmd
dotnet add package IgniteUI.Blazor.GridLite
```

### Grid Lite 사용하기

1 - **_Imports.razor** 파일에 **IgniteUI.Blazor.Controls** 네임스페이스를 추가하십시오:

```razor
@using IgniteUI.Blazor.Controls
```

2 - 호스트 페이지에 테마 스타일시트를 추가하십시오. Blazor Web App에서는 **Components/App.razor**에, 독립형 Blazor WebAssembly 앱에서는 **wwwroot/index.html**에 추가합니다.

앱이 `IgniteUI.Blazor.Lite` 또는 `IgniteUI.Blazor` 패키지도 사용한다면, 그 패키지의 [테마 스타일시트](../themes/overview.mdx)를 유지하십시오. 이것도 그리드에 스타일을 적용합니다. 그렇지 않다면 `IgniteUI.Blazor.GridLite` 패키지가 제공하는 테마 중 하나를 연결하십시오:

```razor
<head>
    <link href="_content/IgniteUI.Blazor.GridLite/themes/light/bootstrap.css" rel="stylesheet" />
</head>
```

테마는 `themes/{light|dark}/{bootstrap|material|fluent|indigo}.css`이며, [스타일 및 테마](./theming.mdx)를 참조하십시오.

그리드에는 서비스 등록이나 script 태그가 필요하지 않습니다. Blazor Web App에서는 대화형 렌더 모드로 렌더링하십시오.

3 - Razor 페이지에 Grid Lite 컴포넌트를 추가하십시오:

```razor
<IgbGridLite Data="data" AutoGenerate="true">
</IgbGridLite>

@code {
    private object[] data = new object[]
    {
        new { Name = "John", Age = 30, City = "New York" },
        new { Name = "Jane", Age = 25, City = "Los Angeles" },
        new { Name = "Bob", Age = 35, City = "Chicago" }
    };
}
```

## Grid Lite는 무료이며 오픈 소스인 {Platform} 데이터 그리드입니까?

네. Ignite UI Grid Lite는 MIT 라이선스로 배포되는 무료 오픈 소스 {Platform} 데이터 그리드입니다. 라이선스 비용 없이 상업용 또는 개인 프로젝트에서 사용할 수 있습니다. Ignite UI를 더 개방적이고 투명하며 접근하기 쉽게 만드는 이니셔티브의 일부입니다.

- MIT 라이선스

- 상업적 사용 무료

- 커뮤니티 주도 개발

- 기능 제한 없음

하지만 프로젝트가 확장되어 복잡성과 기능이 늘고 엔터프라이즈급 애플리케이션이 필요하다면, 원활한 업그레이드 전략이 있습니다. 무료 {Platform} 데이터 그리드(Grid Lite)에서 기능이 풍부하고 고급인 Data Grid로의 전환을 더 간단하고 빠르게 만들어 줍니다.
