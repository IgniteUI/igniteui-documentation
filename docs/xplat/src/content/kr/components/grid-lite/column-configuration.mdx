# 열 구성

<PlatformBlock for="React, WebComponents">



열은 선언적으로 그리드 안의 열 자식 컴포넌트를 사용하여 정의합니다. `field` 속성은 열에 필요한 유일한 속성이며, 열의 식별자 역할을 합니다. 또한 그리드 행에서 관련 데이터를 매핑하고 렌더링하는 데 사용되는 속성이기도 합니다.


</PlatformBlock>



<PlatformBlock for="WebComponents">


```html
<igc-grid-lite .data=${data}>
  <igc-grid-lite-column
    field="account"
    header="Account Number"
    ...
  ></igc-grid-lite-column>
  <!-- Additional columns follow -->
</igc-grid-lite>
```

</PlatformBlock>


<PlatformBlock for="React">

```tsx
return (
  <IgrGridLite data={data}>
    <IgrGridLiteColumn
      field="account"
      header="Account Number"
      ...
    ></IgrGridLiteColumn>
    {/* Additional columns follow */}
  </IgrGridLite>
);
```

</PlatformBlock>


<PlatformBlock for="Blazor">



열은 그리드 안의 `<IgbGridLiteColumn>` 자식 요소를 사용하여 선언적으로 정의됩니다. <ApiLink type="Column" member="field" label="Field" /> 속성은 열의 식별자 역할을 하므로 열마다 필수입니다. 또한 그리드 행에 관련 데이터를 매핑하고 렌더링하는 데 사용되는 속성입니다.

```razor
<IgbGridLite Data="@products">
    <IgbGridLiteColumn 
        Field="Name"
        Header="Product Name"
        DataType="GridLiteColumnDataType.String" />
    <!-- Additional columns follow -->
</IgbGridLite>
```

## 데이터 소스를 기반으로 한 구성

`AutoGenerate`를 true로 설정하면, 그리드는 제공된 데이터 소스를 기준으로 열 구성을 추론하도록 지원합니다. 데이터의 레코드를 기준으로 적절한 <ApiLink type="Column" member="field" label="Field" />와 <ApiLink type="Column" member="dataType" label="DataType" /> 속성을 추론하려고 합니다.

```razor
<IgbGridLite AutoGenerate=true Data="@products"/>
@code {
    private List<ProductInfo> products;

    protected override void OnInitialized()
    {
        products = new List<ProductInfo>
        {
            new ProductInfo { Id = "1", Name = "example", Price = 10 },
            ...
        };
    }

    public class ProductInfo
    {
        public string Id { get; set; }
        public string Name { get; set; }
        public double Price { get; set; }
    }
}
```


</PlatformBlock>

## 데이터 소스를 기반으로 한 구성

`autoGenerate`이(가) true로 설정되면 그리드는 제공된 데이터 소스를 기반으로 열 구성을 추론할 수 있습니다. 데이터의 레코드를 기반으로 적절한 `field`와 `dataType`을(를) 추론하려고 시도합니다.

```typescript
const data: Record[] = [
  { entryId: "1234", source: "https://example.com", ts: 1373521917579 },
  ...
];
```

</PlatformBlock>



<PlatformBlock for="WebComponents">


```html
<igc-grid-lite auto-generate .data=${data}></igc-grid-lite>
```

</PlatformBlock>


<PlatformBlock for="React">

```tsx
return (
  <IgrGridLite data={data} autoGenerate={true}></IgrGridLite>
);
```

</PlatformBlock>

앞의 스니펫은 그리드가 다음과 같은 열을 자동으로 생성하는 결과를 낳습니다:


<PlatformBlock for="WebComponents">


```html
<igc-grid-lite .data=${data}>
  <igc-grid-lite-column field="entryId" data-type="string"></igc-grid-lite-column>
  <igc-grid-lite-column field="source" data-type="string"></igc-grid-lite-column>
  <igc-grid-lite-column field="ts" data-type="number"></igc-grid-lite-column>
</igc-grid-lite>
```

</PlatformBlock>


<PlatformBlock for="React">

```tsx
return (
  <IgrGridLite data={data}>
    <IgrGridLiteColumn field="entryId" dataType="string"></IgrGridLiteColumn>
    <IgrGridLiteColumn field="source" dataType="string"></IgrGridLiteColumn>
    <IgrGridLiteColumn field="ts" dataType="number"></IgrGridLiteColumn>
  </IgrGridLite>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbGridLite Data="@products">
    <IgbGridLiteColumn Field="Id" DataType="GridLiteColumnDataType.String" />
    <IgbGridLiteColumn Field="Name" DataType="GridLiteColumnDataType.String" />
    <IgbGridLiteColumn Field="Price" DataType="GridLiteColumnDataType.Number" />
</IgbGridLite>
```

</PlatformBlock>

추가 사용자 지정 없이 데이터를 빠르게 렌더링하는 데 유용합니다.


## 추가 열 구성

열은 사용자 지정을 위한 여러 속성을 더 노출합니다:

### 열 너비

기본적으로 열의 너비는 **minmax(136px, 1fr)**입니다. 이는 최소 너비 136px이고, {GridLiteTitle}의 사용 가능한 공간 중 최대 1 부분의 너비를 뜻합니다. 이렇게 하면 열이 유동적이며 그리드 너비의 변화에 반응합니다.


<PlatformBlock for="React, WebComponents">


열의 너비를 변경하려면 열의 `width` 속성을 사용하십시오.

</PlatformBlock>




<PlatformBlock for="WebComponents">


```html
<igc-grid-lite-column field="price" width="250px"></igc-grid-lite-column>
```

</PlatformBlock>


<PlatformBlock for="React">

```tsx
return (
  <IgrGridLite>
    <IgrGridLiteColumn field="price" width="250px"></IgrGridLiteColumn>
  </IgrGridLite>
);
```

</PlatformBlock>


<PlatformBlock for="Blazor">


열의 너비를 바꾸려면 <ApiLink type="IgbGridLiteColumn" /> 컴포넌트의 <ApiLink type="Column" member="width" label="Width" /> 매개변수를 사용하십시오.

```razor
<IgbGridLiteColumn Field="Price" Width="250px" />
```


</PlatformBlock>


이 속성은 <a href="https://developer.mozilla.org/en-US/docs/Learn/CSS/Building_blocks/Values_and_units#numbers_lengths_and_percentages" target="_blank">유효한 CSS 길이 단위</a>를 받습니다.

### 열 숨기기

<PlatformBlock for="React, WebComponents">


열의 `hidden` 속성을 설정하여 열을 숨기거나 표시할 수 있습니다.

</PlatformBlock>




<PlatformBlock for="WebComponents">


```html
<igc-grid-lite-column field="price" hidden></igc-grid-lite-column>
```

</PlatformBlock>


<PlatformBlock for="React">

```tsx
return (
  <IgrGridLite>
    <IgrGridLiteColumn field="price" hidden></IgrGridLiteColumn>
  </IgrGridLite>
);
```

</PlatformBlock>


<PlatformBlock for="Blazor">


<ApiLink type="IgbGridLiteColumn" /> 컴포넌트의 <ApiLink type="Column" member="hidden" label="Hidden" /> 매개변수를 설정하여 열을 숨기거나 표시할 수 있습니다.

```razor
<IgbGridLiteColumn Field="Price" Hidden="true" />
```


</PlatformBlock>


### 열 크기 조정


<PlatformBlock for="React, WebComponents">


{GridLiteTitle}의 각 열은 열 요소의 `resizable` 속성을 설정하여 크기 조정이 가능하도록 구성할 수 있습니다.

</PlatformBlock>



<PlatformBlock for="WebComponents">


```html
<igc-grid-lite-column field="price" resizable></igc-grid-lite-column>
```

</PlatformBlock>


<PlatformBlock for="React">

```tsx
return (
  <IgrGridLite>
    <IgrGridLiteColumn field="price" resizable></IgrGridLiteColumn>
  </IgrGridLite>
);
```

</PlatformBlock>


<PlatformBlock for="Blazor">


{GridLiteTitle}의 각 열은 <ApiLink type="IgbGridLiteColumn" /> 컴포넌트의 <ApiLink type="Column" member="resizable" label="Resizable" /> 매개변수를 설정하여 크기 조정이 가능하도록 구성할 수 있습니다.

```razor
<IgbGridLiteColumn Field="Price" Resizable="true" />
```


</PlatformBlock>


열이 크기 조정 가능하도록 설정되어 있으면 열 헤더의 오른쪽 가장자리를 드래그하여 열 너비를 늘리거나 줄일 수 있습니다. 크기 조정 영역을 두 번 클릭하면 열의 자동 크기 조정이 실행되며, 셀과 헤더의 가장 큰 콘텐츠에 맞춰 너비를 설정하려고 시도합니다.

<DocsAside type="info">
"fluid" 너비(fr, % 등)를 가진 열은 그리드 크기를 조정할 때 새 크기에 맞추려고 하므로 불규칙하게 동작할 수 있습니다. 애플리케이션 시나리오에 따라서는 사용자가 레이아웃 이동을 겪지 않도록 "hard" 단위를 사용하는 편이 나을 수 있습니다.
</DocsAside>
