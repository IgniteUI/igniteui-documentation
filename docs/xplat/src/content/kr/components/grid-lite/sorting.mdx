# 정렬 작업

<PlatformBlock for="React, WebComponents">


{GridLiteTitle}는 데이터 소스에 대한 정렬 작업을 지원합니다. 데이터 정렬은 열 단위로 제어되므로 정렬 가능한 열과 불가능한 열을 둘 다 가질 수 있으며, 그리드 자체는 특정 정렬 동작을 제어합니다. 기본적으로 열의 정렬은 열의 `sortable` 속성으로 명시적으로 구성하지 않는 한 비활성화되어 있습니다.

</PlatformBlock>


<PlatformBlock for="Blazor">


{GridLiteTitle}는 데이터 소스에 대한 정렬 작업을 지원합니다. 데이터 정렬은 열 단위로 제어되므로 정렬 가능한 열과 불가능한 열을 둘 다 가질 수 있으며, 그리드 자체는 특정 정렬 동작을 제어합니다. 기본적으로 열의 정렬은 열의 <ApiLink type="Column" member="sortable" label="Sortable" /> 속성으로 명시적으로 구성하지 않는 한 비활성화되어 있습니다.

</PlatformBlock>

사용자 지정 비교 로직을 사용하려면 `comparer` 함수를 사용하여 `sortConfiguration` 속성을 설정하십시오:

```typescript

column.sortConfiguration = {
  /**
   * Custom comparer function which will be used for sort operations for this column.
   * In the following sample, we compare the `name` values based on their length.
   */
  comparer: (a, b) => a.length - b.length
};
```

</PlatformBlock>

{GridLiteTitle}는 3단계 정렬을 지원하며 항상 활성화되어 있습니다. 최종 사용자가 정렬 가능한 열 머리글을 클릭하면 다음 방향 상태를 순환합니다:

</PlatformBlock>

## 정렬 모델


<PlatformBlock for="React, WebComponents">


{GridLiteTitle}에서 정렬 작업의 기본 구성 요소는 다음 속성을 가진 `SortingExpression<T>`입니다:

</PlatformBlock>


<PlatformBlock for="Blazor">


{GridLiteTitle}에서 정렬 작업의 기본 구성 요소는 다음 속성을 가진 <ApiLink type="IgbGridLiteSortingExpression" />입니다:

</PlatformBlock>



```typescript
type SortingExpression<T> = {
  /**
   * The `key` of the target column for the sort operation.
   */
  key: keyof T;
  /**
   * The sort direction for the operation.
   */
  direction: 'ascending' | 'descending' | 'none';
  /**
   * Should the operation be case sensitive. Applies to the default string type.
   * If not explicitly passed, it will use the value from the target column sort configuration if applicable.
   */
  caseSensitive?: boolean;
  /**
   * Specifies a custom comparer function for the operation.
   * Will use the value from the target column sort configuration if applicable.
   */
  comparer?: SortComparer<T, T[keyof T]>;
};
```

<PlatformBlock for="Blazor">

```csharp
public class IgbGridLiteSortingExpression
{
    /// <summary>
    /// The target column.
    /// </summary>
    public required string Key { get; set; }

    /// <summary>
    /// Sort direction for this operation.
    /// </summary>
    public GridLiteSortingDirection Direction { get; set; }

    /// <summary>
    /// Whether the sort operation should be case sensitive.
    /// If not provided, the value is resolved based on the column sort configuration.
    /// </summary>
    public bool? CaseSensitive { get; set; }
}
```

</PlatformBlock>

그리드는 정렬 API 메서드와 구성에 이 표현식을 소비하며, 최종 사용자가 컴포넌트와 상호 작용할 때 이벤트와 정렬 상태를 위해 이 표현식을 생성합니다. 자세한 내용은 아래를 참조하십시오.

## 정렬 API


<PlatformBlock for="React, WebComponents">


{GridLiteTitle}는 API에서 정렬 작업을 적용하는 두 가지 주요 방법을 제공합니다. `sort()`/`clearSort()` 메서드를 통하거나 `sortingExpressions` 속성을 통해서입니다.

`sort()` 메서드는 단일 표현식 또는 정렬 표현식의 배열을 받아, 그 표현식을 기준으로 그리드 데이터를 정렬합니다.

</PlatformBlock>



<PlatformBlock for="Blazor">


{GridLiteTitle}는 API에서 정렬 작업을 적용하는 두 가지 주요 방법을 제공합니다. `SortAsync()`/`ClearSortAsync()` 메서드를 통하거나 `SortingExpressions` 속성을 통해서입니다.

`SortAsync()` 메서드는 단일 식 또는 정렬 식의 컬렉션을 받은 다음, 그 식들을 기준으로 그리드 데이터를 정렬합니다.

</PlatformBlock>



<PlatformBlock for="WebComponents">


```typescript
// Single
grid.sort({ key: 'price', direction: 'descending' });

// Multiple
grid.sort([
  { key: 'price', direction: 'descending' },
  { key: 'name', direction: 'descending' },
]);
```

</PlatformBlock>


<PlatformBlock for="React">


```typescript
// Single
gridRef.current.sort({ key: 'price', direction: 'descending' });

// Multiple
gridRef.current.sort([
  { key: 'price', direction: 'descending' },
  { key: 'name', direction: 'descending' },
]);
```

</PlatformBlock>



<PlatformBlock for="Blazor">

```razor
// Single
await grid.SortAsync(new IgbGridLiteSortingExpression { Key = "Price", Direction = GridLiteSortingDirection.Descending });

// Multiple
await grid.SortAsync(new IgbGridLiteSortingExpression[]
{
    new IgbGridLiteSortingExpression { Key = "Price", Direction = GridLiteSortingDirection.Descending },
    new IgbGridLiteSortingExpression { Key = "Name", Direction = GridLiteSortingDirection.Descending }
});
```

</PlatformBlock>


<PlatformBlock for="React, WebComponents">


`clearSort()` 메서드는 이름에서 알 수 있듯이, 전달된 인수에 따라 단일 열 또는 그리드 컴포넌트 전체의 정렬 상태를 지웁니다.

</PlatformBlock>


<PlatformBlock for="Blazor">


`ClearSortAsync()` 메서드는 이름에서 알 수 있듯이, 전달된 인수에 따라 단일 열 또는 그리드 컴포넌트 전체의 정렬 상태를 지웁니다.

</PlatformBlock>



<PlatformBlock for="WebComponents">


```typescript

grid.clearSort();
```

</PlatformBlock>


<PlatformBlock for="React">


```typescript

// Clear the sort state of the grid.
```

### 초기 정렬 상태


<PlatformBlock for="React, WebComponents">


`sortingExpressions` 속성은 동작이 `sort()` 메서드 호출과 매우 비슷합니다. 그리드의 정렬 상태를 선언적으로 제어하는 방법을 제공하지만, 가장 유용한 점은 {GridLiteTitle}가 처음 렌더링될 때 초기 정렬 상태를 설정할 수 있다는 것입니다.

</PlatformBlock>



<PlatformBlock for="Blazor">


`SortingExpressions` 속성은 동작이 `SortAsync()` 메서드 호출과 매우 비슷합니다. 그리드의 정렬 상태를 선언적으로 제어하는 방법을 제공하지만, 가장 유용한 점은 {GridLiteTitle}가 처음 렌더링될 때 초기 정렬 상태를 설정할 수 있다는 것입니다.

</PlatformBlock>



<PlatformBlock for="WebComponents">

## 이벤트


<PlatformBlock for="React, WebComponents">


UI를 통해 정렬 작업이 수행되면 컴포넌트는 사용자 지정 `sorting` 이벤트를 발생시킵니다. `detail` 속성은 {GridLiteTitle}가 적용할 정렬 식입니다. 이 이벤트는 취소할 수 있으며, 취소되면 현재 정렬 작업을 중지합니다.

그리드가 새 정렬 상태를 적용한 후에는 `sorted` 이벤트가 발생합니다. 이 이벤트에는 마지막 정렬 작업에 사용된 표현식이 포함되며, 취소할 수 없습니다.

정렬을 원격으로 수행해야 하거나 현재 상태/데이터를 어딘가의 서버에 저장하고 싶은 경우, {GridLiteTitle}는 이 동작을 구현하고 사용자 지정할 수 있는 훅을 노출합니다.

<PlatformBlock for="React, WebComponents">
`dataPipelineConfiguration` 속성을 사용하면 정렬 작업이 실행되기 직전마다 호출되는 사용자 지정 훅을 제공할 수 있습니다. 콜백에는 <ApiLink type="DataPipelineParams" /> 객체가 전달됩니다.

```typescript
export type DataPipelineParams<T extends object> = {
  /**
   * The current data state of the grid.
   */
  data: T[];
  /**
   * The grid component itself.
   */
  grid: IgcGridLite<T>;
  /**
   * The type of data operation being performed.
   */
  type: 'sort' | 'filter';
};
```

<PlatformBlock for="WebComponents">
```typescript
grid.dataPipelineConfiguration = { sort: (params: DataPipelineParams<T>) => T[] | Promise<T[]> };
```
</PlatformBlock>
<PlatformBlock for="React">
```typescript
gridRef.current.dataPipelineConfiguration = { sort: (params: DataPipelineParams<T>) => T[] | Promise<T[]> };
```
</PlatformBlock>
