# 열 헤더 사용자 지정하기

셀 템플릿과 마찬가지로 열 헤더도 원하는 사용 사례에 더 잘 맞도록 사용자 지정할 수 있습니다. `header` 속성으로 텍스트 레이블을 전달하거나, 완전한 사용자 지정 템플릿을 제공할 수 있습니다.

## 헤더 텍스트로 사용자 지정하기

<PlatformBlock for="React, WebComponents">
기본적으로 열은 레이블 텍스트에 `field` 속성을 사용합니다. 레이블을 사용자 지정하려면 `header` 속성을 더 읽기 쉬운 형식으로 설정하십시오.
</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-grid-lite-column field="price" header="Price per item"></igc-grid-lite-column>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
return (
  <IgrGridLite>
    <IgrGridLiteColumn field="price" header="Price per item"></IgrGridLiteColumn>
  </IgrGridLite>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">
기본적으로 열은 레이블 텍스트에 <ApiLink type="Column" member="field" label="Field" /> 속성을 사용합니다. 레이블을 사용자 지정하려면 <ApiLink type="Column" member="header" label="Header" /> 속성을 더 읽기 쉬운 형식으로 설정하십시오.


```razor
<IgbGridLiteColumn Field="Price" Header="Price per item" />
```


</PlatformBlock>

<DocsAside type="info">
`headerTemplate`가 제공되면 `header`는 무시됩니다.
</DocsAside>

## 헤더 템플릿으로 사용자 지정하기

셀 템플릿과 마찬가지로 사용자 지정 템플릿 렌더러를 전달하고 열 헤더 안에 자체 DOM을 만들 수도 있습니다.

<PlatformBlock for="WebComponents">


```typescript
import { html } from 'lit';


const column = document.querySelector('igc-grid-lite-column');
column.headerTemplate = () => html`<h3>⭐ Rating ⭐</h3>`;
```

</PlatformBlock>
<PlatformBlock for="React">


```tsx
const ratingHeaderTemplate = (ctx: IgrHeaderContext) => (
  <h3>{"⭐ Rating ⭐"}</h3>
);


return (
  <IgrGridLite>
    <IgrGridLiteColumn field="rating" headerTemplate={ratingHeaderTemplate}></IgrGridLiteColumn>
  </IgrGridLite>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">


```razor
<!-- Templates TBD in Blazor -->
<IgbGridLiteColumn Field="Rating"></IgbGridLiteColumn>
```

</PlatformBlock>
