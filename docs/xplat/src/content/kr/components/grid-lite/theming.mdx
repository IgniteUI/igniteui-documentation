# 스타일과 테마

{GridLiteTitle}에는 Bootstrap, Material, Fluent, Indigo의 네 가지 서로 다른 테마가 있습니다. 그리드와 그 UI 컴포넌트에는 테마가 내장되어 있지만, 컴포넌트가 제대로 작동하려면 팔레트, 타이포그래피, 기타 전역 구성을 위한 전역 스타일시트가 필요합니다.

## 기본 테마 로드하기

<PlatformBlock for="Blazor">

앱이 `IgniteUI.Blazor.Lite` 또는 `IgniteUI.Blazor` 패키지도 사용한다면, 그 패키지의 [테마 스타일시트](../themes/overview.mdx)를 유지하십시오. 이것도 그리드에 스타일을 적용하므로, 앱에는 아래 스타일시트가 필요하지 않습니다.

{GridLiteTitle}만 사용하는 앱은 호스트 페이지에서 `IgniteUI.Blazor.GridLite` 패키지가 제공하는 테마 중 하나를 연결합니다. Blazor Web App에서는 **Components/App.razor**에, 독립형 Blazor WebAssembly 앱에서는 **wwwroot/index.html**에 연결합니다.

```html
<link href="_content/IgniteUI.Blazor.GridLite/themes/light/bootstrap.css" rel="stylesheet" />
```

| 테마     | 변형 | 경로                                                       |
| --------- | ------- | ---------------------------------------------------------- |
| Bootstrap | 밝음   | _content/IgniteUI.Blazor.GridLite/themes/light/bootstrap.css |
| Bootstrap | 어두움    | _content/IgniteUI.Blazor.GridLite/themes/dark/bootstrap.css  |
| Material  | 밝음   | _content/IgniteUI.Blazor.GridLite/themes/light/material.css  |
| Material  | 어두움    | _content/IgniteUI.Blazor.GridLite/themes/dark/material.css   |
| Fluent    | 밝음   | _content/IgniteUI.Blazor.GridLite/themes/light/fluent.css    |
| Fluent    | 어두움    | _content/IgniteUI.Blazor.GridLite/themes/dark/fluent.css     |
| Indigo    | 밝음   | _content/IgniteUI.Blazor.GridLite/themes/light/indigo.css    |
| Indigo    | 어두움    | _content/IgniteUI.Blazor.GridLite/themes/dark/indigo.css     |

</PlatformBlock>

<PlatformBlock for="React, WebComponents">

프로젝트 유형, 설정 및 빌드 구성에 따라 아래 파일 중 하나를 포함하는 방법은 달라집니다. 프레임워크나 빌드 도구를 사용한다면, 출력 번들에 외부 스타일을 추가하는 방법은 해당 도구의 문서를 참조하십시오.

일반적으로 `themes` 폴더를 assets 디렉터리에 복사하고 index.html에서 그곳의 테마를 연결하면 됩니다.

```html
<link rel="stylesheet" href="./assets/themes/light/bootstrap.css">
```

| 테마     | 변형 | 경로                                                           |
| --------- | ------- | -------------------------------------------------------------- |
| Bootstrap | 밝음   | node_modules/igniteui-webcomponents/themes/light/bootstrap.css |
| Bootstrap | 어두움    | node_modules/igniteui-webcomponents/themes/dark/bootstrap.css  |
| Material  | 밝음   | node_modules/igniteui-webcomponents/themes/light/material.css  |
| Material  | 어두움    | node_modules/igniteui-webcomponents/themes/dark/material.css   |
| Fluent    | 밝음   | node_modules/igniteui-webcomponents/themes/light/fluent.css    |
| Fluent    | 어두움    | node_modules/igniteui-webcomponents/themes/dark/fluent.css     |
| Indigo    | 밝음   | node_modules/igniteui-webcomponents/themes/light/indigo.css    |
| Indigo    | 어두움    | node_modules/igniteui-webcomponents/themes/dark/indigo.css     |

</PlatformBlock>

## 사용자 지정 테마 만들기

{GridLiteTitle} 패키지와 함께 제공되는 기본 테마 외에도, 대체 CSS 사용자 지정 속성 세트를 사용하여 데이터 그리드의 모양과 느낌을 더 사용자 지정할 수 있습니다.

```css
.grid-sample {
  --header-background: #494949;
  --header-text-color: #f2c43c;
  --cell-active-border-color: #f2c43c;
  --row-hover-background: #707070;
  --row-hover-text-color: #f2c43c;
}
```

<PlatformBlock for="Blazor">

```razor
<IgbGridLite class="grid-sample" />
```

</PlatformBlock>
