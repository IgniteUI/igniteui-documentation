# {ProductName}의 타이포그래피

{ProductName}의 타이포그래피는 [Material 타입 시스템](https://material.io/design/typography/the-type-system.html#)을 본떠 만들었습니다. 이는 눈에 거슬리지 않고 선택 사항이며, CSS만으로 타입 스타일을 수정할 수 있게 합니다.

## 사용법

### 글꼴 제품군 변경

모든 컴포넌트의 글꼴 제품군을 바꾸려면 `--ig-font-family` CSS 변수를 덮어쓰기만 하면 됩니다:

```css
:root {
  --ig-font-family: 'Helvetica Neue', sans-serif;
}
```

### 타입 스타일 변경

타입 스타일은 {ProductName}의 대부분의 컴포넌트가 내부적으로 사용합니다. 예를 들어 `igc-button` 컴포넌트는 버튼 타입 스타일을 사용합니다.
타입 스타일 속성을 바꾸려면 해당 CSS 변수를 덮어써야 합니다:

```css
:root {
  --ig-button-font-size: 22px;
  --ig-button-line-height: 26px;
  --ig-button-text-transform: lowercase;
}
```

이렇게 하면 전역 버튼 타이포그래피 스타일이 업데이트된다는 점에 유의하십시오. 이 변경 사항을 특정 버튼에만 적용하려면 클래스 선택기를 사용할 수 있습니다.
