## **{PackageVerLatest}**

### 일반

- **Angular 22 호환성** — 모든 Ignite UI for Angular 컴포넌트가 이제 Angular 22와 완전히 호환됩니다.

- **독립형 컴포넌트 지원** — 컴포넌트를 이제 `NgModule` 없이 독립형 Angular 애플리케이션에서 직접 사용할 수 있습니다. 새 `provide*()` 함수(예: `provideIgxCategoryChart()`)를 사용하면 `bootstrapApplication()` 프로바이더를 통해 컴포넌트 기능 세트를 등록할 수 있으며, DI를 사용하지 않는 설정을 위해 명령형 `register*()` 함수도 제공됩니다.

- **트리 셰이킹 개선을 위한 컴포넌트별 진입점** — 각 패키지는 필요한 기능 세트만 등록하는 이름 있는 하위 경로 진입점(예: `import 'igniteui-angular-charts/category-chart'`)을 노출합니다. 루트 패키지 import는 부작용이 없고 트리 셰이킹이 가능한 상태를 유지하므로, 사용하는 컴포넌트에 대해서만 비용을 지불합니다. DataChart의 경우 `data-chart-category`, `data-chart-scatter`, `data-chart-financial` 같은 세분화된 진입점을 사용하면 차트 전체를 번들하지 않고 개별 시리즈 계열을 가져올 수 있습니다.

### {PackageMaps}(지리 맵)

#### <Badge variant="preview" /> Azure Map 이미지 지원

<ApiLink type="IgxGeographicMap" />는 이제 Azure 기반 지도 이미지를 지원하므로, 개발자는 여러 유형의 애플리케이션에서 상세하고 동적인 지도를 표시할 수 있습니다. 여러 지도 레이어를 결합하고, 지리 데이터를 시각화하며, 대화형 지도 경험을 손쉽게 만들 수 있습니다.

참고: Bing Maps 이미지 지원은 단계적으로 종료되고 있습니다. 기존 엔터프라이즈 키로 여전히 Bing Maps에 접근할 수 있으므로, Azure 지도로 전환하는 동안 현재 애플리케이션이 계속 작동합니다.

공개적으로 사용할 수 있는 일부 [Azure 지도는 여기에서 확인할 수 있습니다](https://azure.microsoft.com/en-us/products/azure-maps).

  - chart.<ApiLink type="SeriesViewer" member="highlightingMode" label="HighlightingMode" /> - 마우스가 올라간 시리즈 또는 올라가지 않은 시리즈를 흐리게 또는 밝게 할지 설정합니다
  - chart.<ApiLink type="SeriesViewer" member="highlightingBehavior" label="HighlightingBehavior" /> - 마우스 위치(예: 바로 위 또는 가장 가까운 항목)에 따라 시리즈가 강조되는지 설정합니다
  - 참고로 이전 릴리스에서는 강조 표시가 마우스 오버 시 흐려지는 효과로만 제한되어 있었습니다.

- 세로 확대/축소를 시리즈 콘텐츠에 자동으로 동기화하는 기능이 추가되었습니다
