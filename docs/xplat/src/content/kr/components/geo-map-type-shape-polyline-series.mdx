# {Platform} 지리 폴리라인 지도

{Platform} 지도 컴포넌트에서는 `GeographicPolylineSeries`를 사용하여 지리적 맥락에서 폴리라인으로 지리 공간 데이터를 표시할 수 있습니다. 이 유형의 지리 시리즈는 도시나 공항 같은 지리적 위치 사이의 도로 또는 연결을 렌더링하는 데 자주 사용됩니다.

<Sample src="/maps/geo-map/type-shape-polyline-series" height={500} alt="{Platform} 셰이프 폴리라인 시리즈 사용 예제" />




`GeographicPolylineSeries`는 지리 공간 데이터를 다각형 대신 폴리라인으로 렌더링한다는 점을 제외하면 `GeographicShapeSeries`와 매우 비슷하게 작동합니다.

## 데이터 요구 사항
컨트롤의 다른 유형의 지리 시리즈와 마찬가지로, `GeographicPolylineSeries`에도 객체의 배열에 바인딩할 수 있는 `dataSource` 속성이 있습니다. 또한 이 객체의 각 데이터 항목에는 지리적 위치를 나타내는 x 및 y 값을 가진 객체의 배열의 배열을 사용하여 단일 또는 여러 셰이프를 저장하는 데이터 열이 하나 있어야 합니다. 그다음 이 데이터 열은 `ShapeMemberPath` 속성에 매핑됩니다. `GeographicPolylineSeries`는 이 매핑된 데이터 열의 점을 사용하여 컨트롤에 폴리라인을 플롯합니다.

셰이프가 셰이프 파일에서 바로 오고 먼저 모양을 바꿀 필요가 없다면, 시리즈에 자체 `ShapefileDataSource`를 줄 수 있으며, 시리즈가 레코드에서 점을 직접 읽습니다. 아래 코드가 바로 이 방식입니다. [셰이프 파일 바인딩](./geo-map-binding-shp-file.mdx)은 다른 방법을 다루는데, 여기서는 핸들러가 각 레코드를 자신만의 객체로 바꾸고 `ShapeMemberPath`를 그 객체에 매핑합니다.

## 코드 조각
다음 코드는 `GeographicPolylineSeries`에 미국 도로의 셰이프 파일을 가리키는 `ShapefileDataSource`를 주고, 그 안의 모든 도로를 그립니다.

```json-snippet source="/maps/geo-map/type-shape-polyline-series"
{
    "type": "GeographicMap",
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicPolylineSeries",
            "name": "GeographicPolylineSeries1",
            "shapefileDataSource": {
                "type": "ShapeDataSource",
                "shapefileSource": "https://static.infragistics.com/xplatform/shapes/AmericanRoads.shp",
                "databaseSource": "https://static.infragistics.com/xplatform/shapes/AmericanRoads.dbf"
            },
            "outline": "Red"
        }
    ]
}
```
