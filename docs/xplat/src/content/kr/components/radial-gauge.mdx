# {Platform} Radial Gauge 개요

{Platform} 방사형 게이지 컴포넌트는 미리 정의된 모양과 눈금을 만들기 위해 바늘, 눈금 표시, 범위, 레이블 같은 여러 시각 요소를 제공합니다. `RadialGauge`은(는) 애니메이션 전환도 기본으로 지원합니다. 이 애니메이션은 `transitionDuration` 속성을 설정하여 쉽게 사용자 지정할 수 있습니다.

## 사용법

다음 코드는 바늘과 눈금 위의 비교 범위 세 개가 있는 방사형 게이지를 만드는 방법을 보여 줍니다.

```json-snippet
{
    "type": "RadialGauge",
    "height": "400px",
    "width": "400px",
    "minimumValue": 0,
    "maximumValue": 100,

    "interval": 5,
    "ranges": [
        { "type": "RadialGaugeRange", "startValue": 0,  "endValue": 30,  "brush": "red" },
        { "type": "RadialGaugeRange", "startValue": 30, "endValue": 60,  "brush": "yellow" },
        { "type": "RadialGaugeRange", "startValue": 60, "endValue": 100, "brush": "green" }
    ]
}
```


## 배경

방사형 게이지 컴포넌트에는 눈금 뒤에 그려지는 백킹 모양이 있으며, 이는 방사형 게이지의 배경 역할을 합니다.

백킹 요소는 방사형 게이지 컴포넌트의 배경과 테두리를 나타냅니다. 항상 가장 먼저 렌더링되며, 바늘, 레이블, 눈금 표시 같은 나머지 요소는 그 위에 겹쳐집니다.

백킹은 원형 또는 맞춤형일 수 있습니다. 원형 모양은 360도 원 게이지를 만들고, 맞춤형 모양은 `scaleStartAngle` 및 `scaleEndAngle` 속성을 감싸는 채워진 호 구간을 만듭니다. 이는 `backingShape` 속성을 설정하여 지정할 수 있습니다.

```json-snippet source="/gauges/radial-gauge/backing"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "backingShape": "Fitted",
    "backingBrush": "#FCFCFC",
    "backingOutline": "DodgerBlue",
    "backingOversweep": 5,
    "backingCornerRadius": 10,
    "backingStrokeThickness": 5,
    "backingOuterExtent": 0.8,
    "backingInnerExtent": 0.15,
    "scaleStartAngle": 135,
    "scaleEndAngle": 45
}
```


<Sample src="/gauges/radial-gauge/backing" height={320} alt="{Platform} 방사형 게이지 백킹" />



## 척도

눈금은 `minimumValue` 및 `maximumValue` 값을 제공하여 만들 수 있는 게이지의 전체 값 범위를 강조하는 시각 요소입니다. 백킹과 함께 게이지의 전체 모양을 정의합니다. `scaleStartAngle` 및 `scaleEndAngle` 속성은 눈금 호의 경계를 정의합니다. `scaleSweepDirection` 속성은 눈금이 시계 방향으로 움직이는지 반시계 방향으로 움직이는지를 지정합니다. `scaleBrush`, `scaleStartExtent` 및 `scaleEndExtent` 속성을 설정하여 눈금의 모양을 사용자 지정할 수 있습니다.

```json-snippet source="/gauges/radial-gauge/scale"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "scaleStartAngle": 135,
    "scaleEndAngle": 45,
    "scaleBrush": "DodgerBlue",
    "scaleSweepDirection": "Clockwise",
    "scaleOversweep": 1,
    "scaleOversweepShape": "Fitted",
    "scaleStartExtent": 0.45,
    "scaleEndExtent": 0.575
}
```

## 레이블과 제목

방사형 게이지 레이블은 `minimumValue` 및 `maximumValue` 속성 값 사이의 지정된 간격마다 숫자 값을 표시하는 시각 요소입니다. `labelExtent` 속성을 분수로 설정하여 레이블 위치를 정할 수 있습니다. 0은 게이지의 중심을, 1은 게이지 백킹의 바깥쪽 끝을 나타냅니다. 또한 `fontBrush` 및 `RadialGauge.FontFamily/RadialGauge.FontSize/RadialGauge.FontStyle/RadialGauge.FontWeight` 같은 다양한 스타일 속성으로 레이블을 사용자 지정할 수 있습니다.

바늘용 각 레이블에는 글꼴, 각도, 브러시, 그리고 `titleExtent`, `titleAngle`, `SubtitleFontSize`, `highlightLabelBrush` 같은 게이지 중심으로부터의 거리를 바꿀 수 있는 다양한 스타일 속성이 있습니다.

```json-snippet source="/gauges/radial-gauge/labels"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "labelInterval": 10,
    "labelExtent": 0.65,
    "font": "11px Verdana",
    "fontBrush": "DodgerBlue"
}
```


<Sample src="/gauges/radial-gauge/labels" height={320} alt="{Platform} 방사형 게이지 레이블" />


## 제목 및 부제목

`titleText` 및 `subtitleText` 속성을 사용할 수 있으며, 둘 다 바늘에 사용자 지정 텍스트를 표시하는 데 쓸 수 있습니다. 또는 `titleDisplaysValue` 및 `subtitleDisplaysValue`를 true로 설정하면 바늘의 값을 표시하고 `titleText` 및 `subtitleText`을(를) 재정의합니다. 따라서 제목에는 사용자 지정 텍스트를 두고 부제목으로 값을 보여 주거나, 그 반대로 할 수 있습니다.

아래에 설명하는 것처럼 강조 바늘이 표시되는 경우 사용자 지정 텍스트는 `highlightLabelText`을(를) 통해 표시할 수 있으며, 그렇지 않으면 `highlightLabelDisplaysValue`을(를) 활성화하여 값을 표시할 수 있습니다.

```json-snippet
{
    "type": "RadialGauge",
    "titleText": "Global Sales",
    "subtitleText": "2024"
}
```


## 광학 스케일링

방사형 게이지의 레이블과 제목은 스케일링을 바꿀 수 있습니다. 이를 활성화하려면 먼저 `opticalScalingEnabled`을(를) true로 설정하십시오. 그다음 `opticalScalingSize`을(를) 설정하면 레이블이 100% 광학 스케일링을 갖는 크기를 관리할 수 있습니다. 게이지 크기가 커지면 레이블의 글꼴도 커집니다. 예를 들어 이 속성을 500으로 설정하고 게이지의 픽셀 크기를 2배인 1000으로 만들면, 레이블의 글꼴 크기는 200% 커집니다.

## 눈금 표시

눈금 표시는 방사형 게이지 중심에서 뻗어 나가는 가느다란 선입니다. 눈금 표시에는 주 눈금과 보조 눈금 두 종류가 있습니다. 주 눈금 표시는 `minimumValue`과(와) `maximumValue` 속성 사이의 `RadialGauge.interval`마다 표시됩니다. `minorTickCount` 속성을 사용하여 각 주 눈금 표시 사이에 표시할 보조 눈금 표시 수를 지정하십시오. `tickStartExtent`, `tickEndExtent`, `minorTickStartExtent` 및 `minorTickEndExtent` 속성에 0과 1 사이의 분수를 설정하여 눈금 표시의 길이를 조정할 수 있습니다.

```json-snippet source="/gauges/radial-gauge/tickmarks"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "tickStartExtent": 0.45,
    "tickEndExtent": 0.575,
    "tickStrokeThickness": 2,
    "tickBrush": "DodgerBlue",
    "minorTickCount": 4,
    "minorTickStartExtent": 0.575,
    "minorTickEndExtent": 0.5,
    "minorTickStrokeThickness": 1,
    "minorTickBrush": "DarkViolet"
}
```


<Sample src="/gauges/radial-gauge/tickmarks" height={320} alt="{Platform} 방사형 게이지 눈금 표시" />



## 범위

범위는 지정한 `minimumValue` 및 `maximumValue` 속성으로 묶인 연속된 값의 집합을 강조합니다. 시작 값과 끝 값을 지정하여 방사형 게이지에 여러 범위를 추가할 수 있습니다. 각 범위에는 `RadialGaugeRange.brush` 및 `RadialGaugeRange.outline` 같은 몇 가지 사용자 지정 속성이 있습니다. 또는 `rangeBrushes` 및 `rangeOutlines` 속성을 범위에 사용할 색상 목록으로 설정할 수도 있습니다.

```json-snippet source="/gauges/radial-gauge/ranges"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "rangeBrushes":  [ "red", "yellow", "green" ],
    "rangeOutlines": [ "red", "yellow", "green" ],
    "ranges": [
        { "type": "RadialGaugeRange", "startValue": 5,  "endValue": 15, "brush": "red" },
        { "type": "RadialGaugeRange", "startValue": 15, "endValue": 35, "brush": "yellow" },
        { "type": "RadialGaugeRange", "startValue": 35, "endValue": 45, "brush": "green" }
    ]
}
```

## 바늘

방사형 게이지 바늘은 게이지에 설정된 값을 나타내는 시각 요소입니다. 바늘은 미리 정의된 여러 모양 중 하나로 제공됩니다. 바늘에는 게이지 중심에 놓이는 피벗 모양이 있을 수 있습니다. 피벗 모양도 미리 정의된 모양 중 하나를 사용합니다. 오버레이나 언더레이가 포함된 피벗 모양에는 모양에 별도의 피벗 브러시를 적용할 수 있습니다.

지원되는 바늘 모양과 캡은 `needleShape` 및 `needlePivotShape` 속성을 사용하여 설정합니다.

게이지의 대화형 모드를 활성화하면(`isNeedleDraggingEnabled` 속성 사용) 최종 사용자가 `minimumValue` 및 `maximumValue` 속성의 값 사이에서 바늘을 끌어 값을 바꿀 수 있습니다.

```json-snippet source="/gauges/radial-gauge/needle"
{
    "type": "RadialGauge",
    "height": "300px",
    "width": "300px",
    "minimumValue": 0,
    "maximumValue": 80,
    "value": 50,
    "interval": 10,
    "isNeedleDraggingEnabled": true,
    "isNeedleDraggingConstrained": true,
    "needleShape": "NeedleWithBulb",
    "needleBrush": "DodgerBlue",
    "needleOutline": "DodgerBlue",
    "needleEndExtent": 0.475,
    "needleStrokeThickness": 1,
    "needlePivotShape": "CircleOverlay",
    "needlePivotBrush": "#9F9FA0",
    "needlePivotOutline": "#9F9FA0",
    "needlePivotWidthRatio": 0.2,
    "needlePivotStrokeThickness": 1
}
```

## 바늘 강조

방사형 게이지를 수정하여 두 번째 바늘을 표시할 수 있습니다. 그러면 주 바늘의 `RadialGauge.value`이(가) 더 낮은 불투명도로 나타납니다. 이를 활성화하려면 먼저 `highlightValueDisplayMode`을(를) Overlay로 설정한 다음 `highlightValue`을(를) 적용하십시오.

    "type": "RadialGauge",
    "height": "100%",
    "width": "100%",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 30,
    "interval": 10,
    "labelInterval": 10,
    "labelExtent": 0.65,
    "isHighlightNeedleDraggingEnabled": true,
    "highlightValueDisplayMode": "Overlay",
    "highlightValue": 50,
    "highlightLabelDisplaysValue": true,
    "highlightLabelSnapsToNeedlePivot": true
}
