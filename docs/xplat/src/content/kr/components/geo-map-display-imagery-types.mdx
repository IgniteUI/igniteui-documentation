# {Platform} 지리 이미지

{Platform} 지리 이미지는 위에서 내려다본 관점에서 세계를 자세히 표현한 것입니다. 다중 축척 이미지 타일 구조의 항공-위성 지도 또는 도로 지도로 구성될 수 있습니다. 지리 맵 컴포넌트는 지리 이미지를 표시하여 최종 사용자에게 풍부하고 대화형인 세계 지도와 지리 공간 데이터의 지리적 맥락을 제공할 수 있습니다.

## 지도 배경 콘텐츠
지도 컴포넌트의 `backgroundContent` 속성은 지원되는 모든 유형의 지리 이미지 소스를 표시하는 데 사용됩니다. 각 이미지 소스에는 해당 지리 이미지 타일을 렌더링하는 데 사용되는 이미지 클래스가 있습니다.

다음 표는 지도 컴포넌트가 제공하는 이미지 클래스를 요약합니다.

| 이미지 클래스 | 설명   |
|---------------|---------------|
|`GeographicMapImagery`|지원되는 모든 유형의 지리 이미지 타일을 표시하는 모든 이미지 클래스의 기본 컨트롤을 나타냅니다. 이 클래스는 Map Quest 매핑 서비스 같은 다른 지리 이미지 소스의 지리 이미지 타일 지원을 구현하기 위해 확장할 수 있습니다.|
|`OpenStreetMapImagery`|Open Street Maps 서비스의 지리 이미지 타일을 표시하는 다중 축척 이미지 컨트롤을 나타냅니다.|

{/*|`BingMapsMapImagery`|Represents the multi-scale imagery control for displaying geographic imagery tiles from the Bing Maps service.|*/}

기본적으로 `backgroundContent` 속성은 `OpenStreetMapImagery` 객체로 설정되어 있으며, 지도 컴포넌트는 Open Street Maps 서비스의 지리 이미지 타일을 표시합니다. 다른 유형의 지리 이미지 타일을 표시하려면 지도 컴포넌트를 다시 구성해야 합니다.

또한 `backgroundContent` 속성은 해당 클래스를 상속하는 모든 객체로 설정할 수 있습니다. 하지만 `GeographicMapImagery` 클래스를 상속하는 객체만 지도 배경 콘텐츠의 패닝과 줌을 허용합니다.

지도 컴포넌트에서 지도 배경 콘텐츠는 항상 모든 지리 시리즈 뒤에 렌더링됩니다. 즉, 지리 이미지 타일이 항상 먼저 렌더링되고, 지도 컴포넌트의 Series 속성에 있는 지리 시리즈는 지리 이미지 타일 위에 렌더링됩니다. 지도 컴포넌트의 같은 플롯 영역에 여러 지리 시리즈를 표시할 때 특히 중요합니다. 지리 이미지 타일이 지도 보기에서 쉽게 가려질 수 있기 때문입니다.
