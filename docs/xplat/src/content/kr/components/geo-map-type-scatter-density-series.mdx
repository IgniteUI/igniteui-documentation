# {Platform} 지리 고밀도 지도

{Platform} 지도 컴포넌트에서는 `GeographicHighDensityScatterSeries`를 사용하여 수백에서 수백만 개의 데이터 포인트에 이르는 산점 데이터를 매우 짧은 로딩 시간으로 바인딩하고 표시할 수 있습니다.

<Sample src="/maps/geo-map/type-scatter-density-series" height={400} alt="{Platform} 산점 고밀도 시리즈 사용 예제" />




위 데모는 호주의 인구 밀도를 나타내는 수백 또는 수천 개의 데이터 포인트에 바인딩된 지도 컴포넌트의 `GeographicHighDensityScatterSeries` 시리즈를 보여 줍니다. 인구가 더 밀집된 데이터 포인트는 붉은 픽셀의 뭉침으로, 드문드문 분포한 데이터 포인트는 개별 파란 픽셀로 지도 플롯 영역에 표시됩니다.

데이터 포인트가 매우 많기 때문에, 이 시리즈는 산점 데이터를 실제 크기의 마커가 아니라 작은 점으로 표시하며, 데이터 포인트의 군집을 나타내는 더 높은 색상 밀도로 데이터가 가장 많은 영역을 표시합니다.

## 데이터 요구 사항
지도 컨트롤의 다른 유형의 산점 시리즈와 마찬가지로, `GeographicHighDensityScatterSeries` 시리즈에도 객체의 배열에 바인딩할 수 있는 `dataSource` 속성이 있습니다. 또한 항목 소스의 각 데이터 항목에는 지리 경도와 위도 좌표를 저장하는 두 개의 데이터 열이 있어야 하며, `longitudeMemberPath`와 `latitudeMemberPath` 속성을 사용하여 이 데이터 열을 매핑합니다.

### 데이터 바인딩
다음 표는 데이터 바인딩에 사용되는 GeographicHighDensityScatterSeries 시리즈 속성을 요약합니다.

| 속성|타입|설명 |
| ---|---|--- |
| `dataSource`|any|항목 소스를 가져오거나 설정합니다 |
| `longitudeMemberPath`|string|DataSource 속성을 사용하여 할당된 항목에서 경도 값의 위치를 결정합니다 |
| `latitudeMemberPath`|string|DataSource 속성을 사용하여 할당된 항목에서 위도 값의 위치를 결정합니다 |

## 열 색상 척도
열 색상 척도는 선택적 기능으로, 시리즈 내의 색상 패턴을 결정합니다. 다음 표는 색상 척도를 결정하는 데 사용되는 속성을 요약합니다.

| 속성 |타입|설명 |
| ---|---|--- |
| `heatMinimum`|Double|색상 척도의 최솟값 끝을 나타내는 double 값을 정의합니다 |
| `heatMaximum`|Double|색상 척도의 최댓값 끝을 나타내는 double 값을 정의합니다 |
| `heatMinimumColor`|Color|색상 척도의 아래쪽 끝에 사용되는 점 밀도 색상을 정의합니다 |
| `heatMaximumColor`|Color|색상 척도의 위쪽 끝에 사용되는 점 밀도 색상을 정의합니다 |
