# {Platform} 선형 게이지 개요

{ProductName} 선형 게이지 컴포넌트는 데이터를 선형 게이지 형태로 시각화할 수 있게 합니다. `LinearGauge`은(는) 눈금과 하나 이상의 범위에 비교한 값을 간결하게 보여 줍니다. 눈금 하나, 눈금 표시 세트 하나, 레이블 세트 하나를 지원합니다. 또한 애니메이션 전환을 기본으로 지원하며, 이 애니메이션은 `transitionDuration` 속성을 설정하여 쉽게 사용자 지정할 수 있습니다. 선형 게이지 컴포넌트의 기능에는 구성 가능한 방향과 진행 방향, 바늘 같은 구성 가능한 시각 요소 등이 포함됩니다.

## 사용법

다음 코드는 바늘 하나와 눈금 위의 비교 범위 세 개가 있는 선형 게이지를 만드는 방법을 보여 줍니다.

```json-snippet
        { "type": "LinearGraphRange", "startValue": 30, "endValue": 55, "brush": "green" }
    ]
}
```


## 바늘

```json-snippet source="/gauges/linear-gauge/needle"
{
    "type": "LinearGauge",
    "height": "80px",
    "width": "400px",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 50,
    "interval": 10,
    "isNeedleDraggingEnabled": true,
    "needleShape": "Custom",
    "needleBrush": "DodgerBlue",
    "needleOutline": "DodgerBlue",
    "needleStrokeThickness": 1,
    "needleBreadth": 15,
    "needleInnerExtent": 0.35,
    "needleOuterExtent": 0.65,
    "needleOuterPointExtent": 0.8,
    "needleInnerPointExtent": 0.325,
    "needleInnerPointWidth": 0,
    "needleOuterPointWidth": 0.3,
    "needleInnerBaseWidth": 0,
    "needleOuterBaseWidth": 0.07
}
```

## 바늘 강조

선형 게이지를 수정하여 두 번째 바늘을 표시할 수 있습니다. 그러면 주 바늘의 `LinearGauge.value`이(가) 더 낮은 불투명도로 나타납니다. 이를 활성화하려면 먼저 `highlightValueDisplayMode`을(를) Overlay로 설정한 다음 `highlightValue`을(를) 적용하십시오.

```json-snippet source="/gauges/linear-gauge/highlight-needle"
{
    "type": "LinearGauge",
    "height": "80px",
    "width": "400px",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 50,
    "interval": 10,
    "labelInterval": 10,
    "labelExtent": 0.025,
    "labelsPreTerminal": 0,
    "labelsPostInitial": 0,
    "needleBrush": "Blue",
    "highlightValueDisplayMode": "Overlay",
    "highlightValue": 25,
    "isHighlightNeedleDraggingEnabled": true
}
```

## 범위

범위는 눈금에서 지정한 값의 범위를 강조하는 시각 요소입니다. 목적은 성능 막대 측정값의 정성적 상태를 시각적으로 전달하고, 동시에 그 값이 해당 상태 안에 얼마나 들어 있는지 보여 주는 것입니다.

```json-snippet source="/gauges/linear-gauge/ranges"
{
    "type": "LinearGauge",
    "height": "80px",
    "width": "400px",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 50,
    "interval": 10,
    "rangeBrushes":  [ "#A4BD29", "#F86232" ],
    "rangeOutlines": [ "#A4BD29", "#F86232" ],
    "ranges": [
        { "type": "LinearGraphRange", "startValue": 0,  "endValue": 50,  "innerStartExtent": 0.075, "innerEndExtent": 0.075, "outerStartExtent": 0.25, "outerEndExtent": 0.4 },
        { "type": "LinearGraphRange", "startValue": 50, "endValue": 100, "innerStartExtent": 0.075, "innerEndExtent": 0.075, "outerStartExtent": 0.4,  "outerEndExtent": 0.55 }
    ]
}
```

## 눈금 표시

눈금 표시는 선형 게이지의 가독성을 높이기 위해 눈금을 간격으로 시각적으로 나눕니다.

주 눈금 표시 – 주 눈금 표시는 척도의 기본 구분선으로 사용됩니다. 나타나는 빈도, 범위, 스타일은 해당 속성을 설정하여 제어할 수 있습니다.

보조 눈금 표시 – 보조 눈금 표시는 척도의 가독성을 추가로 높이는 데 사용될 수 있는 보조 눈금 표시이며, 주 눈금 표시와 비슷한 방식으로 사용자 지정할 수 있습니다.

```json-snippet source="/gauges/linear-gauge/tickmarks"
{
    "type": "LinearGauge",
    "height": "80px",
    "width": "400px",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 50,
    "interval": 10,
    "tickBrush": "DodgerBlue",
    "ticksPreTerminal": 0,
    "ticksPostInitial": 0,
    "tickStrokeThickness": 2,
    "tickStartExtent": 0.25,
    "tickEndExtent": 0.05,
    "minorTickCount": 4,
    "minorTickBrush": "DarkViolet",
    "minorTickStartExtent": 0.15,
    "minorTickEndExtent": 0.05,
    "minorTickStrokeThickness": 1
}
```

## 배경

백킹 요소는 선형 게이지 컴포넌트의 배경과 테두리를 나타냅니다. 항상 가장 먼저 렌더링되며, 레이블과 눈금 표시 같은 나머지 요소는 그 위에 겹쳐집니다.

```json-snippet source="/gauges/linear-gauge/backing"
{
    "type": "LinearGauge",
    "height": "80px",
    "width": "400px",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 50,
    "interval": 10,
    "backingBrush": "#bddcfc",
    "backingOutline": "DodgerBlue",
    "backingStrokeThickness": 4,
    "backingInnerExtent": 0,
    "backingOuterExtent": 1
}
```

## 척도

눈금은 선형 게이지의 전체 값 범위를 강조하는 시각 요소입니다. 눈금의 모양과 형태를 사용자 지정할 수 있습니다. `isScaleInverted` 속성을 사용하여 뒤집을 수도 있으며, 이 경우 모든 레이블이 왼쪽에서 오른쪽이 아니라 오른쪽에서 왼쪽으로 렌더링됩니다.

```json-snippet source="/gauges/linear-gauge/scale"
{
    "type": "LinearGauge",
    "height": "80px",
    "width": "400px",
    "minimumValue": 0,
    "maximumValue": 100,
    "value": 50,
    "interval": 10,
    "isScaleInverted": false,
    "scaleBrush": "DodgerBlue",
    "scaleOutline": "DarkViolet",
    "scaleStrokeThickness": 1,
    "scaleInnerExtent": 0.05,
    "scaleOuterExtent": 0.65,
    "scaleStartExtent": 0.05,
    "scaleEndExtent": 0.95
}
```
