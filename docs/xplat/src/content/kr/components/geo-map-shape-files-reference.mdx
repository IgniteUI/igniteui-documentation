# {Platform} 셰이프 파일 참조

## 목적

이 항목은 지도 및 지리 공간 관련 자료와 셰이프 파일에 대한 정보를 제공합니다. {ProductName} 지도 컴포넌트™ 컨트롤에 지리 공간 데이터를 바인딩하기 시작하기 전에, 이 리소스를 사용하여 셰이프 파일을 알아보고 구하며, 편집을 위한 도구를 찾으십시오.

컨트롤에 지리 공간 데이터를 플롯하기 전에, 지도와 지리 공간 데이터에 대한 일반 정보를 제공하는 다음 리소스에 익숙해져야 합니다.

- [Wikipedia – 지도 제작법](http://en.wikipedia.org/wiki/Cartography)

- [National Atlas of the United States – 지리적 위치](http://nationalatlas.gov/articles/mapping/a_latlong.html)

- [National Atlas of the United States – 지도 투영법](http://nationalatlas.gov/articles/mapping/a_projections.html)

- [미국 지질조사국](http://www.usgs.gov/)

- [Wikipedia – 지도 투영법](http://en.wikipedia.org/wiki/Map_projection)

- [University of Colorado – 지도 투영법](http://www.colorado.edu/geography/gcraft/notes/mapproj/mapproj_f.html)

- [CSISS – 지도 투영법](http://www.csiss.org/map-projections/index.html)

## 셰이프 파일 형식

{Platform} `GeographicMap` 컨트롤은 지리 공간 데이터의 소스 중 하나로 널리 쓰이는 [셰이프 파일](http://en.wikipedia.org/wiki/Shapefile#Overview) 형식을 사용합니다. 셰이프 파일은 보통 **.shp**, **.shx**, **.dbf** 확장자를 가진 파일들과 함께 제공됩니다.

다음 표는 셰이프 파일 각 유형의 기본 정보와 목적을 제공합니다.

| 파일 확장자 | 설명 |
| ---------------|------------ |
| `.shp` | 셰이프 파일에는 점, 폴리라인, 다각형을 설명하는 지리 공간 벡터 데이터 항목이 들어 있습니다. 이 파일에서 점은 도시를, 폴리라인은 도로를, 다각형은 지리적 맥락에서 국가의 모양이나 경계를 설명할 수 있습니다. |
| `.shx` | 셰이프 인덱스 파일에는 지리 공간 벡터 데이터 항목을 빠르게 찾기 위한 인덱스가 들어 있습니다. |
| `.dbf` | 셰이프 데이터베이스 파일에는 셰이프(.shp) 파일의 지리 공간 데이터 항목마다 한 행이 대응하는 표가 들어 있습니다. 셰이프 데이터베이스 파일에서 문자열 열은 국가, 지역, 도시의 이름 같은 지리 공간 데이터 항목의 속성을 설명할 수 있고, 숫자 열은 국가 인구, 도시 위치 같은 값을 담을 수 있습니다. |



지리 공간 데이터가 셰이프 파일에 어떻게 저장되는지에 대한 자세한 정보와 사양은 다음 리소스를 참조하십시오.

- [ESRI - Shape File 기술 설명](http://www.esri.com/library/whitepapers/pdfs/shapefile.pdf)

- [Wikipedia - Shape File 설명](http://en.wikipedia.org/wiki/Shapefile#Overview)
