# {Platform} 목록 개요

{ProductName} 목록 요소는 항목 그룹을 표시할 때 매우 유용합니다. 텍스트 항목으로 된 단순한 목록을 만들 수도 있고, 여러 가지 레이아웃 요소 배열을 포함하는 더 복잡한 목록을 만들 수도 있습니다. <ApiLink pkg="core" type="List" /> 컴포넌트는 항목 행을 표시하며 하나 이상의 머리글도 지원합니다. 각 목록 항목은 완전히 템플릿화할 수 있으며, 유효한 모든 HTML 또는 다른 컴포넌트를 지원합니다.

## {Platform} 목록 예제

다음 예제는 이름과 전화번호 속성이 있는 연락처로 채워진 목록을 보여 줍니다. 아래에서 시연하는 <ApiLink pkg="core" type="List" /> 컴포넌트는 <ApiLink pkg="core" type="Avatar" />와 <ApiLink pkg="core" type="Button" /> 요소를 사용하여 사용자 경험을 풍부하게 하고, 아바타 사진과 텍스트 및 통화 동작용 버튼을 설정하는 기능을 보여 줍니다.

`start` 슬롯은 목록 항목의 다른 모든 콘텐츠 앞에 일종의 미디어를 추가하는 데 사용하기 위한 것입니다. 대상 요소, 즉 이 경우 <ApiLink pkg="core" type="Avatar" /> 컴포넌트에는 기본 위치와 간격도 제공됩니다.

`end` 슬롯은 예를 들어 스위치, 버튼, 체크박스 등으로 표현되는 동작이나 메타데이터가 있는 목록 항목에 사용하기 위한 것입니다. 여기서는 <ApiLink pkg="core" type="Button" /> 컴포넌트를 사용하겠습니다.

### 슬롯에 권장되는 요소

`title` 및 `subtitle` 슬롯에 콘텐츠를 넣을 때는 제목 요소(`<h1>`–`<h6>`) 대신 `<span>` 요소를 사용하는 것을 권장합니다. 제목 요소에는 컴포넌트가 의도한 타이포그래피와 레이아웃을 방해할 수 있는 내장 스타일(글꼴 크기, 줄 높이, 여백 등)이 있습니다. `<span>`를 사용하면 컴포넌트의 스타일을 깔끔하게 상속받는 중립적인 컨테이너를 제공할 수 있습니다.

최상의 결과를 얻으려면, 미디어 콘텐츠를 위한 `start` 슬롯에는 [`<igc-avatar>`](../layouts/avatar.mdx) 컴포넌트를 사용하는 것을 권장합니다. 동작을 위한 `end` 슬롯에는 표시하려는 콘텐츠의 유형에 따라 [`<igc-button>`](../inputs/button.mdx), [`<igc-switch>`](../inputs/switch.mdx), [`<igc-checkbox>`](../inputs/checkbox.mdx) 등의 컴포넌트를 사용하는 것을 권장합니다. 다만 두 슬롯 모두에서, 표시하려는 콘텐츠에 적절하다면 `start` 슬롯에는 `<img>`, `end` 슬롯에는 `<button>` 또는 다른 상호 작용 요소와 같은 일반 HTML 요소도 사용할 수 있습니다.

## 스타일링

<ApiLink pkg="core" type="List" />은 스타일을 완전히 제어할 수 있도록 여러 CSS 파트를 노출합니다:

|이름|설명|
|--|--|
| `start` | 시작 컨테이너. |
| `end` | 끝 컨테이너. |
| `content` | 머리글 및 사용자 지정 콘텐츠 컨테이너. |
| `header` | 제목 및 부제목 컨테이너. |
| `title` | 제목 컨테이너. |
| `subtitle` | 부제목 컨테이너. |

```css
igc-list-header {
  font-size: 20px;
  font-weight: 700;
  color: var(--ig-primary-700);
}

igc-list-item::part(title) {
  font-size: 18px;
  color: var(--ig-primary-600);
}

igc-list-item::part(subtitle) {
  color: var(--ig-primary-300);
}
```
