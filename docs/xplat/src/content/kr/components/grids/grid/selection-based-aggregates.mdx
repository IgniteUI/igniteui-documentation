# {Platform} 그리드 선택 기반 데이터 집계

아래에 설명한 샘플에서는 다중 선택을 사용자 지정 요약 함수와 함께 사용하여, 그리드 바닥글에 그리드의 선택된 값을 기준으로 한 집계를 표시하는 방법을 볼 수 있습니다.

## 항목 개요

선택 기반 집계 기능을 구현하려면, `Grid Summaries`와 함께 `Grid Selection` 기능을 사용할 수 있습니다.
요약은 열 데이터 유형과 요구 사항에 따라 기본 클래스 중 하나인 <ApiLink type="SummaryOperand" />, <ApiLink type="NumberSummaryOperand" />.html) 또는 <ApiLink type="DateSummaryOperand" />를 확장하여 기본 요약 기능을 사용자 지정할 수 있습니다.

## 선택
선택된 그리드 범위의 데이터를 다루기 시작하려면, 그리드 선택의 변경을 알리는 이벤트를 구독해야 합니다. `selected` 이벤트와 `rangeSelected` 이벤트를 구독하면 됩니다. 선택 기능은 단일 셀 선택과 셀 범위 선택을 구분하므로 두 이벤트 모두에 바인딩해야 합니다.

이벤트 구독 로직에서는 그리드의 `getSelectedData`.html#getSelectedData) 함수를 사용하여 선택된 데이터를 추출하고, 선택된 데이터를 사용자 지정 요약 피연산자에 전달할 수 있습니다.


## 요약
사용자 지정 요약 클래스 안에서는 그리드의 데이터 타입을 구분해야 합니다. 예를 들어 아래 시나리오에는 사용자 지정 요약에 적합한 데이터 타입을 가진 네 개의 서로 다른 열이 있습니다. 바로 Unit Price, Units in Stock, Discontinued 상태, Order Date입니다.
<ApiLink type="SummaryOperand" />의 파생 클래스에 있는 `operate` 메서드가 데이터를 처리하는 곳이며, 먼저 데이터 타입에 따라 서로 다른 범주로 나눕니다:

```typescript
const numberData = data.filter(rec => typeof rec === "number");
const boolData = data.filter(rec => typeof rec === "boolean");
const dates = data.filter(rec => isDate(rec));
```

<DocsAside type="info">
`isDate`은(는) 사용자 지정 함수라는 점을 기억하십시오.
</DocsAside>

데이터 유형에 따라 데이터를 그룹화한 다음, 집계 자체를 진행할 수 있습니다. 이를 위해 <ApiLink type="NumberSummaryOperand" /> 및 <ApiLink type="DateSummaryOperand" />의 이미 노출된 메서드를 사용할 수 있습니다.
그 후 집계된 데이터를 같은 배열에 넣어 템플릿으로 반환해야 합니다.
데이터를 시각화하려면 그리드 바닥글을 사용할 수 있으며, 이를 `custom-summaries` 클래스와 함께 사용하면 요약의 자연스러운 모습을 얻을 수 있습니다.
