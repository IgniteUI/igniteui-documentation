# {Platform} 그리드 그룹화

{Platform} {GridName}의 {ProductName} 그룹화 동작은 열 값을 기준으로 그룹화된 데이터 행을 만듭니다. <ApiLink type="Grid" />의 그룹화는 그룹을 계층 구조로 시각화할 수 있게 합니다. 그룹화된 데이터 행은 펼치거나 접을 수 있으며, 그룹화 순서는 UI나 API를 통해 바꿀 수 있습니다. 행 선택이 활성화되면, 그룹 행의 가장 왼쪽 영역에 그룹화 행 선택기가 렌더링됩니다. <ApiLink type="Grid" member="rowSelection" label="RowSelection" /> 속성이 single로 설정된 경우 체크박스는 비활성화되며, 선택이 놓인 그룹을 나타내는 표시 역할만 합니다. <ApiLink type="Grid" member="rowSelection" label="RowSelection" /> 속성이 multiple로 설정된 경우에는 그룹화 행 선택기를 클릭하면 이 그룹에 속한 모든 레코드가 선택됩니다.

## {Platform} 그리드 그룹화 예제
이 예제는 많은 양의 데이터에 대한 그룹화 기능을 보여 줍니다. 열 헤더를 맨 위(그룹화 영역)로 드래그하면 사용자는 선택한 열의 데이터를 계층 구조로 볼 수 있습니다. 더 많은 열 헤더를 맨 위로 드래그하여 여러 필드로 그룹화할 수도 있습니다. 이러한 그룹화 옵션은 행과 열이 많은 표에서 사용자가 데이터를 훨씬 빠르고 시각적으로 보기 좋은 방식으로 제시하고 싶을 때 유용합니다.

### 펼치기/접기 API

그룹화 식 외에도 그룹 행의 펼침 상태를 제어할 수 있습니다. 이는 <ApiLink type="Grid" /> 컴포넌트의 별도 속성 <ApiLink type="Grid" member="groupingExpansionState" label="GroupingExpansionState" />에 저장되며, <ApiLink type="GroupByExpandState" />의 컬렉션입니다. 각 펼침 상태는 생성된 필드 이름과 각 그룹화 수준에서 나타내는 값에 의해 고유하게 정의됩니다. 즉 식별자는 <ApiLink type="GroupByKey" />의 계층 배열입니다.

<ApiLink type="Grid" member="groupingExpressions" label="GroupingExpressions" />와 마찬가지로, <ApiLink type="GroupByExpandState" />의 목록을 <ApiLink type="Grid" member="groupingExpansionState" label="GroupingExpansionState" />에 직접 설정하면 펼침 상태가 그에 따라 바뀝니다. 또한 <ApiLink type="Grid" />는 그룹 레코드 인스턴스 또는 행의 <ApiLink type="RowDirective" member="expanded" label="Expanded" /> 속성을 통해 그룹을 토글하는 <ApiLink type="Grid" member="toggleGroup" label="ToggleGroup" /> 메서드를 노출합니다.


<PlatformBlock for="WebComponents">


```typescript
const groupRow = this.grid.getRowByIndex(0).groupRow;
grid.toggleGroup(groupRow);
```

```typescript
const groupRow = this.grid.getRowByIndex(0);
groupRow.expanded = false;
```

</PlatformBlock>



<PlatformBlock for="React">


```typescript
const groupRow = gridRef.current.getRowByIndex(0).groupRow;
gridRef.current.toggleGroup(groupRow);
```

```typescript
const groupRow = gridRef.current.getRowByIndex(0);
groupRow.expanded = false;
```

</PlatformBlock>


<PlatformBlock for="Blazor">

```razor
<IgbGrid AutoGenerate="true" Data="InvoicesData" GroupingExpressions="GroupingExpression1" GroupingExpansionState=ExpansionState @ref="grid" Id="grid">
</IgbGrid>

@code {
    public IgbGroupingExpression[] GroupingExpression1 = new IgbGroupingExpression[2]
    {
        new IgbGroupingExpression(){ FieldName = "ShipCountry", Dir= SortingDirection.Asc },
        new IgbGroupingExpression() { FieldName = "ShipCity", Dir= SortingDirection.Asc  }
    };
    public IgbGroupByExpandState[] state = new IgbGroupByExpandState[1]
    {
        new IgbGroupByExpandState(){ Hierarchy = new IgbGroupByKey[1]{ new IgbGroupByKey() { FieldName="ShipCountry", Value = "USA" } },  Expanded = false }
    };
}
```

</PlatformBlock>

그룹은 펼친 상태(**기본값**) 또는 접힌 상태로 만들 수 있으며, 펼침 상태에는 일반적으로 기본 동작과 반대되는 상태만 포함됩니다. <ApiLink type="Grid" member="groupsExpanded" label="GroupsExpanded" /> 속성을 통해 그룹을 펼친 상태로 만들지 여부를 제어할 수 있습니다.

### 그룹의 모든 행 선택/선택 해제 API

그룹의 모든 행을 선택하거나 선택 해제하는 기능은 <ApiLink type="Grid" member="selectRowsInGroup" label="SelectRowsInGroup" /> 및 <ApiLink type="Grid" member="deselectRowsInGroup" label="DeselectRowsInGroup" /> API 메서드를 통해 사용할 수 있습니다.

아래 코드 스니펫은 그룹 레코드 인스턴스의 <ApiLink type="Grid" member="selectRowsInGroup" label="SelectRowsInGroup" /> 메서드를 사용하여 그룹 내 모든 행을 선택하는 데 사용할 수 있습니다. 또한 이 메서드의 두 번째 매개변수는 이전 행 선택을 지울지 여부를 선택할 수 있는 불리언 속성입니다. 기본적으로 이전 선택은 유지됩니다.


<PlatformBlock for="WebComponents">


```typescript
const groupRow = this.grid.getRowByIndex(0).groupRow;
grid.selectRowsInGroup(groupRow);
```

</PlatformBlock>



<PlatformBlock for="React">


```typescript

gridRef.current.selectRowsInGroup(groupRow);
```

</PlatformBlock>


<PlatformBlock for="Blazor">


</PlatformBlock>

## 템플릿

### 그룹 행 템플릿

펼치기/접기 UI를 제외한 그룹 행은 완전히 템플릿화할 수 있습니다. 기본적으로 그룹화 아이콘을 렌더링하고, 나타내는 필드 이름과 값을 표시합니다. 템플릿을 렌더링할 때 사용되는 컨텍스트는 <ApiLink type="GroupByRecord" /> 타입입니다.

예를 들어 다음 템플릿은 그룹 행의 요약을 더 자세하게 만듭니다:

<PlatformBlock for="Angular">
```html
<ng-template GroupByRow let-groupRow>
    <span>Total items with value: {{ groupRow.value }} are {{ groupRow.records.length }}</span>
</ng-template>
```
</PlatformBlock>

<PlatformBlock for="React">

```tsx
const template = (ctx: IgrGroupByRowTemplateContext) => {
    const groupRow = ctx.implicit;
    return (<>
       <span>Total items with value: { groupRow.value } are { groupRow.records.length }</span>
    </>)
}
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
    public groupByRowTemplate = (ctx: IgcGroupByRowTemplateContext) => {
        const groupRow: IgcGroupByRecord = ctx.implicit;
        return html`<span>Total items with value: ${ groupRow.value } are ${ groupRow.records.length }</span>`;
    }
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbGrid AutoGenerate="true" Data="InvoicesData" @ref="grid" Id="grid" GroupRowTemplateScript="WebGridGroupByRowTemplate"></IgbGrid>
```

```javascript
//In JavaScript:
igRegisterScript("WebGridGroupByRowTemplate", (ctx) => {
    var html = window.igTemplating.html;
    var groupRow = ctx.implicit;
    return html`<span>Total items with value: ${groupRow.value} are ${groupRow.records.length}</span>`;
}, false);
```

</PlatformBlock>


### 그룹 행 선택기 템플릿

위에서 언급했듯이 펼치기/접기 UI를 제외한 그룹 행은 완전히 템플릿화할 수 있습니다. 사용자 지정 그룹화 행 선택기 템플릿을 만들려면 <ApiLink type="Grid" member="groupByRowSelectorTemplate" label="GroupByRowSelectorTemplate" />를 사용하십시오. 템플릿 안에서는 암시적으로 제공되는 컨텍스트 변수에 액세스할 수 있으며, 이 변수의 속성을 통해 그룹화 행의 상태 정보를 얻을 수 있습니다.

<ApiLink type="GroupByRowSelectorTemplateDetails" member="selectedCount" label="SelectedCount" /> 속성은 현재 선택된 그룹 레코드가 몇 개인지 보여 주고, <ApiLink type="GroupByRowSelectorTemplateDetails" member="totalCount" label="TotalCount" />은(는) 그룹에 속한 레코드가 몇 개인지 보여 줍니다.

<PlatformBlock for="Angular">

## {Platform} 그리드 페이징을 포함한 그룹화

그룹 행은 데이터 행과 함께 페이징 과정에 참여합니다. 각 페이지의 페이지 크기에 포함됩니다. 접힌 행은 페이징 과정에 포함되지 않습니다. 펼치기 또는 접기 작업은 페이징이 페이지 수를 다시 계산하고, 필요하면 페이지 인덱스를 조정하도록 합니다.
여러 페이지에 걸친 그룹은 페이지 사이에서 나뉩니다. 그룹 행은 시작하는 페이지에서만 보이며, 이후 페이지에서는 반복되지 않습니다. 그룹 행의 요약 정보는 그룹 전체를 기준으로 계산되며 페이징의 영향을 받지 않습니다.

## 키보드 탐색

그룹화 UI는 다음 키보드 상호 작용을 지원합니다:

- 그룹 행의 경우(포커스가 행 또는 펼치기/접기 셀에 있어야 함)
  - <kbd>ALT</kbd> + <kbd>RIGHT</kbd> - 그룹을 펼칩니다
  - <kbd>ALT</kbd> + <kbd>LEFT</kbd> - 그룹을 접습니다
  - <kbd>SPACE</kbd> - <kbd>rowSelection</kbd> 속성이 multiple로 설정되어 있으면 그룹의 모든 행을 선택합니다

- 그룹화 영역의 그룹 <ApiLink pkg="core" type="Chip" /> 컴포넌트의 경우(포커스가 칩에 있어야 함)
  - <kbd>SHIFT</kbd> + <kbd>LEFT</kbd> - 가능하다면 포커스된 칩을 왼쪽으로 옮겨 그룹화 순서를 바꿉니다
  - <kbd>SHIFT</kbd> + <kbd>RIGHT</kbd> - 가능하다면 포커스된 칩을 오른쪽으로 옮겨 그룹화 순서를 바꿉니다
  - <kbd>SPACE</kbd> - 정렬 방향을 바꿉니다
  - <kbd>DELETE</kbd> - 필드의 그룹화를 해제합니다
  - 칩의 개별 요소도 포커스할 수 있으며, <kbd>ENTER</kbd> 키로 상호 작용할 수 있습니다.

A <PlatformBlock for="React"><ApiLink type="GroupingExpression" member="groupingComparer" label="GroupingComparer" /></PlatformBlock><ApiLink type="GroupingExpression" member="groupingComparer" label="GroupingComparer" /> 함수는 그룹화 식에 대해 정의되며, 선택된 그룹화 모드를 기준으로 같은 그룹에 속하는 항목을 결정합니다. 정렬된 데이터에서 이 함수가 0을 반환하는 값은 같은 그룹의 일부로 표시됩니다.

```typescript
grid.groupingExpressions = [
    { fieldName: 'OrderDate', dir: SortingDirection.Desc,
    groupingComparer: (a, b) => {
            const dateA = this.getParsedDate(a);
            const dateB = this.getParsedDate(b);
            if (this.groupByMode === 'Month') {
                return dateA.month === dateB.month ? 0 : -1;
            } else if (this.groupByMode === "Year") {
                return dateA.year === dateB.year ? 0 : -1;
            } else if (this.groupByMode === 'Week') {
                return this.getWeekOfDate(a) === this.getWeekOfDate(b) ? 0 : -1;
            }
            return dateA.day === dateB.day && dateA.month === dateB.month ? 0 : -1;
        }
    }
];
```

### 사용자 지정 색상 팔레트 정의하기

위에서 설명한 방식에서는 색상 값이 하드코딩되어 있었습니다. 대신 `palette` 및 `color` 함수를 사용하면 더 큰 유연성을 얻을 수 있습니다.
`palette`는 지정된 기본 색상과 보조 색상을 기준으로 색상 팔레트를 생성합니다.

```scss
$black-color: #292826;
$yellow-color: #FFCD0F;

$custom-palette: palette(
  $primary: $black-color,
  $secondary: $yellow-color
);
```

```scss
$custom-theme: grid-theme(
```

### 사용자 지정 스키마 정의하기

더 나아가 [**스키마**](../themes/sass/schemas.mdx)의 모든 장점을 가진 유연한 구조를 만들 수 있습니다. **스키마**는 테마의 레시피입니다.
모든 컴포넌트에 제공되는 두 개의 사전 정의된 스키마 중 하나를 확장하십시오. 이 경우에는 `$_light_grid`를 사용하겠습니다.

```scss
$custom-grid-schema: extend($_light-grid,(
    group-row-background: (-color:('secondary', 100)),
    group-row-selected-background: (-color:('primary', 400)),
    group-label-column-name-text: (-color:('primary', 600)),
    group-label-icon: (-color:('primary', 600)),
    group-label-text: (-color:('secondary', 700)),
    group-count-background: (-color:('primary', 600)),
    group-count-text-color: (-color:('secondary', 400)),
    expand-icon-color: (-color:('primary', 600)),
    expand-icon-hover-color: (-color:('primary', 400))
));
```

사용자 지정 스키마를 적용하려면 전역 `light` 또는 `dark` 중 하나를 확장해야 합니다. 전체 과정은 컴포넌트에 사용자 지정 스키마를 제공한 다음, 이를 해당 컴포넌트 테마에 추가하는 것입니다.

```scss
$my-custom-schema: extend($light-schema, (
    -grid: $custom-grid-schema
));

$custom-theme: grid-theme(
    $palette: $custom-palette,
    $schema: $my-custom-schema
);
```

### 사용자 지정 테마 적용하기

테마를 적용하는 가장 쉬운 방법은 전역 스타일 파일에 `sass` `@include` 문을 추가하는 것입니다:

```scss
@include grid($custom-theme);
@include chip($custom-chips-theme);
```

### 범위가 지정된 컴포넌트 테마

사용자 지정 테마가 특정 컴포넌트에만 영향을 주도록 하려면, 방금 정의한 모든 스타일을 전역 스타일 파일에서 사용자 지정 컴포넌트의 스타일 파일로 옮길 수 있습니다(`index` 파일의 import 포함).

이렇게 하면 {Platform}의 [ViewEncapsulation](https://{Platform}.io/api/core/Component#encapsulation) 때문에 스타일이 사용자 지정 컴포넌트에만 적용됩니다.

 <DocsAside type="info">
 컴포넌트가 [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, 그리드의 스타일을 지정하려면 `::ng-deep`를 사용하여 이 캡슐화를 관통해야 합니다.
 </DocsAside>

 <DocsAside type="info">
 스타일이 컴포넌트 바깥의 요소에 영향을 주지 않도록, 구문을 `:host` 선택자 안에 넣으십시오:
 </DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid($custom-theme);
        @include chip($custom-chips-theme);
    }
}
```
