# 계층형 그리드 요청 시 로드

Ignite UI for {Platform} <ApiLink type="HierarchicalGrid" />는 사용자가 화면의 결과를 가능한 한 빨리 보고 보이는 데이터와 상호 작용할 수 있도록, 서버에서 가져올 데이터를 최소한으로 요청하여 빠르게 렌더링합니다. 처음에는 루트 그리드의 데이터만 가져와 렌더링하며, 사용자가 하위 그리드가 포함된 행을 펼친 후에야 해당 하위 그리드의 데이터를 받습니다. 요청 시 로드(Load on Demand)라고도 하는 이 메커니즘은 모든 원격 데이터와 함께 쉽게 구성할 수 있습니다.

이 항목은 이미 준비된 원격 서비스와 통신하는 원격 서비스 제공자를 만들어 요청 시 로드를 구성하는 방법을 보여 줍니다. 여기 작동하는 데모가 있으며, 이후 단계별로 살펴보면서 그 생성 과정을 설명하겠습니다.

## 원격 서비스 제공자

먼저 계층형 그리드에 필요한 데이터를 가져올 수 있도록 서비스 제공자를 준비하겠습니다.

### 기본 데이터 가져오기


<PlatformBlock for="Angular">


브라우저가 제공하는 XMLHttpRequest 인터페이스를 사용하여 HTTP 프로토콜로 백엔드 서비스와 통신합니다. 이를 더 쉽게 하기 위해, 단순화된 클라이언트 HTTP API를 제공하는 Angular의 [`HttpClient`](https://angular.io/api/common/http/HttpClient) 모듈을 사용하겠습니다. 이렇게 하면 데이터를 가져오기 위해 서비스에 다음과 같은 간단한 메서드가 필요합니다:

```typescript
public getData(dataState): Observable<any[]> {
    return this.http.get(this.buildUrl(dataState)).pipe(
        map(response => response),
    );
}
```

보시다시피 `this.http`는 `HttpCLient` 모듈에 대한 참조이며, `buildUrl()`는 받은 데이터를 기준으로 URL을 생성하는 메서드입니다. 이 호출은 비동기로 실행되므로, 응답을 매핑하여 Observable을 반환합니다. 그래서 나중에 이를 구독하고, 애플리케이션에서 추가로 처리한 다음 그리드에 전달할 수 있습니다.

</PlatformBlock>

### 요청 URL 만들기

다음으로 GET 요청의 URL을 어떻게 만들지 정의하겠습니다. 이곳에서 주 그리드의 데이터뿐만 아니라 그 안의 모든 하위 그리드의 데이터도 가져올 수 있습니다. 루트 수준에는 이 [항목](https://data-northwind.indigo.design/swagger/index.html)의 `Customers` 데이터를 사용하고, 하위 수준에는 `Orders`와 `Details`를 사용합니다. 모델은 애플리케이션마다 다르지만, 여기서는 다음 모델을 사용하겠습니다:

<Image src={hgridDatabase} alt="hgrid-database" class="responsive-img" />

먼저 필요한 것은 원하는 그리드의 데이터를 어디에서 가져올지 결정하기 위한 테이블의 `key`, 상위 행의 기본 키, 그리고 고유 ID입니다.

```typescript
export interface IDataState {
    key: string;
    parentID: any;
    parentKey: string;
    rootLevel: boolean;
}

//...
public buildUrl(dataState: IDataState): string {
    let qS = "";
    if (dataState) {
        if (dataState.rootLevel) {
            qS += `${dataState.key}`;
        } else {
            qS += `${dataState.parentKey}/${dataState.parentID}/${dataState.key}`;
        }
    }
    return `${this.url}${qS}`;
}
//...
```

```typescript
import { HttpClient } from '@angular/common/http';
import { Injectable } from '@angular/core';
import { Observable } from 'rxjs';
import { map } from 'rxjs/operators';

export interface IDataState {
    key: string;
    parentID: any;
    parentKey: string;
    rootLevel: boolean;
}

@Injectable()
export class RemoteLoDService {
    public url = `https://data-northwind.indigo.design/`;

    constructor(private http: HttpClient) { }

    public getData(dataState: IDataState): Observable<any[]> {
        return this.http.get(this.buildUrl(dataState)).pipe(
            map((response) => response)
        );
    }

    public buildUrl(dataState: IDataState): string {
        let qS = "";
        if (dataState) {
            if (dataState.rootLevel) {
                qS += `${dataState.key}`;
            } else {
                qS += `${dataState.parentKey}/${dataState.parentID}/${dataState.key}`;
            }
        }
        return `${this.url}${qS}`;
    }
}
```

펼쳐진 하위 항목의 데이터를 설정하는 것은 조금 다릅니다. 행이 처음 펼쳐지면 그 행에 대해 새 하위 <ApiLink type="HierarchicalGrid" />가 렌더링되며, 새로 만들어진 그리드의 참조를 얻어 데이터를 설정해야 합니다. 그래서 각 <ApiLink type="RowIsland" /> 컴포넌트는 특정 행 아일랜드에 대해 새 하위 그리드가 만들어질 때 발생하는 `GridCreated` 이벤트를 제공합니다. 이를 사용하여 새 그리드의 참조를 얻고, 서비스에 데이터를 요청한 다음 적용할 수 있습니다.

서비스는 루트 수준 여부, 행 아일랜드의 키, 상위 행의 기본 키, 고유 식별자 정보만 필요하도록 만들었으므로, 모든 행 아일랜드에 대해 하나의 메서드를 사용할 수 있습니다. 이 정보는 이벤트 인수에서 직접 얻거나, 이벤트를 발생시킨 행 아일랜드에서 얻을 수 있습니다.

</PlatformBlock>



<PlatformBlock for="Blazor">

</PlatformBlock>



<PlatformBlock for="Angular, WebComponents">


`GridCreated` 이벤트는 `parentID` 속성, 행 아일랜드에 대한 참조인 `owner`, 그리고 새로 생성된 하위 `grid` 속성을 제공하므로, 이들이 첫 번째 인수로 전달됩니다. 상위 행의 `primaryKey` 정보만 빠져 있지만, 바인딩하는 행 아일랜드에 따라 두 번째 인수로 쉽게 전달할 수 있습니다.

</PlatformBlock>

### 서비스 연결하기

이제 마지막 단계 중 하나는 앞에서 만든 서비스를 계층형 그리드에 연결하는 것입니다.


<PlatformBlock for="Angular">


`Injectable`로 정의했으므로, 애플리케이션에 제공자로 전달할 수 있습니다. 또한 `ViewChild` 쿼리를 사용하여 루트 그리드의 참조를 얻고 데이터를 설정하겠습니다:

```typescript
@Component({
    providers: [RemoteLoDService],
    selector: "app-hierarchical-grid-lod",
    styleUrls: ["./hierarchical-grid-lod.component.scss"],
    templateUrl: "./hierarchical-grid-lod.component.html"
})
export class HierarchicalGridLoDSampleComponent {
    @ViewChild("hGrid")
    public hGrid: IgxHierarchicalGridComponent;

    constructor(private remoteService: RemoteLoDService) { }
}
```

서비스에서 데이터를 요청하고 할당하기 전에 그리드가 렌더링되도록, `AfterViewInit` 라이프사이클 훅을 사용하겠습니다. 상위가 없으므로 `rootLevel`가 **true**라는 사실과 그 키를 서비스의 `getData`에 전달할 수 있습니다. Observable을 반환하므로 이를 구독해야 합니다:

```typescript
public ngAfterViewInit() {
    this.remoteService.getData({ parentID: null, rootLevel: true, key: "Customers" }).subscribe((data) => {
        this.hGrid.data = data;
        this.hGrid.cdr.detectChanges();
    });
}
```

</PlatformBlock>

### 로딩 표시 설정

<ApiLink type="HierarchicalGrid" />는 데이터가 없는 동안 <ApiLink type="GridBaseDirective" member="isLoading" label="IsLoading" /> 속성을 **true**로 설정하여 로딩 표시기를 표시할 수 있습니다. 이 속성은 루트 그리드에 대해 처음에 설정해야 하며, 새 하위 그리드를 만들 때도 데이터가 로드될 때까지 설정해야 합니다. 템플릿에서 항상 **true**로 설정할 수도 있지만, 서비스가 빈 배열을 반환하면 **false**로 설정하여 로딩 표시기를 숨기고 그리드에 데이터가 없음을 표시하고 싶습니다.

이 경우 구성의 최종 버전은 다음과 같습니다:


<PlatformBlock for="Angular">


```typescript
import { AfterViewInit, Component, ViewChild } from "@angular/core";
import {
    IGridCreatedEventArgs,
    IgxHierarchicalGridComponent,
    IgxRowIslandComponent
} from "igniteui-angular";
import { RemoteLoDService } from "../services/remote-lod.service";

@Component({
    providers: [RemoteLoDService],
    selector: "app-hierarchical-grid-lod",
    styleUrls: ["./hierarchical-grid-lod.component.scss"],
    templateUrl: "./hierarchical-grid-lod.component.html"
})
export class HierarchicalGridLoDSampleComponent implements AfterViewInit {
    @ViewChild("hGrid")
    public hGrid: IgxHierarchicalGridComponent;

    constructor(private remoteService: RemoteLoDService) { }

    public ngAfterViewInit() {
        this.hGrid.isLoading = true;
        this.remoteService.getData({ parentID: null, rootLevel: true, key: "Customers" }).subscribe((data) => {
            this.hGrid.isLoading = false;
            this.hGrid.data = data;
            this.hGrid.cdr.detectChanges();
        });
    }

    public gridCreated(event: IGridCreatedEventArgs, _parentKey: string) {
        const dataState = {
            key: event.owner.key,
            parentID: event.parentID,
            parentKey: _parentKey,
            rootLevel: false
        };
        event.grid.isLoading = true;
        this.remoteService.getData(dataState).subscribe(
            (data) => {
                event.grid.isLoading = false;
                event.grid.data = data;
                event.grid.cdr.detectChanges();
            }
        );
    }
}
```
