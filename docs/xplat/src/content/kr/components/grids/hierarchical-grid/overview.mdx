# 계층형 데이터 그리드 개요 및 구성

{ProductName} 계층형 데이터 그리드는 계층형 표 형식 데이터를 표시하고 조작하는 데 사용됩니다. 매우 적은 코드로 데이터를 빠르게 바인딩하거나, 다양한 이벤트를 사용하여 여러 동작을 사용자 지정할 수 있습니다. 이 컴포넌트는 데이터 선택, Excel 스타일 필터링, 정렬, 페이징, 템플릿화, 열 이동, 열 고정, Excel 및 CSV 내보내기 등 풍부한 기능 세트를 제공합니다. Hierarchical Grid는 평면 그리드 컴포넌트를 기반으로 하며, 더 자세한 정보가 필요할 때 사용자가 상위 그리드의 행을 펼치거나 접어서 해당 하위 그리드를 드러낼 수 있도록 기능을 확장합니다.

## {Platform} 계층형 데이터 그리드 사용하기

### 데이터 바인딩

**{HierarchicalGridSelector}**은 {GridSelector}에서 파생되며 대부분의 기능을 공유합니다. 주요 차이점은 여러 수준의 계층을 정의할 수 있다는 것입니다. 이는 **{HierarchicalGridSelector}** 정의 안의 별도의 태그인 **{RowIslandSelector}**를 통해 구성합니다. **{RowIslandSelector}** 컴포넌트는 특정 수준에 대한 각 하위 그리드의 구성을 정의합니다. 수준마다 여러 행 아일랜드도 지원됩니다.
Hierarchical Grid는 데이터에 바인딩하는 두 가지 방식을 지원합니다:

### 계층 데이터 사용하기

애플리케이션이 하위 객체 배열을 참조하는 객체 배열로서 전체 계층형 데이터를 불러오면, Hierarchical Grid는 이를 읽고 자동으로 바인딩하도록 구성할 수 있습니다. 다음은 올바르게 구조화된 계층 데이터 소스의 예입니다:

### 요청 시 로드 사용하기

대부분의 애플리케이션은 처음에 가능한 한 적은 데이터를 로드하도록 설계되어 로드 시간을 단축합니다. 이런 경우 {HierarchicalGridSelector}는 사용자가 만든 서비스가 요청 시 데이터를 제공하도록 구성할 수 있습니다.

```typescript
//  hierarchicalGridSample.component.ts

@Component({...})
export class HierarchicalGridLoDSampleComponent implements AfterViewInit {
    @ViewChild("hGrid")
    public hGrid: IgxHierarchicalGridComponent;

    constructor(private remoteService: RemoteLoDService) { }

    public ngAfterViewInit() {
        this.hGrid.isLoading = true;
        this.remoteService.getData({ parentID: null, rootLevel: true, key: "Customers" }).subscribe((data) => {
            this.hGrid.isLoading = false;
            this.hGrid.data = data;
            this.hGrid.cdr.detectChanges();
        });
    }

    public gridCreated(event: IGridCreatedEventArgs, _parentKey: string) {
        const dataState = {
            key: event.owner.key,
            parentID: event.parentID,
            parentKey: _parentKey,
            rootLevel: false
        };
        event.grid.isLoading = true;
        this.remoteService.getData(dataState).subscribe(
            (data) => {
                event.grid.isLoading = false;
                event.grid.data = data;
                event.grid.cdr.detectChanges();
            }
        );
    }
}
```

```typescript
// remote-load-on-demand.service.ts

@Injectable()
export class RemoteLoDService {
    public url = `https://data-northwind.indigo.design/`;

    constructor(private http: HttpClient) { }

    public getData(dataState: any): Observable<any[]> {
        return this.http.get(this.buildUrl(dataState)).pipe(
            map((response) => response)
        );
    }

    public buildUrl(dataState) {
        let qS = "";
        if (dataState) {
            if (dataState.rootLevel) {
                qS += `${dataState.key}`;
            } else {
                qS += `${dataState.parentKey}/${dataState.parentID}/${dataState.key}`;
            }
        }
        return `${this.url}${qS}`;
    }
}
```

```ts
export class HierarchicalGridLoadOnDemand {
    constructor() {
        const hierarchicalGrid = document.getElementById("hGrid") as IgcHierarchicalGridComponent;
        const ordersRowIsland = document.getElementById("ordersRowIsland");
        const orderDetailsRowIsland = document.getElementById("orderDetailsRowIsland");

        ordersRowIsland.addEventListener("gridCreated", (event: any) => {
            this.gridCreated(event, "Customers");
        });
        orderDetailsRowIsland.addEventListener("gridCreated", (event: any) => {
            this.gridCreated(event, "Orders");
        });

        hierarchicalGrid.isLoading = true;

            hierarchicalGrid.isLoading = false;
            hierarchicalGrid.data = data;
            hierarchicalGrid.markForCheck();

        const context = event.detail;

            key: context.owner.childDataKey,
            parentID: context.parentID,

            context.grid.isLoading = false;
```

- 정렬
- 필터링
- 페이징
- 다중 열 헤더
- 숨기기
- 고정
- 이동
- 요약
- 검색

선택 및 탐색 기능은 전체 {HierarchicalGridTitle}에 전역으로 동작합니다

- 선택
    선택은 서로 다른 두 하위 그리드에 선택된 셀이 동시에 존재하는 것을 허용하지 않습니다.
- 탐색
    <kbd>↑</kbd> + <kbd>↓</kbd>로 탐색할 때, 다음/이전 요소가 하위 그리드이면 탐색은 관련 하위 그리드에서 계속되며, 관련 셀이 선택되고 포커스됩니다. 하위 셀이 현재 보이는 뷰포트 밖에 있으면 화면에 보이도록 스크롤되어, 선택된 셀이 항상 보이게 됩니다.

## 스타일링
igxHierarchicalGrid는 [Ignite UI for Angular 테마 라이브러리](../themes/sass/component-themes.mdx)를 통한 스타일 지정을 지원합니다. 그리드의 <ApiLink type="function-grid-theme" label="theme" kind="sass" module="index.html" />는 다양한 속성을 노출하며, 이를 통해 그리드의 모든 기능을 사용자 지정할 수 있습니다.

아래 단계에서는 igxHierarchicalGrid의 스타일링을 사용자 지정하는 과정을 살펴봅니다.

### 전역 테마 가져오기
계층형 그리드의 사용자 지정을 시작하려면 모든 스타일링 함수와 믹스인이 있는 `index` 파일을 가져와야 합니다.

```scss
@import '~igniteui-angular/lib/core/styles/themes/index'
```

### 사용자 지정 테마 정의하기
다음으로 <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" />을 확장하고 계층형 그리드를 원하는 대로 사용자 지정하는 데 필요한 매개변수를 받는 새 테마를 만드십시오.

 <DocsAside type="info">
 `sass` 계층형 그리드에 특화된 함수는 없습니다.
 </DocsAside>


```scss
$custom-theme: grid-theme(
  $cell-active-border-color: #ffcd0f,
  $cell-selected-background: #6f6f6f,
  $row-hover-background: #f8e495,
  $row-selected-background: #8d8d8d,
  $header-background: #494949,
  $header-text-color: #fff,
  $expand-icon-color: #ffcd0f,
  $expand-icon-hover-color: #e0b710,
  $resize-line-color: #ffcd0f,
  $row-highlight: #ffcd0f
);
```

### 사용자 지정 색상 팔레트 정의하기
위에서 설명한 방식에서는 색상 값이 하드코딩되어 있었습니다. 대신 <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" /> 및 <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" /> 함수를 사용하면 더 큰 유연성을 얻을 수 있습니다.
`igx-palette`는 지정된 기본 색상과 보조 색상을 기준으로 색상 팔레트를 생성합니다.

 ```scss
$black-color: #494949;
$yellow-color: #FFCD0F;

$custom-palette: palette(
  $primary: $black-color,
  $secondary: $yellow-color
);
```

사용자 지정 팔레트가 생성된 후에는 `igx-color` 함수를 사용하여 기본 색상과 보조 색상의 다양한 변형을 얻을 수 있습니다.

```scss
$custom-theme: grid-theme(
    $cell-active-border-color: (igx-color($custom-palette, "secondary", 500)),
    $cell-selected-background: (igx-color($custom-palette, "primary", 300)),
    $row-hover-background: (igx-color($custom-palette, "secondary", 100)),
    $row-selected-background: (igx-color($custom-palette, "primary", 100)),
    $header-background: (igx-color($custom-palette, "primary", 500)),
    $header-text-color: (igx-contrast-color($custom-palette, "primary", 500)),
    $expand-icon-color: (igx-color($custom-palette, "secondary", 500)),
    $expand-icon-hover-color: (igx-color($custom-palette, "secondary", 600)),
    $resize-line-color: (igx-color($custom-palette, "secondary", 500)),
    $row-highlight: (igx-color($custom-palette, "secondary", 500))
);
```

### 사용자 지정 스키마 정의하기
[**스키마**](../themes/sass/schemas.mdx)의 모든 이점을 갖춘 유연한 구조를 만들어 더 나아갈 수도 있습니다. **스키마**는 테마의 레시피입니다.
모든 컴포넌트에 제공되는 사전 정의된 스키마 두 가지 중 하나를 확장하십시오. 이 경우에는 `$_light_grid`를 사용합니다.

```scss
$custom-grid-schema: extend($_light-grid,(
    cell-active-border-color: (igx-color:('secondary', 500)),
    cell-selected-background: (igx-color:('primary', 300)),
    row-hover-background: (igx-color:('secondary', 100)),
    row-selected-background: (igx-color:('primary', 100)),
    header-background: (igx-color:('primary', 500)),
    header-text-color: (igx-contrast-color:('primary', 500)),
    expand-icon-color: (igx-color:('secondary', 500)),
    expand-icon-hover-color: (igx-color:('secondary', 600)),
    resize-line-color: (igx-color:('secondary', 500)),
    row-highlight: (igx-color:('secondary', 500))
));
```

사용자 지정 스키마를 적용하려면 전역 `light` 또는 `dark` 중 하나를 확장해야 합니다. 전체 과정은 컴포넌트에 사용자 지정 스키마를 제공한 다음, 이를 해당 컴포넌트 테마에 추가하는 것입니다.

```scss
$my-custom-schema: extend($light-schema, (
    igx-grid: $custom-grid-schema
));

$custom-theme: grid-theme(
    $palette: $custom-palette,
    $schema: $my-custom-schema
);
```

### 사용자 지정 테마 적용하기
테마를 적용하는 가장 쉬운 방법은 전역 스타일 파일에 `sass` `@include` 문을 추가하는 것입니다:

```scss
@include grid($custom-theme);
```

### 범위가 지정된 컴포넌트 테마

사용자 지정 테마가 특정 컴포넌트에만 영향을 주도록 하려면, 방금 정의한 모든 스타일을 전역 스타일 파일에서 사용자 지정 컴포넌트의 스타일 파일로 옮기십시오(`index` 파일의 가져오기도 포함).

이렇게 하면 Angular의 [ViewEncapsulation](https://angular.io/api/core/Component#encapsulation) 덕분에 스타일이 사용자 지정 컴포넌트에만 적용됩니다.

 <DocsAside type="info">
 컴포넌트가 [`Emulated`](../themes/sass/component-themes.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, 그리드의 스타일을 지정하려면 `::ng-deep`를 사용하여 이 캡슐화를 관통해야 합니다.
 </DocsAside>

 <DocsAside type="info">
 스타일이 컴포넌트 바깥의 요소에 영향을 주지 않도록, 구문을 `:host` 선택자 안에 넣으십시오:
 </DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid($custom-theme);
    }
}
```
