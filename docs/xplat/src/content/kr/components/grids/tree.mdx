# {Platform} 트리 개요

{ProductName} 트리는 TreeView 컴포넌트라고도 하며, 확장 가능한 데이터 구조를 트리 형태의 UI로 시각화하는 고성능 컨트롤입니다. 하위 항목에 요청 시 로드를 적용할 수 있습니다. {ProductName} 트리는 노드의 펼치기와 접기, 중첩된 앱 탐색 등의 기능도 제공합니다. {ProductName} 트리 노드는 수동으로 생성하거나 바인딩된 데이터 소스에서 생성할 수 있습니다.

최종 사용자는 이를 통해 여러 앱 페이지를 쉽게 탐색하고, 선택, 체크박스, 텍스트, 아이콘, 이미지 등을 사용할 수 있습니다.

{ProductName} 트리 컴포넌트를 사용하면 사용자가 상위-하위 관계를 유지하면서 계층형 데이터를 트리 뷰 구조로 표현할 수 있으며, 대응하는 데이터 모델 없이 정적인 트리 뷰 구조를 정의할 수도 있습니다. 주된 목적은 최종 사용자가 계층형 데이터 구조를 시각화하고 그 안에서 탐색할 수 있게 하는 것입니다. <ApiLink pkg="core" type="Tree" /> 컴포넌트는 요청 시 로드 기능, 항목 활성화, 내장 체크박스를 통한 다중 및 계단식 항목 선택, 내장 키보드 탐색 등도 제공합니다.

### 트리 선언하기
<ApiLink pkg="core" type="TreeItem" />는 <ApiLink pkg="core" type="Tree" />에 속한 모든 항목을 나타냅니다.
항목은 <ApiLink pkg="core" type="TreeItem" member="disabled" label="Disabled" />, <ApiLink pkg="core" type="TreeItem" member="active" label="Active" />, <ApiLink pkg="core" type="TreeItem" member="selected" label="Selected" />, <ApiLink pkg="core" type="TreeItem" member="expanded" label="Expanded" /> 속성을 제공하며, 이를 통해 요구 사항에 따라 항목의 상태를 구성할 수 있습니다.
<ApiLink pkg="core" type="TreeItem" member="value" label="Value" /> 속성을 사용하면 항목이 나타내는 데이터 항목에 대한 참조를 추가할 수 있습니다.

- 항목 계층을 지정하고 데이터 집합을 순회하여 트리와 그 항목을 선언하기

### 항목 상호 작용

<ApiLink pkg="core" type="TreeItem" />은(는) 다음과 같이 펼치거나 접을 수 있습니다:
- 항목의 펼치기 표시기를 클릭하면 됩니다(기본 동작).
- <ApiLink pkg="core" type="Tree" /> <ApiLink pkg="core" type="Tree" member="toggleNodeOnClick" label="ToggleNodeOnClick" /> 속성이 `true`로 설정된 경우, 항목을 클릭하면 됩니다.

<PlatformBlock for="WebComponents">

```html
<igc-tree toggle-node-on-click="true">
    <igc-tree-item label="North America">
        <igc-tree-item label="United States"></igc-tree-item>
        <igc-tree-item label="Canada"></igc-tree-item>
        <igc-tree-item label="Mexico"></igc-tree-item>
    </igc-tree-item>
    <igc-tree-item label="South America">
        <igc-tree-item label="Brazil"></igc-tree-item>
    </igc-tree-item>
</igc-tree>
```

</PlatformBlock>

기본적으로 여러 항목을 동시에 펼칠 수 있습니다. 이 동작을 바꾸어 한 번에 하나의 가지만 펼치도록 하려면 <ApiLink pkg="core" type="Tree" member="singleBranchExpand" label="SingleBranchExpand" /> 속성을 활성화할 수 있습니다. 이렇게 하면 항목을 펼칠 때 같은 수준에서 이미 펼쳐져 있던 다른 모든 가지가 접힙니다.

<PlatformBlock for="WebComponents">


또한 <ApiLink pkg="core" type="Tree" />는 항목 상호 작용을 위해 다음 API 메서드를 제공합니다:

- <ApiLink type="Tree" member="Expand" label="Tree.Expand" /> - 모든 항목을 펼칩니다. 항목 배열을 전달하면 지정된 항목만 펼칩니다.
- <ApiLink type="Tree" member="Collapse" label="Tree.Collapse" /> - 모든 항목을 접습니다. 항목 배열을 전달하면 지정된 항목만 접습니다.
- <ApiLink type="Tree" member="Select" label="Tree.Select" /> - 모든 항목을 선택합니다. 항목 배열을 전달하면 지정된 항목만 선택합니다. `selection` 이벤트를 발생시키지 않습니다.
- <ApiLink type="Tree" member="Deselect" label="Tree.Deselect" /> - 모든 항목의 선택을 해제합니다. 항목 배열을 전달하면 지정된 항목만 선택 해제합니다. `selection` 이벤트를 발생시키지 않습니다.

</PlatformBlock>


## {Platform} 트리 선택

{ProductName} 트리 컴포넌트에서 항목 선택을 설정하려면 <ApiLink pkg="core" type="Tree" member="selection" label="Selection" /> 속성만 설정하면 됩니다. 이 속성은 다음 세 가지 모드를 받습니다: **None**, **Multiple**, **Cascade**. 아래에서 각 모드를 더 자세히 살펴보겠습니다.

### None

<ApiLink pkg="core" type="Tree" />에서는 기본적으로 항목 선택이 비활성화되어 있습니다. 사용자는 UI 상호 작용으로 항목을 선택하거나 선택 해제할 수 없지만, 이 작업은 제공된 API 메서드를 통해 여전히 완료할 수 있습니다.

### Multiple

<ApiLink pkg="core" type="Tree" />에서 다중 항목 선택을 활성화하려면 <ApiLink pkg="core" type="Tree" member="selection" label="Selection" /> 속성을 **multiple**로 설정하기만 하면 됩니다. 그러면 모든 항목에 체크박스가 렌더링됩니다. 각 항목은 선택됨 또는 선택되지 않음의 두 가지 상태를 가집니다. 이 모드는 다중 선택을 지원합니다.

<PlatformBlock for="WebComponents">

```html
<igc-tree selection="multiple">
</igc-tree>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbTree Selection=TreeSelection.Multiple>
</IgbTree>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrTree selection="multiple" />
```

</PlatformBlock>

### Cascade
<ApiLink pkg="core" type="Tree" />에서 계단식 항목 선택을 활성화하려면 선택 속성을 **cascade**로 설정하기만 하면 됩니다. 그러면 모든 항목에 체크박스가 렌더링됩니다.

<PlatformBlock for="WebComponents">

```html
<igc-tree selection="Cascade">
</igc-tree>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbTree Selection=TreeSelection.Cascade>
</IgbTree>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrTree selection="cascade" />
```

</PlatformBlock>

이 모드에서 부모의 선택 상태는 전적으로 자식들의 선택 상태에 따라 달라집니다. 부모에 선택된 자식과 선택되지 않은 자식이 함께 있으면, 그 부모의 체크박스는 불확정 상태가 됩니다.

## 키보드 탐색
<ApiLink pkg="core" type="Tree" />의 키보드 탐색은 사용자에게 다양한 키보드 상호 작용을 제공합니다. 이 기능은 기본적으로 활성화되어 있으며, 사용자가 항목 사이를 이동할 수 있게 합니다.

<ApiLink pkg="core" type="Tree" />의 탐색은 W3C 접근성 표준을 준수하며 사용하기 편리합니다.

**키 조합**

- <kbd>↓</kbd> - 다음으로 보이는 항목으로 이동합니다. 해당 항목을 활성 상태로 표시합니다. 마지막 항목에 있으면 아무 일도 일어나지 않습니다.
- <kbd>CTRL</kbd> + <kbd>↓</kbd> - 다음으로 보이는 항목으로 이동합니다. 마지막 항목에 있으면 아무 일도 일어나지 않습니다.
- <kbd>↑</kbd> - 이전으로 보이는 항목으로 이동합니다. 해당 항목을 활성 상태로 표시합니다. 첫 번째 항목에 있으면 아무 일도 일어나지 않습니다.
- <kbd>CTRL</kbd> + <kbd>↑</kbd> - 이전으로 보이는 항목으로 이동합니다. 첫 번째 항목에 있으면 아무 일도 일어나지 않습니다.
- <kbd>←</kbd> - 펼쳐진 상위 항목에서는 그 항목을 접습니다. 항목이 접혀 있거나 하위 항목이 없으면 상위 항목으로 이동합니다. 상위 항목이 없으면 아무 일도 일어나지 않습니다.
- <kbd>→</kbd> - 펼쳐진 상위 항목에서는 그 항목의 첫 번째 하위 항목으로 이동합니다. 접힌 상위 항목에 있으면 그 항목을 펼칩니다. 하위 항목이 없으면 아무 일도 일어나지 않습니다.
- <kbd>HOME</kbd> - 첫 번째 항목으로 이동합니다.
- <kbd>END</kbd> - 마지막으로 보이는 항목으로 이동합니다.
- <kbd>TAB</kbd> - 트리 바깥의 페이지에서 다음 포커스 가능한 요소로 이동합니다.
- <kbd>SHIFT</kbd> + <kbd>TAB</kbd> - 트리 바깥의 페이지에서 이전 포커스 가능한 요소로 이동합니다.
- <kbd>SPACE</kbd> - 현재 항목의 선택을 토글합니다. 해당 노드를 활성 상태로 표시합니다.
- <kbd>SHIFT</kbd> + <kbd>SPACE</kbd> - 선택이 활성화되어 있으면, 활성 항목과 <kbd>SHIFT</kbd>를 누른 상태에서 스페이스 키를 누른 항목 사이의 모든 항목 선택을 토글합니다.
- <kbd>ENTER</kbd> - 포커스된 항목을 활성화합니다. 항목에 링크가 있으면 링크를 엽니다.
- <kbd>*</kbd> - 항목과 같은 수준의 모든 형제 항목을 펼칩니다.

선택이 활성화되면, 최종 사용자의 항목 선택은 렌더링된 체크박스를 통해서만 허용됩니다. 두 선택 유형 모두 다중 선택을 허용하므로, 다음 마우스 및 키보드 상호 작용을 사용할 수 있습니다:

- <kbd>클릭</kbd> - 항목 체크박스에서 수행하면, 선택이 활성화된 경우 항목의 선택을 토글합니다. 그렇지 않으면 항목에 포커스를 둡니다.
- <kbd>SHIFT</kbd> + <kbd>클릭</kbd> - 항목 체크박스에서 수행하면, 선택이 활성화된 경우 <kbd>SHIFT</kbd>를 누른 상태에서 활성 항목과 클릭한 항목 사이의 모든 항목 선택을 토글합니다

## {Platform} 트리 요청 시 로드

{ProductName} 트리는 사용자가 가능한 한 빨리 볼 수 있도록 서버에서 가져올 데이터를 최소한으로 요구하는 방식으로 렌더링할 수 있습니다. 이 동적 데이터 로드 방식에서는 사용자가 항목을 펼친 후에야 해당 상위 항목의 하위 항목을 가져옵니다. 요청 시 로드(Load on Demand)라고도 하는 이 메커니즘은 모든 원격 데이터와 함께 쉽게 구성할 수 있습니다.

<Sample src="/grids/tree/load-on-demand" height={400} alt="{Platform} 트리 요청 시 로드 예제" />




사용자가 펼치기 아이콘을 클릭하면 그 자리에 로딩 표시기가 나타납니다. loading 속성이 false로 확정되면 로딩 표시기가 사라지고 하위 항목이 로드됩니다.

`loadingIndicator` 슬롯을 사용하면 로딩 영역에 사용자 지정 슬롯 콘텐츠를 제공할 수 있습니다. 해당 슬롯이 정의되지 않은 경우에는 <ApiLink pkg="core" type="CircularProgress" />가 사용됩니다.

### 가상화를 사용한 요청 시 로드

{ProductName} 트리는 설계상 트리 항목이 선언적으로 정의되므로, 요청 시 더 많은 하위 항목을 로드하면 성능에 부정적인 영향을 줄 수 있습니다. 다음 데모는 [@lit-labs/virtualizer](https://github.com/lit/lit/tree/main/packages/labs/virtualizer) 라이브러리를 사용하여 가상화된 컨테이너에서 하위 트리 항목을 렌더링하는 방법을 보여 줍니다. 그 결과 DOM에는 보이는 하위 항목 묶음만 렌더링되므로 성능이 향상됩니다.

## 스타일링

아래 나열된 노출된 CSS 파트 중 일부를 사용하여 <ApiLink pkg="core" type="TreeItem" />의 모양을 바꿀 수 있습니다:

| 파트 이름 | 설명 |
| ---------|------------ |
| `wrapper` | 트리 항목의 래퍼입니다. |
| `selected`  | 선택된 상태를 나타냅니다. `wrapper`에 적용됩니다. |
| `focused` | 포커스된 상태를 나타냅니다. `wrapper`에 적용됩니다. |
| `active` | 활성 상태를 나타냅니다. `wrapper`에 적용됩니다. |
| `indicator` | 트리 항목의 펼치기 표시기입니다. |
| `label` | 트리 항목의 콘텐츠입니다. |
| `text` | 트리 항목에 표시되는 텍스트입니다. |
| `select` | 선택이 활성화되었을 때의 트리 항목 체크박스입니다. |

이러한 CSS 파트를 사용하면 다음과 같이 <ApiLink pkg="core" type="Tree" /> 컴포넌트의 모양을 사용자 지정할 수 있습니다:

```css
igc-tree-item {
    --background-active: var(--ig-secondary-500);
    --foreground-active: var(--ig-secondary-500-contrast);
}
```
