# 가장 빠른 {Platform} 그리드

{ProductName}는 세계에서 가장 빠른 가상화 {Platform} 데이터 그리드를 포함하여, {Platform} 네이티브 Material 기반 UI 컴포넌트의 완전한 라이브러리를 제공합니다.


## {Platform} 그리드 예제

이 {Platform} 그리드 예제에서는 데이터 검색 및 필터링, 열 정렬, 크기 조정, 고정과 숨기기, 행 선택, Excel 및 CSV 내보내기, 가로 및 세로 스크롤 등 그리드에 내장된 다양한 기능을 활용하여 사용자가 _데이터 보기_를 어떻게 사용자 지정할 수 있는지 볼 수 있습니다. 선형 진행률 표시기와 스파크라인 같은 컴포넌트를 포함하는 셀 템플릿 예제도 제공합니다. 더 많은 기능은 이 [항목](#{PlatformLower}-그리드-기능)에서 확인하십시오.

## {Platform} 그리드란 무엇입니까?

{Platform} 데이터 그리드는 여러 행과 열로 된 표 형식의 데이터를 표시하는 데 사용되는 컴포넌트입니다. 테이블이라고도 하는 데이터 그리드는 Microsoft Excel 같은 인기 소프트웨어를 통해 데스크톱 세계에서 잘 알려져 있습니다. 그리드는 오랫동안 데스크톱 플랫폼에서 사용할 수 있었지만, 최근에는 {Platform} UI 같은 웹 앱 UI의 일부가 되었습니다. 최신 그리드는 복잡할 수 있으며, 데이터 바인딩, 편집, Excel 같은 필터링, 사용자 지정 정렬, 그룹화, 행 재정렬, 행과 열 고정, 행 집계, Excel, CSV, PDF 형식 내보내기 등 다양한 기능을 포함할 수 있습니다.


## 왜 {Platform} 그리드를 사용해야 할까요?

{Platform} 데이터 그리드는 대량의 데이터를 저장하고 빠르게 정렬해야 하는 사용 사례에서 필수적입니다. 여기에는 고용량, 고속 데이터를 자주 사용하는 금융이나 보험 같은 산업이 포함됩니다. 이런 기업의 성공은 종종 이러한 데이터 그리드의 기능과 성능에 달려 있습니다. 예를 들어 주식 결정을 마이크로초 단위로 내려야 할 때, 데이터 그리드가 지연이나 깜박임 없이 작동하는 것이 반드시 필요합니다.

### 데이터 가상화와 성능
데이터 그리드의 열 및 행 단위 가상화를 통해 {Platform} 그리드에서 무제한 행과 열을 끊김 없이 스크롤할 수 있습니다. 로컬 또는 원격 데이터 소스를 지원하므로, 데이터가 어디에 있든 최고의 성능을 얻을 수 있습니다. 사용자는 엔터프라이즈 수준의 속도로 Excel과 같은 스크롤을 경험하며, 지연, 화면 깜박임, 시각적 지연이 없습니다. 성능을 희생하지 않으면서 최고의 사용자 경험(UX)을 제공합니다.
