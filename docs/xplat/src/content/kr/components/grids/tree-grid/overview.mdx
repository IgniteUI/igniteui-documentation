# {Platform} 트리 그리드 개요 및 구성

{Platform} Tree Grid는 데이터 그리드(테이블)의 기능과 트리 뷰를 결합한 UI 컴포넌트로, 계층형 데이터를 표 형식으로 쉽게 표시할 수 있게 합니다. 일반 그리드와 달리 Tree Grid에서는 행을 펼치고 접을 수 있어, 상위 행 아래에 중첩된 하위 행을 드러낼 수 있습니다. 따라서 파일 탐색기, 조직도, 프로젝트 작업, 제품 카테고리와 같은 구조화된 데이터를 나타내는 데 유용합니다.

{ProductName} Tree Grid는 계층형 또는 평면 데이터를 쉽게 표시하고 조작하는 데 사용됩니다. 매우 적은 코드로 데이터를 빠르게 바인딩하거나, 다양한 이벤트를 사용하여 여러 동작을 사용자 지정할 수 있습니다. 이 컴포넌트는 데이터 선택, Excel 스타일 필터링, 정렬, 페이징, 템플릿화, 열 이동 등 풍부한 기능 세트를 제공합니다. Material Table 기반 UI Tree Grid 덕분에 테이블 형식 데이터를 표시하는 것이 그 어느 때보다 쉽고 아름다워졌습니다.

## 사용법

트리 그리드는 그리드와 많은 기능을 공유하지만, 데이터를 계층적으로 표시하는 기능도 추가로 제공합니다.
이를 위해 트리 그리드는 데이터 객체 사이의 관계를 정의하는 몇 가지 방법을 제공합니다. 모든 데이터 객체에 [하위 컬렉션](./overview.mdx#자식-컬렉션)을 사용하거나, 모든 데이터 객체에 [기본 키와 외래 키](./overview.mdx#기본-키-및-외래-키)를 사용하는 방법입니다.

### 트리 셀

트리 그리드의 계층을 구성하는 데 어떤 옵션(자식 컬렉션 또는 기본 키와 외래 키)을 사용하든, 트리 그리드의 행은 두 가지 유형의 셀로 구성됩니다:

- `GridCell` - 값을 포함하는 일반 셀입니다.
- `TreeGridCell` - 값, 펼치기/접기 표시기, 그리고 셀 행의 레벨에 따라 정해지는 들여쓰기 div 요소를 포함하는 트리 셀입니다. 행 컴포넌트의 레벨은 내부 `treeRow`의 `level` 속성을 통해 접근할 수 있습니다.

<DocsAside type="info">
각 행은 트리 셀을 하나만 가질 수 있지만, 일반 셀은 여러 개(또는 없음) 가질 수 있습니다.
</DocsAside>

### 초기 펼침 깊이

처음에 트리 그리드는 모든 노드 수준을 펼쳐서 보여 줍니다. 이 동작은 <ApiLink type="TreeGrid" member="expansionDepth" label="ExpansionDepth" /> 속성을 사용하여 구성할 수 있습니다. 기본값은 **Infinity**이며, 이는 모든 노드 수준이 펼쳐진다는 뜻입니다. 이 속성을 숫자 값으로 설정하여 초기 펼침 깊이를 제어할 수 있습니다. 예를 들어 **0**이면 루트 수준 노드만 표시되고, **1**이면 루트 수준 노드와 그 자식 노드가 표시되며, 이런 식입니다.

### 자식 컬렉션

하위 컬렉션 옵션을 사용하면 모든 데이터 객체에 하위 컬렉션이 포함되며, 이 컬렉션은 상위 데이터 객체와 같은 유형의 항목으로 채워집니다. 이렇게 하면 트리 그리드의 모든 레코드가 자신의 하위 항목에 직접 참조를 가집니다. 이 경우 원본 데이터 소스를 담고 있는 트리 그리드의 data 속성은 계층적으로 정의된 컬렉션이 됩니다.

### 기본 키 및 외래 키
**기본 키 및 외래 키** 옵션을 사용할 때, 모든 데이터 객체는 기본 키와 외래 키를 포함합니다. 기본 키는 현재 데이터 객체의 고유 식별자이며, 외래 키는 상위 객체의 고유 식별자입니다. 이 경우 원본 데이터 소스를 담고 있는 트리 그리드의 `data` 속성은 평면 컬렉션이 됩니다.

상위-자식 관계는 트리 그리드의 <ApiLink type="GridBaseDirective" member="primaryKey" label="PrimaryKey" /> 및 <ApiLink type="TreeGrid" member="foreignKey" label="ForeignKey" /> 속성을 사용하여 구성합니다.

## 유지와 통합

트리 그리드 셀의 들여쓰기는 필터링, 정렬, 페이징과 같은 다른 트리 그리드 기능에서도 유지됩니다.

- 열에 `Sorting`가 적용되면 데이터 행은 수준별로 정렬됩니다. 즉 루트 수준의 행은 각자의 하위 항목과 독립적으로 정렬됩니다. 각 하위 컬렉션도 독립적으로 정렬되며, 이는 계속 이어집니다.
- 첫 번째 열(<ApiLink type="Column" member="visibleIndex" label="VisibleIndex" />이 0인 열)은 항상 트리 열입니다.
- 열 고정, 열 숨기기, 열 이동 같은 작업 이후 <ApiLink type="Column" member="visibleIndex" label="VisibleIndex" />이 0이 되는 열이 트리 열이 됩니다.
- 내보낸 Excel 워크시트는 트리 그리드 자체에서 그룹화된 것과 같은 방식으로 레코드를 그룹화하여 계층을 반영합니다. 모든 레코드의 펼침 상태도 유지되어 반영됩니다.
- CSV로 내보내면 레벨과 펼침 상태는 무시되고 모든 데이터가 평면으로 내보내집니다.
