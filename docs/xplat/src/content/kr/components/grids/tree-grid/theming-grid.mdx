# 테마 {Platform} 그리드
{Platform} 테마 지정 CSS를 사용하면 {ProductName} 그리드를 브랜드 아이덴티티에 맞게 쉽게 사용자 지정할 수 있습니다.
미리 정의된 테마와 팔레트 외에도, 대체 CSS 사용자 지정 속성 세트를 사용하여 데이터 그리드의 모양과 느낌을 더 사용자 지정할 수 있습니다.

## 사용 가능한 테마 지정 속성

|------------------------------------------|--------------------------|----------------------------------------------------------------------------------------------|
| --grid-elevation                         | 0-24 사이의 숫자      | 그리드에 사용할 높이(elevation) 수준                                                 |
| --drag-elevation                         | 0-24 사이의 숫자      | 이동 가능한 요소(예: 열 머리글)에 사용할 높이(elevation) 수준                     |
| --grouparea-color                        | color                    | 그리드 그룹 영역의 텍스트 색상                                                               |

| --drop-area-background                   | color                    | 놓기 영역의 배경색                                                               |
