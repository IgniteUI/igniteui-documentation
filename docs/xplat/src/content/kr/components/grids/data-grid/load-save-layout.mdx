# {Platform} 그리드 레이아웃 불러오기 및 저장

{ProductName} 데이터 테이블/데이터 그리드는 그리드 레이아웃의 불러오기와 저장을 지원합니다. 이는 그리드의 `m:LoadLayout` 및 `m:SaveLayout` 메서드를 호출하여 수행합니다. 이 기능은 최종 사용자가 열을 이동, 정렬, 그룹화할 수 있고, 그리드의 상태를 보존하여 나중에 레이아웃을 복구하고 작업을 이어 가고 싶을 때 유용합니다.
