# {Platform} 실시간 데이터에서의 고성능

{ProductName} 데이터 테이블/데이터 그리드는 실시간 데이터 시나리오에서 고성능을 발휘하도록 최적화되어 있습니다. 빠른 로드 시간, 지연 없이 화면 깜박임 없는 부드러운 스크롤을 통해, 그리드의 열과 행을 완전히 가상화하여 {Platform} 데이터 그리드 애플리케이션에서 무제한 행과 열을 끊김 없이 스크롤할 수 있습니다.

## {Platform} 실시간 데이터에서의 고성능 예제

이 샘플은 수천 건의 금융 레코드를 {Platform} 데이터 그리드에 바인딩하고, 1개 열(예: Territory)로 그룹화하며, 여러 열을 몇 밀리초마다 실시간으로 업데이트하여 이러한 성능을 보여 줍니다. 실시간으로 다양한 옵션을 변경할 수 있으며, 데이터 그리드는 지연, 화면 깜박임, 시각적 지연 없이 성능을 유지합니다.
