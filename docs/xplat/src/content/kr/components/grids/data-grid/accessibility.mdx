## Section 508 준수
재활 법(Rehabilitation Act)의 <a href="https://www.section508.gov/" target="_blank">Section 508</a>은 1998년 미국 의회에서 개정되어, 모든 연방 기관이 전자 및 정보 기술을 장애인이 접근할 수 있도록 만들 것을 요구했습니다. 그 이후로 Section 508 준수는 정부 기관의 요건일 뿐만 아니라, 소프트웨어 솔루션을 제공하고 웹 페이지를 설계할 때도 중요합니다.

Section 508 법의 Section 1194.22는 웹 기반 인트라넷 및 인터넷 정보와 시스템을 구체적으로 다루며, 16개의 규칙 세트를 포함합니다. 웹 애플리케이션과 웹 사이트가 최소한의 노력으로 이 규칙을 준수할 수 있도록, Infragistics는 Ignite UI for Angular 컨트롤과 컴포넌트가 관련 접근성 규칙을 준수하도록 조치를 취했습니다.

## WAI-ARIA 지원
2014년 W3C는 장애가 있는 사용자가 웹 콘텐츠와 웹 애플리케이션에 더 쉽게 접근할 수 있도록 설계하는 방법을 정의한 <a href="https://www.w3.org/TR/wai-aria/" target="_blank">WAI-ARIA 명세</a>를 확정했습니다.

이 섹션은 프레임워크의 접근성(ARIA) 지원과, 컴포넌트의 방향성이 얼마나 쉽게 관리되는지를 보여 줍니다.

ARIA 속성
화면 읽기 프로그램이 그리드를 해석하고 상호 작용하는 데 필요한 문맥 정보를 제공하기 위해, 그리드 DOM 요소에 ARIA 속성이 추가됩니다. 이 속성은 div와 span 같은 일반 HTML 요소를 사용하여 복잡한 DOM 구조를 만들 때 특히 유용하며, ag-Grid의 경우도 그렇습니다.

그리드의 DOM 요소를 살펴보면 다음 역할과 속성이 지원되며 화면 읽기 프로그램이 이를 안내합니다:

- Grid Cell - 그리드 셀을 담고 있는 요소입니다.
- Row Count - 행의 개수를 알려 줍니다.
- Column Count - 열의 개수를 알려 줍니다(원문은 행 개수로 표기되어 있습니다).
- Row - 열 머리글 또는 그리드 셀의 행입니다.
- Row Index - 행의 보이는 인덱스를 알려 줍니다.
- Row Selected - 행을 선택할 수 있는 경우에만 나타나며, 선택 상태를 알려 줍니다.
- Group Expanded - 행 그룹에만 나타나며, 펼침 상태를 알려 줍니다.
- Column Header - 열 머리글을 담고 있는 요소입니다.
- Cell Index - 열의 보이는 인덱스를 알려 줍니다.
- Colspan - 열이 여러 열에 걸쳐 있는 경우에만 나타나며, 화면 읽기 프로그램을 안내하는 데 도움이 됩니다.
- Sort - 정렬 가능한 열에만 나타나며, 정렬 상태를 알려 줍니다.
- Column Index - 셀의 보이는 인덱스를 알려 줍니다.
- Selected - 셀을 선택할 수 있는 경우에만 나타나며, 선택 상태를 알려 줍니다.
- Expanded - 그룹 셀에만 나타나며, 펼침 상태를 알려 줍니다.

## 키보드 탐색

`UseAccessibility` 속성을 **true**로 설정하면, 화면 읽기 프로그램이 인식할 수 있는 다양한 키보드 탐색 옵션이 데이터 그리드에서 활성화됩니다. 아래는 각 키 입력/조합과 현재 활성화된 셀을 기준으로 한 효과에 대한 설명입니다:

그리드 내 탐색

- <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>→</kbd>: 한 셀 위로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>←</kbd>: 한 셀 왼쪽으로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>↓</kbd>: 한 셀 아래로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>↑</kbd>: 한 셀 위로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>HOME</kbd>: 첫 번째 열 머리글로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>END</kbd>: 마지막으로 보이는 셀로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>SHIFT</kbd> + <kbd>↑</kbd> 현재 열 머리글로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>SHIFT</kbd> + <kbd>↓</kbd> 현재 열의 마지막 셀로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>SHIFT</kbd> + <kbd>←</kbd> 현재 행의 첫 번째 셀로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>SHIFT</kbd> + <kbd>→</kbd> 현재 행의 마지막 셀로 이동합니다.

화면 읽기 프로그램 명령

- <kbd>CTRL</kbd> 또는 <kbd>ALT</kbd> + <kbd>숫자 키패드 5</kbd>: 현재 셀을 읽습니다.
- <kbd>INSERT</kbd> + <kbd>SHIFT</kbd> + <kbd>↑</kbd>: 현재 행을 읽습니다.
- <kbd>INSERT</kbd> + <kbd>SHIFT</kbd> + <kbd>HOME</kbd>: 행의 시작부터 읽습니다.
- <kbd>INSERT</kbd> + <kbd>SHIFT</kbd> + <kbd>PAGE UP</kbd>: 현재 셀부터 행의 끝까지 읽습니다.
- <kbd>INSERT</kbd> + <kbd>SHIFT</kbd> + <kbd>숫자 키패드 5</kbd>: 현재 열을 읽습니다.
- <kbd>INSERT</kbd> + <kbd>SHIFT</kbd> + <kbd>END</kbd>: 열의 맨 위부터 읽습니다.
- <kbd>INSERT</kbd> + <kbd>SHIFT</kbd> + <kbd>PAGE DOWN</kbd>: 열의 맨 아래까지 읽습니다.

## 코드 조각

다음은 {Platform} 데이터 그리드에서 셀 접근성을 구현하는 방법을 보여 줍니다:

<PlatformBlock for="React">

```tsx
<IgrDataGrid
    height="100%"
    width="100%"
    dataSource={this.data}
    useAccessibility="true" />
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-data-grid id="grid"
     height="100%"
     width="100%"
     use-accessibility="true">
</igc-data-grid>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<div style="--use-accessibility:true;">

        @if (DataSource != null)
        {
            <IgbDataGrid Height="100%" Width="100%" />
        }
</div>
```

</PlatformBlock>
