## 그룹화 영역

위 예제에서 보여 준 대로 DataGrid의 `IsGroupByAreaVisible` 속성을 True로 설정하여 사용자 인터페이스에 표시하십시오. 그룹화 영역을 사용하면 사용자는 DataGrid와 간접적으로 상호 작용하지 않고도 열을 그룹화하고 정렬하는 더 많은 옵션을 얻을 수 있습니다. 그룹은 사용자의 필요에 따라 위치를 정하고 순서를 다시 지정할 수 있습니다. 이 영역은 DataGrid의 `GroupDescriptions`로 열을 프로그래밍 방식으로 추가할 때도 채워집니다.

## 계층형 그룹

`GroupHeaderDisplayMode` 속성을 사용하면 그룹을 계층 구조로 만들 수 있습니다. 기본적으로 추가된 각 그룹 설명은 함께 집계됩니다. `GroupHeaderDisplayMode`를 `Split`로 설정하면 `DataGrid`의 `GroupDescriptions` 속성에 정의된 모든 그룹마다 섹션 머리글이 만들어집니다.


```json-snippet id="groupHeaderDisplayMode" source="/grids/data-grid/row-group-descriptions" channel="code"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "groupHeaderDisplayMode": "Split",
            "height": "100%",
            "width": "100%"
        }
    }
}
```

```json-snippet ref="groupHeaderDisplayMode" source="/grids/data-grid/row-group-descriptions"
```

## 접을 수 있는 그룹

또한 `DataGrid`는 각 그룹 섹션에 토글을 표시하여, 최종 사용자가 `IsGroupCollapsable` 속성을 통해 그룹화된 데이터를 펼치거나 접을 수 있도록 할 수 있습니다.

```json-snippet id="isGroupCollapsable" source="/grids/data-grid/row-grouping" channel="code"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "isGroupCollapsable": true,
            "height": "100%",
            "width": "100%"
        }
    }
}
```

```json-snippet ref="isGroupCollapsable" source="/grids/data-grid/row-grouping"
```

## 요약

편의를 위해 위의 모든 코드 조각을 하나의 코드 블록으로 합쳤으며, 프로젝트에 쉽게 복사할 수 있습니다.


```json-snippet id="groupingSummary" source="/grids/data-grid/row-group-descriptions" channel="code"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "isGroupCollapsable": true,
            "groupHeaderDisplayMode": "Split",
            "height": "100%",
            "width": "100%",
            "groupDescriptions": [
                {
                    "type": "ColumnGroupDescription",
                    "field": "Country",
                    "displayName": "Location",
                    "sortDirection": "Descending"
                },
                {
                    "type": "ColumnGroupDescription",
                    "field": "City",
                    "displayName": "City"
                },
                {
                    "type": "ColumnGroupDescription",
                    "field": "Income",
                    "displayName": "Income"
                }
            ]
        }
    }
}
```

```json-snippet ref="groupingSummary" source="/grids/data-grid/row-group-descriptions"
```
