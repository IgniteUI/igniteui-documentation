# {Platform} 그리드 열 선택기 개요

{ProductName} 데이터 그리드는 페이지의 어디에든 배치할 수 있는 유연성을 제공하는 `DataGridToolbar` 컴포넌트를 통해 UI로 열을 표시하고 숨길 수 있으며, 또는 `ColumnChooser` 컴포넌트를 통해서도 가능합니다. 열의 `IsHidden` 속성을 사용하여, 수동 열 생성을 위해 프로그래밍 방식으로 단일 열을 빠르게 숨기거나 표시할 수도 있으며, `IsHidden`의 값은 `ColumnChooser` 컴포넌트에 반영됩니다. 각 방식은 서로 바꿔 사용하여 열의 표시 상태를 바꿀 수 있습니다.

## 도구 모음의 열 선택기 UI

열 선택기 UI는 그리드와 별도로 `DataGridToolbar` 컴포넌트 안에서 사용할 수 있습니다. 이를 위해서는 도구 모음의 `ColumnChooser` 속성을 true로 설정하기만 하면 됩니다. 그러면 도구 모음에 `Button`이(가) 표시되며, 이를 클릭하면 열 선택기 UI가 나타납니다. 이 버튼에는 숨겨진 열의 총 개수도 표시됩니다. 도구 모음이 생성되지 않았다면 `ColumnChooser` 속성을 활성화해도 효과가 없고 버튼도 숨겨집니다.

`DataGridToolbar`은(는) 추가 속성을 제공합니다. `ToolbarTitle` 속성으로 도구 모음에 제목을 추가하고, `ColumnChooserText` 속성을 설정하여 `Button`에 텍스트를 배치하며, `ColumnChooserTitle`를 설정하여 열 선택기 UI에 제목 머리글을 추가할 수 있습니다.

그리드의 `ColumnHidingAnimationMode` 및 `ColumnShowingAnimationMode` 속성을 설정하여 열 선택기에 애니메이션을 구성할 수 있습니다.
