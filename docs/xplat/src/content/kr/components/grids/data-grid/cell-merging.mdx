# {Platform} 그리드 셀 병합

{ProductName} 데이터 테이블/데이터 그리드는 셀 병합을 지원합니다. 특정 열에서 인접한 형제 레코드가 같은 값을 가지고 있을 때 이를 감지하도록 선택적으로 설정할 수 있습니다. 셀이 활성, 선택 또는 편집 모드가 아닐 때는 값이 여러 셀에 걸쳐 표시됩니다.

## 개요

{Platform} 데이터 그리드의 셀 병합은 전체 {Platform} 그리드 또는 개별 열의 `MergedCellMode` 옵션을 사용하여 구성할 수 있습니다. 이 속성은 아래에 나열된 옵션 중 하나로 설정할 수 있습니다:

- `Never`: 그리드 또는 열은 셀을 절대 병합하지 않습니다. 이것이 기본 동작입니다.
- `Always`: 그리드 또는 열은 항상 셀 병합을 시도합니다.
- `OnlyWhenSorted`: 그리드 또는 열은 열이 정렬되어 있을 때에만 셀 병합을 시도합니다.

참고로, 이 속성의 값과 관계없이 셀은 형제 레코드 사이에서만 병합될 수 있습니다.

`MergedCellEvaluationCriteria` 속성을 사용하여 데이터가 서식이 지정되었는지 여부에 따라 셀 병합을 평가할 수 있습니다. 이는 전체 그리드 또는 개별 열에 적용되며, 아래에 나열된 옵션 중 하나로 설정할 수 있습니다:

- `RawValue`: 셀의 원시 값이 같을 때 인접한 행의 셀을 병합합니다. 이것이 기본값입니다.
- `FormattedText`: 셀의 서식이 지정된 값이 같을 때 인접한 행의 셀을 병합합니다.
