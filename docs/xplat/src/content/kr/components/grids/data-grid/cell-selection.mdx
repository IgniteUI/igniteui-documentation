## 개요

{Platform} 데이터 그리드의 선택은 행과 셀 수준에서 활성화되며, {Platform} 그리드의 `SelectionMode` 옵션을 사용하여 구성할 수 있습니다. 이 속성은 아래에 나열된 다섯 가지 옵션을 받습니다:

- `None`: 선택이 활성화되지 않습니다.
- `SingleCell`: 단일 셀 선택이 활성화됩니다.
- `SingleRow`: 단일 행 선택이 활성화됩니다.
- `MultipleCell`: 다중 셀 선택이 활성화됩니다.
- `MultipleRow`: 다중 행 선택이 활성화됩니다.
- `RangeCell`: 클릭하고 드래그하여 여러 셀의 범위를 선택하는 기능이 활성화됩니다.

`SelectionBehavior`의 기본값은 `ModifierBased`입니다. 이 모드에서는 한 번에 한 행 또는 한 셀만 선택되며, 항목을 여러 개 선택하려면 보조 키(CTRL)가 필요합니다. `SelectionBehavior`을(를) `Toggle`로 설정하면 한 번의 클릭만으로 여러 행 또는 셀을 선택할 수 있습니다.

`MultipleRow`에는 다음 기능이 포함됩니다:
- 클릭하고 드래그하여 행을 선택합니다
- <kbd>SHIFT</kbd>를 누른 상태에서 클릭하여 여러 행을 선택합니다.
- <kbd>SHIFT</kbd>를 누른 상태에서 <kbd>↑</kbd> + <kbd>↓</kbd> 화살표 키를 눌러 여러 행을 선택합니다.

스페이스 바를 누르면 `MultipleRow` 또는 `SingleRow`를 통해 활성 행의 선택이 토글됩니다.
