# {Platform} 그리드 열 크기 조정

{ProductName} 데이터 그리드는 열 크기를 조정하는 기능을 지원하며, 각 열의 너비와 관련하여 열을 표시하는 방식을 유연하게 정할 수 있습니다.

{ProductName} DataGrid의 열 크기 조정은 기본적으로 켜져 있으며, 그리드의 `ColumnResizingMode` 속성을 사용하여 제어할 수 있습니다. 이 속성에는 세 가지 옵션이 있으며, 각 옵션은 아래에 설명되어 있습니다:

- `Deferred`: 기본 옵션입니다. 크기를 조정할 때 구분선이 나타나 크기 조정 후 열이 얼마나 커지거나 작아질지 보여 줍니다.
- `Immediate`: 크기를 조정할 때 구분선이 없습니다. 열의 가장자리를 끌면 열의 너비가 포인터를 따라가며 그에 맞게 크기가 조정됩니다.
- `None`: 열의 크기를 조정할 수 없습니다.

열 크기 조정이 `Deferred`로 설정된 경우, 나타나는 구분선의 색상과 너비는 그리드의 `ColumnResizingSeparatorBackground` 및 `ColumnResizingSeparatorWidth` 속성을 사용하여 각각 수정할 수 있습니다.

크기 조정 모드가 `Deferred`로만 설정된 경우, 크기가 조정되는 동안 열에 애니메이션을 적용할 수도 있습니다. 이는 `ColumnResizingAnimationMode` 속성을 `Interpolate`로 설정하여 수행합니다.

그리드의 각 열은 개별적으로 크기를 조정할 수 있는지 여부를 정할 수 있습니다. 특정 열의 크기 조정을 활성화하거나 비활성화하려면 해당 열의 <b>IsResizingEnabled</b> 속성을 설정하면 됩니다.

별 너비(star-width) 열의 크기를 조정하면 그 열은 고정 너비 열로 바뀝니다.

## 코드 조각

다음 코드 조각은 {Platform} 데이터 그리드에서 열 크기 조정을 구현하는 방법을 보여 줍니다. 이 예에서 <b>Street</b> 열은 크기를 조정할 수 없습니다. 이 경우 열 크기 조정 구분선의 너비는 5픽셀이고, 크기를 조정할 수 있는 열은 크기가 조정될 때 애니메이션이 적용됩니다:

```json-snippet source="/grids/data-grid/column-resizing"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "autoGenerateColumns": false,
            "columnResizingMode": "Deferred",
            "columnResizingAnimationMode": "Interpolate",
            "columnResizingSeparatorWidth": 5,
            "height": "100%",
            "width": "100%",
            "columns": [
                {
                    "type": "TextColumn",
                    "field": "FirstName"
                },
                {
                    "type": "TextColumn",
                    "field": "LastName"
                },
                {
                    "type": "TextColumn",
                    "field": "Street",
                    "isResizingEnabled": false
                },
                {
                    "type": "TextColumn",
                    "field": "City"
                }
            ],
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
