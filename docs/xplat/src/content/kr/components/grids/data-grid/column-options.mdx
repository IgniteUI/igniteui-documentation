# {Platform} 그리드 열 옵션 개요

{ProductName} 데이터 그리드는 각 열 머리글에 노출된 UI에서 열을 직접 그룹화, 숨기기, 정렬, 이동, 고정, 필터링, 정렬할 수 있는 기능을 지원합니다.

열 옵션 UI를 활성화하려면 그리드의 `IsColumnOptionsEnabled` 속성을 true로 설정하면 됩니다.

## 열 옵션 구성

열의 `IsFilteringEnabled` 속성을 설정하면 열별로 필터링을 켜고 끌 수 있습니다. true 또는 false를 설정하면 열 옵션 UI의 필터링 섹션이 표시되거나 숨겨집니다.

`HeaderClickAction` 속성을 적용하면 그리드 전체에 대해 정렬을 켜고 끌 수 있습니다. 예를 들어 이를 `None`로 설정하면 그리드에서 정렬이 완전히 제거되고, 각 열의 옵션 UI에도 이것이 반영됩니다. 반면 예를 들어 `SortByOneColumnOnly`를 설정하면 한 번에 한 열만 정렬할 수 있도록 계속 허용합니다.

## 코드 조각

다음 코드는 그리드와 열을 조정하여 열 옵션 UI를 프로그래밍 방식으로 활성화하고, 열 옵션 UI에서 필터링과 정렬을 조정하는 방법을 보여 줍니다.

```json-snippet source="/grids/data-grid/column-options"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "ProductOrders",
            "headerClickAction": "SortByOneColumnOnly",
            "isColumnOptionsEnabled": true,
            "height": "100%",
            "width": "100%",
            "columns": [
                {
                    "type": "TextColumn",
                    "field": "ID",
                    "isFilteringEnabled": false
                }
            ],
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```

## API 참조

- `HeaderClickAction`
- `IsColumnOptionsEnabled`
- `IsFilteringEnabled`
- `SortByOneColumnOnly`
