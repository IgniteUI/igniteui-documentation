# {Platform} 그리드 열 고정 개요

{ProductName} 데이터 그리드는 열을 고정하는 기능을 지원하며, 최종 사용자가 열을 특정 열 순서에 고정할 수 있습니다.

하나 또는 여러 열을 데이터 그리드의 왼쪽 또는 오른쪽에 고정할 수 있습니다. 또한 `m:PinColumn` 함수를 사용하여 열의 고정 상태를 바꿀 수 있습니다.

데이터 그리드의 열 고정 API는 열의 `Pinned` 속성을 설정하거나, 그리드의 `m:PinColumn` 함수를 사용하여 설정하면 활성화할 수 있습니다.

`Pinned` 속성에는 세 가지 옵션이 있습니다:

- Left - `Left`을(를) 활성화하면 고정된 열이 그리드의 왼쪽에 배치됩니다.
- Right - `Right`을(를) 활성화하면 고정된 열이 그리드의 오른쪽에 배치됩니다.
- None - `None`을(를) 활성화하면 열의 고정이 해제되고 그리드 안의 기본 위치로 다시 배치됩니다.

고정된 열에 인접한 고정되지 않은 열은 여전히 가로 스크롤을 유지합니다.

`m:PinColumn` 함수는 필수 매개변수 두 개를 가집니다. 첫 번째 매개변수는 고정할 열이고, 두 번째 매개변수는 `PinnedPositions` 열거형 설정입니다.

## 도구 모음의 열 고정 UI

열 고정 UI는 그리드와 별도로 `DataGridToolbar` 컴포넌트 안에서 사용할 수 있습니다. 이를 위해서는 도구 모음의 `columnPinning` 속성을 true로 설정하기만 하면 됩니다. 그러면 도구 모음에 `Button`이(가) 표시되며, 이를 클릭하면 열 고정 UI가 나타납니다. 이 버튼에는 왼쪽에 고정된 열의 총 개수도 표시됩니다. 도구 모음이 생성되지 않았다면 `columnPinning` 속성을 활성화해도 효과가 없고 버튼도 숨겨집니다.

`DataGridToolbar`은(는) 추가 속성을 제공합니다. `ToolbarTitle` 속성으로 도구 모음에 제목을 추가하고, `columnPinningText` 속성을 설정하여 `Button`에 텍스트를 배치하며, `columnPinningTitle`를 설정하여 열 숨기기 UI에 제목 머리글을 추가할 수 있습니다.

            "dataSourceRef": "EmployeesSalesData",
            "autoGenerateColumns": false,

            "scrollbarStyle": "Thin",

            "width": "100%",

                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
