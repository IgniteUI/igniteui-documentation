# {Platform} 그리드 필터링 개요

{ProductName} 데이터 테이블/데이터 그리드는 필터 행과 API를 통한 열 필터링을 포함하며, 이를 통해 필터링되는 열의 데이터 형식에 따라 명확한 정렬 조건을 수행할 수 있습니다.

## 필터 연산자

열에는 필터 행 피연산자 드롭다운에 표시되는 사용자 지정 `FilterOperand`를 지정할 수 있습니다. 핵심 요구 사항은 피연산자에 `DisplayName`가 지정되어 있고, 피연산자의 `FilterRequested` 이벤트를 활용하여 열을 필터링할 연산자와 값을 할당하는 `FilterFactory`를 적용할 수 있도록 하는 것입니다(예: 값이 "A"인 StartsWith).

또한 그리드의 `FilterLogicalOperator` 속성은 필드 간 필터가 어떻게 결합되는지를 나타내는 역할을 합니다:

- `And` 논리 연산자입니다. 일치가 성공하려면 모든 조건을 통과해야 합니다.
- `Or` 논리 연산자입니다. 일치가 성공하려면 조건 중 하나 이상을 통과해야 합니다.
