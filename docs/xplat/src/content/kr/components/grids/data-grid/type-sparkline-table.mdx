# {Platform} 열 스파크라인

{ProductName} 데이터 테이블/데이터 그리드는 {ProductName} 스파크라인 컴포넌트와 같은 다른 컴포넌트를 내장할 수 있는 방법을 제공하는 템플릿 열을 지원합니다. `DataGrid` 컴포넌트에서 지원되는 다른 열 유형은 [열 유형](column-types.mdx) 항목을 참조하십시오.

## 코드 조각

다음 코드 예제는 `DataGrid` 컴포넌트의 `TemplateColumn`에 `Sparkline` 컴포넌트를 내장하는 방법을 보여 줍니다:

```json-snippet source="/charts/sparkline/grid"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "ProductsWithHistory",
            "autoGenerateColumns": false,
            "rowHeight": 90,
            "height": "100%",
            "width": "100%",
            "columns": [
                {
                    "type": "TextColumn",
                    "field": "ProductID",
                    "headerText": "ID",
                    "width": {
                        "type": "ColumnWidth",
                        "isStarSized": true,
                        "value": 1,
                        "minimumWidth": 110
                    },
                    "horizontalAlignment": "Center"
                },
                {
                    "type": "TextColumn",
                    "field": "ProductName",
                    "headerText": "Product",
                    "width": {
                        "type": "ColumnWidth",
                        "isStarSized": true,
                        "value": 1,
                        "minimumWidth": 140
                    }
                },
                {
                    "type": "NumericColumn",
                    "field": "ProductPrice",
                    "headerText": "Price",
                    "width": {
                        "type": "ColumnWidth",
                        "isStarSized": true,
                        "value": 1,
                        "minimumWidth": 110
                    },
                    "positivePrefix": "$",
                    "showGroupingSeparator": true,
                    "minFractionDigits": 2
                },
                {
                    "type": "TemplateColumn",
                    "field": "OrderHistory",
                    "headerText": "Order History",
                    "width": {
                        "type": "ColumnWidth",
                        "isStarSized": true,
                        "value": 1,
                        "minimumWidth": 180
                    },
                    "paddingTop": 10,
                    "paddingBottom": 10,
                    "templateRef": "DataGridSparklineTemplate"
                }
            ],
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
