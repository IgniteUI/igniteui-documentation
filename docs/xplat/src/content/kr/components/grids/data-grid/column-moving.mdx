# {Platform} 그리드 열 이동 개요

{ProductName} 데이터 그리드는 열을 이동하는 기능을 지원하므로, 표시되는 열의 순서와 관련하여 열을 표시하는 방식을 유연하게 설정할 수 있습니다.

{ProductName} 데이터 그리드의 열 이동은 기본적으로 켜져 있으며, 그리드의 `ColumnMovingMode` 속성을 설정하여 제어할 수 있습니다. 이 속성에는 `Deferred` 또는 `None`라는 두 가지 옵션이 있습니다. `Deferred`는 열 이동을 허용하며, `None`는 그리드 전체의 열 이동을 비활성화합니다.

열 이동이 `Deferred`로 설정되면, 열을 이동하는 동안 구분선이 나타납니다. 열을 이동하면서 마우스 포인터를 놓으면, 이동된 열은 구분선 오른쪽에 있던 열의 자리를 차지합니다. 이 구분선은 `ColumnMovingSeparatorWidth` 및 `ColumnMovingSeparatorBackground` 속성을 사용하여 각각 너비와 색상을 사용자 지정할 수도 있습니다.

원한다면 열 이동에 애니메이션을 적용할 수도 있습니다. 이는 그리드의 `ColumnMovingAnimationMode` 속성을 설정하여 할 수 있습니다. 애니메이션은 기본적으로 켜져 있지 않습니다.

## 코드 조각

다음은 지연된 열 이동, 애니메이션 활성화, 너비 5px의 구분선을 사용하여 {ProductName} 데이터 그리드에서 열 이동을 구현하는 방법을 보여 줍니다:

```json-snippet source="/grids/data-grid/column-moving"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "columnMovingMode": "Deferred",
            "columnMovingAnimationMode": "SlideOver",
            "columnMovingSeparatorWidth": 5,
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
