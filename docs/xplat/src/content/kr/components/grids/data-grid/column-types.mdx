# {Platform} 열 유형

{ProductName} 데이터 테이블/데이터 그리드는 5개의 열 유형과 템플릿 열 유형을 지원하여, {Platform} 데이터 그리드에서 데이터가 표시되는 방식을 완전히 유연하게 설정할 수 있습니다. 지원되는 열 유형은 텍스트 열, 숫자 열, 날짜/시간 열, 이미지 열, ComboBox 및 템플릿입니다.

각 열은 `Field` 속성을 {Platform} 데이터 그리드에 바인딩된 기반 데이터 소스 항목의 해당 속성 이름으로 설정하여 데이터에 바인딩됩니다.

## 텍스트 열

{Platform} 데이터 그리드는 연결된 셀에 서식이 지정된 텍스트를 표시하는 데 사용됩니다. 문자열 형식의 데이터를 표시하는 데 사용되는 기본 열 유형입니다.

## 숫자 열

`NumericColumn`은(는) 연결된 셀에 서식이 지정된 숫자 값을 표시하는 데 사용되며, 셀 안의 소수점 위치와 소수 자릿수 표시를 제어할 수 있습니다.

## 날짜/시간 열

`DateTimeColumn`은(는) 연결된 셀에 Date 객체를 표시하는 데 사용되며, Date 객체의 형식을 원하는 대로 지정할 수 있습니다.

## 이미지 열

`ImageColumn`은(는) 셀 안에 이미지를 표시하는 데 사용되며, `ImageStretchOption` 옵션을 사용하여 셀의 이미지 늘이기를 사용자 지정할 수 있는 옵션을 제공합니다.

`ImageResourceType` 옵션을 설정하여 이미지의 리소스 유형을 선택할 수도 있습니다.

## ComboBox 열

`ComboBoxColumn`은(는) 최종 사용자가 항목 하나를 선택할 수 있는 드롭다운 목록을 표시하는 데 사용됩니다.

열의 `DataSource` 속성을 통해 복합 객체 배열을 사용하여 데이터 바인딩을 수행할 수 있습니다.

`TextField` 속성은 사용자가 선택했을 때 표시되는 값을 결정합니다.

`ValueField` 속성은 선택된 기반 데이터 항목의 바인딩된 값을 결정합니다. 객체 목록에 속성이 여러 개 있는 경우 이것이 필요합니다.

## 템플릿 열

`TemplateColumn`은(는) 셀 템플릿과 함께 사용됩니다. 열의 셀에 사용자 지정 템플릿을 적용할 수 있게 해 줍니다. 이는 템플릿 열의 `CellUpdating` 이벤트를 처리하여 수행합니다.

`CellUpdating` 이벤트의 인수는 이벤트를 발생시킨 `TemplateColumn`와 `TemplateCellUpdatingEventArgs` 매개변수를 노출합니다. 이 이벤트 인수 매개변수는 `Content` 속성을 노출합니다. 이는 플랫폼에 따라 종류가 달라지는, 해당 열의 연결된 셀 안에 배치될 기본 컨테이너입니다. 그런 다음 이 컨테이너의 콘텐츠를 업데이트하거나 추가할 수 있습니다.

`TemplateCellUpdatingEventArgs`은(는) `CellInfo` 속성도 노출하며, 이를 사용하여 `TemplateCellInfo` 객체를 가져올 수 있습니다. 이 객체는 인덱스, 기반 데이터 항목, 셀의 모양 등 셀과 행에 대한 정보를 노출합니다.
