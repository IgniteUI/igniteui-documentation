# {Platform} 행 고정

 {ProductName} 데이터 테이블/데이터 그리드는 키 또는 기반 데이터 소스 항목을 사용하여 행 고정을 허용합니다. 행이 고정되면 {PlatformLower} 데이터 그리드의 맨 위에 복제되어 밝은 회색 배경과 함께 그 자리에 고정되며, 실제 행은 낮은 불투명도로 렌더링됩니다.
