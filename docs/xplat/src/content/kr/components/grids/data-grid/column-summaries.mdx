# {Platform} 열 요약

{ProductName} 데이터 테이블/데이터 그리드는 열 요약을 지원합니다. 경우에 따라 최종 사용자는 그리드에 표시되는 데이터의 양에 압도될 수 있으며, 종종 데이터의 요약을 찾고 싶어 합니다. 또한 최종 사용자는 특정 열의 데이터에서 추가 정보를 얻고 싶어 할 수도 있습니다. 요약은 최종 사용자가 이를 달성하도록 돕습니다. `SummaryScope` 속성을 설정하여 요약을 활성화할 수 있습니다.

## 요약 범위 속성

{Platform} 데이터 그리드는 `SummaryScope` 속성을 사용하여 구성할 수 있는 네 가지 요약 설정을 지원합니다. 아래에 나열되고 설명되어 있습니다:

- `Root`: 요약이 적용된 열에 대해 그리드의 모든 행에 대한 총합계를 표시합니다.
- `Groups`: 그룹화된 행에 특화되어 있으며, 특정 그룹의 모든 행에 대한 총합계를 표시합니다.
- `Both`: `Groups`와 `Root` 옵션을 동시에 사용합니다.
- `None`: 그리드의 요약을 비활성화합니다.

## 그룹 요약 표시 모드 속성

{Platform} 데이터 그리드는 요약이 표시되는 위치를 구성하는 것을 지원합니다. `GroupSummaryDisplayMode` 속성을 사용하여 이를 구성할 수 있습니다. 이 속성의 여러 옵션은 아래에 나열되고 설명되어 있습니다:

- **List**: 그룹 요약을 걸쳐 있는 그룹 머리글의 평면 목록으로 렌더링합니다.
- **Cells**: 그룹 머리글을 셀로 렌더링하며, 요약 값은 해당 열에 맞춰 셀 안에 렌더링됩니다. 이 옵션을 사용하면 그리드는 열당 하나의 요약만 표시합니다.
- **RowTop**: 그룹 요약을 그룹 위쪽의 요약 행으로 렌더링합니다.
- **RowBottom**: 그룹 요약을 그룹 아래쪽의 요약 행으로 렌더링합니다.
- **None**: 그룹 요약 렌더링을 비활성화합니다.
