# {Platform} 그리드 열 애니메이션

{ProductName} 데이터 테이블/데이터 그리드는 열 숨기기나 열 이동과 같은 이벤트 중에 열 애니메이션을 지원합니다. {Platform} 데이터 그리드의 열 애니메이션이 설정되면, 해당 열의 모든 셀에 대해 대응하는 애니메이션이 실행됩니다.

## 애니메이션 속성

각 열 애니메이션 속성은 아래에 나열되고 설명되어 있습니다:

- `ColumnAddingAnimationMode`: 열이 추가되면, 열 머리글과 그 셀이 왼쪽, 오른쪽, 위 또는 아래에서 슬라이드되어 들어오도록 선택할 수 있습니다. 페이드 인하거나, 슬라이드와 페이드 인을 함께 적용하는 옵션도 있습니다.
- `ColumnExchangingAnimationMode`: 열의 위치가 교환되면, 교환된 열 머리글과 그 셀이 왼쪽, 오른쪽, 위 또는 아래로 슬라이드되도록 선택할 수 있습니다. 페이드하거나, 슬라이드와 페이드를 함께 적용하는 옵션도 있습니다.
- `ColumnHidingAnimationMode`: 열이 숨겨지면, 열 머리글과 그 셀이 왼쪽, 오른쪽, 위 또는 아래로 슬라이드되어 나가도록 선택할 수 있습니다. 페이드 아웃하거나, 슬라이드와 페이드 아웃을 함께 적용하는 옵션도 있습니다.
- `ColumnMovingAnimationMode`: 열이 이동되면, 열 머리글과 그 셀이 옆으로 슬라이드되도록 선택할 수 있습니다.
- `ColumnPropertyUpdatingAnimationMode`: 열의 속성이 바뀌면, 그 속성의 변화가 보간 또는 깊은 보간을 통해 애니메이션되도록 선택할 수 있습니다.
- `ColumnShowingAnimationMode`: 열이 추가되면, 열 머리글과 그 셀이 왼쪽, 오른쪽, 위 또는 아래에서 슬라이드되어 들어오도록 선택할 수 있습니다. 페이드 인하거나, 슬라이드와 페이드 인을 함께 적용하는 옵션도 있습니다.

## 코드 조각

다음은 이 항목에서 설명한 각 열 애니메이션의 구현을 보여 줍니다:

```json-snippet source="/grids/data-grid/column-animation"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "columnAddingAnimationMode": "SlideFromLeft",
            "columnExchangingAnimationMode": "SlideToRight",
            "columnHidingAnimationMode": "SlideToTopAndFadeOut",
            "columnMovingAnimationMode": "SlideOver",
            "columnPropertyUpdatingAnimationMode": "Interpolate",
            "columnShowingAnimationMode": "SlideFromBottomAndFadeIn",
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
