# {Platform} 그리드 셀 활성화

{ProductName} 데이터 테이블/데이터 그리드는 그리드의 셀을 통한 키보드 탐색을 가능하게 하는 셀 활성화 기능을 지원합니다. 이는 그리드의 `ActivationMode` 속성을 `Cell`로 설정하면 활성화됩니다.

## Excel 스타일 탐색

`EnterBehaviorAfterEdit` 속성은 편집 모드에서 Enter 키를 누른 뒤 위, 아래, 왼쪽 또는 오른쪽의 다음 셀로 이동하도록 그리드를 구성합니다. 편집 모드가 아닐 때 다른 셀로 위, 아래, 왼쪽 또는 오른쪽으로 이동하려면 그리드의 `EnterBehavior` 속성을 사용할 수 있습니다.

## 키보드 탐색

그리드의 `ActivationMode` 속성을 `Cell`로 설정하면 데이터 그리드에서 다양한 키보드 탐색 옵션이 활성화됩니다. 아래는 각 키 입력/조합과 현재 활성화된 셀을 기준으로 한 효과에 대한 설명입니다:

- <kbd>↑</kbd>: 한 셀 위로 이동합니다.
- <kbd>↓</kbd>: 한 셀 아래로 이동합니다.
- <kbd>←</kbd>: 현재 행에서만 한 셀 왼쪽으로 이동합니다.
- <kbd>→</kbd>: 현재 행에서만 한 셀 오른쪽으로 이동합니다.
- <kbd>PAGE UP</kbd>: 그리드를 뷰포트 한 페이지만큼 위로 스크롤합니다.
- <kbd>PAGE DOWN</kbd>: 그리드를 뷰포트 한 페이지만큼 아래로 스크롤합니다.
- <kbd>TAB</kbd>: 활성 셀을 오른쪽의 다음 셀로 이동합니다. 행의 마지막 셀에 도달하면 다음 행의 가장 왼쪽 셀로 이동합니다.
- <kbd>SHIFT</kbd> + <kbd>TAB</kbd>: 활성 셀을 왼쪽의 다음 셀로 이동합니다. 행의 첫 번째 셀에 도달하면 이전 행의 가장 오른쪽 셀로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>↑</kbd>: 열의 맨 위 셀로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>↓</kbd>: 열의 맨 아래 셀로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>←</kbd>: 행의 가장 왼쪽 셀로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>→</kbd>: 행의 가장 오른쪽 셀로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>HOME</kbd>: 그리드의 왼쪽 위 셀로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>END</kbd>: 그리드의 오른쪽 아래 셀로 이동합니다.

## API 참조

- `ActivationMode`
- `Cell`
