# {Platform} 그리드 지역화

{ProductName} 데이터 테이블/데이터 그리드는 열 옵션 팝업과 요약에 특화된 리소스 문자열의 지역화를 지원합니다. 참고로, 이는 데이터를 번역하기 위한 것이 아니며 그럴 수도 없습니다.

<PlatformBlock for="Blazor">
데이터 그리드에는 열 옵션과 관련된 문자열을 지정하는 <ApiLink raw type="DataGrid" member="SetCustomizedStringAsync" />이(가) 포함되어 있습니다. 그리드의 `ActualDataSource` 속성에도 요약에 필요한 리소스 문자열을 지정하는 이 메서드가 있습니다.
</PlatformBlock>
