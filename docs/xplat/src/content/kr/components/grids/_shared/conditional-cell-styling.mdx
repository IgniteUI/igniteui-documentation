{Platform} {ComponentTitle}의 {ProductName} 조건부 스타일 지정 기능을 사용하면 행 또는 셀 수준에서 사용자 지정 스타일을 적용할 수 있습니다.  <ApiLink type="{ComponentName}" /> 조건부 스타일 지정 기능은 특정 조건을 충족하는 데이터를 시각적으로 강조하거나 두드러지게 표시하는 데 사용되며, 이를 통해 사용자는 그리드에서 중요한 정보나 추세를 더 쉽게 식별할 수 있습니다.

## {ComponentTitle} 조건부 행 스타일

{ProductName}의 <ApiLink type="{ComponentName}" /> 컴포넌트는 사용자 지정 규칙에 따라 행을 **조건부로 스타일 지정**하는 두 가지 방법을 제공합니다.

- <ApiLink type="{ComponentName}" /> 컴포넌트에 <ApiLink type="{ComponentName}" member="rowClasses" /> 입력을 설정하면;
- <ApiLink type="{ComponentName}" /> 컴포넌트에 <ApiLink type="{ComponentName}" member="rowStyles" /> 입력을 설정하면;

이 항목의 뒷부분에서 두 방법을 모두 더 자세히 다루겠습니다.

```ts
public ngOnInit() {
    this.data = athletesData;

        { field: 'Id' },
        { field: 'Position' },
        { field: 'Name' },
        { field: 'AthleteNumber' },
        { field: 'CountryName' }
    ];

    this.applyCSS();
}

public applyCSS() {
    this.columns.forEach((column, index) => {
        column.cellStyles = (index % 2 === 0 ? this.evenColStyles : this.oddColStyles);
    });
}

public updateCSS(css: string) {
    this.oddColStyles = {...this.oddColStyles, ...JSON.parse(css)};
    this.evenColStyles = {...this.evenColStyles, ...JSON.parse(css)};
    this.applyCSS();
}
```

## 알려진 문제와 제한 사항

- (서로 다른 열의) 같은 조건에 바인딩된 셀이 있고 그중 하나가 업데이트되면, 조건이 충족될 때 다른 셀은 새 값을 기준으로 업데이트되지 않습니다.

<PlatformBlock for="Angular, WebComponents">
나머지 셀에도 변경 사항을 적용하려면 확인 과정이 필요합니다. 아래 예제에서 이를 수행하는 방법을 보여 줍니다.

```ts
public backgroundClasses = {
    myBackground: (rowData: any, columnKey: string) => {
        return rowData.Col2 < 10;
    }
};

public editDone(evt) {
    this.Col1.cellClasses = {...this.backgroundClasses};
}
```

```html

  <igx-column field="Col1" dataType="number" [cellClasses]="backgroundClasses"></igx-column>
  <igx-column field="Col2" dataType="number" [editable]="true" [cellClasses]="backgroundClasses"></igx-column>
  <igx-column field="Col3" header="Col3" dataType="string" [cellClasses]="backgroundClasses"></igx-column>
</igx-grid>
```
