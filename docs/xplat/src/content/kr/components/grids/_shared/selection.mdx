{Platform} {ComponentTitle}의 {ProductName} 선택 기능을 사용하면 간단한 마우스 상호 작용으로 데이터와 쉽게 상호 작용하고 조작할 수 있습니다. 사용 가능한 선택 모드는 세 가지입니다:

- 행 선택
- 셀 선택

### {Platform} {ComponentTitle} 행 선택

<ApiLink type="{ComponentName}" member="rowSelection" /> 속성을 사용하면 다음 옵션을 지정할 수 있습니다:

- `None` - <ApiLink type="{ComponentName}" />에서는 행 선택이 비활성화됩니다.
- `Single` - <ApiLink type="{ComponentName}" /> 안에서 한 행만 선택할 수 있습니다.
- `Multiple` - <kbd>CTRL</kbd> + <kbd>클릭</kbd>과 같은 키 조합으로 행 선택기를 사용하거나, 셀에 포커스가 있을 때 <kbd>스페이스 키</kbd>를 한 번 누르면 여러 행을 선택할 수 있습니다.

<ComponentBlock for="TreeGrid, HierarchicalGrid">
- `MultipleCascade` - 사용자가 선택한 레코드 아래의 트리에 있는 모든 하위 항목이 선택되는 계단식 선택 모드입니다. 이 모드에서 상위 항목의 선택 상태는 전적으로 하위 항목의 선택 상태에 따라 결정됩니다.

</ComponentBlock>

> 자세한 내용은 [행 선택 주제](row-selection.mdx)로 이동하십시오.

### {Platform} {ComponentTitle} 셀 선택

<ApiLink type="{ComponentName}" member="cellSelection" /> 속성을 사용하면 다음 옵션을 지정할 수 있습니다:

- `None` - <ApiLink type="{ComponentName}" />에서는 셀 선택이 비활성화됩니다.
- `Single` - <ApiLink type="{ComponentName}" /> 안에서 한 셀만 선택할 수 있습니다.
- `Multiple` - 현재 <ApiLink type="{ComponentName}" />의 기본 선택 상태입니다. 마우스 왼쪽 버튼을 누른 상태로 셀 위를 드래그하면 다중 셀 선택이 가능합니다.

### {Platform} {ComponentTitle} 열 선택

<ApiLink type="Column" member="selectable" /> 속성을 사용하면 각 <ApiLink type="Column" />에 대해 다음 옵션을 지정할 수 있습니다. 이 속성을 true 또는 false로 설정하면 해당 열 선택이 각각 활성화되거나 비활성화됩니다.

이에 따라 다음 세 가지 변형이 있습니다:

- 단일 선택 - 열 셀 위에서 <kbd>마우스 클릭</kbd>.
- 다중 열 선택 - 열 셀 위에서 <kbd>CTRL</kbd> + <kbd>마우스 클릭</kbd>을 누른 상태로 유지합니다.
- 범위 열 선택 - <kbd>SHIFT</kbd> + <kbd>마우스 클릭</kbd>을 누르면 그 사이의 모든 항목이 선택됩니다.

## {Platform} {ComponentTitle} 컨텍스트 메뉴

<ApiLink type="{ComponentName}" member="contextMenu" /> 이벤트를 사용하면 <ApiLink type="{ComponentName}" />의 작업을 돕는 사용자 지정 컨텍스트 메뉴를 추가할 수 있습니다. 그리드 본문에서 **마우스 오른쪽 버튼**을 클릭하면, 이벤트는 이벤트가 발생한 셀을 전달합니다. **컨텍스트 메뉴**는 전달된 셀을 대상으로 동작합니다.

**다중 셀 선택**이 있으면, 선택된 셀이 다중 셀 선택 영역 안에 있는지 확인하는 로직을 두겠습니다. 그렇다면 선택된 셀들의 값도 발생시킵니다.

기본적으로 주 함수는 다음과 같습니다:

public rightClick(eventArgs: any) {
     // Prevent the default behavior of the right click
    eventArgs.event.preventDefault();
    this.multiCellArgs = {};
    // If we have multi-cell selection, check if selected cell is within the ranges
    if (this.multiCellSelection) {
        const node = eventArgs.cell.selectionNode;
        const isCellWithinRange = this.grid1.getSelectedRanges().some(range => {
            if (node.column >= range.columnStart &&
                node.column <= range.columnEnd &&
                node.row >= range.rowStart &&
                node.row <= range.rowEnd) {
                return true;
            }
            return false;
        })
        // If the cell is within a multi-cell selection range, bind all the selected cells data
        if (isCellWithinRange) {
            this.multiCellArgs = { data: this.multiCellSelection.data };
        }
    }
    // Set the position of the context menu
    this.contextmenuX = eventArgs.event.clientX;
    this.contextmenuY = eventArgs.event.clientY;
    this.clickedCell = eventArgs.cell;
    // Enable the context menu
    this.contextmenu = true;
}

컨텍스트 메뉴에는 다음 기능이 있습니다:

- 선택한 셀의 _값_을 복사합니다.
- 선택한 셀의 _dataRow_를 복사합니다.
- 선택한 셀이 **다중 셀 선택 범위** 안에 있다면, 모든 _선택된 데이터_를 복사합니다.

public copySelectedCellData(event) {
    const selectedData = { [this.cell.column.field]: this.cell.value };
    this.copyData(JSON.stringify({ [this.cell.column.field]: this.cell.value }));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copyRowData(event) {
    const selectedData = this.cell.row.data ;
    this.copyData(JSON.stringify(this.cell.row.data));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copySelectedCells(event) {
    const selectedData = this.selectedCells.data;
    this.copyData(JSON.stringify(selectedData));
    this.onCellValueCopy.emit({ data: selectedData });
}

    private copyData(data: any[]) {
        const tempElement = document.createElement('input');
        document.body.appendChild(tempElement);
        tempElement.setAttribute('id', 'temp_id');
        (document.getElementById('temp_id') as HTMLInputElement).value = JSON.stringify(data);
        tempElement.select();
        document.execCommand('copy');
        document.body.removeChild(tempElement);
    }

## 알려진 문제와 제한 사항

<PlatformBlock for="Angular">
- 선택 기능이 활성화된 <ApiLink type="{ComponentName}" />를 IE11에서 사용하려면, {Platform} 애플리케이션의 polyfill.ts에서 배열 폴리필을 명시적으로 import해야 합니다. IE11은 13.0.0 버전부터 더 이상 지원되지 않습니다.

```typescript
import "core-js/es7/array";
```

그리드에 <ApiLink type="{ComponentName}" member="primaryKey" />이(가) 설정되어 있지 않고 원격 데이터 시나리오가 활성화되어 있으면(페이징, 정렬, 필터링, 스크롤이 표시할 데이터를 가져오기 위해 원격 서버에 요청을 트리거할 때), 데이터 요청이 완료된 후 행은 다음 상태를 잃게 됩니다:

- 행 선택
- 행 펼치기/접기
