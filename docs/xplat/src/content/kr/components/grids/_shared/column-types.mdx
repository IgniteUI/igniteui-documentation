## {Platform} {ComponentTitle} 기본 템플릿

데이터 유형별 템플릿을 활성화하려면 열의 <ApiLink type="Column" member="dataType" /> 입력을 설정해야 합니다. 그렇지 않으면 열 <ApiLink type="Column" member="dataType" />의 기본값이 문자열이므로 문자열 열로 처리됩니다.

다음 섹션에서는 각 <ApiLink type="Column" member="dataType" />의 기본 템플릿을 설명합니다.

### 문자열

이 열 <ApiLink type="Column" member="dataType" />은(는) 셀 값의 모양이나 형식을 바꾸지 않습니다.

### Number

<ApiLink type="Column" member="dataType" />이(가) **숫자**로 설정되면, 셀 값은 애플리케이션 또는 그리드의 <ApiLink pkg="core" type="DatePicker" member="locale" label="Locale" /> 설정과 <ApiLink type="Column" member="pipeArgs" /> 속성이 지정된 경우 그것을 기준으로 형식이 지정됩니다. 그러면 숫자 형식은 이들을 기준으로 바뀌며, 예를 들어 다음이 바뀔 수 있습니다:

- 소수점 이하 자릿수
- `,` 또는 `.`가 있는 소수점 구분 기호

### DateTime, Date 및 Time

날짜 부분(예: 일, 월, 연도)의 모양은 <ApiLink pkg="core" type="DatePicker" member="locale" label="Locale" /> 형식 또는 <ApiLink type="Column" member="pipeArgs" /> 입력을 기준으로 설정됩니다. 파이프 인수를 사용하여 사용자 지정 날짜 형식이나 시간대를 지정할 수 있습니다:

- **format** - 날짜 형식의 기본값은 `'mediumDate'`입니다. 다른 사용 가능한 옵션은 `'short'`, `'long'`, `'shortDate'`, `'fullDate'`, `'longTime'`, `'fullTime'` 등입니다.
- **timezone** - 기본값은 사용자의 로컬 시스템 시간대입니다. 시간대 오프셋 또는 표준 GMT/UTC나 대륙별 미국 시간대 약어도 전달할 수 있습니다. 세계 어디에서든 해당 위치의 시간을 표시하는 다양한 시간대 예는 다음과 같습니다:

#### 셀 편집

열 유형에 따라 셀 편집을 할 때 서로 다른 편집기가 나타납니다:
- `DateTime` - <ApiLink pkg="core" type="DatePicker" />가 사용됩니다. 이 편집기는 `DateTime` 객체의 일부인 입력 요소에 대한 마스크 안내를 제공합니다.
- `Date` - <ApiLink pkg="core" type="DatePicker" />가 사용됩니다.
- `Time` - <ApiLink pkg="core" type="DateTimeInput" />가 사용됩니다.

#### 필터링

빠른 필터링/Excel 스타일 필터링의 경우에도 위에 나열된 것과 같은 편집기가 사용됩니다. 각 유형이 노출하는 필터링 연산자는 다음과 같습니다:
- `DateTime` 및 `Date` - 같음, 같지 않음, 이전, 이후, 오늘, 어제, 이번 달, 지난달, 다음 달, 올해, 작년, 내년, 비어 있음, 비어 있지 않음, Null, Null 아님;
- `Time` - 일치, 일치하지 않음, 이전, 이후, 이전 또는 일치, 이후 또는 일치, 비어 있음, 비어 있지 않음, Null, Null 아님;

#### 요약

사용 가능한 요약 연산자는 **Count**, **Earliest**(날짜/시간) 및 **Latest**(날짜/시간)입니다.

#### 정렬

- `Time`: 열은 객체의 시간 부분을 기준으로 정렬되며, 밀리초는 무시됩니다.
- `Date`: 열은 날짜 부분을 기준으로 정렬되며, 시간 부분은 무시됩니다.
- `DateTime`: 열은 전체 날짜를 기준으로 정렬됩니다.

### 이미지

기본 템플릿은 데이터에서 가져온 값을 기본 이미지 템플릿의 이미지 소스로 사용합니다. 기본 이미지 템플릿은 이미지 파일의 이름을 추출하여 접근성 요구 사항을 충족하도록 이미지의 `alt` 속성으로 설정합니다. 표시되는 셀 크기는 렌더링되는 이미지의 크기에 맞게 조정되므로, 큰 이미지도 여전히 렌더링되며 그리드 행은 이미지 열의 이미지만큼 커진다는 점을 기억하십시오. 이미지 유형 열에서는 필터링, 정렬, 그룹화가 기본적으로 꺼져 있습니다. 이들을 활성화하려면 데이터 작업을 수행하는 사용자 지정 전략을 제공해야 합니다.

### 백분율

기본 템플릿은 기본 숫자 값에 해당하는 백분율을 표시합니다. 표시되는 셀 값은 표시 계수 '100'을 곱한 결과입니다. 예를 들어 기본 계수가 100이고 셀에 전달된 "값"이 0.123이면, 표시되는 셀 값은 "12.3%"가 됩니다.

셀 편집의 경우 값은 데이터 소스 값과 같으며 표시 계수는 '1'입니다. 셀을 편집하는 동안에는 백분율 값의 미리 보기가 접미사 요소로 표시됩니다. 예를 들어 '0.0547'을 편집하는 동안 미리 보기 요소에는 '5.47%'가 표시됩니다.

<PlatformBlock for="Angular">
```ts
public options = {
    /**
    * Decimal representation options, specified by a string in the following format:
    * `{minIntegerDigits}`.`{minFractionDigits}`-`{maxFractionDigits}`.
    * `minIntegerDigits`: The minimum number of integer digits before the decimal point. Default is 1.
    * `minFractionDigits`: The minimum number of digits after the decimal point. Default is 0.
    * `maxFractionDigits`: The maximum number of digits after the decimal point. Default is 3.
    */
    digitsInfo: '2.2-3'
};
public formatPercentOptions = this.options;
```

</PlatformBlock>
