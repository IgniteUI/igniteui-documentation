# 연쇄 콤보가 있는 {Platform} {ComponentTitle}

{ComponentTitle}의 편집 기능은 연쇄 콤보박스 컴포넌트를 사용할 기회를 제공합니다. 앞의 <ApiLink type="Combo" />에서 값을 선택하면, 사용자는 다음 {Platform} 콤보박스 컴포넌트에서 자신의 선택과 관련된 데이터만 받게 됩니다.

## 연쇄 콤보가 있는 {Platform} {ComponentTitle} 샘플 개요

아래 샘플은 <ApiLink type="{ComponentName}" />가 중첩된 연쇄 <ApiLink type="Combo" /> 컴포넌트와 어떻게 작동하는지 보여 줍니다.

- <ApiLink type="Combo" member="displayKey" /> - 객체 배열에 필요합니다. 항목의 텍스트로 사용할 속성을 지정합니다. <ApiLink type="Combo" member="displayKey" />에 값이 지정되지 않으면, 콤보는 지정된 <ApiLink type="Combo" member="valueKey" />(있는 경우)를 사용합니다.

선택 변경을 처리하려면 change 이벤트가 필요합니다. 발생한 이벤트 인수에는 변경 전 선택, 현재 선택, 추가되거나 제거된 항목에 대한 정보가 들어 있습니다. 따라서 이전 콤보의 선택을 기준으로 값을 필터링합니다.

    const onCountryChange = (rowId: string, event: CustomEvent) => {
        const regionCombo = getComboRef(`region_${rowId}`).current;
        const cityCombo = getComboRef(`city_${rowId}`).current;
        const regions = regions;
        const newValue = event.detail.newValue[0];

        if (newValue === undefined) {
            regionCombo.deselect(regionCombo.value);

            regionCombo.data = [];

            cityCombo.deselect(regionCombo.value);
            cityCombo.disabled = true;
            cityCombo.data = [];

            regionCombo.data = regions.filter(x => x.Country === newValue);

            cityCombo.deselect(cityCombo.value);
            cityCombo.disabled = true;
            cityCombo.data = [];
        }
    }

그다음 템플릿에서 콤보의 `SimpleCombo`을(를) 일부 데이터에 바인딩해야 합니다.

- `displayKey` - 객체 배열에 필요합니다. 항목의 텍스트로 사용할 속성을 지정합니다. `displayKey`에 값이 지정되지 않으면, 단순 콤보박스는 지정된 `valueKey`(있는 경우)를 사용합니다.

```typescript
export class MySimpleComboComponent implements OnInit {
    public countriesData: Country[];
    public selectedCountry: Country;
    public selectedCity: City;

    public ngOnInit() {
        this.countriesData = getCountries([
            'United States',
            'Japan',
            'United Kingdom'
        ]);
    }
}
```

선택 변경을 처리하려면 `selectionChanging`이(가) 필요합니다. 발생하는 이벤트 인수 `IComboSelectionChangingEventArgs`에는 변경 전 선택, 현재 선택, 추가되거나 제거된 항목에 대한 정보가 들어 있습니다. 따라서 이전 콤보의 선택을 기준으로 값을 필터링합니다.

```html
<igx-combo [data]="countriesData" (selectionChanging)="countryChanging($event)"></igx-combo>
```

```typescript
public countryChanging(event: IComboSelectionChangeEventArgs) {
    if (event.added.length) {
        event.newSelection = event.added;
    }
}
```

## 알려진 문제와 제한 사항

|제한 사항|설명|
|--- |--- |
| 콤보 드롭다운 목록이 다른 UI 요소 뒤에 숨을 수 있습니다. | 그리드 안 요소의 쌓임 순서 때문에, 콤보 드롭다운이 머리글, 바닥글 등 다른 요소 뒤에 숨을 수 있습니다. |
