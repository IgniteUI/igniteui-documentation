{Platform} {ComponentTitle}는 Excel 같은 필터링 UI를 제공하는 Excel 스타일 필터링 기능을 노출합니다. 대용량 데이터 세트를 다루는 과정을 단순화합니다. 핵심 아이디어는 가장 관련성 높은 데이터를 필터링하고, 관련 없는 항목을 제외하도록 돕는 것입니다.

## 상호 작용

특정 열의 필터 메뉴를 열려면 머리글의 {Platform} 필터 아이콘을 클릭해야 합니다. 또한 선택한 머리글에서 <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>L</kbd> 조합을 사용할 수도 있습니다. 필터링과 함께 열을 정렬, 고정, 이동, 선택 또는 숨길 수 있다면, 활성화된 기능에 대한 버튼이 나타납니다.

필터가 적용되지 않은 경우 목록의 모든 항목이 선택됩니다. 목록 위의 입력란에서 항목을 필터링할 수 있습니다. 데이터를 필터링하려면 목록에서 항목을 선택하거나 선택 해제한 다음, 적용 버튼을 클릭하거나 <kbd>ENTER</kbd>를 누르십시오. 목록 항목을 통한 필터링은 `equals` 연산자를 사용하는 필터 식을 만들며, 식 사이의 논리 연산자는 `OR`입니다.

검색 상자에 무언가를 입력하고 필터를 적용하면 검색 조건과 일치하는 항목만 선택됩니다. 하지만 현재 필터링된 항목에 항목을 추가하려면 **현재 선택 항목을 필터에 추가** 옵션을 선택해야 합니다.

필터를 지우려면 **모두 선택** 옵션을 선택한 다음 적용 버튼을 클릭하면 됩니다.

다른 식으로 필터를 적용하려면 **텍스트 필터**를 클릭하면 됩니다. 그러면 해당 열에서 사용할 수 있는 모든 필터 연산자가 있는 하위 메뉴가 열립니다. 그중 하나를 선택하면 사용자 지정 필터 대화 상자가 열리며, 여기서 서로 다른 필터 및 논리 연산자로 원하는 만큼 많은 식을 추가할 수 있습니다. 필터를 지울 수 있는 지우기 버튼도 있습니다.

## 템플릿

<PlatformBlock for="Angular">
열 기능을 비활성화하지 않고 Excel 스타일 필터 메뉴를 더 사용자 지정하려면 사용자 지정 템플릿을 사용할 수 있습니다. Excel 스타일 필터 메뉴는 템플릿화를 위한 두 가지 디렉티브를 제공합니다:
- `IgxExcelStyleColumnOperationsTemplateDirective` - 정렬, 고정 등 모든 열 작업이 있는 영역을 다시 템플릿화합니다.
- `IgxExcelStyleFilterOperationsTemplateDirective` - 모든 필터 전용 작업이 있는 영역을 다시 템플릿화합니다.

이 영역 중 하나만 다시 템플릿화하거나 둘 다 다시 템플릿화할 수 있습니다. 이 디렉티브 안에 사용자 지정 콘텐츠를 넣을 수도 있고, 우리의 내장 Excel 스타일 필터링 컴포넌트 중 어느 것이든 사용할 수도 있습니다.

다음 코드는 `excel-style-header`, `excel-style-sorting` 및 `excel-style-search` 컴포넌트를 사용하여 사용자 지정 Excel 스타일 필터 메뉴를 정의하는 방법을 보여 줍니다.

</PlatformBlock>

## 외부 아웃레트

{ComponentTitle}의 [z-index](https://developer.mozilla.org/en-US/docs/Web/CSS/z-index)는 DOM에서 각 그리드마다 별도의 쌓임 맥락(stacking context)을 만듭니다. 이를 통해 그리드의 모든 하위 요소가 서로 겹치지 않고 의도한 대로 렌더링됩니다.
하지만 그리드 바깥으로 나가는 요소(예: Excel 스타일 필터)는 같은 `z-index`를 가진 외부 요소(예: 그리드 두 개가 위아래로 놓인 경우)와 충돌하여 잘못 렌더링될 수 있습니다. 이 문제의 해결책은 `Outlet` 속성을 외부 아웃렛 디렉티브로 설정하는 것이며, 이렇게 하면 오버레이 요소가 항상 맨 위에 표시됩니다.

## 스타일링

Excel 스타일 필터링 대화 상자의 스타일 지정을 시작하려면, 모든 테마 함수와 컴포넌트 믹스인이 있는 `index` 파일을 import해야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

Excel 스타일 필터링 대화 상자는 `filtering-row-background` 매개변수를 사용하여 그리드의 테마에서 배경색을 가져옵니다. 배경을 바꾸려면 사용자 지정 테마를 만들어야 합니다:

```scss
$custom-grid: grid-theme(
    $filtering-row-background: #FFCD0F
);
```

Excel 같은 필터링 대화 상자 안에는 버튼, 체크박스, 목록, 드롭다운 등 훨씬 더 많은 컴포넌트가 있습니다. 이들의 스타일을 지정하려면 각각에 대해 별도의 테마를 만들어야 합니다:

```scss
$dark-button: flat-button-theme(
    $background: #FFCD0F,
    $foreground: #292826,
    $hover-background: #292826,
    $hover-foreground: #FFCD0F
);

$dark-input-group: input-group-theme(
    $box-background: #FFCD0F,
    $idle-text-color: #292826,
    $focused-text-color: #292826,
    $filled-text-color: #292826
);

$custom-list: list-theme(
    $background: #FFCD0F
);

$custom-checkbox: checkbox-theme(
    $empty-color: #292826,
    $fill-color: #292826,
    $tick-color: #FFCD0F,
    $label-color: #292826
);

$custom-drop-down: drop-down-theme(
    $background-color: #FFCD0F,
    $item-text-color: #292826,
    $hover-item-background: #292826,
    $hover-item-text-color: #FFCD0F
);
```

이 예제에서는 나열된 컴포넌트의 일부 매개변수만 바꿨지만, <ApiLink type="function-flat-button-theme" label="flat-button-theme" kind="sass" module="index.html" />, <ApiLink type="function-checkbox-theme" label="checkbox-theme" kind="sass" module="index.html" />, <ApiLink type="function-drop-down-theme" label="drop-down-theme" kind="sass" module="index.html" />, <ApiLink type="function-input-group-theme" label="input-group-theme" kind="sass" module="index.html" />, <ApiLink type="function-list-theme" label="list-theme" kind="sass" module="index.html" /> 테마는 각 스타일을 제어하는 훨씬 많은 매개변수를 제공합니다.

마지막 단계는 각 컴포넌트 믹스인을 해당 테마와 함께 **include**하는 것입니다. 또한 입력란의 플레이스홀더 색상 속성도 설정합니다.

```scss
@include drop-down($custom-drop-down);
@include grid($custom-grid);
.igx-excel-filter, .igx-excel-filter__secondary {
    @include button($dark-button);
    @include input-group($dark-input-group);
    @include list($custom-list);
    @include checkbox($custom-checkbox);
    .igx-input-group__input::placeholder {
        color: #FFCD0F;
    }
}
```

<DocsAside type="info">
대부분의 컴포넌트 믹스인은 `.igx-excel-filter`와 `.igx-excel-filter__secondary` 안에 범위를 지정합니다. 이렇게 하면 이 사용자 지정 테마는 Excel 스타일 필터링 대화 상자와 그 하위 대화 상자 전체에 중첩된 컴포넌트에만 영향을 줍니다. 그렇지 않으면 다른 버튼, 체크박스, 입력 그룹, 목록도 영향을 받게 됩니다.
</DocsAside>

<DocsAside type="info">
컴포넌트가 [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, `::ng-deep`를 사용하여 이 캡슐화를 `penetrate`해야 합니다:
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include drop-down($custom-drop-down);
        @include grid($custom-grid);
        .igx-excel-filter, .igx-excel-filter__secondary {
            @include button($dark-button);
            @include input-group($dark-input-group);
            @include list($custom-list);
            @include checkbox($custom-checkbox);
            .igx-input-group__input::placeholder {
                color: #FFCD0F;
            }
        }
    }
}
```

### 색상 팔레트 정의하기

방금 한 것처럼 색상 값을 하드코딩하는 대신, <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" />와 <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" /> 함수를 사용하면 색상에 대해 더 큰 유연성을 얻을 수 있습니다.

`igx-palette`는 전달된 기본 색상과 보조 색상을 기준으로 색상 팔레트를 생성합니다:

```scss
$yellow-color: #FFCD0F;
$black-color: #292826;

$dark-palette: palette($primary: $black-color, $secondary: $yellow-color);
```

그다음 <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />로 팔레트에서 색상을 쉽게 가져올 수 있습니다.

```scss
$custom-grid: grid-theme(
    $filtering-row-background: #FFCD0F

$dark-button: flat-button-theme(
    $background: color($dark-palette, "secondary", 400),
    $foreground: color($dark-palette, "primary", 400),

    $hover-foreground: color($dark-palette, "secondary", 400)
);

$dark-input-group: input-group-theme(
    $box-background: color($dark-palette, "secondary", 400),
    $idle-text-color: color($dark-palette, "primary", 400),
    $focused-text-color: color($dark-palette, "primary", 400),
    $filled-text-color: color($dark-palette, "primary", 400)
);

$custom-list: list-theme(
    $background: color($dark-palette, "secondary", 400)
);

$custom-checkbox: checkbox-theme(
    $empty-color: color($dark-palette, "primary", 400),
    $fill-color: color($dark-palette, "primary", 400),
    $tick-color: color($dark-palette, "secondary", 400),
    $label-color: color($dark-palette, "primary", 400)
);

$custom-drop-down:drop-down-theme(
    $background-color: color($dark-palette, "secondary", 400),
    $item-text-color: color($dark-palette, "primary", 400),
    $hover-item-background: color($dark-palette, "primary", 400),
    $hover-item-text-color: color($dark-palette, "secondary", 400)
);
```

<DocsAside type="info">
`igx-color`와 `igx-palette`는 색상을 생성하고 가져오는 강력한 함수입니다. 사용 방법에 대한 자세한 안내는 [팔레트](../themes/sass/palettes.mdx) 항목을 참조하십시오.
</DocsAside>

### 스키마 사용하기

테마 엔진을 더 활용하여 [**스키마**](../themes/sass/schemas.mdx)의 이점을 얻는 견고하고 유연한 구조를 만들 수 있습니다. **스키마**는 테마의 레시피입니다.

모든 컴포넌트에 제공되는 두 가지 사전 정의된 스키마 중 하나를 확장하십시오. 이 경우 <ApiLink type="variable-_light-grid" label="light-grid" kind="sass" module="index.html" />, <ApiLink type="variable-_light-input-group" label="light-input-group" kind="sass" module="index.html" />, <ApiLink type="variable-_light-button" label="light-button" kind="sass" module="index.html" />, <ApiLink type="variable-_light-list" label="light-list" kind="sass" module="index.html" />, <ApiLink type="variable-_light-checkbox" label="light-checkbox" kind="sass" module="index.html" />, <ApiLink type="variable-_light-drop-down" label="light-drop-down" kind="sass" module="index.html" /> 스키마입니다:

```scss
$custom-grid-schema: extend($_light-grid,
    (
        filtering-row-background:(
           color: ("secondary", 400)
        )
    )
);

$custom-button-schema: extend($_light-button,
    (
        flat-background:(
           color: ("secondary", 400)
        ),
        flat-text-color:(
           color: ("primary", 400)
        ),
        flat-hover-background:(
           color: ("primary", 400)
        ),
        flat-hover-text-color:(
           color: ("secondary", 400)
        ),

        raised-background:(
           color: ("secondary", 400)
        ),
        raised-text-color:(
           color: ("primary", 400)
        ),
        raised-hover-background:(
           color: ("primary", 400)
        ),
        raised-hover-text-color:(
           color: ("secondary", 400)
        )
    )
);

$custom-input-group-schema: extend($_light-input-group,
    (
        box-background:(
           color: ("secondary", 400)
        ),
        idle-text-color:(
           color: ("primary", 400)
        ),
        focused-text-color:(
           color: ("primary", 400)
        ),
        filled-text-color:(
           color: ("primary", 400)
        )
    )
);

$custom-list-schema: extend($_light-list,
    (
        background:(
           color: ("secondary", 400)
        )
    )
);

$custom-checkbox-schema: extend($_light-checkbox,
    (
        empty-color:(
           color: ("primary", 400)
        ),
        fill-color:(
           color: ("primary", 400)
        ),
        tick-color:(
           color: ("secondary", 400)
        ),
        label-color:(
           color: ("primary", 400)
        )
    )
);

$custom-drop-down-schema: extend($_light-drop-down,
    (
        background-color:(
           color: ("secondary", 400)
        ),
        item-text-color:(
           color: ("primary", 400)
        ),
        hover-item-background:(
           color: ("primary", 400)
        ),
        hover-item-text-color:(
           color: ("secondary", 400)
        )
    )
);
```

사용자 지정 스키마를 적용하려면 전역(<ApiLink type="variable-light-schema" label="light" kind="sass" module="index.html" /> 또는 <ApiLink type="variable-dark-schema" label="dark" kind="sass" module="index.html" />) 중 하나를 **확장**해야 합니다. 이는 기본적으로 사용자 지정 스키마를 가진 컴포넌트를 지정하는 것이며, 그다음 해당 컴포넌트 테마에 추가합니다:

```scss
$custom-light-schema: extend($light-schema,(
   grid: $custom-grid-schema,
   button: $custom-button-schema,
   input-group: $custom-input-group-schema,
   list: $custom-list-schema,
   checkbox: $custom-checkbox-schema,
   drop-down: $custom-drop-down-schema
));

$custom-grid: grid-theme(
    $schema: $custom-light-schema
);

$custom-button: flat-button-theme(
    $schema: $custom-light-schema
);

$custom-input-group: input-group-theme(
    $schema: $custom-light-schema
);

$custom-list: list-theme(
    $schema: $custom-light-schema
);

$custom-checkbox: checkbox-theme(
    $schema: $custom-light-schema
);

$custom-drop-down: drop-down-theme(
    $schema: $custom-light-schema
);
```

위에서 보여 드린 것과 같은 방식으로 테마를 포함하는 것을 잊지 마십시오.

## 스타일링

기본 제공 테마 외에도, 사용 가능한 CSS 속성 몇 가지를 설정하여 그리드를 더 사용자 지정할 수 있습니다. 몇 가지 색상만으로 완전한 테마를 만드는 방법은 [테마 지정 항목](theming.mdx)을 참조하십시오.

```
</PlatformBlock>

<{ComponentSelector} className="grid"></{ComponentSelector}>

</PlatformBlock>

<{ComponentSelector} class="grid"></{ComponentSelector}>
```
</PlatformBlock>

```css
.grid {
    --ig-grid-filtering-row-background: #ffcd0f;
    --ig-list-item-background: #ffcd0f;
}
```
