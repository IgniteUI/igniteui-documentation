### 선택 없음

<ApiLink type="{ComponentName}" />에서는 기본적으로 행 선택이 비활성화되어 있습니다(<ApiLink type="{ComponentName}" member="rowSelection" />는 None). 따라서 <ApiLink type="{ComponentName}" /> UI와의 상호 작용으로는 행을 **선택하거나 선택 해제할 수 없으며**, 이러한 작업을 완료하는 유일한 방법은 제공된 API 메서드를 사용하는 것입니다.

### 단일 선택

단일 행 선택은 이제 쉽게 설정할 수 있으며, 해야 할 일은 <ApiLink type="{ComponentName}" member="rowSelection" />을(를) `Single` 속성으로 설정하는 것뿐입니다. 이렇게 하면 **그리드 안에서 한 행만 선택**할 수 있습니다. 셀을 클릭하거나, 행의 셀에 포커스가 있을 때 <kbd>SPACE</kbd> 키를 누르면 행을 선택할 수 있으며, 물론 행 선택기 필드를 클릭해서도 행을 선택할 수 있습니다. 행이 선택되거나 선택 해제되면 <ApiLink type="{ComponentName}" member="rowSelectionChanging" /> 이벤트가 발생합니다.

### 다중 선택

<ApiLink type="{ComponentName}" />에서 여러 행 선택을 활성화하려면 <ApiLink type="{ComponentName}" member="rowSelection" /> 속성을 `Multiple`로 설정하기만 하면 됩니다. 이렇게 하면 각 행과 <ApiLink type="{ComponentName}" /> 머리글에 행 선택기 필드가 활성화됩니다. 행 선택기를 사용하면 사용자가 여러 행을 선택할 수 있으며, 선택 상태는 스크롤, 페이징, 정렬과 필터링 같은 데이터 작업 중에도 유지됩니다. 셀을 클릭하거나 셀에 포커스가 있을 때 <kbd>SPACE</kbd> 키를 눌러서도 행을 선택할 수 있습니다. 한 행을 선택한 상태에서 <kbd>SHIFT</kbd> 키를 누른 채 다른 행을 클릭하면 행 전체 범위가 선택됩니다. 이 선택 모드에서 단일 행을 클릭하면 이전에 선택된 행은 선택이 해제됩니다. <kbd>CTRL</kbd> 키를 누른 상태에서 **클릭**하면 해당 행이 토글되고 이전 선택은 유지됩니다.

### 연쇄 선택

<ApiLink type="{ComponentName}" />에서 계단식 행 선택을 활성화하려면 <ApiLink type="{ComponentName}" member="rowSelection" /> 속성을 `MultipleCascade`로 설정하기만 하면 됩니다. 이렇게 하면 각 행과 <ApiLink type="{ComponentName}" /> 머리글에 행 선택기 필드가 활성화됩니다. 행 선택기를 사용하면 사용자가 여러 행을 선택할 수 있으며, 그러면 트리에서 그 아래의 모든 하위 항목이 선택됩니다. 선택 상태는 스크롤, 페이징, 정렬과 필터링 같은 데이터 작업 중에도 유지됩니다. 셀을 클릭하거나 셀에 포커스가 있을 때 <kbd>SPACE</kbd> 키를 눌러서도 행을 선택할 수 있습니다. 한 행을 선택한 상태에서 <kbd>SHIFT</kbd> 키를 누른 채 다른 행을 **클릭**하면, 상위 레코드를 선택할 때 선택된 범위에 없더라도 그 모든 하위 항목이 선택됩니다. 이 선택 모드에서 단일 행을 **클릭**하면 이전에 선택된 행은 선택이 해제됩니다. <kbd>CTRL</kbd> 키를 누른 상태에서 **클릭**하면 해당 행과 그 하위 항목이 토글되고 이전 선택은 유지됩니다.

- <ApiLink type="{ComponentName}" />에 원격 가상화가 있는 경우에도 올바른 행 선택과 셀 선택을 하려면 <ApiLink type="{ComponentName}" member="primaryKey" />을(를) 제공해야 합니다.
- <ApiLink type="{ComponentName}" />에 원격 가상화가 있으면, 머리글 체크박스를 클릭하면 그리드에 현재 있는 모든 레코드를 선택/선택 해제합니다. <ApiLink type="{ComponentName}" />에 데이터가 요청 시 새로 로드되면, 새로 추가된 행은 선택되지 않습니다. 이는 제한 사항이므로, 그 동작은 직접 처리해야 하며, 이러한 행은 제공된 API 메서드를 사용하여 선택할 수 있습니다.
</PlatformBlock>

</ComponentBlock>

- 행 선택은 <ApiLink type="{ComponentName}" member="rowSelectionChanging" /> 이벤트를 발생시킵니다. 이 이벤트는 **새 선택**, **이전 선택**, 이전 선택에서 **추가된** 행과 **제거된** 행에 대한 정보를 제공합니다. 또한 이 이벤트는 **취소할 수 있으므로**, 선택을 막을 수 있습니다.
- 행 선택이 활성화되면 행 선택기가 표시되지만, 표시하고 싶지 않다면 <ApiLink type="GridBaseDirective" member="hideRowSelectors" label="HideRowSelectors" />을(를) **true**로 설정할 수 있습니다.
- 실행 중에 행 선택 모드를 바꾸면, 이전 행 선택 상태가 지워집니다.

### 행 선택 이벤트

행 선택에 변화가 생기면 <ApiLink type="{ComponentName}" member="rowSelectionChanging" /> 이벤트가 발생합니다. <ApiLink type="{ComponentName}" member="rowSelectionChanging" />는 다음 인수를 노출합니다:
- `OldSelection` - 행 선택의 이전 상태를 담고 있는 행 ID 배열입니다.
- `NewSelection` - 행 선택의 새 상태와 일치하는 행 ID 배열입니다.
- `Added` - 현재 선택에 추가된 행 ID 배열입니다.
- `Removed` - 이전 선택 상태에 따라 현재 제거된 행 ID 배열입니다.
- `Event` - 행 선택 변경을 발생시킨 원래 이벤트입니다.
- `Cancel` - 행 선택 변경을 막을 수 있게 합니다.

<ComponentBlock for="HierarchicalGrid">
- `Owner` - 이벤트가 하위 그리드에서 발생한 경우, 이벤트를 발생시킨 컴포넌트에 대한 참조를 제공합니다.

</ComponentBlock>

### 모든 행 선택하기

<ApiLink type="{ComponentName}" />가 제공하는 또 다른 유용한 API 메서드는 <ApiLink type="{ComponentName}" member="selectAllRows" label="SelectAllRows" />입니다. 기본적으로 이 메서드는 모든 데이터 행을 선택하지만, 필터가 적용되어 있으면 필터 조건과 일치하는 행만 선택합니다. 이 메서드를 **false** 매개변수로 호출하면, 필터가 적용되어 있더라도 `SelectAllRows(false)`는 항상 그리드의 모든 데이터를 선택합니다.

> **참고** <ApiLink type="GridBaseDirective" member="selectAllRows" label="SelectAllRows" />는 삭제된 행을 선택하지 않는다는 점에 유의하십시오.

### 모든 행 선택 해제하기

<ApiLink type="{ComponentName}" />는 <ApiLink type="{ComponentName}" member="deselectAllRows" label="DeselectAllRows" /> 메서드를 제공합니다. 기본적으로 이 메서드는 모든 데이터 행의 선택을 해제하지만, 필터가 적용되어 있으면 필터 조건과 일치하는 행만 선택 해제합니다. 이 메서드를 **false** 매개변수로 호출하면, 필터가 적용되어 있더라도 `DeselectAllRows(false)`는 항상 모든 행 선택 상태를 지웁니다.

### 행 선택기 템플릿

<ApiLink type="{ComponentName}" />에서 머리글 선택기와 행 선택기를 템플릿화할 수 있으며, 다양한 상황에 유용한 기능을 제공하는 그 컨텍스트에도 접근할 수 있습니다.

기본적으로 <ApiLink type="{ComponentName}" />는 행 선택기의 상위 컨테이너 또는 행 자체에서 **모든 행 선택 상호 작용을 처리**하며, 템플릿에는 상태 시각화만 남겨 둡니다. 기본 기능을 재정의하는 작업은 일반적으로 [RowSelectionChanging 이벤트](#행-선택-이벤트)를 사용하여 수행해야 합니다. 기본 기능을 재정의하는 <ApiLink pkg="core" type="Checkbox" member="click" label="Click" /> 핸들러가 있는 사용자 지정 템플릿을 구현하는 경우, 올바른 행 상태를 유지하기 위해 이벤트 전파를 중지해야 합니다.

#### 행 템플릿


사용자 지정 행 선택기 템플릿을 만들려면 `{ComponentSelector}` 안에서 <ApiLink type="GridBaseDirective" member="rowSelectorTemplate" label="RowSelectorTemplate" /> 속성을 사용할 수 있습니다. 템플릿에서는 암시적으로 제공되는 컨텍스트 변수에 액세스할 수 있으며, 이 변수의 속성을 통해 행의 상태 정보를 얻을 수 있습니다.

<ApiLink type="Column" member="selected" /> 속성은 현재 행이 선택되었는지 여부를 보여 주고, <ApiLink type="RowSelectorTemplateDetails" member="index" label="Index" /> 속성은 행 인덱스에 접근하는 데 사용할 수 있습니다.
