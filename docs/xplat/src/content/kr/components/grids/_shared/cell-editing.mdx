# {Platform} {ComponentTitle} 셀 편집

{Platform} {ComponentTitle}의 {ProductName} 셀 편집은 {Platform} {ComponentTitle} 컴포넌트 안의 개별 셀 내용에 대한 훌륭한 데이터 조작 기능을 제공하며, React CRUD 작업을 위한 강력한 API를 갖추고 있습니다. 스프레드시트, 데이터 표, 데이터 그리드 같은 앱의 기본 기능으로, 사용자가 특정 셀에 데이터를 추가, 편집, 업데이트할 수 있게 합니다.
기본적으로 {ProductName}의 그리드는 셀 편집에 사용됩니다. 그리고 **기본 셀 편집 템플릿** 때문에 열 데이터 유형에 따라 서로 다른 편집기가 나타납니다. 폼 상단을 참조하십시오.

또한 데이터 업데이트 작업을 위한 자신만의 사용자 지정 템플릿을 정의하고, 변경 사항을 확정하고 버리는 기본 동작을 재정의할 수 있습니다.

## 셀 편집

### UI를 통한 편집

편집 가능한 셀에 포커스가 있을 때 다음 방법 중 하나로 특정 셀의 편집 모드에 들어갈 수 있습니다:
- 더블 클릭하면;
- 싱글 클릭 - 싱글 클릭은 이전에 선택된 셀이 편집 모드였고 현재 선택된 셀이 편집 가능한 경우에만 편집 모드에 들어갑니다. 이전에 선택된 셀이 편집 모드가 아니었다면, 싱글 클릭은 편집 모드에 들어가지 않고 셀만 선택합니다;
- 키 입력 <kbd>ENTER</kbd>에서;
- 키 입력 <kbd>F2</kbd>에서;

다음 방법 중 하나로 변경 사항을 **커밋하지 않고** 편집 모드를 벗어날 수 있습니다:
- 키 입력 <kbd>Escape</kbd>에서;
- **정렬**, **필터링**, **검색** 및 **숨기기** 작업을 수행할 때;

다음 방법 중 하나로 편집 모드를 벗어나 변경 사항을 **커밋**할 수 있습니다:
- 키 입력 <kbd>ENTER</kbd>에서;
- 키 입력 <kbd>F2</kbd>에서;
- 키 입력 <kbd>TAB</kbd>에서;
- 다른 셀을 싱글 클릭하면 - <ApiLink type="{ComponentName}" />에서 다른 셀을 클릭하면 변경 사항이 제출됩니다.
- 페이징, 크기 조정, 고정 또는 이동과 같은 작업은 편집 모드를 벗어나게 하며, 변경 사항이 제출됩니다.


<DocsAside type="info">
세로 또는 가로로 스크롤하거나 <ApiLink type="{ComponentName}" /> 바깥을 클릭해도 셀은 편집 모드에 남아 있습니다. 이는 셀 편집과 행 편집 모두에 적용됩니다.
</DocsAside>

### 셀 편집 템플릿

기본 셀 편집 템플릿에 대한 자세한 내용은 [일반 편집 주제](editing.mdx#편집-템플릿)에서 확인할 수 있습니다.

<PlatformBlock for="Angular">
셀이 편집 모드에 있을 때 적용될 사용자 지정 템플릿을 제공하려면, `CellTemplateDirective`를 사용할 수 있습니다. 이를 위해서는 <ApiLink type="{ComponentName}" member="cellEditor" /> 디렉티브로 표시된 **ng-template**을 전달하고 사용자 지정 컨트롤을 셀의 <ApiLink type="CellType" member="editValue" />에 적절히 바인딩해야 합니다:

```html
<igx-column field="class" header="Class" [editable]="true">
    <ng-template igxCellEditor let-cell="cell" let-value>
        <igx-select class="cell-select" [(ngModel)]="cell.editValue" [igxFocus]="true">
            <igx-select-item *ngFor="let class of classes" [value]="class">
                {{ class }}
            </igx-select-item>
        </igx-select>
    </ng-template>
</igx-column>
```

<PlatformBlock for="WebComponents">
```html

```

```ts
constructor() {
    const classColumn = document.getElementById('class') as IgcColumnComponent;

    this._bind = () => {
        classColumn.inlineEditorTemplateRef = this.classEditTemplate;
    }
    this._bind();
}

public classEditTemplate = (ctx: IgcCellTemplateContext) => {
    return html`
        <igc-select class="cell-select" value="${ctx.cell.value}" >
        </igc-select>
    `;
}
```

```javascript
    let cellValues = [];
```

```typescript
public webGridCellEditCellTemplate = (e: IgrCellTemplateContext) => {
    let cellValues: any = [];
    let uniqueValues: any = [];
    const cell = e.cell;
    const colIndex = cell.id.columnID;
    const field: string = this.grid1.getColumnByVisibleIndex(colIndex).field;
    let index = 0;
    for (const i of this.roleplayDataStats as any) {
      if (uniqueValues.indexOf(i[field]) === -1) {
        cellValues.push(
          <>
            <IgrSelectItem
              selected={e.cell.value == i[field]}
              value={i[field]}
            >
              <div>{i[field]}</div>
            </IgrSelectItem>
          </>
        );
        uniqueValues.push(i[field]);
      }
      index++;
    }
    return (
      <>
        <IgrSelect
          onChange={(x: any) => {
            setTimeout(() => {
              cell.editValue = x.target.value;
            });
          }}
        >
          {cellValues}
        </IgrSelect>
      </>
    );
  };
```

Excel 스타일 편집을 사용하면 사용자는 Excel을 사용할 때처럼 셀 사이를 이동하며 매우 빠르게 편집할 수 있습니다.

<DocsAside type="info">
React의 synthetic onKeyDown 이벤트 대신 네이티브 브라우저 keydown 이벤트를 사용합니다. 셀이 편집 모드에 들어가고 ENTER 키를 눌러 다음 행으로 이동하면, 그리드의 편집 기능이 셀 값을 업데이트하고 편집 모드를 닫습니다. 그 결과 편집에 사용된 입력 요소가 DOM에서 제거됩니다. React의 이벤트 시스템 최적화 때문에, 그 순간 요소가 더 이상 React 트리에 없으므로 onKeyDown 합성 이벤트는 그리드까지 버블링되지 않습니다. 따라서 기대하는 동작을 보장하려면 네이티브 이벤트 리스너를 사용해야 합니다.
</DocsAside>

</PlatformBlock>

```typescript
public keydownHandler(event) {
  const key = event.keyCode;
  const grid = this.grid;
  const activeElem = grid.navigation.activeNode;

  if ((key >= 48 && key <= 57) ||
      (key >= 65 && key <= 90) ||
      (key >= 97 && key <= 122)) {
        // Number or Alphabet upper case or Alphabet lower case
        const columnName = grid.getColumnByVisibleIndex(activeElem.column).field;
        const cell = grid.getCellByColumn(activeElem.row, columnName);
        if (cell && !grid.crudService.cellInEditMode) {
            grid.crudService.enterEditMode(cell);
            cell.editValue = event.key;
        }
    }
}

```

```typescript
function handleKeyDown(event: KeyBoardEvent) {
    const code = event.code;
    const grid = event.currentTarget as IgrGrid;
    const activeElem = grid.selectedCells[0];

    if ((event.code >= "Digit0" && event.code <= "Digit9") || (event.code >= "KeyA" && event.code <= "KeyZ")
        || (event.code >= "Numpad0" && event.code <= "Numpad9" && event.code !== "Enter" && event.code !== "NumpadEnter")) {
        if (activeElem && !activeElem.editMode) {
            activeElem.editMode = true;
            activeElem.editValue = event.key;
        } else if (activeElem && activeElem.editMode) {
            event.preventDefault();
            activeElem.editValue = activeElem.editValue + event.key;
        }
    }
}
```

</PlatformBlock>

### 스타일 지정 예제

<Sample src="/{ComponentSample}/cell-editing-styling" height={650} alt="{Platform} {ComponentTitle} 셀 편집 스타일 지정 예제" />

<PlatformBlock for="Angular">
<ApiLink type="{ComponentName}" />는 [{ProductName} 테마 라이브러리](../themes/styles.mdx)를 통해 셀의 스타일을 지정할 수 있도록 합니다. 그리드의 <ApiLink type="function-grid-theme" label="theme" kind="sass" module="index.html" />는 그리드의 여러 측면에 스타일을 지정할 수 있는 다양한 속성을 노출합니다.

아래 단계에서는 편집 모드에 있는 그리드 셀의 스타일을 지정하는 방법과 그 스타일의 범위를 지정하는 방법을 살펴보겠습니다.

[Ignite UI 테마 라이브러리](../themes/styles.mdx)를 사용하려면, 먼저 전역 스타일에서 테마 `index` 파일을 import해야 합니다:


### 스타일 라이브러리 import하기

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to {ProductName} version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

이제 {ProductName} 테마 엔진이 노출하는 모든 함수를 사용할 수 있습니다.

### 팔레트 정의하기

index 파일을 올바르게 import한 후, 사용할 수 있는 사용자 지정 팔레트를 만듭니다. 마음에 드는 두 가지 색상을 정의하고, 이를 사용하여 [igx-palette](../themes/palettes.mdx)로 팔레트를 만드십시오:

```scss
$white: #fff;
$blue: #4567bb;

$color-palette: palette($primary: $white, $secondary: $blue);
```

### 테마 정의하기

이제 팔레트를 사용하여 테마를 정의할 수 있습니다. 셀은 <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" />에 의해 스타일이 지정되므로, 이를 사용하여 <ApiLink type="{ComponentName}" />의 테마를 생성할 수 있습니다:

```scss
$custom-grid-theme: grid-theme(
    $cell-editing-background: $blue,
    $cell-edited-value-color: $white,
    $cell-active-border-color: $white,
    $edit-mode-color: color($color-palette, "secondary", 200)
);
```

### 테마 적용하기

테마를 적용하는 가장 쉬운 방법은 전역 스타일 파일에 `sass` `@include` 문을 넣는 것입니다:

```scss
@include grid($custom-grid-theme);
```

이렇게 하면 테마가 애플리케이션의 **모든** 그리드에 적용됩니다. 이 사용자 지정 스타일을 특정 컴포넌트에만 적용하려면 테마의 범위를 지정해야 합니다.

### 범위가 지정된 컴포넌트 테마

사용자 지정 테마가 특정 컴포넌트에만 영향을 주도록 하려면, 방금 정의한 모든 스타일을 전역 스타일 파일에서 사용자 지정 컴포넌트의 스타일 파일로 옮길 수 있습니다(`index` 파일의 [import](#importing-style-library) 포함).

이렇게 하면 {Platform}의 [ViewEncapsulation](https://angular.io/api/core/Component#encapsulation) 때문에 스타일이 사용자 지정 컴포넌트에만 적용됩니다.

 <DocsAside type="info">
 컴포넌트가 [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, 그리드의 스타일을 지정하려면 `::ng-deep`를 사용하여 이 캡슐화를 관통해야 합니다.
 </DocsAside>

 <DocsAside type="info">
 컴포넌트 바깥의 요소에 스타일이 영향을 주지 않도록, 이 문을 `:host` 선택자로 감쌉니다:
 </DocsAside>

```scss
:host {
    ::ng-deep {
            @include grid($custom-grid-theme);
        }
    }
}
```
