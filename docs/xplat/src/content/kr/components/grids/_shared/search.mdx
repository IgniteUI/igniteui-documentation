# {Platform} {ComponentTitle} 검색 필터

{Platform} {ComponentTitle}의 {ProductName} 검색 필터 기능은 데이터 컬렉션에서 값을 찾는 과정을 지원합니다. 이 기능은 설정하기 쉽게 만들었으며, 검색 입력 상자, 버튼, 키보드 탐색 및 기타 유용한 기능으로 구현하여 더 나은 사용자 경험을 제공할 수 있습니다. 브라우저는 기본적으로 콘텐츠 검색 기능을 제공하지만, 대부분의 경우 <ApiLink type="{ComponentName}" />는 보이지 않는 열과 행을 가상화합니다. 이런 경우 가상화된 셀은 DOM에 포함되지 않으므로, 브라우저의 기본 검색으로는 가상화된 셀의 데이터를 검색할 수 없습니다. 저희는 {Platform} Material 테이블 기반 그리드를 확장하여, <ApiLink type="{ComponentName}" />의 **가상화된 콘텐츠**를 검색할 수 있는 **검색 API**를 추가했습니다.

`FindNext`과 `FindPrev` 메서드는 모두 세 개의 인수를 받습니다:

- `Text`: **문자열**(찾고 있는 텍스트)
- (선택 사항) <PlatformBlock for="Angular"><ApiLink type="ISearchInfo" member="caseSensitive" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="SearchInfo" member="caseSensitive" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="SearchInfo" member="caseSensitive" /></PlatformBlock>: **boolean** (검색이 대소문자를 구분할지 여부이며, 기본값은 false입니다)
- (선택 사항) <PlatformBlock for="Angular"><ApiLink type="ISearchInfo" member="exactMatch" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="SearchInfo" member="exactMatch" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="SearchInfo" member="exactMatch" /></PlatformBlock>: **boolean** (검색이 정확히 일치하는 항목을 찾을지 여부이며, 기본값은 false입니다)

정확히 일치하는 방식으로 검색하면, 검색 API는 대소문자 구분까지 고려하여 <ApiLink type="{ComponentName}" member="findNext" />와 완전히 일치하는 셀 값만 결과로 강조 표시합니다. 예를 들어 문자열 '_software_'와 '_Software_'는 대소문자를 무시하면 정확히 일치합니다.

위 메서드들은 **숫자** 값을 반환합니다(<ApiLink type="{ComponentName}" />에 주어진 문자열이 포함된 횟수).

### 결과 개수 표시

현재 일치 항목의 위치와 전체 결과 개수도 표시해 보겠습니다! 이를 위해 그리드의 <ApiLink type="{ComponentName}" member="lastSearchInfo" /> 속성을 사용할 수 있습니다. 이 속성은 **find** 메서드를 사용할 때 자동으로 업데이트됩니다.

- 그리드의 `LastSearchInfo.MatchInfoCache.Length` 값은 전체 결과 개수를 알려 줍니다.
- 그리드의 `LastSearchInfo.ActiveMatchIndex` 값은 현재 항목(일치 항목)의 인덱스 위치를 알려 줍니다.

```html
@if (@@igObjectRef.lastSearchInfo) {
    <div class="resultsText">
        @if (@@igObjectRef.lastSearchInfo.matchInfoCache.length > 0) {
            <span>
                {{ @@igObjectRef.lastSearchInfo.activeMatchIndex + 1 }} of {{ @@igObjectRef.lastSearchInfo.matchInfoCache.length }} results
            </span>
        }
        @if (@@igObjectRef.lastSearchInfo.matchInfoCache.length == 0) {
            <span>
                No results
            </span>
        }
    </div>
}
```

### 유지

<ApiLink type="{ComponentName}" />을(를) 필터링 및 정렬하거나 레코드를 추가하고 제거하고 싶다면 어떻게 해야 할까요? 이러한 작업을 한 후에도 현재 검색의 강조 표시가 자동으로 업데이트되며, <ApiLink type="{ComponentName}" member="findNext" />와 일치하는 텍스트 위에 계속 유지됩니다! 또한 검색은 페이징과 함께 작동하며, <ApiLink type="{ComponentName}" />의 `PerPage` 속성이 바뀌어도 강조 표시를 유지합니다.

## 알려진 제한 사항


|제한 사항|설명|
|--- |--- |
|템플릿이 있는 셀에서 검색하기|검색 기능의 강조는 기본 셀 템플릿에서만 작동합니다. 사용자 지정 셀 템플릿이 있는 열이 있으면 강조가 작동하지 않으므로, 열 포매터 같은 다른 방법을 사용하거나, 그 열의 <ApiLink type="Column" member="searchable" label="Searchable" /> 속성을 false로 설정해야 합니다.|
|원격 가상화| 원격 가상화를 사용하면 검색이 올바르게 작동하지 않습니다|
|잘린 텍스트가 있는 셀| 셀의 텍스트가 너무 커서 말줄임표로 잘리고, 찾고 있는 텍스트가 잘린 부분에 있으면, 그 셀로 스크롤하고 일치 개수에 포함하지만 아무것도 강조되지 않습니다 |
