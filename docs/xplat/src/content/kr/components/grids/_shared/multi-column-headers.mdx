# {Platform} {ComponentTitle} 다중 열 머리글 개요

{Platform} {ComponentTitle}의 {ProductName} 다중 열 머리글 기능을 사용하면 열을 공통 다중 머리글 아래에 배치하여 그룹화할 수 있습니다. <ApiLink type="{ComponentName}" />의 각 다중 열 머리글 그룹은 다른 그룹이나 열의 조합을 나타낼 수 있습니다. 이 기능은 가로 스크롤이 번거로울 수 있는 대용량 데이터 세트를 다룰 때 특히 유용합니다.

모든 <ApiLink type="ColumnGroup" />은 [이동](column-moving.mdx), [고정](column-pinning.mdx), [숨기기](column-hiding.mdx)를 지원합니다.
<DocsAside type="info">
열과 열 그룹이 함께 있는 경우, 고정은 최상위 열 부모에 대해서만 작동합니다. 더 구체적으로는 중첩된 열 그룹이나 열별 고정은 허용되지 않습니다. <br />
열과 열 그룹 사이의 이동은 계층 구조에서 같은 수준에 있고 둘 다 같은 `group` 안에 있을 때만 허용됩니다. <br />
`columns/column-groups`가 현재 `group`로 감싸여 있지 않은 경우, 즉 **최상위** `columns`인 경우에는 보이는 전체 열 사이에서 이동이 허용됩니다.
</DocsAside>

## 스타일링

정렬 동작의 스타일 지정을 시작하려면, 모든 테마 함수와 컴포넌트 믹스인이 있는 `index` 파일을 import해야 합니다:

```scss
@import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink type="function-igx-grid-theme" label="igx-grid-theme" kind="sass" module="index.html" />을(를) 확장하고 `$header-background`, `$header-text-color`, `$header-border-width`, `$header-border-style` 및 `$header-border-color` 매개변수를 받는 새 테마를 만듭니다.

```scss
$custom-theme: igx-grid-theme(
    $header-background: #e0f3ff,
    $header-text-color: #e41c77,
    $header-border-width: 1px,
    $header-border-style: solid,
    $header-border-color: rgba(0, 0, 0, 0.08)
);
```

마지막 단계는 컴포넌트 믹스인을 **include**하는 것입니다:

```scss
@include igx-grid($custom-theme);
```

<DocsAside type="info">
컴포넌트가 [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, `::ng-deep`를 사용하여 이 캡슐화를 `penetrate`해야 합니다:
</DocsAside>

 ```scss
:host {
    ::ng-deep {
        @include igx-grid($custom-theme);
    }
}
```

### 색상 팔레트 정의하기

방금 한 것처럼 색상 값을 하드코딩하는 대신, `igx-palette` 및 `igx-color` 함수를 사용하면 색상 면에서 더 큰 유연성을 얻을 수 있습니다.

`igx-palette`는 전달된 기본 색상과 보조 색상을 기준으로 색상 팔레트를 생성합니다:

```scss
$light-blue-color: #e0f3ff;
$deep-pink-color: #e41c77;

$custom-palette: igx-palette($primary: $light-blue-color, $deep-pink-color);
```

그다음 `igx-color`로 팔레트에서 색상을 쉽게 가져올 수 있습니다.

```scss
$custom-theme: igx-grid-theme(
    $header-background: igx-color($custom-palette, "primary", 500),
    $header-text-color: igx-color($custom-palette, "secondary", 500),
    $header-border-width: 1px,
    $header-border-style: solid,
    $header-border-color: igx-color($custom-palette, "grays", 200)
);
```

<DocsAside type="info">
`igx-color`와 `igx-palette`는 색상을 생성하고 가져오는 강력한 함수입니다. 사용 방법에 대한 자세한 안내는 [팔레트](../themes/palette.mdx) 항목을 참조하십시오.
</DocsAside>

### 스키마 사용하기

테마 엔진을 더 활용하여 [스키마](../themes/schemas.mdx)의 이점을 얻는 견고하고 유연한 구조를 만들 수 있습니다. 스키마는 테마의 레시피입니다.

모든 컴포넌트에 제공되는 사전 정의된 스키마 두 가지 중 하나를 확장하십시오. 이 경우에는 `_light-grid`입니다:

```scss
// Extending the light grid schema
$custom-grid-schema: extend($_light-grid,
    (
        header-background: (igx-color:('primary', 500)),
        header-text-color: (igx-color:('secondary', 500)),
        header-border-width: 1px,
        header-border-style: solid,
        header-border-color: (igx-color:('grays', 200))
    )
);
```

사용자 지정 스키마를 적용하려면 전역 `light` 또는 `dark` 중 하나를 **확장**해야 합니다. 이는 기본적으로 사용자 지정 스키마를 가진 컴포넌트를 지정하는 것이며, 그다음 해당 컴포넌트 테마에 추가합니다:

```scss
Extending the global light-schema
$my-custom-schema: extend($light-schema,
    (
        igx-grid: $custom-grid-schema
    )
);

// Defining our custom theme with the custom schema
$custom-theme: igx-grid-theme(
  $palette: $custom-palette,
  $schema: $my-custom-schema
);
```

위에서 보여 드린 것과 같은 방식으로 테마를 포함하는 것을 잊지 마십시오.
