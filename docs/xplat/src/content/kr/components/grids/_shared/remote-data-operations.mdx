## 무한 스크롤

 엔드포인트에서 청크 단위로 데이터를 가져와야 하는 시나리오에서 많이 쓰이는 설계가 이른바 무한 스크롤입니다. 데이터 그리드에서는 최종 사용자가 맨 아래까지 스크롤하면서 로드된 데이터가 계속 늘어나는 것이 특징입니다. 다음 단락에서는 사용 가능한 API를 사용하여 <ApiLink type="{ComponentName}" />에서 무한 스크롤을 쉽게 구현하는 방법을 설명합니다.

무한 스크롤을 구현하려면 데이터를 청크 단위로 가져와야 합니다. 이미 가져온 데이터는 로컬에 저장해야 하며, 청크의 길이와 청크의 개수를 결정해야 합니다. 또한 그리드에서 마지막으로 보이는 데이터 행의 인덱스도 추적해야 합니다. 이렇게 <ApiLink type="ForOfState" member="chunkSize" />과 <ApiLink type="ForOfState" member="chunkSize" /> 속성을 사용하면, 사용자가 위로 스크롤하여 이미 가져온 데이터를 보여 줘야 하는지, 아니면 아래로 스크롤하여 엔드포인트에서 더 많은 데이터를 가져와야 하는지 판단할 수 있습니다.




가장 먼저 할 일은 데이터의 첫 번째 묶음을 가져오는 것입니다. <ApiLink type="{ComponentName}" member="totalItemCount" /> 속성을 설정하는 것이 중요합니다. 이 속성을 설정해야 그리드가 스크롤바 크기를 올바르게 결정할 수 있습니다.

public ngAfterViewInit() {
    this._remoteService.loadDataForPage(this.page, this.pageSize, (request) => {
        if (request.data) {
            this.grid.totalItemCount = this.page * this.pageSize;
            this.grid.data = this._remoteService.getCachedData({startIndex: 0, chunkSize: 10});
            this.totalItems = request.data['@odata.count'];
            this.totalPageCount = Math.ceil(this.totalItems / this.pageSize);
            this.grid.isLoading = false;

    });
}

public handlePreLoad() {
    const isLastChunk = this.grid.totalItemCount ===
                        this.grid.virtualizationState.startIndex + this.grid.virtualizationState.chunkSize;
    // when last chunk reached load another page of data
    if (isLastChunk) {
        if (this.totalPageCount === this.page) {
            this.grid.data = this._remoteService.getCachedData(this.grid.virtualizationState);
            return;
        }
        this.page++;
        this.grid.isLoading = true;
        this._remoteService.loadDataForPage(this.page, this.pageSize, (request) => {
            if (request.data) {
                this.grid.totalItemCount = Math.min(this.page * this.pageSize, this.totalItems);
                this.grid.data = this._remoteService.getCachedData(this.grid.virtualizationState);
                this.grid.isLoading = false;
            }
        });
    } else {
        this.grid.data = this._remoteService.getCachedData(this.grid.virtualizationState);
    }
}

        private IgbGrid grid;
        public async void OnDataPreLoad(IgbForOfStateEventArgs e)
        {
            int chunkSize = (int)e.Detail.ChunkSize;
            int startIndex = (int)e.Detail.StartIndex;
            int totalCount = (int)this.grid.TotalItemCount;

            bool isLastChunk = totalCount == startIndex + chunkSize;
            // when last chunk reached load another page of data
            if (isLastChunk)
            {
                if (this.TotalPageCount == this.Page)
                {
                    this.LocalData = this.CachedData.Skip(startIndex).Take(chunkSize).ToList();
                    return;
                }

                // add next page of remote data to cache
                this.grid.IsLoading = true;
                this.Page++;
                var remoteData = await GetDataRemote(this.Page, this.PageSize);
                this.CachedData.AddRange(remoteData);

                var data = this.CachedData.Skip(startIndex).Take(chunkSize);
                this.LocalData = data.ToList();
                this.grid.IsLoading = false;
                this.grid.TotalItemCount = Math.Min(this.Page * this.PageSize, this.TotalItems);
            }
            else
            {
                var data = this.CachedData.Skip(startIndex).Take(chunkSize).ToList();
                this.LocalData = data;
            }

## 원격 정렬/필터링

원격 정렬과 필터링을 제공하려면, 받은 인수에 따라 적절한 요청을 하도록 <ApiLink type="{ComponentName}" member="dataPreLoad" />, <ApiLink type="{ComponentName}" member="sortingExpressionsChange" /> 및 <ApiLink type="{ComponentName}" member="filteringExpressionsTreeChange" /> 출력을 구독해야 합니다. 또한 서비스에서 가져온 해당 정보로 공개 <ApiLink type="{ComponentName}" /> 속성 <ApiLink type="{ComponentName}" member="totalItemCount" />을(를) 설정해야 합니다.

또한 **rxjs**의 `debounceTime` 함수를 활용합니다. 이 함수는 원본 Observable에서 다른 발행 없이 특정 시간이 지난 후에만 값을 발행합니다. 이렇게 하면 사용자가 중간에 끼어들지 않고 지정된 시간이 지났을 때만 원격 작업이 트리거됩니다.

```typescript
const DEBOUNCE_TIME = 300;
public ngAfterViewInit() {
    this.grid.dataPreLoad.pipe(
        debounceTime(DEBOUNCE_TIME),
        takeUntil(this.destroy$)
    ).subscribe(() => {
        this.processData();
    });

    this.grid.filteringExpressionsTreeChange.pipe(
        debounceTime(DEBOUNCE_TIME),
        takeUntil(this.destroy$)
    ).subscribe(() => {
        this.processData(true);
    });

    this.grid.sortingExpressionsChange.pipe(
        debounceTime(DEBOUNCE_TIME),
        takeUntil(this.destroy$)
    ).subscribe(() => {
        this.processData();
    });
}
```

## 고유 열 값 전략

Excel 스타일 필터링 대화 상자 안의 목록 항목은 각 열의 고유 값을 나타냅니다. <ApiLink type="{ComponentName}" />은(는) 기본적으로 데이터 소스를 기준으로 이 값들을 생성합니다. 원격 필터링의 경우, 그리드 데이터에는 서버의 모든 데이터가 들어 있지 않습니다. 고유 값을 수동으로 제공하고 필요할 때 로드하려면, <ApiLink type="{ComponentName}" />의 <ApiLink type="{ComponentName}" member="uniqueColumnValuesStrategy" label="UniqueColumnValuesStrategy" /> 입력을 활용할 수 있습니다. 이 입력은 실제로 세 개의 인수를 제공하는 메서드입니다:

- <ApiLink type="Column" />  - 해당 열 인스턴스입니다.
- <ApiLink type="FilteringExpressionsTree" /> - 해당 열을 기준으로 축소된 필터링 식 트리입니다.
- `Done` - 서버에서 새 열 값을 가져올 때 새로 생성된 열 값과 함께 호출해야 하는 콜백입니다.

개발자는 <ApiLink type="Column" /> 및 <ApiLink type="FilteringExpressionsTree" /> 인수가 제공하는 정보를 기반으로 필요한 고유 열 값을 직접 생성한 다음, `Done` 콜백을 호출할 수 있습니다.

<DocsAside type="info">
`UniqueColumnValuesStrategy` 입력이 제공되면, Excel 스타일 필터링의 기본 고유 값 생성 프로세스는 사용되지 않습니다.
</DocsAside>

    this.remoteService.getData(0, this.perPage);
}

public nextPage() {
    this.firstPage = false;
    this.page++;
    const skip = this.page * this.perPage;
    const top = this.perPage;
    this.remoteService.getData(skip, top);
    if (this.page + 1 >= this.totalPages) {
        this.lastPage = true;
    }
    this.setNumberOfPagingItems(this.page, this.totalPages);
}

public previousPage() {
    this.lastPage = false;
    this.page--;
    const skip = this.page * this.perPage;
    const top = this.perPage;
    this.remoteService.getData(skip, top);
    if (this.page <= 0) {
        this.firstPage = true;
    }
    this.setNumberOfPagingItems(this.page, this.totalPages);
}

public paginate(page: number, recalculate = false) {
    this.page = page;
    const skip = this.page * this.perPage;
    const top = this.perPage;
    if (recalculate) {
        this.totalPages = Math.ceil(this.totalCount / this.perPage);
    }
    this.setNumberOfPagingItems(this.page, this.totalPages);
    this.remoteService.getData(skip, top);
    this.buttonDeselection(this.page, this.totalPages);
}

### 원격 페이징과 일괄 편집

지금까지의 예제로 원격 데이터와 함께 <ApiLink type="{ComponentName}" />을(를) 설정하는 방법을 명확히 했습니다. 이제 [일괄 편집 주제/가이드](batch-editing.mdx)를 따라 그리드에 일괄 편집을 활성화하는 데 집중해 보겠습니다.
