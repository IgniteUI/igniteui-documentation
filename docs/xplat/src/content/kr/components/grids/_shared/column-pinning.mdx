{Platform} {ComponentTitle}의 {ProductName} 열 고정 기능을 사용하면 개발자가 특정 열을 원하는 순서로 잠가, 사용자가 `{ComponentName}`를 가로로 스크롤하는 경우에도 항상 표시되도록 할 수 있습니다. 열 고정을 위한 통합 UI는 {Platform} {ComponentTitle} 도구 모음을 통해 사용할 수 있습니다. 또한 개발자는 열의 고정 상태를 변경하는 사용자 지정 사용자 인터페이스를 유연하게 구축할 수 있습니다.

## 고정 위치

<ApiLink type="Column" member="pinningPosition" /> 구성 옵션을 통해 열 고정 위치를 바꿀 수 있습니다. 이를 통해 열 위치를 Start 또는 End로 설정할 수 있습니다.
End로 설정하면 열은 고정되지 않은 열 다음에 그리드의 끝에 렌더링됩니다. 고정되지 않은 열은 가로로 스크롤할 수 있고, 고정된 열은 오른쪽에 고정된 상태를 유지합니다.

// In JavaScript
igRegisterScript("WebGridPinHeaderTemplate", (ctx) => {
    var html = window.igTemplating.html;
    window.toggleColumnPin = function toggleColumnPin(field) {
        var grid = document.getElementsByTagName["igc-grid"](0);
        var col = grid.getColumnByName(field);
        col.pinned = !col.pinned;
        grid.markForCheck();
    }
    return html`<div>
    <span style="float:left">${ctx.column.field}</span>
    <span style="float:right" @pointerdown="${() => toggleColumnPin(ctx.column.field)}">📌</span>
</div>`;
}, false);

## 스타일링

<ApiLink type="{ComponentName}" />는 [{ProductName} 테마 라이브러리](../themes/styles.mdx)를 통한 스타일 지정을 지원합니다. 그리드의 <ApiLink type="function-grid-theme" label="theme" kind="sass" module="index.html" />는 다양한 속성을 노출하며, 이를 통해 그리드의 모든 기능을 사용자 지정할 수 있습니다.

아래 단계에서는 그리드의 고정 스타일을 사용자 지정하는 과정을 살펴보겠습니다.

### 전역 테마 가져오기
고정 기능의 사용자 지정을 시작하려면 모든 스타일 함수와 믹스인이 있는 `index` 파일을 가져와야 합니다.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### 사용자 지정 테마 정의하기
다음으로 <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" />을(를) 확장하고 원하는 대로 고정 기능을 사용자 지정하는 데 필요한 매개변수를 받는 새 테마를 만드십시오.

```scss
$custom-theme: grid-theme(
    /* Pinning properties that affect styling */
    $pinned-border-width: 5px,
    $pinned-border-style: double,
    $pinned-border-color: #FFCD0F,
    $cell-active-border-color: #FFCD0F
    /* add other features properties here... */
);
```

### 사용자 지정 색상 팔레트 정의하기
위에서 설명한 방식에서는 색상 값이 하드코딩되어 있었습니다. 대신 <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" /> 및 <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" /> 함수를 사용하면 더 큰 유연성을 얻을 수 있습니다.
`igx-palette`는 지정된 기본 색상과 보조 색상을 기준으로 색상 팔레트를 생성합니다.

 ```scss
$primary-color: #292826;
$secondary-color: #ffcd0f;

$custom-palette: palette(
  $primary: $primary-color,
  $secondary: $secondary-color
);
```

사용자 지정 팔레트가 생성된 후에는 `igx-color` 함수를 사용하여 기본 색상과 보조 색상의 다양한 변형을 얻을 수 있습니다.


```scss
$custom-theme: grid-theme(
    $pinned-border-width: 5px,
    $pinned-border-style: double,
    $pinned-border-color: color($custom-palette, "secondary", 500),
    $cell-active-border-color: color($custom-palette, "secondary", 500)
);
```

`$custom-theme`에는 이전 섹션과 같은 속성이 들어 있지만, 이번에는 색상이 하드코딩되어 있지 않습니다. 대신 사용자 지정 `igx-palette`를 사용했고, 기본 색상과 보조 색상, 그리고 지정된 색상 변형을 통해 색상을 가져왔습니다.

### 사용자 지정 스키마 정의하기
더 나아가 [**스키마**](../themes/sass/schemas.mdx)의 모든 장점을 가진 유연한 구조를 만들 수 있습니다. **스키마**는 테마의 레시피입니다.
모든 컴포넌트에 제공되는 두 개의 사전 정의된 스키마 중 하나를 확장하십시오. 이 경우에는 `$_light_grid`를 사용하겠습니다.

```scss
$custom-grid-schema: extend($_light-grid,(
    pinned-border-width: 5px,
    pinned-border-style: double,
    pinned-border-color: color: ("secondary", 500),
    cell-active-border-color: color: ("secondary", 500)
));
```

사용자 지정 스키마를 적용하려면 전역 `light` 또는 `dark` 중 하나를 확장해야 합니다. 전체 과정은 컴포넌트에 사용자 지정 스키마를 제공한 다음, 이를 해당 컴포넌트 테마에 추가하는 것입니다.

```scss
$my-custom-schema: extend($light-schema, (
    igx-grid: $custom-grid-schema
));
$custom-theme: grid-theme(
    $palette: $custom-palette,
    $schema: $my-custom-schema
);
```

### 사용자 지정 테마 적용하기
테마를 적용하는 가장 쉬운 방법은 전역 스타일 파일에 `sass` `@include` 문을 추가하는 것입니다:

```scss
@include grid($custom-theme);
```

### 범위가 지정된 컴포넌트 테마

사용자 지정 테마가 특정 컴포넌트에만 영향을 주도록 하려면, 방금 정의한 모든 스타일을 전역 스타일 파일에서 사용자 지정 컴포넌트의 스타일 파일로 옮길 수 있습니다(`index` 파일의 import 포함).

이렇게 하면 Angular의 [ViewEncapsulation](https://angular.io/api/core/Component#encapsulation) 덕분에 스타일이 사용자 지정 컴포넌트에만 적용됩니다.
 <DocsAside type="info">
 컴포넌트가 [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, 그리드의 스타일을 지정하려면 `::ng-deep`를 사용하여 이 캡슐화를 관통해야 합니다.
 </DocsAside>

 <DocsAside type="info">
 스타일이 컴포넌트 바깥의 요소에 영향을 주지 않도록, 구문을 `:host` 선택자 안에 넣으십시오:
 </DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid($custom-theme);
    }
}
```
