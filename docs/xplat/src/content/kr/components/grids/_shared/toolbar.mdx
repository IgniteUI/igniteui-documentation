# {Platform} {ComponentTitle} 도구 모음

{ProductName} 도구 모음은 {Platform} {ComponentTitle}의 UI 작업을 담는 컨테이너입니다. {Platform} 도구 모음은 {Platform} 컴포넌트의 맨 위, 즉 <ApiLink type="{ComponentName}" />에 위치하며 그 가로 크기와 일치합니다. 도구 모음 컨테이너에는 사용자 지정 콘텐츠나 미리 정의된 UI 컨트롤 세트를 넣을 수 있습니다. {Platform} {ComponentTitle}의 기본 세트는 다음을 포함합니다:

- 열 숨기기
- 열 고정
- Excel 내보내기
- 고급 필터링

도구 모음과 미리 정의된 UI 컴포넌트는 {Platform} 이벤트를 지원하며, 개발자를 위한 API를 노출합니다.

### 작업


<ApiLink type="GridToolbarActions" />은(는) 부모 그리드와 관련된 작업이나 상호 작용을 배치하는 곳입니다.
도구 모음의 제목 부분과 마찬가지로, 그 템플릿 부분에는 기본

### 데이터 내보내기

<ComponentBlock for="HierarchicalGrid">

<DocsAside type="info">
<ApiLink type="{ComponentName}" /> 또는 그 계층 아래의 하위 그리드를 내보낼 때, 내보내는 데이터는 각 그리드에 속한 행의 평면 컬렉션이 됩니다(하위 그리드는 내보내기 데이터에 포함되지 않습니다).
</DocsAside>

</ComponentBlock>

도구 모음의 다른 작업과 마찬가지로, 내보내기도 기본으로 <ApiLink type="GridToolbarExporter" />을(를) 통해 제공됩니다.

<PlatformBlock for="Angular">
내보내기 컴포넌트는 대상 데이터 형식 <ApiLink type="ExcelExporterService" /> 및 `CSVExporterService`에 맞는 서비스를 사용합니다. 즉, 해당 서비스가 의존성 주입 체인을 통해 제공되지 않으면 컴포넌트는 아무것도 내보낼 수 없습니다.

{Platform}의 DI가 기억나지 않는다면 [공식 가이드](https://{Platform}.io/guide/dependency-injection)를 확인하십시오. 다음은 애플리케이션의 모든 내보내기 서비스를 활성화하는 방법을 보여 주는 샘플 코드 조각입니다.

```typescript
// app.module.ts

import { IgxExcelExporterService, IgxCsvExporterService } from 'igniteui-{Platform}';

@NgModule({
    //...
    providers: [IgxExcelExporterService, IgxCsvExporterService ]
})
export class AppModule { ... }
```

<DocsAside type="info">
v12.2.1 이후에는 내보내기 서비스가 root에 제공되므로, 더 이상 AppModule providers에 선언할 필요가 없습니다.
</DocsAside>

</PlatformBlock>

도구 모음 내보내기 컴포넌트는 UI와 내보내기 경험을 모두 사용자 지정하는 여러 입력 속성을 노출합니다.

표시 텍스트를 바꾸는 것부터 드롭다운의 옵션을 활성화/비활성화하는 것, 생성되는 파일 이름을 사용자 지정하는 것까지 다양합니다. 전체 참조는 `ToolbarExporter`의 API 문서를 참조하십시오.

## 내보내기 표시기

기본 도구 모음 내보내기 컴포넌트를 사용하면, 내보내기 작업이 실행될 때마다 작업이 진행되는 동안 도구 모음에 진행률 표시기가 나타납니다.

또한 사용자는 도구 모음의 <ApiLink type="GridToolbar" member="showProgress" label="ShowProgress" /> 속성을 설정하여 자신만의 장시간 작업에 사용하거나, 그리드에서 작업이 진행 중임을 나타내는 또 다른 방법으로 사용할 수 있습니다.

아래 샘플은 진행률 표시줄을 볼 수 있도록 데이터 내보내기 시간을 늘리기 위해 많은 양의 데이터를 사용합니다. 또한 그리드에서 장시간 작업을 시뮬레이션하는 버튼이 하나 더 있습니다:

## 사용자 지정 콘텐츠

<PlatformBlock for="Angular">
<DocsAside type="info">
이 기능은 이전의 도구 모음 템플릿 디렉티브를 대체합니다. v11 이전 버전에서 마이그레이션하는 경우, 마이그레이션이 템플릿 콘텐츠의 이동을 처리합니다. 하지만 템플릿의 바인딩은 처리하지 않으므로, 마이그레이션이 끝난 후 수정된 템플릿 파일을 반드시 다시 확인하십시오.
</DocsAside>

</PlatformBlock>

도구 모음 컴포넌트의 작업 부분으로 특정 사용 사례를 충분히 처리할 수 없다면, 도구 모음 자체에는 추가 UI를 제공할 수 있는 일반 콘텐츠 프로젝션이 있습니다. 사용자가 API 호출이나 바인딩을 위해 그리드 인스턴스가 필요하다면 템플릿 참조 변수를 만들 수 있습니다.

```css
    --ig-grid-toolbar-dropdown-background: #2a2b2f;
}
```

## 스타일링

도구 모음의 스타일 지정을 시작하려면, 모든 테마 함수와 컴포넌트 믹스인이 있는 index 파일을 import해야 합니다:

```scss
@use "igniteui-{Platform}/theming" as *;

// IMPORTANT: Prior to {ProductName} version 13 use:
// @import '~igniteui-{Platform}/lib/core/styles/themes/index';
```

먼저 새 팔레트를 만들어 봅시다.

```scss
$my-dark-palette: palette(
    $primary: #2466ff,
    $secondary: #FFCD0F,
    $surface: #2a2b2f,
    $grays: #fff,
);

$my-dark-color: color($my-dark-palette, 'surface');
```

이제 <ApiLink type="function-grid-toolbar-theme" label="grid-toolbar-theme" kind="sass" module="index.html" />을(를) 확장하고 `$background-color` 및 `$title-text-color` 매개변수를 수정하는 새 테마를 만드십시오.

```scss
$dark-grid-toolbar-theme: grid-toolbar-theme(
    $background-color: $my-dark-color,
    $title-text-color: color($my-dark-palette, 'secondary'),
    $dropdown-background: $my-dark-color,
);
```

도구 모음의 열 작업 메뉴에 테마를 적용하려면 `column-actions-theme` 컴포넌트의 테마를 바꿔야 합니다.

```scss
$dark-column-actions-theme: column-actions-theme(
    $title-color: color($my-dark-palette, 'secondary'),
    $background-color: color($my-dark-palette, 'surface')
);
```

열 작업은 다른 컴포넌트(igx-button, igx-checkbox, igx-input-group)를 사용하므로, 새 도구 모음 테마와 맞추려면 이들의 테마도 바꿔야 합니다.

```scss
$dark-button-theme: outlined-button-theme(
    $background: color($my-dark-palette, 'secondary'),
    $hover-background: color($my-dark-palette, 'gray', 100),
    $hover-foreground: color($my-dark-palette, 'secondary')
);

$dark-checkbox-theme: checkbox-theme(
    $tick-color: $my-dark-color,
);

$dark-input-group-theme: input-group-theme(
    $filled-text-color: color($my-dark-palette, 'secondary')
);
```

마지막 단계는 새로 만든 테마를 **포함**하는 것입니다.

```scss
:host {
    @include grid-toolbar($dark-grid-toolbar-theme);
    @include column-actions($dark-column-actions-theme);
    @include checkbox($dark-checkbox-theme);
    @include input-group($dark-input-group-theme);
    @include button($dark-button-theme);
}
```

<DocsAside type="info">
`$legacy-support`이(가) `false(default)`로 설정되어 있다면, 다음과 같이 컴포넌트 CSS 변수를 포함하십시오:
</DocsAside>

```scss
:host {
    @include tokens($dark-grid-toolbar-theme);
    @include tokens($dark-column-actions-theme);
    @include tokens($dark-checkbox-theme);
    @include tokens($dark-input-group-theme);
    @include tokens($dark-button-theme);
}
```

<DocsAside type="info">
컴포넌트가 [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, `::ng-deep`를 사용하여 이 캡슐화를 `penetrate`해야 합니다:
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid-toolbar($dark-grid-toolbar-theme);
        @include column-actions($dark-column-actions-theme);
        @include checkbox($dark-checkbox-theme);
        @include input-group($dark-input-group-theme);
        @include button($dark-button-theme);
    }
}
```
