# {Platform}  {ComponentTitle} 열 크기 조정 개요

{Platform} {ComponentTitle}의 {ProductName} 열 크기 조정 기능을 사용하면 사용자가 <ApiLink type="{ComponentName}" />의 열 너비를 쉽게 조정할 수 있습니다. 기본적으로 드래그하여 크기를 조정하는 동안 임시 크기 조정 표시기가 표시됩니다. 사용할 수 있는 크기 조정 옵션은 여러 가지입니다. 픽셀/백분율 단위로 열 크기 조정, 열 크기 조정 제한, 더블 클릭 시 열 자동 크기 조정, 초기화 시 열 자동 크기 조정이 있습니다.

<DocsAside type="info">
픽셀로 설정된 열과 백분율로 설정된 열의 크기 조정 방식에는 약간의 차이가 있습니다.
</DocsAside>

**픽셀**

픽셀 너비가 있는 열의 크기 조정은 마우스 이동의 가로 거리를 열의 크기에 직접 더하거나 빼서 작동합니다.

**백분율**

백분율 너비가 있는 열을 크기 조정할 때, 픽셀 단위의 마우스 이동 거리는 그리드 너비에 대한 대략적인 백분율 값으로 변환됩니다. 열은 계속 반응형으로 유지되며, 이후 그리드 크기가 바뀌어도 열에 그대로 반영됩니다.

## 열 크기 조정 제한

허용되는 최소 및 최대 열 너비를 구성할 수도 있습니다. 이는 <ApiLink type="Column" />의 <ApiLink type="Column" member="minWidth" /> 및 <ApiLink type="ColumnState" member="maxWidth" /> 입력을 통해 합니다. 이 경우 크기 조정 표시기 드래그 작업이 제한되어, 열이 <ApiLink type="Column" member="minWidth" />과(와) <ApiLink type="ColumnState" member="maxWidth" />로 정의된 경계 밖으로 크기 조정될 수 없다는 것을 사용자에게 알려 줍니다.

## 더블 클릭 시 열 자동 크기 조정

각 열은 머리글의 오른쪽 면을 더블 클릭하여 **자동 크기 조정**할 수 있습니다. 열은 머리글 자체를 포함하여 현재 보이는 가장 긴 셀 값에 맞춰 크기가 정해집니다. 이 동작은 기본적으로 활성화되어 있으며, 추가 구성은 필요하지 않습니다. 하지만 그 열에 <ApiLink type="ColumnState" member="maxWidth" />이(가) 설정되어 있고 새 너비가 그 <ApiLink type="ColumnState" member="maxWidth" /> 값을 초과하는 경우에는 열이 자동 크기 조정되지 않습니다. 이 경우 열은 미리 설정된 <ApiLink type="ColumnState" member="maxWidth" /> 값에 따라 크기가 정해집니다.

<ApiLink type="Column" />의 노출된 <ApiLink type="Column" member="autosize" /> 메서드를 사용하여 열을 동적으로 자동 크기 조정할 수도 있습니다.

## 스타일링

<ApiLink type="{ComponentName}" /> 열 크기 조정 선의 스타일 지정을 시작하려면, 모든 테마 함수와 컴포넌트 믹스인이 있는 index 파일을 import해야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

이를 달성하는 가장 간단한 방법은 <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" />을(를) 확장하고, 많은 매개변수와 `$resize-line-color` 매개변수를 받는 새 테마를 만드는 것입니다.

```scss
$custom-grid-theme: grid-theme(
    $resize-line-color: #0288D1
);
```

 <DocsAside type="info">
 컴포넌트가 [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, `::ng-deep`를 사용하여 이 캡슐화를 `penetrate`해야 합니다.
 </DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid($custom-grid-theme);
    }
}
```

### 색상 팔레트 정의하기
색상 값을 하드코딩하는 대신, <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" /> 및 <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" /> 함수를 사용하면 색상 면에서 더 큰 유연성을 얻을 수 있습니다.

`igx-palette`는 지정된 기본 색상과 보조 색상을 기준으로 색상 팔레트를 생성합니다:

```scss
$primary-color: #0288D1;
$secondary-color: #BDBDBD;

$custom-theme-palette: palette($primary: $primary-color, $secondary: $secondary-color);
```

그다음 <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />를 사용하면 팔레트에서 색상을 쉽게 가져올 수 있습니다.

```scss
$custom-grid-theme: grid-theme(
    $palette: $custom-theme-palette,
    $resize-line-color: color($custom-theme-palette, 'secondary', 500)
);
```

<DocsAside type="info">
`igx-color` 및 `igx-palette`는 색상을 생성하고 가져오는 강력한 함수입니다. 사용 방법에 대한 자세한 안내는 [팔레트](../themes/sass/palettes.mdx) 항목을 참조하십시오.
</DocsAside>

### 스키마 사용하기
테마 엔진을 더 활용하여 [**스키마**](../themes/sass/schemas.mdx)의 이점을 얻는 견고하고 유연한 구조를 만들 수 있습니다. **스키마**는 테마의 레시피입니다.

모든 컴포넌트에 제공되는 사전 정의된 스키마를 확장하십시오. 이 경우에는 <ApiLink type="variable-_light-grid" label="light-grid" kind="sass" module="index.html" /> 스키마입니다:

```scss
// Extending the light grid schema
$light-grid-schema: extend($_light-grid,
    (
        resize-line-color: (
           color: ('secondary', 500)
            ),
        header-background: (
           color: ("primary", 100)
            ),
        header-text-color: (
           color: ("primary", 600)
            )
    )
);
```

사용자 지정 스키마를 적용하려면 전역(<ApiLink type="variable-light-schema" label="light" kind="sass" module="index.html" /> 또는 <ApiLink type="variable-dark-schema" label="dark" kind="sass" module="index.html" />) 중 하나를 **확장**해야 합니다. 이는 기본적으로 사용자 지정 스키마를 가진 컴포넌트를 지정하는 것이며, 그다음 해당 컴포넌트 테마에 추가합니다:

```scss
// Extending the global light-schema
$custom-light-grid-schema: extend($light-schema,(
    igx-grid: $light-grid-schema
));

// Specifying the palette and schema of the custom grid theme
$custom-grid-theme: grid-theme(
    $palette: $custom-theme-palette,
    $schema: $custom-light-grid-schema
);
```

위에서 설명한 것과 같은 방식으로 테마를 포함하는 것을 잊지 마십시오.
