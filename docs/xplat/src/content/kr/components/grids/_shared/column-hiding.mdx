# {Platform} {ComponentTitle} 열 숨기기

<PlatformBlock for="Angular">
{ProductName} <ApiLink type="{ComponentName}" />는 <ApiLink type="ColumnActionsComponent" />를 제공하며, 여기에는 `ColumnHidingDirective`가 포함되어 있어 사용자가 사용자 인터페이스를 통해 또는 {Platform} 컴포넌트를 사용하여 직접 열 숨기기를 수행할 수 있습니다.
</PlatformBlock>

{ProductName}에는 내장 열 숨기기 UI가 있으며, {Platform} {ComponentTitle} 도구 모음을 통해 열의 표시 상태를 변경하는 데 사용할 수 있습니다. 개발자는 필요에 따라 페이지 내 어디에서나 열 숨기기 UI를 정의할 수 있는 유연성을 갖습니다. {Platform} {ComponentTitle} 열 숨기기 기능은 그리드의 크기를 줄이고 불필요한 필드를 탭으로 이동할 필요를 없애려는 경우에 특히 유용합니다.

## 도구 모음의 열 숨기기 UI

내장 열 숨기기 UI는 <ApiLink type="{ComponentName}" />의 도구 모음에 있는 <ApiLink pkg="core" type="Dropdown" /> 안에 배치됩니다. 바로 이 드롭다운을 사용하여 열 숨기기 UI를 표시하거나 숨길 수 있습니다.

이를 위해 <ApiLink type="{ComponentName}" /> 안에서 <ApiLink type="GridToolbarActions" />와 <ApiLink type="GridToolbarHiding" />를 모두 설정하기만 하면 됩니다.

## 스타일링

열 작업 컴포넌트의 스타일링을 시작하려면 모든 테마 함수와 컴포넌트 믹스인이 있는 인덱스 파일을 가져와야 합니다:

```scss
@use "igniteui-{Platform}/theming" as *;

// IMPORTANT: Prior to {ProductName} version 13 use:
// @import '~igniteui-{Platform}/lib/core/styles/themes/index';
```

가장 간단한 방법으로, `column-actions-theme`을(를) 확장하고 `$title-color` 및 `$background-color` 매개변수를 받는 새 테마를 만듭니다.

```scss
$custom-column-actions-theme: column-actions-theme(
    $background-color: steelblue,
    $title-color: gold
);
```

보시다시피 `column-actions-theme`은(는) 열 작업 컨테이너의 색상만 제어하며, 그 안의 버튼, 체크박스, 입력 그룹에는 영향을 주지 않습니다. 버튼의 스타일도 지정하고 싶다고 해 보겠습니다. 그래서 새 버튼 테마를 만들겠습니다:

```scss
$custom-button: flat-button-theme($foreground: gold, $disabled-foreground: black);
```

이 예제에서는 flat 버튼의 텍스트 색상과 버튼 비활성화 색상만 바꾸었지만, `flat-button-theme`은(는) 버튼 스타일을 제어하는 훨씬 많은 매개변수를 제공합니다.

마지막 단계는 각 컴포넌트 믹스인을 해당 테마와 함께 **포함**하는 것입니다:

```scss
@include column-actions($custom-column-actions-theme);
.igx-column-actions {
    @include button($custom-button);
}
```

> **참고**
>열 숨기기 버튼에만 스타일이 적용되도록 **igx-button** 믹스인의 범위를 `.igx-column-actions` 안으로 지정합니다. 그렇지 않으면 그리드의 다른 버튼에도 영향을 줍니다.

 > **참고**
 >컴포넌트가 `Emulated`ViewEncapsulation을 사용하는 경우 `::ng-deep`를 사용하여 이 캡슐화를 `penetrate`해야 합니다:

```scss
:host {
    ::ng-deep {
        @include column-actions($custom-column-actions-theme);
        .igx-column-actions {
            @include button($custom-button);
        }
    }
}
```

### 색상 팔레트 정의하기

방금 한 것처럼 색상 값을 하드코딩하는 대신, `igx-palette`와 `igx-color` 함수를 사용하면 색상에 대해 더 큰 유연성을 얻을 수 있습니다.

`igx-palette`는 전달된 기본 색상과 보조 색상을 기준으로 색상 팔레트를 생성합니다:

```scss
$yellow-color: gold;
$blue-color: steelblue;

$custom-palette: palette($primary: $blue-color, $secondary: $yellow-color);
```

그다음 `igx-color`로 팔레트에서 색상을 쉽게 가져올 수 있습니다.

```scss
$custom-column-actions-theme: column-actions-theme(
    $title-color: color($custom-palette, "secondary", 400),
    $background-color: color($custom-palette, "primary", 200)
);

$custom-button: flat-button-theme(
    $foreground: color($custom-palette, "secondary", 400),
    $disabled-foreground: black
);
```

> **참고**
>`igx-color`와 `igx-palette`는 색상을 생성하고 검색하는 강력한 함수입니다. 사용 방법에 대한 자세한 안내는 [팔레트](../themes/sass/palettes.mdx) 토픽을 참조하십시오.

### 스키마 사용하기

테마 엔진을 더 활용하여 [**스키마**](themes/sass/schemas.mdx)의 이점을 얻는 견고하고 유연한 구조를 만들 수 있습니다. **스키마**는 테마의 레시피입니다.

```scss
// Extending the dark column actions schema
$custom-column-actions-schema: extend($_dark-column-actions,
    (
        title-color:(
           color: ("secondary", 400)
        ),
        background-color:(
           color: ("primary", 200)
        )
    )
);
// Extending the dark button schema
$custom-button-schema: extend($_dark-button,
    (
        flat-text-color:(
           color: ("secondary", 500)
        ),
        disabled-color:(
           color: ("primary", 700)
        )
    )
);
```

사용자 지정 스키마를 적용하려면 전역 `light` 또는 `dark` 중 하나를 **확장**해야 합니다. 이는 사실상 사용자 지정 스키마가 있는 컴포넌트를 지정하는 것이며, 그런 다음 이를 해당 컴포넌트 테마에 추가합니다:

```scss
// Extending the global dark-schema
$custom-dark-schema: extend($dark-schema,(
    igx-column-actions: $custom-column-actions-schema,
    igx-button: $custom-button-schema
));

// Defining column-actions-theme with the global dark schema
$custom-column-actions-theme: column-actions-theme(
  $schema: $custom-dark-schema
);

// Defining flat-button-theme with the global dark schema
$custom-button: flat-button-theme(
  $schema: $custom-dark-schema
);
```

위에서 보여 드린 것과 같은 방식으로 테마를 포함하는 것을 잊지 마십시오.
