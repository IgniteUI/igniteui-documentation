# {Platform} {ComponentTitle} 페이지 나누기 개요

{Platform} {ComponentTitle}의 {ProductName} 페이징 기능은 대량의 데이터 세트를 비슷한 내용의 페이지 순서로 나누는 데 사용됩니다. React 그리드 페이징은 사용자 경험과 데이터 상호 작용을 개선합니다. <ApiLink type="{ComponentName}" /> 페이징은 열을 추가하는 것과 비슷하게, 그리드 트리에 <ApiLink type="Paginator" /> 태그를 정의하여 프로젝션되는 별도의 컴포넌트를 통해 구성할 수 있습니다. 다른 {Platform} 테이블과 마찬가지로, {Platform} {ComponentTitle}의 페이징도 사용자 지정 페이지용 템플릿을 지원합니다.

## {Platform}의 페이지 나누기 스타일 지정

paginator의 스타일 지정을 시작하려면, 모든 테마 함수와 컴포넌트 믹스인이 있는 `index` 파일을 import해야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, `PaginatorTheme`을(를) 확장하고 `$text-color`, `$background-color` 및 `$border-color` 매개변수를 받는 새 테마를 만듭니다.

```scss
$dark-paginator: paginator-theme(
    $text-color: #F4D45C,
    $background-color: #575757,
    $border-color: #292826
);
```

보시다시피 `PaginatorTheme`는 페이징 컨테이너의 색상만 제어하고, 페이저 UI의 버튼에는 영향을 주지 않습니다. 페이저 버튼은 평면 아이콘 버튼이므로, 이들의 스타일을 지정하려면 새 아이콘 버튼 테마를 만드십시오:

```scss
$dark-button: flat-icon-button-theme(
    $foreground: #FFCD0F,
    $hover-foreground: #292826,
    $hover-background: #FFCD0F,
    $focus-foreground: #292826,
    $focus-background: #FFCD0F,
    $disabled-foreground: #16130C
);
```

이 예제에서는 아이콘 색상, 배경, 버튼 비활성화 색상만 바꿨지만, `flat-icon-button-theme`는 버튼 스타일을 제어하는 매개변수를 훨씬 더 많이 제공합니다.

마지막 단계는 각 컴포넌트 믹스인을 해당 테마와 함께 **포함**하는 것입니다:

```scss
@include grid-paginator($dark-grid-paginator);
.igx-grid-paginator__pager {
    @include button($dark-button);
}
```

<DocsAside type="info">
<ApiLink pkg="core" type="Button" /> 믹스인은 `.igx-paginator__pager` 안에 범위를 지정하여, paginator 버튼에만 스타일이 적용되도록 합니다. 그렇지 않으면 그리드의 다른 버튼도 영향을 받습니다.
</DocsAside>

<DocsAside type="info">
컴포넌트가 [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, `::ng-deep`를 사용하여 이 캡슐화를 `penetrate`해야 합니다:
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include paginator($dark-paginator);
        .igx-paginator__pager {
            @include button($dark-button);
        }
    }
}
```

### 색상 팔레트 정의하기

방금 한 것처럼 색상 값을 하드코딩하는 대신, `Palette`와 <ApiLink pkg="core" type="Color" /> 함수를 사용하면 색상에 대해 더 큰 유연성을 얻을 수 있습니다.

`Palette`는 전달된 기본 색상과 보조 색상을 기준으로 색상 팔레트를 생성합니다:

```scss
$yellow-color: #F9D342;
$black-color: #292826;

$dark-palette: palette($primary: $black-color, $secondary: $yellow-color);
```

그다음 <ApiLink pkg="core" type="Color" />로 팔레트에서 색상을 쉽게 가져올 수 있습니다.

```scss
$dark-paginator: paginator-theme(
    $text-color: color($dark-palette, "secondary", 400),
    $background-color: color($dark-palette, "primary", 200),
    $border-color: color($dark-palette, "primary", 500)
);

$dark-button: flat-icon-button-theme(
    $foreground: color($dark-palette, "secondary", 700),
    $hover-foreground: color($dark-palette, "primary", 500),
    $hover-background: color($dark-palette, "secondary", 500),
    $focus-foreground: color($dark-palette, "primary", 500),
    $focus-background: color($dark-palette, "secondary", 500),
    $disabled-foreground: color($dark-palette, "primary", 700)
);
```

<DocsAside type="info">
<ApiLink pkg="core" type="Color" />와 `Palette`는 색상을 생성하고 가져오는 강력한 함수입니다. 사용 방법에 대한 자세한 안내는 [팔레트](../themes/sass/palettes.mdx) 항목을 참조하십시오.
</DocsAside>

### 스키마 사용하기

 테마 엔진을 더 활용하여 [스키마](../themes/sass/schemas.mdx)의 이점을 얻는 견고하고 유연한 구조를 만들 수 있습니다. 스키마는 테마의 레시피입니다.

모든 컴포넌트에 제공되는 사전 정의된 스키마 두 가지 중 하나를 확장하십시오. 이 경우에는 `DarkPagination` 및 `DarkButton` 스키마입니다:

```scss
// Extending the dark paginator schema
$dark-paginator-schema: extend($_dark-pagination,
        (
            text-color:(
               color: ("secondary", 400)
            ),
            background-color:(
               color: ("primary", 200)
            ),
            border-color:(
               color: ("primary", 500)
            )
        )
);
// Extending the dark button schema
$dark-button-schema: extend($_dark-button,
        (
            icon-color:(
               color: ("secondary", 700)
            ),
            icon-hover-color:(
               color: ("primary", 500)
            ),
            icon-hover-background:(
               color: ("secondary", 500)
            ),
            icon-focus-color:(
               color: ("primary", 500)
            ),
            icon-focus-background:(
               color: ("secondary", 500)
            ),
            disabled-color:(
               color: ("primary", 700)
            )
        )
);
```

사용자 지정 스키마를 적용하려면 전역 `Light` 또는 `Dark` 중 하나를 **확장**해야 합니다. 이는 사실상 사용자 지정 스키마가 있는 컴포넌트를 지정하는 것이며, 그런 다음 이를 해당 컴포넌트 테마에 추가합니다:

```scss
// Extending the global dark-schema
$custom-dark-schema: extend($dark-schema,(
    igx-paginator: $dark-paginator-schema,
    igx-button: $dark-button-schema
));

// Definingpaginator-theme with the global dark schema
$dark-paginator: paginator-theme(
  $schema: $custom-dark-schema
);

// Defining flat-icon-button-theme with the global dark schema
$dark-button: flat-icon-button-theme(
  $schema: $custom-dark-schema
);
```

위에서 보여 드린 것과 같은 방식으로 테마를 포함하는 것을 잊지 마십시오.
