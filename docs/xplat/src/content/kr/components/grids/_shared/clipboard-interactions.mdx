## 기능

복사 동작은 브라우저와 운영체제가 정의한 기본 상호 작용을 따릅니다. 따라서 복사와 붙여넣기 동작은 다음과 같습니다:

- Windows/Unix 계열
  - 키보드 단축키로 <kbd>CTRL</kbd> + <kbd>C</kbd> / <kbd>CTRL</kbd> + <kbd>Ins</kbd> 사용
  - 키보드 단축키로 <kbd>CTRL</kbd> + <kbd>V</kbd> / <kbd>SHIFT</kbd> + <kbd>Ins</kbd> 사용
  - 브라우저 메뉴를 통한 복사 작업
- macOS
  - 키보드 단축키로 <kbd>CMD</kbd> + <kbd>C</kbd> 사용
  - 키보드 단축키로 <kbd>CMD</kbd> + <kbd>V</kbd> 사용
  - 브라우저 메뉴를 통한 복사 작업


## 제한 사항

- **cut** 및 **copy** 이벤트는 모두 Internet Explorer에서 기본적으로 지원되지 않습니다. 예외는

**paste** 이벤트(IE 11)이며, 이 이벤트는 발생하지만 <PlatformBlock for="Angular"><ApiLink type="IClipboardOptions" label="ClipboardData" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="ClipboardOptions" label="ClipboardData" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="ClipboardOptions" label="ClipboardData" /></PlatformBlock> 속성을 이벤트에 노출하지 않습니다.
<DocsAside type="info">
IE 11에서 셀을 **복사**하려면 키보드 선택을 사용할 수 있습니다. <kbd>SHIFT</kbd> 키를 누른 채 다중 셀 선택을 만들고 <kbd>CTRL</kbd> + <kbd>C</kbd>를 눌러 복사하십시오.
</DocsAside>

- 그리드가 편집 모드에 있는 동안에는 복사 동작이 비활성화됩니다.
- 이 기능의 현재 버전은 그리드에서 **복사**하는 동작만 다룹니다. 이후 그리드 내에서 `paste` 기능도 제공할 계획입니다.

## API 사용법

다음 옵션을 처리하는 <ApiLink type="{ComponentName}" member="clipboardOptions" /> 속성을 제공합니다:
- <PlatformBlock for="Angular"><ApiLink type="IClipboardOptions" member="enabled" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="ClipboardOptions" member="enabled" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="ClipboardOptions" member="enabled" /></PlatformBlock> 선택한 셀의 복사를 활성화하거나 비활성화합니다.
- <PlatformBlock for="Angular"><ApiLink type="IClipboardOptions" member="copyHeaders" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="ClipboardOptions" member="copyHeaders" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="ClipboardOptions" member="copyHeaders" /></PlatformBlock> 복사할 때 연결된 헤더를 포함합니다.
- <PlatformBlock for="Angular"><ApiLink type="IClipboardOptions" member="copyFormatters" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="ClipboardOptions" member="copyFormatters" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="ClipboardOptions" member="copyFormatters" /></PlatformBlock> 복사된 데이터에 기존 열 포맷터를 적용합니다.
- <PlatformBlock for="Angular"><ApiLink type="IClipboardOptions" member="separator" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="ClipboardOptions" member="separator" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="ClipboardOptions" member="separator" /></PlatformBlock> 클립보드의 데이터 서식 지정에 사용할 문자열 구분자입니다. 기본값은 `/t`입니다

<DocsAside type="info">
Excel은 탭으로 구분된 텍스트(탭으로 구분된 `/t`)를 자동으로 감지하고 데이터를 별도의 열에 올바르게 붙여넣을 수 있습니다. 붙여넣기 형식이 작동하지 않고 붙여넣은 모든 내용이 한 열에 나타난다면, Excel의 구분 기호가 다른 문자로 설정되어 있거나 텍스트가 탭 대신 공백을 사용하고 있는 것입니다.
</DocsAside>

- <PlatformBlock for="WebComponents"><ApiLink type="GridComponentEventMap" member="gridCopy" label="gridCopy" /></PlatformBlock><PlatformBlock for="React"><ApiLink type="Grid" member="onGridCopy" label="gridCopy" /></PlatformBlock><PlatformBlock for="Angular"><ApiLink type="Grid" member="gridCopy" label="gridCopy" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="Grid" member="gridCopy" label="gridCopy" /></PlatformBlock> 복사 작업이 실행될 때 발생합니다. <ApiLink type="{ComponentName}" member="clipboardOptions" />를 통해 복사 동작이 활성화된 경우에만 발생합니다.
