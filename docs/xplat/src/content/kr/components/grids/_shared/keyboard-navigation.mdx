# {Platform} {ComponentTitle} 키보드 탐색

 {Platform} {ComponentTitle}의 {ProductName} 키보드 탐색 기능은 사용자에게 다양한 키보드 상호 작용을 제공합니다. 이 기능은 <ApiLink type="{ComponentName}" />의 접근성을 높이고, 사용자가 내부의 모든 유형의 요소(셀, 행, 열 머리글, 도구 모음, 바닥글 등)를 탐색할 수 있도록 합니다. 이 기능은 기본적으로 활성화되어 있으며, 개발자는 쉬운 방식으로 기본 동작을 재정의할 수 있습니다.

<ApiLink type="{ComponentName}" />의 탭 정지 지점이 줄어들어, 탐색이 W3C 접근성 표준을 준수하며 사용하기 편리해졌습니다.

현재 <ApiLink type="{ComponentName}" />은(는) 다음 탭 정지 지점을 도입합니다:

- **그룹화 또는 도구 모음 영역**(활성화된 경우).
- **{ComponentTitle} 머리글**.
- **{ComponentTitle} 본문**.
- **열 요약**(활성화된 경우).
- **{ComponentTitle} 페이지 탐색기**(활성화된 경우).


<DocsAside type="info">
이 변경으로 인해 <ApiLink type="{ComponentName}" />에서는 <kbd>TAB</kbd>과 <kbd>SHIFT</kbd> + <kbd>TAB</kbd>으로 셀 사이를 이동하는 기능이 더 이상 지원되지 않습니다.
이제 <kbd>TAB</kbd> 키를 누르면 다음 순서로 탭 정지 지점을 거칩니다: **그룹화** / **도구 모음** -> **머리글** -> **본문** -> **요약** -> **바닥글 / 페이지 탐색기**.
</DocsAside>

<DocsAside type="info">
템플릿을 통해 <ApiLink type="{ComponentName}" /> 본문에 **포커스 가능한** 요소를 노출하면, 브라우저의 기본 동작이 막히지 않기 때문에 키보드 탐색에 **부작용**이 생길 수 있습니다. 이를 적절히 막거나 수정하는 것은 개발자의 책임입니다.
</DocsAside>

## 머리글 탐색

이제 <ApiLink type="{ComponentName}" /> 머리글에 대한 완전한 **키보드 탐색** 지원이 도입되었습니다. 열 머리글은 화살표 키로 쉽게 이동할 수 있습니다. 또한 **필터링**, **정렬**, **그룹화** 등 열에 대한 작업을 실행하는 여러 키 조합이 있습니다.
<ApiLink type="{ComponentName}" /> 머리글 컨테이너에 포커스가 있을 때 다음 키 조합을 사용할 수 있습니다:

### 키 조합

- <kbd>↑</kbd>는 머리글에서 한 셀 위로 이동합니다(순환하지 않음). 다중 행 레이아웃(MRL) 또는 다중 열 머리글(MCH)이 정의된 경우에만 사용할 수 있습니다.
- <kbd>↓</kbd>는 머리글에서 한 셀 아래로 이동합니다(순환하지 않음). 다중 행 레이아웃(MRL) 또는 다중 열 머리글(MCH)이 정의된 경우에만 사용할 수 있습니다.
- <kbd>←</kbd>는 한 셀 왼쪽으로 이동합니다(순환하지 않음).
- <kbd>→</kbd>는 한 셀 오른쪽으로 이동합니다(줄 사이에서 순환하지 않음).
- <kbd>CTRL</kbd> + <kbd>←</kbd>는 행에서 가장 왼쪽 셀로 이동합니다. MRL 또는 MCH가 활성화된 경우에는 같은 수준에서 가장 왼쪽 셀로 이동합니다.
- <kbd>HOME</kbd>은 행에서 가장 왼쪽 셀로 이동합니다. MRL 또는 MCH가 활성화된 경우에는 같은 수준에서 가장 왼쪽 셀로 이동합니다.
- <kbd>CTRL</kbd> + <kbd>→</kbd>는 행에서 가장 오른쪽 셀로 이동합니다. MRL 또는 MCH가 활성화된 경우에는 같은 수준에서 가장 오른쪽 셀로 이동합니다.
- <kbd>END</kbd>는 행에서 가장 오른쪽 셀로 이동합니다. MRL 또는 MCH가 활성화된 경우에는 같은 수준에서 가장 오른쪽 셀로 이동합니다.
- <kbd>ALT</kbd> + <kbd>L</kbd>은 고급 필터링이 활성화된 경우 고급 필터링 대화 상자를 엽니다.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>L</kbd>은 열이 필터링 가능하면 Excel 스타일 필터 대화 상자 또는 기본(행) 필터를 엽니다.
- <kbd>CTRL</kbd> + <kbd>↑</kbd>는 활성 열 머리글을 오름차순으로 정렬합니다. 열이 이미 오름차순으로 정렬되어 있다면 정렬 상태가 해제됩니다.
- <kbd>CTRL</kbd> + <kbd>↓</kbd>는 활성 열 머리글을 내림차순으로 정렬합니다. 열이 이미 내림차순으로 정렬되어 있다면 정렬 상태가 해제됩니다.
- <kbd>SPACE</kbd>는 열을 선택합니다. 열이 이미 선택되어 있다면 선택이 해제됩니다.
<ComponentBlock for="Grid">
- <kbd>SHIFT</kbd> + <kbd>ALT</kbd> + <kbd>←</kbd>는 열이 그룹화 가능으로 표시된 경우 열을 그룹화합니다.
</ComponentBlock>
- <kbd>SHIFT</kbd> + <kbd>ALT</kbd> + <kbd>→</kbd>는 열이 그룹화 가능으로 표시된 경우 열의 그룹화를 해제합니다.
- <kbd>ALT</kbd> + <kbd>←</kbd> 또는 <kbd>ALT</kbd> + <kbd>↑</kbd>는 열 그룹 머리글이 이미 접혀 있지 않은 경우 열 그룹 머리글을 접습니다.
- <kbd>ALT</kbd> + <kbd>→</kbd> 또는 <kbd>ALT</kbd> + <kbd>↓</kbd>는 열 그룹 머리글이 이미 펼쳐져 있지 않은 경우 열 그룹 머리글을 펼칩니다.

## 사용자 지정 키보드 탐색

특정 키 또는 키 조합에 대한 기본 동작을 재정의하는 것은 **키보드 탐색** 기능이 제공하는 장점 중 하나입니다. 예를 들어 <kbd>ENTER</kbd> 또는 <kbd>TAB</kbd> 키를 눌러 다음 셀이나 아래 셀로 이동할 수 있습니다. 이 탐색 시나리오나 다른 탐색 시나리오는 **키보드 탐색** API로 쉽게 구현할 수 있습니다:

|---------|-------------|-----------|
| <ApiLink type="{ComponentName}" member="gridKeydown" /> | 위에서 설명한 키 입력/조합 중 어느 것이든 수행될 때 발생하는 이벤트입니다. 취소할 수 있습니다. 그 밖의 다른 키 입력/조합에는 기본 `onkeydown` 이벤트를 사용하십시오. | <ApiLink type="GridKeydownEventArgs" /> |
| <ApiLink type="{ComponentName}" member="activeNodeChange" /> | 활성 노드가 바뀔 때 발생하는 이벤트입니다. 이를 사용하여 활성 포커스 위치(머리글, tbody 등), 열 인덱스, 행 인덱스 또는 중첩 수준을 확인할 수 있습니다. | <ApiLink type="ActiveNodeChangeEventArgs" /> |
