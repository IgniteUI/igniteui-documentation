## 선택 유형

### {ComponentTitle} 다중 셀 선택

<ComponentBlock for="HierarchicalGrid">
이는 상위 그리드와 하위 그리드 모두의 기본 셀 선택 모드입니다. 셀 선택은 한 번에 한 그리드에서만 할 수 있으며, 그리드를 가로지르는 범위 선택이나 여러 그리드에 걸친 선택 셀은 만들 수 없다는 점을 기억하십시오. 범위 선택과 마우스 드래그 기능과 관련된 각 키 조합은 같은 그리드 안에서만 사용할 수 있습니다.
</ComponentBlock>

셀을 선택하는 방법:
- **마우스 드래그**로 - 셀의 직사각형 데이터 선택이 수행됩니다.
- <kbd>CTRL</kbd> 키를 누른 채 **마우스 드래그**를 하면 여러 범위가 선택됩니다. 기존의 다른 셀 선택은 유지됩니다.
- <kbd>SHIFT</kbd> 키를 사용한 즉시 다중 셀 선택. 단일 셀을 선택한 다음 <kbd>SHIFT</kbd> 키를 누른 채 다른 단일 셀을 선택하십시오. 두 셀 사이의 셀 범위가 선택됩니다. <kbd>SHIFT</kbd> 키를 누른 채 두 번째 셀을 다시 선택하면 셀 선택 범위는 처음 선택한 셀의 위치(시작점)를 기준으로 업데이트된다는 점에 유의하십시오.
- <kbd>Arrow</kbd> 키와 <kbd>SHIFT</kbd> 키를 누른 상태에서 사용하는 키보드 다중 셀 선택. 다중 셀 선택 범위는 포커스된 셀을 기준으로 생성됩니다.
- <kbd>CTRL</kbd> + <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> 키와 <kbd>CTRL</kbd> + <kbd>HOME</kbd>/<kbd>END</kbd> 키를 사용하고 <kbd>SHIFT</kbd> 키를 누른 상태를 유지하는 키보드 다중 셀 선택. 다중 셀 선택 범위는 포커스된 셀을 기준으로 생성됩니다.
- **마우스 왼쪽** 버튼을 클릭하면서 <kbd>CTRL</kbd> 키를 누르고 있으면 선택된 셀 컬렉션에 단일 셀 범위가 추가됩니다.
- 마우스로 클릭한 채 끌면 연속된 다중 셀 선택이 가능합니다.

### {ComponentTitle} 단일 선택

<ApiLink type="{ComponentName}" member="cellSelection" /> 속성을 **single**로 설정하면 그리드에서 한 번에 하나의 셀만 선택할 수 있습니다. 또한 **마우스 드래그** 모드는 작동하지 않으며, 셀을 선택하는 대신 기본 텍스트 선택이 수행됩니다.

> 단일 셀이 선택되면 **선택 모드**가 **single**이든 **multiple**이든 상관없이 <ApiLink type="Column" member="selected" /> 이벤트가 발생합니다. 다중 셀 선택 모드에서 셀 범위를 선택하면 <ApiLink type="{ComponentName}" member="rangeSelected" /> 이벤트가 발생합니다.

### {ComponentTitle} 선택 없음

셀 선택을 비활성화하려면 <ApiLink type="{ComponentName}" member="cellSelection" /> 속성을 **none** 값으로 설정하면 됩니다. 이 모드에서는 셀을 클릭하거나 키보드로 이동해도 셀이 **선택되지 않고** **활성화 스타일**만 적용되며, 이 스타일은 스크롤하거나 페이지의 다른 요소를 클릭하면 사라집니다. 선택을 정의하는 유일한 방법은 아래에 설명된 API 메서드를 사용하는 것입니다.

## 키보드 탐색 상호 작용

### Shift 키를 누르고 있는 동안

- <kbd>SHIFT</kbd> + <kbd>↑</kbd>: 위쪽 셀을 현재 선택에 추가합니다.
- <kbd>SHIFT</kbd> + <kbd>↓</kbd>: 아래쪽 셀을 현재 선택에 추가합니다.
- <kbd>SHIFT</kbd> + <kbd>←</kbd>: 왼쪽 셀을 현재 선택에 추가합니다.
- <kbd>SHIFT</kbd> + <kbd>→</kbd>: 오른쪽 셀을 현재 선택에 추가합니다.

### Ctrl + Shift 키를 누르고 있는 동안

- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>↑</kbd>: 열에서 포커스된 셀 위쪽의 모든 셀을 선택합니다.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>↓</kbd>: 열에서 포커스된 셀 아래쪽의 모든 셀을 선택합니다.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>←</kbd>: 행의 시작까지 모든 셀을 선택합니다.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>→</kbd>: 행의 끝까지 모든 셀을 선택합니다.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>HOME</kbd>: 포커스된 셀부터 그리드의 첫 번째 셀까지 모든 셀을 선택합니다.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>END</kbd>: 포커스된 셀부터 그리드의 마지막 셀까지 모든 셀을 선택합니다.

<DocsAside type="info">
연속 스크롤은 그리드 본문 안에서만 가능합니다.
</DocsAside>

## 기능 통합

다중 셀 선택은 인덱스 기반입니다(DOM 요소 선택).

- <ApiLink type="{ComponentName}" member="sortingExpressions" label="Sorting" /> - 정렬을 수행해도 선택이 지워지지 않습니다. 오름차순 또는 내림차순으로 정렬하는 동안 현재 선택된 셀은 그대로 유지됩니다.
- <ApiLink type="{ComponentName}" member="pagingMode" label="Paging" /> - 페이징을 하면 선택된 셀이 지워집니다. 선택은 페이지를 넘어서 유지되지 않습니다.
- <ApiLink type="{ComponentName}" member="allowFiltering" label="Filtering" /> - 필터링을 수행해도 선택이 지워지지 않습니다. 필터링을 지우면 처음에 선택된 셀이 다시 나타납니다.
- <ApiLink type="Column" member="resizable" label="Resizing" /> - 열 크기를 조정해도 선택된 셀은 지워지지 않습니다.
- <ApiLink type="Column" member="hidden" label="Hiding" /> - 선택된 셀을 지우지 않습니다. 열이 숨겨져 있으면 다음 보이는 열의 셀이 선택됩니다.
- <ApiLink type="{ComponentName}" member="pinning" /> - 선택된 셀은 지워지지 않습니다. 숨기기와 동일합니다
- <ApiLink type="{ComponentName}" member="groupingExpressions" label="GroupBy" /> - 열 그룹화를 하면 선택된 셀이 지워지지 않습니다.

## 스타일링 가이드라인

테마 엔진은 **선택된 셀의 범위**를 스타일링할 수 있는 속성을 노출합니다.

### 테마 가져오기

선택 항목의 스타일링을 시작하려면 모든 테마 함수와 컴포넌트 믹스인이 있는 `index` 파일을 가져와야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### 색상 정의

가져오기가 끝나면 <ApiLink type="function-igx-contrast-color" label="igx-contrast-color" kind="sass" module="index.html" />과(와) <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" /> 함수를 사용할 수 있습니다. 이들을 사용하여 선택 범위에 사용할 색상을 정의합니다:

```scss
    $text-color:contrast-color($default-palette, 'primary', 900);
    $background-color: color($default-palette, "primary", 900);
    $border-yellow: #f2c43c;
```

### 사용자 지정 테마 만들기

다음으로 <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" />을(를) 확장하는 새 테마를 만듭니다. 우리의 `text-color`, `background-color` 및 `border-yellow` 변수를 각각 `$cell-selected-text-color`, `$cell-selected-background` 및 `$cell-active-border-color`로 전달합니다:

```scss
$custom-grid-theme: grid-theme(
    $cell-selected-text-color: $text-color,
    $cell-active-border-color: $border-yellow,
    $cell-selected-background: $background-color
);
```

### 테마 적용

그런 다음 컴포넌트의 스타일(앱 스타일에 두어도 됩니다)에 믹스인을 포함하기만 하면 @@igSelector가 기본 테마 대신 새로 만든 테마를 사용합니다:

```scss
    @include grid($custom-grid-theme);
```

 <DocsAside type="info">
 컴포넌트가 [Emulated ViewEncapsulation](../themes/styles.mdx#view-encapsulation)을 사용하는 경우 `::ng-deep`를 사용하여 이 캡슐화를 관통해야 합니다.
 애플리케이션에 있을 수 있는 다른 그리드에 영향을 주지 않도록 `:host` 셀렉터 아래로 스타일 범위를 지정합니다.
 </DocsAside>

 ```scss
    :host {
        ::ng-deep {
            @include grid($custom-grid-theme);
        }
    }
```


사용자 지정 테마를 적용하면 선택된 그리드 셀이 우리가 선택한 색상으로 강조 표시됩니다:
