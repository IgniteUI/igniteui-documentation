# {Platform} {ComponentTitle}의 행 작업

{Platform} {ComponentTitle}의 {ProductName} 행 작업 기능을 사용하면 개발자가 <ApiLink type="ActionStrip" />를 사용하고, 행/셀 컴포넌트에 대해 CRUD를 활용하며, 행 고정을 할 수 있습니다. 이러한 작업을 위해 미리 정의된 UI 컨트롤이 여러 개 있으며, 이는 <ApiLink type="{ComponentName}" />의 특정 행에 적용됩니다. 편집과 고정이 그것입니다.

## 사용법

<PlatformBlock for="Angular">
첫 번째 단계는 **app.module.ts** 파일에서 **IgxActionStripModule**을 가져오는 것입니다:

```typescript
// app.module.ts
import { IgxActionStripModule } from 'igniteui-angular';

@NgModule({
    imports: [..., IgxActionStripModule],
})
```

</PlatformBlock>

미리 정의된 작업 UI 컴포넌트는 다음과 같습니다:

- <ApiLink type="GridEditingActions" /> - <ApiLink type="{ComponentName}" /> 편집을 위해 특별히 설계된 기능과 UI를 포함합니다. <ApiLink type="{ComponentName}" member="rowEditable" /> 옵션과 <ApiLink type="{ComponentName}" />의 행 삭제 설정에 따라 셀 또는 행의 편집 모드를 빠르게 전환할 수 있습니다.

- <ApiLink type="GridPinningActions" /> - <ApiLink type="{ComponentName}" /> 행 고정을 위해 특별히 설계된 기능과 UI를 포함합니다. 행을 빠르게 고정하고, 고정된 행과 그 비활성 사본 사이를 이동할 수 있습니다.

이들은 <ApiLink type="{ComponentName}" /> 안에 추가되며, 기본 상호 작용을 제공하는 <ApiLink type="ActionStrip" />를 갖추기 위해 필요한 것은 이것이 전부입니다.

## 사용자 지정 구현

이 컴포넌트들은 사용자 지정을 위한 유연성을 제공하는 템플릿을 노출합니다. 예를 들어 **삭제**, **편집** 등의 행 작업이 있는 Gmail 시나리오에 <ApiLink type="ActionStrip" />를 사용하고 싶다면, 아이콘이 있는 버튼 컴포넌트를 만들고 클릭 이벤트를 추가한 다음 <ApiLink type="ActionStrip" />에 삽입하면 됩니다.


<PlatformBlock for="Angular">
```html
<{ComponentSelector}>
    <igx-action-strip #actionstrip>
        <igx-grid-pinning-actions></igx-grid-pinning-actions>
        <button title="Edit" igxButton="icon" igxRipple (click)='startEdit(actionstrip.context)'>
            <igx-icon>edit</igx-icon>
        </button>
        @if (!isDeleted(actionstrip.context)) {
            <button title="Delete" igxButton="icon" igxRipple (click)='actionstrip.context.delete()'>
                <igx-icon>delete</igx-icon>
            </button>
        }
    </igx-action-strip>
</{ComponentSelector}>
```
</PlatformBlock>

<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">
<PlatformBlock for="Blazor">
```razor

                DeleteRow="true"

            </IgbGridEditingActions>
        </IgbActionStrip>
    </{ComponentSelector}>
</div>
```
</PlatformBlock>
