## {ComponentTitle} 데이터 내보내기

IgniteUI Excel 및 PDF 내보내기 도구를 사용하려면, 먼저 app.module.ts 파일에서 <ApiLink type="ExcelExporterService" /> 및/또는 <ApiLink type="PdfExporterService" />를 import하고 서비스를 `providers` 배열에 추가하십시오:

```ts
// app.module.ts
import { ExcelExporterService, PdfExporterService } from 'igniteui-{Platform}';

@NgModule({
  providers: [ ExcelExporterService, PdfExporterService ]
})

export class AppModule {}
```

<DocsAside type="info">
v12.2.1 이후에는 내보내기 서비스가 root에 제공되므로, 더 이상 AppModule providers에 선언할 필요가 없습니다.
</DocsAside>

내보내기를 시작하려면 컴포넌트 템플릿의 버튼 핸들러를 사용할 수 있습니다.

```html
<{ComponentTitle} #{ComponentTitle} [data]="localData" [autoGenerate]="true"></{ComponentTitle}>
<button (click)="exportButtonHandler()">Export {ComponentTitle} to Excel</button>
<button (click)="exportPdfButtonHandler()">Export {ComponentTitle} to PDF</button>
```

<ApiLink type="ExcelExporterService" /> 또는 <ApiLink type="PdfExporterService" /> 형식의 생성자 인수를 정의하여 내보내기 서비스에 액세스할 수 있으며, {Platform} 프레임워크가 서비스 인스턴스를 제공합니다. Excel 또는 PDF로 데이터를 내보내려면 `Export` 메서드를 호출하고 첫 번째 인수로 {ComponentTitle} 컴포넌트를 전달하십시오.

다음 코드는 컴포넌트 파일에서 내보내기 과정을 실행합니다:

```ts
// component.ts
import { ExcelExporterService, ExcelExporterOptions, PdfExporterService, PdfExporterOptions } from 'igniteui-{Platform}';
import { {ComponentName} } from 'igniteui-{Platform}';

@ViewChild('{ComponentName}') public {ComponentName}: {ComponentName};

constructor(private excelExportService: ExcelExporterService, private pdfExportService: PdfExporterService) {
}

public exportButtonHandler() {
  this.excelExportService.export(this.{ComponentName}, new ExcelExporterOptions('ExportedDataFile'));
}

public exportPdfButtonHandler() {
  this.pdfExportService.export(this.{ComponentName}, new PdfExporterOptions('ExportedDataFile'));
}
```

모든 것이 제대로 작동하면 {ComponentTitle} 컴포넌트와 두 개의 내보내기 버튼이 보여야 합니다. 해당 버튼을 누르면 내보내기 과정이 시작되고, 브라우저가 <ApiLink type="{ComponentName}" /> 컴포넌트의 데이터를 Excel 또는 PDF 형식으로 담은 "ExportedDataFile.xlsx" 또는 "ExportedDataFile.pdf" 파일을 다운로드합니다.
</PlatformBlock>

## 모든 데이터 내보내기

**페이징**과 같은 원격 작업을 사용하면 그리드가 전체 데이터 세트에 한 번에 액세스하지 못할 수 있습니다. 이런 경우에는 [Excel 내보내기 서비스](../exporter-excel.mdx)를 사용하고, 가능하다면 전체 데이터 컬렉션을 전달하는 것을 권장합니다. 예:

```ts
public exportButtonHandler() {
  this.excelExportService.exportData(this.localData, new ExcelExporterOptions('ExportedDataFile'));
}
```

원격 데이터에 대해 PDF 다운로드를 제공하는 경우, 먼저 전체 데이터 세트를 가져온 다음 `export`를 호출하여 문서가 사용자가 기대하는 모습과 일치하도록 하는 것을 고려하십시오.

## 고정된 열 머리글이 있는 그리드 내보내기

기본적으로 Excel Exporter 서비스는 스크롤 가능한(고정되지 않은) 열 헤더로 그리드를 내보냅니다. 많은 시나리오에서 사용자가 레코드를 스크롤하는 동안에도 항상 보이도록 내보낸 Excel 파일 상단의 모든 헤더를 고정하려 할 수 있습니다. 이를 위해 `ExporterOption`를 설정하십시오 <PlatformBlock for="Angular"><ApiLink type="IGridToolbarExportEventArgs" member="freezeHeaders" /></PlatformBlock><PlatformBlock for="React"><ApiLink type="ExporterOptionsBase" member="freezeHeaders" /></PlatformBlock><PlatformBlock for="WebComponents"><ApiLink type="ExporterOptionsBase" member="freezeHeaders" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="GridToolbarExportEventArgs" member="freezeHeaders" /></PlatformBlock> `true`로 설정하십시오.

<DocsAside type="info">
PDF 내보내기는 문서 맨 위에 열 머리글 행을 자동으로 포함하므로, 독자가 파일을 열거나 인쇄할 때도 같은 맥락을 유지합니다.
</DocsAside>

## 내보내는 콘텐츠 사용자 지정하기

위 예제에서 Excel 내보내기 서비스는 사용 가능한 모든 데이터를 내보냅니다. 하지만 행이나 열 전체를 내보내지 않으려는 상황이 있을 수 있습니다. 이를 위해 각각 열과 행마다 발생하는 <ApiLink type="{ComponentName}" member="columnExporting" /> 및/또는 <ApiLink type="{ComponentName}" member="rowExporting" /> 이벤트를 구독하고, 이벤트 인수 객체의 `cancel` 속성을 `true`로 설정하여 이벤트를 취소하십시오.

다음 예제는 헤더가 "Age"이고 인덱스가 1인 열을 내보내기에서 제외합니다:

```ts
// component.ts

this.excelExportService.columnExporting.subscribe((args: IColumnExportingEventArgs) => {
  if (args.header == 'Age' && args.columnIndex == 1) {
      args.cancel = true;
  }
});
this.excelExportService.export(this.{ComponentTitle}, new ExcelExporterOptions('ExportedDataFile'));
```

<ApiLink type="{ComponentName}" /> 컴포넌트의 데이터를 내보낼 때, 내보내기 과정은 행 필터링과 열 숨기기 같은 기능을 고려하여 <ApiLink type="{ComponentName}" />에 보이는 데이터만 내보냅니다. <ApiLink type="ExcelExporterOptions" /> 또는 <ApiLink type="PdfExporterOptions" /> 객체의 속성을 설정하면 필터링된 행이나 숨겨진 열을 포함하도록 내보내기 서비스를 구성할 수 있습니다.
