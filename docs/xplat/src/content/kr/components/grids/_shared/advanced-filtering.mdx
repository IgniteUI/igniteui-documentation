# {Platform} {ComponentTitle} 고급 필터링

{Platform} {ComponentTitle}의 {ProductName} 고급 필터링을 사용하면, <ApiLink type="{ComponentName}" />의 모든 열에 걸친 필터링 조건이 있는 다양한 그룹을 만들 수 있는 대화 상자가 제공되어 데이터를 조작할 수 있습니다.

## 상호 작용

고급 필터링 대화 상자를 열려면 그리드 도구 모음의 **고급 필터링** 버튼을 클릭해야 합니다. 고급 필터가 적용되지 않았다면, **AND** 또는 **OR**로 연결된 필터링 조건 그룹을 만드는 것으로 시작해야 합니다. 그 후에 필터링 조건이나 하위 그룹을 추가할 수 있습니다.

필터링 조건을 추가하려면 <ApiLink type="Column" member="filterable" /> 열 중 하나, 열 <ApiLink type="Column" member="dataType" />를 기준으로 한 피연산자, 그리고 피연산자가 단항이 아닌 경우 값을 선택해야 합니다. 조건을 확정하면 조건 정보가 담긴 칩이 나타납니다. 칩에 마우스를 올리거나 클릭하면 이를 수정하거나, 바로 뒤에 다른 조건이나 그룹을 추가하는 옵션이 나타납니다.

필터링 조건 칩을 둘 이상 선택하면, 그룹을 만들거나 필터를 삭제하는 옵션이 있는 컨텍스트 메뉴가 나타납니다. 선택한 조건으로 그룹을 만들기로 하면, 새로 만든 그룹은 가장 위에 선택된 조건이 있던 자리에 나타납니다.

그룹을 선택하려면 연결 조건 **AND** 또는 **OR**에 따라 색이 지정된 세로선을 클릭할 수도 있습니다. 단일 그룹을 선택하면, 필터링 로직을 변경하거나, 그룹 해제하거나, 삭제하는 옵션이 있는 컨텍스트 메뉴가 나타납니다.

필터링 조건과 그룹을 준비했으면 데이터를 필터링하기 위해 **적용** 버튼을 클릭해야 합니다. 고급 필터를 수정했지만 변경 사항을 유지하고 싶지 않다면 **취소** 버튼을 클릭해야 합니다. **필터 지우기** 버튼을 클릭하여 고급 필터를 지울 수도 있습니다.

## 스타일링

고급 필터링 대화 상자의 스타일 지정을 시작하려면, 모든 테마 함수와 컴포넌트 믹스인이 있는 **index** 파일을 import해야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

고급 필터링 대화 상자는 **filtering-row-background** 매개변수를 사용하여 그리드의 테마에서 배경색을 가져옵니다. 배경을 바꾸려면 사용자 지정 테마를 만들어야 합니다:

```scss
$custom-grid: grid-theme(
    $filtering-row-background: #FFCD0F
);
```

고급 필터링 대화 상자 안에는 버튼, 칩, 드롭다운, 입력 같은 다른 컴포넌트도 있으므로, 각각에 대해 별도의 테마를 만들어야 합니다:

```scss
$custom-button: flat-button-theme(
    $disabled-foreground: gray,

);

$custom-button-group: button-group-theme(
    $item-background:  #292826,

);

$custom-input-group: input-group-theme(
    $box-background: #4a4a4a,

);

$custom-chip: chip-theme(
    $background: #FFCD0F,

);

$custom-drop-down: drop-down-theme(
    $background-color: #292826,

);
```

이 예제에서는 나열된 컴포넌트의 일부 매개변수만 바꿨지만, <ApiLink type="function-flat-button-theme" label="flat-button-theme" kind="sass" module="index.html" />, <ApiLink type="function-button-group-theme" label="button-group-theme" kind="sass" module="index.html" />, <ApiLink type="function-chip-theme" label="chip-theme" kind="sass" module="index.html" />, <ApiLink type="function-drop-down-theme" label="drop-down-theme" kind="sass" module="index.html" />, <ApiLink type="function-input-group-theme" label="input-group-theme" kind="sass" module="index.html" /> 테마는 각 스타일을 제어하는 훨씬 많은 매개변수를 제공합니다.

마지막 단계는 각 컴포넌트 믹스인을 해당 테마와 함께 **include**하는 것입니다. 고급 필터링 대화 상자 안의 다른 요소에 대한 스타일도 추가하겠습니다.

```scss

igx-advanced-filtering-dialog {
    @include button($custom-button);
    @include button-group($custom-button-group);
    @include input-group($custom-input-group);
    @include chip($custom-chip);
    @include drop-down($custom-drop-down);
    .igx-filter-empty__title {
        color: #FFCD0F
    }
    .igx-advanced-filter__header {
        color: #FFCD0F
    }
    .igx-filter-tree__expression-actions igx-icon {
        color: #FFCD0F
    }
    .igx-filter-tree__expression-actions igx-icon:hover {
        color: #ffe482
    }
    .igx-filter-tree__expression-actions igx-icon:focus {
        color: #ffe482
    }
    .igx-filter-contextual-menu {
        border: 1px solid #FFCD0F
    }
    .igx-filter-contextual-menu__close-btn {
        position: absolute !important;
        background: #292826 !important;
        border-color: #FFCD0F !important;
    }
    .igx-input-group__input::placeholder {
        color: gray;
    }
}
```

대부분의 컴포넌트 믹스인은 `igx-advanced-filtering-dialog` 안에 범위를 지정하여, 이 사용자 지정 테마가 고급 필터링 대화 상자 안에 중첩된 컴포넌트에만 영향을 주도록 합니다. 그렇지 않으면 애플리케이션의 다른 버튼, 칩, 입력, 드롭다운도 영향을 받게 됩니다.

### 색상 팔레트 정의하기

방금 한 것처럼 색상 값을 하드코딩하는 대신, <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" />와 <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" /> 함수를 사용하면 색상에 대해 더 큰 유연성을 얻을 수 있습니다.

`igx-palette`는 전달된 기본 색상과 보조 색상을 기준으로 색상 팔레트를 생성합니다:

```scss
$yellow-color: #FFCD0F;
$black-color: #292826;
$dark-palette: palette($primary: $yellow-color, $secondary: $black-color);
```

그다음 <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />로 팔레트에서 색상을 쉽게 가져올 수 있습니다.

```scss
$custom-grid: grid-theme(
    $filtering-row-background: color($dark-palette, "secondary", 400)
);

$custom-button: flat-button-theme(
    $disabled-foreground: color($dark-palette, "secondary", 100),

);

$custom-button-group: button-group-theme(
    $item-background: color($dark-palette, "secondary", 400),

);

$custom-input-group: input-group-theme(
    $box-background: color($dark-palette, "secondary", 200),

);

$custom-chip: chip-theme(
    $background: color($dark-palette, "primary", 400),

);

$custom-drop-down: drop-down-theme(
    $background-color: color($dark-palette, "secondary", 400),

);
```

<DocsAside type="info">
`igx-color`와 `igx-palette`는 색상을 생성하고 가져오는 강력한 함수입니다. 사용 방법에 대한 자세한 안내는 [팔레트](../themes/sass/palettes.mdx) 항목을 참조하십시오.
</DocsAside>

### 스키마 사용하기

테마 엔진을 더 활용하여 [**스키마**](../themes/sass/schemas.mdx)의 이점을 얻는 견고하고 유연한 구조를 만들 수 있습니다. **스키마**는 테마의 레시피입니다.

모든 컴포넌트에 제공되는 두 가지 사전 정의된 스키마 중 하나를 확장하십시오. 이 경우 <ApiLink type="variable-_light-grid" label="light-grid" kind="sass" module="index.html" />, <ApiLink type="variable-_light-button" label="light-button" kind="sass" module="index.html" />, <ApiLink type="variable-_light-button-group" label="light-button-group" kind="sass" module="index.html" />, <ApiLink type="variable-_light-chip" label="light-chip" kind="sass" module="index.html" />, <ApiLink type="variable-_light-input-group" label="light-input-group" kind="sass" module="index.html" />, <ApiLink type="variable-_light-drop-down" label="light-drop-down" kind="sass" module="index.html" /> 스키마입니다:

```scss
$grid-dark-palette: palette($primary: #11bd7b, $secondary: #e32057, $info: $black-color);

$custom-grid-schema: extend($_light-grid,
    (
        filtering-row-background:(
           color: ("info")
        )
    )
);

$custom-button-schema: extend($_light-button,
    (
        disabled-color:(
           color: ("secondary", 100)
        ),

    )
);

$custom-button-group-schema: extend($_light-button-group,
    (
        item-background:(
           color: ("secondary", 400)
        ),

    )
);

$custom-input-group-schema: extend($_light-input-group,
    (
        box-background:(
           color: ("secondary", 200)
        ),

    )
);

$custom-chip-schema: extend($_light-chip,
    (
        background:(
           color: ("primary", 400)
        ),

    )
);

$custom-drop-down-schema: extend($_light-drop-down,
    (
        background-color:(
           color: ("secondary", 400)
        ),

    )
);
```

사용자 지정 스키마를 적용하려면 전역(<ApiLink type="variable-light-schema" label="light" kind="sass" module="index.html" /> 또는 <ApiLink type="variable-dark-schema" label="dark" kind="sass" module="index.html" />) 중 하나를 **확장**해야 합니다. 이는 기본적으로 사용자 지정 스키마를 가진 컴포넌트를 지정하는 것이며, 그다음 해당 컴포넌트 테마에 추가합니다:

```scss
$custom-light-schema: extend($light-schema,(
    igx-grid: $custom-grid-schema,
    igx-button: $custom-button-schema,
    igx-button-group: $custom-button-group-schema,
    igx-input-group: $custom-input-group-schema,
    igx-chip: $custom-chip-schema,
    igx-drop-down: $custom-drop-down-schema
));

$custom-grid: grid-theme(
    $schema: $custom-light-schema
);

$custom-button: flat-button-theme(
    $schema: $custom-light-schema
);

$custom-button-group: button-group-theme(
    $schema: $custom-light-schema
);

$custom-input-group: input-group-theme(
    $schema: $custom-light-schema
);

$custom-chip: chip-theme(
    $schema: $custom-light-schema
);

$custom-drop-down: drop-down-theme(
    $schema: $custom-light-schema
);
```

위에서 보여 드린 것과 같은 방식으로 테마를 포함하는 것을 잊지 마십시오.

## 스타일링

기본 제공 테마 외에도, 사용 가능한 CSS 속성 몇 가지를 설정하여 그리드를 더 사용자 지정할 수 있습니다. 몇 가지 색상만으로 완전한 테마를 만드는 방법은 [테마 지정 항목](theming.mdx)을 참조하십시오.
일부 색상을 바꾸려면 먼저 그리드에 클래스를 설정해야 합니다:

<PlatformBlock for="WebComponents">
```html
<{ComponentSelector} class="grid"></{ComponentSelector}>
```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
<{ComponentSelector} className="grid"></{ComponentSelector}>
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```razor
<{ComponentSelector} class="grid"></{ComponentSelector}>
```
</PlatformBlock>

그다음 이 클래스에 관련 CSS 속성을 설정하십시오:

```css
.grid {
    --ig-query-builder-header-foreground: #512da8;
    --ig-query-builder-color-expression-group-and: #eb0000;
    --ig-query-builder-color-expression-group-or: #0000f3;
    --ig-query-builder-subquery-header-background: var(--ig-gray-300);
    --ig-query-builder-subquery-border-color: var(--ig-warn-500);
    --ig-query-builder-subquery-border-radius: 4px;
}
```
