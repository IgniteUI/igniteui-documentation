# {Platform} {ComponentTitle} 실시간 데이터 업데이트

{Platform} {ComponentTitle}의 {ProductName} 실시간 데이터 업데이트 기능은 그리드에 표시되는 데이터를 실시간 또는 실시간에 가까운 방식으로 업데이트할 수 있게 합니다. 이는 주식 시장 추적기, 실시간 스포츠 점수, IoT(사물 인터넷) 대시보드처럼 데이터가 끊임없이 바뀌는 앱에서 매우 유용합니다. <ApiLink type="{ComponentName}" />는 초당 수천 건의 업데이트를 처리하면서도 사용자 상호 작용에 계속 반응할 수 있습니다.

## Dock Manager 및 igxGrid 컴포넌트를 사용한 실시간 데이터 피드
이 데모의 목적은 [SignalR](https://dotnet.microsoft.com/apps/aspnet/signalr) 허브 백엔드를 사용하는 실시간 데이터 스트림으로 금융 화면 보드를 보여 주는 것입니다.
보시다시피 igxGrid 컴포넌트는 서버에서 오는 고빈도 업데이트를 쉽게 처리합니다. SignalR을 사용하는 ASP.NET Core 애플리케이션의 코드는 이 [공개 GitHub 저장소](https://github.com/IgniteUI/finjs-web-api)에서 찾을 수 있습니다.
<Sample src="/{ComponentSample}/finjs-dock-manager" height={700} alt="{Platform} {ComponentTitle} 서비스를 사용한 실시간 데이터 업데이트 예제" />




### 허브 연결 시작하기

signal-r.service는 연결과, 관리 가능한 매개변수인 **빈도**, **볼륨** 및 **실시간 업데이트 상태 토글**(시작/중지)의 업데이트를 처리합니다.

```ts
this.hubConnection = new signalR.HubConnectionBuilder()
        .configureLogging(signalR.LogLevel.Trace)
        .withUrl('https://www.infragistics.com/angular-apis/webapi/streamHub')
        .build();
    this.hubConnection
        .start()
        .then(() => {
            this.hasRemoteConnection = true;
            this.registerSignalEvents();
            this.broadcastParams(interval, volume, live, updateAll);
        })
        .catch(() => {});
```

지정된 빈도에 따라 그리드는 서버에서 총 30건의 새 업데이트를 받게 됩니다. 변경을 처리하는 세 열(Price, Change, Change in percent)에는 특정 cellStyle 클래스가 적용됩니다.

### 업데이트 빈도와 데이터 볼륨

왼쪽의 작업 패널을 사용하여 데이터 피드의 빈도와 요청된 데이터의 볼륨을 관리할 수 있습니다. 모든 그리드는 같은 데이터 소스를 사용합니다. 다른 작업 요소를 자유롭게 사용하여 **데이터 피드를 중지**하거나, **애플리케이션 테마**를 바꾸거나, igxGrid가 있는 **DockSlot 컨테이너를 동적으로 추가**할 수 있습니다.

특정 주기로 새 데이터 세트를 요청하기 위해 `updateParameters` 메서드를 사용합니다. 이 메서드는 SignalR [스트림 허브 구현](https://github.com/IgniteUI/finjs-web-api/blob/master/WebAPI/Models/StreamHub.cs#L18)의 일부입니다.

```ts
this.hubConnection.invoke('updateparameters', frequency, volume, live, updateAll)
    .then(() => console.log('requestLiveData', volume))
    .catch(err => {
        console.error(err);
    });
```

### DockSlot 및 Grid 컴포넌트를 동적으로 만들기

[ComponentFactoryResolver](https://angular.io/api/core/ComponentFactoryResolver)를 사용하여 DockSlot 및 Grid 컴포넌트를 즉석에서 만들 수 있습니다.

### DockManager 컴포넌트
[Dock Manager](../../layouts/dock-manager.mdx) 웹 컴포넌트를 활용하여, 도킹된 패널이나 플로팅 패널을 사용해 자신만의 웹 뷰를 만들어 보십시오. 새 플로팅 패널을 추가하려면, 오른쪽의 작업 창을 열고 'Add floating pane' 버튼을 클릭하십시오. 새 패널을 원하는 위치로 끌어다 놓으십시오.
