# {Platform} {ComponentTitle} 정렬

{Platform} {ComponentTitle}의 {ProductName} 데이터 정렬 기능은 열 단위로 활성화되므로, <ApiLink type="{ComponentName}" />에는 정렬 가능한 열과 정렬할 수 없는 열이 섞여 있을 수 있습니다. {Platform} 정렬 작업을 수행하면 지정된 기준에 따라 레코드의 표시 순서를 바꿀 수 있습니다.

<PlatformBlock for="Angular">
<DocsAside type="info">
지금까지는 그룹화와 정렬이 함께 동작했습니다. 13.2 버전에서는 그룹화를 정렬과 분리하는 새 동작이 도입되었습니다. 예를 들어 그룹화를 지워도 그리드의 정렬 표현식은 지워지지 않으며, 그 반대도 마찬가지입니다. 다만 열이 정렬되고 그룹화되어 있다면 그룹화 표현식이 우선합니다.
</DocsAside>

</PlatformBlock>

## 초기 정렬 상태

## 정렬 표시기 템플릿

열 머리글의 정렬 표시기 아이콘은 템플릿을 사용하여 사용자 지정할 수 있습니다. 모든 정렬 상태(오름차순, 내림차순, 없음)에 대한 정렬 표시기를 템플릿화할 때 다음 속성을 사용할 수 있습니다:

<PlatformBlock for="Angular">

```html

    <igx-icon>unfold_more</igx-icon>
</ng-template>
```

</PlatformBlock>

- <ApiLink type="{ComponentName}" member="sortHeaderIconTemplate" /> - 정렬이 적용되지 않았을 때 정렬 아이콘을 다시 템플릿화합니다.

## 스타일링

정렬 동작의 스타일 지정을 시작하려면, 모든 테마 함수와 컴포넌트 믹스인이 있는 `index` 파일을 import해야 합니다:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

가장 간단한 방법으로, <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" />을(를) 확장하고 `$sorted-header-icon-color` 및 `sortable-header-icon-hover-color` 매개변수를 받는 새 테마를 만듭니다.

```scss
$custom-theme: grid-theme(
    $sorted-header-icon-color: #ffb06a,
    $sortable-header-icon-hover-color: black
);
```

마지막 단계는 컴포넌트 믹스인을 **include**하는 것입니다:

```scss
 @include grid($custom-theme);
```

<DocsAside type="info">
컴포넌트가 [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, `::ng-deep`를 사용하여 이 캡슐화를 `penetrate`해야 합니다:
</DocsAside>

 ```scss
:host {
    ::ng-deep {
        @include grid($custom-theme);
    }
}
```

### 색상 팔레트 정의하기

방금 한 것처럼 색상 값을 하드코딩하는 대신, <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" />와 <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" /> 함수를 사용하면 색상에 대해 더 큰 유연성을 얻을 수 있습니다.

`igx-palette`는 전달된 기본 색상과 보조 색상을 기준으로 색상 팔레트를 생성합니다:

```scss
$black-color: black;
$orange-color: #ffb06a;

$custom-palette: palette($primary: $black-color, $secondary: $orange-color);
```

그다음 <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />로 팔레트에서 색상을 쉽게 가져올 수 있습니다.

```scss
$custom-theme: grid-theme(
    $sorted-header-icon-color: color($custom-palette, "secondary", 500),
    $sortable-header-icon-hover-color: color($custom-palette, "primary", 500)
);
```

<DocsAside type="info">
`igx-color`와 `igx-palette`는 색상을 생성하고 가져오는 강력한 함수입니다. 사용 방법에 대한 자세한 안내는 [팔레트](../themes/sass/palettes.mdx) 항목을 참조하십시오.
</DocsAside>

### 스키마 사용하기

테마 엔진을 더 활용하여 [**스키마**](../themes/sass/schemas.mdx)의 이점을 얻는 견고하고 유연한 구조를 만들 수 있습니다. **스키마**는 테마의 레시피입니다.

모든 컴포넌트에 제공되는 사전 정의된 스키마 두 가지 중 하나를 확장하십시오. 이 경우에는 <ApiLink type="variable-_light-grid" label="_light-grid" kind="sass" module="index.html" />입니다:

```scss
// Extending the light grid schema
$custom-grid-schema: extend($_light-grid,
    (
        sorted-header-icon-color: (igx-color:('secondary', 500)),
        sortable-header-icon-hover-color: (igx-color:('primary', 500))
    )
);
```

사용자 지정 스키마를 적용하려면 전역(<ApiLink type="variable-light-schema" label="light" kind="sass" module="index.html" /> 또는 <ApiLink type="variable-dark-schema" label="dark" kind="sass" module="index.html" />) 중 하나를 **확장**해야 합니다. 이는 기본적으로 사용자 지정 스키마를 가진 컴포넌트를 지정하는 것이며, 그다음 해당 컴포넌트 테마에 추가합니다:

```scss
// Extending the global light-schema
$my-custom-schema: extend($light-schema,
    (
        igx-grid: $custom-grid-schema
    )
);

// Defining our custom theme with the custom schema
$custom-theme: grid-theme(
  $palette: $custom-palette,
  $schema: $my-custom-schema
);
```

위에서 보여 드린 것과 같은 방식으로 테마를 포함하는 것을 잊지 마십시오.
