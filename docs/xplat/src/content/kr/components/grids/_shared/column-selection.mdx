# {Platform} {ComponentTitle} 열 선택 개요

{ProductName}의 {Platform} {ComponentTitle} 열 선택 기능은 단일 클릭으로 열 전체를 선택하고 강조 표시하는, 단순하고 Excel과 비슷한 방식을 제공합니다. 이 기능은 <ApiLink type="{ComponentName}" member="columnSelection" /> 입력을 통해 활성화할 수 있습니다. 풍부한 API 덕분에 선택 상태를 쉽게 조작하고, 선택한 항목에서 데이터를 추출하며, 데이터 분석 작업과 시각화를 수행할 수 있습니다.

## 기본 사용법

열 선택 기능은 <ApiLink type="GridSelectionMode" /> 값을 받는 <ApiLink type="{ComponentName}" member="columnSelection" /> 입력을 통해 활성화할 수 있습니다.

## 상호 작용

기본 선택 모드는 `None`입니다. `Single` 또는 `Multiple`로 설정하면 표시된 모든 열이 <ApiLink type="Column" member="selectable" />됩니다. 이 말은 열을 선택하려면 열을 하나 클릭하기만 하면 되며, 그러면 해당 열이 <ApiLink type="Column" member="selected" />로 표시된다는 뜻입니다. 열을 선택할 수 없는 경우에는 마우스를 올려도 머리글에 선택 스타일이 적용되지 않습니다.

<DocsAside type="info">
[다중 열 머리글](multi-column-headers.mdx) 기능은 <ApiLink type="{ComponentName}" member="selectable" /> 입력에 반영되지 않습니다. <ApiLink type="ColumnGroupComponent" />는 하위 항목 중 하나라도 선택 동작이 활성화되어 있으면 <ApiLink type="{ComponentName}" member="selectable" /> 상태가 됩니다. 또한 모든 <ApiLink type="{ComponentName}" member="selectable" /> 하위 항목이 <ApiLink type="{ComponentName}" member="selected" />이면 컴포넌트는 <ApiLink type="{ComponentName}" member="selected" />로 표시됩니다.
</DocsAside>

## 키보드 조합

<DocsAside type="info">
키보드 조합은 그리드의 <ApiLink type="{ComponentName}" member="columnSelection" /> 입력이 `multiple`(으)로 설정된 경우에만 사용할 수 있습니다.
</DocsAside>

**열 선택** 기능의 키보드 탐색에는 두 가지 시나리오가 있습니다:
- 다중 열 선택 - <kbd>CTRL</kbd> + <kbd>클릭</kbd>을 모든 **선택 가능한** 헤더 셀에서 수행합니다.
- 범위 열 선택 - <kbd>SHIFT</kbd> + <kbd>클릭</kbd>을 수행하면 그 사이의 모든 **선택 가능한** 열이 선택됩니다.

## API 조작

**API**는 **보이지 않는** 열에 대해 몇 가지 추가 기능을 제공합니다. 즉, 해당 **setter**를 설정하여 모든 **숨겨진** 열을 <ApiLink type="Column" member="selected" />(으)로 표시할 수 있습니다.

<DocsAside type="info">
위 설명은 <ApiLink type="ColumnGroupComponent" />에도 적용되며, 다만 <ApiLink type="{ComponentName}" member="selected" /> 속성이 바뀌면 그 하위 항목의 상태도 바뀐다는 점이 다릅니다.
</DocsAside>

API 조작에 대한 자세한 정보는 [API 참조](#api-참조) 섹션에서 확인할 수 있습니다.

## 스타일링

스타일 옵션을 살펴보기 전에, 코어 모듈과 모든 컴포넌트 믹스인을 import해야 합니다.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```


<ComponentBlock for="Grid">
>[행 선택](row-selection.mdx)과 [열 선택](column-selection.mdx)은 서로 독립적으로 조작할 수 없습니다. 둘은 같은 `variables`에 의존합니다.
</ComponentBlock>

그렇다면 이제 **선택** 및 **마우스 오버** 스타일을 바꿔 봅시다. <br/>

가장 단순한 방식을 따라, 사용자 지정 **테마**를 정의해 봅시다.

<ComponentBlock for="TreeGrid">
```scss
$custom-grid-theme: grid-theme(
    $row-selected-background: #011627,
    $row-selected-text-color: #ECAA53,
    $row-selected-hover-background: #011627,
    $header-selected-text-color: #ECAA53,
    $header-selected-background: #011627,
    $expand-icon-color: #ECAA53,
    $expand-icon-hover-color: #B64B80
);
```

</ComponentBlock>

<ComponentBlock for="Grid, HierarchicalGrid">
```scss
$custom-grid-theme: grid-theme(
    $row-selected-background: #011627,
    $row-selected-text-color: #ECAA53,
    $row-selected-hover-background: #011627,
    $header-selected-text-color: #ECAA53,
    $header-selected-background: #011627
);
```

</ComponentBlock>

<ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" />는 여러 매개변수를 받지만, 선택된 모든 열의 모양을 바꾸는 데 관여하는 것은 다음 다섯 가지입니다:
- **$row-selected-background** - 선택된 부분의 배경을 설정합니다.
- **$row-selected-text-color** - 선택된 부분의 텍스트 색상을 설정합니다
- **$row-selected-hover-background** - 마우스를 올린 셀 또는 셀 묶음의 색상을 설정합니다.
- **$header-selected-text-color** - 선택된 열 머리글의 텍스트 색상을 설정합니다
- **$header-selected-background** - 선택된 열 머리글의 배경 색상을 설정합니다.


### CSS 변수 사용하기
마지막 단계는 사용자 지정 `{ComponentSelector}` 테마를 include하는 것입니다.

```scss
@include tokens($custom-grid-theme);
```

### 기본 테마 재정의하기
Internet Explorer 11용으로 컴포넌트의 스타일을 지정하려면, CSS 변수를 지원하지 않으므로 다른 방식을 사용해야 합니다.

<DocsAside type="info">
컴포넌트가 [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation을 사용한다면, `::ng-deep`를 사용하여 이 캡슐화를 `penetrate`해야 합니다. 사용자 지정 테마가 다른 컴포넌트로 새어 나가지 않도록 하려면, `::ng-deep` 앞에 `:host` 선택자를 포함했는지 확인하십시오.
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid($custom-column-selection-theme);
    }
}
```
