# {Platform} Zoom Slider 개요

{Platform} ZoomSlider 컨트롤은 범위를 지원하는 컨트롤에 확대/축소 기능을 제공합니다. ZoomSlider에는 가로 스크롤바, 전체 범위의 축소판, 크기를 조정할 수 있는 확대/축소 범위 창이 있습니다. ZoomSlider는 독립형 컨트롤로 작동할 수 없으며, DataChart나 CategoryChart 같은 범위 기반 컨트롤을 보강하는 역할을 합니다.

## 사용법

| 기능 이름        | 설명 |
| --------------------|----------------------- |
| 스크롤바 탐색       | 사용자는 ZoomSlider 스크롤바에 내장된 기능을 사용하여 배율을 바꾸고 데이터 범위를 스크롤할 수 있습니다. |
| 패닝과 확대/축소       | 사용자는 썸 패드의 가장자리를 끌어 현재 표시가 더 넓은 범위(축소)를 덮게 하거나 더 좁은 범위(확대)를 덮게 하여 표시 배율을 조정할 수 있습니다. |
| 여러 사용자 상호 작용 옵션       | 모든 마우스 사용자 상호 작용은 터치로도 중복 지원되며, 대부분은 키보드로도 지원됩니다. 자세한 내용은 사용자 상호 작용 및 사용성을 참조하십시오. |
| 터치 지원       |  터치를 지원하는 기기에서 사용자는 ZoomSlider의 모든 기능을 누릴 수 있습니다. 모든 마우스 상호 작용은 터치 환경에서도 지원됩니다. |
| 확장성       | ZoomSlider 컨트롤은 DataChart 컨트롤을 기본 상태에서 바로 지원합니다. |
| 구성 가능한 확대/축소 범위 창       | 초기 확대/축소 범위 창의 너비와 위치, 그리고 최소 크기를 구성할 수 있습니다. |

## 컴포넌트 모듈

<PlatformBlock for="Angular, React, WebComponents">

`ZoomSlider`에는 다음 모듈이 필요합니다:

```json-snippet source="/charts/zoomslider/overview" channel="modulesImports...moduleRegistration" exclude="Xaml"
{
    "descriptions": {
        "content": {
            "type": "ZoomSlider",
            "name": "zoomSlider"
        }
    },
    "modules": [
        "charts/ZoomSliderModule"
    ],
    "$modules": [
        "+doc:modulesImports",
        "+doc:moduleRegistration"
    ]
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

{ProductName} 서비스를 등록합니다:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

`ZoomSlider`의 클라이언트 리소스 모듈인 <ApiLink raw type="ZoomSliderModule" /> 등록은 **선택 사항**입니다. 컴포넌트는 처음 렌더링될 때 리소스를 로드합니다. `builder.Services.AddIgniteUIBlazor(typeof(IgbZoomSliderModule))`에 나열하면 리소스를 미리 로드하거나 클라이언트에서만 생성되는 요소를 지원할 수 있습니다([컴포넌트 모듈](general-getting-started.mdx#컴포넌트-모듈) 참조).
