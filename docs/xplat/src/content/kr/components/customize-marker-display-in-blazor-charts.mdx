## 샘플 Blazor 앱과 Blazor 차트 만들기

바인딩된 항목의 속성에 따라 마커의 표시(그리기)를 사용자 지정하려면, 마커를 그리는 JavaScript 프로그램을 만들고, 이 JavaScript 프로그램을 사용하여 마커를 그릴 시리즈의 속성을 지정합니다. HTML Canvas 요소의 2D 컨텍스트 객체가 시리즈에서 마커를 그리는 역할을 맡은 JavaScript 프로그램으로 전달됩니다.

마커의 표시(그리기)를 사용자 지정하려면 JavaScript와 HTML Canvas에서 그리기에 대한 사전 지식이 필요하다는 점을 기억하십시오.

먼저, 바인딩할 샘플 데이터의 유형은 다음 레코드 유형입니다. [Blazor 산점도 차트 유형](https://www.infragistics.com/products/ignite-ui-blazor/blazor/components/charts/types/scatter-chart)에서 일반적으로 사용되는 [Blazor 차트](https://www.infragistics.com/products/ignite-ui-blazor/blazor/components/charts/chart-overview)의 X축 및 Y축 값인 XValue와 YValue 같은 속성 외에도 다음을 추가합니다:

- "Double" 유형의 Volume 속성 하나
- "Color" 속성 하나

Blazor 차트의 Volume 속성 값은 마커의 크기로, Color 속성 값은 마커의 채우기 색상으로 사용됩니다.

<PlatformBlock for="Blazor">

```csharp
public record SampleDataType (
    string Name,
    double XValue,
    double YValue,
    double Volume, // Set Shape 👈this property to the size of the marker,
    System.Drawing.Color // Shape 👈Refer to this property as the fill color
);
```

</PlatformBlock>

위의 SampleDataType 레코드 유형을 사용하여 아래와 같이 샘플 데이터를 준비합니다:

## 마커의 사용자 지정 그리기 객체를 반환하는 팩토리 함수 정의하기

measure와 render, 두 메서드를 가진 JavaScript 객체를 반환하는 팩토리 함수를 정의해야 합니다. 이 함수는 마커를 그릴 때마다 Ignite UI 툴박스에서 호출됩니다.

<PlatformBlock for="Blazor">

```javascript
// in /wwwroot/customMarkerTemplateFunc.js
function customMarkerTemplateFunc() {
    return {
        measure: function (measureInfo) {},
        render: function (renderInfo) {}
   }
}
```

</PlatformBlock>

## Blazor 차트에서 마커의 사용자 지정 그리기 객체에 대한 measure 메서드 구현하기
Ignite UI는 마커 크기가 필요할 때마다 이 measure 메서드를 자동으로 호출합니다. 이때 measure 메서드 호출의 인수에는 그려질 데이터의 JavaScript 측 표현이 인수 객체의 .data.item 필드에 들어 있습니다.

즉, measure 메서드를 호출할 때 인수에서 SampleDataType 레코드 유형의 각 속성 값을 참조할 수 있습니다. 이렇게 하면 특정 값에 따라 마커의 크기가 계산되고 Ignite UI의 호출에 응답합니다.

결과적으로 이 메서드를 호출하면 마커의 너비와 높이(둘 다 px 단위)가 인수의 width와 height 필드에 설정됩니다.

<PlatformBlock for="Blazor">

```javascript
// in /wwwroot/customMarkerTemplateFunc.js

function customMarkerTemplateFunc() {
    return {
        measure: function ( measureInfo ) {
           // In this example, based on the Volume property value of the data to draw
           // 3 times that radius (so the diameter is 2 times that) Circle as a marker
           // Width and height are calculated and set for drawing.
           const item = measureInfo.data.item;
           const size = item.Volume * 3 * 2;
           measureInfo.width = size;
           measureInfo.height = size;
       }
   }
}
```

</PlatformBlock>

## 마커의 사용자 지정 렌더링 객체에 대한 render 메서드 구현하기

다음으로 render 메서드를 구현합니다. 이 메서드는 마커를 렌더링해야 할 때마다 Ignite UI 측에서 호출됩니다.
이 시점에 이 render 메서드가 호출될 때, 렌더링될 데이터의 JavaScript 측 표현이 인수 객체의 .data.item 필드에 포함됩니다(measure 메서드와 유사하게).

따라서 render 메서드를 호출할 때 그려질 데이터는 JavaScript 측 표현을 통해 마커 그리기 매개변수로 참조할 수 있습니다.
이 메서드가 해당 인수로 전달된 HTML Canvas 요소의 2D 컨텍스트 객체에 마커를 그리는 것을 볼 수 있습니다.

<PlatformBlock for="Blazor">

```javascript
// in /wwwroot/customMarkerTemplateFunc.js

function customMarkerTemplateFunc() {
    return {
        // ...
        render: function ( renderInfo ) {
            // Since the renderInfo passed as an argument is packed with coordinate-related information for drawing,
            // Take this out
            const cx = renderInfo.xPosition;
            const cy = renderInfo.yPosition;
            const halfWidth = renderInfo.availableWidth / 2.0;
            const halfHeight = renderInfo.availableHeight / 2.0;
            // For the marker fill color, use the Color property value of the data to be drawn.
            // (By the way, the default marker fill color is
            // stored in renderInfo.data.actualItemBrush.fill)
            const color = renderInfo.data.item .Color;
            // Draw a marker against the 2D context of the HTML Canvas element
            // (Draw a perfect circle marker with the size calculated by the measure method)
            const ctx = renderInfo.context ;
            ctx.beginPath();
            ctx.fillStyle = `rgba (${color.R} , ${color.G} , ${color.B} , ${color.A})`;
            ctx.ellipse (cx, cy, halfWidth, halfHeight, 0 , 0 , 360 * Math.PI / 180);
            ctx.fill();
        }
    }
}
```

</PlatformBlock>

HTML Canvas 2D 컨텍스트로 어떤 사용자 지정 그리기도 구현할 수 있다는 점에 유의하십시오.

하지만 render 메서드가 마커 렌더링을 담당하므로, 마커를 표시하는 데 필요한 모든 처리를 직접 구현해야 합니다. 따라서 HTML Canvas 요소에 대한 2D 렌더링에 관한 사전 지식이 필요합니다.

## 마커의 사용자 지정 그리기 객체를 반환하는 팩토리 함수를 Ignite UI에 등록하기

measure와 render 메서드를 구현한 후에는 Ignite UI가 제공하는 igRegisterScript 함수를 호출하십시오. 이렇게 하면 measure와 render, 두 메서드를 가진 객체를 반환하는 함수가 등록됩니다. 그런 다음 igRegisterScript 함수의 첫 번째 인수에 "script name" 문자열을 지정하십시오.

Ignite UI에서는 실제 JavaScript 함수의 이름과 관계없이 이 첫 번째 인수에 지정된 "script name"으로 식별됩니다.

<PlatformBlock for="Blazor">

```javascript
// in /wwwroot/customMarkerTemplateFunc.js

function customMarkerTemplateFunc() {
    // ...
}

// Register the factory function implemented above in the Ignite UI.
// (* The "script" name specified in the first argument of this registration is used
// regardless of the JavaScript name of the factory function.
igRegisterScript("customMarkerTemplateFunc", customMarkerTemplateFunc);
```

</PlatformBlock>

위의 JavaScript 프로그램은 브라우저에 로드됩니다. 다만 전역 오염을 피하기 위해, 위의 스크립트 등록이 실행될 때 지금까지의 JavaScript 프로그램은 즉시 실행되는 익명 함수로 감싸집니다.

<PlatformBlock for="Blazor">

```javascript
// in /wwwroot/customMarkerTemplateFunc.js

(function() {
    function customMarkerTemplateFunc() {
        // ...
    }
    igRegisterScript("customMarkerTemplateFunc", customMarkerTemplateFunc);
}) ();
```

</PlatformBlock>

이로써 JavaScript 측 구현이 완료되었습니다.

만든 JavaScript 프로그램 파일(.js)은 브라우저에서 로드될 수 있도록 앱의 호스트 페이지에 script 요소로 포함해야 합니다(독립형 Blazor WebAssembly 또는 Blazor Hybrid 앱의 경우 **wwwroot/index.html**, Blazor Server 앱의 경우 **Pages/_Host.cshtml**, Blazor Web App의 경우 **Components/App.razor**).

Ignite UI for Blazor의 JavaScript 런타임 다음에 로드되도록 script 요소의 배치 순서에 유의하십시오.

<PlatformBlock for="Blazor">

```razor
<script src="_content/IgniteUI.Blazor/app.bundle.js"></script>

<!-- After JavaScript in Ignite UI for Blazor,
load a custom drawing JavaScript program for marker display. -->

<script src="customMarkerTemplateFunc.js"></script>
```

</PlatformBlock>

## 시리즈 매개변수에서 "Script Name" 지정하기

마지막으로 시리즈 매개변수에서 "script name"을 지정하여, 지금까지 만든 마커의 사용자 지정 렌더링을 위한 JavaScript 프로그램을 사용하도록 합니다.

마커의 사용자 지정 그리기를 수행할 JavaScript 프로그램의 script name을 지정하는 MarkerTemplateScript라는 문자열 매개변수가 있습니다. 이는 igRegisterScript 함수로 등록할 때 첫 번째 인수에 지정한 문자열로 식별됩니다.

<PlatformBlock for="Blazor">

```razor
@* In the markup in the sample Razor component (.razor) *@
<IgbDataChart Height="320px" Width="320px">
    @*...*@
    <IgbScatterSeries MarkerTemplateScript="customMarkerTemplateFunc"/>
    @*...*@
</IgbDataChart>
```

</PlatformBlock>

이제 산점도는 바인딩된 항목의 속성에 따라 크기와 채우기 색상이 다른 마커로 표시됩니다.

## 결론

Blazor는 고급 웹 애플리케이션을 구축하고, 데이터 시각화를 관리하며, [Angular 같은 인기 프레임워크](https://www.infragistics.com/community/blogs/b/jason_beres/posts/blazor-vs-angular)의 복잡성을 다루지 않고도 데이터 차트의 기본 외관을 개선하려는 .NET 개발자에게 훌륭한 선택이라고 생각합니다.

하지만 이를 하려면 색상, 여백, 안쪽 여백을 조정하는 것 이상이 필요합니다. 대용량의 실시간 데이터 부하를 처리하면서 동시에 아름답고 대화형인 경험을 제공할 수 있는 데이터 시각화 도구 세트가 중요하다는 것을 알고 있기에, [최신 Ultimate 22.1 제품 릴리스](https://www.infragistics.com/community/blogs/b/jason_beres/posts/product-release-whats-new-in-infragistics-ultimate-22-1)에서 Ignite UI for Blazor의 모든 데이터 시각화 기능과 데이터 차트를 개선하는 데 노력과 시간을 투자했습니다.

Ignite UI for Blazor의 가장 최근 추가 기능에는 자동 레이블 회전, 스타일 이벤트, 레이블 간격 속성, 콜아웃 레이어의 위치 지정, 시리즈 모드 강조, 가로 및 세로 스크롤바, 여백 각도 모드 및 [Blazor 그리드](https://www.youtube.com/watch?v=1dWR_N4teDs), 데이터 범례와 데이터 툴팁 같은 컴포넌트가 포함됩니다.
