# {Platform} Spreadsheet 개요

{Platform} Spreadsheet(Excel 뷰어) 컴포넌트는 가볍고 기능이 풍부하며, 과학, 비즈니스, 금융 등 모든 유형의 스프레드시트 데이터를 작업, 시각화 및 편집하는 데 필요한 모든 옵션을 갖추고 있습니다. 모든 정보는 셀, 패널 및 워크시트 사이를 직관적이고 쉽게 탐색할 수 있는 표 형식으로 표시할 수 있습니다. <ApiLink type="Spreadsheet" />은(는) 유연한 Excel 같은 인터페이스, 상세한 차트, 그리고 활성화, 셀 편집, 조건부 서식, 스타일 지정, 선택, 클립보드 같은 기능으로 보완됩니다.

## 기능

- 기능

Excel 스프레드시트와 마찬가지로 필터링, 정렬, 셀 이동, 셀 색 사용자 지정, 키보드 단축키를 적용할 수 있으며, 수식을 계산하는 기능도 추가할 수 있습니다.

## 스프레드시트 사용

- 성능

이 스프레드시트는 모든 최신 브라우저에서 호환되며, 복잡하고 대용량인 스프레드시트 모델에 맞게 최적화되어 있으면서도 완벽한 기능과 단순함을 보장합니다.

- 유연한 레이아웃과 쉬운 사용자 지정

원하는 기능을 쉽게 선택, 추가, 제거, 켜거나 끌 수 있으며, React 시트를 즉시 구성하여 최종 사용자의 요구를 모두 충족할 수 있습니다. 구성 가능한 라이브러리, 스타일 및 서식 지정 대안, 표시 옵션, 그리고 선택할 수 있는 많은 테마도 제공됩니다.

- 편리한 Excel 같은 인터페이스

Excel에서 데이터를 다루는 것과 마찬가지로, 저희 스프레드시트 컴포넌트는 잘 알려진 Excel 클립보드 작업인 복사, 붙여넣기, 잘라내기를 모두 제공합니다. 별도의 교육이나 새로운 기술 없이도 바로 사용할 수 있습니다. 또한 정렬, 전체 키보드 탐색, 값과 수식, 셀 드래그, 열과 행 편집, 필터링, 숫자 서식 지정, 크기 조정 옵션도 제공합니다. 스마트하고 빠른 계산 엔진은 가장 복잡한 계산도 처리합니다. Excel에 의존하지 않습니다.

- 데이터 작업

과학, 비즈니스, 엔지니어링, 금융 및 교육 데이터를 수집하고 관리하십시오. 분석, 고급 그리드, 보고서, 데이터 입력 양식, 예산 책정, 예측 시나리오, 사용자 지정 스프레드시트를 준비하고 만드십시오. 이 모든 것은 포괄적인 API 덕분에 가능합니다.

- 빠르고 안전한 데이터 처리

저희 스프레드시트를 사용하면 데이터 처리는 100% 안전하고 보안이 확보됩니다…

- Excel 및 CSV 가져오기와 내보내기

내장된 Excel 가져오기/내보내기 기능을 사용하면 Excel 문서를 바로 불러와 필요할 때 보고, 변경 사항을 추가하고 저장할 수 있습니다. 또한 완성된 Excel .xlsx 스프레드시트를 손쉽게 내보낼 수 있습니다.

## 종속성

{Platform} 스프레드시트 컴포넌트를 설치할 때는 core 및 excel 패키지도 함께 설치해야 합니다.

```cmd
npm install --save {PackageCore}
npm install --save {PackageExcel}
npm install --save {PackageSpreadsheet}
```

다음은 통합 문서를 {Platform} 스프레드시트에 불러오는 방법을 보여 줍니다

<PlatformBlock for="Angular">

```ts
import { IgxSpreadsheetComponent } from 'igniteui-angular-spreadsheet';
import { ExcelUtility } from 'ExcelUtility';

// ...

@ViewChild("spreadsheet", { read: IgxSpreadsheetComponent })
public spreadsheet: IgxSpreadsheetComponent;

ngOnInit() {
    const excelFile = '../../assets/Sample1.xlsx';
    ExcelUtility.loadFromUrl(excelFile).then((w) => {
      this.spreadsheet.workbook = w;
    });
}
```

</PlatformBlock>

<PlatformBlock for="React">

```ts
import { IgrSpreadsheet } from 'igniteui-react-spreadsheet';

      this.spreadsheet.workbook = w;
    });
}
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts

```
