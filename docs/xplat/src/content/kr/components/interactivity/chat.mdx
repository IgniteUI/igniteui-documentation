# {Platform} 채팅 개요

{ProductName} 채팅 컴포넌트는 애플리케이션에서 대화형 인터페이스를 만들기 위한 완전한 솔루션을 제공합니다. 고객 지원 도구, 협업 작업 공간, 챗봇 어시스턴트 중 무엇을 만들든, 채팅 컴포넌트는 필요한 구성 요소를 제공합니다. 텍스트 메시지 보내기와 받기, 파일 첨부 업로드, 빠른 응답 제안 표시, 상대방이 응답을 입력하는 중일 때 입력 중 표시기 보여 주기가 그것입니다.

정적인 메시지 목록과 달리 <ApiLink pkg="core" type="Chat" /> 컴포넌트는 대화형이며 **실시간 통신**을 위해 설계되었습니다. 입력, 렌더링, 사용자 상호 작용을 관리하며, 메시지와 첨부 파일이 표시되는 방식을 완전히 제어할 수 있게 합니다. 또한 레이아웃이나 시각 요소의 어떤 부분이든 재정의할 수 있는 광범위한 렌더링 API를 노출합니다.

## 사용법

<ApiLink pkg="core" type="Chat" />를 사용하는 가장 간단한 방법은 다음과 같이 선언하는 것입니다:

<PlatformBlock for="WebComponents">


```ts
const options: IgcChatOptions = {
  currentUserId: 'me',
  headerText: 'Support Chat',
};
```

```html
<igc-chat id="myChat" .options=${options}>
</igc-chat>
```

</PlatformBlock>


<PlatformBlock for="React">


```tsx
import { IgrChat, IgrChatOptions } from 'igniteui-react';

const options: IgrChatOptions = {
  currentUserId: 'me',
  headerText: 'Support Chat',
};

return (
  <IgrChat options={options} />
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">


```cs
 public IgbChatOptions Options = new IgbChatOptions()
 {
  CurrentUserId = "user",
  HeaderText = "Support Chat"
 };
```

```razor
<IgbChat @ref="Chat" Options="Options">
</IgbChat>
```

</PlatformBlock>


여기서 `currentUserId` 속성은 컴포넌트에 어떤 메시지가 "발신"(현재 사용자가 보낸 메시지)이고 어떤 메시지가 "수신"(다른 사람이 보낸 메시지)인지 알려 줍니다. `headerText`은(는) 채팅 창의 제목을 제공합니다.

렌더링된 후에는 메시지를 프로그래밍 방식으로 추가할 수 있습니다:

<PlatformBlock for="WebComponents">



```ts
const chat = document.getElementById('myChat');
const newMessage = {
  id: '1',
  sender: 'me',
  text: 'Hello! How can I help you?',
  timestamp: Date.now().toString()
};
chat.messages = [...chat.messages, newMessage ];

```

</PlatformBlock>


<PlatformBlock for="React">


```tsx
import { useRef } from 'react';
import { IgrChat } from 'igniteui-react';

const ChatExample = () => {
  const chatRef = useRef<IgrChat>(null);

  const sendMessage = () => {
    const newMessage = {
      id: '1',
      sender: 'me',
      text: 'Hello! How can I help you?',
      timestamp: Date.now().toString()
    };
    chatRef.current!.messages = [...chatRef.current!.messages, newMessage];
  };

  return (
    <>
      <IgrChat ref={chatRef} options={{ currentUserId: 'me', headerText: 'Support Chat' }} />
      <button onClick={sendMessage}>Send Message</button>
    </>
  );
};
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbChat @ref="Chat" Options="Options" Messages="Messages" MessageCreated="OnMessageCreated"></IgbChat>
```

```cs
 public IgbChatMessage[] Messages = new IgbChatMessage[]

     new IgbChatMessage()
     {
```

사용자가 메시지를 보내면 `Messages` 컬렉션이 자동으로 업데이트됩니다. 메시지를 저장하거나 다른 부수 효과를 처리하려면 `MessageCreated` 이벤트를 처리할 수 있습니다. 이벤트 세부 정보를 `Messages`에 다시 추가하지 마십시오:

```cs
public void OnMessageCreated(IgbChatMessageEventArgs e)
{
  Console.WriteLine($"Message created: {e.Detail.Text}");
}
```

</PlatformBlock>

이 방식을 사용하면 서버 엔드포인트, 챗봇 엔진 또는 공동 작업 앱 백엔드와 같은 자체 데이터 소스에 Chat을 쉽게 연결할 수 있습니다.

### 속성
<ApiLink pkg="core" type="Chat" /> 컴포넌트는 상태와 구성을 제어할 수 있게 하는 몇 가지 핵심 속성을 노출합니다:

| 이름                                                                                                                                    | 설명                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <PlatformBlock for="Blazor">`Messages`</PlatformBlock><PlatformBlock for="WebComponents,React">`messages`</PlatformBlock>               | 채팅에 표시되는 메시지의 양방향 배열(<ApiLink pkg="core" type="ChatMessage" />[])입니다. 사용자가 메시지를 보내면 채팅이 제공된 컬렉션을 업데이트합니다.                  |
| <PlatformBlock for="Blazor">`DraftMessage`</PlatformBlock><PlatformBlock for="WebComponents,React">`draftMessage`</PlatformBlock>       | 아직 전송되지 않은 현재 메시지로, `text`과(와) 선택적 `attachments`을(를) 포함하는 객체로 표현됩니다. 메시지 초안을 저장하거나 복원하는 데 유용합니다.                          |
| <PlatformBlock for="Blazor">`Options`</PlatformBlock><PlatformBlock for="WebComponents,React">`options`</PlatformBlock>                 | 현재 사용자 ID, 입력 플레이스홀더, 허용되는 파일 유형, 빠른 응답 제안, 입력 중 지연 시간, 사용자 지정 렌더러 같은 채팅 구성(<ApiLink pkg="core" type="ChatOptions" />)입니다. |
| <PlatformBlock for="Blazor">`ResourceStrings`</PlatformBlock><PlatformBlock for="WebComponents,React">`resourceStrings`</PlatformBlock> | 레이블, 머리글, 시스템 텍스트를 위한 지역화된 리소스 문자열입니다. 이 속성을 사용하여 컴포넌트를 다른 언어에 맞게 조정할 수 있습니다.                                                 |

이 속성들을 사용하면 Chat의 UI를 애플리케이션 상태 및 백엔드와 간단하게 동기화할 수 있습니다.

#### 양방향 메시지 컬렉션

이 <PlatformBlock for="WebComponents,React">`messages`</PlatformBlock><PlatformBlock for="Blazor">`Messages`</PlatformBlock> 컬렉션은 양방향입니다. 애플리케이션이 표시할 메시지를 제공하고, 대화가 이어지면 채팅이 원래 컬렉션을 업데이트합니다. 사용자가 메시지를 보낸 후, 컬렉션에 대한 참조를 가진 코드는 새로 만들어진 메시지에 액세스할 수 있습니다.

이 <PlatformBlock for="WebComponents">`igcMessageCreated`</PlatformBlock><PlatformBlock for="React">`onMessageCreated`</PlatformBlock><PlatformBlock for="Blazor">`MessageCreated`</PlatformBlock> 이벤트는 저장이나 다른 부수 효과를 위한 알림입니다. 만들어진 메시지를 컬렉션에 다시 추가하지 마십시오.

원래 컬렉션을 변경하지 않은 상태로 유지해야 한다면, 채팅에 얕은 복사본을 전달하십시오. 기존 메시지 객체는 여전히 공유됩니다. 그 객체들도 독립적으로 유지되어야 한다면, 복사된 컬렉션을 만들 때 각 메시지의 새 인스턴스를 만드십시오.

<PlatformBlock for="WebComponents">


```ts
const chatMessages = [...originalMessages];
chat.messages = chatMessages;
```

</PlatformBlock>

<PlatformBlock for="React">


```tsx
const chatMessages = [...originalMessages];

return <IgrChat messages={chatMessages} options={options} />;
```

</PlatformBlock>

<PlatformBlock for="Blazor">


```cs
IgbChatMessage[] chatMessages = originalMessages.ToArray();
```

```razor
<IgbChat Messages="chatMessages" Options="Options"></IgbChat>
```

</PlatformBlock>

### 첨부 파일
현대의 대화는 텍스트만으로 이루어지는 경우가 드뭅니다. Chat 컴포넌트에는 사용자가 이미지, 문서 및 기타 파일을 공유할 수 있도록 파일 첨부 기능이 기본으로 포함되어 있습니다.
기본적으로 입력 영역에는 첨부 버튼이 있습니다. `acceptedFiles` 속성을 설정하여 허용할 파일 형식을 제어할 수 있습니다:


<PlatformBlock for="WebComponents">


```ts
const options: IgcChatOptions = {
  acceptedFiles: "image/*,.pdf",
};
```

</PlatformBlock>


<PlatformBlock for="React">


```tsx
const options: IgrChatOptions = {
  acceptedFiles: "image/*,.pdf",
};
```

</PlatformBlock>

이 예제에서 사용자는 이미지와 PDF 파일만 업로드할 수 있습니다.
사용 사례에 첨부 파일이 필요하지 않다면 쉽게 끌 수 있습니다:

<PlatformBlock for="WebComponents">


```ts
const options: IgcChatOptions = {
  disableInputAttachments: true,
};
```

</PlatformBlock>


<PlatformBlock for="React">


```tsx
const options: IgrChatOptions = {
  disableInputAttachments: true,
```

### 추천 항목
빠른 응답 제안은 사용자가 탭하여 즉시 응답할 수 있는 미리 정의된 응답을 제공합니다. 이 기능은 챗봇, 고객 서비스 흐름, 또는 사용자를 구조화된 절차로 안내할 때 특히 유용합니다.
suggestions 속성에 문자열 배열을 바인딩하여 제안을 제공할 수 있습니다. `suggestions-position` 어트리뷰트를 사용하면 제안이 표시되는 위치를 제어할 수 있습니다. 입력 영역 아래에 또는 메시지 목록 아래에 표시할 수 있습니다.

<PlatformBlock for="WebComponents">


```ts
const options: IgcChatOptions = {
  currentUserId: "me",
  suggestions: ['Yes', 'No', 'Maybe later'],
  suggestionsPosition: "below-input"
};
```

```html
<igc-chat
  .options=${options}>
</igc-chat>
```

</PlatformBlock>


<PlatformBlock for="React">


```tsx
const options: IgrChatOptions = {
  currentUserId: "me",
  suggestions: ['Yes', 'No', 'Maybe later'],
  suggestionsPosition: "below-input"
};

return (
  <IgrChat ref={chatRef} options={options} />
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```cs
public IgbChatOptions Options = new IgbChatOptions
{
  CurrentUserId = "me",
  Suggestions = new string[] { "Yes", "No", "Maybe later" },

```

</PlatformBlock>

이 방식은 반복적인 답변을 입력할 필요를 줄여 사용자 상호 작용을 간소화하고, 안내된 대화에서 전반적인 경험을 개선합니다.

### 입력 표시기
참여자가 상대방이 입력 중인 것을 볼 수 있으면 대화가 더 자연스럽게 느껴집니다. Chat 컴포넌트는 옵션 객체의 `isTyping` 속성을 통해 이 동작을 제공합니다.
true로 설정하면 채팅은 메시지 아래에 은은한 입력 표시기를 표시합니다:

<PlatformBlock for="WebComponents">


```ts
const options: IgcChatOptions = {
  isTyping: true
};
```

</PlatformBlock>


<PlatformBlock for="React">


```tsx
const options: IgrChatOptions = {
  isTyping: true
};
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```cs
public IgbChatOptions Options = new IgbChatOptions
{
  IsTyping = true
};
```

</PlatformBlock>

이 기능은 일반적으로 프로그래밍 방식으로 전환되며, 예를 들어 백엔드 서비스에서 입력 이벤트를 받을 때 사용합니다.

### 사용자 지정 렌더러
채팅 컴포넌트는 기본 UI로 바로 동작하지만, 많은 애플리케이션은 모양과 느낌을 사용자 지정해야 합니다. 예를 들어 읽음 확인을 추가하거나, 아바타를 표시하거나, 입력 영역을 음성 녹음 버튼으로 바꾸고 싶을 수 있습니다.
<ApiLink pkg="core" type="Chat" /> 컴포넌트는 렌더러 시스템으로 이 요구를 해결합니다. 렌더러는 UI의 주어진 부분에 대한 템플릿을 반환하는 함수일 뿐입니다. 원하는 만큼 많이 또는 적게 렌더러를 재정의할 수 있습니다.

#### ChatTemplateRenderer
모든 렌더러는 같은 함수 시그니처를 따릅니다:

<PlatformBlock for="WebComponents, React">

```ts
export type ChatTemplateRenderer<T> = (ctx: T) => unknown;
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```js
igRegisterScript("MyTemplate", (ctx) => {
}, false);
```

</PlatformBlock>

ctx 매개변수는 렌더링되는 대상에 따라 다른 맥락 데이터를 제공합니다.

#### 렌더러 컨텍스트

| 컨텍스트 타입                | 제공되는 데이터                                                                                                          |
| --------------------------- | -----------------------------------------------------------------------------------------------------------------------|
| <ApiLink pkg="core" type="ChatRenderContext" />       | `instance`(채팅 컴포넌트 인스턴스).                                                |
| <ApiLink pkg="core" type="ChatInputRenderContext" />      | <ApiLink pkg="core" type="ChatRenderContext" />을 상속하며 `attachments`(<ApiLink pkg="core" type="ChatMessageAttachment" />의 배열)과 `value`(현재 입력 텍스트)를 추가합니다. |
| <ApiLink pkg="core" type="ChatMessageRenderContext" />    | <ApiLink pkg="core" type="ChatRenderContext" />을 상속하며 <ApiLink pkg="core" type="ChatMessage" />(렌더링되는 <ApiLink pkg="core" type="ChatMessage" />)를 추가합니다.                                      |
| <ApiLink pkg="core" type="ChatAttachmentRenderContext" /> | <ApiLink pkg="core" type="ChatMessageRenderContext" />을 상속하며 `attachment`(렌더링되는 <ApiLink pkg="core" type="ChatMessageAttachment" />)를 추가합니다.                      |

#### 사용 가능한 렌더러

Chat의 다음 부분을 사용자 지정할 수 있습니다:
- 메시지 수준: message, messageHeader, messageContent, messageAttachments, messageActions
- 첨부 파일 수준: attachment, attachmentHeader, attachmentContent
- 입력 수준: input, inputActions, inputActionsStart, inputActionsEnd, inputAttachments, fileUploadButton, sendButton
- 추천 항목: suggestionPrefix

기본적으로 메시지는 일반 텍스트로 렌더링됩니다. Markdown 지원을 활성화하려면 아래처럼 messageContent 렌더러를 재정의하고 Markdown 렌더러를 사용하면 됩니다:

<PlatformBlock for="WebComponents">


```ts
import { createMarkdownRenderer } from 'igniteui-webcomponents/extras';

// Create a reusable Markdown renderer instance
const markdownRenderer = await createMarkdownRenderer();

const options = {
  renderers: {
    messageContent: async ({ message }) => markdownRenderer(message),
  }
};
```

</PlatformBlock>


<PlatformBlock for="React">


```tsx

  renderers: {
    messageContent: async ({ message }) => markdownRenderer(message),
  }
};
```

</PlatformBlock>

이 예제에서:
- 각 메시지의 text 속성은 [marked](https://github.com/markedjs/marked) 라이브러리를 사용하여 Markdown으로 파싱됩니다.
- 렌더러는 [DOMPurify](https://github.com/cure53/DOMPurify)를 사용하여 출력을 정화합니다.
- 링크는 안전한 rel 속성과 함께 자동으로 새 탭에서 열립니다.

#### 구문 강조

Markdown 렌더러는 [Shiki](https://shiki.matsu.io/)를 사용하여 코드 블록의 구문 강조도 지원합니다. 기본적으로 github-light 테마로 JavaScript, TypeScript, HTML, CSS의 강조를 포함합니다. MarkdownRendererOptions를 통해 이 동작을 사용자 지정할 수 있습니다:

```ts
const markdownRenderer = await createMarkdownRenderer({
  theme: { light: 'min-light' },
  languages: ['javascript', 'python']
});
```

이렇게 하면 GitHub 다크 테마로 스타일이 지정된 JavaScript, Python, Go의 강조된 코드 블록이 활성화됩니다.

#### 구성 옵션

| 옵션          | 설명                                                                     |
| --------------- | ------------------------------------------------------------------------------- |
| `noHighlighter` | `true`이면 구문 강조를 완전히 끕니다.                               |
| `languages`     | 강조된 코드 블록에서 지원할 프로그래밍 언어의 목록입니다.            |
| `theme`         | 적용할 **Shiki** 테마를 지정하는 객체입니다. `light`와 `dark` 모드에 대해 별도의 값을 지원합니다(예: `{ light: 'github-light', dark: 'github-dark' }`). |
| `sanitizer`     | 최종 HTML을 정제하는 사용자 지정 함수입니다. 기본값은 `DOMPurify.sanitize`입니다. |

</PlatformBlock>

| "file-name"                     | 첨부 파일에 표시되는 파일 이름의 스타일을 지정합니다.                                         |

#### 루트 스타일 적용(adoptRootStyles)

Chat 컴포넌트의 옵션에는 고급 스타일링 시나리오를 위한 특별한 플래그가 있습니다:

| 옵션            | 타입      | 기본값 | 설명        |
| ----------------- | --------- | ------- | ------------------ |
| `adoptRootStyles` | `boolean` | false   | `true`인 경우, 컴포넌트의 Shadow DOM 안에 렌더링된 콘텐츠(예: 사용자 지정 렌더러에서 렌더링된 콘텐츠)가 문서의 루트에서 스타일을 상속할 수 있습니다. 이는 스타일링을 위한 빠른 임시 방법이지만 운영 환경에서는 **권장되지 않습니다**. |

이 속성은 사용자 지정 렌더링 템플릿에 전역 CSS를 적용할 때 Shadow DOM 캡슐화를 다루고 싶지 않은 경우에 유용할 수 있습니다.
그러나 다음과 같은 절충점이 있습니다:
- ✅ 편의성: (문서의) 전역 스타일이 사용자 지정 메시지 렌더러에 영향을 줄 수 있습니다.
- ⚠ 위험: 캡슐화를 깨뜨려, 전역 CSS가 의도치 않게 내부 시각 요소를 바꾸는 스타일 누출을 일으킬 수 있습니다.
- 🔒 일회성 설정: 이 옵션은 초기화 시에만 설정할 수 있습니다. 실행 중에 변경해도 효과가 없습니다.

이 속성을 사용하기 전에 표준 Web Component 스타일링 방식을 사용하는 것을 강력히 권장합니다:
- CSS 변수 및 ::part API – 노출된 파트와 변수를 통해 사용자 지정하는 것을 우선하십시오.
- `<link>` 요소 – 더 큰 스타일시트는 Shadow DOM 안에 삽입하십시오.
- 인라인 `<style>` 태그 – 작고 범위가 한정된 스타일 재정의에 사용하십시오.

#### 예제

```css
igc-chat::part(header) {
  background-color: var(--ig-gray-800);
  color: var(--ig-warn-400);
}

igc-chat::part(message-container) {
  background: var(--ig-warn-200);
  color: var(--ig-warn-200-contrast);
}

igc-chat::part(message-sent) {
  background: var(--ig-warn-500);
  color: var(--ig-warn-500-contrast);
}

igc-chat::part(message-header) {
  color: var(--ig-warn-A700); 
}
```

이를 통해 기능을 대체하지 않고도 <ApiLink pkg="core" type="Chat" />의 스타일을 브랜드에 맞게 지정할 수 있습니다.
