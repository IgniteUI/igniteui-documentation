# Componente Carousel

{ProductName} Carousel es un componente de diseño basado en diapositivas para presentar imágenes, tarjetas u otro contenido con controles de navegación e indicadores.

Use Carousel cuando los usuarios necesiten recorrer de una en una una pequeña colección de diapositivas relacionadas, con animación opcional, navegación personalizada y transiciones automáticas.

```ts
import { defineComponents, IgcCarouselComponent } from "igniteui-webcomponents";
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Registre los servicios de {ProductName}:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

Registrar <ApiLink pkg="core" type="CarouselModule" />, el módulo de recursos de cliente de Carousel, es **opcional**: el componente carga sus recursos cuando se renderiza por primera vez. Incluirlo en `builder.Services.AddIgniteUIBlazor(typeof(IgbCarouselModule))` puede usarse para precargar recursos o para admitir elementos creados solo en el cliente (véase [Component Modules](../general-getting-started.mdx#módulos-de-componentes)).

Añada la hoja de estilos del tema a la página host de la aplicación.

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```

</PlatformBlock>

## Uso

{Platform} Carousel se configura colocando componentes de diapositiva dentro del host y activando después el comportamiento de navegación, de indicadores y de transición que necesite su diseño.

### Diapositiva activa

<PlatformBlock for="WebComponents, React, Blazor">

<PlatformBlock for="Angular">


<DocsAside type="info">
Si no se establece ninguna diapositiva activa, la primera está activa de forma predeterminada. Si hay varias diapositivas activas durante el renderizado inicial o en actualizaciones posteriores, se usa la última diapositiva activa.
</DocsAside>

## Accesibilidad

{Platform} Carousel expone la semántica de carousel, diapositiva e indicador para los usuarios de teclado y de tecnologías de asistencia.

### Interacción por teclado

| Clave | Acción |
| --- | --- |
| <kbd>Space</kbd> o <kbd>Enter</kbd> | Activa el botón de navegación que tiene el foco. |
| <kbd>Arrow Left</kbd> | Mueve el foco del indicador al indicador de diapositiva anterior, o al indicador siguiente en modo de derecha a izquierda. |
| <kbd>Arrow Right</kbd> | Mueve el foco del indicador al indicador de diapositiva siguiente, o al indicador anterior en modo de derecha a izquierda. |
| <kbd>Home</kbd> | Mueve el foco del indicador al primer indicador de diapositiva, o al último indicador en modo de derecha a izquierda. |
| <kbd>End</kbd> | Mueve el foco del indicador al último indicador de diapositiva, o al primero en modo de derecha a izquierda. |

### Lectores de pantalla / ARIA

El Carousel proporciona roles y estado de ARIA para el host, las diapositivas, los indicadores y los controles de navegación.

| Elemento | Rol o atributo | Finalidad |
| --- | --- | --- |
| Host de Carousel | `role="region"` y `aria-roledescription="carousel"` | Identifica el Carousel como una región de contenido navegable. |
| Contenedor de diapositivas | `aria-live="polite"` o `aria-live="off"` | Anuncia los cambios de diapositiva cuando la reproducción automática no está activa. |
| Diapositiva | `role="tabpanel"`, `aria-roledescription="slide"` y `aria-label` | Identifica cada diapositiva y su posición dentro del conjunto. |
| Contenedor de indicadores | `role="tablist"` | Agrupa los indicadores de diapositiva. |
| Indicator | `role="tab"`, `aria-label` y `aria-selected` | Identifica la diapositiva que representa el indicador y si está seleccionada. |
| Botones de navegación | `aria-label` | Nombra las acciones de diapositiva anterior y siguiente. |

## Preguntas frecuentes

<Faq>
  <FaqItem question="¿Debe un carousel reproducirse automáticamente?" indicatorPosition="end">
    Prefiera la navegación manual cuando sea posible. Si un carousel rota automáticamente, proporcione una forma clara de pausarlo y reanudarlo para que los usuarios tengan tiempo suficiente para leer e interactuar con cada diapositiva.
  </FaqItem>
  <FaqItem question="¿Qué debe ocurrir cuando alguien pasa el ratón sobre un carousel o lo enfoca?" indicatorPosition="end">
    Pause la rotación automática mientras el usuario lee o interactúa con el carousel. No la reanude hasta que el usuario elija explícitamente continuar.
  </FaqItem>
  <FaqItem question="¿Cuántas diapositivas debe contener un carousel?" indicatorPosition="end">
    Mantenga el conjunto pequeño y centrado. Una colección corta de diapositivas relacionadas es más fácil de descubrir y de recorrer que una secuencia larga con contenido oculto.
  </FaqItem>
  <FaqItem question="¿Puede una diapositiva contener formularios, botones o varias acciones?" indicatorPosition="end">
    Sí, cuando el contenido interactivo tiene un orden de foco predecible y la diapositiva no cambia mientras el usuario interactúa con ella. Mantenga las acciones centradas en la tarea principal de la diapositiva.
  </FaqItem>
  <FaqItem question="¿Deben ser interactivos los puntos indicadores?" indicatorPosition="end">
    Haga que los indicadores sean interactivos cuando representen una navegación directa a diapositivas individuales. Así los usuarios pueden llegar a un contenido concreto sin seleccionar repetidamente anterior o siguiente.
  </FaqItem>
  <FaqItem question="¿Cuándo debo usar un diseño estático en lugar de un carousel?" indicatorPosition="end">
    Use una lista estática, una cuadrícula, pestañas o un stepper cuando los usuarios necesiten comparar elementos, leer todos los elementos o encontrar un elemento concreto de inmediato. Un carousel funciona mejor para una secuencia compacta de contenido relacionado.
  </FaqItem>
</Faq>
