# Descripción general de {Platform} Expansion Panel

El {ProductName} Expansion Panel es un componente de acordeón ligero que puede renderizarse en dos estados: contraído o expandido. El expansion panel puede alternarse con un clic del ratón o mediante interacciones de teclado.

## Enlazar eventos

## Personalización del componente
El control <ApiLink pkg="core" type="ExpansionPanel" /> permite añadir todo tipo de contenido dentro de su cuerpo. ¡Puede renderizar [campos de entrada](../inputs/input.mdx), gráficos e incluso otros expansion panels!

El <ApiLink pkg="core" type="ExpansionPanel" /> permite personalizar fácilmente el encabezado mediante los slots expuestos `title`, `subTitle` y `indicator`.

La posición del indicador de expansión se configura con la propiedad <ApiLink pkg="core" type="ExpansionPanel" member="indicatorPosition" label="IndicatorPosition" /> del Expansion Panel. Las opciones posibles son **start**, **end** o **none**.

### Elementos recomendados para los slots

Al insertar contenido en los slots `title` y `subtitle`, recomendamos usar elementos `<span>` en lugar de elementos de encabezado (`<h1>`–`<h6>`). Los elementos de encabezado tienen estilos integrados (como el tamaño de fuente, la altura de línea y los márgenes) que pueden interferir con la tipografía y el diseño previstos del componente. Usar un `<span>` le da un contenedor neutro que hereda limpiamente los estilos del componente.

El slot `indicator` está pensado para contenido de tipo icono. Recomendamos usar el componente [`<igc-icon>`](../layouts/icon.mdx) para este fin. Como alternativa, si no quiere usar un icono para el indicador, puede usarse un elemento `<span>` para mostrar texto, símbolos o emojis.

<PlatformBlock for="WebComponents">

```html
<igc-expansion-panel>
  <span slot="title">Golden Retriever</span>
  <span slot="subtitle">Medium-large gun dog</span>
  <igc-icon slot="indicator" name="arrow_forward"></igc-icon>
</igc-expansion-panel>
```

</PlatformBlock>

<PlatformBlock for="React">


## Navegación por teclado

La navegación por teclado de {ProductName} Expansion Panel cumple las normas de accesibilidad de W3C y es cómoda de usar.

**Combinaciones de teclas**

- <kbd>ALT</kbd> + <kbd>↓</kbd>: expande el panel enfocado
- <kbd>ALT</kbd> + <kbd>↑</kbd>: contrae el panel enfocado
- <kbd>SPACE</kbd>/<kbd>ENTER</kbd>: alterna el estado de expansión del panel enfocado

## Estilos

El componente <ApiLink pkg="core" type="ExpansionPanel" /> expone varias partes CSS que le dan control total sobre su estilo:

|Nombre|Descripción|
|--|--|
| `header` | El contenedor del indicador de expansión, del título y del subtítulo. |
| `title` | El contenedor del título. |
| `subtitle` | El contenedor del subtítulo. |
| `indicator` | El contenedor del indicador. |
| `content` | El wrapper del contenido del expansion panel. |

```css
igc-expansion-panel {
  background-color: var(--ig-secondary-900);
  color: var(--ig-secondary-900-contrast);
}

igc-button::part(base) {
  color: var(--ig-secondary-900-contrast);
}

igc-button::part(base)::before {
  background-color: var(--ig-warn-500);
}

igc-expansion-panel::part(indicator) {
  color: var(--ig-warn-500);
}

igc-expansion-panel::part(header) {
  background-color: var(--ig-secondary-900);
}

igc-expansion-panel::part(title),
igc-expansion-panel::part(subtitle) {
  color: var(--ig-warn-500);
}
```
