# Componente Breadcrumbs <Badge variant="new" />

El componente {ProductName} Breadcrumbs muestra una ruta ordenada de elementos de navegación separados por un icono configurable, que comunica la ubicación del usuario dentro de la jerarquía de un sitio y ofrece una forma de volver a las páginas de nivel superior.

## Anatomía

El componente {Platform} Breadcrumbs está formado por dos elementos: un contenedor que gestiona el estado compartido y se renderiza como una lista ARIA, y uno o más elementos hijos de tipo item que renderizan contenido en slot seguido de un separador.

```text
<igc-breadcrumbs role="list">
  <igc-breadcrumb role="listitem">
    ├── ::part(label)
    │   ├── slot="prefix"                 // optional prefix content
    │   ├── default slot                  // main content, typically <a>
    │   └── slot="suffix"                 // optional suffix content
    └── ::part(separator)                 // hidden on the last item
        └── slot="separator"              // per-item override
  </igc-breadcrumb>
  <!-- more <igc-breadcrumb> items ... -->
  <igc-breadcrumb current role="listitem" aria-current="page">
    <!-- last item, no trailing separator -->
  </igc-breadcrumb>
</igc-breadcrumbs>
```

## Uso

### Página actual

Marque el elemento que representa la página que se está viendo con la propiedad <PlatformBlock for="WebComponents, Angular">[`current`]({environment:infragisticsBaseUrl}/api/webcomponents/igniteui-webcomponents/latest/classes/IgcBreadcrumbComponent#current)</PlatformBlock><PlatformBlock for="React, Blazor"><ApiLink pkg="core" type="Breadcrumb" member="current" label="current" /></PlatformBlock> . El elemento la refleja como atributo y establece `aria-current="page"`, para que los lectores de pantalla anuncien la página actual.

<PlatformBlock for="WebComponents, Angular">

### Separador compartido

Use el <PlatformBlock for="WebComponents, Angular">[`separator`]({environment:infragisticsBaseUrl}/api/webcomponents/igniteui-webcomponents/latest/classes/IgcBreadcrumbsComponent#separator)</PlatformBlock><PlatformBlock for="React, Blazor"><ApiLink pkg="core" type="Breadcrumbs" member="separator" label="separator" /></PlatformBlock> propiedad en el contenedor para establecer un icono de separador compartido para cada elemento del recorrido. El valor es el nombre de un icono de la colección de iconos registrada, y el contenedor lo propaga a cada elemento.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-breadcrumbs separator="slash">
  <igc-breadcrumb><a href="/home">Home</a></igc-breadcrumb>
  <igc-breadcrumb><a href="/home/products">Products</a></igc-breadcrumb>
  <igc-breadcrumb><a href="/home/products/laptops">Laptops</a></igc-breadcrumb>
  <igc-breadcrumb current><a href="/home/products/laptops/gaming">Gaming Laptop</a></igc-breadcrumb>
</igc-breadcrumbs>
```

</PlatformBlock>

### Sustitución del separador por elemento

El separador también puede sustituirse para un único elemento insertando contenido en el slot `separator` de ese elemento. Esto resulta útil para combinar separadores de texto (como `/` o `›`) con iconos, o para usar un separador totalmente distinto en cada límite.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-breadcrumbs>
  <igc-breadcrumb>
    <a href="/home">Home</a>
    <span slot="separator">/</span>
  </igc-breadcrumb>
  <igc-breadcrumb current><a href="/home/settings">Settings</a></igc-breadcrumb>
</igc-breadcrumbs>
```

</PlatformBlock>

### Qué hacer y qué no

Use breadcrumbs para orientar a los usuarios en aplicaciones con mucho contenido y tres o más niveles de jerarquía, ofreciendo una ruta clara y de poco esfuerzo para volver a las páginas superiores. No use breadcrumbs en estructuras de sitio planas de un solo nivel, donde generan un desorden visual innecesario, ni en procesos secuenciales paso a paso, donde se requieren indicadores de progreso.

## Accesibilidad

{Platform} Breadcrumbs sigue el patrón de navegación de breadcrumbs de ARIA. El contenedor expone el rol `list` de ARIA, cada elemento expone el rol `listitem` y el elemento actual se anuncia con `aria-current="page"`.

### Punto de referencia de navegación accesible

Envuelva el recorrido en un elemento `<nav>` con un `aria-label` para que la tecnología de asistencia lo exponga como un punto de referencia de navegación. La etiqueta debe ir en el `<nav>`, no en la lista, según el patrón de breadcrumbs de ARIA.

<PlatformBlock for="WebComponents, Angular">

```html
<nav aria-label="Breadcrumb">
  <igc-breadcrumbs>
    <igc-breadcrumb><a href="/">Root</a></igc-breadcrumb>
    <igc-breadcrumb current><a href="/products">Products</a></igc-breadcrumb>
  </igc-breadcrumbs>
</nav>
```

</PlatformBlock>

### Interacción por teclado

Los componentes Breadcrumbs no implementan gestión de teclado personalizada: la navegación depende del comportamiento nativo del contenido interactivo insertado en el slot:

| Clave | Acción |
| -- | -- |
| `Tab` / `Shift` + `Tab` | Mueve el foco entre los elementos interactivos (normalmente enlaces) insertados en el slot de cada elemento de breadcrumb. |
| `Enter` / `Space` | Activa el enlace que tiene el foco, según el comportamiento nativo del elemento insertado en el slot. |

### Lectores de pantalla / ARIA

- El host `Breadcrumbs` tiene `role="list"`.
- Cada host `Breadcrumb` tiene `role="listitem"`.
- Establecer `current` en `true` aplica `aria-current="page"` al host; al volver a establecerlo en `false` se elimina el atributo.
- Establecer `disabled` en `true` aplica `aria-disabled="true"` al host.
- Los iconos de separador son decorativos y los lectores de pantalla no los anuncian.

Infragistics documenta la compatibilidad de accesibilidad de {ProductName} con las áreas de las pautas de la Sección 508 y WCAG 2.1 en el tema [Cumplimiento de accesibilidad](../interactivity/accessibility-compliance.mdx).

## Solución de problemas

Las recomendaciones de solución de problemas de {Platform} Breadcrumbs siguen un formato de problema → causa → solución para los problemas habituales de integración y renderizado.

### ¿Por qué no se ve mi separador en algunos elementos?

El separador se oculta automáticamente en el último elemento del recorrido; es el comportamiento previsto según el patrón de breadcrumbs de ARIA. Si falta en un elemento inesperado, compruebe si ese elemento es el último hijo visible del contenedor.

### ¿Por qué no se renderiza el nombre de icono personalizado que establecí en «separator»?

El icono del separador debe estar registrado en el registro de iconos. Regístrelo antes de renderizar el recorrido, o use el icono predeterminado `tree_expand` que incluye el tema.

### ¿Por qué el recorrido no se ajusta a líneas en RTL?

El ajuste de líneas no es específico de RTL: se produce siempre que el ancho total del contenido supera el ancho del contenedor. En contextos RTL, el orden visual se invierte y el icono del separador se refleja automáticamente; si el recorrido sigue desbordándose, compruebe si un elemento padre impide que el contenedor ocupe su ancho natural.

## Limitaciones conocidas

{Platform} Breadcrumbs tiene las siguientes limitaciones independientes de la plataforma.

- Los componentes Breadcrumbs no implementan gestión de teclado personalizada: la activación depende del elemento interactivo insertado en cada elemento (normalmente un ancla).
- Breadcrumbs no renderiza por sí mismo un punto de referencia `<nav>`; la aplicación que lo usa debe proporcionar el wrapper `<nav aria-label="...">`.
- El contenedor no trunca automáticamente los recorridos largos. Combine el ajuste de líneas flex natural con su propia estrategia de desbordamiento (por ejemplo, plegar los elementos intermedios en un menú) cuando se requiera un recorrido de una sola línea en anchos reducidos.

## Preguntas frecuentes

<Faq>
  <FaqItem question="¿Cómo cambio el icono del separador entre los elementos?" indicatorPosition="end">
    Establezca la propiedad `separator` del contenedor Breadcrumbs con el nombre de cualquier icono registrado; el contenedor propaga el icono a cada elemento descendiente. Para sustituir el separador de un único elemento, inserte el contenido de reemplazo en el slot `separator` de ese elemento.
  </FaqItem>

  <FaqItem question="¿Necesito ocultar manualmente el último separador?" indicatorPosition="end">
    No. El elemento de breadcrumb oculta automáticamente su separador final cuando es el último elemento del recorrido, así que puede renderizar los elementos en un bucle sin ningún tratamiento especial.
  </FaqItem>

  <FaqItem question="¿Renderiza el componente Breadcrumbs por sí mismo un punto de referencia <nav>?" indicatorPosition="end">
    No. Breadcrumbs se renderiza como una `list` de ARIA con `listitem` hijos. Según el patrón de breadcrumbs de ARIA, la aplicación que lo usa envuelve el contenedor en `<nav aria-label="Breadcrumb">` (o en una etiqueta más específica), para que el nombre accesible esté en el punto de referencia y no en la lista.
  </FaqItem>

  <FaqItem question="¿Cómo marco la página actual?" indicatorPosition="end">
    Establezca la propiedad `current` en el elemento de breadcrumb que representa la página que se está viendo. El elemento refleja `current` como atributo y aplica `aria-current="page"` en el host, para que los lectores de pantalla anuncien qué entrada es la página actual.
  </FaqItem>

  <FaqItem question="¿Qué paquete debo instalar para Breadcrumbs?" indicatorPosition="end">
    <PlatformBlock for="WebComponents, Angular">Breadcrumbs se distribuye en el paquete `igniteui-webcomponents`, versión 7.4.0 o posterior.</PlatformBlock>
    <PlatformBlock for="Angular">Las aplicaciones de Angular lo instalan directamente porque `igniteui-angular` no incluye Breadcrumbs.</PlatformBlock>
    <PlatformBlock for="React, Blazor">Breadcrumbs se distribuye en el paquete `{PackageCommon}`.</PlatformBlock>
  </FaqItem>
</Faq>
