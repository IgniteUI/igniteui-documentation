# Descripción general de {Platform} Stepper

El componente {Platform} Stepper ofrece un flujo de trabajo de tipo asistente y se usa para mostrar el progreso mediante pasos numerados. Permite a los desarrolladores dividir un contenido extenso en una secuencia de pasos lógicos, lo que ayuda a los usuarios finales a recorrer el proceso completo con más facilidad. El {Platform} Stepper se muestra como una línea vertical u horizontal. El {Platform} Stepper tiene varias funciones, como validación de pasos, estilos, orientación y navegación por teclado.

## Cómo usar {Platform} Stepper
El <ApiLink pkg="core" type="Step" /> es la representación de cada paso que pertenece a <ApiLink pkg="core" type="Stepper" />. Los pasos ofrecen las propiedades <ApiLink pkg="core" type="Step" member="Invalid" label="Step.Invalid" />, <ApiLink pkg="core" type="Step" member="Active" label="Step.Active" />, <ApiLink pkg="core" type="Step" member="Optional" label="Step.Optional" />, <ApiLink pkg="core" type="Step" member="Disabled" label="Step.Disabled" /> y <ApiLink pkg="core" type="Step" member="Complete" label="Step.Complete" />, que le permiten configurar los estados de cada paso según los requisitos de su negocio.

### Orientación en {Platform} Stepper

Puede personalizar la orientación del stepper mediante la propiedad <ApiLink pkg="core" type="Stepper" member="orientation" label="Orientation" /> expuesta. Puede establecerse en **horizontal** o **vertical**.

**Orientación horizontal del Stepper**

**horizontal** es el valor predeterminado de la propiedad de orientación <ApiLink pkg="core" type="Stepper" />.

Cuando el stepper {Platform} tiene orientación horizontal, puede decidir si el contenido de los pasos se muestra encima o debajo de los encabezados de los pasos. Esto se consigue estableciendo la propiedad booleana <ApiLink pkg="core" type="Stepper" /> <ApiLink pkg="core" type="Stepper" member="contentTop" label="ContentTop" />, cuyo valor predeterminado es **false**. Si se habilita, el contenido de los pasos se muestra encima de los encabezados de los pasos.

### Estados de los pasos

{Platform} <ApiLink pkg="core" type="Stepper" /> admite cinco estados de paso, y cada uno aplica estilos distintos de forma predeterminada:

- **active**: determina si el paso es el que se muestra actualmente. Por diseño, si el usuario no establece explícitamente el atributo active de un paso en **true**, el paso activo inicial será el primer paso no deshabilitado.
- **disabled**: determina si el paso es inaccesible. De forma predeterminada, el atributo disabled de un paso está establecido en **false**.
- **invalid**: determina si el paso es válido. Según su valor, se decide si el usuario puede avanzar en el modo de stepper lineal. Su valor predeterminado es **false**.
- **optional**: de forma predeterminada, el atributo optional de un paso está establecido en **false**. Si no se requiere la validez de un paso en un stepper lineal, puede habilitarse el atributo optional para poder avanzar independientemente de la validez del paso.
- **complete**: de forma predeterminada, el atributo complete de un paso devuelve **false**. Sin embargo, el usuario puede sustituir este comportamiento predeterminado estableciendo el atributo complete según sea necesario. Cuando un paso se marca como completo, no solo cambia el estilo del encabezado del paso de forma predeterminada, sino también el estilo de la línea de progreso entre el paso completado y el siguiente.

El {Platform} <ApiLink pkg="core" type="Stepper" /> le permite establecer el flujo de sus pasos mediante la propiedad <ApiLink pkg="core" type="Stepper" member="linear" label="Linear" />. La validez de los pasos opcionales no se tiene en cuenta para avanzar.
</DocsAside>

### Interacciones con los pasos

<ApiLink pkg="core" type="Stepper" /> proporciona los siguientes métodos de la API para las interacciones con los pasos:
- **navigateTo**: activa el paso indicado por el índice dado.
- **next**: activa el siguiente paso no deshabilitado.
- **prev**: activa el paso anterior no deshabilitado.
- **reset**: restablece el stepper a su estado inicial.

<DocsAside type="info">
El método reset devolvería el stepper a su estado inicial, es decir, activaría el primer paso. No borraría el contenido de los pasos. Esto debe hacerse manualmente.
</DocsAside>

### Personalizar los pasos

El {ProductName} Stepper le permite configurar distintas opciones para los títulos, los indicadores y mucho más.

Esto se consigue mediante la propiedad <ApiLink pkg="core" type="Stepper" member="stepType" label="StepType" /> de <ApiLink pkg="core" type="Stepper" />. Acepta los siguientes valores:
- Full **(valor predeterminado)**
- Indicator
- Título

**full**

Si se definen títulos y subtítulos, con esta configuración se renderizarán tanto los indicadores como los títulos.

El usuario también puede definir la posición del título de los pasos, de modo que pueda colocarse antes, después, encima o debajo del indicador del paso.
El usuario puede configurar la posición del título mediante la propiedad <ApiLink pkg="core" type="Stepper" member="titlePosition" label="TitlePosition" />. Acepta los siguientes valores:
- undefined **(valor predeterminado)**
- end
- start
- bottom
- top

Cuando el {Platform} <ApiLink pkg="core" type="Stepper" /> tiene orientación horizontal y la posición del título **no está definida**, los títulos se muestran **debajo** de los indicadores.

Cuando la orientación es vertical y la posición del título **no está definida**, los títulos se muestran **después** de los indicadores.

<DocsAside type="info">
La propiedad **titlePosition** se aplica **solo** cuando la propiedad stepType del stepper está establecida en **full**.
</DocsAside>

**indicator**

Si quiere mostrar solo los indicadores de los pasos, establezca la opción stepType en **indicator**.

El indicador de paso admite cualquier contenido, aunque con la restricción de que su tamaño será siempre de **24 píxeles**. Teniendo esto en cuenta, recomendamos usar <ApiLink pkg="core" type="Icon" /> o <ApiLink pkg="core" type="Avatar" /> como indicadores de paso.

**Title**

Si quiere mostrar solo los títulos de los pasos, establezca la opción stepType en **title**.

De este modo, si se definen subtítulos, también se renderizarán debajo del título del paso.

<DocsAside type="info">
Este contenedor puede volver a tener plantilla según sus necesidades, sin restricciones de tamaño. Por ejemplo, puede añadir dentro de él un indicador de más de 24 píxeles.
</DocsAside>

### Altura dinámica de los pasos

Cuando <ApiLink pkg="core" type="Stepper" /> tiene orientación horizontal, la altura del área de contenido la determina el paso con más contenido. Todos los demás pasos comparten esta altura fija, lo que puede dejar un espacio vacío visible en los pasos con menos contenido.

Para sustituir la altura fija y hacer que el área de contenido se adapte al contenido del paso activo, establezca la variable CSS **--body-grid-rows** en **0fr** (el valor predeterminado es **1fr**):

```css
igc-stepper {
  --body-grid-rows: 0fr;
}
```

### Animaciones del Stepper

Las animaciones de {Platform} <ApiLink pkg="core" type="Stepper" /> ofrecen a los usuarios finales una experiencia atractiva al interactuar con los pasos definidos. Las opciones de animación disponibles varían según la orientación del stepper.

Cuando el stepper tiene orientación horizontal, está configurado para usar la animación `slide` de forma predeterminada. También admite `fade` como alternativa. Las animaciones se configuran mediante la entrada <ApiLink pkg="core" type="Stepper" member="horizontalAnimation" label="HorizontalAnimation" />.

En un diseño con orientación vertical, el tipo de animación puede definirse mediante la propiedad <ApiLink pkg="core" type="Stepper" member="verticalAnimation" label="VerticalAnimation" />. De forma predeterminada, su valor es `grow`, y el usuario también puede establecerlo en `fade`.

Establecer `none` en ambas entradas de tipo de animación desactiva las animaciones del stepper.

El componente <ApiLink pkg="core" type="Stepper" /> también permite configurar la duración de la transición entre los pasos. Esto se consigue mediante la propiedad <ApiLink pkg="core" type="Stepper" member="animationDuration" label="AnimationDuration" />, que recibe un número como argumento y es común a ambas orientaciones. El valor predeterminado es 320 ms.

## Navegación por teclado

El {ProductName} Stepper ofrece al usuario final una gran variedad de interacciones por teclado. Esta funcionalidad está habilitada de forma predeterminada y permite a los usuarios finales desplazarse con facilidad por los pasos.
La navegación de {Platform} <ApiLink pkg="core" type="Stepper" /> cumple las [normas de accesibilidad de W3C](https://www.w3.org/WAI/ARIA/apg/patterns/tabpanel/) y es cómoda de usar.

**Combinaciones de teclas**

- <kbd>TAB</kbd>: mueve el foco al siguiente elemento enfocable con tabulación
- <kbd>SHIFT</kbd> + <kbd>TAB</kbd>: mueve el foco al elemento enfocable anterior con tabulación
- <kbd>↓</kbd>: mueve el foco al encabezado del siguiente paso accesible cuando el stepper tiene **orientación vertical**
- <kbd>↑</kbd>: mueve el foco al encabezado del paso accesible anterior cuando el stepper tiene **orientación vertical**
- <kbd>←</kbd>: mueve el foco al encabezado del paso accesible anterior en ambas orientaciones
- <kbd>→</kbd>: mueve el foco al encabezado del siguiente paso accesible en ambas orientaciones
- <kbd>HOME</kbd>: mueve el foco al encabezado del PRIMER paso habilitado del stepper
- <kbd>END</kbd>: mueve el foco al encabezado del ÚLTIMO paso habilitado del stepper
- <kbd>ENTER</kbd> o <kbd>SPACE</kbd>: activa el paso enfocado

## Dar estilo a {Platform} Stepper

Puede cambiar el aspecto de <ApiLink pkg="core" type="Step" /> usando algunas de las partes CSS expuestas que se indican a continuación:

| Nombre de la parte | Descripción |
| ---------|------------ |
| `header-container` | Wrapper del encabezado del paso y de sus separadores. |
| `disabled` | Indica un estado deshabilitado. Se aplica a header-container. |
| `complete-start` | Indica un estado completo del paso actual. Se aplica a header-container. |
| `complete-end` | Indica un estado completo del paso anterior. Se aplica a header-container. |
| `optional` | Indica un estado opcional. Se aplica a header-container. |
| `invalid` | Indica un estado no válido. Se aplica a header-container. |
| `top` | Indica que el título debe estar encima del indicador. Se aplica a header-container. |
| `bottom` | Indica que el título debe estar debajo del indicador. Se aplica a header-container. |
| `start` | Indica que el título debe estar antes del indicador. Se aplica a header-container. |
| `end` | Indica que el título debe estar después del indicador. Se aplica a header-container. |
| `header` | Wrapper del indicador del paso y de su texto. |
| `indicator` | El indicador del paso. |
| `text` | Wrapper del título y del subtítulo del paso. |
| `empty` | Indica que no se ha proporcionado ningún título ni subtítulo al paso. Se aplica a text. |
| `title` | El título del paso. |
| `subtitle` | El subtítulo del paso. |
| `body` | Wrapper del contenido del paso. |

}

  background-color: var(--ig-surface-500);
}
