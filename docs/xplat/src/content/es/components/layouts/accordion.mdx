### Expansión mediante programación

<PlatformBlock for="Angular">

Use <ApiLink type="Accordion" member="collapseAll" label="collapseAll()" /> y <ApiLink type="Accordion" member="expandAll" label="expandAll()" /> para contraer o expandir los paneles del accordion mediante programación.

<DocsAside type="info">
Llamar a <ApiLink type="Accordion" member="expandAll" label="expandAll()" /> expande solo el último panel habilitado cuando <ApiLink type="Accordion" member="singleBranchExpand" label="singleBranchExpand" /> es `true`.
</DocsAside>

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

Use <ApiLink pkg="core" type="Accordion" member="hideAll" label="HideAll" /> y <ApiLink pkg="core" type="Accordion" member="showAll" label="ShowAll" /> para contraer o expandir todos los paneles disponibles mediante programación.

<DocsAside type="info">
Llamar a <ApiLink pkg="core" type="Accordion" member="showAll" label="ShowAll" /> expande todos los paneles, incluso cuando <ApiLink pkg="core" type="Accordion" member="singleExpand" label="SingleExpand" /> es `true`.
</DocsAside>

</PlatformBlock>

### Qué hacer y qué no

**Cuándo usarlo:** use el accordion cuando necesite organizar contenido secundario, entradas de preguntas frecuentes, grupos de ajustes u otras secciones verticales relacionadas que los usuarios expandan según lo necesiten. Mantenga los títulos de los paneles breves y descriptivos, y habilite el comportamiento de expansión única cuando los usuarios deban centrarse en una sección cada vez.

<PlatformBlock for="Angular">

**Cuándo no usarlo:** use [Expansion Panel](../expansion-panel.mdx) cuando necesite una única sección expandible independiente, en lugar de un contenedor coordinado que gestione varios paneles a la vez. No use un accordion para ocultar contenido principal esencial ni para agrupar secciones no relacionadas.

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

**Cuándo no usarlo:** use [Expansion Panel](./expansion-panel.mdx) cuando necesite una única sección expandible independiente, en lugar de un contenedor coordinado que gestione varios paneles a la vez. No use un accordion para ocultar contenido principal esencial ni para agrupar secciones no relacionadas.

</PlatformBlock>

## Propiedades

El accordion expone controles a nivel de contenedor; el estado de cada panel se configura en cada <ApiLink pkg="core" type="ExpansionPanel" />.

<PlatformBlock for="Angular">

| Nombre | Tipo | Valor predeterminado | Descripción |
| -- | -- | -- | -- |
| <ApiLink type="Accordion" member="singleBranchExpand" label="singleBranchExpand" /> | `boolean` | `false` | Determina si uno o varios paneles pueden permanecer expandidos al mismo tiempo. |
| <ApiLink type="Accordion" member="panels" label="panels" /> | `QueryList<IgxExpansionPanelComponent>` | n/a | Devuelve la colección de paneles de expansión hijos del accordion. |

</PlatformBlock>

<PlatformBlock for="WebComponents, React, Blazor">

| Nombre | Tipo | Valor predeterminado | Descripción |
| -- | -- | -- | -- |
| <ApiLink pkg="core" type="Accordion" member="singleExpand" label="SingleExpand" /> | `boolean` | `false` | Determina si uno o varios paneles pueden permanecer expandidos al mismo tiempo. |
| <ApiLink pkg="core" type="Accordion" member="panels" label="Panels" /> | <ApiLink pkg="core" type="ExpansionPanel" label="ExpansionPanel[]" /> | n/a | Devuelve la colección de paneles de expansión hijos del accordion. |

</PlatformBlock>

### Variables de estilo

Use las variables CSS del tema de {ProductName} como valores al dar estilo a las partes del panel de expansión.

| Variable | Qué cambia |
| -- | -- |
| `--ig-secondary-900` | Proporciona el color de fondo oscuro que usan el panel y el encabezado en el ejemplo siguiente. |
| `--ig-secondary-900-contrast` | Proporciona un color de primer plano legible para el contenido sobre `--ig-secondary-900`. |
| `--ig-warn-500` | Proporciona el color de acento que usan el indicador, el título y el subtítulo en el ejemplo siguiente. |

### Lectores de pantalla / ARIA

La semántica de accesibilidad del accordion se proporciona a través de sus paneles de expansión hijos y de sus encabezados.

- Cada encabezado de panel expone `role="button"`, `aria-expanded` y `aria-controls`.
- Cada cuerpo de panel expone `role="region"` y una etiqueta mediante `aria-labelledby` o `aria-label`.
- Use un texto de título claro para cada panel, para que las tecnologías de asistencia puedan anunciar una etiqueta significativa.
- Mantenga el contenido interactivo dentro de los cuerpos de los paneles en un orden de tabulación lógico.

## Preguntas frecuentes

<Faq>
  <FaqItem question="¿Deben poder estar abiertos varios paneles del accordion al mismo tiempo?" indicatorPosition="end">
    Permita que varios paneles permanezcan abiertos cuando los usuarios necesiten comparar o cruzar su contenido. Use el comportamiento de expansión única cuando el flujo sea más claro con una sola sección activa cada vez.
  </FaqItem>
  <FaqItem question="¿Cuándo debo evitar usar un accordion?" indicatorPosition="end">
    Evite usar un accordion para contenido esencial, largo o que requiera comparación constante y que los usuarios necesiten leer de una vez. Use encabezados claros, una página independiente u otro diseño cuando ocultar el contenido dificultaría encontrarlo o compararlo.
  </FaqItem>
  <FaqItem question="¿Cómo debo escribir los encabezados del accordion?" indicatorPosition="end">
    Use encabezados cortos y descriptivos que identifiquen claramente el contenido que muestra cada panel. Los usuarios deben poder recorrer los encabezados y decidir qué sección abrir.
  </FaqItem>
  <FaqItem question="¿Puede un encabezado de accordion contener otros botones o enlaces?" indicatorPosition="end">
    Evite colocar otros controles interactivos dentro del encabezado de un accordion. Mantenga las acciones secundarias fuera del encabezado para que el disparador del panel siga siendo claro y no contenga elementos interactivos anidados.
  </FaqItem>
</Faq>
