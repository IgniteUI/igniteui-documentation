# Descripción general de {Platform} Tile Manager

El componente {ProductName} Tile Manager permite mostrar contenido en mosaicos individuales. Permite a los usuarios interactuar con estos mosaicos reordenándolos y redimensionándolos, dándoles libertad para personalizar el diseño y el aspecto del contenido según sus preferencias. Esta flexibilidad mejora la experiencia de usuario, porque permite ver y gestionar el contenido de una forma más personalizada y eficiente.

## Uso

El <ApiLink pkg="core" type="TileManager" /> proporciona un comportamiento base de diseño por mosaicos, gestionando la colocación de los mosaicos en estado maximizado o normal. Los mosaicos pueden dimensionarse de forma independiente entre sí y usarse para formar diseños complejos. Los usuarios finales pueden reordenar los mosaicos arrastrándolos y soltándolos, lo que ofrece una experiencia flexible e intuitiva.

El Tile Manager ofrece dos componentes que podemos usar:

- <ApiLink pkg="core" type="Tile" />: representa un mosaico individual mostrado dentro del Tile Manager.
- <ApiLink pkg="core" type="TileManager" />: es el componente principal que contiene todos los componentes de mosaico, y actúa como contenedor de toda la disposición de mosaicos.

### Columnas y filas

Podemos especificar el número de columnas de la cuadrícula de Tile Manager. Para ello, basta con establecer la propiedad <ApiLink pkg="core" type="TileManager" member="columnCount" label="ColumnCount" /> en el número de columnas deseado. ## Componente Tile

El componente Tile tiene propiedades que pueden establecerse de forma individual para cada mosaico. Algunas de estas propiedades son:

- La propiedad <ApiLink pkg="core" type="Tile" member="colSpan" label="ColSpan" /> especifica cuántas columnas ocupará el mosaico en el diseño, lo que permite controlar su tamaño horizontal.
- La propiedad <ApiLink pkg="core" type="Tile" member="rowSpan" label="RowSpan" /> determina cuántas filas ocupará verticalmente el mosaico, ajustando la altura del mosaico dentro del diseño.
- La propiedad <ApiLink type="ColumnState" member="colStart" label="ColStart" /> especifica la columna inicial donde se coloca el mosaico.
- La propiedad <ApiLink pkg="core" type="Tile" member="rowStart" label="RowStart" /> especifica la fila inicial donde se coloca el mosaico.
- La propiedad <ApiLink pkg="core" type="Tile" member="disableFullscreen" label="DisableFullscreen" /> oculta el botón de acción de pantalla completa predeterminado.
- La propiedad <ApiLink pkg="core" type="Tile" member="disableMaximize" label="DisableMaximize" /> oculta el botón de acción de alternar maximizado predeterminado.
- La propiedad <ApiLink pkg="core" type="Tile" member="disableResize" label="DisableResize" /> impide que el usuario redimensione el mosaico.

| Nombre del slot | Descripción |
| ---------|------------ |
| `title` | Contenido del encabezado del mosaico. |
| `fullscreen-action` | Sustituye el contenido de la acción de pantalla completa predeterminada. |

Al usar el slot `title`, recomendamos usar un elemento `<span>` en lugar de elementos de encabezado (`<h1>`–`<h6>`). Usar un `<span>` le da un contenedor neutro que hereda limpiamente los estilos del componente.

Al usar los slots `fullscreen-action`, `maximize-action`, `actions`, `side-adorner`, `corner-adorner` y `bottom-adorner`, recomendamos usar un componente [`<igc-icon>`](../layouts/icon.mdx) o [`<igc-icon-button>`](../inputs/icon-button.mdx) para los iconos personalizados.

## Redimensionamiento

El redimensionado en Tile Manager es una función que permite redimensionar los mosaicos mediante tres adornos de redimensionado distintos.

- **Adorno lateral**: ajusta el ancho modificando la extensión de columnas.
- **Adorno inferior**: ajusta el alto modificando la extensión de filas.
- **Adorno de esquina**: ajusta el ancho y el alto a la vez.

Para garantizar un redimensionado fluido, se usa un elemento fantasma en lugar de modificar directamente las dimensiones del mosaico. Este elemento aparece encima del mosaico original, muestra sus dimensiones actuales al empezar el redimensionado y se actualiza en tiempo real mientras el usuario arrastra cualquiera de los tiradores de redimensionado.

<DocsAside type="info">
Si el elemento fantasma supera el espacio de cuadrícula disponible, se ajustará automáticamente a la extensión máxima posible dentro de los límites de la cuadrícula.
</DocsAside>

Tile Manager se reorganiza automáticamente cuando un mosaico cambia de tamaño, para garantizar que haya el mínimo espacio vacío. Por eso, al ampliar un mosaico, los mosaicos adyacentes pueden desplazarse a nuevas posiciones, mientras que al reducirlo se crean huecos que otros mosaicos pueden ocupar dinámicamente. Así Tile Manager se mantiene lo más compacto posible, sin mosaicos superpuestos, y todos los movimientos permanecen dentro de la estructura de cuadrícula definida.

Podemos usar la propiedad <ApiLink pkg="core" type="TileManager" member="resizeMode" label="ResizeMode" /> para controlar cómo se aplica el redimensionado en Tile Manager. Puede establecerse en `none`, `hover` o `always`, lo que determina cuándo son visibles los adornos de redimensionado. El valor predeterminado es `none` y el mosaico no puede redimensionarse.

### Ajuste a la cuadrícula

Los mosaicos se redimensionan en unidades completas de cuadrícula, lo que significa que solo pueden crecer o reducirse por columnas o filas completas. El elemento fantasma se ajusta a la siguiente columna o fila al ampliarse más allá del punto medio, y a la anterior al reducirse más allá de la mitad. Esto se aplica a todos los adornos (inferior, lateral y de esquina), garantizando que los mosaicos siempre permanezcan alineados con la cuadrícula.

También se tienen en cuenta los huecos de la cuadrícula, lo que mantiene el diseño coherente durante el redimensionado.

### Limitaciones

El proceso de redimensionado tiene varias restricciones y limitaciones:

- Un mosaico no puede redimensionarse por debajo de su ancho o alto mínimos definidos (<ApiLink pkg="core" type="TileManager" member="minColumnWidth" label="MinColumnWidth" />, <ApiLink pkg="core" type="TileManager" member="minRowHeight" label="MinRowHeight" />).
- Un mosaico no puede superar el espacio horizontal máximo disponible en la cuadrícula.

## Reordenar

Puede reordenar los mosaicos en Tile Manager mediante la función de arrastrar y soltar. De forma predeterminada, los mosaicos no se pueden arrastrar. Para habilitar esta función, establezca la propiedad <ApiLink pkg="core" type="TileManager" member="dragMode" label="DragMode" /> de Tile Manager en `tile` o en `tile-header`.

- Con la opción `tile`, puede hacer clic y mantener pulsado en cualquier parte de un mosaico individual para empezar a arrastrarlo.
- Con la opción `tile-header`, solo puede hacer clic y mantener pulsado en la sección de encabezado del mosaico para empezar el proceso de arrastre.

<DocsAside type="info">
Mientras el mosaico está en estado maximizado o de pantalla completa, no puede arrastrarse.
</DocsAside>

Igual que con el redimensionado, al iniciar el proceso de arrastrar y soltar aparece un elemento fantasma debajo del mosaico que ha agarrado. A medida que arrastra el mosaico, el elemento fantasma se mueve con él, reordenando dinámicamente los demás mosaicos en tiempo real. Así puede previsualizar cómo quedará la cuadrícula de mosaicos al soltar el mosaico.

## Serialización

Tile Manager ofrece métodos que ayudan a gestionar el diseño de los mosaicos:

- El método <ApiLink pkg="core" type="TileManager" member="saveLayout" label="SaveLayout" /> permite guardar la disposición actual de los mosaicos en Tile Manager: captura el orden, el tamaño y la posición actuales de todos los mosaicos, de modo que más adelante puede restaurarla exactamente a esta configuración.
- El método <ApiLink pkg="core" type="TileManager" member="loadLayout" label="LoadLayout" /> permite cargar un diseño guardado previamente. Al llamarlo, restaura los mosaicos exactamente al estado en el que estaban cuando se guardó el diseño, incluidos su orden, su tamaño y su posición.

## Estilos

También puede personalizar el aspecto de los dos componentes: <ApiLink pkg="core" type="TileManager" /> y <ApiLink pkg="core" type="Tile" />.
<ApiLink pkg="core" type="TileManager" /> expone solo una propiedad CSS, `base`, que puede usarse para dar estilo al wrapper base de Tile Manager.
<ApiLink pkg="core" type="Tile" /> expone varias propiedades CSS que podemos usar:

| Nombre de la parte | Descripción |
| ---------|------------ |
| `base` | El contenedor envolvente del componente de mosaico. |
| `header` | El contenedor del encabezado del mosaico, que incluye las partes de título y de acciones. |
| `title` | El contenedor del título. |
| `actions` | El contenedor de acciones. |
| `content-container` | El contenedor que envuelve el slot predeterminado del mosaico. |
| `trigger-side` | El adorno horizontal. |
| `trigger` | El adorno diagonal |
| `trigger-bottom` | El adorno vertical. |

Con estas partes CSS puede personalizar el aspecto de los dos componentes de la siguiente manera:

```css
igc-tile-manager::part(base) {
  background-color: var(--ig-surface-900);
}

igc-tile::part(content-container) {
  color: var(--ig-secondary-200);
}

igc-tile::part(header) {
  background-color: var(--ig-gray-300);
}

igc-tile::part(title) {
  color: var(--ig-primary-400);
}

igc-tile:nth-child(n+2)::part(trigger-side),
igc-tile:nth-child(n+2)::part(trigger-bottom) {
  background-color: var(--ig-success-500);
}

igc-tile:nth-child(n+2)::part(trigger) {
  background-color: var(--ig-error-500);
}
```

También puede cambiar el icono de los adornos por uno personalizado usando los slots `side-adorner`, `corner-adorner` y `bottom-adorner`. Por ejemplo:

<PlatformBlock for="WebComponents">

```html
<igc-tile>
  <igc-icon slot="side-adorner" class="side" name="indicator"></igc-icon>
  <igc-icon slot="corner-adorner" class="corner" name="indicator"></igc-icon>
  <igc-icon slot="bottom-adorner" class="bottom" name="indicator"></igc-icon>
  <span slot="title">Tile header</span>
</igc-tile>
```

</PlatformBlock>
