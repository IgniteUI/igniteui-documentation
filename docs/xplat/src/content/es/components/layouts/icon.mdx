# Icon

El {ProductName} Icon es un componente que renderiza un icono con nombre de un conjunto de iconos registrado, como una colección de iconos SVG personalizados.

<PlatformBlock for="Angular">

De forma predeterminada, el Icon de Angular renderiza los ligaduras de Material Icons. Registre iconos SVG y otras fuentes de iconos con `IgxIconService` para usarlos de la misma manera.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Registre los iconos SVG por nombre en una colección y, después, muestre cada icono con un tamaño basado en el tema y en el color del texto que lo rodea.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

El {Platform} Icon renderiza un elemento `igc-icon`, que dibuja el SVG registrado en su shadow root y no expone partes CSS:

```text
igc-icon                 // host - inline box sized by --size
└─ #shadow-root
   └─ svg                // the registered SVG, 1em × 1em, filled with the current color
```

</PlatformBlock>

<PlatformBlock for="Angular">

El elemento `igx-icon` renderiza uno de los siguientes, según el tipo de su familia de iconos:

```text
igx-icon.igx-icon[aria-hidden="true"]   // host - also carries the family class, e.g. .material-icons
├─ ligature text                        // `liga` family - the icon name, e.g. home
├─ div > svg                            // SVG icon registered with IgxIconService
└─ ng-content                           // projected ligature text when `name` isn't set
```

Para una familia `font`, las clases del host dibujan el glifo y el elemento no tiene contenido.

</PlatformBlock>

## Uso

Use el {Platform} Icon para añadir un símbolo reconocible a etiquetas, botones, elementos de lista y navegación, o para mostrar un estado de un vistazo.

<PlatformBlock for="React,WebComponents,Blazor">

### Nombre y colección

El {Platform} Icon dibuja el SVG registrado con su nombre en su colección. La colección predeterminada es `default`. Todos los iconos de la página comparten un único registro, así que un icono que registre una vez está disponible para todos los Icon, y un Icon que se renderiza antes de que su SVG esté registrado se actualiza en cuanto lo registra.

</PlatformBlock>

<PlatformBlock for="WebComponents">

Registre el marcado SVG con <ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" />, o recupere un archivo SVG desde una URL con <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" />:

```ts
import { registerIcon, registerIconFromText } from 'igniteui-webcomponents';

const searchIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

registerIconFromText('search', searchIcon, 'material');
registerIcon('build', '/icons/build.svg', 'material');
```

A continuación, establezca el mismo nombre y la misma colección en cada icono:

```html
<igc-icon name="search" collection="material"></igc-icon>
<igc-icon name="build" collection="material"></igc-icon>
```

</PlatformBlock>

<PlatformBlock for="React">

Registre el marcado SVG con <ApiLink pkg="core" type="registerIconFromText" kind="function" label="registerIconFromText" />, o recupere un archivo SVG desde una URL con <ApiLink pkg="core" type="registerIcon" kind="function" label="registerIcon" />. Después establezca el mismo nombre y la misma colección en cada icono:

```tsx
import { useEffect } from 'react';
import { IgrIcon, registerIcon, registerIconFromText } from 'igniteui-react';

const searchIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

export default function SearchToolbar() {
  useEffect(() => {
    registerIconFromText('search', searchIcon, 'material');
    registerIcon('build', '/icons/build.svg', 'material');
  }, []);

  return (
    <>
      <IgrIcon name="search" collection="material" />
      <IgrIcon name="build" collection="material" />
    </>
  );
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Registre el marcado SVG con el método <ApiLink pkg="core" type="Icon" member="RegisterIconFromTextAsync" label="RegisterIconFromTextAsync" />, o recupere un archivo SVG desde una URL con <ApiLink pkg="core" type="Icon" member="RegisterIconAsync" label="RegisterIconAsync" />. Llámelos sobre un `IgbIcon` referenciado cuando esté listo, y después establezca el mismo `IconName` y `Collection` en cada icono:

```razor
<IgbIcon @ref="SearchIcon" IconName="search" Collection="material" />
<IgbIcon IconName="build" Collection="material" />

@code {
    private IgbIcon SearchIcon { get; set; }

    private const string SearchSvg = "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'><path d='M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z'/></svg>";

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender && SearchIcon != null)
        {
            await SearchIcon.EnsureReady();
            await SearchIcon.RegisterIconFromTextAsync("search", SearchSvg, "material");
            await SearchIcon.RegisterIconAsync("build", "/icons/build.svg", "material");
        }
    }
}
```

### Nombre y familia

El Icon de Angular busca su <ApiLink pkg="core" type="Icon" member="name" label="name" /> en su <ApiLink pkg="core" type="Icon" member="family" label="family" />. La familia `material` predeterminada renderiza ligaduras de Material Icons, así que el nombre es la ligadura, como `home` o `favorite`:

```html
<igx-icon name="home"></igx-icon>
<igx-icon name="favorite"></igx-icon>
```

También puede proyectar la ligadura como contenido:

```html
<igx-icon>bluetooth</igx-icon>
```

### Iconos SVG

Registre los iconos SVG con <ApiLink pkg="core" type="IconService" /> y establezca después su nombre y su familia en el icono. El método <ApiLink pkg="core" type="IconService" member="addSvgIcon" label="addSvgIcon" /> recupera un archivo SVG desde una URL, y <ApiLink pkg="core" type="IconService" member="addSvgIconFromText" label="addSvgIconFromText" /> registra el marcado SVG:

```ts
import { Component, OnInit, inject } from '@angular/core';
import { IgxIconComponent, IgxIconService } from 'igniteui-angular/icon';

const searchIcon =
    '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M15.5 14h-.79l-.28-.27C15.41 12.59 16 11.11 16 9.5 16 5.91 13.09 3 9.5 3S3 5.91 3 9.5 5.91 16 9.5 16c1.61 0 3.09-.59 4.23-1.57l.27.28v.79l5 4.99L20.49 19l-4.99-5zm-6 0C7.01 14 5 11.99 5 9.5S7.01 5 9.5 5 14 7.01 14 9.5 11.99 14 9.5 14z"/></svg>';

@Component({
    selector: 'app-filter-icons',
    template: `
        <igx-icon name="contains" family="filter-icons"></igx-icon>
        <igx-icon name="search" family="filter-icons"></igx-icon>
    `,
    imports: [IgxIconComponent]
})
export class FilterIconsComponent implements OnInit {
    private iconService = inject(IgxIconService);

    public ngOnInit() {
        this.iconService.addSvgIcon('contains', 'assets/images/svg/contains.svg', 'filter-icons');
        this.iconService.addSvgIconFromText('search', searchIcon, 'filter-icons');
    }
}
```

Cuando un icono SVG y una ligadura comparten el mismo nombre y la misma familia, el icono renderiza el SVG.

### Familias de fuentes

Use <ApiLink pkg="core" type="IconService" member="setFamily" label="setFamily" /> para añadir otra fuente de iconos, como [Material Symbols](https://fonts.google.com/icons), como familia. Cargue primero la hoja de estilos de la fuente:

```html
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" rel="stylesheet" />
```

Asigne el nombre de la familia a la clase CSS de la fuente y establezca su tipo en `liga`:

```ts
this.iconService.setFamily('material-symbols', { className: 'material-symbols-outlined', type: 'liga' });
```

A continuación, establezca la familia en el icono. Material Symbols es una fuente variable, así que puede ajustar opciones como el relleno y el grosor:

```html
<igx-icon family="material-symbols" name="diamond" class="custom-icon"></igx-icon>
```

```scss
.custom-icon {
  font-variation-settings: "FILL" 0, "wght" 200, "GRAD" 0, "opsz" 40;
}
```

El tema [Icon Service](../icon-service.mdx) cubre las familias del tipo `font`, los prefijos de nombre y las referencias de iconos.

</PlatformBlock>

### Referencias de iconos

Una referencia de icono apunta un nombre de icono a otro icono registrado. Componentes como Combo y Date Picker renderizan sus iconos integrados mediante referencias en la colección `default`, y una referencia que usted establezca tiene prioridad sobre ellas. Por ejemplo, apunte la referencia `input_clear` a su propio icono para sustituir el icono de borrado de estos dos componentes:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
import { registerIconFromText, setIconRef } from 'igniteui-webcomponents';

const closeIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z"/></svg>';

registerIconFromText('close', closeIcon, 'my-icons');
setIconRef('input_clear', 'default', { name: 'close', collection: 'my-icons' });
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
import { registerIconFromText, setIconRef } from 'igniteui-react';

const closeIcon =
  '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"><path d="M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z"/></svg>';

registerIconFromText('close', closeIcon, 'my-icons');
setIconRef('input_clear', 'default', { name: 'close', collection: 'my-icons' });
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIcon @ref="CloseIcon" IconName="close" Collection="my-icons" />

@code {
    private IgbIcon CloseIcon { get; set; }

    private const string CloseSvg = "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'><path d='M19 6.41 17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z'/></svg>";

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender && CloseIcon != null)
        {
            await CloseIcon.EnsureReady();
            await CloseIcon.RegisterIconFromTextAsync("close", CloseSvg, "my-icons");
            await CloseIcon.SetIconRefAsync("input_clear", "default", new IgbIconMeta()
            {
                Name = "close",
                Collection = "my-icons",
            });
        }
    }
}
```

### Tamaño

El {Platform} Icon admite los presets de tamaño pequeño, mediano y grande del tema, y usa de forma predeterminada el preset grande. Establezca la variable CSS `--ig-size` en `--ig-size-small`, `--ig-size-medium` o `--ig-size-large` para elegir un preset:

```css
.small {
  --ig-size: var(--ig-size-small);
}

.medium {
  --ig-size: var(--ig-size-medium);
}
```

### Activo

Establezca <ApiLink pkg="core" type="Icon" member="active" label="active" /> en `false` para mostrar el icono como inactivo. Un icono inactivo usa el color deshabilitado del tema con una opacidad reducida:


### Nombre accesible

Oculte a la tecnología de asistencia un icono decorativo, y dé a un icono que transmite significado por sí solo un nombre accesible que describa ese significado.

<PlatformBlock for="React,WebComponents,Blazor">

Establezca `aria-label` en el icono para ponerle nombre. El elemento `<title>` de un SVG registrado también nombra el icono. Establezca `aria-hidden="true"` en un icono decorativo junto a texto visible:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-icon name="warning" collection="material" aria-label="Warning"></igc-icon>

<span>
  <igc-icon name="search" collection="material" aria-hidden="true"></igc-icon>
  Search
</span>
```

</PlatformBlock>

<PlatformBlock for="Angular">

El Icon de Angular está oculto para la tecnología de asistencia de forma predeterminada, porque su entrada <ApiLink pkg="core" type="Icon" member="ariaHidden" label="ariaHidden" /> establece `aria-hidden="true"`. Para exponer un icono que transmite significado, establezca `ariaHidden` en `false` y añada el rol `img` y un `aria-label`:

```html
<igx-icon name="warning" [ariaHidden]="false" role="img" aria-label="Warning"></igx-icon>
```

</PlatformBlock>

## Propiedades

El {Platform} Icon expone las siguientes propiedades. Consulte la referencia de la API para ver las definiciones de tipos completas.

<PlatformBlock for="React,WebComponents">

| Nombre | Tipo | Valor predeterminado | Descripción |

## Accesibilidad

El {Platform} Icon es un elemento visual no interactivo que decora el contenido cercano o transmite significado por sí solo.

### Interacción por teclado

El {Platform} Icon no recibe el foco y no tiene interacción por teclado: no establece `tabindex` y no gestiona eventos de teclado ni de puntero. Use el <PlatformBlock for="Angular">[Icon Button](../icon-button.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Icon Button](../inputs/icon-button.mdx)</PlatformBlock> cuando los usuarios deban activar un icono con el teclado.

| Clave | Acción |
| --- | --- |
| n/a | El Icon no es interactivo con el teclado. |

### Lectores de pantalla / ARIA

El {Platform} Icon no realiza anuncios propios. Lo que informa la tecnología de asistencia depende del nombre accesible del icono:

<PlatformBlock for="React,WebComponents">

- El icono establece su rol y su nombre accesible mediante los internals del elemento, no mediante atributos en el elemento `igc-icon`.
- Un elemento `<title>` que es hijo directo de la raíz `<svg>` del icono registrado se convierte en el nombre accesible del icono.
- Un atributo `aria-label` o `aria-labelledby` en el icono le da nombre a un icono cuyo SVG no tiene title, y tiene prioridad sobre el title.
- Con `igniteui-webcomponents` 7.3.0 y posteriores, el icono declara el rol `img` solo cuando tiene un nombre accesible, de modo que un icono sin nombre no se expone como una imagen sin nombre.
- El icono comprueba si tiene un nombre accesible al resolver su SVG: cuando cambian `name` o `collection`, cuando cambia el tema, o cuando se registra un icono. Establezca `aria-label` o `aria-labelledby` en el marcado inicial.
- La opción de registro `stripMeta` elimina los elementos `<title>` y `<desc>` del SVG almacenado, pero el icono conserva el texto del title como nombre accesible.

</PlatformBlock>

<PlatformBlock for="Blazor">

- Un elemento `<title>` que es hijo directo de la raíz `<svg>` del icono registrado se convierte en el nombre accesible del icono.
- Un atributo `aria-label` en el icono le da nombre a un icono cuyo SVG no tiene title, y tiene prioridad sobre el title.
- Un atributo `aria-hidden="true"` oculta a la tecnología de asistencia un icono decorativo.

</PlatformBlock>

<PlatformBlock for="Angular">

- El icono establece `aria-hidden="true"` de forma predeterminada mediante su entrada `ariaHidden`, así que la tecnología de asistencia lo ignora. Un `aria-label` por sí solo no expone un icono oculto.
- El icono no establece ningún rol. Cuando establece `ariaHidden` en `false` sin un rol y una etiqueta, los lectores de pantalla leen un icono de ligadura como su texto, como `home`.
- Establezca `ariaHidden` en `false`, añada el rol `img` y añada un `aria-label` para exponer un icono que transmite significado.
- La entrada `active` cambia solo el estilo. El estado inactivo no se expone a la tecnología de asistencia.

</PlatformBlock>

## Solución de problemas

Use estas respuestas cuando un {Platform} Icon no se renderice o no tenga el aspecto esperado.

### ¿Por qué mi icono está vacío?

<PlatformBlock for="React,WebComponents,Blazor">

El {Platform} Icon dibuja solo un SVG registrado con el mismo nombre y la misma colección. Compruebe las siguientes causas:

- El nombre o la colección no coinciden exactamente con el registro. La colección predeterminada es `default`.
- El marcado SVG está mal formado. El registro lanza el error `SVG element not found or malformed SVG string.` cuando el texto no tiene un elemento raíz `<svg>` o no se puede analizar.
- La solicitud del archivo SVG ha fallado. El registro desde una URL falla ante una respuesta distinta de OK, así que revise la consola del navegador y el panel de red. Un archivo de otro origen también necesita un servidor que permita las solicitudes de origen cruzado.

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

Durante el renderizado del lado del servidor, el icono no renderiza ningún SVG. Dibuja el SVG después de cargarse en el navegador.

</PlatformBlock>

<PlatformBlock for="Angular">

Compruebe las siguientes causas:

- Un icono de ligadura necesita la fuente de su familia, como Material Icons para la familia `material` predeterminada. Compruebe que se carga la hoja de estilos de la fuente.
- Un icono SVG necesita el mismo nombre y la misma familia que su registro.
- `addSvgIcon` necesita `HttpClient` para recuperar el archivo. Revise el panel de red por si hay una solicitud fallida.
- El servicio guarda en caché los iconos SVG solo en el navegador, así que los iconos SVG no se renderizan durante el renderizado del lado del servidor.

</PlatformBlock>

### ¿Por qué mi icono SVG no toma el color del tema?

El {Platform} Icon aplica su color al elemento raíz `<svg>`, y los elementos hijos lo heredan como relleno. Un elemento hijo con un color fijo conserva ese color:

```html
<svg viewBox="0 0 24 24">
  <path fill="#050d42" d="..." />
</svg>
```

Elimine los colores fijos de los elementos hijos, o establezca el color en el elemento raíz `<svg>`, donde el tema lo sustituye. Para colorear deliberadamente una parte del icono, use una variable de color del tema, como `fill="var(--ig-primary-500)"`.

### ¿Por qué aparece un tooltip cuando paso el ratón sobre un icono?

Los navegadores muestran el elemento `<title>` de un SVG como un tooltip nativo.

<PlatformBlock for="React,WebComponents">

Registre el icono con la opción `stripMeta` para eliminar los elementos `<title>` y `<desc>` del SVG almacenado. El icono conserva el texto del title como su nombre accesible:

```ts
registerIconFromText('search', searchIcon, { collection: 'material', stripMeta: true });
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Elimine el elemento `<title>` del marcado SVG antes de registrarlo, y establezca `aria-label` en los iconos que necesiten un nombre accesible.

</PlatformBlock>

<PlatformBlock for="Angular">

Pase `true` como argumento `stripMeta` de `addSvgIcon` o `addSvgIconFromText` para eliminar los elementos `<title>` y `<desc>` del SVG guardado en caché:

```ts
this.iconService.addSvgIcon('contains', 'assets/images/svg/contains.svg', 'filter-icons', true);
```

</PlatformBlock>

### Limitaciones conocidas

El {Platform} Icon tiene las siguientes limitaciones:

- El Icon es un elemento visual no interactivo: no recibe el foco ni gestiona la entrada del teclado.
- Los colores del tema llegan al elemento raíz `<svg>` y a los elementos hijos que heredan su relleno. Los elementos hijos con colores fijos los conservan.
<PlatformBlock for="React,WebComponents,Blazor">- El Icon dibuja solo iconos SVG registrados. Las fuentes de iconos y las ligaduras no se admiten.</PlatformBlock><PlatformBlock for="Angular">- El Icon de Angular no tiene ninguna opción para reflejar un icono en los diseños de derecha a izquierda.</PlatformBlock>
