# Componente Avatar

El {ProductName} Avatar representa a un usuario, una entidad o un objeto con una imagen, iniciales o contenido personalizado.

Use el avatar para ofrecer una identidad visual compacta en listas, tarjetas, menús de perfil y fuentes de actividad.

### Qué hacer y qué no

**Cuándo usarlo:** use el avatar cuando una interfaz necesite una representación pequeña de una persona, una organización, un objeto o una cuenta, como una imagen de perfil, unas iniciales o un icono. Mantenga una estrategia de avatar coherente dentro de la misma región de la interfaz para que las identidades repetidas sean fáciles de identificar.

<PlatformBlock for="WebComponents, React, Blazor">

**Cuándo no usarlo:** use el componente [Badge](../inputs/badge.mdx) cuando necesite mostrar un recuento, un estado o un indicador de notificación en lugar de representar una entidad. Los badges también pueden decorar avatares cuando la identidad y el estado deben aparecer juntos.

</PlatformBlock>

</PlatformBlock>

## Accesibilidad

El avatar es un elemento visual de identidad no interactivo con semántica de imagen accesible.

### Interacción por teclado

El avatar no recibe el foco y no tiene interacción por teclado.

| Clave | Acción |
| -- | -- |
| n/a | El avatar no es interactivo con el teclado. |

### Lectores de pantalla / ARIA

El avatar se inicializa con semántica de imagen y una etiqueta accesible predeterminada de `avatar`.

<PlatformBlock for="WebComponents, React, Blazor">

- Establezca `alt` cuando una imagen `src` represente a una persona, entidad u objeto concreto.
- Añada un `aria-label` explícito cuando el contenido personalizado proyectado necesite un nombre accesible distinto.
- Considere redundantes los avatares decorativos cuando el texto adyacente ya identifica la misma entidad.

</PlatformBlock>

<PlatformBlock for="Angular">

- Use el texto que rodea al avatar para identificar a la persona, entidad u objeto representado cuando un avatar de imagen transmita identidad.
- Considere redundantes los avatares decorativos cuando el texto adyacente ya identifica la misma entidad.

</PlatformBlock>

### Cumplimiento de accesibilidad

Infragistics documenta la compatibilidad de accesibilidad de {ProductName} con las áreas de las pautas de la Sección 508 y WCAG 2.1 en el tema [Cumplimiento de accesibilidad](../interactivity/accessibility-compliance.mdx).

<PlatformBlock for="WebComponents, React, Blazor">

| [4.1.2 Nombre, función, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | El componente se inicializa con semántica de imagen y expone información ARIA relacionada con el contenido. |

<PlatformBlock for="Angular">

| -- | -- |
| [1.1.1 Contenido no textual](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content) | El avatar tiene una etiqueta accesible y puede combinarse con el texto que rodea e identifica la entidad representada. |
| [4.1.2 Nombre, función, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | El componente se inicializa con `role="img"` y una etiqueta accesible predeterminada. |

Sus responsabilidades:

- Mantenga un contraste suficiente entre el fondo del avatar y el color del texto o del icono al sustituir estilos.
- Evite repetir el mismo anuncio de identidad cuando el texto adyacente ya nombra a la persona o entidad.

<PlatformBlock for="WebComponents, React, Blazor">

- Proporcione una etiqueta descriptiva o un texto `alt` cuando el avatar transmita identidad.

</PlatformBlock>

<PlatformBlock for="Angular">

- Asegúrese de que el texto cercano identifique la entidad representada cuando la imagen del avatar transmita identidad.

</PlatformBlock>

## Solución de problemas

Use esta sección para revisar los límites y las decisiones habituales antes de tratar Avatar como un componente interactivo o de estado.

### Limitaciones conocidas

El avatar es una primitiva visual de identidad y no añade por sí solo comportamiento de interacción, de estado ni de notificación.

- Use un contenedor interactivo, como un botón o un elemento de lista, cuando la entidad representada deba poder pulsarse.
- Use un badge junto al avatar cuando necesite mostrar estado, recuentos o indicadores de notificación.

- [Badge](../inputs/badge.mdx): use Badge para mostrar recuentos, estados o indicadores de notificación. Badge puede decorar Avatar cuando la interfaz necesita tanto identidad como estado.

</PlatformBlock>

## Preguntas frecuentes

<Faq>
  <FaqItem question="¿Cuándo debo usar Avatar en lugar de Badge?" indicatorPosition="end">
    Use Avatar cuando la interfaz necesite representar a una persona, una cuenta, una organización o un objeto. Use Badge cuando la interfaz necesite mostrar un recuento, un estado o un indicador de notificación.
  </FaqItem>

  <FaqItem question="¿Añade Avatar interacción por teclado?" indicatorPosition="end">
    No. Avatar no es interactivo y no recibe el foco por sí mismo. Colóquelo dentro de un componente interactivo cuando la entidad representada necesite una acción.
  </FaqItem>

  <FaqItem question="¿Cómo debo etiquetar los avatares de imagen para los lectores de pantalla?" indicatorPosition="end">
    Proporcione un texto alternativo significativo cuando la imagen del avatar identifique una entidad concreta. Evite repetir la misma identidad cuando el texto adyacente ya nombra esa entidad.
  </FaqItem>
</Faq>
