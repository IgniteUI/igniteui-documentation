# Descripción general de {Platform} Splitter

El {ProductName} Splitter ofrece un diseño de paneles divididos redimensionable que separa el contenido en dos áreas: `start` y `end`. Los usuarios pueden arrastrar la barra del splitter, usar atajos de teclado, o contraer y expandir paneles con controles integrados. También puede anidar splitters para crear diseños complejos de estilo panel.

## Uso de {Platform} Splitter

Use los slots `start` y `end` para colocar el contenido de los paneles:

<PlatformBlock for="WebComponents">

```html
<igc-splitter style="height: 400px;">
  <div slot="start">Start pane content</div>
  <div slot="end">End pane content</div>
</igc-splitter>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrSplitter>
  <div slot="start">Start pane content</div>
  <div slot="end">End pane content</div>
</IgrSplitter>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbSplitter>
  <div slot="start">Start pane content</div>
  <div slot="end">End pane content</div>
</IgbSplitter>
```

</PlatformBlock>

Recomendamos usar un `<div>` u otros elementos semánticos como `<section>` o `<article>` para los slots `start` y `end` del componente Splitter.

### Orientación

Establezca la propiedad <ApiLink pkg="core" type="Splitter" member="orientation" label="Orientation" /> para controlar la dirección de los paneles:

- `horizontal` (predeterminado): los paneles de inicio y de fin se renderizan a la izquierda y a la derecha.
- `vertical`: los paneles de inicio y de fin se renderizan arriba y abajo.

<PlatformBlock for="WebComponents">

```html
<igc-splitter orientation="vertical" style="height: 400px;">
  <div slot="start">Top pane</div>
  <div slot="end">Bottom pane</div>
</igc-splitter>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrSplitter orientation="vertical">
  <div slot="start">Top pane</div>
  <div slot="end">Bottom pane</div>
</IgrSplitter>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

  <div slot="start">Top pane</div>
  <div slot="end">Bottom pane</div>
</IgbSplitter>
```

</PlatformBlock>

### Contraer y redimensionar

Use estas propiedades para controlar las interacciones:

- <ApiLink pkg="core" type="Splitter" member="disableResize" label="DisableResize" />: desactiva el redimensionado de los paneles.
- <ApiLink pkg="core" type="Splitter" member="disableCollapse" label="DisableCollapse" />: desactiva el contraer de los paneles.
- <ApiLink pkg="core" type="Splitter" member="hideDragHandle" label="HideDragHandle" />: oculta el tirador de arrastre.
- <ApiLink pkg="core" type="Splitter" member="hideCollapseButtons" label="HideCollapseButtons" />: oculta los botones de contraer y expandir.

También puede contraer o expandir los paneles mediante programación:

<PlatformBlock for="WebComponents">

```ts
const splitter = document.querySelector('igc-splitter') as IgcSplitterComponent;

splitter.toggle('start'); // collapse start pane
splitter.toggle('start'); // expand start pane
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
import { useRef } from 'react';

const splitterRef = useRef<IgrSplitterComponent>(null);

const toggleStartPane = () => {
  splitterRef.current?.toggle('start');
};
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbSplitter @ref="SplitterRef">
  <div slot="start">Start pane</div>
  <div slot="end">End pane</div>
</IgbSplitter>

@code {
    private IgbSplitter SplitterRef;

    public async Task ToggleStartPane()
    {
      this.SplitterRef.Toggle(PanePosition.Start);
    }
}
```

</PlatformBlock>

## Eventos

El Splitter emite los siguientes eventos durante las operaciones de redimensionado:

<PlatformBlock for="WebComponents">

- `igcResizeStart`: se dispara una vez cuando empieza el redimensionado.
- `igcResizing`: se dispara de forma continua mientras se redimensiona.
- `igcResizeEnd`: se dispara una vez cuando termina el redimensionado.

El detalle del evento incluye los valores actuales de `startPanelSize`, `endPanelSize` y `delta` para los eventos en curso y finales.

</PlatformBlock>

<PlatformBlock for="React, Blazor">

- <ApiLink type="Splitter" member="onResizeStart" label="ResizeStart" />: se dispara una vez cuando empieza el redimensionado.
- <ApiLink type="Splitter" member="onResizing" label="Resizing" />: se dispara de forma continua mientras se redimensiona.
- <ApiLink type="Splitter" member="onResizeEnd" label="ResizeEnd" />: se dispara una vez cuando termina el redimensionado.

El detalle del evento incluye los valores actuales de `StartPanelSize`, `EndPanelSize` y `Delta` para los eventos en curso y finales.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
const splitter = document.querySelector('igc-splitter');

splitter?.addEventListener('igcResizeEnd', (event: CustomEvent) => {
  console.log(event.detail.startPanelSize, event.detail.endPanelSize, event.detail.delta);
});
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const handleResizeEnd = (event: CustomEvent<IgcSplitterResizeEventArgs>) => {
  console.log(event.detail.startPanelSize, event.detail.endPanelSize, event.detail.delta);
};

<IgrSplitter onResizeEnd={handleResizeEnd}>
  <div slot="start">Start pane</div>
  <div slot="end">End pane</div>
</IgrSplitter>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbSplitter ResizeEnd="OnResizeEnd">
  <div slot="start">Start pane</div>
  <div slot="end">End pane</div>
</IgbSplitter>

@code {
    public void OnResizeEnd(IgbSplitterResizeEventArgs e)
    {
        Console.WriteLine($"StartPanelSize: {e.Detail.StartPanelSize}, EndPanelSize: {e.Detail.EndPanelSize}");
    }
}
```

</PlatformBlock>

## Navegación por teclado

Cuando la barra del splitter tiene el foco:

| Teclas | Descripción |
| ---- | ----------- |
| <kbd>Flecha izquierda</kbd> / <kbd>Flecha derecha</kbd> | Redimensionar los paneles en orientación horizontal |
| <kbd>Flecha arriba</kbd> / <kbd>Flecha abajo</kbd> | Redimensionar los paneles en orientación vertical |
| <kbd>Home</kbd> | Ajustar el panel de inicio a su tamaño mínimo |
| <kbd>End</kbd> | Ajustar el panel de inicio a su tamaño máximo |
| <kbd>Ctrl</kbd> + <kbd>Flecha izquierda</kbd> / <kbd>Flecha arriba</kbd> | Contraer o expandir el panel de inicio |
| <kbd>Ctrl</kbd> + <kbd>Flecha derecha</kbd> / <kbd>Flecha abajo</kbd> | Contraer o expandir el panel de fin |

## Estilos

El componente <ApiLink pkg="core" type="Splitter" /> expone partes CSS para el estilo:

| Nombre | Descripción |
| ---- | ----------- |
| `splitter-bar` | El separador arrastrable entre los paneles |
| `drag-handle` | El elemento del tirador de arrastre de la barra del splitter |
| `start-pane` | El contenedor del panel de inicio |
| `end-pane` | El contenedor del panel de fin |
| `start-collapse-btn` | Botón que contrae el panel de inicio |
| `end-collapse-btn` | Botón que contrae el panel de fin |
| `start-expand-btn` | Botón que expande el panel de inicio |
| `end-expand-btn` | Botón que expande el panel de fin |

También admite variables CSS del tema, entre ellas:

- `--bar-color`
- `--handle-color`
- `--expander-color`
- `--bar-color-active`
- `--handle-color-active`
- `--expander-color-active`
- `--focus-color`
- `--size`

```css
igc-splitter {
  --bar-color: #011627;
  --handle-color: #ecaa53;
  --expander-color: #ecaa53;
  --bar-color-active: #011627;
  --handle-color-active: #ecaa53;
  --expander-color-active: #ecaa53;
  --focus-color: #ecaa53;
}
```
