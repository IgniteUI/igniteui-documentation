# Tabs

El componente {ProductName} Tabs organiza el contenido relacionado del mismo nivel jerárquico en pestañas y muestra el contenido de la pestaña seleccionada.

<PlatformBlock for="Angular">

El selector del componente Tabs de Angular es `igx-tabs`. Cada `igx-tab-item` que contiene tiene un encabezado de pestaña y el contenido que muestra el componente Tabs cuando se selecciona la pestaña.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Cada pestaña contiene su encabezado y su contenido en un único elemento. El componente Tabs admite la navegación por teclado y muestra botones de desplazamiento cuando los encabezados de las pestañas no caben.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

El elemento `igc-tabs` renderiza la franja de encabezados y los botones de desplazamiento. Cada `igc-tab` renderiza su propio encabezado y su contenido, y el componente Tabs coloca el contenido de todas las pestañas debajo de la franja de encabezados<PlatformBlock for="WebComponents">, o junto a ella cuando los encabezados de las pestañas forman una columna</PlatformBlock>:

```text
igc-tabs[role="tablist"]
└─ #shadow-root
   └─ div[part="tabs"]                                 // the scrollable header strip
      └─ div[part="inner"]
         ├─ igc-icon-button[part="start-scroll-button"] // rendered when the headers overflow
         ├─ slot                                       // the igc-tab elements
         │  └─ igc-tab
         │     └─ #shadow-root
         │        ├─ div[part="tab-header"][role="tab"]
         │        │  └─ div[part="base"]
         │        │     ├─ slot[name="prefix"][part="prefix"]
         │        │     ├─ div[part="content"]
         │        │     │  └─ slot[name="label"]        // falls back to the label property
         │        │     └─ slot[name="suffix"][part="suffix"]
         │        └─ div[part="tab-body"][role="tabpanel"] // visible only for the selected tab
         │           └─ slot                           // the content of the tab
         ├─ igc-icon-button[part="end-scroll-button"]   // rendered when the headers overflow
         └─ div[part="selected-indicator"]
            └─ span                                    // follows the selected tab header
```

</PlatformBlock>

<PlatformBlock for="Angular">

El elemento `igx-tabs` renderiza la franja de encabezados a partir del `igx-tab-header` de cada elemento de pestaña, y el área de contenido a partir del `igx-tab-content` de cada elemento de pestaña:

```text
igx-tabs.igx-tabs
├─ div.igx-tabs-header
│  ├─ button.igx-tabs-header-button                 // start scroll button, hidden when the headers fit
│  ├─ div.igx-tabs-header__content
│  │  └─ div.igx-tabs-header__wrapper[role="tablist"]
│  │     ├─ div.igx-tabs-header-scroll
│  │     │  └─ igx-tab-header[role="tab"]          // one for each igx-tab-item
│  │     │     ├─ [igxPrefix]
│  │     │     ├─ div.igx-tab-header__inner        // [igxTabHeaderIcon] above [igxTabHeaderLabel]
│  │     │     └─ [igxSuffix]
│  │     └─ div.igx-tabs-header__active-indicator
│  └─ button.igx-tabs-header-button                 // end scroll button, hidden when the headers fit
└─ div.igx-tabs-content
   └─ igx-tab-content[role="tabpanel"]             // one for each igx-tab-item; renders its content only when selected
```

</PlatformBlock>

## Uso

Use {Platform} Tabs para organizar distintas vistas de la misma información o para cambiar entre conjuntos de datos similares o relacionados.

### Tipo

Las pestañas están disponibles en dos tipos: corta, que muestra solo texto de forma predeterminada, con la opción de tener iconos de prefijo y de sufijo, y alta, que además tiene un tercer icono adicional encima del texto.

<PlatformBlock for="React,WebComponents,Blazor">

Para una pestaña corta, establezca la `label` de la pestaña. Para una pestaña alta, coloque en su lugar un Icon y un `<span>` en el slot `label`, y el componente Tabs mostrará el icono encima del texto. El slot `label` tiene prioridad sobre la propiedad `label`. Registre antes los iconos, como se describe en el tema [Icon](./icon.mdx):

</PlatformBlock>

### Adaptabilidad

Las pestañas pueden ajustarse al contenido (Content Fit) para ocupar el espacio horizontal disponible adaptando su ancho, o tener un tamaño fijo (Fixed) con botones de desplazamiento para navegar por un gran número de elementos de pestaña. Así se puede mostrar más contenido que con el otro modo en el mismo espacio total.

El <PlatformBlock for="Angular"><ApiLink pkg="core" type="Tabs" member="tabAlignment" label="tabAlignment" /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor"><ApiLink pkg="core" type="Tabs" member="alignment" label="alignment" /></PlatformBlock> La propiedad establece cómo organiza el componente {Platform} Tabs los encabezados de las pestañas:

- `start` (predeterminado): cada encabezado de pestaña tiene el ancho de su contenido, y los encabezados empiezan en el borde inicial de Tabs.
- `center`: cada encabezado de pestaña tiene el ancho de su contenido, y los encabezados quedan centrados.
- `end`: cada encabezado de pestaña tiene el ancho de su contenido, y los encabezados terminan en el borde final de Tabs.
- `justify`: los encabezados de las pestañas se estiran para ocupar el ancho de Tabs. Úselo para el modo Content Fit.

<PlatformBlock for="WebComponents">

```html
<igc-tabs alignment="justify">

  <igc-tab label="Genres"></igc-tab>
</igc-tabs>
```

</PlatformBlock>

Cuando el usuario selecciona una pestaña, el componente Tabs desplaza su encabezado a la vista.

### Cantidad

En la mayoría de los casos, Tabs debe contener entre dos y cinco elementos. Si su caso de uso requiere más de cinco pestañas, considere el modo Fixed explicado anteriormente.

</PlatformBlock>

### Estados

Los elementos de pestaña admiten los estados Active, Inactive, Active y hover, Inactive y hover y Disabled. En Tabs siempre hay una pestaña activa y un número arbitrario de pestañas inactivas y deshabilitadas.

Establezca `selected` en una pestaña para convertirla en la pestaña activa, y `disabled` para desactivarla. Los usuarios no pueden seleccionar una pestaña deshabilitada, y la navegación por teclado la omite.<PlatformBlock for="React,WebComponents,Blazor"> Cuando deshabilita la pestaña seleccionada, el componente {Platform} Tabs selecciona la primera pestaña habilitada.</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-tabs>
  <igc-tab label="Overview"></igc-tab>
  <igc-tab label="Activity" selected></igc-tab>
  <igc-tab label="Billing" disabled></igc-tab>
</igc-tabs>
```

</PlatformBlock>

</PlatformBlock>

### Selección

<PlatformBlock for="WebComponents">

El componente {Platform} Tabs emite `igcChange` con la pestaña recién seleccionada cuando el usuario selecciona una pestaña con un clic o con una tecla. Para seleccionar una pestaña desde el código, llame a <ApiLink pkg="core" type="Tabs" member="select" label="select" /> con la pestaña, o con su `id` o su `label`. Lea la pestaña seleccionada desde <ApiLink pkg="core" type="Tabs" member="selectedTab" label="selectedTab" />:

```html
<igc-tabs>
  <igc-tab id="overview" label="Overview"></igc-tab>
  <igc-tab id="details" label="Details"></igc-tab>
</igc-tabs>
```

```ts
const tabs = document.querySelector('igc-tabs')!;

tabs.addEventListener('igcChange', (event) => {
  console.log(`Selected: ${event.detail.label}`);
});

tabs.select('details');
console.log(tabs.selectedTab?.label); // "Details"
```

</PlatformBlock>

<PlatformBlock for="React">

El componente {Platform} Tabs llama a `onChange` con la pestaña recién seleccionada cuando el usuario selecciona una pestaña con un clic o con una tecla. Para seleccionar una pestaña desde el código, llame a <ApiLink pkg="core" type="Tabs" member="select" label="select" /> con la pestaña, o con su `id` o su `label`:

```tsx
        <IgrTab label="Details" />
      </IgrTabs>
      <button onClick={() => tabsRef.current?.select('Details')}>Show details</button>
    </>
  );
}
```

</PlatformBlock>

</PlatformBlock>

Enlace <ApiLink pkg="core" type="Tabs" member="selectedIndex" label="selectedIndex" /> para leer y establecer el índice de la pestaña seleccionada. El componente Tabs de Angular emite <ApiLink pkg="core" type="Tabs" member="selectedIndexChanging" label="selectedIndexChanging" /> antes de que cambie la selección, y puede cancelar el cambio en su manejador:

```html

    <igx-tab-header><span igxTabHeaderLabel>Profile</span></igx-tab-header>
    <igx-tab-content>The profile form.</igx-tab-content>
  </igx-tab-item>
  <igx-tab-item>
    <igx-tab-header><span igxTabHeaderLabel>Billing</span></igx-tab-header>
    <igx-tab-content>The billing form.</igx-tab-content>
  </igx-tab-item>
</igx-tabs>
```

```ts
import { ITabsSelectedIndexChangingEventArgs } from 'igniteui-angular/tabs';

public selectedIndex = 0;
public hasUnsavedChanges = false;

public onSelectedIndexChanging(event: ITabsSelectedIndexChangingEventArgs) {
    if (this.hasUnsavedChanges) {
        event.cancel = true;
    }
}
```

Después de que cambie la selección, el componente Tabs de Angular emite <ApiLink pkg="core" type="Tabs" member="selectedItemChange" label="selectedItemChange" /> con el elemento de pestaña anterior y el nuevo. Estos eventos también se disparan cuando establece `selectedIndex` desde el código.

</PlatformBlock>

### Qué hacer y qué no

Las pestañas son adecuadas para organizar información, y conviene evitar usarlas para diseñar flujos de trabajo y acciones que siguen una secuencia lógica, por ejemplo un proceso de compra o un asistente de configuración. Al usar pestañas cortas, nunca combine en la misma barra una pestaña de texto con una pestaña de icono. Elija uno de los dos modos de contenido y úselo de forma coherente para todos los elementos de la barra.

<DoDont
  doSrc={tabsDoInformation}
  doAlt="Pestañas llamadas Products, Cart y Orders sobre una imagen de producto"
  dontSrc={tabsDoNotWorkflow}
  dontAlt="Pestañas llamadas Extras, Payment y Address usadas como los pasos de un flujo de pedido"
>
<Fragment slot="do">

Use pestañas para organizar información relacionada.

</Fragment>
<Fragment slot="dont">

Evite las pestañas para los pasos de un flujo de trabajo secuencial, como un proceso de compra.

</Fragment>
</DoDont>

<DoDont
  doSrc={tabsDoContent}
  doAlt="Pestañas llamadas Podcasts, Playlists y Genres que usan todas etiquetas de texto"
  dontSrc={tabsDoNotMixedContent}
  dontAlt="Pestañas que combinan las etiquetas de texto Podcasts y Playlists con una pestaña de icono de nota musical"
>
<Fragment slot="do">

Use el mismo modo de contenido, texto o iconos, para todas las pestañas de una barra.

</Fragment>
<Fragment slot="dont">

Evite combinar pestañas de texto y pestañas de icono en la misma barra.

</Fragment>
</DoDont>

## Accesibilidad

El componente {Platform} Tabs usa los roles del patrón de pestañas de WAI-ARIA: los usuarios llegan a los encabezados de las pestañas con la tecla Tab, se mueven entre ellos con las teclas de flecha y seleccionan una pestaña para mostrar su contenido.

### Interacción por teclado

<PlatformBlock for="React,WebComponents,Blazor">

La franja de encabezados del componente {Platform} Tabs es una única parada de tabulación: solo el encabezado de la pestaña seleccionada está en el orden de tabulación, o el primer encabezado de pestaña habilitado cuando no hay ninguna pestaña seleccionada. El contenido de la pestaña seleccionada es la siguiente parada de tabulación. Las siguientes teclas funcionan mientras un encabezado de pestaña tiene el foco:

| Clave | Acción |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Mueve el foco fuera de la franja de encabezados, al contenido de la pestaña seleccionada o al elemento enfocable anterior. El componente Tabs no gestiona estas teclas. |
| <kbd>Arrow Right</kbd> | Mueve el foco al siguiente encabezado de pestaña habilitado, y desde el último al primero. En un diseño de derecha a izquierda, lo mueve al anterior. Con la activación `auto`, también selecciona la pestaña.<PlatformBlock for="WebComponents"> En una columna de encabezados de pestaña, el componente Tabs no gestiona esta tecla.</PlatformBlock> |
| <kbd>Arrow Left</kbd> | Mueve el foco al encabezado de pestaña habilitado anterior, y desde el primero al último. En un diseño de derecha a izquierda, lo mueve al siguiente. Con la activación `auto`, también selecciona la pestaña.<PlatformBlock for="WebComponents"> En una columna de encabezados de pestaña, el componente Tabs no gestiona esta tecla.</PlatformBlock> |
<PlatformBlock for="WebComponents">| <kbd>Arrow Down</kbd> | En una columna de encabezados de pestaña, mueve el foco al siguiente encabezado de pestaña habilitado, y desde el último al primero. Con la activación `auto`, también selecciona la pestaña. |
| <kbd>Arrow Up</kbd> | En una columna de encabezados de pestaña, mueve el foco al encabezado de pestaña habilitado anterior, y desde el primero al último. Con la activación `auto`, también selecciona la pestaña. |
</PlatformBlock>| <kbd>Home</kbd> | Mueve el foco al primer encabezado de pestaña habilitado. Con la activación `auto`, también selecciona la pestaña. |
| <kbd>End</kbd> | Mueve el foco al último encabezado de pestaña habilitado. Con la activación `auto`, también selecciona la pestaña. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Selecciona la pestaña enfocada. |

El componente {Platform} Tabs gestiona estas teclas en `keydown`:

- Impide su acción predeterminada, de modo que las teclas de flecha que mueven el foco, Home, End y Space no desplazan la página.
- Una tecla que se mantiene pulsada no repite su acción.
- Una tecla que se pulsa junto con Shift, Ctrl, Alt o Meta no hace nada.
- El componente Tabs desplaza a la vista el encabezado que recibe el foco.

Con un puntero, un clic en un encabezado de pestaña enfoca y selecciona la pestaña. Una pestaña deshabilitada ignora los clics. Los botones de desplazamiento no están en el orden de tabulación.

### Lectores de pantalla / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

El componente {Platform} Tabs renderiza los siguientes roles y atributos:

| Elemento | Rol | Atributos |
| --- | --- | --- |
| `igc-tabs` | `tablist` | `aria-orientation="horizontal"`<PlatformBlock for="WebComponents">, o `aria-orientation="vertical"` en una columna de encabezados de pestaña</PlatformBlock>, establecido mediante los internals del elemento |
| La parte `tab-header` de cada pestaña | `tab` | `aria-selected`, `aria-disabled`, `aria-controls` que apunta al contenido de la pestaña, `aria-posinset` y `aria-setsize` |
| La parte `tab-body` de cada pestaña | `tabpanel` | `aria-labelledby` que apunta al encabezado de la pestaña |

El componente {Platform} Tabs también se comporta de la siguiente manera para la tecnología de asistencia:

- Una pestaña toma su nombre accesible del contenido de su encabezado: la propiedad `label` o el slot `label`, y el contenido de los slots `prefix` y `suffix`.
- El contenido de las pestañas que no están seleccionadas está oculto y `inert`, de modo que la tecnología de asistencia y el teclado lo omiten.
- Los atributos `aria-posinset` y `aria-setsize` de cada encabezado de pestaña indican a los lectores de pantalla la posición de la pestaña dentro del conjunto, por ejemplo «2 de 3».
- El componente Tabs no usa una región live. Un cambio de selección llega a la tecnología de asistencia a través del estado `aria-selected` y del foco.

</PlatformBlock>

<PlatformBlock for="Angular">

El componente Tabs de Angular renderiza los siguientes roles y atributos:

| Elemento | Rol | Atributos |
| --- | --- | --- |
| El elemento `div.igx-tabs-header__wrapper` del encabezado | `tablist` | `aria-orientation="horizontal"`, o `aria-orientation="vertical"` en una columna de encabezados de pestaña |
| `igx-tab-header` | `tab` | `aria-selected`, `aria-disabled` y, cuando el elemento de pestaña tiene contenido, un `id` y un `aria-controls` que apunta al contenido |
| `igx-tab-content` | `tabpanel` | `aria-labelledby` que apunta al encabezado del elemento de pestaña |

El componente Tabs de Angular también se comporta de la siguiente manera para la tecnología de asistencia:

- Una pestaña toma su nombre accesible del contenido de su `igx-tab-header`.
- El componente Tabs renderiza solo el contenido del elemento de pestaña seleccionado, de modo que el contenido de los demás elementos de pestaña no está en el DOM.
- Los elementos de pestaña sin `igx-tab-content`, como las pestañas que controlan el router, no reciben `id` ni `aria-controls`.
- El componente Tabs no usa una región live. Un cambio de selección llega a la tecnología de asistencia a través del estado `aria-selected` y del foco.

</PlatformBlock>
