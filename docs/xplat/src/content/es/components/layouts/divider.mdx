Si se establece el atributo <ApiLink pkg="core" type="Divider" member="vertical" label="Vertical" />, la dirección del divider cambia de horizontal a vertical.

### Divider con sangría

El <ApiLink pkg="core" type="Divider" /> puede establecerse en ambos lados. Para `inset` el divider, establezca el atributo <ApiLink pkg="core" type="Divider" member="middle" label="Middle" /> en true junto con la variable CSS `--inset`. Esto acorta la línea del divider por ambos lados. El valor predeterminado del atributo <ApiLink pkg="core" type="Divider" member="middle" label="Middle" /> es false.

```css
/* DividerStyles.css */
.withInset{
    --inset: 100px;
    --color:red;
}
```

<PlatformBlock for="WebComponents">

```html
// Both side
<igc-divider middle="true" class="withInset"></igc-divider>
// Left side only
<igc-divider></igc-divider>
```

</PlatformBlock>


<PlatformBlock for="React">

```tsx
// Both side
<IgrDivider middle="true" className="withInset"></IgrDivider>
// Left side only
<IgrDivider  className="withInset"></IgrDivider>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
// Both side
<IgbDivider Middle="True" class="withInset"></IgbDivider>
// Left side only
<IgbDivider class="withInset"></IgbDivider>
```

</PlatformBlock>

## Variables CSS
### Sangría
La variable CSS `--inset` acorta el divider en la cantidad indicada desde el inicio. Si se establece middle, se acorta por ambos lados.

### Color
La variable CSS `--color` establece el color del divider.
