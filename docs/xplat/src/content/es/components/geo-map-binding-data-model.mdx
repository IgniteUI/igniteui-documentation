# {Platform}: enlazar modelos de datos geográficos

El componente de mapa de {ProductName} está diseñado para mostrar datos geoespaciales de archivos de forma y/o ubicaciones geográficas de modelos de datos sobre mapas de imágenes geográficas. La propiedad `dataSource` de las series geográficas se usa para enlazar modelos de datos. Esta propiedad puede enlazarse a un array de objetos personalizados.

## Ejemplo de {Platform}: enlazar modelos de datos geográficos


<Sample src="/maps/geo-map/binding-data-model" height={500} alt="Ejemplo de {Platform}: enlazar modelos de datos geográficos" />




La siguiente tabla resume las estructuras de datos necesarias para cada tipo de serie geográfica:

| Serie geográfica  | Propiedades   | Descripción   |
|--------------|---------------| ---------------|
| `GeographicSymbolSeries` | `longitudeMemberPath`, `latitudeMemberPath`   | Indica los nombres de 2 coordenadas numéricas de longitud y latitud |<PlatformBlock for="Web">
| `GeographicHighDensityScatterSeries` | `longitudeMemberPath`, `latitudeMemberPath`   | Indica los nombres de 2 coordenadas numéricas de longitud y latitud |</PlatformBlock>
| `GeographicProportionalSymbolSeries` | `longitudeMemberPath`, `latitudeMemberPath`, `radiusMemberPath`   | Indica los nombres de 2 coordenadas numéricas de longitud y latitud, y 1 columna numérica para el tamaño/radio de los símbolos |<PlatformBlock for="Angular, React, WebComponents, Blazor">
| `GeographicScatterAreaSeries` | `longitudeMemberPath`, `latitudeMemberPath`, `colorMemberPath`   | Indica los nombres de 2 coordenadas numéricas de longitud y latitud, y 1 columna numérica para la triangulación de los valores |</PlatformBlock>
| `GeographicContourLineSeries` | `longitudeMemberPath`, `latitudeMemberPath`, `valueMemberPath`   | Indica los nombres de 2 coordenadas numéricas de longitud y latitud, y 1 columna numérica para la triangulación de los valores |
|`GeographicShapeSeries`|`shapeMemberPath`|Indica el nombre de la columna de datos de los elementos `dataSource` que contiene los puntos geográficos de las formas. Esta propiedad debe asignarse a un array de arrays de objetos con las propiedades x e y. |
|`GeographicPolylineSeries`|`shapeMemberPath`|Indica el nombre de la columna de datos de los elementos `dataSource` que contiene las coordenadas geográficas de las líneas. Esta propiedad debe asignarse a un array de arrays de objetos con las propiedades x e y. |

## Fragmento de código
El siguiente código muestra cómo enlazar la `GeographicSymbolSeries` a un modelo de datos personalizado que contiene las ubicaciones geográficas de algunas ciudades del mundo, almacenadas con coordenadas de longitud y latitud. Además, usamos `GeographicPolylineSeries` para trazar la ruta geográfica más corta entre estas ubicaciones usando las matemáticas del círculo máximo de `\MapGeodesics`, que se muestran completas con el código siguiente

```json-snippet source="/maps/geo-map/binding-data-model"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "$type": "+doc:markup",
            "height": "100%",
            "width": "100%",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapBindingDataModelOnViewInit"
    ]
}
```

```json-snippet source="/maps/geo-map/binding-data-model" channel="handlersImports...supportingTypes...handler" item="MapBindingDataModelOnViewInit"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "height": "100%",
            "width": "100%",
            "zoomable": true
        }
    },
    "$onViewInit": "+doc:handler",
    "onViewInit": [
        "MapBindingDataModelOnViewInit"
    ]
}
```
