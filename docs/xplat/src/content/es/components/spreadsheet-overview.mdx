# Descripción general de {Platform} Spreadsheet

El componente {Platform} Spreadsheet (visor de Excel) es ligero, tiene muchas funciones y ofrece todas las opciones necesarias para manejar, visualizar y editar todo tipo de datos de hojas de cálculo: científicos, empresariales, financieros y más. Toda la información puede presentarse en un formato tabular intuitivo y fácil de recorrer entre celdas, paneles y hojas de trabajo. El <ApiLink type="Spreadsheet" /> se complementa con una interfaz flexible similar a Excel, gráficos detallados y funciones como activación, edición de celdas, formato condicional, estilos, selección y portapapeles.

## Funcionalidad

- Funciones

Igual que en una hoja de cálculo de Excel, puede aplicar funciones de filtrado, ordenar, mover celdas, personalizar el color de las celdas y los atajos de teclado, e incluso calcular fórmulas.

## Uso de la hoja de cálculo

- Rendimiento

La hoja de cálculo es compatible con todos los navegadores modernos y está optimizada para modelos de hojas de cálculo complejos y voluminosos, garantizando un funcionamiento impecable y sencillez.

- Diseño flexible y personalización sencilla

Puede seleccionar, añadir o eliminar fácilmente las funciones que quiera activar o desactivar, y configurar hojas React en un instante para que todo responda a las necesidades de los usuarios finales. También hay bibliotecas configurables, alternativas de estilo y formato, opciones de visibilidad y muchos temas entre los que elegir.

- Interfaz cómoda similar a Excel

Igual que al trabajar con datos en Excel, nuestro componente de hoja de cálculo ofrece todas las operaciones conocidas del portapapeles de Excel: copiar, pegar y cortar. No necesitará formación adicional ni nuevas habilidades para empezar a usarlo de inmediato. También incluye opciones de ordenación, navegación completa por teclado, valores y fórmulas, arrastre de celdas, edición de columnas y filas, filtrado, formato de números y redimensionado. El motor de cálculo inteligente y rápido admite incluso las estimaciones más complejas. Sin dependencias de Excel.

- Operaciones con datos

Recopile y gestione datos científicos, empresariales, de ingeniería, financieros y educativos. Prepare y cree análisis, cuadrículas avanzadas, informes, formularios de entrada de datos, presupuestos, escenarios de previsión y hojas de cálculo personalizadas. Todo ello gracias a la API completa.

- Procesamiento de datos rápido y seguro

Con nuestra hoja de cálculo, el procesamiento de datos es 100 % seguro…

- Importación y exportación de Excel y CSV

Con la funcionalidad integrada de importación y exportación de Excel, puede cargar y abrir documentos de Excel al instante, verlos cuando los necesite, añadir cambios y guardarlos. Además, exporte sin esfuerzo sus hojas de cálculo de Excel completadas en formato .xlsx.

## Dependencias

Al instalar el componente de hoja de cálculo {Platform}, también deben instalarse los paquetes core y excel.

```cmd
npm install --save {PackageCore}
npm install --save {PackageExcel}
npm install --save {PackageSpreadsheet}
```

<DocsAside type="info">

En el siguiente fragmento de código, se usa una clase externa [ExcelUtility](./excel-utility.mdx) para guardar y cargar un <ApiLink type="Spreadsheet" member="workbook" label="Workbook" />.
</DocsAside>

A continuación se muestra cómo cargar un libro en la hoja de cálculo {Platform}

<PlatformBlock for="Angular">

```ts
import { IgxSpreadsheetComponent } from 'igniteui-angular-spreadsheet';
import { ExcelUtility } from 'ExcelUtility';

// ...

@ViewChild("spreadsheet", { read: IgxSpreadsheetComponent })
public spreadsheet: IgxSpreadsheetComponent;

ngOnInit() {
    const excelFile = '../../assets/Sample1.xlsx';
    ExcelUtility.loadFromUrl(excelFile).then((w) => {
      this.spreadsheet.workbook = w;
    });
}
```

</PlatformBlock>

<PlatformBlock for="React">

```ts
import { IgrSpreadsheet } from 'igniteui-react-spreadsheet';

</PlatformBlock>

<PlatformBlock for="WebComponents">

```
