# Descripción general de {Platform} Dialog

El componente {ProductName} Dialog se usa para mostrar información o para pedir al usuario una acción o una confirmación. Se muestra en una ventana modal, lo que significa que el usuario no puede interactuar con la aplicación principal hasta que realiza una acción concreta que cierra el diálogo.

La forma más sencilla de mostrar el componente de diálogo es usar su método <ApiLink pkg="core" type="Dialog" member="show" label="Show" /> y llamarlo al hacer clic en un botón.

<PlatformBlock for="Blazor">

```razor
<div class="container vertical">
    <IgbButton @onclick="OnDialogShow" Variant=@ButtonVariant.Contained>Show Dialog</IgbButton>
    <IgbDialog @ref="DialogRef" Title="Confirmation">
        <p>Are you sure you want to delete the Annual_Report_2016.pdf and Annual_Report_2017.pdf files?</p>
        <IgbButton slot="footer" @onclick="OnDialogHide" Variant=@ButtonVariant.Flat>Cancel</IgbButton>
        <IgbButton slot="footer" @onclick="OnDialogHide" Variant=@ButtonVariant.Flat>OK</IgbButton>
    </IgbDialog>
</div>

@code {
    public IgbDialog DialogRef;
    public async Task OnDialogShow()
    {
        if (this.DialogRef != null)
            await this.DialogRef.ShowAsync();
    }
    public async Task OnDialogHide()
    {
        if (this.DialogRef != null)
            await this.DialogRef.HideAsync();
    }
}
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton variant="contained" clicked={this.onDialogShow}>
    <span>Show Dialog</span>
</IgrButton>

<IgrDialog ref={this.onDialogRef}>
    <span>Dialog Message</span>
</IgrDialog>

public onDialogRef(dialog: IgrDialog) {
    if (!dialog) { return; }
    this.dialogRef = dialog;
}

public onDialogShow() {
    if (this.dialogRef) {
        this.dialogRef.show();
    }
}
```

</PlatformBlock>

El componente <ApiLink pkg="core" type="Dialog" /> proporciona una propiedad <ApiLink pkg="core" type="Dialog" member="open" label="Open" />, que le permite configurar su estado según el escenario de su aplicación.

Use la propiedad <ApiLink pkg="core" type="Dialog" member="title" label="Title" /> para establecer el título del diálogo. Sin embargo, si se proporciona contenido en el slot `title`, tendrá prioridad sobre la propiedad.

Los botones de acción o la información adicional pueden colocarse en la parte inferior del diálogo mediante el slot `footer`. Si no se añade contenido allí, se mostrará un botón `OK` predeterminado que cierra el Dialog al hacer clic. Si no quiere que se muestre este botón, puede establecer la propiedad <ApiLink pkg="core" type="Dialog" member="hideDefaultAction" label="HideDefaultAction" /> en **true**. El valor predeterminado es **false**.

### Cierre

De forma predeterminada, el Dialog se cierra automáticamente cuando el usuario pulsa `ESC`. Puede impedir este comportamiento con la propiedad <ApiLink pkg="core" type="Dialog" member="keepOpenOnEscape" label="KeepOpenOnEscape" />. El valor predeterminado es **false**. Si hay un desplegable abierto (o cualquier otro elemento que deba gestionar `ESC` internamente) en el diálogo, al pulsar `ESC` una vez se cerrará el desplegable, y al pulsarla de nuevo se cerrará el diálogo.

Use la propiedad <ApiLink type="OverlaySettings" member="closeOnOutsideClick" label="CloseOnOutsideClick" /> para configurar si el diálogo debe cerrarse al hacer clic fuera de él. El valor predeterminado es **false**.

### Formulario

Los elementos de formulario pueden cerrar un Dialog si tienen el atributo `method="dialog"`. Al enviar el formulario se disparará el cierre del diálogo.

## Estilos

El componente <ApiLink pkg="core" type="Dialog" /> expone varias partes CSS para darle control total sobre su estilo:

|Nombre|Descripción|
|--|--|
| `base` | El wrapper base del diálogo. |
| `title` | El contenedor del título. |
| `footer` | El contenedor del pie. |
| `content` | El contenedor del contenido. |

```css
igc-dialog::part(content) {
  background: var(--ig-secondary-800);
  color: var(--ig-secondary-800-contrast);
}

igc-dialog::part(title),
igc-dialog::part(footer) {
  background: var(--ig-secondary-800);
  color: var(--ig-warn-500);
}
```
