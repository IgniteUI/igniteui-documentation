## Ejemplos

### Tiempo de visualización

Use la propiedad <ApiLink pkg="core" type="Snackbar" member="displayTime" label="DisplayTime" /> para configurar durante cuánto tiempo es visible el componente snackbar. De forma predeterminada, está establecida en 4000 milisegundos.

<Sample src="/notifications/snackbar/display-time" height={230} alt="Ejemplo del tiempo de visualización de {Platform} Snackbar" />




### Texto de acción

De forma predeterminada, el componente snackbar se oculta automáticamente tras el periodo especificado por <ApiLink pkg="core" type="Snackbar" member="displayTime" label="DisplayTime" />. Puede usar la propiedad <ApiLink pkg="core" type="Snackbar" member="keepOpen" label="KeepOpen" /> para cambiar este comportamiento. De esta forma, el snackbar permanecerá visible. Con el <ApiLink pkg="core" type="Snackbar" member="actionText" label="ActionText" /> del snackbar puede mostrar un botón de acción dentro del componente.

<Sample src="/notifications/snackbar/action-text" height={230} alt="Ejemplo del texto de acción de {Platform} Snackbar" />




## Estilos

El componente <ApiLink pkg="core" type="Snackbar" /> expone varias partes CSS para darle control total sobre su estilo:

|Nombre|Descripción|
|--|--|
| `base` | El wrapper base del componente snackbar. |
| `message` | El mensaje del snackbar. |
| `action` | El botón de acción predeterminado del snackbar. |
| `action-container` | El área que contiene las acciones. |

```css
igc-snackbar::part(base) {
  background: var(--ig-primary-500);
  border-color: var(--ig-primary-800);
  color: white;
}
```
