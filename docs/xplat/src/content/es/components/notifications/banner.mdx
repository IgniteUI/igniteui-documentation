# Descripción general de {Platform} Banner

El componente Banner de {ProductName} permite mostrar fácilmente a los usuarios de la aplicación un mensaje destacado, de forma menos transitoria que un snackbar y menos intrusiva que un diálogo. También puede indicar acciones que realizar según el contexto del mensaje.

### Mostrar banner

Para mostrar el componente banner, use su método <ApiLink pkg="core" type="Banner" member="show" label="Show" /> y llámelo al hacer clic en un botón. El banner aparece en la posición del elemento en la plantilla de la página, desplazando el resto del contenido. Normalmente muestra contenido no intrusivo que requiere una interacción mínima del usuario para cerrarse.

<PlatformBlock for="WebComponents">

```html
<igc-button onclick="banner.show()">Show Banner</igc-button>

<igc-banner id="banner">
    You are currently offline.
</igc-banner>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton onClick={() => bannerRef.current.show()}>
    <span>Show Banner</span>
</IgrButton>

<IgrBanner ref={bannerRef}>
    <span>You are currently offline.</span>
</IgrBanner>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbButton @onclick="ShowBanner">Show Banner</IgbButton>

<IgbBanner @ref="bannerRef">
    You are currently offline.
</IgbBanner>

@code {

    private void ShowBanner()
    {
        this.bannerRef.ShowAsync();
    }
}
```

</PlatformBlock>

</DocsAside>

### Enlazar eventos

El componente banner emite los eventos `Closing` y `Closed` al cerrarse. El evento `Closing` es cancelable: usa la interfaz [`CustomEvent`](https://developer.mozilla.org/docs/Web/API/CustomEvent) y el objeto emitido tiene su propiedad `cancelable` establecida en **true**. Si cancelamos el evento `Closing`, la acción final y el evento correspondientes no se dispararán: el banner no se cerrará y no se emitirá el evento `Closed`.

Para cancelar el evento de cierre, llame al método [`preventDefault`](https://developer.mozilla.org/en-US/docs/Web/API/Event/preventDefault).

<PlatformBlock for="WebComponents">

```html
<igc-banner id="banner">
    ...
</igc-banner>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
const banner = document.getElementById('banner') as IgcBannerComponent;

banner.addEventListener('igcClosing', (event) => {
  event.preventDefault();
});
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrBanner onClosing={(event) => event.preventDefault()}>
    ...
</IgrBanner>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbBanner id="banner">
    ...
</IgbBanner>

@code {
    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender)
        {
            await JS.InvokeVoidAsync("handleClosing");
        }
    }
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">


```javascript
//In JavaScript:
function handleClosing() {
    const banner = document.getElementById('banner');

    banner.addEventListener('igcClosing', (event) => {
        event.preventDefault();
    });
}
```

</PlatformBlock>

<DocsAside type="info">
Si se aplican los cambios anteriores, el banner nunca se cerrará, ya que el evento de cierre siempre se cancela.
</DocsAside>

## Ejemplo avanzado

Creemos un banner con dos botones personalizados: uno para descartar la notificación y otro para activar la conexión. Podemos pasar manejadores de acción personalizados usando el slot `actions`:

<PlatformBlock for="WebComponents">

```html
<igc-banner id="banner">
    <igc-icon slot="prefix" name="signal_wifi_off"></igc-icon>
    You have lost connection to the internet. This app is offline.
    <div slot="actions">
        <igc-button onclick="banner.hide()">
            <igc-ripple></igc-ripple>
            Continue Offline
        </igc-button>
        <igc-button id="button">
            <igc-ripple></igc-ripple>
            Turn On Wifi
        </igc-button>
    </div>
</igc-banner>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrBanner ref={bannerRef}>
    <IgrIcon slot="prefix" name="signal_wifi_off"></IgrIcon>
    <span>You have lost connection to the internet. This app is offline.</span>
    <div slot="actions">
        <IgrButton variant="flat" onClick={() => bannerRef.current.hide()}>
            <IgrRipple />
            <span>Continue Offline</span>
        </IgrButton>
        <IgrButton variant="flat" onClick={refreshBanner}>
            <IgrRipple />
            <span>Turn On Wifi</span>
        </IgrButton>
    </div>
</IgrBanner>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbBanner @ref="bannerRef">
    <IgbIcon IconName="signal_wifi_off" Collection="material" slot="prefix"></IgbIcon>
    You have lost connection to the internet. This app is offline.
    <div slot="actions">
        <IgbButton Variant="ButtonVariant.Flat" @onclick="HideBanner">
            Continue Offline
            <IgbRipple />
        </IgbButton>
        <IgbButton Variant="ButtonVariant.Flat" @onclick="RefreshBanner">
            Turn On Wifi
            <IgbRipple />
        </IgbButton>
    </div>
</IgbBanner>

@code {
    private IgbBanner bannerRef;

    private void HideBanner()
    {
        this.bannerRef.HideAsync();
    }
}
```

</PlatformBlock>

> Según las pautas de [Material Design](https://material.io/design/components/banners.html#anatomy) de Google, un banner debe tener un máximo de 2 botones. El <ApiLink pkg="core" type="Banner" /> no limita explícitamente el número de elementos bajo el slot `actions`, pero se recomienda encarecidamente usar hasta 2 si quiere cumplir las pautas de material design.


La opción de descartar (**Continue Offline**) no necesita más lógica, así que basta con que llame al método <ApiLink pkg="core" type="Banner" member="hide" label="Hide" />. Sin embargo, la acción de confirmar (**Turn On Wifi**) requiere lógica adicional, así que debemos definirla en el componente. Después, añadiremos un manejador de eventos para el evento `click`. El último paso es llamar al método `refreshBanner()` en cada cambio, lo que alternará el banner según el valor de `wifiState`.

La barra de navegación tendrá un icono de Wifi, y también añadiremos un manejador de eventos para su evento `click`. Como el método `refreshBanner()` se llama en cada cambio, el icono no solo alternará el banner, sino que también cambiará según el estado de la conexión:

<PlatformBlock for="WebComponents">

```html
<igc-navbar>
  <h1>Gallery</h1>
  <igc-icon id="icon" slot="end" name="signal_wifi_off"></igc-icon>
</igc-navbar>

<igc-banner id="banner">
    ...
    <div slot="actions">
        ...
        <igc-button id="button">
            <igc-ripple></igc-ripple>
            Turn On Wifi
        </igc-button>
    </div>
</igc-banner>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
private banner: IgcBannerComponent;
private icon: IgcIconComponent;
private button: IgcButtonComponent;

private wifiState: boolean = false;

constructor() {
    this.banner = document.getElementById('banner') as IgcBannerComponent;
    this.icon = document.getElementById('icon') as IgcIconComponent;
    this.button = document.getElementById('button') as IgcButtonComponent;

    this.icon.addEventListener('click', () => this.refreshBanner());
    this.button.addEventListener('click', () => this.refreshBanner());
}

public refreshBanner() {
    if (!this.wifiState) {
        this.icon.name = 'signal_wifi_4_bar';
        this.banner.hide();
    } else {
        this.icon.name = 'signal_wifi_off';
        this.banner.show();
    }
    this.wifiState = !this.wifiState;
}
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const bannerRef = useRef<IgrBanner>(null);
const iconRef = useRef<IgrIcon>(null);

const [wifiState, setWifiState] = useState(false);
const [iconName, setIconName] = useState("signal_wifi_off");

const refreshBanner = () => {
    const nextWifiState = !wifiState;
    setWifiState(nextWifiState);
    setIconName(nextWifiState ? "signal_wifi_4_bar" : "signal_wifi_off");

    if (nextWifiState) {
        bannerRef.current.hide();
    } else {
        bannerRef.current.show();
    }
}

return(
    <>
        <IgrNavbar>
            <h1>Gallery</h1>
            <IgrIcon ref={iconRef} name={iconName} slot="end" onClick={refreshBanner}></IgrIcon>
        </IgrNavbar>

        <IgrBanner ref={bannerRef}>
            ...
            <div slot="actions">
                ...
                <IgrButton variant="flat" onClick={refreshBanner}>
                    <IgrRipple />
                    <span>Turn On Wifi</span>
                </IgrButton>
            </div>
        </IgrBanner>
    </>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbNavbar>
    <h1>Gallery</h1>
    <IgbIcon @ref="iconRef" IconName="@iconName" Collection="material" slot="end" @onclick="RefreshBanner"></IgbIcon>
</IgbNavbar>

<IgbBanner @ref="bannerRef">
    ...
    <div slot="actions">
        ...
        <IgbButton Variant="ButtonVariant.Flat" @onclick="RefreshBanner">
            Turn On Wifi
            <IgbRipple />
        </IgbButton>
    </div>
</IgbBanner>

@code {

    private string iconName = "signal_wifi_off";
    private bool wifiState = false;

    private void RefreshBanner()
    {

        {
            this.iconName = "signal_wifi_4_bar";
            this.bannerRef.HideAsync();

        else
        {
            this.iconName = "signal_wifi_off";
            this.bannerRef.ShowAsync();
        }
        this.wifiState = !this.wifiState;

}
```

## Estilos

El componente <ApiLink pkg="core" type="Banner" /> expone varias partes CSS que le dan control total sobre su estilo:

|Nombre|Descripción|
|--|--|
| `base` | El wrapper base del componente banner. |
| `spacer` | El wrapper interno que establece el espacio alrededor del banner. |
| `message` | La parte que contiene el texto y la ilustración. |
| `illustration` | La parte que contiene el icono o la ilustración del banner. |
| `content` | La parte que contiene el contenido de texto del banner. |
| `actions` | La parte que contiene los botones de acción del banner. |

```css
igc-banner::part(spacer) {
  background: var(--ig-surface-600);
}

igc-banner::part(illustration) {
  color: var(--ig-surface-600-contrast);
}

igc-banner::part(content) {
  color: var(--ig-gray-900);
}
```
