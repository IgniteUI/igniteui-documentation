# {Platform} Trabajar con gráficos

La funcionalidad <ApiLink type="WorksheetChart" /> del motor de Excel de Infragistics {Platform} le permite añadir representaciones gráficas de las tendencias de datos en regiones de celdas de una hoja de cálculo. Por ejemplo, si quiere ver sus datos de Excel en una región de celdas representada como una columna, una línea o cualquiera de otros más de 70 tipos de gráfico, esta característica puede ayudarle a conseguirlo.

## Uso
Para añadir un gráfico a una hoja de cálculo, debe usar el método <ApiLink type="WorksheetShapeCollection" member="addChart" label="AddChart" /> de la colección de formas de la hoja de cálculo. En este método puede especificar el tipo de gráfico que quiere usar, la celda superior izquierda, la celda inferior derecha y los porcentajes de esas celdas que quiere que ocupe el gráfico.

El método <ApiLink type="WorksheetShapeCollection" member="addChart" label="AddChart" /> devuelve el elemento de gráfico de la hoja de cálculo que se añadirá a la hoja. Una vez obtenido, puede usar el método <ApiLink type="WorksheetChart" member="setSourceData" label="SetSourceData" /> del gráfico para establecer la dirección de celda de la región de celdas de la hoja que quiere usar como origen de datos, así como indicar si quiere cambiar la asignación de columnas y filas a los ejes X e Y.

Hay más de 70 tipos de gráfico admitidos, entre ellos `Line`, `Area`, <ApiLink type="Column" /> y `Pie`.

El siguiente código muestra cómo usar la función de gráficos de Excel. El fragmento siguiente añadirá un gráfico de columnas entre la primera celda y la decimotercera celda de la primera fila de la hoja de cálculo. A continuación, se establece el origen de datos en la región A2:M6, cambiando la asignación de columnas y filas a los ejes X e Y del gráfico de columnas:

```ts
var chart = ws.shapes().addChart(ChartType.ColumnClustered,
      ws.rows(0).cells(0), { x: 0, y: 0 },
      ws.rows(0).cells(12), { x: 100, y: 100 });

chart.setSourceData("A2:M6", true);
```

<PlatformBlock for="Blazor">

```razor
var chart = sheet.Shapes.AddChart(Documents.Excel.Charts.ChartType.ColumnClustered,
    sheet.Rows[0].Cells[0], new Core.Point(0, 0),
    sheet.Rows[0].Cells[props.Length - 1], new Core.Point(100, 100));

chart.SetSourceData("A2:M6", true);
```
