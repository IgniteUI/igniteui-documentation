# Mapa de símbolos geográfico de {Platform}

En el componente de mapa de {Platform} puede usar `GeographicSymbolSeries` para mostrar datos geoespaciales mediante puntos o marcadores en un contexto geográfico. Este tipo de serie geográfica se usa a menudo para representar un conjunto de ubicaciones geográficas, como ciudades, aeropuertos, terremotos o puntos de interés.

## Requisitos de datos
De forma similar a otros tipos de series geográficas del componente de mapa, `GeographicSymbolSeries` tiene la propiedad `dataSource`, que puede enlazarse a un array de objetos. Además, cada elemento de datos de este objeto debe tener dos columnas de datos numéricas que almacenen una ubicación geográfica (longitud y latitud). Estas columnas de datos se asignan después a las propiedades `latitudeMemberPath` y `longitudeMemberPath`. `GeographicSymbolSeries` usa los valores de estas columnas de datos asignadas para representar los elementos de símbolo en el componente de mapa geográfico.

## Fragmento de código
El siguiente código muestra cómo enlazar `GeographicSymbolSeries` a las ubicaciones de ciudades cargadas desde un archivo de forma mediante `ShapefileRecord`.

```json-snippet source="/maps/geo-map/type-scatter-symbol-series" code="allCode"
{
    "type": "GeographicMap",
    "name": "geoMap",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicSymbolSeries",
            "name": "citiesSeries",
            "dataSourceRef": "WorldCities",
            "markerType": "Circle",
            "latitudeMemberPath": "Y",
            "longitudeMemberPath": "X",
            "markerBrush": "White",
            "markerOutline": "Gray"
        },
        {
            "type": "GeographicSymbolSeries",
            "name": "capitalsSeries",
            "dataSourceRef": "WorldCapitals",
            "markerType": "Circle",
            "latitudeMemberPath": "Y",
            "longitudeMemberPath": "X",
            "markerBrush": "White",
            "markerOutline": "rgb(32, 146, 252)"
        }
    ]
}
```
