# {Platform}: navegar por el contenido del mapa

La navegación en el control `GeographicMap` está habilitada de forma predeterminada y permite ampliar y desplazar el contenido del mapa. Sin embargo, este comportamiento puede cambiarse con la propiedad `Zoomable`. Es importante saber que el mapa solo permite el zoom sincronizado: escala el contenido del mapa conservando la relación de aspecto. Por tanto, no es posible escalar el contenido del mapa verticalmente sin escalarlo también horizontalmente, y viceversa.

## Coordenadas geográficas

Navega por el contenido del mapa dentro de la región geográfica delimitada por estas coordenadas:
- horizontalmente, desde 180°E (negativo) hasta 180°W (positivo) de longitud
- verticalmente, desde 85°S (negativo) hasta 85°N (positivo) de latitud

Este fragmento de código muestra cómo navegar por el mapa usando coordenadas geográficas:

```json-snippet channel="eventHandlers"
{
    "descriptions": {
        "content": { "type": "GeographicMap", "name": "geoMap", "height": "100%", "width": "100%", "zoomable": true }
    },
    "onViewInit": [ "MapNavigationOnViewInit" ]
}
```


## Coordenadas de ventana

Además, puede navegar por el contenido del mapa dentro del rectángulo de la ventana delimitado por estas coordenadas relativas:
- horizontalmente, con valores de 0.0 a 1.0
- verticalmente, con valores de 0.0 a 1.0

Este fragmento de código muestra cómo navegar por el mapa usando coordenadas relativas de la ventana:

```json-snippet channel="code"
{
    "$styleOptions": { "qualifyCodeBehindFields": true },
    "type": "GeographicMap",
    "name": "geoMap",
    "windowRect": { "left": 0.1, "top": 0.1, "width": 0.5, "height": 0.5 },
    "$windowRect": "+nav:code"
}
```

o

```json-snippet channel="code"
{
    "$styleOptions": { "qualifyCodeBehindFields": true },
    "type": "GeographicMap",
    "name": "geoMap",
    "windowPositionHorizontal": 0.1,
    "$windowPositionHorizontal": "+nav:code",
    "windowPositionVertical": 0.1,
    "$windowPositionVertical": "+nav:code",
    "windowScale": 0.5,
    "$windowScale": "+nav:code"
}
```


## Propiedades
La tabla siguiente resume las propiedades que pueden usarse en la navegación del control `GeographicMap`:

| Nombre de la propiedad  | Tipo de propiedad   | Descripción   |
|----------------|-----------------|---------------|
|`WindowRect`| {RectType} | Establece la nueva posición y el nuevo tamaño de la ventana de navegación en el área visible del contenido del mapa. {RectType} con los valores 0, 0, 1, 1 alejará todo el contenido del mapa en la ventana de navegación. |
|`windowScale`| número | Establece el nuevo tamaño de la ventana de navegación en el control de mapa. Equivale al valor más pequeño de Width o Height almacenado en la propiedad `WindowRect`. |
|`windowPositionHorizontal`| número | Establece la nueva posición horizontal del punto de anclaje de la ventana de navegación desde el borde izquierdo del control de mapa. Equivale al valor almacenado en Left de la propiedad `WindowRect`. |
|`windowPositionVertical`| número | Establece la nueva posición vertical del punto de anclaje de la ventana de navegación desde el borde superior del control de mapa. Equivale al valor almacenado en Top de la propiedad `WindowRect`. |
|`actualWindowRect`| {RectType} | Indica la posición y el tamaño actuales de la ventana de navegación en el área visible del contenido del mapa. {RectType} con los valores 0, 0, 1, 1 muestra todo el contenido del mapa en la ventana de navegación.  |
|`actualWindowScale`| número | Indica el tamaño actual de la ventana de navegación en el control de mapa. Equivale al valor más pequeño de Width o Height almacenado en la propiedad `actualWindowRect`. |
|`actualWindowPositionHorizontal`| número | Indica la posición horizontal actual del punto de anclaje de la ventana de navegación desde el borde izquierdo del control de mapa. Equivale al valor almacenado en Left de la propiedad `actualWindowRect`. |
|`actualWindowPositionVertical`| número | Indica la posición vertical del punto de anclaje de la ventana de navegación desde el borde superior del control de mapa. Equivale al valor almacenado en Top de la propiedad `actualWindowRect`. |
