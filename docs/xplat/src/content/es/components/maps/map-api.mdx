# API de {Platform} Geographic Map

El {Platform} `GeographicMap` tiene los siguientes miembros de API:

- `Zoomable`
- `m:ZoomToGeographic`
- `WorldRect`
- `WindowRect`
- `WindowScale`
- `m:GetGeographicFromZoom`
- `m:GetGeographicPoint`
- `m:GetPixelPoint`
