# {Platform} Configurar Spreadsheet

El componente {Platform} Spreadsheet le permite al usuario configurar muchos aspectos distintos del control. Esto incluye, entre otros, la edición de las celdas, la visibilidad de las líneas de cuadrícula y de los encabezados, la protección, el nivel de zoom y otras propiedades relacionadas con la hoja de trabajo de Excel.

## Configurar la edición de celdas

Cuando un usuario edita el valor de una celda y confirma la nueva entrada, el control <ApiLink type="Spreadsheet" /> puede desplazarse a las celdas adyacentes a la celda activa actual al pulsar la tecla <kbd>ENTER</kbd>, según la configuración de la hoja de cálculo.

Para habilitar esta navegación con la tecla <kbd>ENTER</kbd>, puede establecer la propiedad <ApiLink type="Spreadsheet" member="isEnterKeyNavigationEnabled" label="IsEnterKeyNavigationEnabled" /> en **true**. Si se establece en false, la celda activa seguirá siendo la misma al pulsar la tecla <kbd>ENTER</kbd>.

También puede configurar la dirección de la celda adyacente a la que se navega al pulsar la tecla <kbd>ENTER</kbd>, estableciendo la propiedad <ApiLink type="Spreadsheet" member="enterKeyNavigationDirection" label="EnterKeyNavigationDirection" /> en `\Down`, `\Up`, `\Left` o `\Right`.

Los siguientes fragmentos de código muestran lo anterior:

<PlatformBlock for="Angular">

```html
<igx-spreadsheet isEnterKeyNavigationEnabled=true
    enterKeyNavigationDirection="Left">
</igx-spreadsheet>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-spreadsheet is-enter-key-navigation-enabled="true"
    enter-key-navigation-direction="Left">
</igc-spreadsheet>
```

</PlatformBlock>

<PlatformBlock for="React">
```ts
import { SpreadsheetEnterKeyNavigationDirection } from 'igniteui-react-spreadsheet';
```


</PlatformBlock>

<PlatformBlock for="WebComponents">
```ts
import { SpreadsheetEnterKeyNavigationDirection } from 'igniteui-webcomponents-spreadsheet';
```


</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrSpreadsheet isEnterKeyNavigationEnabled={true} enterKeyNavigationDirection={SpreadsheetEnterKeyNavigationDirection.Left} />
```

</PlatformBlock>

```ts
this.spreadsheet.isEnterKeyNavigationEnabled = true;
this.spreadsheet.enterKeyNavigationDirection = SpreadsheetEnterKeyNavigationDirection.Left;
```

## Configurar la navegación

El control <ApiLink type="Spreadsheet" /> le permite configurar la navegación entre las celdas de una hoja de trabajo, según si el control está en "modo final" o no. El modo final es la función en la que, al pulsar una tecla de flecha, la celda activa se mueve desde la celda actual hasta el final de la fila o columna donde hay datos en las celdas adyacentes, según la dirección de la flecha pulsada. Esta función resulta útil para desplazarse muy rápidamente hasta el final de grandes bloques de datos.

Por ejemplo, si está en modo final y hace clic en un gran bloque de datos de 100x100 y pulsa la tecla de flecha <kbd>→</kbd>, se desplazará hasta el extremo derecho de la fila en la que se encuentra, hasta la columna más a la derecha con datos. Después de esta operación, <ApiLink type="Spreadsheet" /> saldrá del modo final.

El modo final entra en vigor en tiempo de ejecución cuando el usuario pulsa la tecla <kbd>END</kbd>, pero puede configurarse mediante programación estableciendo la propiedad <ApiLink type="Spreadsheet" member="isInEndMode" label="IsInEndMode" /> del control de hoja de cálculo.

Los siguientes fragmentos de código muestran lo anterior, de modo que <ApiLink type="Spreadsheet" /> empezará en modo final:

<PlatformBlock for="Angular">

```html
<igx-spreadsheet isInEndMode=true></igx-spreadsheet>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrSpreadsheet isInEndMode={true} />
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html

```

</PlatformBlock>

```ts
this.spreadsheet.isInEndMode = true;
```

## Configurar la protección

<ApiLink type="Spreadsheet" /> respetará la protección de un libro hoja por hoja. La configuración de la protección de una hoja de trabajo puede establecerse llamando al método `Protect()` de la hoja para protegerla, y al método `Unprotect()` para desprotegerla.

Puede activar o desactivar la protección de la hoja de trabajo activa actualmente en el control <ApiLink type="Spreadsheet" /> con el siguiente código:

```ts
this.spreadsheet.activeWorksheet.protect();
this.spreadsheet.activeWorksheet.unprotect();
```

## Configurar la selección

El control <ApiLink type="Spreadsheet" /> le permite configurar el tipo de selección permitido en el control cuando el usuario pulsa teclas modificadoras (<kbd>SHIFT</kbd> o <kbd>CTRL</kbd>). Esto se hace estableciendo la propiedad <ApiLink type="Spreadsheet" member="selectionMode" label="SelectionMode" /> de la hoja de cálculo en uno de los siguientes valores:

- `\AddToSelection`: los nuevos intervalos de celdas se añaden a la colección <ApiLink type="SpreadsheetSelection" member="cellRanges" label="CellRanges" /> del objeto <ApiLink type="SpreadsheetSelection" /> sin necesidad de mantener pulsada la tecla <kbd>CTRL</kbd> al arrastrar con el ratón, y un intervalo se añade con la primera navegación por flechas tras entrar en el modo. Puede entrar en el modo pulsando <kbd>SHIFT</kbd> + <kbd>F8</kbd>.
- `\ExtendSelection`: el intervalo de selección de la colección <ApiLink type="SpreadsheetSelection" member="cellRanges" label="CellRanges" /> del objeto <ApiLink type="SpreadsheetSelection" /> que representa la celda activa se actualiza a medida que se usa el ratón para seleccionar una celda o se navega con el teclado.
- `\Normal`: la selección se reemplaza al arrastrar el ratón para seleccionar una celda o un intervalo de celdas. Del mismo modo, al navegar con el teclado se crea una nueva selección. Puede añadir un nuevo intervalo manteniendo pulsada la tecla <kbd>CTRL</kbd> y usando el ratón, y puede modificar el intervalo de selección que contiene la celda activa manteniendo pulsada la tecla <kbd>SHIFT</kbd> mientras hace clic con el ratón o navega con el teclado, por ejemplo con las teclas de flecha.

<ApiLink type="SpreadsheetSelection" />

El
<ApiLink type="SpreadsheetSelection" />

## Configurar el área de la barra de pestañas

El control <ApiLink type="Spreadsheet" /> respeta la configuración de visibilidad y de ancho del área de la barra de pestañas de la <ApiLink type="Workbook" member="windowOptions" label="WindowOptions" /> de la <ApiLink type="Spreadsheet" member="workbook" label="Workbook" /> activa actualmente, mediante las propiedades `\TabBarWidth` y `\TabBarVisibility`, respectivamente.

El área de la barra de pestañas es la zona que muestra los nombres de las hojas de trabajo como pestañas en el control.

Puede configurar la visibilidad y el ancho de la barra de pestañas con el siguiente fragmento de código:

```ts
this.spreadsheet.workbook.windowOptions.tabBarVisible = false;

this.spreadsheet.workbook.windowOptions.tabBarWidth = 200;
```

## Configurar el nivel de zoom

El componente {Platform} Spreadsheet admite acercar y alejar la vista configurando su propiedad <ApiLink type="Spreadsheet" member="zoomLevel" label="ZoomLevel" />. El nivel de zoom puede ser como máximo del 400 % y como mínimo del 10 %.

Al establecer esta propiedad con un número, se representa el porcentaje como número entero, de modo que establecer <ApiLink type="Spreadsheet" member="zoomLevel" label="ZoomLevel" /> en 100 equivale a establecerlo en 100 %.

Los siguientes fragmentos de código muestran cómo configurar el nivel de zoom de la hoja de cálculo:

</PlatformBlock>


</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-spreadsheet zoom-level="200"></igc-spreadsheet>
```

</PlatformBlock>

```ts
this.spreadsheet.zoomLevel = 200;
```
