# Instalar Ignite UI for Blazor

Ignite UI for Blazor se distribuye mediante paquetes NuGet. Para usar los componentes de Ignite UI for Blazor en sus aplicaciones Blazor, primero debe instalar los paquetes NuGet adecuados.

Hay tres formas de instalar Ignite UI for Blazor mediante NuGet:
- [Usar Visual Studio](#usar-visual-studio)
- [Usar la CLI de .NET](#usar-la-cli-de-net)
- [Usar el administrador de paquetes](#usar-el-administrador-de-paquetes)

Los usuarios con licencia deben usar los paquetes NuGet oficiales de Ignite UI for Blazor con licencia que se publican en el [feed privado de NuGet de Infragistics](./general-nuget-feed.mdx).

<DocsAside type="info">
Los usuarios de prueba pueden instalar el paquete NuGet **IgniteUI.Blazor.Trial**, disponible en [NuGet.org](https://www.nuget.org/packages/IgniteUI.Blazor.Trial).
</DocsAside>

## Usar Visual Studio

Haga clic con el botón derecho en la solución o en el proyecto y seleccione **Administrar paquetes NuGet para la solución**.

<Image src={nugetManagePackages} alt="nuget-manage-packages" />

En el cuadro de diálogo del administrador de paquetes, abra la pestaña **Examinar**, seleccione el origen de paquetes **Infragistics** e instale el paquete NuGet **IgniteUI.Blazor** en el proyecto.

<Image src={nugetPackageManagerBrowse} alt="nuget-package-manager-browse" />

<DocsAside type="info">
Si no dispone de un origen de paquetes de Infragistics, aprenda a añadirlo leyendo el tema [Feed de NuGet de Infragistics](./general-nuget-feed.mdx).
</DocsAside>

## Usar la CLI de .NET

```cmd
> dotnet add package IgniteUI.Blazor --version {PackageVerLatestShort}
```

## Usar el administrador de paquetes

```cmd
PM> Install-Package IgniteUI.Blazor -Version {PackageVerLatestShort}
```
