# Mapa de polilíneas geográfico de {Platform}

En el componente de mapa de {Platform} puede usar `GeographicPolylineSeries` para mostrar datos geoespaciales mediante polilíneas en un contexto geográfico. Este tipo de serie geográfica se usa a menudo para representar carreteras o conexiones entre ubicaciones geográficas, como ciudades o aeropuertos.

## Ejemplo de mapa de polilíneas geográfico de {Platform}


<Sample src="/maps/geo-map/type-shape-polyline-series" height={500} alt="{Platform}: ejemplo de uso de la serie de polilíneas de forma" />




`GeographicPolylineSeries` funciona de forma muy parecida a `GeographicShapeSeries`, salvo que los datos geoespaciales se representan con polilíneas en lugar de polígonos.

## Requisitos de datos
De forma similar a otros tipos de series geográficas del control, `GeographicPolylineSeries` tiene la propiedad `dataSource`, que puede enlazarse a un array de objetos. Además, cada elemento de datos de este objeto debe tener una columna de datos que almacene una o varias formas usando un array de arrays de objetos con valores x e y que representan ubicaciones geográficas. Esta columna de datos se asigna después a la propiedad `ShapeMemberPath`. `GeographicPolylineSeries` usa los puntos de esta columna de datos asignada para dibujar polilíneas en el control.

Cuando las formas proceden directamente de un archivo de forma y no necesitan remodelarse antes, la serie puede recibir su propio `ShapefileDataSource`, y lee los puntos de los registros por sí misma. Eso es lo que hace el código siguiente; [Enlazar archivos de forma](./geo-map-binding-shp-file.mdx) cubre la otra vía, en la que un manejador convierte cada registro en un objeto propio y asigna `ShapeMemberPath` a él.

## Fragmento de código
El siguiente código asigna a `GeographicPolylineSeries` un `ShapefileDataSource` que apunta a un archivo de forma de las carreteras de Estados Unidos, y dibuja todas las carreteras que contiene.

```json-snippet source="/maps/geo-map/type-shape-polyline-series"
{
    "type": "GeographicMap",
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicPolylineSeries",
            "name": "GeographicPolylineSeries1",
            "shapefileDataSource": {
                "type": "ShapeDataSource",
                "shapefileSource": "https://static.infragistics.com/xplatform/shapes/AmericanRoads.shp",
                "databaseSource": "https://static.infragistics.com/xplatform/shapes/AmericanRoads.dbf"
            },
            "outline": "Red"
        }
    ]
}
```
