# Guía paso a paso con Ignite UI CLI

El modo paso a paso de Ignite UI CLI es un asistente interactivo que le guía por la creación del proyecto, la selección de la plantilla, la configuración del tema y la adición de vistas de componentes para los proyectos de {ProductName}. Cubre las mismas operaciones que los comandos no interactivos `ig new` y `ig add`, pero le pregunta en cada paso en lugar de exigir todos los argumentos de antemano.

El modo paso a paso no admite el uso mediante scripts ni no interactivo; para ello, use los comandos `ig new` y `ig add` con argumentos explícitos. El asistente depende de `Inquirer.js`; consulte [los terminales compatibles](https://github.com/SBoudrias/Inquirer.js#support-os-terminals) para ver la compatibilidad. Para la referencia completa de la CLI, consulte [Información general de Ignite UI CLI](./general-cli-overview.mdx).

Para activar el asistente, ejecute:

```cmd
ig
```

o:

```cmd
ig new
```

## Crear un proyecto nuevo

El asistente recorre en secuencia el nombre del proyecto, la selección de framework y tipo, la elección de la plantilla y el tema. Cada paso muestra sus opciones como una lista interactiva: navegue con las teclas de flecha y confirme con ENTER.

### Escriba un nombre de proyecto

En primer lugar, se le pedirá que escriba un nombre para su aplicación. El proyecto se crea dentro de un directorio con el mismo nombre.

Navegue por las opciones con las teclas de flecha y pulse ENTER para confirmar:

Si selecciona **Side Navigation** o **Side Navigation Mini**, el asistente añade un paso adicional que pregunta si desea añadir autenticación al proyecto. Si responde que sí, se genera la variante de autenticación correspondiente (`side-nav-auth` o `side-nav-mini-auth`). Si selecciona **Empty**, se omite la pregunta de autenticación.

### Seleccione un tema

Elija un tema para su aplicación:

- La opción **default** incluye un archivo CSS precompilado con el tema predeterminado {ProductName}.
- La opción **custom** genera una paleta de colores y una configuración de tema basadas en Sass, usando la [API de temas](./themes/overview.mdx).

### Configurar las herramientas de IA

Después del tema, el asistente le pide que configure los asistentes de programación con IA. Primero, seleccione qué asistentes deben recibir la configuración del servidor MCP:

```bash
? Which AI coding assistants do you want to configure MCP servers for? (Press <space> to select)
❯◉ VS Code (GitHub Copilot)
 ◉ Cursor
 ◯ Generic (.mcp.json)
 ◯ Gemini CLI
 ◯ JetBrains (AI Assistant)
 ◯ None
```

A continuación, seleccione qué agentes de IA deben recibir los archivos de skills:

```bash
? Which AI agents should receive skill files? (Press <space> to select)
❯◉ GitHub Copilot (.agents/skills/)
 ◉ Claude (.claude/skills/)
 ◉ Cursor (.cursor/rules/)
 ◯ Codex (.codex/)
 ◯ Windsurf (.windsurfrules)
 ◯ Gemini CLI (.gemini/)
 ◯ JetBrains Junie (.junie/guidelines/)
 ◯ None
```

Navegue por las opciones con las teclas de flecha, active o desactive las selecciones con SPACE y confirme con ENTER. Si selecciona **None** en ambas preguntas, se omite por completo la configuración de IA.

Para omitir estos mensajes en modo no interactivo, pase directamente los indicadores `--assistants` y `--agents` a `ig new`:

```cmd
ig new my-app --framework=react --type=igr-ts --template=side-nav --assistants vscode --agents copilot claude
```

Para más detalles sobre los valores disponibles de los indicadores, consulte [Información general de Ignite UI CLI](./general-cli-overview.mdx#configuración-de-ia-durante-la-creación-del-proyecto).

### Completar o continuar

Tras completar los pasos anteriores, se genera la estructura del proyecto, se inicializa un repositorio de Git y se confirma el proyecto. A continuación se le preguntará si quiere completar el proceso o añadir una vista nueva a su aplicación.

## Añadir vista

Ignite UI CLI admite varias plantillas de componentes que pueden añadirse a un proyecto existente. Este modo está disponible como continuación de la creación del proyecto o dentro de un proyecto existente, usando:

```cmd
ig add
```

Se le mostrará una lista de las plantillas de componentes disponibles, agrupadas por categoría. Use las teclas de flecha para navegar por los grupos y ENTER para seleccionar. Para algunas plantillas, como `Custom Grid`, se le mostrará una lista de funciones opcionales que puede activar o desactivar con la tecla SPACE antes de confirmar su selección.

Después de seleccionar un grupo, elija una plantilla concreta de la lista e introduzca un nombre para el nuevo componente. Si elige una plantilla de escenario, también se le mostrará una lista de las plantillas de escenario disponibles.

Después de añadir una plantilla, se le preguntará si desea añadir más vistas o completar el proceso. Al completarlo, se instalan las dependencias de paquetes que falten, se compila la aplicación y se abre en su navegador predeterminado.

Para añadir más vistas a un proyecto más adelante sin el asistente, use el comando directo `add`:

```cmd
ig add [template] [name]
```

Por ejemplo:

```cmd
ig add grid MyGrid
```

<DocsAside type="info">
Su archivo de rutas se actualizará con la ruta de la página recién generada. Por ejemplo, un componente llamado `MyGrid` será accesible en `/my-grid`.
</DocsAside>

## Ejecutar la aplicación

Cuando el proyecto esté completo, ejecútelo en cualquier momento con:

```cmd
ig start
```

Esto compila el proyecto, inicia un servidor web local y abre la aplicación en su navegador predeterminado.
