# Actualizaciones de datos en vivo de {Platform} {ComponentTitle}

La función de actualizaciones de datos en vivo de {ProductName} en {Platform} {ComponentTitle} sirve para habilitar actualizaciones en tiempo real o casi en tiempo real de los datos que se muestran en la cuadrícula. Esto resulta muy útil en aplicaciones cuyos datos cambian constantemente, como los monitores bursátiles, los marcadores deportivos en directo o los paneles de IoT (Internet de las cosas). <ApiLink type="{ComponentName}" /> puede gestionar miles de actualizaciones por segundo, manteniendo al mismo tiempo la respuesta a las interacciones del usuario.

## Plantillas
Actualizar la vista funciona igual para las columnas con plantilla predeterminada que para las columnas con plantilla personalizada. Sin embargo, se recomienda mantener las plantillas personalizadas relativamente sencillas. A medida que aumenta el número de elementos de la plantilla, también aumenta el impacto negativo en el rendimiento.

## Alimentación de datos en vivo con Dock Manager y componentes igxGrid
El objetivo de esta demostración es mostrar un panel financiero con un flujo de datos en tiempo real que usa un back-end de concentrador [SignalR](https://dotnet.microsoft.com/apps/aspnet/signalr).
Como puede ver, el componente igxGrid gestiona con facilidad las actualizaciones de alta frecuencia procedentes del servidor. El código de la aplicación ASP.NET Core con SignalR puede encontrarse en este [repositorio público de GitHub](https://github.com/IgniteUI/finjs-web-api).
<Sample src="/{ComponentSample}/finjs-dock-manager" height={700} alt="Ejemplo de actualización de datos en vivo de {Platform} {ComponentTitle} con un servicio" />




### Iniciar la conexión del concentrador

El servicio signal-r gestiona la conectividad y las actualizaciones de los parámetros gestionables expuestos: **frecuencia**, **volumen** y **alternancia del estado de actualización en vivo** (Iniciar/Detener).

```ts
this.hubConnection = new signalR.HubConnectionBuilder()
        .configureLogging(signalR.LogLevel.Trace)
        .withUrl('https://www.infragistics.com/angular-apis/webapi/streamHub')
        .build();
    this.hubConnection
        .start()
        .then(() => {
            this.hasRemoteConnection = true;
            this.registerSignalEvents();
            this.broadcastParams(interval, volume, live, updateAll);
        })
        .catch(() => {});
```

Según la frecuencia especificada, los grids recibirán del servidor un total de 30 actualizaciones nuevas. Se aplican clases cellStyle específicas a las tres columnas que gestionan los cambios (Price, Change y Change in percent).

### Frecuencia de actualización y volumen de datos

Usando el panel de acciones de la izquierda, puede gestionar la frecuencia del flujo de datos y el volumen de datos solicitados. Todos los grids usan el mismo origen de datos. Siéntase libre de usar los demás elementos de acción para **detener el flujo de datos**, cambiar el **tema de la aplicación** o añadir **dinámicamente un contenedor DockSlot** con un igxGrid.

Usamos el método `updateParameters` para solicitar un nuevo conjunto de datos con cierta frecuencia. Este método forma parte de la [implementación del hub de streaming](https://github.com/IgniteUI/finjs-web-api/blob/master/WebAPI/Models/StreamHub.cs#L18) de SignalR.

```ts
this.hubConnection.invoke('updateparameters', frequency, volume, live, updateAll)
    .then(() => console.log('requestLiveData', volume))
    .catch(err => {
        console.error(err);
    });
```

### Crear dinámicamente los componentes DockSlot y Grid

Usando [ComponentFactoryResolver](https://angular.io/api/core/ComponentFactoryResolver) podemos crear los componentes DockSlot y Grid sobre la marcha.
