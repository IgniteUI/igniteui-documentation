# Ocultación de columnas de {Platform} {ComponentTitle}

<PlatformBlock for="Angular">
{ProductName} <ApiLink type="{ComponentName}" /> proporciona un <ApiLink type="ColumnActionsComponent" /> con un `ColumnHidingDirective` que permite a los usuarios ocultar columnas directamente desde la interfaz de usuario o mediante el componente {Platform}.
</PlatformBlock>

{ProductName} tiene una interfaz integrada de ocultación de columnas, que puede usarse a través de la barra de herramientas de {Platform} {ComponentTitle} para cambiar el estado visible de las columnas. Los desarrolladores tienen la flexibilidad de definir la interfaz de ocultación de columnas en cualquier lugar de la página que necesiten. La característica de ocultación de columnas de {Platform} {ComponentTitle} es especialmente útil cuando se quiere reducir el tamaño de la cuadrícula y eliminar la necesidad de recorrer campos redundantes con el tabulador.

## Interfaz de ocultar columnas de la barra de herramientas

La interfaz integrada de ocultación de columnas se coloca dentro de un <ApiLink pkg="core" type="Dropdown" /> en la barra de herramientas de <ApiLink type="{ComponentName}" />. Podemos mostrar u ocultar la interfaz de ocultación de columnas usando exactamente este desplegable.

Para ello, lo único que tenemos que hacer es establecer tanto <ApiLink type="GridToolbarActions" /> como <ApiLink type="GridToolbarHiding" /> dentro de <ApiLink type="{ComponentName}" />.

<ComponentBlock for="Grid">
<PlatformBlock for="Angular">
```html
<igx-grid [data]="localdata">
    <igx-grid-toolbar>
        <igx-grid-toolbar-actions>
            <igx-grid-toolbar-hiding></igx-grid-toolbar-hiding>
        </igx-grid-toolbar-actions>
    </igx-grid-toolbar>
</igx-grid>
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```razor
<{ComponentSelector} Data=northwindEmployees>

        </IgbGridToolbarActions>
```

</PlatformBlock>

## Estilos

Para empezar a dar estilo al componente de acciones de columna, debemos importar el archivo index, donde viven todas las funciones de tema y los mixins de componentes:

```scss
@use "igniteui-{Platform}/theming" as *;

// IMPORTANT: Prior to {ProductName} version 13 use:
// @import '~igniteui-{Platform}/lib/core/styles/themes/index';
```

Usando el enfoque más sencillo, creamos un tema nuevo que extiende `column-actions-theme` y acepta los parámetros `$title-color` y `$background-color`.

```scss
$custom-column-actions-theme: column-actions-theme(
    $background-color: steelblue,
    $title-color: gold
);
```

Como se ve, `column-actions-theme` solo controla los colores del contenedor de acciones de columna, pero no afecta a los botones, las casillas ni el grupo de entrada que contiene. Supongamos que queremos dar estilo también a los botones, así que crearemos un nuevo tema de botón:

```scss
$custom-button: flat-button-theme($foreground: gold, $disabled-foreground: black);
```

En este ejemplo solo hemos cambiado el color de texto de los botones planos y el color de los botones deshabilitados, pero `flat-button-theme` ofrece muchos más parámetros para controlar el estilo de los botones.

El último paso es **incluir** los mixins de los componentes, cada uno con su tema correspondiente:

```scss
@include column-actions($custom-column-actions-theme);
.igx-column-actions {
    @include button($custom-button);
}
```

> **Nota**
>Acotamos el mixin de **igx-button** dentro de `.igx-column-actions`, de modo que solo se den estilo a los botones de ocultación de columnas. En caso contrario, otros botones de la cuadrícula también se verían afectados.

 > **Nota**
 >Si el componente usa un `Emulated`ViewEncapsulation, es necesario `penetrate` esa encapsulación usando `::ng-deep`:

```scss
:host {
    ::ng-deep {
        @include column-actions($custom-column-actions-theme);
        .igx-column-actions {
            @include button($custom-button);
        }
    }
}
```

### Definir una paleta de colores

En lugar de codificar los valores de color como acabamos de hacer, podemos conseguir más flexibilidad en cuanto a colores usando las funciones `igx-palette` y `igx-color`.

`igx-palette` genera una paleta de colores basada en los colores primario y secundario que se le pasan:

```scss
$yellow-color: gold;
$blue-color: steelblue;

$custom-palette: palette($primary: $blue-color, $secondary: $yellow-color);
```

Y después, con `igx-color`, podemos obtener fácilmente un color de la paleta.

```scss
$custom-column-actions-theme: column-actions-theme(
    $title-color: color($custom-palette, "secondary", 400),
    $background-color: color($custom-palette, "primary", 200)
);

$custom-button: flat-button-theme(
    $foreground: color($custom-palette, "secondary", 400),
    $disabled-foreground: black
);
```

> **Nota**
>Las funciones `igx-color` y `igx-palette` son muy potentes para generar y obtener colores. Consulte el tema [Paletas](../themes/sass/palettes.mdx) para una guía detallada sobre cómo usarlas.

### Usar esquemas

Para avanzar con el motor de temas, puede crear una estructura sólida y flexible que se beneficie de [**esquemas**](themes/sass/schemas.mdx). Un **esquema** es una receta de un tema.

```scss
// Extending the dark column actions schema
$custom-column-actions-schema: extend($_dark-column-actions,
    (
        title-color:(
           color: ("secondary", 400)
        ),
        background-color:(
           color: ("primary", 200)
        )
    )
);
// Extending the dark button schema
$custom-button-schema: extend($_dark-button,
    (
        flat-text-color:(
           color: ("secondary", 500)
        ),
        disabled-color:(
           color: ("primary", 700)
        )
    )
);
```

Para aplicar nuestros esquemas personalizados debemos **extender** uno de los globales `light` o `dark`, lo que básicamente señala los componentes con un esquema personalizado, y después añadirlo a los temas de cada componente:

```scss
// Extending the global dark-schema
$custom-dark-schema: extend($dark-schema,(
    igx-column-actions: $custom-column-actions-schema,
    igx-button: $custom-button-schema
));

// Defining column-actions-theme with the global dark schema
$custom-column-actions-theme: column-actions-theme(
  $schema: $custom-dark-schema
);

// Defining flat-button-theme with the global dark schema
$custom-button: flat-button-theme(
  $schema: $custom-dark-schema
);
```

No olvide incluir los temas de la misma forma que se ha mostrado anteriormente.
