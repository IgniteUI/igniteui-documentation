# Descripción general de la selección de {Platform} {ComponentTitle}

Con la función de selección de {ProductName} en {Platform} {ComponentTitle} puede interactuar y manipular datos de forma sencilla mediante interacciones básicas con el ratón. Hay tres modos de selección disponibles:

- Selección de filas
- Selección de celdas
- Selección de columnas

Con la propiedad <ApiLink type="{ComponentName}" member="rowSelection" /> puede especificar:

- None
- Single
- Selección múltiple

## Opciones de selección de {Platform} {ComponentTitle}

<ComponentBlock for="Grid, HierarchicalGrid">
El componente {ProductName} <ApiLink type="{ComponentName}" /> ofrece tres modos de selección diferentes: [selección de filas](row-selection.mdx), [selección de celdas](cell-selection.mdx) y [selección de columnas](column-selection.mdx). De forma predeterminada, en <ApiLink type="{ComponentName}" /> solo está habilitado el modo **selección multicelda**. Para cambiar o habilitar el modo de selección, puede usar las propiedades <ApiLink type="{ComponentName}" member="rowSelection" />, <ApiLink type="{ComponentName}" member="cellSelection" /> o <ApiLink type="Column" member="selectable" />.

</ComponentBlock>

### Selección de filas de {Platform} {ComponentTitle}

La propiedad <ApiLink type="{ComponentName}" member="rowSelection" /> le permite especificar las siguientes opciones:

- `None` - La selección de filas estaría deshabilitada para <ApiLink type="{ComponentName}" />.
- `Single` - Estaría disponible la selección de una sola fila dentro de <ApiLink type="{ComponentName}" />.
- `Multiple` - La selección de varias filas estaría disponible mediante los selectores de fila, con una combinación de teclas como <kbd>CTRL</kbd> + <kbd>clic</kbd>, o pulsando la <kbd>tecla espacio</kbd> cuando una celda tiene el foco.

<ComponentBlock for="TreeGrid, HierarchicalGrid">
- `MultipleCascade` - Es un modo de selección en cascada, que selecciona todos los hijos del árbol que hay debajo del registro que el usuario selecciona con la interacción. En este modo, el estado de selección de un padre depende por completo del estado de selección de sus hijos.

</ComponentBlock>

> Consulte el tema [Selección de filas](row-selection.mdx) para más información.

### Selección de celdas de {Platform} {ComponentTitle}

La propiedad <ApiLink type="{ComponentName}" member="cellSelection" /> le permite especificar las siguientes opciones:

- `None` - La selección de celdas estaría deshabilitada para <ApiLink type="{ComponentName}" />.
- `Single` - Estaría disponible la selección de una sola celda dentro de <ApiLink type="{ComponentName}" />.
- `Multiple` - Actualmente, este es el estado predeterminado de la selección en <ApiLink type="{ComponentName}" />. La selección multicelda está disponible arrastrando el ratón sobre las celdas, tras mantener pulsado el botón izquierdo del ratón de forma continua.

<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">
> Consulte el tema [Selección de celdas](cell-selection.mdx) para más información.

</ComponentBlock>

### Selección de columnas de {Platform} {ComponentTitle}

La propiedad <ApiLink type="Column" member="selectable" /> le permite especificar las siguientes opciones para cada <ApiLink type="Column" />. La selección de columnas correspondiente se habilitará o deshabilitará si esta propiedad se establece en true o false, respectivamente.

Esto da lugar a las tres variantes siguientes:

- Selección única: <kbd>clic con el ratón</kbd> sobre la celda de la columna.
- Selección de varias columnas: manteniendo pulsada la tecla <kbd>CTRL</kbd> + <kbd>clic del ratón</kbd> sobre las celdas de la columna.
- Selección de columnas por rango: manteniendo pulsada la tecla <kbd>SHIFT</kbd> + <kbd>clic del ratón</kbd> se selecciona todo lo que hay entre medias.

## Menú contextual de {Platform} {ComponentTitle}

Mediante el evento <ApiLink type="{ComponentName}" member="contextMenu" /> puede añadir un menú contextual personalizado para facilitar su trabajo con <ApiLink type="{ComponentName}" />. Con un **clic derecho** sobre el cuerpo de la cuadrícula, el evento emite la celda sobre la que se ha disparado. El **menú contextual** operará con la celda emitida.

Si hay una **selección de varias celdas**, añadiremos lógica que comprobará si la celda seleccionada está dentro del área de la selección de varias celdas. Si es así, también emitiremos los valores de las celdas seleccionadas.

En esencia, la función principal tendrá este aspecto:

<PlatformBlock for="Angular">
```typescript
public rightClick(eventArgs: any) {
     // Prevent the default behavior of the right click
    eventArgs.event.preventDefault();
    this.multiCellArgs = {};
    // If we have multi-cell selection, check if selected cell is within the ranges
    if (this.multiCellSelection) {
        const node = eventArgs.cell.selectionNode;
        const isCellWithinRange = this.grid1.getSelectedRanges().some(range => {
            if (node.column >= range.columnStart &&
                node.column <= range.columnEnd &&
                node.row >= range.rowStart &&
                node.row <= range.rowEnd) {
                return true;
            }
            return false;
        })
        // If the cell is within a multi-cell selection range, bind all the selected cells data
        if (isCellWithinRange) {
            this.multiCellArgs = { data: this.multiCellSelection.data };
        }
    }
    // Set the position of the context menu
    this.contextmenuX = eventArgs.event.clientX;
    this.contextmenuY = eventArgs.event.clientY;
    this.clickedCell = eventArgs.cell;
    // Enable the context menu
    this.contextmenu = true;
}
```

El menú contextual tendrá las siguientes funciones:

- Copiar el _valor_ de la celda seleccionada.
- Copiar el _dataRow_ de la celda seleccionada.
- Si la celda seleccionada está dentro de un **rango de selección de varias celdas**, copie todos los _datos seleccionados_.

public copySelectedCellData(event) {
    const selectedData = { [this.cell.column.field]: this.cell.value };
    this.copyData(JSON.stringify({ [this.cell.column.field]: this.cell.value }));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copyRowData(event) {
    const selectedData = this.cell.row.data ;
    this.copyData(JSON.stringify(this.cell.row.data));
    this.onCellValueCopy.emit({ data: selectedData });
}

public copySelectedCells(event) {
    const selectedData = this.selectedCells.data;
    this.copyData(JSON.stringify(selectedData));
    this.onCellValueCopy.emit({ data: selectedData });
}

        selectedDataArea.innerText = JSON.stringify(selectedData);
        this.toggleContextMenu();

    public copySelectedData() {
        const selectedData = this.grid.getSelectedData();
        this.copyData(selectedData);
        const selectedDataArea = document.getElementById('selectedArea');
        selectedDataArea.innerText = JSON.stringify(selectedData);

        this.toggleContextMenu();
    }

    private copyData(data: any[]) {
        const tempElement = document.createElement('input');
        document.body.appendChild(tempElement);
        tempElement.setAttribute('id', 'temp_id');
        (document.getElementById('temp_id') as HTMLInputElement).value = JSON.stringify(data);
        tempElement.select();
        document.execCommand('copy');
        document.body.removeChild(tempElement);
    }

## Problemas conocidos y limitaciones

<PlatformBlock for="Angular">
- Usar <ApiLink type="{ComponentName}" /> con la selección habilitada en IE11 requiere importar explícitamente el polyfill de array en polyfill.ts de la aplicación {Platform}. IE11 ya no se admite a partir de la versión 13.0.0.

```typescript
import "core-js/es7/array";
```

</PlatformBlock>

Cuando el grid no tiene <ApiLink type="{ComponentName}" member="primaryKey" /> establecido y los escenarios de datos remotos están habilitados (cuando la paginación, la ordenación, el filtrado o el desplazamiento provocan solicitudes a un servidor remoto para obtener los datos que se mostrarán en el grid), una fila perderá el siguiente estado tras completarse una solicitud de datos:

- Selección de filas
- Expandir/contraer filas
- Edición de filas
- Anclaje de filas
