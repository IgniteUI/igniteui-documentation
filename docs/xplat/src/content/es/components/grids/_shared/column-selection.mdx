# Información general de la selección de columnas de {Platform} {ComponentTitle}

La característica de selección de columnas de {Platform} {ComponentTitle} en {ProductName} ofrece una forma simplificada, al estilo de Excel, de seleccionar y resaltar una columna completa con un solo clic. Puede habilitarse mediante la propiedad de entrada <ApiLink type="{ComponentName}" member="columnSelection" />. Gracias a su completa API, la característica permite manipular fácilmente el estado de la selección, extraer datos de las fracciones seleccionadas, realizar operaciones de análisis de datos y crear visualizaciones.

## Uso básico

La función de selección de columnas puede habilitarse mediante la entrada <ApiLink type="{ComponentName}" member="columnSelection" />, que acepta valores <ApiLink type="GridSelectionMode" />.

## Interacciones

El modo de selección predeterminado es `None`. Si se establece en `Single` o en `Multiple`, todas las columnas presentadas serán <ApiLink type="Column" member="selectable" />. Dicho esto, para seleccionar una columna basta con hacer clic en una de ellas, lo que la marcará como <ApiLink type="Column" member="selected" />. Si la columna no es seleccionable, no se aplicará ningún estilo de selección en el encabezado al pasar el cursor.

<DocsAside type="info">
La característica [Multi Column Headers](multi-column-headers.mdx) no se refleja en la propiedad de entrada <ApiLink type="{ComponentName}" member="selectable" />. El <ApiLink type="ColumnGroupComponent" /> está <ApiLink type="{ComponentName}" member="selectable" /> si al menos uno de sus hijos tiene habilitado el comportamiento de selección. Además, el componente se marca como <ApiLink type="{ComponentName}" member="selected" /> si todos sus descendientes <ApiLink type="{ComponentName}" member="selectable" /> están <ApiLink type="{ComponentName}" member="selected" />.
</DocsAside>

## Combinaciones de teclas

<DocsAside type="info">
Las combinaciones de teclas solo están disponibles cuando la entrada <ApiLink type="{ComponentName}" member="columnSelection" /> del grid está establecida en `multiple`.
</DocsAside>

Hay dos escenarios para la navegación por teclado de la función **Selección de columnas**:
- Selección de varias columnas: mantener pulsada <kbd>CTRL</kbd> + <kbd>clic</kbd> en cada celda de encabezado **seleccionable**.
- Selección de un rango de columnas: mantener pulsada <kbd>SHIFT</kbd> + <kbd>clic</kbd> selecciona todas las columnas **seleccionables** intermedias.

## Manipulaciones con la API

La **API** ofrece algunas capacidades adicionales para las columnas **no visibles**, de modo que cada columna **oculta** puede marcarse como <ApiLink type="Column" member="selected" /> mediante el **setter** correspondiente.

<DocsAside type="info">
Lo anterior también se aplica a <ApiLink type="ColumnGroupComponent" />, salvo que, al cambiar la propiedad <ApiLink type="{ComponentName}" member="selected" />, cambia el estado de sus descendientes.
</DocsAside>

Puede encontrar más información sobre las manipulaciones con la API en la sección [Referencias de la API](#referencias-de-api).

## Estilos

Además de los temas predefinidos, la cuadrícula puede personalizarse aún más estableciendo algunas de las propiedades CSS disponibles. Para crear un tema completo a partir de solo unos pocos colores, consulte el [tema de temas](theming.mdx).
Si quiere cambiar algunos colores, primero debe establecer una `class` para la cuadrícula:

<PlatformBlock for="WebComponents">
```html
<{ComponentSelector} class="grid"></{ComponentSelector}>
```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
<{ComponentSelector} className="grid"></{ComponentSelector}>
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```razor
<{ComponentSelector} class="grid"></{ComponentSelector}>
```
</PlatformBlock>

Después, establezca las propiedades CSS correspondientes en esta clase:


```css
.grid {
    --ig-grid-row-selected-background: #0062A3;
    --ig-grid-row-selected-text-color: #ecaa53;
    --ig-grid-row-selected-hover-background: #0062A3;
    --ig-grid-header-selected-text-color: #ecaa53;
    --ig-grid-header-selected-background: #0062A3;
    --ig-grid-row-selected-hover-text-color: #ecaa53;
    --ig-grid-row-selected-hover-background: #0062A3;
}
```

## Estilos

Antes de entrar en las opciones de estilo, hay que importar el módulo principal y todos los mixins de componentes.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```


<ComponentBlock for="Grid">
>Tenga en cuenta que la [selección de filas](row-selection.mdx) y la [selección de columnas](column-selection.mdx) no pueden manipularse de forma independiente. Ambas dependen de la misma `variables`.
</ComponentBlock>

Dicho esto, pasemos a cambiar los estilos de **selección** y de **pase del cursor**. <br/>

Siguiendo el enfoque más sencillo, definamos nuestro **tema** personalizado.

<ComponentBlock for="TreeGrid">
```scss
$custom-grid-theme: grid-theme(
    $row-selected-background: #011627,
    $row-selected-text-color: #ECAA53,
    $row-selected-hover-background: #011627,
    $header-selected-text-color: #ECAA53,
    $header-selected-background: #011627,
    $expand-icon-color: #ECAA53,
    $expand-icon-hover-color: #B64B80
);
```

</ComponentBlock>

<ComponentBlock for="Grid, HierarchicalGrid">
```scss
$custom-grid-theme: grid-theme(
    $row-selected-background: #011627,
    $row-selected-text-color: #ECAA53,
    $row-selected-hover-background: #011627,
    $header-selected-text-color: #ECAA53,
    $header-selected-background: #011627
);
```

</ComponentBlock>

<ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" /> acepta varios parámetros, pero estos cinco son los responsables de cambiar el aspecto de todas las columnas seleccionadas:
- **$row-selected-background**: establece el fondo de la fracción seleccionada.
- **$row-selected-text-color**: establece el color del texto de la fracción seleccionada
- **$row-selected-hover-background**: establece el color de la celda o del conjunto de celdas sobre el que se pasa el cursor.
- **$header-selected-text-color**: establece el color del texto del encabezado de la columna seleccionada
- **$header-selected-background**: establece el color de fondo del encabezado de la columna seleccionada.


### Uso de variables CSS
El último paso es incluir el tema personalizado de `{ComponentSelector}`.

```scss
@include tokens($custom-grid-theme);
```

### Sustituir el tema base
Para dar estilo a los componentes en Internet Explorer 11 tenemos que usar un enfoque distinto, ya que no admite variables CSS.

<DocsAside type="info">
Si el componente usa el ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), es necesario `penetrate` esa encapsulación usando `::ng-deep`. Para evitar que el tema personalizado se filtre a otros componentes, asegúrese de haber incluido el selector `:host` antes de `::ng-deep`.
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid($custom-column-selection-theme);
    }
}
```
