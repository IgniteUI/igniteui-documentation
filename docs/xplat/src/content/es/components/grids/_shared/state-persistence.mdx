## Uso

<PlatformBlock for="Angular">
El método <ApiLink type="GridState" member="getState" /> devuelve el estado de la cuadrícula en una cadena JSON serializada, de modo que los desarrolladores puedan tomarla y guardarla en cualquier almacenamiento de datos (base de datos, nube, localStorage del navegador, etc.). El método acepta como primer parámetro opcional `Serialize`, que determina si <ApiLink type="GridState" member="getState" /> devolverá un objeto <ApiLink type="IGridState" /> o una cadena JSON serializada.

El desarrollador puede optar por obtener solo el estado de una o varias funciones, pasando el nombre de la función o una matriz con nombres de funciones como segundo argumento.
</PlatformBlock>

La API de un único punto, sencilla de usar, permite lograr una persistencia completa del estado con unas pocas líneas de código. **Copie y pegue el código de abajo**: guardará el estado del grid en el objeto `LocalStorage` del navegador cada vez que el usuario abandone la página actual. Cada vez que el usuario vuelva a la página principal, el estado del grid se restaurará. Ya no es necesario configurar cada vez las expresiones complejas de filtrado y ordenación avanzadas para obtener los datos que desea; hágalo una vez y deje que el código de abajo haga el resto para sus usuarios:

<PlatformBlock for="Angular">
```typescript
@ViewChild(IgxGridStateDirective, { static: true })
public state!: IgxGridStateDirective;

public ngOnInit() {
    this.router.events.pipe(take(1)).subscribe((event: NavigationStart) => {
        this.saveGridState();
    });
}

public ngAfterViewInit() {
    this.restoreGridState();
}

public saveGridState() {
    const state = this.state.getState() as string;
    window.sessionStorage.setItem('grid1-state', state);
}

public restoreGridState() {
    const state = window.sessionStorage.getItem('grid1-state');
    this.state.setState(state);
}

```
</PlatformBlock>

<PlatformBlock for="WebComponents">
```typescript
constructor() {
    window.addEventListener("load", () => { this.restoreGridState(); });
    window.addEventListener("beforeunload", () => { this.saveGridState(); });
}

// Using methods that work with IgcGridStateInfo object.
public saveGridState() {
    const state = this.gridState.getState();
    window.localStorage.setItem('grid-state', JSON.stringify(state));
}

public restoreGridState() {
    const state = window.localStorage.getItem('grid-state');
    if (state) {
        this.gridState.applyState(JSON.parse(state));
    }
}

// Or using string alternative methods.
public saveGridStateString() {
    const state = this.gridState.getStateAsString();
    window.localStorage.setItem('grid-state', state);
}

public restoreGridStateString() {
    const state = window.localStorage.getItem('grid-state');
    if (state) {
        this.gridState.applyStateFromString(state);
    }
}
```

</PlatformBlock>

```ts
constructor() {
    var grid = this.grid = document.getElementById('grid') as IgcGridComponent;
    var isActiveCol = this.isActive = document.getElementById('isActive') as IgcColumnComponent;
    this.onColumnInit = this.onColumnInit.bind(this);

    this._bind = () => {
        grid.data = this.data;
        grid.addEventListener("columnInit", this.onColumnInit);
        isActiveCol.bodyTemplate = this.activeTemplate;
```

## Limitaciones

<ComponentBlock for="HierarchicalGrid">
- Al restaurar todas las funciones de la cuadrícula a la vez (usando la API de `applyState` sin parámetros), las propiedades de columna de la cuadrícula raíz podrían restablecerse a sus valores predeterminados. Si esto ocurre, restaure después las columnas o la función de selección de columnas por separado:

```typescript
state.applyState(gridState);
state.applyState(gridState.columns);
state.applyState(gridState.columnSelection);
```
