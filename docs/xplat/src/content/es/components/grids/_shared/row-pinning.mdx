# Anclaje de filas de {Platform} {ComponentTitle}

La función de fijación de filas de {ProductName} en {Platform} {ComponentTitle} le permite fijar una o varias filas en la parte superior o inferior de la cuadrícula. La fijación de filas permite a los usuarios finales fijar filas en un orden determinado, duplicándolas en un área especial que siempre es visible, incluso cuando se desplazan verticalmente por <ApiLink type="{ComponentName}" />. {Platform} {ComponentTitle} tiene una interfaz de fijación de filas integrada, que se habilita inicializando un componente <ApiLink type="ActionStrip" /> en el contexto de {ComponentTitle}. Además, puede definir una interfaz personalizada y cambiar el estado de fijación de las filas mediante la API de fijación de filas.

## API de anclaje de filas

El anclaje de filas se controla mediante la entrada <ApiLink type="RowDirective" member="pinned" /> de `Row`. Las filas ancladas se muestran de forma predeterminada en la parte superior de <ApiLink type="{ComponentName}" /> y permanecen fijas mientras se desplazan verticalmente las filas no ancladas en el cuerpo de <ApiLink type="{ComponentName}" />.

<PlatformBlock for="Angular, WebComponents">
```typescript
this.grid.getRowByIndex(0).pinned = true;
```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
gridRef.current.getRowByIndex(0).pinned = true;
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```csharp
this.Grid.PinRowAsync("ALFKI", 0);
```
</PlatformBlock>

También puede usar los métodos <ApiLink type="{ComponentName}" member="pinRow" label="PinRow" /> o <ApiLink type="{ComponentName}" member="unpinRow" label="UnpinRow" /> de <ApiLink type="{ComponentName}" /> para anclar o desanclar registros por su ID:

<PlatformBlock for="Angular, WebComponents">
```typescript

this.grid.unpinRow('ALFKI');
```
</PlatformBlock>

<PlatformBlock for="React">
```tsx

gridRef.current.unpinRow('ALFKI');
```
</PlatformBlock>
<PlatformBlock for="Blazor">
```csharp

this.Grid.UnpinRowAsync("ALFKI");
```
</PlatformBlock>

Tenga en cuenta que el ID de la fila es el valor de la clave primaria, definido por <ApiLink type="{ComponentName}" member="primaryKey" /> de la cuadrícula, o la propia instancia del registro. Ambos métodos devuelven un valor booleano que indica si su operación respectiva se ha realizado correctamente. Normalmente fallan porque la fila ya está en el estado deseado.

Una fila se ancla debajo de la última fila anclada. Para cambiar el orden de las filas ancladas, puede suscribirse al evento <ApiLink type="{ComponentName}" member="rowPinning" /> y cambiar la propiedad <ApiLink type="PinRowEventArgs" /> de los argumentos del evento a la posición de índice deseada.

## Posición del anclaje

Puede cambiar la posición del anclaje de filas mediante la opción de configuración <ApiLink type="{ComponentName}" member="pinning" />. Permite establecer la posición del área de anclaje en Top o Bottom.
Cuando se establece en Bottom, las filas ancladas se renderizan al final de la cuadrícula, después de las filas no ancladas. Las filas no ancladas pueden desplazarse verticalmente, mientras que las filas ancladas permanecen fijas en la parte inferior.

### Mediante arrastre de filas

Supongamos que quiere poder arrastrar y soltar directamente una fila entre las filas ancladas y las no ancladas para cambiar su estado de anclaje.
Esto puede lograrse habilitando la función de arrastre de filas y anclando o desanclando las filas mediante la API al soltarlas.

En primer lugar, el grid debe marcarse como área de colocación usando la directiva `igxDrop`, y la función de arrastre de filas debe habilitarse mediante la opción `rowDraggable`.

```html
<igx-grid [data]="data" [autoGenerate]="true" [rowDraggable]="true"
    [primaryKey]="'ID'" igxDrop (dropped)="onDropAllowed($event)">
</igx-grid>
```

Después, el evento `dropped` puede usarse para gestionar la lógica de reordenación y de anclar/desanclar.

```typescript
public onDropAllowed(args) {
    const event = args.originalEvent;
    let currRowPinnedIndex;
    const currRowIndex = this.getCurrentRowIndex(this.grid.rowList.toArray(),
        { x: event.clientX, y: event.clientY });
    if (currRowIndex === -1) { return; }

    const currRowID = this.getCurrentRowID(this.grid.rowList.toArray(),
        { x: event.clientX, y: event.clientY });

    const currentRow = this.grid.rowList.toArray().find((r) => r.rowID === currRowID);
    if (currentRow.pinned) {
        currRowPinnedIndex = this.grid.pinnedRows.indexOf(this.grid.pinnedRows.find((r) => r.rowID === currRowID));
    }
    // remove the row that was dragged and place it onto its new location
    this.grid.deleteRow(args.dragData.key);
    this.data.splice(currRowIndex, 0, args.dragData.data);
    if (currentRow.pinned && !args.dragData.pinned) {
        this.grid.pinRow(args.dragData.key, currRowPinnedIndex);
    } else if (!currentRow.pinned && args.dragData.pinned) {
        this.grid.unpinRow(args.dragData.key);
    } else if (currentRow.pinned && args.dragData.pinned) {
        this.grid.unpinRow(args.dragData.key);
        this.grid.pinRow(args.dragData.key, currRowPinnedIndex);
    }
}
```

Esto permitiría reordenar las filas y moverlas entre las colecciones de filas ancladas y no ancladas.

## Limitaciones del anclaje de filas

- Solo pueden anclarse los registros que existen en el origen de datos.
- El estado de anclaje de filas no se exporta a Excel. El grid se exporta como si no se aplicara ningún anclaje de filas.
- Las copias de las filas ancladas en el área desplazable de la cuadrícula forman parte integral de cómo otras funciones de la cuadrícula logran su funcionalidad en presencia de filas ancladas; por tanto, no puede deshabilitarse su creación ni eliminarse.
- Como la selección de filas funciona por completo con los ID de fila, al seleccionar filas ancladas también se seleccionan sus copias (y viceversa). Además, la selección por rango (por ejemplo, usando <kbd>SHIFT</kbd> + clic) dentro del área anclada funciona igual que seleccionar un rango de filas en el área desplazable. La selección resultante incluye todas las filas intermedias, aunque no estén ancladas en ese momento. Al obtener las filas seleccionadas mediante la API, solo se devuelve una instancia de cada registro seleccionado.

<PlatformBlock for="Angular">
- Debido a la forma en que se almacenan internamente las filas ancladas para que puedan aparecer tanto en el área anclada como en la no anclada de la cuadrícula, el anclaje de filas no se admite cuando los registros de la cuadrícula se obtienen bajo demanda desde un punto final remoto (virtualización remota).
- Cuando el grid no tiene <ApiLink type="{ComponentName}" member="primaryKey" /> establecido y los escenarios de datos remotos están habilitados (cuando la paginación, la ordenación, el filtrado o el desplazamiento provocan solicitudes a un servidor remoto para obtener los datos que se mostrarán en el grid), una fila perderá el siguiente estado tras completarse una solicitud de datos:
  - Selección de filas
  - Expandir/contraer filas
  - Edición de filas
  - Anclaje de filas

</PlatformBlock>

A continuación, cree un tema nuevo que extienda <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" /> y acepte los parámetros necesarios para personalizar la función de anclaje de filas como desee.

```scss
$custom-grid-theme: grid-theme(
    /* Pinning properties that affect styling */
    $pinned-border-width: 5px,
    $pinned-border-style: double,
    $pinned-border-color: #FFCD0F,
    $cell-active-border-color: #FFCD0F
    /* add other features properties here... */
);
```

### Uso de variables CSS

El último paso es pasar el tema personalizado de la cuadrícula:

```scss
@include tokens($custom-grid-theme);
```

### Uso de mixins

Para dar estilo a los componentes en Internet Explorer 11 hay que usar un enfoque diferente, ya que no admite variables CSS.

Si el componente usa una [Emulated](../themes/styles.mdx#view-encapsulation) ViewEncapsulation, es necesario `penetrate` esta encapsulación usando `::ng-deep`. Sin embargo, para evitar que el tema personalizado se filtre a otros componentes, asegúrese de incluir el selector `:host` antes de `::ng-deep`:

```scss
:host {
    ::ng-deep {
        // Pass the custom grid theme to the `igx-grid` mixin
        @include grid($custom-grid-theme);
    }
}
```
