</ComponentBlock>

## Uso

Debe habilitar <ApiLink type="{ComponentName}" member="batchEditing" /> en su {ComponentTitle}:

<PlatformBlock for="WebComponents">
```html
<{ComponentSelector} [data]="data" [batchEditing]="true">
</{ComponentSelector}>
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```razor
<{ComponentSelector} Data=data BatchEditing="true">
</{ComponentSelector}>
```
</PlatformBlock>

Esto garantiza que se proporcione una instancia adecuada del servicio `Transaction` para <ApiLink type="{ComponentName}" />. El <ApiLink type="TransactionService" /> adecuado se proporciona a través de un `TransactionFactory`.

<PlatformBlock for="Angular">
Puede conocer más sobre esta implementación interna en el tema [transacciones](../transaction-classes.mdx#transaction-factory).

</PlatformBlock>

Una vez habilitada la edición por lotes, defina un <ApiLink type="{ComponentName}" /> con el origen de datos enlazado, establezca <ApiLink type="{ComponentName}" member="rowEditable" /> en true y enlácelo:

```ts
constructor() {
    var grid = this.grid = document.getElementById('grid') as IgcGridComponent;
    var undo = this.undo = document.getElementById('undo') as HTMLButtonElement;
    var redo = this.redo = document.getElementById('redo') as HTMLButtonElement;
    var commit = this.commit = document.getElementById('commit') as HTMLButtonElement;
}

this._bind = () => {
    grid.data = this.data;
    undo.addEventListener('click', this.OnUndoClick);
    redo.addEventListener('click', this.OnRedoClick);
    commit.addEventListener('click', this.OnCommitClick);
}
this._bind();

private OnCommitClick() {
    if (this.grid.transactions.getAggregatedChanges(false).length > 0)
        this.grid.transactions.commit(this.data);
}

private OnUndoClick() {
    if (this.grid.transactions.canUndo)
        this.grid.transactions.undo();
}

private OnRedoClick() {
    if (this.grid.transactions.canRedo)
        this.grid.transactions.redo();
}
```

```typescript
export class GridBatchEditingSampleComponent {

    public undo() {
        /* exit edit mode and commit changes */
        this.grid.endEdit(true);
        this.grid.transactions.undo();
    }

    public redo() {
        /* exit edit mode and commit changes */
        this.grid.endEdit(true);
        this.grid.transactions.redo()

        this.toggle.close();
```

```typescript
export class HierarchicalGridBatchEditingSampleComponent {
    public undo(grid: IgxHierarchicalGridComponent) {
        /* exit edit mode and commit changes */
```

<DocsAside type="info">
La API de transacciones no gestiona el fin de la edición, así que tendrá que hacerlo usted mismo. De lo contrario, `{ComponentName}` permanecería en modo de edición. Una forma de hacerlo es llamar a `EndEdit` en el método correspondiente.
</DocsAside>

<ComponentBlock for="TreeGrid">
Eliminar un nodo padre en <ApiLink type="{ComponentName}" /> tiene algunas particularidades. Si usa datos jerárquicos, los hijos se eliminarán al eliminar su padre. Si usa datos planos, puede establecer el comportamiento deseado con la propiedad `CascadeOnDelete` de <ApiLink type="{ComponentName}" />. Esta propiedad indica si los registros hijos deben eliminarse cuando se elimina su padre (de forma predeterminada, está establecida en **true**).
</ComponentBlock>

<DocsAside type="info">
Desactivar la propiedad <ApiLink type="{ComponentName}" member="rowEditable" /> hará que `{ComponentName}` cree transacciones al cambiar una celda y no mostrará la superposición de edición de filas en la interfaz.
</DocsAside>
