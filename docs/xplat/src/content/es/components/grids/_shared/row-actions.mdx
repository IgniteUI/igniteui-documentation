# Acciones de fila en {Platform} {ComponentTitle}

La función de acciones de fila de {ProductName} en {Platform} {ComponentTitle} permite a los desarrolladores usar un <ApiLink type="ActionStrip" /> y utilizar CRUD para componentes de fila/celda y para el anclaje de filas. Hay varios controles de interfaz predefinidos para estas operaciones, aplicables a una fila específica de <ApiLink type="{ComponentName}" />: edición y anclaje.

## Uso

<PlatformBlock for="Angular">
El primer paso es importar **IgxActionStripModule** en nuestro archivo **app.module.ts**:

```typescript
// app.module.ts
import { IgxActionStripModule } from 'igniteui-angular';

@NgModule({
    imports: [..., IgxActionStripModule],
})
```

</PlatformBlock>

Los componentes de interfaz de acciones predefinidos son:

- <ApiLink type="GridEditingActions" />: incluye funciones e interfaz diseñadas específicamente para la edición de <ApiLink type="{ComponentName}" />. Permite activar rápidamente el modo de edición de celdas o filas, según la opción <ApiLink type="{ComponentName}" member="rowEditable" /> y la eliminación de filas de <ApiLink type="{ComponentName}" />.

- <ApiLink type="GridPinningActions" />: incluye funciones e interfaz diseñadas específicamente para el anclaje de filas de <ApiLink type="{ComponentName}" />. Permite anclar rápidamente filas y desplazarse entre las filas ancladas y sus contrapartidas deshabilitadas.

Se añaden dentro de <ApiLink type="{ComponentName}" /> y con esto basta para que <ApiLink type="ActionStrip" /> ofrezca interacciones predeterminadas.

<PlatformBlock for="Angular">
```html
<{ComponentSelector} [data]="data" [rowEditable]="true" [primaryKey]="'ID'">
    <igx-column *ngFor="let c of columns" [field]="c.field">
    </igx-column>

    <igx-action-strip #actionStrip>
        <igx-grid-pinning-actions></igx-grid-pinning-actions>
        <igx-grid-editing-actions></igx-grid-editing-actions>
    </igx-action-strip>
</{ComponentSelector}>

```

## Implementación personalizada

Estos componentes exponen plantillas que ofrecen flexibilidad para la personalización. Por ejemplo, si quisiéramos usar <ApiLink type="ActionStrip" /> para un escenario tipo Gmail con acciones de fila como **eliminar**, **editar**, etc., simplemente puede crear un componente de botón con icono, añadirle un evento de clic e insertarlo en <ApiLink type="ActionStrip" />.


<PlatformBlock for="Angular">
```html
<{ComponentSelector}>
    <igx-action-strip #actionstrip>
        <igx-grid-pinning-actions></igx-grid-pinning-actions>
        <button title="Edit" igxButton="icon" igxRipple (click)='startEdit(actionstrip.context)'>
            <igx-icon>edit</igx-icon>
        </button>
        @if (!isDeleted(actionstrip.context)) {
            <button title="Delete" igxButton="icon" igxRipple (click)='actionstrip.context.delete()'>
                <igx-icon>delete</igx-icon>
            </button>
        }
    </igx-action-strip>
</{ComponentSelector}>
```
</PlatformBlock>

<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">
<PlatformBlock for="Blazor">
```razor
<div class="grid__wrapper">
    <{ComponentSelector} Data=northwindEmployees>
        <IgbActionStrip @ref=actionstrip>

            <IgbGridEditingActions
                EditRow="true"
                DeleteRow="true"
                AddRow="true">
            </IgbGridEditingActions>
        </IgbActionStrip>
    </{ComponentSelector}>
</div>
```
</PlatformBlock>
</ComponentBlock>
