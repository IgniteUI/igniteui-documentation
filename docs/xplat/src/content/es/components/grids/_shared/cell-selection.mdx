# Selección de celdas de {Platform} {ComponentTitle}

La selección de celdas de {ProductName} en {Platform} {ComponentTitle} ofrece amplias capacidades de selección de datos y una potente API en el componente <ApiLink type="{ComponentName}" />. {Platform} {ComponentTitle} admite tres modos de selección:

- Selección múltiple de celdas en {ComponentTitle}
- {ComponentTitle} Selección única
- Sin selección en {ComponentTitle}

<ComponentBlock for="HierarchicalGrid">
En <ApiLink type="{ComponentName}" /> puede especificar el modo de selección de celdas a nivel de cuadrícula. Por ejemplo, en la cuadrícula principal puede habilitarse la selección múltiple de celdas, pero en las cuadrículas secundarias el modo de selección de celdas puede ser único o estar deshabilitado.
</ComponentBlock>

Veamos en detalle cada una de estas opciones.

## Tipos de selección

### Selección de varias celdas en {ComponentTitle}

<ComponentBlock for="HierarchicalGrid">
Este es el modo de selección de celdas predeterminado tanto en las cuadrículas principales como en las secundarias. Tenga en cuenta que solo puede hacer la selección de celdas en una cuadrícula cada vez, y no puede hacer selecciones de rango entre cuadrículas ni tener celdas seleccionadas en varias cuadrículas. Cada combinación de teclas relacionada con la selección de rangos y con la función de arrastre con el ratón solo puede usarse dentro de la misma cuadrícula.
</ComponentBlock>

Cómo seleccionar celdas:
- Mediante **arrastre con el ratón**: se realiza una selección rectangular de datos de celdas.
- Mediante la tecla <kbd>CTRL</kbd> + **arrastre con el ratón**: se realizan selecciones de varios rangos. Cualquier otra selección de celdas existente se conserva.
- Selección instantánea de varias celdas con la tecla <kbd>SHIFT</kbd>. Seleccione una celda y después otra celda manteniendo pulsada la tecla <kbd>SHIFT</kbd>. Se seleccionará el rango de celdas entre las dos. Tenga en cuenta que, si se selecciona una segunda celda mientras se mantiene pulsada la tecla <kbd>SHIFT</kbd>, el rango de selección de celdas se actualizará según la posición de la primera celda seleccionada (punto de partida).
- Selección de varias celdas con el teclado usando las teclas de <kbd>flecha</kbd> mientras se mantiene pulsada la tecla <kbd>SHIFT</kbd>. El rango de selección de varias celdas se creará a partir de la celda enfocada.
- Selección de varias celdas con el teclado usando las teclas <kbd>CTRL</kbd> + <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> y <kbd>CTRL</kbd> + <kbd>HOME</kbd>/<kbd>END</kbd> mientras se mantiene pulsada la tecla <kbd>SHIFT</kbd>. El rango de selección de varias celdas se creará a partir de la celda enfocada.
- Al hacer clic con el **botón izquierdo del ratón** mientras se mantiene pulsada la tecla <kbd>CTRL</kbd>, se añadirán rangos de una sola celda a la colección de celdas seleccionadas.
- También está disponible la selección continua de varias celdas, haciendo clic con el ratón y arrastrando.

### {ComponentTitle} Selección única

Cuando establece <ApiLink type="{ComponentName}" member="cellSelection" /> en **single**, solo puede haber una celda seleccionada en la cuadrícula a la vez. Además, el modo **arrastre con el ratón** no funcionará, y en lugar de seleccionar una celda se realizará la selección de texto predeterminada.

> Cuando se selecciona una única celda se emite el evento <ApiLink type="Column" member="selected" />, independientemente de si el **modo de selección** es **single** o **multiple**. En el modo de selección de varias celdas, cuando selecciona un rango de celdas se emite el evento <ApiLink type="{ComponentName}" member="rangeSelected" />.

### Sin selección en {ComponentTitle}

Si quiere deshabilitar la selección de celdas, basta con establecer <ApiLink type="{ComponentName}" member="cellSelection" /> en **none**. En este modo, al hacer clic en una celda o intentar navegar con el teclado, la celda **no se selecciona**; solo se aplica el **estilo de activación**, que se perderá al desplazarse o al hacer clic en otro elemento de la página. La única forma de definir la selección es mediante los métodos de la API que se describen a continuación.

## Interacciones de navegación con el teclado

### Mientras se pulsa la tecla Shift

- <kbd>SHIFT</kbd> + <kbd>↑</kbd> para añadir la celda de arriba a la selección actual.
- <kbd>SHIFT</kbd> + <kbd>↓</kbd> para añadir la celda de abajo a la selección actual.
- <kbd>SHIFT</kbd> + <kbd>←</kbd> para añadir la celda de la izquierda a la selección actual.
- <kbd>SHIFT</kbd> + <kbd>→</kbd> para añadir la celda de la derecha a la selección actual.

### Mientras se pulsan las teclas Ctrl + Shift

- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>↑</kbd> para seleccionar todas las celdas situadas encima de la celda enfocada en la columna.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>↓</kbd> para seleccionar todas las celdas situadas debajo de la celda enfocada en la columna.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>←</kbd> para seleccionar todas las celdas hasta el inicio de la fila.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>→</kbd> para seleccionar todas las celdas hasta el final de la fila.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>HOME</kbd> para seleccionar todas las celdas desde la celda enfocada hasta la primera celda de la cuadrícula
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>END</kbd> para seleccionar todas las celdas desde la celda enfocada hasta la última celda de la cuadrícula

<DocsAside type="info">
El desplazamiento continuo solo es posible dentro del cuerpo del Grid.
</DocsAside>

### Seleccionar un rango

<ApiLink type="{ComponentName}" member="selectRange" />: selecciona un rango de celdas con la API. rowStart y rowEnd deben usar índices de fila, y columnStart y columnEnd pueden usar el índice de columna o el valor del campo de datos de la columna.

### Obtener los datos seleccionados

<PlatformBlock for="Blazor">
<ApiLink type="{ComponentName}" member="getSelectedData" /> devuelve un array de los datos seleccionados en formato Dictionary. Ejemplos a continuación:

```razor
<{ComponentSelector} @ref=grid  CellSelection="GridSelectionMode.Multiple" AutoGenerate=true></<{ComponentSelector}>

@code {
    private {ComponentSelector} grid;

    private async void GetSelectedData()
    {
        object[] data = await this.grid.GetSelectedDataAsync(true, true);
    }
}
```

</PlatformBlock>

<PlatformBlock for="Angular, WebComponents, React">
<ApiLink type="{ComponentName}" member="getSelectedData" /> devuelve un array con los datos seleccionados, en un formato que depende de la selección. Ejemplos a continuación:

- Si se seleccionan tres celdas individuales distintas:

```typescript
expectedData = [
    { CompanyName: 'Infragistics' },
    { Name: 'Michael Langdon' },
    { ParentID: 147 }
];
```

- Si se seleccionan tres celdas de una misma columna:

```typescript
expectedData = [
    { Address: 'Obere Str. 57'},
    { Address: 'Avda. de la Constitución 2222'},
    { Address: 'Mataderos 2312'}
];
```

- Si se seleccionan tres celdas arrastrando el ratón desde una fila y tres columnas:

```typescript
expectedData = [
    { Address: 'Avda. de la Constitución 2222', City: 'México D.F.', ContactTitle: 'Owner' }
];
```

- Si se seleccionan tres celdas arrastrando el ratón desde dos filas y tres columnas:

```typescript
expectedData = [
    { ContactTitle: 'Sales Agent', Address: 'Cerrito 333', City: 'Buenos Aires'},
    { ContactTitle: 'Marketing Manager', Address: 'Sierras de Granada 9993', City: 'México D.F.'}

```

```typescript
expectedData = [
```

```typescript
expectedData = [
```

## Integración de características

La selección de varias celdas se basa en índices (selección de elementos del DOM).

- <ApiLink type="{ComponentName}" member="sortingExpressions" label="Sorting" />: al ordenar, la selección no se borra. Las celdas seleccionadas se mantienen al ordenar de forma ascendente o descendente.
- <ApiLink type="{ComponentName}" member="pagingMode" label="Paging" />: al paginar, las celdas seleccionadas se borran. La selección no se conserva entre páginas.
- <ApiLink type="{ComponentName}" member="allowFiltering" label="Filtering" />: al filtrar, la selección no se borra. Si se borra el filtro, vuelven a aparecer las celdas seleccionadas inicialmente.
- <ApiLink type="Column" member="resizable" label="Resizing" />: al redimensionar columnas, las celdas seleccionadas no se borran.
- <ApiLink type="Column" member="hidden" label="Hiding" />: no borra las celdas seleccionadas. Si la columna se oculta, se seleccionarán las celdas de la siguiente columna visible.
- <ApiLink type="{ComponentName}" member="pinning" />: la celda seleccionada no se borra. Igual que al ocultar.
- <ApiLink type="{ComponentName}" member="groupingExpressions" label="GroupBy" />: al agrupar columnas, las celdas seleccionadas no se borran.

## Pautas de estilo

El motor de temas expone propiedades que nos permiten dar estilo al **rango de celdas seleccionadas**.

### Importar el tema

Para empezar a dar estilo a la selección, debemos importar el archivo `index`, donde viven todas las funciones de tema y los mixins de componentes:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### Definir los colores

Una vez hecho esto, podemos usar las funciones <ApiLink type="function-igx-contrast-color" label="igx-contrast-color" kind="sass" module="index.html" /> y <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />. Con ellas definimos los colores que queremos usar para el rango de selección:

```scss
    $text-color:contrast-color($default-palette, 'primary', 900);
    $background-color: color($default-palette, "primary", 900);
    $border-yellow: #f2c43c;
```

### Crear un tema personalizado

A continuación creamos un tema nuevo que extiende <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" />, pasando nuestras variables `text-color`, `background-color` y `border-yellow` como `$cell-selected-text-color`, `$cell-selected-background` y `$cell-active-border-color`, respectivamente:

```scss
$custom-grid-theme: grid-theme(
    $cell-selected-text-color: $text-color,
    $cell-active-border-color: $border-yellow,
    $cell-selected-background: $background-color
);
```

### Aplicar el tema

Después, solo tenemos que incluir el mixin en el estilo de nuestro componente (también podría estar en los estilos de la aplicación), para que nuestro @@igSelector use el tema recién creado en lugar del predeterminado:

```scss
    @include grid($custom-grid-theme);
```

 <DocsAside type="info">
 Si el componente usa un [ViewEncapsulation Emulated](../themes/styles.mdx#view-encapsulation), es necesario atravesar esa encapsulación con `::ng-deep`.
 Acotamos el estilo bajo el selector `:host` para no afectar a otras cuadrículas que pueda tener en la aplicación.
 </DocsAside>

 ```scss
    :host {
        ::ng-deep {
            @include grid($custom-grid-theme);
        }
    }
```


Con el tema personalizado aplicado, las celdas seleccionadas de la cuadrícula se resaltan con nuestros colores de selección:
