# Filtrado de Excel en {Platform} {ComponentTitle}

El {Platform} {ComponentTitle} expone una función de filtrado al estilo de Excel que proporciona una interfaz de filtrado similar a la de Excel. Simplifica el trabajo con conjuntos de datos grandes. La idea principal es ayudar al usuario a filtrar los datos más relevantes, eliminando las entradas irrelevantes.

## Uso

Para activar el filtrado al estilo de Excel del componente <ApiLink type="{ComponentName}" />, hay que establecer dos entradas. La propiedad <ApiLink type="{ComponentName}" member="allowFiltering" /> debe establecerse en **true** y la propiedad <ApiLink type="{ComponentName}" member="filterMode" /> debe establecerse en el valor `ExcelStyleFilter`.

## Interacciones

Para abrir el menú de filtro de una columna concreta, haga clic en el icono de filtro {Platform} del encabezado. Además, puede usar la combinación <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>L</kbd> sobre un encabezado seleccionado. Si la columna puede ordenarse, fijarse, moverse, seleccionarse u ocultarse junto con la función de filtrado, aparecerán botones para las funciones que estén activadas.

Si no se aplica ningún filtro, se seleccionarán todos los elementos de la lista. Pueden filtrarse desde el campo de entrada situado encima de la lista. Para filtrar los datos, puede seleccionar o deseleccionar los elementos de la lista y, a continuación, hacer clic en el botón Apply o pulsar <kbd>ENTER</kbd>. El filtrado aplicado mediante los elementos de la lista crea expresiones de filtro con el operador `equals`, y el operador lógico entre las expresiones es `OR`.

Si escribe algo en el cuadro de búsqueda y aplica el filtro, solo se seleccionarán los elementos que coincidan con los criterios de búsqueda. Sin embargo, si desea añadir elementos a los que ya están filtrados, debe seleccionar la opción **Add current selection to filter**.

Si desea borrar el filtro, puede marcar la opción **Select All** y, a continuación, hacer clic en el botón Apply.

Para aplicar un filtro con distintas expresiones, puede hacer clic en **Filtro de texto**, que abrirá un submenú con todos los operadores de filtro disponibles para la columna concreta. Al seleccionar uno de ellos se abrirá el cuadro de diálogo de filtro personalizado, donde puede añadir todas las expresiones que quiera con distintos operadores de filtro y lógicos. También hay un botón de borrar, que puede eliminar el filtro.

## Plantillas

<PlatformBlock for="Angular">
Si quiere personalizar aún más el menú de filtro al estilo de Excel sin deshabilitar las funciones de las columnas, puede usar plantillas personalizadas. El menú de filtro al estilo de Excel proporciona dos directivas para crear plantillas:
- `IgxExcelStyleColumnOperationsTemplateDirective`: vuelve a crear la plantilla del área con todas las operaciones de columna, como ordenar, anclar, etc.
- `IgxExcelStyleFilterOperationsTemplateDirective`: vuelve a crear la plantilla del área con todas las operaciones específicas del filtro.

Puede volver a crear la plantilla de solo una de esas áreas o de ambas. Puede poner cualquier contenido personalizado dentro de esas directivas, o usar cualquiera de nuestros componentes integrados de filtrado al estilo de Excel.

El código siguiente muestra cómo definir un menú de filtro personalizado al estilo de Excel usando los componentes `excel-style-header`, `excel-style-sorting` y `excel-style-search`.

</PlatformBlock>

<PlatformBlock for="WebComponents, Blazor, React">
Si desea personalizar aún más el menú de filtro al estilo de Excel, puede usar la propiedad <ApiLink type="{ComponentName}" member="excelStyleHeaderIconTemplate" /> para definir una plantilla personalizada para el icono del encabezado del menú.

El código siguiente muestra cómo personalizar el menú de filtro al estilo de Excel mediante <ApiLink type="{ComponentName}" member="excelStyleHeaderIconTemplate" />:

## Salida externa

El [z-index](https://developer.mozilla.org/en-US/docs/Web/CSS/z-index) de {ComponentTitle} crea un contexto de apilamiento independiente para cada cuadrícula del DOM. Esto garantiza que todos los elementos descendientes de la cuadrícula se muestren como se espera, sin superponerse entre sí.
Sin embargo, los elementos que salen de la cuadrícula (por ejemplo, el filtro al estilo de Excel) entrarán en conflicto con los elementos externos que tengan el mismo `z-index` (por ejemplo, dos cuadrículas una debajo de otra), lo que provocará un renderizado incorrecto. La solución para este problema es establecer la propiedad `Outlet` en una directiva de salida externa, que permite que los elementos superpuestos aparezcan siempre encima.

## Estilos

Para empezar a dar estilo al cuadro de diálogo de filtrado al estilo de Excel, debemos importar el archivo `index`, donde viven todas las funciones de tema y los mixins de componentes:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

El cuadro de diálogo de filtrado al estilo de Excel toma su color de fondo del tema de la cuadrícula, mediante el parámetro `filtering-row-background`. Para cambiar el fondo, debemos crear un tema personalizado:

```scss
$custom-grid: grid-theme(
    $filtering-row-background: #FFCD0F
);
```

Evidentemente, el cuadro de diálogo de filtrado al estilo de Excel contiene muchos más componentes, como botones, casillas de verificación, una lista e incluso un desplegable. Para darles estilo, debemos crear un tema independiente para cada uno:

```scss
$dark-button: flat-button-theme(
    $background: #FFCD0F,
    $foreground: #292826,
    $hover-background: #292826,
    $hover-foreground: #FFCD0F
);

$dark-input-group: input-group-theme(
    $box-background: #FFCD0F,
    $idle-text-color: #292826,
    $focused-text-color: #292826,
    $filled-text-color: #292826
);

$custom-list: list-theme(
    $background: #FFCD0F
);

$custom-checkbox: checkbox-theme(
    $empty-color: #292826,
    $fill-color: #292826,
    $tick-color: #FFCD0F,
    $label-color: #292826
);

$custom-drop-down: drop-down-theme(
    $background-color: #FFCD0F,
    $item-text-color: #292826,
    $hover-item-background: #292826,
    $hover-item-text-color: #FFCD0F
);
```

En este ejemplo solo hemos cambiado algunos parámetros de los componentes indicados, pero los temas <ApiLink type="function-flat-button-theme" label="flat-button-theme" kind="sass" module="index.html" />, <ApiLink type="function-checkbox-theme" label="checkbox-theme" kind="sass" module="index.html" />, <ApiLink type="function-drop-down-theme" label="drop-down-theme" kind="sass" module="index.html" />, <ApiLink type="function-input-group-theme" label="input-group-theme" kind="sass" module="index.html" /> y <ApiLink type="function-list-theme" label="list-theme" kind="sass" module="index.html" /> ofrecen muchos más parámetros para controlar sus respectivos estilos.

El último paso es **incluir** los mixins de componentes, cada uno con su tema correspondiente. También estableceremos la propiedad color para el marcador de posición de la entrada.

```scss
@include drop-down($custom-drop-down);
@include grid($custom-grid);
.igx-excel-filter, .igx-excel-filter__secondary {
    @include button($dark-button);
    @include input-group($dark-input-group);
    @include list($custom-list);
    @include checkbox($custom-checkbox);
    .igx-input-group__input::placeholder {
        color: #FFCD0F;
    }
}
```

<DocsAside type="info">
Limitamos la mayoría de los mixins de componentes dentro de `.igx-excel-filter` y `.igx-excel-filter__secondary`, de modo que estos temas personalizados solo afecten a los componentes anidados en el cuadro de diálogo de filtrado al estilo de Excel y en todos sus subcuadros de diálogo. De lo contrario, otros botones, casillas de verificación, grupos de entrada y listas también se verían afectados.
</DocsAside>

<DocsAside type="info">
Si el componente usa un ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), es necesario `penetrate` esa encapsulación usando `::ng-deep`:
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include drop-down($custom-drop-down);
        @include grid($custom-grid);
        .igx-excel-filter, .igx-excel-filter__secondary {
            @include button($dark-button);
            @include input-group($dark-input-group);
            @include list($custom-list);
            @include checkbox($custom-checkbox);
            .igx-input-group__input::placeholder {
                color: #FFCD0F;
            }
        }
    }
}
```

### Definir una paleta de colores

En lugar de codificar los valores de color como acabamos de hacer, podemos conseguir más flexibilidad en cuanto a colores usando las funciones <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" /> y <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />.

`igx-palette` genera una paleta de colores basada en los colores primario y secundario que se le pasan:

```scss
$yellow-color: #FFCD0F;
$black-color: #292826;

$dark-palette: palette($primary: $black-color, $secondary: $yellow-color);
```

Y después, con <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />, podemos obtener fácilmente un color de la paleta.

```scss
$custom-grid: grid-theme(
    $filtering-row-background: #FFCD0F
);

$dark-button: flat-button-theme(
    $background: color($dark-palette, "secondary", 400),
    $foreground: color($dark-palette, "primary", 400),
    $hover-background: color($dark-palette, "primary", 400),
    $hover-foreground: color($dark-palette, "secondary", 400)
);

$dark-input-group: input-group-theme(
    $box-background: color($dark-palette, "secondary", 400),
    $idle-text-color: color($dark-palette, "primary", 400),
    $focused-text-color: color($dark-palette, "primary", 400),
    $filled-text-color: color($dark-palette, "primary", 400)
);

$custom-list: list-theme(
    $background: color($dark-palette, "secondary", 400)
);

$custom-checkbox: checkbox-theme(
    $empty-color: color($dark-palette, "primary", 400),
    $fill-color: color($dark-palette, "primary", 400),
    $tick-color: color($dark-palette, "secondary", 400),
    $label-color: color($dark-palette, "primary", 400)
);

$custom-drop-down:drop-down-theme(
    $background-color: color($dark-palette, "secondary", 400),
    $item-text-color: color($dark-palette, "primary", 400),
    $hover-item-background: color($dark-palette, "primary", 400),
    $hover-item-text-color: color($dark-palette, "secondary", 400)
);
```

<DocsAside type="info">
`igx-color` y `igx-palette` son funciones potentes para generar y obtener colores. Consulte el tema [Paletas](../themes/sass/palettes.mdx) para una guía detallada sobre cómo usarlas.
</DocsAside>

### Usar esquemas

Para avanzar con el motor de temas, puede crear una estructura sólida y flexible que se beneficie de [**esquemas**](../themes/sass/schemas.mdx). Un **esquema** es una receta de un tema.

Extienda uno de los dos esquemas predefinidos que se proporcionan para cada componente, en este caso, los esquemas <ApiLink type="variable-_light-grid" label="light-grid" kind="sass" module="index.html" />, <ApiLink type="variable-_light-input-group" label="light-input-group" kind="sass" module="index.html" />, <ApiLink type="variable-_light-button" label="light-button" kind="sass" module="index.html" />, <ApiLink type="variable-_light-list" label="light-list" kind="sass" module="index.html" />, <ApiLink type="variable-_light-checkbox" label="light-checkbox" kind="sass" module="index.html" /> y <ApiLink type="variable-_light-drop-down" label="light-drop-down" kind="sass" module="index.html" />:

```scss
$custom-grid-schema: extend($_light-grid,
    (
        filtering-row-background:(
           color: ("secondary", 400)
        )
    )
);

$custom-button-schema: extend($_light-button,
    (
        flat-background:(
           color: ("secondary", 400)
        ),
        flat-text-color:(
           color: ("primary", 400)
        ),
        flat-hover-background:(
           color: ("primary", 400)
        ),
        flat-hover-text-color:(
           color: ("secondary", 400)
        ),

        raised-background:(
           color: ("secondary", 400)
        ),
        raised-text-color:(
           color: ("primary", 400)
        ),
        raised-hover-background:(
           color: ("primary", 400)
        ),
        raised-hover-text-color:(
           color: ("secondary", 400)
        )
    )
);

$custom-input-group-schema: extend($_light-input-group,
    (
        box-background:(
           color: ("secondary", 400)
        ),
        idle-text-color:(
           color: ("primary", 400)
        ),
        focused-text-color:(
           color: ("primary", 400)

           color: ("primary", 400)

$custom-list-schema: extend($_light-list,
    (
        background:(
           color: ("secondary", 400)
        )
    )
);

$custom-checkbox-schema: extend($_light-checkbox,

           color: ("primary", 400)
        ),

           color: ("primary", 400)
        ),
```

Para aplicar nuestros esquemas personalizados, debemos **extender** uno de los globales (<ApiLink type="variable-light-schema" label="light" kind="sass" module="index.html" /> o <ApiLink type="variable-dark-schema" label="dark" kind="sass" module="index.html" />), lo que básicamente señala los componentes con un esquema personalizado, y después añadirlo a los temas de cada componente:

```scss
$custom-light-schema: extend($light-schema,(
   grid: $custom-grid-schema,
   button: $custom-button-schema,
   input-group: $custom-input-group-schema,
   list: $custom-list-schema,
   checkbox: $custom-checkbox-schema,
   drop-down: $custom-drop-down-schema
));

$custom-grid: grid-theme(
    $schema: $custom-light-schema
);

$custom-button: flat-button-theme(
    $schema: $custom-light-schema
);

$custom-input-group: input-group-theme(
    $schema: $custom-light-schema
);

$custom-list: list-theme(
    $schema: $custom-light-schema
);

$custom-checkbox: checkbox-theme(
    $schema: $custom-light-schema
);

$custom-drop-down: drop-down-theme(
    $schema: $custom-light-schema
);
```
