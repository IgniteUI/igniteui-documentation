# Navegación por teclado de {Platform} {ComponentTitle}

 La función de navegación por teclado de {ProductName} en {Platform} {ComponentTitle} proporciona una amplia variedad de interacciones por teclado para el usuario. Mejora la accesibilidad de <ApiLink type="{ComponentName}" /> y permite al usuario desplazarse por cualquier tipo de elemento que contenga (celda, fila, encabezado de columna, barra de herramientas, pie de página, etc.). Esta función está habilitada de forma predeterminada, y el desarrollador tiene la opción de sustituir cualquiera de los comportamientos predeterminados de forma sencilla.

Se ha reducido el número de paradas de tabulación de <ApiLink type="{ComponentName}" />, de modo que la navegación cumpla los estándares de accesibilidad del W3C y sea cómoda de usar.

Actualmente, <ApiLink type="{ComponentName}" /> introduce las siguientes paradas de tabulación:

- **Área de GroupBy o de la barra de herramientas** (si está habilitada).
- **Encabezado de {ComponentTitle}**.
- **Cuerpo de {ComponentTitle}**.
- **Resúmenes de columna** (si están habilitados).
- **Paginador de {ComponentTitle}** (si está habilitado).


<DocsAside type="info">
Debido a este cambio, ya no se admite la navegación entre celdas con <kbd>TAB</kbd> y <kbd>SHIFT</kbd> + <kbd>TAB</kbd> en <ApiLink type="{ComponentName}" />.
Al pulsar la tecla <kbd>TAB</kbd>, ahora se recorren los puntos de tabulación en este orden: **GroupBy** / **Toolbar** -> **Headers** -> **Body** -> **Summaries** -> **Footer / Paginator**.
</DocsAside>

<DocsAside type="info">
Exponer cualquier elemento **enfocable** en el cuerpo de <ApiLink type="{ComponentName}" /> mediante una plantilla puede introducir **efectos secundarios** en la navegación por teclado, ya que no se impide el comportamiento predeterminado del navegador.
Es responsabilidad del desarrollador impedirlo o modificarlo adecuadamente.
</DocsAside>

## Navegación por encabezados

Ahora se incorpora un soporte completo de **navegación por teclado** en el encabezado de <ApiLink type="{ComponentName}" />. Los encabezados de columna pueden recorrerse fácilmente con las teclas de flecha. Además, hay varias combinaciones de teclas que activan acciones sobre las columnas, como **filtrado**, **ordenación**, **agrupación** y demás.
Cuando el contenedor del encabezado de <ApiLink type="{ComponentName}" /> tiene el foco, están disponibles las siguientes combinaciones de teclas:

### Combinaciones de teclas

- <kbd>↑</kbd> se desplaza una celda hacia arriba en los encabezados (sin bucle). Solo disponible cuando se definen Multi-row Layout (MRL) o Multi-column Headers (MCH).
- <kbd>↓</kbd> se desplaza una celda hacia abajo en los encabezados (sin ajuste). Solo disponible cuando se definen Multi-row Layout (MRL) o Multi-column Headers (MCH).
- <kbd>←</kbd> se desplaza una celda a la izquierda (sin bucle).
- <kbd>→</kbd> se desplaza una celda a la derecha (sin ajuste entre líneas).
- <kbd>CTRL</kbd> + <kbd>←</kbd> se desplaza a la celda más a la izquierda de la fila; si MRL o MCH están habilitados, se desplaza a la celda más a la izquierda del mismo nivel.
- <kbd>HOME</kbd> se desplaza a la celda más a la izquierda de la fila; si MRL o MCH están habilitados, se desplaza a la celda más a la izquierda del mismo nivel.
- <kbd>CTRL</kbd> + <kbd>→</kbd> se desplaza a la celda más a la derecha de la fila; si MRL o MCH están habilitados, se desplaza a la celda más a la derecha del mismo nivel.
- <kbd>END</kbd> se desplaza a la celda más a la derecha de la fila; si MRL o MCH están habilitados, se desplaza a la celda más a la derecha del mismo nivel.
- <kbd>ALT</kbd> + <kbd>L</kbd> abre el cuadro de diálogo de filtrado avanzado si el filtrado avanzado está habilitado.
- <kbd>CTRL</kbd> + <kbd>SHIFT</kbd> + <kbd>L</kbd> abre el cuadro de diálogo de filtro al estilo de Excel o el filtro predeterminado (de fila) si la columna es filtrable.
- <kbd>CTRL</kbd> + <kbd>↑</kbd> ordena el encabezado de columna activo en orden ASC. Si la columna ya está ordenada en ASC, se borra el estado de ordenación.
- <kbd>CTRL</kbd> + <kbd>↓</kbd> ordena el encabezado de columna activo en orden DSC. Si la columna ya está ordenada en DSC, se borra el estado de ordenación.
- <kbd>SPACE</kbd> selecciona la columna. Si la columna ya está seleccionada, se borra la selección.
<ComponentBlock for="Grid">
- <kbd>SHIFT</kbd> + <kbd>ALT</kbd> + <kbd>←</kbd> agrupa la columna, si está marcada como agrupable.
</ComponentBlock>
- <kbd>SHIFT</kbd> + <kbd>ALT</kbd> + <kbd>→</kbd> desagrupa la columna, si está marcada como agrupable.
- <kbd>ALT</kbd> + <kbd>←</kbd> o <kbd>ALT</kbd> + <kbd>↑</kbd> contrae el encabezado del grupo de columnas, si el encabezado no está ya contraído.
- <kbd>ALT</kbd> + <kbd>→</kbd> o <kbd>ALT</kbd> + <kbd>↓</kbd> expande el encabezado del grupo de columnas, si el encabezado no está ya expandido.

## Navegación por teclado personalizada

Sustituir el comportamiento predeterminado de una tecla o de una combinación de teclas es una de las ventajas que ofrece la función de **navegación por teclado**. Por ejemplo: pulsar la tecla <kbd>ENTER</kbd> o <kbd>TAB</kbd> para desplazarse a la siguiente celda o a la celda de abajo. Este escenario o cualquier otro de navegación se logra fácilmente con la API de **navegación por teclado**:

Para cualquier otra pulsación o combinación de teclas, use el evento predeterminado `onkeydown`. | <ApiLink type="GridKeydownEventArgs" /> |
| <ApiLink type="{ComponentName}" member="activeNodeChange" /> | Un evento que se emite cuando cambia el nodo activo. Puede usarse para determinar la posición de foco activa (encabezado, tbody, etc.), el índice de columna, el índice de fila o el nivel anidado. | <ApiLink type="ActiveNodeChangeEventArgs" /> |
</PlatformBlock>
