# Filtrado avanzado de {Platform} {ComponentTitle}

El filtrado avanzado de {ProductName} en {Platform} {ComponentTitle} le permite manipular datos mediante un cuadro de diálogo en el que puede crear distintos grupos con condiciones de filtrado en todas las columnas de <ApiLink type="{ComponentName}" />.

## Ejemplo de filtrado avanzado de {Platform} {ComponentTitle}

<Sample src="/{ComponentSample}/advanced-filtering-options" height={530} alt="Ejemplo de filtrado avanzado de {Platform} {ComponentTitle}" />

## Interacción

Para abrir el cuadro de diálogo de filtrado avanzado, haga clic en el botón **Advanced Filtering** de la barra de herramientas de la cuadrícula. Si no hay ningún filtro avanzado aplicado, empiece por crear un grupo de condiciones de filtrado unidas con **AND** u **OR**. Después, puede añadir condiciones de filtrado o subgrupos.

Para añadir una condición de filtrado, debe seleccionar cualquiera de las columnas <ApiLink type="Column" member="filterable" />, un operando basado en el tipo de datos <ApiLink type="Column" member="dataType" /> de la columna y un valor si el operando no es unario. Una vez confirmada la condición, aparece un chip con la información de la condición. Al pasar el cursor o al hacer clic en el chip, tiene opciones para modificarlo o añadir otra condición o grupo justo después.

Si selecciona más de un chip de condición de filtrado, aparece un menú contextual con opciones para crear un grupo o eliminar los filtros. Si elige crear un grupo con las condiciones seleccionadas, el grupo nuevo aparecerá donde estaba la condición seleccionada más arriba.

Para seleccionar un grupo, también puede hacer clic en su línea vertical, que se colorea según la condición de unión **AND** u **OR**. Si se selecciona un único grupo, aparece un menú contextual con opciones para cambiar su lógica de filtrado, desagruparlo o eliminarlo.

Para filtrar los datos cuando haya terminado de crear las condiciones y los grupos de filtrado, haga clic en el botón **Aplicar**. Si ha modificado el filtro avanzado, pero no quiere conservar los cambios, haga clic en el botón **Cancelar**. También puede borrar el filtro avanzado haciendo clic en el botón **Borrar filtro**.

El filtrado avanzado genera un <ApiLink type="{ComponentName}" member="filteringExpressionsTree" />, que se almacena en la propiedad de entrada <ApiLink type="{ComponentName}" member="advancedFilteringExpressionsTree" />. Puede usar la propiedad <ApiLink type="{ComponentName}" member="advancedFilteringExpressionsTree" /> para establecer un estado inicial del filtrado avanzado.

<PlatformBlock for="Angular">
```typescript
ngAfterViewInit(): void {
    const tree = new FilteringExpressionsTree(FilteringLogic.And);
    tree.filteringOperands.push({
        fieldName: 'ID',
        condition: IgxStringFilteringOperand.instance().condition('contains'),
        searchVal: 'a',
        ignoreCase: true
    });
    const subTree = new FilteringExpressionsTree(FilteringLogic.Or);
    subTree.filteringOperands.push({
        fieldName: 'ContactTitle',
        condition: IgxStringFilteringOperand.instance().condition('doesNotContain'),
        searchVal: 'b',
        ignoreCase: true
    });
    subTree.filteringOperands.push({
        fieldName: 'CompanyName',
        condition: IgxStringFilteringOperand.instance().condition('startsWith'),
        searchVal: 'c',
        ignoreCase: true
    });
    tree.filteringOperands.push(subTree);

    this.@@igObjectRef.advancedFilteringExpressionsTree = tree;
}

```

</PlatformBlock>

## Filtrado avanzado externo

Como se ve en la demostración anterior, el cuadro de diálogo de filtrado avanzado se aloja en una superposición encima de <ApiLink type="{ComponentName}" />. Cuando la configuración del cuadro de diálogo está lista, las acciones de aplicar o cerrar ocultan ese cuadro. Hay una forma de mantenerlo visible: usarlo como componente independiente. En la demostración siguiente, el cuadro de diálogo de filtrado avanzado se declara por separado de <ApiLink type="{ComponentName}" />.

## Estilos

Para empezar a dar estilo al cuadro de diálogo de filtrado avanzado, debemos importar el archivo **index**, donde viven todas las funciones de tema y los mixins de componentes:

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

El cuadro de diálogo de filtrado avanzado toma su color de fondo del tema de la cuadrícula, usando el parámetro **filtering-row-background**. Para cambiar el fondo, debemos crear un tema personalizado:

```scss
$custom-grid: grid-theme(
    $filtering-row-background: #FFCD0F
);
```

Como dentro del cuadro de diálogo de filtrado avanzado hay otros componentes, como botones, chips, desplegables y campos de entrada, necesitamos crear un tema independiente para cada uno:

```scss
$custom-button: flat-button-theme(
    $disabled-foreground: gray,

);

$custom-button-group: button-group-theme(
    $item-background:  #292826,

);

$custom-input-group: input-group-theme(
    $box-background: #4a4a4a,

);

$custom-chip: chip-theme(
    $background: #FFCD0F,

);

$custom-drop-down: drop-down-theme(
    $background-color: #292826,

);
```

En este ejemplo solo hemos cambiado algunos parámetros de los componentes indicados, pero los temas <ApiLink type="function-flat-button-theme" label="flat-button-theme" kind="sass" module="index.html" />, <ApiLink type="function-button-group-theme" label="button-group-theme" kind="sass" module="index.html" />, <ApiLink type="function-chip-theme" label="chip-theme" kind="sass" module="index.html" />, <ApiLink type="function-drop-down-theme" label="drop-down-theme" kind="sass" module="index.html" /> y <ApiLink type="function-input-group-theme" label="input-group-theme" kind="sass" module="index.html" /> ofrecen muchos más parámetros para controlar sus respectivos estilos.

El último paso es **incluir** los mixins de los componentes, cada uno con su tema correspondiente. También añadiremos algunos estilos para otros elementos dentro del cuadro de diálogo de filtrado avanzado.

```scss
@include grid($custom-grid);
igx-advanced-filtering-dialog {
    @include button($custom-button);
    @include button-group($custom-button-group);
    @include input-group($custom-input-group);
    @include chip($custom-chip);
    @include drop-down($custom-drop-down);
    .igx-filter-empty__title {
        color: #FFCD0F
    }
    .igx-advanced-filter__header {
        color: #FFCD0F
    }
    .igx-filter-tree__expression-actions igx-icon {
        color: #FFCD0F
    }
    .igx-filter-tree__expression-actions igx-icon:hover {
        color: #ffe482
    }
    .igx-filter-tree__expression-actions igx-icon:focus {
        color: #ffe482
    }
    .igx-filter-contextual-menu {
        border: 1px solid #FFCD0F
    }
    .igx-filter-contextual-menu__close-btn {
        position: absolute !important;
        background: #292826 !important;
        border-color: #FFCD0F !important;
    }
    .igx-input-group__input::placeholder {
        color: gray;
    }
}
```

<DocsAside type="info">
Limitamos la mayoría de los mixins de los componentes a `igx-advanced-filtering-dialog`, de modo que estos temas personalizados solo afecten a los componentes anidados en el cuadro de diálogo de filtrado avanzado. En caso contrario, otros botones, chips, campos de entrada y desplegables de la aplicación también se verían afectados.
</DocsAside>

### Definir una paleta de colores

En lugar de codificar los valores de color como acabamos de hacer, podemos conseguir más flexibilidad en cuanto a colores usando las funciones <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" /> y <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />.

`igx-palette` genera una paleta de colores basada en los colores primario y secundario que se le pasan:

```scss
$yellow-color: #FFCD0F;
$black-color: #292826;
$dark-palette: palette($primary: $yellow-color, $secondary: $black-color);
```

Y después, con <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />, podemos obtener fácilmente un color de la paleta.

```scss
$custom-grid: grid-theme(
    $filtering-row-background: color($dark-palette, "secondary", 400)
);

$custom-button: flat-button-theme(
    $disabled-foreground: color($dark-palette, "secondary", 100),

);

$custom-button-group: button-group-theme(
    $item-background: color($dark-palette, "secondary", 400),

);

$custom-input-group: input-group-theme(
    $box-background: color($dark-palette, "secondary", 200),

);

$custom-chip: chip-theme(
    $background: color($dark-palette, "primary", 400),

);

$custom-drop-down: drop-down-theme(
    $background-color: color($dark-palette, "secondary", 400),

);
```

<DocsAside type="info">
`igx-color` y `igx-palette` son funciones potentes para generar y obtener colores. Consulte el tema [Paletas](../themes/sass/palettes.mdx) para una guía detallada sobre cómo usarlas.
</DocsAside>

### Usar esquemas

Para avanzar con el motor de temas, puede crear una estructura sólida y flexible que se beneficie de [**esquemas**](../themes/sass/schemas.mdx). Un **esquema** es una receta de un tema.

Extienda uno de los dos esquemas predefinidos que se proporcionan para cada componente, en este caso, los esquemas <ApiLink type="variable-_light-grid" label="light-grid" kind="sass" module="index.html" />, <ApiLink type="variable-_light-button" label="light-button" kind="sass" module="index.html" />, <ApiLink type="variable-_light-button-group" label="light-button-group" kind="sass" module="index.html" />, <ApiLink type="variable-_light-chip" label="light-chip" kind="sass" module="index.html" />, <ApiLink type="variable-_light-input-group" label="light-input-group" kind="sass" module="index.html" /> y <ApiLink type="variable-_light-drop-down" label="light-drop-down" kind="sass" module="index.html" />:

```scss
$grid-dark-palette: palette($primary: #11bd7b, $secondary: #e32057, $info: $black-color);

$custom-grid-schema: extend($_light-grid,
    (
        filtering-row-background:(
           color: ("info")
        )
    )
);

$custom-button-schema: extend($_light-button,
    (
        disabled-color:(
           color: ("secondary", 100)
        ),

    )
);

$custom-button-group-schema: extend($_light-button-group,
    (
        item-background:(
           color: ("secondary", 400)
        ),

    )
);

$custom-input-group-schema: extend($_light-input-group,
    (
        box-background:(
           color: ("secondary", 200)
        ),

    )
);

$custom-chip-schema: extend($_light-chip,
    (
        background:(
           color: ("primary", 400)
        ),

    )
);

$custom-drop-down-schema: extend($_light-drop-down,
    (
        background-color:(
           color: ("secondary", 400)
        ),

    )
);
```

Para aplicar nuestros esquemas personalizados, debemos **extender** uno de los globales (<ApiLink type="variable-light-schema" label="light" kind="sass" module="index.html" /> o <ApiLink type="variable-dark-schema" label="dark" kind="sass" module="index.html" />), lo que básicamente señala los componentes con un esquema personalizado, y después añadirlo a los temas de cada componente:

```scss
$custom-light-schema: extend($light-schema,(
    igx-grid: $custom-grid-schema,
    igx-button: $custom-button-schema,
    igx-button-group: $custom-button-group-schema,
    igx-input-group: $custom-input-group-schema,
    igx-chip: $custom-chip-schema,
    igx-drop-down: $custom-drop-down-schema
));

$custom-grid: grid-theme(
    $schema: $custom-light-schema
);

$custom-button: flat-button-theme(
    $schema: $custom-light-schema
);

$custom-button-group: button-group-theme(
    $schema: $custom-light-schema
);

$custom-input-group: input-group-theme(
    $schema: $custom-light-schema
);

$custom-chip: chip-theme(
    $schema: $custom-light-schema
);

$custom-drop-down: drop-down-theme(
    $schema: $custom-light-schema
);
```

No olvide incluir los temas de la misma forma que se ha mostrado anteriormente.
