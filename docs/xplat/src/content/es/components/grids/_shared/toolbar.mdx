# Barra de herramientas de {Platform} {ComponentTitle}

La barra de herramientas {ProductName} en es un contenedor para las operaciones de interfaz de {Platform} {ComponentTitle}. La barra de herramientas {Platform} se encuentra en la parte superior del componente {Platform}, es decir, <ApiLink type="{ComponentName}" />, y coincide con su tamaño horizontal. El contenedor de la barra de herramientas puede alojar cualquier contenido personalizado o un conjunto de controles de interfaz predefinidos. El conjunto predeterminado para {Platform} {ComponentTitle} incluye:

- Ocultación de columnas
- Anclaje de columnas
- Exportación a Excel
- Filtrado avanzado

La barra de herramientas y los componentes de interfaz predefinidos admiten eventos {Platform} y exponen una API para los desarrolladores.

## Barra de herramientas con cuadrículas secundarias

<PlatformBlock for="Angular">
Debido a ciertas limitaciones en la forma en que se implementan las cuadrículas secundarias de un IgxHierarchicalGrid y en cómo funciona el ámbito de DI, existe una advertencia al
usar la barra de herramientas en el ámbito de las cuadrículas secundarias. Al definir un componente de barra de herramientas dentro de las etiquetas `igx-row-island`, asegúrese siempre de usar IgxGridToolbar y de pasar la instancia de cuadrícula proporcionada como propiedad de entrada a la propia barra de herramientas.
De este modo, siempre tendrá la instancia de cuadrícula correcta en el ámbito de su plantilla:

```html
<igx-hierarchical-grid>
    <!--...-->
    <igx-row-island>
        <!--
            You can name the binding from igxGridToolbar however you want. Just make sure to use
            it inside the template if you need to access the grid instance.
        -->
        <igx-grid-toolbar [grid]="gridRef" *igxGridToolbar="let gridRef">
            <igx-grid-toolbar-title>Child toolbar {{ gridRef.parentIsland.level }}</igx-grid-toolbar-title>
        </igx-grid-toolbar>
    </igx-row-island>
    <!--...-->
</igx-hierarchical-grid>
```

</PlatformBlock>

<PlatformBlock for="WebComponents, React">
Debido a ciertas limitaciones en la forma en que se implementan las cuadrículas secundarias de un `{ComponentSelector}` y en cómo funciona el ámbito de DI, para definir un componente de barra de herramientas dentro de `{RowIslandSelector}`, use la propiedad de entrada `ToolbarTemplate`. Esto permite que las cuadrículas secundarias creen sus propias instancias independientes de la barra de herramientas:

Estas funciones pueden habilitarse de forma independiente entre sí siguiendo un patrón similar al del componente card de la suite {ProductName}.

```typescript
})
export class AppModule { ... }
```

## Estilos

Para empezar a dar estilo a la barra de herramientas, debemos importar el archivo index, donde se encuentran todas las funciones de tema y los mixins de componentes:

```scss
@use "igniteui-{Platform}/theming" as *;

// IMPORTANT: Prior to {ProductName} version 13 use:
// @import '~igniteui-{Platform}/lib/core/styles/themes/index';
```

Primero, creemos una nueva paleta.

```scss
$my-dark-palette: palette(
    $primary: #2466ff,
    $secondary: #FFCD0F,
    $surface: #2a2b2f,
    $grays: #fff,
);

$my-dark-color: color($my-dark-palette, 'surface');
```

Ahora, cree un tema nuevo que extienda <ApiLink type="function-grid-toolbar-theme" label="grid-toolbar-theme" kind="sass" module="index.html" /> y modifique los parámetros `$background-color` y `$title-text-color`.

```scss
$dark-grid-toolbar-theme: grid-toolbar-theme(
    $background-color: $my-dark-color,
    $title-text-color: color($my-dark-palette, 'secondary'),
    $dropdown-background: $my-dark-color,
);
```

Para aplicar el tema a los menús de acciones de columna de la barra de herramientas, tenemos que cambiar el tema del componente `column-actions-theme`.

```scss
$dark-column-actions-theme: column-actions-theme(
    $title-color: color($my-dark-palette, 'secondary'),
    $background-color: color($my-dark-palette, 'surface')
);
```

Como las acciones de columna usan otros componentes (igx-button, igx-checkbox e igx-input-group), debemos cambiar sus temas para que coincidan con nuestro nuevo tema de barra de herramientas.

```scss
$dark-button-theme: outlined-button-theme(
    $background: color($my-dark-palette, 'secondary'),
    $hover-background: color($my-dark-palette, 'gray', 100),
    $hover-foreground: color($my-dark-palette, 'secondary')
);

$dark-checkbox-theme: checkbox-theme(
    $tick-color: $my-dark-color,
);

$dark-input-group-theme: input-group-theme(
    $filled-text-color: color($my-dark-palette, 'secondary')
);
```

El último paso es **incluir** los temas recién creados.

```scss
:host {
    @include grid-toolbar($dark-grid-toolbar-theme);
    @include column-actions($dark-column-actions-theme);
    @include checkbox($dark-checkbox-theme);
    @include input-group($dark-input-group-theme);
    @include button($dark-button-theme);
}
```

<DocsAside type="info">
Si `$legacy-support` se establece en `false(default)`, incluya así las variables CSS del componente:
</DocsAside>

```scss
:host {
    @include tokens($dark-grid-toolbar-theme);
    @include tokens($dark-column-actions-theme);
    @include tokens($dark-checkbox-theme);
    @include tokens($dark-input-group-theme);
    @include tokens($dark-button-theme);
}
```

<DocsAside type="info">
Si el componente usa un ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), es necesario `penetrate` esa encapsulación usando `::ng-deep`:
</DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid-toolbar($dark-grid-toolbar-theme);
        @include column-actions($dark-column-actions-theme);
        @include checkbox($dark-checkbox-theme);
        @include input-group($dark-input-group-theme);
        @include button($dark-button-theme);
    }
}
```
