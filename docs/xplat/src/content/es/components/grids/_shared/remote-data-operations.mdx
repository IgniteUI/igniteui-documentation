## Desplazamiento infinito

 Un diseño muy habitual en los escenarios que requieren obtener datos por fragmentos desde un punto final es el denominado desplazamiento infinito. En las cuadrículas de datos se caracteriza por el aumento continuo de los datos cargados, provocado por el usuario final al desplazarse hasta el final. Los siguientes párrafos explican cómo puede usar la API disponible para lograr fácilmente el desplazamiento infinito en <ApiLink type="{ComponentName}" />.

Para implementar el desplazamiento infinito, debe obtener los datos por fragmentos. Los datos que ya se han obtenido deben almacenarse localmente, y debe determinar la longitud de un fragmento y cuántos fragmentos hay. También debe llevar un registro del índice de la última fila de datos visible en la cuadrícula. De este modo, usando las propiedades <ApiLink type="ForOfState" member="chunkSize" /> y <ApiLink type="ForOfState" member="chunkSize" />, puede determinar si el usuario se desplaza hacia arriba, en cuyo caso debe mostrar los datos ya obtenidos, o hacia abajo, en cuyo caso debe obtener más datos del punto final.




Lo primero que hay que hacer es obtener el primer fragmento de datos. Establecer la propiedad <ApiLink type="{ComponentName}" member="totalItemCount" /> es importante, ya que permite que la cuadrícula dimensione correctamente su barra de desplazamiento.

<PlatformBlock for="Angular">
```typescript
public ngAfterViewInit() {
    this._remoteService.loadDataForPage(this.page, this.pageSize, (request) => {
        if (request.data) {
            this.grid.totalItemCount = this.page * this.pageSize;
            this.grid.data = this._remoteService.getCachedData({startIndex: 0, chunkSize: 10});
            this.totalItems = request.data['@odata.count'];
            this.totalPageCount = Math.ceil(this.totalItems / this.pageSize);
            this.grid.isLoading = false;
        }
    });
}
```

```typescript
    const isLastChunk = this.grid.totalItemCount ===
                        this.grid.virtualizationState.startIndex + this.grid.virtualizationState.chunkSize;
    // when last chunk reached load another page of data
    if (isLastChunk) {
        if (this.totalPageCount === this.page) {
```

```razor
                this.grid.TotalItemCount = Math.Min(this.Page * this.PageSize, this.TotalItems);
```

## Ordenación/filtrado remoto

Para proporcionar ordenación y filtrado remotos, debe suscribirse a las salidas <ApiLink type="{ComponentName}" member="dataPreLoad" />, <ApiLink type="{ComponentName}" member="sortingExpressionsChange" /> y <ApiLink type="{ComponentName}" member="filteringExpressionsTreeChange" />, para realizar la solicitud adecuada según los argumentos recibidos, así como establecer la propiedad pública <ApiLink type="{ComponentName}" /> <ApiLink type="{ComponentName}" member="totalItemCount" /> con la información correspondiente procedente del servicio.

También aprovecharemos la función **rxjs** `debounceTime`, que emite un valor del Observable de origen solo después de que haya pasado un periodo de tiempo concreto sin que se emita otro valor. Así, la operación remota solo se disparará cuando haya transcurrido el tiempo especificado sin que el usuario la interrumpa.

```typescript
const DEBOUNCE_TIME = 300;
public ngAfterViewInit() {
    this.grid.dataPreLoad.pipe(
        debounceTime(DEBOUNCE_TIME),
        takeUntil(this.destroy$)
    ).subscribe(() => {
        this.processData();
    });

    this.grid.filteringExpressionsTreeChange.pipe(
        debounceTime(DEBOUNCE_TIME),
        takeUntil(this.destroy$)
    ).subscribe(() => {
        this.processData(true);
    });

    this.grid.sortingExpressionsChange.pipe(
        debounceTime(DEBOUNCE_TIME),
        takeUntil(this.destroy$)
    ).subscribe(() => {
        this.processData();
    });
}
```

## Estrategia de valores únicos de columna

Los elementos de la lista del cuadro de diálogo de filtrado al estilo de Excel representan los valores únicos de la columna correspondiente. De forma predeterminada, <ApiLink type="{ComponentName}" /> genera estos valores a partir de su origen de datos. En el caso del filtrado remoto, los datos del grid no contienen todos los datos del servidor. Para proporcionar los valores únicos manualmente y cargarlos a demanda, podemos aprovechar la entrada <ApiLink type="{ComponentName}" member="uniqueColumnValuesStrategy" label="UniqueColumnValuesStrategy" /> de <ApiLink type="{ComponentName}" />. Esta entrada es en realidad un método que proporciona tres argumentos:

- <ApiLink type="Column" />  - La instancia de columna correspondiente.
- <ApiLink type="FilteringExpressionsTree" /> - El árbol de expresiones de filtrado, que se reduce según la columna correspondiente.
- `Done` - Devolución de llamada que debe invocarse con los nuevos valores de columna generados cuando se recuperan del servidor.

El desarrollador puede generar manualmente los valores únicos de columna necesarios a partir de la información proporcionada por los argumentos <ApiLink type="Column" /> y <ApiLink type="FilteringExpressionsTree" />, y después invocar la devolución de llamada `Done`.

<DocsAside type="info">
Cuando se proporciona la entrada `UniqueColumnValuesStrategy`, no se usará el proceso predeterminado de generación de valores únicos del filtrado al estilo de Excel.
</DocsAside>

## Paginación remota

<ComponentBlock for="Grid">
La función de paginación puede funcionar con datos remotos. Para demostrarlo, declaremos primero nuestro servicio, responsable de la obtención de datos. Necesitaremos el número de todos los elementos de datos para calcular el número de páginas. Esta lógica se añadirá a nuestro servicio.

<PlatformBlock for="Angular">
```typescript
@Injectable()
export class RemotePagingService {
    public remoteData: BehaviorSubject<any[]>;
    public dataLenght: BehaviorSubject<number> = new BehaviorSubject(0);
    public url = 'https://www.igniteui.com/api/products';

    constructor(private http: HttpClient) {
        this.remoteData = new BehaviorSubject([]) as any;
    }

    public getData(index?: number, perPage?: number): any {
        let qS = '';

        if (perPage) {
            qS = `?$skip=${index}&$top=${perPage}&$count=true`;
        }

        this.http
            .get(`${this.url + qS}`).pipe(
                map((data: any) => data)
            ).subscribe((data) => this.remoteData.next(data));
    }

    public getDataLength(): any {
        return this.http.get(this.url).pipe(
            map((data: any) => data.length)
        );
    }
}

```

```ts
export class RemotePagingService {
    public static CUSTOMERS_URL = `https://data-northwind.indigo.design/Customers/GetCustomersWithPage`;
    constructor() {}

    public static getDataWithPaging(pageIndex?: number, pageSize?: number) {
        return fetch(RemotePagingService.buildUrl(RemotePagingService.CUSTOMERS_URL, pageIndex, pageSize))
        .then((result) => result.json())
        .catch((error) => console.error(error.message));
    }

    private static buildUrl(baseUrl: string, pageIndex?: number, pageSize?: number) {
        let qS = "";
        if (baseUrl) {
                qS += `${baseUrl}`;
        }

        // Add pageIndex and size to the query string if they are defined
        if (pageIndex !== undefined) {
            qS += `?pageIndex=${pageIndex}`;
            if (pageSize !== undefined) {
                qS += `&size=${pageSize}`;
            }
        } else if (pageSize !== undefined) {
            qS += `?perPage=${pageSize}`;
        }

        return `${qS}`;
    }
}
```

```typescript
    public remoteData: BehaviorSubject<any[]>;
    public dataLenght: BehaviorSubject<number> = new BehaviorSubject(0);
    public url = 'https://www.igniteui.com/api/products';

    constructor(private http: HttpClient) {
        this.remoteData = new BehaviorSubject([]) as any;
    }

    public getData(index?: number, perPage?: number): any {
        let qS = '';

        if (perPage) {
            qS = `?$skip=${index}&$top=${perPage}&$count=true`;
        }

        this.http
            .get(`${this.url + qS}`).pipe(
                map((data: any) => data)
            ).subscribe((data) => this.remoteData.next(data));
    }

    public getDataLength(): any {
        return this.http.get(this.url).pipe(
            map((data: any) => data.length)
        );
    }
}
```

### Paginación remota con la plantilla predeterminada

Si desea usar la plantilla de paginación predeterminada, debe establecer la propiedad <ApiLink type="GridBaseDirective" member="totalRecords" label="TotalRecords" /> del paginador; solo así la cuadrícula podrá calcular el número total de páginas a partir de los registros remotos totales. Al realizar una paginación remota, el paginador pasará a la cuadrícula solo los datos de la página actual, por lo que la cuadrícula no intentará paginar el origen de datos proporcionado. Por eso debemos establecer la propiedad <ApiLink type="GridBaseDirective" member="pagingMode" label="PagingMode" /> de la cuadrícula en <ApiLink type="GridPagingMode" member="Remote" label="GridPagingMode.Remote" />.
```typescript
@ViewChild('grid1', { static: true }) public grid1: IgxGridComponent;

public ngAfterViewInit() {
    this.grid1.isLoading = true;
    this.remoteService.getData(0, this.perPage);
}

public nextPage() {
    this.firstPage = false;
    this.page++;
    const skip = this.page * this.perPage;
    const top = this.perPage;
    this.remoteService.getData(skip, top);
    if (this.page + 1 >= this.totalPages) {
        this.lastPage = true;
    }
    this.setNumberOfPagingItems(this.page, this.totalPages);
}

public previousPage() {
    this.lastPage = false;
    this.page--;
    const skip = this.page * this.perPage;
    const top = this.perPage;
    this.remoteService.getData(skip, top);
    if (this.page <= 0) {
        this.firstPage = true;
    }
    this.setNumberOfPagingItems(this.page, this.totalPages);
}

public paginate(page: number, recalculate = false) {
    this.page = page;
    const skip = this.page * this.perPage;
    const top = this.perPage;
    if (recalculate) {
        this.totalPages = Math.ceil(this.totalCount / this.perPage);
    }
    this.setNumberOfPagingItems(this.page, this.totalPages);
    this.remoteService.getData(skip, top);
    this.buttonDeselection(this.page, this.totalPages);
}
```

### Paginación remota con edición por lotes

Con los ejemplos vistos hasta ahora hemos aclarado cómo configurar <ApiLink type="{ComponentName}" /> con datos remotos. Ahora centrémonos en habilitar la edición por lotes del grid siguiendo la [guía o tema de edición por lotes](batch-editing.mdx).

Antes de continuar con el ejemplo conviene aclarar el caso de uso actual. Cuando la paginación se realiza en el servidor, el grid contiene los datos solo de la página actual, y si añadimos filas nuevas, las filas añadidas (con edición por lotes) se concatenarán con los datos actuales del grid. Por tanto, si el servidor no devuelve datos para una página determinada, el origen de datos del grid estará compuesto solo por las filas recién añadidas, que el grid paginará según la configuración de paginación definida (page, perPage).

```typescript
        this.totalCount = data;
        this._recordOnServer = data;
        this._totalPagesOnServer = Math.floor(this.totalCount / this.perPage);
        this.grid1.isLoading = false;
    });
}
```

Para gestionar correctamente este caso de uso, necesitamos implementar cierta lógica personalizada.

En primer lugar, debemos conocer el número total de registros que hay en el servidor. Con ese dato, calculamos el número total de páginas de datos del servidor y, según su valor, implementaremos la lógica de paginación personalizada.

```typescript
public paginate(page: number) {
    this.grid1.endEdit(true);
    if (page > this._totalPagesOnServer) {
        if (this.page !== this._totalPagesOnServer) {
            const skipEl = this._totalPagesOnServer * this.perPage;
            this.remoteService.getData(skipEl, this.perPage);
        }
        this.page = page - this._totalPagesOnServer;
        this.page = page;
        return;
    } else {
        this.page = 0;
    }
    this.page = page;
    const skip = this.page * this.perPage;
    this.remoteService.getData(skip, this.perPage);
}
```
