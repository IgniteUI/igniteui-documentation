# Información general del portapapeles de {Platform} {ComponentTitle}

Las operaciones de copiar al portapapeles ya están disponibles en <ApiLink type="{ComponentName}" />. Esta funcionalidad ofrece una forma rápida, sencilla y personalizable de copiar los datos de {Platform} <ApiLink type="{ComponentName}" /> mediante la selección actual de datos de varias celdas. El comportamiento del portapapeles del sistema permite al usuario copiar datos de <ApiLink type="{ComponentName}" /> a Excel u otros programas externos.

## Funcionalidad

El comportamiento de copiar funciona con la interacción predeterminada definida por el navegador y el sistema operativo. Por tanto, para copiar y pegar, estas son las opciones:

- Basado en Windows/Unix
  - <kbd>CTRL</kbd> + <kbd>C</kbd> / <kbd>CTRL</kbd> + <kbd>Ins</kbd> como atajo de teclado
  - <kbd>CTRL</kbd> + <kbd>V</kbd> / <kbd>SHIFT</kbd> + <kbd>Ins</kbd> como atajo de teclado
  - Acción de copiar mediante el menú del navegador
- macOS
  - <kbd>CMD</kbd> + <kbd>C</kbd> como atajo de teclado
  - <kbd>CMD</kbd> + <kbd>V</kbd> como atajo de teclado
  - Acción de copiar mediante el menú del navegador


## Limitaciones

- Los eventos **cut** y **copy** no se admiten de forma nativa en Internet Explorer. La excepción es el

evento **paste** (IE 11), que se emite pero no expone la <PlatformBlock for="Angular"><ApiLink type="IClipboardOptions" label="ClipboardData" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="ClipboardOptions" label="ClipboardData" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="ClipboardOptions" label="ClipboardData" /></PlatformBlock> propiedad en el evento.
<DocsAside type="info">
Para **copiar** celdas en IE 11, puede usar la selección con el teclado. Mantenga pulsada la tecla <kbd>SHIFT</kbd> para hacer una selección de varias celdas, y pulse <kbd>CTRL</kbd> + <kbd>C</kbd> para copiar.
</DocsAside>

- El comportamiento de copiar está deshabilitado mientras el grid está en modo de edición.
- La versión actual de esta función solo cubre el comportamiento de **copiar** desde la cuadrícula. Más adelante planeamos exponer `paste` dentro del comportamiento de la cuadrícula.

## Uso de la API

Exponemos la propiedad <ApiLink type="{ComponentName}" member="clipboardOptions" />, que gestiona las siguientes opciones:
- <PlatformBlock for="Angular"><ApiLink type="IClipboardOptions" member="enabled" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="ClipboardOptions" member="enabled" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="ClipboardOptions" member="enabled" /></PlatformBlock> Habilita o deshabilita la copia de las celdas seleccionadas.
- <PlatformBlock for="Angular"><ApiLink type="IClipboardOptions" member="copyHeaders" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="ClipboardOptions" member="copyHeaders" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="ClipboardOptions" member="copyHeaders" /></PlatformBlock> Incluye los encabezados asociados al copiar.
- <PlatformBlock for="Angular"><ApiLink type="IClipboardOptions" member="copyFormatters" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="ClipboardOptions" member="copyFormatters" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="ClipboardOptions" member="copyFormatters" /></PlatformBlock> Aplica los formateadores de columna existentes a los datos copiados.
- <PlatformBlock for="Angular"><ApiLink type="IClipboardOptions" member="separator" /></PlatformBlock><PlatformBlock for="React,WebComponents"><ApiLink type="ClipboardOptions" member="separator" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="ClipboardOptions" member="separator" /></PlatformBlock> El separador de cadena que se usa para dar formato a los datos en el portapapeles. El valor predeterminado es `/t`

<DocsAside type="info">
Excel puede detectar automáticamente el texto separado por tabulaciones (`/t` delimitado por tabuladores) y pegar los datos correctamente en columnas separadas. Cuando el formato de pegado no funciona y todo lo que pega aparece en una única columna, es porque el delimitador de Excel está configurado con otro carácter, o porque su texto usa espacios en lugar de tabulaciones.
</DocsAside>

- <PlatformBlock for="WebComponents"><ApiLink type="GridComponentEventMap" member="gridCopy" label="gridCopy" /></PlatformBlock><PlatformBlock for="React"><ApiLink type="Grid" member="onGridCopy" label="gridCopy" /></PlatformBlock><PlatformBlock for="Angular"><ApiLink type="Grid" member="gridCopy" label="gridCopy" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="Grid" member="gridCopy" label="gridCopy" /></PlatformBlock> Se emite cuando se ejecuta una operación de copia. Solo se dispara si el comportamiento de copia está habilitado mediante <ApiLink type="{ComponentName}" member="clipboardOptions" />.
