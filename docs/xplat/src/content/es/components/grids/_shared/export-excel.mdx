# Exportación de {Platform} {ComponentTitle}

<PlatformBlock for="Blazor, React, WebComponents">
El {ProductName} {ComponentTitle} proporciona la funcionalidad de exportación de datos mediante el componente Grid Toolbar Exporter. Puede exportar los datos mostrados a los formatos Excel, CSV o PDF. Las exportaciones a Excel usan el formato de tabla de MS Excel, que admite funciones como el filtrado y la ordenación. Para habilitar la exportación, coloque <ApiLink type="GridToolbarExporter" /> dentro de la barra de herramientas de la cuadrícula. De forma predeterminada, todos los formatos de exportación están habilitados.
</PlatformBlock>

<PlatformBlock for="Angular">
Los servicios de exportación {ProductName} de {Platform} {ComponentTitle} pueden exportar datos a los formatos Excel y PDF. La funcionalidad de exportación está encapsulada en las clases <ApiLink type="ExcelExporterService" /> y <ApiLink type="PdfExporterService" />. Las exportaciones a Excel usan el formato de tabla de MS Excel, que admite funciones como el filtrado y la ordenación, mientras que las exportaciones a PDF capturan el estado actual de la cuadrícula. Para iniciar una exportación, invoque el método `Export` de <ApiLink type="ExcelExporterService" /> o <ApiLink type="PdfExporterService" /> y pase el componente <ApiLink type="{ComponentName}" /> como primer argumento.
</PlatformBlock>

## Exportación de datos de {ComponentTitle}

Para empezar a usar los exportadores de IgniteUI Excel y PDF, primero importe <ApiLink type="ExcelExporterService" /> y/o <ApiLink type="PdfExporterService" /> en el archivo app.module.ts y añada los servicios a la matriz `providers`:

```ts
// app.module.ts
import { ExcelExporterService, PdfExporterService } from 'igniteui-{Platform}';

@NgModule({
  providers: [ ExcelExporterService, PdfExporterService ]
})

export class AppModule {}
```

<DocsAside type="info">
En la versión 12.2.1 y posteriores, los servicios de exportación se proporcionan en root, lo que significa que ya no es necesario declararlos en los providers de AppModule.
</DocsAside>

Para iniciar una exportación, puede usar el controlador de un botón en la plantilla de su componente.

```html
<{ComponentTitle} #{ComponentTitle} [data]="localData" [autoGenerate]="true"></{ComponentTitle}>
<button (click)="exportButtonHandler()">Export {ComponentTitle} to Excel</button>
<button (click)="exportPdfButtonHandler()">Export {ComponentTitle} to PDF</button>
```

Puede acceder a los servicios de exportación definiendo argumentos del constructor de tipo <ApiLink type="ExcelExporterService" /> o <ApiLink type="PdfExporterService" />, y el framework {Platform} proporcionará instancias de los servicios. Para exportar datos a Excel o PDF, invoque el método `Export` y pase el componente {ComponentTitle} como primer argumento.

El código siguiente ejecuta los procesos de exportación en el archivo del componente:

```ts
// component.ts
import { ExcelExporterService, ExcelExporterOptions, PdfExporterService, PdfExporterOptions } from 'igniteui-{Platform}';
import { {ComponentName} } from 'igniteui-{Platform}';

@ViewChild('{ComponentName}') public {ComponentName}: {ComponentName};

constructor(private excelExportService: ExcelExporterService, private pdfExportService: PdfExporterService) {
}

public exportButtonHandler() {
  this.excelExportService.export(this.{ComponentName}, new ExcelExporterOptions('ExportedDataFile'));
}

public exportPdfButtonHandler() {
  this.pdfExportService.export(this.{ComponentName}, new PdfExporterOptions('ExportedDataFile'));
}
```

Si todo ha ido bien, debería ver el componente {ComponentTitle} y los dos botones de exportación. Al pulsar el botón correspondiente, se inicia el proceso de exportación y el navegador descarga un archivo llamado "ExportedDataFile.xlsx" o "ExportedDataFile.pdf" con los datos del componente <ApiLink type="{ComponentName}" /> en formato Excel o PDF.
</PlatformBlock>

## Exportar todos los datos

Cuando usa operaciones remotas como **paginación**, es posible que la cuadrícula no tenga acceso al conjunto completo de datos a la vez. En estos casos, recomendamos usar el [Excel Export Service](../exporter-excel.mdx) y pasar toda la colección de datos, si está disponible. Ejemplo:

```ts
public exportButtonHandler() {
  this.excelExportService.exportData(this.localData, new ExcelExporterOptions('ExportedDataFile'));
}
```

Al ofrecer descargas en PDF para datos remotos, considere obtener primero el conjunto completo de datos y después llamar a `export`, para que el documento refleje lo que los usuarios esperan ver.

</PlatformBlock>

## Exportar un grid con encabezados de columna fijos

De forma predeterminada, el servicio Excel Exporter exporta la cuadrícula con los encabezados de columna desplazables (no fijos). En muchos escenarios, puede que desee fijar todos los encabezados en la parte superior del archivo Excel exportado para que siempre permanezcan visibles mientras el usuario recorre los registros. Para lograrlo, establezca la propiedad `ExporterOption` <PlatformBlock for="Angular"><ApiLink type="IGridToolbarExportEventArgs" member="freezeHeaders" /></PlatformBlock><PlatformBlock for="React"><ApiLink type="ExporterOptionsBase" member="freezeHeaders" /></PlatformBlock><PlatformBlock for="WebComponents"><ApiLink type="ExporterOptionsBase" member="freezeHeaders" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink type="GridToolbarExportEventArgs" member="freezeHeaders" /></PlatformBlock> en `true`.

<DocsAside type="info">
Las exportaciones a PDF incluyen automáticamente la fila de encabezados de columna en la parte superior del documento, de modo que los lectores mantienen el mismo contexto al abrir o imprimir el archivo.
</DocsAside>

<PlatformBlock for="Angular">
```ts
public exportButtonHandler() {
    const exporterOptions = new ExcelExporterOptions('ExportedDataFile');
    exporterOptions.freezeHeaders = true;
    this.excelExportService.export(this.grid, exporterOptions);
}
```
</PlatformBlock>

## Personalizar el contenido exportado

En los ejemplos anteriores, el servicio Excel Exporter exporta todos los datos disponibles. Hay situaciones en las que puede que desee omitir la exportación de una fila o incluso de una columna entera. Para ello, suscríbase a los eventos <ApiLink type="{ComponentName}" member="columnExporting" /> y/o <ApiLink type="{ComponentName}" member="rowExporting" />, que se disparan para cada columna y cada fila respectivamente, y cancele el evento estableciendo la propiedad `cancel` del objeto de argumentos del evento en `true`.

El siguiente ejemplo excluye de la exportación una columna si su encabezado es "Age" y su índice es 1:

```ts
// component.ts

this.excelExportService.columnExporting.subscribe((args: IColumnExportingEventArgs) => {
  if (args.header == 'Age' && args.columnIndex == 1) {
      args.cancel = true;
  }
});
this.excelExportService.export(this.{ComponentTitle}, new ExcelExporterOptions('ExportedDataFile'));
```

Cuando exporta datos del componente <ApiLink type="{ComponentName}" />, el proceso de exportación tiene en cuenta funciones como el filtrado de filas y la ocultación de columnas, y exporta solo los datos visibles en <ApiLink type="{ComponentName}" />. Puede configurar el servicio de exportación para incluir filas filtradas o columnas ocultas estableciendo propiedades en el objeto <ApiLink type="ExcelExporterOptions" /> o <ApiLink type="PdfExporterOptions" />.

## Limitaciones conocidas

<ComponentBlock for="Grid">
|Limitación|Descripción|
|--- |--- |
|Tamaño máximo de hoja de cálculo|El tamaño máximo de hoja de cálculo que admite Excel es de 1.048.576 filas por 16.384 columnas.|
|Estilo de celdas|El servicio exportador de Excel no admite la exportación de un estilo personalizado aplicado a un componente de celda. En tales casos, recomendamos usar la [Excel Library](../../excel-library.mdx).|
|Diseños PDF anchos|Los grids muy anchos pueden hacer que las columnas del PDF se reduzcan para ajustarse a la página. Aplique anchos de columna u oculte los campos de menor prioridad antes de exportar para que el documento siga siendo legible.|
</ComponentBlock>
