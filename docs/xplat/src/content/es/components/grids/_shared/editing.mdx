# Edición de {Platform} {ComponentTitle}

La característica de edición de celdas de {ProductName} en {Platform} {ComponentTitle} ofrece una forma sencilla de realizar operaciones de manipulación de datos, como crear, actualizar y eliminar registros. <ApiLink type="{ComponentName}" /> le proporciona una potente API pública que le permite personalizar la forma en que se realizan estas operaciones. Las fases de manipulación de datos son:
- [Edición de celdas](cell-editing.mdx)
- [Edición de filas](row-editing.mdx)
- Edición por lotes (próximamente)

<PlatformBlock for="Angular">
Además, la **edición de celdas** expone varios editores predeterminados según el tipo de datos de la columna, que pueden personalizarse fácilmente mediante la directiva [CellEditor](cell-editing.mdx#cell-editing-templates) o las [directivas de fila](row-editing.mdx#customizing-row-editing-overlay).

</PlatformBlock>

## Configuración

Para especificar qué modo de edición debe habilitarse, el <ApiLink type="{ComponentName}" /> expone las siguientes propiedades booleanas: <ApiLink type="Column" member="editable" /> y <ApiLink type="{ComponentName}" member="rowEditable" />.

La propiedad <ApiLink type="Column" member="editable" /> le permite especificar las siguientes opciones:

- **false**: la edición de la columna correspondiente queda deshabilitada. Es el valor predeterminado.
- **true**: la edición de la columna correspondiente queda habilitada.

>Tenga en cuenta que, si la columna no es editable, aún puede modificar su valor mediante la API pública que expone <ApiLink type="{ComponentName}" />.

La propiedad <ApiLink type="{ComponentName}" member="rowEditable" /> le permite especificar las siguientes opciones:

- **false**: la edición de filas en la cuadrícula correspondiente queda deshabilitada. Es el valor predeterminado.
- **true**: la edición de filas en la cuadrícula correspondiente queda habilitada.

En <ApiLink type="{ComponentName}" />, si establece la propiedad <ApiLink type="{ComponentName}" member="rowEditable" /> en true, y la propiedad <ApiLink type="Column" member="editable" /> no está definida explícitamente en ninguna columna, la edición quedará habilitada para todas las columnas excepto la **clave primaria**.

La [edición por lotes](batch-editing.mdx) de la cuadrícula puede habilitarse tanto para el modo de [edición de celdas](cell-editing.mdx) como para el de [edición de filas](row-editing.mdx). Para configurar la edición por lotes es necesario proporcionar a la cuadrícula un **TransactionService**.


- **Edición de celdas y por lotes**: en este escenario, cada modificación individual de cada celda se conserva por separado, y las operaciones de deshacer y rehacer están disponibles a nivel de celda;
- **Edición de filas y por lotes**: en este escenario, las modificaciones se conservan a nivel de fila, de modo que las operaciones de deshacer y rehacer no funcionarán para cada celda modificada, sino para el conjunto de celdas de cada fila.

### Plantillas de edición

 Si desea usar plantillas de edición específicas del tipo de datos, debe especificar la propiedad <ApiLink type="Column" member="dataType" /> de la columna. Veamos ahora cuáles son las plantillas predeterminadas de cada tipo:

- Para el tipo de datos `string`, la plantilla predeterminada usa <ApiLink pkg="core" type="Input" />.
- Para el tipo de datos `number`, la plantilla predeterminada usa <ApiLink pkg="core" type="Input" /> type="number", así que si intenta actualizar una celda con un valor que no puede interpretarse como número, su cambio se descartará y el valor de la celda se establecerá en 0.
- Para el tipo de datos `date`, la plantilla predeterminada usa <ApiLink pkg="core" type="DatePicker" />
- Para el tipo de datos `dateTime`, la plantilla predeterminada usa <ApiLink pkg="core" type="DatePicker" />. Este editor le ofrecerá indicaciones de máscara para los elementos de entrada que forman parte del objeto DateTime.
- Para el tipo de datos `time`, la plantilla predeterminada es <ApiLink pkg="core" type="DateTimeInput" />.
- Para el tipo de datos `boolean`, la plantilla predeterminada usa <ApiLink pkg="core" type="Checkbox" />.
- Para el tipo de datos `currency`, la plantilla predeterminada usa <ApiLink pkg="core" type="Input" /> con una configuración de prefijo/sufijo según la configuración regional de la aplicación o de la cuadrícula.
- Para el tipo de datos `percent`, la plantilla predeterminada usa <ApiLink pkg="core" type="Input" /> con un elemento sufijo que muestra una vista previa del valor editado en porcentaje.
<ComponentBlock for="Grid">
- Para plantillas personalizadas, puede consultar el tema [Edición de celdas](cell-editing.mdx#ejemplo-de-edición-de-celdas-y-plantillas-de-edición-de-{PlatformLower}-grid)
</ComponentBlock>

### Argumentos del evento y secuencia
<ComponentBlock for="Grid, TreeGrid, HierarchicalGrid">
La cuadrícula expone una amplia variedad de eventos que ofrecen un mayor control sobre la experiencia de edición. Estos eventos se disparan durante el ciclo de vida de [**edición de filas**](row-editing.mdx) y [**edición de celdas**](cell-editing.mdx): al iniciar, confirmar o cancelar la acción de edición.
</ComponentBlock>

 | Evento           | Descripción                                                                                                                                               | Argumentos                  | Cancelable |
 | --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ----------- |
 | <ApiLink type="{ComponentName}" member="rowEditEnter" />  | Si `RowEditing` está habilitado, se dispara cuando una fila entra en modo de edición                                                                                             | <ApiLink type="GridEditEventArgs" />    | **true**    |
 | <ApiLink type="{ComponentName}" member="cellEditEnter" /> | Se dispara cuando una celda **entra en modo de edición** (después de <ApiLink type="{ComponentName}" member="rowEditEnter" />)                                                                                             | <ApiLink type="GridEditEventArgs" />     | **true**    |
 | <ApiLink type="{ComponentName}" member="cellEdit" />      | Si el valor cambia, se dispara justo **antes** de que el valor de una celda se **confirme** (por ejemplo, al pulsar <kbd>ENTER</kbd>)                                                     | <ApiLink type="GridEditEventArgs" />     | **true**    |
 | <ApiLink type="{ComponentName}" member="cellEditDone" />  | Si el valor cambia, se dispara **después** de que una celda se haya editado y el valor de la celda se haya **confirmado**                                                             | <ApiLink type="GridEditDoneEventArgs" /> | **false**   |
 | <ApiLink type="{ComponentName}" member="cellEditExit" />  | Se dispara cuando una celda **sale del modo de edición**                                                                                                                     | <ApiLink type="GridEditDoneEventArgs" /> | **false**   |
 | <ApiLink type="{ComponentName}" member="rowEdit" />       | Si `RowEditing` está habilitado, se dispara justo antes de que se **confirme** el valor de una fila en modo de edición (por ejemplo, al hacer clic en el botón `Done` de la superposición de edición de filas) | <ApiLink type="GridEditEventArgs" />     | **true**    |
 | <ApiLink type="{ComponentName}" member="rowEditDone" />   | Si `RowEditing` está habilitado, se dispara **después** de que una fila se haya editado y el nuevo valor de la fila se haya **confirmado**.                                             | <ApiLink type="GridEditDoneEventArgs" /> | **false**   |
 | <ApiLink type="{ComponentName}" member="rowEditExit" />   | Si `RowEditing` está habilitado, se dispara cuando una fila **sale del modo de edición**                                                                                          | <ApiLink type="GridEditDoneEventArgs" /> | **false**   |

### Cancelación del evento

- <ApiLink type="{ComponentName}" member="rowEditEnter" /> - Ni `Row` ni `Cell` entrarán en modo de edición.
- <ApiLink type="{ComponentName}" member="cellEditEnter" />: impide entrar en la edición de celdas. Si <ApiLink type="{ComponentName}" member="rowEditable" /> está habilitado, se activará la edición de filas, aunque la edición de celdas seguirá prohibida.
- <ApiLink type="{ComponentName}" member="cellEdit" /> - Si se permite la edición `Cell` y/o `Row`, al pulsar el botón **Done** o **Enter** no se confirmará el valor ni la transacción de la fila. La edición de celdas y la edición de filas no se cerrarán hasta que se haga clic en el botón **Cancel**.
- <ApiLink type="{ComponentName}" member="rowEdit" />: es posible confirmar la celda, pero no la fila completa. La fila permanecerá en modo de edición y la transacción de la fila se considerará abierta. Al pulsar **Hecho** no se confirma ni se cierra la fila. El botón **Cancelar** cierra el proceso de edición y la transacción sin confirmar los cambios.

### Integración de funciones
Mientras una celda o fila está en modo de edición, el usuario puede interactuar con la cuadrícula de muchas formas. La tabla siguiente indica cómo afecta una determinada interacción a la edición actual:

| {ComponentTitle} | Filtrado | Ordenación | Paginación | Movimiento | Anclaje | Ocultación | GroupBy | Redimensionamiento | Escape | Enter |  F2   |  Tabulador  | Clic en celda | Añadir fila/Eliminar/Editar |
| ---------------- | :-------: | :-----: | :----: | :----: | :-----: | :----: | :-----: | :------: | :----: | :---: | :---: | :---: | :--------: | :---------------------: |
| Mantener el modo de edición   |           |         |        |        |         |        |         |    ✔     |        |       |       |       |            |                         |
| Salir del modo de edición   |     ✔     |    ✔    |   ✔    |   ✔    |    ✔    |   ✔    |    ✔    |          |   ✔    |   ✔   |   ✔   |   ✔   |     ✔      |            ✔            |
| Confirmar           |           |         |        |        |         |        |         |          |        |   ✔   |   ✔   |   ✔   |     ✔      |            ✔            |
| Descartar          |     ✔     |    ✔    |   ✔    |   ✔    |    ✔    |   ✔    |    ✔    |          |   ✔    |       |       |       |            |                         |

Como se ve en la tabla, todas las interacciones, excepto redimensionar una columna, terminarán la edición y descartarán los nuevos valores. Si quiere confirmar el nuevo valor, el desarrollador puede hacerlo en el evento "-ing" correspondiente de la función.

Ejemplo de cómo confirmar los nuevos valores si el usuario intenta ordenar la columna mientras una celda o fila está en modo de edición:

<PlatformBlock for="Angular">
```html
<{ComponentSelector} #grid [data]="localData" [primaryKey]="'ProductID'" (sorting)="onSorting($event)">
</{ComponentSelector}>
```

```typescript
public onSorting(event: ISortingEventArgs) {
    this.grid.endEdit(true);
}
```

</PlatformBlock>

```html
</{ComponentSelector}>
```

```typescript
constructor() {

    grid.data = this.data;
    grid.addEventListener("sorting", this.onSorting);
```

</PlatformBlock>
