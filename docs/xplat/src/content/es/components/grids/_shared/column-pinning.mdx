# Anclaje de columnas de {Platform} {ComponentTitle}

La característica de anclaje de columnas de {ProductName} en {Platform} {ComponentTitle} permite a los desarrolladores bloquear columnas concretas en el orden deseado, lo que garantiza que sigan visibles en todo momento, incluso cuando los usuarios se desplazan horizontalmente por el `{ComponentName}`. Hay una interfaz integrada para el anclaje de columnas, accesible a través de la barra de herramientas {Platform} {ComponentTitle}. Además, los desarrolladores pueden crear una interfaz de usuario personalizada que cambie el estado de anclaje de las columnas.

## API de anclaje de columnas

El anclaje de columnas se controla mediante la propiedad <ApiLink type="Column" member="pinned" /> de <ApiLink type="Column" />. Las columnas ancladas se representan de forma predeterminada en el lado izquierdo de <ApiLink type="{ComponentName}" /> y permanecen fijas durante el desplazamiento horizontal de las columnas no ancladas en el cuerpo de <ApiLink type="{ComponentName}" />.

## Posición del anclaje

Puede cambiar la posición del anclaje de columnas mediante la opción de configuración <ApiLink type="Column" member="pinningPosition" />. Permite establecer la posición de las columnas en Start o End.
Cuando se establece en End, las columnas se renderizan al final de la cuadrícula, después de las columnas no ancladas. Las columnas no ancladas pueden desplazarse horizontalmente, mientras que las columnas ancladas permanecen fijas a la derecha.

## Interfaz personalizada de anclaje de columnas

Puede definir su propia interfaz y cambiar el estado de anclaje de las columnas mediante la API relacionada.

Digamos que, en lugar de una barra de herramientas, quiere definir iconos de anclaje en los encabezados de columna para que el usuario final haga clic y cambie el estado de anclaje de una columna concreta.

Esto puede hacerse creando una plantilla de encabezado para las columnas con un icono personalizado.

// In JavaScript
igRegisterScript("WebGridPinHeaderTemplate", (ctx) => {
    var html = window.igTemplating.html;
    window.toggleColumnPin = function toggleColumnPin(field) {
        var grid = document.getElementsByTagName["igc-grid"](0);
        var col = grid.getColumnByName(field);
        col.pinned = !col.pinned;
        grid.markForCheck();
    }
    return html`<div>

    <span style="float:right" @pointerdown="${() => toggleColumnPin(ctx.column.field)}">📌</span>
</div>`;

## Limitaciones del anclaje

## Estilos

<ApiLink type="{ComponentName}" /> permite dar estilo mediante la [{ProductName} Theme Library](../themes/styles.mdx). La propiedad <ApiLink type="function-grid-theme" label="theme" kind="sass" module="index.html" /> de la cuadrícula expone una gran variedad de propiedades que permiten personalizar todas las características de la cuadrícula.

En los pasos siguientes veremos cómo personalizar el estilo del anclaje de la cuadrícula.

### Importar el tema global
Para empezar a personalizar la función de anclaje, debe importar el archivo `index`, donde se encuentran todas las funciones de estilo y los mixins.

```scss
@use "igniteui-angular/theming" as *;

// IMPORTANT: Prior to Ignite UI for Angular version 13 use:
// @import '~igniteui-angular/lib/core/styles/themes/index';
```

### Definir un tema personalizado
A continuación, cree un tema nuevo que extienda <ApiLink type="function-grid-theme" label="grid-theme" kind="sass" module="index.html" /> y acepte los parámetros necesarios para personalizar la función de anclaje como desee.

```scss
$custom-theme: grid-theme(
    /* Pinning properties that affect styling */
    $pinned-border-width: 5px,
    $pinned-border-style: double,
    $pinned-border-color: #FFCD0F,
    $cell-active-border-color: #FFCD0F
    /* add other features properties here... */
);
```

### Definir una paleta de colores personalizada
En el enfoque descrito anteriormente, los valores de color estaban codificados directamente. Como alternativa, puede conseguir más flexibilidad usando las funciones <ApiLink type="function-igx-palette" label="igx-palette" kind="sass" module="index.html" /> y <ApiLink type="function-igx-color" label="igx-color" kind="sass" module="index.html" />.
`igx-palette` genera una paleta de colores a partir de los colores primario y secundario proporcionados.

 ```scss
$primary-color: #292826;
$secondary-color: #ffcd0f;

$custom-palette: palette(
  $primary: $primary-color,
  $secondary: $secondary-color
);
```

Después de generar una paleta personalizada, la función `igx-color` puede usarse para obtener distintas variantes de los colores primario y secundario.


```scss
$custom-theme: grid-theme(
    $pinned-border-width: 5px,
    $pinned-border-style: double,
    $pinned-border-color: color($custom-palette, "secondary", 500),
    $cell-active-border-color: color($custom-palette, "secondary", 500)
);
```

El `$custom-theme` contiene las mismas propiedades que el de la sección anterior, pero esta vez los colores no están codificados. En su lugar, se usa la `igx-palette` personalizada, y los colores se obtienen a partir de sus colores primario y secundario, con una variante de color dada.

### Definir esquemas personalizados
Puede ir aún más allá y construir una estructura flexible que tenga todas las ventajas de un [**esquema**](../themes/sass/schemas.mdx). El **esquema** es la receta de un tema.
Extienda uno de los dos esquemas predefinidos que se proporcionan para cada componente. En nuestro caso, usaríamos `$_light_grid`.

```scss
$custom-grid-schema: extend($_light-grid,(
    pinned-border-width: 5px,
    pinned-border-style: double,
    pinned-border-color: color: ("secondary", 500),
    cell-active-border-color: color: ("secondary", 500)
));
```

Para que se aplique el esquema personalizado, hay que extender `light` o `dark` globales. Todo el proceso consiste en proporcionar a un componente un esquema personalizado y añadirlo después al tema de ese componente.

```scss
$my-custom-schema: extend($light-schema, (
    igx-grid: $custom-grid-schema
));
$custom-theme: grid-theme(
    $palette: $custom-palette,
    $schema: $my-custom-schema
);
```

### Aplicar el tema personalizado
La forma más sencilla de aplicar su tema es con una sentencia `sass` `@include` en el archivo de estilos global:

```scss
@include grid($custom-theme);
```

### Tema acotado al componente

Para que el tema personalizado afecte solo a un componente concreto, puede mover todos los estilos que acaba de definir del archivo de estilos global al archivo de estilos del componente personalizado (incluida la importación del archivo `index`).

De este modo, gracias al [ViewEncapsulation](https://angular.io/api/core/Component#encapsulation) de Angular, sus estilos se aplicarán solo a su componente personalizado.
 <DocsAside type="info">
 Si el componente usa un ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), es necesario atravesar esa encapsulación con `::ng-deep` para dar estilo a la cuadrícula.
 </DocsAside>

 <DocsAside type="info">
 Envuelva la instrucción dentro de un selector `:host` para evitar que sus estilos afecten a elementos situados fuera de nuestro componente:
 </DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid($custom-theme);
    }
}
```
