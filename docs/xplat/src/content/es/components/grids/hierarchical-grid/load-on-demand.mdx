# Carga a demanda de Hierarchical Grid

Ignite UI for {Platform} <ApiLink type="HierarchicalGrid" /> permite un renderizado rápido solicitando la cantidad mínima de datos que hay que recuperar del servidor, de modo que el usuario pueda ver el resultado en pantalla e interactuar con los datos visibles lo antes posible. Inicialmente, solo se recuperan y renderizan los datos de la cuadrícula raíz; solo cuando el usuario expande una fila que contiene una cuadrícula hija recibe los datos de esa cuadrícula hija concreta. Este mecanismo, también conocido como carga bajo demanda, puede configurarse fácilmente para trabajar con cualquier dato remoto.

Este tema muestra cómo configurar la carga bajo demanda creando un proveedor de servicio remoto que se comunica con un servicio remoto ya disponible. Aquí tiene la demostración en funcionamiento; más adelante la recorreremos paso a paso y describiremos el proceso de creación.

## Proveedor de servicio remoto

Primero prepararemos nuestro proveedor de servicios para estar listos para obtener los datos que necesitaríamos para la cuadrícula jerárquica.

### Obtener datos básicos


<PlatformBlock for="Angular">


Nos comunicaremos con nuestro servicio de backend mediante el protocolo HTTP, usando la interfaz XMLHttpRequest que proporcionan los navegadores. Para lograrlo más fácilmente, usaremos el módulo [`HttpClient`](https://angular.io/api/common/http/HttpClient) de Angular, que ofrece una API HTTP de cliente simplificada. Así, para obtener nuestros datos necesitaremos este método sencillo en nuestro servicio:

```typescript
public getData(dataState): Observable<any[]> {
    return this.http.get(this.buildUrl(dataState)).pipe(
        map(response => response),
    );
}
```

Como puede ver, `this.http` será una referencia a nuestro módulo `HttpCLient`, y `buildUrl()` será el método que generará nuestra URL según los datos que hayamos recibido. Asignamos nuestra respuesta y devolvemos un Observable, ya que esto se ejecuta de forma asíncrona. Así podremos suscribirnos más tarde, procesarlo en nuestra aplicación y pasarlo a nuestra cuadrícula.

</PlatformBlock>

export async function getData(dataState: any): Promise<any> {

### Construir nuestra URL de petición

A continuación definiremos cómo construir nuestra URL para la petición GET. Aquí es donde podremos obtener los datos de nuestra cuadrícula principal, pero también los de cualquier cuadrícula hija que contenga. Usaremos los datos de `Customers` de este [tema](https://data-northwind.indigo.design/swagger/index.html) para nuestro nivel raíz, y `Orders` y `Details` para los niveles inferiores. Lo primero que necesitamos es el `key` de nuestra tabla para determinar de dónde obtener los datos de la cuadrícula deseada, la clave principal de la fila padre y su ID único.


<PlatformBlock for="Angular">


Definiremos todo esto en una interfaz llamada `IDataState`. Un ejemplo:

```typescript
export interface IDataState {
    key: string;
    parentID: any;
    parentKey: string;
    rootLevel: boolean;
}

//...
public buildUrl(dataState: IDataState): string {
    let qS = "";
    if (dataState) {
        if (dataState.rootLevel) {
            qS += `${dataState.key}`;
        } else {
            qS += `${dataState.parentKey}/${dataState.parentID}/${dataState.key}`;
        }
    }
    return `${this.url}${qS}`;
}
//...
```

Establecer los datos de cualquier hijo que se haya expandido es un poco diferente. Cuando una fila se expande por primera vez, se renderiza una nueva <ApiLink type="HierarchicalGrid" /> hija para ella, y necesitamos obtener la referencia de la cuadrícula recién creada para establecer sus datos. Por eso cada componente <ApiLink type="RowIsland" /> proporciona el evento `GridCreated`, que se dispara cuando se crea una nueva cuadrícula hija para esa isla de filas concreta. Podemos usarlo para obtener la referencia que necesitamos para la nueva cuadrícula, solicitar sus datos al servicio y aplicarlos.

Podemos usar un método para todas las islas de filas, ya que hemos construido nuestro servicio para que solo necesite información sobre si es el nivel raíz, la clave de la isla de filas, la clave principal de la fila padre y su identificador único. Toda esta información puede obtenerse directamente de los argumentos del evento o de la isla de filas responsable de disparar el evento.

Con esto, la configuración de nuestra aplicación está casi terminada. Este último paso pretende mejorar la experiencia de usuario informando de que los datos siguen cargándose, para que el usuario no tenga que mirar una cuadrícula vacía mientras tanto. Por eso <ApiLink type="HierarchicalGrid" /> admite un indicador de carga que puede mostrarse mientras la cuadrícula está vacía. Si se reciben nuevos datos, el indicador de carga se ocultará y los datos se renderizarán.

### Configuración del indicador de carga

<ApiLink type="HierarchicalGrid" /> puede mostrar un indicador de carga estableciendo la propiedad <ApiLink type="GridBaseDirective" member="isLoading" label="IsLoading" /> en **true** mientras no haya datos. Debemos establecerla inicialmente para la cuadrícula raíz y también al crear nuevas cuadrículas hijas, hasta que se carguen sus datos. Podríamos establecerla siempre en **true** en nuestra plantilla, pero queremos ocultarla y mostrar que la cuadrícula no tiene datos si el servicio devuelve una matriz vacía, estableciéndola en **false**.

En este caso, la versión final de nuestra configuración tendría este aspecto:


<PlatformBlock for="Angular">


```typescript
import { AfterViewInit, Component, ViewChild } from "@angular/core";
import {
    IGridCreatedEventArgs,
    IgxHierarchicalGridComponent,
    IgxRowIslandComponent
} from "igniteui-angular";
import { RemoteLoDService } from "../services/remote-lod.service";

@Component({
    providers: [RemoteLoDService],
    selector: "app-hierarchical-grid-lod",
    styleUrls: ["./hierarchical-grid-lod.component.scss"],
    templateUrl: "./hierarchical-grid-lod.component.html"
})
export class HierarchicalGridLoDSampleComponent implements AfterViewInit {
    @ViewChild("hGrid")
    public hGrid: IgxHierarchicalGridComponent;

    constructor(private remoteService: RemoteLoDService) { }

    public ngAfterViewInit() {
        this.hGrid.isLoading = true;
        this.remoteService.getData({ parentID: null, rootLevel: true, key: "Customers" }).subscribe((data) => {
            this.hGrid.isLoading = false;
            this.hGrid.data = data;
            this.hGrid.cdr.detectChanges();
        });
    }

    public gridCreated(event: IGridCreatedEventArgs, _parentKey: string) {
        const dataState = {
            key: event.owner.key,
            parentID: event.parentID,
            parentKey: _parentKey,
            rootLevel: false
        };
        event.grid.isLoading = true;
        this.remoteService.getData(dataState).subscribe(
            (data) => {
                event.grid.isLoading = false;
                event.grid.data = data;
                event.grid.cdr.detectChanges();
            }
        );
    }
}
```
