# Características de {Platform} {PivotGridTitle}

Los componentes de tabla dinámica y de cuadrícula plana heredan de una base común y, por tanto, comparten algunas funciones y características.

<DocsAside type="info">
Algunas funciones no tienen un comportamiento útil en el contexto de una tabla dinámica y, por tanto, no pueden habilitarse para <ApiLink type="PivotGrid" />. Entre ellas están:
- Operaciones CRUD
- Agrupación
- Anclaje de filas/columnas
- Resúmenes
- Paginación
</DocsAside>

El componente {PivotGridTitle} tiene características y funciones adicionales relacionadas con sus dimensiones, como se describe a continuación.

## Filtrado de dimensiones

Todas las dimensiones (filtros, filas, columnas) pueden filtrarse mediante la interfaz de chips o la API. Esta funcionalidad está integrada y habilitada de forma predeterminada.

<DocsAside type="info">
Puede usar la dimensión de filtrado para excluir valores de datos que no forman parte de la vista dinámica.
</DocsAside>

La interfaz de filtrado puede abrirse mediante el icono de filtro del chip de la dimensión y permite el filtrado al estilo Excel de los valores únicos de la dimensión.

<DocsAside type="info">
Si no hay espacio suficiente para todos los chips de filtrado, {PivotGridTitle} mostrará en un desplegable los que no caben. Los usuarios finales pueden acceder a ellos y manipularlos allí.
</DocsAside>

Las dimensiones también pueden filtrarse inicialmente mediante la configuración de dimensiones en <ApiLink type="PivotGrid" member="pivotConfiguration" label="PivotConfiguration" />, con la propiedad `filter` de la dimensión.
Puede establecerse en un <ApiLink type="GridBaseDirective" member="filteringExpressionsTree" label="FilteringExpressionsTree" /> nuevo con la condición de filtro correspondiente, por ejemplo:

```typescript
public filterExpTree = new FilteringExpressionsTree(FilteringLogic.And);

constructor() {
    this.filterExpTree.filteringOperands = [
        {
            condition: IgxStringFilteringOperand.instance().condition('equals'),
            fieldName: 'SellerName',
            searchVal: 'Stanley'
        }
    ];
}

public pivotConfigHierarchy: IPivotConfiguration = {
    filters: [
        {
            memberName: 'SellerName',
            enabled: true,
            filter: this.filterExpTree
        }
    ]
}
```

</PlatformBlock>


## Ordenación de dimensiones

Los valores de dimensión de `rows` o `columns` pueden ordenarse mediante el chip correspondiente o la API. Esta funcionalidad está integrada y habilitada de forma predeterminada.

La dimensión se ordena al hacer clic en el chip correspondiente, y como resultado los valores de la dimensión se ordenan en sentido ascendente o descendente.

La ordenación también puede aplicarse inicialmente mediante la propiedad `sortDirection` de la definición de la dimensión.

<PlatformBlock for="Angular, WebComponents">

```typescript
public pivotConfigHierarchy: IPivotConfiguration = {
    rows: [
        {
            memberName: 'SellerName',
            enabled: true,
            sortDirection: SortingDirection.Asc
        }
    ]
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```csharp
    var pivotConfiguration = new IgbPivotConfiguration();
    var rowDimension = new IgbPivotDimension() {
        MemberName = "SellerName",
        Enabled = true,
        SortDirection = SortingDirection.Asc
    };
    pivotConfiguration.Rows.Add(rowDimension);
```


</PlatformBlock>


<PlatformBlock for="React">



```tsx
const dimension: IgrPivotDimension = {
    memberName: "SellerName",
    enabled: true,
    sortDirection: SortingDirection.Asc
};
```

</PlatformBlock>


## Cambio de tamaño de dimensiones

Las dimensiones de fila pueden redimensionarse de forma similar al redimensionado de columnas, mediante un indicador de redimensionado situado en el borde derecho de las celdas.
También pueden ajustarse automáticamente de tamaño haciendo doble clic en el indicador de redimensionado, o usando la API correspondiente: <ApiLink type="PivotGrid" member="autoSizeRowDimension" label="AutoSizeRowDimension" />.

También puede establecerse inicialmente un tamaño distinto con la propiedad <ApiLink type="PivotGrid" member="width" label="Width" /> disponible en la definición de la dimensión:

<PlatformBlock for="Angular, WebComponents">

```typescript
public pivotConfigHierarchy: IPivotConfiguration = {
    rows: [
        {
            memberName: 'Country',
            enabled: true,
            width: '400px'
        }
    ]
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```csharp
    var pivotConfiguration = new IgbPivotConfiguration();
    var rowDimension = new IgbPivotDimension() {
        MemberName = "SellerName",
        Enabled = true,
        Width = "400px"
    };
    pivotConfiguration.Rows.Add(rowDimension);
```


</PlatformBlock>



<PlatformBlock for="React">



```tsx
const igrPivotDimension2: IgrPivotDimension = {
    memberName: "SellerName",
    enabled: true,
```

## Selección de dimensiones

{PivotGridTitle} admite la selección simple, que se habilita igual que en la cuadrícula base. Por ejemplo:


<PlatformBlock for="Angular">


```html
<{PivotGridSelector} #grid1 [rowSelection]="'single'" [data]="data" [pivotConfiguration]="pivotConfigHierarchy">
</{PivotGridSelector}>
```

</PlatformBlock>


<PlatformBlock for="WebComponents">
```html
<{PivotGridSelector} id="grid" row-selection="single">
</{PivotGridSelector}>
```
</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<{PivotGridSelector} PivotConfiguration="PivotConfiguration"
        Data="PivotSalesData"
        Name="grid"
        RowSelection=GridSelectionMode.Single
        @ref="grid">
</{PivotGridSelector}>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrPivotGrid data={pivotData} pivotConfiguration={pivotConfiguration} rowSelection="single">
</IgrPivotGrid>
```

</PlatformBlock>

Si hay varias dimensiones de fila o de columna que crean grupos que abarcan varias filas o columnas, la selección se aplica a todas las celdas que pertenecen al grupo seleccionado.

## Modo supercompacto
El componente <ApiLink type="PivotGrid" /> proporciona una entrada <ApiLink type="PivotGrid" member="superCompactMode" label="SuperCompactMode" />. Es adecuada para casos que requieren que haya muchas celdas en pantalla a la vez. Si se habilita, la opción ignora la variable CSS `--ig-size` de {PivotGridTitle}. Habilitar <ApiLink type="PivotGrid" member="superCompactMode" label="SuperCompactMode" /> también establece `--ig-size` en `small` para cada componente hijo (como <ApiLink pkg="core" type="Chip" />) que no tenga la opción <ApiLink type="PivotGrid" member="superCompactMode" label="SuperCompactMode" />.

<PlatformBlock for="Angular">


```html
<{PivotGridSelector} [superCompactMode]="true"></{PivotGridSelector}>
```

</PlatformBlock>


<PlatformBlock for="WebComponents">
```html
<{PivotGridSelector} super-compact-mode="true"></{PivotGridSelector}>
```
</PlatformBlock>

```razor
<{PivotGridSelector} SuperCompactMode=true></{PivotGridSelector}>
```

</PlatformBlock>

## Columna de resumen adicional

Cuando una dimensión de `column` define una jerarquía, {PivotGridTitle} mostrará una columna adicional de resumen/total, que acumula las agregaciones de todas las columnas dentro del grupo. Cuando el grupo está contraído, solo permanece visible la columna de resumen. Y cuando el grupo está expandido, la columna de resumen adicional aparece al final del grupo.

## Interacciones

### Navegación por teclado

La navegación por teclado en `{PivotGridSelector}` funciona de forma similar a la de `{GridSelector}`. El {PivotGridTitle} se divide en tres áreas: `rows`, `columns` y `values`. Las áreas de `rows` y `columns` se consideran encabezados a efectos de navegación, mientras que el área de `values` es el cuerpo.
Las teclas de flecha permiten desplazar el elemento activo solo dentro del área actual.

### Arrastrar y soltar dimensiones
Las dimensiones se representan mediante chips, que pueden arrastrarse y soltarse.
Todos los chips pueden cambiar su orden dentro de su área mediante arrastrar y soltar.
Los chips de `rows`, `column` y `filter` (chips de dimensión) pueden moverse desde cualquiera de esas áreas a cualquier otra y en cualquier posición.
Los chips de estas áreas no pueden moverse al área `values`, y los chips del área `values` no pueden moverse a ninguna de las áreas de dimensión.

<DocsAside type="info">
Los chips de {PivotGridTitle} no pueden moverse al selector de datos dinámicos, y los elementos del selector de datos dinámicos no pueden moverse a {PivotGridTitle}.
</DocsAside>
