# Descripción general de la cuadrícula dinámica {Platform}

La cuadrícula dinámica {Platform} se usa para resumir y representar datos multidimensionales voluminosos en un formato de tabla cruzada. El resumen de datos puede ordenarse, agruparse o filtrarse de forma fácil y rápida. Estos datos pueden incluir sumas, promedios y otras estadísticas. Los usuarios finales pueden modificar la disposición de la tabla dinámica mediante operaciones de arrastrar y soltar, según sus necesidades.

La cuadrícula dinámica {Platform} presenta los datos en una tabla dinámica y ayuda a los usuarios a realizar análisis complejos sobre el conjunto de datos proporcionado. Este sofisticado control de cuadrícula dinámica se usa para organizar, resumir y filtrar grandes volúmenes de datos, que después se muestran en formato de tabla cruzada. Las características clave de una cuadrícula dinámica de {Platform} son las dimensiones de fila, las dimensiones de columna, las agregaciones y los filtros.

El <ApiLink type="PivotGrid" /> permite a los usuarios configurar y mostrar sus datos en una estructura de tabla dinámica multidimensional.
Las filas y columnas representan grupos de datos distintos, y los valores de las celdas de datos representan agregaciones. Esto permite realizar análisis de datos complejos a partir de un conjunto de datos plano sencillo. El <ApiLink type="PivotGrid" /> es una tabla dinámica con muchas funciones que facilita la configuración de las distintas dimensiones y valores, así como operaciones de datos adicionales sobre ellos, como el filtrado y la ordenación.

Se define mediante tres dimensiones principales: **filas**, **columnas** y **valores**. Las **filas** y las **columnas** definen la estructura agrupada que se muestra en las filas y columnas de la cuadrícula. Los **valores** definen los campos de agregación y la agregación que se usará para calcular y mostrar los valores relacionados de los grupos.

También puede definirse un filtro mediante la propiedad de configuración **filters**. Puede usarse para campos que no quiere añadir como dimensión o como valor, pero cuyos valores de miembro relacionados quiere filtrar mediante la interfaz.

### Configuración de dimensiones

Cada configuración de dimensión básica requiere un <ApiLink type="PivotDimension" member="memberName" label="MemberName" /> que coincida con un campo de los **datos** proporcionados.

Pueden definirse varias dimensiones hermanas, lo que crea un grupo anidado más complejo en el área de dimensiones de fila o de columna correspondiente.

Las dimensiones pueden reordenarse o moverse de un área a otra mediante sus chips correspondientes, usando arrastrar y soltar.

Una dimensión también puede describir una jerarquía expandible mediante la propiedad <ApiLink type="PivotDimension" member="childLevel" label="ChildLevel" />, por ejemplo:

### Configuración de valores

La configuración de un valor requiere un **miembro** que coincida con un campo de los **datos** proporcionados, o puede definir una función **agregadora** personalizada para escenarios más complejos. De forma predeterminada hay 4 agregaciones predefinidas que pueden usarse según el tipo de datos del campo:

- `PivotNumericAggregate`: para campos numéricos.
  Contiene las siguientes funciones de agregación: `SUM`, `AVG`, `MIN`, `MAX`, `COUNT`.
- `PivotDateAggregate`: para campos de fecha.
  Contiene las siguientes funciones de agregación: `LATEST`, `EARLIEST`, `COUNT`.
- `PivotTimeAggregate`: para campos de hora.
  Contiene las siguientes funciones de agregación: `LATEST`, `EARLIEST`, `COUNT`.
- `PivotAggregate`: para cualquier otro tipo de datos. Es la agregación base.
  Contiene la siguiente función de agregación: `COUNT`.

La función de agregación actual puede cambiarse en tiempo de ejecución usando el menú desplegable del chip de valor. De forma predeterminada, muestra una lista de las agregaciones disponibles según el tipo de datos del campo. También puede establecerse una lista personalizada de agregaciones mediante la propiedad <ApiLink type="PivotValue" member="aggregateList" label="AggregateList" />, por ejemplo:

### Propiedad Enable

<ApiLink type="PivotGrid" member="pivotConfiguration" label="PivotConfiguration" /> es la interfaz que describe el estado actual del componente <ApiLink type="PivotGrid" />. Con ella, el desarrollador puede declarar campos de los datos como **filas**, **columnas**, **filtros** o **valores**. La configuración permite habilitar o deshabilitar cada uno de estos elementos por separado. Solo los elementos habilitados se incluyen en el estado actual de la cuadrícula dinámica. El componente <ApiLink type="PivotDataSelector" /> usa la misma configuración y muestra una lista de todos los elementos, habilitados y deshabilitados. Para cada uno de ellos hay una casilla de verificación en el estado adecuado. Los usuarios finales pueden ajustar fácilmente el estado de la tabla dinámica alternando los distintos elementos con estas casillas.
La propiedad `Enable` controla si un <ApiLink type="PivotDimension" /> o un <ApiLink type="PivotValue" /> está activo y participa en la vista dinámica que renderiza la cuadrícula dinámica.

### Generar la configuración automáticamente
La propiedad <ApiLink type="PivotGrid" member="autoGenerateConfig" label="AutoGenerateConfig" /> genera automáticamente dimensiones y valores a partir de los campos del origen de datos:

- Campos numéricos:
  - Se crea como <ApiLink type="PivotValue" /> usando el agregador `PivotNumericAggregate.sum`.
  - Se añade a la colección de valores y se habilita de forma predeterminada.

- Campos no numéricos:
  - Se crea como <ApiLink type="PivotDimension" />.
  - Desactivado de forma predeterminada.
  - Se añade a la colección de columnas.

- Campos de fecha (solo está habilitado el primer campo `date`; los demás campos `date` aplican la regla de campos no numéricos):
  - Se crea como <ApiLink type="PivotDateDimension" />
  - Habilitado de forma predeterminada
  - se añade a la colección de filas.

Esta función permite a los desarrolladores crear rápidamente una vista dinámica sin especificar manualmente las dimensiones y los valores. Con un selector de pivot junto a la cuadrícula dinámica, los usuarios pueden habilitar y reordenar las dimensiones y los valores según sea necesario.

### Claves de cálculo dinámico

La cuadrícula dinámica permite personalizar los campos de clave de objeto que usa para sus cálculos dinámicos.
Abajo puede ver con más detalle cómo se usan, en datos de ejemplo, donde ya se ven los valores agregados:

```json
[
  {
    ProductCategory: 'All', AllProducts: 'All Products', All: 1000, 'All-Bulgaria': 774, 'All-USA': 829, 'All-Uruguay': 524,
    AllProducts_records: [
      { ProductCategory: 'Clothing', 'All-Bulgaria': 774, 'All-USA': 296, 'All-Uruguay': 456 },
      { ProductCategory: 'Bikes', 'All-Uruguay': 68 },
      { ProductCategory: 'Accessories', 'All-USA': 293 },
      { ProductCategory: 'Components', 'All-USA': 240 }
    ]
  }
];
```

Todas estas claves se almacenan en la propiedad **pivotKeys**, que forma parte de <ApiLink type="PivotGrid" member="pivotConfiguration" label="PivotConfiguration" /> y puede usarse para cambiar las claves dinámicas predeterminadas.
- **children**: campo que almacena los hijos para construir la jerarquía. Representa un mapa de los valores agrupados y de todos los pivotGridRecords basados en ese valor. Puede utilizarse en escenarios muy específicos en los que haya que hacer algo al crear las jerarquías. No es necesario cambiarlo para un uso habitual.
- **records**: campo que almacena una referencia a los registros de datos originales. Puede verse en el ejemplo anterior: **AllProducts_records**. Evite definir en los datos campos con el mismo nombre que esta propiedad. Si sus registros de datos tienen una propiedad **records**, puede especificar un valor distinto y único para ella usando **pivotKeys**.
- **aggregations**: campo que almacena los valores de agregación. Se aplica al crear las jerarquías y, en escenarios habituales, no debe modificarse.
- **level**: campo que almacena el nivel de dimensión según su jerarquía. Evite definir en los datos campos con el mismo nombre que esta propiedad. Si sus registros de datos tienen una propiedad **level**, puede especificar un valor distinto y único para ella usando **pivotKeys**.
- **columnDimensionSeparator**: separador usado al generar los valores únicos de campo de columna. Es el guion (**-**) del valor de ejemplo: **All-Bulgaria**.
- **rowDimensionSeparator**: separador usado al generar los valores únicos de campo de fila. Se usa al crear los campos **records** y **level**.

Los valores predeterminados son:

<PlatformBlock for="Angular, WebComponents">
```typescript
{
  aggregations: 'aggregations',
  records: 'records',
```

## Problemas conocidos y limitaciones

|Limitación|Descripción|
|--- |--- |
| No se admite establecer columnas de forma declarativa. | La cuadrícula dinámica genera sus columnas a partir de la configuración de <ApiLink type="PivotGrid" member="columns" label="Columns" />, por lo que no se admite establecerlas de forma declarativa, como en la cuadrícula base. Estas columnas se descartan. |
| Establecer valores duplicados en las propiedades <ApiLink type="PivotDimension" member="memberName" label="MemberName" /> o <ApiLink type="PivotValue" member="member" label="Member" /> de las dimensiones/valores. | Estas propiedades deben ser únicas para cada dimensión/valor. La duplicación puede provocar la pérdida de datos en el resultado final. |
| La selección de filas solo se admite en modo **Single**. | Actualmente no se admite la selección múltiple. |

<PlatformBlock for="Angular">
| La combinación de miembros de dimensión distingue entre mayúsculas y minúsculas | La cuadrícula dinámica crea grupos y combina los valores iguales (distinguiendo mayúsculas y minúsculas). Pero las dimensiones proporcionan <ApiLink type="PivotDimension" member="memberFunction" label="MemberFunction" /> y esto puede cambiarse allí; el resultado de <ApiLink type="PivotDimension" member="memberFunction" label="MemberFunction" /> se compara y se usa como valor mostrado.|
</PlatformBlock>
