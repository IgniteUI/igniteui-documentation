# Tema de la cuadrícula {Platform}
Con el CSS de temas de {Platform}, la cuadrícula de {ProductName} puede personalizarse fácilmente para que coincida con la identidad de su marca.
Además de los temas y paletas predefinidos, puede personalizar aún más el aspecto de su cuadrícula de datos usando un conjunto alternativo de propiedades personalizadas CSS.

<Sample src="/grids/grid/overview-dark" height={500} alt="Ejemplo de tema oscuro de la cuadrícula {Platform}" />



<PlatformBlock for="Blazor">
```razor
<head>
    <link href="_content/IgniteUI.Blazor/themes/grid/dark/bootstrap.css" rel="stylesheet" />
</head>
```
</PlatformBlock>

| --grid-elevation                         | número entre 0 y 24      | El nivel de elevación que se usará para la cuadrícula                                                 |
