# Descripción general del filtrado de la cuadrícula {Platform}

La tabla / cuadrícula de datos {ProductName} incluye filtrado por columna, con una fila de filtro y una API que permiten realizar condiciones de ordenación expresivas según el tipo de datos de la columna filtrada.

Como se ve arriba, al establecer la propiedad `FilterUIType` en FilterRow se habilita en la interfaz de usuario el filtrado de registros, donde el usuario puede especificar criterios de filtro para filtrar los registros. Los registros que no coincidan con los criterios de filtro especificados se ocultarán.

El filtrado también está disponible en la interfaz de opciones de columna: al pasar el cursor sobre un campo y hacer clic en los puntos suspensivos verticales. Esto se logra al establecer `FilterUIType` en ColumnOptions. Consulte el ejemplo siguiente.

## Operadores de filtro

Las columnas pueden tener un `FilterOperand` personalizado que aparecerá en el desplegable de operandos de la fila de filtro. El requisito clave es asegurarse de que el operando tenga un `DisplayName` y de usar el evento `FilterRequested` del operando para aplicar un `FilterFactory`, que es el responsable de asignar el operador y el valor con los que se filtrará la columna, por ejemplo, StartsWith con el valor "A".

Además, la propiedad `FilterLogicalOperator` de la cuadrícula indica cómo se combinan los filtros de distintos campos:

- Operador lógico `And`. Para que haya una coincidencia correcta, todas las condiciones deben cumplirse.
- Operador lógico `Or`. Para que haya una coincidencia correcta, al menos una de las condiciones debe cumplirse.
