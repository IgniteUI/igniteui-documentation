# Descripción general del selector de columnas de la cuadrícula {Platform}

La cuadrícula de datos {ProductName} permite mostrar y ocultar columnas desde la interfaz mediante el componente `DataGridToolbar` o mediante el componente `ColumnChooser`, que ofrece flexibilidad para colocarlo en cualquier lugar de la página. La propiedad `IsHidden` de las columnas también puede usarse para ocultar o mostrar rápidamente una sola columna mediante programación en la generación manual de columnas, y el valor de `IsHidden` se reflejará en el componente `ColumnChooser`. Cada enfoque puede usarse indistintamente para cambiar el estado visible de las columnas.

## Interfaz del selector de columnas de la barra de herramientas

La interfaz del selector de columnas es accesible dentro del componente `DataGridToolbar`, independiente de la cuadrícula. Para ello, solo tenemos que establecer la propiedad `ColumnChooser` de la barra de herramientas en true. La barra de herramientas mostrará un `Button` que, al hacer clic, muestra la interfaz del selector de columnas. Este botón también muestra el total de columnas ocultas. Si no se crea la barra de herramientas, habilitar la propiedad `ColumnChooser` no tendrá ningún efecto y ocultará el botón.

`DataGridToolbar` proporciona propiedades adicionales, como añadir un título a la barra de herramientas mediante la propiedad `ToolbarTitle`, colocar texto en `Button` estableciendo la propiedad `ColumnChooserText`, y añadir un encabezado de título a la interfaz del selector de columnas estableciendo `ColumnChooserTitle`.

El selector de columnas puede configurarse con animaciones estableciendo las propiedades `ColumnHidingAnimationMode` y `ColumnShowingAnimationMode` de la cuadrícula.
