# Localización de la cuadrícula {Platform}

La tabla / cuadrícula de datos {ProductName} admite la localización de las cadenas de recursos específicas del menú emergente de opciones de columna y de los resúmenes. Tenga en cuenta que esto no está pensado para traducir los datos ni es capaz de hacerlo.

<PlatformBlock for="Blazor">
La cuadrícula de datos contiene <ApiLink raw type="DataGrid" member="SetCustomizedStringAsync" /> para asignar cadenas asociadas a las opciones de columna. La propiedad `ActualDataSource` de la cuadrícula también tiene este método para asignar las cadenas de recursos necesarias para los resúmenes.
</PlatformBlock>
