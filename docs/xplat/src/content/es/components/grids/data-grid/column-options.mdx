# Descripción general de las opciones de columna de la cuadrícula {Platform}

La cuadrícula de datos {ProductName} permite agrupar, ocultar, ordenar, mover, anclar, filtrar y ordenar columnas directamente desde una interfaz expuesta en el encabezado de cada columna.

Para habilitar la interfaz de opciones de columna, puede establecer la propiedad `IsColumnOptionsEnabled` de la cuadrícula en true.

## Configuraciones de opciones de columna

El filtrado puede activarse o desactivarse por columna estableciendo la propiedad `IsFilteringEnabled` de la columna. Si se establece en true o false, se mostrará u ocultará la sección de filtrado en la interfaz de opciones de la columna.

La ordenación puede activarse o desactivarse para toda la cuadrícula si se aplica la propiedad `HeaderClickAction`. Por ejemplo, si se establece en `None`, se eliminará por completo la ordenación de la cuadrícula, lo que se reflejará en la interfaz de opciones de cada columna. Y si se establece en `SortByOneColumnOnly`, por ejemplo, seguirá permitiendo ordenar una columna a la vez.

## Fragmento de código

El código siguiente muestra cómo habilitar mediante programación la interfaz de opciones de columna y ajustar el filtrado y la ordenación en la interfaz de opciones de columna, modificando la cuadrícula y la columna.

```json-snippet source="/grids/data-grid/column-options"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "ProductOrders",
            "headerClickAction": "SortByOneColumnOnly",
            "isColumnOptionsEnabled": true,
            "height": "100%",
            "width": "100%",
            "columns": [
                {
                    "type": "TextColumn",
                    "field": "ID",
                    "isFilteringEnabled": false
                }
            ],
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
