# Resaltado de la cuadrícula {Platform}

La tabla / cuadrícula de datos {ProductName} admite la configuración del aspecto del resaltado de filas.

<div class="divider--half"></div>

## Descripción general

El resaltado de registros de los datos de {Platform} puede activarse o desactivarse estableciendo la propiedad booleana `IsRowHoverEnabled` de la cuadrícula {Platform}. Tenga en cuenta que esta opción está habilitada de forma predeterminada.

Además, el color puede configurarse estableciendo la propiedad de cadena `RowHoverBackground` en un valor hexadecimal.

## Fragmento de código

A continuación se muestra cómo habilitar el resaltado de filas en la cuadrícula de datos {Platform} y aplicar el color azul:

```json-snippet source="/grids/data-grid/row-highlighting"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "isRowHoverEnabled": true,
            "rowHoverBackground": "#bfbfff",
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
