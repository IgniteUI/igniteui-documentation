# Combinación de celdas de la cuadrícula {Platform}

La tabla / cuadrícula de datos {ProductName} admite la combinación de celdas. Puede optar por activarla y detectar cuándo los registros hermanos adyacentes de una columna concreta contienen el mismo valor. Mientras las celdas no estén activas, seleccionadas o en modo de edición, el valor se muestra abarcando las celdas.

## Descripción general

La combinación de celdas en la cuadrícula de datos {Platform} puede configurarse mediante la opción `MergedCellMode` de toda la cuadrícula {Platform} o de columnas individuales. Esta propiedad puede establecerse en una de las siguientes opciones, que se enumeran a continuación:

- `Never`: la cuadrícula o la columna nunca combinará celdas. Este es el comportamiento predeterminado.
- `Always`: la cuadrícula o la columna siempre intentará combinar celdas.
- `OnlyWhenSorted`: la cuadrícula o la columna solo intentará combinar celdas cuando una columna esté ordenada.

Tenga en cuenta que, independientemente del valor de esta propiedad, las celdas solo pueden combinarse entre registros hermanos.

La combinación de celdas puede evaluarse según si los datos tienen formato o no, usando la propiedad `MergedCellEvaluationCriteria`. Esto se aplica a toda la cuadrícula o a columnas individuales y puede establecerse en una de las siguientes opciones, que se enumeran a continuación:

- `RawValue`: combina celdas de filas adyacentes cuando los valores sin formato de las celdas son iguales. Este es el valor predeterminado.
- `FormattedText`: combina celdas de filas adyacentes cuando el valor con formato de las celdas es igual.
