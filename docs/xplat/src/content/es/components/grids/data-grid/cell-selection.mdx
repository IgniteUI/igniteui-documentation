## Descripción general

La selección en la cuadrícula de datos {Platform} se habilita a nivel de fila y de celda, y puede configurarse mediante la opción `SelectionMode` de la cuadrícula {Platform}. Esta propiedad admite cinco opciones diferentes, que se enumeran a continuación:

- `None`: la selección no está habilitada.
- `SingleCell`: la selección de una sola celda está habilitada.
- `SingleRow`: la selección de una sola fila está habilitada.
- `MultipleCell`: la selección de varias celdas está habilitada.
- `MultipleRow`: la selección de varias filas está habilitada.
- `RangeCell`: la selección de un rango de varias celdas haciendo clic y arrastrando está habilitada.

`SelectionBehavior` tiene por defecto `ModifierBased`, donde solo se selecciona una fila o celda a la vez y se requieren teclas modificadoras (CTRL) para seleccionar varios elementos. `SelectionBehavior` establecido en `Toggle` permitirá seleccionar varias filas o celdas solo con un clic.

`MultipleRow` incluye la siguiente funcionalidad:
- Haga clic y arrastre para seleccionar filas
- <kbd>SHIFT</kbd> y haga clic para seleccionar varias filas.
- Mantenga pulsado <kbd>SHIFT</kbd> y pulse las teclas de flecha <kbd>↑</kbd> + <kbd>↓</kbd> para seleccionar varias filas.

Pulsar la barra espaciadora alterna la selección de la fila activa mediante `MultipleRow` o `SingleRow`.
