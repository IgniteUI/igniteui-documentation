# Anclaje de filas de {Platform}

 La tabla / cuadrícula de datos {ProductName} permite el anclaje de filas usando claves o los elementos del origen de datos subyacente. Cuando una fila se fija, se duplica en la parte superior de la cuadrícula de datos {PlatformLower} y permanece fija allí con un fondo gris claro, mientras que su fila real se renderiza con baja opacidad.

## Ejemplo de anclaje de filas de {Platform}

Puede anclar filas en la cuadrícula de datos {Platform} añadiendo el elemento de datos subyacente de la fila de destino a la colección pinnedItems de la cuadrícula {Platform}.

## Fragmento de código

<PlatformBlock for="React">

```ts
public onGridRef(grid: IgrDataGrid) {
    this.grid = grid;
    this.grid.pinnedItems.add(this.data[2]);
    this.grid.pinnedItems.add(this.data[4]);
}
```
