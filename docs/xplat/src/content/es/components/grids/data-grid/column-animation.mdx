# Animaciones de columnas de la cuadrícula {Platform}

La tabla / cuadrícula de datos {ProductName} admite animaciones de columnas durante eventos como la ocultación o el movimiento de columnas. Cuando se establece la animación de columnas en la cuadrícula de datos {Platform}, la animación correspondiente se disparará para todas las celdas de esa columna.

## Propiedades de animación

A continuación se enumera y describe cada propiedad de animación de columnas:

- `ColumnAddingAnimationMode`: cuando se añade una columna, puede hacer que el encabezado de la columna y sus celdas se deslicen desde la izquierda, la derecha, arriba o abajo. También hay opciones para que aparezca con un efecto de desvanecimiento, así como deslizándose y desvaneciéndose a la vez.
- `ColumnExchangingAnimationMode`: cuando se intercambia una columna, puede hacer que el encabezado de la columna intercambiada y sus celdas se deslicen hacia la izquierda, la derecha, arriba o abajo. También hay opciones para que se desvanezca, así como para que se deslice y desvanezca.
- `ColumnHidingAnimationMode`: cuando se oculta una columna, puede hacer que el encabezado de la columna y sus celdas se deslicen hacia fuera, hacia la izquierda, la derecha, arriba o abajo. También hay opciones para que se desvanezca, así como para que se deslice y desvanezca.
- `ColumnMovingAnimationMode`: cuando se mueve una columna, puede hacer que el encabezado de la columna y sus celdas se deslicen sobre su posición.
- `ColumnPropertyUpdatingAnimationMode`: cuando cambia una propiedad de la columna, puede hacer que ese cambio de propiedad se anime mediante interpolación o interpolación profunda de su cambio.
- `ColumnShowingAnimationMode`: cuando se añade una columna, puede hacer que el encabezado de la columna y sus celdas se deslicen desde la izquierda, la derecha, arriba o abajo. También hay opciones para que aparezca con un efecto de desvanecimiento, así como deslizándose y desvaneciéndose a la vez.
