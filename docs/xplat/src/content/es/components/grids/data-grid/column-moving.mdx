# Descripción general del movimiento de columnas de la cuadrícula {Platform}

La cuadrícula de datos {ProductName} permite mover columnas, lo que le ofrece flexibilidad para decidir cómo mostrar sus columnas en cuanto al orden de las columnas visibles.

El movimiento de columnas en la cuadrícula de datos {ProductName} está activado de forma predeterminada y puede controlarse estableciendo la propiedad `ColumnMovingMode` de la cuadrícula. Esta propiedad tiene dos opciones: `Deferred` o `None`. `Deferred` permitirá el movimiento de columnas, mientras que `None` deshabilitará el movimiento de columnas en toda la cuadrícula.

Cuando el movimiento de columnas se establece en `Deferred`, aparecerá un separador mientras se mueve una columna. Al mover una columna, cuando se suelta el puntero del ratón, la columna movida ocupará el lugar de la columna situada a la derecha del separador. Este separador también puede personalizarse en anchura y color mediante las propiedades `ColumnMovingSeparatorWidth` y `ColumnMovingSeparatorBackground`, respectivamente.

También puede animar los movimientos de las columnas si lo desea. Esto se hace estableciendo la propiedad `ColumnMovingAnimationMode` de la cuadrícula. Las animaciones no están activadas de forma predeterminada.

## Fragmento de código

A continuación se muestra cómo implementar el movimiento de columnas en la cuadrícula de datos {ProductName} con movimiento de columnas diferido, animaciones habilitadas y un separador de 5 px de ancho:

```json-snippet source="/grids/data-grid/column-moving"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "columnMovingMode": "Deferred",
            "columnMovingAnimationMode": "SlideOver",
            "columnMovingSeparatorWidth": 5,
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
