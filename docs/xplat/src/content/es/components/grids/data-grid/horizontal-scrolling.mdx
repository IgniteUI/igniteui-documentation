# Desplazamiento horizontal de {Platform}

La tabla / cuadrícula de datos {ProductName} admite el desplazamiento horizontal, que se habilita estableciendo el ancho total de las columnas por encima del ancho de la cuadrícula de datos {Platform}.

## Establecer el ancho predeterminado de las columnas

```json-snippet id="scrolling" source="/grids/data-grid/column-scrolling"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "defaultColumnMinWidth": 120,
            "height": "100%",
            "width": "100%",
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
