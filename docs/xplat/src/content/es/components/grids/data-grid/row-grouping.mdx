# Agrupación de filas de {Platform}

<PlatformBlock for="Angular,React,WebComponents,Blazor">

La tabla / cuadrícula de datos {ProductName} le permite agrupar filas en un grupo de filas con 'encabezado fijo'. Es similar a la función Group By de Microsoft Outlook, una forma sencilla de agrupar visualmente los datos según sus propios criterios.

## Área Group-By

Establezca la propiedad `IsGroupByAreaVisible` de DataGrid en True, como se muestra en el ejemplo anterior, para la interfaz de usuario. El área de group-by ofrece a los usuarios más opciones para agrupar y ordenar columnas sin interactuar directamente con DataGrid. Los grupos pueden colocarse y reordenarse según las necesidades del usuario. Esta área también se rellena cuando se añaden columnas mediante programación como `GroupDescriptions` en DataGrid.

## Grupos jerárquicos

La propiedad `GroupHeaderDisplayMode` permite que los grupos sean jerárquicos. De forma predeterminada, cada descripción de grupo que se añade se agrega junta. Si se establece `GroupHeaderDisplayMode` en `Split`, se creará un encabezado de sección para cada grupo definido en la propiedad `GroupDescriptions` de `DataGrid`.


```json-snippet id="groupHeaderDisplayMode" source="/grids/data-grid/row-group-descriptions" channel="code"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "groupHeaderDisplayMode": "Split",
            "height": "100%",
            "width": "100%"
        }
    }
}
```


## Grupos plegables

Además, `DataGrid` puede mostrar un conmutador en cada sección de grupo para que el usuario final expanda o contraiga los datos agrupados mediante la propiedad `IsGroupCollapsable`.

```json-snippet id="isGroupCollapsable" source="/grids/data-grid/row-grouping" channel="code"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "isGroupCollapsable": true,
            "height": "100%",
            "width": "100%"
        }
    }
}
```

```json-snippet ref="isGroupCollapsable" source="/grids/data-grid/row-grouping"
```

## Resumen

Para su comodidad, todos los fragmentos de código anteriores se combinan en un único bloque de código que puede copiar fácilmente en su proyecto.


```json-snippet id="groupingSummary" source="/grids/data-grid/row-group-descriptions" channel="code"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "isGroupCollapsable": true,
            "groupHeaderDisplayMode": "Split",
            "height": "100%",
            "width": "100%",
            "groupDescriptions": [
                {
                    "type": "ColumnGroupDescription",
                    "field": "Country",
                    "displayName": "Location",
                    "sortDirection": "Descending"
                },
                {
                    "type": "ColumnGroupDescription",
                    "field": "City",
                    "displayName": "City"
                },
                {
                    "type": "ColumnGroupDescription",
                    "field": "Income",
                    "displayName": "Income"
                }
            ]
        }
    }
}
```
