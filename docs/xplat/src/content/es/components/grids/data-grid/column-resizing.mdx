# Cambio de tamaño de columnas de la cuadrícula {Platform}

La cuadrícula de datos {ProductName} permite cambiar el tamaño de las columnas, lo que le ofrece flexibilidad para decidir cómo mostrar sus columnas según el ancho de cada una.

El cambio de tamaño de columnas en la DataGrid {ProductName} está activado de forma predeterminada y puede controlarse mediante la propiedad `ColumnResizingMode` de la cuadrícula. Esta propiedad tiene tres opciones. Cada opción se explica a continuación:

- `Deferred`: la opción predeterminada. Al cambiar el tamaño, aparecerá un separador que muestra cuánto se hará más grande o más pequeña la columna al redimensionarla.
- `Immediate`: al cambiar el tamaño no habrá separador. El ancho de la columna seguirá el puntero mientras arrastra el borde de la columna y se redimensionará en consecuencia.
- `None`: las columnas no pueden cambiar de tamaño.

Cuando el cambio de tamaño de columnas se establece en `Deferred`, el separador que aparece puede modificarse en color y ancho mediante las propiedades `ColumnResizingSeparatorBackground` y `ColumnResizingSeparatorWidth` de la cuadrícula, respectivamente.

También puede animar las columnas al cambiar de tamaño, pero solo cuando el modo de cambio de tamaño está establecido en `Deferred`. Esto se hace estableciendo la propiedad `ColumnResizingAnimationMode` en `Interpolate`.

Puede determinarse individualmente si cada columna de la cuadrícula puede cambiar de tamaño. Si desea habilitar o deshabilitar el cambio de tamaño en una columna concreta, puede establecer la propiedad <b>IsResizingEnabled</b> de esa columna.

Al cambiar el tamaño de una columna de ancho star, esa columna pasará a ser una columna de ancho fijo.

## Fragmento de código

El fragmento de código siguiente muestra cómo implementar el cambio de tamaño de columnas en la cuadrícula de datos {Platform}, donde la columna <b>Street</b> en este caso no podrá cambiar de tamaño. En este caso, el separador de cambio de tamaño tendrá 5 píxeles de ancho y las columnas que pueden cambiar de tamaño se animarán también al redimensionarse:

```json-snippet source="/grids/data-grid/column-resizing"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "DataGrid",
            "name": "grid",
            "dataSourceRef": "EmployeesSalesData",
            "autoGenerateColumns": false,
            "columnResizingMode": "Deferred",
            "columnResizingAnimationMode": "Interpolate",
            "columnResizingSeparatorWidth": 5,
            "height": "100%",
            "width": "100%",
            "columns": [
                {
                    "type": "TextColumn",
                    "field": "FirstName"
                },
                {
                    "type": "TextColumn",
                    "field": "LastName"
                },
                {
                    "type": "TextColumn",
                    "field": "Street",
                    "isResizingEnabled": false
                },
                {
                    "type": "TextColumn",
                    "field": "City"
                }
            ],
            "$setInCode": {
                "dataSourceRef": [
                    "webComponents"
                ]
            }
        }
    }
}
```
