# La cuadrícula de datos {Platform} más rápida


<PlatformBlock for="React">



Una cuadrícula de datos o tabla de datos {Platform} es un componente que se usa para mostrar datos tabulares en una serie de filas y columnas. Las cuadrículas de datos, también conocidas como tablas, son muy conocidas en el mundo del escritorio con software popular como Microsoft Excel. Aunque las cuadrículas llevan mucho tiempo disponibles en plataformas de escritorio, solo recientemente se han incorporado a las interfaces de aplicaciones web, como la interfaz de {Platform}. Las cuadrículas y tablas modernas pueden ser complejas e incluir una serie de funciones, como el enlace de datos, la edición, el filtrado al estilo de Excel, la ordenación personalizada, la agrupación, la reordenación de filas, la inmovilización de filas y columnas, la agregación de filas y la exportación a formatos Excel, CSV y PDF.

</PlatformBlock>

<PlatformBlock for="WebComponents">

Una cuadrícula de datos {Platform}, también conocida como tabla de datos {Platform}, es un componente de visualización de datos que le permite enlazar y mostrar sus datos como una serie de filas y columnas. Son algo nuevas en el mundo de las interfaces de aplicaciones web, aunque llevan mucho tiempo disponibles en plataformas de escritorio con muchas formas diferentes, por ejemplo, Microsoft Excel. Estas cuadrículas y tablas suelen tener la capacidad de ser muy complejas, con funciones como la selección de celdas y filas, el filtrado, la edición, la ocultación de filas y columnas, los resúmenes de columnas, la búsqueda y la capacidad de mostrar sus datos en columnas de tipo específico.

</PlatformBlock>

<PlatformBlock for="Blazor">

Una tabla de datos {Platform}, más conocida como cuadrícula de datos {Platform}, es un componente que le permite visualizar sus datos enlazados como una serie de filas y columnas. Estas cuadrículas de datos llevan bastante tiempo disponibles en plataformas relacionadas con el escritorio, como WPF y Windows Forms, pero solo recientemente se han vuelto disponibles para el desarrollo de aplicaciones web. Las aplicaciones web modernas usan tablas y cuadrículas de datos con muchas funciones: enlace de datos, selección de celdas y filas, edición de celdas y filas con validación de errores, resúmenes de columnas, agrupación interactiva al estilo de Outlook, filtrado al estilo de Microsoft Excel y filas y columnas virtualizadas, de modo que puede cargar potencialmente millones de registros.

</PlatformBlock>

## ¿Por qué usar una cuadrícula de datos {Platform}?

Las cuadrículas de datos {Platform} son esenciales en casos de uso en los que hay que almacenar y ordenar rápidamente grandes volúmenes de datos. Esto puede incluir sectores como los servicios financieros, la banca y los seguros, que a menudo usan datos de gran volumen y alta velocidad. El éxito de estas empresas depende de las funciones, la funcionalidad y el rendimiento de estas cuadrículas de datos. Cuando hay que tomar decisiones sobre acciones en microsegundos, por ejemplo, es imprescindible que la cuadrícula de datos funcione sin retardo ni parpadeo.
