# Descripción general de la lista de {Platform}

El elemento de lista de {ProductName} es muy útil para presentar un grupo de elementos. Puede crear una lista sencilla de elementos de texto, o una más compleja que contenga una matriz de distintos elementos de disposición. El componente <ApiLink pkg="core" type="List" /> muestra filas de elementos y también admite uno o varios encabezados. Cada elemento de la lista es totalmente personalizable con plantillas y admite cualquier HTML válido u otros componentes.

## Ejemplo de lista de {Platform}

El siguiente ejemplo muestra una lista con contactos que tienen las propiedades de nombre y número de teléfono. El componente <ApiLink pkg="core" type="List" /> que se muestra a continuación usa los elementos <ApiLink pkg="core" type="Avatar" /> y <ApiLink pkg="core" type="Button" /> para mejorar la experiencia de usuario y mostrar las posibilidades de establecer una imagen de avatar y botones para las acciones de texto y llamada.

El slot `start` está pensado para añadir algún tipo de contenido multimedia antes de todo el resto del contenido de nuestros elementos de lista. Al elemento de destino, en nuestro caso el componente <ApiLink pkg="core" type="Avatar" />, también se le proporcionará una posición y un espaciado predeterminados.

El slot `end` está pensado para los elementos de lista que tienen algún tipo de acción o metadatos, representados, por ejemplo, por un conmutador, un botón, una casilla de verificación, etc. Usaremos componentes <ApiLink pkg="core" type="Button" />.

También permitamos al usuario cambiar el tamaño de la lista usando la variable CSS `--ig-size`. Añadiremos algunos botones de radio para mostrar todos los valores de tamaño. Así, cada vez que se seleccione uno, cambiaremos el tamaño de la lista.

```html
  <igc-radio name="size" value="medium" label-position="after">Medium</igc-radio>
  <igc-radio name="size" value="large" label-position="after" checked>Large</igc-radio>
</igc-radio-group>
```

### Elementos recomendados para los slots

Al colocar contenido en los slots `title` y `subtitle`, recomendamos usar elementos `<span>` en lugar de elementos de encabezado (`<h1>`–`<h6>`). Los elementos de encabezado tienen un estilo integrado (como el tamaño de fuente, la altura de línea y los márgenes) que puede interferir con la tipografía y la disposición previstas del componente. Usar un `<span>` proporciona un contenedor neutro que hereda limpiamente los estilos del componente.

Para obtener los mejores resultados, recomendamos usar el componente [`<igc-avatar>`](../layouts/avatar.mdx) para el slot `start`, que está pensado para contenido multimedia. Para el slot `end`, que está pensado para acciones, recomendamos usar componentes como [`<igc-button>`](../inputs/button.mdx), [`<igc-switch>`](../inputs/switch.mdx), [`<igc-checkbox>`](../inputs/checkbox.mdx), etc., según el tipo de contenido que desee mostrar. Sin embargo, para esos dos slots también puede usar elementos HTML simples, como `<img>` para el slot `start` e `<button>` u otro elemento interactivo para el slot `end`, siempre que sean apropiados para el contenido que desee mostrar.

## Estilos

<ApiLink pkg="core" type="List" /> expone varias partes CSS, que le dan control total sobre su estilo:

|Nombre|Descripción|
|--|--|
| `start` | El contenedor de inicio. |
| `end` | El contenedor de fin. |
| `content` | El contenedor del encabezado y del contenido personalizado. |
| `header` | El contenedor del título y el subtítulo. |
| `title` | El contenedor del título. |
| `subtitle` | El contenedor del subtítulo. |

```css
igc-list-header {
  font-size: 20px;
  font-weight: 700;
  color: var(--ig-primary-700);
}

igc-list-item::part(title) {
  font-size: 18px;
  color: var(--ig-primary-600);
}

igc-list-item::part(subtitle) {
  color: var(--ig-primary-300);
}
```
