# Group By de la cuadrícula {Platform}

El comportamiento de Group By de {ProductName} en {Platform} {GridName} crea filas de datos agrupados según los valores de las columnas. Group By en <ApiLink type="Grid" /> permite visualizar los grupos en una estructura jerárquica. Las filas de datos agrupados pueden expandirse o contraerse, y el orden de agrupación puede cambiarse mediante la interfaz o la API. Cuando la selección de filas está habilitada, se muestra un selector de filas de Group By en el área más a la izquierda de la fila de grupo. Si la propiedad <ApiLink type="Grid" member="rowSelection" label="RowSelection" /> se establece en single, las casillas de verificación se deshabilitan y solo sirven para indicar el grupo en el que se coloca la selección. Si la propiedad <ApiLink type="Grid" member="rowSelection" label="RowSelection" /> se establece en multiple, al hacer clic en el selector de filas de Group By se seleccionan todos los registros que pertenecen a ese grupo.

## Ejemplo de Group By de la cuadrícula {Platform}
Este ejemplo presenta las capacidades de agrupación de una gran cantidad de datos. Al arrastrar los encabezados de columna hasta la parte superior (área de agrupación), los usuarios pueden ver los datos de la columna seleccionada en una estructura jerárquica. Pueden agrupar por varios campos arrastrando más encabezados de columna a la parte superior. Estas opciones de agrupación resultan útiles cuando tiene tablas con muchas filas y columnas y los usuarios quieren presentar los datos de una forma mucho más rápida y visualmente aceptable.

### API de expandir/contraer

Además de las expresiones de agrupación, también puede controlar los estados de expansión de las filas de grupo. Se almacenan en una propiedad aparte del componente <ApiLink type="Grid" /> <ApiLink type="Grid" member="groupingExpansionState" label="GroupingExpansionState" />, que es una colección de <ApiLink type="GroupByExpandState" />. Cada estado de expansión se define de forma única por el nombre del campo para el que se creó y el valor que representa en cada nivel de agrupación; es decir, el identificador es una matriz jerárquica de <ApiLink type="GroupByKey" />.

Al igual que con <ApiLink type="Grid" member="groupingExpressions" label="GroupingExpressions" />, establecer directamente una lista de <ApiLink type="GroupByExpandState" /> en <ApiLink type="Grid" member="groupingExpansionState" label="GroupingExpansionState" /> cambiará la expansión en consecuencia. Además, <ApiLink type="Grid" /> expone un método <ApiLink type="Grid" member="toggleGroup" label="ToggleGroup" /> que alterna un grupo a partir de la instancia del registro de grupo o mediante la propiedad <ApiLink type="RowDirective" member="expanded" label="Expanded" /> de la fila.

De forma predeterminada, muestra un icono de agrupación y el nombre del campo y el valor que representa. El contexto con el que se renderiza la plantilla es de tipo <ApiLink type="GroupByRecord" />.

Como ejemplo, la siguiente plantilla haría más detallado el resumen de las filas de grupo:

## Group By de la cuadrícula {Platform} con paginación

Las filas de grupo participan en el proceso de paginación junto con las filas de datos. Cuentan para el tamaño de página de cada página. Las filas contraídas no se incluyen en el proceso de paginación. Cualquier operación de expandir o contraer obliga a la paginación a recalcular el número de páginas y, si es necesario, ajustar el índice de página.
Los grupos que abarcan varias páginas se dividen entre ellas. La fila de grupo solo es visible en la página en la que empieza y no se repite en las páginas siguientes. La información de resumen de las filas de grupo se calcula sobre todo el grupo y no se ve afectada por la paginación.

## Navegación por teclado

La interfaz de agrupación admite las siguientes interacciones con el teclado:

- Para las filas de grupo (el foco debe estar en la fila o en la celda de expandir/contraer)
  - <kbd>ALT</kbd> + <kbd>RIGHT</kbd>: expande el grupo
  - <kbd>ALT</kbd> + <kbd>LEFT</kbd>: contrae el grupo
  - <kbd>SPACE</kbd>: selecciona todas las filas del grupo, si la propiedad <kbd>rowSelection</kbd> está establecida en multiple

- Para los componentes de grupo <ApiLink pkg="core" type="Chip" /> en el área de agrupación (el foco debe estar en el chip)
  - <kbd>SHIFT</kbd> + <kbd>LEFT</kbd>: mueve el chip enfocado a la izquierda, cambiando el orden de agrupación, si es posible
  - <kbd>SHIFT</kbd> + <kbd>RIGHT</kbd>: mueve el chip enfocado a la derecha, cambiando el orden de agrupación, si es posible
  - <kbd>SPACE</kbd>: cambia la dirección de la ordenación
  - <kbd>DELETE</kbd>: desagrupa el campo
  - Los elementos independientes del chip también pueden recibir el foco y se puede interactuar con ellos usando la tecla <kbd>ENTER</kbd>.

## Group By personalizado de la cuadrícula {Platform}

La cuadrícula permite definir agrupación personalizada por columna o por expresión de agrupación, lo que proporciona agrupación según una condición personalizada. Esto resulta útil cuando necesita agrupar por objetos complejos o para otros escenarios específicos de la aplicación.

<PlatformBlock for="Angular">

<DocsAside type="info">
Para implementar la agrupación personalizada, primero hay que ordenar los datos de forma adecuada. Por ello, puede que también necesite aplicar una estrategia de ordenación personalizada que extienda la clase base `DefaultSortingStrategy`. Una vez ordenados los datos, los grupos personalizados pueden determinarse especificando un <ApiLink type="GroupingExpression" member="groupingComparer" label="GroupingComparer" /> para la columna o para la expresión de agrupación concreta.
</DocsAside>

Una vez ordenados los datos, los grupos personalizados pueden determinarse especificando un <ApiLink type="GroupingExpression" member="groupingComparer" label="GroupingComparer" /> para la columna o para la expresión de agrupación concreta.

El ejemplo define una ordenación personalizada para las distintas condiciones de fecha.
Cada estrategia personalizada define el <PlatformBlock for="React"><ApiLink type="GroupingExpression" member="groupingComparer" label="GroupingComparer" /></PlatformBlock>método <ApiLink type="GroupingExpression" member="groupingComparer" label="GroupingComparer" />, que es la función de comparación personalizada usada al ordenar los valores. A <PlatformBlock for="React"><ApiLink type="GroupingExpression" member="groupingComparer" label="GroupingComparer" /></PlatformBlock>Se define la función <ApiLink type="GroupingExpression" member="groupingComparer" label="GroupingComparer" /> para las expresiones de agrupación, que determina los elementos que pertenecen al mismo grupo según el modo de agrupación seleccionado. Los valores de los datos ordenados para los que esta función devuelve 0 se marcan como parte del mismo grupo.

```typescript
grid.groupingExpressions = [
    { fieldName: 'OrderDate', dir: SortingDirection.Desc,
    groupingComparer: (a, b) => {
            const dateA = this.getParsedDate(a);
            const dateB = this.getParsedDate(b);
            if (this.groupByMode === 'Month') {
                return dateA.month === dateB.month ? 0 : -1;
            } else if (this.groupByMode === "Year") {
                return dateA.year === dateB.year ? 0 : -1;
            } else if (this.groupByMode === 'Week') {
                return this.getWeekOfDate(a) === this.getWeekOfDate(b) ? 0 : -1;
            }
            return dateA.day === dateB.day && dateA.month === dateB.month ? 0 : -1;
        }
    }
];
```

La cuadrícula permite dar estilo mediante la [{ProductName} Theme Library](../themes/styles.mdx). El tema de la cuadrícula expone una gran variedad de propiedades que permiten personalizar todas las funciones de la cuadrícula.

En los pasos siguientes vamos a personalizar el estilo de la agrupación de la cuadrícula.

### Importar el tema global

Para empezar a personalizar la función de agrupación, debe importar el archivo `index`, donde se encuentran todas las funciones de estilo y los mixins.

```scss
@use "igniteui-{Platform}/theming" as *;

// IMPORTANT: Prior to {ProductName} version 13 use:
// @import '~igniteui-{Platform}/lib/core/styles/themes/index';
```

### Definir un tema personalizado

A continuación, cree un tema nuevo que extienda `grid-theme` y acepte los parámetros necesarios para personalizar la agrupación como desee. También tiene que extender `chip-theme`, porque se usa en la función de agrupación.

```scss

$custom-theme: grid-theme(
    /* Group By properties that affect styling */
    $group-row-background: #494949,
    $group-row-selected-background: #383838,
    $group-label-column-name-text: #f8f8f8,
    $group-label-icon: #FFCD0F,
    $group-label-text: #f8f8f8,
    $group-count-background: #FFCD0F,
    $group-count-text-color: #000,
    $expand-icon-color: #FFCD0F,
    $expand-icon-hover-color: rgb(223, 181, 13),
    $cell-active-border-color: #FFCD0F,
    $row-selected-background: #fff6d3,
    $row-selected-text-color: #000,
    $drop-indicator-color: #FFCD0F
    /* add other features properties here... */
);

/* Chip theme will style the chips in the Group By area */
$custom-chips-theme: chip-theme(
    $background: #494949,
    $text-color: #f8f8f8,
    $hover-text-color: #e7e7e7
);
```

### Definir una paleta de colores personalizada

En el enfoque que describimos anteriormente, los valores de color estaban codificados. Como alternativa, puede lograr más flexibilidad usando las funciones `palette` y `color`.
`palette` genera una paleta de colores a partir de los colores primario y secundario indicados.

```scss
$black-color: #292826;
$yellow-color: #FFCD0F;

$custom-palette: palette(
  $primary: $black-color,
  $secondary: $yellow-color
);
```

Después de generar una paleta personalizada, la función `color` puede usarse para obtener distintas variantes de los colores primario y secundario.

```scss
$custom-theme: grid-theme(
    $group-row-background: color($custom-palette, "primary", 300),
    $group-row-selected-background: color($custom-palette, "primary", 400),
    $group-label-column-name-text:contrast-color($custom-palette, "primary", 500),
    $group-label-icon: color($custom-palette, "secondary", 600),
    $group-label-text:contrast-color($custom-palette, "primary", 500),
    $group-count-background: color($custom-palette, "secondary", 600),
    $group-count-text-color: color($custom-palette, "primary", 400),
    $expand-icon-color: color($custom-palette, "secondary", 600),
    $expand-icon-hover-color: color($custom-palette, "secondary", 300),
    $cell-active-border-color: color($custom-palette, "secondary", 600)
);

$custom-chips-theme: chip-theme(
    $background: color($custom-palette, "primary", 300),
    $text-color:contrast-color($custom-palette, "primary", 500),
    $hover-text-color:contrast-color($custom-palette, "primary", 600)
);
```

### Definir esquemas personalizados

Puede ir aún más allá y construir una estructura flexible que tenga todas las ventajas de un [**esquema**](../themes/sass/schemas.mdx). El **esquema** es la receta de un tema.
Extienda uno de los dos esquemas predefinidos que se proporcionan para cada componente. En nuestro caso, usaríamos `$_light_grid`.

```scss
$custom-grid-schema: extend($_light-grid,(
    group-row-background: (-color:('secondary', 100)),
    group-row-selected-background: (-color:('primary', 400)),
    group-label-column-name-text: (-color:('primary', 600)),
    group-label-icon: (-color:('primary', 600)),
    group-label-text: (-color:('secondary', 700)),
    group-count-background: (-color:('primary', 600)),
    group-count-text-color: (-color:('secondary', 400)),
    expand-icon-color: (-color:('primary', 600)),
    expand-icon-hover-color: (-color:('primary', 400))
));
```

Para que se aplique el esquema personalizado, hay que extender `light` o `dark` globales. Todo el proceso consiste en proporcionar a un componente un esquema personalizado y añadirlo después al tema de ese componente.

```scss
$my-custom-schema: extend($light-schema, (
    -grid: $custom-grid-schema
));

$custom-theme: grid-theme(
    $palette: $custom-palette,
    $schema: $my-custom-schema
);
```

### Aplicar el tema personalizado

La forma más sencilla de aplicar su tema es con una sentencia `sass` `@include` en el archivo de estilos global:

```scss
@include grid($custom-theme);
@include chip($custom-chips-theme);
```

### Tema acotado al componente

Para que el tema personalizado afecte solo a un componente concreto, puede mover todos los estilos que acaba de definir del archivo de estilos global al archivo de estilos del componente personalizado (incluida la importación del archivo `index`).

De este modo, gracias a la [ViewEncapsulation](https://{Platform}.io/api/core/Component#encapsulation) de {Platform}, sus estilos se aplicarán solo a su componente personalizado.

 <DocsAside type="info">
 Si el componente usa un ViewEncapsulation [Emulated](../themes/styles.mdx#view-encapsulation), es necesario atravesar esa encapsulación con `::ng-deep` para dar estilo a la cuadrícula.
 </DocsAside>

 <DocsAside type="info">
 Envuelva la instrucción dentro de un selector `:host` para evitar que sus estilos afecten a elementos situados fuera de nuestro componente:
 </DocsAside>

```scss
:host {
    ::ng-deep {
        @include grid($custom-theme);
        @include chip($custom-chips-theme);
    }
}
```
