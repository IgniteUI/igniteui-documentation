# Cuadrícula maestro-detalle de {Platform}

El componente <ApiLink type="Grid" /> admite especificar una plantilla de detalle que muestra información adicional de una fila concreta expandiendo o contrayendo su contenido. Cuando se especifica, cada registro actúa como maestro, que al expandirse muestra una plantilla de detalles personalizable con los datos contextuales del registro actual.

Este modo es útil cuando necesita mostrar datos al estilo maestro-detalle en una estructura jerárquica.

## Configuración

Para configurar <ApiLink type="Grid" /> de modo que se muestre en modo maestro-detalle, debe especificar una plantilla para la cuadrícula:


<PlatformBlock for="Angular">
```html
<{ComponentSelector}>
         <ng-template GridDetail let-dataItem>
              <!-- Custom detail template content here -->
        </ng-template>
</{ComponentSelector}>
```
</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
constructor() {
  var grid = this.grid = document.getElementById('grid') as IgcGridComponent;
  this._bind = () => {
    grid.data = this.customersData;
    grid.detailTemplate = this.masterDetailTemplate;
  }
  this._bind();
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
    <IgbGrid DetailTemplateScript="DetailTemplate"  AutoGenerate=true  Data=northwindEmployees></IgbGrid>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrGrid detailTemplate={masterDetailTemplate} autoGenerate={false} data={nwindData}></IgrGrid>
```

</PlatformBlock>

El contexto de la plantilla son los datos del registro maestro, de modo que los valores del registro maestro pueden mostrarse en la plantilla de detalle. Por ejemplo:

<PlatformBlock for="Angular">
```html
<{ComponentSelector}>
         <ng-template GridDetail let-dataItem>
            @if (dataItem.Category) {
                <div>
                    <header>{{dataItem.Category.CategoryName}}</header>
                    <span>{{dataItem.Category.Description}}</span>
                </div>
            }
        </ng-template>
</{ComponentSelector}>
```
</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
    public masterDetailTemplate = (ctx: IgcGridMasterDetailContext) => {
        var data = ctx.implicit;
        return html` <div class="contact-container">
        <span><strong>Name:</strong> ${data.ContactName}</span> <br/>
        <span><strong>Title:</strong> ${data.ContactTitle}</span> <br/>
        <span><strong>Company:</strong> ${data.CompanyName}</span> <br/>
    </div>`;
    }
```

</PlatformBlock>

## Navegación por teclado

- Cuando el foco está en una fila de detalle:

  - <kbd>🡑</kbd>: se desplaza una fila hacia arriba, enfocando una celda de la fila anterior.
  - <kbd>🡓</kbd>: se desplaza una fila hacia abajo, enfocando una celda de la fila siguiente.
  - <kbd>TAB</kbd>: permite que el foco pase al siguiente elemento enfocable dentro de la plantilla si hay elementos enfocables; en caso contrario, pasa a la siguiente fila de la cuadrícula.
  - <kbd>SHIFT</kbd> + <kbd>TAB</kbd>: mueve el foco a la fila anterior.

- Cuando el foco está en una fila de datos con expansor:
  - <kbd>ALT</kbd> + <kbd>🡒</kbd> o <kbd>ALT</kbd> + <kbd>🡓</kbd>: expande la fila.
  - <kbd>ALT</kbd> + <kbd>🡐</kbd> o <kbd>ALT</kbd> + <kbd>🡑</kbd>: contrae la fila.

## Problemas conocidos y limitaciones


|Limitaciones conocidas| Descripción|
| --- | --- |
| La navegación con tabulación dentro de la plantilla de detalle personalizada puede no actualizar la posición de desplazamiento de la cuadrícula maestra si el siguiente elemento enfocado está fuera del área visible.| La navegación con tabulación dentro de la plantilla de detalle personalizada se deja en manos del navegador. |
| La plantilla de detalle no se exportará a Excel.| Como la plantilla de detalle puede contener cualquier tipo de contenido, no podemos exportarla a Excel de forma nativa.|
| La función de búsqueda no resaltará los elementos de la plantilla de detalle. | |
