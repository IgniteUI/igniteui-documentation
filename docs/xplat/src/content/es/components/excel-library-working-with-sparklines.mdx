# {Platform} Trabajar con sparklines

La biblioteca de Excel de Infragistics {Platform} admite la adición de sparklines a una hoja de cálculo de Excel. Pueden usarse para mostrar representaciones visuales sencillas de las tendencias de datos en una región de celdas de datos de su hoja de cálculo. Por ejemplo, si quisiera ver sus datos de Excel en una región de celdas concreta representada como un gráfico sparkline sencillo de columnas o de líneas, esta característica puede ayudarle a conseguirlo.

## Sparklines admitidos
A continuación se muestra una lista de los tipos de sparkline predefinidos admitidos.

- Line
- Column
- Apilado (ganancia/pérdida)

El siguiente código muestra cómo añadir sparklines de forma programática a una hoja de cálculo mediante la colección sparklineGroups:

```ts
var workbook: Workbook;
var sheet1 = workbook.worksheets().add("Sparklines");
var sheet2 = workbook.worksheets().add("Data");
sheet1.sparklineGroups().add(SparklineType.Line, "Sparklines!A1:A1", "Data!A2:A11");
sheet1.sparklineGroups().add(SparklineType.Column, "Sparklines!B1:B1", "Data!A2:A11");
workbook.save(workbook, "Sparklines.xlsx");
```
