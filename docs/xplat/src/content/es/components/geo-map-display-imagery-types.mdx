# Imágenes geográficas de {Platform}

{Platform} Las imágenes geográficas son una representación detallada del mundo desde una perspectiva cenital. Pueden consistir en un mapa aéreo o satélite, o en mapas de carreteras, en una estructura de teselas de imágenes multiescala. El componente de mapa geográfico puede mostrar imágenes geográficas para ofrecer a los usuarios finales mapas del mundo ricos e interactivos y un contexto geográfico para los datos geoespaciales.

## Tipos de imágenes geográficas
El componente de mapa puede mostrar teselas de imágenes geográficas de tres servicios de mapas admitidos, o de otros servicios de mapas que pueden implementarse fácilmente en una aplicación.

## Contenido de fondo del mapa
La propiedad `backgroundContent` del componente de mapa se usa para mostrar todos los tipos admitidos de orígenes de imágenes geográficas. Para cada origen de imágenes hay una clase de imagen que se usa para renderizar las teselas de imagen geográfica correspondientes.

La tabla siguiente resume las clases de imagen que proporciona el componente de mapa.

| Clase de imagen | Descripción   |
|---------------|---------------|
|`GeographicMapImagery`|Representa el control base para todas las clases de imagen que muestran todos los tipos admitidos de teselas de imagen geográfica. Esta clase puede extenderse para implementar la compatibilidad con teselas de imagen geográfica de otros orígenes, como el servicio de mapas Map Quest.|
|`OpenStreetMapImagery`|Representa el control de imagen multiescala para mostrar teselas de imagen geográfica del servicio Open Street Maps.|

{/*|`BingMapsMapImagery`|Represents the multi-scale imagery control for displaying geographic imagery tiles from the Bing Maps service.|*/}

De forma predeterminada, la propiedad `backgroundContent` se establece en el objeto `OpenStreetMapImagery` y el componente de mapa muestra teselas de imagen geográfica del servicio Open Street Maps. Para mostrar otros tipos de teselas de imagen geográfica, el componente de mapa debe reconfigurarse.

Además, la propiedad `backgroundContent` puede establecerse en cualquier objeto que herede de la clase. Sin embargo, solo los objetos que heredan de la clase `GeographicMapImagery` permitirán desplazar y ampliar el contenido de fondo del mapa.

En el componente de mapa, el contenido de fondo siempre se renderiza detrás de todas las series geográficas. Es decir, las teselas de imagen geográfica siempre se renderizan primero, y cualquier serie geográfica de la propiedad Series del componente de mapa se renderiza encima de las teselas. Esto es especialmente importante cuando se muestran varias series geográficas en la misma área de trazado del componente de mapa, porque las teselas de imagen geográfica pueden quedar fácilmente ocultas en la vista del mapa.
