# {Platform}: estilo de formas en series de formas geográficas

Este tema explica cómo aplicar estilos personalizados a `GeographicShapeSeries` en {Platform} `GeographicMap`.

## Ejemplo de {Platform}: estilo de formas en series de formas geográficas


<Sample src="/maps/geo-map/shape-styling" height={500} alt="Ejemplo de {Platform}: estilo de formas en series de formas geográficas" />




Las cuatro clases de estilo que usa cada sección — **ShapeRandomStyling**, **ShapeScaleStyling**, **ShapeRangeStyling** y **ShapeComparisonStyling** — proceden de la [Utilidad de estilo de formas](./geo-map-resources-shape-styling-utility.mdx), que publica el archivo que debe copiar en su propio proyecto.

## Importaciones necesarias

El estilo de formas requiere que importe las siguientes clases:

```json-snippet id="shapeStyling" source="/maps/geo-map/shape-styling" channel="bindingImports,handlersImports"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true,
            "series": [
                {
                    "type": "GeographicShapeSeries",
                    "name": "shapeSeries",
                    "isCustomShapeStyleAllowed": true,
                    "assigningShapeStyleRef": "ShapeFileStyling"
                }
            ]
        }
    },
    "onViewInit": [ "ShapeFileOnViewInit" ]
}
```


## Estilo aleatorio de formas

Este fragmento de código crea instancias de **ShapeRandomStyling** que asignan aleatoriamente colores de relleno a los países del mundo.

```json-snippet source="/maps/geo-map/shape-styling-random" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeRandomStyling"
    ]
}
```

## Estilo de escala de formas

Este fragmento de código crea instancias de **ShapeScaleStyling** que asignan colores de relleno a la forma de los países según su población, en una escala logarítmica.

```json-snippet source="/maps/geo-map/shape-styling-scale" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeScaleStyling"
    ]
}
```

## Estilo de rangos de formas

Este fragmento de código crea instancias de **ShapeRangeStyling** que asignan colores a la forma de los países según rangos de población.

```json-snippet source="/maps/geo-map/shape-styling-range" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeRangeStyling"
    ]
}
```

## Estilo de comparación de formas

Este fragmento de código crea instancias de **ShapeComparisonStyling** que asignan colores a los países según el nombre de su región en el mundo.

```json-snippet source="/maps/geo-map/shape-styling-comparison" channel="handlersImports...handler"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "zoomable": true
        }
    },
    "onViewInit": [
        "MapShapeComparisonStyling"
    ]
}
```
