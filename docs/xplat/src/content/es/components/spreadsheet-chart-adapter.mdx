# Adaptador de gráficos de {Platform} Spreadsheet

El componente {Platform} Spreadsheet permite mostrar gráficos en su <ApiLink type="Spreadsheet" />.

## Descripción general del adaptador de gráficos

Usando
<ApiLink type="SpreadsheetChartAdapterBase" />
puede mostrar los gráficos en la hoja de cálculo. Los adaptadores de gráficos de la hoja de cálculo crean e inicializan los elementos del gráfico para la hoja de cálculo a partir de una instancia de Infragistics.Documents.Excel.WorksheetChart.

Para añadir un WorksheetChart a una hoja de trabajo, debe usar el método <ApiLink type="WorksheetShapeCollection" member="addChart" label="AddChart" /> de la colección Shapes de la hoja de trabajo. Encontrará más detalles sobre cómo añadir gráficos en Excel a continuación.

Estos son los pasos, descritos uno a uno:

1. Añada la referencia a SpreadsheetChartAdapterModule a su proyecto
2. Cree una instancia de la clase SpreadsheetChartAdapter asignándola a Spreadsheet
3. Ejecute su aplicación y cargue una hoja de trabajo que contenga un gráfico.

Los adaptadores de gráficos de Spreadsheet admiten más de 35 tipos de gráficos, entre ellos Line, Area, Column y Doughnut. Consulte la lista completa aquí:

- Gráficos de columnas

  - Columnas apiladas
  - Columnas apiladas al 100 %
- Gráficos de líneas
  - Line
  - Líneas con marcadores
  - Líneas apiladas
  - Líneas apiladas con marcadores
  - Líneas apiladas al 100 %
  - Líneas apiladas al 100 % con marcadores
- Gráficos circulares
- Gráficos de anillo
- Gráficos de barras
  - Barras agrupadas
  - Barras apiladas
  - Barras apiladas al 100 %
  - Gráficos de áreas
  - Area
  - Áreas apiladas
  - Áreas apiladas al 100 %
- Gráficos XY (dispersión) y de burbujas
  - Dispersión (solo con marcador)
  - Dispersión con líneas suavizadas
  - Dispersión con líneas suavizadas y marcadores
  - Dispersión con líneas rectas
  - Dispersión con líneas rectas y marcadores
  - Burbujas (sin efectos)
  - Bubble3DEffect
- Gráficos bursátiles
  - Máximo-mínimo-cierre
  - Apertura-máximo-mínimo-cierre
  - Volumen-máximo-mínimo-cierre
  - Volumen-apertura-máximo-mínimo-cierre
- Gráficos de radar
  - Radar sin marcadores
  - Radar con marcadores
  - Radar relleno
- Gráficos combinados
  - Gráfico de columnas y líneas que comparte el eje X
  - Gráfico de columnas y líneas con un segundo eje X
  - Áreas apiladas y columnas
  - Combinación personalizada

## Fragmento de código

El siguiente fragmento de código muestra cómo añadir gráficos a la hoja de trabajo que se está viendo en el control <ApiLink type="Spreadsheet" />:

```typescript
this.spreadsheet.chartAdapter = new SpreadsheetChartAdapter();

ExcelUtility.loadFromUrl(process.env.PUBLIC_URL + "/ExcelFiles/ChartData.xlsx").then((w) => {
    this.spreadsheet.workbook = w;

    const sheet: Worksheet = this.spreadsheet.workbook.worksheets(0);

    sheet.defaultColumnWidth = 500 * 20;
    sheet.rows(0).height = 150 * 20;

    const cell1: WorksheetCell = sheet.getCell("A1");
    const cell2: WorksheetCell = sheet.getCell("B1");
    const cell3: WorksheetCell = sheet.getCell("C1");
    const cell4: WorksheetCell = sheet.getCell("D1");

    const dataCellAddress = "A4:D6";

    const chart1 = sheet.shapes().addChart(ChartType.Line, cell1, { x: 0, y: 0 }, cell1, { x: 100, y: 100 });

    const title: {Platform} ChartTitle = new ChartTitle();
    title.text = new FormattedString("Line Chart");
    chart1.chartTitle = title;

    chart1.setSourceData(dataCellAddress, true);

    const chart2 = sheet.shapes().addChart(ChartType.ColumnClustered, cell2, { x: 0, y: 0 }, cell2, { x: 100, y: 100 });

    const title2: ChartTitle = new ChartTitle();
    title2.text = new FormattedString("Column Chart");
    chart2.chartTitle = title2;

    chart2.setSourceData(dataCellAddress, true);

    const chart3 = sheet.shapes().addChart(ChartType.Area, cell3, { x: 0, y: 0 }, cell3, { x: 100, y: 100 });

    const title3: ChartTitle = new ChartTitle();
    title3.text = new FormattedString("Area Chart");
    chart3.chartTitle = title3;

    chart3.setSourceData(dataCellAddress, true);

    const chart4 = sheet.shapes().addChart(ChartType.Pie, cell4, { x: 0, y: 0 }, cell4, { x: 100, y: 100 });

    const title4: ChartTitle = new ChartTitle();
    title4.text = new FormattedString("Pie Chart");
    chart4.chartTitle = title4;

    chart4.setSourceData(dataCellAddress, true);
});
```
