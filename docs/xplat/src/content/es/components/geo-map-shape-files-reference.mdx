## Formato de archivos de forma

El control {Platform} `GeographicMap` usa el formato popular [Shape Files](http://en.wikipedia.org/wiki/Shapefile#Overview) como uno de los orígenes de datos geoespaciales. Los archivos de forma suelen distribuirse junto con otros tipos de archivo, generalmente con las extensiones **.shp**, **.shx** y **.dbf**.

La tabla siguiente ofrece información básica y la finalidad de cada tipo de archivo de forma.

| Extensión de archivo | Descripción |
| ---------------|------------ |
| `.shp` | Un archivo de forma contiene elementos de datos vectoriales geoespaciales que describen puntos, polilíneas y polígonos. En este archivo, los puntos pueden describir ciudades, las polilíneas pueden describir carreteras, y los polígonos pueden describir las formas o los límites de los países en un contexto geográfico. |
| `.shx` | Un archivo de índice de forma contiene un índice para la búsqueda rápida de elementos de datos vectoriales geoespaciales. |
| `.dbf` | Un archivo de base de datos de forma contiene una tabla en la que cada fila corresponde a un elemento de datos geoespacial de un archivo de forma (.shp). En el archivo de base de datos de forma, las columnas de cadena pueden describir atributos del elemento de datos geoespacial, como cadenas (nombres de países, regiones, ciudades) y columnas numéricas (población de países, ubicación de ciudades). |



Consulte los siguientes recursos para obtener información detallada y las especificaciones sobre cómo se almacenan los datos geoespaciales en los archivos de forma.
