# Feed de NuGet de Infragistics

Infragistics proporciona un feed privado de NuGet para que los usuarios con licencia consuman y añadan a sus aplicaciones los paquetes NuGet con licencia de Ignite UI for Blazor, mediante el administrador de paquetes NuGet.

Este tema contiene las siguientes secciones:

- Añadir el feed de NuGet de Infragistics con Visual Studio
- Añadir el feed de NuGet de Infragistics con la CLI de NuGet

## Añadir con Visual Studio

1 - En Visual Studio, seleccione **Herramientas → Administrador de paquetes NuGet → Configuración del Administrador de paquetes**.

<Image src={nugetPackageManagerSettingMenuItem} alt="nuget-package-manager-setting-menu-item" />

2 - En la sección **Orígenes de paquetes**, añada un origen de paquetes nuevo haciendo clic en el **icono de más** de la esquina superior derecha del cuadro de diálogo.
- Establezca el nombre en **Infragistics**
- Establezca el origen en **https://packages.infragistics.com/nuget/licensed/v3/index.json** si prefiere usar la versión 3 del protocolo NuGet. En caso contrario, debe establecerse en **https://packages.infragistics.com/nuget/licensed/**

<DocsAside type="info">
Para más detalles sobre si conviene usar v3 o una versión anterior, visite: **https://devblogs.microsoft.com/nuget/nuget-3-what-and-why/**. El protocolo v3 solo es aplicable con versiones recientes de los clientes NuGet (posteriores a 2015). Los clientes NuGet más antiguos pueden o no ser compatibles con v3.
</DocsAside>

Haga clic en el botón **Actualizar** y después en **Aceptar** para cerrar el cuadro de diálogo.

<Image src={nugetPackageManagerPackageSourcesIgServer} alt="nuget-package-manager-package-sources-ig-server" />

<DocsAside type="info">
Al añadir por primera vez un paquete NuGet de este origen, se le pedirán sus credenciales de Infragistics.
</DocsAside>

## Añadir con la CLI de NuGet

1 - Descargue el [ejecutable de NuGet más reciente](https://dist.nuget.org/win-x86-commandline/latest/nuget.exe). Indique a su navegador que guarde el archivo en la carpeta que elija. El archivo no es un instalador: si lo ejecuta directamente desde el navegador, no verá nada.
2 - Abra un símbolo del sistema en la ruta de la carpeta del archivo `nuget.exe` que acaba de descargar.
3 - Ejecute el siguiente comando

```cmd
//nuget protocol v3
nuget sources add -name "Infragistics" -source "https://packages.infragistics.com/nuget/licensed/v3/index.json" -username "your login email" -password "your password"

//nuget protocol v2
nuget sources add -name "Infragistics" -source "https://packages.infragistics.com/nuget/licensed" -username "your login email" -password "your password"
```

<DocsAside type="info">
La contraseña se almacenará cifrada en el archivo de configuración de NuGet y solo puede descifrarse en el mismo contexto de usuario en el que se cifró. La ubicación predeterminada del archivo de configuración se encuentra aquí `%AppData%\NuGet\NuGet.config`
</DocsAside>
