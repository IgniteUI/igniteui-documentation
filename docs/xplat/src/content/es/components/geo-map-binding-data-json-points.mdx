# {Platform}: enlazar archivos JSON con ubicaciones geográficas

Con el mapa de {ProductName} puede representar datos geográficos cargados desde distintos tipos de archivo. Por ejemplo, puede cargar ubicaciones geográficas desde un archivo JavaScript Object Notation (JSON).

## Fragmento de código
El siguiente código carga y enlaza <PlatformBlock for="Web">`GeographicHighDensityScatterSeries`</PlatformBlock><PlatformBlock for="WinUI, Uno">`GeographicSymbolSeries`</PlatformBlock> en el componente de mapa a un array de objetos creado a partir del archivo JSON cargado con ubicaciones geográficas:

```json-snippet id="jsonMap" source="/maps/geo-map/binding-data-json-points"
{
    "descriptions": {
        "content": { "type": "GeographicMap", "name": "geoMap", "height": "100%", "width": "100%", "zoomable": true }
    },
    "onViewInit": [ "MapBindingDataJsonPointsOnViewInit" ]
}
```

