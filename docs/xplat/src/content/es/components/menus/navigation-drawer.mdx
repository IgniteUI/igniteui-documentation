# Descripción general de {Platform} Navigation Drawer

El Navigation Drawer de {ProductName} ofrece navegación lateral que puede expandirse o contraerse dentro del contenido. Una versión mini ofrece acceso rápido a la navegación incluso cuando está cerrado. Su contenido es totalmente personalizable, y además ofrece un estilo predeterminado para los elementos de menú.

## Integración con Navbar

Aunque en el cajón puede proporcionarse cualquier contenido, el <ApiLink pkg="core" type="NavDrawerItem" /> está disponible para aplicar estilos listos para usar a los elementos.

Para mejorar un poco nuestro componente, podemos usarlo junto con el <ApiLink pkg="core" type="Navbar" />. Así logramos un aspecto más completo y podemos usar los métodos del cajón. Veamos cómo podemos usarlo en el siguiente ejemplo:

<PlatformBlock for="WebComponents">

```html
<igc-navbar>
  <igc-icon slot="start" name="menu" id="menu"></igc-icon>
  <h2>Home</h2>
</igc-navbar>

<igc-nav-drawer id="navDrawer">
    <igc-nav-drawer-header-item>
        Sample Drawer
    </igc-nav-drawer-header-item>
    <igc-nav-drawer-item>
        <igc-icon slot="icon" name="home"></igc-icon>
        <span slot="content">Home</span>
    </igc-nav-drawer-item>
    <igc-nav-drawer-item>
        <igc-icon slot="icon" name="search"></igc-icon>
        <span slot="content">Search</span>
    </igc-nav-drawer-item>
</igc-nav-drawer>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Añadamos también algunos botones de opción para mostrar todos los valores de <ApiLink pkg="core" type="NavDrawer" member="position" label="position" />. Así, cada vez que se seleccione uno, cambiaremos la posición del cajón.

<PlatformBlock for="WebComponents">

```ts
// ...
import { defineComponents, IgcNavDrawerComponent, IgcRadioComponent, IgcRadioGroupComponent } from 'igniteui-webcomponents';

defineComponents(IgcNavDrawerComponent, IgcRadioComponent, IgcRadioGroupComponent);
this.navDrawer = document.getElementById('navDrawer') as IgcNavDrawerComponent;
this.radioGroup = document.getElementById('radio-group') as IgcRadioGroupComponent;
this.radioGroup.addEventListener('click', (radio: any) => {
    this.navDrawer.position = radio.target.value;
});
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

</igc-radio-group>

</PlatformBlock>

    if (e.checked == true) {
        this.setState({ drawerPosition: e.detail.value });

</PlatformBlock>

Por último, necesitamos una forma de abrir y cerrar el navigation drawer. Hay varias maneras de conseguirlo, pero en aras de este ejemplo haremos lo siguiente:

<PlatformBlock for="WebComponents">

```ts
// ...
const menu = document.getElementById('menu');
const navDrawer = document.querySelector('igc-nav-drawer') as IgcNavDrawerComponent;

menu!.addEventListener('click', () => {
    navDrawer.show();
})

document.getElementById('root')!.onclick = (e) => {
    if (e.target != document.getElementById('navDrawer')) {
        navDrawer.hide();
    }
}
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
public void OnMenuIconClick()
{
    if (this.NavDrawerRef != null)
    {
        this.NavDrawerRef.Show();
    }
}
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
public onMenuIconClick() {
    if (this.navDrawerRef) {
        this.navDrawerRef.show();
    }
}
```

</PlatformBlock>

## Variante mini

Con la variante mini, el Navigation Drawer cambia su ancho en lugar de cerrarse. Se usa para mantener una navegación rápida disponible en todo momento, dejando solo los iconos. Para conseguirlo, basta con configurar el slot `mini` del cajón.

<PlatformBlock for="WebComponents">

```html
<igc-nav-drawer position="start">
    <igc-nav-drawer-header-item>Sample Drawer</igc-nav-drawer-header-item>
    <igc-nav-drawer-item>
        <igc-icon slot="icon" name="home"></igc-icon>
        <span slot="content">Home</span>
    </igc-nav-drawer-item>
    <igc-nav-drawer-item>
        <igc-icon slot="icon" name="search"></igc-icon>
        <span slot="content">Search</span>
    </igc-nav-drawer-item>
    <div slot="mini">
        <igc-nav-drawer-item>
            <igc-icon slot="icon" name="home"></igc-icon>
        </igc-nav-drawer-item>
        <igc-nav-drawer-item>
            <igc-icon slot="icon" name="search"></igc-icon>
        </igc-nav-drawer-item>
    </div>
</igc-nav-drawer>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

## Estilos

El <ApiLink pkg="core" type="NavDrawer" /> expone varias partes CSS: `base`, `main` y `mini`, que le dan control total sobre su estilo.

```scss
igc-nav-drawer::part(base) {
  background: var(--ig-secondary-500);
}

igc-nav-drawer-item::part(base) {
  color: var(--ig-secondary-500-contrast);
}

igc-nav-drawer-item::part(base):hover {
  background-color: var(--ig-gray-800);
}

igc-nav-drawer-item[active]::part(base) {
  background: var(--ig-warn-500);
  color: var(--ig-warn-500-contrast);
}

igc-nav-drawer-header-item {
  color: var(--ig-warn-500);
}
```
