# Descripción general de {Platform} Navbar

El {ProductName} Navbar informa al usuario de su posición actual en una aplicación. La barra de navegación también puede ofrecer enlaces a acciones rápidas, como buscar o marcar como favorito, lo que ayuda a los usuarios a desplazarse con fluidez por una aplicación sin intentar acceder a rutas o estados no válidos. La barra se sitúa en la parte superior del contenedor en el que se coloca.

### Contenido

Puede mejorar el componente <ApiLink pkg="core" type="Navbar" /> añadiendo <ApiLink pkg="core" type="Icon" /> u otros componentes en la posición de inicio o de fin como contenido, lo que permite a los usuarios ir directamente a puntos clave desde la barra:

<PlatformBlock for="WebComponents">

```html
<igc-navbar>
    <igc-icon name="home" slot="start"></igc-icon>
    <h2>Sample App</h2>
    <igc-icon name="search" slot="end"></igc-icon>
    ...
</igc-navbar>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```Razor
<IgbNavbar>
    <IgbIcon @ref="@HomeIcon" slot="start" IconName="home" Collection="material" />
    <h3>Sample App</h3>
    <IgbIcon @ref="@SearchIcon" slot="end" IconName="search" Collection="material" />
    ...
</IgbNavbar>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
 <IgrNavbar>
    <div slot="start">
        <IgrIcon name="home" collection="material" />
    </div>
    <h2>Sample App</h2>
    <div slot="end">
        <IgrIcon name="search" collection="material" />
    </div>
    ...
</IgrNavbar>

```

</PlatformBlock>

## Estilos

El componente <ApiLink pkg="core" type="Navbar" /> expone varias partes CSS que le dan control total sobre su estilo:

|Nombre|Descripción|
|--|--|
| `base` | El wrapper base de la barra de navegación. |
| `start` | El contenedor del icono alineado a la izquierda. |
| `middle` | El contenedor del título de la barra de navegación. |
| `end` | El contenedor de los iconos de acción alineados a la derecha. |

```css
igc-icon {
  color: var(--ig-primary-500);
}

igc-navbar {
  background-color: var(--ig-secondary-200);
}

igc-navbar::part(middle) {
  font-family: Titillium Web, sans-serif;
  color: var(--ig-primary-500);;
}
```
