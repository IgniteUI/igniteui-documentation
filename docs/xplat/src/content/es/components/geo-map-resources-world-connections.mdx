# {Platform}: conexiones mundiales

Este tema de recursos ofrece la implementación de una utilidad de datos para generar las ubicaciones de los aeropuertos, las rutas de vuelo y las líneas de cuadrícula geográficas. Puede usar estos orígenes de datos como punto de referencia para crear sus propios datos geográficos. Tenga en cuenta que esta utilidad depende de los scripts [WorldUtil](./geo-map-resources-world-util.mdx) y [WorldLocations](./geo-map-resources-world-locations.mdx).

## Fragmento de código

```json-snippet source="/maps/geo-map/binding-multiple-sources" channel="WorldConnections"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "series": [
                {
                    "type": "GeographicPolylineSeries",
                    "name": "lineSeries",
                    "dataSourceRef": "WorldFlights",
                    "$dataSourceRef": "+doc:WorldConnections",
                    "shapeMemberPath": "Points"
                }
            ]
        }
    }
}
```
