# Mapa de alta densidad geográfico de {Platform}

En el componente de mapa de {Platform} puede usar `GeographicHighDensityScatterSeries` para enlazar y mostrar datos de dispersión, desde cientos hasta millones de puntos de datos, con un tiempo de carga muy reducido.

## Ejemplo de mapa de alta densidad geográfico de {Platform}


<Sample src="/maps/geo-map/type-scatter-density-series" height={400} alt="{Platform}: ejemplo de uso de la serie de dispersión de alta densidad" />




La demostración anterior muestra la serie `GeographicHighDensityScatterSeries` del componente de mapa enlazada a cientos o incluso miles de puntos de datos que representan la densidad de población de Australia. En el área de trazado del mapa, los puntos de datos con mayor densidad de población se representan como agrupaciones de píxeles rojos, y los puntos de datos más dispersos, mediante píxeles azules discretos.

Como hay muchísimos puntos de datos, la serie muestra los datos de dispersión como puntos diminutos en lugar de marcadores de tamaño completo, y muestra las zonas con más datos con una mayor densidad de color, que representa una agrupación de puntos de datos.

## Requisitos de datos
Al igual que otros tipos de series de dispersión del control de mapa, la serie `GeographicHighDensityScatterSeries` tiene la propiedad `dataSource`, que puede enlazarse a un array de objetos. Además, cada elemento de datos del origen de elementos debe tener dos columnas de datos que almacenen las coordenadas geográficas de longitud y latitud, y usa las propiedades `longitudeMemberPath` y `latitudeMemberPath` para asignar estas columnas de datos.

### Enlace de datos
La tabla siguiente resume las propiedades de la serie GeographicHighDensityScatterSeries usadas para el enlace de datos.

| Propiedad|Tipo|Descripción |
| ---|---|--- |
| `dataSource`|cualquiera|Obtiene o establece el origen de elementos |
| `longitudeMemberPath`|string|Usa la propiedad DataSource para determinar la ubicación de los valores de longitud en los elementos asignados |
| `latitudeMemberPath`|string|Usa la propiedad DataSource para determinar la ubicación de los valores de latitud en los elementos asignados |

## Escala de color de calor
La escala de color de calor, una característica opcional, determina el patrón de color dentro de la serie. La tabla siguiente resume las propiedades que se usan para determinar la escala de color.

| Propiedad |Tipo|Descripción |
| ---|---|--- |
| `heatMinimum`|Double|Define el valor double que representa el extremo mínimo de la escala de color |
| `heatMaximum`|Double|Define el valor double que representa el extremo máximo de la escala de color |
| `heatMinimumColor`|Color|Define el color de densidad de puntos que se usa en el extremo inferior de la escala de color |
| `heatMaximumColor`|Color|Define el color de densidad de puntos que se usa en el extremo superior de la escala de color |
