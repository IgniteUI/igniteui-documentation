# Descripción general de {Platform} Zoom Slider

El control {Platform} ZoomSlider ofrece funcionalidad de zoom a los controles compatibles con intervalos. ZoomSlider incluye una barra de desplazamiento horizontal, una miniatura de todo el intervalo y una ventana de intervalo de zoom redimensionable. ZoomSlider no puede funcionar como control independiente y actúa como una mejora para los controles basados en intervalos, como DataChart o CategoryChart.

## Uso

| Nombre de la función        | Descripción |
| --------------------|----------------------- |
| Navegación por barra de desplazamiento       | Los usuarios pueden cambiar la escala y desplazarse por intervalos de datos usando las funciones integradas de la barra de desplazamiento de ZoomSlider. |
| Desplazamiento y zoom       | Los usuarios pueden ajustar la escala de visualización arrastrando los bordes del pad del pulgar, para que la visualización actual cubra un intervalo más amplio (alejar) o más reducido (acercar). |
| Múltiples opciones de interacción del usuario       | Todas las interacciones con el ratón se admiten también de forma redundante mediante el tacto, y la mayoría también mediante el teclado. Para más detalles, consulte User Interactions and Usability. |
| Compatibilidad táctil       |  En los dispositivos con pantalla táctil, los usuarios pueden disfrutar de toda la funcionalidad de ZoomSlider. Todas las interacciones con el ratón se admiten en un entorno táctil. |
| Extensibilidad       | El control ZoomSlider es compatible con el control DataChart de forma inmediata. |
| Ventana de intervalo de zoom configurable       | Se pueden configurar el ancho y la posición iniciales de la ventana de intervalo de zoom, así como su tamaño mínimo. |

