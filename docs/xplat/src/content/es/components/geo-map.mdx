# {Platform} Información general del mapa

El componente de mapa de {ProductName} le permite mostrar datos que contienen ubicaciones geográficas desde modelos de vista, o datos geoespaciales cargados desde archivos de forma, sobre mapas de imágenes geográficas.

## Ejemplo de mapa de {Platform}

El siguiente ejemplo muestra cómo mostrar datos en `GeographicMap` usando `GeographicProportionalSymbolSeries`, también conocida como serie de burbujas.

El componente de mapa le permite representar imágenes geográficas de Bing Maps™ y de Open Street Maps.

</PlatformBlock>

<PlatformBlock for="WinUI, Uno">

El componente de mapa le permite representar imágenes geográficas de Open Street Maps.

El mapa permite representar decenas de miles de puntos de datos y actualizarlos cada pocos milisegundos, de modo que el control puede gestionar sus fuentes de datos en tiempo real.

La propiedad Series del mapa permite renderizar un número ilimitado de series geográficas. Esta propiedad es una colección de objetos de serie geográfica, y en ella puede añadirse cualquier tipo de serie geográfica. Por ejemplo, `GeographicSymbolSeries` puede añadirse para representar ubicaciones geográficas como ciudades, y `GeographicPolylineSeries` para representar conexiones (por ejemplo, carreteras) entre estas ubicaciones geográficas.

El mapa ofrece comportamientos de navegación personalizables para desplazarse por el contenido del mapa con el ratón, el teclado o mediante código.

## Módulos de componentes

<PlatformBlock for="Angular, React, WebComponents">

`GeographicMap` requiere los siguientes módulos; sin embargo, DataChartInteractivityModule solo es necesario para las interacciones con el ratón, como desplazar y ampliar el contenido del mapa.

</PlatformBlock>

<PlatformBlock for="Blazor">

Las interacciones del ratón en el mapa, como el desplazamiento y el zoom, proceden de <ApiLink raw type="DataChartInteractivityModule" />, que ningún componente solicita por sí mismo, por lo que debe registrarse. <ApiLink raw type="GeographicMapModule" /> es opcional: el `GeographicMap` lo carga la primera vez que se renderiza (consulte [Módulos de componentes](general-getting-started.mdx#módulos-de-componentes)).

</PlatformBlock>

```json-snippet source="/maps/geo-map/type-scatter-bubble-series" channel="modulesImports...moduleRegistration" exclude="Xaml"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "map"
        }
    },
    "modules": [
        "maps/GeographicMapModule",
        "charts/DataChartInteractivityModule"
    ],
    "$modules": [
        "+doc:modulesImports",
        "+doc:moduleRegistration"
    ]
}
```

</PlatformBlock>


## Uso

Configure el mapa geográfico y habilite el zoom con el siguiente ejemplo.

```json-snippet
{
    "type": "GeographicMap",
    "height": "100%",
    "width": "100%",
    "zoomable": true
}
```
