# Primeros pasos: crear una aplicación Blazor Hybrid con .NET MAUI

Este tema ofrece instrucciones paso a paso para crear aplicaciones Blazor de .NET MAUI con Ignite UI for Blazor usando Visual Studio.

## ¿Qué es Blazor Hybrid?

Blazor Hybrid es un punto intermedio entre Blazor Server y Blazor WebAssembly. Simplifica el desarrollo, el código y los procesos, ya que reúne las capacidades de los frameworks de cliente nativo de escritorio y móvil. Esta tecnología le permite aplicar sus conocimientos de C# y .NET al crear aplicaciones de cliente nativo.

Pero para poder usarlo en sus aplicaciones, necesita .NET MAUI.

## ¿Qué es .NET MAUI?

.NET MAUI (.NET Multi-platform App UI) es un framework de código abierto y multiplataforma para crear aplicaciones nativas de escritorio y móviles a partir de una única base de código compartida. Con él, puede desarrollar más fácilmente aplicaciones Blazor que se ejecutan en distintos dispositivos y sistemas operativos, como Android, iOS, macOS y Windows, usando C# y XAML.


## Requisitos previos

- Visual Studio 2022 17.12 o posterior, con la carga de trabajo **.NET Multi-platform App UI development**

Para más información, consulte el tema [Instalación de .NET MAUI](https://learn.microsoft.com/dotnet/maui/get-started/installation).

## Crear y ejecutar una aplicación Blazor Hybrid con .NET MAUI e Ignite UI for Blazor

Los pasos siguientes describen cómo crear un proyecto nuevo de .NET MAUI Blazor. Si quiere añadir Ignite UI for Blazor a una aplicación existente, vaya a la sección [**Instalar el paquete Ignite UI for Blazor**](#instalar-ignite-ui-for-blazor).

Inicie Visual Studio, haga clic en **Crear un proyecto nuevo** en la página de inicio, seleccione la plantilla **.NET MAUI Blazor Hybrid App** y haga clic en **Siguiente**.

<Image src={newBlazorProjectMaui} alt="new-blazor-project-maui" />

Indique un nombre y una ubicación para el proyecto, y haga clic en **Siguiente**.

<Image src={newBlazorProjectConfigureMaui} alt="new-blazor-project-configure-maui" />

En el cuadro de diálogo **Información adicional**, seleccione la versión del framework y haga clic en **Crear**.

## Instalar Ignite UI for Blazor

Ignite UI for Blazor se distribuye mediante paquetes NuGet. Instale **IgniteUI.Blazor** desde el [feed de NuGet de Infragistics](./general-nuget-feed.mdx) o **IgniteUI.Blazor.Trial** desde [NuGet.org](https://www.nuget.org/packages/IgniteUI.Blazor.Trial).

Para más información sobre la instalación de Ignite UI for Blazor con NuGet, lea el tema [Instalación de Ignite UI for Blazor](./general-installing-blazor.mdx).

## Registrar Ignite UI for Blazor

1 - Abra el archivo **MauiProgram.cs** y registre el servicio de Ignite UI for Blazor llamando a la función **builder.Services.AddIgniteUIBlazor**:

```cs
public static class MauiProgram
{
    public static MauiApp CreateMauiApp()
    {
        var builder = MauiApp.CreateBuilder();
        // ...
        builder.Services.AddMauiBlazorWebView();
#if DEBUG
        builder.Services.AddBlazorWebViewDeveloperTools();
#endif

        //register IgniteUI for Blazor
        builder.Services.AddIgniteUIBlazor();
        return builder.Build();
    }
}
```

2 - Añada el espacio de nombres **IgniteUI.Blazor.Controls** en el archivo **_Imports.razor**:

<PlatformBlock for="Blazor">

```razor
@using IgniteUI.Blazor.Controls
```

</PlatformBlock>

3 - Añada la hoja de estilos en el elemento **`<head>`** del archivo **wwwroot/index.html**:

<PlatformBlock for="Blazor">

```razor
<head>
    <link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
</head>
```

</PlatformBlock>

## Añadir un componente de Ignite UI for Blazor

Añada un componente de Ignite UI for Blazor a su página razor:

<PlatformBlock for="Blazor">

```razor
<IgbCard style="width:350px">
    <IgbCardMedia>
        <img src="https://images.unsplash.com/photo-1541516160071-4bb0c5af65ba?ixlib=rb-1.2.1&ixid=eyJhcHBfaWQiOjEyMDd9&auto=format&fit=crop&w=350&q=80" />
    </IgbCardMedia>
    <IgbCardHeader>
        <h4>Jane Doe</h4>
        <h6>Professional Photographer</h6>
    </IgbCardHeader>
    <IgbCardContent>Hi! I'm Jane, photographer and filmmaker.
        Photography is a way of feeling, of touching,
        of loving. What you have caught on film is captured forever...
        it remembers little things, long after you have
        forgotten everything.</IgbCardContent>
    <IgbCardActions>
        <IgbButton>More Info</IgbButton>
    </IgbCardActions>
</IgbCard>
```

</PlatformBlock>
