# Hipervínculos de {Platform} Spreadsheet

El componente {Platform} Spreadsheet permite mostrar los hipervínculos que ya existen en su libro de Excel, así como insertar otros nuevos que pueden enlazar con sitios web, directorios de archivos e incluso otras hojas de trabajo del libro.

## Ejemplo de hipervínculos de {Platform} Spreadsheet


<Sample src="/excel/spreadsheet/hyperlinks" height={500} alt="Ejemplo de hipervínculos de {Platform} Spreadsheet" />




## Descripción general de los hipervínculos

Los hipervínculos se añaden al control <ApiLink type="Spreadsheet" /> accediendo a la colección `\Hyperlinks` de la hoja de trabajo en la que quiere colocar el hipervínculo. Esta colección tiene un método `\Add` que recibe un objeto <ApiLink type="WorksheetHyperlink" />, en el que puede definir la dirección de la celda, la URL del hipervínculo a la que se navegará, el texto que se mostrará y un tooltip que puede mostrarse opcionalmente al pasar el ratón.

## Dependencias

Al configurar su control de hoja de cálculo {Platform} para usar hipervínculos, deberá importar la clase <ApiLink type="WorksheetHyperlink" /> de la siguiente manera:

```ts

```


</PlatformBlock>

```

```

## Fragmento de código

El siguiente fragmento de código muestra cómo añadir un hipervínculo a la hoja de trabajo que se está viendo en el control {Platform} <ApiLink type="Spreadsheet" />:

```ts
this.spreadsheet.activeWorksheet.hyperlinks().add(new WorksheetHyperlink("A1", "http://www.infragistics.com", "Infragistics", "Infragistics Home Page"));
```
