# Personalizar temas en {ProductName}

Los temas de {ProductName} pueden personalizarse modificando diversas variables CSS. Al sobrescribir esas variables, puede personalizar las paletas, la tipografía, las elevaciones, el redondeado, el tamaño y el espaciado.

## Descripción general

Tratamos las paletas, la tipografía y las elevaciones en las secciones siguientes; esta sección trata las opciones que afectan a los estilos de los componentes a nivel global mediante la modificación de una sola variable.


## Redondeo

Todos los componentes definen algún tipo de redondeado (border-radius). Mientras que algunos componentes ofrecen atributos para definir la forma del componente, como el avatar y el badge, otros, como el botón, solo definen su border-radius internamente como parte del tema. En esos casos, puede ajustar el border-radius de esos componentes modificando el valor de la variable CSS `--ig-radius-factor`. Puede modificarla globalmente en el ámbito `:root`, o componente por componente. La variable acepta un valor numérico racional entre 0 y 1. Si establece el valor en 0, el border-radius queda efectivamente en 0. Si lo establece en 1, el border-radius vuelve al valor inicial predefinido. Cualquier valor entre 0 y 1, por ejemplo 0,5, establecerá el border-radius al 50 % del border-radius predeterminado definido en la hoja de estilos del componente.

Ejemplos:

```css
/* Set the border-radius for all components to 50% of their default value. */
:root {
  --ig-radius-factor: .5;
}
```

```css
/* Set the border-radius of the button component to 0. */
igc-button {
  --ig-radius-factor: 0;
}
```

## Elevación

Igual que con el radio global, algunos componentes definen una elevación interna (box-shadow). Dejar planos todos los componentes puede resultar tedioso si se hace sobrescribiendo el box-shadow de cada uno. Puede modificar el comportamiento del box-shadow de todos los componentes modificando la variable CSS `--ig-elevation-factor`. La variable acepta un valor numérico racional entre 0 y 1. Si establece el valor en 0, el box-shadow de todos los componentes queda efectivamente en none. Si lo establece en 1, el valor de elevación vuelve a los valores de box-shadow iniciales predefinidos. Cualquier valor entre 0 y 1, por ejemplo 0,5, establecerá la intensidad del box-shadow al 50 % del valor original definido en la hoja de estilos del componente.

```css
/* Set the elevation for all components to 50% of their original box-shadow values. */
:root {
  --ig-elevation-factor: .5;
}
```

## Tamaño

Algunos componentes admiten dimensionado variable: `small`, `medium` y `large`, con un tamaño predeterminado definido en la hoja de estilos del componente. Puede modificar el tamaño de todos los componentes a la vez, o de forma individual, usando la variable CSS `--ig-size`. Los valores posibles son `var(--ig-size-small)`, `var(--ig-size-medium)` o `var(--ig-size-large)`;

Para establecer un tamaño concreto para todos los componentes de su aplicación, defina la variable `--ig-size` en el ámbito `:root`.

Ejemplo:

```css
:root {
  --ig-size: var(--ig-size-small);
}
```

Como alternativa, si quiere dirigirse solo a un componente concreto, limite el ámbito de la variable al selector de etiqueta del componente.

```css
igc-avatar {
  --ig-size: var(--ig-size-medium);
}
```

## Espaciado

El espaciado se refiere a los rellenos y márgenes internos de los componentes, tal como los establece el tema del componente. El espaciado puede ser horizontal (en línea) y vertical (en bloque). Hemos facilitado el control del relleno de los distintos elementos dentro de un componente, sin tener que sobrescribir manualmente todos los valores de relleno y margen de cada componente. Esto se hace con la variable CSS `--ig-spacing`. Puede establecer su valor en cualquier número racional positivo, y el espaciado se escalará en consecuencia. El valor predeterminado es 1, que representa el relleno/margen horizontal/vertical predeterminado definido en la hoja de estilos del componente. Si cambia el valor a 1,5, todo el espaciado se escalará 1,5 veces, es decir, un 150 %. Por el contrario, si establece el valor en 0, todo quedará pegado y el espaciado se reducirá a la equivalencia de ningún relleno/margen. Cambiar el factor de espaciado funciona junto con la propiedad de tamaño y se escala en consecuencia.

Algunos componentes solo le permiten alterar su espaciado en una dirección (horizontal o vertical), mientras que otros le permiten especificar valores de espaciado distintos en ambas direcciones.

Para alterar el espaciado de todos los componentes, puede sobrescribir su valor en el ámbito `:root`.

Ejemplo:

```css
/* Increase the spacing for all components to 150%. */
:root {
  --ig-spacing: 1.5;
}
```

Para cambiar el espaciado de un único componente, limite el ámbito de la variable al selector de etiqueta del componente.

```css
/* Reduce the spacing for the drop-down elements to 50% of their original value. */
igc-dropdown {
  --ig-spacing: 0.5;
}
```

Como se ha dicho antes, puede controlar el espaciado horizontal y vertical de forma individual en los componentes que lo admiten. Esto se consigue modificando las variables `--ig-spacing-inline` (horizontal) y `--ig-spacing-block` (vertical). El principio es el mismo que con la variable `--ig-spacing`. Modificar solo la variable `--ig-spacing` cambiará el espaciado en ambas direcciones en la misma cantidad.
