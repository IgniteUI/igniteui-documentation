# Tipografía en {ProductName}

La tipografía de {ProductName} se inspira en el [Material Type System](https://material.io/design/typography/the-type-system.html#). No es intrusiva y es opcional, lo que le permite modificar los estilos de texto solo con CSS.

## Descripción general

El sistema de tipos es una **_escala tipográfica_** compuesta por **_13 estilos tipográficos de categoría diferentes_** que se usan en la mayoría de los componentes. Todas las categorías de la escala son totalmente reutilizables y ajustables por el usuario final.

Cada tema define su propia escala tipográfica. Esto significa que cada uno de los temas que incluimos (Material, Fluent, Bootstrap e Indigo) tendrá su propia escala tipográfica. Todos comparten las mismas _categorías de escala_, pero pueden tener distinta familia tipográfica, grosor, tamaño, transformación del texto, espaciado entre letras y altura de línea.

## Uso

### Cambiar la familia tipográfica

Para cambiar la familia tipográfica en todos los componentes, basta con sobrescribir la variable CSS `--ig-font-family`:

```css
:root {
  --ig-font-family: 'Helvetica Neue', sans-serif;
}
```

### Cambiar los estilos tipográficos

La mayoría de los componentes de {ProductName} usan internamente los estilos tipográficos. Por ejemplo, el componente `igc-button` usa el estilo tipográfico de botón.
Para cambiar cualquiera de las propiedades de estilo tipográfico, hay que sobrescribir la variable CSS correspondiente:

```css
:root {
  --ig-button-font-size: 22px;
  --ig-button-line-height: 26px;
  --ig-button-text-transform: lowercase;
}
```

Tenga en cuenta que esto actualizará los estilos tipográficos globales de los botones. Si quiere aplicar estos cambios a un botón concreto, puede usar un selector de clase.
