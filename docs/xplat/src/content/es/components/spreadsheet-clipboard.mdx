## Uso

El siguiente fragmento de código muestra cómo puede ejecutar comandos relacionados con el portapapeles en el control {Platform} <ApiLink type="Spreadsheet" />:

```ts
public cut(): void {
    this.spreadsheet.executeAction(SpreadsheetAction.Cut);
}

public copy(): void {
    this.spreadsheet.executeAction(SpreadsheetAction.Copy);
}

public paste(): void {
    this.spreadsheet.executeAction(SpreadsheetAction.Paste);
}
```
