## Uso

Establezca `value` con cualquier cadena para renderizar un código QR escaneable. El componente elige el modo de codificación más compacto (numérico, alfanumérico o de bytes) y la versión QR más pequeña que quepa en el valor. Al borrar `value` se elimina el SVG.

### Corrección de errores

Use `errorLevel` para elegir el nivel de corrección de errores `L`, `M` (predeterminado), `Q` o `H`. Los niveles más altos recuperan más información de un código dañado o cubierto, pero producen un código más denso. Use `version` para anclar una versión de QR entre `1` y `40` cuando necesite dimensiones de módulo predecibles; déjela sin establecer para usar la versión más pequeña que quepa en `value`.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-qr-code
  value="https://www.infragistics.com"
  version="4"
  error-level="H">
</igc-qr-code>
```

</PlatformBlock>

### Logotipo central

Establezca `logoSrc` para renderizar una imagen en el centro del código; el componente enmascara los módulos que hay debajo. `logoSize` establece el tamaño del logotipo como una proporción de `0` a `1` del área de logotipo segura más grande, que es el 9 % del código con el nivel `H`. `logoMargin` añade espacio en blanco alrededor del logotipo en píxeles.

El logotipo nunca cubre más de lo que permite el `errorLevel` actual. Con el nivel `M` predeterminado, los valores de `logoSize` por encima de aproximadamente `0.44` se renderizan con el mismo tamaño limitado, así que establezca `errorLevel` en `H` para obtener el logotipo más grande.

`logoSrc` acepta URL normales y URI `data:image/*`. Los orígenes con esquemas no seguros (como `javascript:` o `vbscript:`) y los URI `data:` que no son de imagen se rechazan, y no se renderiza ningún logotipo.

  logo-margin="4">
</igc-qr-code>

### Exportar

Llame a `toImage()` para exportar el código QR como archivo PNG, JPEG, WebP o SVG, o a `toBlob()` para obtenerlo como `Blob` SVG. Ambos métodos resuelven los colores del tema y añaden el logotipo en línea, de modo que la exportación coincide con el código renderizado.

```ts
const qrCode = document.querySelector('igc-qr-code') as IgcQrCodeComponent;

// Downloads a 512×512 PNG from a 256px QR code.
await qrCode.toImage({ format: 'png', scale: 2, fileName: 'my-qr-code', download: true });
```

</PlatformBlock>

### Qué hacer y qué no

**Cuándo usarlo:** los códigos QR ofrecen a los usuarios un puente rápido desde un medio impreso o una pantalla estática hacia una acción digital, como abrir una página, descargar una aplicación o verificar un enlace.

**Cuándo no usarlo:** evite los códigos QR para información que deba poder leerse sin escáner, o cuando un botón, un enlace directo o una URL corta sirvan mejor al destino.

## Métodos

| Nombre | Devuelve | Descripción |
| -- | -- | -- |
| `toBlob()` | `Promise<Blob>` | Serializa el código QR como un blob `image/svg+xml` con los colores del tema resueltos y el logotipo en línea. Se rechaza cuando `value` no está establecido. |
| `toImage(options?)` | `Promise<File>` | Exporta el código QR como archivo de imagen. `options` acepta `format` (`'png'` predeterminado, `'jpeg'`, `'webp'` o `'svg'`), `scale` (predeterminado `1`), `fileName` (predeterminado `'qr-code'`) y `download` (predeterminado `false`). Se rechaza cuando `value` no está establecido o las opciones no son válidas. |

El aspecto del {Platform} QR Code se controla mediante variables CSS, partes CSS y el sistema de temas.

### Variables de estilo

| Variable | Qué cambia |
| -- | -- |
| `--ig-qr-code-background` | El color de fondo del código QR. Por defecto, `white`. |
| `--ig-qr-code-dark-color` | El color de los módulos de datos, y el de los cuadrados y puntos de las esquinas salvo que se sobrescriba. Por defecto, `black`. |
| `--ig-qr-code-corner-square-color` | El color de los cuadrados exteriores de las esquinas del patrón de localización. Recurre a `--ig-qr-code-dark-color`. |
| `--ig-qr-code-corner-dot-color` | El color de los puntos interiores de las esquinas del patrón de localización. Recurre a `--ig-qr-code-dark-color`. |

### Partes de estilo

| Parte | Qué estiliza |
| -- | -- |
| `background` | El rectángulo de fondo del código QR. |
| `dots` | Los módulos de datos (puntos) del código QR. |
| `corner-square` | Los cuadrados exteriores de las esquinas del patrón de localización. |
| `corner-dot` | Los puntos interiores de las esquinas del patrón de localización. |

## Accesibilidad

El {Platform} QR Code es un gráfico estático que los lectores de pantalla anuncian mediante el `<title>` de su SVG.

### Interacción por teclado

El QR Code no es enfocable y no responde a la entrada del teclado.

### Lectores de pantalla / ARIA

El `<svg>` renderizado tiene `role="img"` y un `<title>` que los lectores de pantalla anuncian. El título predeterminado es `QR code: <value>`; establezca `aria-label` para anunciar una frase más significativa.

<PlatformBlock for="WebComponents, Angular">

```html
<igc-qr-code
  value="https://www.infragistics.com/products"
  aria-label="Scan to visit our product page">
</igc-qr-code>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrQrCode
  value="https://www.infragistics.com/products"
  ariaLabel="Scan to visit our product page">
</IgrQrCode>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

  Value="https://www.infragistics.com/products"
  AriaLabel="Scan to visit our product page">
</IgbQrCode>
```

</PlatformBlock>

### Cumplimiento de accesibilidad

Infragistics documenta la compatibilidad de accesibilidad de {ProductName} con las áreas de las pautas de la Sección 508 y WCAG 2.1 en el tema [Cumplimiento de accesibilidad](../interactivity/accessibility-compliance.mdx).

| Criterio | Cómo cumple el componente |
| -- | -- |
| [1.1.1 Contenido no textual](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content) | El `<title>` del SVG proporciona una alternativa textual, tomada de `aria-label` o derivada de `value`. |
| [1.4.11 Contraste de elementos no textuales](https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast) | Los módulos negros predeterminados sobre fondo blanco superan la relación de contraste de 3:1 para los objetos gráficos. |
| [4.1.2 Nombre, función, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value) | El SVG expone `role="img"` con `<title>` como su nombre accesible. |

Sus responsabilidades:

- Acompañe el QR Code con una llamada a la acción breve y visible, para que los usuarios que ven puedan saber qué ocurrirá después de escanearlo.
- Proporcione un `aria-label` cuando el `value` codificado sea opaco (por ejemplo, un token o un identificador corto), para que el texto anunciado sea significativo.
- Mantenga un contraste suficiente entre el color de los módulos y el fondo al sobrescribir las variables CSS, para que los escáneres puedan leer el código de forma fiable.

## Solución de problemas

La guía de resolución de problemas del {Platform} QR Code sigue un formato problema → causa → solución para los problemas habituales de integración y de renderizado.

### ¿Por qué mi código QR no se escanea?

El contraste entre los módulos y el fondo es demasiado bajo, el código es demasiado pequeño en la pantalla o el margen de la zona silenciosa es demasiado pequeño. Restaure los colores `black` predeterminados en `white`, aumente `size`, y use un `margin` de al menos `4` módulos para un escaneo fiable.

### ¿Por qué mi logotipo es más pequeño que el logoSize que establecí?

El logotipo se limita al área segura de la `errorLevel` actual. Establezca `errorLevel` en `H` para permitir el logotipo más grande.

### ¿Por qué no aparece mi logotipo?

`logoSrc` usa un origen rechazado (un esquema no seguro o un URI `data:` que no es de imagen), o la imagen no se ha cargado. Use una URL de imagen válida o un URI `data:image/*`; asignar después un origen válido renderiza el logotipo.

### ¿Por qué mi código QR no cambió automáticamente a un tema oscuro?

Los colores del QR Code no se invierten con el tema global claro/oscuro, porque los códigos de texto claro sobre fondo oscuro no se pueden escanear de forma fiable. Para cambiarlos en la variante oscura de su interfaz, establezca `--ig-qr-code-background` y `--ig-qr-code-dark-color` explícitamente.

## Limitaciones conocidas

El {Platform} QR Code tiene las siguientes limitaciones.

- El QR Code no tiene slots ni eventos.
- La estructura visual del QR Code sigue una disposición fija y estandarizada, y no se refleja en contextos de derecha a izquierda.

<PlatformBlock for="WebComponents, Angular">

- Las exportaciones omiten un logotipo cargado desde una URL de origen cruzado que no envía cabeceras CORS.

</PlatformBlock>

## Preguntas frecuentes

<Faq>
  <FaqItem question="¿Qué datos puedo codificar en un código QR?" indicatorPosition="end">
    La propiedad `value` acepta cualquier cadena. Los usos habituales incluyen URL, texto plano, referencias de pago, tokens de configuración de un solo uso, credenciales de Wi-Fi y cargas vCard. El componente selecciona automáticamente el modo de codificación más compacto (numérico, alfanumérico o de bytes) que cabe en la entrada.
  </FaqItem>

  <FaqItem question="¿Necesito una conexión a internet o una biblioteca externa para renderizar un QR Code?" indicatorPosition="end">
    No. El componente QR Code genera el SVG completamente en el cliente a partir de la cadena `value`, sin depender de bibliotecas externas de generación de QR. La única petición de red es para la imagen del logotipo central cargada desde una URL.
  </FaqItem>

  <FaqItem question="¿Qué tamaño puede tener el logotipo central sin romper el código?" indicatorPosition="end">
    La proporción `logoSize` (predeterminada `0.4`) es una fracción del área de logotipo segura más grande, que es el 9 % del código con el nivel de error `H`. El QR Code limita el logotipo al área segura de la `errorLevel` actual, de modo que el código sigue siendo escaneable. Establezca `errorLevel` en `H` para permitir el logotipo más grande.
  </FaqItem>
