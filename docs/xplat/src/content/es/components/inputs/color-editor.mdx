# Descripción general del Editor de color de {Platform} <Badge variant="preview" />
El Editor de color de {ProductName} es un componente selector de color ligero. El Editor de color puede abrirse haciendo clic en el icono del pincel. En la parte inferior se pueden obtener los valores rgba y hex del color deseado. Estos valores se actualizan al modificar los tres controles deslizantes. El cuadro central está diseñado para ajustar la saturación y el brillo, junto con dos controles deslizantes adyacentes para ajustar los valores rgb y de luminancia. Rgb se registra entre (1-255). La luminosidad se registra entre (0-1).

## Uso

La forma más sencilla de empezar a usar `ColorEditor` es la siguiente:


```json-snippet source="/inputs/color-editor/overview" code="allCode"
{
    "type": "ColorEditor",
    "name": "colorEditor"
}
```

## Enlazar eventos

El componente Editor de color lanza los siguientes eventos:

- valueChanged
- valueChanging

```json-snippet source="/inputs/color-editor/overview" code="allCode"
{
    "type": "ColorEditor",
    "name": "colorEditor",
    "valueChangedRef": "ColorEditorValueChanged"
}
```

El controlador recibe el editor y un `ColorEditorPanelSelectedValueChangedEventArgs`, cuyo `newValue` contiene el color recién elegido:

```json-snippet source="/inputs/color-editor/overview" channel="handlersImports...handler"
{
    "type": "ColorEditor",
    "name": "colorEditor",
    "valueChangedRef": "ColorEditorValueChanged",
    "$valueChangedRef": "+doc:handler"
}
```
