# Descripción general del progreso circular de {Platform}

El componente Indicador de progreso circular de {ProductName} proporciona un indicador visual del proceso de una aplicación a medida que cambia. El indicador circular actualiza su aspecto a medida que cambia su estado.

### Tipos de progreso

Puede establecer el tipo de su indicador usando el atributo <ApiLink pkg="core" type="CircularProgress" member="variant" label="Variant" />. Hay cinco tipos de indicadores de progreso circular: **primary** (predeterminado), **error**, **success**, **info** y **warning**.

<PlatformBlock for="React">

```tsx
<IgrCircularProgress value="100" variant="success"></IgrCircularProgress>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-circular-progress value="100" variant="success"></igc-circular-progress>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCircularProgress Value=100 Variant=@ProgressBaseVariant.Success  />
```

</PlatformBlock>

### Progreso indeterminado

Si quiere hacer seguimiento de un proceso que no está determinado con precisión, puede establecer la propiedad <ApiLink pkg="core" type="CircularProgress" member="indeterminate" label="Indeterminate" />. Además, puede ocultar la etiqueta predeterminada del {ProductName} <ApiLink pkg="core" type="CircularProgress" /> estableciendo la propiedad <ApiLink pkg="core" type="CircularProgress" member="hideLabel" label="HideLabel" />, y personalizar la etiqueta predeterminada del indicador de progreso mediante la propiedad expuesta <ApiLink pkg="core" type="CircularProgress" member="labelFormat" label="LabelFormat" />.

```tsx
<IgrCircularProgress value="100" indeterminate="true"></IgrCircularProgress>
```

</PlatformBlock>

### Progreso con degradado

La barra de progreso puede personalizarse para usar un degradado de color en lugar de un color sólido, usando el slot `gradient` y el componente <ApiLink pkg="core" type="CircularGradient" />, que define los puntos del degradado.

<Sample src="/inputs/circular-progress-indicator/dynamic" height={200} alt="Ejemplo dinámico de progreso circular de {Platform}" />

<DocsAside type="info">
Por cada <ApiLink pkg="core" type="CircularGradient" /> definido como slot `gradient` de {ProductName} <ApiLink pkg="core" type="CircularProgress" /> se crearía un elemento [SVG stop](https://developer.mozilla.org/en-US/docs/Web/SVG/Element/stop). Los valores pasados como `color`, `offset` y `opacity` se establecerían como stop-color, offset y stop-opacity del elemento SVG sin más validaciones.
</DocsAside>

```tsx
    <IgrCircularGradient slot="gradient" offset="100%" color="#ff0079">

</IgrCircularProgress>
```

## Estilos

El componente <ApiLink pkg="core" type="CircularProgress" /> expone partes CSS para casi todos sus elementos internos:

|Nombre|Descripción|
|--|--|
| `svg`               | El elemento SVG del progreso.                 |
| `gradient_start`     | El color inicial del degradado lineal del progreso. |
| `gradient_end`       | El color final del degradado lineal del progreso.   |
| `track`              | El área de pista del anillo de progreso.           |
| `fill`               | El área del indicador de progreso.              |
| `label`              | La etiqueta del progreso.                       |
| `value`              | El valor de la etiqueta del progreso.                 |
| `indeterminate`      | El estado indeterminado del progreso.         |
| `primary`            | El estado primary del indicador de progreso.     |
| `danger`             | El estado de error del indicador de progreso.       |
| `warning`            | El estado de advertencia del indicador de progreso.     |
| `info`               | El estado de información del indicador de progreso.        |
| `success`            | El estado de éxito del indicador de progreso.     |

Con estas partes CSS tenemos un control casi total sobre el estilo del progreso circular.

```css

igc-circular-progress {
  margin: 20px;
  --diameter: 50px;
}

igc-circular-progress::part(gradient_end),
igc-circular-progress::part(gradient_start) {
  stop-color: var(--ig-success-200);
}

igc-circular-progress::part(track) {
  stroke: var(--ig-gray-400);
}

```
