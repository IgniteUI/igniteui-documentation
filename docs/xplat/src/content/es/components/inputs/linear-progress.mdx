# {Platform} Linear Progress - Descripción general

El componente {ProductName} Linear Progress Indicator proporciona un indicador visual del proceso de una aplicación a medida que cambia. El indicador <ApiLink pkg="core" type="LinearProgress" /> actualiza su aspecto a medida que cambia su estado. Además, puede dar estilo a este componente con una selección de colores en rayas o sólidos.

### Tipos de progreso

Puede establecer el tipo de su indicador usando el atributo <ApiLink pkg="core" type="LinearProgress" member="variant" label="Variant" />. Hay cinco tipos de indicadores de progreso lineales: **primary** (predeterminado), **error**, **success**, **info** y **warning**.

<PlatformBlock for="React">

```tsx

```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html

```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

```

</PlatformBlock>

### Progreso indeterminado

Si quiere hacer seguimiento de un proceso que no está determinado con precisión, puede establecer la propiedad <ApiLink pkg="core" type="LinearProgress" member="indeterminate" label="Indeterminate" />.

### Duración de la animación

La propiedad <ApiLink pkg="core" type="LinearProgress" member="animationDuration" label="AnimationDuration" /> sirve para especificar cuánto debe durar el ciclo de animación. Su valor es un número que representa la duración de la animación en milisegundos.

### Propiedades del texto

Puede alinear el valor predeterminado usando la propiedad <ApiLink pkg="core" type="LinearProgress" member="labelAlign" label="LabelAlign" />. Los valores permitidos son **top**, **bottom**, **top-start**, **top-end**, **bottom-start** y **bottom-end**.

Para ocultar la etiqueta predeterminada del indicador de progreso, use el atributo <ApiLink pkg="core" type="LinearProgress" member="hideLabel" label="HideLabel" />.

La propiedad <ApiLink pkg="core" type="LinearProgress" member="labelFormat" label="LabelFormat" /> puede usarse para personalizar la etiqueta predeterminada <ApiLink pkg="core" type="LinearProgress" />.

## Estilos

El componente <ApiLink pkg="core" type="LinearProgress" /> expone partes CSS para casi todos sus elementos internos:

|Nombre|Descripción|
|--|--|
| `track`         | El área de pista del anillo de progreso. |
| `fill`          | El área del indicador de progreso. |
| `striped`       | El indicador de progreso con rayas. |
| `label`         | La etiqueta del indicador de progreso. |
| `value`         | El valor de la etiqueta del progreso. |
| `indeterminate` | El estado indeterminado del progreso. |
| `primary`       | El estado primary del indicador de progreso. |
| `danger`        | El estado de error del indicador de progreso. |
| `warning`       | El estado de advertencia del indicador de progreso. |
| `info`          | El estado de información del indicador de progreso. |
| `success`       | El estado de éxito del indicador de progreso. |

Con estas partes CSS tenemos un control casi total sobre el estilo del Linear Progress.

<Sample src="/inputs/linear-progress-indicator/styling" height={80} alt="Estilo de {Platform} Linear Progress" />


```css
igc-linear-progress::part(track){
  background-color: var(--ig-gray-300)
}

igc-linear-progress::part(fill){
  background-color: var(--ig-primary-300)
}

igc-linear-progress::part(label){
  color: var(--ig-primary-300)
}
```
