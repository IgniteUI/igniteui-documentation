# Radio Group

Los componentes Radio y Radio Group de {Platform} permiten a los usuarios seleccionar exactamente una opción de un conjunto de opciones mutuamente excluyentes. Cada radio button representa una opción, y el Radio Group dispone los radio buttons en una disposición vertical u horizontal.

## Primeros pasos

Para usar los componentes Radio y Radio Group de {Platform}, siga el tema <PlatformBlock for="Angular">[{ProductName} Primeros pasos](../general/getting-started.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[{ProductName} Primeros pasos](../general-getting-started.mdx)</PlatformBlock> para la configuración básica del proyecto y, después, importe o registre los componentes para su plataforma de destino.

<PlatformBlock for="WebComponents">

Importe <ApiLink pkg="core" type="Radio" /> y <ApiLink pkg="core" type="RadioGroup" />, un tema, y registre los componentes:

```ts
import { defineComponents, IgcRadioComponent, IgcRadioGroupComponent } from 'igniteui-webcomponents';
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcRadioComponent, IgcRadioGroupComponent);
```

</PlatformBlock>

<PlatformBlock for="React">

Importe los wrappers <ApiLink pkg="core" type="Radio" /> y <ApiLink pkg="core" type="RadioGroup" /> y un tema:

```tsx
import { IgrRadio, IgrRadioGroup } from 'igniteui-react';
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Registre los servicios de {ProductName}:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

Registrar <ApiLink pkg="core" type="RadioGroupModule" />, el módulo de recursos de cliente del <ApiLink pkg="core" type="RadioGroup" />, es **opcional**: el componente carga sus recursos cuando se renderiza por primera vez. Incluirlo en `builder.Services.AddIgniteUIBlazor(typeof(IgbRadioGroupModule))` puede usarse para precargar recursos o para admitir elementos creados solo en el cliente; también registra los elementos de radio dentro del grupo. Un <ApiLink pkg="core" type="Radio" /> usado por sí solo tiene su propio módulo, <ApiLink pkg="core" type="RadioModule" /> (véase [Component Modules](../general-getting-started.mdx#módulos-de-componentes)).

Después, añada la hoja de estilos del tema a su página host:

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```

</PlatformBlock>

<PlatformBlock for="Angular">

Importe el componente <ApiLink type="Radio" /> y la directiva <ApiLink type="RadioGroupDirective" />:

```ts
import { IgxRadioComponent, IgxRadioGroupDirective } from 'igniteui-angular/radio';
```

Añada ambos a la colección `imports` de su componente, o añada la colección `IGX_RADIO_GROUP_DIRECTIVES`, que los contiene, y después use los elementos `igx-radio-group` y `igx-radio` en su plantilla.

</PlatformBlock>

Después del registro, coloque los componentes {Platform} Radio dentro de un Radio Group y dé al grupo un `name`, para que los usuarios solo puedan seleccionar una de las opciones. Establezca `value` en cada radio button para identificar la opción seleccionada.

## Uso

### Disposición

El {Platform} Radio coloca su etiqueta después del control de radio de forma predeterminada. Establezca la propiedad <ApiLink pkg="core" type="Radio" member="labelPosition" label="labelPosition" /> en `before` para colocar la etiqueta antes del control. En un Radio Group vertical, los radio buttons con la etiqueta antes del control se alinean al final del grupo.

<PlatformBlock for="React,WebComponents,Blazor">

Coloque los radio buttons como hijos directos del Radio Group. Los radio buttons dentro de un elemento contenedor no forman parte del grupo, y el grupo no los dispone.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-radio-group name="color">
  <igc-radio value="yellow" label-position="before" checked>Yellow</igc-radio>
  <igc-radio value="orange" label-position="before">Orange</igc-radio>
</igc-radio-group>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrRadioGroup name="color">
  <IgrRadio value="yellow" labelPosition="before" checked={true}>Yellow</IgrRadio>
  <IgrRadio value="orange" labelPosition="before">Orange</IgrRadio>
</IgrRadioGroup>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbRadioGroup name="color">
    <IgbRadio Value="yellow" LabelPosition="ToggleLabelPosition.Before" Checked="true">Yellow</IgbRadio>
    <IgbRadio Value="orange" LabelPosition="ToggleLabelPosition.Before">Orange</IgbRadio>
</IgbRadioGroup>
```

</PlatformBlock>

<PlatformBlock for="Angular">

```html
<igx-radio-group name="color" alignment="vertical" value="yellow">
  <igx-radio value="yellow" labelPosition="before">Yellow</igx-radio>
  <igx-radio value="orange" labelPosition="before">Orange</igx-radio>
</igx-radio-group>
```

</PlatformBlock>

<PlatformBlock for="Angular,React,WebComponents">

Un radio button también puede etiquetarse con un elemento externo a él. Referencie el elemento con `aria-labelledby` cuando necesite control total sobre dónde se sitúa la etiqueta y cómo se ve.

</PlatformBlock>

<PlatformBlock for="React,WebComponents">

El elemento externo nombra el radio button en `igniteui-webcomponents` 7.4.1 y versiones posteriores. En versiones anteriores, el radio button no obtiene de él ningún nombre accesible.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html

<igc-radio aria-labelledby="radio-label" value="express"></igc-radio>
```

### Formularios

El {Platform} Radio envía el `value` del radio button seleccionado bajo el `name` del grupo. Establezca la propiedad <ApiLink pkg="core" type="Radio" member="required" label="required" /> en un radio button del grupo para exigir una selección antes de enviar el formulario.

<PlatformBlock for="React,WebComponents,Blazor">

Para mostrar un mensaje cuando falta la selección, colóquelo en el slot `value-missing` de un radio button. La selección obligatoria hace no válidos todos los radio buttons del grupo, así que coloque el mensaje en el último radio button para que se muestre debajo del grupo.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<form>
  <igc-radio-group name="fruit">
    <igc-radio value="apple" required>Apple</igc-radio>
    <igc-radio value="banana">Banana</igc-radio>
    <igc-radio value="orange">
      Orange
      <span slot="value-missing">Choose a fruit.</span>
    </igc-radio>
  </igc-radio-group>
</form>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<form>
  <IgrRadioGroup name="fruit">
    <IgrRadio value="apple" required={true}>Apple</IgrRadio>
    <IgrRadio value="banana">Banana</IgrRadio>
    <IgrRadio value="orange">
      Orange
      <span slot="value-missing">Choose a fruit.</span>
    </IgrRadio>
  </IgrRadioGroup>
</form>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbRadioGroup name="fruit">
    <IgbRadio Value="apple" Required="true">Apple</IgbRadio>
    <IgbRadio Value="banana">Banana</IgbRadio>
    <IgbRadio Value="orange">
        Orange
        <span slot="value-missing">Choose a fruit.</span>
    </IgbRadio>
</IgbRadioGroup>
```

<DocsAside type="warning" title="Warning">
El componente <ApiLink pkg="core" type="Radio" /> no funciona con un elemento HTML `<form>` estándar en Blazor. Use en su lugar el componente `EditForm` de Blazor.
</DocsAside>

</PlatformBlock>

<PlatformBlock for="Angular">

El Radio Group funciona con formularios basados en plantillas y con formularios reactivos. Enlace el valor seleccionado con `ngModel` o con un control de formulario en `igx-radio-group`:

```html
<form [formGroup]="fruitsForm">
  <igx-radio-group name="fruit" alignment="vertical" formControlName="favoriteFruit">
    <igx-radio value="apple">Apple</igx-radio>
    <igx-radio value="banana">Banana</igx-radio>
    <igx-radio value="orange">Orange</igx-radio>
  </igx-radio-group>
</form>
```

</PlatformBlock>

### Qué hacer y qué no

Al ampliar un Radio Group con elementos adicionales, asegúrese de que se alineen de forma coherente y formen una única columna. Evite la disposición en varias columnas, así como las situaciones en las que haya más de un elemento Radio en estado activado a la vez.

## Accesibilidad

El {Platform} Radio renderiza un input de radio nativo, así que las tecnologías de asistencia anuncian cada radio button con su rol, su etiqueta y su estado marcado.

### Interacción por teclado

El {Platform} Radio Group mueve el foco y la selección entre sus radio buttons habilitados con las teclas de flecha. Los radio buttons deshabilitados se omiten.

| Clave | Acción |
| --- | --- |
| Tab / Shift+Tab | Mueve el foco hacia dentro o hacia fuera del Radio Group. |
| Flecha abajo / Flecha derecha | Mueve el foco al radio button habilitado siguiente y lo activa. Desde el último radio button, pasa al primero. En disposiciones de derecha a izquierda, Arrow Right pasa al radio button anterior. |
| Flecha arriba / Flecha izquierda | Mueve el foco al radio button habilitado anterior y lo activa. Desde el primer radio button, pasa al último. En disposiciones de derecha a izquierda, Arrow Left pasa al radio button siguiente. |
| Space | Activa el radio button enfocado. |
<PlatformBlock for="React,WebComponents,Blazor">| Enter | Envía el formulario que contiene el radio button. |</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Cuando un radio button del grupo está activado, es la única parada de tabulación del grupo. Cuando ninguno de los radio buttons está activado, cada uno de ellos es una parada de tabulación.

</PlatformBlock>

<PlatformBlock for="Blazor">

En `IgniteUI.Blazor` 26.1, borrar la selección por código no deja ninguna parada de tabulación en el grupo. Consulte [Limitaciones conocidas](#limitaciones-conocidas).

</PlatformBlock>

### Lectores de pantalla / ARIA

- Cada {Platform} Radio renderiza un `<input type="radio">` nativo, que expone el rol de radio, el estado marcado y los estados deshabilitado y obligatorio.<PlatformBlock for="Angular"> El input también establece `aria-invalid` a partir de la propiedad `invalid`.</PlatformBlock>
- El contenido de la etiqueta del radio button es su nombre accesible.<PlatformBlock for="Angular,React,WebComponents"> Cuando la etiqueta está fuera del componente, conéctela con `aria-labelledby`.</PlatformBlock>

<PlatformBlock for="React,WebComponents">

- El Radio Group renderiza el rol `radiogroup` y establece `aria-orientation` a partir de su `alignment`.

</PlatformBlock>

<PlatformBlock for="Blazor">

- El Radio Group renderiza el rol `radiogroup`. En `IgniteUI.Blazor` 26.1, no establece `aria-orientation`.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

- Dé al Radio Group un nombre accesible, por ejemplo, con `aria-labelledby` apuntando a la pregunta que responde.

</PlatformBlock>

<PlatformBlock for="Angular">

- El elemento `igx-radio-group` no renderiza el rol `radiogroup`. Añada `role="radiogroup"` y un nombre accesible, por ejemplo con `aria-labelledby`, cuando el grupo deba anunciarse como una sola pregunta.

</PlatformBlock>

### Cumplimiento de accesibilidad

## Limitaciones conocidas

</PlatformBlock>

<PlatformBlock for="Blazor">

El {Platform} Radio y el Radio Group tienen las siguientes limitaciones conocidas:

- El Radio no funciona con un elemento HTML `<form>` estándar en Blazor. Use en su lugar el componente `EditForm` de Blazor.
- En `IgniteUI.Blazor` 26.1, un radio button no puede etiquetarse con un elemento externo a él. `IgbRadio` no tiene el parámetro `AriaLabelledBy`, y un atributo `aria-labelledby` no da al radio button un nombre accesible. Coloque el texto de la etiqueta dentro del radio button.
- En `IgniteUI.Blazor` 26.1, borrar la selección por código saca a todos los radio buttons del orden de tabulación. Los usuarios de teclado no pueden llegar al grupo hasta que un clic del ratón o su código vuelva a activar uno de sus radio buttons.

</PlatformBlock>

<PlatformBlock for="Angular">

El {Platform} Radio y el Radio Group tienen la siguiente limitación conocida:

- El elemento `igx-radio-group` no renderiza el rol `radiogroup`. Añada usted mismo el rol y un nombre accesible al elemento.

</PlatformBlock>
