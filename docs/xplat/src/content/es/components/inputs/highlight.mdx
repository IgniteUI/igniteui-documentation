# {Platform} Highlight - Descripción general

{ProductName} Highlight se usa para resaltar partes del contenido de la página para que sean más visibles para el usuario. Es un componente ligero que puede usarse junto con otros componentes para crear una experiencia de usuario más interactiva y atractiva.

<igc-divider></igc-divider>

## Uso

Para usar el componente <ApiLink pkg="core" type="Highlight" />, solo tiene que envolver con sus etiquetas el contenido en el que quiere buscar. El componente busca en el contenido de todos los elementos anidados dentro de las <PlatformBlock for="WebComponents">`<igc-highlight>`</PlatformBlock><PlatformBlock for="React">`<IgrHighlight>`</PlatformBlock><PlatformBlock for="Blazor">`<IgbHighlight>`</PlatformBlock> etiquetas, y resalta todas las coincidencias de la cadena especificada.

<DocsAside type="note">
El componente <ApiLink pkg="core" type="Highlight" /> solo busca en los nodos de texto del DOM. No busca los valores de los campos de entrada ni el contenido establecido mediante la propiedad CSS `content`.
</DocsAside>

### Coincidencia sensible a mayúsculas

El componente <ApiLink pkg="core" type="Highlight" /> también expone un atributo <ApiLink type="BaseSearchInfo" member="caseSensitive" label="case-sensitive" />. Su valor predeterminado es `false`, que habilita la coincidencia sin distinguir mayúsculas y minúsculas. Si lo establece en `true`, puede habilitar la coincidencia sensible a mayúsculas.

El siguiente fragmento:

<PlatformBlock for="WebComponents">
```html
<igc-highlight search-text='lorem' case-sensitive='true'>
    <p>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</p>
</igc-highlight>
```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
<IgrHighlight search-text='lorem' case-sensitive={true}>
    <p>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</p>
</IgrHighlight>
```
</PlatformBlock>

<PlatformBlock for="Blazor">
```razor
<IgbHighlight SearchText="lorem" CaseSensitive="true">
    <p>Lorem ipsum dolor sit, amet consectetur adipisicing elit.</p>
</IgbHighlight>
```
</PlatformBlock>

Devuelve 0 coincidencias porque el texto de búsqueda "lorem" está en minúsculas, mientras que el texto del contenido es **Lorem** con una **L** mayúscula.

### Uso de Highlight con un campo de búsqueda

El caso de uso más habitual es enlazar el componente <ApiLink pkg="core" type="Highlight" /> a un componente de búsqueda <ApiLink pkg="core" type="Input" />, de modo que las coincidencias se resalten en tiempo real a medida que el usuario escribe.

Para enlazar ambos, puede escuchar el evento `igcInput` del componente <ApiLink pkg="core" type="Input" /> y establecer el atributo <ApiLink type="BaseSearchInfo" member="searchText" label="search-text" /> del componente <ApiLink pkg="core" type="Highlight" /> con el valor de la entrada cada vez que se dispare el evento (también puede usar el evento estándar `input`).

<PlatformBlock for="WebComponents">
En primer lugar, necesita acceder al componente <ApiLink type="Highlight" /> para manipular sus propiedades:

```ts
const highlight = document.querySelector('igc-highlight') as IgcHighlightComponent;
```

Después, cree una función que actualice el texto de búsqueda cada vez que se dispare el evento `igcInput`:

```ts
const onInput = ({ detail }: CustomEvent<string>) => {
    highlight.searchText = detail;
};

document.querySelector('igc-input')?.addEventListener('igcInput', onInput);
```

```html
<igc-input label="Search"></igc-input>
<igc-highlight>
    <p>
      Lorem ipsum dolor sit, amet consectetur adipisicing elit. Quae doloribus odit id excepturi ipsum provident eaque dignissimos beatae!
    </p>
</igc-highlight>
```

</PlatformBlock>

<PlatformBlock for="React">
En primer lugar, necesita acceder al componente <ApiLink type="Highlight" /> para manipular sus propiedades. La forma más sencilla de hacerlo es mediante una referencia:

```tsx
import { useRef } from 'react';
```

```tsx
const highlightRef = useRef<IgrHighlight>(null);
```

```tsx
<IgrHighlight ref={highlightRef}>
    ...
</IgrHighlight>
```

Después, cree una función que actualice el texto de búsqueda, a la que se llama cada vez que se dispara el evento `igcInput`:

```tsx
const onInput = ({ detail }: CustomEvent<string>) => {
    highlightRef.current.searchText = detail;
};
```

```tsx
<IgrInput label="Search" onigcInput={onInput}></IgrInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">
En primer lugar, necesita añadir la propiedad searchText:

```razor
private string searchText = "";
```

Después, cree una función que actualice el texto de búsqueda cada vez que se dispare el evento `igcInput`:

```razor
private void OnValueChanging(string newValue)
{
    searchText = newValue;
}
```

```razor
<IgbInput Label="Search" ValueChanging="OnValueChanging"></IgbInput>
<IgbHighlight SearchText="@searchText">
    <p>
        Lorem ipsum dolor sit, amet consectetur adipisicing elit. Quae doloribus
        odit id excepturi ipsum provident eaque dignissimos beatae! Rerum vero
        distinctio libero, quasi magni quod natus nesciunt doloremque temporibus
        voluptate?
    </p>
</IgbHighlight>
```

</PlatformBlock>

### Métodos

El componente también expone dos métodos para navegar por las coincidencias de búsqueda. El método <ApiLink pkg="core" type="Highlight" member="next" label="next()" /> pasa a la coincidencia siguiente, mientras que el método <ApiLink pkg="core" type="Highlight" member="previous" label="previous()" /> pasa a la anterior.

Con ellos podemos hacer la búsqueda más interactiva añadiendo dos botones para navegar entre las coincidencias:

<PlatformBlock for="WebComponents">
```ts
const highlight = document.querySelector('igc-highlight') as IgcHighlightComponent;

const prev = () => {
    highlight.previous();
};

const next = () => {
    highlight.next();
};

document.querySelector('#prev-btn')?.addEventListener('click', prev);
document.querySelector('#next-btn')?.addEventListener('click', next);

```
</PlatformBlock>

<PlatformBlock for="React">
```tsx
const highlightRef = useRef<IgrHighlight>(null);

const prev = () => {
    highlightRef.current?.previous();
};

const next = () => {
    highlightRef.current?.next();
};
```

</PlatformBlock>

<PlatformBlock for="Blazor">

### Funciones adicionales

<PlatformBlock for="WebComponents">
El componente también expone dos propiedades de solo lectura para seguir el estado de las coincidencias: <ApiLink type="Highlight" member="size" label="size" /> devuelve el número total de coincidencias, y <ApiLink type="Highlight" member="current" label="current" /> devuelve el índice de la coincidencia activa.

Son útiles para crear un indicador de estado de la búsqueda que muestre al usuario en qué coincidencia se encuentra y cuántas coincidencias hay en total.

Este es un ejemplo sencillo de cómo usar esas propiedades para crear un estado de búsqueda:

```ts
const highlight = document.querySelector('igc-highlight') as IgcHighlightComponent;
const status = document.querySelector('#helper-text') as HTMLParagraphElement;

const updateStatus = () => {
    status.textContent = highlight.size
      ? `${highlight.current + 1} of ${highlight.size} match${highlight.size === 1 ? '' : 'es'}`
      : '';
}

```

</PlatformBlock>

Son útiles para crear un indicador de estado de la búsqueda que muestre al usuario en qué coincidencia se encuentra y cuántas coincidencias hay en total.

<PlatformBlock for="Blazor">
El componente también expone dos métodos asíncronos para seguir el estado de las coincidencias: GetSizeAsync() devuelve el número total de coincidencias, y GetCurrentAsync() devuelve el índice de la coincidencia activa.

Estos métodos son útiles para crear un indicador de estado de la búsqueda que muestre al usuario en qué coincidencia se encuentra y cuántas coincidencias hay en total.

Este es un ejemplo sencillo de cómo usar estos métodos para crear un estado de búsqueda:

```razor
private async Task UpdateStatus()
{
    var size = (int)await HighlightRef.GetSizeAsync();
    var current = (int)await HighlightRef.GetCurrentAsync();
    helperText = $"{current + 1} of {size} match{(size == 1 ? "" : "es")}";
}
```

</PlatformBlock>

## Estilos

El componente <ApiLink pkg="core" type="Highlight" /> expone cuatro variables CSS que pueden usarse para dar estilo a todo el componente:
- `--foreground` El color del texto de un nodo de texto resaltado.
- `--background` El color de fondo de un nodo de texto resaltado.
- `--foreground-active` El color del texto del nodo de texto resaltado activo.
- `--background-active` El color de fondo del nodo de texto resaltado activo.

```css
igc-highlight {
    --background: var(--ig-gray-700);
    --foreground: var(--ig-gray-700-contrast);
    --background-active: var(--ig-warn-500);
    --foreground-active: var(--ig-warn-500-contrast);
}
```
