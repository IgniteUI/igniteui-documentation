# {Platform} Icon Button - Descripción general

El componente {ProductName} Icon Button permite a los desarrolladores usar iconos registrados como botones en su aplicación. Incluye todas las funciones del componente [icon](../layouts/icon.mdx), pero también añade funciones del componente [button](./button.mdx).

## Uso


<PlatformBlock for="WebComponents">


Primero, debe instalar {ProductName} ejecutando el siguiente comando:

```cmd
npm install {PackageWebComponents}
```

Antes de usar <ApiLink pkg="core" type="IconButton" />, debe registrarlo de la siguiente manera:


Para una introducción completa a {ProductName}, lea el tema [**Primeros pasos**](../general-getting-started.mdx).

<PlatformBlock for="React">

<PlatformBlock for="Blazor">

## Ejemplos

### Variante

Al igual que los componentes de botón normales, el icon button admite varias variantes: `flat` (predeterminada), `contained` y `outlined`; para cambiar el tipo de icon button, establezca el atributo <ApiLink pkg="core" type="IconButton" member="variant" label="variant" /> del icon button.

<Sample src="/inputs/icon-button/variant" height={100} alt="Ejemplo de {Platform} Icon Button" />



<PlatformBlock for="React">

```tsx
<IgrIconButton name="search" variant="contained"></IgrIconButton>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-icon-button name="search" variant="contained"></igc-icon-button>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton IconName="search" Variant="@IconButtonVariant.Contained" Collection="material" />
```

</PlatformBlock>

### Tamaño

El tamaño del botón puede cambiarse usando la variable CSS `--ig-size` con cualquiera de los tres tamaños admitidos: `--ig-size-small`, `--ig-size-medium`, `--ig-size-large` (predeterminado).

<Sample src="/inputs/icon-button/size" height={100} alt="Ejemplo de {Platform} Icon Button" />



<PlatformBlock for="React">

```tsx
<IgrIconButton className="size-medium" name="thumb-up"></IgrIconButton>
```

</PlatformBlock>
<PlatformBlock for="React, Blazor">
```css
.size-medium {
    --ig-size: var(--ig-size-medium);
}
```
</PlatformBlock>

<PlatformBlock for="WebComponents">
```css
igc-icon-button {
    --ig-size: var(--ig-size-medium);
}
```
</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton class="size-medium" IconName="thumb-up" Collection="material" />
```

</PlatformBlock>

### Tipo

El componente icon button cambiará su estructura interna de `<button>` a un elemento de tipo `<a>` cuando se establezca el atributo <ApiLink pkg="core" type="IconButton" member="href" label="href" />. En ese caso, el icon button puede considerarse un enlace normal. Al establecer el atributo <ApiLink pkg="core" type="IconButton" member="href" label="href" /> también podrá establecer los atributos <ApiLink pkg="core" type="IconButton" member="rel" label="rel" />, <ApiLink pkg="core" type="IconButton" member="target" label="target" /> y <ApiLink pkg="core" type="IconButton" member="download" label="download" /> del icon button.

<PlatformBlock for="WebComponents">

```html
<igc-icon-button
  name="thumb-up"
  collection="material"
  href="https://duckduckgo.com"
  target="_blank">
</igc-icon-button>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrIconButton name="thumb-up" collection="material" href="https://duckduckgo.com" target="_blank">
</IgrIconButton>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton IconName="thumb-up" Collection="material" Href="https://duckduckgo.com" Target="_blank" />
```

</PlatformBlock>

### Reflejado

Algunos iconos deben verse un poco diferentes cuando se usan en modo de derecha a izquierda (RTL). Por eso proporcionamos un atributo `mirrored` que, al establecerse, invierte horizontalmente el icon button.

<PlatformBlock for="React">

```tsx
<IgrIconButton name="thumb-up" mirrored={true}></IgrIconButton>
```

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-icon-button name="thumb-up" mirrored></igc-icon-button>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbIconButton IconName="thumb-up" Collection="material" Mirrored="true" />
```

</PlatformBlock>

## Estilos

El componente <ApiLink pkg="core" type="IconButton" /> expone dos partes CSS, `base` y `icon`, que le permiten dar estilo al elemento contenedor (`<button>` o `<a>`) y al elemento `<igc-icon>` envuelto.

```css
igc-icon-button[variant="contained"]:not([disabled])::part(base) {
  padding: 12px;
  background-color: var(--ig-success-500);
}

igc-icon-button::part(icon) {
  --size: 22px;
  color: var(--ig-success-500-contrast);
}
```
