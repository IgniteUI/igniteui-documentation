# Descripción general de Date Time Input de {Platform}

El Date Time Input de {ProductName} permite al usuario establecer y editar la fecha y la hora en un elemento de entrada elegido. El usuario puede editar las partes de fecha y de hora mediante una entrada enmascarada editable. Además, se puede especificar un formato de visualización y de entrada deseado, así como valores mínimo y máximo para usar la validación.

<PlatformBlock for="WebComponents, React">



El <ApiLink pkg="core" type="DateTimeInput" /> también acepta cadenas [ISO 8601](https://tc39.es/ecma262/#sec-date-time-string-format).

La cadena puede ser una cadena `ISO` completa, con el formato `YYYY-MM-DDTHH:mm:ss.sssZ`, o puede separarse en partes de solo fecha y de solo hora.

#### Solo fecha
Si se enlaza una cadena que solo contiene la fecha a la propiedad <ApiLink pkg="core" type="DateTimeInput" member="value" label="Value" /> del componente, debe estar en el formato `YYYY-MM-DD`. El <ApiLink pkg="core" type="DateTimeInput" member="inputFormat" label="InputFormat" /> sigue usándose al escribir valores en la entrada, y no tiene que estar en el mismo formato. Además, al enlazar una cadena que solo contiene la fecha, la directiva evitará desplazamientos horarios forzando la hora a `T00:00:00`.

#### Solo hora
Las cadenas que solo contienen la hora normalmente no se definen en la especificación `ECMA`; sin embargo, para que la directiva pueda integrarse en escenarios que requieren soluciones de solo hora, admite el formato de 24 horas: `HH:mm:ss`. El formato de 12 horas no se admite.

#### Cadena ISO completa
Si se enlaza una cadena `ISO` completa, la directiva solo la analizará si se proporcionan todos los elementos que requiere [Date.parse](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/parse#date_time_string_format).

Todos los valores falsy, incluido `InvalidDate`, se analizarán como `null`. Las cadenas incompletas de solo fecha, de solo hora o `ISO` completas se analizarán como `InvalidDate`.


</PlatformBlock>


### Navegación por teclado

El <ApiLink pkg="core" type="DateTimeInput" /> tiene una navegación intuitiva por teclado que facilita incrementar, decrementar o saltar entre distintas `DateParts`, entre otras acciones, sin tener que tocar el ratón.

|Teclas|Descripción|
|----|-----------|
| <kbd>←</kbd> | Mover un carácter al principio |
| <kbd>→</kbd> | Mover un carácter al final |
| <kbd>HOME</kbd> | Mover al principio |
| <kbd>END</kbd> | Mover al final |
| <kbd>CTRL</kbd> / <kbd>CMD</kbd> + <kbd>←</kbd> | Mover al principio de la sección de fecha/hora: la actual o la de la izquierda |
| <kbd>CTRL</kbd> / <kbd>CMD</kbd> + <kbd>→</kbd> | Mover al final de la sección de fecha/hora: la actual o la de la derecha |
| Enfocar una parte de fecha/hora + <kbd>↓</kbd> | Decrementa una parte de fecha/hora |
| Enfocar una parte de fecha/hora + <kbd>↑</kbd> | Incrementa una parte de fecha/hora |
| <kbd>CTRL</kbd> / <kbd>CMD</kbd> + <kbd>;</kbd> | Establece la fecha/hora actual como valor del editor |

## Establecer formatos

<ApiLink pkg="core" type="DateTimeInput" /> admite distintos formatos de visualización y de entrada.

Usa [Intl.DateTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat), lo que le permite admitir opciones de formato predefinidas, como `long` y `short`, `medium` y `full`. Además, también puede aceptar una cadena personalizada construida con caracteres admitidos, como `dd-MM-yy`. Asimismo, si no se proporciona <ApiLink pkg="core" type="DateTimeInput" member="displayFormat" label="DisplayFormat" />, el componente usará <ApiLink pkg="core" type="DateTimeInput" member="inputFormat" label="InputFormat" /> tal cual.

### Formato de entrada
La tabla siguiente muestra los formatos que admite el <ApiLink pkg="core" type="DateTimeInput" member="inputFormat" label="InputFormat" /> del componente:

|Formato|Descripción|
|-------|----------|
| `d` | Día; se completará con un cero a la izquierda durante la edición. |
| `dd` | Día con un cero a la izquierda establecido explícitamente. |
| `M` | Mes; se completará con un cero a la izquierda durante la edición. |
| `MM` | Mes con un cero a la izquierda establecido explícitamente. |
| `yy` | Formato de año corto. |
| `yyyy` | Formato de año completo. |
| `h` | Horas en formato de 12 horas; se completará con un cero a la izquierda durante la edición. |
| `hh` | Horas en formato de 12 horas con un cero a la izquierda establecido explícitamente. |
| `H` | Horas en formato de 24 horas; se completará con un cero a la izquierda durante la edición. |
| `HH` | Horas en formato de 24 horas, con un cero a la izquierda establecido explícitamente. |
| `m` | Minutos; se completarán con un cero a la izquierda durante la edición. |
| `mm` | Minutos con un cero a la izquierda establecido explícitamente. |
| `tt` | Sección AM/PM para el formato de 12 horas. |

Para establecer un formato de entrada concreto, páselo como cadena a <ApiLink pkg="core" type="DateTimeInput" />. Esto establecerá tanto el formato de entrada que se espera del usuario como el `mask`. Además, el <ApiLink pkg="core" type="DateTimeInput" member="inputFormat" label="InputFormat" /> depende de la configuración regional, así que si no se proporciona ninguno, el editor usará `dd/MM/yyyy` de forma predeterminada.

## Incrementar/decrementar (step up/down)

<ApiLink pkg="core" type="DateTimeInput" /> expone los métodos públicos <ApiLink pkg="core" type="DateTimeInput" member="stepUp" label="StepUp" /> y <ApiLink pkg="core" type="DateTimeInput" member="stepDown" label="StepDown" />. Incrementan o decrementan una <ApiLink pkg="core" type="DatePart" /> concreta de la fecha y la hora establecidas actualmente, y se pueden usar de un par de maneras.

En el primer escenario, si no se pasa al método ninguna DatePart concreta, una DatePart predeterminada se incrementa o decrementa, según el <ApiLink pkg="core" type="DateTimeInput" member="inputFormat" label="InputFormat" /> especificado y la implementación interna del componente. En el segundo escenario, puede especificar explícitamente qué DatePart manipular, ya que puede adaptarse a requisitos distintos. Además, ambos métodos aceptan un parámetro opcional `delta` de tipo número que puede usarse para establecer el paso de stepUp/stepDown.


<PlatformBlock for="WebComponents, Blazor">



Además, <ApiLink pkg="core" type="DateTimeInput" member="spinDelta" label="SpinDelta" /> es una propiedad que puede usarse para aplicar un incremento distinto a cada segmento de fecha y hora. Se aplicará al girar con el teclado, la rueda del ratón o con los métodos <ApiLink pkg="core" type="DateTimeInput" member="stepUp" label="StepUp" /> y <ApiLink pkg="core" type="DateTimeInput" member="stepDown" label="StepDown" />, siempre que no se les pase el parámetro delta, ya que tendrá prioridad sobre <ApiLink pkg="core" type="DateTimeInput" member="spinDelta" label="SpinDelta" />.


</PlatformBlock>


<PlatformBlock for="WebComponents">

```ts
const input = document.getElementById('dateTimeInput') as IgcDateTimeInputComponent;

const spinDelta: DatePartDeltas = {
  date: 2,
  month: 3,
  year: 10,
};

input.spinDelta = spinDelta;
```

</PlatformBlock>
