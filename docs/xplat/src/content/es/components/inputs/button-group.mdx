# Componente Button Group

<PlatformBlock for="Angular">
El componente Button Group de {Platform} se usa para organizar botones con la directiva <ApiLink type="IgxButtonDirective" label="IgxButton" /> en grupos de botones con estilo, con alineación horizontal/vertical, selección simple/múltiple y alternancia.
</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">
El componente Button Group de {Platform} se usa para organizar <ApiLink pkg="core" type="ToggleButton" /> en grupos de botones con estilo, con alineación horizontal/vertical, selección simple/múltiple y alternancia.
</PlatformBlock>

### Selección
Para configurar la selección del Button Group de {ProductName}, use su propiedad de selección específica de la plataforma.

Para {Platform}, use la propiedad <ApiLink pkg="IgniteUI.Blazor" type="IgbButtonGroup" member="selection" label="selection" />. Los modos disponibles son:

- **single**: modo de selección predeterminado del grupo de botones. El usuario puede seleccionar o deseleccionar un único botón.
- **single-required**: imita el comportamiento de un grupo de radio. Solo puede seleccionarse un botón y, una vez hecha la selección inicial, no es posible deseleccionarlo mediante la interacción del usuario.
- **multiple**: se pueden seleccionar y deseleccionar varios botones del grupo.

### Botones de alternancia personalizados

<PlatformBlock for="Angular">

En Angular, use la entrada `values` para proporcionar una matriz de botones personalizados. Cada elemento puede definir propiedades como `label`, `icon`, `selected`, `disabled` y `togglable`.

Defina los valores de los botones en la clase del componente:

```ts
interface IButton {
    label?: string;
    icon?: string;
    disabled?: boolean;
    togglable?: boolean;
    selected?: boolean;
    color?: string;
}

public bordersButtons: IButton[] = [
    { icon: 'border_top', selected: true },
    { icon: 'border_right' },
    { icon: 'border_bottom' },
    { icon: 'border_left' }
];
```

```html
<igx-buttongroup [selectionMode]="'multi'" [values]="bordersButtons"></igx-buttongroup>
```

## Accesibilidad

El Button Group de {Platform} organiza botones de alternancia relacionados y expone el estado seleccionado y deshabilitado de cada botón.

### Interacción por teclado

El Button Group delega la interacción por teclado en los botones de alternancia que contiene. Cada botón de alternancia renderiza un botón nativo, por lo que el comportamiento estándar del teclado para botones activa el elemento enfocado y actualiza su selección según el modo de selección configurado.

| Clave | Acción |
| --- | --- |
| Tab / Shift+Tab | Mueve el foco al botón de alternancia habilitado siguiente o anterior del grupo. |
| Enter / Space | Activa el botón de alternancia enfocado y lo selecciona o deselecciona según el modo de selección configurado. |

Cuando el Button Group está deshabilitado, deshabilita los botones de alternancia que contiene para que no sean interactivos con el teclado.

### Lectores de pantalla / ARIA

El Button Group expone una relación de grupo, y cada botón de alternancia expone su estado mediante la semántica nativa de los botones.

<PlatformBlock for="WebComponents, React, Blazor">

- El contenedor del grupo usa `role="group"` y refleja el estado deshabilitado del grupo mediante `aria-disabled`.
- Cada botón de alternancia renderiza un `button` nativo con `aria-pressed` para el estado de selección y `aria-disabled` para el estado deshabilitado.
- El grupo emite `igcSelect` y `igcDeselect` después de que una interacción del usuario cambie la selección de un botón de alternancia. El detalle del evento es el `value` del botón de alternancia.
- Proporcione texto visible o un `aria-label` para cada botón de alternancia, especialmente para los controles solo con icono.

</PlatformBlock>

<PlatformBlock for="Angular">

- El contenedor del grupo usa `role="group"`.
- Angular actualiza el valor `aria-pressed` de cada botón contenido cuando cambia su selección, y deshabilita los botones hijos cuando el grupo está deshabilitado.
- El grupo emite `selected` y `deselected` cuando un usuario cambia la selección. Cada evento proporciona el botón de alternancia seleccionado y su índice.
- Proporcione texto visible, un `igxLabel` u otro nombre accesible para cada botón solo con icono.

</PlatformBlock>

## Solución de problemas

Use esta sección para revisar los límites y las decisiones habituales antes de tratar el Button Group como un único botón de alternancia, un campo de formulario o un grupo de acciones.

### ¿Por qué selectedItems no selecciona ningún botón?

Asegúrese de que cada botón de alternancia tenga un atributo `value` único. La propiedad `selectedItems` depende de esos valores.

### Limitaciones conocidas

El Button Group de {Platform} coordina los botones de alternancia, pero no sustituye sus etiquetas individuales ni sus nombres accesibles.

- El comportamiento de selección depende del modo `selection` configurado.
- La propiedad `selectedItems` depende de atributos `value` únicos en los botones de alternancia contenidos.
- El Button Group no proporciona etiquetas ni iconos para sus botones; defina el contenido de cada botón de alternancia por separado.

<FaqItem question="¿Cómo establezco los botones seleccionados en un Button Group?">
Asigne a cada elemento de botón un valor único y, después, use la configuración de elementos seleccionados específica de la plataforma para identificar los elementos que deben aparecer seleccionados al inicio. Los valores únicos permiten que el grupo registre la selección de forma coherente en todas las plataformas admitidas.
</FaqItem>

<FaqItem question="¿Puedo usar iconos y etiquetas en un Button Group?">
Sí. Cada elemento de botón puede contener un icono, una etiqueta o ambos. Mantenga el patrón de contenido coherente en todo el grupo y proporcione una etiqueta visible o un nombre accesible cuando el icono por sí solo no explique la opción.
</FaqItem>

<FaqItem question="¿Puedo mostrar un Button Group en vertical?">
Sí. Establezca la propiedad de alineación específica de la plataforma en la opción vertical. Use la alineación horizontal cuando las opciones relacionadas deban presentarse en una sola fila.
</FaqItem>

</Faq>
