# Rating

El {ProductName} Rating es un componente asociado a formularios que permite a los usuarios ver y seleccionar una puntuación en una escala de estrellas o de símbolos personalizados.

<PlatformBlock for="Angular">

En Angular, el Rating es el web component `igc-rating` de `igniteui-webcomponents`. Enlácelo a los formularios de Angular con `IgcFormControlDirective`.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

El Rating admite medias estrellas y otros valores fraccionarios, una vista previa al pasar el cursor, la selección única de símbolos diferenciados y la entrada completa por teclado.

</PlatformBlock>

## Anatomía

El Rating se compone de Label y Value, donde el Value es el número de la escala de valoración. La etiqueta se muestra cuando establece `label`. Establezca `max` para cambiar el número de símbolos (5 por defecto).

El elemento `igc-rating` renderiza la etiqueta y un control deslizante que contiene los símbolos. Sin símbolos proyectados, renderiza una estrella por cada punto de `max`:

```text
igc-rating
└─ #shadow-root
   ├─ label[part="label"]                    // hidden when label isn't set
   └─ div[part="base"][role="slider"]
      ├─ div[part="symbols"]                 // aria-hidden="true"
      │  └─ slot[name="symbol"]              // projected igc-rating-symbol elements
      │     └─ igc-rating-symbol × max       // default stars when nothing is projected
      │        └─ #shadow-root
      │           ├─ div[part="symbol full"]   // star_filled icon, clipped to the value
      │           └─ div[part="symbol empty"]  // star_outlined icon, clipped to the rest
      └─ label[part="value-label"]
         └─ slot[name="value-label"]         // hidden when the slot is empty
```

Cada `igc-rating-symbol` renderiza su slot predeterminado en la parte `full` y su slot `empty` en la parte `empty`.

## Uso

Use el Rating de {Platform} para recoger una puntuación de un producto, de un servicio o de una experiencia, o para mostrar una puntuación media que los usuarios no puedan cambiar.

### Vista previa al pasar el cursor

Establezca `hoverPreview` para rellenar los símbolos hasta el valor situado bajo el puntero antes de que el usuario haga clic. Cuando el puntero sale de los símbolos, el Rating {Platform} vuelve a mostrar su valor. Un Rating de solo lectura o deshabilitado no muestra vista previa.

<PlatformBlock for="WebComponents">

Mientras la vista previa está activa, el Rating emite `igcHover` con el valor situado bajo el puntero:

```html
<igc-rating hover-preview label="Rate this article"></igc-rating>
<span id="hint"></span>
```

```ts
const rating = document.querySelector('igc-rating')!;
const hint = document.getElementById('hint')!;

rating.addEventListener('igcHover', (event) => {
  hint.textContent = `${event.detail} stars`;
});
```

</PlatformBlock>

<PlatformBlock for="React">

Mientras la vista previa está activa, el Rating llama a `onHover` con el valor situado bajo el puntero:

```tsx
<IgrRating
  hoverPreview={true}
  label="Rate this article"
  onHover={(e: CustomEvent<number>) => setHint(`${e.detail} stars`)}
/>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

Mientras la vista previa está activa, el Rating lanza `Hover` con el valor situado bajo el puntero:

```razor
<IgbRating HoverPreview="true" Label="Rate this article" Hover="OnHover" />

@code {
    private string Hint { get; set; }

    private void OnHover(IgbNumberEventArgs e)
    {
        Hint = $"{e.Detail} stars";
    }
}
```

</PlatformBlock>

<PlatformBlock for="Angular">

Mientras la vista previa está activa, el Rating emite `igcHover` con el valor situado bajo el puntero:

```html
<igc-rating hover-preview label="Rate this article" (igcHover)="onHover($event)"></igc-rating>
```

```ts
public hint = '';

public onHover(event: Event) {
    this.hint = `${(event as CustomEvent<number>).detail} stars`;
}
```

</PlatformBlock>

### Disposición

La propiedad `label` muestra una etiqueta visible encima de los símbolos y da nombre al Rating {Platform} para la tecnología de asistencia. Para mostrar contenido personalizado junto a los símbolos, como la puntuación actual, colóquelo en el slot `value-label`:

<PlatformBlock for="WebComponents">

```html

  <span slot="value-label">4 of 5</span>
</igc-rating>
```

Actualice el contenido del slot en el controlador `igcChange` para mantenerlo sincronizado con el valor.

</PlatformBlock>

### Estado vacío/lleno

El `value` del Rating {Platform} establece lo llenos que están sus símbolos. Un valor de 0, el predeterminado, muestra todos los símbolos vacíos, y un valor igual a `max` muestra todos los símbolos llenos.

<PlatformBlock for="WebComponents">

Establezca el valor y el máximo como atributos, y escuche `igcChange` para obtener el valor que selecciona el usuario:

```html
<igc-rating value="3" max="10" label="Rate this movie"></igc-rating>
```

```ts
const rating = document.querySelector('igc-rating')!;

rating.addEventListener('igcChange', (event) => {
  console.log(`New rating: ${event.detail}`);
});
```

</PlatformBlock>

<PlatformBlock for="React">

Mantenga el valor en el estado y actualícelo en el controlador `onChange`:

```tsx
import { useState } from 'react';
import { IgrRating } from 'igniteui-react';

export default function MovieRating() {
  const [score, setScore] = useState(3);

  return (
    <IgrRating
      value={score}
      max={10}
      label="Rate this movie"
      onChange={(e: CustomEvent<number>) => setScore(e.detail)}
    />
  );
}
```

</PlatformBlock>

### Tamaño

El Rating está disponible en tres tamaños: Small, Medium y Large. Los tamaños small, medium y large renderizan símbolos de 18px, 24px y 36px, y el Rating de {Platform} usa el tamaño medium de forma predeterminada. Establezca la variable CSS `--ig-size` en `--ig-size-small`, `--ig-size-medium` o `--ig-size-large` para elegir un tamaño. Para un tamaño fuera de estos preajustes, establezca `--ig-rating-symbol-size`:

```css
.rating-small {
  --ig-size: var(--ig-size-small);
}

.rating-large {
  --ig-size: var(--ig-size-large);
}

.rating-custom {
  --ig-rating-symbol-size: 3rem;
}
```

De forma predeterminada, el Rating de {Platform} renderiza iconos de estrella. Para usar otros símbolos, coloque un <PlatformBlock for="Angular">elemento `igc-rating-symbol`</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor"><ApiLink pkg="core" type="RatingSymbol" /></PlatformBlock> por cada punto de la escala dentro del Rating. El número de símbolos de valoración establece `max`, y el Rating ignora el `max` que haya establecido.

### Qué hacer y qué no

La estrella es un símbolo de clasificación muy reconocible, y es posible que las personas no asocien otros símbolos con una escala de valoración. Si sustituye la estrella por un símbolo personalizado, asegúrese de que su finalidad sea clara. Evite colores con poco contraste, como tonos muy parecidos del mismo color o combinaciones que generen aberraciones cromáticas. Las selecciones de iconos deben destacar y tener un aspecto visual claramente distinto.

## Estilos

El {Platform} Rating toma sus colores y el tamaño de sus símbolos del tema. Cámbielos con las siguientes variables CSS:

| Variable | Qué cambia |
| --- | --- |
| `--ig-rating-symbol-full-color` | El color de los símbolos completos: las estrellas, los iconos y el texto predeterminados. |
| `--ig-rating-symbol-empty-color` | El color de los símbolos vacíos. |
| `--ig-rating-label-color` | El color de la etiqueta. |
| `--ig-rating-value-label` | El color de la etiqueta del valor. |
| `--ig-rating-symbol-size` | El tamaño de los símbolos. |
| `--ig-size` | El preajuste de tamaño: `--ig-size-small`, `--ig-size-medium` o `--ig-size-large`. |
| `--ig-rating-disabled-full-symbol-color` | El color de los símbolos completos cuando la valoración está deshabilitada. |
| `--ig-rating-disabled-empty-symbol-color` | El color de los símbolos vacíos cuando la valoración está deshabilitada. |
| `--ig-rating-disabled-label-color` | El color de la etiqueta y de la etiqueta del valor cuando la valoración está deshabilitada. |
| `--ig-rating-symbol-full-filter` | El filtro CSS de los símbolos completos distintos de los iconos, como los emoji, cuando la valoración está deshabilitada. |
| `--ig-rating-symbol-empty-filter` | El filtro CSS de los símbolos vacíos distintos de los iconos, como los emoji, cuando la valoración está deshabilitada. |

El elemento `igc-rating` expone las siguientes partes CSS:

| Parte | Qué estiliza |
| --- | --- |
| `base` | El control deslizante que contiene los símbolos y la etiqueta del valor. |
| `label` | La etiqueta. |
| `value-label` | El contenedor del slot `value-label`. |
| `symbols` | El contenedor de todos los símbolos. |
| `symbol` | Cada símbolo predeterminado. |
| `full` | La capa completa de cada símbolo predeterminado. |
| `empty` | La capa vacía de cada símbolo predeterminado. |

El elemento `igc-rating` exporta las partes `symbol`, `full` y `empty` solo de sus estrellas predeterminadas. Para dar estilo a los símbolos de valoración proyectados, use las partes `symbol`, `full` y `empty` del elemento `igc-rating-symbol`.

## Accesibilidad

El Rating de {Platform} es un control deslizante: los usuarios llegan a él con la tecla Tab, cambian su valor con las teclas de flecha y oyen el valor a través de sus atributos ARIA.

### Interacción por teclado

El Rating de {Platform} es una única parada de tabulación, porque solo recibe el foco el elemento control deslizante que contiene, la parte `base`. Un Rating deshabilitado sale del orden de tabulación. Un Rating de solo lectura permanece en el orden de tabulación, pero ignora las teclas siguientes, de modo que conservan su acción predeterminada del navegador, como el desplazamiento de página.

| Clave | Acción |
| --- | --- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Mueve el foco al elemento enfocable siguiente o anterior. El Rating no gestiona estas teclas, así que nunca atrapa el foco. |
| <kbd>Arrow Right</kbd> | Aumenta el valor un paso. En una disposición de derecha a izquierda, lo disminuye. |
| <kbd>Arrow Left</kbd> | Disminuye el valor un paso. En una disposición de derecha a izquierda, lo aumenta. |
| <kbd>Arrow Up</kbd> | Aumenta el valor un paso. |
| <kbd>Arrow Down</kbd> | Disminuye el valor un paso. |
| <kbd>Home</kbd> | Establece el valor en un paso, el valor más bajo que puede seleccionar un clic. |
| <kbd>End</kbd> | Establece el valor en el valor máximo. |

El {Platform} Rating gestiona estas teclas sobre `keydown`:

- Impide su acción predeterminada, de modo que las teclas de flecha, Home y End no desplazan la página mientras el Rating tiene el foco.
- Una tecla que se mantiene pulsada repite su acción.
- Una tecla que se pulsa junto con Shift, Ctrl, Alt o Meta no hace nada.
- El valor se mantiene entre 0 y el valor máximo. Una tecla que llevaría el valor más allá de un límite mantiene el valor y no emite ningún evento.
- Cada tecla que cambia el valor emite el evento change.

Con un puntero, un clic selecciona el valor situado bajo el puntero, redondeado hacia arriba al siguiente paso. Un Rating de solo lectura o deshabilitado ignora los clics.

### Lectores de pantalla / ARIA

El {Platform} Rating renderiza un único elemento enfocable, la parte `base`, con el rol `slider`. Su `tabindex` es `0`, o `-1` cuando el Rating está deshabilitado, y lleva los siguientes atributos de valor:

| Atributo | Valor |
| --- | --- |
| `aria-valuemin` | `0` |
| `aria-valuemax` | El valor máximo |
| `aria-valuenow` | El valor, incluidas las fracciones como `4.3` |
| `aria-valuetext` | "3 of 5" de forma predeterminada, o el texto `valueFormat` |

<PlatformBlock for="React,WebComponents,Angular">

Con `igniteui-webcomponents` 7.3.0 y versiones posteriores, el control deslizante también establece `aria-disabled` y `aria-readonly` para exponer los estados deshabilitado y de solo lectura. Con la 7.4.1 y versiones posteriores, el control deslizante toma su nombre accesible del primero de los siguientes:

1. El atributo `aria-labelledby` del host.
2. Un elemento `<label>` enlazado mediante `for`, o que envuelve el Rating. Un clic en la etiqueta enfoca el control deslizante.
3. La propiedad `label`, que renderiza una etiqueta visible a la que el control deslizante hace referencia mediante `aria-labelledby`.
4. El atributo `aria-label` del host. El control deslizante lo ignora cuando se establece la propiedad `label`.

</PlatformBlock>

<PlatformBlock for="Blazor">

La propiedad `Label` renderiza una etiqueta visible a la que el control deslizante hace referencia mediante `aria-labelledby`, lo que da al control deslizante su nombre accesible.

</PlatformBlock>

El {Platform} Rating también se comporta de la siguiente manera para la tecnología de asistencia:

- La parte `symbols` establece `aria-hidden="true"`, de modo que los símbolos, incluidos los iconos proyectados y los emoji, quedan ocultos y no necesitan alternativas textuales. El valor llega a la tecnología de asistencia solo a través de `aria-valuenow` y `aria-valuetext`.
- El slot `value-label` se renderiza dentro del control deslizante. Los lectores de pantalla leen el valor de `aria-valuetext`, así que describa el valor con `valueFormat` en lugar de con el contenido del slot.
- El Rating no usa una región live. Un valor modificado llega a la tecnología de asistencia solo a través de los atributos del control deslizante.
- El Rating no establece `aria-invalid`, así que un mensaje de validación personalizado no se expone como estado no válido.

Sus responsabilidades:

- Dé nombre a cada Rating con la propiedad `label`<PlatformBlock for="React,WebComponents,Angular">, un elemento `<label>` asociado, o `aria-label`</PlatformBlock>. Consulte [Disposición](#disposición).
- Establezca `valueFormat` cuando "3 of 5" no describa la escala, o cuando la página use otro idioma.
- Con símbolos personalizados, haga que los símbolos completos y vacíos se diferencien por la forma o el relleno, y no solo por el color, y mantenga una relación de contraste de al menos 3:1 frente al fondo, como exige [1.4.11 Contraste de elementos no textuales](https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast).
- Al cambiar el estilo de la parte `base`, mantenga un indicador de foco visible.
- Mantenga los objetivos del puntero lo bastante grandes. Cada valor es un objetivo tan ancho como un símbolo, o medio símbolo con un paso de 0,5. - No ponga información solo en la vista previa al pasar el cursor, porque los usuarios de teclado no la ven.
- Cuando valide la valoración con un mensaje de validación personalizado, muestre también el mensaje como texto junto al Rating, como exige [3.3.1 Identificación de errores](https://www.w3.org/WAI/WCAG21/Understanding/error-identification), porque el Rating no establece `aria-invalid`.

Diferencias con el [patrón de control deslizante WAI-ARIA](https://www.w3.org/WAI/ARIA/apg/patterns/slider/):

- <kbd>Home</kbd> establece el valor en un paso en lugar de en `aria-valuemin`, que es 0. Use <kbd>Arrow Down</kbd> para llegar a 0.
- El Rating no admite <kbd>Page Up</kbd> ni <kbd>Page Down</kbd>, que el patrón enumera como teclas opcionales.

## Solución de problemas

Use estas respuestas cuando un Rating de {Platform} no se comporte como se espera.

### ¿Por qué no se dispara el evento change cuando establezco el valor?

El Rating de {Platform} emite el evento change solo por la entrada del usuario: un clic o una tecla. Establecer el valor en el código, o llamar a los métodos de paso, cambia el valor sin el evento, así que actualice su propio estado en el lugar donde establece el valor.

### ¿Por qué un clic sobre el valor actual no restablece la valoración?

El Rating de {Platform} conserva el valor con un clic sobre el valor actual, a menos que establezca `allowReset`. Antes de `igniteui-webcomponents` 4.7.0, un clic sobre el valor actual siempre restablecía la valoración; establezca `allowReset` para mantener ese comportamiento tras una actualización.

### ¿Por qué no se dispara el evento de hover?

El Rating de {Platform} emite el evento de hover solo mientras `hoverPreview` está activado, y no cuando el Rating es de solo lectura o está deshabilitado. Establezca `hoverPreview` para recibir el evento.
