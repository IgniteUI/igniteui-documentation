# Tooltip de {Platform}

El componente {ProductName} Tooltip permite mostrar un tooltip para un elemento concreto. Un tooltip es una ventana emergente que muestra información relacionada con un elemento, normalmente cuando el elemento recibe el foco del teclado o cuando el ratón pasa sobre él.

### Posicionamiento

El <ApiLink pkg="core" type="Tooltip" /> también puede posicionarse con facilidad respecto a su elemento de destino. Solo tiene que usar la propiedad <ApiLink pkg="core" type="Tooltip" member="placement" label="Placement" /> junto con una de las <PlatformBlock for="Angular,React,WebComponents"><ApiLink pkg="core" type="PopoverPlacement" /></PlatformBlock><PlatformBlock for="Blazor"><a href="https://staging.infragistics.com/api/blazor/IgniteUI.Blazor.Lite/0.0.1/enums/PopoverPlacement"><code>PopoverPlacement</code></a></PlatformBlock> opciones.

Si no se establece la propiedad <ApiLink pkg="core" type="Tooltip" member="placement" label="Placement" />, el valor predeterminado es `Bottom`, que coloca el <ApiLink pkg="core" type="Tooltip" /> debajo del elemento de destino.

Además, puede hacer que el <ApiLink pkg="core" type="Tooltip" /> sea «fijo» con la propiedad <ApiLink pkg="core" type="Tooltip" member="sticky" label="Sticky" />, que añade un botón de cierre y mantiene el <ApiLink pkg="core" type="Tooltip" /> visible hasta que el usuario lo cierra manualmente, ya sea haciendo clic en el botón de cierre o pulsando la tecla `Esc`. Este comportamiento sustituye al comportamiento predeterminado al pasar el ratón, de modo que el <ApiLink pkg="core" type="Tooltip" /> no desaparece cuando el usuario deja de pasar el ratón por el elemento de destino.

El <ApiLink pkg="core" type="Tooltip" /> también incluye un indicador de flecha opcional que puede configurarse mediante la propiedad <ApiLink pkg="core" type="Tooltip" member="withArrow" label="WithArrow" />. La flecha conecta visualmente el tooltip con su elemento de anclaje, y su posición se ajusta automáticamente según la <ApiLink pkg="core" type="Tooltip" member="placement" label="Placement" /> del tooltip.

<PlatformBlock for="WebComponents">

```html
<igc-button id="target-button">Hover me</igc-button>
<igc-tooltip anchor="target-button" placement="top-start" sticky with-arrow>
  Congrats you've hovered the button!
</igc-tooltip>
```

</PlatformBlock>

```tsx

</IgrTooltip>
```

</PlatformBlock>

<PlatformBlock for="Blazor">


### Disparadores

De forma predeterminada, el <ApiLink pkg="core" type="Tooltip" /> solo se activa al pasar el ratón sobre el elemento de destino. Sin embargo, puede cambiar este comportamiento con las propiedades <ApiLink pkg="core" type="Tooltip" member="showTriggers" label="ShowTriggers" /> y <ApiLink pkg="core" type="Tooltip" member="hideTriggers" label="HideTriggers" />, que le permiten controlar cuándo aparece y desaparece el <ApiLink pkg="core" type="Tooltip" />. Estas propiedades aceptan nombres de eventos como valores, como `click`, `focus` o `keypress`, lo que le permite activar el <ApiLink pkg="core" type="Tooltip" /> en distintos escenarios.

### Propiedades adicionales

Además de las propiedades que ya hemos visto, el componente <ApiLink pkg="core" type="Tooltip" /> ofrece otras propiedades que le permiten configurar con más detalle su comportamiento, su posición y su apariencia.

|Nombre|Tipo|Descripción|
|--|--|--|
| <ApiLink pkg="core" type="Tooltip" member="open" label="Open" /> | boolean | Determina si el tooltip es visible. |
| <ApiLink pkg="core" type="Tooltip" member="withArrow" label="WithArrow" /> | boolean | Determina si se muestra un indicador de flecha para el tooltip. |
| <ApiLink pkg="core" type="Tooltip" member="offset" label="Offset" /> | número | Establece la distancia en píxeles entre el tooltip y su <ApiLink pkg="core" type="Tooltip" member="anchor" label="Anchor" />. |

### Métodos

Además de sus propiedades configurables, el <ApiLink pkg="core" type="Tooltip" /> expone tres métodos que puede usar:

|Nombre|Descripción|
|--|--|
| <ApiLink pkg="core" type="Tooltip" member="show" label="Show" /> | Muestra el tooltip si aún no está visible. Si se proporciona un destino, lo establece como <ApiLink pkg="core" type="Tooltip" member="anchor" label="Anchor" /> transitorio. |
| <ApiLink pkg="core" type="Tooltip" member="hide" label="Hide" /> | Oculta el tooltip si aún no está oculto. |
| <ApiLink pkg="core" type="Tooltip" member="toggle" label="Toggle" /> |  Alterna el tooltip entre los estados mostrado y oculto. |

## Compatibilidad con accesibilidad y ARIA

El <ApiLink pkg="core" type="Tooltip" /> se ha diseñado teniendo en cuenta la accesibilidad e incluye los siguientes atributos ARIA:

- `role`: cuando la información emergente tiene su comportamiento predeterminado, se aplica `role="tooltip"`. Si la propiedad <ApiLink pkg="core" type="Tooltip" member="sticky" label="Sticky" /> está habilitada, el rol cambia a `status`.
- `inert` - Se alterna dinámicamente según la visibilidad. Cuando el tooltip está oculto, pasa a estar inerte.
- `aria-atomic` - Se establece en true, para garantizar que se anuncie todo el contenido del tooltip cuando cambie.
- `aria-live` - Se establece en polite, para indicar a los lectores de pantalla que las actualizaciones deben anunciarse solo cuando el usuario esté inactivo.

## Estilos

El componente <ApiLink pkg="core" type="Tooltip" /> expone dos partes CSS que puede usar para dar estilo:

|Nombre|Descripción|
|--|--|
| `base` | El wrapper base del componente tooltip. |
| `top, right, bottom, left ...` | El área que contiene la flecha del tooltip. El nombre de la parte coincide con el valor de la propiedad de posicionamiento del tooltip. |

```css
igc-tooltip::part(base) {
  background-color: var(--ig-primary-500);
  color: var(--ig-primary-500-contrast);
}

igc-tooltip::part(bottom) {
  border-bottom-color: var(--ig-primary-500);
}
```
