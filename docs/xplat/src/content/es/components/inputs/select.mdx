# {Platform} Select

El componente {ProductName} Select permite una única selección de una lista de elementos, colocada en un desplegable. Este control de formulario ofrece una navegación rápida por la lista de elementos, incluida la selección, basada en la coincidencia de uno o varios caracteres.

### Select

El componente <ApiLink pkg="core" type="Select" /> puede usarse dentro de un componente `Form`, así que expone una propiedad <ApiLink pkg="core" type="Select" member="name" label="Name" /> con la que registrarse.

También tiene las propiedades <ApiLink pkg="core" type="Select" member="label" label="Label" /> y <ApiLink pkg="core" type="Select" member="placeholder" label="Placeholder" />. La propiedad <ApiLink pkg="core" type="Select" member="outlined" label="Outlined" /> solo se usa con fines de estilo en el tema Material.

Salvo el slot predeterminado, el componente proporciona otros slots, como `header`, `footer`, `helper-text`, `prefix`, `suffix` y `toggle-icon`. Al colocar contenido en los slots, recomendamos usar un elemento `<span>` para texto simple, símbolos o emojis, y un componente [`<igc-icon>`](../layouts/icon.mdx) para iconos.

El tamaño del componente puede cambiarse con la variable CSS `--ig-size`.

### Elemento

El componente <ApiLink pkg="core" type="SelectItem" /> permite a los usuarios especificar de forma declarativa una lista de opciones que usa el control <ApiLink pkg="core" type="Select" />. Cada elemento proporciona una propiedad <ApiLink pkg="core" type="SelectItem" member="value" label="Value" /> que representa los datos que transporta al seleccionarse. El <ApiLink pkg="core" type="SelectItem" /> tiene un slot predeterminado que permite especificar el contenido de texto del elemento. Este contenido de texto se usará como valor cuando la propiedad <ApiLink pkg="core" type="SelectItem" member="value" label="Value" /> no esté presente en el <ApiLink pkg="core" type="SelectItem" />.

También puede proporcionar contenido personalizado que se renderice antes o después del contenido de <ApiLink pkg="core" type="SelectItem" /> mediante los slots `prefix` y `suffix`. Igual que con el componente <ApiLink pkg="core" type="Select" />, recomendamos usar un elemento `<span>` cuando se añada texto simple, símbolos o emojis, y un componente [`<igc-icon>`](../layouts/icon.mdx) cuando se añadan iconos a los slots `prefix` y `suffix`.

Puede predefinir un elemento seleccionado estableciendo la propiedad <ApiLink pkg="core" type="SelectItem" member="selected" label="Selected" />. También puede deshabilitar algunos o todos los elementos mediante la propiedad <ApiLink pkg="core" type="SelectItem" member="disabled" label="Disabled" />.

### Grupo

Se pueden colocar varios <ApiLink pkg="core" type="SelectItem" /> entre las etiquetas de apertura y de cierre de un componente <ApiLink pkg="core" type="SelectGroup" />, para que los usuarios los agrupen visualmente. El <ApiLink pkg="core" type="SelectGroup" /> puede etiquetarse mediante su slot `label` y deshabilitarse mediante su propiedad <ApiLink pkg="core" type="SelectGroup" member="disabled" label="Disabled" />. Recomendamos usar un elemento `<span>` para el slot `label`.

<DocsAside type="info">
Tenga en cuenta que, si un grupo del select está deshabilitado, no puede habilitar por separado sus elementos.
</DocsAside>

## Validación

Además, el <ApiLink pkg="core" type="Select" /> admite la mayoría de las propiedades de <ApiLink pkg="core" type="Input" />, como <ApiLink pkg="core" type="Select" member="required" label="Required" />, <ApiLink pkg="core" type="Select" member="disabled" label="Disabled" />, <ApiLink pkg="core" type="Select" member="autofocus" label="Autofocus" />, etc. El componente también expone un método vinculado a su validación:

- `reportValidity` - comprueba la validez y enfoca el componente si no es válido.

## Navegación por teclado

Cuando el select tiene el foco y la lista de opciones **no está visible**:

- Abra el <ApiLink pkg="core" type="Input" member="select" label="Select" /> con la combinación <kbd>ALT</kbd> + <kbd>↑</kbd> <kbd>↓</kbd> o pulsando la tecla <kbd>SPACE</kbd> o <kbd>ENTER</kbd>.
- Cierre el <ApiLink pkg="core" type="Input" member="select" label="Select" /> con la combinación <kbd>ALT</kbd> + <kbd>↑</kbd> o <kbd>↓</kbd>, o con cualquiera de las teclas <kbd>ENTER</kbd>, <kbd>SPACE</kbd>, <kbd>ESC</kbd> o <ApiLink pkg="core" type="Tab" />.
- Usar las teclas <kbd>←</kbd> <kbd>→</kbd> selecciona el elemento anterior de la lista.
- Usar las teclas <kbd>↑</kbd> <kbd>↓</kbd> selecciona el elemento siguiente de la lista.
- Usar las teclas <kbd>HOME</kbd> o <kbd>END</kbd> selecciona el primer o el último elemento de la lista.
- Escribir caracteres busca en la lista de elementos y selecciona el que más se parece a la entrada actual del usuario.

Cuando el select tiene el foco y la lista de opciones **está visible**:

- Usar las teclas <kbd>ENTER</kbd> o <kbd>SPACE</kbd> selecciona un elemento y cierra la lista.
- Usar las teclas <kbd>←</kbd> <kbd>→</kbd> activa el elemento anterior de la lista.
- Usar las teclas <kbd>↑</kbd> <kbd>↓</kbd> activa el elemento siguiente de la lista.
- Usar las teclas <kbd>HOME</kbd> o <kbd>END</kbd> activa el primer o el último elemento de la lista.

<DocsAside type="info">
El componente <ApiLink pkg="core" type="Input" member="select" label="Select" /> solo admite la selección **única** de elementos.
</DocsAside>

## Estilos

Puede cambiar el aspecto del componente {ProductName} <ApiLink pkg="core" type="Select" /> y de sus elementos mediante las partes CSS expuestas que se indican a continuación:

**Componente Select**

| Nombre de la parte | Descripción |
| ---------|------------ |
| `input` | El igc-input encapsulado. |
| `label` | La etiqueta de texto encapsulada. |
| `list` | Un wrapper que contiene la lista de opciones. |
| `prefix`  | Un wrapper de prefijo que renderiza contenido antes de la entrada. |
| `suffix` | Un wrapper de sufijo que renderiza contenido después de la entrada. |
| `toggle-icon` | Un wrapper del icono de alternancia que renderiza contenido dentro del wrapper de sufijo. |
| `helper-text` | Un wrapper del texto de ayuda que renderiza contenido debajo de la entrada. |

**Componente Select Item**

| Nombre de la parte | Descripción |
| ---------|------------ |
| `content` | El wrapper principal que contiene el contenido de texto de un elemento. |
| `prefix`  | Un wrapper de prefijo que renderiza contenido antes del wrapper principal. |
| `suffix` | Un wrapper de sufijo que renderiza contenido después del wrapper principal. |

**Componente Select Group**

| Nombre de la parte | Descripción |
| ---------|------------ |
| `label` | Un wrapper de etiqueta que renderiza contenido encima de los elementos del grupo del select. |

```css
igc-select::part(base) {
  background: var(--ig-primary-50);
}

igc-select-item[active] {
  background: var(--ig-secondary-300);
}

igc-select::part(input) {
  background-color: var(--ig-primary-50);
}

igc-select::part(prefix),
igc-select::part(suffix) {
  color: var(--ig-secondary-500-contrast);
  background: var(--ig-secondary-500);
}
```
