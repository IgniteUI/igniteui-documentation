# {Platform} Text Area - Descripción general

El {ProductName} Text Area representa un control de edición de texto plano de varias líneas, útil cuando quiere permitir que los usuarios introduzcan una cantidad considerable de texto libre, por ejemplo, un comentario en una reseña o en un formulario de opiniones.

## Prefijo, sufijo y texto de ayuda

Con los slots `prefix` y `suffix` podemos añadir contenido distinto antes y después del contenido principal del Text Area. El slot `helper-text` proporciona una sugerencia situada debajo del Text Area. Al colocar contenido en los slots, recomendamos usar un elemento `<span>` para texto simple, símbolos o emojis, y un componente [`<igc-icon>`](../layouts/icon.mdx) para iconos. En el siguiente ejemplo crearemos un nuevo campo Text Area con un prefijo de icono y un texto de ayuda como sugerencia:

<PlatformBlock for="WebComponents">

```html
<igc-textarea label="Your feedback">
    <igc-icon name="feedback" slot="prefix"></igc-icon>
    <span slot="helper-text">Give us a short description of what you liked/disliked</span>
</igc-textarea>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrTextarea label="Your feedback">
    <IgrIcon name="feedback" slot="prefix"></IgrIcon>
    <span slot="helper-text">Give us a short description of what you liked/disliked</span>
</IgrTextarea>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbTextarea Label="Your feedback">
    <IgbIcon IconName="feedback" Collection="material" slot="prefix"></IgbIcon>

</IgbTextarea>
```

## Cambio de tamaño del Text Area

Hay tres opciones de cambio de tamaño del <ApiLink pkg="core" type="Textarea" />. Cuando se establece en `none`, el text area no cambia de tamaño y usa una barra de desplazamiento para mostrar el texto que se desborda. Cuando se establece en `vertical` (la opción predeterminada), el text area permite al usuario cambiar su tamaño verticalmente. Cuando se establece en `auto`, el text area muestra de una vez todo lo que introduce el usuario. El texto desbordado se ajusta en una nueva línea y amplía el text area automáticamente.

## Estilos

El componente <ApiLink pkg="core" type="Textarea" /> expone partes CSS para casi todos sus elementos internos. La tabla siguiente enumera todas las partes CSS expuestas:

|Nombre|Descripción|
|--|--|
| `container` | El wrapper principal que contiene todos los elementos de entrada principales. |
| `input` | El elemento input nativo. |
| `label` | El elemento label nativo. |
| `prefix` | El wrapper del prefijo. |
| `suffix` | El wrapper del sufijo. |
| `helper-text` | El wrapper del texto de ayuda. |

```css
igc-textarea::part(input) {
  background-color: var(--ig-info-100);
  border-color: var(--ig-primary-400);
}

igc-textarea::part(label) {
  color: var(--ig-gray-800);
}

igc-textarea::part(prefix),
igc-textarea::part(suffix) {
  color: var(--ig-primary-500-contrast);
  border-color: var(--ig-primary-500);
  background-color: var(--ig-primary-500);
}
```
