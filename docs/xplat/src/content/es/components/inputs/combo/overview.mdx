# Combo

El Combo de {ProductName} es un componente que combina un campo de entrada con una lista desplegable con búsqueda, lo que permite a los usuarios filtrar las opciones escribiendo y seleccionar uno o varios elementos.

<PlatformBlock for="Angular">

El Combo de Angular es el componente `igx-combo`. Muestra sus opciones en una lista desplegable virtualizada y admite filtrado, agrupación, valores personalizados y enlace bidireccional con formularios de Angular.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

El Combo muestra sus opciones en una lista virtualizada, de modo que la lista puede contener miles de opciones. El Combo admite filtrado con distinción de mayúsculas, agrupación y enlace a datos complejos.

</PlatformBlock>

## Uso

Use el Combo de {Platform} cuando los usuarios elijan una o varias opciones de una lista larga y necesiten buscar en ella, como una lista de ciudades o de países.

### Tipo (tema Material)

En el tema Material, la entrada del Combo ofrece un tipo con borde, para una percepción más estructurada sobre fondos de color sólido, y un tipo con caja, más adecuado cuando se coloca sobre una imagen vivaz para mejorar la legibilidad. Los temas Bootstrap, Fluent e Indigo dibujan ambos tipos de la misma manera, por lo que los demás ejemplos de este tema muestran el tipo con caja solo en el tema Material.

### Tamaño

El Combo está disponible en tres tamaños: Large, Medium y Small. El desplegable ajusta automáticamente sus dimensiones para que coincidan con la variante de tamaño seleccionada. Establezca el tamaño con la variable CSS `--ig-size`:

```css
.small {
  --ig-size: var(--ig-size-small);
}

.large {
  --ig-size: var(--ig-size-large);
}
```

### Estados de interacción

El componente Combo admite cinco estados para las variantes habilitadas: Idle, Idle y Hover, Filled, Filled y Hover, y Focused, así como tres estados de validación: Success, Warn y Error.

Al hacer clic en el campo de entrada o en la alternancia se abre el desplegable. Para abrir y cerrar el desplegable en el código, use la <PlatformBlock for="React,WebComponents">propiedad `open` o los métodos `show`, `hide` y `toggle`</PlatformBlock><PlatformBlock for="Blazor">parámetro `Open` o los métodos `ShowAsync`, `HideAsync` y `ToggleAsync`</PlatformBlock><PlatformBlock for="Angular">métodos `open`, `close` y `toggle`</PlatformBlock>:

<PlatformBlock for="WebComponents">

```ts
const combo = document.querySelector('igc-combo');

await combo.show();
await combo.hide();
await combo.toggle();
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const comboRef = useRef<IgrCombo>(null);

const open = () => comboRef.current?.show();

const toggle = () => comboRef.current?.toggle();

return <IgrCombo ref={comboRef} data={cities} valueKey="id" displayKey="name" />;
```

</PlatformBlock>

### Estados de validación

Todo diseñador experimentado usa las restricciones con criterio para limitar la entrada del usuario y evitar estados no válidos, de ahí la disponibilidad de los estilos de validación. Gracias a los estilos de validación disponibles, la entrada del Combo es coherente con el estándar <PlatformBlock for="Angular">[Input](../../input-group.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Input](../input.mdx)</PlatformBlock> y preparado para diseños sofisticados que muestran indicadores visuales de éxito, advertencia y error.

<PlatformBlock for="React,WebComponents,Blazor">

El Combo de {Platform} está asociado a formularios. Establezca `required` para exigir al menos un elemento seleccionado, y `invalid` para mostrar el estado de error. Coloque la orientación o el mensaje de error en el slot `helper-text`. El Combo también expone los métodos `checkValidity`, `reportValidity` y `setCustomValidity` de la API de validación de restricciones. El Combo no tiene un estado de éxito o de advertencia integrado. El ejemplo muestra los estados de éxito y de advertencia como combos no válidos que toman el color de éxito o de advertencia del tema en lugar del color de error.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html

</igc-combo>
```

</PlatformBlock>

### Campo de búsqueda del desplegable

El desplegable del Combo de {Platform} contiene un campo de búsqueda que filtra las opciones a medida que el usuario escribe.

```ts
combo.filteringOptions = { filterKey: 'name', caseSensitive: false, matchDiacritics: true };
```

### Enlace de datos

El Combo de {Platform} construye su lista de opciones a partir de la matriz que enlaza a `data`. Cuando la matriz contiene objetos, establezca las claves que usa el Combo:

<PlatformBlock for="React,WebComponents">

- <ApiLink type="Combo" member="valueKey" label="valueKey" />: el campo que identifica una opción. El valor y la API de selección del Combo lo usan. Si lo omite, el Combo usa las referencias a los objetos.
- <ApiLink type="Combo" member="displayKey" label="displayKey" />: el campo que muestran la lista y el campo de entrada. Si lo omite, el Combo usa `valueKey`.
- <ApiLink type="Combo" member="groupKey" label="groupKey" />: el campo que agrupa las opciones. Cada grupo tiene un encabezado, y <ApiLink type="Combo" member="groupSorting" label="groupSorting" /> ordena los grupos de forma ascendente o descendente. Consulte [Agrupación](./features.mdx#agrupación) en el tema Funciones del Combo.

</PlatformBlock>

<PlatformBlock for="Blazor">

- <ApiLink pkg="core" type="Combo<T>" member="ValueKey" label="ValueKey" />: el campo que identifica una opción. El valor y la API de selección del Combo lo usan. Si lo omite, el Combo usa las referencias a los objetos.
- <ApiLink pkg="core" type="Combo<T>" member="DisplayKey" label="DisplayKey" />: el campo que muestran la lista y el campo de entrada. Si lo omite, el Combo usa `ValueKey`.
- <ApiLink pkg="core" type="Combo<T>" member="GroupKey" label="GroupKey" />: el campo que agrupa las opciones. Cada grupo tiene un encabezado, y <ApiLink pkg="core" type="Combo<T>" member="GroupSorting" label="GroupSorting" /> ordena los grupos de forma ascendente o descendente. Consulte [Agrupación](./features.mdx#agrupación) en el tema Funciones del Combo.

El parámetro de tipo `T` del Combo de Blazor es el tipo de sus valores. Establézcalo en el tipo del campo `ValueKey`, o en el tipo de las opciones cuando no establezca un `ValueKey`. Cuando enlace el `Value` con `@bind-Value`, Razor deduce `T` a partir del campo enlazado.

</PlatformBlock>

<PlatformBlock for="Angular">

- <ApiLink type="Combo" member="valueKey" label="valueKey" />: el campo que identifica una opción. El valor y la selección del Combo lo usan. Si lo omite, el Combo usa las referencias a los objetos.
- <ApiLink type="Combo" member="displayKey" label="displayKey" />: el campo que muestran la lista y el campo de entrada. Si lo omite, el Combo usa `valueKey`.
- <ApiLink type="Combo" member="groupKey" label="groupKey" />: el campo que agrupa las opciones. Cada grupo tiene un encabezado, y <ApiLink type="Combo" member="groupSortingDirection" label="groupSortingDirection" /> ordena los grupos. Consulte [Agrupación](./features.mdx#agrupación) en el tema Funciones del Combo.

</PlatformBlock>

<PlatformBlock for="Angular,React,WebComponents">

Para enlazar datos que se cargan desde un servicio remoto, consulte [Enlace remoto](./features.mdx#enlace-remoto) en el tema Funciones del Combo.

</PlatformBlock>

Cuando la matriz contiene valores primitivos, como cadenas o números, no establezca `valueKey` ni `displayKey`. El Combo usa los propios valores.

### Valor y selección

El Combo de {Platform} expone sus elementos seleccionados mediante su valor, y métodos que seleccionan y deseleccionan elementos en el código.

<PlatformBlock for="React,WebComponents,Blazor">

`value` contiene los elementos seleccionados como sus valores `valueKey`, o como referencias a objetos cuando no hay `valueKey`. Establézcalo para seleccionar elementos cuando el Combo se renderiza por primera vez. Los métodos `select` y `deselect` reciben una matriz de elementos; con una matriz vacía, seleccionan o deseleccionan todos los elementos:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
// select and deselect items by their ids, because the valueKey is 'id'
combo.select(['BG01', 'BG02']);
combo.deselect(['BG01']);

// select and deselect all items
combo.select();
combo.deselect();

console.log(combo.value); // the ids of the selected items
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
// select and deselect items by their ids, because the valueKey is 'id'
comboRef.current?.select(['BG01', 'BG02']);
comboRef.current?.deselect(['BG01']);

// select and deselect all items
comboRef.current?.select([]);
comboRef.current?.deselect([]);

console.log(comboRef.current?.value); // the ids of the selected items
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
@code {
    private IgbCombo<string> Combo;

    public void SelectCities() => Combo.Select(new object[] { "BG01", "BG02" });

    public void DeselectAll() => Combo.Deselect(new object[] { });
}
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Para permitir que los usuarios seleccionen un único elemento y escriban en el campo de entrada para filtrar la lista, use el modo [Selección única](./single-selection.mdx).

</PlatformBlock>

<PlatformBlock for="Angular">

El Combo de Angular admite el enlace bidireccional con `[(ngModel)]` y funciona en formularios basados en plantillas y reactivos. La propiedad <ApiLink type="Combo" member="selection" label="selection" /> devuelve los elementos seleccionados, y los métodos <ApiLink type="Combo" member="select" label="select" />, <ApiLink type="Combo" member="deselect" label="deselect" />, <ApiLink type="Combo" member="selectAllItems" label="selectAllItems" /> y <ApiLink type="Combo" member="deselectAllItems" label="deselectAllItems" /> la modifican:

```html
<igx-combo [data]="cities" displayKey="name" valueKey="id" [(ngModel)]="selectedCities"></igx-combo>
```

```ts
export class CitiesComponent {
    @ViewChild(IgxComboComponent, { static: true })
    public combo: IgxComboComponent;

    public selectedCities: string[] = ['BG01', 'UK01'];

    public selectFavorites(): void {
        this.combo.select(['UK01', 'BG01']);
    }
}
```

El Combo de Angular emite <ApiLink type="Combo" member="selectionChanging" label="selectionChanging" /> antes de que cambie la selección, que puede cancelarse, y <ApiLink type="Combo" member="selectionChanged" label="selectionChanged" /> después de que la selección se confirme.

Para permitir que los usuarios seleccionen un único elemento y escriban en el campo de entrada, use el [Combo simple](./single-selection.mdx).

</PlatformBlock>

### Qué hacer y qué no

Al usar el Combo, su entrada y su desplegable deben tener el mismo ancho, y sus bordes izquierdo y derecho deben coincidir. En cuanto a cómo se muestra el desplegable cuando el Combo recibe el foco, muéstrelo siempre encima del contenido que sigue al Combo que lo activa. Los combos no desplazan el contenido como hacen los paneles de expansión.

<DoDont
  doSrc={comboDoAlignment}
  doAlt="Combo de país abierto cuyo desplegable tiene el mismo ancho que su entrada y cubre los campos que tiene debajo"
  dontSrc={comboDoNotAlignment}
  dontAlt="Combo de país abierto cuyo desplegable es más estrecho que su entrada y está desplazado a la derecha"
>
<Fragment slot="do">

Alinee el desplegable con la entrada para que ambos tengan el mismo ancho y bordes izquierdo y derecho coincidentes.

</Fragment>
<Fragment slot="dont">

Evite un desplegable más estrecho que la entrada o desalineado, porque rompe la conexión visual entre ambos.

</Fragment>
</DoDont>

### Temas con Sass

Cuando modifica una propiedad primaria, todas las propiedades dependientes relacionadas se actualizan automáticamente para reflejar el cambio. El parámetro primario de la <PlatformBlock for="Angular"><ApiLink kind="sass" module="themes" type="function-combo-theme" label="combo-theme" code={true} /></PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">`combo-theme`</PlatformBlock> función es `$toggle-button-background`, a partir del cual el tema deriva los colores del botón de alternancia en todos los estados. Cree los temas del Combo, de su desplegable y de sus casillas de verificación, e inclúyalos con el mixin `tokens()`, que emite las variables CSS correspondientes en el ámbito donde lo incluya.

<PlatformBlock for="Angular">

```scss
@use "igniteui-angular/theming" as *;

$custom-combo-theme: combo-theme(
  $toggle-button-background: #e0e0e0
);

$custom-drop-down-theme: drop-down-theme(
  $background-color: #e6f2ff
);

$custom-checkbox-theme: checkbox-theme(
  $fill-color: #005dcc,
  $empty-color: #005dcc
);

:host {
  @include tokens($custom-combo-theme);
  @include tokens($custom-drop-down-theme);
  @include tokens($custom-checkbox-theme);
}
```

El Combo de Angular muestra su desplegable en una superposición. Según la encapsulación de vista y la ubicación del outlet de la superposición, un tema incluido bajo `:host` puede no llegar al desplegable. Consulte el tema [Estilo de superposiciones](../../overlay-styling.mdx).

</PlatformBlock>

## Accesibilidad

El Combo de {Platform} usa los roles del patrón WAI-ARIA combobox: el campo de entrada es un `combobox` que controla un `listbox` de opciones, y los usuarios abren la lista, se desplazan por ella y seleccionan opciones con el teclado.

### Interacción por teclado

<PlatformBlock for="React,WebComponents,Blazor">

El campo de entrada del Combo de {Platform} es una parada de tabulación. Cuando se abre el desplegable, el campo de búsqueda recibe el foco, o la lista cuando `autofocusList` está establecido o el campo de búsqueda está oculto. En el modo de selección única, el foco permanece en el campo de entrada. Las siguientes teclas funcionan mientras el Combo tiene el foco:

| Clave | Acción |
| --- | --- |
| <kbd>Arrow Down</kbd> | En el campo de entrada, abre el desplegable, y en el modo de selección única también mueve el foco a la lista y activa la primera opción. En el campo de búsqueda, mueve el foco a la lista y activa la primera opción. En la lista, activa la opción siguiente. |
| <kbd>Alt</kbd> + <kbd>Arrow Down</kbd> | En el campo de entrada, hace lo mismo que <kbd>Arrow Down</kbd>. |
| <kbd>Arrow Up</kbd> | En el campo de entrada, cierra el desplegable. En el campo de búsqueda, cierra el desplegable y mueve el foco al campo de entrada. En la lista, activa la opción anterior. Desde la primera opción, mueve el foco al campo de búsqueda, o cierra el desplegable y mueve el foco al campo de entrada cuando el campo de búsqueda está oculto. |
| <kbd>Home</kbd> / <kbd>End</kbd> | En la lista, activa la primera o la última opción. |
| <kbd>Space</kbd> | En la lista, selecciona o deselecciona la opción activa. |
| <kbd>Enter</kbd> | Con una opción activa, cierra el desplegable y mueve el foco al campo de entrada. En el modo de selección única, también selecciona la opción activa. |
| <kbd>Escape</kbd> | Cuando el desplegable está abierto, lo cierra y mueve el foco al campo de entrada. Cuando el desplegable está cerrado, borra la selección. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Cierra el desplegable y mueve el foco al elemento enfocable siguiente o anterior. En el modo de selección única, también selecciona la opción activa. |

Un Combo deshabilitado ignora estas teclas.

</PlatformBlock>

El campo de entrada del Combo de Angular es una parada de tabulación. Las siguientes teclas funcionan mientras el Combo tiene el foco:

| Clave | Acción |

| <kbd>Home</kbd> / <kbd>End</kbd> | En la lista, mueve el foco a la primera o a la última opción. |
| <kbd>Space</kbd> | En la lista, selecciona o deselecciona la opción activa. |

### Lectores de pantalla / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

El Combo de {Platform} renderiza los siguientes roles y atributos:

| Elemento | Rol | Atributos |
| --- | --- | --- |
| El campo de entrada | `combobox` | `aria-haspopup="listbox"`, `aria-expanded`, `aria-disabled`, `aria-controls` que apunta a la lista, y, con un texto de ayuda, `aria-describedby` que apunta a ella |
| La parte `list` | `listbox` | `aria-multiselectable` (`false` en el modo de selección única), `aria-labelledby` que apunta al campo de entrada, y `aria-activedescendant` que apunta a la opción activa |
| Cada parte `item` | `option` | `aria-selected`, `aria-posinset` y `aria-setsize` |
| La parte `clear-icon` | `button` | `aria-label` a partir de las cadenas de recursos |

El Combo de {Platform} también se comporta de la siguiente manera para la tecnología de asistencia:

- El campo de entrada toma su nombre accesible de la `label`. Sin etiqueta, obtiene un nombre de las cadenas de recursos que indica si hay opciones seleccionadas.
- La opción activa se anuncia mediante `aria-activedescendant` mientras el foco permanece en la lista.
- El contenido del desplegable cerrado es `inert`.

</PlatformBlock>

## Limitaciones conocidas

- El campo de entrada que muestra los elementos seleccionados no es editable. En Firefox, el cursor es visible en él.
- Cuando el Combo de Angular está enlazado a una matriz de valores primitivos que contiene `undefined`, la lista no muestra `undefined`. Cuando el campo `valueKey` de un objeto es `undefined`, la lista muestra el elemento, pero los usuarios no pueden seleccionarlo.
- Cuando el Combo de Angular está enlazado a un servicio remoto y tiene una selección predefinida, el campo de entrada permanece en blanco hasta que se cargan los datos.
- La lista usa el [Virtual Scroll](../../layouts/virtual-scroll.mdx#limitaciones-conocidas), así que se aplican sus limitaciones. La lista renderiza solo las opciones visibles, y el código que consulta el DOM encuentra solo esas opciones.

## Componentes relacionados

El Combo de {Platform} permite a los usuarios buscar en una lista y seleccionar una o varias opciones. Use estos componentes cuando la selección funcione de otra manera:

- <PlatformBlock for="Angular">[Select](../../select.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Select](../select.mdx)</PlatformBlock> - Use Select cuando los usuarios elijan una única opción de una lista corta que no necesite búsqueda.
- <PlatformBlock for="Angular">[Dropdown](../../drop-down.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Dropdown](../dropdown.mdx)</PlatformBlock> - Use Dropdown para mostrar una lista de acciones u opciones desde un botón u otro elemento.
<PlatformBlock for="Angular">- [Combo simple](./single-selection.mdx): use el Combo simple cuando los usuarios seleccionen un único elemento y puedan escribir en el campo de entrada para filtrar la lista o introducir un valor personalizado.</PlatformBlock>

## Preguntas frecuentes

Estas preguntas cubren los escenarios habituales de configuración, selección y uso del Combo de {Platform}.

<Faq>
  <FaqItem question="¿Cómo establezco los elementos seleccionados del Combo?" indicatorPosition="end">
    <PlatformBlock for="Angular">Enlace el Combo de Angular con `[(ngModel)]` o un control de formulario a una matriz de valores `valueKey`, o llame al método `select` con los elementos. Sin un `valueKey`, el Combo de Angular usa las referencias a los objetos de su `data`.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">Establezca el `value` del Combo de {Platform} en una matriz de valores `valueKey`, o llame al método `select` con los elementos. Sin un `valueKey`, el Combo de {Platform} usa las referencias a los objetos de su `data`.</PlatformBlock>
  </FaqItem>
  <FaqItem question="¿Puede el Combo permitir solo un elemento seleccionado?" indicatorPosition="end">
    <PlatformBlock for="Angular">El Combo de Angular siempre permite la selección múltiple. Use el Combo simple cuando los usuarios deban seleccionar un único elemento; además, permite escribir en el campo de entrada para filtrar la lista.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">Sí. Establezca `singleSelect` en el Combo de {Platform}, y los usuarios seleccionan un elemento y filtran la lista desde el campo de entrada en lugar del campo de búsqueda. Consulte el tema [Selección única](./single-selection.mdx).</PlatformBlock>
  </FaqItem>
  <FaqItem question="¿Cómo agrupo las opciones del Combo?" indicatorPosition="end">
    Establezca el `groupKey` del Combo de {Platform} en el campo que contiene el grupo de cada opción. El Combo de {Platform} muestra un encabezado para cada grupo y ordena los grupos.
  </FaqItem>
  <FaqItem question="¿Debo usar el Combo o el Select?" indicatorPosition="end">
    Use el Combo de {Platform} cuando la lista sea larga, los usuarios necesiten buscar en ella o seleccionen más de una opción. Use el Select de {Platform} para una lista corta de la que los usuarios elijan una única opción sin buscar.
  </FaqItem>
</Faq>
