# Combo de selección única

El Combo de selección única de {ProductName} es un Combo en el que los usuarios seleccionan una opción y filtran la lista desplegable con búsqueda escribiendo en el campo de entrada.

<PlatformBlock for="Angular">

El Combo de selección única de Angular es el Combo simple, el componente `igx-simple-combo`. Enlaza, agrupa y aplica plantillas a sus opciones como el Combo, y permite a los usuarios escribir en el campo de entrada para filtrar la lista o introducir un valor personalizado.

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

Establezca <PlatformBlock for="React,WebComponents"><ApiLink type="Combo" member="singleSelect" label="singleSelect" /></PlatformBlock><PlatformBlock for="Blazor"><ApiLink pkg="core" type="Combo<T>" member="SingleSelect" label="SingleSelect" /></PlatformBlock> en el Combo de {Platform} para cambiarlo a selección única. El campo de entrada pasa a ser editable y filtra la lista mientras el usuario escribe, el campo de búsqueda del desplegable se oculta, y las opciones no muestran casillas de verificación.

</PlatformBlock>

<DocsAside type="info">
El Combo tiene dos opciones de disposición: Combo con selección única (Combo simple) y Combo (selección múltiple).
</DocsAside>

En el modo de selección única, el elemento `igc-combo` renderiza un campo de entrada editable, oculta el campo de búsqueda del desplegable y renderiza las opciones sin casillas de verificación:

```text
igc-combo[single-select]
└─ #shadow-root
   ├─ igc-popover
   │  ├─ igc-input#target[slot="anchor"]            // the editable input field, exported as the "input" part
   │  │  ├─ slot[name="prefix"]
   │  │  ├─ span[part="clear-icon"]                  // shown when the Combo has a value
   │  │  ├─ slot[name="suffix"]
   │  │  └─ span[part="toggle-icon"]
   │  └─ div[part="list-wrapper"]                    // the dropdown
   │     ├─ div[part="filter-input"][hidden]         // the search input is hidden
   │     ├─ div[part="header"]
   │     │  └─ slot[name="header"]
   │     ├─ igc-virtual-scroll#dropdown[part="list"][role="listbox"]
   │     │  ├─ igc-combo-header[part="group-header"] // one for each group
   │     │  └─ igc-combo-item[part="item"][hide-checkbox] // one for each option
   │     ├─ div[part="empty"]                        // shown when the list has no options
   │     │  └─ slot[name="empty"]
   │     └─ div[part="footer"]
   │        └─ slot[name="footer"]
   └─ igc-validator#combo-helper-text               // the helper text and the validation messages, exported as the "helper-text" part
```

</PlatformBlock>

## Uso

Use el Combo de selección única de {Platform} cuando los usuarios elijan exactamente una opción de una lista en la que necesiten buscar, como un país o una ciudad.

### Tipo (tema Material)

En el tema Material, la entrada del Combo simple ofrece selección entre un tipo con borde, para una percepción más estructurada sobre fondos de color sólido, y un tipo con caja, más adecuado cuando se coloca sobre una imagen vivaz para mejorar la legibilidad. Los temas Bootstrap, Fluent e Indigo dibujan ambos tipos de la misma manera, por lo que los demás ejemplos de este tema muestran el tipo con caja solo en el tema Material.

```css
.small {
  --ig-size: var(--ig-size-small);
}

.large {
  --ig-size: var(--ig-size-large);
}
```

### Estados de interacción

El componente Combo admite cinco estados para las variantes habilitadas: Idle, Idle y Hover, Filled, Filled y Hover, y Focused, así como tres estados de validación: Success, Warn y Error.

Al hacer clic en el campo de entrada o en la alternancia se abre el desplegable, y al escribir en el campo de entrada se abre y se filtra la lista. Para abrir y cerrar el desplegable en el código, use la <PlatformBlock for="React,WebComponents">propiedad `open` o los métodos `show`, `hide` y `toggle`</PlatformBlock><PlatformBlock for="Blazor">parámetro `Open` o los métodos `ShowAsync`, `HideAsync` y `ToggleAsync`</PlatformBlock><PlatformBlock for="Angular">métodos `open`, `close` y `toggle`</PlatformBlock>:

<PlatformBlock for="WebComponents">

```ts
const combo = document.getElementById('countries') as IgcComboComponent;

await combo.show();
await combo.hide();
await combo.toggle();
```

</PlatformBlock>

```tsx
const comboRef = useRef<IgrCombo>(null);

const open = () => comboRef.current?.show();

return <IgrCombo ref={comboRef} singleSelect data={countries} valueKey="id" displayKey="name" />;
```

### Estados de validación

Todo diseñador experimentado usa las restricciones con criterio para limitar la entrada del usuario y evitar estados no válidos, de ahí la disponibilidad de los estilos de validación. Gracias a los estilos de validación disponibles, la entrada del Combo es coherente con el estándar <PlatformBlock for="Angular">[Input](../../input-group.mdx)</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">[Input](../input.mdx)</PlatformBlock> y preparado para diseños sofisticados que muestran indicadores visuales de éxito, advertencia y error.

<PlatformBlock for="React,WebComponents,Blazor">

El Combo de {Platform} está asociado a formularios. Establezca `required` para exigir un elemento seleccionado, y `invalid` para mostrar el estado de error. Coloque la orientación o el mensaje de error en el slot `helper-text`. En el modo de selección única, el valor del formulario es el valor `valueKey` del elemento seleccionado. El Combo no tiene un estado de éxito o de advertencia integrado. El ejemplo muestra los estados de éxito y de advertencia como combos no válidos que toman el color de éxito o de advertencia del tema en lugar del color de error.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-combo single-select outlined required invalid placeholder="Country">
  <span slot="helper-text">Please select a different region</span>
</igc-combo>
```

</PlatformBlock>

### Valor y selección

El Combo de selección única de {Platform} contiene un elemento seleccionado, y lo expone mediante su valor y su API de selección.

<PlatformBlock for="React,WebComponents,Blazor">

`value` contiene el elemento seleccionado como una matriz con un elemento: su valor `valueKey`, o la referencia al objeto cuando no hay `valueKey`. Establézcalo para seleccionar un elemento cuando el Combo se renderiza por primera vez. El método `select` selecciona un único elemento y deselecciona el anterior, así que pase un elemento; el método `deselect` lo deselecciona. Llamado sin elemento, `select` borra la selección en el modo de selección única:

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
// select the item matching the 'BG' value of the value key field
combo.select('BG');

// deselect it
combo.deselect('BG');

console.log(combo.value); // ['BG'] while Bulgaria is selected, [] after the deselection
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
// select the item matching the 'BG' value of the value key field
comboRef.current?.select('BG');

// deselect it
comboRef.current?.deselect('BG');

console.log(comboRef.current?.value); // ['BG'] while Bulgaria is selected, [] after the deselection
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCombo T="string" @ref="Combo" SingleSelect="true" Data="Countries" ValueKey="Id" DisplayKey="Name" />

@code {
    private IgbCombo<string> Combo;

    public void SelectBulgaria() => Combo.Select(new object[] { "BG" });

    public void DeselectBulgaria() => Combo.Deselect(new object[] { "BG" });
}
```

</PlatformBlock>

<PlatformBlock for="React,WebComponents,Blazor">

El Combo emite <PlatformBlock for="WebComponents">`igcChange`</PlatformBlock><PlatformBlock for="React">`onChange`</PlatformBlock><PlatformBlock for="Blazor">`Change`</PlatformBlock> antes de que el usuario cambie la selección. Su detalle contiene el nuevo valor, los elementos modificados y el tipo de cambio, y cancelarlo conserva la selección.

</PlatformBlock>

<PlatformBlock for="Angular">

El Combo simple de Angular admite el enlace bidireccional con `[(ngModel)]` y funciona en formularios basados en plantillas y reactivos. El valor enlazado es un único elemento: su valor `valueKey`, o la referencia al objeto cuando no hay `valueKey`. La propiedad <ApiLink type="SimpleCombo" member="selection" label="selection" /> devuelve el elemento seleccionado, el método <ApiLink type="SimpleCombo" member="select" label="select" /> selecciona un elemento, y el método <ApiLink type="SimpleCombo" member="deselect" label="deselect" /> borra la selección:

```html

```

```ts
    public combo: IgxSimpleComboComponent;

    public selectedCountry = 'BG';

    public selectBelgium(): void {
        this.combo.select('BE');

    public clear(): void {
        this.combo.deselect();
    }
}
```

El Combo simple de Angular emite <ApiLink type="SimpleCombo" member="selectionChanging" label="selectionChanging" /> antes de que cambie la selección, y <ApiLink type="SimpleCombo" member="selectionChanged" label="selectionChanged" /> después. Los argumentos del evento contienen el valor y el elemento anteriores y nuevos, así como el texto mostrado del campo de entrada, y establecer `cancel` en `selectionChanging` conserva la selección:

```html

```

```ts
public onCountryChanging(event: ISimpleComboSelectionChangingEventArgs): void {
    if (event.newValue === 'BY') {
        event.cancel = true;
    }
}
```

El evento `selectionChanging` también impulsa un escenario en cascada, en el que la selección de un Combo simple carga los datos del siguiente, por ejemplo, un combo de país, de región y de ciudad. Gestione el evento `selectionChanging` de cada Combo simple para cargar los datos del siguiente y borrar su selección:

```html
<igx-simple-combo #country
    [data]="countriesData"
    (selectionChanging)="countryChanging($event)"
    placeholder="Choose Country..."
    [(ngModel)]="selectedCountry"
    displayKey="name">
</igx-simple-combo>
<igx-simple-combo #region
    [data]="regionData"
    (selectionChanging)="regionChanging($event)"
    placeholder="Choose Region..."
    [(ngModel)]="selectedRegion"
    displayKey="name"
    [disabled]="regionData.length === 0">
</igx-simple-combo>
<igx-simple-combo #city
    [data]="citiesData"
    placeholder="Choose City..."
    [(ngModel)]="selectedCity"
    displayKey="name"
    [disabled]="citiesData.length === 0">
</igx-simple-combo>
```

```ts
export class SimpleComboCascadingComponent implements OnInit {
    public selectedCountry: Country;
    public selectedRegion: Region;
    public selectedCity: City;
    public countriesData: Country[];
    public regionData: Region[] = [];
    public citiesData: City[] = [];

    public ngOnInit(): void {
        this.countriesData = getCountries(['United States', 'Japan', 'United Kingdom']);
    }

    public countryChanging(e: ISimpleComboSelectionChangingEventArgs) {
        this.selectedCountry = e.newSelection as Country;
        this.regionData = getCitiesByCountry([this.selectedCountry?.name])
            .map(c => ({ name: c.region, country: c.country }))
            .filter((v, i, a) => a.findIndex(r => r.name === v.name) === i);
        this.selectedRegion = null;
        this.selectedCity = null;
        this.citiesData = [];
    }

    public regionChanging(e: ISimpleComboSelectionChangingEventArgs) {
        this.selectedRegion = e.newSelection as Region;
        this.citiesData = getCitiesByCountry([this.selectedCountry?.name])
            .filter(c => c.region === this.selectedRegion?.name);
        this.selectedCity = null;
    }
}
```

</PlatformBlock>

### Filtrado

Al escribir en el campo de entrada del Combo de selección única de {Platform} se abre el desplegable y se filtra la lista a las opciones que contienen el texto. La primera coincidencia pasa a ser la opción activa, así que <kbd>Enter</kbd> la selecciona.

<PlatformBlock for="React,WebComponents,Blazor">

Establezca `disableFiltering` para conservar la lista completa mientras el usuario escribe. El objeto `filteringOptions` establece la clave por la que filtra el texto, y si el filtrado distingue mayúsculas y coincide con los signos diacríticos. Cuando el Combo pierde el foco sin una opción seleccionada, el campo de entrada se borra.

</PlatformBlock>

<PlatformBlock for="WebComponents">

```ts
combo.filteringOptions = { filterKey: 'name', caseSensitive: false, matchDiacritics: true };
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrCombo singleSelect filteringOptions={{ filterKey: 'name', caseSensitive: false, matchDiacritics: true }} />
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbCombo T="string" SingleSelect="true" DisableFiltering="true" Data="Countries" ValueKey="Id" DisplayKey="Name" />
```

</PlatformBlock>

<PlatformBlock for="Angular">

Establezca <ApiLink type="SimpleCombo" member="disableFiltering" label="disableFiltering" /> para conservar la lista completa mientras el usuario escribe, y <ApiLink type="SimpleCombo" member="showSearchCaseIcon" label="showSearchCaseIcon" /> para mostrar en el campo de entrada un botón que alterna el filtrado con distinción de mayúsculas. La entrada <ApiLink type="SimpleCombo" member="filteringOptions" label="filteringOptions" /> establece la clave por la que filtra el texto y si el filtrado distingue mayúsculas, y <ApiLink type="SimpleCombo" member="filterFunction" label="filterFunction" /> sustituye el filtrado por el suyo propio. Cuando el Combo simple pierde el foco sin una opción seleccionada, el campo de entrada se borra:

```html
<igx-simple-combo [data]="countries" displayKey="name" [showSearchCaseIcon]="true"
                  [filteringOptions]="{ filteringKey: 'name', caseSensitive: false }">
</igx-simple-combo>
```

Establezca <ApiLink type="SimpleCombo" member="allowCustomValues" label="allowCustomValues" /> para permitir que el usuario introduzca un valor que no está en la lista. Cuando el texto no coincide con ninguna opción, el desplegable muestra un botón de añadir elemento, y <kbd>Enter</kbd> sobre él añade el texto como un nuevo elemento y lo selecciona. El Combo simple emite <ApiLink type="SimpleCombo" member="addition" label="addition" /> antes de añadir el elemento:

```html
<igx-simple-combo [data]="countries" displayKey="name" valueKey="id" [allowCustomValues]="true" (addition)="onAddition($event)"></igx-simple-combo>
```

</PlatformBlock>

### Qué hacer y qué no

Al usar el Combo simple, su entrada y su desplegable deben tener el mismo ancho, y sus bordes izquierdo y derecho deben coincidir. En cuanto a cómo se muestra el desplegable cuando el Combo simple recibe el foco, muéstrelo siempre encima del contenido que sigue al Combo que lo activa. Los combos no desplazan el contenido como hacen los paneles de expansión.

### Temas con Sass

Cuando modifica una propiedad primaria, todas las propiedades dependientes relacionadas se actualizan automáticamente para reflejar el cambio. ## Accesibilidad

El Combo de selección única de {Platform} usa los roles del patrón WAI-ARIA combobox: el campo de entrada editable es un `combobox` que controla un `listbox` de opciones, y los usuarios filtran la lista escribiendo y seleccionan una opción con el teclado.

### Interacción por teclado

<PlatformBlock for="React,WebComponents,Blazor">

El campo de entrada del Combo de selección única de {Platform} es una parada de tabulación, y el foco permanece en él mientras el usuario escribe. Las siguientes teclas funcionan mientras el Combo tiene el foco:

| Clave | Acción |
| --- | --- |
| Caracteres imprimibles | En el campo de entrada, abre el desplegable, filtra la lista y activa la primera coincidencia. |
| <kbd>Flecha abajo</kbd> / <kbd>Alt</kbd> + <kbd>Flecha abajo</kbd> | En el campo de entrada, abre el desplegable, mueve el foco a la lista y activa la primera opción. En la lista, activa la opción siguiente. |
| <kbd>Arrow Up</kbd> | En el campo de entrada, cierra el desplegable. En la lista, activa la opción anterior. Desde la primera opción, cierra el desplegable y mueve el foco al campo de entrada. |
| <kbd>Home</kbd> / <kbd>End</kbd> | En la lista, activa la primera o la última opción. |
| <kbd>Space</kbd> | En la lista, selecciona la opción activa, o la deselecciona cuando ya está seleccionada. |
| <kbd>Enter</kbd> | Con una opción activa, la selecciona, cierra el desplegable y mueve el foco al campo de entrada con su texto seleccionado. |
| <kbd>Escape</kbd> | Cuando el desplegable está abierto, lo cierra y mueve el foco al campo de entrada. Cuando el desplegable está cerrado, borra la selección. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Cuando el desplegable está abierto, selecciona la opción activa, cierra el desplegable y mueve el foco al elemento enfocable siguiente o anterior. |

Un Combo deshabilitado ignora estas teclas.

</PlatformBlock>

### Lectores de pantalla / ARIA

<PlatformBlock for="React,WebComponents,Blazor">

El Combo de selección única de {Platform} renderiza los siguientes roles y atributos:

| Elemento | Rol | Atributos |
| --- | --- | --- |
| El campo de entrada | `combobox` | `aria-haspopup="listbox"`, `aria-expanded`, `aria-disabled`, `aria-controls` que apunta a la lista, y, con un texto de ayuda, `aria-describedby` que apunta a ella |
| La parte `list` | `listbox` | `aria-multiselectable="false"`, `aria-labelledby` que apunta al campo de entrada, y `aria-activedescendant` que apunta a la opción activa |
| Cada parte `item` | `option` | `aria-selected`, `aria-posinset` y `aria-setsize` |
| La parte `clear-icon` | `button` | `aria-label` a partir de las cadenas de recursos |

El Combo de selección única de {Platform} también se comporta de la siguiente manera para la tecnología de asistencia:

- El campo de entrada toma su nombre accesible de la `label`. Sin etiqueta, obtiene un nombre de las cadenas de recursos que indica si una opción está seleccionada.
- El campo de entrada es editable, y el texto que escriben los usuarios es el filtro de la lista.
- La opción activa se anuncia mediante `aria-activedescendant` mientras el foco permanece en la lista.
- El contenido del desplegable cerrado es `inert`.

</PlatformBlock>

## Limitaciones conocidas

<PlatformBlock for="React,WebComponents,Blazor">

- El modo de selección única oculta el campo de búsqueda del desplegable, así que `placeholderSearch`, `caseSensitiveIcon` y `autofocusList` no tienen efecto.
- El Combo de {Platform} no añade valores personalizados. Cuando el texto del campo de entrada no coincide con ninguna opción, el Combo borra el campo de entrada al perder el foco.

</PlatformBlock>

<PlatformBlock for="Angular">

- Cuando el Combo simple de Angular está enlazado a una matriz de valores primitivos que contiene `undefined`, la lista no muestra `undefined`. Cuando el campo `valueKey` de un objeto es `undefined`, la lista muestra el elemento, pero los usuarios no pueden seleccionarlo.
- Cuando el Combo simple de Angular está enlazado con `ngModel` y está `required`, los valores `null`, `undefined` y `''` no pueden seleccionarse.
- Cuando el Combo simple de Angular está enlazado a un servicio remoto y tiene una selección predefinida, el campo de entrada permanece en blanco hasta que se cargan los datos.
- La lista usa el [Virtual Scroll](../../layouts/virtual-scroll.mdx#limitaciones-conocidas), así que se aplican sus limitaciones. La lista renderiza solo las opciones visibles, y el código que consulta el DOM encuentra solo esas opciones.

</PlatformBlock>

## Preguntas frecuentes

Estas preguntas cubren los escenarios habituales de configuración, selección y uso del Combo de selección única de {Platform}.

<Faq>
  <FaqItem question="¿Cómo hago que el Combo seleccione un único elemento?" indicatorPosition="end">
    <PlatformBlock for="Angular">Use el Combo simple de Angular, el componente `igx-simple-combo`, en lugar del Combo. El Combo simple selecciona un elemento y permite a los usuarios escribir en su campo de entrada para filtrar la lista.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">Establezca `singleSelect` en el Combo de {Platform}. El Combo selecciona entonces un elemento cada vez, permite a los usuarios escribir en su campo de entrada para filtrar la lista, y oculta el campo de búsqueda y las casillas de verificación del desplegable.</PlatformBlock>
  </FaqItem>
  <FaqItem question="¿Cómo establezco el elemento seleccionado del Combo de selección única?" indicatorPosition="end">
    <PlatformBlock for="Angular">Enlace el Combo simple de Angular con `[(ngModel)]` o con un control de formulario a un único valor `valueKey`, o llame al método `select` con el elemento. Sin un `valueKey`, el Combo simple usa una referencia al objeto de su `data`.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">Establezca el `value` del Combo de {Platform} en una matriz con el valor `valueKey` del elemento, o llame al método `select` con el elemento. Sin un `valueKey`, el Combo de {Platform} usa una referencia al objeto de su `data`.</PlatformBlock>
  </FaqItem>
  <FaqItem question="¿Pueden los usuarios introducir un valor que no está en la lista?" indicatorPosition="end">
    <PlatformBlock for="Angular">Sí. Establezca `allowCustomValues` en el Combo simple de Angular, y el desplegable muestra un botón de añadir elemento cuando el texto no coincide con ninguna opción. El Combo simple añade el texto como un nuevo elemento y lo selecciona.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">No. El Combo de {Platform} selecciona opciones solo de su `data`. Cuando el texto del campo de entrada no coincide con ninguna opción, el Combo borra el campo de entrada al perder el foco.</PlatformBlock>
  </FaqItem>
  <FaqItem question="¿Por qué escribir en el Combo de selección única no filtra la lista?" indicatorPosition="end">
    <PlatformBlock for="Angular">El Combo simple de Angular filtra por el campo `displayKey`. Compruebe que `disableFiltering` no esté establecido, y que `filteringOptions` o `filterFunction` coincidan con el campo que muestra la lista.</PlatformBlock><PlatformBlock for="React,WebComponents,Blazor">El Combo de {Platform} filtra por el campo `displayKey`, o por el `filterKey` de su `filteringOptions`. Compruebe que `disableFiltering` no esté establecido, y que el nombre de la clave corresponda a un campo de las opciones.</PlatformBlock>
  </FaqItem>
  <FaqItem question="¿Debo usar el Combo de selección única o el Select?" indicatorPosition="end">
    Use el Combo de selección única de {Platform} cuando la lista sea larga y los usuarios necesiten buscar en ella escribiendo. Use el Select de {Platform} para una lista corta de la que los usuarios elijan una opción sin buscar.
  </FaqItem>
</Faq>
