# {Platform} Ripple - Descripción general

El componente {ProductName} Ripple crea una animación en respuesta a un toque o a un clic del ratón.

## Uso


<PlatformBlock for="WebComponents">


Primero, debe instalar {ProductName} ejecutando el siguiente comando:

```cmd
npm install {PackageWebComponents}
```

Antes de usar <ApiLink pkg="core" type="Ripple" />, debe registrarlo de la siguiente manera:

```ts
import { defineComponents, IgcRippleComponent } from "igniteui-webcomponents";
import 'igniteui-webcomponents/themes/light/bootstrap.css';

defineComponents(IgcRippleComponent);
```

Para una introducción completa a {ProductName}, lea el tema [**Primeros pasos**](../general-getting-started.mdx).

</PlatformBlock>



<PlatformBlock for="React">


Primero, debe instalar el paquete npm correspondiente {ProductName} ejecutando el siguiente comando:

```cmd
npm install igniteui-react
```

A continuación, debe importar <ApiLink pkg="core" type="Ripple" /> y su CSS necesario, de la siguiente manera:

```tsx
import { IgrRipple } from 'igniteui-react';
import 'igniteui-webcomponents/themes/light/bootstrap.css';
```

</PlatformBlock>



<PlatformBlock for="Blazor">



Registre los servicios de {ProductName}:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

Registrar <ApiLink pkg="core" type="RippleModule" />, el módulo de recursos de cliente de <ApiLink pkg="core" type="Ripple" />, es **opcional**: el componente carga sus recursos la primera vez que se muestra. Incluirlo en `builder.Services.AddIgniteUIBlazor(typeof(IgbRippleModule))` sirve para precargar recursos o para admitir elementos creados solo en el cliente (véase [Módulos de componentes](../general-getting-started.mdx#módulos-de-componentes)).

También necesitará enlazar un archivo CSS adicional para aplicar el estilo al componente <ApiLink pkg="core" type="Ripple" />. Lo siguiente debe colocarse en la página host de la aplicación (**wwwroot/index.html** en una aplicación Blazor WebAssembly independiente o Blazor Hybrid, **Pages/_Host.cshtml** en una aplicación Blazor Server, **Components/App.razor** en una aplicación Blazor Web App):

```razor
<link href="_content/IgniteUI.Blazor/themes/light/bootstrap.css" rel="stylesheet" />
```


</PlatformBlock>


La forma más sencilla de empezar a usar <ApiLink pkg="core" type="Ripple" /> es la siguiente:

<PlatformBlock for="WebComponents">

```html
<igc-button>
  <igc-ripple></igc-ripple>
  Ripple Button
</igc-button>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrButton>
  <IgrRipple></IgrRipple>
  <span>Ripple Button</span>
</IgrButton>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbButton Variant="@ButtonVariant.Contained">
    Ripple Button
    <IgbRipple></IgbRipple>
</IgbButton>
```

</PlatformBlock>

Puede añadir el componente <ApiLink pkg="core" type="Ripple" /> a cualquier elemento web siempre que su propiedad CSS `position` tenga un valor distinto de `static`;

## Ejemplos

### Color

Puede cambiar el color del ripple estableciendo la propiedad CSS `--color` en cualquier color CSS válido:

```css
igc-ripple {
  --color: olive;
}
```
