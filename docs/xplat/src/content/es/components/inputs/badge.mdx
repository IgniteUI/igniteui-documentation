# Componente Badge

El componente Badge de {Platform} se proporciona en el paquete específico de la plataforma {ProductName} y se usa junto con avatares, menús de navegación u otros componentes de una aplicación cuando se necesita una notificación visual. Los badges suelen diseñarse con estilos predefinidos para comunicar información, éxito, advertencias o errores.

## Uso

Use el Badge de {Platform} para mostrar un indicador breve de estado, categoría, recuento o notificación junto a otro componente.

<PlatformBlock for="Angular">

Veamos cómo se hace la demostración. Es un badge sencillo de éxito sobre un avatar. Para crearlo, importe `IgxAvatarModule` junto con `IgxBadgeModule`:

```typescript
import { IgxBadgeModule } from 'igniteui-angular/badge';
import { IgxAvatarModule } from 'igniteui-angular/avatar';
```

Añada ambos módulos a la colección `imports` del componente, o importe los componentes independientes. Después, añada los componentes a su plantilla:

```html
<div class="wrapper">
  <igx-avatar icon="person" shape="circle" size="small"></igx-avatar>
  <igx-badge icon="check" type="success"></igx-badge>
</div>
```

Use un wrapper con posición relativa para colocar el Badge sobre el avatar:

```scss
.wrapper {
  position: relative;
  margin-top: 15px;
}

igx-badge {
  position: absolute;
  bottom: 0;
  left: 28px;
}
```

### Tipo

El Badge puede contener distintos tipos de contenido, como un número o un icono.

Use la entrada `[value]` para mostrar texto o un recuento numérico dentro del Badge:

```html
<igx-badge [value]="model.value"></igx-badge>
```

Use la entrada `[icon]` para mostrar un icono dentro del Badge:

```html
<igx-badge icon="check" type="success"></igx-badge>
```

Cuando se establecen `[icon]` y `[value]`, el Badge muestra ambos a la vez:

```html
<igx-badge icon="check" value="5" type="success"></igx-badge>
```

También puede proyectar contenido directamente. Al proyectar tanto un icono como texto, envuelva el texto para mantener el relleno correcto:

```html
<igx-badge>
  <igx-icon>bluetooth</igx-icon>
  <span>Bluetooth</span>
</igx-badge>
```

### Qué hacer y qué no

**Cuándo usarlo:** use un Badge para comunicar un estado breve, una categoría, un recuento o el estado de una notificación junto a otro componente. Use `dot` cuando el indicador no necesite texto visible.

**Cuándo no usarlo:** no use un Badge como control principal de una acción, como sustituto de un mensaje de validación de formulario, ni cuando el estado no pueda entenderse a partir del contenido del badge, del contexto que lo rodea o de la etiqueta accesible.

## Accesibilidad

El Badge de {Platform} es un elemento visual de estado no interactivo que comunica un recuento, un estado o una notificación breve.

### Interacción por teclado

El Badge no recibe el foco, no gestiona la entrada del teclado ni expone eventos de interacción del componente.

| Clave | Acción |
| -- | -- |
| n/a | El Badge no es interactivo con el teclado. |

### Lectores de pantalla / ARIA

El host del Badge usa `role="status"` para exponer su contenido como información de estado.

<PlatformBlock for="WebComponents, React, Blazor">

- El componente establece `aria-roledescription` para identificar el Badge y su `variant` actual.
- Añada un `aria-label` cuando un Badge sin texto, incluido un Badge `dot`, comunique un estado que de otro modo no estaría disponible para la tecnología de asistencia.
- Mantenga el contenido del Badge o la etiqueta accesible específicos del elemento decorado, como `3 unread messages` en lugar de solo `3`.

</PlatformBlock>

<PlatformBlock for="Angular">

- El componente se inicializa con `role="status"` y `aria-label="badge"`.
- Angular deriva `aria-roledescription` del tipo de Badge y de su icono o valor. Establezca la entrada `label` cuando `badge` no sea un nombre accesible significativo.
- Añada un `label` significativo para un Badge sin texto o para un Badge `dot` cuando su estado no esté disponible de otro modo para la tecnología de asistencia.

</PlatformBlock>

### Cumplimiento de accesibilidad

Infragistics documenta la compatibilidad de accesibilidad de {ProductName} con las áreas de las pautas de la Sección 508 y WCAG 2.1 en el tema [Cumplimiento de accesibilidad](../interactivity/accessibility-compliance.mdx).

| Criterio | Cómo cumple el componente |
| -- | -- |
| [4.1.2 Nombre, función, valor](https://www.w3.org/WAI/WCAG21/Understanding/name-role-value.html) | El Badge expone el rol semántico `status`. La implementación xplat también expone una descripción de rol basada en la variante actual; Angular expone una etiqueta accesible y una descripción de rol basadas en su tipo y contenido. |

Sus responsabilidades:

- Proporcione un nombre accesible que explique el estado cuando el Badge no tenga texto significativo, especialmente en los Badges `dot`.
- No use el color del Badge como única indicación del estado; acompáñelo de texto, un icono u otra señal accesible.
- Mantenga un contraste suficiente entre el primer plano y el fondo del Badge al sobrescribir los estilos del tema.

## Solución de problemas

Use esta sección para revisar los límites y las decisiones habituales antes de tratar el Badge como un control interactivo o como única indicación de estado.

### ¿Por qué mi color de fondo personalizado no cambia el Badge?

La `variant` seleccionada tiene prioridad sobre la variable CSS `--background-color`. Para usar un color de fondo personalizado, evite establecer una variante que aplique su propio color de fondo.

### ¿Por qué mi Badge de punto no muestra contenido?

La propiedad `dot` renderiza el Badge como un indicador mínimo y no admite contenido. Use un Badge normal cuando necesite mostrar texto u otro contenido en línea.

### Limitaciones conocidas

El Badge de {Platform} tiene las siguientes limitaciones independientes de la plataforma.

- Un Badge de punto es solo un indicador y no puede mostrar texto ni un icono.
- El estilo del Badge y los nombres de variante/tipo difieren entre Angular y los demás frameworks compatibles. Use los ejemplos específicos de cada plataforma y los enlaces a la API de esta página en lugar de copiar un atributo de un framework a otro.
- El Badge es un indicador visual de estado y no proporciona interacción propia por teclado.

## Preguntas frecuentes

<Faq>

  <FaqItem question="¿Puede un Badge mostrar un icono y texto a la vez?">
    Sí. Use el área de contenido del Badge para el texto y el contenido de icono admitido para el indicador visual. Mantenga la combinación breve para que siga siendo una etiqueta compacta de estado o categoría.
  </FaqItem>

  <FaqItem question="¿Cómo muestro un punto de notificación sin contenido?">
    Establezca la propiedad o el atributo `dot` específico de la plataforma. Un Badge de punto se renderiza intencionadamente sin texto ni otro contenido.
  </FaqItem>

  <FaqItem question="¿Cuándo debo usar un Badge de punto en lugar de un Badge de texto?">
    Use un Badge de punto cuando el estado se comunique solo por su presencia. Use un Badge de texto cuando los usuarios necesiten entender el estado, la categoría o el recuento sin depender del color o de la posición.
  </FaqItem>

  <FaqItem question="¿Qué paquete debo instalar para el Badge?">
    Use `igniteui-angular` para Angular, `igniteui-react` para React, `igniteui-webcomponents` para Web Components y `IgniteUI.Blazor` para Blazor. Mantenga los paquetes relacionados de Ignite UI en la misma versión.
  </FaqItem>
