# Componente Dropdown List de {Platform} - Descripción general

Con muchas funciones, la lista desplegable {Platform} ofrece de serie filtrado, accesibilidad, valores preseleccionados, enlace de datos flexible, agrupación, personalización de la interfaz y mucho más. En la práctica, este componente sustituye de forma eficaz y sencilla las etiquetas select de HTML, y permite a los usuarios elegir rápidamente un valor no editable de un conjunto predefinido de varias opciones.

El componente Dropdown de Ignite UI for {Platform} muestra una lista desplegable de valores predefinidos y permite a los usuarios seleccionar fácilmente un único elemento con un clic. Puede configurarse rápidamente para actuar como un menú desplegable {Platform}, o simplemente usarse para ofrecer información visual más útil agrupando datos. Además, con la agrupación puede usar datos planos y jerárquicos.

Con nuestro componente obtiene todas las funciones y opciones de personalización que necesita para su proyecto: personalizaciones de estilo, opciones de colocación del Dropdown de {Platform}, plantillas y la capacidad de cambiar qué se muestra y cómo en el encabezado, el pie, el cuerpo, la lista, etc.

### Destino

La lista desplegable de {Platform} se posiciona de forma relativa a su destino. El slot `target` permite proporcionar un componente integrado que alterna la propiedad `open` al hacer clic. En algunos casos querrá usar un destino externo o usar otro evento para alternar la apertura del Dropdown. Puede lograrlo con los métodos <ApiLink pkg="core" type="Dropdown" member="show" label="Show" />, <ApiLink pkg="core" type="Dropdown" member="hide" label="Hide" /> y <ApiLink pkg="core" type="Dropdown" member="toggle" label="Toggle" />, que permiten pasar el destino como parámetro. De forma predeterminada, la lista desplegable usa la posición CSS `absolute`. Tendrá que establecer el <ApiLink kind="interface" type="OverlaySettings" member="positionStrategy" label="PositionStrategy" /> del Dropdown de {Platform} en `fixed` cuando el elemento de destino esté dentro de un contenedor fijo, pero el Dropdown no lo esté. La lista desplegable se dimensiona automáticamente según su contenido; si quiere que la lista tenga el mismo ancho que el destino, debe establecer la propiedad <ApiLink pkg="core" type="Dropdown" member="sameWidth" label="SameWidth" /> en `true`.

### Posición

La posición preferida del Dropdown de {Platform} puede establecerse mediante la propiedad <ApiLink pkg="core" type="Dropdown" member="placement" label="Placement" />. La posición predeterminada del Dropdown es `bottom-start`. La propiedad <ApiLink pkg="core" type="Dropdown" member="flip" label="Flip" /> determina si la posición debe invertirse cuando no hay espacio suficiente para mostrar el Dropdown en la posición indicada. La distancia entre la lista desplegable de {Platform} y su destino puede especificarse mediante la propiedad <ApiLink pkg="core" type="Dropdown" member="distance" label="Distance" />.

### Selección

El <ApiLink pkg="core" type="Dropdown" /> emite el evento `Change` cuando el usuario selecciona un elemento. El método <ApiLink pkg="core" type="Dropdown" member="select" label="Select" /> del Dropdown permite seleccionar un elemento por su índice o por su valor.

### Elemento

El <ApiLink pkg="core" type="DropdownItem" /> representa un elemento seleccionable de la lista desplegable. Puede predefinir un elemento seleccionado estableciendo la propiedad <ApiLink pkg="core" type="DropdownItem" member="selected" label="Selected" />. También puede deshabilitar un elemento para que no pueda seleccionarse mediante la propiedad <ApiLink pkg="core" type="DropdownItem" member="disabled" label="Disabled" />.

El <ApiLink pkg="core" type="DropdownItem" /> tiene un slot predeterminado que permite especificar el contenido del elemento. También puede proporcionar contenido personalizado que se renderice antes o después del contenido mediante los slots `prefix` y `suffix`.
Recomendamos usar un elemento `<span>` cuando se añada texto simple, símbolos o emojis, y un componente [`<igc-icon>`](../layouts/icon.mdx) cuando se añadan iconos a los slots `prefix` y `suffix`.


### Estrategia de desplazamiento

La propiedad <ApiLink kind="interface" type="OverlaySettings" member="scrollStrategy" label="ScrollStrategy" /> determina el comportamiento del componente cuando se desplaza el contenedor del elemento de destino. El valor predeterminado es `scroll`, lo que significa que el Dropdown se desplazará junto con su destino. Si establece la propiedad en `block`, se bloqueará el desplazamiento mientras el Dropdown esté abierto. También puede establecer la propiedad en `close`, lo que significa que el Dropdown se cerrará automáticamente al desplazarse.

### Mantener abierto

De forma predeterminada, el Dropdown se cierra automáticamente cuando el usuario hace clic fuera de él o selecciona un elemento. Puede impedir este comportamiento con las propiedades <ApiLink pkg="core" type="Dropdown" member="keepOpenOnOutsideClick" label="KeepOpenOnOutsideClick" /> y <ApiLink pkg="core" type="Dropdown" member="keepOpenOnSelect" label="KeepOpenOnSelect" />.

## Estilos

Puede cambiar el aspecto del Dropdown y de sus elementos mediante las partes CSS expuestas. El <ApiLink pkg="core" type="Dropdown" /> expone las partes `base` y `list`, el <ApiLink pkg="core" type="DropdownItem" /> expone las partes `prefix`, `content` y `suffix`, y el <ApiLink pkg="core" type="DropdownGroup" /> expone la parte `label`.

```css
igc-dropdown::part(list) {
  height: 220px;
}

igc-dropdown-item[selected] {
  background: var(--ig-success-300);
}

igc-dropdown-group::part(label) {
  display: flex;
  justify-content: center;
}
```
