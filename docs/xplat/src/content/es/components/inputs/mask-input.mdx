## {Platform} Mask Input - Descripción general

El {ProductName} Mask Input es un campo de entrada que permite al desarrollador controlar la entrada del usuario y dar formato al valor visible, según reglas configurables. Ofrece distintas opciones de entrada y es fácil de usar y de configurar.

### Reglas de máscara
La tabla siguiente muestra las reglas de máscara integradas admitidas:

| Carácter de máscara | Descripción |
| :--- | :--- |
| 0 | Carácter de dígito [0-9]. La entrada es obligatoria. |
| 9 | Carácter de dígito [0-9]. La entrada es opcional. |
| # | Carácter de dígito [0-9], signo más (+) o signo menos (-). La entrada es obligatoria. |
| L | Carácter de letra. La entrada es obligatoria. |
| ? | Carácter de letra. La entrada es opcional. |
| A | Carácter alfanumérico (letra o dígito). La entrada es obligatoria. |
| a | Carácter alfanumérico (letra o dígito). La entrada es opcional. |
| & | Cualquier carácter del teclado. La entrada es obligatoria. |
| C | Cualquier carácter del teclado. La entrada es opcional. |
| \ | Escapa un indicador de máscara y lo convierte en un literal. |

Estos indicadores también participan en la validación del componente; es decir, la entrada pasa a ser no válida si se rellenan algunas, pero no todas, las posiciones obligatorias (que no haya posiciones rellenas o un valor vacío sigue siendo responsabilidad de <ApiLink pkg="core" type="MaskInput" member="required" label="required" />). Esto se aplica tanto a las entradas independientes como a las incluidas en un formulario.

### Aplicar la máscara

Aplicar la máscara es bastante sencillo. Solo tiene que proporcionar un patrón predeterminado a la propiedad <ApiLink pkg="core" type="MaskInput" member="mask" label="Mask" /> de la entrada.

En el siguiente ejemplo, aplicaremos una máscara para un número de teléfono con código de extensión.

<PlatformBlock for="WebComponents">

```html
<igc-mask-input id="mask-input" mask="(####) 00-00-00 Ext. 9999">
    <igc-icon name="phone" slot="prefix"></igc-icon>
    <span slot="helper-text">Phone number</span>
</igc-mask-input>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrMaskInput mask="(####) 00-00-00 Ext. 9999">
    <span slot="prefix">
        <IgrIcon ref={iconPhoneRef} name="phone" collection="material"></IgrIcon>
    </span>
    <span slot="helper-text">Phone number</span>
</IgrMaskInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbMaskInput @ref="MaskInputRef" Mask="(####) 00-00-00 Ext. 9999">
    <IgbIcon IconName="phone" Collection="material" slot="prefix"></IgbIcon>
    <span slot="helper-text">Phone number</span>
</IgbMaskInput>
```

</PlatformBlock>

### Carácter de indicación

Los desarrolladores pueden personalizar el símbolo de indicación que se usa para las partes no rellenas de la máscara. Para ello, basta con proporcionar cualquier carácter a la propiedad <ApiLink pkg="core" type="MaskInput" member="prompt" label="Prompt" />:

<PlatformBlock for="WebComponents">

```html
<igc-mask-input id="mask-input" mask="(####) 00-00-00 Ext. 9999" prompt="-"></igc-mask-input>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrMaskInput mask="(####) 00-00-00 Ext. 9999" prompt="-"></IgrMaskInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbMaskInput @ref="MaskInputRef" Mask="(####) 00-00-00 Ext. 9999" Prompt="-"></IgbMaskInput>
```

</PlatformBlock>

De forma predeterminada, el carácter `prompt` es el **guion bajo**.

### Placeholder

Los desarrolladores también pueden aprovechar la propiedad <ApiLink pkg="core" type="MaskInput" member="placeholder" label="Placeholder" />, que cumple la función del atributo placeholder nativo de la entrada. Si no se proporciona ningún valor para el placeholder, se usa el valor de la máscara tal cual.

<PlatformBlock for="WebComponents">

```html
<igc-mask-input id="mask-input" mask="00/00/0000" placeholder="dd/MM/yyyy"></igc-mask-input>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrMaskInput mask="00/00/0000" placeholder="dd/MM/yyyy"></IgrMaskInput>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbMaskInput @ref="MaskInputRef" Mask="00/00/0000" Placeholder="dd/MM/yyyy"></IgbMaskInput>
```

</PlatformBlock>

### Modos de valor

El <ApiLink pkg="core" type="MaskInput" /> expone una propiedad <ApiLink pkg="core" type="MaskInput" member="valueMode" label="ValueMode" /> que le permite elegir entre las opciones `raw` y `withFormatting` para configurar qué valor de la entrada (con formato o sin formato) se enlaza en su formulario cuando se aplica una máscara concreta. De forma predeterminada, <ApiLink pkg="core" type="MaskInput" member="valueMode" label="ValueMode" /> está establecido en `raw`. Pruébelo usted mismo en el siguiente ejemplo:

## Estilos

El componente <ApiLink pkg="core" type="MaskInput" /> expone partes CSS para casi todos sus elementos internos. La tabla siguiente enumera todas las partes CSS expuestas:

|Nombre|Descripción|
|--|--|
| `container` | El wrapper principal que contiene todos los elementos de entrada principales. |
| `input` | El elemento input nativo. |
| `label` | El elemento label nativo. |
| `prefix` | El wrapper del prefijo. |
| `suffix` | El wrapper del sufijo. |
| `helper-text` | El wrapper del texto de ayuda. |

```css
igc-mask-input::part(input) {
  background-color: var(--ig-primary-100);
  border-color: var(--ig-secondary-500);
  box-shadow: none;
}

igc-mask-input::part(input)::placeholder {
  color: var(--ig-primary-100-contrast);
}
```

## Supuestos y limitaciones

- La entrada con máscara no expone un atributo _type_, ya que siempre es una entrada de tipo **text**.
- Actualmente, el comportamiento de deshacer/rehacer no está admitido.
