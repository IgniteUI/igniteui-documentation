# {Platform} File Input - Descripción general

El componente {ProductName} File Input ofrece una forma interactiva para que los usuarios seleccionen y carguen archivos. Amplía la funcionalidad base de <ApiLink pkg="core" type="Input" /> con características específicas de archivos, como la selección de archivos, la visualización de los nombres de los archivos seleccionados y la compatibilidad con la carga de varios archivos.

## Uso

El componente <ApiLink type="FileInput" /> permite a los usuarios seleccionar archivos de su dispositivo y cargarlos en una aplicación web. Muestra los nombres de los archivos seleccionados y ofrece opciones de personalización para el botón de examinar y el texto "No file chosen". El componente también proporciona propiedades, métodos y slots que pueden usarse para configurar aún más su comportamiento según sus necesidades.

## Configuración

### Propiedades

El componente <ApiLink type="FileInput" /> ofrece una variedad de propiedades que le permiten configurar su comportamiento según requisitos específicos. Estas propiedades le dan control sobre la funcionalidad, el aspecto y la validación de la entrada.

- <ApiLink pkg="core" type="Input" member="value" label="Value" />: establece el valor actual del campo de entrada de archivo.
- <ApiLink pkg="core" type="Input" member="disabled" label="Disabled" />: deshabilita el file input e impide la interacción del usuario.
- <ApiLink pkg="core" type="Input" member="required" label="Required" />: marca la entrada como obligatoria. El envío del formulario se bloqueará a menos que se seleccione un archivo.
- <ApiLink pkg="core" type="Input" member="invalid" label="Invalid" />: indica que el valor de la entrada no es válido; se usa para activar los estados visuales de error.
- `Multiple`: permite seleccionar varios archivos.
- `Accept`: define los tipos de archivo que pueden seleccionarse. El valor de esta propiedad debe ser una lista de formatos de archivo separados por comas (por ejemplo, .jpg, .png, .gif).
- <ApiLink pkg="core" type="Input" member="autofocus" label="Autofocus" />: enfoca automáticamente el campo de entrada de archivo cuando se carga la página.
- <ApiLink pkg="core" type="Input" member="label" label="Label" />: establece el texto de la etiqueta asociada al elemento de entrada de archivo.
- <ApiLink pkg="core" type="Input" member="placeholder" label="Placeholder" />: proporciona el texto de marcador de posición que se muestra cuando no hay ningún archivo seleccionado.

<PlatformBlock for="WebComponents">

```html
<igc-file-input
  label="Files Input"
  accept=".jpg, .png, .gif"
  placeholder="Files missing"
  required
  multiple>
</igc-file-input>
```

</PlatformBlock>

### Métodos

Además de sus propiedades configurables, hay cuatro métodos útiles heredados del componente <ApiLink pkg="core" type="Input" /> que puede usar en el componente <ApiLink type="FileInput" />:

- `Focus`: establece el foco en el elemento de entrada de archivo.
- `Blur`: quita el foco del elemento de entrada de archivo.
- <ApiLink pkg="core" type="Input" member="reportValidity" label="ReportValidity" />: comprueba la validez de la entrada y muestra un mensaje de validación si la entrada no es válida.
- <ApiLink pkg="core" type="Input" member="setCustomValidity" label="SetCustomValidity" />: establece un mensaje de validación personalizado. Si el mensaje proporcionado no está vacío, la entrada se marcará como no válida.

### Slots

El componente <ApiLink type="FileInput" /> también expone varios slots que pueden usarse para personalizar su aspecto y su comportamiento.

- `prefix` y `suffix`: le permiten insertar contenido antes o después del área principal de entrada.
- `helper-text`: muestra una sugerencia o un mensaje instructivo debajo de la entrada. Es útil para ofrecer orientación adicional, como consejos de formato o requisitos del campo.
- `file-selector-text`: le permite personalizar el texto que se muestra en el botón de selección de archivos.
- `file-missing-text`: establece el texto que se muestra en el campo de entrada cuando no se ha seleccionado ningún archivo.
- `value-missing`: renderiza contenido personalizado cuando falla la validación del campo obligatorio (es decir, cuando se requiere un archivo pero no se ha proporcionado).
- `invalid`: le permite renderizar contenido personalizado cuando la entrada está en estado no válido.
- `custom-error`: muestra contenido cuando se establece un mensaje de validación personalizado mediante el método <ApiLink type="FileInput" member="setCustomValidity" label="setCustomValidity()" />.

Al colocar contenido en los slots, recomendamos usar un elemento `<span>` para texto simple, símbolos o emojis, y un componente [`<igc-icon>`](../layouts/icon.mdx) para iconos.

## Limitaciones

El componente <ApiLink type="FileInput" /> tiene actualmente las siguientes limitaciones:
- Las cadenas predeterminadas del botón "Browse" y del mensaje "No file chosen" no se localizan automáticamente. Estas cadenas son las mismas en todas las configuraciones regionales, pero pueden personalizarse manualmente mediante los slots adecuados o el enlace del marcador de posición.
- Los archivos no pueden establecerse manualmente mediante la propiedad `value`. La selección de archivos solo puede hacerse mediante el selector de archivos. Sin embargo, puede pasar una cadena vacía `''` para restablecer el campo.

## Compatibilidad con accesibilidad y ARIA

El componente <ApiLink type="FileInput" /> es enfocable e interactivo, lo que garantiza la accesibilidad completa con teclado y lector de pantalla. El componente puede etiquetarse mediante el atributo <ApiLink type="FileInput" member="label" label="Label" />, que aprovecha el elemento `<label>` nativo para proporcionar una etiqueta semánticamente correcta y accesible.

Para respaldar las buenas prácticas de accesibilidad, el componente también aplica los atributos ARIA pertinentes:

- `aria-invalid`: se establece en "true" cuando la entrada está en estado no válido.
- `aria-describedby`: se vincula automáticamente al elemento de texto de ayuda cuando está presente, lo que permite que las tecnologías de asistencia anuncien la información adicional.
