### Qué hacer y qué no

**Cuándo usarlo:** use Switch para un ajuste inmediato de activado/desactivado que surte efecto cuando el usuario lo cambia.

**Cuándo no usarlo:** use [Checkbox](./checkbox.mdx) cuando los usuarios seleccionen una o más opciones para un envío de formulario posterior, o [Button](./button.mdx) cuando el control represente una acción o un comando alternable.

## Estilos

El {Platform} Switch usa partes CSS y variables CSS para dar estilo a su pista, su pulgar y su etiqueta.

<PlatformBlock for="Angular">

### Temas con Sass

Para empezar a dar estilo al switch, importe el archivo `index`, donde se exportan todas las funciones de tema y el mixin `tokens()`:

```scss
@use "igniteui-angular/theming" as *;
```

A continuación, cree un tema nuevo que extienda <ApiLink kind="sass" module="themes" type="function-switch-theme" label="switch-theme" code={true} />. Proporcionar `$thumb-off-color` y `$thumb-on-color` basta para obtener un switch totalmente estilizado, porque el tema genera a partir de ellos los colores restantes:

```scss
$custom-switch-theme: switch-theme(
    $thumb-off-color: #7cadd5,
    $thumb-on-color: #ecaa53,
);
```

Por último, incluya el tema personalizado en su aplicación:

```scss
:host {
  @include tokens($custom-switch-theme);
}
```

### Temas con Sass

Use el sistema de temas de {ProductName} para dar estilo al Switch de forma coherente con el resto de su aplicación.

Importe las funciones de tema antes de crear un tema personalizado para el Switch:

```scss
@use "igniteui-theming" as *;
```

```scss

```

El mismo tema se aplica directamente a Web Components y al elemento `igc-switch` subyacente que renderizan los wrappers de React y Blazor.

## Accesibilidad

El {Platform} Switch expone un estado binario y admite un nombre accesible mediante su etiqueta o sus atributos ARIA.

### Interacción por teclado

| Clave | Acción |
| --- | --- |
| Tab / Shift+Tab | Mueve el foco hacia el switch o desde él. |
| Space | Alterna el switch enfocado. |

### Lectores de pantalla / ARIA

El Switch renderiza un control interactivo con un estado binario marcado. Proporcione contenido de etiqueta visible o un nombre accesible con `aria-label` o `aria-labelledby`, y mantenga la etiqueta específica del ajuste que controla el switch.

<PlatformBlock for="WebComponents, React, Blazor">

- El control expone a la tecnología de asistencia su estado marcado y su estado deshabilitado.
- El evento `igcChange` se emite cuando cambia el estado marcado.

</PlatformBlock>

## Solución de problemas

Use esta sección para revisar los límites y las decisiones habituales antes de tratar el Switch como un campo de formulario, un comando interactivo o un control de ajustes.

### ¿Por qué el Switch no se envía con mi formulario?

El Switch está asociado a formularios, pero necesita un `name` y un `value` para aportar un valor cuando se envía el formulario. Establezca ambas propiedades y use la integración con formularios que admita su plataforma de destino.

### ¿Por qué un lector de pantalla no anuncia bien el Switch?

El Switch necesita un nombre accesible. Añada contenido de etiqueta visible o haga referencia a una etiqueta externa con `aria-labelledby`; use `aria-label` cuando no haya texto visible disponible.

### Limitaciones conocidas

El {Platform} Switch tiene las siguientes limitaciones independientes de la plataforma:

- Un Switch representa un único ajuste binario; use un control diferente cuando los usuarios necesiten varias opciones o una selección diferida en un formulario.
- Un Switch no proporciona automáticamente un nombre accesible cuando no tiene etiqueta ni un atributo ARIA de nombrado.

## Preguntas frecuentes

<Faq>
  <FaqItem question="¿Cómo establezco el Switch en su estado inicial de activado o desactivado?">
    Establezca la propiedad <ApiLink pkg="core" type="Switch" member="checked" label="checked" /> en `true` para el estado activado, o en `false` para el estado desactivado. La propiedad usa un valor booleano en la sintaxis de React, Web Components y Blazor.
  </FaqItem>
  <FaqItem question="¿Cómo coloco la etiqueta del Switch?">
    Coloque el texto de la etiqueta dentro del Switch y establezca la propiedad <ApiLink pkg="core" type="Switch" member="labelPosition" label="labelPosition" /> en `before` o en `after`. La posición predeterminada de la etiqueta es `after`.
  </FaqItem>
  <FaqItem question="¿Cómo envío el valor de un Switch con un formulario?">
    Establezca las propiedades <ApiLink pkg="core" type="Switch" member="name" label="name" /> y <ApiLink pkg="core" type="Switch" member="value" label="value" />. En Blazor, use el componente `EditForm` en lugar de un `form` HTML estándar.
  </FaqItem>
  <FaqItem question="¿Cómo hago que un Switch sea obligatorio o no válido?">
    Establezca la propiedad <ApiLink pkg="core" type="Switch" member="required" label="required" /> cuando el ajuste deba estar seleccionado, y <ApiLink pkg="core" type="Switch" member="invalid" label="invalid" /> cuando el control esté en estado no válido. Use <ApiLink pkg="core" type="Switch" member="disabled" label="disabled" /> cuando los usuarios no deban poder cambiar el ajuste.
  </FaqItem>
</Faq>
