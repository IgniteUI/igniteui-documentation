## Dependencias

Registre los servicios de {ProductName}:

```csharp
// in Program.cs file

builder.Services.AddIgniteUIBlazor();
```

Registrar <ApiLink pkg="core" type="InputModule" />, el módulo de recursos de cliente del componente Input, es **opcional**: el componente carga sus recursos cuando se renderiza por primera vez. Incluirlo en `builder.Services.AddIgniteUIBlazor(typeof(IgbInputModule))` puede usarse para precargar recursos o para admitir elementos creados solo en el cliente (véase [Component Modules](../general-getting-started.mdx#módulos-de-componentes)).

</PlatformBlock>

## Prefijo y sufijo

Con los slots `prefix` y `suffix` podemos añadir contenido distinto antes y después del contenido principal del <ApiLink pkg="core" type="Input" />. Recomendamos usar un elemento `<span>` cuando se añada texto simple, símbolos o emojis, y un componente [`<igc-icon>`](../layouts/icon.mdx) cuando se añadan iconos a los slots `prefix` y `suffix`. ## Tamaño del Input

Podemos permitir que el usuario cambie el tamaño del <ApiLink pkg="core" type="Input" /> usando la variable CSS `--ig-size`. Para ello, añadiremos algunos botones de radio que muestren todos los valores de tamaño. Así, cada vez que se seleccione uno, cambiaremos el tamaño del Input:

<Sample src="/inputs/input/size" height={320} alt="Ejemplo de tamaño de {Platform} Input" />

En el ejemplo anterior hemos demostrado el uso de los siguientes atributos:
- `required`: se usa para marcar la entrada como obligatoria
- `disabled`: se usa para deshabilitar la entrada
- `readonly`: se usa para marcar la entrada como de solo lectura

## Estilos

El componente <ApiLink pkg="core" type="Input" /> expone partes CSS para casi todos sus elementos internos. La tabla siguiente enumera todas las partes CSS expuestas:

|Nombre|Descripción|
|--|--|
| `container` | El wrapper principal que contiene todos los elementos de entrada principales. |
| `input` | El elemento input nativo. |
| `label` | El elemento label nativo. |
| `prefix` | El wrapper del prefijo. |
| `suffix` | El wrapper del sufijo. |
| `helper-text` | El wrapper del texto de ayuda. |

```scss
igc-input::part(input) {
  background-color: var(--ig-primary-100);
  border-color: var(--ig-secondary-500);
  box-shadow: none;
}

igc-input::part(label) {
  color: var(--ig-gray-700);
}

igc-input::part(prefix),
igc-input::part(suffix) {
  color: var(--ig-primary-600-contrast);
  background-color: var(--ig-primary-600);
  border-color: var(--ig-secondary-600);
}
```
