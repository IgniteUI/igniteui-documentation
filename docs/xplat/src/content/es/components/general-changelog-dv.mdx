# Registro de cambios de {ProductName}

Todos los cambios destacados de cada versión de {ProductName} se documentan en esta página.

<DocsAside type="info">

## **{PackageVerLatest}**

### General

- **Compatibilidad con Angular 22**: todos los componentes de Ignite UI for Angular son ahora totalmente compatibles con Angular 22.

- **Compatibilidad con componentes independientes**: los componentes pueden usarse ahora directamente en aplicaciones Angular independientes sin `NgModule`. Las nuevas funciones `provide*()` (p. ej., `provideIgxCategoryChart()`) permiten registrar conjuntos de características de componentes mediante proveedores `bootstrapApplication()`, y hay funciones imperativas `register*()` disponibles para configuraciones sin DI.

- **Puntos de entrada por componente para mejorar el tree-shaking**: cada paquete expone ahora puntos de entrada con subruta con nombre (p. ej., `import 'igniteui-angular-charts/category-chart'`) que registran solo el conjunto de características que necesita. La importación del paquete raíz sigue sin efectos secundarios y es apta para tree-shaking, de modo que solo paga por los componentes que usa. Para DataChart, puntos de entrada graduales como `data-chart-category`, `data-chart-scatter` y `data-chart-financial` permiten incorporar familias de series individuales sin empaquetar todo el gráfico.

#### Anotaciones de usuario de <Badge variant="preview" />

### {PackageCharts} (gráficos)

- [Agrupación en la leyenda de datos](./charts/features/chart-data-legend.mdx#agrupación-de-la-leyenda-de-datos-de-{PlatformLower}) y [agrupación en la información emergente de datos](./charts/features/chart-data-tooltip.mdx#agrupación-de-la-información-emergente-de-datos-de-{PlatformLower}-para-data-chart): nueva característica de agrupación. La propiedad <ApiLink type="DataLegend" member="groupRowVisible" label="GroupRowVisible" /> activa o desactiva la agrupación, y cada serie que se incorpora puede asignar un texto de grupo mediante la propiedad <ApiLink type="CrosshairLayer" member="dataLegendGroup" label="DataLegendGroup" />. Si se aplica el mismo valor a más de una serie, aparecerán agrupadas. Es útil para conjuntos de datos grandes que deben clasificarse y organizarse para todos los usuarios.

- [Selección de gráficos](./charts/features/chart-data-selection.mdx): nuevo estilo de selección de series. Se adopta de forma amplia en todas las series de categorías, financieras y radiales para <ApiLink type="CategoryChart" /> y <ApiLink type="DataChart" />. Las series pueden pulsarse y mostrar un color distinto, aclararse u oscurecerse, y mostrar contornos de foco. Puede gestionar qué elementos se ven afectados, mediante series individuales o elementos de datos completos. Se admiten varias series y marcadores. Es útil para ilustrar diferencias o similitudes entre los valores de un elemento de datos concreto. Además, están disponibles el evento `SelectedSeriesItemsChanged` y <ApiLink type="SeriesViewer" member="selectedSeriesItems" label="SelectedSeriesItems" /> para ayudar a definir requisitos de negocio sólidos en torno a otras acciones que pueden producirse en una aplicación, como una ventana emergente u otra pantalla con análisis de datos basado en la selección.

Las instrucciones de importación se han simplificado para usar solo los nombres de paquete en lugar de las rutas completas a las clases y enumeraciones de la API.
