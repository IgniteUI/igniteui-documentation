# Descripción general de {Platform} Date Range Picker

El {ProductName} Date Range Picker es un componente ligero que incluye una entrada de texto y un calendario emergente, lo que permite a los usuarios seleccionar fácilmente las fechas de inicio y de fin. Es muy personalizable para adaptarse a los distintos requisitos de las aplicaciones, y ofrece funciones como restricciones de intervalos de fechas, formatos de fecha configurables y más.

## Uso

<ApiLink pkg="core" type="DateRangePicker" /> permite a los usuarios seleccionar una fecha de inicio y una de fin, bien eligiendo un intervalo en un desplegable o un calendario emergente, bien escribiendo directamente en los campos de entrada (uno para la fecha de inicio y otro para la de fin). El picker ofrece dos modos para mostrar los valores de fecha: entrada única y dos entradas. Ambos ofrecen capacidades de edición y de máscara.

Cuando el calendario está visible, puede seleccionarse un intervalo de fechas eligiendo una fecha de inicio y una de fin. Al seleccionar una fecha se establecen la de inicio y la de fin, y una vez elegida una segunda fecha, se establece la de fin. Si ya hay un intervalo seleccionado, al hacer clic en cualquier otra fecha del calendario se iniciará una nueva selección de intervalo.

### Valor

Además de ser seleccionado o escrito por el usuario, el valor de intervalo de <ApiLink pkg="core" type="DateRangePicker" /> también puede establecerse mediante la propiedad <ApiLink pkg="core" type="DateRangePicker" member="value" />. Es importante tener en cuenta que el valor debe seguir el formato **`{ start: startDate, end: endDate }`**, donde `startDate` y `endDate` son objetos `Date` que representan el intervalo seleccionado.

<PlatformBlock for="WebComponents">

```ts
let dateRange = document.querySelector('igc-date-range-picker') as IgcDateRangePickerComponent;
let startDate = new Date(2025, 4, 6);
let endDate = new Date(2025, 4, 8);
dateRange.value = { start: startDate, end: endDate }
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const dateRangeRef = useRef<IgrDateRangePicker>();
let startDate = new Date(2025, 4, 6);
let endDate = new Date(2025, 4, 8);
useEffect (() => {
  dateRangeRef.current.value = { start: startDate, end: endDate }
}, [])

return (
  <IgrDateRangePicker ref={dateRangeRef} />
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
 <IgbDateRangePicker Value="@Range" Label="Date Range"/>

 @code {
    public IgbDateRangeValue Range = new IgbDateRangeValue()
    {
        Start = DateTime.Today,
        End = DateTime.Today.AddDays(3)
    };
}
```

</PlatformBlock>

<PlatformBlock for="WebComponents, React">

```html
<igc-date-range-picker/>
```

</PlatformBlock>

</PlatformBlock>

</PlatformBlock>

### Navegación por teclado

<ApiLink pkg="core" type="DateRangePicker" /> ofrece una navegación por teclado intuitiva, que permite a los usuarios incrementar, decrementar o saltar entre las distintas partes del componente, sin necesidad de usar el ratón.

|Teclas|Descripción|
|----|-----------|
| <kbd>←</kbd> | Mueve el cursor un carácter a la izquierda |
| <kbd>→</kbd> | Mueve el cursor un carácter a la derecha |
| <kbd>CTRL</kbd> + <kbd>ArrowLeft</kbd> | Mueve el cursor al inicio de la sección actual de la máscara de entrada o al inicio de la anterior si ya está al principio |
| <kbd>CTRL</kbd> + <kbd>ArrowRight</kbd> | Mueve el cursor al final de la sección actual de la máscara de entrada o al final de la siguiente si ya está al final |
| <kbd>ArrowUp</kbd> | Incrementa en un paso la parte de la máscara de entrada que tiene el foco |
| <kbd>ArrowDown</kbd> | Decrementa en un paso la parte de la máscara de entrada que tiene el foco |
| <kbd>HOME</kbd> | Mueve el cursor al inicio de la máscara de entrada |
| <kbd>END</kbd> | Mueve el cursor al final de la máscara de entrada |
| <kbd>CTRL</kbd> + <kbd>;</kbd> | Establece la fecha actual como valor del componente |
| <kbd>ALT</kbd> + <kbd>↓</kbd> | Abre la lista desplegable del calendario |
| <kbd>ALT</kbd> + <kbd>↑</kbd> | Cierra la lista desplegable del calendario |

También puede navegar dentro de la ventana emergente del calendario con el teclado. La navegación es la misma que en el componente <ApiLink pkg="core" type="Calendar" />.

|Teclas|Descripción|
|----|-----------|
| <kbd>↑</kbd> / <kbd>↓</kbd> / <kbd>←</kbd> / <kbd>→</kbd>| Recorre los días del mes |
| <kbd>ENTER</kbd> | Selecciona el día enfocado |
| <kbd>PAGE UP</kbd> | Pasa a la vista del mes anterior |
| <kbd>PAGE DOWN</kbd> | Pasa a la vista del mes siguiente |
| <kbd>SHIFT</kbd> + <kbd>PAGE UP</kbd> | Pasa al año anterior |
| <kbd>SHIFT</kbd> + <kbd>PAGE DOWN</kbd> | Pasa al año siguiente |
| <kbd>HOME</kbd> | Enfoca el primer día del mes actual que está visible (o el mes más antiguo cuando se muestran varias vistas mensuales) |
| <kbd>END</kbd> | Enfoca el último día del mes actual que está visible (o el mes más reciente cuando se muestran varias vistas mensuales). |
| <kbd>Escape</kbd> | Cierra la ventana emergente del calendario |

### Intervalos de fechas personalizados y predefinidos

También puede añadir chips de intervalos de fechas personalizados a la ventana emergente del calendario para seleccionar intervalos más rápido, usando la propiedad <ApiLink pkg="core" type="DateRangePicker" member="customRanges" />. Por ejemplo, puede crear un chip de intervalo personalizado para seleccionar rápidamente el intervalo de los próximos 7 días, que termine en la fecha actual. Además, al establecer la propiedad <ApiLink pkg="core" type="DateRangePicker" member="usePredefinedRanges" />, se mostrará un conjunto de chips de intervalos predefinidos junto con los personalizados.

<PlatformBlock for="WebComponents">

```ts
const today = new Date();

const nextSeven = new Date(
  today.getFullYear(),
  today.getMonth(),
  today.getDate() + 7
);
const nextWeek: CustomDateRange[] = [
  {
    label: 'Next 7 days',
    dateRange: {
      start: today,
      end: nextSeven
    }
  }
]

const dateRange = document.querySelector('igc-date-range-picker') as IgcDateRangePickerComponent;
dateRange.customRanges = nextWeek;
dateRange.usePredefinedRanges = true;
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx

  today.getFullYear(),
  today.getMonth(),
  today.getDate() + 7
);

  {

    dateRange: {
      start: today,
      end: nextSeven
    }
  }
];

  <IgrDateRangePicker usePredefinedRanges customRanges={nextWeek} />
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor

@code {
```

</PlatformBlock>

Ahora, cuando haga clic en el chip **"Next 7 days"** recién creado en la ventana emergente del calendario, el intervalo se seleccionará automáticamente, desde hoy hasta los 7 días siguientes.

### Fechas deshabilitadas y especiales

También puede establecer fechas desactivadas en el calendario para reducir el intervalo de fechas entre las que puede elegir el usuario. Para establecer las fechas desactivadas, puede usar la propiedad <ApiLink pkg="core" type="DateRangePicker" member="disabledDates" />.

<PlatformBlock for="WebComponents">

```ts
let dateRange = document.querySelector('igc-date-range-picker') as IgcDateRangePickerComponent;

const minDate = new Date(2025, 4, 1);
const maxDate = new Date(2025, 4, 31);

dateRange.disabledDates = [
  {
    type: DateRangeType.Between,
    dateRange: [minDate, maxDate]
  }
] as DateRangeDescriptor[];
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const dateRangeRef = useRef<IgrDateRangePicker>();
const minDate = new Date(2025, 4, 5);
const maxDate = new Date(2025, 4, 15);
useEffect (() => {
  dateRangeRef.current.disabledDates = [
    {
      type: DateRangeType.Between,
      dateRange: [minDate, maxDate]
    }
  ] as DateRangeDescriptor[];
}, [])

return (
  <IgrDateRangePicker ref={dateRangeRef} />
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDateRangePicker DisabledDates="@DisabledDates" />

@code {
    public IgbDateRangeDescriptor[] DisabledDates = [
        new IgbDateRangeDescriptor
    {
        RangeType = DateRangeType.Between,
        DateRange = new DateTime[] { new DateTime(DateTime.Today.Year, DateTime.Today.Month, 5), new DateTime(DateTime.Today.Year, DateTime.Today.Month, 8) },
    }];
}
```

</PlatformBlock>

Puede consultar más información sobre todas las posibilidades que ofrece la propiedad <ApiLink pkg="core" type="DateRangePicker" member="disabledDates" /> aquí: [Fechas deshabilitadas](./calendar.mdx#fechas-deshabilitadas)

También puede hacer lo mismo si quiere establecer una o más fechas especiales en el calendario; la única diferencia es que, en su lugar, debe usar la propiedad <ApiLink pkg="core" type="DateRangePicker" member="specialDates" />. [Fechas especiales](./calendar.mdx#fechas-especiales)

### Slots

También puede añadir contenido personalizado y modificar el aspecto del componente <ApiLink pkg="core" type="DateRangePicker" /> usando los slots disponibles.

Los slots `prefix` y `suffix` le permiten insertar contenido personalizado antes o después del campo de entrada (solo disponible en modo de entrada única):

<PlatformBlock for="WebComponents">

```html
<igc-date-range-picker>
  <igc-icon slot="prefix" name="down_arrow_icon"></igc-icon>
  <igc-icon slot="suffix" name="upload_icon"></igc-icon>
</igc-date-range-picker>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrDateRangePicker>
  <IgrIcon slot='prefix' name='down_arrow_icon'></IgrIcon>
  <IgrIcon slot='suffix' name='upload_icon'></IgrIcon>
</IgrDateRangePicker>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDateRangePicker>
    <IgbIcon @ref="DropDownIcon" slot="prefix" IconName="dropdown" Collection="material"></IgbIcon>
    <IgbIcon @ref="UploadIcon" slot="suffix" IconName="upload" Collection="material"></IgbIcon>
</IgbDateRangePicker>
```

</PlatformBlock>

En modo de dos entradas, puede usar en su lugar los slots `prefix-start`, `prefix-end`, `suffix-start` y `suffix-end` para dirigirse a cada entrada. Para todos los slots de tipo `prefix-` y `suffix-`, recomendamos usar un elemento `<span>` para texto sencillo, símbolos o emojis, y un componente [`<igc-icon>`](../layouts/icon.mdx) para iconos.

Otro conjunto de slots útiles son `clear-icon` y `calendar-icon`, que le permiten personalizar los iconos de los botones de borrado y de calendario de los campos de entrada. Para estos slots también recomendamos usar un elemento `<span>` para símbolos o emojis, y un componente [`<igc-icon>`](../layouts/icon.mdx) para iconos.

<PlatformBlock for="WebComponents">

```html
<igc-date-range-picker>
  <igc-icon slot="clear-icon" name="apps_icon"></igc-icon>
  <igc-icon slot="calendar-icon" name="bin_icon"></igc-icon>
</igc-date-range-picker>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrDateRangePicker>
  <IgrIcon slot="clear-icon" name="apps_icon"></IgrIcon>
  <IgrIcon slot="calendar-icon" name="bin_icon"></IgrIcon>
</IgrDateRangePicker>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDateRangePicker>
    <IgbIcon slot="clear-icon" @ref="ClearIcon" IconName="bin" Collection="material"></IgbIcon>
    <IgbIcon slot="calendar-icon" @ref="CalendarIcon" IconName="apps" Collection="material"></IgbIcon>
</IgbDateRangePicker>
```

</PlatformBlock>

En modo de dos entradas, también puede personalizar el texto "to" predeterminado entre los campos usando el slot `separator`. Para obtener el mejor resultado, recomendamos usar un elemento `<span>` para este slot.

<PlatformBlock for="WebComponents">

```html
  <span slot="separator">till</span>
</igc-date-range-picker>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
<IgrDateRangePicker useTwoInputs>
  <span slot='separator'>till</span>
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
  <span slot="separator">till</span>

```

</PlatformBlock>

El slot `actions` le permite insertar un botón de acción personalizado con su propia lógica. Por ejemplo, el botón siguiente activa o desactiva la columna de números de semana del calendario. Recomendamos usar el componente [`<igc-button>`](../inputs/button.mdx) al añadir contenido al slot `actions`.

<PlatformBlock for="WebComponents">

```html
<igc-date-range-picker id="DateRange">
  <igc-button slot="actions" onclick="DateRange.showWeekNumbers = true">Toggle Week Numbers</igc-button>
</igc-date-range-picker>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
const dateRangeRef = useRef<IgrDateRangePicker>();
const toggleWeekNumbers = () => {
  dateRangeRef.current.showWeekNumbers = !dateRangeRef.current.showWeekNumbers;
};

return (
  <IgrDateRangePicker ref={dateRangeRef}>
    <IgrButton slot="actions" onClick={toggleWeekNumbers}>Toggle Week Numbers</IgrButton>
  </IgrDateRangePicker>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbDateRangePicker Mode="PickerMode.Dialog" ShowWeekNumbers="@ShowWeekNumbers">
    <IgbButton slot="actions" @onclick="() => ShowWeekNumbers = !ShowWeekNumbers">Toggle week numbers</IgbButton>
</IgbDateRangePicker>

@code {
    private bool ShowWeekNumbers;
}
```

</PlatformBlock>

Además de los slots que ya hemos visto, los siguientes slots también están disponibles en el componente <ApiLink pkg="core" type="DateRangePicker" />:

|Nombre|Descripción|
|--|--|
| `title` | Renderiza contenido para el título del calendario. Solo aplicable en modo de diálogo. |
| `helper-text` | Renderiza contenido debajo del campo de entrada. |
| `header-date` | Sustituye el texto predeterminado de la fecha o el intervalo actual en el encabezado del calendario. Solo aplicable en modo de diálogo. |
| `clear-icon-start` | Icono de borrado personalizado para la entrada de inicio (modo de dos entradas). |
| `clear-icon-end` | Icono de borrado personalizado para la entrada de fin (modo de dos entradas). |
| `calendar-icon-start` | Icono de calendario personalizado para la entrada de inicio (modo de dos entradas). |
| `calendar-icon-end` | Icono de calendario personalizado para la entrada de fin (modo de dos entradas). |
| `calendar-icon-open` | Icono o contenido que se muestra cuando el selector está abierto (se aplica a ambas entradas en el modo de dos entradas). |
| `calendar-icon-open-start` | Icono o contenido para el estado abierto de la entrada de inicio (modo de dos entradas).|
| `calendar-icon-open-end` | Icono o contenido para el estado abierto de la entrada de fin (modo de dos entradas). |

Para los slots `title`, `helper-text` y `header-date`, recomendamos usar un elemento `<span>`. Un `<span>` proporciona un contenedor neutro que hereda limpiamente los estilos del componente, sin propiedades de estilo integradas que puedan interferir con la tipografía y el diseño previstos del componente.

Y para los slots de tipo `clear-icon-` y `calendar-icon-`, recomendamos usar un elemento `<span>` para símbolos o emojis, y un componente [`<igc-icon>`](../layouts/icon.mdx) para iconos.

## Estilos

Como el componente <ApiLink pkg="core" type="DateRangePicker" /> usa el componente <ApiLink pkg="core" type="Calendar" />, también hereda las partes CSS del Calendar, lo que le permite dar estilo a ambos componentes de forma coherente. Puede consultar la lista completa de partes CSS del Calendar expuestas aquí: [Calendar Styling](./calendar.mdx#estilos). Además de las partes CSS del Calendar, <ApiLink pkg="core" type="DateRangePicker" /> también expone algunas partes CSS propias que puede usar para personalizar su aspecto:

|Nombre|Descripción|
|--|--|
| `separator` | El elemento separador entre las dos entradas. |
| `ranges` | El wrapper que renderiza los intervalos personalizados y predefinidos. |
| `label` | El wrapper de la etiqueta que renderiza el contenido encima de la entrada de destino. |
| `container` | El wrapper principal que contiene todos los elementos de entrada principales. |
| `input` | El elemento input nativo. |
| `prefix` | El wrapper del prefijo. |
| `suffix` | El wrapper del sufijo. |
| `calendar-icon` | El wrapper del icono de calendario para el estado cerrado. |
| `calendar-icon-start` | El wrapper del icono de calendario para el estado cerrado de la entrada de inicio (dos entradas). |
| `calendar-icon-end` | El wrapper del icono de calendario para el estado cerrado de la entrada de fin (dos entradas). |
| `calendar-icon-open` | El wrapper del icono de calendario para el estado abierto. |
| `calendar-icon-open-start` | El wrapper del icono de calendario para el estado abierto de la entrada de inicio (dos entradas). |
| `calendar-icon-open-end` | El wrapper del icono de calendario para el estado abierto de la entrada de fin (dos entradas). |
| `clear-icon` | El wrapper del icono de borrado (entrada única). |
| `clear-icon-start` | El wrapper del icono de borrado para la entrada de inicio (dos entradas). |
| `clear-icon-end` | El wrapper del icono de borrado para la entrada de fin (dos entradas). |
| `actions` | El wrapper de las acciones. |
| `helper-text` | El wrapper del texto de ayuda que renderiza el contenido debajo de la entrada de destino. |

```css
igc-date-range-picker::part(label) {
```
