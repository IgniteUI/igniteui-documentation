# Descripción general de {Platform} Calendar

El componente {ProductName} Calendar es ligero y fácil de configurar. Se usa para mostrar fechas y días de la semana. Es además la mejor forma de ofrecer a los usuarios finales vistas mensuales o anuales. El control {ProductName} Calendar le permite restringir el intervalo mínimo y máximo de fechas por el que pueden navegar los usuarios.

El Calendar de Ignite UI for {ProductName} ofrece una forma sencilla e intuitiva de mostrar información de fechas. Incluye distintas funciones, como modos de selección de una o varias fechas, resaltado y selección de intervalos de fechas, navegación por teclado, activación de números de semana, opciones de tamaño y espaciado, y mucho más.

### Vista y fecha activas

El componente {ProductName} Calendar le permite cambiar entre tres vistas distintas: días, meses y años. La propiedad <ApiLink pkg="core" type="Calendar" member="activeView" /> del componente refleja la vista actual. De forma predeterminada, el Calendar muestra la fecha actual al cargarse por primera vez. Puede modificarlo estableciendo la propiedad <ApiLink pkg="core" type="Calendar" member="activeDate" />. La propiedad <ApiLink pkg="core" type="Calendar" member="activeDate" /> también refleja los cambios de la fecha visible actualmente que realiza el usuario final.

### Localización y formato

Por su propia naturaleza, la localización y el formato son esenciales en cualquier calendario. En {ProductName} <ApiLink pkg="core" type="Calendar" /> se controlan y personalizan mediante las siguientes propiedades: <ApiLink pkg="core" type="Calendar" member="locale" />, <ApiLink type="IWorksheetCellFormat" member="formatOptions" />, <ApiLink type="FieldPipeArgs" member="weekStart" />.

Vamos a probarlas junto con otras personalizaciones. Lo primero que debemos establecer es <ApiLink type="FieldPipeArgs" member="weekStart" />, que controla el primer día de la semana. Su valor predeterminado es `Sunday`, así que lo estableceremos en `Monday`. También personalizaremos la propiedad <ApiLink type="IWorksheetCellFormat" member="formatOptions" />, que especifica las opciones usadas para dar formato a los meses y a los días de la semana en las vistas del calendario. Por último, estableceremos la propiedad <ApiLink pkg="core" type="Calendar" member="locale" /> con un valor, según la elección de ubicación del usuario:

```html

    <igc-radio name="locale" value="fr">FR</igc-radio>
    <igc-radio name="locale" value="ar">AR</igc-radio>
    <igc-radio name="locale" value="ja">JA</igc-radio>
</igc-radio-group>

<igc-calendar
    id="calendar1"
    week-start="monday"
>
```

### Fechas deshabilitadas

En algunos casos querrá tener en el Calendar fechas deshabilitadas que el usuario final no pueda seleccionar. Esta funcionalidad se consigue con la propiedad <ApiLink pkg="core" type="Calendar" member="disabledDates" />. La propiedad <ApiLink pkg="core" type="Calendar" member="disabledDates" /> es un array de objetos <ApiLink pkg="core" type="DateRangeDescriptor" />. Cada descriptor tiene un <ApiLink type="Type" /> y, opcionalmente, un <ApiLink type="SparklineGroup" member="dateRange" label="DateRange" />, que es un array de objetos `Date`.

Estas son las opciones disponibles para la propiedad <ApiLink type="Type" />:

- `After`: deshabilita las fechas posteriores a la primera fecha de <ApiLink type="SparklineGroup" member="dateRange" label="DateRange" />
- `Before`: deshabilita las fechas anteriores a la primera fecha de <ApiLink type="SparklineGroup" member="dateRange" label="DateRange" />
- `Between`: deshabilita las fechas comprendidas entre la primera y la segunda fecha de <ApiLink type="SparklineGroup" member="dateRange" label="DateRange" />
- `Specific`: deshabilita las fechas especificadas en el array <ApiLink type="SparklineGroup" member="dateRange" label="DateRange" />
- `Weekdays`: deshabilita todos los días laborables
- `Weekends`: deshabilita todos los fines de semana

Creemos un ejemplo que desactive las fechas comprendidas entre el día 3 y el día 8 del mes actual:

```ts
const today = new Date(Date.now());
const range = [
    new Date(today.getFullYear(), today.getMonth(), 3),
    new Date(today.getFullYear(), today.getMonth(), 8)
];

this.calendar.disabledDates = [{ type: DateRangeType.Between, dateRange: range }];
```

## Navegación por teclado

Si recorre la página con la tecla <kbd>TAB</kbd>, tenga en cuenta que, según las [recomendaciones de accesibilidad de W3](https://www.w3.org/TR/wai-aria-practices/#layoutGrid), el <ApiLink pkg="core" type="Calendar" /> introduce las siguientes paradas de tabulación:

- Botón de selección de mes
- Botón de selección de año
- Botón anterior
- Botón siguiente
- Elemento de fecha activo

Cuando un **día/mes/año** del componente <ApiLink pkg="core" type="Calendar" /> tiene el foco, use:

- La tecla <kbd>PAGE UP</kbd> para pasar a la página anterior de mes, año o años.
- La tecla <kbd>PAGE DOWN</kbd> para pasar a la página siguiente de mes, año o años.
- La tecla <kbd>HOME</kbd> para enfocar el primer día del mes actual, el primer mes visible o el primer año visible.
- La tecla <kbd>END</kbd> para enfocar el último día del mes actual, el último mes visible o el último año visible.
- Las teclas <kbd>Arrow</kbd> para navegar por los días, meses o años. Navegar más allá del primer o del último elemento cambiará la vista a la página siguiente o anterior de mes, año o años.

Cuando un **día** de la vista `days` tiene el foco, use:

- Las teclas <kbd>SHIFT</kbd> + <kbd>PAGE UP</kbd> para pasar al año anterior.
- Las teclas <kbd>SHIFT</kbd> + <kbd>PAGE DOWN</kbd> para pasar al año siguiente.
- La tecla <kbd>SPACE</kbd> o <kbd>ENTER</kbd> para seleccionar el día enfocado.

Cuando un **mes** de la vista `months` tiene el foco, use:

- La tecla <kbd>SPACE</kbd> o <kbd>ENTER</kbd> para cambiar <ApiLink pkg="core" type="Calendar" member="activeDate" /> al mes enfocado y pasar a la vista `days`.

Cuando un **año** de la vista `years` tiene el foco, use:

- La tecla <kbd>SPACE</kbd> o <kbd>ENTER</kbd> para cambiar <ApiLink pkg="core" type="Calendar" member="activeDate" /> al año enfocado y pasar a la vista `months`.

Cuando el botón **anterior** o el botón **siguiente** (en el subencabezado) tiene el foco, use:

- La tecla <kbd>SPACE</kbd> o <kbd>ENTER</kbd> para pasar a la página anterior/siguiente de mes, año o años.

Cuando el botón de **mes** (en el subencabezado) tiene el foco, use:

- La tecla <kbd>SPACE</kbd> o <kbd>ENTER</kbd> para pasar a la vista `months`.

Cuando el botón de **año** (en el subencabezado) tiene el foco, use:

- La tecla <kbd>SPACE</kbd> o <kbd>ENTER</kbd> para pasar a la vista `years`.

| `special` | El elemento de fecha especial. |
