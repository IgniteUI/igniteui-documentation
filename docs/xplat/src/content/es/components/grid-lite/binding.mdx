# Enlace de datos de {Platform} {GridLiteTitle}


<PlatformBlock for="React, WebComponents">


{GridLiteTitle} acepta un array de objetos simples como origen de datos. Cada fila de la cuadrícula es la representación renderizada de un registro de datos del array, y las celdas de la fila se controlan mediante la configuración de columnas.

</PlatformBlock>



<PlatformBlock for="Blazor">


{GridLiteTitle} acepta un `IEnumerable<TItem>`, como un `List<TItem>`, como origen de datos, donde `TItem` representa su modelo. Cada fila de la cuadrícula es la representación renderizada de un registro de datos de la colección, y las celdas de la fila se controlan mediante la configuración de columnas.

</PlatformBlock>


Al aplicar transformaciones de datos, como la ordenación y el filtrado, la cuadrícula no modifica la referencia de los datos originales. Es decir, las transformaciones de datos no se reflejarán en el origen original. La cuadrícula no hace un seguimiento de los cambios en los objetos del array de datos, por lo que la modificación directa de los objetos de datos no se reflejará.

## Cambiar el origen de datos en tiempo de ejecución

El componente admite cambiar su origen de datos en tiempo de ejecución. Si el nuevo origen tiene una "forma" distinta a la del anterior, asegúrese de actualizar también la configuración de columnas.


<PlatformBlock for="WebComponents">


```typescript
grid.data = [...{
  /** records follow */
}];
```

```html
<igc-grid-lite>
    <!-- Update column configuration, add or remove columns as needed to represent the new data. -->
    <igc-grid-lite-column field="id"></igc-grid-lite-column>
</igc-grid-lite>
```

</PlatformBlock>


<PlatformBlock for="React">

```tsx
/* First we set the initial data */
const [data, setData] = React.useState([/* initial data */]);

/* Then inside an event handler or a useEffect we update the data via setData */
const updateData = () => {
  setData([]);
};

return (
    <>
        <IgrButton onClick={updateData}>Update Data</IgrButton>
        <IgrGridLite data={data}>
            {/* Update column configuration, add or remove columns as needed to represent the new data. */}
            <IgrGridLiteColumn field="id"></IgrGridLiteColumn>
        </IgrGridLite>
    </>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">

```razor
<IgbGridLite Data="data">
    <!-- Update column configuration, add or remove columns as needed to represent the new data. -->
    <IgbGridLiteColumn Field="Id" />
</IgbGridLite>

@code {
    private List<Product> data = new();

    private void UpdateData()
    {
        // Assign a new collection
        data = new List<Product>
        {
            // records follow
        };
    }
}
```

</PlatformBlock>


<PlatformBlock for="React, WebComponents">


Si la cuadrícula tiene habilitado `autoGenerate`, "_inferirá_" automáticamente la nueva configuración de columnas cuando cambien los datos.

</PlatformBlock>



<PlatformBlock for="Blazor">


Si la cuadrícula tiene habilitado `AutoGenerate`, "_inferirá_" automáticamente la nueva configuración de columnas cuando cambien los datos.

</PlatformBlock>



<PlatformBlock for="WebComponents">


```typescript
grid.autoGenerate = true;

/** After the new binding the grid will infer the column collection from the bound data. */
grid.data = [];
```

</PlatformBlock>


<PlatformBlock for="React">


```tsx
const [data, setData] = React.useState([/* initial data */]);


/** After the new binding the grid will infer the column collection from the bound data. */
const updateData = () => {
  setData([/* new data */]);
};

return (
    <>
        <IgrButton onClick={updateData}>Update Data</IgrButton>
        <IgrGridLite id="grid-lite" data={data} autoGenerate={true} />
    </>
);
```

</PlatformBlock>



<PlatformBlock for="Blazor">


```razor
<IgbGridLite Data="data" AutoGenerate="true" />

@code {
    private List<Product> data = new();

    private void UpdateData()
    {
        // After the new binding the grid will infer the column collection from the bound data.
        data = new List<Product>();
    }
}
```

</PlatformBlock>
