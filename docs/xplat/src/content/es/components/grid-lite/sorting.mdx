# Operaciones de ordenación

<PlatformBlock for="React, WebComponents">


{GridLiteTitle} admite operaciones de ordenación sobre su origen de datos. La ordenación de datos se controla por columna, lo que permite tener columnas ordenables y no ordenables, mientras que la propia cuadrícula controla ciertos comportamientos de ordenación. De forma predeterminada, la ordenación de una columna está deshabilitada, a menos que se configure explícitamente con la propiedad `sortable` de la columna.

</PlatformBlock>

<PlatformBlock for="WebComponents">


Para una lógica de comparación personalizada, establezca la propiedad `sortConfiguration` con una función `comparer`:

```typescript
const column = document.querySelector('igc-grid-lite-column[field="name"]');
column.sortConfiguration = {
  /**
   * Custom comparer function which will be used for sort operations for this column.
   * In the following sample, we compare the `name` values based on their length.
   */
  comparer: (a, b) => a.length - b.length
};
```

</PlatformBlock>

## Ordenación simple y múltiple

<PlatformBlock for="React, WebComponents">


{GridLiteTitle} admite la ordenación por una sola columna y por varias columnas. La ordenación por varias columnas está habilitada de forma predeterminada y puede configurarse con la propiedad `sortingOptions` de la cuadrícula. La propiedad `mode` acepta `'single'` o `'multiple'` como valores.

</PlatformBlock>



<PlatformBlock for="Blazor">


{GridLiteTitle} admite la ordenación por una sola columna y por varias columnas. La ordenación por varias columnas está habilitada de forma predeterminada y puede configurarse con la propiedad <ApiLink type="SortingOptions" /> de la cuadrícula. La propiedad <ApiLink type="SortingOptions" member="mode" label="Mode" /> acepta <ApiLink type="GridLiteSortingMode" member="Single" label="GridLiteSortingMode.Single" /> o <ApiLink type="GridLiteSortingMode" member="Multiple" label="GridLiteSortingMode.Multiple" /> como valores.

</PlatformBlock>



<PlatformBlock for="WebComponents">


```typescript

```

</PlatformBlock>


<PlatformBlock for="React">


```tsx

// or directly in the JSX
```

</PlatformBlock>

<DocsAside type="info">
El comportamiento de ordenación por una o varias columnas controla cómo interactúan los usuarios finales con {GridLiteTitle}. La ordenación mediante la API con varias expresiones seguirá funcionando cuando la ordenación simple esté habilitada.
</DocsAside>

### Ordenación de tres estados
{GridLiteTitle} admite la ordenación de tres estados y siempre está habilitada. Los usuarios finales recorrerán los siguientes estados de dirección al hacer clic en los encabezados de columna ordenables:



<PlatformBlock for="React, WebComponents">


```
ascending -> descending -> none -> ascending
```

donde `none` es el estado inicial de los datos, es decir, sin ordenación aplicada por la cuadrícula.

</PlatformBlock>


<PlatformBlock for="Blazor">


```
Ascending -> Descending -> None -> Ascending
```

donde `None` es el estado inicial de los datos, es decir, sin ordenación aplicada por la cuadrícula.

</PlatformBlock>

Cuando la ordenación por varias columnas está habilitada, los encabezados de columna muestran un indicador de ordenación: un número que representa el orden en que se aplicaron las operaciones de ordenación.

## Modelo de ordenación


<PlatformBlock for="React, WebComponents">


El elemento básico de las operaciones de ordenación en {GridLiteTitle} es `SortingExpression<T>`, que tiene las siguientes propiedades:

</PlatformBlock>


<PlatformBlock for="Blazor">


El elemento básico de las operaciones de ordenación en {GridLiteTitle} es <ApiLink type="IgbGridLiteSortingExpression" />, que tiene las siguientes propiedades:

</PlatformBlock>



```typescript
type SortingExpression<T> = {
  /**
   * The `key` of the target column for the sort operation.
   */
  key: keyof T;
  /**
   * The sort direction for the operation.
   */
  direction: 'ascending' | 'descending' | 'none';
  /**
   * Should the operation be case sensitive. Applies to the default string type.
   * If not explicitly passed, it will use the value from the target column sort configuration if applicable.
   */
  caseSensitive?: boolean;
  /**
   * Specifies a custom comparer function for the operation.
   * Will use the value from the target column sort configuration if applicable.
   */
  comparer?: SortComparer<T, T[keyof T]>;
};
```

<PlatformBlock for="Blazor">

```csharp
public class IgbGridLiteSortingExpression
{
    /// <summary>
    /// The target column.
    /// </summary>
    public required string Key { get; set; }

    /// <summary>
    /// Sort direction for this operation.
    /// </summary>
    public GridLiteSortingDirection Direction { get; set; }

    /// <summary>
    /// Whether the sort operation should be case sensitive.
    /// If not provided, the value is resolved based on the column sort configuration.
    /// </summary>
    public bool? CaseSensitive { get; set; }
}
```

</PlatformBlock>

La cuadrícula consume estas expresiones para sus métodos y configuración de la API de ordenación, y las produce para los eventos y su estado de ordenación cuando
un usuario interactúa con el componente. Consulte más información a continuación.

## API de ordenación


<PlatformBlock for="React, WebComponents">


{GridLiteTitle} ofrece dos enfoques principales para aplicar operaciones de ordenación desde su API: mediante los métodos `sort()`/`clearSort()` o mediante la propiedad `sortingExpressions`.

El método `sort()` acepta una única expresión o un array de expresiones de ordenación, y después ordena los datos de la cuadrícula según esas expresiones.

</PlatformBlock>



<PlatformBlock for="Blazor">


{GridLiteTitle} ofrece dos enfoques principales para aplicar operaciones de ordenación desde su API: mediante los métodos `SortAsync()`/`ClearSortAsync()` o mediante la propiedad `SortingExpressions`.

El método `SortAsync()` acepta una única expresión o una colección de expresiones de ordenación, y después ordena los datos de la cuadrícula según esas expresiones.

</PlatformBlock>



<PlatformBlock for="WebComponents">


```typescript
// Single
grid.sort({ key: 'price', direction: 'descending' });

// Multiple
grid.sort([
  { key: 'price', direction: 'descending' },
  { key: 'name', direction: 'descending' },
]);
```

</PlatformBlock>


<PlatformBlock for="React">


```typescript
// Single
gridRef.current.sort({ key: 'price', direction: 'descending' });

// Multiple
gridRef.current.sort([
  { key: 'price', direction: 'descending' },
  { key: 'name', direction: 'descending' },
]);
```

</PlatformBlock>



<PlatformBlock for="Blazor">

```razor
// Single
await grid.SortAsync(new IgbGridLiteSortingExpression { Key = "Price", Direction = GridLiteSortingDirection.Descending });

// Multiple
await grid.SortAsync(new IgbGridLiteSortingExpression[]
{
    new IgbGridLiteSortingExpression { Key = "Price", Direction = GridLiteSortingDirection.Descending },
    new IgbGridLiteSortingExpression { Key = "Name", Direction = GridLiteSortingDirection.Descending }
});
```

</PlatformBlock>


<PlatformBlock for="React, WebComponents">


El método `clearSort()`, como indica su nombre, borra el estado de ordenación de una sola columna o de todo el componente de cuadrícula, según
los argumentos que se pasen.

</PlatformBlock>


<PlatformBlock for="Blazor">


El método `ClearSortAsync()`, como indica su nombre, borra el estado de ordenación de una sola columna o de todo el componente de cuadrícula, según
los argumentos que se pasen.

</PlatformBlock>



<PlatformBlock for="WebComponents">


```typescript
// Clear the sort state for the `price` column.
grid.clearSort('price');

// Clear the sort state of the grid.
grid.clearSort();
```

</PlatformBlock>


<PlatformBlock for="React">


```typescript
// Clear the sort state for the `price` column.
gridRef.current.clearSort('price');

// Clear the sort state of the grid.
gridRef.current.clearSort();
```

</PlatformBlock>


<PlatformBlock for="Blazor">

```razor
// Clear the sort state for the `Price` column.
await grid.ClearSortAsync("Price");

// Clear the sort state of the grid.
await grid.ClearSortAsync();
```

</PlatformBlock>

### Estado de ordenación inicial


<PlatformBlock for="React, WebComponents">


La propiedad `sortingExpressions` se comporta de forma muy parecida a la llamada al método `sort()`. Ofrece una forma declarativa de controlar el estado
de ordenación de la cuadrícula, pero la propiedad más útil es la posibilidad de establecer el estado inicial de ordenación cuando {GridLiteTitle} se renderiza por primera vez.

</PlatformBlock>



<PlatformBlock for="Blazor">


La propiedad `SortingExpressions` se comporta de forma muy parecida a la llamada al método `SortAsync()`. Ofrece una forma declarativa de controlar el estado
de ordenación de la cuadrícula, pero la propiedad más útil es la posibilidad de establecer el estado inicial de ordenación cuando {GridLiteTitle} se renderiza por primera vez.

</PlatformBlock>



<PlatformBlock for="WebComponents">


Por ejemplo, aquí tiene un ejemplo basado en Lit:

```typescript
{
  sortState: SortingExpression<Products>[] = [
    { key: 'price', direction: 'descending' },
    { key: 'name', direction: 'ascending', caseSensitive: true },
  ];

  render() {
    return html`<igc-grid-lite .sortingExpressions=${sortState}></igc-grid-lite>`
  }
}
```

</PlatformBlock>


<PlatformBlock for="React">


Este es un ejemplo:

```tsx
const sortState: SortingExpression<Products>[] = [
  { key: 'price', direction: 'descending' },
  { key: 'name', direction: 'ascending', caseSensitive: true },
];

return (
  <IgrGridLite sortingExpressions={sortState} />
);
```

</PlatformBlock>



<PlatformBlock for="Blazor">


Por ejemplo:

```razor
<IgbGridLite Data="@data" SortingExpressions="sortState" />

@code {
    private IgbGridLiteSortingExpression[] sortState = new[]
    {
        new IgbGridLiteSortingExpression { Key = "Price", Direction = GridLiteSortingDirection.Descending },
        new IgbGridLiteSortingExpression { Key = "Name", Direction = GridLiteSortingDirection.Ascending, CaseSensitive = true }
    };
}
```

</PlatformBlock>


<PlatformBlock for="React, WebComponents">

Puede usarse para obtener el estado de ordenación actual del componente y realizar un procesamiento adicional según otro estado de su aplicación.

</PlatformBlock>

<PlatformBlock for="Blazor">

El parámetro `SortingExpressions` establece el estado de ordenación; no sigue los cambios que hace el usuario a través de la interfaz. Para seguir el estado de ordenación, gestione el evento `Sorted`: su `Expression` es la expresión de ordenación de la columna que se ordenó.

</PlatformBlock>


<PlatformBlock for="WebComponents">


```typescript
const state = grid.sortingExpressions;
// Save the current sort state
saveUserSortState(state);
```

</PlatformBlock>


<PlatformBlock for="React">


```typescript
const state = gridRef.current.sortingExpressions;
// Save the current sort state
saveUserSortState(state);
```

</PlatformBlock>


<PlatformBlock for="Blazor">

```razor
<IgbGridLite Data="@data" Sorted="OnSorted" />

@code {
    private void OnSorted(IgbGridLiteSortedEventArgs args)
    {
        // Save the sort state of the column
        SaveUserSortState(args.Expression);
    }
}
```

</PlatformBlock>

## Eventos


<PlatformBlock for="React, WebComponents">


Cuando se realiza una operación de ordenación a través de la interfaz, el componente emite un evento personalizado `sorting`. La propiedad `detail` es la expresión de ordenación que aplicará {GridLiteTitle}. El evento es cancelable, y si se cancela, detendrá la operación de ordenación actual.

Después de que la cuadrícula aplique el nuevo estado de ordenación, se emite un evento `sorted`. Contiene la expresión que se usó en la última operación de ordenación y no es cancelable.

<PlatformBlock for="WebComponents">
```typescript
grid.addEventListener('sorting', (event: CustomEvent<SortingExpression<T>>) => { ... });
grid.addEventListener('sorted', (event: CustomEvent<SortingExpression<T>>) => { ... });
```
</PlatformBlock>
<PlatformBlock for="React">
```typescript
gridRef.current.addEventListener('sorting', (event: CustomEvent<SortingExpression<T>>) => { ... });
gridRef.current.addEventListener('sorted', (event: CustomEvent<SortingExpression<T>>) => { ... });
```
</PlatformBlock>


</PlatformBlock>



<PlatformBlock for="Blazor">


Cuando se realiza una operación de ordenación a través de la interfaz, el componente dispara el evento `Sorting` con la expresión de ordenación de la operación. Es una notificación: no puede cancelar ni cambiar la operación.

Después de que la cuadrícula aplique el nuevo estado de ordenación, se dispara un evento `Sorted`. Contiene la expresión que se usó en la última operación de ordenación.

```razor
<IgbGridLite Sorting="OnSorting" Sorted="OnSorted" />

@code {
    private void OnSorting(IgbGridLiteSortingEventArgs args)
    {
        // Handle sorting event
    }

    private void OnSorted(IgbGridLiteSortedEventArgs args)
    {
        // Handle sorted event
    }
}
```

</PlatformBlock>

## Operaciones de ordenación remota

Cuando la ordenación debe hacerse de forma remota, o quiere guardar el estado o los datos actuales en un servidor, {GridLiteTitle} expone un punto de enlace donde puede implementar y personalizar este comportamiento.

<PlatformBlock for="React, WebComponents">
Con la propiedad `dataPipelineConfiguration`, puede proporcionar un punto de enlace personalizado que se llamará cada vez que vaya a ejecutarse una operación de ordenación. Al callback se le pasa un objeto <ApiLink type="DataPipelineParams" />.

```typescript
export type DataPipelineParams<T extends object> = {
  /**
   * The current data state of the grid.
   */
  data: T[];
  /**
   * The grid component itself.
   */
  grid: IgcGridLite<T>;
  /**
   * The type of data operation being performed.
   */
  type: 'sort' | 'filter';
};
```

<PlatformBlock for="WebComponents">
```typescript
grid.dataPipelineConfiguration = { sort: (params: DataPipelineParams<T>) => T[] | Promise<T[]> };
```
</PlatformBlock>
<PlatformBlock for="React">
```typescript
gridRef.current.dataPipelineConfiguration = { sort: (params: DataPipelineParams<T>) => T[] | Promise<T[]> };
```
</PlatformBlock>
