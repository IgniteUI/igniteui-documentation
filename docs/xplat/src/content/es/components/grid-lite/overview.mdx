## Lo que obtiene con nuestra cuadrícula de datos {Platform} gratuita

Nuestro {Platform} Grid Lite gratuito y de código abierto incluye las siguientes funciones por columna: ordenación, filtrado, ocultación, redimensionamiento y una variedad de tipos de datos predefinidos. Su rendimiento es muy rápido gracias a la virtualización de filas. Además, el componente admite la navegación por teclado y la personalización de temas mediante el [Ignite UI Theming Framework](../themes/overview.mdx).

### Instalar IgniteUI.Blazor.GridLite

{GridLiteTitle} se distribuye en el paquete [IgniteUI.Blazor.GridLite](https://www.nuget.org/packages/IgniteUI.Blazor.GridLite), con licencia MIT, en NuGet.org. Su código fuente está en [GitHub]({GithubLinkLite}).

En Visual Studio, abra el administrador de paquetes NuGet seleccionando **Herramientas** → **Administrador de paquetes NuGet** → **Administrar paquetes NuGet para la solución**. Busque e instale el paquete NuGet **IgniteUI.Blazor.GridLite**.

O instálelo mediante la consola del administrador de paquetes:

```cmd
Install-Package IgniteUI.Blazor.GridLite
```

O mediante la CLI de .NET:

```cmd
dotnet add package IgniteUI.Blazor.GridLite
```

### Usar Grid Lite

1 - Añada el espacio de nombres **IgniteUI.Blazor.Controls** en el archivo **_Imports.razor**:

```razor
@using IgniteUI.Blazor.Controls
```

2 - Añada una hoja de estilos de tema a la página host: **Components/App.razor** en una Blazor Web App, o **wwwroot/index.html** en una aplicación Blazor WebAssembly independiente.

Si la aplicación también usa el paquete `IgniteUI.Blazor.Lite` o `IgniteUI.Blazor`, conserve la [hoja de estilos del tema](../themes/overview.mdx) de ese paquete; también da estilo a la cuadrícula. En caso contrario, enlace uno de los temas que incluye el paquete `IgniteUI.Blazor.GridLite`:

```razor
<head>
    <link href="_content/IgniteUI.Blazor.GridLite/themes/light/bootstrap.css" rel="stylesheet" />
</head>
```

Los temas son `themes/{light|dark}/{bootstrap|material|fluent|indigo}.css`; consulte [Estilos y temas](./theming.mdx).

La cuadrícula no necesita registro de servicio ni etiqueta script. En una Blazor Web App, renderícela en un modo de renderizado interactivo.

3 - Añada el componente Grid Lite a su página razor:

```razor
<IgbGridLite Data="data" AutoGenerate="true">
</IgbGridLite>

@code {
    private object[] data = new object[]
    {
        new { Name = "John", Age = 30, City = "New York" },
        new { Name = "Jane", Age = 25, City = "Los Angeles" },
        new { Name = "Bob", Age = 35, City = "Chicago" }
    };
}
```
