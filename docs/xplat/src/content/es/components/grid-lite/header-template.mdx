# Personalizar el encabezado de la columna

Al igual que las plantillas de celda, los encabezados de columna también pueden personalizarse para adaptarse mejor al caso de uso deseado. Puede pasar una etiqueta de texto mediante la propiedad `header`, o proporcionar una plantilla personalizada completa.

## Personalización mediante el texto del encabezado

<PlatformBlock for="React, WebComponents">
De forma predeterminada, la columna usa la propiedad `field` para el texto de la etiqueta. Para personalizar la etiqueta, establezca la propiedad `header` en un formato más legible para las personas.
</PlatformBlock>

<PlatformBlock for="WebComponents">

```html
<igc-grid-lite-column field="price" header="Price per item"></igc-grid-lite-column>
```

</PlatformBlock>

<PlatformBlock for="React">

```tsx
return (
  <IgrGridLite>
    <IgrGridLiteColumn field="price" header="Price per item"></IgrGridLiteColumn>
  </IgrGridLite>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">
De forma predeterminada, la columna usa la propiedad <ApiLink type="Column" member="field" label="Field" /> para el texto de la etiqueta. Para personalizar la etiqueta, establezca la propiedad <ApiLink type="Column" member="header" label="Header" /> en un formato más legible para las personas.


```razor
<IgbGridLiteColumn Field="Price" Header="Price per item" />
```


</PlatformBlock>

<DocsAside type="info">
Cuando se proporciona `headerTemplate`, `header` se ignora.
</DocsAside>

## Personalización mediante la plantilla del encabezado

Al igual que con la plantilla de celda, también puede pasar un renderizador de plantilla personalizado y crear su propio DOM dentro del encabezado de la columna.

<PlatformBlock for="WebComponents">


```typescript
import { html } from 'lit';


const column = document.querySelector('igc-grid-lite-column');
column.headerTemplate = () => html`<h3>⭐ Rating ⭐</h3>`;
```

</PlatformBlock>
<PlatformBlock for="React">


```tsx
const ratingHeaderTemplate = (ctx: IgrHeaderContext) => (
  <h3>{"⭐ Rating ⭐"}</h3>
);


return (
  <IgrGridLite>
    <IgrGridLiteColumn field="rating" headerTemplate={ratingHeaderTemplate}></IgrGridLiteColumn>
  </IgrGridLite>
);
```

</PlatformBlock>

<PlatformBlock for="Blazor">


```razor
<!-- Templates TBD in Blazor -->
<IgbGridLiteColumn Field="Rating"></IgbGridLiteColumn>
```

</PlatformBlock>
