# Estilos y temas

{GridLiteTitle} incluye cuatro temas distintos: Bootstrap, Material, Fluent e Indigo. La cuadrícula y sus componentes de interfaz tienen los temas integrados, pero el componente requiere una hoja de estilos global para que funcionen las paletas, la tipografía y otras configuraciones globales.

## Cargar un tema base

<PlatformBlock for="Blazor">

Si la aplicación también usa el paquete `IgniteUI.Blazor.Lite` o `IgniteUI.Blazor`, conserve la [hoja de estilos del tema](../themes/overview.mdx) de ese paquete. También da estilo a la cuadrícula, por lo que la aplicación no necesita las hojas de estilo siguientes.

Una aplicación que usa solo {GridLiteTitle} enlaza en la página host uno de los temas que incluye el paquete `IgniteUI.Blazor.GridLite`: **Components/App.razor** en una Blazor Web App, o **wwwroot/index.html** en una aplicación Blazor WebAssembly independiente.

```html
<link href="_content/IgniteUI.Blazor.GridLite/themes/light/bootstrap.css" rel="stylesheet" />
```

| Tema     | Variante | Ruta                                                       |
| --------- | ------- | ---------------------------------------------------------- |
| Bootstrap | Claro   | _content/IgniteUI.Blazor.GridLite/themes/light/bootstrap.css |
| Bootstrap | Oscuro    | _content/IgniteUI.Blazor.GridLite/themes/dark/bootstrap.css  |
| Material  | Claro   | _content/IgniteUI.Blazor.GridLite/themes/light/material.css  |
| Material  | Oscuro    | _content/IgniteUI.Blazor.GridLite/themes/dark/material.css   |
| Fluent    | Claro   | _content/IgniteUI.Blazor.GridLite/themes/light/fluent.css    |
| Fluent    | Oscuro    | _content/IgniteUI.Blazor.GridLite/themes/dark/fluent.css     |
| Indigo    | Claro   | _content/IgniteUI.Blazor.GridLite/themes/light/indigo.css    |
| Indigo    | Oscuro    | _content/IgniteUI.Blazor.GridLite/themes/dark/indigo.css     |

</PlatformBlock>

<PlatformBlock for="React, WebComponents">

Según el tipo de proyecto, la configuración y la configuración de compilación, el método para incluir uno de los archivos siguientes variará. Si usa un framework o una herramienta de compilación, consulte su documentación sobre cómo añadir estilos externos al bundle de salida.

Como regla general, siempre puede copiar la carpeta `themes` en su directorio de recursos (assets) y enlazar el tema desde allí en su index.html.

```html
<link rel="stylesheet" href="./assets/themes/light/bootstrap.css">
```

| Tema     | Variante | Ruta                                                           |
| --------- | ------- | -------------------------------------------------------------- |
| Bootstrap | Claro   | node_modules/igniteui-webcomponents/themes/light/bootstrap.css |
| Bootstrap | Oscuro    | node_modules/igniteui-webcomponents/themes/dark/bootstrap.css  |
| Material  | Claro   | node_modules/igniteui-webcomponents/themes/light/material.css  |
| Material  | Oscuro    | node_modules/igniteui-webcomponents/themes/dark/material.css   |
| Fluent    | Claro   | node_modules/igniteui-webcomponents/themes/light/fluent.css    |
| Fluent    | Oscuro    | node_modules/igniteui-webcomponents/themes/dark/fluent.css     |
| Indigo    | Claro   | node_modules/igniteui-webcomponents/themes/light/indigo.css    |
| Indigo    | Oscuro    | node_modules/igniteui-webcomponents/themes/dark/indigo.css     |

</PlatformBlock>

## Crear temas personalizados

Además de los temas predeterminados que incluye el paquete {GridLiteTitle}, puede personalizar aún más el aspecto de su cuadrícula de datos usando un conjunto alternativo de propiedades personalizadas CSS.

```css
.grid-sample {
  --header-background: #494949;
  --header-text-color: #f2c43c;
  --cell-active-border-color: #f2c43c;
  --row-hover-background: #707070;
  --row-hover-text-color: #f2c43c;
}
```
