# Utilidad de estilo de formas de {Platform}

Este tema de recursos ofrece la implementación de una utilidad que ayuda a dar estilo a los elementos de interfaz de `GeographicShapeSeries` en el componente {Platform} `GeographicMap`.

## Importaciones necesarias

```json-snippet source="/maps/geo-map/shape-styling" channel="handlersImports"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap"
        }
    },
    "onViewInit": [
        "MapShapeRandomStyling"
    ],
    "$onViewInit": "+doc:handlersImports"
}
```
