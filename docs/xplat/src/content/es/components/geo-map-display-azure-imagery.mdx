# Imágenes de Azure Maps en {Platform} <Badge variant="preview" />

El {Platform} `AzureMapsImagery` es un servicio de mapas de imágenes geográficas proporcionado por Microsoft®. Ofrece varios estilos de teselas de imágenes geográficas del mundo. Este servicio de imágenes geográficas es accesible directamente en el sitio web <a href="https://azure.microsoft.com/en-us/products/azure-maps" target="_blank">www.azure.microsoft.com</a>. El componente de mapa {ProductName} puede mostrar imágenes geográficas de Azure Maps en el contenido de fondo del mapa mediante la clase `AzureMapsImagery`.

## {Platform}: mostrar imágenes de Azure Maps: ejemplo de código
El siguiente fragmento de código muestra cómo mostrar teselas de imágenes geográficas de Azure Maps en {Platform} `GeographicMap` usando la clase `AzureMapsImagery`.

```json-snippet channel="auto" include="bindingFields"

{

    "$styleOptions": { "directAssignment": true },

        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",

            "wpf"
        ]
    },
    "$assignInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]

    "width": "100%",
    "zoomable": true,
    "backgroundContent": {
        "type": "AzureMapsImagery",
        "name": "azureImagery",
        "apiKey": "YOUR_AZURE_MAPS_API_KEY",

    }
}
```

## {Platform}: superponer imágenes de Azure Maps: información general

Al trabajar con `GeographicTileSeries`, puede combinar **superposiciones** (tráfico, meteorología, etiquetas) sobre un **estilo de mapa base**, por ejemplo, **Satellite**, **Road** o **DarkGrey**. Usar **TerraOverlay** con, por ejemplo, **Satellite** permite visualizar el terreno.

- **Estilos base**: Satellite, Road, Terra y DarkGrey proporcionan las teselas de fondo principales.
- **Estilos de superposición**: las imágenes de tráfico y meteorología (por ejemplo, `TrafficRelativeOverlay`, `WeatherRadarOverlay`) están diseñadas para superponerse sobre un estilo base, asignándolas a una serie de teselas.
- **Estilos híbridos**: variantes como `HybridRoadOverlay` y `HybridDarkGreyOverlay` ya combinan un estilo base con superposiciones (etiquetas, carreteras, etc.), por lo que no necesita gestionar varias capas manualmente.

Este diseño le permite crear mapas más ricos; por ejemplo:
- Mostrar **imágenes de satélite** con una **TrafficOverlay** para destacar las congestiones sobre imágenes reales.
- Usar **Terra** con **WeatherRadarOverlay** para visualizar el terreno con precipitaciones.
- Aplicar **DarkGrey** con **LabelsRoadOverlay** para una vista de alto contraste, adecuada para paneles.

## {Platform}: superponer imágenes de Azure Maps: ejemplo de código
El siguiente fragmento de código muestra cómo mostrar teselas de imágenes geográficas sobre una imagen de fondo, combinando, por ejemplo, el tráfico con un mapa gris oscuro para el {Platform} `GeographicMap` usando las clases `AzureMapsImagery` y `GeographicTileSeries`.

```json-snippet channel="auto" include="bindingFields"

{
    "type": "GeographicMap",
    "$styleOptions": { "directAssignment": true },
    "name": "azureMap",
    "$setInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "$assignInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "backgroundContent": {
        "type": "AzureMapsImagery",
        "name": "azureImagery",
        "apiKey": "YOUR_AZURE_MAPS_API_KEY",
        "imageryStyle": "DarkGrey"
    },
    "series": [
        {
            "type": "GeographicTileSeries",
            "name": "imagerySeries",
            "$setInCode": {
                "tileImagery": [
                    "angular",
                    "react",
                    "webComponents",
                    "blazor",
                    "winUI",
                    "wpf"
                ]
            },
            "$assignInCode": {
                "tileImagery": [
                    "angular",
                    "react",
                    "webComponents",
                    "blazor",
                    "winUI",
                    "wpf"
                ]
            },
            "tileImagery": {
                "type": "AzureMapsImagery",
                "name": "trafficImagery",
                "apiKey": "YOUR_AZURE_MAPS_API_KEY",
                "imageryStyle": "TrafficAbsoluteOverlay"
            }
        }
    ]
}

```

## Propiedades
La tabla siguiente resume las propiedades de la clase `AzureMapsImagery`:

| Nombre de la propiedad  | Tipo de propiedad   | Descripción   |
|----------------|-----------------|---------------|
|`apiKey`|string|Representa la propiedad para establecer una clave de API necesaria para el servicio de imágenes de Azure Maps. Debe obtener esta clave en el sitio web <a href="https://azure.microsoft.com/en-us/products/azure-maps" target="_blank">azure.microsoft.com</a>.|
|`imageryStyle`|`AzureMapsImageryStyle`|Representa la propiedad para establecer el estilo de mapa de las teselas de imágenes de Azure Maps. Esta propiedad puede establecerse con los siguientes valores de la enumeración `AzureMapsImageryStyle`:<ul><li>Satellite: especifica el estilo de mapa satélite sin superposición de carreteras o etiquetas</li><li>Road: especifica el estilo de mapa aéreo con superposición de carreteras y etiquetas</li><li>DarkGrey: especifica un estilo de mapa base gris oscuro para el contraste y las superposiciones destacadas</li><li>TerraOverlay: especifica un estilo de mapa de terreno con relieve sombreado para destacar la elevación y los rasgos del paisaje</li><li>LabelsRoadOverlay: una de varias superposiciones de etiquetas de ciudades sin superposición aérea</li><li>HybridRoadOverlay: fondo satélite combinado con superposiciones de carreteras y etiquetas</li><li>HybridDarkGreyOverlay: fondo satélite combinado con superposiciones de etiquetas en gris oscuro</li><li>LabelsDarkGreyOverlay: una de varias superposiciones de etiquetas de ciudades sobre un mapa base gris oscuro</li><li>TrafficDelayOverlay: muestra los retrasos del tráfico y las zonas de congestión en tiempo real</li><li>TrafficAbsoluteOverlay: muestra las velocidades actuales del tráfico como valores absolutos</li><li>TrafficReducedOverlay: muestra el flujo de tráfico reducido con una visualización basada en luces</li><li>TrafficRelativeOverlay: muestra las velocidades del tráfico en relación con las condiciones normales</li><li>TrafficRelativeDarkOverlay: muestra las velocidades del tráfico en relación con las condiciones normales sobre un mapa base oscuro para un mayor contraste</li><li>WeatherRadarOverlay: muestra imágenes de radar de precipitaciones casi en tiempo real</li><li>WeatherInfraredOverlay: muestra imágenes de satélite infrarrojo de la cobertura de nubes</li></ul> |
