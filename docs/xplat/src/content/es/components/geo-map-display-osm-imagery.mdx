# {Platform}: mostrar imágenes de Open Street Maps

El {Platform} `OpenStreetMapImagery` es un servicio gratuito de mapas de imágenes geográficas creado de forma colaborativa por colaboradores de OpenStreetMap© de todo el mundo. Ofrece teselas de imagen geográfica del mundo solo en estilo de mapa de carreteras, sin opciones de configuración. Este servicio de imágenes geográficas puede consultarse directamente en el sitio web <a href="http://www.openstreetmap.org" target="_blank">www.OpenStreetMap.org</a>.
De forma predeterminada, el componente de mapa {ProductName} ya muestra imágenes geográficas de Open Street Maps. Por tanto, no es necesario configurar el control para mostrar imágenes geográficas de Open Street Maps.

## Fragmento de código
Este ejemplo de código establece explícitamente `backgroundContent` del componente de mapa en el objeto `OpenStreetMapImagery`, que proporciona imágenes geográficas de los colaboradores de OpenStreetMap©.

```json-snippet source="/maps/geo-map/display-osm-imagery"
{
    "type": "GeographicMap",
    "$setInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "$assignInCode": {
        "backgroundContent": [
            "angular",
            "react",
            "webComponents",
            "blazor",
            "winUI",
            "wpf"
        ]
    },
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "backgroundContent": {
        "type": "OpenStreetMapImagery",
        "name": "osmImagery"
    },
    "$type": "+doc:markup"
}
```
