# Gráfico de áreas de {Platform}

El gráfico de áreas de {ProductName} se representa como una colección de puntos unidos por segmentos de línea recta, con el área situada bajo la línea rellena. Los valores se representan en el eje Y (etiquetas a la izquierda) y las categorías se muestran en el eje X (etiquetas inferiores). Este gráfico destaca la magnitud del cambio a lo largo de un periodo de tiempo, o compara varios elementos, así como la relación entre las partes de un todo, mostrando el total de los valores representados. Por ello, suelen ser cronológicos y muestran un cambio de cantidad, por ejemplo, la acumulación de un producto básico a lo largo del tiempo.

## Recomendaciones para el gráfico de áreas

### Casos de uso del gráfico de áreas

Hay varios casos de uso habituales para elegir un gráfico de áreas:

- Tiene un conjunto de datos grande y de alto volumen que encaja bien con las interacciones del gráfico, como el desplazamiento, el zoom y la exploración detallada (drill-down).
- Necesita comparar las tendencias de sus datos a lo largo del tiempo.
- Quiere mostrar la diferencia entre dos o más series de datos.
- Quiere mostrar comparaciones acumuladas de parte del todo entre categorías distintas.
- Necesita mostrar tendencias de datos de una o varias categorías para realizar un análisis comparativo.
- Necesita visualizar en detalle datos de series temporales.

### Buenas prácticas del gráfico de áreas

- Empiece siempre el eje Y (eje izquierdo o derecho) en 0 para que la comparación de datos sea precisa.
- Ordene los datos de series temporales de izquierda a derecha.
- Use colores transparentes para asegurarse de que los datos representados detrás de otra serie no queden ocultos.

### Cuándo no usar gráficos de áreas

- Tiene muchas series de datos (más de 7 o 10). Su objetivo es garantizar que el gráfico sea legible.
- Los datos de series temporales tienen valores similares (datos del mismo periodo). Esto hace imposible diferenciar las áreas sombreadas superpuestas.

### Estructura de datos del gráfico de áreas

- El origen de datos debe ser un array o una lista de elementos de datos (para una única serie).
- El origen de datos debe ser un array de arrays o una lista de listas (para varias series).
- El origen de datos debe contener dos o más elementos de datos para poder dibujar una línea entre ellos.
- Todos los elementos de datos deben contener al menos una columna de datos (cadena o fecha y hora).
- Todos los elementos de datos deben contener al menos una columna de datos numérica.

## Gráfico de áreas apiladas de {Platform}

El gráfico de áreas apiladas de {Platform} se representa mediante un conjunto de puntos unidos por segmentos de línea, con el área situada bajo la línea rellena y apilada una encima de otra. Los gráficos de áreas apiladas siguen los mismos requisitos que los gráficos de áreas; la única diferencia es que, visualmente, las áreas sombreadas se apilan unas sobre otras. Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a `StackedAreaSeries`, como se muestra en el ejemplo siguiente.

El gráfico de áreas spline apiladas al 100 % de {Platform} es idéntico al gráfico de áreas spline apiladas en todos los aspectos, excepto en el tratamiento de los valores del eje Y. ## Gráfico de áreas radiales de {Platform}

El gráfico de áreas radiales de {Platform} pertenece a un grupo de [Radial Chart](radial-chart.mdx) y tiene la forma de un polígono relleno delimitado por una colección de líneas rectas que unen los puntos de datos. Este tipo de gráfico usa el mismo concepto de trazado de datos que el gráfico de áreas, pero envuelve los puntos de datos alrededor de un eje circular en lugar de extenderlos horizontalmente. Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a `RadialAreaSeries`, como se muestra en el ejemplo siguiente.


<Sample src="/charts/data-chart/radial-area-chart" height={600} alt="Gráfico de áreas radiales de {Platform}" />



## Gráfico de áreas polares de {Platform}

El gráfico de áreas polares de {Platform} pertenece a un grupo de [Polar Chart](polar-chart.mdx) y tiene la forma de un polígono relleno, cuyos vértices o esquinas se sitúan en las coordenadas polares (ángulo/radio) de los puntos de datos y se unen mediante una línea recta; después se rellena el área representada por los puntos unidos. El gráfico de áreas polares usa los mismos conceptos de trazado de datos que el gráfico de marcadores de dispersión, pero en lugar de extender los puntos y el área rellena a lo largo de una línea horizontal, envuelve los puntos alrededor de un círculo y rellena el área dibujada. Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a `PolarAreaSeries`, como se muestra en el ejemplo siguiente.


<Sample src="/charts/data-chart/polar-area-chart" height={600} alt="Gráfico de áreas polares de {Platform}" />
