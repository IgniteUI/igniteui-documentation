# Gráfico de barras de {Platform}
El gráfico de barras de {ProductName}, Bar Graph o gráfico de barras horizontales, es uno de los tipos de gráfico por categorías más habituales para comparar rápidamente la frecuencia, el recuento, el total o la media de datos de distintas categorías, con datos codificados mediante barras horizontales de igual altura pero distinta longitud. Este gráfico es ideal para mostrar variaciones en el valor de un elemento a lo largo del tiempo. Los datos se representan mediante un conjunto de rectángulos que se extienden de izquierda a derecha del gráfico hacia los valores de los puntos de datos. El gráfico de barras es muy similar a [Column Chart](column-chart.mdx), salvo que el gráfico de barras se representa con una rotación de 90 grados en el sentido de las agujas del reloj y, por tanto, tiene orientación horizontal (de izquierda a derecha), mientras que [Column Chart](column-chart.mdx) tiene orientación vertical (de arriba abajo)

## Recomendaciones para el gráfico de barras

### ¿Son los gráficos de barras de {Platform} adecuados para su proyecto?
El gráfico de barras de {Platform} incluye varias variantes según sus datos o la forma en que quiera contar la historia correcta con ellos. Entre ellas se incluyen:

- Gráfico de barras agrupadas
- Gráfico de barras apiladas
- Gráfico de barras polares
- Gráfico de barras apiladas al 100

### Casos de uso del gráfico de barras
Hay varios casos de uso habituales para elegir un gráfico de barras:

- Necesita mostrar tendencias a lo largo del tiempo o cambios de un valor numérico en una categoría de datos.
- Necesita comparar los valores de datos de una o más series de datos.
- Quiere mostrar una comparación de parte del todo.
- Quiere mostrar el porcentaje superior o inferior de las categorías.
- Analizar varios puntos de datos agrupados en subcategorías (barras apiladas).

Estos casos de uso se emplean habitualmente en los siguientes escenarios:

- Gestión de ventas.
- Gestión de inventario.
- Gráficos bursátiles.
- Cualquier valor de cadena que se compare con un valor numérico o con un valor de series temporales.

### Buenas prácticas del gráfico de barras
- Empiece su eje numérico en 0.
- Use un único color para las barras.
- Asegúrese de que el espacio que separa cada barra sea la mitad de la anchura de la propia barra.
- Asegúrese de que las categorías (elementos) que compare o clasifique estén ordenadas de forma creciente o decreciente.
- Alinee a la derecha los valores de las categorías en el eje Y (etiquetas a la izquierda del gráfico) para facilitar la lectura.

### Cuándo no usar el gráfico de barras
- Tiene demasiados datos, por lo que el eje Y no cabe en el espacio disponible o no es legible.
- Necesita un análisis detallado de series temporales: para este tipo de datos, considere un [Line Chart](line-chart.mdx) con una serie temporal.

### Estructura de datos del gráfico de barras
- El origen de datos debe ser un array o una lista de elementos de datos.
- El origen de datos debe contener al menos un elemento de datos.
- La lista debe contener al menos una columna de datos (cadena o fecha y hora).
- La lista debe contener al menos una columna de datos numérica.

## Gráfico de barras apiladas de {Platform}

El gráfico de barras apiladas, o gráfico de barras apiladas horizontales, es un tipo de gráfico por categorías que se usa para comparar la composición de distintas categorías de datos mostrando fragmentos de distinto tamaño en las barras horizontales del gráfico. La longitud de cada barra, o pila de fragmentos, es proporcional a su valor total.

El gráfico de barras apiladas se diferencia del gráfico de barras en que los puntos de datos que representan sus datos se apilan unos junto a otros horizontalmente para agrupar visualmente los datos. Cada pila puede contener valores positivos y negativos. Todos los valores positivos se agrupan en el lado positivo del eje X, y todos los valores negativos, en el lado negativo del eje X.

Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a una `StackedBarSeries`, como se muestra en el ejemplo siguiente:

## Gráfico de barras de rango de {Platform}

El gráfico de barras de rango de {Platform} pertenece a un grupo de gráficos de rango y se representa mediante rectángulos horizontales que pueden aparecer en el centro del área de trazado del gráfico, en lugar de extenderse desde la izquierda como el tradicional [Category Bar Chart](bar-chart.mdx#ejemplo-de-gráfico-de-barras-de-{PlatformLower}). Este tipo de serie destaca la magnitud del cambio entre valores bajos y valores altos de un mismo punto de datos a lo largo de un periodo de tiempo, o compara varios elementos.

Los valores de rango se representan en el eje X y las categorías se muestran en el eje Y. Como cada barra visualiza un valor bajo y un valor alto, este gráfico resulta útil en escenarios como la representación de rangos de temperatura diarios, precios mínimos y máximos, o cualquier medición acotada en la que un único valor no sea suficiente.

El gráfico de barras de rango es idéntico al [Range Column Chart](column-chart.mdx#gráfico-de-columnas-de-rango-de-{PlatformLower}) en todos los aspectos, salvo que los rangos se representan como un conjunto de barras horizontales en lugar de columnas verticales.

Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a una `RangeBarSeries`. La serie lee los valores bajos y altos de `LowMemberPath` y `HighMemberPath`, y normalmente usa una `NumericXAxis` con una `CategoryYAxis`, como se muestra en el ejemplo siguiente:
