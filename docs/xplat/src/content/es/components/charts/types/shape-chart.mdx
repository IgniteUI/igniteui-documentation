# Shape Charts de {Platform}

Los Shape Charts de {ProductName} son un grupo de gráficos que toman un array de formas (array o arrays de puntos X/Y) y las representan como una colección de polígonos o polilíneas en el sistema de coordenadas cartesianas (x, y). Se usan a menudo para destacar regiones de datos científicos, o pueden usarse para representar diagramas, planos o incluso la distribución de edificios.

## Gráfico de dispersión de polígonos de {Platform}

El Scatter Polygon Chart de {Platform} representa un array o un array de arrays de polígonos en el sistema de coordenadas cartesianas (x, y) usando `ScatterPolygonSeries` en el control `DataChart`. Este gráfico puede usarse para rellenar formas de diagramas, planos o incluso la distribución de edificios.

Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a una `ScatterPolygonSeries`, como se muestra en el ejemplo siguiente:

## Scatter Polyline Chart de {Platform}

El Scatter Polyline Chart de {Platform} representa un array o un array de arrays de polilíneas en el sistema de coordenadas cartesianas (x, y) usando `ScatterPolylineSeries` en el control `DataChart`. Este gráfico puede usarse para trazar los contornos de diagramas, planos o incluso la distribución de edificios. Además, puede visualizar relaciones complejas entre una gran cantidad de elementos.

Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a una `ScatterPolylineSeries`, como se muestra en el ejemplo siguiente:
