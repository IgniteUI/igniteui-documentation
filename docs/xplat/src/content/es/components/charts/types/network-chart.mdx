# Gráfico de red de {Platform}
El gráfico de red de {ProductName}, también llamado Network Graph o Polyline Chart, visualiza relaciones complejas entre una gran cantidad de elementos. Esta visualización muestra estructuras de grafo no dirigidas y dirigidas. También muestra las relaciones entre entidades, que se representan como nodos redondos, y las líneas muestran las relaciones entre ellos.

Las siguientes secciones ofrecen ejemplos de varios tipos de gráficos de red.

## Gráfico de red polar de {Platform}
Este ejemplo muestra cómo crear un gráfico de red polar usando `PolarScatterSeries` (para representar los marcadores de nodo) y `PolarLineSeries` (para representar las conexiones de nodos) en el control `DataChart`.
