## Recomendaciones para el Sparkline

### ¿Es el gráfico Sparkline adecuado para su proyecto?
La principal ventaja del control Sparkline frente a otros controles de gráficos es que puede representarse en un espacio limitado, como una celda de cuadrícula, con todos sus elementos visuales visibles.

El Sparkline de {Platform} puede marcar los puntos de datos con iconos elípticos para indicar los valores más altos, más bajos, primero, último y negativos. Los marcadores pueden personalizarse con la forma, el color o la imagen deseados.

### Casos de uso del Sparkline
- Tiene un espacio reducido para mostrar un gráfico.
- Quiere mostrar tendencias en una serie de valores, como los ingresos semanales.

### Buenas prácticas del Sparkline
- Empiece siempre el eje Y (eje izquierdo o derecho) en 0 para que la comparación de datos sea precisa.
- Ordene los datos de series temporales de izquierda a derecha.
- Use atributos visuales, como las líneas continuas, para mostrar una serie de datos.

### Cuándo no usar el Sparkline
- Necesita analizar los datos en detalle.
- Necesita mostrar todas las etiquetas de los puntos de datos. Solo permite mostrar los valores máximo y mínimo en el eje Y, y los valores primero y último en el eje X.

### Estructura de datos del Sparkline
- Requiere datos unidimensionales.
- El conjunto de datos debe contener al menos dos campos numéricos.
- El texto de los campos del origen de datos puede usarse para mostrar la primera y la última etiqueta en el eje X.

## Tipos de sparkline
El Sparkline de {Platform} admite los siguientes tipos de sparkline, estableciendo la propiedad `displayType` en consecuencia:

- `Line`: muestra el tipo de gráfico de líneas de Sparkline con datos numéricos, uniendo los puntos de datos con segmentos de línea. Deben proporcionarse al menos dos puntos de datos para visualizar los datos en el Sparkline.
- `Area`: muestra el tipo de gráfico de áreas de Sparkline con datos numéricos. Es como el tipo de línea, con el paso adicional de cerrar el área después de dibujar cada línea. Deben proporcionarse al menos dos puntos de datos para visualizar los datos en el Sparkline.
- `Column`: muestra el tipo de gráfico de columnas de Sparkline con datos numéricos. Algunos lo llaman barras verticales. Este tipo puede representar un único punto de datos, pero requiere especificar la propiedad de rango mínimo de valores (minimum) en el Sparkline para que el punto de datos único sea visible; de lo contrario, el valor se tratará como el valor mínimo y no será visible.
- `WinLoss`: este tipo es similar en apariencia visual al tipo de gráfico de columnas, en el que el valor de cada columna es igual al máximo positivo (para valores positivos) o al mínimo negativo (para valores negativos) del conjunto de datos. La idea es indicar un escenario de ganancia o pérdida. Para que el gráfico de ganancias/pérdidas se muestre correctamente, el conjunto de datos debe tener valores positivos y negativos. Si el Sparkline WinLoss se enlaza a los mismos datos que los otros tipos, como el tipo de línea, que puede enlazarse a una colección de valores numéricos, entonces el Sparkline {Platform} seleccionará dos valores de la colección (el más alto y el más bajo) y representará el sparkline basándose en esos valores.

## Marcadores

El Sparkline de {Platform} le permite mostrar marcadores como iconos circulares de color en sus series para indicar los puntos de datos individuales según las coordenadas X/Y. Los marcadores pueden establecerse en sparklines de los tipos de visualización `Line`, `Area` y `Column`. El tipo de sparkline `WinLoss` no admite marcadores por el momento. De forma predeterminada, los marcadores no se muestran, pero pueden habilitarse estableciendo la propiedad de visibilidad de marcador correspondiente.

Los marcadores del sparkline pueden colocarse en cualquier combinación de las siguientes ubicaciones:

- `MarkerVisibility`: muestra marcadores en todos los puntos de datos del sparkline.
- `LowMarkerVisibility`: muestra marcadores en el punto de datos del valor más bajo. Si hay varios puntos con el valor más bajo, se mostrará en cada uno de ellos.
- `HighMarkerVisibility`: muestra marcadores en el punto de datos del valor más alto. Si hay varios puntos con el valor más alto, se mostrará en cada uno de ellos.
- `FirstMarkerVisibility`: muestra un marcador en el primer punto de datos del sparkline.
- `LastMarkerVisibility`: muestra un marcador en el último punto de datos del sparkline.
- `NegativeMarkerVisibility`: muestra marcadores en los puntos de datos negativos representados en el sparkline.

Todos los marcadores mencionados anteriormente pueden personalizarse en cuanto a color, visibilidad y tamaño usando la propiedad del tipo de marcador correspondiente. Por ejemplo, los marcadores `\\Low` de arriba tendrán las propiedades `lowMarkerBrush`, `lowMarkerVisibility` y `lowMarkerSize`.

## Rango normal

La función de rango normal del Sparkline de {Platform} es una franja horizontal que representa un rango predefinido y significativo al visualizar los datos. El rango normal puede establecerse como un área sombreada delimitada por el color deseado.

El rango normal puede ser más ancho que el punto de datos máximo o incluso mayor, y también puede ser tan fino como el tipo de visualización `Line` del sparkline, para servir, por ejemplo, como indicador de umbral. El ancho del rango normal lo determinan las tres propiedades siguientes, que son los ajustes mínimos necesarios para mostrar el rango normal:

- `NormalRangeVisibility`: indica si el rango normal es visible.
- `NormalRangeMaximum`: el borde inferior del rango.
- `NormalRangeMinimum`: el borde superior del rango.

De forma predeterminada, el rango normal no se muestra. Cuando está habilitado, el rango normal aparece con un color gris claro, que también puede configurarse con la propiedad `normalRangeFill`.

También puede configurar si el rango normal se muestra delante o detrás de las series representadas en su Sparkline de {Platform}, estableciendo la propiedad `displayNormalRangeInFront`.

## Líneas de tendencia

El Sparkline de {Platform} admite una serie de líneas de tendencia que se muestran como otra capa sobre la capa del sparkline. Para mostrar un sparkline, puede usar la propiedad `TrendLineType`.

Las líneas de tendencia se calculan según el algoritmo especificado por la propiedad `TrendLineType`, usando los valores de los datos a los que está enlazado el gráfico.

Las líneas de tendencia solo pueden mostrarse una a la vez y, de forma predeterminada, la línea de tendencia no se muestra.

## Interpolación de valores desconocidos

El Sparkline de {Platform} puede detectar valores desconocidos y reservar el espacio para ellos mediante un algoritmo de interpolación especificado. Si sus datos contienen valores nulos y no usa esta característica, es decir, no se especifica ninguna interpolación, el valor desconocido no se representará.

Para representar los valores desconocidos, puede establecer la propiedad `unknownValuePlotting` del Sparkline {Platform}.
