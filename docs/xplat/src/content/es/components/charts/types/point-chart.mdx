# Gráfico de puntos de {Platform}
El gráfico de puntos de {ProductName} representa una colección de puntos. Los valores se representan en el eje Y (etiquetas a la izquierda) y las categorías se muestran en el eje X (etiquetas inferiores). Estos gráficos destacan la magnitud del cambio a lo largo de un periodo de tiempo, o comparan varios elementos, así como la relación entre las partes de un todo, mostrando el total de los valores representados.

## Ejemplo de gráfico de puntos de {Platform}
Puede crear el gráfico de puntos de {Platform} en el control `CategoryChart` enlazando sus datos a la propiedad `dataSource` y estableciendo la propiedad `chartType` en la enumeración **Point**, como se muestra en el ejemplo siguiente.

## Gráfico de puntos de {Platform} con varias series
Como el gráfico de puntos de {Platform} le permite combinar varias series y comparar o ver cómo cambian a lo largo del tiempo, veamos lo sencillo que es lograrlo. Solo tenemos que enlazar un origen de datos que contenga los datos de China y de Estados Unidos, y el gráfico de puntos se actualizará automáticamente para ajustarse a los datos adicionales.
