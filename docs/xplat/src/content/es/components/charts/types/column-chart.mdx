# Gráfico de columnas de {Platform}

El gráfico de columnas de {ProductName}, Column Graph o gráfico de barras verticales, es uno de los tipos de gráfico por categorías más habituales para comparar rápidamente la frecuencia, el recuento, el total o la media de datos de distintas categorías, con datos codificados mediante columnas de igual anchura pero distinta altura. Estas columnas se extienden de abajo arriba del gráfico hacia los valores de los puntos de datos. Este gráfico destaca la magnitud del cambio a lo largo de un periodo de tiempo o compara varios elementos. El gráfico de columnas es muy similar a [Bar Chart](bar-chart.mdx), salvo que el gráfico de columnas se representa con orientación vertical (de abajo arriba), mientras que [Bar Chart](bar-chart.mdx) tiene orientación horizontal (de izquierda a derecha) o una rotación de 90 grados en el sentido de las agujas del reloj.

## Recomendaciones para los gráficos de columnas

### Casos de uso de los gráficos de columnas

Hay varios casos de uso para los gráficos de columnas. Cuando:

- Necesita comparar valores de datos de categorías relacionadas.
- Necesita comparar datos a lo largo de un periodo de tiempo.
- Necesita mostrar valores negativos y positivos en el mismo conjunto de datos.
- Tiene un conjunto de datos grande y de alto volumen que encaja bien con las interacciones del gráfico, como el desplazamiento, el zoom y la exploración detallada (drill-down).

### Buenas prácticas de los gráficos de columnas

- Empiece siempre el eje Y (eje izquierdo o derecho) en 0 para que la comparación de datos sea precisa.
- Ordene los datos de series temporales de izquierda a derecha.

### Cuándo no usar gráficos de columnas

- Tiene muchas series de datos (más de 10 o 12). Su objetivo es garantizar que el gráfico sea legible.

### Estructura de datos de los gráficos de columnas

- El modelo de datos debe contener al menos una propiedad numérica.
- El modelo de datos puede contener una propiedad de cadena de opciones o de fecha y hora para las etiquetas.
- El origen de datos debe contener al menos un elemento de datos.

## Gráfico de cascada de {Platform}

El gráfico de cascada pertenece a un grupo de gráficos por categorías y se representa mediante un conjunto de columnas verticales que muestran la diferencia entre puntos de datos consecutivos. Las columnas tienen códigos de color para distinguir entre cambios de valor positivos y negativos. El gráfico de cascada es parecido en apariencia al [Range Column Chart](column-chart.mdx#gráfico-de-columnas-de-rango-de-{PlatformLower}), pero solo requiere una columna de datos numérica en lugar de dos columnas por cada punto de datos.

## Gráfico de columnas apiladas de {Platform}

El gráfico de columnas apiladas es similar al [Category Column Chart](column-chart.mdx#ejemplo-de-gráfico-de-columnas-de-{PlatformLower}) en todos los aspectos, salvo que las series se representan unas encima de otras en lugar de una junto a otra. El gráfico de columnas apiladas se usa para mostrar la comparación de resultados entre series. Cada fragmento apilado de la colección representa un elemento visual en cada pila. Cada pila puede contener valores positivos y negativos. Todos los valores positivos se agrupan en el lado positivo del eje Y, y todos los valores negativos, en el lado negativo del eje Y. El gráfico de columnas apiladas usa los mismos conceptos de trazado de datos que el [Stacked Bar Chart](stacked-chart.mdx#gráfico-de-barras-apiladas-de-{PlatformLower}), pero los puntos de datos se apilan a lo largo de una línea vertical (eje Y) en lugar de a lo largo de una línea horizontal (eje X).

Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a una `StackedBarSeries`, como se muestra en el ejemplo siguiente:

## Gráfico de columnas apiladas al 100 % de {Platform}

## Gráfico de columnas de rango de {Platform}

El gráfico de columnas de rango de {Platform} pertenece a un grupo de gráficos de rango y se representa mediante rectángulos verticales que pueden aparecer en el centro del área de trazado del gráfico, en lugar de extenderse desde la parte inferior como el tradicional [Category Column Chart](column-chart.mdx#ejemplo-de-gráfico-de-columnas-de-{PlatformLower}). Este tipo de serie destaca la magnitud del cambio entre valores bajos y valores altos de un mismo punto de datos a lo largo de un periodo de tiempo, o compara varios elementos. Los valores de rango se representan en el eje Y y las categorías se muestran en el eje X.

El gráfico de columnas de rango es idéntico al [Range Area Chart](area-chart.mdx#gráfico-de-áreas-de-rango-de-{PlatformLower}) en todos los aspectos, salvo que los rangos se representan como un conjunto de columnas verticales en lugar de un área rellena.

Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a una `RangeColumnSeries`, como se muestra en el ejemplo siguiente:

<Sample src="/charts/data-chart/range-column-chart" height={600} alt="Gráfico de columnas de rango de {Platform}" />




## Gráfico de columnas radiales de {Platform}

El gráfico de columnas radiales pertenece a un grupo de [Radial Chart](radial-chart.mdx) y se visualiza mediante un conjunto de rectángulos que se extienden desde el centro del gráfico hacia la ubicación de los puntos de datos. Usa los mismos conceptos de trazado de datos que el [Category Column Chart](column-chart.mdx#ejemplo-de-gráfico-de-columnas-de-{PlatformLower}), pero envuelve los puntos de datos alrededor de un círculo en lugar de extenderlos horizontalmente.
