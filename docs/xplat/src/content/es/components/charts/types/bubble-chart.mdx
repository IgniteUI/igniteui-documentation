# Gráfico de burbujas de {Platform}
El gráfico de burbujas de {ProductName} es un tipo de [Scatter Chart](scatter-chart.mdx) que muestra marcadores con una escala variable para representar la relación entre elementos de varias series de datos distintas, o para representar elementos de datos mediante coordenadas x e y. Estas coordenadas del punto de datos se determinan mediante dos columnas de datos numéricas. El gráfico de burbujas llama la atención sobre intervalos irregulares o agrupaciones de datos. Este gráfico se usa a menudo para representar datos científicos y puede destacar la desviación de los datos recopilados respecto a los resultados previstos. El gráfico de burbujas tiene muchas de las características del [Scatter Marker Chart](scatter-chart.mdx#gráfico-de-dispersión-con-marcadores-de-{PlatformLower}), pero con la opción de tener distintos tamaños de escala de radio.

## Estilo del gráfico de burbujas de {Platform}
En el gráfico de burbujas de {Platform}, puede personalizar la forma de los marcadores de burbuja con la propiedad `markerType`, su tamaño con la propiedad `radiusScale` y su aspecto con las propiedades `markerBrush`, `markerOutline` y `markerThickness`. Además, también puede colorear los marcadores de burbuja según una columna de datos usando las propiedades `fillMemberPath` y `fillScale`.
