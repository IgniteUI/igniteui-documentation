# Gráfico de anillo de {Platform}
El gráfico de anillo de {ProductName} es similar al [Pie Chart](pie-chart.mdx), y muestra proporcionalmente las apariciones de una variable. El gráfico de anillo puede mostrar varias variables en anillos concéntricos, y ofrece compatibilidad integrada para visualizar datos jerárquicos. Los anillos pueden enlazarse a un elemento de datos distinto, o compartir un origen de datos común.

## Recomendaciones para el gráfico de anillo de {Platform}

### ¿Son los gráficos de anillo de {Platform} adecuados para su proyecto?
Los gráficos de anillo son adecuados para conjuntos de datos pequeños y son fáciles de leer de un vistazo. Los gráficos de anillo son solo un tipo de visualización de parte del todo. Otros son:

- [Pie](pie-chart.mdx)
- [Stacked Area](area-chart.mdx)
- [Área apilada al 100 % (área apilada porcentual)](area-chart.mdx)
- [Stacked Bar](bar-chart.mdx)
- [Barra apilada al 100 % (barra apilada porcentual)](bar-chart.mdx)
- [Treemap](treemap-chart.mdx)
- [Waterfall](column-chart.mdx)

El gráfico de anillo de {Platform} incluye características interactivas que ofrecen al usuario herramientas para analizar datos, como:

- Leyendas
- Separación de sectores
- Selección de sectores
- Animaciones del gráfico

### Buenas prácticas para los gráficos de anillo
- Uso de varios conjuntos de datos para mostrar sus datos en una visualización en anillo.
- Colocar la información, como valores o etiquetas, dentro del hueco del anillo para una explicación rápida de los datos.
- Comparar sectores o segmentos como valores porcentuales en proporción a un valor total o a un todo.
- Mostrar cómo se divide un grupo de categorías en segmentos más pequeños.
- Asegurarse de que los segmentos de datos suman el 100 %.
- Asegurarse de que la paleta de colores permite distinguir los segmentos o sectores de las partes.

### Cuándo no usar un gráfico de anillo
- Comparar cambios a lo largo del tiempo: use un gráfico de [barras](bar-chart.mdx), de [líneas](line-chart.mdx) o de [áreas](area-chart.mdx).
- Necesitar una comparación precisa de datos: use un gráfico de [barras](bar-chart.mdx), de [líneas](line-chart.mdx) o de [áreas](area-chart.mdx).
- Tener más de 6 u 8 segmentos (gran volumen de datos): considere un gráfico de [barras](bar-chart.mdx), de [líneas](line-chart.mdx) o de [áreas](area-chart.mdx) si se ajusta a la historia de sus datos.
- Al espectador le resultaría más fácil percibir la diferencia de valor en un gráfico de [barras](bar-chart.mdx).
- Tener datos negativos, ya que no pueden representarse en un gráfico de anillo.

## Gráfico de anillo de {Platform} - Selección de sectores
El gráfico de anillo de {Platform} puede seleccionar sectores al hacer clic. Opcionalmente, puede aplicar un único estilo visual personalizado a los sectores seleccionados. El evento `sliceClick` se genera cuando el usuario hace clic en un sector. Habilitar la selección de sectores le permite modificar la selección del sector al hacer clic.
