# Gráficos de dispersión de {Platform}

El Scatter Chart de {ProductName} pertenece a un grupo de gráficos que muestran la relación entre elementos de series de datos distintas, o que representan elementos de datos mediante coordenadas numéricas x e y. Estos gráficos llaman la atención sobre intervalos irregulares o agrupaciones de datos. Se usan a menudo para representar datos científicos y pueden destacar la desviación de los datos recopilados respecto a los resultados previstos. Además, puede usarlos para organizar los datos cronológicamente (aunque los datos no estén en orden cronológico).

## Gráfico de dispersión con marcadores de {Platform}

El Scatter Marker Chart de {Platform} se representa como un conjunto de marcadores, cada uno con un par de valores numéricos X/Y que determina su ubicación en el sistema de coordenadas cartesianas. Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a una `ScatterSeries`, como se muestra en el ejemplo siguiente:

## Scatter High Density Chart de {Platform}

Use el Scatter High Density (HD) Chart de {Platform} para enlazar y mostrar datos de dispersión, desde miles hasta millones de puntos de datos, con muy poco tiempo de carga. Como este tipo de gráfico está diseñado para una cantidad tan grande de puntos, se visualiza como puntos diminutos en lugar de marcadores de tamaño completo, y muestra las zonas con más datos con una mayor densidad de color que representa una agrupación de puntos de datos. Puede crear este tipo de gráfico en el control `DataChart` enlazando sus datos a una `HighDensityScatterSeries`, como se muestra en el ejemplo siguiente:

## Scatter Area Chart de {Platform}

El Scatter Area Chart de {Platform} dibuja una superficie coloreada basada en una triangulación de datos X e Y, con un valor de datos numérico asignado a cada punto. Este gráfico es útil para representar mapas de calor, la intensidad de un campo magnético o la intensidad de la señal Wi-Fi en una oficina.
