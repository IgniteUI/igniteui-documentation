# Gráfico de líneas de {Platform}

El gráfico de líneas de {ProductName} o Line Graph es un tipo de gráfico por categorías que muestra los valores de datos continuos representados por puntos unidos por segmentos de línea recta de una o varias cantidades a lo largo de un periodo de tiempo. Suele usarse para mostrar tendencias y realizar análisis comparativos. El eje Y (etiquetas a la izquierda) muestra un valor numérico, mientras que el eje X (etiquetas inferiores) muestra una serie temporal o una categoría de comparación. Puede incluir uno o varios conjuntos de datos para comparar, que se representarán como varias líneas en el gráfico.

## Recomendaciones para el gráfico de líneas

### ¿Son los gráficos de líneas de {Platform} adecuados para su proyecto?

- A diferencia de un [gráfico de áreas](area-chart.mdx), el gráfico de líneas no rellena el área comprendida entre el eje X (eje inferior) y la línea.
- El gráfico de líneas de {Platform} es idéntico al {Platform} [gráfico spline](spline-chart.mdx) en todos los aspectos, salvo que la línea que une los puntos de datos no tiene interpolación spline ni suavizado para mejorar la presentación de los datos.

Un gráfico de líneas incluye varias variantes según sus datos o la forma en que quiera contar la historia correcta con ellos. Entre ellas se incluyen:

- Gráfico de líneas en capas
- Gráfico de líneas apiladas
- Gráfico de líneas escalonadas
- Gráfico de líneas polares
- Gráfico de líneas apiladas al 100

### Casos de uso del gráfico de líneas

Hay varios casos de uso habituales para elegir un gráfico de líneas:

- Tiene un conjunto de datos grande y de alto volumen que encaja bien con las interacciones del gráfico, como el desplazamiento, el zoom y la exploración detallada (drill-down).
- Necesita comparar las tendencias a lo largo del tiempo.
- Quiere mostrar la diferencia entre dos o más series de datos.
- Quiere mostrar comparaciones acumuladas de parte del todo entre categorías distintas.
- Necesita mostrar tendencias de datos de una o varias categorías para realizar un análisis comparativo.
- Necesita visualizar datos detallados de series temporales.

### Buenas prácticas del gráfico de líneas

- Empiece siempre el eje Y (eje izquierdo o derecho) en 0 para que la comparación de datos sea precisa.
- Ordene los datos de series temporales de izquierda a derecha.
- Use atributos visuales, como las líneas continuas, para mostrar una serie de datos.

### Cuándo no usar el gráfico de líneas

- Tiene muchas series de datos (más de 7 o 10). Su objetivo es garantizar que el gráfico sea legible.
- Los datos de series temporales tienen valores similares (datos del mismo periodo), lo que hace imposible diferenciar las líneas superpuestas.

### Estructura de datos del gráfico de líneas

- El origen de datos debe ser un array o una lista de elementos de datos (para una única serie).
- El origen de datos debe ser un array de arrays o una lista de listas (para varias series).
- El origen de datos debe contener al menos un elemento de datos.
- Todos los elementos de datos deben contener al menos una columna de datos (cadena o fecha y hora).
- Todos los elementos de datos deben contener al menos una columna de datos numérica.

## Gráfico de líneas apiladas al 100 % de {Platform}

El gráfico de líneas apiladas al 100 % es idéntico al gráfico de líneas apiladas en todos los aspectos, salvo en el tratamiento de los valores del eje Y. En lugar de presentar una representación directa de los datos, el gráfico de líneas apiladas al 100 % presenta los datos como un porcentaje de la suma de todos los valores de un punto de datos. ## Gráfico de líneas radiales de {Platform}

El gráfico de líneas radiales pertenece a un grupo de gráficos radiales y tiene la forma de un polígono sin relleno delimitado por una colección de líneas rectas que unen los puntos de datos. Este tipo de gráfico usa el mismo concepto de trazado de datos que el gráfico de líneas, pero envuelve los puntos de datos alrededor de un eje circular en lugar de extenderlos horizontalmente.

## Gráfico de líneas polares de {Platform}

El gráfico de líneas polares pertenece a un grupo de gráficos polares y se representa mediante una colección de líneas rectas que unen los puntos de datos en un sistema de coordenadas polares (ángulo/radio). Los gráficos de líneas polares usan los mismos conceptos de trazado de datos que el [Scatter Line Chart](scatter-chart.mdx), con la diferencia de que la visualización envuelve los puntos de datos alrededor de un círculo en lugar de extenderlos horizontalmente.
