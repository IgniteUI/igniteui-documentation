# Tipos de ejes de {Platform}

El gráfico de categorías {ProductName} usa solo un `CategoryXAxis` y un `NumericYAxis`.<PlatformBlock for="Web"> De forma similar, {ProductName} Financial Chart usa solo un `TimeXAxis` y un `NumericYAxis`.</PlatformBlock> Sin embargo, {ProductName} Data Chart admite varios tipos de ejes que puede colocar en cualquier lado del gráfico estableciendo la [ubicación del eje](chart-axis-layouts.mdx#ejemplo-de-ubicaciones-de-ejes), o incluso dentro del gráfico usando las propiedades de [cruce de ejes](chart-axis-layouts.mdx#ejemplo-de-cruce-de-ejes). Este tema repasa cada uno de ellos, qué ejes y series son compatibles entre sí y algunas propiedades específicas de los ejes únicos.

## Ejes cartesianos

El `DataChart` con ejes cartesianos le permite representar datos en dirección horizontal (eje X) y vertical (eje Y), con 3 tipos de eje X
(`CategoryXAxis`, `NumericXAxis` y `TimeXAxis`) y 2 tipos de eje Y (`CategoryYAxis` y `NumericYAxis`).

### Eje X de categoría

El `CategoryXAxis` trata sus datos como una secuencia de elementos de datos categóricos. Puede mostrar casi cualquier tipo de datos, incluidas cadenas y números. Si representa números en este eje, es importante tener en cuenta que se trata de un eje discreto y no continuo. Esto significa que cada elemento de datos categórico se colocará a la misma distancia del anterior. Los elementos también se representarán en el orden en que aparecen en el origen de datos del eje.

El `CategoryXAxis` requiere que proporcione un `DataSource` y un `NumericYAxis.label` para representar datos con él. Se usa generalmente con `NumericYAxis` para representar el siguiente tipo de serie:

### Eje Y de categoría

Además, este eje requiere que proporcione un `DataSource` y un `NumericYAxis.label` para representar datos con él. El `CategoryYAxis` se usa generalmente con `NumericXAxis` para representar el siguiente tipo de serie:

### Eje X numérico

El `NumericXAxis` trata sus datos como elementos de datos numéricos que varían de forma continua. Las etiquetas de este eje se colocan horizontalmente a lo largo del eje X. La ubicación de las etiquetas del `NumericXAxis` depende de la propiedad `BubbleSeries.xMemberPath` de las distintas [Scatter Series](../types/scatter-chart.mdx) que admite si se combina con un `NumericYAxis`. Como alternativa, si se combina con `CategoryXAxis`, estas etiquetas se colocarán según `valueMemberPath` de `BarSeries`, `RangeBarSeries`, `StackedBarSeries` y `Stacked100BarSeries`.

El `NumericXAxis` es compatible con el siguiente tipo de serie:

- `BarSeries`
- `RangeBarSeries`
- `BubbleSeries`<PlatformBlock for="Web">
- `HighDensityScatterSeries`</PlatformBlock>
- `ScatterSeries`
- `ScatterLineSeries`
- `ScatterSplineSeries`
- `ScatterAreaSeries`
- `ScatterContourSeries`
- `ScatterPolylineSeries`
- `ScatterPolygonSeries`
- `StackedBarSeries`
- `Stacked100BarSeries`

### Eje Y numérico

El `NumericYAxis` trata sus datos como elementos de datos numéricos que varían de forma continua. Las etiquetas de este eje se colocan verticalmente a lo largo del eje Y. La ubicación de las etiquetas del `NumericYAxis` depende de la propiedad `yMemberPath` de las distintas [ScatterSeries](../types/scatter-chart.mdx) que admite si se combina con un `NumericXAxis`. Como alternativa, si se combina con `CategoryYAxis`, estas etiquetas se colocarán según `valueMemberPath` de las series de categoría o apiladas mencionadas en la tabla anterior. Si usa una de las series financieras, se colocarán según las trayectorias de apertura, máximo, mínimo y cierre y el tipo de serie que esté usando.

### Eje X de tiempo

El `TimeXAxis` trata sus datos como una secuencia de elementos de datos, ordenados por fecha. Las etiquetas de este tipo de eje son fechas y pueden formatearse y organizarse según intervalos de fechas. El rango de fechas de este eje se determina por los valores de fecha de una columna de datos asignada mediante su `dateTimeMemberPath`. Esto, junto con `DataSource`, es necesario para representar datos con este tipo de eje.
<PlatformBlock for="Web">
El `TimeXAxis` es el tipo de eje X del componente `FinancialChart`.</PlatformBlock>

#### Interrupciones en el eje X de tiempo

El `TimeXAxis` permite excluir intervalos de datos mediante `TimeXAxis.breaks`. Como resultado, las etiquetas y los datos representados no aparecerán en el intervalo excluido. Por ejemplo, días laborables y no laborables, festivos o fines de semana. Puede añadirse una instancia de `TimeAxisBreak` a la colección `TimeXAxis.breaks` del eje y configurarse mediante `TimeAxisBreak.start`, `TimeAxisBreak.end` y `NumericYAxis.interval` únicos.

#### Formato en el eje X de tiempo

El `TimeXAxis` tiene la propiedad `labelFormats`, que representa una colección de objetos `TimeAxisLabelFormat`. Cada `TimeAxisLabelFormat` añadido a la colección se encarga de asignar un `TimeAxisLabelFormat.format` y un `TimeAxisLabelFormat.range` únicos. Esto puede ser especialmente útil para explorar datos desde años hasta milisegundos y ajustar las etiquetas según el rango de tiempo que muestra el gráfico.

La propiedad `TimeAxisLabelFormat.format` de `TimeAxisLabelFormat` especifica qué formato usar para un rango visible concreto. La propiedad `TimeAxisLabelFormat.range` de `TimeAxisLabelFormat` especifica el rango visible en el que los formatos de las etiquetas del eje cambiarán a otro formato. Por ejemplo, si tiene dos elementos `TimeAxisLabelFormat` con un rango establecido en 10 días y otro en 5 horas, en cuanto el rango visible del eje sea inferior a 10 días, cambiará al formato de 5 horas.

#### Intervalos en el eje X de tiempo

El `TimeXAxis` sustituye la propiedad `NumericYAxis.interval` convencional de los ejes de categoría y numéricos por una colección `TimeXAxis.intervals` de tipo `TimeAxisInterval`. Cada `TimeAxisInterval` añadido a la colección se encarga de asignar un `NumericYAxis.interval`, un `TimeAxisLabelFormat.range` y un `intervalType` únicos. Esto puede ser especialmente útil para explorar datos desde años hasta milisegundos y ofrecer un espaciado propio entre las etiquetas según el rango de tiempo que muestra el gráfico. A continuación se describen estas propiedades:

- `NumericYAxis.interval`: especifica el intervalo que se usará. Está vinculado a la propiedad `intervalType`. Por ejemplo, si `intervalType` se establece en `Days`, el valor numérico indicado en `NumericYAxis.interval` estará expresado en días.
- `TimeAxisLabelFormat.range`: especifica el rango visible en el que el intervalo del eje cambiará a otro intervalo. Por ejemplo, si tiene dos TimeAxisInterval con un rango establecido en 10 días y otro en 5 horas, en cuanto el rango visible del eje sea inferior a 10 días, cambiará al intervalo cuyo rango es de 5 horas.
- `intervalType`: especifica la unidad de tiempo para la propiedad `NumericYAxis.interval`.

## Ejes polares

El `DataChart` con ejes polares le permite representar datos hacia fuera desde el centro del gráfico (eje de radio) y alrededor del centro del gráfico (eje angular).

### Eje angular de categoría

El `CategoryAngleAxis` trata sus datos como una secuencia de elementos de datos de categoría. Las etiquetas de este eje se colocan a lo largo del borde de un círculo según su posición en la secuencia. Este tipo de eje puede mostrar casi cualquier tipo de datos, incluidas cadenas y números.

El `CategoryAngleAxis` se usa generalmente con `NumericRadiusAxis` para representar [Radial Series](../types/radial-chart.mdx).

### Eje angular de categoría proporcional

El `ProportionalCategoryAngleAxis` trata sus datos como una secuencia de elementos de datos de categoría. Las etiquetas de este eje se colocan a lo largo del borde de un círculo según su posición en la secuencia. Este tipo de eje puede mostrar casi cualquier tipo de datos, incluidas cadenas y números.

El `ProportionalCategoryAngleAxis` se usa generalmente con `NumericRadiusAxis` para representar un gráfico circular, p. ej., [Radial Series](../types/radial-chart.mdx).

### Eje angular numérico

El `NumericAngleAxis` trata sus datos como elementos de datos numéricos que varían de forma continua. Las etiquetas de este eje se colocan a lo largo de una línea radial que parte del centro del gráfico circular. La ubicación de las etiquetas del `NumericAngleAxis` varía según el valor de la columna de datos asignada mediante la propiedad `radiusMemberPath` del objeto [Polar Series](../types/polar-chart.mdx) o la propiedad `valueMemberPath` del objeto [Radial Series](../types/radial-chart.mdx).

El `NumericAngleAxis` puede usarse con `CategoryAngleAxis` para representar [Radial Series](../types/radial-chart.mdx) o con `NumericRadiusAxis` para representar [Polar Series](../types/polar-chart.mdx), respectivamente.

El `NumericRadiusAxis` trata los datos como elementos de datos numéricos que varían de forma continua. Las etiquetas de este eje se colocan alrededor del gráfico circular. La ubicación de las etiquetas varía según el valor de una columna de datos asignada mediante la propiedad `AngleMemberPath` de la serie polar correspondiente.

El `NumericRadiusAxis` puede usarse con `NumericRadiusAxis` para representar [Polar Series](../types/polar-chart.mdx).
