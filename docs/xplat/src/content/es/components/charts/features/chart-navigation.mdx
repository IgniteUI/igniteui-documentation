## Navegación de gráficos con interacciones del usuario

Que el zoom esté activado de forma predeterminada depende del gráfico que use. Si usa `CategoryChart`, está activado de forma predeterminada, pero no en `DataChart`. Para habilitar o deshabilitar la navegación en la interfaz de usuario, debe establecer las propiedades `isHorizontalZoomEnabled` o `isVerticalZoomEnabled` del gráfico, o ambas, según la dirección en la que quiera habilitar o deshabilitar el zoom.

También es posible ampliar o desplazar simplemente haciendo clic con el ratón o usando el tacto. La propiedad `defaultInteraction` de data chart determina qué ocurre al hacer clic con el ratón o al tocar. Esta propiedad tiene como valor predeterminado `DragZoom` y, si se establece así con el zoom habilitado, al hacer clic y arrastrar aparecerá un rectángulo de vista previa sobre el área de trazado que se convertirá en el área ampliada del gráfico. Esta propiedad `defaultInteraction` también puede establecerse en `DragPan` para permitir el desplazamiento o en `InteractionState.None` para impedir estas operaciones.

## Navegación de gráficos con tacto, ratón y teclado

La navegación en data chart {Platform} puede realizarse con el tacto, el ratón o el teclado. De forma predeterminada, las siguientes operaciones pueden invocarse con el tacto, el ratón o el teclado:

- **Desplazamiento**: con las teclas de flecha <kbd>🡐</kbd> <kbd>🡒</kbd> <kbd>🡑</kbd> <kbd>🡓</kbd> del teclado o manteniendo pulsada la tecla <kbd>SHIFT</kbd>, haciendo clic y arrastrando con el ratón, o pulsando y moviendo el dedo en la pantalla táctil.
- **Acercar**: con la tecla <kbd>PAGE UP</kbd> del teclado, girando la rueda del ratón hacia arriba, o pellizcando con el tacto para acercar.
- **Alejar**: con la tecla <kbd>PAGE DOWN</kbd> del teclado, girando la rueda del ratón hacia abajo, o pellizcando con el tacto para alejar.
- **Ajustar al área de trazado del gráfico**: con la tecla <kbd>HOME</kbd> del teclado. No hay ninguna operación con el ratón ni con el tacto para esta función.
- **Zoom de área**: haga clic y arrastre con el ratón dentro del área de trazado con la propiedad `defaultInteraction` establecida en su valor predeterminado: `DragZoom`.

Las operaciones de zoom y desplazamiento también pueden habilitarse mediante teclas modificadoras, estableciendo las propiedades `dragModifier` y `panModifier`, respectivamente. Estas propiedades pueden establecerse en las siguientes teclas modificadoras y, al pulsarlas, se ejecutará la operación correspondiente:

| Valor del modificador | Tecla correspondiente |
| ---------------|------------------ |
| `Shift`        | <kbd>SHIFT</kbd> |
| `Control`      | <kbd>CTRL</kbd> |
| `Windows`      | <kbd>WIN</kbd> |
| `Apple`        | <kbd>APPLE</kbd> |
| `None`         | sin teclas |

## Navegación de gráficos con barras de desplazamiento

El gráfico puede desplazarse habilitando las propiedades `verticalViewScrollbarMode` y `horizontalViewScrollbarMode`.

Pueden configurarse con las siguientes opciones

- `Persistent`: las barras de desplazamiento permanecen siempre visibles mientras el gráfico esté ampliado, y se desvanecen cuando está completamente alejado.
- `Fading`: las barras de desplazamiento desaparecen después de usarlas y vuelven a aparecer cuando el ratón está cerca de su ubicación.
- `FadeToLine`: las barras de desplazamiento se reducen a una línea más fina cuando no se usa el zoom.
- `None`: valor predeterminado; no se muestran barras de desplazamiento.

## Navegación de gráficos mediante código

<DocsAside type="info">
La navegación por código del gráfico solo puede usarse con el control `DataChart`.
</DocsAside>

El data chart {Platform} proporciona varias propiedades de navegación que se actualizan cada vez que se produce una operación de zoom o de desplazamiento en el gráfico. También puede establecer cada una de estas propiedades para ampliar o desplazar el data chart mediante código. A continuación se muestra la lista de estas propiedades:

- `windowPositionHorizontal`: valor numérico que describe la parte X del rectángulo de vista de contenido que muestra el data chart.
- `windowPositionVertical`: valor numérico que describe la parte Y del rectángulo de vista de contenido que muestra el data chart.
- `windowRect`: un objeto `{RectType}` que representa un rectángulo que indica la parte del gráfico que está visible en ese momento. Por ejemplo, un `windowRect` de "0, 0, 1, 1" correspondería a la totalidad del data chart.
- `windowScaleHorizontal`: valor numérico que describe la parte de ancho del rectángulo de vista de contenido que muestra el data chart.
- `windowScaleVertical`: valor numérico que describe la parte de alto del rectángulo de vista de contenido que muestra el data chart.
