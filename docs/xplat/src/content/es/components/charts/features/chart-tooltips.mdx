# Información emergente de gráficos de {Platform}

En los gráficos {Platform}, las información emergente (tooltips) muestran detalles de los datos enlazados y se representan en ventanas emergentes cuando el usuario final pasa el cursor sobre los puntos de datos. La información emergente es compatible con `CategoryChart`<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> y los controles `DataChart`.

## Tipos de información emergente de gráficos de {Platform}

El gráfico {Platform} ofrece tres tipos de información emergente que puede usar con la información emergente habilitada, estableciendo la propiedad `DomainChart.toolTipType`. El siguiente ejemplo muestra el [Column Chart](../types/column-chart.mdx) con un cuadro combinado que puede usar para cambiar el tipo de información emergente.

<Sample src="/charts/category-chart/column-chart-with-tooltips" height={500} alt="Ejemplo de tipos de información emergente de {Platform}" />




La propiedad `DomainChart.toolTipType` es configurable y puede establecerse en una de las siguientes opciones:

| Valor de la propiedad     | Descripción  |
| -------------------|----------------|
| Tooltip de `Default` | Muestra una información emergente para un único elemento cuando el puntero se sitúa sobre él.  |
| Tooltip de `Data` | Muestra las informaciones emergentes de datos de todas las series del gráfico.  |
| Tooltip de `Item`    | Muestra una información emergente para cada elemento de datos de la categoría sobre la que se sitúa el puntero.  |
| Tooltip de `Category` | Muestra una información emergente agrupada para todos los puntos de datos de la categoría sobre la que se sitúa el puntero.  |


## Plantilla de información emergente de gráficos de {Platform}

Si ninguno de los tipos de información emergente integrados se ajusta a sus necesidades, puede crear sus propias informaciones emergentes para mostrar y dar estilo al título de la serie, a los valores de datos y a los valores de los ejes. En las secciones siguientes se muestra cómo hacerlo en distintos tipos de gráficos {Platform}.
