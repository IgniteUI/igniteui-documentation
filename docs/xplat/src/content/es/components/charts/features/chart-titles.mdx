# Título y subtítulo del gráfico de {Platform}

La característica de título y subtítulo del control de gráfico le permite añadir información en la sección superior de los gráficos {Platform}.

## Referencias de API

Al añadir un título o un subtítulo al control de gráfico, el contenido del gráfico se redimensiona automáticamente para dejar espacio a la información del título y del subtítulo.

| Nombre de la propiedad         | Tipo de propiedad   |     Descripción  |
| ----------------------|------------------|------------|
| `ChartTitle`          | string |  Contenido de texto del título.  |
| `titleTextColor`      | string |  Color del texto del título.  |
| `titleAlignment`      | HorizontalAlignment |  Alineación horizontal del título.  |
| `titleTextStyle`      | string | Estilo de fuente del título, p. ej., Italic Bold 8pt Times New Roman  |
| `titleTopMargin`      | número | Margen superior del título.  |
| `titleLeftMargin`     | número | Margen izquierdo del título.  |
| `titleRightMargin`    | número | Margen derecho del título.  |
| `titleBottomMargin`   | número | Margen inferior del título.  |
| `CategoryChart.subtitle`            | string |  Contenido de texto del título.  |
| `subtitleTextColor`   | string |  Color del texto del título.  |
| `subtitleAlignment`   | HorizontalAlignment |  Alineación horizontal del título.  |
| `subtitleTextStyle`   | string | Estilo de fuente del título, p. ej., Italic Bold 8pt Times New Roman  |
| `subtitleTopMargin`   | número | Margen superior del título.  |
| `subtitleLeftMargin`  | número | Margen izquierdo del título.  |
| `subtitleRightMargin` | número | Margen derecho del título.  |
| `subtitleBottomMargin`| número | Margen inferior del título.  |
