# Animaciones de gráficos de {Platform}

Las animaciones le permiten suavizar la entrada de las series cuando se carga un nuevo origen de datos. La animación disponible depende del tipo de serie de que se trate. Por ejemplo, la serie de columnas se anima subiendo desde el eje X, y una serie de líneas se anima dibujándose desde el origen del eje Y.

Las animaciones están deshabilitadas en los gráficos de {ProductName}, pero pueden habilitarse estableciendo la propiedad `isTransitionInEnabled` en true. A partir de ahí, puede establecer la propiedad `transitionInDuration` para determinar cuánto tarda en completarse la animación, y `transitionInMode` para determinar el tipo de animación que se produce.
