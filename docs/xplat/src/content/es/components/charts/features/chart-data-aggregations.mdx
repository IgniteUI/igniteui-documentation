# Agregaciones de datos de {Platform}

En el control {ProductName} `CategoryChart`, la función de agregaciones de datos le permite agrupar los datos del gráfico por los valores únicos de un miembro de datos en el eje X y, después, ordenar esos grupos. A continuación, puede aplicar resúmenes que se reflejarán en el rango del eje Y y se mostrarán en la información emergente al pasar el cursor sobre la serie.

## Ejemplo de agregaciones de datos de {Platform}

El siguiente ejemplo muestra un [gráfico de columnas](../types/column-chart.mdx) que agrupa por el miembro Country en el eje X, y que puede cambiarse a otras propiedades de cada elemento de datos, como Product, MonthName y Year, para agregar los datos de ventas. También hay una opción de resumen y de ordenación para obtener el orden deseado para la propiedad agrupada.

Tenga en cuenta que las funciones abreviadas de los desplegables de `initialSummaries` y `groupSorts` deben aplicarse tal como se muestra para obtener un resultado correcto según la propiedad que asigne. Por ejemplo: Sum(sales) as Sales | Sales Desc

<Sample src="/charts/category-chart/data-aggregations" height={500} alt="Ejemplo de agregaciones de datos de {Platform}" />


```json-snippet source="/charts/category-chart/data-aggregations"
{
    "skipAlterDataCasing": true,
    "descriptions": {
        "content": {
            "type": "CategoryChart",
    "name": "chart",
            "dataSourceRef": "SalesData",
            "initialGroups": "Country",
            "initialSummaries": "Sum(Sales) as Sales",
            "groupSorts": "Sales Desc"
        }
    }
}
```
