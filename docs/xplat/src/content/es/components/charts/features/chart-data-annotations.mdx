# Anotaciones de datos de gráficos de {Platform} <Badge variant="preview" />

En el gráfico {Platform}, las capas de anotación de datos le permiten anotar los datos representados en Data Chart con líneas inclinadas, líneas verticales u horizontales (también llamadas cortes de eje), bandas verticales u horizontales (que apuntan a un eje concreto), rectángulos e incluso paralelogramos (también llamados bandas). Con la compatibilidad con enlace de datos, puede crear tantas anotaciones como quiera para personalizar sus gráficos. Además, puede combinar distintas capas de anotación y superponer texto dentro del área de trazado para anotar eventos, patrones y regiones importantes de sus datos.

<DocsAside type="info">
Estas características están diseñadas para ejes cartesianos y, por ahora, no admiten ejes de radio ni angulares.
</DocsAside>

Por ejemplo, puede anotar los precios de las acciones con eventos y patrones bursátiles.

## Ejemplo de capa de cortes de anotación de datos de {Platform}

En {Platform}, el `DataAnnotationSliceLayer` representa varias líneas verticales u horizontales que cortan el gráfico en varios valores de un eje del componente `DataChart`. Esta capa de anotación de datos se usa a menudo para anotar eventos importantes (por ejemplo, los informes trimestrales de una empresa) en el eje X, o valores importantes en el eje Y. Si establece la propiedad TargetAxis en el eje Y, la capa de anotación de datos se representará como cortes horizontales; si la establece en el eje X, se representará como cortes verticales. Al igual que todas las series, DataAnnotationSliceLayer también admite el enlace de datos mediante la propiedad `DataSource`, que puede establecerse en una colección de elementos de datos que tengan al menos 1 columna de datos numérica asignada a la propiedad `annotationValueMemberPath`.

Por ejemplo, puede usar DataAnnotationSliceLayer para anotar los precios de las acciones con eventos importantes, como una división de acciones o los resultados de los informes de beneficios.

## Ejemplo de capa de bandas de anotación de datos de {Platform}

En {Platform}, el `DataAnnotationStripLayer` representa varias bandas verticales u horizontales entre 2 valores de un eje del componente `DataChart`. Esta capa de anotación de datos puede usarse para anotar la duración de eventos (por ejemplo, un desplome bursátil) en el eje X, o un rango importante de valores en el eje Y. Si establece la propiedad TargetAxis en el eje Y, la capa de anotación de datos se representará como bandas horizontales; si la establece en el eje X, se representará como bandas verticales. Al igual que todas las series, `DataAnnotationStripLayer` también admite el enlace de datos mediante la propiedad `DataSource`, que puede establecerse en una colección de elementos de datos que tengan al menos 1 columna de datos numérica asignada a la propiedad AnnotationValueMemberPath.

Por ejemplo, puede usar `DataAnnotationStripLayer` para anotar el gráfico con desplomes bursátiles y cambios en los tipos de interés federales.

## Ejemplo de capa de líneas de anotación de datos de {Platform}

En {Platform}, `DataAnnotationLineLayer` representa varias líneas entre 2 puntos del área de trazado del componente `DataChart`. Esta capa de anotación de datos puede usarse para anotar un gráfico bursátil con el crecimiento y el descenso de los precios de las acciones. Al igual que todas las series, DataAnnotationLineLayer también admite el enlace de datos mediante la propiedad `DataSource`, que puede establecerse en una colección de elementos de datos que tengan al menos 4 columnas de datos numéricas que representen las coordenadas x/y del punto inicial y del punto final de las líneas. Los puntos iniciales deben asignarse mediante las propiedades `startValueXMemberPath` y `startValueYMemberPath`, y los puntos finales mediante las propiedades `endValueXMemberPath` y `endValueYMemberPath`.

Por ejemplo, puede usar DataAnnotationLineLayer para anotar patrones de crecimiento y descenso en los precios de las acciones, así como los máximos y mínimos de 52 semanas de los precios de las acciones en el eje Y.

<Sample src="/charts/data-chart/data-annotation-line-layer" height={500} alt="Ejemplo de capa de líneas de anotación de datos de {Platform}" />


## Ejemplo de capa de rectángulos de anotación de datos de {Platform}

En {Platform}, `DataAnnotationRectLayer` representa varios rectángulos definidos por los puntos inicial y final en el área de trazado del componente `DataChart`. Esta capa de anotación de datos puede usarse para anotar una región del área de trazado, como patrones bajistas en los precios de las acciones. Al igual que todas las series, DataAnnotationRectLayer también admite el enlace de datos mediante la propiedad `DataSource`, que puede establecerse en una colección de elementos de datos que tengan al menos 4 columnas de datos numéricas que representen las coordenadas x/y del punto inicial y del punto final de los rectángulos. Los puntos iniciales deben asignarse mediante las propiedades `startValueXMemberPath` y `startValueYMemberPath`, y los puntos finales mediante las propiedades `endValueXMemberPath` y `endValueYMemberPath`.

Por ejemplo, puede usar DataAnnotationRectLayer para anotar patrones bajistas y huecos en los precios de las acciones en el eje Y.

<Sample src="/charts/data-chart/data-annotation-rect-layer" height={500} alt="Ejemplo de capa de rectángulos de anotación de datos de {Platform}" />


## Ejemplo de capa de bandas de anotación de datos de {Platform}

En {Platform}, `DataAnnotationBandLayer` representa varios rectángulos sesgados (paralelogramo de forma libre) entre 2 puntos del área de trazado del componente `DataChart`. Esta capa de anotación de datos puede usarse para anotar el rango de crecimiento y descenso de los precios de las acciones. Al igual que todas las series, DataAnnotationBandLayer también admite el enlace de datos mediante la propiedad `DataSource`, que puede establecerse en una colección de elementos de datos que tengan al menos 4 columnas de datos numéricas que representen las coordenadas x/y del punto inicial y del punto final de las líneas. Los puntos iniciales deben asignarse mediante las propiedades `startValueXMemberPath` y `startValueYMemberPath`, y los puntos finales mediante las propiedades `endValueXMemberPath` y `endValueYMemberPath`. Además, puede especificar el grosor o tamaño del rectángulo sesgado enlazando una columna de datos numérica a la propiedad AnnotationBreadthMemberPath.

Por ejemplo, puede usar DataAnnotationBandLayer para anotar el rango de crecimiento de los precios de las acciones.

## Referencias de API

La siguiente es una lista de miembros de la API mencionados en las secciones anteriores:

- `targetAxis`: esta propiedad especifica qué eje debe tener habilitada una capa DataAnnotationBandLayer, DataAnnotationLineLayer o DataAnnotationRectLayer.
- `DataSource`: esta propiedad enlaza datos a la capa de anotación para proporcionar la forma exacta.
- `startValueXMemberPath`: esta propiedad es una asignación al nombre de la columna de datos con las posiciones X del inicio de DataAnnotationBandLayer, DataAnnotationLineLayer o DataAnnotationRectLayer.
- `startValueYMemberPath`: esta propiedad es una asignación al nombre de la columna de datos con las posiciones Y del inicio de DataAnnotationBandLayer, DataAnnotationLineLayer o DataAnnotationRectLayer.
- `endValueXMemberPath`: esta propiedad es una asignación a la columna de datos con las posiciones X del final de DataAnnotationBandLayer, DataAnnotationLineLayer o DataAnnotationRectLayer.
- `endValueYMemberPath`: esta propiedad es una asignación a la columna de datos con las posiciones Y del final de DataAnnotationBandLayer, DataAnnotationLineLayer o DataAnnotationRectLayer.
- `startLabelXMemberPath`: esta propiedad es una asignación a la columna de datos que representa la etiqueta de superposición de la posición inicial del eje X a lo largo del eje.
- `startLabelXDisplayMode` | `startLabelYDisplayMode` | `endLabelXDisplayMode` | `endLabelYDisplayMode` | `centerLabelXDisplayMode`: estas propiedades especifican lo que deben mostrar las etiquetas de anotación en el inicio, el final o el centro de la forma de anotación, por ejemplo, el valor de datos asignado, la etiqueta de datos asignada, el valor del eje u ocultar una etiqueta de anotación concreta.
- `startLabelYMemberPath`: esta propiedad es una asignación a la columna de datos que representa la etiqueta del eje para la posición inicial de `DataAnnotationBandLayer`, `DataAnnotationLineLayer` y `DataAnnotationRectLayer` en el eje Y.
- `endLabelYMemberPath`: esta propiedad es una asignación a la columna de datos que representa la etiqueta del eje para la posición final de `DataAnnotationBandLayer`, `DataAnnotationLineLayer` y `DataAnnotationRectLayer` en el eje Y.
