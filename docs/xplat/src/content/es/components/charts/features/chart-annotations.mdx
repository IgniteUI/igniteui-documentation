# Anotaciones de gráficos de {Platform}

Las interacciones al pasar el cursor y las anotaciones del gráfico {Platform} se implementan mediante capas de interacción al pasar el cursor, que son series añadidas a la colección de series. Estas capas dependen de la posición del cursor. Cada una de estas capas de anotación ofrece una interacción distinta al pasar el cursor, que puede usarse por separado o combinada con otras para obtener interacciones potentes.

## Capa de línea de mira de {Platform}

La `CrosshairLayer` se representa como líneas cruzadas que se intersecan en el valor real de cada serie a la que están configuradas para apuntar, y cada serie representa un conjunto de líneas independiente.

Los tipos de línea de mira son:
- Horizontal
- Vertical
- Ambas

Las líneas de mira del gráfico también pueden configurarse para ajustarse a los puntos de datos estableciendo la propiedad `crosshairsSnapToData` en true; en caso contrario, las líneas de mira se interpolarán entre los puntos de datos. Las anotaciones también pueden habilitarse para mostrar el valor de la línea de mira a lo largo del eje.

Puede configurar la capa de línea de mira para que solo se muestre en una serie concreta, ya que de forma predeterminada se aplica a todas las series del control del gráfico. Para ello, establezca la propiedad `targetSeries`.

De forma predeterminada, el color de las líneas de mira es más claro que la serie con la que interactúan. Sin embargo, este valor predeterminado puede sustituirse para elegir el color que se usará en las líneas de mira. Esto se hace estableciendo la propiedad `CrosshairLayer.brush` de la capa de línea de mira.

## Capa de valor final de {Platform}

El `FinalValueLayer` del control `DataChart` ofrece una vista rápida a lo largo del eje del valor final mostrado en una serie.

Puede configurar esta anotación para que apunte a una serie concreta si quiere tener varias capas de valor final con configuraciones diferentes. Esto se puede hacer estableciendo la propiedad `targetSeries`.

También puede personalizar esta anotación estableciendo las siguientes propiedades:

- `axisAnnotationBackground`: esta propiedad se usa para elegir el pincel del color de fondo de la anotación. El valor predeterminado es usar el pincel de la serie.
- `axisAnnotationTextColor`: esta propiedad se usa para elegir el pincel del color del texto de la anotación.
- `axisAnnotationOutline`: esta propiedad se usa para elegir el pincel del color del contorno de la anotación.

El siguiente ejemplo muestra cómo dar estilo a la anotación de la capa de valor final estableciendo las propiedades indicadas arriba.

<Sample src="/charts/data-chart/final-value-layer-styling" height={500} alt="Estilo de la capa de valor final de {Platform}" />




```json-snippet source="/charts/category-chart/annotations-final-value"
{
    "type": "CategoryChart",
    "name": "chart",
    "dataSourceRef": "TemperatureAnnotatedData",
    "finalValueAnnotationsVisible": true,
    "finalValueAnnotationsBackground": "dodgerblue",
    "finalValueAnnotationsTextColor": "white",
    "finalValueAnnotationsPrecision": 0
}
```


## Capa de llamadas de {Platform}

El `CalloutLayer` muestra anotaciones de datos existentes o nuevos en el control del gráfico. Las anotaciones aparecen junto a los valores de datos indicados en el origen de datos.

Use las anotaciones de llamada para mostrar información adicional, como notas o detalles concretos sobre los puntos de datos, que quiera señalar a sus usuarios.

Puede configurar las llamadas para que apunten a una serie concreta si quiere tener varias capas de llamadas con configuraciones diferentes. Esto se puede hacer estableciendo la propiedad `targetSeries`.

También puede personalizar esta anotación estableciendo las siguientes propiedades:

- `calloutLeaderBrush`: esta propiedad se usa para elegir el pincel de las líneas guía de las llamadas de la capa.
- `calloutOutline`: esta propiedad se usa para elegir el pincel del color del contorno de la anotación.
- `calloutBackground`: esta propiedad se usa para elegir el pincel del color de fondo de la anotación. El valor predeterminado es usar el pincel de la serie.
- `calloutTextColor`: esta propiedad se usa para elegir el pincel del color del texto de la anotación.
- `calloutStrokeThickness`: esta propiedad se usa para elegir el grosor del fondo de las llamadas.
- `calloutCornerRadius`: esta propiedad se usa para redondear las esquinas de las llamadas.
- `allowedPositions`: esta propiedad se usa para elegir las posiciones que la capa de llamadas puede utilizar. Por ejemplo, arriba, abajo.

El siguiente ejemplo muestra cómo dar estilo a las anotaciones de la capa de llamadas estableciendo las propiedades indicadas arriba:
