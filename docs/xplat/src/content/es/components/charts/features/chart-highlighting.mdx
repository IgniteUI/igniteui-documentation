# Modos y comportamientos de resaltado de gráficos de {Platform}

Todos los gráficos {Platform} admiten una gran variedad de opciones de resaltado. `highlightingMode` puede establecerse para aclarar u oscurecer cuando el ratón está sobre una serie o un elemento de datos representado en el área de trazado. `highlightingBehavior` puede establecerse para que se aplique directamente sobre el elemento de datos o sobre el más cercano, con el fin de activar el efecto de resaltado. Los modos y comportamientos de resaltado son compatibles con `CategoryChart`<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> y los controles `DataChart`, y tienen la misma API para usar la característica de resaltado.

# Resaltado de la leyenda de gráficos de {Platform}

Todos los gráficos {Platform} admiten el resaltado desde la leyenda. `legendHighlightingMode` puede habilitarse para que, al pasar el ratón sobre un elemento de marcador de la leyenda, la serie representada se resalte en el área de trazado. El resaltado desde la leyenda es compatible con `CategoryChart`<PlatformBlock for="Web">, `FinancialChart`,</PlatformBlock> y los controles `DataChart`, y tienen la misma API para usar la característica de resaltado.

## Capas de resaltado

{ProductName} `CategoryChart` puede habilitar tres tipos de resaltado al pasar el cursor sobre los elementos de datos.

1. El resaltado de series resalta el punto de datos individual representado por un marcador o una columna cuando el puntero se sitúa sobre él. Se habilita estableciendo la propiedad `isSeriesHighlightingEnabled` en true.

2. El resaltado de elementos resalta los elementos de una serie dibujando una forma en banda en su posición o representando un marcador en su posición. Se habilita estableciendo la propiedad `isItemHighlightingEnabled` en true.

3. El resaltado de categorías se aplica a todos los ejes de categoría del gráfico. Dibuja una forma que ilumina la zona del eje más cercana a la posición del puntero. Se habilita estableciendo la propiedad `isCategoryHighlightingEnabled` en true.
