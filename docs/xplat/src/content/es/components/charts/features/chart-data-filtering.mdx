# Filtrado de datos de gráficos de {Platform}

El filtrado de datos le permite consultar grandes volúmenes de datos para analizar y representar un pequeño subconjunto de entradas mediante expresiones de filtro, sin necesidad de modificar manualmente el origen de datos enlazado al gráfico.

Puede encontrar aquí una lista completa de expresiones y palabras clave válidas para formar una cadena de consulta:

[Expresiones de filtro](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/webservices/use-filter-expressions-in-odata-uris)

> NOTA: cualquier filtro incorrecto aplicado dará como resultado un gráfico vacío.

## Ejemplo de filtro de datos de gráficos de {Platform}

El siguiente ejemplo muestra un [gráfico de columnas](../types/column-chart.mdx) de las tasas anuales de natalidad de varias décadas. El desplegable le permite seleccionar una década, que inserta una expresión mediante la propiedad `initialFilter` para actualizar la visualización del gráfico y, así, filtrar las demás décadas.

<Sample src="/charts/category-chart/data-filter" height={500} alt="Ejemplo de filtro de datos de {Platform}" />



La propiedad `initialFilter` es una cadena que requiere la siguiente sintaxis para filtrar correctamente. El valor requiere conjuntos de paréntesis que incluyan tanto la definición de la expresión de filtro como la columna y el valor asociados al registro o registros que se filtran.

p. ej., para mostrar todos los países que empiezan por la letra B:

"(startswith(Country, 'B'))"

p. ej., para concatenar más de una expresión:

"(startswith(Country, 'B') and endswith(Country, 'L') and contains(Product, 'Royal Oak') and contains(Date, '3/1/20'))"
