# Marcadores de gráficos de {Platform}

En {ProductName}, los marcadores son elementos visuales que muestran los valores de los puntos de datos en el área de trazado del gráfico. Los marcadores ayudan a los usuarios finales a identificar de inmediato el valor de un punto de datos, incluso si el valor cae entre las líneas de cuadrícula principales o secundarias.

## Tamaño de marcador de gráficos de {Platform}

Puede controlar las dimensiones exactas en píxeles independientes del dispositivo de los marcadores de puntos de datos estableciendo la propiedad `MarkerSize` en cualquier serie que admita marcadores. Esto le da un control preciso del tamaño que tienen los marcadores en pantalla, con independencia de la plantilla o del estilo de marcador que se use.

De forma predeterminada, el tamaño de los marcadores lo determina la plantilla de marcador de la serie. Cuando establece `MarkerSize` en un valor numérico concreto, todos los marcadores de esa serie se representan con ese ancho y alto exactos en píxeles independientes del dispositivo. Si vuelve a establecer `MarkerSize` en `\\NaN`, se restaura el tamaño predeterminado definido por la plantilla.

La propiedad `MarkerSize` está disponible en todos los tipos de serie que derivan de `MarkerSeries`, incluidos `LineSeries`, `SplineSeries`, `AreaSeries`, `ColumnSeries`, `ScatterSeries`, `ScatterLineSeries`, `ScatterSplineSeries` y los tipos de series polares y radiales.

Los siguientes ejemplos de código muestran cómo establecer `MarkerSize` en 30 píxeles independientes del dispositivo en un `ScatterLineSeries` del control `DataChart`:

```json-snippet
{
    "type": "DataChart",
    "$styleOptions": { "preferNameBindings": true },
    "axes": [
        { "type": "NumericXAxis", "name": "xAxis" },
        { "type": "NumericYAxis", "name": "yAxis" }
    ],
    "series": [
        {
            "type": "ScatterLineSeries",
            "name": "scatterLineSeries",
            "xAxisRef": "xAxis",
            "yAxisRef": "yAxis",
            "xMemberPath": "X",
            "yMemberPath": "Y",
            "markerType": "Circle",
            "markerSize": 30
        }
    ]
}
```


Para restablecer los marcadores a su tamaño predeterminado definido por la plantilla, establezca `MarkerSize` en `\\NaN` (o elimine el atributo en el marcado):

```json-snippet
{
    "type": "DataChart",
    "axes": [
        { "type": "CategoryXAxis", "name": "xAxis", "dataSourceRef": "CountryRenewableElectricity", "label": "Year" },
        { "type": "NumericYAxis", "name": "yAxis" }
    ],
    "series": [
        {
            "type": "LineSeries",
            "$type": "+doc:markup",
            "$markerType": "+doc:markup",
            "$markerSize": "+doc:markup",
            "xAxisRef": "xAxis",
            "yAxisRef": "yAxis",
            "dataSourceRef": "CountryRenewableElectricity",
            "valueMemberPath": "America",
            "markerType": "Circle",
            "markerSize": null
        }
    ]
}
```

## Tipo de marcador de marca de verificación de gráficos de {Platform}

Los gráficos {ProductName} incluyen una opción `MarkerType.Checkmark`. Este marcador dibuja un icono de marca de verificación en forma de V dentro de un círculo en los puntos de datos del gráfico.

Puede aplicar el tipo de marcador `Checkmark` a una serie concreta estableciendo su propiedad `MarkerType` en `MarkerType.Checkmark`. Para usar la forma de marca de verificación en todas las series del gráfico a la vez, establezca la propiedad `MarkerAutomaticBehavior` del gráfico en `MarkerAutomaticBehavior.Checkmark`.

<PlatformBlock for="WPF">

La propiedad `SeriesViewer.CheckmarkMarkerTemplate` define la plantilla de marcador usada para las series con tipo de marcador de marca de verificación, y puede usarse para personalizar su aspecto en todo el gráfico.

</PlatformBlock>
