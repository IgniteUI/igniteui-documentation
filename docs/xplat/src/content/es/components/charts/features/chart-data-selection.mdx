# Selección de gráficos de {Platform}

La función de selección {ProductName} de {Platform} Data Chart permite a los usuarios seleccionar de forma interactiva, resaltar y perfilar, y a la inversa, deseleccionar una o varias series dentro de un gráfico. Esto ofrece muchas posibilidades distintas sobre cómo interactúan los usuarios con los datos presentados, de formas más significativas.

## Configurar la selección

El comportamiento predeterminado de `selectionMode` está desactivado y requiere optar por una de las siguientes opciones. Hay varios modos de selección disponibles en `DataChart`:

- **Auto**
- **None**
- **Brighten**
- **FadeOthers**
- **GrayscaleOthers**
- **FocusColorThickOutline**
- **FocusColorOutline**
- **SelectionColorThickOutline**
- **SelectionColorOutline**
- **FocusColorFill**
- **SelectionColorFill**
- **ThickOutline**

`Brighten` atenuará el elemento seleccionado, mientras que `FadeOthers` producirá el efecto contrario.
`GrayscaleOthers` se comportará de forma similar a `FadeOthers`, pero mostrará un color gris en el resto de las series. Tenga en cuenta que esto sustituirá cualquier configuración de `selectionBrush`.
`SelectionColorOutline` y `SelectionColorThickOutline` dibujarán un borde alrededor de la serie.

Junto con ello, hay disponible un `selectionBehavior` para controlar con mayor precisión qué elementos se seleccionan. El comportamiento predeterminado de Auto es `PerSeriesAndDataItemMultiSelect`.

- **Auto**
- **PerDataItemMultiSelect**
- **PerDataItemSingleSelect**
- **PerSeriesAndDataItemMultiSelect**
- **PerSeriesAndDataItemSingleSelect**
- **PerSeriesAndDataItemGlobalSingleSelect**
- **PerSeriesMultiSelect**
- **PerSeriesSingleSelect**

## Configurar la selección múltiple

Otros modos de selección ofrecen distintos métodos de selección. Por ejemplo, usar `selectionBehavior` con `PerDataItemMultiSelect` afectará a todas las series de toda la categoría cuando haya varias series, permitiendo la selección entre categorías. En comparación con `PerDataItemSingleSelect`, solo puede seleccionarse una categoría de elementos a la vez. Esto resulta útil si varias series están enlazadas a orígenes de datos distintos y proporciona un mayor control de la selección entre categorías.
`PerSeriesAndDataItemGlobalSingleSelect` permite seleccionar una única serie en todas las categorías a la vez.

Cuando se aplica `focusBrush`, las series seleccionadas aparecerán con un borde cuando la propiedad `selectionMode` se establezca en una de las opciones de enfoque.

## Selección programática
La selección de gráficos también puede configurarse en código, de modo que los elementos seleccionados del gráfico se vean al iniciar o durante la ejecución. Esto se consigue añadiendo elementos a `SelectedSeriesItems` de `CategoryChart`. La propiedad `ChartSelection.matcher` del objeto `ChartSelection` permite seleccionar una serie basándose en un "comparador", ideal cuando no tiene acceso a la serie real del gráfico. Si conoce las propiedades que contiene su origen de datos, puede usar `ValueMemberPath` que tendría la serie.

El comparador es ideal para usarlo en gráficos, como `CategoryChart`, cuando no tiene acceso a la serie real, como `DataChart`. En este caso, si conoce las propiedades que contenía su origen de datos, puede deducir las ValueMemberPaths que tendría la serie.
