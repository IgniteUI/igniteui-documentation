# Superposiciones de gráficos de {Platform}

La {Platform} `DataChart` permite colocar líneas horizontales o verticales en un único valor numérico que defina con `ValueOverlay`. Esto puede ayudarle a visualizar datos como la media o la mediana de una serie concreta.

## Propiedades de la superposición de valores de {Platform}

A diferencia de otros tipos de serie que usan `DataSource` para el enlace de datos, la superposición de valores usa una propiedad `Value` para enlazar un único valor numérico. Además, la superposición de valores requiere que defina un único `ValueOverlay.axis` para usar. Si usa un eje X, la superposición de valores será una línea vertical, y si usa un eje Y, será una línea horizontal.

Cuando use un eje X o Y numérico, la propiedad `Value` debe reflejar el valor numérico real del eje donde quiera dibujar la superposición de valores. Cuando use un eje X o Y de categoría, `Value` debe reflejar el índice de la categoría en la que quiera que aparezca la superposición de valores.

Cuando use la superposición de valores con un eje angular numérico, aparecerá como una línea desde el centro del gráfico, y cuando use un eje de radio numérico, aparecerá como un círculo.

Las propiedades de apariencia de `ValueOverlay` se heredan de `Series`, por lo que `ValueOverlay.brush` y `ValueOverlay.thickness`, por ejemplo, están disponibles y funcionan igual que en otros tipos de serie.

También es posible mostrar una anotación en el eje sobre `ValueOverlay` para mostrar el valor de la superposición en el eje correspondiente. Para ello, puede establecer la propiedad `isAxisAnnotationEnabled` en true.

## Capa de valor de {Platform}

Los componentes de gráfico {Platform} también permiten usar líneas de valor para destacar distintos puntos focales de sus datos, como los valores mínimo, máximo y medio.

Aplicar `ValueLayer` en el <PlatformBlock for="Web">los componentes `CategoryChart` y `FinancialChart`</PlatformBlock><PlatformBlock for="WinUI, Uno">el componente `CategoryChart`</PlatformBlock> se hace estableciendo la propiedad `valueLines` en el gráfico. Esta propiedad recibe una colección de la enumeración `ValueLayerValueMode`. Puede combinar varias capas de valor en el mismo gráfico añadiendo varias enumeraciones `ValueLayerValueMode` a la colección `valueLines` del gráfico.

En `DataChart`, esto se hace añadiendo un `ValueLayer` a la colección `Series` del gráfico y, a continuación, estableciendo la propiedad `ValueLayer` en una de las enumeraciones `ValueLayerValueMode`. A continuación se indica cada una de estas enumeraciones y su significado:

- `Auto`: el modo de valor predeterminado de la enumeración `ValueLayerValueMode`.
- `Average`: aplica potencialmente varias líneas de valor para destacar el valor medio de cada serie representada en el gráfico.
- `GlobalAverage`: aplica una única línea de valor para destacar la media de todos los valores de las series del gráfico.
- `GlobalMaximum`: aplica una única línea de valor para destacar el valor máximo absoluto de todos los valores de las series del gráfico.
- `GlobalMinimum`: aplica una única línea de valor para destacar el valor mínimo absoluto de todos los valores de las series del gráfico.
- `Maximum`: aplica potencialmente varias líneas de valor para destacar el valor máximo de cada serie representada en el gráfico.
- `Minimum`: aplica potencialmente varias líneas de valor para destacar el valor mínimo de cada serie representada en el gráfico.

Si quiere evitar que una serie concreta se tenga en cuenta al usar el elemento `ValueLayer`, puede establecer la propiedad `targetSeries` en la capa. Esto obligará a la capa a apuntar a la serie que defina. Puede tener tantos elementos `ValueLayer` como quiera dentro de una única `DataChart`.

## Texto de superposición del gráfico <Badge variant="preview" />

{Platform} `ValueOverlay`, `ValueLayer` y todas las capas de anotación de datos pueden representar texto de superposición personalizado dentro del área de trazado del componente DataChart. Puede usar este texto de superposición para anotar eventos importantes (por ejemplo, informes trimestrales de la empresa) en el eje X, o valores importantes en el eje Y, en relación con las capas.

Por ejemplo, puede usar `DataAnnotationSliceLayer`, `ValueOverlay` y `ValueLayer` para mostrar texto de superposición.
