# {Platform}: enlazar y superponer varios archivos de forma

En el mapa de {ProductName} puede añadir varios objetos de serie geográfica para superponer algunos archivos de forma con datos geoespaciales. Por ejemplo, `GeographicSymbolSeries` para representar las ubicaciones geográficas de los puertos, `GeographicPolylineSeries` para representar las rutas entre puertos, y `GeographicShapeSeries` para representar las formas de los países.

## Ejemplo de {Platform}: enlazar y superponer varios archivos de forma


<Sample src="/maps/geo-map/binding-multiple-shapes" height={500} alt="Ejemplo de {Platform}: enlazar y superponer varios archivos de forma" />




Este tema le guía paso a paso para mostrar varias series geográficas en el componente de mapa. Todas las series geográficas representan los datos geoespaciales cargados desde archivos de forma mediante la clase `ShapefileRecord`. Consulte el tema [Enlazar archivos de forma](./geo-map-binding-shp-file.mdx) para más información sobre el objeto `ShapefileRecord`.

- `GeographicSymbolSeries`: muestra las ubicaciones de las principales ciudades
- `GeographicPolylineSeries`: muestra las rutas entre los principales puertos
- `GeographicShapeSeries`: muestra las formas de los países del mundo

Puede usar series geográficas en las combinaciones anteriores u otras para representar los datos que desee.

## Importar los componentes

En primer lugar, importemos los componentes y los módulos necesarios:

```json-snippet id="shapes" source="/maps/geo-map/binding-multiple-shapes" channel="bindingImports,handlersImports"
{
    "descriptions": {
        "content": {
            "type": "GeographicMap",
            "name": "geoMap",
            "height": "100%",
            "width": "100%",
            "zoomable": true,
            "series": [
                {
                    "type": "GeographicShapeSeries",
                    "name": "polygonSeries",
                    "shapeMemberPath": "points",
                    "shapeFill": "rgb(150, 150, 150)",
                    "shapeStroke": "Black",
                    "shapeStrokeThickness": 1
                },
                {
                    "type": "GeographicPolylineSeries",
                    "name": "lineSeries",
                    "shapeMemberPath": "points",
                    "shapeStroke": "rgba(147, 15, 180, 0.5)",
                    "thickness": 3
                },
                {
                    "type": "GeographicSymbolSeries",
                    "name": "symbolSeries",
                    "longitudeMemberPath": "longitude",
                    "latitudeMemberPath": "latitude",
                    "markerType": "Circle",
                    "markerOutline": "rgb(2, 102, 196)",
                    "markerBrush": "White"
                }
            ]
        }
    },
    "onViewInit": [
        "MapMultipleShapesLoad"
    ]
}
```

## Fondo del mapa

Además, puede que quiera ocultar las imágenes geográficas del contenido de fondo del mapa si sus archivos de forma proporcionan contexto geográfico suficiente (por ejemplo, la forma de los países) para su aplicación.

```json-snippet code="allCode"
{
    "type": "GeographicMap",
    "name": "geoMap",
    "height": "100%",
    "width": "100%",
    "backgroundContent": null
}
```
