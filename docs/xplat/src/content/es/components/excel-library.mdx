# Información general de la biblioteca de Excel de {Platform}

La biblioteca de Excel de Infragistics {Platform} le permite trabajar con datos de hojas de cálculo mediante objetos de hoja de cálculo de Microsoft® Excel® conocidos, como <ApiLink type="Workbook" />, <ApiLink type="Worksheet" />, <ApiLink type="WorksheetCell" label="Cell" />, <ApiLink type="Formula" /> y muchos más. La biblioteca de Excel de Infragistics {Platform} le facilita representar los datos de su aplicación en una hoja de cálculo de Excel, así como transferir datos desde Excel a su aplicación.

## Implementación de los módulos


- **IgxExcelCoreModule**: contiene el modelo de objetos y gran parte de la infraestructura de Excel
- **IgxExcelFunctionsModule**: contiene la mayoría de las funciones para la evaluación de fórmulas, como Sum, Average, Min, Max, etc. La ausencia de este módulo no causará problemas con el análisis de fórmulas si la fórmula va a calcularse. Por ejemplo, si aplica una fórmula como "=SUM(A1:A5)" y pide el Value de la celda, obtendrá un error #NAME!. No es una excepción lanzada, sino un objeto que representa un error concreto, ya que las fórmulas pueden dar lugar a errores.
- **IgxExcelXlsModule**: contiene la lógica de carga y guardado de archivos xls (y tipos relacionados), es decir, los WorkbookFormats relacionados con Excel 97 a 2003.
- **IgxExcelXlsxModule**: contiene la lógica de carga y guardado de archivos xlsx (y tipos relacionados), es decir, los WorkbookFormats relacionados con Excel 2007 y StrictOpenXml.
- **IgxExcelModule**: hace referencia a los otros 4 módulos y, básicamente, garantiza que toda la funcionalidad esté cargada y disponible.

## Requisitos

Para usar la biblioteca de Excel de {Platform}, debe añadir el paquete NuGet de la biblioteca de Excel de esta manera:

```cmd
> dotnet add package IgniteUI.Blazor.Documents.Excel
```

Añada la siguiente instrucción using:

```razor
@using Infragistics.Documents.Excel
```

Si usa un proyecto Blazor WebAssembly (WASM), hay un par de pasos adicionales:

- Añada una referencia al siguiente script en el archivo wwwroot/index.html:

```razor
<script src="_content/IgniteUI.Blazor.Documents.Excel/excel.js"></script>
```

- Establezca la propiedad estática <ApiLink type="Workbook" member="InProcessRuntime" label="Workbook.InProcessRuntime" /> en el entorno de ejecución actual. Esto puede hacerse usando el siguiente código:

```razor
@using Microsoft.JSInterop

@code {

    [Inject]
    public IJSRuntime Runtime { get; set; }

    protected override void OnInitialized()
    {
        base.OnInitialized();
        Workbook.InProcessRuntime = (IJSInProcessRuntime)this.Runtime;
    }
}
```

<PlatformBlock for="Blazor">

```csharp
protected override void OnInitialized()
{
    var memoryStream = new System.IO.MemoryStream();
    workbook.Save(memoryStream);

    memoryStream.Position = 0;
    var bytes = memoryStream.ToArray();
    this.SaveFile(bytes, "fileName.xlsx", string.Empty);
}

private void SaveFile(byte[] bytes, string fileName, string mime)
{
    if (this.Runtime is WebAssemblyJSRuntime wasmRuntime)
      wasmRuntime.InvokeUnmarshalled<string, string, byte[], bool>("BlazorDownloadFileFast", fileName, mime, bytes);
    else if (this.Runtime is IJSInProcessRuntime inProc)
      inProc.InvokeVoid("BlazorDownloadFile", fileName, mime, bytes);
}
```

</PlatformBlock>

## Gestión del heap

Debido al tamaño de la biblioteca de Excel, se recomienda deshabilitar la generación de mapas de código fuente.

Modifique `angular.json` estableciendo la opción `vendorSourceMap` en architect => build => options y en serve => options:

```ts
    "architect": {
        "build": {
          "builder": "...",
          "options": {
            "vendorSourceMap": false,
            "outputPath": "dist",
            "index": "src/index.html",
            "main": "src/main.ts",
            "tsConfig": "src/tsconfig.app.json",
                  // ...
          },
              // ...
        },
        "serve": {
          "builder": "...",
          "options": {
            "vendorSourceMap": false,
            "browserTarget": "my-app:build"
          },
              // ...
        },
        // ...
      }
```
