# {Platform}: enlazar varios orígenes de datos

En el mapa de {ProductName} puede añadir varios objetos de serie geográfica para superponer orígenes de datos personalizados con datos geoespaciales. Por ejemplo, `GeographicSymbolSeries` para representar las ubicaciones geográficas de los aeropuertos, `GeographicPolylineSeries` para representar los vuelos entre aeropuertos, y una segunda `GeographicPolylineSeries` para representar las líneas de cuadrícula de las principales coordenadas geográficas.


## Ejemplo de {Platform}: enlazar varios orígenes de datos


<Sample src="/maps/geo-map/binding-multiple-sources" height={500} alt="Ejemplo de {Platform}: enlazar varios orígenes de datos" />




Este tema le guía paso a paso para mostrar varias series geográficas que representarán los siguientes datos geoespaciales:

- `GeographicSymbolSeries`: muestra las ubicaciones de los principales aeropuertos
- `GeographicPolylineSeries`: muestra los vuelos entre aeropuertos
- `GeographicPolylineSeries`: muestra las líneas de cuadrícula de las principales coordenadas

Puede usar series geográficas en esta u otras combinaciones para representar los datos que desee.

## Crear los orígenes de datos

Cree orígenes de datos para todas las series geográficas que quiera mostrar en el mapa de {ProductName}. Por ejemplo, puede usar el script [WorldConnections](./geo-map-resources-world-connections.mdx).


```json-snippet source="/maps/geo-map/binding-multiple-sources" channel="auto"
{
    "type": "GeographicMap",
    "name": "geoMap",
    "$type": ["+doc:markup", "+doc:bindingCode"],
    "$series": "-doc:markup",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicPolylineSeries",
            "name": "lineSeries",
            "dataSourceRef": "WorldFlights",
            "shapeMemberPath": "Points",
            "shapeStroke": "rgba(196, 14, 14, 0.05)",
            "shapeStrokeThickness": 4
        },
        {
            "type": "GeographicPolylineSeries",
            "name": "gridSeries",
            "dataSourceRef": "WorldGridlines",
            "shapeMemberPath": "Points",
            "shapeStroke": "Gray",
            "shapeStrokeThickness": 1
        },
        {
            "type": "GeographicSymbolSeries",
            "name": "symbolSeries",
            "dataSourceRef": "WorldAirports",
            "latitudeMemberPath": "Lat",
            "longitudeMemberPath": "Lon",
            "markerType": "Circle",
            "markerBrush": "#aad3df",
            "markerOutline": "rgb(73, 73, 73)",
            "thickness": 1
        }
    ]
}
```
