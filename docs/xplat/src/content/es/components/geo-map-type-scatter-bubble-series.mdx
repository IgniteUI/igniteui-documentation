# Mapa de burbujas geográfico de {Platform}

En el componente de mapa de {Platform} puede usar `GeographicProportionalSymbolSeries` para representar burbujas o marcadores proporcionales en las ubicaciones geográficas indicadas por los datos de su aplicación. Esta serie de mapa puede ser útil para destacar puntos de interés en su caso de negocio concreto, como grandes almacenes, almacenes u oficinas. También puede usar esta serie de mapa en un sistema de gestión de flotas o en un sistema GPS para el seguimiento dinámico de vehículos.

## Resumen de la configuración
Al igual que otros tipos de series de dispersión del control de mapa, la serie `GeographicProportionalSymbolSeries` tiene la propiedad `dataSource`, que puede enlazarse a un array de objetos. Además, cada elemento de datos del origen de elementos debe tener dos columnas de datos que almacenen las coordenadas geográficas de longitud y latitud, y usa las propiedades `longitudeMemberPath` y `latitudeMemberPath` para asignar estas columnas de datos. La configuración de `radiusScale` y `radiusMemberPath` define el radio de las burbujas.

La tabla siguiente resume las propiedades de la serie `GeographicProportionalSymbolSeries` usadas para el enlace de datos.

| Propiedad|Tipo|Descripción |
| ---|---|--- |
| `dataSource`|cualquiera|Obtiene o establece el origen de elementos |
| `longitudeMemberPath`|string|Usa la propiedad DataSource para determinar la ubicación de los valores de longitud en los elementos asignados |
| `latitudeMemberPath`|string|Usa la propiedad DataSource para determinar la ubicación de los valores de latitud en los elementos asignados |
| `radiusMemberPath`|string|Establece la ruta que se usa para obtener los valores de radio de la serie. |
| `radiusScale`|`SizeScale`|Obtiene o establece la propiedad de escala de radio para la serie de burbujas actual. |
| `minimumValue`|cualquiera|Configura el valor mínimo para calcular los subrangos de valores. |
| `maximumValue`|cualquiera|Configura el valor máximo para calcular los subrangos de valores. |

## Fragmento de código

```json-snippet source="/maps/geo-map/type-scatter-bubble-series" code="allCode"
{
    "type": "GeographicMap",
    "name": "map",
    "height": "100%",
    "width": "100%",
    "zoomable": true,
    "series": [
        {
            "type": "GeographicProportionalSymbolSeries",
            "name": "WorldCitiesSeries",
            "dataSourceRef": "WorldCities",
            "markerType": "Circle",
            "radiusScale": {
                "type": "SizeScale",
                "minimumValue": 4,
                "maximumValue": 60
            },
            "fillScale": {
                "type": "ValueBrushScale",
                "brushes": [
                    "rgba(14, 194, 14, 0.4)",
                    "rgba(252, 170, 32, 0.4)",
                    "rgba(252, 32, 32, 0.4)"
                ],
                "minimumValue": 0,
                "maximumValue": 30
            },
            "fillMemberPath": "Population",
            "radiusMemberPath": "Population",
            "latitudeMemberPath": "Y",
            "longitudeMemberPath": "X",
            "markerOutline": "rgba(0,0,0,0.3)"
        }
    ]
}
```
